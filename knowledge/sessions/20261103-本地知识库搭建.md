# 本地知识库搭建（Claude Code 每次会话自动检索）

## [2026-11-03] 动作：搭建 BM25 本地知识库 + UserPromptSubmit hook 自动注入

### 产物
- `.claude/kb/kb_search.py` — 纯标准库 BM25 检索（中文 bigram + 英文分词、标题加权 ×2、## 分块、mtime pickle 缓存、top-4 片段 ≤1600 字、异常静默 exit 0）
- `.claude/settings.json` — UserPromptSubmit hook，用仓库根 `.venv` Python 3.12（勿用系统 py -3 / 3.14）
- `CLAUDE.md` — 知识库使用/沉淀规则
- `knowledge/{INDEX.md,external/,sessions/}` — 知识库三层结构

### 知识源（~210 文件 + 外部源）
`knowledge/**/*.md` + `.kiro/steering/*.md`（精华，specs 2634 个不入）+ `docs/**/*.md` + `README.md`

### 验证证据（2026-11-03 实测）
- 中文「试算平衡表导入」→ README 项目概述；「电子签名三级 CA」→ docs/reference/platform-requirements.md § 附录D（精准）
- 英文「Redis connection refused login 500」→ .kiro/steering/memory.md § 环境配置（精准命中 Docker 端口转发陈旧坑）
- 无关词/短问候 → 空输出；坏 JSON/空 stdin → 静默 exit 0
- 性能：冷建索引 1.30s / 缓存命中 0.66s（timeout 15s 充裕）

### 坑与决策
- **Windows 管道编码**：stdin 默认 GBK 解码中文 JSON 会炸、stdout print 中文受控制台编码影响 → 必须 `sys.stdin.buffer.read()` + utf-8 优先 gbk 回退，输出走 `sys.stdout.buffer.write(...encode('utf-8'))`
- **BM25 而非向量**：本地轻量优先（用户偏好）；后续要语义检索可升级 qmd/pgvector
- 每次提问注入上限 1600 字、prompt <6 字符跳过，避免污染上下文
