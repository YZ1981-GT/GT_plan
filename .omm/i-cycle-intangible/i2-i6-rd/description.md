## 共享的截止测试机制

两者共用 `useCycleCutoff`（配置驱动通用循环截止测试）：

- 双向：正向（记账 → 原始凭证）+ 反向（原始凭证 → 记账）
- 跨期判定：`isCutoffPeriodCrossing` → 已委托 `cutoffCanonical.crossesByCutoffBoundary`（**截止日两侧 XOR**）
- 自动提取：`POST /sampling/cutoff-test` + 显式传 `cutoff_date`（历史上调不存在的 `ledger/cutoff-samples` 恒 404，已修）
- 跨期 → `draftAjeFromCrossPeriod` 生成 AJE 草稿到 I2-3 / I6-3 + 发 `a13:push-misstatement`
- 双侧证据缺失 → 结论"证据不完整"（不判正常），完成门禁扣除该类行

## 审计要点

- **资本化 vs 费用化的分流合理性**是核心：研究/开发阶段划分点、五条件是否真满足、
  是否存在为规避费用化而提前资本化
- **截止测试**：研发支出跨期是常见操纵手法（年末大额资本化、次年初费用化）
- I2/I6 金额与研发投入总额（政府补助/高新认定口径）的一致性
