# I1 无形资产（1701 原值 / 1702 累计摊销 / 1703 减值准备）

componentType `i1-intangible-assets`，后端 `_i1_intangible_assets.py`。结构对标 H1 固定资产。

## 子目录

| 目录 | 内容 |
|---|---|
| `core/` | 审定表 I1-1（原值/摊销/减值三段，**回写三个科目**）/ 明细 I1-2 / 调整 I1-3 / 附注上市国企 / 目录 |
| `amortization/` | 摊销测算（直线法为主；**使用寿命不确定的无形资产不摊销只减值**）+ 摊销归属分配 |
| `impairment/` | 减值测试（CAS8 迹象 → 可收回金额 DCF/公允净额） |
| `inspection/` | 增加检查（抽凭 1701）/ 减少检查 / 权属证明（专利证书 / 商标注册证 / 土地使用权证）/ 合同检查 |

## 关键机制

- **审定回写三科目**：1701 + 1702 + 1703（`useI1FormData` / `useI1Adjudication` 各有一份常量）
- **附注上市变动表列头动态**：`buildI1ListedColumns(state)` 随 `categories` 运行时构建；
  国企版为英文键子表（`I1_SOE_COLUMNS`）需显式映射中文列头
- **数据资源 / 摊销归属子表**（上市版附注特有）
- 附注 **五、26（上市）/ 八、27（国企）**，正反向跳转 + `buildI1SyncPayload` + columns 已登记覆盖率守卫
- 减值 → K11（6701）；摊销 → F5/K8/K9/I6（按用途归属）

## 与其他元素的关系

- **上游**：I2 开发支出转入（内部研发形成）、外购、投资者投入、非同控合并取得
- **下游**：处置 → H10（`i1_disposal` 类行）；摊销年限税会差异 → N1/N3；土地使用权与 H1 房屋建筑的划分
- **权属受限**：抵押的无形资产（土地使用权最常见）→ L1/L3 借款质押披露
