# I3 商誉（1711）

componentType `i3-goodwill`，后端 `_i3_goodwill.py`。**唯一"不摊销只减值"的长期资产**，
故没有 `amortization/`，只有 `core/` + `impairment/` + `shared/`。

## 子目录

| 目录 | 内容 |
|---|---|
| `core/` | 审定表 I3-1 / 明细 I3-2（按被投资单位/资产组）/ 调整 I3-3 / 附注上市国企 / 目录 |
| `impairment/` | 减值测试：资产组认定 + 商誉分摊 + 可收回金额（DCF：预测期/增长率/WACC/敏感性）+ 业绩承诺跟踪 |
| `shared/` | 共享表体/工具 |

科目 `ACCOUNT_CODE_1711='1711'`。附注 **五、28（上市）/ 八、29（国企）**，
附注含"被投资单位 / 期初 / 增 / 减 / 期末 + 资产组假设 + 业绩承诺"子表。

## 审计逻辑（CAS8 + CAS20）

1. **来源**：非同控合并的合并成本 > 取得可辨认净资产公允价值份额的差额（来自 **G7-13 投资成本测试**的正差额）
2. **资产组认定与商誉分摊**：商誉必须分摊到能受益于协同效应的资产组/资产组组合 ——
   **没有资产组认定，减值测试无对象**
3. **年度强制减值测试**（无论有无迹象）：可收回金额 = MAX(公允价值净额, 使用价值)；
   使用价值用 DCF（预测期 5 年 + 稳定期永续增长 + WACC 折现），须做关键假设敏感性分析
4. **业绩承诺**：并购对赌未达标是减值强信号，需跟踪承诺期实际 vs 承诺业绩
5. **减值顺序**：先抵减商誉，再按比例分摊到资产组其他资产；**一经确认不得转回**
6. 减值损失 → **K11 资产减值损失（6701）**

## 与其他元素的关系

- 上游：G7-13（投资成本测试正差额）/ G7-8·G7-9（合并初始计量）/ 合并模块
- 下游：K11（6701）减值损失；处置子公司时商誉随之处置（合并层面）
- 少数股东享有的商誉（全部商誉法 vs 部分商誉法）在合并模块处理
