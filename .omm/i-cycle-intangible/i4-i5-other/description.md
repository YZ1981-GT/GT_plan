# I4 长期待摊费用（1801）/ I5 其他非流动资产（1911）

两个"零散科目"，结构较轻（`core/` + `shared/`，I4 另有 `amortization/`）。

## I4 长期待摊费用（`i4-long-term-prepaid`）

| 目录 | 内容 |
|---|---|
| `core/` | 审定表 I4-1 / 明细 I4-2 / 调整 I4-3 / 附注上市国企 / 目录 |
| `amortization/` | 摊销测算（按受益期限直线摊销） |
| `shared/` | 共享表体 |

- 科目 `ACCOUNT_CODE_1801='1801'`
- 默认类别（`useI4Adjudication.DEFAULT_CATEGORIES`）：**装修费 / 开办费 / 租赁改良 / 技术转让费 / 其他**
- 附注 **五、29 / 八、30**（变动表：期初 / 本期增加 / 本期摊销 / 其他减少 / 期末）
- 审计要点：受益期限是否合理（不得超过租赁期）、是否应费用化而非资本化、
  租赁改良的摊销期 = min(租赁期, 改良使用寿命)

## I5 其他非流动资产（`i5-other-noncurrent-assets`）

| 目录 | 内容 |
|---|---|
| `core/` | 审定表 I5-1（**三层矩阵**）/ 明细 I5-2（4 区段 Tab）/ 调整 / 附注上市国企 / 目录 |
| `shared/` | 共享表体 |

- 科目 `ACCOUNT_CODE_1911='1911'`
- **审定表三层矩阵**：原值 / 减值 / 净值，且有**期初账项调整 + 期初重分类调整**（`openingAje` / `openingRje`），
  期末 = F + H − I（对齐源模板列公式）
- **明细表 4 区段 Tab**（原值 | 减值 | 净值 + 未审→期初调整→账项/重分类→审定），公式如 L = B + F + G
- 内置 **10 类** + 可从 **D7 合同负债 / M12 / G2-13** 等来源带入；CAS14 相关提示
- 旧字段回写净值审定供 I5-1 消费（`i5-2 → i5-1` seed 链，`openingAje`/`openingRje` 写入）
- 附注 **五、31 / 八、32**（上市"期末/上年年末" vs 国企"期末/期初"列头不同）

## 共同要点

- 两者都是**兜底/零散科目**，内容随客户差异极大 → 分类归属必须人工核对，防与来源科目重复列报
- 长期待摊与其他非流动资产的边界（预付长期费用 vs 预付设备款）容易混
- 减值 → K11（6701）
