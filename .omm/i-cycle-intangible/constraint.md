# 约束（I 循环）

平台通用铁律见 `.omm/d-cycle-sales/constraint.md`。以下为 I 循环附加约束。

1. **I6 与 K9 共用 6602**：I6 只处理研发明细口径，回写 TB 时不得与 K9 管理费用整体审定数相互覆盖；
   两者审定合计的关系必须显式核对而非各自独立回写。
2. **I1 审定回写三个科目**（1701 原值 / 1702 累计摊销 / 1703 减值准备），缺一会导致净值口径错。
3. **资本化判定不自动化**：CAS6 五条件逐项留痕 + 证据索引，禁止用规则自动判"可资本化"。
4. **截止测试用 `POST /sampling/cutoff-test` 并显式传 `cutoff_date`**；
   缺双侧证据（记账日 / 原始凭证日任一缺失）结论必须是"证据不完整"，不得判正常；
   完成门禁要扣除"证据不完整"行。
5. **前端调后端一律带 `/api` 前缀**（`http` 的 baseURL 是 `/`，不自动补），改端点前 grep 核实端点真实存在。
6. **商誉不摊销只减值**；无资产组认定/未分摊时减值测试应阻断或明确提示，不产出无归属数值。
7. **减值一经确认不得转回**（CAS8），减值损失进 K11（6701）。
8. **I5 带入后必须核对分类归属**，防与来源科目重复列报。
9. **附注章节号对 `note_template_variant_matrix.json` 核权威**（I1 五、26 / I2 五、27 / I3 五、28 /
   I4 五、29 / I5 五、31 / I6 五、66），纯编号谓词必须精确 `===`。
10. **动态列头表（I1 上市变动表随 categories）用 `buildI1ListedColumns(state)` 运行时构建**，
    不硬编码列头；两级表头（I2）扁平合并为组合列名。
