# M6 利润分配-未分配利润（4104）— 权益枢纽

componentType `m6-retained-earnings`，后端 `_m6_retained_earnings`。M 循环的**勾稽枢纽**，
连接损益结转、盈余公积提取、一般风险准备、股利分配四条下游。

## 利润分配表（源模板固定顺序）

```
期初未分配利润
+ 本年净利润（本年利润 4103本年利润 结转）
+ 其他调整（会计政策变更/前期差错更正等）
= 可分配利润
− 提取法定盈余公积（净利润 × 10%，累计达注册资本 50% 可停提）→ M5
− 提取任意盈余公积 → M5
− 提取一般风险准备（金融企业）→ M8
− 应付普通股股利 → M1
− 转作股本的普通股股利 → M2
= 期末未分配利润
```

## 关键勾稽

- **本年净利润 ↔ 利润表**：M6 的本年净利润行必须与利润表净利润一致
- **提取盈余公积 ↔ M5**：法定 10% 的计算基数是净利润（不是可分配利润）
- **一般风险准备 ↔ M8**：金融企业专属（M8 也用 4104，见 `../concern.md` §1）
- **应付股利 ↔ M1**：宣告分配的股利进 M1 应付股利（2232）

## 审计要点

- 净利润结转的完整性与准确性
- 盈余公积提取比例合规（法定 10%、累计上限 50%）
- 利润分配方案的董事会/股东会决议依据
- 弥补以前年度亏损的顺序（税前 vs 税后）
- 期末未分配利润 = SCE 与资产负债表所有者权益的勾稽点

## 与其他元素的关系

- 上游：本年利润（全部损益科目结转）
- 下游：M5 盈余公积 / M8 一般风险准备 / M1 应付股利 / M2 转增股本
- SCE（所有者权益变动表）的主要变动行
