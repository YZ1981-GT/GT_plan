# 明细表族：现金 / 银行 / 其他 / 数字货币（E1-2 · E1-3 · E1-4）

## E1-2 现金明细（`E1TabCashDetail`）

按币种 / 保管人逐行；公式 `期末 = (期初 + 增加 − 减少) × 汇率`（`recalcRow`）。
四表取数从 `tb_balance` 1001 叶子科目 seed。持久化 `E1-cash-detail-rows` + 聚合键。

## E1-3 银行存款明细（`E1TabBankDetail`，双 variant）

- `variant='rmb'`（sheet 名含"仅人民币"）/ `variant='multi'`（含"人民币及外币"）
- 分组：**银行存款本金**（1002 → institution 组）与 **其他货币资金**（1012 → other 组）
- 四表取数把 1002 与 1012 的叶子分别 seed 到对应组
- 函证回函按**开户行名规范化匹配**回写 `confirmAmount`（只对 bank 类型做名称匹配，不误配其他类型）
- 保证金 / 受限资金字段供附注"受限制的货币资金明细"与 CFS 勾稽

## E1-4 数字货币明细（`E1TabDigitalCurrency`）

数字人民币等，归入 1012 组一起回写。

## 明细 → 审定的契约

每个明细 composable 在持久化行数据时**必须同时持久化聚合键**（未审合计），
否则审定表在明细 sheet 未挂载时取不到数（这是 E1 早期"差异恒为现金额"的根因之一）。

## 四表来源面板

E1-2 / E1-3 / E1-10 顶部有「🔗四表取数（公式管理）」面板：列出来源科目、`TB('code','期末余额')` 公式、
期初/增/减/期末，以及「🔄重新取数」（**会覆盖持久化**，与 onMounted 的 persist-first 种子不同）。
