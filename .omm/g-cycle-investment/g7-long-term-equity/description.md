# G7 长期股权投资（1511）

**拆三个 componentType**，是 G 循环最复杂的科目包（成本法 / 权益法 / 子公司三套审计逻辑）。

| 入口 | 主入口组件 | 子目录 |
|---|---|---|
| main | `GtG7LongTermEquityMain` | `core/`（审定 G7-1 / 明细 / 调整 / 目录 / 减值 G7-17 / 凭证 G7-18 / 未确认损失 G7-16 等）、`disclosure/`（附注上市 + 国企）、`handbooks/` |
| method | `GtG7EquityMethod` | `calculation/`（权益法调整计算 G7-14）、`impairment/`、`info/`（被投资单位信息 G7-5） |
| subsidiary | `GtG7EquitySubsidiary` | `initial/`（同控 G7-8 / 非同控 G7-9 初始计量）、`subsequent/`（后续计量）、`disposal/`（处置 G7-10 / 一揽子处置 G7-12）、`voucher/` |

`useG7FormData`：`G7_ACCOUNT_CODE='1511'`，草稿前缀 `g7-main-draft`，`MAX_RETRIES=3`。

## 关键 sheet 与联动（按既有复盘记录）

| sheet | 内容 | 联动 |
|---|---|---|
| G7-1 | 审定表 | 仅保存且 `writebackTb:true` 时回写 TB（**不在 mount 回写**） |
| G7-4 | 被投资单位清单（含持股比例） | → G7-14 / G7-16 / 少数股东披露 |
| G7-5 | 被投资单位财务信息 | → 权益法调整、少数股东损益/权益（× NCI%） |
| G7-6 | 会计政策差异 | → G7-14（仅"不一致"项累加，零金额跳过） |
| G7-8 / G7-9 | 同控 / 非同控合并初始计量 | → 合并模块建议分录、廉价购买/商誉 |
| G7-10 / G7-12 | 处置 / 一揽子处置（各次交易明细 + 累计回写） | → 合并、盈余公积比例可配 |
| G7-13 | 投资成本测试 | 正差额→商誉、负差额→廉价购买（可推 AJE 至 G7-3） |
| G7-14 | 权益法调整（枢纽） | 汇总 G7-5/G7-6/G7-15/G7-16/G7-17 |
| G7-16 | 未确认投资损失 | CAS2§44 瀑布分配（投资→长应收→其他权益），与 `equity_method_service` 一致 |

| G7-18 | 凭证检查 | 抽凭引擎（1511）+ 版本快照 |
