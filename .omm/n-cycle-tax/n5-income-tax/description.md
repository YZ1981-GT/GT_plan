# N5 所得税费用（6801）— 税务枢纽

componentType `n5-income-tax-expense`，后端 `_n5_income_tax_expense`。**损益取发生额**。
连接当期所得税（→N2）与递延所得税（←N1/N3），是 N 循环的勾稽枢纽。

## 核心公式

```
所得税费用（N5, 6801）= 当期所得税 + 递延所得税
  当期所得税 = 应纳税所得额 × 税率
    应纳税所得额 = 会计利润总额 ± 纳税调整（永久性差异 + 暂时性差异的当期影响）
  递延所得税 = 期末递延净额变动 = ΔN1（1811 DTA）− ΔN3（2901 DTL）
    （计入 OCI 的递延部分不进 N5，进 M9）
```

## N5 的 sheet

- **N5-1 审定表**：当期所得税 + 递延所得税 = 所得税费用（2 行 + 合计）；
  从 N5-4（当期）/ N5-8（递延）回填 `N5-1-current-tax` / `N5-1-deferred-tax`
- **N5-2 有效税率调节表**（源模板真实结构）：会计利润 × 法定税率 → +不可抵扣 + 免税 + 税率差异 +
  未确认亏损 + 汇算清缴 = 实际所得税费用
  （**当前渲染的是"当期/递延分项分解表"，与源模板不符，重建属 spec 级未做**）
- **N5-4 当期所得税纳税调整**：会计利润 → 应纳税所得额（纳税调增/调减明细）→ 当期应交所得税
- **N5-8 递延所得税**：暂时性差异 × 税率的期末净额变动
- 税收优惠 / 财产损失 / 递延核对等专项

## 自包含结构（N5 特殊）

N5-1 审定表**无独立 composable**（`useN5Adjudication` 不存在），
`currentRow` / `deferredRow` 是组件本地两行 refs，`updateCell` 直接 mutate `target.value[field]`
+ 调既有 `handleCellChange` 持久化。带入调整 target 也是这两行。

## 与其他元素的关系

- **上游**：会计利润（利润表）、N4 纳税调整、N1/N3 递延所得税净额变动
- **下游**：当期所得税 → N2 应交企业所得税（2221）；所得税费用 → 利润表 IS
- N5 有效税率是分析性程序的关键指标（实际税率偏离法定税率需解释）
