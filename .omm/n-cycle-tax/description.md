# N 税务循环

N 循环覆盖税务相关科目：递延所得税（资产/负债）、应交税费、税金及附加、所得税费用。
N1~N5 共 **5 个 componentType**，前端目录 `n1/`~`n5/`。是钩稽关系最集中的循环
（当期所得税 + 递延所得税 = 所得税费用；暂时性差异 → 递延所得税资产/负债）。

## N 循环的主脉

### 所得税费用勾稽（N5 枢纽）

```
所得税费用（N5, 6801）= 当期所得税 + 递延所得税
  当期所得税 = 应纳税所得额 × 税率（应纳税所得额 = 会计利润 ± 纳税调整）
  递延所得税 = 期末递延所得税净额变动 = ΔN1（1811）− ΔN3（2901）
```

N5 有效税率调节表：会计利润 × 法定税率 → 各调整项（不可抵扣/免税/税率差异/未确认亏损等）→ 实际所得税费用。

### 递延所得税（暂时性差异）

```
可抵扣暂时性差异（账面 < 计税基础，资产；或账面 > 计税基础，负债）→ N1 递延所得税资产（1811）
应纳税暂时性差异（账面 > 计税基础，资产；或账面 < 计税基础，负债）→ N3 递延所得税负债（2901）
DTA/DTL = 暂时性差异 × 适用税率（默认 25%）
```

来源：各资产折旧/摊销税会差异（H1/H3/I1）、资产减值准备（不得税前扣除）、可抵扣亏损、
公允价值变动、预计负债、递延收益等 → N1/N3 附注的固定行项。

### 应交税费（N2）

应交增值税 + 企业所得税 + 各种流转税/附加。N2-2 有增值税/房产税/土增税等专项测算表。
当期所得税（N5）→ 应交企业所得税（N2）；税金及附加（N4）计提 → 应交城建税/教育附加等（N2）。
