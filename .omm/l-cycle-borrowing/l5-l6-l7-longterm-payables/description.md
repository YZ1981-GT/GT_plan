# L5 长期应付款 / L6 专项应付款 / L7 其他非流动负债

三个"其他长期负债"科目，结构较简（审定 + 明细 + 调整 + 附注）。

## L5 长期应付款（`l5-long-term-payables`，2701 应付 / 2702 未确认融资费用 ⚠）

**三区段结构**（源模板）：
- 一、原值（应付融资租赁款 / 分期付款购入固资 / 其他 + 合计）
- 二、未确认融资费用（同 3 行）
- 三、净值 = 原值 − 未确认（逐行 computed）

审定表双期（各未审/账项调整/重分类/审定/减一年内到期/最终审定数）+ 本期审定较期初变动额率 +
与经审计财报核对区（含专项应付款手填）。双科目回写（2701 原值 + 2702 未确认融资费用）。

**⚠ 2701 与 K5 预计负债同码**（见 `../concern.md` §2）。

## L6 专项应付款（`l6-special-payables`，2601）

政府拨款形成的专项应付款（资本性拨款、专项工程款等）。
审定表**两期动态行结构**（beginUnadjusted/beginAje/beginRje/beginAudited + endUnadjusted/... + variance/varianceRate），
项目行从明细带/可增删，**无减一年内到期**。结构较简，本就正确（无需双期重建）。

## L7 其他非流动负债（`l7-other-noncurrent-liabilities`，2801）

兜底的长期负债（长期递延、长期应付款项中不属其他科目的部分等）。
审定表同 L6 两期动态行结构，从明细带入/可增删。

## 共同要点

- **L6/L7 审定表本就是两期动态行**（不是单期 roll-forward，也不是 L1~L5 的固定分类双期）→ 无需重建
- L5 的净值三区段是其特色（原值 − 未确认融资费用），双科目回写
- 一年内到期部分（L5）重分类作流动负债
- 专项应付款（L6）到期后按用途转入资本公积或递延收益（政府补助口径）
