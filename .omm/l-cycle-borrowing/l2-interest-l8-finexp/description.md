# L2 应付利息（2231）/ L8 财务费用（6603）

利息的**负债侧（应计未付）与损益侧（费用化）**，与 L1/L3/L4 本金联动。

## L2 应付利息（`l2-interest-payable`，2231）

| sheet | 内容 |
|---|---|
| L2-1 审定表 | 双期，源模板 5 类（分期付息长借利息/企业债券/短借/优先股永续债[工具1/2汇总]/其他）+ 变动分析 + 原因分析 + 审计说明（增减原因/欠付利息）+ 审计结论 + 与经审计财报核对区（应付利息/应付股利/其他应付款 → 报表数 → 差异）+ 从 L2-2 明细带入 |
| L2-2 明细 | 债权人 × 利息计提/支付（补债权人名称列）|
| L2-3 调整 | 类别（报表/账项/其他）+ 报表/附注项目 + 索引 + A13 push |
| L2-4 检查表 | **凭证级**（测试原因 + 记账凭证行 + 支持性文件 + 核对①~⑤ + 检查比例[本期发生额来自 L2-2 Σ计提/Σ支付]）+ L1/L3 计提核对摘要 |
| 附注上市/国企 | category-level（5 类 + 优先股[工具1/2汇总] + 其他 + 合计）+ 重要逾期未付利息表；上市"上年年末"/国企"期初"列 |

利息来源：L1 短期借款 + L3 长期借款 + L4 债券票面 + F3 带息票据。

## L8 财务费用（`l8-financial-expenses`，6603 损益取发生额）

财务费用汇总：利息支出（− 利息资本化）+ 利息收入 + 汇兑损益 + 手续费等。

- 审定 + 明细（按性质分项）+ 调整 + 附注
- **利息费用化 vs 资本化**：L1-5 / L3 利息测算的费用化部分进 L8（6603），资本化部分进 H2 在建工程（CAS17）
- 汇兑损益（外币借款/往来）在 L8 归集
- 损益类审定数进利润表 IS 行

## 共同要点

- L2 是"应计未付"（时点余额，资产负债表），L8 是"费用发生"（期间发生额，利润表）——两者口径不同勿混
- 利息测算（365 天制）同时驱动 L2 计提与 L8 费用化
- L2 优先股/永续债利息（工具1/2）按金融工具准则判断权益 vs 负债
