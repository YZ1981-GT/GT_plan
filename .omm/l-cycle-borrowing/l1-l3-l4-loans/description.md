# L1 短期借款 / L3 长期借款 / L4 应付债券（本金类）

三个"借款本金"科目，审定表都是双期结构，按种类分类。

## L1 短期借款（`l1-short-term-loans`，2001）

L1A 程序表 + L1-1~L1-9 + 附注上市/国企 + 目录：

| sheet | 内容 |
|---|---|
| L1-1 审定表 | 按种类（信用/抵押/保证/质押）双期，回写 TB 2001，SUMIF 从 L1-2 带入 |
| L1-2 明细 | 按银行/合同逐笔（30 列，⚙列设置）|
| L1-3 调整 | AJE/RJE 借贷平衡 → 回写 L1-1 + 发 A13 |
| L1-4 征信核对 | 人行/百行征信报告 vs 账面双向差集（防账外借款，30 列）|
| L1-5 利息测算 | 本金×利率×天数/365，联动 L2/L8 |
| L1-6 合同检查 | 26 列凭证级 + ⚙列设置 |
| L1-7 逾期检查 | 逾期比例 = 逾期金额 / L1-1 审定数 |
| L1-8 抵质押检查 | 评估价值列 |
| 附注 | category-level（信用/抵押/保证/质押）+ 逾期表 + 国企/上市 |

**负债类贷方**：期末 = 期初 + 贷方(借入) − 借方(归还)。带入调整 `subjectPrefix:'2001'` / `direction:'credit'`。

## L3 长期借款（`l3-long-term-loans`，2501）

结构对标 L1，审定表双期 + **减一年内到期 → 披露审定数**列（披露审定 = 审定 − 一年内到期，进非流动列报）：

| sheet | 内容 |
|---|---|
| L3-1 审定表 | 质押/抵押/保证/信用借款，双期 + 减一年内到期；审计说明 4 项（增减原因/已到期未偿/抵押质押/关联方保证）|
| L3-2 明细 / L3-5 利息 / L3-6 合同 / L3-7 逾期 / L3-8 抵押 | JSON-array 存储 + hydrate；L3-7 逾期比例联动 L3-1；L3-8 评估价值 |
| L3-9 检查表 | 凭证级（记账凭证行 + 核对①~⑤ + 检查比例来自 L3-2 借=Σ归还/贷=Σ借入）|

一年内到期 → 重分类作短期借款（与 L1 区分）。

## L4 应付债券（`l4-bonds-payable`，2502）

| sheet | 内容 |
|---|---|
| L4-1 审定表 | 品种（普通/可转换）× 子项（成本/利息调整/应计利息）双期 + 减一年内到期，回写 2502 |
| L4-2 明细 | 摊余成本（实际利率法 EIR）+ hydrate（JSON-array）|
| L4-5/L4-6 检查 | 权益负债划分（可转换债券）等 |

**IE 模型不匹配**（后端 detail 字段 vs 前端三分解，deferred，见 concern §8）。

## 共同要点

- 本金 → 利息（L2）→ 费用化（L8）/ 资本化（H2）
- 一年内到期重分类（L3/L4）
- 抵押/质押 → 与 H 资产（固定资产/无形/投资性房地产）的所有权受限披露对应
