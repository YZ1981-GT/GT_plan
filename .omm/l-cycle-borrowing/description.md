# L 借款与债务循环

L 循环覆盖债务融资：短期/长期借款、应付利息、应付债券、长期应付款、专项应付款、其他非流动负债、财务费用。
8 个科目包 = **8 个 componentType**，前端目录 `l1/`~`l8/`。

## L 循环的主脉：本金 — 利息 — 费用

1. **借款本金**：L1 短期借款 / L3 长期借款 / L4 应付债券（本金按种类分类审定，双期）
2. **利息计提**：本金 × 利率 × 天数/365 → L2 应付利息（贷 2231）
3. **利息费用化 vs 资本化**：L8 财务费用（费用化 6603）vs H2 在建工程利息资本化（CAS17）
4. **一年内到期重分类**：长期借款/债券的一年内到期部分 → 重分类（RJE）作短期列报（"减一年内到期"列）

## 审定表双期结构（L 循环特征）

L1/L2/L3/L4/L5 的审定表是**期初/期末双期**：期初数（未审/账项调整/重分类/审定）+
期末数（同）+ 本期未审较期初（变动额/率）+ 本期审定较期初（变动额/率）+ 原因分析。
带一年内到期的（L3/L4/L5）另有"减一年内到期 → 披露审定数"列（披露审定 = 审定 − 一年内到期）。

## L5/L6/L7 的差异

- **L5 长期应付款**：三区段（一、原值 / 二、未确认融资费用 / 三、净值 = 原值 − 未确认），双科目 2701 + 2702
- **L6 专项应付款 / L7 其他非流动负债**：审定表本就是两期动态行结构（beginUnadjusted/endUnadjusted 等），
  从明细带入/可增删，无"减一年内到期"，结构较简

## 统一骨架

LxA 程序表 → Lx-1 审定表（双期，回写各科目）→ Lx-2 明细（按银行/合同逐笔）→ Lx-3 调整 →
利息测算（L1-5 等）→ 检查表（凭证级 useLxVoucherCheck）→ 征信/逾期/抵质押检查 → 附注上市/国企 → 目录
