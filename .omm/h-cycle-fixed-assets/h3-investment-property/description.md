## 关键机制

- **回写双科目**：1503 原值（两模式都回写）+ 1504 累计折旧（**仅成本模式**）
- **跨表引擎** `useH3CrossSheet`：H3-2 → H3-1 审定 / H3-6 互转 / H3-8 公允变动 → H3-1 / 多源 → 附注 `disclosureAutoFill`
- **产权受限**：H3-12 产权核查 ↔ L1 抵押（`syncFromL1`），受限房地产进披露
- **互转**：投资性房地产 ↔ 固定资产（H1）/ 存货（F2）三方向互转
- **减值**：`impairment:calculated` 事件（已入 `crossWpEventBridge`）→ K11（6701）；与 K11 反向 pull 勾稽

## 与其他元素的关系

- 互转 → H1 固定资产 / F2 存货
- 租金 → D4 营业收入（或其他业务收入 6051）
- 抵押 → L1/L3 借款质押披露
- 公允变动（公允模式）→ G13 公允价值变动收益（6101）或按准则进当期损益
