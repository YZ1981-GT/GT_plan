# H2 在建工程（1604）/ H4 工程物资（1605）

两者是"建造中"的资产，业务上连续（物资领用 → 在建 → 转固），故合并为一个元素描述。

## H2 在建工程（`h2-construction-in-progress`）

| 目录 | 内容 |
|---|---|
| `core/` | 审定表 H2-1 / 明细 H2-2（可从序时账取数 `pullAssetMovementFromLedger('1604')`）/ 调整 H2-3 / 分析 H2-4 / 附注上市国企 / 目录 |
| `inspection/` | H2-5 转固时点检查（双表：该转未转 + 已转时点 CAS4）/ H2-8 增加检查（抽凭 1604）/ H2-9 减少检查 |
| `interest/` | **H2-10 一般借款 / H2-11 专门借款 利息资本化（CAS17，两支互斥择一）** |
| `impairment/` | H2-15 减值测算 / H2-16 减值迹象（迹象 ≥2 项时 H2-16 为强制门禁） |
| `stocktake/` | H2-13 盘点（`readyForUse=是` 可回写转固检查表一） |

**关键机制**
- 审定表工具栏显示 `TB·1604 未审/审定` + `H2-3：1604 账项净额`；"从 TB 带入工程物资"写 **1605 核对行**
- **带入调整**：`subjectPrefix:'1604'` / `direction:'debit'`（资产借方净额 = 借 − 贷），
  逐笔分配到各工程的**期末账项调整（单列，增量累加）**
- **该转未转**（少计折旧）：直线法月折旧 × 达可用次月起至转固日/报表日的月数 → "折旧影响 → H2-3" 生成借管理费用/贷累计折旧
- **拉期后转固凭证**：扫描截止日次日起 3 个月 1601/1604 序时账，按工程名/转固关键词回填
- 减值 AJE：借 6701 资产减值损失 / 贷 1604 减值准备（重复推送替换旧自动草稿）；CAS8 不得转回
- 转固完成后**联动 H1**（`h2H1TransferPull` 反向核对 H1 实际入账原值）；C7 控制失效时扩大实质性程序
- BOT 业务按《企业会计准则解释第 2 号》判断确认为无形资产或长期应收款
