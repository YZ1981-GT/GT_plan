# H6 固定资产清理（1606 过渡）/ H10 资产处置收益（6115 损益）

资产**退出链**的两端：清理过程挂账（H6）→ 净损益结转损益（H10）。

## H6 固定资产清理（`h6-asset-disposal-clearing`）

| 目录 | 内容 |
|---|---|
| `core/` | 审定表 H6-1 / 明细 H6-2（清理项目：原值 − 累计折旧 − 减值 = 账面净值，加清理费用、变价收入）/ 调整 H6-3 / 披露 / 目录 |
| `inspection/` | 清理凭证检查、清理完成情况检查 |

- `ACCOUNT_CODE_1606='1606'`，回写时 detail 带 **`isTransitAccount: true`**（明确标记过渡科目）
- **期末通常应为零**（清理完成即结转）；有余额需解释未完成清理
- `h1SoeClearingH6Pull`：H6 清理净损益 → H1 固定资产（减少侧核对）
- `h10RelatedH6Pull`：H6-2 净损益 → H10-1（`勾稽H6` 按钮）
- H1-8 减少检查完成发 `h1:disposal-completed` → GtH6 消费

## H10 资产处置收益（`h10-asset-disposal-income`）

| 目录 | 内容 |
|---|---|
| `core/` | 审定 H10-1 / 明细 / 调整 / 附注上市国企 / 目录 |
| `inspection/` | H10-4 处置凭证检查（抽凭 + `fillFromSampledVouchers`，抽查比例门槛 20%） |
| `handbooks/` + `H10ImportExportDropdown` | 手册 + 导入导出 ▾ |

- `h10Constants`：`H10_ACCOUNT_CODE='6115'`、`H10_CHANGE_RATE_THRESHOLD=0.2`
- **审定表行映射各来源科目**：H1 固定资产 / H2 在建工程 / H3 投资性房地产 / H4 工程物资 /
  H8 使用权资产（`rou_disposal`）/ H5 油气 / H7 生物资产 / I1 无形资产 + **试运行**行
- 净值 = 原值 − 折旧 − 减值（按来源汇总带入未审，保留 AJE/RJE）
- **附注 三、资产处置收益（上市）/ 八、75（国企）**；上市版试运行收入/成本明细净额回写
- 试运行（IE15）→ D4 提示（试运行收入是否应确认为收入）

## 与其他元素的关系

- 上游：H1/H2/H3/H4/H5/H7/H8/I1 的处置与报废
- H6 是"清理过程"的过渡容器，H10 是"损益结果"
- 处置价款 → E1 货币资金；处置税费 → N2 应交税费
