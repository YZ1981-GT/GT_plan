## K10~K13 汇总损益

- **K10 其他收益（6117）**：K10-4 政府补助核对（与 K7 一致性，K7AmortManual 手工锚点）/ K10-5 应收补助检查（期后收款验证）/
  K10-6 综合检查（从明细带入 + 覆盖率 + 错配分类→重分类告警）
- **K11 资产减值损失（6701）**：18 类 canonical + 来源映射各资产底稿 + 减值准备 rollforward；
  与 G14 信用减值（6702）严格区分；K11-1 有 TB 勾稽 + K11-3 调整（报表调整/账项调整/其他 10 列）回写 AJE/RJE
- **K12 营业外收入（6301）/ K13 营业外支出（6711）**：审定 + 明细 + 调整 + 凭证检查（K1-12 式重建，
  K12=贷方收入 / K13=借方支出，核对内容 1-5 + 检查比例来自 Kx-2）+ 附注（关键词标题 + 非经常性损益列）；
  K13 不合规/跨期 → A13；K12 错配（应转 6117）→ 重分类提示

## 共同要点

- 损益类审定数进利润表 IS 行，不进资产负债表
- 截止测试（K8/K9）用自然月跨期判定；跨期 → A13 push
- 「从集中登记带入调整」全部接入（损益单科目 direction=credit/debit）
