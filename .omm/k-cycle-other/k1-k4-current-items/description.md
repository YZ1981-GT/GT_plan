# K1~K4 往来杂项（其他应收/应付、其他流动资产/负债）

四个"往来杂项"科目，结构同构（审定 + 明细 + 大额 + 关联方 + 凭证检查 + 调整 + 附注），K1 最重。

## K1 其他应收款（`k1-other-receivables`，1221 + 坏账 1231）

**K 循环范式提供者**（凭证检查、认定 alert、坏账 ECL 都在 K1 首发）：

| sheet | 内容 |
|---|---|
| K1-1 审定表 | 双维度（款项性质 + 账龄），回写 1221 + 坏账 1231 |
| K1-2 明细 | 往来单位明细 + 账龄（`useAgingConfig('K1')`）+ ⚙列设置 |
| K1-3 坏账明细 / K1-6 政策检查 / K1-7 三阶段 | 减值组合划分（单项 / 押金组合 / 账龄组合）+ 6 家上市公司政策参考（内嵌可套用）+ ECL 三阶段 |
| K1-5 大额 / K1-9 核销 / K1-10 长期未收回 / K1-11 关联方 | 动态行明细表（源模板具体列） |
| K1-8 坏账测算 | 单项 + 押金组合 + 账龄组合（③=①×② 公式 + 差异勾稽） |
| K1-12 凭证检查（gold 标准） | 认定目标 + 样本选取 + 双凭证测试（本期发生额/期后收款）+ 检查比例 + 抽凭 1221 |

附注 **五、8 / 八、9**（含 G2 应收利息 / G3 应收股利并入）。

## K2 其他流动资产（`k2-other-current-assets`，1231 ⚠）

待摊费用 / 预缴税费 / 合同取得成本增量 等。K2-6 检查表是**最简凭证级测试表**（无样本选取段、无期后段，
仅测试目标 + 凭证表 + 检查比例，account-code=1231/借方）；K2-4 合同取得成本 23 列专表 + K2-5 摊销测算 28 列专表（K2 特色）。

## K3 其他应付款（`k3-other-payables`，2241）

- **双维度审定表**（按性质 + 按账龄）+ 与报表核对区（应付利息 + 应付股利 + 其他应付款 = 报表数）
- K3-4 大额 / K3-5 长期挂账（CAS16 转销评估）/ K3-6 关联方（8 类下拉 + 公允判断 + 借贷分列）
- K3-7 凭证检查（复用 useK1VoucherCheck，account-code=2241，债权人/期后付款）

## K4 其他流动负债（`k4-other-current-liabilities`，2245）

- 审定表 4 类型（短期应付债券 / 政府补助 / 待转销项税额 / 应付退货款）
- K4-4 凭证检查（复用 useK1VoucherCheck，2245，**单张本期发生额表无期后段**）
- 附注上市重建（短期应付债券明细 + 续表含是否违约 + 递延收益-政府补助）

## 共同要点

- 完整性是负债类（K3/K4）主认定；存在性 + 可收回性是资产类（K1/K2）主认定
- 长期挂账（K3-5）转销 → K12 营业外收入 / 其他应付款重分类
- 关联方（K1-11/K3-6）→ B19 关联方清单
