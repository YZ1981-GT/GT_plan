# K 其他资产负债与损益循环

K 循环是"杂项归集循环"：其他应收/应付、其他流动资产/负债、预计负债、持有待售、递延收益，
以及一批损益类（销售费用/管理费用/其他收益/资产减值损失/营业外收支）。K1~K13 共 **13 个科目包 = 13 个 componentType**。

## K 循环的分组

1. **往来杂项（K1~K4）**：其他应收/应付、其他流动资产/负债 —— 明细 + 大额 + 关联方 + 凭证检查，K1 最重（坏账 ECL 三阶段）
2. **专项负债（K5~K7）**：预计负债（CAS13 或有事项：诉讼/担保/亏损合同）、持有待售（CAS42 孰低）、递延收益（CAS16 政府补助）
3. **损益归集（K8~K13）**：费用类（K8 销售 / K9 管理，含截止测试）+ 收益/损失类（K10~K13，多为汇总科目，数据来自上游）

## 统一骨架

KxA 程序表 → Kx-1 审定表（TB 回写各自科目）→ Kx-2 明细 → Kx-3 调整分录 →
专项检查（大额 / 关联方 / 凭证级）→ 附注上市/国企 → 目录页（**已按 E1 标准重建**：
目录卡 + 跨表结论看板 + 4 阶段泳道 + 本循环 grid + 编制/使用手册）。
