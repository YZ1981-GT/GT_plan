# K5~K7 专项负债（预计负债 / 持有待售 / 递延收益）

三个各有专属会计准则的负债类科目，检查逻辑差异大。

## K5 预计负债（`k5-provisions`，2701 ⚠ 与 L5 同码）

CAS13 或有事项。审定表 + 明细 + 调整 + 专项检查 + 附注：

| sheet | 内容 |
|---|---|
| K5-4 保修 | 政策 + **3 年历史保修率对照**（本期 + 前 2 年发生额/收入）+ 重新测算差异表 + 预计发生时间（1 年内/外） |
| K5-5 弃置义务 | 完整性检查 + 关键假设评估 + 借贷方发生额分析（PV 现值折现） |
| K5-6 诉讼 | CAS13 三级可能性（很可能/可能/极小可能）+ 已计提预计负债 + 差异勾稽 + 证监会 2020 监管报告提示 |
| K5-7 凭证检查 | 复用 useK1VoucherCheck（2701，本期发生额 + 期后检查双表） |

## K6 持有待售（`k6-held-for-sale`，1481 资产 / 2605 负债）

CAS42 孰低（账面价值 vs 公允价值减去出售费用）。**双科目**（资产 1481 + 负债 2605）：

| sheet | 内容 |
|---|---|
| K6-4 初始确认 | **19 列分层估值表**（公允价值三方法：销售协议价/活跃市场价/估计价，各带依据 + 出售费用 + 孰低净额；分层：非流动资产/处置组资产/处置组负债 + 决议协议索引）+ CAS42 五条件判断 |
| K6-5 减值测试 | 孰低法（应计提减值 = MAX(0, 账面 − 公允净额)）+ 公允价值确定依据 |
| K6-6 处置组减值 | (一) 减值测算 + (二) 按报表项目分摊表（资产/负债类 15+ 项 + 勾稽一致） |
| K6-7 不再满足 | 净额 ④ = ①被划归前账面 − ②假设折旧摊销 − ③假设减值；持有待售会计政策 5 段编制说明 |

## K7 递延收益（`k7-deferred-income`，2401）

CAS16 政府补助：

| sheet | 内容 |
|---|---|
| K7-1 审定表 | 3 固定行（与资产相关 / 与收益相关 / 其他），SUMIF 从 K7-2 汇总 |
| K7-2 明细 | 增减"其中项"（新增补助/其他增加/转入其他收益/其他减少）+ 日期驱动摊销 + ⚙列设置 |
| K7-4 测算 | 摊销测算（开始摊销日/摊销到期日/DATEDIF 月份数）|
| K7-5 凭证检查 | 复用 useK1VoucherCheck（2401，仅贷方检查比例）|

## 共同要点

- **适用性**：K5 诉讼/担保、K6 持有待售、K7 政府补助均非普通年审必做 → 应可整包裁剪
- K7 政府补助转入 → K10 其他收益（6117）
- K6 处置完成 → 各资产科目转出 + H10 处置收益
- K5 预计负债与 L5 长期应付款共用 2701（见 `../concern.md` §1）
