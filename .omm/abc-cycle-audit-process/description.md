# A / B / C 审计过程循环（报告与调整 / 计划 / 控制）

与 D~N/S 科目循环不同，A/B/C 不审"科目余额"，而是审计**过程与结论**：
A = 报表与调整（收尾、报告、沟通、合并、现金流量），B = 审计计划（承接、风险评估、重要性、总体策略），
C = 内部控制（企业层/业务层控制 + 控制测试 + ITGC）。渲染上大量走 **`a-program-console`（程序表控制台）**
+ 一批**专属组件**（收尾类文书、风险评估、控制矩阵等）。

## 三大类定位

| 循环 | 审计阶段 | 核心内容 |
|---|---|---|
| **B 计划** | 承接与计划（最先做）| 业务承接（B1）、前任沟通（B2）、企业层控制了解（B22）、业务层控制（B23）、重要性（B15）、关联方（B19）、风险评估（B50）、总体策略（B60） |
| **C 控制** | 控制测试 | 企业层面控制（C1）、控制测试（C2~C15）、ITGC（C22）、会计分录控制（C23/C24）、内审依赖（C25）、信息处理控制（C26） |
| **A 报表调整** | 收尾与报告（最后做）| 报表仪表盘（A1）、调整分录汇总（A2）、合并（A3）、现金流量（A5）、期后事项（A11）、未更正错报（A13）、缺陷函（A9）、治理沟通（A10）、律师函（A12）、审计总结/KAM（A17）、监管报送（A18）、IT 审计备忘（A27） |

## A 报表与调整（部分 componentType）

- **A1 dashboard**（报表仪表盘，走 render_a_program）/ **A2 调整分录控制台** / **A3 合并控制台**
- **A5-1 现金流量审计** / **A3-8 商誉减值**
- **A9-1/A9-2 缺陷函**（管理层 / 治理层，读 B22B 缺陷）/ **A10-1 治理沟通** / **A12-1 律师函**
- **A11-1 期后事项问询** / **A13 未更正错报汇总**（各底稿 `a13:push-misstatement` 的唯一消费者）
- **A17 系列**：A17-1 审计总结 / A17-2-1 KAM / A17-3 咨询记录 / A17-4 意见分歧 / A17-6 收尾会议 / A17-7 独立性声明
- **A18-1/A18-2 监管报送/沟通** / **A27-1 IT 审计备忘** / **A8-1 其他信息声明**
- **A1-12/A1-15/A1-17** 双清单/披露清单/对应数据

## B 审计计划（专属组件）

- **B1 业务承接**：`b1-risk-assessment`（承接/保持风险评估）/ `b1-3-business-evaluation` / `b1-5-kaa-check` /
  `b1-4-due-diligence-report`（尽调报告，账户包聚合 7 sheet）
- **B2 前任沟通**：`b2-12-evaluation`（对前任评价）+ 一批 word-template 信函
- **B15 重要性**（redirect 到 Materiality 模块）
- **B19 关联方**：`b19-bundle`（结构化清单 → related_party_registry 唯一真源 + 未披露扫描 → B50）
- **B22 企业层控制**：`b22a-control-matrix`（COSO 五要素）/ `b22b-control-matrix`（控制矩阵登记册）/ `b22c-design-effectiveness`
- **B23 业务层控制**：`b23-process-control`（14 循环 × 控制矩阵/穿行/控制测试/缺陷）
- **B50 风险评估**：`b50-risk-assessment`（风险因素 → 报表层/认定层风险 → 应对方案，风险导向链源头）
- **B60 总体策略**：`b60-strategy`（38 表结构化，含 Table26/27 认定层次应对路由 → D~N）

## C 内部控制

- **C1 企业层面控制**：`c1-entity-level-control`
- **C2~C15 控制测试**：`c-control-test`（各业务循环控制测试，弹窗增强 + OCR）
- **C22 ITGC**：`c22-itgc-bundle`（IT 一般控制）
- **C23 会计分录控制** / **C24 会计分录明细测试**（四表联动，序时账抽取异常分录）
- **C25 内审依赖** / **C26 信息处理控制**

## 风险导向审计主链（贯穿 A/B/C 与 D~N）

```
B50 风险评估 → B60 总体策略（认定层次应对）→ C 控制测试 → D~N 实质性程序
  → A13 未更正错报 → A17 审计总结 → 审计报告
```
