# 约束（改 F 循环必须遵守）

## 科目与口径

- **F2 科目归属只改 `f2AccountModel.ts`**：四个 F2 入口共用，散落硬编码会导致审定表 rowKey ↔ 科目错配。
- **1412 商品进销差价 ≠ 1471 存货跌价准备**：前者是原值类调整账户，后者是备抵；两者在审定表分属不同区块。
- **F5 营业成本是损益类（6401）**：取发生额不取余额；与 D4 收入做毛利率勾稽时两端都必须是发生额口径。
- **F4 / F3 是负债贷方**：期末 = 期初 + 贷 − 借。
- **F2 审定表账项调整是单列净额**：任何"带入调整"实现都必须自包含（`net = aje + rje` 一次累加），禁止套用双列 helper。

## 数据模型

- **F4 账龄暂维持扁平 4 字段**：读写同源不要单边改（只改明细或只改审定会立刻产生静默 0）；统一走 `f4-aging-enum-unification` spec。
- **F2-14 overlay 优先**：审定表 adjustment 在 F2-14 有数据时以 crossSheet overlay 为准，手工值仅 fallback；写手工值前要提示用户。
- **F3 TB 种子 persist-first**：`F3-1-adj-tb-2201` 已有持久化时不得覆盖。

## 导入导出

F 循环导入导出走各自 `useFxImportExport`，后端 `_fx_import_export.py`。三条硬约束：
1. `sheet` 是后端 **Query 参数**，必须 `http.post(url, null, { params: { sheet } })`，塞进 FormData 收不到 → 422
2. 后端 `_FX_SPECS` 必须含该 sheet，否则 400「不支持的 sheet」
3. 新增数值字段要进 `is_numeric_field_key` 白名单，否则金额被当字符串

## 来源模板

- F2-33 采购入库检查是 **20+ 列凭证级**（记账凭证 + 入库验收 + 质检 + 物流 + 采购发票 五类单据横向展开），不是汇总表
- F2-35 委外加工表三是**计价勾稽**（收回材料成本 ≈ 发出材料成本 + 加工费，CAS 存货成本恒等）
- 特殊存货的 IPO 专项、合同履约成本（含亏损合同）都有源模板对应表，禁自造列头
