## 2. 关键冲突与决议

### 2.1 损益类取数（6115）

- **xlsx / 模板库**：6115 为损益类，取**发生额**（贷方 − 借方），非期末余额。
- **决议**：HTML + TB 回写 + renderer 均按发生额；`wp_fine_rules` 科目修正为 **6115**（原误写 6702）。

### 2.2 审定表列结构

- **requirements** 描述：借方发生 / 贷方发生 / 发生净额 / 未审 / AJE / RJE / 审定。
- **xlsx H10-1 行 6–12**：按**处置类型** 7 行（持有待售、固定资产…非货币性资产交换），列为未审+调整+审定模式。
- **决议**：HTML 对齐 **xlsx 7 行 + 未审/AJE/RJE/审定**（与 G11 损益审定 UX 一致）；借方/贷方发生列在 OO 完整版保留，HTML 通过 TB 刷新发生净额。

### 2.3 明细表 36 列

- **决议**：业务操作按 3 Tab 分区（基础 / 处置计算 / 审计证据），公式在 `useH10DisposalCalcEngine` 前端计算；导入导出走 H10-2 模板列子集。

### 2.4 检查表 80 行

- **决议**：检查行由 H10-2 明细**自动生成/联动**，合规字段 9 项下拉；静态 80 行模板在 OO；HTML 侧重逐笔合规 + 抽凭。

### 2.5 跨底稿联动

| 联动 | 方向 | 实现 |
|------|------|------|
| H6 清理 | H6 → H10-2 | `disposal:completed` EventBus（主入口单监听，防重复） |
| H1~H8 减少 | 源 → H10-2 | `disposal:source-updated`（H 循环源底稿待发布；H10 已 subscribe） |
| H10-1 ↔ H10-2 | 双向勾稽 | `useH10CrossSheet` + CHK-02 |
| H10-1 ↔ H6 | 固定资产行 | CHK-03 |
| H10-1 ↔ 源底稿 | 分类型 | CHK-04 |
| H10-3 → A13 | 调整 | `adjustment:created` EventBus |

### 2.6 附注 sheet 名称

- xlsx：`附注披露信息（上市公司）` / `附注披露信息（国企）`
- fine rules 写「国有企业」；`extractH10SheetCode` 已兼容「国企/国有」。
