## 2. 负债类方向确认

### xlsx证据（权威）
- **L6-2 明细表** 核心公式 `G10: =C10+D10-E10-F10`
  - 语义：`期末余额 = 期初余额(C) + 本期拨入(D) - 本期结转(E) - 本期返还(F)`
  - **确认：期末 = 期初 + 贷方(拨入) - 借方(结转+返还)**（负债类贷方科目）

- **L6-2 审定数区** 公式 `T10: =P10+Q10-R10-S10`
  - 语义：`审定期末 = 审定期初(P) + 审定拨入(Q) - 审定结转(R) - 审定返还(S)`
  - **二次确认：负债类贷方方向**

- **L6-1 审定表** 公式 `E7: =B7+C7+D7`
  - 语义：`期初审定数 = 期初未审 + 期初AJE + 期初RJE`
  - `I7: =F7+G7+H7` → `期末审定数 = 期末未审 + 期末AJE + 期末RJE`

### md证据
- L6-2明细表列头明确标注：`期初余额 | 本期拨入 | 本期结转 | 本期返还 | 期末余额`
- L6A程序表：科目为"专项应付款"（负债类）
- md提示第1条："本科目核算企业取得政府作为企业所有者投入的具有专项或特定用途的资本性投资项目拨款"

### 结论
| 项目 | 结论 |
|---|---|
| 科目方向 | **贷方/负债类** ✅ 两源一致 |
| 期末公式 | `期末 = 期初 + 拨入(贷方) - 结转(借方) - 返还(借方)` ✅ |
| spec design P2 | `calcLiabilityEndBalance(b, cr, dr) = b + cr - dr` ✅ 正确 |
| 备注 | xlsx中"结转"和"返还"属于借方发生，合并为一个dr参数正确 |

**确认：专款专用核查是L6的核心审计程序。** 由L6A第4步程序和L6-4检查表共同验证。

### ⚠️ 差异分析

| 对比项 | xlsx/md | spec当前 | 差异性质 |
|--------|---------|---------|---------|
| "本期使用"列 | 无此列（仅有"本期结转"和"本期返还"） | 有"本期使用" | spec多了一列 |

### 决议
1. **"本期使用"需修正**：xlsx中是"本期结转"（形成资产转销）和"本期返还"（结余返还），不是泛化的"本期使用"。spec Requirement 3.1应修正列名为"本期结转 | 本期返还"（与xlsx一致）
2. **"拨款来源/批文号/用途"属spec增强**：xlsx/md将这些信息合并在"文件依据"和"拨款项目的完成情况"列。spec拆分为独立列提升可操作性，属合理UI增强，无冲突
3. **公式核心确认**：`期末 = 期初 + 拨入 - 结转 - 返还`（负债类变体）✅
4. **33列宽表拆分**：spec设计3区段Tab正确（项目信息/资金变动/用途核查），xlsx原始24列+调整区=33列确认

**需修改spec：**
- Requirement 3.2 公式描述应改为：`期末余额 = 期初 + 本期拨入 - 本期结转 - 本期返还`
- Requirement 3.1 列名"本期使用"改为"本期结转 | 本期返还"

## 9. md中发现的额外业务规则（xlsx未体现但应纳入）

从md提示区提取的L6特有业务规则：

1. **专项应付款≠政府补助**：专项应付款核算的是"政府作为企业所有者投入的具有专项或特定用途的款项"，政府补助走递延收益/营业外收入（CAS16），不在L6核算。UI需要提示区分。
2. **搬迁补偿**：城镇规划/库区建设/棚户区改造/沉陷区治理的搬迁补偿款在专项应付款核算。
3. **结构调整奖补**：中央企业收到工业企业结构调整专项奖补资金，暂通过"专项应付款"核算。
4. **转销规则**：
   - 形成资产部分→转销（借记"专项应付款"，贷记"资本公积-资本溢价"）
   - 未形成资产需核销→经批准程序
   - 拨款结余返还→借记"专项应付款"，贷记"银行存款"
5. **外币处理**：外币专项应付款应在备注栏列明原币金额及折合汇率
6. **审计结论三级**：A未见异常 / B除调整外未见异常 / C无法确认
7. **按明细账户分别列示**：每个专项项目独立一行

这些规则不影响公式引擎，但影响：
- UI提示文案（区分专项应付款vs政府补助）
- 方法论上下文块内容
- 检查表L6-4的核对重点
