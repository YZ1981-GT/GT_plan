# 需求：CITAR「鉴证报告」四个菜单

来源：用户 2026-11-03「鉴证报告分类下分为四个菜单：报告正文、审核说明、汇算申报表、单体财务报表」，附四份案例文件（`CITAR/真实案例资料/案例1/六部案例-税审报告/1~4`）；同日拍板：单体报表按会计准则代码自动选格式、税审专用配置单独放、现金流量表要做、审核说明只做生成 + 预览 + 导出 Word、报告封面按案例 docx 第一页；「单体财务报表可能是在试算平衡表页面中相同的数据源」。

承接 `tax-workpaper-data-fetch`（税审底稿计算模型、取数、手工值保存）与 `citar-pages-data-wiring`（试算平衡表的标准科目余额视图）。

## R1 菜单
- 左侧「鉴证报告」组改为四项：报告正文、审核说明、汇算申报表、单体财务报表；原「纳税申报表 / 税审报告」两项移除（`disclosure-notes` 路由本身不动）。

## R2 汇算申报表
- 37 张申报表（申报表封面、表单、A000000 ~ A109010）按样表版式显示，数来自税审底稿同一计算模型（底稿改了，申报表跟着变）。
- 左侧按「表单」目录列出全部表；「是否填报」默认取样表，可勾选改动并保存；未填报的表默认不列出（可展开）、导出时隐藏。
- 申报表上的公式格不可改（如 A000000 的会计准则代码、投资方比例取自底稿 1-12 企业基础信息表，在底稿里填）；非公式的空白格可填写保存。
- 导出 xlsx：只保留值，表样与样表一致，未填报的表隐藏。

## R3 报告正文
- 按文书版式显示报告封面与正文：被审核单位、年度、报告号、审核意见段、数据摘录表 25 行（金额取申报主表 A100000，0 值留空）、落款、附件清单。正文措辞一字不改，年度随项目审核年度。
- 报告号取底稿「填写参数」；报告日期可在页面填写并保存。
- 导出 Word：以案例 docx 为模板（封面 + 正文），只替换单位名称、年度、报告号、日期与 25 个金额。

## R4 审核说明
- 按样表「审核报告说明」规则表生成段落：占位符取金额、标题层级与编号（一、（一）1、（1）①…）、显示规则（※ 必显；﹟ 标题下无数据整节隐藏；无标记正文无金额不显示）。
- 页面预览；导出 Word（样式、页眉页脚按案例 docx）。不做页面上逐段修改。

## R5 单体财务报表
- 数据源与「试算平衡表」页同一份标准科目余额（审定数）。
- 按 A000000 第 107 项会计准则代码（取自底稿 1-12）自动选格式：3xx = 企业会计制度格式（资产负债表、资产负债表续、利润表、现金流量表、现金流量表补充资料）；1xx = 企业会计准则格式（复用平台审定报表）；未填写时按客户科目编码判断（旧编码体系 ⇒ 企业会计制度）并提示去 1-12 填写；其他代码提示暂不支持。
- 企业会计制度格式的行次与取数公式是税审专用配置，不进平台报表配置。上期 / 上年年末：资产负债表取试算表期初；利润表取上年项目（取不到写原因、不填 0）。现金流量表取平台现金流量表的已生成数，按行对应。
- 导出 xlsx。

## R6 约束
- 读接口项目只读权限、写接口项目编辑权限，新端点有接口级测试（401 / 403 / 能用）。
- 生成脚本幂等，`--check` 无差异 exit 0；模板文件由脚本从样表 / 案例文件生成。
- stylelint / eslint / 单区域 vue-tsc 通过；浏览器实测四个菜单的读、写、导出。
- 验收：用案例 1 底稿的计算结果比对四份案例文件（版本差异逐条登记，不改判据凑数）。
