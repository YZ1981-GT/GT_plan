# 现金流量表支持底稿（A5系列）— 需求文档

## 概述

A5（财务报表支持程序表）及子底稿 A5-1~A5-4 处理现金流量表核查、承诺事项、或有事项和持续/终止经营净利润。A5 主表已有 `cf-verification` componentType。

## 底稿结构

### A5 财务报表支持程序表
- 已有 `cf-verification` componentType（现金流量表核查视图）
- 无需修改

### A5-1 现金流量表审计（60KB xlsx）
- 现金流量表各项目核查表
- 与 A1-13/14 分析性复核类似的横向/纵向分析

### A5-2 承诺事项（31KB xlsx）
- 承诺事项披露核查表
- 结构：承诺类型 × 金额 × 期限 × 是否已披露
- 标准审定表结构

### A5-3 或有事项（75KB xlsx）
- 或有负债/或有资产披露核查
- 结构：或有事项描述 × 涉及金额 × 可能性判断 × 会计处理 × 披露情况
- 标准审定表结构

### A5-4 持续经营利润和终止经营净利润（102KB xlsx）
- 计算表：利润拆分为持续经营/终止经营
- 行：本年净利润 / 按持续性分类 / 终止经营收入(A) / 终止经营费用(B) / 终止经营利润总额(C) / 终止经营所得税费用(D) / 经营活动净利润(E=C-D) / 资产减值损失(F) / 处置收益总额(G) / 处置相关所得税费用(H) / 处置净利润(I=G-H) / 终止经营净利润(J=E+F+I)
- 含公式（E=C-D, J=E+F+I 等）
- 归属于母公司/少数股东拆分
- 经营/投资/筹资活动现金流量净额
- 审计说明 + 大额变动主要原因

## 功能需求

### 1. A5-1 现金流量表审计
- 1.1 现金流各项目核查（经营/投资/筹资活动）
- 1.2 与 trial_balance 现金流量表行取数联动
- 1.3 异常项目标记

### 2. A5-2 承诺事项
- 2.1 承诺事项录入表（类型/金额/期限/披露状态）
- 2.2 标准审定表渲染

### 3. A5-3 或有事项
- 3.1 或有事项录入（描述/金额/可能性/处理/披露）
- 3.2 可能性判断下拉（很可能/可能/极小可能）
- 3.3 标准审定表渲染

### 4. A5-4 持续/终止经营净利润
- 4.1 计算表渲染（含内置公式 E=C-D, J=E+F+I 等）
- 4.2 从利润表取数（净利润行）
- 4.3 终止经营各组成部分明细录入
- 4.4 审计说明+大额变动原因填写

## 非功能需求
- A5-2/A5-3 结构简单可用 audit-sheet 或 Univer
- A5-4 含公式计算，Univer 保留公式为低成本方案
- A5-1 与现有 cf-verification 组件联动
