## 2. 政府补助分类验证 ✅

| 检查项 | K10 其他收益(6117) | K12 营业外收入(6301) | 分类依据 |
|--------|-------------------|---------------------|----------|

| 政府补助(总额法) | 与日常活动相关的政府补助 | 与日常活动无关的政府补助（如自然灾害补助） | CAS16第11条 |
| 增值税加计抵减 | ✅ 与日常活动相关 | — | 财税政策 |
| 增值税直接减免 | ✅ 与日常活动相关 | — | 财税政策 |

| 债务重组利得(新准则) | ✅ CAS12修订后计入其他收益 | ❌ 旧准则才计入营业外收入 | 2019年CAS12修订 |
| 罚款/捐赠/盘盈等 | — | ✅ 与日常活动无关 | CAS28等 |

### xlsx证据

K10-1审定表(27行×11列)按来源分行，从K10-2引用行名（`A6='明细表K10-2'!A11`）。

K10-2明细表(43行×12列)含**类型**列和**判断依据**列，用于记录分类判断过程。

### 模板库md证据

K10-1审定表明确列出"其他收益"的来源：
- **总额法下与日常活动相关的政府补助**
- **增值税进项税额加计抵减（实际缴纳时）**
- **增值税直接减免**
- **个人所得税扣缴税款手续费返还**
- **债务人以非金融资产清偿债务损益**

K10-2明细表编制说明引用两项准则：
1. CAS 16（2017）：与企业日常活动相关的政府补助，应当按照经济业务实质，**计入其他收益或冲减相关成本费用**。与企业日常活动无关的政府补助，应当**计入营业外收支**。
2. 财政部解读：个人所得税手续费返还应作为其他与日常活动相关的项目在"其他收益"项目中填列。

K10A程序表第5条要求：
- "判断政府补助是否与日常活动相关、款项是否收到、**分类是否正确**"
- "同类政府补助是否采用一样的处理方法，如都采用总额法或都采用净额法"

**决议**: 
- 分类边界清晰：**与日常活动相关=其他收益6117(K10)，与日常活动无关=营业外收入6301(K12)**
- K10-2含"类型"+"判断依据"两列专门用于记录分类判断过程
- K10-6检查表含"分类正确性"检查逻辑，防止误将K12事项计入K10
- 实现时K10-2应内置分类选项：`与资产相关/与收益相关/与日常活动无关(应重分至K12)`

```
期末递延收益余额 P = 期初I + 本期新增J - 摊销冲减成本K - 摊销转其他收益L - 摊销转营业外收入M - 本期返还N - 其他转出O
```

## 7. K10特有业务逻辑验证

### 7.1 损益类 vs 资产/负债类取数对比

| 维度 | K10 其他收益(损益类) | K7 递延收益(负债类) |
|------|---------------------|-------------------|
| 取数来源 | **tb_ledger 发生额** | tb_balance 期末余额 |
| 核心字段 | 贷方发生额-借方发生额 | 期末余额(贷方正) |
| 审定公式 | 审定=未审(发生额)+AJE+RJE | 审定=未审(余额)+AJE+RJE |
| TB回写字段 | audited_amount=**发生额** | audited_amount=余额 |
| 方向 | 贷方=收入增加 | 贷方=负债增加 |
| 期末余额 | **=0**（损益类年末结转） | ≠0（余额累计） |

**决议**: K10作为损益类科目6117，取数逻辑与K7(负债类)根本不同。`calcIncomeStatementOccurrence(cr, dr) = cr - dr` 是K10核心特征。这与K8/K9/K11/K12/K13/L8/N4/N5等损益类底稿共享相同的取数模式。

### 7.2 K10-4政府补助核对表的三向核对

```
                    ┌────────────────────────┐
                    │  K10-4 政府补助核对表   │
                    │  (桥接/核对底稿)        │
                    └────────┬───────────────┘
                             │
          ┌──────────────────┼──────────────────┐
          ▼                  ▼                  ▼
┌─────────────────┐ ┌──────────────────┐ ┌──────────────────┐
│ K10-2 明细表    │ │ K7 递延收益      │ │ K12 营业外收入   │

│ (6117)          │ │ 期末余额(2401)   │ │ (6301)           │

```

K10-4核对等式验证：
- `K10-4.摊销转其他收益合计` = `K10-2.递延摊销行审定数`（内部一致）
- `K10-4.摊销转营业外收入合计` = `K12明细中递延摊销行`（跨底稿核对）
- `K10-4.期末递延收益余额合计` = `K7-1审定表期末审定数`（跨底稿核对）
- `K10-4.本期新增合计` = `K7-2本期增加合计`（跨底稿核对）

**决议**: K10-4是多底稿联动枢纽。实现时应：
1. 自动从K7获取递延收益期末余额用于核对
2. 差异超过0.01时标红提示（`isConsistentWithK7`）
3. GtIndexChip跳转K7-1/K7-4/K12-2
