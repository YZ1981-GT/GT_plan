## 六、Cx-2 偏差评价决策树（6步 IF 公式链）

### 源模板完整 IF 逻辑

```
行9  ┌ 评价步骤 | 是/否 | 评价分析过程 | 备注
行10 │ 步骤一：控制例外情况是否属于控制偏差？
行11 │ =IF(C10="否","不属于控制偏差；进入步骤六",IF(C10="是","进入步骤二",""))
行12 │ 步骤二：确定偏差性质（系统性/人为/随机性）
行13 │ =IF(C12="随机性偏差","确定应对措施；进入步骤三",IF(OR(C12="系统性偏差",C12="人为偏差"),"属于控制缺陷；进入步骤五",""))
行14 │ 步骤三：随机性偏差应对措施
行15 │ =IF(C14="直接认定为偏差","进入步骤五",IF(C14="扩大样本量","进入步骤四",""))
行16 │ 步骤四：扩大样本量后是否发现新偏差
行17 │ =IF(C16="否","控制有效",IF(C16="是","该控制无效；进入步骤五",""))
行18 │ 步骤五：评价控制缺陷
行19 │ =IF(OR(D15="进入步骤五",D17="该控制无效；进入步骤五"),"进入内部控制缺陷评价底稿","")
行19 │ 备注列=IF(LEN(D19)>0,"A14","")  ← 联动 A14 底稿
行20 │ 步骤六：非偏差是否表明设计缺陷
行21 │ =IF(C20="否","该控制例外情况不构成偏差或缺陷",IF(C20="是","存在设计缺陷；回到步骤五",""))
行22 │ 评价结论
```

### 决策路径汇总

| 路径 | 输入组合 | 最终结论 | goToA14 |
|------|---------|---------|:---:|
| A | 步骤一=否 → 步骤六=否 | 不构成偏差或缺陷，控制有效 | ✗ |
| B | 步骤一=否 → 步骤六=是 | 存在设计缺陷 → 步骤五 | ✓ |
| C | 步骤一=是 → 步骤二=系统性/人为 | 属于控制缺陷 → 步骤五 | ✓ |
| D | 步骤一=是 → 步骤二=随机 → 步骤三=直接认定 | 步骤五 | ✓ |
| E | 步骤一=是 → 步骤二=随机 → 步骤三=扩大 → 步骤四=否 | 控制有效 | ✗ |
| F | 步骤一=是 → 步骤二=随机 → 步骤三=扩大 → 步骤四=是 | 控制无效 → 步骤五 | ✓ |

### 评价结论可能值（行24~27）

```
1. 该控制例外情况不构成控制偏差，控制有效
2. 该控制例外情况属于随机性偏差，扩大样本量测试后未发现偏差，控制有效
3. 该控制例外情况属于随机性偏差，扩大样本量测试后仍发现偏差，构成控制缺陷
4. 该控制例外情况属于系统性偏差，构成控制缺陷
```

## 九、历史 C{n}- checklist_responses 数据结构兼容性

### 现有 item_id 命名规范（`useCControlTest.ts` generateCControlItemId）

```typescript
// 已有前缀格式：
`C${n}-ctrl-count`                          // 控制点数量
`C${n}-ctrl-${ctrlIndex}-${field}`          // 控制点字段（objective/testMethods/conclusion/...）
`C${n}-ctrl-${ctrlIndex}-sample-count`      // 样本数量
`C${n}-ctrl-${ctrlIndex}-sample-${s}-${f}`  // 样本字段（voucher/date/amount/result/deviation）
`C${n}-cycle-conclusion`                    // 循环结论
`C${n}-cycle-conclusion-override`           // 循环结论覆盖原因
`C${n}-tolerable-rate`                      // 可容忍偏差率
`C${n}-review-sign`                         // 复核签字
`C${n}-amend-${round}-reason`               // 修改原因
```

### 翻新后新增 item_id（design.md 规定）

```typescript
// 汇总表字段（新增）
`C${n}-sum-${m}-${field}`                   // 汇总表控制行各字段
// 子页字段（复用 ctrl 命名，扩展）
`C${n}-ctrl-${m}-${field}`                  // 基本信息/程序/偏差定义等
`C${n}-ctrl-${m}-sample-${s}-result`        // 样本结果
`C${n}-ctrl-${m}-sample-size`               // 样本规模
// 决策树
`C${n}-dev-${m}-step${k}`                   // 偏差评价步骤选择
`C${n}-dev-${m}-conclusion`                 // 偏差评价结论
// 循环级
`C${n}-cycle-conclusion`                    // 保持兼容
```

### 兼容性分析

| 维度 | 判定 | 说明 |
|------|:---:|------|
| 前缀 `C{n}-` | ✓ 兼容 | 加载时按前缀过滤，新旧数据并存 |
| ctrl 命名 | ✓ 兼容 | 旧 `ctrl-{i}-objective/testMethods/conclusion` 字段在翻新后子页中仍可映射 |
| sample 命名 | ✓ 兼容 | 旧 `ctrl-{i}-sample-{s}-result` 与新格式一致 |
| cycle-conclusion | ✓ 兼容 | 保持相同 item_id |
| tolerable-rate | ⚠️ 仅旧版 | 翻新后汇总表不再单独存 tolerable-rate（样本规模由区间表驱动），但读取时忽略即可 |
| sum-{m} 新增 | ✓ 新增 | 旧数据无此 key，不冲突 |
| dev-{m} 新增 | ✓ 新增 | 旧数据无此 key，不冲突 |

**结论**: 历史数据完全兼容。翻新后组件加载 `C{n}-` 前缀数据时：
- `ctrl-{i}-*` 数据映射到对应子页
- `cycle-conclusion` 直接读取
- 新增 `sum-{m}-*` 和 `dev-{m}-*` 不影响旧数据

## 十一、开发指引汇总

1. **sheetName v-if 分发**：directory / summary / ctrl-{m} / deviation-{m}
2. **汇总表15列** 实现为 el-table，6列下拉（多选认定/多选测试方法，其余单选）
3. **Cx-1-X 子页** 分13区域，逐笔样本动态行，结果点选按钮
4. **Cx-2 决策树** 6步 el-radio 点选，选后自动推进 + IF逻辑指引 + 联动A14
5. **样本规模** 从区间表建议，tooltip展示来源
6. **命名下拉** 统一常量定义（不从后端加载，源模板固定不变）
7. **偏差回填** 子页有偏差 → 汇总表 col12 = 'Y'；决策树→缺陷 → 汇总表 col14
8. **EventBus** 循环整体结论变更时发布 control:test-concluded
9. **历史数据兼容** 加载时 ctrl-{i}-* 映射到对应子页/汇总行
