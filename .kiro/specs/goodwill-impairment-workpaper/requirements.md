# 商誉减值+可收回金额测试底稿 — 需求文档

## 概述

A3-8（商誉减值准备测试表）和 A3-8-1（可收回金额测试）是合并模块（A3 循环）的专用底稿，涉及 DCF 估值模型和 WACC 计算。

## 底稿结构

### A3-8 商誉减值准备测试表
- 上半部分：项目名称 × 账面价值(1) + 可收回金额(2) + 差额(3)=(1)-(2) + 已计提减值准备 + 导致资产减值原因 + 备注
- 账面价值拆分：对应资产组的账面(A) + 应分配的商誉(B1) + 未确认归属少数股东权益的商誉(B2) + 合计(A+B1+B2)
- 下半部分：按商誉分摊到资产类别（流动/固定/无形/商誉）× 同样列结构
- 底部：审计说明
- 注释：①资产组账面价值应为合并报表层面（购买日公允价值基础持续计算）②①公允价值减处置费用净额 ②资产预计未来现金流量现值

### A3-8-1 可收回金额测试
- (一) 资产的公允价值减去处置费用后的净额
  - 项目名称 × 公允价值(销售协议价/资产活跃市场价格/估计价格) × 说明 × 处置费用(法律/税费/搬运/直接费用) × 公允价值-处置费用
- (二) 资产预计未来现金流量的现值
  - 现金净流量（税前）5年预测 + 以后年度(基数×增长率)
  - 折现率：WACC 计算表（所得税率/债务总额D/资本总额E/Kd/无风险Rf/β/市场Rm/Ke/WACC）
  - 折现系数 = 1/(1+WACC)^n
  - 预计未来现金流量现值 = ∑(每年现金流 × 折现系数)
- (三) 可收回金额 = max(公允净值, 现金流现值)

## 功能需求

### 1. WACC 计算引擎
- 1.1 WACC = [D×Kd×(1-T) + E×Ke] / (D+E)
- 1.2 Ke = Rf + β×(Rm - Rf)（CAPM 模型）
- 1.3 参数定义：
  - Kd: 税前债务成本（可比企业长期债券到期收益率）
  - Rf: 无风险报酬率（10年期国债到期收益率）
  - Rm: 市场平均收益率（几何平均，含繁荣+衰退周期）
  - β: 资产组与市场组合的系统风险相关性
  - D: 债务总额（有息负债）
  - E: 资本总额（股本+溢价+留存收益）
- 1.4 用户填写参数，系统自动计算 WACC 和 Ke

### 2. DCF 现金流折现
- 2.1 5年预测期现金流输入（第一年~第五年）
- 2.2 永续期增长率输入
- 2.3 折现系数自动计算：1/(1+WACC)^n
- 2.4 现值 = ∑(CF_n × DF_n) + TV × DF_5（终值折现）
- 2.5 年化处理说明

### 3. 商誉减值判定
- 3.1 账面价值 vs 可收回金额比较
- 3.2 差额(3) = (1) - (2)，如 (3) > 0 则需计提减值
- 3.3 减值分摊规则：先冲减商誉，再按资产比例分摊

### 4. 编制说明展示
- 4.1 6条编制说明作为 guidance 悬停/侧栏展示（不可编辑）
- 4.2 WACC/CAPM 公式以数学公式格式展示
- 4.3 参数说明（Kd/Rf/Rm/β/D/E）以 tooltip 或折叠面板展示

### 5. 数据联动
- 5.1 资产组账面价值可从合并报表数据取（预留接口）
- 5.2 已计提减值从 trial_balance 取（预留接口）
