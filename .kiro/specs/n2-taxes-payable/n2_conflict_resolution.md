## 3. 冲突清单

### 冲突#1: 房产税从价公式含月份因子

| 项目 | 内容 |
|------|------|
| **xlsx实际公式** | `=REF*(1-REF)*1.2%*REF/12` |
| **spec/design描述** | `原值×(1-扣除比例)×1.2%` |
| **差异** | xlsx多了`×月份/12`因子（按月份比例计算部分年度房产税） |
| **解决方案** | 🔧 以xlsx为准。修正公式引擎为: `calcPropertyTaxByValue(ov, dr, months=12) = ov × (1-dr) × 0.012 × months/12` |
| **影响范围** | useN2MultiTaxEngine.ts / design.md P6 PBT / requirements R6.2 |

### 冲突#2: 房产税从租公式含月份因子

| 项目 | 内容 |
|------|------|
| **xlsx实际公式** | `=REF*REF*REF/12` |
| **spec/design描述** | `租金×12%` |
| **差异** | xlsx实际为`租金收入×税率×月份/12`（按月份比例+税率参数化） |
| **解决方案** | 🔧 以xlsx为准。修正公式为: `calcPropertyTaxByRent(rent, rate=0.12, months=12) = rent × rate × months/12` |
| **影响范围** | useN2MultiTaxEngine.ts / design.md / requirements R6.2 |

### 冲突#3: N2-1审定表列结构（xlsx实际14列 vs design简化版）

| 项目 | 内容 |
|------|------|
| **xlsx实际列头(row5-6)** | A:税种 / B-E:未审数(期初/AJE/RJE/小计) / F-I:审定数(期末/AJE/RJE/小计) / J-K:期末变动(金额/比率) / L-M:审定变动(金额/比率) / N:备注 |
| **design描述** | 税种\|期初余额\|本期贷方(计提)\|本期借方(缴纳)\|未审数\|AJE\|RJE\|审定数 |
| **差异** | xlsx实际结构更复杂：未审数=期初+AJE+RJE=小计；审定数=期末+AJE+RJE=小计；还有两组变动比率列 |
| **解决方案** | 🔧 以xlsx为准。实际列结构从N2-2引用而来：A(税种名)从N2-2!A列取, B(期初)从N2-2!C列取, C(AJE)从N2-2!G列取, D(RJE)从N2-2!H列取, E=B+C+D(未审小计), F(审定期末)从N2-2!F列取, G(审定AJE)从N2-2复合公式, H(审定RJE)从N2-2复合公式, I=F+G+H(审定小计), J=F-B(期末变动), K=J/B(变动率), L=I-E(审定变动), M=L/E(审定变动率), N(备注) |
| **影响范围** | N2TabAdjudication.vue / requirements R2.2 / design Composable接口 |

### 冲突#4: N2-2明细表实际列头（23列→实际结构）

| 项目 | 内容 |
|------|------|
| **xlsx实际列头(N2-2 row8-9)** | A:项目 / B:税率或税收优惠 / C:未审数-期初数 / D:本期应交数 / E:本期已交数 / F:期末数 / G:期初调整-账项调整 / H:重分类调整 / I:账项调整-本期应交 / J:本期已交 / K:本期应交 / L:本期已交 / M:审定数-期初数 / N:本期应交数 / O:本期已交数 / P:期末数 / Q:备注 |
| **design描述** | 税种\|明细子目\|计税依据\|税率\|期初\|本期计提\|本期缴纳\|期末\|申报表金额\|差异\|核查结论 |
| **差异** | xlsx实际23列是"未审+调整+审定"三段式结构(未审4列+期初调整2列+账项调整4列+重分类调整2列+审定4列+备注)，design中描述的"计税依据/申报表金额/差异/核查结论"列在xlsx中不存在 |
| **解决方案** | 🔧 以xlsx列头为准。F=C+D-E(负债类期末); M=C+G+H(审定期初); N=D+I+K(审定应交); O=E+J+L(审定已交); P=M+N-O(审定期末)。design需修正N2-2列描述 |
| **影响范围** | N2TabDetail.vue / useN2Detail.ts / requirements R3.1 / R3.2 / R3.5 |
