# L 类底稿（筹资循环）— 需求文档

## 1. 概述

L 类底稿覆盖"实质性程序—筹资循环"阶段（审计循环代号 L），根据 B50 风险评估结果和 C13（债务）+C14（租赁）控制测试结论，执行实质性程序。包含 **8 大科目组 + 1 函证组、9 个模板文件、约 50+ 个子底稿 sheet**。

L 类特殊性：L4（应付债券）涉及实际利率法摊销的复杂公式，与 G4（债权投资）对称但站在发行方角度。

## 3. 术语表

- **筹资循环系统（Financing_Cycle_System）**：平台中负责 L 类底稿的子系统
- **实际利率法（Effective_Interest_Method）**：按摊余成本和实际利率确认利息的方法
- **应付债券（Bonds_Payable）**：企业发行的债券（L4），涉及折价/溢价摊销
- **财务费用（Finance_Costs）**：利息支出/汇兑损益/手续费等（L8）

## 5. 各组详细需求

### L0: 筹资循环函证
与其他循环函证模式一致。L0→ConfirmationHub（cycle=L），向银行/债权人确认借款余额。

### L1: 短期借款
**需求：** L1A程序表 + L1-1审定表 + L1-2明细 + L1-3利息测算 + L1-4还款计划 + L1-5检查 + L1-6调整分录
- L1-3 利息测算（本金×利率×天数/360）→`audit-sheet`

### L2: 应付利息
**需求：** L2A程序表 + L2-1审定表 + L2-2明细 + L2-3利息计提测算 + L2-4调整分录
- L2-3 利息计提测算→`audit-sheet`

### L3: 长期借款
**需求：** L3A程序表 + L3-1审定表 + L3-2明细 + L3-3利息测算 + L3-4一年内到期重分类 + L3-5检查 + L3-6调整分录
- L3-4 一年内到期长期借款重分类→`d-form-table`

### L4: 应付债券（实际利率法）
**需求：** L4A程序表 + L4-1审定表 + L4-2明细 + L4-3实际利率计算 + L4-4摊余成本摊销表 + L4-5利息费用测算 + L4-6折价/溢价分析 + L4-7检查 + L4-8调整分录
- L4-3 实际利率计算（IRR 公式：面值×票面利率的现金流折现=发行价）→`audit-sheet`
- L4-4 摊余成本摊销表（每期：期初摊余×实际利率=利息费用，-票面利息=摊销额）→`audit-sheet`
- L4-5 利息费用测算→`audit-sheet`

### L5: 长期应付款
**需求：** L5A程序表 + L5-1审定表 + L5-2明细 + L5-3现值测算 + L5-4调整分录

### L6: 专项应付款
**需求：** L6A程序表 + L6-1审定表 + L6-2明细 + L6-3使用情况检查 + L6-4调整分录

### L7: 其他非流动负债
**需求：** L7A程序表 + L7-1审定表 + L7-2明细 + L7-3检查 + L7-4调整分录

### L8: 财务费用
**需求：** L8A程序表 + L8-1审定表 + L8-2明细（利息支出/汇兑损益/手续费分类）+ L8-3利息测算 + L8-4分析 + L8-5汇兑测算 + L8-6调整分录
- L8-3 利息测算（对应 L1/L3/L4 各借款的利息汇总）→`audit-sheet`
- L8-5 汇兑损益测算（期末汇率×外币余额-账面）→`audit-sheet`

- wp_code 规则：L0~L8 共 9 组
