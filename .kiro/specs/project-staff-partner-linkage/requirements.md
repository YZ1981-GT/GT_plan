# 新建项目人员档案联动

## 需求
1. 签字合伙人从人员档案职级为“合伙人”的人员选择，显示姓名，不依赖账号角色。
2. 项目经理从所选合伙人名下人员选择，不再限定账号的 manager 角色；未选合伙人时禁用，切换或清空合伙人时清空经理。
3. 未关联登录账号的人员仍可选择和保存；人员 UUID 与用户 UUID 不混用。
4. 新建、编辑、重新打开保持选择；旧项目按关联用户唯一匹配回填，无法匹配时提示重新选择，不静默清除。
5. 后端校验职级、存在性和所属关系；列表分页读取完整，加载失败明确显示并可重试。
6. 不改人员档案维护、账号角色、项目权限和团队委派，不写真实业务测试数据。
