# 需求：CITAR「报表分析」菜单 —— 搬入旧财务报表页 9 个标签页

来源：用户 2026-11-03「按照你的建议 把旧财务报表里面 9 个标签页面拿到目前的报表分析菜单中，并适配当前系统的 UI 页面和风格」。
承接 `citar-pages-data-wiring`（R1 当时把报表分析定为待开发页）。

旧页 `views/ReportView.vue` 的 9 个标签页：资产负债表、利润表、现金流量表、权益变动表、现金流附表、减值准备表、跨表核对、多年对比、分析（试算全景 / 期初核对 / 财务比率）。

## R1 页面与版式
- 路由 `projects/:projectId/report-analysis` 由 `CitarPendingNode` 换成 `citar/screens/CitarReportAnalysis.vue`
- CITAR 版式：紫色渐变页头、标签栏（报表组与分析组之间一道分隔）、白底面板、`sheet-table` 表格、`citar-notice` 提示条；颜色 / 字号只用 `citar-tokens.css` 变量（stylelint 卡点）
- 当前标签记在 `?tab=`，刷新与返回不丢；年度取 `useCitarProject`（未设年度显示空态）
- 金额格式沿用 `fmtMoney`：未生成留空，0 显示「-」

## R2 六张报表
- 每张报表可切「审定 / 未审 / 对比」：审定读已生成的 `financial_report`，未审读时按试算表未审数计算；对比列 = 未审、调整影响、审定、上期、变动额、变动率
- 资产负债表 / 利润表 / 现金流量表 / 现金流附表：行次表（缩进、合计行按报表配置）
- 权益变动表：矩阵（实收资本 … 未分配利润 + 合计，本年金额），数据取行上的 `eq_matrix`
- 减值准备表：年初账面余额 / 期末账面余额（本期增减列平台无数据来源，不显示假的 0）
- 模板里没有的报表（上市单体无减值准备表）显示「本报表口径无此表」
- 未生成时提示并提供「生成报表」（与审定报表页同一前置条件提示）

## R3 跨表核对
- 消费 `GET /api/projects/{pid}/formula/report-cross-check?year=`，逐条显示通过 / 不通过、左值、右值、差额
- 后端勾稽按现行模板取数（见 R7.3），不能有恒为通过的条目

## R4 多年对比
- 消费 `GET /api/projects/{pid}/reports/multi-year`，报表类型可选；只有一年数据时提示「只有 {year} 年数据，暂无对比」

## R5 变动分析（接前端从未调用的 bs-trend / pl-trend）
- 资产负债表、利润表本期对上期：变动额、变动率，变动率绝对值 ≥ 10% 标「显著」；上期为空不算变动率
- 只列有数的行（本期或上期非 0）

## R6 财务比率 / 期初核对 / 试算全景
- 财务比率：9 个比率显示数值、分子、分母（各取自哪一行）；已审 / 未审切换真正生效；取不到的行写原因，不当 0 算
- 期初核对：本年试算表期初 vs 上年项目审定；上年项目按平台单一来源 `prior_year_context.find_prior_project` 查找，找不到写原因，不列假差异
- 试算全景：科目级未审 + AJE + RJE + 底稿调整 + 其他 = 审定；平衡判断不能用倒挤项自证

## R7 后端缺陷（实测确认，见 design §1）
1. `wp_report_analysis.py` 6 个端点只校登录不校项目 ⇒ 改 `require_project_access("readonly")`，鉴权基线下调
2. `FinancialRatioService` 写死的行编码与现行模板不符（国企「流动资产」取到「其中：原材料」、利润表用不存在的 `PL-xxx`），且忽略 mode ⇒ 按行名定位、按 mode 取审定 / 未审
3. 跨表核对 `logic_check` 勾稽取 `IS-017/018/019`、`BS-001`（两版模板里这些编码是「▲赔付支出净额」「流动资产：」标题行等），权益变动表从未传入（#5 恒比 0）⇒ 按行名定位、传入权益变动表
4. `ReportTrendAnalysisService` 忽略 mode、按 row_code 字典序排、未过滤已删除行 ⇒ 按模板行次排序、mode 生效
5. `reconcile_opening_balance` 不传上年项目时把上年审定当 0 ⇒ 自动找上年项目，找不到返回原因
6. `check_balance_formula` 的「其他调整」是倒挤数，平衡恒成立 ⇒ 改为显式各分量之和与审定数比对，「其他调整」非 0 的科目列出

## 约束
- 不改报表生成、试算表口径、公式管理表间审核的执行接口契约（只改取数定位与权益表传入）
- 新增 / 改动端点有端点级测试（含未登录 401、非成员 403、成员 200）
- stylelint / eslint / 单区域 vue-tsc 通过；浏览器实测每个标签页
