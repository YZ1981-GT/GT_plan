### 摊销测算I4-6（直线法，65行×28列）

xlsx实际列结构（从公式推断）：
| 列 | 含义 | 公式 |
|----|------|------|
| A | 序号 | — |
| B | 项目名称 | ='明细表I4-2'!A{n} |
| C | 原始金额 | 手填 |
| D | 已摊销金额 | 手填 |
| E | 摊销起始日 | 手填 |
| F | 摊销期限 | 手填（如"5年"） |
| G | 上年月摊销额 | 手填 |
| H | 总月数 | =IF解析F列年→月 |
| I | 到期日 | =DATE(YEAR(E)+H月) |
| J | 已摊月数 | =DATEDIF(E, min(截止日,I)) |
| K | 剩余月数 | =H-J |
| L | 本期应摊月数 | =DATEDIF(期初,期末)条件判断 |
| M | 月摊销额 | =((1-0)/H)*C → 原始÷总月数 |
| N | 本期摊销 | =M*L |
| O | 月摊差异 | =G-M |
| P | 累计摊销 | =M*J |
| Q | 期末净值 | =D-P（原始-累计） |

**md模板**（I4-8）：费用项目|原值|摊销期限|年摊销额|累计摊销|净值|审计评价|索引号（8列）

**解决**：xlsx有28列（含DATEDIF日期函数、月数计算、条件判断），远比md描述复杂。**以xlsx 28列公式为准**。直线法核心确认：`月摊销 = 原始金额 ÷ 总月数`（md语义一致）。

### 摊销测算I4-7（工作量法，65行×28列）

xlsx公式中引用`'明细表I4-2'!A{n}`取项目名，结构与I4-6类似但计算逻辑不同（工作量比例）。

**md模板**（I4-9）：费用项目|原值|总工作量|已完工作量|摊销比例|累计摊销|净值|审计评价|索引号（9列）

**解决**：同I4-6，xlsx为准。工作量法核心确认：`月摊销 = 原始金额 × (本月工作量 ÷ 总工作量)`（md语义一致）。

## 3. 公式逻辑 vs 业务语义验证

| 公式/规则 | xlsx公式 | md语义 | 一致性 |
|-----------|---------|--------|--------|
| 审定数 | =未审+账项调整 | 审定=未审+调整 | ✅ 一致 |
| 期末数 | =期初+增加-摊销-减少 | 期末=期初+增加-摊销-减少 | ✅ 一致 |
| 直线法月摊 | =((1-0)/H)*C → C/H | 原始金额÷摊销总月数 | ✅ 一致（xlsx含残值率=0） |
| 工作量法 | 原始×(本期量÷总量) | 原始×(本月工作量÷总量) | ✅ 一致 |
| 变动率 | =IF(AND(D=0,H=0),0,IF(AND(D=0,H>0),1,H/D)) | — | ✅ xlsx独有，含除零保护 |
| 附注期末 | =B+C-D-E | 期初+增加-摊销-减少 | ✅ 一致 |
| SUMIF汇总 | =SUMIF(明细表!$A:$A,$A{n},明细表!O:O) | 按类别汇总 | ✅ 公式实现md描述的聚合逻辑 |
| 日期→月数 | DATEDIF + 条件4分支 | — | ✅ xlsx独有精确算法 |

## 4. 联动方向 / EventBus流（md为准）

| 联动 | md定义 | xlsx验证 | 采纳 |
|------|--------|---------|------|

## 6. 额外发现

### 6.1 xlsx独有：GT_Custom sheet
- 8行×2列，0公式
- 平台内部配置sheet（类别设置等），md无对应
- **处理**：开发时作为config sheet忽略或fallback OO

### 6.2 xlsx审定表实际结构是"双期审定表"
- xlsx I4-1 是期初+期末双期对比格式（9列含变动额/率）
- md简化版是单列（项目|未审|调整|审定）
- **处理**：以xlsx双期格式开发，这与design.md描述的"项目|期初|本期增加|本期摊销|本期减少|期末|未审|AJE|RJE|审定数"需要进一步对齐

### 6.3 design.md审定表列描述 vs xlsx实际列

design.md描述：`项目|期初|本期增加|本期摊销|本期减少|期末|未审|AJE|RJE|审定数`（10列）

xlsx实际：`项目类别 | 期初(未审/调整/审定) | 期末(未审/调整/审定) | 变动额 | 变动率`（9列，2组×3列+变动2列）

**差异本质**：design.md描述的是"资产变动维度"视角（期初→变动→期末），xlsx是"审定维度"视角（期初三态 + 期末三态 + 变动分析）。

**解决建议**：以xlsx 9列为真实数据结构。design.md的描述应调整为双期审定格式。开发时前端展示可以同时呈现两种视角。

### 6.4 公式数量差异

| sheet | design.md预估 | xlsx实际 | 差异 |
|-------|-------------|---------|------|
| I4-1审定表 | 47公式 | 47 | ✅ |
| 明细表I4-2 | 18公式(req)→98(actual) | 98 | ⚠️ requirements说18但实际98 |
| I4-6直线法 | 39公式(design) | 150 | ⚠️ design严重低估 |
| I4-7工作量法 | 21公式(design) | 77 | ⚠️ design低估 |

**原因分析**：design.md中的公式数是"去重后的公式模板数"（一个模板重复N行），xlsx统计的是"所有公式单元格总数"。实际开发中以模板数为逻辑复杂度参考，以总数为工作量参考。

## 7. 总结与开发建议

### 无冲突项（直接采纳）
- ✅ 核心公式语义一致：审定=未审+调整、期末=期初+增加-摊销-减少、直线月摊=原始÷月数
- ✅ 数据流方向一致：明细→审定→附注、调整→审定
- ✅ 摊销2方法分支确认：直线法(I4-6) + 工作量法(I4-7)
- ✅ 附注双版本：上市(14×13) + 国企(16×12)

### 已解决冲突
| 冲突 | 解决 |
|------|------|
| 编号体系 I4-2~I4-9(md) vs I4-2~I4-7(xlsx) | **xlsx为准**：明细=I4-2，摊销=I4-6/I4-7 |
| 列数 md简化 vs xlsx完整 | **xlsx为准**：开发以完整列结构为标准 |
| 联动方向（附注取数路径） | **md为准**：EventBus审定→附注（虽xlsx物理路径是明细→附注） |
| 公式数量预估 | 以xlsx为工作量基准，模板数为逻辑复杂度基准 |

### 开发注意事项
1. **sheetName匹配必须用xlsx原始tab名**（含中文全角括号）
2. **摊销I4-6公式含DATEDIF**：需前端composable精确实现日期→月数转换
3. **明细表25列宽表**：必须拆分为3区段Tab（未审/调整/审定）
4. **双期审定表**：期初+期末两组各3列，非design.md描述的单行变动格式
