# 需求：底稿附件就地预览与易用性（attachment-inline-preview）

来源：用户 2026-10-27「最好在每个底稿对应的附件处有个小眼睛，点击后可以预览附件等，对于使用功能上你在看下」。承接 Spec A（附件安全底线）、Spec B（底稿证据入口 `workpaper_evidence_intake`、行级证据 `evidence_links`、共享链接仓 `useWpEvidenceLinks`）。

## 现状（2026-10-27 现读，盘点口径见 design §1）

| 点 | 现状 |
|---|---|
| 已有预览 | 底稿附件抽屉（每项有「预览」按钮）、右侧附件页签（整行点击）、函证附件抽屉、附件管理页 |
| 行级附件 `ItemAttachment`（40 余个页面在用） | 点文件名直接下载，没有预览 |
| 各页自带的附件展示 | C22 / C23 / C24 / C 类控制测试 / C25 / C26 的 📎、B2-12 步骤附件只能下载；D4-12 合同卡片、D1 备忘卡片、D2 终止确认向导只显示文件名；G6 凭证检查 📎 悬浮提示显示附件编号；证据分组展开「附件ID」列只显示编号前 8 位；证据链接列表、识别字段抽屉、血缘图附件节点只有文件名 |

## 需求 1　统一的「小眼睛」

1.1 底稿内凡显示附件的地方，每份附件旁有一个小眼睛按钮：图标 + 悬浮提示「预览」，读屏名「预览 {文件名}」。
1.2 点击从右侧打开预览：PDF、图片在线看；Word / Excel 转 PDF 在线看（转换服务不可用时提示并给下载）；其他格式说明不支持在线预览并给下载。顶部显示文件名与识别状态（中文）；已识别的附件在原件下方显示识别全文。
1.3 只知道附件编号时先取附件信息再预览；附件已删除或无权查看 ⇒ 中文提示「附件不存在或无权查看」，不打开空白预览。
1.4 只读（复核、已归档）照常可预览、下载。
1.5 同一页几十行各有小眼睛时，不为每行预先发请求、不预先挂预览容器；点开才加载。

## 需求 2　覆盖范围

2.1 行级附件 `ItemAttachment`：每份文件有小眼睛；点文件名也是预览；另设下载按钮。
2.2 右侧附件页签：每项有小眼睛（整行点击照旧预览）。
2.3 各页自带的附件展示（design §1.2 清单）全部加小眼睛；只记了文件名、没记附件编号的（D2 终止确认向导、G7 减值测试）补记编号。
2.4 行内「📎 上传 / 识别」：上传后该行显示本行的附件 —— 一份显示小眼睛，多份显示份数，点开逐个预览。做法：识别请求带上本行位置（表页 + 行），后端照 Spec B 只写行级证据链接；**不往行数据里加字段**（行数据会同步到在线编辑与导出，新增字段有契约风险）。
2.5 并发会话正在改的页面（凭证检查 D1 / D3 / D4、E1 银行流水 / 大额收付）与 Spec C 负责的函证替代程序页本 spec 不动，登记在守卫豁免清单并写明原因。

## 需求 3　易用性修正

3.1 预览判型统一按文件扩展名给类型提示（PDF → `application/pdf`，图片 → `image/<扩展名>`）；识别状态 `completed` 显示为「OCR ✓」。
3.2 证据分组展开显示文件名与小眼睛，不显示附件编号。
3.3 G6 凭证检查 📎 悬浮提示显示文件名，不显示附件编号。
3.4 G7 减值测试估值依据：识别摘要取回执的识别全文前 120 字与已识别出的合同字段；记附件编号并显示小眼睛。
3.5 浏览器走查中发现的其他易用性问题：在本 spec 范围内的就地修复，范围外的登记归属。

## 需求 4　守卫

4.1 覆盖守卫：扫描底稿组件，模板里展示附件（📎 链接、下载调用、附件名）或调用识别端点的文件，必须带小眼睛（`AttachmentEyeButton` / `RowEvidenceEye` / `ItemAttachment`）；豁免清单逐条写原因，只许删不许加；清单里的文件确实存在且确实未接（防失效条目）。
4.2 组件测试：小眼睛按需取附件信息、判型、只读可用、失败提示中文；行内小眼睛按位置计数、单份直接预览、多份列表；`ItemAttachment` 文件名点开预览。mock 用后端真实返回形状。
4.3 识别请求带行位置：抽样页面的组件测试断言表单里有 `evidence_sheet` / `evidence_cell`，识别成功后本底稿链接仓失效重取。

## 需求 5　验证

5.1 前端相关用例、单区域 vue-tsc、行数门。
5.2 浏览器走查（远端线候选树私有前后端 +【测试】项目）：行级附件预览 PDF / 图片 / Word，右侧页签图片预览，行内识别后小眼睛与份数，只读可预览，无权限 / 已删除提示；数据走平台路径清理并对账。
