# 需求：合并自动建树范围外问题收口（报表域鉴权 / 操作门禁 / 状态名 / 合并范围单一来源）

> 承接 `consol-autotree-linkage-closure` 验收记录登记的范围外三项（用户 2026-10-27「发现没改的问题继续改」），连同修的过程中查到的同类问题（R2.3、R2.4、R3 归档、R6）。现状 grep、复现与真库核对见 design §1。

## R1 报表域端点项目隔离

1. 报表页取数的三个端点（`GET /api/reports/{project_id}/{year}/{report_type}`、`…/drilldown/{row_code}`、`…/export-excel`）只认项目成员：非成员 403「权限不足」，admin 照旧放行。
2. 生成报表（`POST /api/reports/generate`，项目在请求体）按请求体里的项目校验编辑权限；只有操作矩阵通过、不是该项目 edit 级成员的用户 403。
3. 报表页同域、只校验登录的端点一并改为项目级：报表行次映射（读 readonly、写 edit）、报表行关联底稿、报表导出、报表映射（读 readonly、保存 edit）、底稿报表分析（readonly）。
4. 鉴权基线（路径维 / 前缀维 / 请求体维）按现算下调；本次修过的端点逐个钉住级别。

## R2 读取另一个项目数据的参数

1. 端点读写另一个项目的数据时，对那个项目同样校验成员（只读即可）；校验后 RLS 上下文设回本项目。
2. 期初核对的上年项目（`prior_project_id`）须可读。
3. 报表行次映射参照复制：试算表「参照其他单位」按选定的来源项目复制（须可读），来源下拉不列本项目；向导「一键参照」按客户名称只在可读项目里找，找不到就不复制并提示（不再退回到任意一个有映射的项目）。
4. 试算表导入的列映射：可参照项目只列可读项目，复制前校验来源可读；保存 / 复制列映射要真的落库。

## R3 操作门禁带项目时校验成员与归档

1. `require_operation` 能从路径 / 查询参数取到项目时：会改数据的操作遇已归档项目 423（只读查看、归档编排除外），权限矩阵放行后还须是该项目成员（admin 例外）；取不到项目的全局端点照旧只按系统角色判。
2. 受影响端点（调整分录新建 / 底稿同步、归档编排等）非成员被拒，成员照旧按操作矩阵判。
3. 鉴权基线把 `require_operation` 算作项目级的口径有可伪证测试；项目在请求体的端点不能只靠它。

## R4 调整分录状态中文名一致

1. 可解释状态机面板里调整分录的状态与动作名与系统字典「调整分录状态」同一套：草稿 / 待复核 / 已批准 / 已驳回，动作「提交复核」「驳回」。
2. 底稿侧集中登记的状态标签与调整分录页同一常量（「已批准」，不再是「已通过」）。
3. 合并抵销分录保持「待审批 / 已审批」措辞，「已驳回」与调整分录一致；守卫钉住两处一致与前后端一致。

## R5 合并范围成员以企业树为准

1. 附注正文变量（子公司数、子公司清单）与程序表「确定合并范围」自动取数改读企业树（与合并计算同一棵树）；持股比例沿用合并范围表里同一企业代码的属性行，没有则为空。
2. 合并总览不再拿合并范围表比对（真库该表 0 行，每棵树都会显示「合并范围差异」、诱导同步到一张不影响合并数的表）；改为提示「企业树有变化」（与最近记录的树版本相比有结构变化），点开即企业树版本弹窗。
3. 旧的范围校对 / 同步端点与服务无调用方后删除。

## R6 向导「基本信息」读法统一

1. 向导确认后项目的准则（国企 / 上市 × 单户 / 合并）与向导填的一致，不被改回默认。
2. 试算平衡表按报表行次汇总取哪套行次模板，与报表页同一个解析。
3. 其余读向导基本信息的地方与向导保存的位置同口径。

## R7 登记不改（另立 spec）

签名域（签署人可任意指定、按对象 id 读 / 验 / 撤签名不校项目、工作底稿签字组件请求体与接口不符）、审计报告正文端点（状态更新等按对象 id 不校项目）、可解释状态机「允许动作」按实例 id 不校项目、G7「从合并范围带入」查的是单体项目、合并底稿导出（旧模型、无前端入口）、平台其余只校验登录的端点（棘轮继续）；`app/permissions/enforcement.require_permission`（无调用方，与旧 `require_operation` 同一缺陷）、准则切换只改向导平铺副本（steps 里仍是旧准则）、确认后改基本信息不刷新结构化准则；附注正文变量读企业树新增一条「附注 → 合并」域边界违规（检查器在 HEAD 已红，见 design ADR-5）；报表配置上市两版资产负债表 BS-016~018 与 BS-013~015 重复（报表页「一年内到期的非流动资产 / 其他流动资产 / 流动资产合计」各出现两次）；向导「报表行次映射」步骤组件没有挂载点（只有 vitest 覆盖）；试算表「参照其他单位」候选取的是项目列表（系统角色 partner 能看到非成员项目、选了即 403，同名不同年度分不清，不看有无已确认映射）；回归里 HEAD 已红、与本 spec 无关的用例见 design §4。
