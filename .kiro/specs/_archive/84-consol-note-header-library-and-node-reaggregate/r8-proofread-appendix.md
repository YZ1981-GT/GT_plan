# R8.4 校对附录：单体附注模板 ↔ 底稿披露 sheet（2026-10-24 探针，只读）

口径：底稿模板 xlsx 的附注披露 sheet（`note_workpaper_sync_registry.json` 的 sheet 名，同一章节几张底稿合并比）切表；【】提示与括号提示（「（不适用删除）」等）、勾稽注记（「（1）」「C=A+B」）、「……」占位列、「返回目录」去掉；行名 / 组合名只作参考不比；比「表 + 续表」单元的逐列表头（期间 + 计量）。模板按 HEAD 版（并发会话 spec 69 的未提交改动单列）。

分类：OK 逐字相同 / MINOR 只差标点 / SYN 期间词或计量写法不同（期末数≡期末余额、年初≡期初 等，语义相同）/ SPLIT 拆表方式不同、列都对得上 / DIFF 列或计量不同 / TPL_ONLY 底稿没有这张表 / XLSX_ONLY 底稿有、模板没有。
