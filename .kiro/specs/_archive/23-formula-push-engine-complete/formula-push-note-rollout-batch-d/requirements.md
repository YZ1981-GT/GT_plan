# 公式推送附注铺开 · 批 D：简单型族 binding

## 背景

上游：
- `formula-push-all-subjects-rollout`（26/26 ✅）——平台化 + E1/K1 + Tier A canary
- `formula-push-note-rollout-batch-c`——已注册码加附注规则 + 章节映射基础设施

批 C 完成后，20 个已注册码全部有附注推送能力。但还有 **~28 个未注册的主编码**需要新建 binding 才能接入推送。其中绝大多数是"简单型"——单科目、只需从试算表取审定数推到底稿审定表和附注。

本 spec 建立**附注直推族 binding**（`NoteDirectBinding`），用工厂模式批量覆盖这些简单型科目。

## 现状实证（2026-10-05 现算）

| 编号 | 事实 |
|------|------|
| D-S1 | 72 个主编码 − 20 个已注册 = **52 个未注册**（含 24 个无 `note_section` 映射） |
| D-S2 | 52 个中有附注章节映射的约 **28 个**，无映射的约 **24 个**（函证中心/程序表/无科目等） |
| D-S3 | 28 个有映射的科目中，**绝大多数是单科目 + 期末/期初两列结构**（从上游 spec 分析得 45/47 为"简单型"） |
| D-S4 | 族 binding 先例：`TierAAnchorBinding` 用 `binding_for(code)` 工厂函数按科目码实例化，注册表写一行工厂调用即完成一个科目的接入 |
| D-S5 | 四套模板编号体系各不相同（批 C C-S2 实证），章节定位必须按科目名匹配 |
| D-S6 | 部分科目在国企/上市版附注章节名称有差异（如 soe "资产减值损失" vs listed "资产减值损失（损失以"—"号填列）"） |
| D-S7 | 损益类科目（K8~K13/G11~G14/L8/N4/N5 等）取数须用发生额口径 `TB(code, '本期发生额')`（上游 Task 8 已支持） |

## 需求

### 需求 1：族 binding 框架

1. SHALL 建立 `NoteDirectBinding` 族 binding，通过工厂函数 `note_direct_for(code)` 按 `wp_account_mapping.json` 自动实例化
2. binding SHALL 支持：单科目取数（`TB(code, '期末余额')` / `TB(code, '年初余额')`）+ 附注主表推送
3. 损益类科目 SHALL 自动识别并使用发生额口径（`TB(code, '本期发生额')`）
4. binding 的 `note_rows()` SHALL 输出与 E1 格式一致的行数据
5. 注册表每个科目只需**一行工厂调用**（如 `"G1": "...note_direct:note_direct_for('G1')"` ）

### 需求 2：底稿审定表锚点

1. 每个新注册科目 SHALL 同时有底稿审定表锚点规则（`domain: "workpaper"`，`TB()` 公式）
2. 锚点规则的 `item_id` SHALL 从该科目现有的预设库（`d_cycle_extraction_presets.json`）或渲染策略（`adjudication_prefill`）取

### 需求 3：附注推送规则

1. 每个科目 SHALL 有附注推送规则（`domain: "note"`）
2. 章节编号 SHALL 从批 C 建立的映射基础设施取
3. 两版中任一版无对应章节的 SHALL 声明为 null

### 需求 4：验收

1. 每个新注册科目 SHALL 有真 ORM 集成测试
2. 规则清单校验通过；现有推送测试全绿
3. 独占键集合更新（新增底稿锚点进独占集合，附注规则不进）

## 交付范围

按 `wp_account_mapping.json` 的未注册主编码中有附注映射的科目，按循环分组：

| 循环 | 科目 | 数量 |
|------|------|------|
| G（投资） | G1~G14（去掉已注册的） | ~14 |
| H（固定资产） | H1~H4（去掉已注册的） | ~4 |
| J（职工薪酬） | J1~J3 | ~3 |
| K（管理） | K2~K13（去掉已注册的） | ~7 |
| L（筹资） | L1~L8（去掉已注册的） | ~6 |
| M（股东权益） | M1~M10（去掉已注册的） | ~6 |
| N（税费） | N1~N5（去掉已注册的） | ~3 |

> 精确清单须现算确认（去掉已注册 + 无章节映射 + 函证中心 + 无科目映射的）

## 非目标

- 已注册的 20 个 binding（E1/K1/Tier A 由批 C 处理）
- H1 固定资产 / I1 无形资产（多科目减项型，归批 E）
- 复杂附注子表
- 合并附注推送
- 函证中心（E0/F0/G0/H0/K0/L0）、程序表、检查表、文档型底稿
