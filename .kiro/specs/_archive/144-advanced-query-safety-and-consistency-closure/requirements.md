# 需求文档：高级查询安全与一致性收口

## 目标

本 spec 承接 `advanced-query-linkage-closure` 已完成的查询主链，只处理其后复核发现的阶段 0 问题。目标是保证高级查询不会越权读取回收站项目、不会把失败的分组或透视伪装成成功、不会绕过时间与资源预算，也不会因前端上下文或请求竞态展示错误结果。

本轮不实现 W3 系统预置、W6 业务页对象级入口、查询证据、AI、知识库、附件或交付联动。它们在本 spec 验收后继续实施。

## R1 HTTP 回写面退役

1. `POST /api/custom-query/cell-writeback`、`writeback-preview`、`writeback-confirm` 统一返回 410，包含稳定错误码、中文说明和替代路径说明。
2. 退役桩不得声明数据库或登录依赖，不解析请求体，不触达数据、审计或 outbox。
3. 底稿、附注、TB、调整和报表只能在各自权威页面及既有保存/发布门写入。
4. `SnapshotWriter` 等底层模块暂保留，避免破坏 workpaper-sync 的既有契约；后续按调用方清册单独清理。

## R2 项目与权限隔离

1. 业务视图、指标树、底稿预览、模板执行及 ACNR 查询必须先确认项目存在且 `projects.is_deleted=false`。
2. admin、partner 的全项目权限也不得绕过项目存活检查。
3. 普通成员可访问集合只包含未删除项目；软删项目返回 403 `FORBIDDEN_PROJECT`，并且不触达领域数据表。
4. 缓存身份必须包含用户当前循环范围，循环范围变化后不得命中原来的更宽结果。

## R3 查询语义 fail-closed

1. 用户请求分组或透视时，模块缺失或执行异常必须返回明确 4xx/5xx，禁止返回原始明细 HTTP 200。
2. PostgreSQL `SET LOCAL statement_timeout` 设置失败必须中止；仅明确的非 PostgreSQL 方言可跳过。
3. 客户端取消与数据库超时继续回滚当前事务并返回现有可识别错误。

## R4 构建器资源与语义边界

1. `fields≤60`、`filters≤20`、`order_by≤5`、`joins≤3`、`aggregates≤10`、`group_by≤5`，`offset≤100000`。
2. JOIN 与聚合元素使用严格模型，拒绝额外键；聚合别名非空、长度有限且与所有输出列唯一。
3. 选择普通字段并聚合时，所有普通字段必须进入 `GROUP BY`；否则在执行前返回 400。
4. 分组结果分页必须有确定性排序；未显式排序时按全部分组列升序。
5. 数据库执行错误只向客户端返回中文通用原因和追踪号，详细 SQL/驱动错误只记服务端日志。
## R5 审计与结果时效

1. 构建器成功执行必须记录审计，至少包含用户、项目范围、表、条件摘要、行数与是否跨项目；同一查询可按 60 秒窗口聚合。
2. 审计失败不改变只读查询结果，但必须写服务端 WARNING。
3. 业务查询缓存继续短 TTL；涉及循环范围的键必须带范围摘要。`count_token` 继续绑定用户与 SQL 摘要，不得跨查询复用。
4. 本轮不新建全平台数据事件版本表；数据变化的强一致由后续 QueryArtifact/事件版本 spec 处理，并在界面明确结果所属查询上下文。

## R6 前端上下文与竞态

1. `CustomQueryFieldPicker` 显式接收宿主所选 `projectId`；项目变化时清缓存、重载树并清理不属于新上下文的已选地址。
2. 弹窗、页面版和构建器的查询只允许最新请求写入状态；旧响应、旧错误和旧 loading 结束不得覆盖新请求。
3. 项目、年度、数据源、构建器范围或表变化后，旧结果立即清除，导出、下钻和复制引用不可继续使用。
4. 全局弹窗接入 `count_token`；新查询清空，后续翻页复用，查询定义变化时不得复用。
5. 无项目模式只允许浏览指标/模板结构，不得向必须带项目的执行链发送空项目 id。
6. 全局弹窗指标树改为骨架加按需分支，不再默认下载全部底稿 sheet 树；底稿选区仍可通过选定底稿后按需加载。

## R7 验收

1. 后端端点级测试覆盖 410 桩、软删项目、语义失败、PG 超时设置失败、DSL 各上限、错误脱敏和成功审计。
2. 前端测试覆盖项目显式传递、上下文清理、后到旧请求丢弃和弹窗 COUNT 凭证。
3. 真 PG 只读核对软删项目和辅助明细查询；写入测试只在回滚事务或【测试】项目执行。
4. Playwright 在 `http://127.0.0.1:3030` 验证业务视图与构建器，控制台无新增 error。
5. 不新增依赖，不新增数据库迁移，所有用户可见文案为中文。
