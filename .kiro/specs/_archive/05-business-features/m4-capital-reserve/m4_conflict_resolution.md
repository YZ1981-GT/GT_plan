## 1. 权益类方向验证 ✅ 一致

| 验证项 | xlsx实证 | md描述 | 结论 |
|--------|---------|--------|------|
| 科目方向 | M4-2明细表 E列公式 `=B#+C#-D#`（期末=期初+增-减）| md M4-2:"项目类别 \| 期初数 \| 本期增加 \| 本期减少 \| 期末数" | ✅ 一致：权益类贷方(期末=期初+贷方-借方) |
| 审定数公式 | M4-2 O列 `=L#+M#-N#`（审定期末=审定期初+审定增加-审定减少）| md同描述"审定数"区段 | ✅ 一致 |
| 附注公式 | 上市公司附注 E7 `=B7+C7-D7` / E8 `=B8+C8-D8` | md:"期末余额=期初余额+本期增加-本期减少" | ✅ 一致 |
| 变动额 | M4-1 J列 `=I#-E#`（期末审定-期初审定）| md M4-1审定表"变动额"列 | ✅ 一致 |

**结论**：两源对M4**权益类贷方科目**方向完全一致。公式链：`期末 = 期初 + 贷方(增加) - 借方(减少)`。

## 3. J3 股份支付 → M4 其他资本公积 联动验证

| 验证项 | xlsx实证 | md描述 | 结论 |
|--------|---------|--------|------|
| M4-2中"权益结算的股份支付"行 | Row16区域（other资本公积子项），无显式跨表引用J3 | md明确列示"权益结算的股份支付"作为其他资本公积子项 | ⚠️ 差异：xlsx无显式J3联动公式 |
| 审计程序认定 | M4A程序表无显式提及J3 | md M4-2提示第14条："对于权益结算的涉及职工的股份支付，是否按照授予日权益工具的公允价值计入成本费用和**资本公积(其他资本公积)**" | ✅ md确认联动方向 |
| J循环侧引用 | （未在M4 xlsx中发现J3→M4公式）| J1A程序表第8项"检查股份支付"→J1-11/J1-12 | ✅ md描述J3出口→M4 |

**冲突解决**：
- **联动方向以md为准**：J3股份支付权益结算 → M4其他资本公积（贷方增加）
- xlsx中无显式跨表公式（实际审计中为手工录入+核对），前端设计应通过EventBus订阅`j3:equity-settled`实现自动联动
- 具体映射：J3等待期确认的权益结算金额 → M4-2"权益结算的股份支付"行的"本期增加"

## 4. M2 外币折算差异 → M4 资本溢价 联动验证

| 验证项 | xlsx实证 | md描述 | 结论 |
|--------|---------|--------|------|
| M4-2中外币相关行 | Row10-14区域（资本溢价子项），无显式跨表引用M2 | md M4-2无显式"外币折算差异"行；但资本溢价来源包含"投资者溢价投入" | ⚠️ xlsx无显式M2联动 |
| M2实收资本侧 | M2-4外币投资汇率测算表存在 | md M2-4:"投资者 \| 币种 \| 原币金额 \| 折算汇率 \| 折合人民币 \| 账面数 \| 差额" | ✅ md确认M2有外币出资 |
| 会计准则联动 | — | md操作手册提及"外商投资企业"专项，外币出资汇率折算差异计入**资本溢价** | ✅ md确认联动方向 |

**冲突解决**：
- **联动方向以md为准**：M2外币出资折算差异 → M4资本溢价（贷方/借方取决于汇率变动方向）
- xlsx中无显式跨表公式（实际为手工核对），前端设计应通过EventBus订阅`m2:fx-diff`实现
- 具体映射：M2-4测算的折算差额 → M4-2"资本溢价"区段中对应投资者行

## 7. 公式链汇总（以xlsx为准）

### M4-2 明细表核心公式
```
未审期末:  E# = B# + C# - D#          (权益类：期末=期初+增加-减少)
审定期初:  L# = B# + F# + G#          (审定期初=未审期初+账项+重分类)
审定增加:  M# = C# + H# + J#          (审定增加=未审增加+账项增加+重分类增加)
审定减少:  N# = D# + I# + K#          (审定减少=未审减少+账项减少+重分类减少)
审定期末:  O# = L# + M# - N#          (权益类：审定期末=审定期初+审定增加-审定减少)
分类小计:  B10 = SUM(B11:B14)          (资本溢价=Σ子项)
           B15 = SUM(B16:B18)          (其他资本公积=Σ子项)
合计:      B20 = B10 + B15             (合计=溢价+其他)
```

### M4-1 审定表跨sheet取数
```
Row7(股本溢价):     从 '明细表M4-2'!B10/E10/F10/G10/L10/O10 取数
Row8(其他资本公积): 从 '明细表M4-2'!B15/E15/F15/G15/L15/O15 取数
Row10(合计):        SUM(Row7:Row9)
变动额:             J# = I# - E#
变动率:             K# = IF(AND(E#=0,J#=0),0,IF(AND(E#=0,J#>0),1,J#/E#))
```

### 附注公式（上市/国企共用逻辑）
```
期初:     B7 = '明细表M4-2'!L10    (溢价审定期初)
本期增加: C7 = '明细表M4-2'!M10
本期减少: D7 = '明细表M4-2'!N10
期末:     E7 = B7 + C7 - D7        (权益类)
合计:     B9 = SUM(B7:B8)
```

## 9. 前端设计指导（基于交叉验证结论）

1. **权益类公式引擎**：`calcEquityEndBalance(begin, credit, debit) = begin + credit - debit`
2. **双区块UI**：审定表&明细表均分"资本溢价"+"其他资本公积"两区段
3. **J3联动**：订阅`j3:equity-settled` EventBus → 自动填入M4-2"权益结算的股份支付"行本期增加
4. **M2联动**：订阅`m2:fx-diff` EventBus → 自动填入M4-2资本溢价区段对应投资者行
5. **24列宽表**：M4-2按xlsx实际24列(A~Q+隐藏)，前端拆区段Tab（资本溢价/其他资本公积）
6. **附注自动切换**：根据企业类型(上市/国企)切换附注模板sheet
7. **检查比例自动计算**：M4-4从M4-2取本期发生额(`='明细表M4-2'!N20`/`M20`)计算检查覆盖比例
