# M9 其他综合收益 — 双源交叉验证 & 冲突解决

## 概述

| 维度 | xlsx 源 | md 源 | 状态 |
|------|---------|-------|------|
| 文件 | `M9 其他综合收益.xlsx` (9 sheet) | `M权益循环底稿模板库.md` | md**不含**M9 |
| 提取产出 | `m9_structure_summary.json` (117KB) | 仅 M0~M8 覆盖 | ⚠️ 缺失 |

**关键发现**：`M权益循环底稿模板库.md` 仅涵盖 M0(函证)~M8(一般风险准备)，**M9(其他综合收益)** 和 **M10(其他权益工具)** 均未包含在 md 模板库中。

**原因推测**：M9/M10 属于2019年新金融工具准则(CAS22/CAS37)实施后新增科目，致同2025修订版md模板库可能因时间差尚未覆盖这两个科目的详细程序文本（xlsx源模板已提供完整结构）。

## 三、税后净额验证 ✅

### 3.1 公式链分析

从xlsx明细表M9-2提取核心公式模式：

```
// 不能重分类项(row11~15)—无R列转出
T{n} = P{n} + Q{n} - R{n} - S{n}   // 期末 = 审定期初 + 税前发生 - 转出 - 所得税

// 能重分类项(row17~26)—有R列转出
T{n} = P{n} + Q{n} - R{n} - S{n}   // 同上，R列=前期转入损益

// 合并公式
P{n} = C{n} + H{n} + I{n}          // 审定期初 = 未审期初 + 期初账项调整 + 期初重分类调整  
Q{n} = D{n} + J{n} + M{n}          // 审定税前 = 未审税前 + 账项调整税前 + 重分类调整税前
R{n} = E{n} + K{n} + N{n}          // 审定转出 = 未审转出 + 账项调整转出 + 重分类调整转出(仅能重分类类)
S{n} = F{n} + L{n} + O{n}          // 审定所得税 = 未审所得税 + 账项调整所得税 + 重分类调整所得税
```

### 3.2 附注税后净额

**上市公司附注**（row7列定义）：
```
期末余额(3) = 期初余额(1) + 税后归属母公司(2)
// 税后净额 = 本期所得税前发生额 - 前期转损益 - 所得税费用
```

**国企附注**（row9列定义）：
```
税后净额 = 税前金额 - 所得税
// F{n} = B{n} - D{n}
```

### 3.3 冲突检查

| 对比点 | xlsx | md | 冲突？ | 解决 |
|--------|------|-----|--------|------|
| 税后净额公式 | T=P+Q-R-S（完整） | md缺失 | N/A | **以xlsx为准** |
| 国企税后=税前-所得税 | F=B-D | md缺失 | N/A | **以xlsx为准** |
| 不能重分类无R列 | row11~15无R公式 | md缺失 | N/A | **以xlsx为准** |
| 能重分类有R列 | row17~26有R公式 | md缺失 | N/A | **以xlsx为准** |

**结论**：税后净额=税前发生-所得税影响（能重分类还需扣除转入损益部分）。逻辑一致。
