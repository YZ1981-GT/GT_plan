## 3. 利润分配结转公式链验证（核心！）

### xlsx证据（M6-2 完整公式链）

**分配结转主线**（以E列=审定数为例）:
```
E10 = B10+C10+D10     → 审定上年末 = 未审 + AJE + RJE
E11 = B11+C11+D11     → 审定会计政策变更
E12 = B12+C12+D12     → 审定前期差错更正
E13 = E10+E11+E12     → 审定年初 = 上年末 + 变更 + 更正
E14 = B14+C14+D14     → 审定盈余公积补亏（加项）
E15 = B15+C15+D15     → 审定本期净利润（加项，核心输入！）
E16 = SUM(E17:E21)    → 审定利润分配合计（减项！）
  E17 = B17+C17+D17   →   提取法定盈余公积 → M5
  E18 = B18+C18+D18   →   提取任意盈余公积 → M5
  E19 = B19+C19+D19   →   应付现金股利 → M1
  E20 = B20+C20+D20   →   转作股本的股利
  E21 = B21+C21+D21   →   其他
E22 = SUM(E23:E24)    → 所有者权益内部结转
E25 = E13+E14+E15-E16 → **年末=年初+补亏+净利润-分配**
```

**简化核心公式**: `期末未分配利润 = 期初 + 本年净利润 - 利润分配合计`
**展开**: `期末 = 期初 + 净利润 - (法定盈余公积 + 任意盈余公积 + 现金股利 + 转股股利 + 其他)`

### md证据
M6-2明细表行标签完全对应:
- "二、本年年初余额" = 计算起点
- "四、本期净利润" = 核心输入(利润表结转)
- "五、利润分配" = 核心减项(驱动M5+M1)
- "七、本年年末余额" = 最终结果

### 交叉验证

| 验证点 | xlsx公式 | md语义 | 一致性 |
|--------|----------|--------|--------|
| 结转起点 | E13=E10+E11+E12 | 年初=上年末+变更+更正 | ✅ |
| 净利润加入 | E15=B15+C15+D15 | 四、本期净利润 | ✅ |
| 分配合计 | E16=SUM(E17:E21) | 五、利润分配(5项合计) | ✅ |
| 法定计提 | E17(明细行) | 1、提取法定盈余公积 | ✅ |
| 任意计提 | E18(明细行) | 2、提取任意盈余公积 | ✅ |
| 现金股利 | E19(明细行) | 3、应付现金股利 | ✅ |
| 转股股利 | E20(明细行) | 4、转作股本的股利 | ✅ |
| 年末公式 | E25=E13+E14+E15-E16 | 年末=年初+补亏+净利润-分配 | ✅ |

**结论**: ✅ **利润分配结转公式链完全一致**。设计文档ADR-2正确。核心公式链:
- `calcRetainedEnd(begin, netProfit, surplusAccrual, dividend) = begin + netProfit - surplusAccrual - dividend`
- 对应xlsx: `E25 = E13 + E14 + E15 - E16`（其中E14补亏通常为0，E16包含surplusAccrual+dividend+其他）
- **注意**: xlsx的E25实际包含`+E14(补亏)`，设计引擎中应考虑补亏项。简化版`calcRetainedEnd`够用于PBT，完整版需包含补亏。
