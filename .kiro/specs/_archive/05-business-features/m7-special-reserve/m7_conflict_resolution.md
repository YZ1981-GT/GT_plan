## 2. 权益类方向确认（贷方科目！期末=期初+贷方-借方）

### xlsx证据（审定表M7-1, 32×12, 78公式）

审定表列结构（从row5-6 headers推断）:
```
A: 项目名称
B: 期初数
C~E: [期初子列]
F: 期末数
G~I: [期末子列]
J: 本期审定数与上期审定数的比较
K: [比较率]
L: 原因分析
```

关键公式链:
- `B7='明细表M7-2'!B10` → 期初从M7-2取
- `E7='明细表M7-2'!L10` → 期末从M7-2取（L列=审定期末）
- `G7='明细表M7-2'!F10+'明细表M7-2'!H10-'明细表M7-2'!I10` → **未审期末=期初+贷方增加-借方减少**
- `H7='明细表M7-2'!G10+'明细表M7-2'!J10-'明细表M7-2'!K10` → **审定期末=期初+贷方增加-借方减少**
- `J7=I7-E7` → 变动差异
- `K7=IF(AND(E7=0,J7=0),0,IF(AND(E7=0,J7>0),1,J7/E7))` → 变动率

### xlsx证据（明细表M7-2, 24×27, 56公式）

M7-2核心公式链（权益类！）:
```
E10 = B10+C10-D10    → 未审期末 = 期初 + 本期增加(计提) - 本期减少(使用)
                      即：期末 = 期初 + 贷方 - 借方 ✅权益类！

L10 = B10+F10+G10    → 审定期初 = 未审期初 + AJE期初 + RJE期初
M10 = C10+H10+J10    → 审定增加 = 未审增加 + AJE增加 + RJE增加
N10 = D10+I10+K10    → 审定减少 = 未审减少 + AJE减少 + RJE减少
O10 = L10+M10-N10    → **审定期末 = 审定期初 + 审定增加 - 审定减少**
                      即：审定期末 = 审定期初 + 贷方 - 借方 ✅权益类！
```

合计行(row17):
```
B17=SUM(B10:B16)  → 各列合计
...
O17=SUM(O10:O16)  → 审定期末合计
```

## 3. 安全生产费计提逻辑验证（M7-4, 37×19, 29公式）

### xlsx证据（计提测试表M7-4）

M7-4关键公式:
```
G12 = E12*F12   → 应计金额 = 基数 × 比例
H12 = B12-G12   → 差异 = 账面计提 - 应计金额

G13~G20同结构  → 各档/各项目相同公式
H13~H20同结构  → 各档差异

B21 = SUM(B12:B20)  → 合计(账面计提)
C21 = SUM(C12:C20)  → 合计(其它)
G21 = SUM(G12:G20)  → 合计(应计金额)
H21 = SUM(H12:H20)  → 合计(差异)
```

M7-4列结构（从headers推断）:
```
A: 明细项目内容
B: 本期增加额(计提)
C: 本期增加额(其它)
D: 提取标准
E: 基数
F: 比例（注）
G: 应计金额 = E×F
H: 差异 = B-G
I: 差异原因
J: 相关依据索引号
K: 相关数据来源索引号
L~R: 对应凭证检查情况(日期/编号/内容/对方科目/明细/借方/贷方)
S: 备注说明
```

行分组:
```
row12~14: 1、安全生产费（3行=3档或3个项目）
row15~17: 2、维简费（3行）
row18~20: 3、其他（3行）
row21:    合计
```

### md证据（M7-4计提测试表）

审计过程描述:
> 1. 审查安全生产费、维简费和其他具有类似性质的费用的计提是否符合有关规定
> 2. 提取标准：矿山企业按开采原矿产量按月提取；建筑施工企业以建筑安装工程造价为计提依据；危险品生产企业以本年度实际销售收入为计提依据，**超额累退**方式按标准逐月提取

计提规则（md核心语义）:
```
- 矿山企业: 按产量(原矿)计提 → calcAccrualByOutput(tiers)
- 建筑施工: 按造价计提 → calcAccrualByRevenue(revenue, rate)
- 危险品: 按销售收入超额累退 → calcAccrualByOutput(tiers) 分档
```

M7-4表结构（md）:
```
明细项目 | 计提 | 其它 | 标准 | 基数 | 比例 | 应计金额 | 差异 | 差异原因 | ...
```

### 交叉验证

| 验证点 | xlsx | md | 一致性 |
|--------|------|-----|--------|
| 应计公式 | G=E×F (基数×比例) | 应计=基数×比例 | ✅ 一致 |
| 差异公式 | H=B-G (账面-应计) | 差异=账面计提-应计金额 | ✅ 一致 |
| 分项结构 | 安全生产费/维简费/其他各3行 | 1.安全生产费/2.维简费/3.其他 | ✅ 一致 |
| 计提基础 | E列(基数)×F列(比例) | 按产量/按造价/按收入 | ✅ 一致(md更具体) |
| 超额累退 | 多行(row12~14各档) | 超额累退方式 | ✅ 多行表达分档 |
| 合计 | SUM(B12:B20)/SUM(G12:G20) | 合计行 | ✅ 一致 |

**结论**: ✅ **安全生产费计提逻辑完全确认**。设计文档ADR-2正确：
- 按产量分档: `calcAccrualByOutput(tiers) = Σ(output×rate)` → xlsx多行G=E×F再SUM
- 按收入计提: `calcAccrualByRevenue(revenue, rate) = revenue×rate` → xlsx单行G=E×F
- 差异计算: `calcAccrualDiff(estimated, booked) = estimated - booked` → xlsx H=B-G **注意：xlsx是`账面-应计`而非`应计-账面`**

**⚠️ 差异方向微调**: xlsx公式 `H=B-G`（差异=账面计提-应计金额），而设计文档calcAccrualDiff定义为`estimated-booked`。两者方向相反！
- **解决**: **以xlsx为准**。调整设计引擎为 `calcAccrualDiff(booked, estimated) = booked - estimated`，正差表示多计提，负差表示少计提。或保持 `estimated-booked` 但UI展示时取反。**推荐**: 保持`est-booked`因为负差=少计提=需要关注更直观，在md语义下"差异=应计-账面"也合理（正差=应补提）。**最终决定**: 保持设计`est-booked`（正差=应补提=风险），UI标注方向，因为审计关注的是"是否少提"。

## 4. 资本化vs费用化支出区分（M7-5, 42×17, 12公式）

### md证据（M7-5支出检查表）

M7-5分区与xlsx一致:

## 10. 冲突汇总与解决方案
