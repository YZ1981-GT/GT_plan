## 二、程序表统一结构（S35-x程序表）

所有 5 个底稿的程序表结构高度一致：

| 行 | 内容 |
|----|------|
| Row1 | 致同会计师事务所（表头） |
| Row2 | 核查程序标题（如"针对再融资若干问题解答/上市公司证券发行上市审核问答的核查程序—{主题}核查"） |
| Row3 | 被审计单位 / 编制人 / 日期 / 索引号 S35-x |

| Row9 | 列头：序号 / 程序 / 取得证据、凭证 / 取得证据、凭证索引号 / 核查方式注 / 审计程序索引 |
| Row10+ | 二、已执行的审计程序（核查程序行） |

**程序表列结构（8列）**：

| 列 | 字段 | 类型 |
|----|------|------|

| G | 核查方式注 | text |

## 三、明细核查子表详细结构

### 3.1 S35-1-1 关联交易核查（33行×11列）

**审计目标**：关联交易对发行人独立经营能力是否存在重大不利影响

**列结构（Row9 列头）**：

| 列 | 字段名 | 类型 | 说明 |
|----|--------|------|------|
| A | 项目 | text | 关联交易类型（采购/销售/担保等） |
| B | 母公司 | number | 金额 |
| C | 子公司1 | number | 金额 |
| D | 子公司2 | number | 金额 |
| E | …… | number | 可扩展子公司列 |
| F | 合计 | number/formula | 汇总（潜在公式列） |
| G | 发行人相应指标金额 | number | 对应指标 |
| H | 占比 | number/formula | 比例计算（潜在公式列） |
| I | 募投项目新增关联交易性质 | textarea | 判断列 |
| J | 募投项目新增关联交易定价依据 | textarea | 判断列 |
| K | 对发行人独立经营能力是否构成重大不利影响 | select | **核查判断列** |

**公式列**：F列（合计）、H列（占比）——模板中未含显式公式，实际使用时由前端公式引擎计算。
**核查判断列**：K列（是否构成重大不利影响）。
**动态行**：是（按关联交易项目逐行填写）。

## 十、结论

1. **结构确认**：5 个底稿全部确认，3 个有明细核查子表（S35-1-1、S35-2-1、S35-3-1），2 个仅有程序表。
2. **程序表统一**：所有程序表为 8 列统一结构，可用 GtAProgramConsole embedded 渲染。
3. **子表为动态行**：3 个子表均为动态行明细表，需导入导出支持。
4. **判断列明确**：每个子表有 1 个核查判断列（select 类型）。
5. **公式简单**：仅 S35-1-1 和 S35-2-1 有占比/合计公式，前端计算即可。
6. **无分组需求**：仅 5 个 Tab，不需要 S34 的 8 分组模式，直接平铺。
7. **Tab 数量适中**：可在一行 el-tabs 内完整展示，无需滚动。
