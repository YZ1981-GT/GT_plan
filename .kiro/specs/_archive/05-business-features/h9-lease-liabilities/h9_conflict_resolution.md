## 二、冲突清单与解决

### Conflict-1: H9-4 是"调整分录汇总"而非"摊销表"

| 项 | spec 预期 | xlsx 实际 | md 实际 |
|----|-----------|-----------|---------|
| H9-4 内容 | 摊销表（Amortization） | **调整分录汇总**（10列标准调整分录格式） | **调整分录汇总**（标准AJE/RJE格式） |

**解决**：spec Requirement 4 中的"摊销表H9-4"需要调整。实际物理sheet `调整分录汇总H9-4` 仅做AJE。  
→ **摊销表功能为前端计算视图**（由 `useH9AmortizationEngine` 生成），不对应独立物理sheet。  
→ 编码映射：`H9-4` = 调整分录汇总 ✅

### Conflict-2: 不存在独立 H9-5/H9-6 sheet

| 项 | spec Requirement 5 | xlsx 实际 |
|----|-------------------|-----------|
| H9-5 调整分录 | 独立sheet | ❌ 不存在。H9-4 已是调整分录汇总 |
| H9-6 关联交易 | 独立sheet | ❌ 不存在。关联方信息嵌入 H9-2 列 S（是否关联方）和 H9-3 列 T（是否是关联方） |

**解决**：  
→ Requirement 5 中 H9-5 功能合并到 H9-4（调整分录汇总）  
→ 关联方检查不单独成sheet，在 H9-2/H9-3 的关联方列中呈现（筛选+高亮模式）  
→ 取消 H9-6 作为独立组件，改为 H9-2 的关联方子视图

### Conflict-3: H9-2 期末余额公式方向

| 项 | spec 预期 | xlsx 公式 (E9) | CAS21 |
|----|-----------|---------------|-------|
| 负债期末 | 期初+贷方-借方 | **`=B9-C9+D9`**（期初-借方+贷方） | 负债贷方，期末=期初-偿还+新增 |

**解决**：公式语义一致，只是列顺序不同。xlsx 中 B=期初, C=借方发生(偿还), D=贷方发生(新增)。  
→ `E=B-C+D` 即 `期末=期初-借方+贷方` = `期初+贷方-借方`（等价！列名以xlsx为准）  
→ H9-2 列映射：A=出租方名称, B=期初余额, C=借方发生, D=贷方发生, E=期末余额 ✅  
→ **CAS21合规** ✅

### Conflict-4: H9-3 出租方名称联动公式来源

| 项 | xlsx 公式 (A9) | md 描述 |
|----|---------------|---------|
| H9-3 出租方名称 | `='租赁负债明细表H9-2'!A9` | "出租方名称" |

**解决**：  
→ H9-3 第一列通过跨sheet公式引用 H9-2 的出租方名称，保证一一对应  
→ 联动方向：H9-2 → H9-3（md为准）  
→ 实现：H9-3 组件 watch H9-2 出租方列表，自动同步

### Conflict-5: H9-3 期末余额公式方向（未确认融资费用=借方/备抵）

| 项 | xlsx 公式 | spec预期 |
|----|-----------|----------|
| H9-3 E9 | `=B9+C9-D9`（期初+借方-贷方） | 未确认融资费用：借方/负债备抵 |
| H9-3 M9(审定期末) | `=J9+K9-L9`（审定期初+借方-贷方） | 同上 |

**解决**：未确认融资费用是负债备抵科目，属于**借方余额**。  
→ 期末=期初+借方-贷方（因为摊销确认时贷记未确认融资费用=减少）  
→ xlsx 公式与 CAS21 方向一致 ✅  
→ Requirement 2.5 已正确描述

## 五、实际利率法/现值公式验证

### 5.1 现值公式（初始确认）

```
租赁负债 = Σ(PMTₙ / (1+r)^n)  n=1..N
```

来源验证：H8-6（按年）示例数据：
- 年租金=50,000，利率=5%，10期
- 计算：50000/(1.05)^1 + ... + 50000/(1.05)^9 = 355,391.08
- xlsx H8-6 合计列 = 355,391.08 ✅

### 5.2 实际利率法摊销

```
利息费用ₙ = 期初余额ₙ × 实际利率
本金偿还ₙ = 租赁付款额 - 利息费用ₙ  
期末余额ₙ = 期初余额ₙ - 本金偿还ₙ
```

来源验证：H8-6 第1期：
- 期初=355,391.08, 利率=5%
- 利息=355,391.08×0.05=17,769.55
- 本金=0（第1期付款在租赁期开始，第2年才开始付款）
- 期末=355,391.08+17,769.55=373,160.64 ✅（首期不付款，利息计入）

### 5.3 增量借款利率(IBR)

```
IBR = 市场基准利率 + 信用利差 + 期限调整
```

xlsx中没有独立IBR计算sheet，折现率作为输入参数（用户手工确定后填入H8-6）。  
→ 前端提供 `useH9IBREngine` 辅助计算（非必填，审计判断优先）

## 七、关键公式汇总（以xlsx为准）

### H9-1 审定表

```
审定数 = 未审数 + AJE      → D=B+C (每行)
报表数 = 审定数 - 重分类   → F=D-E (每行)
变动额 = 期末报表 - 期初报表 → L=K-F
变动率 = IF(F=0∧L=0,0, IF(F=0∧L>0,1, L/F))
净值 = 原值 - 未确认融资费用  → row18=row8-row13
```

### H9-2 租赁负债明细表（22列/负债贷方）

```
未审期末 = 期初 - 借方 + 贷方   → E=B-C+D  ⚠️ 负债方向
审定期初 = 期初 + 期初调整       → I=B+F
审定借方 = 未审借 + 调整借       → J=C+G
审定贷方 = 未审贷 + 调整贷       → K=D+H
审定期末 = 审定初 - 审定借 + 审定贷 → L=I-J+K
报表数 = 审定期末 - 重分类       → N=L-M
合计行 = SUM(各行)
```

### H9-3 未确认融资费用明细表（21列/借方备抵）

```
出租方名称 = H9-2同行引用        → A='H9-2'!A
未审期末 = 期初 + 借方 - 贷方    → E=B+C-D  ⚠️ 借方方向
审定期初 = 期初                   → J=B
审定借方 = 未审借+AJE借+RJE借     → K=C+F+H
审定贷方 = 未审贷+AJE贷+RJE贷     → L=D+G+I
审定期末 = 审定初+审定借-审定贷    → M=J+K-L
最终审定 = 审定期末 - 一年内到期   → O=M-N
合计行 = SUM(各行)
```
