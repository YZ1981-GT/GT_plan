## 2. 逐项验证详情

### 2.1 负债类贷方方向

**md定义**：
- L2A程序表认定D明确写"应付利息以恰当的金额包括在财务报表中，与之相关的计价或分摊调整已恰当记录"
- L2为负债类科目（应付利息），贷方增加、借方减少

**xlsx验证**：
- 明细表L2-2核心公式 `K12 = H12 + I12 - J12`
  - K = 期末余额
  - H = 期初余额
  - I = 本期应付利息（贷方增加）
  - J = 本期已付利息（借方减少）
- 等价于：**期末 = 期初 + 贷方 - 借方** ✅

**审定后公式**：
- `U12 = R12 + S12 - T12`
  - R = 审定期初 = H + L(账项调整期初) + M(重分类调整期初)
  - S = 审定贷方 = I + N(账项调整贷方) + P(重分类调整贷方)
  - T = 审定借方 = J + O(账项调整借方) + Q(重分类调整借方)
- 维持负债类贷方方向 ✅

### 2.2 计提核对流程（L1/L3利息 → L2应付利息）

**md定义**：
- L2A程序表第4步："与借款等相关科目核对应付利息金额是否正确"（认定：准确性、计价和分摊）
- L2A程序表第5步："检查与应付利息有关的记账凭证和相应的支持性证据"，底稿索引号明确引用 `L2-4/L1-5/L3-5`
- L2-2明细表审计目标第3条："应付利息以恰当的金额包括在财务报表中，与之相关的计价或分摊调整已恰当记录"
- L2-2审计说明提示："利息测算过程详见"（指向L1-5/L3-5）

**xlsx验证**：
- L2-1审定表按来源分类（SUMIF from L2-2!A列）：
  - "分期付息到期还本的长期借款利息" → 对应L3长期借款利息测算L3-5
  - "短期借款应付利息" → 对应L1短期借款利息测算L1-5
  - "企业债券利息" → 对应L4应付债券后续计量
  - "划分为金融负债的优先股\永续债利息" → 对应L4权益负债划分
  - "其他"
- L2-4检查表凭证检查核对内容5项，与md描述吻合 ✅

**计提核对业务流**：
```
L1短期借款 → L1-5利息测算表 ──┐
                              ├→ L2-2明细表（按来源分类汇总）→ L2-1审定表
L3长期借款 → L3-5利息测算表 ──┘        ↓
                                    L2-4检查表（凭证核对）
```

### 2.3 L1-L3-L8联动方向

**md定义**：
- L1→L2：短期借款利息测算(L1-5)产出 → 计入L2应付利息明细表"短期借款应付利息"行
- L3→L2：长期借款利息测算(L3-5)产出 → 计入L2应付利息明细表"分期付息到期还本的长期借款利息"行
- L2→L8：L2本期计提利息 → L8财务费用-利息支出（md中L8底稿明确包含"非金融机构利息支出测算表L8-4"）
- L2A列报认定引用 A1-1/A1-15/A1-16（报表/附注披露）

**xlsx验证**：
- L2-1 用SUMIF按A列分类汇总，实现了L1/L3来源的自动汇总 ✅
- L2-2 列I（本期应付利息/贷方）即为L1-5/L3-5测算值的填入列 ✅
- 附注sheet(国企/上市)均从L2-2取数(U列=审定期末, R列=审定期初)用于披露 ✅
- L2→L8联动通过"本期应付利息"列(I列/S列)汇入财务费用 ✅

### 2.4 审定数公式链

**md定义**：
- 审定表结构：项目 | 期初(未审/账项/重分类/审定) | 期末(同) | 变动分析

**xlsx验证**：
- L2-1 `E7 = B7 + C7 + D7`（审定数 = 未审数 + 账项调整 + 重分类调整）✅
- L2-1 `I7 = F7 + G7 + H7`（期末审定 = 期末未审 + 期末账项 + 期末重分类）✅
- 变动分析：`J7 = F7 - B7`（未审变动额）, `L7 = I7 - E7`（审定变动额）✅
- 变动率：`K7 = IF(AND(B7=0,J7=0),0,...)`（零值保护）✅

## 3. 差异记录（非冲突性）

### 3.1 Sheet命名/数量微差异

| 维度 | md底稿模板库 | xlsx实际结构 |
|------|-------------|-------------|
| 底稿数量 | "7个"（分类索引） | **8个sheet**（含2个附注sheet） |
| 底稿清单 | L2A, L2-1, L2-2, L2-3, L2-4 (5个内容底稿) | + 底稿目录 + 附注(国企) + 附注(上市) = 8 sheet |
| L2-3命名 | "调整分录汇总" | "应付利息调整分录汇总L2-3" |
| 附注sheet | md目录未单独列出（但在底稿目录"附注披露信息"行有提及） | xlsx有2个独立sheet |

**处理方式**：以xlsx为准。md在顶层目录"附注披露信息（国企）"有注释行"无需打印"，表明附注sheet存在但非独立索引号。不影响开发。

### 3.2 md编号体系说明

md文件顶部的完整目录索引中L2编号为"应付利息"（而非"长期借款"等），这与底稿模板库封面索引不同（封面写"L2-长期借款"是**文档整体目录顺序的误差**，实际章节标题正确为"L2 应付利息"）。

> 注：md文件封面索引里L2写的是"长期借款"，但章节实际内容标题为"L2 应付利息"。这是md生成时的已知问题，**以章节实际内容为准**。

## 5. 开发实施建议

基于交叉验证确认，以下为Phase 1~7的关键约束：

1. **公式引擎**：负债类 `calcLiabilityEndBalance(begin, credit, debit) = begin + credit - debit`
2. **审定数公式**：`calcAuditedAmount(unadjusted, aje, rje) = unadjusted + aje + rje`
3. **分类汇总**：L2-1用SUMIF按A列"类别"字段汇总，前端composable需实现`aggregateBySource`
4. **计提核对**：接收L1/L3利息测算结果，对比账面计提额，产出差异→L2-4检查
5. **附注取数**：国企/上市分开，分别从L2-2的U列(审定期末)和R列(审定期初)取数
6. **L8联动**：本期计提利息(I列汇总)作为L8财务费用-利息支出的输入
