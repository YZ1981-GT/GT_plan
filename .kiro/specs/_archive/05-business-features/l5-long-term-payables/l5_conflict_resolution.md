## 2. 未确认融资费用摊销逻辑（实际利率法）✅ 一致

### xlsx实证

**L5-5 未确认融资费用测算表**（26×17，57公式）：

列头结构（row9-11）：
| 列 | 含义 |
|----|------|
| A | 年份（期数） |
| B | 各期付款金额 |
| C | 实际利率 |
| D | 长期应付款现值 |
| E | 尚未确认的未确认融资费用 |
| F | **确认的融资费用**（每期摊销额） |
| G | 应付本金减少额 |
| H | 应付本金余额 |
| I | 年末账面余额（被审计单位） |
| J | 差异 |
| K | 差异原因 |

核心公式：
```
F13 = H12 * C12    → 确认的融资费用 = 期初应付本金余额 × 实际利率
G13 = B13 - F13    → 应付本金减少额 = 各期付款金额 - 确认的融资费用
H13 = H12 - G13    → 期末应付本金余额 = 期初本金余额 - 应付本金减少额
J12 = H12 - I12    → 差异 = 测算余额 - 账面余额
```

滚动规律（row12→row13→...）：
- `F{n} = H{n-1} * C{n-1}` — **每期摊销=期初摊余成本×实际利率**
- `G{n} = B{n} - F{n}` — 本金减少=付款-利息
- `H{n} = H{n-1} - G{n}` — 期末余额=期初-本金减少

### md验证

md L5-5 测算表列头：
> （1）年份 | （2）各期付款金额 | （6）实际利率 | （3）确认的融资费用=期初(5)×(6) | （4）应付本金减少额=(2)-(3) | 期末(5)=期初(5)-(4)

md L5A程序表第6步明确：
> "与被审计单位讨论确定实际利率或经信用调整的实际利率确定依据是否充分，复核实际利率或经信用调整的实际利率是否与前期一致；重新计算占有期间的利息"

### 结论

- ✅ **实际利率法公式完全一致**：每期摊销 = 期初摊余成本 × 实际利率
- ✅ xlsx用列H存储"应付本金余额"（即摊余成本），md用编号(5)标记
- ✅ 本金减少额=(各期付款-确认融资费用)，两源完全对齐
- ⚠️ **列编号差异（非冲突）**：md用(1)~(6)序号，xlsx用A~K列。映射关系：md(1)=xlsx.A, md(2)=xlsx.B, md(3)=xlsx.F, md(4)=xlsx.G, md(5)=xlsx.H, md(6)=xlsx.C

## 3. 未确认融资费用明细（备抵类方向）✅ 一致

### xlsx实证

**L5-3 未确认融资费用明细表**（31×30，167公式）：

列头 row9-10：
| 列 | 含义 |
|----|------|
| A | 债权人名称 |
| B | 期初余额 |
| C | **借方发生** |
| D | **贷方发生** |
| E | 期末余额 |

核心公式：
```
E12 = B12 - C12 + D12  → 期末余额 = 期初余额 - 借方发生 + 贷方发生
```

**注意**：未确认融资费用是**借方/负债备抵类**账户。正常摊销时，借方减少（摊销计入费用），贷方增加（新增融资费用初始确认）。

但xlsx公式 `E = B - C + D` 写法与L5-2完全相同（期初-借+贷）。这是因为在**总账层面**，未确认融资费用虽然是备抵类，但余额方向仍是**借方余额**科目（期末=期初+借方-贷方），而xlsx表格从"**发生额角度**"来看：
- 实际意义：`期末余额 = 期初余额 + 贷方发生（新增） - 借方发生（摊销减少）`

### md验证

md L5-3明确：
> 债权人名称 | 期初余额 | 借方发生 | 贷方发生 | 期末余额

### 结论 — ⚠️ 需特别注意方向

- ✅ 公式语法一致：`E = B - C + D`
- ⚠️ **业务方向解读**：未确认融资费用是借方备抵类。xlsx的公式 `E=B-C+D` 从总账角度看，是"期末=期初+贷方新增-借方摊销"的反写。
- 🔴 **design.md中的 calcContraLiabilityEndBalance(begin, debit, credit) = begin + debit - credit** 与xlsx不一致！
  - xlsx实际公式：`E = B - C + D`（期末=期初-借方+贷方，即期末=期初+贷方-借方）
  - design.md定义：`期末=期初+借方-贷方`
  
### 🔴 冲突解决

**xlsx公式优先**。未确认融资费用明细表L5-3的xlsx公式明确是 `E = B - C + D`。

这里的**关键洞察**：L5-3的"借方发生"列含义是"本期摊销（减少）"，"贷方发生"含义是"本期新增"。所以公式 `期末=期初-摊销+新增` 在业务上完全正确。

但从**科目方向铁律**角度：未确认融资费用是**资产类借方余额**科目（虽然是负债备抵，但余额在借方），应该是 `期末=期初+借-贷`。xlsx的公式 `E=B-C+D` 等价于 `期末=期初+D-C`（期初+贷-借），看似矛盾。

**最终裁定**：xlsx L5-3的列头定义为 `C=借方发生 D=贷方发生`，公式 `E=B-C+D`。这与L5-2的公式完全相同。在L5明细表体系中，**统一使用负债类公式**（期末=期初+贷方-借方）处理所有明细——即使是未确认融资费用备抵科目。原因是L5-3是从**长期应付款的备抵视角**编制（负债的减项），而非从独立借方科目视角。

**前端实现应遵循xlsx公式**：`calcEndBalance(begin, debit, credit) = begin - debit + credit` 统一用于L5-2和L5-3。Design.md中的 `calcContraLiabilityEndBalance` 需修正为与xlsx一致的 `begin - debit + credit`（即 `begin + credit - debit`，负债方向）。

## 8. 对design.md的修正建议

### 8.1 calcContraLiabilityEndBalance 修正

**当前**（design.md）：
```typescript
// 备抵类期末（未确认融资费用，借方）：期末=期初+借方-贷方
export function calcContraLiabilityEndBalance(begin: number, debit: number, credit: number): number
```

**修正为**（以xlsx L5-3公式为准）：
```typescript
// L5-3 未确认融资费用明细：期末=期初-借方+贷方（与L5-2统一负债方向）
// 注：xlsx公式 E=B-C+D，C=借方发生（摊销减少），D=贷方发生（新增）
export function calcUnrecognizedEndBalance(begin: number, debitAmort: number, creditNew: number): number {
  return begin - debitAmort + creditNew  // 等价于 begin + credit - debit
}
```

**原因**：L5-3在xlsx中与L5-2使用完全相同的公式结构，统一为负债方向。这在审计实务中是合理的——未确认融资费用虽然余额在借方，但在L5底稿体系中作为负债的减项统一处理。

### 8.2 AmortizationEngine 列映射明确

design.md `AmortRow` 接口与xlsx L5-5精确映射：

| AmortRow字段 | xlsx列 | md编号 | 含义 |
|--------------|--------|--------|------|
| period | A | (1) | 年份/期数 |
| payment | B | (2) | 各期付款金额 |
| eir | C | (6) | 实际利率 |
| amortization | F | (3) | 确认的融资费用=期初H×C |
| principalReduction | G | (4) | 应付本金减少额=B-F |
| endCost | H | (5) | 应付本金余额=期初H-G |

design.md当前 `AmortRow` 字段名需调整：
- `beginCost` → 对应 `H{n-1}`（上期期末=本期期初）
- `repayment` → 应为 `payment`（各期付款金额B列，非"偿还"）
- 新增：`accountBalance`（I列，被审计单位账面）和 `diff`（J列，差异=H-I）

## 9. 前端实现核心公式清单（以xlsx为准）
