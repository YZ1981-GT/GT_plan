## 四、跨Sheet联动关系验证

### 4.1 H2-1 审定表 ←→ H2-2 明细表 ✅ 一致

**xlsx实际公式**（从h2_structure_summary.json）：
- `A8 = '明细表H2-2'!A13` （工程项目名称从明细表引入）
- `B8 = '明细表H2-2'!J13` （期初未审数）
- `C8 = '明细表H2-2'!S13` （期初账项调整）
- `D8 = B8+C8` （期初审定数）
- `E8 = '明细表H2-2'!Q13` （期末未审数）
- `F8 = '明细表H2-2'!S13+'明细表H2-2'!U13-'明细表H2-2'!W13-'明细表H2-2'!X13` （期末账项调整）
- `G8 = E8+F8` （期末审定数）
- `H8 = E8-B8` （变动额）
- `I8 = IF(AND(B8=0,H8=0),0,IF(AND(B8=0,H8>0),1,H8/B8))` （变动率）

**md描述**：H2-1从H2-2自动取数，展示期初/期末未审数、审定数、变动分析。

**联动方向**（以md为准）：**H2-2 → H2-1**（明细表驱动审定表）

### 4.2 H2-5 转固检查 → H1 固定资产 ✅ 联动确认

**md中描述**：
- 程序7：了解在建工程转固定资产政策，检查是否存在推迟转固时间（底稿H2-5）
- 程序10：结合固定资产审计，考虑转销额是否正确（底稿H2-9）

**联动方向**（md定义）：**H2-5 → H1-1**（转固金额应与H1新增固定资产一致）

### 4.3 利息资本化 H2-10/H2-11 → H2-1/H2-2 ✅ 联动确认

**xlsx中H2-10公式逻辑**：
- 加权资本化率 = Σ(一般借款利息费用) ÷ Σ(一般借款本金加权平均数)
- 累计支出加权平均数 = T-1期加权 + (工程支出合计-借款费用-本年减少+预付工程款)/2
- 资本化金额 = 加权平均支出 × 资本化率（月）

**md中描述**：
- 一般借款资本化率 = 一般借款加权平均利率 = 实际利息÷本金加权平均
- 有专门借款：专门借款利息-闲置收益+一般借款补充资本化

**联动方向**（md定义）：**H2-10/H2-11 → H2-2的利息列**（资本化金额回填明细表利息列）

### 4.4 减值 H2-15/H2-16 ← H2-1 ✅ 联动确认

**md中描述**：
- 程序14：对存在减值迹象的在建工程，检查减值测试参数
- H2-15从H2-1取在建工程账面价值，与可收回金额(H2-16)比较

**联动方向**：**H2-1 → H2-15/H2-16**（账面价值传入减值测算）

| 本期未审数与上期未审数的比较.变动额/变动率 | — | spec未提及同期比较列 | 不冲突，spec Requirements 2.2简化了 |

### 5.2 ⚠️ 冲突 #1：H2-1 审定表 "账项调整" vs "AJE+RJE"

**xlsx实际**：H2-1审定表只有一列"账项调整"（col C/F），公式`D8=B8+C8`即`审定=未审+调整`

**spec Requirements 2.2**：显示列为"未审数 | AJE | RJE | 审定数"（分为两列）

**冲突原因**：xlsx源模板H2-1的审定表将调整合并为一列（与H1-1结构一致），但requirements.md设计时参考了其他更详细的底稿格式拆为AJE+RJE两列。

**决议**（列名以xlsx为准）：
- **前端实现应沿用xlsx的"期初数{未审数|账项调整|审定数} + 期末数{未审数|账项调整|审定数}"结构**
- "账项调整"内部可在表单层面拆分录入(AJE/RJE分别输入后合计)，但列展示保持与xlsx一致的单列"账项调整"
- 公式不变：审定数 = 未审数 + 账项调整

### 5.3 ⚠️ 冲突 #2：H2-1 审定表列组与spec Requirements 2描述的差异

**xlsx实际列组**（12列）：
```
项目 | 期初数{未审数, 账项调整, 审定数} | 期末数{未审数, 账项调整, 审定数} | 本期未审与上期未审比较{变动额, 变动率} | 本期审定与上期审定比较{变动额, 变动率}
```

**spec Requirements 2.2描述**：
```
项目名称 | 期初余额 | 本期增加 | 本期减少 | 本期转固 | 期末余额 | 未审数 | AJE | RJE | 审定数 | 已计提减值 | 备注
```

**分析**：spec Requirements 2.2错误地将"明细表H2-2的增减结构"混入了审定表H2-1的列定义。xlsx中H2-1是审定表格式（期初/期末×未审/调整/审定+同期比较），不含"本期增加/减少/转固"列——那些是明细表H2-2的列。

**决议**（列名以xlsx为准）：
- H2-1审定表前端列结构应严格按xlsx实际12列布局
- "本期增加/减少/转固"列属于H2-2明细表，不出现在H2-1
- Requirements 2.4的"三角勾稽"校验应在H2-2上实施（明细表有期初/增加/减少/转固/期末列），而非H2-1
- Requirements 2.6的三角勾稽红色高亮在H2-2上实现

### 5.4 H2-2 明细表列名 ✅ 一致

xlsx实际：50列，3段打印区（A~R / S~AH / AI~AX），包含：
- 工程名称(A) / 预算(B) / 开工日期(C) / 预计竣工(D) / 实际竣工(E) / 进度(F) / 累计投入(G) / 资金来源(H) / 资本化率(I)
- 期初余额(J) / 本期增加各分项(K~P) / 期末未审(Q) / 期初审定(R)
- 调整(S~V) / 减少(W) / 转固(X) / 期末审定等
- 减值准备 / 净值 / 附注披露金额等

md描述的拆分与xlsx结构一致（3段打印区≈3区段Tab）。

### 5.5 H2-10 利息资本化列名 ✅ 一致

xlsx列：一般借款本金① / 本期开始计息日 / 本期结束计息日 / 本期计息天数② / 当期天数③ / 一般借款本金加权平均数④=①×②÷③ / 一般借款当期实际发生的利息费用⑤ / 一般借款资本化率⑥=⑤÷④
