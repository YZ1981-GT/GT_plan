## 1. 负债类方向确认 ✅ 一致

### xlsx 公式证据

明细表L7-2核心公式：
```
E12 = B12 + C12 - D12    （期末余额 = 期初余额 + 本期增加(贷方) - 本期减少(借方)）
O12 = L12 + M12 - N12    （审定期末 = 审定期初 + 审定贷方 - 审定借方）
```

审定表L7-1核心公式：
```
E7 = B7 + C7 + D7        （期初审定数 = 未审数 + 账项调整 + 重分类调整）
I7 = F7 + G7 + H7        （期末审定数 = 未审数 + 账项调整 + 重分类调整）
```

### md 业务逻辑

L7-2明细表列头描述：
- 项目 | 期初余额 | 本期增加 | 本期减少 | 期末余额

期末余额 = 期初余额 + 本期增加(贷方) - 本期减少(借方)

### 结论

**两源一致**：负债类账户，期末=期初+贷方-借方。公式方向确认无冲突。

| 位置 | md "使用说明" (line 24-25) | md 实际内容 | xlsx |

**原因**：md文档的"使用说明"段落是早期版本遗留，使用了旧的编号体系（L7=递延所得税负债）。但文档实际内容段落已经更新为2025修订版编号（L7=其他非流动负债, L8=财务费用）。

**解决**：以md实际内容段落和xlsx为准。使用说明段落的编号映射已过时，忽略。
