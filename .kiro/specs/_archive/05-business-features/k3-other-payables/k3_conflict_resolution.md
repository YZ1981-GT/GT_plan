## 7. 发现的差异与冲突解决

### 7.1 审定表结构：双区块（按性质+按账龄）

| 源 | 描述 |
|----|------|
| md模板 | K3-1含"一、按照性质分类"+"二、按照账龄分类"两个独立区块 |
| xlsx | K3-1确认: 行5"一、按照性质分类" + 行15~24"二、按照账龄分类" + 行26后"审计说明+结论" |
| design.md | 仅列"项目\|期初\|本期贷方\|本期借方\|期末\|未审\|AJE\|RJE\|审定数\|变动率\|备注" |

**决议**: K3-1审定表为**双区块结构**（性质分类+账龄分类+审计说明），design.md需按此实现。区别于design.md中单行列示——实际为两段独立表格。

### 7.2 明细表列数

| 源 | 列数 |
|----|------|
| md模板 | 27列（含各类字段） |
| xlsx k3_structure_summary | max_column: 需从明细表sheet确认 |
| design.md | "51行27列19公式" |

**决议**: 27列以xlsx为准，与md模板列结构一致（债权人名称/公司代码/关联方类型/款项性质/期初系列/账龄4档/借方/贷方/期末系列/函证/期后/备注）。

### 7.3 K3-5长期挂账门槛

| 源 | 门槛 |
|----|------|
| md模板 | "账龄1年以上的其他应付款检查表"（标题） |
| design.md | "3年以上→转营业外评估" |
| 实际业务 | 1年以上全部进入检查范围，3年以上为重点关注+转销评估 |

**决议**: 无冲突。K3-5收录1年以上全部项目，前端对3年以上行标橙色+提示"评估是否需转营业外收入"。

### 7.4 K3-7检查表包含反向截止

| 源 | 描述 |
|----|------|
| md模板 | K3-7含两区块: "1.本期发生额检查" + "2.期后付款检查表" |
| xlsx | K3-7确认双区块结构 |
| design.md | "K3-7综合检查（含反向截止）" |

**决议**: K3-7的"期后付款检查表"即为反向截止测试（期后偿付→倒查期末未入账负债），与design.md一致。

## 10. 无冲突声明

经交叉验证，**底稿模板库md的业务语义与xlsx的物理结构完全一致**，无实质性冲突。所有差异均为表述粒度差异（md为语义描述，xlsx为公式实现），已统一决议。

前端开发可按design.md + 本文决议执行，以xlsx物理结构为列/公式权威来源，以md模板库为认定/方向/检查要求语义来源。
