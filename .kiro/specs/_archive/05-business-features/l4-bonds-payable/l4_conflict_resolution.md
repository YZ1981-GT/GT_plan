## 2. 负债类方向确认

### xlsx证据
- **审定表L4-1** 结构：22×19，140个公式
  - 列结构：`项目 | 期初数(未审/账项/重分类/审定/减一年内到期/最终审定) | 期末数(...) | 比较 | 原因分析`
  - 行结构：(一)普通应付债券→成本/利息调整/应计利息/小计 + (二)可转换公司债券→... + 划分为金融负债 + 合计
  - 公式确认：`审定数 = 未审数 + 账项调整 + 重分类调整`

- **明细表L4-2** 结构：35×89，374个公式
  - 三区域并列布局：未审数(A-AH) | 审计调整(AI-BF) | 审定数(BG-CK)
  - 列含：期初余额|本期增加|本期减少|期末余额
  - **确认：期末=期初+贷方(发行增加)-借方(兑付减少) → 负债类贷方科目**

### md证据
- L4A程序表明确：科目=应付债券（负债类）
- L4-1审定表列头含"期初数"、"期末数"，子列含"未审数/账项调整/重分类调整/审定数"
- L4-2明细表列头含"本期增加"(贷方=发行)、"本期减少"(借方=兑付)
- md提示："本科目核算企业为筹集（长期）资金而发行债券的本金和利息"

### 结论
| 项目 | 结论 |
|---|---|
| 科目方向 | **贷方/负债类** ✅ 两源一致 |
| 期末公式(明细) | `期末 = 期初 + 贷方(发行增加) - 借方(兑付减少)` ✅ |
| 审定数公式 | `审定 = 未审 + AJE + RJE` ✅ |
| 最终审定数 | `最终审定 = 审定 - 一年内到期的应付债券` ✅ |
| spec design P2 | `calcLiabilityEndBalance(b, cr, dr) = b + cr - dr` ✅ 正确 |

## 3. 实际利率法后续计量（核心！）

### xlsx证据（权威）
- **L4-6初始计量** (53×27, 84公式)：
  - 含"实际利率"、"实际利率（插值）"行
  - IRR求解：利息现值(测试1/测试2) + 插值法
  - "利息调整初始确认金额" = 发行价格 - 面值 - 发行费用影响
  - "确认的利息费用" = 期初摊余成本 × 实际利率
  - "应付本金减少" = 实付金额 - 利息费用
  - "—利息调整" = 利息费用 - 票面利息

- **L4-7A(到期一次还本付息)** (27×35, 9公式)：
  - 利息资本化滚入：期末摊余成本 = 期初 + 实际利息费用
  - 不支付现金利息直到到期

- **L4-7B(分期付息到期一次还本)** (26×34, 15公式)：
  - 每期支付票面利息：期末摊余成本 = 期初 + 实际利息费用 - 实付利息(面值×票面利率)

### md证据
- L4-6初始计量表明确列出：
  - "计息基数-面值/本金"、"合同利率"、"发行价格"、"发行费用"
  - "利息调整初始确认金额"
  - "实际利率（插值）"、"实际利率（测试1）-较小"、"实际利率（测试2）-较大"
  - "按合同利率计算的应付利息"(多期)、"本金支付期（第？年末）"
  - "期初应付本金余额"、"期末应付本金余额"
  - "确认的利息费用" = 期初 × 实际利率
  
- L4-6提示明确写出：
  > "资产负债表日，应按摊余成本和实际利率计算确定的利息费用，借记'利息支出'.'在建工程'.'财务费用'.'研发支出'等科目，按合同利率计算确定的应付未付利息，贷记本科目，按其差额，借记或贷记'长期借款——利息调整'.'吸收存款——利息调整'等科目。"

- md L4-7仅提供简化列头"序号|债券名称|期初余额|本期变动|期末余额|计量方法|检查结果|备注"
  - **md未展示完整后续计量公式细节**，仅为概述模板

### 结论
| 项目 | 结论 |
|---|---|
| 实际利率法 | **两源一致** ✅ 利息费用=期初摊余成本×实际利率 |
| 分支A（到期一次还本付息） | 期末=期初+利息费用 ✅ xlsx有独立sheet证实 |
| 分支B（分期付息到期一次还本） | 期末=期初+利息费用-实付利息 ✅ xlsx有独立sheet证实 |
| IRR求解 | 插值法（两个测试利率+线性插值） ✅ xlsx L4-6有完整结构 |
| spec EIR_Engine | 设计正确，与xlsx完全对应 |

## 13. 实际利率法完整规则（从xlsx L4-6提取）

```typescript
// 初始计量
const initialCost = issuePrice - transactionCosts;
const premiumDiscount = initialCost - faceValue; // 正=溢价, 负=折价

// IRR求解（插值法）
// 找r使得: Σ(coupon_i / (1+r)^i) + faceValue/(1+r)^n = initialCost
const eir = solveEIR(initialCost, faceValue, couponRate, periods);

// 后续计量 - 分支A（到期一次还本付息）
function calcBulletSchedule(initialCost, faceValue, couponRate, eir, periods) {
  let beginCost = initialCost;
  for (period of 1..periods) {
    interestExpense = beginCost * eir;         // 实际利息费用
    couponInterest = faceValue * couponRate;    // 票面利息（资本化,不支付）
    interestAdjustment = interestExpense - couponInterest; // 利息调整摊销
    endCost = beginCost + interestExpense;     // 期末=期初+利息费用（全部资本化）
    beginCost = endCost;
  }
  // 最后一期调整尾差使 endCost ≈ faceValue + 累计应计利息
}

// 后续计量 - 分支B（分期付息到期一次还本）
function calcInstallmentSchedule(initialCost, faceValue, couponRate, eir, periods) {
  let beginCost = initialCost;
  for (period of 1..periods) {
    interestExpense = beginCost * eir;         // 实际利息费用
    couponPaid = faceValue * couponRate;       // 实付利息（每期支付）
    interestAdjustment = interestExpense - couponPaid; // 利息调整摊销
    endCost = beginCost + interestExpense - couponPaid; // 期末=期初+利息-实付
    beginCost = endCost;
  }
  // 最后一期调整尾差使 endCost ≈ faceValue
}
```
