## 2. 逐项详细验证

### 2.1 损益类取数规则

**要求：确认从tb_ledger取发生额（借方发生-贷方发生），而非tb_balance期末余额**

| 来源 | 证据 |
|------|------|
| 源A (xlsx) | `income_statement_confirmation.data_source = "tb_ledger（发生额，非期末余额）"`<br>`formula_pattern = "借方发生额累计 - 贷方发生（红冲）"`<br>K9-1审定表公式 `B7=SUMIF('明细表K9-2'!$X$11:$X$28,$A7,'明细表K9-2'!$T$11:$T$28)` 取明细表发生额聚合 |

| design.md | ADR-1明确："K9管理费用（6602）损益类，从tb_ledger取本期发生额（借方发生累计-贷方红冲），非tb_balance期末余额" |

**结论：✅ 三源一致。** 损益类取数规则确认无误。design中`calcIncomeStatementOccurrence(debitOcc, creditOcc) = 借方发生 - 贷方发生`与xlsx公式模式对齐。

### 2.3 实质性分析（同比/环比/占收入比/异常波动公式）

**要求：确认K9-4实质性分析表的核心公式**

| 来源 | 证据 |
|------|------|
| 源A (xlsx) | K9-4 `48行×16列`，183公式(176业务公式)<br>`A12='明细表K9-2'!A11` (取明细项目名)<br>`B12='明细表K9-2'!Q11` (取审定金额)<br>`C12=IF(B12=0,0,B12/$B$30)` (占收入比=费用项/合计) |
| 源B (md) | K9-4实质性分析表列结构：`项目|本期合计|结构比|占主营业务收入比率|上年同期|增长比例|占主营业务收入比率变动|变动分析`<br>含三子表：①构成分析表 ②预算对比表 ③行业费用指标对比表 |
| design.md | `calcYoYChange(current, prior) = (本期-上期)/上期`<br>`calcRatioToRevenue(expense, revenue) = 费用/营业收入`<br>`isAbnormalFluctuation(changeRate, threshold) = |变动率|>阈值` |

**细节差异（非冲突）：**

| 差异点 | 说明 | 解决方式 |
|--------|------|---------|
| md有"环比"但xlsx无环比列 | md模板为通用参考，实际K9-4 xlsx仅有同比+占收入比 | **以xlsx为准**，design中"环比"改为可选扩展，核心实现同比+占收入比 |
| md有预算对比+行业对比子表 | xlsx K9-4无独立的预算/行业对比sheet | **预算/行业对比作为K9-4的section二/三实现**，非独立子组件 |
| xlsx `C12=IF(B12=0,0,B12/$B$30)` 是占合计比 | md写"占主营业务收入比率" | **两者都需要**：结构比=本项/合计，占收入比=本项/主营收入。design已覆盖两者 |

**结论：✅ 核心公式一致（同比变动率+占收入比+异常判断）。** md补充的预算/行业对比为辅助分析区，在K9-4组件中作为独立section实现。

### 2.4 截止双向（K9-6记账→原始、K9-7原始→记账方向）

**要求：确认K9-6和K9-7的方向定义**

| 来源 | 证据 |
|------|------|
| 源A (xlsx) | `截止性测试(从记账凭证至原始凭证）K9-6`（44行×11列）<br>`截止性测试（从原始凭证至记账凭证）K9-7`（44行×12列）<br>K9-6列：序号/日期/凭证编号/业务内容/对方科目/金额/凭单编号/凭单日期/是否跨期/跨期金额<br>K9-7列：序号/凭单编号/凭单日期/金额/日期/凭证编号/业务内容/对方科目/是否跨期/跨期金额 |
| 源B (md) | K9-6标题："管理费用截止性测试(从记账凭证至原始凭证）"<br>列序：`序号|记账凭证(日期/凭证编号/业务内容/对方科目/金额)|支出凭单(凭单编号/凭单日期)|是否跨期|跨期金额`<br>K9-7标题："管理费用截止性测试（从原始凭证至记账凭证）"<br>列序：`序号|支出凭单(凭单编号/凭单日期/金额)|记账凭证(日期/凭证编号/业务内容/对方科目)|是否跨期|跨期金额` |
| design.md | `cutoff_K9-6_direction = "记账凭证→原始凭证"`<br>`cutoff_K9-7_direction = "原始凭证→记账凭证"`<br>`isCrossPeriod(sourceDate, bookDate, periodEnd)` 纯函数 |

**方向确认：**
- **K9-6**：起点=记账凭证(已入账)，验证→原始凭证(支出凭单)日期是否匹配。**测试目标：已记账的费用是否属于本期(防前推)**
- **K9-7**：起点=原始凭证(支出凭单)，验证→记账凭证日期是否及时入账。**测试目标：已发生的费用是否已入账(防后推)**
- 两表均以"——截止日期：202X年12月31日——"为分界，上半为期末前样本，下半为期初后样本

**结论：✅ 完全一致。** 方向、列结构、业务含义均对齐。design中`useCutoffAutoSampling`从序时账期末±5天提取样本的设计与模板"样本选取标准"一致。

## 5. 最终结论

**双源输入交叉验证结果：无实质性冲突。**

两个来源（openpyxl实读xlsx + 底稿模板库md）在以下关键维度完全一致：
1. ✅ 损益类取数规则（发生额，非余额）
2. ✅ 6602明细科目结构（按费用性质分项+月度明细）
3. ✅ 实质性分析核心公式（同比+占收入比+异常判断）
4. ✅ 截止双向方向（K9-6记账→原始，K9-7原始→记账）

唯一细节差异为md模板中"环比"和"预算/行业对比"为通用参考内容，xlsx中未独立设列。设计已将其作为K9-4辅助section处理，不影响核心实现。

**可安全进入Phase 1开发。**
