## D1 表格

所有声明叶子列保留。表头统一为 rows + cell(text, colspan, rowspan)，优先显式 multi_header，兼容 `_column_groups`。
上市历史子表头只按章节配置规范化，不能按数据文本模糊识别并误删业务行。
Word、API 和 Vue 共享结构契约；每个适配器测试独特金额，不仅测列数。

## D2 受控节点

父组件唯一拥有选择；子组件可兼容未传 nodeKey 的独立旧入口，受控入口只发选择事件。
请求快照包含项目/年度/节点/报表类型，独立视图与穿透取消器。HTTP 配置传 signal 及 `_dedupe:false`。
响应必须与快照及返回身份一致，根省略仅限旧独立入口首次解析，不能掩盖显式错误节点。
差额表非 aggregate 展示不适用；工作底稿仍是项目年度级，不改变其存储边界。

## D3 状态

真实刷新按叶结果分类；`skipped_locked`/人工保护是合法跳过，缺模板/树是未完成且带原因。
notes step metadata 保留完整计数，局部失败为 partial，全失败为 failed；合法全保护为 skipped。
外层 run 继续按项目及步骤成功程度分类，上层推送不因下层附注失败停止。
SSE 仅通知 run_id/status，消费者按既有共享事件流重读权威状态，不广播全章节正文。

## D4 变体

变体是读写作用域的一部分。切换前处理 dirty，立即清旧配置/公式/穿透并取消请求，然后并行目录及章节读取。
保存绑定加载时的 variant/section/node/context，不允许旧状态写入新模板。

## D5 范围与来源

服务端确认事实、树指纹、有效版本和角色批次须独立实施；不把 wizard.completed 当确认。
legacy 树只读兼容，重新确认只能用户主动触发；确认 API 必须项目权限、合并锁和指纹 CAS。
现有 parent 是母分汇总，hq 才是本部；三角色为身份的计算投影，不复制企业、不重复金额。
CP-07 先查现有 registry/trigger/快照/版本差集，再实施最小补线，不另建披露计算真源。
