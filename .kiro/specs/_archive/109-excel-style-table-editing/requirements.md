# 需求：表格按 Excel 方式呈现与编辑

用户原话（2026-10-27）：

- 「你分析下平台表格的前端显示，能不能参照 excel 的呈现方式进行修改，用户单击或双击单元格进行输入编辑。」
- 「按 Excel 标准，再加一个个人设置可以切换；表格的地方都做；同时做『平时只显示文本、编辑时才出输入框』；其他的你根据建议来逐一完成」

现状（现算口径见 design §1，禁写死行号）：全平台 1325 个文件 2244 张 el-table；表格单元格里常驻编辑控件约 7971 个；只绑 `:model-value` 不写回的 el-input 2157 个（表格内 1487 个）在真浏览器里**打不进字**（输入即回退，见 design §1.3）。

## R1 编辑方式与个人设置

1.1 三种编辑方式，在顶栏「Aa 显示设置」里切换，立即生效，与其他显示偏好一同按浏览器本地保存：
- **Excel 方式**（默认）：单击选中；双击 / F2 / 选中后直接输入进入编辑。
- **单击编辑**：单击可编辑格直接进入编辑，其余与 Excel 方式相同。
- **经典方式**：单元格输入框常驻、不启用选中框与表格键盘（等同改造前，作为回退开关）。
1.2 切换后已打开的表格即时按新方式工作，不需刷新页面；切换时正在编辑的格先提交。

## R2 覆盖范围

2.1 所有 el-table 自动获得选中、键盘、复制粘贴；表体单元格里以模板写法出现的 el-input / el-input-number / el-select / el-date-picker / el-checkbox / el-switch / el-radio-group 自动按单元格编辑器工作，不逐文件改模板。
2.2 只有表体单元格按单元格编辑器工作；表头插槽、展开行、单元格里弹出层（弹窗 / 气泡 / 抽屉）中的控件、表格以外的表单控件，行为与改造前一致。
2.3 渲染函数里显式导入的上述组件、原生 `<table>` 里的编辑控件，逐文件接入（清单见 design §8）。
2.4 个别表格可声明不启用（`data-gt-grid="off"`），每处写明理由并登记。

## R3 平时只显示文本

3.1 未在编辑的单元格只渲染格式化文本，不挂输入控件：文本原样（多行保留换行）；数字按 design §4 规则（有小数或 ≥1 万时千分位）；下拉显示选项名称（多选用「、」连接）；日期按格式显示；勾选 / 开关 / 单选显示控件本身，可直接点击切换。
3.2 空值显示空白；只读或禁用的格同样显示文本，不显示禁用态输入框。
3.3 需要自定义显示的格（附注金额单位、试算平衡表等）用 `GtGridCell` 的显示插槽，编辑时才挂编辑器。
3.4 进入编辑时编辑器贴合单元格，不撑高或撑宽行列。

## R4 选中与键盘（Excel 标准）

4.1 单击选中一格，Shift+单击 / 拖拽选区域，Ctrl+单击追加；Ctrl+A 全选；选中格有边框，选区有底色。
4.2 方向键移动，Shift+方向键扩展选区，Ctrl+方向键到边，Home / Ctrl+Home / Ctrl+End，PageUp / PageDown；移动时自动滚动到可见。
4.3 Enter / Shift+Enter 下移 / 上移；Tab / Shift+Tab 移到下一个 / 上一个可编辑格（连续 Tab 后 Enter 回到起始列的下一行）。
4.4 进入编辑：双击、F2（光标在末尾）、选中后直接输入（覆盖原内容，含中文输入法）；Backspace 清空并进入编辑。
4.5 编辑中：Enter / Tab 提交并移动；Esc 取消并还原；直接输入进入的编辑里方向键提交并移动，F2 / 双击进入的编辑里方向键移动光标；文本框 Alt+Enter 换行。
4.6 Delete 清空选区内可编辑格。
4.7 下拉 / 日期格进入编辑即展开选择，选定即提交；勾选 / 开关格空格键切换。

## R5 提交与取消

5.1 提交时宿主收到与改造前相同的事件（`update:modelValue` / `input` / `change` / `blur`），既有保存、联动、勾稽、同步逻辑不改即生效；值未变不发 `change`。
5.2 取消时宿主数据回到进入编辑前的值；编辑中已发出的即时更新一并还原。
5.3 焦点离开表格、点工具栏按钮、Ctrl+S、切换在线编辑、编辑器被卸载时，先提交正在编辑的格。

## R6 复制、粘贴、撤销

6.1 Ctrl+C / Ctrl+X 复制选区为制表符文本与 HTML 表格，可直接粘进 Excel；剪切在复制后清空可编辑格。
6.2 Ctrl+V 从 Excel / 网页表格粘贴多行多列：从选区左上角写起；单个值粘到区域则填满区域；锁定 / 只读格跳过，超出表格的部分丢弃，结束后提示写入 / 跳过数。
6.3 粘贴值按目标格类型解析（金额千分位、括号负数、百分比、日期、下拉按名称或值匹配、勾选按是 / 否），解析失败的格跳过并计数。
6.4 Ctrl+Z / Ctrl+Y 撤销 / 重做表格内的编辑、粘贴、清空；目标格已被其他操作改过时跳过并提示。表格没有可撤销记录时快捷键交还页面原有处理。

## R7 只读与锁定

7.1 公式格、合计格、只读格可选中、可复制，不可编辑；尝试输入时给一次轻提示。
7.2 页面原有的只读判定（`disabled` / `readonly` / 条件不渲染编辑器）不变。

## R8 快捷键与手势

8.1 编辑中按 Esc 只取消编辑，不关闭弹窗、不退出全屏；选中态按 Esc 交还页面原有处理。
8.2 选中态下全局快捷键（Ctrl+S 保存、Ctrl+E 导出、F5 刷新等）照常；编辑中 Ctrl+S 先提交再保存。
8.3 可编辑格双击 = 编辑；只读格双击照旧触发页面原有穿透 / 跳转。
8.4 「单击即改数据」的交互改为双击或右键菜单（试算表方向切换等，清单见 design §9）；可编辑表上的行双击跳转改走右键 / 「更多」菜单。

## R9 单向绑定输入框修复

9.1 只绑 `:model-value`、靠 `@change` / `@blur` / `@input` 回写的 el-input，表格内外都能正常输入并按原事件回写（经典方式下同样生效）。

## R10 自建编辑实现统一

10.1 各页面自建的「点了才出输入框」与选中实现（清单见 design §9）改用统一内核，单击 / 双击 / 键盘语义与 R4 一致，不出现两套选中框。
10.2 `useCellSelection` 的右键菜单能力（复制、求和、统计、对比）改读统一内核的选区。
10.3 页面靠 `ref.focus()`、`autofocus` 或「点击后才渲染编辑器」打开的编辑框，在迁移完成前仍能正常编辑（兼容规则见 design §7）。

## R11 切在线编辑与离开页面

11.1 切到 OnlyOffice 在线编辑前，正在编辑的格已提交并进入待写盘等待（`pendingWrites`）。

## R12 验收

12.1 内核、适配层、格式与解析各有单测，含中文输入法、键盘、粘贴、撤销、取消还原；新模块与改动的每条判据配磁盘变异（必须红在预期断言上）。
12.2 前端相关测试与改前逐条对比，新增失败为 0；单区域 vue-tsc 0 错（配埋错验证）。
12.3 浏览器实测（Excel / 单击编辑 / 经典三种方式）：底稿明细表与审定表、原生表格披露表、附注编辑器、试算平衡表、报表权益表、合并工作表、调整分录列表（只读表）、弹窗里的表格；核对改值后保存回读一致。
12.4 只提交本 spec 的文件与改动块，推送到当前分支并按 `push_version.py` 打版本标签。
