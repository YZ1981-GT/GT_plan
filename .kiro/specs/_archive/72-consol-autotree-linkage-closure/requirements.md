# 需求：合并模块自动建树、左树联动与四维表收口

> 来源：2026-10-26 合并模块分析（用户拍板五项决策：自动确认 + 树版本、节点命名、基本信息表按企业树带出、草稿预览列、数据节点显示单体报表附注），以及同轮分析列出的 P0 正确性 / P1 联动 / P2 四维表问题。
> 口径：合并数 = 直接下级合计（抵销后）；差额户 = 本级调整与抵销；单体母公司户 = 本部单体；母公司有分公司时母公司户 = 本部 + 分公司 + 母分差额。

## R1 自动建树与树版本（取代范围确认门）

1. 计算合并数不再要求用户先确认合并范围；只校验请求年度与合并项目审计年度一致（不一致仍拒绝并说明）。
2. 每次合并推送（审批 / 撤销审批 / 手动 / 公式变更触发），对每个目标合并项目在重算差额表前自动记录树版本：当前树指纹与已记录版本不同 ⇒ 新建一版（记录方式「自动」，记录触发人，取不到为系统），旧版改为已替代；相同 ⇒ 不新建。推送步骤明细写明所用树版本。合并锁定的项目不记录。
3. 企业树接口返回树版本信息：已记录的版本号、记录方式、记录时间、当前树是否与已记录版本一致，以及结构差异（新增节点、移除节点、上级变化、节点类型或与上级关系变化）；只有名称变化不算结构变化。
4. 合并页企业树头部显示当前树版本；树结构变化时给出提示（不拦截）：差异摘要，并说明「合并数已按新树读时计算，已生成的合并报表与附注是旧树结果，建议重新推送」，附「重新推送」入口。
5. 「确认范围」入口改为「树版本」：查看当前树、与已记录版本的差异和诊断，可手动记录为新版本（非必需）。向导新建合并项目后弹出的是自动生成的企业树预览，不要求确认。
6. 三码全等时，项目基本信息保存前仍请用户确认「本企业即为最终控制方（集团总部或母公司）」（现有行为保留并加测试守护）；企业树根节点标注「最终控制方」。

## R2 节点命名

1. 合并项目的三个节点：`X（合并户）`、`X（差额户）`、`X（单体母公司户）`。
2. 母公司有分公司时：`X（母公司户）`，下挂 `X（母分差额户）`、`X（本部单体户）` 与各分公司（原名）。
3. 子公司 / 分公司自身有分公司且没有合并项目时，其汇总节点为 `X（汇总户）`；其余数据节点用企业原名。
4. 前端角色标签、向导提示、差额面板说明与后端同一口径；节点键 `{企业代码}:{角色}` 不变，不迁移数据。

## R3 拖拽改上级同步项目信息

1. 「合并」总览页拖拽改上级保留；保存时同企业同年度的合并项目与单体项目同步写：上级企业代码、上级企业名称（取新上级本年度项目的企业名称，单体优先）、与上级关系（有有效上级时保留原值，缺省按名称），最终控制方为空时按新上级补齐；向导回填数据同步更新。
2. 只有本项目可编辑成员（及管理员）能调整上级（现在只要求登录）。
3. 返回同步了哪些项目与字段，前端提示用户。
4. 受影响的合并项目照常标合并试算待更新，并在合并页显示树结构变化提示（R1.4）。

## R4 基本信息表按企业树带出

1. 合并工作底稿「基本信息表」的企业清单按企业树自动生成：根合并节点下的子公司类成员（含经中间企业间接持有、提升上来的），企业名称、企业代码、上级单位代码、最终控制方、控制方代码取自企业树，只读；持股类型 / 间接持股方按「经 X 间接持有」预填，可改。
2. 已保存的行按企业代码保留用户填写的其余字段（核算科目、核算方式、持股比例、股比变动、新增 / 减少等）；企业树里已没有的行标「已不在企业树中」，可删除，不进企业列。
3. 企业树可用时不再提供「新增子企业」；导入 Excel 按企业代码只更新可编辑字段，没匹配上的行列出并跳过。
4. 工作底稿各表的企业列只以企业树为准（不再被合并范围表覆盖），持股比例取基本信息表的填写值。

## R5 草稿预览列

1. 合并试算平衡表页增加「含草稿预览」列：按已审批 + 草稿 + 待审批分录（不含已驳回）求合并数；与「合并审定数」不同的格高亮并说明差额来自未审批分录。
2. 分录汇总表同时给出「含草稿」净额。
3. 合并数、推送、合并报表与附注仍只认已审批分录。

## R6 数据节点显示单体项目的报表与附注

1. 左树选中数据节点（本部单体户、单体母公司户、子公司、分公司）且有本年度单体项目时：「合并报表」页显示该单体项目的报表（本期 / 上期，只读），「合并附注」页显示该单体项目的附注（章节目录 + 表格只读，按单体模板表头呈现，含多级表头与续表、表后文字），均提供「进入该企业项目」。
2. 没有单体项目、无权查看、或单体项目尚未生成报表 / 附注时给出中文说明，不拿合并口径数据冒充。
3. 合并户、母公司户、汇总户与差额户仍显示合并口径（读时计算）。

## R7 左树与右侧联动

1. 合并页只保留一棵企业树（中栏），带搜索；集团架构页组织图 / 树形列表的点击、试算页与差额表页的节点切换都回写当前节点并同步中栏高亮。
2. 点击差额户：右侧切到该差额户的报表口径调整与抵销数，不自动弹出分录抽屉；通过「📝 差额分录」按钮打开。
3. 内容区顶部显示当前节点及口径（合并口径 / 本级调整与抵销 / 单体项目）；合并报表列名随口径（合并本期 / 上期、调整抵销本期 / 上期）。
4. 带 `?tab=` 直接进入时，等企业树与审计年度就绪后再取数，不发年度为空的请求，就绪后自动加载当前页。
5. 进入「合并附注」页自动显示附注目录（四栏）；修复四栏切换事件自我重发的死循环；附注空态去掉写死的章节 / 表格数。
6. 报表差额表选中非汇总节点时，按其最近的上级汇总节点展示并高亮该节点所在列，不报错。

## R8 合并数正确性

1. 合并报表「合并上期」取上年同企业合并项目同一节点的合并数；没有上年合并项目或上年树没有该节点时留空，并给出原因。
2. 报表页右键「查看合并明细」按报表行读时计算（与报表差额表同源）：列出直接下级的金额、来源（个别数 / 抵销与调整 / 下级汇总）与占比，底部合并数取后端合计。
3. 合并试算「一致性校验」接口可用：按科目自然方向汇总借方性质与贷方性质合计判平衡。
4. 删除手改合并试算金额的接口（绕开唯一来源，且提交未落库）。
5. 合并试算平衡表页按科目自然方向给出借贷平衡检查，不平时提示。

## R9 分录汇总表同源

1. 分录汇总表改为读合并计算口径：差额节点 × 科目 × 分录类型，列原始借方 / 贷方与按科目方向归一的净额、分录笔数；只计已审批且归属成功的分录；未归属分录单列说明不计入。
2. 与合并试算逐科目对账（调整合计、抵销合计）并显示结果；持久化合并试算与读时结果不一致时提示重新推送。
3. 类型标签与分录枚举一致（`other` = 其他调整）。
4. 放进合并工作底稿「合并抵消」分组；每次进入、分录变化或推送完成后重读。
5. 内部往来 / 内部交易抵销分录使相关科目余额同时增加时给出方向提示。

## R10 四维表显示

1. 试算平衡表页按节点类型说明列口径（汇总节点 / 差额户 / 单体数据）。
2. 节点下拉列出企业树全部节点（按层级缩进、显示名称），不显示内部键；切换节点回写左树。
3. 穿透：合并审定数给完整构成（个别数 + 分录）；分录明细带类型与说明；个别数明细带所属上级并可进入项目；弹窗内 0 与空值分开显示。

## 非目标

- 不改合并计算算式与五度量恒等式；不改附注明细映射与重新汇总（并发 spec 范围）。
- 不改项目列表的「（合并）/（母公司）」项目显示后缀（项目层面，不是企业树节点）。
- 不修改真库合成集团已有的分录数据（方向错误由 R9.5 提示）。
