# 分析性复核底稿 — 需求文档

## 概述

A1-13（母公司/单体）和 A1-14（合并）是完成阶段分析性复核底稿，包含多维度财务数据分析。需要结构化渲染并与报表模块、各科目审定表联动。

## 底稿结构

### A1-13 母公司（6 sheet）
1. 完成阶段的分析性复核 A1-13 — 主表：审计目标 + 5大类审计程序 + 同行业比较 + 差异分析
2. 已审资产负债横向分析 A1-13-1 — BS 横向趋势（上年审定/本年审定/变动额/变动%/变动状况/变动原因）
3. 已审资产负债纵向分析 A1-13-2 — BS 纵向结构（上年/本年审定数+比重%+变动%+变动原因）
4. 已审利润横向分析 A1-13-3 — IS 横向趋势（同 BS 横向结构）
5. 已审利润纵向分析 A1-13-4 — IS 纵向结构
6. 已审报表比率分析 A1-13-5 — 46个财务比率（6大类：盈利/短期偿债/长期偿债/资产管理/资本管理/现金流量）

### A1-14 合并（8 sheet，含上市公司专用）
- Sheet 1~6：与 A1-13 相同结构，数据源换为合并报表
- Sheet 7：同行业对比分析 A1-14-6（**上市公司专用**）— 5家可比公司 × 8指标 × 3年
- Sheet 8：EPS-ROE(参考)（**上市公司专用**）— 净资产收益率(全面摊薄/加权平均) + 基本/稀释每股收益计算

## 功能需求

### 1. 数据自动取数
- 1.1 横向/纵向分析表的金额列从 `trial_balance.audited_amount` 按 row_code 自动取数（与报表模块同源）
- 1.2 上年审定数从上年度 trial_balance 取
- 1.3 变动额 = 本年 - 上年；变动% = 变动额 / |上年|
- 1.4 比率分析的分子/分母按固定公式从 trial_balance 计算

### 2. 变动原因联动
- 2.1 "显著变动原因分析"列从各科目底稿的审定表审计说明引用填充
- 2.2 目前各科目底稿未修订完成，预留引用接口（按 row_code/standard_account_code 关联）
- 2.3 变动状况列（显著/关注）按阈值自动标记（如变动%>20%或变动额>重要性水平）

### 3. 比率分析（46 指标）
- 3.1 盈利能力（9个）：长期资本报酬率/资本金收益率/股本权益报酬率/总资产报酬率/毛利率/营业利润率/销售净利率/成本费用利润率/研发费用比例
- 3.2 短期偿债能力（3个）：流动比率/速动比率/现金比率
- 3.3 长期偿债能力（7个）：资产负债比率/产权比率/有形净值债务比率/利息保障倍数/营运资金长期负债比率/长期负债比率/融资结构弹性比率
- 3.4 资产管理效率（6个）：总资产周转率/固定资产周转率/流动资产周转率/应收账款周转率/存货周转率/营业周期
- 3.5 资本管理效果（6个）：资本保值增值率/社会贡献率/社会积累率/不良资产比率/资产损失率/固定资产成新率
- 3.6 现金流量分析（4个）：经营活动净现金比率1/2+净利润现金保证比率+销售收入现金回收比率
- 3.7 公式固定不可编辑，指标值自动计算
- 3.8 增减列（绿色/红色）标记变动方向
- 3.9 注释规则：①平均数按年末年初算术平均 ②时期数据年化处理(annualized) ③流动比率正常值2/速动比率正常值1/现金比率正常值0.3

### 4. 同行业对比（上市公司专用）
- 4.1 可比公司选择（5家 A~E，证券简称+代码）
- 4.2 主要财务数据表：资产总额/净资产额/营业收入/净利润/净资产收益率/存货周转率/资产负债率
- 4.3 对比分析表：净资产收益率/综合毛利率/XX毛利率/应收账款周转率/存货周转率 × 3年
- 4.4 数据来源标注
- 4.5 按 `project.is_listed` 判断是否显示此 sheet

### 5. EPS-ROE 计算表（上市公司专用）
- 5.1 净资产收益率：全面摊薄 = P/E、加权平均（按 CAS 34 公式）
- 5.2 基本每股收益 = P/S（归属普通股东净利润 / 加权平均普通股数）
- 5.3 稀释每股收益（考虑可转债/期权/认股权证等稀释因素）
- 5.4 股本变动明细：期初股份S0 + 各类增减(S1~Sk) × 时间权重
- 5.5 公式内置，用户填写参数（净利润/股份数/转股数等），自动计算结果
- 5.6 注释区域：CAS 34 相关规定说明（配股/公积转增/拆股等处理规则）

### 6. 表格交互
- 6.1 科目行点击可跳转到对应循环底稿（如"应收账款"→D1 底稿）
- 6.2 阈值超标行红色标记，需关注行黄色标记
- 6.3 变动原因列支持手动编辑（覆盖自动引用）
- 6.4 Sheet 切换 tab 导航

### 7. 适用性
- 7.1 A1-13 = standalone 项目（母公司/单体）
- 7.2 A1-14 = consolidated 项目（合并报表）
- 7.3 同行业对比 + EPS-ROE = 仅上市公司项目（`project.is_listed = true`）
- 7.4 根据项目类型自动选择 A1-13 或 A1-14

## 非功能需求

- 性能：BS 86行 + IS 50行 + 比率 46行 = ~180 数据点，普通 DOM 足够
- 各科目底稿审计说明接口预留（当前返回空/placeholder，后续补全）
