# N 类底稿（税费循环）— 需求文档

## 1. 概述

N 类底稿覆盖"实质性程序—税费循环"阶段（审计循环代号 N），根据 B50 风险评估结果和 C12（税金）控制测试结论，执行实质性程序。包含 **5 个科目、5 个模板文件、约 35+ 个子底稿 sheet**。

N 类特殊性：N5（所得税费用）涉及所得税计算（税率×利润+调增调减），N1/N3（递延所得税资产/负债）涉及暂时性差异计算。

## 2. 现状与差距

|------|------|------|
| wp_account_mapping | 少量 N 类条目 | 缺大量子码 |
| _WP_CODE_OVERRIDE | 0 条 | N 类无显式映射 |
| risk_for_cycle | B50→N 就绪 | ✅ |
| control_test_result_for_cycle | C12→N 就绪 | ✅ |

## 3. 术语表

- **税费循环系统（Tax_Cycle_System）**：平台中负责 N 类底稿的子系统
- **暂时性差异（Temporary_Differences）**：资产/负债的账面价值与计税基础之差
- **递延所得税（Deferred_Income_Tax）**：因暂时性差异确认的未来税务影响
- **纳税调增调减（Tax_Adjustments）**：会计利润→应纳税所得额的调整项目

## 5. 各组详细需求

### N1: 递延所得税资产
**需求：** N1A程序表 + N1-1审定表 + N1-2明细 + N1-3暂时性差异计算表 + N1-4可抵扣确认条件 + N1-5分析 + N1-6调整分录
- N1-3 暂时性差异计算（账面价值-计税基础=差异×税率=递延税）→`audit-sheet`
- N1-4 可抵扣暂时性差异确认条件（未来应纳税所得额是否足够）→`d-form-table`

### N2: 应交税费
**需求：** N2A程序表 + N2-1审定表 + N2-2明细（增值税/企业所得税/个税/城建/教育附加等多税种）+ N2-3增值税核对 + N2-4税费完整性检查 + N2-5分析 + N2-6调整分录
- N2-2 多税种明细（10+ 税种分行）→`audit-sheet`
- N2-3 增值税核对（销项-进项-转出=应缴）→`audit-sheet`

### N3: 递延所得税负债
**需求：** N3A程序表 + N3-1审定表 + N3-2明细 + N3-3暂时性差异计算表 + N3-4应纳税差异来源 + N3-5分析 + N3-6调整分录
- N3-3 与 N1-3 对称（应纳税暂时性差异）→`audit-sheet`

### N4: 税金及附加
**需求：** N4A程序表 + N4-1审定表 + N4-2明细 + N4-3测算验证 + N4-4调整分录
- N4-3 测算（营业额×税率 验证各附加税计提正确性）→`audit-sheet`

### N5: 所得税费用（核心计算）
**需求：** N5A程序表 + N5-1审定表 + N5-2明细 + N5-3所得税计算表 + N5-4纳税调增调减明细 + N5-5有效税率分析 + N5-6递延所得税联动 + N5-7研发加计扣除 + N5-8调整分录
- N5-3 所得税计算表（利润总额±调增调减=应纳税所得额×税率=当期所得税）→`audit-sheet`
- N5-4 纳税调增调减明细（逐项列示：超标费用/免税收入/减值准备/折旧差异等）→`audit-sheet`
- N5-5 有效税率分析（实际税负率 vs 法定税率，解释差异原因）→`audit-sheet`
- N5-6 递延所得税联动（读取 N1/N3 递延税变动）→`d-form-table`
- N5-7 研发加计扣除（联动 I6-7）→`audit-sheet`

## 7. 技术约束

- wp_code 规则：N1~N5 共 5 组（无函证）
- componentType：暂时性差异/所得税计算/增值税核对→audit-sheet，确认条件/联动→d-form-table
- 审定表回写正则：`^N\d+-1$`
- N5 所得税计算是全循环联动终点：需汇总利润+读取调增调减+联动递延税
- N1/N3 暂时性差异需遍历全部资产负债科目

## 9. 跨循环依赖提示

> 📌 **全局交叉索引**：`.kiro/specs/CYCLE-CROSS-REFERENCE.md`

- **前置依赖**：I6 研发费用 P2 完成（N5-7 读取加计扣除）；D~N 损益审定完成（N5 所得税计算需利润总额）
- **B23 穿行编号**：N 对应 B23-12（税费循环穿行测试）
- **C 类编号**：N 对应 C12（税金计算/申报控制）
- **完整链路**：B23-12 穿行→C12 控制测试→N{n}A 实质性程序表
- **后续被依赖**：N5 所得税费用→M6 未分配利润（净利润=利润总额-所得税）
- **全链路终点**：N5 是计算链最下游——需 D~N 全部损益+I6 加计扣除+N1/N3 递延税
- **新增 resolver**：`rd_super_deduction_for_n5`（从 I6-7 读取研发加计扣除金额）
- **⚠️ N5 所得税和 M6 未分配利润是整个审计 "闭环验证" 的终点，执行顺序必须最后**
