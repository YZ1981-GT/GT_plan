# H 类底稿（固定资产循环）— 需求文档

## 1. 概述

H 类底稿覆盖"实质性程序—固定资产循环"阶段（审计循环代号 H），根据 B50 风险评估结果和 C6（固定资产）+C7（在建工程）控制测试结论，执行实质性程序。包含 **10 大科目组 + 1 函证组、11 个模板文件、约 60+ 个子底稿 sheet**。

H 类特殊性：H8（使用权资产）/H9（租赁负债）为新租赁准则 CAS21 特有科目，涉及租赁负债现值计算和使用权资产折旧。

## 3. 术语表

- **固定资产循环系统（Fixed_Asset_System）**：平台中负责 H 类底稿的子系统
- **使用权资产（Right_of_Use_Asset）**：CAS21 新租赁准则下承租人确认的资产（H8）
- **租赁负债（Lease_Liability）**：承租人确认的未来租金支付义务的现值（H9）
- **资产处置损益（Asset_Disposal_Gain_Loss）**：固定资产处置产生的利得或损失（H10）

## 5. 各组详细需求

### H0: 固定资产循环函证
与 D0/E0/F0/G0 模式一致。H0→ConfirmationHub（cycle=H），H0-1~H0-5 用 `d-form-table`。

### H1: 固定资产
**需求：** H1A程序表 + H1-1审定表 + H1-2明细 + H1-3折旧测算 + H1-4增减变动 + H1-5减值测试 + H1-6分析 + H1-7检查 + H1-8调整分录
- H1-3 折旧测算含公式（原值×(1-残值率)/年限）→`audit-sheet`
- H1-5 减值测试→`audit-sheet`

### H2: 在建工程
**需求：** H2A程序表 + H2-1审定表 + H2-2明细 + H2-3利息资本化测算 + H2-4转固测试 + H2-5分析 + H2-6调整分录
- H2-3 利息资本化含复杂公式（加权平均资本化率×累计支出）→`audit-sheet`

### H3: 投资性房地产
**需求：** H3A程序表 + H3-1审定表 + H3-2明细 + H3-3公允价值测试 + H3-4折旧/摊销 + H3-5分析 + H3-6调整分录
- H3-3 公允价值模式需评估报告→`audit-sheet`

### H4: 工程物资
**需求：** H4A程序表 + H4-1审定表 + H4-2明细 + H4-3检查 + H4-4调整分录

### H5: 油气资产
**需求：** H5A程序表 + H5-1审定表 + H5-2明细 + H5-3折耗测算 + H5-4调整分录
- 行业特殊科目，非油气企业标"不适用"

### H6: 固定资产清理
**需求：** H6A程序表 + H6-1审定表 + H6-2明细 + H6-3检查 + H6-4调整分录

### H7: 生产性生物资产
**需求：** H7A程序表 + H7-1审定表 + H7-2明细 + H7-3折旧测算 + H7-4调整分录
- 农林牧渔行业特殊，非该行业标"不适用"

### H8: 使用权资产（CAS21 新租赁准则）
**需求：** H8A程序表 + H8-1审定表 + H8-2明细 + H8-3折旧测算 + H8-4租赁还原 + H8-5减值 + H8-6调整分录
- H8-4 租赁还原：从租赁合同提取付款计划→计算使用权资产原值→`audit-sheet`
- H8 与 H9 联动：使用权资产原值=租赁负债初始计量+预付+初始直接费用

### H9: 租赁负债（CAS21 新租赁准则）
**需求：** H9A程序表 + H9-1审定表 + H9-2明细 + H9-3现值测算 + H9-4摊销表 + H9-5分析 + H9-6调整分录
- H9-3 租赁负债现值计算（未来付款额折现，含增量借款利率确定）→`audit-sheet`
- H9-4 租赁负债摊销表（每期利息+本金分摊）→`audit-sheet`

### H10: 资产处置损益
**需求：** H10A程序表 + H10-1审定表 + H10-2明细 + H10-3检查 + H10-4调整分录
- 损益类科目，从 tb_ledger 取发生额
