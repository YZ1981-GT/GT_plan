# 现金流量表支持底稿 Design

## Overview

A5 主表已有 `cf-verification` 组件。子底稿 A5-1~A5-4 P0 走 Univer 渲染，P1 结构化。或有事项需要判断逻辑引擎，终止经营需要公式计算。

## P0 设计（Univer + 准则说明）

### 路由确认
- A5 → `cf-verification`（已有，不动）
- A5-1 → 确认是否已被 cf-verification 覆盖（可能是同一底稿的 multi-sheet）
- A5-2/A5-3/A5-4 → Univer 渲染（F-审定表 或默认）

### 准则说明面板
- A5-3 或有事项：CAS 13 判断标准（很可能/可能/极小可能 三级 + 对应处理）
- A5-4 终止经营：CAS 42 定义 + 列报要求
- 以 guidance 侧栏面板展示

## P1 设计（结构化渲染）

### A5-3 或有事项组件
```
┌──────────────────────────────────────────────────┐
│ 或有事项汇总                                      │
├──────┬──────┬──────┬──────┬──────┬──────────────┤
│ 事项 │可能性│ 金额 │ 处理 │ 披露 │ 审计说明      │
├──────┼──────┼──────┼──────┼──────┼──────────────┤
│ xxx  │很可能│ 100万│ 确认 │ 附注 │              │
│ yyy  │可能  │ 50万 │ 披露 │ 附注 │              │
│ zzz  │极小  │ 20万 │不披露│  —  │              │
└──────┴──────┴──────┴──────┴──────┴──────────────┘
```

可能性选择自动联动处理建议：
- 很可能(>50%) → 确认预计负债 + 披露
- 可能(5~50%) → 仅披露（或有负债）
- 极小可能(<5%) → 一般不披露

### A5-4 终止经营计算组件
公式链：
- C = A - B（终止经营利润总额 = 收入 - 费用）
- E = C - D（经营活动净利润 = 利润总额 - 所得税）
- I = G - H（处置净利润 = 处置收益 - 处置所得税）
- J = E + F + I（终止经营净利润 = 经营净利润 + 减值 + 处置净利润）

## Testing Strategy
- P0：Univer 渲染 + guidance 面板
- P1：或有事项判断联动 + 终止经营公式计算单测
