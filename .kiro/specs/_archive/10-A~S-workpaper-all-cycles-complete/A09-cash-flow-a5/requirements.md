# 现金流量表支持底稿 — 需求文档

## 概述

A5（财务报表支持程序表）及其子底稿 A5-1~A5-4 覆盖现金流量表审计、承诺事项、或有事项、持续/终止经营分类。A5 主表已有 `cf-verification` componentType，子底稿需要结构化支持。

## 底稿结构

### A5 财务报表支持程序表（21KB）
- 已有 `cf-verification` componentType（现金流量表核查视图）
- 不需要改动

### A5-1 现金流量表审计（60KB）
- 现金流量表核查明细（间接法调节/直接法验证）
- 与现有 `cf-verification` 组件可能有重叠或互补关系
- 需确认是否已被 cf-verification 覆盖

### A5-2 承诺事项（31KB）
- 承诺事项汇总表
- 结构：承诺类型/金额/期限/对方/相关合同/披露要求
- 标准审定表结构

### A5-3 或有事项（75KB）
- 或有事项（或有负债/或有资产）汇总表
- 结构：事项描述/可能性判断/金额估计/披露处理
- 含判断逻辑：很可能/可能/极小可能 → 确认/披露/不披露

### A5-4 持续经营利润和终止经营净利润（102KB）
- 计算表结构：
  - 本年净利润(净亏损以"-"号填写)
  - 按持续性分类
  - 终止经营收入(A) / 终止经营费用(B) / 终止经营利润总额(C=A-B)
  - 终止经营所得税(D) / 经营活动净利润(E=C-D)
  - 资产减值损失(F) / 处置收益总额(G) / 处置所得税(H) / 处置净利润(I=G-H)
  - 终止经营净利润(J=E+F+I)
  - 归属母公司/少数股东的终止经营净利润
  - 各类现金流量净额（经营/投资/筹资）
  - 审计说明 + 大额变动主要原因

## 功能需求

### 1. A5-2 承诺事项
- 1.1 承诺事项清单（类型/金额/期限/相关方）
- 1.2 与附注披露联动（承诺事项章节）
- 1.3 审计说明填写

### 2. A5-3 或有事项
- 2.1 或有事项清单（描述/可能性/金额/处理）
- 2.2 可能性判断三级：很可能(>50%)/可能(5~50%)/极小可能(<5%)
- 2.3 对应会计处理自动提示：很可能→确认负债、可能→披露、极小可能→不披露
- 2.4 与附注披露联动

### 3. A5-4 持续/终止经营
- 3.1 计算公式内置（C=A-B, E=C-D, I=G-H, J=E+F+I）
- 3.2 从利润表取净利润数据（预留接口）
- 3.3 审计说明 + 大额变动主要原因填写
- 3.4 现金流量分类展示

### 4. 准则说明
- 4.1 或有事项判断标准（CAS 13 相关规定）
- 4.2 终止经营定义和分类标准（CAS 42）
- 4.3 以 guidance hover/侧栏 展示

## 非功能需求
- P0：A5-2/A5-3/A5-4 走 Univer 渲染（保留公式）
- P1：结构化组件（或有事项判断逻辑+终止经营计算引擎）
- A5-1 需确认是否已被 cf-verification 覆盖
