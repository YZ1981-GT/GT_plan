## 一、权益备抵借方方向铁律 ✅ 已确认

### xlsx公式验证

**M3-2明细表核心公式链**（59×19，72公式）：

| 列 | 公式 | 含义 | 方向验证 |
|----|------|------|---------|
| F | `=B+C-D-E` | 未审期末=期初+本期增加-转让-注销 | ✅ 借方增加(+C)，贷方减少(-D-E) |
| M | `=B+G+H` | 期初审定=期初未审+期初AJE+期初RJE | 加法累计 |
| N | `=C+I+K` | 借方发生审定=增加+增加AJE+增加RJE | **借方方向（回购增加）** |
| O | `=D+E+J+L` | 贷方发生审定=转让+注销+减少AJE+减少RJE | **贷方方向（注销/转让减少）** |
| **P** | **`=M+N-O`** | **期末审定=期初审定+借方-贷方** | **✅ 权益备抵借方铁律核心公式** |

**M3-1审定表公式链**（33×12，129公式）：
- 各行引用 `='明细表M3-2'!P{row}`（审定数列）
- 变动额：`=I-E`（期末审定-期初审定）
- 变动率：`=IF(AND(E=0,J=0),0,IF(AND(E=0,J>0),1,J/E))`

### md模板库验证

**编制说明第6条**（明确铁律）：
> "库存股不得参与公司利润分配,**股份有限公司应当将其作为所有者权益的备抵项目反映**。"

**明细表列头结构（md §M3-2）**：
> 库存股类别 | 期初数 | 本期增加 | 转让 | 注销 | 期末数 | 账项调整 | 重分类调整 | ... | 审定数

### 交叉验证结论

| 验证点 | xlsx证据 | md证据 | 结论 |
|--------|---------|--------|------|
| 科目性质 | P=M+N-O（借方余额公式） | "所有者权益的备抵项目" | ✅ 一致：借方/权益备抵 |
| 增加方向 | N列=增加(借方) | "本期增加"列 | ✅ 一致：回购→借方增加 |
| 减少方向 | O列=转让+注销(贷方) | "转让"+"注销"分列 | ✅ 一致：注销/转让→贷方减少 |
| 与其他M权益对比 | M3: P=M+N-O ≠ M2: 期末=期初+贷-借 | 备抵vs正常权益 | ✅ 方向相反已确认 |

**铁律公式引擎设计**：
```typescript
// 权益备抵借方（M3独有，其他M权益类用 begin+credit-debit）
calcContraEquityEndBalance(begin, debit, credit) = begin + debit - credit
```

## 二、回购注销业务 ✅ 已确认

### xlsx公式验证

**M3-2明细表回购/注销结构**：
- C列 = 本期增加（回购）→ 计入N列借方发生
- D列 = 转让 → 计入O列贷方发生
- E列 = 注销 → 计入O列贷方发生

**M3-5检查表交叉引用**：
- `F18 = '明细表M3-2'!O25`（贷方发生合计=注销+转让合计）
- `G18 = '明细表M3-2'!N25`（借方发生合计=回购合计）
- `F19 = F17/F18`（检查比例=抽样贷方/全部贷方）
- `G19 = G17/G18`（检查比例=抽样借方/全部借方）

### md模板库验证

**M3-2明细表审计过程（md）**：
> 1. 检查股票回购的交易活动。检查的内容包括已发行股票的登记簿、回购的股票、银行对账单、会计账面记录等；
> 2. 以回购股票以及其他法定程序报经批准减资的，检查股东会决议以及相关的法律文件，手续是否办理，检查其是否**按注销的股票面值总额和所注销的库存股的账面余额，冲减资本公积**，会计处理是否正确；

**M3A程序表步骤4（md）**：
> 对本期库存股发生的增减变动：
> （1）获取公司回购股份的股东（大）会/董事会决议、审批文件等，检查回购股份手续是否完整
> （2）检查回购股份交易的记账凭证和原始凭证，检查会计处理是否正确
> （3）检查注销股份的相关流程是否合规、会计处理是否正确

### 交叉验证结论

| 验证点 | xlsx证据 | md证据 | 结论 |
|--------|---------|--------|------|
| 回购增加借方 | C列→N列(借方) | "本期增加"=回购 | ✅ 一致 |
| 注销减少贷方 | E列→O列(贷方) | "注销"列+编制说明第3条 | ✅ 一致 |
| 转让减少贷方 | D列→O列(贷方) | "转让"列+编制说明第4条 | ✅ 一致 |
| 检查表核对 | M3-5引用M3-2!N25/O25 | "检查回购/注销交易" | ✅ 一致 |

**引擎设计**：
```typescript
calcRepurchaseAmount(shares, price) = shares × price  // 回购金额（借方增加）
```

## 三、M2-M4冲减联动 ✅ 已确认

### md模板库验证（业务逻辑权威）

**M3-2编制说明第3条**（注销冲减规则）：
> "库存股注销时,按照注销的股份数量减少相应**股本**[M2],**库存股成本高于对应股本的部分,依次冲减资本公积金**[M4]**、盈余公积金**[M5]**、以前年度未分配利润**[M6];低于对应股本的部分,增加资本公积金[M4]。"

**M3-2审计说明模板**：
> 2. 因库存股注销而减少的股本：___________________
> 3. 本期注销的库存股成本**高于**对应股本成本\_\_元，**依次冲减资本公积**\_\_元、盈余公积\_\_元、未分配利润\_\_元。
> 4. 本期注销的库存股成本**低于**对应股本成本\_\_元，**增加资本公积**\_\_元。

### xlsx公式验证

M3-5检查表公式仅包含合计和比例计算（F17=SUM, G17=SUM, F19=F17/F18），**不含直接冲减M2/M4的公式联动**（冲减是跨底稿业务逻辑，非单表公式）。

### 交叉验证结论

| 联动关系 | 来源 | 方向 | 实现方式 |
|---------|------|------|---------|
| 注销→减少M2实收资本 | md编制说明第3条 | 注销面值金额→贷记M2 | EventBus + GtIndexChip |
| 注销差额→冲减M4资本公积 | md编制说明第3条 | 注销成本-面值差额→借记M4 | EventBus + cross_wp_ref |
| 注销差额不足→冲减M5/M6 | md编制说明第3条 | M4不足部分→M5→M6 | 级联冲减规则 |
| 转让差额→增减M4资本公积 | md编制说明第4条 | 转让收入vs成本差额→M4 | EventBus + cross_wp_ref |

**引擎设计**：
```typescript
// 注销冲减差额=注销金额-冲减实收资本(M2)-冲减资本公积(M4)
calcCancelDiff(cancelAmount, deductCapital, deductReserve) = cancelAmount - deductCapital - deductReserve
// 差额≠0时，需进一步冲减M5盈余公积/M6未分配利润
```
