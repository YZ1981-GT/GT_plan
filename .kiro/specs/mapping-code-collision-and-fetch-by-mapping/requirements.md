# 需求：科目自动匹配编码撞号 + 税审取数一级科目只认映射 + 存量修复

来源：用户 2026-11-03 底稿映射页上线后问「两个问题，你的建议是什么」→ 给出建议 →「要修复」。
承接 `citar-account-workpaper-map` design §6、`legacy-pl-account-crosswalk-mapping`（只做了损益类对照）。

## 现状（2026-11-03 真库只读实测）
- 自动匹配先按编码认（完整码 → 前 4 位 → 一级码），名称只在编码认不出时才用。客户用《企业会计制度》编号时，资产负债类同码不同义：
  四川医药 / ABC餐饮（同一份账）9 个一级科目被精确匹配错（1501 固定资产 → 持有至到期投资、1502 累计折旧 → 持有至到期投资减值准备、1231 低值易耗品 → 坏账准备、1301 待摊费用 → 贴现资产、1401 长期股权投资 → 材料采购、1603 在建工程 → 固定资产减值准备、1701 固定资产清理 → 无形资产、1801 无形资产 → 长期待摊费用、3101 实收资本 → 盈余公积）；辽宁 1407 发出商品 → 商品进销差价。试算表、审定报表、税审底稿都按这些映射汇总。
- 四川医药 / ABC餐饮的客户科目表仍是 10-30 旧导入：287 行编码全带「.0」、名称错一行（1133.0 =「\预付账款」）；余额表已重新导入且正确。自动匹配读客户科目表 ⇒ 50 条模糊匹配按错位名称配错。
- 自动匹配「已有映射就跳过」按原样编码比较：「1133」与旧的「1133.0」不算同一个 ⇒ 重新匹配会两条并存，试算表按归一编码取哪条不确定。
- 税审取数一级科目找不到映射时按客户科目名「包含」兜底：5 个有账项目 52 个一级名里 14 个靠包含 / 同义命中明细（「其他收入 / 支出 / 费用」抓任何叫「其他」的明细、「生产性生物资产累计折旧」抓累计折旧、短期 / 长期借款都抓其他应付款-借款）。

## R1 自动匹配：编码相同但名称不是同一科目时不按编码认
- 按编码命中标准科目时，比较客户一级科目名与该标准一级科目名；名称兼容（全等、一方包含另一方、或在同义表同一组）才按编码认。
- 不兼容时改按客户一级科目名找标准科目（全等、同义表），找到即映射；找不到不自动映射（留在「有余额未映射」由人定）。不做模糊匹配。
- 同义表收录新旧准则改名（现金 / 库存现金、低值易耗品 / 周转材料、应付工资 / 应付职工薪酬、应交税金 / 应交税费、长期投资 / 长期股权投资、短期投资 / 交易性金融资产 等），手工维护、可增补。
- 明细科目跟随所属一级科目：本身编码在标准科目表里且通过名称校验的照常；否则用一级科目的匹配结果；一级科目存在但没匹配上的，明细不按自己的名称猜。
- 一级科目名取法：客户科目表有一级科目行用该行名称；没有时从明细名称的分隔符前一段取（「实收资本_国有资本」→ 实收资本）；都取不到不做名称校验（与原逻辑一致）。
- 损益类旧编码对照（legacy_pl_crosswalk）、坏账准备二级（1231 系列）优先级不变。

## R2 已有映射按归一编码判断
- 自动匹配跳过已有映射、「有余额未映射」清单、已映射计数，客户科目码一律剥「.0」后比较（与试算表 `tb_mapping_sql.normalized_code` 同口径）。

## R3 税审取数：一级科目只认标准科目映射
- 规则一级科目名在标准科目表里：只取映射到该标准科目的客户科目；没有 ⇒ 留空，原因「没有客户科目映射到标准科目 XXXX 名称」。
- 不在标准科目表里（民非 / 事业单位科目）：只认客户一级科目名称全等 / 同义；不做包含匹配、不认同名明细。
- 一级以下的明细匹配不变；「存货」等别名组不变。
- 底稿映射页「科目 → 底稿」同口径（同一执行器）。

## R4 存量修复（用户 2026-11-03「要修复」）
- 四川医药、ABC餐饮：备份 → 按当前有效余额表重建客户科目表 → 删除自动映射（手工映射不动）→ 按新规则重新匹配 → 全量重算试算表 → 重新生成报表。
- 辽宁：只改新规则下判为「编码撞号」的自动映射（含 1407），其余不动；同样重算、重新生成报表。
- 先 dry-run 列出每条映射的前后对照，再执行；执行后对比试算表、报表、税审取数格的前后差异。
- 正式工具 `backend/scripts/fix/rematch_account_mapping.py`（可重复用于以后导入的项目），带 `--dry-run` / `--apply` / `--restore <备份>`。

## R5 约束
- 只 flush 不 commit 的 service 约定不变；工具按项目逐个事务。
- 测试：映射规则单测（撞号、同义、明细跟随、一级行缺失、损益对照与坏账准备不回归）、归一编码、取数只认映射；隔离副本磁盘变异。
- 浏览器实测底稿映射页两个页签读回修复后数据。
