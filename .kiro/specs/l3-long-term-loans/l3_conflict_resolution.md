## 3. 🔴 利息测算公式 — **关键冲突**

### xlsx证据（权威）
```
M11: =J11*I11/365*L11
```
- **J11** = 借款本金
- **I11** = 年利率
- **L11** = 计息天数
- **除数 = 365**

应付利息测算同样使用365：
```
S11: =J11*I11/365*R11
```

### md证据
- md利息测算表列头：`序号 | 借款种类 | 贷款单位 | 借款起始日期 | 借款讫止日期 | 结息日 | 起算时点 | 截止时点 | 年利率 | 借款本金 | 本期实计利息① | 本期应计息天数 | 本期应计利息 | 差异 | 财务费用-利息支出② | 资本化利息支出③ | 本期未付利息天数 | 本期应付利息账面数 | 本期应付利测算 | 备注`
- md**未明确写出360还是365**，仅描述"对长期借款的利息进行测算"

### spec当前状态
- requirements.md Req10.1 写：`calcInterest(principal, annualRate, days): 利息=本金×年利率×天数/360`
- tasks.md P3 PBT 写：`断言：calcInterest(p, rate, days) === p×rate×days/360`

### 冲突分析
| 来源 | 天数基准 | 权威性 |
|---|---|---|
| xlsx公式（实际模板） | **365** | ⭐⭐⭐ 最高（这是实际执行的底稿） |
| md模板库 | 未明确 | — |
| spec requirements | 360 | ⭐ 需修正 |

### 🔴 决议
**以xlsx为准：利息计算使用365天制。**

与L1短期借款完全一致（L1 conflict_resolution已确认365天制）。中国银行借款实务中，央行基准利率贷款通常按365天（实际天数/365）计息，致同2025修订版模板统一采用365天制。

spec中需修正：
1. `requirements.md` Req10.1: `/360` → `/365`
2. `requirements.md` Req4.2: `/360` → `/365`
3. `design.md` P3: `p×rate×days/360` → `p×rate×days/365`
4. `tasks.md` 2.6 PBT P3断言: `/360` → `/365`
5. `useL3InterestEngine.ts` 实现: 除数用365

## 4. 计息天数逻辑

### xlsx证据
```
L11: =IF(G11=0,0,IF((H11-G11)=365,H11-G11,H11-G11+1))
G11: =IF(D11<=$D$9,$D$9,D11)    // 起算=max(借款起始日,报告期初)
H11: =IF(E11<=$E$9,E11,$E$9)    // 截止=min(借款到期日,报告期末)
```

### md证据
- md列头有"本期应计息天数"、"起算时点"、"截止时点"但未给出具体计算公式

### 决议
**以xlsx为准。天数计算规则：**
```
startDate = max(reportStart, loanStart)
endDate = min(loanEnd, reportEnd)
days = startDate==0 ? 0 : (endDate - startDate)==365 ? 365 : (endDate - startDate)+1
```
含义：报告期区间裁剪 + 整年取365天 + 非整年"算头算尾"（+1天）。
与L1完全一致。

## 5. 一年内到期重分类

### xlsx证据（L3-2 + L3-1）
- **L3-2** V列="减：期初一年内到期的长期借款"、W列="减：期末一年内到期的长期借款"
- **L3-1** F列公式: `=SUMIF('明细表L3-2'!B:B,A7,'明细表L3-2'!V:V)`（按类型汇总期初一年内到期）
- **L3-1** L列公式: `=SUMIF('明细表L3-2'!B:B,A7,'明细表L3-2'!W:W)`（按类型汇总期末一年内到期）
- **L3-1** G列="披露审定数" `=E7-F7`（审定数 - 一年内到期 = 报表上的非流动负债）
- **L3-1** M列="披露审定数" `=K7-L7`（期末同理）
- **L3-2** X列=`R-V`, Y列=`U-W`（披露=审定-一年内到期）

### md证据
- L3-1审定表列头明确包含"减：一年内到期的长期借款"列
- L3-2明细表列头明确包含"减：期初一年内到期"和"减：期末一年内到期"
- md描述：确定流动负债和非流动负债的划分是否正确

### 结论
**两源完全一致。** 重分类链路：
```
L3-2 V/W列（每笔借款一年内到期金额）
  → L3-1 F/L列（按类型SUMIF汇总）
  → L3-1 G/M列（披露审定数 = 审定 - 一年内到期）
  → RJE: 借:长期借款 / 贷:一年内到期的非流动负债
```
spec设计的 `calcCurrentPortion(dueDate, reportDate, amount)` 正确。

## 14. 天数计算完整规则（从xlsx发现）

L3-5与L1-5完全一致的天数体系：

```typescript
// 起算时点：max(报告期起始日, 借款起始日)
const startDate = loanStart <= reportStart ? reportStart : loanStart;

// 截止时点：min(借款讫止日, 报告期截止日)
const endDate = loanEnd <= reportEnd ? loanEnd : reportEnd;

// 计息天数
const days = startDate === 0 ? 0
  : (endDate - startDate) === 365 ? 365
  : (endDate - startDate) + 1;

// 未付利息天数（从结息日算）
const unpaidDays = settleDate === 0 ? 0
  : (endDate - settleDate) === 365 ? 365
  : (endDate - settleDate) + 1;
```
