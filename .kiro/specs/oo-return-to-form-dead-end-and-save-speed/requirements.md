# 在线编辑回表单死路与回写提速 — Requirements

承接 2026-10-24 对 D2-2 双向回写的验证分析（用户拍板：共享层修一处、所有在线编辑底稿同时生效；P0、P1 逐项做）。

现状证据（和平药房 2025 D2，room g12）：20:55 / 21:00 两次点「保存并回到表单模式」都是 Command Service 返回码 4（`cs_error=4`），文档服务最后回 status 4（关闭且无改动），用户被困在编辑器里只能刷新页面。改过内容回表单：后端稳定时约 10 s（apply 7.25 s），后端刚热重载时约 76 s（回调等 31 个 adapter 冷注册约 36 s）。

## R1 未改动 / 无可存改动时一定能回到表单，且立即回（P0）

1. 「保存并回到表单模式」在本次会话没有编辑（桥 `dirty=false`）时直接离开在线编辑：恰一次 leave、零次强制保存、零次 close-intent，状态回 `html_idle`。
2. 有编辑时，发强制保存前先等编辑器报告改动已送达文档服务（`onDocumentStateChange` 最近一次为 `false`），有上限（默认 3 s）；记下是否确认送达。
3. 强制保存结果为「无改动」（`cs_outcome=no_changes`）：
   1. 改动已确认送达（或会话内本无未送达改动）⇒ 按后端契约「直接放行离开」：释放 lease、回到表单、`dirty` 清零，给一条普通提示（不是错误）；
   2. 未确认送达（等到上限）⇒ 留在在线编辑，编辑器可操作，`dirty` 保留，提示「改动还在发送，请稍候再保存」。
4. 冻结态（`forcesave_frozen`：命令未受理或无回调终态）不算「同步进行中」：未改动时可直接离开；编辑器不被遮挡；工具栏不显示「同步中…」；关页不弹「离开此网站」。
5. 在线编辑里每个「等用户动作、不会自己推进」的状态都有「退出在线编辑」出口（冻结、出错、冲突、需重载、折叠、仅下载终态、无接任者、关闭仲裁失权、恢复待认领）：有未保存改动先二次确认并说明后果；释放 lease（失败不阻断）；回到表单。
6. 单元格正在输入、未按回车：先实测 OnlyOffice 9.4 `requestClose()` / `onRequestClose` 的行为；能让编辑器自己提示未保存内容就接到离开路径上，不能则在 design 记录实测结论、维持现状。任何结论都不得重新挡住离开。
7. 判据：把旧死路钉成预期的判据按新语义改写（不删）；桥 / 状态机 / 宿主新判据 + 磁盘变异；浏览器实测和平药房 D2-2（只读路径）与【测试】项目（有改动路径）。

## R2 重启 / 热重载后第一次保存不等全部注册（P1-1）

1. 回调后的 apply：进程级注册缓存未建好时，不等全局冷建锁，只为本 entry 准备（源码事实、本 entry 模板结构 hash 在工作线程算，与预热共用同一次计算），再按目标底稿现绑；不得把只含部分 entry 的注册写进全局缓存。
2. 目标底稿还没有已发布版本时退回原路径。
3. HTML→OO 端点（`_registration`）同样处理，前提是逐个确认端点只用本 entry 的注册；不满足的保持原样并写明原因。
4. 现有接线判据（`router_registration_wiring_ast`）与预热语义不变。
5. 证据：预热进行中到达的回调，等待从约 36 s 降到秒级。

## R3 OO→HTML apply 去掉重复提取（P1-2）

1. P8：物化计划阶段复用三方提取里同一份 incoming 的逐 binding 结果（同 adapter 实例、同文件身份、同形态、同 binding 才复用），否则照常提取；复用结果与重新提取逐字段相同（受保护格发现除外，物化计划从不读它）。
2. P9：已发布形态的整簿提取结果跨请求缓存，键覆盖全部影响输出与门判据的输入；命中与重新提取逐字段相同；顺带填好受保护格 baseline；有界。
3. 证据：重放同一条真实 application（外层事务回滚、文件根换临时副本），apply 前后耗时对比，合并摘要与新内容版本摘要逐字节不变。

## R4 保存后先回表单、后台合并（P1-3）

1. 用户点了「保存并回到表单模式」（或从编辑器切回结构化视图）且文件已在服务端耐久（`incoming_durable` 或之后）⇒ 立即离开编辑器回到表单，表单只读，顶部横幅「正在合并在线编辑的改动」。
2. 合并完成 ⇒ 表单按结果版本重载、解除只读、释放 lease、横幅消失；冲突 / 出错 / 需重载 ⇒ 横幅给中文原因与出口（重试回写 / 刷新状态 / 关闭横幅），表单解除只读。
3. 合并期间不能再进在线编辑；关页 / 切页不弹阻断（服务端照常完成）。
4. 单点接入：页面级渲染器（只读 + 横幅）+ 持久化层（合并期间拒写），不逐个改宿主。
5. 证据：浏览器（【测试】项目）点击到回表单、点击到新值出现两段耗时。

## R5 开发环境热重载开关（P1-4）

1. `start-dev.bat` 增加可选开关关闭后端热重载（默认不变），供在线编辑验收与计时使用。
