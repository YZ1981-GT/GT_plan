## 需求

- R1 审定报表未分配利润含未结转损益：未分配利润 = 本年利润 + 利润分配 + 未结转损益（损益类科目未审期末余额 + 已批准调整 + 底稿发布调整，利润为正）。审定 / 未审 / 期初三种口径各自成立；公式里显式可见（不藏在取数里）；四套准则同改；已结账、无损益调整的账套结果不变。
- R2 重导后新出现的客户科目自动进客户科目表并自动映射（与首次导入同一入口），旧科目与手工映射不动。
- R3 2-07 / 2-08 / 2-09 / 2-10 账载金额按行标签从对应一级科目的末级明细取数：每个末级只归一行、归不进的列在「其他 / 空行」明细里；各行合计 = 一级科目借方发生额（含 R12 未结转扣减），不等时给原因。
- R4 3-03-01 税收金额默认等于账载金额（计税基础 = 原值、税收折旧 = 本年折旧、累计 = 累计），标「待确认」，可改；3-03-04 按类别取本年摊销额并默认税收摊销额 = 账载，原值 / 累计 / 计税基础留人工。
- R5 需人工判断 / 账套里没有数据的表（3-03-08、5-01-06 前十年、3-02-13、3-02-15）整表给出说明文字，告诉用户要填什么、从哪里来。
- R6 数据处理：辽宁补映射；激光（只传 3 个 SAP 文件）、ABC 重导；三个项目重算试算表、重新生成报表；全程走平台接口 / 正式工具，留底可还原。
- R7 勘误：`citar-case-chain-fetch-fixes` tasks 6.2 追加勘误（不改原记录）。

## 不改

- 审计判断类差异（餐饮收入算劳务还是其他、个税手续费返还、按摘要拆其他收益、案例 2 手工审计调整、案例 3-03-01 手工分类与税收折旧额、3-03-04 的原值 / 累计 / 计税基础）。
- 应收退货成本没有标准科目 / 报表行（国企单体 BS「其他流动资产」BS-026 无公式），激光差 12,622.30：列为待拍板，不擅自改报表模板。
- 合并报表的未结转损益（合并取数走另一套 resolver）：本次显式返回 0 并记录，不改合并口径。
