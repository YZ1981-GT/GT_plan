# 需求：账号「允许修改」开关

来源：用户 2026-11-04「做成一个修改配置，可以控制能否修改，可以放到账号权限里面加一列」。承接 `citar-table-manual-edit`（表格数据都可人工修改）。

## 需求

- R1 账号权限页（用户管理）加一列「允许修改」，管理员逐个账号开 / 关，即时保存；改动记安全审计。已有账号与新建账号默认允许（行为不变）。
- R2 关闭后，该账号不能人工修改自动生成的数据，界面不给修改入口、后端拒收（403，提示去「账号权限」开启）：
  - 税审底稿 / 汇算申报表：公式格、自动取数格（「需人工填写」的除外）、样表预置数字，含「恢复自动值」；
  - 报告正文摘录表金额、审核说明段落（改 / 删 / 恢复）、审定报表金额、单体财务报表金额；
  - 科目余额表、序时账的行修改与恢复；
  - 试算平衡表点审定数生成调整分录草稿（界面入口；调整分录页本身照常）。
- R3 关闭后照常可用：查看、导出、税审底稿手填格与「需人工填写」的取数格、表头信息、是否填报、报告日期、调整分录、科目映射、数据导入、生成报表。
- R4 别人保存过的手工值，未开通的账号保存同一张底稿时原样保留（只是不能改动它们）。
- R5 开关变化后，该账号进入项目时重新读取账号信息，不必重新登录。

## 验收

- V1 后端：未开通账号改公式格 / 自动取数格 / 恢复他人手工值 → 403；改手填格、保留他人手工值 → 200；四个只做人工修改的接口与余额表 / 序时账写接口 → 403；用户接口能改、能读回、记审计。
- V2 前端：用户管理开关只发 `allow_manual_edit`；表格组件未开通时公式格不能点开、手填格照常。
- V3 浏览器实测：管理员关掉自己的开关 → 各页无修改入口 → 打开恢复，实测后复原。
