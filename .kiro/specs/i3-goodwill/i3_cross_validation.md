## 3. DCF 模型交叉验证

### 3.1 xlsx 中 I3-7 的 DCF 公式结构（100行×16列）

**核心公式链**（每个 CGU 一组，最多 3 组并列）：

| 行 | 含义 | 公式 |
|----|------|------|
| row18 | FCF预测(Y1~Y5) | 用户输入 |
| row18 G列 | 永续期FCF | `=F18`（第5年FCF复制） |
| row19 | 折现系数 | `=1/(1+$K$23)^i` (i=1..5) |
| row19 G列 | 永续价值折现 | `=(1+H18)/((J23-H18)*(1+K23)^5)` |
| row20 | 现值 | `=FCF×折现系数` |
| N20 | DCF使用价值(PV) | `=SUM(B20:G20)` |

**解读**:
- TV = FCF₅ × (1+g) / (WACC-g)，折现到第0年 = TV/(1+WACC)⁵
- xlsx 用 `(1+H18)/((J23-H18)*(1+K23)^5)` 合并了 TV计算+折现
- 其中 H18 = 永续增长率g，J23 = WACC(税后)，K23 = WACC(税前)

### 3.2 WACC 计算（I3-7 row23）

| 参数 | 列 | 公式 |
|------|----|----|
| 所得税率 | B23 | 用户输入 |
| 债务总额占比 | C23 | 用户输入 |
| 权益总额占比 | D23 | 用户输入 |
| 债务成本Kd | E23 | 用户输入 |
| 无风险报酬率Rf | F23 | 用户输入 |

### 3.3 md 模板描述的 DCF

md `I3-9 可收回金额测试` 提供了:
- 公允价值减去处置费用净额的表格结构

## 4. CGU 分摊逻辑交叉验证

### 4.1 xlsx I3-6 减值分摊公式（row20~row26）

**两步分摊法**:

| 步骤 | 含义 | xlsx公式 |
|------|------|---------|
| H25 | 第一步：先冲商誉 | `=E25`（商誉账面=全额冲减） |
| G26 | 减值总额 | `=E26-F26`（账面合计-可收回金额） |
| H21~H24 | 第二步：剩余按比例分摊 | `=($G$26-$H$25)/SUM($E$21:$E$24)*Ei` |

其中:
- E25 = 商誉账面价值
- E21~E24 = 各其他资产账面
- G26 = 总减值损失
- H25 = MIN(总减值, 商誉) → 先冲商誉至零
- 剩余 = G26 - H25 → 按 Ei/ΣEi 比例分摊到其他资产

**关键约束**: 
- `I22=H22+$H$21/SUM($E$22:$E$24)*C22` → 二次分配考虑了未确认少数股东部分
- 商誉冲减后 J25=E25-I25=0（商誉净值归零）

### 4.2 md 描述

md `I3-8 商誉减值测试` 仅提供简化表格:
> | 商誉来源 | 账面价值 | 可收回金额 | 减值准备 | 审计评价 |

md 未详述两步分摊公式，但 xlsx 附注提示明确:
> "①为资产的公允价值减去处置费用后的净额；②资产预计未来现金流量的现值"

**验证结论**: ✅ 逻辑一致，**分摊公式以 xlsx 为准**
- 核心铁律: 先冲商誉至零 → 剩余按账面比例分摊 → 不可转回
- md 提供审计目标/程序框架，xlsx 提供精确公式

## 5. 减值测试核心公式验证

### 5.1 可收回金额 = MAX(公允-处置费, DCF)

xlsx I3-7 N23: `=MAX(N11, N20)`
- N11 = 公允价值减处置费用后净额（Section一）
- N20 = DCF使用价值（Section二）

**与 md 编制说明第1条完全一致**: "可收回金额应当根据资产的公允价值减去处置费用后的净额与资产预计未来现金流量的现值两者之间较高者确定"

### 5.2 减值金额判定

xlsx I3-6 row14:
- I14 = `=E14-MAX(G14,H14)` → 账面-可收回金额
- J14 = `=IF(F14>0,IF(I14>0,I14,"未减值"),)` → 有账面才判定

**约束**: 减值金额 ∈ [0, 资产组账面价值]，不可为负（不可转回）

## 10. 开发注意事项

1. **Sheet编号映射**（开发用xlsx编号）:
   - I3A=程序表, I3-1=审定表, I3-2=明细表, I3-3=调整分录
   - I3-4=入账价值, I3-5=针对性检查, I3-6=减值测试, I3-7=可收回金额DCF, I3-8=复核过程
   - 附注披露=无独立索引号（上市+国企两版）

2. **DCF引擎实现要点**:
   - 折现系数: `1/(1+WACC)^i` (i=1~5)
   - 永续价值折现: `(1+g)/((WACC-g)*(1+WACC)^5)` × FCF₅
   - WACC(税后): `(D*Kd*(1-T) + E*Ke) / (D+E)`
   - WACC(税前): `WACC(税后) / (1 - T - extraRate)`
   - Ke(CAPM): `Rf + β*(Rm - Rf)`

3. **减值分摊引擎实现要点**:
   - Step1: goodwillImpairment = MIN(totalImpairment, goodwillBookValue)
   - Step2: remainder = totalImpairment - goodwillImpairment
   - Step2分配: assetImpairment_i = remainder × (assetBookValue_i / ΣassetBookValues)
   - 约束: 每项资产减值后净值 ≥ MAX(公允-处置费, 使用价值, 0)

4. **I3-7 为每个CGU独立一组**（最多3组并列），每组独立WACC参数
