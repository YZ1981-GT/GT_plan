承接 `citar-layout-full-port`（版式已移植，页面为静态）。

## R1 左侧菜单（按图）
四组，组标题小字灰色，菜单项带图标，选中项浅紫圆角底 + 紫色加粗：
- 数据导入与账务查询：数据导入、账务查询
- 试算平衡与报表：试算平衡表、调整分录、审定报表、报表分析
- 税审底稿：底稿映射、税审底稿（按图上手写批注替换「底稿目录 / 科目映射 / 底稿填报」）
- 鉴证报告：纳税申报表、税审报告
报表分析 / 纳税申报表 / 税审报告平台暂无对应功能，显示待开发页。

## R2 数据导入（接真实导入流程）
上传 → 预检识别 → 列映射确认 → 提交作业 → 进度 → 完成；复用平台导入的校验规则（致命错误拦截、年度置信度确认、规模警告强制继续、关键列必须映射）；按项目审计年度导入；完成后进「账务查询」。

## R3 账务查询（未审，真实数据）
- 科目余额表：本项目当年导入的客户科目余额（期初方向 / 期初余额 / 本期借贷 / 期末方向 / 期末余额），可按编码或名称搜索，点科目进入该科目序时账
- 序时账：全年分录分页（日期、凭证号、摘要、科目、借贷），可按科目过滤
- 资产负债表 / 利润表：按试算表未审数读时计算

## R4 试算平衡表（真实数据）
- 审定科目余额表：期初 / 本期借贷 + 借贷方审计调整 / 调整后期末，标准科目口径，只列有数的科目
- 底稿取数余额表：全部标准科目（含零行），期初、本期借贷、调整后期末 —— 即底稿取数读的口径
- 可触发「重算试算表」

## R5 调整分录（真实增删改 + 复核流程）
列表、新建（多借多贷、科目编码选择带出名称、借贷平衡才可保存）、编辑 / 删除（仅草稿与驳回）、提交复核、通过、驳回（填原因）、撤回复核；导出汇总 Excel。只有已批准的分录进入试算表（平台既有规则）。

## R6 审定报表
资产负债表、利润表取平台已生成报表；未生成时提示并提供「生成报表」。

## R7 底稿映射
客户科目 → 标准科目映射：完成率、映射列表、自动匹配、手工改映射、有余额未映射科目清单。
