## 一、源模板披露逻辑梳理

### 1.1 上市公司披露表（10 段，五层递进）

| 层 | 段 | 内容 | 披露意图 |
|----|----|------|---------|
| 规模·结构 | ① 按账龄 | 1年以内（含 `0-X个月`/`X-Y个月` 细分 + `1年以内小计`）/1至2/2至3/3至4/4至5/5年以上 → 小计 → 减坏账 → 合计 | 回收期限结构 = 信用风险的时间维度 |
| 业务实质 | ② 按款项性质 | 备用金 / 保证金、押金 / 可无限量添加；期末数与上年年末数各 3 列（账面余额-坏账准备=账面价值） | 揭示"其他应收款"这个混杂科目的真实构成 |
| 减值计量 | ③ 坏账准备计提情况 | **6 张表**：期末第一/二/三阶段 + 上年年末第一/二/三阶段；每表按「单项计提 / 组合计提」双轨列示，列＝账面余额·ECL率·坏账准备·账面价值·理由 | 15号文第十九条（四）5：分三阶段披露 + 各阶段划分依据 + 计提比例 |
| 减值变动 | ④ 本期计提、收回或转回 | 三阶段滚动矩阵（期初→阶段迁移→计提/转回/转销/核销/其他→期末）+ 重大转回逐笔（单位·转回原因·收回方式·原确定依据·金额） | 把"存量"打通到"流量"，解释减值增减动因 |
| 终局处理 | ⑤ 本期实际核销 | 汇总表（项目·核销金额）+ 重要核销逐项（性质·原因·履行程序·是否关联交易） | 15号文（四）6：重要项逐项，关联交易单独 |
| 集中度 | ⑥ 前五名 | 单位·性质·期末余额·账龄·占比%·坏账准备 | 集中度风险 |
| 特殊列报 | ⑦ 资金集中管理 | 金额 + 文字（解释15号：可增设"应收资金集中管理款"） | 与"非经营性资金占用专项说明"联动 |
| 特殊性质 | ⑧ 应收政府补助 | 逐项：发文单位·补助项目·期末余额·账龄·预计收取时间/金额/依据 | 信息披露解释性公告2号 |
| 表外化 | ⑨ 转移终止确认 | 项目·转移方式·终止确认金额·相关利得或损失 | 金融资产转移 |
| 表外化 | ⑩ 继续涉入 | 资产：/资产小计 · 负债：/负债小计 + 说明 | 未全部终止确认的关系披露 |

**贯穿逻辑**：账龄（时间）→ 性质（业务）→ 阶段（信用风险）三个正交维度对同一余额切片，
三者合计必须互等且等于 K1-1 审定数；④ 的期末余额必须等于 ③ 三阶段坏账合计；
⑤ 核销与 ④「本期核销」行互等；⑥ 占比分母 = ① 小计。

### 1.2 国企披露表（8 段，先分类后明细）

| 段 | 内容 | 与上市差异 |
|----|------|-----------|
| 账龄 | 1年以内(含1年)/1至2/2至3/3至4/4至5/5年以上 → 小计 → 减坏账 → 合计（期末/期初） | 无 1 年以内月度细分 |
| 按计提方法分类 | 期末余额表 + **续：期初余额表**；列＝账面余额(金额·比例%)·坏账准备(金额·预期信用损失率%)·账面价值 | 上市无此维度（上市按阶段组织） |
| ① 单项计提明细 | 债务人·账面余额·坏账准备·ECL率·计提理由 | 上市并入三阶段表内子行 |
| ② 组合计提 | **账龄组合**（期末/期初各：账面余额金额·比例%·坏账准备）+ **其他组合**（组合名称·账面余额·计提比例%·坏账准备，期末/期初） | 上市无独立组合明细表 |
| — 坏账准备三阶段变动 | 与上市 ④ 同构（一张） | 上市另有上年年末 3 张阶段快照 |
| — **账面余额三阶段变动** | 期初→阶段迁移（带【正数】【负数】方向提示）→本期新增/终止确认/其他→期末 | **国企特有** |
| ③ 收回或转回 | 债务人·转回或收回金额·**转回或收回前累计已计提坏账准备金额**·原因方式 | 该"累计已计提"列上市无 |
| ④ 核销 / ⑤ 前五名 / ⑥ 转移终止确认 / ⑦ 继续涉入 / ⑧ 政府补助 | 结构同上市，列名口径为"其他应收款项" | 无"资金集中管理"（国企附注独立成 §八、8） |

## 三、需求

### R1 底稿·上市披露表补全至源模板 10 段
- **R1.1** 账龄表在 `1年以内` 之下渲染两条可编辑月度细分行（默认 `其中：0-6个月`/`7-12个月`，标签可改）+ 只读 `1年以内小计`；细分行不参与 `小计` 求和，但须校验「细分合计 = 1年以内」并给出差异提示。
- **R1.2** 新增「上年年末处于第一/二/三阶段的坏账准备」3 张表，结构与期末三阶段完全一致。
- **R1.3** 期末 / 上年年末第二阶段各提供「本公司不存在处于第二阶段的应收利息、应收股利和其他应收款」开关；开启后表格折叠为标准语句并同步为附注文字。
- **R1.4** 新增 2 个说明文本框：`账面余额显著变动情况`、`坏账准备计提金额及信用风险显著增加评估依据`；均带 AI 辅助按钮。
- **R1.5** 新增 ⑨ 转移终止确认表（项目·转移方式·终止确认金额·相关利得或损失 + 合计）与 ⑩ 继续涉入表（可多行，分资产/负债两区 + 小计 + 说明文本框）。
- **R1.6** 核销段增「说明」文本框；政府补助段增源模板红字方法论提示（琥珀色左边线块）。
- **R1.7** ④ 三阶段矩阵改两级表头（第一/二/三阶段 + 二级释义），并对「本期转销」行按源模板置灰仅合计可填。
- **R1.8** 所有可编辑金额单元格改用 `composables/wpAmountInput` 千分符输入；只读金额走 `displayPrefs.fmtAmount()`。比率/占比列不得套用金额格式。

### R2 底稿·国企披露表补全至源模板 8 段
- **R2.1** 新增「其他组合」表（组合名称·账面余额·计提比例(%)·坏账准备，期末/期初），支持动态增删行；新增行须 `ElMessageBox.prompt` 先输入组合名称。
- **R2.2** 转回表增 `转回或收回前累计已计提坏账准备金额` 列并可编辑。
- **R2.3** 前五名 / 转回 / 核销 / 政府补助 / 转移 由只读改为可编辑（保留「自动」标签标识取数来源，人工改动后清除标签）。
- **R2.4** 新增 2 个说明文本框（账面余额显著变动 / 计提依据），带 AI 辅助。
- **R2.5** 账龄组合表补「期初比例(%)」列。
- **R2.6** 转移表按国企源模板去掉「转移方式」列（改为债务人名称·终止确认金额·与终止确认相关的利得或损失，损失以「-」填列）。
- **R2.7** 继续涉入改可多行（资产区/负债区 + 各自小计 + 说明文本框）。
- **R2.8** 账面余额三阶段变动表补源模板【正数】/【负数】方向提示（列 tooltip），并对方向异常单元格标红。
