## Notes

- 本 spec 为纯数据交付（28 个 .md 文件 + 1 个验证脚本），零服务/路由/前端代码变更
- ReviewPromptService 的文件发现机制自动支持新文件——放入正确路径即生效
- 源内容从 `backend/data/tsj_review_prompts/货币资金提示词.md` 抽取重组
- 骨架共享：盘点类(E1-7/8/9) 共享 ≥3 个 checklist 项、截止类(E1-21/22) 共享 ≥3 个、IPO/舞弊(E1-26~32) 共享 ≥3 个
- 核心 sheet(E1-1/6/14) 各自包含 ≥10 个 checklist 项
- 验证脚本可挂 CI（governance-checks.yml）但非本 spec 范围
- 端到端验证（batch-review API 调用）需后端运行，属手动验证
