# 需求：单体财务报表「其他问题」跳到数据源头并定位到行

用户 2026-11-04：「点击问题的时候，能否跳转到数据源头以及定位到行级别」。
上一轮已能把问题定位到本页报表的页签 / 行（`notice_targets` / `checks[].targets`）；本轮往上追到产生问题的源头数据行。

现状核对（ABC餐饮_2025，只读探针）：期末「资产总计 − 负债和所有者权益总计」= −11,340.42。资产负债类科目自身相平；
差额全部来自科目余额表末级科目 5801「以前年度损益调整」本期借方 −11,340.42（映射到 6901），序时账里该科目没有分录；
其余 239 个末级科目余额表发生额与序时账一致，序时账自身借贷相平。

## R1 不平校验拆出差额来源
1. 资产负债表期末 / 上年年末不平时，后端把差额拆成若干来源，每项带金额（对差额的影响，资产 − 负债和所有者权益口径）与源头行：
   - 科目余额表本身借贷不平：余额表本期发生额与序时账逐科目比对（定位到客户科目行）；序时账自身借贷不平；序时账里有余额表没有的科目；
     余额表行内期初 + 借方 − 贷方 ≠ 期末；余额表期初合计不为 0；没有序时账时只指到科目余额表页并写明借贷合计
   - 有余额未映射的客户科目 → 底稿映射该行
   - 试算表审定数（或期初）与余额表 + 调整不一致（未重算）、底稿发布调整合计不为 0 → 试算平衡表该标准科目行
   - 已批准调整分录借贷合计不等 → 调整分录页
   - 标准科目没进（或重复进）资产负债表项目 → 试算平衡表该行
   - 损益类科目有期初余额（上年未结转）→ 试算平衡表该行
   - 本页手工修改 → 本页该格
2. 各项金额之和 = 差额；拆不尽的部分单列「其余差额未能定位」，不硬凑。每类最多列 20 行，多出的写明还有几行。
3. 受限成员（只看分配循环的科目）不拆：报表本来就不全。导出 Excel 不拆。

## R2 点来源跳到源头页并定位行
1. 科目余额表（账务查询）：滚到该客户科目行并高亮，清掉会挡住它的筛选；另给「序时账」按该科目筛选。
2. 底稿映射「客户科目 → 标准科目」页签：滚到该客户科目行（有余额未映射表或已映射表）。
3. 试算平衡表：滚到该标准科目行；审定科目余额表不列零余额行时切到底稿取数余额表。
4. 本页手工修改：沿用本页定位。
5. 源头页找不到该行时提示原因，不静默。有未保存的修改时离开本页先确认。

## R3 提示类问题的源头（页级）
- 「利润表上期金额为空」「本年度还没有试算表数据」→ 数据导入页；企业会计准则格式「报表尚未生成」→ 审定报表页（取代原来按文字判断的按钮）。
