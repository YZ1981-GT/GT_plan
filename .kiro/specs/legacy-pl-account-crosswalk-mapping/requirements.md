# 旧制度损益科目自动映射到新准则 6xxx — 需求

用户 2026-11-02：「1 现在修，2 自动映射要从根上改」。

## 背景（真库现象）

重庆医药集团四川医药 / 新健康大药房临港店 2025（同一份余额表）：账务查询利润表、审定利润表全为 0。

- 平台四套报表配置（listed / soe × standalone / consolidated）的利润表公式只读新准则 6xxx 科目
  （营业收入 = `TB('6001') + TB('6051')`）；现扫 `report_config` 里引用 `TB('5xxx'` 的公式 **0 行**。
- 客户损益科目是《企业会计制度》（2001）编码：5101 主营业务收入、5401 主营业务成本、5501 营业费用……
- 标准科目表同时有一套《小企业会计准则》风格的 5xxx（5001 主营业务收入、5401 主营业务成本、5601 销售费用……）。
  `_match_single` 先按编码匹配 ⇒ 客户 5xxx 全部落到标准 5xxx，6xxx 全为 0，利润表取不到数。
- 两套 5xxx 同码不同义 ⇒ 按编码命中还会错位：5402 税金及附加 → 5402 其他业务成本、5501 营业费用 → 5403 营业税金及附加、
  5601 营业外支出 → 5601 销售费用、5801 以前年度损益调整 → 5801 所得税费用。

## 需求

R1 客户科目表是旧编码体系（《企业会计制度》或《小企业会计准则》）时，损益类一级科目及其下级按对照表映射到新准则 6xxx，
   不再按编码 / 名称去匹配标准科目表里的 5xxx。
R2 判定只看编码，不看名称（真库客户科目名整体错位，如 5101 存成「\利润分配」）：
   - 客户科目里出现任一新准则损益一级码（6001 / 6051 / 6401 / 6402 / 6601 / 6602 / 6603 / 6711 / 6801）⇒ 新准则账套，不套对照表；
   - 否则按两套体系的特征码各自计数，命中 ≥ 2 且严格多于另一套才认定；都不满足 ⇒ 不套对照表（原逻辑不变）。
R3 对照表的目标码在本项目标准科目表里不存在 ⇒ 该科目不套对照表，走原逻辑。
R4 映射页显示该匹配方式的中文名。
R5 已有的两个项目：把错映射改成对照表结果（人工改过的 `manual` 不动、列出待人工复核），备份后改，改完全量重算试算表。

## 不在范围

- 资产负债类旧编码（这份账的资产负债类已是新准则编码）。
- 成本类（新准则 5001 生产成本 / 5101 制造费用等）。
- 客户科目名错位本身（导入「上级科目名称」当科目名，导入端已改，存量名称未修）。
