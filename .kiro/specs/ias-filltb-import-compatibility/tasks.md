- [ ] 4. 分离年度/月度净额语义，修正方向与单金额

  - 方向列含义判定（科目方向 / 金额方向 / 待确认），科目方向时保留原符号；单金额+方向与带符号单金额拆到借/贷两栏；拆分后逐凭证校验借贷平衡并在回执定位。

- [ ] 6. 收口层级、父子和最近祖先口径
