## D4-1 sheet 网格（80 行 × 9 列 A~I）

### 表头（两级，合并区实证）
| 行 | 结构 |
|----|------|
| R1 | `致同会计师事务所`（A1:I1 合并，标题带） |
| R2 | `营业收入审定表`（A2:I2 合并） |
| R3~R4 | 项目抬头，`=底稿目录!Ax` 引用 + 索引号 `I3='D4-1'` |
| R5 | `项目`(A5:A6 合并) \| `本期数`(B5:E5 合并) \| `上期数`(F5:I5 合并) |
| R6 | `未审数`\|`账项调整`\|`重分类调整`\|`审定数`（本期 B~E）；同四列（上期 F~I） |

**列映射（唯一真源）**：
- A = 项目名（行标签）
- 本期：B=未审数、C=账项调整(AJE)、D=重分类调整(RJE)、E=审定数【公式】
- 上期：F=未审数、G=账项调整(AJE)、H=重分类调整(RJE)、I=审定数【公式】

→ 与前端 `D4_ADJ_VALUE_FIELDS` 六字段一一对应：
`currentUnadjusted=B, currentAje=C, currentRje=D, priorUnadjusted=F, priorAje=G, priorRje=H`；
`E/I 审定数`是派生公式列（`=SUM(本期三列)` / `=SUM(上期三列)`），**不是输入**。

### 行身份（section + 空白可扩区）
| 行 | 身份 |
|----|------|
| R7 | 段标题 `主营业务收入：`（section=main-revenue） |
| **R8:R11** | **主营业务收入 4 行空白可扩行**（E列 `=SUM(Bn:Dn)`、I列 `=SUM(Fn:Hn)`） |
| R12 | 主营 `小计` = `=SUM(B8:B11)` 等，E12=`=B12+C12+D12` |
| R13 | 段标题 `其他业务收入：`（section=other-revenue） |
| **R14:R17** | **其他业务收入 4 行空白可扩行** |
| R18 | 其他 `小计` = `=SUM(B14:B17)` 等 |
| R19 | `合计` = `=B18+B12` 等（主营小计 + 其他小计） |
| R20 | `试算平衡表数`（TB 核对行，手工/取数填入） |
| R21 | `差异数` = `E21=E19-E20`、`I21=I19-I20` |
| R22+ | 审计说明(A22)/审计结论(E22)、前五名客户(R26)、程序概述表(R28~R35)、监管提示(R36+) |

**可扩行语义**：R8:R11 / R14:R17 各是「4 行空白可扩」——不是固定行集。动态行超过 4 行时需插行（保持小计 SUM 范围随之扩展）。这与前端动态行模型（`D4-1-rows` 清单 + 按 section 分组）一致。

### 公式格（48 个，全部在 E/I/小计/合计/差异列）
- 明细行审定：`E{n}=SUM(B{n}:D{n})`、`I{n}=SUM(F{n}:H{n})`（n∈8..11,14..17）
- 小计：`B12=SUM(B8:B11)`…`E12=B12+C12+D12`；`B18=SUM(B14:B17)`…
- 合计：`B19=B18+B12`…`I19=I18+I12`
- 差异：`E21=E19-E20`、`I21=I19-I20`
- 抬头引用：`A3=底稿目录!A2` 等（跨 sheet 引用，非业务公式）

## 对 spec 实施的约束（DEC1 模板先行落地）

1. **tab 名用 `营业收入审定表D4-1`**，render/OO 定位不得写 `D4-1`。
2. **公式列 = E/I/小计/合计/差异**（共 48 格）→ 这些是 OO formula mask 要保护的公式字节；HTML/OO 双模式下由 effective definition 求值，普通值投影不得覆盖。
3. **受管输入字段 = B/C/D/F/G/H 六列**（对应 per-field 六键）+ R20 试算平衡表数。
4. **动态行区 = R8:R11(主营) / R14:R17(其他)**，可扩；插行时小计 SUM 范围联动。
5. **审定数 E/I 是派生**：`审定=未审+AJE+RJE`（`=SUM(本期三列)`）——前端/后端/OO 三处必须同定义。
