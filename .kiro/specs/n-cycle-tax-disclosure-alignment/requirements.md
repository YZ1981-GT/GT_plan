# Requirements Document

N 循环税务类披露表与附注对齐（N2 应交税费 / N4 税金及附加 / N5 所得税费用）

## Introduction

延续 `n1-deferred-tax-disclosure-template-alignment` 的做法，把 N 循环其余三个有披露 sheet 的底稿
（N2 应交税费 / N4 税金及附加 / N5 所得税费用）的**三层披露链路**对齐致同 2025 修订版源模板，
并把底稿披露表接进附注同步（这三个循环目前**完全没有同步入口**，披露数据只停在
`checklist_responses`，附注永远拿不到）。

N3 递延所得税负债无独立披露 sheet（与 N1 共节 §五、30 / §八、31，owner=N1），本 spec 不涉及。

## Glossary

| 术语 | 含义 |
|------|------|
| 变动表 vs 双期表 | 变动表 = 期初 + 本期发生 → 期末（国企 N2 口径）；双期表 = 期末 + 上期（上市 N2 口径） |
| 表名泄漏 | md 重建器把表头首格（如 `项  目`）当成表名，导致同章节多表同名 |
| 同名表覆盖 | `sub_table_data` 按表名建键，同名表互相覆盖 → 丢表（平台已知坑） |
| 无同步链路 | 组件不含 `syncToDisclosureNotes` / `sync-from-workpaper` / `scheduleAutoSync` 三者之一 |
| 章节错挂 | md 重建把利润表项目注释挂到 `chapter-03 重要会计政策` 而非 `chapter-05 项目注释` |

## Requirements

### 现状实证（2026-07-30 精读源模板 + 模板 JSON + 前端组件）

源模板权威 = `backend/wp_templates/N/{N2 应交税费,N4 税金及附加,N5 所得税费用}.xlsx`。

**六个披露组件全部是自造结构，且全部无同步链路**（探针实测：无 `syncToDisclosureNotes`、
无章节常量、无载荷构造器）：

| 循环/版本 | 源模板 | 组件现状 | 模板 JSON 现状 |
|---|---|---|---|
| N2 上市 | 1 表 3 列 `税  项 / 期末余额 / 上年年末余额` + `合  计`；说明 2 段 + 提示 1 段 | **5 列变动表**（项目/期初余额/本期计提/本期缴纳/期末余额）—— 用的是国企口径；另有自造「税种变动说明」「欠缴税款说明」 | 五、41 结构对（3 列），缺 `columns`/`guidance` |
| N2 国企 | 1 表 **5 列** `项  目 / 期初余额 / 本期应交 / 本期已交 / 期末余额` + `合  计`；提示 1 段 | 5 列但列名自造（本期计提/本期缴纳 ≠ 本期应交/本期已交）；自造「应缴国有资本收益说明」 | 八、41 **被压扁成 3 列**（项目/期末余额/期初余额） |
| N4 上市 | 1 表 3 列 `项  目 / 本期发生额 / 上期发生额` + `合  计`；说明 1 段 | **6 列**（+变动额/变动率/变动原因说明）= 自造分析列 | 五、63 结构对，缺 `columns`/`guidance` |
| N4 国企 | **`附注披露信息：无`** —— 国企版**不披露**税金及附加 | 却有整套国企披露表（6 列 + 说明文本）= **完全自造** | 无该章节（`variant_matrix` soe=None）—— 与源模板一致 ✓ |
| N5 上市 | 2 表：（1）所得税费用明细 3 列 3 行；（2）所得税费用与利润总额的关系 3 列 13 行；注 3 段 | 列头自造（`本期金额`/`上期金额`/`金额`） | `三、所得税费用`：两表**同名 `项  目`**（表头首格泄漏）；缺 `columns`/`guidance` |
| N5 国企 | 2 表：（1）3 列 4 行；（2）会计利润与所得税费用调整过程 **3 列**（本期/上期发生额）14 行动态；注 3 段 | 列头自造（`本年累计数`/`上年同期数`） | 八、78：两表**同名 `所得税费用`**；表 2 **只剩 2 列**（丢「上期发生额」） |

两个附带实证：
- **N5 国企披露 sheet 的 xlsx tab 名是 `附注披露信息（国企`（缺右括号）**，而 sheet 内 A2 写的是完整
  `附注披露信息（国企）`。`workpaper_sheet_classification` 忠实记录了缺括号版本 → 同步 `sheet_name`
  必须**逐字**用 tab 名，否则附注「打开同步底稿」会落到底稿首个 sheet。
- **N5 上市章节 `三、所得税费用` 被 md 重建错挂到 `chapter-03 重要会计政策及会计估计`**，
  内容却是利润表项目注释（应在 `chapter-05`）。同批错挂还有公允价值变动收益 / 信用减值损失 /
  资产减值损失 / 资产处置收益 / 营业外收入 / 营业外支出 / 现金流量表项目注释 —— 共 8 个章节。

### R1 N2 应交税费底稿披露表按源模板重建

1.1 **上市**：1 张表，3 列 `税  项` / `期末余额` / `上年年末余额`，末行 `合  计`（公式行）。
    行骨架 = 附注模板既有税种集合（增值税/消费税/企业所得税/个人所得税/城市维护建设税），支持动态增删行。
1.2 上市表下方保留源模板 R24~R26 说明（`（小税（费）种可合并反映。）` 与所得税抵销列示段）
    与 R27 提示，作只读方法论上下文。
1.3 **国企**：1 张表，5 列 `项  目` / `期初余额` / `本期应交` / `本期已交` / `期末余额`，
    末行 `合  计`。`期末余额` 为公式列（`=期初 + 本期应交 − 本期已交`，源模板 `=B8+C8-D8`）。
1.4 国企表下方保留 R24 增值税填列提示。
1.5 删除两版自造 section（税种变动说明 / 欠缴税款说明 / 应缴国有资本收益说明）；
    🔴 **两版列结构本质不同，禁止共用一份列定义**（现状即两版复制粘贴导致上市用了国企口径）。

### R2 N4 税金及附加底稿披露表按源模板重建

2.1 **上市**：1 张表，3 列 `项  目` / `本期发生额` / `上期发生额` + `合  计`；
    行骨架 = 附注模板既有 8 项税费（消费税/城市维护建设税/教育费附加/资源税/房产税/土地使用税/车船使用税/印花税）。
2.2 上市表下方保留 R18 说明（`各项税金及附加的计缴标准详见附注四、税项。`）。
2.3 删除自造的变动额 / 变动率 / 变动原因说明三列（变动分析属审计过程，留在 N4-1 审定表）。
2.4 **国企**：源模板明确写 `附注披露信息：无` → 国企版**不披露**税金及附加。
    国企 Tab 改为「本版不适用」说明页（说明依据 + 指向上市版），**不得**保留自造披露表，
    也**不得**为其创建附注章节（`variant_matrix` soe=None 是正确的）。

### R3 N5 所得税费用底稿披露表按源模板重建

3.1 **上市表（1）所得税费用明细**：3 列 `项  目` / `本期发生额` / `上期发生额`；
    行 = `按税法及相关规定计算的当期所得税` / `递延所得税费用` / `合  计`。
3.2 **上市表（2）所得税费用与利润总额的关系列示如下**（源模板标题带括注
    `（不适用项目可删除，"其他"金额不应过大）`）：3 列，13 行（利润总额 → … → 所得税费用），
    行骨架逐字取自附注模板；末行 `所得税费用` 是勾稽落点而非合计。
3.3 上市注 3 段（所得税费用 = 第二行至倒数第二行之和 / 对以前期间当期所得税的调整定义 /
    两个不应为负数的项目）作只读提示。
3.4 **国企表（1）**：3 列，行 = `当期所得税费用` / `递延所得税调整` / `其他` / `合  计`。
3.5 **国企表（2）会计利润与所得税费用调整过程**（源模板括注 `（国资委格式未要求披露，建议披露）`）：
    3 列 `项  目` / `本期发生额` / `上期发生额`，行骨架取自附注模板 10 项 + `合  计`，支持动态增行。
3.6 国企注 3 段同 3.3 口径。
3.7 删除两版自造列头（`本期金额`/`上期金额`/`本年累计数`/`上年同期数`）。

### R4 披露内部勾稽

4.1 N2 上市：`合  计` = 各税种之和（源模板 `=SUM(B8:B22)`）；国企四列各自求和。
4.2 N2 国企：每行 `期末余额` = `期初余额 + 本期应交 − 本期已交`（源模板 `=B8+C8-D8`），逐行校验。
4.3 N4 上市：`合  计` = 各税费之和（源模板 `=SUM(B8:B16)`）。
4.4 N5 表（1）：`合  计` = 当期所得税 + 递延所得税（源模板 `=SUM(C9:C10)`）。
4.5 N5 上市表（2）：`所得税费用` 行 = 第 2 行至倒数第 2 行之和（源模板注 1 明确要求）。
4.6 N5 跨表：表（2）的 `所得税费用` 行 = 表（1）的 `合  计`（同一金额两处列示）。
4.7 复用 N1 的 `eqCheck` 语义：容差 0.01 元、任一侧 `null` → `skip`、紧凑 bar + 折叠明细 + 规则 tooltip。

### R5 附注模板 JSON 结构修订

5.1 N2 国企 八、41 从 3 列恢复为 **5 列**（期初余额 / 本期应交 / 本期已交 / 期末余额）。
5.2 N5 两版**表名去重**：上市 `三、所得税费用` 两表由同名 `项  目` 改为
    `所得税费用明细` / `所得税费用与利润总额的关系`；国企 八、78 两表由同名 `所得税费用` 改为
    `所得税费用` / `会计利润与所得税费用调整过程`。
    🔴 表名是同步键，同名必互相覆盖丢表。
5.3 N5 国企 八、78 表 2 从 2 列恢复为 **3 列**（补回 `上期发生额`）。
5.4 全部涉及表补 `columns`（单级标 `flat`）与 `guidance`（只取源模板红字/括注/注，或以「勾稽：」
    前缀标注的工具口径）。
5.5 `text_sections` 表标题统一 `#### ` 前缀（避免被 `_is_table_title_paragraph` 当正文）；
    补齐源模板实质披露文本。
5.6 **行集合不动原则**：明细行标签保持附注模板既有集合（seed 行会被底稿整表覆盖）。
    唯一例外 = N5 国企表 2 需按源模板补回被压扁丢掉的列，不改行。
5.7 **N4 国企不新建章节**（源模板不披露）。
5.8 修订必须是幂等脚本（`--dry-run` / `--check` / `_aligned_by`），禁止手改 JSON。

### R6 同步映射与推送（这三个循环从零建立）

6.1 新建 `n2NoteSectionMap.ts` / `n4NoteSectionMap.ts` / `n5NoteSectionMap.ts`：
    章节号取自 `note_template_variant_matrix.json`（N2 五、41 / 八、41；N4 五、63；
    N5 soe 八、78；**N5 listed 用模板现存的 `三、所得税费用`**）。
6.2 `sheet_name` 逐字取自 `workpaper_sheet_classification`，收进 `X_DISCLOSURE_SHEET_NAME` 常量；
    🔴 **N5 国企是 `附注披露信息（国企`（缺右括号）**，禁写"修正"过的字面量。
6.3 `sub_table_data` 与 `columns` 键集合恒相同；子表名逐字取自附注模板 `tables[].name`。
6.4 行型判定先去空白（源模板写 `合  计`）；小计/合计打 `is_total`；取不到写 `null`。
6.5 N4 国企**不产出载荷**（`buildN4SyncPayload('soe', ...)` 返回 `null`）。
6.6 三个循环六个 Tab（N4 国企除外，共 5 个）接 `useDisclosureAutoSync` + 手动「同步到附注」按钮
    + 反向跳转 + AI 辅助 + `GtReviewTrigger`。
6.7 N5 表名变更（5.2）会使既有已同步项目产生孤儿键 → 按 `disclosureSyncedTables` 上报
    `_removed_table_keys`，并声明 `X_TABLE_NAMESPACE` 支持基线播种。

### R8 实测验收

8.2 postgres 只读比对 `disclosure_notes`：键数 / `_sub_table_columns` / `_last_sync_sheet` / `_last_sync_at`。
8.3 进程内 ASGI e2e 验 `get_note_detail` 返回的表数 / 列结构 / guidance（范式沿用 N1）。

## 非目标

- **不修 `三、所得税费用` 的章节归属**（连带 8 个利润表章节 + 既有项目 `note_section` 定位键，
  blast radius 远超本 spec）→ 记为跨 spec 依赖，本 spec 用模板现存章节号保证链路通。
- 不动 N3（无独立披露 sheet，与 N1 共节）。
- 不动 N2-2~N2-11 / N4-1~N4-3 / N5-1~N5-8 的审计过程底稿；变动分析、税种测算等留在原处。
- 不接 `applicable_standards` gating（前端全链缺失，另有记录）。
- 不做 `disclosure_notes.source_template` 生成侧口径修正（N1 spec 已在读端旁路）。
