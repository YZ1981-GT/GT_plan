# A17 重大事项概要底稿（上市公司 A 类业务）

## 背景

A17 是审计完成阶段最核心的综合性底稿——"重大事项概要"是整个审计项目的执行摘要，仅 A 类业务（上市公司/IPO/重大资产重组等）强制编制。涵盖 14 个子底稿，按功能分为：

- A17 程序表（xlsx，已有 a-program-console）
- A17-1 重大事项概要汇总（docx，核心文档，14 表+目录）
- A17-2-1 关键审计事项 KAM（docx，5 表结构化）
- A17-3/3-1 业务咨询记录（docx，弹窗）
- A17-4 重大专业分歧事项记录（docx，弹窗）
- A17-5-1~5-5 审计工作完成核对表（xlsx，5 个，共 770 行）
- A17-6 总结会会议纪要（docx，弹窗）
- A17-7/7A 独立性声明书（doc，已有 independence-signing）

## 适用条件

- `applicable_categories: ["A"]`（仅 A 类业务强制）
- B 类业务可选（部分程序适用），C 类不适用
- 程序表 A17 中各步骤按 business_category 自动判定适用性

## 需求

### 1. A17-3/3-1/4/6 — 弹窗模式（适用时弹出）
- 加入 WpPopupDocxEditor 配置
- 弹窗中提供使用说明 + 预填充下载 + OnlyOffice 在线编辑
- 程序表 chip 点击时弹窗展示
- **适用时才生成**：当程序表对应步骤标为"适用"时，弹窗引导用户编辑

### 2. A17-5-1~5-5 — 核对表模式
- 按 business_category 选择适用版本：
  - 财报审计（A17-5-1）：所有项目必做
  - 内控审计（A17-5-2）：整合审计项目
  - IPO 特别程序（A17-5-3）：IPO 项目
  - 新三板特别程序（A17-5-4）：新三板项目
  - 函证程序（A17-5-5）：所有项目推荐
- componentType = `checklist-table`（复用已有组件）
- 206 行核对表支持搜索、批量标记、进度统计

### 3. A17-7/7A — 独立性签署（HTML 组件增强）
- 已有 `independence-signing` componentType（HTML 组件）
- 增强：每个项目组成员弹出**独立性确认弹窗**（逐条确认：利益冲突/近亲属/持有证券等）
- 确认结果自动汇总到声明书正文"我们确认..."段落
- 与 B3 独立性了解底稿联动（B3 识别潜在利益→该成员卡片标红预警）

### 4. A17-1 重大事项概要汇总 — 章节导航式 HTML 组件（核心）
- componentType = `a17-summary`（HTML 组件，非 OnlyOffice Word 编辑）
- **设计原则：编辑时结构化 HTML，交付时生成 Word**（与附注编辑器 DisclosureEditor 同一思路）
- 章节结构（10+ 章，从模板目录提取）：
  1. 审计业务约定范围及执行情况
  2. 独立性
  3. 对审计计划的更新和修改
  4. 前任注册会计师的审计报告
  5. 重大职业判断
  6. 重大错报风险
  7. 舞弊
  8. 关键审计事项（引用 A17-2-1）
  9. 持续经营（引用 A15）
  10. 与治理层/管理层的沟通
  11. 其他重大事项

- **每章节功能**：
  - 左侧目录导航（点击跳转）
  - **提示栏**（折叠面板，灰色/蓝色底）：显示该章节的编制说明、准则要求、填写指引——不导出
  - 正文编辑区（用户实际填写的内容——导出到 Word）
  - "从关联模块拉取"按钮（一键从对应底稿提取数据填充该章节）
  - "AI 辅助生成"按钮（调 LLM + 知识库 RAG 生成该章节初稿）
  - 引用标记（显示数据来源底稿编码）

- **文字内容分类规则**（致同模板通用）：
  | 类型 | 识别方式 | 编辑时展示 | 导出处理 |
  |------|----------|------------|----------|
  | 提示性/说明性 | 蓝色字体 / 【注：...】/ 模板原文说明 | 提示栏（折叠面板） | **不导出** |
  | 需用户修改的 | 红色字体 / XX/201X 占位符 | 正文区高亮提示"需修改" | 替换后导出 |
  | 固定正文 | 黑色字体 | 正文区（不可编辑/仅格式参考） | 原样导出 |
  | 用户填写的 | 输入框/textarea | 正文编辑区 | 导出 |

- **章节数据来源映射**：
  | 章节 | 自动取数来源 | LLM 辅助 |
  |------|-------------|----------|
  | 约定范围 | 项目信息表 + B10 了解 | 格式化输出 |
  | 独立性 | A17-7 签署状态 | - |
  | 计划更新 | B40~B50 风险底稿变更记录 | 差异总结 |
  | 重大判断 | 各循环底稿审计说明 | 摘要提炼 |
  | 错报风险 | B40 风险评估表 | 格式化输出 |
  | 舞弊 | issue_tickets(fraud) + A14 | 总结生成 |
  | KAM | A17-2-1 结论 | - |
  | 持续经营 | A15 评估结论 | - |
  | 沟通 | A10 沟通记录 | 摘要 |
  | 其他 | A17-3/4 咨询/分歧记录 | - |

### 5. A17-2-1 关键审计事项(KAM) — 结构化表单
- componentType = `kam-workpaper`
- 5 个结构化表格：
  1. KAM 识别过程（从重大风险领域筛选）
  2. 在审计报告中沟通的 KAM 事项列表
  3. 每个 KAM 的描述（基本情况 + 认定原因 + 审计应对）
  4. 描述语言审核（措辞检查清单）
  5. 与治理层沟通确认
- **与审计报告联动**：KAM 描述自动同步到审计报告正文"关键审计事项"段落
- **LLM 辅助**：根据风险描述 + 审计程序 + 知识库中同类 KAM 案例，生成 KAM 描述初稿
- **蓝色提示文字**：编制指引（导出时删除）

### 6. Word 导出
- A17-1：从结构化数据生成完整 Word（按目录章节组装）
- A17-2-1：从表单数据填充模板（不适用 KAM 删除对应行）
- 通用规则：蓝色提示删除、红色占位符替换、注释表格删除

## LLM 集成要求

- 使用 `llm_client.chat_completion()`（httpx + 熔断器）
- RAG 上下文：从知识库检索同行业/同类型的 KAM 案例、重大事项概要范例
- 提示词模板存放 `backend/data/wp_llm_prompts/a17/`
- 生成结果为"建议稿"，用户可修改后采纳
- 生成时传入：项目信息 + 相关底稿摘要 + 知识库检索结果

## 关联模块

- A10 与治理层沟通（沟通记录来源）
