## 1. 权益类方向验证 ✅ 一致

### xlsx 实际公式（审定表M2-1，49×12）

审定表M2-1结构 49×12，129公式，关键公式：
- `J7=I7-E7`（变动额=期末审定-期初审定）
- `K7=IF(AND(E7=0,J7=0),0,IF(AND(E7=0,J7>0),1,J7/E7))`（条件变动率）
- `A7='明细表（非上市公司）M2-2'!A13`（出资人名称引用明细表）
- `B7='明细表（非上市公司）M2-2'!C13`（期初数引用明细表）
- `G7='明细表（非上市公司）M2-2'!J13+'明细表（非上市公司）M2-2'!L13-'明细表（非上市公司）M2-2'!M13`

**权益类贷方方向体现**：
- 科目4001实收资本/股本为**贷方/权益类**
- G列公式`=J+L-M`表示：**期末调整=贷方发生(J+L)-借方发生(M)**，即增资在贷方、减资在借方
- 明细表非上市版T列公式 `T13=P13+R13-S13` → **审定期末=未审期末+贷方调整-借方调整**
- 明细表上市版K列公式 `K13=D13+F13-J13` → 某一维度：**本期末=期初+本期增加-减少小计**

### md 业务逻辑

> M2A程序表："获取或编制实收资本明细表，复核加计正确，并与总账数和明细账合计数核对是否相符"
> 
> M2-5检查表提示："审阅公司章程、股东（大）会、董事会会议记录中相关规定。收集与所有者权益账户变动有关的董股东（大）会决议、事会会议纪要、合同、协议、公司章程及营业执照，公司设立批文、**验资报告**以及政府主管部门、财政部门批复、资产评估报告等文件资料"

md明确实收资本为所有者权益科目，增资时**贷方增加**（贷记实收资本），减资时**借方减少**（借记实收资本）。

### 验证结论

| 维度 | xlsx | md | 一致性 |
|------|------|-----|--------|
| 科目方向 | 贷方/权益类 | 贷方/权益类（所有者权益） | ✅ |
| 期末公式 | 期末=期初+贷方(增资)-借方(减资) | 增资贷记增加,减资借记减少 | ✅ |
| 审定数 | 审定表数据全部引用明细表 | 明细汇总=审定表 | ✅ |

**确认实现公式**：`calcEquityEndBalance(begin, credit, debit) = begin + credit - debit`

- J~O: AJE/RJE(J=AJE增, K=AJE减, L=RJE增, M=RJE减, N=..., O=...)
- P~Q: 审定期初(P=`C+J+K`, Q=比例)
- R~S: 审定贷方/借方(R=`E+L+N`, S=`G+M+O`)

## 4. 外币投资折算验证 ✅ 一致

### xlsx 实际公式（外币投资汇率测算表M2-4，20×7）

列结构（从header_rows+公式推断）：
- A: 投资者
- B: 币种
- C: 原币金额
- D: 折算汇率
- E: 折合人民币 = **C×D**（`E10=C10*D10`, ..., `E15=C15*D15`）
- F: 账面数（用户输入）
- G: 差额 = **E-F**（`G10=E10-F10`, ..., `G15=E15-F15`）
- 合计行：`C16=SUM(C10:C15)`, `E16=SUM(E10:E15)`, `F16=SUM(F10:F15)`, `G16=SUM(G10:G15)`

共23个公式（含7个header引用）→ **16个calc公式**（6×E + 6×G + 4×SUM）

### md 业务逻辑

> "投资者 | 币种 | 原币金额 | 折算汇率 | 折合人民币 | 账面数 | 差额"
> "1.实收资本以恰当的金额包括在财务报表中，与之相关的计价或分摊调整已恰当记录，相关披露已得到恰当计量和描述。"

md列名与xlsx完全对应。md还在M2A程序表中明确："检查外币投资汇率测算"→索引M2-4。

### 验证结论

| 维度 | xlsx公式 | md描述 | design定义 | 一致性 |
|------|----------|--------|-----------|--------|
| 折算本位币 | E=C×D | 原币金额×折算汇率=折合人民币 | calcFxConverted(amt,rate)=amt×rate | ✅ |
| 折算差异 | G=E-F | 折合人民币-账面数=差额 | calcFxDiff(conv,booked)=conv-booked | ✅ |
| 合计 | SUM(range) | 合计行 | calcSubtotal(arr)=Σarr | ✅ |

**确认实现公式**：
- `calcFxConverted(amount, rate) = amount × rate`（xlsx: E=C*D）
- `calcFxDiff(converted, booked) = converted - booked`（xlsx: G=E-F）

**列名映射（xlsx列名权威）**：

| xlsx列名 | design变量名 | 备注 |
|----------|-------------|------|
| 投资者 | investor | A列（与M1的"股本名称"不同） |
| 原币金额 | amount | C列 |
| 折算汇率 | rate | D列 |
| 折合人民币 | converted | E列（计算值） |
| 账面数 | booked | F列（用户输入） |
| 差额 | diff | G列（计算值） |

**ADR-4确认**：外币出资折算差异计入资本公积（M4），md未直接说明此联动（M2-4仅计算差额），但xlsx的M2-4也无跨工作簿引用M4。联动方向以design为准：M2-4折算差异→M4资本公积（通过EventBus/GtIndexChip实现）。

- `C7='明细表（非上市公司）M2-2'!J13`（AJE调整）
- `D7='明细表（非上市公司）M2-2'!K13`
- `E7='明细表（非上市公司）M2-2'!P13`（审定期初）
- `F7='明细表（非上市公司）M2-2'!H13`（未审期末）

**重要发现**：审定表M2-1默认引用**非上市公司版**明细表。上市公司版附注单独引用上市明细表。

### 设计影响

| 场景 | xlsx默认 | design处理 |
|------|----------|-----------|
| 审定表引用 | 引用非上市版 | 根据分支选择器动态切换引用源 |

**决策**：xlsx模板中审定表默认引用非上市版是因为模板预设。在系统实现中，审定表应根据用户选择的分支（上市/非上市）动态引用对应明细表的合计数据。

## 8. 最终确认公式模式（实现依据）

### useM2FormulaEngine.ts（权益类！）

```typescript
// P1: 审定数 = 未审 + AJE + RJE
calcAuditedAmount(unadj, aje, rje) = unadj + aje + rje

// P2: 权益类期末余额（贷方科目！增资贷方增加，减资借方减少）
calcEquityEndBalance(begin, credit, debit) = begin + credit - debit
// xlsx验证：非上市T=P+R-S, 上市K=D+F-J, AF=Y+AE

// P7: 分类小计
calcSubtotal(arr) = Σarr  // SUM(range)

// 变动额 = 期末审定 - 期初审定
calcVarianceAmount(endAudited, beginAudited) = endAudited - beginAudited  // xlsx: J=I-E

// 变动率 = 条件除法
calcVarianceRate(beginAudited, varianceAmount) =
  if (beginAudited === 0 && varianceAmount === 0) return 0
  if (beginAudited === 0 && varianceAmount > 0) return 1
  return varianceAmount / beginAudited  // xlsx: K=IF(AND(E=0,J=0),0,IF(AND(E=0,J>0),1,J/E))
```

### useM2FxEngine.ts（纯函数）

```typescript
// P3: 折算本位币 = 原币金额 × 折算汇率
calcFxConverted(amount, rate) = amount × rate  // xlsx: E=C*D

// P4: 折算差异 = 折算本位币 - 账面数
calcFxDiff(converted, booked) = converted - booked  // xlsx: G=E-F
```

### useM2VerifyEngine.ts（纯函数）

```typescript
// P5: 验资差异 = 实缴出资 - 验资金额
calcVerifyDiff(paid, verified) = paid - verified

// P6: 出资到位率 = 实缴出资 / 认缴出资（subscribed≠0）
calcPaidInRate(paid, subscribed) = paid / subscribed  // xlsx: G20=G18/G19
```

## 10. 与M1对比确认的共性模式

M2与M1（应付股利）同属M权益循环，对比确认以下共性：

| 模式 | M1(负债类) | M2(权益类) | 差异 |
|------|-----------|-----------|------|
| 科目方向 | 贷方/负债 | 贷方/权益 | 公式相同(期末=期初+贷-借) |
| 外币测算表 | M1-4(25×7) | M2-4(20×7) | 列结构完全相同 |
| 检查表 | M1-6(36×16) | M2-5(27×18) | M2多验资核对 |
| 明细表 | M1-2单版本 | M2-2双版本(上市/非上市) | M2更复杂 |
| 调整分录 | M1-3(23×10) | M2-3(23×10) | 结构完全相同 |
| 附注 | 双版本(上市/国企) | 双版本(上市/国企) | 相同模式 |

**结论**：M2的外币折算引擎(useM2FxEngine)与M1的(useM1FxEngine)公式完全相同，仅列名从"股本名称"变为"投资者"。验资核对引擎是M2的独特增量。
