# J 类底稿（职工薪酬循环）— 需求文档

## 1. 概述

J 类底稿覆盖"实质性程序—职工薪酬循环"阶段（审计循环代号 J），根据 B50 风险评估结果和 C10（职工薪酬）控制测试结论，执行实质性程序。包含 **3 个科目、3 个模板文件、约 20+ 个子底稿 sheet**。

J 类特殊性：J2（设定受益计划净资产）涉及精算假设（会计估计），需要评估精算师工作。J3（股份支付）涉及期权定价模型。

## 3. 术语表

- **职工薪酬循环系统（Employee_Compensation_System）**：平台中负责 J 类底稿的子系统
- **设定受益计划（Defined_Benefit_Plan）**：企业承担精算风险和投资风险的养老金计划（J2）
- **精算假设（Actuarial_Assumptions）**：设定受益计划中使用的折现率、工资增长率等假设
- **股份支付（Share_Based_Payment）**：以股权结算或现金结算的员工激励（J3）

## 5. 各组详细需求

### J1: 应付职工薪酬
**需求：** J1A程序表 + J1-1审定表 + J1-2明细（工资/奖金/社保/公积金/福利分类）+ J1-3工资测算 + J1-4社保测算 + J1-5分析 + J1-6检查 + J1-7个税验证 + J1-8调整分录
- J1-3 工资测算（人数×平均工资×月份）→`audit-sheet`
- J1-4 社保测算（基数×比例）→`audit-sheet`

### J2: 设定受益计划净资产（会计估计）
**需求：** J2A程序表 + J2-1审定表 + J2-2明细 + J2-3精算假设评估 + J2-4精算师工作利用 + J2-5精算重新计算 + J2-6调整分录
- J2-3 精算假设评估（折现率/工资增长率/离职率/死亡率）→`d-form-table`
- J2-4 利用精算师工作（评估胜任能力/客观性/工作范围）→`d-form-table`
- J2-5 精算重新计算含复杂公式（DBO 精算现值/计划资产公允价值）→`audit-sheet`

### J3: 股份支付
**需求：** J3A程序表 + J3-1审定表 + J3-2明细 + J3-3授予条件检查 + J3-4公允价值测算 + J3-5等待期费用分摊 + J3-6调整分录
- J3-4 期权公允价值测算（Black-Scholes/二叉树模型）→`audit-sheet`
- J3-5 等待期费用分摊（总公允价值/等待期×已服务月份）→`audit-sheet`
