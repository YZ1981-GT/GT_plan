## 1. 财务报表

### 1.1 模板行绑定（新模块 `report_template_binding.py`）
- `template_row_labels(template_key)`：读模板 xlsx（按文件 mtime 缓存），对 `{{row:CODE:…}}` / `{{eq:CODE:…}}` / `{{imp:CODE:…}}`
  取同行左侧最近的非占位文字为行名，得 `TemplateLabel(code, family, label, key, markers, order)`。
- `normalize_row_label(text) -> (key, markers)`：去空白（含全角空格）、统一括号与破折号、去引号；去序号前缀（一、/（一）/1./1、/①）、
  去「其中：/加：/减：」前缀、去「（…填列）」「（或股本）」类括注后缀；△▲#* 单独作为 markers。
- `bind_rows_to_template(rows, labels) -> BindingResult`：按编码前缀分族（BS/IS/CFS/CFSS/EQ/IMP），依次：
  ① 同编码且 key、markers 相同；② 同族 key+markers 唯一匹配；③ 同名多行按模板出现序 ↔ 库内 row_number 序配对。
  编码相同但行名不同 → 记 `code_conflict`，不取数。结果 `index: {模板编码: 行副本(db_row_code)}`、`unresolved`、`unbound_rows`、`method_counts`。
- 导出器 `load_bound_report_index(...)` 统一入口：导出填充、母公司个别列（对母公司单体行同样绑定）、差异检测 `_compute_expected` 都调用它。

### 1.2 导出器修正（`report_excel_exporter.py`）
- 报表类型别名：`impairment_provision` 与 `asset_impairment` 同义；`REPORT_TYPE_SHEET_NAMES` 的权益表 / 减值表匹配改为多关键词
  （所有者权益变动表 / 股东权益变动表 / （或所有者）权益变动表；资产减值准备情况表）；manifest `sheet_aliases` 补齐四变体。
- 合并变体的「母公司」权益 / 减值 sheet：`{{eq}}` / `{{imp}}` 取母公司个别绑定索引。
- 表头：`{{period_end_date}}` 按 sheet 族替换（资产负债表 = 审计期末日期，其余 = 「YYYY年度」）；表头区（前 4 行）写死的「YYYY年度」按所在列是否位于「上年金额」块替换为上年 / 本年。
- 减值表：期初取 `prior_period_amount`（= 本年期初数），期末取本期数；期末列为模板公式且有期末值时直接写值；增减列无数据留空。
- 金额格：占位格为 General 格式时套用同 sheet 金额格式。
- 导出提醒 `export_warnings`：资产总计 ≠ 负债和所有者权益总计；导出件合计与报表合计不一致；库内有金额但未绑定的行；未绑定且候选有金额的模板行；
  过期行数；现金流量表全零；期初 / 上期无来源。路由 `render_financial_reports` 回传 `warnings`，一键全套写入 job payload。

### 1.3 上期数（`report_engine.py`）
- `ReportFormulaParser._use_opening`：期末余额 / 审定数 / 未审数列改取 `opening_balance`，`ADJ()` 记 0；配套期初 ROW 缓存使合计行正确。
- `PriorPeriodResolver`：
  - 资产负债表、减值表：期初公式；本年试算表无任何期初数时返回 None。
  - 利润表 / 现金流量表 / 权益表 / 补充资料：① 同项目存在 year-1 试算表 → 旧逻辑；② 上年项目（`prior_year_project_id`，否则同 `company_code`、`audit_year=year-1`、同口径）
    的报表行按编码→行名取本期数；③ 上年项目仅有试算表 → 用本年配置公式在上年项目试算表上求值；④ 均无 → None。
- `_generate_report` 与 `_compute_unadjusted_report_rows` 共用；None 落库为 NULL（导出留空）。
- 权益表净利润兜底按行名（「净利润」且非「归属于…」）取利润表行。

### 1.4 附注引用
- `report_row_note_mapping.json` 指错章节的条目修正（实施时现算：四个变体共 57 条，国企 11×2 指向「四、」会计政策章，
  上市 10×2 指向「三、」、IS-015~018/020/021 与 CFSS-004 指向编号相同但标题不同的节）。
- 新模块 `note_deliverable_outline.py`（取代原计划的 `note_chapter_display_map`）：解析附注模板轮廓 —— 一级标题位次 = 显示章号；
  「节」= `##SECTION##` 块 + 块外同级标题（上市模板「财务报表项目附注」章有 21 个块外标题）；节号 = 本章保留节的位次。
  保留判定与附注交付件一键预设同口径（`note_has_data` 且不在 `should_skip_empty_section` 内）。
- 报表附注列：按模板行名找节（精确 → 「行名 + 和/及/与/、」合并标题 → 映射兜底且映射标题须与行名一致），写交付件显示编号
  （单体国企「八、10」→「七、N」）；节无数据留空并提醒。合并模板 `{{note_ref:X}};{{note_ref:X:parent}}` 复合占位逐个替换
  （旧导出原样留在交付件里），母公司部分取母公司报表附注章。

### 1.5 实施中现算补充（2026-10-16 四项目在事务内重新生成报表后导出比对，332 格/项目）

  所有者权益少 1.5 亿，四项目中三个）；单体口径「带 * 合并专用」行的模板公式清空（旧导出把全部净利润算成「少数股东损益」）。

  与「财务费用」同为 `TB('6603')`；「以摊余成本计量的金融资产终止确认收益」与「投资收益」同为 `TB('6111')`；若干行用未注册列名
  `TB(…,'发生额')`；seed 行 BS-126「归属于母公司所有者权益合计」公式与通用合计口径不一（和平差 1,298.9 万）；权益变动表未含利润分配

## 2. 附注（模板模式重建）

新模块 `note_template_block_fill.py`，由 `_export_template_mode_with_meta` 调用；`note_word_exporter.py` 只改接线（避开并发会话改动的 7.6 段）。

### 2.1 预处理
- 收编块尾参考表：块结束标记后紧随（中间只有空段）的表格移入该块。
- 记录编号重启：每个一级章内首个三级标题、每个块内首个四级标题的显式 numPr。
- 页眉 / 页脚 / 正文中的 `{{company_full_name}}`、`{{company_short_name}}`、`{{audit_year}}` 用项目值替换。

### 2.2 删除规则
- 不适用口径、未匹配库内 note、未勾选、`should_skip`（用投影后表数据判空）的块删除；块内一级标题段保留。
- 块外（两个块之间、非一级标题）的模板内容视为编制指引删除。

### 2.3 保留块重建
元素分类：标记 / `{{seq}}` / 标题（首个内容段）/ 子标题（标题样式）/ 表题（紧邻表位的普通段）/ 表位 `{{table:…:N}}` + 参考表 / 正文位 `{{section}}` / 其余模板内容。
1. 库内表（`effective_table_data` + 表头投影）按「表题 / 子标题 ↔ 表名」规范化后匹配表位；`（续…）` 续表跟随主表；名称都缺失且数量相等时按序号。
2. 表位：对应库内表有数据 → 在表位渲染，删参考表；否则表位、表题、参考表一并删除。
3. 子标题：其下无保留表位 / 正文时删除；保留的字面编号「（n）」按序重排；首个保留子标题补回重启 numPr。
4. 正文位：渲染交付过滤后的正文；无正文位时放在标题后。
5. 未对应表位的有数库内表：追加在块内最后一个保留表之后，以表名作表题。
6. `{{seq}}`：独立成段且标题有自动编号 → 删段；否则沿用旧填号（兼容合成模板）。
7. 其余模板内容（指引、示例、空段、未用参考表）删除。

### 2.4 表格渲染
- 克隆路径（参考表叶子列数 = 库内列数）：深拷贝参考表，保留表头行（`w:tblHeader`，无则 1 行），按行标签选原型行（同名行 / 合计行 / 首个数据行）逐行克隆写值；
  金额右对齐千分位、0 与空留白；保留模板字体字号、列宽、边框、表头合并。
- 回退路径：沿用 `_render_table` 结构，套参考表 tblPr（表样式、宽度、边框），字号 9pt、最小行高 340 twip、表头行重复、合计行加粗。

### 2.5 库内有内容但模板无位置的章节
按所属一级章（库内纯章号 note 的标题 ↔ 一级标题文字，回退块编码前缀）追加到该章末尾：三级标题段克隆本章标题样式 + 正文 + 表格。

### 2.6 交付过滤（新模块 `note_deliverable_filter.py`）
对正文解析出的块列表（`note_text_word_render._parse`）过滤：
- 首段与「编码 + 标题」或标题相同 → 删；
- 大模型对话 / 编制提示段（审计师提示、审计师备注、数据缺失提示、请提供…、我将为您…、注：以上文本为…等）及其后紧随的编号列表 → 删；
- 段首为模板指引括注（（注：/（提示：/（说明/（若/（如有/（如果/（应/（企业应/（根据 开头且以括号结束）→ 删；段内此类括注 → 剔除；
  「[或：…]」备选段 → 删；以「【注 / 【提示 / 【根据 / 【披露 / 【企业应」开头的【…】段（可跨段）→ 删；
- 表格单元格全部为占位（[请补充] / [待补充] / xx / X.XX / 空）→ 删。
`append_note_text` / `fill_paragraph_with_note_text` 增加可选 `block_filter` 参数，导出两种模式都接入；统计剔除数与残留「[请补充」章节数。

### 2.7 交叉引用
正文中「附注八、10」类引用按 1.4 显示映射改写（单体国企）。

### 2.8 提醒扩展（`_note_delivery_warnings`）
追加：剔除的编制提示段数；仍含「[请补充」的章节；报表有余额但对应附注表为空的科目（报表行 → `report_row_note_mapping` 章节）；库内有内容但未能导出的章节。
