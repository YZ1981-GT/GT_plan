# 经营分部审定表 — 需求文档

## 概述

A4（分部信息及有关判断程序表）和 A4-1（经营分部审定表）是分部信息披露相关的底稿。A4-1 包含分部利润/资产/负债数据表、其他分部信息（产品劳务/地区/客户）以及准则列报要求说明。

## 底稿结构

### A4 分部信息及有关判断程序表
- 走现有 `a-program-console`（程序表）

### A4-1 经营分部审定表（1 sheet）
**三大板块**：

#### 1. 分部利润或亏损、资产及负债
- 两段结构：本期或期末 + 上期或期初
- 行项目：营业收入 / 其中对外交易收入 / 其中分部间交易收入 / 营业费用 / 营业利润(亏损) / 资产总额 / 负债总额 + 补充信息(资本性支出/折旧和摊销费用/折旧摊销以外的非现金费用/资产减值损失)
- 列（动态）：XX分部 / XX分部 / 其他 / 抵销 / 合计
- 分部列名由用户自定义填写

#### 2. 其他分部信息
- ① 产品和劳务对外交易收入：项目 × 本期发生额 / 上期发生额
- ② 地区信息：本期或期末/上期或期初 × 中国境内/香港及澳门/海外/抵销/合计
  - 行：对外交易收入 / 非流动资产
- ③ 主要客户信息

#### 3. 准则列报要求说明（不可少）
- 蓝色文字 = 准则引用（解释3号"八(三)"、"八(四)"）
- 必须在界面中展示，作为 guidance/hover 提示
- 内容包括：
  - 解释3号"八(三)"2: 每一报告分部的利润(亏损)总额相关信息
  - 解释3号"八(三)"3: 每一报告分部的资产总额、负债总额相关信息
  - 解释3号"八(四)"1: 每一产品和劳务的对外交易收入
  - 解释3号"八(四)"2: 地区信息（对外交易收入+非流动资产）
  - 解释3号"八(四)"3: 主要客户的依赖程度

## 功能需求

### 1. 动态分部列
- 1.1 用户可自定义分部名称（默认 2 个 XX分部 + 其他 + 抵销 + 合计）
- 1.2 支持增加/删除分部列
- 1.3 合计列自动计算

### 2. 数据填写
- 2.1 各分部的营业收入/费用/利润/资产/负债由用户填写
- 2.2 合计列 = 各分部之和 - 抵销
- 2.3 可从试算表/合并底稿取数（预留接口）

### 3. 准则说明展示（必须有）
- 3.1 蓝色准则引用文字以 guidance 面板或 hover tooltip 展示
- 3.2 不可省略，是底稿编制的重要参考依据
- 3.3 包含示例说明（如"90%来自中国境内"的情形说明）

### 4. 地区信息
- 4.1 按地区维度的交叉表（行=对外交易收入+非流动资产，列=中国境内/港澳/海外/抵销/合计）
- 4.2 本期或期末 + 上期或期初 两段

### 5. 主要客户信息
- 5.1 列示主要客户及其收入占比
- 5.2 10% 以上的客户需披露

## 非功能需求
- 方案：audit-sheet 组件 + 动态列名 + 准则说明 hover 提示
- 暂用 Univer 渲染（P0），结构化组件为 P1
