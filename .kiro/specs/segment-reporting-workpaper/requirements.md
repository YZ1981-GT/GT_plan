# 经营分部审定表 — 需求文档

## 概述

A4（分部信息程序表）和 A4-1（经营分部审定表）用于审计分部报告信息。A4 走现有 `a-program-console`，A4-1 需要结构化渲染（动态分部列+准则说明提示）。

## A4-1 经营分部审定表结构

### 1. 分部利润或亏损、资产及负债
- **两段结构**：本期或期末 + 上期或期初（相同行结构）
- **行**：营业收入 / 其中对外交易收入 / 其中分部间交易收入 / 营业费用 / 营业利润(亏损) / 资产总额 / 负债总额 + 补充信息（资本性支出/折旧摊销/非现金费用/资产减值损失）
- **列**：动态分部列（XX分部 × N个）+ 其他 + 抵销 + 合计
- 合计 = 各分部 + 其他 + 抵销

### 2. 其他分部信息
- ① 产品和劳务对外交易收入：项目 × 本期发生额 / 上期发生额
- ② 地区信息：本期或期末/上期或期初 × 中国境内 / 香港及澳门 / 海外 / 抵销 / 合计
- ③ 主要客户信息：客户名称 + 收入金额 + 占比

### 3. 准则说明（不可省略）
- 解释3号"八(三)"2: 每一报告分部的利润(亏损)总额相关信息
- 解释3号"八(三)"3: 每一报告分部的资产总额、负债总额
- 解释3号"八(四)"1: 每一产品和劳务的对外交易收入
- 解释3号"八(四)"2: 来自本国的对外交易收入总额+非流动资产
- 解释3号"八(四)"3: 企业对主要客户的依赖程度
- 这些说明必须在界面中完整展示（hover tooltip 或折叠面板），不能省略

## 功能需求

### 1. 动态分部列
- 1.1 用户可添加/删除分部列（输入分部名称）
- 1.2 默认提供"其他"和"抵销"列 + "合计"列（自动计算）
- 1.3 合计行公式：各行横向求和

### 2. 数据填写
- 2.1 数值输入（金额）
- 2.2 本期+上期两段独立填写
- 2.3 自动保存 debounce 2s

### 3. 准则说明提示
- 3.1 每个区域标题旁有 ⓘ 图标，hover 显示对应准则条文
- 3.2 或者用折叠面板在表格上方/下方展示完整说明
- 3.3 蓝色准则文字以 guidance 样式渲染（灰色斜体背景）
- 3.4 说明文字不可编辑

### 4. 数据联动（预留）
- 4.1 营业收入/费用/利润可从试算表取数（按分部科目编码映射）
- 4.2 资产总额/负债总额从合并报表分部附注取

## 非功能需求
- 动态列不超过 10 个分部（UI 上限）
- 说明提示必须完整、不能省略准则引用
