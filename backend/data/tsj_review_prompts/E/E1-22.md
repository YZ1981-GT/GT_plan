# E1-22 其他货币资金截止测试复核提示词

## 概述

本提示词针对其他货币资金截止测试底稿（E1-22，科目1012）的复核，聚焦银行汇票、银行本票、信用证保证金、存出投资款等其他货币资金收支的会计期间归属、跨期错报识别、以及保证金存取的截止准确性。其他货币资金形态多样、专用性强，截止测试须结合各类保证金的存入解付时点，识别跨期挂账与期末异常操纵。

**法规依据：**
- 《中国注册会计师审计准则第1301号——审计证据》
- 《中国注册会计师审计准则第1312号——函证》

---

## tips

1. **测试须覆盖各类其他货币资金**：银行汇票、本票、信用证保证金、存出投资款、外埠存款等各类其他货币资金收支均应纳入截止测试范围。
2. **以银行/机构凭证判断实际期间**：以银行进账单、保证金存取凭证、机构对账单判断收支实际发生期间，与账面记账日期对比。
3. **保证金存入解付时点须核对**：开票保证金、投标保证金等的存入与解付时点须核对，跨期挂账须查明。
4. **期末异常存取须警惕**：期末大额转入其他货币资金（如虚构保证金）或期初随即转回，可能为粉饰或操纵。
5. **跨期错报评估影响并调整**：跨期收支须评估对其他货币资金余额、相关往来/费用的影响并调整。
6. **结合受限性与函证**：其他货币资金多为受限资金，截止测试须与受限性识别、函证结合，验证专用资金的真实性与期间归属。

## checklist

### 一、测试范围与样本

- [ ] 测试是否覆盖各类其他货币资金（汇票/本票/信用证保证金/存出投资款）
- [ ] 测试是否覆盖资产负债表日前后合理期间
- [ ] 大额其他货币资金收支是否纳入测试
- [ ] 期末最后几笔、期初最初几笔是否纳入

### 二、期间归属核对

- [ ] 是否以银行进账单/保证金凭证判断实际发生期间
- [ ] 账面记账日期是否与实际发生期间一致
- [ ] 保证金存入、解付时点是否核对
- [ ] 是否识别跨期收支

### 三、跨期错报处理

- [ ] 跨期收支是否评估对其他货币资金余额的影响
- [ ] 跨期收支是否评估对相关往来/费用的影响
- [ ] 应调整的跨期错报是否已编制调整分录（E1-5）
- [ ] 保证金跨期挂账是否查明原因

### 四、异常与受限识别

- [ ] 期末大额异常转入/转回是否识别并核查
- [ ] 是否存在虚构保证金操纵迹象
- [ ] 截止测试是否与受限性识别结合
- [ ] 是否与函证（保证金/信用证）结合验证

## risk_areas

### 高风险

1. **虚构保证金操纵余额**：期末虚构开票/投标保证金转入其他货币资金，期初随即转回，粉饰货币资金规模。
2. **跨期错报影响损益与往来**：其他货币资金收支跨期导致相关费用、往来期间归属错误。

### 中风险

1. **各类其他货币资金覆盖不全**：截止测试仅覆盖部分类型，遗漏潜在跨期。
2. **保证金存取时点未核对**：保证金跨期挂账未查明，可能掩盖资金占用。
3. **跨期错报未调整**：识别的跨期收支未评估影响、未调整。

### 低风险

1. **测试样本量不足**：截止测试覆盖笔数偏少但含大额项目。
2. **测试记录不规范**：核对过程、判断依据记录不充分。
3. **交叉索引不完整**：截止测试未与函证、受限识别、调整分录建立索引引用。
