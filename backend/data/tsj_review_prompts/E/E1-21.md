# E1-21 银行存款截止测试复核提示词

## 概述

本提示词针对银行存款截止测试底稿（E1-21）的复核，聚焦资产负债表日前后银行存款收支的会计期间归属正确性、跨期错报识别、测试样本覆盖充分性、以及大额收支的截止准确性。截止测试验证银行存款收支是否记入正确会计期间，跨期收支错误将同时影响货币资金、往来款项和损益的期间归属。

**法规依据：**
- 《中国注册会计师审计准则第1301号——审计证据》
- 《中国注册会计师审计准则第1312号——函证》

---

## tips

1. **测试须覆盖资产负债表日前后**：选取报表日前后一定期间（如前后各若干天/若干笔）的银行收支，核对记账日期与实际发生日期是否属于正确期间。
2. **以银行对账单/回单为准判断实际期间**：以银行对账单入账日期、银行回单为准判断收支实际发生期间，与账面记账日期对比识别跨期。
3. **大额收支须重点截止测试**：金额重大的银行收支、期末最后几笔和期初最初几笔须重点核查截止准确性。
4. **跨期收支须评估对余额和损益的影响**：报表日前实际发生但账面记入下期（或反之），须评估对货币资金余额、往来款、收入的影响并调整。
5. **关注期末冲减存款的异常交易**：期末大额提现随即期初存回（粉饰余额）、期末集中收款等异常须警惕舞弊性截止操纵。
6. **截止测试须与函证、余额调节表结合**：截止差异可能表现为函证差异或未达账项，须与E1-11、E1-6结合分析。

## checklist

### 一、测试范围与样本

- [ ] 测试是否覆盖资产负债表日前后合理期间
- [ ] 测试样本是否覆盖大额银行收支
- [ ] 期末最后几笔、期初最初几笔收支是否纳入测试
- [ ] 测试笔数/覆盖比例是否充分

### 二、期间归属核对

- [ ] 是否以银行对账单入账日期/回单判断实际发生期间
- [ ] 账面记账日期是否与实际发生期间一致
- [ ] 是否识别报表日前发生但记入下期的收支
- [ ] 是否识别报表日后发生但记入本期的收支

### 三、跨期错报处理

- [ ] 跨期收支是否评估对货币资金余额的影响
- [ ] 跨期收支是否评估对往来款、收入的影响
- [ ] 应调整的跨期错报是否已编制调整分录（E1-5）
- [ ] 跨期错报是否与余额调节表未达账项结合分析

### 四、异常识别

- [ ] 期末大额提现随即期初存回等粉饰余额行为是否识别
- [ ] 期末集中收款是否核查业务实质
- [ ] 截止差异是否与函证差异结合分析
- [ ] 是否存在截止操纵舞弊迹象

## risk_areas

### 高风险

1. **截止操纵粉饰余额**：期末大额提现随即期初存回、期末集中收款虚增货币资金余额，属舞弊性财务粉饰。
2. **跨期错报影响损益**：银行收支跨期导致收入、往来款期间归属错误，影响损益真实性。

### 中风险

1. **大额收支未截止测试**：金额重大的收支未纳入截止测试，遗漏潜在跨期错报。
2. **判断期间依据不当**：仅凭账面记账日期而非银行对账单判断实际期间，截止测试失效。
3. **跨期错报未调整**：识别的跨期收支未评估影响、未调整。

### 低风险

1. **测试样本量不足**：截止测试覆盖笔数偏少，但已含大额项目。
2. **测试记录不规范**：核对过程、判断依据记录不充分。
3. **交叉索引不完整**：截止测试未与函证、余额调节表、调整分录建立索引引用。
