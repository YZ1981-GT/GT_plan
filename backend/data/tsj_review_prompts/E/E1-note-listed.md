# E1-note-listed 货币资金附注披露复核提示词（上市公司）

## 概述

本提示词针对货币资金上市公司附注披露底稿（E1-note-listed）的复核，聚焦上市公司财务报表附注中货币资金相关披露的充分性和准确性：库存现金/银行存款/其他货币资金分类披露、受限货币资金披露、外币货币资金披露、境外存放资金披露、以及与现金流量表现金及现金等价物的衔接。货币资金附注披露不充分（尤其受限资金）将严重误导报表使用者对企业流动性的判断。

**法规依据：**
- 《企业会计准则第37号——金融工具列报》
- 《企业会计准则第22号——金融工具确认和计量》
- 《企业会计准则第19号——外币折算》
- 《公开发行证券的公司信息披露编报规则第15号——财务报告的一般规定》

## tips

1. **货币资金须按类别分项披露**：附注须按库存现金、银行存款、其他货币资金分项列示期末数与期初数，各项合计等于审定表货币资金审定数。
2. **受限货币资金是披露核心**：因抵押、质押、冻结、保证金等原因使用受限的货币资金须单独披露金额、受限原因，这是上市公司货币资金披露的关键，缺失即属重大披露不充分。
3. **境外存放货币资金须单独披露**：存放境外的货币资金须披露金额及所在国家/地区，评估资金汇回是否存在限制。
4. **外币货币资金须披露原币与折算**：重要外币货币资金须披露原币金额、折算汇率与折算人民币金额。
5. **须与现金流量表衔接**：附注货币资金总额与现金流量表期末现金及现金等价物余额的差异（受限资金/非现金等价物）须说明衔接关系。
6. **附注数据须与审定表/明细表勾稽**：附注货币资金总额=审定表审定数，分类小计=明细表对应合计，受限金额=受限资金明细，形成闭环。

## checklist

### 一、分类披露检查

- [ ] 货币资金是否按库存现金/银行存款/其他货币资金分项披露
- [ ] 各分项是否同时列示期末数与期初数（可比信息）
- [ ] 各分项合计是否等于审定表货币资金审定数
- [ ] 其他货币资金构成（银行汇票/本票/信用证保证金/存出投资款）是否披露
- [ ] 分类是否与会计政策口径一致

### 二、受限货币资金披露

- [ ] 使用受限的货币资金是否单独披露金额
- [ ] 受限原因（抵押/质押/冻结/保证金/监管）是否说明
- [ ] 受限资金金额是否与E1底稿受限识别一致
- [ ] 受限资金是否从现金及现金等价物中剔除
- [ ] 重大受限（如大额定期存款质押）是否与借款/担保披露勾稽

### 三、外币与境外资金披露

- [ ] 重要外币货币资金是否披露原币、汇率、折算金额
- [ ] 外币折算是否采用资产负债表日即期汇率
- [ ] 存放境外的货币资金是否单独披露金额及国家/地区
- [ ] 境外资金汇回限制是否说明

### 四、现金流量表衔接

- [ ] 附注货币资金总额与现金流量表期末现金及等价物是否说明衔接
- [ ] 现金等价物范围界定是否披露
- [ ] 受限资金与非现金等价物的差异是否说明

### 五、勾稽一致性

- [ ] 附注货币资金总额是否与审定表审定数一致
- [ ] 分类小计是否与明细表对应合计勾稽
- [ ] 利息收入相关披露是否与损益勾稽
- [ ] 期初数是否与上年审定数一致

## risk_areas

### 高风险

1. **受限货币资金未披露**：抵押、质押、冻结、保证金等受限资金未单独披露，严重误导报表使用者对企业实际可动用资金和流动性的判断。
2. **境外资金及汇回限制未披露**：存放境外资金金额及汇回限制未披露，掩盖资金可用性风险。
3. **附注总额与审定表不一致**：附注货币资金总额与审定表审定数不一致，属数据勾稽重大错误。

### 中风险

1. **分类披露不完整**：其他货币资金构成未细分，或未列示期初可比数据。
2. **外币披露不充分**：重要外币货币资金未披露原币与折算信息。
3. **现金流量表衔接缺失**：附注货币资金与现金及等价物差异未说明，受限资金未从等价物剔除。

### 低风险

1. **披露格式不规范**：分类列示格式、金额单位不完全符合编报规则。
2. **文字说明模板化**：受限原因说明过于笼统，未结合具体安排。
3. **数字精度不一致**：披露表格精度不统一但不影响决策判断。
