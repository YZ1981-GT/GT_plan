# E1-4 数字货币明细复核提示词

## 概述

本提示词针对数字货币明细表（E1-4）的复核，聚焦数字人民币（DCEP）钱包及其他数字货币资产的余额构成、存在性验证、期末计价与列报归属。数字货币属新型货币资金形态，须核实钱包账户真实性、余额与运营机构记录一致性，并评估其列报是否恰当（数字人民币计入货币资金，其他加密资产列报需审慎判断）。

**法规依据：**
- 《企业会计准则第22号——金融工具确认和计量》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **数字人民币应计入货币资金**：数字人民币（DCEP）是法定货币的数字形态，其钱包余额应计入货币资金，明细表列示钱包机构、钱包编号与余额。
2. **存在性须通过独立记录验证**：数字货币余额须与运营机构（指定运营银行）出具的记录或区块链链上记录核对，不能仅凭企业自报。
3. **其他加密资产列报须审慎**：比特币等加密资产不属于货币资金，若企业持有须评估其性质（存货/无形资产/金融资产）与列报恰当性。
4. **关注钱包控制权与私钥安全**：数字货币的控制取决于私钥/账户权限，须核实钱包控制权归属企业，防止资产被盗或私钥丢失。
5. **期末计价须核实**：数字人民币按面值计量；其他数字货币如需公允价值计量，须核实估值来源与计价日期。
6. **交易可追溯性核查**：数字货币交易应可追溯，异常大额转入转出应核查业务实质，防范洗钱与资金异常。

## checklist

### 一、余额构成与勾稽

- [ ] 数字货币明细是否按钱包机构、钱包编号列示
- [ ] 数字人民币余额是否计入货币资金并与审定表勾稽
- [ ] 明细表余额合计是否与账面记录一致
- [ ] 期初余额是否与上年期末一致

### 二、存在性与控制权

- [ ] 数字货币余额是否与运营机构记录或链上记录核对一致
- [ ] 钱包控制权（私钥/账户权限）是否归属企业
- [ ] 是否存在钱包被冻结、受限或第三方控制的情况
- [ ] 期末钱包余额是否有独立第三方证据支持

### 三、计价与列报

- [ ] 数字人民币是否按面值计量
- [ ] 其他数字货币（如持有）是否评估性质并恰当列报
- [ ] 非货币资金性质的加密资产是否误计入货币资金
- [ ] 期末计价日期与估值来源是否恰当

### 四、交易合规性

- [ ] 大额数字货币转入转出是否核查业务实质
- [ ] 是否存在异常交易或洗钱风险迹象
- [ ] 数字货币交易是否可追溯

## risk_areas

### 高风险

1. **数字货币存在性无法验证**：仅凭企业自报钱包余额，缺乏运营机构记录或链上证据，无法确认资产真实存在。
2. **加密资产错误列报**：将比特币等非货币资金性质的加密资产计入货币资金，导致列报错误。
3. **私钥/控制权风险**：钱包控制权不明或私钥由第三方持有，资产随时可能被转移或丧失。

### 中风险

1. **期末计价不当**：其他数字货币未采用恰当估值或估值来源不可靠。
2. **异常交易未核查**：大额数字货币异常转入转出未核查业务实质，存在资金异常风险。
3. **钱包受限未识别**：钱包被冻结或受限但仍列示为可动用资金。

### 低风险

1. **明细列示不规范**：钱包机构、编号未完整列示。
2. **交叉索引不完整**：数字货币明细未与审定表建立索引引用。
