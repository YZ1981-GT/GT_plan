# E1-3 银行存款明细复核提示词

## 概述

本提示词针对银行存款明细表（E1-3，科目1002）的复核，聚焦各银行账户余额构成、函证结果核对、外币存款折算、定期存款受限性识别与账户完整性。银行存款是货币资金的主体，明细表须真实反映各开户行、各账户的余额，并与银行询证函回函（E1-11）、余额调节表（E1-6）、账户清单（E1-10）勾稽。本底稿区分上市/国企双变体。

**法规依据：**
- 《中国注册会计师审计准则第1312号——函证》
- 《中国注册会计师审计准则第1301号——审计证据》
- 《企业会计准则第19号——外币折算》

---

## tips

1. **明细表须按开户行、账号逐户列示**：每个银行账户（含活期、定期、外币、专户）应分行列示开户行名称、账号、币种、余额，合计等于审定表银行存款审定数。
2. **各账户余额须与函证回函核对**：明细表账面余额须与银行询证函回函确认金额逐户核对，差异应通过余额调节表（E1-6）的未达账项解释。
3. **定期存款及质押存款须识别受限性**：作为借款质押、开票保证金的定期存款属受限资金，应重分类或披露，不得列示为可自由动用存款。
4. **外币存款须列示原币与折算金额**：外币账户须按资产负债表日即期汇率折算，明细表列示原币、汇率、折算后人民币金额（CAS19）。
5. **账户完整性双向核对**：明细表账户须与企业信用报告（E1-18/19）披露的账户、银行询证回函账户双向核对，识别账外账户或遗漏账户。
6. **关注长期不动户与销户账户**：长期无交易的账户、已销户但账面仍有余额的账户，可能存在账实不符或隐匿资金。

## checklist

### 一、明细构成与勾稽

- [ ] 银行存款明细是否按开户行、账号逐户列示
- [ ] 各账户期末余额合计是否等于审定表银行存款（1002）审定数
- [ ] 明细表账户余额是否与序时账（tb_ledger）银行存款余额一致
- [ ] 各账户期初余额是否与上年期末一致
- [ ] 外币账户是否列示原币、折算汇率与折算后人民币金额

### 二、函证核对

- [ ] 每个银行账户是否均已发出银行询证函
- [ ] 明细表账面余额是否与函证回函确认金额逐户核对一致
- [ ] 函证差异是否通过余额调节表（E1-6）未达账项合理解释
- [ ] 未回函账户是否实施了替代程序（对账单核对/期后流水核对）
- [ ] 回函是否由银行直接寄回审计师，函证过程是否受审计师控制

### 三、外币折算与受限识别

- [ ] 外币存款折算是否采用资产负债表日即期汇率
- [ ] 定期存款、质押存款、保证金账户是否已识别受限性
- [ ] 受限存款是否已重分类或在附注中披露受限性质与金额
- [ ] 冻结、监管账户资金是否单独列示
- [ ] 长期不动户、销户账户余额是否查明原因

### 四、账户完整性

- [ ] 明细表账户是否与企业信用报告（E1-18/19）账户双向核对
- [ ] 明细表账户是否与银行询证回函账户一致
- [ ] 是否存在账面记录但信用报告未显示的账户（账外账户）
- [ ] 是否存在信用报告显示但账面未记录的账户（遗漏账户）
- [ ] 期末新开户或销户是否有完整审批记录

## risk_areas

### 高风险

1. **账外银行账户隐匿资金**：企业存在账面未记录的银行账户（信用报告显示但账面无），可能用于隐匿收入、体外资金循环或私设小金库。
2. **受限存款未识别列报**：定期存款质押、开票保证金等受限存款列示为可自由动用存款，虚增企业流动性。
3. **函证差异未合理解释**：账面余额与银行回函确认金额存在差异但未通过未达账项解释，可能存在虚假存款或伪造回函。
4. **虚假银行存款**：伪造银行对账单或回函虚增存款余额，需核实回函来源真实性和函证过程控制。

### 中风险

1. **外币折算错误**：外币存款未按资产负债表日汇率折算或汇率取值错误，导致存款金额与汇兑损益失真。
2. **未回函替代程序不充分**：未回函账户仅凭企业提供的对账单核对，替代程序证据力不足。
3. **未达账项异常挂账**：余额调节表中未达账项长期挂账未清理，可能掩盖账实差异。
4. **账户完整性核对不到位**：未与信用报告双向核对，无法发现账外或遗漏账户。

### 低风险

1. **明细列示不规范**：开户行、账号、币种未完整列示，影响可读性。
2. **长期不动户未说明**：长期无交易账户未附说明，但金额较小不构成重大风险。
3. **交叉索引不完整**：银行存款明细未与函证、余额调节表、账户清单建立索引引用。
