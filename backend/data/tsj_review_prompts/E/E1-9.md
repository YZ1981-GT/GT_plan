# E1-9 银行存单盘点表复核提示词

## 概述

本提示词针对银行存单盘点表（E1-9）的复核，聚焦定期存单、大额存单等实物凭证的盘点验证、受限性识别、金额与账面勾稽、以及质押冻结状态核查。银行存单盘点通过清点实物存单验证其他货币资金/银行存款中定期存款部分的存在性，并识别存单是否被质押、冻结而受限。

**法规依据：**
- 《中国注册会计师审计准则第1311号——对存货、诉讼和索赔、分部信息的具体考虑》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **实物存单须现场清点核对**：定期存单、大额存单等实物凭证应现场清点，核对存单编号、开户行、金额、存期、到期日等要素。
2. **存单不在企业保管时须函证或查看托管证明**：存单被质押、托管于第三方时无法现场清点，须通过函证或查看质押/托管协议验证。
3. **受限存单须识别并单独列示**：作为借款质押、开票保证金的存单属受限资金，须在盘点表中标注受限状态，并联动重分类/披露。
4. **存单金额须与账面勾稽**：盘点存单金额合计须与账面对应科目（银行存款定期/其他货币资金）余额核对一致。
5. **关注存单权属与背书**：核实存单权属归企业，是否存在背书转让、质押他人的情况，防止资产权属瑕疵。
6. **到期日核查**：核对存单到期日，评估流动性分类（一年内到期计入流动资产），已到期未兑付存单须查明原因。

## checklist

### 一、盘点程序与实物核对

- [ ] 存单盘点是否由审计师现场监督执行
- [ ] 是否清点核对存单编号、开户行、金额、存期、到期日
- [ ] 保管人是否在场并签字确认
- [ ] 不在企业保管的存单是否通过函证或托管证明验证

### 二、金额勾稽

- [ ] 盘点存单金额合计是否与账面对应科目余额核对一致
- [ ] 各存单金额是否与银行存款明细（E1-3）勾稽
- [ ] 是否存在账面记录但实物缺失的存单
- [ ] 是否存在实物存在但账面未记录的存单

### 三、受限性与权属

- [ ] 存单是否被质押、冻结（受限状态是否标注）
- [ ] 受限存单是否联动重分类或在附注披露
- [ ] 存单权属是否归属企业（是否背书转让/质押他人）
- [ ] 质押、托管存单是否有相应协议支持

### 四、到期日与流动性

- [ ] 存单到期日是否核对
- [ ] 流动性分类是否正确（一年内到期计入流动资产）
- [ ] 是否存在已到期未兑付的存单
- [ ] 已到期未兑付存单是否查明原因

## risk_areas

### 高风险

1. **存单被质押受限未识别**：作为借款质押的存单仍列示为可自由动用资金，虚增流动性并隐瞒担保安排。
2. **存单实物缺失或权属瑕疵**：账面记录存单但实物缺失、或已背书转让/质押他人，资产实际不存在或权属受限。
3. **虚假存单**：伪造存单虚增货币资金，需核实存单真实性（函证或查看开户行系统记录）。

### 中风险

1. **不在企业保管未有效验证**：托管、质押存单未通过函证或协议充分验证存在性。
2. **金额与账面不勾稽**：存单盘点金额与账面余额不一致未查明。
3. **到期未兑付未查明**：已到期存单未兑付且未查明原因，可能存在兑付障碍。

### 低风险

1. **存单要素记录不全**：存单编号、存期、到期日等要素记录不完整。
2. **盘点表格式不规范**：参与人、盘点时点等要素记录不全。
3. **交叉索引不完整**：存单盘点表未与明细表、审定表建立索引引用。
