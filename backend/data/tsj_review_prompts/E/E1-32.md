# E1-32 董监高及关键岗位人员银行流水核查复核提示词

## 概述

本提示词针对董监高及关键岗位人员银行流水核查底稿（E1-32，IPO/舞弊应对专项）的复核，聚焦对董事、监事、高管及财务、销售、采购等关键岗位人员个人银行流水的核查，识别关联方资金占用、体外资金循环、利益输送与舞弊风险。本底稿是IPO审计中穿透式核查货币资金舞弊风险的最深层程序，核心是发现企业资金与个人账户之间的异常往来。

**法规依据：**
- 《中国注册会计师审计准则第1141号——财务报表审计中与舞弊相关的责任》
- 《中国注册会计师审计准则第1312号——函证》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **核查对象须覆盖关键人员**：董事、监事、高管及财务负责人、出纳、销售/采购关键岗位人员的个人银行流水均应纳入核查范围。
2. **须取得个人授权与流水**：个人流水核查须取得本人授权，流水应完整（主要账户）并核实真实性。
3. **识别企业与个人间异常往来**：企业资金流向个人、个人资金流入企业（尤其大额、频繁、无正当事由）须重点核查。
4. **关联方资金占用穿透**：个人账户是否作为企业与关联方资金往来的通道，实现资金占用或体外循环。
5. **须先确认程序适用性**：确认企业是否属IPO/高舞弊风险适用情形，适用则核查执行充分性与覆盖范围。
6. **异常往来须核查性质并追加程序**：发现企业与个人间异常资金往来须核查交易性质（薪酬/借款/代收代付/利益输送）并追加程序。

## checklist

### 一、程序适用性与核查范围

- [ ] 本程序适用情形（IPO/高舞弊风险）是否已确认
- [ ] 核查对象是否覆盖董监高
- [ ] 核查对象是否覆盖财务、出纳等关键岗位
- [ ] 是否覆盖销售/采购等重点岗位人员
- [ ] 个人流水核查是否取得本人授权

### 二、流水完整性与真实性

- [ ] 个人主要账户流水是否完整获取
- [ ] 流水真实性是否核实
- [ ] 是否核对个人账户清单完整性
- [ ] 核查期间是否覆盖报告期

### 三、异常往来识别

- [ ] 企业资金流向个人是否核查（大额/频繁/无事由）
- [ ] 个人资金流入企业是否核查
- [ ] 个人账户是否作为关联方资金往来通道
- [ ] 是否识别资金体外循环/利益输送迹象
- [ ] 大额异常往来交易性质是否核查

### 四、异常处理

- [ ] 异常资金往来是否核查交易性质
- [ ] 发现舞弊迹象是否追加程序
- [ ] 是否提请项目组及合伙人关注
- [ ] 核查结论是否明确（无异常/已解释/发现迹象）

## risk_areas

### 高风险

1. **关联方资金占用穿透**：个人账户作为企业资金流向关联方的通道，实现隐性资金占用，属IPO重大舞弊。
2. **资金体外循环**：企业与关键人员个人账户间大额往返资金无正当业务，构成体外循环或虚构业务闭环。
3. **利益输送**：企业资金异常流向董监高个人，涉及利益输送、职务侵占或商业贿赂。

### 中风险

1. **核查范围不足**：核查对象未覆盖全部关键岗位人员，存在核查盲区。
2. **流水不完整**：个人主要账户流水未完整获取，异常往来可能遗漏。
3. **异常往来未核查性质**：识别异常往来但未核查交易性质。

### 低风险

1. **授权/记录不完整**：个人授权、核查过程记录不充分。
2. **核查期间覆盖不足**：未覆盖完整报告期。
3. **交叉索引不完整**：本底稿未与银行流水双向核对、账户清单、关联方底稿建立索引引用。
