# E1-26 现金交易模式分析复核提示词

## 概述

本提示词针对现金交易模式分析底稿（E1-26，IPO/舞弊应对专项）的复核，聚焦现金交易规模与模式的合理性、异常现金交易识别、体外循环与虚构业务迹象排查。本底稿属针对IPO及高舞弊风险执行的加严货币资金核查程序，核心目标是通过分析现金交易模式识别资金体外循环、虚构业务、商业贿赂等舞弊风险。

**法规依据：**
- 《中国注册会计师审计准则第1141号——财务报表审计中与舞弊相关的责任》
- 《中国注册会计师审计准则第1314号——审计抽样》
- 《中国注册会计师审计准则第1301号——审计证据》

## tips

1. **现金交易规模须与业务性质匹配**：分析现金收支占总收支比例，现金交易规模与行业特征、经营模式明显不符（如应以银行结算的B2B业务大量现金）须警惕。
2. **识别异常现金交易模式**：频繁大额现金收支、整数金额、临近审批权限、集中于特定时点/对手方等异常模式须重点分析。
3. **排查资金体外循环迹象**：现金收入未入账、以现金支付本应转账的大额款项、现金往返于关联方，可能构成体外循环。
4. **虚构业务的现金特征**：虚构收入常伴随现金回款以完成资金闭环，须核查现金回款对应交易的真实性。
5. **须先确认程序适用性**：本程序针对IPO及舞弊风险，复核时须确认企业是否属适用情形，适用则核查执行充分性。
6. **异常须扩大测试并提请关注**：分析发现舞弊迹象须扩大测试范围、追加程序，并提请项目组及合伙人关注。

## checklist

### 一、程序适用性

- [ ] 本程序适用情形（IPO/高舞弊风险）是否已确认
- [ ] 是否根据风险评估结果确定核查深度
- [ ] 分析目标是否明确（识别体外循环/虚构业务）

### 二、现金交易规模与模式

- [ ] 现金收支规模及占比是否分析
- [ ] 现金交易规模是否与业务性质、行业特征匹配
- [ ] 是否识别频繁大额现金收支
- [ ] 是否识别整数金额、临近审批权限等异常
- [ ] 现金交易是否集中于特定时点或对手方

### 三、体外循环与虚构业务排查

- [ ] 是否排查现金收入未入账迹象
- [ ] 大额款项以现金支付是否核查合理性
- [ ] 现金往返于关联方/个人是否核查
- [ ] 虚构业务的现金回款闭环是否排查
- [ ] 异常现金交易对应业务真实性是否核查

### 四、异常处理

- [ ] 发现的舞弊迹象是否扩大测试
- [ ] 异常事项是否追加程序核查
- [ ] 是否提请项目组及合伙人关注
- [ ] 分析结论是否明确（匹配/异常已解释/发现迹象）

## risk_areas

### 高风险

1. **资金体外循环**：现金收入未入账或大额现金往返关联方/个人，构成资金体外循环，严重虚假陈述。
2. **虚构业务资金闭环**：以现金回款完成虚构收入的资金闭环，掩盖虚增收入，属重大舞弊。
3. **商业贿赂/利益输送**：大额异常现金支出无正当业务支持，可能涉及商业贿赂或利益输送。

### 中风险

1. **现金交易规模异常未解释**：现金交易与业务性质不匹配但未查明原因。
2. **异常模式未追查**：识别异常现金模式但未追加程序核查。
3. **程序适用性判断不当**：未正确判断本程序适用情形或核查深度不足。

### 低风险

1. **分析维度不足**：现金交易分析维度单一，未充分识别模式异常。
2. **记录不完整**：分析过程、异常判断记录不充分。
3. **交叉索引不完整**：本底稿未与现金明细、收支检查、盘点建立索引引用。
