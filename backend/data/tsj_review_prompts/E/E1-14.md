# E1-14 货币资金分析表复核提示词

## 概述

本提示词针对货币资金分析表（E1-14）的复核，聚焦货币资金期末余额的趋势分析、结构分析、与相关指标（收入、利息收入、经营现金流）的匹配性分析、以及异常波动的合理解释。分析程序通过建立数据预期识别异常，货币资金的异常增减、与经营规模脱节的余额往往指向资金异常或舞弊。

**法规依据：**
- 《中国注册会计师审计准则第1313号——分析程序》

---

## tips

1. **趋势分析须建立合理预期**：将本期货币资金余额与期初、上年同期、多期趋势对比，重大变动须与经营活动、筹资投资活动匹配解释。
2. **结构分析识别异常构成**：分析库存现金、银行存款、其他货币资金的构成比例，现金占比畸高或受限资金占比大均需关注。
3. **货币资金须与经营规模匹配**：货币资金余额与营业收入、资产总额的比例应合理，余额与经营规模严重脱节可能存在虚假资金。
4. **利息收入匹配性交叉验证**：货币资金规模应产生合理的利息收入，利息收入畸低（存款高但利息少）可能表明存款不真实或被占用（联动E1-15/E1-20）。
5. **与现金流量表勾稽**：货币资金期末减期初的净变动须与现金流量表现金及现金等价物净增加额勾稽一致。
6. **期初数须取审定数**：分析表期初余额应取上年审定数（而非未审数），确保分析基准准确。

## checklist

### 一、趋势与结构分析

- [ ] 期末货币资金余额是否与期初、上年同期对比分析
- [ ] 重大变动是否有合理解释并与经营/筹资/投资活动匹配
- [ ] 库存现金/银行存款/其他货币资金构成比例是否分析
- [ ] 现金占比是否异常偏高
- [ ] 受限资金占比是否分析并评估影响

### 二、匹配性分析

- [ ] 货币资金余额与营业收入、资产总额比例是否合理
- [ ] 货币资金与经营规模是否匹配
- [ ] 利息收入与存款规模是否匹配（联动E1-15/E1-20）
- [ ] 利息收入畸低是否查明原因
- [ ] 期末余额较大但盈利/现金流状况差是否合理解释

### 三、现金流勾稽

- [ ] 货币资金净变动是否与现金流量表现金及等价物净增加额勾稽
- [ ] 现金等价物范围界定是否恰当
- [ ] 受限货币资金是否从现金等价物中剔除

### 四、分析基准与异常识别

- [ ] 分析表期初余额是否取上年审定数
- [ ] 异常波动是否已识别并追查
- [ ] 分析发现的异常是否联动其他底稿核查
- [ ] 分析结论是否支持货币资金整体合理

## risk_areas

### 高风险

1. **货币资金与经营规模严重脱节**：账面大额货币资金但与收入、盈利、现金流不匹配，可能存在虚假存款、存款被质押占用或资金体外循环。
2. **利息收入与存款规模不匹配**：巨额存款仅产生微薄利息收入，强烈提示存款不真实、被冻结或实际不由企业控制。
3. **异常波动未查明**：货币资金重大异常增减未追查原因，可能掩盖资金舞弊。

### 中风险

1. **趋势变动缺乏解释**：重大变动未与经营活动匹配解释，分析流于形式。
2. **现金流不勾稽**：货币资金净变动与现金流量表不一致未查明。
3. **分析基准错误**：期初取未审数导致分析基准偏差。

### 低风险

1. **结构分析不充分**：未分析货币资金构成，遗漏结构性异常。
2. **分析深度不足**：仅列数据未建立预期和对比。
3. **交叉索引不完整**：分析表未与审定表、利息分析等底稿建立索引引用。
