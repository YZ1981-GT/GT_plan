# E1-19 企业信用报告核对复核提示词

## 概述

本提示词针对企业信用报告核对底稿（E1-19）的复核，聚焦将信用报告披露信息与账面记录逐项核对、隐性账户识别、未入账借款与对外担保发现、以及核对差异的调查处理。信用报告核对是把权威第三方证据（E1-18）转化为审计发现的关键环节，核心是识别账面与信用报告之间的差异所隐藏的账外账户、隐性负债和未披露担保。

**法规依据：**
- 《中国注册会计师审计准则第1301号——审计证据》
- 《中国注册会计师审计准则第1312号——函证》

---

## tips

1. **银行账户逐户双向核对**：信用报告披露的账户与账面账户（E1-10）逐户核对，报告有而账面无=账外账户，账面有而报告无=待查异常。
2. **借款信息核对负债完整性**：信用报告披露的贷款须与账面短期/长期借款核对，报告有而账面无=未入账借款（隐性负债）。
3. **对外担保核对或有事项**：信用报告披露的对外担保须与账面及附注核对，未披露担保=或有负债遗漏。
4. **票据承兑与信用证核对**：报告中的承兑、信用证须与应付票据、其他货币资金（保证金）核对。
5. **差异须逐项调查解释**：所有核对差异须查明原因，账外账户资金往来性质须核查，隐性负债须补记或披露。
6. **隐性账户是重大舞弊信号**：信用报告发现的账外账户往往用于隐匿收入或体外循环，须追查资金来源去向。

## checklist

### 一、账户核对

- [ ] 信用报告披露账户是否与账面账户（E1-10）逐户核对
- [ ] 是否识别报告有而账面无的账户（账外账户）
- [ ] 是否识别账面有而报告无的账户
- [ ] 账外账户资金往来性质是否核查
- [ ] 账户差异是否逐项查明原因

### 二、借款与负债核对

- [ ] 信用报告披露借款是否与账面借款核对
- [ ] 是否识别报告有而账面无的借款（隐性负债）
- [ ] 未入账借款是否补记或披露
- [ ] 授信额度使用情况是否与账面借款匹配

### 三、担保与或有事项核对

- [ ] 信用报告披露对外担保是否与账面及附注核对
- [ ] 未披露对外担保是否已识别
- [ ] 或有负债是否补充披露
- [ ] 票据承兑、信用证是否与应付票据/保证金核对

### 四、差异调查处理

- [ ] 所有核对差异是否逐项调查
- [ ] 差异原因是否查明并记录
- [ ] 应调整/披露事项是否已处理
- [ ] 隐性账户/负债/担保发现是否联动相关循环底稿

## risk_areas

### 高风险

1. **账外银行账户隐匿资金**：信用报告发现账面未记录账户，可能隐匿收入、体外循环或私设小金库，属重大舞弊风险。
2. **未入账借款隐性负债**：信用报告披露借款而账面无记录，低估负债，可能构成重大错报。
3. **对外担保未披露**：信用报告披露对外担保而账面及附注未反映，遗漏重大或有负债。

### 中风险

1. **差异未查明原因**：核对差异未逐项调查，隐藏问题未暴露。
2. **票据/信用证未核对**：承兑、信用证未与相关科目核对，遗漏保证金受限或或有负债。
3. **隐性账户未追查资金**：发现账外账户但未追查资金来源去向。

### 低风险

1. **核对记录不完整**：核对过程、差异说明记录不充分。
2. **部分要素未核对**：信用报告部分次要信息未纳入核对。
3. **交叉索引不完整**：信用报告核对未与账户清单、借款、担保、函证建立索引引用。
