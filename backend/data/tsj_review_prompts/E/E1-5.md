# E1-5 货币资金调整分录复核提示词

## 概述

本提示词针对货币资金调整分录（E1-5）的复核，聚焦账项调整（AJE）与重分类调整（RJE）的完整性、借贷平衡、调整依据充分性与对审定表的回写准确性。调整分录是连接未审数与审定数的桥梁，任何遗漏、方向错误或缺乏审批的调整都将导致货币资金审定数失真。

**法规依据：**
- 《中国注册会计师审计准则第1301号——审计证据》
- 《中国注册会计师审计准则第1450号——评价审计过程中识别出的错报》

---

## tips

1. **调整分录须区分账项调整与重分类调整**：账项调整（AJE）影响审定金额，重分类调整（RJE）仅调整列报分类（如受限资金重分类），二者性质不同不可混淆。
2. **每笔调整须借贷平衡**：调整分录借方合计必须等于贷方合计，单笔及汇总均须平衡，不平衡即为错误。
3. **调整须有充分审计证据与审批**：每笔调整应有底稿证据支持（如函证差异、未达账项、外币折算），并经项目负责人及合伙人审批。
4. **调整须准确回写审定表**：调整金额须准确反映到审定表（E1-1）对应科目，审定数=未审数+AJE+RJE。
5. **受限资金重分类是货币资金常见RJE**：将保证金、质押存款等受限资金重分类至其他流动资产/其他非流动资产，须金额准确、方向正确。
6. **建议未采纳的调整须记录SUD**：审计师建议但被管理层拒绝的调整，须记录于未调整错报汇总表并评估累积影响。

## checklist

### 一、调整完整性

- [ ] 所有已识别的错报是否均已编制调整分录或记录于SUD
- [ ] 外币折算差额调整是否已编制（如未审数未反映折算）
- [ ] 余额调节表（E1-6）中应调整的未达账项是否已编制调整
- [ ] 受限货币资金重分类调整是否已编制
- [ ] 是否存在已识别错报但既未调整也未记录SUD的情况

### 二、借贷平衡与准确性

- [ ] 每笔调整分录借方合计是否等于贷方合计
- [ ] 调整分录汇总借贷是否平衡
- [ ] 调整涉及的科目名称、科目代码是否准确
- [ ] 调整金额计算是否准确（外币折算/利息补提等）
- [ ] AJE与RJE是否正确区分标记

### 三、依据与审批

- [ ] 每笔调整是否有充分的底稿证据支持
- [ ] 调整分录是否附有调整原因说明
- [ ] 调整是否经过项目负责人及合伙人审批
- [ ] 重大调整是否与管理层沟通并取得认可
- [ ] 建议但未采纳的调整是否记录于SUD并评估累积影响

### 四、回写审定表

- [ ] 调整金额是否准确回写至审定表（E1-1）对应科目行
- [ ] 审定表审定数是否等于未审数加AJE加RJE
- [ ] 调整对财务费用（汇兑损益）的影响是否同步反映至相关底稿
- [ ] 重分类调整是否同步反映至目标科目底稿

## risk_areas

### 高风险

1. **调整遗漏导致审定数失真**：已识别的错报未编制调整分录，审定数仍为错误的未审数，导致报表错报。
2. **调整借贷不平衡**：调整分录借贷金额不平衡，导致试算平衡表失衡，影响整体报表准确性。
3. **缺乏审批的越权调整**：调整未经合伙人批准即纳入审定表，存在错误调整或人为操纵审定数的风险。

### 中风险

1. **AJE与RJE混淆**：将影响金额的账项调整误作重分类，或反之，导致审定数或分类错误。
2. **回写审定表错误**：调整金额未准确回写或回写至错误科目行，审定数与调整脱节。
3. **未调整错报累积超重要性**：单项未调整错报未超重要性，但累计后可能超过整体重要性水平未评估。

### 低风险

1. **调整说明不充分**：调整分录缺少原因说明，增加复核理解难度。
2. **交叉索引不完整**：调整分录未与来源底稿（余额调节表/函证/外币折算）建立索引引用。
3. **格式不规范**：调整分录格式、编号不统一，影响可读性。
