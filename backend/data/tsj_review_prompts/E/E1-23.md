# E1-23 收支检查情况表复核提示词

## 概述

本提示词针对货币资金收支检查情况表（E1-23）的复核，聚焦大额及异常收支凭证的样本选取合理性、凭证核对完整性、检查比例达标性、以及异常收支的舞弊迹象识别。收支检查是凭证级实质性程序，通过核查大额、异常货币资金收支凭证，验证资金往来的真实性、完整性与业务实质，是识别资金体外循环和舞弊的关键。

**法规依据：**
- 《中国注册会计师审计准则第1314号——审计抽样》
- 《中国注册会计师审计准则第1301号——审计证据》
- 《中国注册会计师审计准则第1141号——财务报表审计中与舞弊相关的责任》

## tips

1. **样本选取须覆盖大额与异常收支**：金额重大、对方为关联方/个人、无合同支持、整数金额、节假日交易等高风险收支须纳入必选样本。
2. **凭证核对须验证完整业务链**：核对记账凭证、原始单据（合同/发票/银行回单）、审批手续，验证收支真实性与业务实质。
3. **收支方向与对方科目须核对**：核对借贷方向、对方明细科目，识别异常对手方（如大额资金流向个人、关联方）。
4. **检查比例须达标**：检查金额占本期收支发生额比例应达到计划水平，比例不足须说明或扩大样本（CAS1314）。
5. **异常收支须标注类型并追查**：金额异常/时间异常/对手方异常/业务逻辑异常须标注并作进一步核查，评估舞弊迹象。
6. **警惕资金体外循环迹象**：大额资金频繁进出、往返于关联方或个人账户、无实质业务支持的收支，可能为资金体外循环或商业贿赂。

## checklist

### 一、样本选取合理性

- [ ] 样本选取方法是否与货币资金舞弊风险匹配
- [ ] 金额重大收支是否纳入必选样本
- [ ] 对方为关联方/个人的收支是否纳入
- [ ] 无合同支持、整数金额、异常时间的收支是否纳入
- [ ] 抽样是否符合CAS1314要求

### 二、凭证核对完整性

- [ ] 记账凭证与原始单据（合同/发票/银行回单）是否齐全一致
- [ ] 收支审批手续是否完整
- [ ] 借贷方向、对方明细科目是否核对
- [ ] 银行回单日期、对方、金额是否与账面一致
- [ ] 是否核对完整业务链验证真实性

### 三、检查比例达标性

- [ ] 检查金额占本期收支发生额比例是否达标
- [ ] 借方（收入）检查比例是否达标
- [ ] 贷方（支出）检查比例是否达标
- [ ] 比例不足是否说明原因或扩大样本

### 四、异常识别与追查

- [ ] 异常收支是否全部标注异常类型
- [ ] 大额资金流向个人/关联方是否核查
- [ ] 是否识别资金体外循环迹象
- [ ] 异常事项是否作进一步核查并记录结论
- [ ] 发现舞弊迹象是否提请项目组关注并扩大测试

## risk_areas

### 高风险

1. **资金体外循环**：大额资金频繁往返于关联方/个人账户、无实质业务支持，可能为资金体外循环、虚构业务或商业贿赂。
2. **虚构收支凭证**：伪造合同、发票、回单支持虚假资金往来，需交叉核对多方原始单据。
3. **大额资金异常流向个人**：货币资金大额流向个人账户无合理业务解释，存在资金挪用或利益输送风险。

### 中风险

1. **检查比例不足**：实际检查比例低于计划水平，审计证据不充分。
2. **凭证核对不完整**：仅核对金额未验证业务实质（合同/发票/审批一致性）。
3. **异常收支未追查**：标注异常但未进一步核查业务实质。

### 低风险

1. **样本记录不完整**：抽样参数、选取依据记录不充分。
2. **检查结果格式不规范**：核对结果记录格式不统一。
3. **交叉索引不完整**：收支检查表未与审定表、截止测试、明细表建立索引引用。
