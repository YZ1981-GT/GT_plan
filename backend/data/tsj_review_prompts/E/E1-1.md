# E1-1 货币资金审定表复核提示词

## 概述

本提示词针对货币资金审定表（E1-1）的复核，聚焦库存现金（1001）、银行存款（1002）、其他货币资金（1012）三类科目的期初期末勾稽、试算平衡表核对、审计调整完整性与受限货币资金列报。审定表是货币资金审计的枢纽底稿，承载未审数→调整→审定数的完整链路，任何勾稽断裂、外币折算错误或受限资金未披露均可能导致报表重大错报。

**法规依据：**
- 《企业会计准则第22号——金融工具确认和计量》
- 《企业会计准则第37号——金融工具列报》
- 《企业会计准则第19号——外币折算》
- 《中国注册会计师审计准则第1301号——审计证据》

## tips

1. **三类科目审定数须分别与试算平衡表勾稽**：库存现金（1001）、银行存款（1002）、其他货币资金（1012）审定数须分别与试算平衡表对应科目审定数完全一致，货币资金合计等于三者之和。
2. **期初审定数必须承前启后**：期初审定数须等于上年审定表期末审定数，任何差异需追溯至会计政策变更或前期差错更正，不得存在无源差异。
3. **外币货币资金须核对折算汇率与折算差额**：外币存款须按资产负债表日即期汇率折算，折算差额计入财务费用（汇兑损益），审定数须反映折算后人民币金额（CAS19）。
4. **受限货币资金须识别并单独列报**：保证金、冻结资金、监管账户、定期存单质押等受限部分不得列示为普通货币资金，应重分类或在附注单独披露。
5. **审计调整必须完整反映**：所有已确认的账项调整（AJE）和重分类调整（RJE，如受限资金重分类）须完整纳入审定表，审定数=未审数+AJE+RJE。
6. **审定表是跨底稿勾稽中心**：审定数应与现金明细（E1-2）、银行存款明细（E1-3）、余额调节表（E1-6）、账户清单（E1-10）、附注披露形成闭环，任何节点断裂均为复核重点。

## checklist

### 一、期初期末勾稽

- [ ] 期初未审数是否等于上年审定表期末审定数（承前启后核对）
- [ ] 期初审定数是否等于期初未审数加期初追溯调整（如有）
- [ ] 期末审定数是否等于期初审定数加本期借方发生额减本期贷方发生额（加减审计调整）
- [ ] 库存现金/银行存款/其他货币资金各行期初期末变动是否与明细表增减一致
- [ ] 是否存在期初数据被修改但未留痕或未说明的情况

### 二、试算平衡表与三类科目核对

- [ ] 库存现金审定数是否与试算平衡表1001科目审定数一致
- [ ] 银行存款审定数是否与试算平衡表1002科目审定数一致
- [ ] 其他货币资金审定数是否与试算平衡表1012科目审定数一致
- [ ] 货币资金合计是否等于1001+1002+1012三科目审定数之和
- [ ] 试算平衡表未审数、调整数是否与审定表对应列一致

### 三、审计调整与外币折算

- [ ] 所有账项调整（AJE）是否完整反映在审定表调整列且借贷平衡
- [ ] 受限货币资金重分类调整（RJE）是否已纳入且方向正确
- [ ] 审定后金额是否等于未审数+AJE+RJE
- [ ] 外币货币资金是否按资产负债表日即期汇率折算
- [ ] 汇兑折算差额是否计入财务费用并与利润表勾稽
- [ ] 建议但未调整的错报是否记录于未调整错报汇总表（SUD）

### 四、分类列报与受限披露

- [ ] 库存现金、银行存款、其他货币资金三类是否分别列示未混淆
- [ ] 受限货币资金（保证金/冻结/监管账户/质押存单）是否已识别并单独列报或披露
- [ ] 其他货币资金明细（银行汇票/本票/信用证保证金等）是否列示正确
- [ ] 审定表分类是否与财务报表附注披露口径一致
- [ ] 存在受限资金时是否已在附注中说明受限性质、金额与期限

## risk_areas

### 高风险

1. **受限货币资金未识别列报**：保证金、冻结资金、监管账户资金仍列示为可自由动用的货币资金，虚增企业流动性，误导报表使用者。
2. **期初期末不勾稽**：期初审定数与上年期末审定数不一致，可能存在未经授权的调整或数据录入错误，动摇本期审定基准。
3. **外币折算错误**：外币存款未按资产负债表日汇率折算或汇兑差额计算错误，导致货币资金金额与损益同时失真。
4. **三类科目与试算平衡表不勾稽**：库存现金/银行存款/其他货币资金审定数与试算平衡表口径不一致，意味着存在未发现的汇总错误或调整遗漏。
5. **审计调整遗漏**：已确认的调整分录未反映在审定表中，导致审定数不真实，可能掩盖资金舞弊或错报。

### 中风险

1. **明细与汇总不勾稽**：审定表各行合计与银行存款明细（E1-3）、现金明细（E1-2）总计不一致，可能存在明细遗漏或重复。
2. **余额调节表未达账项未反映**：银行存款审定数未考虑余额调节表（E1-6）中应调整的未达账项，导致账实不符。
3. **审定表与附注披露口径不一致**：审定表分类与附注披露分类不一致，影响信息一致性。
4. **重分类调整方向错误**：受限资金重分类RJE借贷方向颠倒或冲抵不完全。

### 低风险

1. **审定表格式不规范**：列标题、行顺序、编号等格式问题不影响数据准确性，但影响可读性和复核效率。
2. **底稿交叉索引不完整**：审定表未与试算平衡表、明细表、调整分录等相关底稿建立完整索引引用。
3. **辅助说明不充分**：变动较大的科目行未附简要说明，增加复核理解难度。
4. **历史数据对比缺失**：未列示前期可比数据，不便于分析趋势和异常。
