# E1-2 库存现金明细复核提示词

## 概述

本提示词针对库存现金明细表（E1-2，科目1001）的复核，聚焦各现金账户（人民币现金、外币现金、备用金）的期末余额构成、账实核对、大额现金保有合理性与内控符合性。库存现金是最易被挪用、贪污的资产，明细表须真实反映各现金保管点的余额，并与盘点结果（E1-7/E1-8）勾稽。

**法规依据：**
- 《中国注册会计师审计准则第1301号——审计证据》
- 《中国注册会计师审计准则第1311号——对存货、诉讼和索赔、分部信息的具体考虑》
- 《现金管理暂行条例》

## tips

1. **明细表须按现金保管点分别列示**：各币种、各保管地点（出纳、备用金、门店零钱）的现金余额应分行列示，合计等于审定表库存现金审定数。
2. **账面余额须与盘点结果勾稽**：明细表各账户期末余额须与库存现金盘点表（E1-7人民币、E1-8外币）盘点金额核对一致，差异需查明原因。
3. **关注大额现金保有的合理性**：企业保有大额现金（超过日常经营所需）可能存在资金体外循环、白条抵库或虚假现金迹象。
4. **外币现金须按资产负债表日汇率折算**：外币现金明细须列示原币金额、折算汇率与折算后人民币金额，折算差额计入财务费用。
5. **警惕白条抵库和现金坐支**：现金明细中如存在以借条、未报销单据充抵现金的情况，属违规且虚增现金余额。
6. **现金收支须遵守现金管理规定**：超过结算起点的大额支出应通过银行转账，明细表中异常大额现金收支应重点关注。

## checklist

### 一、明细构成与勾稽

- [ ] 库存现金明细是否按币种和保管点分别列示
- [ ] 各明细行期末余额合计是否等于审定表库存现金（1001）审定数
- [ ] 明细表期末余额是否与序时账（tb_ledger）现金科目余额一致
- [ ] 各现金账户期初余额是否与上年期末一致
- [ ] 是否存在负数现金余额（现金不可能为负，负数即错误或坐支）

### 二、账实核对

- [ ] 明细表各账户余额是否与库存现金盘点表（E1-7/E1-8）勾稽一致
- [ ] 盘点日与资产负债表日不一致时，是否已倒轧至资产负债表日
- [ ] 是否存在账实差异未查明原因或未调整的情况
- [ ] 外币现金是否列示原币、折算汇率与折算后人民币金额
- [ ] 外币折算是否采用资产负债表日即期汇率

### 三、合理性与合规性

- [ ] 大额现金保有是否与业务规模、经营需要匹配
- [ ] 是否存在白条抵库、借条充抵现金的违规情况
- [ ] 是否存在现金坐支（用现金收入直接支付）迹象
- [ ] 大额现金收支是否符合现金管理规定（超结算起点应转账）
- [ ] 备用金是否定额管理，超定额部分是否及时上缴

## risk_areas

### 高风险

1. **白条抵库虚增现金**：以借条、未报销单据充抵库存现金，实际现金已被挪用或占用，导致现金余额虚假。
2. **大额现金体外循环**：企业无正当理由保有或频繁收支大额现金，可能存在资金体外循环、虚构业务或商业贿赂。
3. **账实不符未调整**：盘点金额与账面余额存在差异但未查明原因、未作调整，掩盖现金短缺或长款。
4. **现金坐支违规**：用现金收入直接支付费用，绕过银行账户，导致收支不完整、账实脱节。

### 中风险

1. **外币现金折算错误**：外币现金未按资产负债表日汇率折算或汇率取值错误，导致折算金额失真。
2. **明细与盘点脱节**：明细表未与盘点表勾稽，或盘点日未倒轧至资产负债表日，账实核对流于形式。
3. **现金余额与业务规模不匹配**：现金保有量畸高或畸低，未分析原因，可能隐藏异常。

### 低风险

1. **明细列示不规范**：现金保管点、币种未清晰分行列示，影响可读性。
2. **备用金管理不规范**：备用金未定额管理但金额较小，不构成重大风险。
3. **交叉索引不完整**：现金明细未与盘点表、审定表建立索引引用。
