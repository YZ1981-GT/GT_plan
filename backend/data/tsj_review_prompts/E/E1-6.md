# E1-6 银行存款余额调节表复核提示词

## 概述

本提示词针对银行存款余额调节表（E1-6）的复核，聚焦企业账面余额与银行对账单余额的调节、未达账项的真实性与合理性、调节后余额一致性、以及长期挂账未达账项的异常识别。余额调节表是验证银行存款存在性与完整性的关键工具，未达账项的异常挂账往往隐藏虚假存款、资金挪用或跨期错报。

**法规依据：**
- 《中国注册会计师审计准则第1312号——函证》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **调节表须双向调节至相同余额**：企业账面余额调整企业方未达账项、银行对账单余额调整银行方未达账项，调节后双方余额必须相等。
2. **未达账项须逐笔核实真实性**：企业已收银行未收、企业已付银行未付、银行已收企业未收、银行已付企业未收四类未达账项须逐笔有原始凭证支持。
3. **警惕长期挂账未达账项**：长期（超过一个月）未清理的未达账项异常，可能为虚构存款、资金被挪用或以未达账项掩盖账实差异。
4. **期后核销验证未达账项真实性**：资产负债表日后未达账项应在合理期间内自然核销，核查期后银行流水验证其真实性。
5. **调节表须与函证、明细表勾稽**：企业账面余额须与银行存款明细（E1-3）勾稽，银行对账单余额须与银行询证回函（E1-11）勾稽。
6. **大额未达账项重点核查**：金额重大的未达账项须核查对应业务实质，防范以未达账项虚增或虚减存款余额。

## checklist

### 一、调节逻辑与勾稽

- [ ] 调节表是否对每个银行账户分别编制
- [ ] 企业账面余额是否与银行存款明细表（E1-3）账户余额一致
- [ ] 银行对账单余额是否与银行询证回函（E1-11）确认金额一致
- [ ] 调节后企业方余额是否等于调节后银行方余额
- [ ] 调节表调节后余额是否与审定表银行存款审定数勾稽

### 二、未达账项真实性

- [ ] 企业已收银行未收（在途存款）是否有原始凭证支持
- [ ] 企业已付银行未付（在途付款）是否有原始凭证支持
- [ ] 银行已收企业未收是否已查明并作调整
- [ ] 银行已付企业未付是否已查明并作调整
- [ ] 各未达账项金额是否准确、方向是否正确

### 三、异常挂账识别

- [ ] 是否存在超过一个月未清理的长期未达账项
- [ ] 长期未达账项是否查明原因并评估是否需调整
- [ ] 是否存在金额重大的未达账项且业务实质存疑
- [ ] 是否存在以未达账项掩盖账实差异的迹象
- [ ] 未达账项是否存在人为拼凑以使调节表平衡的情况

### 四、期后核销验证

- [ ] 资产负债表日未达账项是否在期后合理期间内自然核销
- [ ] 期后未核销的未达账项是否重新评估真实性
- [ ] 是否核查期后银行流水验证未达账项
- [ ] 应作调整的未达账项是否已编制调整分录（E1-5）

## risk_areas

### 高风险

1. **虚构未达账项虚增存款**：以不存在的在途存款拼凑调节表使账实"平衡"，实际存款已被挪用或从未存在。
2. **长期未达账项掩盖资金挪用**：大额未达账项长期挂账不核销，掩盖资金被占用、挪用或账实不符的事实。
3. **调节表不平衡强行轧平**：调节后双方余额不等却人为调整数字使其相等，掩盖真实的账实差异。

### 中风险

1. **未达账项缺乏凭证支持**：未达账项无原始凭证或对账单支持，真实性无法验证。
2. **期后未自然核销**：资产负债表日未达账项期后长期未核销，可能为虚构或错报，未重新评估。
3. **应调整未达账项未调整**：属于银行已收/已付企业未记的项目应作调整但未编制调整分录。

### 低风险

1. **调节表格式不规范**：未达账项分类、列示不清晰，影响可读性。
2. **交叉索引不完整**：调节表未与明细表、函证、调整分录建立索引引用。
3. **未达账项说明不充分**：大额未达账项未附业务说明，增加复核难度。
