# E1-note-soe 货币资金附注披露复核提示词（国有企业）

## 概述

本提示词针对货币资金国有企业附注披露底稿（E1-note-soe）的复核，聚焦国有企业特定的货币资金披露要求：基础分类披露、受限货币资金披露、国资监管相关的资金专户与财政性资金披露、大额资金存放合规性、以及与决算报表的衔接。国有企业货币资金审计具有财务审计与国有资产监管双重属性，附注须同时满足会计准则与国资监管要求。

**法规依据：**
- 《企业会计准则第37号——金融工具列报》
- 《企业会计准则第22号——金融工具确认和计量》
- 《企业会计准则第19号——外币折算》
- 《中央企业财务决算报告管理办法》

---

## tips

1. **国企货币资金有双层披露要求**：既满足企业会计准则（分类/受限/外币）通用要求，又满足国资委财务决算的额外披露要求，两套要求互为补充。
2. **受限货币资金仍是披露核心**：抵押、质押、冻结、保证金等受限资金须单独披露，国企尤须关注大额定期存款质押、专项资金受限情况。
3. **财政性资金与专项资金须单独披露**：财政拨款专户、专项资金专户等具有专门用途、使用受限的资金须单独说明性质、金额与使用限制。
4. **大额资金存放合规性须关注**：国企大额资金存放须符合国资监管要求（如集中存放、存款银行准入），异常存放安排须披露。
5. **资金归集与内部往来**：集团资金归集（资金池）安排下，附注货币资金与母子公司往来须清晰，合并层面内部资金往来抵销须完整。
6. **须与决算报表及审定表衔接**：附注货币资金数据须与年度财务决算报表、审定表审定数一致，差异须调节说明。

## checklist

### 一、基础披露完整性（与上市版共有）

- [ ] 货币资金是否按库存现金/银行存款/其他货币资金分项披露
- [ ] 各分项是否列示期末数与期初数
- [ ] 各分项合计是否等于审定表货币资金审定数
- [ ] 受限货币资金是否单独披露金额与原因
- [ ] 重要外币货币资金是否披露原币、汇率、折算金额

### 二、受限与专项资金披露

- [ ] 抵押/质押/冻结/保证金受限资金是否单独披露
- [ ] 财政性资金专户是否单独披露性质、金额、用途限制
- [ ] 专项资金专户（专款专用）是否单独披露
- [ ] 受限及专项资金是否从现金及现金等价物中剔除
- [ ] 大额定期存款质押是否与借款/担保披露勾稽

### 三、国资监管相关披露

- [ ] 大额资金存放是否符合国资监管要求（集中存放/银行准入）
- [ ] 异常存放安排是否披露
- [ ] 集团资金归集（资金池）安排是否说明
- [ ] 与母子公司资金往来（以货币资金/其他货币资金体现）是否清晰
- [ ] 存放境外资金是否披露金额、地区及汇回限制

### 四、决算报表衔接

- [ ] 附注货币资金数据是否与年度财务决算报表一致
- [ ] 决算数据与审计后附注数据差异是否调节说明
- [ ] 合并层面内部资金往来抵销是否完整
- [ ] 现金流量表现金及等价物衔接是否说明

### 五、与上市版差异关注点

- [ ] 是否在基础披露基础上增加财政性/专项资金披露
- [ ] 是否增加大额资金存放合规性说明
- [ ] 是否增加资金归集/内部往来说明
- [ ] 关联方范围是否扩展至同受国有控制企业的资金往来

## risk_areas

### 高风险

1. **受限及专项资金未披露**：抵押质押、财政专项等受限资金未单独披露，误导对企业可动用资金的判断，且可能掩盖专项资金挪用。
2. **附注与决算/审定表不一致**：附注货币资金数据与决算报表、审定表审定数不一致，属重大数据错误。
3. **大额资金异常存放未披露**：违规存放、体外资金或大额资金异常安排未披露，可能掩盖国有资产流失风险。

### 中风险

1. **专项资金性质说明不充分**：财政性/专项资金已披露但用途限制、专款专用情况说明不足。
2. **资金归集安排未说明**：集团资金池、内部资金往来未清晰披露，影响资金可用性判断。
3. **境外资金披露不完整**：存放境外资金金额、汇回限制未充分披露。

### 低风险

1. **披露格式未完全按决算模板**：附注格式与国资委决算报表模板有细微差异但信息完整。
2. **文字说明模板化**：受限原因、存放安排说明过于笼统。
3. **交叉索引不完整**：附注未与受限识别、借款、担保、决算报表建立索引引用。
