# E1-8 库存现金（外币）盘点表复核提示词

## 概述

本提示词针对库存现金外币盘点表（E1-8）的复核，聚焦外币现金的现场监盘、外币折算准确性、倒轧至资产负债表日、以及外币现金保有合理性。外币现金盘点在库存现金盘点基础上叠加外币折算维度，须记录原币金额、折算汇率与折算后人民币金额，并按资产负债表日即期汇率折算（CAS19）。

**法规依据：**
- 《中国注册会计师审计准则第1311号——对存货、诉讼和索赔、分部信息的具体考虑》
- 《企业会计准则第19号——外币折算》
- 《中国注册会计师审计准则第1301号——审计证据》

## tips

1. **外币现金须按币种分别盘点**：不同外币（美元、欧元、港币等）应分别清点、分别列示原币金额，不得混计。
2. **须记录原币、汇率与折算金额**：盘点表须列示各币种原币实存金额、资产负债表日即期汇率与折算后人民币金额。
3. **折算须采用资产负债表日即期汇率**：外币现金折算汇率须为资产负债表日的即期汇率，非盘点日汇率，折算差额计入财务费用（CAS19）。
4. **审计师现场监盘、出纳在场**：与人民币现金盘点一致，须现场监督、出纳在场、签字确认。
5. **倒轧须同时考虑原币收支与汇率**：盘点日至报表日的外币收支须以原币倒轧至报表日原币余额，再按报表日汇率折算。
6. **关注外币现金保有合理性**：企业保有大额外币现金须与外币业务规模匹配，异常外币现金可能存在资金异常或洗钱风险。

## checklist

### 一、盘点程序合规性

- [ ] 外币现金盘点是否由审计师现场监督执行
- [ ] 出纳是否全程在场并签字确认
- [ ] 各币种是否分别清点、分别列示
- [ ] 盘点是否当场实际清点而非凭自报

### 二、原币构成与实存

- [ ] 各币种是否记录面额构成与原币实存金额
- [ ] 各币种原币金额是否准确合计
- [ ] 是否存在白条、借条充抵外币现金的情况

### 三、外币折算准确性

- [ ] 折算汇率是否采用资产负债表日即期汇率
- [ ] 各币种折算后人民币金额是否计算准确
- [ ] 折算差额是否计入财务费用（汇兑损益）
- [ ] 折算后合计是否与外币现金账面（E1-2）核对

### 四、倒轧与差异处理

- [ ] 盘点日实存原币是否倒轧至资产负债表日原币余额
- [ ] 盘点日至报表日外币收支是否有原始凭证支持
- [ ] 倒轧后原币余额折算金额是否与账面核对
- [ ] 账实差异（原币/折算后）是否查明原因并处理

## risk_areas

### 高风险

1. **外币折算错误双重失真**：折算汇率错误或未按报表日汇率折算，导致外币现金金额与汇兑损益同时失真。
2. **盘点走过场无法验证存在性**：外币现金未实际清点或无法可靠倒轧，丧失存在性验证能力。
3. **大额异常外币现金**：企业保有与业务规模不匹配的大额外币现金，可能存在资金异常、洗钱或走私风险。

### 中风险

1. **各币种混计折算**：不同外币未分别列示与折算，导致折算金额不准确。
2. **倒轧未考虑汇率变动**：倒轧仅按原币而折算未采用报表日汇率，或收支缺乏凭证支持。
3. **账实差异未处理**：外币现金账实差异查明后未作处理。

### 低风险

1. **面额构成未记录**：外币盘点表未记录面额明细。
2. **盘点表格式不规范**：币种、汇率、参与人等要素记录不全。
3. **交叉索引不完整**：外币盘点表未与现金明细、审定表建立索引引用。
