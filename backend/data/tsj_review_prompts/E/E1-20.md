# E1-20 应计利息测算复核提示词

## 概述

本提示词针对应计利息测算表（E1-20）的复核，聚焦定期存款、大额存单等应计未收利息的计算准确性、计提完整性、期末应计利息与账面勾稽、以及利率与计息天数的合理性。应计利息测算验证权责发生制下利息收入的完整确认，漏提或错提应计利息将导致利息收入与其他货币资金/应收利息失真。

**法规依据：**
- 《中国注册会计师审计准则第1313号——分析程序》
- 《企业会计准则第22号——金融工具确认和计量》

---

## tips

1. **应计利息按权责发生制计提**：对定期存款、存单等，资产负债表日应计提自上次付息日至报表日的应计未收利息，即使尚未实际收到。
2. **计算三要素须核实**：应计利息=本金×利率×计息天数/360(或365)，本金、利率、计息天数三要素均须核实准确。
3. **利率须与存款协议一致**：测算采用的利率须与存款合同/存单载明利率一致，不得使用错误利率。
4. **计息天数须准确**：自上次结息日（或起息日）至资产负债表日的实际天数，须准确计算，注意闰年与计息基准（360/365）。
5. **应计利息列报归属**：应计利息通常计入其他货币资金或应收利息，须核实列报科目正确。
6. **与利息收入分析勾稽**：应计利息计提金额须与利息收入月度分析（E1-15）、损益勾稽，避免重复或遗漏。

## checklist

### 一、计提完整性

- [ ] 所有应计提利息的存款/存单是否均已测算
- [ ] 定期存款、大额存单是否覆盖完整
- [ ] 是否存在应计提而漏提的情况
- [ ] 计提是否覆盖至资产负债表日

### 二、计算准确性

- [ ] 应计利息计算公式是否正确（本金×利率×天数/基准）
- [ ] 测算本金是否与存款余额一致
- [ ] 测算利率是否与存款协议/存单载明利率一致
- [ ] 计息天数是否准确（起息日/上次结息日至报表日）
- [ ] 计息基准（360/365）是否正确且一致

### 三、勾稽与列报

- [ ] 应计利息期末余额是否与账面勾稽
- [ ] 应计利息列报科目是否正确（其他货币资金/应收利息）
- [ ] 应计利息是否与利息收入分析（E1-15）勾稽
- [ ] 计提利息是否与损益（利息收入）勾稽
- [ ] 是否存在重复计提或遗漏

### 四、合理性

- [ ] 应计利息金额与存款规模、利率是否合理匹配
- [ ] 是否存在异常高/低的应计利息
- [ ] 已到期存款应计利息是否已转应收或实收

## risk_areas

### 高风险

1. **应计利息漏提**：定期存款应计未收利息漏提，低估利息收入和资产，影响损益和资产完整性。
2. **利率错误导致金额失真**：采用错误利率测算，导致应计利息金额与实际严重偏离。

### 中风险

1. **计息天数错误**：起息日或计息基准错误导致应计利息计算偏差。
2. **列报科目错误**：应计利息列报科目不当，影响列报准确性。
3. **重复计提**：应计利息与已收利息重复，虚增利息收入。

### 低风险

1. **计算过程记录不完整**：测算三要素记录不充分，影响复核。
2. **勾稽不完整**：应计利息未与利息分析、损益充分勾稽。
3. **交叉索引不完整**：应计利息测算未与银行存款明细、利息分析建立索引引用。
