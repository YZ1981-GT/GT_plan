# E1-10 银行账户核对表复核提示词

## 概述

本提示词针对银行账户核对表（E1-10）的复核，聚焦银行账户清单的完整性、账户与信用报告/函证的双向核对、隐性账户识别、以及销户与新开户的完整性。账户核对是发现账外银行账户、隐匿资金的关键程序，须将企业提供的账户清单与企业信用报告（E1-18/19）、银行询证回函三方交叉核对。

**法规依据：**
- 《中国注册会计师审计准则第1312号——函证》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **账户清单须三方双向核对**：企业提供的账户清单、企业信用报告披露的账户、银行询证回函确认的账户三方交叉核对，任一方存在而其他方缺失即为异常。
2. **信用报告是发现隐性账户的利器**：人民银行企业信用报告披露企业全部银行结算账户，信用报告有而账面无的账户为潜在账外账户，须重点核查。
3. **销户账户须验证余额清零与去向**：本期销户账户须核实销户前余额去向，防止销户掩盖资金转移。
4. **新开户须有审批与业务合理性**：本期新开账户须有内部审批，评估开户业务合理性，警惕为体外循环开立账户。
5. **零余额与长期不动户须核查**：零余额账户是否应销未销，长期不动户是否隐藏异常交易。
6. **每个账户须发函证**：账户清单中每个账户（含零余额）原则上均应发出银行询证函，验证存在性与余额。

## checklist

### 一、账户清单完整性

- [ ] 账户清单是否列示全部银行结算账户（含活期/定期/专户/外币）
- [ ] 账户清单是否包含零余额账户和长期不动户
- [ ] 各账户是否列示开户行、账号、账户类型、余额
- [ ] 账户清单余额合计是否与银行存款审定数勾稽

### 二、三方双向核对

- [ ] 账户清单是否与企业信用报告（E1-18/19）披露账户核对
- [ ] 账户清单是否与银行询证回函账户核对
- [ ] 是否存在信用报告有而账面无的账户（账外账户）
- [ ] 是否存在账面有而信用报告无的账户
- [ ] 是否存在函证回函账户而清单遗漏的情况

### 三、销户与新开户

- [ ] 本期销户账户是否核实销户前余额去向
- [ ] 销户是否有完整审批记录
- [ ] 本期新开账户是否有内部审批
- [ ] 新开账户业务合理性是否评估
- [ ] 销户/新开户是否与信用报告变动一致

### 四、异常账户核查

- [ ] 零余额账户是否应销未销
- [ ] 长期不动户是否隐藏异常交易
- [ ] 是否存在开户主体与被审计单位不一致的疑似关联/个人账户
- [ ] 账外账户（如发现）是否核查资金往来性质

## risk_areas

### 高风险

1. **账外银行账户隐匿资金**：信用报告显示但账面未记录的账户，可能用于隐匿收入、体外资金循环或私设小金库，属重大舞弊风险。
2. **销户掩盖资金转移**：销户账户余额去向不明，可能通过销户转移或挪用资金。
3. **账户清单不完整**：企业故意遗漏账户不纳入清单，规避审计核查。

### 中风险

1. **三方核对不到位**：未与信用报告或函证双向核对，无法发现账外或遗漏账户。
2. **新开户业务合理性存疑**：新开账户无正当业务需要，可能为体外循环准备。
3. **长期不动户未核查**：长期无交易账户未核查是否隐藏异常。

### 低风险

1. **零余额账户未说明**：零余额账户应销未销但金额为零，风险较低。
2. **账户清单格式不规范**：账户要素列示不完整，影响可读性。
3. **交叉索引不完整**：账户核对表未与信用报告、函证、明细表建立索引引用。
