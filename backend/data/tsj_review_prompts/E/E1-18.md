# E1-18 企业信用报告查询复核提示词

## 概述

本提示词针对企业信用报告查询底稿（E1-18）的复核，聚焦人民银行企业信用报告的完整获取、查询时点恰当性、报告要素齐全性、以及作为账户与负债完整性核查证据的可靠性。企业信用报告是发现隐性银行账户、未入账借款、对外担保的权威第三方证据，是货币资金及负债完整性审计的关键工具。

**法规依据：**
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **信用报告须为人民银行出具的完整版**：应获取人民银行征信中心出具的企业信用报告（详版），非企业自行摘录，确保权威性与完整性。
2. **查询时点须接近资产负债表日**：信用报告查询日应尽量接近资产负债表日，以反映报表日的账户与负债状况，时点过早须评估影响。
3. **报告要素须齐全**：信用报告应涵盖全部结算账户、授信额度、借款、担保、票据承兑、逾期记录等，缺项影响核查完整性。
4. **信用报告是账户完整性核查基础**：报告披露的银行账户清单用于与账面账户双向核对（联动E1-10/E1-19），发现账外账户。
5. **信用报告揭示隐性负债**：报告中的借款、担保、承兑信息用于核查负债完整性，发现未入账借款或对外担保。
6. **查询授权须合规**：查询企业信用报告须取得企业授权，查询过程合规留痕。

## checklist

### 一、报告获取与时点

- [ ] 是否获取人民银行征信中心出具的企业信用报告（详版）
- [ ] 信用报告是否为完整版而非企业摘录
- [ ] 查询时点是否接近资产负债表日
- [ ] 查询时点过早是否评估对核查的影响
- [ ] 查询是否取得企业授权并合规留痕

### 二、报告要素完整性

- [ ] 报告是否涵盖全部银行结算账户
- [ ] 报告是否涵盖授信额度与使用情况
- [ ] 报告是否涵盖借款（贷款）记录
- [ ] 报告是否涵盖对外担保信息
- [ ] 报告是否涵盖票据承兑、信用证等或有事项
- [ ] 报告是否涵盖逾期、违约等信用记录

### 三、作为核查证据的可靠性

- [ ] 信用报告是否用于账户完整性双向核对（联动E1-10）
- [ ] 信用报告是否用于核查借款完整性
- [ ] 信用报告是否用于核查对外担保完整性
- [ ] 报告披露的异常信息是否已识别待核对（E1-19）

## risk_areas

### 高风险

1. **信用报告不完整或非权威版本**：使用企业自行摘录或过时报告，无法可靠发现账外账户和隐性负债。
2. **查询时点严重滞后**：查询日远离资产负债表日，无法反映报表日真实账户与负债状况。

### 中风险

1. **报告要素缺失**：信用报告缺少担保、借款或部分账户信息，核查完整性受限。
2. **未用于完整性核查**：获取报告后未与账面双向核对，未发挥核查作用。

### 低风险

1. **查询授权留痕不全**：查询授权或过程留痕不完整。
2. **报告归档不规范**：信用报告未妥善留档。
3. **交叉索引不完整**：信用报告查询底稿未与账户核对、信用报告核对建立索引引用。
