# E1-30 存款规模与利息收入匹配性分析复核提示词

## 概述

本提示词针对存款规模与利息收入匹配性分析底稿（E1-30，IPO/舞弊应对专项）的复核，聚焦银行存款规模与利息收入的匹配关系、理论利息与账面利息的差异、以及不匹配背后的存款真实性与资金占用问题。本底稿针对IPO及舞弊风险加严分析存款与利息的匹配性，是识别虚假存款、存款受限、资金被关联方占用的关键舞弊排查程序。

**法规依据：**
- 《中国注册会计师审计准则第1141号——财务报表审计中与舞弊相关的责任》
- 《中国注册会计师审计准则第1313号——分析程序》
- 《中国注册会计师审计准则第1301号——审计证据》

## tips

1. **理论利息测算与账面对比**：以各期平均存款余额乘以对应存款利率测算理论利息，与账面利息收入对比，差异重大是重要舞弊信号。
2. **存款高但利息极低是核心红旗**：巨额存款仅产生微薄利息，强烈提示存款不真实、被冻结质押、或实际由第三方（关联方）控制占用。
3. **分存款类型匹配分析**：活期、定期利率差异大，须按存款结构分别测算理论利息，避免混算掩盖异常。
4. **异常须核查存款真实性与资金占用**：不匹配须联动函证、账户核查、银行流水，核查存款是否真实、是否被质押冻结、是否被关联方占用。
5. **须先确认程序适用性**：确认企业是否属IPO/高舞弊风险适用情形，适用则核查执行充分性。
6. **不匹配迹象须扩大核查**：发现不匹配须核查存款真实性及资金占用并追加程序。

## checklist

### 一、程序适用性与理论测算

- [ ] 本程序适用情形（IPO/高舞弊风险）是否已确认
- [ ] 是否以平均存款余额测算理论利息
- [ ] 是否按存款类型（活期/定期）分别测算利率
- [ ] 理论利息测算参数（余额/利率/期间）是否合理

### 二、匹配性分析

- [ ] 理论利息与账面利息收入差异是否分析
- [ ] 差异重大是否查明原因
- [ ] 存款规模与利息收入是否匹配
- [ ] 是否识别存款高但利息极低的情况
- [ ] 是否分账户/分银行分析匹配性

### 三、真实性与占用核查

- [ ] 不匹配是否联动函证核查存款真实性
- [ ] 是否核查存款是否被质押、冻结
- [ ] 是否核查存款是否被关联方占用
- [ ] 是否核查存款是否实际由第三方控制

### 四、异常处理

- [ ] 发现不匹配迹象是否扩大核查
- [ ] 异常事项是否追加程序
- [ ] 是否提请项目组及合伙人关注
- [ ] 分析结论是否明确（匹配/差异已解释/发现迹象）

## risk_areas

### 高风险

1. **虚假存款**：存款规模巨大但利息收入极低，可能存款实际不存在或金额虚假，属IPO重大舞弊风险。
2. **存款被关联方占用**：账面大额存款实际被关联方或第三方控制占用，企业无法自由支配，利息不匹配是核心信号。
3. **存款受限未披露**：大额存款被质押冻结产生受限但账面列示为可动用，利息异常揭示受限真相。

### 中风险

1. **理论利息差异未解释**：理论与账面利息差异重大但未查明原因。
2. **未分类型测算**：理论利息未区分存款类型，测算不准确掩盖异常。
3. **不匹配未联动核查**：识别不匹配但未联动函证、账户核查真实性。

### 低风险

1. **测算依据不充分**：平均余额、利率取值依据不足。
2. **分析维度单一**：未分账户/分银行细化分析。
3. **交叉索引不完整**：本底稿未与利息分析、应计利息、函证建立索引引用。
