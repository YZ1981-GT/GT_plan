# E1-31 银行流水双向核对复核提示词

## 概述

本提示词针对银行流水双向核对底稿（E1-31，IPO/舞弊应对专项）的复核，聚焦银行流水与账面记录的双向完整核对、账外资金与未入账流水识别、资金往来真实性与完整性验证。本底稿针对IPO及舞弊风险执行银行流水与账面的逐笔双向核对，是发现账外资金循环、隐匿收入、资金体外运作的核心舞弊排查程序。

**法规依据：**
- 《中国注册会计师审计准则第1141号——财务报表审计中与舞弊相关的责任》
- 《中国注册会计师审计准则第1312号——函证》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **双向核对是核心**：账面→流水（账面每笔收支是否有流水对应）与流水→账面（流水每笔收支是否已入账）双向核对，仅单向核对无法发现账外流水。
2. **银行流水须完整获取**：须获取全部账户完整银行流水（含历史已销户账户），流水应由银行直接提供或经函证确认完整性。
3. **未入账流水是账外资金红旗**：银行流水中存在但账面未记录的收支，直接指向账外收入、体外循环或隐匿资金。
4. **大额资金往来须核查业务实质**：双向核对中大额、频繁、往返关联方/个人的资金往来须核查业务实质与真实性。
5. **须先确认程序适用性**：确认企业是否属IPO/高舞弊风险适用情形，适用则核查双向核对执行充分性。
6. **账外资金/未入账流水须进一步核查**：发现账外资金或未入账流水须追查资金来源去向并追加程序。

## checklist

### 一、程序适用性与流水完整性

- [ ] 本程序适用情形（IPO/高舞弊风险）是否已确认
- [ ] 是否获取全部账户完整银行流水
- [ ] 已销户账户历史流水是否纳入
- [ ] 流水完整性是否经银行直接提供或函证确认

### 二、双向核对

- [ ] 账面→流水：账面每笔收支是否有流水对应
- [ ] 流水→账面：流水每笔收支是否已入账
- [ ] 是否识别账面有而流水无的记录
- [ ] 是否识别流水有而账面无的记录（未入账流水）
- [ ] 核对是否覆盖全部账户全部期间

### 三、异常资金核查

- [ ] 未入账流水是否追查资金来源去向
- [ ] 大额资金往来是否核查业务实质
- [ ] 往返关联方/个人的资金往来是否核查
- [ ] 是否识别账外资金循环迹象

### 四、异常处理

- [ ] 发现账外资金/未入账流水是否进一步核查
- [ ] 异常事项是否追加程序
- [ ] 是否提请项目组及合伙人关注
- [ ] 核对结论是否明确（一致/差异已解释/发现账外）

## risk_areas

### 高风险

1. **账外资金/未入账流水**：银行流水存在但账面未记录的收支，直接证明账外收入、体外循环或隐匿资金，属IPO最严重舞弊风险。
2. **虚构资金往来**：账面记录但流水无对应，可能为虚构资金往来粉饰交易或虚增收入闭环。
3. **资金体外循环**：大额资金往返于关联方/个人账户无实质业务，构成资金体外循环。

### 中风险

1. **流水不完整**：未获取全部账户完整流水（尤其已销户账户），双向核对存在盲区。
2. **单向核对**：仅账面→流水或流水→账面单向核对，无法发现另一方向异常。
3. **大额往来未核查实质**：识别大额资金往来但未核查业务实质。

### 低风险

1. **核对记录不完整**：双向核对过程、差异说明记录不充分。
2. **核对期间覆盖不足**：未覆盖完整报告期。
3. **交叉索引不完整**：本底稿未与账户清单、函证、收支检查建立索引引用。
