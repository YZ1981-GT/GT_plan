# E1-27 现金收支截止性检查复核提示词

## 概述

本提示词针对现金收支截止性检查底稿（E1-27，IPO/舞弊应对专项）的复核，聚焦现金收支的会计期间归属、跨期错报识别、期末现金收支操纵排查。本底稿在常规截止测试基础上针对IPO及舞弊风险加严核查，重点识别通过现金收支跨期调节收入、粉饰业绩的舞弊行为。

**法规依据：**
- 《中国注册会计师审计准则第1141号——财务报表审计中与舞弊相关的责任》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **截止测试须覆盖报表日前后现金收支**：选取资产负债表日前后现金收支，核对实际发生日期与记账期间是否一致。
2. **以现金流水/原始单据判断实际期间**：以现金日记账、收付款原始单据判断收支实际发生期间，识别人为调节记账日期。
3. **警惕期末现金收入跨期调节**：期末通过提前/延后确认现金收入调节业绩，属舞弊性截止操纵。
4. **现金支出跨期影响费用期间**：现金费用支出跨期导致费用期间归属错误，影响损益真实性。
5. **须先确认程序适用性**：确认企业是否属IPO/高舞弊风险适用情形，适用则核查执行充分性。
6. **跨期错报须扩大测试期间**：发现跨期舞弊迹象须扩大测试期间并追加程序。

## checklist

### 一、程序适用性与范围

- [ ] 本程序适用情形（IPO/高舞弊风险）是否已确认
- [ ] 测试是否覆盖资产负债表日前后合理期间
- [ ] 大额现金收支是否纳入截止测试
- [ ] 期末最后几笔、期初最初几笔现金收支是否纳入

### 二、期间归属核对

- [ ] 是否以现金日记账/原始单据判断实际发生期间
- [ ] 记账日期是否与实际发生期间一致
- [ ] 是否识别报表日前发生记入下期的现金收支
- [ ] 是否识别报表日后发生记入本期的现金收支

### 三、跨期操纵排查

- [ ] 期末现金收入是否存在跨期调节业绩迹象
- [ ] 现金费用支出跨期是否影响费用期间
- [ ] 跨期收支是否评估对收入/费用/余额的影响
- [ ] 应调整跨期错报是否已编制调整分录

### 四、异常处理

- [ ] 发现跨期舞弊迹象是否扩大测试期间
- [ ] 异常事项是否追加程序核查
- [ ] 是否提请项目组及合伙人关注
- [ ] 截止结论是否明确（无跨期/应调整/发现迹象）

## risk_areas

### 高风险

1. **现金收入跨期调节业绩**：期末提前或延后确认现金收入以粉饰业绩，属IPO舞弊性截止操纵。
2. **跨期错报影响损益真实性**：现金收支跨期导致收入、费用期间归属错误，扭曲经营成果。

### 中风险

1. **大额现金收支未截止测试**：金额重大的现金收支未纳入截止测试。
2. **判断依据不当**：仅凭记账日期而非原始单据判断实际期间。
3. **跨期错报未调整**：识别的跨期收支未评估影响、未调整。

### 低风险

1. **测试样本量不足**：截止测试覆盖笔数偏少。
2. **记录不规范**：核对过程、判断依据记录不充分。
3. **交叉索引不完整**：本底稿未与现金明细、盘点、收支检查建立索引引用。
