# E1-15 利息收入月度分析复核提示词

## 概述

本提示词针对利息收入月度分析表（E1-15）的复核，聚焦存款利息收入的完整性、月度分布合理性、与存款规模的匹配性、以及理论利息与账面利息的差异分析。利息收入分析是验证银行存款真实性与完整性的重要间接程序，存款规模与利息收入的不匹配是识别虚假存款、资金被占用的关键信号。

**法规依据：**
- 《中国注册会计师审计准则第1313号——分析程序》
- 《企业会计准则第22号——金融工具确认和计量》

---

## tips

1. **利息收入完整性是核心目标**：月度分析验证利息收入是否完整入账，遗漏利息收入既低估收益也可能提示存款未被企业实际控制。
2. **月度分布须合理**：利息收入通常按季结息（活期）或按期兑付（定期），月度分布应符合结息规律，异常月份缺失或畸高须查明。
3. **理论利息与账面利息对比**：以月度平均存款余额乘以存款利率估算理论利息，与账面利息收入对比，差异重大须解释。
4. **存款规模与利息严重不匹配是重大信号**：大额存款仅产生微薄利息，强烈提示存款被质押冻结、实际不存在或被关联方占用。
5. **区分不同存款类型利率**：活期、定期、通知存款利率不同，理论利息测算须按存款结构分别估算。
6. **利息收入须与损益、现金流勾稽**：账面利息收入须与利润表利息收入（财务费用抵减）、现金流量表收到利息勾稽。

## checklist

### 一、完整性与月度分布

- [ ] 各月利息收入是否完整列示
- [ ] 月度分布是否符合结息规律（活期按季/定期按期）
- [ ] 是否存在应有利息的月份缺失
- [ ] 是否存在个别月份利息畸高畸低
- [ ] 全年利息收入合计是否与账面利息收入一致

### 二、匹配性与理论测算

- [ ] 是否以月度平均存款余额估算理论利息
- [ ] 理论利息与账面利息差异是否分析
- [ ] 差异重大是否查明原因
- [ ] 存款规模与利息收入是否匹配
- [ ] 是否按存款类型（活期/定期）分别测算利率

### 三、异常信号识别

- [ ] 大额存款是否产生合理利息收入
- [ ] 利息收入畸低是否核查存款真实性与受限性
- [ ] 是否存在存款高但利息极少的账户（联动账户核查）
- [ ] 异常账户是否联动函证、账户清单核查

### 四、勾稽核对

- [ ] 账面利息收入是否与利润表勾稽
- [ ] 利息收入是否与现金流量表收到利息勾稽
- [ ] 应计未收利息是否与应计利息测算（E1-20）勾稽

## risk_areas

### 高风险

1. **存款规模与利息严重不匹配**：巨额存款仅产生微薄利息，强烈提示存款被质押冻结、虚假或被关联方占用，属重大舞弊信号。
2. **利息收入不完整**：应有利息未入账，可能表明存款未由企业实际控制或利息被截留。
3. **异常账户未联动核查**：利息异常账户未与函证、账户清单联动核查真实性。

### 中风险

1. **理论利息差异未解释**：理论利息与账面利息差异重大但未查明原因。
2. **月度分布异常**：利息月度分布不符合结息规律未查明。
3. **利率适用错误**：理论测算未区分存款类型利率，测算不准确。

### 低风险

1. **勾稽不完整**：利息收入未与损益、现金流充分勾稽。
2. **测算依据不充分**：月度平均余额估算依据不足。
3. **交叉索引不完整**：利息分析未与银行存款明细、应计利息、审定表建立索引引用。
