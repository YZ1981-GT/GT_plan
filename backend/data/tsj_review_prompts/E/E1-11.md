# E1-11 银行询证函/承诺书复核提示词

## 概述

本提示词针对银行询证与承诺书底稿（E1-11）的复核，聚焦银行询证函的完整发出与控制、回函核对、未回函替代程序、以及函证对存款存在性与受限性、担保、承诺事项的验证。银行函证是验证银行存款存在性最有力的外部证据，函证过程须由审计师全程控制，回函须由银行直接寄回审计师。

**法规依据：**
- 《中国注册会计师审计准则第1312号——函证》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **函证过程须由审计师全程控制**：询证函的发出、回收全程由审计师控制，回函须由银行直接寄回审计师，不得经被审计单位转交，防止函证被篡改。
2. **每个银行账户原则上全部函证**：银行存款账户（含零余额、定期、外币、专户）原则上全部发函，货币资金重要性高，通常不采用抽样。
3. **函证内容须覆盖余额及其他事项**：除存款余额外，函证应涵盖存款受限情况、质押/冻结、担保、承诺、未使用授信额度等，全面验证。
4. **回函差异须逐笔调查解释**：回函确认金额与账面不一致的，须通过余额调节表（E1-6）未达账项解释或查明原因作调整。
5. **未回函须实施替代程序**：未收到回函的账户须实施替代程序（核对银行对账单、期后流水、期后收付），并评估替代证据充分性。
6. **警惕回函真实性风险**：核实回函印章、寄回地址、银行经办人信息，防范被审计单位伪造回函虚增存款。

## checklist

### 一、函证发出与控制

- [ ] 是否对全部银行账户发出询证函（含零余额/定期/外币/专户）
- [ ] 询证函发出、回收是否全程由审计师控制
- [ ] 回函是否由银行直接寄回审计师（未经被审计单位转交）
- [ ] 询证函寄出记录、回函信封是否留档
- [ ] 函证清单是否与账户核对表（E1-10）账户一致

### 二、函证内容完整性

- [ ] 函证是否涵盖存款余额
- [ ] 函证是否涵盖存款受限（质押/冻结/保证金）情况
- [ ] 函证是否涵盖对外担保、承诺事项
- [ ] 函证是否涵盖未使用授信额度、贷款等其他银行业务
- [ ] 存单、票据等其他货币资金相关事项是否函证

### 三、回函核对与差异处理

- [ ] 回函确认余额是否与账面逐户核对一致
- [ ] 回函差异是否通过余额调节表未达账项解释
- [ ] 差异中应调整部分是否已编制调整分录（E1-5）
- [ ] 回函披露的受限、担保、质押是否在底稿反映并联动披露
- [ ] 回函印章、经办人、寄回地址真实性是否核实

### 四、未回函替代程序

- [ ] 未回函账户是否实施替代程序
- [ ] 替代程序是否核对银行对账单、期后流水、期后收付
- [ ] 替代程序证据是否充分支持余额存在性
- [ ] 未回函比例是否评估对审计结论的影响
- [ ] 是否重新发函或电话跟进未回函账户

## risk_areas

### 高风险

1. **回函被篡改或伪造**：回函经被审计单位转交或印章、信息存疑，可能被伪造虚增存款，函证证据失效。
2. **函证未覆盖受限与担保**：函证仅确认余额未涵盖质押、冻结、担保，导致受限资金和或有负债未被发现。
3. **应函证而未函证**：部分账户（如账外账户、定期存款）未发函，无法验证其存在性与真实性。

### 中风险

1. **回函差异未合理解释**：回函与账面差异未通过未达账项解释或未查明原因。
2. **替代程序不充分**：未回函账户替代程序仅凭企业提供对账单，独立性和证据力不足。
3. **函证过程失控**：函证发出回收未由审计师控制，存在被干预风险。

### 低风险

1. **函证清单不完整**：函证发出记录、回函登记不完整，影响可追溯性。
2. **回函归档不规范**：回函信封、寄出凭证未妥善留档。
3. **交叉索引不完整**：函证底稿未与账户清单、余额调节表、审定表建立索引引用。
