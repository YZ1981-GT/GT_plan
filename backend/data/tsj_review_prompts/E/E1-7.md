# E1-7 库存现金（人民币）盘点表复核提示词

## 概述

本提示词针对库存现金人民币盘点表（E1-7）的复核，聚焦盘点程序的存在性验证能力、盘点时点与倒轧、盘点差异处理、以及审计师现场监盘的独立性与充分性。现金盘点是验证库存现金存在性最直接的审计程序，盘点须由审计师现场监督、出纳在场、当场清点并倒轧至资产负债表日。

**法规依据：**
- 《中国注册会计师审计准则第1311号——对存货、诉讼和索赔、分部信息的具体考虑》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **盘点须审计师现场监督、出纳在场**：现金盘点应由审计师亲临现场监督，出纳（现金保管人）必须在场，盘点结果由出纳签字确认，防止事后补账。
2. **盘点时点须能倒轧至资产负债表日**：盘点通常在资产负债表日后进行，须记录盘点日实存金额，加减盘点日至资产负债表日之间的现金收支，倒轧出资产负债表日应有余额。
3. **盘点面额构成须记录**：盘点表应记录各面额纸币、硬币的张数与金额，合计等于实存现金，便于复核盘点真实性。
4. **白条、借条不得计入库存现金**：盘点中发现的白条抵库、未报销单据不属于现金，须单独列示并作调整。
5. **盘点差异须查明原因并处理**：实存与账面（倒轧后）如有差异（长款/短款），须查明原因、报告管理层并作相应处理。
6. **警惕盘点走过场**：仅凭出纳自报金额而未实际清点，或盘点日与报表日间隔过长无法可靠倒轧，均削弱盘点证据力。

## checklist

### 一、盘点程序合规性

- [ ] 盘点是否由审计师现场监督执行
- [ ] 出纳（现金保管人）是否全程在场
- [ ] 盘点结果是否经出纳签字确认
- [ ] 盘点是否当场实际清点而非凭自报
- [ ] 盘点表是否记录盘点日期、时间、地点、参与人

### 二、面额构成与实存

- [ ] 盘点表是否记录各面额纸币、硬币张数与金额
- [ ] 各面额金额合计是否等于实存现金金额
- [ ] 盘点中的白条、借条是否单独列示未计入现金
- [ ] 未报销单据充抵现金部分是否已剔除

### 三、倒轧与账实核对

- [ ] 盘点日实存金额是否加减盘点日至资产负债表日收支倒轧至报表日
- [ ] 倒轧后应有余额是否与账面（E1-2现金明细）核对
- [ ] 盘点日至报表日的现金收支是否有原始凭证支持
- [ ] 是否存在账实差异（长款/短款）

### 四、差异处理

- [ ] 账实差异是否查明原因
- [ ] 长款/短款是否报告管理层
- [ ] 差异是否作相应会计处理或调整
- [ ] 重大短款是否评估舞弊风险并追加程序

## risk_areas

### 高风险

1. **盘点走过场无法验证存在性**：仅凭出纳自报未实际清点，或盘点日与报表日间隔过长无法可靠倒轧，盘点丧失存在性验证能力。
2. **白条抵库虚增现金**：盘点发现白条、借条充抵现金但仍计入库存现金，掩盖现金已被挪用的事实。
3. **重大短款隐藏舞弊**：实存显著低于账面（倒轧后）但未查明原因、未追加程序，可能掩盖现金贪污或挪用。

### 中风险

1. **倒轧证据不足**：盘点日至报表日的收支缺乏原始凭证支持，倒轧金额不可靠。
2. **出纳未在场或未签字**：盘点程序缺陷，事后可能被质疑或补账。
3. **差异未处理**：账实差异查明后未作会计处理或调整。

### 低风险

1. **面额构成未记录**：盘点表未记录面额明细，削弱盘点真实性佐证。
2. **盘点表格式不规范**：盘点日期、地点、参与人等要素记录不全。
3. **交叉索引不完整**：盘点表未与现金明细、审定表建立索引引用。
