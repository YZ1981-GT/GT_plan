# E1-28 现金收支真实性完整性准确性检查复核提示词

## 概述

本提示词针对现金收支真实性、完整性、准确性检查底稿（E1-28，IPO/舞弊应对专项）的复核，聚焦现金收支凭证的真实性验证、收支完整入账、金额准确性、以及检查比例充分性。本底稿针对IPO及舞弊风险对现金收支执行加严凭证核查，验证现金收支不存在虚构、遗漏或错误。

**法规依据：**
- 《中国注册会计师审计准则第1141号——财务报表审计中与舞弊相关的责任》
- 《中国注册会计师审计准则第1314号——审计抽样》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **真实性核查凭证与业务实质**：核对现金收支的记账凭证、原始单据（发票/收据/合同/审批），验证交易真实发生，警惕虚构现金交易。
2. **完整性排查未入账收支**：现金收入是否完整入账（防坐支、账外收入），现金支出是否遗漏，是否存在账外现金循环。
3. **准确性核对金额一致性**：记账金额与原始单据金额、实际收付金额是否一致，识别金额篡改或错误。
4. **检查比例须充分**：现金收支检查金额占本期现金发生额比例应达到加严核查要求，比例偏低须扩大样本或说明。
5. **须先确认程序适用性**：确认企业是否属IPO/高舞弊风险适用情形，适用则核查执行充分性。
6. **异常须扩大样本核查**：发现虚构、遗漏、篡改迹象须扩大样本并追加程序。

## checklist

### 一、程序适用性与样本

- [ ] 本程序适用情形（IPO/高舞弊风险）是否已确认
- [ ] 样本选取是否覆盖大额及异常现金收支
- [ ] 高风险现金收支（对方个人/无合同/整数金额）是否纳入
- [ ] 样本量是否满足加严核查要求

### 二、真实性核查

- [ ] 现金收支记账凭证与原始单据是否齐全一致
- [ ] 现金收支审批手续是否完整
- [ ] 是否核查交易业务实质验证真实性
- [ ] 是否识别虚构现金交易迹象

### 三、完整性核查

- [ ] 现金收入是否完整入账（防坐支/账外收入）
- [ ] 现金支出是否存在遗漏
- [ ] 是否存在账外现金循环迹象
- [ ] 现金日记账与总账是否勾稽完整

### 四、准确性与检查比例

- [ ] 记账金额与原始单据、实际收付金额是否一致
- [ ] 是否识别金额篡改或错误
- [ ] 检查比例是否达到加严核查水平
- [ ] 比例偏低是否扩大样本或说明原因
- [ ] 发现异常是否扩大测试并提请关注

## risk_areas

### 高风险

1. **虚构现金交易**：伪造现金收支凭证虚构交易，掩盖虚增收入或套取资金，属重大舞弊。
2. **现金收入未入账**：现金收入坐支或账外循环，导致收入不完整、资金账外运行。
3. **金额篡改**：记账金额与实际收付不一致，人为篡改金额套取资金或调节业绩。

### 中风险

1. **检查比例不足**：现金收支检查比例低于加严核查要求，证据不充分。
2. **凭证核对不完整**：仅核对金额未验证业务实质。
3. **异常未扩大核查**：发现异常迹象但未扩大样本追加程序。

### 低风险

1. **样本记录不完整**：抽样参数、选取依据记录不充分。
2. **检查结果格式不规范**：核对结果记录格式不统一。
3. **交叉索引不完整**：本底稿未与现金明细、盘点、截止测试建立索引引用。
