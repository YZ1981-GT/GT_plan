# E1-29 银行账户变动分析复核提示词

## 概述

本提示词针对银行账户变动分析底稿（E1-29，IPO/舞弊应对专项）的复核，聚焦报告期内银行账户的新增、销户、异常变动分析、以及账户变动与信用报告、账面记录的一致性。本底稿针对IPO及舞弊风险对银行账户变动执行加严分析，识别异常账户、账外账户与账户变动背后的舞弊风险。

**法规依据：**
- 《中国注册会计师审计准则第1141号——财务报表审计中与舞弊相关的责任》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **梳理报告期账户变动全貌**：分析报告期内（含IPO申报期各年度）银行账户的开立、销户、变动，形成账户变动全景。
2. **账户清单三方一致性核对**：账户变动须与账面记录（E1-10）、企业信用报告（E1-18/19）、函证回函三方核对一致。
3. **频繁开销户是异常信号**：短期内频繁开立、销户账户，或申报期临近前集中销户，可能用于隐匿资金往来痕迹。
4. **销户账户资金去向须核查**：销户前余额去向、销户账户历史大额交易须核查，防止销户掩盖体外循环。
5. **须先确认程序适用性**：确认企业是否属IPO/高舞弊风险适用情形，适用则核查执行充分性。
6. **异常账户须进一步核查**：发现账户异常或舞弊迹象须核查账户资金往来性质并追加程序。

## checklist

### 一、程序适用性与变动梳理

- [ ] 本程序适用情形（IPO/高舞弊风险）是否已确认
- [ ] 报告期内账户开立、销户、变动是否完整梳理
- [ ] IPO申报期各年度账户变动是否覆盖
- [ ] 账户变动是否形成全景分析

### 二、三方一致性核对

- [ ] 账户变动是否与账面记录（E1-10）核对
- [ ] 账户变动是否与信用报告（E1-18/19）核对
- [ ] 账户变动是否与函证回函核对
- [ ] 是否识别账外账户或遗漏账户

### 三、异常账户识别

- [ ] 是否存在短期频繁开销户
- [ ] 申报期临近前是否集中销户
- [ ] 销户账户余额去向是否核查
- [ ] 销户账户历史大额交易是否核查
- [ ] 是否存在开户主体异常（关联/个人）账户

### 四、异常处理

- [ ] 账户异常是否核查资金往来性质
- [ ] 发现舞弊迹象是否追加程序
- [ ] 是否提请项目组及合伙人关注
- [ ] 分析结论是否明确（一致/异常已解释/发现迹象）

## risk_areas

### 高风险

1. **账外账户隐匿资金往来**：报告期存在账面未记录账户，用于隐匿收入、体外循环，IPO审计中属重大舞弊风险。
2. **销户掩盖资金痕迹**：申报期前集中销户以掩盖历史体外循环或异常资金往来痕迹。
3. **异常账户利益输送**：开户主体异常（关联方/个人）的账户用于利益输送或资金占用。

### 中风险

1. **三方核对不到位**：账户变动未与信用报告、函证充分核对，无法发现账外账户。
2. **销户去向未核查**：销户账户余额去向、历史交易未核查。
3. **频繁开销户未查明**：识别频繁开销户但未查明原因。

### 低风险

1. **变动梳理不完整**：账户变动分析未覆盖完整报告期。
2. **记录不规范**：分析过程、异常判断记录不充分。
3. **交叉索引不完整**：本底稿未与账户清单、信用报告、函证建立索引引用。
