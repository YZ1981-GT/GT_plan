# F3-2 应付票据明细复核提示词

## 概述

本提示词针对 **F3-2 应付票据明细表**（科目 2201）。聚焦票面要素完整性、到期日与银行对账、关联方标记，以及与 F3-1 审定合计勾稽；明细是逾期、利息、关联方与附注的数据源。

加载优先级：sheet-level（本文件）→ subject-level（应付票据审计复核提示词）→ generic。

**法规依据：**
- 《企业会计准则第 22 号——金融工具确认和计量》
- 《企业会计准则第 37 号——金融工具列报》
- 《中国注册会计师审计准则第 1301 号——审计证据》
- 《中国注册会计师审计准则第 1312 号——函证》

---

## tips

1. **票面要素**：出票人、收款人、票面金额、出票日、到期日、承兑行/承兑人须齐全且与实物/电子票据系统一致。
2. **到期结构**：按到期日分层，已到期未兑付须进入 F3-5，不得仍按正常未到期列示。
3. **银行对账**：银行承兑须与承兑行对账单/电子票据平台余额勾稽；差异须解释。
4. **关联方**：关联方为收款人或承兑人的须标记，并与 F3-6 清单一致。
5. **与审定勾稽**：明细合计 = F3-1 未审/审定对应口径；拆分银行承兑与商业承兑。
6. **函证衔接**：大额票据函证对象、金额与明细行一一对应。

---

## checklist

### 一、完整性与要素

- [ ] 明细覆盖全部未到期及已到期未兑付票据
- [ ] 票面金额、到期日、承兑类型字段无空缺重大行
- [ ] 无重复票号或同票拆分行未说明
- [ ] 负数/异常金额行已调查

### 二、对账与勾稽

- [ ] 银行承兑余额与银行/票据系统对账一致或差异已解释
- [ ] 明细合计与 F3-1 勾稽
- [ ] 关联方标记与 F3-6 不冲突
- [ ] 大额样本已索引至开票申请、合同或入库证据

### 三、结论

- [ ] 逾期候选已推送/核对 F3-5
- [ ] 审计说明覆盖遗漏开票与虚假票据风险
- [ ] 结论 A/B/C 与发现一致

## risk_areas

### 高风险

1. **账外开票未入明细** — 完整性认定失败。
2. **票面与账面金额不符** — 准确性/存在性错报。
3. **已到期未兑付仍按正常列示** — 掩盖流动性与违约风险。
4. **关联方票据未标记** — 披露与利益输送风险遗漏。

### 中风险

1. 与银行对账差异长期挂账未清。
2. 明细与审定差额无说明。
3. 票号/电子票据 ID 无法追溯。

### 低风险

1. 非关键字段格式不统一。
