# F4-4 应付分析复核提示词

## 概述

本提示词针对 **F4-4 应付账款分析**。聚焦周转天数、供应商集中度、同比变动，并与采购、预付、存货勾稽；异常须解释并评估是否扩大未入账或函证程序。

加载优先级：sheet-level（本文件）→ subject-level（应付账款审计复核提示词）→ generic。

**法规依据：**
- 《中国注册会计师审计准则第 1313 号——分析程序》
- 《中国注册会计师审计准则第 1301 号——审计证据》
- 《企业会计准则第 30 号——财务报表列报》

---

## tips

1. **周转与规模**：应付周转天数/余额与采购规模、付款政策匹配；异常缩短可能暗示隐瞒负债或突击付款。
2. **集中度**：前五大供应商占比异常升高或单一依赖须评估完整性与关联方风险。
3. **同比/月度**：重大变动须有业务原因；期末突击挂账或清空为红旗。
4. **跨科目勾稽**：与预付（F1）、存货采购入库、成本（F5）逻辑一致，避免“货到账未到”与“账到货未到”双漏。
5. **行业对比**：偏离行业惯例须说明（账期、承兑结算占比等）。
6. **程序联动**：分析异常应驱动 F4-7 未入账检查或扩大函证，而非仅文字描述。

## checklist

### 一、指标与变动

- [ ] 周转/余额指标计算口径正确
- [ ] 同比及重大供应商变动已分析
- [ ] 集中度指标已计算并评价
- [ ] 异常月度/期末波动已调查

### 二、跨科目与行业

- [ ] 与采购入库/存货变动逻辑勾稽
- [ ] 与预付变动不冲突或差异已解释
- [ ] 行业/历史比较已记录（如适用）
- [ ] 分析结论已链接至进一步程序

### 三、结论

- [ ] 红旗事项已升级程序或调整
- [ ] 审计说明与分析发现一致
- [ ] 结论 A/B/C 可支持

## risk_areas

### 高风险

1. **应付异常下降无解释** — 可能少计负债。
2. **期末突击挂账推高成本** — 操纵利润。
3. **分析停留在描述、未扩大程序** — 错报未被发现。

### 中风险

1. 集中度升高未评估关联方/依赖风险。
2. 与存货/预付勾稽断裂。
3. 指标口径与上年不一致。

### 低风险

1. 分析表述简略但数据勾稽完整。
