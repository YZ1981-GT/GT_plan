# F2A 存货审计程序表复核提示词

## 概述

本提示词针对 **F2A 存货审计程序表** 的 AI/人工复核，聚焦该底稿特有审计要点。加载优先级：sheet-level（本文件）→ subject-level → generic。

**法规依据：**
- 《企业会计准则第 1 号——存货》（存货相关）及其他适用准则
- 《中国注册会计师审计准则第 1301 号——审计证据》
- 《中国注册会计师审计准则第 1314 号——审计抽样》

---

## tips

1. **程序覆盖认定**：复核时逐项确认并留痕。
2. **与子表索引**：复核时逐项确认并留痕。
3. **风险应对**：复核时逐项确认并留痕。
4. **完成勾选**：复核时逐项确认并留痕。
5. **复核签字**：复核时逐项确认并留痕。

---

## checklist

### 一、核心勾稽与完整性

- [ ] 程序覆盖认定
- [ ] 与子表索引
- [ ] 风险应对
- [ ] 完成勾选
- [ ] 复核签字

### 二、证据与结论

- [ ] 审计说明是否概括程序、发现与拟调整事项
- [ ] 审计结论是否采用明确 A/B/C（或等价）口径
- [ ] 索引号与支持性底稿/附件是否可追溯
- [ ] 跨 sheet / 跨科目勾稽差异是否已解释或调整
- [ ] 重大异常是否已上报或扩大程序

---

## risk_areas

- high: 勾稽断裂、科目错用（如跌价 1471 vs 进销差价 1412）、截止跨期未处理、跌价计提明显不足
- medium: 覆盖率偏低、样本代表性不足、披露与审定不一致
- low: 格式/索引不完整但不影响认定结论
