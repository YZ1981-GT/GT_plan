# F2-29 截止测试（入库·账→单）复核提示词

## 概述

本提示词针对 **F2-29**：从记账凭证追查至入库/验收等原始凭证，测试**存在/发生**，识别提前入账与跨期。与 F2-30（单→账·完整性）成对。

**法规依据：**
- 《中国注册会计师审计准则第 1301 号——审计证据》
- 《企业会计准则第 1 号——存货》

---

## tips

1. **认定方向**：账→单侧重防多记/提前入账；勿与 F2-30 完整性方向混淆。
2. **细判规则**：单据日与记账日分落截止日两侧 → 跨期；账在期内、单在期后 → 提前入账。
3. **证据缺口**：有账无单、金额不符须标不正确并可强制覆盖（需理由）。
4. **分类编制**：原材料/产成品应分开或明确标记，避免混样。
5. **扩大程序**：发现错报时应扩大窗口或样本量（对称扩展）。
6. **引导弹窗**：逐笔核对弹窗实时勾稽应与表内细判一致。

---

## checklist

### 一、样本与窗口

- [ ] 截止日是否与资产负债表日一致或已说明差异
- [ ] 抽样窗口（截止日前后天数）是否充分
- [ ] 金额门槛是否合理覆盖重大项目
- [ ] 原材料/产成品分类是否完整
- [ ] 抽凭/自动提取结果是否已复核来源

### 二、细判与证据

- [ ] 提前入账样本是否均已识别并评估影响
- [ ] 有账无单是否已追查补证或调整
- [ ] 账金额与单据金额差异是否核实
- [ ] 「截止正确」覆盖是否有书面理由
- [ ] 跨期金额合计是否与重要性比较并考虑调整

### 三、结论

- [ ] 审计说明是否描述窗口、发现与拟调整
- [ ] 结论是否明确 A/B/C 口径
- [ ] 与监盘收发截止信息是否勾稽
- [ ] 需调整事项是否已转入 F2-14
- [ ] 索引与附件是否可追溯

---

## risk_areas

- high: 大额提前入账未调整；有账无单系统性存在；窗口过窄遗漏跨期
- medium: 分类未标；覆盖率低；强制覆盖无理由
- low: 弹窗未使用但表内细判完整
