# F3-6 关联方票据复核提示词

## 概述

本提示词针对 **F3-6 关联方应付票据**。聚焦关联方开票/收票清单完整性、融资性票据与终止确认、定价公允性及 CAS36 披露；须与 F3-2 关联方标记、F3-1 审定及附注勾稽。

加载优先级：sheet-level（本文件）→ subject-level（应付票据审计复核提示词）→ generic。

**法规依据：**
- 《企业会计准则第 36 号——关联方披露》
- 《企业会计准则第 22 号——金融工具确认和计量》
- 《企业会计准则第 37 号——金融工具列报》
- 《中国注册会计师审计准则第 1323 号——关联方》

---

## tips

1. **清单完整**：收款人、承兑人或担保人为关联方的票据须全覆盖，含隐性关联（同一实控人供应商）。
2. **终止确认**：向关联方背书/贴现是否满足终止确认，防止“假出表”虚减负债。
3. **融资性票据**：无真实采购背景的开票、循环对开，应按融资实质列报并评估披露。
4. **公允与商业实质**：票面期限、保证金、贴息分担是否异常偏离独立第三方。
5. **披露**：关联方票据余额、交易额须与附注及关联方往来汇总一致。
6. **异常模式**：期末集中开票、期后立即兑付或转应付账款，须扩大程序。

## checklist

### 一、识别与完整性

- [ ] 关联方范围与集团关联方清单一致
- [ ] F3-2 标记为关联方的票据均已纳入本表
- [ ] 隐性关联/担保安排已询问并记录
- [ ] 余额与发生额可追溯至明细行

### 二、实质与会计处理

- [ ] 融资性票据已识别并恰当列报
- [ ] 终止确认判断有合同与风险报酬分析支持
- [ ] 异常期限/保证金/贴息已调查
- [ ] 拟调整已推送 F3-3 或说明不调

### 三、披露

- [ ] CAS36 披露要素齐全
- [ ] 与上市/国企附注关联方段落一致
- [ ] 审计结论覆盖利益输送与隐瞒关联风险

## risk_areas

### 高风险

1. **融资性票据伪装采购** — 虚增采购/隐瞒融资。
2. **不当终止确认** — 虚减应付票据。
3. **未披露关联方票据** — 违反 CAS36，掩盖占用。

### 中风险

1. 与 F3-2 关联方标记不一致。
2. 定价/期限异常无商业理由说明。
3. 附注金额与本表不符。

### 低风险

1. 披露措辞不规范但金额完整。
