# F5-1 营业成本审定表复核提示词

## 概述

本提示词针对 **F5-1 营业成本审定表** 的 AI/人工复核。审定表是成本枢纽：未审数→AJE/RJE→审定数，并回写试算；须与收入配比、成本结构合理，重大调整闭环自 F5-4/F5-8。

加载优先级：sheet-level（本文件）→ subject-level（成本审计复核提示词）→ generic。

**法规依据：**
- 《企业会计准则第 1 号——存货》
- 《企业会计准则第 14 号——收入》（成本与收入配比）
- 《中国注册会计师审计准则第 1301 号——审计证据》
- 《中国注册会计师审计准则第 1313 号——分析程序》

---

## tips

1. **期初期末与发生额**：成本为损益类，关注本期发生额审定与试算一致，勿套用资产负债余额公式。
2. **试算一致**：主营业务成本/其他业务成本审定数须与试算对应科目一致。
3. **收入配比**：收入确认时点与结转成本时点匹配；有收入无成本或严重错配须解释。
4. **调整完整**：F5-4 / F5-8 调整须反映至审定表；未调整错报进 SUD。
5. **结构披露**：产品/业务线成本结构与 F5-2、附注一致。
6. **重大变动**：毛利率或成本率异常变动须追溯 F5-5 / F5-7。

## checklist

### 一、试算与发生额

- [ ] 本期成本发生额审定与试算一致
- [ ] 未审数、调整数口径与试算一致
- [ ] 主营与其他业务成本分列正确
- [ ] 上年比较数（如列示）勾稽正确

### 二、调整与跨表

- [ ] F5-4/F5-8 调整已完整入审定表
- [ ] 与 F5-2 月度合计、F5-3 其他业务成本勾稽
- [ ] 倒轧/分析结论与 F5-5/F5-7 不冲突
- [ ] 建议未调整事项已记入未调整错报汇总

### 三、配比与披露

- [ ] 与收入配比关系已评价
- [ ] 成本结构与附注（上市/国企）口径一致
- [ ] 审计说明与结论 A/B/C 可追溯至证据
- [ ] 重大异常已上报或扩大程序

## risk_areas

### 高风险

1. **成本与收入严重错配** — 毛利操纵。
2. **调整遗漏** — 审定成本失真。
3. **试算与审定不一致** — 汇总或回写失败。
4. **虚增/虚减成本** — 配合收入或存货舞弊。

### 中风险

1. 月度/结构与审定差异未解释。
2. 重大毛利率变动无分析。
3. 索引号断裂。

### 低风险

1. 格式/索引不完整但不影响认定结论。
