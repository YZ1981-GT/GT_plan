# F2-47 存货跌价准备 NRV 测试复核提示词

## 概述

本提示词针对 **F2-47 跌价准备测试**。评价可变现净值测算与跌价计提充分性，并与审定表科目 **1471**、F2-48 长库龄、F2-49 转回勾稽。

---

## tips

1. **NRV 公式**：可变现净值 = 估计售价 − 至完工估计成本 − 估计销售费用 − 相关税费。
2. **售价来源**：合同价/市场价/最近售价须可验证，禁止无依据拍脑袋。
3. **库龄**：库龄 >1 年或明显呆滞应逐项或按组合充分测试（衔接 F2-48）。
4. **科目**：计提/审定跌价对应 **1471**，与 F2-1 跌价区勾稽。
5. **转回边界**：转回条件见 CAS1 第 21 条，细节在 F2-49 复核。
6. **规则引擎**：系统孰低分析为辅助，最终金额须审计师确认。

---

## checklist

### 一、测算

- [ ] NRV 组成是否完整（售价、费用、税费、至完工成本）
- [ ] 售价取数来源是否可靠并留痕
- [ ] 样本是否覆盖高库龄、跌价迹象、重大余额
- [ ] 应计提与账面已计提差异是否计算正确
- [ ] 按组合计提的标准和比例是否合理披露

### 二、勾稽

- [ ] 建议补提/转回是否与 F2-1 / 1471 勾稽
- [ ] 是否与 F2-48 长库龄明细交叉核对
- [ ] 转回事项是否转到 F2-49 专项核对
- [ ] 合并范围内未实现利润对跌价的影响是否考虑
- [ ] 附注跌价政策与测试方法是否一致

### 三、结论

- [ ] 审计说明是否描述政策、样本与差异
- [ ] 结论 A/B/C 是否明确
- [ ] 调整是否进入 F2-14
- [ ] 索引与计算底稿是否可追溯
- [ ] 管理层估计偏见是否已评价

---

## risk_areas

- high: NRV 售价无依据；高库龄未测；1471 与审定脱节；明显计提不足
- medium: 样本代表性不足；组合计提未披露
- low: AI/规则引擎建议未人工确认但差异不重大
