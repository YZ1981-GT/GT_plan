# F3-1 应付票据审定表复核提示词

## 概述

本提示词针对 **F3-1 应付票据审定表**（科目 2201）的 AI/人工复核。审定表是应付票据枢纽：未审数→AJE/RJE→审定数，并回写试算；银行承兑/商业承兑分类错误、贴现未终止确认或逾期未重分类可直接导致负债错报。

加载优先级：sheet-level（本文件）→ subject-level（应付票据审计复核提示词）→ generic。

**法规依据：**
- 《企业会计准则第 22 号——金融工具确认和计量》
- 《企业会计准则第 37 号——金融工具列报》
- 《企业会计准则第 30 号——财务报表列报》
- 《中国注册会计师审计准则第 1301 号——审计证据》

---

## tips

1. **期初期末勾稽**：期初审定数须等于上年期末审定数；无源差异不得接受。
2. **试算一致**：2201 审定数须与试算平衡表一致，含调整列口径。
3. **票种分类**：银行承兑与商业承兑、有息/无息、已贴现未到期须分列，不得混入应付账款。
4. **调整完整**：F3-3 全部 AJE/RJE 须反映至审定表；未调整错报进 SUD。
5. **贴现与逾期**：已贴现未终止确认、逾期票据须与 F3-4 / F3-5 结论一致并恰当列报。
6. **重大变动**：变动超 20% 或重要性水平时，须追溯至明细与开票/兑付说明。

## checklist

### 一、期初期末与试算

- [ ] 期初审定 = 上年期末审定（承前启后）
- [ ] 期末审定 = 期初审定 + 贷方 − 借方 ± 本期调整（贷方科目口径）
- [ ] 审定合计与试算 2201 一致
- [ ] 未审数、调整数口径与试算一致

### 二、调整与跨表

- [ ] F3-3 调整已完整入审定表
- [ ] 明细合计与 F3-2 勾稽（允许说明差异）
- [ ] 利息、逾期、关联方余额与 F3-4 / F3-5 / F3-6 不冲突
- [ ] 建议未调整事项已记入未调整错报汇总

### 三、分类与披露

- [ ] 银行承兑/商业承兑及到期结构列报恰当
- [ ] 已贴现未到期票据确认/终止确认判断正确
- [ ] 审定分类与附注（上市/国企）口径一致
- [ ] 审计说明与结论 A/B/C 可追溯至证据

## risk_areas

### 高风险

1. **期初期末不勾稽** — 审定失去基准。
2. **调整遗漏** — 审定数失真，掩盖少计/多计负债。
3. **试算与审定不一致** — 汇总或回写失败。
4. **贴现票据虚减负债** — 未满足终止确认仍转出 2201。
5. **虚构或隐瞒票据** — 无票面支持的余额或账外开票。

### 中风险

1. 明细合计与审定差异未解释。
2. 重大变动无开票/兑付分析说明。
3. 索引号断裂，无法追溯 F3-2/F3-3。

### 低风险

1. 格式/索引不完整但不影响认定结论。
