# F3-7 凭证检查复核提示词

## 概述

本提示词针对 **F3-7 应付票据凭证检查**。聚焦样本覆盖、票证相符（开票申请-合同/入库-票据-账务）、审批合规与异常跟进；检查结论应支撑存在性与权利义务认定。

加载优先级：sheet-level（本文件）→ subject-level（应付票据审计复核提示词）→ generic。

**法规依据：**
- 《中国注册会计师审计准则第 1314 号——审计抽样》
- 《中国注册会计师审计准则第 1301 号——审计证据》
- 《企业会计准则第 22 号——金融工具确认和计量》

---

## tips

1. **样本覆盖**：须覆盖大额、关联方、期末开票、逾期、已贴现票据，不只随机小额。
2. **票证相符**：开票申请、采购合同或入库单、票据影像/电子票面、记账凭证相互勾稽。
3. **审批**：超权限开票、拆单规避审批、无真实交易背景开票为红旗。
4. **兑付与贴现路径**：关注兑付资金来源、贴现银行回单与账面分录方向。
5. **异常率**：不符比例过高须扩大样本或改程序，并索引至 F3-3。
6. **商业承兑**：额外关注承兑人信用与担保安排证据。

## checklist

### 一、样本设计

- [ ] 样本选取标准与规模已记录
- [ ] 大额、关联方、期末突增、逾期已纳入或说明排除理由
- [ ] 银行承兑与商业承兑均有覆盖
- [ ] 已贴现样本单独标识

### 二、证据与相符

- [ ] 票面要素与账面记录一致
- [ ] 合同/入库/服务确认支持开票商业背景
- [ ] 审批链条完整
- [ ] 不符事项已跟进至调整或结论

### 三、结论

- [ ] 检查比例/覆盖率计算正确
- [ ] 异常已索引 F3-3/F3-5/F3-6（如适用）
- [ ] 审计结论与发现一致（A/B/C）

## risk_areas

### 高风险

1. **无真实采购背景开票** — 虚构负债或融资出表。
2. **样本刻意避开高风险票据** — 程序失效。
3. **票证严重不符仍通过检查** — 存在性认定失败。

### 中风险

1. 检查表勾选齐全但附件缺失。
2. 异常未索引至调整表。
3. 商业承兑缺少承兑人信用评价记录。

### 低风险

1. 样本工作底稿格式不统一。
