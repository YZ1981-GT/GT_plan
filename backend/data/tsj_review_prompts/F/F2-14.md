# F2-14 存货调整分录复核提示词

## 概述

本提示词针对 **F2-14 调整分录**（非 F2-3 明细）。本表汇总存货相关 AJE/RJE，并回写 F2-1 审定表账项调整列；可选推送至集中调整台账。

**法规依据：**
- 《企业会计准则第 1 号——存货》
- 《中国注册会计师审计准则第 1301 号——审计证据》

---

## tips

1. **编码锚点**：调整分录底稿是 **F2-14**；F2-3 是原材料明细，不可混淆。
2. **科目锚点**：跌价准备 **1471**；进销差价 **1412**；库存商品 **1406**。
3. **借贷成组**：同一事项说明下的多行应借贷平衡，方可推送集中表。
4. **回写闭环**：保存后 F2-1 对应类别调整列应变化；跌价 AJE 进跌价区。
5. **证据链**：每笔调整须有索引至盘点差异/截止/跌价测试等支持底稿。
6. **集中台账**：推送成功后行应带 sourceGroupId，避免重复推送。

---

## checklist

### 一、完整性与平衡

- [ ] 所有已确认存货相关错报是否已编制调整分录
- [ ] 借方合计是否等于贷方合计（整表平衡）
- [ ] 同一摘要/事项组内是否借贷成组平衡
- [ ] AJE 与 RJE 分类是否正确
- [ ] 零金额空行是否已清理或不影响平衡校验

### 二、科目与回写

- [ ] 跌价准备分录是否使用 1471（禁止误用 1412）
- [ ] 进销差价分录是否使用 1412
- [ ] 调整是否已回写 F2-1 原值/跌价账项调整列
- [ ] 对方科目（成本/减值损失/往来等）是否合理
- [ ] 附注项目字段是否便于附注勾稽

### 三、证据与治理

- [ ] 每笔是否有索引号指向支持底稿
- [ ] 调整说明是否足以使复核人理解来源
- [ ] 未调整错报是否另有记录（SUD）
- [ ] 如已推送集中调整表，是否与底稿金额一致且无重复
- [ ] 合伙人/经理复核痕迹是否齐全

---

## risk_areas

- high: 科目错用导致审定跌价/原值串行；不平衡分录被推送；调整未回写 F2-1
- medium: 索引缺失；重复推送；RJE/AJE 混用
- low: 摘要措辞不规范
