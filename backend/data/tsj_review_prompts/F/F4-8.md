# F4-8 凭证检查复核提示词

## 概述

本提示词针对 **F4-8 应付账款凭证检查**。聚焦样本覆盖、三单匹配（合同/订单-入库/验收-发票）、审批合规与异常跟进；检查结论应支撑存在性、准确性与权利义务认定。

加载优先级：sheet-level（本文件）→ subject-level（应付账款审计复核提示词）→ generic。

**法规依据：**
- 《中国注册会计师审计准则第 1314 号——审计抽样》
- 《中国注册会计师审计准则第 1301 号——审计证据》
- 《企业会计准则第 30 号——财务报表列报》

---

## tips

1. **样本覆盖**：须覆盖大额、关联方、期末挂账、新供应商、长期挂账户，不只随机小额。
2. **三单匹配**：采购订单/合同、入库或服务确认、发票相互勾稽，金额与期间一致。
3. **审批**：超权限采购、拆单规避审批、无合同挂账为红旗。
4. **贷方与付款**：关注大额贷方冲销、期后付款路径与退货折让处理。
5. **异常率**：不符比例过高须扩大样本或改程序，并索引至 F4-3。
6. **服务类采购**：无实物入库时须有工作量确认、进度单等替代证据。

## checklist

### 一、样本设计

- [ ] 样本选取标准与规模已记录
- [ ] 大额、关联方、期末突增、新供应商已纳入或说明排除理由
- [ ] 货物采购与服务采购均有覆盖
- [ ] 长期挂账户有抽查

### 二、证据与相符

- [ ] 合同/订单、入库或服务确认、发票三单匹配
- [ ] 审批链条完整
- [ ] 记账科目与业务性质相符（成本/存货/费用）
- [ ] 不符事项已跟进至调整或结论

### 三、结论

- [ ] 检查比例/覆盖率计算正确
- [ ] 异常已索引 F4-3/F4-5/F4-6（如适用）
- [ ] 审计结论与发现一致（A/B/C）

## risk_areas

### 高风险

1. **无合同/无入库大额挂账仍通过检查** — 存在性失败。
2. **样本刻意避开高风险供应商** — 程序失效。
3. **三单严重不符未升级** — 准确性/舞弊风险。

### 中风险

1. 检查表勾选齐全但附件缺失。
2. 异常未索引至调整表。
3. 服务类缺少工作量证据。

### 低风险

1. 样本工作底稿格式不统一。
