# F4-1 应付账款审定表复核提示词

## 概述

本提示词针对 **F4-1 应付账款审定表**（科目 2202）的 AI/人工复核。审定表是应付科目枢纽：未审数→AJE/RJE→审定数，并回写试算；完整性不足、关联方未单独列示或与预付不当抵销可直接导致负债低估。

加载优先级：sheet-level（本文件）→ subject-level（应付账款审计复核提示词）→ generic。

**法规依据：**
- 《企业会计准则第 30 号——财务报表列报》
- 《企业会计准则第 36 号——关联方披露》
- 《中国注册会计师审计准则第 1301 号——审计证据》
- 《中国注册会计师审计准则第 1312 号——函证》

---

## tips

1. **期初期末勾稽**：期初审定数须等于上年期末审定数；无源差异不得接受。
2. **试算一致**：2202 审定数须与试算平衡表一致，含调整列口径。
3. **完整性优先**：应付审计重完整性；审定结论须呼应 F4-7 未入账检查。
4. **调整完整**：F4-3 全部 AJE/RJE 须反映至审定表；未调整错报进 SUD。
5. **关联方列示**：关联方应付须单独列示，并与 F4-6 / 附注勾稽；不得与应收/预付随意抵销。
6. **重大变动**：变动超 20% 或重要性水平时，须追溯至明细与采购/付款说明。

## checklist

### 一、期初期末与试算

- [ ] 期初审定 = 上年期末审定（承前启后）
- [ ] 期末审定 = 期初审定 + 贷方 − 借方 ± 本期调整（贷方科目口径）
- [ ] 审定合计与试算 2202 一致
- [ ] 未审数、调整数口径与试算一致

### 二、调整与跨表

- [ ] F4-3 调整已完整入审定表
- [ ] 明细合计与 F4-2 勾稽（允许说明差异）
- [ ] 长期挂账、关联方、未入账结论与 F4-5 / F4-6 / F4-7 不冲突
- [ ] 建议未调整事项已记入未调整错报汇总

### 三、分类与披露

- [ ] 关联方单独列示且未与预付/应收不当抵销
- [ ] 供应商融资相关余额分类与 F4-9 一致
- [ ] 审定分类与附注（上市/国企）口径一致
- [ ] 审计说明与结论 A/B/C 可追溯至证据

## risk_areas

### 高风险

1. **期初期末不勾稽** — 审定失去基准。
2. **少计负债** — 未入账采购/暂估遗漏未反映至审定。
3. **试算与审定不一致** — 汇总或回写失败。
4. **关联方隐瞒或不当抵销** — 美化资产负债。
5. **虚构应付推高成本** — 无采购支持的大额贷方余额。

### 中风险

1. 明细合计与审定差异未解释。
2. 重大变动无分析说明。
3. 索引号断裂，无法追溯 F4-2/F4-3。

### 低风险

1. 格式/索引不完整但不影响认定结论。
