# F2-35 委托加工物资核查表复核提示词

## 概述

本提示词针对 **F2-35**：表一余额倒轧、表二供应商加工规模、表三发出/收回材料流。核心恒等：**收回材料成本 ≈ 发出材料成本 + 加工费**（CAS1 存货成本）。并与 **F2-7** 委托加工明细期末勾稽。

---

## tips

1. **计价恒等**：表三逐行校验收回 vs 发出+加工费；未全额收回与计价差异须分色区分。
2. **三表加工费**：表一 processingFee、表二 feeAmount、表三 fee 合计应交叉勾稽。
3. **F2-7 对照**：期末余额应与 F2-7 明细加工物资成本勾稽（可手填对照数）。
4. **未收回风险**：重大未收回应考虑函证/现场查看。
5. **合同与结算**：加工合同、发料、加工费结算凭证链完整。
6. **结论口径**：A/B/C 须覆盖未收回与计价差异处理。

---

## checklist

### 一、表内勾稽

- [ ] 表一期初+增加−减少=期末是否成立
- [ ] 表三是否逐行执行「收回≈发出+加工费」校验
- [ ] 未全额收回行是否填写原因及是否需函证
- [ ] 计价差异行是否已解释或拟调整
- [ ] 三表加工费合计差异是否已消除或说明

### 二、跨表与证据

- [ ] F2-35 期末是否与 F2-7 期末对照（差异可接受或已调整）
- [ ] 主要供应商是否抽查合同/结算单/凭证
- [ ] 必要时是否向加工方函证加工费与结存
- [ ] 异常供应商（关联方/新设/地址异常）是否扩大程序
- [ ] 与采购入库、生产成本归集是否冲突

### 三、结论

- [ ] 审计说明是否覆盖程序、未收回与计价差异
- [ ] 结论是否明确
- [ ] 需调整是否转入 F2-14
- [ ] 索引完整
- [ ] AI 生成内容是否已经人工确认

---

## risk_areas

- high: 系统性收回不足；加工费三表严重不符；与 F2-7 断裂未解释
- medium: 函证范围不足；合同链缺失
- low: 对照金额手填未自动带入但不影响结论
