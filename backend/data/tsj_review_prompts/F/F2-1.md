# F2-1 存货审定表复核提示词

## 概述

本提示词针对 **F2-1 存货审定表** 的复核。审定表是存货科目枢纽：未审 → 账项调整 → 审定，并分原值 / 跌价准备 / 净值三区。任何类别勾稽断裂或科目错用均可导致报表重大错报。

**法规依据：**
- 《企业会计准则第 1 号——存货》
- 《中国注册会计师审计准则第 1301 号——审计证据》
- 《中国注册会计师审计准则第 1502 号——在审计报告中发表非无保留意见》

---

## tips

1. **科目铁律**：商品进销差价 = **1412**；存货跌价准备 = **1471**。不得混用，不得把跌价误记为 1412。
2. **明细滚上去**：原值区各类别期末未审应与 F2-3~F2-13 明细合计勾稽（容差内）。
3. **调整滚上来**：F2-14 AJE 应按科目回写原值账项调整；1471 AJE 回写跌价准备区。
4. **净值只读**：净值 = 原值审定 − 跌价准备审定，禁止手工改写破坏恒等。
5. **试算闭环**：审定数须与试算平衡表对应存货科目审定数一致。
6. **列报完整**：在途物资、发出商品、开发产品等不得被错误并入库存商品。

---

## checklist

### 一、期初期末与试算

- [ ] 期初审定数是否与上年期末审定数承前启后一致
- [ ] 原值区期末未审合计是否与 F2-3~13 明细期末合计勾稽
- [ ] 审定表存货相关科目审定数是否与试算平衡表一致
- [ ] 未审数是否与明细账/总账一致
- [ ] 重大同比变动（如 >20% 或超重要性）是否已追查并说明

### 二、调整与科目

- [ ] F2-14 账项调整是否完整反映在对应类别调整列
- [ ] 跌价准备调整是否仅来自科目 **1471**（非 1412）
- [ ] 进销差价相关调整是否使用 **1412** 且不与 1406 库存商品混淆
- [ ] AJE/RJE 分类是否正确，借贷是否平衡
- [ ] 建议未调整错报是否已记入未调整错报汇总

### 三、跌价与净值

- [ ] 跌价准备区是否与 F2-47/48/49 测试结论勾稽
- [ ] 净值是否等于原值审定减去跌价准备审定
- [ ] 跌价准备对冲列示是否符合列报要求
- [ ] 零跌价或全额跌价的异常类别是否已评价

### 四、分类列报

- [ ] 原材料/在途/周转材料/半成品/委托加工/库存商品/发出商品等分类是否正确
- [ ] 开发产品、开发成本、合同履约成本、消耗性生物资产是否单独列报
- [ ] 关联方存货或受限存货是否在说明或附注中恰当反映

---

## risk_areas

- high: 1471/1412 科目错用；明细合计与审定断裂；净值恒等被破坏；跌价明显不足
- medium: 调整未回写；试算不一致未解释；分类列报错误
- low: 索引/格式问题但不影响认定
