# I2-15 开发支出减值准备测试复核提示词

## 概述

本提示词针对开发支出减值准备测试底稿（I2-15）的复核，聚焦尚未达到可使用状态的开发支出强制年度减值测试的执行、减值迹象识别、可收回金额确定及减值损失确认。开发支出（在研项目）因尚未达到可使用状态，无论有无减值迹象均须每年减值测试，是CAS8的强制要求。

**法规依据：**
- 《企业会计准则第8号——资产减值》
- 《企业会计准则第6号——无形资产》

---

## tips

1. **强制年度减值测试**：尚未达到可使用状态的开发支出（在研项目）无论有无减值迹象，每年均须进行减值测试。
2. **减值迹象全面评估**：技术过时、项目搁置/失败、市场需求消失、研发进度严重滞后、预算严重超支等均为减值迹象。
3. **可收回金额确定**：可收回金额=公允价值减处置费用与使用价值（未来现金流量折现）孰高，在研项目使用价值预测须谨慎。
4. **减值损失确认**：账面价值超过可收回金额的差额确认为减值损失（资产减值损失）。
5. **减值不可转回**：开发支出减值一经确认不得转回（CAS8）。
6. **失败项目全额减值/费用化**：已失败或终止的开发项目应全额转销（费用化或全额减值）。

---

## checklist

### 一、强制测试执行

- [ ] 尚未达到可使用状态的开发支出是否全部执行年度减值测试
- [ ] 减值测试是否无论有无迹象均执行（在研项目强制）
- [ ] 减值迹象（技术过时/搁置/失败/进度滞后/预算超支）是否全面评估

### 二、可收回金额与减值确认

- [ ] 可收回金额是否取公允价值减处置费用与使用价值孰高
- [ ] 在研项目使用价值预测是否谨慎合理（勾稽I2-16）
- [ ] 减值损失是否等于账面价值减可收回金额
- [ ] 减值损失是否计入资产减值损失科目
- [ ] 失败/终止项目是否全额减值或费用化

### 三、减值处理与勾稽

- [ ] 是否体现开发支出减值不可转回
- [ ] 减值金额是否与I2-3调整分录、I2-2明细表勾稽
- [ ] 减值准备是否计入I2-1审定表
- [ ] 本期减值损失是否与利润表资产减值损失勾稽

## risk_areas

### 高风险

1. **强制测试未执行**：在研开发支出未执行强制年度减值测试。
2. **失败项目未减值**：已失败或搁置项目未全额减值/费用化，虚增资产虚增利润。
3. **可收回金额虚高**：在研项目使用价值预测过于乐观，规避减值。
4. **减值转回**：将开发支出减值损失转回。

### 中风险

1. **减值迹象识别不充分**：明显减值迹象未识别（进度滞后、预算超支）。
2. **减值金额计算错误**：账面价值或可收回金额确定错误。
3. **减值未勾稽调整分录**。

### 低风险

1. **减值测试记录不完整**。
2. **可收回金额确定依据文档不充分**。
3. **与审定表/明细表勾稽索引缺失**。
