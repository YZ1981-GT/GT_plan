# I2-1 开发支出审定表复核提示词

## 概述

本提示词针对开发支出审定表（I2-1）的复核，聚焦开发支出（资本化研发投入）的期初期末勾稽、试算平衡表1717科目核对、本期资本化投入与结转无形资产的完整性、以及资本化条件持续满足的评估。开发支出是资本化研发支出的归集科目，其审定数的可靠性依赖资本化条件判断（I2-6）的严谨性。

**法规依据：**
- 《企业会计准则第6号——无形资产》
- 《企业会计准则第8号——资产减值》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **开发支出滚动勾稽**：期末余额=期初余额+本期资本化投入−本期结转无形资产−本期费用化转出−本期减值，各环节须逐项勾稽。
2. **期初承前**：期初审定数须等于上年审定表期末审定数，差异须追溯至前期差错更正。
3. **试算平衡表核对**：审定表开发支出合计须与试算平衡表1717开发支出科目审定数一致。
4. **资本化投入须满足条件**：本期资本化投入须以持续满足CAS6五条件为前提（勾稽I2-6资本化时点判断），条件不再满足的须停止资本化并将已资本化支出转费用。
5. **结转无形资产须及时**：开发项目达到预定用途时应及时从开发支出结转至无形资产，结转金额须与I1-2内部研发形成无形资产原值勾稽。
6. **关注长期挂账的开发支出**：长期挂账未结转、未费用化的开发支出可能存在项目失败或减值风险，须追溯项目进展。

## checklist

### 一、期初期末勾稽

- [ ] 期初审定数是否等于上年审定表期末审定数（承前）
- [ ] 期末余额=期初+本期资本化投入−结转无形资产−费用化转出−减值 是否成立
- [ ] 本期资本化投入是否与I2-2明细表、I2-7研发项目构成一致
- [ ] 本期结转无形资产是否与I1-2内部研发形成原值勾稽
- [ ] 各项目期初期末变动是否与明细表一致

### 二、试算平衡表核对

- [ ] 审定表开发支出合计是否与试算平衡表1717科目审定数一致
- [ ] 试算平衡表未审数、调整数与审定表对应列是否一致
- [ ] 是否存在试算平衡表已更新但审定表未同步的情况

### 三、审计调整完整性

- [ ] 不符合资本化条件转费用化的调整是否完整反映
- [ ] 结转无形资产、减值等账项调整（AJE）是否完整反映
- [ ] 调整分录借贷平衡，审定数=未审数+AJE+RJE是否成立
- [ ] 是否存在I2-3已编制但未纳入审定表的调整
- [ ] 建议未调整错报是否记录（勾稽A13）

### 四、资本化条件与列报

- [ ] 期末资本化的开发支出是否持续满足CAS6五条件（勾稽I2-6）
- [ ] 长期挂账未结转的开发支出是否评估项目进展和减值
- [ ] 开发支出是否在非流动资产恰当列报
- [ ] 审定表分类是否与附注披露一致

## risk_areas

### 高风险

1. **期初期末不勾稽**：期初与上年期末不一致或滚动公式不成立，审定基准失真。
2. **不满足条件仍资本化**：资本化条件不再满足却继续资本化或未转费用，虚增资产虚增利润。
3. **结转无形资产不及时或金额不符**：达到预定用途未及时结转，或结转金额与I1-2不一致。
4. **试算平衡表与审定表不一致**：1717科目口径不一致，存在未发现的调整遗漏。

### 中风险

1. **明细与汇总不勾稽**：审定表合计与I2-2明细表不一致。
2. **长期挂账未减值**：长期未结转开发支出存在减值迹象但未测试。
3. **费用化转出遗漏**：应费用化的研究阶段支出仍挂账开发支出。

### 低风险

1. **审定表格式不规范**。
2. **交叉索引不完整**（未链接I2-6/I2-7/I1-2）。
3. **变动说明不充分**。
