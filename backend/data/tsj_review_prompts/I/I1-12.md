# I1-12 无形资产减值准备测试复核提示词

## 概述

本提示词针对无形资产减值准备测试底稿（I1-12）的复核，聚焦减值迹象识别的充分性、减值测试的强制性执行（不确定寿命及未达可使用状态项目）、可收回金额确定的合理性及减值损失确认的准确性。无形资产减值一经确认不得转回，减值判断的独立性和证据充分性至关重要。

**法规依据：**
- 《企业会计准则第8号——资产减值》
- 《企业会计准则第6号——无形资产》

---

## tips

1. **减值迹象识别是起点**：外部（市场价值下跌、技术/市场/经济环境不利变化、利率上升）和内部（陈旧过时、闲置、计划处置、绩效低于预期）迹象须全面评估。
2. **强制年度测试项目**：使用寿命不确定的无形资产、尚未达到可使用状态的无形资产（如在建软件）无论有无迹象均须每年减值测试。
3. **可收回金额=公允价值减处置费用与使用价值孰高**：两者取高，使用价值采用现金流量折现（勾稽I1-13可收回金额测试DCF）。
4. **减值损失=账面价值−可收回金额**：当可收回金额低于账面价值时确认减值损失，计入资产减值损失。
5. **减值不可转回**：无形资产（除商誉外）减值损失在以后期间不得转回。
6. **勾稽摊销测算与审定表**：减值金额须传递至I1-11含减值摊销测算，并计入I1-1审定表减值准备。

## checklist

### 一、减值迹象识别

- [ ] 是否全面评估外部减值迹象（市场价值、技术/市场/环境变化、利率）
- [ ] 是否全面评估内部减值迹象（陈旧、闲置、计划处置、绩效低于预期）
- [ ] 使用寿命不确定的无形资产是否无论有无迹象均执行减值测试
- [ ] 尚未达到可使用状态的无形资产是否每年减值测试
- [ ] 有减值迹象的其他无形资产是否均执行减值测试

### 二、可收回金额与减值确认

- [ ] 可收回金额是否取公允价值减处置费用与使用价值孰高
- [ ] 使用价值现金流量折现是否合理（勾稽I1-13）
- [ ] 减值损失是否等于账面价值减可收回金额
- [ ] 减值损失是否计入资产减值损失科目
- [ ] 无法单独测试的无形资产是否并入相关资产组测试

### 三、减值处理与勾稽

- [ ] 是否体现无形资产减值不可转回
- [ ] 减值金额是否传递至I1-11含减值摊销测算
- [ ] 减值准备是否计入I1-1审定表并勾稽试算平衡表1703科目
- [ ] 本期减值损失是否与利润表资产减值损失勾稽

## risk_areas

### 高风险

1. **减值迹象识别不充分规避减值**：对明显减值迹象（技术过时、绩效低于预期）视而不见，不确认减值，虚增资产虚增利润。
2. **强制测试项目未测试**：不确定寿命或在建无形资产未执行强制年度减值测试。
3. **可收回金额虚高**：使用价值现金流量假设过于乐观，规避或少计减值。
4. **减值转回**：将无形资产减值损失转回。

### 中风险

1. **资产组划分不当**：无法单独产生现金流的无形资产未恰当并入资产组测试。
2. **减值损失计算错误**：账面价值或可收回金额确定错误导致减值金额偏差。
3. **减值未传递至摊销测算**：减值后摊销基数未调整（勾稽I1-11）。

### 低风险

1. **减值迹象评估记录不完整**。
2. **可收回金额确定依据文档不充分**。
3. **减值测试与审定表勾稽索引缺失**。
