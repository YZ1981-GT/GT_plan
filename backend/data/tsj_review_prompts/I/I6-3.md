# I6-3 研发费用调整分录复核提示词

## 概述

本提示词针对研发费用调整分录汇总表（I6-3，损益类）的复核，含账项调整（AJE）、重分类调整（RJE）及未调整错报评估。复核重点是费用化/资本化重分类调整、非研发支出调出、跨期费用调整的证据充分性、借贷平衡及与I6-1审定表、试算平衡表6602科目的闭环勾稽。

**法规依据：**
- 《企业会计准则第6号——无形资产》
- 《企业会计准则第28号——会计政策、会计估计变更和差错更正》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **费用化/资本化重分类**：审计发现应资本化误费用化（或应费用化误资本化）的支出须调整，涉及研发费用与开发支出（I2）的对调。
2. **非研发支出调出**：将不当计入研发费用的非研发支出调出至相应科目（管理费用等）。
3. **跨期费用调整**：跨期归集的研发费用须调整至正确期间（勾稽I6-5/I6-6截止测试）。
4. **与I6-1勾稽**：审定表调整列金额须与I6-3已确认分录逐笔一致。
5. **加计扣除影响**：研发费用调整影响加计扣除基数，须评估对递延所得税/所得税费用的影响（勾稽N所得税）。
6. **TB回写**：调整须同步试算平衡表6602科目。

## checklist

### 一、调整证据与审批

- [ ] 费用化/资本化重分类是否有资本化条件判断证据（勾稽I2-6）
- [ ] 非研发支出调出是否有性质判断依据
- [ ] 跨期费用调整是否有截止测试支持（勾稽I6-5/I6-6）
- [ ] 超重要性水平调整是否经适当审批
- [ ] 每笔调整分录借贷方是否平衡

### 二、与审定表及TB勾稽

- [ ] 调整金额是否完整反映到I6-1审定表调整列
- [ ] 审定数=未审数+AJE+RJE是否成立
- [ ] 调整后研发费用是否回写试算平衡表6602科目
- [ ] 资本化重分类是否勾稽I2开发支出
- [ ] 未调整错报是否与A13勾稽

### 三、调整性质与影响

- [ ] 费用化/资本化重分类计入科目是否正确
- [ ] 跨期调整是否正确区分本期/前期差错
- [ ] 研发费用调整对加计扣除及所得税的影响是否评估（勾稽N）
- [ ] 调整原因说明是否可追溯至具体审计程序

## risk_areas

### 高风险

1. **费用化/资本化调整遗漏**：应调整的划分错误未调整，影响损益和资产。
2. **非研发支出未调出**：不当计入的非研发支出未调出，虚增研发费用及加计扣除。
3. **加计扣除影响未评估**：研发费用调整未评估对加计扣除和所得税的影响。

### 中风险

1. **审定表与I6-3调整不一致**。
2. **跨期调整无截止测试支持**。
3. **未调整错报累计超阈值未处理**。

### 低风险

1. **分录摘要、科目编码不规范**。
2. **索引指向支持底稿不完整**。
3. **审计说明未概括调整性质**。

## 跨底稿勾稽

- I6-3 费用化/资本化重分类 ↔ I2 开发支出
- I6-3 跨期调整 ↔ I6-5/I6-6 截止测试
- I6-3 已确认调整合计 ↔ I6-1 审定表调整列
- I6-3 SUD ↔ A13 未调整错报汇总
- 调整后审定数 ↔ 试算平衡表 6602
