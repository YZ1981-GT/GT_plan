# I6-note-soe 研发费用附注披露复核提示词（国有企业）

## 概述

本提示词针对研发费用国有企业附注披露底稿（I6-note-soe）的复核，聚焦研发费用构成及投入披露（与上市版共有）及国有企业特定关注：科技创新投入的国资考核披露、研发投入强度考核指标、研发投入与预算执行、财务决算报表口径一致性。国企研发投入是科技创新考核的核心指标，须准确披露。

**法规依据：**
- 《企业会计准则第6号——无形资产》
- 《企业会计准则第30号——财务报表列报》
- 《中央企业财务决算报告管理办法》

---

## tips

1. **国企附注双层披露**：既满足CAS6通用披露，又满足国资委财务决算及科技创新考核披露要求。
2. **研发费用构成披露**：按性质（人员薪酬/直接投入/折旧摊销/委外/其他）披露构成。
3. **研发投入强度考核**：研发投入强度（研发投入/营业收入）是国资委科技创新考核指标，须准确披露不得虚增。
4. **研发投入与预算**：研发投入与年度研发预算对比，偏差须说明。
5. **加计扣除合规**：研发费用加计扣除归集须合规，避免为提升考核指标虚增研发投入。
6. **决算口径一致**：研发费用数据须与年度财务决算报表一致。

## checklist

### 一、基础披露完整性（与上市版共有）

- [ ] 研发费用是否按性质分类披露构成
- [ ] 各构成合计是否等于研发费用总额及I6-1审定数
- [ ] 研发投入总额、费用化/资本化金额是否披露
- [ ] 各构成是否与I6-2明细表勾稽
- [ ] 本期上期可比信息是否完整

### 二、投入强度与预算

- [ ] 研发投入强度（研发投入/营业收入）是否准确披露
- [ ] 研发投入是否纳入科技创新考核披露
- [ ] 研发投入与年度研发预算对比是否披露
- [ ] 预算执行偏差是否说明

### 三、合规与决算

- [ ] 研发费用加计扣除归集是否合规
- [ ] 是否存在为提升考核指标虚增研发投入
- [ ] 研发费用数据是否与年度财务决算报表一致
- [ ] 决算与审计口径差异是否编制调节说明
- [ ] 与上市版相比是否补充国资监管/科技创新层面信息

## risk_areas

### 高风险

1. **构成不勾稽或与审定表不一致**。
2. **研发投入强度虚增**：为提升科技创新考核指标虚增研发投入。
3. **加计扣除违规**：研发费用加计扣除归集不合规存在税务风险。

### 中风险

1. **构成分类不完整**。
2. **预算执行偏差未说明**。
3. **决算与审计口径差异未调节**。

### 低风险

1. **披露格式未完全按决算模板**。
2. **项目说明简略**。
3. **可比信息不完整**。
