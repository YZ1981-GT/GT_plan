# I2-13 开发支出截止性测试（账到单据）复核提示词

## 概述

本提示词针对开发支出截止性测试（由账面记录到原始单据，账→单）底稿（I2-13）的复核，聚焦资产负债表日前后资本化开发支出的会计期间归属正确性，从账面记录追查至原始单据（领料单/工时/委外验收），验证是否存在跨期资本化。截止测试确保开发支出资本化归属于正确会计期间。

**法规依据：**
- 《企业会计准则第6号——无形资产》
- 《中国注册会计师审计准则第1314号——审计抽样》

---

## tips

1. **账到单据方向**：从账面资本化记录出发，追查至原始单据（领料单/工时记录/委外验收单/发票），验证单据日期与入账期间一致。
2. **测试窗口覆盖跨期**：选取资产负债表日前后一定天数（如前后5天/10天）的资本化记录测试。
3. **跨期资本化识别**：期末资本化支出对应的原始单据若属下期，则本期资本化提前，虚增期末开发支出。
4. **关注期末突增**：期末最后几天集中资本化的支出须重点核查单据日期。
5. **满足条件时点结合**：跨期测试须结合资本化时点判断（I2-6），确保仅满足条件后的支出资本化。
6. **与I2-14互补**：I2-13（账→单）验证已入账支出的期间，I2-14（单→账）验证已发生支出是否遗漏入账，两者互补。

---

## checklist

### 一、测试设计

- [ ] 测试窗口是否覆盖资产负债表日前后合理天数
- [ ] 样本是否覆盖期末突增的资本化支出
- [ ] 样本选取是否与风险评估匹配

### 二、账到单据核查

- [ ] 账面资本化记录是否逐笔追查至原始单据
- [ ] 单据日期（领料/工时/委外验收）与入账期间是否一致
- [ ] 是否存在期末资本化但单据属下期（提前资本化）
- [ ] 跨期支出是否结合资本化时点判断评估

### 三、结果处理

- [ ] 发现的跨期资本化是否标注并评估调整
- [ ] 跨期金额是否与I2-3调整分录勾稽
- [ ] 截止测试结论是否与审定表勾稽

## risk_areas

### 高风险

1. **提前资本化虚增期末开发支出**：期末资本化的支出对应单据属下期，虚增期末资产。
2. **期末突增未核查跨期**：期末集中资本化未验证单据期间。

### 中风险

1. **测试窗口不足**：窗口天数过短未覆盖跨期风险。
2. **单据日期核对不严**：仅核对金额未核对单据日期。
3. **跨期金额未评估调整**。

### 低风险

1. **样本选取记录不完整**。
2. **截止测试记录格式不规范**。
3. **与调整分录勾稽索引缺失**。
