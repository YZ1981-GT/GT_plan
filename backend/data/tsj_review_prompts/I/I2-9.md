# I2-9 研发人员认定检查复核提示词

## 概述

本提示词针对研发人员认定检查底稿（I2-9）的复核，聚焦资本化研发人员薪酬的人员认定准确性、直接从事开发活动的判断、薪酬归集的完整性及与人员名单/薪酬记录的勾稽。研发人员薪酬通常是资本化开发支出的最大构成，人员认定不当将直接虚增资本化金额。

**法规依据：**
- 《企业会计准则第6号——无形资产》
- 《中国注册会计师审计准则第1314号——审计抽样》

---

## tips

1. **仅直接从事开发人员薪酬可资本化**：直接从事特定开发项目的人员薪酬可资本化，行政/销售/一般管理人员不得计入。
2. **人员认定须有依据**：研发人员认定须凭研发人员名单、劳动合同、岗位说明、项目分工，不得随意扩大范围。
3. **薪酬归集完整**：资本化薪酬包括工资、奖金、社保、公积金等，归集口径须完整一致（勾稽J职工薪酬）。
4. **兼职人员按工时分摊**：既从事研发又从事其他工作的人员，薪酬须按合理工时分摊（勾稽I2-10工时检查）。
5. **满足条件后薪酬资本化**：仅满足五条件后从事开发的人员薪酬可资本化，此前费用化。
6. **关注人员数量与薪酬异常**：研发人员数量激增、人均薪酬畸高、与工时不匹配须核查。

---

## checklist

### 一、人员认定

- [ ] 资本化研发人员是否有名单、劳动合同、岗位说明支持
- [ ] 是否仅认定直接从事特定开发项目的人员
- [ ] 是否将行政/销售/一般管理人员不当认定为研发人员
- [ ] 研发人员数量较上年变动是否合理

### 二、薪酬归集

- [ ] 资本化薪酬口径是否完整（工资/奖金/社保/公积金）
- [ ] 薪酬金额是否与J职工薪酬循环勾稽
- [ ] 兼职人员薪酬是否按合理工时分摊（勾稽I2-10）
- [ ] 是否仅将满足条件后薪酬资本化

### 三、合理性

- [ ] 人均薪酬是否合理（与企业整体薪酬水平匹配）
- [ ] 人员数量激增是否有合理解释
- [ ] 资本化人员薪酬是否与I2-7项目构成、I2-10工时勾稽

## risk_areas

### 高风险

1. **人员认定范围扩大**：将非直接研发人员（管理/销售）薪酬资本化，虚增开发支出。
2. **虚增研发人员**：认定不实际从事研发的人员，虚增资本化薪酬。
3. **兼职人员全额资本化**：兼职研发人员薪酬未按工时分摊全额资本化。

### 中风险

1. **薪酬口径不完整或不一致**：资本化薪酬口径与J循环不一致。
2. **满足条件前薪酬资本化**。
3. **人员数量激增未解释**。

### 低风险

1. **人员名单/合同证据不完整**。
2. **薪酬归集记录不规范**。
3. **与工时/项目构成勾稽索引缺失**。
