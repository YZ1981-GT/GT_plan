# I2-note-soe 开发支出附注披露复核提示词（国有企业）

## 概述

本提示词针对开发支出国有企业附注披露底稿（I2-note-soe）的复核，聚焦开发支出变动披露（与上市版共有）及国有企业特定披露要求：科技创新投入的国资监管披露、研发投入与预算执行、重大研发项目的立项审批、财务决算报表口径一致性。国企研发投入既反映会计信息又服务国资科技创新考核。

**法规依据：**
- 《企业会计准则第6号——无形资产》
- 《企业会计准则第8号——资产减值》
- 《企业会计准则第30号——财务报表列报》
- 《中央企业财务决算报告管理办法》

---

## tips

1. **国企附注双层披露**：既满足CAS6通用披露，又满足国资委财务决算及科技创新考核披露要求。
2. **研发投入与预算执行**：披露本期研发投入与年度研发预算的对比，偏差须说明。
3. **重大项目立项审批**：重大研发项目的立项是否经适当决策程序（"三重一大"），须披露审批情况。
4. **资本化政策审慎性**：国企资本化政策须审慎，避免通过资本化调节业绩考核指标。
5. **科技创新考核**：研发投入强度（研发投入/营业收入）是国资委科技创新考核指标，须准确披露。
6. **决算口径一致**：开发支出数据须与年度财务决算报表一致。

## checklist

### 一、基础披露完整性（与上市版共有）

- [ ] 开发支出变动表是否完整（期初/增加/减少/期末）
- [ ] 附注期末余额是否与I2-1审定数一致
- [ ] 本期资本化投入是否与I2-2明细表勾稽
- [ ] 研发投入总额、资本化金额、资本化率是否披露
- [ ] 期初期末可比信息是否完整

### 二、研发投入与预算

- [ ] 本期研发投入与年度研发预算对比是否披露
- [ ] 研发投入强度（研发投入/营业收入）是否披露
- [ ] 预算执行偏差是否说明原因
- [ ] 研发投入是否纳入科技创新考核披露

### 三、项目审批与减值

- [ ] 重大研发项目立项是否经适当决策程序并披露
- [ ] 重大在研项目进展/累计投入是否披露
- [ ] 本期减值/失败项目的金额、原因是否披露
- [ ] 资本化政策审慎性是否符合国资监管要求

### 四、决算一致与差异

- [ ] 开发支出数据是否与年度财务决算报表一致
- [ ] 决算与审计口径差异是否编制调节说明
- [ ] 与上市版相比是否补充国资监管/科技创新层面信息

## risk_areas

### 高风险

1. **变动表不勾稽或与审定表不一致**。
2. **资本化政策调节考核指标**：通过过度资本化调节研发投入强度或业绩考核指标未审慎披露。
3. **重大项目未经审批**：重大研发项目立项未经决策程序或未披露。

### 中风险

1. **研发投入强度披露不实**：科技创新考核指标披露与实际不符。
2. **预算执行偏差未说明**。
3. **决算与审计口径差异未调节**。

### 低风险

1. **披露格式未完全按决算模板**。
2. **项目进展说明简略**。
3. **历史趋势分析不完整**。
