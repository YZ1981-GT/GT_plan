# I3-note-soe 商誉附注披露复核提示词（国有企业）

## 概述

本提示词针对商誉国有企业附注披露底稿（I3-note-soe）的复核，聚焦商誉变动及减值披露（与上市版共有）及国有企业特定披露要求：并购重组的国资审批、商誉减值对国有资本保值增值的影响、重大并购决策程序、财务决算报表口径一致性。国企并购形成的商誉减值涉及国有资产管理责任。

**法规依据：**
- 《企业会计准则第20号——企业合并》
- 《企业会计准则第8号——资产减值》
- 《企业会计准则第30号——财务报表列报》
- 《中央企业财务决算报告管理办法》

---

## tips

1. **国企附注双层披露**：既满足CAS8/CAS20通用披露，又满足国资委财务决算及国有资产监管披露要求。
2. **并购重组审批披露**：形成商誉的重大并购须经"三重一大"决策程序及国资监管审批，须披露审批情况。
3. **减值对国有资本影响**：商誉大额减值须说明对国有资本保值增值率的影响及责任评估。
4. **减值责任追究**：并购标的业绩严重不达预期导致大额商誉减值的，须说明是否启动责任追究程序。
5. **减值测试关键信息**：同上市版须披露资产组、可收回金额方法、关键假设。
6. **决算口径一致**：商誉数据须与年度财务决算报表一致。

## checklist

### 一、基础披露完整性（与上市版共有）

- [ ] 商誉变动表是否按资产组列示（期初/减值/期末）
- [ ] 附注商誉账面价值是否与I3-1审定数一致
- [ ] 各资产组商誉是否与I3-2明细表勾稽
- [ ] 减值测试关键信息（资产组/可收回金额方法/关键假设）是否披露
- [ ] 期初期末可比信息是否完整

### 二、并购审批与国资监管

- [ ] 形成商誉的重大并购是否经决策程序并披露审批情况
- [ ] 商誉大额减值对国有资本保值增值率影响是否说明
- [ ] 并购标的业绩不达预期是否说明责任评估/追究
- [ ] 商誉减值是否纳入国有资产经营考核披露

### 三、减值与决算

- [ ] 本期计提商誉减值损失金额、涉及资产组、原因是否披露
- [ ] 商誉数据是否与年度财务决算报表一致
- [ ] 决算与审计口径差异是否编制调节说明
- [ ] 与上市版相比是否补充国资监管层面信息

## risk_areas

### 高风险

1. **变动表不勾稽或减值信息缺失**：商誉变动与审定表不一致或减值关键信息未披露。
2. **并购未经审批**：形成商誉的重大并购未经决策程序或未披露。
3. **减值对国有资本影响未说明**：大额减值未说明对保值增值影响及责任。
4. **减值责任追究缺失**：业绩严重不达预期大额减值未说明责任追究。

### 中风险

1. **关键假设未量化披露**。
2. **决算与审计口径差异未调节**。
3. **减值原因披露不充分**。

### 低风险

1. **披露格式未完全按决算模板**。
2. **并购审批说明简略**。
3. **历史趋势分析不完整**。
