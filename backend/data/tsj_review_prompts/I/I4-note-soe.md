# I4-note-soe 长期待摊费用附注披露复核提示词（国有企业）

## 概述

本提示词针对长期待摊费用国有企业附注披露底稿（I4-note-soe）的复核，聚焦长期待摊费用变动及摊销披露（与上市版共有）及国有企业特定关注：大额支出的立项审批、经营租入固定资产改良的合规性、财务决算报表口径一致性。国企长期待摊费用虽金额有限，仍须符合国资监管的资产质量披露要求。

**法规依据：**
- 《企业会计准则第30号——财务报表列报》
- 《中央企业财务决算报告管理办法》

---

## tips

1. **国企附注双层披露**：既满足CAS30通用披露，又满足国资委财务决算披露要求。
2. **变动情况披露**：披露各项目期初、本期增加、本期摊销、其他减少、期末，勾稽须成立。
3. **大额支出立项审批**：形成大额长期待摊费用的支出（如大额装修/改良）须经适当审批，须关注合规性。
4. **经营租入改良合规性**：经营租入固定资产改良须核查租赁合规性及改良必要性。
5. **决算口径一致**：长期待摊费用数据须与年度财务决算报表一致。
6. **资产质量视角**：长期挂账无受益基础的长期待摊费用可能影响资产质量评价。

## checklist

### 一、基础披露完整性（与上市版共有）

- [ ] 长期待摊费用变动表是否完整（期初/增加/摊销/其他减少/期末）
- [ ] 是否按项目/性质分类披露
- [ ] 附注期末余额是否与I4-1审定数一致
- [ ] 各项目是否与I4-2明细表勾稽
- [ ] 期初期末可比信息是否完整

### 二、审批与合规

- [ ] 大额长期待摊费用支出立项审批是否合规
- [ ] 经营租入固定资产改良租赁合规性是否核查
- [ ] 是否披露摊销期限
- [ ] 长期挂账无受益基础项目是否说明

### 三、决算一致

- [ ] 长期待摊费用数据是否与年度财务决算报表一致
- [ ] 决算与审计口径差异是否编制调节说明
- [ ] 与上市版相比是否补充国资监管层面信息

## risk_areas

### 高风险

1. **变动表不勾稽或与审定表不一致**。
2. **大额支出未审批**：形成大额长期待摊费用支出未经适当审批。
3. **无受益基础项目未转销未说明**。

### 中风险

1. **经营租入改良合规性未核查**。
2. **摊销期限披露缺失**。
3. **决算与审计口径差异未调节**。

### 低风险

1. **披露格式未完全按决算模板**。
2. **项目说明简略**。
3. **可比信息不完整**。
