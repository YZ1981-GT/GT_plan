# I2-note-listed 开发支出附注披露复核提示词（上市公司）

## 概述

本提示词针对开发支出上市公司附注披露底稿（I2-note-listed）的复核，聚焦开发支出变动情况披露、研发投入资本化政策及资本化率披露、重要研发项目信息、开发支出减值信息及研发投入总额（含费用化）的披露充分性。上市公司研发投入及资本化政策是投资者关注的焦点，须满足CAS6及信息披露编报规则要求。

**法规依据：**
- 《企业会计准则第6号——无形资产》
- 《企业会计准则第8号——资产减值》
- 《企业会计准则第30号——财务报表列报》
- 《公开发行证券的公司信息披露编报规则第15号》

---

## tips

1. **开发支出变动表**：披露期初、本期增加（资本化投入）、本期减少（结转无形资产/费用化/减值）、期末，勾稽须成立。
2. **研发投入总额及资本化率**：披露本期研发投入总额、资本化金额及资本化率，是评价研发能力和资本化政策审慎性的关键指标（勾稽I6费用化研发）。
3. **资本化政策披露**：披露研究阶段与开发阶段划分标准、资本化五条件的具体判断标准，是理解资本化基础的前提。
4. **重要研发项目披露**：重要在研项目的名称、进展、累计投入、预计完成时间等信息（上市公司重点关注）。
5. **减值信息披露**：本期计提开发支出减值的金额、原因（项目失败/搁置等）及可收回金额确定方法。
6. **附注与审定表勾稽**：附注开发支出期末余额须等于I2-1审定数，本期资本化投入须与I2-2明细表勾稽。

---

## checklist

### 一、变动与资本化率披露

- [ ] 开发支出变动表是否完整（期初/增加/减少[结转/费用化/减值]/期末）
- [ ] 是否披露本期研发投入总额、资本化金额及资本化率
- [ ] 资本化金额是否与I2-2明细表本期资本化投入勾稽
- [ ] 费用化研发投入是否与I6研发费用勾稽
- [ ] 期末开发支出余额是否等于I2-1审定数

### 二、政策与项目披露

- [ ] 是否披露研究与开发阶段划分标准
- [ ] 是否披露资本化五条件的具体判断标准
- [ ] 重要在研研发项目的进展/累计投入/预计完成是否披露
- [ ] 资本化政策是否与上年一致，变更是否披露

### 三、减值与其他

- [ ] 本期计提开发支出减值的金额、原因是否披露
- [ ] 可收回金额确定方法是否披露（勾稽I2-15/I2-16）
- [ ] 本期结转无形资产的金额是否披露（勾稽I1）
- [ ] 是否同时列示期末数和期初数（可比信息）

## risk_areas

### 高风险

1. **变动表不勾稽**：开发支出变动勾稽不成立或与审定表/明细表不一致。
2. **资本化率披露缺失或不实**：未披露资本化率或与实际资本化/费用化结构不符，掩盖过度资本化。
3. **减值信息缺失**：本期项目失败/减值未披露金额和原因。
4. **资本化政策披露不充分**：未披露五条件判断标准，投资者无法评估资本化基础。

### 中风险

1. **重要项目信息缺失**：未披露重要在研项目进展。
2. **研发投入总额未披露**：仅披露资本化金额未披露投入总额。
3. **可比信息缺失**。

### 低风险

1. **披露格式不完全规范**。
2. **政策描述模板化**。
3. **数字精度不一致**。
