# I1-13 无形资产可收回金额测试（DCF）复核提示词

## 概述

本提示词针对无形资产可收回金额测试（现金流量折现，DCF）底稿（I1-13）的复核，聚焦使用价值现金流量预测的合理性、折现率（税前）确定的适当性、预测期与稳定增长率假设及可收回金额确定方法的准确性。DCF测算是减值测试（I1-12）的核心支撑，关键假设的合理性直接影响减值结论。

**法规依据：**
- 《企业会计准则第8号——资产减值》

---

## tips

1. **可收回金额取两者孰高**：公允价值减处置费用与使用价值（DCF）孰高。若能取得公允价值减处置费用且高于账面价值，可无需DCF。
2. **使用价值现金流量口径**：基于资产当前状况的未来现金流量，不含筹资活动、所得税及未来重组/资产改良带来的现金流量。
3. **预测期通常不超过5年**：超过5年的预测须有充分理由；预测期后采用稳定或递减增长率外推。
4. **折现率为税前利率**：使用价值现金流量为税前口径，折现率须为反映货币时间价值和资产特定风险的税前利率（勾稽WACC推算）。
5. **关键假设合理性**：收入增长率、毛利率、增长率外推等关键假设须与历史业绩、行业趋势、管理层预算一致，过于乐观将规避减值。
6. **敏感性分析**：对关键假设（折现率、增长率）进行敏感性分析，评估减值结论的稳健性。

## checklist

### 一、现金流量预测

- [ ] 现金流量预测是否基于资产当前状况（不含未来重组/改良）
- [ ] 现金流量是否为税前口径且不含筹资活动现金流量
- [ ] 收入增长率、毛利率等关键假设是否与历史、预算、行业一致
- [ ] 预测期是否合理（通常不超过5年，超过须有理由）
- [ ] 预测期后稳定增长率是否合理（不超过行业长期增长率）

### 二、折现率确定

- [ ] 折现率是否为税前利率（与税前现金流量口径一致）
- [ ] 折现率是否反映货币时间价值和资产特定风险
- [ ] WACC推算（如采用）的参数（无风险利率、风险溢价、Beta等）是否合理
- [ ] 折现率与被审计单位实际风险水平是否匹配

### 三、可收回金额与减值结论

- [ ] 使用价值现值计算是否正确（现金流量×折现系数）
- [ ] 可收回金额是否取公允价值减处置费用与使用价值孰高
- [ ] 可收回金额是否与账面价值比较得出减值结论（勾稽I1-12）
- [ ] 是否进行关键假设敏感性分析
- [ ] DCF测算结论是否与I1-12减值测试一致

## risk_areas

### 高风险

1. **现金流量假设过于乐观规避减值**：收入增长率、毛利率明显高于历史和行业水平，人为抬高使用价值以规避减值。
2. **折现率口径错误**：使用税后折现率折现税前现金流量，或折现率过低虚高使用价值。
3. **预测期不当延长**：无理由将预测期延长至5年以上，累积乐观假设虚高使用价值。

### 中风险

1. **稳定增长率过高**：永续增长率超过行业长期增长率，虚高终值。
2. **现金流量口径错误**：现金流量含筹资活动、所得税或未来改良带来的现金流。
3. **敏感性分析缺失**：未对关键假设进行敏感性分析，减值结论稳健性不明。

### 低风险

1. **DCF参数来源文档不充分**。
2. **折现系数计算精度差异**。
3. **测算与减值测试勾稽索引不完整**。
