# I4-7 长期待摊费用摊销测算（工作量法）复核提示词

## 概述

本提示词针对长期待摊费用摊销测算（工作量法）底稿（I4-7）的复核，聚焦按工作量法（受益量比例）逐项目测算本期摊销额，验证工作量参数（总工作量/本期工作量）准确性及测算结果与账面计提的一致性。工作量法适用于受益随工作量非均匀分布的长期待摊费用，摊销测算是审计师对企业摊销的独立验证。

**法规依据：**
- 《企业会计准则第30号——财务报表列报》

---

## tips

1. **工作量法摊销公式**：本期摊销额=原值×（本期工作量÷预计总工作量）；单位工作量摊销额=原值÷预计总工作量。
2. **工作量法适用性**：适用于受益与工作量（产量/使用量）挂钩且非均匀的项目，须有合理依据说明为何不用直线法。
3. **工作量参数须可靠**：预计总工作量、本期实际工作量须有记录支持，参数估计不当将扭曲摊销分布。
4. **累计摊销不超过原值**：累计摊销额不得超过项目原值，工作量超预计时须及时调整。
5. **测算差异须解释**：审计师测算与账面计提的差异须查明原因。
6. **勾稽审定表与明细表**：测算本期摊销总额须与I4-1审定表、I4-2明细表勾稽。

---

## checklist

### 一、工作量参数

- [ ] 预计总工作量是否有合理依据
- [ ] 本期实际工作量是否有记录支持
- [ ] 工作量法适用性是否说明（为何不用直线法）
- [ ] 测算原值是否与I4-2明细表一致

### 二、测算准确性

- [ ] 单位工作量摊销额=原值÷预计总工作量 是否正确
- [ ] 本期摊销额=原值×（本期工作量÷预计总工作量）是否正确
- [ ] 累计摊销额是否未超过原值
- [ ] 预计总工作量变动是否作为会计估计变更处理

### 三、结果勾稽

- [ ] 审计师测算本期摊销与账面计提是否一致
- [ ] 测算差异是否查明原因并评估调整
- [ ] 测算摊销总额是否与I4-1审定表、I4-2明细表勾稽
- [ ] 摊销去向（成本/费用）是否合理

## risk_areas

### 高风险

1. **工作量参数不实**：预计总工作量虚高或本期工作量虚低，少提摊销虚增资产。
2. **工作量法适用不当**：受益均匀项目改用工作量法调节摊销分布。

### 中风险

1. **累计摊销超原值**：工作量超预计但未及时调整导致超额摊销。
2. **工作量记录不可靠**：本期工作量缺乏记录支持。
3. **测算差异未解释**。

### 低风险

1. **测算精度差异**。
2. **工作量参数来源索引不完整**。
3. **测算过程记录不规范**。
