# I4-4 长期待摊费用摊销政策检查复核提示词

## 概述

本提示词针对长期待摊费用摊销政策检查底稿（I4-4）的复核，聚焦长期待摊费用确认标准、摊销期间确定、摊销方法选择及政策一致性。长期待摊费用是无法计入资产、摊销期在一年以上的支出，其确认与摊销政策的适当性是计量的前提。

**法规依据：**
- 《企业会计准则第30号——财务报表列报》
- 《企业会计准则第28号——会计政策、会计估计变更和差错更正》

---

## tips

1. **确认标准**：长期待摊费用须为已经发生、但应由本期和以后各期负担、摊销期在一年以上的费用，不符合资产确认条件（不产生独立可辨认经济利益）。
2. **摊销期间确定原则**：摊销期为受益期间；经营租入固定资产改良按剩余租期与使用寿命孰短；无明确受益期的从严确定。
3. **摊销方法**：通常采用直线法（受益均匀），特殊情况可采用与受益方式匹配的方法（如工作量法）。
4. **政策一致性**：确认标准和摊销政策须与上年一致，变更须符合会计政策/估计变更规定。
5. **区分资本性支出与费用性支出**：达到固定资产/无形资产确认条件的应资本化为相应资产，不应计入长期待摊费用。
6. **开办费处理**：新准则下开办费一般于发生时费用化（管理费用），不再作为长期待摊费用（历史余额除外）。

## checklist

### 一、确认标准

- [ ] 长期待摊费用是否符合确认标准（已发生、跨期负担、摊销期一年以上）
- [ ] 是否将达到资产确认条件的支出误计入长期待摊费用
- [ ] 是否将应一次性费用化的支出误计入长期待摊费用
- [ ] 开办费是否恰当处理（新准则费用化）

### 二、摊销期间与方法

- [ ] 摊销期是否为受益期间
- [ ] 经营租入固定资产改良摊销期是否为剩余租期与使用寿命孰短
- [ ] 摊销方法是否与受益方式匹配（默认直线法）
- [ ] 无明确受益期的项目摊销期是否从严确定

### 三、政策一致性

- [ ] 确认标准和摊销政策是否与上年一致
- [ ] 政策变更是否符合规定并披露
- [ ] 摊销起止时点是否正确

## risk_areas

### 高风险

1. **确认标准过松**：将应费用化支出计入长期待摊费用以延迟费用确认，虚增资产虚增利润。
2. **摊销期过长**：摊销期明显超过实际受益期，虚减各期费用。
3. **应资本化支出误计入**：达到资产确认条件的支出计入长期待摊费用。

### 中风险

1. **摊销期确定无依据**：受益期确定缺乏依据。
2. **经营租入改良摊销期超租期**：摊销期超过剩余租赁期。
3. **政策不一致**：确认标准或摊销方法年度间不一致。

### 低风险

1. **政策文档表述模板化**。
2. **摊销起止时点记录不精确**。
3. **政策变更披露不充分**。
