# I2-6 开发支出资本化时点判断复核提示词

## 概述

本提示词针对开发支出资本化时点判断底稿（I2-6）的复核，聚焦研究阶段与开发阶段的划分、开发阶段支出资本化五条件的逐项判断、资本化起始时点的确定及资本化条件持续满足的评估。资本化时点判断是开发支出会计处理的核心，直接决定研发支出费用化与资本化的分界，是舞弊和盈余管理的高风险领域。

**法规依据：**
- 《企业会计准则第6号——无形资产》

---

## tips

1. **研究阶段全部费用化**：研究阶段（探索性、无明确目标）的支出于发生时计入当期损益（管理费用/研发费用），不得资本化。
2. **开发阶段五条件同时满足才可资本化**：（1）技术上可行；（2）有完成并使用/出售的意图；（3）能产生经济利益（存在市场或内部使用效用）；（4）有足够技术/财务/其他资源支持；（5）支出能可靠计量。五条件缺一不可。
3. **资本化起始时点**：自满足全部五条件之日起，之后发生的开发支出才可资本化，此前支出（含研究阶段及未满足条件的开发阶段支出）已费用化不得转回资本化。
4. **五条件判断须有客观证据**：技术可行性（立项/技术评审/样机/中试）、市场（市场调研/订单）、资源（预算/资金安排）等须有文档支持，不得仅凭管理层声明。
5. **持续满足评估**：资本化后须持续评估五条件是否满足，不再满足时停止资本化，已资本化部分评估减值。
6. **勾稽项目明细与审定表**：资本化时点判断结论须与I2-7研发项目构成、I2-2明细表资本化投入、I2-1审定表勾稽。

## checklist

### 一、研究与开发阶段划分

- [ ] 是否明确区分研究阶段与开发阶段
- [ ] 研究阶段支出是否全部费用化
- [ ] 阶段划分是否有项目立项文件、技术路线图等依据
- [ ] 是否存在将研究阶段支出计入开发阶段以资本化的情况

### 二、五条件逐项判断

- [ ] 技术可行性是否有立项/技术评审/样机/中试等证据
- [ ] 完成并使用/出售的意图是否有管理层决议或计划支持
- [ ] 产生经济利益是否有市场调研/订单/内部使用效用证据
- [ ] 技术/财务/其他资源支持是否有预算/资金安排证据
- [ ] 开发支出是否能可靠计量（成本归集系统健全）
- [ ] 五条件是否同时满足（缺一不得资本化）

### 三、资本化时点与持续满足

- [ ] 资本化起始时点是否为满足全部五条件之日
- [ ] 满足条件前的支出是否已费用化且未转回资本化
- [ ] 资本化后是否持续评估五条件满足情况
- [ ] 条件不再满足的项目是否停止资本化并评估减值
- [ ] 判断结论是否与I2-7/I2-2/I2-1勾稽

## risk_areas

### 高风险

1. **研究阶段支出资本化**：将无明确目标的研究阶段支出计入开发支出资本化，虚增资产虚减费用。
2. **五条件不满足即资本化**：五条件缺项（尤其技术可行性、经济利益）仍资本化，缺乏客观证据支持。
3. **资本化时点提前**：将满足条件前的支出追溯资本化，虚增资产。
4. **失败项目未费用化**：已判定失败或条件不再满足的开发项目未停止资本化、未转费用或减值。

### 中风险

1. **阶段划分依据不足**：研究与开发阶段划分缺乏立项文件等客观依据。
2. **五条件证据仅凭声明**：技术可行性/市场前景仅凭管理层声明无文档支持。
3. **持续满足评估缺失**：资本化后未持续评估条件满足情况。

### 低风险

1. **五条件判断记录不完整**。
2. **判断过程与项目明细勾稽索引缺失**。
3. **资本化时点文档表述不清晰**。
