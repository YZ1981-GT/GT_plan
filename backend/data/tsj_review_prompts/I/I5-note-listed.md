# I5-note-listed 其他非流动资产附注披露复核提示词（上市公司）

## 概述

本提示词针对其他非流动资产上市公司附注披露底稿（I5-note-listed）的复核，聚焦其他非流动资产按项目性质的构成披露、变动情况、重大项目说明及长期性/减值信息披露的充分性。其他非流动资产作为"其他"归集科目，其构成透明度直接影响报表使用者对资产真实性和质量的判断。

**法规依据：**
- 《企业会计准则第30号——财务报表列报》
- 《公开发行证券的公司信息披露编报规则第15号》

---

## tips

1. **构成明细披露**：其他非流动资产须按项目性质（预付长期资产购置款/工程款/待处理项目等）分类披露构成，避免笼统列示。
2. **变动情况披露**：披露各项目期初、本期增加、本期减少、期末，勾稽须成立。
3. **重大项目说明**：金额重大或性质特殊的项目须说明性质、形成原因及预计变现/转出安排。
4. **长期性说明**：说明各项目预计变现/耗用期在一年以上的依据。
5. **减值信息披露**：存在减值的项目须披露减值金额及原因。
6. **附注与审定表勾稽**：附注其他非流动资产期末余额须等于I5-1审定数，各项目与I5-2明细表勾稽。

---

## checklist

### 一、构成与变动披露

- [ ] 是否按项目性质分类披露构成（避免笼统列示）
- [ ] 变动情况（期初/增加/减少/期末）是否披露
- [ ] 各项目期末余额合计是否等于I5-1审定数
- [ ] 各项目是否与I5-2明细表勾稽
- [ ] 是否同时列示期末数和期初数

### 二、重大项目与长期性

- [ ] 金额重大/性质特殊项目是否说明性质、形成原因
- [ ] 预付长期购置款/工程款的预计转出安排是否说明
- [ ] 各项目长期性（一年以上）依据是否说明
- [ ] 是否存在应归入具体科目却笼统披露为其他非流动资产

### 三、减值信息

- [ ] 存在减值的项目是否披露减值金额及原因
- [ ] 长期挂账无进展项目是否说明
- [ ] 附注披露分类是否与审定表、明细表一致

## risk_areas

### 高风险

1. **变动表不勾稽**：变动勾稽不成立或与审定表/明细表不一致。
2. **笼统披露掩盖性质**：其他非流动资产笼统列示未披露构成，掩盖资产性质和风险。
3. **减值信息缺失**：存在减值项目未披露。

### 中风险

1. **重大项目未说明**：金额重大项目未说明性质和形成原因。
2. **长期性依据缺失**：未说明长期性判断依据。
3. **可比信息缺失**。

### 低风险

1. **披露格式不完全规范**。
2. **项目说明模板化**。
3. **数字精度不一致**。
