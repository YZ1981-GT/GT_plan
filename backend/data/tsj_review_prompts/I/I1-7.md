# I1-7 无形资产使用寿命检查复核提示词

## 概述

本提示词针对无形资产使用寿命检查底稿（I1-7）的复核，聚焦有限使用寿命与不确定使用寿命的判断依据、使用寿命年限的合理性、年度复核的执行及使用寿命重估的会计处理。使用寿命判断直接决定是否摊销及摊销速度，是无形资产计量的核心估计。

**法规依据：**
- 《企业会计准则第6号——无形资产》
- 《企业会计准则第28号——会计政策、会计估计变更和差错更正》

---

## tips

1. **有限vs不确定判断须有充分依据**：能预见带来经济利益期限的为有限使用寿命；无法预见的为不确定使用寿命。判断须综合合同/法律期限、技术更新、行业惯例等因素。
2. **不确定使用寿命的严格条件**：只有当无法合理估计带来经济利益期限时才判定为不确定，实务中较少见，滥用将规避摊销。
3. **使用寿命年限依据**：源自法律/合同的取较短者；源自续约的须有证据支持续约不需重大成本；技术性无形资产须考虑技术更新速度。
4. **每年复核使用寿命**：年末须复核使用寿命及摊销方法，如与原估计不同应作为会计估计变更（未来适用）。
5. **不确定寿命的年度重估**：使用寿命不确定的无形资产每年须复核是否仍为不确定，若变为有限须开始摊销。
6. **勾稽摊销测算与政策检查**：使用寿命是I1-10/I1-11摊销测算的关键参数，须与I1-4政策检查一致。

## checklist

### 一、使用寿命判断依据

- [ ] 每项无形资产的有限/不确定判断是否有书面依据
- [ ] 有限使用寿命年限确定是否综合考虑合同期、法律期、技术更新
- [ ] 使用寿命不确定的判断是否符合准则严格条件
- [ ] 存在续约条款的是否有续约不需重大成本的证据支持
- [ ] 判断依据是否与行业惯例和企业实际使用情况相符

### 二、年限合理性

- [ ] 土地使用权使用寿命是否按证载剩余年限
- [ ] 专利权/非专利技术使用寿命是否考虑技术更新与法定保护期
- [ ] 商标权使用寿命判断是否合理（可续展是否作为不确定寿命依据）
- [ ] 软件使用寿命是否考虑技术迭代速度
- [ ] 使用寿命年限是否与I1-4政策、I1-10摊销测算一致

### 三、年度复核与重估

- [ ] 是否执行了年末使用寿命及摊销方法复核
- [ ] 使用寿命重估是否作为会计估计变更（未来适用）处理
- [ ] 不确定使用寿命项目是否每年复核是否仍不确定
- [ ] 由不确定变为有限的项目是否开始摊销且处理正确
- [ ] 重估过程与结论是否充分留痕

## risk_areas

### 高风险

1. **滥用不确定使用寿命规避摊销**：将实际有限寿命的无形资产判定为不确定寿命以不摊销，虚增资产虚增利润。
2. **使用寿命过长虚减摊销**：使用寿命年限明显超过合理估计（如软件按20年摊销），系统性虚减摊销费用。
3. **不确定寿命项目未年度减值测试**：判定为不确定寿命却未执行强制年度减值测试。

### 中风险

1. **使用寿命重估处理错误**：重估未作为会计估计变更处理，或追溯调整前期。
2. **续约假设无依据**：以可续约为由延长使用寿命但缺乏续约不需重大成本的证据。
3. **年度复核未执行**：未在年末复核使用寿命，估计与实际脱节。

### 低风险

1. **判断依据文档不充分**：使用寿命判断过程记录简略。
2. **与政策/摊销测算年限微小不一致**。
3. **复核记录格式不规范**。
