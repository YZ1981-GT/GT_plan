# I2-5 开发支出实质性分析复核提示词

## 概述

本提示词针对开发支出实质性分析底稿（I2-5）的复核，聚焦研发投入总额及资本化率的趋势分析、资本化率与同行业对比、开发支出与研发产出（无形资产结转）的匹配性分析及异常波动的解释。实质性分析程序通过比率和趋势识别开发支出的异常，为进一步审计提供方向。

**法规依据：**
- 《企业会计准则第6号——无形资产》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **资本化率是核心分析指标**：资本化率=资本化研发投入÷研发投入总额，异常高的资本化率（尤其突增）是过度资本化的信号。
2. **趋势分析**：开发支出余额、本期资本化投入、资本化率的年度趋势须与研发活动实际、经营战略一致。
3. **同行业对比**：资本化率与同行业上市公司对比，明显偏高须查明原因。
4. **投入产出匹配**：资本化开发支出与后续结转无形资产、形成产品收入的匹配性分析，长期只投入不产出须警惕。
5. **异常波动解释**：开发支出或资本化率的重大波动（超阈值）须有合理解释并追溯至具体项目。
6. **勾稽费用化研发**：资本化开发支出与费用化研发费用（I6）的比例结构分析，异常结构须解释。

---

## checklist

### 一、比率与趋势分析

- [ ] 是否计算并分析资本化率（资本化投入÷研发投入总额）
- [ ] 资本化率年度趋势是否与研发活动实际一致
- [ ] 开发支出余额趋势是否合理
- [ ] 资本化率是否与同行业水平对比

### 二、投入产出匹配

- [ ] 资本化开发支出与后续结转无形资产是否匹配
- [ ] 是否存在长期只投入不产出的项目
- [ ] 资本化开发支出与形成产品收入的匹配性是否分析
- [ ] 资本化与费用化研发的比例结构是否合理（勾稽I6）

### 三、异常波动分析

- [ ] 开发支出或资本化率重大波动是否有合理解释
- [ ] 异常波动是否追溯至具体项目
- [ ] 分析发现的异常是否实施了进一步审计程序
- [ ] 分析结论是否与其他底稿（I2-6/I2-7）勾稽

## risk_areas

### 高风险

1. **资本化率异常高未查明**：资本化率明显高于历史和同行但未查明原因，可能过度资本化。
2. **长期只投入不产出**：资本化项目长期无结转无产出但未减值，虚增资产。

### 中风险

1. **趋势异常未解释**：开发支出或资本化率重大波动缺乏合理解释。
2. **投入产出严重不匹配**：资本化投入与产品收入长期背离。
3. **同行业对比缺失**：未与同行业对比评估资本化率合理性。

### 低风险

1. **分析指标单一**：仅分析余额未分析比率结构。
2. **分析深度不足**：异常识别后未追溯至项目。
3. **分析结论与其他底稿勾稽索引缺失**。
