# I5-4 其他非流动资产针对性检查复核提示词

## 概述

本提示词针对其他非流动资产针对性检查底稿（I5-4）的复核，聚焦针对识别风险实施的专项程序：重大项目真实性核查、预付长期购置款的合同与进度核查、性质归集恰当性的复核及减值风险评估。其他非流动资产因"其他"性质，是不当归集和减值风险掩盖的高风险领域，针对性检查是关键。

**法规依据：**
- 《企业会计准则第30号——财务报表列报》
- 《中国注册会计师审计准则第1314号——审计抽样》

---

## tips

1. **重大项目真实性**：金额重大项目须核查支出真实性、原始凭证、合同及资产/权利归属。
2. **预付款进度核查**：预付长期购置款/工程款须核查合同履行进度、供应商资信，长期无进展须评估违约风险。
3. **性质归集复核**：核查是否存在应归入具体资产科目却计入其他非流动资产的项目（掩盖减值/性质）。
4. **减值风险评估**：核查是否存在减值迹象（工程停滞、供应商违约、项目取消）未评估减值。
5. **关注期末突增及关联方**：期末突增项目、向关联方预付的长期款项须核查动机和公允性。
6. **勾稽核心底稿**：针对性检查结论须与I5-2明细表、I5-3调整勾稽。

---

## checklist

### 一、真实性核查

- [ ] 重大项目是否核查支出真实性和原始凭证
- [ ] 预付长期购置款/工程款是否核查合同及进度
- [ ] 资产/权利归属是否明确
- [ ] 期末突增项目是否核查合理性

### 二、性质与减值

- [ ] 是否核查应归入具体资产科目却计入其他非流动资产的项目
- [ ] 是否存在减值迹象（工程停滞/供应商违约/项目取消）
- [ ] 存在减值迹象项目是否评估减值
- [ ] 长期无进展预付款违约风险是否评估

### 三、关联方与勾稽

- [ ] 向关联方预付的长期款项是否核查公允性
- [ ] 关联方长期资金占用是否以其他非流动资产名义挂账
- [ ] 针对性检查结论是否与I5-2明细表勾稽
- [ ] 应重分类/减值项目是否与I5-3调整勾稽

## risk_areas

### 高风险

1. **不当归集掩盖减值未识别**：应减值项目计入其他非流动资产规避减值未被查出。
2. **关联方资金占用挂账**：关联方长期资金占用以其他非流动资产名义挂账未识别。
3. **预付款违约风险未评估**：长期无进展预付款供应商违约风险未评估减值。

### 中风险

1. **重大项目核查深度不足**。
2. **性质归集复核缺失**：未核查性质归集恰当性。
3. **期末突增未追查**。

### 低风险

1. **检查记录不完整**。
2. **针对性程序与风险评估勾稽索引缺失**。
3. **检查结论表述不清晰**。
