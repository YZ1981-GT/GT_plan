# I1-5 无形资产增加检查复核提示词

## 概述

本提示词针对无形资产本期增加检查底稿（I1-5）的复核，聚焦本期新增无形资产的取得成本准确性、取得方式合规性、资本化时点恰当性及原始凭证完整性。增加检查覆盖外购、内部研发形成、投资者投入、非货币性资产交换、企业合并、债务重组等取得方式，取得成本的准确计量是无形资产账面价值可靠的起点。

**法规依据：**
- 《企业会计准则第6号——无形资产》
- 《中国注册会计师审计准则第1314号——审计抽样》

---

## tips

1. **取得成本按取得方式确定**：外购按购买价款加相关税费加达到预定用途前的支出；内部研发形成按开发阶段符合资本化条件的支出；投资者投入按合同约定价值（公允）。
2. **资本化时点须恰当**：达到预定用途前的必要支出计入成本，之后的支出费用化；内部研发资本化时点须满足CAS6五条件（勾稽I2开发支出）。
3. **凭证核对覆盖完整链条**：合同/协议→付款凭证→权属证书/验收单→入账凭证，逐项核对金额与时点一致性。
4. **内部研发形成须与I2勾稽**：由开发支出结转形成的无形资产原值须等于I2开发支出资本化累计金额，不得包含研究阶段费用。
5. **关注大额及关联方取得**：大额无形资产取得、向关联方购买无形资产须重点核查交易实质和定价公允性。
6. **样本选取匹配风险**：金额重大项目全覆盖，其余按CAS1314合理抽样，新增大额与关联方取得纳入必选样本。

## checklist

### 一、取得成本准确性

- [ ] 外购无形资产成本是否包含购买价款、相关税费及达到预定用途前的支出
- [ ] 内部研发形成的无形资产原值是否等于I2开发支出资本化累计金额
- [ ] 投资者投入的无形资产是否按合同约定价值（公允）入账
- [ ] 非货币性资产交换/债务重组取得的无形资产计量是否符合准则
- [ ] 企业合并取得的无形资产是否按购买日公允价值单独确认（勾稽I3商誉）

### 二、资本化时点与范围

- [ ] 达到预定用途前的支出是否计入成本，之后支出是否费用化
- [ ] 内部研发资本化时点是否满足CAS6五条件（勾稽I2-6资本化判断）
- [ ] 是否将不符合资本化条件的研究阶段支出误计入无形资产
- [ ] 培训费、管理费用等不应资本化的支出是否已排除

### 三、凭证核对与权属

- [ ] 合同/协议、付款凭证、权属证书、验收单是否齐全
- [ ] 凭证金额与入账金额是否一致
- [ ] 取得时点与入账时点是否一致，是否存在跨期
- [ ] 权属是否已办理转移登记（土地使用权证/专利证书/商标注册证）
- [ ] 关联方取得的定价公允性是否有证据支持

## risk_areas

### 高风险

1. **取得成本虚增**：将不应资本化的支出（培训、管理费、研究阶段支出）计入无形资产成本，虚增资产虚减费用。
2. **虚构无形资产取得**：无真实交易或无经济利益的"无形资产"入账，虚增资产。
3. **内部研发资本化过度**：不符合CAS6五条件的开发支出结转为无形资产（勾稽I2-6）。
4. **关联方高买无形资产**：向关联方以显失公允高价购买无形资产，输送利益。

### 中风险

1. **资本化时点错误**：达到预定用途后的支出继续资本化，或跨期入账。
2. **权属未转移即入账**：权属登记未完成即确认无形资产，存在权利不完整风险。
3. **凭证不齐全**：缺少合同、付款凭证或权属证书，取得成本证据不充分。

### 低风险

1. **抽样参数记录不完整**：样本选取过程、检查比例记录不完整。
2. **凭证核对结果格式不规范**。
3. **交叉索引缺失**（未链接I2开发支出、I3商誉）。
