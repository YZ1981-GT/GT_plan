# I1-1 无形资产审定表复核提示词

## 概述

本提示词针对无形资产审定表（I1-1）的复核，聚焦无形资产（土地使用权/专利权/商标权/软件/内部研发形成）的取得成本、累计摊销、减值准备、账面价值的期初期末勾稽与试算平衡表核对。审定表承载未审数→账项调整→重分类调整→审定数的完整链路，无形资产因涉及使用寿命判断和减值测试，其审定数的可靠性直接影响非流动资产列报和当期损益。

**法规依据：**
- 《企业会计准则第6号——无形资产》
- 《企业会计准则第8号——资产减值》
- 《中国注册会计师审计准则第1301号——审计证据》

## tips

1. **三栏勾稽是无形资产审定表的核心**：账面价值=原值−累计摊销−减值准备，三者的期初期末必须分别勾稽，任一栏断裂均导致账面价值失真。
2. **期初审定数必须承前**：期初原值/累计摊销/减值准备须等于上年审定表期末审定数，差异应追溯至会计政策变更或前期差错更正。
3. **试算平衡表核对是第一道防线**：审定表原值合计须与试算平衡表1701科目、累计摊销须与1702科目、减值准备须与1703科目审定数一致。
4. **审计调整须完整反映**：本期计提摊销、减值损失、处置转出等已确认调整（AJE/RJE）须逐笔纳入审定表，遗漏将导致审定数与明细表不勾稽。
5. **使用寿命不确定的无形资产不摊销但须减值测试**：审定表须区分有限寿命（摊销）与不确定寿命（不摊销、每年减值测试）项目，误将不确定寿命项目摊销属计量错误。
6. **关注原值突增或减值突增的行项目**：新增大额无形资产（尤其内部研发形成）及本期大额减值，须追溯至I1-5增加检查、I1-12减值测试，评估其合理性。

## checklist

### 一、期初期末勾稽

- [ ] 审定表期初原值/累计摊销/减值准备是否等于上年审定表期末审定数（承前）
- [ ] 期末原值是否等于期初原值加本期增加减本期减少（勾稽I1-5/I1-6）
- [ ] 期末累计摊销是否等于期初加本期计提减处置转出（勾稽I1-10/I1-11摊销测算）
- [ ] 期末减值准备是否等于期初加本期计提减处置转出（勾稽I1-12减值测试）
- [ ] 账面价值是否等于原值减累计摊销减减值准备
- [ ] 各行项目期初期末变动是否与I1-2明细表增减变动一致

### 二、试算平衡表核对

- [ ] 审定表原值合计是否与试算平衡表1701无形资产审定数一致
- [ ] 审定表累计摊销是否与试算平衡表1702累计摊销审定数一致（贷方）
- [ ] 审定表减值准备是否与试算平衡表1703无形资产减值准备审定数一致（贷方）
- [ ] 试算平衡表未审数、调整数（AJE+RJE）与审定表对应列是否一致
- [ ] 是否存在试算平衡表已更新但审定表未同步的情况

### 三、审计调整完整性

- [ ] 本期摊销、减值损失、处置转出等账项调整（AJE）是否完整反映
- [ ] 重分类调整（RJE，如土地使用权与投资性房地产互转）是否完整反映
- [ ] 调整分录借贷方是否平衡，审定数是否等于未审数加AJE加RJE
- [ ] 是否存在I1-3已编制但未纳入审定表的调整
- [ ] 建议未调整的错报是否记录于未调整错报汇总（勾稽A13）

### 四、分类与计量准确性

- [ ] 是否区分有限使用寿命（摊销）与不确定使用寿命（不摊销）项目
- [ ] 一年内到期的分期支付无形资产款项是否正确列报
- [ ] 土地使用权是否与房屋建筑物、投资性房地产正确划分
- [ ] 内部研发形成的无形资产与外购无形资产是否分别列示
- [ ] 审定表分类是否与附注披露分类一致

## risk_areas

### 高风险

1. **期初期末不勾稽**：期初审定数与上年期末审定数不一致，可能存在未授权调整或数据录入错误，导致本期审定基准失真。
2. **不确定使用寿命项目被摊销**：将本应每年减值测试的不确定寿命无形资产按有限寿命摊销，属计量错误，虚减资产虚增费用。
3. **减值调整遗漏**：I1-12已测算的减值损失未纳入审定表，导致无形资产虚增、资产减值损失少计。
4. **试算平衡表与审定表不一致**：原值/累计摊销/减值准备任一科目口径不一致，意味着存在未发现的汇总错误或调整遗漏。
5. **内部研发形成无形资产原值虚增**：将不符合资本化条件的研究阶段支出计入无形资产原值，虚增资产（勾稽I2开发支出）。

### 中风险

1. **明细与汇总不勾稽**：审定表各行合计与I1-2明细表总计不一致，可能存在明细遗漏或重复。
2. **摊销与减值方向错误**：累计摊销、减值准备为备抵科目应为贷方，审定表列示方向颠倒导致账面价值计算错误。
3. **土地使用权分类错误**：自用土地使用权与投资性房地产、房屋建筑物之间划分错误，影响列报和折旧/摊销处理。
4. **重分类调整方向颠倒**：一年内到期部分重分类方向错误，或RJE多笔冲抵不完全。

### 低风险

1. **审定表格式不规范**：列标题、行顺序、编号等不影响数据准确性但影响可读性。
2. **交叉索引不完整**：未与I1-2明细表、I1-10摊销测算、I1-12减值测试建立完整索引。
3. **变动说明不充分**：变动较大的行项目未附简要说明，增加复核理解难度。
