# I5-1 其他非流动资产审定表复核提示词

## 概述

本提示词针对其他非流动资产审定表（I5-1）的复核，聚焦其他非流动资产（预付长期资产购置款、预付长期工程款、待摊/待处理长期项目等不宜归入其他非流动资产明细科目的项目）的期初期末勾稽、试算平衡表1911科目核对、长期性判断的恰当性及分类列报准确性。其他非流动资产是"其他"性质的归集科目，须警惕不当归集掩盖资产性质。

**法规依据：**
- 《企业会计准则第30号——财务报表列报》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **滚动勾稽**：期末余额=期初余额+本期增加−本期减少（转出/结转），各环节须逐项勾稽。
2. **期初承前**：期初审定数须等于上年审定表期末审定数。
3. **试算平衡表核对**：审定表其他非流动资产合计须与试算平衡表1911科目审定数一致。
4. **长期性判断**：其他非流动资产须为预计变现或耗用期在一年以上的项目，一年内的应重分类至流动资产。
5. **性质归集恰当**：能归入具体资产科目（固定资产/无形资产/长期股权投资等）的不应计入其他非流动资产，"其他"科目须警惕掩盖资产性质或减值风险。
6. **关注预付长期购置款**：预付的长期资产购置款/工程款须核查合同、进度，长期挂账未转资产的须评估。

## checklist

### 一、期初期末勾稽

- [ ] 期初审定数是否等于上年审定表期末审定数（承前）
- [ ] 期末余额=期初+本期增加−本期减少 是否成立
- [ ] 本期增加/减少是否与I5-2明细表一致
- [ ] 各项目期初期末变动是否与明细表一致

### 二、试算平衡表核对

- [ ] 审定表其他非流动资产合计是否与试算平衡表1911科目审定数一致
- [ ] 试算平衡表未审数、调整数与审定表对应列是否一致
- [ ] 是否存在试算平衡表已更新但审定表未同步的情况

### 三、审计调整完整性

- [ ] 转出/结转/减值等账项调整（AJE）是否完整反映
- [ ] 重分类调整（RJE，如一年内到期部分/性质重分类）是否完整反映
- [ ] 调整分录借贷平衡，审定数=未审数+AJE+RJE是否成立
- [ ] 是否存在I5-3已编制但未纳入审定表的调整

### 四、长期性与分类

- [ ] 各项目变现/耗用期是否均在一年以上
- [ ] 一年内到期项目是否重分类至流动资产
- [ ] 能归入具体资产科目的项目是否未不当计入其他非流动资产
- [ ] 预付长期购置款是否核查合同及进度
- [ ] 审定表分类是否与附注披露一致

## risk_areas

### 高风险

1. **期初期末不勾稽**：期初与上年期末不一致或滚动公式不成立。
2. **不当归集掩盖性质**：将本应归入具体资产科目或应减值的项目计入"其他非流动资产"，掩盖资产性质和减值风险。
3. **长期挂账预付款未评估**：预付长期购置款长期未转资产、供应商违约风险未评估。
4. **试算平衡表与审定表不一致**：1911科目口径不一致。

### 中风险

1. **明细与汇总不勾稽**：审定表合计与I5-2明细表不一致。
2. **长期性判断错误**：一年内到期项目仍列非流动。
3. **减值遗漏**：存在减值迹象的项目未评估减值。

### 低风险

1. **审定表格式不规范**。
2. **交叉索引不完整**。
3. **变动说明不充分**。
