# I1-note-soe 无形资产附注披露复核提示词（国有企业）

## 概述

本提示词针对无形资产国有企业附注披露底稿（I1-note-soe）的复核，聚焦无形资产分类与变动披露（与上市版共有）及国有企业特定披露要求：土地使用权（国有划拨/出让）来源、国有资产权属完整性、无形资产减值对国有资本保值增值的影响、财务决算报表口径一致性。国企审计兼具财务审计与国有资产监管属性。

**法规依据：**
- 《企业会计准则第6号——无形资产》
- 《企业会计准则第8号——资产减值》
- 《企业会计准则第30号——财务报表列报》
- 《中央企业财务决算报告管理办法》

## tips

1. **国企附注双层披露**：既满足CAS6/CAS8通用披露，又满足国资委财务决算报告额外要求，两者互补不可替代。
2. **土地使用权来源须区分**：区分国有划拨（无偿取得）与出让（有偿取得），划拨土地使用权处置须经批准，来源和处置限制须披露。
3. **国有资产权属完整性**：无形资产（尤其土地使用权、特许经营权）权属须完整清晰，权属瑕疵可能被视为国有资产管理不到位。
4. **减值影响国有资本保值增值**：无形资产大额减值须说明对国有资本保值增值率的影响。
5. **权属受限与对外担保**：以无形资产（土地使用权）对外抵押担保须披露，涉及国有资产处置须符合审批程序。
6. **决算报表口径一致**：无形资产数据须与年度财务决算报表一致，纳入国有资产经营考核。

## checklist

### 一、基础披露完整性（与上市版共有）

- [ ] 无形资产是否按类别披露（土地使用权/专利/商标/软件/其他）
- [ ] 变动表是否完整列示原值/累计摊销/减值准备三层滚动
- [ ] 附注账面价值是否与I1-1审定数一致
- [ ] 各类别合计是否与I1-2明细表勾稽
- [ ] 期初期末可比信息是否完整

### 二、土地使用权与国有资产权属

- [ ] 土地使用权是否区分国有划拨与出让来源
- [ ] 划拨土地使用权的处置限制是否披露
- [ ] 无形资产权属（尤其土地/特许经营权）是否完整清晰
- [ ] 权属存在瑕疵或未办妥的无形资产是否披露
- [ ] 特许经营权/采矿权等特殊无形资产的取得依据是否披露

### 三、减值与国有资本影响

- [ ] 本期计提减值准备的金额、原因是否披露
- [ ] 大额减值对国有资本保值增值率的影响是否说明
- [ ] 可收回金额确定方法是否披露（勾稽I1-12/I1-13）
- [ ] 长期闲置或计划处置的无形资产是否说明处置计划

### 四、权属受限、决算与差异

- [ ] 以无形资产对外抵押/担保是否披露且符合审批程序
- [ ] 无形资产数据是否与年度财务决算报表一致
- [ ] 决算报表与审计报表口径差异是否编制调节说明
- [ ] 无形资产减值损失是否纳入国有资产经营考核披露
- [ ] 与上市版相比是否补充了国资监管层面信息

## risk_areas

### 高风险

1. **变动表不勾稽或与审定表不一致**：三层滚动勾稽不成立或与审定表数据不一致。
2. **土地使用权来源及处置限制未披露**：划拨土地未说明处置限制，可能掩盖国有资产处置违规。
3. **国有资产权属瑕疵未披露**：无形资产权属不清未披露，涉及国有资产管理责任。
4. **减值对国有资本影响未说明**：大额减值未说明对保值增值的影响。

### 中风险

1. **对外担保未披露或未审批**：以无形资产对外担保未披露或未符合审批程序。
2. **决算与审计口径差异未调节**：无形资产数据两口径不一致未说明。
3. **特殊无形资产取得依据不充分**：特许经营权/采矿权取得依据披露不足。

### 低风险

1. **披露格式未完全按决算模板**。
2. **土地使用权来源说明简略**。
3. **历史趋势分析不完整**。
