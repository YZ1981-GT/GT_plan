# I3-5 商誉针对性检查表复核提示词

## 概述

本提示词针对商誉针对性检查表（I3-5）的复核，聚焦针对商誉重大错报风险实施的专项程序：合并交易真实性核查、业绩承诺及补偿的核查、商誉减值迹象的针对性评估及资产组认定合理性。商誉是财务报表舞弊和减值调节的高风险领域，针对性检查是关键审计程序。

**法规依据：**
- 《企业会计准则第20号——企业合并》
- 《企业会计准则第8号——资产减值》
- 《中国注册会计师审计准则第1314号——审计抽样》

---

## tips

1. **业绩承诺及补偿核查**：并购标的的业绩承诺完成情况须核查，未完成承诺是商誉减值的强信号；业绩补偿的会计处理须正确。
2. **合并交易真实性**：核查合并交易的商业实质、对价支付、被购买方控制权转移，警惕虚假并购。
3. **减值迹象针对性评估**：标的业绩未达预期、行业景气度下降、核心团队流失、协同效应未实现等均为商誉减值迹象。
4. **资产组认定合理性**：商誉所属资产组的认定须合理，不当扩大资产组范围可能"稀释"商誉减值。
5. **关注商誉占比高的合并**：商誉占合并成本比例畸高、或占净资产比例畸高的并购须重点核查。
6. **业绩承诺期后减值风险**：业绩承诺期结束后商誉减值风险陡增（失去业绩保障），须重点关注。

## checklist

### 一、业绩承诺核查

- [ ] 并购标的是否存在业绩承诺，完成情况是否核查
- [ ] 未完成业绩承诺是否评估商誉减值
- [ ] 业绩补偿的会计处理是否正确
- [ ] 业绩承诺期是否结束，期后减值风险是否评估

### 二、合并交易与商誉真实性

- [ ] 合并交易的商业实质是否核查
- [ ] 对价支付、控制权转移是否有证据
- [ ] 商誉占合并成本/净资产比例是否合理
- [ ] 是否存在虚假并购虚增商誉

### 三、减值迹象与资产组

- [ ] 标的业绩、行业景气度、核心团队变化等减值迹象是否评估
- [ ] 协同效应是否实现
- [ ] 商誉所属资产组认定是否合理（未不当扩大范围）
- [ ] 针对性检查结论是否与I3-6减值测试勾稽

## risk_areas

### 高风险

1. **业绩未达承诺未减值**：并购标的业绩未达承诺仍不计提商誉减值，虚增资产。
2. **资产组不当扩大稀释减值**：将商誉分摊至更大资产组，用其他资产盈利"稀释"商誉减值。
3. **虚假并购虚增商誉**：无商业实质的并购虚增商誉。
4. **业绩承诺期后集中暴雷**：承诺期结束后商誉减值风险未提前评估。

### 中风险

1. **业绩补偿处理错误**：业绩补偿会计处理不当。
2. **减值迹象评估不充分**：明显减值迹象（团队流失/景气下降）未评估。
3. **协同效应未实现未关注**。

### 低风险

1. **针对性检查记录不完整**。
2. **业绩承诺核查依据不充分**。
3. **与减值测试勾稽索引缺失**。
