# I2-8 研发材料投入检查复核提示词

## 概述

本提示词针对研发材料投入检查底稿（I2-8）的复核，聚焦资本化研发材料投入的真实性、领用与研发项目的关联性、材料成本计价的准确性及领用凭证的完整性。研发材料投入是开发支出资本化构成的重要部分，虚增材料投入是虚增资本化金额的常见手段。

**法规依据：**
- 《企业会计准则第6号——无形资产》
- 《中国注册会计师审计准则第1314号——审计抽样》

---

## tips

1. **材料领用须与项目关联**：资本化的研发材料须凭领料单明确用于特定开发项目，与生产领用严格区分。
2. **领用凭证完整**：领料单→研发项目→计价（加权平均/先进先出）→入账，凭证链完整可追溯。
3. **计价准确**：研发领用材料计价方法须与存货核算一致，计价错误影响资本化金额（勾稽F存货循环）。
4. **关注领用异常**：研发领用材料数量与项目规模不匹配、期末集中大额领用、领用后无对应产出须核查。
5. **区分资本化与费用化领用**：仅开发阶段（满足条件后）领用材料可资本化，研究阶段领用应费用化。
6. **样本覆盖大额及异常**：大额领用、期末领用、关联方供应材料纳入必选样本，其余按CAS1314抽样。

## checklist

### 一、材料投入真实性与关联性

- [ ] 资本化研发材料是否凭领料单明确用于特定开发项目
- [ ] 研发领用与生产领用是否严格区分
- [ ] 领用材料数量是否与研发项目规模匹配
- [ ] 是否存在领用后无对应研发活动或产出的情况

### 二、计价与凭证

- [ ] 研发领用材料计价方法是否与存货核算一致
- [ ] 领料单、计价记录、入账凭证是否齐全
- [ ] 材料成本金额是否与存货循环（F）勾稽
- [ ] 领用时点与入账时点是否一致

### 三、资本化范围

- [ ] 是否仅将满足条件后开发阶段领用材料资本化
- [ ] 研究阶段领用材料是否费用化
- [ ] 资本化材料投入是否与I2-7项目构成勾稽
- [ ] 期末集中大额领用是否核查合理性

## risk_areas

### 高风险

1. **虚增材料投入**：无真实领用或超实际需要领用材料资本化，虚增开发支出。
2. **生产领用混入研发**：将生产用材料计入研发资本化，虚增资产虚减成本。
3. **研究阶段领用资本化**：满足条件前领用材料资本化。

### 中风险

1. **计价错误**：研发领用材料计价与存货核算不一致。
2. **领用与项目不匹配**：领用数量与项目规模明显不符未核查。
3. **凭证不齐全**：缺领料单或计价记录。

### 低风险

1. **抽样参数记录不完整**。
2. **领用凭证核对结果格式不规范**。
3. **与存货循环勾稽索引缺失**。
