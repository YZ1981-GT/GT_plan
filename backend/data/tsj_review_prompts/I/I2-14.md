# I2-14 开发支出截止性测试（单据到账）复核提示词

## 概述

本提示词针对开发支出截止性测试（由原始单据到账面记录，单→账）底稿（I2-14）的复核，聚焦资产负债表日前后原始单据（领料单/工时/委外验收）对应支出是否完整、正确入账，从单据追查至账面记录，验证是否存在应资本化未资本化或跨期遗漏。与I2-13（账→单）互补，共同保证开发支出资本化的期间完整性。

**法规依据：**
- 《企业会计准则第6号——无形资产》
- 《中国注册会计师审计准则第1314号——审计抽样》

---

## tips

1. **单据到账方向**：从原始单据（领料单/工时/委外验收）出发，追查至账面资本化记录，验证支出是否完整入账、期间是否正确。
2. **完整性导向**：本测试重在发现已发生但遗漏入账或延迟入账的开发支出（应资本化未资本化）。
3. **测试窗口覆盖跨期**：选取资产负债表日前后一定天数的原始单据测试。
4. **区分资本化与费用化**：单据对应支出须结合资本化时点判断确定应资本化还是费用化，不得将应费用化支出通过截止测试转资本化。
5. **关注期后单据**：期后发生但属本期的开发支出单据须评估是否应在本期资本化。
6. **与I2-13互补**：I2-14（单→账）验证完整性，I2-13（账→单）验证发生性/期间，两者互补覆盖截止双向风险。

---

## checklist

### 一、测试设计

- [ ] 测试窗口是否覆盖资产负债表日前后合理天数
- [ ] 样本是否从完整的原始单据总体选取
- [ ] 样本选取是否与风险评估匹配

### 二、单据到账核查

- [ ] 原始单据对应支出是否完整入账
- [ ] 单据期间与入账期间是否一致
- [ ] 是否存在已发生但遗漏/延迟入账的开发支出
- [ ] 单据对应支出应资本化还是费用化是否结合条件判断

### 三、结果处理

- [ ] 发现的遗漏/延迟入账是否评估调整
- [ ] 是否存在将应费用化支出转资本化的情况
- [ ] 跨期金额是否与I2-3调整分录勾稽
- [ ] 截止测试结论是否与审定表勾稽

---

## risk_areas

### 高风险

1. **应资本化支出遗漏**：已发生的资本化开发支出遗漏入账，低估资产（较少见但影响完整性）。
2. **应费用化转资本化**：通过截止测试将应费用化的期后支出转资本化，虚增资产。

### 中风险

1. **测试窗口不足**：窗口天数过短未覆盖跨期。
2. **单据总体不完整**：未从完整单据总体选取样本。
3. **跨期金额未评估调整**。

### 低风险

1. **样本选取记录不完整**。
2. **截止测试记录格式不规范**。
3. **与调整分录勾稽索引缺失**。
