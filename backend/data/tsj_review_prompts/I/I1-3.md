# I1-3 无形资产调整分录复核提示词

## 概述

本提示词针对无形资产调整分录汇总表（I1-3）的复核，含账项调整（AJE）、重分类调整（RJE）及未调整错报评估。复核须验证：每笔调整有充分证据、借贷平衡、完整反映到I1-1审定表、并与试算平衡表1701/1702/1703科目形成闭环。

**法规依据：**
- 《企业会计准则第6号——无形资产》
- 《企业会计准则第28号——会计政策、会计估计变更和差错更正》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **AJE 与 RJE 区分**：AJE 影响无形资产账面价值或损益（如补提摊销、计提减值）；RJE 仅影响列报（如土地使用权与投资性房地产重分类、一年内到期部分重分类）。
2. **与 I1-1 勾稽**：审定表调整列金额须与 I1-3 已确认分录逐笔一致，遗漏任一笔即审定数失真。
3. **摊销/减值调整须有测算支持**：补提或冲回摊销须勾稽 I1-10/I1-11，减值调整须勾稽 I1-12，不得无依据调整。
4. **区分本期错报与前期差错**：使用寿命重估、摊销方法变更属会计估计变更（未来适用）；前期漏提摊销属前期差错（追溯重述），会计处理和披露不同。
5. **审批链留痕**：超过明细层次重要性水平的调整须经合伙人/项目经理审批。
6. **TB 回写**：确认调整已同步试算平衡表，避免"底稿已调、TB 未更"双真源。

## checklist

### 一、调整证据与审批

- [ ] 所有 AJE 是否有充分审计证据（摊销测算、减值测试、权属核查等）
- [ ] 减值调整是否有 I1-12 可收回金额测试支持
- [ ] 摊销补提/冲回是否有 I1-10/I1-11 测算支持
- [ ] 超过重要性水平的调整是否经适当层级审批留痕
- [ ] 每笔调整分录借贷方是否完全平衡

### 二、与审定表及 TB 勾稽

- [ ] 调整金额是否完整反映到 I1-1 审定表对应调整列
- [ ] 审定数是否等于未审数+AJE调整+RJE调整
- [ ] 调整后无形资产净额是否回写试算平衡表 1701/1702/1703 科目
- [ ] 是否存在 I1-3 已编制但未纳入审定表的调整
- [ ] 未调整错报是否已记录并与 A13 未调整错报汇总交叉验证

### 三、调整性质与列报

- [ ] RJE 是否仅涉及列报（重分类），未误含损益影响
- [ ] 使用寿命/摊销方法变更是否作为会计估计变更（未来适用）处理
- [ ] 前期漏提摊销/减值是否作为前期差错（追溯重述）处理
- [ ] 一年内到期的分期支付款项重分类是否正确
- [ ] 调整原因说明是否清晰可追溯至具体审计程序

## risk_areas

### 高风险

1. **调整缺乏证据或未经授权**：减值、摊销调整无测算支持或越权审批，导致审定数失真。
2. **审定表与 I1-3 调整金额不一致**：调整遗漏或错录导致审定表与调整汇总长期不勾稽。
3. **会计估计变更与前期差错混淆**：将前期漏提摊销作为本期费用处理（而非追溯重述），掩盖前期错报。

### 中风险

1. **RJE 误含损益影响**：本应仅重分类的调整影响了损益类科目。
2. **减值调整方向错误**：计提减值应贷记减值准备，方向颠倒导致账面价值错误。
3. **未调整错报累计超阈值未处理**：单项未超但累计后可能超过整体重要性水平。

### 低风险

1. **分录摘要、科目编码不规范**。
2. **索引指向支持底稿不完整**（未链接 I1-12/I1-10）。
3. **审计说明未概括调整性质与残余风险**。

## 跨底稿勾稽

- I1-3 已确认 AJE/RJE 合计 ↔ I1-1 审定表调整列
- I1-3 减值调整 ↔ I1-12 可收回金额测试
- I1-3 摊销调整 ↔ I1-10/I1-11 摊销测算
- I1-3 SUD ↔ A13 未调整错报汇总
- 调整后审定数 ↔ 试算平衡表 1701/1702/1703
