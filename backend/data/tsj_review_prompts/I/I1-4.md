# I1-4 无形资产摊销减值政策检查复核提示词

## 概述

本提示词针对无形资产摊销与减值政策检查底稿（I1-4）的复核，聚焦使用寿命判断（有限/不确定）、摊销方法选择、摊销年限合理性、减值测试政策的一致性与合规性。会计政策的适当性是无形资产摊销额和减值判断的前提，政策错误将导致系统性错报。

**法规依据：**
- 《企业会计准则第6号——无形资产》
- 《企业会计准则第8号——资产减值》
- 《企业会计准则第28号——会计政策、会计估计变更和差错更正》

---

## tips

1. **使用寿命判断决定是否摊销**：有限使用寿命无形资产在预计使用年限内摊销；使用寿命不确定的不摊销但每年减值测试。判断依据须充分（合同/法律/技术更新等）。
2. **摊销方法须反映经济利益实现方式**：通常采用直线法；若能可靠确定经济利益预期实现方式（如产量法），可采用其他方法，无法可靠确定时应采用直线法。
3. **摊销年限须有依据且不超过法定/合同期**：土地使用权按证载年限、专利权按法定保护期与合同期孰短，摊销年限延长将虚减摊销费用。
4. **残值通常为零**：无形资产残值一般假定为零，除非存在第三方购买承诺或活跃市场，残值估计不当将虚减摊销。
5. **减值测试政策的触发条件**：每年至少对使用寿命不确定的无形资产和尚未达到可使用状态的无形资产进行减值测试；有减值迹象时对所有无形资产测试。
6. **政策一致性与变更**：会计政策/估计须与上年一致，如变更须符合CAS28（会计估计变更未来适用、会计政策变更须符合条件）。

## checklist

### 一、使用寿命判断

- [ ] 每项无形资产的使用寿命判断（有限/不确定）是否有充分依据
- [ ] 有限使用寿命的确定是否考虑合同期、法律保护期、技术更新等因素
- [ ] 使用寿命不确定的判断是否符合准则条件（无法预见带来经济利益的期限）
- [ ] 使用寿命不确定的无形资产是否未摊销且每年减值测试
- [ ] 使用寿命是否每年复核，重估是否作为会计估计变更处理

### 二、摊销方法与年限

- [ ] 摊销方法是否反映经济利益预期实现方式（默认直线法）
- [ ] 土地使用权摊销年限是否按证载剩余年限
- [ ] 专利权/商标权摊销年限是否按法定保护期与合同期孰短
- [ ] 摊销年限是否与上年一致，变更是否有依据
- [ ] 残值假定是否为零，非零残值是否有第三方购买承诺或活跃市场支持
- [ ] 摊销起止时点是否正确（达到预定用途起、处置/报废时止）

### 三、减值测试政策

- [ ] 减值测试的触发条件（减值迹象、每年强制测试）是否明确
- [ ] 尚未达到可使用状态的无形资产是否每年减值测试
- [ ] 使用寿命不确定的无形资产是否每年减值测试
- [ ] 减值损失确认后是否不得转回（除商誉外的无形资产减值不可转回）
- [ ] 减值测试方法（可收回金额=公允价值减处置费用与使用价值孰高）是否符合CAS8

## risk_areas

### 高风险

1. **使用寿命判断错误规避摊销**：将有限寿命无形资产人为判断为不确定寿命以规避摊销，虚增资产虚增利润。
2. **摊销年限不当延长**：土地使用权/专利权摊销年限超过证载/法定期限，系统性虚减摊销费用。
3. **减值测试政策缺失**：对不确定寿命和未达可使用状态的无形资产未执行强制年度减值测试。
4. **无形资产减值转回**：将已确认的无形资产减值损失转回（违反CAS8减值不可转回原则）。

### 中风险

1. **摊销方法不当**：采用非直线法但无法可靠确定经济利益实现方式，或方法变更无依据。
2. **残值假定不当**：非零残值缺乏第三方购买承诺或活跃市场支持，虚减摊销。
3. **会计估计变更处理错误**：使用寿命重估未按会计估计变更（未来适用）处理。

### 低风险

1. **政策文档表述模板化**：政策描述照搬准则原文，未结合本企业无形资产特点。
2. **摊销起止时点记录不精确**：达到预定用途/处置时点记录有偏差但金额影响微小。
3. **减值迹象评估记录不完整**：减值迹象识别过程未充分留痕。
