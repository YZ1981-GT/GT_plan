# I5-note-soe 其他非流动资产附注披露复核提示词（国有企业）

## 概述

本提示词针对其他非流动资产国有企业附注披露底稿（I5-note-soe）的复核，聚焦其他非流动资产构成及变动披露（与上市版共有）及国有企业特定关注：大额预付款的审批合规性、关联方长期资金占用的披露、资产质量评价、财务决算报表口径一致性。国企"其他非流动资产"须警惕掩盖国有资产占用或减值。

**法规依据：**
- 《企业会计准则第30号——财务报表列报》
- 《中央企业财务决算报告管理办法》

---

## tips

1. **国企附注双层披露**：既满足CAS30通用披露，又满足国资委财务决算及资产质量披露要求。
2. **构成明细披露**：按项目性质（预付购置款/工程款/待处理项目等）分类披露构成及变动。
3. **大额预付款审批**：形成大额预付款的支出须经适当审批，须关注合规性。
4. **关联方资金占用披露**：以其他非流动资产名义的关联方长期资金占用须单独披露。
5. **资产质量视角**：长期挂账无进展、存在减值风险的项目影响资产质量评价，须说明。
6. **决算口径一致**：其他非流动资产数据须与年度财务决算报表一致。

---

## checklist

### 一、基础披露完整性（与上市版共有）

- [ ] 其他非流动资产是否按项目/性质分类披露
- [ ] 变动情况（期初/增加/减少/期末）是否披露
- [ ] 附注期末余额是否与I5-1审定数一致
- [ ] 各项目是否与I5-2明细表勾稽
- [ ] 期初期末可比信息是否完整

### 二、审批与关联方

- [ ] 大额预付款支出审批是否合规
- [ ] 关联方长期资金占用是否单独披露
- [ ] 预付长期购置款的合同履行进度是否说明
- [ ] 是否存在以其他非流动资产名义掩盖资金占用

### 三、资产质量与决算

- [ ] 长期挂账无进展项目是否说明
- [ ] 存在减值风险项目是否说明
- [ ] 其他非流动资产数据是否与年度财务决算报表一致
- [ ] 决算与审计口径差异是否编制调节说明
- [ ] 与上市版相比是否补充国资监管层面信息

## risk_areas

### 高风险

1. **变动表不勾稽或与审定表不一致**。
2. **关联方资金占用未披露**：以其他非流动资产名义的关联方资金占用未披露。
3. **大额预付款未审批**：形成大额预付款支出未经适当审批。

### 中风险

1. **减值风险项目未说明**。
2. **预付款进度披露缺失**。
3. **决算与审计口径差异未调节**。

### 低风险

1. **披露格式未完全按决算模板**。
2. **项目说明简略**。
3. **可比信息不完整**。
