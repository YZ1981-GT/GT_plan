# I6-4 研发费用针对性检查复核提示词

## 概述

本提示词针对研发费用针对性检查底稿（I6-4）的复核，聚焦针对识别风险实施的专项程序：研发项目归集准确性核查、研发费用加计扣除归集合规性、人员/材料/折旧归集真实性及非研发支出混入的追查。研发费用因涉及加计扣除税收优惠，是虚增费用套取税收利益的高风险领域，针对性检查是关键审计程序。

**法规依据：**
- 《企业会计准则第6号——无形资产》
- 《中国注册会计师审计准则第1314号——审计抽样》
- 《研发费用税前加计扣除政策》（财税相关规定）

---

## tips

1. **研发项目归集核查**：研发费用须按研发项目（RD项目）归集，费用与项目的关联性、项目的真实性须核查。
2. **加计扣除归集合规**：加计扣除的研发费用归集范围须符合税收政策（人员人工/直接投入/折旧/无形资产摊销/新产品设计费等），不符合的须调出。
3. **人员归集真实性**：研发人员薪酬归集须与人员认定、工时匹配，警惕将非研发人员薪酬计入。
4. **材料/折旧归集**：研发领用材料、研发用设备折旧归集须真实，与存货、固定资产勾稽。
5. **非研发支出追查**：核查是否将生产成本、日常管理费用等非研发支出混入研发费用套取加计扣除。
6. **勾稽核心底稿**：针对性检查结论须与I6-2明细表、I6-1审定表勾稽，加计扣除归集与所得税（N）勾稽。

---

## checklist

### 一、研发项目归集

- [ ] 研发费用是否按研发项目归集
- [ ] 费用与研发项目的关联性是否核查
- [ ] 研发项目的真实性（立项/进展）是否核查
- [ ] 是否存在无对应项目的费用归集

### 二、加计扣除合规性

- [ ] 加计扣除研发费用归集范围是否符合税收政策
- [ ] 不符合加计扣除范围的费用是否调出
- [ ] 加计扣除辅助账/归集台账是否完整
- [ ] 加计扣除基数是否与所得税（N）勾稽

### 三、分项归集真实性

- [ ] 研发人员薪酬归集是否真实（勾稽人员认定/工时）
- [ ] 研发领用材料是否真实（勾稽存货F）
- [ ] 研发用设备折旧归集是否真实（勾稽固定资产H）
- [ ] 是否存在非研发支出（生产成本/日常管理费）混入
- [ ] 针对性检查结论是否与I6-2/I6-1勾稽

## risk_areas

### 高风险

1. **非研发支出混入套取加计扣除**：将生产/管理费用混入研发费用虚增加计扣除基数，套取税收利益。
2. **虚增研发费用**：无真实研发活动或夸大归集，虚增研发费用及加计扣除。
3. **加计扣除范围违规**：将不符合税收政策的费用纳入加计扣除，存在税务风险。

### 中风险

1. **研发项目归集不清**：费用未按项目归集或与项目关联性不明。
2. **人员/材料归集不实**：研发人员/材料归集与认定/存货不匹配。
3. **加计扣除台账不完整**。

### 低风险

1. **检查记录不完整**。
2. **针对性程序与风险评估勾稽索引缺失**。
3. **检查结论表述不清晰**。
