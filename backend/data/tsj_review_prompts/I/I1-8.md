# I1-8 无形资产权属检查复核提示词

## 概述

本提示词针对无形资产权属检查底稿（I1-8）的复核，聚焦无形资产权属证明的完整性、权属主体一致性、权利受限（抵押/质押/查封）情况及权属瑕疵的识别。权属是无形资产"权利和义务"认定的核心证据，权属不清将导致资产确认不当。

**法规依据：**
- 《企业会计准则第6号——无形资产》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **权属证明须与资产类别匹配**：土地使用权→不动产权证/国有土地使用证；专利权→专利证书；商标权→商标注册证；软件→软件著作权登记证书；特许经营权→特许经营协议。
2. **权属主体须为被审计单位**：权属证书载明的权利人须与被审计单位名称一致，不一致须查明原因（受托持有、代持等）。
3. **权利受限须识别并披露**：已抵押/质押/查封的无形资产（如土地使用权抵押担保）须核查担保合同并在附注披露（勾稽借款/或有事项底稿）。
4. **权属有效期与摊销年限勾稽**：权属证书载明的有效期须与使用寿命判断（I1-7）、摊销年限（I1-10）一致。
5. **关注权属未过户即入账**：取得无形资产但权属登记未完成即确认，存在权利不完整风险。
6. **权属瑕疵评估**：权属存在争议、诉讼、共有等瑕疵须评估对资产确认和减值的影响。

## checklist

### 一、权属证明完整性

- [ ] 每项无形资产是否有对应的权属证明文件
- [ ] 土地使用权是否有不动产权证/国有土地使用证
- [ ] 专利权/商标权是否有专利证书/商标注册证
- [ ] 软件是否有软件著作权登记证书
- [ ] 特许经营权/其他权利是否有对应协议或批准文件

### 二、权属主体与有效性

- [ ] 权属证书载明的权利人是否与被审计单位名称一致
- [ ] 不一致的情况是否查明原因（代持/受托/更名等）
- [ ] 权属证书是否在有效期内
- [ ] 权属有效期是否与使用寿命（I1-7）、摊销年限（I1-10）一致
- [ ] 权属是否已完成转移登记（新增项目勾稽I1-5）

### 三、权利受限与瑕疵

- [ ] 是否核查无形资产是否存在抵押/质押/查封等权利受限
- [ ] 已受限的无形资产是否有担保合同支持并在附注披露
- [ ] 是否存在权属争议、诉讼、共有等瑕疵
- [ ] 权属瑕疵对资产确认和减值的影响是否评估
- [ ] 受限金额是否与借款/或有事项底稿勾稽

## risk_areas

### 高风险

1. **权属证明缺失**：无权属证书支持的无形资产入账，存在权利不实或虚构资产风险。
2. **权属主体不一致**：权属证书权利人非被审计单位，可能资产不属于企业或存在代持安排。
3. **权利受限未披露**：已抵押/质押的无形资产未在附注披露，隐瞒担保事项。

### 中风险

1. **权属未过户即入账**：取得无形资产权属登记未完成即确认。
2. **权属有效期与摊销年限不符**：证书有效期短于摊销年限，虚减摊销。
3. **权属瑕疵未评估**：存在争议/诉讼的无形资产未评估减值影响。

### 低风险

1. **权属证书复印件未核对原件**。
2. **权属信息记录不完整**（证书编号、有效期）。
3. **交叉索引缺失**（未链接借款/或有事项底稿）。
