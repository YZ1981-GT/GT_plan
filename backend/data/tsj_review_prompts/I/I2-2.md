# I2-2 开发支出明细表复核提示词

## 概述

本提示词针对开发支出明细表（I2-2）的复核，聚焦按研发项目列示的开发支出滚动变动：期初余额+本期资本化投入−结转无形资产−费用化转出−减值=期末余额。明细表支撑审定表（I2-1），其资本化投入须与项目构成（I2-7）、材料/人员/委外投入检查（I2-8/I2-9/I2-10/I2-11）逐项勾稽。

**法规依据：**
- 《企业会计准则第6号——无形资产》

---

## tips

1. **逐项目滚动**：每个研发项目分别列示期初、本期资本化投入、结转无形资产、费用化转出、减值、期末，滚动公式须成立。
2. **明细合计回勾审定表**：各项目期末余额合计须等于I2-1审定表审定数。
3. **资本化投入构成勾稽**：本期资本化投入应等于该项目资本化的材料（I2-8）、人员薪酬（I2-9/I2-10）、委外费用（I2-11）、折旧摊销等归集之和。
4. **结转与费用化去向清晰**：结转无形资产须勾稽I1-2，费用化转出须勾稽当期损益（研发费用/管理费用）。
5. **单项目余额异常关注**：单个项目开发支出余额畸高或长期无变动，须追溯项目进展和减值风险。
6. **区分资本化与费用化投入**：明细表仅归集资本化投入，费用化的研发投入不应进入开发支出（勾稽I6研发费用）。

---

## checklist

### 一、滚动勾稽

- [ ] 每个项目：期初+资本化投入−结转−费用化−减值=期末 是否成立
- [ ] 明细表期末余额合计是否回勾I2-1审定表审定数
- [ ] 本期资本化投入是否与I2-7研发项目构成一致
- [ ] 本期结转无形资产是否勾稽I1-2内部研发形成原值
- [ ] 本期费用化转出是否勾稽当期损益（研发费用/管理费用）

### 二、资本化投入构成

- [ ] 资本化材料投入是否与I2-8研发材料投入检查勾稽
- [ ] 资本化人员薪酬是否与I2-9/I2-10研发人员认定/工时勾稽
- [ ] 资本化委外费用是否与I2-11委外研发检查勾稽
- [ ] 资本化折旧摊销等其他费用归集是否合理
- [ ] 是否将费用化研发投入误计入开发支出

### 三、项目状态与减值

- [ ] 各项目开发状态（进行中/已完成结转/已失败）是否标注
- [ ] 长期无变动或余额畸高项目是否追溯进展
- [ ] 减值项目是否勾稽I2-15减值准备测试
- [ ] 已结转项目是否正确注销余额

## risk_areas

### 高风险

1. **滚动公式不成立**：项目开发支出期初增减期末不勾稽，审定表基础不可靠。
2. **费用化投入混入资本化**：将应费用化的研发投入计入开发支出，虚增资产虚减费用。
3. **资本化投入构成虚增**：材料/人员/委外投入归集金额与检查底稿不符，虚增资本化。
4. **失败项目余额未处理**：已失败项目开发支出未费用化或减值，虚增资产。

### 中风险

1. **明细合计与审定表不勾稽**。
2. **结转/费用化去向不清**：结转无形资产或费用化转出未勾稽相关底稿。
3. **项目状态标注缺失**：无法判断项目进展和结转时点。

### 低风险

1. **项目名称与立项文件不一致**。
2. **投入构成明细列示不规范**。
3. **交叉索引缺失**。
