# I1-10 无形资产摊销测算（不含减值）复核提示词

## 概述

本提示词针对无形资产摊销测算（不含减值影响）底稿（I1-10）的复核，聚焦按逐项目直线法（或其他方法）独立测算本期摊销额，验证摊销参数（原值/使用寿命/残值/摊销起止）准确性及测算结果与账面计提的一致性。摊销测算是审计师对企业摊销计提合理性的独立验证。

**法规依据：**
- 《企业会计准则第6号——无形资产》

---

## tips

1. **摊销额公式**：直线法下年摊销额=（原值−残值）÷使用寿命；本期摊销额按实际使用月份计算。测算须逐项目独立进行。
2. **摊销参数须与政策/使用寿命一致**：原值取I1-2明细、使用寿命取I1-7判断、残值通常为零，参数须与I1-4政策检查一致。
3. **摊销起止时点**：达到预定用途当月起摊销，处置/报废当月止；本期新增/减少项目按实际月份计算。
4. **测算差异须解释**：审计师测算的本期摊销额与企业账面计提的差异须查明原因（参数不同、方法不同、计算错误），差异重大须提调整。
5. **不含减值口径**：本表按未考虑减值的原值测算摊销，含减值影响的摊销另见I1-11，两表适用场景须区分。
6. **勾稽审定表与明细表**：测算的本期摊销总额须与I1-1审定表累计摊销本期增加、I1-2明细表本期摊销一致。

## checklist

### 一、摊销参数准确性

- [ ] 测算使用的原值是否与I1-2明细表一致
- [ ] 使用寿命是否与I1-7使用寿命检查一致
- [ ] 残值假定是否与I1-4政策一致（通常为零）
- [ ] 摊销方法是否与政策一致（直线法或其他）

### 二、测算准确性

- [ ] 年摊销额=（原值−残值）÷使用寿命是否计算正确
- [ ] 本期摊销额是否按实际使用月份计算
- [ ] 本期新增项目是否从达到预定用途当月起摊销
- [ ] 本期减少项目是否摊销至处置/报废当月止
- [ ] 已提足摊销项目是否停止摊销

### 三、测算结果勾稽

- [ ] 审计师测算本期摊销总额与企业账面计提是否一致
- [ ] 测算差异是否查明原因并评估是否需调整
- [ ] 测算摊销总额是否与I1-1审定表累计摊销本期增加勾稽
- [ ] 测算摊销总额是否与I1-2明细表本期摊销勾稽
- [ ] 摊销分配是否与I1-9摊销分配分析一致

## risk_areas

### 高风险

1. **企业摊销少计**：企业账面摊销明显低于审计师测算（参数虚高或漏提），虚增资产虚增利润，测算差异重大未调整。
2. **摊销参数不实**：使用寿命虚高或残值虚高导致系统性少提摊销。

### 中风险

1. **摊销起止时点错误**：新增/减少项目未按实际月份计算摊销。
2. **测算差异未解释**：测算与账面差异未查明原因。
3. **已提足项目继续摊销**：账面价值为零仍计提摊销。

### 低风险

1. **测算精度差异**：因取整或月份计算方式差异产生微小差异。
2. **参数来源索引不完整**。
3. **测算过程记录不规范**。
