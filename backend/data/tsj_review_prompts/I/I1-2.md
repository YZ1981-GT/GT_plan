# I1-2 无形资产明细表复核提示词

## 概述

本提示词针对无形资产明细表（I1-2）的复核，聚焦按具体项目（土地使用权/专利权/商标权/非专利技术/软件/内部研发形成的无形资产等）列示的原值、累计摊销、减值准备三层滚动变动。明细表是审定表（I1-1）的支撑底稿，其增减变动须与增加检查（I1-5）、减少明细（I1-6）、摊销测算（I1-10/11）、减值测试（I1-12）逐项勾稽。

**法规依据：**
- 《企业会计准则第6号——无形资产》
- 《企业会计准则第8号——资产减值》

---

## tips

1. **逐项目三层滚动**：每个无形资产项目须分别列示原值、累计摊销、减值准备的期初+增加−减少=期末，三层滚动公式须成立。
2. **明细合计回勾审定表**：明细表各项目原值/累计摊销/减值准备合计须等于I1-1审定表对应审定数，是审定表可靠性的基础。
3. **按类别正确归集**：土地使用权、专利权、商标权、软件、内部研发形成的无形资产须按性质分类，不同类别摊销年限和减值特征不同。
4. **本期增加须有来源**：外购、内部研发资本化、投资者投入、非货币性资产交换、企业合并取得等不同来源的增加须可追溯至I1-5及原始凭证。
5. **本期减少须有依据**：处置、报废、对外投资、无偿划转等减少须可追溯至I1-6及审批文件，处置损益计算正确。
6. **关注账面价值为零仍在使用的项目**：已摊销完毕（账面价值为零）但仍在使用的无形资产应保留在表内说明，不得直接注销。

## checklist

### 一、三层滚动勾稽

- [ ] 每个项目原值：期初+本期增加−本期减少=期末是否成立
- [ ] 每个项目累计摊销：期初+本期计提−处置转出=期末是否成立
- [ ] 每个项目减值准备：期初+本期计提−处置转出=期末是否成立
- [ ] 每个项目账面价值=原值−累计摊销−减值准备是否正确
- [ ] 明细表原值/累计摊销/减值准备合计是否回勾I1-1审定表审定数

### 二、增减变动核对

- [ ] 本期增加是否与I1-5增加检查逐笔一致且有原始凭证支持
- [ ] 本期减少是否与I1-6减少明细逐笔一致且有审批文件
- [ ] 本期摊销计提是否与I1-10/I1-11摊销测算一致
- [ ] 本期减值计提是否与I1-12减值准备测试一致
- [ ] 处置项目的处置损益是否正确计算并结转当期损益

### 三、分类与列示

- [ ] 各无形资产是否按性质正确分类（土地使用权/专利/商标/软件/研发形成等）
- [ ] 内部研发形成的无形资产是否单独标识（勾稽I2开发支出结转）
- [ ] 使用寿命有限与不确定的项目是否分别标注
- [ ] 已提足摊销仍在使用的项目是否保留列示并说明
- [ ] 剩余摊销年限/剩余账面价值是否正确列示

## risk_areas

### 高风险

1. **滚动公式不成立**：原值/累计摊销/减值准备任一层期初增减期末不勾稽，导致账面价值失真、审定表基础不可靠。
2. **虚构无形资产**：明细表列示无实际权属或无经济利益流入的无形资产项目，虚增资产（如无实质的"技术使用权"）。
3. **内部研发形成无形资产原值不实**：资本化金额与I2开发支出结转金额不一致，或包含研究阶段费用。
4. **减值/摊销漏计**：明细表某项目本期未计提摊销或减值但实际已发生减值迹象，虚增账面价值。

### 中风险

1. **明细合计与审定表不勾稽**：明细表合计与I1-1审定数存在差异，可能明细遗漏或重复。
2. **分类归集错误**：将土地使用权归入软件类、或研发形成归入外购类，影响摊销年限和减值判断。
3. **处置损益计算错误**：处置项目的账面价值结转不完整或处置损益计入科目错误。
4. **剩余摊销年限错误**：剩余年限与已使用年限、总年限不匹配，影响后续摊销测算。

### 低风险

1. **项目名称口径不一致**：明细项目命名与合同/权属证书不一致，影响追溯核对。
2. **列示精度不统一**：部分项目保留两位小数、部分取整，精度不一致。
3. **交叉索引缺失**：明细项目未标注对应的增加检查/减少明细/摊销测算索引。
