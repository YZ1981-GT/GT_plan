# I4-1 长期待摊费用审定表复核提示词

## 概述

本提示词针对长期待摊费用审定表（I4-1）的复核，聚焦长期待摊费用（经营租入固定资产改良支出、其他摊销期限在一年以上的待摊费用）的期初期末勾稽、试算平衡表1801科目核对、本期新增与摊销的完整性及余额合理性。长期待摊费用是无法计入当期损益或资产的、摊销期在一年以上的支出，其归集与摊销的适当性影响资产与损益。

**法规依据：**
- 《企业会计准则第30号——财务报表列报》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **滚动勾稽**：期末余额=期初余额+本期增加−本期摊销−本期转销，各环节须逐项勾稽。
2. **期初承前**：期初审定数须等于上年审定表期末审定数。
3. **试算平衡表核对**：审定表长期待摊费用合计须与试算平衡表1801科目审定数一致。
4. **摊销期须在一年以上**：长期待摊费用的摊销期须在一年以上，一年内的应计入待摊费用（预付费用）或当期损益，误分类将影响流动性列报。
5. **本期摊销勾稽测算**：本期摊销须与I4-6/I4-7摊销测算一致，摊销去向（成本/费用）合理。
6. **关注余额合理性**：长期挂账、剩余摊销期与实际受益期不符、已无受益基础仍挂账的长期待摊费用须评估是否应转销。

## checklist

### 一、期初期末勾稽

- [ ] 期初审定数是否等于上年审定表期末审定数（承前）
- [ ] 期末余额=期初+本期增加−本期摊销−本期转销 是否成立
- [ ] 本期增加是否与I4-2明细表、原始凭证勾稽
- [ ] 本期摊销是否与I4-6/I4-7摊销测算一致
- [ ] 各项目期初期末变动是否与明细表一致

### 二、试算平衡表核对

- [ ] 审定表长期待摊费用合计是否与试算平衡表1801科目审定数一致
- [ ] 试算平衡表未审数、调整数与审定表对应列是否一致
- [ ] 是否存在试算平衡表已更新但审定表未同步的情况

### 三、审计调整完整性

- [ ] 本期摊销、转销等账项调整（AJE）是否完整反映
- [ ] 重分类调整（RJE，如一年内摊销部分重分类）是否完整反映
- [ ] 调整分录借贷平衡，审定数=未审数+AJE+RJE是否成立
- [ ] 是否存在I4-3已编制但未纳入审定表的调整

### 四、分类与列报

- [ ] 长期待摊费用摊销期是否均在一年以上
- [ ] 一年内到期的待摊部分是否恰当列报（如重分类）
- [ ] 是否将应费用化的支出误计入长期待摊费用
- [ ] 审定表分类是否与附注披露一致

## risk_areas

### 高风险

1. **期初期末不勾稽**：期初与上年期末不一致或滚动公式不成立。
2. **应费用化支出挂账**：将本应计入当期损益的支出计入长期待摊费用，虚增资产虚增利润。
3. **摊销遗漏**：本期应摊销未摊销，虚增资产。
4. **试算平衡表与审定表不一致**：1801科目口径不一致。

### 中风险

1. **明细与汇总不勾稽**：审定表合计与I4-2明细表不一致。
2. **摊销期分类错误**：一年内摊销费用误计入长期待摊费用。
3. **无受益基础仍挂账**：已无受益基础的长期待摊费用未转销。

### 低风险

1. **审定表格式不规范**。
2. **交叉索引不完整**。
3. **变动说明不充分**。
