# I3-7 商誉可收回金额测试复核提示词

## 概述

本提示词针对商誉可收回金额测试底稿（I3-7）的复核，聚焦包含商誉资产组可收回金额的确定：公允价值减处置费用的评估、使用价值现金流量折现（DCF）预测的合理性、折现率（WACC/CAPM）的适当性及关键假设的敏感性。可收回金额是商誉减值测试（I3-6）的核心，其高估将直接导致商誉减值漏计。

**法规依据：**
- 《企业会计准则第8号——资产减值》

---

## tips

1. **可收回金额取孰高**：公允价值减处置费用与使用价值（DCF）孰高。资产组可收回金额确定通常依赖使用价值。
2. **使用价值现金流量口径**：基于资产组当前状况的税前未来现金流量，不含筹资活动、所得税及未来重组/改良带来的现金流量。
3. **预测期与永续增长率**：明确预测期（通常5年）现金流量+永续期终值，永续增长率不超过行业长期增长率和宏观经济增长率。
4. **折现率为税前利率**：与税前现金流量口径一致，通常基于WACC（CAPM推算权益成本）调整为税前，须反映资产组特定风险。
5. **关键假设合理性**：收入增长率、毛利率、资本性支出等关键假设须与并购时预测、历史业绩、行业趋势一致，与业绩承诺对比。
6. **敏感性分析必备**：对折现率、永续增长率、收入增长率等关键假设进行敏感性分析，是上市公司商誉减值披露的重点。

## checklist

### 一、现金流量预测

- [ ] 现金流量预测是否基于资产组当前状况
- [ ] 现金流量是否为税前口径且不含筹资/未来改良现金流
- [ ] 收入增长率、毛利率是否与并购预测、历史、行业一致
- [ ] 关键假设是否与业绩承诺对比（承诺未达是否下调预测）
- [ ] 预测期是否合理（通常5年），永续增长率是否不超过行业/宏观增长

### 二、折现率确定

- [ ] 折现率是否为税前利率（与税前现金流量一致）
- [ ] WACC/CAPM参数（无风险利率、市场风险溢价、Beta、资本结构）是否合理
- [ ] 折现率是否反映资产组特定风险
- [ ] 折现率与被审计单位实际风险水平是否匹配

### 三、可收回金额与减值

- [ ] 使用价值现值计算是否正确
- [ ] 可收回金额是否取公允价值减处置费用与使用价值孰高
- [ ] 可收回金额是否与资产组账面价值比较（勾稽I3-6）
- [ ] 是否进行关键假设敏感性分析
- [ ] 测算结论是否与I3-6减值测试一致

## risk_areas

### 高风险

1. **现金流量假设过于乐观**：收入增长率、毛利率明显高于历史和业绩承诺实际，人为抬高可收回金额规避商誉减值。
2. **折现率口径错误或过低**：税后折现率折现税前现金流量，或折现率过低虚高可收回金额。
3. **永续增长率过高**：永续增长率超过行业/宏观增长，虚高终值。
4. **业绩未达仍不下调预测**：业绩承诺未完成但预测假设未相应下调。

### 中风险

1. **现金流量口径错误**：含筹资/所得税/未来改良现金流。
2. **敏感性分析缺失或不充分**：未对关键假设敏感性分析。
3. **WACC参数不合理**：Beta、资本结构等参数缺乏依据。

### 低风险

1. **DCF参数来源文档不充分**。
2. **折现系数计算精度差异**。
3. **测算与减值测试勾稽索引缺失**。
