# I6-1 研发费用审定表复核提示词

## 概述

本提示词针对研发费用审定表（I6-1，损益类科目）的复核，聚焦研发费用（费用化的研发支出）本期发生额的完整性、试算平衡表6602科目核对、费用化与资本化划分的恰当性及审计调整完整性。研发费用为损益类科目，取本期发生额，其审定数直接影响当期利润，与开发支出（I2资本化）的划分是核心风险。

**法规依据：**
- 《企业会计准则第6号——无形资产》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **损益类取发生额**：研发费用为损益类科目，审定表审定的是本期发生额（借方累计），无期初期末余额概念，须与本期发生额勾稽。
2. **试算平衡表核对**：审定表研发费用审定数须与试算平衡表6602研发费用科目本期发生额一致。
3. **费用化与资本化划分**：研发费用（费用化）与开发支出（资本化）的划分须恰当，研究阶段支出及不满足资本化条件的开发阶段支出费用化（勾稽I2）。
4. **构成完整**：研发费用按人员薪酬、直接投入（材料/燃料动力）、折旧摊销、委外、其他分项归集，各分项发生额须完整。
5. **审计调整完整**：不符合资本化条件转费用化、不当归集调出等调整须完整反映。
6. **关注费用化率异常**：研发费用与资本化开发支出的比例结构须合理，费用化率异常波动须解释（勾稽I2-5）。

## checklist

### 一、发生额与试算平衡表核对

- [ ] 审定表研发费用审定数是否为本期发生额（借方累计）
- [ ] 审定数是否与试算平衡表6602科目本期发生额一致
- [ ] 试算平衡表未审数、调整数与审定表对应列是否一致
- [ ] 是否存在试算平衡表已更新但审定表未同步的情况

### 二、构成完整性

- [ ] 研发费用是否按分项归集（人员薪酬/直接投入/折旧摊销/委外/其他）
- [ ] 各分项发生额是否与I6-2明细表勾稽
- [ ] 各分项归集是否完整无遗漏
- [ ] 分项构成是否与明细表一致

### 三、费用化与资本化划分

- [ ] 费用化研发支出与开发支出（I2资本化）划分是否恰当
- [ ] 研究阶段支出是否全部费用化
- [ ] 不满足资本化条件的开发阶段支出是否费用化（勾稽I2-6）
- [ ] 费用化率是否合理（勾稽I2-5实质性分析）

### 四、审计调整完整性

- [ ] 转费用化、不当归集调出等账项调整（AJE）是否完整反映
- [ ] 调整分录借贷平衡，审定数=未审数+AJE+RJE是否成立
- [ ] 是否存在I6-3已编制但未纳入审定表的调整
- [ ] 建议未调整错报是否记录（勾稽A13）

## risk_areas

### 高风险

1. **发生额与试算平衡表不一致**：审定数与6602科目本期发生额不一致，存在调整遗漏或汇总错误。
2. **费用化研发挪至资本化**：将应费用化研发支出计入开发支出资本化，虚减费用虚增利润（勾稽I2）。
3. **研发费用少计**：应计入研发费用的支出遗漏或错计其他科目，影响研发费用真实性和加计扣除。
4. **审计调整遗漏**：不符合条件转费用化调整未反映。

### 中风险

1. **构成不完整**：研发费用分项归集遗漏（如漏计折旧摊销）。
2. **明细与汇总不勾稽**：审定表分项与I6-2明细表不一致。
3. **费用化率异常未解释**。

### 低风险

1. **审定表格式不规范**。
2. **交叉索引不完整**（未链接I2/I6-2）。
3. **变动说明不充分**。
