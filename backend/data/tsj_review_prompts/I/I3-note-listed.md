# I3-note-listed 商誉附注披露复核提示词（上市公司）

## 概述

本提示词针对商誉上市公司附注披露底稿（I3-note-listed）的复核，聚焦商誉按资产组列示的变动情况、商誉减值测试关键信息（资产组、可收回金额确定方法、关键假设）、减值损失及原因的披露充分性。商誉减值是上市公司财务报表最受关注的事项之一，证监会对商誉减值披露有专门要求。

**法规依据：**
- 《企业会计准则第20号——企业合并》
- 《企业会计准则第8号——资产减值》
- 《企业会计准则第30号——财务报表列报》
- 《会计监管风险提示第8号——商誉减值》

---

## tips

1. **商誉变动表按资产组列示**：披露各资产组/资产组组合商誉的期初原值、减值准备、本期变动、期末，与I3-2明细表勾稽。
2. **减值测试关键信息披露**：披露商誉所在资产组、可收回金额确定方法（公允价值减处置费用/使用价值）、关键假设（增长率、折现率）——这是证监会《会计监管风险提示第8号》重点要求。
3. **关键假设量化披露**：预测期收入增长率、永续增长率、税前折现率等关键假设须量化披露，并说明确定依据。
4. **减值损失及原因**：本期计提商誉减值损失的金额、涉及资产组及减值原因（业绩未达/行业下滑等）须披露。
5. **敏感性分析披露**：关键假设变动对减值测试结果的敏感性分析（上市公司重点）。
6. **附注与审定表勾稽**：附注商誉账面价值须等于I3-1审定数，各资产组商誉须与I3-2明细表勾稽。

## checklist

### 一、商誉变动与构成披露

- [ ] 商誉变动表是否按资产组/资产组组合列示
- [ ] 是否列示各资产组期初原值、减值准备、本期变动、期末
- [ ] 商誉形成的被投资单位/合并事项是否披露
- [ ] 附注商誉账面价值是否等于I3-1审定数
- [ ] 各资产组商誉是否与I3-2明细表勾稽

### 二、减值测试关键信息（监管重点）

- [ ] 是否披露商誉所在资产组/资产组组合的认定
- [ ] 是否披露可收回金额确定方法（公允价值减处置费用/使用价值）
- [ ] 是否量化披露关键假设（收入增长率、永续增长率、税前折现率）
- [ ] 关键假设确定依据是否说明
- [ ] 是否披露关键假设敏感性分析

### 三、减值损失披露

- [ ] 本期计提商誉减值损失金额是否披露
- [ ] 减值涉及的资产组及减值原因是否披露
- [ ] 减值损失是否计入资产减值损失并与利润表勾稽
- [ ] 是否同时列示期末数和期初数

## risk_areas

### 高风险

1. **减值测试关键信息缺失**：未按《会计监管风险提示第8号》披露资产组、可收回金额方法、关键假设，不满足监管要求。
2. **变动表不勾稽**：商誉变动与审定表/明细表不一致。
3. **减值原因披露不充分**：本期大额减值未披露原因（业绩未达/行业下滑）。
4. **关键假设未量化**：未量化披露增长率、折现率等关键假设。

### 中风险

1. **敏感性分析缺失**：未披露关键假设敏感性分析。
2. **资产组认定披露不清**：商誉所在资产组认定披露模糊。
3. **可比信息缺失**。

### 低风险

1. **披露格式不完全规范**。
2. **减值测试方法描述模板化**。
3. **数字精度不一致**。
