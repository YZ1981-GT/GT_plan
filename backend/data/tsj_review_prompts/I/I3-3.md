# I3-3 商誉调整分录复核提示词

## 概述

本提示词针对商誉调整分录汇总表（I3-3）的复核，含账项调整（AJE）、重分类调整（RJE）及未调整错报评估。复核重点是商誉减值调整、初始确认商誉更正、处置商誉结转的证据充分性、借贷平衡及与I3-1审定表、试算平衡表1711/1712科目的闭环勾稽。

**法规依据：**
- 《企业会计准则第20号——企业合并》
- 《企业会计准则第8号——资产减值》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **减值调整是核心**：商誉减值须借资产减值损失、贷商誉减值准备，须有I3-6减值测试支持。
2. **初始确认更正**：初始商誉计量错误（可辨认净资产公允价值份额确定错误）的更正须区分本期与前期差错。
3. **处置商誉结转**：处置子公司时相关商誉结转计入投资收益/处置损益。
4. **与I3-1勾稽**：审定表调整列金额须与I3-3已确认分录逐笔一致。
5. **商誉减值不可转回**：调整中不得出现商誉减值转回。
6. **TB回写**：调整须同步试算平衡表1711/1712科目。

---

## checklist

### 一、调整证据与审批

- [ ] 商誉减值调整是否有I3-6减值测试支持
- [ ] 初始确认更正是否有可辨认净资产公允价值重新评估支持
- [ ] 处置商誉结转是否有处置协议支持
- [ ] 超重要性水平调整是否经适当审批
- [ ] 每笔调整分录借贷方是否平衡

### 二、与审定表及TB勾稽

- [ ] 调整金额是否完整反映到I3-1审定表调整列
- [ ] 审定数=未审数+AJE+RJE是否成立
- [ ] 调整后商誉是否回写试算平衡表1711/1712科目
- [ ] 是否存在I3-3已编制但未纳入审定表的调整
- [ ] 未调整错报是否与A13勾稽

### 三、调整性质

- [ ] 是否体现商誉减值不可转回（无减值转回调整）
- [ ] 初始确认更正是否正确区分本期/前期差错
- [ ] 处置商誉结转损益计入科目是否正确
- [ ] 调整原因说明是否可追溯至具体审计程序

## risk_areas

### 高风险

1. **减值调整遗漏**：I3-6已测算减值未调整，虚增资产虚增利润。
2. **商誉减值转回调整**：出现商誉减值转回，违反准则。
3. **前期差错作本期处理**：初始商誉计量错误更正作为本期而非追溯重述。

### 中风险

1. **审定表与I3-3调整不一致**。
2. **处置商誉结转损益错误**。
3. **未调整错报累计超阈值未处理**。

### 低风险

1. **分录摘要、科目编码不规范**。
2. **索引指向支持底稿不完整**。
3. **审计说明未概括调整性质**。

## 跨底稿勾稽

- I3-3 减值调整 ↔ I3-6 商誉减值测试
- I3-3 已确认调整合计 ↔ I3-1 审定表调整列
- I3-3 SUD ↔ A13 未调整错报汇总
- 调整后审定数 ↔ 试算平衡表 1711/1712
