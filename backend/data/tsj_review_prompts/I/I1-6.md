# I1-6 无形资产减少明细复核提示词

## 概述

本提示词针对无形资产本期减少明细底稿（I1-6）的复核，聚焦本期处置、报废、对外投资、无偿划转等减少事项的账面价值结转完整性、处置损益准确性、审批合规性及凭证完整性。无形资产减少若结转不完整或损益计算错误，将导致资产虚增或损益错报。

**法规依据：**
- 《企业会计准则第6号——无形资产》
- 《中国注册会计师审计准则第1314号——审计抽样》

---

## tips

1. **减少方式多样**：处置（出售）、报废、对外投资、无偿划转、非货币性资产交换换出等，不同方式的账务处理和损益确认不同。
2. **账面价值须完整结转**：减少时须同时结转原值、累计摊销、减值准备，账面价值=原值−累计摊销−减值准备须完整转出。
3. **处置损益=处置收入−账面价值−相关税费**：处置损益计入资产处置收益/营业外收支，计算须准确、科目归属正确。
4. **审批合规**：无形资产处置尤其大额或关联方处置须有审批文件，国企处置还须符合国有资产处置程序。
5. **凭证核对**：处置协议→收款凭证→权属注销/转移登记→结转凭证，逐项核对。
6. **关注低价处置及关联方处置**：显失公允的低价处置、向关联方处置须核查交易实质与定价公允性。

## checklist

### 一、账面价值结转

- [ ] 减少项目的原值、累计摊销、减值准备是否同时结转
- [ ] 结转的账面价值是否等于原值减累计摊销减减值准备
- [ ] 结转金额是否与I1-2明细表本期减少一致
- [ ] 减少后该项目在明细表中是否正确注销或保留说明

### 二、处置损益准确性

- [ ] 处置损益是否等于处置收入减账面价值减相关税费
- [ ] 处置损益是否计入正确科目（资产处置收益/营业外收支）
- [ ] 处置收入是否与收款凭证一致
- [ ] 相关税费（增值税等）是否正确计算

### 三、审批与凭证

- [ ] 处置/报废是否有适当层级审批文件
- [ ] 大额或关联方处置是否符合审批权限和程序（国企含国资处置程序）
- [ ] 处置协议、收款凭证、权属注销/转移登记是否齐全
- [ ] 处置时点与结转时点是否一致，是否存在跨期

## risk_areas

### 高风险

1. **账面价值结转不完整**：仅结转原值未同时结转累计摊销/减值准备，导致资产虚增或损益错误。
2. **低价处置输送利益**：向关联方或特定方显失公允低价处置无形资产，损害企业利益（国企涉国有资产流失）。
3. **处置未审批**：大额处置未经适当审批，存在越权处置风险。

### 中风险

1. **处置损益计算错误**：处置收入或相关税费计算错误，或损益计入科目错误。
2. **跨期处置**：处置时点与结转时点不一致，导致跨期损益错报。
3. **权属未注销**：已处置但权属登记未注销，存在权利瑕疵。

### 低风险

1. **凭证不齐全**：缺少处置协议或收款凭证但金额影响微小。
2. **减少原因说明不充分**。
3. **交叉索引缺失**。
