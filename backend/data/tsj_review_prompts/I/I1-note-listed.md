# I1-note-listed 无形资产附注披露复核提示词（上市公司）

## 概述

本提示词针对无形资产上市公司附注披露底稿（I1-note-listed）的复核，聚焦无形资产分类披露、变动情况表（原值/累计摊销/减值准备三层滚动）、内部研发形成无形资产占比、使用寿命及摊销方法披露、减值信息及所有权受限披露的充分性与准确性。上市公司披露须满足CAS6及证监会信息披露编报规则要求。

**法规依据：**
- 《企业会计准则第6号——无形资产》
- 《企业会计准则第8号——资产减值》
- 《企业会计准则第30号——财务报表列报》
- 《公开发行证券的公司信息披露编报规则第15号》

---

## tips

1. **变动表是无形资产附注核心**：须完整列示原值、累计摊销、减值准备的期初、本期增加（购置/内部研发/其他）、本期减少（处置/其他）、期末，三层勾稽须成立。
2. **内部研发形成须单独披露**：披露期末无形资产中内部研发形成的金额及占比，是上市公司研发能力和资本化政策的关键信息（勾稽I2开发支出）。
3. **土地使用权单独列示**：土地使用权通常单独作为一类披露，说明取得方式和剩余摊销年限。
4. **使用寿命及摊销方法披露**：披露各类无形资产的使用寿命（有限年限/不确定）、摊销方法及使用寿命不确定的判断依据。
5. **减值信息披露**：披露本期计提减值准备的金额、原因及可收回金额确定方法（勾稽I1-12/I1-13）。
6. **附注与审定表/明细表闭环勾稽**：附注无形资产账面价值须等于I1-1审定数，各类别合计须等于I1-2明细表分类合计。

## checklist

### 一、分类与变动披露

- [ ] 无形资产是否按类别披露（土地使用权/专利权/商标权/软件/非专利技术/其他）
- [ ] 变动表是否完整列示原值/累计摊销/减值准备三层滚动
- [ ] 本期增加是否区分购置、内部研发形成、企业合并、其他
- [ ] 各类别期末账面价值合计是否等于I1-1审定数
- [ ] 是否同时列示期末数和期初数（可比信息）

### 二、内部研发与土地使用权

- [ ] 是否披露内部研发形成无形资产的金额及占无形资产比例
- [ ] 内部研发形成金额是否与I2开发支出结转勾稽
- [ ] 土地使用权是否单独列示并说明取得方式
- [ ] 土地使用权剩余摊销年限是否披露

### 三、使用寿命、摊销与减值

- [ ] 是否披露各类无形资产使用寿命（有限年限/不确定）及摊销方法
- [ ] 使用寿命不确定的无形资产是否披露判断依据
- [ ] 本期计提减值准备的金额、原因是否披露
- [ ] 可收回金额确定方法（公允价值减处置费用/使用价值）是否披露
- [ ] 摊销费用在成本费用间的分配是否披露（勾稽I1-9）

### 四、所有权受限及其他

- [ ] 所有权受限（抵押/质押）的无形资产是否披露金额及受限原因
- [ ] 已到期未续期或权属存在瑕疵的无形资产是否披露
- [ ] 尚未办妥权属证书的无形资产是否披露
- [ ] 附注披露分类是否与审定表、明细表一致

## risk_areas

### 高风险

1. **变动表不勾稽**：原值/累计摊销/减值准备三层滚动勾稽不成立，或与审定表/明细表不一致，属重大披露错误。
2. **内部研发形成披露缺失或不实**：未披露内部研发形成金额或与I2开发支出结转不一致，掩盖资本化政策问题。
3. **减值信息缺失**：本期大额减值未披露金额、原因及可收回金额确定方法。
4. **所有权受限未披露**：已抵押/质押的无形资产未披露，隐瞒担保事项。

### 中风险

1. **使用寿命披露不充分**：未披露使用寿命不确定项目的判断依据。
2. **摊销方法披露缺失**：未披露各类无形资产摊销方法。
3. **可比信息缺失**：仅列期末数未列期初可比数。

### 低风险

1. **披露格式不完全规范**：表格标题、列序不严格按编报规则。
2. **文字描述模板化**：会计政策描述照搬准则原文。
3. **数字精度不一致**。
