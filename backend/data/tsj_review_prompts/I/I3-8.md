# I3-8 复核公司减值测试过程及结论复核提示词

## 概述

本提示词针对复核公司商誉减值测试过程及结论底稿（I3-8）的复核，聚焦对被审计单位（或其聘请的评估机构）执行的商誉减值测试的独立复核：测试方法适当性、关键假设合理性、评估专家工作的利用、测试结论的评价。审计师须独立评价管理层减值测试的过程和结论，不得简单接受。

**法规依据：**
- 《企业会计准则第8号——资产减值》
- 《中国注册会计师审计准则第1301号——审计证据》
- 《中国注册会计师审计准则第1620号——利用专家的工作》

---

## tips

1. **独立评价而非接受**：审计师须独立评价管理层/评估机构减值测试的方法、假设、数据和结论，不得简单接受评估报告结论。
2. **测试方法适当性**：评价减值测试采用的方法（收益法/市场法/成本法）是否适当，DCF模型逻辑是否正确。
3. **关键假设复核**：独立复核收入增长率、折现率、永续增长率等关键假设的合理性（勾稽I3-7），与历史、行业、业绩承诺对比。
4. **利用评估专家工作**：若管理层聘请评估机构，须评价评估专家的胜任能力、独立性、客观性及工作结论（CAS1620）。
5. **数据基础核查**：减值测试使用的基础数据（历史财务数据、预算）须与账面记录、经批准的预算勾稽。
6. **结论评价与差异**：审计师须对减值测试结论形成独立判断，与管理层结论存在差异时须提出并评估调整。

---

## checklist

### 一、测试方法与专家工作

- [ ] 减值测试方法（收益法/市场法/成本法）是否适当
- [ ] DCF模型逻辑、公式是否正确
- [ ] 若聘请评估机构，评估专家胜任能力/独立性/客观性是否评价（CAS1620）
- [ ] 评估专家工作范围、假设、结论是否复核

### 二、关键假设与数据

- [ ] 收入增长率、折现率、永续增长率等关键假设是否独立复核（勾稽I3-7）
- [ ] 关键假设是否与历史业绩、行业趋势、业绩承诺对比
- [ ] 减值测试基础数据是否与账面记录、经批准预算勾稽
- [ ] 关键假设敏感性分析是否复核

### 三、结论评价

- [ ] 审计师是否对减值测试结论形成独立判断
- [ ] 与管理层结论差异是否提出并评估调整
- [ ] 减值测试结论是否与I3-6/I3-1一致
- [ ] 复核过程和结论是否充分留痕

## risk_areas

### 高风险

1. **简单接受评估结论**：审计师未独立评价即接受管理层/评估机构减值测试结论，未履行职业怀疑。
2. **关键假设未独立复核**：对乐观的收入/折现率假设未独立复核质疑。
3. **评估专家工作未评价**：未评价评估专家胜任能力/独立性即利用其结论。
4. **审计师独立结论缺失**：未对减值结论形成独立判断。

### 中风险

1. **测试方法适当性未评价**：未评价减值测试方法是否适当。
2. **基础数据未核查**：减值测试基础数据未与账面/预算勾稽。
3. **敏感性分析未复核**：未复核关键假设敏感性。

### 低风险

1. **复核过程记录不完整**。
2. **专家工作评价文档不充分**。
3. **与减值测试底稿勾稽索引缺失**。
