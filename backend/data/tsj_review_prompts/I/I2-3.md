# I2-3 开发支出调整分录复核提示词

## 概述

本提示词针对开发支出调整分录汇总表（I2-3）的复核，含账项调整（AJE）、重分类调整（RJE）及未调整错报评估。复核重点是不符合资本化条件的支出转费用化调整、结转无形资产调整、减值调整的证据充分性、借贷平衡及与I2-1审定表、试算平衡表1717科目的闭环勾稽。

**法规依据：**
- 《企业会计准则第6号——无形资产》
- 《企业会计准则第28号——会计政策、会计估计变更和差错更正》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **费用化调整是核心**：审计发现不符合资本化条件的支出，须调整转费用化（借研发费用/管理费用，贷开发支出），影响资产和损益。
2. **结转无形资产调整**：达到预定用途的开发项目结转无形资产（借无形资产，贷开发支出），须勾稽I1-2。
3. **减值调整**：开发支出减值须勾稽I2-15，借资产减值损失，贷开发支出减值准备。
4. **与I2-1勾稽**：审定表调整列金额须与I2-3已确认分录逐笔一致。
5. **前期差错处理**：前期错误资本化的研发支出更正须作为前期差错追溯重述，而非本期费用。
6. **TB回写**：调整须同步试算平衡表1717科目，避免双真源。

## checklist

### 一、调整证据与审批

- [ ] 费用化调整是否有资本化条件不满足的证据（勾稽I2-6）
- [ ] 结转无形资产调整是否有项目达到预定用途的证据
- [ ] 减值调整是否有I2-15减值测试支持
- [ ] 超重要性水平调整是否经适当审批
- [ ] 每笔调整分录借贷方是否平衡

### 二、与审定表及TB勾稽

- [ ] 调整金额是否完整反映到I2-1审定表调整列
- [ ] 审定数=未审数+AJE+RJE是否成立
- [ ] 调整后开发支出是否回写试算平衡表1717科目
- [ ] 结转无形资产调整是否勾稽I1-2
- [ ] 未调整错报是否与A13勾稽

### 三、调整性质

- [ ] 费用化调整计入科目是否正确（研发费用/管理费用）
- [ ] 前期错误资本化更正是否作为前期差错追溯重述
- [ ] RJE是否仅涉及列报未误含损益
- [ ] 调整原因说明是否可追溯至具体审计程序

## risk_areas

### 高风险

1. **费用化调整遗漏**：审计发现的不符合条件支出未调整转费用，虚增资产虚增利润。
2. **调整缺乏证据**：费用化/减值调整无I2-6/I2-15支持。
3. **前期差错作本期费用**：前期错误资本化更正作为本期费用而非追溯重述，掩盖前期错报。

### 中风险

1. **审定表与I2-3调整不一致**：调整遗漏或错录。
2. **减值调整方向错误**。
3. **未调整错报累计超阈值未处理**。

### 低风险

1. **分录摘要、科目编码不规范**。
2. **索引指向支持底稿不完整**。
3. **审计说明未概括调整性质**。

## 跨底稿勾稽

- I2-3 费用化调整 ↔ I2-6 资本化条件判断
- I2-3 减值调整 ↔ I2-15 减值准备测试
- I2-3 结转调整 ↔ I1-2 内部研发形成无形资产
- I2-3 已确认调整合计 ↔ I2-1 审定表调整列
- 调整后审定数 ↔ 试算平衡表 1717
