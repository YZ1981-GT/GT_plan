# I4-3 长期待摊费用调整分录复核提示词

## 概述

本提示词针对长期待摊费用调整分录汇总表（I4-3）的复核，含账项调整（AJE）、重分类调整（RJE）及未调整错报评估。复核重点是应费用化支出转出调整、补提/冲回摊销调整、无受益基础项目转销的证据充分性、借贷平衡及与I4-1审定表、试算平衡表1801科目的闭环勾稽。

**法规依据：**
- 《企业会计准则第30号——财务报表列报》
- 《企业会计准则第28号——会计政策、会计估计变更和差错更正》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **费用化调整**：审计发现不符合长期待摊条件的支出（应一次性费用化）须调整转出。
2. **摊销调整**：补提或冲回摊销须勾稽I4-6/I4-7测算。
3. **转销调整**：已无受益基础的长期待摊费用余额须转销计入当期损益。
4. **与I4-1勾稽**：审定表调整列金额须与I4-3已确认分录逐笔一致。
5. **区分本期与前期差错**：前期错误资本化或漏摊销的更正须区分本期调整与前期差错追溯重述。
6. **TB回写**：调整须同步试算平衡表1801科目。

---

## checklist

### 一、调整证据与审批

- [ ] 费用化调整是否有不符合长期待摊条件的证据
- [ ] 摊销补提/冲回是否有I4-6/I4-7测算支持
- [ ] 转销调整是否有无受益基础的证据
- [ ] 超重要性水平调整是否经适当审批
- [ ] 每笔调整分录借贷方是否平衡

### 二、与审定表及TB勾稽

- [ ] 调整金额是否完整反映到I4-1审定表调整列
- [ ] 审定数=未审数+AJE+RJE是否成立
- [ ] 调整后长期待摊费用是否回写试算平衡表1801科目
- [ ] 是否存在I4-3已编制但未纳入审定表的调整
- [ ] 未调整错报是否与A13勾稽

### 三、调整性质

- [ ] 费用化调整计入科目是否正确
- [ ] 前期错误更正是否作为前期差错追溯重述
- [ ] RJE是否仅涉及列报未误含损益
- [ ] 调整原因说明是否可追溯至具体审计程序

## risk_areas

### 高风险

1. **费用化调整遗漏**：应费用化支出未调整仍挂账，虚增资产虚增利润。
2. **转销遗漏**：无受益基础项目未转销。
3. **前期差错作本期处理**：前期错误资本化更正作为本期费用而非追溯重述。

### 中风险

1. **审定表与I4-3调整不一致**。
2. **摊销调整无测算支持**。
3. **未调整错报累计超阈值未处理**。

### 低风险

1. **分录摘要、科目编码不规范**。
2. **索引指向支持底稿不完整**。
3. **审计说明未概括调整性质**。

## 跨底稿勾稽

- I4-3 摊销调整 ↔ I4-6/I4-7 摊销测算
- I4-3 已确认调整合计 ↔ I4-1 审定表调整列
- I4-3 SUD ↔ A13 未调整错报汇总
- 调整后审定数 ↔ 试算平衡表 1801
