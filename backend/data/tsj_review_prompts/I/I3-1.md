# I3-1 商誉审定表复核提示词

## 概述

本提示词针对商誉审定表（I3-1）的复核，聚焦商誉的期初期末勾稽、试算平衡表1711科目核对、商誉减值准备的完整性及商誉不摊销原则的贯彻。商誉源自非同一控制下企业合并，不摊销但须每年减值测试，审定表须准确反映商誉原值与累计减值准备。

**法规依据：**
- 《企业会计准则第20号——企业合并》
- 《企业会计准则第8号——资产减值》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **商誉不摊销**：商誉不进行摊销，仅计提减值准备，审定表不得出现商誉摊销，出现即计量错误。
2. **期初承前**：期初商誉原值及累计减值准备须等于上年审定表期末审定数。
3. **试算平衡表核对**：审定表商誉原值须与试算平衡表1711商誉科目、减值准备与1712商誉减值准备科目审定数一致。
4. **商誉减值不可转回**：已确认的商誉减值损失在以后期间不得转回（CAS8），审定表减值准备只增不减（除处置外）。
5. **本期新增商誉须勾稽入账测算**：本期企业合并新增商誉须与I3-4入账价值测算勾稽，等于合并成本减可辨认净资产公允价值份额。
6. **减值须每年测试**：无论有无减值迹象，商誉每年均须减值测试（勾稽I3-6），减值金额须计入审定表。

## checklist

### 一、期初期末勾稽

- [ ] 期初商誉原值及累计减值准备是否等于上年审定表期末审定数
- [ ] 期末商誉原值=期初+本期合并新增−本期处置 是否成立
- [ ] 本期新增商誉是否与I3-4入账价值测算勾稽
- [ ] 期末减值准备=期初+本期减值−处置转出 是否成立
- [ ] 商誉是否未计提摊销

### 二、试算平衡表核对

- [ ] 审定表商誉原值是否与试算平衡表1711科目审定数一致
- [ ] 审定表商誉减值准备是否与试算平衡表1712科目审定数一致（贷方）
- [ ] 试算平衡表未审数、调整数与审定表对应列是否一致

### 三、审计调整与减值

- [ ] 本期商誉减值损失是否完整反映（勾稽I3-6）
- [ ] 调整分录借贷平衡，审定数=未审数+AJE+RJE是否成立
- [ ] 是否体现商誉减值不可转回
- [ ] 是否存在I3-3已编制但未纳入审定表的调整

### 四、列报

- [ ] 商誉是否在非流动资产单独列示
- [ ] 商誉减值损失是否计入资产减值损失
- [ ] 审定表分类是否与附注披露一致

## risk_areas

### 高风险

1. **商誉计提摊销**：对商誉计提摊销，违反CAS8/CAS20商誉不摊销原则。
2. **商誉减值转回**：将已确认商誉减值损失转回，违反减值不可转回原则。
3. **减值遗漏**：I3-6已测算的商誉减值未纳入审定表，虚增资产虚增利润。
4. **新增商誉与测算不符**：本期新增商誉与I3-4入账测算不一致。

### 中风险

1. **期初期末不勾稽**：期初与上年期末不一致。
2. **试算平衡表与审定表不一致**：1711/1712科目口径不一致。
3. **处置商誉结转不完整**：处置子公司时相关商誉未完整结转。

### 低风险

1. **审定表格式不规范**。
2. **交叉索引不完整**（未链接I3-4/I3-6）。
3. **变动说明不充分**。
