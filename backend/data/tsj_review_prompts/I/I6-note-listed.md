# I6-note-listed 研发费用附注披露复核提示词（上市公司）

## 概述

本提示词针对研发费用上市公司附注披露底稿（I6-note-listed）的复核，聚焦研发费用按性质的构成披露、研发投入总额及资本化/费用化结构、研发投入强度及重要研发项目披露的充分性。研发费用是上市公司创新能力的重要体现，证监会信息披露编报规则对研发投入披露有专门要求。

**法规依据：**
- 《企业会计准则第6号——无形资产》
- 《企业会计准则第30号——财务报表列报》
- 《公开发行证券的公司信息披露编报规则第15号》

---

## tips

1. **研发费用构成披露**：按性质（人员薪酬/直接投入/折旧摊销/委外/其他）披露研发费用构成，各项合计须等于研发费用总额。
2. **研发投入总额及结构**：披露本期研发投入总额、费用化金额、资本化金额及资本化率，反映研发投入及资本化政策（勾稽I2/I6-1）。
3. **研发投入强度**：披露研发投入占营业收入比例（研发投入强度），是上市公司关键披露指标。
4. **重要研发项目**：重要研发项目的进展、投入等信息（上市公司重点关注）。
5. **加计扣除相关**：研发费用加计扣除对所得税的影响可在所得税附注体现（勾稽N）。
6. **附注与审定表勾稽**：附注研发费用总额须等于I6-1审定数，各构成与I6-2明细表勾稽。

## checklist

### 一、构成与结构披露

- [ ] 研发费用是否按性质分类披露构成（人员薪酬/直接投入/折旧摊销/委外/其他）
- [ ] 各构成合计是否等于研发费用总额及I6-1审定数
- [ ] 是否披露研发投入总额、费用化金额、资本化金额及资本化率
- [ ] 费用化金额是否与I6-1勾稽，资本化金额是否与I2勾稽
- [ ] 是否同时列示本期数和上期数（可比信息）

### 二、投入强度与项目

- [ ] 是否披露研发投入占营业收入比例（研发投入强度）
- [ ] 重要研发项目的进展/投入是否披露
- [ ] 研发投入趋势变动是否合理

### 三、勾稽与一致性

- [ ] 研发费用构成是否与I6-2明细表勾稽
- [ ] 费用化/资本化划分披露是否与实际一致
- [ ] 附注披露分类是否与审定表一致

## risk_areas

### 高风险

1. **构成不勾稽**：研发费用构成合计与总额/审定表不一致。
2. **资本化率披露不实**：费用化/资本化结构披露与实际不符，掩盖过度资本化。
3. **研发投入强度不实**：研发投入强度披露与实际不符（虚增研发投入）。

### 中风险

1. **构成分类不完整**：未按性质完整披露构成。
2. **重要项目信息缺失**。
3. **可比信息缺失**。

### 低风险

1. **披露格式不完全规范**。
2. **文字描述模板化**。
3. **数字精度不一致**。
