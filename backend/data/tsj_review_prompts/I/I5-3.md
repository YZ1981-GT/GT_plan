# I5-3 其他非流动资产调整分录复核提示词

## 概述

本提示词针对其他非流动资产调整分录汇总表（I5-3）的复核，含账项调整（AJE）、重分类调整（RJE）及未调整错报评估。复核重点是性质重分类调整（转入具体资产科目）、一年内到期部分重分类、减值/转销调整的证据充分性、借贷平衡及与I5-1审定表、试算平衡表1911科目的闭环勾稽。

**法规依据：**
- 《企业会计准则第30号——财务报表列报》
- 《企业会计准则第28号——会计政策、会计估计变更和差错更正》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **性质重分类是核心**：将不当计入其他非流动资产、应归入具体资产科目（固定资产/无形资产/长期股权投资等）的项目重分类转出。
2. **一年内到期重分类**：变现/耗用期缩短至一年内的项目重分类至流动资产。
3. **减值/转销调整**：存在减值或无价值的项目须计提减值或转销。
4. **与I5-1勾稽**：审定表调整列金额须与I5-3已确认分录逐笔一致。
5. **区分本期与前期差错**：前期错误归集的更正须区分本期调整与前期差错追溯重述。
6. **TB回写**：调整须同步试算平衡表1911科目。

## checklist

### 一、调整证据与审批

- [ ] 性质重分类是否有资产性质判断证据
- [ ] 一年内到期重分类是否有变现/耗用期证据
- [ ] 减值/转销调整是否有减值/无价值证据
- [ ] 超重要性水平调整是否经适当审批
- [ ] 每笔调整分录借贷方是否平衡

### 二、与审定表及TB勾稽

- [ ] 调整金额是否完整反映到I5-1审定表调整列
- [ ] 审定数=未审数+AJE+RJE是否成立
- [ ] 调整后其他非流动资产是否回写试算平衡表1911科目
- [ ] 重分类转入具体资产科目是否勾稽相应底稿
- [ ] 未调整错报是否与A13勾稽

### 三、调整性质

- [ ] 性质重分类（RJE）是否仅涉及列报未误含损益
- [ ] 前期错误归集更正是否作为前期差错追溯重述
- [ ] 减值/转销调整计入科目是否正确
- [ ] 调整原因说明是否可追溯至具体审计程序

## risk_areas

### 高风险

1. **性质重分类遗漏**：应转出至具体资产科目的项目未重分类，掩盖资产性质。
2. **减值/转销遗漏**：无价值项目未转销，虚增资产。
3. **前期差错作本期处理**：前期错误归集更正作为本期而非追溯重述。

### 中风险

1. **审定表与I5-3调整不一致**。
2. **一年内到期重分类遗漏**。
3. **未调整错报累计超阈值未处理**。

### 低风险

1. **分录摘要、科目编码不规范**。
2. **索引指向支持底稿不完整**。
3. **审计说明未概括调整性质**。

## 跨底稿勾稽

- I5-3 性质重分类 ↔ 相应资产科目底稿
- I5-3 已确认调整合计 ↔ I5-1 审定表调整列
- I5-3 SUD ↔ A13 未调整错报汇总
- 调整后审定数 ↔ 试算平衡表 1911
