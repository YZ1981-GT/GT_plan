# I4-note-listed 长期待摊费用附注披露复核提示词（上市公司）

## 概述

本提示词针对长期待摊费用上市公司附注披露底稿（I4-note-listed）的复核，聚焦长期待摊费用按项目分类的变动情况披露、摊销期限及方法披露、无法计入资产的支出说明及余额合理性披露的充分性。长期待摊费用金额通常不重大，但其构成和摊销政策的透明度影响报表使用者对资产质量的判断。

**法规依据：**
- 《企业会计准则第30号——财务报表列报》
- 《公开发行证券的公司信息披露编报规则第15号》

---

## tips

1. **变动情况披露**：披露长期待摊费用各项目期初、本期增加、本期摊销、本期其他减少、期末，勾稽须成立。
2. **按项目分类**：按经营租入固定资产改良支出、装修费、其他长期待摊费用等分类披露。
3. **摊销期限披露**：披露各类长期待摊费用的摊销期限。
4. **重大项目说明**：金额重大的长期待摊费用项目须说明性质、形成原因及摊销期。
5. **附注与审定表勾稽**：附注长期待摊费用期末余额须等于I4-1审定数，各项目与I4-2明细表勾稽。
6. **可比信息**：同时列示期末数和期初数。

---

## checklist

### 一、变动与分类披露

- [ ] 长期待摊费用变动表是否完整（期初/增加/摊销/其他减少/期末）
- [ ] 是否按项目/性质分类披露
- [ ] 各项目期末余额合计是否等于I4-1审定数
- [ ] 各项目是否与I4-2明细表勾稽
- [ ] 是否同时列示期末数和期初数

### 二、摊销与说明

- [ ] 是否披露各类长期待摊费用的摊销期限
- [ ] 金额重大项目是否说明性质、形成原因、摊销期
- [ ] 本期摊销去向（成本/费用）是否合理
- [ ] 无法计入资产的支出性质是否清晰

### 三、合理性

- [ ] 长期挂账或摊销期异常项目是否说明
- [ ] 附注披露分类是否与审定表、明细表一致

## risk_areas

### 高风险

1. **变动表不勾稽**：变动勾稽不成立或与审定表/明细表不一致。
2. **重大项目未说明**：金额重大项目未说明性质和形成原因。

### 中风险

1. **摊销期限披露缺失**：未披露各类长期待摊费用摊销期限。
2. **分类披露不完整**：未按项目分类披露。
3. **可比信息缺失**。

### 低风险

1. **披露格式不完全规范**。
2. **项目说明模板化**。
3. **数字精度不一致**。
