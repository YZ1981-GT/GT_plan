# I3-4 商誉入账价值测算表复核提示词

## 概述

本提示词针对商誉入账价值测算表（I3-4）的复核，聚焦非同一控制下企业合并中商誉初始计量的准确性：合并成本的确定、购买日可辨认净资产公允价值的评估、合并成本大于可辨认净资产公允价值份额的差额确认为商誉。商誉初始计量是后续减值测试的基础，计量错误将导致商誉虚增或漏计。

**法规依据：**
- 《企业会计准则第20号——企业合并》
- 《企业会计准则第8号——资产减值》

---

## tips

1. **商誉=合并成本−可辨认净资产公允价值份额**：非同一控制下企业合并，合并成本大于取得的被购买方可辨认净资产公允价值份额的差额确认为商誉。
2. **合并成本构成**：合并成本为购买方付出对价（现金/非现金资产/发行权益工具/承担债务）的公允价值，或有对价按公允价值计入。
3. **可辨认净资产公允价值须评估**：购买日被购买方可辨认资产、负债须按公允价值计量（通常依赖评估报告），不得按账面价值。
4. **可辨认无形资产单独确认**：合并中被购买方符合确认条件的可辨认无形资产（专利/商标/客户关系等）须单独确认，不计入商誉。
5. **负商誉计入当期损益**：合并成本小于可辨认净资产公允价值份额的（负商誉），经复核后差额计入营业外收入。
6. **份额按持股比例**：可辨认净资产公允价值份额=可辨认净资产公允价值×购买方持股比例。

---

## checklist

### 一、合并成本确定

- [ ] 合并成本是否按付出对价的公允价值确定
- [ ] 现金/非现金资产/权益工具对价公允价值是否准确
- [ ] 或有对价是否按购买日公允价值计入合并成本
- [ ] 合并相关费用是否正确处理（计入当期损益而非合并成本）

### 二、可辨认净资产公允价值

- [ ] 购买日可辨认资产、负债是否按公允价值计量
- [ ] 公允价值评估是否有评估报告支持
- [ ] 可辨认无形资产（专利/商标/客户关系）是否单独确认
- [ ] 是否将本应单独确认的无形资产计入商誉
- [ ] 或有负债是否按公允价值确认

### 三、商誉确认

- [ ] 商誉=合并成本−可辨认净资产公允价值×持股比例 是否正确
- [ ] 持股比例是否准确
- [ ] 负商誉是否经复核后计入营业外收入
- [ ] 商誉入账金额是否与I3-1审定表、I3-2明细表勾稽

## risk_areas

### 高风险

1. **可辨认净资产公允价值低估虚增商誉**：将可辨认资产/无形资产公允价值低估，导致差额（商誉）虚增。
2. **可辨认无形资产计入商誉**：本应单独确认的无形资产（客户关系/技术）计入商誉，规避后续摊销。
3. **合并成本虚高**：或有对价或非现金对价公允价值高估，虚增合并成本和商誉。
4. **负商誉未计入损益**：合并成本小于净资产份额未确认营业外收入。

### 中风险

1. **持股比例错误**：可辨认净资产份额计算持股比例错误。
2. **合并费用计入合并成本**：合并相关中介费用误计入合并成本。
3. **公允价值评估依据不足**：可辨认净资产公允价值缺乏评估报告支持。

### 低风险

1. **测算过程记录不完整**。
2. **可辨认资产明细列示不规范**。
3. **与审定表/明细表勾稽索引缺失**。
