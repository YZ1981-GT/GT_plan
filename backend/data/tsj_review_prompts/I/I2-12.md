# I2-12 开发支出针对性检查复核提示词

## 概述

本提示词针对开发支出针对性检查底稿（I2-12）的复核，聚焦针对识别的重大错报风险实施的针对性程序，包括重大开发项目资本化的深度核查、可疑资本化的追查、失败项目处理及关键判断的复核。针对性检查是对高风险开发支出项目的专项审计程序。

**法规依据：**
- 《企业会计准则第6号——无形资产》
- 《中国注册会计师审计准则第1314号——审计抽样》

---

## tips

1. **针对性程序匹配风险**：检查程序须针对识别的具体风险（过度资本化、失败项目未处理、关联方委外虚增等）设计。
2. **重大项目深度核查**：金额重大的开发项目须深度核查五条件满足证据、投入构成真实性、成果进展。
3. **失败/搁置项目重点关注**：已失败、搁置或长期无进展的项目须核查是否及时费用化或减值。
4. **可疑资本化追查**：期末突增资本化、临近扭亏为盈的资本化、与业绩考核挂钩的资本化须追查动机和依据。
5. **关键判断复核**：资本化时点、使用寿命、减值等关键管理层判断须独立复核合理性。
6. **勾稽核心底稿**：针对性检查结论须与I2-6资本化判断、I2-15减值测试、I2-2明细表勾稽。

---

## checklist

### 一、针对性程序设计

- [ ] 检查程序是否针对识别的具体重大错报风险
- [ ] 重大开发项目是否纳入深度核查范围
- [ ] 高风险特征项目（期末突增/关联方/失败）是否重点覆盖
- [ ] 检查程序是否充分应对过度资本化风险

### 二、重大及可疑项目核查

- [ ] 重大项目五条件满足证据是否深度核查
- [ ] 重大项目投入构成真实性是否核查（勾稽I2-7/I2-8/I2-9）
- [ ] 失败/搁置项目是否核查是否及时费用化/减值
- [ ] 期末突增或业绩敏感期资本化是否追查动机

### 三、关键判断复核

- [ ] 资本化时点判断合理性是否独立复核（勾稽I2-6）
- [ ] 减值判断合理性是否独立复核（勾稽I2-15）
- [ ] 使用寿命判断是否复核
- [ ] 针对性检查结论是否与相关底稿勾稽

## risk_areas

### 高风险

1. **过度资本化未识别**：针对性程序未能发现管理层过度资本化的迹象。
2. **失败项目未处理**：已失败或长期无进展项目未费用化/减值，虚增资产。
3. **业绩驱动资本化**：临近扭亏或业绩考核期突增资本化未追查动机。

### 中风险

1. **针对性程序不匹配风险**：检查程序未针对识别的具体风险设计。
2. **重大项目核查深度不足**：重大项目仅表面核查未深入。
3. **关键判断复核缺失**：资本化/减值判断未独立复核。

### 低风险

1. **检查记录不完整**。
2. **针对性程序与风险评估勾稽索引缺失**。
3. **检查结论表述不清晰**。
