# I6-5 研发费用截止测试（账→单据）复核提示词

## 概述

本提示词针对研发费用截止测试（由账面记录到原始单据，账→单）底稿（I6-5）的复核，聚焦资产负债表日前后研发费用的会计期间归属正确性，从账面记录追查至原始单据（领料单/工时/委外发票），验证是否存在跨期费用归集。截止测试确保研发费用归属于正确会计期间，防止跨期调节利润或加计扣除基数。

**法规依据：**
- 《企业会计准则第6号——无形资产》
- 《中国注册会计师审计准则第1314号——审计抽样》

---

## tips

1. **账到单据方向**：从账面研发费用记录出发，追查至原始单据（领料单/工时记录/委外发票），验证单据日期与入账期间一致。
2. **测试窗口覆盖跨期**：选取资产负债表日前后一定天数（如前后5天/10天）的研发费用记录测试。
3. **跨期费用识别**：期末研发费用对应单据若属下期，则本期费用多计（虚减利润/虚增加计扣除基数）。
4. **关注期末突增**：期末最后几天集中归集的研发费用须重点核查单据日期，警惕凑数满足加计扣除。
5. **加计扣除期间影响**：跨期归集影响加计扣除基数的所属年度，须评估税务影响。
6. **与I6-6互补**：I6-5（账→单）验证已入账费用的期间，I6-6（单→账）验证已发生费用是否遗漏入账，两者互补。

## checklist

### 一、测试设计

- [ ] 测试窗口是否覆盖资产负债表日前后合理天数
- [ ] 样本是否覆盖期末突增的研发费用
- [ ] 样本选取是否与风险评估匹配

### 二、账到单据核查

- [ ] 账面研发费用记录是否逐笔追查至原始单据
- [ ] 单据日期（领料/工时/委外发票）与入账期间是否一致
- [ ] 是否存在期末归集但单据属下期（费用提前）
- [ ] 期末突增费用单据日期是否重点核查

### 三、结果处理

- [ ] 发现的跨期费用是否标注并评估调整
- [ ] 跨期金额是否与I6-3调整分录勾稽
- [ ] 跨期对加计扣除基数所属年度的影响是否评估
- [ ] 截止测试结论是否与审定表勾稽

## risk_areas

### 高风险

1. **费用提前虚减利润**：期末归集的研发费用对应单据属下期，本期多计费用虚减利润。
2. **凑数满足加计扣除**：期末集中归集研发费用满足加计扣除或研发投入指标，单据期间不符。

### 中风险

1. **测试窗口不足**：窗口天数过短未覆盖跨期。
2. **单据日期核对不严**：仅核对金额未核对单据日期。
3. **跨期金额未评估调整**。

### 低风险

1. **样本选取记录不完整**。
2. **截止测试记录格式不规范**。
3. **与调整分录勾稽索引缺失**。
