# I3-6 商誉减值测试复核提示词（资产组分摊）

## 概述

本提示词针对商誉减值测试底稿（I3-6）的复核，聚焦商誉分摊至资产组/资产组组合的合理性、包含商誉的资产组账面价值的完整性、可收回金额的确定、减值损失的确认顺序（先冲减商誉后按比例冲减其他资产）。商誉每年均须减值测试，是CAS8的强制要求，也是财务报表最重要的会计估计之一。

**法规依据：**
- 《企业会计准则第8号——资产减值》
- 《企业会计准则第20号——企业合并》

---

## tips

1. **每年强制测试**：无论有无减值迹象，商誉每年均须进行减值测试。
2. **商誉分摊至资产组**：商誉须分摊至能从合并协同效应受益的资产组/资产组组合，分摊方法合理且一致。
3. **资产组账面价值须包含商誉**：减值测试时资产组账面价值=资产组可辨认资产账面价值+分摊的商誉，须完整。
4. **少数股东权益商誉调整**：部分股权收购形成的商誉，测试时须将归属于少数股东的商誉包含在内（调整后账面价值）。
5. **减值损失确认顺序**：资产组减值损失先冲减分摊的商誉，商誉冲减完毕后按比例冲减资产组其他资产，其他资产不得减记至低于其可收回金额。
6. **可收回金额勾稽I3-7**：资产组可收回金额=公允价值减处置费用与使用价值孰高（勾稽I3-7），减值损失=账面价值−可收回金额。

## checklist

### 一、资产组认定与商誉分摊

- [ ] 是否对全部商誉执行年度减值测试（无论有无迹象）
- [ ] 商誉是否分摊至能从协同效应受益的资产组/资产组组合
- [ ] 商誉分摊方法是否合理且与上年一致
- [ ] 资产组认定是否与I3-2明细表一致

### 二、账面价值与可收回金额

- [ ] 资产组账面价值是否完整（可辨认资产账面价值+分摊商誉）
- [ ] 部分股权收购形成的商誉是否包含少数股东部分（调整后账面价值）
- [ ] 可收回金额是否取公允价值减处置费用与使用价值孰高（勾稽I3-7）
- [ ] 减值损失=资产组账面价值−可收回金额 是否正确

### 三、减值损失确认

- [ ] 减值损失是否先冲减分摊的商誉
- [ ] 商誉冲减后是否按比例冲减资产组其他资产
- [ ] 其他资产是否未减记至低于其可收回金额
- [ ] 减值损失是否计入资产减值损失并勾稽I3-1/I3-2
- [ ] 是否体现商誉减值不可转回

## risk_areas

### 高风险

1. **未执行年度减值测试**：商誉未每年强制减值测试。
2. **资产组账面价值不完整**：未包含全部分摊商誉或少数股东商誉，低估账面价值规避减值。
3. **可收回金额虚高**：资产组可收回金额虚高（勾稽I3-7假设乐观），规避或少计减值。
4. **减值确认顺序错误**：未先冲减商誉即冲减其他资产，或未确认应有减值。

### 中风险

1. **商誉分摊不合理**：分摊至不受益资产组或方法不一致。
2. **资产组认定不当**：资产组范围不当扩大稀释减值。
3. **少数股东商誉调整错误**：部分收购商誉减值测试调整错误。

### 低风险

1. **减值测试记录不完整**。
2. **资产组账面价值明细列示不规范**。
3. **与可收回金额测试勾稽索引缺失**。
