# K1-3 其他应收款坏账准备明细表复核提示词

## 概述

本提示词针对其他应收款坏账准备明细表（K1-3，坏账准备科目，资产备抵类贷方）的复核，聚焦：坏账准备变动完整性、期初期末勾稽、本期计提与信用减值损失核对、单项与组合计提分列准确性。坏账准备明细表按对象/组合列示减值准备的期初、计提、转回、核销、期末变动，是审定表 K1-1 净额确定、K1-8 坏账测算结果落地、附注坏账变动披露的枢纽。

**法规依据：**
- 《企业会计准则第22号——金融工具确认和计量》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **坏账准备变动表须五要素完整且勾稽**：期初余额+本期计提−本期转回−本期核销±其他变动=期末余额，任一勾稽关系不成立即为重大错误。
2. **本期计提须与利润表信用减值损失核对**：K1-3 本期计提（转回）净额应与利润表"信用减值损失"中其他应收款部分一致，差异须解释。
3. **单项计提与组合计提须分列并与 K1-8 测算一致**：明细表须区分单项认定和账龄/风险组合计提，各自期末余额须与 K1-8 坏账测算结果逐项勾稽。
4. **核销须有充分依据与审批**：本期核销金额须有核销证据（债务人破产/清算/逾期无法收回证明）和适当层级审批，核销依据不足属高风险，与 K1-9 核销检查交叉验证。
5. **坏账准备期末余额驱动净额与披露**：期末坏账准备=其他应收款账面余额−账面价值（净额），须与审定表 K1-1 净额列勾稽，并支撑附注坏账变动披露。
6. **转回须有客观证据支持**：本期转回（信用风险下降/已收回）须有客观依据，警惕通过无据转回冲减费用调节利润。

## checklist

### 一、变动完整性与勾稽

- [ ] 坏账准备变动是否五要素完整（期初/计提/转回/核销/期末）
- [ ] 期初+计提−转回−核销±其他=期末，逐行勾稽是否成立
- [ ] 期初坏账准备是否与上年审定期末数衔接
- [ ] 期末坏账准备合计是否与审定表 K1-1 减值列一致
- [ ] 期末净额（余额−准备）是否与 K1-1 净额勾稽

### 二、计提与损益核对

- [ ] 本期计提（转回）净额是否与利润表信用减值损失中其他应收款部分一致
- [ ] 单项计提与组合计提是否分列，各期末余额是否与 K1-8 测算一致
- [ ] 本期计提金额是否有 K1-8 坏账测算结果支撑
- [ ] 组合计提比例变动是否有依据（迁徙率/历史损失率更新）

### 三、核销与转回

- [ ] 本期核销是否有充分依据（破产/清算/逾期证明）
- [ ] 核销是否经适当层级审批并留痕
- [ ] 核销金额是否与 K1-9 核销检查一致
- [ ] 本期转回是否有客观证据支持，无据转回是否已质疑

## risk_areas

### 高风险

1. **变动表勾稽不成立**：期初+计提−转回−核销≠期末，或与 K1-1/K1-8 数据不一致，属重大数据错误。
2. **无据核销掩盖损失**：核销缺乏证据或未经授权，虚减坏账准备余额、粉饰资产质量。
3. **计提与损益不一致**：本期计提与利润表信用减值损失不符，存在少提/漏提或跨表汇总错误。

### 中风险

1. **单项/组合未分列**：单项认定与组合计提混列，无法与 K1-8 测算勾稽。
2. **无据转回调节利润**：本期转回缺乏信用风险下降或收回的客观证据。

### 低风险

1. **变动原因说明不足**：大额计提/核销/转回未附简要说明。
2. **交叉索引不完整**：与 K1-8/K1-9 及附注坏账变动表的引用标注不全。
