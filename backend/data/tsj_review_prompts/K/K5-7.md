# K5-7 预计负债检查表复核提示词

## 适用底稿
预计负债凭证级检查表（K5-7，科目 2701），聚焦样本选取方法合理性、计提/使用/转回凭证核对完整性、计提依据充分性、检查比例达标性及异常事项标注。

## tips

- 样本选取应覆盖本期计提、使用（实际支出）、转回三类发生额，高风险项目（大额计提、期末集中转回、无依据变动）纳入必选样本
- 凭证核对须验证计提有依据（历史赔付率测算/律师函/合同/董事会决议）、使用有实际支付凭证、转回有义务解除证据
- 检查比例应满足《中国注册会计师审计准则第1314号——审计抽样》要求，本期发生额检查比例=已检查金额÷本期发生额合计
- 每笔预计负债变动须能追溯至 CAS13 确认条件的判断依据，无依据的计提/转回须标注为异常
- 关注期末集中大额转回、无历史数据支撑的计提、长期挂账不动的僵尸余额等舞弊/差错信号
- 计提依据的充分性是本检查表的核心：产品质保须有历史赔付率、诉讼须有律师函、亏损合同须有测算表、重组须有正式计划
- 职业怀疑贯穿始终：对管理层利用预计负债"蓄水池"平滑利润保持警觉，记录质疑过程

## checklist

### 一、样本选取合理性（高风险）

- [ ] 样本选取方法是否与预计负债的重大错报风险相匹配
- [ ] 抽样方法是否符合 CAS1314 要求（统计/非统计抽样选择有据）
- [ ] 本期大额计提项目（超过重要性水平）是否 100% 全覆盖检查
- [ ] 期末集中大额转回、无依据变动是否纳入必选样本
- [ ] 抽样总体是否完整（涵盖计提/使用/转回三类发生额，未人为排除）
- [ ] 高风险类别（未决诉讼、亏损合同、重组义务）是否重点抽查

### 二、凭证核对与计提依据（高风险）

- [ ] 计提凭证是否附充分依据（历史赔付率测算/律师函/合同/董事会决议）
- [ ] 产品质保计提是否有历史赔付率和计提基数的支持性文件
- [ ] 未决诉讼计提是否与律师函（A 循环）评估结果一致
- [ ] 亏损性合同计提是否有不可避免成本超过预期利益的测算表
- [ ] 使用（实际支出）凭证是否附付款凭证/结算单据，冲减科目恰当
- [ ] 转回凭证是否附义务解除、重新估计或诉讼终结的支持性证据
- [ ] 是否存在无实际业务支持或无依据的计提/转回凭证

### 三、检查比例与异常标注（中风险）

- [ ] 本期计提发生额检查比例是否达到计划水平
- [ ] 本期使用/转回发生额检查比例是否达标
- [ ] 检查比例计算公式是否正确（分子=已检查金额，分母=本期发生额）
- [ ] 异常事项是否全部标注并记录异常类型（无依据计提/期末集中转回/金额异常/时间异常）
- [ ] 核对过程中发现的差异是否逐一追踪解决并评估是否形成调整（K5-3）

### 四、记录规范与追溯（低风险）

- [ ] 抽样工作底稿是否完整记录抽样参数（总体/置信水平/可容忍偏差/预计偏差）
- [ ] 样本选取过程是否可追溯（随机数种子/系统抽样间隔/选取依据）
- [ ] 凭证检查结果记录格式是否规范统一
- [ ] 底稿索引与交叉引用是否完整（关联 K5-1 审定表/K5-2 明细/K5-4/5/6 专项检查）

## risk_areas

### 高风险

- **计提依据缺失风险**：本期计提无历史赔付率、律师函、合同或正式计划等支持性证据，金额可靠性无法验证
- **无依据转回风险**：期末集中大额转回预计负债无义务解除依据，涉嫌利用"蓄水池"调节利润
- **样本选取偏差风险**：抽样未覆盖高风险类别或大额变动项目，样本不具代表性，无法支持审计结论
- **完整性遗漏风险**：凭证检查仅核对已入账项目，未通过合同/诉讼/担保搜寻应计提未计提的现时义务

### 中风险

- **检查比例不足风险**：实际检查比例低于计划水平，审计证据不充分
- **凭证核对深度不够风险**：仅核对金额而忽略计提依据的实质合理性（如历史赔付率口径、律师意见时效）
- **异常标注不充分风险**：无依据计提、期末集中转回、时间异常等交易未被识别和标注

### 低风险

- **记录不完整风险**：抽样参数、选取过程、核对结果的工作底稿记录不完整，影响复核可追溯性
- **索引缺失风险**：凭证检查底稿与审定表/明细表/专项检查底稿的交叉索引不完整
- **格式不规范风险**：检查结果记录格式不统一，影响汇总分析效率

## 法规依据

- 《中国注册会计师审计准则第1314号——审计抽样》：抽样设计、执行与评价
- 《中国注册会计师审计准则第1301号——审计证据》：证据充分性与适当性
- 《企业会计准则第13号——或有事项》：预计负债确认与计量
- 《中国注册会计师审计准则第1141号——财务报表审计中与舞弊相关的责任》：舞弊风险凭证核查
