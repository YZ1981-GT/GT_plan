# K8-8 销售费用凭证检查表复核提示词

## 概述

本提示词针对销售费用凭证级检查表（K8-8，科目 6601，损益类借方）的复核，聚焦：样本选取方法合理性、凭证核对完整性、检查比例达标性、异常凭证标注充分性。检查表逐笔核对销售费用记账凭证与原始支持性文件（发票/运费单/审批单/合同/银行回单），验证费用发生的真实性、准确性、期间归属与合规性；损益类费用仅设借方检查比例（本期发生额）。

**法规依据：**
- 《中国注册会计师审计准则第1314号——审计抽样》
- 《中国注册会计师审计准则第1301号——审计证据》
- 《中国注册会计师审计准则第1141号——财务报表审计中与舞弊相关的责任》

---

## tips

1. **样本选取匹配风险**：抽样方法应与识别的重大错报风险匹配，大额费用、业务招待费、佣金手续费、关联方费用、年末集中列支凭证应纳入必选样本（CAS1314）。
2. **核对五要素**：记账凭证须核对①原始单据齐全（发票/运费单/审批单/合同）②账记相符③账务处理正确（科目/金额）④会计期间恰当⑤其他核对事项，逐项勾选留痕。
3. **仅借方检查比例**：销售费用为损益类，检查比例=已检查金额÷本期借方发生额（K8-2 审定发生额），无期末余额检查比例；比例低于计划（如<30%）须扩样。
4. **发生认定为核心**：核对重点在费用是否真实发生（有对应服务/货物流转与审批），警惕无实质业务支持的往来款以费用名义列支。
5. **异常凭证标注**：金额异常（整数/恰好低于审批权限）、时间异常（节假日/年末集中）、对手方异常（新供应商首笔大额）、业务逻辑异常（无合同的大额广告费）须标注异常类型。
6. **异常→下游联动**：检查发现的异常凭证/费用应推送至 A13 未更正错报汇总或 K8-3 调整分录，形成闭环。

## checklist

### 一、样本选取合理性

- [ ] 样本选取方法是否与识别的重大错报风险相匹配
- [ ] 抽样方法是否符合 CAS1314（统计/非统计抽样选择有据）
- [ ] 大额费用（超重要性水平）是否纳入必选样本
- [ ] 业务招待费/佣金手续费/关联方费用/年末集中列支是否纳入必选样本
- [ ] 抽样总体是否完整（本期借方发生额），是否排除了不应排除的项目

### 二、凭证核对完整性

- [ ] 记账凭证是否核对原始单据齐全性（发票/运费单/审批单/合同/回单）
- [ ] 账记是否相符（记账金额与原始单据一致）
- [ ] 账务处理是否正确（费用科目、明细项目、金额）
- [ ] 是否记入恰当会计期间（结合截止）
- [ ] 费用支出是否经恰当授权审批（审批权限、审批人）
- [ ] 是否存在无实质业务支持的费用列支

### 三、检查比例与异常标注

- [ ] 检查比例=已检查金额÷本期借方发生额，计算是否正确
- [ ] 检查比例是否达到计划水平，不达标是否扩样并说明
- [ ] 异常凭证是否全部标注异常类型（金额/时间/对手方/业务逻辑）
- [ ] 异常凭证是否推送 A13 错报或 K8-3 调整分录
- [ ] 检查结论及审计说明是否明确记录

## risk_areas

### 高风险

1. **虚构费用支出**：无真实服务/货物流转的广告费/咨询费/佣金凭证用于虚增费用或套取资金，缺乏原始单据支撑。
2. **样本未覆盖高风险**：业务招待费、佣金、关联方、年末集中列支等高风险费用未纳入必选样本。
3. **费用发生认定失败**：账内费用无对应审批与业务证据，发生认定不成立。
4. **截止性错误未识别**：年末集中列支费用凭证未结合截止判断期间归属。

### 中风险

1. **检查比例不足**：实际检查比例低于计划，审计证据不充分。
2. **审批越权**：费用支出超越审批权限或审批链不完整。
3. **异常凭证未联动**：识别异常但未推送错报或调整，未形成闭环。

### 低风险

1. **核对记录不完整**：五要素勾选、异常说明记录不全。
2. **索引缺失**：与审定表/明细表/合同检查底稿的交叉索引不完整。
