# K6-3 持有待售调整分录复核提示词

## 适用底稿
持有待售调整分录汇总表（K6-3），含账项调整（AJE）、重分类调整（RJE）及未调整错报（SUD）评估，是持有待售审定数（K6-1）链路的关键环节。

## 概述

K6-3 承载对持有待售科目（1481/2605）识别出的错报调整。复核须验证：每笔调整有充分证据、借贷平衡、完整反映至审定表 K6-1、SUD 评估符合重要性水平要求。持有待售调整的典型情形包括：将符合 CAS42 条件的非流动资产重分类至持有待售（RJE）、按孰低计量补提减值（AJE）、将不再满足条件的资产转回原类别并补提折旧（AJE+RJE）、以及处置组资产负债的重分类。

---

## tips

1. **AJE 与 RJE 区分**：AJE 影响资产账面价值及损益（如补提减值、补提折旧）；RJE 仅影响列报（如非流动资产重分类至持有待售、处置组资产负债列示），持有待售的分类本身多为 RJE，但孰低减值为 AJE。
2. **与 K6-1 逐笔勾稽**：审定表调整列金额须与 K6-3 已确认分录逐笔一致，资产（1481）与负债（2605）分别核对。
3. **重分类调整须有 CAS42 分类条件证据**：将资产重分类至持有待售的 RJE，须附董事会决议、销售协议或买方意向等分类条件满足证据。
4. **减值调整须有孰低计量测算**：按公允价值减出售费用孰低补提减值的 AJE，须附估值报告和孰低计量测算（与 K6-5/K6-6 勾稽）。
5. **不再满足条件的转回调整须补提折旧**：将资产转出持有待售的调整，须补提持有待售期间应计提而未计提的折旧/摊销（AJE），并按孰低计量确认账面价值。
6. **TB 回写**：确认调整已同步试算平衡表 1481/2605 科目，避免"底稿已调、TB 未更"的双真源不一致。

## checklist

### 一、账项调整（AJE）证据与授权（高风险）

- [ ] 所有 AJE 是否有充分审计证据（估值报告、孰低测算、折旧补提计算）
- [ ] 补提减值的调整是否有公允价值减出售费用的孰低计量依据
- [ ] 转出持有待售补提折旧的调整是否计算正确
- [ ] AJE 是否经适当层级审批（超重要性水平须合伙人知悉）
- [ ] 每笔调整分录借贷方是否完全平衡
- [ ] 调整金额是否完整反映到 K6-1 审定表对应调整列（资产/负债分别）
- [ ] 是否存在通过高估公允价值规避减值调整

### 二、重分类调整（RJE）与SUD（中风险）

- [ ] 非流动资产重分类至持有待售的 RJE 是否有 CAS42 分类条件证据
- [ ] 处置组资产负债的列示重分类是否正确（1481 资产/2605 负债）
- [ ] RJE 是否仅涉及列报未影响损益
- [ ] 未调整错报累计是否超过整体重要性水平（须评估并与 A13 勾稽）
- [ ] 跨期调整是否正确区分本期错报与前期差错更正

### 三、记录规范与追溯（低风险）

- [ ] 调整原因说明是否清晰可追溯至具体审计程序或底稿
- [ ] 调整分录编号是否连续，删除后重号风险是否可控
- [ ] 索引是否指向 K6-2 明细、K6-4 初始确认、K6-5/K6-6 减值测试、K6-7 转出检查
- [ ] 审计说明/结论是否概括调整性质与剩余风险

## risk_areas

### 高风险

1. **减值调整缺乏依据或未经授权**：补提减值的调整无孰低计量测算/估值报告支撑，或未经适当层级审批。
2. **应重分类未重分类**：符合 CAS42 条件的资产未重分类至持有待售，或不满足条件的错误列入而未调整转回。
3. **审定表与 K6-3 调整金额不一致**：调整未完整反映至 K6-1，或 TB（1481/2605）未同步回写。

### 中风险

1. **RJE 误含损益影响**：本应仅列报的重分类调整错误影响了损益。
2. **转出未补提折旧**：资产转出持有待售的调整遗漏补提持有待售期间的折旧/摊销。
3. **跨期调整分类错误**：本期错报与前期差错更正混淆。

### 低风险

1. **编号、格式、索引不规范**：调整分录摘要、科目编码、交叉索引标注不完整。
2. **调整说明过于简略**：未充分说明调整的判断依据和剩余风险。

## 跨底稿勾稽

- K6-3 已确认 AJE/RJE 合计 ↔ K6-1 审定表调整列（1481/2605 分别）
- K6-3 SUD ↔ A13 未调整错报汇总
- 调整后审定数 ↔ 试算平衡表 1481/2605 科目
- 减值调整依据 ↔ K6-5 减值测试 / K6-6 处置组减值 / K11 资产减值损失
