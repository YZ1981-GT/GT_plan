# K6-1 持有待售审定表复核提示词

## 概述

本提示词针对持有待售审定表（K6-1，科目 1481 持有待售资产 / 2605 持有待售负债，取期末余额）的复核。聚焦：期初期末勾稽、试算表核对、CAS42 持有待售分类条件、以账面价值与公允价值减去出售费用孰低计量、减值确认。核心风险为分类条件不满足仍列持有待售、孰低计量减值计提不足。

**法规依据：**
- 《企业会计准则第42号——持有待售的非流动资产、处置组和终止经营》
- 《企业会计准则第8号——资产减值》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **资产/负债分区取"期末余额"**：1481 资产、2605 负债分别核对；审定数=期初+增加−减少/处置±调整。
2. **期初期末勾稽**：期初审定数=上年期末审定数；审定合计（账面价值）=明细表 K6-2 账面价值合计（K6-2-detail-book-value-total）。
3. **试算表核对**：1481/2605 审定余额分别与试算表一致。
4. **CAS42 分类条件**：可立即出售+出售极可能发生（已作决议、已签协议/找到买方、一年内完成），条件不满足不得分类为持有待售。
5. **孰低计量**：按"账面价值"与"公允价值减去出售费用"孰低计量，差额确认减值（K6-1 减值应与 K11 资产减值/处置损益勾稽）。
6. **闭环**：审定↔K6-2 明细↔试算表 1481/2605↔减值测算↔附注/终止经营披露。

## checklist

### 一、期初期末勾稽与试算表核对

- [ ] 期初审定数是否等于上年期末审定数
- [ ] 审定数=期初+增加−减少/处置±调整 是否正确
- [ ] 资产审定合计（账面价值）是否与明细表 K6-2 合计一致
- [ ] 1481/2605 审定余额是否分别与试算表一致

### 二、分类条件与计量

- [ ] 各处置组/资产是否满足 CAS42 持有待售分类条件（可立即出售+极可能一年内完成）
- [ ] 是否存在不满足条件仍列持有待售（掩盖长期闲置/减值）
- [ ] 是否按账面价值与公允价值减出售费用孰低计量
- [ ] 孰低产生的减值是否足额确认，与 K11/处置损益勾稽
- [ ] 划分为持有待售后是否停止计提折旧/摊销

### 三、审计调整与披露

- [ ] 已确认的账项/重分类调整是否完整反映
- [ ] 是否涉及终止经营，披露是否充分
- [ ] 调整分录借贷平衡、证据充分、经审批

## risk_areas

### 高风险

1. **分类条件不满足**：不符合 CAS42 条件仍列持有待售，掩盖闲置资产减值或规避折旧计提。
2. **减值计提不足**：未按孰低计量或公允价值/出售费用估计不当，少提减值。
3. **期初期末不勾稽 / 与试算表不一致**。

### 中风险

1. **停止折旧摊销未执行**：划分持有待售后仍计提折旧。
2. **终止经营披露不足**：涉及终止经营但披露不充分。
3. **审计调整遗漏**。

### 低风险

1. **格式与索引不规范**。
2. **项目说明不足**。
