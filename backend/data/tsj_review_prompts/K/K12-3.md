# K12-3 营业外收入调整分录复核提示词

## 适用底稿
营业外收入调整分录汇总表（K12-3，科目 6301），含账项调整（AJE）、重分类调整（RJE），回写审定表 K12-1，并推送 A13 未调整错报汇总。

## 概述

K12-3 是营业外收入审定链路的关键环节。营业外收入调整通常源于分类纠正（营业外收入↔其他收益 K10）、跨期利得的截止调整、无法支付款项转入依据不足的冲回、非经常性损益重分类等。复核须验证：每笔调整有证据、借贷平衡、完整回写 K12-1、未采纳调整正确推送 A13 并与重要性水平比较。

**法规依据：**
- 《企业会计准则第28号——会计政策、会计估计变更和差错更正》
- 《企业会计准则第30号——财务报表列报》
- 《中国注册会计师审计准则第1301号——审计证据》
- 《中国注册会计师审计准则第1324号——期后事项》

## tips

1. **AJE vs RJE**：冲回无依据利得、补记漏计利得、跨期利得截止调整影响损益属 AJE；营业外收入与其他收益（K10）之间、或利润表行次间的重分类属 RJE，不得以 RJE 掩盖损益错报。
2. **每笔调整须有证据**：冲回无法支付款项转入须有原始负债仍需支付的证据；补记利得须有收款/批准文件；分类调整须有无关性判断依据。
3. **借贷平衡与科目正确**：核对借贷相等，且调整对手方科目正确（如营业外收入↔其他收益、营业外收入↔其他应付款）。
4. **完整回写 K12-1**：每笔已确认调整金额须逐笔反映到审定表 K12-1 对应项目的 AJE/RJE 列。
5. **未采纳调整推送 A13**：管理层未接受的调整（如坚持将经常性利得计营业外收入）须作为未调整错报推送 A13，与重要性水平比较，并关注对营业利润/扣非利润的影响。
6. **关注分类调整对扣非利润的影响**：营业外收入↔其他收益的重分类会改变营业利润与非经常性损益金额，须评估对上市公司扣非披露的影响。

## checklist

### 高风险检查项

- [ ] 所有冲回/补记利得 AJE 是否有充分证据支持
- [ ] 每笔调整分录借贷方是否完全平衡
- [ ] 调整对手方科目是否正确（其他收益/其他应付款/资产处置等）
- [ ] 调整金额是否完整回写至 K12-1 审定表对应项目调整列
- [ ] 分类调整（营业外收入↔其他收益 K10）是否有无关性判断依据
- [ ] 管理层未采纳的调整是否已推送 A13 未调整错报
- [ ] 未调整错报累计是否超过整体重要性水平（须评估对意见的影响）

### 中风险检查项

- [ ] RJE 是否仅涉及列报/重分类，未影响损益总额
- [ ] 跨期利得调整是否正确区分本期与前期差错更正
- [ ] 分类调整对营业利润/扣非利润的影响是否评估
- [ ] 调整原因说明是否可追溯至具体审计程序
- [ ] 调整分录编号是否连续，与 A13 交叉索引是否完整
- [ ] 建议调整与已执行调整是否分别记录

### 低风险检查项

- [ ] 分录摘要、科目编码是否规范
- [ ] 索引是否指向 K12-2 明细表及 K12-4 检查表
- [ ] 审计说明/结论是否概括调整性质与剩余风险

## risk_areas

### 高风险

1. **分类调整缺乏依据**：营业外收入与其他收益重分类无无关性判断支持，扭曲营业利润。
2. **审定表与 K12-3 调整不勾稽**：已确认调整未完整回写 K12-1。
3. **未采纳错报未推送 A13**：管理层拒绝的调整未纳入未调整错报汇总，累计可能超重要性水平。
4. **借贷不平衡或科目错配**：调整对手方科目错误或借贷不等。

### 中风险

1. **RJE 误含损益影响**：以重分类名义调整实际影响营业外收入总额。
2. **跨期调整分类错误**：本期利得与前期差错更正混淆。

### 低风险

1. **编号、格式不规范**。
2. **索引指向不完整**。

## 跨底稿勾稽

- K12-3 已确认 AJE/RJE 合计 ↔ K12-1 审定表调整列
- K12-3 未采纳错报 ↔ A13 未调整错报汇总
- 调整后审定数 ↔ 试算平衡表 6301 科目
- 分类调整 ↔ 其他收益（K10）/其他应付款等对手方底稿
