# K6-4 持有待售初始确认检查复核提示词

## 概述

本提示词针对持有待售初始确认检查底稿（K6-4，科目 1481/2605）的复核。CAS42 对非流动资产（或处置组）划分为持有待售类别设定了严格条件，须同时满足"可立即出售"和"出售极可能发生"两大要件。复核聚焦：CAS42 分类条件的逐项判断、是否可在当前状况下立即出售、出售是否极可能在一年内完成（已作决议、已签协议/找到买方、价格合理）。核心风险为分类条件不满足仍列持有待售（掩盖长期闲置资产减值、规避折旧计提、粉饰资产结构）。

**法规依据：**
- 《企业会计准则第42号——持有待售的非流动资产、处置组和终止经营》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **两大要件缺一不可**："可立即出售"（在当前状况下即可出售，仅受出售此类资产的惯常和通常条款约束）与"出售极可能发生"须同时满足，任一不满足均不得划分为持有待售，须逐项判断留痕。
2. **"出售极可能发生"的具体标准须逐条核对**：包括（1）已就出售作出决议（董事会/有权机构批准）；（2）已与买方签订不可撤销的销售协议或积极寻找买方；（3）出售价格合理（与当前公允价值相称）；（4）预计出售在一年内完成；（5）相关行动表明计划不会重大改变或撤销。
3. **一年内完成的例外情形须审慎评估**：因不可控因素导致超过一年的，须评估是否仍符合例外条件（企业仍承诺出售计划），滥用例外条款长期挂账是常见规避手法。
4. **"可立即出售"须评估资产实际状态**：资产是否存在阻碍立即出售的障碍（如未完工、被抵押查封、需政府审批、租约未到期等），存在实质障碍即不满足"可立即出售"。
5. **分类判断须有客观证据支撑**：董事会决议、销售协议、买方意向书、挂牌/招标文件、评估报告等是分类条件满足的关键证据，仅有管理层意向而无客观行动证据不足以支持分类。
6. **划分后立即影响后续计量**：一旦确认符合持有待售条件，须立即按孰低计量（K6-5）并停止折旧摊销，因此初始确认判断错误将连锁影响减值和折旧处理。

## checklist

### 一、"可立即出售"条件判断（高风险）

- [ ] 【必检】资产是否在当前状况下即可出售（仅受惯常条款约束）
- [ ] 【必检】是否存在阻碍立即出售的实质障碍（未完工/抵押查封/待审批/租约未到期）
- [ ] 【必检】是否为处置组，处置组的构成（资产+直接相关负债）是否清晰界定
- [ ] 【条件检查：若需政府/监管审批】审批进展是否支持"可立即出售"判断
- [ ] 【风险检查】是否存在实际无法立即出售却判断为满足条件

### 二、"出售极可能发生"条件逐项判断（高风险）

- [ ] 【必检】是否已就出售作出决议（董事会/有权机构批准文件）
- [ ] 【必检】是否已签订不可撤销销售协议或已积极寻找买方（挂牌/招标/意向书）
- [ ] 【必检】拟出售价格是否合理（与当前公允价值相称，非明显偏离）
- [ ] 【必检】是否预计出售在一年内完成
- [ ] 【必检】相关行动是否表明出售计划不会重大改变或撤销
- [ ] 【条件检查：若预计超过一年】是否符合准则规定的例外情形（因不可控因素且仍承诺计划）
- [ ] 【风险检查】是否滥用一年期例外条款长期挂账持有待售

### 三、分类证据与后续影响（中风险）

- [ ] 【必检】分类判断是否有客观证据（决议/协议/意向书/评估报告）支撑
- [ ] 【必检】仅有管理层意向而无客观行动证据的是否不予分类
- [ ] 【必检】符合条件的是否自条件满足之日起立即按孰低计量并停止折旧（衔接 K6-5/K6-2）
- [ ] 【条件检查：若为拟分配给所有者的资产】是否满足可供立即分配且分配极可能条件
- [ ] 【风险检查】分类时点是否被人为提前/推迟以调节折旧或减值确认期间

## risk_areas

### 高风险

1. **分类条件不满足仍列持有待售**：不符合 CAS42 两大要件（可立即出售+极可能发生）仍划分为持有待售，掩盖长期闲置资产减值、规避折旧计提。
2. **滥用一年期例外条款长期挂账**：出售明显无法在一年内完成却援引例外条款持续列作持有待售，规避正常资产的折旧和减值处理。
3. **分类缺乏客观证据**：仅凭管理层出售意向而无董事会决议、销售协议、买方意向等客观行动证据即划分为持有待售。

### 中风险

1. **"可立即出售"障碍未识别**：存在抵押查封、待审批、未完工等实质障碍却判断为满足"可立即出售"条件。
2. **拟出售价格不合理**：拟出售价格明显偏离公允价值（过高导致出售无法实现，过低损害资产价值），影响"极可能发生"判断。
3. **分类时点操纵**：人为提前或推迟持有待售分类时点以调节折旧停止或减值确认的期间。

### 低风险

1. **格式与索引不规范**：条件判断记录、证据索引标注不完整。
2. **处置组构成说明不足**：处置组包含的资产和负债范围界定说明不充分。
