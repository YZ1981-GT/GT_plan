# K8-note-listed 销售费用附注披露复核提示词（上市公司）

## 概述

本提示词针对销售费用上市公司附注披露底稿（K8-note-listed，科目 6601）的复核，聚焦：按性质列示明细项目的完整性、本期/上期可比数据、与审定表的勾稽、关联方承担费用披露、以及证监会编报规则对销售费用披露的细化要求。销售费用附注是报表使用者理解企业销售投入结构与费用率的主要途径，披露须与利润表"销售费用"行、审定表 K8-1 完全勾稽。

**法规依据：**
- 《企业会计准则第30号——财务报表列报》
- 《企业会计准则第36号——关联方披露》
- 《公开发行证券的公司信息披露编报规则第15号——财务报告的一般规定》

## tips

1. **按性质列示明细项目**：附注须按费用性质分项列示销售费用（运输费/广告宣传费/职工薪酬/差旅费/业务招待费/仓储费/折旧摊销/其他），各项合计等于利润表销售费用金额。
2. **本期与上期可比列示**：每一明细项目须同时列示本期发生额与上期发生额，供报表使用者对比费用结构变化。
3. **与审定表/明细表闭环勾稽**：附注销售费用合计=审定表 K8-1 审定合计=明细表 K8-2 合计=利润表销售费用行，任一节点不一致属披露错误。
4. **重大变动须说明**：销售费用较上期重大变动（如广告费大增）应结合管理层讨论与分析（MD&A）说明原因，附注与 MD&A 口径须一致。
5. **关联方承担/分摊费用**：由关联方承担或向关联方支付的销售费用（如向关联方支付佣金/广告代理费）须在关联方交易附注单独披露、说明定价公允性。
6. **"其他"项目重大须细分**：若"其他"销售费用金额重大（如超过合计一定比例），须进一步细分或说明构成，不得笼统列示掩盖敏感支出。

## checklist

### 一、明细项目列示完整性

- [ ] 销售费用是否按费用性质分项列示（运输/广告/薪酬/差旅/招待/仓储/折旧摊销/其他）
- [ ] 各明细项目发生额合计是否等于利润表销售费用金额
- [ ] "其他"项目金额是否重大，如重大是否进一步细分或说明构成
- [ ] 敏感费用（业务招待费/佣金手续费）是否单独列示
- [ ] 明细项目口径是否与会计政策及明细表 K8-2 一致

### 二、可比信息与勾稽

- [ ] 每一明细项目是否同时列示本期数与上期数
- [ ] 附注销售费用合计是否与审定表 K8-1 审定合计一致
- [ ] 附注明细是否与明细表 K8-2 分项合计勾稽
- [ ] 上期数是否与上年经审计附注一致
- [ ] 销售费用披露是否与利润表"销售费用"行勾稽

### 三、变动说明与关联方披露

- [ ] 销售费用重大变动是否说明原因，附注与 MD&A 口径是否一致
- [ ] 向关联方支付/由关联方承担的销售费用是否在关联方交易附注单独披露
- [ ] 关联方费用交易的定价方式与公允性是否说明
- [ ] 是否披露与股份支付/以权益结算相关计入销售费用的金额（如适用）
- [ ] 政府补助冲减销售费用的情形是否披露（如适用）

## risk_areas

### 高风险

1. **附注合计与审定表/利润表不一致**：附注销售费用各项合计与 K8-1 审定数或利润表销售费用行不勾稽，属重大披露错误。
2. **明细项目分类不完整**：未按费用性质分项列示或漏列重大项目，不满足 CAS30 及编报规则要求。
3. **关联方费用未单独披露**：向关联方支付的佣金/广告代理费混入普通费用未单独列示，违反 CAS36。

### 中风险

1. **"其他"项目笼统列示**：金额重大的"其他"销售费用未细分，掩盖敏感支出。
2. **重大变动未说明**：销售费用大幅变动但附注/MD&A 未说明原因或口径不一致。
3. **可比信息缺失**：仅列本期数未列上期可比数据。

### 低风险

1. **披露格式不规范**：明细列示顺序、金额单位等格式细节未严格按编报规则。
2. **文字说明模板化**：费用变动说明照搬模板未结合企业实际。
