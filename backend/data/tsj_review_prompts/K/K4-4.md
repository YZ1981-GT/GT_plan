# K4-4 其他流动负债检查表复核提示词

## 概述

本提示词针对其他流动负债检查表（K4-4，凭证级检查，科目 2245）的复核，聚焦：样本选取充分性、凭证核对完整性、完整性（未入账负债/预提充分性）测试、检查比例与异常标注。其他流动负债首要认定是"完整性"，本检查表对本期发生额逐笔核对存在性/准确性，并重点验证预提费用充分性、待转销项税额准确性和未入账负债的完整性，是负债完整性和计价认定的直接证据。

**法规依据：**
- 《中国注册会计师审计准则第1314号——审计抽样》
- 《中国注册会计师审计准则第1301号——审计证据》
- 《中国注册会计师审计准则第1141号——财务报表审计中与舞弊相关的责任》

## tips

1. **样本选取须兼顾存在性与完整性**：已入账样本测存在性（贷方新增/借方支付真实），并须结合完整性测试（预提是否充分、待转销项税额是否漏挂、应付义务是否遗漏），高风险项（大额预提、待转销项税额、期末突增）须纳入必选。
2. **凭证核对须验证义务真实性与计价**：核对记账凭证与原始单据（预提依据/税务资料/合同/审批单），验证预提费用的义务基础与估计依据、待转销项税额与开票及纳税义务的对应关系。
3. **预提费用充分性是完整性核心**：核对预提项目是否有明确应付义务、预提金额是否充分（预提不足低估负债）或过度（预提过度调节利润），期后实际发生额可佐证预提合理性。
4. **待转销项税额准确性**：核对待转销项税额是否与已开票未确认收入对应，转销时点是否与收入确认匹配，避免长期挂账或错配。
5. **检查比例须达标**：检查比例=已检查金额÷本期发生额（借方+贷方），本期发生额取自 K4-2，比例不达标须说明并评估补充样本。
6. **异常与调整闭环**：预提不足、待转销项税额错配、未入账负债等异常须评估并通过 K4-3 调整，异常项目须标注类型并记录初步判断。

## checklist

### 一、样本选取充分性

- [ ] 样本选取方法是否与识别的重大错报风险匹配（CAS1314）
- [ ] 样本是否覆盖各主要项目（预提费用/待转销项税额/短期应付债券）
- [ ] 金额重大项目是否全查，高风险项（大额预提/待转销项税额/期末突增）是否纳入必选
- [ ] 抽样总体是否完整（本期发生额取自 K4-2，无人为排除）

### 二、凭证核对与计价

- [ ] 记账凭证与原始单据是否核对一致（金额/性质）
- [ ] 原始单据是否齐全（预提依据/税务资料/合同/审批单）
- [ ] 预提费用是否有明确应付义务和可靠估计依据
- [ ] 待转销项税额是否与已开票未确认收入对应，转销时点是否与收入确认匹配
- [ ] 核对差异是否逐笔追踪解决

### 三、完整性测试

- [ ] 预提费用充分性是否核对（期后实际发生额佐证）
- [ ] 是否评估预提不足（低估负债）或过度（调节利润）
- [ ] 是否结合未入账负债搜索评估应付义务完整性
- [ ] 待转销项税额是否漏挂或错配

### 四、检查比例与异常

- [ ] 检查比例（已检查÷本期发生额）是否达到计划水平，分母是否与 K4-2 一致
- [ ] 异常项目（预提无依据/待转销项税额错配/未入账负债）是否标注异常类型
- [ ] 异常事项是否记录初步判断并评估对总体影响
- [ ] 异常错报是否考虑通过 K4-3 调整或扩样

## risk_areas

### 高风险

1. **预提不足低估负债**：应预提费用未足额预提或漏提，负债低估、费用少计。
2. **待转销项税额错配**：待转销项税额转销时点/金额错误，扭曲收入确认与纳税义务。
3. **样本未覆盖高风险项/完整性缺失**：抽样遗漏大额预提、待转销项税额或未入账负债，负债完整性未验证。

### 中风险

1. **检查比例不足**：实际检查比例低于计划水平，审计证据不充分。
2. **凭证核对不深**：仅核对金额未验证预提义务基础和估计依据。
3. **预提过度未识别**：预提超过实际需要以调节利润未被发现。

### 低风险

1. **抽样记录不完整**：抽样参数/异常处理记录不完整。
2. **异常标注不规范**：异常类型分类不清或初步判断缺失。
3. **交叉索引不完整**：与 K4-2/K4-3 的交叉引用标注不全。
