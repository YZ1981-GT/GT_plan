# K7-note-listed 递延收益附注披露复核提示词（上市公司）

## 概述

本提示词针对递延收益上市公司附注披露底稿（K7-note-listed，科目 2401）的复核，聚焦上市公司财务报表附注中递延收益相关披露的充分性和准确性：递延收益分类披露（与资产相关/与收益相关）、本期变动情况、政府补助明细、CAS16 政府补助列报要求、以及与审定表/明细表的勾稽闭环。递延收益披露是报表使用者判断未来损益释放节奏和政府补助依赖度的重要信息，披露不充分将影响投资者对盈利质量的判断。

**法规依据：**
- 《企业会计准则第16号——政府补助》
- 《企业会计准则第30号——财务报表列报》
- 《公开发行证券的公司信息披露编报规则第15号——财务报告的一般规定》
- 《中国注册会计师审计准则第1501号——对财务报表形成审计意见和出具审计报告》

## tips

1. **分类披露须区分与资产/与收益相关**：附注应按"与资产相关"和"与收益相关"分别披露递延收益期初余额、本期增加、本期计入损益（摊销）、本期其他减少和期末余额，两类合计=递延收益总额。
2. **变动情况表是核心披露**：变动表须完整列示期初余额、本期新增补助、本期摊销转出（计入其他收益/营业外收入）、其他变动、期末余额，各项可追溯至 K7-2/K7-4。
3. **政府补助明细披露充分性**：上市公司须披露主要政府补助项目的名称、金额、与资产/收益相关分类、列报项目（其他收益/营业外收入）及是否影响当期损益，重大补助不得笼统归集。
4. **CAS16 列报要求**：须披露政府补助的会计政策（总额法/净额法选择）、计入当期损益的政府补助金额、与资产相关补助的摊销方法及期限。
5. **非经常性损益标识**：计入营业外收入的政府补助及与主营业务无直接关系的补助通常属非经常性损益，须与非经常性损益明细表勾稽，影响扣非净利润披露。
6. **闭环勾稽**：附注递延收益期末余额=审定表 K7-1 审定合计=明细表 K7-2 期末合计；本期摊销转出=K10 计入其他收益的政府补助额；分类小计相互勾稽。

## checklist

### 一、分类与变动披露

- [ ] 是否按与资产相关/与收益相关分类披露递延收益
- [ ] 两类合计是否等于审定表递延收益审定数
- [ ] 变动表是否完整（期初/本期新增/本期摊销转出/其他减少/期末）
- [ ] 变动表各项金额是否与 K7-2 明细表、K7-4 摊销测算勾稽
- [ ] 是否同时披露期末数和期初数（可比信息）
- [ ] 本期摊销转出计入损益的科目（其他收益/营业外收入）是否列明

### 二、政府补助明细与列报

- [ ] 主要政府补助项目名称、金额、分类是否列示完整
- [ ] 各补助计入损益的金额及列报项目是否披露
- [ ] 计入当期损益的政府补助总额是否与利润表其他收益/营业外收入勾稽
- [ ] 与资产相关补助的摊销方法及期限是否披露
- [ ] 总额法/净额法会计政策是否披露且与实际处理一致
- [ ] 是否披露尚未满足附加条件、存在返还风险的补助

### 三、CAS16 及非经常性损益披露

- [ ] 政府补助会计政策披露是否完整（确认、计量、列报）
- [ ] 非经常性损益标识是否正确（计入营业外收入及非主营相关补助）
- [ ] 非经常性损益中政府补助金额是否与非经常性损益明细表勾稽
- [ ] 重大补助是否说明批准部门、用途及附加条件
- [ ] 附注递延收益期末余额是否与审定表 K7-1 一致

## risk_areas

### 高风险

1. **分类披露缺失或错误**：未按与资产/与收益相关分类披露，或分类与摊销路径不一致，误导使用者判断未来损益释放。
2. **变动表不勾稽**：变动表各项金额与 K7-2 明细、K7-4 测算或利润表损益不一致，属重大披露错误。
3. **非经常性损益标识错误**：政府补助非经常性损益标识错误，影响上市公司扣非净利润披露。
4. **附注总额与审定表不一致**：附注递延收益期末余额与审定表审定数不符，数据勾稽重大错误。

### 中风险

1. **政府补助明细不充分**：重大补助笼统归集，未披露项目名称、金额、分类及列报项目。
2. **会计政策披露不完整**：总额法/净额法选择或摊销方法期限未披露。
3. **返还风险未披露**：存在附加条件未满足、可能返还的补助未提示风险。

### 低风险

1. **披露格式不规范**：表格标题、列序、金额单位不严格按编报规则。
2. **文字描述模板化**：会计政策照搬准则原文，未结合本企业实际补助情况说明。
