# K3-3 其他应付款调整分录复核提示词

## 概述

本提示词针对其他应付款调整分录汇总表（K3-3，科目 2241）的复核，含账项调整（AJE）、重分类调整（RJE）及未调整错报（SUD）评估。复核须验证：每笔调整有充分证据、借贷平衡、完整回写审定表 K3-1、SUD 与 A13 交叉验证。其他应付款调整常见于补记未入账负债、长期挂账转营业外收入、关联方往来重分类、错分科目纠正、流动/非流动重分类等。

**法规依据：**
- 《企业会计准则第28号——会计政策、会计估计变更和差错更正》
- 《企业会计准则第30号——财务报表列报》
- 《中国注册会计师审计准则第1301号——审计证据》

## tips

1. **AJE 与 RJE 须区分**：AJE 影响负债金额或损益（如补记负债、长期挂账转营业外收入）；RJE 仅影响列报（如关联方重分类、错分科目重分类），不得以 RJE 掩盖负债少计。
2. **完整性调整是负债调整重点**：搜索到的未入账负债须通过 AJE 补记（借费用/资产，贷其他应付款），负债类调整多为"调增"，须重点关注是否已足额补记。
3. **与审定表 K3-1 逐笔勾稽**：每笔已确认调整须完整回写 K3-1 对应调整列，审定数=未审+AJE+RJE，遗漏任一笔即审定数失真。
4. **长期挂账转营业外收入调整须有依据**：长期挂账转销（借其他应付款，贷营业外收入）须有确实无需支付的依据（债权人放弃/超过诉讼时效），无据转销属高风险。
5. **SUD 累计评估**：未调整错报（尤其少计负债）须记入 A13，单独及累计是否超过整体/明显微小错报阈值须评估，负债低估的错报方向须重点关注。
6. **调整已同步试算平衡表**：确认调整已回写 TB 2241 及相关科目，避免"底稿已调、TB 未更"双真源。

## checklist

### 一、调整依据与审批

- [ ] 所有 AJE 是否有充分证据（未入账负债搜索结果/原始凭证/管理层确认）
- [ ] 补记未入账负债的调整是否有 K3-7 反向截止/搜索支撑
- [ ] 长期挂账转营业外收入是否有确实无需支付的依据
- [ ] 关联方往来重分类是否有 K3-6 认定依据
- [ ] 超重要性水平调整是否经适当层级审批留痕

### 二、平衡与回写

- [ ] 每笔调整分录借贷方是否完全平衡
- [ ] 调整金额是否完整回写审定表 K3-1 对应调整列
- [ ] AJE 是否正确反映到审定数（未审+AJE+RJE=审定）
- [ ] 调整后审定数是否已同步试算平衡表 2241 及相关科目
- [ ] 调整分录编号是否连续，删除后重号风险是否可控

### 三、分类与未调整错报

- [ ] RJE 是否仅涉及列报（关联方/流动性重分类），未掩盖负债少计
- [ ] 未调整错报（尤其少计负债）是否记入 A13 未调整错报汇总表
- [ ] SUD 单独及累计是否超过重要性阈值并已评估
- [ ] 跨期调整是否正确区分本期错报与前期差错更正

## risk_areas

### 高风险

1. **未入账负债未补记**：搜索到的未入账负债未通过 AJE 补记，负债持续低估。
2. **无据转销长期挂账**：长期挂账缺乏确实无需支付依据即转营业外收入，虚增利润。
3. **审定表与 K3-3 不一致**：已确认调整未完整回写 K3-1，审定数失真。

### 中风险

1. **RJE 掩盖负债少计**：本应作 AJE 的负债补记以 RJE 处理，掩盖完整性错报。
2. **SUD 累计超阈值未处理**：少计负债的未调整错报累计超阈值未评估。

### 低风险

1. **编号格式不规范**：分录摘要、科目编码、编号连续性不规范。
2. **索引缺失**：与 K3-5/K3-7/A13 支持底稿的交叉索引不完整。
