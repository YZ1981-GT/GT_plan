# K10-3 其他收益调整分录复核提示词

## 概述

本提示词针对其他收益调整分录汇总表（K10-3，科目 6117）的复核，含账项调整（AJE）、重分类调整（RJE）及未调整错报评估。其他收益调整常见于分类错误重分类（其他收益↔营业外收入↔冲减成本）、漏计补助补记、确认时点纠正、与递延收益结转金额纠正。复核须验证：每笔调整有批文/结转测算依据、借贷平衡、完整回写至审定表 K10-1、并与未更正错报汇总（A13）交叉验证。核心风险为分类调整不当、审定数遗漏、错报累计超阈值。

**法规依据：**
- 《企业会计准则第16号——政府补助》
- 《企业会计准则第28号——会计政策、会计估计变更和差错更正》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **AJE vs RJE**：AJE 影响其他收益金额或损益（补记补助、冲回多计）；RJE 仅影响列报（其他收益↔营业外收入重分类），不得通过 RJE 掩盖损益错报。
2. **与 K10-1 勾稽**：审定表调整列金额须与 K10-3 已确认分录逐笔一致，遗漏任一笔即审定数失真。
3. **分类调整依据**：其他收益↔营业外收入重分类须有"是否与日常活动相关"的判断依据；与递延收益结转纠正须能追溯到 K7 摊销测算。
4. **错报累计评估**：未调整的其他收益错报单独及累计是否超过整体/损益层次重要性水平，须与 A13 未更正错报汇总交叉验证并推送。
5. **跨期调整区分**：区分本期补助确认纠正与前期差错更正（CAS28），会计处理与披露不同。
6. **TB 回写与联动**：确认调整已同步试算平衡表 6117 及对应科目（递延收益 2401/营业外收入 6301），避免双真源；分类调整须联动利润表列报。

## checklist

### 一、调整依据与授权（高风险）

- [ ] 每笔 AJE 是否有充分依据（批文、K7 结转测算、管理层确认）
- [ ] 调整是否经适当层级审批（超重要性水平须合伙人知悉）
- [ ] 其他收益↔营业外收入重分类是否有日常活动相关性判断依据
- [ ] 是否存在仅为美化经营利润或规避亏损的不当调整
- [ ] 【风险检查】是否存在无依据补记/冲回其他收益

### 二、平衡性与审定表勾稽（高风险）

- [ ] 每笔调整分录借贷方是否完全平衡
- [ ] 调整金额是否完整反映到 K10-1 审定表对应调整列
- [ ] AJE 对应科目（递延收益 2401/营业外收入 6301）是否正确
- [ ] 调整后审定数是否与试算表 6117 一致
- [ ] 【条件检查：若涉及净额法】误计损益改冲减成本的调整是否正确

### 三、分类、跨期与错报评估（中风险）

- [ ] RJE 是否仅涉及列报（其他收益↔营业外收入），未额外影响损益总额
- [ ] 跨期调整是否正确区分本期确认纠正与前期差错更正
- [ ] 未调整错报累计是否超过重要性水平，是否推送 A13 未更正错报汇总
- [ ] 与递延收益结转金额纠正是否与 K7 一致
- [ ] 调整分录编号是否连续，与 K10-1/K10-2 索引是否完整

## risk_areas

### 高风险

1. **分类调整不当**：其他收益↔营业外收入重分类无日常活动相关性依据，或应冲减成本的补助未调整，影响经营利润列报。
2. **审定表与 K10-3 不一致**：调整金额未完整回写 K10-1，审定数失真。
3. **错报累计超阈值未处理**：其他收益未更正错报累计超重要性水平仍出具无保留意见。

### 中风险

1. **RJE 误增损益**：重分类调整实质改变了损益总额（非纯列报）。
2. **跨期调整分类错误**：本期确认纠正误作前期差错更正（或反之）。
3. **TB 未同步**：调整仅在底稿反映，试算表 6117 及联动科目未更新。

### 低风险

1. **编号、格式不规范**：调整分录编号、摘要、科目编码不规范。
2. **索引不完整**：与 K10-1/K10-2/K7/A13 的交叉索引缺失。
