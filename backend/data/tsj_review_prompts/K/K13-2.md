# K13-2 营业外支出明细表复核提示词

## 概述

本提示词针对营业外支出明细表（K13-2，科目 6711，损益类借方，取本期发生额）的复核。明细表按损失项目（捐赠支出、非流动资产毁损报废损失、罚款滞纳金支出、非常损失、对外捐赠、债务重组损失等）分项列示本期发生额，是营业外支出科目的基础数据底稿，向上支撑审定表 K13-1，向外与非流动资产处置底稿及所得税（N 循环）勾稽。核心关注：各损失与日常活动的无关性、税前扣除性标识、非流动资产处置损失勾稽、完整性（应确认损失是否被隐匿或跨期）。

**法规依据：**
- 《企业会计准则第30号——财务报表列报》
- 《中国注册会计师审计准则第1301号——审计证据》
- 《中华人民共和国企业所得税法》及其实施条例（税前扣除性判断依据）

## tips

1. **取"发生额"非"余额"**：明细表各损失项目按 6711 本期借方发生额减贷方发生额填列净发生额，损益类无期末余额。
2. **无关性判断是明细表核心**：逐项判断损失是否确与企业日常经营活动无关——日常经营损失（如正常存货毁损、坏账）不应计入营业外支出，错计将美化营业利润。
3. **税前扣除性标识**：明细表须逐项标识税前扣除性——罚款滞纳金、非公益性捐赠、赞助支出等企业所得税前不得扣除，须为 N 循环递延所得税/所得税费用的纳税调整提供依据。
4. **非流动资产处置损失勾稽**：非流动资产毁损报废损失须与固定资产（H）、无形资产（I）等资产处置底稿勾稽，核对处置损失金额、处置原因及审批。
5. **完整性优先**：资产毁损、报废、非常损失是否足额确认，有无将应计损失隐匿、少计或跨期递延以虚增利润，是本科目完整性认定的重点。
6. **明细合计闭环勾稽**：明细表各项净发生额合计=审定表 K13-1 审定合计=试算表 6711 审定发生额=利润表营业外支出行。

## checklist

### 一、发生额勾稽与汇总（高风险）

- [ ] 【必检】各损失项目本期净发生额=借方−贷方是否计算正确
- [ ] 【必检】明细表各项净发生额合计是否与审定表 K13-1 审定合计一致
- [ ] 【必检】明细表本期发生额合计是否与试算平衡表 6711 审定发生额一致
- [ ] 【必检】未审发生额合计是否与试算表 6711 未审数一致
- [ ] 【必检】上期本期发生额是否与上年 K13-2 底稿衔接
- [ ] 【风险检查】是否存在单项损失金额异常且缺乏说明

### 二、计入科目与无关性判断（高风险）

- [ ] 【必检】各项损失计入营业外支出是否确与日常活动无关
- [ ] 【必检】日常经营损失是否未错计营业外支出以美化营业利润
- [ ] 【必检】正常存货毁损/坏账损失是否未混入营业外支出
- [ ] 【条件检查：若有大额非常损失】非常损失性质是否符合营业外支出定义
- [ ] 【风险检查】是否将营业成本/费用错转营业外支出以调节营业利润

### 三、税前扣除性与资产处置勾稽（高风险）

- [ ] 【必检】罚款滞纳金支出是否标识为税前不可扣除
- [ ] 【必检】非公益性捐赠/赞助支出是否标识税前扣除限制
- [ ] 【必检】税前不可扣除项目是否供 N 循环纳税调整
- [ ] 【必检】非流动资产毁损报废损失是否与 H/I 资产处置底稿勾稽
- [ ] 【条件检查：若有公益性捐赠】是否按税法限额（利润总额12%）标识可扣除部分
- [ ] 【风险检查】税前扣除性标识是否完整、准确

### 四、完整性与截止（中风险）

- [ ] 【必检】资产毁损/报废/非常损失是否足额确认
- [ ] 【必检】捐赠支出、非常损失是否有支持性证据与审批
- [ ] 【必检】资产负债表日前后损失是否记入恰当期间（截止）
- [ ] 【风险检查】是否存在应确认损失被隐匿、少计或跨期递延

## risk_areas

### 高风险

1. **完整性缺失虚增利润**：应确认的资产毁损、报废、非常损失未足额确认或跨期递延，虚增当期利润，属完整性认定的首要风险。
2. **分类错误美化营业利润**：将日常经营损失（正常毁损、坏账、成本费用）错计营业外支出，或反之，扭曲营业利润。
3. **非流动资产处置损失不勾稽**：营业外支出中的资产毁损报废损失与资产处置底稿（H/I）金额不一致。
4. **明细与审定表/试算表不勾稽**：净发生额合计与 K13-1 审定数或 6711 试算发生额存在无源差异。

### 中风险

1. **税前扣除性未标识**：罚款滞纳金、非公益性捐赠等未标识税前扣除限制，影响所得税纳税调整（N 循环）。
2. **证据不足**：捐赠支出、非常损失缺乏审批文件与支持性证据。
3. **损失确认时点不当**：资产毁损/报废损失确认时点与实际处置/报废时点不符。

### 低风险

1. **格式与索引不规范**：明细项目排列、与 K13-1/资产处置底稿的交叉索引标注不完整。
2. **损失项目说明不足**：分项仅列金额未附损失性质及依据简述。
