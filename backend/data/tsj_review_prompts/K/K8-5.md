# K8-5 销售费用合同检查复核提示词

## 概述

本提示词针对销售费用合同费用摊销核对表（K8-5，科目 6601）的复核，聚焦：合同要素完整性、费用摊销测算准确性、本期应计与已计差异分析、跨期与截止合理性。销售相关合同（广告投放合同、运输框架合同、代理/佣金合同、展览合同等）常跨期，本期应计损益=合同金额÷合同总月份×本期应计月份，与账面已计比较验证费用发生额的完整性与准确性。

**法规依据：**
- 《中国注册会计师审计准则第1301号——审计证据》
- 《企业会计准则第30号——财务报表列报》

---

## tips

1. **摊销测算是核心逻辑**：本期应计损益=合同金额÷合同总月份×本期应计月份（合同期∩报告期），须核对合同起止日期、总月份、本期应计月份计算是否正确。
2. **应计与已计差异揭示错报**：本期应计损益与账面本期已计损益的差异（差异>阈值如1元/重要性）指向少计（漏计费用）或多计（提前列支），须逐笔查明。
3. **合同要素须完整**：对方单位、合同内容、金额、开票方、支付条件与时间、合同起止日期须齐全，缺失将无法验证摊销期间与费用真实性。
4. **跨期合同关注截止**：广告投放/展览等跨年度合同的费用应按受益期间摊销，警惕一次性全额列支本期或延迟列支下期。
5. **手工覆盖须留痕**：本期应计月份若因合同特殊约定（如按投放量而非直线）手工覆盖直线摊销，须说明依据。
6. **合同与凭证/明细勾稽**：合同项摊销测算应与 K8-8 凭证检查、K8-2 明细表相应费用项目相互印证，索引可追溯。

## checklist

### 一、合同要素完整性

- [ ] 合同对方单位、合同内容、合同金额是否完整、可追溯至合同原件
- [ ] 合同起止日期、支付条件与时间是否明确
- [ ] 开票方、合同索引、凭证索引是否填列完整
- [ ] 大额/跨期销售相关合同是否纳入检查（广告/运输/代理佣金/展览）
- [ ] 是否存在应纳入检查但遗漏的重大合同

### 二、费用摊销测算准确性

- [ ] 合同总月份计算是否正确（含起止月，跨年合同月份口径一致）
- [ ] 本期应计月份是否为合同期与报告期的交集且计算正确
- [ ] 本期应计损益=合同金额÷合同总月份×本期应计月份，公式是否正确
- [ ] 手工覆盖直线摊销的（如按投放量）是否说明依据、测算合理
- [ ] 摊销期起点是否为服务开始/投放开始日，非合同签订日

### 三、应计与已计差异分析

- [ ] 本期应计损益与账面本期已计损益的差异是否逐笔列示
- [ ] 差异超阈值（1元/重要性水平）的行是否标红并查明原因
- [ ] 差异是否指向少计（应调增销售费用）或多计（应调减）并推送 K8-3 调整
- [ ] 摊销期初/期末余额（预付/待摊）是否与相关资产科目勾稽
- [ ] 检查结论是否明确记录，异常合同是否单独说明

## risk_areas

### 高风险

1. **跨期合同全额列支本期**：广告/展览等跨年合同费用未按受益期摊销而一次性列支本期，费用多计、利润低估或调节。
2. **应计费用漏计**：合同约定应计的本期费用未在账面列支（本期应计>已计），费用少计、利润虚增。
3. **摊销测算错误**：合同总月份、本期应计月份计算错误导致应计损益失真。
4. **合同真实性存疑**：无实质业务的广告/佣金合同用于虚增费用或利益输送。

### 中风险

1. **摊销起点错误**：以合同签订日而非服务/投放开始日起算摊销，期间归属错误。
2. **手工覆盖无依据**：非直线摊销的手工调整缺乏量化依据。
3. **差异未推送调整**：应计与已计差异已识别但未推送 K8-3 调整分录。

### 低风险

1. **合同要素填列不全**：合同索引、凭证索引缺失，影响可追溯性。
2. **检查范围说明不足**：未说明合同抽取标准（金额/跨期/关联方）。
