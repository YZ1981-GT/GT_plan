# K4-3 其他流动负债调整分录复核提示词

## 概述

本提示词针对其他流动负债调整分录汇总表（K4-3，科目 2245）的复核，含账项调整（AJE）、重分类调整（RJE）及未调整错报（SUD）评估。复核须验证：每笔调整有充分证据、借贷平衡、完整回写审定表 K4-1、SUD 与 A13 交叉验证。其他流动负债调整常见于补提预提费用、待转销项税额转销、一年内到期非流动负债重分类、错分科目纠正等。

**法规依据：**
- 《企业会计准则第28号——会计政策、会计估计变更和差错更正》
- 《企业会计准则第30号——财务报表列报》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **AJE 与 RJE 须区分**：AJE 影响负债金额或损益（如补提预提费用、待转销项税额转销确认收入）；RJE 仅影响列报（如一年内到期非流动负债重分类、错分科目重分类），不得以 RJE 掩盖负债少计。
2. **完整性调整是负债调整重点**：预提不足须通过 AJE 补提（借费用贷其他流动负债），负债类调整多为"调增"，须重点关注是否已足额补提。
3. **与审定表 K4-1 逐笔勾稽**：每笔已确认调整须完整回写 K4-1 对应调整列，审定数=未审+AJE+RJE，遗漏任一笔即审定数失真。
4. **一年内到期重分类是常见 RJE**：其他非流动负债将于一年内到期的部分须重分类至其他流动负债，重分类金额须准确、依据须充分，避免流动性列报错误。
5. **SUD 累计评估**：未调整错报（尤其少计负债）须记入 A13，单独及累计是否超过整体/明显微小错报阈值须评估。
6. **调整已同步试算平衡表**：确认调整已回写 TB 2245 及相关科目，避免"底稿已调、TB 未更"双真源。

## checklist

### 一、调整依据与审批

- [ ] 所有 AJE 是否有充分证据（预提测算/纳税义务依据/原始凭证）
- [ ] 补提预提费用/待转销项税额转销调整是否有依据支撑
- [ ] 一年内到期非流动负债重分类是否有到期时间判断依据
- [ ] 超重要性水平调整是否经适当层级审批留痕

### 二、平衡与回写

- [ ] 每笔调整分录借贷方是否完全平衡
- [ ] 调整金额是否完整回写审定表 K4-1 对应调整列
- [ ] AJE 是否正确反映到审定数（未审+AJE+RJE=审定）
- [ ] 调整后审定数是否已同步试算平衡表 2245 及相关科目
- [ ] 调整分录编号是否连续，删除后重号风险是否可控

### 三、分类与未调整错报

- [ ] RJE 是否仅涉及列报（流动性/科目重分类），未掩盖负债少计
- [ ] 未调整错报（尤其少计负债）是否记入 A13 未调整错报汇总表
- [ ] SUD 单独及累计是否超过重要性阈值并已评估
- [ ] 跨期调整是否正确区分本期错报与前期差错更正

## risk_areas

### 高风险

1. **预提不足未补提**：应补提预提费用未通过 AJE 补记，负债低估、费用少计。
2. **待转销项税额转销错误**：转销时点或金额错误，扭曲收入确认与纳税义务。
3. **审定表与 K4-3 不一致**：已确认调整未完整回写 K4-1，审定数失真。

### 中风险

1. **RJE 掩盖负债少计**：本应作 AJE 的负债补提以 RJE 处理，掩盖完整性错报。
2. **一年内到期重分类金额错误**：重分类金额计算不准或依据不足。

### 低风险

1. **编号格式不规范**：分录摘要、科目编码、编号连续性不规范。
2. **索引缺失**：与 K4-4/A13 支持底稿的交叉索引不完整。
