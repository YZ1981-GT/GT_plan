# K10-1 其他收益审定表复核提示词

## 概述

本提示词针对其他收益审定表（K10-1，科目 6117，损益类贷方，取本期发生额）的复核。其他收益核算与日常活动相关、总额法核算的政府补助等。聚焦：发生额勾稽、试算表核对、与递延收益（K7）的勾稽、计入科目正确性（其他收益 vs 营业外收入 vs 冲减成本费用）。主要风险为分类（应计营业外收入的补助错计其他收益）与完整性。

**法规依据：**
- 《企业会计准则第16号——政府补助》
- 《企业会计准则第30号——财务报表列报》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **取"发生额"非"余额"**：审定数按 6117 本期贷方发生额−借方（冲回）±调整。
2. **发生额勾稽**：审定合计=未审+AJE+RJE，且=明细表 K10-2 审定合计。
3. **与递延收益勾稽**：与资产相关、分期计入其他收益的政府补助，本期结转额应与递延收益（K7）本期摊销转出额勾稽一致。
4. **计入科目判断**：与日常活动相关的补助计其他收益；与日常活动无关的计营业外收入（K12）；与资产/成本直接相关的按净额法冲减——错计将影响列报。
5. **跨底稿闭环**：审定合计↔K10-2 明细↔试算表 6117↔利润表"其他收益"行；补助明细↔K7 递延收益结转。
6. **完整性**：核对政府补助批文/到账凭证，防止漏计或将补助挂往来科目。

---

## checklist

### 一、发生额勾稽与试算表核对

- [ ] 审定表各项目审定数=未审发生额+AJE+RJE 是否正确
- [ ] 审定合计是否与明细表 K10-2 审定合计一致
- [ ] 审定合计是否与试算平衡表 6117 审定发生额一致
- [ ] 未审发生额是否与试算表 6117 一致
- [ ] 上期审定数是否与上年底稿一致

### 二、与递延收益及计入科目

- [ ] 与资产相关补助本期计入其他收益金额是否与 K7 递延收益本期摊销一致
- [ ] 计入其他收益的补助是否确与日常活动相关（否则应计营业外收入 K12）
- [ ] 是否存在应按净额法冲减成本费用的补助误计其他收益
- [ ] 政府补助是否有正式批文/到账依据，确认时点是否恰当

### 三、审计调整与完整性

- [ ] 已确认的账项/重分类调整是否完整反映
- [ ] 调整分录借贷平衡、证据充分、经审批
- [ ] 是否存在漏计补助或将补助挂其他往来科目
- [ ] 非经常性损益标识是否正确（供上市披露）

## risk_areas

### 高风险

1. **分类错误**：与日常活动无关的补助错计其他收益（应计营业外收入），或应冲减资产/成本的补助计入损益。
2. **与递延收益不勾稽**：本期结转其他收益额与 K7 递延收益摊销不一致，存在多结转/少结转。
3. **完整性缺失**：漏计已到账政府补助或挂往来科目未确认收益。

### 中风险

1. **确认时点不当**：补助在收到批文/到账前提前确认，或满足条件后延迟确认。
2. **审计调整遗漏**：已确认调整未纳入审定表。
3. **非经常性损益标识错误**：影响上市公司扣非利润披露。

### 低风险

1. **格式与索引不规范**。
2. **补助项目说明不足**。
