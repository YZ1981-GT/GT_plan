# K2-3 其他流动资产调整分录复核提示词

## 概述

本提示词针对其他流动资产调整分录汇总表（K2-3，科目 1231）的复核，含账项调整（AJE）、重分类调整（RJE）及未调整错报（SUD）评估。复核须验证：每笔调整有充分证据、借贷平衡、完整回写审定表 K2-1、SUD 与 A13 交叉验证。其他流动资产调整常见于流动/非流动重分类、待摊费用补摊、不可抵扣进项税转出、错分科目纠正、合同取得成本摊销调整等。

**法规依据：**
- 《企业会计准则第28号——会计政策、会计估计变更和差错更正》
- 《企业会计准则第30号——财务报表列报》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **AJE 与 RJE 须区分**：AJE 影响资产金额或损益（如补摊待摊费用、进项税转出、合同取得成本摊销调整）；RJE 仅影响列报（如超一年部分重分类至非流动、错分科目重分类），不得以 RJE 掩盖资产高估。
2. **与审定表 K2-1 逐笔勾稽**：每笔已确认调整须完整回写 K2-1 对应调整列，审定数=未审+AJE+RJE，遗漏任一笔即审定数失真。
3. **调整须有充分证据**：待摊费用补摊须有摊销测算（K2-5）支撑、进项税转出须有税务依据、错分纠正须有原始凭证、重分类须有流动性判断依据。
4. **流动性重分类是其他流动资产常见 RJE**：超一年摊销/收回项目须重分类至其他非流动资产，重分类金额须准确、依据须充分。
5. **SUD 累计评估**：未调整错报须记入 A13，单独及累计是否超过整体/明显微小错报阈值须评估。
6. **调整已同步试算平衡表**：确认调整已回写 TB 1231 及相关科目，避免"底稿已调、TB 未更"双真源。

## checklist

### 一、调整依据与审批

- [ ] 所有 AJE 是否有充分证据（K2-5 摊销测算/税务依据/原始凭证）
- [ ] 待摊费用补摊/进项税转出调整是否有依据支撑
- [ ] 流动性重分类是否有一年内/一年以上判断依据
- [ ] 超重要性水平调整是否经适当层级审批留痕

### 二、平衡与回写

- [ ] 每笔调整分录借贷方是否完全平衡
- [ ] 调整金额是否完整回写审定表 K2-1 对应调整列
- [ ] AJE 是否正确反映到审定数（未审+AJE+RJE=审定）
- [ ] 调整后审定数是否已同步试算平衡表 1231 及相关科目
- [ ] 调整分录编号是否连续，删除后重号风险是否可控

### 三、分类与未调整错报

- [ ] RJE 是否仅涉及列报（流动性/科目重分类），未掩盖资产高估
- [ ] 未调整错报是否记入 A13 未调整错报汇总表
- [ ] SUD 单独及累计是否超过重要性阈值并已评估
- [ ] 跨期调整是否正确区分本期错报与前期差错更正

## risk_areas

### 高风险

1. **调整缺乏证据或未授权**：补摊/转出/重分类无充分依据或未经审批。
2. **审定表与 K2-3 不一致**：已确认调整未完整回写 K2-1，审定数失真。
3. **SUD 累计超阈值未处理**：未调整错报累计超整体重要性水平未评估。

### 中风险

1. **RJE 误含资产减记**：本应作 AJE 的资产减记（进项税转出/待摊补摊）以 RJE 处理，掩盖资产高估。
2. **流动性重分类金额错误**：超一年部分重分类金额计算不准或依据不足。

### 低风险

1. **编号格式不规范**：分录摘要、科目编码、编号连续性不规范。
2. **索引缺失**：与 K2-5/A13 支持底稿的交叉索引不完整。
