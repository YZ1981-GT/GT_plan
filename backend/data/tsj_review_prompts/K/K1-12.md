# K1-12 其他应收款检查表复核提示词

## 概述

本提示词针对其他应收款检查表（K1-12，凭证级检查，科目 1221）的复核，聚焦：样本选取充分性、凭证核对完整性、检查比例达标性、异常与截止事项标注充分性。本检查表对其他应收款的本期发生额（借方新增/贷方收回）及期后收款逐笔选样、核对记账凭证与原始单据、验证款项真实性与截止，是存在性、发生（准确性）与截止认定的直接证据。

**法规依据：**
- 《中国注册会计师审计准则第1314号——审计抽样》
- 《中国注册会计师审计准则第1301号——审计证据》
- 《中国注册会计师审计准则第1141号——财务报表审计中与舞弊相关的责任》

## tips

1. **样本选取须覆盖认定目标与高风险项**：本期借方发生额（新增其他应收款）测存在性，贷方发生额（收回）测存在性，样本须覆盖大额、关联方、异常整数、期末突增项目，金额重大项目 100% 全查（CAS1314）。
2. **凭证核对须验证款项真实性与业务实质**：核对记账凭证与原始单据（付款审批单/借款申请/合同协议/银行回单/收款凭证），核对内容包括金额、对象、款项性质、审批完整性，其他应收款尤须警惕无真实业务支撑的资金往来。
3. **检查比例须达标并分方向计算**：检查比例=已检查金额÷本期发生额（借方+贷方分别计算），须达到计划水平，本期发生额取自明细表 K1-2 的借贷方发生额，比例不达标须说明并评估是否补充样本。
4. **期后收款测试佐证存在性与可收回性**：期末大额其他应收款的期后实际收款情况须核对（银行回单/收款凭证），既佐证余额存在性，也为可收回性/减值评估提供证据。
5. **截止与异常须充分标注**：资产负债表日前后的借款/收回是否记入恰当期间（截止），异常项目（整数金额、恰好低于审批权限、无审批、关联方、非工作时间）须标注异常类型和初步判断。
6. **抽样参数与结果须可追溯**：抽样方法、总体、样本量、检查比例、异常处理须记录完整，异常错报须评估对总体的影响并考虑是否需调整（K1-4）或扩大样本。

## checklist

### 一、样本选取充分性

- [ ] 样本选取方法是否与识别的重大错报风险匹配（CAS1314）
- [ ] 金额重大项目（超重要性水平）是否 100% 全查
- [ ] 高风险项（大额/关联方/整数金额/期末突增）是否纳入必选样本
- [ ] 借方发生额（新增）与贷方发生额（收回）是否分别抽样
- [ ] 抽样总体是否完整（取自 K1-2 本期借贷方发生额，无人为排除）

### 二、凭证核对完整性

- [ ] 记账凭证与原始单据是否核对一致（金额/对象/性质）
- [ ] 原始单据是否齐全（借款申请/付款审批/合同/银行回单/收款凭证）
- [ ] 款项性质与业务实质是否有真实支撑（非虚构往来）
- [ ] 审批手续是否完整、权限是否匹配
- [ ] 核对差异是否逐笔追踪解决

### 三、检查比例与期后收款

- [ ] 检查比例（已检查÷本期发生额）是否达到计划水平
- [ ] 借方/贷方检查比例是否分别计算达标
- [ ] 检查比例分母是否与 K1-2 本期发生额一致
- [ ] 期末大额其他应收款期后收款是否核对（回单/收款凭证）

### 四、异常与截止

- [ ] 资产负债表日前后借款/收回是否记入恰当期间（截止）
- [ ] 异常项目（整数金额/低于审批权限/无审批/关联方）是否标注异常类型
- [ ] 异常事项是否记录初步判断（合理/需调查/疑似错报）
- [ ] 异常错报是否评估对总体影响并考虑调整或扩样

## risk_areas

### 高风险

1. **虚构往来款项**：无真实业务支撑的其他应收款（资金拆借伪装成往来），核对不出原始单据。
2. **样本未覆盖高风险项**：抽样遗漏关联方、大额、异常整数款项，未能覆盖重大错报风险。
3. **截止错误未识别**：期末集中借款/收回未做截止测试，跨期事项未标注。

### 中风险

1. **检查比例不足**：实际检查比例低于计划水平，审计证据不充分。
2. **凭证核对不深**：仅核对金额未验证款项性质、审批完整性和业务实质。
3. **期后收款测试缺失**：期末大额款项未做期后收款核对，存在性/可收回性证据不足。

### 低风险

1. **抽样记录不完整**：抽样参数/选取过程/异常处理记录不完整。
2. **异常标注不规范**：异常类型分类不清或初步判断缺失。
3. **交叉索引不完整**：与 K1-2/K1-4/K1-5 的交叉引用标注不全。
