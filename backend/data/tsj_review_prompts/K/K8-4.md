# K8-4 销售费用实质性分析复核提示词

## 概述

本提示词针对销售费用实质性分析程序底稿（K8-4，科目 6601）的复核，通过分析程序验证销售费用与营业收入/业务规模的匹配性、费用率变动的合理性、费用结构变化趋势，识别费用少计（完整性）、多计、跨期或错分类的重大错报风险。销售费用与销售规模强相关，费用率（销售费用/营业收入）异常是核心分析指标。

**法规依据：**
- 《中国注册会计师审计准则第1313号——分析程序》
- 《企业会计准则第30号——财务报表列报》

---

## tips

1. **费用率是首要分析指标**：销售费用率=销售费用÷营业收入，须与上期、预算、同行业对比；费用率突升可能虚增费用/跨期，突降可能费用少计（完整性风险）。
2. **费用与收入的匹配关系**：广告费、运输费、佣金等与销量/收入强相关，其变动应与收入变动同向且幅度匹配；收入增而运费/佣金不增须警惕漏记。
3. **变动分析须区分驱动因素**：费用增长应区分业务量增长、单价上涨、新市场投入等驱动，与收入变动脱节的增长须查明。
4. **异常波动阈值参考**：单项目变动超 30%、费用率变动超 20%、占收入比偏离历史均值超 15% 应触发深入分析。
5. **分析须形成闭环**：识别异常→调查→获取管理层解释→取得支持证据评价合理性→形成结论，不得仅有管理层口头说明。
6. **期末突增结合截止**：销售费用（尤其广告费/佣金）在年末最后一个月突增须结合 K8-6/K8-7 截止测试，判断是否跨期或提前列支。

## checklist

### 一、费用率与匹配性分析（高风险）

- [ ] 销售费用率（销售费用÷营业收入）计算是否准确、分子分母口径一致
- [ ] 销售费用率与上期对比变动是否合理，变动超 20% 是否有充分解释
- [ ] 销售费用总额变动率与营业收入变动率是否匹配（差异超 15% 须解释）
- [ ] 运输费/佣金/广告费等与收入强相关项目的变动是否与收入同向匹配
- [ ] 收入增长但相关变动费用未同步增长是否已查明（漏记/滞后列支风险）

### 二、费用结构与趋势分析（中风险）

- [ ] 各费用项目占销售费用比例的结构变动是否合理
- [ ] 费用结构较上期是否出现重大迁移（如广告费占比骤升/骤降）
- [ ] 分产品线/分区域/分渠道的销售费用变动是否分别分析（如适用）
- [ ] 销售费用率与同行业可比公司是否存在显著偏离（偏离 30% 须评估）
- [ ] 季节性业务的费用分析是否按季度/月度拆分，避免全年均值掩盖异常

### 三、异常调查与结论闭环（高风险）

- [ ] 分析发现的异常波动是否全部得到调查和解释
- [ ] 异常解释是否有充分审计证据支持（合同、市场投入计划、业务量数据）
- [ ] 期末突增费用是否结合截止测试（K8-6/K8-7）分析
- [ ] 分析程序结论是否明确记录，与审计总体结论衔接
- [ ] 前后期对比数据口径是否一致（合并范围/会计政策变更已调整可比数据）

## risk_areas

### 高风险

1. **费用率异常下降未解释**：销售费用率显著低于上期/同行但无合理解释，可能存在费用少计（完整性）或跨期递延以虚增利润。
2. **收入增而变动费用不增**：营业收入增长而运输费/佣金等变动费用未同步增长，费用漏记或滞后列支的信号。
3. **期末费用异常波动**：年末最后一个月销售费用突增或突减，可能提前列支/延迟列支操纵当期利润。
4. **异常波动无证据解释**：识别出异常但仅凭管理层口头说明，未获取支持性审计证据。

### 中风险

1. **费用率偏离行业显著**：销售费用率与同行业差异超 30%，需评估是否行业特性或异常信号。
2. **费用结构急剧变动**：某费用项目占比大幅迁移但未分析原因。
3. **对比口径不一致**：合并范围或会计政策变更未调整可比数据，导致分析结论误导。

### 低风险

1. **分析深度不足**：仅做总额同比，未按项目/产品/区域细分分析。
2. **数据来源标注不规范**：分析引用数据未标注来源底稿或行业对标数据过于陈旧。
