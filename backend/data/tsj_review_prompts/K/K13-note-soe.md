# K13-note-soe 营业外支出附注披露复核提示词（国有企业）

## 概述

本提示词针对营业外支出国有企业附注披露底稿（K13-note-soe，科目 6711，损益类）的复核。在满足企业会计准则通用披露（按损失性质分项、捐赠/非常损失披露、与审定表勾稽）基础上，聚焦国有企业特定要求：对外捐赠的合规性与决策程序、非流动资产报废损失的国有资产处置审批、损失的责任追究、以及财务决算报告补充披露。国有企业对外捐赠、资产报废、非常损失均涉及国有资产减少，其合规性与决策程序是国资监管重点。

**法规依据：**
- 《企业会计准则第30号——财务报表列报》
- 《企业国有资产法》
- 《中央企业财务决算报告管理办法》
- 《公开发行证券的公司信息披露编报规则第9号——非经常性损益》

## tips

1. **国企附注"双层"披露**：既满足 CAS 通用分项披露（按损失性质、捐赠/非常损失），又满足国资委财务决算报告对营业外支出及国有资产损失的补充披露要求。
2. **对外捐赠须披露合规性与决策程序**：国有企业对外捐赠须符合国资监管规定，重大捐赠须经"三重一大"决策，附注应披露捐赠决策程序及是否符合规定。
3. **非流动资产报废损失涉及国有资产处置**：资产毁损报废须经国有资产处置审批程序，附注应说明报废资产的审批情况及残值处置。
4. **损失的责任追究**：因经营决策失误、管理不善导致的重大损失（如资产毁损、非常损失），须说明是否启动国有资产损失责任追究程序。
5. **非经常性损益披露**：营业外支出属非经常性损益，须单独列示供业绩考核剔除，国企业绩考核对扣非指标同样关注。
6. **附注数据与审定表/明细表/决算报表闭环**：附注分项本期发生额=K13-2 明细净发生额=利润表营业外支出行=审定表 K13-1 审定合计=财务决算报表相应数据。

## checklist

### 一、基础披露完整性（与上市版共有）

- [ ] 营业外支出是否按损失性质完整分项列示本期发生额
- [ ] 各分项合计是否等于利润表营业外支出行及审定表 K13-1 审定合计
- [ ] 是否同时披露本期数与上期可比数
- [ ] 各分项是否与 K13-2 明细表勾稽
- [ ] 对外捐赠是否披露对象、金额、性质
- [ ] 非经常性损益项目是否单独列示

### 二、对外捐赠合规性披露（国企特定）

- [ ] 重大对外捐赠是否披露决策程序（是否经"三重一大"）
- [ ] 对外捐赠是否符合国资监管对捐赠的规定
- [ ] 是否披露是否存在向关联方或非公益对象的捐赠
- [ ] 公益性捐赠税前扣除情况是否说明
- [ ] 捐赠是否履行了必要的审批程序

### 三、国有资产处置与损失披露

- [ ] 非流动资产毁损报废损失是否说明国有资产处置审批情况
- [ ] 报废资产是否与固定资产（H）/无形资产（I）附注处置减少勾稽
- [ ] 非常损失是否披露事件性质、损失金额及保险理赔
- [ ] 重大损失是否说明是否启动国有资产损失责任追究程序
- [ ] 损失对国有资本保值增值的影响是否说明

### 四、决算报表特殊要求

- [ ] 营业外支出数据是否与年度财务决算报表一致
- [ ] 国有资产损失数据是否按决算要求单独披露
- [ ] 非经常性损益金额是否用于业绩考核指标剔除
- [ ] 集团合并层面内部损失抵销是否完整
- [ ] 营业外支出分类是否与决算口径一致

### 五、与上市版的差异关注点

- [ ] 是否在基础分项披露之上增加了对外捐赠合规性与决策程序说明
- [ ] 是否增加了国有资产处置审批情况披露
- [ ] 是否增加了损失责任追究相关披露
- [ ] 是否增加了对国有资本保值增值的影响分析

## risk_areas

### 高风险

1. **对外捐赠未经决策程序**：重大对外捐赠未经"三重一大"或不符合国资监管规定，存在合规风险及国有资产流失风险。
2. **资产报废损失未经处置审批**：非流动资产毁损报废未经国有资产处置审批程序，可能掩盖资产流失。
3. **分项与决算/审定表不勾稽**：附注营业外支出数据与财务决算报表或 K13-1 审定合计不一致。
4. **重大损失责任追究缺失**：因决策失误的重大损失未说明是否启动责任追究程序。

### 中风险

1. **国有资产处置审批披露不足**：报废资产的审批情况及残值处置未充分说明。
2. **非经常性损益披露不足**：未单独列示营业外支出的非经常性损益金额，影响考核指标剔除。
3. **资产处置损失不勾稽**：附注资产处置损失与资产附注处置减少不一致。
4. **决算与审计口径差异未调节**：财务决算营业外支出数据与审计后附注存在差异未调节。

### 低风险

1. **披露格式未完全按决算模板**：附注格式与国资委决算报表模板有细微差异。
2. **损失性质说明过于简略**：仅列金额未结合国企实际说明损失成因。
