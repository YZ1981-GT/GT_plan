# K11-note-listed 资产减值损失附注披露复核提示词（上市公司）

## 概述

本提示词针对资产减值损失上市公司附注披露底稿（K11-note-listed，科目 6701，损益类）的复核。聚焦利润表"资产减值损失"项目的附注分项披露：按资产类别（存货跌价损失、固定资产减值损失、在建工程减值损失、无形资产减值损失、商誉减值损失、长期股权投资减值损失、合同资产减值损失等）列示本期计提额，区分资产减值损失（6701）与信用减值损失（6702），并与审定表 K11-1、各资产减值专项底稿及利润表勾稽。上市公司披露口径受证监会编报规则约束，商誉减值披露尤为投资者与监管关注。

**法规依据：**
- 《企业会计准则第8号——资产减值》
- 《企业会计准则第30号——财务报表列报》
- 《企业会计准则第37号——金融工具列报》
- 《公开发行证券的公司信息披露编报规则第15号——财务报告的一般规定》
- 《会计监管风险提示第8号——商誉减值》

## tips

1. **资产减值损失（6701）与信用减值损失（6702）须分行披露**：利润表自2019年起将两者分列，附注亦须分项，不得将金融资产预期信用损失并入资产减值损失，混列即列报错误。
2. **按资产类别分项列示本期计提额**：附注须完整列示存货跌价、固定资产、在建工程、无形资产、商誉、长期股权投资、合同资产等各类别本期计提的减值损失，各分项合计=利润表资产减值损失行=审定表 K11-1 审定合计。
3. **商誉减值是上市公司披露重中之重**：须披露商誉减值测试的资产组划分、可收回金额确定方法（公允价值减处置费用/预计未来现金流量现值）、关键假设（增长率、折现率）及敏感性，缺失属重大披露不足（会计监管风险提示第8号）。
4. **减值不可转回须体现于披露**：附注中商誉及部分长期资产减值披露应体现一经计提不转回，不得出现减值损失负数（转回）行。
5. **各分项须与减值准备变动表勾稽**：附注资产减值损失本期计提额须与资产负债表相关资产减值准备附注的"本期计提"栏一致，形成损益表与资产表的闭环。
6. **附注数据与审定表/明细表/各资产底稿闭环勾稽**：附注分项本期计提额=K11-2 明细表分项净发生额=各资产减值专项底稿计提额=利润表资产减值损失行。

## checklist

### 一、分项披露完整性

- [ ] 资产减值损失是否按资产类别完整分项列示本期计提额
- [ ] 各分项本期计提额合计是否等于利润表"资产减值损失"行金额
- [ ] 各分项合计是否与审定表 K11-1 审定合计一致
- [ ] 是否同时披露本期数与上期可比数
- [ ] 资产减值损失（6701）与信用减值损失（6702）是否分行分项披露
- [ ] 各分项是否与 K11-2 明细表对应分项勾稽

### 二、商誉减值披露充分性

- [ ] 是否披露商誉减值测试的资产组/资产组组合划分
- [ ] 是否披露可收回金额确定方法（公允价值减处置费用/现值法）
- [ ] 是否披露预计未来现金流量现值的关键假设（增长率/折现率/预测期）
- [ ] 商誉减值金额是否与 I4 商誉底稿一致
- [ ] 是否披露商誉减值的敏感性分析（如适用）
- [ ] 商誉减值是否未出现转回

### 三、各类资产减值披露

- [ ] 存货跌价损失披露是否与 F2 底稿及存货减值准备附注勾稽
- [ ] 固定资产/在建工程减值披露是否与 H 循环底稿勾稽
- [ ] 无形资产/开发支出减值披露是否与 H4/I 底稿勾稽
- [ ] 长期股权投资减值披露是否与 G7 底稿勾稽
- [ ] 各分项减值本期计提额是否与对应资产减值准备变动表"本期计提"一致
- [ ] 重大减值项目是否披露减值原因及测试方法

### 四、减值不可转回与列报

- [ ] 商誉及长期资产减值披露是否体现一经计提不转回
- [ ] 是否存在减值损失负数（转回）异常行需说明
- [ ] 是否与资产负债表各资产减值准备附注形成闭环
- [ ] 减值损失分类是否与会计政策一致

## risk_areas

### 高风险

1. **6701 与 6702 混列披露**：将金融资产预期信用损失并入资产减值损失分项，违反利润表分列要求，属重大列报错误。
2. **商誉减值披露不充分**：未披露资产组划分、可收回金额方法或关键假设，不满足会计监管风险提示第8号要求，为监管重点关注领域。
3. **分项合计与利润表/审定表不勾稽**：附注分项本期计提额之和与利润表资产减值损失行或 K11-1 审定合计不一致。
4. **减值违规转回体现于披露**：附注出现商誉或长期资产减值转回，虚增利润且违反准则。

### 中风险

1. **可比信息缺失**：仅披露本期计提额未列示上期可比数据。
2. **减值原因披露不足**：重大减值项目未披露减值迹象、测试方法及关键判断。
3. **与资产减值准备附注不勾稽**：损益表资产减值损失分项与资产负债表减值准备"本期计提"栏不一致。

### 低风险

1. **披露格式不规范**：分项排列顺序、金额单位等格式细节未严格按编报规则。
2. **文字描述模板化**：减值测试方法描述照搬会计政策，未结合本企业资产实际。
