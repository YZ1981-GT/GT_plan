# K9-2 管理费用明细表复核提示词

## 概述

本提示词针对管理费用明细表（K9-2，科目 6602，损益类借方，按费用项目×12个月归集本期发生额）的复核，聚焦：费用项目归集完整性、月度发生额勾稽、审定数与占比分析、同比变动合理性。明细表按性质列示管理费用明细项目（职工薪酬/折旧摊销/无形资产摊销/办公费/中介机构费/业务招待费/研发费用/税金/差旅费/物业费等），是审定表 K9-1 的数据源，其明细审定合计（K9-2-detail-audited-total）为跨底稿勾稽键。研发费用列示口径与招待费是管理费用明细的核查重点。

**法规依据：**
- 《企业会计准则第30号——财务报表列报》
- 《中国注册会计师审计准则第1301号——审计证据》
- 《中国注册会计师审计准则第1313号——分析程序》

## tips

1. **明细取本期发生额而非余额**：每个费用项目按月归集本期借方发生额（扣除结转/红冲），全年合计为该项目发生额，不得混入余额口径。
2. **明细合计是审定表生命线**：K9-2 各项目审定合计（月度合计+AJE+RJE）必须等于审定表 K9-1 审定合计并等于试算表 6602 审定发生额，此为勾稽键 K9-2-detail-audited-total。
3. **研发费用列示口径**：计入管理费用的研发费用须与研发费用归集底稿（I/N 循环）口径一致；关注费用化研发与资本化开发支出的边界，避免重复列示或错列。
4. **业务招待费单独关注**：业务招待费是税前扣除受限项目，须单独列示、金额可追溯，警惕以会议费/办公费名义列支超标招待费。
5. **月度发生额揭示异常**：折旧摊销应逐月均匀，某月畸变须查明（如资产处置/减值影响）；中介费/审计费多在年末列支，须结合截止判断期间。
6. **占比与同比双维分析**：各项目占管理费用及占营业收入比例、同比变动超 30% 须逐项分析；折旧摊销、中介费、招待费为高波动关注项。

## checklist

### 一、费用项目归集完整性

- [ ] 各费用明细项目名称是否规范、不重不漏，无大额"其他"笼统归集
- [ ] 明细项目是否覆盖管理费用全部性质（薪酬/折旧摊销/办公/中介费/研发/招待/税金/差旅等）
- [ ] 研发费用是否单独列示，与研发归集（I/N 循环）口径是否一致
- [ ] 业务招待费是否单独列示、金额可追溯（税前扣除受限项）
- [ ] 是否存在应属销售费用/营业成本的项目错误归集至管理费用

### 二、月度发生额与勾稽

- [ ] 各项目 1—12 月发生额之和是否等于该项目本期未审发生额
- [ ] 全部项目月度合计是否与试算表 6602 未审发生额一致
- [ ] 折旧摊销是否逐月均匀，畸变月份是否查明
- [ ] 中介费/审计费/年终奖等年末集中列支项目是否结合截止判断期间
- [ ] 明细数据是否直接取自序时账，未经人工调整

### 三、审定数勾稽与占比分析

- [ ] 各项目审定数=未审+AJE+RJE，逐行计算是否正确
- [ ] 明细审定合计是否等于审定表 K9-1 审定合计（勾稽键 K9-2-detail-audited-total）
- [ ] 各费用项目占管理费用合计比例是否计算正确、合理
- [ ] 各项目占营业收入比例是否与经营规模匹配、无异常偏离
- [ ] 调整分录（K9-3）对明细项目的影响是否已正确反映

### 四、同比变动分析

- [ ] 各费用项目本期较上期变动额、变动率是否列示
- [ ] 变动超 30% 的项目是否附充分原因说明
- [ ] 折旧摊销变动是否与固定资产/无形资产变动匹配
- [ ] 研发费用变动是否与研发投入计划、研发归集一致
- [ ] 上期数是否与上年审定底稿一致（可比性）

## risk_areas

### 高风险

1. **明细合计与审定表/试算表不勾稽**：K9-2 审定合计与 K9-1、试算表 6602 发生额不一致，存在汇总错误或调整遗漏。
2. **费用完整性缺失**：期末应计未计的中介费/审计费/办公费未在相应月份归集，导致费用少计、利润虚增。
3. **研发费用列示错误**：费用化研发与资本化开发支出边界不清，重复列示或错列，影响研发费用披露与加计扣除。
4. **招待费隐匿超标**：以会议费/办公费名义列支超标业务招待费，掩盖税前扣除受限项。

### 中风险

1. **费用错分类**：应属销售费用/营业成本的项目错误归集至管理费用。
2. **折旧摊销异常未解释**：折旧摊销月度畸变或同比大幅波动未分析（资产处置/减值）。
3. **占比与变动异常未解释**：项目占收入比或同比变动大幅偏离但无原因分析。

### 低风险

1. **项目命名与排列不规范**：明细项目口径不统一、排列混乱。
2. **辅助分析信息缺失**：缺少占比、同比等辅助分析列或未标注数据来源。
