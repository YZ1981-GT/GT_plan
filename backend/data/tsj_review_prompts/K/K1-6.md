# K1-6 其他应收款会计政策检查复核提示词

## 概述

本提示词针对其他应收款会计政策检查表（K1-6）的复核，聚焦：坏账计提政策合理性、减值组合划分依据、政策一致性与变更、与同行业/上市公司政策对标。会计政策检查评价企业其他应收款减值会计政策（一般方法/简化方法适用、组合划分标准、账龄计提比例、单项认定标准）是否符合 CAS22 并前后期一致，是坏账三阶段（K1-7）和坏账测算（K1-8）的政策前提。

**法规依据：**
- 《企业会计准则第22号——金融工具确认和计量》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **其他应收款减值方法适用须判断准确**：其他应收款通常不含重大融资成分，多数适用预期信用损失一般方法（三阶段），是否采用简化方法须有依据，方法选择错误将影响整体减值模型。
2. **减值组合划分须有合理依据**：按信用风险特征划分组合（账龄组合/关联方组合/押金保证金组合等），组合划分须反映风险差异，随意归组将扭曲损失率。
3. **账龄计提比例须有历史损失经验支撑**：各账龄段计提比例须基于历史损失率并考虑前瞻性调整，比例过低（尤其长账龄）可能计提不足。
4. **单项认定标准须清晰**：单项计提的认定标准（信用风险显著不同/客观减值证据）须明确，避免应单项而未单项。
5. **政策一致性与变更须评估**：本期政策是否与上期一致，如变更是否符合 CAS28、是否有合理理由并追溯调整，警惕通过政策变更调节减值。
6. **政策对标增强合理性判断**：与同行业上市公司减值政策对标（组合划分/计提比例）有助于评价政策的审慎性和合理性，但须结合本企业其他应收款结构差异。

## checklist

### 一、减值方法与组合

- [ ] 其他应收款减值方法（一般方法/简化方法）适用判断是否正确
- [ ] 减值组合划分是否有合理依据并反映信用风险差异
- [ ] 组合划分标准（账龄/性质/关联方）是否清晰且一致
- [ ] 单项计提认定标准是否明确（信用风险显著不同/客观减值证据）
- [ ] 押金保证金等特殊款项的减值考虑是否恰当

### 二、计提比例合理性

- [ ] 各账龄段计提比例是否有历史损失经验支撑
- [ ] 计提比例是否考虑前瞻性信息调整
- [ ] 长账龄计提比例是否审慎（避免长账龄低计提）
- [ ] 计提比例与同行业/上市公司政策对标是否合理

### 三、政策一致性

- [ ] 本期会计政策是否与上期一致
- [ ] 政策变更是否符合 CAS28 且有合理理由
- [ ] 政策变更是否追溯调整并披露
- [ ] 政策是否与附注披露的会计政策描述一致

## risk_areas

### 高风险

1. **减值方法适用错误**：错误采用简化方法或组合划分不当，导致整体减值模型失真。
2. **计提比例明显偏低**：账龄计提比例（尤其长账龄）缺乏历史损失支撑且明显偏低，减值计提不足。
3. **借政策变更调节利润**：无合理理由变更减值政策以减少/增加当期减值。

### 中风险

1. **组合划分不合理**：组合未反映风险差异，损失率被平均化扭曲。
2. **单项认定标准模糊**：应单项评估的重大/异常款项未单项认定。

### 低风险

1. **政策描述不一致**：K1-6 政策与附注会计政策描述细节不一致。
2. **对标分析不足**：未与同行业政策对标，合理性论证不充分。
