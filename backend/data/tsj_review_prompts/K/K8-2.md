# K8-2 销售费用明细表复核提示词

## 概述

本提示词针对销售费用明细表（K8-2，科目 6601，损益类借方，按费用项目×12个月归集本期发生额）的复核，聚焦：费用项目归集完整性、月度发生额勾稽、审定数与占比分析、同比变动合理性。明细表按性质列示销售费用明细项目（运输费/广告宣传费/职工薪酬/差旅费/业务招待费/仓储费/展览费/佣金手续费/折旧摊销等），是审定表 K8-1 的数据源，其明细审定合计（K8-2-total-audited）为跨底稿勾稽键。

**法规依据：**
- 《企业会计准则第30号——财务报表列报》
- 《中国注册会计师审计准则第1301号——审计证据》
- 《中国注册会计师审计准则第1313号——分析程序》

## tips

1. **明细表取本期发生额而非余额**：每个费用项目按月归集本期借方发生额（扣除红冲/结转），全年合计为该项目发生额；切勿混入期末余额口径。
2. **明细合计是审定表生命线**：K8-2 各项目审定合计（未审月度合计+AJE+RJE）必须等于审定表 K8-1 审定合计，并等于试算表 6601 审定发生额，此为跨底稿勾稽键 K8-2-total-audited。
3. **月度发生额揭示异常波动**：某月费用畸高（如年末集中列支广告费/佣金）或畸低（少计）须结合业务节奏判断，警惕通过月度腾挪调节利润。
4. **占比分析定位重点项目**：各费用项目占销售费用合计比例、占营业收入比例应与业务模式匹配，占比异常项目为核查重点（如广告费占收入比远超行业）。
5. **同比变动是异常识别的抓手**：单项目本期较上期变动超 30% 或与收入变动方向背离时须逐项分析原因并留痕，不得仅有数字无解释。
6. **归集口径须清晰**：明细项目命名规范、不重不漏，避免"其他"笼统归集掩盖大额或敏感费用（业务招待费、佣金手续费）；应确保与费用报销系统、序时账归集一致。

## checklist

### 一、费用项目归集完整性

- [ ] 各费用明细项目名称是否规范、不重不漏，无大额"其他"笼统归集
- [ ] 明细项目是否覆盖销售费用全部性质（运输/广告/薪酬/差旅/招待/仓储/佣金/折旧摊销等）
- [ ] 明细表项目归集是否与序时账 6601 明细科目、费用报销系统一致
- [ ] 是否存在应属营业成本/管理费用的项目错误归集至销售费用明细
- [ ] 敏感费用（业务招待费、佣金手续费、赞助费）是否单独列示、金额可追溯

### 二、月度发生额与勾稽

- [ ] 各项目 1—12 月发生额之和是否等于该项目本期未审发生额
- [ ] 全部项目月度合计是否与试算表 6601 未审发生额一致
- [ ] 是否存在某月发生额畸高/畸低且无业务解释（月度腾挪调节利润迹象）
- [ ] 年末最后一个月是否存在费用集中列支或延迟列支现象
- [ ] 明细数据是否直接取自序时账，未经人工调整

### 三、审定数勾稽与占比分析

- [ ] 各项目审定数=未审+AJE+RJE，逐行计算是否正确
- [ ] 明细审定合计是否等于审定表 K8-1 审定合计（勾稽键 K8-2-total-audited）
- [ ] 各费用项目占销售费用合计比例是否计算正确、合理
- [ ] 各项目占营业收入比例是否与业务模式匹配、无异常偏离
- [ ] 调整分录（K8-3）对明细项目的影响是否已正确反映

### 四、同比变动分析

- [ ] 各费用项目本期较上期变动额、变动率是否列示
- [ ] 变动超 30% 的项目是否附充分原因说明（非仅口头）
- [ ] 费用项目变动方向是否与营业收入变动方向匹配
- [ ] 广告费/运输费/佣金等与销量/收入强相关项目的变动是否合理
- [ ] 上期数是否与上年审定底稿一致（可比性）

## risk_areas

### 高风险

1. **明细合计与审定表/试算表不勾稽**：K8-2 审定合计与 K8-1、试算表 6601 发生额不一致，存在汇总错误或调整遗漏。
2. **费用完整性缺失**：期末应计未计的运输费/佣金/广告费未在相应月份归集，导致费用少计、利润虚增。
3. **月度腾挪调节利润**：通过将费用在各月间人为腾挪或年末集中/延迟列支，操纵各期利润。
4. **敏感费用隐匿**：业务招待费、佣金手续费以"其他"笼统归集或错分至其他项目，掩盖异常支出。

### 中风险

1. **费用错分类**：应属营业成本或管理费用的项目错误归集至销售费用明细，影响费用结构与毛利分析。
2. **占比与变动异常未解释**：项目占收入比或同比变动大幅偏离但无原因分析。
3. **归集口径不一致**：明细表与序时账、费用报销系统的项目归集口径存在差异。

### 低风险

1. **项目命名与排列不规范**：明细项目名称口径不统一、排列顺序混乱，影响复核效率。
2. **辅助分析信息缺失**：缺少占比、同比等辅助分析列或未标注数据来源。
