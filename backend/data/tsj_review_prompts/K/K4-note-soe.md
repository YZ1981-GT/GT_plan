# K4-note-soe 其他流动负债附注披露复核提示词（国有企业）

## 概述

本提示词针对其他流动负债国有企业附注披露底稿（K4-note-soe）的复核，聚焦：基础分类明细披露（与上市版共有）、国有资产监管相关披露、待转销项税额及预提费用披露、负债完整性、决算报表口径一致。国有企业其他流动负债披露须在 CAS30/CAS37 通用要求基础上，叠加国资委财务决算对负债完整性和资金管理的额外要求。

**法规依据：**
- 《企业会计准则第30号——财务报表列报》
- 《企业会计准则第37号——金融工具列报》
- 《中央企业财务决算报告管理办法》

---

## tips

1. **国企附注"双层"披露要求**：既满足 CAS30/CAS37 通用披露（按性质明细/短期应付债券要素/流动性），又满足国资委财务决算对负债完整性和资金管理的额外要求。
2. **"筐类"负债须按性质明细披露**：其他流动负债须按性质列示各构成项目及金额，重大项目单独列示，合计须等于审定表 K4-1 审定数，分类小计与 K4-2 明细勾稽。
3. **负债完整性是国资监管关注点**：其他流动负债须完整反映各项应付义务，预提不足或漏挂将影响国有企业经营业绩和资产负债真实性，与检查表（K4-4）完整性结论一致。
4. **短期应付债券及利息披露**：如含短期应付债券须披露债券要素（面值/利率/期限/利息/违约），债务融资信息是国资监管关注的偿债能力指标。
5. **待转销项税额与预提费用**：待转销项税额须说明与纳税义务的衔接，预提费用须说明项目和依据，涉及财政性资金的须单独说明。
6. **决算口径一致**：附注数据须与年度财务决算报表一致，与上市版差异主要在国资监管层面而非准则层面。

## checklist

### 一、基础披露完整性（与上市版共有）

- [ ] 是否按性质明细披露各构成项目及金额，合计是否等于审定表 K4-1 审定数
- [ ] 重大项目是否单独列示，分类小计是否与 K4-2 明细表勾稽
- [ ] 短期应付债券是否披露债券要素（面值/利率/期限/利息/违约）
- [ ] 是否同时列示期末与期初可比数
- [ ] 附注是否完整反映各项其他流动负债义务（负债完整性）

### 二、专项与国资监管披露

- [ ] 待转销项税额是否说明与纳税义务的衔接
- [ ] 预提费用是否说明预提项目和依据
- [ ] 涉及财政性资金的其他流动负债是否单独说明
- [ ] 短期债务融资是否结合偿债能力说明

### 三、决算口径一致

- [ ] 附注数据是否与年度财务决算报表一致
- [ ] 各项目分类是否与决算报表口径衔接
- [ ] 重大变动是否结合预算执行说明

## risk_areas

### 高风险

1. **隐瞒负债**：其他流动负债未完整反映应付义务（预提不足/待转销项税额漏挂），低估负债、虚增业绩。
2. **短期应付债券要素缺失**：含短期应付债券但未披露要素或违约情况，不满足 CAS37。
3. **基础披露与审定表不勾稽**：附注各项目合计与 K4-1 审定数不一致。

### 中风险

1. **重大项目未单独披露**：大额待转销项税额/预提费用笼统归入"其他"。
2. **财政性款项披露缺失**：涉财政性资金的负债未单独说明。
3. **决算口径差异未调节**：决算数据与审计后附注数据差异未编制调节说明。

### 低风险

1. **披露格式未按决算模板**：与国资委决算报表模板有细微格式差异。
2. **可比信息缺失**：仅列期末数未列期初可比数。
3. **交叉索引不完整**：与 K4-1/K4-2 及决算报表的勾稽索引标注不全。
