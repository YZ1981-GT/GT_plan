# K12-4 营业外收入检查表复核提示词

## 适用底稿
营业外收入凭证检查表（K12-4，科目 6301，损益类贷方），聚焦样本选取方法合理性、凭证核对完整性（无法支付款项转入/盘盈/罚款等依据）、检查比例达标性、异常交易标注充分性、以及截止测试有效性。

## tips

- 样本选取应覆盖金额重大利得、无法支付款项转入、期末集中确认的利得等高风险凭证
- 凭证核对须验证利得的真实性与依据充分性（债权人放弃证明/盘点记录/罚款判决/捐赠协议）
- 检查比例应满足《中国注册会计师审计准则第1314号——审计抽样》要求
- 异常交易标注需明确异常类型（金额异常/时间异常/依据异常/分类异常）
- 重点核查无法支付款项转入的原始负债真实性，防止将仍需支付的负债不当转入收入
- 截止测试关注资产负债表日前后利得是否记入恰当期间，防止跨期调节利润
- 关注营业外收入与其他收益（K10）的分类是否正确（无关性判断）
- 职业怀疑贯穿始终：营业外收入是舞弊调节利润高发领域，对期末大额利得保持警觉

## checklist

### 高风险检查项

- [ ] 样本选取方法是否与营业外收入重大错报风险相匹配
- [ ] 金额重大利得（超过重要性水平）是否100%全覆盖检查
- [ ] 无法支付款项转入是否纳入必选样本并核实原始负债真实性
- [ ] 期末集中确认的营业外收入是否重点核查
- [ ] 每笔样本利得是否有充分依据支持（债权人放弃/盘点/判决/协议）
- [ ] 无法支付款项转入是否确已超诉讼时效或债权人明确放弃
- [ ] 盘盈利得是否有盘点记录及批准文件
- [ ] 是否存在虚构利得或将负债不当转入营业外收入
- [ ] 计入营业外收入的利得是否确与日常活动无关（非其他收益 K10）
- [ ] 是否存在无实际业务支持的利得凭证

### 中风险检查项

- [ ] 抽样总体是否完整（是否从完整的 6301 序时账导出）
- [ ] 样本量是否满足审计目标所需的置信水平
- [ ] 检查比例（已检查金额/本期发生额）是否达到计划水平
- [ ] 凭证日期与记账日期是否一致，是否存在跨期记录
- [ ] 资产负债表日前后利得凭证的截止测试是否执行并记录
- [ ] 罚款收入是否有合法收款依据（判决/仲裁/协议）
- [ ] 捐赠利得的资产价值确认依据是否充分
- [ ] 非经常性损益标识是否在凭证层面得到验证
- [ ] 核对过程中发现的差异是否逐一追踪解决

### 低风险检查项

- [ ] 抽样工作底稿是否完整记录抽样参数（总体/置信水平/可容忍错报）
- [ ] 样本选取过程是否可追溯（随机数种子/系统抽样间隔/选取依据）
- [ ] 凭证检查结果记录格式是否规范统一
- [ ] 检查比例计算公式是否正确（分子=已检查金额，分母=本期发生额）
- [ ] 底稿索引与交叉引用是否完整（关联审定表 K12-1/明细表 K12-2）

## risk_areas

### 高风险

- **虚构利得风险**：将仍需支付的负债不当转入营业外收入，或虚构盘盈/罚款收入，虚增利润，须核实原始负债与利得的真实性
- **无法支付款项转入依据不足风险**：转入营业外收入的应付款项未真正超诉讼时效或债权人未明确放弃，属提前确认利得
- **截止性错误风险**：资产负债表日前后利得未实施截止测试，跨期确认利得以调节利润
- **分类操纵风险**：将与日常活动相关的补助/退税错计营业外收入（或反之），扭曲营业利润与扣非利润
- **异常交易遗漏风险**：期末集中确认、金额异常的大额利得未被标注和重点核查

### 中风险

- **检查比例不足风险**：实际检查比例低于计划水平，审计证据不充分
- **依据核对不深入风险**：仅核对金额而未验证利得依据的法律效力（如放弃债权的书面证明）
- **非经常性损益验证不足风险**：凭证层面未验证非经常性损益标识，影响扣非披露
- **盘盈利得核对不充分风险**：盘盈未追溯盘点记录及资产来源合理性

### 低风险

- **记录不完整风险**：抽样参数/选取过程/核对结果的工作底稿记录不完整
- **索引缺失风险**：凭证检查底稿与审定表/明细表的交叉索引不完整
- **格式不规范风险**：检查结果记录格式不统一

## 法规依据

- 《中国注册会计师审计准则第1314号——审计抽样》：抽样设计、执行与评价
- 《中国注册会计师审计准则第1301号——审计证据》：证据充分性与适当性
- 《中国注册会计师审计准则第1141号——财务报表审计中与舞弊相关的责任》：营业外收入舞弊风险
- 《中国注册会计师审计准则第1211号——识别和评估重大错报风险》：风险导向抽样

## 关注场景

### 样本选取方法合理性
1. 确认必选样本涵盖：金额超重要性水平的利得、无法支付款项转入、期末集中确认的利得、大额盘盈/罚款收入
2. 检查总体完整性：是否从完整的 6301 贷方序时账导出，未人为排除项目
3. 评估分层标准：按金额分层（大额全查/中额抽样）+ 按性质分层（无法支付款项转入/盘盈/罚款重点关注）

### 凭证核对完整性
1. 无法支付款项转入核对：原始应付款项台账→债权人放弃证明/超诉讼时效证据→转入分录→是否真实无需支付
2. 盘盈利得核对：盘点表→盘盈批准文件→资产来源说明→记账分录
3. 罚款收入核对：判决书/仲裁裁决/协议→收款凭证→记账分录
4. 政府补助（营业外收入）核对：补助文件→用途/条件→无关性判断→分类正确性
5. 异常核对结果分类：依据缺失/依据不充分/金额不一致/日期跨期/分类错误

### 检查比例达标性
1. 计算检查比例：已检查利得金额 ÷ 营业外收入本期发生额 × 100%
2. 对照计划比例：实际比例 ≥ 计划比例为达标；不达标须说明原因并评估是否补充样本
3. 高风险项（无法支付款项转入/期末大额利得）检查比例应显著高于一般项

### 异常交易标注充分性
1. 金额异常：单笔超重要性水平/与历史偏差超30%/期末最后几天集中确认
2. 时间异常：资产负债表日前后异常波动/跨期确认
3. 依据异常：无书面依据/依据法律效力存疑/负债仍需支付却转入收入
4. 分类异常：与日常活动相关的利得错计营业外收入
5. 标注要素：异常类型 + 异常描述 + 涉及金额 + 初步判断（合理解释/需进一步调查/疑似错报）
