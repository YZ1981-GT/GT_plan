# K1-2 其他应收款明细表复核提示词

## 概述

本提示词针对其他应收款明细表（K1-2，科目 1221，资产类借方，按期末余额口径）的复核，聚焦：款项性质分类完整性、与审定表 K1-1 的余额勾稽、账龄划分正确性、款项来源与对象核对。其他应收款不同于应收账款，主要由备用金、押金保证金、关联方往来、代垫款等非经营性往来构成，明细表是坏账三阶段计提（K1-7/K1-8）、关联方占款识别（K1-11）、长期挂账评估（K1-10）的数据基础。

**法规依据：**
- 《企业会计准则第22号——金融工具确认和计量》
- 《企业会计准则第36号——关联方披露》
- 《中国注册会计师审计准则第1301号——审计证据》

## tips

1. **款项性质分类是其他应收款明细表的灵魂**：每笔款项须明确性质（备用金/押金保证金/关联方往来/代垫代付/其他），性质决定坏账计提组合、披露分类和资金占用判断，笼统归入"其他"将掩盖关联方非经营性占款和长期挂账风险。
2. **与审定表 K1-1 双向勾稽是余额准确性根基**：明细表各对象期末余额合计（勾稽键 K1-2-end-subtotal）必须等于审定表 K1-1 期末审定数，期初余额须与上年审定数衔接，差异须追溯至具体调整分录（K1-4）。
3. **账龄划分直接驱动坏账三阶段计提**：账龄起算日须以款项形成日为准且口径统一，各账龄段之和须等于对象余额，人为通过滚动挂账缩短账龄将导致 ECL 输入失真、减值计提不足。
4. **关联方标注完整性影响披露与占款识别**：明细中关联方对象须逐笔标注，与 B19 关联方清单核对，遗漏将导致 K1-11 关联方占款分析和附注披露不完整。
5. **备用金/押金/保证金的长期挂账须重点标注**：这类款项应随业务结算及时清理，长期不核销（尤其超 1 年）须逐笔说明原因并评估可收回性，为 K1-10 长期未收回检查提供线索。
6. **明细表是多张下游底稿的数据源**：账龄分布→K1-7 三阶段划分与 K1-8 坏账测算；大额对象→K1-5 大额分析；关联方→K1-11；长账龄→K1-10；分类合计→附注披露，明细表错误将沿数据链传导。

## checklist

### 一、款项性质分类完整性

- [ ] 每笔款项是否标注性质（备用金/押金保证金/关联方往来/代垫款/其他），无"其他"笼统归集
- [ ] 是否逐笔标注关联方对象，并与 B19 关联方清单核对一致
- [ ] 对象名称是否完整规范，无空白或匿名归集
- [ ] 是否存在应归入应收账款/预付账款而错分至其他应收款的经营性往来
- [ ] 大额对象的款项形成背景与业务实质是否有说明

### 二、余额准确性与勾稽

- [ ] 明细表各对象期末余额合计（K1-2-end-subtotal）是否等于审定表 K1-1 期末审定数
- [ ] 明细表期初余额是否与上年审定期末数衔接
- [ ] 各对象余额计算是否正确（期初+本期增加−本期收回=期末）
- [ ] 明细数据是否直接来自科目余额表/序时账，未经人工调整
- [ ] 借方余额异常（应付性质挂入其他应收款）是否已识别

### 三、账龄分析正确性

- [ ] 账龄划分标准是否与会计政策一致（1年以内/1-2年/2-3年/3年以上）
- [ ] 各对象各账龄段金额之和是否等于该对象余额
- [ ] 全部对象各账龄段合计是否与 K1-7 三阶段/K1-8 坏账测算的账龄汇总一致
- [ ] 账龄起算日是否以款项形成日为准且口径统一
- [ ] 1年以上（尤其3年以上）款项是否逐笔标注原因及可收回性

### 四、长期挂账与关联方线索

- [ ] 备用金/押金保证金长期未清理（超1年）是否标注并说明原因
- [ ] 关联方非经营性资金占用是否单独识别，供 K1-11 分析
- [ ] 大额对象是否标注供 K1-5 大额分析覆盖
- [ ] 期后收回情况是否记录，作为可收回性佐证

## risk_areas

### 高风险

1. **关联方非经营性占款隐藏**：关联方资金占用以"其他款项"名义挂账未识别，规避资金占用披露与占用费评估。
2. **明细与审定表不勾稽**：明细合计（K1-2-end-subtotal）与 K1-1 审定数存在差异未调节，存在遗漏或错误记录。
3. **账龄人为缩短**：通过滚动挂账、虚假收回后重新挂账缩短账龄，导致坏账三阶段计提不足。
4. **长期挂账未评估减值**：备用金/押金/代垫款长期未清理但未评估可收回性，减值计提不充分。

### 中风险

1. **款项性质错分**：经营性往来错分至其他应收款，或性质归类不当影响坏账计提组合和披露分类。
2. **关联方标注遗漏**：部分关联方对象未标注，导致 K1-11 与附注关联方披露不完整。
3. **账龄起算口径不一**：不同对象采用不同起算日，影响账龄分析可比性与减值输入。

### 低风险

1. **明细表格式不规范**：对象排序、金额单位、辅助信息不统一。
2. **小额款项归集**：零星小额款项归入"其他"未附明细清单。
3. **交叉索引不完整**：与 K1-5/K1-10/K1-11 及附注的交叉引用标注不全。
