# K9-1 管理费用审定表复核提示词

## 概述

本提示词针对管理费用审定表（K9-1，科目 6602，损益类借方，取本期发生额）的复核，聚焦：发生额勾稽、试算平衡表核对、审计调整完整性、分类与截止。管理费用项目繁杂（职工薪酬、折旧摊销、办公费、中介机构费、研发费用列示等），主要风险为完整性、跨期截止与错分类（尤其研发费用、业务招待费的列示与税前扣除口径）。

**法规依据：**
- 《企业会计准则第30号——财务报表列报》
- 《中国注册会计师审计准则第1301号——审计证据》
- 《中国注册会计师审计准则第1141号——财务报表审计中与舞弊相关的责任》

---

## tips

1. **取"发生额"非"余额"**：审定数=本期借方发生额−贷方±调整，试算表核对针对 6602 发生额。
2. **发生额勾稽为生命线**：审定合计=未审+AJE+RJE，且=明细表 K9-2 审定合计，差异须追溯。
3. **完整性与截止**：关注期末应计未计的中介费、审计费、办公费；有无跨期调节利润。
4. **研发费用列示**：计入管理费用的研发费用是否与研发费用归集（I/N 循环）口径一致、是否需单独列报。
5. **跨底稿闭环**：审定合计↔K9-2 明细↔试算表 6602↔利润表"管理费用"行。
6. **异常变动**：管理费用较上期变动超 30% 或与业务规模背离须解释（如折旧突变、招待费异常）。

## checklist

### 一、发生额勾稽与试算表核对

- [ ] 审定表各项目审定数=未审发生额+AJE+RJE 是否正确
- [ ] 审定合计是否与明细表 K9-2 审定合计一致
- [ ] 审定合计是否与试算平衡表 6602 审定发生额一致
- [ ] 未审发生额是否与试算表 6602 未审发生额一致
- [ ] 上期审定数是否与上年底稿一致

### 二、审计调整完整性

- [ ] 已确认的账项调整（AJE，补提管理费用）是否完整反映
- [ ] 重分类调整（RJE，与销售费用/成本互转）是否完整反映
- [ ] 调整分录借贷平衡、证据充分、经审批
- [ ] 未调整错报是否记入 SUD

### 三、分类与截止

- [ ] 各明细项目分类是否正确（薪酬/折旧摊销/办公/中介费/研发等）
- [ ] 研发费用是否与研发归集口径一致、是否需单独列报
- [ ] 是否存在应资本化项目费用化或错分至其他费用科目
- [ ] 资产负债表日前后费用是否记入恰当期间
- [ ] 关联方管理费用分摊是否公允、单独识别

## risk_areas

### 高风险

1. **完整性缺失**：期末应计未计的中介费/审计费/办公费导致费用少计、利润虚增。
2. **跨期调节**：管理费用提前或递延确认操纵当期利润。
3. **审计调整遗漏**：已确认调整未纳入审定表。
4. **审定表与试算表/明细表不勾稽**：发生额口径不一致。

### 中风险

1. **费用错分类**：管理费用与销售费用/成本边界不清；研发费用列示口径不一致。
2. **关联方分摊不公允**：集团内管理费用分摊存在利益输送。
3. **异常变动未解释**：折旧/招待费等大幅波动未分析。

### 低风险

1. **格式与索引不规范**。
2. **变动项目辅助说明不足**。
