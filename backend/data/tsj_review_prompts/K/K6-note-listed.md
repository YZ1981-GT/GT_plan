# K6-note-listed 持有待售附注披露复核提示词（上市公司）

## 概述

本提示词针对持有待售上市公司附注披露底稿（K6-note-listed，科目 1481 持有待售资产/2605 持有待售负债）的复核，聚焦上市公司财务报表附注中持有待售相关披露的充分性和准确性：持有待售资产/负债/处置组披露、公允价值减去出售费用的计量披露、减值确认披露、终止经营列报、以及与审定表（K6-1）的勾稽闭环。持有待售及终止经营涉及重大资产处置和经营板块退出，是投资者判断企业战略调整和未来盈利结构的关键信息，披露不充分将掩盖处置损失或误导对持续经营业务的判断。

**法规依据：**
- 《企业会计准则第42号——持有待售的非流动资产、处置组和终止经营》
- 《企业会计准则第8号——资产减值》
- 《企业会计准则第30号——财务报表列报》
- 《公开发行证券的公司信息披露编报规则第15号——财务报告的一般规定》

## tips

1. **持有待售资产/负债/处置组分类披露**：附注须分别披露持有待售的非流动资产、处置组包含的资产和负债明细，处置组须列示其构成（各类资产及负债），资产（1481）与负债（2605）分区列示。
2. **分类为持有待售的事实与预计**：须披露划分为持有待售的原因、预计处置方式、预计处置时间及是否属于关联方交易，说明分类符合 CAS42 条件（可立即出售+一年内极可能完成）。
3. **孰低计量与减值披露**：须披露以账面价值与公允价值减去出售费用孰低计量的结果，公允价值的确定方法及层次，以及因孰低确认的资产减值损失金额。
4. **终止经营列报**：若处置组构成终止经营，须在利润表单独列示终止经营损益，附注披露终止经营的收入、费用、利润总额、所得税及现金流量，并重述比较期间。
5. **停止折旧摊销披露**：须说明划分为持有待售后已停止计提折旧/摊销，持有待售资产不再折旧。
6. **闭环勾稽**：附注持有待售资产/负债合计=审定表 K6-1 审定数=试算表 1481/2605；减值金额与 K6 减值测算及资产减值损失（K11）勾稽；终止经营损益与利润表列报一致。

## checklist

### 一、分类与构成披露

- [ ] 持有待售的非流动资产、处置组是否分别披露
- [ ] 处置组是否列示所含资产及负债的构成明细
- [ ] 持有待售资产（1481）与负债（2605）是否分区列示
- [ ] 附注持有待售资产/负债合计是否与审定表 K6-1 一致
- [ ] 是否同时披露期末数和期初数（可比信息）
- [ ] 划分为持有待售的原因、预计处置方式及时间是否披露

### 二、计量、减值与分类条件

- [ ] 是否披露以账面价值与公允价值减出售费用孰低计量
- [ ] 公允价值确定方法及层次是否披露
- [ ] 因孰低确认的资产减值损失金额是否披露
- [ ] 减值金额是否与 K6 减值测算及 K11 资产减值损失勾稽
- [ ] 是否说明分类符合 CAS42 条件（可立即出售+一年内极可能完成）
- [ ] 是否披露划分持有待售后已停止折旧/摊销
- [ ] 【条件检查：若为关联方交易】处置对手方是否为关联方，定价是否公允

### 三、终止经营列报

- [ ] 处置组是否构成终止经营，判断依据是否披露
- [ ] 终止经营损益是否在利润表单独列示
- [ ] 终止经营的收入、费用、利润总额、所得税、现金流量是否披露
- [ ] 比较期间的终止经营损益是否重述
- [ ] 持续经营与终止经营的划分是否清晰

## risk_areas

### 高风险

1. **分类条件不满足仍披露持有待售**：不符合 CAS42 条件的资产列为持有待售，掩盖长期闲置资产减值或规避折旧计提。
2. **减值披露不充分**：孰低计量确认的减值金额未披露或与 K6 测算/K11 不勾稽，掩盖处置损失。
3. **终止经营列报缺失**：处置组构成终止经营但未单独列示终止经营损益、未重述比较期间，误导对持续经营业务盈利的判断。
4. **附注与审定表不一致**：持有待售资产/负债合计与审定表审定数不符，属重大披露错误。

### 中风险

1. **公允价值确定方法未披露**：孰低计量的公允价值确定方法及层次未说明，无法评估计量可靠性。
2. **停止折旧摊销未披露**：未说明划分持有待售后已停止折旧/摊销。
3. **关联方交易未披露**：处置对手方为关联方但未披露关系及定价公允性。

### 低风险

1. **披露格式不规范**：表格标题、列序、金额单位不严格按编报规则。
2. **处置进展说明不足**：预计处置时间/方式的进展信息不充分。
