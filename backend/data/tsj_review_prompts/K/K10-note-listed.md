# K10-note-listed 其他收益附注披露复核提示词（上市公司）

## 概述

本提示词针对其他收益上市公司附注披露底稿（K10-note-listed，科目 6117）的复核，聚焦上市公司财务报表附注中其他收益相关披露的充分性和准确性：其他收益分项披露、政府补助明细、非经常性损益标识、CAS16 政府补助列报要求、以及与审定表/明细表/递延收益的勾稽闭环。其他收益列报于利润表营业利润之内，其构成（政府补助等）及非经常性属性是投资者判断经营盈利质量、剔除政府补助依赖的关键信息，披露不充分将影响扣非净利润判断。

**法规依据：**
- 《企业会计准则第16号——政府补助》
- 《企业会计准则第30号——财务报表列报》
- 《公开发行证券的公司信息披露编报规则第15号——财务报告的一般规定》
- 《公开发行证券的公司信息披露解释性公告第1号——非经常性损益》

## tips

1. **其他收益分项披露**：附注须按补助/收益项目分项披露其他收益的本期金额和上期金额（如增值税加计抵减、稳岗补贴、即征即退、各类产业扶持补助等），不得笼统列示一个总数。
2. **政府补助明细披露**：须披露主要政府补助项目名称、金额、与资产/收益相关分类、列报项目（其他收益/营业外收入）及是否影响当期损益，重大补助单独列示。
3. **非经常性损益标识**：其他收益中与主营业务无直接关系、偶发性的政府补助属非经常性损益，须与非经常性损益明细表勾稽；与主营密切相关且持续的补助（如即征即退）通常不属非经常性。
4. **CAS16 会计政策披露**：须披露政府补助确认、计量、列报的会计政策（总额法/净额法选择、与日常活动相关性判断标准）。
5. **与递延收益勾稽**：其他收益中来自递延收益本期摊销的部分应与 K7 递延收益变动表本期摊销转出勾稽。
6. **闭环勾稽**：附注其他收益合计=利润表其他收益行=审定表 K10-1 审定合计=明细表 K10-2 本期发生额合计；非经常性损益部分与非经常性损益明细勾稽。

## checklist

### 一、分项与金额披露

- [ ] 其他收益是否按项目分项披露（不笼统列一个总数）
- [ ] 各分项是否同时披露本期数和上期数（可比信息）
- [ ] 各分项合计是否等于审定表 K10-1 审定合计
- [ ] 附注其他收益合计是否与利润表其他收益行一致
- [ ] 主要政府补助项目名称、金额是否列示完整

### 二、政府补助与非经常性损益

- [ ] 计入其他收益的政府补助是否与营业外收入的补助区分披露
- [ ] 与资产相关补助本期摊销计入其他收益部分是否与 K7 勾稽
- [ ] 非经常性损益标识是否正确（与主营无关的偶发补助）
- [ ] 非经常性损益中政府补助金额是否与非经常性损益明细表勾稽
- [ ] 与主营密切相关持续性补助（即征即退等）是否恰当排除非经常性
- [ ] 重大补助是否说明批准部门、用途及性质

### 三、会计政策与勾稽

- [ ] 政府补助会计政策披露是否完整（确认/计量/列报/总额净额法）
- [ ] 与日常活动相关性判断标准是否披露
- [ ] 附注其他收益期末数是否与审定表一致
- [ ] 本期新增补助与递延收益结转补助是否区分说明

## risk_areas

### 高风险

1. **非经常性损益标识错误**：其他收益中政府补助非经常性属性判断错误，影响扣非净利润披露，误导投资者判断经营盈利质量。
2. **分项披露缺失**：其他收益笼统列一个总数，未分项披露补助构成，掩盖对政府补助的依赖。
3. **附注与利润表/审定表不一致**：其他收益合计与利润表、审定表不勾稽，属重大披露错误。

### 中风险

1. **政府补助明细不充分**：重大补助未披露项目名称、金额、分类及列报项目。
2. **会计政策披露不完整**：总额法/净额法选择或日常活动相关性判断标准未披露。
3. **与递延收益勾稽缺失**：来自递延收益摊销的其他收益未与 K7 变动表勾稽说明。

### 低风险

1. **披露格式不规范**：表格标题、列序、金额单位不严格按编报规则。
2. **文字描述模板化**：会计政策照搬准则原文，未结合本企业实际补助情况。
