# K3-7 其他应付款检查表复核提示词

## 概述

本提示词针对其他应付款检查表（K3-7，凭证级检查+反向截止，科目 2241）的复核，聚焦：样本选取充分性、凭证核对完整性、反向截止（未入账负债搜索）充分性、检查比例与异常标注。其他应付款首要认定是"完整性"，本检查表除对本期发生额逐笔核对存在性/准确性外，重点通过反向截止测试（期后付款/期后发票倒查）搜索资产负债表日已存在但未入账的负债，是完整性认定的关键证据。

**法规依据：**
- 《中国注册会计师审计准则第1314号——审计抽样》
- 《中国注册会计师审计准则第1301号——审计证据》
- 《中国注册会计师审计准则第1141号——财务报表审计中与舞弊相关的责任》

## tips

1. **反向截止是负债完整性的核心程序**：通过资产负债表日后一段期间的付款凭证、收到的发票、银行付款记录倒查，识别应属本期但未入账的其他应付款（未入账负债搜索），这是防止负债低估的关键，仅测已入账项目无法发现遗漏。
2. **样本选取须兼顾存在性与完整性**：已入账样本测存在性（贷方新增真实、借方支付真实），期后付款/发票样本测完整性（应记未记），高风险项（大额、关联方、期末突增、押金暂收）须纳入必选。
3. **凭证核对须验证支付义务真实性**：核对记账凭证与原始单据（合同、收款收据、押金协议、发票、银行回单），验证款项性质、义务真实性和金额准确性，警惕虚构负债或漏记负债。
4. **反向截止范围须充分**：期后倒查期间须覆盖足够长度（通常至审计报告日或足以捕获重大遗漏），倒查金额门槛须与重要性水平匹配，范围不足将遗漏未入账负债。
5. **检查比例须达标**：检查比例=已检查金额÷本期发生额（借方+贷方分别计算），本期发生额取自 K3-2，比例不达标须说明并评估补充样本。
6. **异常与调整闭环**：搜索到的未入账负债须评估金额并通过 K3-3 补记调整（AJE），异常项目（无审批、整数金额、关联方、无合同支撑）须标注并记录初步判断。

## checklist

### 一、样本选取充分性

- [ ] 样本选取方法是否与识别的重大错报风险匹配（CAS1314）
- [ ] 已入账样本（贷方新增/借方支付）与期后付款/发票样本是否分别选取
- [ ] 金额重大项目是否全查，高风险项（大额/关联方/期末突增）是否纳入必选
- [ ] 抽样总体是否完整（本期发生额取自 K3-2，无人为排除）

### 二、凭证核对完整性

- [ ] 记账凭证与原始单据是否核对一致（金额/对象/性质）
- [ ] 原始单据是否齐全（合同/押金协议/收款收据/发票/银行回单）
- [ ] 支付义务真实性是否验证（非虚构负债/非漏记负债）
- [ ] 审批手续是否完整、权限是否匹配
- [ ] 核对差异是否逐笔追踪解决

### 三、反向截止（未入账负债搜索）

- [ ] 期后付款/发票倒查是否执行并记录
- [ ] 倒查期间是否覆盖足够长度（至报告日或足以捕获重大遗漏）
- [ ] 倒查金额门槛是否与重要性水平匹配
- [ ] 搜索到的未入账负债是否评估金额
- [ ] 应记未记负债是否通过 K3-3 补记调整（AJE）

### 四、检查比例与异常

- [ ] 检查比例（已检查÷本期发生额）是否达到计划水平
- [ ] 借方/贷方检查比例是否分别计算达标，分母是否与 K3-2 一致
- [ ] 异常项目（无审批/整数金额/关联方/无合同）是否标注异常类型
- [ ] 异常事项是否记录初步判断并评估对总体影响

## risk_areas

### 高风险

1. **未入账负债未搜索/未补记**：反向截止未执行或范围不足，资产负债表日已存在负债未被发现，负债严重低估。
2. **虚构或漏记负债**：其他应付款存在无真实支付义务的虚构负债，或应付未付款项漏记。
3. **反向截止范围不足**：期后倒查期间过短或门槛过高，遗漏重大未入账负债。

### 中风险

1. **检查比例不足**：实际检查比例低于计划水平，审计证据不充分。
2. **凭证核对不深**：仅核对金额未验证支付义务真实性和款项性质。
3. **异常未标注**：异常大额/关联方/无审批款项未标注异常。

### 低风险

1. **抽样记录不完整**：抽样参数/倒查过程/异常处理记录不完整。
2. **异常标注不规范**：异常类型分类不清或初步判断缺失。
3. **交叉索引不完整**：与 K3-2/K3-3/K3-4 的交叉引用标注不全。
