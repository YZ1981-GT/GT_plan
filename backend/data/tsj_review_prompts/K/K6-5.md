# K6-5 持有待售减值测试复核提示词

## 概述

本提示词针对持有待售减值测试底稿（K6-5，科目 1481，孰低法）的复核。CAS42 规定持有待售资产按账面价值与公允价值减去出售费用两者孰低计量，账面价值高于公允价值减出售费用的差额确认为资产减值损失。复核聚焦：孰低计量的正确应用、公允价值的确定依据、出售费用的合理估计、减值确认的充分性、以及与 K11 资产减值损失/处置损益的勾稽。核心风险为高估公允价值/低估出售费用导致减值计提不足、以及减值转回处理不当。

**法规依据：**
- 《企业会计准则第42号——持有待售的非流动资产、处置组和终止经营》
- 《企业会计准则第8号——资产减值》
- 《中国注册会计师审计准则第1301号——审计证据》

## tips

1. **孰低计量是持有待售减值的核心**：持有待售资产按"账面价值"与"公允价值减出售费用"孰低计量，须复算孰低取值，账面价值超出部分即减值金额，取值方向错误将直接导致减值多提或少提。
2. **公允价值须有可靠估值依据**：优先采用销售协议价，其次活跃市场报价，再次采用估值技术（评估报告），须核对公允价值的层级和依据，高估公允价值是规避减值的常见手法。
3. **出售费用须合理且完整估计**：出售费用包括为出售直接发生的增量成本（中介佣金、法律费用、评估费、相关税费、资产搬迁/清理费等），不含融资费用和所得税费用，低估出售费用会虚增公允价值净额、少提减值。
4. **减值确认须计入当期损益并勾稽**：孰低产生的减值损失应计入当期损益（资产减值损失/处置损益），须与 K11 资产减值损失底稿和利润表勾稽，减值不得计入其他综合收益或递延。
5. **减值转回受限**：后续期间公允价值减出售费用回升的，可在原减值范围内转回减值利得，但不得超过划分持有待售前的账面价值（考虑正常折旧后），转回超限或转回缺乏依据是关注点。
6. **与初始确认和明细表衔接**：减值测试须与 K6-4 初始确认（分类条件满足才计量）、K6-2 明细表（减值列反映）勾稽，减值发生时点应为划分持有待售之日或后续公允价值下降之时。

## checklist

### 一、孰低计量应用（高风险）

- [ ] 【必检】是否按账面价值与公允价值减出售费用孰低计量
- [ ] 【必检】孰低取值方向是否正确（取两者较低者）
- [ ] 【必检】账面价值超出公允价值减出售费用的差额是否确认为减值
- [ ] 【必检】减值金额复算是否与账面减值一致
- [ ] 【风险检查】是否存在孰低取值方向错误导致减值多提/少提

### 二、公允价值与出售费用（高风险）

- [ ] 【必检】公允价值是否有可靠依据（销售协议价/市场报价/评估报告）
- [ ] 【必检】公允价值估值层级是否恰当（优先协议价，次市场价，再估值技术）
- [ ] 【必检】出售费用是否合理完整估计（中介费/法律费/评估费/税费/清理费）
- [ ] 【必检】出售费用是否不含融资费用和所得税费用
- [ ] 【风险检查】是否存在高估公允价值以规避减值确认
- [ ] 【风险检查】是否存在低估出售费用以虚增公允价值净额

### 三、减值确认、转回与勾稽（中风险）

- [ ] 【必检】减值损失是否计入当期损益（资产减值损失/处置损益）
- [ ] 【必检】减值是否与 K11 资产减值损失底稿和利润表勾稽
- [ ] 【必检】减值是否在 K6-2 明细表减值列足额反映
- [ ] 【条件检查：若公允价值回升】减值转回是否不超过原减值且不超过划分前账面价值（扣正常折旧）
- [ ] 【风险检查】减值确认时点是否恰当（划分之日或公允价值下降之时）
- [ ] 【风险检查】减值转回是否有公允价值回升的客观依据

## risk_areas

### 高风险

1. **高估公允价值规避减值**：采用明显高于可实现价值的公允价值，或估值报告参数不合理，导致减值计提不足。
2. **低估出售费用少提减值**：出售费用估计不完整或偏低，虚增公允价值净额，少提减值。
3. **孰低取值方向错误**：错误地取账面价值与公允价值净额的较高者，导致减值确认错误。

### 中风险

1. **减值确认时点不当**：应在划分之日或公允价值下降时确认减值却延迟确认，跨期调节损益。
2. **减值转回超限或无依据**：公允价值回升时转回减值超过原减值金额或划分前账面价值，或转回缺乏客观依据。
3. **减值未与 K11/利润表勾稽**：减值金额与资产减值损失底稿或利润表不一致。

### 低风险

1. **格式与索引不规范**：孰低计量测算过程、估值参数、交叉索引标注不完整。
2. **估值依据说明不足**：公允价值确定的方法、参数和依据说明不充分。
