# K3-1 其他应付款审定表复核提示词

## 概述

本提示词针对其他应付款审定表（K3-1，科目 2241，负债类取期末余额）的复核。其他应付款核算押金保证金、暂收款、代扣代缴、关联方往来、往来挂账等。聚焦：期初期末勾稽、试算表核对、负债完整性（隐瞒负债）、长期挂账与关联方占用、按性质与账龄双维度分类。核心风险为完整性——低估负债虚增净资产。

**法规依据：**
- 《企业会计准则第30号——财务报表列报》
- 《企业会计准则第36号——关联方披露》
- 《中国注册会计师审计准则第1301号——审计证据》
- 《中国注册会计师审计准则第1141号——与舞弊相关的责任》

---

## tips

1. **负债类取"期末余额"**：审定数=期初+本期贷方−本期借方±调整。
2. **完整性是负债首要风险**：重点搜寻未入账负债（应付未付、暂收长期挂账），确认负债不被低估。
3. **期初期末勾稽**：期初审定数=上年期末审定数；审定合计=明细表 K3-2 合计（K3-2-detail-total）。
4. **试算表核对**：审定合计与试算表 2241 审定余额一致（贷方方向）。
5. **长期挂账处理**：确实无需支付的其他应付款（超诉讼时效、债权人放弃）应转营业外收入（K12），不得长期挂账规避收益。
6. **关联方与双维度分类**：关联方占用款单独识别（对 B19）；审定表按性质分类兼顾账龄分析，与报表列报口径一致。

## checklist

### 一、期初期末勾稽与试算表核对

- [ ] 期初审定数是否等于上年期末审定数
- [ ] 审定数=期初+本期贷方−本期借方±调整 是否正确
- [ ] 审定合计是否与明细表 K3-2 合计一致（按性质与按账龄两维度合计相等）
- [ ] 审定合计是否与试算表 2241 审定余额一致（贷方方向）

### 二、负债完整性

- [ ] 是否执行未入账负债搜寻（期后付款测试、合同/协议核查）
- [ ] 应付未付的押金、暂收款、代扣代缴是否完整入账
- [ ] 是否存在以低估其他应付款虚增净资产的迹象

### 三、长期挂账与关联方

- [ ] 长期挂账、无需支付的款项是否评估转营业外收入
- [ ] 关联方其他应付款是否单独识别，与 B19 清单核对
- [ ] 大额往来性质、审批是否合规
- [ ] 押金保证金到期是否清理

### 四、审计调整完整性

- [ ] 已确认的账项/重分类调整是否完整反映
- [ ] 一年以上应付款是否评估重分类至非流动
- [ ] 调整分录借贷平衡、证据充分、经审批

## risk_areas

### 高风险

1. **负债完整性缺失**：应付未付款项未入账，低估负债、虚增净资产。
2. **长期挂账规避收益**：无需支付款项长期挂账不转营业外收入。
3. **关联方资金占用**：关联方大额往来未识别、未披露。
4. **期初期末不勾稽 / 与试算表不一致**。

### 中风险

1. **性质/账龄分类不当**：双维度分类合计不等或列报不准确。
2. **代扣代缴挂账异常**：代扣个税/社保长期挂账未缴。
3. **审计调整遗漏**。

### 低风险

1. **格式与索引不规范**。
2. **明细项目说明不足**。
