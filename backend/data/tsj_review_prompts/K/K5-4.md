# K5-4 产品质量保证检查复核提示词

## 概述

本提示词针对预计负债项下产品质量保证检查底稿（K5-4，科目 2701）的复核。产品质量保证是最常见的预计负债之一，通常伴随商品销售产生的保修义务，须在销售确认时按最佳估计计提。复核聚焦：CAS13 确认条件的满足、历史赔付率的合理性、计提比例的测算依据、以及与收入（销售规模）的匹配性。核心风险为计提比例缺乏历史数据支撑（少提虚增利润或超额计提"蓄水池"）、历史赔付率选取偏差、以及质保义务与收入确认期间不匹配。

**法规依据：**
- 《企业会计准则第13号——或有事项》
- 《企业会计准则第14号——收入》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **质保义务的确认基础是销售交易**：产品保修属于随销售产生的现时义务，须在收入确认时按最佳估计计提，计提基数通常为本期含保修条款的销售收入或销售数量。
2. **历史赔付率是最佳估计的核心依据**：计提比例应基于过去若干年（通常 3 年以上）实际保修支出占对应销售额的比率，须核对历史赔付数据的完整性和口径一致性。
3. **计提比例合理性须重新测算验证**：以历史赔付率×本期计提基数复算应计提金额，与账面计提金额比较，差异重大须查明原因，防止人为调节比例。
4. **区分保证类质保与服务类质保（CAS14）**：保证类质保（确保产品符合既定标准）计入预计负债；服务类质保（单独销售的延保服务）作为单项履约义务确认收入，不得混为预计负债。
5. **关注质保期与产品寿命匹配**：长期质保义务（如多年保修）时间价值影响重大的应折现；质保期跨年度的须评估期末未到期部分的合理计提。
6. **完整性与转回合理性并重**：既要防止应计提未计提（少提），也要关注实际赔付率持续低于计提率时超额计提的转回是否及时、有据。

## checklist

### 一、确认条件与计提基础（高风险）

- [ ] 【必检】产品保修义务是否满足 CAS13 三个确认条件（现时义务+很可能+可靠计量）
- [ ] 【必检】计提基数（含保修条款的销售收入/数量）是否准确、口径一致
- [ ] 【必检】是否区分保证类质保（预计负债）与服务类质保（CAS14 履约义务）
- [ ] 【必检】质保计提是否在收入确认的同一期间进行（匹配原则）
- [ ] 【条件检查：若有免费保修与延保服务并存】两者是否分别核算未混淆

### 二、历史赔付率与计提比例合理性（高风险）

- [ ] 【必检】历史赔付率是否基于过去 3 年以上实际保修支出/对应销售额计算
- [ ] 【必检】历史赔付数据的完整性和口径一致性是否核对
- [ ] 【必检】以历史赔付率×本期计提基数重新测算应计提金额，与账面比较是否合理
- [ ] 【必检】计提比例变化（较上年）是否有合理解释（产品质量变化/保修政策调整）
- [ ] 【风险检查】是否存在人为调低计提比例以少提负债、虚增利润
- [ ] 【风险检查】是否存在超额计提形成"利润蓄水池"以后转回

### 三、期末余额与转回评估（中风险）

- [ ] 【必检】期末质保预计负债余额是否与实际未到期质保义务规模匹配
- [ ] 【必检】本期实际保修支出是否冲减预计负债，未超提部分是否合理
- [ ] 【必检】实际赔付率持续低于计提率时，超额部分是否及时转回并有依据
- [ ] 【条件检查：若质保期跨多年】期末未到期质保部分是否合理计提，是否需折现
- [ ] 【风险检查】是否存在长期挂账不动的僵尸质保余额

## risk_areas

### 高风险

1. **计提比例缺乏历史数据支撑**：质保计提比例为管理层主观确定，无历史赔付率测算依据，金额可靠性存疑。
2. **人为调节计提比例操纵利润**：调低计提率少提负债虚增利润，或超额计提形成"蓄水池"以后期间转回。
3. **保证类与服务类质保混淆（CAS14）**：将应作为单项履约义务确认收入的延保服务错误计入预计负债，或反之。
4. **应计提未计提**：有保修条款的销售未相应计提质保预计负债，少计负债、虚增利润。

### 中风险

1. **历史赔付数据口径不一致**：历史赔付率计算的分子分母口径前后不一，导致比率失真。
2. **质保期跨年未合理计提**：期末未到期的长期质保义务未合理计提或未折现。
3. **超额计提未及时转回**：实际赔付持续低于计提，超额部分长期挂账不转回。

### 低风险

1. **格式与索引不规范**：检查底稿列序、计算过程、交叉索引标注不完整。
2. **产品分类说明不足**：未按产品类别分别列示保修计提，影响赔付率分析的针对性。
