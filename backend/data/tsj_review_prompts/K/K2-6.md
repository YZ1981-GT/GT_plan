# K2-6 其他流动资产检查表复核提示词

## 概述

本提示词针对其他流动资产检查表（K2-6，凭证级检查，科目 1231）的复核，聚焦：样本选取充分性、凭证核对完整性、检查比例达标性、异常与流动性分类标注。本检查表对其他流动资产各项目（待摊费用、预缴税费、合同取得成本等）逐笔选样、核对记账凭证与原始单据，验证项目真实性、资本化依据和摊销期限，是存在性、计价与分类认定的直接证据。

**法规依据：**
- 《中国注册会计师审计准则第1314号——审计抽样》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **样本选取须覆盖各类项目与高风险项**：其他流动资产为"筐类"科目，样本须覆盖待摊费用、预缴税费、合同取得成本等各主要项目，大额、长期挂账、异常项目须纳入必选，金额重大项目全查（CAS1314）。
2. **凭证核对须验证项目真实性与资本化依据**：核对记账凭证与原始单据（费用发票、缴款凭证、合同、审批单），核对内容包括金额、性质、资本化/待摊依据、摊销期限，警惕将应费用化项目挂账为资产。
3. **检查比例须达标**：检查比例=已检查金额÷其他流动资产总额（或本期发生额），须达到计划水平，本期发生额取自明细表 K2-2，比例不达标须说明并评估补充样本。
4. **重点关注摊销期限与流动性分类**：核对待摊费用/合同取得成本的摊销期限是否合理（长期待摊应重分类）、预缴税费是否可实际抵扣退还，验证流动性分类是否正确。
5. **异常与长期挂账须标注**：长期未摊销、应转出未转出、不可抵扣进项、超一年项目未重分类等异常须标注类型并记录初步判断。
6. **抽样与结果可追溯**：抽样方法、样本量、检查比例、异常处理须记录完整，异常错报须评估对总体影响并考虑是否调整（K2-3）或扩样。

## checklist

### 一、样本选取充分性

- [ ] 样本选取方法是否与识别的重大错报风险匹配（CAS1314）
- [ ] 样本是否覆盖各主要项目（待摊/预缴税费/合同取得成本）
- [ ] 金额重大项目是否全查，长期挂账/异常项目是否纳入必选
- [ ] 抽样总体是否完整（取自 K2-2，无人为排除）

### 二、凭证核对完整性

- [ ] 记账凭证与原始单据是否核对一致（金额/性质）
- [ ] 原始单据是否齐全（发票/缴款凭证/合同/审批单）
- [ ] 资本化/待摊依据是否充分（非应费用化项目挂账）
- [ ] 摊销期限是否合理并与 K2-5 一致
- [ ] 核对差异是否逐笔追踪解决

### 三、检查比例与分类

- [ ] 检查比例（已检查÷总额或发生额）是否达到计划水平
- [ ] 检查比例分母是否与 K2-2 一致
- [ ] 流动性分类是否正确（超一年项目是否应重分类）
- [ ] 预缴税费是否可实际抵扣/退还

### 四、异常标注

- [ ] 长期未摊销/应转出未转出项目是否标注异常
- [ ] 不可抵扣进项税/无法退还预缴税费是否标注
- [ ] 异常事项是否记录初步判断（合理/需调查/疑似错报）
- [ ] 异常错报是否评估对总体影响并考虑调整或扩样

## risk_areas

### 高风险

1. **应费用化项目挂账为资产**：日常费用/无资本化依据项目挂入其他流动资产，虚增资产、递延费用。
2. **样本未覆盖高风险项**：抽样遗漏长期挂账、异常大额项目，未覆盖重大错报风险。
3. **不可抵扣/无法退还税费未转出**：预缴税费实际无法抵扣退还但仍挂账，资产高估。

### 中风险

1. **检查比例不足**：实际检查比例低于计划水平，审计证据不充分。
2. **摊销期限核对不深**：未核对摊销期限合理性，长期待摊未识别重分类。
3. **凭证核对不深**：仅核对金额未验证资本化/待摊依据。

### 低风险

1. **抽样记录不完整**：抽样参数/异常处理记录不完整。
2. **异常标注不规范**：异常类型分类不清或初步判断缺失。
3. **交叉索引不完整**：与 K2-2/K2-3/K2-5 的交叉引用标注不全。
