# K7-1 递延收益审定表复核提示词

## 概述

本提示词针对递延收益审定表（K7-1，科目 2401，负债类取期末余额）的复核。递延收益主要核算与资产相关的政府补助（分期计入损益）及与收益相关但需分期确认的补助。聚焦：期初期末勾稽、试算表核对、CAS16 政府补助确认与摊销、与其他收益（K10）/营业外收入（K12）的结转勾稽。核心风险为摊销不当（多转/少转损益）、总额法/净额法选择错误、分类错误。

**法规依据：**
- 《企业会计准则第16号——政府补助》
- 《企业会计准则第30号——财务报表列报》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **负债类取"期末余额"**：审定数=期初+本期收到（增加）−本期摊销转出±调整。
2. **期初期末勾稽**：期初审定数=上年期末审定数；审定合计=明细表 K7-2 期末合计（K7-2-detail-end-total）。
3. **试算表核对**：审定合计与试算表 2401 审定余额一致（贷方方向）。
4. **摊销与损益勾稽**：本期摊销转出额应与计入其他收益（K10）/营业外收入（K12）的政府补助金额勾稽一致；与资产相关补助按资产使用寿命系统分摊。
5. **确认与计量**：政府补助须有批文/到账依据；总额法与净额法选择一致并恰当；与资产相关计递延收益、与收益相关区分是否需递延。
6. **闭环**：审定↔K7-2 明细↔试算表 2401↔K10/K12 结转↔附注。

## checklist

### 一、期初期末勾稽与试算表核对

- [ ] 期初审定数是否等于上年期末审定数
- [ ] 审定数=期初+收到−摊销转出±调整 是否正确
- [ ] 审定合计是否与明细表 K7-2 期末合计一致
- [ ] 审定合计是否与试算表 2401 审定余额一致（贷方方向）

### 二、确认、摊销与结转勾稽

- [ ] 每笔政府补助是否有批文/到账依据，确认时点恰当
- [ ] 与资产相关补助是否按资产寿命系统分摊
- [ ] 本期摊销转出额是否与 K10 其他收益/K12 营业外收入结转一致
- [ ] 总额法/净额法选择是否恰当且一致
- [ ] 与收益相关补助是否区分应递延 vs 直接计入当期

### 三、审计调整完整性

- [ ] 已确认的账项/重分类调整是否完整反映
- [ ] 一年内摊销部分是否重分类考虑
- [ ] 调整分录借贷平衡、证据充分、经审批

## risk_areas

### 高风险

1. **摊销不当**：多转/少转损益调节利润，或与 K10/K12 结转不勾稽。
2. **确认时点/依据不当**：无批文提前确认或满足条件延迟确认递延收益。
3. **期初期末不勾稽 / 与试算表不一致**。

### 中风险

1. **总额法/净额法错误**：方法选择不当或前后不一致。
2. **分类错误**：与资产/收益相关划分错误，影响摊销期间。
3. **审计调整遗漏**。

### 低风险

1. **格式与索引不规范**。
2. **补助项目说明不足**。
