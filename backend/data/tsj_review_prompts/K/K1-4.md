# K1-4 其他应收款调整分录复核提示词

## 概述

本提示词针对其他应收款调整分录汇总表（K1-4）的复核，含账项调整（AJE）、重分类调整（RJE）及未调整错报（SUD）评估。复核须验证：每笔调整有充分证据、借贷平衡、完整回写审定表 K1-1、SUD 与 A13 未调整错报汇总交叉验证。其他应收款调整常见于关联方占款重分类、错分往来纠正、坏账准备补提、长期挂账转销等。

**法规依据：**
- 《企业会计准则第28号——会计政策、会计估计变更和差错更正》
- 《中国注册会计师审计准则第1301号——审计证据》
- 《中国注册会计师审计准则第1324号——持续经营》

---

## tips

1. **AJE 与 RJE 性质须区分**：AJE 影响资产净额或损益（如补提坏账、错分纠正）；RJE 仅影响列报（如关联方往来重分类、非流动部分重分类），不得以 RJE 掩盖减值错报。
2. **与审定表 K1-1 逐笔勾稽**：每笔已确认调整须完整回写 K1-1 对应调整列（账项调整/重分类调整），审定数=未审+AJE+RJE，遗漏任一笔即审定数失真。
3. **调整须有充分审计证据**：坏账补提须有 K1-8 测算支撑、错分纠正须有原始凭证、关联方重分类须有 K1-11 认定依据，无据调整属高风险。
4. **超重要性水平调整须审批留痕**：超过明细层次重要性水平的调整须经合伙人/项目经理审批。
5. **SUD 累计评估**：未调整错报须记入 A13 未调整错报汇总表，单独及累计是否超过整体/明显微小错报阈值须评估。
6. **调整已同步试算平衡表**：确认调整已回写 TB 1221 及坏账准备科目，避免"底稿已调、TB 未更"双真源。

## checklist

### 一、调整依据与审批

- [ ] 所有 AJE 是否有充分审计证据（K1-8 测算/原始凭证/管理层确认）
- [ ] 坏账补提/转销调整是否与 K1-8/K1-9 结果一致
- [ ] 关联方占款重分类是否有 K1-11 认定依据
- [ ] 超重要性水平的调整是否经适当层级审批留痕
- [ ] 是否存在仅为美化资产质量或规避披露的不当调整

### 二、平衡与回写

- [ ] 每笔调整分录借贷方是否完全平衡
- [ ] 调整金额是否完整回写审定表 K1-1 对应调整列
- [ ] AJE 是否正确反映到审定数（未审+AJE+RJE=审定）
- [ ] 调整后审定数是否已同步试算平衡表 1221 及坏账准备科目
- [ ] 调整分录编号是否连续，删除后重号风险是否可控

### 三、分类与未调整错报

- [ ] RJE 是否仅涉及列报（关联方/流动性重分类），未影响减值损益
- [ ] 未调整错报是否记入 A13 未调整错报汇总表
- [ ] SUD 单独及累计是否超过重要性阈值并已评估
- [ ] 跨期调整是否正确区分本期错报与前期差错更正

## risk_areas

### 高风险

1. **调整缺乏证据或未授权**：坏账补提/转销/重分类无充分依据或未经审批。
2. **审定表与 K1-4 不一致**：已确认调整未完整回写 K1-1，审定数失真。
3. **SUD 累计超阈值未处理**：未调整错报累计超整体重要性水平仍出具无保留意见未评估。

### 中风险

1. **RJE 误含减值影响**：本应作 AJE 的坏账/损益调整以 RJE 处理，掩盖减值错报。
2. **跨期调整分类错误**：本期错报与前期差错更正混淆，会计处理与披露不当。

### 低风险

1. **编号格式不规范**：分录摘要、科目编码、编号连续性不规范。
2. **索引缺失**：与 K1-8/K1-9/A13 支持底稿的交叉索引不完整。
