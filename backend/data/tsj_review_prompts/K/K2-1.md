# K2-1 其他流动资产审定表复核提示词

## 概述

本提示词针对其他流动资产审定表（K2-1，科目 1231，资产类取期末余额）的复核。其他流动资产核算待摊费用、预缴税费（待抵扣进项税额、预缴所得税）、合同取得成本/合同履约成本的流动部分等。聚焦：期初期末勾稽、试算表核对、项目性质与流动性分类、待摊/摊销的准确性。核心风险为应费用化项目挂账递延、流动性分类错误、预缴税费与税务申报不符。

**法规依据：**
- 《企业会计准则第14号——收入》（合同成本）
- 《企业会计准则第30号——财务报表列报》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **资产类取"期末余额"**：审定数=期初+本期增加−本期摊销/结转±调整。
2. **期初期末勾稽**：期初审定数=上年期末审定数；审定合计=明细表 K2-2 期末合计（K2-2-end-total）。
3. **试算表核对**：审定合计与试算表 1231 审定余额一致。
4. **性质与流动性**：各项目是否确属流动资产（一年内可变现/受益）；超一年部分应重分类至非流动。
5. **待摊/摊销准确性**：待摊费用摊销期限、合同取得成本摊销是否与政策/合同一致；应费用化项目不得挂账递延。
6. **预缴税费勾稽**：待抵扣进项税额、预缴所得税/增值税须与税务申报表、N 循环应交税费勾稽。

## checklist

### 一、期初期末勾稽与试算表核对

- [ ] 期初审定数是否等于上年期末审定数
- [ ] 审定数=期初+增加−摊销/结转±调整 是否正确
- [ ] 审定合计是否与明细表 K2-2 期末合计一致
- [ ] 审定合计是否与试算表 1231 审定余额一致

### 二、性质与流动性分类

- [ ] 各项目是否确属其他流动资产（一年内受益/变现）
- [ ] 超一年受益部分是否重分类至非流动资产（如长期待摊）
- [ ] 待摊费用是否应费用化却挂账递延（虚增资产/利润）
- [ ] 合同取得成本/履约成本的流动部分划分是否正确

### 三、摊销与预缴税费

- [ ] 待摊费用摊销期限、方法是否与政策一致
- [ ] 合同取得成本摊销是否与收入确认匹配
- [ ] 待抵扣进项税额是否与增值税申报勾稽
- [ ] 预缴所得税/增值税是否与税务申报、N 循环应交税费勾稽

### 四、审计调整完整性

- [ ] 已确认的账项/重分类调整是否完整反映
- [ ] 调整分录借贷平衡、证据充分、经审批

## risk_areas

### 高风险

1. **应费用化项目挂账递延**：将当期费用挂待摊费用递延，虚增资产与利润。
2. **流动性分类错误**：超一年受益项目仍列流动资产。
3. **期初期末不勾稽 / 与试算表不一致**。

### 中风险

1. **摊销不准确**：待摊/合同成本摊销期限与政策/合同不符。
2. **预缴税费与申报不符**：待抵扣进项、预缴税款与税务申报差异未解释。
3. **审计调整遗漏**。

### 低风险

1. **格式与索引不规范**。
2. **项目说明不足**。
