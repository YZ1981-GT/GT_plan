# K1-note-listed 其他应收款附注披露复核提示词（上市公司）

## 概述

本提示词针对其他应收款上市公司附注披露底稿（K1-note-listed）的复核，聚焦：按款项性质分类披露、账龄披露、坏账准备变动披露、CAS37 金融工具列报充分性、关联方及资金占用披露、前五名其他应收款披露。上市公司其他应收款披露除 CAS37/CAS36 通用要求外，须满足证监会编报规则第 15 号对分类、前五名、关联方资金占用的额外披露要求，是识别控股股东资金占用的关键披露。

**法规依据：**
- 《企业会计准则第37号——金融工具列报》
- 《企业会计准则第36号——关联方披露》
- 《公开发行证券的公司信息披露编报规则第15号——财务报告的一般规定》

## tips

1. **按款项性质分类披露是上市公司必备**：其他应收款须按性质分类（备用金/押金保证金/关联方往来/代垫款/应收利息股利/其他），各类别期末/期初数须列示，分类合计须等于审定表 K1-1 审定数。
2. **坏账准备变动表须完整并勾稽**：期初+计提−转回−核销±其他=期末，须与 K1-3 坏账明细一致，本期计提须与信用减值损失勾稽，须区分单项与组合（三阶段）变动。
3. **前五名其他应收款是证监会强制披露**：须披露前五名对象的名称、性质、期末余额、账龄、占其他应收款总额比例及对应坏账准备，与 K1-5 大额分析数据一致。
4. **关联方资金占用披露是监管红线**：关联方（尤其控股股东及其关联方）非经营性资金占用须单独披露，包括占用方、占用金额、占用费、形成原因、清偿安排，缺失或隐瞒是重大违规。
5. **CAS37 信用风险披露须充分**：须披露信用风险管理政策、预期信用损失计量方法（一般方法三阶段）、关键假设参数（违约定义/损失率/前瞻性信息）、按阶段/风险等级的账面余额和减值。
6. **附注须与审定表/明细表/坏账表闭环勾稽**：附注其他应收款总额=K1-1 审定数；分类/账龄小计=K1-2 明细对应合计；坏账变动=K1-3；前五名=K1-5，任一断裂为披露错误。

## checklist

### 一、分类与账龄披露

- [ ] 是否按款项性质分类披露（备用金/押金/关联方/代垫/其他）
- [ ] 各类别期末数合计是否等于审定表 K1-1 审定数
- [ ] 是否同时列示期末与期初可比数
- [ ] 账龄披露是否完整（1年以内/1-2年/2-3年/3年以上）且合计等于总额
- [ ] 账龄各段是否同时列示账面余额与坏账准备
- [ ] 分类/账龄数据是否与 K1-2 明细表一致

### 二、坏账准备与减值披露

- [ ] 坏账准备变动表是否完整（期初/计提/转回/核销/期末）并与 K1-3 勾稽
- [ ] 本期计提是否与利润表信用减值损失勾稽
- [ ] 是否按三阶段（12个月/存续期/已减值）披露账面余额与减值
- [ ] 是否披露 ECL 计量方法及关键假设（违约定义/损失率/前瞻性信息）
- [ ] 本期核销的重大款项是否披露对象及原因

### 三、前五名与关联方资金占用

- [ ] 是否披露前五名其他应收款（名称/性质/余额/账龄/占比/坏账准备）
- [ ] 前五名数据是否与 K1-5 大额分析一致
- [ ] 关联方非经营性资金占用是否单独披露（占用方/金额/占用费/清偿安排）
- [ ] 关联方其他应收款的余额、账龄、坏账准备是否单独列示
- [ ] 控股股东及其关联方占款是否按监管要求专项说明

## risk_areas

### 高风险

1. **关联方资金占用未披露或隐瞒**：控股股东非经营性占款未单独披露，属重大违规，可能被认定为隐瞒关联交易。
2. **坏账变动表不勾稽**：变动表勾稽不成立或与 K1-3 不一致，属重大披露错误。
3. **附注总额与审定表不一致**：附注其他应收款总额与 K1-1 审定数不符。
4. **ECL 关键假设未披露**：未披露预期信用损失方法、损失率、前瞻性调整，不满足 CAS37。

### 中风险

1. **前五名披露不完整**：未披露前五名或缺少账龄/坏账准备等要素。
2. **分类维度不足**：仅按账龄未按款项性质分类披露。
3. **可比信息缺失**：仅列期末数未列期初可比数。

### 低风险

1. **披露格式不规范**：表格列序、金额单位不完全符合编报规则。
2. **信用风险政策模板化**：信用风险管理政策照搬准则原文未结合企业实际。
3. **交叉索引不完整**：与 K1-1/K1-2/K1-3/K1-5 的勾稽索引标注不全。
