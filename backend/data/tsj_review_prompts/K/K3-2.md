# K3-2 其他应付款明细表复核提示词

## 概述

本提示词针对其他应付款明细表（K3-2，科目 2241，负债类贷方，期末余额=期初+贷方−借方）的复核，聚焦：债权人构成完整性、与审定表 K3-1 的余额勾稽、款项性质分类、长期挂账与关联方线索识别。其他应付款是隐瞒负债的高发科目，主要由押金保证金、暂收款、关联方往来、代扣代缴款等构成。负债类科目首要认定是"完整性"，明细表须完整反映全部应付义务，为大额分析（K3-4）、长期挂账检查（K3-5）、关联方检查（K3-6）提供基础。

**法规依据：**
- 《企业会计准则第30号——财务报表列报》
- 《企业会计准则第36号——关联方披露》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **完整性是负债类明细表的首要认定**：其他应付款明细须完整反映全部应付义务，警惕未入账负债（已收押金/暂收款未挂账、应付未付款项遗漏），完整性缺失是负债类科目的核心风险。
2. **与审定表 K3-1 勾稽是余额准确性根基**：明细表各债权人期末余额合计（勾稽键 K3-2-detail-total）须等于审定表 K3-1 期末审定数，期初须与上年审定数衔接，负债类期末=期初+贷方−借方（方向与资产类相反）。
3. **款项性质分类完整**：每笔款项须标注性质（押金保证金/暂收款/关联方往来/代扣代缴/其他），性质决定披露分类、长期挂账处理和关联方占用判断。
4. **长期挂账须重点标注**：长期挂账（尤其 3 年以上）的其他应付款可能已无需支付，须标注供 K3-5 检查评估是否应转营业外收入，长期挂账不清理可能虚增负债或延迟确认收益。
5. **关联方标注完整性**：关联方债权人须逐笔标注并与 B19 核对，识别关联方通过其他应付款占用资金或调节往来，遗漏影响 K3-6 和披露完整性。
6. **明细表是下游底稿数据源**：大额债权人→K3-4；长期挂账→K3-5；关联方→K3-6；分类合计→附注披露，明细表遗漏（尤其未入账负债）将沿链传导并低估负债。

## checklist

### 一、债权人构成完整性

- [ ] 明细表是否完整反映全部应付义务（无遗漏未入账负债）
- [ ] 每笔款项是否标注性质（押金/暂收/关联方/代扣代缴/其他）
- [ ] 债权人名称是否完整规范，无笼统"其他"归集
- [ ] 是否逐笔标注关联方债权人并与 B19 清单核对
- [ ] 是否存在应列应付账款/应付职工薪酬等而错分至其他应付款

### 二、余额准确性与勾稽

- [ ] 明细表各债权人期末余额合计（K3-2-detail-total）是否等于审定表 K3-1 审定数
- [ ] 明细表期初余额是否与上年审定期末数衔接
- [ ] 各债权人余额计算是否正确（期初+贷方−借方=期末，负债类方向）
- [ ] 明细数据是否来自科目余额表/序时账，未经人工调整
- [ ] 是否存在借方余额异常（应收性质挂入其他应付款）

### 三、长期挂账与关联方线索

- [ ] 长期挂账款项（1年以上/3年以上）是否标注供 K3-5 评估
- [ ] 长期挂账是否评估是否已无需支付（转营业外收入线索）
- [ ] 大额债权人是否标注供 K3-4 大额分析覆盖
- [ ] 关联方占用是否单独识别供 K3-6 分析
- [ ] 押金保证金是否随业务结束及时清退（长期挂账原因）

## risk_areas

### 高风险

1. **隐瞒负债（完整性缺失）**：已收押金/暂收款/应付款项未入账，其他应付款明细遗漏，低估负债。
2. **明细与审定表不勾稽**：明细合计（K3-2-detail-total）与 K3-1 审定数存在差异未调节。
3. **长期挂账应转未转**：长期挂账已无需支付但未转营业外收入，虚增负债、延迟确认收益。

### 中风险

1. **关联方占用未识别**：关联方通过其他应付款调节往来未标注，K3-6 和披露不完整。
2. **款项性质错分**：应列其他科目的负债错分至其他应付款影响披露分类。

### 低风险

1. **明细表格式不规范**：债权人排序、性质标注、金额单位不统一。
2. **小额款项归集**：零星款项归入"其他"未附明细。
3. **交叉索引不完整**：与 K3-4/K3-5/K3-6 的交叉引用标注不全。
