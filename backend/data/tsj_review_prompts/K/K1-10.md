# K1-10 其他应收款长期未收回检查复核提示词

## 概述

本提示词针对其他应收款长期未收回款项检查表（K1-10）的复核，聚焦：长账龄款项识别完整性、未收回原因合理性、可收回性与减值评估、催收/处置措施充分性。长期未收回款项（尤其 1 年以上备用金、押金保证金、代垫款、往来款）反映资金管理松散和潜在损失，是减值评估、内控缺陷识别和国有资产流失风险的重点，须逐笔追踪原因、责任和收回安排。

**法规依据：**
- 《企业会计准则第22号——金融工具确认和计量》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **长账龄款项识别须完整**：须从 K1-2 明细表按账龄筛出全部长期未收回款项（通常 1 年以上，重点 3 年以上），不得遗漏，识别口径与账龄起算日须一致。
2. **未收回原因须逐笔查明**：备用金长期挂账（未报销）、押金保证金未清理（业务已结束）、代垫款未收回、往来款长期占用，各有不同性质，原因不同影响可收回性和减值判断。
3. **可收回性评估驱动减值**：长期未收回款项的对方偿付能力、清理可行性、期后收回情况须评估，作为 K1-7 阶段升级和 K1-8 单项减值的依据，长期挂账不能默认可全额收回。
4. **催收与处置措施须充分**：须评价企业是否采取了催收、清理、转销等措施，长期挂账不清理反映内控缺陷（备用金/押金管理制度失效）。
5. **关联方长期占款须专项关注**：关联方长期未收回款项须与 K1-11 交叉，评估是否构成非经营性资金占用，上市公司须专项披露。
6. **长期挂账与减值/核销闭环**：确认无法收回的长期款项应纳入 K1-8 单项减值或 K1-9 核销，长期挂而不减/不销属减值不足。

## checklist

### 一、识别完整性

- [ ] 长期未收回款项是否从 K1-2 明细表按账龄完整筛出（1年以上/3年以上）
- [ ] 识别口径与账龄起算日是否与明细表一致
- [ ] 各类长期款项（备用金/押金/代垫/往来）是否分类列示
- [ ] 是否遗漏应纳入的长账龄对象

### 二、原因与可收回性

- [ ] 每笔长期未收回款项的原因是否逐笔查明
- [ ] 备用金长期未报销/押金未清理的原因是否合理
- [ ] 对方偿付能力与清理可行性是否评估
- [ ] 期后收回情况是否记录作为可收回性佐证
- [ ] 可收回性结论是否作为 K1-7/K1-8 减值输入

### 三、措施与关联方

- [ ] 企业是否采取催收/清理/转销措施
- [ ] 长期挂账是否反映备用金/押金管理内控缺陷
- [ ] 关联方长期占款是否与 K1-11 交叉并评估非经营性占用
- [ ] 确认无法收回的款项是否纳入 K1-8 减值或 K1-9 核销

## risk_areas

### 高风险

1. **长期挂账未减值**：长期未收回款项对方偿付能力恶化但未纳入单项减值，减值计提不足。
2. **关联方长期占款隐藏**：关联方长期资金占用以长期挂账形式存在未识别未披露（上市公司尤须关注）。
3. **应核销未核销/应减值未减值**：确认无法收回款项长期挂账既不减值也不核销，虚增资产。

### 中风险

1. **识别不完整**：部分长账龄对象未筛出，长期未收回分析覆盖不足。
2. **原因查明不深**：仅记录账龄未查明未收回根本原因和责任。

### 低风险

1. **内控缺陷未提示**：长期挂账反映的管理制度缺陷未在底稿中提示。
2. **催收记录不完整**：催收/清理措施的记录简略。
