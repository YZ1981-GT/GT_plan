# K2-note-soe 其他流动资产附注披露复核提示词（国有企业）

## 概述

本提示词针对其他流动资产国有企业附注披露底稿（K2-note-soe）的复核，聚焦：基础分类明细披露（与上市版共有）、国有资产监管相关披露、长期挂账清理、预缴税费及财政性款项披露、决算报表口径一致。国有企业其他流动资产披露须在 CAS30/CAS14 通用要求基础上，叠加国资委财务决算对资产质量、长期挂账清理和财政性资金的额外披露要求。

**法规依据：**
- 《企业会计准则第30号——财务报表列报》
- 《企业会计准则第14号——收入》
- 《中央企业财务决算报告管理办法》

---

## tips

1. **国企附注"双层"披露要求**：既满足 CAS30/CAS14 通用披露（按性质明细/合同取得成本/流动性），又满足国资委财务决算对资产质量分析的额外要求。
2. **长期挂账须按国资要求单独说明**：长期未摊销的待摊费用、长期无法抵扣退还的预缴税费等长期挂账项目须单独说明形成原因和清理计划，防止掩盖国有资产管理问题。
3. **财政性/涉政府款项须单独披露**：其他流动资产中涉及财政拨款、政府补助尾款、政府预缴退税等财政性款项须单独列示，明确性质和预期实现方式。
4. **资产质量分析视角**：长期挂账、无法实现的其他流动资产可能构成"不良资产"，须按决算要求评估资产质量并单独披露。
5. **合同取得成本披露与上市版一致**：CAS14 合同取得成本的确认、摊销、减值披露要求与上市版相同，国企版差异主要在国资监管层面。
6. **决算口径一致**：附注数据须与年度财务决算报表一致，各项目分类须与决算报表附加信息表口径衔接。

## checklist

### 一、基础披露完整性（与上市版共有）

- [ ] 是否按性质明细披露各构成项目及金额，合计等于审定表 K2-1 审定数
- [ ] 重大项目是否单独列示，分类小计是否与 K2-2 明细表勾稽
- [ ] 流动性分类依据是否说明，超一年部分是否重分类披露
- [ ] 合同取得成本是否单独披露（余额/摊销/减值/方法）
- [ ] 是否同时列示期末与期初可比数

### 二、国有资产监管披露

- [ ] 长期挂账项目（长期待摊/长期无法抵扣税费）是否单独说明原因及清理计划
- [ ] 财政性/涉政府款项（财政拨款/补助尾款/预缴退税）是否单独披露
- [ ] 无法实现的其他流动资产是否按资产质量分析要求评估披露
- [ ] 其他流动资产中"不良资产"部分是否按决算要求单独披露

### 三、决算口径一致

- [ ] 附注数据是否与年度财务决算报表一致
- [ ] 各项目分类是否与决算报表附加信息表口径衔接
- [ ] 重大变动是否结合预算执行说明

## risk_areas

### 高风险

1. **长期挂账掩盖资产问题**：长期待摊/长期无法实现项目未单独说明，掩盖国有资产管理问题。
2. **基础披露与审定表不勾稽**：附注各项目合计与 K2-1 审定数不一致。
3. **财政性款项披露缺失**：涉政府款项未单独披露性质和实现方式。

### 中风险

1. **资产质量分析不足**：无法实现的其他流动资产未评估资产质量。
2. **决算口径差异未调节**：决算数据与审计后附注数据差异未编制调节说明。

### 低风险

1. **披露格式未按决算模板**：与国资委决算报表模板有细微格式差异。
2. **可比信息缺失**：仅列期末数未列期初可比数。
3. **交叉索引不完整**：与 K2-1/K2-2/K2-4 及决算报表的勾稽索引不全。
