# K10-2 其他收益明细表复核提示词

## 概述

本提示词针对其他收益明细表（K10-2，科目 6117，损益类贷方，取本期发生额）的复核，聚焦其他收益各项目本期发生额明细的质量。明细表按补助/收益项目维度记录项目名称、本期发生额、来源批文、与递延收益（K7）结转关系、计入科目正确性，是审定表 K10-1 的数据来源。其他收益核算与日常活动相关、总额法核算的政府补助等，明细数据准确性直接影响其他收益审定数、利润表列报及非经常性损益披露。核心风险为分类错误（应计营业外收入/冲减成本的补助误计其他收益）、与递延收益结转不勾稽、完整性缺失。

**法规依据：**
- 《企业会计准则第16号——政府补助》
- 《企业会计准则第30号——财务报表列报》
- 《中国注册会计师审计准则第1301号——审计证据》

## tips

1. **取"本期发生额"非余额**：明细表各项目=6117 本期贷方发生额−借方（冲回），损益类科目按发生额核对。
2. **计入科目判断是核心**：与日常活动相关的政府补助计其他收益；与日常活动无关的计营业外收入（K12）；与资产/成本直接相关按净额法冲减——明细表须逐项判断计入科目正确性。
3. **与递延收益（K7）结转勾稽**：与资产相关、分期计入其他收益的政府补助，本期结转额应与 K7 递延收益本期摊销转出额逐项勾稽一致。
4. **明细合计与审定表勾稽**：明细表本期发生额合计=审定表 K10-1 审定合计（未审+AJE+RJE），差异需追溯至调整分录。
5. **完整性核查**：核对政府补助批文/到账凭证，防止漏计已到账补助或将补助挂往来科目未确认收益。
6. **双向勾稽**：各项目本期发生额之和=K10-1 审定合计=试算表 6117 本期发生额；与资产相关补助结转额=K7 本期摊销；非经常性损益标识与非经常性损益明细勾稽。

## checklist

### 一、项目明细完整性（高风险）

- [ ] 其他收益各项目名称是否完整规范，无笼统"其他"归集
- [ ] 每笔补助/收益是否对应批文/协议及到账依据
- [ ] 是否存在漏计已到账政府补助或挂往来科目未确认
- [ ] 项目本期发生额是否与账面（6117 贷方发生额）一致
- [ ] 【条件检查：若有直接减免/返还税费】增值税加计抵减、即征即退等是否完整记录
- [ ] 【风险检查】是否存在将非补助性收入挂其他收益虚增经营利润

### 二、计入科目与结转勾稽（高风险）

- [ ] 各项目计入其他收益是否确与日常活动相关
- [ ] 应计营业外收入（与日常活动无关）的补助是否误计其他收益
- [ ] 应按净额法冲减成本/资产的补助是否误计其他收益
- [ ] 与资产相关补助本期计入其他收益额是否与 K7 递延收益摊销一致
- [ ] 与收益相关补助本期计入是否符合确认时点
- [ ] 【风险检查】是否存在跨期确认补助以平滑利润

### 三、勾稽关系与数据源一致性（中风险）

- [ ] 明细表本期发生额合计是否等于审定表 K10-1 审定合计
- [ ] 明细合计是否与试算表 6117 本期发生额一致
- [ ] 上期发生额是否与上年底稿一致
- [ ] 非经常性损益标识是否正确（供上市披露）
- [ ] 【风险检查】各项目本期发生额是否与历史趋势匹配，异常须解释

## risk_areas

### 高风险

1. **计入科目分类错误**：与日常活动无关的补助误计其他收益（应计营业外收入），或应净额法冲减成本/资产的补助计入损益，虚增经营利润。
2. **与递延收益不勾稽**：与资产相关补助本期结转其他收益额与 K7 递延收益摊销不一致，存在多结转/少结转。
3. **完整性缺失**：漏计已到账政府补助或将补助挂往来科目未确认收益。
4. **明细与审定表不勾稽**：明细合计与 K10-1 审定合计存在无源差异。

### 中风险

1. **确认时点不当**：补助在收到批文/到账前提前确认，或满足条件后延迟确认。
2. **非经常性损益标识错误**：影响上市公司扣非利润披露。
3. **本期发生额异常波动**：与历史趋势偏离重大但无合理解释。

### 低风险

1. **格式与索引不规范**：明细项目、单位、交叉索引不统一。
2. **补助项目说明不足**：补助用途、批文文号等辅助说明缺失。
