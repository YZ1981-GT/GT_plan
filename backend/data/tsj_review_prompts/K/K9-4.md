# K9-4 管理费用实质性分析复核提示词

## 概述

本提示词针对管理费用实质性分析程序底稿（K9-4，科目 6602）的复核，通过分析程序验证管理费用与经营规模的匹配性、管理费用率变动的合理性、费用结构变化趋势，识别费用少计（完整性）、多计、跨期或错分类的重大错报风险。管理费用中折旧摊销、职工薪酬相对刚性，中介费、招待费、研发费用波动较大，是分析关注重点。

**法规依据：**
- 《中国注册会计师审计准则第1313号——分析程序》
- 《企业会计准则第30号——财务报表列报》

---

## tips

1. **管理费用率是核心指标**：管理费用率=管理费用÷营业收入，须与上期、预算、同行业对比；管理费用相对固定，费用率随收入增长应下降，异常上升或大幅下降均须查明。
2. **刚性费用可独立预期**：职工薪酬（人数×平均薪酬）、折旧摊销（资产原值×折旧率）可建立独立预期值与账面比对，偏差超阈值须解释。
3. **高波动项目重点分析**：中介机构费、业务招待费、研发费用波动大，须结合业务事项（并购/上市/研发项目）解释其变动。
4. **异常波动阈值参考**：单项目变动超 30%、管理费用率变动超 20%、职工薪酬/折旧预期偏差超 10% 应触发深入分析。
5. **分析须形成闭环**：识别异常→调查→获取解释→取得证据评价→结论，不得仅凭管理层口头说明。
6. **期末突增结合截止**：中介费/审计费/年终奖等常在年末列支，突增须结合 K9-6/K9-7 截止测试判断期间归属。

## checklist

### 一、费用率与匹配性分析（高风险）

- [ ] 管理费用率（管理费用÷营业收入）计算是否准确、分子分母口径一致
- [ ] 管理费用率与上期对比变动是否合理，变动超 20% 是否有充分解释
- [ ] 管理费用总额变动与经营规模（收入/资产/人数）变动是否匹配
- [ ] 职工薪酬是否可用人数×平均薪酬建立独立预期并与账面比对
- [ ] 折旧摊销是否与固定资产/无形资产原值及折旧摊销政策匹配

### 二、费用结构与趋势分析（中风险）

- [ ] 各费用项目占管理费用比例的结构变动是否合理
- [ ] 中介机构费/招待费/研发费用等高波动项目变动是否结合业务事项解释
- [ ] 研发费用变动是否与研发投入计划、研发归集一致
- [ ] 管理费用率与同行业可比公司是否存在显著偏离（偏离 30% 须评估）
- [ ] 费用结构较上期是否出现重大迁移并已分析原因

### 三、异常调查与结论闭环（高风险）

- [ ] 分析发现的异常波动是否全部得到调查和解释
- [ ] 异常解释是否有充分审计证据支持（合同/薪酬册/研发项目资料）
- [ ] 期末突增费用（中介费/年终奖）是否结合截止测试分析
- [ ] 分析程序结论是否明确记录，与审计总体结论衔接
- [ ] 前后期对比数据口径是否一致（合并范围/会计政策变更已调整）

## risk_areas

### 高风险

1. **费用率异常下降未解释**：管理费用率显著低于上期/同行但无合理解释，可能存在费用少计（完整性）或跨期递延以虚增利润。
2. **刚性费用预期偏差大**：职工薪酬/折旧摊销与独立预期值偏差重大且无解释，可能少计或多计。
3. **期末费用异常波动**：中介费/年终奖等在年末突增或异常延迟，可能跨期操纵利润。
4. **异常波动无证据解释**：识别出异常但仅凭管理层口头说明，未获取支持性审计证据。

### 中风险

1. **费用率偏离行业显著**：管理费用率与同行业差异超 30%，需评估是否行业特性或异常信号。
2. **研发费用变动异常**：研发费用大幅变动与研发投入/归集不一致。
3. **对比口径不一致**：合并范围或会计政策变更未调整可比数据，导致分析结论误导。

### 低风险

1. **分析深度不足**：仅做总额同比，未对刚性费用建立独立预期。
2. **数据来源标注不规范**：分析引用数据未标注来源或行业对标数据过于陈旧。
