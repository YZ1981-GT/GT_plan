# K9-note-listed 管理费用附注披露复核提示词（上市公司）

## 概述

本提示词针对管理费用上市公司附注披露底稿（K9-note-listed，科目 6602）的复核，聚焦：按性质列示明细项目的完整性、研发费用单独列报、本期/上期可比数据、与审定表的勾稽、关联方承担费用披露、以及证监会编报规则对管理费用披露的细化要求。管理费用附注是报表使用者理解企业管理投入结构的主要途径，研发费用列示与中介费披露是核查重点。

**法规依据：**
- 《企业会计准则第30号——财务报表列报》
- 《企业会计准则第36号——关联方披露》
- 《公开发行证券的公司信息披露编报规则第15号——财务报告的一般规定》

## tips

1. **按性质列示明细项目**：附注须按费用性质分项列示管理费用（职工薪酬/折旧摊销/无形资产摊销/办公费/中介机构费/业务招待费/研发费用/税金/其他），各项合计等于利润表管理费用金额。
2. **研发费用列示是核心**：计入管理费用的研发费用（费用化部分）须单独披露，与研发费用附注/开发支出（资本化）口径衔接，避免重复披露或列报口径不一致。
3. **本期与上期可比列示**：每一明细项目须同时列示本期与上期发生额，供报表使用者对比费用结构变化。
4. **与审定表/明细表闭环勾稽**：附注管理费用合计=审定表 K9-1 审定合计=明细表 K9-2 合计=利润表管理费用行，任一节点不一致属披露错误。
5. **关联方费用披露**：向关联方支付的管理服务费/中介费须在关联方交易附注单独披露、说明定价公允性。
6. **重大变动与"其他"细分**：管理费用重大变动应结合 MD&A 说明；"其他"项目金额重大须进一步细分，不得笼统列示掩盖敏感支出（招待费）。

## checklist

### 一、明细项目列示完整性

- [ ] 管理费用是否按费用性质分项列示（薪酬/折旧摊销/办公/中介费/招待/研发/税金/其他）
- [ ] 各明细项目发生额合计是否等于利润表管理费用金额
- [ ] 计入管理费用的研发费用是否单独列示
- [ ] "其他"项目金额是否重大，如重大是否进一步细分或说明构成
- [ ] 业务招待费等敏感费用是否单独列示

### 二、研发费用与勾稽

- [ ] 费用化研发费用披露是否与研发费用附注/开发支出口径衔接
- [ ] 研发费用列报是否避免与资本化开发支出重复披露
- [ ] 附注管理费用合计是否与审定表 K9-1 审定合计一致
- [ ] 附注明细是否与明细表 K9-2 分项合计勾稽
- [ ] 上期数是否与上年经审计附注一致、与利润表管理费用行勾稽

### 三、变动说明与关联方披露

- [ ] 管理费用重大变动是否说明原因，附注与 MD&A 口径是否一致
- [ ] 向关联方支付的管理服务费/中介费是否在关联方交易附注单独披露
- [ ] 关联方费用交易的定价方式与公允性是否说明
- [ ] 是否披露计入管理费用的股份支付金额（如适用）
- [ ] 是否披露政府补助冲减管理费用的情形（如适用）

## risk_areas

### 高风险

1. **附注合计与审定表/利润表不一致**：附注管理费用各项合计与 K9-1 审定数或利润表管理费用行不勾稽，属重大披露错误。
2. **研发费用列示错误或重复**：费用化研发与资本化开发支出披露口径不一致或重复，影响研发投入信息与加计扣除。
3. **关联方费用未单独披露**：向关联方支付的管理服务费/中介费混入普通费用未单独列示，违反 CAS36。

### 中风险

1. **"其他"项目笼统列示**：金额重大的"其他"管理费用未细分，掩盖招待费等敏感支出。
2. **重大变动未说明**：管理费用大幅变动但附注/MD&A 未说明原因或口径不一致。
3. **明细分类不完整**：未按费用性质分项列示或漏列重大项目。

### 低风险

1. **披露格式不规范**：明细列示顺序、金额单位等格式细节未严格按编报规则。
2. **文字说明模板化**：费用变动说明照搬模板未结合企业实际。
