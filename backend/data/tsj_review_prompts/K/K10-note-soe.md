# K10-note-soe 其他收益附注披露复核提示词（国有企业）

## 概述

本提示词针对其他收益国有企业附注披露底稿（K10-note-soe，科目 6117）的复核，聚焦国有企业特定的其他收益披露要求：政府补助/财政资金分项披露、国资监管相关信息、财政专项资金结转形成的其他收益、国资委财务决算报告补充披露事项，以及与上市公司版本的差异关注点。国有企业其他收益多来自财政专项资金、产业扶持资金摊销及税费返还，附注披露须同时满足会计准则和国资监管要求，并反映政府补助对经营业绩的影响。

**法规依据：**
- 《企业会计准则第16号——政府补助》
- 《企业会计准则第30号——财务报表列报》
- 《企业国有资产法》
- 《中央企业财务决算报告管理办法》
- 《财政专项资金管理相关规定》

## tips

1. **分项披露区分财政资金性质**：附注须分项披露其他收益构成，区分财政专项资金摊销、产业扶持资金、税费返还（即征即退等）、稳岗补贴等，专项资金摊销部分单独说明。
2. **双层披露要求**：既满足 CAS16 政府补助披露，又满足国资委财务决算报告对财政资金及其对经营业绩影响的额外披露要求。
3. **政府补助对业绩的影响**：国企其他收益中政府补助占比往往较高，附注须说明政府补助对利润总额的影响程度，反映经营业绩中政府支持的贡献，服务于国有资本经营业绩考核。
4. **专项资金结转勾稽**：财政专项资金形成递延收益并分期结转其他收益的，附注须与 K7 递延收益变动表勾稽，说明结转依据及绩效目标完成情况。
5. **与主营相关性判断**：与国企主营业务相关的持续性补助计其他收益；与主营无关的一次性财政奖励计营业外收入，划分须有依据并符合国资监管口径。
6. **闭环勾稽**：附注其他收益合计=利润表其他收益行=审定表 K10-1 审定数=明细 K10-2 本期发生额；与递延收益结转部分与 K7 勾稽；与财务决算报表相关数据一致。

## checklist

### 一、基础分项披露（与上市版共有）

- [ ] 其他收益是否按项目分项披露（不笼统列一个总数）
- [ ] 各分项是否同时披露本期数和上期数
- [ ] 各分项合计是否等于审定表 K10-1 审定合计
- [ ] 附注其他收益合计是否与利润表其他收益行一致
- [ ] 主要政府补助项目名称、金额是否列示完整

### 二、财政资金与国资监管披露

- [ ] 财政专项资金摊销形成的其他收益是否单独披露项目、金额、批复文号
- [ ] 政府补助对利润总额的影响程度是否说明
- [ ] 专项资金摊销结转是否与 K7 递延收益变动表勾稽
- [ ] 专项资金绩效目标完成情况是否说明
- [ ] 税费返还（即征即退等）是否与纳税申报勾稽
- [ ] 与主营相关性判断（其他收益 vs 营业外收入）是否符合国资口径

### 三、决算一致性与差异关注

- [ ] 其他收益数据是否与年度财务决算报表一致
- [ ] 政府补助对经营业绩考核的影响是否披露
- [ ] 决算报表与审计后附注数据差异是否编制调节说明
- [ ] 非经常性损益标识是否正确（如适用于国有控股上市主体）
- [ ] 与上市版差异：是否在基础分项披露上增加了财政资金监管及业绩影响信息

## risk_areas

### 高风险

1. **政府补助业绩影响未披露**：其他收益中政府补助占比高但未说明对利润总额的影响，掩盖对政府支持的依赖，影响业绩考核信息可靠性。
2. **分项披露缺失**：其他收益笼统列示，未区分财政专项资金、税费返还等构成。
3. **附注与利润表/审定表不一致**：其他收益合计与利润表、审定表不勾稽，属重大披露错误。

### 中风险

1. **专项资金结转勾稽缺失**：财政专项资金摊销形成的其他收益未与 K7 递延收益变动表勾稽。
2. **决算与审计口径差异未调节**：财务决算数据与审计后附注数据存在差异未说明。
3. **与主营相关性判断依据不足**：其他收益/营业外收入划分缺乏符合国资口径的依据。

### 低风险

1. **披露格式未完全按决算模板**：附注格式与国资委决算报表模板有细微差异。
2. **绩效说明过于简略**：专项资金绩效目标完成情况说明深度不足。
