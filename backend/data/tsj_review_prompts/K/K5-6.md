# K5-6 未决诉讼检查复核提示词

## 概述

本提示词针对预计负债项下未决诉讼检查底稿（K5-6，科目 2701）的复核。未决诉讼、仲裁形成的潜在赔偿义务是预计负债的重要来源，须结合律师函（A 循环）评估败诉可能性，按 CAS13 判断是确认预计负债还是作或有负债披露。复核聚焦：诉讼事项的完整性搜寻、结合律师专业意见的败诉可能性判断、最佳估计的确定、以及确认与披露的临界判断。核心风险为应确认未确认（少计负债隐瞒败诉风险）、可能性判断偏乐观、以及应披露的或有负债未披露。

**法规依据：**
- 《企业会计准则第13号——或有事项》
- 《中国注册会计师审计准则第1301号——审计证据》
- 《中国注册会计师审计准则第1318号——期后事项》

## tips

1. **诉讼完整性须多渠道搜寻**：不能仅依赖管理层提供的诉讼清单，须结合律师函回函、法律费用明细、董事会/管理层会议纪要、监管处罚公告、期后事项等交叉搜寻未决诉讼，防止遗漏。
2. **律师函（A 循环）是可能性判断的关键证据**：败诉可能性及预计赔偿金额应主要依据被审计单位法律顾问/代理律师的专业意见，律师函须明确诉讼进展、败诉可能性和金额估计，与本底稿判断勾稽一致。
3. **按 CAS13 可能性梯度确定处理**：很可能（>50%）败诉且金额可靠计量→确认预计负债；可能（≤50% 且 >5%）→作或有负债披露；极小可能→无须披露。可能性判断偏乐观是最常见舞弊/差错手法。
4. **最佳估计的确定**：单项诉讼取最可能结果金额；一组类似诉讼可用期望值法（各种结果金额×概率加权）；存在连带责任或分摊的须考虑可回收部分（另作资产而非冲减负债）。
5. **确认与披露的临界判断须留痕**：对于处于"很可能"与"可能"临界的诉讼，须记录判断依据（律师意见、类似案例、和解进展），临界判断应保持职业怀疑，倾向审慎。
6. **关注期后进展**：资产负债表日后至报告日诉讼的最新进展（判决、和解、上诉）属期后事项（CAS1318），可能影响期末计提金额或披露，须更新评估。

## checklist

### 一、诉讼完整性搜寻（高风险）

- [ ] 【必检】是否取得完整的未决诉讼/仲裁清单并核对完整性
- [ ] 【必检】是否发函律师并取得律师函回函（A 循环）
- [ ] 【必检】是否核对法律费用明细以发现未列示的诉讼
- [ ] 【必检】是否查阅董事会/管理层会议纪要、监管公告搜寻潜在诉讼
- [ ] 【条件检查：若有监管调查/处罚】相关潜在赔偿义务是否评估
- [ ] 【风险检查】是否存在管理层隐瞒重大不利诉讼

### 二、败诉可能性与最佳估计（高风险）

- [ ] 【必检】各诉讼败诉可能性判断是否以律师专业意见为主要依据
- [ ] 【必检】本底稿可能性判断是否与律师函结论勾稽一致
- [ ] 【必检】很可能败诉且可可靠计量的是否确认预计负债
- [ ] 【必检】预计赔偿金额是否为最佳估计（单项取最可能/一组用期望值法）
- [ ] 【必检】是否考虑诉讼费、连带责任、可回收赔偿等因素
- [ ] 【风险检查】可能性判断是否偏乐观以规避确认预计负债
- [ ] 【风险检查】临界（很可能/可能）判断是否有充分依据并审慎处理

### 三、确认、披露与期后进展（中风险）

- [ ] 【必检】可能（未达很可能）的诉讼是否作或有负债充分披露
- [ ] 【必检】确认预计负债的诉讼是否与 K5-2 明细、K5-1 审定表勾稽
- [ ] 【必检】资产负债表日后诉讼进展（判决/和解/上诉）是否更新评估（CAS1318）
- [ ] 【条件检查：若期后判决结果与期末估计差异重大】是否评估对期末计提的影响
- [ ] 【风险检查】是否存在应披露的或有负债未在附注披露

## risk_areas

### 高风险

1. **应确认未确认（隐瞒败诉风险）**：很可能败诉且金额可靠计量的诉讼未计提预计负债，少计负债、虚增利润、隐瞒重大不利事项。
2. **败诉可能性判断偏乐观**：管理层将很可能败诉的诉讼判断为"可能"以规避确认，或律师意见与账面处理不一致。
3. **诉讼事项遗漏**：未通过律师函、法律费用、会议纪要等多渠道搜寻，遗漏重大未决诉讼。

### 中风险

1. **最佳估计缺乏依据**：预计赔偿金额无律师意见、类似案例或期望值测算支撑。
2. **或有负债披露不足**：达到披露标准的可能诉讼未在附注充分披露。
3. **期后进展未更新**：资产负债表日后诉讼重大进展未评估其对期末计提/披露的影响。

### 低风险

1. **格式与索引不规范**：诉讼台账、律师函索引、判断记录标注不完整。
2. **诉讼说明不足**：未逐项说明诉讼案由、进展阶段、涉及金额及判断依据。
