# K7-4 递延收益分摊测算表复核提示词

## 概述

本提示词针对递延收益分摊测算表（K7-4，科目 2401）的复核，聚焦每笔政府补助的摊销期限确定、摊销方法选择、本期摊销额测算及与其他收益（K10）结转的勾稽。与资产相关的政府补助应在相关资产使用寿命内系统、合理分摊；与收益相关且补偿以后期间费用的按补偿期间分摊。测算表是审定表 K7-1 本期摊销转出额和 K10 本期结转其他收益额的计算依据。核心风险为摊销期限与资产寿命不匹配、摊销方法随意变更、本期摊销额测算错误。

**法规依据：**
- 《企业会计准则第16号——政府补助》
- 《企业会计准则第4号——固定资产》
- 《中国注册会计师审计准则第1301号——审计证据》

## tips

1. **摊销期限须与资产寿命/补偿期间一致**：与资产相关补助的摊销期限=相关资产剩余折旧年限；与收益相关补助的摊销期限=其补偿的费用发生期间，不得随意设定。
2. **摊销方法系统合理且一贯**：通常采用直线法在受益期内平均分摊，方法一经确定不得随意变更；与资产按加速折旧的，补助摊销宜与折旧模式匹配。
3. **本期摊销额测算准确**：本期摊销=补助总额÷摊销期限×本期受益月份（或按进度/产量），起点为相关资产达到可使用状态或补偿期间开始之月。
4. **与 K10 其他收益结转勾稽**：测算表本期摊销转出额之和应与 K10 本期计入其他收益的政府补助额一致；与资产相关补助采用净额法冲减资产的除外。
5. **与 K7-1/K7-2 闭环**：本期摊销额汇总→K7-1 本期摊销转出（审定数减项）；累计摊销、期末余额→K7-2 明细表；测算依据（资产寿命/补偿期间）→附注披露。
6. **关注摊销终止与提前**：相关资产提前处置/报废时，尚未摊销的递延收益余额应一次性转入当期损益（营业外收入或其他收益），测算表须反映该特殊事项。

## checklist

### 一、摊销期限与方法（高风险）

- [ ] 与资产相关补助摊销期限是否等于相关资产剩余折旧年限
- [ ] 与收益相关补助摊销期限是否等于补偿的费用发生期间
- [ ] 摊销方法是否系统合理（直线法/进度法）且前后一贯
- [ ] 摊销起点是否为相关资产达可使用状态或补偿期间开始之月
- [ ] 【条件检查：若资产加速折旧】补助摊销模式是否与折旧模式匹配
- [ ] 【风险检查】是否存在人为拉长/缩短摊销期限调节利润

### 二、本期摊销额测算（高风险）

- [ ] 本期摊销额=总额÷期限×受益月份 计算是否正确
- [ ] 受益月份是否与资产可使用/补偿期间一致（不足整年按月计）
- [ ] 累计已摊销+本期摊销+期末余额是否与补助总额勾稽
- [ ] 【条件检查：若资产提前处置/报废】未摊销余额是否一次性转入当期损益
- [ ] 【风险检查】本期摊销额是否与历史各期趋势匹配，异常须解释

### 三、结转勾稽与数据一致性（高风险）

- [ ] 本期摊销转出额之和是否与 K10 本期结转其他收益的政府补助额一致
- [ ] 本期摊销汇总是否与 K7-1 本期摊销转出（审定数减项）一致
- [ ] 累计摊销、期末余额是否与 K7-2 明细表一致
- [ ] 净额法冲减资产的补助是否已从计入损益的摊销中剔除
- [ ] 摊销依据（资产寿命/补偿期间）是否与附注披露一致

## risk_areas

### 高风险

1. **摊销期限不匹配**：与资产相关补助摊销期限与资产折旧年限不一致，人为拉长/缩短调节利润。
2. **本期摊销额测算错误**：受益月份、总额或期限取数错误导致本期结转损益金额失真。
3. **结转不勾稽**：测算摊销额与 K10 其他收益结转、K7-1 审定数不一致，存在多转/少转。

### 中风险

1. **摊销方法随意变更**：无正当理由变更摊销方法，影响可比性。
2. **提前处置未一次转出**：相关资产提前处置/报废，未将未摊销余额一次性转入损益。
3. **净额法混淆**：净额法冲减资产的补助误计入损益摊销，重复影响损益。

### 低风险

1. **格式与索引不规范**：测算表项目、期限单位、交叉索引不统一。
2. **测算依据说明不足**：摊销期限/方法的确定依据未充分记录。
