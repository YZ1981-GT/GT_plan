# K1-9 其他应收款核销检查复核提示词

## 概述

本提示词针对其他应收款坏账核销检查表（K1-9）的复核，聚焦：核销依据充分性、核销审批程序合规性、核销会计处理正确性、核销与坏账准备/明细勾稽。核销是将确认无法收回的其他应收款及其对应坏账准备予以转销的程序，核销依据不足或审批缺失将掩盖资产损失，是舞弊高发领域，须逐笔核查证据链和审批链。

**法规依据：**
- 《企业会计准则第22号——金融工具确认和计量》
- 《中国注册会计师审计准则第1301号——审计证据》
- 《中国注册会计师审计准则第1141号——财务报表审计中与舞弊相关的责任》

---

## tips

1. **核销依据须客观充分**：每笔核销须有客观证据（债务人破产/清算/注销证明、法院终结执行裁定、逾期多年且追偿无果的书面说明），仅凭管理层判断或账龄长即核销属依据不足。
2. **核销审批须符合内控与授权**：核销须经适当层级审批（大额核销须董事会/股东会决议），审批权限与金额匹配，缺失审批属合规风险，国企/上市公司尤须关注决策程序。
3. **核销会计处理须正确**：核销分录=借"坏账准备"贷"其他应收款"，仅冲减已计提准备不再计入当期损益（除超额部分），须验证核销金额不超过对应已提准备。
4. **核销与坏账明细/测算勾稽**：K1-9 核销金额须与 K1-3 坏账明细"本期核销"栏一致，被核销对象须来自 K1-2 明细表。
5. **警惕核销掩盖舞弊或利益输送**：关联方款项核销、无充分证据的大额核销可能掩盖资金占用或利益输送，须保持职业怀疑并追查资金实际去向。
6. **已核销款项的后续管理**：核销不等于放弃追索权，须关注是否建立备查登记、期后是否收回（收回应重新入账），核销后责任追究（国企）是否启动。

## checklist

### 一、核销依据

- [ ] 每笔核销是否有客观证据（破产/清算/注销/法院裁定/追偿无果说明）
- [ ] 核销依据是否充分（非仅账龄长或管理层判断）
- [ ] 被核销对象是否来自 K1-2 明细表且金额一致
- [ ] 关联方款项核销是否有特别充分的依据

### 二、审批程序

- [ ] 核销是否经适当层级审批，审批权限与金额是否匹配
- [ ] 大额核销是否经董事会/股东会决议（国企含"三重一大"）
- [ ] 审批文件是否留痕完整

### 三、会计处理与勾稽

- [ ] 核销分录（借坏账准备贷其他应收款）是否正确
- [ ] 核销金额是否不超过对应已计提坏账准备
- [ ] K1-9 核销金额是否与 K1-3 坏账明细本期核销栏一致
- [ ] 核销后其他应收款净额是否与审定表 K1-1 勾稽
- [ ] 已核销款项是否建立备查登记，期后收回是否重新入账

## risk_areas

### 高风险

1. **核销依据不足**：缺乏客观无法收回证据即核销，虚减资产损失、粉饰资产质量。
2. **关联方核销掩盖占款**：关联方资金占用以坏账核销名义转销，掩盖利益输送。
3. **审批程序缺失**：大额核销未经适当决策程序，存在重大合规风险（国企/上市公司）。

### 中风险

1. **核销金额超已提准备**：核销超过对应已计提坏账准备且未正确计入损益。
2. **核销与明细不勾稽**：K1-9 与 K1-3/K1-2 核销数据不一致。

### 低风险

1. **备查登记不完整**：已核销款项未建立备查台账或后续追索管理缺失。
2. **责任追究未启动**：国企大额核销未按规定启动损失责任追究（披露层面）。
