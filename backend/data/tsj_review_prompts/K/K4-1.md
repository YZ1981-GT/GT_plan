# K4-1 其他流动负债审定表复核提示词

## 概述

本提示词针对其他流动负债审定表（K4-1，科目 2245，负债类取期末余额）的复核。其他流动负债核算待转销项税额、预提费用、短期应付债券、一年内到期的其他非流动负债等。聚焦：期初期末勾稽、试算表核对、负债完整性、流动性分类（一年内到期部分）、待转销项税额与增值税勾稽。

**法规依据：**
- 《企业会计准则第30号——财务报表列报》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **负债类取"期末余额"**：审定数=期初+本期贷方−本期借方±调整。
2. **期初期末勾稽**：期初审定数=上年期末审定数；审定合计=明细表 K4-2 合计（K4-2-detail-total）。
3. **试算表核对**：审定合计与试算表 2245 审定余额一致（贷方方向）。
4. **完整性**：预提费用是否足额计提，待转销项税额是否完整（与增值税申报勾稽）。
5. **流动性分类**：一年内到期的其他非流动负债重分类至此，判断是否准确；超一年部分不应留在流动。
6. **跨底稿闭环**：审定合计↔K4-2 明细↔试算表 2245↔附注；待转销项税额↔N 循环应交税费。

---

## checklist

### 一、期初期末勾稽与试算表核对

- [ ] 期初审定数是否等于上年期末审定数
- [ ] 审定数=期初+本期贷方−本期借方±调整 是否正确
- [ ] 审定合计是否与明细表 K4-2 合计一致
- [ ] 审定合计是否与试算表 2245 审定余额一致（贷方方向）

### 二、完整性与分类

- [ ] 预提费用是否足额计提、有依据
- [ ] 待转销项税额是否完整，与增值税申报/N 循环勾稽
- [ ] 一年内到期的其他非流动负债重分类是否准确
- [ ] 短期应付债券等是否分类正确

### 三、审计调整完整性

- [ ] 已确认的账项/重分类调整是否完整反映
- [ ] 调整分录借贷平衡、证据充分、经审批

## risk_areas

### 高风险

1. **负债完整性缺失**：预提费用少提或待转销项税额漏计，低估负债。
2. **流动性分类错误**：超一年负债留在流动，或一年内到期未重分类至此。
3. **期初期末不勾稽 / 与试算表不一致**。

### 中风险

1. **待转销项税额与申报不符**：与增值税申报差异未解释。
2. **审计调整遗漏**。

### 低风险

1. **格式与索引不规范**。
2. **明细项目说明不足**。
