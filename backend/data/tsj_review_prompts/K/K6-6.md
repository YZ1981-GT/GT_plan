# K6-6 处置组减值复核提示词

## 概述

本提示词针对持有待售处置组减值底稿（K6-6，科目 1481/2605）的复核。处置组作为一个整体划分为持有待售时，减值测试须以处置组整体（账面价值 vs 公允价值减出售费用）为单位进行，产生的减值损失须按规定顺序在处置组内各项资产间分摊。复核聚焦：处置组整体孰低计量、减值损失的分摊顺序（先商誉后其他非流动资产按比例）、以及分摊后各项资产账面价值不低于其可回收金额的限制。核心风险为分摊顺序错误、分摊后个别资产减记过度、以及处置组整体减值计提不足。

**法规依据：**
- 《企业会计准则第42号——持有待售的非流动资产、处置组和终止经营》
- 《企业会计准则第8号——资产减值》
- 《中国注册会计师审计准则第1301号——审计证据》

## tips

1. **处置组减值以整体为单位测试**：处置组的减值不是各项资产分别测试，而是以处置组整体的账面价值（含相关负债）与整体公允价值减出售费用比较，整体账面价值超出部分为处置组减值损失。
2. **减值分摊顺序须严格遵循准则**：处置组减值损失先冲减处置组中商誉的账面价值，再按适用 CAS42 计量的各项非流动资产账面价值比例分摊，不得随意选择分摊对象。
3. **分摊须区分适用与不适用 CAS42 计量的资产**：处置组中不适用 CAS42 后续计量规定的资产（如按其他准则计量的存货、金融资产、递延所得税资产等）不参与减值分摊，须先按各自准则计量后再确定参与分摊的资产范围。
4. **分摊后个别资产减记有下限**：分摊减值后，各项资产账面价值不应低于其公允价值减出售费用（如可确定）、其可回收金额、以及零三者中的最高者，超过下限的减值不应分摊至该资产而应保留在处置组层面。
5. **后续减值与转回同样按整体处理**：后续期间处置组公允价值减出售费用继续下降的，继续确认减值并分摊；回升的，在原确认减值（不含已冲减的商誉）范围内转回并按比例调整各资产账面价值。
6. **与明细表和减值损失勾稽**：处置组减值分摊结果须反映到 K6-2 明细表各项资产账面价值，减值损失总额与 K11 资产减值损失/处置损益及利润表勾稽。

## checklist

### 一、处置组整体孰低计量（高风险）

- [ ] 【必检】减值是否以处置组整体为单位测试（账面价值 vs 公允价值减出售费用）
- [ ] 【必检】处置组账面价值是否正确（包含各项资产及直接相关负债）
- [ ] 【必检】处置组公允价值减出售费用是否有可靠估值依据
- [ ] 【必检】处置组整体减值损失金额复算是否正确
- [ ] 【风险检查】是否以单项资产测试代替处置组整体测试导致减值计提不足

### 二、减值分摊顺序与范围（高风险）

- [ ] 【必检】是否先冲减处置组中商誉账面价值
- [ ] 【必检】剩余减值是否按适用 CAS42 计量的各项非流动资产账面价值比例分摊
- [ ] 【必检】不适用 CAS42 计量的资产（存货/金融资产/递延所得税等）是否先按各自准则计量并排除在分摊外
- [ ] 【必检】分摊比例计算是否正确（各资产账面价值/参与分摊资产账面价值合计）
- [ ] 【风险检查】是否存在分摊顺序错误或随意选择分摊对象

### 三、分摊下限与后续处理（中风险）

- [ ] 【必检】分摊后各项资产账面价值是否不低于其公允价值减出售费用/可回收金额/零的最高者
- [ ] 【必检】超过下限的减值是否保留在处置组层面而非过度减记个别资产
- [ ] 【条件检查：若后续公允价值下降】继续确认减值并分摊是否正确
- [ ] 【条件检查：若后续公允价值回升】转回是否在原减值（不含已冲减商誉）范围内并按比例调整
- [ ] 【必检】分摊结果是否反映到 K6-2 明细表及与 K11/利润表勾稽

## risk_areas

### 高风险

1. **处置组整体减值计提不足**：以单项资产测试代替处置组整体测试，或高估处置组公允价值减出售费用，少提整体减值。
2. **减值分摊顺序错误**：未先冲减商誉、未按非流动资产账面价值比例分摊，或将减值分摊至不适用 CAS42 计量的资产。
3. **分摊范围界定错误**：未将存货、金融资产、递延所得税资产等不适用 CAS42 计量的资产排除在减值分摊之外。

### 中风险

1. **分摊后个别资产减记过度**：分摊减值后个别资产账面价值低于其公允价值减出售费用/可回收金额/零的最高者。
2. **减值转回处理不当**：后续公允价值回升时转回减值超限、错误冲回已冲减的商誉、或未按比例调整各资产账面价值。
3. **分摊结果未勾稽**：处置组减值分摊结果未反映到 K6-2 明细表或未与 K11/利润表勾稽。

### 低风险

1. **格式与索引不规范**：整体减值测算、分摊过程、交叉索引标注不完整。
2. **处置组构成说明不足**：处置组包含的资产、负债及适用计量规定的说明不充分。
