# K2-4 合同取得成本明细表复核提示词

## 概述

本提示词针对合同取得成本明细表（K2-4，其他流动资产 1231 项下）的复核，聚焦：合同取得成本确认条件、资本化范围合理性、增量成本判断、摊销期与合同期匹配。CAS14 下，企业为取得合同发生的增量成本（如销售佣金），预期能够收回的应确认为一项资产（合同取得成本），本明细表逐合同列示取得成本的确认、资本化金额和摊销安排，是收入准则应用的关键判断点。

**法规依据：**
- 《企业会计准则第14号——收入》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **增量成本判断是资本化的前提**：合同取得成本仅限"增量成本"——即不取得合同就不会发生的成本（如成交后支付的销售佣金），无论是否取得合同都会发生的成本（如固定薪酬、日常差旅）不得资本化，应费用化。
2. **预期收回是资本化的必要条件**：资本化的合同取得成本须预期能够收回（通过合同履约获得的对价覆盖），不能收回的不得资本化，须评估合同盈利性。
3. **摊销期须与相关商品/服务转让期匹配**：合同取得成本按与其相关的商品/服务转让方式摊销，摊销期通常为合同期（含预期续约期），摊销期错误将扭曲各期损益。
4. **简化处理的适用须核实**：摊销期不超过一年的合同取得成本可于发生时费用化（简化处理），采用简化处理须符合条件且一致，避免选择性资本化调节利润。
5. **资本化金额与明细/摊销测算勾稽**：K2-4 资本化合同取得成本余额须与 K2-2 明细表对应项目一致，摊销安排须与 K2-5 摊销测算衔接。
6. **减值评估须关注**：合同取得成本账面价值超过"剩余对价−预计发生成本"的差额须计提减值，合同盈利性恶化时须评估减值。

## checklist

### 一、确认条件与增量成本

- [ ] 资本化的成本是否为"增量成本"（不取得合同就不发生）
- [ ] 是否将非增量成本（固定薪酬/日常费用）错误资本化
- [ ] 资本化的合同取得成本是否预期能够收回
- [ ] 合同盈利性是否支撑成本收回

### 二、资本化与摊销

- [ ] 摊销期不超过一年的是否采用简化处理（费用化）且一致
- [ ] 摊销期是否与相关商品/服务转让期（合同期含续约）匹配
- [ ] 资本化金额是否与 K2-2 明细表对应项目一致
- [ ] 摊销安排是否与 K2-5 摊销测算衔接

### 三、减值与流动性

- [ ] 合同取得成本是否评估减值（账面 vs 剩余对价−预计成本）
- [ ] 合同盈利性恶化时是否计提减值
- [ ] 合同取得成本减值是否与相关合同资产/存货减值协调
- [ ] 超一年摊销部分的流动性分类是否恰当

## risk_areas

### 高风险

1. **非增量成本资本化**：将固定薪酬/日常费用错误资本化为合同取得成本，虚增资产、递延费用。
2. **不可收回成本资本化**：亏损合同的取得成本仍资本化，未评估收回可能性。
3. **减值未计提**：合同盈利性恶化但合同取得成本未计提减值，资产高估。

### 中风险

1. **摊销期不匹配**：摊销期与商品/服务转让期不一致，扭曲各期损益。
2. **简化处理选择性适用**：选择性对不同合同采用/不采用简化处理调节利润。

### 低风险

1. **明细记录不完整**：合同取得成本的合同背景和摊销依据记录简略。
2. **交叉索引不完整**：与 K2-2/K2-5 的引用标注不全。
