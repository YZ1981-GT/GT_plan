# K11-2 资产减值损失明细表复核提示词

## 概述

本提示词针对资产减值损失明细表（K11-2，科目 6701，损益类借方，取本期发生额）的复核。明细表按资产类别分项列示本期计提、本期转回及净发生额，是资产减值损失科目的基础数据底稿，向上支撑审定表 K11-1 的汇总，向外与各资产减值专项底稿（存货 F2、固定资产/在建工程 H、无形资产/开发支出 I、商誉 I4、应收类 D2）逐项勾稽。其数据质量直接决定利润的真实性——少提减值即虚增利润，是本科目完整性认定的高发风险点。

**法规依据：**
- 《企业会计准则第8号——资产减值》
- 《企业会计准则第22号——金融工具确认和计量》（预期信用损失）
- 《中国注册会计师审计准则第1301号——审计证据》
- 《中国注册会计师审计准则第1211号——通过了解被审计单位及其环境识别和评估重大错报风险》

## tips

1. **取"发生额"非"余额"**：明细表每一资产类别按本期计提额（借方）减本期转回额（贷方，商誉及部分长期资产不得转回）计算净发生额，勿以减值准备余额填列。
2. **逐项勾稽各资产减值底稿是明细表核心**：存货跌价准备↔F2、固定资产/在建工程减值↔H 循环、无形资产/开发支出减值↔H4/I 循环、商誉减值↔I4、应收类信用减值↔D2（属 6702 须单独列示），每一分项本期计提额须与对应资产底稿减值测试结论一致。
3. **本期发生额合计必须等于 K11-1 审定合计**：明细表各项净发生额之和 = 审定表 K11-1 汇总审定数 = 试算表 6701 审定发生额，任何差异须追溯至具体分项或调整分录。
4. **商誉减值不可转回是明细表红线**：核对明细表中商誉、以及已确认减值的固定资产/无形资产等长期资产是否出现违规转回（贷方），一经违规转回即虚增利润。
5. **计提充分性优先于准确性**：存在减值迹象（资产闲置、市价持续下跌、亏损合同、技术淘汰、逾期应收）的资产类别若本期计提为零或明显不足，须重点质疑是否存在漏提。
6. **区分 6701 资产减值损失与 6702 信用减值损失**：应收账款、其他应收款、债权投资等金融资产的预期信用损失计入 6702，不得混入 6701 明细表，混列将导致列报错误。

## checklist

### 一、发生额勾稽与汇总（高风险）

- [ ] 【必检】各资产类别本期发生额=本期计提−本期转回是否计算正确
- [ ] 【必检】明细表各分项净发生额合计是否与审定表 K11-1 审定合计一致
- [ ] 【必检】明细表本期发生额合计是否与试算平衡表 6701 审定发生额一致
- [ ] 【必检】未审发生额合计是否与试算表 6701 未审数一致
- [ ] 【必检】上期本期发生额是否与上年 K11-2 底稿衔接
- [ ] 【风险检查】是否存在分项金额异常波动（超过30%）且无合理说明

### 二、与各资产减值底稿逐项勾稽（高风险）

- [ ] 【必检】存货跌价准备本期计提是否与 F2 存货底稿一致
- [ ] 【必检】固定资产减值本期计提是否与 H1 固定资产底稿一致
- [ ] 【必检】在建工程减值本期计提是否与 H2 底稿一致
- [ ] 【必检】无形资产/开发支出减值是否与 H4/I 循环底稿一致
- [ ] 【必检】商誉减值是否与 I4 底稿一致
- [ ] 【必检】长期股权投资减值是否与 G7 底稿一致
- [ ] 【必检】各减值分项是否有减值测试/可收回金额计算过程支持
- [ ] 【条件检查：若有合同资产减值】合同资产减值是否与 D6 底稿一致
- [ ] 【风险检查】存在减值迹象的资产类别是否均已评估并计提

### 三、转回与列报正确性（高风险）

- [ ] 【必检】商誉减值是否未出现违规转回
- [ ] 【必检】已计提减值的固定资产/无形资产等长期资产是否未违规转回
- [ ] 【必检】存货跌价准备转回是否以原计提金额为限且有依据
- [ ] 【必检】应收类信用减值损失（6702）是否单独列示，未混入 6701
- [ ] 【条件检查：若有减值转回】转回原因及依据是否充分（价值回升证据）
- [ ] 【风险检查】是否存在为调节利润而不当转回减值准备

### 四、完整性与计提充分性（中风险）

- [ ] 【必检】各类资产减值迹象排查是否覆盖全部资产类别
- [ ] 【必检】逾期、闲置、亏损合同、市价下跌等迹象是否对应计提
- [ ] 【条件检查：若有零计提分项】存在减值迹象却零计提是否有合理说明
- [ ] 【风险检查】长账龄/长期闲置资产减值计提比例是否与历史经验匹配

## risk_areas

### 高风险

1. **漏提/少提减值虚增利润**：存在明确减值迹象（闲置、市价下跌、亏损合同、逾期）的资产类别本期未足额计提，直接虚增利润，属完整性认定的首要风险。
2. **商誉/长期资产减值违规转回**：将不可转回的商誉或已减值长期资产减值贷方转回，虚增当期利润。
3. **与各资产底稿不勾稽**：明细分项本期计提额与对应资产减值专项底稿测试结论不一致，表明汇总遗漏或错误。
4. **明细合计与审定表/试算表不勾稽**：K11-2 净发生额合计与 K11-1 审定数或 6701 试算发生额存在无源差异。

### 中风险

1. **6701 与 6702 混列**：将金融资产预期信用损失计入资产减值损失，导致利润表列报错误。
2. **减值测算依据不足**：可收回金额、公允价值确定的关键假设（折现率、市价来源）缺乏支持性证据。
3. **转回依据不充分**：存货跌价准备等转回缺乏价值回升的客观证据，可能为利润调节。

### 低风险

1. **格式与索引不规范**：明细表分项排列、与各资产底稿的交叉索引标注不完整。
2. **减值项目说明不足**：分项减值仅列金额未附计提原因或测试方法简述。
