# K12-note-soe 营业外收入附注披露复核提示词（国有企业）

## 概述

本提示词针对营业外收入国有企业附注披露底稿（K12-note-soe，科目 6301，损益类）的复核。在满足企业会计准则通用披露（按利得性质分项、政府补助无关性、与审定表勾稽）基础上，聚焦国有企业特定要求：与政府/国有单位相关利得的披露、政府补助的财政资金属性、无法支付款项转入涉及国有资产的处理、以及财务决算报告补充披露。国有企业营业外收入中政府补助占比通常较高，其分类与披露是国资监管关注点。

**法规依据：**
- 《企业会计准则第16号——政府补助》
- 《企业会计准则第30号——财务报表列报》
- 《企业国有资产法》
- 《中央企业财务决算报告管理办法》
- 《公开发行证券的公司信息披露编报规则第9号——非经常性损益》

## tips

1. **国企附注"双层"披露**：既满足 CAS 通用分项披露（按利得性质、政府补助无关性），又满足国资委财务决算报告对营业外收入及政府补助的补充披露要求。
2. **政府补助的财政资金属性**：计入营业外收入的政府补助须区分财政拨款、税收返还、贴息等来源，并说明是否属专项资金及其使用要求。
3. **与政府/国有单位相关利得**：与政府部门、其他国有单位相关的利得（如财政奖励、国有单位捐赠）须单独说明，关注是否存在利益输送或资金性质混淆。
4. **无法支付款项转入涉及国有资产**：将应付国有单位款项转入营业外收入须审慎，核对是否真正无需支付，防止变相处置国有资产/负债。
5. **非经常性损益披露**：营业外收入属非经常性损益，须单独列示供业绩考核剔除非经常因素，国企业绩考核对扣非指标同样关注。
6. **附注数据与审定表/明细表/决算报表闭环**：附注分项本期发生额=K12-2 明细净发生额=利润表营业外收入行=审定表 K12-1 审定合计=财务决算报表相应数据。

## checklist

### 一、基础披露完整性（与上市版共有）

- [ ] 营业外收入是否按利得性质完整分项列示本期发生额
- [ ] 各分项合计是否等于利润表营业外收入行及审定表 K12-1 审定合计
- [ ] 是否同时披露本期数与上期可比数
- [ ] 各分项是否与 K12-2 明细表勾稽
- [ ] 计入营业外收入的政府补助是否披露与日常活动无关性
- [ ] 非经常性损益项目是否单独列示

### 二、政府补助与财政资金披露

- [ ] 政府补助是否区分财政拨款/税收返还/贴息等来源
- [ ] 是否说明政府补助是否属专项资金及使用要求
- [ ] 计入营业外收入的补助是否与递延收益（K7）转入金额勾稽
- [ ] 政府补助计入营业外收入而非其他收益（K10）的依据是否披露
- [ ] 与政府部门相关的财政奖励/返还是否单独列示

### 三、国有资产监管相关披露

- [ ] 无法支付款项转入涉及国有单位款项是否审慎核实并说明
- [ ] 与其他国有单位相关的利得是否单独说明性质
- [ ] 是否存在应付国有单位款项变相转入收入的情况并说明
- [ ] 营业外收入对当期利润及考核指标的影响是否说明
- [ ] 重大利得是否说明形成原因及审批情况

### 四、决算报表特殊要求

- [ ] 营业外收入数据是否与年度财务决算报表一致
- [ ] 政府补助数据是否与决算报表补助明细一致
- [ ] 非经常性损益金额是否用于业绩考核指标剔除
- [ ] 集团合并层面内部利得抵销是否完整
- [ ] 营业外收入分类是否与决算口径一致

### 五、与上市版的差异关注点

- [ ] 是否在基础分项披露之上增加了政府补助财政资金属性说明
- [ ] 是否增加了与政府/国有单位相关利得的单独披露
- [ ] 是否增加了无法支付款项转入涉及国有资产的审慎说明
- [ ] 是否增加了对业绩考核指标的影响分析

## risk_areas

### 高风险

1. **无法支付款项转入变相处置国有负债**：将应付国有单位款项在未真正免除的情况下转入营业外收入，虚增利润且可能损害国有权益。
2. **政府补助分类披露错误**：与日常活动相关的补助错计营业外收入，或财政资金性质混淆，扭曲营业利润与考核指标。
3. **分项与决算/审定表不勾稽**：附注营业外收入数据与财务决算报表或 K12-1 审定合计不一致。

### 中风险

1. **政府补助财政资金属性未披露**：未区分补助来源及专项资金使用要求。
2. **非经常性损益披露不足**：未单独列示营业外收入的非经常性损益金额，影响考核指标剔除。
3. **与政府/国有单位利得说明缺失**：相关利得未单独说明性质及公允性。
4. **决算与审计口径差异未调节**：财务决算营业外收入数据与审计后附注存在差异未调节。

### 低风险

1. **披露格式未完全按决算模板**：附注格式与国资委决算报表模板有细微差异。
2. **利得性质说明过于简略**：仅列金额未结合国企实际说明利得成因。
