# K1-5 其他应收款大额分析复核提示词

## 概述

本提示词针对其他应收款大额款项分析表（K1-5）的复核，聚焦：大额对象选取充分性、款项性质与业务实质核查、关联方非经营性占款识别、可收回性与减值评估。大额分析针对超过设定阈值（或前 N 大）的其他应收款对象逐笔穿透其形成原因、资金去向和收回安排，是识别关联方资金占用、异常往来和减值风险的关键程序。

**法规依据：**
- 《企业会计准则第22号——金融工具确认和计量》
- 《企业会计准则第36号——关联方披露》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **大额对象选取阈值须合理并覆盖充分**：选取标准（金额阈值/前 N 大/占比）须与重要性水平匹配，选取后覆盖率应达到充分水平（通常对总额覆盖不低于计划比例），阈值过高将遗漏重大风险敞口。
2. **款项性质与业务实质须穿透核查**：大额款项须核查形成背景、资金去向、合同/协议依据，警惕以其他应收款名义变相拆借资金或输送利益。
3. **关联方非经营性占款是首要关注点**：大额对象须与 K1-11 关联方检查交叉，识别控股股东/关联方资金占用，评估是否收取占用费、是否构成非经营性占用（尤其上市公司须专项关注）。
4. **可收回性评估须有客观依据**：大额款项的对方财务状况、履约能力、期后收回情况须评估，作为 K1-7 三阶段划分和 K1-8 单项减值的输入。
5. **大额款项与明细表勾稽**：K1-5 分析对象须来自 K1-2 明细表，金额、性质、账龄须一致，遗漏大额对象即分析覆盖不足。
6. **异常大额往来须标注并追踪**：整数金额、期末突增、无合同支撑、长期无收回安排的大额款项须标注异常并评估是否需调整或披露。

## checklist

### 一、选取充分性

- [ ] 大额对象选取阈值（金额/前N大/占比）是否合理且与重要性水平匹配
- [ ] 选取后对其他应收款总额的覆盖比例是否达到计划水平
- [ ] 大额对象是否全部来自 K1-2 明细表且金额一致
- [ ] 是否遗漏应纳入的重大风险敞口（关联方/长账龄/异常往来）

### 二、性质与实质核查

- [ ] 每笔大额款项的形成背景与业务实质是否核查
- [ ] 是否有合同/协议/审批等原始依据支撑
- [ ] 资金去向是否清晰，是否存在变相拆借
- [ ] 是否存在以其他应收款名义的利益输送迹象

### 三、关联方与可收回性

- [ ] 大额对象是否与 K1-11 关联方检查交叉，关联方占款是否识别
- [ ] 关联方资金占用是否评估占用费收取及非经营性占用性质
- [ ] 大额款项对方履约能力/财务状况是否评估
- [ ] 期后收回情况是否记录，作为可收回性佐证
- [ ] 减值评估结论是否作为 K1-7/K1-8 输入

## risk_areas

### 高风险

1. **关联方非经营性占款未识别**：大额款项实为关联方资金占用但未识别或未评估占用费，规避披露（上市公司尤须关注）。
2. **变相拆借资金**：以其他应收款名义向关联方或第三方拆借资金，缺乏合同依据和商业实质。
3. **大额款项可收回性存疑未减值**：对方财务恶化/长期无收回安排但未纳入单项减值评估。

### 中风险

1. **选取覆盖不足**：阈值过高或遗漏重大对象，大额分析未覆盖主要风险敞口。
2. **业务实质核查不深**：仅核对金额未穿透资金去向和形成原因。

### 低风险

1. **分析记录不完整**：大额对象的背景说明和收回安排记录简略。
2. **交叉索引不完整**：与 K1-2/K1-11/K1-8 的引用标注不全。
