# K13-1 营业外支出审定表复核提示词

## 概述

本提示词针对营业外支出审定表（K13-1，科目 6711，损益类借方，取本期发生额）的复核。营业外支出核算与日常活动无关的损失：捐赠支出、非流动资产毁损报废损失、罚款滞纳金支出、非常损失等。聚焦：发生额勾稽、计入科目正确性、税前扣除性（与所得税勾稽）、完整性与截止。

**法规依据：**
- 《企业会计准则第30号——财务报表列报》
- 《中国注册会计师审计准则第1301号——审计证据》
- 《中国注册会计师审计准则第1141号——与舞弊相关的责任》

---

## tips

1. **取"发生额"非"余额"**：审定数按 6711 本期借方发生额−贷方±调整。
2. **发生额勾稽**：审定合计=未审+AJE+RJE，且=明细表 K13-2 审定合计。
3. **计入科目判断**：与日常活动无关的损失计营业外支出；日常经营损失不应计入营业外支出（避免美化营业利润）。
4. **税前扣除性**：罚款滞纳金、非公益性捐赠等在企业所得税前不得扣除，须为 N 循环递延所得税/所得税费用（纳税调整）提供依据。
5. **完整性**：资产毁损报废损失是否足额确认，有无将应计损失隐匿或跨期。
6. **跨底稿闭环**：审定合计↔K13-2↔试算表 6711↔利润表"营业外支出"行；非流动资产处置损失↔相关资产处置底稿。

## checklist

### 一、发生额勾稽与试算表核对

- [ ] 审定表各项目审定数=未审+AJE+RJE 是否正确
- [ ] 审定合计是否与明细表 K13-2 审定合计一致
- [ ] 审定合计是否与试算平衡表 6711 审定发生额一致
- [ ] 未审发生额是否与试算表 6711 一致
- [ ] 上期审定数是否与上年底稿一致

### 二、计入科目与税前扣除性

- [ ] 各项损失计入营业外支出是否确与日常活动无关
- [ ] 是否存在日常经营损失错计营业外支出以美化营业利润
- [ ] 罚款滞纳金、非公益性捐赠等税前不可扣除项目是否标识，供纳税调整
- [ ] 非流动资产毁损报废损失是否与资产处置底稿勾稽

### 三、审计调整与完整性

- [ ] 已确认的账项/重分类调整是否完整反映
- [ ] 捐赠支出、非常损失是否有支持性证据与审批
- [ ] 资产负债表日前后损失是否记入恰当期间（截止）
- [ ] 是否存在应确认损失被隐匿或跨期

## risk_areas

### 高风险

1. **完整性缺失**：应确认的资产毁损/非常损失未足额确认或跨期，虚增利润。
2. **分类错误**：日常经营损失错计营业外支出美化营业利润，或反之。
3. **审定表与试算表不勾稽**：发生额口径不一致。

### 中风险

1. **税前扣除性未标识**：罚款/非公益捐赠等未标识，影响所得税纳税调整（N 循环）。
2. **证据不足**：捐赠、非常损失缺乏审批与支持性证据。
3. **审计调整遗漏**：已确认调整未纳入审定表。

### 低风险

1. **格式与索引不规范**。
2. **损失项目说明不足**。
