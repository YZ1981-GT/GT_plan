# K7-note-soe 递延收益附注披露复核提示词（国有企业）

## 概述

本提示词针对递延收益国有企业附注披露底稿（K7-note-soe，科目 2401）的复核，聚焦国有企业特定的递延收益披露要求：政府补助/财政资金的分类披露、国资监管相关信息、财政专项资金的使用与结转、国资委财务决算报告的补充披露事项，以及与上市公司版本的差异关注点。国有企业政府补助往往体量大、涉及财政专项资金和产业扶持资金，附注披露须同时满足会计准则和国资监管要求。

**法规依据：**
- 《企业会计准则第16号——政府补助》
- 《企业会计准则第30号——财务报表列报》
- 《企业国有资产法》
- 《中央企业财务决算报告管理办法》
- 《财政专项资金管理相关规定》

## tips

1. **国企递延收益多为财政专项资金**：附注须区分一般政府补助与财政专项拨款/产业扶持资金，专项资金往往有严格用途限定和结转结余管理要求，须单独说明使用进度。
2. **双层披露要求**：既满足 CAS16 政府补助披露，又满足国资委财务决算报告对财政资金的额外披露要求，两套要求互补不可替代。
3. **专项资金结转结余管理**：财政专项资金结余是否按规定结转或上缴，长期挂账未使用的专项资金递延收益须说明原因及使用计划，防止被认定为资金闲置。
4. **与资产相关补助的国资视角**：政府补助形成的资产其后续使用、处置须符合国有资产管理规定，相关递延收益摊销与国有资本保值增值考核相关。
5. **返还与合规风险**：专项资金若未按批复用途使用或未达绩效目标，存在被财政收回的风险，附注须披露相关或有事项及合规情况。
6. **闭环勾稽**：附注递延收益期末余额=审定表 K7-1 审定数=明细 K7-2 期末合计=财务决算报表相关数据；本期摊销转出与其他收益（K10）勾稽。

## checklist

### 一、基础披露完整性（与上市版共有）

- [ ] 是否按与资产相关/与收益相关分类披露递延收益
- [ ] 变动表是否完整（期初/本期新增/本期摊销转出/其他减少/期末）
- [ ] 附注递延收益期末余额是否与审定表 K7-1 一致
- [ ] 各分类小计与总额是否勾稽
- [ ] 期初数/期末数可比信息是否完整
- [ ] 本期计入损益的政府补助总额是否与利润表勾稽

### 二、财政专项资金与国资监管披露

- [ ] 财政专项拨款/产业扶持资金是否单独披露项目、金额、批复文号
- [ ] 专项资金结转结余是否按规定结转或上缴，长期挂账原因是否说明
- [ ] 专项资金使用进度及绩效目标完成情况是否说明
- [ ] 政府补助形成资产的后续使用/处置是否符合国有资产管理规定
- [ ] 与资产相关补助摊销对国有资本保值增值率的影响是否说明
- [ ] 是否披露涉及财政资金的重大补助的批准部门及用途限定

### 三、返还合规与决算一致性

- [ ] 未达绩效目标或用途不符可能被收回的专项资金是否披露或有事项
- [ ] 专项资金使用合规性（是否专款专用）是否说明
- [ ] 递延收益数据是否与年度财务决算报表一致
- [ ] 本期摊销转出是否与 K10 其他收益/营业外收入结转勾稽
- [ ] 决算报表与审计后附注数据差异是否编制调节说明
- [ ] 与上市版差异：是否在基础披露上增加了财政资金监管层面的补充信息

## risk_areas

### 高风险

1. **专项资金用途/结转不合规未披露**：财政专项资金未专款专用或结余未按规定结转上缴，未披露合规风险，涉及审计责任。
2. **返还风险未披露**：未达绩效目标或用途不符、可能被财政收回的专项资金未披露或有事项。
3. **变动表不勾稽**：变动表与 K7-2 明细、K7-4 测算或利润表损益不一致，属重大披露错误。
4. **基础披露与审定表不一致**：附注递延收益期末余额与审定表审定数不符。

### 中风险

1. **专项资金明细不充分**：财政专项拨款未单独披露批复文号、用途限定及使用进度。
2. **决算与审计口径差异未调节**：财务决算数据与审计后附注数据存在差异未说明。
3. **长期挂账未说明**：长期未使用的专项资金递延收益未说明原因及使用计划。

### 低风险

1. **披露格式未完全按决算模板**：附注格式与国资委决算报表模板有细微差异。
2. **绩效说明过于简略**：专项资金绩效目标完成情况说明深度不足。
