# K13-4 营业外支出检查表复核提示词

## 适用底稿
营业外支出凭证检查表（K13-4，科目 6711，损益类借方），聚焦样本选取方法合理性、凭证核对完整性（捐赠/罚款/毁损等依据）、检查比例达标性、税前扣除性核查、异常交易标注充分性、以及截止测试有效性。

## tips

- 样本选取应覆盖金额重大损失、捐赠支出、非流动资产毁损报废损失、期末集中确认的损失等
- 凭证核对须验证损失的真实性与依据充分性（捐赠协议/罚款判决/毁损报废鉴定/审批文件）
- 检查比例应满足《中国注册会计师审计准则第1314号——审计抽样》要求
- 每笔损失须核查税前扣除性，罚款滞纳金、非公益性捐赠等标识税前不可扣除
- 截止测试关注资产负债表日前后损失是否记入恰当期间，防止跨期递延损失虚增利润
- 关注营业外支出与营业成本/费用的分类是否正确（日常经营损失不应计营业外支出）
- 异常交易标注需明确异常类型（金额异常/时间异常/依据异常/分类异常/税务异常）
- 职业怀疑贯穿始终：对无审批或依据不足的大额损失、期末集中确认的损失保持警觉

## checklist

### 高风险检查项

- [ ] 样本选取方法是否与营业外支出重大错报风险相匹配
- [ ] 金额重大损失（超过重要性水平）是否100%全覆盖检查
- [ ] 捐赠支出、非流动资产毁损报废损失是否纳入必选样本
- [ ] 期末集中确认的营业外支出是否重点核查
- [ ] 每笔样本损失是否有充分依据支持（协议/判决/毁损鉴定/审批）
- [ ] 捐赠支出是否有捐赠协议及受赠方接收证明
- [ ] 非流动资产毁损报废是否有资产报废鉴定及审批文件
- [ ] 罚款滞纳金是否有处罚决定书/判决/缴款凭证
- [ ] 计入营业外支出的损失是否确与日常活动无关（非营业成本/费用）
- [ ] 是否存在无实际业务支持或无审批的大额损失凭证

### 中风险检查项

- [ ] 抽样总体是否完整（是否从完整的 6711 借方序时账导出）
- [ ] 样本量是否满足审计目标所需的置信水平
- [ ] 检查比例（已检查金额/本期发生额）是否达到计划水平
- [ ] 每笔损失的税前扣除性是否核查并标识
- [ ] 罚款滞纳金、非公益性捐赠是否标识税前不可扣除
- [ ] 凭证日期与记账日期是否一致，是否存在跨期记录
- [ ] 资产负债表日前后损失凭证的截止测试是否执行并记录
- [ ] 非流动资产毁损报废损失是否与资产处置底稿勾稽
- [ ] 核对过程中发现的差异是否逐一追踪解决

### 低风险检查项

- [ ] 抽样工作底稿是否完整记录抽样参数（总体/置信水平/可容忍错报）
- [ ] 样本选取过程是否可追溯（随机数种子/系统抽样间隔/选取依据）
- [ ] 凭证检查结果记录格式是否规范统一
- [ ] 检查比例计算公式是否正确（分子=已检查金额，分母=本期发生额）
- [ ] 底稿索引与交叉引用是否完整（关联审定表 K13-1/明细表 K13-2）

## risk_areas

### 高风险

- **无依据/无审批损失风险**：大额损失（捐赠、报废、非常损失）缺乏审批或依据，可能为虚构损失或掩盖资金流失
- **完整性错误风险**：应确认的资产毁损报废损失被隐匿、少计或跨期递延，虚增利润，须核查资产实物状态与账面处理一致性
- **截止性错误风险**：资产负债表日前后损失未实施截止测试，跨期递延损失以调节利润
- **分类操纵风险**：将日常经营损失（正常毁损、成本费用）错计营业外支出以美化营业利润
- **税前扣除性遗漏风险**：罚款滞纳金、非公益性捐赠等税前不可扣除项目未识别标识，导致所得税费用错算

### 中风险

- **检查比例不足风险**：实际检查比例低于计划水平，审计证据不充分
- **依据核对不深入风险**：仅核对金额而未验证损失依据的合规性（如捐赠受赠方资质、报废鉴定有效性）
- **资产处置勾稽不充分风险**：非流动资产处置损失与资产处置底稿金额未核对一致
- **税前扣除性判断不准风险**：公益性捐赠税前扣除限额（利润总额12%）计算未核查

### 低风险

- **记录不完整风险**：抽样参数/选取过程/核对结果的工作底稿记录不完整
- **索引缺失风险**：凭证检查底稿与审定表/明细表的交叉索引不完整
- **格式不规范风险**：检查结果记录格式不统一

## 法规依据

- 《中国注册会计师审计准则第1314号——审计抽样》：抽样设计、执行与评价
- 《中国注册会计师审计准则第1301号——审计证据》：证据充分性与适当性
- 《中国注册会计师审计准则第1141号——财务报表审计中与舞弊相关的责任》：营业外支出舞弊风险
- 《中华人民共和国企业所得税法》及其实施条例：税前扣除性判断依据

## 关注场景

### 样本选取方法合理性
1. 确认必选样本涵盖：金额超重要性水平的损失、捐赠支出、非流动资产毁损报废损失、期末集中确认的损失
2. 检查总体完整性：是否从完整的 6711 借方序时账导出，未人为排除项目
3. 评估分层标准：按金额分层（大额全查/中额抽样）+ 按性质分层（捐赠/毁损/罚款重点关注）

### 凭证核对完整性
1. 捐赠支出核对：捐赠协议→受赠方接收证明/公益性捐赠票据→审批文件→记账分录→税前扣除限额判断
2. 非流动资产毁损报废核对：资产报废鉴定/毁损证明→报废审批→资产账面价值转销→残值处理→记账分录
3. 罚款滞纳金核对：处罚决定书/判决/仲裁→缴款凭证→记账分录→税前不可扣除标识
4. 非常损失核对：损失事实证明（灾害/事故）→保险理赔情况→损失金额确认依据→审批
5. 异常核对结果分类：依据缺失/无审批/金额不一致/日期跨期/分类错误/税务处理错误

### 检查比例达标性
1. 计算检查比例：已检查损失金额 ÷ 营业外支出本期发生额 × 100%
2. 对照计划比例：实际比例 ≥ 计划比例为达标；不达标须说明原因并评估是否补充样本
3. 高风险项（无审批大额损失/期末集中确认损失）检查比例应显著高于一般项

### 税前扣除性核查
1. 罚款滞纳金：行政/税务罚款、税收滞纳金税前不得扣除，须标识供纳税调整
2. 捐赠支出：公益性捐赠在利润总额12%以内可扣除、超额部分结转；非公益性捐赠不得扣除
3. 赞助支出：非广告性质赞助支出税前不得扣除
4. 标识要素：项目名称 + 金额 + 税前扣除性（可扣除/不可扣除/限额扣除）+ 纳税调整金额

### 异常交易标注充分性
1. 金额异常：单笔超重要性水平/与历史偏差超30%/期末最后几天集中确认
2. 时间异常：资产负债表日前后异常波动/跨期记录/损失确认时点与实际处置时点不符
3. 依据异常：无审批/无原始凭证/依据合规性存疑
4. 分类异常：日常经营损失错计营业外支出
5. 税务异常：税前不可扣除项目未标识/公益性捐赠超限额未调整
6. 标注要素：异常类型 + 异常描述 + 涉及金额 + 初步判断（合理解释/需进一步调查/疑似错报）
