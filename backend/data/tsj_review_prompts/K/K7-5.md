# K7-5 递延收益检查表复核提示词

## 概述

本提示词针对递延收益凭证检查表（K7-5，科目 2401）的复核，聚焦样本选取方法合理性、记账凭证与政府批文/到账凭证核对完整性、检查比例达标性、异常事项标注充分性。检查表以逐笔凭证核对验证递延收益的存在性、完整性和确认时点，核对链条覆盖批文/协议→到账凭证→记账凭证→摊销测算。核心风险为无批文提前确认、到账金额与入账金额不符、摊销凭证与测算表不符。

**法规依据：**
- 《中国注册会计师审计准则第1314号——审计抽样》
- 《企业会计准则第16号——政府补助》
- 《中国注册会计师审计准则第1301号——审计证据》

## tips

1. **样本选取匹配风险**：大额补助、新增补助、期末临近确认的补助应作必选样本全覆盖，其余合理抽样；本期发生额（贷方新增/借方摊销转出）分别达到计划检查比例。
2. **核对链条完整**：递延收益凭证核对须覆盖 批文/协议（文号、金额、用途、附加条件）→ 到账凭证（银行回单日期、金额、付款方）→ 记账凭证（确认时点、科目、金额）→ 摊销测算（K7-4）。
3. **确认时点核查**：政府补助应在实际收到或有确凿证据表明能够收到且满足条件时确认，重点核查是否存在无批文/未到账即提前确认递延收益。
4. **检查比例达标**：检查比例=已检查金额÷本期发生额，须达到计划水平；贷方新增补助与借方摊销转出分别计算检查比例。
5. **异常标注充分**：金额异常（到账金额≠入账金额）、时间异常（期末突击确认）、依据异常（批文缺失或用途不符）、对手方异常（非政府主体拨款挂补助）须标注异常类型及初步判断。
6. **闭环**：K7-5 抽样结果 ↔ K7-2 明细逐笔 ↔ K7-4 摊销测算 ↔ 批文/银行到账凭证；异常发现推送 K7-3 调整及 A13 错报汇总。

## checklist

### 一、样本选取合理性（高风险）

- [ ] 样本选取方法是否与递延收益重大错报风险相匹配
- [ ] 大额补助、新增补助是否纳入必选样本全覆盖
- [ ] 抽样方法是否符合 CAS1314 要求（统计/非统计选择有据）
- [ ] 抽样总体是否完整（从完整补助台账导出，未人为排除）
- [ ] 【风险检查】是否存在仅抽查有批文项目而遗漏可疑挂账

### 二、凭证核对完整性（高风险）

- [ ] 每笔样本是否有政府批文/补助协议（文号、金额、用途）
- [ ] 到账凭证（银行回单）日期、金额、付款方是否与入账一致
- [ ] 记账凭证确认时点、科目、金额是否恰当
- [ ] 摊销凭证是否与 K7-4 摊销测算表一致
- [ ] 确认时点是否恰当（收到/满足条件时确认，无提前确认）
- [ ] 【风险检查】是否存在无批文/未到账即确认递延收益

### 三、检查比例与异常标注（中风险）

- [ ] 检查比例（已检查金额÷本期发生额）是否达到计划水平
- [ ] 贷方新增补助与借方摊销转出检查比例是否分别达标
- [ ] 异常交易是否全部标注异常类型及初步判断
- [ ] 到账金额与入账金额差异是否逐笔追踪解释
- [ ] 【条件检查：若有非政府主体拨款】是否核查其补助性质真实性
- [ ] 抽样参数、选取过程、核对结果记录是否完整可追溯

## risk_areas

### 高风险

1. **无依据提前确认**：无政府批文或资金未到账即确认递延收益，虚增负债或提前/延迟影响损益。
2. **到账与入账不符**：银行到账金额与递延收益入账金额不一致，存在截留、错记或虚假补助。
3. **样本选取偏差**：仅抽查有批文的规范项目，遗漏可疑挂账或大额补助，样本不具代表性。
4. **摊销凭证与测算不符**：本期摊销转出凭证金额与 K7-4 测算表不一致，摊销损益失真。

### 中风险

1. **检查比例不足**：实际检查比例低于计划水平，审计证据不充分。
2. **确认时点核查不到位**：未针对期末临近确认的补助实施截止性核查。
3. **异常标注不充分**：金额/时间/依据异常未标注异常类型，影响后续调整评估。

### 低风险

1. **记录不完整**：抽样参数、核对结果的工作底稿记录不完整。
2. **索引缺失**：与 K7-1/K7-2/K7-4 及批文凭证的交叉索引不完整。
