# K1-1 其他应收款审定表复核提示词

## 概述

本提示词针对其他应收款审定表（K1-1，科目 1221 其他应收款 + 1231 坏账准备，资产类取期末余额）的复核。其他应收款核算备用金、押金保证金、关联方往来、代垫款等。聚焦：期初期末勾稽、试算表核对、坏账准备计提充分性、关联方资金占用与长期挂账。核心风险为关联方非经营性占款、长期挂账未减值、以其他应收款隐匿资金体外循环。

**法规依据：**
- 《企业会计准则第22号——金融工具确认和计量》（预期信用损失）
- 《企业会计准则第36号——关联方披露》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **资产类取"期末余额"**：审定数=期初余额+本期借方−本期贷方±调整；1221 应收与 1231 坏账准备分区核对，坏账准备为贷方备抵。
2. **期初期末勾稽**：期初审定数=上年期末审定数；审定合计（净额）应与明细表 K1-2 期末余额小计（K1-2-end-subtotal）一致。
3. **试算表核对**：1221 审定余额、1231 坏账准备审定余额分别与试算表对应科目一致，方向正确。
4. **坏账计提充分性**：其他应收款同样适用预期信用损失，长期挂账、关联方欠款须评估可收回性并足额计提。
5. **关联方资金占用是重灾区**：大额非经营性关联方往来、股东/高管借款须重点核查性质、审批、是否变相分红或资金占用。
6. **跨底稿闭环**：审定合计↔K1-2 明细↔试算表 1221/1231↔坏账计提测算↔附注；关联方往来↔B19 关联方清单。

## checklist

### 一、期初期末勾稽与试算表核对

- [ ] 期初审定数是否等于上年期末审定数
- [ ] 审定数=期初+本期借方−本期贷方±调整 是否正确
- [ ] 应收净额（1221−1231）审定数是否与明细表 K1-2 期末小计一致
- [ ] 1221 审定余额是否与试算表 1221 一致
- [ ] 1231 坏账准备审定余额是否与试算表 1231 一致（贷方方向）

### 二、坏账准备与可收回性

- [ ] 坏账准备计提方法（单项/组合）是否与政策一致
- [ ] 长期挂账、关联方欠款是否评估可收回性并足额计提
- [ ] 本期计提/转回/核销是否有依据，是否与信用减值损失勾稽
- [ ] 账龄划分是否正确，长账龄项目是否重点关注

### 三、关联方与性质核查

- [ ] 关联方其他应收款是否单独识别，与 B19 关联方清单核对
- [ ] 大额非经营性往来（股东/高管借款）性质、审批是否合规
- [ ] 是否存在以其他应收款科目隐匿资金占用/体外循环
- [ ] 备用金、押金保证金长期挂账是否清理

### 四、审计调整完整性

- [ ] 已确认的账项/重分类调整是否完整反映
- [ ] 一年以上大额其他应收款是否评估重分类至非流动
- [ ] 调整分录借贷平衡、证据充分、经审批

## risk_areas

### 高风险

1. **关联方资金占用**：大额非经营性关联方/股东占款，可能构成资金占用或变相分红。
2. **长期挂账未减值**：长账龄其他应收款可收回性存疑却未足额计提坏账。
3. **期初期末不勾稽 / 与试算表不一致**：审定数失去基准或存在汇总错误。
4. **隐匿资金体外循环**：以其他应收款科目掩盖虚假往来。

### 中风险

1. **坏账计提不足**：组合/单项计提比例与实际回收经验不符。
2. **关联方未识别**：其他应收款中关联方往来未单独列示。
3. **审计调整遗漏**：已确认调整未纳入审定表。

### 低风险

1. **格式与索引不规范**。
2. **明细项目说明不足**。
