# K1-11 其他应收款关联方检查复核提示词

## 概述

本提示词针对其他应收款关联方及交易检查表（K1-11）的复核，聚焦：关联方识别完整性、非经营性资金占用认定、占用费/定价公允性、关联方款项减值与披露。其他应收款是关联方资金占用的高发科目，控股股东及关联方常以往来款名义占用上市公司/被审计单位资金。本检查须与 B19 关联方清单核对，识别占款、评估占用费、判断非经营性占用，为披露和减值提供依据。

**法规依据：**
- 《企业会计准则第36号——关联方披露》
- 《企业会计准则第22号——金融工具确认和计量》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **关联方识别须完整并与 B19 核对**：其他应收款中的关联方对象须逐笔识别，与 B19 关联方清单双向核对（清单有而明细未标 / 明细疑似关联方而清单未列），遗漏将导致占款和披露不完整。
2. **非经营性资金占用是核心风险**：须区分经营性往来（代垫、押金）与非经营性占用（无商业实质的资金拆借），非经营性占用是监管重点（上市公司须专项披露并限期清偿）。
3. **占用费/定价公允性须评估**：关联方资金占用是否收取合理占用费（利息），定价是否公允，无偿占用或低息占用可能构成利益输送。
4. **关联方款项减值不得因关联关系豁免**：关联方长期占款的可收回性须客观评估，不能仅因关联关系或母公司背景默认可全额收回而豁免减值（K1-7/K1-8）。
5. **交易实质须穿透**：关联方往来的形成背景、资金去向、还款安排须穿透核查，警惕通过其他应收款变相向关联方输送资金或转移利润。
6. **披露完整性支撑附注**：关联方名称、关系、期末余额、占用费、非经营性占用情况须完整，支撑附注关联方披露（CAS36）和上市公司资金占用专项说明。

## checklist

### 一、识别完整性

- [ ] 其他应收款关联方对象是否逐笔识别
- [ ] 是否与 B19 关联方清单双向核对（漏标/疑似）
- [ ] 关联关系类型是否明确（控股股东/子公司/共同控制等）
- [ ] 关联方款项是否来自 K1-2 明细表且金额一致

### 二、占用性质与定价

- [ ] 是否区分经营性往来与非经营性资金占用
- [ ] 非经营性占用是否单独识别（上市公司须专项关注）
- [ ] 资金占用是否收取合理占用费/利息
- [ ] 占用费定价是否公允，无偿/低息占用是否评估利益输送

### 三、减值与披露

- [ ] 关联方长期占款可收回性是否客观评估（未因关联关系豁免减值）
- [ ] 关联方款项是否纳入 K1-7 阶段划分和 K1-8 减值测算
- [ ] 交易实质（资金去向/还款安排）是否穿透核查
- [ ] 关联方披露要素（名称/关系/余额/占用费）是否完整支撑附注

## risk_areas

### 高风险

1. **非经营性占款未识别或未披露**：控股股东/关联方资金占用未识别或未按监管要求专项披露（上市公司重大合规风险）。
2. **无偿占用利益输送**：关联方无偿或低息占用资金，损害被审计单位利益。
3. **关联方款项豁免减值**：因关联关系默认全额可收回，未客观评估减值。

### 中风险

1. **关联方识别遗漏**：部分关联方对象未标注，占款和披露不完整。
2. **占用费定价不公允未评估**：占用费收取标准与市场利率背离未分析。

### 低风险

1. **交易实质说明不足**：关联方往来背景和资金去向记录简略。
2. **披露要素不完整**：关联方披露的关系类型或占用费信息缺失。
