# K6-7 不再满足持有待售检查复核提示词

## 概述

本提示词针对不再满足持有待售条件检查底稿（K6-7，科目 1481/2605）的复核。当非流动资产（或处置组）不再满足持有待售分类条件（如出售计划撤销、超过一年且不符合例外条件、买方违约等）时，须停止持有待售分类并重新计量、重新分类回原类别。复核聚焦：不再满足条件的识别、重新计量金额的确定、补提持有待售期间应计提而未计提的折旧摊销、以及重分类对当期损益的影响。核心风险为该转出未转出（继续隐匿于持有待售规避折旧）、重新计量金额错误、以及补提折旧遗漏。

**法规依据：**
- 《企业会计准则第42号——持有待售的非流动资产、处置组和终止经营》
- 《企业会计准则第4号——固定资产》
- 《中国注册会计师审计准则第1301号——审计证据》

## tips

1. **不再满足条件须及时停止分类**：出售计划撤销、超过一年未完成且不符合例外情形、买方违约、市场条件变化导致出售不再极可能等情形出现时，应立即停止持有待售分类，须核对是否存在应转出而未转出的情形。
2. **重新计量金额取孰低**：停止持有待售分类的资产，按（1）划分持有待售前的账面价值调整持有待售期间应计提的折旧/摊销/减值后的金额，与（2）决定不再出售之日的可收回金额，两者孰低计量。
3. **补提持有待售期间的折旧摊销是关键**：持有待售期间停止计提的折旧/摊销，在转出时须补提（视同从未划分持有待售正常计提），补提折旧计入当期损益，遗漏补提将高估资产、少计费用。
4. **重分类回原资产类别**：转出的资产应重新分类回原类别（固定资产/无形资产/长期股权投资等），负债转回相应类别，会计科目由 1481/2605 转回原科目。
5. **重新计量差额计入当期损益**：因重新计量产生的资产账面价值调整（含补提折旧和可收回金额孰低差异）计入继续经营的当期损益，须评估对损益的影响是否恰当反映。
6. **警惕"该转不转"规避折旧**：管理层可能将实际已放弃出售的资产继续挂账持有待售以规避折旧计提、虚增资产/利润，须结合出售进展、市场情况、后续处置计划审慎判断是否仍满足条件。

## checklist

### 一、不再满足条件的识别（高风险）

- [ ] 【必检】是否评估各持有待售项目在期末是否仍满足 CAS42 分类条件
- [ ] 【必检】是否存在出售计划撤销、买方违约、市场变化等不再满足条件的情形
- [ ] 【必检】超过一年未完成的是否重新评估例外条件，不符合的是否转出
- [ ] 【必检】是否存在应停止分类而未停止（继续挂账持有待售）的情形
- [ ] 【风险检查】是否存在"该转不转"以规避折旧、虚增资产/利润

### 二、重新计量与补提折旧（高风险）

- [ ] 【必检】转出资产是否按孰低计量（调整后账面价值 vs 决定不再出售日可收回金额）
- [ ] 【必检】是否补提持有待售期间停止计提的折旧/摊销
- [ ] 【必检】补提折旧计算是否正确（视同正常计提，按剩余年限/方法）
- [ ] 【必检】补提折旧是否计入当期损益
- [ ] 【风险检查】是否遗漏补提折旧导致高估资产、少计费用

### 三、重分类与损益影响（中风险）

- [ ] 【必检】转出资产是否重新分类回原类别（1481→原资产科目）
- [ ] 【必检】相关负债是否转回相应类别（2605→原负债科目）
- [ ] 【必检】重新计量差额是否计入继续经营的当期损益
- [ ] 【必检】转出处理是否与 K6-3 调整分录、K6-2 明细勾稽
- [ ] 【条件检查：若为处置组部分转出】剩余处置组是否重新评估分类和计量
- [ ] 【风险检查】重新计量差额是否被错误计入其他综合收益或递延

## risk_areas

### 高风险

1. **该转出未转出规避折旧**：实际已不满足持有待售条件（出售计划撤销/长期未完成）的资产继续挂账持有待售，规避折旧计提、虚增资产和利润。
2. **补提折旧遗漏**：转出持有待售时未补提持有待售期间停止计提的折旧/摊销，高估资产、少计当期费用。
3. **重新计量金额错误**：未按调整后账面价值与可收回金额孰低计量，重新计量金额不正确。

### 中风险

1. **重分类科目错误**：转出资产未正确重新分类回原类别，或负债转回科目错误。
2. **重新计量差额处理不当**：差额未计入当期损益，或错误计入其他综合收益/递延。
3. **超一年例外条件评估不足**：对超过一年未完成的持有待售项目未审慎评估是否仍符合例外情形。

### 低风险

1. **格式与索引不规范**：条件评估记录、重新计量测算、交叉索引标注不完整。
2. **转出原因说明不足**：不再满足条件的具体原因和后续处置安排说明不充分。
