# K5-5 弃置费用检查复核提示词

## 概述

本提示词针对预计负债项下弃置费用检查底稿（K5-5，科目 2701）的复核。弃置费用指企业因固定资产（如油气设施、核电站、矿山、部分环保设备等）弃置义务而应承担的未来支出，须在资产达到预定可使用状态时按现值确认预计负债并计入资产成本（CAS4）。复核聚焦：弃置义务的确认、未来弃置支出的现值折现、后续期间的利息费用摊销与折现率复核。核心风险为弃置义务应确认未确认、折现率选取不当（影响现值和后续利息）、以及未来弃置支出估计缺乏依据。

**法规依据：**
- 《企业会计准则第4号——固定资产》
- 《企业会计准则第13号——或有事项》
- 《中国注册会计师审计准则第1301号——审计证据》

## tips

1. **弃置义务的确认时点是资产达到预定可使用状态**：符合弃置义务的固定资产在初始确认时，应按弃置费用的现值确认预计负债，同时计入相关资产成本（CAS4 特殊计量），后续通过折旧和利息费用分摊。
2. **未来弃置支出须为最佳估计并有依据**：弃置支出金额应基于法律法规、行业惯例、专业机构评估或类似弃置项目经验，须核对估计的支持性证据，防止低估或高估。
3. **折现是弃置费用计量的核心**：弃置义务通常在远期发生，须按反映货币时间价值和特定负债风险的折现率折现至现值确认，折现率选取直接影响初始确认金额和后续利息费用。
4. **后续利息费用（折现摊销）须复核**：每期按期初预计负债余额×折现率确认利息费用（财务费用），使预计负债余额逐期增至弃置日的名义金额，须验证摊销计算的正确性。
5. **区分弃置费用与一般修理/环保支出**：日常维护、常规环保治理支出不属于弃置义务，不应确认弃置预计负债；仅法定或推定的资产报废清理/复原义务方可确认。
6. **估计变更须追溯调整**：弃置支出金额或折现率发生变化时，应按 CAS4/CAS13 相关规定调整预计负债及对应资产账面价值，须评估变更处理是否恰当。

## checklist

### 一、弃置义务确认（高风险）

- [ ] 【必检】是否识别所有存在法定或推定弃置义务的固定资产（油气/矿山/核电/环保设施等）
- [ ] 【必检】弃置义务是否满足 CAS13 确认条件（现时义务+很可能+可靠计量）
- [ ] 【必检】弃置预计负债是否在资产达到预定可使用状态时按现值确认
- [ ] 【必检】弃置费用现值是否同时计入相关固定资产成本（CAS4）
- [ ] 【必检】是否区分弃置义务与日常维护/常规环保支出（后者不计提）
- [ ] 【风险检查】是否存在应确认弃置义务的资产未计提弃置预计负债

### 二、未来支出估计与折现（高风险）

- [ ] 【必检】未来弃置支出金额是否为最佳估计，有法规/评估/经验支撑
- [ ] 【必检】折现率是否反映货币时间价值和该项负债的特定风险
- [ ] 【必检】现值计算（未来支出÷(1+折现率)^n）是否正确
- [ ] 【必检】折现率选取是否与弃置期限、风险特征匹配且前后一致
- [ ] 【风险检查】是否存在通过调高折现率或低估未来支出以少计负债

### 三、后续利息摊销与估计变更（中风险）

- [ ] 【必检】本期利息费用是否=期初弃置预计负债余额×折现率，计算正确
- [ ] 【必检】利息费用（折现摊销）是否计入财务费用
- [ ] 【必检】期末弃置预计负债余额是否逐期增至弃置日名义金额的合理路径上
- [ ] 【条件检查：若弃置支出或折现率变更】估计变更是否按准则追溯调整预计负债及资产账面价值
- [ ] 【风险检查】估计变更是否被用于调节当期损益

## risk_areas

### 高风险

1. **弃置义务应确认未确认**：存在法定/推定弃置义务的资产（矿山、油气、核电等）未计提弃置预计负债，少计负债并低估资产成本。
2. **折现率选取不当**：折现率过高低估初始确认金额和负债余额，或前后期不一致，直接影响现值和后续利息费用。
3. **未来弃置支出估计缺乏依据**：弃置支出金额为主观估计，无法规、专业评估或历史经验支撑。

### 中风险

1. **利息费用摊销计算错误**：后续期间折现摊销（利息费用）计算或计入科目错误。
2. **估计变更处理不当**：弃置支出或折现率变更未按准则追溯调整，或被用于调节损益。
3. **弃置义务与日常支出混淆**：将常规维护/环保治理支出错误计提为弃置预计负债。

### 低风险

1. **格式与索引不规范**：现值计算过程、折现参数、交叉索引标注不完整。
2. **弃置项目说明不足**：未逐项说明弃置义务来源、预计弃置时间及依据。
