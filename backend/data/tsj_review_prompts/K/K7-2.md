# K7-2 递延收益明细表复核提示词

## 概述

本提示词针对递延收益明细表（K7-2，科目 2401，负债类取期末余额）的复核，聚焦政府补助台账逐笔明细的质量。明细表按补助项目维度记录批文文号、到账日期、总额、与资产相关/与收益相关分类、累计已摊销、本期摊销、期末余额，是审定表 K7-1 的数据来源和摊销测算表 K7-4 的输入。其数据准确性直接影响递延收益期末余额、其他收益（K10）结转金额及附注披露的完整性。核心风险为分类错误、批文依据缺失、摊销口径与资产寿命不匹配。

**法规依据：**
- 《企业会计准则第16号——政府补助》
- 《企业会计准则第30号——财务报表列报》
- 《中国注册会计师审计准则第1301号——审计证据》

## tips

1. **补助台账完整性是明细表基石**：每笔递延收益必须对应政府批文/协议及到账凭证，无批文依据的挂账应追查是否虚增负债或掩盖其他往来。
2. **与资产相关 vs 与收益相关分类决定摊销路径**：与资产相关补助随资产使用寿命系统分摊、计入其他收益或冲减资产；与收益相关且用于补偿以后期间的分期确认，分类错误将导致摊销期间和列报口径失真。
3. **明细合计必须与审定表 K7-1 勾稽**：明细表期末余额合计=K7-1 审定合计（K7-2-detail-end-total），期初余额合计=上年期末审定数，任何差异需追溯至具体调整。
4. **摊销口径须与批文用途一致**：本期摊销=总额÷摊销期限（或按受益进度），摊销期限应与相关资产折旧年限或补偿期间一致，不得人为拉长/缩短调节利润。
5. **明细表是多项后续程序的数据源**：K7-4 分摊测算、K10 其他收益结转勾稽、附注政府补助明细披露均以本表为基础，明细错误将沿数据链传导。
6. **双向勾稽**：期末余额=总额−累计已摊销；各项目期末余额之和=K7-1 审定合计=试算表 2401 审定余额；本期摊销之和=K10 本期结转其他收益的政府补助额。

## checklist

### 一、补助台账完整性（高风险）

- [ ] 每笔递延收益是否对应政府批文/补助协议文号及到账凭证
- [ ] 补助项目名称、批准部门、到账日期、金额是否完整规范
- [ ] 是否存在无批文依据或依据不充分的挂账
- [ ] 补助资金是否实际到账，与银行流水/货币资金勾稽
- [ ] 【条件检查：若有跨年度补助】跨年度补助的分期到账是否逐笔记录
- [ ] 【风险检查】是否存在将非补助性往来款项挂递延收益的情况

### 二、分类与计量准确性（高风险）

- [ ] 与资产相关/与收益相关分类是否与批文用途一致
- [ ] 总额法/净额法核算选择是否恰当且前后一致
- [ ] 累计已摊销、本期摊销、期末余额计算是否正确（期末=总额−累计摊销）
- [ ] 与资产相关补助摊销期限是否与相关资产折旧年限一致
- [ ] 与收益相关补助是否区分应递延 vs 应直接计入当期
- [ ] 【条件检查：若补助用于购建资产】相关资产是否已达可使用状态、摊销起点是否恰当

### 三、勾稽关系与数据源一致性（高风险）

- [ ] 明细表期末余额合计是否等于审定表 K7-1 审定合计
- [ ] 明细表期初余额是否与上年期末审定数衔接
- [ ] 各项目本期摊销合计是否与 K10 本期结转其他收益的政府补助额一致
- [ ] 明细表数据是否与 K7-4 分摊测算表输入一致
- [ ] 【风险检查】是否存在期末余额异常波动（超30%且无合理解释）
- [ ] 【风险检查】是否存在人为调整摊销以平滑利润的迹象

## risk_areas

### 高风险

1. **分类错误**：与资产相关/与收益相关划分错误，导致摊销期间及计入其他收益/营业外收入的口径失真。
2. **批文依据缺失**：无政府批文或协议依据即确认递延收益，可能虚增负债或掩盖其他往来款项性质。
3. **摊销口径不当**：摊销期限与相关资产寿命或补偿期间不一致，人为拉长/缩短调节各期利润。
4. **明细与审定表不勾稽**：明细合计与 K7-1 审定合计存在无源差异，数据链断裂。

### 中风险

1. **总额法/净额法不一致**：同类补助前后期核算方法不一致，影响可比性。
2. **摊销起点错误**：与资产相关补助在相关资产达到可使用状态前即开始摊销。
3. **累计摊销记录不完整**：跨年度补助的累计已摊销金额未准确滚动结转。

### 低风险

1. **格式与索引不规范**：明细表项目排列、单位、交叉索引不统一。
2. **补助项目说明不足**：补助用途、附加条件等辅助说明缺失。
