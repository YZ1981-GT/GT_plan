# K12-note-listed 营业外收入附注披露复核提示词（上市公司）

## 概述

本提示词针对营业外收入上市公司附注披露底稿（K12-note-listed，科目 6301，损益类）的复核。聚焦利润表"营业外收入"项目的附注分项披露：按利得性质（与日常活动无关的政府补助、非流动资产处置利得、盘盈利得、捐赠利得、罚款收入、无法支付款项转入等）列示本期发生额，政府补助须与日常活动无关性说明，非经常性损益金额须单独披露，并与审定表 K12-1、利润表勾稽。上市公司披露受证监会编报规则及非经常性损益披露规则约束。

**法规依据：**
- 《企业会计准则第16号——政府补助》
- 《企业会计准则第30号——财务报表列报》
- 《公开发行证券的公司信息披露编报规则第9号——非经常性损益》
- 《公开发行证券的公司信息披露编报规则第15号——财务报告的一般规定》

## tips

1. **按利得性质分项披露本期发生额**：附注须完整列示营业外收入各利得项目本期金额，各分项合计=利润表营业外收入行=审定表 K12-1 审定合计。
2. **政府补助须披露与日常活动无关性**：计入营业外收入的政府补助须说明其与企业日常活动无关（否则应计其他收益 K10），并按 CAS16 披露补助项目、金额、性质及是否影响损益。
3. **非经常性损益单独披露**：营业外收入项目多属非经常性损益，须在非经常性损益明细表中单独列示各项金额，且与营业外收入附注勾稽，供计算扣非归母净利润。
4. **重大利得须披露性质与依据**：金额重大的无法支付款项转入、非流动资产处置利得、罚款收入等须披露形成原因与依据。
5. **计入损益的政府补助与递延收益勾稽**：本期计入营业外收入的政府补助须与递延收益（K7）的本期转入营业外收入金额勾稽。
6. **附注数据闭环勾稽**：附注分项本期发生额=K12-2 明细表分项净发生额=利润表营业外收入行=审定表 K12-1 审定合计；非经常性损益金额与非经常性损益明细表勾稽。

## checklist

### 一、分项披露完整性

- [ ] 营业外收入是否按利得性质完整分项列示本期发生额
- [ ] 各分项本期发生额合计是否等于利润表"营业外收入"行金额
- [ ] 各分项合计是否与审定表 K12-1 审定合计一致
- [ ] 是否同时披露本期数与上期可比数
- [ ] 各分项是否与 K12-2 明细表对应项目勾稽
- [ ] 重大利得项目是否披露形成原因及依据

### 二、政府补助披露

- [ ] 计入营业外收入的政府补助是否披露与日常活动无关性
- [ ] 政府补助是否按 CAS16 披露项目、金额、性质
- [ ] 计入营业外收入的政府补助是否与递延收益（K7）转入金额勾稽
- [ ] 政府补助计入营业外收入而非其他收益（K10）的判断依据是否披露
- [ ] 是否披露与资产相关/与收益相关补助的分类

### 三、非经常性损益披露

- [ ] 营业外收入中属非经常性损益的项目是否单独列示
- [ ] 非经常性损益金额是否与营业外收入附注勾稽
- [ ] 非经常性损益金额是否用于计算扣非归母净利润
- [ ] 非经常性损益列示是否符合证监会第9号编报规则口径
- [ ] 是否披露非经常性损益的所得税影响

### 四、重大利得与勾稽

- [ ] 无法支付款项转入重大金额是否披露形成原因
- [ ] 非流动资产处置利得是否与相关资产处置底稿勾稽
- [ ] 罚款收入、捐赠利得重大金额是否披露性质
- [ ] 营业外收入总额是否与利润表及审定表勾稽

## risk_areas

### 高风险

1. **分项合计与利润表/审定表不勾稽**：附注营业外收入分项之和与利润表营业外收入行或 K12-1 审定合计不一致。
2. **政府补助无关性未披露**：计入营业外收入的政府补助未说明与日常活动无关，或本应计其他收益却计营业外收入未披露判断依据。
3. **非经常性损益披露缺失或不勾稽**：营业外收入未在非经常性损益明细表单独列示，或两者金额不一致，影响扣非利润计算。

### 中风险

1. **重大利得原因未披露**：大额无法支付款项转入、非流动资产处置利得未披露形成原因与依据。
2. **可比信息缺失**：仅披露本期发生额未列示上期可比数据。
3. **政府补助与递延收益不勾稽**：计入营业外收入的补助与 K7 递延收益转入金额不一致。

### 低风险

1. **披露格式不规范**：分项排列顺序、金额单位等格式细节未严格按编报规则。
2. **利得性质说明模板化**：利得性质描述过于笼统，未结合本企业实际。
