# K5-1 预计负债审定表复核提示词

## 概述

本提示词针对预计负债审定表（K5-1，科目 2701，负债类取期末余额）的复核。预计负债核算或有事项形成的现时义务：产品质量保证、未决诉讼、亏损性合同、重组义务、退货义务、担保等。聚焦：期初期末勾稽、试算表核对、CAS13 确认条件（现时义务+很可能+可靠计量）、最佳估计与折现、完整性。核心风险为应确认未确认（少计负债）或确认条件不满足（多计负债调节利润）。

**法规依据：**
- 《企业会计准则第13号——或有事项》
- 《企业会计准则第30号——财务报表列报》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **负债类取"期末余额"**：审定数=期初+本期计提−本期使用/转回±调整。
2. **期初期末勾稽**：期初审定数=上年期末审定数；审定合计=明细表 K5-2 期末合计（K5-2-detail-end-total）。
3. **试算表核对**：审定合计与试算表 2701 审定余额一致（贷方方向）。
4. **CAS13 三条件**：每项预计负债须同时满足"现时义务、很可能导致经济利益流出、金额能可靠计量"，缺一不应确认；反之满足却未确认即少计负债。
5. **最佳估计与折现**：金额为履行义务所需支出的最佳估计（存在区间取中值/期望值）；影响重大且时间价值显著的应折现。
6. **完整性（首要风险）**：产品质保、未决诉讼、亏损合同易被隐瞒或低估，须结合律师函（A 循环）、合同、历史赔付率评估。

## checklist

### 一、期初期末勾稽与试算表核对

- [ ] 期初审定数是否等于上年期末审定数
- [ ] 审定数=期初+计提−使用/转回±调整 是否正确
- [ ] 审定合计是否与明细表 K5-2 期末合计一致
- [ ] 审定合计是否与试算表 2701 审定余额一致（贷方方向）

### 二、确认条件与计量

- [ ] 每项预计负债是否同时满足 CAS13 三个确认条件
- [ ] 金额是否为最佳估计（区间取中值/期望值、有测算依据）
- [ ] 影响重大的长期预计负债是否折现，折现率是否合理
- [ ] 产品质量保证是否按历史赔付率合理计提
- [ ] 未决诉讼是否结合律师函评估结果，与 A 循环勾稽

### 三、完整性与或有事项

- [ ] 是否搜寻未确认的现时义务（合同、诉讼、担保、重组）
- [ ] 很可能但金额不能可靠计量的、或可能义务是否作或有负债披露
- [ ] 是否存在多计预计负债以在以后期间转回调节利润
- [ ] 本期使用/转回是否有依据

### 四、审计调整完整性

- [ ] 已确认的账项/重分类调整是否完整反映
- [ ] 一年内预计使用部分是否重分类考虑
- [ ] 调整分录借贷平衡、证据充分、经审批

## risk_areas

### 高风险

1. **应确认未确认**：满足 CAS13 条件的义务（质保、败诉可能大的诉讼、亏损合同）未计提，少计负债、虚增利润。
2. **多计/滥计预计负债**：不满足确认条件仍计提，或超额计提"利润蓄水池"，以后期间转回调节利润。
3. **期初期末不勾稽 / 与试算表不一致**。

### 中风险

1. **最佳估计缺乏依据**：计提金额无测算/历史数据支持。
2. **折现处理不当**：长期预计负债未折现或折现率不合理。
3. **或有事项披露不足**：应披露的或有负债未在附注披露。
4. **审计调整遗漏**。

### 低风险

1. **格式与索引不规范**。
2. **项目说明不足**。
