# K3-5 其他应付款长期挂账检查复核提示词

## 概述

本提示词针对其他应付款长期挂账检查表（K3-5，科目 2241）的复核，聚焦：长期挂账识别完整性、是否无需支付的判断、转营业外收入的依据与时点、挂账原因合理性。长期挂账的其他应付款（尤其 3 年以上）可能已无需支付（债权人放弃、超过诉讼时效、无法联系），须评估是否应转销为营业外收入。长期挂而不转将虚增负债、延迟确认收益，是负债类科目的重点检查。

**法规依据：**
- 《企业会计准则第16号——政府补助》（涉及无需支付款项确认）
- 《企业会计准则第30号——财务报表列报》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **长期挂账识别须完整**：从 K3-2 明细表按账龄筛出全部长期挂账款项（通常 3 年以上，含 1-3 年重点项目），不得遗漏，识别口径与账龄起算日须一致。
2. **是否"无需支付"是核心判断**：长期挂账须逐笔判断是否仍存在支付义务——债权人是否放弃、是否超过诉讼时效（一般 3 年）、债权人是否注销/失联，无需支付的应转营业外收入。
3. **转营业外收入的依据须充分**：确认无需支付而转销须有客观依据（债权人书面放弃、注销证明、超时效说明），无据转销（虚增利润）或应转不转（虚增负债）均属错报。
4. **转销时点须准确**：无需支付的义务应在确认无需支付的当期转销，跨期转销将导致损益期间错配。
5. **挂账原因须查明**：长期挂账反映款项清理不及时或内控缺陷（押金保证金未清退、暂收款未处理），须查明原因并评价内控。
6. **与 K3-2/K3-3 联动**：长期挂账对象来自 K3-2 明细，确认应转销的须通过 K3-3 调整（借其他应付款贷营业外收入），检查与调整须闭环。

## checklist

### 一、识别完整性

- [ ] 长期挂账款项是否从 K3-2 明细表按账龄完整筛出（3年以上/1-3年重点）
- [ ] 识别口径与账龄起算日是否与明细表一致
- [ ] 各类长期挂账（押金/暂收/往来）是否分类列示
- [ ] 是否遗漏应纳入的长期挂账对象

### 二、无需支付判断

- [ ] 每笔长期挂账是否判断仍存在支付义务
- [ ] 是否评估债权人放弃/超诉讼时效/注销失联
- [ ] 无需支付的判断是否有客观依据
- [ ] 押金保证金长期未清退原因是否合理

### 三、转销与调整

- [ ] 确认无需支付的款项是否有充分转销依据
- [ ] 转销时点是否准确（确认无需支付的当期）
- [ ] 应转销款项是否通过 K3-3 调整（借2241贷营业外收入）
- [ ] 挂账原因是否查明并评价内控缺陷

## risk_areas

### 高风险

1. **应转未转虚增负债**：长期挂账已无需支付但仍列报为负债，虚增负债、延迟确认收益。
2. **无据转销虚增利润**：缺乏无需支付客观依据即转营业外收入，虚增利润。
3. **转销时点错配**：无需支付义务未在确认当期转销，损益期间错配。

### 中风险

1. **识别不完整**：部分长期挂账对象未筛出，长期挂账检查覆盖不足。
2. **无需支付判断不充分**：仅凭账龄长判断无需支付，未核查诉讼时效和债权人状态。

### 低风险

1. **挂账原因查明不深**：仅记录账龄未查明长期挂账根本原因。
2. **交叉索引不完整**：与 K3-2/K3-3 的引用标注不全。
