# K12-1 营业外收入审定表复核提示词

## 概述

本提示词针对营业外收入审定表（K12-1，科目 6301，损益类贷方，取本期发生额）的复核。营业外收入核算与日常活动无关的利得：与日常活动无关的政府补助、捐赠利得、盘盈利得、罚款收入、无法支付款项转入等。聚焦：发生额勾稽、计入科目正确性（营业外收入 vs 其他收益）、非经常性损益列报、完整性与截止。

**法规依据：**
- 《企业会计准则第16号——政府补助》
- 《企业会计准则第30号——财务报表列报》
- 《中国注册会计师审计准则第1301号——审计证据》
- 《中国注册会计师审计准则第1141号——与舞弊相关的责任》

---

## tips

1. **取"发生额"非"余额"**：审定数按 6301 本期贷方发生额−借方±调整。
2. **发生额勾稽**：审定合计=未审+AJE+RJE，且=明细表 K12-2 审定合计。
3. **计入科目判断**：与日常活动无关的利得计营业外收入；与日常活动相关的补助应计其他收益（K10）——错计将影响列报与扣非利润。
4. **完整性与真实性**：无法支付款项转入、盘盈等易被用于跨期调节利润，须核对依据（如债权人放弃、盘点记录）。
5. **非经常性损益**：营业外收入通常属非经常性损益，须正确标识供上市公司扣非披露。
6. **跨底稿闭环**：审定合计↔K12-2↔试算表 6301↔利润表"营业外收入"行。

## checklist

### 一、发生额勾稽与试算表核对

- [ ] 审定表各项目审定数=未审+AJE+RJE 是否正确
- [ ] 审定合计是否与明细表 K12-2 审定合计一致
- [ ] 审定合计是否与试算平衡表 6301 审定发生额一致
- [ ] 未审发生额是否与试算表 6301 一致
- [ ] 上期审定数是否与上年底稿一致

### 二、计入科目与非经常性损益

- [ ] 各项利得计入营业外收入是否确与日常活动无关（否则应计其他收益 K10）
- [ ] 政府补助分类（营业外收入 vs 其他收益）是否正确
- [ ] 非经常性损益标识是否正确、金额是否准确（供扣非披露）
- [ ] 无法支付款项转入是否有债权人放弃/超诉讼时效等充分依据

### 三、审计调整与完整性

- [ ] 已确认的账项/重分类调整是否完整反映
- [ ] 盘盈、罚款收入、捐赠利得是否有支持性证据
- [ ] 资产负债表日前后利得是否记入恰当期间（截止）
- [ ] 是否存在跨期确认利得以调节当期利润

## risk_areas

### 高风险

1. **分类错误**：与日常活动相关的补助错计营业外收入，或反之，扭曲营业利润与扣非利润。
2. **跨期调节利润**：将无法支付款项转入、盘盈等在特定期间集中确认以调节利润。
3. **审定表与试算表不勾稽**：发生额口径不一致。

### 中风险

1. **依据不充分**：无法支付款项转入、捐赠利得缺乏充分证据。
2. **非经常性损益标识错误**：影响上市公司扣非利润披露。
3. **审计调整遗漏**：已确认调整未纳入审定表。

### 低风险

1. **格式与索引不规范**。
2. **利得项目说明不足**。
