# K5-3 预计负债调整分录复核提示词

## 适用底稿
预计负债调整分录汇总表（K5-3），含账项调整（AJE）、重分类调整（RJE）及未调整错报（SUD）评估，是预计负债审定数（K5-1）链路的关键环节。

## 概述

K5-3 承载对预计负债科目（2701）识别出的错报调整。复核须验证：每笔调整有充分证据、借贷平衡、完整反映至审定表 K5-1、SUD 评估符合重要性水平要求。预计负债调整的典型情形包括：补提应确认未确认的现时义务、冲回不满足确认条件的多计负债、将一年内预计使用部分重分类至流动负债、以及诉讼/质保估计变更的调整。

---

## tips

1. **AJE 与 RJE 区分**：AJE 影响预计负债金额及对应损益（如补提质保费用、冲回超额计提）；RJE 仅影响列报（如一年内使用部分重分类），不得通过 RJE 掩盖负债金额错报。
2. **与 K5-1 逐笔勾稽**：审定表调整列金额须与 K5-3 已确认分录逐笔一致，遗漏任一笔即审定数失真。
3. **补提调整须有确认依据**：补提预计负债的调整须满足 CAS13 三条件（现时义务+很可能+可靠计量），并附律师函、合同、历史赔付率等证据。
4. **冲回调整须有解除依据**：冲回多计/滥计预计负债须证明确认条件不再满足或原估计明显不当，防止无依据冲回调节利润。
5. **SUD 累计评估**：未调整的预计负债错报（尤其少计负债）单独及累计是否超过整体/明细层次重要性水平，须与 A13 未调整错报汇总交叉验证。
6. **TB 回写**：确认调整已同步试算平衡表 2701 科目，避免"底稿已调、TB 未更"的双真源不一致。

## checklist

### 一、账项调整（AJE）证据与授权（高风险）

- [ ] 所有 AJE 是否有充分审计证据（律师函、合同、历史赔付率、专家评估）
- [ ] 补提预计负债的调整是否满足 CAS13 三个确认条件
- [ ] 冲回预计负债的调整是否有义务解除或原估计不当的证据
- [ ] AJE 是否经适当层级审批（超重要性水平须合伙人知悉）
- [ ] 每笔调整分录借贷方是否完全平衡
- [ ] 调整金额是否完整反映到 K5-1 审定表对应调整列
- [ ] 是否存在仅为平滑利润或规避业绩考核的不当计提/冲回

### 二、重分类调整（RJE）与SUD（中风险）

- [ ] RJE 是否仅涉及列报（如一年内使用部分重分类至一年内到期的非流动负债）
- [ ] RJE 是否未影响预计负债总额或损益
- [ ] 一年内预计使用/支付部分是否恰当重分类
- [ ] 未调整错报累计是否超过整体重要性水平（须评估并与 A13 勾稽）
- [ ] 跨期调整是否正确区分本期错报与前期差错更正

### 三、记录规范与追溯（低风险）

- [ ] 调整原因说明是否清晰可追溯至具体审计程序或底稿
- [ ] 调整分录编号是否连续，删除后重号风险是否可控
- [ ] 索引是否指向 K5-2 明细、K5-4/5/6 专项检查、K5-7 凭证检查等支持底稿
- [ ] 审计说明/结论是否概括调整性质与剩余（residual）风险

## risk_areas

### 高风险

1. **调整缺乏证据或未经授权**：补提或冲回预计负债的调整无支持性证据或未经适当层级审批。
2. **少计负债错报未调整**：识别出应确认未确认的现时义务但未作调整，SUD 累计超阈值仍出具无保留意见。
3. **审定表与 K5-3 调整金额不一致**：调整未完整反映至 K5-1，或 TB 未同步回写。

### 中风险

1. **RJE 误含负债金额或损益影响**：重分类调整错误影响了预计负债总额或利润。
2. **跨期调整分类错误**：本期错报与前期差错更正混淆，会计处理及披露要求不同。
3. **无依据冲回调节利润**：冲回预计负债缺乏义务解除依据。

### 低风险

1. **编号、格式、索引不规范**：调整分录摘要、科目编码、交叉索引标注不完整。
2. **调整说明过于简略**：未充分说明调整的判断依据和剩余风险。

## 跨底稿勾稽

- K5-3 已确认 AJE/RJE 合计 ↔ K5-1 审定表调整列
- K5-3 SUD ↔ A13 未调整错报汇总
- 调整后审定数 ↔ 试算平衡表 2701 科目
- 补提/冲回依据 ↔ K5-4 质保检查 / K5-5 弃置费用检查 / K5-6 未决诉讼检查
