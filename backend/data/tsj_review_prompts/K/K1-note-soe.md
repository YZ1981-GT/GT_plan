# K1-note-soe 其他应收款附注披露复核提示词（国有企业）

## 概述

本提示词针对其他应收款国有企业附注披露底稿（K1-note-soe）的复核，聚焦：基础分类/账龄/坏账变动披露（与上市版共有）、国有资产监管相关披露、关联方（含同受国有控制单位）资金往来、长期挂账清理与责任追究、决算报表口径一致。国有企业其他应收款审计具双重属性（财务审计+国资监管），须在 CAS 通用披露基础上叠加国资委财务决算和资金占用管理的额外要求。

**法规依据：**
- 《企业会计准则第37号——金融工具列报》
- 《企业会计准则第36号——关联方披露》
- 《企业国有资产法》
- 《中央企业财务决算报告管理办法》

---

## tips

1. **国企附注"双层"披露要求**：既满足 CAS37/CAS36 通用披露（分类/账龄/坏账变动），又满足国资委财务决算与资金占用管理的额外要求，两套要求互补不可替代。
2. **关联方范围扩展至"同受国有控制"单位**：其他应收款关联方除一般定义外须考虑同一国有控股股东控制的兄弟单位间资金往来，可依准则豁免条款简化部分披露但须符合条件。
3. **国有资金被占用须单独披露**：其他国有企业或政府部门以往来款名义长期占用本单位资金须单独说明（占用方/金额/账龄/占用费），防止掩盖国有资产流失。
4. **长期挂账清理与责任追究**：3 年以上长期未收回其他应收款须逐笔披露形成原因、催收措施、清理处置方案；确认损失核销须说明"三重一大"决策程序，无法收回的须启动责任追究。
5. **减值对国有资本保值增值的影响**：长账龄其他应收款减值/核销对国有资本保值增值率的影响须说明，长期挂账累积可能被视为国有资产管理不到位。
6. **决算口径一致**：附注数据须与年度财务决算报表一致，其他应收款中的"不良资产"部分须按决算要求单独披露，与上市版差异主要在国资监管层面而非准则层面。

## checklist

### 一、基础披露完整性（与上市版共有）

- [ ] 是否按款项性质分类披露，合计是否等于审定表 K1-1 审定数
- [ ] 账龄披露是否完整（含3年以上/5年以上）且合计等于总额
- [ ] 坏账准备变动表是否完整并与 K1-3 勾稽
- [ ] 是否同时列示期末与期初可比数
- [ ] 分类/账龄小计是否与 K1-2 明细表勾稽

### 二、国有资产监管披露

- [ ] 3年以上长期未收回款项是否逐笔披露原因及催收措施
- [ ] 其他国企/政府部门资金占用是否单独说明（占用方/金额/账龄/占用费）
- [ ] 是否披露涉及财政性资金的其他应收款
- [ ] 长账龄款项减值/核销对国有资本保值增值率影响是否说明
- [ ] 其他应收款中"不良资产"部分是否按决算要求单独披露

### 三、关联交易与核销程序

- [ ] 与控股股东及关联企业的其他应收款是否逐户列示
- [ ] 与同一母公司控制的其他国企往来是否披露（豁免条款适用是否合规）
- [ ] 大额核销是否说明"三重一大"决策程序
- [ ] 无法收回款项是否启动损失责任追究并披露
- [ ] 附注数据是否与年度财务决算报表一致

## risk_areas

### 高风险

1. **国有资金被占用未披露**：其他国企/政府长期占用资金以往来款挂账未单独说明，掩盖国有资产流失。
2. **关联方范围遗漏**：未将同受国有控制的兄弟单位纳入关联方披露，关联往来信息不完整。
3. **核销缺"三重一大"程序**：大额其他应收款核销未经集体决策或未披露决策过程，重大合规风险。
4. **基础披露与审定表不勾稽**：附注各维度合计与 K1-1 审定数不一致。

### 中风险

1. **长账龄责任追究缺失**：3年以上无法收回款项未说明是否启动责任追究。
2. **豁免条款适用不当**：不符合条件却简化同受国有控制关联方披露。
3. **决算口径差异未调节**：决算数据与审计后附注数据差异未编制调节说明。

### 低风险

1. **披露格式未按决算模板**：与国资委决算报表模板有细微格式差异。
2. **占用费说明简略**：资金占用已披露但占用费计算依据未详述。
3. **交叉索引不完整**：与 K1-1/K1-2/K1-3 及决算报表的勾稽索引不全。
