# K2-5 其他流动资产摊销测算复核提示词

## 概述

本提示词针对其他流动资产摊销测算表（K2-5）的复核，聚焦：摊销方法一致性、摊销期与摊销基数准确性、本期摊销测算勾稽、测算结果与明细/账面比对。摊销测算对待摊费用、合同取得成本等按摊销方法（直线法/进度法）逐项计算本期应摊金额和期末余额，测算结果驱动 K2-3 补摊调整，是费用确认完整性和资产计价准确性的关键。

**法规依据：**
- 《企业会计准则第14号——收入》
- 《中国注册会计师审计准则第1301号——审计证据》
- 《中国注册会计师审计准则第1321号——审计会计估计（含公允价值会计估计）和相关披露》

## tips

1. **摊销方法须与项目性质匹配并一致**：待摊费用通常直线法（按受益期均摊），合同取得成本按商品/服务转让进度摊销，摊销方法须与相关资产性质匹配且前后期一致。
2. **摊销期与摊销基数须准确**：摊销期=受益期/合同期（起始日、到期日、月份数须准确），摊销基数=资本化原值，起始日错误或月份数误算将导致本期摊销失真。
3. **本期摊销测算须逐项勾稽**：本期应摊=摊销基数÷总月份×本期月份数（直线法），期末余额=期初+本期新增−本期摊销，逐项计算须正确，公式列断裂即测算失真。
4. **测算结果与账面已摊比对驱动调整**：本期应摊金额与账面已摊数比对，差异重大须通过 K2-3 补摊/冲回调整，测算与调整须闭环。
5. **期初新增分档与到期结转**：区分期初已在摊项目与本期新增项目分别测算，到期项目须结转完毕（期末余额为零），避免到期未结转虚增资产。
6. **与 K2-2/K2-4 勾稽**：摊销测算项目须来自 K2-2 明细/K2-4 合同取得成本，期末余额须与明细表对应项目一致。

## checklist

### 一、方法与参数

- [ ] 摊销方法是否与项目性质匹配（待摊直线法/合同取得成本按进度）
- [ ] 摊销方法是否前后期一致
- [ ] 摊销期（起始日/到期日/总月份）是否准确
- [ ] 摊销基数（资本化原值）是否正确

### 二、测算勾稽

- [ ] 本期应摊=基数÷总月份×本期月份数，逐项计算是否正确
- [ ] 期末余额=期初+本期新增−本期摊销，勾稽是否成立
- [ ] 期初已摊项目与本期新增项目是否分别测算
- [ ] 到期项目是否结转完毕（期末余额为零）

### 三、结果比对与勾稽

- [ ] 本期应摊金额与账面已摊数差异是否列示
- [ ] 差异重大是否通过 K2-3 补摊/冲回调整
- [ ] 摊销测算项目是否来自 K2-2 明细/K2-4 合同取得成本
- [ ] 期末余额是否与 K2-2 明细表对应项目一致

## risk_areas

### 高风险

1. **应摊未摊虚增资产**：待摊费用/合同取得成本本期应摊未足额摊销，虚增流动资产、递延费用。
2. **测算与调整脱节**：应摊与已摊差异重大但未通过 K2-3 调整，审定资产失真。
3. **到期未结转**：受益期/合同期已满但项目未结转完毕，期末余额虚高。

### 中风险

1. **摊销期错误**：起始日或总月份误算，导致本期摊销金额失真。
2. **摊销方法不一致**：同类项目采用不同摊销方法或方法与性质不匹配。

### 低风险

1. **测算记录不完整**：摊销参数（起始日/月份）依据未附说明。
2. **交叉索引不完整**：与 K2-2/K2-4/K2-3 的引用标注不全。
