# K4-note-listed 其他流动负债附注披露复核提示词（上市公司）

## 概述

本提示词针对其他流动负债上市公司附注披露底稿（K4-note-listed）的复核，聚焦：按性质分类披露、短期应付债券明细披露、待转销项税额及预提费用披露、与审定表/明细表勾稽、CAS30 列报要求。上市公司其他流动负债须按性质明细披露各构成项目，其中短期应付债券须按 CAS37 披露债券要素，是列报"筐类"负债科目披露充分性的关键。

**法规依据：**
- 《企业会计准则第30号——财务报表列报》
- 《企业会计准则第37号——金融工具列报》
- 《公开发行证券的公司信息披露编报规则第15号——财务报告的一般规定》

---

## tips

1. **"筐类"负债须按性质明细披露**：其他流动负债须在附注中按性质列示各构成项目及金额（待转销项税额/预提费用/短期应付债券/一年内到期的其他非流动负债/其他），不得仅列总额，重大项目须单独列示。
2. **各项目合计须与审定表勾稽**：附注各项目期末数合计须等于审定表 K4-1 审定数，分类小计须与 K4-2 明细表对应合计一致，形成闭环。
3. **短期应付债券须披露债券要素（CAS37）**：如含短期应付债券，须披露债券名称、面值、票面利率、发行日、期限、发行金额、本期计提利息、期末余额及是否违约等要素。
4. **待转销项税额与预提费用须说明**：待转销项税额须说明性质（已开票未确认收入对应销项税）和转销安排，预提费用须说明预提项目和依据，重大项目须结合业务说明。
5. **完整性披露须充分**：附注须完整反映各项其他流动负债义务，与检查表（K4-4）完整性结论一致，避免披露遗漏低估负债。
6. **可比信息与变动分析**：附注须同时列示期末与期初可比数，重大变动须说明原因。

## checklist

### 一、分类明细披露

- [ ] 是否按性质明细披露各构成项目及金额
- [ ] 重大项目是否单独列示（非笼统"其他"）
- [ ] 各项目期末数合计是否等于审定表 K4-1 审定数
- [ ] 分类小计是否与 K4-2 明细表勾稽
- [ ] 是否同时列示期末与期初可比数

### 二、专项项目披露

- [ ] 短期应付债券是否披露债券要素（名称/面值/利率/发行日/期限/金额/利息/违约）
- [ ] 待转销项税额是否说明性质和转销安排
- [ ] 预提费用是否说明预提项目和依据
- [ ] 一年内到期的其他非流动负债是否与非流动负债附注衔接

### 三、完整性与变动

- [ ] 附注是否完整反映各项其他流动负债义务（与 K4-4 完整性结论一致）
- [ ] 其他流动负债重大变动是否说明原因
- [ ] 附注其他流动负债总额是否等于 K4-1 审定数

## risk_areas

### 高风险

1. **隐瞒负债披露遗漏**：附注未完整反映其他流动负债义务，与完整性测试结论不符，低估负债。
2. **短期应付债券要素缺失**：含短期应付债券但未披露债券要素或违约情况，不满足 CAS37。
3. **附注总额与审定表不一致**：附注其他流动负债总额与 K4-1 审定数不符。

### 中风险

1. **重大项目未单独披露**：大额待转销项税额/预提费用笼统归入"其他"。
2. **待转销项税额/预提未说明**：未说明性质、转销安排或预提依据。
3. **分类明细不足**：仅按大类披露未细分性质。

### 低风险

1. **可比信息缺失**：仅列期末数未列期初可比数。
2. **披露格式不规范**：表格列序、金额单位不完全符合编报规则。
3. **交叉索引不完整**：与 K4-1/K4-2 的勾稽索引标注不全。
