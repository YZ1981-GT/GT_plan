# K11-3 资产减值损失调整分录复核提示词

## 适用底稿
资产减值损失调整分录汇总表（K11-3，科目 6701），含账项调整（AJE）、重分类调整（RJE），回写审定表 K11-1，并推送 A13 未调整错报汇总。

## 概述

K11-3 是资产减值损失审定链路的关键环节。资产减值调整通常源于减值测试发现的计提不足（补提）、违规转回的冲回、6701 与 6702 的重分类等。复核须验证：每笔调整有减值测试证据支持、借贷平衡、完整回写 K11-1 审定表、未采纳调整正确推送 A13 并与整体重要性水平比较。

**法规依据：**
- 《企业会计准则第8号——资产减值》
- 《企业会计准则第28号——会计政策、会计估计变更和差错更正》
- 《中国注册会计师审计准则第1301号——审计证据》
- 《中国注册会计师审计准则第1324号——期后事项》

## tips

1. **AJE vs RJE**：补提/冲回减值影响损益与资产账面价值属 AJE；6701 与 6702 之间、或减值损失在利润表行次间的重分类属 RJE，不得以 RJE 掩盖计提不足的损益错报。
2. **每笔调整须有减值测试证据**：补提减值的调整须附可收回金额计算、公允价值评估或亏损合同测算等支持性底稿，不得凭空调整。
3. **借贷平衡与科目正确**：借"资产减值损失（6701）"贷"XX减值准备"（存货跌价准备/固定资产减值准备/商誉减值准备等），核对借贷相等且减值准备科目与资产类别匹配。
4. **完整回写 K11-1**：每笔已确认调整金额须逐笔反映到审定表 K11-1 对应分项的 AJE/RJE 列，遗漏任一笔即审定数失真。
5. **未采纳调整推送 A13**：管理层未接受的减值补提建议须作为未调整错报（SUD）推送 A13，与整体/明细层次重要性水平及明显微小错报阈值比较。
6. **商誉减值调整不可反向**：涉及商誉减值的调整只能补提不得转回，核对调整方向合规。

## checklist

### 高风险检查项

- [ ] 所有减值补提 AJE 是否有减值测试/可收回金额计算证据支持
- [ ] 每笔调整分录借贷方是否完全平衡
- [ ] 减值准备科目是否与资产类别正确匹配（存货跌价/固资减值/商誉减值等）
- [ ] 调整金额是否完整回写至 K11-1 审定表对应分项调整列
- [ ] 商誉及长期资产减值调整是否仅补提未违规转回
- [ ] 管理层未采纳的减值补提建议是否已推送 A13 未调整错报
- [ ] 未调整减值错报累计是否超过整体重要性水平（须评估对意见的影响）

### 中风险检查项

- [ ] RJE 是否仅涉及列报/重分类（如 6701↔6702），未影响损益金额
- [ ] 调整原因说明是否可追溯至具体减值测试程序或底稿
- [ ] 跨期减值调整是否正确区分本期计提与前期差错更正
- [ ] 调整分录编号是否连续，删除后重号风险是否可控
- [ ] 与 A13 未调整错报汇总表的交叉索引是否完整
- [ ] 建议调整与已执行调整是否分别记录

### 低风险检查项

- [ ] 分录摘要、科目编码是否规范
- [ ] 索引是否指向 K11-2 明细表及各资产减值专项底稿
- [ ] 审计说明/结论是否概括调整性质与剩余风险

## risk_areas

### 高风险

1. **补提减值调整缺乏证据**：减值补提无可收回金额计算或评估报告支持，调整金额缺乏客观依据。
2. **审定表与 K11-3 调整不勾稽**：已确认调整未完整回写 K11-1，导致审定数与调整脱节。
3. **未采纳减值错报未推送 A13**：管理层拒绝补提的减值差异未纳入未调整错报汇总，累计可能超重要性水平却未评估。
4. **借贷不平衡或科目错配**：减值准备科目与资产类别不匹配，或调整分录借贷不等。

### 中风险

1. **RJE 误含损益影响**：以重分类名义调整实际影响减值损失金额。
2. **跨期调整分类错误**：本期减值与前期差错更正混淆，会计处理及披露要求不同。

### 低风险

1. **编号、格式不规范**：调整分录编号不连续或摘要不完整。
2. **索引指向不完整**：未标注支持底稿来源。

## 跨底稿勾稽

- K11-3 已确认 AJE/RJE 合计 ↔ K11-1 审定表调整列
- K11-3 未采纳减值错报 ↔ A13 未调整错报汇总
- 调整后审定数 ↔ 试算平衡表 6701 科目
- 各减值调整 ↔ 对应资产减值准备科目（存货跌价准备/固资减值准备/商誉减值准备等）及 F2/H/I/D2 底稿
