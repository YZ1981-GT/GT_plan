# K9-6 管理费用截止测试（记账凭证→原始凭证）复核提示词

## 概述

本提示词针对管理费用正向截止测试底稿（K9-6，科目 6602，方向：记账凭证→原始凭证 V2S）的复核。测试方向为从资产负债表日前后账内已记录的管理费用凭证出发，追查其原始单据（发票/服务确认单/费用报销单）日期，判断费用是否记入恰当会计期间。**本方向主要检测"费用提前/多计入本期"（overstatement）**——即将应属下期的管理费用（如预付下期中介费/软件维护费）提前列支于本期，操纵当期利润。

**法规依据：**
- 《中国注册会计师审计准则第1301号——审计证据》
- 《中国注册会计师审计准则第1141号——财务报表审计中与舞弊相关的责任》

---

## tips

1. **方向决定检测目标**：V2S（记账→原始）从账内凭证追至原始单据，检测**已入账费用是否本不应属本期（提前列支/多计）**；与 K9-7（原始→记账，检测漏记）方向相反、互补，二者不可混淆。
2. **双组列核对**：底稿含记账凭证组（记账日期/凭证号/业务内容/对方科目/金额）与原始凭证组（凭单编号/凭单日期/金额），逐笔核对两侧日期与金额一致性。
3. **截止日两侧分段**：以资产负债表日为界分"日前"与"日后"两段样本，日前样本重点查是否有下期费用提前入账，日后样本印证跨期方向。
4. **跨期判定**：记账日期在本期但原始单据/服务期间属下期即为跨期，该笔为费用提前多计，须记入错报并评估。
5. **关注预付性质费用**：预付下期软件维护费/保险费/中介费若全额列支本期而非计入待摊/预付，属提前多计，须结合 K9-5 合同摊销核对。
6. **样本选取标准**：按资产负债表日前后 N 天选取，大额、年末集中列支、关联方费用凭证应纳入必选样本。

---

## checklist

### 一、样本选取与范围

- [ ] 样本是否覆盖资产负债表日前后 N 天的管理费用记账凭证
- [ ] 年末最后几天集中列支的费用凭证是否纳入必选样本
- [ ] 大额及关联方管理费用凭证是否重点选取
- [ ] 样本量与检查比例是否满足审计目标（本期发生额来自 K9-2）
- [ ] 抽样标准（前后天数/金额阈值/首次承接扩样）是否说明

### 二、双向凭证核对（记账→原始）

- [ ] 每笔记账凭证是否追查到对应原始单据（发票/服务确认单/报销单）
- [ ] 记账日期与原始单据日期及服务期间是否核对并列示
- [ ] 记账金额与原始单据金额是否一致，不符是否标注
- [ ] 业务内容、对方科目是否与原始单据匹配
- [ ] 原始单据是否齐全（缺单据的凭证是否标注异常）

### 三、跨期判定与错报（提前/多计方向）

- [ ] 记账在本期但原始单据/服务期间属下期的凭证是否识别为跨期（费用提前多计）
- [ ] 预付性质费用全额列支本期的是否结合 K9-5 判断应否计入待摊/预付
- [ ] 跨期笔数、跨期金额是否统计汇总
- [ ] 提前列支的费用是否评估为本期费用多计错报并推送 A13/K9-3
- [ ] 截止测试结论是否明确（本期费用是否存在提前列支的重大截止错报）

## risk_areas

### 高风险

1. **费用提前列支多计本期**：将应属下期的中介费/软件维护费/保险费提前记入本期，虚减当期利润或平滑利润，属重大截止错报。
2. **预付费用未待摊**：跨期预付性质费用全额列支本期而未计入待摊/预付，费用多计。
3. **原始单据缺失或不符**：账内记录费用无对应原始单据或金额不符，费用真实性存疑。

### 中风险

1. **跨期金额未评估错报**：识别出跨期凭证但未汇总跨期金额、未评估是否构成错报。
2. **样本未覆盖高风险**：大额/关联方/年末突增费用凭证未纳入必选样本。

### 低风险

1. **核对记录不规范**：双组列日期/金额记录不完整，影响复核可追溯。
2. **抽样参数记录缺失**：前后天数、金额阈值等抽样标准未记录。
