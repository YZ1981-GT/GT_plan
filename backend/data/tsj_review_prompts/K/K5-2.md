# K5-2 预计负债明细表复核提示词

## 概述

本提示词针对预计负债明细表（K5-2，科目 2701，负债类取期末余额）的复核。明细表按预计负债类别（产品质量保证、未决诉讼、亏损性合同、重组义务、退货义务、担保等）逐项列示期初余额、本期计提、本期使用、本期转回及期末余额，是审定表 K5-1 的数据基础。其数据质量直接影响审定数的准确性、CAS13 确认条件的逐项判断以及附注分类披露的完整性。核心风险为项目遗漏（应确认未确认导致少计负债）、计提/转回缺乏依据以及各项滚存计算错误。

**法规依据：**
- 《企业会计准则第13号——或有事项》
- 《企业会计准则第30号——财务报表列报》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **滚存公式是明细表准确性的核心**：每项预计负债期末余额=期初余额+本期计提−本期使用−本期转回±调整，任一列勾稽不成立即数据失真，须逐行验证滚存逻辑。
2. **明细合计必须向上勾稽审定表**：K5-2 各项期末余额合计（K5-2-detail-end-total）须与审定表 K5-1 审定合计及试算表 2701 贷方审定余额三方一致，不得存在无源差异。
3. **项目分类须与 CAS13 确认逻辑对应**：每项预计负债应可归入明确的或有事项类别（质保/诉讼/亏损合同/重组/退货/担保），分类不清或"其他"笼统归集可能掩盖不满足确认条件的项目。
4. **本期计提须有测算依据、本期转回/使用须有支持性证据**：计提金额应有历史数据、合同条款或专家评估支撑；使用（实际支付）须有付款凭证，转回须有义务解除或重估依据，防止无依据转回调节利润。
5. **期初余额须与上年审定期末数衔接**：明细表各项期初余额应逐项等于上年度审定后期末余额，续审项目须核对上年底稿，新增项目须说明来源。
6. **完整性是首要关注点**：明细表须结合合同台账、律师函（A 循环）、董事会决议、历史赔付记录搜寻应计提而未列示的现时义务，明细表遗漏即审定表遗漏。

## checklist

### 一、滚存计算与勾稽（高风险）

- [ ] 【必检】各项期末余额=期初+计提−使用−转回±调整 是否逐行成立
- [ ] 【必检】明细表期末余额合计是否与审定表 K5-1 审定合计一致
- [ ] 【必检】明细表期末余额合计是否与试算表 2701 审定余额一致（贷方方向）
- [ ] 【必检】各项期初余额是否逐项等于上年度审定后期末余额
- [ ] 【必检】本期计提合计是否与利润表相关费用/损失科目勾稽
- [ ] 【条件检查：若涉及折现】折现摊销（利息费用）是否单独列示且计算正确

### 二、项目分类与计提依据（高风险）

- [ ] 【必检】每项预计负债是否可明确归入 CAS13 或有事项类别
- [ ] 【必检】产品质量保证计提是否以历史赔付率×本期销售额为基础
- [ ] 【必检】未决诉讼计提是否与律师函评估结果（A 循环）一致
- [ ] 【必检】亏损性合同预计负债是否以合同不可避免成本超过预期经济利益的差额计量
- [ ] 【必检】本期计提金额是否有测算表、合同条款或专家意见支撑
- [ ] 【条件检查：若有重组义务】重组预计负债是否以已宣布的正式重组计划为依据
- [ ] 【风险检查】是否存在无依据超额计提形成"利润蓄水池"

### 三、使用与转回真实性（中风险）

- [ ] 【必检】本期使用（实际支出）是否有付款凭证或结算依据
- [ ] 【必检】本期转回是否有义务解除、重新估计或诉讼终结等支持性证据
- [ ] 【必检】转回金额计入的科目是否恰当（冲减原计提科目或计入损益）
- [ ] 【风险检查】是否存在集中在期末的大额转回，可能为调节利润
- [ ] 【风险检查】是否存在长期挂账不使用不转回的僵尸预计负债

### 四、完整性搜寻（高风险）

- [ ] 【必检】是否结合合同台账搜寻亏损性合同、未履行义务
- [ ] 【必检】是否结合律师函、诉讼清单搜寻未列示的未决诉讼
- [ ] 【必检】是否结合销售政策评估退货义务、质保义务的完整性
- [ ] 【条件检查：若有对外担保】担保履约义务是否评估并在满足条件时计提
- [ ] 【风险检查】满足 CAS13 确认条件的义务是否存在遗漏未列示

## risk_areas

### 高风险

1. **项目遗漏导致少计负债**：满足 CAS13 确认条件的现时义务（质保、败诉可能大的诉讼、亏损合同）未在明细表列示，导致审定表少计负债、虚增利润。
2. **滚存计算错误或与审定表/试算表不勾稽**：期末余额滚存公式不成立，或明细合计与 K5-1、试算表 2701 存在无源差异。
3. **计提缺乏依据**：本期计提金额无历史数据、合同条款或专家评估支撑，金额为管理层主观估计。
4. **无依据转回调节利润**：本期转回无义务解除或重估证据，或集中在期末大额转回美化业绩。

### 中风险

1. **项目分类不当**：预计负债类别归集错误或以"其他"笼统列示，影响 CAS13 确认逻辑判断和附注分类披露。
2. **折现处理不当**：影响重大的长期预计负债未折现，或折现摊销未在明细表单独反映。
3. **期初数与上年审定数不衔接**：明细表期初余额未逐项核对上年底稿。

### 低风险

1. **格式与索引不规范**：明细表列序、金额单位、交叉索引标注不完整。
2. **项目说明不足**：各项预计负债缺少形成原因、预计支出时间等辅助说明。
