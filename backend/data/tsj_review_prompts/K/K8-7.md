# K8-7 销售费用截止测试（原始凭证→记账凭证）复核提示词

## 概述

本提示词针对销售费用反向截止测试底稿（K8-7，科目 6601，方向：原始凭证→记账凭证 S2V）的复核。测试方向为从资产负债表日前后的原始单据（运费单/广告发票/服务确认单）出发，追查其是否已入账及记账期间，判断费用是否记入恰当会计期间。**本方向主要检测"费用漏记/滞后（完整性）"（understatement）**——即本期应确认的销售费用未记或被推迟至下期，虚增当期利润。

**法规依据：**
- 《中国注册会计师审计准则第1301号——审计证据》
- 《中国注册会计师审计准则第1141号——财务报表审计中与舞弊相关的责任》

---

## tips

1. **方向决定检测目标**：S2V（原始→记账）从原始单据追至账内记录，检测**本期原始单据是否被漏记或滞后入账（完整性/少计）**；与 K8-6（记账→原始，检测提前多计）方向相反、互补，是销售费用完整性的关键程序。
2. **完整性是损益费用首要风险**：反向截止直接应对"少计费用虚增利润"，须从完整的原始单据总体（收发货记录/服务验收/供应商对账）出发，而非仅账内凭证。
3. **双组列核对**：底稿含原始凭证组（凭单编号/凭单日期/金额/业务内容）与记账凭证组（记账日期/凭证号/金额），核对本期原始单据是否均已在本期入账。
4. **跨期判定**：原始单据日期属本期但未入账或记入下期，即为费用漏记/滞后，该笔构成本期费用少计错报。
5. **样本来源须完整**：样本应取自独立的原始单据流水（如运输签收记录、广告投放确认、供应商月结对账单），避免仅从账内选取导致漏记无法被发现。
6. **样本选取标准**：按资产负债表日前后 N 天选取原始单据，期末大额未入账、供应商对账差异项应纳入必选样本。

---

## checklist

### 一、样本选取与总体完整性

- [ ] 样本是否取自独立完整的原始单据总体（非仅账内凭证）
- [ ] 样本是否覆盖资产负债表日前后 N 天的原始单据
- [ ] 期末供应商对账差异、未入账原始单据是否纳入必选样本
- [ ] 大额及关联方相关原始单据是否重点选取
- [ ] 样本量与检查比例是否满足完整性审计目标

### 二、双向凭证核对（原始→记账）

- [ ] 每份原始单据是否追查到对应记账凭证
- [ ] 原始单据日期与记账日期是否核对并列示
- [ ] 原始单据金额与记账金额是否一致
- [ ] 业务内容是否与账内记录匹配
- [ ] 未找到对应记账凭证的原始单据是否标注（漏记疑点）

### 三、跨期判定与错报（漏记/滞后方向）

- [ ] 原始单据属本期但未入账或记入下期的是否识别为跨期（费用漏记/少计）
- [ ] 漏记/滞后笔数、金额是否统计汇总
- [ ] 漏记费用是否评估为本期费用少计错报并推送 A13/K8-3 补提
- [ ] 期末大额未入账费用（如未开票运费/广告费）是否与 K8-3 补提调整衔接
- [ ] 截止测试结论是否明确（本期费用是否存在漏记/滞后的重大完整性错报）

## risk_areas

### 高风险

1. **费用漏记少计虚增利润**：本期已发生的运输费/广告费/佣金原始单据未入账或推迟至下期，费用少计、利润虚增，属重大完整性错报。
2. **样本总体不完整**：仅从账内凭证抽样而非独立原始单据总体，导致漏记根本无法被发现（程序失效）。
3. **期末未开票费用未补提**：资产负债表日已发生但未取得发票的费用未入账且未补提。

### 中风险

1. **漏记金额未评估错报**：识别出漏记原始单据但未汇总金额、未推送补提调整。
2. **供应商对账差异未追**：期末供应商对账差异项未纳入截止测试范围。

### 低风险

1. **核对记录不规范**：原始单据组与记账组的日期/金额记录不完整。
2. **抽样参数记录缺失**：原始单据总体来源、前后天数等未记录。
