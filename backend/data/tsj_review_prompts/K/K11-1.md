# K11-1 资产减值损失审定表复核提示词

## 概述

本提示词针对资产减值损失审定表（K11-1，科目 6701，损益类借方，取本期发生额）的复核。资产减值损失汇总各类资产（存货跌价、固定资产/在建工程/无形资产/商誉、长期股权投资、合同资产等）本期计提的减值。聚焦：发生额勾稽、与各资产减值底稿的逐项勾稽、商誉减值不可转回、减值迹象与计提充分性。核心风险为完整性（少提减值虚增利润）与准确性。

**法规依据：**
- 《企业会计准则第8号——资产减值》
- 《企业会计准则第22号——金融工具确认和计量》（预期信用损失）
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **取"发生额"非"余额"**：审定数按 6701 本期计提额（借方）−转回（贷方，除商誉外）±调整。
2. **逐项勾稽各资产底稿**：审定表各减值项目本期计提额应与对应资产底稿（存货 F2、固资 H1、无形 H4/I、商誉 I4、应收 D2 等）本期减值计提额逐项一致；本表是减值损失的汇总枢纽。
3. **发生额勾稽**：审定合计=未审+AJE+RJE，且=明细表 K11-2 本期发生额合计。
4. **商誉减值不可转回**：商誉及部分长期资产减值一经计提不得转回，核对是否存在违规转回。
5. **计提充分性（完整性首要风险）**：存在减值迹象（如资产闲置、市价下跌、亏损合同、逾期应收）却未足额计提，是虚增利润的高发点。
6. **跨底稿闭环**：审定合计↔K11-2↔试算表 6701↔利润表"资产减值损失"行；各明细↔各资产减值底稿。

## checklist

### 一、发生额勾稽与试算表核对

- [ ] 审定表各项目审定数=未审+AJE+RJE 是否正确
- [ ] 审定合计是否与明细表 K11-2 本期发生额合计一致
- [ ] 审定合计是否与试算平衡表 6701 审定发生额一致
- [ ] 未审发生额是否与试算表 6701 一致
- [ ] 上期审定数是否与上年底稿一致

### 二、与各资产减值底稿勾稽

- [ ] 存货跌价准备本期计提是否与 F2 存货底稿一致
- [ ] 固定资产/在建工程减值本期计提是否与 H 循环底稿一致
- [ ] 无形资产/开发支出减值是否与 H4/I 循环底稿一致
- [ ] 商誉减值是否与 I4 底稿一致，且未违规转回
- [ ] 应收类信用减值损失是否单独列示（6702，勿与 6701 混淆）
- [ ] 各减值项目是否有减值测试/可收回金额计算支持

### 三、审计调整与充分性

- [ ] 已确认的账项/重分类调整是否完整反映
- [ ] 存在减值迹象的资产是否均已评估并足额计提
- [ ] 是否存在应计提减值但未计提（完整性缺失）
- [ ] 是否存在不可转回资产（商誉等）违规转回

## risk_areas

### 高风险

1. **少提/漏提减值**：存在减值迹象（闲置、市价下跌、逾期、亏损合同）却未足额计提，虚增利润。
2. **商誉减值违规转回**：将不可转回的商誉/长期资产减值转回，虚增利润。
3. **与各资产底稿不勾稽**：审定汇总数与各资产减值底稿计提额不一致。
4. **审定表与试算表不勾稽**：发生额口径不一致。

### 中风险

1. **减值测算依据不足**：可收回金额/公允价值确定的关键假设缺乏支持。
2. **6701 与 6702 混淆**：资产减值损失与信用减值损失列报错误。
3. **审计调整遗漏**：已确认减值调整未纳入审定表。

### 低风险

1. **格式与索引不规范**。
2. **减值项目说明不足**。
