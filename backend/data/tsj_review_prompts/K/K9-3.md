# K9-3 管理费用调整分录复核提示词

## 概述

本提示词针对管理费用调整分录汇总表（K9-3，科目 6602，损益类）的复核，含账项调整（AJE）、重分类调整（RJE）及未调整错报（SUD）评估。管理费用为损益类，AJE 多为期末补提（未入账中介费/审计费/办公费）或冲减，RJE 多为与销售费用/营业成本/研发费用列示的费用性质重分类。复核须验证每笔调整有证据、借贷平衡、完整反映至审定表 K9-1、SUD 评估符合重要性水平。

**法规依据：**
- 《企业会计准则第28号——会计政策、会计估计变更和差错更正》
- 《中国注册会计师审计准则第1301号——审计证据》
- 《中国注册会计师审计准则第1141号——财务报表审计中与舞弊相关的责任》

## tips

1. **AJE 影响费用发生额，RJE 仅影响列报**：AJE（补提/冲减管理费用）改变损益金额，RJE（管理费用↔销售费用/成本/研发费用列示互转）仅改变费用结构；不得以 RJE 掩盖费用完整性错报。
2. **与审定表 K9-1 逐笔勾稽**：审定表调整列 AJE/RJE 合计须与 K9-3 已确认分录逐笔一致，遗漏任一笔即审定发生额失真。
3. **补提调整体现完整性**：期末未入账的中介费、审计费、办公费、计提未付薪酬的补提是管理费用最常见 AJE，须有合同/服务完成/权责发生制依据。
4. **研发费用列示重分类须谨慎**：管理费用中研发费用的列示重分类须与研发归集口径一致，避免通过重分类影响研发费用披露或加计扣除基数。
5. **SUD 累计评估**：未调整的管理费用错报单独及累计是否超明显微小/整体重要性水平，须与 A13 未调整错报汇总交叉验证。
6. **调整闭环回写**：确认调整已同步至审定表并回写试算表 6602 发生额，避免双真源；调整应发布至集中调整登记（adjustment:created）。

## checklist

### 一、账项调整（AJE）完整性与依据

- [ ] 每笔 AJE（补提/冲减管理费用）是否有充分证据（合同、服务完成凭证、管理层确认）
- [ ] 期末应计未计费用（中介费/审计费/办公费/未付薪酬）是否已按权责发生制补提
- [ ] AJE 是否经适当层级审批（超明细层次重要性水平须合伙人/项目经理审批留痕）
- [ ] AJE 金额是否完整反映至审定表 K9-1 对应项目账项调整列
- [ ] 是否存在仅为调节利润而无实质依据的不当调整

### 二、重分类调整（RJE）

- [ ] RJE 是否仅涉及费用列报（管理费用↔销售费用/营业成本/研发费用列示），未影响利润总额
- [ ] 费用性质重分类是否有明确依据
- [ ] 研发费用列示的重分类是否与研发归集口径一致，不影响加计扣除基数
- [ ] RJE 是否完整反映至审定表 K9-1 重分类调整列
- [ ] 是否存在通过重分类粉饰费用结构或规避异常波动分析的迹象

### 三、平衡、勾稽与未调整错报

- [ ] 每笔调整分录借贷方是否完全平衡
- [ ] K9-3 已确认 AJE/RJE 合计是否与审定表 K9-1 调整列一致
- [ ] 调整后审定发生额是否已回写试算表 6602 科目
- [ ] 未调整错报（SUD）单独及累计是否超阈值，是否记入 A13 未调整错报汇总
- [ ] 调整原因说明、编号、索引（指向 K9-5/K9-8 支持底稿）是否完整

## risk_areas

### 高风险

1. **调整缺乏证据或未授权**：补提/冲减管理费用无支持性证据或未经适当审批。
2. **审定表与 K9-3 长期不一致**：审定表调整列与已确认分录金额不勾稽，审定发生额失真。
3. **以重分类掩盖完整性错报**：将本应补提的费用通过 RJE 在费用科目间腾挪，规避利润影响。
4. **SUD 累计超阈值未处理**：未调整的管理费用错报累计超整体重要性水平仍未恰当处理。

### 中风险

1. **RJE 误含损益影响**：重分类调整错误影响了费用发生额或利润总额。
2. **研发费用重分类口径不一致**：与研发归集口径不符，影响研发费用披露/加计扣除。
3. **回写试算表遗漏**：调整已在底稿确认但未同步回写 TB 6602 发生额。

### 低风险

1. **分录摘要、科目编码不规范**：影响调整可追溯性。
2. **索引与交叉引用不完整**：与 K9-5 合同检查、K9-8 凭证检查等支持底稿的索引缺失。
