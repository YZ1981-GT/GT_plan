# K8-note-soe 销售费用附注披露复核提示词（国有企业）

## 概述

本提示词针对销售费用国有企业附注披露底稿（K8-note-soe，科目 6601）的复核，聚焦：按性质列示的基础披露、国资监管敏感费用（业务招待费/差旅费/会议费等"三公"类费用）的专项披露、与关联方（含同受国有控制单位）的费用交易、以及财务决算报表口径一致性。国有企业销售费用披露既须满足会计准则通用要求，又须满足国资委决算与费用管控要求。

**法规依据：**
- 《企业会计准则第30号——财务报表列报》
- 《企业会计准则第36号——关联方披露》
- 《中央企业财务决算报告管理办法》

---

## tips

1. **双层披露要求**：既满足 CAS30 按性质分项列示的通用要求，又满足国资委决算报告对敏感费用（招待/差旅/会议/宣传）的专项披露要求。
2. **敏感费用专项管控**：业务招待费、差旅费、会议费、广告宣传费等国资监管重点关注费用须单独列示金额、说明本期较上期变动及超预算情况。
3. **与审定表/决算勾稽**：附注销售费用合计=审定表 K8-1 审定合计=利润表销售费用行=年度财务决算报表销售费用数，多口径须一致。
4. **关联方范围更广**：向控股股东及同受国有控制的其他国有企业支付的销售费用（如运输/代理/广告服务）须纳入关联方交易披露。
5. **预算执行视角**：销售费用实际发生额与年度预算的对比、重大超预算项目的原因是国企附注独有关注点。
6. **与上市版差异在监管层面**：基础披露框架与上市版相同（按性质分项+可比数据），国企版额外增加敏感费用管控、预算执行与国资监管信息，非替代基础披露。

## checklist

### 一、基础披露完整性（与上市版共有）

- [ ] 销售费用是否按费用性质分项列示（运输/广告/薪酬/差旅/招待/仓储/折旧摊销/其他）
- [ ] 各明细项目是否同时列示本期数与上期数
- [ ] 附注销售费用合计是否与审定表 K8-1 审定合计及利润表销售费用行一致
- [ ] 明细项目口径是否与明细表 K8-2 一致
- [ ] 上期可比数据是否与上年决算/审计附注衔接

### 二、国资监管敏感费用披露

- [ ] 业务招待费是否单独列示金额并说明变动
- [ ] 差旅费、会议费是否单独披露及超预算说明
- [ ] 广告宣传费/赞助费等大额费用是否说明合规性与审批
- [ ] 敏感费用较上期重大变动是否说明原因
- [ ] 是否披露费用列支是否符合国资委费用管控与"过紧日子"要求

### 三、关联方费用与预算执行披露

- [ ] 向控股股东及同受国有控制单位支付的销售费用是否纳入关联方交易披露
- [ ] 关联方费用交易定价方式（市场价/协议价）是否披露
- [ ] 销售费用实际发生额与年度预算的对比是否披露
- [ ] 重大超预算项目（超一定比例）是否说明原因
- [ ] 附注销售费用是否与年度财务决算报表数一致

## risk_areas

### 高风险

1. **敏感费用未按国资要求单独披露**：业务招待费/差旅费/会议费等未单独列示或未说明变动，不满足国资监管披露要求。
2. **附注与决算/审定表不勾稽**：附注销售费用与决算报表、审定表 K8-1、利润表多口径不一致。
3. **关联方费用范围遗漏**：向同受国有控制单位支付的费用未纳入关联方披露，违反 CAS36 及国资委要求。

### 中风险

1. **超预算未说明**：销售费用重大超预算但未披露原因和改进措施。
2. **敏感费用合规性说明不足**：大额广告/赞助费未说明审批与合规性。
3. **明细分类不完整**：未按性质分项或"其他"笼统列示掩盖敏感支出。

### 低风险

1. **披露格式未按决算模板**：与国资委决算报表模板有细微格式差异。
2. **预算对比维度单一**：仅对比总额未按项目细分对比。
