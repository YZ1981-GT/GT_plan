# K3-note-listed 其他应付款附注披露复核提示词（上市公司）

## 概述

本提示词针对其他应付款上市公司附注披露底稿（K3-note-listed）的复核，聚焦：按性质分类披露、账龄披露、大额及长账龄披露、关联方资金往来披露、与审定表/明细表勾稽。上市公司其他应付款披露除 CAS30/CAS36 通用要求外，须满足证监会编报规则第 15 号对分类、大额款项、账龄超一年及关联方资金往来的额外披露要求，是识别隐瞒负债和关联方资金占用的重要披露。

**法规依据：**
- 《企业会计准则第30号——财务报表列报》
- 《企业会计准则第36号——关联方披露》
- 《公开发行证券的公司信息披露编报规则第15号——财务报告的一般规定》

---

## tips

1. **按性质分类披露是上市公司必备**：其他应付款须按性质分类（押金保证金/暂收款/关联方往来/代扣代缴/其他），各类别期末/期初数须列示，分类合计须等于审定表 K3-1 审定数。
2. **账龄披露及超一年大额款项说明**：须披露账龄分布，账龄超一年的大额其他应付款须披露内容和未偿还原因（证监会编报规则要求），长期挂账须说明是否仍需支付。
3. **大额其他应付款须披露**：金额重大的其他应付款须披露债权人、性质、金额和账龄，与 K3-4 大额分析数据一致。
4. **关联方资金往来是监管关注点**：关联方（尤其控股股东）通过其他应付款拆入资金须单独披露（往来方/金额/性质/占用费），与 K3-6 一致，警惕隐瞒关联方资金调度。
5. **完整性披露须充分**：附注须反映全部其他应付款义务，与未入账负债搜索（K3-7）结论一致，避免披露遗漏低估负债。
6. **附注须与审定表/明细表闭环勾稽**：附注其他应付款总额=K3-1 审定数；分类/账龄小计=K3-2 明细对应合计；大额=K3-4；关联方=K3-6，任一断裂为披露错误。

## checklist

### 一、分类与账龄披露

- [ ] 是否按性质分类披露（押金/暂收/关联方/代扣代缴/其他）
- [ ] 各类别期末数合计是否等于审定表 K3-1 审定数
- [ ] 是否同时列示期末与期初可比数
- [ ] 账龄披露是否完整，账龄超一年的大额款项是否披露内容及未偿还原因
- [ ] 分类/账龄数据是否与 K3-2 明细表一致

### 二、大额与关联方披露

- [ ] 金额重大的其他应付款是否披露（债权人/性质/金额/账龄）
- [ ] 大额披露是否与 K3-4 大额分析一致
- [ ] 关联方资金往来是否单独披露（往来方/金额/性质/占用费）
- [ ] 关联方披露是否与 K3-6 一致

### 三、完整性与其他

- [ ] 附注是否反映全部其他应付款义务（与 K3-7 完整性结论一致）
- [ ] 长期挂账是否说明是否仍需支付
- [ ] 附注其他应付款总额是否等于 K3-1 审定数

## risk_areas

### 高风险

1. **隐瞒负债披露遗漏**：附注未完整反映其他应付款义务，与未入账负债搜索结论不符，低估负债。
2. **关联方资金往来未披露**：控股股东通过其他应付款拆入资金未单独披露，隐瞒关联方资金调度。
3. **附注总额与审定表不一致**：附注其他应付款总额与 K3-1 审定数不符。

### 中风险

1. **大额/超一年款项披露不足**：未披露大额债权人或账龄超一年款项的未偿还原因。
2. **分类维度不足**：仅列总额或按单一维度披露，未按性质分类。
3. **长期挂账未说明**：长期挂账未说明是否仍需支付。

### 低风险

1. **可比信息缺失**：仅列期末数未列期初可比数。
2. **披露格式不规范**：表格列序、金额单位不完全符合编报规则。
3. **交叉索引不完整**：与 K3-1/K3-2/K3-4/K3-6 的勾稽索引标注不全。
