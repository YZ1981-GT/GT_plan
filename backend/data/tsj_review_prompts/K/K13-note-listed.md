# K13-note-listed 营业外支出附注披露复核提示词（上市公司）

## 概述

本提示词针对营业外支出上市公司附注披露底稿（K13-note-listed，科目 6711，损益类）的复核。聚焦利润表"营业外支出"项目的附注分项披露：按损失性质（对外捐赠、非流动资产毁损报废损失、罚款滞纳金支出、非常损失、债务重组损失等）列示本期发生额，捐赠及非常损失重大项目须披露性质与依据，非经常性损益金额须单独披露，并与审定表 K13-1、利润表勾稽。上市公司披露受证监会编报规则及非经常性损益披露规则约束。

**法规依据：**
- 《企业会计准则第30号——财务报表列报》
- 《公开发行证券的公司信息披露编报规则第9号——非经常性损益》
- 《公开发行证券的公司信息披露编报规则第15号——财务报告的一般规定》

## tips

1. **按损失性质分项披露本期发生额**：附注须完整列示营业外支出各损失项目本期金额，各分项合计=利润表营业外支出行=审定表 K13-1 审定合计。
2. **对外捐赠须披露性质与对象**：重大对外捐赠须披露捐赠对象、金额、是否为公益性捐赠及是否为关联方，公益性捐赠涉及税前扣除限额。
3. **非流动资产毁损报废损失须与资产处置勾稽**：附注中的资产处置/报废损失须与固定资产（H）、无形资产（I）附注的处置减少勾稽。
4. **非经常性损益单独披露**：营业外支出项目多属非经常性损益，须在非经常性损益明细表中单独列示，且与营业外支出附注勾稽，供计算扣非归母净利润。
5. **非常损失须披露事件与理赔**：因灾害、事故等形成的非常损失须披露事件性质、损失金额及保险理赔情况。
6. **附注数据闭环勾稽**：附注分项本期发生额=K13-2 明细表分项净发生额=利润表营业外支出行=审定表 K13-1 审定合计；非经常性损益金额与非经常性损益明细表勾稽。

## checklist

### 一、分项披露完整性

- [ ] 营业外支出是否按损失性质完整分项列示本期发生额
- [ ] 各分项本期发生额合计是否等于利润表"营业外支出"行金额
- [ ] 各分项合计是否与审定表 K13-1 审定合计一致
- [ ] 是否同时披露本期数与上期可比数
- [ ] 各分项是否与 K13-2 明细表对应项目勾稽
- [ ] 重大损失项目是否披露形成原因及依据

### 二、捐赠与非常损失披露

- [ ] 对外捐赠是否披露捐赠对象、金额、性质（公益性/非公益性）
- [ ] 公益性捐赠税前扣除情况是否有说明
- [ ] 是否披露是否存在向关联方的捐赠
- [ ] 非常损失是否披露事件性质（灾害/事故）及损失金额
- [ ] 非常损失的保险理赔情况是否披露
- [ ] 债务重组损失（如有）是否披露重组安排

### 三、非流动资产处置损失披露

- [ ] 非流动资产毁损报废损失是否与固定资产（H）附注处置减少勾稽
- [ ] 无形资产处置损失是否与无形资产（I）附注勾稽
- [ ] 处置损失是否披露处置资产类别及原因
- [ ] 资产处置损益列报口径是否正确（营业外 vs 资产处置收益）

### 四、非经常性损益披露

- [ ] 营业外支出中属非经常性损益的项目是否单独列示
- [ ] 非经常性损益金额是否与营业外支出附注勾稽
- [ ] 非经常性损益金额是否用于计算扣非归母净利润
- [ ] 非经常性损益列示是否符合证监会第9号编报规则口径
- [ ] 是否披露非经常性损益的所得税影响

## risk_areas

### 高风险

1. **分项合计与利润表/审定表不勾稽**：附注营业外支出分项之和与利润表营业外支出行或 K13-1 审定合计不一致。
2. **非经常性损益披露缺失或不勾稽**：营业外支出未在非经常性损益明细表单独列示，或两者金额不一致，影响扣非利润计算。
3. **重大损失原因未披露**：大额捐赠、非常损失、资产报废损失未披露形成原因与依据。

### 中风险

1. **对外捐赠披露不足**：未披露捐赠对象、性质或是否向关联方捐赠。
2. **非流动资产处置损失不勾稽**：附注资产处置损失与资产附注处置减少不一致。
3. **可比信息缺失**：仅披露本期发生额未列示上期可比数据。
4. **非常损失理赔披露缺失**：非常损失未披露保险理赔情况。

### 低风险

1. **披露格式不规范**：分项排列顺序、金额单位等格式细节未严格按编报规则。
2. **损失性质说明模板化**：损失性质描述过于笼统，未结合本企业实际。
