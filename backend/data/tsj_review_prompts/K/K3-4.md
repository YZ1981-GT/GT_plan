# K3-4 大额其他应付款分析复核提示词

## 概述

本提示词针对大额其他应付款情况分析表（K3-4）的复核，聚焦：大额债权人选取充分性、款项性质与业务实质核查、关联方资金占用识别、支付义务真实性与时效。大额分析针对超过设定阈值（或前 N 大）的其他应付款债权人逐笔穿透形成原因、款项性质和支付安排，是识别隐瞒负债、关联方资金拆借和长期挂账应转收益的关键程序。

**法规依据：**
- 《企业会计准则第30号——财务报表列报》
- 《企业会计准则第36号——关联方披露》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **大额债权人选取阈值须合理并覆盖充分**：选取标准（金额阈值/前 N 大/占比）须与重要性水平匹配，覆盖率应达计划水平，同时须考虑负债完整性——不仅分析已入账大额，还须结合未入账负债搜索。
2. **款项性质与支付义务真实性须穿透**：大额款项须核查形成背景、是否存在真实支付义务，警惕虚构负债（虚增负债转移资产）或长期挂账已无需支付仍列报。
3. **关联方资金占用是首要关注点**：大额债权人须与 K3-6 交叉，识别关联方通过其他应付款向被审计单位拆入资金或调节往来，评估资金性质和往来实质。
4. **合同/协议依据须核查**：大额款项须有合同、协议或原始凭证支撑，无依据的大额挂账须质疑其真实性和支付义务。
5. **大额款项与明细表勾稽**：K3-4 分析对象须来自 K3-2 明细表，金额、性质、账龄须一致，遗漏大额债权人即分析覆盖不足。
6. **长期无支付安排的大额款项须评估**：大额款项长期无支付安排、债权人失联或超诉讼时效的，须评估是否应转营业外收入（联动 K3-5）。

---

## checklist

### 一、选取充分性

- [ ] 大额债权人选取阈值（金额/前N大/占比）是否合理且与重要性水平匹配
- [ ] 选取后对其他应付款总额的覆盖比例是否达到计划水平
- [ ] 大额对象是否全部来自 K3-2 明细表且金额一致
- [ ] 是否结合未入账负债搜索评估完整性（不仅分析已入账）

### 二、性质与真实性

- [ ] 每笔大额款项的形成背景与业务实质是否核查
- [ ] 是否有合同/协议/原始凭证支撑真实支付义务
- [ ] 是否存在虚构负债或长期无需支付仍列报
- [ ] 款项性质分类是否与 K3-2 一致

### 三、关联方与支付安排

- [ ] 大额债权人是否与 K3-6 交叉，关联方资金占用是否识别
- [ ] 关联方资金拆入/往来实质是否评估
- [ ] 大额款项支付安排是否明确
- [ ] 长期无支付安排/超时效款项是否评估转营业外收入（联动 K3-5）

## risk_areas

### 高风险

1. **虚构负债**：大额其他应付款缺乏真实支付义务，虚增负债以转移资产或调节报表。
2. **关联方资金拆借未识别**：关联方通过其他应付款拆入资金未识别披露。
3. **长期挂账应转未转**：大额长期挂账已无需支付但仍列报，虚增负债延迟确认收益。

### 中风险

1. **选取覆盖不足**：阈值过高或遗漏重大债权人，大额分析未覆盖主要负债。
2. **业务实质核查不深**：仅核对金额未穿透形成原因和支付义务。

### 低风险

1. **分析记录不完整**：大额款项背景说明和支付安排记录简略。
2. **交叉索引不完整**：与 K3-2/K3-5/K3-6 的引用标注不全。
