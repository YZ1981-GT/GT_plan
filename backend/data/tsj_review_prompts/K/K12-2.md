# K12-2 营业外收入明细表复核提示词

## 概述

本提示词针对营业外收入明细表（K12-2，科目 6301，损益类贷方，取本期发生额）的复核。明细表按利得项目（与日常活动无关的政府补助、捐赠利得、盘盈利得、罚款收入、无法支付款项转入、非流动资产处置利得等）分项列示本期发生额，是营业外收入科目的基础数据底稿，向上支撑审定表 K12-1，向外与其他收益（K10）划分并勾稽。核心关注：各利得与日常活动的无关性、计入科目正确性、非经常性损益标识、以及完整性与截止（易被用于跨期调节利润）。

**法规依据：**
- 《企业会计准则第16号——政府补助》
- 《企业会计准则第30号——财务报表列报》
- 《中国注册会计师审计准则第1301号——审计证据》
- 《公开发行证券的公司信息披露编报规则第9号——非经常性损益》

---

## tips

1. **取"发生额"非"余额"**：明细表各利得项目按 6301 本期贷方发生额减借方发生额填列净发生额，损益类无期末余额。
2. **无关性判断是明细表核心**：逐项判断利得是否确与企业日常经营活动无关——与日常活动相关的政府补助应计其他收益（K10）而非营业外收入，错计将扭曲营业利润与扣非利润。
3. **计入科目与 K10 划分**：明细表须清晰区分营业外收入（K12，与日常活动无关）与其他收益（K10，与日常活动相关的补助/返还），核对政府补助分类依据。
4. **非经常性损益标识**：营业外收入项目通常属非经常性损益，明细表须逐项标识供上市公司扣非利润披露，标识错误影响扣非披露准确性。
5. **完整性与真实性并重**：无法支付款项转入、盘盈利得等易被用于跨期集中确认调节利润，明细每笔须核对依据（债权人放弃/超诉讼时效证据、盘点记录、批准文件）。
6. **明细合计闭环勾稽**：明细表各项净发生额合计=审定表 K12-1 审定合计=试算表 6301 审定发生额=利润表营业外收入行。

## checklist

### 一、发生额勾稽与汇总（高风险）

- [ ] 【必检】各利得项目本期净发生额=贷方−借方是否计算正确
- [ ] 【必检】明细表各项净发生额合计是否与审定表 K12-1 审定合计一致
- [ ] 【必检】明细表本期发生额合计是否与试算平衡表 6301 审定发生额一致
- [ ] 【必检】未审发生额合计是否与试算表 6301 未审数一致
- [ ] 【必检】上期本期发生额是否与上年 K12-2 底稿衔接
- [ ] 【风险检查】是否存在单项利得金额异常且集中于期末确认

### 二、计入科目与无关性判断（高风险）

- [ ] 【必检】各项利得计入营业外收入是否确与日常活动无关
- [ ] 【必检】政府补助分类（营业外收入 vs 其他收益 K10）是否正确
- [ ] 【必检】与日常活动相关的补助/退税是否未错计营业外收入
- [ ] 【必检】非流动资产处置利得计入营业外收入是否符合列报要求
- [ ] 【条件检查：若有政府补助】补助文件的用途/条件是否支持无关性判断
- [ ] 【风险检查】是否将经常性利得错计营业外收入以规避营业利润下滑

### 三、依据充分性与真实性（高风险）

- [ ] 【必检】无法支付款项转入是否有债权人放弃/超诉讼时效等充分依据
- [ ] 【必检】盘盈利得是否有盘点记录及批准文件支持
- [ ] 【必检】罚款收入是否有收款依据（判决/协议/收据）
- [ ] 【必检】捐赠利得是否有捐赠协议及资产价值确认依据
- [ ] 【条件检查：若有大额无法支付款项转入】是否核实原始负债真实性
- [ ] 【风险检查】是否存在虚构利得或将负债不当转入收入

### 四、非经常性损益与截止（中风险）

- [ ] 【必检】各利得项目非经常性损益标识是否正确
- [ ] 【必检】非经常性损益金额是否准确（供扣非披露）
- [ ] 【必检】资产负债表日前后利得是否记入恰当期间（截止）
- [ ] 【风险检查】是否存在跨期确认利得以调节当期利润

## risk_areas

### 高风险

1. **分类错误扭曲营业利润**：与日常活动相关的政府补助/退税错计营业外收入（或反之），影响营业利润与扣非利润的真实性。
2. **跨期调节利润**：将无法支付款项转入、盘盈、罚款收入等在特定期间集中确认以平滑或调节利润，属截止与完整性风险。
3. **虚构利得**：无实际依据将负债不当转入营业外收入，或虚构盘盈/罚款收入虚增利润。
4. **明细与审定表/试算表不勾稽**：净发生额合计与 K12-1 审定数或 6301 试算发生额存在无源差异。

### 中风险

1. **依据不充分**：无法支付款项转入、捐赠利得缺乏充分证据（债权人放弃证明、捐赠协议）。
2. **非经常性损益标识错误**：影响上市公司扣非利润披露的准确性。
3. **政府补助分类判断不足**：补助计入营业外收入还是其他收益缺乏文件用途/条件的支持性分析。

### 低风险

1. **格式与索引不规范**：明细项目排列、与 K12-1/K10 的交叉索引标注不完整。
2. **利得项目说明不足**：分项仅列金额未附利得性质及依据简述。
