# K2-note-listed 其他流动资产附注披露复核提示词（上市公司）

## 概述

本提示词针对其他流动资产上市公司附注披露底稿（K2-note-listed）的复核，聚焦：按性质分类披露、流动性分类依据、合同取得成本披露、与审定表/明细表勾稽、CAS30 列报要求。其他流动资产是列报"筐类"科目，上市公司须按性质明细披露各构成项目（待摊费用、待抵扣进项税、预缴所得税、合同取得成本等），使报表使用者理解其构成，避免"其他"科目掩盖重大项目。

**法规依据：**
- 《企业会计准则第30号——财务报表列报》
- 《企业会计准则第14号——收入》
- 《公开发行证券的公司信息披露编报规则第15号——财务报告的一般规定》

---

## tips

1. **"筐类"科目须按性质明细披露**：其他流动资产须在附注中按性质列示各构成项目及金额（待摊费用/待抵扣进项税/预缴所得税/合同取得成本/待处理损益/其他），不得仅列总额，重大项目须单独列示。
2. **各项目合计须与审定表勾稽**：附注各项目期末数合计须等于审定表 K2-1 审定数，分类小计须与 K2-2 明细表对应合计一致，形成闭环。
3. **流动性分类依据须清晰**：列为其他流动资产须以"一年内摊销/抵扣/收回"为依据，超一年部分应在其他非流动资产披露，流动/非流动划分依据须说明。
4. **合同取得成本须单独披露（CAS14）**：合同取得成本的期末余额、本期摊销、减值须单独披露，摊销方法和摊销期须说明，与 K2-4/K2-5 数据一致。
5. **重大项目须结合业务说明**：金额重大或性质特殊的项目（如大额待抵扣进项税、大额预缴税费）须结合业务背景说明形成原因和预期实现方式。
6. **可比信息与变动分析**：附注须同时列示期末与期初可比数，重大变动须说明原因，避免其他流动资产异常波动无解释。

## checklist

### 一、分类明细披露

- [ ] 是否按性质明细披露各构成项目及金额
- [ ] 重大项目是否单独列示（非笼统"其他"）
- [ ] 各项目期末数合计是否等于审定表 K2-1 审定数
- [ ] 分类小计是否与 K2-2 明细表勾稽
- [ ] 是否同时列示期末与期初可比数

### 二、流动性与合同取得成本

- [ ] 流动性分类依据（一年内摊销/抵扣/收回）是否说明
- [ ] 超一年部分是否在其他非流动资产披露
- [ ] 合同取得成本期末余额/本期摊销/减值是否单独披露（CAS14）
- [ ] 合同取得成本摊销方法和摊销期是否说明并与 K2-4/K2-5 一致

### 三、变动与重大项目说明

- [ ] 重大项目形成原因和预期实现方式是否结合业务说明
- [ ] 其他流动资产重大变动是否说明原因
- [ ] 待抵扣进项税/预缴税费的可实现性是否有说明

## risk_areas

### 高风险

1. **重大项目未单独披露**：大额构成项目笼统归入"其他"，掩盖重大资产或长期挂账。
2. **附注总额与审定表不一致**：附注其他流动资产总额与 K2-1 审定数不符。
3. **合同取得成本未披露**：CAS14 合同取得成本未单独披露摊销和减值。

### 中风险

1. **流动性分类依据缺失**：未说明列为流动的依据，超一年项目未重分类披露。
2. **分类明细不足**：仅按大类披露未细分性质，信息不充分。

### 低风险

1. **可比信息缺失**：仅列期末数未列期初可比数。
2. **变动分析不足**：重大变动未说明原因。
3. **交叉索引不完整**：与 K2-1/K2-2/K2-4 的勾稽索引标注不全。
