# K6-2 持有待售明细表复核提示词

## 概述

本提示词针对持有待售明细表（K6-2，科目 1481 持有待售资产 / 2605 持有待售负债，取期末余额）的复核。明细表按处置组/单项资产逐项列示原账面价值、公允价值减去出售费用、账面价值（孰低后）、减值准备及期末账面价值，是审定表 K6-1 的数据基础。其数据质量直接影响审定数准确性、CAS42 分类判断、孰低计量减值的确认。核心风险为账面价值滚存与孰低计量错误、划分持有待售后未停止折旧摊销、以及明细合计与审定表不勾稽。

**法规依据：**
- 《企业会计准则第42号——持有待售的非流动资产、处置组和终止经营》
- 《企业会计准则第8号——资产减值》
- 《中国注册会计师审计准则第1301号——审计证据》

## tips

1. **账面价值滚存与孰低计量是明细表核心**：每项持有待售资产账面价值=划分时账面价值−累计减值（孰低差额），须验证公允价值减出售费用与账面价值孰低取值正确，减值列反映差额。
2. **明细合计必须向上勾稽审定表**：K6-2 各项账面价值合计（K6-2-detail-book-value-total）须与审定表 K6-1 资产审定合计及试算表 1481 审定余额三方一致；负债项与 2605 一致。
3. **划分持有待售后停止折旧摊销是明细表须验证的关键**：自划分为持有待售之日起，相关固定资产、无形资产、投资性房地产（成本模式）应停止计提折旧/摊销，明细表须反映该处理，未停止即多计费用少计资产。
4. **处置组须按组列示且区分资产与负债**：处置组包含的各项资产和直接相关负债应在明细表清晰列示，处置组整体孰低计量的减值须按顺序分摊（K6-6），明细表反映分摊结果。
5. **公允价值减出售费用须有估值依据**：每项资产的公允价值应有销售协议价、活跃市场报价或估值报告支撑，出售费用（中介费/税费/法律费用等）须合理估计，明细表须能追溯估值来源。
6. **期初数与上年衔接、新增/处置须有依据**：续存持有待售项目期初数须与上年审定期末数衔接；本期新划入的须有 CAS42 分类条件满足证据；本期处置/转出的须有处置协议或不再满足条件的评估。

## checklist

### 一、账面价值滚存与勾稽（高风险）

- [ ] 【必检】各项账面价值=划分时账面价值−累计减值 是否逐行成立
- [ ] 【必检】明细表资产账面价值合计是否与审定表 K6-1 资产审定合计一致
- [ ] 【必检】明细表账面价值合计是否与试算表 1481 审定余额一致
- [ ] 【必检】负债项合计是否与试算表 2605 及审定表 K6-1 负债审定合计一致
- [ ] 【必检】期初余额是否与上年审定期末数衔接
- [ ] 【条件检查：若为处置组】处置组内各项资产/负债是否清晰列示并区分

### 二、孰低计量与减值（高风险）

- [ ] 【必检】各项是否按账面价值与公允价值减出售费用孰低计量
- [ ] 【必检】公允价值是否有销售协议价/市场报价/估值报告支撑
- [ ] 【必检】出售费用估计是否合理（中介费/税费/法律费用等）
- [ ] 【必检】孰低产生的减值是否在明细表减值列足额反映
- [ ] 【必检】减值是否与 K6-5 减值测试、K11 资产减值损失勾稽
- [ ] 【风险检查】是否存在高估公允价值以规避减值确认

### 三、停止折旧摊销与后续计量（中风险）

- [ ] 【必检】划分持有待售后相关资产是否停止计提折旧/摊销
- [ ] 【必检】明细表是否反映了停止折旧摊销的处理
- [ ] 【条件检查：若公允价值后续回升】减值转回是否不超过原减值金额且处理恰当
- [ ] 【风险检查】是否存在划分持有待售后仍计提折旧（多计费用）

### 四、划入划出真实性（中风险）

- [ ] 【必检】本期新划入持有待售的项目是否有 CAS42 分类条件满足证据
- [ ] 【必检】本期处置/转出的项目是否有处置协议或重新计量依据
- [ ] 【风险检查】是否存在不满足条件的资产列入持有待售以规避减值/折旧

## risk_areas

### 高风险

1. **孰低计量错误、减值计提不足**：未按账面价值与公允价值减出售费用孰低计量，或高估公允价值/低估出售费用少提减值。
2. **滚存计算错误或与审定表/试算表不勾稽**：账面价值滚存不成立，或明细合计与 K6-1、试算表 1481/2605 存在无源差异。
3. **划分持有待售后未停止折旧摊销**：相关资产未停止计提折旧/摊销，多计费用少计资产。

### 中风险

1. **公允价值估值缺乏依据**：公允价值无销售协议、市场报价或估值报告支撑，减值计量可靠性存疑。
2. **处置组资产负债列示不清**：处置组内各项资产和负债未清晰区分列示，影响整体孰低计量和分摊。
3. **期初数与上年不衔接**：续存持有待售项目期初余额未核对上年底稿。
4. **减值转回处理不当**：公允价值回升时减值转回超过原减值金额或处理错误。

### 低风险

1. **格式与索引不规范**：明细表列序、金额单位、交叉索引标注不完整。
2. **项目说明不足**：各项持有待售资产缺少划分原因、预计出售时间、估值方法等辅助说明。
