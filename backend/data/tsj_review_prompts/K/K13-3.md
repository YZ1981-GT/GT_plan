# K13-3 营业外支出调整分录复核提示词

## 适用底稿
营业外支出调整分录汇总表（K13-3，科目 6711），含账项调整（AJE）、重分类调整（RJE），回写审定表 K13-1，并推送 A13 未调整错报汇总。

## 概述

K13-3 是营业外支出审定链路的关键环节。营业外支出调整通常源于漏计损失的补记、日常经营损失误计营业外支出的重分类、跨期损失的截止调整、税前扣除性重分类等。复核须验证：每笔调整有证据、借贷平衡、完整回写 K13-1、未采纳调整正确推送 A13 并与重要性水平比较；同时关注税前不可扣除项目的调整对所得税（N 循环）的联动影响。

**法规依据：**
- 《企业会计准则第28号——会计政策、会计估计变更和差错更正》
- 《企业会计准则第30号——财务报表列报》
- 《中国注册会计师审计准则第1301号——审计证据》
- 《中国注册会计师审计准则第1324号——期后事项》

## tips

1. **AJE vs RJE**：补记漏计损失、跨期损失截止调整影响损益属 AJE；营业外支出与营业成本/费用之间、或利润表行次间的重分类属 RJE，不得以 RJE 掩盖损益错报。
2. **每笔调整须有证据**：补记损失须有资产毁损报废证明、捐赠协议、判决书等支持；分类调整须有无关性判断依据。
3. **借贷平衡与科目正确**：核对借贷相等，且调整对手方科目正确（如营业外支出↔营业成本、营业外支出↔固定资产清理）。
4. **完整回写 K13-1**：每笔已确认调整金额须逐笔反映到审定表 K13-1 对应项目的 AJE/RJE 列。
5. **未采纳调整推送 A13**：管理层未接受的损失补记建议须作为未调整错报推送 A13，与重要性水平比较，关注对营业利润的影响。
6. **税前扣除性调整联动 N 循环**：涉及税前不可扣除项目（罚款、非公益捐赠）的调整须同步供 N 循环纳税调整，避免所得税费用错算。

## checklist

### 高风险检查项

- [ ] 所有损失补记 AJE 是否有充分证据支持（毁损证明/协议/判决）
- [ ] 每笔调整分录借贷方是否完全平衡
- [ ] 调整对手方科目是否正确（营业成本/固定资产清理/其他应付款等）
- [ ] 调整金额是否完整回写至 K13-1 审定表对应项目调整列
- [ ] 分类调整（营业外支出↔营业成本/费用）是否有无关性判断依据
- [ ] 涉及税前不可扣除项目的调整是否同步供 N 循环纳税调整
- [ ] 管理层未采纳的损失补记是否已推送 A13 未调整错报
- [ ] 未调整错报累计是否超过整体重要性水平（须评估对意见的影响）

### 中风险检查项

- [ ] RJE 是否仅涉及列报/重分类，未影响损益总额
- [ ] 跨期损失调整是否正确区分本期与前期差错更正
- [ ] 分类调整对营业利润的影响是否评估
- [ ] 调整原因说明是否可追溯至具体审计程序
- [ ] 调整分录编号是否连续，与 A13 交叉索引是否完整
- [ ] 建议调整与已执行调整是否分别记录

### 低风险检查项

- [ ] 分录摘要、科目编码是否规范
- [ ] 索引是否指向 K13-2 明细表及 K13-4 检查表
- [ ] 审计说明/结论是否概括调整性质与剩余风险

## risk_areas

### 高风险

1. **损失补记调整缺乏证据**：补记损失无毁损报废证明或协议判决支持，调整金额缺乏依据。
2. **审定表与 K13-3 调整不勾稽**：已确认调整未完整回写 K13-1。
3. **未采纳错报未推送 A13**：管理层拒绝的损失补记未纳入未调整错报汇总，累计可能超重要性水平。
4. **借贷不平衡或科目错配**：调整对手方科目错误或借贷不等。

### 中风险

1. **税前扣除性调整未联动 N 循环**：税前不可扣除项目调整未同步纳税调整，导致所得税费用错算。
2. **RJE 误含损益影响**：以重分类名义调整实际影响营业外支出总额。
3. **跨期调整分类错误**：本期损失与前期差错更正混淆。

### 低风险

1. **编号、格式不规范**。
2. **索引指向不完整**。

## 跨底稿勾稽

- K13-3 已确认 AJE/RJE 合计 ↔ K13-1 审定表调整列
- K13-3 未采纳错报 ↔ A13 未调整错报汇总
- 调整后审定数 ↔ 试算平衡表 6711 科目
- 税前不可扣除项目调整 ↔ N 循环递延所得税/所得税费用纳税调整
- 资产处置损失调整 ↔ 固定资产清理/H、I 资产处置底稿
