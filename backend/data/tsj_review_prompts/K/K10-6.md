# K10-6 其他收益检查表复核提示词

## 概述

本提示词针对其他收益凭证检查表（K10-6，科目 6117）的复核，聚焦样本选取方法合理性、记账凭证与政府批文/到账凭证核对完整性、检查比例达标性、异常事项标注充分性。检查表以逐笔凭证核对验证其他收益的发生、准确性和计入科目正确性，核对链条覆盖批文/协议→到账凭证→记账凭证→计入科目判断。其他收益为损益类贷方科目，重点核查本期贷方发生额。核心风险为无依据确认、计入科目错误、跨期确认。

**法规依据：**
- 《中国注册会计师审计准则第1314号——审计抽样》
- 《企业会计准则第16号——政府补助》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **样本选取匹配风险**：大额补助、新增补助项目、期末临近确认的其他收益应作必选样本全覆盖，其余合理抽样；损益类重点核查本期贷方发生额的检查比例。
2. **核对链条完整**：其他收益凭证核对须覆盖 批文/协议（文号、金额、用途）→ 到账凭证（银行回单）→ 记账凭证（确认时点、科目、金额）→ 计入科目判断（是否与日常活动相关）。
3. **计入科目核查**：重点核查凭证对应补助是否确与日常活动相关（应计其他收益），是否存在与日常活动无关的补助误计其他收益（应营业外收入）。
4. **检查比例达标**：检查比例=已检查金额÷本期发生额（6117 贷方），须达到计划水平；损益类科目主要核查贷方检查比例。
5. **异常标注充分**：金额异常（到账≠入账）、时间异常（期末突击确认）、依据异常（批文缺失/用途不符）、科目异常（营业外性质计其他收益）须标注异常类型及初步判断。
6. **闭环**：K10-6 抽样结果 ↔ K10-2 明细逐笔 ↔ K10-4 政府补助核对 ↔ 批文/到账凭证；异常发现推送 K10-3 调整及 A13 错报汇总。

## checklist

### 一、样本选取合理性（高风险）

- [ ] 样本选取方法是否与其他收益重大错报风险相匹配
- [ ] 大额补助、新增补助项目是否纳入必选样本全覆盖
- [ ] 抽样方法是否符合 CAS1314 要求（统计/非统计选择有据）
- [ ] 抽样总体是否完整（从完整补助明细导出，未人为排除）
- [ ] 【风险检查】是否存在仅抽查规范项目而遗漏可疑确认

### 二、凭证核对完整性（高风险）

- [ ] 每笔样本是否有政府批文/协议（文号、金额、用途）
- [ ] 到账凭证（银行回单）金额、日期是否与入账一致
- [ ] 记账凭证确认时点、科目、金额是否恰当
- [ ] 计入其他收益是否确与日常活动相关（非营业外性质）
- [ ] 确认时点是否恰当（收到/满足条件时确认，无跨期）
- [ ] 【风险检查】是否存在无批文/未到账即确认其他收益

### 三、检查比例与异常标注（中风险）

- [ ] 检查比例（已检查金额÷本期贷方发生额）是否达到计划水平
- [ ] 异常交易是否全部标注异常类型及初步判断
- [ ] 到账金额与入账金额差异是否逐笔追踪解释
- [ ] 【条件检查：若期末集中确认】是否实施截止性核查
- [ ] 抽样参数、选取过程、核对结果记录是否完整可追溯

## risk_areas

### 高风险

1. **无依据确认**：无政府批文或资金未到账即确认其他收益，虚增经营利润。
2. **计入科目错误**：与日常活动无关补助误计其他收益（应营业外收入），扭曲经营利润列报。
3. **样本选取偏差**：仅抽查规范项目，遗漏可疑确认或大额补助，样本不具代表性。
4. **跨期确认**：期末突击确认补助或将下期补助提前计入本期。

### 中风险

1. **检查比例不足**：实际检查比例低于计划水平，审计证据不充分。
2. **截止核查不到位**：未针对期末集中确认的其他收益实施截止测试。
3. **异常标注不充分**：金额/时间/依据/科目异常未标注异常类型。

### 低风险

1. **记录不完整**：抽样参数、核对结果的工作底稿记录不完整。
2. **索引缺失**：与 K10-1/K10-2/K10-4 及批文凭证的交叉索引不完整。
