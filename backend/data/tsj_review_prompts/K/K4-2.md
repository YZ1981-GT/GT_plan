# K4-2 其他流动负债明细表复核提示词

## 概述

本提示词针对其他流动负债明细表（K4-2，科目 2245，负债类贷方，期末余额=期初+贷方−借方）的复核，聚焦：项目构成完整性、与审定表 K4-1 的余额勾稽、流动性分类正确性、待转销项税额与预提费用核对。其他流动负债是列报"筐类"负债科目，主要由待转销项税额、预提费用、短期应付债券、一年内到期的其他非流动负债等构成。负债类首要认定是"完整性"，明细表须完整反映各项应付义务，为检查表（K4-4）和流动性重分类提供基础。

**法规依据：**
- 《企业会计准则第30号——财务报表列报》
- 《企业会计准则第13号——或有事项》（涉及预提费用/预计负债边界）
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **完整性是负债类明细表的首要认定**：其他流动负债须完整反映各项应付义务（待转销项税额、预提费用、短期应付债券等），警惕预提不足或应转销项税额漏挂，完整性缺失将低估负债。
2. **与审定表 K4-1 勾稽是余额准确性根基**：明细表各项目期末余额合计（勾稽键 K4-2-detail-total）须等于审定表 K4-1 期末审定数，期初须与上年审定数衔接，负债类期末=期初+贷方−借方（方向与资产类相反）。
3. **项目性质分类完整**：每个项目须标注性质（待转销项税额/预提费用/短期应付债券/一年内到期非流动负债/其他），性质决定计量、披露分类和流动性判断。
4. **待转销项税额须核对纳税义务**：待转销项税额（如已开票未确认收入对应的销项税）须与收入确认和增值税纳税义务衔接，转销时点与收入确认时点匹配，避免长期挂账或提前/滞后转销。
5. **预提费用须评估合理性**：预提费用是否有明确的应付义务和可靠估计（区别于预计负债），预提是否充分（预提不足低估负债）或过度（预提过度调节利润）。
6. **流动性分类须准确**：一年内到期的其他非流动负债转入本科目须准确，超一年部分不应列入其他流动负债，明细表是下游检查表（K4-4）和披露的数据源。

## checklist

### 一、项目构成完整性

- [ ] 明细表是否完整反映各项应付义务（无遗漏未入账负债）
- [ ] 每个项目是否标注性质（待转销项税额/预提费用/短期应付债券/一年内到期/其他）
- [ ] 项目名称是否完整规范，无笼统"其他"归集
- [ ] 是否存在应列应交税费/预计负债等而错分至其他流动负债

### 二、余额准确性与勾稽

- [ ] 明细表各项目期末余额合计（K4-2-detail-total）是否等于审定表 K4-1 审定数
- [ ] 明细表期初余额是否与上年审定期末数衔接
- [ ] 各项目余额计算是否正确（期初+贷方−借方=期末，负债类方向）
- [ ] 明细数据是否来自科目余额表/序时账，未经人工调整

### 三、性质核对与流动性

- [ ] 待转销项税额是否与收入确认和增值税纳税义务衔接
- [ ] 待转销项税额转销时点是否与收入确认时点匹配
- [ ] 预提费用是否有明确应付义务和可靠估计（预提是否充分/过度）
- [ ] 一年内到期的其他非流动负债转入是否准确
- [ ] 超一年部分是否未列入其他流动负债（流动性分类正确）

## risk_areas

### 高风险

1. **隐瞒负债（完整性缺失）**：预提不足、待转销项税额漏挂或应付义务遗漏，低估负债。
2. **明细与审定表不勾稽**：明细合计（K4-2-detail-total）与 K4-1 审定数存在差异未调节。
3. **待转销项税额转销错配**：转销时点与收入确认不匹配，长期挂账或提前/滞后转销扭曲损益与纳税。

### 中风险

1. **预提费用过度/不足**：预提缺乏明确义务或估计不可靠，调节利润或低估负债。
2. **流动性分类错误**：超一年项目错列入其他流动负债，或一年内到期转入不准。

### 低风险

1. **明细表格式不规范**：项目排序、性质标注、金额单位不统一。
2. **项目性质错分**：应列其他科目的负债错分影响披露分类。
3. **交叉索引不完整**：与 K4-4 及审定表的交叉引用标注不全。
