# K8-1 销售费用审定表复核提示词

## 概述

本提示词针对销售费用审定表（K8-1，科目 6601，损益类借方，取本期发生额而非余额）的复核，聚焦：发生额勾稽（未审→调整→审定）、试算平衡表核对、审计调整完整性、费用分类与截止准确性。销售费用属损益类，主要错报风险是"完整性（少计/跨期少记）"与"分类（资本化/错分至管理费用）"，审定表是发生额审定与调整的枢纽。

**法规依据：**
- 《企业会计准则第30号——财务报表列报》
- 《中国注册会计师审计准则第1301号——审计证据》
- 《中国注册会计师审计准则第1141号——财务报表审计中与舞弊相关的责任》

---

## tips

1. **销售费用取"发生额"非"期末余额"**：审定数=本期借方发生额−贷方（红冲/结转）±审计调整，切勿按余额口径核对，试算平衡表核对亦应对发生额。
2. **发生额勾稽是审定表生命线**：审定合计=未审发生额+账项调整(AJE)+重分类调整(RJE)，且必须等于明细表 K8-2 审定合计，差异须追溯至具体调整或明细遗漏。
3. **完整性是损益费用的首要风险**：关注期末前后的费用是否足额计提、有无将本期费用递延至下期以虚增利润（截止），审定表应体现所有已确认的补提调整。
4. **分类准确性影响利润结构**：销售费用与管理费用、销售费用与营业成本、费用化与资本化的边界须清晰，错分虽不影响利润总额但影响费用结构与毛利率分析。
5. **审定表是跨底稿勾稽中心**：审定合计↔K8-2 明细合计↔试算表 6601 审定发生额↔利润表"销售费用"行应形成闭环，任一节点断裂为复核重点。
6. **关注变动率异常行**：某费用项目本期较上期变动超 30% 或与营业收入变动明显背离时，须追溯原因并评估是否存在少计/多计或跨期。

## checklist

### 一、发生额勾稽与试算表核对

- [ ] 审定表各项目审定数=未审发生额+AJE+RJE，逐行计算是否正确
- [ ] 审定表审定合计是否与明细表 K8-2 审定合计一致
- [ ] 审定表审定合计是否与试算平衡表 6601 科目审定发生额一致
- [ ] 未审发生额是否与试算表 6601 未审发生额（借方−贷方）一致
- [ ] 是否按发生额口径核对（未误用期末余额）
- [ ] 上期审定数是否与上年审定底稿一致（可比性）

### 二、审计调整完整性

- [ ] 所有已确认的账项调整（AJE，如补提费用）是否完整反映在审定表
- [ ] 所有重分类调整（RJE，如从管理费用重分类）是否完整反映
- [ ] 调整分录借贷是否平衡，是否有充分证据与合伙人审批
- [ ] 建议未调整的错报是否记入未调整错报汇总表（SUD）

### 三、分类与截止

- [ ] 各费用明细项目分类是否正确（运输费/广告费/职工薪酬/差旅费等）
- [ ] 是否存在应计入营业成本或管理费用的项目错分至销售费用
- [ ] 是否存在应资本化（如长期待摊）项目费用化或反之
- [ ] 资产负债表日前后的费用是否记入恰当会计期间（截止）
- [ ] 关联方承担/分摊的销售费用是否单独识别、定价公允

## risk_areas

### 高风险

1. **费用完整性缺失**：期末应计未计销售费用（如未开票的运输费/佣金），导致费用少计、利润虚增。
2. **跨期调节利润**：将本期销售费用递延至下期或将下期费用提前，通过截止操纵当期利润。
3. **审计调整遗漏**：已确认的补提/重分类调整未纳入审定表，审定数失真。
4. **审定表与试算表/明细表不勾稽**：三者发生额口径不一致，存在汇总错误或调整遗漏。

### 中风险

1. **费用错分类**：销售费用与管理费用/营业成本边界不清，影响费用结构与毛利分析。
2. **关联方费用分摊不公允**：关联方承担的销售费用分摊比例不合理，存在利益输送。
3. **变动异常未解释**：费用项目大幅变动与收入变动背离但未分析原因。

### 低风险

1. **审定表格式与索引不规范**：行项目顺序、交叉索引不完整，影响复核效率。
2. **辅助说明不足**：变动较大项目未附简要说明。
