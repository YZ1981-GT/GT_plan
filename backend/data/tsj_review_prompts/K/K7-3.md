# K7-3 递延收益调整分录复核提示词

## 概述

本提示词针对递延收益调整分录汇总表（K7-3，科目 2401）的复核，含账项调整（AJE）、重分类调整（RJE）及未调整错报评估。递延收益调整常见于摊销金额纠正、分类错误重分类（与资产/收益相关互调）、一年内摊销部分重分类、总额法/净额法调整。复核须验证：每笔调整有批文/测算依据、借贷平衡、完整回写至审定表 K7-1、并与未更正错报汇总（A13）交叉验证。核心风险为调整缺乏依据、审定数遗漏、错报累计超阈值未恰当处理。

**法规依据：**
- 《企业会计准则第16号——政府补助》
- 《企业会计准则第28号——会计政策、会计估计变更和差错更正》
- 《中国注册会计师审计准则第1301号——审计证据》

## tips

1. **AJE vs RJE**：AJE 影响递延收益金额或损益（如补提/冲回摊销）；RJE 仅影响列报（如一年内到期部分重分类、与资产/收益相关重分类），不得通过 RJE 掩盖摊销损益错报。
2. **与 K7-1 勾稽**：审定表调整列金额须与 K7-3 已确认分录逐笔一致，遗漏任一笔即审定数失真。
3. **调整依据充分性**：每笔调整须有政府批文、摊销测算表（K7-4）或管理层确认支持，摊销纠正须能追溯到具体项目和期限。
4. **错报累计评估**：未调整的递延收益/摊销错报单独及累计是否超过整体/明细层次重要性水平，须与 A13 未更正错报汇总交叉验证并推送。
5. **跨期调整区分**：区分本期摊销纠正与前期差错更正（CAS28），前者调本期损益、后者可能追溯调整期初留存收益，会计处理与披露不同。
6. **TB 回写与联动**：确认调整已同步试算平衡表 2401 及对应损益科目（其他收益 6117/营业外收入 6301），避免「底稿已调、TB 未更」双真源。

## checklist

### 一、调整依据与授权（高风险）

- [ ] 每笔 AJE 是否有充分依据（批文、K7-4 摊销测算、管理层确认）
- [ ] 调整是否经适当层级审批（超重要性水平须合伙人知悉）
- [ ] 摊销纠正是否可追溯至具体补助项目及摊销期限
- [ ] 是否存在仅为平滑利润或规避亏损的不当调整
- [ ] 【风险检查】是否存在无依据补提/冲回递延收益摊销

### 二、平衡性与审定表勾稽（高风险）

- [ ] 每笔调整分录借贷方是否完全平衡
- [ ] 调整金额是否完整反映到 K7-1 审定表对应调整列
- [ ] AJE 对应损益科目（其他收益 6117/营业外收入 6301）是否正确
- [ ] 调整后审定数是否与试算表 2401 一致
- [ ] 【条件检查：若涉及一年内到期】重分类金额是否与流动性划分一致

### 三、分类、跨期与错报评估（中风险）

- [ ] RJE 是否仅涉及列报（一年内到期/与资产收益相关重分类），未影响损益
- [ ] 跨期调整是否正确区分本期摊销纠正与前期差错更正
- [ ] 未调整错报累计是否超过重要性水平，是否推送 A13 未更正错报汇总
- [ ] 调整原因说明是否清晰可追溯至具体审计程序
- [ ] 调整分录编号是否连续，与 K7-2/K7-4 索引是否完整

## risk_areas

### 高风险

1. **调整缺乏依据或未授权**：补提/冲回摊销无批文或测算支持，或超重要性调整未经审批。
2. **审定表与 K7-3 不一致**：调整金额未完整回写 K7-1，审定数失真。
3. **错报累计超阈值未处理**：递延收益/摊销未更正错报累计超整体重要性水平仍出具无保留意见。

### 中风险

1. **RJE 误含损益影响**：重分类调整实质影响了摊销损益。
2. **跨期调整分类错误**：本期摊销纠正误作前期差错更正（或反之），会计处理与披露错误。
3. **TB 未同步**：调整仅在底稿反映，试算表 2401 及损益科目未更新。

### 低风险

1. **编号、格式不规范**：调整分录编号、摘要、科目编码不规范。
2. **索引不完整**：与 K7-1/K7-2/K7-4/A13 的交叉索引缺失。
