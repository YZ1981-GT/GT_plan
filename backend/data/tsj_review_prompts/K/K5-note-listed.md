# K5-note-listed 预计负债附注披露复核提示词（上市公司）

## 概述

本提示词针对预计负债上市公司附注披露底稿（K5-note-listed，科目 2701）的复核。聚焦上市公司财务报表附注中预计负债相关披露的充分性和准确性：按类别（产品质量保证、未决诉讼、亏损性合同、重组义务、担保等）分类披露、期初期末变动情况、CAS13 要求的确认依据和预期支出时间说明、以及未确认或有负债的披露。上市公司预计负债与或有事项披露是投资者评估潜在风险敞口的关键信息，披露不充分或隐瞒重大或有负债将严重误导决策。

**法规依据：**
- 《企业会计准则第13号——或有事项》
- 《企业会计准则第30号——财务报表列报》
- 《公开发行证券的公司信息披露编报规则第15号——财务报告的一般规定》
- 《中国注册会计师审计准则第1501号——对财务报表形成审计意见和出具审计报告》

## tips

1. **预计负债须按类别分项披露变动情况**：附注须按产品质量保证、未决诉讼、重组义务、亏损性合同、担保等类别分别列示期初余额、本期增加（计提）、本期减少（使用/转回）和期末余额，各类别变动合计须与审定表 K5-1 及明细表 K5-2 勾稽。
2. **每类预计负债须披露确认依据和不确定性**：CAS13 要求披露预计负债形成的原因、预期支出的时间、金额的不确定性以及导致不确定性的因素，笼统披露金额而无形成原因和不确定性说明属披露不充分。
3. **或有负债的披露是重点也是易漏点**：未达到确认条件但达到披露标准的或有负债（如未决诉讼、担保、其他潜在义务）须披露其形成原因、预计财务影响、获得补偿的可能性，隐瞒或有负债是重大披露缺陷。
4. **未决诉讼披露须与法律意见一致**：附注中未决诉讼的进展、金额、可能性判断须与律师函（A 循环）结论一致，重大诉讼须单独披露案由、金额、进展和公司应对措施。
5. **重组义务披露须说明计划进展**：涉及重组预计负债的，须披露重组计划的性质、涉及的业务/区域、预计完成时间和已发生/预计发生的支出。
6. **附注数据须与审定表/明细表形成闭环勾稽**：附注中预计负债期末余额总额=审定表 K5-1 审定数=试算表 2701 审定余额；各类别期末余额=明细表 K5-2 对应类别余额；本期变动=K5-2 计提/使用/转回。

## checklist

### 一、分类与变动披露

- [ ] 预计负债是否按类别（质保/诉讼/亏损合同/重组/担保等）分项披露
- [ ] 各类别是否完整列示期初余额、本期增加、本期减少、期末余额
- [ ] 各类别变动合计是否与明细表 K5-2 勾稽
- [ ] 预计负债披露总额是否与审定表 K5-1 审定数一致
- [ ] 是否同时列示期末数和期初数（可比信息）
- [ ] 本期计提/转回的重大变动是否有原因说明

### 二、确认依据与不确定性披露（CAS13）

- [ ] 每类预计负债是否披露形成原因
- [ ] 是否披露预期支出的时间（一年内/一年以上）
- [ ] 是否披露金额的不确定性及导致不确定性的因素
- [ ] 影响重大的长期预计负债是否披露折现相关信息（折现率/摊销）
- [ ] 是否披露预期可获得的补偿及确认为资产的金额（如有）
- [ ] 产品质量保证是否披露计提基础（历史赔付率/销售规模）

### 三、未决诉讼与重大事项披露

- [ ] 重大未决诉讼/仲裁是否单独披露案由、涉及金额、进展和可能性
- [ ] 诉讼披露的可能性判断是否与律师函（A 循环）结论一致
- [ ] 重组预计负债是否披露重组计划性质、范围、预计完成时间和支出
- [ ] 亏损性合同是否披露合同性质和预计损失金额
- [ ] 期后诉讼/事项重大进展是否披露（CAS1318）

### 四、或有负债披露

- [ ] 未达确认条件但达披露标准的或有负债是否充分披露
- [ ] 或有负债是否披露形成原因、预计财务影响、可能性
- [ ] 对外担保形成的或有负债是否披露担保对象、金额、期限
- [ ] 是否披露获得补偿的可能性（如反担保、连带责任分摊）
- [ ] 极小可能的或有负债是否恰当地未披露（避免信息过载）

## risk_areas

### 高风险

1. **重大或有负债隐瞒未披露**：达到披露标准的未决诉讼、担保、潜在赔偿等或有负债未在附注披露，严重误导投资者对风险敞口的判断。
2. **附注总额与审定表不勾稽**：附注预计负债期末余额与审定表 K5-1、试算表 2701 不一致，属数据勾稽重大错误。
3. **诉讼披露与法律意见不一致**：附注中诉讼可能性/金额判断与律师函结论矛盾，或重大不利诉讼未披露。
4. **确认依据和不确定性未披露**：仅披露预计负债金额而无形成原因、支出时间和不确定性说明，不满足 CAS13 强制披露要求。

### 中风险

1. **分类披露不完整**：预计负债仅按总额披露，未按质保/诉讼/重组等类别分项列示变动情况。
2. **重组/亏损合同披露不足**：重组计划进展或亏损合同性质未充分说明。
3. **可比信息缺失**：附注仅列示期末数据，未列示期初可比数据。
4. **补偿资产处理不当**：预期补偿在附注中直接冲减预计负债而非单独确认为资产披露。

### 低风险

1. **披露格式不完全规范**：表格标题、列序、金额单位等格式细节未严格按编报规则，但信息实质完整。
2. **文字描述模板化**：或有事项说明照搬准则原文，未结合本企业实际情况针对性说明。
3. **不确定性因素说明简略**：披露了不确定性但对导致不确定性的具体因素说明不足。
