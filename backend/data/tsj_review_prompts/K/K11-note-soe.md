# K11-note-soe 资产减值损失附注披露复核提示词（国有企业）

## 概述

本提示词针对资产减值损失国有企业附注披露底稿（K11-note-soe，科目 6701，损益类）的复核。在满足企业会计准则通用披露（按资产类别分项、6701 与 6702 分列、商誉减值测试披露）基础上，聚焦国有企业特定要求：资产减值损失对国有资本保值增值的影响、重大减值的"三重一大"决策程序、减值损失责任追究、以及财务决算报告的补充披露。国有企业资产减值既是财务事项，也是国有资产监管关注的资产质量事项。

**法规依据：**
- 《企业会计准则第8号——资产减值》
- 《企业会计准则第30号——财务报表列报》
- 《企业会计准则第37号——金融工具列报》
- 《企业国有资产法》
- 《中央企业财务决算报告管理办法》
- 《会计监管风险提示第8号——商誉减值》

## tips

1. **国企附注"双层"披露**：既满足 CAS 通用分项披露（按资产类别、6701 与 6702 分列），又满足国资委财务决算报告对资产质量与减值的补充披露要求。
2. **减值损失影响国有资本保值增值**：重大资产减值损失须说明对当期利润及国有资本保值增值率的影响，长期资产大额减值可能触发国有资产质量预警。
3. **重大减值须"三重一大"决策**：超过规定金额标准的资产减值（尤其商誉、长期股权投资减值）须经"三重一大"集体决策，附注应披露决策程序与审批情况。
4. **减值与责任追究挂钩**：因经营决策失误导致的重大资产减值（如投资减值、存货积压跌价），须说明是否启动国有资产损失责任追究程序。
5. **商誉减值披露同样受监管风险提示约束**：国企商誉减值须披露资产组划分、可收回金额方法及关键假设，且并购形成的商誉减值可能涉及并购决策责任。
6. **附注数据与审定表/明细表/决算报表闭环**：附注分项本期计提额=K11-2 明细净发生额=各资产减值底稿=利润表资产减值损失行=财务决算报表相应数据。

## checklist

### 一、基础披露完整性（与上市版共有）

- [ ] 资产减值损失是否按资产类别完整分项列示本期计提额
- [ ] 资产减值损失（6701）与信用减值损失（6702）是否分行分项披露
- [ ] 各分项合计是否等于利润表资产减值损失行及审定表 K11-1 审定合计
- [ ] 是否同时披露本期数与上期可比数
- [ ] 各分项是否与 K11-2 明细表及各资产减值底稿勾稽
- [ ] 商誉减值是否披露资产组划分、可收回金额方法及关键假设

### 二、国有资产监管相关披露

- [ ] 重大资产减值损失对国有资本保值增值率的影响是否说明
- [ ] 长期资产（固定资产/无形资产/长投）大额减值是否披露形成原因
- [ ] 存货大额跌价（积压/滞销）是否披露原因及处置计划
- [ ] 减值是否涉及国有资产质量预警或不良资产认定
- [ ] 减值损失是否纳入年度经营业绩考核相关披露

### 三、决策程序与责任追究（国企特定）

- [ ] 超过规定金额的重大减值是否经"三重一大"集体决策并披露
- [ ] 商誉/长投减值是否披露决策过程及审批情况
- [ ] 因决策失误导致的重大减值是否说明责任追究程序启动情况
- [ ] 并购形成商誉的减值是否说明与并购决策的关联
- [ ] 减值测试的关键假设是否经内部审核并留痕

### 四、决算报表特殊要求

- [ ] 资产减值损失数据是否与年度财务决算报表一致
- [ ] 决算报表资产质量分析表中的减值数据是否与本附注一致
- [ ] 属于"不良资产"减值的部分是否按决算要求单独披露
- [ ] 集团合并层面减值抵销/汇总是否完整
- [ ] 减值不可转回（商誉/长期资产）是否体现于披露且无违规转回

### 五、与上市版的差异关注点

- [ ] 是否在基础分项披露之上增加了国资监管层面补充信息
- [ ] 是否增加了国有资本保值增值影响分析
- [ ] 是否增加了"三重一大"决策程序说明
- [ ] 是否增加了减值责任追究相关披露
- [ ] 是否增加了资产处置/清理计划信息

## risk_areas

### 高风险

1. **6701 与 6702 混列披露**：金融资产预期信用损失并入资产减值损失，违反利润表分列要求。
2. **重大减值未经"三重一大"决策**：超限额减值（尤其商誉、长投）未经集体决策或未披露决策过程，存在合规风险。
3. **商誉减值披露不充分**：未披露资产组、可收回金额方法及关键假设，不满足监管风险提示要求。
4. **减值分项与决算/审定表不勾稽**：附注减值数据与财务决算报表或 K11-1 审定合计不一致。

### 中风险

1. **国有资本保值增值影响未说明**：重大减值对保值增值率的影响缺乏定量分析。
2. **责任追究信息缺失**：因决策失误的重大减值未说明是否启动责任追究程序。
3. **减值不可转回体现不当**：附注出现商誉/长期资产减值违规转回。
4. **决算与审计口径差异未调节**：财务决算减值数据与审计后附注存在差异未调节说明。

### 低风险

1. **披露格式未完全按决算模板**：附注格式与国资委决算报表模板有细微差异。
2. **减值原因说明过于简略**：仅列金额未结合国企资产实际说明减值成因。
