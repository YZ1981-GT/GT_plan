# K3-note-soe 其他应付款附注披露复核提示词（国有企业）

## 概述

本提示词针对其他应付款国有企业附注披露底稿（K3-note-soe）的复核，聚焦：基础分类/账龄披露（与上市版共有）、国有资产监管相关披露、关联方（含同受国有控制单位）资金往来、长期挂账处理、决算报表口径一致。国有企业其他应付款审计具双重属性（财务审计+国资监管），须在 CAS30/CAS36 通用披露基础上，叠加国资委财务决算对负债完整性、长期挂账和资金占用管理的额外要求。

**法规依据：**
- 《企业会计准则第30号——财务报表列报》
- 《企业会计准则第36号——关联方披露》
- 《企业国有资产法》
- 《中央企业财务决算报告管理办法》

---

## tips

1. **国企附注"双层"披露要求**：既满足 CAS30/CAS36 通用披露（分类/账龄/大额/关联方），又满足国资委财务决算对负债完整性和资金占用的额外要求。
2. **关联方范围扩展至"同受国有控制"单位**：其他应付款关联方须考虑同一国有控股股东控制的兄弟单位间资金往来，可依准则豁免条款简化部分披露但须符合条件。
3. **资金占用双向须披露**：其他应付款反映本单位占用他方资金（或他方向本单位拆入），须单独说明占用方向、金额、性质和占用费，防止掩盖国有企业间资金调度。
4. **长期挂账处理须披露**：长期挂账其他应付款须披露是否仍需支付、处理计划；确认无需支付转营业外收入的须说明依据和决策程序（大额涉"三重一大"）。
5. **负债完整性是国资监管关注点**：其他应付款须完整反映应付义务，隐瞒负债将影响国有企业经营业绩和资产负债真实性，与未入账负债搜索结论一致。
6. **决算口径一致**：附注数据须与年度财务决算报表一致，与上市版差异主要在国资监管层面而非准则层面。

## checklist

### 一、基础披露完整性（与上市版共有）

- [ ] 是否按性质分类披露，合计是否等于审定表 K3-1 审定数
- [ ] 账龄披露是否完整（含3年以上），大额/超一年款项是否披露原因
- [ ] 是否同时列示期末与期初可比数
- [ ] 分类/账龄小计是否与 K3-2 明细表勾稽
- [ ] 附注是否完整反映全部其他应付款义务（负债完整性）

### 二、国有资产监管披露

- [ ] 与其他国企/政府的资金往来是否单独说明（占用方向/金额/性质/占用费）
- [ ] 长期挂账其他应付款是否披露是否仍需支付及处理计划
- [ ] 确认转营业外收入的长期挂账是否说明依据及决策程序（"三重一大"）
- [ ] 涉及财政性资金的其他应付款是否单独披露

### 三、关联交易与决算口径

- [ ] 与控股股东及关联企业的其他应付款是否逐户列示
- [ ] 与同一母公司控制的其他国企往来是否披露（豁免条款适用是否合规）
- [ ] 附注数据是否与年度财务决算报表一致
- [ ] 大额资金往来是否穿透说明性质

## risk_areas

### 高风险

1. **隐瞒负债**：其他应付款未完整反映应付义务，与未入账负债搜索结论不符，低估负债、虚增业绩。
2. **国企间资金调度未披露**：与其他国企/政府资金往来未单独说明方向和性质。
3. **长期挂账转销缺程序**：大额长期挂账转营业外收入未说明"三重一大"决策程序。
4. **基础披露与审定表不勾稽**：附注各维度合计与 K3-1 审定数不一致。

### 中风险

1. **关联方范围遗漏**：未将同受国有控制的兄弟单位纳入关联方披露。
2. **豁免条款适用不当**：不符合条件却简化同受国有控制关联方披露。
3. **长期挂账未说明处理计划**：长期挂账未说明是否仍需支付及处理安排。

### 低风险

1. **披露格式未按决算模板**：与国资委决算报表模板有细微格式差异。
2. **决算口径差异未调节**：决算数据与审计后附注数据差异未编制调节说明。
3. **交叉索引不完整**：与 K3-1/K3-2/K3-4/K3-6 及决算报表的勾稽索引不全。
