# K10-4 政府补助核对表复核提示词

## 概述

本提示词针对政府补助核对表（K10-4，科目 6117/2401/6301）的复核，聚焦政府补助的批文/到账核对、总额法与净额法选择、以及计入科目判断（其他收益 vs 营业外收入 vs 冲减成本费用/资产）。核对表汇总本期全部政府补助，逐项核对批准文号、到账凭证、与日常活动相关性、核算方法及列报去向，是判断其他收益（K10）、递延收益（K7）、营业外收入（K12）分类正确性的枢纽底稿。核心风险为核算方法选择错误、计入科目判断错误、补助完整性缺失。

**法规依据：**
- 《企业会计准则第16号——政府补助》
- 《企业会计准则第30号——财务报表列报》
- 《中国注册会计师审计准则第1301号——审计证据》

## tips

1. **批文与到账双重核对**：每笔补助须同时具备政府批准文件（文号、金额、用途、附加条件）和实际到账凭证（银行回单），两者金额、日期须匹配。
2. **总额法 vs 净额法**：总额法将补助全额计入其他收益/营业外收入或递延收益；净额法冲减相关资产账面价值或成本费用——方法选择须恰当（通常总额法，与资产直接相关成本补偿可净额法）且前后一致。
3. **计入科目三分判断**：与日常活动相关→其他收益（6117）；与日常活动无关→营业外收入（6301）；与资产/未来费用相关→先计递延收益（2401）分期结转——核对表须对每笔补助明确列报去向。
4. **日常活动相关性判断**：判断依据为补助是否与企业日常经营活动直接相关（如与销售/生产相关的即征即退、稳岗补贴属其他收益；与主营无关的一次性奖励属营业外收入）。
5. **完整性交叉核对**：核对表补助总额应与政府补助台账、银行到账记录、纳税申报（退税类）交叉核对，防止漏计。
6. **闭环勾稽**：核对表→计入其他收益部分=K10-2/K10-1；计入递延收益部分=K7-2；计入营业外收入部分=K12；净额法冲减部分不进损益类补助合计。

## checklist

### 一、批文与到账核对（高风险）

- [ ] 每笔补助是否有政府批准文件（文号、金额、用途、附加条件）
- [ ] 到账凭证（银行回单）金额、日期是否与批文及入账一致
- [ ] 是否存在无批文或未到账即确认的补助
- [ ] 退税类补助（即征即退/先征后返）是否与纳税申报勾稽
- [ ] 【风险检查】是否存在虚构补助或将其他资金伪装成补助

### 二、核算方法与计入科目判断（高风险）

- [ ] 总额法/净额法选择是否恰当且前后一致
- [ ] 每笔补助计入科目判断是否正确（其他收益/营业外收入/递延收益/冲减）
- [ ] 与日常活动相关性判断是否有充分依据
- [ ] 与资产相关补助是否计递延收益分期结转（非一次计入损益）
- [ ] 与成本费用直接相关的净额法补助是否恰当冲减
- [ ] 【风险检查】是否存在将营业外性质补助计其他收益虚增经营利润

### 三、完整性与勾稽（中风险）

- [ ] 核对表补助总额是否与政府补助台账、银行到账交叉核对一致
- [ ] 计入其他收益部分是否与 K10-2/K10-1 一致
- [ ] 计入递延收益部分是否与 K7-2 一致
- [ ] 计入营业外收入部分是否与 K12 一致
- [ ] 是否存在漏计已到账补助
- [ ] 非经常性损益标识是否正确（供上市披露）

## risk_areas

### 高风险

1. **核算方法错误**：应总额法却净额法（或反之），或同类补助前后方法不一致，影响损益与资产列报。
2. **计入科目判断错误**：与日常活动无关补助计其他收益（应营业外收入），或与资产相关补助一次计入损益（应递延），扭曲经营利润。
3. **补助完整性缺失**：漏计已到账补助或无批文提前确认，影响损益准确性和完整性。

### 中风险

1. **日常活动相关性判断依据不足**：其他收益/营业外收入划分缺乏充分判断依据。
2. **退税类补助勾稽不到位**：即征即退等未与纳税申报交叉核对。
3. **跨底稿分类不一致**：核对表列报去向与 K7/K10/K12 底稿不勾稽。

### 低风险

1. **格式与索引不规范**：核对表项目、单位、交叉索引不统一。
2. **补助附加条件说明不足**：用途限定、返还条款等辅助说明缺失。
