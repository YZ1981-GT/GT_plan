# K5-note-soe 预计负债附注披露复核提示词（国有企业）

## 概述

本提示词针对预计负债国有企业附注披露底稿（K5-note-soe，科目 2701）的复核。聚焦国有企业特定的预计负债披露要求：在满足 CAS13 通用披露的基础上，增加国有资产监管相关披露（重大诉讼/担保的"三重一大"决策、重大或有负债对国有资本的影响、重组义务与预算的关系）、以及与上市公司版本的差异关注点。国有企业审计具有财务审计与国有资产监管双重属性，预计负债及或有负债披露须同时满足会计准则和国资监管要求，尤其关注可能造成国有资产损失的重大或有事项。

**法规依据：**
- 《企业会计准则第13号——或有事项》
- 《企业会计准则第30号——财务报表列报》
- 《企业国有资产法》
- 《中央企业财务决算报告管理办法》
- 《国有资产监督管理委员会关于加强中央企业财务决算管理工作有关事项的通知》

## tips

1. **国有企业预计负债披露有"双层"要求**：既要满足 CAS13 的通用披露（分类/变动/形成原因/不确定性），又要满足国资委财务决算报告的额外披露要求（重大或有事项、担保、诉讼对国有资产的影响），两套要求互补不可替代。
2. **重大诉讼/担保须披露"三重一大"决策程序**：涉及重大金额的对外担保、重大诉讼应对、大额预计负债计提，须经"三重一大"集体决策，附注须披露相关决策过程和审批情况。
3. **对外担保是国企或有负债披露的重点**：国有企业对外担保（尤其对非国有单位或关联方担保）易形成或有负债和国有资产流失风险，须逐笔披露担保对象、金额、期限、反担保安排及履约可能性。
4. **重组义务须与国企改革/重组预算衔接**：涉及国企改革、职工安置、业务重组的预计负债，须披露重组计划、职工安置方案、预计支出与国资批复/年度预算的关系。
5. **重大或有负债须评估对国有资本保值增值的影响**：重大未决诉讼、担保履约、环保治理等潜在义务可能侵蚀国有资本，须在附注中说明对国有资本保值增值率的潜在影响。
6. **与上市版差异主要在监管层面而非准则层面**：基础披露框架（分类/变动/确认依据/或有负债）与上市版相同，国企版额外增加国资监管相关信息（三重一大/担保监管/责任追究/预算衔接），而非替代基础披露。

## checklist

### 一、基础披露完整性（与上市版共有）

- [ ] 预计负债是否按类别（质保/诉讼/亏损合同/重组/担保等）分项披露变动
- [ ] 各类别是否完整列示期初/本期增加/本期减少/期末余额
- [ ] 附注预计负债总额是否与审定表 K5-1 审定数一致
- [ ] 各类别期末余额是否与明细表 K5-2 勾稽
- [ ] 每类预计负债是否披露形成原因、支出时间、不确定性（CAS13）
- [ ] 是否同时列示期末数和期初数（可比信息）

### 二、国有资产监管相关披露

- [ ] 重大预计负债计提是否披露"三重一大"决策程序
- [ ] 涉及职工安置/重组的预计负债是否披露国资批复和安置方案
- [ ] 重大或有负债对国有资本保值增值的潜在影响是否说明
- [ ] 是否披露可能造成国有资产损失的重大潜在义务
- [ ] 环保治理/生态修复等法定义务形成的预计负债是否单独披露
- [ ] 大额预计负债（超过规定限额）是否按国资委要求详细披露

### 三、对外担保与或有负债披露（国企特定）

- [ ] 对外担保是否逐笔披露担保对象、金额、期限、担保方式
- [ ] 对非国有单位/关联方的担保是否单独说明合规性
- [ ] 担保是否设置反担保或连带责任分摊安排
- [ ] 担保履约可能性及预计财务影响是否披露
- [ ] 是否披露担保是否经"三重一大"决策及审批文件
- [ ] 未达确认条件的或有负债（诉讼/担保/其他）是否充分披露

### 四、重大诉讼与责任追究披露

- [ ] 重大未决诉讼是否单独披露案由、金额、进展、可能性
- [ ] 诉讼披露的可能性判断是否与律师函（A 循环）一致
- [ ] 涉及国有资产损失的诉讼是否说明是否启动责任追究程序
- [ ] 重大或有负债转为实际损失时是否披露损失责任认定情况
- [ ] 期后诉讼/担保履约重大进展是否披露（CAS1318）

### 五、与上市版的差异关注点

- [ ] 国企版是否在基础披露上增加了"三重一大"决策说明
- [ ] 是否增加了对外担保的详细逐笔披露
- [ ] 是否增加了对国有资本保值增值影响的分析
- [ ] 是否增加了国有资产损失责任追究相关信息
- [ ] 重组预计负债是否与国资批复和年度预算衔接说明
- [ ] 决算报表中的预计负债/或有负债数据是否与本附注一致

## risk_areas

### 高风险

1. **对外担保或有负债隐瞒未披露**：对非国有单位或关联方的重大担保未逐笔披露，可能掩盖国有资产流失风险，违反国资监管要求。
2. **重大或有负债未披露对国有资产影响**：可能造成国有资产损失的重大诉讼、担保履约、环保义务未评估和披露其对国有资本的侵蚀。
3. **附注与审定表数据不勾稽**：附注预计负债各类别合计与审定表 K5-1、试算表 2701 不一致，属重大数据错误。
4. **"三重一大"决策程序缺失或未披露**：大额预计负债计提或重大担保未经集体决策或未披露决策过程，存在合规风险。

### 中风险

1. **责任追究信息缺失**：涉及国有资产损失的或有事项未说明是否启动责任追究程序，不符合国有资产损失责任追究制度。
2. **重组预算衔接未说明**：重组预计负债与国资批复、年度预算的关系未披露。
3. **确认依据和不确定性披露不足**：仅披露金额而无形成原因、支出时间和不确定性说明（CAS13）。
4. **决算报表口径差异未调节**：财务决算数据与审计后附注数据存在差异但未编制调节说明。

### 低风险

1. **披露格式未完全按决算报表模板**：附注格式与国资委决算报表模板有细微差异，但信息内容完整。
2. **担保履约可能性分析简略**：已披露担保事项但对履约可能性的定性分析深度不足。
3. **历史趋势信息不完整**：预计负债增减变动的历史趋势分析覆盖年限不足国资委建议要求。
