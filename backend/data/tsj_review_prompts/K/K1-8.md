# K1-8 其他应收款坏账准备测算复核提示词

## 概述

本提示词针对其他应收款坏账准备测算表（K1-8）的复核，聚焦：单项计提测算准确性、组合（账龄/押金保证金等）计提测算准确性、损失率参数合理性、测算结果与坏账明细（K1-3）勾稽。坏账测算是减值会计估计的落地：单项按预计可收回金额与账面差额计提，组合按"账面余额×损失率"计提（③=①×②），测算差异须与已计提数比对并驱动 K1-4 调整。

**法规依据：**
- 《企业会计准则第22号——金融工具确认和计量》
- 《中国注册会计师审计准则第1301号——审计证据》
- 《中国注册会计师审计准则第1321号——审计会计估计（含公允价值会计估计）和相关披露》

## tips

1. **测算须区分单项与组合两条线**：单项计提=账面余额−预计可收回金额（现值），组合计提=账面余额×账龄/风险组合损失率（应提③=账面①×损失率②），两条线合计为应计提坏账准备。
2. **组合损失率公式勾稽须校验**：逐组"应计提=账面基数×损失率"计算须正确，各组应计提合计须等于组合计提总额，公式列断裂即测算失真。
3. **损失率参数须有依据**：账龄组合损失率须基于历史损失经验并含前瞻性调整，押金保证金等特殊组合损失率须结合对方信用和款项性质，参数无据或明显偏低属高风险。
4. **单项测算的可收回金额须有支撑**：单项计提的预计可收回金额（含担保物、期后收回、对方偿付能力）须有客观依据，避免高估可收回金额少提减值。
5. **测算结果与已提数比对驱动调整**：应计提坏账准备与账面已计提数的差异须列示，差异重大须通过 K1-4 补提/转回调整，测算与调整须闭环。
6. **与 K1-3/K1-7 勾稽**：单项/组合期末应计提数须与 K1-3 坏账明细期末余额一致，测算对象阶段划分须与 K1-7 三阶段一致。

## checklist

### 一、单项计提测算

- [ ] 单项计提对象是否与 K1-7 第三阶段/单项认定一致
- [ ] 单项计提=账面余额−预计可收回金额，计算是否正确
- [ ] 预计可收回金额是否有客观依据（担保/期后收回/偿付能力）
- [ ] 是否存在高估可收回金额导致单项少提

### 二、组合计提测算

- [ ] 组合划分是否与 K1-6 政策一致（账龄/押金保证金/关联方组合）
- [ ] 逐组"应计提③=账面基数①×损失率②"计算是否正确
- [ ] 各组应计提合计是否等于组合计提总额
- [ ] 账龄组合损失率是否有历史损失经验及前瞻性调整支撑
- [ ] 长账龄组损失率是否审慎（避免长账龄低损失率）

### 三、结果勾稽与差异

- [ ] 应计提坏账准备（单项+组合）合计是否与 K1-3 期末余额一致
- [ ] 应计提数与账面已计提数差异是否列示
- [ ] 差异重大是否通过 K1-4 补提/转回调整
- [ ] 测算结果是否支撑审定表 K1-1 减值列及净额

## risk_areas

### 高风险

1. **损失率明显偏低**：账龄/组合损失率缺乏历史损失支撑且明显偏低，减值测算不足。
2. **单项可收回金额高估**：预计可收回金额缺乏依据或高估，单项减值少提。
3. **测算与调整脱节**：应计提与已提数差异重大但未通过 K1-4 调整，审定减值失真。

### 中风险

1. **组合公式勾稽断裂**：③=①×② 计算错误或各组合计不等于总额。
2. **测算与 K1-3/K1-7 不一致**：单项/组合划分或期末应提数与坏账明细、三阶段不勾稽。

### 低风险

1. **参数依据记录不足**：损失率取值依据未附说明。
2. **交叉索引不完整**：与 K1-3/K1-6/K1-7/K1-4 的引用标注不全。
