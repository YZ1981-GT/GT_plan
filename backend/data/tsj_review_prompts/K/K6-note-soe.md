# K6-note-soe 持有待售附注披露复核提示词（国有企业）

## 概述

本提示词针对持有待售国有企业附注披露底稿（K6-note-soe，科目 1481 持有待售资产/2605 持有待售负债）的复核，聚焦国有企业特定的持有待售披露要求：持有待售资产/负债/处置组披露、孰低计量与减值、终止经营列报、以及国有资产处置合规性（进场交易、评估备案、审批程序）等国资监管相关披露，并关注与上市公司版本的差异。国有企业资产处置须履行国有资产评估、进场交易、审批备案等法定程序，持有待售附注须同时满足会计准则和国有资产处置监管要求，防止国有资产流失。

**法规依据：**
- 《企业会计准则第42号——持有待售的非流动资产、处置组和终止经营》
- 《企业会计准则第8号——资产减值》
- 《企业国有资产法》
- 《企业国有资产交易监督管理办法》（32号令）
- 《中央企业财务决算报告管理办法》

## tips

1. **国有资产处置合规性披露**：持有待售的国有资产处置须履行资产评估、进场交易（产权交易所）、审批备案等法定程序，附注须披露处置是否合规、评估备案情况及审批文号。
2. **双层披露要求**：既满足 CAS42 持有待售/终止经营披露，又满足国有资产处置监管对合规程序、防止流失的额外披露要求。
3. **孰低计量与国资视角减值**：以账面价值与公允价值减出售费用孰低计量，公允价值须以国有资产评估值为重要参考，减值确认须防止低估处置价值导致国有资产流失，也须防止高估掩盖减值。
4. **终止经营列报**：处置国有经营性板块构成终止经营的，须单独列示终止经营损益、重述比较期间，并说明退出该板块对国有资本布局的影响。
5. **"三重一大"决策程序**：重大资产处置须经"三重一大"集体决策，附注须披露决策程序履行情况及是否属于关联方/同一控制下交易。
6. **闭环勾稽**：附注持有待售资产/负债合计=审定表 K6-1 审定数=试算表 1481/2605；减值金额与 K6 减值测算及 K11 勾稽；处置数据与财务决算报表一致。

## checklist

### 一、基础披露完整性（与上市版共有）

- [ ] 持有待售的非流动资产、处置组是否分别披露
- [ ] 处置组是否列示所含资产及负债构成明细
- [ ] 持有待售资产（1481）与负债（2605）是否分区列示
- [ ] 附注持有待售资产/负债合计是否与审定表 K6-1 一致
- [ ] 是否披露以账面价值与公允价值减出售费用孰低计量及减值金额
- [ ] 减值金额是否与 K6 减值测算及 K11 资产减值损失勾稽
- [ ] 是否披露划分持有待售后已停止折旧/摊销

### 二、国有资产处置合规披露

- [ ] 处置国有资产是否履行资产评估程序，评估值是否作为公允价值参考
- [ ] 是否披露资产评估备案情况及备案文号
- [ ] 经营性资产处置是否进场交易（产权交易所），是否披露交易情况
- [ ] 重大处置是否经"三重一大"集体决策，是否披露决策程序
- [ ] 处置审批文号及审批层级是否披露
- [ ] 处置对手方是否为关联方/同一控制下企业，定价是否公允
- [ ] 【风险检查】是否存在低价处置导致国有资产流失的迹象

### 三、终止经营与决算一致性

- [ ] 处置组是否构成终止经营，是否单独列示终止经营损益
- [ ] 终止经营收入、费用、利润、所得税、现金流量是否披露
- [ ] 比较期间终止经营损益是否重述
- [ ] 退出经营板块对国有资本布局的影响是否说明
- [ ] 持有待售/处置数据是否与年度财务决算报表一致
- [ ] 与上市版差异：是否在基础披露上增加了国有资产处置合规程序信息

## risk_areas

### 高风险

1. **处置合规程序缺失**：国有资产处置未履行评估、进场交易、审批备案程序或未披露，存在国有资产流失和合规风险，涉及审计责任。
2. **低价处置流失风险**：公允价值/出售费用估计不当，处置定价低于评估值且无合理依据，掩盖国有资产流失。
3. **分类条件不满足仍披露持有待售**：不符合 CAS42 条件仍列持有待售，规避折旧或掩盖减值。
4. **终止经营列报缺失**：处置国有板块构成终止经营但未单独列示、未重述比较期间。

### 中风险

1. **"三重一大"程序未披露**：重大资产处置未披露集体决策程序履行情况。
2. **评估备案信息不完整**：资产评估已做但备案文号、评估机构等信息未充分披露。
3. **减值披露与测算不勾稽**：孰低计量减值金额与 K6 测算/K11 不一致。
4. **决算与审计口径差异未调节**：财务决算处置数据与审计后附注数据存在差异未说明。

### 低风险

1. **披露格式未完全按决算模板**：附注格式与国资委决算报表模板有细微差异。
2. **处置进展说明不足**：预计处置时间/方式的进展信息不充分。
