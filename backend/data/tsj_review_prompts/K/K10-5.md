# K10-5 应收政府补助检查表复核提示词

## 概述

本提示词针对应收政府补助检查表（K10-5）的复核，聚焦尚未到账、以应收款项形式确认的政府补助的确认条件、可收回性评估及到账跟踪。当企业已满足补助确认条件但资金尚未到账时，可确认应收政府补助并同时确认其他收益/递延收益。检查表逐项核对确认依据、批复文件、可收回性证据及期后到账情况，是防止提前确认补助收益、虚增资产的关键控制。核心风险为确认条件不满足、可收回性证据不足、长期挂账未减值。

**法规依据：**
- 《企业会计准则第16号——政府补助》
- 《企业会计准则第22号——金融工具确认和计量》
- 《中国注册会计师审计准则第1301号——审计证据》

## tips

1. **确认条件严格**：应收政府补助确认须同时满足"符合补助所附条件"和"能够收到补助"两项，仅有批复而资金无明确到位安排的不得确认应收款。
2. **可收回性是核心**：须评估补助资金到位的确定性，依据包括正式批复文件、财政预算安排、历史到账记录、政府沟通证据；证据不足的应收补助存在虚增资产风险。
3. **确认时点核查**：重点核查是否在批复前或条件未满足前即确认应收政府补助，防止提前确认收益虚增利润。
4. **到账跟踪**：核查资产负债表日后应收补助的实际到账情况，长期未到账（如超1年）的须评估可收回性并考虑减值。
5. **配比确认**：确认应收政府补助时，对应贷方应正确计入其他收益（与日常活动相关）、营业外收入或递延收益（与资产相关），不得错配。
6. **闭环勾稽**：应收政府补助↔对应其他收益（K10）/递延收益（K7）确认；期后到账↔货币资金；减值↔信用减值损失（K11）。

## checklist

### 一、确认条件与依据（高风险）

- [ ] 应收政府补助是否同时满足"符合所附条件"和"能够收到"两项确认条件
- [ ] 是否有正式补助批复文件支持确认
- [ ] 是否在批复前或条件未满足前提前确认应收补助
- [ ] 确认金额是否与批复文件一致
- [ ] 【风险检查】是否存在无批复即确认应收补助虚增资产和收益

### 二、可收回性评估（高风险）

- [ ] 补助资金到位是否有财政预算安排或明确到位时间
- [ ] 可收回性证据是否充分（批复/预算/历史到账/政府沟通）
- [ ] 长期未到账（超1年）的应收补助是否评估可收回性
- [ ] 可收回性存疑的应收补助是否考虑减值（信用减值损失 K11）
- [ ] 【条件检查：若有政府财政困难迹象】是否重新评估到位可能性

### 三、到账跟踪与配比（中风险）

- [ ] 资产负债表日后应收补助的实际到账情况是否核查
- [ ] 期后到账金额、日期是否与应收确认一致
- [ ] 确认应收补助时对应贷方计入科目是否正确（其他收益/营业外收入/递延收益）
- [ ] 应收政府补助是否与其他收益（K10）/递延收益（K7）确认勾稽
- [ ] 【风险检查】是否存在长期挂账应收补助未减值虚增资产

## risk_areas

### 高风险

1. **确认条件不满足**：仅有意向或口头承诺即确认应收政府补助，条件未满足提前确认收益虚增利润和资产。
2. **可收回性证据不足**：应收补助缺乏财政预算安排或明确到位证据，存在无法收回风险。
3. **长期挂账未减值**：应收政府补助长期未到账（超1年）仍全额挂账，未评估减值，虚增资产。

### 中风险

1. **确认时点不当**：在批复前确认应收补助，或满足条件后延迟确认。
2. **配比科目错误**：确认应收补助时对应贷方计入科目错误（如应递延却一次计损益）。
3. **到账跟踪不到位**：未核查期后实际到账情况验证存在性。

### 低风险

1. **格式与索引不规范**：检查表项目、单位、交叉索引不统一。
2. **可收回性依据说明不足**：到位安排、政府沟通记录等辅助证据说明缺失。
