# G12-note-soe 净敞口套期收益附注披露复核提示词（国有企业）

## 概述

本提示词针对净敞口套期收益国有企业附注披露底稿（G12-note-soe）的复核。国有企业套期披露除满足会计准则通用要求外，还须关注国资监管对衍生品/套期业务的合规要求：套期业务的授权审批、套期而非投机的定性、以及决算报表口径一致性。

**法规依据：**
- 《企业会计准则第24号——套期会计》
- 《企业会计准则第37号——金融工具列报》
- 《企业会计准则第30号——财务报表列报》
- 《中央企业财务决算报告管理办法》

---

## tips

1. **国企套期披露有双层要求**：既满足会计准则通用披露，又满足国资监管对衍生品业务的合规披露要求。
2. **须体现套期而非投机**：国资监管严格限制央企/国企从事投机性衍生品交易，附注须说明套期业务的商业实质（对冲已识别风险敞口），佐证非投机。
3. **套期业务授权审批须说明**：重大套期/衍生品业务的授权审批、额度管理情况须说明，佐证合规决策。
4. **无效部分损益关注管理责任**：套期无效部分损失较大时须说明原因，是否涉及套期策略失当。
5. **与决算报表口径一致**：附注套期损益须与年度财务决算报表相关数据一致，差异编制调节说明。
6. **附注须与审定表闭环勾稽**：披露套期损益各分项合计与G12-1审定数、G12-2套期明细勾稽。

## checklist

### 一、基础披露（与上市版共有）

- [ ] 是否披露被套期风险类型及风险管理策略
- [ ] 套期工具名义金额、账面价值、被套期项目是否披露
- [ ] 套期无效部分损益是否单独披露
- [ ] 现金流量套期OCI变动是否披露

### 二、国有资产监管相关披露

- [ ] 是否说明套期业务对冲已识别风险敞口（佐证非投机）
- [ ] 重大套期/衍生品业务授权审批、额度管理是否说明
- [ ] 套期无效部分较大损失是否说明原因及责任

### 三、勾稽与决算一致性

- [ ] 附注套期损益是否与G12-1审定数、G12-2套期明细勾稽
- [ ] 附注是否与财务决算报表数据一致
- [ ] 差异是否编制调节说明

### 四、其他

- [ ] 是否披露套期有效性评估方法及结果
- [ ] 是否同时披露本期数和上期可比数

## risk_areas

### 高风险

1. **投机性交易伪装套期**：不满足套期条件的衍生品交易被列为套期，违反国资监管对投机交易的限制。
2. **无效部分损失责任信息缺失**：套期重大无效损失未说明原因及是否涉及策略失当。
3. **附注与审定表/决算不勾稽**：披露套期损益与G12-1审定数或决算报表存在差异。
4. **风险管理策略披露缺失**：未披露套期目标与策略，无法评估商业实质。

### 中风险

1. **授权审批说明不足**：重大套期业务的授权审批、额度管理未说明。
2. **套期关系明细不充分**：未按套期类型披露明细。
3. **可比信息缺失**：仅披露本期数，未列上期可比数。

### 低风险

1. **披露格式未按决算模板**：附注格式与国资委决算模板有细微差异。
2. **文字说明模板化**：风险管理策略照搬模板。
3. **底稿索引不完整**：披露底稿交叉索引缺失。
