# G10-5 交易性金融负债公允价值测试 复核提示词

## 概述

本提示词针对交易性金融负债公允价值测试表（G10-5）的复核。交易性金融负债以公允价值计量且变动进损益（FVTPL），须按公允价值层次确定并测试期末公允价值。衍生金融负债、指定FVTPL负债的估值多依赖估值模型（第二/三层次）。复核聚焦公允价值层次划分、估值技术选择、关键输入合理性、自身信用风险考虑、以及测试结果与明细表/审定表的勾稽。

**法规依据：**
- 《企业会计准则第22号——金融工具确认和计量》
- 《企业会计准则第39号——公允价值计量》
- 《企业会计准则第37号——金融工具列报》

## tips

1. **公允价值层次**：第一层次=活跃市场未调整报价；第二层次=可观察输入（利率/汇率曲线等）；第三层次=不可观察输入（模型+假设）。
2. **负债公允价值须考虑自身信用风险**：金融负债公允价值应反映自身不履约风险（own credit risk），衍生负债估值须考虑信用价值调整（CVA/DVA）。
3. **衍生工具估值模型**：利率互换、外汇远期等衍生负债采用贴现现金流/期权定价模型，须核对利率/汇率曲线、波动率等输入。
4. **防低估负债**：负债公允价值低估会导致负债少计、损益虚增，测试须审慎防止系统性低估。
5. **估值日一致**：公允价值测算须以资产负债表日为估值日。
6. **勾稽明细审定表**：测试确定的公允价值须与G10-2明细表、G10-1审定表勾稽，第三层次调节须与G10-6一致。

## checklist

### 一、公允价值层次

- [ ] 各笔负债是否明确划分公允价值层次
- [ ] 活跃市场负债是否采用未调整报价（第一层次）
- [ ] 衍生/指定FVTPL负债是否合理划分层次
- [ ] 层次划分是否与输入值可观察性匹配

### 二、估值技术与假设

- [ ] 衍生工具估值模型（贴现现金流/期权定价）是否适当
- [ ] 关键输入（利率/汇率曲线/波动率）是否有依据
- [ ] 负债公允价值是否考虑自身信用风险（CVA/DVA）
- [ ] 估值是否以资产负债表日为估值日

### 三、结果与勾稽

- [ ] 测试确定的公允价值是否与G10-2明细表一致
- [ ] 公允价值是否与G10-1审定表勾稽
- [ ] 第三层次公允价值是否与G10-6调节表一致
- [ ] 重大估值是否考虑利用专家工作

## risk_areas

### 高风险

1. **公允价值低估负债**：负债公允价值系统性低估导致负债少计、公允价值变动损益虚增。
2. **衍生负债估值不当**：估值模型/输入错误导致衍生负债公允价值失真。
3. **未考虑自身信用风险**：负债估值未反映自身不履约风险（CVA/DVA），公允价值不准。

### 中风险

1. **层次划分错误**：第三层次误划为第二层次，掩盖估值不确定性。
2. **关键输入缺乏支持**：利率/汇率曲线、波动率等假设无客观依据。
3. **使用过期估值**：未以资产负债表日为估值日。

### 低风险

1. **估值报告索引缺失**：公允价值来源未建立索引。
2. **敏感性未分析**：第三层次估值未做关键假设敏感性分析。
3. **格式不规范**：测试表字段不统一。
