# G1-13 交易性金融资产凭证检查表复核提示词

## 适用底稿
交易性金融资产凭证检查表（G1-13），聚焦买入/卖出交易凭证核对完整性、样本选取合理性、检查比例达标性、异常交易标注充分性。

## tips

- 样本选取方法应与风险评估匹配，大额买卖、频繁交易、关联方交易纳入必选样本
- 凭证核对须覆盖完整交易链（交易指令→成交回报→资金划付→券商对账单→账务处理）
- 检查比例应满足《中国注册会计师审计准则第1314号——审计抽样》要求
- 买入交易核对成本入账准确性；卖出交易核对处置损益结转正确性
- 关注资产负债表日前后的买卖交易（截止测试），防止跨期确认损益
- 关联方证券交易须核查交易价格公允性和商业实质
- 异常交易标注需明确类型（价格异常/时间异常/对手方异常/频繁对倒）

## checklist

### 高风险检查项

- [ ] 样本选取方法是否与识别的重大错报风险相匹配
- [ ] 大额买卖交易（超过重要性水平）是否100%全覆盖检查
- [ ] 频繁交易/关联方交易是否纳入必选样本
- [ ] 凭证核对是否覆盖完整交易链（指令-成交回报-资金-对账单-账务）
- [ ] 买入成本入账是否准确（含交易费用处理是否正确）
- [ ] 卖出处置损益结转是否正确（卖出净额−账面价值）
- [ ] 资产负债表日前后交易是否实施截止测试
- [ ] 是否存在无真实成交回报支持的交易凭证
- [ ] 异常交易是否全部标注并记录异常类型

### 中风险检查项

- [ ] 抽样总体是否完整（是否涵盖全部买卖交易）
- [ ] 检查比例（已检查金额/总体金额）是否达到计划水平
- [ ] 买入交易检查比例是否达标
- [ ] 卖出交易检查比例是否达标
- [ ] 关联方交易价格公允性是否核查
- [ ] 凭证日期与成交日期是否一致，是否存在跨期
- [ ] 核对中发现的差异是否逐一追踪解决

### 低风险检查项

- [ ] 抽样参数（总体/置信水平/可容忍偏差）是否完整记录
- [ ] 样本选取过程是否可追溯
- [ ] 凭证检查结果记录格式是否规范统一
- [ ] 底稿索引与交叉引用是否完整（关联审定表/明细表/结存表）

## risk_areas

### 高风险

1. **凭证造假风险**：虚构买卖交易凭证（伪造成交回报/资金流水）虚增资产或调节损益，须交叉核对券商对账单。
2. **截止性错误风险**：资产负债表日前后的买卖交易未实施截止测试，跨期确认公允价值变动或处置损益。
3. **处置损益结转错误风险**：卖出交易的成本结转或损益计算错误，导致投资收益虚增虚减。
4. **关联方对倒交易风险**：关联方之间频繁对倒证券操纵价格或损益，未识别商业实质。
5. **异常交易遗漏风险**：价格异常（偏离市场价）、时间异常（节假日/收盘后）、频繁对倒交易未被标注。

### 中风险

1. **检查比例不足风险**：实际检查比例低于计划水平，审计证据不充分。
2. **交易费用处理错误风险**：FVTPL交易费用误计入成本而非当期损益。
3. **核对深度不够风险**：仅核对金额而忽略交易实质（成交时点/价格/对手方）。

### 低风险

1. **记录不完整风险**：抽样参数、选取过程、核对结果记录不完整。
2. **索引缺失风险**：凭证检查底稿与审定表/明细表/结存表交叉索引不完整。
3. **格式不规范风险**：检查结果记录格式不统一。

## 法规依据

- 《中国注册会计师审计准则第1314号——审计抽样》
- 《中国注册会计师审计准则第1301号——审计证据》
- 《中国注册会计师审计准则第1141号——财务报表审计中与舞弊相关的责任》
