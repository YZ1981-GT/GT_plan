# G8-2 其他权益工具投资明细表 复核提示词

## 概述

本提示词针对其他权益工具投资明细表（G8-2）的复核。明细表逐项列示各笔权益工具投资的名称、持股比例、取得成本、公允价值、公允价值变动、计入OCI的累计额及股利收入，是审定表（G8-1）和附注披露的数据来源。复核聚焦逐项公允价值计量、OCI累计额滚动、股利收入确认、以及明细合计与审定表的勾稽。

**法规依据：**
- 《企业会计准则第22号——金融工具确认和计量》
- 《企业会计准则第37号——金融工具列报》

---

## tips

1. **明细合计勾稽审定表**：明细各笔期末公允价值合计须等于G8-1审定数，OCI累计额合计须等于审定表OCI余额。
2. **公允价值来源分层**：区分活跃市场报价（第一层次）、可观察输入（第二层次）、不可观察输入（第三层次），非上市股权多为第三层次须重点核查估值。
3. **公允价值变动全进OCI**：每笔公允价值变动=期末公允价值-（取得成本+期初累计公允价值变动），差额全部进OCI。
4. **股利单列进损益**：宣告分派的现金股利单独列示并计入投资收益，不进OCI。
5. **不计提减值**：其他权益工具投资不适用预期信用损失模型（权益工具无信用风险），公允价值已反映减值。
6. **关注非上市股权**：非上市权益工具公允价值缺乏活跃市场，须重点核查估值方法和关键假设合理性。

## checklist

### 一、逐项计量

- [ ] 各笔权益工具名称、持股比例、取得日期是否准确
- [ ] 取得成本是否包含交易费用（初始计入成本）
- [ ] 公允价值来源是否明确分层
- [ ] 第三层次（非上市股权）估值方法和假设是否有依据

### 二、OCI与股利

- [ ] 公允价值变动是否全部计入OCI（不进损益）
- [ ] OCI累计额是否逐项滚动且与审定表勾稽
- [ ] 股利收入是否单独列示并计入投资收益
- [ ] 处置项OCI累计额是否已结转（转留存收益）

### 三、勾稽

- [ ] 明细合计（公允价值/OCI）是否与G8-1审定表勾稽
- [ ] 是否未计提减值（权益工具不适用ECL）
- [ ] 是否存在明细遗漏或重复列示

## risk_areas

### 高风险

1. **非上市股权公允价值高估**：第三层次估值缺乏依据或采用管理层单方假设，公允价值高估、OCI失真。
2. **公允价值变动计入损益**：将公允价值变动错误计入损益而非OCI。
3. **股利收入误进OCI**：股利收入错误计入OCI而非投资收益。
4. **明细与审定表不勾稽**：明细合计与G8-1审定数不一致。

### 中风险

1. **交易费用处理错误**：取得交易费用未计入初始成本。
2. **OCI累计额滚动断裂**：处置项OCI未结转或期初OCI承前错误。
3. **错误计提减值**：对权益工具错误适用ECL计提减值。

### 低风险

1. **明细列示不完整**：缺少股票代码、被投资单位信息等。
2. **索引引用缺失**：未与交割单、估值报告建立索引。
3. **精度不统一**：持股比例、金额精度不一致。
