# G7-7 长期股权投资控制判断 复核提示词

## 概述

本提示词针对长期股权投资控制/共同控制/重大影响判断表（G7-7）的复核。控制判断决定核算方法（合并/成本法vs权益法vs金融资产）和合并范围，须综合评估权力、可变回报、权力与回报的联系三要素。复核聚焦控制三要素判断的充分性、共同控制与重大影响区分的合理性、以及判断结论与后续核算方法的一致性。

**法规依据：**
- 《企业会计准则第33号——合并财务报表》
- 《企业会计准则第2号——长期股权投资》
- 《企业会计准则第20号——企业合并》

---

## tips

1. **控制三要素**：CAS33控制=拥有对被投资方的权力+享有可变回报+有能力运用权力影响回报，三者须同时满足。
2. **实质重于形式**：不能仅以持股比例判断，须评估潜在表决权、结构化主体、一致行动协议、董事会控制等实质因素。
3. **共同控制vs重大影响**：共同控制需合营安排各方一致同意方能决策（权益法-合营）；重大影响是参与决策但不能控制（权益法-联营）。
4. **区分金融资产**：无控制、无共同控制、无重大影响的股权投资应作为金融资产（其他权益工具投资/交易性金融资产）核算。
5. **持股50%不必然控制**：低于50%可能通过其他安排控制，超过50%也可能因一票否决等丧失控制，须实质判断。
6. **判断联动核算**：控制判断结论须与核算方法（G7-8/G7-9合并初始计量、G7-14权益法）一致。

## checklist

### 一、控制三要素判断

- [ ] 是否评估对被投资方的权力（表决权/董事会/关键决策）
- [ ] 是否评估享有的可变回报（分红/资产增值/其他利益）
- [ ] 是否评估运用权力影响回报的能力
- [ ] 是否考虑潜在表决权、一致行动、结构化主体等实质因素

### 二、共同控制与重大影响

- [ ] 共同控制判断是否基于合营安排各方一致同意机制
- [ ] 重大影响判断是否基于参与决策但不控制的事实
- [ ] 持股比例与判断结论是否一致（异常情形是否说明）
- [ ] 无控制/共同控制/重大影响的是否归类为金融资产

### 三、判断联动

- [ ] 控制判断结论是否与核算方法选择一致
- [ ] 判断是否与合并范围一致
- [ ] 判断依据是否有底稿和文档支持

## risk_areas

### 高风险

1. **控制判断遗漏实质因素**：仅按持股比例判断，忽略潜在表决权、一致行动、结构化主体，导致合并范围错误。
2. **应合并未合并**：实质控制的被投资单位未纳入合并（或权益法误作金融资产），合并报表重大错报。
3. **共同控制与重大影响混淆**：合营误作联营（或反之），虽同用权益法但内部交易抵销、超额亏损处理不同。

### 中风险

1. **50%以上控制假设错误**：持股超50%但因一票否决实际无控制，仍按控制处理。
2. **金融资产误作权益法**：无重大影响的投资误用权益法。
3. **判断与核算不一致**：控制结论与实际核算方法不匹配。

### 低风险

1. **判断依据文档不充分**：结论正确但支持文档不足。
2. **索引引用缺失**：未与基本信息、合并范围建立索引。
3. **格式不规范**：判断表字段不统一。
