# G11-note-soe 投资收益附注披露复核提示词（国有企业）

## 概述

本提示词针对投资收益国有企业附注披露底稿（G11-note-soe）的复核。国有企业投资收益披露除满足会计准则通用要求外，还须满足国资监管要求：对外投资收益的经营考核关联、国有股权投资收益的单独说明、投资损失的责任追究及决算报表口径一致性。

**法规依据：**
- 《企业会计准则第22号——金融工具确认和计量》
- 《企业会计准则第2号——长期股权投资》
- 《企业会计准则第30号——财务报表列报》
- 《中央企业财务决算报告管理办法》

---

## tips

1. **国企投资收益披露有双层要求**：既满足企业会计准则通用披露，又满足国资委财务决算报告的对外投资经营成果披露要求，两套要求互为补充。
2. **对外投资收益关联经营考核**：国企对外投资收益是国有资本经营考核的重要指标，附注需说明重要投资项目的收益贡献及与预算目标的对比。
3. **国有股权投资收益单独说明**：对国有控股/参股企业的权益法投资收益应单独列示，便于评估国有资本投资运营效果。
4. **投资损失关注责任追究**：重大投资损失（处置损失/权益法确认的被投资方亏损）须说明形成原因，是否涉及决策失误及责任追究程序。
5. **与决算报表口径一致**：附注投资收益须与年度财务决算报表相关数据一致，差异须编制调节说明。
6. **附注须与审定表闭环勾稽**：投资收益各分项合计等于G11-1审定数，权益法分项与G7长期股权投资附注勾稽。

## checklist

### 一、基础披露（与上市版共有）

- [ ] 投资收益是否按来源分类披露（权益法/股利/处置损益/利息）
- [ ] 各分项合计是否等于利润表投资收益及G11-1审定数
- [ ] 是否同时披露本期数和上期可比数
- [ ] 分类方法是否与会计政策一致

### 二、国有资产监管相关披露

- [ ] 重要对外投资项目的收益贡献是否说明
- [ ] 对外投资收益是否与年度预算目标对比分析
- [ ] 国有控股/参股企业权益法收益是否单独列示
- [ ] 是否说明投资收益对国有资本保值增值率的影响

### 三、投资损失与责任

- [ ] 重大投资损失是否说明形成原因
- [ ] 重大投资损失是否涉及决策程序及责任追究说明
- [ ] 处置国有股权取得的损益是否披露决策审批情况

### 四、勾稽与决算一致性

- [ ] 附注投资收益是否与财务决算报表数据一致
- [ ] 权益法分项是否与G7长期股权投资附注勾稽
- [ ] 差异是否编制调节说明

## risk_areas

### 高风险

1. **投资损失责任信息缺失**：重大投资损失未说明形成原因及是否启动责任追究，不符合国有资产损失责任追究要求。
2. **附注与利润表/审定表不勾稽**：投资收益分项合计与利润表或G11-1审定数不一致。
3. **国有股权投资收益未单独披露**：对国有控股/参股企业的收益未单独列示，无法评估国有资本运营效果。
4. **决算与审计口径差异未调节**：附注投资收益与决算报表数据存在差异但未编制调节说明。

### 中风险

1. **预算执行对比缺失**：对外投资收益远低于预算目标但未说明原因。
2. **权益法收益逐户披露不足**：重要国有联营/合营企业收益未逐户披露。
3. **保值增值影响未说明**：投资收益/损失对国有资本保值增值率的影响未量化说明。

### 低风险

1. **披露格式未按决算模板**：附注格式与国资委决算报表模板有细微差异。
2. **文字说明模板化**：投资收益确认方法说明照搬会计政策原文。
3. **历史趋势追溯不完整**：投资收益变动趋势分析未覆盖建议年限。
