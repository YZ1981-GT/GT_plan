# G12-3 净敞口套期收益调整分录复核提示词

## 概述

本提示词针对净敞口套期收益调整分录（G12-3）的复核，含账项调整（AJE）、重分类调整（RJE）及未调整错报（SUD）评估。复核须验证每笔调整有证据、借贷平衡、完整反映到G12-1审定表，并同步试算平衡表。

**法规依据：**
- 《企业会计准则第24号——套期会计》
- 《企业会计准则第22号——金融工具确认和计量》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **AJE影响损益、RJE仅影响列报**：套期收益的AJE调整损益金额（如补计无效部分损益、更正有效性评估），RJE仅涉及列报（如损益与OCI之间的重分类），不得以RJE掩盖损益错报。
2. **调整须与G12-1审定表逐笔勾稽**：审定表调整列金额必须与G12-3已确认分录逐笔一致。
3. **有效性评估调整须有证据**：调整套期有效部分/无效部分金额的分录须有套期有效性测试（G12-4）支持。
4. **OCI结转调整须符合准则**：现金流量套期OCI累计额转入损益的调整须符合CAS24结转条件（被套期预期交易影响损益时）。
5. **审批链留痕**：超过明细层次重要性水平的调整须经合伙人/项目经理审批。
6. **TB回写一致**：确认调整已同步试算平衡表6106科目。

## checklist

### 一、账项调整（AJE）

- [ ] 所有AJE是否有充分审计证据（有效性测试、估值确认等）
- [ ] AJE是否经适当层级审批
- [ ] 每笔调整分录借贷方是否完全平衡
- [ ] 调整金额是否完整反映到G12-1审定表调整列
- [ ] 无效部分损益调整是否与G12-4有效性测试勾稽

### 二、重分类调整（RJE）

- [ ] RJE是否仅涉及列报，未影响损益总额
- [ ] 损益与OCI之间的重分类是否恰当
- [ ] 现金流量套期OCI累计额转入损益是否符合结转条件
- [ ] 是否存在以RJE掩盖损益错报的情形

### 三、未调整错报（SUD）与勾稽

- [ ] 未调整错报累计是否超过整体重要性水平
- [ ] 与A13未调整错报汇总表索引是否完整
- [ ] 跨期调整是否正确区分本期错报与前期差错更正
- [ ] 调整后审定数是否已同步试算平衡表6106科目

## risk_areas

### 高风险

1. **调整缺乏证据或未经授权**：套期收益调整无有效性测试/估值支持，或未经审批即纳入审定表。
2. **审定表与调整金额不一致**：G12-1审定表调整列与G12-3已确认分录长期不一致。
3. **以RJE掩盖损益错报**：将套期无效部分损益错报以重分类处理，规避损益影响。
4. **OCI违规结转**：现金流量套期OCI累计额在不满足条件时转入损益。

### 中风险

1. **RJE误含损益影响**：重分类调整影响了损益总额而非仅列报。
2. **跨期调整分类错误**：未区分本期错报与前期差错更正。
3. **SUD累计超阈值未处理**：未调整错报累计超重要性水平但未评估。

### 低风险

1. **分录摘要、科目编码不规范**：调整分录摘要笼统或编码不规范。
2. **索引指向不完整**：调整分录未指向套期明细、有效性测试等支持底稿。
3. **审计说明不充分**：未概括调整性质与剩余风险。
