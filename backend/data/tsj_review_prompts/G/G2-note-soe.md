# G2-note-soe 应收利息附注披露复核提示词（国有企业）

## 概述

本提示词针对应收利息国有企业附注披露底稿（G2-note-soe）的复核，聚焦国有企业特定的附注披露要求：基础披露（分类/账龄/坏账变动）之上，叠加国有资产监管相关披露——关联方（含同受国有控制单位）应收利息、长期未收回利息的国资监管视角、资金占用利息披露、以及与上市公司版本的差异关注点。

**法规依据：**
- 《企业会计准则第37号——金融工具列报》
- 《企业会计准则第36号——关联方披露》
- 《企业国有资产法》
- 《中央企业财务决算报告管理办法》

---

## tips

1. **国企关联方范围更广**：应收利息的关联方披露须考虑同一国有控股股东控制的其他国有企业。
2. **资金占用利息是国企关注点**：其他国企或关联方长期占用资金产生的应收利息须单独说明，评估是否存在资金占用挂账。
3. **基础披露框架与上市版相同**：分类、账龄、坏账变动等基础披露一致，国企版增加国资监管信息。
4. **长期未收回利息的国有资产视角**：长期未收回利息累积可能反映国有资产占用问题，须披露催收和处置。
5. **利息减值影响保值增值**：应收利息减值损失对国有资本保值增值率的影响须评估。
6. **与上市版差异在监管层面**：国企版在基础披露基础上补充国资监管相关信息。

## checklist

### 一、基础披露完整性（与上市版共有）

- [ ] 应收利息是否按来源分类披露
- [ ] 各类别合计是否等于G2-1审定表审定数
- [ ] 坏账准备变动表是否完整并与G2-3勾稽
- [ ] 期初数/期末数可比信息是否完整

### 二、国有资产监管相关披露

- [ ] 长期未收回应收利息是否单独披露金额、债务人及原因
- [ ] 其他国企/关联方资金占用产生的应收利息是否单独说明
- [ ] 应收利息减值对国有资本保值增值的影响是否说明
- [ ] 大额应收利息是否按国资委要求逐户披露

### 三、关联方披露（国企特定）

- [ ] 与控股股东及关联企业的应收利息是否逐户列示
- [ ] 与同受国有控制企业的应收利息是否披露
- [ ] 关联方资金往来利率是否披露公允性
- [ ] 是否存在资金占用以应收利息挂账并予以说明

### 四、与上市版差异关注点

- [ ] 国企版是否在基础披露上增加国资监管信息
- [ ] 关联方范围是否扩展至同受国有控制企业
- [ ] 是否增加资金占用利息的说明
- [ ] 决算报表应收利息数据是否与本附注一致

## risk_areas

### 高风险

1. **资金占用利息未披露**：其他国企/关联方长期占用资金产生的应收利息未单独说明，可能掩盖资金占用。
2. **关联方应收利息范围遗漏**：未纳入同受国有控制企业，关联交易信息不完整。
3. **基础披露与审定表不勾稽**：附注应收利息合计与G2-1审定数不一致。

### 中风险

1. **长期未收回利息披露不足**：长账龄利息未说明原因和催收措施。
2. **保值增值影响未分析**：利息减值对国有资本保值增值影响未说明。
3. **利率公允性未披露**：关联方资金往来利率公允性缺乏说明。

### 低风险

1. **披露格式未按决算模板**：附注格式与国资委决算模板细微差异。
2. **可比信息追溯不完整**：历史趋势分析不足。
3. **资金占用说明简略**：占用利息计算依据说明不充分。
