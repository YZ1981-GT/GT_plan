# G7-4 长期股权投资被投资单位基本信息 复核提示词

## 概述

本提示词针对长期股权投资被投资单位基本信息表（G7-4）的复核。基本信息表登记各被投资单位的名称、注册资本、持股比例、表决权比例、注册地、主营业务、成立日期及取得投资方式，是判断核算方法（成本法/权益法）、控制/共同控制/重大影响、以及关联方关系的基础。复核聚焦持股与表决权比例准确性、控制关系判断的信息完整性、以及与后续核算方法选择的一致性。

**法规依据：**
- 《企业会计准则第2号——长期股权投资》
- 《企业会计准则第33号——合并财务报表》
- 《企业会计准则第36号——关联方披露》

---

## tips

1. **持股比例≠表决权比例**：控制/影响判断以表决权比例为基础，存在优先股、一致行动、表决权委托时二者可能不一致，须分别登记。
2. **基本信息决定核算方法**：控制→纳入合并（母公司报表成本法）、共同控制/重大影响→权益法、无重大影响→金融资产，信息错误导致方法错误。
3. **实质重于形式**：即使持股低于20%，若通过董事会席位、重大交易等对被投资单位有重大影响，仍应用权益法。
4. **关联方识别基础**：被投资单位（尤其合营/联营）通常构成关联方，基本信息是CAS36关联方披露的来源。
5. **取得方式影响初始计量**：同一控制下/非同一控制下合并、非合并方式取得，初始投资成本计量不同。
6. **信息更新及时性**：注册资本变更、股权结构调整等须及时更新，避免基于过期信息判断。

## checklist

### 一、基本信息准确性

- [ ] 被投资单位名称、统一社会信用代码是否准确
- [ ] 注册资本、实缴资本是否与工商登记/验资一致
- [ ] 持股比例是否与出资协议/股权结构一致
- [ ] 表决权比例是否单独登记（存在优先股/一致行动时）
- [ ] 成立日期、注册地、主营业务是否登记

### 二、控制关系判断

- [ ] 是否根据表决权比例正确判断控制/共同控制/重大影响
- [ ] 是否考虑潜在表决权、一致行动、董事会席位等实质影响因素
- [ ] 持股低于20%但有重大影响的是否已识别并说明
- [ ] 控制关系判断是否与核算方法选择一致

### 三、取得方式与关联方

- [ ] 取得投资方式（同一控制/非同一控制合并/非合并取得）是否登记
- [ ] 取得方式是否与初始投资成本计量方法一致
- [ ] 合营/联营企业是否已识别为关联方
- [ ] 信息是否及时更新（注册资本/股权变更）

## risk_areas

### 高风险

1. **控制关系判断错误**：持股/表决权信息错误或忽略实质影响因素，导致合营/联营误判为金融资产（或反之），核算方法错误。
2. **实质重大影响遗漏**：持股低于20%但实际有重大影响未识别，应用权益法却按金融资产核算。
3. **取得方式判断错误**：同一控制/非同一控制判断错误，初始投资成本计量错误。

### 中风险

1. **表决权比例未单独登记**：存在优先股/一致行动时仅登记持股比例，控制判断基础不准。
2. **关联方识别遗漏**：合营/联营企业未纳入关联方，影响CAS36披露。
3. **信息更新滞后**：注册资本/股权结构变更未及时更新。

### 低风险

1. **辅助信息不完整**：主营业务、成立日期等登记不全。
2. **索引引用缺失**：未与工商登记、出资协议建立索引。
3. **格式不规范**：登记表字段不统一。
