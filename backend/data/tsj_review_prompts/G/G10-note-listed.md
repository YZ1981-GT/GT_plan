# G10-note-listed 交易性金融负债附注披露 复核提示词（上市公司）

## 概述

本提示词针对交易性金融负债上市公司附注披露底稿（G10-note-listed）的复核，聚焦FVTPL金融负债的分类披露、公允价值层次披露、第三层次公允价值调节披露、公允价值变动损益披露、自身信用风险变动披露、以及衍生金融负债披露的充分性和准确性。交易性金融负债公允价值变动直接进损益，衍生工具估值不确定性高，披露不充分将影响投资者对损益质量和金融风险的判断。

**法规依据：**
- 《企业会计准则第37号——金融工具列报》
- 《企业会计准则第22号——金融工具确认和计量》
- 《企业会计准则第39号——公允价值计量》

## tips

1. **分类披露FVTPL属性**：附注须明确交易性金融负债的构成（交易目的负债/衍生金融负债/指定FVTPL负债），并说明分类依据。
2. **公允价值层次强制披露**：须按第一/二/三层次披露公允价值，第三层次须披露估值技术、关键不可观察输入及调节表。
3. **公允价值变动损益披露**：须披露本期计入损益的公允价值变动金额，与利润表勾稽。
4. **自身信用风险披露**：指定为FVTPL的金融负债须披露因自身信用风险变化引起的公允价值变动金额（计入OCI部分）。
5. **衍生金融负债披露**：须披露衍生金融负债的名义金额、公允价值、到期期限分布及风险类型。
6. **附注勾稽底稿闭环**：附注金额须与G10-1审定表、G10-2明细表、G10-5公允价值测试、G10-6调节表、G10-8衍生检查形成闭环勾稽。

## checklist

### 一、分类与构成披露

- [ ] 是否披露交易性金融负债构成（交易目的/衍生/指定FVTPL）
- [ ] 期末余额是否等于审定表审定数
- [ ] 是否同时披露期末数和期初数（可比信息）
- [ ] 分类依据是否披露

### 二、公允价值层次与调节

- [ ] 是否按第一/二/三层次披露公允价值
- [ ] 第三层次是否披露估值技术和关键不可观察输入
- [ ] 第三层次公允价值调节表是否完整（与G10-6一致）
- [ ] 层次间转移是否披露及说明

### 三、损益、信用风险与衍生

- [ ] 本期计入损益的公允价值变动是否披露且与利润表勾稽
- [ ] 指定FVTPL负债自身信用风险变动（计入OCI）是否披露
- [ ] 衍生金融负债名义金额、公允价值、到期分布是否披露
- [ ] 附注各项金额是否与G10-1/G10-2/G10-5/G10-6/G10-8勾稽

## risk_areas

### 高风险

1. **公允价值变动损益披露与利润表不一致**：附注披露的公允价值变动与利润表不勾稽，属重大披露错误。
2. **自身信用风险变动未披露**：指定FVTPL负债自身信用风险变动（进OCI）未披露，不满足CAS37要求。
3. **第三层次调节表不完整或不勾稽**：调节表要素缺失或与G10-6不一致。
4. **附注总额与审定表不一致**：附注期末余额与审定表审定数不一致。

### 中风险

1. **衍生金融负债披露不足**：未披露衍生负债名义金额、到期分布等。
2. **公允价值层次披露缺失**：未按层次披露或第三层次估值假设不披露。
3. **构成披露不清**：未清晰披露交易性金融负债构成。

### 低风险

1. **披露格式不完全规范**：表格标题、列序、单位等格式细节。
2. **文字描述模板化**：估值方法描述照搬未结合企业实际。
3. **可比信息简略**：期初可比数据列示不完整。
