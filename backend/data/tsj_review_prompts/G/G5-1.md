# G5-1 长期应收款审定表复核提示词

## 概述

本提示词针对长期应收款（科目1531）审定表（G5-1）的复核，聚焦融资租赁应收款、分期收款销售应收款的期初期末勾稽、未实现融资收益核算、实际利率法确认融资收益、预期信用损失计提、一年内到期重分类及分类列报。长期应收款涉及CAS21租赁准则和CAS22金融工具准则，未实现融资收益的核算和减值是审定的两大核心。

**法规依据：**
- 《企业会计准则第21号——租赁》
- 《企业会计准则第22号——金融工具确认和计量》
- 《企业会计准则第37号——金融工具列报》
- 《中国注册会计师审计准则第1301号——审计证据》

## tips

1. **期初期末勾稽是审定表的生命线**：期初审定数须等于上年期末审定数，差异需追溯至新增、融资收益确认、收款或减值调整。
2. **长期应收款净额=应收总额−未实现融资收益**：审定表应清晰反映应收款项总额、未实现融资收益、净额，勾稽须成立。
3. **融资收益按实际利率法确认**：未实现融资收益应在租赁期/收款期内按实际利率法分摊为融资收益（利息收入），须与G5-5摊销表勾稽。
4. **一年内到期须重分类**：一年内到期的长期应收款净额应重分类至一年内到期的非流动资产，须核对RJE。
5. **ECL须计提**：长期应收款须按CAS22计量预期信用损失，与G5-8/G5-9/G5-10勾稽。
6. **试算平衡表核对**：审定表长期应收款审定数合计须与试算平衡表1531科目审定数一致（含总额/未实现融资收益/减值明细）。

## checklist

### 一、期初期末勾稽

- [ ] 期初未审数是否等于上年审定表期末审定数
- [ ] 期末净额=期初+新增应收−收款+融资收益确认−减值，滚动是否成立
- [ ] 审定表各行变动是否与G5-2余额明细表增减一致
- [ ] 应收总额、未实现融资收益、净额勾稽是否成立

### 二、融资收益与实际利率法

- [ ] 未实现融资收益是否按实际利率法在期间内分摊
- [ ] 本期确认融资收益是否与G5-5融资租赁摊销表勾稽
- [ ] 分期收款销售融资收益是否与G5-6勾稽
- [ ] 实际利率确定是否合理

### 三、减值与试算核对

- [ ] 预期信用损失是否计提（与G5-8/G5-9/G5-10勾稽）
- [ ] 长期应收款减值准备是否单独列示
- [ ] 审定数合计是否与试算平衡表1531科目一致
- [ ] 所有AJE/RJE是否完整反映在审定表调整列

### 四、分类列报

- [ ] 一年内到期的长期应收款净额是否重分类至一年内到期的非流动资产
- [ ] 未实现融资收益是否作为长期应收款的备抵列示
- [ ] 关联方长期应收款是否单独列示
- [ ] 审定表分类是否与附注披露一致

## risk_areas

### 高风险

1. **未实现融资收益核算错误**：未按实际利率法分摊融资收益，或应收总额与净额勾稽不成立，导致资产和融资收益失真。
2. **ECL计提不足**：长期应收款预期信用损失少提，虚增净额。
3. **期初期末不勾稽**：期初审定数与上年期末不一致，存在未授权调整。
4. **一年内到期未重分类**：一年内到期部分未重分类，流动性列报错误。
5. **审计调整遗漏或缺乏审批**：已确认调整未反映在审定表，或未经合伙人批准。

### 中风险

1. **明细与汇总不勾稽**：审定表合计与G5-2余额明细表不一致。
2. **融资收益确认与摊销表不一致**：本期融资收益与G5-5/G5-6摊销不符。
3. **未实现融资收益列示错误**：未作为备抵列示或方向错误。

### 低风险

1. **审定表格式不规范**：列标题、行顺序、编号格式问题。
2. **底稿交叉索引不完整**：未与G5-2/G5-5/G5-10及试算平衡表建立索引。
3. **辅助说明不充分**：变动较大行项目未附说明。
