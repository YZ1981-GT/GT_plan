# G5-note-listed 长期应收款附注披露复核提示词（上市公司）

## 概述

本提示词针对长期应收款上市公司附注披露底稿（G5-note-listed）的复核，聚焦上市公司财务报表附注中长期应收款相关披露：分类构成（融资租赁应收款/分期收款销售等）、未实现融资收益披露、坏账准备三阶段披露、信用风险披露、一年内到期部分披露及CAS37/CAS21列报要求。

**法规依据：**
- 《企业会计准则第37号——金融工具列报》
- 《企业会计准则第21号——租赁》
- 《企业会计准则第22号——金融工具确认和计量》
- 《公开发行证券的公司信息披露编报规则第15号——财务报告的一般规定》

---

## tips

1. **长期应收款须披露净额构成**：附注应披露应收款项总额、未实现融资收益、减值准备、净额，与G5-1审定表勾稽。
2. **融资租赁应收款须专项披露**：CAS21要求出租方披露融资租赁应收款的未担保余值、未实现融资收益、租赁收款额到期分布。
3. **坏账准备三阶段披露**：CAS37要求披露减值准备按三阶段（或简化方法存续期ECL）的期初期末变动。
4. **一年内到期部分披露**：附注须披露一年内到期的长期应收款净额（重分类至一年内到期的非流动资产）。
5. **信用风险披露**：须披露信用风险敞口、按信用等级/阶段分布、ECL计量方法和关键假设。
6. **关联方长期应收款单独披露**：与关联方的长期应收款须按CAS36单独列示。

## checklist

### 一、分类与净额构成披露

- [ ] 长期应收款是否按类别（融资租赁/分期收款销售/其他）分类披露
- [ ] 是否披露应收总额/未实现融资收益/减值准备/净额构成
- [ ] 净额合计是否等于G5-1审定表审定数
- [ ] 是否同时披露期末数和期初数

### 二、融资租赁与到期披露

- [ ] 融资租赁应收款是否披露未担保余值、未实现融资收益
- [ ] 租赁收款额到期分布是否披露（CAS21）
- [ ] 一年内到期部分净额是否单独披露
- [ ] 分期收款销售融资成分是否披露

### 三、减值与信用风险披露

- [ ] 坏账准备是否按三阶段/存续期披露期初期末变动
- [ ] 变动表是否与G5-3/G5-10勾稽
- [ ] 是否披露信用风险敞口和ECL计量方法/关键假设
- [ ] 逾期/信用减值长期应收款是否单独披露

### 四、关联方与勾稽

- [ ] 关联方长期应收款是否单独披露（名称/关系/金额）
- [ ] 本期融资收益是否与G5-5/G5-6/利润表勾稽
- [ ] 附注分类是否与审定表一致

## risk_areas

### 高风险

1. **附注净额与审定表不一致**：附注长期应收款净额与G5-1审定数不符，属重大数据勾稽错误。
2. **减值准备三阶段披露缺失**：未按三阶段/存续期披露减值准备变动，不满足CAS37要求。
3. **未实现融资收益披露缺失**：未披露未实现融资收益，长期应收款计量信息不完整。

### 中风险

1. **融资租赁专项披露不足**：未披露未担保余值、租赁收款到期分布。
2. **一年内到期未单独披露**：一年内到期部分未披露，流动性信息不足。
3. **信用风险披露不充分**：未披露ECL计量方法和关键假设。

### 低风险

1. **披露格式不规范**：表格标题、列序、单位格式细节问题。
2. **文字描述模板化**：信用风险政策照搬会计政策原文。
3. **可比信息缺失**：仅披露期末数据未披露期初可比数据。
