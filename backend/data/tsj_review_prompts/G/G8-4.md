# G8-4 其他权益工具投资公允价值测试 复核提示词

## 概述

本提示词针对其他权益工具投资公允价值测试表（G8-4）的复核。其他权益工具投资以公允价值计量，须按公允价值层次（第一/二/三层次）确定并测试期末公允价值。上市股权采用活跃市场报价（第一层次），非上市股权多采用估值技术（第三层次，如市场法/收益法/成本法）。复核聚焦公允价值层次划分、估值技术选择、关键不可观察输入的合理性、以及测试结果与明细表/审定表的勾稽。

**法规依据：**
- 《企业会计准则第22号——金融工具确认和计量》
- 《企业会计准则第39号——公允价值计量》
- 《企业会计准则第37号——金融工具列报》

---

## tips

1. **公允价值层次**：第一层次=活跃市场未调整报价；第二层次=可观察输入（类似资产报价/可观察参数）；第三层次=不可观察输入（估值模型+管理层假设）。
2. **上市股权用报价**：持有上市公司股票以资产负债表日活跃市场收盘价/报价计量（第一层次），不得随意调整。
3. **非上市股权用估值**：非上市股权采用市场法（可比公司/交易）、收益法（现金流折现）或最近交易价，须评估方法适当性和输入合理性。
4. **关键假设合理性**：第三层次估值的折现率、增长率、流动性折扣、可比公司选取等关键假设须有依据。
5. **估值日一致**：公允价值测算须以资产负债表日为估值日，避免使用过期估值。
6. **勾稽明细审定表**：测试确定的公允价值须与G8-2明细表、G8-1审定表勾稽。

## checklist

### 一、公允价值层次

- [ ] 各笔投资是否明确划分公允价值层次
- [ ] 上市股权是否采用活跃市场报价（第一层次，未调整）
- [ ] 非上市股权是否采用估值技术（第三层次）
- [ ] 层次划分是否与输入值可观察性匹配

### 二、估值技术与假设

- [ ] 第三层次估值技术（市场法/收益法/成本法）选择是否适当
- [ ] 关键不可观察输入（折现率/增长率/流动性折扣）是否有依据
- [ ] 可比公司/可比交易选取是否合理
- [ ] 估值是否以资产负债表日为估值日

### 三、结果与勾稽

- [ ] 测试确定的公允价值是否与G8-2明细表一致
- [ ] 公允价值是否与G8-1审定表勾稽
- [ ] 是否有估值报告或估值底稿支持
- [ ] 重大估值是否考虑利用专家工作

## risk_areas

### 高风险

1. **非上市股权估值高估**：第三层次估值采用过于乐观假设（低折现率/高增长率）导致公允价值高估、资产虚增。
2. **估值技术选择不当**：对不适用的投资采用不恰当估值方法，公允价值失真。
3. **使用过期估值**：未以资产负债表日为估值日，公允价值不反映期末状况。

### 中风险

1. **层次划分错误**：将第三层次估值误划为第二层次，掩盖估值不确定性。
2. **关键假设缺乏支持**：折现率、可比公司选取等假设无客观依据。
3. **上市股权报价调整**：对上市股权活跃市场报价随意调整。

### 低风险

1. **估值报告索引缺失**：公允价值来源未建立索引。
2. **假设敏感性未分析**：第三层次估值未做关键假设敏感性分析。
3. **格式不规范**：测试表字段不统一。
