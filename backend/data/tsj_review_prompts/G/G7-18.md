# G7-18 长期股权投资凭证检查 复核提示词

## 适用底稿
长期股权投资凭证检查表（G7-18），聚焦样本选取合理性、凭证核对完整性、检查比例达标性、异常交易标注充分性。

## tips

- 样本选取应覆盖本期新增投资、追加投资、处置、减值计提等所有重大变动
- 凭证核对须验证投资的真实性、金额准确性、权属清晰性（出资协议→验资/交割→工商变更→记账）
- 检查比例应满足《中国注册会计师审计准则第1314号——审计抽样》要求
- 重大投资/处置应100%检查，关联方投资须单独关注公允性
- 异常标注：投资价款与评估价值大幅偏离、无实际出资的股权登记、循环出资等
- 处置凭证须核对转让协议、收款凭证、工商变更登记，验证丧失控制权时点
- 减值计提凭证须核对减值测试底稿和审批
- 关注期末突击投资、体外资金循环、以投资名义的资金占用

## checklist

### 高风险检查项

- [ ] 样本选取是否覆盖本期所有重大投资变动（新增/追加/处置/减值）
- [ ] 重大投资/处置（超重要性水平）是否100%检查
- [ ] 出资是否有真实资金流出（验资报告/银行回单/交割凭证）
- [ ] 投资价款与被投资单位评估价值是否匹配（防高价利益输送）
- [ ] 股权取得是否办理工商变更登记（权属清晰）
- [ ] 处置凭证是否完整（转让协议/收款/工商变更）
- [ ] 关联方投资是否核查交易公允性
- [ ] 是否存在无实际业务的循环出资/资金占用

### 中风险检查项

- [ ] 抽样方法是否符合CAS1314要求
- [ ] 检查比例（已检查金额/总体金额）是否达到计划水平
- [ ] 投资的初始计量凭证（成本法/权益法/合并）是否核对
- [ ] 现金股利收取凭证是否核对（分方法确认）
- [ ] 减值计提凭证是否核对减值测试和审批
- [ ] 凭证日期与记账日期是否一致，是否跨期
- [ ] 核对差异是否逐一追踪解决

### 低风险检查项

- [ ] 抽样参数（总体/置信水平/可容忍偏差）是否完整记录
- [ ] 样本选取过程是否可追溯
- [ ] 检查结果记录格式是否规范统一
- [ ] 检查比例计算公式是否正确
- [ ] 底稿索引与交叉引用是否完整

## risk_areas

### 高风险

1. **虚假出资风险**：股权登记但无真实资金流出，或出资后抽逃，虚增长期股权投资。
2. **高价投资利益输送风险**：投资价款远高于被投资单位公允价值，向关联方输送利益。
3. **处置时点操纵风险**：处置/丧失控制权时点凭证不清，跨期确认处置损益调节利润。
4. **减值不实风险**：减值计提凭证缺乏减值测试支持，或应提未提。
5. **循环出资风险**：以投资名义的体外资金循环，无实际经营实质。

### 中风险

1. **检查比例不足风险**：实际检查比例低于计划，审计证据不充分。
2. **权属不清风险**：股权取得未办理工商变更登记，权属存在争议。
3. **计量凭证核对不足风险**：初始计量/后续计量凭证核对深度不够。
4. **关联方公允性核查不足风险**：关联方投资未实施针对性公允性核查。

### 低风险

1. **记录不完整风险**：抽样参数/选取过程/核对结果记录不完整。
2. **索引缺失风险**：凭证检查与审定表/明细表交叉索引不完整。
3. **格式不规范风险**：检查结果记录格式不统一。
