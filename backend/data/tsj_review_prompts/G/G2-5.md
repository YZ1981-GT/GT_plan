# G2-5 应收利息利息测算表复核提示词

## 概述

本提示词针对应收利息利息测算表（G2-5）的复核，聚焦逐笔本金、利率、计息期间的独立利息测算，验证企业计提金额的准确性。审计师应基于合同条款独立测算应计利息并与账面计提对比，差异须查明。利息测算是应收利息存在性和准确性的核心程序。

**法规依据：**
- 《企业会计准则第22号——金融工具确认和计量》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **独立测算是核心程序**：审计师应基于本金、合同利率、计息天数独立测算应计利息，而非仅复核企业计算。
2. **利率来源须核对合同**：测算所用利率须核对至借款合同、存款协议、债券票面利率，浮动利率须核对基准和加点。
3. **计息天数口径须一致**：360天或365天基数须与合同约定一致，起息日和计息止日须准确。
4. **实际利率法与合同利率区分**：债权投资利息按实际利率法确认，应收利息为合同应收未收部分，测算口径须清晰。
5. **测算差异须查明**：独立测算金额与账面计提差异须查明原因（利率错误/天数错误/漏计），评估是否需调整。
6. **测算结果联动审定表**：G2-5测算合计须与G2-1审定表计提金额、G2-2明细表勾稽。

---

## checklist

### 一、测算参数核对

- [ ] 每笔本金是否核对至合同/协议
- [ ] 利率是否核对至合同票面利率/基准利率+加点
- [ ] 浮动利率的重定价是否正确反映
- [ ] 计息起止日期是否准确

### 二、测算准确性

- [ ] 应计利息=本金×利率×天数/基数，独立测算是否正确
- [ ] 计息天数基数（360/365）是否与合同一致
- [ ] 实际利率法与合同利率口径是否正确区分
- [ ] 分段计息（利率变动）是否正确处理

### 三、差异与勾稽

- [ ] 独立测算金额与账面计提差异是否查明原因
- [ ] 测算合计是否与G2-1审定表计提金额勾稽
- [ ] 测算结果是否与G2-2明细表一致
- [ ] 重大差异是否评估调整（转G2-4）

## risk_areas

### 高风险

1. **利息计提错误未发现**：独立测算未执行或测算错误，未能发现企业多计/少计利息。
2. **利率或天数取数错误**：测算所用利率、计息天数错误导致测算失真，无法验证账面准确性。
3. **测算与审定表脱节**：G2-5测算结果与G2-1审定数不勾稽。

### 中风险

1. **实际利率法口径混淆**：债权投资利息与合同利息口径混淆，重复或遗漏测算。
2. **浮动利率处理错误**：浮动利率重定价未正确反映在测算中。
3. **差异未查明**：测算与账面差异存在但未查明原因。

### 低风险

1. **测算底稿记录不充分**：测算参数、来源记录简略。
2. **交叉索引不完整**：G2-5未与G2-1/G2-2建立索引。
