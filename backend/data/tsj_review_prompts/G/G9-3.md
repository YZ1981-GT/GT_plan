# G9-3 其他非流动金融资产调整分录汇总 复核提示词

## 适用底稿
其他非流动金融资产调整分录汇总表（G9-3），含账项调整（AJE）、重分类调整（RJE）及未调整错报（SUD）评估。

## 概述
G9-3 是其他非流动金融资产审定数链路的关键环节。复核须验证：每笔调整有充分证据、借贷平衡、完整反映到 G9-1 审定表、公允价值变动调整计入损益方向正确、流动性重分类恰当、SUD 评估符合重要性水平要求。

---

## tips

1. **AJE vs RJE**：AJE 影响资产或损益金额（如公允价值调整）；RJE 仅影响列报（如一年内收回重分类至流动资产），不得通过 RJE 掩盖损益错报。
2. **公允价值调整进损益**：FVTPL资产公允价值变动调整须计入当期损益（公允价值变动损益），不进OCI。
3. **流动性重分类**：一年内到期/收回部分从非流动重分类至流动资产（交易性金融资产），属RJE。
4. **与 G9-1 勾稽**：审定表调整列金额须与 G9-3 已确认分录逐笔一致。
5. **SUD 累计**：未调整错报单独及累计是否超过阈值，须与 A13 未调整错报汇总交叉验证。
6. **TB 回写**：确认调整已同步试算平衡表其他非流动金融资产科目。

## checklist

### 一、调整证据与审批

- [ ] 所有 AJE 是否有充分审计证据（估值差异、公允价值重算等）
- [ ] AJE 是否经适当层级审批
- [ ] 每笔调整分录借贷方是否完全平衡
- [ ] 是否存在为美化资产或损益的不当调整

### 二、方向与重分类

- [ ] 公允价值变动调整是否计入当期损益（不进OCI）
- [ ] 流动性重分类（一年内收回）是否作为RJE处理
- [ ] 处置损益调整是否正确
- [ ] RJE 是否仅涉及列报未影响损益

### 三、勾稽与SUD

- [ ] 调整金额是否完整反映到 G9-1 审定表对应调整列
- [ ] 调整后审定数是否与试算平衡表科目勾稽
- [ ] 未调整错报累计是否超过整体重要性水平（须评估）
- [ ] 与 A13 未调整错报汇总表索引是否完整

## risk_areas

### 高风险

1. **调整缺乏证据或未经授权**：调整分录无证据支持或未经审批。
2. **公允价值调整方向错误**：FVTPL公允价值变动调整错误计入OCI而非损益。
3. **审定表与G9-3长期不一致**：调整金额未逐笔反映到审定表。

### 中风险

1. **RJE误含损益影响**：流动性重分类调整不当影响损益。
2. **重分类遗漏**：一年内收回部分未重分类至流动资产。
3. **TB未同步**：调整已入底稿但试算平衡表未更新。

### 低风险

1. **编号、格式不规范**：分录编号删除后重号风险、摘要不清。
2. **索引指向不完整**：未指向估值报告等支持底稿。
