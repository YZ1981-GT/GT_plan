# G7-12 长期股权投资处置（一揽子交易） 复核提示词

## 概述

本提示词针对通过多次交易分步处置对子公司投资且构成一揽子交易的核算表（G7-12）的复核。构成一揽子交易的多次处置应作为一项处置子公司并丧失控制权的交易进行会计处理，各次交易在丧失控制权前的处置价款与对应净资产份额的差额先计入其他综合收益，丧失控制权时一并转入丧失控制权当期损益。复核聚焦一揽子交易认定、各次交易处理、累计OCI转入损益、以及剩余股权重新计量。

**法规依据：**
- 《企业会计准则第2号——长期股权投资》
- 《企业会计准则第33号——合并财务报表》

---

## tips

1. **一揽子交易认定**：判断多次交易是否为一揽子交易须考虑：同时订立/相互影响、构成完整商业结果、一项交易的发生取决于其他交易、单独看不经济但整体看经济。
2. **丧失控制权前处置进OCI**：一揽子交易中，丧失控制权前各次处置价款与对应享有子公司净资产份额的差额，先计入其他综合收益。
3. **丧失控制权时一并转损益**：丧失控制权时，累计计入OCI的金额一并转入丧失控制权当期的投资收益。
4. **剩余股权重新计量**：丧失控制权时剩余股权按公允价值重新计量，与账面价值差额计入投资收益。
5. **各次交易明细**：须逐次记录各次交易的处置比例、价款、对应净资产份额、计入OCI金额及累计额。
6. **盈余公积比例配置**：涉及留存收益结转的须按适当比例处理，可配置。

## checklist

### 一、一揽子交易认定

- [ ] 是否评估多次交易是否构成一揽子交易（四个判断条件）
- [ ] 认定依据是否充分记录
- [ ] 若不构成一揽子交易是否应用G7-11单次处置处理

### 二、各次交易处理

- [ ] 各次交易的处置比例、价款是否准确记录
- [ ] 丧失控制权前各次处置差额是否计入其他综合收益
- [ ] 累计计入OCI金额是否逐次滚动正确
- [ ] 是否记录各次交易明细（steps）

### 三、丧失控制权处理

- [ ] 丧失控制权时累计OCI是否一并转入投资收益
- [ ] 剩余股权是否按公允价值重新计量
- [ ] 重新计量差额是否计入投资收益
- [ ] 处置损益和OCI结转是否传递至审定表

## risk_areas

### 高风险

1. **一揽子交易认定错误**：应作一揽子交易处理却按多次单独交易（或反之），处置损益确认时点和金额错误。
2. **累计OCI未转损益**：丧失控制权时累计计入OCI的金额未一并转入投资收益，损益重大错报。
3. **剩余股权未重新计量**：丧失控制权时剩余股权未按公允价值重估，资产和损益失真。

### 中风险

1. **各次交易OCI滚动错误**：丧失控制权前各次处置差额计入OCI的累计滚动错误。
2. **处置比例计算错误**：各次处置比例或对应净资产份额计算错误。
3. **留存收益结转比例错误**：盈余公积结转比例处理不当。

### 低风险

1. **各次交易明细不完整**：steps记录缺失影响可追溯性。
2. **认定依据文档不充分**：一揽子交易判断依据记录不足。
3. **索引引用缺失**：未与转让协议、审定表建立索引。
