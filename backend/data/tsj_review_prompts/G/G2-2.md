# G2-2 应收利息明细表复核提示词

## 概述

本提示词针对应收利息明细表（G2-2）的复核，聚焦逐笔应收利息的债务人、本金、利率、计息期间、计提金额、已收金额、期末余额的明细核对，以及明细合计与审定表（G2-1）的勾稽。明细表是审定表的支撑基础，须逐项核对至借款合同、存款协议、债券条款等证据。

**法规依据：**
- 《企业会计准则第22号——金融工具确认和计量》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **逐笔明细须核对至合同**：每笔应收利息的本金、利率、计息期间应核对至借款合同、存款协议或债券条款。
2. **明细合计必须与审定表勾稽**：明细表应收利息期末余额合计须等于G2-1审定表审定数。
3. **利息计算须验算**：计提利息=本金×利率×计息天数/360（或365），须重新验算，关注利率和天数口径。
4. **已收利息可追溯凭证**：本期已收利息须与G2-8凭证检查、银行流水勾稽。
5. **区分不同来源利息**：债权投资利息、存款利息、借款利息、往来款利息应分类列示，来源清晰。
6. **关注长账龄未收利息**：长期未收回的应收利息应标注，与G2-6长期未收回检查联动。

---

## checklist

### 一、明细核对完整性

- [ ] 每笔应收利息的债务人、本金、利率、计息期间是否完整记录
- [ ] 本金和利率是否核对至借款合同/存款协议/债券条款
- [ ] 计息期间起止是否准确
- [ ] 是否存在明细遗漏或重复

### 二、利息计算核对

- [ ] 计提利息=本金×利率×天数/基数，验算是否正确
- [ ] 计息天数口径（360/365）是否一致且与合同相符
- [ ] 明细计提金额合计是否与G2-5利息测算表勾稽
- [ ] 明细期末余额合计是否等于G2-1审定表审定数

### 三、收回与账龄

- [ ] 本期已收利息是否与G2-8凭证检查/银行流水勾稽
- [ ] 长账龄未收利息是否标注（与G2-6联动）
- [ ] 不同来源利息是否分类列示
- [ ] 关联方应收利息是否可识别

## risk_areas

### 高风险

1. **利息计算错误**：本金、利率或计息天数取数错误导致计提金额失真。
2. **明细合计与审定表不符**：明细期末余额合计与G2-1审定数不一致，勾稽断裂。
3. **虚构应收利息**：无合同支撑的应收利息明细，虚增资产。

### 中风险

1. **利率天数口径不一致**：不同明细采用不同计息基数，计提口径不统一。
2. **已收利息不可追溯**：本期已收利息未与凭证/流水勾稽。
3. **来源分类混乱**：不同来源利息未分类，难以核对本金。

### 低风险

1. **明细记录格式不统一**：债务人、金额、日期记录不规范。
2. **交叉索引不完整**：明细未与G2-5/G2-6/G2-8建立索引。
3. **长账龄未标注**：长期未收利息未标注提示。
