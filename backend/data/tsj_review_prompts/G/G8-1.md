# G8-1 其他权益工具投资审定表 复核提示词

## 概述

本提示词针对其他权益工具投资审定表（G8-1，科目1502）的复核。其他权益工具投资是企业不可撤销地指定为以公允价值计量且其变动计入其他综合收益的非交易性权益工具投资，公允价值变动计入OCI且以后不得转入损益（处置时累计OCI转入留存收益），仅股利收入计入投资收益。审定表须完整反映未审→调整→审定链路，勾稽公允价值、OCI累计额及试算平衡表。

**法规依据：**
- 《企业会计准则第22号——金融工具确认和计量》
- 《企业会计准则第37号——金融工具列报》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **指定不可撤销**：其他权益工具投资须在初始确认时不可撤销地指定为FVOCI，且限于非交易性权益工具，审定表基础是该指定成立（G8-5）。
2. **OCI变动不转损益**：公允价值变动计入其他综合收益，与其他债权投资不同，处置时累计OCI不转损益而转留存收益，审定表须体现该差异。
3. **仅股利进损益**：其他权益工具投资仅在被投资单位宣告分派股利时确认投资收益，其余公允价值变动均进OCI。
4. **期初期末承前启后**：期初审定数、OCI累计余额须等于上年期末，任何差异须追溯。
5. **试算平衡表核对**：审定数合计须与试算平衡表其他权益工具投资科目审定数一致。
6. **调整完整性**：审定数=未审数+AJE+RJE，所有调整完整反映。

## checklist

### 一、指定与OCI勾稽

- [ ] 是否有初始确认时不可撤销指定为FVOCI的依据（G8-5）
- [ ] 期初审定数、OCI累计余额是否等于上年期末
- [ ] 公允价值变动是否计入OCI（不进损益）
- [ ] 期末审定数是否等于期初审定数加本期增减（购入/出售/公允价值变动）

### 二、试算平衡表核对

- [ ] 审定数合计是否与试算平衡表其他权益工具投资科目审定数一致
- [ ] 未审数、调整数与审定表对应列是否一致
- [ ] OCI累计额是否与其他综合收益科目勾稽

### 三、审计调整完整性

- [ ] 所有账项调整（AJE）是否完整反映在审定表调整列
- [ ] 所有重分类调整（RJE）是否完整反映
- [ ] 调整分录借贷方是否平衡
- [ ] 审定后金额是否等于未审数+AJE+RJE
- [ ] 建议但未调整的错报是否记录于未调整错报汇总表

### 四、处置与分类

- [ ] 处置时累计OCI是否转入留存收益（不转损益）
- [ ] 股利收入是否计入投资收益
- [ ] 审定表分类是否与财务报表附注披露一致

## risk_areas

### 高风险

1. **处置OCI错误转损益**：其他权益工具投资处置时累计OCI应转留存收益却错误转入损益，虚增/虚减利润。
2. **公允价值变动计入损益**：将公允价值变动错误计入损益而非OCI，扭曲当期利润。
3. **指定不成立**：无初始确认时不可撤销指定依据（或指定了交易性权益工具），分类基础不成立。
4. **期初期末不勾稽**：期初审定数或OCI累计余额与上年期末不一致。
5. **审计调整遗漏**：已确认调整未反映在审定表。

### 中风险

1. **明细与汇总不勾稽**：审定表各行合计与G8-2明细表总计不一致。
2. **股利收入处理错误**：股利收入未计入投资收益或误进OCI。
3. **审定表与附注口径不一致**：审定表分类与附注披露不一致。

### 低风险

1. **审定表格式不规范**：列标题、行顺序等格式问题。
2. **底稿交叉索引不完整**：未与明细表、指定检查建立索引。
3. **辅助说明不充分**：变动较大行项目未附说明。
