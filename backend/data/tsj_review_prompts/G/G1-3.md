# G1-3 交易性金融资产调整分录复核提示词

## 适用底稿
交易性金融资产调整分录汇总表（G1-3），含账项调整（AJE）、重分类调整（RJE）及未调整错报（SUD）评估。

## 概述
G1-3 是审定数链路的关键环节。复核须验证：每笔调整有证据、借贷平衡、完整反映到 G1-1 审定表、公允价值调整与损益结转匹配、SUD 评估符合重要性水平要求。

---

## tips

1. **AJE vs RJE**：AJE 影响公允价值变动损益或资产金额；RJE 仅影响列报（如一年内到期重分类），不得通过 RJE 掩盖损益错报。
2. **公允价值调整须双向匹配**：调增/调减交易性金融资产公允价值时，对应的公允价值变动损益必须同步调整，借贷不可单边。
3. **与 G1-1 勾稽**：审定表调整列金额须与 G1-3 已确认分录逐笔一致，遗漏任一笔即审定数失真。
4. **审批链**：超过明细层次重要性水平的调整须合伙人/项目经理审批留痕。
5. **SUD 累计**：未调整错报单独及累计是否超过整体/明显微小错报阈值，须与 A13 未调整错报汇总交叉验证。
6. **TB 回写**：确认调整已同步试算平衡表（1101 及公允价值变动损益科目），避免「底稿已调、TB 未更」双真源。

## checklist

### 高风险检查项

- [ ] 所有 AJE 是否有充分审计证据（估值差异、公允价值复核、管理层确认等）
- [ ] 公允价值调整分录借贷方是否完全平衡且损益对应
- [ ] AJE 是否经适当层级审批（超重要性水平须合伙人知悉）
- [ ] 调整金额是否完整反映到 G1-1 审定表对应调整列
- [ ] 是否存在仅为美化投资收益或规避亏损的不当调整
- [ ] 未调整错报累计是否超过整体重要性水平（须评估）

### 中风险检查项

- [ ] RJE 是否仅涉及列报（如一年内到期），未影响损益类科目
- [ ] 调整原因说明是否清晰可追溯至具体审计程序（G1-6公允价值测试等）
- [ ] 与 A13 未调整错报汇总表索引是否完整
- [ ] 调整分录编号是否连续，删除后重号风险可控

### 低风险检查项

- [ ] 分录摘要、科目编码规范
- [ ] 索引指向 G1-6 公允价值测试、G1-13 凭证检查等支持底稿
- [ ] 审计说明/结论是否概括调整性质与剩余风险

## risk_areas

### 高风险

1. **调整缺乏证据或未经授权**：公允价值调整无估值复核支持或未经合伙人审批，调整可靠性存疑。
2. **公允价值调整单边失衡**：仅调整资产未同步调整损益，或借贷不平衡，导致审定数与损益脱节。
3. **审定表与调整金额不一致**：G1-1审定表调整列与G1-3已确认分录长期不符，勾稽断裂。

### 中风险

1. **RJE 误含损益影响**：重分类调整错误影响公允价值变动损益或投资收益科目。
2. **SUD 累计超阈值未处理**：未调整错报累计超过整体重要性水平但未恰当处理。

### 低风险

1. **编号格式不规范**：分录编号、摘要、科目编码不规范，影响底稿可读性。
2. **索引不完整**：调整分录未指向支持底稿（G1-6/G1-13）。

## 跨底稿勾稽

- G1-3 已确认 AJE/RJE 合计 ↔ G1-1 审定表调整列
- G1-3 公允价值调整 ↔ G1-6 公允价值测试差异
- G1-3 SUD ↔ A13 未调整错报汇总
- 调整后审定数 ↔ 试算平衡表 1101 及公允价值变动损益科目
