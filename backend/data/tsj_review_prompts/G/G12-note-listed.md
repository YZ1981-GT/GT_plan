# G12-note-listed 净敞口套期收益附注披露复核提示词（上市公司）

## 概述

本提示词针对净敞口套期收益上市公司附注披露底稿（G12-note-listed）的复核，聚焦套期会计披露的充分性：风险管理策略、套期关系明细、套期工具与被套期项目、套期有效性及无效部分损益、以及CAS24/CAS37对上市公司套期披露的要求。

**法规依据：**
- 《企业会计准则第24号——套期会计》
- 《企业会计准则第37号——金融工具列报》
- 《企业会计准则第30号——财务报表列报》

---

## tips

1. **须披露风险管理策略**：附注须说明被套期风险类型、风险管理目标与策略、套期工具的使用方式，缺失将无法评估套期的商业实质。
2. **套期关系明细须充分**：按套期类型（公允价值/现金流量/净投资）披露套期工具名义金额、账面价值、被套期项目及其风险敞口。
3. **无效部分损益单独披露**：套期无效部分计入损益的金额须单独披露，反映套期效果。
4. **现金流量套期OCI变动须披露**：现金流量套期计入其他综合收益的有效部分及转出金额须披露，含转入损益/转入被套期项目成本。
5. **与利润表及OCI勾稽**：附注净敞口套期收益/损益须与利润表、其他综合收益变动表勾稽。
6. **附注须与审定表闭环勾稽**：披露套期损益各分项合计必须与G12-1审定数、G12-2套期明细勾稽。

## checklist

### 一、风险管理与策略披露

- [ ] 是否披露被套期风险类型及风险管理目标策略
- [ ] 是否说明套期工具的使用方式
- [ ] 各套期类型是否分别披露

### 二、套期关系与损益披露

- [ ] 套期工具名义金额、账面价值是否披露
- [ ] 被套期项目及其风险敞口是否披露
- [ ] 套期无效部分损益是否单独披露
- [ ] 现金流量套期OCI有效部分及转出金额是否披露

### 三、勾稽核对

- [ ] 附注套期损益是否与G12-1审定数、G12-2套期明细勾稽
- [ ] 附注是否与利润表、其他综合收益变动表勾稽
- [ ] 各分项合计是否闭环

### 四、上市公司额外要求

- [ ] 是否披露套期有效性评估方法及结果
- [ ] 是否披露对当期损益/权益有重大影响的套期事项
- [ ] 是否同时披露本期数和上期可比数

## risk_areas

### 高风险

1. **风险管理策略披露缺失**：未披露套期的风险管理目标与策略，无法评估套期商业实质。
2. **无效部分损益不披露**：套期无效部分损益未单独披露，掩盖套期效果不佳。
3. **OCI变动披露缺失**：现金流量套期OCI有效部分及转出金额未披露。
4. **附注与审定表不勾稽**：披露套期损益与G12-1审定数存在差异。

### 中风险

1. **套期关系明细不充分**：仅披露套期损益总额，未按套期类型披露明细。
2. **有效性评估结果未披露**：套期有效性评估方法及结果缺失。
3. **可比信息缺失**：仅披露本期数，未列上期可比数。

### 低风险

1. **披露格式不规范**：表格列序、单位等格式细节问题。
2. **文字说明模板化**：风险管理策略照搬模板，未结合实际。
3. **重大事项说明简略**：重大套期事项仅提及未展开。
