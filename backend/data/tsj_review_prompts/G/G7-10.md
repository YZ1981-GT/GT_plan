# G7-10 长期股权投资后续计量 复核提示词

## 概述

本提示词针对长期股权投资后续计量表（G7-10）的复核。后续计量表反映成本法/权益法下投资账面价值的滚动变化：成本法保持初始成本（除减值/追加/处置），收到股利确认投资收益；权益法按持股比例确认净损益、OCI变动、冲减现金股利。复核聚焦后续计量方法一致性、账面价值滚动准确性、以及与减值测试（G7-17）、审定表（G7-1）的勾稽。

**法规依据：**
- 《企业会计准则第2号——长期股权投资》
- 《企业会计准则第8号——资产减值》
- 《企业会计准则第33号——合并财务报表》

---

## tips

1. **成本法后续保持成本**：成本法下投资账面价值保持初始投资成本，仅因追加投资、处置、减值而变动，被投资单位宣告分配现金股利时确认投资收益。
2. **权益法逐期滚动**：权益法账面=初始成本±商誉+累计确认净损益+累计OCI-累计现金股利-累计减值，逐期滚动须连续。
3. **现金股利分方法处理**：成本法收到股利确认投资收益；权益法收到股利冲减账面价值（视为投资收回）。
4. **超额亏损处理**：权益法确认亏损以投资账面价值减记至零为限，超额亏损按长期应收款等顺序处理（详见G7-16）。
5. **减值不可转回**：后续计量中计提的长期股权投资减值不得转回。
6. **勾稽减值与审定表**：后续账面价值须扣除减值（G7-17），期末账面价值须与G7-1审定表勾稽。

## checklist

### 一、后续计量方法

- [ ] 成本法/权益法后续计量方法是否与核算方法判断一致
- [ ] 成本法账面价值是否保持初始成本（除追加/处置/减值）
- [ ] 权益法账面价值滚动是否连续且勾稽损益/OCI/股利
- [ ] 方法转换（成本法↔权益法）的会计处理是否正确

### 二、股利与损益

- [ ] 成本法收到现金股利是否确认投资收益
- [ ] 权益法收到现金股利是否冲减账面价值
- [ ] 权益法按持股比例确认的净损益是否正确
- [ ] 超额亏损是否按顺序处理（不确认为负账面价值）

### 三、减值与勾稽

- [ ] 后续账面价值是否扣除减值准备
- [ ] 减值是否未被违规转回
- [ ] 期末账面价值是否与G7-1审定表、G7-2明细表勾稽
- [ ] 减值信息是否与G7-17减值测试一致

## risk_areas

### 高风险

1. **后续计量方法错误**：成本法/权益法后续处理错误，投资收益或账面价值失真。
2. **权益法账面滚动断裂**：累计损益/OCI/股利滚动错误，账面价值失真。
3. **减值违规转回**：后续计量中转回已计提的长期股权投资减值。
4. **超额亏损处理错误**：将投资减记为负数或未按顺序处理超额亏损。

### 中风险

1. **现金股利处理方法错误**：成本法/权益法收到股利处理颠倒。
2. **方法转换处理不当**：成本法↔权益法转换的追溯/重估处理错误。
3. **减值与后续账面不勾稽**：账面价值未正确扣除减值。

### 低风险

1. **滚动过程记录不完整**：账面价值变动明细记录不足。
2. **索引引用缺失**：未与减值测试、审定表建立索引。
3. **格式不规范**：后续计量表字段不统一。
