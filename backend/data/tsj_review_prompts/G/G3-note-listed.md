# G3-note-listed 应收股利附注披露复核提示词（上市公司）

## 概述

本提示词针对应收股利上市公司附注披露底稿（G3-note-listed）的复核，聚焦上市公司财务报表附注中应收股利相关披露：分类构成（按被投资方）、账龄披露、重要应收股利单独披露、可收回性说明、关联方应收股利单独披露及与投资收益附注的勾稽。

**法规依据：**
- 《企业会计准则第37号——金融工具列报》
- 《企业会计准则第22号——金融工具确认和计量》
- 《企业会计准则第36号——关联方披露》
- 《公开发行证券的公司信息披露编报规则第15号——财务报告的一般规定》

---

## tips

1. **应收股利须按被投资方分类披露**：附注应按被投资方列示应收股利，重要项目单独披露被投资方名称、金额。
2. **分类合计与审定表勾稽**：附注应收股利期末余额合计须等于G3-1审定表审定数。
3. **账龄披露与可收回性**：账龄披露须与G3-2/G3-5一致，长期未收回股利须说明可收回性。
4. **关联方应收股利单独披露**：与关联方（尤其被投资方为关联方）的应收股利须按CAS36单独列示。
5. **与投资收益附注勾稽**：本期确认的应收股利应与投资收益附注中的股利收入勾稽。
6. **一年内到期分类**：应收股利应按流动性正确列示，长期部分是否重分类须核对。

## checklist

### 一、分类与账龄披露

- [ ] 应收股利是否按被投资方分类披露
- [ ] 重要应收股利是否单独披露被投资方名称和金额
- [ ] 各类别合计是否等于G3-1审定表审定数
- [ ] 账龄披露是否与G3-2/G3-5一致
- [ ] 是否同时披露期末数和期初数

### 二、可收回性与关联方披露

- [ ] 长期未收回应收股利可收回性是否说明
- [ ] 关联方应收股利是否单独披露（名称/关系/金额）
- [ ] 关联方分红兑现情况是否说明
- [ ] 是否披露长期挂账应收股利的原因

### 三、勾稽一致性

- [ ] 本期确认应收股利是否与投资收益附注股利收入勾稽
- [ ] 附注分类是否与审定表一致
- [ ] 一年内到期/长期分类是否正确列示

## risk_areas

### 高风险

1. **附注总额与审定表不一致**：附注应收股利合计与G3-1审定数不符，属重大数据勾稽错误。
2. **关联方应收股利未单独披露**：被投资方为关联方的应收股利混入一般项目，违反CAS36。
3. **可收回性说明缺失或不实**：长期未收回股利未说明可收回性或说明与实际不符。

### 中风险

1. **重要项目未单独披露**：重大应收股利未单独列示被投资方。
2. **与投资收益不勾稽**：本期确认应收股利与投资收益附注股利收入不一致。
3. **可比信息缺失**：仅披露期末数据未披露期初可比数据。

### 低风险

1. **披露格式不规范**：表格标题、列序、单位格式细节问题。
2. **账龄披露简略**：账龄分析披露不够详细。
3. **长期挂账原因说明模板化**：原因说明未结合实际。
