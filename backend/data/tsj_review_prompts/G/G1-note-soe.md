# G1-note-soe 交易性金融资产附注披露复核提示词（国有企业）

## 概述

本提示词针对交易性金融资产国有企业附注披露底稿（G1-note-soe）的复核，聚焦国有企业特定的附注披露要求：基础披露（分类/公允价值层次/公允价值变动）之上，叠加国有资产监管相关披露——金融投资合规性、投资决策程序、国有资本保值增值影响、以及与上市公司版本的差异关注点。国有企业金融投资须同时满足会计准则和国资监管要求。

**法规依据：**
- 《企业会计准则第37号——金融工具列报》
- 《企业会计准则第39号——公允价值计量》
- 《企业国有资产法》
- 《中央企业财务决算报告管理办法》
- 《国务院国资委关于中央企业加强金融衍生业务管理有关事项的通知》

---

## tips

1. **国企金融投资须披露合规性**：交易性金融资产投资须符合国资委对央企/国企金融投资、衍生业务的管理规定，附注须反映合规性。
2. **投资决策程序是国企关注点**：重大金融投资须经"三重一大"决策程序，附注宜披露重大投资的决策依据。
3. **基础披露框架与上市版相同**：分类构成、公允价值层次、公允价值变动损益等基础披露与上市版一致，国企版额外增加国资监管信息。
4. **公允价值变动影响国有资本保值增值**：交易性金融资产公允价值波动直接影响国有资本保值增值率，须评估和说明。
5. **衍生业务须严格披露**：国资委对央企金融衍生业务有专门管理要求，衍生工具须披露业务性质（套期/投机）和风险敞口。
6. **金融投资损失须纳入责任追究视角**：重大金融投资损失可能触发国有资产损失责任追究，须关注披露的完整性。

## checklist

### 一、基础披露完整性（与上市版共有）

- [ ] 交易性金融资产是否按类别分类披露
- [ ] 各类别期末余额合计是否等于G1-1审定表审定数
- [ ] 公允价值是否按第一/二/三层次披露
- [ ] 本期公允价值变动损益是否披露并与G1-5/利润表勾稽
- [ ] 期初数/期末数可比信息是否完整

### 二、国有资产监管相关披露

- [ ] 金融投资是否符合国资委投资管理规定并披露合规性
- [ ] 重大金融投资的决策程序（三重一大）是否披露
- [ ] 交易性金融资产公允价值变动对国有资本保值增值的影响是否说明
- [ ] 是否披露金融投资的授权额度和风险限额执行情况
- [ ] 重大投资损失是否披露形成原因

### 三、金融衍生业务披露（国企特定）

- [ ] 衍生工具是否披露业务性质（套期保值/投机）
- [ ] 衍生业务是否符合国资委央企金融衍生业务管理要求
- [ ] 衍生工具风险敞口和名义金额是否披露
- [ ] 是否存在超授权或投机性衍生交易并予以说明

### 四、与上市版差异关注点

- [ ] 国企版是否在上市版基础披露基础上增加国资监管信息
- [ ] 是否增加金融投资合规性和决策程序说明
- [ ] 是否增加国有资本保值增值影响分析
- [ ] 是否增加衍生业务管理合规性披露
- [ ] 决算报表金融资产数据是否与本附注一致

## risk_areas

### 高风险

1. **金融投资合规性披露缺失**：交易性金融资产/衍生投资超越国资委授权或违规，未在附注说明，存在合规风险。
2. **重大投资损失未充分披露**：金融投资重大损失未披露原因，可能掩盖国有资产流失和责任追究事项。
3. **基础披露与审定表不勾稽**：附注交易性金融资产总额与G1-1审定数不一致，属重大数据错误。
4. **投机性衍生交易未识别披露**：超授权或投机性衍生交易未按国资委要求披露风险敞口。

### 中风险

1. **决策程序披露缺失**：重大金融投资未披露"三重一大"决策程序。
2. **保值增值影响未分析**：公允价值波动对国有资本保值增值的影响未说明。
3. **公允价值层次披露不充分**：第三层次估值透明度不足。

### 低风险

1. **披露格式未完全按决算报表模板**：附注格式与国资委决算模板有细微差异。
2. **合规性说明过于简略**：金融投资合规性披露文字模板化。
3. **可比信息追溯不完整**：金融投资变动历史趋势分析不足。
