# G5-8 长期应收款预期信用损失政策复核提示词

## 概述

本提示词针对长期应收款预期信用损失政策底稿（G5-8）的复核，聚焦长期应收款减值会计政策的适当性：预期信用损失计量方法（一般方法/简化方法）的选择、组合划分标准、损失率确定方法、前瞻性信息运用政策。减值政策是长期应收款减值计量的基础框架，政策不当将系统性影响减值计提。

**法规依据：**
- 《企业会计准则第22号——金融工具确认和计量》
- 《企业会计准则第37号——金融工具列报》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **减值方法选择须适当**：融资租赁应收款可选择简化方法（始终按存续期ECL），一般长期应收款采用一般方法（三阶段），政策选择须明确并一致。
2. **组合划分政策须有共同风险特征**：组合划分标准（债务人类型/账龄/担保情况）须基于共同信用风险特征，政策清晰。
3. **损失率确定方法须有依据**：损失率应基于历史损失经验并结合前瞻性调整，方法学政策须合理。
4. **前瞻性信息运用政策**：政策须明确前瞻性宏观信息如何纳入ECL计量。
5. **政策一致性**：减值政策应前后期一致，政策变更须有正当理由并披露。
6. **政策联动测算**：G5-8政策须与G5-9阶段划分、G5-10减值测算的实际应用一致。

## checklist

### 一、方法选择

- [ ] 减值计量方法（一般/简化）选择是否适当
- [ ] 融资租赁应收款是否明确选择方法并一致应用
- [ ] 方法选择是否符合CAS22要求
- [ ] 政策是否前后期一致

### 二、组合与参数政策

- [ ] 组合划分标准是否基于共同信用风险特征
- [ ] 损失率确定方法是否有历史数据基础
- [ ] 前瞻性信息运用政策是否明确
- [ ] 单项评估触发条件是否明确

### 三、政策应用与勾稽

- [ ] G5-8政策是否与G5-9阶段划分实际应用一致
- [ ] 政策是否与G5-10减值测算方法一致
- [ ] 政策变更（如有）是否有正当理由并披露

## risk_areas

### 高风险

1. **减值政策不当系统性少提**：减值方法/组合/损失率政策不合理，系统性导致减值计提不足。
2. **政策变更操纵减值**：无正当理由变更减值政策以调节减值和利润。
3. **政策与实际应用脱节**：G5-8政策与G5-9/G5-10实际计量不一致。

### 中风险

1. **组合划分政策不清**：组合划分标准未基于共同风险特征。
2. **前瞻性政策缺失**：未明确前瞻性信息运用政策。
3. **方法选择不一致**：融资租赁应收款减值方法选择前后不一致。

### 低风险

1. **政策文档记录不充分**：减值政策描述简略。
2. **交叉索引不完整**：G5-8未与G5-9/G5-10建立索引。
