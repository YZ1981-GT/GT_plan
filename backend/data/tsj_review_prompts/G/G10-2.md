# G10-2 交易性金融负债明细表 复核提示词

## 概述

本提示词针对交易性金融负债明细表（G10-2）的复核。明细表逐项列示各笔交易性金融负债的名称、类型（交易目的/衍生/指定FVTPL）、承担金额、公允价值、公允价值变动及本期确认的公允价值变动损益，是审定表（G10-1）和附注披露的数据来源。复核聚焦逐项公允价值计量、公允价值变动进损益/OCI的区分、以及明细合计与审定表的勾稽。

**法规依据：**
- 《企业会计准则第22号——金融工具确认和计量》
- 《企业会计准则第37号——金融工具列报》

---

## tips

1. **明细合计勾稽审定表**：明细各笔期末公允价值合计须等于G10-1审定数，公允价值变动损益合计须与利润表勾稽。
2. **公允价值来源分层**：区分活跃市场报价（第一层次）、可观察输入（第二层次）、不可观察输入（第三层次），衍生工具估值多为第二/三层次。
3. **公允价值变动进损益**：交易性金融负债和衍生金融负债的公允价值变动计入当期损益。
4. **自身信用风险区分**：指定为FVTPL的金融负债须区分自身信用风险变动（进OCI）与其他公允价值变动（进损益）。
5. **交易费用进损益**：FVTPL负债的交易费用计入当期损益，不计入初始确认金额。
6. **关注衍生负债**：衍生金融负债（如利率互换、外汇远期负方）须核对合约要素和估值模型。

## checklist

### 一、逐项计量

- [ ] 各笔负债名称、类型、承担日期是否准确
- [ ] 交易费用是否计入当期损益（不计入初始金额）
- [ ] 公允价值来源是否明确分层
- [ ] 衍生工具估值模型和输入是否有依据

### 二、公允价值变动与损益

- [ ] 公允价值变动是否计入当期损益（交易性/衍生）
- [ ] 指定FVTPL负债的自身信用风险变动是否计入OCI
- [ ] 公允价值变动损益合计是否与利润表勾稽
- [ ] 各笔公允价值变动计算是否正确

### 三、勾稽

- [ ] 明细合计（公允价值/损益）是否与G10-1审定表勾稽
- [ ] 是否存在明细遗漏或重复列示
- [ ] 负债类型划分是否合理

## risk_areas

### 高风险

1. **公允价值低估**：金融负债公允价值低估导致负债少计、损益虚增。
2. **公允价值变动计入OCI**：将交易性/衍生负债公允价值变动错误计入OCI而非损益。
3. **明细与审定表不勾稽**：明细合计与G10-1审定数不一致。
4. **衍生负债估值不当**：衍生工具估值模型或输入错误，公允价值失真。

### 中风险

1. **交易费用处理错误**：FVTPL负债交易费用错误计入初始金额（应进损益）。
2. **自身信用风险未区分**：指定FVTPL负债未区分自身信用风险变动。
3. **负债类型划分不当**：衍生/交易目的/指定FVTPL划分错误。

### 低风险

1. **明细列示不完整**：缺少合约编号、对手方信息等。
2. **索引引用缺失**：未与合约、估值报告建立索引。
3. **精度不统一**：金额精度不一致。
