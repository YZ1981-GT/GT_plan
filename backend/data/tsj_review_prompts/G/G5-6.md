# G5-6 长期应收款分期收款销售复核提示词

## 概述

本提示词针对长期应收款分期收款销售底稿（G5-6）的复核，聚焦具有融资性质的分期收款销售商品的收入确认、未实现融资收益的核算与实际利率法摊销：以应收合同价款公允价值（现销价格/未来现金流现值）确认收入，差额作为未实现融资收益在收款期内摊销。分期收款销售兼涉CAS14收入准则和CAS22金融工具准则。

**法规依据：**
- 《企业会计准则第14号——收入》
- 《企业会计准则第22号——金融工具确认和计量》
- 《中国注册会计师审计准则第1301号——审计证据》

## tips

1. **融资性质分期收款须区分收入与融资收益**：合同含重大融资成分的分期收款销售，收入按现销价格（现值）确认，应收总额与现值差额为未实现融资收益。
2. **收入确认时点须符合CAS14**：分期收款销售收入应在控制权转移时一次性确认（现值），而非按收款进度确认。
3. **未实现融资收益按实际利率法摊销**：应收总额与现值的差额在收款期内按实际利率法确认为融资收益（利息收入）。
4. **折现率须合理**：确定现值采用的折现率应反映单独融资交易的市场利率或使名义金额折现至现销价格的利率。
5. **重大融资成分判断**：须评估是否存在重大融资成分（收款期通常超1年），不重大则不分拆。
6. **摊销联动审定表**：G5-6未实现融资收益摊销、应收净额须与G5-1审定表、G5-2明细表勾稽。

## checklist

### 一、收入与融资成分

- [ ] 是否评估分期收款销售是否含重大融资成分
- [ ] 收入是否按现销价格（现值）确认
- [ ] 收入确认时点是否符合CAS14（控制权转移）
- [ ] 应收总额与现值差额是否作为未实现融资收益

### 二、折现与摊销

- [ ] 折现率是否合理（市场利率/名义金额折至现销价格的利率）
- [ ] 未实现融资收益是否按实际利率法在收款期内摊销
- [ ] 每期融资收益测算是否正确
- [ ] 逐期应收净额滚动是否与G5-1/G5-2勾稽

### 三、勾稽与差异

- [ ] 本期融资收益是否与G5-1审定表/利润表勾稽
- [ ] 独立测算与账面确认差异是否查明
- [ ] 减值是否评估（与G5-10勾稽）
- [ ] 重大差异是否评估调整（转G5-4）

## risk_areas

### 高风险

1. **收入确认时点或金额错误**：分期收款销售未按现值一次性确认收入，或按收款进度确认，导致收入错报。
2. **未实现融资收益核算错误**：应收总额与现值差额未正确核算或摊销，融资收益失真。
3. **测算与审定表脱节**：G5-6应收净额与G5-1审定数不勾稽。

### 中风险

1. **重大融资成分判断错误**：应分拆融资成分却未分拆，或反之。
2. **折现率不合理**：折现率选取不当导致现值和融资收益失真。
3. **差异未查明**：测算与账面差异存在但未查明原因。

### 低风险

1. **底稿记录不充分**：折现率、现值、摊销记录简略。
2. **交叉索引不完整**：G5-6未与G5-1/G5-2建立索引。
