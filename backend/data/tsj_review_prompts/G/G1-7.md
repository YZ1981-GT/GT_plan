# G1-7 交易性金融资产第三层次公允价值调节表复核提示词

## 概述

本提示词针对交易性金融资产第三层次公允价值调节表（G1-7）的复核，聚焦以不可观察输入计量的第三层次金融资产的期初期末变动调节：期初余额、本期购入、本期出售、计入损益/其他综合收益的公允价值变动、层次转入转出的完整披露。第三层次公允价值信息透明度最低，是CAS37/CAS39的重点披露与复核领域。

**法规依据：**
- 《企业会计准则第39号——公允价值计量》
- 《企业会计准则第37号——金融工具列报》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **调节表须完整反映期初到期末变动**：期初余额+本期购入−本期出售+公允价值变动±层次转入转出=期末余额，各环节须完整。
2. **层次转入转出须有明确依据**：资产在层次间转移（如第二转第三）须说明触发事件及转移时点，不得随意调节。
3. **计入损益的公允价值变动须与G1-5勾稽**：第三层次资产的公允价值变动应与投资收益测算表、利润表一致。
4. **不可观察输入的合理性是核心**：调节表背后的估值假设须与G1-6公允价值测试的关键参数一致。
5. **期末余额勾稽审定表**：G1-7期末第三层次余额须能勾稽至G1-1审定表中对应资产。
6. **关注层次转移调节损益动机**：将第一/二层次资产转入第三层次可能为规避市场波动或调节损益，须保持职业怀疑。

---

## checklist

### 一、调节表完整性

- [ ] 期初第三层次余额是否等于上年期末第三层次余额
- [ ] 本期购入/出售金额是否与G1-13凭证检查勾稽
- [ ] 期末余额=期初+购入−出售+公允价值变动±转入转出，是否成立
- [ ] 各变动项目是否完整列示

### 二、层次转移核对

- [ ] 层次转入转出是否有明确触发事件和时点说明
- [ ] 转移是否符合CAS39层次划分标准
- [ ] 是否存在为调节损益或规避披露的不当层次转移

### 三、公允价值变动与勾稽

- [ ] 计入损益的公允价值变动是否与G1-5/利润表一致
- [ ] 不可观察输入是否与G1-6公允价值测试一致
- [ ] 期末第三层次余额是否勾稽至G1-1审定表
- [ ] 调节表数据是否与附注第三层次披露一致

## risk_areas

### 高风险

1. **层次转移操纵损益**：将资产在层次间不当转移以调节公允价值变动损益或规避披露要求。
2. **第三层次估值缺乏依据**：不可观察输入无合理支持，与G1-6估值测试脱节，估值可靠性存疑。
3. **调节表不勾稽**：期初+变动≠期末，或期末余额与审定表不一致。

### 中风险

1. **公允价值变动与损益不一致**：第三层次公允价值变动与G1-5、利润表不勾稽。
2. **转移依据不充分**：层次转入转出未说明触发事件和时点。

### 低风险

1. **调节表格式不规范**：变动项目列序、编号不统一。
2. **披露一致性瑕疵**：调节表与附注第三层次披露存在细微差异。
