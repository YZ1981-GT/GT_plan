# G8-note-soe 其他权益工具投资附注披露 复核提示词（国有企业）

## 概述

本提示词针对其他权益工具投资国有企业附注披露底稿（G8-note-soe）的复核，聚焦国有企业特定的附注披露要求：在指定FVOCI基础披露（指定原因/公允价值层次/OCI/股利/处置）之上，增加对外股权投资合规性、国有股权处置监管、公允价值对国有资本保值增值的影响、以及国资委财务决算报告补充要求。

**法规依据：**
- 《企业会计准则第37号——金融工具列报》
- 《企业会计准则第22号——金融工具确认和计量》
- 《企业国有资产法》
- 《中央企业财务决算报告管理办法》

---

## tips

1. **国企附注双层要求**：既满足CAS37通用披露（指定/公允价值层次/OCI/股利/处置），又满足国资委财务决算报告的额外披露要求。
2. **对外投资合规**：重大权益投资须经"三重一大"决策，附注宜说明本期重大投资/处置的决策审批情况。
3. **国有股权处置监管**：国有权益处置须履行进场交易/评估备案程序，附注须披露处置合规性及评估情况。
4. **保值增值视角**：公允价值持续下跌可能被视为国有资产减值风险，须说明成因及应对（但权益工具减值反映在公允价值，不单独计提）。
5. **公允价值防高估**：第三层次估值须客观依据，防止高估国有资产。
6. **决算勾稽**：附注数据须与年度财务决算报表一致，内部投资抵销须完整。

## checklist

### 一、基础披露完整性（与上市版共有）

- [ ] 是否披露指定为FVOCI的原因
- [ ] 公允价值是否按第一/二/三层次披露
- [ ] 计入OCI的累计公允价值变动是否披露
- [ ] 本期股利收入是否披露
- [ ] 附注期末余额是否与审定表审定数一致
- [ ] 期初/期末可比信息是否完整

### 二、对外投资合规披露

- [ ] 本期重大权益投资/处置是否经"三重一大"集体决策
- [ ] 投资是否符合国资委关于非主业/金融投资监管要求
- [ ] 是否披露投资对手方是否为关联方及交易公允性
- [ ] 是否存在超授权额度投资并予以说明

### 三、国有股权处置监管

- [ ] 国有权益处置是否履行进场交易/评估备案程序
- [ ] 处置价款与评估价值是否匹配（防国有资产流失）
- [ ] 处置是否经"三重一大"决策
- [ ] 处置OCI转留存收益处理是否披露

### 四、保值增值与决算披露

- [ ] 公允价值持续下跌是否说明成因及应对
- [ ] 公允价值变动对国有资本保值增值率的影响是否说明
- [ ] 第三层次估值是否有客观独立依据（防高估）
- [ ] 附注数据是否与年度财务决算报表一致
- [ ] 集团合并层面内部投资抵销是否完整

## risk_areas

### 高风险

1. **重大投资/处置未经决策程序披露**：大额权益投资或国有股权处置未经"三重一大"或未披露决策/评估过程，存在合规及国有资产流失风险。
2. **股权处置低价流失**：处置价款低于评估价值且未说明。
3. **公允价值高估国有资产**：第三层次估值缺乏客观依据导致资产高估。
4. **附注与决算/审定表不勾稽**：附注数据与决算报表或审定表不一致。

### 中风险

1. **非主业投资合规披露缺失**：权益投资是否符合国资委非主业监管要求未说明。
2. **关联方投资公允性未披露**：投资对手方为关联方但未披露公允性。
3. **OCI/处置披露不完整**：基础披露维度缺失。

### 低风险

1. **披露格式未按决算模板**：附注格式与国资委决算报表模板有细微差异。
2. **保值增值影响分析简略**：仅提及影响未量化分析。
3. **历史趋势追溯不完整**：投资变动趋势分析覆盖年限不足。
