# G4-note-listed 债权投资附注披露复核提示词（上市公司）

## 概述

本提示词针对债权投资上市公司附注披露底稿（G4-note-listed）的复核，聚焦上市公司财务报表附注中债权投资相关披露：分类构成、账面价值（摊余成本）、减值准备三阶段披露、信用风险披露、CAS37金融工具列报要求及与利息收入附注的勾稽。债权投资的减值和信用风险信息是投资者关注焦点。

**法规依据：**
- 《企业会计准则第37号——金融工具列报》
- 《企业会计准则第22号——金融工具确认和计量》
- 《公开发行证券的公司信息披露编报规则第15号——财务报告的一般规定》

---

## tips

1. **债权投资须披露账面价值构成**：附注应披露债权投资成本、利息调整、应计利息、减值准备各组成及账面价值，与G4-1审定表勾稽。
2. **减值准备须按三阶段披露**：CAS37要求披露减值准备按三阶段（12个月/存续期未减值/存续期已减值）的期初期末变动。
3. **信用风险披露是重点**：须披露信用风险敞口、按信用等级/阶段的账面价值分布、ECL计量方法和关键假设。
4. **前瞻性信息披露**：须披露ECL计量中采用的前瞻性信息、宏观情景及权重。
5. **利息收入勾稽**：本期确认的利息收入应与利润表投资收益/利息收入、G4-4测算勾稽。
6. **重大或逾期债权投资披露**：重大单项、逾期或信用减值的债权投资须单独披露。

## checklist

### 一、分类与账面价值披露

- [ ] 债权投资是否按类别（债券/其他债权）分类披露
- [ ] 是否披露成本/利息调整/应计利息/减值准备各组成
- [ ] 账面价值合计是否等于G4-1审定表审定数
- [ ] 是否同时披露期末数和期初数

### 二、减值准备三阶段披露

- [ ] 减值准备是否按三阶段披露期初期末变动
- [ ] 变动表是否与G4-10减值测算/G4-9阶段划分勾稽
- [ ] 本期计提是否与信用减值损失一致
- [ ] 各阶段账面价值分布是否披露

### 三、信用风险与前瞻性披露

- [ ] 是否披露信用风险敞口和管理政策
- [ ] 是否披露ECL计量方法和关键假设（PD/LGD）
- [ ] 是否披露前瞻性信息、宏观情景及权重
- [ ] 逾期/信用减值债权投资是否单独披露

### 四、勾稽一致性

- [ ] 本期利息收入是否与G4-4测算/利润表勾稽
- [ ] 重大单项债权投资是否单独披露
- [ ] 附注分类是否与审定表一致

## risk_areas

### 高风险

1. **减值准备三阶段披露缺失**：未按三阶段披露减值准备变动，不满足CAS37要求。
2. **附注账面价值与审定表不一致**：附注债权投资账面价值与G4-1审定数不符，属重大数据错误。
3. **ECL关键假设未披露**：未披露PD/LGD关键假设和前瞻性信息，信息不充分。

### 中风险

1. **信用风险分布披露不足**：未按信用等级/阶段披露账面价值分布。
2. **账面价值构成披露不完整**：未披露成本/利息调整/减值各组成。
3. **利息收入不勾稽**：本期利息收入与G4-4/利润表不一致。

### 低风险

1. **披露格式不规范**：表格标题、列序、单位格式细节问题。
2. **文字描述模板化**：信用风险政策照搬会计政策原文。
3. **可比信息缺失**：仅披露期末数据未披露期初可比数据。
