# G2-3 应收利息坏账准备明细复核提示词

## 概述

本提示词针对应收利息坏账准备明细表（G2-3）的复核，聚焦应收利息预期信用损失（坏账准备）的期初余额、本期计提、本期转回、本期核销、期末余额的明细核对，以及与审定表、坏账准备测算表（G2-7）的勾稽。应收利息作为金融资产须按CAS22计提预期信用损失。

**法规依据：**
- 《企业会计准则第22号——金融工具确认和计量》
- 《企业会计准则第37号——金融工具列报》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **坏账准备变动须完整**：期初+本期计提−本期转回−本期核销±其他=期末，各环节须完整成立。
2. **计提金额须与G2-7测算表勾稽**：本期坏账准备计提金额须与G2-7坏账准备测算表计算结果一致。
3. **计提金额与利润表勾稽**：本期计提净额应与利润表信用减值损失勾稽。
4. **核销须有审批依据**：本期核销的应收利息须有充分证据（债务人破产/无法收回）和适当审批。
5. **区分计提方法**：单项计提与组合计提的坏账准备应分别列示，与G2-7方法一致。
6. **期末余额勾稽审定表**：G2-3期末坏账准备余额须与G2-1审定表应收利息坏账准备一致。

## checklist

### 一、坏账准备变动核对

- [ ] 期初坏账准备是否等于上年期末余额
- [ ] 期末=期初+计提−转回−核销±其他，是否成立
- [ ] 本期计提是否与G2-7坏账准备测算表勾稽
- [ ] 本期计提净额是否与利润表信用减值损失勾稽

### 二、核销与转回核对

- [ ] 本期核销是否有充分证据和适当审批
- [ ] 本期转回原因是否合理
- [ ] 核销/转回是否与G2-8凭证检查勾稽

### 三、方法与勾稽

- [ ] 单项计提与组合计提是否分别列示
- [ ] 计提方法是否与G2-7一致
- [ ] 期末坏账准备余额是否与G2-1审定表一致
- [ ] 是否与G2-2明细表应收利息逐笔对应

## risk_areas

### 高风险

1. **坏账准备变动不勾稽**：期初+变动≠期末，或与G2-7测算不一致，属重大错误。
2. **少提坏账准备虚增资产**：长期未收回利息未足额计提坏账准备，虚增净额。
3. **核销缺乏依据**：坏账核销无证据或未经审批，可能掩盖资产损失或利润操纵。

### 中风险

1. **计提与利润表不勾稽**：本期计提净额与信用减值损失不一致。
2. **转回不合理**：坏账准备转回缺乏合理依据，调节利润。
3. **计提方法不一致**：与G2-7方法矛盾。

### 低风险

1. **明细格式不规范**：变动项目列序、编号不统一。
2. **交叉索引不完整**：G2-3未与G2-1/G2-7建立索引。
