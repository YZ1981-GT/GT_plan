# G1-11 交易性金融资产有价证券盘点表复核提示词

## 概述

本提示词针对交易性金融资产有价证券盘点表（G1-11）的复核，聚焦资产负债表日有价证券持仓的存在性验证：通过券商对账单、证券登记结算机构记录、监盘程序核实证券种类、数量的真实存在，并与账面记录、结存表核对差异。存在性是交易性金融资产的关键认定。

**法规依据：**
- 《企业会计准则第22号——金融工具确认和计量》
- 《中国注册会计师审计准则第1301号——审计证据》
- 《中国注册会计师审计准则第1311号——对存货、诉讼和索赔以及分部信息等特定项目获取审计证据的具体考虑》

---

## tips

1. **存在性以第三方记录为最强证据**：证券持仓应核对至券商对账单、中登公司/中债登持仓记录等独立第三方记录。
2. **盘点应覆盖资产负债表日持仓**：盘点/核对时点应为资产负债表日，非资产负债表日盘点须做滚回调节。
3. **数量核对是重点**：盘点表应核对证券代码、名称、数量与账面/结存表一致，数量差异优先于金额差异。
4. **实物证券须监盘**：如存在实物证券（罕见），须实施监盘程序确认存在和保管状况。
5. **受限证券须查明**：质押、冻结、限售的证券须查明并评估对流动性和列报的影响。
6. **盘点差异须查明处理**：账实差异须追查原因（漏记买卖、跨期交易、记录错误）并做相应调整。

## checklist

### 一、存在性核对

- [ ] 证券持仓是否核对至券商对账单/登记结算机构记录
- [ ] 盘点/核对时点是否为资产负债表日
- [ ] 证券代码、名称、数量是否与账面记录一致
- [ ] 是否存在账面有记录但对账单无持仓的证券

### 二、数量与结存核对

- [ ] 盘点数量是否与G1-4结存表期末数量一致
- [ ] 盘点数量是否与G1-2明细表一致
- [ ] 账实差异是否查明原因并记录
- [ ] 实物证券（如有）是否实施监盘

### 三、权利受限核对

- [ ] 是否核实证券是否存在质押/冻结/限售
- [ ] 受限证券是否评估对流动性/列报的影响
- [ ] 受限情况是否与附注披露一致

## risk_areas

### 高风险

1. **虚构证券持仓**：账面记录的证券在第三方对账单无持仓，可能虚构资产。
2. **数量账实不符**：盘点数量与账面/结存表不一致，存在漏记交易或记录错误。
3. **受限证券未识别**：质押/冻结证券未查明，导致流动性和列报误导。

### 中风险

1. **盘点时点不当**：非资产负债表日盘点且未做滚回调节。
2. **差异未追查**：账实差异存在但未查明原因和处理。

### 低风险

1. **盘点记录不规范**：证券代码、单位、格式记录不统一。
2. **交叉索引不完整**：G1-11未与G1-2/G1-4建立索引。
