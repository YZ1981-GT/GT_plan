# G1-2 交易性金融资产明细表复核提示词

## 概述

本提示词针对交易性金融资产明细表（G1-2）的复核，聚焦逐笔金融资产的成本、公允价值、公允价值变动、持有收益的明细核对，以及明细合计与审定表（G1-1）的勾稽。明细表是审定表数据的支撑基础，须逐项核对至外部证据（对账单、估值报告、交易凭证）。

**法规依据：**
- 《企业会计准则第22号——金融工具确认和计量》
- 《企业会计准则第39号——公允价值计量》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **逐笔明细须核对至外部证据**：每笔股票/基金/债券的成本、期末公允价值应核对至券商对账单、基金净值报告或估值报告，不得仅凭内部记录。
2. **明细合计必须与审定表勾稽**：明细表各金融资产公允价值合计须等于G1-1审定表交易性金融资产审定数。
3. **成本与公允价值须分列**：明细表应清晰区分初始成本与期末公允价值，公允价值变动=期末公允价值−账面成本。
4. **持有期间收益单独列示**：现金股利、债券利息应在明细中单独记录，与公允价值变动区分，避免收益结构混淆。
5. **买入卖出明细可追溯**：本期新增（买入）与减少（卖出）明细须与G1-13凭证检查、G1-11盘点表逐笔对应。
6. **关注单笔重大或异常波动**：单只证券公允价值较成本大幅偏离（超过30%）需追溯估值依据及市场行情合理性。

## checklist

### 一、明细核对完整性

- [ ] 每笔金融资产的名称、代码、数量、成本是否完整记录
- [ ] 成本金额是否核对至买入交易凭证/券商对账单
- [ ] 期末数量是否与G1-11有价证券盘点表一致
- [ ] 本期买入/卖出明细是否与G1-13凭证检查勾稽
- [ ] 是否存在明细遗漏或重复记录

### 二、公允价值明细核对

- [ ] 每笔资产期末公允价值是否核对至估值报告/净值报告/收盘价
- [ ] 公允价值变动=期末公允价值−账面成本，计算是否正确
- [ ] 活跃市场证券是否采用资产负债表日收盘价
- [ ] 非活跃市场证券估值方法是否与G1-6/G1-7一致
- [ ] 明细公允价值合计是否等于G1-1审定表审定数

### 三、收益与损益核对

- [ ] 持有期间现金股利/债券利息是否单独列示
- [ ] 处置损益（卖出价−账面价）是否逐笔计算正确
- [ ] 明细公允价值变动合计是否与G1-5投资收益测算表勾稽
- [ ] 各笔资产的损益方向（收益/损失）是否合理

## risk_areas

### 高风险

1. **公允价值明细不实**：单笔资产期末公允价值未核对至外部估值证据，或采用陈旧报价，导致资产与损益虚假。
2. **明细合计与审定表不符**：明细公允价值合计与G1-1审定数不一致，勾稽断裂影响报表可靠性。
3. **虚构持仓或数量不符**：明细持仓数量与G1-11盘点表不一致，可能存在虚构资产或漏记处置。

### 中风险

1. **成本与公允价值混列**：未清晰区分初始成本与期末公允价值，导致公允价值变动计算错误。
2. **持有收益归类错误**：股利利息并入公允价值变动，投资收益结构失真。
3. **买卖明细不可追溯**：本期增减明细未与凭证/盘点表勾稽，交易真实性存疑。

### 低风险

1. **明细记录格式不统一**：证券代码、数量单位、金额精度记录不规范，影响复核效率。
2. **交叉索引不完整**：明细未与G1-6/G1-11/G1-13建立索引引用。
3. **异常波动未附说明**：单只证券大幅偏离成本但未附估值合理性说明。
