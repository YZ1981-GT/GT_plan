# G7-16 长期股权投资未确认投资损失 复核提示词

## 概述

本提示词针对权益法下超额亏损（未确认投资损失）核算表（G7-16）的复核。权益法确认被投资单位亏损时，以长期股权投资账面价值减记至零为限，仍有超额亏损的，依次以其他实质上构成对被投资单位净投资的长期权益（如长期应收款）减记至零，再确认预计负债，剩余作为未确认投资损失备查登记。复核聚焦减记顺序（瀑布）、超额亏损备查登记、以及被投资单位以后盈利时的反序恢复。

**法规依据：**
- 《企业会计准则第2号——长期股权投资》

---

## tips

1. **超额亏损减记瀑布**：确认亏损顺序=①减记长期股权投资账面至零→②减记其他长期权益（长期应收款等净投资）至零→③按投资合同/协议承担义务确认预计负债→④剩余作未确认投资损失备查。
2. **以零为限**：长期股权投资账面价值和长期权益减记均以减至零为限，不确认为负数。
3. **净投资范围**：构成净投资的长期权益指实质上属于对被投资单位净投资的长期应收款等（不含正常经营往来）。
4. **备查登记**：未确认投资损失不进账，但须备查登记，作为以后盈利恢复的基础。
5. **反序恢复**：被投资单位以后期间实现盈利的，按与减记相反顺序恢复：先冲减未确认投资损失→恢复预计负债→恢复长期权益→恢复长期股权投资。
6. **联动G7-14**：超额亏损处理影响权益法账面价值，须与G7-14勾稽。

## checklist

### 一、减记顺序

- [ ] 是否先减记长期股权投资账面价值至零
- [ ] 是否再减记构成净投资的其他长期权益至零
- [ ] 是否按合同义务确认预计负债
- [ ] 剩余是否作为未确认投资损失备查登记

### 二、以零为限与备查

- [ ] 长期股权投资/长期权益减记是否以零为限（不为负）
- [ ] 净投资范围界定是否合理（不含正常往来）
- [ ] 未确认投资损失是否备查登记（不进账）
- [ ] 累计未确认损失金额是否连续滚动

### 三、恢复与联动

- [ ] 被投资单位盈利时是否按反序恢复
- [ ] 恢复顺序（未确认损失→预计负债→长期权益→长期股权投资）是否正确
- [ ] 超额亏损处理是否与G7-14权益法核算勾稽

## risk_areas

### 高风险

1. **减记顺序错误**：未按瀑布顺序减记（如跳过长期权益直接备查），账面价值或损益失真。
2. **减记为负数**：长期股权投资或长期权益减记为负数，违反以零为限原则。
3. **反序恢复错误**：被投资单位盈利时恢复顺序错误，投资收益确认失真。

### 中风险

1. **净投资范围界定不当**：将正常经营往来误作净投资减记（或遗漏应减记的长期权益）。
2. **预计负债确认遗漏**：有合同义务却未确认预计负债。
3. **未确认损失未备查**：备查登记缺失，影响以后恢复基础。

### 低风险

1. **累计滚动记录不清**：未确认投资损失累计额记录不足。
2. **索引引用缺失**：未与权益法计算、长期应收款建立索引。
3. **格式不规范**：核算表字段不统一。
