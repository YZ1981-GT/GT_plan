# G4-note-soe 债权投资附注披露复核提示词（国有企业）

## 概述

本提示词针对债权投资国有企业附注披露底稿（G4-note-soe）的复核，聚焦国有企业特定的附注披露要求：基础披露（分类/账面价值/减值三阶段/信用风险）之上，叠加国有资产监管相关披露——债权投资合规性、投资决策程序、信用风险的国资监管视角、以及与上市公司版本的差异关注点。

**法规依据：**
- 《企业会计准则第37号——金融工具列报》
- 《企业会计准则第22号——金融工具确认和计量》
- 《企业国有资产法》
- 《中央企业财务决算报告管理办法》

---

## tips

1. **国企债权投资须披露合规性**：债权投资须符合国资委对国企投资、金融资产管理的规定，附注须反映合规性。
2. **投资决策程序是国企关注点**：重大债权投资须经"三重一大"决策程序，附注宜披露重大投资的决策依据。
3. **基础披露框架与上市版相同**：分类、账面价值、减值三阶段、信用风险等基础披露一致，国企版增加国资监管信息。
4. **信用减值影响保值增值**：债权投资减值损失对国有资本保值增值率的影响须评估和说明。
5. **重大减值须责任追究视角**：重大债权投资减值损失可能触发国有资产损失责任追究，须关注披露完整性。
6. **与上市版差异在监管层面**：国企版在基础披露基础上补充国资监管相关信息。

## checklist

### 一、基础披露完整性（与上市版共有）

- [ ] 债权投资是否按类别分类披露
- [ ] 账面价值合计是否等于G4-1审定表审定数
- [ ] 减值准备是否按三阶段披露期初期末变动
- [ ] 是否披露ECL计量方法和关键假设
- [ ] 期初数/期末数可比信息是否完整

### 二、国有资产监管相关披露

- [ ] 债权投资是否符合国资委投资管理规定并披露合规性
- [ ] 重大债权投资的决策程序（三重一大）是否披露
- [ ] 债权投资减值对国有资本保值增值的影响是否说明
- [ ] 重大减值损失是否披露形成原因

### 三、信用风险披露（国企特定）

- [ ] 是否披露信用风险敞口和管理政策
- [ ] 对国有企业/政府相关债权投资是否单独披露
- [ ] 逾期/信用减值债权投资是否单独说明
- [ ] 是否披露担保/增信安排

### 四、与上市版差异关注点

- [ ] 国企版是否在基础披露上增加国资监管信息
- [ ] 是否增加投资合规性和决策程序说明
- [ ] 是否增加国有资本保值增值影响分析
- [ ] 决算报表债权投资数据是否与本附注一致

## risk_areas

### 高风险

1. **债权投资合规性披露缺失**：债权投资超越国资委授权或违规，未在附注说明，存在合规风险。
2. **重大减值损失未充分披露**：债权投资重大减值未披露原因，可能掩盖国有资产流失和责任追究事项。
3. **减值三阶段披露缺失或与审定表不勾稽**：减值准备未按三阶段披露或与G4-1审定数不一致。

### 中风险

1. **决策程序披露缺失**：重大债权投资未披露"三重一大"决策程序。
2. **保值增值影响未分析**：减值对国有资本保值增值的影响未说明。
3. **信用风险敞口披露不足**：对国企/政府相关债权投资未单独披露。

### 低风险

1. **披露格式未按决算模板**：附注格式与国资委决算模板细微差异。
2. **合规性说明简略**：债权投资合规性披露文字模板化。
3. **可比信息追溯不完整**：历史趋势分析不足。
