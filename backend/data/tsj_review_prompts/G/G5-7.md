# G5-7 长期应收款保理检查复核提示词

## 概述

本提示词针对长期应收款保理检查底稿（G5-7）的复核，聚焦长期应收款保理/转让的终止确认判断：是否转移了收取现金流的合同权利、是否转移了几乎所有风险和报酬、是否放弃控制。保理终止确认判断直接决定应收款项是否出表以及是否确认相关负债，是CAS23金融资产转移的核心判断。

**法规依据：**
- 《企业会计准则第23号——金融资产转移》
- 《企业会计准则第22号——金融工具确认和计量》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **终止确认三步判断**：先判断是否转移收取现金流权利，再判断风险报酬转移程度，最后判断是否放弃控制。
2. **风险报酬转移是核心**：有追索权保理通常未转移几乎所有风险报酬（不终止确认，确认担保负债）；无追索权保理通常终止确认。
3. **附回购/差额补足视同未转移**：保理协议含回购义务、差额补足、信用增级等安排通常表明风险未转移，不应终止确认。
4. **继续涉入须部分确认**：既未转移也未保留几乎所有风险报酬但保留控制的，按继续涉入程度确认资产负债。
5. **保理款须核对**：保理取得的资金、终止确认损益、担保负债确认须核对保理合同和资金流水。
6. **判断结论联动审定表**：G5-7终止确认判断影响G5-1审定表长期应收款余额和相关损益。

## checklist

### 一、终止确认判断

- [ ] 是否分析保理是否转移收取现金流的合同权利
- [ ] 是否评估风险报酬转移程度（有无追索权）
- [ ] 是否评估是否放弃对应收款项的控制
- [ ] 终止确认三步判断逻辑是否完整

### 二、协议条款分析

- [ ] 保理协议是否含追索权/回购/差额补足条款
- [ ] 有追索权保理是否未终止确认并确认担保负债
- [ ] 无追索权保理终止确认是否有充分依据
- [ ] 继续涉入情形是否按涉入程度确认资产负债

### 三、会计处理与勾稽

- [ ] 保理资金、终止确认损益是否核对合同和流水
- [ ] 未终止确认的保理是否确认相关负债
- [ ] 终止确认判断是否影响G5-1审定表余额
- [ ] 终止/未终止确认金额是否与附注披露一致

## risk_areas

### 高风险

1. **不当终止确认虚减应收/负债**：有追索权保理不当终止确认，将应收款项出表并隐藏担保负债，虚饰资产负债表。
2. **风险报酬转移判断错误**：附回购/差额补足的保理误判为已转移风险，不当出表。
3. **判断结论与审定表脱节**：终止确认判断与G5-1审定表余额处理不一致。

### 中风险

1. **继续涉入未确认**：既未转移也未保留几乎所有风险报酬但未按继续涉入确认资产负债。
2. **担保负债漏记**：未终止确认的保理未确认相关担保负债。
3. **保理款不可追溯**：保理资金和损益未核对合同/流水。

### 低风险

1. **判断底稿记录不充分**：终止确认三步判断过程记录简略。
2. **交叉索引不完整**：G5-7未与G5-1及附注披露建立索引。
