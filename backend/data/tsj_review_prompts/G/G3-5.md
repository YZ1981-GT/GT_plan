# G3-5 应收股利长期未收回检查复核提示词

## 概述

本提示词针对应收股利长期未收回检查底稿（G3-5）的复核，聚焦长期未收回应收股利的识别、被投资方偿付能力与分红兑现情况评估、可收回性判断及减值考虑。长期未收回股利可能反映被投资方经营困难或分红承诺未兑现，是可收回性和资产真实性的重要信号。

**法规依据：**
- 《企业会计准则第22号——金融工具确认和计量》
- 《企业会计准则第37号——金融工具列报》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **长账龄是可收回性信号**：应收股利长期未收回（如超1年）通常意味着被投资方现金流困难或分红兑现存在障碍。
2. **可收回性须结合被投资方情况**：可收回性判断须基于被投资方财务状况、现金流、分红兑现历史等客观证据。
3. **区分未宣告与已宣告未付**：应收股利应为已宣告未付部分，若长期未付须评估被投资方是否有兑现能力。
4. **减值考虑**：长期无法收回的应收股利须评估减值，与相关坏账/减值处理勾稽。
5. **催收措施须记录**：企业对长期未收回股利的催收措施和进展应记录。
6. **关联方分红须关注**：关联方（尤其是母子公司间）应收股利长期挂账可能涉及资金占用，须保持职业怀疑。

## checklist

### 一、长账龄识别

- [ ] 是否完整识别长期未收回（超账龄阈值）的应收股利
- [ ] 长账龄股利是否与G3-2明细表账龄一致
- [ ] 是否按被投资方/账龄段汇总长期未收回股利

### 二、可收回性评估

- [ ] 可收回性判断是否基于被投资方财务状况/现金流
- [ ] 是否核对被投资方分红兑现历史
- [ ] 长期未收回股利是否评估减值
- [ ] 关联方长期挂账是否评估资金占用可能

### 三、催收与处理

- [ ] 企业催收措施和进展是否记录
- [ ] 无法收回的股利是否评估处理（减值/核销）
- [ ] 评估结果是否联动审定表/披露

## risk_areas

### 高风险

1. **可收回性高估**：长期未收回股利可收回性评估无证据，未计提减值，虚增资产。
2. **被投资方偿付能力恶化忽视**：被投资方经营困难未触发可收回性重估。
3. **关联方资金占用掩盖**：关联方应收股利长期挂账掩盖资金占用。

### 中风险

1. **减值评估缺失**：长期无法收回的股利未评估减值。
2. **催收措施记录缺失**：长期未收回股利催收进展未记录。

### 低风险

1. **账龄划分不一致**：G3-5账龄与G3-2明细表不一致。
2. **交叉索引不完整**：G3-5未与G3-1/G3-2建立索引。
