# G1-6 交易性金融资产公允价值测试复核提示词

## 概述

本提示词针对交易性金融资产公允价值测试底稿（G1-6）的复核，聚焦公允价值计量的层次划分（第一/二/三层次）、估值技术的适当性、关键输入参数的可观察性与合理性，以及估值专家工作的利用。公允价值是交易性金融资产的计量基础，估值错误将直接导致资产与损益重大错报。

**法规依据：**
- 《企业会计准则第39号——公允价值计量》
- 《企业会计准则第22号——金融工具确认和计量》
- 《中国注册会计师审计准则第1301号——审计证据》
- 《中国注册会计师审计准则第1620号——利用专家的工作》

---

## tips

1. **公允价值层次决定证据要求**：第一层次（活跃市场报价）证据最强，第三层次（不可观察输入）需最严格的复核，须验证层次划分是否恰当。
2. **第一层次须为资产负债表日活跃市场报价**：上市股票/交易所债券应采用资产负债表日收盘价（未经调整的活跃市场报价）。
3. **第二层次采用可观察输入**：类似资产报价、可观察利率/汇率等，须验证输入的可观察性和估值模型的适当性。
4. **第三层次须严格复核关键假设**：采用不可观察输入（如折现率、增长率）时，须评估假设的合理性并与市场数据交叉验证。
5. **估值专家的工作须评估胜任能力与独立性**：利用管理层聘请的估值专家时，须评估其专业胜任能力、客观性及工作结论的合理性（CAS1620）。
6. **敏感性分析揭示估值风险**：第三层次公允价值应进行关键假设敏感性分析，评估估值的稳健性。

## checklist

### 一、公允价值层次划分

- [ ] 各金融资产公允价值层次划分是否恰当（第一/二/三层次）
- [ ] 第一层次是否为活跃市场未调整报价
- [ ] 层次之间是否存在不当转移（如第一层次降为第三层次调节利润）
- [ ] 层次划分是否与G1-7第三层次调节表、附注披露一致

### 二、估值技术与输入

- [ ] 第一层次是否采用资产负债表日收盘价，核对至行情数据
- [ ] 第二层次估值模型（如市场法/收益法）是否适当
- [ ] 第二层次可观察输入（利率/汇率/类似资产报价）是否可靠
- [ ] 第三层次不可观察输入（折现率/增长率）是否合理并交叉验证
- [ ] 估值模型的数学逻辑与计算是否正确

### 三、估值专家利用与敏感性

- [ ] 是否利用估值专家的工作，专家胜任能力/独立性是否评估
- [ ] 专家估值结论是否与审计判断一致
- [ ] 第三层次公允价值是否进行关键假设敏感性分析
- [ ] 估值结果是否可勾稽至G1-1审定表、G1-2明细表

## risk_areas

### 高风险

1. **公允价值层次划分不当**：将本应第三层次的资产划为第一/二层次，规避严格披露和估值复核要求。
2. **第三层次关键假设操纵**：折现率、增长率等不可观察输入被人为调节以美化资产估值。
3. **估值专家工作未经审慎评估**：直接采用管理层专家结论而未评估胜任能力、独立性和假设合理性。
4. **估值结果与审定表脱节**：G1-6估值结论与G1-1审定数不一致，勾稽断裂。

### 中风险

1. **可观察输入选取不当**：第二层次采用的类似资产报价或市场利率与被估值资产不匹配。
2. **敏感性分析缺失**：第三层次公允价值未进行敏感性分析，估值稳健性无法评估。
3. **报价时效性问题**：第一层次采用非资产负债表日报价。

### 低风险

1. **估值底稿记录不完整**：估值模型参数、数据来源记录不充分，影响可追溯性。
2. **层次划分说明简略**：公允价值层次划分依据未详细说明。
3. **交叉索引不完整**：G1-6未与G1-1/G1-7及附注披露建立索引。
