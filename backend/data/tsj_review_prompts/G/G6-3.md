# G6-3 其他债权投资减值准备明细表 复核提示词

## 概述

本提示词针对其他债权投资预期信用损失（ECL）减值准备明细表（G6-3）的复核。其他债权投资采用预期信用损失模型计提减值，且减值准备计入其他综合收益而非冲减账面价值。复核聚焦ECL三阶段划分合理性、损失率与前瞻性信息运用、减值计入OCI的正确性、以及减值准备变动与利润表信用减值损失、G6-1审定表的勾稽。

**法规依据：**
- 《企业会计准则第22号——金融工具确认和计量》
- 《企业会计准则第37号——金融工具列报》

---

## tips

1. **ECL三阶段判断是核心**：区分信用风险未显著增加（阶段一，12个月ECL）、信用风险显著增加（阶段二，整个存续期ECL）、已发生信用减值（阶段三），阶段划分直接决定计提金额。
2. **减值计入OCI不冲账面**：其他债权投资减值准备计入其他综合收益，账面公允价值不因减值而调整，这是与摊余成本类资产的关键差异。
3. **本期计提勾稽损益**：本期计提的信用减值损失应与利润表"信用减值损失"科目一致，转回同样勾稽。
4. **前瞻性信息运用**：ECL模型须纳入宏观经济前瞻性调整因子，须有依据不得随意调节。
5. **变动表完整**：减值准备变动须列示期初、本期计提、本期转回、本期核销、期末，各项勾稽且可追溯。
6. **关注阶段跃迁**：从阶段一跃迁至阶段二/三的债券须评估触发事件（逾期、评级下调、发行人财务恶化）是否充分识别。

## checklist

### 一、ECL阶段划分

- [ ] 各笔投资的信用风险阶段划分是否有明确判断依据
- [ ] 信用风险是否显著增加的判断标准是否合理且一致运用
- [ ] 阶段二/三债券的触发事件（逾期/评级下调/违约）是否充分识别
- [ ] 阶段划分是否与债券发行人最新信用状况匹配

### 二、损失率与前瞻性

- [ ] 违约概率（PD）、违约损失率（LGD）参数来源是否可靠
- [ ] 前瞻性宏观经济调整因子是否有依据
- [ ] 12个月ECL与存续期ECL的计算是否与阶段划分匹配
- [ ] 损失率假设较上期变动是否合理并说明

### 三、计入方式与变动勾稽

- [ ] 减值准备是否正确计入其他综合收益（不冲减账面价值）
- [ ] 减值准备变动表是否完整（期初/计提/转回/核销/期末）
- [ ] 本期计提是否与利润表信用减值损失勾稽
- [ ] 期末减值准备是否与G6-1审定表减值信息一致
- [ ] 核销是否有充分审批依据

## risk_areas

### 高风险

1. **阶段划分不当规避计提**：将信用风险显著增加的债券仍划为阶段一，少计提整个存续期ECL，减值不足。
2. **减值计入方向错误**：错误冲减账面价值而非计入OCI，导致资产账面价值与OCI双重错报。
3. **前瞻性信息缺失或滥用**：未纳入前瞻性调整或反向调节损失率以规避计提，ECL失真。
4. **本期计提与损益不勾稽**：减值变动与利润表信用减值损失不一致，损益错报。

### 中风险

1. **损失率参数缺乏支持**：PD/LGD参数来源不明或直接采用管理层估计，缺乏客观依据。
2. **触发事件识别滞后**：发行人已违约或评级下调但未及时跃迁阶段，减值滞后。
3. **变动表不勾稽**：期初+计提-转回-核销≠期末，减值变动逻辑断裂。

### 低风险

1. **模型文档不完整**：ECL模型的假设、参数、计算过程未充分记录。
2. **分阶段列示不清**：未按阶段分别列示减值准备余额，分析不便。
3. **索引引用缺失**：未与G6-1审定表、利润表信用减值损失建立索引。
