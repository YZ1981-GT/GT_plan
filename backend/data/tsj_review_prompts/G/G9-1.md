# G9-1 其他非流动金融资产审定表 复核提示词

## 概述

本提示词针对其他非流动金融资产审定表（G9-1，科目1519）的复核。其他非流动金融资产核算不满足其他金融资产分类（不符合FVOCI或摊余成本条件）而以公允价值计量且其变动计入当期损益（FVTPL）的非流动金融资产。审定表须完整反映未审→调整→审定链路，勾稽公允价值、公允价值变动损益及试算平衡表。复核聚焦分类判断、公允价值计量、变动进损益的正确性及勾稽。

**法规依据：**
- 《企业会计准则第22号——金融工具确认和计量》
- 《企业会计准则第37号——金融工具列报》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **分类兜底性质**：其他非流动金融资产是不满足摊余成本、FVOCI分类条件的非流动金融资产，以FVTPL计量，分类判断（业务模式/SPPI/是否非流动）是审定基础。
2. **公允价值变动进损益**：与其他债权投资/其他权益工具投资不同，其公允价值变动计入当期损益（公允价值变动损益），不进OCI。
3. **期初期末承前启后**：期初审定数须等于上年期末审定数，任何差异须追溯。
4. **流动性分类**：一年内到期或预期一年内收回的应重分类至流动资产（如交易性金融资产），审定表须体现流动/非流动划分。
5. **试算平衡表核对**：审定数合计须与试算平衡表其他非流动金融资产科目审定数一致。
6. **调整完整性**：审定数=未审数+AJE+RJE，所有调整完整反映。

## checklist

### 一、分类与期初期末勾稽

- [ ] 分类为FVTPL的判断依据（不满足摊余成本/FVOCI条件）是否有底稿支持
- [ ] 期初审定数是否等于上年期末审定数（承前启后）
- [ ] 公允价值变动是否计入当期损益（不进OCI）
- [ ] 期末审定数是否等于期初审定数加本期增减（购入/出售/公允价值变动）

### 二、试算平衡表核对

- [ ] 审定数合计是否与试算平衡表其他非流动金融资产科目审定数一致
- [ ] 未审数、调整数与审定表对应列是否一致
- [ ] 公允价值变动损益是否与利润表相应科目勾稽

### 三、审计调整完整性

- [ ] 所有账项调整（AJE）是否完整反映在审定表调整列
- [ ] 所有重分类调整（RJE）是否完整反映
- [ ] 调整分录借贷方是否平衡
- [ ] 审定后金额是否等于未审数+AJE+RJE
- [ ] 建议但未调整的错报是否记录于未调整错报汇总表

### 四、流动性分类

- [ ] 一年内到期/收回部分是否重分类至流动资产
- [ ] 流动/非流动划分是否合理
- [ ] 审定表分类是否与财务报表附注披露一致

## risk_areas

### 高风险

1. **公允价值变动计入方向错误**：将FVTPL的公允价值变动错误计入OCI而非损益，扭曲当期利润。
2. **分类判断错误**：应分类为摊余成本/FVOCI的资产误入FVTPL（或反之），计量基础错误。
3. **公允价值高估**：非活跃市场资产估值高估，资产及公允价值变动损益虚增。
4. **期初期末不勾稽**：期初审定数与上年期末不一致。
5. **审计调整遗漏**：已确认调整未反映在审定表。

### 中风险

1. **明细与汇总不勾稽**：审定表各行合计与G9-2明细表总计不一致。
2. **流动性分类错误**：一年内收回部分未重分类至流动资产。
3. **审定表与附注口径不一致**：审定表分类与附注披露不一致。

### 低风险

1. **审定表格式不规范**：列标题、行顺序等格式问题。
2. **底稿交叉索引不完整**：未与明细表、公允价值测试建立索引。
3. **辅助说明不充分**：变动较大行项目未附说明。
