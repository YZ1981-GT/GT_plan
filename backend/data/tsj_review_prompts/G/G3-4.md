# G3-4 应收股利测算检查表复核提示词

## 概述

本提示词针对应收股利测算检查表（G3-4）的复核，聚焦基于被投资方分红决议独立测算应分股利，验证企业确认金额的准确性：分配总额、持股比例、应分金额的独立测算与账面对比。测算是应收股利存在性和准确性的核心程序，须核对被投资方决议与持股关系。

**法规依据：**
- 《企业会计准则第22号——金融工具确认和计量》
- 《企业会计准则第2号——长期股权投资》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **独立测算是核心程序**：审计师应基于被投资方分红决议和持股比例独立测算应分股利，与账面确认对比。
2. **分配总额须核对决议**：被投资方分配的股利总额须核对至其股东会/董事会分红决议。
3. **持股比例须核对**：应分股利=分配总额×持股比例，持股比例须核对至持股协议、工商登记或验资报告。
4. **确认时点须验证**：测算须验证股利在被投资方宣告时点确认，未宣告不得确认。
5. **权益法与成本法区分**：长期股权投资权益法下分红冲减投资，成本法/金融资产下确认投资收益，测算口径须区分。
6. **测算差异须查明**：独立测算与账面确认差异须查明原因，评估是否需调整（转G3-3）。

---

## checklist

### 一、测算参数核对

- [ ] 被投资方分配总额是否核对至分红决议
- [ ] 持股比例是否核对至持股协议/工商登记
- [ ] 宣告日期是否核对至决议
- [ ] 投资核算方法（权益法/成本法）是否明确

### 二、测算准确性

- [ ] 应分股利=分配总额×持股比例，独立测算是否正确
- [ ] 权益法与成本法处理口径是否正确区分
- [ ] 确认时点是否为被投资方宣告时点
- [ ] 是否存在提前或滞后确认

### 三、差异与勾稽

- [ ] 独立测算与账面确认差异是否查明原因
- [ ] 测算合计是否与G3-1审定表/G3-2明细表勾稽
- [ ] 重大差异是否评估调整（转G3-3）

## risk_areas

### 高风险

1. **应分股利测算错误未发现**：独立测算未执行或测算错误，未能发现企业多确认/少确认股利。
2. **持股比例或分配总额取数错误**：测算参数错误导致测算失真，无法验证账面准确性。
3. **确认时点错误未识别**：未验证宣告时点，提前确认未宣告股利未被发现。

### 中风险

1. **权益法成本法混淆**：投资核算方法混淆导致测算口径错误。
2. **测算与审定表脱节**：G3-4测算结果与G3-1审定数不勾稽。
3. **差异未查明**：测算与账面差异存在但未查明原因。

### 低风险

1. **测算底稿记录不充分**：测算参数、来源记录简略。
2. **交叉索引不完整**：G3-4未与G3-1/G3-2建立索引。
