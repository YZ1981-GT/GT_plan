# G6-note-soe 其他债权投资附注披露 复核提示词（国有企业）

## 概述

本提示词针对其他债权投资国有企业附注披露底稿（G6-note-soe）的复核，聚焦国有企业特定的附注披露要求：在FVOCI基础披露（分类/公允价值层次/OCI/减值）之上，增加国有资产监管相关披露、投资决策合规性、公允价值下跌对国有资本保值增值的影响、以及国资委财务决算报告的补充要求。国有企业金融资产投资须同时满足会计准则和国资监管要求。

**法规依据：**
- 《企业会计准则第37号——金融工具列报》
- 《企业会计准则第22号——金融工具确认和计量》
- 《企业国有资产法》
- 《中央企业财务决算报告管理办法》

---

## tips

1. **国企附注双层要求**：既满足CAS37通用披露，又满足国资委财务决算报告的额外披露要求，两套要求互为补充。
2. **投资决策合规性**：重大金融资产投资须经"三重一大"决策程序，附注宜说明本期重大购入/处置的决策审批情况。
3. **保值增值视角**：其他债权投资公允价值持续下跌或减值累积可能被视为国有资产减值风险，须说明成因及应对。
4. **公允价值层次仍须披露**：与上市版一致须按第一/二/三层次披露，第三层次估值须客观依据，防止高估国有资产。
5. **差异在监管层面**：基础披露框架与上市版相同（分类/公允价值层次/OCI/减值），国企版额外增加国资监管信息而非替代。
6. **决算勾稽**：附注数据须与年度财务决算报表一致，内部投资抵销须完整。

## checklist

### 一、基础披露完整性（与上市版共有）

- [ ] 是否明确披露FVOCI分类及分类依据
- [ ] 公允价值是否按第一/二/三层次披露
- [ ] 计入OCI的累计公允价值变动是否单独披露
- [ ] 预期信用损失是否按三阶段披露
- [ ] 附注期末余额是否与审定表审定数一致
- [ ] 期初/期末可比信息是否完整

### 二、国有资产监管相关披露

- [ ] 重大其他债权投资购入/处置是否披露决策审批程序
- [ ] 公允价值持续下跌或大额减值是否披露成因及应对措施
- [ ] 是否披露投资对国有资本保值增值率的影响
- [ ] 涉及国有资产处置/划转的事项是否单独说明
- [ ] 第三层次估值是否有客观独立依据（防国有资产高估）

### 三、投资合规与决策披露

- [ ] 本期重大投资/处置是否经"三重一大"集体决策
- [ ] 投资是否符合国资委关于金融业务/非主业投资的监管要求
- [ ] 是否披露投资对手方是否为关联方及交易公允性
- [ ] 是否存在超授权额度投资并予以说明

### 四、决算与差异披露

- [ ] 附注数据是否与年度财务决算报表一致
- [ ] 集团合并层面内部债权投资抵销是否完整
- [ ] 其他债权投资中属于"不良资产"的部分是否按决算要求单独披露
- [ ] 与上市版相比是否增加了国资监管补充信息而非替代基础披露

## risk_areas

### 高风险

1. **重大投资未经决策程序披露**：大额其他债权投资购入/处置未经"三重一大"或未披露决策过程，存在合规风险。
2. **公允价值高估国有资产**：第三层次估值缺乏客观依据导致资产高估，掩盖国有资产减值。
3. **减值成因未披露**：大额减值或公允价值持续下跌未说明成因和应对，可能被认定为管理不到位。
4. **附注与决算/审定表不勾稽**：附注数据与决算报表或审定表不一致，属重大数据错误。

### 中风险

1. **非主业投资合规披露缺失**：金融资产投资是否符合国资委非主业监管要求未说明。
2. **关联方投资公允性未披露**：投资对手方为关联方但未披露交易公允性。
3. **OCI/减值三阶段披露不完整**：基础披露维度缺失，影响信息完整性。

### 低风险

1. **披露格式未按决算模板**：附注格式与国资委决算报表模板有细微差异。
2. **保值增值影响分析简略**：仅提及影响未量化分析。
3. **历史趋势追溯不完整**：投资变动趋势分析仅覆盖2年而非3年。
