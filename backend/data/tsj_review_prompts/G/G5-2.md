# G5-2 长期应收款余额明细表复核提示词

## 概述

本提示词针对长期应收款余额明细表（G5-2）的复核，聚焦逐笔长期应收款的债务人/承租人、应收款项总额、未实现融资收益、净额、实际利率、减值准备、期限的明细核对，以及明细合计与审定表（G5-1）的勾稽。明细表须逐项核对至融资租赁合同、分期收款销售合同、摊销表等证据。

**法规依据：**
- 《企业会计准则第21号——租赁》
- 《企业会计准则第22号——金融工具确认和计量》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **逐笔明细须核对至合同**：每笔长期应收款的债务人、应收总额、期限、利率应核对至融资租赁合同/分期收款销售合同。
2. **明细合计必须与审定表勾稽**：明细净额合计须等于G5-1审定表长期应收款审定数。
3. **净额组成须清晰**：明细应清晰反映应收款项总额、未实现融资收益、减值准备、净额，勾稽须成立。
4. **实际利率须核对**：各笔应实际利率应与G5-5/G5-6摊销表一致。
5. **减值准备逐笔列示**：各笔长期应收款减值准备应逐笔列示，与G5-10测算勾稽。
6. **关注单笔重大或信用恶化**：单笔重大或信用状况恶化的长期应收款须标注，联动三阶段划分。

---

## checklist

### 一、明细核对完整性

- [ ] 每笔长期应收款的债务人/承租人、应收总额、期限、利率是否完整记录
- [ ] 应收总额和期限是否核对至合同
- [ ] 是否区分融资租赁应收款与分期收款销售应收款
- [ ] 是否存在明细遗漏或重复

### 二、净额组成核对

- [ ] 应收总额、未实现融资收益、减值准备、净额各组成是否清晰
- [ ] 净额=应收总额−未实现融资收益−减值准备，勾稽是否成立
- [ ] 实际利率是否与G5-5/G5-6摊销表一致
- [ ] 明细净额合计是否等于G5-1审定表审定数

### 三、减值与信用状态

- [ ] 各笔减值准备是否逐笔列示并与G5-10勾稽
- [ ] 信用恶化的长期应收款是否标注（联动G5-9三阶段）
- [ ] 关联方长期应收款是否可识别
- [ ] 一年内到期部分是否可识别（供重分类）

## risk_areas

### 高风险

1. **净额组成不实**：单笔应收总额、未实现融资收益或减值计算错误，导致净额失真。
2. **明细合计与审定表不符**：明细净额合计与G5-1审定数不一致。
3. **虚构长期应收款**：无合同支撑的长期应收款明细，虚增资产。

### 中风险

1. **实际利率不一致**：明细实际利率与G5-5/G5-6摊销表不符。
2. **减值准备漏列**：信用恶化的长期应收款未逐笔列示减值准备。
3. **融资租赁与分期收款混淆**：两类应收款未区分，核算口径混乱。

### 低风险

1. **明细记录格式不统一**：债务人、金额、期限记录不规范。
2. **交叉索引不完整**：明细未与G5-5/G5-6/G5-10建立索引。
3. **信用状态/一年内到期未标注**：未标注提示信息。
