# G2-1 应收利息审定表复核提示词

## 概述

本提示词针对应收利息审定表（G2-1）的复核，聚焦应收利息的期初期末勾稽、利息计提准确性、与债权投资/存款本金的勾稽、预期信用损失（坏账准备）计提及分类列报。应收利息核算已按CAS22调整为反映实际利率法下未收回的合同利息，须与G2-5利息测算表、相关本金科目严密勾稽。

**法规依据：**
- 《企业会计准则第22号——金融工具确认和计量》
- 《企业会计准则第37号——金融工具列报》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **期初期末勾稽是审定表的生命线**：期初审定数须等于上年期末审定数，任何差异需追溯至本期计提、收回或调整分录。
2. **应收利息须与本金科目勾稽**：应收利息应能追溯至对应的债权投资、定期存款、借款等本金科目，利息率×本金×期间应逻辑成立。
3. **计提利息须与G2-5测算表一致**：审定表应收利息计提金额须与G2-5利息测算表计算结果勾稽。
4. **区分合同利息与实际利率法利息**：CAS22下债权投资的利息按实际利率法确认（计入债权投资），应收利息仅反映合同应收未收部分，须核对口径。
5. **坏账准备须计提**：应收利息作为金融资产须评估预期信用损失，与G2-3/G2-7坏账准备勾稽。
6. **试算平衡表核对**：审定表应收利息审定数合计须与试算平衡表对应科目审定数一致。

## checklist

### 一、期初期末勾稽

- [ ] 期初未审数是否等于上年审定表期末审定数
- [ ] 期末审定数=期初+本期计提−本期收回，计算是否正确
- [ ] 审定表各行变动是否与G2-2明细表增减一致
- [ ] 本期计提/收回是否与G2-8凭证检查勾稽

### 二、利息计提与本金勾稽

- [ ] 应收利息计提是否与G2-5利息测算表一致
- [ ] 应收利息是否能追溯至对应本金科目（债权投资/存款/借款）
- [ ] 利息率×本金×期间的计算逻辑是否成立
- [ ] 合同利息与实际利率法利息口径是否正确区分

### 三、坏账准备与试算核对

- [ ] 应收利息坏账准备是否计提（与G2-3/G2-7勾稽）
- [ ] 应收利息净额列示是否准确
- [ ] 审定数合计是否与试算平衡表对应科目一致
- [ ] 所有AJE/RJE是否完整反映在审定表调整列

### 四、分类列报

- [ ] 应收利息是否按流动性正确分类
- [ ] 关联方应收利息是否单独列示
- [ ] 长期未收回利息是否与G2-6检查勾稽
- [ ] 审定表分类是否与附注披露一致

## risk_areas

### 高风险

1. **虚增应收利息**：无对应本金支撑或超计提利息，虚增资产和利息收入，构成重大错报。
2. **期初期末不勾稽**：期初审定数与上年期末不一致，存在未授权调整或录入错误。
3. **利息计提与本金脱节**：应收利息无法追溯至本金科目，或利率/期间计算错误。
4. **坏账准备遗漏**：长期未收回利息未评估预期信用损失，资产虚增。
5. **审计调整遗漏或缺乏审批**：已确认调整未反映在审定表，或未经合伙人批准。

### 中风险

1. **明细与汇总不勾稽**：审定表合计与G2-2明细表不一致。
2. **合同利息与实际利率法混淆**：债权投资利息口径处理错误，重复计提或漏计。
3. **分类列报错误**：长期未收回利息未正确列示或关联方未单独列示。

### 低风险

1. **审定表格式不规范**：列标题、行顺序、编号格式问题。
2. **底稿交叉索引不完整**：未与G2-2/G2-5及试算平衡表建立索引。
3. **辅助说明不充分**：变动较大行项目未附说明。
