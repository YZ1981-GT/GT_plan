# G11-3 投资收益调整分录复核提示词

## 概述

本提示词针对投资收益调整分录（G11-3）的复核，含账项调整（AJE）、重分类调整（RJE）及未调整错报（SUD）评估。复核须验证每笔调整有证据、借贷平衡、完整反映到G11-1审定表，并同步试算平衡表。

**法规依据：**
- 《企业会计准则第22号——金融工具确认和计量》
- 《企业会计准则第2号——长期股权投资》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **AJE影响损益、RJE仅影响列报**：投资收益的AJE直接调整损益金额（如补确认权益法收益、更正处置损益），RJE仅涉及科目列报（如投资收益与公允价值变动损益之间的重分类），不得以RJE掩盖损益错报。
2. **调整须与G11-1审定表逐笔勾稽**：审定表调整列金额必须与G11-3已确认分录逐笔一致，遗漏任一笔即审定数失真。
3. **权益法收益调整须追溯被投资方财报**：补提或冲减权益法收益的调整须有被投资方审定财报及持股比例支持。
4. **OCI结转调整须符合准则**：涉及处置金融资产时OCI累计利得转入损益的调整，须区分工具类型（部分权益工具不得转入损益），错误结转会造成损益操纵。
5. **审批链留痕**：超过明细层次重要性水平的调整须经合伙人/项目经理审批并留痕。
6. **TB回写一致**：确认调整已同步试算平衡表6111科目，避免"底稿已调、TB未更"双真源。

## checklist

### 一、账项调整（AJE）

- [ ] 所有AJE是否有充分审计证据（被投资方财报、处置协议、分红决议等）
- [ ] AJE是否经适当层级审批（超重要性水平须合伙人知悉）
- [ ] 每笔调整分录借贷方是否完全平衡
- [ ] 调整金额是否完整反映到G11-1审定表调整列
- [ ] 权益法收益调整是否与被投资方财报×持股比例勾稽

### 二、重分类调整（RJE）

- [ ] RJE是否仅涉及列报，未影响损益总额
- [ ] 投资收益与公允价值变动损益/资产处置收益之间的重分类是否恰当
- [ ] OCI累计利得转入损益的调整是否符合工具类型规定
- [ ] 是否存在以RJE掩盖损益错报的情形

### 三、未调整错报（SUD）与勾稽

- [ ] 未调整错报累计是否超过整体重要性水平（须评估）
- [ ] 与A13未调整错报汇总表索引是否完整
- [ ] 跨期调整是否正确区分本期错报与前期差错更正
- [ ] 调整后审定数是否已同步试算平衡表6111科目

## risk_areas

### 高风险

1. **调整缺乏证据或未经授权**：投资收益调整无被投资方财报/处置协议支持，或未经合伙人审批即纳入审定表。
2. **审定表与调整金额不一致**：G11-1审定表调整列与G11-3已确认分录长期不一致，审定数失真。
3. **以RJE掩盖损益错报**：将本应作AJE的损益错报以重分类处理，规避损益影响。
4. **OCI违规结转**：处置权益工具时将不得转入损益的OCI累计利得通过调整转入投资收益。

### 中风险

1. **RJE误含损益影响**：重分类调整影响了损益总额而非仅列报。
2. **跨期调整分类错误**：未区分本期错报与前期差错更正，会计处理与披露错误。
3. **SUD累计超阈值未处理**：未调整错报累计超重要性水平但未恰当评估。

### 低风险

1. **分录摘要、科目编码不规范**：调整分录摘要笼统或科目编码不规范。
2. **索引指向不完整**：调整分录未指向G11-2明细分析、被投资方财报等支持底稿。
3. **审计说明不充分**：未概括调整性质与剩余风险。
