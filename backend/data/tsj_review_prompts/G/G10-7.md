# G10-7 交易性金融负债凭证检查 复核提示词

## 适用底稿
交易性金融负债凭证检查表（G10-7），聚焦样本选取合理性、凭证核对完整性、检查比例达标性、异常交易标注充分性。

## tips

- 样本选取应覆盖本期新增承担、偿还/结算、大额公允价值变动等重大变动
- 凭证核对须验证负债真实性、金额准确性、合约有效性（合约/交易确认书/划款凭证/记账）
- 检查比例应满足《中国注册会计师审计准则第1314号——审计抽样》要求
- 重大负债/结算应100%检查，衍生工具须核对合约要素和估值凭证
- 关注负债完整性（表外衍生工具/未入账负债），防止少计负债虚增损益
- 结算凭证须核对结算金额、平仓/交割凭证，验证结算损益确认
- 异常标注：公允价值大幅偏离估值、无合约支持的负债、关联方衍生交易
- 关注期末突击平仓、以衍生工具名义的投机/利益输送

## checklist

### 高风险检查项

- [ ] 样本选取是否覆盖本期所有重大负债变动（新增/结算/大额公允价值变动）
- [ ] 重大负债/结算（超重要性水平）是否100%检查
- [ ] 负债承担是否有真实合约/交易确认书支持
- [ ] 是否核查负债完整性（表外衍生/未入账负债）
- [ ] 衍生工具合约要素（名义本金/执行价/到期日）是否核对
- [ ] 公允价值变动大的项目是否核对估值凭证
- [ ] 结算凭证是否完整（结算单/平仓/交割/划款）
- [ ] 是否存在无商业实质的关联方衍生交易/利益输送

### 中风险检查项

- [ ] 抽样方法是否符合CAS1314要求
- [ ] 检查比例（已检查金额/总体金额）是否达到计划水平
- [ ] 初始确认金额凭证是否核对（交易费用进损益）
- [ ] 公允价值估值凭证/报告是否核对（衍生/第三层次）
- [ ] 结算损益确认凭证是否核对
- [ ] 凭证日期与记账日期是否一致，是否跨期
- [ ] 核对差异是否逐一追踪解决

### 低风险检查项

- [ ] 抽样参数是否完整记录
- [ ] 样本选取过程是否可追溯
- [ ] 检查结果记录格式是否规范统一
- [ ] 检查比例计算公式是否正确
- [ ] 底稿索引与交叉引用是否完整

## risk_areas

### 高风险

1. **负债完整性风险**：表外衍生工具或未入账金融负债未识别，少计负债虚增损益。
2. **衍生工具无合约支持风险**：衍生金融负债缺乏合约/交易确认书支持，真实性存疑。
3. **公允价值变动损益不实风险**：公允价值变动凭证缺乏估值支持，直接虚增/虚减当期损益。
4. **结算损益操纵风险**：结算/平仓凭证不清，跨期确认结算损益调节利润。
5. **关联方衍生利益输送风险**：以衍生工具名义的关联方交易，向关联方输送利益或投机。

### 中风险

1. **检查比例不足风险**：实际检查比例低于计划，审计证据不充分。
2. **合约要素核对不足风险**：衍生工具合约要素与估值输入未核对。
3. **估值凭证核对不足风险**：衍生/第三层次估值凭证核对深度不够。
4. **成本处理错误风险**：交易费用误计入初始金额（应进损益）。

### 低风险

1. **记录不完整风险**：抽样参数/选取过程/核对结果记录不完整。
2. **索引缺失风险**：凭证检查与审定表/明细表交叉索引不完整。
3. **格式不规范风险**：检查结果记录格式不统一。
