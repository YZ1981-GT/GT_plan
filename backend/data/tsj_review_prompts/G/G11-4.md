# G11-4 投资收益率分析表复核提示词

## 概述

本提示词针对投资收益率分析表（G11-4）的复核。该表通过测算各投资项目的收益率并与同期市场基准、历史水平或被投资方业绩对比，评估投资收益确认的合理性，识别异常高/低收益，是实质性分析程序的重要底稿。

**法规依据：**
- 《企业会计准则第22号——金融工具确认和计量》
- 《企业会计准则第2号——长期股权投资》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **收益率测算须口径一致**：收益率=投资收益÷平均投资账面价值，分子分母口径须匹配（同一投资项目、同一期间），避免用期末余额或错配基数导致收益率失真。
2. **对标合理性基准**：将测算收益率与同期市场利率、被投资方净资产收益率、历史收益率对比，显著偏离基准的项目须查明原因。
3. **异常高收益警惕虚构**：收益率异常偏高（远超市场同类投资）的项目可能存在虚构收益或提前确认，须核对现金流入及被投资方业绩支持。
4. **异常低/负收益关注减值信号**：收益率异常偏低或持续为负的长期股权投资，可能是被投资方持续亏损的减值迹象，须联动G7减值评估。
5. **权益法收益率与被投资方ROE勾稽**：权益法下投资收益率应大致等于被投资方净资产收益率×相关调整，重大偏离须说明。
6. **分析结论须支撑审计判断**：收益率分析的异常识别应形成明确结论，并与审定数确认、减值评估等程序联动，不得仅列数据无结论。

## checklist

### 一、测算口径

- [ ] 收益率计算公式是否口径一致（分子分母匹配）
- [ ] 平均投资账面价值基数是否正确（期初+期末）/2或加权
- [ ] 各投资项目收益率是否分项测算
- [ ] 测算所用投资收益是否与G11-1/G11-2一致

### 二、对标与合理性

- [ ] 收益率是否与市场基准/被投资方业绩/历史水平对比
- [ ] 显著偏离基准的项目是否查明原因
- [ ] 权益法收益率是否与被投资方ROE大致勾稽
- [ ] 异常高收益是否核对现金流入及业绩支持

### 三、异常识别与联动

- [ ] 异常偏低/负收益项目是否评估减值迹象（联动G7）
- [ ] 异常识别是否形成明确审计结论
- [ ] 分析结果是否与审定数确认、减值评估程序联动
- [ ] 是否存在异常收益率但未做进一步程序的情形

### 四、列报与勾稽

- [ ] 分析所用投资收益金额是否与审定表勾稽
- [ ] 收益率分析结论是否与附注投资收益说明一致

## risk_areas

### 高风险

1. **异常高收益率未查证虚构**：收益率远超市场同类水平但未核对现金流入和被投资方业绩，可能掩盖虚构投资收益。
2. **减值迹象漏识别**：长期股权投资收益率持续为负未触发减值评估，导致资产高估、损失漏计。
3. **测算口径错配导致误判**：分子分母口径不一致使收益率严重失真，掩盖真实异常。

### 中风险

1. **对标基准不当**：选用不可比的市场基准或历史水平，无法有效识别异常。
2. **分析无结论**：仅列示收益率数据未形成审计判断，分析程序流于形式。
3. **权益法收益率与ROE重大偏离未说明**：偏离未查明原因，可能反映收益确认错误。

### 低风险

1. **分析维度单一**：仅测算整体收益率未分项，异常项目难以定位。
2. **可比数据不足**：缺少上期或行业可比收益率，趋势分析受限。
3. **底稿索引不完整**：分析表未标注数据来源底稿索引。
