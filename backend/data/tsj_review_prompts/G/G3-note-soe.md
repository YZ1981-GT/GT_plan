# G3-note-soe 应收股利附注披露复核提示词（国有企业）

## 概述

本提示词针对应收股利国有企业附注披露底稿（G3-note-soe）的复核，聚焦国有企业特定的附注披露要求：基础披露（按被投资方分类/账龄/可收回性）之上，叠加国有资产监管相关披露——对国有控股/参股企业的应收股利、分红兑现的国资监管视角、长期挂账股利的资金占用考量、以及与上市公司版本的差异关注点。

**法规依据：**
- 《企业会计准则第37号——金融工具列报》
- 《企业会计准则第36号——关联方披露》
- 《企业国有资产法》
- 《中央企业财务决算报告管理办法》

---

## tips

1. **国企关联方范围更广**：应收股利的关联方披露须考虑同一国有控股股东控制的其他国有企业及被投资国企。
2. **国有股权分红是国企关注点**：对国有控股/参股企业的应收股利须单独说明，评估分红兑现的合规性。
3. **基础披露框架与上市版相同**：分类、账龄、可收回性等基础披露一致，国企版增加国资监管信息。
4. **长期挂账股利的资金占用考量**：长期未收回应收股利可能反映资金占用或分红未兑现，须结合国资监管说明。
5. **股利收益影响保值增值**：应收股利兑现情况影响国有资本收益和保值增值率。
6. **与上市版差异在监管层面**：国企版在基础披露基础上补充国资监管相关信息。

## checklist

### 一、基础披露完整性（与上市版共有）

- [ ] 应收股利是否按被投资方分类披露
- [ ] 各类别合计是否等于G3-1审定表审定数
- [ ] 账龄披露是否与G3-2/G3-5一致
- [ ] 期初数/期末数可比信息是否完整

### 二、国有资产监管相关披露

- [ ] 对国有控股/参股企业的应收股利是否单独披露
- [ ] 长期未收回应收股利是否说明原因及催收措施
- [ ] 应收股利兑现对国有资本收益/保值增值的影响是否说明
- [ ] 大额应收股利是否按国资委要求逐户披露

### 三、关联方披露（国企特定）

- [ ] 与控股股东及关联企业的应收股利是否逐户列示
- [ ] 与同受国有控制企业/被投资国企的应收股利是否披露
- [ ] 关联方分红兑现情况是否说明
- [ ] 是否存在长期挂账股利涉及资金占用并予以说明

### 四、与上市版差异关注点

- [ ] 国企版是否在基础披露上增加国资监管信息
- [ ] 关联方范围是否扩展至同受国有控制企业
- [ ] 是否增加国有股权分红兑现说明
- [ ] 决算报表应收股利数据是否与本附注一致

## risk_areas

### 高风险

1. **长期挂账股利资金占用未披露**：对国有企业长期未收回股利未说明是否涉及资金占用，可能掩盖国有资产问题。
2. **关联方应收股利范围遗漏**：未纳入同受国有控制企业或被投资国企，关联交易信息不完整。
3. **基础披露与审定表不勾稽**：附注应收股利合计与G3-1审定数不一致。

### 中风险

1. **国有股权分红兑现未说明**：对国有控股/参股企业应收股利的兑现情况未充分说明。
2. **保值增值影响未分析**：应收股利兑现对国有资本收益影响未说明。
3. **可收回性说明不足**：长期未收回股利可收回性缺乏说明。

### 低风险

1. **披露格式未按决算模板**：附注格式与国资委决算模板细微差异。
2. **可比信息追溯不完整**：历史趋势分析不足。
3. **催收措施说明简略**：长期挂账催收进展说明不充分。
