# G6-note-listed 其他债权投资附注披露 复核提示词（上市公司）

## 概述

本提示词针对其他债权投资上市公司附注披露底稿（G6-note-listed）的复核，聚焦FVOCI债务工具的分类披露、公允价值层次披露、其他综合收益累计额披露、预期信用损失披露、以及处置转损益披露的充分性和准确性。其他债权投资的公允价值计量属性和OCI处理是报表使用者理解权益变动的关键，披露不充分将影响投资者判断。

**法规依据：**
- 《企业会计准则第37号——金融工具列报》
- 《企业会计准则第22号——金融工具确认和计量》
- 《公开发行证券的公司信息披露编报规则第15号——财务报告的一般规定》

---

## tips

1. **分类披露须体现FVOCI属性**：附注须明确其他债权投资分类为以公允价值计量且其变动计入其他综合收益的金融资产，并说明分类依据（业务模式+SPPI）。
2. **公允价值层次强制披露**：须按第一/二/三层次披露公允价值计量输入值，第三层次须披露估值技术和关键不可观察输入。
3. **OCI累计额单独列示**：期末计入其他综合收益的公允价值变动累计额须单独披露，并列示本期变动和处置结转金额。
4. **ECL披露体现OCI特性**：预期信用损失计入OCI，附注须说明减值不冲减账面价值，并披露三阶段减值准备及变动。
5. **处置披露转损益金额**：本期处置的其他债权投资须披露处置收益及从OCI转入损益的累计公允价值变动金额。
6. **附注勾稽底稿闭环**：附注披露金额须与G6-1审定表、G6-2明细表、G6-3减值明细形成闭环勾稽。

## checklist

### 一、分类与计量属性披露

- [ ] 是否明确披露分类为FVOCI债务工具及分类依据（业务模式既收取又出售+SPPI）
- [ ] 期末余额是否等于审定表其他债权投资审定数
- [ ] 是否同时披露期末数和期初数（可比信息）
- [ ] 是否披露以摊余成本计量的利息收入和以公允价值列示的账面价值

### 二、公允价值层次披露

- [ ] 是否按第一/二/三层次披露公允价值
- [ ] 第三层次是否披露估值技术和关键不可观察输入
- [ ] 各层次金额合计是否等于其他债权投资总额
- [ ] 层次间转移是否披露及说明原因

### 三、OCI与减值披露

- [ ] 计入其他综合收益的累计公允价值变动是否单独披露
- [ ] 本期OCI变动和处置结转金额是否披露
- [ ] 预期信用损失是否按三阶段披露且说明计入OCI
- [ ] 减值准备变动表是否完整（期初/计提/转回/核销/期末）
- [ ] 本期计提减值是否与利润表信用减值损失勾稽

### 四、处置与其他披露

- [ ] 本期处置收益及从OCI转入损益的金额是否披露
- [ ] 已质押/受限的其他债权投资是否披露
- [ ] 信用风险敞口和信用质量信息是否披露
- [ ] 附注各项金额是否与G6-1/G6-2/G6-3勾稽

## risk_areas

### 高风险

1. **OCI累计额未披露或不勾稽**：未单独披露计入OCI的累计公允价值变动，或与审定表OCI余额不一致，投资者无法理解权益构成。
2. **公允价值层次披露缺失**：未按层次披露或第三层次估值假设不披露，不满足CAS37强制要求。
3. **减值披露与损益不一致**：ECL披露的本期计提与利润表信用减值损失不一致，属重大披露错误。
4. **附注总额与审定表不一致**：附注其他债权投资期末余额与审定表审定数不一致。

### 中风险

1. **分类依据披露不充分**：仅列示分类结果未说明业务模式和SPPI判断依据。
2. **处置结转披露不完整**：处置收益披露但未单独列示从OCI转入损益的金额。
3. **减值三阶段披露缺失**：仅披露减值总额未按阶段分类。

### 低风险

1. **披露格式不完全规范**：表格标题、列序、单位等格式细节不完全符合编报规则。
2. **文字描述模板化**：信用风险管理政策照搬会计政策未结合企业实际。
3. **可比信息简略**：期初可比数据列示不完整。
