# G7-note-listed 长期股权投资附注披露 复核提示词（上市公司）

## 概述

本提示词针对长期股权投资上市公司附注披露底稿（G7-note-listed）的复核，聚焦重要子公司/合营/联营企业信息披露、权益法投资变动披露、减值披露、以及丧失控制权/一揽子交易等重大处置披露的充分性和准确性。上市公司须按证监会编报规则详细披露长期股权投资的构成、被投资单位关键财务信息及处置影响，披露不充分将影响投资者对投资价值和风险的判断。

**法规依据：**
- 《企业会计准则第2号——长期股权投资》
- 《企业会计准则第33号——合并财务报表》
- 《企业会计准则第36号——关联方披露》
- 《公开发行证券的公司信息披露编报规则第15号——财务报告的一般规定》

## tips

1. **分类披露成本法/权益法**：附注须区分对子公司（成本法）和对合营/联营企业（权益法）的投资分别披露，各类合计须与审定表勾稽。
2. **重要被投资单位关键信息**：须披露重要子公司/合营/联营企业的名称、注册地、业务性质、持股比例、表决权比例、核算方法。
3. **权益法变动明细**：权益法投资须披露期初、追加/减少、权益法确认损益、OCI变动、宣告分派现金股利、减值、期末的完整变动表。
4. **减值披露**：须披露减值准备的计提、期末余额及减值迹象，减值一经计提不得转回须体现。
5. **重大处置披露**：本期丧失控制权、构成一揽子交易的处置须披露处置损益、剩余股权重新计量、原OCI结转金额。
6. **附注勾稽底稿闭环**：附注金额须与G7-1审定表、G7-2明细表、G7-14权益法核算、G7-17减值测试形成闭环勾稽。

## checklist

### 一、分类与被投资单位信息

- [ ] 是否区分子公司（成本法）和合营/联营（权益法）分类披露
- [ ] 各类投资期末余额合计是否与审定表审定数一致
- [ ] 重要被投资单位名称、注册地、业务性质是否披露
- [ ] 持股比例、表决权比例、核算方法是否披露
- [ ] 是否同时披露期末数和期初数（可比信息）

### 二、权益法变动披露

- [ ] 权益法投资变动表是否完整（期初/追加减少/确认损益/OCI/现金股利/减值/期末）
- [ ] 权益法确认的投资损益是否与利润表投资收益勾稽
- [ ] OCI变动是否单独披露
- [ ] 宣告分派现金股利是否披露

### 三、减值披露

- [ ] 减值准备的计提金额、期末余额是否披露
- [ ] 减值迹象和减值测试关键假设是否披露
- [ ] 减值一经计提不得转回是否体现（无转回）
- [ ] 减值准备是否与G7-17减值测试勾稽

### 四、处置与其他披露

- [ ] 本期重大处置（丧失控制权/一揽子交易）是否披露处置损益
- [ ] 丧失控制权剩余股权重新计量金额是否披露
- [ ] 原计入OCI转入损益的金额是否披露
- [ ] 关联方（合营/联营）投资是否结合CAS36披露
- [ ] 投资受限/质押情况是否披露

## risk_areas

### 高风险

1. **权益法变动表不完整或不勾稽**：变动表各项金额与G7-14权益法核算不一致，或期初+变动≠期末，属重大披露错误。
2. **重大处置披露缺失**：丧失控制权/一揽子交易的处置损益、剩余股权重新计量、OCI结转未披露，投资者无法评估处置影响。
3. **减值披露与减值测试不一致**：附注减值金额与G7-17不一致，或体现减值转回。
4. **附注总额与审定表不一致**：附注长期股权投资期末余额与审定表审定数不一致。

### 中风险

1. **被投资单位信息不完整**：重要被投资单位持股比例/表决权比例/核算方法披露不全。
2. **确认损益与利润表不勾稽**：权益法确认的投资损益与利润表投资收益不一致。
3. **关联方投资披露不足**：合营/联营投资未结合CAS36充分披露关联交易。

### 低风险

1. **披露格式不完全规范**：表格标题、列序、单位等格式细节不完全符合编报规则。
2. **文字描述模板化**：核算方法说明照搬准则未结合企业实际。
3. **可比信息简略**：期初可比数据列示不完整。
