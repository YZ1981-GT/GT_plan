# G8-6 其他权益工具投资凭证检查 复核提示词

## 适用底稿
其他权益工具投资凭证检查表（G8-6），聚焦样本选取合理性、凭证核对完整性、检查比例达标性、异常交易标注充分性。

## tips

- 样本选取应覆盖本期新增投资、处置、大额股利收取等重大变动
- 凭证核对须验证投资真实性、成本准确性、权属清晰性（认购协议/交割单/工商登记/记账）
- 检查比例应满足《中国注册会计师审计准则第1314号——审计抽样》要求
- 重大投资/处置应100%检查，关联方投资须单独关注公允性和商业实质
- 股利收取凭证须核对被投资单位利润分配决议和到账凭证
- 处置凭证须核对转让协议、收款凭证、工商变更，验证OCI累计额转留存收益处理
- 异常标注：投资价款与公允价值大幅偏离、无实际出资的股权登记、体外资金循环
- 关注以股权投资名义的关联方资金占用

## checklist

### 高风险检查项

- [ ] 样本选取是否覆盖本期所有重大投资变动（新增/处置/大额股利）
- [ ] 重大投资/处置（超重要性水平）是否100%检查
- [ ] 出资是否有真实资金流出（银行回单/交割凭证）
- [ ] 投资价款与被投资单位公允价值是否匹配（防高价利益输送）
- [ ] 股权取得是否办理工商变更登记（权属清晰）
- [ ] 股利收取是否核对利润分配决议和到账凭证
- [ ] 处置凭证是否完整（转让协议/收款/工商变更）
- [ ] 关联方投资是否核查交易公允性和商业实质

### 中风险检查项

- [ ] 抽样方法是否符合CAS1314要求
- [ ] 检查比例（已检查金额/总体金额）是否达到计划水平
- [ ] 取得成本凭证是否核对（含交易费用计入成本）
- [ ] 公允价值估值凭证/报告是否核对（第三层次）
- [ ] 处置时OCI累计额转留存收益处理是否核对
- [ ] 凭证日期与记账日期是否一致，是否跨期
- [ ] 核对差异是否逐一追踪解决

### 低风险检查项

- [ ] 抽样参数是否完整记录
- [ ] 样本选取过程是否可追溯
- [ ] 检查结果记录格式是否规范统一
- [ ] 检查比例计算公式是否正确
- [ ] 底稿索引与交叉引用是否完整

## risk_areas

### 高风险

1. **虚假出资风险**：股权登记但无真实资金流出，虚增其他权益工具投资。
2. **高价投资利益输送风险**：投资价款远高于被投资单位公允价值，向关联方输送利益。
3. **股利虚增收入风险**：确认股利收入缺乏利润分配决议和到账凭证支持。
4. **处置OCI结转错误风险**：处置凭证核对不到位，OCI累计额错误转入损益而非留存收益。
5. **体外资金循环风险**：以股权投资名义的关联方资金占用，无商业实质。

### 中风险

1. **检查比例不足风险**：实际检查比例低于计划，审计证据不充分。
2. **权属不清风险**：股权取得未办理工商变更登记。
3. **估值凭证核对不足风险**：第三层次估值报告/凭证核对深度不够。
4. **关联方公允性核查不足风险**：关联方投资未实施针对性公允性核查。

### 低风险

1. **记录不完整风险**：抽样参数/选取过程/核对结果记录不完整。
2. **索引缺失风险**：凭证检查与审定表/明细表交叉索引不完整。
3. **格式不规范风险**：检查结果记录格式不统一。
