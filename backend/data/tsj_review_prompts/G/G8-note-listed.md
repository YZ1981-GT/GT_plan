# G8-note-listed 其他权益工具投资附注披露 复核提示词（上市公司）

## 概述

本提示词针对其他权益工具投资上市公司附注披露底稿（G8-note-listed）的复核，聚焦指定为FVOCI的权益工具披露：指定原因、各项投资的公允价值、股利收入、公允价值层次、以及处置时OCI转留存收益的披露。其他权益工具投资的"公允价值变动不转损益"特性和指定不可撤销性是CAS37的特定披露要求，披露不充分将影响报表使用者理解权益及损益构成。

**法规依据：**
- 《企业会计准则第37号——金融工具列报》
- 《企业会计准则第22号——金融工具确认和计量》
- 《企业会计准则第39号——公允价值计量》

---

## tips

1. **指定原因披露**：CAS37要求披露将权益工具投资指定为FVOCI的原因（如战略性持有、长期投资等）。
2. **逐项公允价值披露**：须披露各项其他权益工具投资的名称、期末公允价值、本期确认的股利收入。
3. **公允价值层次披露**：须按第一/二/三层次披露，第三层次（非上市股权）须披露估值技术和关键不可观察输入。
4. **OCI与处置披露**：须披露计入OCI的累计公允价值变动，本期处置的须披露处置时点公允价值及OCI转入留存收益的金额（不转损益）。
5. **股利与终止确认**：须披露本期确认的股利收入，以及本期终止确认（处置）的投资的原因和累计利得/损失。
6. **附注勾稽底稿闭环**：附注金额须与G8-1审定表、G8-2明细表、G8-4公允价值测试形成闭环勾稽。

## checklist

### 一、指定与逐项披露

- [ ] 是否披露指定为FVOCI的原因
- [ ] 是否逐项披露投资名称、期末公允价值
- [ ] 期末公允价值合计是否等于审定表审定数
- [ ] 是否同时披露期末数和期初数（可比信息）

### 二、公允价值层次

- [ ] 是否按第一/二/三层次披露公允价值
- [ ] 第三层次是否披露估值技术和关键不可观察输入
- [ ] 各层次金额合计是否等于其他权益工具投资总额
- [ ] 层次间转移是否披露及说明

### 三、OCI、股利与处置

- [ ] 计入OCI的累计公允价值变动是否披露
- [ ] 本期确认的股利收入是否披露
- [ ] 本期处置的投资是否披露处置时点公允价值及OCI转留存收益金额
- [ ] 是否明确处置不影响损益（OCI转留存收益）

### 四、勾稽

- [ ] 附注各项金额是否与G8-1/G8-2/G8-4勾稽
- [ ] 受限/质押的其他权益工具投资是否披露

## risk_areas

### 高风险

1. **OCI转损益披露错误**：附注披露处置时将OCI转入损益而非留存收益，与准则要求不符。
2. **公允价值层次披露缺失**：未按层次披露或第三层次估值假设不披露，不满足CAS37/CAS39要求。
3. **指定原因未披露**：未披露指定为FVOCI的原因，不满足CAS37特定披露要求。
4. **附注总额与审定表不一致**：附注期末余额与审定表审定数不一致。

### 中风险

1. **股利收入披露缺失**：未单独披露本期确认的股利收入。
2. **处置披露不完整**：处置投资未披露OCI转留存收益金额。
3. **第三层次假设披露不足**：非上市股权估值关键假设未披露。

### 低风险

1. **披露格式不完全规范**：表格标题、列序、单位等格式细节。
2. **文字描述模板化**：指定原因描述照搬未结合企业实际。
3. **可比信息简略**：期初可比数据列示不完整。
