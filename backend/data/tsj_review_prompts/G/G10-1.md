# G10-1 交易性金融负债审定表 复核提示词

## 概述

本提示词针对交易性金融负债审定表（G10-1，科目2101）的复核。交易性金融负债以公允价值计量且其变动计入当期损益（FVTPL），包含以近期回购为目的承担的负债、衍生金融负债、以及指定为FVTPL的金融负债。审定表须完整反映未审→调整→审定链路，勾稽公允价值、公允价值变动损益、自身信用风险变动（指定为FVTPL部分计入OCI）及试算平衡表。复核聚焦分类、公允价值计量、变动进损益/OCI的正确性及勾稽。

**法规依据：**
- 《企业会计准则第22号——金融工具确认和计量》
- 《企业会计准则第37号——金融工具列报》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **负债方向勾稽**：交易性金融负债为负债类科目，期末审定数=期初审定数+本期承担-本期偿还±公允价值变动，审定表须体现负债增减方向。
2. **公允价值变动进损益**：交易性（持有交易目的）金融负债公允价值变动全部计入当期损益（公允价值变动损益）。
3. **自身信用风险特例**：对指定为FVTPL的金融负债，因自身信用风险变化引起的公允价值变动计入其他综合收益（OCI），其余部分进损益，审定表须区分处理（G10-8/衍生除外）。
4. **期初期末承前启后**：期初审定数须等于上年期末审定数，任何差异须追溯。
5. **试算平衡表核对**：审定数合计须与试算平衡表2101科目审定数一致。
6. **调整完整性**：审定数=未审数+AJE+RJE，所有调整完整反映。

## checklist

### 一、分类与期初期末勾稽

- [ ] 交易性金融负债分类判断（交易目的/衍生/指定FVTPL）是否有底稿支持
- [ ] 期初审定数是否等于上年期末审定数（承前启后）
- [ ] 公允价值变动是否计入当期损益（交易性/衍生）
- [ ] 指定FVTPL负债的自身信用风险变动是否计入OCI
- [ ] 期末审定数是否等于期初审定数加本期增减

### 二、试算平衡表核对

- [ ] 审定数合计是否与试算平衡表2101科目审定数一致
- [ ] 未审数、调整数与审定表对应列是否一致
- [ ] 公允价值变动损益是否与利润表勾稽

### 三、审计调整完整性

- [ ] 所有账项调整（AJE）是否完整反映在审定表调整列
- [ ] 所有重分类调整（RJE）是否完整反映
- [ ] 调整分录借贷方是否平衡
- [ ] 审定后金额是否等于未审数+AJE+RJE
- [ ] 建议但未调整的错报是否记录于未调整错报汇总表

### 四、分类列报

- [ ] 衍生金融负债是否正确列示
- [ ] 一年以上的交易性金融负债列报是否合理
- [ ] 审定表分类是否与财务报表附注披露一致

## risk_areas

### 高风险

1. **公允价值变动方向错误**：将交易性金融负债公允价值变动错误计入OCI，或将指定FVTPL负债自身信用风险变动错误计入损益，扭曲利润。
2. **公允价值低估负债**：金融负债公允价值低估导致负债少计、损益虚增。
3. **分类判断错误**：应作为交易性金融负债却分类为其他金融负债（或反之），计量基础错误。
4. **期初期末不勾稽**：期初审定数与上年期末不一致。
5. **审计调整遗漏**：已确认调整未反映在审定表。

### 中风险

1. **明细与汇总不勾稽**：审定表各行合计与G10-2明细表总计不一致。
2. **自身信用风险未区分**：指定FVTPL负债未区分自身信用风险变动（进OCI）与其他变动（进损益）。
3. **审定表与附注口径不一致**：审定表分类与附注披露不一致。

### 低风险

1. **审定表格式不规范**：列标题、行顺序等格式问题。
2. **底稿交叉索引不完整**：未与明细表、公允价值测试建立索引。
3. **辅助说明不充分**：变动较大行项目未附说明。
