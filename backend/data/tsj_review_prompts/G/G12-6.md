# G12-6 净敞口套期收益凭证检查表复核提示词

## 概述

本提示词针对净敞口套期收益凭证检查表（G12-6）的复核，聚焦样本选取合理性、凭证核对完整性、检查比例达标性及异常交易标注充分性。凭证检查须覆盖套期工具合约、估值确认、套期指定文档及损益结转的完整证据链。

**法规依据：**
- 《中国注册会计师审计准则第1314号——审计抽样》
- 《企业会计准则第24号——套期会计》
- 《企业会计准则第22号——金融工具确认和计量》

---

## tips

1. **样本须覆盖各套期关系**：抽样应涵盖不同类型套期（公允价值/现金流量/净投资），大额及异常损益项目全覆盖（CAS1314）。
2. **核对完整证据链**：套期工具合约、套期正式指定文档、公允价值估值/对手方确认、有效性测试记录、损益结转分录须逐环核对。
3. **套期指定文档是核对重点**：每笔纳入套期会计的凭证须核对套期开始时的书面指定文件，无指定文档的须标注异常。
4. **无现金流损益须验证估值依据**：套期公允价值变动损益多不伴随现金流，须核对估值依据及对手方确认。
5. **检查比例应满足计划水平**：已检查套期损益金额÷套期损益总额须达到计划检查比例。
6. **异常交易标注须明确类型**：明确标注异常类型（无指定文档/估值无依据/有效性存疑/期末集中确认）及初步判断。

## checklist

### 一、样本选取

- [ ] 样本选取方法是否与识别的重大错报风险相匹配
- [ ] 各类型套期关系是否均纳入样本
- [ ] 大额套期损益（超重要性水平）是否100%全覆盖
- [ ] 期末集中确认、异常波动的损益是否纳入必选样本

### 二、凭证核对完整性

- [ ] 套期工具合约是否核对（名义金额/期限/条款）
- [ ] 套期正式指定文档是否齐全
- [ ] 公允价值估值/对手方确认是否核对
- [ ] 有效性测试记录及损益结转分录是否核对
- [ ] 核对中发现的差异是否逐一追踪解决

### 三、检查比例

- [ ] 已检查套期损益金额÷总额是否达到计划检查比例
- [ ] 不达标是否说明原因并评估是否补充样本
- [ ] 检查比例计算公式是否正确

### 四、异常交易标注

- [ ] 异常交易是否全部标注并记录异常类型
- [ ] 无指定文档的套期是否标注异常
- [ ] 期末集中确认的损益是否实施截止测试
- [ ] 异常标注是否含类型/描述/金额/初步判断

## risk_areas

### 高风险

1. **套期指定文档缺失**：纳入套期会计的凭证无书面指定文件，套期会计适用无依据。
2. **估值无依据**：套期工具公允价值凭证缺估值模型/对手方确认支持，损益失真。
3. **截止性错误**：期末集中确认的套期损益未实施截止测试。
4. **样本选取偏差**：抽样未覆盖高风险套期类型，样本不具代表性。

### 中风险

1. **检查比例不足**：实际检查比例低于计划水平，证据不充分。
2. **有效性证据不足**：套期损益凭证缺有效性测试记录支持。
3. **异常交易漏标注**：无指定文档或估值存疑的损益未被标注调查。

### 低风险

1. **抽样参数记录不完整**：抽样参数记录不全，影响可追溯性。
2. **核对结果格式不统一**：检查结果记录格式不规范。
3. **底稿索引缺失**：凭证检查底稿与审定表/套期明细交叉索引不完整。
