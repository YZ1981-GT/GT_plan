# G5-10 长期应收款减值准备测算复核提示词

## 概述

本提示词针对长期应收款减值准备测算表（G5-10）的复核，聚焦预期信用损失（ECL）的测算：单项计提、组合计提的划分，违约概率、违约损失率、违约风险敞口的确定，前瞻性信息运用，以及测算结果与审定表、坏账明细的勾稽。长期应收款减值涉及重大管理层判断，是减值审计的核心。

**法规依据：**
- 《企业会计准则第22号——金融工具确认和计量》
- 《企业会计准则第37号——金融工具列报》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **ECL基于三要素**：预期信用损失=违约概率（PD）×违约损失率（LGD）×违约风险敞口（EAD），各参数须有依据。
2. **单项计提须逐笔评估**：信用减值或重大的长期应收款须单项评估预计可收回金额（未来现金流现值）。
3. **组合损失率须有数据支撑**：组合损失率应基于历史损失经验并结合前瞻性调整。
4. **担保和抵押须考虑**：融资租赁应收款的租赁物、有担保的应收款LGD应反映担保回收价值。
5. **前瞻性信息须运用**：ECL测算须纳入前瞻性宏观信息对参数的调整。
6. **测算结果联动**：G5-10测算减值准备须与G5-1审定表、G5-2明细表减值、G5-3坏账明细勾稽。

## checklist

### 一、计量方法与要素

- [ ] ECL测算是否区分单项计提与组合计提
- [ ] 单项计提对象（重大/信用减值）是否恰当识别
- [ ] ECL是否基于PD/LGD/EAD三要素
- [ ] 单项减值是否按未来现金流现值评估可收回金额

### 二、参数合理性

- [ ] 组合损失率是否基于历史损失经验
- [ ] LGD是否考虑担保/租赁物/抵押回收价值
- [ ] 是否纳入前瞻性信息调整
- [ ] 参数是否与G5-9阶段划分一致

### 三、测算与勾稽

- [ ] 单项+组合计提减值准备合计是否正确
- [ ] G5-10测算结果是否与G5-3坏账明细勾稽
- [ ] 是否与G5-1审定表减值准备一致
- [ ] 本期计提净额是否与利润表信用减值损失勾稽

## risk_areas

### 高风险

1. **ECL计提不足**：PD/LGD参数人为压低，减值准备计提不足，虚增长期应收款净额。
2. **担保回收高估**：LGD高估担保/租赁物回收价值，减值不足。
3. **单项评估不充分**：信用减值的单项应收款未逐笔评估可收回金额。

### 中风险

1. **参数缺乏数据支撑**：组合损失率无历史数据基础，参数主观。
2. **前瞻性信息缺失或操纵**：未纳入前瞻性信息或操纵调整以调节减值。
3. **测算与坏账明细不勾稽**：G5-10与G5-3/G5-1不一致。

### 低风险

1. **测算底稿记录不充分**：ECL模型参数、数据来源记录简略。
2. **交叉索引不完整**：G5-10未与G5-1/G5-3/G5-9建立索引。
