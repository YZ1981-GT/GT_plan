# G10-note-soe 交易性金融负债附注披露 复核提示词（国有企业）

## 概述

本提示词针对交易性金融负债国有企业附注披露底稿（G10-note-soe）的复核，聚焦国有企业特定的附注披露要求：在FVTPL负债基础披露（分类/公允价值层次/第三层次调节/损益/衍生）之上，增加衍生金融工具/金融负债业务合规性、金融风险敞口对国有资本的影响、以及国资委财务决算报告补充要求。国有企业开展衍生金融工具等业务须符合国资委对金融衍生业务的严格监管（套期保值为主、禁止投机）。

**法规依据：**
- 《企业会计准则第37号——金融工具列报》
- 《企业会计准则第22号——金融工具确认和计量》
- 《企业国有资产法》
- 《中央企业财务决算报告管理办法》
- 《关于切实加强金融衍生业务管理有关事项的通知》（国资委）

---

## tips

1. **国企附注双层要求**：既满足CAS37/CAS39通用披露（分类/公允价值层次/第三层次调节/损益/衍生），又满足国资委财务决算报告的额外披露要求。
2. **衍生业务合规**：国资委要求中央企业金融衍生业务坚持套期保值原则、严禁投机，附注须披露衍生业务是否以套期保值为目的及合规性。
3. **业务审批**：开展金融衍生业务须经董事会/"三重一大"审批并报备，附注宜说明本期衍生业务的审批备案情况。
4. **风险敞口披露**：须披露衍生工具的名义金额、风险敞口及公允价值损失对国有资本的影响。
5. **第三层次防低估**：负债公允价值须客观估值，防止低估负债虚增损益、掩盖国有资产风险。
6. **决算勾稽**：附注数据须与年度财务决算报表一致，内部衍生交易抵销须完整。

## checklist

### 一、基础披露完整性（与上市版共有）

- [ ] 是否披露交易性金融负债构成及分类依据
- [ ] 公允价值是否按第一/二/三层次披露
- [ ] 第三层次公允价值调节表是否完整
- [ ] 本期计入损益的公允价值变动是否披露
- [ ] 指定FVTPL负债自身信用风险变动是否披露
- [ ] 附注期末余额是否与审定表审定数一致

### 二、衍生业务合规披露

- [ ] 衍生金融业务是否以套期保值为目的（非投机）
- [ ] 是否披露衍生业务的审批备案情况（董事会/三重一大）
- [ ] 是否符合国资委金融衍生业务监管要求
- [ ] 是否存在超授权或投机性衍生交易并予以说明

### 三、风险敞口与保值增值披露

- [ ] 衍生工具名义金额和风险敞口是否披露
- [ ] 公允价值损失对国有资本保值增值率的影响是否说明
- [ ] 是否披露风险管理制度和敞口限额执行情况
- [ ] 第三层次估值是否有客观独立依据（防低估负债）

### 四、决算披露

- [ ] 附注数据是否与年度财务决算报表一致
- [ ] 集团合并层面内部衍生交易抵销是否完整
- [ ] 与上市版相比是否增加了国资监管补充信息

## risk_areas

### 高风险

1. **投机性衍生交易未披露**：开展投机性（非套期保值）衍生业务违反国资委监管要求且未披露，存在合规及国有资产损失风险。
2. **衍生业务未经审批披露**：金融衍生业务未经董事会/"三重一大"审批备案或未披露。
3. **负债低估掩盖风险**：第三层次估值低估负债虚增损益，掩盖衍生业务风险敞口。
4. **附注与决算/审定表不勾稽**：附注数据与决算报表或审定表不一致。

### 中风险

1. **风险敞口披露不足**：衍生工具名义金额、风险敞口披露不完整。
2. **自身信用风险披露缺失**：指定FVTPL负债自身信用风险变动未披露。
3. **合规性说明不足**：未说明衍生业务套期保值目的及监管符合性。

### 低风险

1. **披露格式未按决算模板**：附注格式与国资委决算报表模板有细微差异。
2. **风险管理描述简略**：风险管理制度描述过于笼统。
3. **历史趋势追溯不完整**：衍生业务变动趋势分析覆盖年限不足。
