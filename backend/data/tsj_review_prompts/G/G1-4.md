# G1-4 交易性金融资产有价证券结存表复核提示词

## 概述

本提示词针对交易性金融资产有价证券结存表（G1-4）的复核，聚焦期初结存、本期增加（买入）、本期减少（卖出）、期末结存的数量与金额滚动核对，验证结存逻辑（期末=期初+增加−减少）的完整性以及与明细表、盘点表的一致性。

**法规依据：**
- 《企业会计准则第22号——金融工具确认和计量》
- 《企业会计准则第39号——公允价值计量》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **结存滚动逻辑是核心**：期末结存数量/金额=期初结存+本期增加−本期减少，任一环节错误均导致期末结存失真。
2. **数量与金额须双维度核对**：结存表应同时反映证券数量和金额，两者变动方向应逻辑一致。
3. **与盘点表勾稽**：期末结存数量须与G1-11有价证券盘点表实际盘点数量一致，差异需查明。
4. **买入卖出可追溯凭证**：本期增减金额须与G1-13凭证检查、券商对账单逐笔对应。
5. **成本结转方法一致**：卖出证券的成本结转方法（加权平均/个别计价）应前后一致，与会计政策相符。
6. **关注频繁交易证券**：本期买卖频繁的证券结存核对工作量大，须关注是否存在漏记或重复计。

---

## checklist

### 一、结存滚动核对

- [ ] 期初结存是否等于上年期末结存（数量+金额）
- [ ] 期末结存=期初+本期增加−本期减少，计算是否正确
- [ ] 各证券结存数量变动方向与金额变动是否逻辑一致
- [ ] 是否存在结存为负数的异常情况

### 二、增减明细核对

- [ ] 本期买入数量/金额是否与G1-13凭证检查勾稽
- [ ] 本期卖出数量/金额是否与处置凭证对应
- [ ] 卖出成本结转方法是否与会计政策一致
- [ ] 本期增减是否与G1-2明细表一致

### 三、期末结存核对

- [ ] 期末结存数量是否与G1-11盘点表实际盘点数一致
- [ ] 期末结存金额是否可勾稽至G1-1审定表/G1-2明细表
- [ ] 差异是否已查明并说明

## risk_areas

### 高风险

1. **结存滚动逻辑错误**：期末结存计算错误（期初+增−减不成立），导致期末余额失真。
2. **期末结存与盘点不符**：结存数量与G1-11盘点表不一致，可能存在虚构或漏记证券。
3. **卖出成本结转错误**：成本结转方法不一致或计算错误，影响处置损益准确性。

### 中风险

1. **增减明细不可追溯**：本期买卖金额未与凭证/对账单勾稽，交易真实性存疑。
2. **数量金额不匹配**：证券数量与金额变动逻辑矛盾，存在记录错误。

### 低风险

1. **结存表格式不规范**：列序、单位、编号不统一，影响复核效率。
2. **交叉索引不完整**：结存表未与G1-2/G1-11/G1-13建立索引。
