# G1-1 交易性金融资产审定表复核提示词

## 概述

本提示词针对交易性金融资产（科目1101）审定表（G1-1）的复核，聚焦以公允价值计量且其变动计入当期损益（FVTPL）金融资产的期初期末勾稽、公允价值计量准确性、公允价值变动损益核对与分类列报。审定表承载未审数→调整→审定数的完整链路，是交易性金融资产审计的枢纽底稿，任何勾稽断裂或公允价值计量错误均可能导致利润与资产重大错报。

**法规依据：**
- 《企业会计准则第22号——金融工具确认和计量》
- 《企业会计准则第37号——金融工具列报》
- 《企业会计准则第39号——公允价值计量》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **期初期末勾稽是审定表的生命线**：期初审定数必须等于上年期末审定数，任何差异需追溯至公允价值变动、买入卖出或调整分录，不得存在无源差异。
2. **公允价值是交易性金融资产审定的核心**：审定数应基于资产负债表日的公允价值（活跃市场报价或估值模型），而非成本或摊余成本，须核对至G1-6公允价值测试底稿。
3. **公允价值变动损益必须完整反映**：本期公允价值变动应全额计入当期损益（公允价值变动收益），审定数与G1-5投资收益测算表及利润表须勾稽一致。
4. **股利与利息收益单独确认**：持有期间取得的现金股利、债券利息应确认为投资收益，不并入公允价值变动，须与G1-5测算表核对。
5. **试算平衡表是勾稽的第一道防线**：审定表交易性金融资产审定数合计必须与试算平衡表1101科目审定数完全一致。
6. **FVTPL分类不得随意变更**：交易性金融资产一经指定不得重分类，审定表中的分类应与G1-8业务模式、G1-9分类测试结论一致。

## checklist

### 一、期初期末勾稽

- [ ] 审定表期初未审数是否等于上年审定表期末审定数
- [ ] 期末审定数是否等于期初审定数加本期购入减本期卖出加减公允价值变动
- [ ] 审定表各行项目期初期末变动是否与G1-2明细表增减一致
- [ ] 本期买入/卖出金额是否与G1-13凭证检查、G1-11盘点表勾稽
- [ ] 是否存在期初数据被人为修改但未留痕的情况

### 二、公允价值计量与试算平衡表核对

- [ ] 审定数是否基于资产负债表日公允价值计量（非成本/摊余成本）
- [ ] 审定表公允价值是否与G1-6公允价值测试底稿一致
- [ ] 交易性金融资产审定数合计是否与试算平衡表1101科目一致
- [ ] 第三层次公允价值是否与G1-7调节表勾稽
- [ ] 试算平衡表调整数（AJE+RJE）与审定表调整数是否一致

### 三、公允价值变动与收益核对

- [ ] 本期公允价值变动是否全额计入当期损益（公允价值变动收益）
- [ ] 审定表公允价值变动是否与G1-5投资收益测算表一致
- [ ] 持有期间股利/利息是否确认为投资收益且未并入公允价值变动
- [ ] 处置损益（卖出价与账面价差额）是否正确结转投资收益
- [ ] 公允价值变动损益是否与利润表相关项目勾稽

### 四、分类列报准确性

- [ ] 交易性金融资产分类是否与G1-8业务模式、G1-9分类测试结论一致
- [ ] 一年内到期的债券投资是否正确列示（是否需重分类）
- [ ] 审定表分类是否与财务报表附注披露分类一致
- [ ] 衍生金融资产是否单独列示（与G1-14衍生工具检查勾稽）
- [ ] 所有已确认的AJE/RJE是否完整反映在审定表调整列

## risk_areas

### 高风险

1. **公允价值计量错误**：以成本或过期报价代替资产负债表日公允价值，导致资产与公允价值变动损益虚增或虚减，构成重大错报。
2. **公允价值变动损益遗漏**：本期公允价值变动未全额计入当期损益，或与G1-5、利润表不勾稽，掩盖投资损益。
3. **期初期末不勾稽**：期初审定数与上年期末审定数不一致，存在未经授权调整或数据录入错误。
4. **第三层次公允价值缺乏依据**：无活跃市场报价的资产采用估值模型但关键参数不合理，且与G1-7调节表脱节。
5. **审计调整遗漏或缺乏审批**：已确认的调整分录未反映在审定表，或未经合伙人批准即纳入审定数。

### 中风险

1. **明细与汇总不勾稽**：审定表各行合计与G1-2明细表总计不一致，可能存在明细遗漏或重复。
2. **股利利息与公允价值变动混淆**：持有收益未从公允价值变动中分离，导致投资收益结构失真。
3. **分类结论不一致**：审定表分类与G1-8/G1-9测试结论矛盾，FVTPL分类依据不足。
4. **重分类调整方向错误**：RJE借贷方向颠倒导致审定数偏离真实值。

### 低风险

1. **审定表格式不规范**：列标题、行顺序、编号等格式问题不影响数据准确性，但影响可读性。
2. **底稿交叉索引不完整**：审定表未与G1-2/G1-5/G1-6及试算平衡表建立完整索引引用。
3. **辅助说明不充分**：公允价值变动较大的行项目未附简要说明，增加复核难度。
