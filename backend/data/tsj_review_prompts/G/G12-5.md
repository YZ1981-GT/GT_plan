# G12-5 净敞口检查表复核提示词

## 概述

本提示词针对净敞口检查表（G12-5）的复核。净敞口套期是对一组项目的净风险敞口进行套期，本表验证净敞口的识别、构成项目的归集、被套期净敞口与套期工具的匹配及损益在构成项目间的分摊，是净敞口套期会计的关键底稿。

**法规依据：**
- 《企业会计准则第24号——套期会计》
- 《企业会计准则第22号——金融工具确认和计量》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **净敞口的构成须完整归集**：净敞口是一组资产/负债或预期交易的净额，须核对构成项目的完整性（正敞口与负敞口）及净额计算的准确性。
2. **仅特定风险的净敞口可套期**：CAS24对净敞口套期有限定（现金流量套期的净头寸须为影响损益的预期交易，且仅外汇风险等），须核对被套期净敞口是否符合适用范围。
3. **损益分摊须合理**：净敞口套期的损益应在构成净敞口的各项目间按合理方法分摊列报，分摊方法须一致且有依据。
4. **净敞口须与套期工具匹配**：被套期净敞口的金额、期限、风险类型须与套期工具匹配，防止过度套期或套期不足。
5. **与套期明细勾稽**：净敞口检查数据须与G12-2套期明细、G12-4有效性测试勾稽。
6. **关注净敞口的动态变化**：净敞口构成项目在期间内变动的，须核对套期关系的持续有效性。

## checklist

### 一、净敞口识别与构成

- [ ] 净敞口构成项目（正/负敞口）是否完整归集
- [ ] 净额计算是否准确
- [ ] 被套期净敞口是否符合CAS24适用范围
- [ ] 净敞口风险类型是否明确（外汇/利率/价格）

### 二、匹配与损益分摊

- [ ] 被套期净敞口与套期工具在金额/期限/风险类型上是否匹配
- [ ] 是否存在过度套期或套期不足
- [ ] 净敞口套期损益是否在构成项目间合理分摊
- [ ] 分摊方法是否一致且有依据

### 三、勾稽与持续性

- [ ] 净敞口检查数据是否与G12-2套期明细勾稽
- [ ] 是否与G12-4有效性测试勾稽
- [ ] 净敞口构成项目变动是否评估套期持续有效性

### 四、列报

- [ ] 净敞口套期损益列报是否与审定表G12-1一致
- [ ] 分摊后各项目损益列报是否与附注一致

## risk_areas

### 高风险

1. **净敞口构成不完整**：正/负敞口归集遗漏导致净额错误，套期基础失真。
2. **被套期净敞口超适用范围**：对不符合CAS24适用条件的净敞口适用套期会计。
3. **损益分摊不合理**：净敞口套期损益在构成项目间分摊方法无依据或不一致，损益列报失真。
4. **净敞口与套期工具不匹配**：过度套期或套期不足导致无效部分被掩盖。

### 中风险

1. **净额计算错误**：正负敞口净额计算有误。
2. **持续有效性未评估**：净敞口构成变动时未评估套期关系持续有效性。
3. **勾稽断裂**：净敞口检查数据与套期明细/有效性测试不勾稽。

### 低风险

1. **构成项目粒度不足**：净敞口构成项目合并列示，不便追溯。
2. **分摊过程记录简略**：损益分摊计算过程记录不充分。
3. **底稿索引缺失**：净敞口检查底稿交叉索引不完整。
