# G2-6 应收利息长期未收回检查复核提示词

## 概述

本提示词针对应收利息长期未收回检查底稿（G2-6）的复核，聚焦长期未收回应收利息的识别、可收回性评估、坏账准备计提充分性及信用风险恶化信号的关注。长期未收回利息是信用风险和减值的重要信号，可收回性评估直接影响坏账准备计提。

**法规依据：**
- 《企业会计准则第22号——金融工具确认和计量》
- 《企业会计准则第37号——金融工具列报》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **长账龄是信用风险信号**：应收利息长期未收回（如超1年）通常意味着债务人偿付能力或意愿恶化，须评估信用风险阶段迁移。
2. **可收回性评估须有证据**：长期未收回利息的可收回性判断须基于债务人财务状况、还款计划、担保等客观证据。
3. **本金与利息联动评估**：应收利息可收回性应与对应本金（债权投资/借款）的信用状况联动评估。
4. **坏账准备计提充分性**：长期未收回利息应评估是否足额计提坏账准备，与G2-3/G2-7勾稽。
5. **催收措施须记录**：企业对长期未收回利息的催收措施和进展应记录，评估管理层判断合理性。
6. **关注利息资本化或展期**：将未收利息展期或资本化可能掩盖信用问题，须保持职业怀疑。

## checklist

### 一、长账龄识别

- [ ] 是否完整识别长期未收回（超账龄阈值）的应收利息
- [ ] 长账龄利息是否与G2-2明细表账龄分析一致
- [ ] 是否按债务人/账龄段汇总长期未收回利息

### 二、可收回性评估

- [ ] 可收回性判断是否有客观证据（债务人财务/还款计划/担保）
- [ ] 应收利息与对应本金信用状况是否联动评估
- [ ] 是否评估信用风险阶段迁移（三阶段）
- [ ] 是否存在利息展期/资本化掩盖信用问题

### 三、坏账与催收

- [ ] 长期未收回利息坏账准备是否足额计提
- [ ] 坏账评估是否与G2-3/G2-7勾稽
- [ ] 企业催收措施和进展是否记录
- [ ] 无法收回的利息是否评估核销

## risk_areas

### 高风险

1. **可收回性高估**：长期未收回利息可收回性评估无证据支撑，坏账准备计提不足，虚增资产。
2. **信用风险信号忽视**：长账龄未触发信用风险阶段迁移和减值评估。
3. **利息展期资本化掩盖问题**：通过展期或资本化掩盖债务人偿付困难。

### 中风险

1. **本金利息评估脱节**：应收利息可收回性未与本金信用状况联动。
2. **催收措施记录缺失**：长期未收回利息催收进展未记录，管理层判断无法评估。

### 低风险

1. **账龄划分不一致**：G2-6账龄划分与G2-2明细表不一致。
2. **交叉索引不完整**：G2-6未与G2-2/G2-3/G2-7建立索引。
