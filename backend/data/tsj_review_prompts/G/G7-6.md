# G7-6 长期股权投资会计政策核对 复核提示词

## 概述

本提示词针对长期股权投资会计政策核对表（G7-6）的复核。会计政策核对表核对投资方与被投资单位在收入确认、资产减值、折旧摊销、公允价值计量等会计政策上的一致性，权益法下确认投资损益前须将被投资单位会计政策调整为与投资方一致。复核聚焦政策差异识别完整性、差异调整的正确性、以及对权益法核算（G7-14）的影响。

**法规依据：**
- 《企业会计准则第2号——长期股权投资》
- 《企业会计准则第28号——会计政策、会计估计变更和差错更正》
- 《企业会计准则第33号——合并财务报表》

---

## tips

1. **权益法须政策一致**：确认投资损益前，被投资单位与投资方会计政策/会计期间不一致的须调整为一致，这是CAS2的明确要求。
2. **重点差异领域**：收入确认时点、固定资产折旧年限/方法、无形资产摊销、资产减值政策、公允价值计量方法是常见差异领域。
3. **差异须量化**：识别政策差异后须量化对被投资单位净损益/净资产的影响，作为权益法调整依据。
4. **只调不一致**：政策一致的项目无需调整，仅对确有差异的项目量化调整，避免过度调整。
5. **零金额跳过**：差异金额为零的政策项目不产生调整分录，防止污染权益法计算。
6. **联动G7-14**：政策差异调整须传递至G7-14权益法核算，影响确认的投资收益金额。

## checklist

### 一、政策差异识别

- [ ] 是否核对收入确认政策一致性
- [ ] 是否核对固定资产折旧年限/方法一致性
- [ ] 是否核对无形资产摊销政策一致性
- [ ] 是否核对资产减值政策一致性
- [ ] 是否核对公允价值计量方法一致性
- [ ] 会计期间不一致的是否已识别

### 二、差异调整正确性

- [ ] 识别的政策差异是否量化对净损益/净资产的影响
- [ ] 仅对确有差异的项目调整，一致项目未调整
- [ ] 差异金额为零的项目是否未产生调整
- [ ] 调整方向是否正确（调整为投资方政策）

### 三、联动与勾稽

- [ ] 政策差异调整是否传递至G7-14权益法核算
- [ ] 调整后被投资单位净损益是否用于确认投资收益
- [ ] 是否有政策差异说明文档支持

## risk_areas

### 高风险

1. **政策差异未调整**：被投资单位与投资方政策不一致却未调整即确认损益，违反CAS2，投资收益失真。
2. **差异量化错误**：政策差异对净损益影响量化错误，导致权益法调整金额错误。
3. **调整传递断裂**：政策差异调整未传递至G7-14，权益法核算基础错误。

### 中风险

1. **差异识别不完整**：仅核对部分政策领域，遗漏重要差异（如减值政策）。
2. **过度调整**：对政策一致项目也做调整，产生不必要偏差。
3. **会计期间差异未处理**：被投资单位期间与投资方不一致未调整。

### 低风险

1. **政策差异说明不充分**：识别差异但未详细说明差异内容和调整依据。
2. **索引引用缺失**：未与被投资单位会计政策、权益法计算建立索引。
3. **格式不规范**：核对表字段不统一。
