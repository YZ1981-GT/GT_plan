# G7-note-soe 长期股权投资附注披露 复核提示词（国有企业）

## 概述

本提示词针对长期股权投资国有企业附注披露底稿（G7-note-soe）的复核，聚焦国有企业特定的附注披露要求：在权益法/成本法基础披露之上，增加对外投资合规性（"三重一大"决策）、国有股权处置监管、投资对国有资本保值增值的影响、以及国资委财务决算报告的补充要求。国有企业股权投资须同时满足会计准则和国资监管要求。

**法规依据：**
- 《企业会计准则第2号——长期股权投资》
- 《企业会计准则第33号——合并财务报表》
- 《企业会计准则第36号——关联方披露》
- 《企业国有资产法》
- 《中央企业财务决算报告管理办法》

---

## tips

1. **国企附注双层要求**：既满足CAS通用披露（分类/权益法变动/减值/处置），又满足国资委财务决算报告的额外披露要求。
2. **对外投资合规**：重大对外投资须经"三重一大"决策，附注宜说明本期重大投资/处置的决策审批情况。
3. **国有股权处置监管**：国有股权处置须履行进场交易/评估备案等程序，附注须披露处置合规性及评估情况。
4. **保值增值视角**：长期股权投资减值、被投资单位持续亏损可能被视为国有资产减值风险，须说明成因及应对。
5. **同受国有控制关联方**：合营/联营企业及同受国有控制的其他企业须纳入关联方披露（可按豁免条款简化）。
6. **决算勾稽**：附注数据须与年度财务决算报表一致，集团内部投资抵销须完整。

## checklist

### 一、基础披露完整性（与上市版共有）

- [ ] 是否区分子公司/合营/联营分类披露
- [ ] 权益法投资变动表是否完整
- [ ] 减值准备计提及期末余额是否披露
- [ ] 重大处置损益是否披露
- [ ] 附注期末余额是否与审定表审定数一致
- [ ] 期初/期末可比信息是否完整

### 二、对外投资合规披露

- [ ] 本期重大对外投资是否经"三重一大"集体决策
- [ ] 投资是否符合国资委关于非主业投资/金融投资监管要求
- [ ] 是否披露投资对手方是否为关联方及交易公允性
- [ ] 是否存在超授权额度投资并予以说明

### 三、国有股权处置监管

- [ ] 国有股权处置是否履行进场交易/评估备案程序
- [ ] 处置价款与评估价值是否匹配（防国有资产流失）
- [ ] 处置是否经"三重一大"决策
- [ ] 处置损益是否纳入国有资本经营业绩

### 四、保值增值与决算披露

- [ ] 长期股权投资减值对国有资本保值增值率的影响是否说明
- [ ] 被投资单位持续亏损的处置/退出计划是否披露
- [ ] 附注数据是否与年度财务决算报表一致
- [ ] 集团合并层面内部投资抵销是否完整
- [ ] 同受国有控制关联方是否纳入披露范围

## risk_areas

### 高风险

1. **重大投资/处置未经决策程序披露**：大额对外投资或国有股权处置未经"三重一大"或未披露决策/评估过程，存在合规及国有资产流失风险。
2. **股权处置低价流失**：处置价款低于评估价值且未说明，可能造成国有资产流失。
3. **减值成因未披露**：大额减值或被投资单位持续亏损未说明成因和应对措施。
4. **附注与决算/审定表不勾稽**：附注数据与决算报表或审定表不一致。

### 中风险

1. **非主业投资合规披露缺失**：股权投资是否符合国资委非主业监管要求未说明。
2. **关联方范围遗漏**：同受国有控制的企业未纳入关联方披露。
3. **权益法变动/减值披露不完整**：基础披露维度缺失。

### 低风险

1. **披露格式未按决算模板**：附注格式与国资委决算报表模板有细微差异。
2. **保值增值影响分析简略**：仅提及影响未量化分析。
3. **历史趋势追溯不完整**：投资变动趋势分析覆盖年限不足。
