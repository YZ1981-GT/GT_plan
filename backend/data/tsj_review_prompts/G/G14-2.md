# G14-2 信用减值损失明细表复核提示词

## 概述

本提示词针对信用减值损失明细表（G14-2）的复核。该表按金融资产类别分项列示本期信用减值损失的计提/转回、ECL阶段及计提基础，是审定表（G14-1）的支撑底稿。复核聚焦分项计提的ECL模型依据、三阶段迁徙、与各金融资产减值准备的勾稽及本期计提转回的合理性。

**法规依据：**
- 《企业会计准则第22号——金融工具确认和计量》
- 《企业会计准则第37号——金融工具列报》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **按金融资产类别分项列示**：明细表须按应收账款、其他应收款、债权投资、其他债权投资等类别分项列示本期计提/转回及ECL阶段。
2. **本期计提=期末减值准备−期初减值准备+本期核销−本期收回**：核对本期计提逻辑，防止将核销/收回混入计提净额。
3. **三阶段迁徙须逐类核对**：各类金融资产在ECL三阶段间的迁徙须有信用风险变化依据，迁徙导致计提基础从12个月ECL变为存续期ECL须体现。
4. **各类计提须与对应减值准备底稿勾稽**：应收账款减值与D2坏账准备、其他应收款减值与K1、债权投资减值与对应底稿逐类勾稽。
5. **分项合计回勾审定表**：明细各分项计提/转回合计必须等于G14-1审定表信用减值损失合计。
6. **关注计提率异常**：某类金融资产的减值计提率较上期或行业水平异常偏低/偏高的，须分析ECL参数合理性。

## checklist

### 一、分项列示与计算

- [ ] 各金融资产类别是否分项列示本期计提/转回
- [ ] 本期计提逻辑是否正确（剔除核销/收回影响）
- [ ] 明细各分项计提/转回合计是否等于G14-1审定表合计
- [ ] 是否覆盖所有需计提ECL的金融资产类别

### 二、ECL模型与阶段

- [ ] 各类金融资产ECL阶段划分是否列示
- [ ] 三阶段迁徙是否有信用风险变化依据
- [ ] 计提基础（12个月/存续期ECL）是否与阶段对应
- [ ] ECL参数（违约概率/损失率/前瞻性）是否合理

### 三、勾稽验证

- [ ] 应收账款减值是否与D2坏账准备底稿勾稽
- [ ] 其他应收款减值是否与K1底稿勾稽
- [ ] 债权投资/其他债权投资减值是否与对应底稿勾稽

### 四、变动分析

- [ ] 各类减值计提率较上期是否列示
- [ ] 计提率异常的类别是否有合理性分析
- [ ] 本期转回是否有客观依据

## risk_areas

### 高风险

1. **ECL参数不合理少提减值**：违约概率/损失率低估或前瞻性调整缺失导致减值计提不足。
2. **三阶段迁徙滞后**：信用风险显著增加的资产未及时迁徙至更高阶段，计提基础错误。
3. **分项合计与审定表不勾稽**：明细各分项计提合计与G14-1审定表存在无源差异。
4. **与减值准备底稿不勾稽**：某类金融资产减值与对应减值准备底稿（D2/K1等）无法勾稽。

### 中风险

1. **计提率异常未分析**：某类金融资产减值计提率异常但缺合理性分析。
2. **转回缺乏依据**：本期转回信用减值无客观证据支持。
3. **计提逻辑错误**：将核销/收回混入本期计提净额。

### 低风险

1. **明细粒度不足**：多类金融资产合并列示，不便逐类追溯。
2. **交叉索引缺失**：明细分项未标注对应减值准备底稿索引。
3. **可比信息不完整**：仅列本期分项计提，缺上期可比数据。
