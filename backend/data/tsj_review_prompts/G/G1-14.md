# G1-14 交易性金融资产衍生工具检查表复核提示词

## 概述

本提示词针对交易性金融资产衍生工具检查表（G1-14）的复核，聚焦衍生金融工具（远期、期货、期权、互换等）的确认、公允价值计量、套期关系认定与列报。衍生工具默认以公允价值计量且变动计入当期损益（除指定为套期工具外），杠杆性强、波动大，是高风险审计领域。

**法规依据：**
- 《企业会计准则第22号——金融工具确认和计量》
- 《企业会计准则第24号——套期会计》
- 《企业会计准则第39号——公允价值计量》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **衍生工具默认FVTPL**：除指定为有效套期工具外，衍生工具应以公允价值计量且变动计入当期损益，须核对分类。
2. **完整性是衍生工具首要风险**：衍生工具可能表外或未入账，须通过合同、银行询证、董事会决议等排查是否存在未记录衍生工具。
3. **公允价值计量须专业估值**：期权、互换等复杂衍生品公允价值需估值模型（如B-S模型），须评估模型和参数合理性。
4. **套期会计须满足严格条件**：如适用套期会计，须核对套期关系正式指定、套期有效性测试文档（CAS24）。
5. **嵌入衍生工具须识别**：混合合同中的嵌入衍生工具须评估是否需分拆，避免遗漏。
6. **衍生工具名义金额与公允价值区分**：披露应区分名义金额（合约规模）与公允价值（资产/负债），避免混淆。

## checklist

### 一、完整性与确认

- [ ] 是否通过合同/银行询证/决议排查全部衍生工具
- [ ] 是否存在表外或未入账的衍生工具
- [ ] 衍生工具是否在合同订立日确认
- [ ] 混合合同中的嵌入衍生工具是否识别并评估分拆

### 二、公允价值计量

- [ ] 衍生工具是否以资产负债表日公允价值计量
- [ ] 复杂衍生品估值模型（B-S/蒙特卡洛等）是否适当
- [ ] 估值关键参数（波动率/无风险利率/期限）是否合理
- [ ] 公允价值变动是否计入当期损益（非套期情形）

### 三、套期会计与列报

- [ ] 如适用套期会计，套期关系是否正式指定并文档化
- [ ] 套期有效性测试是否执行并符合CAS24
- [ ] 衍生金融资产/负债是否分别列示（未不当抵销）
- [ ] 名义金额与公允价值是否区分披露

## risk_areas

### 高风险

1. **衍生工具遗漏未入账**：存在表外衍生工具未确认，导致资产负债和损益重大错报。
2. **公允价值估值不当**：复杂衍生品估值模型或参数不合理，公允价值失真。
3. **套期会计滥用**：不满足套期条件却适用套期会计，将损益递延或平滑，规避波动。
4. **嵌入衍生工具未分拆**：应分拆的嵌入衍生工具未识别，混合合同计量错误。

### 中风险

1. **公允价值变动损益处理错误**：非套期衍生工具的公允价值变动未全额计入当期损益。
2. **套期有效性文档不足**：套期关系指定或有效性测试文档不完整。
3. **名义金额与公允价值混淆**：披露未区分合约名义金额与公允价值。

### 低风险

1. **衍生工具台账不完整**：衍生工具明细台账记录不规范。
2. **交叉索引不完整**：G1-14未与G1-1审定表、附注衍生工具披露建立索引。
3. **列报格式瑕疵**：衍生金融资产/负债列报格式不完全规范。
