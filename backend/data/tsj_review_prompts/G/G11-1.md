# G11-1 投资收益审定表复核提示词

## 概述

本提示词针对投资收益审定表（G11-1）的复核。投资收益（科目6111）为损益类科目，取本期发生额，涵盖处置投资损益、权益法确认的投资收益、股利与利息收益等。审定表须完整反映未审数→AJE/RJE调整→审定数链路，并与各投资科目（交易性金融资产、债权投资、长期股权投资、其他权益工具投资）及利润表勾稽。

**法规依据：**
- 《企业会计准则第22号——金融工具确认和计量》
- 《企业会计准则第2号——长期股权投资》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **损益类取发生额而非余额**：投资收益审定数应基于本期发生额（贷方为收益、借方为损失），复核时须核对本期发生额而非期末余额，避免与资产负债类科目口径混淆。
2. **权益法与成本法收益来源须区分**：权益法确认的投资收益应与被投资单位净利润×持股比例勾稽（追溯G7长期股权投资底稿），成本法下仅在被投资方宣告分红时确认股利收益，两者确认时点和金额依据不同。
3. **处置损益须验证计价基础**：处置投资形成的损益=处置价款−处置日账面价值（含累计公允价值变动结转），须核对处置协议、成交价与账面终止确认金额，防止损益虚增或递延。
4. **审定数须与利润表投资收益勾稽**：审定表投资收益合计必须与利润表"投资收益"行项目一致，差异应追溯至调整分录或分类错误。
5. **关注其他综合收益重分类转入**：处置以公允价值计量且其变动计入其他综合收益的金融资产/权益工具时，须关注原计入OCI的累计利得是否恰当结转（部分工具不得转入损益），错误结转直接影响投资收益。
6. **审定表是投资循环的枢纽底稿**：应与G11-2明细分析、G11-3调整分录、各投资科目审定表形成闭环勾稽，任一节点断裂均为复核重点。

## checklist

### 一、发生额与勾稽核对

- [ ] 投资收益审定数是否基于本期发生额（区分收益/损失方向）
- [ ] 审定表投资收益合计是否与利润表投资收益行项目一致
- [ ] 未审数是否与试算平衡表6111科目发生额一致
- [ ] 各投资收益明细项目合计是否等于审定表合计
- [ ] 是否与G11-2明细分析表的分项收益合计勾稽

### 二、收益构成合理性

- [ ] 权益法确认的投资收益是否与被投资单位净利润×持股比例勾稽（追溯G7）
- [ ] 成本法下股利收益是否以被投资方宣告分红为确认依据
- [ ] 处置投资损益是否=处置价款−处置日账面价值
- [ ] 金融资产利息收益是否按实际利率法计算并与债权投资底稿勾稽
- [ ] 处置时原计入OCI的累计利得/损失结转是否符合准则规定

### 三、审计调整完整性

- [ ] 所有已确认的账项调整（AJE）是否完整反映在审定表调整列
- [ ] 所有重分类调整（RJE）是否完整反映在重分类列
- [ ] 调整分录借贷方是否平衡，审定数=未审数+AJE+RJE
- [ ] 建议但未调整的错报是否已记录于未调整错报汇总（SUD）

### 四、分类列报准确性

- [ ] 投资收益与公允价值变动损益、资产处置收益的划分是否正确
- [ ] 各投资收益明细是否按来源正确归类（处置/权益法/股利/利息）
- [ ] 审定表分类是否与财务报表附注披露分类一致

## risk_areas

### 高风险

1. **虚构投资收益**：无真实交易或被投资方经营支持的投资收益入账，虚增利润，须核对分红决议、被投资方财报及资金流水。
2. **权益法收益与被投资方业绩不勾稽**：确认的投资收益与被投资单位净利润×持股比例存在无源差异，可能存在多计或漏计。
3. **处置损益计价错误**：处置日账面价值未含累计公允价值变动结转，或以协议价外的价格入账，导致处置损益失真。
4. **OCI累计利得违规转入损益**：不得转入损益的权益工具在处置时将OCI累计利得转入投资收益，构成损益操纵。
5. **审定数与利润表不一致**：审定表投资收益合计与利润表投资收益行项目存在差异，属重大勾稽错误。

### 中风险

1. **收益确认时点不当**：跨期确认股利收益或权益法收益，将下期收益提前或本期收益递延。
2. **明细与汇总不勾稽**：审定表合计与G11-2明细分析表分项收益合计不一致。
3. **审定表与附注口径不一致**：投资收益分类与财务报表附注披露分类不一致。
4. **重分类调整方向错误**：RJE借贷方向颠倒导致审定数偏离真实值。

### 低风险

1. **审定表格式不规范**：列标题、行顺序等格式问题不影响数据准确性但影响复核效率。
2. **交叉索引不完整**：审定表未与G11-2、G11-3及各投资科目底稿建立完整索引。
3. **变动说明不充分**：投资收益重大变动的行项目未附简要说明。
