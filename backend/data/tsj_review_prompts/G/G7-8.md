# G7-8 长期股权投资同一控制下合并初始计量 复核提示词

## 概述

本提示词针对同一控制下企业合并形成的长期股权投资初始计量表（G7-8）的复核。同一控制下合并中，合并方以被合并方所有者权益账面价值份额作为初始投资成本，差额调整资本公积（不足冲留存收益），不确认商誉。复核聚焦初始成本计量基础（账面价值份额）、差额调整方向、合并日确定的合理性、以及分步取得的累计处理。

**法规依据：**
- 《企业会计准则第20号——企业合并》
- 《企业会计准则第2号——长期股权投资》
- 《企业会计准则第33号——合并财务报表》

---

## tips

1. **账面价值份额计量**：同一控制下合并，初始投资成本=被合并方所有者权益（合并日在最终控制方合并报表中的）账面价值×持股比例，非公允价值。
2. **不确认商誉**：同一控制下合并不产生商誉，支付对价与账面价值份额的差额调整资本公积（资本公积不足冲减留存收益）。
3. **合并日判断**：合并日是合并方实际取得对被合并方控制权的日期，须有依据。
4. **对价与差额**：支付对价（现金/非现金资产/发行权益）的公允价值与初始成本的差额调整所有者权益，不进损益。
5. **分步取得累计**：多次交易分步取得同一控制下合并的，须累计各次交易并按最终控制方角度计量。
6. **联动审定表**：初始成本须传递至G7-1审定表和G7-2明细表，作为账面价值起点。

## checklist

### 一、初始成本计量

- [ ] 初始投资成本是否以被合并方所有者权益账面价值份额计量
- [ ] 账面价值是否为合并日在最终控制方合并报表中的金额
- [ ] 持股比例是否准确
- [ ] 是否未确认商誉（同一控制下不产生商誉）

### 二、差额调整

- [ ] 支付对价公允价值与初始成本的差额是否调整资本公积
- [ ] 资本公积不足时是否冲减留存收益
- [ ] 差额调整是否未进损益
- [ ] 合并相关直接费用是否正确处理（计入当期损益）

### 三、合并日与分步取得

- [ ] 合并日确定是否有依据（取得控制权日期）
- [ ] 分步取得的是否累计各次交易
- [ ] 初始成本是否传递至审定表/明细表
- [ ] 是否有出资协议、评估报告等证据支持

## risk_areas

### 高风险

1. **以公允价值计量初始成本**：同一控制下合并错误按公允价值（而非账面价值份额）计量初始成本，投资成本失真。
2. **错误确认商誉**：同一控制下合并错误确认商誉，虚增资产。
3. **差额计入损益**：支付对价与初始成本差额错误计入损益而非资本公积，扭曲利润。

### 中风险

1. **合并日判断错误**：合并日确定错误导致账面价值份额计量时点错误。
2. **分步取得累计遗漏**：多次交易未累计处理。
3. **直接费用处理错误**：合并直接费用错误计入投资成本。

### 低风险

1. **计量依据文档不充分**：账面价值份额来源未充分记录。
2. **索引引用缺失**：未与出资协议、被合并方财报建立索引。
3. **格式不规范**：计量表字段不统一。
