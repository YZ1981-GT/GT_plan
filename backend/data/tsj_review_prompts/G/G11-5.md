# G11-5 投资收益凭证检查表复核提示词

## 概述

本提示词针对投资收益凭证检查表（G11-5）的复核，聚焦样本选取合理性、凭证核对完整性、检查比例达标性及异常交易标注充分性。投资收益凭证检查须覆盖处置交易、分红收取、权益法确认及利息收取的完整证据链。

**法规依据：**
- 《中国注册会计师审计准则第1314号——审计抽样》
- 《企业会计准则第22号——金融工具确认和计量》
- 《企业会计准则第2号——长期股权投资》

---

## tips

1. **样本须覆盖各类收益来源**：抽样应涵盖处置损益、权益法收益、股利收益、利息收益各类型，大额及异常收益项目全覆盖（CAS1314）。
2. **核对完整证据链**：处置收益核对处置协议/成交价/资金到账/终止确认计算；股利收益核对分红决议/到账凭证；权益法收益核对被投资方审定财报及持股比例。
3. **权益法确认无现金流须特别验证**：权益法收益不伴随现金流入，须核对被投资方财报及持股计算，防止无依据虚增。
4. **检查比例应满足计划水平**：已检查投资收益金额÷投资收益总额须达到计划检查比例，不达标须说明并补充样本。
5. **关注期末集中确认的收益**：期末突增或临近资产负债表日集中确认的投资收益凭证须重点核查截止性。
6. **异常交易标注须明确类型**：明确标注异常类型（金额异常/时间异常/无现金流支持/被投资方业绩不匹配）及初步判断。

## checklist

### 一、样本选取

- [ ] 样本选取方法是否与识别的重大错报风险相匹配
- [ ] 各类收益来源（处置/权益法/股利/利息）是否均纳入样本
- [ ] 大额投资收益（超重要性水平）是否100%全覆盖
- [ ] 期末集中确认、异常波动的收益是否纳入必选样本

### 二、凭证核对完整性

- [ ] 处置收益是否核对处置协议/成交价/资金到账/终止确认计算
- [ ] 股利收益是否核对分红决议及到账凭证
- [ ] 权益法收益是否核对被投资方审定财报及持股比例
- [ ] 利息收益是否核对实际利率法计算及到账
- [ ] 核对中发现的差异是否逐一追踪解决

### 三、检查比例

- [ ] 已检查投资收益金额÷总额是否达到计划检查比例
- [ ] 不达标是否说明原因并评估是否补充样本
- [ ] 检查比例计算公式是否正确（分子=已检查金额，分母=总体金额）

### 四、异常交易标注

- [ ] 异常交易是否全部标注并记录异常类型
- [ ] 无现金流支持的收益（如权益法）是否已核实业绩依据
- [ ] 期末集中确认的收益是否实施截止测试
- [ ] 异常标注是否含类型/描述/金额/初步判断

## risk_areas

### 高风险

1. **虚构收益凭证**：伪造处置协议或分红决议掩盖虚增投资收益，须交叉核对资金流水与被投资方业绩。
2. **权益法收益无依据**：权益法收益凭证缺被投资方审定财报支持，或持股比例计算错误。
3. **截止性错误**：期末集中确认的投资收益未实施截止测试，跨期收益未被识别。
4. **样本选取偏差**：抽样未覆盖高风险收益类型，样本不具代表性，遗漏重大错报领域。

### 中风险

1. **检查比例不足**：实际检查比例低于计划水平，审计证据不充分。
2. **核对深度不够**：仅核对金额一致性而忽略交易实质（协议条款/被投资方业绩匹配）。
3. **异常交易漏标注**：金额异常或无现金流支持的收益未被标注和调查。

### 低风险

1. **抽样参数记录不完整**：总体/置信水平/可容忍偏差等参数记录不全，影响可追溯性。
2. **核对结果格式不统一**：检查结果记录格式不规范，影响汇总效率。
3. **底稿索引缺失**：凭证检查底稿与审定表/明细分析表交叉索引不完整。
