# G3-3 应收股利调整分录复核提示词

## 适用底稿
应收股利调整分录汇总表（G3-3），含账项调整（AJE）、重分类调整（RJE）及未调整错报（SUD）评估。

## 概述
G3-3 是审定数链路的关键环节。复核须验证：每笔调整有证据、借贷平衡、完整反映到 G3-1 审定表、股利确认调整与投资收益/投资科目匹配、SUD 评估符合重要性水平要求。

---

## tips

1. **AJE vs RJE**：AJE 影响投资收益或资产金额；RJE 仅影响列报（如一年内到期），不得通过 RJE 掩盖损益错报。
2. **股利确认调整须双向匹配**：调整应收股利时对应的投资收益（成本法）或投资账面价值（权益法）须同步调整。
3. **提前确认更正是常见调整**：将未宣告即确认的股利冲回是常见调整，须核对宣告时点。
4. **与 G3-1 勾稽**：审定表调整列金额须与 G3-3 已确认分录逐笔一致。
5. **SUD 累计**：未调整错报单独及累计是否超阈值，与 A13 未调整错报汇总交叉验证。
6. **TB 回写**：确认调整已同步试算平衡表，避免双真源。

## checklist

### 高风险检查项

- [ ] 所有 AJE 是否有充分审计证据（分红决议核对、可收回性评估等）
- [ ] 调整分录借贷方是否完全平衡且损益/投资对应
- [ ] AJE 是否经适当层级审批
- [ ] 调整金额是否完整反映到 G3-1 审定表对应调整列
- [ ] 提前确认未宣告股利是否已冲回调整
- [ ] 是否存在仅为美化投资收益的不当调整
- [ ] 未调整错报累计是否超过整体重要性水平（须评估）

### 中风险检查项

- [ ] RJE 是否仅涉及列报，未影响损益类科目
- [ ] 权益法调整是否正确冲减投资账面价值
- [ ] 调整原因说明是否清晰可追溯至具体审计程序（G3-4）
- [ ] 与 A13 未调整错报汇总表索引是否完整
- [ ] 调整分录编号是否连续，删除后重号风险可控

### 低风险检查项

- [ ] 分录摘要、科目编码规范
- [ ] 索引指向 G3-4 测算检查等支持底稿
- [ ] 审计说明/结论是否概括调整性质与剩余风险

## risk_areas

### 高风险

1. **调整缺乏证据或未经授权**：股利调整无分红决议核对支持或未经合伙人审批。
2. **确认时点调整不匹配**：冲回提前确认股利时投资收益/投资科目未同步调整。
3. **审定表与调整金额不一致**：G3-1审定表调整列与G3-3已确认分录不符。

### 中风险

1. **权益法调整错误**：调整应收股利未正确冲减长期股权投资账面价值。
2. **SUD 累计超阈值未处理**：未调整错报累计超重要性水平未恰当处理。

### 低风险

1. **编号格式不规范**：分录编号、摘要、科目编码不规范。
2. **索引不完整**：调整分录未指向支持底稿。

## 跨底稿勾稽

- G3-3 已确认 AJE/RJE 合计 ↔ G3-1 审定表调整列
- G3-3 股利调整 ↔ G3-4 测算检查差异
- G3-3 SUD ↔ A13 未调整错报汇总
- 调整后审定数 ↔ 试算平衡表对应科目
