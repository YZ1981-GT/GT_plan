# G11-note-listed 投资收益附注披露复核提示词（上市公司）

## 概述

本提示词针对投资收益上市公司附注披露底稿（G11-note-listed）的复核，聚焦投资收益按来源分类披露的充分性、与利润表勾稽、权益法收益单独列示、处置损益披露及证监会编报规则对上市公司投资收益披露的额外要求。

**法规依据：**
- 《企业会计准则第22号——金融工具确认和计量》
- 《企业会计准则第2号——长期股权投资》
- 《企业会计准则第30号——财务报表列报》
- 《公开发行证券的公司信息披露编报规则第15号——财务报告的一般规定》

---

## tips

1. **投资收益须按来源分类披露**：附注须区分权益法核算的长期股权投资收益、成本法核算的股利收益、处置各类金融资产/长期股权投资取得的投资收益、以摊余成本计量金融资产的利息收益等，各分项合计须等于利润表投资收益。
2. **权益法收益应逐户列示**：重要联营/合营企业的权益法投资收益应单独披露被投资单位名称及金额，便于报表使用者评估收益来源可靠性。
3. **处置损益须披露构成**：处置长期股权投资/金融资产产生的投资收益应披露处置价款、账面价值及损益构成，重大处置事项须单独说明。
4. **与利润表及现金流量表勾稽**：附注投资收益合计=利润表投资收益；收到的分红/利息现金流应与现金流量表"取得投资收益收到的现金"勾稽。
5. **披露与会计政策一致**：各类投资收益的确认方法须与会计政策披露一致（权益法/公允价值/摊余成本），确认时点须清晰。
6. **附注须与审定表形成闭环勾稽**：附注投资收益各分项合计必须等于G11-1审定表审定数，权益法分项须与G7长期股权投资附注勾稽。

## checklist

### 一、分类披露

- [ ] 投资收益是否按来源分类披露（权益法/股利/处置损益/利息）
- [ ] 各分项合计是否等于利润表投资收益
- [ ] 各分项是否同时披露本期数和上期可比数
- [ ] 分类方法是否与会计政策一致

### 二、权益法与处置披露

- [ ] 重要联营/合营企业权益法收益是否逐户披露名称及金额
- [ ] 权益法分项是否与G7长期股权投资附注勾稽
- [ ] 处置损益是否披露处置价款、账面价值及损益构成
- [ ] 重大处置事项是否单独说明

### 三、勾稽核对

- [ ] 附注投资收益合计是否等于G11-1审定表审定数
- [ ] 分红/利息现金流是否与现金流量表相关行项目勾稽
- [ ] 附注投资收益与利润表是否一致

### 四、上市公司额外要求

- [ ] 是否披露对当期损益有重大影响的投资收益事项
- [ ] 是否披露关联方相关的投资收益
- [ ] 收益确认涉及重大判断的是否有充分说明

## risk_areas

### 高风险

1. **附注与利润表不勾稽**：附注投资收益各分项合计与利润表投资收益不一致，属重大披露错误。
2. **权益法收益来源披露缺失**：重要联营/合营企业收益未逐户披露，报表使用者无法评估收益可靠性。
3. **处置损益构成不披露**：重大处置事项仅披露净额，未披露处置价款与账面价值，掩盖损益来源。
4. **附注与审定表不一致**：披露投资收益与G11-1审定数存在差异。

### 中风险

1. **可比信息缺失**：仅披露本期投资收益，未列示上期可比数。
2. **现金流勾稽断裂**：分红/利息现金流与现金流量表相关行项目不勾稽。
3. **分类维度不完整**：未按来源多维度披露，仅列投资收益总额。

### 低风险

1. **披露格式不规范**：表格列序、金额单位等格式细节未严格按编报规则。
2. **文字说明模板化**：确认方法说明照搬会计政策原文，未结合实际。
3. **重大事项说明简略**：重大处置或收益事项仅提及未展开。
