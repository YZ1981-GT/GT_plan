# G10-4 交易性金融负债分类检查 复核提示词

## 概述

本提示词针对交易性金融负债分类检查表（G10-4）的复核。金融负债分类为以公允价值计量且其变动计入当期损益（FVTPL）须满足：属于交易性金融负债（以近期回购为目的/属于集中管理组合/衍生工具），或初始确认时被指定为FVTPL（满足指定条件）。复核聚焦分类条件成立性、交易性判断、指定条件评估、以及分类是否恰当（防止规避损益波动或美化负债）。

**法规依据：**
- 《企业会计准则第22号——金融工具确认和计量》
- 《企业会计准则第37号——金融工具列报》

---

## tips

1. **交易性判断**：交易性金融负债指以近期回购为目的、属于集中管理且近期有获利模式的金融工具组合、或衍生工具（套期工具除外）。
2. **指定为FVTPL条件**：初始确认时可指定为FVTPL须满足：消除或显著减少会计错配，或按公允价值对负债组合进行管理和评价。
3. **默认摊余成本**：不满足交易性且未指定FVTPL的金融负债应以摊余成本计量，分类检查须防止误将普通负债作交易性。
4. **指定不可撤销**：一经指定为FVTPL不可撤销。
5. **衍生工具**：衍生金融负债（非套期）默认FVTPL，须识别嵌入衍生工具是否需分拆。
6. **联动审定表**：分类结论须与G10-1审定表计量方法一致。

---

## checklist

### 一、交易性判断

- [ ] 是否为以近期回购为目的的负债
- [ ] 是否属于集中管理且近期有获利模式的组合
- [ ] 衍生金融负债（非套期）是否识别
- [ ] 交易性判断是否有依据

### 二、指定条件

- [ ] 指定为FVTPL的是否满足指定条件（消除会计错配/按公允价值管理）
- [ ] 指定是否在初始确认时作出且不可撤销
- [ ] 指定是否有管理层书面决策

### 三、分类恰当性与勾稽

- [ ] 不满足条件的负债是否以摊余成本计量（未误作FVTPL）
- [ ] 嵌入衍生工具是否评估是否需分拆
- [ ] 分类结论是否与G10-1审定表计量方法一致
- [ ] 是否存在为规避损益波动的不当分类

## risk_areas

### 高风险

1. **普通负债误作交易性**：将非交易目的的普通负债误分类为交易性金融负债，计量基础错误。
2. **指定条件不成立**：指定为FVTPL不满足条件（无会计错配消除依据），分类不当。
3. **嵌入衍生工具未分拆**：混合合同中嵌入衍生工具未识别分拆，计量错误。

### 中风险

1. **交易性判断依据不足**：交易目的/集中管理判断缺乏支持。
2. **事后追认指定**：非初始确认时指定而事后追认。
3. **分类与审定表不一致**：分类结论未传递至审定表计量。

### 低风险

1. **分类依据文档不充分**：分类条件评估记录不足。
2. **索引引用缺失**：未与合约、管理层决策建立索引。
3. **格式不规范**：检查表字段不统一。
