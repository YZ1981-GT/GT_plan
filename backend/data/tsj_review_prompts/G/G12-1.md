# G12-1 净敞口套期收益审定表复核提示词

## 概述

本提示词针对净敞口套期收益审定表（G12-1）的复核。净敞口套期收益（科目6106）为损益类科目，取本期发生额，反映套期会计下套期工具与被套期项目损益的净影响。审定表须完整反映套期有效部分/无效部分的损益、公允价值套期与现金流量套期的核算差异，并与利润表勾稽。

**法规依据：**
- 《企业会计准则第24号——套期会计》
- 《企业会计准则第22号——金融工具确认和计量》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **损益类取发生额**：净敞口套期收益审定数应基于本期发生额，区分套期有效部分与无效部分损益，复核核对本期发生额而非余额。
2. **区分三类套期的损益路径**：公允价值套期的套期工具与被套期项目公允价值变动均计入当期损益（净影响即净敞口套期收益）；现金流量套期有效部分计入其他综合收益、无效部分计入损益；境外经营净投资套期类似现金流量套期，须核对损益路径正确。
3. **套期无效部分必须计入损益**：套期无效部分（套期工具与被套期项目变动不完全抵销的部分）应及时计入当期损益，漏计将虚增套期效果。
4. **套期关系须满足套期会计条件**：审定收益的前提是套期关系符合CAS24指定条件（正式指定与书面文件、经济关系、信用风险不主导、套期比率适当），不满足条件的不得适用套期会计。
5. **审定数须与利润表勾稽**：审定表净敞口套期收益合计必须与利润表相关行项目一致。
6. **审定表是套期循环枢纽**：应与G12-2套期明细、G12-4公允价值测试、G12-5净敞口检查形成闭环勾稽。

## checklist

### 一、发生额与勾稽核对

- [ ] 净敞口套期收益审定数是否基于本期发生额（区分有效/无效部分）
- [ ] 审定表合计是否与利润表相关行项目一致
- [ ] 未审数是否与试算平衡表6106科目发生额一致
- [ ] 是否与G12-2套期明细表分项损益合计勾稽

### 二、套期核算正确性

- [ ] 公允价值套期损益是否计入当期损益（净影响）
- [ ] 现金流量套期有效部分是否计入其他综合收益、无效部分计入损益
- [ ] 套期无效部分是否完整识别并计入损益
- [ ] 套期关系是否符合CAS24指定条件（正式指定/经济关系/套期比率）

### 三、审计调整完整性

- [ ] 所有AJE是否完整反映在审定表调整列
- [ ] 所有RJE是否完整反映在重分类列
- [ ] 调整分录借贷方是否平衡，审定数=未审数+AJE+RJE
- [ ] 建议但未调整的错报是否记录于SUD

### 四、分类列报准确性

- [ ] 净敞口套期收益与投资收益、公允价值变动损益的划分是否正确
- [ ] 有效部分（OCI）与无效部分（损益）的列报是否正确
- [ ] 审定表分类是否与附注披露一致

## risk_areas

### 高风险

1. **套期关系不符合会计条件仍适用套期会计**：无正式指定文件或经济关系不成立却适用套期会计，导致损益核算错误。
2. **套期无效部分漏计损益**：无效部分未及时计入损益，虚增套期效果、错报损益。
3. **公允价值套期与现金流量套期损益路径错误**：将应计OCI的现金流量套期有效部分计入损益，或反之，损益失真。
4. **审定数与利润表不一致**：审定表净敞口套期收益与利润表存在无源差异。

### 中风险

1. **套期比率不当**：套期比率未反映实际风险敞口，导致套期有效性评估偏差。
2. **明细与汇总不勾稽**：审定表合计与G12-2套期明细分项合计不一致。
3. **重分类调整方向错误**：RJE借贷方向颠倒导致审定数偏离真实值。

### 低风险

1. **审定表格式不规范**：列标题、行顺序等格式问题。
2. **交叉索引不完整**：审定表未与套期明细、有效性测试底稿建立索引。
3. **变动说明不充分**：净敞口套期收益重大变动未附说明。
