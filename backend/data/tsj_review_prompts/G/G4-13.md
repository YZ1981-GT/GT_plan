# G4-13 债权投资凭证检查表复核提示词

## 适用底稿
债权投资凭证检查表（G4-13），聚焦购入/收回/处置交易凭证核对完整性、样本选取合理性、检查比例达标性、异常交易标注充分性。

## tips

- 样本选取应与风险评估匹配，大额购入、信用恶化、关联方债权投资纳入必选样本
- 凭证核对须覆盖完整交易链（投资决议→合同/申购→资金划付→托管交割单→账务处理）
- 检查比例应满足《中国注册会计师审计准则第1314号——审计抽样》要求
- 购入交易核对成本入账（含交易费用计入初始确认金额）；收回/处置核对损益结转
- 关注资产负债表日前后的购入/到期交易（截止测试）
- 关联方债权投资须核查利率公允性和商业实质
- 异常标注需明确类型（利率异常/无托管记录/关联方非公允）

## checklist

### 高风险检查项

- [ ] 样本选取方法是否与识别的重大错报风险相匹配
- [ ] 大额购入交易（超过重要性水平）是否100%全覆盖检查
- [ ] 信用恶化/关联方债权投资是否纳入必选样本
- [ ] 凭证核对是否覆盖完整交易链（决议-合同-资金-托管交割-账务）
- [ ] 购入成本入账是否准确（交易费用计入初始确认金额）
- [ ] 收回/处置损益结转是否正确
- [ ] 资产负债表日前后交易是否实施截止测试
- [ ] 是否存在无托管交割记录支持的交易凭证
- [ ] 异常交易是否全部标注并记录异常类型

### 中风险检查项

- [ ] 抽样总体是否完整（涵盖全部购入/收回/处置交易）
- [ ] 购入交易检查比例是否达标
- [ ] 收回/处置交易检查比例是否达标
- [ ] 关联方债权投资利率公允性是否核查
- [ ] 凭证日期与交割日期是否一致，是否存在跨期
- [ ] 核对中发现的差异是否逐一追踪解决

### 低风险检查项

- [ ] 抽样参数（总体/置信水平/可容忍偏差）是否完整记录
- [ ] 样本选取过程是否可追溯
- [ ] 凭证检查结果记录格式是否规范统一
- [ ] 底稿索引与交叉引用是否完整（关联审定表/明细表/利息测算/盘点表）

## risk_areas

### 高风险

1. **凭证造假风险**：虚构购入交易凭证（伪造合同/交割单）虚增资产，须交叉核对托管机构记录。
2. **截止性错误风险**：资产负债表日前后的购入/到期交易未实施截止测试，跨期确认资产或利息。
3. **成本入账错误风险**：购入交易费用处理错误（摊余成本计量的交易费用应计入初始确认金额）。
4. **关联方非公允风险**：关联方债权投资利率显著偏离市场，未识别商业实质。

### 中风险

1. **检查比例不足风险**：实际检查比例低于计划水平，审计证据不充分。
2. **处置损益结转错误风险**：收回/处置损益计算或结转错误。
3. **核对深度不够风险**：仅核对金额而忽略交易实质（决议/托管/交割时点）。

### 低风险

1. **记录不完整风险**：抽样参数、选取过程、核对结果记录不完整。
2. **索引缺失风险**：凭证检查底稿与审定表/明细表/利息测算/盘点表交叉索引不完整。
3. **格式不规范风险**：检查结果记录格式不统一。

## 法规依据

- 《中国注册会计师审计准则第1314号——审计抽样》
- 《中国注册会计师审计准则第1301号——审计证据》
- 《中国注册会计师审计准则第1141号——财务报表审计中与舞弊相关的责任》
