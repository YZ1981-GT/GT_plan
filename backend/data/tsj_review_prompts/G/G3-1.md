# G3-1 应收股利审定表复核提示词

## 概述

本提示词针对应收股利审定表（G3-1）的复核，聚焦应收股利的期初期末勾稽、股利确认时点（被投资方宣告）、与长期股权投资/金融资产投资的勾稽、可收回性评估及分类列报。应收股利的确认取决于被投资方股利分配决议，确认时点错误是本科目的核心风险。

**法规依据：**
- 《企业会计准则第22号——金融工具确认和计量》
- 《企业会计准则第37号——金融工具列报》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **期初期末勾稽是审定表的生命线**：期初审定数须等于上年期末审定数，差异需追溯至本期宣告确认、收回或调整。
2. **股利确认时点是核心**：应收股利应在被投资方宣告发放现金股利时确认，须核对被投资方股东会/董事会决议，不得提前确认未宣告股利。
3. **应收股利须与投资科目勾稽**：应收股利应能追溯至对应的长期股权投资、其他权益工具投资或交易性金融资产。
4. **权益法下的处理特殊**：长期股权投资权益法下，被投资方宣告分红应冲减投资账面价值并确认应收股利，须核对处理正确。
5. **可收回性评估**：长期未收回的应收股利须评估被投资方偿付能力和分红兑现情况。
6. **试算平衡表核对**：审定表应收股利审定数合计须与试算平衡表对应科目审定数一致。

## checklist

### 一、期初期末勾稽

- [ ] 期初未审数是否等于上年审定表期末审定数
- [ ] 期末审定数=期初+本期宣告确认−本期收回，计算是否正确
- [ ] 审定表各行变动是否与G3-2明细表增减一致
- [ ] 本期确认/收回是否与G3-4测算检查、凭证勾稽

### 二、确认时点与投资勾稽

- [ ] 应收股利是否在被投资方宣告时确认（核对分红决议）
- [ ] 是否存在提前确认未宣告股利的情况
- [ ] 应收股利是否能追溯至对应投资科目
- [ ] 权益法下分红是否正确冲减投资账面价值

### 三、可收回性与试算核对

- [ ] 长期未收回应收股利可收回性是否评估（与G3-5勾稽）
- [ ] 审定数合计是否与试算平衡表对应科目一致
- [ ] 所有AJE/RJE是否完整反映在审定表调整列

### 四、分类列报

- [ ] 应收股利是否按流动性正确分类
- [ ] 关联方（含被投资方）应收股利是否单独列示
- [ ] 审定表分类是否与附注披露一致

## risk_areas

### 高风险

1. **提前确认未宣告股利**：在被投资方宣告分红前确认应收股利，虚增资产和投资收益，构成重大错报。
2. **期初期末不勾稽**：期初审定数与上年期末不一致，存在未授权调整。
3. **应收股利与投资脱节**：应收股利无法追溯至对应投资科目，或权益法处理错误。
4. **可收回性高估**：长期未收回股利未评估被投资方偿付能力，虚增资产。
5. **审计调整遗漏或缺乏审批**：已确认调整未反映在审定表，或未经合伙人批准。

### 中风险

1. **明细与汇总不勾稽**：审定表合计与G3-2明细表不一致。
2. **权益法处理错误**：被投资方分红未正确冲减长期股权投资账面价值。
3. **分类列报错误**：长期未收回股利未正确列示或关联方未单独列示。

### 低风险

1. **审定表格式不规范**：列标题、行顺序、编号格式问题。
2. **底稿交叉索引不完整**：未与G3-2/G3-4及试算平衡表建立索引。
3. **辅助说明不充分**：变动较大行项目未附说明。
