# G1-note-listed 交易性金融资产附注披露复核提示词（上市公司）

## 概述

本提示词针对交易性金融资产上市公司附注披露底稿（G1-note-listed）的复核，聚焦上市公司财务报表附注中交易性金融资产相关披露的充分性与准确性：分类构成披露、公允价值层次披露、公允价值变动损益披露、第三层次调节披露、CAS37金融工具列报要求。上市公司披露要求高于一般企业，公允价值信息透明度是投资者关注焦点。

**法规依据：**
- 《企业会计准则第37号——金融工具列报》
- 《企业会计准则第39号——公允价值计量》
- 《企业会计准则第22号——金融工具确认和计量》
- 《公开发行证券的公司信息披露编报规则第15号——财务报告的一般规定》

---

## tips

1. **公允价值层次披露是上市公司强制要求**：须按第一/二/三层次披露交易性金融资产公允价值，并披露层次转移情况和原因（CAS39）。
2. **分类构成须与审定表勾稽**：附注按股票/基金/债券/衍生工具等分类披露的合计须等于G1-1审定表交易性金融资产审定数。
3. **公允价值变动损益须披露**：附注须披露本期计入损益的公允价值变动金额，与G1-5投资收益测算表、利润表勾稽。
4. **第三层次调节表是披露重点**：以不可观察输入计量的第三层次资产须披露期初到期末变动调节，与G1-7一致。
5. **估值技术和关键输入须披露**：第二/三层次公允价值须披露采用的估值技术及关键不可观察输入的定量信息。
6. **信用风险和市场风险披露**：CAS37要求披露金融工具的市场风险（价格风险）敏感性分析，交易性金融资产为重点。

## checklist

### 一、分类构成披露

- [ ] 交易性金融资产是否按类别（股票/基金/债券/衍生工具/理财产品等）分类披露
- [ ] 各类别期末余额合计是否等于G1-1审定表审定数
- [ ] 是否同时披露期末数和期初数（可比信息）
- [ ] 分类是否与会计政策及G1-9分类测试结论一致

### 二、公允价值层次披露

- [ ] 是否按第一/二/三层次披露交易性金融资产公允价值
- [ ] 各层次金额合计是否等于交易性金融资产总额
- [ ] 层次转移是否披露金额和原因
- [ ] 第二/三层次估值技术和关键输入是否披露
- [ ] 层次划分是否与G1-6公允价值测试一致

### 三、公允价值变动与损益披露

- [ ] 本期计入损益的公允价值变动金额是否披露
- [ ] 公允价值变动金额是否与G1-5、利润表勾稽
- [ ] 持有期间取得的股利/利息是否披露
- [ ] 处置损益是否披露

### 四、第三层次调节与风险披露

- [ ] 第三层次公允价值期初到期末调节表是否完整披露
- [ ] 调节表是否与G1-7一致
- [ ] 是否披露市场风险（价格风险）敏感性分析
- [ ] 衍生工具的名义金额和公允价值是否分别披露

## risk_areas

### 高风险

1. **公允价值层次披露缺失或错误**：未按层次披露或层次划分不当，规避第三层次严格披露要求，违反CAS39。
2. **附注总额与审定表不一致**：附注交易性金融资产期末余额与G1-1审定数不一致，属重大数据勾稽错误。
3. **公允价值变动损益披露不实**：本期计入损益的公允价值变动与G1-5/利润表不勾稽。
4. **第三层次调节表不完整**：以不可观察输入计量的资产未披露完整变动调节，透明度不足。

### 中风险

1. **估值技术披露不充分**：第二/三层次未披露估值技术和关键不可观察输入的定量信息。
2. **市场风险敏感性分析缺失**：未按CAS37披露价格风险敏感性分析。
3. **可比信息缺失**：仅披露期末数据未披露期初可比数据。

### 低风险

1. **披露格式不完全规范**：表格标题、列序、金额单位等格式细节未严格按编报规则。
2. **文字描述模板化**：风险管理政策照搬会计政策原文，未结合本企业实际。
3. **衍生工具披露简略**：名义金额与公允价值披露不够清晰。
