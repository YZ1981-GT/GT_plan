# G8-3 其他权益工具投资调整分录汇总 复核提示词

## 适用底稿
其他权益工具投资调整分录汇总表（G8-3），含账项调整（AJE）、重分类调整（RJE）及未调整错报（SUD）评估。

## 概述
G8-3 是其他权益工具投资审定数链路的关键环节。复核须验证：每笔调整有充分证据、借贷平衡、完整反映到 G8-1 审定表、公允价值变动调整计入OCI方向正确、处置结转转留存收益而非损益、股利收入调整进损益、SUD 评估符合重要性水平要求。

---

## tips

1. **AJE vs RJE**：AJE 影响资产或损益金额（如公允价值调整、股利调整）；RJE 仅影响列报，不得通过 RJE 掩盖错报。
2. **公允价值调整进OCI**：公允价值变动调整须计入其他综合收益，不进损益。
3. **处置结转转留存收益**：处置时原计入OCI的累计公允价值变动调整须转入留存收益，而非损益（区别于其他债权投资）。
4. **股利调整进损益**：股利收入相关调整计入投资收益。
5. **与 G8-1 勾稽**：审定表调整列金额须与 G8-3 已确认分录逐笔一致。
6. **TB 回写**：确认调整已同步试算平衡表其他权益工具投资科目。

## checklist

### 一、调整证据与审批

- [ ] 所有 AJE 是否有充分审计证据（估值差异、股利凭证等）
- [ ] AJE 是否经适当层级审批
- [ ] 每笔调整分录借贷方是否完全平衡
- [ ] 是否存在为美化资产或权益的不当调整

### 二、OCI与损益方向

- [ ] 公允价值变动调整是否计入其他综合收益（不进损益）
- [ ] 处置结转调整是否转入留存收益（不转损益）
- [ ] 股利收入调整是否计入投资收益
- [ ] 是否未对权益工具错误计提减值调整

### 三、勾稽与SUD

- [ ] 调整金额是否完整反映到 G8-1 审定表对应调整列
- [ ] 调整后审定数是否与试算平衡表科目勾稽
- [ ] RJE 是否仅涉及列报未影响损益/OCI
- [ ] 未调整错报累计是否超过整体重要性水平（须评估）
- [ ] 与 A13 未调整错报汇总表索引是否完整

## risk_areas

### 高风险

1. **调整缺乏证据或未经授权**：调整分录无证据支持或未经审批。
2. **处置结转错误转损益**：处置时原OCI累计额调整错误转入损益而非留存收益。
3. **公允价值调整进损益**：应计入OCI的公允价值变动调整错误进损益。
4. **审定表与G8-3长期不一致**：调整金额未逐笔反映到审定表。

### 中风险

1. **RJE误含损益或OCI影响**：重分类调整不当影响损益/OCI。
2. **股利调整方向错误**：股利收入调整误进OCI。
3. **TB未同步**：调整已入底稿但试算平衡表未更新。

### 低风险

1. **编号、格式不规范**：分录编号删除后重号风险、摘要不清。
2. **索引指向不完整**：未指向估值报告、股利凭证等支持底稿。
