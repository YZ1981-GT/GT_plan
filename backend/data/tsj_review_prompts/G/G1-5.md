# G1-5 交易性金融资产投资收益测算表复核提示词

## 概述

本提示词针对交易性金融资产投资收益测算表（G1-5）的复核，聚焦持有期间收益（现金股利、债券利息）、处置损益、公允价值变动损益的测算与结转，验证收益确认的完整性、准确性及与利润表、审定表的勾稽。

**法规依据：**
- 《企业会计准则第22号——金融工具确认和计量》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **收益三要素须分列**：交易性金融资产收益应区分持有期间收益（股利/利息）、处置损益、公允价值变动损益三类，分别测算。
2. **现金股利在被投资方宣告时确认**：持有期间取得的现金股利应在被投资方宣告发放时确认为投资收益，须核对分红公告。
3. **处置损益=卖出净额−账面价值**：处置损益应按卖出价扣除交易费用后与处置日账面公允价值的差额计算。
4. **公允价值变动损益全额计入当期损益**：未处置部分的公允价值变动应全额计入公允价值变动收益。
5. **与利润表勾稽**：投资收益、公允价值变动收益合计须与利润表相应项目一致。
6. **交易费用处理**：FVTPL金融资产的交易费用应计入当期损益（投资收益）而非成本，核对处理是否正确。

---

## checklist

### 一、持有期间收益核对

- [ ] 现金股利是否在被投资方宣告时确认，核对分红公告
- [ ] 债券利息是否按票面利率/持有期正确计算
- [ ] 持有收益是否单独列示、未并入公允价值变动
- [ ] 应收未收的股利/利息是否合理列示（是否转G3应收股利/G2应收利息）

### 二、处置损益核对

- [ ] 处置损益=卖出净额−处置日账面价值，计算是否正确
- [ ] 交易费用是否计入当期损益
- [ ] 处置金额是否与G1-13凭证检查/G1-4结存表勾稽
- [ ] 处置损益结转科目是否正确（投资收益）

### 三、公允价值变动与勾稽

- [ ] 未处置部分公允价值变动是否全额计入公允价值变动收益
- [ ] 公允价值变动是否与G1-1审定表/G1-6公允价值测试一致
- [ ] 投资收益+公允价值变动收益合计是否与利润表勾稽
- [ ] 收益测算是否与G1-2明细表逐笔对应

## risk_areas

### 高风险

1. **收益确认不完整或跨期**：现金股利/利息未在恰当时点确认，或处置损益漏记，导致投资收益失真。
2. **公允价值变动损益与利润表不勾稽**：公允价值变动收益金额与利润表不一致，报表存在错报。
3. **处置损益计算错误**：卖出净额或账面价值取数错误，导致处置损益虚增虚减。

### 中风险

1. **收益要素混淆**：持有收益、处置损益、公允价值变动未分列，收益结构失真。
2. **交易费用处理错误**：FVTPL交易费用误计入成本而非当期损益。
3. **应收未收股利利息处理不当**：应转G3/G2的应收项目未及时重分类。

### 低风险

1. **测算表格式不规范**：收益分类、列序、编号不统一。
2. **交叉索引不完整**：测算表未与G1-1/G1-2/G1-6建立索引。
