# G7-3 长期股权投资调整分录汇总 复核提示词

## 适用底稿
长期股权投资调整分录汇总表（G7-3），含账项调整（AJE）、重分类调整（RJE）及未调整错报（SUD）评估。

## 概述
G7-3 是长期股权投资审定数链路的关键环节。复核须验证：每笔调整有充分证据、借贷平衡、完整反映到 G7-1 审定表、权益法损益调整与减值调整方向正确、丧失控制权重分类调整恰当、SUD 评估符合重要性水平要求。

---

## tips

1. **AJE vs RJE**：AJE 影响损益或资产金额（如权益法损益补记、减值计提）；RJE 仅影响列报（如子公司投资与金融资产间重分类），不得通过 RJE 掩盖投资收益错报。
2. **权益法调整方向**：按比例确认被投资单位净损益调整计入投资收益，OCI变动计入其他综合收益，现金股利冲减账面价值，方向不得混淆。
3. **减值调整不可转回**：长期股权投资减值调整一经计提不得转回，调整分录不应出现减值转回。
4. **与 G7-1 勾稽**：审定表调整列金额须与 G7-3 已确认分录逐笔一致。
5. **SUD 累计**：未调整错报单独及累计是否超过阈值，须与 A13 未调整错报汇总交叉验证。
6. **TB 回写**：确认调整已同步试算平衡表1511/1512科目，避免双真源。

## checklist

### 一、调整证据与审批

- [ ] 所有 AJE 是否有充分审计证据（被投资单位审定财报、减值测试、内部交易抵销等）
- [ ] AJE 是否经适当层级审批（超重要性水平须合伙人知悉）
- [ ] 每笔调整分录借贷方是否完全平衡
- [ ] 是否存在为美化投资收益或规避减值的不当调整

### 二、权益法与减值方向

- [ ] 权益法损益调整是否正确计入投资收益
- [ ] 被投资单位OCI变动调整是否计入其他综合收益
- [ ] 现金股利调整是否冲减账面价值（权益法）
- [ ] 减值调整是否仅计提未转回

### 三、勾稽与SUD

- [ ] 调整金额是否完整反映到 G7-1 审定表对应调整列
- [ ] 调整后审定数是否与试算平衡表1511/1512科目勾稽
- [ ] RJE 是否仅涉及列报（丧失控制权重分类等），未不当影响损益
- [ ] 未调整错报累计是否超过整体重要性水平（须评估）
- [ ] 与 A13 未调整错报汇总表索引是否完整

## risk_areas

### 高风险

1. **调整缺乏证据或未经授权**：权益法损益调整无被投资单位审定财报支持，或调整未经审批。
2. **减值违规转回**：调整分录出现长期股权投资减值转回，违反准则。
3. **权益法方向错误**：损益/OCI/现金股利调整方向混淆，扭曲投资收益或权益。
4. **审定表与G7-3长期不一致**：调整金额未逐笔反映到审定表。

### 中风险

1. **RJE误含损益影响**：丧失控制权等重分类调整不当影响损益。
2. **内部交易抵销遗漏**：权益法下未抵销与联营/合营企业的内部交易未实现利润。
3. **TB未同步**：调整已入底稿但试算平衡表未更新。

### 低风险

1. **编号、格式不规范**：分录编号删除后重号风险、摘要不清。
2. **索引指向不完整**：未指向权益法计算、减值测试等支持底稿。
