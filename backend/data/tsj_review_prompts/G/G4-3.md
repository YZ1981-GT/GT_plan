# G4-3 债权投资调整分录复核提示词

## 适用底稿
债权投资调整分录汇总表（G4-3），含账项调整（AJE）、重分类调整（RJE）及未调整错报（SUD）评估。

## 概述
G4-3 是审定数链路的关键环节。复核须验证：每笔调整有证据、借贷平衡、完整反映到 G4-1 审定表、摊余成本/减值调整与相关损益科目匹配、SUD 评估符合重要性水平要求。

---

## tips

1. **AJE vs RJE**：AJE 影响利息收入/信用减值损失或资产金额；RJE 仅影响列报（如一年内到期重分类），不得通过 RJE 掩盖损益错报。
2. **摊余成本调整须双向匹配**：调整债权投资摊余成本时对应的利息收入/投资收益须同步调整。
3. **减值调整须匹配减值损失**：调整债权投资减值准备时对应信用减值损失须同步。
4. **与 G4-1 勾稽**：审定表调整列金额须与 G4-3 已确认分录逐笔一致。
5. **SUD 累计**：未调整错报单独及累计是否超阈值，与 A13 未调整错报汇总交叉验证。
6. **TB 回写**：确认调整已同步试算平衡表（1501 及相关损益科目），避免双真源。

## checklist

### 高风险检查项

- [ ] 所有 AJE 是否有充分审计证据（利息摊销验算、ECL评估等）
- [ ] 调整分录借贷方是否完全平衡且损益对应
- [ ] AJE 是否经适当层级审批
- [ ] 调整金额是否完整反映到 G4-1 审定表对应调整列
- [ ] 是否存在仅为美化利息收入或规避减值的不当调整
- [ ] 未调整错报累计是否超过整体重要性水平（须评估）

### 中风险检查项

- [ ] RJE 是否仅涉及列报（如一年内到期），未影响损益类科目
- [ ] 调整原因说明是否清晰可追溯至具体审计程序（G4-4/G4-10/G4-11）
- [ ] 与 A13 未调整错报汇总表索引是否完整
- [ ] 调整分录编号是否连续，删除后重号风险可控

### 低风险检查项

- [ ] 分录摘要、科目编码规范
- [ ] 索引指向 G4-4 利息测算、G4-13 凭证检查等支持底稿
- [ ] 审计说明/结论是否概括调整性质与剩余风险

## risk_areas

### 高风险

1. **调整缺乏证据或未经授权**：摊余成本或减值调整无程序支持或未经合伙人审批。
2. **摊余成本/减值调整单边失衡**：仅调整资产未同步调整损益，借贷不平衡。
3. **审定表与调整金额不一致**：G4-1审定表调整列与G4-3已确认分录不符。

### 中风险

1. **RJE 误含损益影响**：重分类调整错误影响利息收入或减值损失科目。
2. **SUD 累计超阈值未处理**：未调整错报累计超重要性水平未恰当处理。

### 低风险

1. **编号格式不规范**：分录编号、摘要、科目编码不规范。
2. **索引不完整**：调整分录未指向支持底稿。

## 跨底稿勾稽

- G4-3 已确认 AJE/RJE 合计 ↔ G4-1 审定表调整列
- G4-3 利息调整 ↔ G4-4 利息测算差异
- G4-3 减值调整 ↔ G4-10 减值准备测算
- G4-3 SUD ↔ A13 未调整错报汇总
- 调整后审定数 ↔ 试算平衡表 1501 及相关损益科目
