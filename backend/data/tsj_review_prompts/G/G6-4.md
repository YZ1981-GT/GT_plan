# G6-4 其他债权投资调整分录汇总 复核提示词

## 适用底稿
其他债权投资调整分录汇总表（G6-4），含账项调整（AJE）、重分类调整（RJE）及未调整错报（SUD）评估。

## 概述
G6-4 是其他债权投资审定数链路的关键环节。复核须验证：每笔调整有充分证据、借贷平衡、完整反映到 G6-1 审定表、公允价值变动与OCI调整方向正确、处置转损益调整恰当、SUD 评估符合重要性水平要求。

---

## tips

1. **AJE vs RJE**：AJE 影响损益或资产/负债金额（如减值调整、利息调整）；RJE 仅影响列报（如一年内到期重分类），不得通过 RJE 掩盖损益或OCI错报。
2. **OCI相关调整方向**：公允价值变动、减值准备的调整须计入其他综合收益，处置结转的调整须从OCI转入投资收益，方向不得颠倒。
3. **与 G6-1 勾稽**：审定表调整列金额须与 G6-4 已确认分录逐笔一致，遗漏任一笔即审定数失真。
4. **审批链**：超过明细层次重要性水平的调整须合伙人/项目经理审批留痕。
5. **SUD 累计**：未调整错报单独及累计是否超过整体/明显微小错报阈值，须与 A13 未调整错报汇总交叉验证。
6. **TB 回写**：确认调整已同步试算平衡表1503科目，避免「底稿已调、TB 未更」双真源。

## checklist

### 一、调整证据与审批

- [ ] 所有 AJE 是否有充分审计证据（估值差异、减值重算、利息重算等）
- [ ] AJE 是否经适当层级审批（超重要性水平须合伙人知悉）
- [ ] 每笔调整分录借贷方是否完全平衡
- [ ] 是否存在仅为美化资产或规避减值的不当调整

### 二、OCI与损益方向

- [ ] 公允价值变动调整是否正确计入其他综合收益
- [ ] 减值准备调整是否计入OCI而非冲减账面价值
- [ ] 处置结转调整是否将原OCI累计额转入投资收益
- [ ] 利息收入调整是否按实际利率法计入投资收益

### 三、勾稽与SUD

- [ ] 调整金额是否完整反映到 G6-1 审定表对应调整列
- [ ] 调整后审定数是否与试算平衡表1503科目勾稽
- [ ] RJE 是否仅涉及列报（如一年内到期重分类），未影响损益
- [ ] 未调整错报累计是否超过整体重要性水平（须评估）
- [ ] 与 A13 未调整错报汇总表索引是否完整

## risk_areas

### 高风险

1. **调整缺乏证据或未经授权**：调整分录无审计证据支持或未经适当层级审批即纳入审定表。
2. **OCI与损益方向颠倒**：将应计入OCI的公允价值变动/减值错误计入损益，或处置结转方向错误，扭曲利润。
3. **审定表与G6-4长期不一致**：调整金额未逐笔反映到审定表，审定数失真。
4. **SUD累计超阈值未处理**：未调整错报累计超过整体重要性水平却仍出具无保留意见。

### 中风险

1. **RJE误含损益或OCI影响**：重分类调整不应影响损益/OCI却产生影响。
2. **处置结转不完整**：处置项OCI累计额未完全转入损益或多次冲抵不完全。
3. **TB未同步**：调整已入底稿但试算平衡表1503科目未更新。

### 低风险

1. **编号、格式不规范**：分录编号删除后重号风险、摘要不清。
2. **索引指向不完整**：未指向G6-3减值明细、估值报告等支持底稿。
