# G14-1 信用减值损失审定表复核提示词

## 概述

本提示词针对信用减值损失审定表（G14-1）的复核。信用减值损失（科目6702）为损益类科目，取本期发生额，反映各金融资产按预期信用损失（ECL）模型计提/转回的减值。审定表须完整反映各类金融资产ECL计提本期变动，并与应收款项、债权投资等减值准备科目及利润表勾稽。

**法规依据：**
- 《企业会计准则第22号——金融工具确认和计量》
- 《企业会计准则第37号——金融工具列报》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **损益类取本期计提/转回净额**：信用减值损失审定数为本期各金融资产ECL计提减去转回的净额（借方计提、贷方转回），复核核对本期发生额而非减值准备余额。
2. **须区分信用减值损失与资产减值损失**：信用减值损失（6702）仅针对金融资产（应收款项/债权投资/其他债权投资等）的ECL；存货、固定资产、商誉等非金融资产减值属资产减值损失（6701），不得混淆科目。
3. **ECL三阶段迁徙须核对**：金融资产在三阶段（未显著增加/显著增加/已发生减值）间迁徙导致减值计提基础变化（12个月ECL vs 整个存续期ECL），须核对阶段划分及迁徙的合理性。
4. **本期计提须与减值准备变动勾稽**：审定表信用减值损失本期计提/转回须与各金融资产减值准备（如坏账准备）的本期计提/转回勾稽形成闭环。
5. **审定数须与利润表勾稽**：审定表信用减值损失合计必须与利润表"信用减值损失"行项目一致（以"−"号或损失列示）。
6. **审定表是减值循环枢纽**：应与G14-2明细、G14-3调整、应收款项/债权投资减值底稿形成闭环勾稽。

## checklist

### 一、发生额与勾稽核对

- [ ] 信用减值损失审定数是否基于本期计提减转回净额
- [ ] 审定表合计是否与利润表信用减值损失行项目一致
- [ ] 未审数是否与试算平衡表6702科目发生额一致
- [ ] 是否与G14-2明细表分项计提合计勾稽

### 二、科目范围与ECL模型

- [ ] 纳入本科目的是否仅为金融资产的ECL（非金融资产减值不得计入）
- [ ] ECL三阶段划分是否合理，阶段迁徙是否有依据
- [ ] 12个月ECL与整个存续期ECL的计提基础是否正确
- [ ] 本期计提/转回是否与各金融资产减值准备变动勾稽

### 三、审计调整完整性

- [ ] 所有AJE是否完整反映在审定表调整列
- [ ] 所有RJE是否完整反映在重分类列
- [ ] 调整分录借贷方是否平衡，审定数=未审数+AJE+RJE
- [ ] 建议但未调整的错报是否记录于SUD

### 四、分类列报准确性

- [ ] 信用减值损失（6702）与资产减值损失（6701）划分是否正确
- [ ] 各金融资产的减值损失是否按类别正确归类
- [ ] 审定表分类是否与附注披露一致

## risk_areas

### 高风险

1. **ECL计提不足操纵利润**：通过低估违约概率/损失率或延迟阶段迁徙少提减值，虚增利润，须核对ECL模型参数合理性。
2. **信用减值损失与资产减值损失科目混淆**：将非金融资产减值计入6702或反之，科目列报错误。
3. **三阶段迁徙不当**：信用风险已显著增加的资产未迁徙至第二/三阶段，减值计提基础错误。
4. **本期计提与减值准备变动不勾稽**：审定表信用减值损失与各金融资产减值准备本期变动存在无源差异。
5. **审定数与利润表不一致**：审定表信用减值损失与利润表存在差异。

### 中风险

1. **转回缺乏依据**：本期转回信用减值损失无客观证据支持（如债务人信用改善实证）。
2. **明细与汇总不勾稽**：审定表合计与G14-2明细表分项合计不一致。
3. **前瞻性调整缺失**：ECL计提未考虑前瞻性信息或调整因子。
4. **重分类调整方向错误**：RJE借贷方向颠倒导致审定数偏离真实值。

### 低风险

1. **审定表格式不规范**：列标题、行顺序等格式问题。
2. **交叉索引不完整**：审定表未与G14-2、各金融资产减值底稿建立索引。
3. **变动说明不充分**：信用减值损失重大变动未附说明。
