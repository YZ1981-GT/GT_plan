# G13-note-listed 公允价值变动损益附注披露复核提示词（上市公司）

## 概述

本提示词针对公允价值变动损益上市公司附注披露底稿（G13-note-listed）的复核，聚焦公允价值变动损益按来源分类披露、公允价值层次披露、与利润表勾稽及CAS39对公允价值计量披露的要求。

**法规依据：**
- 《企业会计准则第22号——金融工具确认和计量》
- 《企业会计准则第39号——公允价值计量》
- 《企业会计准则第30号——财务报表列报》

---

## tips

1. **公允价值变动损益按来源分类披露**：附注须区分交易性金融资产、交易性金融负债、衍生金融工具、指定为FVTPL的金融工具等来源的公允价值变动损益，各分项合计须等于利润表公允价值变动收益。
2. **公允价值层次披露是CAS39强制要求**：以公允价值计量的资产负债须按Level 1/2/3层次披露，Level 3须披露估值技术、关键不可观察输入及敏感性分析。
3. **未实现损益应有说明**：公允价值变动损益多为未实现损益，重大未实现损益的形成原因应说明。
4. **与资产负债表附注勾稽**：公允价值变动损益应与交易性金融资产/负债附注的公允价值变动勾稽。
5. **与利润表勾稽**：附注公允价值变动损益合计=利润表公允价值变动收益。
6. **附注须与审定表闭环勾稽**：披露公允价值变动损益各分项合计必须与G13-1审定数、G13-2明细勾稽。

## checklist

### 一、分类披露

- [ ] 公允价值变动损益是否按来源分类披露（交易性资产/负债/衍生/指定FVTPL）
- [ ] 各分项合计是否等于利润表公允价值变动收益
- [ ] 各分项是否同时披露本期数和上期可比数
- [ ] 分类方法是否与会计政策一致

### 二、公允价值层次披露

- [ ] 相关资产负债是否按Level 1/2/3层次披露
- [ ] Level 3是否披露估值技术及关键不可观察输入
- [ ] Level 3是否披露敏感性分析
- [ ] 层次间转换（如有）是否披露

### 三、勾稽核对

- [ ] 附注公允价值变动损益是否与G13-1审定数勾稽
- [ ] 是否与交易性金融资产/负债附注公允价值变动勾稽
- [ ] 附注是否与利润表一致

### 四、上市公司额外要求

- [ ] 重大未实现损益形成原因是否说明
- [ ] 是否披露对当期损益有重大影响的公允价值变动事项
- [ ] 估值涉及重大判断的是否充分说明

## risk_areas

### 高风险

1. **公允价值层次披露缺失**：未按Level 1/2/3披露，或Level 3未披露估值技术与关键输入，不满足CAS39要求。
2. **附注与利润表不勾稽**：公允价值变动损益分项合计与利润表不一致。
3. **来源分类披露缺失**：仅披露总额未按来源分类，无法评估损益来源。
4. **附注与审定表不一致**：披露公允价值变动损益与G13-1审定数存在差异。

### 中风险

1. **敏感性分析缺失**：Level 3估值未披露敏感性分析。
2. **未实现损益说明不足**：重大未实现损益形成原因未说明。
3. **可比信息缺失**：仅披露本期数，未列上期可比数。

### 低风险

1. **披露格式不规范**：表格列序、单位等格式细节问题。
2. **文字说明模板化**：估值方法说明照搬会计政策原文。
3. **层次转换说明简略**：层次间转换仅提及未展开。
