# G5-3 长期应收款坏账准备明细复核提示词

## 概述

本提示词针对长期应收款坏账准备明细表（G5-3）的复核，聚焦长期应收款预期信用损失（坏账准备）的期初余额、本期计提、本期转回、本期核销、期末余额的明细核对，以及与审定表、减值测算（G5-10）的勾稽。长期应收款作为金融资产须按CAS22计提预期信用损失。

**法规依据：**
- 《企业会计准则第22号——金融工具确认和计量》
- 《企业会计准则第37号——金融工具列报》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **坏账准备变动须完整**：期初+本期计提−本期转回−本期核销±其他=期末，各环节须完整成立。
2. **计提金额须与G5-10测算勾稽**：本期坏账准备计提金额须与G5-10减值准备测算结果一致。
3. **计提金额与利润表勾稽**：本期计提净额应与利润表信用减值损失勾稽。
4. **核销须有审批依据**：本期核销的长期应收款须有充分证据（债务人破产/无法收回）和适当审批。
5. **区分计提基础**：坏账准备应基于长期应收款净额（扣除未实现融资收益后）计提，基础须正确。
6. **期末余额勾稽审定表**：G5-3期末坏账准备余额须与G5-1审定表长期应收款减值准备一致。

---

## checklist

### 一、坏账准备变动核对

- [ ] 期初坏账准备是否等于上年期末余额
- [ ] 期末=期初+计提−转回−核销±其他，是否成立
- [ ] 本期计提是否与G5-10减值准备测算勾稽
- [ ] 本期计提净额是否与利润表信用减值损失勾稽

### 二、核销与转回核对

- [ ] 本期核销是否有充分证据和适当审批
- [ ] 本期转回原因是否合理（与G5-11勾稽）
- [ ] 核销/转回是否与G5-12凭证检查勾稽

### 三、计提基础与勾稽

- [ ] 坏账准备是否基于长期应收款净额计提
- [ ] 计提方法（单项/组合）是否与G5-8政策一致
- [ ] 期末坏账准备余额是否与G5-1审定表一致
- [ ] 是否与G5-2余额明细表逐笔对应

## risk_areas

### 高风险

1. **坏账准备变动不勾稽**：期初+变动≠期末，或与G5-10测算不一致，属重大错误。
2. **少提坏账准备虚增资产**：长期应收款未足额计提坏账准备，虚增净额。
3. **核销缺乏依据**：坏账核销无证据或未经审批，可能掩盖资产损失或利润操纵。

### 中风险

1. **计提与利润表不勾稽**：本期计提净额与信用减值损失不一致。
2. **计提基础错误**：坏账准备基于应收总额而非净额计提。
3. **转回不合理**：坏账准备转回缺乏合理依据。

### 低风险

1. **明细格式不规范**：变动项目列序、编号不统一。
2. **交叉索引不完整**：G5-3未与G5-1/G5-10建立索引。
