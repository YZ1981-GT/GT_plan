# G7-14 长期股权投资权益法核算 复核提示词

## 概述

本提示词针对长期股权投资权益法核算表（G7-14）的复核。权益法核算表汇总各权益法投资的账面价值滚动：初始成本→按持股比例确认被投资单位调整后净损益→OCI变动→内部交易抵销→冲减现金股利→超额亏损处理→减值。复核聚焦按比例确认损益的准确性、被投资单位净损益调整（政策差异/公允价值摊销/内部交易）的完整性、以及与审定表、投资收益的勾稽。

**法规依据：**
- 《企业会计准则第2号——长期股权投资》
- 《企业会计准则第33号——合并财务报表》

---

## tips

1. **确认基础是调整后净损益**：权益法确认投资收益以被投资单位调整后净损益（经会计政策统一G7-6、公允价值差异摊销、内部交易抵销）×持股比例为基础。
2. **多来源变动**：账面价值变动来自净损益（投资收益）、OCI变动（其他综合收益）、其他权益变动（资本公积）、现金股利（冲减），须分别处理。
3. **内部交易抵销**：与联营/合营企业顺流/逆流交易的未实现利润按持股比例抵销（G7-15）。
4. **超额亏损顺序**：确认亏损以账面价值减记至零为限，超额部分按长期应收款等顺序处理（G7-16）。
5. **现金股利冲账面**：权益法下收到现金股利冲减投资账面价值，不确认投资收益。
6. **勾稽审定表与投资收益**：确认的投资收益须与利润表投资收益勾稽，期末账面价值须与G7-1审定表勾稽。

## checklist

### 一、确认基础

- [ ] 被投资单位净损益是否已经会计政策统一调整（G7-6）
- [ ] 是否做公允价值差异摊销调整
- [ ] 是否抵销内部交易未实现利润（G7-15）
- [ ] 确认的投资收益是否=调整后净损益×持股比例

### 二、账面滚动

- [ ] OCI变动是否按比例计入其他综合收益
- [ ] 其他权益变动是否计入资本公积
- [ ] 收到现金股利是否冲减账面价值
- [ ] 超额亏损是否按顺序处理（G7-16）

### 三、减值与勾稽

- [ ] 期末账面价值是否扣除减值（G7-17）
- [ ] 确认的投资收益是否与利润表投资收益勾稽
- [ ] 期末账面价值是否与G7-1审定表、G7-2明细表勾稽
- [ ] 各调整来源（G7-6/13/15/16）是否完整传递

## risk_areas

### 高风险

1. **未调整净损益直接确认**：以被投资单位未调整净损益（未统一政策/未摊销公允价值差异/未抵销内部交易）确认投资收益，投资收益失真。
2. **内部交易未抵销**：顺流/逆流交易未实现利润未抵销，投资收益高估。
3. **确认基础与投资收益不勾稽**：确认的投资收益与利润表不一致。
4. **超额亏损处理错误**：将投资减记为负数或未按顺序处理。

### 中风险

1. **OCI变动误计入损益**：被投资单位OCI变动错误按净损益确认。
2. **现金股利处理错误**：收到股利未冲减账面价值。
3. **公允价值差异摊销遗漏**：取得时可辨认资产公允价值与账面差异未后续摊销。

### 低风险

1. **各调整来源传递不完整**：G7-6/13/15/16调整未完整汇总。
2. **滚动记录不清**：账面价值变动来源列示不足。
3. **索引引用缺失**：未与被投资单位财报、审定表建立索引。
