# G10-8 交易性金融负债衍生金融负债检查 复核提示词

## 概述

本提示词针对衍生金融负债检查表（G10-8）的复核。衍生金融负债（利率互换、外汇远期、期权、掉期等公允价值为负的衍生工具）以公允价值计量且变动进损益（未指定为套期工具的），须核查合约要素、公允价值估值、嵌入衍生工具分拆、以及是否符合套期会计条件。复核聚焦衍生工具识别完整性、合约要素核对、公允价值估值合理性、以及套期/非套期区分。

**法规依据：**
- 《企业会计准则第22号——金融工具确认和计量》
- 《企业会计准则第24号——套期会计》
- 《企业会计准则第37号——金融工具列报》

## tips

1. **衍生工具三特征**：价值随基础变量（利率/汇率/价格/指数）变动、初始净投资很小或为零、在未来结算，同时满足即为衍生工具。
2. **公允价值为负入负债**：衍生工具公允价值为负的列为衍生金融负债，公允价值变动（非套期）计入当期损益。
3. **嵌入衍生工具分拆**：混合合同中，若嵌入衍生工具与主合同经济特征不密切相关且单独符合衍生定义，须分拆单独核算。
4. **套期会计条件**：指定为套期工具的衍生负债须满足套期会计条件（正式指定+文档+高度有效），否则按FVTPL处理。
5. **合约要素核对**：核对名义本金、执行价格/利率、到期日、结算方式等合约要素与估值模型输入一致。
6. **联动明细审定表**：衍生负债公允价值须与G10-2明细表、G10-5公允价值测试、G10-1审定表勾稽。

## checklist

### 一、衍生工具识别

- [ ] 是否完整识别所有衍生金融负债（公允价值为负的衍生工具）
- [ ] 是否符合衍生工具三特征
- [ ] 嵌入衍生工具是否评估是否需分拆
- [ ] 分拆的嵌入衍生工具是否单独核算

### 二、合约与估值

- [ ] 合约要素（名义本金/执行价/到期日/结算方式）是否核对
- [ ] 合约要素是否与估值模型输入一致
- [ ] 公允价值估值模型是否适当（G10-5）
- [ ] 是否考虑信用价值调整（CVA/DVA）

### 三、套期与勾稽

- [ ] 是否区分套期工具与非套期衍生工具
- [ ] 指定为套期的是否满足套期会计条件（指定/文档/有效性）
- [ ] 非套期衍生负债公允价值变动是否计入损益
- [ ] 衍生负债是否与G10-2/G10-5/G10-1勾稽

## risk_areas

### 高风险

1. **衍生金融负债漏识别**：表外衍生工具或嵌入衍生工具未识别，负债和损益漏记。
2. **嵌入衍生工具未分拆**：混合合同嵌入衍生工具未分拆，计量错误。
3. **套期会计条件不满足仍套期处理**：未满足条件却按套期会计处理，损益确认错误。
4. **衍生负债估值失真**：合约要素与估值输入不一致或模型不当，公允价值错误。

### 中风险

1. **合约要素核对不足**：名义本金/执行价等未与估值输入核对。
2. **未考虑信用调整**：衍生负债估值未考虑CVA/DVA。
3. **套期非套期未区分**：套期与投机衍生工具混同处理。

### 低风险

1. **合约明细不完整**：衍生合约要素记录不足。
2. **索引引用缺失**：未与衍生合约、估值报告建立索引。
3. **格式不规范**：检查表字段不统一。
