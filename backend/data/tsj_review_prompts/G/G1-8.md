# G1-8 交易性金融资产业务模式分析复核提示词

## 概述

本提示词针对交易性金融资产业务模式分析底稿（G1-8）的复核，聚焦金融资产管理业务模式的判定：以出售为目标（交易性）、以收取合同现金流为目标、以收取现金流和出售为目标。业务模式判定与G1-10合同现金流量特征（SPPI）测试共同决定金融资产分类，是CAS22分类的两大支柱之一。

**法规依据：**
- 《企业会计准则第22号——金融工具确认和计量》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **业务模式判定是分类的第一支柱**：CAS22要求金融资产分类基于业务模式+合同现金流特征双重测试，业务模式判定错误将导致分类错误。
2. **交易性资产的业务模式为"以出售为目标"**：FVTPL交易性金融资产应属于以短期获利/出售为目标的业务模式，须核对管理层意图和历史交易频率。
3. **业务模式应以客观证据支撑**：不能仅凭管理层声明，须核对实际持有期限、交易频率、业绩考核方式、报告给关键管理人员的信息。
4. **业务模式是组合层面而非单项资产判定**：业务模式应在管理金融资产的组合/业务层面判定，而非逐项判定。
5. **业务模式变更极为罕见**：CAS22规定业务模式变更极少发生，如本期发生变更须严格评估触发事件的真实性。
6. **与分类测试结论联动**：G1-8业务模式结论须与G1-9分类测试、G1-1审定表分类一致。

## checklist

### 一、业务模式判定

- [ ] 是否明确判定金融资产的管理业务模式（以出售为目标/收取现金流/两者兼有）
- [ ] 交易性金融资产是否判定为"以出售/短期获利为目标"
- [ ] 判定是否以组合/业务层面而非单项资产进行
- [ ] 判定依据是否有客观证据（持有期限/交易频率/考核方式）

### 二、判定证据充分性

- [ ] 是否核对历史交易频率和持有期限数据
- [ ] 是否核对关键管理人员的业绩考核和报告方式
- [ ] 管理层意图是否有实际行为佐证（非仅声明）
- [ ] 本期是否发生业务模式变更，如有是否严格评估

### 三、分类联动

- [ ] G1-8业务模式结论是否与G1-9分类测试一致
- [ ] 业务模式结论是否支持FVTPL分类
- [ ] 结论是否与G1-1审定表分类一致

## risk_areas

### 高风险

1. **业务模式判定错误导致分类错误**：将实际以收取现金流为目标的资产误判为交易性，或反之，导致计量方法错误。
2. **判定缺乏客观证据**：仅凭管理层声明判定业务模式，无历史交易/考核数据支撑。
3. **业务模式变更不实**：本期声称业务模式变更但无真实触发事件，可能为规避损益/减值确认。

### 中风险

1. **组合层面判定缺失**：逐项判定业务模式而非组合层面，判定逻辑不符合CAS22。
2. **分类结论不一致**：G1-8与G1-9/G1-1分类矛盾。

### 低风险

1. **分析底稿记录不充分**：业务模式判定过程和证据记录简略。
2. **交叉索引不完整**：G1-8未与G1-9/G1-1建立索引。
