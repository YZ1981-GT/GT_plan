# G9-4 其他非流动金融资产公允价值测试 复核提示词

## 概述

本提示词针对其他非流动金融资产公允价值测试表（G9-4）的复核。其他非流动金融资产以公允价值计量且变动进损益（FVTPL），须按公允价值层次确定并测试期末公允价值。此类资产常包含结构化产品、非上市股权、衍生工具等第三层次资产，估值不确定性高。复核聚焦公允价值层次划分、估值技术选择、关键不可观察输入的合理性、以及测试结果与明细表/审定表的勾稽。

**法规依据：**
- 《企业会计准则第22号——金融工具确认和计量》
- 《企业会计准则第39号——公允价值计量》
- 《企业会计准则第37号——金融工具列报》

## tips

1. **公允价值层次**：第一层次=活跃市场未调整报价；第二层次=可观察输入；第三层次=不可观察输入（模型+管理层假设）。
2. **结构化产品估值**：结构化理财/信托产品须核对底层资产、预期收益率、赎回条款，评估估值是否反映真实公允价值。
3. **关键假设合理性**：第三层次估值的折现率、预期收益率、波动率、信用利差等关键假设须有依据。
4. **变动直接影响损益**：由于公允价值变动进损益，估值偏差会直接影响当期利润，测试须尤为审慎。
5. **估值日一致**：公允价值测算须以资产负债表日为估值日。
6. **勾稽明细审定表**：测试确定的公允价值须与G9-2明细表、G9-1审定表勾稽，第三层次调节须与G9-5一致。

## checklist

### 一、公允价值层次

- [ ] 各笔资产是否明确划分公允价值层次
- [ ] 活跃市场资产是否采用未调整报价（第一层次）
- [ ] 结构化产品/非上市股权/衍生工具是否合理划分层次
- [ ] 层次划分是否与输入值可观察性匹配

### 二、估值技术与假设

- [ ] 第三层次估值技术选择是否适当
- [ ] 关键不可观察输入（折现率/预期收益率/波动率）是否有依据
- [ ] 结构化产品底层资产和条款是否核对
- [ ] 估值是否以资产负债表日为估值日

### 三、结果与勾稽

- [ ] 测试确定的公允价值是否与G9-2明细表一致
- [ ] 公允价值是否与G9-1审定表勾稽
- [ ] 第三层次公允价值是否与G9-5调节表一致
- [ ] 重大估值是否考虑利用专家工作

## risk_areas

### 高风险

1. **第三层次估值高估**：结构化产品/非上市资产估值采用乐观假设导致公允价值高估，公允价值变动损益虚增。
2. **估值影响损益放大**：由于变动进损益，估值偏差直接虚增/虚减当期利润。
3. **结构化产品底层未穿透**：未穿透核查底层资产，估值脱离真实价值。

### 中风险

1. **层次划分错误**：第三层次误划为第二层次，掩盖估值不确定性。
2. **关键假设缺乏支持**：折现率、预期收益率等假设无客观依据。
3. **使用过期估值**：未以资产负债表日为估值日。

### 低风险

1. **估值报告索引缺失**：公允价值来源未建立索引。
2. **敏感性未分析**：第三层次估值未做关键假设敏感性分析。
3. **格式不规范**：测试表字段不统一。
