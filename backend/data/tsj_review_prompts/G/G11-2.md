# G11-2 投资收益明细分析表复核提示词

## 概述

本提示词针对投资收益明细分析表（G11-2）的复核。该表按投资项目/被投资单位分项列示投资收益的构成、来源及本期变动，是审定表（G11-1）的支撑底稿。复核聚焦分项收益的确认依据、权益法收益的带入准确性、变动率异常分析及与各投资科目的勾稽。

**法规依据：**
- 《企业会计准则第22号——金融工具确认和计量》
- 《企业会计准则第2号——长期股权投资》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **逐项目分析投资收益来源**：明细表须按被投资单位或投资工具分项列示，明确每项收益属处置损益/权益法收益/股利/利息，来源不清的分项须追查原始凭证。
2. **权益法收益应从G7长期股权投资底稿带入**：权益法确认的投资收益应与G7-14（权益法调整）或被投资单位审定财报×持股比例一致，带入数据须验证被投资方财报的可靠性（是否经审计）。
3. **变动率超30%须重点分析**：某项目投资收益较上期变动超过30%或重要性水平的，须结合被投资方经营、持股变化、处置事项分析变动合理性。
4. **利息收益按实际利率法验证**：债权投资/其他债权投资的利息收益应按实际利率法（摊余成本×实际利率）计算，与G类债权投资底稿的利息测算勾稽。
5. **分项合计须回勾审定表**：明细分析表各分项收益合计必须等于G11-1审定表投资收益合计，任何差异须查明。
6. **关注负收益（投资损失）的充分性**：权益法下被投资方亏损、处置损失等负收益是否完整确认，是否存在应确认损失但未确认（低估费用）的情形。

## checklist

### 一、分项来源核对

- [ ] 各投资项目收益是否明确来源类型（处置/权益法/股利/利息）
- [ ] 来源不清的分项是否追查原始凭证并说明
- [ ] 明细表各分项收益合计是否等于G11-1审定表合计
- [ ] 是否覆盖所有产生投资收益的被投资单位/投资工具

### 二、权益法与利息收益验证

- [ ] 权益法投资收益是否与G7长期股权投资底稿/被投资方财报×持股比例勾稽
- [ ] 被投资方财报是否可靠（是否经审计、报告期是否一致）
- [ ] 利息收益是否按实际利率法计算并与债权投资底稿勾稽
- [ ] 成本法股利收益是否有被投资方分红决议支持

### 三、变动分析

- [ ] 各项目投资收益较上期变动率是否已列示
- [ ] 变动超30%或重要性水平的项目是否有合理性分析
- [ ] 是否结合持股比例变化、处置事项、被投资方经营解释变动
- [ ] 负收益（投资损失）是否完整确认，无应确认未确认情形

### 四、勾稽与列报

- [ ] 处置损益分项是否与G11-1处置损益一致
- [ ] 明细分类是否与附注投资收益分类披露一致
- [ ] 是否与各投资科目（交易性金融资产/债权投资/长投）期末余额变动勾稽

## risk_areas

### 高风险

1. **权益法收益带入错误**：从G7带入的权益法收益金额或持股比例错误，或被投资方财报未经审计即采用，导致投资收益失真。
2. **投资损失漏确认**：被投资方亏损或处置损失应确认而未确认，低估投资损失、虚增利润。
3. **分项合计与审定表不勾稽**：明细分析各分项合计与G11-1审定表合计存在无源差异。
4. **利息收益计算错误**：未按实际利率法计算利息收益，或摊余成本基础错误，导致收益虚增或虚减。

### 中风险

1. **变动率异常未分析**：投资收益重大变动缺乏合理性分析，异常波动未被识别。
2. **收益来源归类不清**：分项未明确来源类型，处置损益与权益法收益混淆。
3. **被投资方报告期不一致**：权益法收益基于与本单位报告期不一致的被投资方财报，未做恰当调整。

### 低风险

1. **明细项目粒度不足**：多个被投资单位合并列示，不便于逐项追溯。
2. **交叉索引缺失**：明细分项未标注对应投资科目底稿索引。
3. **可比信息不完整**：仅列本期分项收益，缺少上期可比数据。
