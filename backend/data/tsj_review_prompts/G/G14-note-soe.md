# G14-note-soe 信用减值损失附注披露复核提示词（国有企业）

## 概述

本提示词针对信用减值损失国有企业附注披露底稿（G14-note-soe）的复核。国有企业信用减值损失披露除满足会计准则通用要求外，还须关注国资监管要求：坏账减值对国有资产保值增值的影响、大额减值的决策程序、长账龄金融资产减值的责任及决算报表口径一致性。

**法规依据：**
- 《企业会计准则第22号——金融工具确认和计量》
- 《企业会计准则第37号——金融工具列报》
- 《企业会计准则第30号——财务报表列报》
- 《中央企业财务决算报告管理办法》

---

## tips

1. **国企信用减值披露有双层要求**：既满足会计准则通用披露，又满足国资监管对资产质量与减值的审慎披露要求。
2. **减值影响国有资产保值增值**：信用减值损失直接影响国有资本保值增值率，附注须说明重大减值对经营业绩考核的影响。
3. **大额减值关注决策程序**：重大信用减值计提/坏账核销涉及"三重一大"决策的，须说明决策与审批情况。
4. **长账龄金融资产减值关注责任**：长账龄应收款项/债权投资的减值累积可能反映国有资产管理不到位，须说明催收措施及责任追究。
5. **与决算报表口径一致**：附注信用减值损失须与年度财务决算报表（含资产质量分析）相关数据一致，差异编制调节说明。
6. **附注须与审定表闭环勾稽**：披露信用减值损失各分项合计与G14-1审定数、G14-2明细勾稽。

## checklist

### 一、基础披露（与上市版共有）

- [ ] 信用减值损失是否按金融资产类别分类披露
- [ ] 各分项合计是否等于利润表信用减值损失及G14-1审定数
- [ ] 是否披露ECL计量方法、违约定义、损失率、前瞻性信息
- [ ] 是否按三阶段披露账面金额及减值准备

### 二、国有资产监管相关披露

- [ ] 重大信用减值损失对国有资本保值增值率的影响是否说明
- [ ] 大额减值/坏账核销是否说明"三重一大"决策程序
- [ ] 长账龄金融资产减值的催收措施是否说明
- [ ] 长账龄减值是否涉及责任追究说明

### 三、勾稽与决算一致性

- [ ] 附注信用减值损失是否与G14-1审定数、G14-2明细勾稽
- [ ] 是否与财务决算报表（资产质量分析）数据一致
- [ ] 差异是否编制调节说明

### 四、其他

- [ ] 是否同时披露本期数和上期可比数
- [ ] 重大转回是否披露原因及依据

## risk_areas

### 高风险

1. **ECL计提不足粉饰保值增值**：低估违约概率/损失率少提减值，虚增国有资本保值增值率。
2. **大额减值决策程序缺失**：重大减值/核销未经"三重一大"决策或未披露决策过程，合规风险。
3. **附注与利润表/审定表/决算不勾稽**：信用减值损失分项合计与利润表、G14-1审定数或决算报表存在差异。
4. **ECL模型关键假设未披露**：未披露违约定义、损失率、前瞻性调整，不满足CAS37要求。

### 中风险

1. **长账龄减值责任信息缺失**：长账龄金融资产减值未说明催收措施及责任追究。
2. **保值增值影响未量化**：重大减值对国有资本保值增值率的影响未量化说明。
3. **三阶段信息缺失**：未按信用风险阶段披露账面金额及减值准备。

### 低风险

1. **披露格式未按决算模板**：附注格式与国资委决算模板有细微差异。
2. **文字说明模板化**：信用风险管理政策照搬会计政策原文。
3. **底稿索引不完整**：披露底稿交叉索引缺失。
