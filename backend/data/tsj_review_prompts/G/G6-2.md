# G6-2 其他债权投资明细表 复核提示词

## 概述

本提示词针对其他债权投资明细表（G6-2）的复核。明细表逐项列示各笔债务工具投资的名称、面值、票面利率、购入成本、摊余成本、公允价值、公允价值变动、其他综合收益累计额及减值准备，是审定表（G6-1）和附注披露的数据来源。复核聚焦逐项计量准确性、公允价值来源可靠性、摊余成本与实际利率法一致性、以及明细合计与审定表的勾稽。

**法规依据：**
- 《企业会计准则第22号——金融工具确认和计量》
- 《企业会计准则第37号——金融工具列报》

---

## tips

1. **明细合计勾稽审定表**：明细表各笔期末公允价值合计须等于G6-1审定表审定数，各笔OCI累计额合计须等于审定表OCI余额。
2. **摊余成本用实际利率法**：利息收入应按实际利率法计算并计入投资收益，明细表摊余成本滚动须与利息确认一致。
3. **公允价值来源分层**：区分活跃市场报价（第一层次）、可观察输入（第二层次）、不可观察输入（第三层次），高层次估值须有独立证据支持。
4. **公允价值变动计入OCI**：每笔公允价值变动=期末公允价值-（摊余成本+期初公允价值变动），差额进OCI而非损益。
5. **减值单列不冲账面**：其他债权投资减值准备计入OCI，明细表须单独列示预期信用损失，不直接冲减公允价值列示金额。
6. **关注异常项**：面值与成本大幅偏离、公允价值持续下跌、票面利率显著偏离市场利率的债券须重点核查减值迹象。

## checklist

### 一、逐项计量准确性

- [ ] 各笔债务工具的面值、票面利率、购入日期是否与合同/交割单一致
- [ ] 购入成本是否包含交易费用（FVOCI下计入初始成本）
- [ ] 摊余成本滚动是否采用实际利率法且计算正确
- [ ] 利息收入是否按实际利率法确认并计入投资收益
- [ ] 应计利息是否单独列示且计算准确

### 二、公允价值与OCI

- [ ] 公允价值来源是否明确分层（第一/二/三层次）
- [ ] 第三层次估值的关键假设是否有底稿和依据
- [ ] 公允价值变动计算是否正确（进OCI不进损益）
- [ ] OCI累计额是否逐项滚动且与审定表勾稽
- [ ] 处置项的OCI累计额是否已从明细中结转

### 三、减值与勾稽

- [ ] 各笔预期信用损失是否单独列示且与G6-3一致
- [ ] 减值是否计入OCI不冲减账面价值
- [ ] 明细合计（公允价值/OCI/减值）是否与G6-1审定表勾稽
- [ ] 是否存在明细遗漏或重复列示

## risk_areas

### 高风险

1. **公允价值来源不可靠**：第三层次估值缺乏独立证据或采用管理层单方假设，导致公允价值高估、OCI失真。
2. **公允价值变动计入损益**：将FVOCI债务工具的公允价值变动错误计入损益，扭曲当期利润。
3. **减值迹象漏识别**：票面利率显著偏离市场、发行人信用恶化的债券未计提减值，资产虚高。
4. **明细与审定表不勾稽**：明细合计与G6-1审定数不一致，属数据勾稽重大错误。

### 中风险

1. **实际利率法应用错误**：摊余成本滚动未采用实际利率法或计算错误，利息收入失真。
2. **交易费用处理错误**：购入交易费用未计入初始成本（FVOCI应计入）。
3. **OCI累计额滚动断裂**：处置项OCI未结转或期初OCI承前错误。

### 低风险

1. **明细列示不完整**：缺少债券代码、发行人评级等辅助信息，影响分析。
2. **索引引用缺失**：未与交割单、估值报告、减值明细建立索引。
3. **精度不统一**：部分保留两位小数、部分取整，精度不一致。
