# G7-17 长期股权投资减值测试 复核提示词

## 概述

本提示词针对长期股权投资减值测试表（G7-17）的复核。长期股权投资存在减值迹象时，须估计可收回金额（公允价值减处置费用净额与预计未来现金流量现值孰高），账面价值高于可收回金额的差额确认减值损失（一经计提不得转回）。复核聚焦减值迹象识别、可收回金额估计的合理性、减值损失计算、以及减值不可转回的合规性。

**法规依据：**
- 《企业会计准则第8号——资产减值》
- 《企业会计准则第2号——长期股权投资》

---

## tips

1. **可收回金额孰高**：可收回金额=公允价值减处置费用后的净额 与 预计未来现金流量现值 两者中的较高者。
2. **减值迹象先行**：先评估是否存在减值迹象（被投资单位持续亏损、经营环境恶化、市价大幅下跌、丧失重大合同等），存在迹象才测试。
3. **减值损失=账面-可收回**：账面价值大于可收回金额的差额确认为资产减值损失（计入损益），并计入减值准备（1512）。
4. **减值不得转回**：长期股权投资减值损失一经确认，以后期间不得转回，这是与部分资产的关键差异。
5. **现值参数合理**：预计未来现金流量现值的折现率、现金流预测须合理且有依据，防止低估减值。
6. **勾稽审定表**：减值准备须与G7-1审定表减值信息、试算平衡表1512科目勾稽。

---

## checklist

### 一、减值迹象

- [ ] 是否评估减值迹象（持续亏损/环境恶化/市价下跌/合同丧失）
- [ ] 存在迹象的投资是否已实施减值测试
- [ ] 减值迹象判断是否有依据

### 二、可收回金额

- [ ] 可收回金额是否取公允价值净额与现值孰高
- [ ] 公允价值减处置费用净额估计是否有依据
- [ ] 预计未来现金流量现值的折现率是否合理
- [ ] 现金流预测假设是否有支持

### 三、减值损失与勾稽

- [ ] 减值损失=账面价值-可收回金额是否正确
- [ ] 减值损失是否计入资产减值损失（损益）
- [ ] 减值是否未被违规转回
- [ ] 减值准备是否与G7-1审定表、试算平衡表1512勾稽

## risk_areas

### 高风险

1. **减值迹象漏识别**：被投资单位持续亏损或经营恶化但未识别减值迹象、未计提减值，资产虚高。
2. **可收回金额高估**：现值折现率过低或现金流预测过于乐观，可收回金额高估、减值不足。
3. **减值违规转回**：以后期间转回已计提的长期股权投资减值损失，违反准则。

### 中风险

1. **可收回金额取值错误**：未取公允价值净额与现值孰高，减值计算基础错误。
2. **减值损失计入错误科目**：未计入资产减值损失或减值准备科目错误。
3. **减值与审定表不勾稽**：减值信息与审定表/试算平衡表不一致。

### 低风险

1. **现值模型文档不充分**：折现率、现金流预测依据记录不足。
2. **减值迹象评估记录不全**：迹象评估过程记录不充分。
3. **索引引用缺失**：未与被投资单位财报、审定表建立索引。
