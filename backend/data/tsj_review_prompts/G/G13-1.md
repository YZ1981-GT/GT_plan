# G13-1 公允价值变动损益审定表复核提示词

## 概述

本提示词针对公允价值变动损益审定表（G13-1）的复核。公允价值变动损益（科目6101）为损益类科目，取本期发生额，反映以公允价值计量且其变动计入当期损益（FVTPL）的金融资产/负债及衍生工具的未实现公允价值变动。审定表须完整反映未实现损益、并与交易性金融资产（G1）、交易性金融负债（G10）及利润表勾稽。

**法规依据：**
- 《企业会计准则第22号——金融工具确认和计量》
- 《企业会计准则第39号——公允价值计量》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **仅FVTPL资产负债的变动进本科目**：公允价值变动损益仅反映以公允价值计量且变动计入当期损益的金融工具（交易性金融资产/负债、衍生工具、指定为FVTPL的工具），须核对纳入范围正确，其他综合收益类（FVOCI）的公允价值变动不得计入本科目。
2. **未实现与已实现须区分**：公允价值变动损益反映持有期间的未实现变动，处置时应将累计公允价值变动转入投资收益（已实现），复核须核对处置时的结转，防止未实现与已实现混淆或重复计算。
3. **公允价值计量层次须支撑**：变动损益依赖资产负债的公允价值计量，须核对估值层次（Level 1/2/3）、估值方法及输入参数，Level 3估值须重点关注不可观察输入的合理性（CAS39）。
4. **审定数须与G1/G10勾稽**：审定表公允价值变动损益应与交易性金融资产（G1）、交易性金融负债（G10）期末公允价值变动勾稽形成闭环。
5. **审定数须与利润表勾稽**：审定表合计必须与利润表"公允价值变动收益"行项目一致。
6. **审定表是估值循环枢纽**：应与G13-2明细、G13-3调整、G1/G10各资产负债底稿形成闭环勾稽。

## checklist

### 一、发生额与勾稽核对

- [ ] 公允价值变动损益审定数是否基于本期发生额
- [ ] 审定表合计是否与利润表公允价值变动收益行项目一致
- [ ] 未审数是否与试算平衡表6101科目发生额一致
- [ ] 是否与G13-2明细表分项变动合计勾稽

### 二、核算范围与计量

- [ ] 纳入本科目的是否仅为FVTPL金融工具及衍生工具
- [ ] FVOCI类公允价值变动是否被误计入本科目
- [ ] 处置时累计公允价值变动是否恰当转入投资收益
- [ ] 公允价值计量层次/方法/输入是否有支撑（Level 3重点）

### 三、审计调整完整性

- [ ] 所有AJE是否完整反映在审定表调整列
- [ ] 所有RJE是否完整反映在重分类列
- [ ] 调整分录借贷方是否平衡，审定数=未审数+AJE+RJE
- [ ] 建议但未调整的错报是否记录于SUD

### 四、勾稽与列报

- [ ] 审定数是否与G1交易性金融资产期末公允价值变动勾稽
- [ ] 审定数是否与G10交易性金融负债期末公允价值变动勾稽
- [ ] 审定表分类是否与附注披露一致

## risk_areas

### 高风险

1. **公允价值估值不可靠**：Level 3估值的不可观察输入无合理依据，或估值方法不当，导致公允价值变动损益虚增/虚减。
2. **FVOCI变动误计入损益**：以公允价值计量且变动计入其他综合收益的工具变动被计入本科目，损益失真。
3. **未实现与已实现重复计算**：处置时未将累计公允价值变动转出，导致投资收益与公允价值变动损益重复。
4. **审定数与利润表/G1/G10不勾稽**：审定表公允价值变动损益与利润表或交易性金融资产负债底稿存在无源差异。

### 中风险

1. **估值层次判断不当**：将Level 3估值列为Level 2，掩盖估值不确定性。
2. **明细与汇总不勾稽**：审定表合计与G13-2明细表分项合计不一致。
3. **重分类调整方向错误**：RJE借贷方向颠倒导致审定数偏离真实值。

### 低风险

1. **审定表格式不规范**：列标题、行顺序等格式问题。
2. **交叉索引不完整**：审定表未与G13-2、G1/G10底稿建立索引。
3. **变动说明不充分**：公允价值变动损益重大变动未附说明。
