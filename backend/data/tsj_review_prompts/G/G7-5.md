# G7-5 长期股权投资被投资单位财务信息 复核提示词

## 概述

本提示词针对被投资单位财务信息表（G7-5）的复核。财务信息表收集各被投资单位的净利润、净资产、其他综合收益、现金股利分配等，是权益法下按持股比例确认投资收益、调整账面价值的数据基础。复核聚焦财务数据来源可靠性（经审计优先）、净损益调整（内部交易/公允价值调整）、以及与权益法计算（G7-14）的勾稽。

**法规依据：**
- 《企业会计准则第2号——长期股权投资》
- 《企业会计准则第33号——合并财务报表》

---

## tips

1. **经审计财报优先**：权益法确认损益应以被投资单位经审计财务报表为准，未审财报须评估可靠性并实施替代程序。
2. **净损益需调整**：确认投资收益前须按公允价值调整被投资单位可辨认资产/负债的差异摊销、抵销内部交易未实现利润。
3. **净资产变动多来源**：被投资单位净资产变动可能来自净损益、OCI、股利分配、资本公积变动，权益法须区分处理。
4. **同一会计政策**：被投资单位会计政策/期间与投资方不一致时须调整为一致后再确认损益。
5. **变动额与变动率**：净利润/净资产较上期变动超过阈值（如30%）须分析原因，评估异常波动。
6. **勾稽权益法计算**：财务信息须与G7-14权益法核算逐户勾稽，净损益×持股比例=确认的投资收益。

---

## checklist

### 一、数据来源可靠性

- [ ] 被投资单位财务数据是否来自经审计财报
- [ ] 未审财报是否评估可靠性并实施替代程序
- [ ] 净利润、净资产、OCI、现金股利是否完整收集
- [ ] 财务信息期间是否与投资方审计期间一致

### 二、净损益调整

- [ ] 是否按公允价值调整被投资单位可辨认资产/负债差异摊销
- [ ] 是否抵销与被投资单位的内部交易未实现利润
- [ ] 会计政策不一致时是否调整为一致
- [ ] 调整后净损益是否用于权益法确认

### 三、异常分析与勾稽

- [ ] 净利润/净资产较上期变动超阈值是否分析原因
- [ ] 关键财务项目是否缺失
- [ ] 财务信息是否与G7-14权益法计算逐户勾稽
- [ ] 上年金额是否可滚存对比

## risk_areas

### 高风险

1. **采用未审财报确认损益**：以未经审计的被投资单位财报确认投资收益且无替代程序，投资收益缺乏可靠依据。
2. **净损益调整遗漏**：未做公允价值差异摊销或未抵销内部交易未实现利润，投资收益高估。
3. **财务信息与权益法计算不勾稽**：净损益×持股比例与G7-14确认的投资收益不一致。

### 中风险

1. **会计政策未统一**：被投资单位会计政策与投资方不一致未调整。
2. **净资产变动来源混淆**：将OCI变动误按净损益确认（或反之）。
3. **异常波动未分析**：净利润大幅波动未说明原因。

### 低风险

1. **财务信息汇总不完整**：缺关键项目导致分析不便。
2. **上年对比缺失**：未列示上年可比数据。
3. **索引引用缺失**：未与被投资单位审定财报建立索引。
