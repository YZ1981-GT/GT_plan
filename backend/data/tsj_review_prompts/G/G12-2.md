# G12-2 套期明细表复核提示词

## 概述

本提示词针对套期明细表（G12-2）的复核。该表按套期关系分项列示套期工具、被套期项目、套期类型、名义金额及本期损益，是审定表（G12-1）的支撑底稿。复核聚焦套期关系文档完整性、套期工具与被套期项目匹配、损益分项确认及勾稽。

**法规依据：**
- 《企业会计准则第24号——套期会计》
- 《企业会计准则第22号——金融工具确认和计量》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **逐套期关系列示**：明细表须按每项套期关系列示套期工具（如远期/期权/互换）、被套期项目、套期类型、名义金额、本期公允价值变动及损益归属。
2. **套期工具与被套期项目须经济匹配**：核对套期工具的风险敞口与被套期项目的被套期风险在方向、金额、期限上匹配，防止无实际对冲关系的"套期"。
3. **套期正式指定文档须齐全**：每项套期关系应有套期开始时的书面指定文件（风险管理目标、套期工具、被套期项目、套期有效性评估方法），缺失文档的不得适用套期会计。
4. **损益分项须区分有效/无效**：明细表须分项列示有效部分（公允价值套期入损益/现金流量套期入OCI）与无效部分（入损益）。
5. **分项合计回勾审定表**：套期明细各分项损益合计必须等于G12-1审定表净敞口套期收益合计。
6. **关注套期终止的会计处理**：套期关系提前终止或不再满足条件时的会计处理（现金流量套期OCI累计额结转）须核对。

## checklist

### 一、套期关系与文档

- [ ] 每项套期关系是否有书面正式指定文件
- [ ] 套期工具、被套期项目、套期类型、名义金额是否完整列示
- [ ] 套期工具与被套期项目在方向/金额/期限上是否经济匹配
- [ ] 是否覆盖所有产生净敞口套期收益的套期关系

### 二、损益分项确认

- [ ] 本期公允价值变动损益是否分项列示
- [ ] 有效部分与无效部分是否分别列示且路径正确
- [ ] 套期明细各分项损益合计是否等于G12-1审定表合计
- [ ] 套期终止的会计处理（OCI结转）是否正确

### 三、勾稽与验证

- [ ] 套期工具公允价值变动是否与衍生工具估值/对手方确认勾稽
- [ ] 被套期项目公允价值变动是否有计量依据
- [ ] 名义金额是否与合约一致

### 四、列报

- [ ] 明细分类是否与附注套期披露一致
- [ ] 是否与G12-4公允价值测试、G12-5净敞口检查数据勾稽

## risk_areas

### 高风险

1. **无正式指定文档仍列为套期**：套期关系缺书面指定文件却适用套期会计，损益核算无依据。
2. **套期工具与被套期项目不匹配**：无实际经济对冲关系被列为套期，虚构套期效果。
3. **分项合计与审定表不勾稽**：明细分项损益合计与G12-1审定表存在无源差异。
4. **有效/无效部分划分错误**：无效部分未识别或路径错误，损益失真。

### 中风险

1. **套期终止处理错误**：套期提前终止时OCI累计额结转不当。
2. **名义金额与合约不一致**：明细表名义金额与套期合约不符。
3. **被套期项目计量无依据**：被套期项目公允价值变动缺计量支持。

### 低风险

1. **明细粒度不足**：多项套期关系合并列示，不便逐项追溯。
2. **交叉索引缺失**：套期明细未标注对应估值/有效性测试底稿索引。
3. **可比信息不完整**：仅列本期分项损益，缺上期可比数据。
