# G14-3 信用减值损失调整分录复核提示词

## 概述

本提示词针对信用减值损失调整分录（G14-3）的复核，含账项调整（AJE）、重分类调整（RJE）及未调整错报（SUD）评估。复核须验证每笔调整有证据、借贷平衡、完整反映到G14-1审定表，并同步试算平衡表及对应金融资产减值准备。

**法规依据：**
- 《企业会计准则第22号——金融工具确认和计量》
- 《企业会计准则第37号——金融工具列报》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **AJE影响损益、RJE仅影响列报**：信用减值损失的AJE调整损益金额（如补提/冲减ECL），且须同步调整对应金融资产减值准备；RJE仅涉及列报（如信用减值损失与资产减值损失科目重分类），不得以RJE掩盖损益错报。
2. **调整须与G14-1审定表逐笔勾稽**：审定表调整列金额必须与G14-3已确认分录逐笔一致。
3. **补提/冲减ECL调整须有证据**：调整ECL金额的分录须有ECL模型重算、债务人信用变化证据支持，并同步影响减值准备。
4. **调整须双向影响损益与减值准备**：信用减值损失调整通常对应减值准备的调整（借信用减值损失/贷减值准备或反向），须核对双向一致。
5. **审批链留痕**：超过明细层次重要性水平的调整须经合伙人/项目经理审批。
6. **TB回写一致**：确认调整已同步试算平衡表6702科目及对应减值准备科目。

## checklist

### 一、账项调整（AJE）

- [ ] 所有AJE是否有充分审计证据（ECL重算、信用变化证据等）
- [ ] AJE是否经适当层级审批
- [ ] 每笔调整分录借贷方是否完全平衡
- [ ] 调整金额是否完整反映到G14-1审定表调整列
- [ ] 信用减值损失调整是否同步影响对应减值准备科目

### 二、重分类调整（RJE）

- [ ] RJE是否仅涉及列报，未影响损益总额
- [ ] 信用减值损失（6702）与资产减值损失（6701）之间的重分类是否恰当
- [ ] 是否存在以RJE掩盖损益错报的情形

### 三、未调整错报（SUD）与勾稽

- [ ] 未调整错报累计是否超过整体重要性水平
- [ ] 与A13未调整错报汇总表索引是否完整
- [ ] 跨期调整是否正确区分本期错报与前期差错更正
- [ ] 调整后审定数是否已同步试算平衡表6702及减值准备科目

## risk_areas

### 高风险

1. **调整缺乏证据或未经授权**：ECL调整无模型重算/信用变化证据支持，或未经审批即纳入审定表。
2. **审定表与调整金额不一致**：G14-1审定表调整列与G14-3已确认分录长期不一致。
3. **调整未同步减值准备**：信用减值损失调整未同步影响对应减值准备科目，导致损益与资产不匹配。
4. **以RJE掩盖损益错报**：将信用减值损失错报以科目重分类处理，规避损益影响。

### 中风险

1. **RJE误含损益影响**：重分类调整影响了损益总额而非仅列报。
2. **跨期调整分类错误**：未区分本期错报与前期差错更正。
3. **SUD累计超阈值未处理**：未调整错报累计超重要性水平但未评估。

### 低风险

1. **分录摘要、科目编码不规范**：调整分录摘要笼统或编码不规范。
2. **索引指向不完整**：调整分录未指向G14-2明细、减值准备底稿等支持底稿。
3. **审计说明不充分**：未概括调整性质与剩余风险。
