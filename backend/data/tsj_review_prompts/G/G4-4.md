# G4-4 债权投资利息测算表复核提示词

## 概述

本提示词针对债权投资利息测算表（G4-4）的复核，聚焦实际利率法下利息收入的测算：实际利率的确定、期初摊余成本×实际利率的利息收入、票面利息、利息调整（溢折价）摊销的独立测算与账面对比。实际利率法是摊余成本计量的核心，测算错误直接导致利息收入和摊余成本失真。

**法规依据：**
- 《企业会计准则第22号——金融工具确认和计量》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **实际利率法是核心**：利息收入=期初摊余成本×实际利率，非票面利息，须验证实际利率计算和逐期摊销。
2. **实际利率确定须验算**：实际利率是使未来现金流现值等于初始购入价的折现率，须核对IRR计算（购入价、票息、面值、期限）。
3. **利息调整摊销=实际利息−票面利息**：溢价购入的利息调整摊销减少利息收入，折价则增加，方向须正确。
4. **摊余成本滚动须与审定表勾稽**：G4-4逐期摊余成本须与G4-1审定表、G4-2明细表勾稽。
5. **测算差异须查明**：独立测算利息与账面确认差异须查明（实际利率错误/摊销错误），评估调整。
6. **一次性还本付息与分期付息区分**：现金流结构不同影响摊余成本滚动路径，须核对现金流假设。

## checklist

### 一、实际利率核对

- [ ] 实际利率是否基于购入价、票息、面值、期限正确计算（IRR）
- [ ] 实际利率与合同/初始确认一致
- [ ] 现金流结构（一次还本/分期付息）是否正确反映
- [ ] 浮动利率债券实际利率处理是否恰当

### 二、利息测算准确性

- [ ] 利息收入=期初摊余成本×实际利率，测算是否正确
- [ ] 利息调整摊销=实际利息−票面利息，方向是否正确
- [ ] 溢折价摊销在存续期是否完整摊销
- [ ] 逐期摊余成本滚动是否与G4-1/G4-2勾稽

### 三、差异与勾稽

- [ ] 独立测算利息与账面确认差异是否查明原因
- [ ] 测算利息收入合计是否与G4-1审定表/利润表勾稽
- [ ] 重大差异是否评估调整（转G4-3）

## risk_areas

### 高风险

1. **实际利率法未采用或错误**：以票面利率替代实际利率，或实际利率计算错误，导致利息收入和摊余成本失真。
2. **溢折价摊销错误**：利息调整摊销方向或金额错误，摊余成本偏离真实值。
3. **测算与审定表脱节**：G4-4测算摊余成本与G4-1审定数不勾稽。

### 中风险

1. **现金流假设错误**：还本付息结构假设错误影响摊余成本滚动。
2. **浮动利率处理不当**：浮动利率债券实际利率处理错误。
3. **差异未查明**：测算与账面差异存在但未查明原因。

### 低风险

1. **测算底稿记录不充分**：实际利率、现金流、摊销记录简略。
2. **交叉索引不完整**：G4-4未与G4-1/G4-2建立索引。
