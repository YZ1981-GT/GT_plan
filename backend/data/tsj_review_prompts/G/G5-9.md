# G5-9 长期应收款三阶段划分复核提示词

## 概述

本提示词针对长期应收款三阶段划分底稿（G5-9）的复核，聚焦预期信用损失模型下的三阶段划分：第一阶段（信用风险未显著增加，12个月ECL）、第二阶段（信用风险显著增加，存续期ECL）、第三阶段（已发生信用减值，存续期ECL并按净额计息）。采用一般方法的长期应收款须划分三阶段；采用简化方法（如融资租赁应收款）始终按存续期ECL计量。

**法规依据：**
- 《企业会计准则第22号——金融工具确认和计量》
- 《企业会计准则第37号——金融工具列报》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **方法决定是否分阶段**：采用简化方法的应收款始终按存续期ECL，无需分阶段；采用一般方法的须划分三阶段，须与G5-8政策一致。
2. **信用风险显著增加（SICR）判断是核心**：第一至第二阶段迁移的触发条件（逾期天数、债务人财务恶化、评级下调）须明确一致。
3. **30天逾期是SICR的可反驳推定**：逾期超30天推定信用风险显著增加，须核对逾期数据。
4. **第三阶段=已发生信用减值**：违约、重大财务困难、债务重组、逾期90天等触发第三阶段，须核对客观减值证据。
5. **第三阶段按净额计息**：第三阶段融资收益按净额（扣除减值准备）×实际利率确认。
6. **阶段划分联动减值测算**：G5-9阶段结论须与G5-10减值准备测算一致。

## checklist

### 一、方法与阶段划分

- [ ] 减值方法（一般/简化）是否与G5-8政策一致
- [ ] 采用一般方法的应收款是否划分三阶段
- [ ] SICR判断标准（逾期天数/财务恶化/评级）是否明确
- [ ] 30天逾期是否触发第二阶段推定

### 二、划分证据

- [ ] 阶段划分是否基于客观证据（逾期数据/财务状况）
- [ ] 90天逾期/违约/减值证据是否触发第三阶段
- [ ] 信用风险显著增加判断是否一致应用
- [ ] 是否存在为规避减值而不当划分阶段

### 三、计量联动

- [ ] 第一阶段计12个月ECL，第二/三阶段计存续期ECL
- [ ] 第三阶段融资收益是否按净额计息
- [ ] G5-9阶段结论是否与G5-10一致

## risk_areas

### 高风险

1. **阶段划分不当规避减值**：将应属第二/三阶段的应收款划为第一阶段，少提减值。
2. **SICR触发条件忽视**：逾期或财务恶化未触发阶段迁移，减值范围不足。
3. **第三阶段计息基础错误**：第三阶段未按净额计息，融资收益虚增。

### 中风险

1. **方法与阶段不一致**：简化方法却分阶段，或一般方法未分阶段。
2. **SICR标准不一致**：不同应收款采用不同SICR判断标准。
3. **阶段划分与测算脱节**：G5-9与G5-10不一致。

### 低风险

1. **划分底稿记录不充分**：阶段划分依据和证据记录简略。
2. **交叉索引不完整**：G5-9未与G5-8/G5-10建立索引。
