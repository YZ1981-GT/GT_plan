# G13-note-soe 公允价值变动损益附注披露复核提示词（国有企业）

## 概述

本提示词针对公允价值变动损益国有企业附注披露底稿（G13-note-soe）的复核。国有企业公允价值变动损益披露除满足会计准则通用要求外，还须关注国资监管对持有金融资产/衍生品的合规要求：估值波动对经营考核的影响、Level 3估值的审慎性及决算报表口径一致性。

**法规依据：**
- 《企业会计准则第22号——金融工具确认和计量》
- 《企业会计准则第39号——公允价值计量》
- 《企业会计准则第30号——财务报表列报》
- 《中央企业财务决算报告管理办法》

---

## tips

1. **国企公允价值披露有双层要求**：既满足会计准则通用披露，又满足国资监管对金融资产估值的审慎披露要求。
2. **估值波动关联经营考核**：公允价值变动损益属未实现损益，对国企经营业绩考核有影响，附注须说明重大未实现损益及其可持续性。
3. **Level 3估值须审慎**：国资监管关注不可观察输入的公允价值计量审慎性，Level 3估值须披露估值技术、关键假设及敏感性，防止估值虚增业绩。
4. **金融资产持有合规性**：附注可结合说明持有FVTPL金融资产/衍生品是否符合国资对金融投资的授权与限制。
5. **与决算报表口径一致**：附注公允价值变动损益须与年度财务决算报表相关数据一致，差异编制调节说明。
6. **附注须与审定表闭环勾稽**：披露公允价值变动损益各分项合计与G13-1审定数、G13-2明细勾稽。

## checklist

### 一、基础披露（与上市版共有）

- [ ] 公允价值变动损益是否按来源分类披露
- [ ] 各分项合计是否等于利润表公允价值变动收益及G13-1审定数
- [ ] 相关资产负债是否按Level 1/2/3层次披露
- [ ] Level 3是否披露估值技术、关键输入及敏感性

### 二、国有资产监管相关披露

- [ ] 重大未实现损益及其可持续性是否说明
- [ ] Level 3估值的审慎性（关键假设合理性）是否体现
- [ ] 持有FVTPL金融资产/衍生品的授权合规性是否可结合说明
- [ ] 估值波动对经营业绩考核的影响是否说明

### 三、勾稽与决算一致性

- [ ] 附注公允价值变动损益是否与G13-1审定数、G13-2明细勾稽
- [ ] 附注是否与财务决算报表数据一致
- [ ] 差异是否编制调节说明

### 四、其他

- [ ] 是否同时披露本期数和上期可比数
- [ ] 层次间转换（如有）是否披露

## risk_areas

### 高风险

1. **Level 3估值虚增业绩**：不可观察输入激进导致未实现损益虚增，粉饰国企经营业绩，未披露敏感性。
2. **附注与利润表/审定表/决算不勾稽**：公允价值变动损益分项合计与利润表、G13-1审定数或决算报表存在差异。
3. **公允价值层次披露缺失**：未按Level 1/2/3披露，不满足CAS39要求。
4. **重大未实现损益不说明**：重大未实现损益及可持续性未说明，掩盖业绩波动。

### 中风险

1. **金融投资合规性未说明**：持有FVTPL金融资产/衍生品是否符合国资授权限制未结合说明。
2. **敏感性分析缺失**：Level 3估值未披露敏感性分析。
3. **可比信息缺失**：仅披露本期数，未列上期可比数。

### 低风险

1. **披露格式未按决算模板**：附注格式与国资委决算模板有细微差异。
2. **文字说明模板化**：估值方法说明照搬会计政策原文。
3. **底稿索引不完整**：披露底稿交叉索引缺失。
