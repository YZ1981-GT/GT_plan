# G9-6 其他非流动金融资产凭证检查 复核提示词

## 适用底稿
其他非流动金融资产凭证检查表（G9-6），聚焦样本选取合理性、凭证核对完整性、检查比例达标性、异常交易标注充分性。

## tips

- 样本选取应覆盖本期新增投资、处置/结算、大额公允价值变动等重大变动
- 凭证核对须验证投资真实性、成本准确性、权属清晰性（认购/申购协议、划款凭证、权属证明、记账）
- 检查比例应满足《中国注册会计师审计准则第1314号——审计抽样》要求
- 重大投资/处置应100%检查，结构化产品须核对底层资产和合同条款
- 公允价值变动大的项目须核对估值报告和估值凭证
- 处置/结算凭证须核对到账金额、结算单，验证处置损益确认
- 异常标注：无实际划款的投资登记、公允价值大幅偏离底层价值、体外资金循环
- 关注以理财/信托投资名义的关联方资金占用和刚性兑付安排

## checklist

### 高风险检查项

- [ ] 样本选取是否覆盖本期所有重大投资变动（新增/处置/大额公允价值变动）
- [ ] 重大投资/处置（超重要性水平）是否100%检查
- [ ] 投资是否有真实资金划出（划款凭证/申购确认）
- [ ] 结构化产品底层资产和合同条款是否核对
- [ ] 权属证明（份额确认书/权益凭证）是否核对
- [ ] 公允价值变动大的项目是否核对估值报告
- [ ] 处置/结算凭证是否完整（结算单/到账凭证）
- [ ] 是否存在无商业实质的关联方资金占用/刚性兑付

### 中风险检查项

- [ ] 抽样方法是否符合CAS1314要求
- [ ] 检查比例（已检查金额/总体金额）是否达到计划水平
- [ ] 取得成本凭证是否核对（交易费用计入损益）
- [ ] 公允价值估值凭证/报告是否核对（第三层次）
- [ ] 处置损益确认凭证是否核对
- [ ] 凭证日期与记账日期是否一致，是否跨期
- [ ] 核对差异是否逐一追踪解决

### 低风险检查项

- [ ] 抽样参数是否完整记录
- [ ] 样本选取过程是否可追溯
- [ ] 检查结果记录格式是否规范统一
- [ ] 检查比例计算公式是否正确
- [ ] 底稿索引与交叉引用是否完整

## risk_areas

### 高风险

1. **虚假投资风险**：投资登记但无真实资金划出，虚增其他非流动金融资产。
2. **结构化产品底层风险**：未穿透核查底层资产，估值脱离真实价值，或存在刚性兑付/资金池风险。
3. **公允价值变动损益不实风险**：公允价值变动凭证缺乏估值支持，直接虚增/虚减当期损益。
4. **处置损益操纵风险**：处置/结算凭证不清，跨期确认处置损益调节利润。
5. **体外资金循环风险**：以理财/信托投资名义的关联方资金占用，无商业实质。

### 中风险

1. **检查比例不足风险**：实际检查比例低于计划，审计证据不充分。
2. **权属不清风险**：投资份额权属证明缺失。
3. **估值凭证核对不足风险**：第三层次估值报告核对深度不够。
4. **成本处理错误风险**：交易费用误计入成本（FVTPL应进损益）。

### 低风险

1. **记录不完整风险**：抽样参数/选取过程/核对结果记录不完整。
2. **索引缺失风险**：凭证检查与审定表/明细表交叉索引不完整。
3. **格式不规范风险**：检查结果记录格式不统一。
