# G12-4 套期公允价值与有效性测试复核提示词

## 概述

本提示词针对套期公允价值与有效性测试（G12-4）的复核。该表验证套期工具与被套期项目的公允价值计量，并评估套期有效性（经济关系、套期比率、信用风险影响），是审定净敞口套期收益的核心支撑底稿。

**法规依据：**
- 《企业会计准则第24号——套期会计》
- 《企业会计准则第22号——金融工具确认和计量》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **套期有效性三条件缺一不可**：CAS24要求套期工具与被套期项目之间存在经济关系、信用风险不主导价值变动、套期比率与实际风险敞口一致，三条件须逐项测试留证。
2. **公允价值计量须验证估值方法与输入**：套期工具（衍生品）公允价值应核对估值模型、市场输入参数（利率/汇率/价格曲线）及对手方确认，被套期项目公允价值变动须有可观察依据。
3. **无效部分须量化并入损益**：有效性测试须量化套期工具与被套期项目公允价值变动的抵销程度，未抵销的无效部分金额须计入损益（联动G12-1/G12-3）。
4. **套期比率再平衡须记录**：套期比率发生变化需再平衡的，须记录再平衡的会计处理及对损益的影响。
5. **信用风险影响须评估**：套期工具/被套期项目对手方信用风险的变化是否主导公允价值变动，若主导则不满足套期有效性。
6. **测试结论支撑审定**：有效性测试结论（有效/部分有效/无效）应明确，并与套期收益审定、无效部分损益确认联动。

## checklist

### 一、公允价值计量

- [ ] 套期工具公允价值是否核对估值模型及市场输入参数
- [ ] 套期工具公允价值是否与对手方确认/第三方估值勾稽
- [ ] 被套期项目公允价值变动是否有可观察依据
- [ ] 估值输入参数（利率/汇率/价格）是否来源可靠

### 二、有效性测试

- [ ] 套期工具与被套期项目是否存在经济关系（方向相反、金额匹配）
- [ ] 信用风险是否不主导公允价值变动
- [ ] 套期比率是否与实际风险敞口一致
- [ ] 有效性测试方法（比率分析/回归/关键条款比较）是否恰当

### 三、无效部分与再平衡

- [ ] 无效部分金额是否量化并计入损益（联动G12-1/G12-3）
- [ ] 套期比率变化是否记录再平衡处理
- [ ] 再平衡对损益的影响是否正确核算

### 四、结论与联动

- [ ] 有效性测试结论是否明确（有效/部分有效/无效）
- [ ] 测试结论是否与套期收益审定联动
- [ ] 不再满足套期条件的是否终止套期会计

## risk_areas

### 高风险

1. **有效性条件不满足仍适用套期会计**：经济关系/套期比率/信用风险主导等条件不满足却继续套期会计，损益核算失据。
2. **公允价值估值输入不可靠**：套期工具估值参数无市场支持或对手方未确认，公允价值失真。
3. **无效部分漏计损益**：有效性测试未量化无效部分或未计入损益，虚增套期效果。
4. **信用风险主导未识别**：对手方信用风险主导价值变动但未评估，套期有效性判断错误。

### 中风险

1. **套期比率再平衡未处理**：套期比率变化需再平衡而未记录处理。
2. **有效性测试方法不当**：所选测试方法无法有效评估经济关系。
3. **测试结论与审定不联动**：有效性结论与套期收益审定脱节。

### 低风险

1. **估值文档不完整**：估值模型/参数来源记录不充分。
2. **测试频率不足**：有效性测试仅期末进行，中间期间未评估。
3. **底稿索引缺失**：测试底稿与套期明细/审定表交叉索引不完整。
