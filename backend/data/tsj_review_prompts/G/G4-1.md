# G4-1 债权投资审定表复核提示词

## 概述

本提示词针对债权投资（科目1501）审定表（G4-1）的复核，聚焦以摊余成本计量金融资产的期初期末勾稽、实际利率法下摊余成本滚动、预期信用损失（ECL）计提、试算平衡表核对及分类列报。债权投资以摊余成本计量的前提是业务模式为收取合同现金流且通过SPPI测试，摊余成本与减值是审定的两大核心。

**法规依据：**
- 《企业会计准则第22号——金融工具确认和计量》
- 《企业会计准则第37号——金融工具列报》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **期初期末勾稽是审定表的生命线**：期初审定数须等于上年期末审定数，差异需追溯至购入、利息摊销、收回本息或减值调整。
2. **摊余成本滚动须成立**：期末摊余成本=期初摊余成本+实际利息−收到本息−减值，须与G4-4利息测算表勾稽。
3. **实际利率法而非票面利率**：债权投资利息收入按实际利率法确认，利息调整（溢折价）在存续期摊销，须核对利息调整摊销。
4. **摊余成本计量前提须验证**：以摊余成本计量须由G4-5业务模式（收取现金流）和G4-6 SPPI测试共同支撑。
5. **ECL须计提**：债权投资须按三阶段模型计提预期信用损失，与G4-9/G4-10/G4-11勾稽。
6. **试算平衡表核对**：审定表债权投资审定数合计须与试算平衡表1501科目审定数一致（含成本/利息调整/应计利息/减值明细）。

## checklist

### 一、期初期末勾稽

- [ ] 期初未审数是否等于上年审定表期末审定数
- [ ] 期末摊余成本=期初+实际利息−收本息−减值，滚动是否成立
- [ ] 审定表各行变动是否与G4-2明细表增减一致
- [ ] 本期购入/收回是否与G4-13凭证检查、G4-7盘点表勾稽

### 二、摊余成本与利息核对

- [ ] 利息收入是否按实际利率法确认（非票面利率）
- [ ] 利息调整（溢折价）摊销是否与G4-4利息测算表一致
- [ ] 应计利息是否单独列示且计算正确
- [ ] 摊余成本计量前提（G4-5业务模式+G4-6 SPPI）是否成立

### 三、减值与试算核对

- [ ] 预期信用损失是否计提（与G4-9/G4-10/G4-11勾稽）
- [ ] 债权投资减值准备是否单独列示
- [ ] 审定数合计是否与试算平衡表1501科目一致
- [ ] 所有AJE/RJE是否完整反映在审定表调整列

### 四、分类列报

- [ ] 一年内到期的债权投资是否重分类至一年内到期的非流动资产
- [ ] 债权投资分类（摊余成本）是否与G4-5/G4-6结论一致
- [ ] 关联方债权投资是否单独列示
- [ ] 审定表分类是否与附注披露一致

## risk_areas

### 高风险

1. **摊余成本计量错误**：未按实际利率法摊销溢折价，或摊余成本滚动不成立，导致资产和利息收入失真。
2. **ECL计提不足**：预期信用损失少提，虚增债权投资净额。
3. **期初期末不勾稽**：期初审定数与上年期末不一致，存在未授权调整。
4. **分类计量前提不足**：以摊余成本计量但业务模式/SPPI测试不支持，分类计量错误。
5. **审计调整遗漏或缺乏审批**：已确认调整未反映在审定表，或未经合伙人批准。

### 中风险

1. **明细与汇总不勾稽**：审定表合计与G4-2明细表不一致。
2. **利息调整摊销错误**：溢折价摊销与G4-4测算不一致。
3. **一年内到期未重分类**：一年内到期债权投资未正确重分类列示。

### 低风险

1. **审定表格式不规范**：列标题、行顺序、编号格式问题。
2. **底稿交叉索引不完整**：未与G4-2/G4-4/G4-10及试算平衡表建立索引。
3. **辅助说明不充分**：变动较大行项目未附说明。
