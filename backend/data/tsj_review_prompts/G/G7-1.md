# G7-1 长期股权投资审定表 复核提示词

## 概述

本提示词针对长期股权投资审定表（G7-1，科目1511，减值1512）的复核。长期股权投资涉及成本法与权益法两种核算方法，审定表须完整反映未审数→账项调整→重分类调整→审定数链路，并勾稽初始投资成本、被投资单位损益调整、商誉、减值准备（1512）及试算平衡表。审定表是本科目审计枢纽，成本法/权益法适用错误或损益调整遗漏将直接导致投资资产及投资收益重大错报。

**法规依据：**
- 《企业会计准则第2号——长期股权投资》
- 《企业会计准则第20号——企业合并》
- 《企业会计准则第33号——合并财务报表》
- 《中国注册会计师审计准则第1301号——审计证据》

## tips

1. **成本法/权益法区分是审定前提**：对子公司采用成本法，对合营/联营企业采用权益法，审定表须按核算方法分别列示，方法适用错误将导致损益确认基础错误。
2. **权益法下账面滚动**：权益法投资账面价值=初始成本±商誉调整+按持股比例确认的被投资单位净损益+其他综合收益变动-已分配现金股利-减值，审定表须逐项勾稽。
3. **期初期末承前启后**：期初审定数须等于上年期末审定数，任何差异须追溯至调整分录或会计政策变更。
4. **减值准备勾稽1512**：长期股权投资减值一经计提不得转回（成本法/权益法均如此），审定表减值信息须与G7-17减值测试一致。
5. **试算平衡表核对**：审定数合计须与试算平衡表1511科目审定数、减值与1512科目一致。
6. **调整完整性**：所有AJE/RJE须完整反映在审定表，审定数=未审数+AJE+RJE，遗漏任一笔即审定失真。

## checklist

### 一、核算方法与期初期末勾稽

- [ ] 各笔投资的核算方法（成本法/权益法）判断是否正确且有底稿支持
- [ ] 期初审定数是否等于上年期末审定数（承前启后）
- [ ] 权益法投资账面滚动是否勾稽被投资单位损益、OCI、现金股利
- [ ] 期末审定数是否等于期初审定数加本期增减（追加投资/损益确认/处置/减值）
- [ ] 是否存在期初数据被修改但未说明

### 二、试算平衡表与减值核对

- [ ] 审定表长期股权投资审定数合计是否与试算平衡表1511科目审定数一致
- [ ] 减值准备是否与试算平衡表1512科目一致（借贷方向核对）
- [ ] 减值信息是否与G7-17减值测试勾稽
- [ ] 减值一经计提未被转回（长期股权投资减值不得转回）

### 三、审计调整完整性

- [ ] 所有账项调整（AJE）是否完整反映在审定表调整列
- [ ] 所有重分类调整（RJE）是否完整反映
- [ ] 调整分录借贷方是否平衡
- [ ] 审定后金额是否等于未审数+AJE+RJE
- [ ] 建议但未调整的错报是否记录于未调整错报汇总表

### 四、分类列报

- [ ] 对子公司、合营、联营企业的投资是否分别列示
- [ ] 商誉是否正确列示（非同一控制下合并）
- [ ] 因丧失控制权转为金融资产/权益法的部分是否正确重分类
- [ ] 审定表分类是否与财务报表附注披露一致

## risk_areas

### 高风险

1. **核算方法适用错误**：应采用权益法却用成本法（或反之），导致投资收益确认基础错误，损益重大错报。
2. **权益法损益调整遗漏**：未按持股比例确认被投资单位净损益，或未抵销内部交易未实现利润，投资收益失真。
3. **减值违规转回**：长期股权投资减值一经计提不得转回，若审定表出现减值转回则属重大错误。
4. **期初期末不勾稽**：期初审定数与上年期末不一致，本期审定数失去基准。
5. **审计调整遗漏**：已确认调整未反映在审定表，审定数不真实。

### 中风险

1. **明细与汇总不勾稽**：审定表各行合计与G7-2明细表总计不一致。
2. **商誉列示错误**：非同一控制下合并商誉未单独列示或计算错误。
3. **现金股利处理错误**：权益法下收到现金股利未冲减账面价值，或成本法下未确认投资收益。
4. **试算平衡表与审定表不一致**：口径不一致意味存在未发现的调整遗漏。

### 低风险

1. **审定表格式不规范**：列标题、行顺序等格式问题不影响数据准确性。
2. **底稿交叉索引不完整**：未与明细表、减值测试、权益法计算建立索引。
3. **辅助说明不充分**：变动较大行项目未附说明。
