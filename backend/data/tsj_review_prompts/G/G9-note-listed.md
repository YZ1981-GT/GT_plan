# G9-note-listed 其他非流动金融资产附注披露 复核提示词（上市公司）

## 概述

本提示词针对其他非流动金融资产上市公司附注披露底稿（G9-note-listed）的复核，聚焦FVTPL非流动金融资产的分类披露、公允价值层次披露、第三层次公允价值调节披露、公允价值变动损益披露、以及流动性分类披露的充分性和准确性。其公允价值变动直接进损益，且常含第三层次资产，披露不充分将影响投资者对损益质量和估值风险的判断。

**法规依据：**
- 《企业会计准则第37号——金融工具列报》
- 《企业会计准则第22号——金融工具确认和计量》
- 《企业会计准则第39号——公允价值计量》

---

## tips

1. **分类披露FVTPL属性**：附注须明确其他非流动金融资产以公允价值计量且变动计入当期损益，并说明分类原因。
2. **公允价值层次强制披露**：须按第一/二/三层次披露公允价值，第三层次须披露估值技术、关键不可观察输入及调节表。
3. **第三层次调节表**：须披露第三层次资产的期初、购入、出售、计入损益金额、层次转换、期末的完整调节（与G9-5一致）。
4. **公允价值变动损益披露**：须披露本期计入损益的公允价值变动金额，与利润表勾稽。
5. **资产构成披露**：须披露其他非流动金融资产的构成（结构化产品/权益投资/衍生工具等）。
6. **附注勾稽底稿闭环**：附注金额须与G9-1审定表、G9-2明细表、G9-4公允价值测试、G9-5调节表形成闭环勾稽。

## checklist

### 一、分类与构成披露

- [ ] 是否明确披露FVTPL分类及分类原因
- [ ] 是否披露其他非流动金融资产的构成
- [ ] 期末余额是否等于审定表审定数
- [ ] 是否同时披露期末数和期初数（可比信息）

### 二、公允价值层次与调节

- [ ] 是否按第一/二/三层次披露公允价值
- [ ] 第三层次是否披露估值技术和关键不可观察输入
- [ ] 第三层次公允价值调节表是否完整（与G9-5一致）
- [ ] 层次间转移是否披露及说明原因

### 三、损益与流动性

- [ ] 本期计入损益的公允价值变动是否披露
- [ ] 公允价值变动损益是否与利润表勾稽
- [ ] 流动/非流动分类依据是否披露
- [ ] 附注各项金额是否与G9-1/G9-2/G9-4/G9-5勾稽

## risk_areas

### 高风险

1. **第三层次调节表不完整或不勾稽**：调节表要素缺失或与G9-5不一致，第三层次估值透明度不足。
2. **公允价值层次披露缺失**：未按层次披露或第三层次估值假设不披露，不满足CAS39要求。
3. **公允价值变动损益披露与利润表不一致**：附注披露的公允价值变动与利润表不勾稽。
4. **附注总额与审定表不一致**：附注期末余额与审定表审定数不一致。

### 中风险

1. **资产构成披露不清**：未清晰披露其他非流动金融资产构成。
2. **层次转换原因未披露**：层次间转移未说明原因。
3. **分类原因披露不足**：未说明FVTPL分类依据。

### 低风险

1. **披露格式不完全规范**：表格标题、列序、单位等格式细节。
2. **文字描述模板化**：估值方法描述照搬未结合企业实际。
3. **可比信息简略**：期初可比数据列示不完整。
