# G13-2 公允价值变动损益明细表复核提示词

## 概述

本提示词针对公允价值变动损益明细表（G13-2）的复核。该表按金融工具/衍生工具分项列示本期公允价值变动的构成、估值方法及变动金额，是审定表（G13-1）的支撑底稿。复核聚焦分项变动的估值依据、公允价值计量层次、变动率异常及与G1/G10的勾稽。

**法规依据：**
- 《企业会计准则第22号——金融工具确认和计量》
- 《企业会计准则第39号——公允价值计量》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **逐工具列示公允价值变动**：明细表须按每项金融工具/衍生工具列示期初公允价值、期末公允价值、本期变动及估值方法，来源不清的分项须追查估值底稿。
2. **公允价值变动=期末公允价值−期初公允价值−本期处置结转**：核对变动金额的计算逻辑，防止将处置已实现损益混入未实现变动。
3. **估值层次与输入须逐项核对**：Level 1核对活跃市场报价；Level 2核对可观察输入及估值模型；Level 3核对不可观察输入的合理性及敏感性（CAS39）。
4. **变动率异常须重点分析**：某工具公允价值变动较上期波动异常的，须结合市场行情、工具特性分析合理性，警惕估值操纵。
5. **分项合计回勾审定表**：明细各分项变动合计必须等于G13-1审定表公允价值变动损益合计。
6. **与G1/G10逐项勾稽**：明细分项应与交易性金融资产（G1）、交易性金融负债（G10）明细逐项对应。

## checklist

### 一、分项列示与计算

- [ ] 各工具是否列示期初/期末公允价值及本期变动
- [ ] 变动金额计算逻辑是否正确（剔除处置结转）
- [ ] 明细各分项变动合计是否等于G13-1审定表合计
- [ ] 是否覆盖所有FVTPL金融工具及衍生工具

### 二、估值依据

- [ ] 各工具估值层次（Level 1/2/3）是否列示
- [ ] Level 1是否核对活跃市场报价
- [ ] Level 2是否核对可观察输入及估值模型
- [ ] Level 3不可观察输入是否有合理依据及敏感性分析

### 三、变动分析

- [ ] 各工具公允价值变动较上期是否列示
- [ ] 变动异常的工具是否有合理性分析
- [ ] 是否结合市场行情、工具特性解释变动

### 四、勾稽与列报

- [ ] 明细分项是否与G1交易性金融资产明细逐项对应
- [ ] 明细分项是否与G10交易性金融负债明细逐项对应
- [ ] 明细分类是否与附注公允价值变动披露一致

## risk_areas

### 高风险

1. **Level 3估值输入无依据**：不可观察输入缺合理依据或敏感性分析，公允价值变动虚增/虚减。
2. **处置结转混入未实现变动**：将已实现处置损益计入未实现公允价值变动，重复或错误计量。
3. **分项合计与审定表不勾稽**：明细各分项变动合计与G13-1审定表存在无源差异。
4. **与G1/G10不对应**：明细分项无法与交易性金融资产负债明细逐项对应，存在遗漏或虚构。

### 中风险

1. **估值层次判断不当**：Level 3工具被列为Level 2，掩盖估值不确定性。
2. **变动率异常未分析**：公允价值变动异常波动缺合理性分析。
3. **估值模型不一致**：同类工具采用不一致的估值方法。

### 低风险

1. **明细粒度不足**：多个工具合并列示，不便逐项追溯。
2. **交叉索引缺失**：明细分项未标注对应估值底稿索引。
3. **可比信息不完整**：仅列本期分项变动，缺上期可比数据。
