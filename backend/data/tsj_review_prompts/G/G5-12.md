# G5-12 长期应收款凭证检查表复核提示词

## 适用底稿
长期应收款凭证检查表（G5-12），聚焦新增/收款/融资收益确认交易凭证核对完整性、样本选取合理性、检查比例达标性、异常交易标注充分性。

## tips

- 样本选取应与风险评估匹配，大额应收款、信用恶化、关联方长期应收款纳入必选样本
- 凭证核对须覆盖完整交易链（合同→资产交付/发货→资金收款→账务处理→摊销）
- 检查比例应满足《中国注册会计师审计准则第1314号——审计抽样》要求
- 新增交易核对应收总额、未实现融资收益、净额入账准确性
- 收款交易核对本金收回与融资收益分解是否正确
- 关注资产负债表日前后的收款交易（截止测试）
- 关联方长期应收款须核查利率公允性和商业实质
- 异常标注需明确类型（利率异常/无合同支撑/关联方非公允）

## checklist

### 高风险检查项

- [ ] 样本选取方法是否与识别的重大错报风险相匹配
- [ ] 大额长期应收款（超过重要性水平）是否100%全覆盖检查
- [ ] 信用恶化/关联方长期应收款是否纳入必选样本
- [ ] 凭证核对是否覆盖完整交易链（合同-交付-收款-账务-摊销）
- [ ] 新增交易应收总额/未实现融资收益/净额入账是否准确
- [ ] 收款交易本金收回与融资收益分解是否正确
- [ ] 资产负债表日前后收款交易是否实施截止测试
- [ ] 是否存在无合同支撑的长期应收款凭证
- [ ] 异常交易是否全部标注并记录异常类型

### 中风险检查项

- [ ] 抽样总体是否完整（涵盖全部新增/收款交易）
- [ ] 新增交易检查比例是否达标
- [ ] 收款交易检查比例是否达标
- [ ] 关联方长期应收款利率公允性是否核查
- [ ] 凭证日期与合同/收款日期是否一致，是否存在跨期
- [ ] 核对中发现的差异是否逐一追踪解决

### 低风险检查项

- [ ] 抽样参数（总体/置信水平/可容忍偏差）是否完整记录
- [ ] 样本选取过程是否可追溯
- [ ] 凭证检查结果记录格式是否规范统一
- [ ] 底稿索引与交叉引用是否完整（关联审定表/明细表/摊销表）

## risk_areas

### 高风险

1. **凭证造假风险**：虚构长期应收款交易凭证（伪造合同/交付单）虚增资产，须交叉核对合同和资金流水。
2. **截止性错误风险**：资产负债表日前后的收款交易未实施截止测试，跨期确认收款或融资收益。
3. **入账准确性风险**：新增交易应收总额/未实现融资收益/净额入账错误，或收款分解错误。
4. **关联方非公允风险**：关联方长期应收款利率显著偏离市场，未识别商业实质。

### 中风险

1. **检查比例不足风险**：实际检查比例低于计划水平，审计证据不充分。
2. **收款分解错误风险**：本金收回与融资收益分解错误。
3. **核对深度不够风险**：仅核对金额而忽略交易实质（合同/交付/收款时点）。

### 低风险

1. **记录不完整风险**：抽样参数、选取过程、核对结果记录不完整。
2. **索引缺失风险**：凭证检查底稿与审定表/明细表/摊销表交叉索引不完整。
3. **格式不规范风险**：检查结果记录格式不统一。

## 法规依据

- 《中国注册会计师审计准则第1314号——审计抽样》
- 《中国注册会计师审计准则第1301号——审计证据》
