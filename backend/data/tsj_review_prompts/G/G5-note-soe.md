# G5-note-soe 长期应收款附注披露复核提示词（国有企业）

## 概述

本提示词针对长期应收款国有企业附注披露底稿（G5-note-soe）的复核，聚焦国有企业特定的附注披露要求：基础披露（分类/未实现融资收益/减值三阶段/信用风险）之上，叠加国有资产监管相关披露——长期应收款合规性、对国有单位/政府的长期应收款、长账龄应收款的国资监管视角、以及与上市公司版本的差异关注点。

**法规依据：**
- 《企业会计准则第37号——金融工具列报》
- 《企业会计准则第21号——租赁》
- 《企业国有资产法》
- 《中央企业财务决算报告管理办法》

---

## tips

1. **国企长期应收款须披露合规性**：融资租赁/分期收款销售等长期应收款业务须符合国资委相关规定，附注须反映合规性。
2. **对国有单位/政府应收款须关注**：对其他国企或政府部门的长期应收款须单独说明，评估是否存在资金占用挂账。
3. **基础披露框架与上市版相同**：分类、未实现融资收益、减值三阶段、信用风险等基础披露一致，国企版增加国资监管信息。
4. **长账龄应收款的国有资产视角**：长期未收回应收款累积可能反映国有资产占用风险，须披露催收和处置。
5. **减值影响保值增值**：长期应收款减值损失对国有资本保值增值率的影响须评估。
6. **与上市版差异在监管层面**：国企版在基础披露基础上补充国资监管相关信息。

## checklist

### 一、基础披露完整性（与上市版共有）

- [ ] 长期应收款是否按类别分类披露
- [ ] 是否披露应收总额/未实现融资收益/减值准备/净额构成
- [ ] 净额合计是否等于G5-1审定表审定数
- [ ] 坏账准备是否按三阶段/存续期披露变动
- [ ] 期初数/期末数可比信息是否完整

### 二、国有资产监管相关披露

- [ ] 长期应收款业务是否符合国资委规定并披露合规性
- [ ] 对国有单位/政府的长期应收款是否单独披露
- [ ] 长账龄应收款是否单独披露金额、债务人及原因
- [ ] 长期应收款减值对国有资本保值增值的影响是否说明

### 三、关联方与资金占用披露（国企特定）

- [ ] 与控股股东及关联企业的长期应收款是否逐户列示
- [ ] 与同受国有控制企业的长期应收款是否披露
- [ ] 是否存在资金占用以长期应收款挂账并予以说明
- [ ] 大额长期应收款是否按国资委要求逐户披露

### 四、与上市版差异关注点

- [ ] 国企版是否在基础披露上增加国资监管信息
- [ ] 关联方范围是否扩展至同受国有控制企业
- [ ] 是否增加长账龄应收款催收/处置说明
- [ ] 决算报表长期应收款数据是否与本附注一致

## risk_areas

### 高风险

1. **资金占用挂账未披露**：对其他国企/政府长期应收款涉及资金占用未说明，可能掩盖国有资产问题。
2. **长账龄应收款未按国资要求披露**：长期未收回应收款未逐户说明原因和催收措施。
3. **基础披露与审定表不勾稽**：附注长期应收款净额与G5-1审定数不一致。

### 中风险

1. **合规性披露缺失**：长期应收款业务合规性未说明。
2. **保值增值影响未分析**：减值对国有资本保值增值影响未说明。
3. **关联方范围遗漏**：未纳入同受国有控制企业。

### 低风险

1. **披露格式未按决算模板**：附注格式与国资委决算模板细微差异。
2. **可比信息追溯不完整**：历史趋势分析不足。
3. **催收措施说明简略**：长账龄应收款催收进展说明不充分。
