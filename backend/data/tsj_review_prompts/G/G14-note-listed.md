# G14-note-listed 信用减值损失附注披露复核提示词（上市公司）

## 概述

本提示词针对信用减值损失上市公司附注披露底稿（G14-note-listed）的复核，聚焦信用减值损失按金融资产类别分类披露、ECL模型关键假设披露、与利润表勾稽及CAS37对预期信用损失披露的要求。

**法规依据：**
- 《企业会计准则第22号——金融工具确认和计量》
- 《企业会计准则第37号——金融工具列报》
- 《企业会计准则第30号——财务报表列报》

---

## tips

1. **信用减值损失按类别分类披露**：附注须区分应收账款、其他应收款、债权投资、其他债权投资、合同资产等各金融资产的信用减值损失，各分项合计须等于利润表信用减值损失。
2. **ECL模型关键假设是CAS37强制披露**：须披露预期信用损失计量方法（一般方法/简化方法）、违约定义、损失率假设、前瞻性信息及关键参数。
3. **本期计提/转回须与减值准备变动勾稽**：附注信用减值损失本期计提/转回须与各金融资产减值准备变动表勾稽。
4. **三阶段ECL信息须披露**：须披露按信用风险阶段（三阶段）划分的账面金额及减值准备。
5. **与利润表勾稽**：附注信用减值损失合计=利润表信用减值损失。
6. **附注须与审定表闭环勾稽**：披露信用减值损失各分项合计必须与G14-1审定数、G14-2明细勾稽。

## checklist

### 一、分类披露

- [ ] 信用减值损失是否按金融资产类别分类披露
- [ ] 各分项合计是否等于利润表信用减值损失
- [ ] 各分项是否同时披露本期数和上期可比数
- [ ] 分类方法是否与会计政策一致

### 二、ECL模型披露

- [ ] 是否披露预期信用损失计量方法（一般/简化）
- [ ] 是否披露违约定义、损失率假设、前瞻性信息
- [ ] 是否披露ECL关键参数及重大判断
- [ ] 是否披露按三阶段划分的账面金额及减值准备

### 三、勾稽核对

- [ ] 附注信用减值损失是否与G14-1审定数勾稽
- [ ] 本期计提/转回是否与各金融资产减值准备变动表勾稽
- [ ] 附注是否与利润表一致

### 四、上市公司额外要求

- [ ] 是否披露信用风险管理目标与政策
- [ ] 重大转回是否披露原因
- [ ] ECL模型变更/参数调整是否披露影响

## risk_areas

### 高风险

1. **ECL模型关键假设未披露**：未披露违约定义、损失率、前瞻性调整因子，不满足CAS37要求。
2. **附注与利润表不勾稽**：信用减值损失分项合计与利润表不一致。
3. **三阶段信息缺失**：未按信用风险阶段披露账面金额及减值准备。
4. **附注与审定表不一致**：披露信用减值损失与G14-1审定数存在差异。

### 中风险

1. **减值准备变动不勾稽**：附注本期计提/转回与减值准备变动表不一致。
2. **转回原因不充分**：重大转回未披露原因，投资者无法评估合理性。
3. **可比信息缺失**：仅披露本期数，未列上期可比数。

### 低风险

1. **披露格式不规范**：表格列序、单位等格式细节问题。
2. **文字说明模板化**：信用风险管理政策照搬会计政策原文。
3. **参数变更说明简略**：ECL参数调整仅提及未量化影响。
