# G2-8 应收利息凭证检查表复核提示词

## 适用底稿
应收利息凭证检查表（G2-8），含借方（计提）区块与贷方（收回）区块，聚焦凭证核对完整性、样本选取合理性、检查比例达标性、异常交易标注充分性。

## tips

- 样本选取应与风险评估匹配，大额利息、长账龄、关联方利息纳入必选样本
- 借方（计提）凭证核对计提依据（本金/利率/期间）与计算准确性
- 贷方（收回）凭证核对实际收款至银行流水，验证收回真实性
- 检查比例应满足《中国注册会计师审计准则第1314号——审计抽样》要求
- 关注跨期计提（资产负债表日前后）的截止性
- 关联方利息须核查利率公允性和商业实质
- 异常标注需明确类型（利率异常/计提无本金支撑/收回无流水）

## checklist

### 高风险检查项

- [ ] 样本选取方法是否与识别的重大错报风险相匹配
- [ ] 大额应收利息（超过重要性水平）是否100%全覆盖检查
- [ ] 长账龄/关联方利息是否纳入必选样本
- [ ] 借方计提凭证是否核对本金/利率/计息期间及计算准确性
- [ ] 贷方收回凭证是否核对至银行流水验证实际收款
- [ ] 计提利息是否有对应本金合同支撑
- [ ] 资产负债表日前后利息计提是否实施截止测试
- [ ] 异常交易是否全部标注并记录异常类型

### 中风险检查项

- [ ] 抽样总体是否完整（涵盖全部计提和收回交易）
- [ ] 借方（计提）检查比例是否达标
- [ ] 贷方（收回）检查比例是否达标
- [ ] 关联方利息利率公允性是否核查
- [ ] 凭证日期与计息期间是否一致，是否存在跨期
- [ ] 核对中发现的差异是否逐一追踪解决

### 低风险检查项

- [ ] 抽样参数（总体/置信水平/可容忍偏差）是否完整记录
- [ ] 样本选取过程是否可追溯
- [ ] 凭证检查结果记录格式是否规范统一
- [ ] 底稿索引与交叉引用是否完整（关联审定表/明细表/利息测算表）

## risk_areas

### 高风险

1. **虚构利息计提风险**：无本金合同支撑的利息计提凭证，虚增资产和利息收入，须核对本金合同。
2. **收回真实性风险**：贷方收回凭证无银行流水支撑，可能虚假冲减或掩盖坏账。
3. **截止性错误风险**：资产负债表日前后利息计提未实施截止测试，跨期确认利息收入。
4. **关联方利率不公允风险**：关联方利息利率显著偏离市场，未识别商业实质。

### 中风险

1. **检查比例不足风险**：实际检查比例低于计划水平，审计证据不充分。
2. **计提依据不足风险**：利息计提的本金/利率/期间依据核对不充分。
3. **核对深度不够风险**：仅核对金额而忽略计提依据的合理性。

### 低风险

1. **记录不完整风险**：抽样参数、选取过程、核对结果记录不完整。
2. **索引缺失风险**：凭证检查底稿与审定表/明细表/利息测算表交叉索引不完整。
3. **格式不规范风险**：检查结果记录格式不统一。

## 法规依据

- 《中国注册会计师审计准则第1314号——审计抽样》
- 《中国注册会计师审计准则第1301号——审计证据》
- 《中国注册会计师审计准则第1141号——财务报表审计中与舞弊相关的责任》
