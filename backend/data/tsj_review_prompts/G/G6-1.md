# G6-1 其他债权投资审定表 复核提示词

## 概述

本提示词针对其他债权投资审定表（G6-1，科目1503）的复核。其他债权投资分类为以公允价值计量且其变动计入其他综合收益（FVOCI）的债务工具，审定表须完整反映未审数→账项调整（AJE）→重分类调整（RJE）→审定数链路，并勾稽公允价值、其他综合收益累计额、预期信用损失准备（G6-3）及试算平衡表1503科目。审定表是本科目审计枢纽，勾稽断裂或分类错误将直接影响资产及所有者权益列报。

**法规依据：**
- 《企业会计准则第22号——金融工具确认和计量》
- 《企业会计准则第37号——金融工具列报》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **FVOCI计量属性决定审定逻辑**：其他债权投资以公允价值列示，公允价值变动计入其他综合收益，审定数须同时勾稽摊余成本、公允价值调整和OCI累计额三条线，任一断裂即审定失真。
2. **期初期末承前启后**：期初审定数须等于上年期末审定数，OCI累计余额同样须连续，任何期初差异须追溯至会计政策变更或前期差错更正。
3. **减值准备勾稽G6-3**：其他债权投资的预期信用损失准备计入OCI（不冲减账面价值），审定表减值信息须与G6-3坏账准备明细表逐项一致。
4. **试算平衡表是第一道防线**：审定数合计须与试算平衡表1503科目审定数完全一致，差异意味着存在未记录调整或汇总错误。
5. **处置转损益核对**：处置时原计入OCI的累计公允价值变动应转入投资收益（损益），审定表须体现该重分类，避免OCI与损益双计或漏计。
6. **调整完整性**：所有已确认AJE/RJE须完整反映在审定表对应列，审定数=未审数+AJE+RJE，遗漏任一笔即审定数不可靠。

## checklist

### 一、期初期末与OCI勾稽

- [ ] 期初审定数是否等于上年期末审定数（承前启后）
- [ ] 其他综合收益累计余额期初是否与上年期末一致
- [ ] 期末审定数是否等于期初审定数加本期增减（购入/出售/公允价值变动）
- [ ] 公允价值变动金额是否与OCI变动金额勾稽一致
- [ ] 是否存在期初数据被修改但未做说明的情况

### 二、试算平衡表与减值核对

- [ ] 审定表其他债权投资审定数合计是否与试算平衡表1503科目审定数一致
- [ ] 减值准备信息是否与G6-3坏账准备明细表期末余额一致
- [ ] 减值准备是否正确计入OCI而非冲减账面价值
- [ ] 试算平衡表未审数、调整数与审定表对应列是否一致

### 三、审计调整完整性

- [ ] 所有账项调整（AJE）是否完整反映在审定表调整列
- [ ] 所有重分类调整（RJE）是否完整反映在审定表重分类列
- [ ] 调整分录借贷方是否平衡
- [ ] 审定后金额是否等于未审数+AJE+RJE
- [ ] 建议但未调整的错报是否记录于未调整错报汇总表

### 四、分类列报与处置

- [ ] FVOCI分类判断（业务模式既收取合同现金流又出售+SPPI测试）是否有底稿支持
- [ ] 处置部分原OCI累计公允价值变动是否转入投资收益
- [ ] 一年内到期部分是否正确列报
- [ ] 审定表分类是否与财务报表附注披露一致

## risk_areas

### 高风险

1. **期初期末不勾稽**：期初审定数或OCI累计余额与上年期末不一致，导致本期审定数失去基准，可能存在未授权调整。
2. **审计调整遗漏**：已确认调整分录未反映在审定表，审定数不真实，可能掩盖重大错报。
3. **减值计入方向错误**：其他债权投资减值准备错误冲减账面价值而非计入OCI，导致资产与OCI双重错报。
4. **处置未转损益**：处置时原计入OCI的累计公允价值变动未重分类至投资收益，损益与OCI同时失真。
5. **试算平衡表与审定表不一致**：两者口径不一致意味存在未发现的汇总错误或调整遗漏。

### 中风险

1. **明细与汇总不勾稽**：审定表各行合计与G6-2明细表总计不一致，可能存在明细遗漏或重复。
2. **FVOCI分类缺乏依据**：业务模式判断或SPPI测试底稿不充分，分类结论无支持。
3. **审定表与附注口径不一致**：审定表分类与附注披露分类不一致，影响信息一致性。
4. **重分类方向错误**：RJE借贷方向颠倒导致审定数偏离真实值。

### 低风险

1. **审定表格式不规范**：列标题、行顺序等格式问题不影响数据准确性但影响可读性。
2. **底稿交叉索引不完整**：未与试算平衡表、明细表、减值明细建立完整索引引用。
3. **辅助说明不充分**：变动较大行项目未附简要说明，增加复核理解难度。
