# G5-11 长期应收款转回核销检查复核提示词

## 概述

本提示词针对长期应收款减值准备转回核销检查底稿（G5-11）的复核，聚焦长期应收款减值准备本期转回和核销的合理性、证据充分性、审批完整性及会计处理正确性。转回和核销直接影响信用减值损失和资产净额，是减值审计中易被操纵的领域。

**法规依据：**
- 《企业会计准则第22号——金融工具确认和计量》
- 《企业会计准则第37号——金融工具列报》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **转回须有信用改善证据**：减值准备转回须由债务人/承租人信用状况实质改善支撑（还款、担保增强、租赁物价值回升）。
2. **转回不得超原计提**：转回后长期应收款账面价值不得超过假设无减值情况下的摊余成本。
3. **核销须有充分证据**：核销须有债务人破产、清算、确实无法收回等客观证据，且经适当审批。
4. **核销后追偿须记录**：核销不等于放弃债权，后续追偿及收回须表外记录或披露。
5. **转回核销与阶段联动**：转回通常伴随阶段回迁（第三→第二/一），须与G5-9阶段划分一致。
6. **转回核销联动损益与审定表**：转回冲减信用减值损失，核销冲减减值准备，须与G5-1审定表、G5-3坏账明细勾稽。

---

## checklist

### 一、转回检查

- [ ] 减值准备转回是否有信用改善的客观证据
- [ ] 转回后账面价值是否未超原无减值摊余成本
- [ ] 转回是否伴随阶段回迁（与G5-9一致）
- [ ] 转回是否冲减信用减值损失且金额正确

### 二、核销检查

- [ ] 核销是否有充分客观证据（破产/清算/无法收回）
- [ ] 核销是否经适当层级审批
- [ ] 核销会计处理是否正确（冲减减值准备）
- [ ] 核销后追偿是否表外记录/披露

### 三、勾稽与合理性

- [ ] 转回核销是否与G5-12凭证检查勾稽
- [ ] 转回核销是否与G5-3坏账明细/G5-1审定表变动一致
- [ ] 本期转回是否与信用减值损失勾稽
- [ ] 是否存在无据转回或不当核销调节利润

## risk_areas

### 高风险

1. **无据转回调节利润**：无信用改善证据即转回减值准备，虚增利润和资产净额。
2. **核销缺乏证据或审批**：核销无客观证据或未经审批，可能掩盖资产损失或利润操纵。
3. **转回超原计提**：转回后账面价值超过原无减值摊余成本，违反准则。

### 中风险

1. **转回与阶段不联动**：减值转回但阶段未回迁，逻辑矛盾。
2. **核销后追偿未记录**：核销债权后续追偿权未表外记录/披露。
3. **转回核销与坏账明细不勾稽**：G5-11与G5-3/G5-1不一致。

### 低风险

1. **检查底稿记录不充分**：转回核销证据、审批记录简略。
2. **交叉索引不完整**：G5-11未与G5-1/G5-3/G5-9建立索引。
