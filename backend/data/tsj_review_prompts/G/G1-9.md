# G1-9 交易性金融资产分类测试复核提示词

## 概述

本提示词针对交易性金融资产分类测试底稿（G1-9）的复核，聚焦金融资产分类结论的综合判定：结合业务模式（G1-8）与合同现金流特征（G1-10 SPPI），确定金融资产应分类为FVTPL、以摊余成本计量或以公允价值计量且其变动计入其他综合收益（FVOCI）。分类决定后续计量方法，分类错误是CAS22下的高风险错报。

**法规依据：**
- 《企业会计准则第22号——金融工具确认和计量》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **分类=业务模式+合同现金流双重测试**：FVTPL分类须由业务模式（以出售为目标）或SPPI测试未通过共同支撑，测试逻辑须完整。
2. **FVTPL是默认分类**：不满足摊余成本或FVOCI条件的金融资产默认分类为FVTPL，须验证是否恰当。
3. **权益工具投资的分类特殊**：非交易性权益工具可指定为FVOCI（不可撤销），交易性权益工具应为FVTPL，须核对指定情况。
4. **指定为FVTPL须消除会计错配**：将本可摊余成本/FVOCI的资产指定为FVTPL须以消除会计错配为目的，且指定不可撤销。
5. **分类测试须逐组合执行**：分类结论应针对各金融资产组合分别测试，避免笼统判定。
6. **分类结论联动审定与披露**：G1-9结论须与G1-1审定表、附注金融工具分类披露一致。

## checklist

### 一、分类逻辑完整性

- [ ] 分类结论是否结合业务模式（G1-8）和SPPI（G1-10）双重测试
- [ ] FVTPL分类是否有业务模式或SPPI测试结果支撑
- [ ] 权益工具是否区分交易性（FVTPL）与指定FVOCI
- [ ] 指定为FVTPL是否以消除会计错配为目的且不可撤销

### 二、分类判定核对

- [ ] 分类是否逐组合/逐类资产执行测试
- [ ] 债务工具分类是否同时考虑业务模式和SPPI结果
- [ ] 是否存在为达特定损益结果的分类操纵
- [ ] 本期是否发生分类变更，依据是否充分

### 三、分类联动

- [ ] G1-9结论是否与G1-8业务模式一致
- [ ] G1-9结论是否与G1-10 SPPI测试一致
- [ ] 分类结论是否与G1-1审定表、附注披露一致

## risk_areas

### 高风险

1. **分类结论与测试脱节**：分类结论未由业务模式和SPPI测试共同支撑，分类依据不足。
2. **分类操纵损益**：通过不当分类将损益从当期转移或递延，规避公允价值波动影响。
3. **权益工具指定不当**：交易性权益工具误指定为FVOCI以规避损益波动，或指定可撤销。

### 中风险

1. **分类未逐组合测试**：笼统判定所有资产分类，未针对不同组合分别测试。
2. **分类变更依据不足**：本期分类变更无充分依据。

### 低风险

1. **测试记录不充分**：分类判定逻辑和证据记录简略。
2. **交叉索引不完整**：G1-9未与G1-8/G1-10/G1-1建立索引。
