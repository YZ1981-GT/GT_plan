# G7-2 长期股权投资明细表 复核提示词

## 概述

本提示词针对长期股权投资明细表（G7-2）的复核。明细表逐户列示各被投资单位名称、持股比例、核算方法、初始投资成本、本期增减、商誉、被投资单位损益调整、现金股利、减值准备及期末账面价值，是审定表（G7-1）和附注披露的数据来源。复核聚焦逐户核算方法准确性、持股比例与账面价值勾稽、权益法调整完整性、以及明细合计与审定表的勾稽。

**法规依据：**
- 《企业会计准则第2号——长期股权投资》
- 《企业会计准则第33号——合并财务报表》

---

## tips

1. **明细合计勾稽审定表**：明细表各户期末账面价值合计须等于G7-1审定表审定数，减值合计须与减值明细一致。
2. **持股比例决定核算方法**：一般控制（>50%或实质控制）用成本法、重大影响或共同控制（通常20%-50%）用权益法，持股比例变动可能触发方法转换。
3. **权益法逐户滚动**：权益法各户账面价值滚动须体现按比例确认的净损益、OCI变动、现金股利冲减。
4. **成本法保持成本**：成本法投资账面价值保持初始成本不变（除减值/追加/处置），收到股利确认投资收益。
5. **商誉不摊销但测减值**：非同一控制下合并形成的商誉不摊销，每年测试减值。
6. **关注比例异动户**：持股比例本期发生变动的户可能涉及方法转换、丧失控制权或分步取得，须重点核查会计处理。

## checklist

### 一、逐户信息准确性

- [ ] 各户被投资单位名称、持股比例、核算方法是否准确
- [ ] 初始投资成本是否与出资协议/交割凭证一致
- [ ] 本期增减（追加/减少/处置）是否有依据
- [ ] 持股比例变动户是否评估方法转换或丧失控制权

### 二、核算方法处理

- [ ] 权益法各户账面滚动是否勾稽净损益、OCI、现金股利
- [ ] 成本法各户账面价值是否保持成本（除减值/追加/处置）
- [ ] 成本法收到现金股利是否确认投资收益
- [ ] 权益法收到现金股利是否冲减账面价值
- [ ] 商誉是否单独列示且不摊销

### 三、减值与勾稽

- [ ] 各户减值准备是否单独列示且与G7-17减值测试一致
- [ ] 减值是否未被违规转回
- [ ] 明细合计（账面价值/减值）是否与G7-1审定表勾稽
- [ ] 是否存在明细遗漏或重复列示

## risk_areas

### 高风险

1. **核算方法逐户错误**：个别户方法适用错误，损益确认基础错误。
2. **权益法调整逐户遗漏**：某户未按比例确认损益或未冲减现金股利，账面价值失真。
3. **持股比例变动会计处理错误**：分步取得/丧失控制权/方法转换的会计处理错误，重大错报。
4. **明细与审定表不勾稽**：明细合计与G7-1审定数不一致。

### 中风险

1. **商誉计算或列示错误**：合并商誉未单独列示或初始计量错误。
2. **成本法误确认公允价值变动**：成本法投资错误按公允价值调整账面。
3. **减值逐户不一致**：明细减值与减值测试底稿不一致。

### 低风险

1. **明细列示不完整**：缺少统一社会信用代码、注册资本等辅助信息。
2. **索引引用缺失**：未与出资协议、被投资单位财报、减值测试建立索引。
3. **精度不统一**：持股比例、金额精度不一致。
