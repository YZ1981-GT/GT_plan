# G9-2 其他非流动金融资产明细表 复核提示词

## 概述

本提示词针对其他非流动金融资产明细表（G9-2）的复核。明细表逐项列示各笔金融资产的名称、类型、取得成本、公允价值、公允价值变动、以及本期确认的公允价值变动损益，是审定表（G9-1）和附注披露的数据来源。复核聚焦逐项公允价值计量、公允价值变动进损益的正确性、以及明细合计与审定表的勾稽。

**法规依据：**
- 《企业会计准则第22号——金融工具确认和计量》
- 《企业会计准则第37号——金融工具列报》

---

## tips

1. **明细合计勾稽审定表**：明细各笔期末公允价值合计须等于G9-1审定数，公允价值变动损益合计须与利润表勾稽。
2. **公允价值来源分层**：区分活跃市场报价（第一层次）、可观察输入（第二层次）、不可观察输入（第三层次），第三层次须重点核查估值。
3. **公允价值变动进损益**：每笔公允价值变动=期末公允价值-（取得成本+期初累计公允价值变动），差额全部进当期损益。
4. **交易费用进损益**：FVTPL资产的取得交易费用计入当期损益，不计入初始成本（区别于FVOCI）。
5. **资产类型多样**：其他非流动金融资产可能包含结构化产品、非流动权益投资、衍生工具等，须按类型区分计量。
6. **关注非活跃资产**：缺乏活跃市场的资产（如结构化产品、非上市权益）须重点核查估值方法和关键假设。

## checklist

### 一、逐项计量

- [ ] 各笔金融资产名称、类型、取得日期是否准确
- [ ] 取得交易费用是否计入当期损益（FVTPL不计入成本）
- [ ] 公允价值来源是否明确分层
- [ ] 第三层次估值方法和假设是否有依据

### 二、公允价值变动与损益

- [ ] 公允价值变动是否计入当期损益（不进OCI）
- [ ] 公允价值变动损益合计是否与利润表勾稽
- [ ] 各笔公允价值变动计算是否正确
- [ ] 处置损益是否正确确认

### 三、勾稽

- [ ] 明细合计（公允价值/损益）是否与G9-1审定表勾稽
- [ ] 是否存在明细遗漏或重复列示
- [ ] 资产类型划分是否合理

## risk_areas

### 高风险

1. **公允价值高估**：第三层次估值缺乏依据或采用管理层单方假设，公允价值高估、损益虚增。
2. **公允价值变动计入OCI**：将FVTPL资产的公允价值变动错误计入OCI而非损益。
3. **明细与审定表不勾稽**：明细合计与G9-1审定数不一致。

### 中风险

1. **交易费用处理错误**：FVTPL资产交易费用错误计入初始成本（应进损益）。
2. **资产类型划分不当**：结构化产品/衍生工具等未按类型正确计量。
3. **公允价值变动计算错误**：累计公允价值变动滚动错误。

### 低风险

1. **明细列示不完整**：缺少产品代码、发行方信息等。
2. **索引引用缺失**：未与合同、估值报告建立索引。
3. **精度不统一**：金额精度不一致。
