# G2-7 应收利息坏账准备测算复核提示词

## 概述

本提示词针对应收利息坏账准备测算表（G2-7）的复核，聚焦预期信用损失（ECL）的计量：单项计提、账龄组合、其他组合的划分，违约概率与损失率的合理性，前瞻性信息的运用。应收利息作为金融资产须按CAS22计量预期信用损失，测算方法和参数是减值审计的核心。

**法规依据：**
- 《企业会计准则第22号——金融工具确认和计量》
- 《企业会计准则第37号——金融工具列报》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **ECL计量方法须适当**：应收利息应按预期信用损失模型计量，单项重大或信用恶化的须单项评估，其余按组合评估。
2. **组合划分须有共同风险特征**：账龄组合、债务人类型组合等划分须基于共同信用风险特征，划分标准清晰。
3. **损失率须有数据支撑**：组合损失率应基于历史损失经验并结合前瞻性调整，参数须有依据。
4. **单项计提须逐笔评估**：信用减值的单项应收利息须逐笔评估预计可收回金额和减值损失。
5. **前瞻性信息须运用**：ECL计量须纳入前瞻性宏观信息（如GDP、行业景气）对损失率的调整。
6. **测算结果联动坏账明细**：G2-7测算的坏账准备须与G2-3坏账准备明细、G2-1审定表勾稽。

## checklist

### 一、计量方法与组合划分

- [ ] ECL计量方法是否适当（单项/组合）
- [ ] 单项计提对象（重大/信用恶化）是否恰当识别
- [ ] 组合划分是否基于共同信用风险特征
- [ ] 组合划分标准是否清晰、前后一致

### 二、参数合理性

- [ ] 组合损失率是否基于历史损失经验
- [ ] 损失率是否结合前瞻性信息调整
- [ ] 违约概率/违约损失率参数是否有数据支撑
- [ ] 单项减值的可收回金额估计是否合理

### 三、测算与勾稽

- [ ] 单项+组合计提坏账准备合计是否正确
- [ ] G2-7测算结果是否与G2-3坏账准备明细勾稽
- [ ] 测算结果是否与G2-1审定表应收利息坏账准备一致
- [ ] 本期计提净额是否与利润表信用减值损失勾稽

## risk_areas

### 高风险

1. **ECL计量不足**：损失率或违约概率人为压低，坏账准备计提不足，虚增资产净额。
2. **组合划分不当规避减值**：将高风险利息划入低损失率组合，规避充分计提。
3. **前瞻性信息缺失或操纵**：未纳入前瞻性信息，或操纵前瞻性调整以调节减值。

### 中风险

1. **损失率缺乏数据支撑**：组合损失率无历史数据基础，参数主观。
2. **单项评估不充分**：信用减值的单项利息未逐笔评估可收回金额。
3. **测算与坏账明细不勾稽**：G2-7与G2-3不一致。

### 低风险

1. **测算底稿记录不充分**：ECL模型参数、数据来源记录简略。
2. **交叉索引不完整**：G2-7未与G2-1/G2-3建立索引。
