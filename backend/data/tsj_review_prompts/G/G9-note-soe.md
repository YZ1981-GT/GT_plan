# G9-note-soe 其他非流动金融资产附注披露 复核提示词（国有企业）

## 概述

本提示词针对其他非流动金融资产国有企业附注披露底稿（G9-note-soe）的复核，聚焦国有企业特定的附注披露要求：在FVTPL基础披露（分类/公允价值层次/第三层次调节/损益）之上，增加金融投资合规性、投资对国有资本保值增值的影响、结构化产品风险披露、以及国资委财务决算报告补充要求。国有企业的金融投资（尤其结构化产品/理财）须符合国资监管对非主业金融投资的限制。

**法规依据：**
- 《企业会计准则第37号——金融工具列报》
- 《企业会计准则第22号——金融工具确认和计量》
- 《企业国有资产法》
- 《中央企业财务决算报告管理办法》

---

## tips

1. **国企附注双层要求**：既满足CAS37/CAS39通用披露（分类/公允价值层次/第三层次调节/损益），又满足国资委财务决算报告的额外披露要求。
2. **金融投资合规**：结构化产品/理财/信托等金融投资须符合国资委对非主业金融业务的监管要求，附注宜说明合规性。
3. **重大投资决策**：大额金融投资须经"三重一大"决策，附注宜说明本期重大投资的决策审批情况。
4. **保值增值视角**：公允价值下跌导致的损失可能被视为国有资产减值/流失风险，须说明成因及应对。
5. **第三层次估值防高估**：结构化产品/非上市资产估值须客观依据，防止高估国有资产虚增损益。
6. **决算勾稽**：附注数据须与年度财务决算报表一致，内部投资抵销须完整。

## checklist

### 一、基础披露完整性（与上市版共有）

- [ ] 是否明确披露FVTPL分类及分类原因
- [ ] 公允价值是否按第一/二/三层次披露
- [ ] 第三层次公允价值调节表是否完整
- [ ] 本期计入损益的公允价值变动是否披露
- [ ] 附注期末余额是否与审定表审定数一致
- [ ] 期初/期末可比信息是否完整

### 二、金融投资合规披露

- [ ] 结构化产品/理财等金融投资是否符合国资委非主业监管要求
- [ ] 大额金融投资是否经"三重一大"集体决策
- [ ] 是否披露投资对手方是否为关联方及交易公允性
- [ ] 是否存在超授权额度或违规金融投资并予以说明

### 三、风险与保值增值披露

- [ ] 结构化产品底层资产风险和刚性兑付安排是否披露
- [ ] 公允价值下跌损失是否说明成因及应对
- [ ] 公允价值变动对国有资本保值增值率的影响是否说明
- [ ] 第三层次估值是否有客观独立依据（防高估）

### 四、决算披露

- [ ] 附注数据是否与年度财务决算报表一致
- [ ] 集团合并层面内部投资抵销是否完整
- [ ] 金融投资中属于"不良/风险资产"的部分是否单独披露
- [ ] 与上市版相比是否增加了国资监管补充信息

## risk_areas

### 高风险

1. **违规金融投资未披露**：结构化产品/理财投资违反国资委非主业监管要求且未披露，存在合规风险。
2. **重大投资未经决策披露**：大额金融投资未经"三重一大"或未披露决策过程。
3. **第三层次高估国有资产**：结构化产品估值缺乏客观依据导致资产及损益虚增。
4. **附注与决算/审定表不勾稽**：附注数据与决算报表或审定表不一致。

### 中风险

1. **底层资产风险披露不足**：结构化产品底层风险和刚性兑付安排未充分披露。
2. **关联方投资公允性未披露**：投资对手方为关联方但未披露公允性。
3. **第三层次调节/损益披露不完整**：基础披露维度缺失。

### 低风险

1. **披露格式未按决算模板**：附注格式与国资委决算报表模板有细微差异。
2. **保值增值影响分析简略**：仅提及影响未量化分析。
3. **历史趋势追溯不完整**：投资变动趋势分析覆盖年限不足。
