# G2-note-listed 应收利息附注披露复核提示词（上市公司）

## 概述

本提示词针对应收利息上市公司附注披露底稿（G2-note-listed）的复核，聚焦上市公司财务报表附注中应收利息相关披露：分类构成（按利息来源）、账龄披露、坏账准备变动、CAS37金融工具列报要求、关联方应收利息单独披露、以及重大应收利息可收回性说明。

**法规依据：**
- 《企业会计准则第37号——金融工具列报》
- 《企业会计准则第22号——金融工具确认和计量》
- 《企业会计准则第36号——关联方披露》
- 《公开发行证券的公司信息披露编报规则第15号——财务报告的一般规定》

---

## tips

1. **应收利息须按来源分类披露**：附注应按债权投资利息、存款利息、借款利息、往来款利息等来源分类披露，各类合计勾稽总额。
2. **分类合计与审定表勾稽**：附注应收利息期末余额合计须等于G2-1审定表审定数。
3. **坏账准备变动表须完整**：期初/计提/转回/核销/期末须完整，与G2-3坏账准备明细勾稽。
4. **信用风险披露**：CAS37要求披露应收利息的信用风险敞口、ECL计量方法和关键参数。
5. **关联方应收利息单独披露**：关联方应收利息须按CAS36单独列示关联方名称、关系、金额、坏账准备。
6. **重大或长账龄利息须说明**：重大应收利息或长期未收回利息的可收回性须结合G2-6说明。

## checklist

### 一、分类与账龄披露

- [ ] 应收利息是否按来源分类披露（债权投资/存款/借款/往来款）
- [ ] 各类别合计是否等于G2-1审定表审定数
- [ ] 是否同时披露期末数和期初数
- [ ] 账龄披露（如适用）是否与G2-2/G2-6一致

### 二、坏账准备与信用风险披露

- [ ] 坏账准备变动表是否完整（期初/计提/转回/核销/期末）
- [ ] 变动表是否与G2-3勾稽
- [ ] 本期计提是否与信用减值损失一致
- [ ] 是否披露信用风险敞口和ECL计量方法/关键参数

### 三、关联方与重大项目披露

- [ ] 关联方应收利息是否单独披露（名称/关系/金额/坏账准备）
- [ ] 重大应收利息可收回性是否说明
- [ ] 长期未收回利息是否披露原因及催收措施
- [ ] 附注分类是否与审定表一致

## risk_areas

### 高风险

1. **附注总额与审定表不一致**：附注应收利息合计与G2-1审定数不符，属重大数据勾稽错误。
2. **坏账准备变动表不勾稽**：变动表各项不成立或与G2-3不一致。
3. **关联方应收利息未单独披露**：混入一般项目，违反CAS36要求。

### 中风险

1. **信用风险披露不充分**：未披露ECL计量方法和关键参数。
2. **来源分类不完整**：仅笼统披露未按利息来源分类。
3. **可比信息缺失**：仅披露期末数据未披露期初可比数据。

### 低风险

1. **披露格式不规范**：表格标题、列序、单位格式细节问题。
2. **文字描述模板化**：信用风险政策照搬会计政策原文。
3. **长账龄利息说明简略**：可收回性说明不够充分。
