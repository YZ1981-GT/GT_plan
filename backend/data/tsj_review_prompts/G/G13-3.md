# G13-3 公允价值变动损益调整分录复核提示词

## 概述

本提示词针对公允价值变动损益调整分录（G13-3）的复核，含账项调整（AJE）、重分类调整（RJE）及未调整错报（SUD）评估。复核须验证每笔调整有证据、借贷平衡、完整反映到G13-1审定表，并同步试算平衡表。

**法规依据：**
- 《企业会计准则第22号——金融工具确认和计量》
- 《企业会计准则第39号——公允价值计量》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **AJE影响损益、RJE仅影响列报**：公允价值变动损益的AJE调整损益金额（如更正估值、补计变动），RJE仅涉及列报（如公允价值变动损益与投资收益之间的重分类），不得以RJE掩盖损益错报。
2. **调整须与G13-1审定表逐笔勾稽**：审定表调整列金额必须与G13-3已确认分录逐笔一致。
3. **估值调整须有证据**：更正公允价值估值的调整须有第三方估值/市场报价/敏感性分析支持。
4. **处置结转调整须准确**：涉及处置时将累计公允价值变动转入投资收益的调整须金额准确、方向正确。
5. **审批链留痕**：超过明细层次重要性水平的调整须经合伙人/项目经理审批。
6. **TB回写一致**：确认调整已同步试算平衡表6101科目。

## checklist

### 一、账项调整（AJE）

- [ ] 所有AJE是否有充分审计证据（估值报告、市场报价等）
- [ ] AJE是否经适当层级审批
- [ ] 每笔调整分录借贷方是否完全平衡
- [ ] 调整金额是否完整反映到G13-1审定表调整列
- [ ] 估值更正调整是否与G13-2明细/估值底稿勾稽

### 二、重分类调整（RJE）

- [ ] RJE是否仅涉及列报，未影响损益总额
- [ ] 公允价值变动损益与投资收益之间的重分类是否恰当
- [ ] 处置结转调整（转入投资收益）是否金额准确、方向正确
- [ ] 是否存在以RJE掩盖损益错报的情形

### 三、未调整错报（SUD）与勾稽

- [ ] 未调整错报累计是否超过整体重要性水平
- [ ] 与A13未调整错报汇总表索引是否完整
- [ ] 跨期调整是否正确区分本期错报与前期差错更正
- [ ] 调整后审定数是否已同步试算平衡表6101科目

## risk_areas

### 高风险

1. **调整缺乏证据或未经授权**：估值调整无第三方估值/市场报价支持，或未经审批即纳入审定表。
2. **审定表与调整金额不一致**：G13-1审定表调整列与G13-3已确认分录长期不一致。
3. **以RJE掩盖损益错报**：将公允价值变动损益错报以重分类处理，规避损益影响。
4. **处置结转调整错误**：累计公允价值变动转入投资收益的调整金额或方向错误，造成损益重复或遗漏。

### 中风险

1. **RJE误含损益影响**：重分类调整影响了损益总额而非仅列报。
2. **跨期调整分类错误**：未区分本期错报与前期差错更正。
3. **SUD累计超阈值未处理**：未调整错报累计超重要性水平但未评估。

### 低风险

1. **分录摘要、科目编码不规范**：调整分录摘要笼统或编码不规范。
2. **索引指向不完整**：调整分录未指向G13-2明细、估值底稿等支持底稿。
3. **审计说明不充分**：未概括调整性质与剩余风险。
