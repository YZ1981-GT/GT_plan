# J2-4 长期应付职工薪酬计提情况检查表复核提示词

## 概述

本提示词针对长期应付职工薪酬计提情况检查表（J2-4）的复核。该表检查设定受益计划的判定依据、精算师资质及利用精算师工作的评价、精算假设完整性与计量准确性，是设定受益计划审计的核心底稿，重点体现对CAS1421利用专家工作的执行。

**法规依据：**
- 《企业会计准则第9号——职工薪酬》
- 《中国注册会计师审计准则第1421号——利用专家的工作》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **设定受益计划判定须有依据**：核对判定为设定受益计划的理由（如企业承担精算和投资风险、福利与最终工资挂钩、保证提存回报等），判定错误将导致会计处理迥异。
2. **精算师资质与客观性须评价**：利用精算师工作须评价其专业胜任能力、专业素质和客观性（CAS1421），核对精算师资质证明、独立性及是否受管理层不当影响。
3. **精算假设完整性测试**：核对精算报告中的假设是否涵盖所有相关条款（折现率、死亡率、离职率、工资增长率、通胀率、医疗成本趋势等），假设是否与被审计单位实际及市场数据一致。
4. **计量准确性测试**：对义务现值、计划资产、当期损益、其他综合收益等关键项目进行计量准确性测试，可通过复核精算方法、重新计算或聘请我方专家评估。
5. **利用专家须留证充分**：利用精算师工作的评价过程、假设合理性判断、计量准确性测试须充分留证，不得直接引用精算结论而无审计程序。
6. **检查结论支撑审定**：计提情况检查结论应支撑J2-1审定表的设定受益净负债确认。

## checklist

### 一、计划判定

- [ ] 判定为设定受益计划的理由是否充分（风险承担/福利公式/保证回报）
- [ ] 判定依据是否有相关条款支持
- [ ] 是否存在设定受益计划被误判为设定提存计划

### 二、精算师资质与客观性

- [ ] 是否利用精算师工作，精算师资质是否核实
- [ ] 精算师专业胜任能力、专业素质是否评价
- [ ] 精算师客观性/独立性是否评价（是否受管理层不当影响）
- [ ] 是否引用评估专家/精算专家工作并索引（如S12/S12A）

### 三、精算假设完整性

- [ ] 精算假设是否涵盖所有相关条款
- [ ] 折现率/死亡率/离职率/工资增长率等假设是否与实际及市场一致
- [ ] 假设是否在精算报告中完整披露
- [ ] 假设较上期变动是否有依据

### 四、计量准确性与结论

- [ ] 义务现值/计划资产/损益/OCI计量准确性是否测试
- [ ] 是否复核精算方法或重新计算
- [ ] 利用专家的评价过程是否充分留证
- [ ] 检查结论是否支撑J2-1审定表

## risk_areas

### 高风险

1. **直接引用精算结论无审计程序**：未评价精算师胜任能力/客观性、未测试假设合理性即采用结论，违反CAS1421。
2. **精算假设不合理少计负债**：折现率过高/工资增长率过低等激进假设低估设定受益义务。
3. **计划判定错误**：设定受益计划被误判为设定提存计划，规避长期负债与精算计量。
4. **计量准确性未测试**：未对义务现值等关键项目进行计量准确性测试，无法验证精算结果。

### 中风险

1. **精算师客观性存疑未识别**：精算师受管理层不当影响但未评价。
2. **精算假设不完整**：精算报告遗漏相关假设条款。
3. **假设变动无依据**：折现率等假设较上期变动缺依据。

### 低风险

1. **专家资质文档不全**：精算师资质证明记录不充分。
2. **利用专家留证简略**：评价与测试过程记录不充分。
3. **索引缺失**：检查底稿与审定表/精算报告/专家利用底稿交叉索引不完整。
