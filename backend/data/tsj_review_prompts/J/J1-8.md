# J1-8 应付职工薪酬一般检查（凭证检查）复核提示词

## 概述

本提示词针对应付职工薪酬一般检查（凭证检查表，J1-8）的复核，聚焦样本选取合理性、凭证核对完整性、检查比例达标性及异常交易标注充分性。凭证检查须覆盖薪酬计提（贷方）、发放（借方）及期后支付的完整证据链。

**法规依据：**
- 《中国注册会计师审计准则第1314号——审计抽样》
- 《企业会计准则第9号——职工薪酬》

---

## tips

1. **样本须覆盖计提与发放双向**：抽样应涵盖贷方计提（薪酬计算表/社保公积金申报）与借方发放（付款审批单/银行回单/社保缴纳凭证），大额及异常凭证全覆盖（CAS1314）。
2. **计提凭证核对薪酬计算表**：贷方计提凭证须核对职工薪酬计算表（月份/金额/是否恰当审批）。
3. **发放凭证核对付款单据**：借方发放/期后支付凭证须核对付款审批单（日期编号/审批）、银行回单（日期/摘要/金额）。
4. **期后支付验证负债存在性**：核对资产负债表日后实际支付情况，验证期末应付职工薪酬余额的存在性与完整性。
5. **检查比例应满足计划水平**：已检查薪酬发生额÷本期发生额须达到计划检查比例。
6. **异常交易标注须明确类型**：明确标注异常类型（金额异常/无审批/发放对象异常/期后未支付长期挂账）及初步判断。

## checklist

### 一、样本选取

- [ ] 样本选取方法是否与识别的重大错报风险相匹配
- [ ] 计提（贷方）与发放（借方）凭证是否均纳入样本
- [ ] 大额薪酬凭证（超重要性水平）是否100%全覆盖
- [ ] 期末集中计提、异常发放是否纳入必选样本

### 二、凭证核对完整性

- [ ] 计提凭证是否核对职工薪酬计算表（月份/金额/审批）
- [ ] 发放凭证是否核对付款审批单及银行回单
- [ ] 社保公积金缴纳是否核对申报表及缴纳凭证
- [ ] 期后支付是否核对验证负债存在性
- [ ] 核对中发现的差异是否逐一追踪解决

### 三、检查比例

- [ ] 已检查薪酬发生额÷本期发生额是否达到计划检查比例
- [ ] 计提与发放方向检查比例是否分别达标
- [ ] 检查比例计算公式是否正确

### 四、异常交易标注

- [ ] 异常交易是否全部标注并记录异常类型
- [ ] 无审批的计提/发放是否标注异常
- [ ] 期后未支付长期挂账的薪酬是否标注
- [ ] 异常标注是否含类型/描述/金额/初步判断

## risk_areas

### 高风险

1. **虚构薪酬发放**：伪造薪酬计算表或付款单据虚列人工套取资金，须交叉核对薪酬计算表、银行回单及用工实际。
2. **无审批计提/发放**：薪酬计提或发放缺恰当审批，存在越权或虚列风险。
3. **期末负债不真实**：期末应付职工薪酬余额缺期后支付验证，存在性/完整性存疑。
4. **样本选取偏差**：抽样未覆盖计提发放双向或高风险凭证，样本不具代表性。

### 中风险

1. **检查比例不足**：实际检查比例低于计划水平，证据不充分。
2. **核对深度不够**：仅核对金额一致性而忽略审批完整性及用工实际。
3. **异常交易漏标注**：无审批或长期挂账的薪酬未被标注调查。

### 低风险

1. **抽样参数记录不完整**：抽样参数记录不全，影响可追溯性。
2. **核对结果格式不统一**：检查结果记录格式不规范。
3. **底稿索引缺失**：凭证检查底稿与审定表/明细表交叉索引不完整。
