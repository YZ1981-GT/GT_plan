# J1-1 应付职工薪酬审定表复核提示词

## 概述

本提示词针对应付职工薪酬审定表（J1-1）的复核。应付职工薪酬（科目2211）为负债类科目，取期末余额，涵盖工资、社保、公积金、工会经费、职工教育经费等短期薪酬及离职后福利。审定表须完整反映期初期末勾稽、未审数→AJE/RJE调整→审定数链路，并与试算平衡表、明细表、利润表成本费用勾稽。

**法规依据：**
- 《企业会计准则第9号——职工薪酬》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **负债类取期末余额，期初期末须勾稽**：审定表期初审定数须等于上年期末审定数，期末审定数=期初+本期计提（贷方）−本期发放（借方）±审计调整，任何无源差异须查明。
2. **按薪酬项目分类审定**：应付职工薪酬须按工资/社保/住房公积金/工会经费/职工教育经费/非货币性福利/辞退福利等项目分类审定，各项目计提与发放口径须一致。
3. **计提数须与成本费用勾稽**：本期计提的职工薪酬应与生产成本、管理费用、销售费用等归集的人工费用勾稽，防止计提与费用化不匹配。
4. **社保公积金须按规定比例核对**：社保、住房公积金计提须核对缴费基数与法定比例，异常低于法定标准的须关注合规风险及少计负债。
5. **审定数须与试算平衡表勾稽**：审定表应付职工薪酬审定数合计必须与试算平衡表2211科目审定数一致。
6. **审定表是薪酬循环枢纽**：应与J1-2明细、J1-3调整、J1-6计提检查、J1-7分配检查形成闭环勾稽。

## checklist

### 一、期初期末勾稽

- [ ] 审定表期初审定数是否等于上年期末审定数
- [ ] 期末审定数是否=期初+本期计提−本期发放±审计调整
- [ ] 各薪酬项目期初期末变动是否与明细表一致
- [ ] 是否存在无源差异未说明

### 二、试算平衡表核对

- [ ] 审定表应付职工薪酬审定数是否与试算平衡表2211科目一致
- [ ] 各薪酬项目审定数之和是否等于一级科目审定数
- [ ] 试算平衡表未审数与审定表未审数是否一致
- [ ] 试算平衡表调整数与审定表调整数是否一致

### 三、审计调整完整性

- [ ] 所有AJE是否完整反映在审定表调整列
- [ ] 所有RJE是否完整反映在重分类列
- [ ] 调整分录借贷方是否平衡，审定数=未审数+AJE+RJE
- [ ] 建议但未调整的错报是否记录于SUD

### 四、分类与合规

- [ ] 应付职工薪酬是否按薪酬项目正确分类
- [ ] 社保、公积金计提基数与法定比例是否核对
- [ ] 短期薪酬与离职后福利、辞退福利分类是否正确
- [ ] 审定表分类是否与附注披露一致

## risk_areas

### 高风险

1. **期初期末不勾稽**：期初审定数与上年期末审定数不一致，可能存在未授权调整或数据错误。
2. **计提与成本费用不匹配**：本期计提职工薪酬与归集的人工费用不勾稽，可能存在漏计费用或负债。
3. **社保公积金少计负债**：计提基数或比例低于法定标准，少计应付职工薪酬负债，存在合规及错报风险。
4. **审定数与试算平衡表不一致**：审定表应付职工薪酬审定数与试算平衡表2211不一致，属重大勾稽错误。
5. **审计调整遗漏**：已确认调整未反映在审定表中，导致审定数失真。

### 中风险

1. **明细与汇总不勾稽**：审定表合计与J1-2明细表总计不一致。
2. **薪酬项目分类错误**：辞退福利/离职后福利与短期薪酬混淆。
3. **审定表与附注口径不一致**：审定表分类与附注披露分类不一致。
4. **重分类调整方向错误**：RJE借贷方向颠倒导致审定数偏离真实值。

### 低风险

1. **审定表格式不规范**：列标题、行顺序等格式问题。
2. **交叉索引不完整**：审定表未与明细表、调整分录建立索引。
3. **变动说明不充分**：薪酬项目重大变动未附说明。
