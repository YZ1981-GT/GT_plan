# J1-6 应付职工薪酬计提检查表复核提示词

## 概述

本提示词针对应付职工薪酬计提检查表（J1-6）的复核。该表检查各薪酬项目本期计提的准确性与完整性，包括工资计提、社保公积金按基数比例计提、工会经费与职工教育经费按规定比例计提，是负债完整性审计的核心底稿。

**法规依据：**
- 《企业会计准则第9号——职工薪酬》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **计提完整性是负债审计核心**：应付职工薪酬审计的关键认定是完整性（负债不得低估），须核对所有应计提项目是否齐全，尤其工会经费、职工教育经费等易漏项。
2. **社保公积金按基数比例重算**：核对社保、住房公积金的缴费基数与法定/约定比例，独立重算本期应计提金额，与实际计提对比。
3. **工会经费/职工教育经费按规定比例**：工会经费一般按工资总额2%、职工教育经费按规定比例计提，须核对计提基数与比例。
4. **计提与费用归集匹配**：本期计提须与成本费用中的人工费用归集勾稽，防止计提与费用化不匹配。
5. **计提基数须准确**：核对计提基数（工资总额）是否准确，基数错误将导致所有比例计提项目连锁错误。
6. **检查结论支撑审定**：计提检查发现的少计/多计应形成调整建议，并联动J1-1审定表及J1-3调整。

## checklist

### 一、计提完整性

- [ ] 所有应计提薪酬项目是否齐全（含工会经费、职工教育经费）
- [ ] 是否存在应计提未计提的项目（低估负债）
- [ ] 计提项目是否与用工实际匹配

### 二、计提准确性

- [ ] 社保公积金计提基数与法定/约定比例是否核对
- [ ] 社保公积金本期应计提金额是否独立重算并对比
- [ ] 工会经费/职工教育经费计提基数与比例是否核对
- [ ] 计提基数（工资总额）是否准确

### 三、计提与费用匹配

- [ ] 本期计提是否与成本费用人工费用归集勾稽
- [ ] 计提与费用化时点是否匹配
- [ ] 是否存在计提未费用化或费用化未计提

### 四、结论与联动

- [ ] 计提检查发现的差异是否形成调整建议
- [ ] 是否联动J1-1审定表及J1-3调整
- [ ] 检查结论是否明确

## risk_areas

### 高风险

1. **应计提项目漏计**：工会经费、职工教育经费等应计提项目漏计，低估负债与费用。
2. **社保公积金计提不足**：计提基数或比例低于法定标准，少计负债，存在合规风险。
3. **计提基数错误连锁影响**：工资总额基数错误导致所有比例计提项目连锁错误。
4. **计提与费用不匹配**：计提未费用化或费用化未计提，损益与负债失真。

### 中风险

1. **计提比例适用错误**：工会经费/职工教育经费适用比例错误。
2. **计提检查未重算**：仅核对金额未独立重算，无法验证准确性。
3. **差异未形成调整**：检查发现少计/多计未形成调整建议。

### 低风险

1. **检查记录不完整**：计提检查过程记录不充分。
2. **索引缺失**：检查底稿与审定表/明细表交叉索引不完整。
3. **计提依据文档缺失**：计提比例的政策依据未附。
