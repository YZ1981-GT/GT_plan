# J1-note-listed 应付职工薪酬附注披露复核提示词（上市公司）

## 概述

本提示词针对应付职工薪酬上市公司附注披露底稿（J1-note-listed）的复核，聚焦职工薪酬按项目分类披露、短期薪酬/离职后福利/辞退福利分类披露、变动情况披露及CAS9与证监会编报规则对上市公司职工薪酬披露的要求。

**法规依据：**
- 《企业会计准则第9号——职工薪酬》
- 《企业会计准则第30号——财务报表列报》
- 《公开发行证券的公司信息披露编报规则第15号——财务报告的一般规定》

---

## tips

1. **应付职工薪酬按项目分类披露**：附注须按短期薪酬（工资奖金/社保/公积金/工会经费/职工教育经费/非货币性福利）、离职后福利（设定提存计划）、辞退福利等分类披露期初、本期增加、本期减少、期末。
2. **短期薪酬须细分列示**：短期薪酬各明细项目须分项披露，各分项合计须等于短期薪酬合计。
3. **设定提存计划须单独披露**：基本养老保险、失业保险等设定提存计划的本期应缴存金额须单独披露。
4. **变动情况须完整勾稽**：应付职工薪酬变动表（期初+计提−支付=期末）须完整，且与审定表J1-1勾稽。
5. **与利润表及资产负债表勾稽**：附注职工薪酬期末余额=资产负债表应付职工薪酬；本期计提费用与利润表相关成本费用勾稽。
6. **附注须与审定表闭环勾稽**：披露应付职工薪酬各分项合计必须与J1-1审定数勾稽。

## checklist

### 一、分类披露

- [ ] 应付职工薪酬是否按短期薪酬/离职后福利/辞退福利分类披露
- [ ] 短期薪酬各明细项目是否分项披露
- [ ] 各分项合计是否勾稽
- [ ] 是否同时披露期初/期末数

### 二、变动情况披露

- [ ] 变动表是否完整（期初/本期增加/本期减少/期末）
- [ ] 变动表各项是否勾稽（期初+计提−支付=期末）
- [ ] 变动表是否与审定表J1-1勾稽

### 三、设定提存计划

- [ ] 设定提存计划（养老/失业保险）本期应缴存金额是否单独披露
- [ ] 是否披露欠缴金额（如有）

### 四、勾稽核对

- [ ] 附注职工薪酬期末余额是否等于资产负债表应付职工薪酬
- [ ] 本期计提费用是否与利润表相关成本费用勾稽
- [ ] 附注是否与J1-1审定数勾稽

## risk_areas

### 高风险

1. **变动表不勾稽**：应付职工薪酬变动表各项金额勾稽关系不成立，或与审定表不一致，属重大披露错误。
2. **分类披露缺失**：未按短期薪酬/离职后福利/辞退福利分类披露，无法评估薪酬结构。
3. **设定提存计划未披露**：养老/失业保险应缴存金额未单独披露，不满足CAS9要求。
4. **附注与资产负债表/审定表不一致**：披露职工薪酬期末余额与报表或J1-1审定数存在差异。

### 中风险

1. **短期薪酬明细不完整**：短期薪酬仅披露总额，未分项披露。
2. **欠缴披露缺失**：社保公积金欠缴金额未披露。
3. **可比信息缺失**：仅披露期末数，未列期初可比数。

### 低风险

1. **披露格式不规范**：表格列序、单位等格式细节问题。
2. **文字说明模板化**：薪酬政策说明照搬会计政策原文。
3. **辞退福利说明简略**：重大辞退福利事项仅提及未展开。
