# J1-2 应付职工薪酬明细表复核提示词

## 概述

本提示词针对应付职工薪酬明细表（J1-2）的复核。该表按薪酬项目分项列示期初余额、本期计提（增加）、本期发放（减少）及期末余额，是审定表（J1-1）的支撑底稿。复核聚焦各薪酬项目的计提发放勾稽、项目分类完整性及与审定表的勾稽。

**法规依据：**
- 《企业会计准则第9号——职工薪酬》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **按薪酬项目逐项列示增减**：明细表须按工资/奖金/社保/公积金/工会经费/职工教育经费/非货币性福利/辞退福利等分项列示期初、本期计提、本期发放、期末。
2. **期末=期初+计提−发放**：逐项目核对期末余额勾稽逻辑，防止计提或发放漏记导致期末余额失真。
3. **计提项目须齐全**：核对是否涵盖所有应计提的薪酬项目（含工会经费、职工教育经费等易漏项），避免漏计负债。
4. **发放须有实际支付支持**：本期发放（借方减少）须与银行付款、社保缴纳凭证勾稽，防止虚列发放冲减负债。
5. **分项合计回勾审定表**：明细各分项期末余额合计必须等于J1-1审定表应付职工薪酬合计。
6. **关注长期挂账项目**：期末余额长期挂账不发放的薪酬项目（如多年未发奖金）须关注真实性及是否应转销。

## checklist

### 一、分项列示与勾稽

- [ ] 各薪酬项目是否列示期初/计提/发放/期末
- [ ] 各项目期末余额是否=期初+计提−发放
- [ ] 明细各分项期末余额合计是否等于J1-1审定表合计
- [ ] 计提项目是否齐全（含工会经费、职工教育经费）

### 二、计提与发放验证

- [ ] 本期计提是否与成本费用归集人工费用勾稽
- [ ] 本期发放是否与银行付款/社保缴纳凭证勾稽
- [ ] 是否存在虚列发放冲减负债的情形
- [ ] 社保公积金计提是否按法定基数比例

### 三、异常项目分析

- [ ] 期末长期挂账的薪酬项目是否关注真实性
- [ ] 长期未发放项目是否评估是否应转销
- [ ] 各项目本期变动较上期是否合理

### 四、勾稽与列报

- [ ] 明细分项是否与J1-1审定表逐项对应
- [ ] 明细分类是否与附注职工薪酬披露一致

## risk_areas

### 高风险

1. **薪酬项目漏计提**：工会经费、职工教育经费等应计提项目漏计，低估负债与费用。
2. **虚列发放冲减负债**：无实际支付支持的发放冲减应付职工薪酬，低估负债。
3. **分项合计与审定表不勾稽**：明细各分项期末合计与J1-1审定表存在无源差异。
4. **社保公积金计提不足**：计提基数/比例低于法定标准，少计负债。

### 中风险

1. **计提发放勾稽断裂**：期末余额与期初+计提−发放不符。
2. **长期挂账未处理**：长期未发放薪酬项目未评估真实性或转销。
3. **计提与费用不匹配**：本期计提与成本费用归集人工费用不勾稽。

### 低风险

1. **明细粒度不足**：薪酬项目合并列示，不便逐项追溯。
2. **交叉索引缺失**：明细分项未标注对应凭证/底稿索引。
3. **可比信息不完整**：仅列本期分项，缺上期可比数据。
