# J1-4 应付职工薪酬月度分析表复核提示词

## 概述

本提示词针对应付职工薪酬月度分析表（J1-4）的复核。该表按月列示薪酬计提/发放金额及人数，通过月度趋势分析识别异常波动（如无对应人数的薪酬突增、月度计提发放不匹配），是实质性分析程序的重要底稿。

**法规依据：**
- 《企业会计准则第9号——职工薪酬》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **月度趋势须平稳可解释**：正常经营下月度薪酬计提应相对平稳，某月突增/突减须结合人数变化、季节性奖金、政策调整分析合理性。
2. **人均薪酬须合理**：以月度薪酬÷月度人数测算人均薪酬，异常偏高/偏低的月份须查明原因，警惕虚构薪酬套取资金。
3. **计提与发放的时间匹配**：核对月度计提与发放的时间关系，年终奖等在计提月与发放月的分布是否合理。
4. **年末月份重点关注**：年末计提的绩效奖金、年终奖须核对是否有考核依据及审批，防止无依据计提调节利润。
5. **与明细表及全年计提勾稽**：月度分析全年合计须与J1-2明细表本期计提/发放及J1-1审定表勾稽。
6. **异常识别须形成结论**：月度异常波动的识别应形成审计判断，并与计提检查、凭证检查联动。

---

## checklist

### 一、月度趋势分析

- [ ] 月度薪酬计提/发放是否列示
- [ ] 月度趋势是否平稳，突增/突减是否有合理解释
- [ ] 是否结合人数变化、季节性、政策调整分析
- [ ] 全年合计是否与J1-2明细表勾稽

### 二、人均薪酬测算

- [ ] 是否列示月度人数
- [ ] 人均薪酬测算是否合理
- [ ] 异常偏高/偏低月份是否查明原因
- [ ] 是否警惕无对应人数的薪酬突增

### 三、计提发放匹配

- [ ] 月度计提与发放时间关系是否合理
- [ ] 年终奖/绩效奖金在计提月/发放月分布是否合理
- [ ] 年末计提奖金是否有考核依据及审批

### 四、异常识别与联动

- [ ] 月度异常波动是否形成审计结论
- [ ] 分析结果是否与计提检查、凭证检查联动
- [ ] 是否存在异常但未做进一步程序的情形

## risk_areas

### 高风险

1. **虚构薪酬套取资金**：无对应人数的薪酬突增或人均薪酬异常偏高，可能存在虚列人工套取资金。
2. **年末无依据计提调节利润**：年末大额计提奖金无考核依据或审批，操纵利润。
3. **全年合计与明细/审定表不勾稽**：月度分析全年合计与J1-2/J1-1存在无源差异。

### 中风险

1. **月度异常未分析**：月度薪酬突增/突减缺合理性分析。
2. **人均薪酬异常未查证**：人均薪酬异常偏离但未查明原因。
3. **计提发放时间不匹配**：奖金计提与发放时间分布异常未说明。

### 低风险

1. **分析维度单一**：仅列月度金额未测算人均，异常难以定位。
2. **人数数据缺失**：未列月度人数，无法测算人均薪酬。
3. **底稿索引不完整**：分析表未标注数据来源底稿索引。
