# J2-2 长期应付职工薪酬明细表复核提示词

## 概述

本提示词针对长期应付职工薪酬明细表（J2-2）的复核。该表列示设定受益计划义务现值变动（期初、当期服务成本、利息成本、精算利得损失、支付福利、期末）及计划资产公允价值变动，是审定表（J2-1）的支撑底稿。复核聚焦义务与资产变动的完整性、各变动要素的确认路径及与精算报告的勾稽。

**法规依据：**
- 《企业会计准则第9号——职工薪酬》
- 《中国注册会计师审计准则第1421号——利用专家的工作》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **义务现值变动要素须完整**：设定受益义务现值变动=期初+当期服务成本+利息成本+精算损失（减利得）−支付福利±结算，各要素须完整列示且与精算报告勾稽。
2. **计划资产变动要素须完整**：计划资产公允价值变动=期初+计划资产回报+缴存−支付福利，回报中的净利息部分入损益、超出部分入OCI（重计量）。
3. **各变动要素确认路径须正确**：当期服务成本/过去服务成本/净利息入损益；精算利得损失/计划资产回报超净利息部分入OCI，须逐项核对路径。
4. **明细变动须与精算报告逐项勾稽**：义务现值与计划资产的各变动要素金额须与精算师提供的报告逐项一致。
5. **期末余额回勾审定表**：明细表期末设定受益净负债必须等于J2-1审定表长期应付职工薪酬审定数。
6. **关注精算假设变动的影响**：折现率等假设变动导致的精算利得损失须体现在明细表并计入OCI。

## checklist

### 一、义务现值变动

- [ ] 义务现值变动要素是否完整（服务成本/利息成本/精算利得损失/支付福利/结算）
- [ ] 各要素金额是否与精算报告勾稽
- [ ] 期末义务现值是否勾稽（期初±各要素）
- [ ] 精算假设变动的影响是否体现

### 二、计划资产变动

- [ ] 计划资产变动要素是否完整（回报/缴存/支付福利）
- [ ] 计划资产回报的净利息部分与超出部分是否区分
- [ ] 期末计划资产公允价值是否勾稽
- [ ] 计划资产公允价值计量是否恰当

### 三、确认路径

- [ ] 当期服务成本/过去服务成本/净利息是否入损益
- [ ] 精算利得损失/资产回报超净利息部分是否入OCI
- [ ] 结算利得损失是否恰当处理

### 四、勾稽

- [ ] 期末设定受益净负债是否等于J2-1审定数
- [ ] 各变动要素是否与精算报告逐项一致
- [ ] 明细分类是否与附注披露一致

## risk_areas

### 高风险

1. **变动要素与精算报告不勾稽**：义务现值/计划资产各变动要素与精算报告不一致，计量失据。
2. **确认路径错误**：应入OCI的精算利得损失计入损益，或反之，操纵利润。
3. **期末净负债与审定表不勾稽**：明细期末设定受益净负债与J2-1审定数存在无源差异。
4. **义务现值变动要素遗漏**：漏计过去服务成本或结算影响，负债失真。

### 中风险

1. **计划资产回报拆分错误**：净利息部分与超出部分（重计量）拆分错误。
2. **精算假设变动未体现**：折现率等假设变动的精算利得损失未在明细体现。
3. **计划资产计量错误**：计划资产公允价值计量错误。

### 低风险

1. **明细粒度不足**：变动要素合并列示，不便逐项追溯。
2. **交叉索引缺失**：明细未标注对应精算报告索引。
3. **可比信息不完整**：仅列本期变动，缺上期可比数据。
