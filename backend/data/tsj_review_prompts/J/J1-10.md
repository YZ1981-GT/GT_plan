# J1-10 辞退福利检查表复核提示词

## 概述

本提示词针对辞退福利检查表（J1-10）的复核。辞退福利指企业在职工劳动合同到期前解除劳动关系或鼓励职工自愿接受裁减而给予的补偿，须在满足确认条件时一次性计入当期损益。复核聚焦辞退福利的确认时点、计量准确性及负债完整性。

**法规依据：**
- 《企业会计准则第9号——职工薪酬》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **确认时点须满足两条件**：辞退福利在企业不能单方面撤回解除劳动关系计划/裁减建议、且确认与之相关的重组成本或费用时的较早日确认，须核对确认时点是否恰当，防止提前或滞后确认。
2. **计量须区分一次性补偿与持续福利**：一次性辞退补偿按预计支付金额计量；对超过一年支付的辞退福利（如内退人员至法定退休日的工资社保）须按折现后金额计量。
3. **内退人员福利须折现**：实行内部退养的，自内退开始至正常退休日的工资、社保等应按预计支付总额折现计入当期损益，须核对折现率与期间。
4. **辞退计划须有正式文件**：辞退福利确认须有经批准的正式辞退计划（人数、岗位、补偿标准、实施时间），缺失文件的确认无依据。
5. **与应付职工薪酬及损益勾稽**：辞退福利金额计入应付职工薪酬（或长期应付职工薪酬）并计入管理费用，与J1-1及利润表勾稽。
6. **检查结论支撑完整性**：辞退福利检查发现的漏确认/计量错误应形成调整建议。

## checklist

### 一、确认时点

- [ ] 辞退福利确认是否满足两确认条件
- [ ] 是否有经批准的正式辞退计划文件
- [ ] 确认时点是否恰当（无提前/滞后确认）
- [ ] 辞退计划要素（人数/补偿标准/实施时间）是否明确

### 二、计量准确性

- [ ] 一次性辞退补偿是否按预计支付金额计量
- [ ] 超过一年的辞退福利是否折现计量
- [ ] 内退人员福利是否按预计支付总额折现
- [ ] 折现率与期间是否恰当

### 三、负债完整性

- [ ] 是否识别所有应确认的辞退福利
- [ ] 辞退福利是否计入应付职工薪酬（或长期应付职工薪酬）
- [ ] 是否存在应确认未确认（低估负债）

### 四、勾稽与联动

- [ ] 辞退福利是否计入管理费用并与利润表勾稽
- [ ] 一年以上部分是否重分类至长期应付职工薪酬（联动J2）
- [ ] 检查发现的差异是否形成调整建议

## risk_areas

### 高风险

1. **辞退福利漏确认**：满足确认条件的辞退福利未确认，低估负债与费用、虚增利润。
2. **确认时点操纵**：提前或滞后确认辞退福利以调节各期损益。
3. **内退福利未折现**：超过一年的内退人员福利未折现，高估或错误计量负债与费用。
4. **无正式计划确认**：无经批准辞退计划却确认辞退福利，或有计划却未确认。

### 中风险

1. **计量金额错误**：补偿标准或人数错误导致辞退福利计量失真。
2. **未重分类长期部分**：一年以上辞退福利未重分类至长期应付职工薪酬。
3. **折现率不当**：内退福利折现率选取不合理。

### 低风险

1. **辞退计划文档不全**：辞退计划要素记录不充分。
2. **计量过程记录简略**：折现计算过程记录不充分。
3. **索引缺失**：检查底稿与审定表/利润表交叉索引不完整。
