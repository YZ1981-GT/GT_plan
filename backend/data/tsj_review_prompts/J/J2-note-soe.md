# J2-note-soe 长期应付职工薪酬附注披露复核提示词（国有企业）

## 概述

本提示词针对长期应付职工薪酬国有企业附注披露底稿（J2-note-soe）的复核。国有企业长期应付职工薪酬披露除满足会计准则通用要求外，还须关注国资监管要求：内退福利/补充退休福利的合规性、设定受益义务对国有资本的影响及决算报表口径一致性。

**法规依据：**
- 《企业会计准则第9号——职工薪酬》
- 《企业会计准则第30号——财务报表列报》
- 《中央企业财务决算报告管理办法》

---

## tips

1. **国企长期薪酬披露有双层要求**：既满足会计准则通用披露（设定受益计划变动/精算假设/敏感性），又满足国资监管对退休福利合规的披露要求。
2. **内退/补充退休福利合规性**：国企的内退人员福利、补充退休福利（如企业年金外的额外承诺）须关注是否符合国资监管政策及审批程序。
3. **设定受益义务对国有资本影响**：设定受益净负债及重计量对净资产（国有资本）的影响须说明，长期福利承诺可能构成国有资本潜在负担。
4. **精算假设审慎性**：国资监管关注长期负债计量审慎性，精算假设（尤其折现率）须审慎，附注须披露假设及敏感性。
5. **与决算报表口径一致**：附注长期应付职工薪酬须与年度财务决算报表相关数据一致，差异编制调节说明。
6. **附注须与审定表闭环勾稽**：披露设定受益净负债期末余额必须与J2-1审定数、J2-2明细勾稽。

## checklist

### 一、基础披露（与上市版共有）

- [ ] 是否披露设定受益计划特征、风险及企业义务
- [ ] 义务现值/计划资产变动表是否完整
- [ ] 重大精算假设是否披露
- [ ] 敏感性分析是否披露

### 二、国有资产监管相关披露

- [ ] 内退福利/补充退休福利合规性是否说明
- [ ] 长期福利承诺的审批程序是否说明
- [ ] 设定受益净负债/重计量对国有资本（净资产）的影响是否说明
- [ ] 精算假设审慎性是否体现

### 三、勾稽与决算一致性

- [ ] 披露设定受益净负债期末余额是否与J2-1审定数勾稽
- [ ] 各变动要素是否与J2-2明细/精算报告勾稽
- [ ] 附注是否与财务决算报表数据一致
- [ ] 差异是否编制调节说明

### 四、其他

- [ ] 计划资产是否按类别披露构成
- [ ] 是否同时披露本期数和上期可比数

## risk_areas

### 高风险

1. **补充退休福利违规未披露**：企业年金外的额外退休福利承诺不符合国资政策或未经审批，且未在附注反映。
2. **精算假设不审慎低估负债**：折现率过高等激进假设低估设定受益义务，掩盖国有资本潜在负担。
3. **附注与决算/审定表不勾稽**：披露长期应付职工薪酬与决算报表或J2-1审定数存在差异。
4. **敏感性分析缺失**：未披露主要假设变动的敏感性，不满足CAS9要求。

### 中风险

1. **国有资本影响未说明**：设定受益净负债/重计量对净资产的影响未说明。
2. **内退福利合规性未说明**：内退人员福利合规性及审批程序未说明。
3. **计划资产构成披露不足**：仅披露计划资产总额，未按类别披露构成。

### 低风险

1. **披露格式未按决算模板**：附注格式与国资委决算模板有细微差异。
2. **文字说明模板化**：计划性质说明照搬模板。
3. **可比信息不完整**：仅披露本期数，未列上期可比数。
