# J3-2 股份支付检查表复核提示词

## 概述

本提示词针对股份支付检查表（J3-2）的复核。该表检查股份支付增减变动测算的准确性、凭证核对及各期费用确认的合规性，验证股份支付会计处理与授予文件、行权记录的一致性，是股份支付列报准确性的核心底稿。

**法规依据：**
- 《企业会计准则第11号——股份支付》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **增减变动测算须准确**：股份支付授予、行权、失效、注销等变动的数量与金额须与授予文件、行权记录、董事会/股东大会决议核对，测算准确性直接影响费用确认。
2. **本期费用测算须重算**：以授予日公允价值×预计可行权数量÷等待期独立重算本期应确认费用，与账面确认费用对比，差异须查明。
3. **凭证核对完整证据链**：核对股份支付计划批准文件（决议）、授予协议、估值报告、行权记录及费用确认分录的完整证据链。
4. **可行权条件变化的会计处理**：核对等待期内可行权条件、行权价、授予数量等条款变更（修改）的会计处理，有利修改增加费用、不利修改不减少费用。
5. **非雇员股份支付区分**：向非雇员（如供应商）的股份支付以取得商品/服务的公允价值计量，与雇员股份支付处理不同，须核对区分。
6. **检查结论支撑列报**：股份支付检查发现的测算/确认错误应形成调整建议，影响费用列报及资本公积/负债。

## checklist

### 一、增减变动测算

- [ ] 授予/行权/失效/注销变动数量是否与授予文件/行权记录核对
- [ ] 变动金额测算是否准确
- [ ] 是否与董事会/股东大会决议核对
- [ ] 本期应确认费用是否独立重算并与账面对比

### 二、凭证核对

- [ ] 股份支付计划批准文件（决议）是否核对
- [ ] 授予协议及估值报告是否核对
- [ ] 行权记录及费用确认分录是否核对
- [ ] 核对中发现的差异是否逐一追踪解决

### 三、条款变更与非雇员

- [ ] 等待期内条款变更（修改）的会计处理是否正确
- [ ] 有利修改是否增加费用、不利修改是否未减少费用
- [ ] 是否区分雇员与非雇员股份支付
- [ ] 非雇员股份支付是否按取得商品/服务公允价值计量

### 四、结论与联动

- [ ] 检查发现的测算/确认差异是否形成调整建议
- [ ] 是否联动J3-1及资本公积/应付职工薪酬
- [ ] 检查结论是否明确

## risk_areas

### 高风险

1. **本期费用测算错误**：授予日公允价值/预计可行权数量/等待期错误导致本期费用测算失真，虚增/虚减费用。
2. **变动数量与授予文件不符**：授予/行权/失效数量与决议、行权记录不一致，会计处理无依据。
3. **条款变更处理错误**：有利修改未增加费用或不利修改减少了费用，违反准则。
4. **无批准文件确认费用**：股份支付计划缺经批准的正式文件却确认费用。

### 中风险

1. **非雇员股份支付混淆**：非雇员股份支付按雇员方式处理，计量基础错误。
2. **失效/注销处理不当**：失效或注销股份支付的会计处理错误。
3. **重算与账面差异未查明**：独立重算与账面确认费用差异未查明原因。

### 低风险

1. **凭证核对记录不完整**：股份支付凭证核对过程记录不充分。
2. **估值报告索引缺失**：检查底稿与估值报告索引不完整。
3. **格式不规范**：检查结果记录格式不统一。
