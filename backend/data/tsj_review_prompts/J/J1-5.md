# J1-5 应付职工薪酬同行业对比表复核提示词

## 概述

本提示词针对应付职工薪酬同行业对比表（J1-5）的复核。该表将本单位人均薪酬、薪酬占收入比、社保公积金缴纳水平等指标与同行业可比企业对比，通过横向分析识别薪酬水平异常，是实质性分析程序的补充底稿。

**法规依据：**
- 《企业会计准则第9号——职工薪酬》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **对比样本须可比**：选取的同行业企业须在规模、地区、业务性质上可比，样本不可比将使对比结论失效。
2. **人均薪酬对比须口径一致**：本单位与对比企业的人均薪酬计算口径（是否含社保/奖金、人数口径）须一致，避免口径差异导致误判。
3. **显著偏离须查明原因**：本单位人均薪酬或薪酬占收入比显著高于/低于同行业的，须结合业务特点、地区差异、员工结构分析。
4. **偏高警惕虚列、偏低警惕漏计**：人均薪酬显著偏高可能存在虚列人工；显著偏低可能存在薪酬体外支付或漏计负债。
5. **社保公积金水平对比**：社保公积金缴纳水平显著低于同行业的，须关注合规风险及少计负债。
6. **对比结论须支撑审计判断**：横向对比的异常识别应形成明确结论，并与计提检查、凭证检查联动。

---

## checklist

### 一、对比样本

- [ ] 对比企业是否在规模/地区/业务上可比
- [ ] 对比数据来源是否可靠（公开财报/行业统计）
- [ ] 对比指标口径是否一致

### 二、指标对比

- [ ] 人均薪酬是否与同行业对比
- [ ] 薪酬占收入比是否与同行业对比
- [ ] 社保公积金缴纳水平是否对比
- [ ] 显著偏离的指标是否查明原因

### 三、异常判断

- [ ] 人均薪酬显著偏高是否核查虚列人工
- [ ] 人均薪酬显著偏低是否核查体外支付/漏计
- [ ] 社保公积金显著偏低是否关注合规及少计负债

### 四、结论与联动

- [ ] 横向对比异常是否形成审计结论
- [ ] 分析结果是否与计提检查、凭证检查联动
- [ ] 是否存在异常但未做进一步程序的情形

## risk_areas

### 高风险

1. **人均薪酬异常偏高掩盖虚列**：远高于同行业但未查证，可能存在虚列人工套取资金。
2. **薪酬体外支付漏计**：人均薪酬异常偏低可能反映薪酬体外支付或负债漏计。
3. **社保公积金少计负债**：缴纳水平显著低于同行业，存在合规风险及少计负债。

### 中风险

1. **对比样本不可比**：选用不可比企业导致对比结论失效。
2. **口径不一致误判**：本单位与对比企业指标口径不一致产生误导性差异。
3. **异常无结论**：仅列对比数据未形成审计判断。

### 低风险

1. **对比维度单一**：仅对比人均薪酬未含占收入比等多维度。
2. **数据来源标注不清**：对比数据来源未标注，可追溯性不足。
3. **底稿索引不完整**：对比表未标注数据来源底稿索引。
