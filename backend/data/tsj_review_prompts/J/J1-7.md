# J1-7 应付职工薪酬分配检查表复核提示词

## 概述

本提示词针对应付职工薪酬分配检查表（J1-7）的复核。该表检查本期计提的职工薪酬在各成本费用科目间的分配（生产成本/制造费用/管理费用/销售费用/研发支出/在建工程等），验证人工费用归集分配的合理性，是薪酬费用化列报准确性的核心底稿。

**法规依据：**
- 《企业会计准则第9号——职工薪酬》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **薪酬分配须与用工部门匹配**：职工薪酬应按职工提供服务的受益对象分配至相应成本费用科目，生产人员计入生产成本、管理人员计入管理费用等，分配须与用工部门/岗位匹配。
2. **分配合计须等于计提总额**：各成本费用科目分配的薪酬合计必须等于本期计提的职工薪酬总额，差异意味着分配遗漏或重复。
3. **关注资本化薪酬的合理性**：计入在建工程、研发支出（资本化）的薪酬须核对是否符合资本化条件，防止费用资本化调节利润。
4. **分配比例须稳定可解释**：各科目分配比例较上期异常变动的，须结合用工结构变化分析，警惕通过分配调节各项费用。
5. **与成本费用底稿勾稽**：分配至各科目的薪酬须与对应成本费用底稿（生产成本、管理费用等）的人工费用勾稽。
6. **检查结论支撑列报准确性**：分配检查发现的错误分配应形成调整建议，影响费用列报及产品成本。

---

## checklist

### 一、分配合理性

- [ ] 薪酬分配是否与职工受益对象/用工部门匹配
- [ ] 生产/管理/销售/研发人员薪酬是否分配至相应科目
- [ ] 分配依据（工时/人数/部门）是否合理

### 二、分配完整性

- [ ] 各科目分配薪酬合计是否等于本期计提总额
- [ ] 是否存在分配遗漏或重复
- [ ] 分配是否覆盖所有用工

### 三、资本化与费用化

- [ ] 计入在建工程/研发支出的薪酬是否符合资本化条件
- [ ] 是否存在应费用化薪酬被资本化的情形
- [ ] 资本化薪酬金额是否与对应资产底稿勾稽

### 四、分析与联动

- [ ] 各科目分配比例较上期是否合理
- [ ] 分配比例异常变动是否分析
- [ ] 分配至各科目的薪酬是否与成本费用底稿勾稽

## risk_areas

### 高风险

1. **薪酬费用不当资本化**：应费用化的薪酬计入在建工程/研发支出，虚增资产、虚减费用、调节利润。
2. **分配合计与计提总额不符**：各科目分配合计不等于计提总额，存在分配遗漏或重复。
3. **分配与用工部门不匹配**：薪酬分配至错误科目，扭曲各项成本费用及产品成本。

### 中风险

1. **分配比例异常未分析**：各科目分配比例较上期异常变动未说明。
2. **资本化条件不满足**：资本化薪酬不符合资本化条件但未识别。
3. **与成本费用底稿不勾稽**：分配薪酬与对应成本费用底稿人工费用不勾稽。

### 低风险

1. **分配依据文档不足**：工时/人数等分配依据记录不充分。
2. **检查记录不完整**：分配检查过程记录不充分。
3. **索引缺失**：检查底稿与成本费用底稿交叉索引不完整。
