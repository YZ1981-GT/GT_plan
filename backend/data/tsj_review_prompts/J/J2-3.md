# J2-3 长期应付职工薪酬调整分录复核提示词

## 概述

本提示词针对长期应付职工薪酬调整分录（J2-3）的复核，含账项调整（AJE）、重分类调整（RJE）及未调整错报（SUD）评估。复核须验证每笔调整有证据、借贷平衡、完整反映到J2-1审定表，并同步试算平衡表。

**法规依据：**
- 《企业会计准则第9号——职工薪酬》
- 《中国注册会计师审计准则第1421号——利用专家的工作》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **AJE影响负债/损益/OCI、RJE仅影响列报**：设定受益计划的AJE可能同时影响长期应付职工薪酬、损益（服务成本/净利息）及OCI（重计量），须核对影响路径正确；RJE仅涉及列报（如一年内到期部分重分类），不得以RJE掩盖负债错报。
2. **调整须与J2-1审定表逐笔勾稽**：审定表调整列金额必须与J2-3已确认分录逐笔一致。
3. **精算调整须有专家依据**：更正义务现值/精算假设的调整须有精算师重新计算或复核意见支持（CAS1421）。
4. **重计量调整须计入OCI**：涉及精算利得损失重新计量的调整须计入其他综合收益，不得转损益。
5. **审批链留痕**：超过明细层次重要性水平的调整须经合伙人/项目经理审批。
6. **TB回写一致**：确认调整已同步试算平衡表2221科目及OCI/损益科目。

## checklist

### 一、账项调整（AJE）

- [ ] 所有AJE是否有充分审计证据（精算报告、专家复核意见等）
- [ ] AJE是否经适当层级审批
- [ ] 每笔调整分录借贷方是否完全平衡
- [ ] 调整金额是否完整反映到J2-1审定表调整列
- [ ] 调整对损益/OCI的影响路径是否正确

### 二、重分类调整（RJE）

- [ ] RJE是否仅涉及列报，未影响负债总额
- [ ] 一年内到期的长期应付职工薪酬重分类是否恰当
- [ ] 重计量调整是否计入OCI而非损益
- [ ] 是否存在以RJE掩盖负债错报的情形

### 三、未调整错报（SUD）与勾稽

- [ ] 未调整错报累计是否超过整体重要性水平
- [ ] 与A13未调整错报汇总表索引是否完整
- [ ] 跨期调整是否正确区分本期错报与前期差错更正
- [ ] 调整后审定数是否已同步试算平衡表2221及OCI/损益科目

## risk_areas

### 高风险

1. **调整缺乏专家依据**：精算调整无精算师重算/复核意见支持，或未经审批即纳入审定表。
2. **审定表与调整金额不一致**：J2-1审定表调整列与J2-3已确认分录长期不一致。
3. **重计量调整违规入损益**：将应入OCI的重计量调整计入损益，操纵利润。
4. **调整影响路径错误**：服务成本/净利息与重计量的路径混淆，损益与OCI失真。

### 中风险

1. **RJE误含负债/损益影响**：重分类调整影响了负债或损益总额而非仅列报。
2. **跨期调整分类错误**：未区分本期错报与前期差错更正。
3. **SUD累计超阈值未处理**：未调整错报累计超重要性水平但未评估。

### 低风险

1. **分录摘要、科目编码不规范**：调整分录摘要笼统或编码不规范。
2. **索引指向不完整**：调整分录未指向J2-2明细、精算报告等支持底稿。
3. **审计说明不充分**：未概括调整性质与剩余风险。
