# J2-1 长期应付职工薪酬审定表复核提示词

## 概述

本提示词针对长期应付职工薪酬审定表（J2-1）的复核。长期应付职工薪酬（科目2221）为负债类科目，取期末余额，核心为设定受益计划义务及其他长期职工福利。审定表须完整反映设定受益计划净负债（义务现值−计划资产公允价值）、重计量计入OCI，并与试算平衡表、精算报告、明细表勾稽。

**法规依据：**
- 《企业会计准则第9号——职工薪酬》
- 《中国注册会计师审计准则第1421号——利用专家的工作》
- 《中国注册会计师审计准则第1301号——审计证据》

## tips

1. **区分设定提存计划与设定受益计划**：设定提存计划仅按应缴存额确认（一般为短期，J1核算）；设定受益计划须按精算确定的义务现值确认长期负债（J2核算），两者会计处理迥异，须核对计划类型判定正确。
2. **净负债=义务现值−计划资产公允价值**：设定受益计划净负债（或净资产）为设定受益义务现值减计划资产公允价值，审定须核对两者计量。
3. **重计量计入OCI不得转损益**：设定受益计划净负债/净资产的重计量（精算利得损失、计划资产回报超出净利息部分、资产上限影响变动）计入其他综合收益且后续不得转入损益，须核对损益路径。
4. **精算假设须合理且依赖专家**：义务现值依赖折现率、死亡率、离职率、工资增长率等精算假设，通常须利用精算师工作（CAS1421），审定须评估专家胜任能力、客观性及假设合理性。
5. **审定数须与试算平衡表勾稽**：审定表长期应付职工薪酬审定数合计必须与试算平衡表2221科目审定数一致。
6. **审定表是设定受益计划枢纽**：应与J2-2明细、J2-3调整、J2-4计提情况检查及精算报告形成闭环勾稽。

## checklist

### 一、期初期末与勾稽

- [ ] 审定表期初审定数是否等于上年期末审定数
- [ ] 期末净负债是否=义务现值−计划资产公允价值
- [ ] 审定数是否与试算平衡表2221科目一致
- [ ] 是否与J2-2明细表勾稽

### 二、计划类型与计量

- [ ] 计划类型判定（设定提存/设定受益）是否正确
- [ ] 设定受益义务现值是否有精算报告支持
- [ ] 计划资产公允价值计量是否恰当
- [ ] 净利息（净负债×折现率）是否正确计入损益

### 三、重计量与损益路径

- [ ] 重计量（精算利得损失等）是否计入其他综合收益
- [ ] 重计量是否未违规转入损益
- [ ] 当期服务成本/过去服务成本是否计入损益
- [ ] 结算利得损失是否恰当处理

### 四、精算假设与专家利用

- [ ] 折现率/死亡率/离职率/工资增长率等假设是否合理
- [ ] 是否利用精算师工作，专家胜任能力/客观性是否评估（CAS1421）
- [ ] 精算假设较上期变动是否有依据
- [ ] 所有AJE/RJE是否完整反映在审定表，审定数=未审+AJE+RJE

## risk_areas

### 高风险

1. **计划类型判定错误**：将设定受益计划误判为设定提存计划，规避长期负债确认与精算计量，重大低估负债。
2. **精算假设不合理操纵负债**：通过高折现率或低工资增长率假设低估设定受益义务，少计负债与费用。
3. **重计量违规转入损益**：将应计OCI的重计量转入损益，操纵当期利润。
4. **审定数与试算平衡表不一致**：审定表长期应付职工薪酬与试算平衡表2221不一致。
5. **未评估精算专家**：直接采用精算结论未评估专家胜任能力、客观性及假设合理性，违反CAS1421。

### 中风险

1. **净负债计量错误**：义务现值或计划资产公允价值计量错误导致净负债失真。
2. **净利息计算错误**：净利息未按期初净负债×折现率计算。
3. **明细与汇总不勾稽**：审定表合计与J2-2明细表不一致。
4. **重分类调整方向错误**：RJE借贷方向颠倒导致审定数偏离真实值。

### 低风险

1. **审定表格式不规范**：列标题、行顺序等格式问题。
2. **交叉索引不完整**：审定表未与明细表、精算报告建立索引。
3. **假设变动说明不充分**：精算假设变动未附说明。
