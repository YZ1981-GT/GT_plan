# J1-3 应付职工薪酬调整分录复核提示词

## 概述

本提示词针对应付职工薪酬调整分录（J1-3）的复核，含账项调整（AJE）、重分类调整（RJE）及未调整错报（SUD）评估。复核须验证每笔调整有证据、借贷平衡、完整反映到J1-1审定表，并同步试算平衡表。

**法规依据：**
- 《企业会计准则第9号——职工薪酬》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **AJE影响负债与费用、RJE仅影响列报**：应付职工薪酬的AJE调整负债及对应成本费用金额（如补提社保、更正计提），RJE仅涉及列报（如短期薪酬与长期薪酬重分类），不得以RJE掩盖负债/费用错报。
2. **调整须与J1-1审定表逐笔勾稽**：审定表调整列金额必须与J1-3已确认分录逐笔一致。
3. **补提薪酬调整须有依据**：补提社保/公积金/工会经费的调整须有计提基数、法定比例及费用归集依据。
4. **调整须双向影响负债与费用**：应付职工薪酬计提调整通常对应成本费用调整（借费用/贷应付职工薪酬），须核对双向一致。
5. **审批链留痕**：超过明细层次重要性水平的调整须经合伙人/项目经理审批。
6. **TB回写一致**：确认调整已同步试算平衡表2211科目及对应费用科目。

## checklist

### 一、账项调整（AJE）

- [ ] 所有AJE是否有充分审计证据（计提基数、法定比例、费用归集等）
- [ ] AJE是否经适当层级审批
- [ ] 每笔调整分录借贷方是否完全平衡
- [ ] 调整金额是否完整反映到J1-1审定表调整列
- [ ] 补提薪酬调整是否同步影响对应成本费用科目

### 二、重分类调整（RJE）

- [ ] RJE是否仅涉及列报，未影响负债/费用总额
- [ ] 短期薪酬与长期薪酬/辞退福利之间的重分类是否恰当
- [ ] 是否存在以RJE掩盖负债/费用错报的情形

### 三、未调整错报（SUD）与勾稽

- [ ] 未调整错报累计是否超过整体重要性水平
- [ ] 与A13未调整错报汇总表索引是否完整
- [ ] 跨期调整是否正确区分本期错报与前期差错更正
- [ ] 调整后审定数是否已同步试算平衡表2211及费用科目

## risk_areas

### 高风险

1. **调整缺乏证据或未经授权**：薪酬调整无计提基数/费用归集支持，或未经审批即纳入审定表。
2. **审定表与调整金额不一致**：J1-1审定表调整列与J1-3已确认分录长期不一致。
3. **调整未同步费用**：应付职工薪酬调整未同步影响对应成本费用，负债与费用不匹配。
4. **以RJE掩盖负债/费用错报**：将薪酬错报以重分类处理，规避负债/费用影响。

### 中风险

1. **RJE误含损益影响**：重分类调整影响了费用总额而非仅列报。
2. **跨期调整分类错误**：未区分本期错报与前期差错更正。
3. **SUD累计超阈值未处理**：未调整错报累计超重要性水平但未评估。

### 低风险

1. **分录摘要、科目编码不规范**：调整分录摘要笼统或编码不规范。
2. **索引指向不完整**：调整分录未指向J1-2明细、计提检查等支持底稿。
3. **审计说明不充分**：未概括调整性质与剩余风险。
