# J1-note-soe 应付职工薪酬附注披露复核提示词（国有企业）

## 概述

本提示词针对应付职工薪酬国有企业附注披露底稿（J1-note-soe）的复核。国有企业职工薪酬披露除满足会计准则通用要求外，还须关注国资监管要求：工资总额预算管理、薪酬合规性、内退人员福利及决算报表口径一致性。

**法规依据：**
- 《企业会计准则第9号——职工薪酬》
- 《企业会计准则第30号——财务报表列报》
- 《中央企业财务决算报告管理办法》

---

## tips

1. **国企薪酬披露有双层要求**：既满足会计准则通用披露，又满足国资监管对工资总额预算与薪酬合规的披露要求。
2. **工资总额预算管理**：国企实行工资总额预算管理，附注可结合说明本期职工薪酬与核定工资总额预算的关系及执行情况。
3. **薪酬合规性关注**：国企薪酬水平须符合国资监管薪酬调控政策，附注须关注是否存在超发、违规发放福利等合规问题。
4. **内退人员福利单独关注**：国企内退人员较多的，内退福利（自内退至退休的工资社保）的确认与折现须单独关注并披露。
5. **与决算报表口径一致**：附注职工薪酬须与年度财务决算报表相关数据一致，差异编制调节说明。
6. **附注须与审定表闭环勾稽**：披露应付职工薪酬各分项合计必须与J1-1审定数勾稽。

## checklist

### 一、基础披露（与上市版共有）

- [ ] 应付职工薪酬是否按短期薪酬/离职后福利/辞退福利分类披露
- [ ] 短期薪酬各明细项目是否分项披露
- [ ] 变动表是否完整且与审定表J1-1勾稽
- [ ] 设定提存计划应缴存金额是否单独披露

### 二、国有资产监管相关披露

- [ ] 本期职工薪酬与核定工资总额预算关系是否说明
- [ ] 工资总额预算执行情况是否说明
- [ ] 薪酬水平是否符合国资监管薪酬调控政策
- [ ] 是否存在超发或违规福利并说明

### 三、内退人员福利

- [ ] 内退人员福利确认与折现是否单独披露
- [ ] 内退福利金额及影响是否说明

### 四、勾稽与决算一致性

- [ ] 附注职工薪酬是否与财务决算报表数据一致
- [ ] 附注是否与J1-1审定数勾稽
- [ ] 差异是否编制调节说明

## risk_areas

### 高风险

1. **工资总额超预算未披露**：职工薪酬超核定工资总额预算但未说明，合规风险。
2. **违规发放福利未披露**：存在超发薪酬或违规发放福利但未在附注反映。
3. **附注与决算/审定表不勾稽**：披露职工薪酬与决算报表或J1-1审定数存在差异。
4. **变动表不勾稽**：应付职工薪酬变动表各项勾稽关系不成立。

### 中风险

1. **工资总额预算执行说明缺失**：未说明本期薪酬与工资总额预算的执行关系。
2. **内退福利披露不足**：内退人员福利确认与折现未单独披露。
3. **短期薪酬明细不完整**：短期薪酬仅披露总额，未分项披露。

### 低风险

1. **披露格式未按决算模板**：附注格式与国资委决算模板有细微差异。
2. **文字说明模板化**：薪酬政策说明照搬会计政策原文。
3. **可比信息不完整**：仅披露期末数，未列期初可比数。
