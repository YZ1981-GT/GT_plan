# J3-1 股份支付情况表复核提示词

## 概述

本提示词针对股份支付情况表（J3-1）的复核。该表列示股份支付计划的类型（权益结算/现金结算）、授予日公允价值、等待期、可行权条件及各期费用确认，是股份支付审计的核心底稿。复核聚焦股份支付分类、授予日公允价值计量、等待期分摊及可行权条件处理。

**法规依据：**
- 《企业会计准则第11号——股份支付》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **权益结算与现金结算处理迥异**：权益结算股份支付以授予日权益工具公允价值计量、后续不重新计量、贷记资本公积；现金结算以每个资产负债表日的负债公允价值重新计量、贷记应付职工薪酬，须核对分类判定正确。
2. **授予日公允价值是权益结算计量基础**：权益结算股份支付的费用总额基于授予日权益工具公允价值×预计可行权数量，须核对估值模型（如B-S模型）、参数及授予日确定的合理性，且授予日后不因市价变动重新计量。
3. **等待期内分摊费用**：股份支付费用应在等待期内按预计可行权情况分期计入成本费用，可行权条件为服务期限/业绩条件的须核对分摊逻辑与预计可行权数量的调整。
4. **可行权条件区分市场/非市场条件**：市场条件（如股价目标）在授予日公允价值中考虑、不因未满足而转回；非市场条件（如服务期/盈利目标）影响预计可行权数量、可后续调整，须核对处理正确。
5. **加速行权须一次性确认**：发生加速行权（如提前解锁）的，剩余等待期未确认费用须在加速日一次性确认，须核对是否恰当。
6. **与资本公积/应付职工薪酬勾稽**：权益结算股份支付累计费用应与M2资本公积（其他资本公积）勾稽；现金结算应与应付职工薪酬勾稽。

## checklist

### 一、分类与计量

- [ ] 股份支付类型（权益结算/现金结算）判定是否正确
- [ ] 权益结算是否按授予日公允价值计量且后续不重新计量
- [ ] 现金结算是否按资产负债表日负债公允价值重新计量
- [ ] 授予日公允价值估值模型/参数是否合理

### 二、等待期分摊

- [ ] 费用是否在等待期内分期确认
- [ ] 预计可行权数量是否合理并适时调整
- [ ] 本期确认费用金额是否正确
- [ ] 各期分摊逻辑是否一致

### 三、可行权条件

- [ ] 市场条件是否在授予日公允价值中考虑
- [ ] 非市场条件是否影响预计可行权数量
- [ ] 市场条件未满足是否未转回费用（正确）
- [ ] 加速行权是否一次性确认剩余费用

### 四、勾稽与联动

- [ ] 权益结算累计费用是否与M2资本公积勾稽
- [ ] 现金结算负债是否与应付职工薪酬勾稽
- [ ] 本期费用是否计入相关成本费用并与利润表勾稽

## risk_areas

### 高风险

1. **分类判定错误**：权益结算与现金结算判定错误导致后续计量方式错误（是否重新计量），费用与负债/权益失真。
2. **授予日公允价值计量不当**：估值模型/参数不合理或授予日确定错误，导致费用总额失真。
3. **权益结算违规重新计量**：权益结算股份支付因市价变动重新计量，违反准则。
4. **加速行权未一次性确认**：加速行权时剩余等待期费用未一次性确认，费用滞后。
5. **与资本公积/应付职工薪酬不勾稽**：累计费用与M2资本公积或应付职工薪酬存在无源差异。

### 中风险

1. **预计可行权数量未调整**：非市场条件变化时预计可行权数量未适时调整，费用分摊失真。
2. **市场条件处理错误**：市场条件未在授予日公允价值中考虑，或未满足时错误转回。
3. **等待期分摊不一致**：各期费用分摊逻辑不一致。

### 低风险

1. **估值参数文档不全**：授予日公允价值估值参数记录不充分。
2. **计划要素记录不完整**：股份支付计划的授予数量/行权价/等待期等记录不充分。
3. **索引缺失**：情况表与资本公积/应付职工薪酬底稿交叉索引不完整。
