# J1-9 非货币性福利检查表复核提示词

## 概述

本提示词针对非货币性福利检查表（J1-9）的复核。非货币性福利指以自产产品/外购商品/企业资产使用权/无偿提供服务等形式提供给职工的福利，须按公允价值计量并计入相关成本费用。复核聚焦非货币性福利的识别完整性、公允价值计量及税务处理。

**法规依据：**
- 《企业会计准则第9号——职工薪酬》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **非货币性福利须完整识别**：核对是否识别所有非货币性福利形式（自产产品发放、外购商品发放、企业住房/车辆供职工使用、无偿旅游/体检等），漏识别将低估费用与负债。
2. **按公允价值计量**：非货币性福利以其公允价值计入相关成本费用，自产产品按售价、外购商品按购买成本或市价，须核对计量基础是否恰当。
3. **视同销售税务处理**：以自产产品/外购商品作为福利发放通常涉及增值税视同销售，须核对是否恰当计提销项税额。
4. **企业资产供职工使用的折旧/租金**：将企业拥有的住房、车辆等无偿供职工使用的，须按折旧/应付租金计入成本费用。
5. **与成本费用及应付职工薪酬勾稽**：非货币性福利金额须计入应付职工薪酬并分配至相关成本费用，与J1-1/J1-7勾稽。
6. **检查结论支撑完整性**：非货币性福利检查发现的漏识别/计量错误应形成调整建议。

## checklist

### 一、识别完整性

- [ ] 是否识别所有非货币性福利形式
- [ ] 自产产品/外购商品发放是否识别
- [ ] 企业资产（住房/车辆）供职工使用是否识别
- [ ] 无偿服务（旅游/体检等）是否识别

### 二、公允价值计量

- [ ] 自产产品福利是否按售价（公允价值）计量
- [ ] 外购商品福利是否按购买成本/市价计量
- [ ] 企业资产使用是否按折旧/应付租金计量
- [ ] 计量基础是否恰当且有依据

### 三、税务处理

- [ ] 自产/外购商品福利是否涉及增值税视同销售
- [ ] 是否恰当计提销项税额
- [ ] 个人所得税代扣是否考虑

### 四、勾稽与联动

- [ ] 非货币性福利是否计入应付职工薪酬
- [ ] 是否分配至相关成本费用（联动J1-7）
- [ ] 检查发现的差异是否形成调整建议

## risk_areas

### 高风险

1. **非货币性福利漏识别**：未识别自产产品发放/企业资产供职工使用等福利，低估费用与负债。
2. **公允价值计量错误**：自产产品未按售价计量或外购商品计量基础错误，费用失真。
3. **视同销售税务漏处理**：自产/外购商品福利未计提增值税销项税额，少计税负。

### 中风险

1. **企业资产使用未计量**：企业住房/车辆无偿供职工使用未按折旧/租金计入费用。
2. **未计入应付职工薪酬**：非货币性福利未通过应付职工薪酬核算。
3. **个税代扣考虑不足**：非货币性福利的个人所得税代扣未考虑。

### 低风险

1. **福利形式记录不全**：非货币性福利明细记录不充分。
2. **计量依据文档缺失**：公允价值计量依据未附。
3. **索引缺失**：检查底稿与成本费用/应付职工薪酬底稿交叉索引不完整。
