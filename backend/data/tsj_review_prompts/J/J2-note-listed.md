# J2-note-listed 长期应付职工薪酬附注披露复核提示词（上市公司）

## 概述

本提示词针对长期应付职工薪酬上市公司附注披露底稿（J2-note-listed）的复核，聚焦设定受益计划披露的充分性：计划性质、净负债变动、精算假设、敏感性分析、计划资产构成及CAS9对设定受益计划披露的要求。

**法规依据：**
- 《企业会计准则第9号——职工薪酬》
- 《企业会计准则第30号——财务报表列报》

---

## tips

1. **设定受益计划性质须披露**：附注须说明设定受益计划的特征、相关风险及企业承担的义务，缺失将无法评估计划性质。
2. **净负债变动表须完整**：须披露设定受益义务现值变动表、计划资产公允价值变动表及净负债的期初到期末的调节（含服务成本/净利息/重计量/支付/缴存）。
3. **精算假设须披露**：折现率、工资增长率、死亡率、离职率等重大精算假设须披露，且须披露假设较上期的变化。
4. **敏感性分析是CAS9要求**：须披露主要精算假设（如折现率）变动对设定受益义务的敏感性影响。
5. **计划资产构成须披露**：须披露计划资产按类别（权益工具/债务工具/其他）的构成及公允价值。
6. **附注须与审定表闭环勾稽**：披露设定受益净负债期末余额必须与J2-1审定数、J2-2明细勾稽。

## checklist

### 一、计划性质与变动

- [ ] 是否披露设定受益计划的特征、风险及企业义务
- [ ] 义务现值变动表是否完整
- [ ] 计划资产公允价值变动表是否完整
- [ ] 净负债期初到期末调节是否完整

### 二、精算假设与敏感性

- [ ] 重大精算假设（折现率/工资增长率/死亡率等）是否披露
- [ ] 假设较上期变化是否披露
- [ ] 敏感性分析是否披露（主要假设变动对义务的影响）

### 三、计划资产

- [ ] 计划资产是否按类别披露构成及公允价值
- [ ] 计划资产回报是否披露

### 四、勾稽核对

- [ ] 披露设定受益净负债期末余额是否与J2-1审定数勾稽
- [ ] 各变动要素是否与J2-2明细/精算报告勾稽
- [ ] 重计量金额是否与其他综合收益变动表勾稽

## risk_areas

### 高风险

1. **净负债变动表不完整或不勾稽**：变动表要素缺失或与审定表/明细表不一致，属重大披露错误。
2. **精算假设未披露**：重大精算假设未披露，无法评估设定受益义务计量合理性。
3. **敏感性分析缺失**：未披露主要假设变动的敏感性，不满足CAS9要求。
4. **附注与审定表不一致**：披露设定受益净负债与J2-1审定数存在差异。

### 中风险

1. **计划资产构成披露不足**：仅披露计划资产总额，未按类别披露构成。
2. **假设变化未披露**：精算假设较上期变化未披露。
3. **计划性质说明不足**：设定受益计划特征与风险说明不充分。

### 低风险

1. **披露格式不规范**：表格列序、单位等格式细节问题。
2. **文字说明模板化**：计划性质说明照搬模板，未结合实际。
3. **可比信息不完整**：仅披露本期数，未列上期可比数。
