# H9-3 未确认融资费用明细表复核提示词

## 适用底稿
未确认融资费用明细表（H9-3），聚焦未确认融资费用初始金额、本期摊销、期末余额及与租赁负债、财务费用的勾稽。

## 概述
H9-3 记录租赁负债对应的未确认融资费用（租赁付款额名义总额与现值之差）的初始确认及后续摊销。复核须关注未确认融资费用初始计算、按实际利率法摊销计入财务费用及与租赁负债、摊销表的勾稽。

---

## tips

1. **未确认融资费用初始计算**：未确认融资费用=租赁付款额名义总额-租赁负债现值，反映租赁隐含的融资成本。
2. **实际利率法摊销**：未确认融资费用按实际利率法在租赁期内摊销计入财务费用，每期摊销额=租赁负债期初余额×折现率。
3. **摊销勾稽财务费用**：本期摊销额须计入财务费用（利息费用），与利润表财务费用勾稽。
4. **期末余额勾稽**：期末未确认融资费用余额=期初-本期摊销，与租赁负债余额存在配比关系。
5. **列报为负债备抵**：未确认融资费用作为租赁负债的备抵项目列示，净额为租赁负债账面价值。
6. **摊销勾稽摊销表**：本期摊销须与H9摊销表、H9-1审定表未确认融资费用区块勾稽。

## checklist

### 一、初始确认

- [ ] 未确认融资费用初始金额是否等于名义总额减现值
- [ ] 初始金额是否与H9-2租赁负债现值配比
- [ ] 新增租赁的未确认融资费用是否正确确认

### 二、摊销计算

- [ ] 本期摊销是否按实际利率法计算
- [ ] 摊销额是否与H9摊销表一致
- [ ] 摊销是否计入财务费用（利息费用）
- [ ] 摊销与租赁负债计息是否配比

### 三、期末余额与勾稽

- [ ] 期末余额=期初-本期摊销是否成立
- [ ] 期末余额是否与租赁负债余额配比
- [ ] 本期摊销是否与利润表财务费用勾稽
- [ ] 是否与H9-1审定表未确认融资费用区块勾稽

### 四、列报

- [ ] 未确认融资费用是否作为租赁负债备抵列示
- [ ] 净额是否为租赁负债账面价值
- [ ] 租赁变更导致的未确认融资费用调整是否恰当
- [ ] 是否与H9-4调整分录勾稽

## risk_areas

### 高风险

1. **摊销金额错误影响财务费用**：未确认融资费用摊销错误直接影响财务费用和利润。
2. **初始计算错误**：名义总额或现值错误导致未确认融资费用失真。
3. **摊销与计息不配比**：摊销与租赁负债计息不一致，双区块勾稽断裂。

### 中风险

1. **列报方式错误**：未按负债备抵列示或净额计算错误。
2. **租赁变更调整遗漏**：变更未导致未确认融资费用相应调整。
3. **摊销与摊销表不符**：本期摊销与H9摊销表不一致。

### 低风险

1. **明细列示不清**：未确认融资费用明细列示不完整。
2. **索引不完整**：明细未与H9-1、H9-2、摊销表建立索引。
