# H8-11 使用权资产可收回金额测试表复核提示词

## 适用底稿
使用权资产可收回金额测试表（H8-11），聚焦可收回金额两种口径测算细节、现金流量预测合理性、折现率及模型逻辑的正确性。

## 概述
H8-11 是H8-10减值测算的支撑底稿，详细测算使用权资产（或其所属资产组）的可收回金额。复核须关注公允价值减处置费用与未来现金流量现值两种口径测算的完整性、现金流量预测的可靠性及折现率取值。

---

## tips

1. **两种口径孰高**：可收回金额取公允价值减处置费用与预计未来现金流量现值孰高，两者均应测算。
2. **现金流量匹配资产组**：使用权资产通常并入资产组测试，现金流量预测须基于资产组整体（如门店经营现金流）。
3. **现金流量预测期间**：预测期间通常与剩余租赁期匹配，超过部分谨慎处理。
4. **现金流量不含租赁付款**：以现金流量现值确定资产组可收回金额时，若资产组含使用权资产，现金流出不应重复扣除租赁付款额（避免双重计算，注意与租赁负债的关系）。
5. **折现率反映风险**：采用反映资产组特定风险的税前折现率。
6. **模型逻辑校验**：折现期间、现金流量时点、终值处理须校验正确。

---

## checklist

### 一、测算口径

- [ ] 是否同时测算两种口径并取孰高
- [ ] 公允价值来源和处置费用估计是否合理

### 二、现金流量预测

- [ ] 现金流量是否基于资产组整体合理预测
- [ ] 预测期间是否与剩余租赁期/资产使用期匹配
- [ ] 现金流量与租赁付款额的关系处理是否正确（避免双重计算）
- [ ] 预测假设是否与经营预算、H8-10迹象一致

### 三、折现率与模型

- [ ] 折现率是否反映资产组特定风险且有依据
- [ ] 折现期间与现金流量时点是否匹配
- [ ] 终值处理是否恰当
- [ ] 是否进行关键假设敏感性分析

### 四、结论与衔接

- [ ] 可收回金额结果是否传递至H8-10
- [ ] 是否需利用估值专家并评估其工作
- [ ] 测算结论是否支持减值判断

## risk_areas

### 高风险

1. **单口径低估减值**：仅测算一种口径且取值偏高掩盖减值。
2. **现金流双重计算错误**：资产组含使用权资产时错误扣除租赁付款额扭曲可收回金额。
3. **折现率过低/预测乐观**：高估可收回金额规避减值。

### 中风险

1. **预测期间不当**：现金流量预测期间与资产使用期不匹配。
2. **敏感性分析缺失**：关键假设未做敏感性分析。
3. **资产组基础不清**：资产组现金流量基础界定不清。

### 低风险

1. **模型文档不完整**：测算逻辑和参数记录不足。
2. **专家利用评估不足**：复杂测算未评估是否需专家。
