# H5-5 油气资产会计政策检查 复核提示词

## 概述

本提示词针对油气资产会计政策检查表（H5-5，CAS27）的复核，聚焦勘探支出处理方法（成功努力法/全部成本法）、折耗方法（单位产量法）、储量口径及弃置费用政策的合规性与一贯性。CAS27是油气资产会计的专项准则。

## tips

1. **勘探支出方法**：成功努力法（失败井费用化）与全部成本法的选择须明确且一贯，我国准则通常采用成功努力法思路。
2. **折耗方法**：油气资产按单位产量法计提折耗，折耗率=当期产量/（期初探明储量+当期产量）或基于探明已开发储量。
3. **储量口径**：折耗基础采用探明储量还是探明已开发储量须明确一贯，矿区权益与井及设施折耗基础可能不同。
4. **弃置费用**：弃置义务按现值计入油气资产原值并确认预计负债，折现率与后续调整政策须明确（CAS13）。
5. **政策一贯**：勘探/折耗/弃置政策前后期一贯，变更须合规披露。
6. **与测算勾稽**：政策参数须与H5-12折耗测算一致。

## checklist

### 政策合规与一贯
- [ ] 勘探支出方法是否明确且一贯
- [ ] 折耗方法是否为单位产量法
- [ ] 储量口径（探明/探明已开发）是否明确一贯
- [ ] 弃置费用政策是否符合CAS13

### 联动
- [ ] 政策参数是否与H5-12折耗测算一致
- [ ] 政策变更是否合规披露
- [ ] 税会差异是否联动递延所得税

## risk_areas

### 高风险
1. **失败勘探井违规资本化虚增资产**：失败勘探井违规资本化虚增资产。
2. **折耗储量口径操纵少提折耗**：折耗储量口径操纵少提折耗。

### 中风险
1. **弃置费用政策不符CAS13**：弃置费用政策不符CAS13。
2. **政策前后期不一贯**：政策前后期不一贯。

### 低风险
1. **政策描述模板化**：政策描述模板化。
2. **税会差异说明不足**：税会差异说明不足。
