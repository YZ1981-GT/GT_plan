# H6-4 固定资产清理过程检查表复核提示词

## 适用底稿
固定资产清理过程检查表（H6-4），聚焦处置审批合规性、清理凭证核对完整性、处置收入完整性、报废毁损核销证据充分性及净损益归类准确性。

## 概述
H6-4 通过对清理项目的凭证级检查，验证固定资产处置的真实性、合规性和完整性。复核须关注处置授权链条、清理全流程单据核对、处置收入是否入账完整以及异常处置的识别与标注。

---

## tips

1. **处置审批链条须完整**：从处置申请→评估/定价→审批（超权限须董事会/股东会/三重一大）→执行→账务处理，各环节授权手续须齐备，重大处置尤须关注决策程序合规性。
2. **清理凭证核对覆盖全链条**：处置合同→资产交割/报废批复→评估报告→收款凭证→账务处理凭证，各环节单据须相互印证。
3. **处置收入完整性是核查重点**：核对处置价款、残料变价、保险赔偿是否全额入账，警惕账外收款、以物抵债未入账、赔偿款私分等。
4. **报废毁损须有实物核销证据**：报废/毁损资产须有技术鉴定、报废清单、实物处理记录，避免虚假报废掩盖资产流失或体外循环。
5. **关注关联方及低价处置**：处置对象为关联方或处置价格显著低于评估价/账面净值的，须实施针对性的公允性核查。
6. **检查比例与样本选取**：大额处置项目应全覆盖检查，其余按CAS1314合理抽样，检查比例须满足审计目标。

## checklist

### 一、处置审批合规性

- [ ] 每笔处置是否有恰当层级的审批（对照授权审批制度）
- [ ] 超过授权权限的重大处置是否经董事会/股东会/三重一大决策
- [ ] 处置定价是否有评估报告或合理定价依据支持
- [ ] 关联方处置是否履行关联交易审批和回避程序
- [ ] 国有资产处置是否履行进场交易/备案等特定程序

### 二、清理凭证核对完整性

- [ ] 处置合同/协议是否齐备且条款清晰（标的/价格/交割）
- [ ] 资产交割单据/报废批复是否与处置合同一致
- [ ] 评估报告是否在有效期内且评估基准日恰当
- [ ] 账务处理凭证是否与清理明细（H6-2）逐笔对应
- [ ] 处置日期、账务记录日期、实物交割日期是否一致

### 三、处置收入完整性

- [ ] 处置价款是否与银行进账单/收款凭证核对一致
- [ ] 残料变价收入是否入账完整
- [ ] 保险赔偿/责任人赔偿是否全额入账
- [ ] 是否存在以物抵债、债务重组等非现金对价未恰当入账
- [ ] 是否实施期后收款测试验证处置收入的真实性

### 四、报废毁损与异常识别

- [ ] 报废/毁损是否有技术鉴定或报废清单支持
- [ ] 报废资产实物处理是否有记录（销毁/回收/变卖）
- [ ] 是否存在账面报废但实物仍在使用的情况
- [ ] 处置价格显著偏低的项目是否已标注并调查原因
- [ ] 期末集中处置/关联方处置等异常交易是否重点核查

## risk_areas

### 高风险

1. **虚假报废掩盖资产流失**：以报废名义核销账面资产，实物被私自变卖或转移，赔偿/变价款体外循环。
2. **处置收入不入账**：处置价款、残料变价、赔偿款未全额入账形成账外资金，构成舞弊。
3. **关联方低价处置利益输送**：向关联方以显著低价处置资产，损害企业利益且未履行关联交易程序。
4. **超权限处置未审批**：重大资产处置未经董事会/股东会/三重一大决策即已执行。

### 中风险

1. **凭证链条不完整**：缺少评估报告、交割单据或收款凭证，处置真实性证据不足。
2. **报废证据不充分**：报废资产缺乏技术鉴定或实物处理记录。
3. **处置定价依据缺失**：处置价格无评估或定价依据支持。
4. **净损益归类错误**：处置性质判断错误导致损益结转科目错误。

### 低风险

1. **检查比例不足**：实际检查比例低于计划水平，样本代表性不足。
2. **日期核对差异**：处置、账务、交割日期存在小幅偏差未说明。
3. **底稿记录不规范**：检查结果记录格式不统一或索引不完整。
