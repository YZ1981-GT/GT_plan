# H1-18 固定资产关联交易 复核提示词

## 概述

本提示词针对固定资产关联交易检查表（H1-18）的复核，聚焦关联方购建/处置固定资产的识别完整性、交易价格公允性、关联方清单核对及披露充分性。关联方固定资产交易是舞弊与利益输送高发领域。

## tips

1. **关联方完整**：关联方固定资产交易须与B19关联方清单核对，防止未识别关联方交易漏报。
2. **价格公允**：关联方购建/处置价格须与市场价、评估价对比，异常偏离须评估利益输送。
3. **交易实质**：关注以固定资产交易名义进行的资金占用或利益输送。
4. **披露完整**：关联方固定资产交易金额、定价方式、期末往来余额须按CAS36披露。
5. **国企特别关注**：国企与同受国有控制单位的资产划转须评估合规性与公允性。
6. **异常低价处置预警**：向关联方低价处置固定资产须重点核查审批与评估。

## checklist

### 识别与公允性
- [ ] 关联方交易是否与B19清单核对完整
- [ ] 购建/处置价格是否公允（对比市场/评估价）
- [ ] 交易实质是否清晰（非资金占用/利益输送）
- [ ] 异常低价处置是否重点核查

### 披露与合规
- [ ] 交易金额/定价方式/往来余额是否披露
- [ ] 国企资产划转是否合规
- [ ] 审批程序是否完整

## risk_areas

### 高风险
1. **关联方低价处置资产利益输送**：关联方低价处置资产利益输送。
2. **未识别关联方交易漏报**：未识别关联方交易漏报。

### 中风险
1. **交易价格公允性未评估**：交易价格公允性未评估。
2. **披露不完整**：披露不完整。

### 低风险
1. **定价方式说明不充分**：定价方式说明不充分。
2. **与B19索引不完整**：与B19索引不完整。
