# H1-1 固定资产审定表 复核提示词

## 概述

本提示词针对固定资产审定表（H1-1）的复核，聚焦原值、累计折旧、减值准备三栏的期初期末勾稽、与试算平衡表（1601/1602/1603）核对、审计调整完整性及账面净值列报准确性。审定表承载未审数→调整→审定数的完整链路，是固定资产科目审计的枢纽底稿。

## tips

1. **三栏勾稽是审定表生命线**：账面净值=原值−累计折旧−减值准备，三栏各自期末=期初+本期增加−本期减少，任一栏勾稽断裂均需追溯至明细表或调整分录。
2. **试算平衡表核对不可省**：原值合计须与TB 1601一致，累计折旧须与1602一致（贷方备抵），减值准备须与1603一致，方向与金额双核对。
3. **期初承前**：期初审定数须等于上年期末审定数，追溯调整或政策变更导致的差异须有说明与依据。
4. **调整完整反映**：所有已确认AJE/RJE须逐笔落入审定表调整列，审定数=未审+AJE+RJE，遗漏即失真。
5. **净值列报关注受限资产**：抵押、查封、闲置固定资产的净值须在报表附注单独披露，审定表应有索引。
6. **变动异常追溯**：期末较期初变动超过重要性或20%的行项目需追溯至增加/减少检查底稿评估合理性。

## checklist

### 期初期末勾稽
- [ ] 期初未审数是否等于上年审定表期末审定数
- [ ] 三栏（原值/累计折旧/减值）期末=期初+增加−减少是否成立
- [ ] 账面净值=原值−累计折旧−减值准备是否逐行成立
- [ ] 审定表增减变动是否与H1-2明细表一致

### 试算平衡表核对
- [ ] 原值审定合计是否与TB 1601一致
- [ ] 累计折旧审定合计是否与TB 1602一致（备抵方向）
- [ ] 减值准备审定合计是否与TB 1603一致
- [ ] 未审数、调整数（AJE+RJE）是否与TB口径一致

### 审计调整与列报
- [ ] 已确认AJE/RJE是否完整反映在调整列且借贷平衡
- [ ] 折旧测算（H1-12）差异是否已作调整
- [ ] 减值测算（H1-14）结果是否已计入减值准备
- [ ] 受限/抵押固定资产是否有披露索引
- [ ] 分类（房屋建筑物/机器设备/运输工具/电子设备等）是否准确

## risk_areas

### 高风险
1. **累计折旧栏与TB 1602不勾稽**，掩盖少提折旧导致资产虚增、利润虚增。
2. **减值准备遗漏计入**，H1-14已测算应减值但审定表未反映。
3. **期初审定数与上年期末不一致**，基准失真波及全期。

### 中风险
1. **审定表与明细表增减变动不勾稽**：审定表与明细表增减变动不勾稽。
2. **折旧测算差异未作调整分录**：折旧测算差异未作调整分录。
3. **分类错误（如经营租出资产未单独列示）**：分类错误（如经营租出资产未单独列示）。

### 低风险
1. **底稿交叉索引不完整**：底稿交叉索引不完整。
2. **变动较大行项目缺简要说明**：变动较大行项目缺简要说明。
3. **前期可比数据缺失**：前期可比数据缺失。
