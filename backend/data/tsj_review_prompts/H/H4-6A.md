# H4-6A 工程物资监盘计划 复核提示词

## 概述

本提示词针对工程物资监盘计划（H4-6A）的复核，聚焦监盘范围、抽样合理性、重点物资确定及监盘程序设计。工程物资监盘获取存在性与状态证据。

## tips

1. **范围覆盖重大**：监盘范围覆盖大额、大型设备、易损耗、异地存放的工程物资。
2. **双向抽查**：账面抽查实物（存在性）与实物抽查账面（完整性）双向设计。
3. **重点物资标注**：长期积压、大型专用设备、异地物资列为重点。
4. **状态记录安排**：计划记录物资状态（完好/毁损/积压），联动减值。
5. **异地物资替代**：异地物资替代程序预先设计。
6. **与盘点衔接**：计划样本与H4-6盘点检查对应。

## checklist

### 范围与抽样
- [ ] 监盘范围是否覆盖大额/大型设备/异地物资
- [ ] 抽样是否双向
- [ ] 重点物资（积压/大型/异地）是否标注
- [ ] 异地物资替代程序是否设计

### 安排与衔接
- [ ] 监盘时点是否接近资产负债表日
- [ ] 计划样本是否与H4-6对应

## risk_areas

### 高风险
1. **范围遗漏大额或异地物资**：范围遗漏大额或异地物资。
2. **仅单向抽查**：仅单向抽查。

### 中风险
1. **重点物资未标注**：重点物资未标注。
2. **异地物资替代缺失**：异地物资替代缺失。

### 低风险
1. **时点安排不合理**：时点安排不合理。
2. **人员分工不明确**：人员分工不明确。
