# H2-note-listed 在建工程附注披露 复核提示词（上市公司）

## 概述

本提示词针对在建工程上市公司附注披露底稿的复核，聚焦重要在建工程项目明细披露（预算数/期末余额/工程进度/累计资本化利息/本期资本化利息及资本化率/资金来源）、减值准备披露及转固情况的充分性。上市公司在建工程披露要求细化。

## tips

1. **重要项目明细**：重要在建工程须逐项披露名称、预算数、期末余额、工程进度、累计投入占预算比例。
2. **资本化利息披露**：须披露本期资本化利息金额、资本化率及累计资本化利息（勾稽H2-10/H2-11）。
3. **变动表勾稽**：在建工程增减变动（增加/转固/其他减少/期末）须与审定表勾稽。
4. **减值准备披露**：在建工程减值准备计提情况须披露（勾稽H2-15）。
5. **资金来源披露**：重要工程资金来源（自有/借款）须披露。
6. **附注总额勾稽**：附注在建工程期末余额须等于审定表审定数。

## checklist

### 项目明细与利息
- [ ] 重要工程是否逐项披露（预算/余额/进度/占比）
- [ ] 本期资本化利息、资本化率是否披露
- [ ] 累计资本化利息是否披露且与测算勾稽
- [ ] 资金来源是否披露

### 变动与减值
- [ ] 增减变动是否与审定表勾稽
- [ ] 减值准备计提是否披露
- [ ] 附注总额是否等于审定数
- [ ] 是否列示期初可比数据

## risk_areas

### 高风险
1. **资本化利息/资本化率披露与测算不符**：资本化利息/资本化率披露与测算不符。
2. **附注总额与审定表不勾稽**：附注总额与审定表不勾稽。

### 中风险
1. **重要项目明细不完整**：重要项目明细不完整。
2. **减值准备未披露**：减值准备未披露。

### 低风险
1. **资金来源披露简略**：资金来源披露简略。
2. **可比数据缺失**：可比数据缺失。
