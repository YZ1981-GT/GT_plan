# H5-note-listed 油气资产附注披露 复核提示词（上市公司）

## 概述

本提示词针对油气资产上市公司附注披露底稿的复核，聚焦油气资产变动表（矿区权益/井及设施的原值/累计折耗/减值/账面价值四栏）勾稽、折耗政策与储量口径披露、探明储量信息、弃置义务及受限资产披露的充分性。油气行业披露要求专业性强。

## tips

1. **变动表四栏勾稽**：矿区权益与井及设施分别列示原值/累计折耗/减值/账面价值变动，与审定表勾稽。
2. **折耗政策披露**：披露折耗方法（单位产量法）、储量口径（探明/探明已开发）及勘探支出处理方法。
3. **探明储量信息**：披露探明储量变动情况及对折耗的影响（油气行业专项披露）。
4. **弃置义务披露**：披露油气资产弃置义务、弃置费用现值及预计负债（联动CAS13）。
5. **受限资产披露**：矿业权抵押、油气资产抵押须披露受限金额与对象。
6. **附注总额勾稽**：附注期末余额须等于审定表审定数。

## checklist

### 变动表与政策
- [ ] 四栏变动表是否完整并与审定表勾稽
- [ ] 矿区权益/井及设施是否分别披露
- [ ] 折耗方法/储量口径/勘探支出处理是否披露
- [ ] 是否列示期初可比数据

### 储量与专项
- [ ] 探明储量变动及对折耗影响是否披露
- [ ] 弃置义务/弃置费用/预计负债是否披露
- [ ] 抵押受限油气资产是否披露
- [ ] 附注总额是否等于审定数

## risk_areas

### 高风险
1. **变动表与审定表不勾稽**：变动表与审定表不勾稽。
2. **储量口径/折耗政策披露缺失或误导**：储量口径/折耗政策披露缺失或误导。
3. **弃置义务未披露**：弃置义务未披露。

### 中风险
1. **探明储量信息披露不足**：探明储量信息披露不足。
2. **受限资产未披露**：受限资产未披露。

### 低风险
1. **折耗政策描述模板化**：折耗政策描述模板化。
2. **可比数据缺失**：可比数据缺失。
