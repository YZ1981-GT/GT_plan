# H3-7 投资性房地产折旧测算 复核提示词

## 概述

本提示词针对投资性房地产折旧测算表（H3-7，仅成本模式）的复核，聚焦房屋折旧与土地使用权摊销的方法/年限/残值应用、含减值分段重算及本期计提与明细/审定的勾稽。公允价值模式不适用本表。

## tips

1. **仅成本模式适用**：公允价值模式不计提折旧摊销，本表仅成本模式使用，模式判断须正确。
2. **房屋折旧+土地摊销**：房屋按折旧、土地使用权按摊销，分别测算。
3. **方法参数一致**：折旧摊销方法/年限/残值须与H3-4会计政策一致。
4. **减值分段重算**：计提减值后折旧摊销基于减值后价值与剩余年限重算。
5. **本期计提勾稽**：测算本期折旧摊销合计须与H3-2明细、H3-1审定累计折旧变动一致。
6. **起止时点**：折旧摊销起止时点准确。

## checklist

### 模式与参数
- [ ] 是否仅成本模式使用本表
- [ ] 房屋折旧/土地摊销是否分别测算
- [ ] 方法/年限/残值是否与H3-4一致
- [ ] 起止时点是否准确

### 减值与勾稽
- [ ] 含减值是否分段重算
- [ ] 本期计提是否与H3-2/H3-1勾稽

## risk_areas

### 高风险
1. **公允价值模式误计提折旧**：公允价值模式误计提折旧。
2. **参数与政策不符少提折旧**：参数与政策不符少提折旧。

### 中风险
1. **减值后未重算**：减值后未重算。
2. **本期计提不勾稽**：本期计提不勾稽。

### 低风险
1. **起止时点错误**：起止时点错误。
2. **测算格式不规范**：测算格式不规范。
