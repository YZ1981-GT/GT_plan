# H9-1 租赁负债审定表复核提示词

## 概述

本提示词针对租赁负债（承租人，CAS21）审定表（H9-1）的复核。该表按负债类双区块（租赁负债+未确认融资费用）承载期初、增减、期末审定，并区分流动与非流动列报。复核聚焦初始计量与使用权资产勾稽、实际利率法计息、本息偿还及一年内到期部分重分类。

**法规依据：**
- 《企业会计准则第21号——租赁》（承租人会计处理）
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **租赁负债与使用权资产初始勾稽**：租赁负债初始计量=尚未支付的租赁付款额现值，与H8使用权资产初始成本存在勾稽关系，是CAS21承租人会计核心逻辑，须交叉核对。
2. **实际利率法计息**：租赁负债后续按实际利率法计息，每期利息=期初负债余额×折现率，计入财务费用（未确认融资费用摊销），核对计息准确性。
3. **本息偿还拆分**：每期租赁付款拆分为偿还本金（减少租赁负债）和利息（财务费用），核对拆分是否与摊销表（H9摊销表）一致。
4. **流动与非流动列报**：一年内到期的租赁负债须重分类至一年内到期的非流动负债/流动负债，核对重分类金额和列报。
5. **期初期末勾稽**：期末租赁负债=期初+新增-本期偿还本金±租赁变更重估，期初=上年期末（首年执行须关注衔接）。
6. **审定表是跨底稿勾稽枢纽**：审定数须与H9-2租赁负债明细、H9-3未确认融资费用明细、H9摊销表、H8使用权资产勾稽一致。

## checklist

### 一、初始计量与使用权资产勾稽

- [ ] 租赁负债初始计量=未付租赁付款额现值是否正确
- [ ] 租赁负债初始金额是否与H8使用权资产初始成本勾稽
- [ ] 新增租赁负债是否与H8新增使用权资产对应
- [ ] 折现率选取（内含利率/增量借款利率）是否恰当
- [ ] 首年执行新准则衔接调整是否恰当

### 二、双区块结构与计息

- [ ] 租赁负债与未确认融资费用双区块是否齐全
- [ ] 实际利率法计息金额是否与H9摊销表一致
- [ ] 未确认融资费用摊销是否计入财务费用
- [ ] 每期本息拆分（本金/利息）是否正确
- [ ] 期末=期初+新增-偿还本金±重估是否成立

### 三、流动非流动列报

- [ ] 一年内到期的租赁负债是否正确重分类
- [ ] 重分类金额是否准确（未来12个月内偿还本金）
- [ ] 流动与非流动列报是否恰当
- [ ] 重分类是否与H9-4调整分录勾稽

### 四、调整与勾稽

- [ ] 所有AJE/RJE是否完整反映在审定表
- [ ] 租赁变更导致的负债重估是否恰当（与H8-7勾稽）
- [ ] 审定数是否与试算平衡表租赁负债科目勾稽
- [ ] 审定数是否与H9-2、H9-3明细勾稽
- [ ] 审定表列报是否与附注披露一致

## risk_areas

### 高风险

1. **租赁负债与使用权资产不勾稽**：初始计量金额不匹配，违反CAS21承租人会计核心逻辑。
2. **低估租赁负债（表外融资倾向）**：通过高折现率、错误租赁期或滥用豁免低估租赁负债。
3. **计息错误**：实际利率法计息金额错误或未确认融资费用摊销不当，影响财务费用和负债余额。
4. **流动非流动重分类遗漏**：一年内到期部分未重分类，影响流动性列报。
5. **期初衔接调整错误**：首年执行新准则追溯调整错误导致期初数失真。

### 中风险

1. **本息拆分错误**：本金和利息拆分与摊销表不一致。
2. **租赁变更重估遗漏**：租赁变更未导致负债相应重估。
3. **未确认融资费用列示错误**：双区块勾稽关系不成立。
4. **调整分录方向错误**：RJE借贷方向颠倒或金额与明细不符。

### 低风险

1. **双区块列示不清**：租赁负债与未确认融资费用列示不清晰。
2. **底稿索引不完整**：审定表未与明细、摊销表、H8建立索引。
3. **格式不规范**：列标题、编号等格式细节问题。
