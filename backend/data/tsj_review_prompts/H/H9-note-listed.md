# H9-note-listed 租赁负债附注披露复核提示词（上市公司）

## 概述

本提示词针对上市公司租赁负债附注披露底稿（H9-note-listed）的复核。聚焦租赁负债到期期限分析（流动性风险）、利息费用披露、租赁现金流出、可变租金及CAS21承租人租赁负债特有披露，并关注与使用权资产（H8）披露的联动一致性。

**法规依据：**
- 《企业会计准则第21号——租赁》（承租人披露要求）
- 《企业会计准则第30号——财务报表列报》
- 《公开发行证券的公司信息披露编报规则第15号——财务报告的一般规定》

---

## tips

1. **到期期限分析是流动性风险核心披露**：须披露租赁负债未来现金流出的到期期限分析（如1年内/1-2年/2-3年/3-5年/5年以上），支持流动性风险披露。
2. **利息费用单独披露**：本期确认的租赁负债利息费用（计入财务费用）须单独披露。
3. **租赁现金流出总额**：本期租赁的现金流出总额须披露，与现金流量表筹资活动（偿还租赁负债本金）和经营活动（利息、可变租金、短期/低价值租金）勾稽。
4. **与使用权资产联动**：租赁负债披露须与使用权资产（H8）披露联动，初始确认、变更、余额相互印证。
5. **可变租金与承诺**：未纳入租赁负债的可变租金、尚未开始的重大租赁承诺须披露。
6. **售后租回融资**：售后租回中形成的租赁负债须结合销售是否成立的判断恰当披露。

## checklist

### 一、到期期限分析

- [ ] 租赁负债到期期限分析是否完整列示
- [ ] 各期限段金额合计是否与租赁负债余额勾稽
- [ ] 期限分析是否支持流动性风险披露
- [ ] 期限分析是否与H9-2明细勾稽

### 二、利息与现金流出

- [ ] 本期租赁负债利息费用是否单独披露
- [ ] 利息费用是否与财务费用、摊销表勾稽
- [ ] 租赁现金流出总额是否披露
- [ ] 现金流出是否与现金流量表勾稽（本金筹资/利息等经营）

### 三、流动非流动与余额

- [ ] 一年内到期租赁负债是否单独列示
- [ ] 租赁负债余额是否与审定表、明细勾稽
- [ ] 未确认融资费用是否恰当列示（负债备抵）
- [ ] 是否列示上期可比数据

### 四、特殊事项与联动

- [ ] 未纳入负债的可变租金是否披露
- [ ] 尚未开始的重大租赁承诺是否披露
- [ ] 售后租回形成的租赁负债是否恰当披露
- [ ] 租赁负债披露是否与H8使用权资产披露联动一致
- [ ] 附注披露口径是否与审定表、明细一致

## risk_areas

### 高风险

1. **到期期限分析缺失或不勾稽**：未披露到期期限分析或与负债余额不一致，影响流动性风险评估。
2. **低估租赁负债披露**：通过豁免或计量低估租赁负债，未充分披露表外融资实质。
3. **与使用权资产披露不联动**：租赁负债与使用权资产披露口径不一致。
4. **现金流出与现金流量表不勾稽**：租赁现金流出披露与现金流量表分类不一致。

### 中风险

1. **利息费用未单独披露**：租赁负债利息未单独列示。
2. **可变租金披露缺失**：未纳入负债的可变租金未披露。
3. **重大租赁承诺漏披露**：尚未开始的重大租赁未披露。

### 低风险

1. **可比信息缺失**：仅披露本期数未列上期可比数。
2. **文字披露模板化**：租赁负债政策描述笼统。
3. **格式不规范**：金额单位、表格列序等细节问题。
