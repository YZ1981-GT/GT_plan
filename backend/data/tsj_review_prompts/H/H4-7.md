# H4-7 工程物资减值测算 复核提示词

## 概述

本提示词针对工程物资减值测算表（H4-7）的复核，聚焦减值迹象识别（长期积压/毁损/规格过时/工程停建物资无法使用）、可收回金额确定及减值损失计算。工程物资减值常见于停建工程配套物资。

## tips

1. **减值迹象**：长期积压未领用、毁损、规格过时、配套工程停建导致物资无法使用等须评估。
2. **可收回金额**：可收回金额=公允价值减处置费用与预计未来现金流量现值较高者（勾稽H4-8）。
3. **减值损失**：减值损失=账面价值−可收回金额，计入资产减值损失。
4. **停建配套物资**：配套工程停建的专用物资须重点评估减值。
5. **积压时限**：积压超一定期限且无使用计划的物资须评估减值或报废。
6. **联动审定**：减值须计入H4-1减值准备。

## checklist

### 迹象与计算
- [ ] 减值迹象是否逐项评估（积压/毁损/过时/停建配套）
- [ ] 可收回金额是否取较高者（勾稽H4-8）
- [ ] 减值损失计算是否正确
- [ ] 停建配套物资是否重点评估

### 联动
- [ ] 减值是否计入H4-1减值准备
- [ ] 长期积压物资是否评估减值/报废
