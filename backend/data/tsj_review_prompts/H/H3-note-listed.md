# H3-note-listed 投资性房地产附注披露 复核提示词（上市公司）

## 概述

本提示词针对投资性房地产上市公司附注披露底稿的复核，聚焦计量模式披露、变动表（成本模式四栏/公允价值模式公允价值变动）勾稽、公允价值层次披露、受限物业及租金收入披露的充分性。

## tips

1. **计量模式披露**：须披露采用成本模式还是公允价值模式，公允价值模式须披露确定方法与层次（CAS39）。
2. **变动表勾稽**：成本模式披露原值/累计折旧摊销/减值/账面价值变动；公允价值模式披露期初/公允价值变动/期末，与审定表勾稽。
3. **公允价值层次**：公允价值模式须披露公允价值层次、估值技术及第三层次关键参数。
4. **受限物业披露**：抵押、查封的投资性房地产账面价值及受限原因须披露。
5. **租金收入披露**：本期确认的租金收入及相关成本须披露（勾稽H3-14）。
6. **附注总额勾稽**：附注期末余额须等于审定表审定数。

## checklist

### 模式与变动表
- [ ] 计量模式是否披露
- [ ] 变动表是否完整并与审定表勾稽
- [ ] 公允价值模式公允价值变动是否披露
- [ ] 是否列示期初可比数据

### 公允价值与专项
- [ ] 公允价值层次/估值技术/第三层次参数是否披露
- [ ] 受限物业账面价值及原因是否披露
- [ ] 租金收入及成本是否披露
- [ ] 附注总额是否等于审定数

## risk_areas

### 高风险
1. **公允价值层次/参数披露缺失（CAS39）**：公允价值层次/参数披露缺失（CAS39）。
2. **附注总额与审定表不勾稽**：附注总额与审定表不勾稽。
3. **受限物业未披露**：受限物业未披露。

### 中风险
1. **变动表不完整**：变动表不完整。
2. **租金收入披露缺失**：租金收入披露缺失。

### 低风险
1. **计量模式披露不清**：计量模式披露不清。
2. **可比数据缺失**：可比数据缺失。
