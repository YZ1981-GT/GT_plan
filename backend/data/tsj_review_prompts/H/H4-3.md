# H4-3 工程物资调整分录汇总 复核提示词

## 概述

本提示词针对工程物资调整分录汇总表（H4-3）的复核，含账项调整、重分类调整及未调整错报评估。复核须验证调整有证据、借贷平衡、完整反映到H4-1审定表并同步试算平衡表。

## tips

1. **常见调整**：领用未及时结转补记、预付设备款到货结转、积压物资减值计提、误分类调整。
2. **与H4-1勾稽**：审定表调整列须与H4-3已确认分录逐笔一致。
3. **领用结转调整**：已领用未结转的须补作领用转在建工程/固定资产。
4. **TB回写**：确认调整同步TB 1605。
5. **SUD累计**：未调整错报与A13交叉验证。
6. **审批链**：超重要性调整须合伙人审批留痕。

## checklist

### 高风险检查项
- [ ] 每笔AJE是否有证据（领用单/到货单/减值测算）
- [ ] 调整分录借贷是否平衡
- [ ] 调整是否完整反映到H4-1
- [ ] 领用结转调整是否勾稽H2/H1

### 中风险检查项
- [ ] RJE是否仅涉及列报
- [ ] 与A13未调整错报索引是否完整
- [ ] 跨期调整是否区分本期/前期

### 低风险检查项
- [ ] 摘要、科目编码是否规范
- [ ] 编号连续、无重号风险
