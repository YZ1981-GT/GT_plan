# H3-1 投资性房地产审定表 复核提示词

## 概述

本提示词针对投资性房地产审定表（H3-1）的复核，聚焦成本模式与公允价值模式两种计量模式下的期初期末勾稽、与试算平衡表（1503投资性房地产/1504投资性房地产累计折旧/1505投资性房地产减值准备）核对、计量模式一贯性及公允价值变动列报。计量模式决定审定表结构。

## tips

1. **计量模式识别**：成本模式（计提折旧/摊销+减值）与公允价值模式（不计提折旧、公允价值变动计入当期损益）审定表结构不同，须先确认模式。
2. **成本模式勾稽**：账面净值=原值−累计折旧/摊销−减值，与TB 1503/1504/1505核对。
3. **公允价值模式勾稽**：账面价值=公允价值，本期公允价值变动计入公允价值变动损益，与TB核对。
4. **模式一贯**：计量模式一经确定不得随意变更，成本模式转公允价值模式作会计政策变更（追溯），反向不允许。
5. **期初承前**：期初审定数须等于上年期末审定数。
6. **调整完整**：AJE/RJE须完整反映，公允价值模式下公允价值变动调整须勾稽H3-8。

## checklist

### 计量模式与勾稽
- [ ] 计量模式是否明确且一贯
- [ ] 成本模式净值=原值−累计折旧−减值是否成立并与TB核对
- [ ] 公允价值模式账面=公允价值是否与TB核对
- [ ] 公允价值变动是否计入当期损益

### 调整与列报
- [ ] AJE/RJE是否完整反映且平衡
- [ ] 公允价值变动是否与H3-8勾稽
- [ ] 期初审定数是否等于上年期末
- [ ] 减值（成本模式）是否与H3-10勾稽

## risk_areas

### 高风险
1. **计量模式变更未按会计政策变更处理或反向变更**：计量模式变更未按会计政策变更处理或反向变更。
2. **公允价值模式仍计提折旧**：或成本模式确认公允价值变动。
3. **审定合计与TB不勾稽**：审定合计与TB不勾稽。

### 中风险
1. **公允价值变动与H3-8不勾稽**：公允价值变动与H3-8不勾稽。
2. **减值遗漏（成本模式）**：减值遗漏（成本模式）。

### 低风险
1. **交叉索引不完整**：交叉索引不完整。
2. **模式披露不清**：模式披露不清。
