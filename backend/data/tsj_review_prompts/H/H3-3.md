# H3-3 投资性房地产调整分录 复核提示词

## 概述

本提示词针对投资性房地产调整分录汇总表（H3-3）的复核，含账项调整、重分类调整及未调整错报评估。复核须验证调整有证据、借贷平衡、完整反映到H3-1审定表并同步试算平衡表。

## tips

1. **常见调整**：公允价值变动补记/更正、折旧摊销调整（成本模式）、减值补提、自用与投资性互转更正、误分类调整。
2. **与H3-1勾稽**：审定表调整列须与H3-3已确认分录逐笔一致。
3. **公允价值变动调整**：公允价值模式下公允价值变动应计入公允价值变动损益，误计入其他综合收益须更正。
4. **TB回写**：确认调整同步TB 1503/1504/1505。
5. **SUD累计**：未调整错报与A13交叉验证。
6. **审批链**：超重要性调整须合伙人审批留痕。

## checklist

### 高风险检查项
- [ ] 每笔AJE是否有证据（评估报告/折旧测算/减值测算）
- [ ] 调整分录借贷是否平衡
- [ ] 调整是否完整反映到H3-1
- [ ] 公允价值变动是否计入正确损益科目

### 中风险检查项
- [ ] RJE是否仅涉及列报（互转重分类）
- [ ] 与A13未调整错报索引是否完整
- [ ] 跨期调整是否区分本期/前期

### 低风险检查项
- [ ] 摘要、科目编码是否规范
- [ ] 编号连续、无重号风险

## risk_areas

### 高风险
1. **调整缺证据或未授权**：调整缺证据或未授权。
2. **公允价值变动计入错误科目**：公允价值变动计入错误科目。

### 中风险
1. **RJE误含损益**：RJE误含损益。
2. **TB未同步**：TB未同步。

### 低风险
