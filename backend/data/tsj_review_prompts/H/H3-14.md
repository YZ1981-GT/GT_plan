# H3-14 投资性房地产租金收入测算 复核提示词

## 概述

本提示词针对投资性房地产租金收入测算表（H3-14）的复核，聚焦租金收入确认方法、跨期租金递延、免租期处理及与收入底稿的勾稽。租金收入是投资性房地产收益的核心来源。

## tips

1. **直线法确认**：经营租赁租金收入按租赁期直线法确认，一次收取多期租金须递延。
2. **免租期分摊**：租赁合同含免租期的，总租金按直线法在整个租赁期（含免租期）分摊。
3. **租金递延核对**：预收租金计入合同负债/预收账款，按期确认，核对递延余额。
4. **与收入勾稽**：租金收入须与收入底稿（D4）及利润表其他业务收入勾稽。
5. **租赁物业匹配**：产生租金的物业须与H3-2明细出租物业匹配，全部出租物业均应有租金。
6. **可变租金**：与销售额挂钩的可变租金按实际发生确认。

## checklist

### 确认与递延
- [ ] 租金收入是否按直线法确认
- [ ] 免租期是否在整个租赁期分摊
- [ ] 预收租金递延余额是否核对
- [ ] 可变租金是否按实际确认

### 勾稽与匹配
- [ ] 租金收入是否与收入底稿/利润表勾稽
- [ ] 出租物业是否与H3-2明细匹配
- [ ] 是否存在出租物业无租金收入的异常

## risk_areas

### 高风险
1. **租金收入未按直线法确认或提前确认**：租金收入未按直线法确认或提前确认。
2. **出租物业无租金收入**：可能收入体外循环。

### 中风险
1. **免租期未在租赁期分摊**：免租期未在租赁期分摊。
2. **与收入底稿不勾稽**：与收入底稿不勾稽。

### 低风险
1. **可变租金确认时点不当**：可变租金确认时点不当。
2. **递延余额核对不完整**：递延余额核对不完整。
