# H4-note-soe 工程物资附注披露 复核提示词（国有企业）

## 概述

本提示词针对工程物资国有企业附注披露底稿的复核，在满足会计准则通用披露（分类/变动/减值）基础上，聚焦国资监管相关披露：大型设备采购合规性、长期积压物资处置及国有资本性支出预算执行。

## tips

1. **双层披露**：既满足CAS通用披露，又满足国资委财务决算额外要求。
2. **分类变动勾稽**：工程物资分类与变动须完整并与审定表勾稽（与上市版共有）。
3. **大型设备采购**：大型设备采购须披露采购程序（招标）与合规性。
4. **积压处置**：长期积压工程物资须披露处置计划与减值情况。
5. **资本性支出**：工程物资采购的资本性支出预算执行情况须说明。
6. **数据一致**：数据须与年度财务决算报表一致。

## checklist

### 基础披露（与上市版共有）
- [ ] 是否按类别分类披露且合计等于审定数
- [ ] 变动是否与审定表勾稽
- [ ] 减值准备是否披露

### 国资监管专项
- [ ] 大型设备采购程序合规性是否披露
- [ ] 长期积压物资处置计划是否披露
- [ ] 数据是否与年度财务决算一致

## risk_areas

### 高风险
1. **大型设备采购缺合规性说明**：大型设备采购缺合规性说明。
