# H5-16 油气资产权属检查（采矿权） 复核提示词

## 概述

本提示词针对油气资产权属检查表（H5-16，采矿权/探矿权）的复核，聚焦矿业权证的完整性、权属人一致性、有效期及抵押受限情况。矿业权是油气开采资产的法律基础。

## tips

1. **证照核对**：核对采矿许可证/探矿许可证的证号、权属人、矿区范围、有效期与账面一致。
2. **权属人一致**：矿业权登记人须为被审计单位，合作开采须评估权益归属。
3. **有效期关注**：矿业权有效期临近到期须关注续期情况及对持续开采的影响。
4. **抵押受限**：矿业权抵押须披露并联动借款底稿。
5. **矿区范围**：核对矿区范围与实际开采区域一致，越界开采风险关注。
6. **合规缴费**：矿业权出让收益/使用费缴纳合规性关注。

## checklist

### 权属核对
- [ ] 证号/权属人/矿区范围/有效期与账面是否一致
- [ ] 权属人是否为被审计单位
- [ ] 有效期临近到期是否关注续期
- [ ] 合作开采权益归属是否评估

### 受限与合规
- [ ] 矿业权抵押是否披露并勾稽借款
- [ ] 矿区范围与实际开采是否一致
- [ ] 出让收益/使用费缴纳是否合规

## risk_areas

### 高风险
1. **矿业权权属人非被审计单位**：权属存疑。
2. **矿业权到期无法续期影响持续经营**：矿业权到期无法续期影响持续经营。
3. **矿业权抵押未披露**：矿业权抵押未披露。

### 中风险
1. **越界开采风险未评估**：越界开采风险未评估。
2. **使用费缴纳不合规**：使用费缴纳不合规。

### 低风险
1. **证照信息核对不完整**：证照信息核对不完整。
2. **与借款底稿索引缺失**：与借款底稿索引缺失。
