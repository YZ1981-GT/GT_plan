# H7-1 生产性生物资产审定表复核提示词

## 概述

本提示词针对生产性生物资产（科目1621）审定表（H7-1）的复核。该表存在成本模式与公允价值模式两个版本，承载成熟/未成熟生产性生物资产的原值、累计折旧、减值准备（成本模式）或公允价值变动（公允模式）及净额审定。复核聚焦计量模式一致性、期初期末勾稽、折旧/减值完整性及分类列报准确性。

**法规依据：**
- 《企业会计准则第5号——生物资产》
- 《企业会计准则第8号——资产减值》（成本模式减值）
- 《中国注册会计师审计准则第1301号——审计证据》

## tips

1. **计量模式决定审定表结构**：成本模式=原值-累计折旧-减值准备；公允价值模式=公允价值（须有活跃市场且能可靠取得公允价值），两种模式不得混用，且模式变更须符合会计政策变更条件。
2. **区分成熟与未成熟生产性生物资产**：未成熟生产性生物资产（尚处于生长期）达到预定生产经营目的后转为成熟，成熟后才计提折旧，未成熟不提折旧，误提将虚增费用。
3. **区分生产性与消耗性生物资产**：生产性生物资产（如产畜、经济林）为长期资产，消耗性生物资产（如存栏待售牲畜、用材林）计入存货，分类错误影响资产列报和折旧处理。
4. **期初期末勾稽是生命线**：期初审定数须等于上年期末审定数，期末=期初+本期增加（外购/自行营造/繁殖）-本期减少（出售/死亡/淘汰）±折旧/减值/公允价值变动。
5. **审定表是跨底稿勾稽枢纽**：审定数须与H7-2明细表、H7-11折旧测算、H7-15减值测算（成本）或H7-13公允价值复核（公允）勾稽一致。
6. **关注异常增减**：生物资产因自然繁殖、死亡、自然灾害产生的增减须有实物记录支持，异常变动（如死亡率异常、繁殖数异常）须追查原因。

## checklist

### 一、计量模式与分类

- [ ] 计量模式（成本/公允）是否与会计政策一致且全期一贯
- [ ] 若采用公允价值模式，是否满足活跃市场且公允价值可靠取得条件
- [ ] 生产性生物资产与消耗性生物资产分类是否正确
- [ ] 成熟与未成熟生产性生物资产是否正确区分
- [ ] 计量模式变更是否符合会计政策变更条件并追溯调整

### 二、期初期末勾稽

- [ ] 期初审定数是否等于上年审定表期末审定数
- [ ] 期末=期初+本期增加-本期减少±折旧/减值/公允价值变动是否成立
- [ ] 审定表增减变动是否与H7-2明细表勾稽一致
- [ ] 本期增加（外购/繁殖/营造）是否有H7-6增加检查支持
- [ ] 本期减少（出售/死亡/淘汰）是否有H7-7减少检查支持

### 三、折旧/减值/公允价值变动

- [ ] （成本模式）成熟生产性生物资产是否计提折旧，未成熟是否未提
- [ ] （成本模式）折旧金额是否与H7-11测算、H7-12分配勾稽
- [ ] （成本模式）减值准备是否与H7-15/H7-16测算勾稽
- [ ] （公允模式）公允价值变动是否与H7-13复核勾稽
- [ ] （公允模式）公允价值变动损益列报是否正确
- [ ] 减值一经计提是否不得转回（成本模式生物资产减值）

### 四、调整与列报

- [ ] 所有AJE/RJE是否完整反映在审定表
- [ ] 调整分录借贷方是否平衡且有充分证据
- [ ] 审定表审定数合计是否与试算平衡表1621勾稽
- [ ] 审定表分类是否与财务报表附注披露一致
- [ ] 未成熟转成熟的重分类是否恰当处理

## risk_areas

### 高风险

1. **计量模式滥用公允价值**：不满足活跃市场条件却采用公允价值模式，通过公允价值变动虚增资产和利润。
2. **未成熟资产错提折旧或成熟资产漏提折旧**：折旧起止时点判断错误导致费用和净值系统性失真。
3. **生产性与消耗性分类错误**：将应计入存货的消耗性生物资产列为长期生产性生物资产，规避减值和成本结转。
4. **期初期末不勾稽**：期初数与上年期末数不一致，或增减变动无实物记录支持。
5. **异常死亡/减少不核销**：生物资产已死亡淘汰但账面未核销，虚增资产。

### 中风险

1. **折旧/减值与测算表不勾稽**：审定表折旧或减值金额与H7-11/H7-15测算结果不一致。
2. **公允价值变动损益归类错误**：公允价值模式下变动损益列报科目错误。
3. **减值转回违规**：成本模式生物资产减值准备违规转回。
4. **调整分录方向错误**：RJE借贷方向颠倒或调整金额与明细不符。

### 低风险

1. **成熟/未成熟标注不清**：审定表未清晰标注资产成熟状态。
2. **底稿索引不完整**：审定表未与明细、折旧、减值/公允测算建立索引。
3. **格式不规范**：列标题、编号等格式细节问题。
