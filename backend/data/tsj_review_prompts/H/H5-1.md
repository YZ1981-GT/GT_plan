# H5-1 油气资产审定表 复核提示词

## 概述

本提示词针对油气资产审定表（H5-1）的复核，聚焦矿区权益与井及相关设施两类资产的原值、累计折耗、减值准备勾稽、与试算平衡表（1631油气资产/1632累计折耗/减值准备）核对及审计调整完整性。油气资产按探明储量以产量法计提折耗。

## tips

1. **两类资产**：油气资产含矿区权益（探矿权/采矿权）与井及相关设施，审定表须分别列示。
2. **三栏勾稽**：账面净值=原值−累计折耗−减值准备，各栏期末=期初+增加−减少。
3. **试算平衡表核对**：原值与TB 1631一致，累计折耗与1632一致，减值与减值准备科目一致。
4. **折耗勾稽**：本期折耗须与H5-12折耗测算一致，以探明储量为基础的单位产量法计算。
5. **期初承前**：期初审定数须等于上年期末审定数。
6. **调整完整**：AJE/RJE须完整反映且平衡，弃置费用相关调整须关注。

## checklist

### 勾稽与核对
- [ ] 矿区权益/井及设施是否分别列示
- [ ] 三栏（原值/累计折耗/减值）勾稽是否成立
- [ ] 审定合计是否与TB 1631/1632核对
- [ ] 本期折耗是否与H5-12勾稽

### 调整与列报
- [ ] AJE/RJE是否完整反映且平衡
- [ ] 减值是否与H5-14勾稽
- [ ] 弃置费用资本化是否正确反映
- [ ] 期初审定数是否等于上年期末

## risk_areas

### 高风险
1. **累计折耗与TB 1632不勾稽**：少提折耗虚增资产利润。
2. **探明储量高估导致折耗不足**：探明储量高估导致折耗不足。
3. **减值遗漏**：减值遗漏。

### 中风险
1. **弃置费用处理错误**：弃置费用处理错误。
2. **两类资产未分别列示**：两类资产未分别列示。

### 低风险
1. **交叉索引不完整**：交叉索引不完整。
2. **变动较大项目缺说明**：变动较大项目缺说明。
