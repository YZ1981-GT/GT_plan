# H7-14 生产性生物资产互转审核及产量记录表复核提示词

## 适用底稿
生产性生物资产互转审核及产量记录表（H7-14），聚焦生产性/消耗性生物资产互转、成熟/未成熟转化的合规性及产量记录的完整性与合理性。

## 概述
H7-14 审核生物资产在生产性与消耗性、成熟与未成熟之间的转化，并记录生产性生物资产的产出。复核须关注互转判断标准、互转账务处理正确性及产量记录对折旧（产量法）和减值判断的支持。

---

## tips

1. **生产性↔消耗性互转标准**：生产性生物资产因丧失生产能力转为消耗性（如淘汰产畜转育肥），或消耗性转生产性（如育成种畜），互转须有明确判断标准和实物依据。
2. **互转账务处理正确**：互转按转换日账面价值结转，生产性转消耗性（1621→1411/存货），消耗性转生产性（存货→1621），核对结转金额和科目。
3. **成熟/未成熟转化时点**：未成熟转成熟以达到预定生产经营目的为准，转化后开始计提折旧，时点判断影响折旧。
4. **产量记录完整合理**：产量记录（产奶/产蛋/产果等）须完整、真实，与销售/存货记录匹配。
5. **产量支持产量法折旧**：采用产量法折旧的，产量记录是折旧计算基础，须核对可靠性。
6. **产量异常预示减值/健康问题**：产量显著下降可能预示资产减值或健康问题，须衔接减值评估。

## checklist

### 一、互转审核

- [ ] 生产性↔消耗性互转是否有明确判断标准和实物依据
- [ ] 互转是否按转换日账面价值结转
- [ ] 互转结转科目是否正确（1621↔存货）
- [ ] 互转是否办妥内部审批
- [ ] 淘汰产畜转消耗性后是否恰当计入存货并考虑可变现净值

### 二、成熟转化

- [ ] 未成熟转成熟时点判断是否恰当
- [ ] 转化后是否开始计提折旧
- [ ] 转化是否与H7-2明细、H7-11折旧勾稽

### 三、产量记录

- [ ] 产量记录是否完整（品种/期间/数量）
- [ ] 产量是否与销售收入、存货增加匹配
- [ ] 产量记录是否真实可靠（有原始记录支持）
- [ ] 产量法折旧的产量基础是否核对一致

### 四、异常与衔接

- [ ] 产量异常下降是否分析原因
- [ ] 产量异常是否衔接减值评估（H7-15）
- [ ] 互转/转化是否与审定表勾稽

## risk_areas

### 高风险

1. **互转规避减值/成本结转**：通过生产性/消耗性互转规避减值确认或存货成本结转。
2. **成熟时点操纵折旧**：操纵成熟转化时点调节折旧和利润。
3. **产量记录造假**：虚构产量支持产量法折旧或掩盖资产减值。

### 中风险

1. **互转账务处理错误**：结转金额或科目错误。
2. **产量与销售/存货不匹配**：产量记录与实际产出脱节。
3. **产量异常未衔接减值**：产量下降未评估减值。

### 低风险

1. **互转审批不完备**：互转缺乏内部审批记录。
2. **产量记录格式不规范**：产量记录要素不齐全。
