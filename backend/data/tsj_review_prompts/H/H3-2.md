# H3-2 投资性房地产明细表 复核提示词

## 概述

本提示词针对投资性房地产明细表（H3-2）的复核，聚焦按物业单项的原值/累计折旧/减值（成本模式）或公允价值（公允价值模式）明细、增减变动及与审定表、增减检查、互转审核的勾稽。

## tips

1. **明细合计=审定表**：各物业明细合计须与H3-1审定表审定数一致。
2. **增减来源可追溯**：本期增加区分外购、自用转投资性、开发完成转入；减少区分出售、转自用（勾稽H3-5、H3-6）。
3. **成本模式折旧/摊销**：房屋按折旧、土地使用权按摊销，本期计提须与H3-7勾稽。
4. **公允价值逐项**：公允价值模式下每项物业公允价值须有评估或市场依据（勾稽H3-8）。
5. **互转勾稽**：投资性房地产与自用房地产/存货互转须与H3-6互转审核一致。
6. **租金关联**：产生租金收入的物业须与H3-14租金收入勾稽。

## checklist

### 明细与增减
- [ ] 明细合计是否等于H3-1审定数
- [ ] 本期增加是否与H3-5增减检查勾稽
- [ ] 互转是否与H3-6一致
- [ ] 成本模式本期折旧/摊销是否与H3-7勾稽

### 计量与关联
- [ ] 公允价值模式逐项公允价值是否有依据（H3-8）
- [ ] 减值（成本模式）是否与H3-10勾稽
- [ ] 租金物业是否与H3-14勾稽

## risk_areas

### 高风险
1. **明细合计与审定表不符**：明细合计与审定表不符。
2. **互转金额与H3-6不勾稽**：互转金额与H3-6不勾稽。
3. **公允价值逐项缺依据**：公允价值逐项缺依据。

### 中风险
1. **折旧/摊销与H3-7不一致**：折旧/摊销与H3-7不一致。
2. **减值遗漏**：减值遗漏。

### 低风险
1. **物业明细列示不清**：物业明细列示不清。
2. **单据索引不完整**：单据索引不完整。
