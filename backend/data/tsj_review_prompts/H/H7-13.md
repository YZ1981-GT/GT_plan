# H7-13 生产性生物资产公允价值复核表复核提示词

## 适用底稿
生产性生物资产公允价值复核表（H7-13，仅公允价值模式），聚焦公允价值计量的适用条件、估值方法与输入值合理性、公允价值层次及公允价值变动损益准确性。

## 概述
H7-13 复核采用公允价值模式计量的生产性生物资产的公允价值确定过程。复核须关注是否满足活跃市场条件、估值方法与关键输入值合理性、公允价值层次划分及变动损益的正确核算与列报。

---

## tips

1. **适用条件是前提**：公允价值模式仅适用于有确凿证据表明公允价值能够持续可靠取得（存在活跃市场）的情形，须首先复核适用条件是否持续满足。
2. **估值方法恰当**：优先市场法（活跃市场报价），无活跃市场报价时采用收益法/成本法须有充分依据（CAS39公允价值计量）。
3. **公允价值层次划分**：区分第一层次（活跃市场报价）、第二层次（可观察输入值）、第三层次（不可观察输入值），层次越低估值不确定性越高。
4. **关键输入值合理性**：市场价格、生长周期、产出预期、折现率等关键输入值须合理并有支持。
5. **变动损益正确核算**：公允价值变动计入当期损益（公允价值变动损益），核对变动金额和列报科目。
6. **估值日恰当**：公允价值须以资产负债表日为估值日，估值基准日错误导致公允价值失真。

## checklist

### 一、适用条件

- [ ] 是否满足活跃市场且公允价值持续可靠取得条件
- [ ] 适用条件是否持续满足（较初始确认有无变化）
- [ ] 公允价值不再可靠取得时是否转为成本模式

### 二、估值方法与层次

- [ ] 估值方法是否恰当（优先市场法）
- [ ] 无活跃报价时收益法/成本法依据是否充分
- [ ] 公允价值层次划分是否正确
- [ ] 第三层次估值的不确定性是否评估

### 三、输入值合理性

- [ ] 市场价格来源是否可靠、时效恰当
- [ ] 生长周期/产出预期/折现率等输入值是否合理
- [ ] 关键假设是否有支持性证据
- [ ] 是否需利用估值专家并评估其工作

### 四、变动损益与列报

- [ ] 公允价值变动金额计算是否正确
- [ ] 变动损益是否计入公允价值变动损益
- [ ] 估值日是否为资产负债表日
- [ ] 公允价值及变动是否与H7-1审定表勾稽

## risk_areas

### 高风险

1. **不满足条件仍用公允价值**：无活跃市场却采用公允价值模式，通过高估公允价值虚增资产和利润。
2. **输入值操纵**：关键输入值（价格/产出/折现率）缺乏支持而高估公允价值。
3. **变动损益列报错误**：公允价值变动损益金额或科目错误影响利润表。

### 中风险

1. **估值方法不当**：无活跃报价时估值方法选择或应用不合理。
2. **层次划分错误**：低估第三层次估值的不确定性。
3. **估值专家利用不足**：复杂估值缺乏专业支持。

### 低风险

1. **估值文档不完整**：估值过程和依据记录不充分。
2. **层次披露不足**：公允价值层次信息披露不完整。
