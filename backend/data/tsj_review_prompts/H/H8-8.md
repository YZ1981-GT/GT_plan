# H8-8 使用权资产折旧测算表复核提示词

## 适用底稿
使用权资产折旧测算表（H8-8，不含减值/含减值双分支），聚焦折旧年限判断、折旧方法、折旧起算及重新测算，含减值分支下减值后折旧基数调整。

## 概述
H8-8 重新测算使用权资产折旧。复核须关注折旧年限判断（所有权转移按剩余寿命/否则孰短）、折旧方法一贯性、折旧起算时点及减值后折旧基数调整的正确性。

---

## tips

1. **折旧年限规则核心**：能合理确定租赁期届满取得资产所有权的，在剩余使用寿命内计提折旧；否则在租赁期与剩余使用寿命两者孰短期间内计提折旧，年限判断依赖H8-5租赁期。
2. **折旧方法**：通常采用直线法，与资产消耗方式匹配的可采用其他方法，须一贯运用。
3. **折旧起算时点**：自租赁期开始日（使用权资产可供使用）起计提折旧。
4. **减值后折旧基数调整**：计提减值准备后，按减值后账面价值在剩余年限内计提折旧（含减值分支），核对基数调整。
5. **重新测算验证**：独立重新计算折旧，与账面对比，差异查明。
6. **测算勾稽**：折旧测算须与H8-1累计折旧、H8-2明细、H8-9折旧分配勾稽。

## checklist

### 一、折旧年限

- [ ] 所有权转移判断是否正确（据以确定折旧年限规则）
- [ ] 未转移所有权的是否按租赁期与剩余寿命孰短
- [ ] 折旧年限是否与H8-5租赁期一致
- [ ] 租赁期变更后折旧年限是否相应调整

### 二、折旧方法与起算

- [ ] 折旧方法是否合理并一贯
- [ ] 折旧起算时点（租赁期开始日）是否正确
- [ ] 短期/低价值豁免租赁是否未纳入折旧（费用化）

### 三、折旧计算

- [ ] 重新测算折旧与账面计提是否一致
- [ ] 差异是否查明原因
- [ ] 减值后折旧基数是否按减值后账面价值调整（含减值分支）
- [ ] 折旧计算是否覆盖全部使用权资产

### 四、勾稽

- [ ] 折旧测算是否与H8-1累计折旧勾稽
- [ ] 折旧测算是否与H8-2明细勾稽
- [ ] 折旧去向是否与H8-9分配勾稽
- [ ] 双分支（不含/含减值）选择是否恰当

## risk_areas

### 高风险

1. **折旧年限判断错误**：所有权转移判断错误或未按孰短原则，系统性错计折旧。
2. **减值后基数未调整**：计提减值后仍按原值折旧，折旧和净值失真。
3. **折旧起算时点错误**：折旧起止时点操纵调节费用。

### 中风险

1. **折旧方法不一贯**：随意变更折旧方法调节费用。
2. **租赁期变更折旧未调整**：租赁期变更后折旧年限未相应调整。
3. **测算与账面差异未查明**：重新测算与账面计提差异未解释。

### 低风险

1. **测算文档不完整**：折旧要素和年限判断记录不足。
2. **双分支选择说明不足**：含/不含减值分支选择未说明。
