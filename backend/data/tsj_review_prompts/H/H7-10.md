# H7-10 生产性生物资产监盘小结复核提示词

## 适用底稿
生产性生物资产监盘小结（H7-10），聚焦监盘结论的形成、差异汇总与处理、存在性认定及对折旧/减值判断的支持。

## 概述
H7-10 汇总监盘过程和结果，形成生物资产存在性、完整性及状态的审计结论。复核须关注监盘结论是否有充分证据支持、差异是否已恰当处理、结论是否与H7-8计划和H7-9检查一致。

---

## tips

1. **结论须基于监盘证据**：存在性认定须基于H7-9实际盘点结果，不得脱离证据下结论。
2. **差异汇总须完整**：汇总全部账实差异，评估累计差异是否超过重要性水平及是否需调整。
3. **存在性认定明确**：明确认定生物资产是否真实存在、数量是否准确，异常须说明。
4. **支持折旧减值判断**：监盘观察到的成熟状态、健康状况须为折旧计提和减值评估提供依据。
5. **监盘范围充分性评价**：评价实际监盘范围/抽样是否足以支持整体存在性结论。
6. **结论与后续程序衔接**：识别出的问题（盘亏/减值迹象/闲置）须衔接调整分录、减值测算等后续程序。

## checklist

### 一、监盘结论形成

- [ ] 存在性结论是否基于H7-9实际盘点结果
- [ ] 监盘范围/抽样是否足以支持整体结论
- [ ] 结论是否与H7-8计划、H7-9检查一致
- [ ] 未按计划执行的监盘是否说明影响

### 二、差异汇总与处理

- [ ] 账实差异是否完整汇总
- [ ] 累计差异是否评估重要性影响
- [ ] 重大差异是否已提出调整并追踪
- [ ] 盘亏是否评估流失/舞弊风险

### 三、状态认定与后续衔接

- [ ] 成熟度观察是否支持折旧计提判断
- [ ] 健康/疫病观察是否支持减值评估
- [ ] 闲置/无生产能力资产是否识别并衔接减值
- [ ] 识别问题是否衔接调整分录（H7-3）/减值测算（H7-15）

### 四、结论完整性

- [ ] 监盘小结结论是否明确、有据
- [ ] 是否说明监盘的局限性和替代程序
- [ ] 底稿索引是否完整（H7-8/H7-9/H7-2）

## risk_areas

### 高风险

1. **结论脱离证据**：存在性结论无监盘证据支持或与盘点结果矛盾。
2. **重大差异未处理**：汇总差异重大但未调整、未追踪。
3. **减值迹象未衔接**：监盘发现减值迹象但未启动减值测算。

### 中风险

1. **监盘范围不足未评价**：抽样范围不足以支持结论但未评价影响。
2. **差异汇总不完整**：遗漏部分地点或品种的差异。
3. **状态观察未利用**：观察结果未支持折旧/减值判断。

### 低风险

1. **局限性说明不足**：未充分说明监盘局限和替代程序。
2. **底稿索引不完整**：小结未与计划、检查底稿建立索引。
