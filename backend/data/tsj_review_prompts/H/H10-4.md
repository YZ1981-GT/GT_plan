# H10-4 资产处置收益检查表复核提示词

## 适用底稿
资产处置收益检查表（H10-4），聚焦处置业务凭证核对、处置授权合规、处置收入完整性、损益归类准确性及异常处置识别。

## 概述
H10-4 通过对处置业务的凭证级检查，验证资产处置收益的真实、准确、完整。复核须关注处置授权链条、处置全流程凭证核对、处置收入是否入账完整、损益归类是否正确及异常处置的识别标注。

---

## tips

1. **处置授权链条完整**：处置申请→评估/定价→审批（超权限须董事会/股东会）→执行→账务处理，各环节授权须齐备，重大处置尤须关注决策程序。
2. **凭证核对覆盖全链条**：处置合同→资产交割→评估报告→收款凭证→账务凭证，各环节单据相互印证。
3. **处置收入完整性**：处置价款、残值、赔偿须全额入账，核对收款凭证、银行进账单，防止账外收款。
4. **损益归类准确**：核对处置损益是否计入资产处置收益（正常处置）还是营业外收支（非正常损失），归类须与处置性质匹配。
5. **关联方与低价处置**：处置对象为关联方或价格显著低于评估价/账面净值的须实施针对性公允性核查。
6. **检查比例与样本**：大额处置全覆盖，其余按CAS1314合理抽样，异常处置重点核查。

## checklist

### 一、处置授权合规性

- [ ] 每笔处置是否有恰当层级审批
- [ ] 超权限处置是否经董事会/股东会决策
- [ ] 处置定价是否有评估或合理定价依据
- [ ] 关联方处置是否履行关联交易审批和回避

### 二、凭证核对完整性

- [ ] 处置合同/协议是否齐备且条款清晰
- [ ] 资产交割/报废批复是否与合同一致
- [ ] 评估报告是否在有效期内、基准日恰当
- [ ] 账务凭证是否与H10-2明细逐笔对应
- [ ] 处置日期与账务日期是否一致

### 三、处置收入与损益归类

- [ ] 处置价款是否与收款凭证核对完整
- [ ] 残值/赔偿是否全额入账
- [ ] 处置损益归类（资产处置收益/营业外收支）是否正确
- [ ] 是否实施期后收款测试
- [ ] 增值税处理是否正确

### 四、异常识别

- [ ] 处置价格显著偏低项目是否标注并调查
- [ ] 关联方处置是否重点核查公允性
- [ ] 期末集中处置是否核查完成时点
- [ ] 是否存在虚假处置或收入不入账

## risk_areas

### 高风险

1. **处置收入不入账**：处置价款、残值、赔偿未全额入账形成账外资金。
2. **关联方低价处置利益输送**：向关联方低价处置且未履行关联交易程序。
3. **损益归类掩盖损失**：非正常损失错列资产处置收益美化营业利润。
4. **超权限处置未审批**：重大处置未经决策即执行。

### 中风险

1. **凭证链条不完整**：缺少评估报告、交割单据或收款凭证。
2. **损益归类错误**：处置性质判断错误导致归类错误。
3. **处置定价依据缺失**：处置价格无评估或定价依据。
4. **跨期处置调节利润**：期末集中处置操纵完成时点。

### 低风险

1. **检查比例不足**：实际检查比例低于计划水平。
2. **日期核对差异**：处置、账务、交割日期偏差未说明。
3. **底稿记录不规范**：检查结果记录格式不统一或索引不完整。
