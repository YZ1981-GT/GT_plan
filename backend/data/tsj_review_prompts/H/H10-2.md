# H10-2 资产处置收益明细表复核提示词

## 概述

本提示词针对资产处置收益明细表（H10-2）的复核。该表按逐笔处置业务登记处置资产类别、处置收入、账面净值、相关税费及处置损益，是H10-1审定表数据来源。复核聚焦明细完整性、处置损益逐笔计算、损益类别归集及与清理台账、试运行收支的勾稽。

**法规依据：**
- 《企业会计准则第42号——持有待售的非流动资产、处置组和终止经营》
- 《企业会计准则第4号——固定资产》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **明细覆盖全部计入资产处置收益的处置**：本期计入资产处置收益的所有处置业务须逐笔登记，与H6清理台账、无形资产/在建工程处置对应，无遗漏。
2. **处置损益逐笔计算**：处置损益=处置收入-账面净值-相关税费，逐笔核对至处置合同、清理台账。
3. **损益类别归集清晰**：按处置资产类别（固定资产/在建工程/无形资产/使用权资产等）归集损益，支持附注披露。
4. **试运行处置收支的特殊处理**：涉及在建工程试运行产出对外销售的，须关注是否恰当冲减在建工程成本或计入损益（试运行净额处理）。
5. **收入与净值核对**：处置收入核对至收款凭证，账面净值核对至资产台账（原值-累计折旧/摊销-减值）。
6. **明细合计回勾H10-1**：各笔处置损益合计须与H10-1审定表本期发生额一致。

## checklist

### 一、明细完整性

- [ ] 明细是否覆盖本期全部计入资产处置收益的处置业务
- [ ] 每笔是否登记处置资产类别、名称、处置日期
- [ ] 是否与H6清理台账、无形资产/在建工程处置对应
- [ ] 明细合计是否与H10-1审定表本期发生额勾稽
- [ ] 处置方式（出售/转让/对外投资等）是否标注

### 二、处置损益计算

- [ ] 处置损益=收入-账面净值-税费逐笔计算是否正确
- [ ] 处置收入是否与收款凭证核对
- [ ] 账面净值是否与资产台账核对（原值-折旧/摊销-减值）
- [ ] 相关税费（增值税等）是否准确
- [ ] 损益方向（收益/损失）是否与实际一致

### 三、类别归集与列报范围

- [ ] 损益是否按处置资产类别正确归集
- [ ] 是否仅包含应计入资产处置收益的处置
- [ ] 非正常报废毁损是否排除（列营业外支出）
- [ ] 试运行处置收支处理是否恰当

### 四、勾稽

- [ ] 固定资产处置明细是否与H6-2勾稽
- [ ] 明细损益合计是否与H10-1、利润表勾稽
- [ ] 是否与H10-3调整分录、H10-4检查表一致
- [ ] 关联方处置是否标识

## risk_areas

### 高风险

1. **处置收入不完整**：处置收入未全额登记，虚减处置收益或形成账外资金。
2. **账面净值错误**：折旧/摊销/减值截止或转出错误导致处置损益失真。
3. **明细遗漏处置业务**：本期处置业务未全部登记，损益不完整。
4. **低价处置利益输送**：向关联方低价处置未识别。

### 中风险

1. **损益类别归集错误**：处置损益归集类别错误影响披露。
2. **列报范围混淆**：其他准则处理的处置损益混入。
3. **税费处理错误**：处置税费计算或列报错误。
4. **试运行处理不当**：在建工程试运行收支处理错误。

### 低风险

1. **处置方式未标注**：未标注处置方式影响追溯。
2. **明细列示不完整**：未登记资产名称或处置日期。
3. **索引不完整**：明细未与H6、H10-1、台账建立索引。
