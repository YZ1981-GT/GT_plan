# H8-1 使用权资产审定表复核提示词

## 概述

本提示词针对使用权资产（承租人租赁资产，CAS21）审定表（H8-1）的复核。该表按四区块（原值/累计折旧/减值准备/账面净额）承载使用权资产的期初、增减、期末审定。复核聚焦初始计量准确性（与租赁负债勾稽）、折旧计提完整性、减值评估及与租赁负债（H9）的对应关系。

**法规依据：**
- 《企业会计准则第21号——租赁》（承租人会计处理）
- 《企业会计准则第8号——资产减值》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **使用权资产与租赁负债初始勾稽**：使用权资产初始成本=租赁负债初始计量金额+预付租金+初始直接费用+复原成本-已收租赁激励，须与H9租赁负债初始金额勾稽，是CAS21承租人会计的核心逻辑。
2. **四区块结构须完整**：原值、累计折旧、减值准备、账面净额四区块须齐全且勾稽（净额=原值-累计折旧-减值准备）。
3. **折旧年限规则**：能合理确定租赁期届满取得所有权的，按资产剩余使用寿命折旧；否则按租赁期与剩余使用寿命孰短折旧，年限判断错误将系统性错计折旧。
4. **短期/低价值租赁豁免**：适用简化处理的短期租赁（≤12个月且无购买选择权）和低价值资产租赁不确认使用权资产，须核对是否恰当豁免、有无滥用豁免规避表内确认。
5. **期初期末勾稽**：期初审定数=上年期末审定数（首年执行新租赁准则须关注衔接调整），期末=期初+新增-减少-折旧-减值±租赁变更重估。
6. **审定表是跨底稿勾稽枢纽**：审定数须与H8-2明细、H8-6初始及后续计量、H8-8折旧测算、H8-10减值、H9租赁负债勾稽一致。

## checklist

### 一、初始计量与租赁负债勾稽

- [ ] 使用权资产初始成本构成是否完整（租赁负债+预付租金+初始直接费用+复原成本-租赁激励）
- [ ] 使用权资产初始金额是否与H9租赁负债初始计量勾稽
- [ ] 新增使用权资产是否与H8-6初始计量、H9新增租赁负债对应
- [ ] 是否恰当适用短期/低价值租赁豁免，有无滥用
- [ ] 首年执行新准则的衔接调整是否恰当

### 二、四区块结构与勾稽

- [ ] 原值/累计折旧/减值准备/账面净额四区块是否齐全
- [ ] 账面净额=原值-累计折旧-减值准备是否成立
- [ ] 期初审定数是否等于上年期末审定数
- [ ] 期末=期初+新增-减少-折旧-减值±重估是否成立
- [ ] 各区块是否与H8-2明细表勾稽

### 三、折旧与减值

- [ ] 折旧年限判断是否正确（所有权转移按寿命/否则孰短）
- [ ] 折旧金额是否与H8-8折旧测算勾稽
- [ ] 是否评估减值迹象并与H8-10减值测算勾稽
- [ ] 减值损失确认后是否未违规转回
- [ ] 折旧起算时点（租赁期开始日）是否正确

### 四、调整与列报

- [ ] 所有AJE/RJE是否完整反映在审定表
- [ ] 租赁变更导致的使用权资产重估是否恰当（与H8-7勾稽）
- [ ] 审定数是否与试算平衡表使用权资产科目勾稽
- [ ] 使用权资产列报是否单独列示或在附注充分披露
- [ ] 审定表分类是否与附注披露一致

## risk_areas

### 高风险

1. **使用权资产与租赁负债不勾稽**：初始计量金额不匹配，违反CAS21承租人会计核心逻辑，两个底稿数据脱节。
2. **滥用豁免规避表内确认**：将本应确认使用权资产的租赁人为拆分或错误归类为短期/低价值租赁，规避资产负债表确认。
3. **折旧年限判断错误**：所有权转移判断错误导致按错误年限折旧，系统性错计折旧和净值。
4. **减值迹象未评估**：使用权资产（如亏损门店租赁）存在减值迹象却未测试确认减值。
5. **期初衔接调整错误**：首年执行新准则的追溯调整错误导致期初数失真。

### 中风险

1. **初始成本构成不完整**：遗漏初始直接费用、复原成本或未扣减租赁激励。
2. **折旧与测算表不勾稽**：审定表折旧与H8-8测算不一致。
3. **租赁变更重估遗漏**：租赁变更未导致使用权资产相应重估。
4. **调整分录方向错误**：RJE借贷方向颠倒或金额与明细不符。

### 低风险

1. **四区块列示不清**：审定表区块划分或标注不清晰。
2. **底稿索引不完整**：审定表未与明细、计量、折旧、减值、H9建立索引。
3. **格式不规范**：列标题、编号等格式细节问题。
