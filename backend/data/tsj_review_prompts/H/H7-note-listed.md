# H7-note-listed 生产性生物资产附注披露复核提示词（上市公司）

## 概述

本提示词针对上市公司生产性生物资产附注披露底稿（H7-note-listed）的复核。聚焦生物资产分类披露、计量模式披露、成熟/未成熟及生产性/消耗性结构、折旧与减值（成本模式）或公允价值变动（公允模式）的变动表、以及CAS5要求的生物资产特有披露事项。

**法规依据：**
- 《企业会计准则第5号——生物资产》
- 《企业会计准则第8号——资产减值》
- 《企业会计准则第30号——财务报表列报》
- 《公开发行证券的公司信息披露编报规则第15号——财务报告的一般规定》

---

## tips

1. **计量模式须明确披露**：附注须披露生产性生物资产采用成本模式还是公允价值模式，公允价值模式须披露采用依据（活跃市场情况）。
2. **变动表是核心披露**：须完整列示原值、累计折旧、减值准备（成本模式）或公允价值（公允模式）的期初、增加、减少、期末变动。
3. **成熟/未成熟结构披露**：须区分披露成熟与未成熟生产性生物资产，成熟资产计提折旧、未成熟不提。
4. **减值披露（成本模式）**：本期计提减值损失、累计减值准备须披露，减值原因（疫病/灾害/价格）须说明。
5. **公允价值披露（公允模式）**：须披露公允价值确定方法、层次、关键假设及公允价值变动损益。
6. **数量信息与实物匹配**：CAS5要求披露生物资产的实物数量信息，须与H7-2明细、盘点结果匹配。

## checklist

### 一、分类与计量模式披露

- [ ] 是否披露计量模式（成本/公允）及采用依据
- [ ] 生产性与消耗性生物资产是否分别披露
- [ ] 成熟与未成熟生产性生物资产是否区分披露
- [ ] 是否披露生物资产的实物数量信息
- [ ] 各分类合计是否与审定表勾稽

### 二、变动表披露

- [ ] 原值变动表是否完整（期初/增加/减少/期末）
- [ ] 累计折旧变动表（成本模式）是否完整
- [ ] 减值准备变动表（成本模式）是否完整
- [ ] 公允价值变动（公允模式）是否披露
- [ ] 变动表各项是否与H7-2明细勾稽

### 三、折旧减值披露

- [ ] 折旧方法、年限、残值率是否披露（成本模式）
- [ ] 本期计提减值损失金额是否披露
- [ ] 减值原因是否说明
- [ ] 减值不得转回是否体现
- [ ] 计入损益的折旧/减值是否与利润表勾稽

### 四、公允价值与其他披露

- [ ] 公允价值确定方法和层次是否披露（公允模式）
- [ ] 公允价值变动损益是否披露
- [ ] 所有权受限（抵押/担保）的生物资产是否披露
- [ ] 因灾害/疫病发生的重大损失是否披露
- [ ] 附注披露口径是否与审定表、明细表一致

## risk_areas

### 高风险

1. **变动表不勾稽**：变动表各项金额勾稽关系不成立或与审定表/明细不一致。
2. **计量模式披露不当**：公允价值模式采用依据披露不充分或掩盖不满足条件的事实。
3. **减值披露缺失**：本期计提重大减值却未披露原因和金额。
4. **数量信息缺失或不实**：未披露实物数量或披露数量与实际不符。

### 中风险

1. **成熟/未成熟未区分**：未区分披露影响折旧信息完整性。
2. **公允价值假设披露不足**：公允模式关键假设和层次披露不充分。
3. **所有权受限未披露**：抵押/担保的生物资产未披露。

### 低风险

1. **可比信息缺失**：仅披露本期数未列上期可比数。
2. **文字披露模板化**：生物资产管理政策描述笼统。
3. **格式不规范**：金额单位、表格列序等细节问题。
