# H1-8 固定资产减少检查 复核提示词

## 概述

本提示词针对固定资产减少检查表（H1-8）的复核，聚焦本期处置固定资产的处置收益计算、账面价值结转准确性、处置审批合规性及抽凭充分性。处置环节是资产流失与舞弊高发区。

## tips

1. **处置收益准确**：处置收益=处置价款−处置时账面价值−相关税费，账面价值=原值−累计折旧−减值准备，结转须完整。
2. **账面价值结转完整**：处置须同时结转原值、累计折旧、减值准备三栏，不得仅冲原值。
3. **处置审批合规**：大额资产处置须有授权审批，国企须履行"三重一大"及评估进场程序。
4. **处置价款到账**：核对处置价款是否到账，关注低价处置给关联方的舞弊风险。
5. **报废毁损凭据**：报废/毁损须有技术鉴定或审批文件，保险赔款单独核算。
6. **收益列报**：正常处置计入资产处置收益（H10），非正常报废毁损计入营业外收支。

## checklist

### 处置计算与结转
- [ ] 处置收益计算是否正确
- [ ] 原值/累计折旧/减值准备是否同步结转
- [ ] 处置价款是否到账并核对
- [ ] 报废毁损是否有鉴定/审批凭据

### 合规与列报
- [ ] 大额处置是否有授权审批（国企含评估）
- [ ] 关联方处置价格是否公允
- [ ] 处置收益列报科目是否正确（H10/营业外）
- [ ] 本期减少合计是否与H1-2明细表一致

## risk_areas

### 高风险
1. **低价处置给关联方**：国有/公司资产流失。
2. **账面价值结转不完整虚增/虚减处置收益**：账面价值结转不完整虚增/虚减处置收益。
3. **已处置资产未核销继续计提折旧**：已处置资产未核销继续计提折旧。

### 中风险
1. **处置未经审批**：处置未经审批。
2. **处置收益列报科目错误**：处置收益列报科目错误。

### 低风险
1. **处置单据索引不完整**：处置单据索引不完整。
2. **检查比例略低**：检查比例略低。
