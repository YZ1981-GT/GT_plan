# H2-16 在建工程可收回金额（DCF） 复核提示词

## 概述

本提示词针对在建工程可收回金额测试表（H2-16，DCF）的复核，聚焦使用价值DCF模型关键参数合理性、公允价值减处置费用的确定及可收回金额结论支撑。在建工程DCF须考虑后续完工投入。

## tips

1. **后续投入扣减**：使用价值现金流须扣减完工尚需投入，反映在建工程当前状态的真实可收回价值。
2. **现金流预测**：基于工程建成后的经批准预算，预测期合理，增长率不超行业平均。
3. **折现率恰当**：折现率反映资产特定风险的税前利率，与项目风险匹配。
4. **公允价值有据**：公允价值减处置费用须有市场/评估依据（如半成品工程转让价）。
5. **两者取高**：可收回金额取公允净额与使用价值较高者。
6. **敏感性分析**：对关键假设做敏感性分析评估结论稳健性。

## checklist

### 参数与方法
- [ ] 使用价值现金流是否扣减完工尚需投入
- [ ] 现金流预测是否基于批准预算、期限合理
- [ ] 折现率是否恰当且反映特定风险
- [ ] 是否取公允净额与使用价值较高

### 支撑与勾稽
- [ ] 公允价值是否有依据
- [ ] 是否做敏感性分析
- [ ] 结论是否与H2-15勾稽

## risk_areas

### 高风险
1. **未扣减完工投入**：高估可收回金额规避减值。
2. **现金流/折现率主观臆断**：现金流/折现率主观臆断。

### 中风险
1. **仅用单一路径未说明**：仅用单一路径未说明。
2. **缺敏感性分析**：缺敏感性分析。

### 低风险
1. **公允价值依据不足**：公允价值依据不足。
2. **参数来源索引不全**：参数来源索引不全。
