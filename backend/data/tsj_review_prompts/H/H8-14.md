# H8-14 使用权资产关联交易检查表复核提示词

## 适用底稿
使用权资产关联交易检查表（H8-14），聚焦关联方租赁的识别、租金定价公允性、交易实质及披露完整性。

## 概述
H8-14 检查涉及使用权资产的关联方租赁交易（向关联方承租）。复核须关注关联方租赁的完整识别、租金定价公允性、租赁条款的商业合理性及关联交易披露是否符合CAS36。

---

## tips

1. **关联方租赁识别完整**：向关联方承租资产形成的使用权资产须完整识别，关注是否存在未披露关联方通过租赁安排输送利益。
2. **租金定价公允性**：关联方租赁的租金水平须与市场公允租金对比，显著偏高（利益输送）或偏低（隐性补贴）须查明。
3. **租赁条款商业合理性**：租赁期、续租条款、终止条款等是否具有商业合理性，警惕为特定目的设计的非公允条款。
4. **交易实质判断**：关注是否存在以租赁名义进行的融资安排或利益输送。
5. **折现率对关联方影响**：关联方租赁的折现率选取须合理，避免通过折现率操纵使用权资产和负债金额。
6. **披露完整性**：关联方租赁须按CAS36披露关联方关系、租赁内容、租金金额、定价政策及未结算余额，交叉验证B19关联方清单。

---

## checklist

### 一、关联方识别

- [ ] 向关联方承租的租赁是否完整识别
- [ ] 是否核对B19关联方清单确保无遗漏
- [ ] 是否关注隐性关联方租赁
- [ ] 出租方是否存在实质关联关系但未披露

### 二、定价公允性

- [ ] 关联方租金是否与市场公允租金对比
- [ ] 显著偏离是否查明原因和商业合理性
- [ ] 定价政策是否披露
- [ ] 是否存在通过租金定价输送利益

### 三、交易实质

- [ ] 租赁条款是否具有商业合理性
- [ ] 是否存在以租赁名义的融资安排
- [ ] 折现率选取对关联方是否合理
- [ ] 交易是否有真实经营目的

### 四、披露

- [ ] 关联方关系、租赁内容、金额是否完整披露
- [ ] 未结算租赁付款额是否披露
- [ ] 关联方租赁是否与H8-1审定表、H9租赁负债勾稽
- [ ] 披露是否符合CAS36要求

## risk_areas

### 高风险

1. **关联方利益输送**：通过关联方租赁的不公允租金输送利益或隐性补贴。
2. **非公允条款设计**：为特定目的设计的非公允租赁条款影响资产负债金额。
3. **折现率操纵**：关联方租赁通过折现率操纵使用权资产和负债金额。

### 中风险

1. **定价公允性存疑**：关联方租金偏离市场但未充分说明。
2. **隐性关联方未识别**：关联租赁关系未识别披露。
3. **交易实质存疑**：以租赁名义的融资安排未识别。

### 低风险

1. **披露不完整**：关联租赁定价政策或未结算余额披露不全。
2. **交叉索引缺失**：关联租赁未与B19、H9建立索引。
