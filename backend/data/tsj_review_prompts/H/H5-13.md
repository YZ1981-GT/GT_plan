# H5-13 油气资产折耗分配 复核提示词

## 概述

本提示词针对油气资产折耗分配表（H5-13）的复核，聚焦折耗费用按去向（油气生产成本）分配的准确性及与成本费用类底稿的勾稽。油气资产折耗主要计入油气生产成本。

## tips

1. **分配依据合理**：折耗按油气井/矿区归集计入油气生产成本，分配依据与产量匹配。
2. **分配合计=折耗**：各去向分配合计须等于H5-12本期折耗计提总额。
3. **成本勾稽**：折耗计入油气生产成本须与成本底稿（F5）勾稽，影响油气销售成本。
4. **产量匹配**：折耗分配与油气产量、销量匹配，未销售部分应结转存货。
5. **弃置费用折耗**：资本化的弃置费用一并按产量法折耗，分配一致。
6. **异常占比**：某去向折耗占比异常须说明。

## checklist

### 分配准确性
- [ ] 分配依据是否与产量匹配
- [ ] 各去向分配合计是否等于本期折耗总额
- [ ] 弃置费用折耗是否一并分配

### 跨科目勾稽
- [ ] 折耗计入油气生产成本是否与F5勾稽
- [ ] 折耗分配与产量/销量是否匹配
- [ ] 未销售部分是否结转存货

## risk_areas

### 高风险
1. **分配合计≠折耗总额**：折耗漏分或重分。
2. **折耗未正确计入生产成本影响损益**：折耗未正确计入生产成本影响损益。

### 中风险
1. **与成本底稿勾稽不符**：与成本底稿勾稽不符。
2. **未销售部分未结转存货**：未销售部分未结转存货。

### 低风险
1. **某去向占比异常缺说明**：某去向占比异常缺说明。
2. **分配表格式不规范**：分配表格式不规范。
