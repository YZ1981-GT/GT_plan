# H1-2 固定资产明细表 复核提示词

## 概述

本提示词针对固定资产明细表（H1-2）的复核，聚焦原值、累计折旧、减值准备三栏按类别/单项资产的增减变动明细，及与审定表（H1-1）、增加检查（H1-7）、减少检查（H1-8）、折旧测算（H1-12）的勾稽。明细表是审定表数据的支撑基础。

## tips

1. **三栏明细逐行勾稽**：每项资产期末原值=期初+本期购建/转入−本期处置/转出，累计折旧、减值同理，行级勾稽后再汇总。
2. **明细合计=审定表**：各类别原值/累计折旧/减值合计须与H1-1审定表对应审定数一致。
3. **增加来源可追溯**：本期增加须区分外购、在建工程转入（勾稽H2）、融资租入、投资者投入，每笔有单据支持。
4. **减少去向清晰**：本期减少须区分出售、报废、毁损、对外投资、盘亏，处置净值与H1-8减少检查勾稽。
5. **折旧本期计提**：明细表本期折旧应与H1-12折旧测算表一致，关注已提足仍在用及未提折旧资产。
6. **关注零净值仍在用资产**：净值为零但仍在使用的资产应保留原值与全额累计折旧，不得核销。

## checklist

### 三栏增减勾稽
- [ ] 每项资产原值期末=期初+增加−减少是否成立
- [ ] 累计折旧期末=期初+计提−处置转出是否成立
- [ ] 减值准备期末=期初+计提−转销是否成立
- [ ] 账面净值逐行计算是否正确

### 跨底稿勾稽
- [ ] 明细合计是否等于H1-1审定表审定数
- [ ] 本期增加是否与H1-7增加检查一致
- [ ] 本期减少是否与H1-8减少检查一致
- [ ] 本期折旧是否与H1-12折旧测算一致
- [ ] 在建工程转入是否与H2转固勾稽

### 完整性与分类
- [ ] 是否存在账外固定资产未入表
- [ ] 资产分类是否正确（影响折旧年限）
- [ ] 已提足折旧仍在用资产是否保留
- [ ] 待处置资产是否单独标注

## risk_areas

### 高风险
1. **明细合计与审定表不符**，存在明细遗漏、重复或汇总错误。
2. **在建工程转入原值与H2不勾稽**，转固时点或金额失真。
3. **虚构资产入账**或已处置资产未核销。

### 中风险
1. **本期折旧与折旧测算表不一致**：本期折旧与折旧测算表不一致。
2. **减少去向不清或处置净值错误**：减少去向不清或处置净值错误。
3. **资产分类错误影响折旧年限**：资产分类错误影响折旧年限。

### 低风险
1. **资产编号/名称不规范**：资产编号/名称不规范。
2. **明细行过多未分类汇总影响可读性**：明细行过多未分类汇总影响可读性。
3. **单据索引不完整**：单据索引不完整。
