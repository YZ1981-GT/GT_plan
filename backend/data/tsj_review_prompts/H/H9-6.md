# H9-6 租赁负债关联方检查表复核提示词

## 适用底稿
租赁负债关联方检查表（H9-6，筛选视图），聚焦向关联方承租形成的租赁负债的识别、定价公允性、条款合理性及披露完整性。

## 概述
H9-6 通过筛选识别涉及关联方的租赁负债，检查关联方租赁安排的公允性和披露。复核须关注关联方租赁负债的完整识别、租金定价及折现率的公允性、条款商业合理性及关联交易披露是否符合CAS36。

---

## tips

1. **关联方租赁负债识别完整**：向关联方承租形成的租赁负债须完整筛选识别，核对B19关联方清单及H8-14使用权资产关联交易。
2. **定价公允性影响负债金额**：关联方租赁的租金和折现率直接影响租赁负债现值，不公允定价将扭曲负债金额。
3. **折现率公允性**：关联方租赁的折现率选取须合理，避免通过折现率操纵租赁负债金额（表外融资倾向）。
4. **条款商业合理性**：关联方租赁的期限、续租、终止条款是否具有商业合理性，警惕非公允安排。
5. **交易实质**：关注是否存在以关联方租赁名义进行的融资安排或利益输送。
6. **披露完整性**：关联方租赁负债须按CAS36披露关联方关系、租赁内容、未结算租赁付款额及定价政策。

---

## checklist

### 一、关联方识别

- [ ] 向关联方承租的租赁负债是否完整筛选识别
- [ ] 是否核对B19关联方清单及H8-14
- [ ] 是否关注隐性关联方租赁
- [ ] 出租方是否存在实质关联关系但未披露

### 二、定价与折现率公允性

- [ ] 关联方租金是否与市场公允租金对比
- [ ] 折现率选取对关联方是否合理
- [ ] 定价/折现率是否影响租赁负债金额公允性
- [ ] 显著偏离是否查明原因

### 三、条款与实质

- [ ] 租赁条款是否具有商业合理性
- [ ] 是否存在以租赁名义的融资安排
- [ ] 交易是否有真实经营目的
- [ ] 是否存在通过租赁安排的利益输送

### 四、披露与勾稽

- [ ] 关联方关系、租赁内容是否披露
- [ ] 未结算租赁付款额是否披露
- [ ] 关联方租赁负债是否与H9-1、H8-14勾稽
- [ ] 披露是否符合CAS36要求

## risk_areas

### 高风险

1. **关联方利益输送**：通过关联方租赁的不公允定价/折现率输送利益。
2. **折现率操纵负债金额**：关联方租赁通过折现率低估租赁负债（表外融资）。
3. **融资安排伪装租赁**：以关联方租赁名义进行融资安排。

### 中风险

1. **定价公允性存疑**：关联方租金偏离市场但未充分说明。
2. **隐性关联方未识别**：关联租赁关系未识别披露。
3. **条款非公允**：租赁条款缺乏商业合理性。

### 低风险

1. **披露不完整**：关联租赁定价政策或未结算余额披露不全。
2. **交叉索引缺失**：关联租赁未与B19、H8-14建立索引。
