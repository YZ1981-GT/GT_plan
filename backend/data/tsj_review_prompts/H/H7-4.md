# H7-4 生产性生物资产会计政策检查表复核提示词

## 适用底稿
生产性生物资产会计政策检查表（H7-4），聚焦CAS5计量模式选择、初始/后续计量政策、折旧政策、减值政策及政策一贯性的合规性检查。

## 概述
H7-4 验证生产性生物资产会计政策是否符合CAS5要求且一贯运用。复核须关注计量模式选择依据、初始计量成本构成、折旧方法与年限、减值政策及公允价值模式适用条件。

---

## tips

1. **计量模式选择须有依据**：默认采用成本模式，仅当有确凿证据表明公允价值能够持续可靠取得（活跃市场）时方可采用公允价值模式，检查模式选择依据是否充分。
2. **初始计量成本构成完整**：外购=购买价款+相关税费+归属于该资产的其他支出；自行营造/繁殖=达到预定生产经营目的前发生的必要支出，检查成本归集范围是否恰当。
3. **折旧政策符合CAS5**：成熟生产性生物资产按预计使用寿命、预计净残值和折旧方法计提折旧，检查折旧方法、年限、残值率是否合理并一贯。
4. **减值政策（成本模式）**：期末有减值迹象时进行减值测试，减值损失一经确认不得转回，检查减值测试触发条件和计量方法。
5. **未成熟不提折旧**：未达到预定生产经营目的的未成熟生产性生物资产不计提折旧，检查折旧起始时点政策。
6. **政策一贯性**：会计政策前后期须一贯，变更须符合会计政策变更条件，检查是否存在随意变更。

## checklist

### 一、计量模式政策

- [ ] 计量模式选择是否有充分依据（成本模式为默认/公允需活跃市场）
- [ ] 公允价值模式是否满足公允价值持续可靠取得条件
- [ ] 计量模式是否前后期一贯运用
- [ ] 模式变更是否符合会计政策变更条件并追溯

### 二、初始与后续计量政策

- [ ] 外购生物资产初始成本构成是否完整恰当
- [ ] 自繁自育成本归集范围是否符合CAS5
- [ ] 达到预定生产经营目的的判断标准是否明确
- [ ] 后续支出资本化/费用化政策是否合理

### 三、折旧政策

- [ ] 折旧方法是否合理并一贯（年限平均/工作量/产量法）
- [ ] 预计使用寿命是否符合生物资产实际（对比同业/技术参数）
- [ ] 预计净残值率是否合理
- [ ] 折旧起始时点（成熟时）政策是否明确
- [ ] 折旧计提是否区分成熟与未成熟

### 四、减值政策与一贯性

- [ ] 减值测试触发条件是否明确（成本模式）
- [ ] 减值损失确认后不得转回的政策是否执行
- [ ] 减值迹象判断（疫病/灾害/市价下跌）是否恰当
- [ ] 会计政策是否与附注披露一致
- [ ] 是否存在不当政策变更调节利润

## risk_areas

### 高风险

1. **滥用公允价值模式**：不满足活跃市场条件却采用公允价值模式虚增利润。
2. **折旧政策不合理**：故意延长使用寿命或提高残值率少提折旧，虚增资产利润。
3. **减值政策规避**：有减值迹象却不测试或不确认减值。

### 中风险

1. **初始成本归集不当**：将无关支出资本化或应资本化支出费用化。
2. **折旧起始时点错误**：未成熟提前提折旧或成熟延迟提折旧。
3. **政策随意变更**：无正当理由变更会计政策调节利润。

### 低风险

1. **政策文档不完整**：会计政策文档记录不充分。
2. **政策与附注表述差异**：政策描述与附注披露表述存在细微差异。
