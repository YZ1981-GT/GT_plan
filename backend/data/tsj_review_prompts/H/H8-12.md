# H8-12 租赁终止（减少）检查表复核提示词

## 适用底稿
租赁终止（减少）检查表（H8-12），聚焦租赁提前终止/到期的识别、使用权资产与租赁负债终止确认、终止损益计量及处理的准确性。

## 概述
H8-12 检查使用权资产因租赁终止/到期而减少的会计处理。复核须关注终止事项的识别、使用权资产账面净值与租赁负债余额的终止确认、终止损益计算及是否存在应终止未终止的情况。

---

## tips

1. **终止事项识别完整**：租赁提前终止、到期不续租、退租等导致使用权资产减少的事项须完整识别，与合同到期清单核对。
2. **同时终止资产与负债**：租赁终止时须同时终止确认使用权资产账面净值和租赁负债余额，差额计入当期损益。
3. **终止损益计量**：终止损益=终止的租赁负债余额-使用权资产账面净值±支付/收取的终止款项，核对计算。
4. **区分终止与变更**：完全终止（终止确认）与缩小范围的租赁变更（按比例减记）处理不同，须正确区分。
5. **提前终止罚款处理**：支付的提前终止罚款须恰当计入终止损益或按相关准则处理。
6. **终止勾稽**：使用权资产减少须与H8-1、H8-2明细减少、H9租赁负债减少勾稽。

## checklist

### 一、终止事项识别

- [ ] 本期终止/到期租赁是否完整识别
- [ ] 是否与合同到期清单核对
- [ ] 是否存在实际已停用但未终止确认的租赁
- [ ] 终止与租赁变更（缩小范围）是否正确区分

### 二、终止确认

- [ ] 使用权资产账面净值是否终止确认
- [ ] 租赁负债余额是否终止确认
- [ ] 终止时点是否正确
- [ ] 资产与负债是否同步终止

### 三、终止损益

- [ ] 终止损益计算是否正确
- [ ] 提前终止罚款是否恰当处理
- [ ] 终止损益列报科目是否恰当
- [ ] 终止损益是否与H8-3/H9-4调整勾稽

### 四、勾稽

- [ ] 使用权资产减少是否与H8-1、H8-2勾稽
- [ ] 租赁负债减少是否与H9勾稽
- [ ] 终止后短期租赁续用是否恰当处理

## risk_areas

### 高风险

1. **应终止未终止**：租赁实际已终止/停用但账面仍确认使用权资产和负债，账实不符。
2. **终止损益错误**：终止损益计算错误或未确认，影响损益。
3. **仅终止一方**：仅终止使用权资产未终止租赁负债（或反之），两表不平。

### 中风险

1. **终止与变更混淆**：完全终止与缩小范围变更处理混淆。
2. **终止罚款处理错误**：提前终止罚款处理不当。
3. **终止时点错误**：终止确认时点判断错误。

### 低风险

1. **终止识别不及时**：终止未在当期及时处理。
2. **终止文档不足**：终止事项和处理记录不完整。
