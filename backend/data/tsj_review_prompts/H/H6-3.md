# H6-3 固定资产清理调整分录复核提示词

## 适用底稿
固定资产清理调整分录汇总表（H6-3），含账项调整（AJE）、重分类调整（RJE）及未调整错报评估，聚焦调整证据、借贷平衡、回写H6-1审定表及利润表影响。

## 概述
H6-3 是固定资产清理审定链路的关键环节。复核须验证：每笔清理相关调整有证据支持、借贷平衡、完整反映到H6-1审定表、清理净损益结转方向正确、未调整错报评估符合重要性水平要求。

---

## tips

1. **AJE与RJE区分**：AJE影响清理净损益或资产账面（如补转减值准备、补记处置收入）；RJE仅影响列报（如资产处置收益与营业外收支的重分类），不得通过RJE掩盖损益错报。
2. **与H6-1勾稽**：审定表调整列金额须与H6-3已确认分录逐笔一致，遗漏任一笔即审定数失真。
3. **清理清零调整**：期末清理科目应结平为零，核对结转损益的调整分录是否将清理余额完整结转至资产处置收益或营业外收支。
4. **审批链**：重大处置损失/收益调整、超过明细层次重要性水平的调整须经合伙人/项目经理审批留痕。
5. **利润表影响**：调整涉及资产处置收益（6115）或营业外收支的，须评估对利润总额、营业利润的影响并与H10、利润表勾稽。
6. **TB回写**：确认调整已同步试算平衡表1606及相关损益科目，避免「底稿已调、TB未更」双真源。

## checklist

### 高风险检查项

- [ ] 所有AJE是否有充分审计证据（处置合同、评估报告、报废批复、收款凭证）
- [ ] 补转减值准备/累计折旧的调整是否有减值测算或折旧重算支持
- [ ] 每笔调整分录借贷方是否完全平衡
- [ ] 调整金额是否完整反映到H6-1审定表对应调整列
- [ ] 清理科目期末结转为零的调整是否完整（无残留余额）
- [ ] 是否存在仅为调节资产处置收益/营业利润的不当调整
- [ ] 净损益结转方向调整（资产处置收益vs营业外收支）是否恰当

### 中风险检查项

- [ ] RJE是否仅涉及列报重分类，未影响清理净损益金额
- [ ] 调整原因说明是否清晰可追溯至具体审计程序（H6-2/H6-4）
- [ ] 调整分录编号是否连续，删除后重号风险是否可控
- [ ] 与A13未调整错报汇总表索引是否完整
- [ ] 涉及增值税的调整是否同步调整应交税费科目

### 低风险检查项

- [ ] 分录摘要、科目编码是否规范
- [ ] 索引是否指向H6-2明细、H6-4清理过程检查等支持底稿
- [ ] 审计说明/结论是否概括调整性质与残余风险

## risk_areas

### 高风险

1. **清理损失递延不结转**：期末清理余额为借方（净损失）却不结转，人为递延损失确认，利润虚增。
2. **调整缺乏证据或未经授权**：重大处置调整无处置合同/评估依据，或未经合伙人审批即入账。
3. **净损益方向调整掩盖亏损**：通过重分类将处置损失转入其他科目，掩盖真实经营亏损。

### 中风险

1. **RJE误含损益影响**：本应仅列报重分类的RJE实际改变了清理净损益金额。
2. **增值税调整遗漏**：调整处置收入时未同步调整销项税额。
3. **审定表与H6-3金额长期不一致**：调整未及时回写审定表。

### 低风险

1. **编号、格式不规范**：分录编号不连续或摘要不清晰。
2. **索引缺失**：调整分录未指向支持性底稿。

## 跨底稿勾稽

- H6-3 已确认 AJE/RJE 合计 ↔ H6-1 审定表调整列
- H6-3 清理净损益结转 ↔ H10 资产处置收益 / 营业外收支
- H6-3 未调整错报 ↔ A13 未调整错报汇总
- 调整后审定数 ↔ 试算平衡表 1606 科目（期末应为零）
