# H7-7 生产性生物资产减少检查表复核提示词

## 适用底稿
生产性生物资产减少检查表（H7-7，成本/公允双版本），聚焦出售、死亡、淘汰、对外投资、非货币性交换等减少方式的真实性、核销证据充分性及处置损益准确性。

## 概述
H7-7 通过凭证级检查验证本期生产性生物资产减少的真实、准确、完整。复核须重点关注死亡淘汰核销的实物证据、出售处置收入的完整性及处置损益的正确结转，防止虚假核销掩盖资产流失。

---

## tips

1. **死亡淘汰须实物核销证据**：因疫病、自然灾害、正常淘汰导致的减少，须有兽医鉴定、死亡清单、无害化处理记录等，无实物证据的核销是舞弊高风险信号。
2. **出售处置收入完整性**：出售生物资产的价款须与销售合同、收款凭证核对，警惕低价销售给关联方或收入不入账。
3. **处置损益正确结转**：出售净损益（售价-账面净值-相关税费）结转损益，核对结转方向和金额。
4. **减少时点与实物一致**：账面减少时点须与实物出售/死亡时点一致，警惕已死亡不核销或提前/滞后核销跨期。
5. **消耗性转化**：生产性生物资产因丧失生产能力转为消耗性（如淘汰产畜转育肥出售）须正确重分类。
6. **检查比例与样本**：大额减少全覆盖，异常死亡淘汰重点核查。

## checklist

### 高风险检查项

- [ ] 死亡/淘汰减少是否有兽医鉴定/死亡清单/处理记录
- [ ] 是否存在虚假核销掩盖资产被盗/私卖
- [ ] 出售价款是否与合同、收款凭证核对完整
- [ ] 是否存在低价出售给关联方的利益输送
- [ ] 处置净损益计算和结转方向是否正确
- [ ] 减少是否与H7-2明细、H7-1审定表勾稽

### 中风险检查项

- [ ] 减少时点是否与实物处置/死亡时点一致
- [ ] 转为消耗性生物资产的重分类是否正确
- [ ] 异常死亡率/淘汰率是否查明原因
- [ ] 保险赔偿是否入账完整
- [ ] 处置是否办妥审批手续

### 低风险检查项

- [ ] 检查比例是否达到计划水平
- [ ] 核销凭证索引是否完整
- [ ] 检查记录格式是否规范

---

## risk_areas

### 高风险

- 虚假死亡淘汰核销掩盖资产流失/被盗
- 出售收入不入账体外循环
- 关联方低价处置利益输送

### 中风险

- 死亡淘汰不及时核销账实不符
- 消耗性重分类错误
- 处置损益结转错误

### 低风险

- 检查比例不足
- 核销凭证索引缺失
