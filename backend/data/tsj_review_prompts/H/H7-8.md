# H7-8 生产性生物资产监盘计划复核提示词

## 适用底稿
生产性生物资产监盘计划（H7-8），聚焦监盘范围、时间、方法、抽样及针对生物资产特殊性（活体、分散、难点数）的监盘程序设计合理性。

## 概述
H7-8 是生产性生物资产存在性审计的关键前置。生物资产为活体资产，分布分散、难以点数、可能因疫病隔离，监盘计划须针对其特殊性设计恰当的观察、点数和技术手段。

---

## tips

1. **监盘范围覆盖全部重大地点**：生物资产可能分布于多个养殖场/林地/牧区，监盘计划须覆盖全部重大存放地点或按风险抽样。
2. **监盘时间贴近资产负债表日**：监盘应尽量在或接近资产负债表日进行，非资产负债表日监盘须设计滚存程序。
3. **针对活体特性设计方法**：活体资产难以逐一点数，可采用抽样点数、称重估算、影像记录、耳标/芯片核对等方法，计划须说明方法合理性。
4. **难点数生物资产的技术手段**：对水产、家禽等难以精确点数的资产，须设计估算方法（如密度抽样、批次核对）并评估估算误差。
5. **疫病隔离与生物安全**：进入养殖区须遵守生物安全规程，疫病隔离区的监盘须设计替代观察程序。
6. **专家利用考虑**：品种鉴定、成熟度判断、健康状况评估等专业事项可能需利用畜牧/林业专家。

## checklist

### 一、监盘范围与时间

- [ ] 监盘计划是否覆盖全部重大存放地点或按风险合理抽样
- [ ] 监盘时间是否在或接近资产负债表日
- [ ] 非资产负债表日监盘是否设计滚存程序
- [ ] 分散存放地点的监盘资源配置是否充分

### 二、监盘方法设计

- [ ] 是否针对活体资产特性设计恰当点数方法
- [ ] 难点数资产是否设计估算方法及误差评估
- [ ] 是否核对耳标/芯片/批次标识
- [ ] 成熟度/健康状况观察程序是否设计
- [ ] 是否考虑影像记录等辅助证据

### 三、特殊事项与专家利用

- [ ] 疫病隔离区是否设计替代观察程序
- [ ] 生物安全规程是否纳入监盘计划
- [ ] 是否评估需否利用畜牧/林业专家
- [ ] 专家资质和独立性是否评估

### 四、计划完整性

- [ ] 监盘人员分工是否明确
- [ ] 差异处理和调查程序是否预设
- [ ] 是否与H7-9盘点检查、H7-10监盘小结衔接

## risk_areas

### 高风险

1. **重大地点未纳入监盘**：分散养殖场/林地未全覆盖或抽样不当，存在性证据不足。
2. **活体点数方法不当**：估算方法误差过大或无法验证真实存在。
3. **未在资产负债表日附近监盘且无滚存**：存在性与截止证据薄弱。

### 中风险

1. **难点数资产估算误差未评估**：水产/家禽估算未考虑误差影响。
2. **专家利用不足**：品种/成熟度判断缺乏专业支持。
3. **疫病区替代程序缺失**：隔离区无替代观察安排。

### 低风险

1. **人员分工不明确**：监盘分工和职责界定不清。
2. **差异处理程序未预设**：未事先明确差异调查流程。
