# H9-4 租赁负债调整分录复核提示词

## 适用底稿
租赁负债调整分录汇总表（H9-4），含账项调整（AJE）、重分类调整（RJE）及未调整错报评估，聚焦调整证据、借贷平衡、回写H9-1审定表及与使用权资产联动。

## 概述
H9-4 是租赁负债审定链路的关键环节。复核须验证：每笔调整有证据支持、借贷平衡、完整反映到H9-1审定表、租赁相关调整与使用权资产（H8）联动一致，流动非流动重分类恰当，未调整错报评估符合重要性水平要求。

---

## tips

1. **AJE与RJE区分**：AJE影响租赁负债余额或损益（补记初始确认、补记计息、租赁变更重估）；RJE多为流动/非流动重分类，不得通过RJE掩盖损益或负债金额错报。
2. **与使用权资产联动**：初始确认、租赁变更、重估类调整通常同时影响租赁负债和使用权资产，须核对H9-4与H8-3调整联动一致。
3. **与H9-1勾稽**：审定表调整列金额须与H9-4已确认分录逐笔一致。
4. **流动非流动重分类**：一年内到期租赁负债的重分类通过RJE处理，核对重分类金额准确。
5. **计息补记**：漏记或错记的实际利率法计息调整须有摊销表支持。
6. **TB回写**：确认调整已同步试算平衡表租赁负债及财务费用科目。

## checklist

### 高风险检查项

- [ ] 所有AJE是否有充分审计证据（租赁合同、摊销表、重估依据）
- [ ] 初始确认/重估调整是否与H8使用权资产联动一致
- [ ] 计息补记调整是否有摊销表支持
- [ ] 每笔调整分录借贷方是否完全平衡
- [ ] 调整金额是否完整反映到H9-1审定表对应调整列
- [ ] 是否存在低估租赁负债的不当调整（表外融资）
- [ ] 首年衔接调整会计处理是否正确

### 中风险检查项

- [ ] RJE流动/非流动重分类金额是否准确
- [ ] 租赁变更调整是否同步调整使用权资产和负债
- [ ] 调整原因说明是否可追溯至H9-2/H9-3/摊销表
- [ ] 与A13未调整错报汇总表索引是否完整
- [ ] 调整分录编号是否连续

### 低风险检查项

- [ ] 分录摘要、科目编码是否规范
- [ ] 索引是否指向H9-2/H9-3/摊销表等支持底稿
- [ ] 审计说明/结论是否概括调整性质

## risk_areas

### 高风险

- 租赁负债与使用权资产调整不联动导致两表脱节
- 通过调整低估租赁负债（表外融资）
- 调整缺乏证据或未经授权

### 中风险

- 流动/非流动重分类金额错误
- 租赁变更重估调整遗漏一方
- 计息补记无摊销表支持

### 低风险

- 编号、格式不规范
- 索引缺失

## 跨底稿勾稽

- H9-4 已确认 AJE/RJE 合计 ↔ H9-1 审定表调整列
- H9-4 初始确认/重估调整 ↔ H8-3 使用权资产调整（联动）
- H9-4 计息调整 ↔ H9 摊销表
- H9-4 未调整错报 ↔ A13 未调整错报汇总
- 调整后审定数 ↔ 试算平衡表租赁负债科目
