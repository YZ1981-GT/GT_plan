# H10-note-listed 资产处置收益附注披露复核提示词（上市公司）

## 概述

本提示词针对上市公司资产处置收益附注披露底稿（H10-note-listed）的复核。资产处置收益为利润表项目（列示于「三、资产处置收益」），附注须披露其构成明细。复核聚焦资产处置收益构成披露、重大处置事项披露、损益归类准确性及与利润表、固定资产附注的勾稽。

**法规依据：**
- 《企业会计准则第42号——持有待售的非流动资产、处置组和终止经营》
- 《企业会计准则第30号——财务报表列报》
- 《公开发行证券的公司信息披露编报规则第15号——财务报告的一般规定》

---

## tips

1. **资产处置收益构成明细披露**：附注须按处置资产类别（固定资产/在建工程/无形资产/使用权资产等）披露资产处置收益/损失的构成。
2. **列报科目准确**：资产处置收益列示于利润表营业利润之上（三、资产处置收益），须与营业外收支（列示于营业利润之下）区分。
3. **重大处置事项披露**：单项重大或对经营有重大影响的资产处置须披露标的、对价、损益。
4. **正常处置与非正常损失区分披露**：正常处置计入资产处置收益，非正常报废毁损计入营业外支出，两者分别披露。
5. **与利润表及台账勾稽**：附注披露的资产处置收益金额须与利润表、H10-1审定表、H10-2明细一致。
6. **关联方处置披露**：关联方资产处置须在关联交易附注中披露。

## checklist

### 一、构成明细披露

- [ ] 是否披露资产处置收益期末数和上期可比数
- [ ] 是否按处置资产类别披露损益构成
- [ ] 资产处置收益金额是否与利润表项目一致
- [ ] 是否与H10-1审定表、H10-2明细勾稽

### 二、列报准确性

- [ ] 资产处置收益是否列示于营业利润之上（三、资产处置收益）
- [ ] 与营业外收支是否正确区分
- [ ] 处置损失（借方净额）列报是否正确
- [ ] 是否仅包含应计入资产处置收益的处置

### 三、重大处置与关联方

- [ ] 单项重大处置是否披露标的、对价、损益
- [ ] 关联方处置是否在关联交易附注披露
- [ ] 重大处置对经营影响是否说明
- [ ] 处置商业实质和定价依据是否披露

### 四、勾稽与非正常损失

- [ ] 处置减少的固定资产是否与固定资产变动表勾稽
- [ ] 非正常报废毁损损失是否披露于营业外支出
- [ ] 附注披露口径是否与审定表、明细一致
- [ ] 试运行处置收支处理是否恰当披露

## risk_areas

### 高风险

1. **披露与利润表不一致**：附注资产处置收益与利润表/审定表金额不符。
2. **列报科目错误**：资产处置收益与营业外收支列报位置错误影响营业利润。
3. **重大处置漏披露**：单项重大处置未单独披露。
4. **损益归类披露错误**：非正常损失错披露于资产处置收益。

### 中风险

1. **构成明细不完整**：仅披露净额未按资产类别细分。
2. **关联方处置披露不充分**：关联方处置定价公允性未说明。
3. **与固定资产变动表不勾稽**：处置减少额与固定资产附注存在差异。

### 低风险

1. **可比信息缺失**：仅披露本期数未列上期可比数。
2. **文字说明模板化**：处置事项说明笼统。
3. **格式不规范**：金额单位、表格列序等细节问题。
