# H1-19 固定资产经营租出 复核提示词

## 概述

本提示词针对固定资产经营租出检查表（H1-19）的复核，聚焦经营租出资产的识别、租赁分类判断、租金收入确认及列报披露。经营租出固定资产须单独列示并持续计提折旧。

## tips

1. **租赁分类判断**：区分经营租赁与融资租赁，是否转移与资产所有权有关的几乎全部风险和报酬是关键（勾稽H1-20）。
2. **持续折旧**：经营租出的固定资产仍由出租方计提折旧，不得停提。
3. **租金收入确认**：经营租赁租金收入按直线法确认，跨期租金须递延，勾稽收入底稿（D4）。
4. **单独列示**：经营租出固定资产在报表附注中须单独披露。
5. **租赁合同核对**：核对租赁合同的租期、租金、标的物与账面一致。
6. **减值关注**：经营租出资产的减值须考虑未来租金现金流。

## checklist

### 分类与折旧
- [ ] 经营租赁与融资租赁分类判断是否正确
- [ ] 经营租出资产是否持续计提折旧
- [ ] 租赁合同要素是否与账面核对

### 收入与列报
- [ ] 租金收入是否按直线法确认、跨期递延
- [ ] 租金收入是否与收入底稿勾稽
- [ ] 经营租出资产是否单独披露
- [ ] 减值是否考虑租金现金流

## risk_areas

### 高风险
1. **融资租赁误判为经营租赁虚增资产**：融资租赁误判为经营租赁虚增资产。
2. **经营租出资产停提折旧**：经营租出资产停提折旧。

### 中风险
1. **租金收入确认时点/方法错误**：租金收入确认时点/方法错误。
2. **未单独列示披露**：未单独列示披露。

### 低风险
1. **租赁合同核对不完整**：租赁合同核对不完整。
2. **减值未考虑租金现金流**：减值未考虑租金现金流。
