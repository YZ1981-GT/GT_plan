# H8-10 使用权资产减值测算表复核提示词

## 适用底稿
使用权资产减值测算表（H8-10），聚焦减值迹象识别、资产组划分、可收回金额确定、减值损失计量及减值不得转回的合规性。

## 概述
H8-10 测算使用权资产的减值。复核须关注减值迹象识别（如亏损门店/闲置租赁资产）、减值测试的资产组划分、可收回金额确定的合理性及减值损失计量准确性，减值一经确认不得转回。

---

## tips

1. **减值迹象识别**：使用权资产（如亏损经营场所租赁、闲置设备租赁、业务收缩涉及的租赁）存在减值迹象时须测试，迹象识别须结合经营亏损、闲置、业务变化。
2. **资产组划分**：使用权资产通常与其所服务的资产组一并测试减值（如门店整体作为资产组），单独产生现金流入的少见。
3. **可收回金额确定**：可收回金额=公允价值减处置费用与预计未来现金流量现值孰高。
4. **减值不得转回**：使用权资产减值损失一经确认，以后期间不得转回（CAS8）。
5. **减值与后续折旧**：确认减值后按减值后账面价值在剩余年限计提折旧（衔接H8-8）。
6. **减值勾稽**：减值损失和准备须与H8-1审定表、H8-3调整分录、H8-11可收回金额测试勾稽。

## checklist

### 一、减值迹象识别

- [ ] 是否识别使用权资产减值迹象（亏损/闲置/业务收缩）
- [ ] 有迹象的资产是否进行减值测试
- [ ] 迹象判断是否有客观证据

### 二、资产组与可收回金额

- [ ] 减值测试的资产组划分是否合理
- [ ] 可收回金额是否取孰高（公允价值减处置费用/现金流现值）
- [ ] 现金流量预测是否合理（见H8-11）
- [ ] 折现率是否恰当

### 三、减值损失计量

- [ ] 减值损失=账面价值-可收回金额是否正确
- [ ] 资产组减值损失分摊是否恰当
- [ ] 减值损失是否计入资产减值损失
- [ ] 减值后折旧基数是否调整（衔接H8-8）

### 四、合规与勾稽

- [ ] 已确认减值是否未违规转回
- [ ] 减值是否与H8-1、H8-3、H8-11勾稽
- [ ] 减值是否恰当披露

## risk_areas

### 高风险

1. **减值迹象视而不见**：亏损门店/闲置租赁存在减值迹象却不测试确认。
2. **可收回金额高估**：现金流预测乐观或折现率过低规避减值。
3. **减值违规转回**：已确认使用权资产减值违规转回虚增利润。

### 中风险

1. **资产组划分不当**：资产组划分不合理影响减值测算。
2. **现金流预测不合理**：预测脱离经营实际。
3. **减值后折旧未调整**：减值后未按新账面价值折旧。

### 低风险

1. **减值测算文档不足**：测算过程和假设记录不完整。
2. **减值披露不充分**：减值原因和金额披露不完整。
