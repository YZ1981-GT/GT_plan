# H3-13 投资性房地产关联交易 复核提示词

## 概述

本提示词针对投资性房地产关联交易检查表（H3-13）的复核，聚焦关联方租赁/购置/处置物业的识别完整性、交易价格（含租金）公允性、关联方清单核对及披露充分性。

## tips

1. **关联方完整**：关联方物业交易（购置/处置/出租）须与B19关联方清单核对。
2. **价格公允**：关联方租金、购置/处置价格须与市场价对比，异常偏离评估利益输送。
3. **关联租金**：出租给关联方的物业租金公允性须评估（联动H3-14）。
4. **交易实质**：关注以物业交易名义的资金占用或利益输送。
5. **披露完整**：关联方物业交易金额、定价方式、往来余额按CAS36披露。
6. **国企关注**：国企与关联方物业交易合规性与公允性评估。

## checklist

### 识别与公允性
- [ ] 关联方交易是否与B19清单核对完整
- [ ] 购置/处置/租金价格是否公允
- [ ] 关联租金公允性是否评估（H3-14）
- [ ] 交易实质是否清晰

### 披露与合规
- [ ] 交易金额/定价/往来余额是否披露
- [ ] 国企关联交易是否合规

## risk_areas

### 高风险
1. **关联方低价处置/低租金利益输送**：关联方低价处置/低租金利益输送。
2. **未识别关联方交易漏报**：未识别关联方交易漏报。

### 中风险
1. **交易价格公允性未评估**：交易价格公允性未评估。
2. **披露不完整**：披露不完整。

### 低风险
1. **定价方式说明不足**：定价方式说明不足。
2. **与B19索引不完整**：与B19索引不完整。
