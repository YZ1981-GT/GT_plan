# H2-2 在建工程明细表 复核提示词

## 概述

本提示词针对在建工程明细表（H2-2）的复核，聚焦按工程项目的成本构成（设备/建安/待摊/资本化利息）明细、增减变动及与审定表、增加检查、转固检查的勾稽。明细表按项目归集资本性支出。

## tips

1. **成本构成完整**：每项工程成本含设备投资、建筑安装、待摊投资、资本化利息，构成须完整清晰。
2. **明细合计=审定表**：各工程期末余额合计须与H2-1审定表审定数一致。
3. **增加来源可追溯**：本期增加须区分工程款、设备采购、资本化利息，逐笔单据支持（勾稽H2-8）。
4. **转固明细**：转入固定资产的工程须列示转固金额与转固时点，勾稽H2-5转固检查与H1。
5. **待摊投资分摊**：待摊投资（如前期工程费、监理费）应按合理基础分摊至各单项工程。
6. **超概算预警**：实际成本超过工程概算的项目须关注，可能存在成本失控或资本化范围错误。

## checklist

### 成本与增减
- [ ] 工程成本构成是否完整（设备/建安/待摊/利息）
- [ ] 本期增加是否与H2-8增加检查勾稽
- [ ] 转固金额/时点是否与H2-5及H1勾稽
- [ ] 待摊投资分摊是否合理

### 勾稽与预警
- [ ] 明细合计是否等于H2-1审定数
- [ ] 资本化利息是否与H2-10/H2-11勾稽
- [ ] 超概算项目是否关注
- [ ] 是否存在长期停工工程

## risk_areas

### 高风险
1. **明细合计与审定表不符**：明细合计与审定表不符。
2. **转固明细与H1不勾稽**：转固明细与H1不勾稽。
3. **费用性支出误计入工程成本**：费用性支出误计入工程成本。

### 中风险
1. **待摊投资分摊不合理**：待摊投资分摊不合理。
2. **超概算未关注**：超概算未关注。

### 低风险
1. **成本构成列示不清**：成本构成列示不清。
2. **长期停工工程未标注**：长期停工工程未标注。
