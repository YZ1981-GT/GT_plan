# H10-3 资产处置收益调整分录复核提示词

## 适用底稿
资产处置收益调整分录汇总表（H10-3），含账项调整（AJE）、重分类调整（RJE）及未调整错报评估，聚焦调整证据、借贷平衡、回写H10-1审定表及利润表影响。

## 概述
H10-3 是资产处置收益审定链路的关键环节。复核须验证：每笔调整有证据支持、借贷平衡、完整反映到H10-1审定表、损益归类调整（资产处置收益vs营业外收支）恰当，未调整错报评估符合重要性水平要求。

---

## tips

1. **AJE与RJE区分**：AJE影响处置损益金额（补记处置收入、更正账面净值、补记税费）；RJE多为损益重分类（资产处置收益与营业外收支之间、与其他损益科目之间的重分类），不得通过RJE掩盖损益错报。
2. **损益归类调整恰当**：调整涉及资产处置收益与营业外收支重分类的，须基于处置性质（正常处置vs非正常损失）判断，方向正确。
3. **与H10-1勾稽**：审定表调整列金额须与H10-3已确认分录逐笔一致。
4. **与清理台账联动**：涉及固定资产处置的调整须与H6清理台账（H6-3）联动一致。
5. **利润表影响评估**：资产处置收益调整影响营业利润，须评估对利润总额、营业利润的影响并与利润表勾稽。
6. **TB回写**：确认调整已同步试算平衡表6115及相关科目，避免双真源。

## checklist

### 高风险检查项

- [ ] 所有AJE是否有充分审计证据（处置合同、评估报告、收款凭证、台账）
- [ ] 处置收入/账面净值/税费更正调整是否有证据支持
- [ ] 每笔调整分录借贷方是否完全平衡
- [ ] 调整金额是否完整反映到H10-1审定表对应调整列
- [ ] 损益归类调整（资产处置收益vs营业外收支）是否恰当
- [ ] 涉及固定资产的调整是否与H6-3联动一致
- [ ] 是否存在仅为调节营业利润的不当调整

### 中风险检查项

- [ ] RJE是否仅涉及损益重分类，未虚增/虚减处置损益总额
- [ ] 调整原因说明是否可追溯至H10-2/H10-4
- [ ] 调整分录编号是否连续
- [ ] 与A13未调整错报汇总表索引是否完整
- [ ] 涉及增值税的调整是否同步应交税费

### 低风险检查项

- [ ] 分录摘要、科目编码是否规范
- [ ] 索引是否指向H10-2/H10-4/H6等支持底稿
- [ ] 审计说明/结论是否概括调整性质

## risk_areas

### 高风险

- 损益归类调整掩盖非正常损失（营业外支出错入资产处置收益美化营业利润）
- 调整缺乏证据或未经授权
- 与H6清理台账调整不联动

### 中风险

- RJE误改处置损益总额
- 增值税调整遗漏
- 审定表与H10-3金额长期不一致

### 低风险

- 编号、格式不规范
- 索引缺失

## 跨底稿勾稽

- H10-3 已确认 AJE/RJE 合计 ↔ H10-1 审定表调整列
- H10-3 固定资产处置调整 ↔ H6-3 清理调整（联动）
- H10-3 损益归类调整 ↔ 营业外收支
- H10-3 未调整错报 ↔ A13 未调整错报汇总
- 调整后审定数 ↔ 试算平衡表 6115 科目 / 利润表资产处置收益
