# H1-3 固定资产调整分录 复核提示词

## 概述

本提示词针对固定资产调整分录汇总表（H1-3）的复核，含账项调整（AJE）、重分类调整（RJE）及未调整错报评估。复核须验证每笔调整有证据、借贷平衡、完整反映到H1-1审定表并同步试算平衡表。

## tips

1. **AJE vs RJE**：补提折旧、计提减值、更正资本化错误属AJE（影响损益或资产金额）；经营租出资产重分类属RJE（仅影响列报）。
2. **与H1-1勾稽**：审定表调整列须与H1-3已确认分录逐笔一致，遗漏即审定数失真。
3. **常见调整**：少提/多提折旧调整、减值补提、后续支出误费用化/资本化更正、在建工程未及时转固补记。
4. **TB回写**：确认调整已同步试算平衡表1601/1602/1603，避免底稿已调TB未更的双真源。
5. **SUD累计**：未调整错报单独及累计是否超过重要性，须与A13未调整错报汇总交叉验证。
6. **审批链**：超过明细层次重要性的调整须合伙人/项目经理审批留痕。

## checklist

### 高风险检查项
- [ ] 每笔AJE是否有充分审计证据（折旧测算/减值测算/凭证检查）
- [ ] 调整分录借贷方是否完全平衡
- [ ] 调整金额是否完整反映到H1-1审定表对应调整列
- [ ] 折旧调整是否同时更新累计折旧与损益科目
- [ ] 减值调整是否计入资产减值损失并核对H1-14

### 中风险检查项
- [ ] RJE是否仅涉及列报（如经营租出重分类）未影响损益
- [ ] 调整原因是否可追溯至具体审计程序
- [ ] 与A13未调整错报汇总索引是否完整
- [ ] 跨期调整是否正确区分本期与前期差错

### 低风险检查项
- [ ] 分录摘要、科目编码是否规范
- [ ] 调整分录编号是否连续、删除无重号风险
- [ ] 审计说明是否概括调整性质与残余风险

## risk_areas

### 高风险
1. **调整缺乏证据或未经授权**：调整缺乏证据或未经授权。
2. **审定表与H1-3调整金额不一致**：审定表与H1-3调整金额不一致。
3. **SUD累计超阈值未恰当处理**：SUD累计超阈值未恰当处理。

### 中风险
1. **RJE误含损益影响**：RJE误含损益影响。
2. **折旧/减值调整仅调一方科目导致不平衡**：折旧/减值调整仅调一方科目导致不平衡。

### 低风险
1. **编号、格式不规范**：编号、格式不规范。
2. **索引指向支持底稿不完整**：索引指向支持底稿不完整。
