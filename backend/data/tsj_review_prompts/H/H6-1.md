# H6-1 固定资产清理审定表复核提示词

## 概述

本提示词针对固定资产清理（科目1606）审定表（H6-1）的复核。固定资产清理是处置固定资产的过渡性科目，正常情况下期末余额应为零，其借贷方发生额反映资产账面价值转出、清理费用、处置收入及净损益结转。复核聚焦期末清零、清理净损益结转方向、与H6-2明细勾稽及处置收益列报准确性。

**法规依据：**
- 《企业会计准则第4号——固定资产》（处置及清理）
- 《企业会计准则第42号——持有待售的非流动资产、处置组和终止经营》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **期末应为零是清理科目的核心特征**：固定资产清理是过渡科目，正常处置完成后余额应结转为零；期末仍有余额意味着清理未完成或结转遗漏，需追查未了结清理项目及原因。
2. **净损益结转方向决定利润表列报**：清理完成后净收益结转「资产处置收益」（H10/6115）、涉及非流动资产处置或报废按性质结转「营业外收入/支出」，方向错误将错列利润表项目。
3. **借方构成须完整**：借方=转出固定资产账面净值（原值-累计折旧-减值准备）+ 清理相关税费及支出；核对是否遗漏应转出的减值准备或多转累计折旧。
4. **贷方构成须真实**：贷方=处置取得的价款、残料变价收入、保险赔偿及责任人赔偿；关注处置收入是否入账完整、有无体外循环。
5. **审定表是跨底稿勾稽枢纽**：H6-1审定数须与H6-2明细表逐项清理台账合计一致，清理净损益须与H10资产处置收益或营业外收支勾稽，任何断裂即为复核重点。
6. **关注期末未了结的重大清理项目**：对期末仍挂账的清理项目，评估是否属于持有待售（适用CAS42按孰低计量）或长期未处置的僵尸资产，判断计价与列报是否恰当。

## checklist

### 一、期末清零与勾稽

- [ ] 固定资产清理科目期末余额是否为零（正常处置已完成）
- [ ] 若期末有余额，是否已说明未了结清理项目及预计完成时间
- [ ] H6-1审定数各项目是否与H6-2清理明细台账逐笔勾稽一致
- [ ] 本期借方发生额是否等于转出固定资产账面净值加清理费用合计
- [ ] 本期贷方发生额是否等于处置收入、残值变价及各类赔偿合计
- [ ] 期初余额是否等于上年审定表期末余额（若上年未清零）

### 二、账面价值转出准确性

- [ ] 转出的固定资产原值是否与H8/固定资产台账一致
- [ ] 累计折旧转出金额是否与折旧台账、H6-2减少检查勾稽
- [ ] 已计提减值准备是否随资产一并转出（不得遗漏）
- [ ] 处置资产是否办妥内部报废/出售审批手续
- [ ] 是否存在账面已转出但实物仍在使用的情况

### 三、清理净损益结转

- [ ] 清理净损益计算是否正确（贷方合计-借方合计）
- [ ] 正常出售/转让净损益是否结转「资产处置收益」（6115）
- [ ] 报废/毁损净损益是否结转「营业外收入/支出」
- [ ] 结转方向是否与处置性质匹配（正常处置vs非正常损失）
- [ ] 涉及增值税销项税额是否正确处理
- [ ] 清理净损益是否与H10审定数、利润表相关项目勾稽

### 四、调整与列报

- [ ] 所有账项调整（AJE）/重分类调整（RJE）是否完整反映在审定表
- [ ] 调整分录借贷方是否平衡且有充分证据支持
- [ ] 审定表调整后金额是否等于未审数加AJE加RJE
- [ ] 期末未了结清理项目是否评估持有待售分类（CAS42孰低）
- [ ] 审定表列报是否与财务报表附注披露口径一致

## risk_areas

### 高风险

1. **期末未清零掩盖已发生损失**：清理科目长期挂账，实为已发生的处置损失或报废损失迟迟不结转，人为递延损失确认。
2. **净损益结转方向错误**：将报废损失错列为资产处置收益，或将处置收益错入营业外收入，扭曲利润表结构。
3. **账面净值转出不完整**：转出时遗漏已计提减值准备或多转累计折旧，导致清理净损益虚增或虚减。
4. **处置收入入账不完整**：残料变价收入、保险赔偿未入账形成账外资金，构成舞弊风险。
5. **审定数与明细/H10不勾稽**：审定数与清理台账或资产处置收益不一致，存在未记录调整或汇总错误。

### 中风险

1. **持有待售分类判断缺失**：期末未处置资产符合持有待售条件但未按CAS42重分类和孰低计量。
2. **处置审批手续不完备**：重大资产处置未经恰当授权审批即已账务处理。
3. **增值税处理错误**：处置动产/不动产的销项税额计算或列报错误。
4. **调整分录方向或金额错误**：RJE借贷方向颠倒或调整金额与清理台账不符。

### 低风险

1. **清理项目说明不充分**：期末挂账清理项目未附简要进度说明。
2. **底稿交叉索引不完整**：审定表未与H6-2、H10、固定资产台账建立完整索引。
3. **格式不规范**：列标题、编号、金额单位等格式细节问题，不影响数据准确性。
