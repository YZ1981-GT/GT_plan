# H10-1 资产处置收益审定表复核提示词

## 概述

本提示词针对资产处置收益（科目6115，损益类）审定表（H10-1）的复核。资产处置收益反映出售/转让固定资产、无形资产、在建工程等非流动资产（不含金融工具、投资性房地产等按其他准则处理的）产生的处置利得或损失，以及债务重组中处置非流动资产的损益。复核聚焦损益构成完整性、发生额确认（损益类）、结转方向及与清理台账勾稽。

**法规依据：**
- 《企业会计准则第42号——持有待售的非流动资产、处置组和终止经营》
- 《企业会计准则第4号——固定资产》（处置）
- 《中国注册会计师审计准则第1301号——审计证据》

## tips

1. **损益类科目取本期发生额**：资产处置收益为损益类科目，审定关注本期发生额（贷方净额为收益、借方净额为损失），期末结转本年利润后无余额。
2. **明确列报范围**：资产处置收益核算固定资产、在建工程、无形资产等处置损益及债务重组处置非流动资产损益；金融资产、投资性房地产、长期股权投资等处置损益按各自准则列报，不得混入。
3. **正常处置vs非正常损失**：正常出售/转让的处置损益计入资产处置收益，因自然灾害等非正常原因的报废毁损损失计入营业外支出，须区分。
4. **与固定资产清理（H6）勾稽**：固定资产处置净损益通过H6清理科目结转至资产处置收益，须与H6-1、H6-2清理台账勾稽。
5. **审定表是损益勾稽枢纽**：审定数须与H10-2明细、H6清理、无形资产/在建工程处置勾稽，并与利润表资产处置收益项目一致。
6. **关注跨期与集中处置**：期末集中处置或跨期确认处置损益须核对处置完成时点，防止人为调节利润。

## checklist

### 一、发生额与结转

- [ ] 资产处置收益本期发生额（贷方收益/借方损失）是否正确
- [ ] 期末是否结转本年利润后无余额
- [ ] 本期发生额是否与H10-2明细勾稽
- [ ] 发生额方向（收益/损失）是否与实际处置结果一致

### 二、列报范围准确性

- [ ] 是否仅核算固定资产/在建工程/无形资产等处置损益
- [ ] 金融资产/投资性房地产/长投处置损益是否未混入
- [ ] 债务重组处置非流动资产损益是否恰当列入
- [ ] 非正常报废毁损损失是否列入营业外支出而非本科目

### 三、与清理台账勾稽

- [ ] 固定资产处置净损益是否与H6-1、H6-2清理台账勾稽
- [ ] 无形资产/在建工程处置损益是否与相应底稿勾稽
- [ ] 处置收入、账面净值、相关税费是否准确
- [ ] 处置损益计算（收入-净值-税费）是否正确

### 四、调整与勾稽

- [ ] 所有AJE/RJE是否完整反映在审定表
- [ ] 调整分录借贷方是否平衡且有充分证据
- [ ] 审定数是否与试算平衡表6115科目勾稽
- [ ] 资产处置收益是否与利润表相应项目一致
- [ ] 审定表是否与附注披露口径一致

## risk_areas

### 高风险

1. **损益归类错误美化利润结构**：将营业外收支错列资产处置收益（或反之），或将金融资产处置损益混入，扭曲利润结构。
2. **处置损益跨期调节利润**：通过操纵处置完成时点在期末集中确认处置收益调节利润。
3. **处置收入不完整/账面净值错误**：处置收入未全额入账或账面净值计算错误导致处置损益失真。
4. **与H6清理台账不勾稽**：资产处置收益与固定资产清理台账不一致，存在未记录调整。

### 中风险

1. **列报范围混淆**：其他准则处理的资产处置损益混入资产处置收益。
2. **非正常损失错列**：灾害报废损失错列资产处置收益。
3. **调整分录方向错误**：RJE借贷方向颠倒或金额与明细不符。
4. **相关税费处理错误**：处置涉及的增值税等税费处理错误。

### 低风险

1. **明细归集不清**：处置损益未按处置资产类别归集。
2. **底稿索引不完整**：审定表未与H10-2、H6、利润表建立索引。
3. **格式不规范**：列标题、编号等格式细节问题。
