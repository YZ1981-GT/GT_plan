# H5-7 油气资产增加检查 复核提示词

## 概述

本提示词针对油气资产增加检查表（H5-7）的复核，聚焦本期勘探开发资本化支出的资本化范围、成功努力法应用、弃置费用资本化及抽凭充分性。资本化范围是油气资产审计的核心风险。

## tips

1. **资本化范围**：区分勘探支出、开发支出，成功努力法下失败勘探井支出应费用化，仅成功井及开发支出资本化。
2. **矿区权益取得**：探矿权/采矿权取得成本资本化，须核对权证与付款。
3. **弃置费用资本化**：油气井弃置义务现值应在初始确认时资本化计入原值（勾稽预计负债）。
4. **开发井投入**：钻井、完井、地面设施投入核对合同、结算、验收。
5. **抽凭覆盖大额**：大额资本化支出抽凭核对，检查比例达标。
6. **关联工程公允**：关联方钻井/工程服务价格公允性评估。

## checklist

### 资本化范围与成本
- [ ] 失败勘探井支出是否费用化（成功努力法）
- [ ] 成功井/开发支出资本化是否正确
- [ ] 矿区权益取得成本是否核对权证/付款
- [ ] 弃置费用是否资本化并确认预计负债

### 抽凭与勾稽
- [ ] 大额资本化支出抽凭比例是否达标
- [ ] 本期增加是否与H5-2/H5-1勾稽
- [ ] 关联工程服务价格是否公允

## risk_areas

### 高风险
1. **失败勘探井违规资本化虚增资产**：失败勘探井违规资本化虚增资产。
2. **费用性支出误资本化**：费用性支出误资本化。
3. **弃置费用未资本化**：弃置费用未资本化。

### 中风险
1. **关联工程价格不公允**：关联工程价格不公允。
2. **矿区权益成本核对不到位**：矿区权益成本核对不到位。

### 低风险
1. **抽凭比例略低**：抽凭比例略低。
2. **单据索引不完整**：单据索引不完整。
