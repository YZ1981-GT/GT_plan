# H3-6 投资性房地产互转审核 复核提示词

## 概述

本提示词针对投资性房地产互转审核表（H3-6）的复核，聚焦投资性房地产与自用房地产、存货之间转换的转换日判断、转换价值确定及转换损益处理。互转是投资性房地产计量的关键节点。

## tips

1. **转换条件判断**：自用转投资性（停止自用开始出租/资本增值）、存货转投资性、投资性转自用/存货的转换条件须准确判断。
2. **转换日确定**：转换日以用途实质改变日为准，而非管理层意向声明日。
3. **成本模式转换**：成本模式下按转换前账面价值作为转换后入账价值，不产生损益。
4. **公允价值模式转换**：公允价值模式下，自用/存货转投资性时公允价值大于账面价值的差额计入其他综合收益（自用转）或当期损益（存货转）；投资性转自用/存货按转换日公允价值。
5. **损益处理正确**：转换损益的计入科目（其他综合收益/当期损益）须准确。
6. **与明细/审定勾稽**：转换金额须与H3-2明细、H3-1审定勾稽。

## checklist

### 转换判断与价值
- [ ] 转换条件判断是否准确
- [ ] 转换日是否以用途实质改变日为准
- [ ] 转换价值确定是否符合模式规则
- [ ] 转换损益计入科目是否正确

### 勾稽
- [ ] 转换金额是否与H3-2明细勾稽
- [ ] 转换是否反映到H3-1审定表

2. **转换日操纵利用公允价值变动调节利润**：转换日操纵利用公允价值变动调节利润。
