# H1-5 固定资产会计政策检查 复核提示词

## 概述

本提示词针对固定资产会计政策检查表（H1-5）的复核，聚焦折旧方法、折旧年限、预计净残值的确定依据与一贯性，及会计估计变更的合规性。政策一贯性是固定资产审计的基础。

## tips

1. **折旧方法一贯**：年限平均法/工作量法/加速折旧法的选择须与资产使用模式匹配且前后期一贯。
2. **折旧年限合理**：各类别折旧年限须在准则/税法参考区间内，与资产实际经济寿命匹配，异常偏短或偏长需关注。
3. **净残值合理**：预计净残值率通常3%-5%，异常值需依据支持。
4. **估计变更处理**：折旧年限/方法/残值变更属会计估计变更，采用未来适用法，不得追溯，且须充分披露。
5. **与折旧测算勾稽**：政策表确定的方法/年限/残值须与H1-12折旧测算表实际使用参数一致。
6. **税会差异关注**：会计折旧与税法折旧差异形成的暂时性差异应联动递延所得税（N1/N3）。

## checklist

### 政策合理性与一贯性
- [ ] 各类别折旧方法是否明确且与使用模式匹配
- [ ] 折旧年限是否在合理区间且前后期一贯
- [ ] 预计净残值率是否合理且有依据
- [ ] 是否存在未披露的政策变更

### 变更与联动
- [ ] 会计估计变更是否采用未来适用法且已披露
- [ ] 政策参数是否与H1-12折旧测算一致
- [ ] 税会折旧差异是否联动递延所得税

## risk_areas

### 高风险
1. **折旧年限异常偏长**：少提折旧虚增利润。
2. **会计估计变更采用追溯法或未披露**：会计估计变更采用追溯法或未披露。

### 中风险
1. **政策表参数与实际折旧测算不一致**：政策表参数与实际折旧测算不一致。
2. **净残值率缺乏依据**：净残值率缺乏依据。

### 低风险
1. **政策描述模板化未结合企业实际**：政策描述模板化未结合企业实际。
2. **税会差异说明不充分**：税会差异说明不充分。
