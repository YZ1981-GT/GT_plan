# H2-17 在建工程关联交易 复核提示词

## 概述

本提示词针对在建工程关联交易检查表（H2-17）的复核，聚焦关联方承包施工/供应设备材料的识别完整性、交易价格公允性、关联方清单核对及披露充分性。关联方工程交易是成本虚增与利益输送高发领域。

## tips

1. **关联方完整**：关联方承包/供应交易须与B19关联方清单核对，防止漏报。
2. **价格公允**：关联方施工/供应价格须与市场价、招投标价对比，异常偏高提示利益输送。
3. **交易实质**：关注以工程交易名义进行的资金占用或利益输送。
4. **招投标合规**：关联方中标须评估招投标程序合规性。
5. **披露完整**：关联方工程交易金额、定价方式、往来余额按CAS36披露。
6. **国企特别关注**：国企关联方施工须评估合规性与公允性。

## checklist

### 识别与公允性
- [ ] 关联方交易是否与B19清单核对完整
- [ ] 施工/供应价格是否公允（对比市场/招投标）
- [ ] 招投标程序是否合规
- [ ] 交易实质是否清晰

### 披露与合规
- [ ] 交易金额/定价/往来余额是否披露
- [ ] 国企关联施工是否合规
- [ ] 审批程序是否完整

## risk_areas

### 高风险
1. **关联方高价承包虚增工程成本、利益输送**：关联方高价承包虚增工程成本、利益输送。
2. **未识别关联方交易漏报**：未识别关联方交易漏报。

### 中风险
1. **招投标不合规**：招投标不合规。
2. **披露不完整**：披露不完整。

### 低风险
1. **定价方式说明不足**：定价方式说明不足。
2. **与B19索引不完整**：与B19索引不完整。
