# H8-3 使用权资产调整分录复核提示词

## 适用底稿
使用权资产调整分录汇总表（H8-3），含账项调整（AJE）、重分类调整（RJE）及未调整错报评估，聚焦调整证据、借贷平衡、回写H8-1审定表及与租赁负债联动。

## 概述
H8-3 是使用权资产审定链路的关键环节。复核须验证：每笔调整有证据支持、借贷平衡、完整反映到H8-1审定表、租赁相关调整同时考虑使用权资产与租赁负债（H9）的联动影响，未调整错报评估符合重要性水平要求。

---

## tips

1. **AJE与RJE区分**：AJE影响使用权资产账面或损益（补记初始确认、补提折旧、补计减值、租赁变更重估）；RJE仅影响列报，不得通过RJE掩盖损益错报。
2. **使用权资产与租赁负债联动**：初始确认、租赁变更、重估类调整通常同时影响使用权资产和租赁负债，须核对H8-3与H9-4调整是否联动一致。
3. **与H8-1勾稽**：审定表调整列金额须与H8-3已确认分录逐笔一致。
4. **首年衔接调整**：首年执行新租赁准则的追溯调整须区分简化处理和全面追溯，会计处理正确。
5. **审批链**：超过明细层次重要性水平的调整须合伙人/项目经理审批留痕。
6. **TB回写**：确认调整已同步试算平衡表使用权资产及相关科目，避免双真源。

## checklist

### 高风险检查项

- [ ] 所有AJE是否有充分审计证据（租赁合同、重估依据、减值测算）
- [ ] 初始确认/重估调整是否与H9租赁负债联动一致
- [ ] 补提折旧/减值调整是否有H8-8/H8-10测算支持
- [ ] 每笔调整分录借贷方是否完全平衡
- [ ] 调整金额是否完整反映到H8-1审定表对应调整列
- [ ] 首年衔接调整会计处理是否正确
- [ ] 是否存在为规避表内确认的不当豁免调整

### 中风险检查项

- [ ] RJE是否仅涉及列报，未影响使用权资产账面或损益
- [ ] 租赁变更调整是否同步调整使用权资产和租赁负债
- [ ] 调整原因说明是否可追溯至H8-4~H8-7、H8-10
- [ ] 与A13未调整错报汇总表索引是否完整
- [ ] 调整分录编号是否连续

### 低风险检查项

- [ ] 分录摘要、科目编码是否规范
- [ ] 索引是否指向H8-2/H8-6/H8-8/H8-10等支持底稿
- [ ] 审计说明/结论是否概括调整性质

---

## risk_areas

### 高风险

- 使用权资产与租赁负债调整不联动导致两表脱节
- 调整缺乏证据或未经授权
- 通过豁免调整规避表内确认

### 中风险

- RJE误含损益影响
- 租赁变更重估调整遗漏一方
- 首年衔接调整处理错误

### 低风险

- 编号、格式不规范
- 索引缺失

## 跨底稿勾稽

- H8-3 已确认 AJE/RJE 合计 ↔ H8-1 审定表调整列
- H8-3 初始确认/重估调整 ↔ H9-4 租赁负债调整（联动）
- H8-3 折旧/减值调整 ↔ H8-8/H8-10 测算
- H8-3 未调整错报 ↔ A13 未调整错报汇总
- 调整后审定数 ↔ 试算平衡表使用权资产科目
