# H3-8 投资性房地产公允价值复核 复核提示词

## 概述

本提示词针对投资性房地产公允价值复核表（H3-8）的复核，聚焦公允价值确定方法、估值参数合理性、公允价值层次划分（CAS39）及公允价值变动损益计算。公允价值是公允价值模式的核心审计事项。

## tips

1. **公允价值方法**：市场法（同类交易价）、收益法（租金资本化）、成本法，方法选择须适当且优先市场可观察数据。
2. **公允价值层次**：按CAS39划分第一/二/三层次，第三层次（重大不可观察输入）须披露估值技术与关键参数。
3. **评估师利用**：利用外部评估报告须评估评估师胜任能力、独立性及评估假设合理性（勾稽专家利用）。
4. **变动损益计算**：公允价值变动=期末公允价值−期初账面价值，计入公允价值变动损益。
5. **参数合理性**：收益法的租金增长率、资本化率、空置率等参数须合理有据。
6. **一致性**：公允价值确定方法前后期一致。

## checklist

### 方法与层次
- [ ] 公允价值方法是否适当且优先可观察数据
- [ ] 公允价值层次划分是否正确
- [ ] 第三层次估值技术与参数是否披露
- [ ] 外部评估师胜任能力/独立性是否评估

### 变动与参数
- [ ] 公允价值变动损益计算是否正确
- [ ] 收益法关键参数是否合理有据
- [ ] 方法是否前后期一致
- [ ] 是否与H3-1/H3-2勾稽
