# H2-note-soe 在建工程附注披露 复核提示词（国有企业）

## 概述

本提示词针对在建工程国有企业附注披露底稿的复核，在满足会计准则通用披露（项目明细/资本化利息/变动表/减值）基础上，聚焦国资监管相关披露：重大工程投资决策、超概算情况、长期停工缓建工程处置及国有资本性支出合规性。

## tips

1. **双层披露**：既满足CAS通用披露，又满足国资委财务决算额外要求。
2. **项目明细勾稽**：重要工程明细与资本化利息须完整并与审定表勾稽（与上市版共有）。
3. **重大投资决策**：重大在建工程投资须披露决策程序（"三重一大"）与批复情况。
4. **超概算披露**：超概算工程须披露超支金额、原因及追加审批。
5. **停工缓建处置**：长期停工缓建工程须披露处置计划与减值情况。
6. **资本性支出合规**：国有资本性支出预算执行情况须说明。

## checklist

### 基础披露（与上市版共有）
- [ ] 重要工程明细是否披露且与审定表勾稽
- [ ] 资本化利息/资本化率是否披露
- [ ] 增减变动是否与审定表勾稽
- [ ] 减值准备是否披露

### 国资监管专项
- [ ] 重大投资是否披露决策程序与批复
- [ ] 超概算工程是否披露超支及审批
- [ ] 长期停工缓建工程处置计划是否披露
- [ ] 数据是否与年度财务决算一致

## risk_areas

### 高风险
1. **重大投资缺决策程序说明**：重大投资缺决策程序说明。
2. **附注与审定表不勾稽**：附注与审定表不勾稽。

### 中风险
1. **超概算未披露**：超概算未披露。
2. **停工工程处置计划缺失**：停工工程处置计划缺失。

### 低风险
1. **披露格式未按决算模板**：披露格式未按决算模板。
2. **预算执行说明简略**：预算执行说明简略。
