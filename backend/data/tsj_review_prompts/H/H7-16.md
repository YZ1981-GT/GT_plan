# H7-16 生产性生物资产可收回金额测试表复核提示词

## 适用底稿
生产性生物资产可收回金额测试表（H7-16，仅成本模式），聚焦可收回金额两种口径的测算细节、关键假设合理性、折现率及现金流量预测的可靠性。

## 概述
H7-16 是H7-15减值测算的支撑底稿，详细测算生产性生物资产的可收回金额。复核须关注公允价值减处置费用与未来现金流量现值两种口径测算的完整性、关键假设（产量/价格/成本/折现率）的合理性及模型逻辑正确性。

---

## tips

1. **两种口径均须测算**：可收回金额取公允价值减处置费用与预计未来现金流量现值孰高，两者均应测算并取高，仅测算一种口径可能低估可收回金额或掩盖减值。
2. **现金流量基于剩余产出期**：未来现金流量预测须基于资产剩余生产年限的产出，超过剩余年限的现金流量不得纳入。
3. **产量假设匹配H7-14**：产出预测（产量×价格）须与H7-14产量记录、历史产出趋势匹配，不得过度乐观。
4. **成本假设完整**：现金流出须包括饲养/管护成本、防疫成本等维持资产产出的必要支出。
5. **折现率反映风险**：采用反映生物资产特定风险的税前折现率，与企业加权平均资金成本和资产风险匹配。
6. **模型逻辑校验**：折现期间、现金流量时点、终值处理等模型逻辑须校验正确。

---

## checklist

### 一、测算口径完整性

- [ ] 是否同时测算公允价值减处置费用和现金流量现值
- [ ] 可收回金额是否取两者孰高
- [ ] 公允价值来源和处置费用估计是否合理

### 二、现金流量预测

- [ ] 现金流入预测是否基于剩余生产年限的产出
- [ ] 产量假设是否与H7-14产量记录匹配
- [ ] 价格假设是否合理（对比市场/历史）
- [ ] 现金流出是否包括必要维持成本
- [ ] 是否剔除筹资/所得税等不相关现金流

### 三、折现率与模型

- [ ] 折现率是否反映资产特定风险
- [ ] 折现率取值是否有依据
- [ ] 折现期间与产出年限是否匹配
- [ ] 现金流量时点和终值处理是否正确

### 四、结论与衔接

- [ ] 可收回金额测算结果是否传递至H7-15
- [ ] 关键假设是否进行敏感性分析
- [ ] 测算是否需利用估值专家
- [ ] 测算结论是否支持减值判断

## risk_areas

### 高风险

1. **单口径低估减值**：仅测算一种口径且取值偏高，掩盖应确认的减值。
2. **产量/价格假设过度乐观**：现金流入预测脱离实际产出和市场价格，高估可收回金额。
3. **折现率过低**：折现率显著偏低虚增现值规避减值。

### 中风险

1. **现金流出不完整**：漏计维持资产产出的必要成本。
2. **折现期间超剩余年限**：纳入超过资产剩余生产年限的现金流量。
3. **敏感性分析缺失**：关键假设未做敏感性分析。

### 低风险

1. **模型文档不完整**：测算模型逻辑和参数记录不充分。
2. **专家利用评估不足**：复杂测算未评估是否需专家。
