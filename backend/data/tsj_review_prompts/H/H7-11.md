# H7-11 生产性生物资产折旧测算表复核提示词

## 适用底稿
生产性生物资产折旧测算表（H7-11，仅成本模式），聚焦折旧要素准确性、折旧方法与年限合理性、成熟起算时点及折旧计算的重新测算。

## 概述
H7-11 重新测算成熟生产性生物资产的折旧，验证折旧计提的准确性。复核须关注折旧要素（原值/残值/年限）取值、折旧方法一贯性、成熟起算时点及测算结果与账面、审定表的勾稽。

---

## tips

1. **仅成熟资产计提折旧**：未成熟生产性生物资产不计提折旧，测算表须剔除未成熟资产，误将未成熟纳入将虚增折旧。
2. **折旧要素逐项核对**：折旧基数（原值-预计净残值）、折旧年限、折旧方法须逐项核对至固定资产政策和资产卡片。
3. **成熟起算时点准确**：折旧自资产达到预定生产经营目的（成熟）的次月起计提，起算时点错误导致折旧多提/少提。
4. **折旧方法一贯**：年限平均法/工作量法/产量法须一贯运用，与H7-4政策一致。
5. **重新测算验证**：独立重新计算折旧金额，与账面计提对比，差异须查明。
6. **测算勾稽H7-12/H7-1**：折旧测算结果须与H7-12折旧分配、H7-1审定表累计折旧勾稽。

## checklist

### 一、折旧范围

- [ ] 是否仅对成熟生产性生物资产计提折旧
- [ ] 未成熟资产是否已剔除
- [ ] 成熟起算时点（达到预定生产经营目的次月）是否准确
- [ ] 本期成熟转入的资产是否正确纳入折旧

### 二、折旧要素

- [ ] 折旧基数（原值-预计净残值）是否准确
- [ ] 预计使用寿命是否与政策一致且合理
- [ ] 预计净残值率是否合理
- [ ] 折旧方法是否一贯（与H7-4政策一致）

### 三、折旧计算

- [ ] 重新测算折旧金额与账面计提是否一致
- [ ] 差异是否查明原因
- [ ] 产量法/工作量法的产量/工作量数据是否可靠
- [ ] 减值后折旧基数是否按减值后账面价值调整

### 四、勾稽

- [ ] 折旧测算合计是否与H7-12折旧分配勾稽
- [ ] 累计折旧是否与H7-1审定表、H7-2明细勾稽
- [ ] 折旧费用去向是否合理（生产成本/管理费用）

## risk_areas

### 高风险

1. **未成熟资产错提折旧**：将未成熟生产性生物资产纳入折旧虚增费用/减少净值。
2. **成熟起算时点操纵**：延迟成熟认定少提折旧虚增利润。
3. **折旧要素操纵**：延长年限/提高残值率系统性少提折旧。

### 中风险

1. **折旧方法不一贯**：随意变更折旧方法调节费用。
2. **产量/工作量数据不可靠**：产量法基础数据缺乏支持。
3. **减值后折旧基数未调整**：计提减值后未按新账面价值计提折旧。

### 低风险

1. **测算与账面小额差异**：舍入等原因产生的小额差异未说明。
2. **测算表格式不规范**：折旧要素列示不完整。
