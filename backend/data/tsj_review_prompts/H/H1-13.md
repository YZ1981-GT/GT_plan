# H1-13 固定资产折旧分配 复核提示词

## 概述

本提示词针对固定资产折旧分配表（H1-13）的复核，聚焦折旧费用按用途（生产成本/制造费用/管理费用/销售费用/研发支出）分配的准确性及与成本费用类底稿（F5/K8/K9/I6）的跨科目勾稽。折旧分配影响成本与损益归集。

## tips

1. **分配依据合理**：折旧按资产使用部门/用途分配，依据须与资产实际使用匹配。
2. **分配合计=计提**：各去向分配合计须等于H1-12本期折旧计提总额。
3. **跨科目勾稽**：分配至生产的进F5成本、管理费用进K9、销售费用进K8、研发进I6，须逐项勾稽。
4. **资本化折旧**：用于在建工程的固定资产折旧应资本化计入在建工程（H2），不得费用化。
5. **用途变更**：资产用途本期变更的须按变更后用途分配，避免分配口径滞后。
6. **异常占比**：某去向折旧占比异常须说明原因。

## checklist

### 分配准确性
- [ ] 分配依据是否与资产实际用途匹配
- [ ] 各去向分配合计是否等于本期计提总额
- [ ] 用于在建工程的折旧是否资本化

### 跨科目勾稽
- [ ] 生产折旧是否与F5成本勾稽
- [ ] 管理/销售折旧是否与K9/K8勾稽
- [ ] 研发折旧是否与I6勾稽
- [ ] 用途变更是否及时反映

## risk_areas

### 高风险
1. **分配合计≠计提总额**：折旧漏分或重分。
2. **应资本化折旧误费用化**：应资本化折旧误费用化。

### 中风险
1. **跨科目勾稽不符**：跨科目勾稽不符。
2. **用途变更未反映**：用途变更未反映。

### 低风险
1. **某去向占比异常缺说明**：某去向占比异常缺说明。
2. **分配表格式不规范**：分配表格式不规范。
