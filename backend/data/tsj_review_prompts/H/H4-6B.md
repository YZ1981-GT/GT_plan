# H4-6B 工程物资监盘小结 复核提示词

## 概述

本提示词针对工程物资监盘小结（H4-6B）的复核，聚焦监盘结论支撑、差异汇总与处理、存在性完整性结论及对积压/毁损物资减值迹象的评价。

## tips

1. **结论有支撑**：存在性/完整性结论须以H4-6A计划和H4-6盘点结果为依据。
2. **差异汇总完整**：盘盈盘亏差异汇总与盘点检查表一致，处理建议明确。
3. **减值迹象评价**：积压、毁损、过时物资须评价减值迹象（联动H4-7）。
4. **抽样评价**：抽样结果推断总体，评价是否需扩样。
5. **替代程序结论**：异地物资替代程序有效性结论明确。
6. **未决事项跟进**：未解决差异或疑问列示跟进计划。

## checklist

### 结论与差异
- [ ] 存在性/完整性结论是否有支撑
- [ ] 差异汇总是否与盘点检查表一致
- [ ] 处理建议是否明确
- [ ] 抽样推断总体是否合理

### 迹象与跟进
- [ ] 积压/毁损物资减值迹象是否评价
- [ ] 替代程序结论是否明确
- [ ] 未决事项跟进计划是否列示

## risk_areas

### 高风险
1. **结论无支撑或与盘点矛盾**：结论无支撑或与盘点矛盾。
2. **减值迹象未评价**：减值迹象未评价。

### 中风险
1. **差异汇总不一致**：差异汇总不一致。
2. **抽样评价不充分**：抽样评价不充分。

### 低风险
1. **未决事项跟进不明确**：未决事项跟进不明确。
2. **小结格式不规范**：小结格式不规范。
