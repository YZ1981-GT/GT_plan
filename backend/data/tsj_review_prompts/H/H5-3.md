# H5-3 油气资产调整分录 复核提示词

## 概述

本提示词针对油气资产调整分录汇总表（H5-3）的复核，含账项调整、重分类调整及未调整错报评估。复核须验证调整有证据、借贷平衡、完整反映到H5-1审定表并同步试算平衡表。

## tips

1. **常见调整**：折耗调整（储量变动重算）、减值补提、失败勘探井费用化更正、弃置费用调整、储量估计变更影响。
2. **与H5-1勾稽**：审定表调整列须与H5-3已确认分录逐笔一致。
3. **储量变更调整**：探明储量重估导致折耗率变化，属会计估计变更未来适用，本期折耗调整须体现。
4. **弃置费用调整**：弃置费用估计变更调整油气资产原值与预计负债（CAS13）。
5. **TB回写**：确认调整同步TB 1631/1632。
6. **SUD累计**：未调整错报与A13交叉验证。

## checklist

### 高风险检查项
- [ ] 每笔AJE是否有证据（折耗测算/储量报告/减值测算）
- [ ] 调整分录借贷是否平衡
- [ ] 调整是否完整反映到H5-1
- [ ] 储量变更折耗调整是否按未来适用

### 中风险检查项
- [ ] 弃置费用调整是否同步原值与预计负债
- [ ] RJE是否仅涉及列报
- [ ] 与A13未调整错报索引是否完整

### 低风险检查项
- [ ] 摘要、科目编码是否规范
- [ ] 编号连续、无重号风险

## risk_areas

### 高风险
1. **调整缺证据或未授权**：调整缺证据或未授权。
2. **储量变更未调整折耗**：储量变更未调整折耗。

### 中风险
1. **弃置费用调整仅调一方**：弃置费用调整仅调一方。
2. **RJE误含损益**：RJE误含损益。

### 低风险
