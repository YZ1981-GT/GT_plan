# H4-2 工程物资明细表 复核提示词

## 概述

本提示词针对工程物资明细表（H4-2）的复核，聚焦按物资类别（专用设备/专用材料/预付大型设备款等）的收发存明细、增减变动及与审定表、增加检查、减少检查的勾稽。

## tips

1. **收发存勾稽**：期末结存=期初+本期购入−本期领用，逐类别勾稽后汇总。
2. **明细合计=审定表**：各类别期末结存合计须与H4-1审定表审定数一致。
3. **购入来源**：本期购入区分外购设备、外购材料、预付设备款，单据支持（勾稽H4-4）。
4. **领用去向**：领用去向须明确转在建工程/固定资产的项目（勾稽H2/H1）。
5. **预付设备款**：预付大型设备款到货后转工程物资/在建工程，关注长期挂账预付款。
6. **积压识别**：长期未领用物资须标注，评估减值与用途。

## checklist

### 收发存与增减
- [ ] 各类别期末结存=期初+购入−领用是否成立
- [ ] 明细合计是否等于H4-1审定数
- [ ] 本期购入是否与H4-4勾稽
- [ ] 领用去向是否明确并与H2/H1勾稽

### 专项与积压
- [ ] 预付设备款到货是否及时结转
- [ ] 长期积压物资是否标注评估减值

## risk_areas

### 高风险
1. **明细合计与审定表不符**：明细合计与审定表不符。
2. **领用去向不明或与在建工程不勾稽**：领用去向不明或与在建工程不勾稽。

### 中风险
1. **预付设备款长期挂账**：预付设备款长期挂账。
2. **积压物资未评估减值**：积压物资未评估减值。

### 低风险
1. **物资类别列示不清**：物资类别列示不清。
2. **单据索引不完整**：单据索引不完整。
