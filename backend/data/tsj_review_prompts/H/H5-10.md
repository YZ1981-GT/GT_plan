# H5-10 油气资产盘点检查 复核提示词

## 概述

本提示词针对油气资产盘点检查表（H5-10）的复核，聚焦油气井及设施现场查看、运行状态核实、账实核对及存在性确认。盘点检查是油气资产存在性核心证据。

## tips

1. **现场核实**：记录油气井及设施现场实物存在、运行状态（生产/停产/待弃置）。
2. **运行数据核对**：核对生产运行记录、产量数据与账面资产状态一致。
3. **账实核对**：核对油气井清单与账面卡片、权证一致。
4. **状态记录**：记录井的状态（在产/停产/待弃置/报废），联动闲置检查与减值。
5. **储量核对**：现场结合储量评估报告核对折耗基础合理性。
6. **异地替代**：异地/无法到达井替代程序结果记录。

## checklist

### 现场核实
- [ ] 是否记录井及设施实物存在与运行状态
- [ ] 生产运行数据是否与账面核对
- [ ] 账实（清单/卡片/权证）是否核对
- [ ] 井状态是否记录

### 储量与替代
- [ ] 储量评估报告是否核对折耗基础
- [ ] 异地/无法到达井替代程序结果是否记录
- [ ] 差异是否通过H5-3调整闭环

## risk_areas

### 高风险
1. **账实差异重大未查明**：资产不存在风险。
2. **储量数据缺乏支持影响折耗**：储量数据缺乏支持影响折耗。

### 中风险
1. **井状态未记录减值漏识别**：井状态未记录减值漏识别。
2. **差异未闭环**：差异未闭环。

### 低风险
1. **异地替代程序不完整**：异地替代程序不完整。
2. **盘点记录不规范**：盘点记录不规范。
