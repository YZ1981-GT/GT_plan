# H7-15 生产性生物资产减值测算表复核提示词

## 适用底稿
生产性生物资产减值测算表（H7-15，仅成本模式），聚焦减值迹象识别、可收回金额确定、减值损失计量及减值不得转回的合规性。

## 概述
H7-15 测算成本模式下生产性生物资产的减值。复核须关注减值迹象识别的充分性、可收回金额（公允价值减处置费用与预计未来现金流量现值孰高）确定的合理性、减值损失计量准确性及减值一经确认不得转回的执行。

---

## tips

1. **减值迹象识别充分**：疫病、自然灾害、市场价格持续下跌、生产能力下降、技术淘汰等均为减值迹象，须全面识别（CAS8）。
2. **可收回金额孰高确定**：可收回金额=公允价值减处置费用与预计未来现金流量现值两者孰高，两者均须合理测算。
3. **未来现金流量预测合理**：基于资产剩余生产年限的产出预期、价格、成本，预测须合理并与H7-14产量、经营预算匹配。
4. **折现率恰当**：反映资产特定风险的税前折现率，折现率取值须有依据（H7-16可收回金额测试）。
5. **减值不得转回**：生物资产（属CAS8范围的长期资产）减值损失一经确认，在以后会计期间不得转回。
6. **减值勾稽审定表**：减值损失和减值准备须与H7-1审定表、H7-3调整分录勾稽。

## checklist

### 一、减值迹象识别

- [ ] 是否全面识别减值迹象（疫病/灾害/价格下跌/产能下降）
- [ ] 是否结合H7-9盘点、H7-5分析、H7-14产量识别迹象
- [ ] 有迹象的资产是否均进行减值测试
- [ ] 迹象判断是否有客观证据支持

### 二、可收回金额确定

- [ ] 公允价值减处置费用是否合理测算
- [ ] 预计未来现金流量现值是否合理测算
- [ ] 可收回金额是否取两者孰高
- [ ] 现金流量预测是否与产量、经营预算匹配
- [ ] 折现率是否恰当（见H7-16）

### 三、减值损失计量

- [ ] 减值损失=账面价值-可收回金额计算是否正确
- [ ] 减值是否按单项资产或资产组测算
- [ ] 减值损失是否计入资产减值损失
- [ ] 减值后折旧基数是否调整（衔接H7-11）

### 四、合规与勾稽

- [ ] 已确认减值是否未违规转回
- [ ] 减值损失/准备是否与H7-1审定表勾稽
- [ ] 减值调整是否与H7-3勾稽
- [ ] 减值是否恰当披露

## risk_areas

### 高风险

1. **减值迹象视而不见**：存在疫病/灾害/产能下降迹象却不测试、不确认减值，虚增资产利润。
2. **可收回金额高估**：现金流量预测过于乐观或折现率过低高估可收回金额，规避减值。
3. **减值违规转回**：将已确认的生物资产减值准备转回虚增利润。

### 中风险

1. **现金流量预测不合理**：产出/价格预测与实际或产量记录脱节。
2. **折现率不恰当**：折现率取值缺乏依据。
3. **资产组划分不当**：减值测算的资产组划分不合理。

### 低风险

1. **减值测算文档不足**：测算过程和假设记录不完整。
2. **减值披露不充分**：减值原因和金额披露不完整。
