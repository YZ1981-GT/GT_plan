# H9-note-soe 租赁负债附注披露复核提示词（国有企业）

## 概述

本提示词针对国有企业租赁负债附注披露底稿（H9-note-soe）的复核。国有企业除满足CAS21承租人负债披露要求外，还须关注国有资产监管相关披露：重大租赁负债对负债规模和资产负债率的影响、售后租回融资合规性、关联方租赁负债及与上市版的差异关注点。

**法规依据：**
- 《企业会计准则第21号——租赁》
- 《企业会计准则第30号——财务报表列报》
- 《企业国有资产法》
- 《中央企业财务决算报告管理办法》

---

## tips

1. **国企租赁负债有"双层"披露要求**：既满足CAS21承租人负债披露，又满足国资监管对负债规模、融资合规和关联方租赁的披露。
2. **负债规模与资产负债率影响**：租赁负债纳入表内后对负债规模和资产负债率的影响须关注，国资监管对负债率有考核要求。
3. **售后租回融资合规**：售后租回本质为融资的，须关注是否履行融资审批程序及对国有资产的影响。
4. **关联方租赁负债披露**：与控股股东及同受国有控制企业的租赁负债须纳入关联方披露。
5. **到期期限与偿债能力**：租赁负债到期期限分析结合企业偿债能力，国企须关注中长期偿债压力。
6. **与上市版差异在监管层面**：基础披露框架相同（到期分析/利息/现金流出），国企版额外增加融资合规、关联方租赁、负债率影响等国资监管信息。

## checklist

### 一、基础披露完整性（与上市版共有）

- [ ] 租赁负债到期期限分析是否完整
- [ ] 本期利息费用是否单独披露
- [ ] 租赁现金流出总额是否披露
- [ ] 一年内到期是否单独列示
- [ ] 各项是否与审定表、明细勾稽

### 二、国有资产监管披露

- [ ] 租赁负债对负债规模和资产负债率的影响是否关注
- [ ] 售后租回融资是否披露合规性
- [ ] 重大租赁融资安排是否披露审批情况
- [ ] 中长期租赁偿债压力是否结合偿债能力分析

### 三、关联方租赁负债披露

- [ ] 与控股股东的租赁负债是否单独披露
- [ ] 与同受国有控制企业的租赁负债是否纳入披露
- [ ] 关联方租赁定价/折现率公允性是否披露
- [ ] 关联方租赁负债余额及未结算付款额是否披露

### 四、与上市版差异关注点

- [ ] 是否在基础披露上增加国资监管信息
- [ ] 关联方范围是否扩展至同受国有控制企业
- [ ] 融资合规性和负债率影响是否补充
- [ ] 是否与年度财务决算报表数据一致

## risk_areas

### 高风险

1. **售后租回融资规避审批**：以售后租回名义融资未履行审批程序或未披露。
2. **关联方租赁负债范围遗漏**：与同受国有控制企业的租赁负债未纳入关联方披露。
3. **到期分析缺失影响偿债评估**：未披露到期期限分析影响偿债能力评估。
4. **与决算不一致**：租赁负债数据与财务决算报表不勾稽。

### 中风险

1. **负债率影响未分析**：租赁负债对资产负债率影响未说明。
2. **关联方租赁定价存疑**：关联方租赁公允性披露不足。
3. **利息费用披露不足**：租赁负债利息未单独披露。

### 低风险

1. **决算模板差异**：附注格式与决算报表模板有细微差异。
2. **可比信息不足**：历史数据披露覆盖不足。
3. **文字说明简略**：融资合规性和偿债说明笼统。
