# H5-2 油气资产明细表 复核提示词

## 概述

本提示词针对油气资产明细表（H5-2）的复核，聚焦按矿区/油气井的原值、累计折耗、减值明细、增减变动及与审定表、增加检查、折耗测算的勾稽。

## tips

1. **明细合计=审定表**：各矿区/油气井明细合计须与H5-1审定表审定数一致。
2. **增加来源**：本期增加区分勘探资本化支出、开发井投入、矿区权益取得、弃置费用资本化（勾稽H5-7）。
3. **减少去向**：本期减少区分报废废弃井、矿区权益转让、油气井关停（勾稽H5-8）。
4. **折耗勾稽**：各资产本期折耗须与H5-12折耗测算一致，按产量法计提。
5. **弃置费用**：油气资产弃置费用现值应资本化计入原值，同时确认预计负债。
6. **成功井/失败井**：勘探井按成功努力法或全部成本法处理，方法须一贯。

## checklist

### 明细与增减
- [ ] 明细合计是否等于H5-1审定数
- [ ] 本期增加是否与H5-7增加检查勾稽
- [ ] 本期减少是否与H5-8减少检查勾稽
- [ ] 本期折耗是否与H5-12勾稽

### 专项处理
- [ ] 弃置费用是否资本化并确认预计负债
- [ ] 勘探井处理方法（成功努力/全部成本）是否一贯
- [ ] 减值（H5-14）是否反映

## risk_areas

### 高风险
1. **明细合计与审定表不符**：明细合计与审定表不符。
2. **失败勘探井资本化虚增资产**：失败勘探井资本化虚增资产。
3. **弃置费用未资本化**：弃置费用未资本化。

### 中风险
1. **折耗与H5-12不一致**：折耗与H5-12不一致。
2. **勘探井处理方法不一贯**：勘探井处理方法不一贯。

### 低风险
1. **矿区/井明细列示不清**：矿区/井明细列示不清。
2. **单据索引不完整**：单据索引不完整。
