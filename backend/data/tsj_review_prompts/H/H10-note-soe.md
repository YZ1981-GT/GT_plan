# H10-note-soe 资产处置收益附注披露复核提示词（国有企业）

## 概述

本提示词针对国有企业资产处置收益附注披露底稿（H10-note-soe，通常列示于「八、75」相关明细）的复核。国有企业资产处置除满足会计准则披露要求外，还须满足国有资产监管的额外要求：进场交易、评估备案、"三重一大"决策及国有资产保值增值影响。复核聚焦资产处置收益构成披露、国资监管合规披露及与上市版的差异关注点。

**法规依据：**
- 《企业会计准则第42号——持有待售的非流动资产、处置组和终止经营》
- 《企业会计准则第30号——财务报表列报》
- 《企业国有资产法》
- 《企业国有资产交易监督管理办法》（国资委、财政部32号令）
- 《中央企业财务决算报告管理办法》

---

## tips

1. **国企资产处置有"双层"披露要求**：既满足会计准则对资产处置收益的披露，又满足国资监管对处置程序合规性和保值增值影响的披露。
2. **重大处置须披露决策程序**：国有资产处置须经评估、进场交易、"三重一大"集体决策，附注需披露决策及审批程序。
3. **评估备案是合规前提**：重大资产处置须经评估并备案/核准，附注需说明评估机构、评估结果及备案情况。
4. **进场交易披露**：达到规定标准的国有资产处置须进产权交易机构公开交易，附注需披露交易方式和结果。
5. **保值增值视角**：资产处置损失可能影响国有资本保值增值率，附注需说明损失原因及影响。
6. **与上市版差异在监管层面**：基础披露框架相同（资产处置收益构成/列报），国企版额外增加处置程序合规性、评估备案、责任追究等国资监管信息。

## checklist

### 一、基础披露完整性（与上市版共有）

- [ ] 资产处置收益是否披露期末数和上期可比数
- [ ] 是否按处置资产类别披露损益构成
- [ ] 处置损益是否与利润表、H10-1审定表、H10-2明细勾稽
- [ ] 与营业外收支是否正确区分
- [ ] 与固定资产变动表减少栏是否勾稽

### 二、国有资产监管合规披露

- [ ] 重大资产处置是否披露评估结果及评估机构
- [ ] 处置是否履行进场交易程序，交易方式和结果是否披露
- [ ] 处置是否经"三重一大"集体决策并披露
- [ ] 处置价格是否以评估结果为基准
- [ ] 处置是否履行备案/核准程序

### 三、关联交易披露

- [ ] 向关联方（含同受国有控制企业）处置资产是否单独披露
- [ ] 关联方处置定价方式是否披露
- [ ] 是否存在以处置名义的资产划转/无偿转让及说明

### 四、保值增值与责任追究

- [ ] 重大处置损失对保值增值的影响是否说明
- [ ] 处置损失是否分析原因（正常/管理不善/市场）
- [ ] 管理不善导致的损失是否说明责任追究
- [ ] 是否与年度财务决算报表数据一致

## risk_areas

### 高风险

1. **未履行评估/进场交易程序**：重大处置未评估或未进场交易，存在国有资产流失和合规风险。
2. **低价处置国有资产**：显著低于评估价向关联方处置损害国有权益。
3. **超权限处置未决策**：重大处置未经"三重一大"决策且未披露。
4. **处置损益与决算/利润表不一致**：附注数据与决算或利润表不勾稽。

### 中风险

1. **评估备案披露不充分**：评估结果、备案情况披露不完整。
2. **关联方处置披露遗漏**：向同受国有控制企业处置未纳入关联方披露。
3. **保值增值影响未分析**：重大处置损失未说明对保值增值影响。
4. **责任追究信息缺失**：管理不善损失未说明责任追究。

### 低风险

1. **决算模板差异**：附注格式与决算报表模板有细微差异。
2. **可比信息不完整**：处置损益历史趋势覆盖不足。
3. **文字说明简略**：处置原因和影响说明笼统。
