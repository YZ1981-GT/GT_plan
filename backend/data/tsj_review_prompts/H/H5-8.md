# H5-8 油气资产减少检查 复核提示词

## 概述

本提示词针对油气资产减少检查表（H5-8）的复核，聚焦废弃油气井处置、矿区权益转让、弃置义务履行及处置收益计算。减少检查确认油气资产的正确结转与弃置处理。

## tips

1. **处置收益计算**：处置收益=处置价款−账面价值−弃置支出−税费，账面价值=原值−累计折耗−减值。
2. **废弃井弃置**：废弃油气井须履行弃置义务，实际弃置支出冲减弃置预计负债，差额计入损益。
3. **矿区权益转让**：矿区权益转让须核对转让合同、审批及价款到账。
4. **账面价值结转完整**：处置须同步结转原值、累计折耗、减值准备。
5. **弃置负债核对**：弃置义务履行与预计负债余额核对，超支/结余处理正确。
6. **关联转让公允**：关联方矿区权益转让价格公允性评估。

## checklist

### 处置与弃置
- [ ] 处置收益计算是否正确（含弃置支出）
- [ ] 废弃井弃置支出是否冲减弃置负债
- [ ] 原值/累计折耗/减值是否同步结转
- [ ] 弃置负债履行与余额是否核对

### 合规与勾稽
- [ ] 矿区权益转让是否有审批、价款到账
- [ ] 关联转让价格是否公允
- [ ] 本期减少是否与H5-2/H5-1勾稽

## risk_areas

### 高风险
1. **关联方低价转让矿区权益利益输送**：关联方低价转让矿区权益利益输送。
2. **弃置义务未履行或弃置负债处理错误**：弃置义务未履行或弃置负债处理错误。
3. **账面价值结转不完整**：账面价值结转不完整。

### 中风险
1. **处置收益计算错误**：处置收益计算错误。
2. **转让未审批**：转让未审批。

### 低风险
1. **处置单据索引不完整**：处置单据索引不完整。
2. **检查比例略低**：检查比例略低。
