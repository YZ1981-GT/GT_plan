# H7-9 生产性生物资产盘点检查表复核提示词

## 适用底稿
生产性生物资产盘点检查表（H7-9），聚焦盘点执行记录、账实核对、差异识别与处理、监盘证据充分性。

## 概述
H7-9 记录监盘执行过程和账实核对结果，是生物资产存在性的核心证据。复核须关注盘点记录的完整性、账实差异的识别与调查、监盘范围与计划的一致性及差异处理的恰当性。

---

## tips

1. **账实核对到品种/群体**：盘点数量须与H7-2明细账逐品种/群体核对，差异逐项列示并分析原因。
2. **差异调查须彻底**：账实差异（盘盈/盘亏）须查明原因（漏记增减、死亡未核销、点数误差、被盗私卖），重大差异须调整并追究。
3. **活体点数方法执行记录**：记录实际采用的点数/估算方法、抽样比例、影像/耳标核对情况。
4. **成熟度与健康状况观察**：记录观察到的成熟状态、健康状况、疫病迹象，为折旧和减值提供依据。
5. **监盘范围核对计划**：实际监盘地点/范围须与H7-8计划一致，未按计划执行须说明。
6. **盘点时点与滚存**：记录盘点时点，非资产负债表日盘点须记录滚存核对过程。

---

## checklist

### 一、盘点执行记录

- [ ] 盘点记录是否完整（时间/地点/人员/方法）
- [ ] 实际监盘范围是否与H7-8计划一致
- [ ] 采用的点数/估算方法是否记录且合理
- [ ] 耳标/芯片/批次标识核对是否记录
- [ ] 影像等辅助证据是否留存

### 二、账实核对

- [ ] 盘点数量是否与H7-2明细账逐品种核对
- [ ] 账实差异是否逐项列示
- [ ] 盘盈/盘亏金额是否计算正确
- [ ] 核对是否到成熟/未成熟分类层次

### 三、差异识别与处理

- [ ] 账实差异原因是否查明（漏记/未核销/误差/流失）
- [ ] 重大差异是否已提出调整建议
- [ ] 盘亏是否评估是否为资产流失/舞弊
- [ ] 差异处理是否有恰当审批

### 四、状态观察

- [ ] 成熟度观察是否记录并支持折旧判断
- [ ] 健康状况/疫病迹象是否记录并支持减值判断
- [ ] 是否发现闲置/无生产能力资产
- [ ] 观察结果是否与H7-10监盘小结衔接

## risk_areas

### 高风险

1. **重大盘亏未查明处理**：账实差异重大但未调查、未调整，可能掩盖资产流失或舞弊。
2. **账实核对流于形式**：盘点数量直接抄账面数，未真实核对。
3. **虚假盘点记录**：监盘未实际执行或记录造假。

### 中风险

1. **差异原因分析不足**：差异仅记录未深究原因。
2. **成熟度/健康观察缺失**：未记录支持折旧/减值的观察证据。
3. **点数方法误差大**：估算方法可靠性存疑。

### 低风险

1. **辅助证据留存不足**：影像/耳标核对记录不完整。
2. **盘点记录格式不规范**：记录要素不齐全。
