# H7-5 生产性生物资产分析表复核提示词

## 适用底稿
生产性生物资产分析表（H7-5），聚焦本期变动趋势分析、结构分析、周转与产出效率、异常波动识别及与业务经营的匹配性。

## 概述
H7-5 通过实质性分析程序评估生产性生物资产变动的合理性。复核须关注增减变动趋势、成熟/未成熟结构、单位产出效率及异常波动是否有合理解释，实质性分析结论是否有据。

---

## tips

1. **趋势分析对比历史**：本期生物资产原值/净值/数量较上期的变动，须与生产经营规模、产能扩张/收缩计划匹配，异常变动须查明原因。
2. **结构分析看成熟度**：成熟与未成熟生产性生物资产的比例结构，反映未来产能和折旧压力，结构突变须解释。
3. **产出效率验证合理性**：单位生物资产的产出（如产奶量、产果量）与账面价值的匹配性，效率异常低下可能预示减值。
4. **死亡率/淘汰率分析**：死亡率、淘汰率是否在正常区间，异常升高可能预示疫病、管理问题或虚假核销。
5. **变动率阈值预警**：变动率超过设定阈值（如30%）的项目须重点分析并附原因说明。
6. **分析须交叉验证**：分析结论须与H7-2明细、H7-6/H7-7增减检查、H7-9盘点结果交叉印证。

---

## checklist

### 一、变动趋势分析

- [ ] 生物资产原值/净值/数量较上期变动是否分析
- [ ] 重大变动（超阈值）是否附原因说明
- [ ] 变动是否与生产经营规模、产能计划匹配
- [ ] 增加/减少变动是否与H7-6/H7-7检查勾稽

### 二、结构与效率分析

- [ ] 成熟与未成熟结构比例是否分析
- [ ] 结构突变是否有合理解释
- [ ] 单位产出效率是否与账面价值匹配
- [ ] 效率异常项目是否评估减值可能

### 三、死亡淘汰分析

- [ ] 死亡率/淘汰率是否在正常区间
- [ ] 异常死亡/淘汰是否查明原因（疫病/灾害/管理）
- [ ] 死亡淘汰是否及时核销并与H7-7勾稽

### 四、分析结论

- [ ] 分析结论是否有充分数据支持
- [ ] 异常项目是否已延伸实施针对性程序
- [ ] 分析是否与明细、盘点、增减检查交叉验证
- [ ] 是否识别出需进一步关注的减值或核销事项

## risk_areas

### 高风险

1. **效率异常预示减值未识别**：产出效率显著下降但未评估减值。
2. **死亡率异常掩盖流失**：异常高死亡率可能掩盖资产被盗、私卖或虚假核销。
3. **变动与业务不匹配**：账面变动与实际生产规模严重背离未查明。

### 中风险

1. **异常波动无解释**：重大变动缺乏合理原因说明。
2. **分析深度不足**：仅列数据未做实质分析。
3. **结论无支持**：分析结论缺乏数据和交叉验证。

### 低风险

1. **对比维度单一**：仅对比金额未对比数量、效率等多维度。
2. **历史数据不足**：分析仅覆盖1期，趋势判断不充分。
