# H2-4 在建工程分析表 复核提示词

## 概述

本提示词针对在建工程分析表（H2-4）的复核，聚焦各工程项目余额变动分析、工程进度与投入匹配性、长期挂账工程识别及异常波动原因的充分性。分析程序识别停工、超概算与转固滞后风险。

## tips

1. **进度与投入匹配**：工程累计投入占概算比例应与实际形象进度匹配，投入远超进度提示成本失控或虚增。
2. **长期挂账识别**：连续多期无变动或达可使用状态未转固的工程须重点分析。
3. **变动率阈值**：工程余额变动超阈值须有原因分析。
4. **停工工程关注**：停工缓建工程须评估减值迹象（勾稽H2-15）。
5. **概算对比**：实际成本与批准概算对比，超概算须说明。
6. **与明细勾稽**：分析取数须与H2-2明细表一致。

## checklist

### 进度与变动
- [ ] 累计投入占概算比例是否与形象进度匹配
- [ ] 长期无变动/未转固工程是否识别
- [ ] 变动率超阈值是否有原因
- [ ] 停工缓建工程是否评估减值

### 勾稽
- [ ] 分析取数是否与H2-2一致
- [ ] 超概算是否说明
- [ ] 异常波动原因是否充分

## risk_areas

### 高风险
1. **长期挂账未转固工程未识别**：少提折旧。
2. **投入超进度提示成本虚增**：投入超进度提示成本虚增。

### 中风险
1. **停工工程减值未评估**：停工工程减值未评估。
2. **变动率超阈值缺原因**：变动率超阈值缺原因。

### 低风险
1. **概算对比缺失**：概算对比缺失。
2. **分析深度不足**：分析深度不足。
