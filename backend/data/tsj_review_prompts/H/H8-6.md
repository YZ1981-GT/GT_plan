# H8-6 使用权资产初始及后续计量表复核提示词

## 适用底稿
使用权资产初始及后续计量表（H8-6，按年/按月双分支），聚焦初始计量金额构成、租赁负债现值计算、折现率选取及后续计量（折旧+利息）的准确性。

## 概述
H8-6 是使用权资产和租赁负债初始及后续计量的核心测算底稿。复核须关注初始计量金额构成完整性、租赁付款额现值计算、折现率（增量借款利率或内含利率）选取合理性及后续期间使用权资产折旧与租赁负债利息的滚动计算。

---

## tips

1. **初始计量金额构成**：使用权资产=租赁负债初始计量+租赁期开始日或之前支付的租赁付款额（预付租金减租赁激励）+初始直接费用+复原成本估计；租赁负债=尚未支付的租赁付款额现值。
2. **折现率选取关键**：优先采用租赁内含利率（能确定时），无法确定时采用承租人增量借款利率，折现率高低直接影响现值，须核对取值依据。
3. **租赁付款额范围**：包括固定付款额、取决于指数/比率的可变付款额（按期初指数）、担保余值、购买选择权行权价（合理确定行使）、终止租赁罚款（租赁期反映行使终止权）。
4. **按年/按月分支**：现值计算的期间频率（按年/按月）须与实际付款频率一致，频率错误导致现值偏差。
5. **后续计量滚动**：使用权资产按折旧模式减少，租赁负债按实际利率法计息并扣减付款，两者后续独立计量。
6. **测算勾稽**：初始金额勾稽H8-1/H9初始确认，后续折旧勾稽H8-8，后续利息勾稽H9摊销表。

## checklist

### 一、初始计量金额构成

- [ ] 使用权资产初始成本构成是否完整
- [ ] 租赁负债初始计量=未付租赁付款额现值是否正确
- [ ] 预付租金、租赁激励、初始直接费用、复原成本是否恰当处理
- [ ] 初始金额是否勾稽H8-1、H9初始确认

### 二、现值计算与折现率

- [ ] 折现率选取（内含利率/增量借款利率）是否恰当
- [ ] 折现率取值是否有依据（同期限同担保借款利率）
- [ ] 租赁付款额范围是否完整（固定/可变/担保余值/购买权/罚款）
- [ ] 现值计算的期间频率（按年/按月）是否与付款频率一致
- [ ] 现值计算公式和折现期间是否正确

### 三、后续计量

- [ ] 使用权资产后续折旧计算是否正确（勾稽H8-8）
- [ ] 租赁负债后续利息（实际利率法）是否正确（勾稽H9摊销表）
- [ ] 可变租金（不计入负债的）是否计入当期损益
- [ ] 后续期间滚动计算是否连续无断裂

### 四、勾稽与复核

- [ ] 测算结果是否与H8-1、H8-2、H9勾稽
- [ ] 按年/按月分支选择是否与实际租赁一致
- [ ] 是否复核测算模型逻辑正确性

## risk_areas

### 高风险

1. **折现率操纵**：采用过高折现率低估租赁负债和使用权资产（表外融资倾向），折现率无依据。
2. **租赁付款额范围错误**：遗漏担保余值、购买选择权行权价或错误纳入不应计入的可变付款额。
3. **现值计算频率错误**：按年/按月频率与实际付款不一致导致现值系统性偏差。

### 中风险

1. **初始成本构成不完整**：遗漏初始直接费用或复原成本。
2. **后续计量断裂**：使用权资产折旧或租赁负债利息滚动计算不连续。
3. **可变租金处理错误**：应计入损益的可变租金错误资本化。

### 低风险

1. **测算模型文档不足**：折现率依据和参数记录不完整。
2. **分支选择说明不足**：按年/按月分支选择未说明。
