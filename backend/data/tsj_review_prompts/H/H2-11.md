# H2-11 在建工程利息资本化（有专门借款） 复核提示词

## 概述

本提示词针对在建工程利息资本化测算表（有专门借款，H2-11）的复核，聚焦专门借款利息资本化金额、闲置资金投资收益冲减、专门借款+一般借款组合资本化及与借款费用的勾稽。有专门借款时优先按专门借款计算。

## tips

1. **专门借款优先**：专门借款资本化金额=专门借款当期实际利息−闲置资金存款收益/投资收益。
2. **闲置资金冲减**：专门借款尚未动用资金的存款利息或投资收益须冲减资本化金额，不得漏冲。
3. **组合资本化**：专门借款不足部分动用一般借款的，一般借款部分按资本化率计算叠加。
4. **资本化期间**：三条件同时满足方可资本化，达到预定可使用状态即停止。
5. **中断暂停**：非正常中断超3个月暂停资本化。
6. **与借款勾稽**：专门借款本金/利息与借款底稿（L1/L3/L4）勾稽，闲置资金收益与投资收益勾稽。

## checklist

### 专门借款计算
- [ ] 专门借款利息资本化金额计算是否正确
- [ ] 闲置资金收益是否冲减资本化金额
- [ ] 专门借款不足部分一般借款叠加是否正确
- [ ] 资本化率（一般借款部分）是否准确

### 期间与勾稽
- [ ] 资本化期间三条件是否满足、达状态即停
- [ ] 非正常中断超3个月是否暂停
- [ ] 专门借款本息是否与L类借款勾稽
- [ ] 资本化利息是否计入H2-1/H2-2

## risk_areas

### 高风险
1. **闲置资金收益未冲减**：虚增资本化利息。
2. **达可使用状态后继续资本化**：达可使用状态后继续资本化。

### 中风险
1. **组合资本化计算错误**：组合资本化计算错误。
2. **中断未暂停资本化**：中断未暂停资本化。

### 低风险
1. **专门借款与借款底稿索引不全**：专门借款与借款底稿索引不全。
2. **测算记录不完整**：测算记录不完整。
