# H4-1 工程物资审定表 复核提示词

## 概述

本提示词针对工程物资审定表（H4-1）的复核，聚焦期初期末勾稽、与试算平衡表（1605工程物资）核对、领用转在建工程的准确性及减值列报。工程物资是为在建工程准备的专项材料与设备，其领用与在建工程（H2）密切勾稽。

## tips

1. **期初期末勾稽**：期末=期初+本期购入−本期领用（转在建工程/固定资产）−本期减少，勾稽须成立。
2. **领用勾稽H2**：本期领用转在建工程金额须与H2在建工程增加中的设备/材料投入勾稽。
3. **试算平衡表核对**：审定合计须与TB 1605一致。
4. **期初承前**：期初审定数须等于上年期末审定数。
5. **减值列报**：工程物资减值准备须单独列示（长期积压/毁损/规格过时物资减值）。
6. **调整完整**：AJE/RJE须完整反映且平衡。

## checklist

### 勾稽与核对
- [ ] 期末=期初+购入−领用−减少是否成立
- [ ] 本期领用是否与H2在建工程投入勾稽
- [ ] 审定合计是否与TB 1605一致
- [ ] 期初审定数是否等于上年期末

### 调整与列报
- [ ] AJE/RJE是否完整反映且平衡
- [ ] 减值准备是否与H4-7勾稽
- [ ] 长期积压物资是否评估减值

## risk_areas

### 高风险
1. **领用与在建工程投入不勾稽**：成本归集失真。
2. **审定合计与TB不符**：审定合计与TB不符。
3. **期初审定数与上年期末不一致**：期初审定数与上年期末不一致。

### 中风险
1. **长期积压物资减值遗漏**：长期积压物资减值遗漏。
2. **调整不完整**：调整不完整。

### 低风险
1. **减值列示不清**：减值列示不清。
2. **交叉索引不完整**：交叉索引不完整。
