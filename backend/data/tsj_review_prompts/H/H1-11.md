# H1-11 固定资产监盘小结 复核提示词

## 概述

本提示词针对固定资产监盘小结（H1-11）的复核，聚焦监盘结论的充分性、差异汇总与后续处理、存在性与完整性结论的支撑及对减值/报废迹象的评价。监盘小结是监盘程序的总结性底稿。

## tips

1. **结论有支撑**：存在性/完整性结论须以H1-9计划和H1-10盘点结果为依据，不得空泛。
2. **差异汇总完整**：盘盈盘亏差异汇总须与盘点检查表一致，处理建议明确。
3. **迹象评价**：监盘中发现的闲置、老旧、毁损资产须评价减值/报废迹象并联动相关底稿。
4. **抽样评价**：抽样监盘结果推断总体，评价是否需扩大样本。
5. **替代程序结论**：异地/未盘资产替代程序的有效性结论须明确。
6. **未决事项跟进**：监盘中未解决的差异或疑问须列示跟进计划。

## checklist

### 结论与差异
- [ ] 存在性/完整性结论是否有H1-9/H1-10支撑
- [ ] 差异汇总是否与盘点检查表一致
- [ ] 差异处理建议是否明确
- [ ] 抽样结果推断总体是否合理

### 迹象与跟进
- [ ] 闲置/老旧/毁损资产减值报废迹象是否评价
- [ ] 替代程序有效性结论是否明确
- [ ] 未决事项跟进计划是否列示

## risk_areas

### 高风险
1. **结论无支撑或与盘点结果矛盾**：结论无支撑或与盘点结果矛盾。
2. **重大差异未评价对报表影响**：重大差异未评价对报表影响。

### 中风险
1. **减值/报废迹象未评价**：减值/报废迹象未评价。
2. **抽样评价不充分未扩样**：抽样评价不充分未扩样。

### 低风险
1. **未决事项跟进不明确**：未决事项跟进不明确。
2. **小结格式不规范**：小结格式不规范。
