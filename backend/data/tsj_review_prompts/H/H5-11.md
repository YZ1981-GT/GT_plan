# H5-11 油气资产监盘小结 复核提示词

## 概述

本提示词针对油气资产监盘小结（H5-11）的复核，聚焦监盘结论支撑、存在性与运行状态结论、储量数据评价及对停产/待弃置井减值迹象的评价。

## tips

1. **结论有支撑**：存在性/运行状态结论须以H5-9计划和H5-10盘点结果为依据。
2. **储量评价**：评价储量数据来源可靠性及对折耗/减值的影响。
3. **减值迹象**：停产、待弃置、储量枯竭井须评价减值迹象（联动H5-14）。
4. **弃置义务评价**：待弃置井弃置义务与弃置费用充足性评价。
5. **抽样评价**：抽样结果推断总体，评价是否需扩样。
6. **未决事项跟进**：未解决差异或疑问列示跟进。

## checklist

### 结论与储量
- [ ] 存在性/运行状态结论是否有支撑
- [ ] 储量数据来源可靠性是否评价
- [ ] 储量对折耗/减值影响是否评价

### 迹象与跟进
- [ ] 停产/待弃置/储量枯竭井减值迹象是否评价
- [ ] 弃置义务充足性是否评价
- [ ] 抽样评价是否合理
- [ ] 未决事项跟进是否列示

## risk_areas

1. **结论无支撑或与盘点矛盾**：结论无支撑或与盘点矛盾。
2. **储量枯竭减值迹象未评价**：储量枯竭减值迹象未评价。

### 中风险
