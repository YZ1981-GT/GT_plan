# H6-note-soe 固定资产清理附注披露复核提示词（国有企业）

## 概述

本提示词针对国有企业财务报表中与固定资产清理及资产处置相关的附注披露复核（H6-note-soe）。国有企业资产处置除满足会计准则披露要求外，还须满足国有资产监管的额外要求，包括进场交易、评估备案、"三重一大"决策及国有资产保值增值影响披露。复核聚焦资产处置收益披露、国资监管合规披露及与上市版的差异关注点。

**法规依据：**
- 《企业会计准则第4号——固定资产》
- 《企业会计准则第42号——持有待售的非流动资产、处置组和终止经营》
- 《企业国有资产法》
- 《企业国有资产交易监督管理办法》（国资委、财政部32号令）
- 《中央企业财务决算报告管理办法》

## tips

1. **国企资产处置有"双层"披露要求**：既满足会计准则对资产处置收益的披露，又满足国资监管对处置程序合规性和保值增值影响的披露。
2. **重大处置须披露决策程序**：国有资产处置须经评估、进场交易、"三重一大"集体决策，附注需披露决策及审批程序合规情况。
3. **评估备案是国企处置的合规前提**：重大资产处置须经评估并备案/核准，附注需说明评估机构、评估结果及备案情况。
4. **进场交易披露**：达到规定标准的国有资产处置须进产权交易机构公开交易，附注需披露交易方式和结果。
5. **保值增值视角**：资产处置损失可能影响国有资本保值增值率，附注需说明处置损失的原因及对保值增值的影响。
6. **与上市版差异主要在监管层面**：基础披露框架相同（资产处置收益/营业外收支），国企版额外增加处置程序合规性、评估备案、责任追究等国资监管信息。

## checklist

### 一、基础披露完整性（与上市版共有）

- [ ] 资产处置收益/损失是否披露期末数和上期可比数
- [ ] 是否按处置资产类别披露损益构成
- [ ] 处置损益是否与利润表、H10审定表、H6-2明细勾稽
- [ ] 报废毁损净损失是否恰当披露于营业外支出
- [ ] 与固定资产变动表减少栏是否勾稽一致

### 二、国有资产监管合规披露

- [ ] 重大资产处置是否披露评估结果及评估机构
- [ ] 处置是否履行进场交易程序，交易方式和结果是否披露
- [ ] 处置是否经"三重一大"集体决策，决策程序是否披露
- [ ] 处置价格是否以评估结果为基准，低于评估价的是否说明
- [ ] 国有资产处置是否履行备案/核准程序

### 三、关联交易与资金占用披露

- [ ] 向关联方（含同受国有控制企业）处置资产是否单独披露
- [ ] 关联方处置定价方式是否披露（市场价/协议价/评估价）
- [ ] 是否存在以处置名义进行资产划转/无偿转让的情况及说明
- [ ] 处置对价的回收情况是否披露（有无形成关联方应收款项）

### 四、保值增值与责任追究

- [ ] 重大处置损失对国有资本保值增值的影响是否说明
- [ ] 处置损失是否分析原因（正常经营/管理不善/市场因素）
- [ ] 因管理不善导致的处置损失是否说明责任追究情况
- [ ] 是否与年度财务决算报表的资产处置数据一致

## risk_areas

### 高风险

1. **未履行评估/进场交易程序**：重大国有资产处置未评估或未进场公开交易，存在国有资产流失和合规风险。
2. **低价处置国有资产**：处置价格显著低于评估价向关联方或特定对象处置，损害国有权益。
3. **超权限处置未经集体决策**：重大处置未经"三重一大"决策即执行且未披露。
4. **处置损益与决算/利润表不一致**：附注数据与财务决算报表或利润表不勾稽。

### 中风险

1. **评估备案披露不充分**：评估结果、备案情况披露不完整。
2. **关联方处置披露遗漏**：向同受国有控制企业处置资产未纳入关联方披露。
3. **保值增值影响未分析**：重大处置损失未说明对保值增值率的影响。
4. **责任追究信息缺失**：管理不善导致的处置损失未说明责任追究情况。

### 低风险

1. **决算模板差异**：附注格式与国资委决算报表模板有细微差异。
2. **可比信息不完整**：处置损益历史趋势分析覆盖年度不足。
3. **文字说明简略**：处置原因和影响说明过于笼统。
