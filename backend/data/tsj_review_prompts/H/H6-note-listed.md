# H6-note-listed 固定资产清理附注披露复核提示词（上市公司）

## 概述

本提示词针对上市公司财务报表中与固定资产清理及资产处置相关的附注披露复核（H6-note-listed）。固定资产清理为过渡性科目，期末通常无余额，其影响主要体现在利润表「资产处置收益」及「营业外收入/支出」项目。复核聚焦资产处置收益的构成披露、重大处置事项披露、报废毁损损失披露及与固定资产附注的勾稽一致性。

**法规依据：**
- 《企业会计准则第4号——固定资产》
- 《企业会计准则第42号——持有待售的非流动资产、处置组和终止经营》
- 《企业会计准则第30号——财务报表列报》
- 《公开发行证券的公司信息披露编报规则第15号——财务报告的一般规定》

---

## tips

1. **清理科目本身通常无余额需披露**：固定资产清理为过渡科目期末应为零，附注披露重点在其结转形成的资产处置收益及营业外收支，而非科目余额本身。
2. **资产处置收益须披露构成明细**：附注须列示资产处置收益/损失的形成来源（固定资产处置/无形资产处置/在建工程处置等），并区分处置方式。
3. **重大处置事项须单独披露**：单项金额重大或对经营有重大影响的资产处置，须披露标的、对价、损益及对财务状况的影响。
4. **报废毁损损失列报于营业外支出**：非正常原因的固定资产报废/毁损净损失应披露于营业外支出，与正常处置的资产处置收益区分。
5. **与固定资产附注勾稽**：处置形成的固定资产原值/累计折旧减少额须与固定资产变动表的减少栏勾稽一致。
6. **持有待售须专项披露**：若存在拟处置资产符合持有待售条件，须按CAS42披露分类、计量（孰低）及预计处置安排。

## checklist

### 一、资产处置收益披露

- [ ] 是否披露资产处置收益/损失的期末数和上期可比数
- [ ] 是否按处置资产类别披露损益构成（固定资产/无形资产/在建工程等）
- [ ] 资产处置收益金额是否与利润表相应项目一致
- [ ] 是否与H10审定表、清理明细（H6-2）净损益勾稽
- [ ] 处置方式（出售/转让/对外投资）是否有必要说明

### 二、重大处置事项披露

- [ ] 单项重大资产处置是否披露标的、对价及损益
- [ ] 关联方处置是否在关联交易附注中披露
- [ ] 重大处置对经营的影响是否有定性说明
- [ ] 是否披露处置的商业实质和定价依据

### 三、报废毁损与营业外收支

- [ ] 非正常报废/毁损净损失是否列报于营业外支出并披露
- [ ] 保险赔偿/责任人赔偿是否在营业外收入中恰当披露
- [ ] 报废毁损事项是否说明原因和金额
- [ ] 营业外收支中处置相关项目是否与清理台账勾稽

### 四、勾稽与持有待售

- [ ] 处置减少的固定资产原值/折旧是否与固定资产变动表勾稽
- [ ] 是否存在拟处置资产符合持有待售条件的专项披露（CAS42）
- [ ] 持有待售资产是否按账面价值与公允价值减处置费用孰低披露
- [ ] 附注披露口径是否与审定表、明细表一致

## risk_areas

### 高风险

1. **处置损益披露与利润表不一致**：附注披露的资产处置收益与利润表/审定表金额不符，属重大披露错误。
2. **重大处置事项漏披露**：单项重大处置未在附注单独披露，影响报表使用者判断。
3. **报废损失归类披露错误**：非正常报废损失错披露于资产处置收益而非营业外支出。
4. **持有待售未按CAS42披露**：拟处置资产符合条件却未重分类和孰低计量披露。

### 中风险

1. **处置损益构成披露不完整**：仅披露净额未按资产类别或处置方式细分。
2. **关联方处置披露不充分**：关联方处置的定价公允性未在附注说明。
3. **与固定资产变动表不勾稽**：处置减少额与固定资产附注减少栏存在差异。

### 低风险

1. **可比信息缺失**：附注仅披露本期数未列示上期可比数。
2. **文字说明模板化**：处置事项说明过于笼统未结合具体情况。
3. **披露格式不规范**：金额单位、表格列序等细节问题。
