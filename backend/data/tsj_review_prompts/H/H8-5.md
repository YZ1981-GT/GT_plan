# H8-5 租赁期的确定检查表复核提示词

## 适用底稿
租赁期的确定检查表（H8-5，段落型），聚焦不可撤销期间、续租/终止选择权的评估、重大事件对租赁期重估的影响及租赁期判断的合理性。

## 概述
H8-5 确定租赁期，直接影响使用权资产折旧年限和租赁负债计量金额。复核须关注不可撤销期间、续租/终止选择权行使可能性的评估（合理确定）、重大事件触发的重估及租赁期判断的一贯性。

---

## tips

1. **租赁期=不可撤销期间+合理确定行使的选择权期间**：租赁期包括不可撤销期间，加上合理确定将行使续租选择权的期间和合理确定不行使终止选择权的期间。
2. **续租选择权评估**：合理确定将续租的，续租期计入租赁期；判断须考虑经济激励（租金优惠、租赁改良、迁移成本、业务重要性等）。
3. **终止选择权评估**：合理确定不行使终止权的，相应期间计入租赁期；反之则缩短租赁期。
4. **重大事件重估**：发生重大事件或情况变化且在承租人可控范围内、影响选择权评估的，须重估租赁期（如购置重大租赁改良、业务决策变化）。
5. **租赁期影响多处**：租赁期决定使用权资产折旧年限（孰短判断）和租赁负债现值计算期间，判断错误双重影响。
6. **一贯性与文档**：租赁期判断须一贯并有充分文档支持，避免为调节资产/负债金额操纵租赁期。

## checklist

### 一、不可撤销期间

- [ ] 不可撤销期间是否根据合同条款正确确定
- [ ] 是否正确处理不可撤销期间内的免租期

### 二、选择权评估

- [ ] 续租选择权行使可能性是否评估（合理确定）
- [ ] 续租评估是否考虑经济激励因素
- [ ] 终止选择权是否评估（合理确定不行使则计入）
- [ ] 选择权评估结论是否有支持性分析
- [ ] 无固定期限租赁的租赁期判断是否合理

### 三、重大事件重估

- [ ] 是否识别触发租赁期重估的重大事件
- [ ] 重估是否及时且在承租人可控范围内的事件才重估
- [ ] 重估对使用权资产和租赁负债的影响是否处理
- [ ] 重估是否与H8-7租赁变更区分

### 四、影响与勾稽

- [ ] 租赁期是否用于H8-6使用权资产折旧年限判断
- [ ] 租赁期是否用于H9租赁负债现值计算期间
- [ ] 租赁期判断是否一贯
- [ ] ≤12个月是否衔接短期租赁豁免（H8-13）

## risk_areas

### 高风险

1. **租赁期操纵调节金额**：人为缩短/延长租赁期调节使用权资产和租赁负债金额及折旧。
2. **续租期评估不当**：合理确定续租却未计入租赁期，低估资产负债（表外融资倾向）。
3. **重大事件重估遗漏**：应重估租赁期的事件未触发重估。

### 中风险

1. **选择权评估依据不足**：续租/终止评估缺乏经济激励分析。
2. **免租期处理错误**：免租期对租赁期或租金计算处理不当。
3. **租赁期不一贯**：类似租赁租赁期判断不一致。

### 低风险

1. **判断文档不足**：租赁期判断缺乏充分文档。
2. **无固定期限处理说明不足**：无固定期限租赁的期间判断说明不充分。
