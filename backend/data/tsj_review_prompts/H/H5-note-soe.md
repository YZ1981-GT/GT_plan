# H5-note-soe 油气资产附注披露 复核提示词（国有企业）

## 概述

本提示词针对油气资产国有企业附注披露底稿的复核，在满足会计准则通用披露（变动表/折耗政策/储量/弃置/受限）基础上，聚焦国资监管相关披露：矿业权取得处置合规性、重大油气投资决策、储量资产保值增值及国有油气资源管理。

## tips

1. **双层披露**：既满足CAS通用披露，又满足国资委财务决算额外要求。
2. **变动表勾稽**：变动表、折耗政策、储量信息须完整并与审定表勾稽（与上市版共有）。
3. **矿业权合规**：矿业权取得/转让须披露审批程序（"三重一大"）与合规性。
4. **重大投资决策**：重大油气勘探开发投资须披露决策程序与批复。
5. **储量资产管理**：探明储量作为国有资源资产的管理与保值增值情况须说明。
6. **弃置义务合规**：油气弃置义务履行与环保合规须说明。

## checklist

### 基础披露（与上市版共有）
- [ ] 四栏变动表是否完整并与审定表勾稽
- [ ] 折耗方法/储量口径是否披露
- [ ] 探明储量变动是否披露
- [ ] 弃置义务/受限资产是否披露

### 国资监管专项
- [ ] 矿业权取得/转让是否披露审批与合规性
- [ ] 重大油气投资是否披露决策程序
- [ ] 储量资产保值增值是否说明
- [ ] 数据是否与年度财务决算一致

## risk_areas

### 高风险
1. **矿业权取得/转让缺合规性与决策说明**：矿业权取得/转让缺合规性与决策说明。
2. **附注与审定表不勾稽**：附注与审定表不勾稽。
3. **弃置义务未披露**：弃置义务未披露。

### 中风险
1. **重大投资决策程序缺失**：重大投资决策程序缺失。
2. **储量资产管理说明不足**：储量资产管理说明不足。

### 低风险
1. **披露格式未按决算模板**：披露格式未按决算模板。
2. **保值增值影响说明简略**：保值增值影响说明简略。
