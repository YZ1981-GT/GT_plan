# H8-note-soe 使用权资产附注披露复核提示词（国有企业）

## 概述

本提示词针对国有企业使用权资产附注披露底稿（H8-note-soe）的复核。国有企业除满足CAS21承租人披露要求外，还须关注国有资产管理相关披露：租赁资产的合规审批、与关联方（含同受国有控制企业）的租赁安排及与上市版的差异关注点。

**法规依据：**
- 《企业会计准则第21号——租赁》
- 《企业会计准则第30号——财务报表列报》
- 《企业国有资产法》
- 《中央企业财务决算报告管理办法》

---

## tips

1. **国企使用权资产有"双层"披露要求**：既满足CAS21承租人披露，又满足国资监管对重大租赁合规性和关联方租赁的披露。
2. **重大租赁审批合规披露**：国有企业重大租赁安排须经恰当审批，附注需关注重大租赁的合规性说明。
3. **关联方租赁范围更广**：与控股股东及同受国有控制企业的租赁须纳入关联方披露。
4. **与决算口径一致**：使用权资产及租赁负债数据须与财务决算报表口径一致。
5. **售后租回特别关注**：国企售后租回可能涉及国有资产处置，须关注是否履行评估和处置程序及披露。
6. **与上市版差异在监管层面**：基础披露框架相同（变动/折旧减值/简化处理/现金流出），国企版额外增加租赁合规性、关联方租赁等国资监管信息。

## checklist

### 一、基础披露完整性（与上市版共有）

- [ ] 使用权资产按类别变动表是否完整
- [ ] 折旧/减值披露是否完整
- [ ] 短期/低价值简化处理及租金是否披露
- [ ] 租赁现金流出总额是否披露
- [ ] 变动表各项是否与审定表、明细勾稽

### 二、国有资产监管披露

- [ ] 重大租赁安排的合规性是否说明
- [ ] 涉及售后租回的是否披露评估和处置程序
- [ ] 租赁付款对国有资本运营的影响是否说明
- [ ] 重大租赁承诺是否披露

### 三、关联方租赁披露

- [ ] 与控股股东的租赁是否单独披露
- [ ] 与同受国有控制企业的租赁是否纳入披露
- [ ] 关联方租金定价方式是否披露
- [ ] 关联方租赁的商业合理性是否说明

### 四、与上市版差异关注点

- [ ] 是否在基础披露上增加国资监管信息
- [ ] 关联方范围是否扩展至同受国有控制企业
- [ ] 重大租赁合规性说明是否补充
- [ ] 是否与年度财务决算报表数据一致

## risk_areas

### 高风险

1. **售后租回规避处置程序**：以售后租回名义处置国有资产未履行评估/处置程序。
2. **关联方租赁范围遗漏**：与同受国有控制企业的租赁未纳入关联方披露。
3. **变动表与决算不一致**：使用权资产/租赁负债数据与财务决算不勾稽。
4. **重大租赁未审批未披露**：重大租赁安排未经审批或合规性未披露。

### 中风险

1. **关联方租赁定价存疑**：关联方租金公允性披露不足。
2. **售后租回披露不充分**：售后租回的会计处理和处置程序披露不完整。
3. **简化处理披露掩盖表外**：大量简化处理租赁未充分披露。

### 低风险

1. **决算模板差异**：附注格式与决算报表模板有细微差异。
2. **可比信息不足**：历史数据披露覆盖不足。
3. **文字说明简略**：租赁合规性和管理措施说明笼统。
