# H4-6 工程物资盘点检查 复核提示词

## 概述

本提示词针对工程物资盘点检查表（H4-6）的复核，聚焦盘点执行完整性、账实核对差异、物资状态记录及存在性确认。盘点检查是工程物资存在性核心证据。

## tips

1. **账实核对**：记录账面数、实物数、差异数，逐项核对，差异查明原因。
2. **盘盈盘亏处理**：盘盈盘亏经批准后调整，盘亏追究责任。
3. **状态记录**：记录物资状态（完好/毁损/积压/过时），联动减值。
4. **规格型号核对**：核对物资规格型号与账面一致，防止以次充好。
5. **异地物资替代**：异地物资替代程序结果记录。
6. **差异闭环**：盘点差异通过H4-3调整闭环。

## checklist

### 账实核对
- [ ] 是否记录账面数/实物数/差异数并核对
- [ ] 盘盈盘亏是否查明原因处理
- [ ] 物资状态是否记录
- [ ] 规格型号是否核对一致

### 差异与衔接
- [ ] 盘亏是否经批准并追究责任
- [ ] 异地物资替代程序结果是否记录
- [ ] 差异是否通过H4-3闭环

## risk_areas

### 高风险
1. **账实差异重大未查明**：物资不存在风险。
2. **盘亏未处理长期挂账**：盘亏未处理长期挂账。

### 中风险
1. **物资状态未记录减值漏识别**：物资状态未记录减值漏识别。
2. **差异未闭环**：差异未闭环。

### 低风险
1. **规格核对不完整**：规格核对不完整。
2. **盘点记录不规范**：盘点记录不规范。
