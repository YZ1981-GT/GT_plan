# H8-note-listed 使用权资产附注披露复核提示词（上市公司）

## 概述

本提示词针对上市公司使用权资产附注披露底稿（H8-note-listed）的复核。聚焦使用权资产按类别的变动表披露、折旧与减值披露、短期/低价值租赁简化处理披露、租赁现金流出总额及CAS21要求的承租人租赁特有披露事项，并关注与租赁负债（H9）披露的联动一致性。

**法规依据：**
- 《企业会计准则第21号——租赁》（承租人披露要求）
- 《企业会计准则第30号——财务报表列报》
- 《公开发行证券的公司信息披露编报规则第15号——财务报告的一般规定》

---

## tips

1. **使用权资产按标的类别披露变动**：须按租赁资产类别（房屋建筑物/机器设备/运输工具等）披露原值、累计折旧、减值准备的期初、增减、期末变动。
2. **折旧与减值披露**：本期计提折旧、累计折旧、本期减值损失及累计减值准备须披露。
3. **简化处理披露**：短期租赁和低价值资产租赁的简化处理及计入当期损益的租金费用须披露。
4. **租赁现金流出总额**：须披露本期租赁的现金流出总额（含使用权资产租赁付款+简化处理租金+可变租金）。
5. **与租赁负债联动**：使用权资产披露须与租赁负债（H9）披露及现金流量表筹资活动租赁付款勾稽。
6. **重要租赁与承诺**：重大租赁安排、售后租回、转租及尚未开始的重大租赁承诺须披露。

## checklist

### 一、使用权资产变动披露

- [ ] 是否按标的资产类别披露使用权资产变动表
- [ ] 原值/累计折旧/减值准备变动是否完整
- [ ] 变动表各项是否与H8-1审定表、H8-2明细勾稽
- [ ] 期末账面价值是否与资产负债表列报一致
- [ ] 是否列示上期可比数据

### 二、折旧减值与损益披露

- [ ] 本期计提折旧金额是否披露
- [ ] 本期减值损失及累计减值准备是否披露
- [ ] 折旧/减值是否与利润表相关项目勾稽
- [ ] 减值不得转回是否体现

### 三、简化处理与现金流出

- [ ] 短期租赁简化处理及租金费用是否披露
- [ ] 低价值资产租赁简化处理及租金费用是否披露
- [ ] 本期租赁现金流出总额是否披露
- [ ] 可变租金费用是否披露

### 四、特殊事项与联动

- [ ] 重大租赁安排是否披露
- [ ] 售后租回/转租事项是否披露
- [ ] 尚未开始的重大租赁承诺是否披露
- [ ] 使用权资产披露是否与H9租赁负债披露联动一致
- [ ] 附注披露口径是否与审定表、明细表一致

## risk_areas

### 高风险

1. **变动表不勾稽**：使用权资产变动表与审定表/明细不一致或勾稽关系不成立。
2. **简化处理披露掩盖表外融资**：大量租赁通过简化处理表外化却未充分披露。
3. **减值披露缺失**：本期计提重大减值却未披露原因和金额。
4. **与租赁负债披露不联动**：使用权资产与租赁负债披露口径不一致。

### 中风险

1. **类别划分不完整**：未按标的资产类别披露变动。
2. **现金流出总额缺失**：未披露租赁现金流出总额。
3. **重大租赁承诺漏披露**：尚未开始的重大租赁未披露。

### 低风险

1. **可比信息缺失**：仅披露本期数未列上期可比数。
2. **文字披露模板化**：租赁政策描述笼统。
3. **格式不规范**：金额单位、表格列序等细节问题。
