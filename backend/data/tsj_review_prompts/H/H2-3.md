# H2-3 在建工程调整分录 复核提示词

## 概述

本提示词针对在建工程调整分录汇总表（H2-3）的复核，含账项调整、重分类调整及未调整错报评估。复核须验证调整有证据、借贷平衡、完整反映到H2-1审定表并同步试算平衡表。

## tips

1. **常见调整**：延迟转固补记（补提折旧）、资本化利息更正、费用化支出误计入工程的更正、工程物资重分类。
2. **与H2-1勾稽**：审定表调整列须与H2-3已确认分录逐笔一致。
3. **延迟转固调整**：达可使用状态未转固的须补作转固并补提折旧，是常见AJE。
4. **TB回写**：确认调整同步TB 1604/1605，避免双真源。
5. **SUD累计**：未调整错报与A13交叉验证。
6. **审批链**：超重要性调整须合伙人审批留痕。

## checklist

### 高风险检查项
- [ ] 每笔AJE是否有证据（转固检查/成本核对/利息测算）
- [ ] 调整分录借贷是否平衡
- [ ] 调整是否完整反映到H2-1
- [ ] 延迟转固补记是否同时补提折旧

### 中风险检查项
- [ ] RJE是否仅涉及列报（工程物资重分类）
- [ ] 与A13未调整错报索引是否完整
- [ ] 跨期调整是否区分本期/前期

### 低风险检查项
- [ ] 摘要、科目编码是否规范
- [ ] 编号连续、无重号风险

## risk_areas

### 高风险
1. **调整缺证据或未授权**：调整缺证据或未授权。
2. **延迟转固未补提折旧**：延迟转固未补提折旧。

### 中风险
1. **RJE误含损益**：RJE误含损益。
2. **TB未同步**：TB未同步。

### 低风险
