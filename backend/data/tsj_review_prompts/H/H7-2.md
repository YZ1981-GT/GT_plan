# H7-2 生产性生物资产明细表复核提示词

## 概述

本提示词针对生产性生物资产明细表（H7-2，成本/公允双版本）的复核。该表按品种/群体逐项登记生产性生物资产的数量、原值/公允价值、累计折旧、减值准备及净额的期初、增减、期末变动，是H7-1审定表的数据来源。复核聚焦台账完整性、数量与金额勾稽、增减变动真实性及成熟状态标注。

**法规依据：**
- 《企业会计准则第5号——生物资产》
- 《企业会计准则第8号——资产减值》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **数量与金额双维度核对**：生物资产明细须同时登记数量（头/株/亩）和金额，数量变动与金额变动应逻辑一致，繁殖增加、死亡减少须有数量支持。
2. **成熟状态逐项标注**：每一群体/品种须标注成熟或未成熟，成熟状态直接决定是否计提折旧（成本模式）。
3. **增减变动须有原始记录**：外购（合同/发票）、自繁自育（繁殖记录）、出售（销售记录）、死亡淘汰（死亡/淘汰记录）等增减须有实物台账支持。
4. **公允价值模式须逐项估值**：公允模式下每项资产的公允价值须有活跃市场报价或估值依据，估值日恰当。
5. **明细合计回勾H7-1**：各品种数量、原值/公允价值、累计折旧、减值、净额合计须与H7-1审定表对应行一致。
6. **关注自然损耗与灾害损失**：因疫病、自然灾害导致的生物资产损失须及时核销并有相关证明，警惕虚报损失掩盖资产流失。

## checklist

### 一、台账完整性

- [ ] 明细表是否覆盖全部生产性生物资产品种/群体
- [ ] 每项是否登记数量、原值/公允价值、成熟状态
- [ ] 期初数量/金额是否与上年期末一致
- [ ] 明细各列合计是否与H7-1审定表勾稽
- [ ] 是否与实物盘点（H7-9）结果核对一致

### 二、数量与金额勾稽

- [ ] 本期增加数量是否有外购/繁殖记录支持
- [ ] 本期减少数量是否有出售/死亡/淘汰记录支持
- [ ] 数量变动与金额变动是否逻辑一致
- [ ] 期末数量×单位成本/公允价值是否与账面金额匹配
- [ ] 单位价值是否在合理区间（对比市场价/历史成本）

### 三、成熟状态与折旧/公允

- [ ] 成熟与未成熟生产性生物资产是否逐项正确标注
- [ ] （成本模式）成熟资产是否计提折旧，未成熟未提
- [ ] （成本模式）累计折旧、减值准备是否逐项与测算表勾稽
- [ ] （公允模式）各项公允价值是否有估值依据且估值日恰当
- [ ] 未成熟转成熟的时点判断是否恰当

### 四、增减变动真实性

- [ ] 外购增加是否有合同、发票、验收记录
- [ ] 自繁自育增加成本归集是否准确（饲料/人工/防疫等）
- [ ] 出售减少是否与销售收入、H7-7减少检查勾稽
- [ ] 死亡/淘汰损失是否有鉴定/核销证明
- [ ] 是否存在账面存在但实物已死亡的情况

## risk_areas

### 高风险

1. **虚增数量/金额**：账面登记的生物资产数量或价值超过实际，虚增资产。
2. **死亡淘汰不核销**：生物资产已死亡淘汰但明细账未减少，账实不符掩盖损失。
3. **公允价值高估**：公允模式下缺乏可靠估值依据而高估公允价值，虚增资产利润。
4. **自繁成本归集不实**：将无关成本挤入自繁生物资产成本，虚增资产价值。

### 中风险

1. **数量金额不勾稽**：数量变动与金额变动逻辑不一致。
2. **成熟状态标注错误**：影响折旧计提的正确性。
3. **单位价值异常**：单位成本/公允价值显著偏离市场水平未说明。
4. **与盘点结果不符**：明细账与实物盘点存在差异未调节。

### 低风险

1. **品种归集过粗**：未按品种/群体细分，影响分析。
2. **原始记录索引不全**：增减变动未附完整原始记录索引。
3. **格式不规范**：明细列示或单位标注不统一。
