# H5-14 油气资产减值测算 复核提示词

## 概述

本提示词针对油气资产减值测算表（H5-14）的复核，聚焦减值迹象识别（油气价格下跌/储量下调/停产废弃）、可收回金额确定、减值损失计算及减值不可转回原则。油气资产减值受油气价格与储量双重影响。

## tips

1. **减值迹象**：油气价格持续大幅下跌、探明储量下调、井停产废弃、开采成本上升致经济性下降等须评估。
2. **可收回金额**：可收回金额=公允价值减处置费用与预计未来现金流量现值较高者（勾稽H5-15）。
3. **现金流基于储量**：使用价值现金流以探明储量、预计产量、油气价格预测为基础，须合理有据。
4. **减值损失**：减值损失=账面价值−可收回金额，计入资产减值损失。
5. **减值不可转回**：油气资产减值损失一经确认不得转回（CAS8）。
6. **资产组认定**：油气资产以矿区或油气田为资产组认定，减值分摊合理。

## checklist

### 迹象与计算
- [ ] 减值迹象是否逐项评估（价格/储量/停产/经济性）
- [ ] 可收回金额是否取较高者（勾稽H5-15）
- [ ] 现金流是否基于储量/产量/价格预测且有据
- [ ] 减值损失计算是否正确

### 原则与联动
- [ ] 是否存在减值转回（应无）
- [ ] 资产组（矿区/油气田）认定分摊是否合理
- [ ] 减值是否计入H5-1减值准备
- [ ] 减值后折耗是否联动H5-12重算

## risk_areas

### 高风险
1. **油价大跌/储量下调减值迹象明显未计提**：油价大跌/储量下调减值迹象明显未计提。
2. **油气资产减值损失被转回**：油气资产减值损失被转回。
3. **现金流价格/产量假设主观高估规避减值**：现金流价格/产量假设主观高估规避减值。

### 中风险

2. **减值后折耗未重算**：减值后折耗未重算。
