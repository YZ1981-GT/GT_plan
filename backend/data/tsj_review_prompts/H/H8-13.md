# H8-13 简化处理的租赁检查表复核提示词

## 适用底稿
简化处理的租赁检查表（H8-13），聚焦短期租赁和低价值资产租赁豁免适用的恰当性、简化处理的会计核算及租金费用的确认。

## 概述
H8-13 检查采用简化处理（不确认使用权资产和租赁负债）的短期租赁和低价值资产租赁。复核须关注豁免适用条件的判断、租金费用的确认方式及是否存在通过简化处理规避表内确认的情况。

---

## tips

1. **短期租赁条件**：租赁期≤12个月且不包含购买选择权，须核对租赁期判断（含续租选择权评估），有购买选择权则不适用。
2. **低价值资产条件**：单项资产在全新时价值较低（实务参考≤4万元或3.5万元人民币），须核对价值判断；已转租的低价值资产不适用豁免。
3. **简化处理核算**：短期/低价值租赁的租金在租赁期内按直线法或其他系统合理方法计入相关成本费用，不确认使用权资产和负债。
4. **防止滥用豁免**：警惕将本应表内确认的租赁人为拆分为多个短期租赁，或错误归类为低价值资产规避确认。
5. **豁免一贯性**：短期租赁豁免按标的资产类别选择适用，低价值租赁可逐项选择，须一贯。
6. **费用勾稽**：简化处理的租金费用须与相关成本费用科目、H8-14关联交易（如涉及）勾稽。

## checklist

### 一、短期租赁豁免

- [ ] 短期租赁租赁期是否≤12个月
- [ ] 是否不含购买选择权（有则不适用）
- [ ] 租赁期判断是否考虑续租选择权
- [ ] 是否存在拆分租赁规避表内确认

### 二、低价值资产豁免

- [ ] 低价值判断是否恰当（全新时价值较低）
- [ ] 是否已转租（转租则不适用豁免）
- [ ] 低价值判断标准是否一贯
- [ ] 是否将高价值资产错误归类为低价值

### 三、简化处理核算

- [ ] 租金费用是否按直线法或系统合理方法确认
- [ ] 租金费用列报科目是否恰当
- [ ] 是否未确认使用权资产和租赁负债
- [ ] 可变租金是否恰当计入损益

### 四、勾稽与列报

- [ ] 简化处理租金是否与相关成本费用科目勾稽
- [ ] 豁免适用是否一贯
- [ ] 简化处理租赁是否在附注恰当披露
- [ ] 是否与H8-4租赁识别的豁免判断一致

## risk_areas

### 高风险

1. **滥用豁免规避确认**：将应表内确认的租赁拆分或错误归类为短期/低价值租赁规避资产负债确认（表外融资）。
2. **短期租赁含购买权**：含购买选择权仍按短期租赁简化处理，判断错误。
3. **低价值判断错误**：高价值资产错误适用低价值豁免。

### 中风险

1. **租金费用确认方式错误**：未按直线法或系统方法确认租金。
2. **续租评估不足**：短期租赁未充分评估续租可能。
3. **转租低价值适用豁免**：已转租的低价值资产错误适用豁免。

### 低风险

1. **披露不充分**：简化处理租赁在附注披露不完整。
2. **豁免依据文档不足**：豁免适用判断依据记录不足。
