# H3-note-soe 投资性房地产附注披露 复核提示词（国有企业）

## 概述

本提示词针对投资性房地产国有企业附注披露底稿的复核，在满足会计准则通用披露（计量模式/变动表/公允价值层次/受限/租金）基础上，聚焦国资监管相关披露：国有物业出租经营合规性、大额物业处置决策、公允价值评估合规性及国有资产保值增值。

## tips

1. **双层披露**：既满足CAS通用披露，又满足国资委财务决算额外要求。
2. **变动表勾稽**：计量模式、变动表须完整并与审定表勾稽（与上市版共有）。
3. **出租经营合规**：国有物业出租须披露定价方式（市场化/协议）与合规性。
4. **大额处置决策**：大额物业处置须披露"三重一大"决策程序与评估。
5. **公允价值评估合规**：公允价值模式的评估机构资质、评估合规性须说明。
6. **保值增值**：投资性房地产收益及公允价值变动对保值增值影响须说明。

## checklist

### 基础披露（与上市版共有）
- [ ] 计量模式是否披露
- [ ] 变动表是否完整并与审定表勾稽
- [ ] 公允价值层次是否披露（公允价值模式）
- [ ] 受限物业/租金收入是否披露

### 国资监管专项
- [ ] 国有物业出租定价合规性是否披露
- [ ] 大额处置是否披露决策程序与评估
- [ ] 公允价值评估机构资质是否说明
- [ ] 数据是否与年度财务决算一致
