# H8-4 租赁的识别检查表复核提示词

## 适用底稿
租赁的识别检查表（H8-4，段落型），聚焦合同是否包含租赁的判断、已识别资产、控制使用权的判断、租赁与非租赁部分的分拆与合并及短期/低价值豁免。

## 概述
H8-4 是承租人租赁会计的起点，判断合同是否为租赁或包含租赁。复核须关注三要素判断（已识别资产、经济利益、主导使用权）的充分性、租赁与非租赁部分的分拆及豁免适用的恰当性，识别错误将导致租赁确认范围错误。

---

## tips

1. **租赁识别三要素**：合同为租赁须同时满足①存在已识别资产（物理可区分或供应方无实质替换权）②承租人有权获得几乎全部经济利益③承租人有权主导资产使用，三要素缺一不为租赁。
2. **已识别资产判断**：资产须物理可区分且供应方无实质替换权，供应方有实质替换权则不构成已识别资产。
3. **主导使用权判断**：承租人有权决定资产在使用期间的使用方式（如何、何种目的），是控制权的核心。
4. **分拆与合并**：一份合同含多个租赁或租赁与非租赁部分（如租赁+服务），须按单独价格比例分拆；关联的多份合同可能须合并作为一份处理。
5. **短期租赁豁免**：租赁期≤12个月且不含购买选择权的可简化处理，须核对租赁期判断（含续租选择权评估）。
6. **低价值资产豁免**：单项资产全新时价值较低（如≤4万元）的可简化处理，须核对价值判断和转租情况。

## checklist

### 一、租赁识别三要素

- [ ] 是否判断存在已识别资产（物理可区分/无实质替换权）
- [ ] 供应方是否有实质性替换权（有则不构成租赁）
- [ ] 承租人是否有权获得几乎全部经济利益
- [ ] 承租人是否有权主导资产使用方式
- [ ] 三要素判断是否有合同条款支持

### 二、分拆与合并

- [ ] 含多个租赁的合同是否恰当分拆
- [ ] 租赁与非租赁部分（服务）是否按单独价格分拆
- [ ] 承租人是否选择不分拆的简化处理（如选择）
- [ ] 关联多份合同是否评估是否需合并

### 三、豁免适用

- [ ] 短期租赁（≤12个月无购买权）判断是否恰当
- [ ] 租赁期判断是否考虑续租/终止选择权
- [ ] 低价值资产豁免的价值判断是否恰当
- [ ] 低价值资产是否已转租（转租则不适用豁免）
- [ ] 豁免适用是否一贯且有合理依据

### 四、识别结论

- [ ] 识别为租赁的合同是否进入后续计量（H8-5~H8-6）
- [ ] 识别结论是否与H8-6计量、H9租赁负债范围一致
- [ ] 否定判断（非租赁）是否有充分依据
- [ ] 识别底稿是否与合同清单交叉核对

## risk_areas

### 高风险

1. **应识别为租赁未识别**：将实质为租赁的合同判断为服务或采购，规避使用权资产和租赁负债确认（表外融资）。
2. **滥用短期/低价值豁免**：人为拆分或错误判断规避租赁准则表内确认。
3. **控制权判断错误**：主导使用权判断错误导致租赁识别范围系统性错误。

### 中风险

1. **分拆合并处理不当**：租赁与非租赁部分未恰当分拆导致租赁负债金额错误。
2. **续租选择权评估不足**：短期租赁判断未充分评估续租可能。
3. **已识别资产判断粗糙**：替换权评估不充分。

### 低风险

1. **识别依据文档不足**：三要素判断缺乏合同条款引用。
2. **豁免依据记录不全**：豁免适用未记录判断依据。
