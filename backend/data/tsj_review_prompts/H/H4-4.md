# H4-4 工程物资增加检查 复核提示词

## 概述

本提示词针对工程物资增加检查表（H4-4）的复核，聚焦本期购入工程物资的取得成本准确性、采购真实性、抽凭充分性及关联采购公允性。增加检查确认工程物资的合规入账。

## tips

1. **取得成本完整**：外购工程物资成本含买价、运输、装卸等，不含可抵扣增值税。
2. **采购真实性**：核对采购合同、发票、入库单、付款凭证，防止虚增采购。
3. **抽凭覆盖大额**：大额购入须抽凭核对，检查比例达标。
4. **预付设备款**：预付大型设备款须核对合同约定与付款进度。
5. **关联采购公允**：关联方供应工程物资价格公允性评估。
6. **入库验收**：物资入库验收记录核对，防止账实不符。

## checklist

### 成本与真实性
- [ ] 取得成本构成是否完整准确
- [ ] 采购是否核对合同/发票/入库单/付款
- [ ] 预付设备款是否核对合同/进度
- [ ] 入库验收记录是否核对

### 抽凭与勾稽
- [ ] 大额购入抽凭比例是否达标
- [ ] 本期增加是否与H4-2/H4-1勾稽
- [ ] 关联采购价格是否公允

## risk_areas

### 高风险
1. **虚增采购或虚增取得成本**：虚增采购或虚增取得成本。
2. **关联方采购价格不公允**：关联方采购价格不公允。

### 中风险
1. **预付设备款进度不符**：预付设备款进度不符。
2. **入库验收不到位账实不符**：入库验收不到位账实不符。

### 低风险
1. **抽凭比例略低**：抽凭比例略低。
2. **单据索引不完整**：单据索引不完整。
