# H7-note-soe 生产性生物资产附注披露复核提示词（国有企业）

## 概述

本提示词针对国有企业生产性生物资产附注披露底稿（H7-note-soe）的复核。国有企业（尤其农林牧渔类国企）生物资产除满足CAS5披露要求外，还须满足国有资产监管相关披露：国有农业资产保值增值、生物资产损失责任、财政补贴相关生物资产及与上市版的差异关注点。

**法规依据：**
- 《企业会计准则第5号——生物资产》
- 《企业会计准则第8号——资产减值》
- 《企业国有资产法》
- 《中央企业财务决算报告管理办法》
- 《公开发行证券的公司信息披露编报规则第15号——财务报告的一般规定》

---

## tips

1. **国企生物资产有"双层"披露要求**：既满足CAS5通用披露，又满足国资监管对农业资产保值增值和损失管理的披露要求。
2. **重大损失须披露责任情况**：因疫病、灾害、管理不善导致的重大生物资产损失，须披露损失原因及责任追究情况。
3. **财政补贴相关披露**：涉及财政补贴（良种补贴/养殖补贴等）形成或相关的生物资产，须披露补贴情况和会计处理。
4. **保值增值视角**：生物资产减值/损失对国有资本保值增值的影响须说明。
5. **计量模式与决算一致**：国企计量模式选择须与财务决算口径一致，公允价值模式须审慎适用。
6. **与上市版差异在监管层面**：基础披露框架相同（分类/变动/折旧减值），国企版额外增加损失责任、财政补贴、保值增值等国资监管信息。

## checklist

### 一、基础披露完整性（与上市版共有）

- [ ] 计量模式及采用依据是否披露
- [ ] 生产性/消耗性、成熟/未成熟是否分类披露
- [ ] 原值/折旧/减值（或公允价值）变动表是否完整
- [ ] 实物数量信息是否披露
- [ ] 各分类合计是否与审定表勾稽

### 二、国有资产监管披露

- [ ] 重大生物资产损失（疫病/灾害）是否披露原因和金额
- [ ] 因管理不善导致的损失是否说明责任追究情况
- [ ] 生物资产减值对保值增值的影响是否说明
- [ ] 大额生物资产处置是否按国资要求披露

### 三、财政补贴相关披露

- [ ] 涉及财政补贴的生物资产是否披露补贴情况
- [ ] 补贴的会计处理（政府补助）是否恰当披露
- [ ] 补贴形成资产的权属是否清晰

### 四、与上市版差异关注点

- [ ] 是否在基础披露上增加国资监管信息
- [ ] 重大损失责任追究信息是否补充
- [ ] 保值增值影响分析是否补充
- [ ] 是否与年度财务决算报表数据一致

## risk_areas

### 高风险

1. **重大损失掩盖流失**：疫病/灾害/被盗损失未如实披露，掩盖国有资产流失。
2. **损失责任追究缺失**：管理不善损失未说明责任追究，不符合国有资产损失责任追究制度。
3. **变动表与决算不一致**：附注数据与财务决算报表不勾稽。
4. **公允价值模式滥用**：不满足条件采用公允价值虚增农业资产。

### 中风险

1. **财政补贴披露不充分**：补贴相关生物资产会计处理披露不完整。
2. **保值增值影响未分析**：重大减值/损失未说明对保值增值的影响。
3. **成熟/未成熟未区分**：影响折旧信息完整性。

### 低风险

1. **决算模板差异**：附注格式与决算报表模板有细微差异。
2. **可比信息不足**：历史趋势分析覆盖年度不足。
3. **文字说明简略**：损失原因和管理措施说明笼统。
