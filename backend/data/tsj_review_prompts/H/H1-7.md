# H1-7 固定资产增加检查 复核提示词

## 概述

本提示词针对固定资产增加检查表（H1-7）的复核，聚焦本期新增固定资产的取得成本准确性、资本化时点与范围、在建工程转固及时性、抽凭充分性。取得成本错误直接影响后续折旧与减值。

## tips

1. **取得成本完整**：外购固定资产成本含买价、进口关税、运输安装、达到预定可使用状态前的必要支出，不含可抵扣增值税。
2. **资本化范围准确**：区分资本化支出与费用化支出，日常修理费应费用化，改良支出方可资本化。
3. **在建工程转固及时**：达到预定可使用状态即应转固并开始折旧，不得以未办竣工决算为由长期挂账在建工程。
4. **抽凭覆盖大额**：大额新增须核对购货合同、发票、验收单、付款凭证，检查比例达标。
5. **资本化利息核对**：符合条件的借款费用资本化须与H2利息资本化勾稽，不得重复或超额。
6. **关联采购公允**：向关联方购置固定资产须评估价格公允性。

## checklist

### 取得成本与资本化
- [ ] 取得成本构成是否完整准确（含必要支出、不含可抵扣税）
- [ ] 资本化与费用化划分是否正确
- [ ] 在建工程转入是否及时（达到预定可使用状态）且与H2勾稽
- [ ] 资本化利息是否有据且不重复

### 抽凭与勾稽
- [ ] 大额新增是否核对合同/发票/验收单/付款凭证
- [ ] 检查比例是否达到计划水平
- [ ] 本期增加合计是否与H1-2明细表一致
- [ ] 关联方采购价格是否公允

## risk_areas

### 高风险
1. **费用化支出误资本化**：虚增资产、虚增利润。
2. **在建工程达可使用状态未及时转固**：少提折旧。
3. **虚构购建业务或虚增取得成本**：虚构购建业务或虚增取得成本。

### 中风险
1. **资本化利息重复或超额**：资本化利息重复或超额。
2. **关联方采购价格不公允**：关联方采购价格不公允。

### 低风险
1. **检查比例略低于计划**：检查比例略低于计划。
2. **单据索引不完整**：单据索引不完整。
