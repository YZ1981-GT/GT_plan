# H1-note-soe 固定资产附注披露 复核提示词（国有企业）

## 概述

本提示词针对固定资产国有企业附注披露底稿的复核，在满足会计准则通用披露（变动表/分类/折旧政策/受限资产）基础上，聚焦国资监管相关披露：国有资产受限与处置、大额资产处置的"三重一大"决策、闲置及待报废资产的处置计划、国有资本保值增值相关影响。

## tips

1. **双层披露**：既满足CAS通用披露，又满足国资委财务决算报告额外要求，两套互补不可替代。
2. **变动表勾稽**：四栏变动表须完整并与审定表勾稽（与上市版共有基础要求）。
3. **国有资产受限**：抵押、查封、划转的固定资产须逐项披露，涉及国有资产处置须说明审批。
4. **三重一大**：大额固定资产处置须经集体决策程序，披露决策过程与评估情况。
5. **闲置待报废处置**：长期闲置、待报废固定资产须披露处置计划与责任追究情况。
6. **保值增值影响**：固定资产减值损失对国有资本保值增值率的影响须说明。

## checklist

### 基础披露（与上市版共有）
- [ ] 四栏变动表是否完整并与审定表勾稽
- [ ] 是否按类别披露且合计等于审定数
- [ ] 折旧政策是否披露且与H1-5一致
- [ ] 受限资产账面价值及原因是否披露

### 国资监管专项
- [ ] 大额资产处置是否经"三重一大"并披露
- [ ] 国有资产划转/受限是否逐项披露审批
- [ ] 长期闲置/待报废资产处置计划是否披露
- [ ] 减值对国有资本保值增值影响是否说明
- [ ] 数据是否与年度财务决算报表一致

## risk_areas

### 高风险
1. **大额资产处置缺"三重一大"决策说明**：大额资产处置缺"三重一大"决策说明。
2. **国有资产受限/划转未披露**：国有资产受限/划转未披露。
3. **变动表与审定表不勾稽**：变动表与审定表不勾稽。

### 中风险
1. **闲置/待报废资产处置计划缺失**：闲置/待报废资产处置计划缺失。
2. **决算数据与审计数据差异未调节**：决算数据与审计数据差异未调节。

### 低风险
1. **披露格式未完全按决算模板**：披露格式未完全按决算模板。
2. **保值增值影响说明简略**：保值增值影响说明简略。
