# H7-12 生产性生物资产折旧分配表复核提示词

## 适用底稿
生产性生物资产折旧分配表（H7-12，仅成本模式），聚焦折旧费用去向分配的合理性、分配标准一贯性及与成本/费用科目的勾稽。

## 概述
H7-12 将H7-11测算的折旧费用分配至相关成本或费用科目（如生产成本、管理费用）。复核须关注分配去向的恰当性、分配标准的合理一贯及分配金额与折旧测算、成本费用科目的勾稽。

---

## tips

1. **分配去向须与资产用途匹配**：用于农业生产的生产性生物资产折旧计入相关产品成本，管理用途计入管理费用，分配去向须与实际用途匹配。
2. **分配标准合理一贯**：按受益对象/工时/产量等标准分配，标准须合理且前后期一贯。
3. **折旧总额勾稽H7-11**：分配的折旧总额须等于H7-11测算的折旧总额，不得多分或漏分。
4. **计入产品成本的折旧结转**：计入生产成本的折旧最终随产品成本结转，须关注是否恰当结转至存货/主营业务成本。
5. **资本化vs费用化**：折旧原则费用化，特殊情形（如培育其他生物资产）资本化须有依据。
6. **分配勾稽成本费用科目**：分配金额须与生产成本、管理费用等科目发生额勾稽。

---

## checklist

### 一、分配去向

- [ ] 折旧分配去向是否与资产实际用途匹配
- [ ] 生产用途是否计入相关产品成本
- [ ] 管理用途是否计入管理费用
- [ ] 是否存在应费用化却资本化的折旧

### 二、分配标准

- [ ] 分配标准是否合理（受益对象/工时/产量）
- [ ] 分配标准是否前后期一贯
- [ ] 多用途资产折旧分摊是否有据

### 三、金额勾稽

- [ ] 分配折旧总额是否等于H7-11测算总额
- [ ] 分配金额是否与生产成本、管理费用科目勾稽
- [ ] 计入产品成本的折旧是否恰当结转
- [ ] 无多分、漏分、重复分配

### 四、列报影响

- [ ] 折旧分配对损益的影响是否恰当
- [ ] 期末在产品/产成品中的折旧是否合理
- [ ] 分配结果是否与H7-1审定表勾稽

## risk_areas

### 高风险

1. **折旧资本化虚增利润**：将应费用化的折旧计入存货或其他资产，递延费用虚增利润。
2. **分配总额不符**：分配折旧与H7-11测算不一致，存在多分/漏分。

### 中风险

1. **分配去向错误**：折旧去向与资产用途不匹配。
2. **分配标准不一贯**：随意变更分配标准调节各科目费用。
3. **产品成本折旧未结转**：计入生产成本的折旧长期挂账不结转。

### 低风险

1. **分配明细不清**：分配去向明细列示不完整。
2. **分配依据文档不足**：分配标准缺乏文档说明。
