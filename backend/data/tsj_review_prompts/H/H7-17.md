# H7-17 生产性生物资产关联交易检查表复核提示词

## 适用底稿
生产性生物资产关联交易检查表（H7-17），聚焦涉及生物资产的关联方交易识别、定价公允性、交易实质及披露完整性。

## 概述
H7-17 检查涉及生产性生物资产的关联方交易（购买/出售/租赁/托管等）。复核须关注关联方及关联交易的完整识别、交易定价的公允性、交易的商业实质及关联交易披露是否符合CAS36。

---

## tips

1. **关联方识别完整**：涉及生物资产购销、代养代管、场地租赁等的关联方须完整识别，特别关注未披露关联方通过生物资产交易输送利益。
2. **定价公允性核查**：关联方购销生物资产的价格须与市场公允价格对比，显著偏离须查明原因和商业合理性。
3. **交易实质判断**：关注是否存在以生物资产交易名义进行的资金占用、利益输送或虚增收入/成本。
4. **代养代管风险**：委托关联方代养生物资产的，须关注资产存在性、权属清晰性及代养费公允性。
5. **披露完整性**：关联方生物资产交易须按CAS36披露关联方关系、交易内容、金额、定价政策及未结算余额。
6. **交叉验证**：关联交易须与H7-6增加检查、H7-7减少检查、B19关联方清单交叉验证。

---

## checklist

### 一、关联方识别

- [ ] 涉及生物资产的关联方交易是否完整识别
- [ ] 是否核对B19关联方清单确保无遗漏
- [ ] 是否关注隐性关联方（代养/托管方）
- [ ] 交易对手是否存在实质关联关系但未披露

### 二、定价公允性

- [ ] 关联方购销价格是否与市场公允价对比
- [ ] 显著偏离是否查明原因和商业合理性
- [ ] 定价政策是否披露（市场价/协议价）
- [ ] 是否存在通过定价输送利益

### 三、交易实质

- [ ] 是否存在以交易名义的资金占用
- [ ] 代养代管资产存在性和权属是否清晰
- [ ] 代养费/管护费是否公允
- [ ] 交易是否有真实商业实质

### 四、披露

- [ ] 关联方关系、交易内容、金额是否完整披露
- [ ] 未结算余额及坏账准备是否披露
- [ ] 关联交易是否与H7-6/H7-7、审定表勾稽
- [ ] 披露是否符合CAS36要求

## risk_areas

### 高风险

1. **关联方利益输送**：通过关联方生物资产购销的不公允定价输送利益。
2. **虚构关联交易**：虚构生物资产购销虚增收入或转移资产。
3. **代养资产虚假**：委托关联方代养的生物资产实际不存在或权属不清。

### 中风险

1. **定价公允性存疑**：关联方交易价格偏离市场但未充分说明。
2. **隐性关联方未识别**：代养/托管等隐性关联关系未识别披露。
3. **资金占用挂账**：以生物资产交易名义形成关联方资金占用。

### 低风险

1. **披露不完整**：关联交易定价政策或未结算余额披露不全。
2. **交叉索引缺失**：关联交易未与增减检查、B19建立索引。
