# H8-7 租赁变更检查表复核提示词

## 适用底稿
租赁变更检查表（H8-7），聚焦租赁变更的识别、变更是否作为单独租赁、租赁负债重新计量及使用权资产相应调整的准确性。

## 概述
H8-7 检查租赁变更的会计处理。复核须关注租赁变更（范围/对价/期限变化）的识别、是否符合作为单独租赁的条件、租赁负债按修订后付款额和折现率重新计量及使用权资产相应调整。

---

## tips

1. **租赁变更定义**：租赁变更指原合同条款之外的租赁范围、租赁对价或租赁期限的变更（如增减租赁面积、调整租金、延长/缩短期限）。
2. **作为单独租赁的条件**：变更同时满足①扩大租赁范围（增加一项或多项资产使用权）②对价增加额与扩大范围的单独价格相当，则作为单独租赁处理，不重新计量原租赁。
3. **不作为单独租赁的处理**：不满足单独租赁条件的，按变更生效日修订后的租赁付款额和折现率重新计量租赁负债，并调整使用权资产账面价值。
4. **缩小范围的特殊处理**：变更缩小租赁范围的，按比例减记使用权资产和租赁负债，差额计入当期损益。
5. **折现率更新**：不作为单独租赁的变更须采用变更生效日的修订折现率重新计量。
6. **变更勾稽多表**：变更对使用权资产（H8-1/H8-2）、租赁负债（H9）、折旧（H8-8）均有影响，须联动勾稽。

## checklist

### 一、变更识别

- [ ] 是否识别本期发生的全部租赁变更
- [ ] 变更类型是否明确（范围/对价/期限）
- [ ] 变更是否与H8-5租赁期重估区分

### 二、单独租赁判断

- [ ] 是否判断变更是否作为单独租赁
- [ ] 作为单独租赁的两个条件是否同时满足
- [ ] 作为单独租赁的是否单独确认新使用权资产和负债

### 三、重新计量

- [ ] 不作为单独租赁的是否按修订付款额重新计量负债
- [ ] 是否采用变更生效日的修订折现率
- [ ] 使用权资产是否相应调整
- [ ] 缩小范围的是否按比例减记并将差额计入损益

### 四、勾稽与列报

- [ ] 变更对使用权资产、租赁负债的影响是否联动勾稽
- [ ] 变更后折旧是否相应调整（H8-8）
- [ ] 变更是否与H8-3/H9-4调整分录勾稽
- [ ] 变更损益是否恰当列报

## risk_areas

### 高风险

1. **变更未重新计量**：租赁变更发生但未按修订条款重新计量负债和资产，账面失真。
2. **单独租赁判断错误**：错误判断为单独租赁规避原租赁重新计量。
3. **缩小范围损益错误**：缩小范围的比例减记和损益确认错误。

### 中风险

1. **折现率未更新**：重新计量未采用变更日修订折现率。
2. **使用权资产调整遗漏**：负债重新计量但使用权资产未相应调整。
3. **变更与重估混淆**：租赁变更与租赁期重估处理混淆。

### 低风险

1. **变更识别不及时**：变更未在发生当期及时处理。
2. **变更文档不足**：变更条款和处理依据记录不完整。
