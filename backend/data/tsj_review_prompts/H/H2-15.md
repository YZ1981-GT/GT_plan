# H2-15 在建工程减值测算 复核提示词

## 概述

本提示词针对在建工程减值测算表（H2-15）的复核，聚焦减值迹象识别（停工/技术过时/预期无法完工或使用）、可收回金额确定、减值损失计算及减值不可转回原则。在建工程减值常见于停工缓建项目。

## tips

1. **减值迹象**：长期停工、无复工计划、技术方案落后、预期建成后无法产生经济利益等须评估。
2. **可收回金额**：可收回金额=公允价值减处置费用与预计未来现金流量现值较高者（勾稽H2-16）。
3. **减值损失**：减值损失=账面价值−可收回金额，计入资产减值损失。
4. **减值不可转回**：在建工程减值损失一经确认不得转回（CAS8）。
5. **停工工程重点**：停工缓建工程是减值高发区，须逐项评估。
6. **转固后接续**：减值后转固的固定资产以减值后价值为基础计提折旧。

## checklist

### 迹象与计算
- [ ] 减值迹象是否逐项评估（停工/过时/无法完工）
- [ ] 可收回金额是否取公允净额与现值较高
- [ ] 减值损失计算是否正确
- [ ] 停工工程是否重点评估

### 原则与联动
- [ ] 是否存在减值转回（应无）
- [ ] 减值是否计入H2-1减值准备
- [ ] 可收回金额是否与H2-16勾稽
