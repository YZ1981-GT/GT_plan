# H1-4 固定资产闲置检查 复核提示词

## 概述

本提示词针对固定资产闲置检查表（H1-4）的复核，聚焦闲置资产的识别完整性、闲置原因合理性、减值迹象评估及是否需转入待处置资产或计提减值。闲置资产是减值迹象的重要来源。

## tips

1. **闲置识别完整**：长期停用、超产能闲置、季节性停用须逐项识别，避免漏报导致减值迹象未评估。
2. **闲置≠停止折旧**：处于闲置状态的固定资产除持有待售外仍应计提折旧（CAS4），不得以闲置为由停提。
3. **减值联动**：识别的闲置资产须触发H1-14减值测算，评估可收回金额是否低于账面价值。
4. **闲置原因分类**：技术淘汰、产能过剩、临时停产、待报废等原因决定后续处置方向。
5. **超期闲置预警**：闲置超过一定期限（如1年）且无复用计划的资产应重点评估减值或报废。
6. **与分析表联动**：闲置资产变动应与H1-6分析表异常波动交叉印证。

## checklist

### 闲置识别与折旧
- [ ] 闲置资产清单是否完整（结合现场监盘、产能数据）
- [ ] 闲置资产是否仍正常计提折旧（非持有待售）
- [ ] 是否存在以闲置为由停提折旧的情况
- [ ] 闲置原因是否逐项说明且合理

### 减值与处置
- [ ] 识别的闲置资产是否触发减值测算（H1-14）
- [ ] 长期闲置无复用计划资产是否评估报废/处置
- [ ] 待处置资产是否正确重分类
- [ ] 闲置资产减值是否已计入减值准备

## risk_areas

### 高风险
1. **闲置资产减值迹象未评估**：资产虚增。
2. **以闲置为由停止计提折旧**：少计费用。
3. **长期闲置资产隐瞒未报**：长期闲置资产隐瞒未报。

### 中风险
1. **闲置原因说明不充分**：闲置原因说明不充分。
2. **待处置资产未及时重分类**：待处置资产未及时重分类。

### 低风险
1. **闲置清单格式不规范**：闲置清单格式不规范。
2. **与监盘底稿索引不完整**：与监盘底稿索引不完整。
