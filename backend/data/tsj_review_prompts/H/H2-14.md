# H2-14 在建工程监盘小结 复核提示词

## 概述

本提示词针对在建工程监盘小结（H2-14）的复核，聚焦监盘结论支撑、进度与投入匹配评价、存在性结论及对转固滞后/停工减值迹象的评价。监盘小结总结现场查看程序。

## tips

1. **结论有支撑**：存在性/进度真实性结论须以H2-12计划和H2-13盘点结果为依据。
2. **进度匹配评价**：汇总评价形象进度与账面投入的匹配性，异常须说明。
3. **转固迹象**：现场发现已达可使用状态的工程须提示转固（联动H2-5）。
4. **停工减值**：停工缓建工程须评价减值迹象（联动H2-15）。
5. **未决事项跟进**：现场未解决的疑问列示跟进计划。
6. **抽样评价**：现场查看结果推断总体，评价是否需扩大范围。

## checklist

### 结论与评价
- [ ] 存在性/进度结论是否有H2-12/H2-13支撑
- [ ] 进度与投入匹配是否评价
- [ ] 达可使用状态工程是否提示转固
- [ ] 停工工程减值迹象是否评价

### 跟进
- [ ] 未决事项跟进计划是否列示
- [ ] 抽样评价是否合理

## risk_areas

### 高风险
1. **结论无支撑或与盘点矛盾**：结论无支撑或与盘点矛盾。
2. **转固/减值迹象未评价**：转固/减值迹象未评价。

### 中风险
1. **进度匹配评价缺失**：进度匹配评价缺失。
2. **抽样评价不充分**：抽样评价不充分。

### 低风险
1. **未决事项跟进不明确**：未决事项跟进不明确。
2. **小结格式不规范**：小结格式不规范。
