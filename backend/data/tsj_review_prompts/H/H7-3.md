# H7-3 生产性生物资产调整分录复核提示词

## 适用底稿
生产性生物资产调整分录汇总表（H7-3），含账项调整（AJE）、重分类调整（RJE）及未调整错报评估，聚焦调整证据、借贷平衡、回写H7-1审定表。

## 概述
H7-3 是生产性生物资产审定链路的关键环节。复核须验证：每笔调整有证据支持、借贷平衡、完整反映到H7-1审定表、折旧/减值/公允价值调整符合CAS5，未调整错报评估符合重要性水平要求。

---

## tips

1. **AJE与RJE区分**：AJE影响生物资产账面或损益（补提折旧、补计减值、公允价值调整、核销死亡资产）；RJE仅影响列报（如生产性与消耗性重分类、成熟与未成熟重分类），不得通过RJE掩盖损益错报。
2. **与H7-1勾稽**：审定表调整列金额须与H7-3已确认分录逐笔一致。
3. **折旧/减值调整证据**：补提折旧须有H7-11测算支持，补计减值须有H7-15/H7-16可收回金额测试支持。
4. **公允价值调整（公允模式）**：须有H7-13复核及估值依据支持，公允价值变动损益列报正确。
5. **死亡淘汰核销调整**：核销死亡/淘汰资产须有实物鉴定证明，避免虚假核销。
6. **TB回写**：确认调整已同步试算平衡表1621及相关损益科目。

## checklist

### 高风险检查项

- [ ] 所有AJE是否有充分审计证据（测算表/估值报告/核销证明）
- [ ] 补提折旧/减值调整是否有H7-11/H7-15测算支持
- [ ] 公允价值调整是否有H7-13复核及活跃市场依据
- [ ] 每笔调整分录借贷方是否完全平衡
- [ ] 调整金额是否完整反映到H7-1审定表对应调整列
- [ ] 死亡淘汰核销是否有实物鉴定证明
- [ ] 是否存在仅为调节利润的不当公允价值调整

### 中风险检查项

- [ ] RJE是否仅涉及列报（生产性/消耗性、成熟/未成熟重分类）
- [ ] 调整原因说明是否可追溯至具体审计程序
- [ ] 减值准备转回调整是否违反成本模式不得转回规定
- [ ] 与A13未调整错报汇总表索引是否完整
- [ ] 调整分录编号是否连续

### 低风险检查项

- [ ] 分录摘要、科目编码是否规范
- [ ] 索引是否指向H7-2/H7-11/H7-15等支持底稿
- [ ] 审计说明/结论是否概括调整性质

---

## risk_areas

### 高风险

- 公允价值调整缺乏依据虚增利润
- 折旧/减值调整无测算支持
- 死亡淘汰虚假核销

### 中风险

- 减值准备违规转回
- RJE误含损益影响
- 成熟/未成熟重分类错误

### 低风险

- 编号、格式不规范
- 索引缺失

## 跨底稿勾稽

- H7-3 已确认 AJE/RJE 合计 ↔ H7-1 审定表调整列
- H7-3 折旧/减值调整 ↔ H7-11/H7-15 测算
- H7-3 公允价值调整 ↔ H7-13 公允价值复核
- H7-3 未调整错报 ↔ A13 未调整错报汇总
- 调整后审定数 ↔ 试算平衡表 1621 科目
