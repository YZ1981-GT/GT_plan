# H1-17 运输设备权属 复核提示词

## 概述

本提示词针对运输设备权属核对表（H1-17）的复核，聚焦车辆行驶证/机动车登记证书的完整性、登记所有人一致性、抵押及融资租赁情况的识别。运输设备权属核对确认所有权归属。

## tips

1. **证照核对**：核对行驶证/登记证书的车辆识别代号、登记所有人、型号与账面卡片一致。
2. **登记人一致**：登记所有人须为被审计单位，挂靠或代持须评估所有权实质。
3. **抵押识别**：核查机动车是否存在抵押登记，受限须披露并联动借款底稿。
4. **融资租入区分**：融资租入车辆所有权在租赁期内属出租方，须区分自有与租入（勾稽H8使用权资产）。
5. **报废注销**：已报废车辆须核对注销手续，避免账面挂账实物已灭失。
6. **异地车辆**：异地使用车辆的存在性替代程序须记录。

## checklist

### 证照与登记
- [ ] 车辆识别代号/登记所有人/型号与账面是否一致
- [ ] 登记所有人是否为被审计单位
- [ ] 挂靠/代持车辆所有权实质是否评估
- [ ] 融资租入车辆是否正确区分

### 受限与状态
- [ ] 抵押车辆是否披露并勾稽借款
- [ ] 报废车辆是否办理注销
- [ ] 异地车辆存在性是否核实

## risk_areas

### 高风险
1. **登记所有人非被审计单位**：所有权存疑。
2. **抵押车辆未披露**：抵押车辆未披露。

### 中风险
1. **融资租入误作自有资产**：融资租入误作自有资产。
2. **报废车辆未注销挂账**：报废车辆未注销挂账。

### 低风险
1. **证照信息核对不完整**：证照信息核对不完整。
2. **异地车辆替代程序缺失**：异地车辆替代程序缺失。
