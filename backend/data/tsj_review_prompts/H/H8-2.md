# H8-2 使用权资产明细表复核提示词

## 概述

本提示词针对使用权资产明细表（H8-2，源模板58列→原值/折旧/减值区段）的复核。该表按逐项租赁合同登记使用权资产的原值、累计折旧、减值准备及净额的期初、增减、期末变动，是H8-1审定表数据来源。复核聚焦合同台账完整性、初始成本逐项准确性、折旧逐项计算及与租赁负债明细的对应。

**法规依据：**
- 《企业会计准则第21号——租赁》
- 《企业会计准则第8号——资产减值》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **合同台账覆盖全部确认租赁**：每份确认使用权资产的租赁合同须逐项登记，遗漏合同将导致资产不完整，须与租赁合同清单核对。
2. **逐项初始成本核对**：每份合同的使用权资产初始成本=对应租赁负债+预付租金+初始直接费用+复原成本-租赁激励，逐项核对至合同和H9明细。
3. **区段结构清晰**：原值、累计折旧、减值区段须清晰，各区段逐项勾稽（净额=原值-累计折旧-减值）。
4. **折旧逐项计算**：每份合同按其折旧年限（所有权转移按寿命/否则孰短）逐项计算折旧，年限取值逐项核对。
5. **减少与租赁终止对应**：使用权资产减少须与H8-12租赁终止检查、H9租赁负债减少对应。
6. **明细合计回勾H8-1**：各合同原值、折旧、减值、净额合计须与H8-1审定表对应区块一致。

## checklist

### 一、合同台账完整性

- [ ] 明细表是否覆盖全部确认使用权资产的租赁合同
- [ ] 每份合同是否登记合同标的、期限、起止日
- [ ] 是否与租赁合同清单核对无遗漏
- [ ] 短期/低价值豁免的租赁是否单独标识（不确认使用权资产）
- [ ] 明细各区段合计是否与H8-1审定表勾稽

### 二、初始成本准确性

- [ ] 逐项初始成本构成是否完整
- [ ] 逐项使用权资产初始金额是否与H9租赁负债明细对应
- [ ] 预付租金、初始直接费用、复原成本是否恰当计入
- [ ] 租赁激励是否恰当扣减

### 三、折旧逐项计算

- [ ] 每份合同折旧年限判断是否正确
- [ ] 逐项折旧金额是否与H8-8测算一致
- [ ] 折旧起算时点（租赁期开始日）是否正确
- [ ] 累计折旧逐项是否准确

### 四、减少与减值

- [ ] 使用权资产减少是否与H8-12终止检查对应
- [ ] 减少时的账面净值结转是否正确
- [ ] 减值准备是否逐项与H8-10勾稽
- [ ] 明细净额是否与H8-1、H9勾稽

## risk_areas

### 高风险

1. **合同台账遗漏租赁**：确认使用权资产的租赁合同未登记，资产不完整。
2. **初始成本与H9不对应**：逐项使用权资产与租赁负债金额不匹配。
3. **虚增使用权资产**：登记不存在的租赁合同或虚增初始成本。

### 中风险

1. **折旧年限逐项错误**：个别合同折旧年限判断错误。
2. **减少结转错误**：终止租赁时账面净值结转错误。
3. **豁免标识不清**：短期/低价值租赁未单独标识。

### 低风险

1. **合同信息不完整**：未登记合同标的或起止日。
2. **区段列示不清**：原值/折旧/减值区段划分不清晰。
3. **索引不完整**：明细未与合同、H8-1、H9建立索引。
