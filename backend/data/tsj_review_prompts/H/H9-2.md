# H9-2 租赁负债明细表复核提示词

## 概述

本提示词针对租赁负债明细表（H9-2）的复核。该表按逐份租赁合同登记租赁负债的初始金额、本期计息、本期偿还、期末余额及到期期限分析，是H9-1审定表数据来源。复核聚焦合同台账完整性、逐项现值/计息准确性及到期期限分析。

**法规依据：**
- 《企业会计准则第21号——租赁》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **合同台账覆盖全部确认租赁**：每份确认租赁负债的合同须逐项登记，与H8-2使用权资产明细、租赁合同清单核对，无遗漏。
2. **逐项现值与计息**：每份合同租赁负债初始现值、本期利息（期初余额×折现率）、本期偿还本金逐项核对至摊销表。
3. **到期期限分析**：明细表须按到期期限分析未来租赁付款额（1年内/1-2年/2-3年/3年以上），支持流动性披露和重分类。
4. **本期偿还核对资金流出**：本期偿还的租赁付款额须与实际付款、银行流水核对。
5. **明细合计回勾H9-1**：各合同初始金额、计息、偿还、期末余额合计须与H9-1审定表勾稽。
6. **与出租方核对（如适用）**：关联方租赁或重大租赁的负债余额可与出租方应收租赁款核对。

---

## checklist

### 一、合同台账完整性

- [ ] 明细表是否覆盖全部确认租赁负债的合同
- [ ] 是否与H8-2使用权资产明细逐份对应
- [ ] 是否与租赁合同清单核对无遗漏
- [ ] 短期/低价值豁免租赁是否未纳入（不确认负债）
- [ ] 明细合计是否与H9-1审定表勾稽

### 二、现值与计息

- [ ] 逐项租赁负债初始现值是否正确
- [ ] 逐项本期利息计算是否与摊销表一致
- [ ] 折现率逐项取值是否恰当
- [ ] 本期偿还本金逐项是否准确

### 三、到期期限分析

- [ ] 未来租赁付款额是否按到期期限分析
- [ ] 1年内到期金额是否支持重分类
- [ ] 到期期限分析是否支持附注流动性披露
- [ ] 期限分析合计是否与负债余额勾稽

### 四、偿还与勾稽

- [ ] 本期偿还是否与实际付款、银行流水核对
- [ ] 期末余额逐项是否准确
- [ ] 明细是否与H9摊销表、H9-3勾稽
- [ ] 关联方租赁是否标识并与H8-14勾稽

## risk_areas

### 高风险

1. **合同台账遗漏租赁**：确认租赁负债的合同未登记，负债不完整。
2. **逐项现值/计息错误**：个别合同现值或计息错误累积影响审定数。
3. **虚增/虚减租赁负债**：登记不存在的租赁或错误金额。

### 中风险

1. **到期期限分析错误**：期限分析错误影响重分类和流动性披露。
2. **偿还与资金流出不符**：本期偿还与实际付款不一致。
3. **折现率逐项不一致**：个别合同折现率取值不当。

### 低风险

1. **合同信息不完整**：未登记合同标的或起止日。
2. **关联方标识缺失**：关联方租赁未单独标识。
3. **索引不完整**：明细未与合同、H9-1、摊销表建立索引。
