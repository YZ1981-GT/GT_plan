# H4-5 工程物资减少检查 复核提示词

## 概述

本提示词针对工程物资减少检查表（H4-5）的复核，聚焦本期减少去向（领用转在建工程/固定资产、退库、报废）、领用金额准确性及与在建工程的勾稽。减少检查确认工程物资的正确结转。

## tips

1. **领用为主**：正常减少主要为领用转在建工程/固定资产，须与H2/H1勾稽。
2. **领用金额准确**：领用金额按实际成本结转，计价方法（加权平均/个别计价）前后一贯。
3. **退库处理**：退回供应商的物资须核对退货单与款项收回。
4. **报废处理**：毁损报废工程物资损失须有依据，计入相关成本或营业外支出。
5. **减少金额勾稽**：减少金额须与明细表结转一致。
6. **抽凭核对**：大额减少抽凭核对领用单/审批文件。

## checklist

### 去向与金额
- [ ] 领用去向是否清晰并与H2/H1勾稽
- [ ] 领用金额计价方法是否一贯准确
- [ ] 退库是否核对退货单与款项
- [ ] 报废损失是否有依据

### 勾稽与抽凭
- [ ] 减少金额是否与明细表结转一致
- [ ] 大额减少是否抽凭核对
- [ ] 本期减少是否与H4-1勾稽

## risk_areas

### 高风险
1. **领用去向不明或与在建工程不勾稽**：领用去向不明或与在建工程不勾稽。
2. **报废损失缺依据或掩盖物资流失**：报废损失缺依据或掩盖物资流失。

### 中风险
1. **计价方法不一贯**：计价方法不一贯。
2. **退库款项未收回**：退库款项未收回。

### 低风险
1. **抽凭不充分**：抽凭不充分。
2. **去向分类不清**：去向分类不清。
