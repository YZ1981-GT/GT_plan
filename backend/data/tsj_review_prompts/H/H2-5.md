# H2-5 在建工程转固时点检查 复核提示词

## 概述

本提示词针对在建工程转固时点检查表（H2-5）的复核，聚焦达到预定可使用状态的判断、转固时点及时性、转固金额准确性及与H1固定资产的核心勾稽。转固时点直接影响折旧起点与损益。

## tips

1. **可使用状态判断**：以是否达到预定可使用状态（而非竣工决算）为转固标准，已投产使用即应转固。
2. **转固及时性**：达可使用状态未及时转固将少提折旧、虚增利润，是在建工程审计核心风险。
3. **转固金额准确**：转固金额=工程实际成本（决算未完可按暂估），后续决算调整补记。
4. **H1勾稽**：转固金额与时点须与H1固定资产增加（在建工程转入）逐项勾稽。
5. **暂估转固**：以暂估价转固的须在决算后调整，关注长期暂估未调整。
6. **投产迹象核查**：核查生产记录、水电耗用、产品产出等投产迹象判断实际使用时点。

## checklist

### 判断与及时性
- [ ] 转固标准是否为达到预定可使用状态
- [ ] 是否存在已投产未转固工程
- [ ] 投产迹象（生产/耗用/产出）是否核查
- [ ] 转固金额是否准确（含暂估处理）

### 勾稽
- [ ] 转固金额/时点是否与H1增加勾稽
- [ ] 暂估转固是否决算后调整
- [ ] 转固后折旧起点是否正确

## risk_areas

### 高风险
1. **已达可使用状态未转固**：少提折旧虚增利润。
2. **转固金额与H1不勾稽**：转固金额与H1不勾稽。

### 中风险
1. **暂估转固长期未调整**：暂估转固长期未调整。
2. **转固后折旧起点错误**：转固后折旧起点错误。

### 低风险
1. **投产迹象核查不充分**：投产迹象核查不充分。
2. **转固凭据索引不完整**：转固凭据索引不完整。
