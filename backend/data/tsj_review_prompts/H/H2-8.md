# H2-8 在建工程增加检查 复核提示词

## 概述

本提示词针对在建工程增加检查表（H2-8）的复核，聚焦本期工程投入的真实性、资本化范围准确性、抽凭充分性及资本化利息的核对。增加检查确认资本性支出的合规归集。

## tips

1. **投入真实性**：本期工程投入须核对合同、发票、结算单、付款凭证，防止虚增工程成本。
2. **资本化范围**：仅达到预定可使用状态前的必要支出可资本化，试运行收入应冲减工程成本或计入损益。
3. **资本化利息**：符合条件的专门/一般借款利息资本化须核对（勾稽H2-10/H2-11），非正常中断期间不得资本化。
4. **抽凭覆盖大额**：大额投入须抽凭核对，检查比例达标。
5. **设备采购核对**：设备投资核对采购合同、到货验收、安装记录。
6. **关联采购公允**：关联方供应工程材料/设备价格公允性评估。

## checklist

### 真实性与资本化
- [ ] 本期投入是否核对合同/发票/结算/付款
- [ ] 资本化范围是否准确（试运行收入处理）
- [ ] 资本化利息是否核对且不超额
- [ ] 非正常中断期间是否停止资本化

### 抽凭与勾稽
- [ ] 大额投入抽凭比例是否达标
- [ ] 本期增加是否与H2-2/H2-1勾稽
- [ ] 关联采购价格是否公允

## risk_areas

### 高风险
1. **虚增工程投入或费用化支出误资本化**：虚增工程投入或费用化支出误资本化。
2. **试运行收入未冲减成本**：试运行收入未冲减成本。
3. **中断期间利息违规资本化**：中断期间利息违规资本化。

### 中风险
1. **资本化利息超额**：资本化利息超额。
2. **关联采购不公允**：关联采购不公允。

### 低风险
1. **抽凭比例略低**：抽凭比例略低。
2. **单据索引不完整**：单据索引不完整。
