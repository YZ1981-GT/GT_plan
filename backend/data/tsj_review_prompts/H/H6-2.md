# H6-2 固定资产清理明细表复核提示词

## 概述

本提示词针对固定资产清理明细表（H6-2）的复核。该表按逐个清理项目登记转出资产的原值、累计折旧、减值准备、账面净值、清理费用、处置收入及清理净损益，是H6-1审定表的数据来源。复核聚焦清理台账完整性、账面净值计算准确性、处置收入真实性及净损益归类。

**法规依据：**
- 《企业会计准则第4号——固定资产》（处置及清理）
- 《企业会计准则第42号——持有待售的非流动资产、处置组和终止经营》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **明细台账须覆盖本期全部处置**：每一笔固定资产处置/报废/毁损/对外投资均应在明细表逐项登记，遗漏任一清理项目将导致审定数不完整。
2. **账面净值须三要素齐全**：账面净值=原值-累计折旧-减值准备，三要素任一遗漏或错取都会导致清理净损益失真，逐项核对至固定资产卡片。
3. **区分处置性质决定损益归类**：明细表应标注处置方式（出售/转让/报废/毁损/对外投资/非货币性资产交换），不同方式对应不同的损益结转科目和披露要求。
4. **清理费用应真实且相关**：拆卸、运输、评估、中介等清理费用须有单据支持，与被清理资产直接相关，警惕将日常费用挤入清理费用。
5. **处置收入核对至资金流入**：处置价款、残料变价、赔偿款须与银行进账单/收款凭证核对，关注是否存在低价处置国有/上市资产的利益输送。
6. **明细合计必须回勾H6-1审定表**：各清理项目原值、净值、收入、净损益合计须与H6-1审定表对应行完全一致，形成明细-汇总闭环勾稽。

## checklist

### 一、清理台账完整性

- [ ] 明细表是否登记本期全部固定资产处置/报废/毁损项目
- [ ] 每个清理项目是否标注资产名称、编号、处置方式和处置日期
- [ ] 是否与固定资产台账减少项目逐笔对应，无遗漏无重复
- [ ] 期末未完成清理的项目是否单独标识并说明状态
- [ ] 明细各列合计是否与H6-1审定表对应行勾稽一致

### 二、账面净值准确性

- [ ] 转出原值是否与固定资产卡片/台账一致
- [ ] 累计折旧转出金额是否计算至处置当月且与折旧台账一致
- [ ] 已计提减值准备是否随资产一并转出
- [ ] 账面净值=原值-累计折旧-减值准备的公式计算是否正确
- [ ] 是否存在提前停止计提折旧或多提折旧的情况

### 三、处置收入与费用

- [ ] 处置价款/残料变价收入是否与收款凭证、银行进账单核对一致
- [ ] 保险赔偿/责任人赔偿是否入账完整
- [ ] 清理费用是否有合法单据支持且与被清理资产直接相关
- [ ] 是否存在低价处置资产的迹象（对比评估价/市场价）
- [ ] 增值税销项税额计算是否正确（动产/不动产区别处理）

### 四、净损益归类与列报

- [ ] 各项目清理净损益计算是否正确（收入-净值-费用-税费）
- [ ] 处置方式与损益结转科目是否匹配（资产处置收益vs营业外收支）
- [ ] 报废/毁损损失是否有充分的实物核销证据
- [ ] 明细表净损益合计是否与H10资产处置收益勾稽
- [ ] 是否与相关调整分录（H6-3）保持一致

## risk_areas

### 高风险

1. **处置收入体外循环**：残料变价、赔偿款未入账，形成账外资金，构成资产流失和舞弊风险。
2. **低价处置利益输送**：以显著低于评估价/市场价处置资产给关联方，损害企业及股东利益。
3. **账面净值计算错误**：遗漏减值准备转出或折旧计提截止日错误，导致清理净损益系统性失真。
4. **清理台账遗漏处置项目**：固定资产已实物处置但明细表未登记，账实不符。

### 中风险

1. **清理费用不实**：将无关费用挤入清理费用虚增处置成本，或清理费用缺乏单据支持。
2. **损益归类错误**：报废损失错列资产处置收益，或处置收益错入营业外收入。
3. **增值税处理不当**：处置不动产/动产的销项税额或简易计税适用错误。
4. **处置审批不完备**：重大资产处置缺乏授权审批即已入账。

### 低风险

1. **处置日期记录不准**：处置日期与实际交割/停用日期存在偏差，影响折旧计提截止。
2. **明细列示不完整**：未标注处置方式或未附资产编号，影响追溯。
3. **底稿索引不完整**：明细表未与固定资产台账、H6-1、H10建立完整索引引用。
