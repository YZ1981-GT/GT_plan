# H1-note-listed 固定资产附注披露 复核提示词（上市公司）

## 概述

本提示词针对固定资产上市公司附注披露底稿的复核，聚焦固定资产变动表（原值/累计折旧/减值准备/账面价值四栏）的完整勾稽、折旧政策披露、受限资产披露、暂时闲置及经营租出披露的充分性。上市公司披露要求高于一般企业。

## tips

1. **变动表四栏勾稽**：原值/累计折旧/减值准备/账面价值变动表须完整列示期初、增加、减少、期末，且各栏与审定表勾稽。
2. **分类披露完整**：按房屋建筑物/机器设备/运输工具/电子设备等类别分别披露，合计等于审定数。
3. **折旧政策披露**：折旧方法、年限、净残值率须在会计政策中披露，与H1-5一致。
4. **受限资产披露**：抵押、查封、担保的固定资产账面价值及受限原因须单独披露，联动借款附注。
5. **暂时闲置披露**：暂时闲置固定资产账面价值须披露（勾稽H1-4）。
6. **未办证/经营租出/融资租入披露**：未办妥产权证书资产、经营租出资产、以融资租赁租入资产须分别披露。

## checklist

### 变动表与分类
- [ ] 四栏变动表是否完整（期初/增加/减少/期末）
- [ ] 变动表各栏是否与H1-1审定表勾稽
- [ ] 是否按类别分别披露且合计等于审定数
- [ ] 是否列示期初可比数据

### 政策与专项披露
- [ ] 折旧方法/年限/残值率是否披露且与H1-5一致
- [ ] 抵押/查封资产账面价值及原因是否披露
- [ ] 暂时闲置固定资产是否披露
- [ ] 未办证/经营租出/融资租入资产是否分别披露
- [ ] 本期计提减值是否与信用/资产减值损失一致
- [ ] 附注总额是否与审定表审定数一致

## risk_areas

### 高风险
1. **变动表勾稽不成立或与审定表不符**：变动表勾稽不成立或与审定表不符。
2. **受限资产（抵押/查封）未披露**：受限资产（抵押/查封）未披露。
3. **减值披露与利润表资产减值损失不一致**：减值披露与利润表资产减值损失不一致。

### 中风险
1. **分类披露不完整或缺可比数据**：分类披露不完整或缺可比数据。
2. **暂时闲置/未办证资产未披露**：暂时闲置/未办证资产未披露。

### 低风险
1. **折旧政策描述模板化**：折旧政策描述模板化。
2. **披露格式不完全规范**：披露格式不完全规范。
