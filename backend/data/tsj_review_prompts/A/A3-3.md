# A3-3 结构化主体纳入合并范围判断复核提示词

## 概述

本提示词针对报告阶段"结构化主体纳入合并范围判断"（A3-3，CAS33控制判断）的复核，聚焦控制判断三要素的评估完整性、判断依据的证据支持、合并范围结论的准确性及判断记录的充分性。结构化主体（如资管产品、SPV、信托计划）的合并判断是合并范围认定的难点，须基于"权力、可变回报、运用权力影响回报的能力"三要素综合判断，判断错误将直接导致合并范围错误。

**法规依据：**
- 《企业会计准则第33号——合并财务报表》
- 《中国注册会计师审计准则第1301号——审计证据》
- 《中国注册会计师审计准则第1401号——对集团财务报表审计的特殊考虑》

---

## tips

1. **控制判断须完整评估三要素**：CAS33控制模型要求同时评估权力、可变回报、运用权力影响回报的能力，缺一不可，仅凭持股比例判断结构化主体控制是错误的。
2. **权力评估须穿透实质**：须评估投资方对结构化主体相关活动的决策权，包括通过合同安排、代理关系等实质性权力，而非仅法律形式。
3. **可变回报须全面识别**：可变回报包括投资收益、管理费、担保、剩余权益等各种形式，须全面识别并评估重大性。
4. **代理人与主要责任人区分**：须判断投资方是以主要责任人还是代理人身份行使决策权，代理人不控制结构化主体。
5. **判断须有充分证据支持**：控制判断结论须追溯至合同条款、章程、决策记录等证据，杜绝仅凭结论的臆断。
6. **关注隐性合并或出表安排**：警惕通过结构化主体设计规避合并（隐藏负债）或不当出表（虚增出售），须实质重于形式判断。

## checklist

### 一、控制三要素评估完整性

- [ ] 是否评估投资方对结构化主体的权力
- [ ] 是否评估投资方享有的可变回报
- [ ] 是否评估运用权力影响回报的能力
- [ ] 三要素是否综合判断而非单一要素判断
- [ ] 是否穿透法律形式评估实质控制

### 二、判断依据证据支持

- [ ] 权力评估是否有合同/章程/决策记录支持
- [ ] 可变回报识别是否全面（收益/管理费/担保/剩余权益）
- [ ] 代理人与主要责任人判断是否有依据
- [ ] 是否存在结论无据的判断

### 三、合并范围结论准确性

- [ ] 判断结论（合并/不合并）是否与三要素评估一致
- [ ] 应合并的结构化主体是否纳入合并范围
- [ ] 不合并的结构化主体是否评估其他披露要求
- [ ] 是否存在规避合并或不当出表的安排

### 四、判断记录充分性

- [ ] 控制判断过程是否完整记录
- [ ] 关键判断依据是否留痕
- [ ] 判断是否有编制人和复核人签字
- [ ] 底稿索引是否与合并程序表（A3）建立引用

## risk_areas

### 高风险

1. **控制判断三要素评估缺失**：仅凭持股比例或法律形式判断，未评估权力和可变回报，判断结论不可靠。
2. **应合并结构化主体遗漏**：实质控制的结构化主体未纳入合并，隐藏表外负债或风险敞口。
3. **不当出表**：通过结构化主体设计将实质仍控制的主体不当出表，虚增处置损益。
4. **代理人身份误判**：将代理人身份误判为主要责任人（或反之），导致合并范围错误。

### 中风险

1. **可变回报识别不全**：遗漏管理费、担保等形式的可变回报，影响控制判断。
2. **权力评估流于形式**：仅评估法律形式而未穿透实质决策权。
3. **判断证据不足**：控制判断缺乏合同、章程等证据支持。
4. **其他披露遗漏**：不合并的结构化主体未评估表外披露要求。

### 低风险

1. **判断记录不充分**：控制判断过程记录简略。
2. **格式不规范**：判断表格式、要素列示不规范。
3. **底稿索引不完整**：与A3合并程序表交叉引用缺失。
