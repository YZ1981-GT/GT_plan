# A4-1 经营分部审定表复核提示词

## 概述

本提示词针对报告阶段"经营分部审定表"（A4-1）的复核，聚焦分部审定数据的准确性、分部与合并报表的勾稽、审计调整对分部的传导及审定记录的充分性。经营分部审定表汇总各报告分部的审定后收入、损益、资产等数据，是分部报告披露的数据基础，须确保分部数据经过审定、与合并报表勾稽、并正确反映相关审计调整。

**法规依据：**
- 《企业会计准则第35号——分部报告》
- 《中国注册会计师审计准则第1301号——审计证据》
- 《企业会计准则第30号——财务报表列报》

---

## tips

1. **分部审定数据须为审定后口径**：A4-1所列分部数据须为纳入审计调整后的审定数，而非管理层未审的分部报告数。
2. **审计调整须传导至分部**：影响分部的审计调整须正确分摊至相应报告分部，调整未传导将导致分部数据与合并数据脱节。
3. **分部合计须与合并勾稽**：各分部审定数据合计（含分部间抵销和未分配调节）须与合并报表审定数一致。
4. **分部间抵销须准确**：分部间交易的抵销须在审定表中正确反映。
5. **审定表须与分部程序表衔接**：A4-1审定数据须与A4分部程序表的分部划分和识别结论一致。
6. **关注分部数据的一致性**：分部审定数据须与附注分部披露、内部管理报告保持一致。

## checklist

### 一、分部审定准确性

- [ ] A4-1分部数据是否为审定后口径
- [ ] 影响分部的审计调整是否分摊至相应分部
- [ ] 分部收入、损益、资产审定数是否准确
- [ ] 分部划分是否与A4程序表一致
- [ ] 是否存在未审数据混入审定表

### 二、勾稽核对

- [ ] 分部收入审定合计是否与合并收入勾稽
- [ ] 分部损益审定合计是否与合并利润勾稽
- [ ] 分部资产审定合计是否与合并资产勾稽
- [ ] 分部间抵销是否准确反映
- [ ] 未分配项目调节是否列示

### 三、审计调整传导

- [ ] A2调整分录中影响分部的调整是否传导至A4-1
- [ ] 调整分摊方法是否合理
- [ ] 调整后分部数据是否与合并调整一致
- [ ] 是否存在调整遗漏传导的分部

### 四、审定记录充分性

- [ ] 分部审定数据是否与内部管理报告核对
- [ ] 审定数据是否与附注分部披露一致
- [ ] 审定表是否有编制人和复核人签字
- [ ] 底稿索引是否与A4程序表建立引用

## risk_areas

### 高风险

1. **分部审定数据与合并脱节**：分部审定合计与合并报表审定数不一致，暴露分部数据错误或调整未传导。
2. **审计调整未传导分部**：影响分部的调整未分摊至相应分部，分部数据失真。
3. **使用未审数据**：A4-1混入管理层未审分部数据，审定表失去意义。
4. **分部间抵销错误**：分部间交易抵销在审定表中处理错误，虚增分部业绩。

### 中风险

1. **调整分摊不合理**：审计调整向分部分摊的方法不合理。
2. **分部划分不一致**：A4-1分部划分与A4程序表结论不一致。
3. **未分配调节缺失**：未分配项目调节未在审定表列示。
4. **披露不一致**：分部审定数据与附注披露不一致。

### 低风险

1. **审定表格式不规范**：分部审定表格式不规范。
2. **核对记录简略**：与内部报告核对记录不充分。
3. **底稿索引不完整**：与A4程序表交叉引用缺失。
