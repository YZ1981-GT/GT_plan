# A5-2 承诺事项审定表复核提示词

## 概述

本提示词针对报告阶段"承诺事项审定表"（A5-2）的复核，聚焦承诺事项识别的完整性、承诺金额计量的准确性、披露的充分性及审定记录的充分性。承诺事项（如资本承诺、经营租赁承诺、购销合同承诺、对外担保承诺）是表外重要信息，须完整识别、准确计量、充分披露，防止重大表外义务被遗漏或低估，误导报表使用者对企业未来现金流出义务的判断。

**法规依据：**
- 《企业会计准则第13号——或有事项》
- 《中国注册会计师审计准则第1301号——审计证据》
- 《企业会计准则第30号——财务报表列报》

---

## tips

1. **承诺事项识别须完整**：须通过合同审阅、董事会决议、管理层询问、函证等多渠道识别全部重大承诺，防止表外义务遗漏。
2. **承诺与或有事项须区分**：承诺是已存在的确定或较确定的未来义务，或有事项取决于不确定未来事项，两者处理和披露不同。
3. **承诺金额计量须准确**：资本承诺、租赁承诺等的金额须基于合同条款准确计量，未来期间分布须合理。
4. **对外担保承诺须重点关注**：对外担保（尤其对关联方）是高风险承诺，须核实担保金额、期限、被担保方及潜在损失。
5. **承诺披露须充分**：承诺事项的性质、金额、期限须在附注中充分披露，重大承诺不得遗漏。
6. **关注承诺的期后变动**：资产负债表日后承诺的重大变化须评估是否需调整或披露。

## checklist

### 一、承诺事项识别完整性

- [ ] 是否通过合同审阅识别承诺事项
- [ ] 是否检查董事会/股东会决议中的承诺
- [ ] 资本承诺（在建/购建）是否识别
- [ ] 经营租赁/长期采购销售承诺是否识别
- [ ] 对外担保承诺是否识别
- [ ] 是否存在应识别未识别的重大承诺

### 二、计量准确性

- [ ] 承诺金额是否基于合同条款准确计量
- [ ] 承诺的未来期间分布是否合理
- [ ] 外币承诺是否按适当汇率折算
- [ ] 承诺与或有事项是否正确区分

### 三、披露充分性

- [ ] 承诺事项性质、金额、期限是否披露
- [ ] 对外担保承诺是否充分披露
- [ ] 承诺披露是否与附注（A3-5）一致
- [ ] 关联方承诺是否单独披露

### 四、审定记录充分性

- [ ] 承诺识别是否有函证或合同等证据支持
- [ ] 承诺金额是否有计量依据
- [ ] 期后承诺变动是否评估
- [ ] 审定表是否有编制人和复核人签字

## risk_areas

### 高风险

1. **重大承诺遗漏**：重大资本承诺、担保承诺或长期合同承诺未识别，表外义务被隐藏，误导报表使用者。
2. **对外担保未充分披露**：对外担保（尤其对关联方）未识别或未充分披露，潜在重大损失风险被掩盖。
3. **承诺与或有混淆**：承诺误作或有事项（或反之）处理，导致确认或披露错误。
4. **承诺金额重大低估**：承诺金额计量低估，未来现金流出义务被低估。

### 中风险

1. **识别渠道不全**：仅通过管理层询问识别，未审阅合同和决议。
2. **计量依据不足**：承诺金额缺乏合同条款等计量依据。
3. **披露不完整**：承诺性质、期限等披露要素缺失。
4. **期后变动未评估**：资产负债表日后承诺变化未评估影响。

### 低风险

1. **审定表格式不规范**：承诺审定表格式、分类不规范。
2. **证据索引不完整**：承诺识别证据索引不完整。
3. **底稿索引不完整**：与附注、担保底稿交叉引用缺失。
