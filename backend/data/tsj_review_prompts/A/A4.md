# A4 经营分部程序表复核提示词

## 概述

本提示词针对报告阶段"经营分部程序表"（A4，CAS35分部报告）的复核，聚焦分部划分的合理性、分部信息的完整性、分部数据与合并报表的勾稽及审计程序执行的充分性。经营分部报告须基于管理层内部管理视角确定报告分部，完整披露各分部收入、损益、资产等信息，分部数据合计须与合并报表勾稽，确保分部信息真实反映企业的业务构成和经营成果。

**法规依据：**
- 《企业会计准则第35号——分部报告》
- 《中国注册会计师审计准则第1301号——审计证据》
- 《企业会计准则第30号——财务报表列报》

---

## tips

1. **报告分部划分须基于管理视角**：CAS35采用"管理途径"，报告分部应与管理层内部用于决策和业绩评价的分部一致，划分不当将扭曲分部信息。
2. **分部合并（汇总）须符合条件**：多个经营分部合并为一个报告分部须满足经济特征相似等条件，不当合并将掩盖分部差异。
3. **量化门槛须正确应用**：达到收入、损益、资产10%量化门槛的分部须单独报告，须核实门槛计算和分部识别的准确性。
4. **分部数据须与合并报表勾稽**：各分部收入、损益、资产合计（含分部间抵销和未分配项目调节）须与合并报表勾稽一致。
5. **分部间交易须恰当处理**：分部间交易的计价基础须披露，分部间抵销须正确处理。
6. **关注分部披露的完整性**：须披露报告分部的确定依据、各分部的产品和服务、地区分部信息、主要客户信息等。

## checklist

### 一、分部划分合理性

- [ ] 报告分部是否基于管理层内部管理视角确定
- [ ] 分部合并（汇总）是否满足经济特征相似等条件
- [ ] 是否正确应用10%量化门槛识别报告分部
- [ ] 报告分部收入合计是否达到合并收入75%的下限要求
- [ ] 分部划分是否与前期一致（变更是否说明）

### 二、分部信息完整性

- [ ] 各报告分部收入是否完整披露
- [ ] 各分部损益（分部利润/亏损）是否披露
- [ ] 各分部资产、负债（如适用）是否披露
- [ ] 报告分部确定依据是否披露
- [ ] 地区分部、主要客户信息是否披露

### 三、勾稽核对

- [ ] 分部收入合计（含调节）是否与合并收入勾稽
- [ ] 分部损益合计（含调节）是否与合并利润勾稽
- [ ] 分部资产合计（含调节）是否与合并资产勾稽
- [ ] 分部间交易抵销是否正确处理
- [ ] 未分配项目调节是否列示

### 四、程序执行充分性

- [ ] 分部数据是否与内部管理报告核对
- [ ] 分部间交易计价基础是否披露
- [ ] 分部信息是否与附注披露一致
- [ ] 分部程序是否有编制人和复核人签字

## risk_areas

### 高风险

1. **分部划分扭曲**：报告分部划分不符合管理视角或不当合并，掩盖分部间重大差异，误导报表使用者。
2. **分部数据与合并不勾稽**：分部收入、损益、资产合计与合并报表不一致，暴露分部数据错误。
3. **应报告分部遗漏**：达到量化门槛的分部未单独报告，分部信息不完整。
4. **分部间交易处理错误**：分部间交易未恰当抵销或计价基础不当，虚增分部业绩。

### 中风险

1. **量化门槛应用错误**：10%门槛或75%下限计算错误，分部识别失当。
2. **分部披露不完整**：确定依据、地区分部、主要客户等信息披露遗漏。
3. **分部划分变更未说明**：报告分部较前期变更但未说明原因和影响。
4. **未分配项目调节缺失**：未分配项目调节未列示，勾稽不透明。

### 低风险

1. **分部报告格式不规范**：分部信息列示格式不规范。
2. **计价基础披露简略**：分部间交易计价基础披露不充分。
3. **底稿索引不完整**：分部程序表与合并报表、附注交叉引用缺失。
