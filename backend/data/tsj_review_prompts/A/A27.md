# A27 IT审计沟通/备忘复核提示词

## 概述

本提示词针对报告阶段"IT审计沟通/备忘"（A27，与IT审计相关沟通）的复核，聚焦IT审计工作范围与结论的完整反映、IT一般控制与应用控制发现的沟通、结论对财务报表审计的支持性及沟通记录的充分性。A27承载IT审计团队与项目组之间、以及向治理层就IT相关事项的沟通，须确保IT审计发现与信息系统依赖程度评估、内控缺陷、审计结论形成有效衔接。

**法规依据：**
- 《中国注册会计师审计准则第1211号——通过了解被审计单位及其环境识别和评估重大错报风险》
- 《中国注册会计师审计准则第1301号——审计证据》
- 《中国注册会计师审计准则第1151号——与治理层的沟通》

---

## tips

1. **IT审计范围须与财报重大错报风险匹配**：IT审计工作范围应覆盖对财务报表有重大影响的信息系统和IT一般控制（ITGC），范围不足将削弱对系统生成数据的信赖基础。
2. **ITGC与应用控制发现须完整沟通**：访问安全、变更管理、运行维护等ITGC缺陷及关键应用控制测试结果须完整传递给项目组。
3. **IT发现须传导至财报审计结论**：IT控制缺陷若影响系统生成数据的可靠性，须评估对实质性程序性质、时间、范围的影响。
4. **IT专家利用须符合CAS1421要求**：如利用IT审计专家工作，须评估专家的胜任能力、客观性及工作充分性。
5. **沟通记录须清晰可追溯**：IT审计与项目组的沟通、向治理层的IT相关通报须记录时间、内容、结论。
6. **关注IT缺陷与手工控制的补偿关系**：IT控制缺陷是否存在有效的手工补偿控制，直接影响缺陷严重程度评价。

## checklist

### 一、IT审计范围完整性

- [ ] IT审计范围是否覆盖对财报有重大影响的信息系统
- [ ] ITGC四大领域（访问/变更/运维/程序开发）是否评估
- [ ] 关键应用控制是否纳入测试范围
- [ ] 范围界定是否与风险评估结论匹配

### 二、IT发现沟通完整性

- [ ] ITGC测试发现的缺陷是否完整传递给项目组
- [ ] 应用控制测试结果是否沟通
- [ ] IT相关重大缺陷是否向治理层通报
- [ ] IT发现是否记录充分并有证据支持

### 三、结论支持性

- [ ] IT控制缺陷对系统数据可靠性的影响是否评估
- [ ] IT发现是否传导至实质性程序的调整
- [ ] IT缺陷是否评估手工补偿控制
- [ ] IT审计结论是否支持对系统生成数据的信赖判断

### 四、专家利用与记录

- [ ] 如利用IT专家，其胜任能力和客观性是否评估
- [ ] IT专家工作的充分性是否评价
- [ ] IT审计与项目组沟通是否记录
- [ ] 底稿索引是否与风险评估、内控缺陷底稿建立引用

## risk_areas

### 高风险

1. **IT审计范围不足**：范围未覆盖对财报重大影响的系统，导致对系统数据的信赖缺乏基础。
2. **IT缺陷未传导至财报结论**：ITGC重大缺陷未评估对实质性程序的影响，可能过度信赖不可靠数据。
3. **重大IT缺陷未沟通治理层**：影响财报的重大IT控制缺陷未向治理层通报。
4. **专家工作未评价即依赖**：利用IT专家工作但未评估其胜任能力和充分性。

### 中风险

1. **IT发现沟通不完整**：ITGC或应用控制发现未完整传递项目组。
2. **补偿控制评估缺失**：IT缺陷未评估手工补偿控制，缺陷严重程度判断失准。
3. **IT发现证据不足**：IT审计结论缺乏充分测试证据支持。
4. **沟通记录不清**：IT审计与项目组沟通缺乏清晰记录。

### 低风险

1. **备忘录格式不规范**：IT审计备忘格式、结构不规范。
2. **底稿索引不完整**：IT底稿与风险评估、内控底稿交叉引用缺失。
3. **术语使用不一致**：IT技术术语表述前后不一致。
