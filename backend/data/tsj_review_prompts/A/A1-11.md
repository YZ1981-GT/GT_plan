# A1-11 业务约定书和报告文号核对复核提示词

## 概述

本提示词针对业务约定书和报告文号核对（A1-11）的复核，聚焦业务约定条款与审计报告口径的一致性、报告文号编制的规范性与唯一性、报告要素与约定范围的匹配性。该底稿是报告签发前的合规核对环节，约定书范围与报告口径不符或文号错误可能引发法律责任与报告可追溯性问题。

**法规依据：**
- 《中国注册会计师审计准则第1111号——就审计业务约定条款达成一致意见》
- 《中国注册会计师审计准则第1501号——对财务报表形成审计意见和出具审计报告》
- 《中国注册会计师审计准则第1601号——对按照特殊目的编制基础编制的财务报表审计的特殊考虑》

---

## tips

1. **约定书范围决定报告口径**：审计报告的财务报表范围、报告责任、适用编制基础须与业务约定书条款完全一致，不得超范围或缩范围出具。
2. **报告文号须唯一且可追溯**：报告文号编制应遵循事务所统一编号规则，确保唯一性，可追溯至项目档案与质控记录。
3. **报告要素完整性核对**：被审计单位全称、报告期间、财务报表构成、意见类型、签字注册会计师等要素须与约定及底稿一致。
4. **多份报告的文号协调**：同一项目出具多份报告（如财报+内控）时，文号须体现关联关系且互不冲突。
5. **约定书签署时点合规**：业务约定书应在审计工作实质性开展前签署，签署主体与授权须有效。
6. **报告日与约定期间匹配**：审计报告日不得早于取得充分适当审计证据之日，且应落在约定的报告期间内。

## checklist

### 一、约定书与报告口径一致性

- [ ] 审计报告涵盖的财务报表范围是否与业务约定书一致
- [ ] 适用的财务报告编制基础是否与约定书表述一致
- [ ] 管理层责任与注册会计师责任表述是否与约定条款匹配
- [ ] 报告期间是否与约定的审计期间一致
- [ ] 是否存在超出或缩小约定范围出具报告的情况

### 二、报告文号规范性

- [ ] 报告文号是否遵循事务所统一编号规则
- [ ] 报告文号是否唯一、无重号
- [ ] 报告文号是否可追溯至项目档案与质控记录
- [ ] 同一项目多份报告文号是否协调且体现关联

### 三、报告要素核对

- [ ] 被审计单位全称是否准确无误
- [ ] 财务报表构成（资产负债表/利润表/现金流量表/所有者权益变动表/附注）是否完整列示
- [ ] 意见类型是否与完成阶段结论一致
- [ ] 签字注册会计师及事务所信息是否准确

### 四、约定与报告时点合规

- [ ] 业务约定书签署时点是否在审计工作实质性开展前
- [ ] 约定书签署主体与授权是否有效
- [ ] 审计报告日是否不早于取得充分适当审计证据之日
- [ ] 报告日是否落在约定的报告期间内

## risk_areas

### 高风险

1. **超范围出具报告**：审计报告涵盖范围超出业务约定书授权，事务所承担未约定的责任风险。
2. **编制基础表述不一致**：报告适用的编制基础与约定书不符，可能误导报告使用者对报表性质的理解。
3. **报告文号重号或缺失**：文号不唯一或未编制，报告可追溯性丧失，档案管理失控。
4. **意见类型与结论不符**：报告意见类型与完成阶段底稿结论不一致，构成报告要素错误。

### 中风险

1. **报告要素填写错误**：被审计单位名称、报告期间、报表构成等要素填写有误，影响报告准确性。
2. **约定书签署时点滞后**：约定书在审计工作实质性开展后才签署，前期工作缺乏约定基础。
3. **多份报告文号冲突**：同项目多份报告文号未协调，关联关系不清。

### 低风险

1. **文号格式不统一**：报告文号格式与事务所规则存在细微偏差，不影响唯一性但欠规范。
2. **约定书归档索引缺失**：约定书未在底稿中建立索引引用，增加核对难度。
3. **要素表述用词不严谨**：报告非关键性表述用词欠精确，不影响实质但可优化。
