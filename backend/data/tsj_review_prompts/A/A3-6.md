# A3-6 Word附注复核提示词

## 概述

本提示词针对报告阶段"Word附注"（A3-6，附注编制）的复核，作为附注编制的延续或补充部分，聚焦附注披露的完整性、与报表及审定表的勾稽一致性、准则披露要求的遵循及编制准确性。A3-6承载附注的补充章节或特定科目的详细披露，须与A3-5主附注协调统一，共同构成完整、准确、勾稽一致的财务报表附注。

**法规依据：**
- 《企业会计准则第33号——合并财务报表》
- 《企业会计准则第30号——财务报表列报》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **附注补充章节须与主附注协调**：A3-6补充内容须与A3-5主附注在会计政策、科目口径、格式上保持一致，不得前后矛盾。
2. **补充披露须完整覆盖专项要求**：针对特定科目或事项的详细披露须完整满足准则要求。
3. **数据勾稽须贯通主表与审定表**：补充附注的数据须与报表主表、审定表、相关明细底稿勾稽一致。
4. **披露口径须前后期一致**：补充披露的口径须与前期一致，变更须说明。
5. **文字与数据须相互印证**：补充附注的文字说明须与所列数据一致且相互印证。
6. **关注补充附注的完整性衔接**：A3-5与A3-6合计须构成完整附注，无章节遗漏或重复。

## checklist

### 一、补充披露完整性

- [ ] A3-6补充章节是否与A3-5主附注衔接完整
- [ ] 专项科目详细披露是否满足准则要求
- [ ] A3-5与A3-6合计是否构成完整附注
- [ ] 是否存在章节遗漏或重复披露

### 二、勾稽一致性

- [ ] 补充附注数据是否与报表主表一致
- [ ] 补充附注明细合计是否与审定表一致
- [ ] 补充附注是否与相关明细底稿勾稽
- [ ] 交叉引用编号是否准确

### 三、口径一致性

- [ ] 补充披露口径是否与A3-5协调一致
- [ ] 会计政策披露是否前后一致
- [ ] 前后期披露口径是否一致（变更是否说明）
- [ ] 是否存在与主附注矛盾的表述

### 四、编制准确性

- [ ] 补充附注文字与数据是否相互印证
- [ ] 披露内容是否与底稿证据一致
- [ ] 补充附注是否有编制人和复核人签字
- [ ] 底稿索引是否与A3-5及相关底稿建立引用

## risk_areas

### 高风险

1. **补充披露重大遗漏**：专项科目或事项的详细披露遗漏，附注不完整。
2. **补充附注与主附注矛盾**：A3-6与A3-5在政策或数据口径上矛盾，暴露编制混乱。
3. **数据不勾稽**：补充附注数据与主表或审定表不一致。
4. **重大风险披露回避**：补充章节应披露的重大风险事项回避或淡化。

### 中风险

1. **章节衔接断裂**：A3-5与A3-6合计存在章节遗漏或重复。
2. **口径前后期不一致**：披露口径变更未说明。
3. **交叉引用错误**：补充附注引用编号错误。
4. **明细底稿不勾稽**：补充附注与相关明细底稿数据不一致。

### 低风险

1. **格式不规范**：补充附注格式、编号不规范。
2. **文字表述不严谨**：个别措辞不精准。
3. **底稿索引不完整**：与A3-5及相关底稿交叉引用缺失。
