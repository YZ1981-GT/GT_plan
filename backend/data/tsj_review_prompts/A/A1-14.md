# A1-14 完成阶段的分析性复核（续/内部控制关联）复核提示词

## 概述

本提示词针对完成阶段分析性复核续表（A1-14）的复核，聚焦补充分析程序的完整性、分析结果与内部控制评价及风险评估结论的关联印证、异常项目的追加程序落实。A1-14 作为 A1-13 的延伸，承担分部/科目层面的深化分析并与内部控制运行有效性结论相互印证，确保总体复核在整体与细项两个层面均得到覆盖。

**法规依据：**
- 《中国注册会计师审计准则第1313号——分析程序》
- 《中国注册会计师审计准则第1211号——通过了解被审计单位及其环境识别和评估重大错报风险》
- 《中国注册会计师审计准则第1231号——针对评估的重大错报风险采取的应对措施》

---

## tips

1. **续表分析应深化而非重复**：A1-14 应在 A1-13 整体复核基础上进行分部、分产品线或关键科目的深化分析，避免与整体复核简单重复。
2. **分析结果与内控评价相互印证**：分析发现的异常应与内部控制运行有效性结论关联，控制薄弱领域的异常波动需特别警觉。
3. **异常项目追加程序须落实**：续表分析识别的异常应确认是否已在实质性程序中追加应对，未应对的须补充程序。
4. **关注科目间勾稽关系**：分析应验证相关科目间的逻辑勾稽（如收入与应收、成本与存货、费用与负债），断裂的勾稽是错报信号。
5. **对比风险评估的初始预期**：续表分析结果应与风险评估阶段设定的预期比较，超出预期的偏差需重新评估风险应对充分性。
6. **记录需体现分析逻辑链**：从数据对比到异常识别、原因调查、结论形成的完整逻辑链须在底稿中清晰呈现。

## checklist

### 一、深化分析完整性

- [ ] 续表分析是否在整体复核基础上进行分部/科目层面深化
- [ ] 是否覆盖关键业务循环的核心科目
- [ ] 相关科目间勾稽关系是否验证（收入↔应收、成本↔存货等）
- [ ] 分析维度是否较 A1-13 有实质性补充

### 二、内控关联印证

- [ ] 分析发现的异常是否与内部控制评价结论关联
- [ ] 控制薄弱领域的异常波动是否特别关注
- [ ] 分析结果是否与控制测试结论相互印证
- [ ] 内控缺陷对财务数据的影响是否在分析中体现

### 三、异常应对落实

- [ ] 识别出的异常项目是否确认已在实质性程序中应对
- [ ] 未应对的异常是否已补充追加审计程序
- [ ] 追加程序的结果是否支持分析结论
- [ ] 是否存在异常识别但无后续处理的情况

### 四、预期比较与记录

- [ ] 分析结果是否与风险评估阶段的初始预期比较
- [ ] 超出预期的偏差是否重新评估风险应对充分性
- [ ] 分析逻辑链（数据→异常→原因→结论）是否记录完整
- [ ] 底稿是否与 A1-13、内控评价底稿建立交叉索引

## risk_areas

### 高风险

1. **续表与整体复核重复无增量**：A1-14 仅重复 A1-13 内容而无深化分析，未发挥细项复核作用。
2. **异常识别后无应对**：续表分析识别异常却未追加程序应对，程序链条断裂。
3. **内控薄弱领域异常被忽视**：控制存在缺陷的领域出现财务异常却未特别关注，重大错报风险未有效应对。
4. **科目勾稽断裂未追查**：相关科目间逻辑勾稽存在断裂但未识别追查，遗漏潜在错报。

### 中风险

1. **分析与内控结论脱节**：分析程序与内部控制评价各自独立，未形成相互印证。
2. **预期比较缺失**：续表分析未与风险评估初始预期对照，无法评价应对充分性。
3. **深化程度不足**：分析停留在较粗层面，未下沉到能发现问题的细项。

### 低风险

1. **分析逻辑链记录不完整**：底稿仅呈现结论而缺少中间分析过程。
2. **覆盖科目有遗漏**：个别非重大科目未纳入续表分析，不影响主要结论。
3. **索引引用不规范**：与 A1-13 及内控底稿的交叉索引表述不统一。
