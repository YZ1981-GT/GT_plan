# A5 财务报表支持程序表复核提示词

## 概述

本提示词针对报告阶段"财务报表支持程序表"（A5，报表整体勾稽支持）的复核，聚焦报表编制的完整性、报表间勾稽关系的准确性、报表数据与审定表的一致性及支持程序执行的充分性。财务报表支持程序是报告阶段验证报表整体正确性的枢纽程序，须确保资产负债表、利润表、现金流量表、所有者权益变动表相互勾稽，各表数据源自审定数，报表列报符合准则要求。

**法规依据：**
- 《企业会计准则第30号——财务报表列报》
- 《中国注册会计师审计准则第1301号——审计证据》
- 《中国注册会计师审计准则第1251号——评价审计过程中识别出的错报》

---

## tips

1. **四表勾稽是报表整体正确性的基础**：资产负债表、利润表、现金流量表、所有者权益变动表须相互勾稽，任一勾稽断裂均提示报表编制错误。
2. **报表数据须源自审定数**：报表各项目金额须能追溯至审定表和试算平衡表的审定数，而非管理层未审数据。
3. **报表列报须符合准则要求**：项目列报、分类、抵销、比较信息须符合CAS30列报准则，不当列报可能构成错报。
4. **期初数须与上年审定报表一致**：本期报表的期初数（比较信息）须与上年审定报表期末数一致。
5. **报表附注引用须完整**：报表主表项目对附注的引用须完整准确，报表与附注须一致。
6. **关注核心勾稽等式**：资产=负债+所有者权益、净利润传导至未分配利润、现金流量净额传导至货币资金变动等核心等式须验证。

## checklist

### 一、报表编制完整性

- [ ] 资产负债表、利润表、现金流量表、权益变动表是否齐备
- [ ] 报表各项目是否完整列示
- [ ] 合并报表与母公司报表是否均编制（如需）
- [ ] 报表附注是否完整
- [ ] 比较信息（上年数）是否列示

### 二、报表间勾稽准确性

- [ ] 资产负债表是否平衡（资产=负债+权益）
- [ ] 净利润是否正确传导至权益变动表和未分配利润
- [ ] 现金流量净额是否与货币资金变动勾稽
- [ ] 权益变动表期末数是否与资产负债表权益一致
- [ ] 详见A5-1报表勾稽关系核对

### 三、数据一致性

- [ ] 报表各项目金额是否与审定表勾稽
- [ ] 报表数据是否与试算平衡表审定数一致
- [ ] 期初数是否与上年审定报表期末数一致
- [ ] 报表数据是否反映全部审计调整（A2）

### 四、列报与程序

- [ ] 项目列报、分类是否符合CAS30要求
- [ ] 是否存在不当抵销
- [ ] 报表主表对附注引用是否完整准确
- [ ] 支持程序是否有编制人和复核人签字

## risk_areas

### 高风险

1. **资产负债表不平衡**：资产总计不等于负债与所有者权益总计，报表编制存在根本性错误。
2. **报表间勾稽断裂**：净利润、现金流量、权益变动等核心勾稽关系断裂，报表整体不可靠。
3. **报表数据未反映调整**：报表未纳入已确认的审计调整，报表数据失真。
4. **使用未审数据编表**：报表数据源自管理层未审数据而非审定数。

### 中风险

1. **期初数不勾稽**：本期期初数与上年审定报表期末数不一致。
2. **不当列报或抵销**：项目分类、列报或抵销不符合CAS30要求。
3. **报表与附注不一致**：报表主表数据与附注披露不一致。
4. **比较信息缺失或错误**：上年比较数据缺失或与上年报表不符。

### 低风险

1. **报表格式不规范**：报表格式、项目编排不完全规范。
2. **附注引用不完整**：主表对附注引用编号不完整。
3. **底稿索引不完整**：支持程序表与审定表、勾稽核对表交叉引用缺失。
