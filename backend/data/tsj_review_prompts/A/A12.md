# A12 审计程序A12（书面声明）复核提示词

## 概述

本提示词针对书面声明审计程序（A12）的复核，聚焦书面声明内容的完整性、声明日期与签署主体的适当性、声明与其他审计证据的一致性。CAS1341 要求注册会计师就管理层责任及特定认定取得书面声明，书面声明是必要的审计证据但不能替代其他证据，声明遗漏、日期不当或与审计证据矛盾会影响审计结论的支持基础。

**法规依据：**
- 《中国注册会计师审计准则第1341号——书面声明》
- 《中国注册会计师审计准则第1301号——审计证据》
- 《中国注册会计师审计准则第1501号——对财务报表形成审计意见和出具审计报告》

---

## tips

1. **声明内容须覆盖强制事项**：书面声明应涵盖管理层对编制财务报表的责任、提供全部相关信息、记录完整性等 CAS1341 要求的基础事项及各准则要求的专项声明。
2. **声明日期须尽量接近报告日**：书面声明日期应尽量接近但不得晚于审计报告日，且不早于取得充分适当审计证据之日。
3. **签署主体须适当**：书面声明应由负有财务报表责任并了解相关事项的管理层（通常为管理层负责人及财务负责人）签署。
4. **专项声明须完整**：涉及关联方、诉讼、期后事项、持续经营、公允价值、舞弊等的专项声明应完整包含。
5. **声明不能替代其他证据**：书面声明是补充证据，不得作为可获取其他充分适当证据事项的唯一依据。
6. **声明与证据矛盾须处理**：书面声明与其他审计证据不一致时，须调查并评估对声明可靠性及审计意见的影响。

## checklist

### 一、声明内容完整性

- [ ] 是否包含管理层对编制财务报表责任的声明
- [ ] 是否声明已提供全部相关信息和资料
- [ ] 是否声明所有交易均已记录并反映在报表中
- [ ] 各准则要求的专项声明是否完整（关联方/诉讼/期后/持续经营/舞弊等）
- [ ] 声明事项是否与本项目审计范围匹配

### 二、日期与签署主体

- [ ] 书面声明日期是否尽量接近审计报告日
- [ ] 声明日期是否不晚于审计报告日
- [ ] 声明日期是否不早于取得充分适当审计证据之日
- [ ] 签署主体是否为负有财务报表责任的管理层

### 三、声明与证据一致性

- [ ] 书面声明是否与其他审计证据一致
- [ ] 不一致事项是否已调查并评估影响
- [ ] 是否将书面声明不当作为唯一证据依据
- [ ] 声明是否与 A11 期后、A15 持续经营等专项底稿衔接

### 四、可靠性与记录

- [ ] 是否评估管理层作出声明的能力与诚信
- [ ] 管理层拒绝提供声明的情形是否恰当处理
- [ ] 声明取得过程与评估是否记录充分
- [ ] 底稿是否与相关专项底稿建立交叉索引

## risk_areas

### 高风险

1. **强制声明事项遗漏**：书面声明未涵盖管理层责任或准则要求的专项声明，必要审计证据缺失。
2. **声明与审计证据矛盾未处理**：书面声明与其他证据明显不一致却未调查评估，声明可靠性存疑。
3. **以声明替代其他证据**：将本可获取其他证据的事项仅依赖书面声明，证据充分性不足。
4. **声明日期不当**：声明日期晚于报告日或早于证据取得日，声明与审计工作时序脱节。

### 中风险

1. **专项声明不完整**：关联方、诉讼、公允价值等专项声明有遗漏。
2. **签署主体不适当**：声明由不负有相应责任或不了解事项的人员签署。
3. **管理层诚信评估不足**：未评估管理层作出声明的能力与诚信基础。

### 低风险

1. **声明格式不规范**：声明格式与事务所模板存在偏差，不影响内容完整性。
2. **取得过程记录简略**：书面声明取得过程记录不够详细。
3. **交叉索引不完整**：与期后事项、持续经营专项底稿的索引引用不完整。
