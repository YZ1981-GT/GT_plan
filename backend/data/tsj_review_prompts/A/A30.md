# A30 电子底稿归档检查表复核提示词

## 概述

本提示词针对报告阶段"电子底稿归档检查表"（A30，CAS1131审计工作底稿归档）的复核，聚焦归档完整性、归档时效性、归档后不当变动控制及归档记录的充分性。审计工作底稿归档是审计业务收尾的法定程序，须在审计报告日后规定期限内完成最终归整，确保底稿完整、真实、不可篡改，形成支持审计意见的完整证据档案。

**法规依据：**
- 《中国注册会计师审计准则第1131号——审计工作底稿》
- 《中国注册会计师审计准则第1121号——对财务报表审计实施的质量管理》
- 《中国注册会计师审计准则第1101号——注册会计师执行财务报表审计的总体目标》

---

## tips

1. **归档须在规定期限内完成**：CAS1131要求在审计报告日后规定期限（通常60天）内完成最终归整，逾期归档违反准则要求。
2. **底稿归档须完整**：支持审计意见的全部底稿（程序表、审定表、证据、沟通记录、复核记录）须完整归档，无遗漏。
3. **归档后不得不当变动**：最终归整完成后，底稿不得删除或废弃；确需修改须记录修改内容、时间、原因和人员。
4. **归档时点须清晰记录**：底稿归整完成日须明确记录，作为归档时效合规的证据。
5. **电子底稿完整性须保障**：电子底稿须有版本控制和访问权限管理，防止未授权修改，确保可追溯。
6. **关注报告日后新增底稿的处理**：报告日后至归档完成前新增或修改的底稿须记录原因，报告日后取得的新证据须评估是否影响已发表意见。

## checklist

### 一、归档完整性

- [ ] 支持审计意见的全部底稿是否归档
- [ ] 程序表、审定表、实质性证据是否齐备
- [ ] 沟通记录（治理层/管理层）是否归档
- [ ] 三级复核记录是否归档
- [ ] 调整分录、未调整错报汇总是否归档
- [ ] 是否存在应归档但遗漏的底稿

### 二、归档时效性

- [ ] 归档是否在审计报告日后规定期限内完成
- [ ] 底稿归整完成日是否明确记录
- [ ] 是否存在逾期归档情形及原因
- [ ] 归档进度是否与报告签发衔接

### 三、归档后变动控制

- [ ] 归档完成后底稿是否未被删除或废弃
- [ ] 归档后的修改是否记录内容、时间、原因、人员
- [ ] 电子底稿是否有版本控制和权限管理
- [ ] 是否存在未授权修改的迹象

### 四、归档记录充分性

- [ ] 归档检查表是否逐项核对底稿完整性
- [ ] 报告日后新增/修改底稿是否记录原因
- [ ] 报告日后新证据是否评估对意见的影响
- [ ] 归档检查是否有执行人和复核人签字

## risk_areas

### 高风险

1. **底稿归档不完整**：支持审计意见的关键底稿遗漏归档，证据档案不完整，无法支持已发表意见。
2. **逾期归档**：超过CAS1131规定期限归档，违反准则要求，构成质量管理缺陷。
3. **归档后不当删改**：最终归整后删除、废弃或未留痕修改底稿，破坏底稿真实性和完整性，属严重违规。
4. **报告日后新证据未评估**：报告日后取得的重大新证据未评估对已发表意见的影响。

### 中风险

1. **归档时点未记录**：底稿归整完成日未明确记录，无法证明归档时效合规。
2. **修改未留痕**：归档后的修改未记录内容、时间、原因、人员。
3. **电子底稿权限失控**：电子底稿缺乏版本控制或访问权限管理。
4. **新增底稿原因缺失**：报告日后新增或修改底稿未记录原因。

### 低风险

1. **检查表格式不规范**：归档检查表结构、栏目不规范。
2. **索引编排不完整**：归档底稿索引编排不完整。
3. **签字缺失**：归档检查表缺执行或复核签字。
