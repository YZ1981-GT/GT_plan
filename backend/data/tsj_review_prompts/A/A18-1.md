# A18-1 向监管部门报送审计小结的函复核提示词

## 概述

本提示词针对报告阶段"向监管部门报送审计小结的函"（A18-1）的复核，聚焦审计小结内容的准确性、与审计报告结论的一致性、报送时效及沟通记录的充分性。审计小结是对审计工作范围、重点、结论的浓缩表述，报送监管部门后成为监管了解审计情况的重要依据，其内容必须客观、准确、与底稿证据充分对应。

**法规依据：**
- 《中国注册会计师审计准则第1151号——与治理层的沟通》
- 《中国注册会计师审计准则第1301号——审计证据》
- 《中国注册会计师审计准则第1101号——注册会计师执行财务报表审计的总体目标》

---

## tips

1. **审计小结结论须与审计报告严格对应**：小结中关于审计意见、重大事项、关键审计事项的表述必须与正式审计报告一致，不得存在结论松紧不一的情形。
2. **小结内容须有底稿证据支持**：小结中提及的审计发现、重点关注领域、结论判断，均应能追溯至相应审计底稿，杜绝无据陈述。
3. **报送时效是合规硬约束**：审计小结报送须在监管期限内完成，复核时核对报送日期与期限要求。
4. **重大事项披露须充分**：小结应完整反映审计过程中识别的重大不确定性、重大调整、内控缺陷等关键信息，不得选择性省略。
5. **表述客观中立**：小结用语应客观、专业，避免主观夸大或淡化，防止误导监管判断。
6. **关注小结与治理层沟通内容的衔接**：报送监管的小结与向治理层沟通的内容应口径一致，避免同一事项对内对外表述矛盾。

## checklist

### 一、小结内容准确性

- [ ] 审计小结描述的审计范围是否与实际执行的审计工作一致
- [ ] 小结中的财务数据是否与已审财务报表一致
- [ ] 小结提及的审计发现是否均有底稿证据支持
- [ ] 小结中的重点关注领域是否与风险评估结论对应
- [ ] 是否存在夸大或淡化审计发现的表述

### 二、与审计报告一致性

- [ ] 小结的审计意见表述是否与正式审计报告一致
- [ ] 关键审计事项是否与审计报告中披露的KAM一致
- [ ] 重大不确定性事项披露是否与审计报告一致
- [ ] 被审计单位名称、报表期间是否与审计报告一致

### 三、重大事项披露充分性

- [ ] 识别的重大调整事项是否在小结中反映
- [ ] 重大内部控制缺陷是否在小结中说明
- [ ] 持续经营重大不确定性（如有）是否披露
- [ ] 与治理层沟通的重大事项是否口径一致

### 四、报送时效与记录

- [ ] 小结报送日期是否在监管要求期限内
- [ ] 报送函是否加盖公章及签章
- [ ] 报送回执或签收记录是否完整归档
- [ ] 底稿索引是否与审计报告、治理层沟通底稿建立引用

## risk_areas

### 高风险

1. **小结结论与审计报告不一致**：小结中审计意见或重大事项表述与正式报告矛盾，误导监管并引发执业责任。
2. **重大事项选择性省略**：审计识别的重大调整、内控缺陷或不确定性未在小结中充分反映，构成披露不充分。
3. **无据陈述**：小结中的审计发现或结论缺乏底稿证据支持，存在虚假或臆断风险。
4. **逾期报送**：超监管期限报送审计小结，触发合规风险。

### 中风险

1. **表述主观失衡**：小结用语夸大或淡化审计发现，影响监管客观判断。
2. **对内对外口径不一**：报送监管的小结与向治理层沟通内容表述矛盾。
3. **财务数据引用错误**：小结中列示的数据与已审报表存在偏差。
4. **签章或回执缺失**：报送文件缺章或无签收凭证。

### 低风险

1. **小结格式不规范**：结构编排、用语规范等问题不影响内容准确性。
2. **底稿索引不完整**：小结底稿与相关底稿交叉引用缺失。
3. **专业术语使用不严谨**：个别措辞不够精准但不影响整体理解。
