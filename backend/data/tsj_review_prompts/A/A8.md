# A8 审计程序A8复核提示词

## 概述

本提示词针对报告阶段"审计程序A8"（报告阶段核对类程序）的复核，聚焦核对程序执行的完整性、核对结果的准确性、差异追查的充分性及核对记录的充分性。A8作为报告阶段的核对类审计程序，承载报表编制收尾环节的数据核对与验证工作，须系统核对报表、审定表、明细底稿之间的数据一致性，任何核对差异均须追溯解决，确保报告阶段数据链条完整闭环。

**法规依据：**
- 《中国注册会计师审计准则第1301号——审计证据》
- 《企业会计准则第30号——财务报表列报》
- 《中国注册会计师审计准则第1251号——评价审计过程中识别出的错报》

---

## tips

1. **核对程序须系统覆盖数据链条**：核对应系统覆盖报表→审定表→试算平衡表→明细底稿的数据传递链条，任一环节断裂均须查明。
2. **核对结果须逐项记录**：每一核对项的核对对象、核对结果（一致/差异）须逐项记录，不得仅记录总体结论。
3. **核对差异须零容忍追查**：任何核对差异均须追溯原因并解决，差异未解决不得进入报告签发。
4. **核对须基于审定后数据**：核对对象须为纳入审计调整后的审定数据，确保核对结果反映最终审计结论。
5. **交叉核对须多点验证**：同一数据在多处出现时须多点交叉核对，验证一致性。
6. **关注核对程序对遗漏错报的识别作用**：核对不仅验证一致性，异常差异可能揭示遗漏的错报或调整。

## checklist

### 一、核对程序完整性

- [ ] 核对是否覆盖报表与审定表的一致性
- [ ] 核对是否覆盖审定表与试算平衡表的一致性
- [ ] 核对是否覆盖审定表与明细底稿的勾稽
- [ ] 核对是否覆盖附注与主表的一致性
- [ ] 核对项是否系统列示无遗漏

### 二、核对结果准确性

- [ ] 每一核对项结果是否逐项记录
- [ ] 核对对象是否为审定后数据
- [ ] 核对金额是否准确比对
- [ ] 交叉核对是否多点验证一致
- [ ] 是否存在核对结果记录不实

### 三、差异追查充分性

- [ ] 是否存在核对差异项
- [ ] 核对差异是否逐笔追溯原因
- [ ] 差异原因是否有证据支持
- [ ] 差异是否已修正或合理解释
- [ ] 未解决差异是否阻止报告签发

### 四、核对记录充分性

- [ ] 核对程序是否系统记录核对项和结果
- [ ] 核对过程是否留痕
- [ ] 核对是否有编制人和复核人签字
- [ ] 底稿索引是否与报表、审定表等底稿建立引用

## risk_areas

### 高风险

1. **核对差异未追查即签发**：存在未解决的核对差异但报告已签发，报表可能存在未识别错报。
2. **核对基于未审数据**：核对对象为未审数据，核对结果无法反映最终审计结论。
3. **核对结果记录不实**：核对结果记录与实际不符，掩盖数据不一致。
4. **数据链条断裂未查明**：报表→审定表→明细的数据传递断裂未查明原因。

### 中风险

1. **核对覆盖不全**：核对遗漏部分数据链条环节。
2. **差异解释无据**：核对差异解释缺乏证据支持。
3. **交叉核对不充分**：同一数据多处出现但未多点核对。
4. **核对流于形式**：核对仅勾选未实质比对。

### 低风险

1. **核对表格式不规范**：核对程序表列示、格式不规范。
2. **核对记录简略**：核对过程记录不充分。
3. **底稿索引不完整**：与报表、审定表等底稿交叉引用缺失。
