# A26-3 与治理层沟通（续）复核提示词

## 概述

本提示词针对报告阶段"与治理层沟通（续）"（A26-3）的复核，作为治理层沟通系列底稿的进一步延续，聚焦沟通事项的完整覆盖、结论一致性、时效性与记录充分性。A26-3承载治理层沟通的进一步补充或专项沟通内容，须与A26/A26-1/A26-2形成连贯统一的沟通链条，确保治理层沟通全过程完整、口径一致、有据可查。

**法规依据：**
- 《中国注册会计师审计准则第1151号——与治理层的沟通》
- 《中国注册会计师审计准则第1152号——向治理层和管理层通报内部控制缺陷》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **续沟通链条须连贯一致**：A26-3须与前序沟通底稿（A26/A26-1/A26-2）保持事项和结论的连贯，避免链条断裂或口径漂移。
2. **专项沟通事项须聚焦明确**：若A26-3为专项沟通（如特定重大事项深入沟通），须明确沟通主题和目的。
3. **沟通结论须有充分证据支持**：所有沟通所述发现和判断须追溯至底稿证据。
4. **沟通时效与报告协调**：续沟通须在审计报告签发前完成，涉及意见的须留出评估时间。
5. **沟通记录须完整可追溯**：时间、对象、内容、方式及治理层反馈均须记录归档。
6. **关注多轮沟通的累积效果**：多轮续沟通后须确认全部法定沟通事项已完整覆盖，无遗漏。

## checklist

### 一、沟通事项完整性

- [ ] A26-3沟通事项是否与前序沟通连贯
- [ ] 专项沟通主题（如有）是否明确
- [ ] 多轮沟通后法定事项是否全部覆盖无遗漏
- [ ] 治理层追加关注事项是否回应

### 二、结论一致性

- [ ] A26-3结论是否与前序沟通口径一致
- [ ] 沟通结论是否与审计报告一致
- [ ] 沟通所述调整/缺陷是否与A2/A9一致
- [ ] 数据引用是否与已审报表一致

### 三、时效性

- [ ] 续沟通是否在审计报告签发前完成
- [ ] 涉及意见影响的沟通是否留出评估时间
- [ ] 沟通时点是否与审计进度协调

### 四、记录充分性

- [ ] 沟通时间、对象、内容、方式是否记录
- [ ] 书面沟通是否有送达签收记录
- [ ] 治理层反馈是否记录并处理
- [ ] 底稿索引是否与前序沟通底稿建立引用

## risk_areas

### 高风险

1. **沟通链条断裂或口径漂移**：A26-3与前序沟通结论不连贯，暴露沟通过程管理混乱。
2. **法定事项累积遗漏**：多轮沟通后仍有法定沟通事项未覆盖。
3. **专项重大事项沟通不充分**：专项沟通未充分揭示重大问题或结论无据。
4. **涉及意见影响未评估**：续沟通揭示的问题未评估对审计意见的影响。

### 中风险

1. **续沟通不及时**：专项或补充沟通拖延。
2. **数据或结论引用偏差**：沟通中引用与已审报表或前序底稿不一致。
3. **书面沟通无签收**：书面续沟通缺送达记录。
4. **治理层反馈未处理**：反馈记录缺失或未评估。

### 低风险

1. **记录格式不规范**：沟通纪要格式不统一。
2. **底稿索引不完整**：与前序沟通底稿交叉引用缺失。
3. **归档延迟**：沟通记录归档不及时。
