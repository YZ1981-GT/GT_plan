# A1-18 采用新金融工具准则衔接影响数核对复核提示词

## 概述

本提示词针对采用新金融工具准则衔接影响数核对（A1-18）的复核，聚焦新旧金融工具准则过渡调整的完整性、衔接影响数计算的准确性、追溯调整与豁免选择的恰当性及披露充分性。新金融工具准则（CAS22/23/24/37）采用涉及金融资产重分类、预期信用损失模型转换等重大过渡调整，衔接影响数计算错误或披露不足将影响期初留存收益及比较信息的可靠性。

**法规依据：**
- 《企业会计准则第22号——金融工具确认和计量》
- 《企业会计准则第37号——金融工具列报》
- 《中国注册会计师审计准则第1511号——比较信息：对应数据和比较财务报表》
- 《中国注册会计师审计准则第1301号——审计证据》

## tips

1. **明确采用日与过渡方法**：应核实新准则首次采用日、是否追溯调整比较信息或采用累积影响法调整期初留存收益，方法选择须一致适用。
2. **重分类路径须逐项核对**：金融资产按业务模式与合同现金流量特征（SPPI）重分类的路径须逐项验证，分类结果影响后续计量。
3. **预期信用损失转换完整**：由已发生损失模型转为预期信用损失（ECL）模型的影响须完整计算，覆盖所有适用金融资产。
4. **衔接影响数勾稽期初权益**：过渡调整净影响应完整反映在期初留存收益或其他综合收益，与调整后期初余额勾稽一致。
5. **豁免与简化处理合规**：采用准则允许的过渡豁免或简化处理（如不重述比较信息）须符合条件并一致适用。
6. **披露充分性核对**：新准则采用的会计政策变更、衔接影响数、重分类调节表须在附注中充分披露。

## checklist

### 一、过渡方法与采用日

- [ ] 新准则首次采用日是否明确且正确
- [ ] 过渡方法（追溯重述/累积影响法）是否明确
- [ ] 过渡方法选择是否符合准则规定并一致适用
- [ ] 是否采用过渡豁免/简化处理及其合规性

### 二、重分类准确性

- [ ] 金融资产按业务模式的重分类是否逐项验证
- [ ] SPPI（合同现金流量特征）测试结论是否有依据
- [ ] 重分类前后科目对应关系是否正确
- [ ] 重分类对计量属性（摊余成本/公允价值）的影响是否正确

### 三、衔接影响数计算与勾稽

- [ ] 预期信用损失模型转换影响是否完整计算
- [ ] 覆盖的金融资产范围是否完整
- [ ] 过渡调整净影响是否完整反映在期初留存收益/OCI
- [ ] 调整后期初余额是否与衔接影响数勾稽一致

### 四、披露充分性

- [ ] 会计政策变更是否在附注充分披露
- [ ] 衔接影响数及重分类调节表是否披露
- [ ] 比较信息是否重述及重述披露是否充分
- [ ] 底稿是否与相关金融工具科目底稿、附注建立交叉索引

## risk_areas

### 高风险

1. **衔接影响数计算错误**：过渡调整金额计算有误，直接导致期初留存收益及比较信息错报。
2. **重分类路径判断错误**：金融资产业务模式或 SPPI 判断错误，导致后续计量属性错误，影响多期损益。
3. **预期信用损失转换遗漏**：ECL 模型转换未覆盖全部适用金融资产，减值计提不足。
4. **过渡调整未反映至期初权益**：衔接影响数未完整调整期初留存收益/OCI，期初余额失真。

### 中风险

1. **过渡方法适用不一致**：追溯重述与累积影响法混用或前后不一致，调整口径混乱。
2. **豁免选择不合规**：采用的过渡豁免或简化处理不符合准则条件。
3. **披露不充分**：会计政策变更与衔接影响数披露不完整，报表使用者难以理解过渡影响。

### 低风险

1. **重分类调节表格式不规范**：调节表列示格式欠规范但数据准确。
2. **披露表述不够清晰**：附注披露文字表述可优化，不影响信息完整性。
3. **交叉索引不完整**：衔接核对底稿与金融工具科目底稿的索引引用不完整。
