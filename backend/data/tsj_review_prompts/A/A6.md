# A6 组成部分会计师报告程序表复核提示词

## 概述

本提示词针对报告阶段"组成部分会计师报告程序表"（A6，集团审计，CAS1401）的复核，聚焦组成部分工作的评估完整性、组成部分报告结论的利用适当性、集团审计证据的充分性及沟通记录的充分性。集团审计中集团项目组须对组成部分注册会计师的工作范围、独立性、胜任能力进行评估，充分参与并复核重要组成部分的审计工作，确保组成部分审计证据充分支持集团审计意见。

**法规依据：**
- 《中国注册会计师审计准则第1401号——对集团财务报表审计的特殊考虑》
- 《中国注册会计师审计准则第1301号——审计证据》
- 《企业会计准则第33号——合并财务报表》

## tips

1. **组成部分重要性划分须恰当**：须正确识别重要组成部分（财务重大或特定风险重大），对不同类型组成部分实施不同性质和范围的工作。
2. **组成部分会计师胜任与独立性须评估**：集团项目组须了解组成部分注册会计师的专业胜任能力、独立性及执业环境，作为利用其工作的前提。
3. **集团项目组参与程度须充分**：对重要组成部分，集团项目组须充分参与（如参与风险评估、复核底稿、现场走访），参与不足将削弱集团审计证据。
4. **组成部分报告须评估其结论**：组成部分注册会计师报告的结论、发现、未更正错报须评估并汇总至集团层面。
5. **组成部分间的合并抵销须协调**：组成部分层面的调整须与集团合并抵销协调，避免重复或遗漏。
6. **关注组成部分重大发现的传导**：组成部分识别的重大错报、内控缺陷、舞弊迹象须传导至集团审计结论和治理层沟通。

## checklist

### 一、组成部分工作评估完整性

- [ ] 组成部分重要性划分是否恰当（重要/非重要）
- [ ] 组成部分注册会计师胜任能力是否评估
- [ ] 组成部分注册会计师独立性是否评估
- [ ] 对重要组成部分集团项目组参与程度是否充分
- [ ] 组成部分工作范围是否满足集团审计要求

### 二、报告结论利用适当性

- [ ] 组成部分注册会计师报告是否取得
- [ ] 组成部分报告结论是否评估
- [ ] 组成部分未更正错报是否汇总至集团层面
- [ ] 组成部分审计发现是否评估对集团的影响
- [ ] 组成部分报告的限制或保留是否评估

### 三、集团审计证据充分性

- [ ] 集团项目组对重要组成部分的复核是否记录
- [ ] 组成部分证据是否充分支持集团审计意见
- [ ] 组成部分与集团合并抵销是否协调
- [ ] 非重要组成部分的分析程序是否执行

### 四、沟通记录充分性

- [ ] 集团项目组与组成部分注册会计师的沟通是否记录
- [ ] 组成部分指令（集团审计要求）是否下达并记录
- [ ] 组成部分重大发现是否传导至集团结论和治理层
- [ ] 底稿索引是否与合并程序表（A3）建立引用

## risk_areas

### 高风险

1. **重要组成部分参与不足**：集团项目组对重要组成部分参与程度不足，集团审计证据缺乏支持。
2. **组成部分胜任独立性未评估**：未评估即依赖组成部分注册会计师工作，利用前提缺失。
3. **组成部分重大发现未汇总**：组成部分识别的重大错报或缺陷未汇总至集团层面，集团审计意见失据。
4. **组成部分重要性划分错误**：重要组成部分误判为非重要，工作范围严重不足。

### 中风险

1. **组成部分报告结论未评估**：取得组成部分报告但未评估其结论对集团的影响。
2. **未更正错报未汇总**：组成部分未更正错报未汇总至集团整体错报评估。
3. **合并抵销不协调**：组成部分调整与集团合并抵销存在重复或遗漏。
4. **集团指令缺失**：未向组成部分下达明确的集团审计要求。

### 低风险

1. **沟通记录不完整**：与组成部分注册会计师沟通记录简略。
2. **参与记录格式不规范**：集团项目组参与记录格式不规范。
3. **底稿索引不完整**：与合并程序表交叉引用缺失。
