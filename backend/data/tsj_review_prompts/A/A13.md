# A13 错报汇总程序表复核提示词

## 概述

本提示词针对错报汇总程序表（A13）的复核，聚焦已识别错报归集的完整性、已更正与未更正错报的准确划分、错报累计影响与重要性水平比较的恰当性。CAS1251 要求注册会计师累积审计过程中识别的错报并评价其对财务报表的影响，错报归集遗漏、分类错误或重要性比较不当会导致对财务报表整体错报的评价失真，直接影响审计意见。

**法规依据：**
- 《中国注册会计师审计准则第1251号——评价审计过程中识别出的错报》
- 《中国注册会计师审计准则第1221号——计划和执行审计工作时的重要性》
- 《中国注册会计师审计准则第1301号——审计证据》

## tips

1. **错报归集须完整**：审计过程中识别的所有错报（事实错报、判断错报、推断错报）均应归集至汇总表，来源底稿的错报不得遗漏。
2. **已更正与未更正准确划分**：错报应准确划分为已更正（已调整入账）与未更正（管理层拒绝或不重要未调整）两类，划分错误影响未更正错报评价。
3. **推断错报须合理外推**：基于抽样等程序识别的错报应合理外推至总体，推断错报的计算方法须恰当。
4. **累计影响与重要性比较**：未更正错报应汇总（含前期未更正错报对本期的影响）并与整体重要性水平及各类交易/账户/披露的重要性比较。
5. **定性错报同样评价**：除金额错报外，分类、列报、披露等定性错报也须评价其重大性，不得仅关注金额。
6. **与治理层沟通与声明衔接**：未更正错报须与治理层沟通（A10）并取得管理层书面声明（A12），确认其认为不重要。

## checklist

### 一、错报归集完整性

- [ ] 各实质性程序底稿识别的错报是否均已归集至 A13
- [ ] 事实错报、判断错报、推断错报是否分类归集
- [ ] 错报来源、性质、金额、涉及科目是否清晰记录
- [ ] 是否存在底稿已发现但未归集的错报

### 二、已更正/未更正划分

- [ ] 已更正错报是否已确认调整入账（与 AJE/RJE 勾稽）
- [ ] 未更正错报是否记录管理层不调整的原因
- [ ] 划分是否准确、无已更正误列为未更正（反之）
- [ ] 借贷方向与金额是否正确

### 三、推断错报与累计评价

- [ ] 抽样错报是否合理外推至总体
- [ ] 推断错报计算方法是否恰当
- [ ] 未更正错报是否汇总（含前期未更正错报影响）
- [ ] 累计错报是否与整体重要性水平比较
- [ ] 是否与各类交易/账户/披露的重要性比较

### 四、定性评价与沟通

- [ ] 分类、列报、披露等定性错报是否评价重大性
- [ ] 未更正错报是否与治理层沟通（A10 衔接）
- [ ] 管理层书面声明是否确认未更正错报不重要（A12 衔接）
- [ ] 底稿是否与调整分录汇总、重要性底稿建立交叉索引

## risk_areas

### 高风险

1. **错报归集遗漏**：底稿识别的错报未归集至汇总表，累计错报评价基础不完整，可能出具不当意见。
2. **推断错报未外推**：抽样识别的错报未合理外推至总体，低估实际错报影响。
3. **累计错报超重要性未处理**：未更正错报累计已超过重要性水平却未要求调整或评估意见影响。
4. **已更正/未更正误划分**：错报分类错误导致未更正错报评价失真。

### 中风险

1. **前期未更正错报影响遗漏**：未考虑前期未更正错报对本期的累计影响。
2. **定性错报被忽视**：仅关注金额错报，忽视分类、披露等定性错报的重大性。
3. **未更正原因记录不足**：管理层不调整的原因未记录或记录不充分。

### 低风险

1. **错报描述不够具体**：错报来源、性质描述简略，影响复核理解。
2. **汇总表格式不规范**：错报汇总列示格式欠规范但数据准确。
3. **交叉索引不完整**：与调整分录、重要性、治理层沟通底稿的索引引用不完整。
