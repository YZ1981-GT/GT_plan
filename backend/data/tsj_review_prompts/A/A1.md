# A1 审计程序（完成阶段总程序表）复核提示词

## 概述

本提示词针对完成阶段总程序表（A1）的复核，聚焦完成阶段各审计程序是否完整执行、各底稿间交叉索引是否闭环、审计结论是否有充分证据支持。A1 是完成/报告阶段的总控底稿，汇集分析性复核、期后事项、书面声明、错报评价、持续经营、重大事项等收官程序，任一程序遗漏或索引断裂都将影响审计意见的合理性。

**法规依据：**
- 《中国注册会计师审计准则第1101号——注册会计师的总体目标和审计工作的基本要求》
- 《中国注册会计师审计准则第1301号——审计证据》
- 《中国注册会计师审计准则第1501号——对财务报表形成审计意见和出具审计报告》
- 《中国注册会计师审计准则第1601号——对按照特殊目的编制基础编制的财务报表审计的特殊考虑》

## tips

1. **完成阶段程序须逐项签署执行状态**：总程序表每一步骤应有明确的执行结论（已执行/不适用/待补充），空白项即视为程序未完成，不得默认跳过。
2. **交叉索引是完成阶段的骨架**：A1 引用的下级底稿（A11 期后、A12 声明、A13 错报、A15 持续经营、A17 重大事项）必须均已完成并建立可追溯索引。
3. **判断类结论须有底稿证据支撑**：涉及重大判断的步骤（意见类型、持续经营、KAM）不得仅凭勾选完成，须指向支持性分析底稿。
4. **未完成事项应归集于待办清单**：完成阶段发现的遗留问题应集中登记并跟踪至清零，避免在报告签发前存在未解决的重大事项。
5. **准则遵循性逐条核对**：完成阶段程序须覆盖 CAS1501 形成意见、CAS1251 错报评价、CAS1332 期后事项、CAS1341 书面声明等收官准则的强制要求。
6. **记录充分性影响复核质量**：程序执行记录应清晰、可复核，执行人、复核人、日期齐全，避免"程序做了但记录缺失"的实质性缺陷。

## checklist

### 一、程序执行完整性

- [ ] 完成阶段各审计程序是否逐项标注执行状态（已执行/不适用/待补充）
- [ ] 标注"不适用"的程序是否说明依据且判断合理
- [ ] 是否存在应执行而未执行的完成阶段程序
- [ ] 各程序步骤是否均由执行人签署并经现场经理复核
- [ ] 程序执行时点是否在报告日之前的合理期间内

### 二、交叉索引与底稿闭环

- [ ] A1 引用的下级底稿是否均已完成（A11/A12/A13/A15/A17 等）
- [ ] 各步骤的底稿索引号是否准确、可追溯
- [ ] 完成阶段底稿与实质性程序阶段结论是否衔接一致
- [ ] 是否存在引用了不存在或未完成底稿的悬空索引

### 三、判断与结论支持

- [ ] 审计意见类型的判断是否有充分底稿证据支持
- [ ] 重大事项、持续经营、KAM 等判断是否指向支持性分析
- [ ] 完成阶段发现的遗留问题是否已登记并跟踪解决
- [ ] 项目组内部及与治理层的沟通事项是否已完整记录

### 四、准则遵循与记录充分性

- [ ] 完成阶段程序是否覆盖 CAS1501/1251/1332/1341/1324/1504 强制要求
- [ ] 程序记录是否清晰完整、执行人复核人日期齐全
- [ ] 底稿是否存在实质性程序缺失或记录不充分
- [ ] 三级复核（现场经理/项目合伙人/质控复核）是否留痕

## risk_areas

### 高风险

1. **完成阶段程序遗漏**：期后事项、书面声明、错报评价等收官程序未执行，导致审计工作在报告签发前存在实质性缺口。
2. **意见类型判断无证据支持**：审计意见的形成缺乏底稿分析支撑，可能出具不恰当的审计意见。
3. **交叉索引断裂**：A1 引用的下级底稿未完成或索引悬空，完成阶段结论失去底稿基础。
4. **遗留问题未清零即签发报告**：存在未解决的重大事项或未跟踪的待办清单，报告签发时点条件不满足。

### 中风险

1. **程序执行记录不充分**：程序实际执行但记录缺失或含糊，无法在复核时验证程序的有效性。
2. **不适用判断依据不足**：将本应执行的程序标注为"不适用"却无合理依据，实质构成程序缺失。
3. **三级复核未留痕**：现场经理/项目合伙人/质控复核未在完成阶段程序表上留下复核痕迹。

### 低风险

1. **格式与编号不规范**：程序表步骤编号、状态标注格式不统一，影响底稿可读性。
2. **执行时点标注缺失**：程序执行日期未填写，不影响结论但影响时序可追溯性。
3. **索引引用表述不一致**：同一底稿在不同步骤引用时表述不统一，增加复核对照难度。
