# A26-4 与治理层沟通（续）复核提示词

## 概述

本提示词针对报告阶段"与治理层沟通（续）"（A26-4）的复核，作为治理层沟通系列底稿的收尾延续，聚焦沟通完整性的最终确认、结论一致性、时效性及沟通全过程记录的充分性。A26-4通常承载治理层沟通的最终总结或收尾确认内容，须对整个沟通过程进行闭环校验，确保CAS1151/1152要求的全部沟通事项均已完整、及时、有据地履行并记录。

**法规依据：**
- 《中国注册会计师审计准则第1151号——与治理层的沟通》
- 《中国注册会计师审计准则第1152号——向治理层和管理层通报内部控制缺陷》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **收尾沟通须完成闭环确认**：A26-4应对A26系列全部沟通事项进行清单式核对，确认法定事项无遗漏、结论已达成一致。
2. **最终结论须与审计报告完全对应**：收尾沟通的总结性结论须与最终签发的审计报告口径完全一致。
3. **治理层最终反馈须记录**：治理层对整体审计结果的最终意见、确认或异议须完整记录归档。
4. **沟通时效须与报告签发衔接**：收尾沟通须在审计报告签发前完成，作为报告签发的前置条件之一。
5. **全过程记录须完整归档**：A26系列沟通的全部记录（书面/口头、送达/签收、反馈）须齐备并建立完整索引。
6. **关注未决事项的处理**：收尾时须确认沟通过程中的未决事项、治理层异议是否已妥善处理或记录。

## checklist

### 一、沟通完整性最终确认

- [ ] A26系列全部法定沟通事项是否清单式核对无遗漏
- [ ] 审计责任、范围、发现、独立性、内控缺陷是否全部覆盖
- [ ] 收尾沟通是否确认沟通事项已达成共识
- [ ] 未决事项是否明确处理或记录

### 二、结论一致性

- [ ] 收尾总结结论是否与最终审计报告一致
- [ ] 全部沟通口径是否前后连贯
- [ ] 调整、缺陷、KAM等是否与相应底稿一致
- [ ] 数据引用是否与已审报表一致

### 三、时效性

- [ ] 收尾沟通是否在审计报告签发前完成
- [ ] 沟通是否作为报告签发前置条件履行
- [ ] 时点是否与报告签发衔接

### 四、全过程记录充分性

- [ ] A26系列全部沟通记录是否齐备归档
- [ ] 治理层最终反馈是否记录
- [ ] 送达签收证据链是否完整
- [ ] 底稿索引是否与A26/A26-1/A26-2/A26-3建立完整引用

## risk_areas

### 高风险

1. **法定事项遗漏未被发现**：收尾闭环核对流于形式，未发现遗漏的法定沟通事项。
2. **收尾结论与报告矛盾**：最终总结结论与签发的审计报告口径不一致。
3. **报告先于沟通签发**：审计报告在收尾沟通完成前即签发，违反沟通前置要求。
4. **治理层异议未处理**：沟通中治理层的重大异议未妥善处理即出具报告。

### 中风险

1. **未决事项悬空**：沟通过程中的未决事项未在收尾时明确处理。
2. **全过程记录不完整**：A26系列部分沟通记录缺失，证据链断裂。
3. **最终反馈未记录**：治理层对整体审计结果的最终意见未记录。
4. **数据或结论引用偏差**：收尾沟通引用与相关底稿不一致。

### 低风险

1. **闭环核对清单不规范**：核对清单格式不完整。
2. **底稿索引不完整**：A26系列底稿交叉引用未形成完整链条。
3. **归档延迟**：收尾沟通记录归档不及时。
