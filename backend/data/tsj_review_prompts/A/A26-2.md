# A26-2 与治理层沟通（续）复核提示词

## 概述

本提示词针对报告阶段"与治理层沟通（续）"（A26-2）的复核，作为A26/A26-1治理层沟通的延续补充，聚焦补充沟通事项的完整性、沟通结论与底稿证据的一致性、沟通时效及记录充分性。续沟通底稿承载首次沟通之外新增或补充的沟通内容，须与主沟通底稿口径协调，共同构成完整的治理层沟通证据链。

**法规依据：**
- 《中国注册会计师审计准则第1151号——与治理层的沟通》
- 《中国注册会计师审计准则第1152号——向治理层和管理层通报内部控制缺陷》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **续沟通须与主沟通口径协调**：A26-2补充的内容须与A26/A26-1主沟通事项衔接一致，不得对同一事项前后表述矛盾。
2. **补充事项须有触发依据**：续沟通通常因新增审计发现、期后事项、治理层追问等触发，须记录触发原因及依据。
3. **续沟通时效须及时**：新识别的重大事项须及时补充沟通，不得拖延至报告签发后。
4. **续沟通结论须有底稿支持**：补充沟通所述发现和结论须追溯至相应底稿证据。
5. **续沟通记录须完整留痕**：补充沟通的时间、对象、内容、方式（书面/口头）须记录，与主沟通记录共同归档。
6. **关注续沟通对审计结论的影响**：若续沟通涉及重大新发现，须评估是否影响审计意见或需调整审计报告。

## checklist

### 一、补充沟通完整性

- [ ] 续沟通事项是否记录触发原因（新发现/期后事项/追问）
- [ ] 首次沟通后新增的重大事项是否补充沟通
- [ ] 补充沟通是否覆盖治理层关注的追加事项
- [ ] 是否存在应补充但遗漏的事项

### 二、口径一致性

- [ ] 续沟通内容是否与A26/A26-1主沟通口径协调
- [ ] 是否存在同一事项前后表述矛盾
- [ ] 续沟通结论是否与审计报告一致
- [ ] 数据引用是否与已审报表一致

### 三、沟通时效性

- [ ] 新识别重大事项是否及时补充沟通
- [ ] 续沟通是否在审计报告签发前完成
- [ ] 期后事项相关沟通是否及时

### 四、记录充分性

- [ ] 续沟通的时间、对象、内容、方式是否记录
- [ ] 书面续沟通是否有送达签收记录
- [ ] 续沟通对审计结论的影响是否评估
- [ ] 底稿索引是否与A26/A26-1建立引用

## risk_areas

### 高风险

1. **续沟通与主沟通矛盾**：补充沟通对同一事项的表述与首次沟通不一致，暴露审计判断混乱。
2. **重大新发现未补充沟通**：首次沟通后识别的重大事项未及时补充沟通治理层。
3. **续沟通涉及意见影响未评估**：补充沟通揭示的重大问题未评估对审计意见的影响。
4. **无据补充陈述**：续沟通所述内容缺乏底稿证据支持。

### 中风险

1. **补充沟通不及时**：新事项拖延至报告签发后才沟通。
2. **触发依据缺失**：续沟通未记录触发原因。
3. **书面续沟通无签收**：补充书面沟通缺送达记录。
4. **数据引用偏差**：续沟通中数据与已审报表不一致。

### 低风险

1. **记录格式不规范**：续沟通纪要格式不统一。
2. **底稿索引缺失**：续沟通底稿与主沟通底稿交叉引用不完整。
3. **归档延迟**：续沟通记录归档不及时。
