# A7 关联方审计程序复核提示词

## 概述

本提示词针对报告阶段"关联方审计程序"（A7，CAS1323关联方）的复核，聚焦关联方识别的完整性、关联交易实质性程序的充分性、关联交易公允性评估及披露充分性。关联方及关联交易是财务报表舞弊和错报的高风险领域，须完整识别关联方、充分测试关联交易的真实性和公允性、防范通过关联方进行的利润操纵或资产转移，并确保披露完整。

**法规依据：**
- 《中国注册会计师审计准则第1323号——关联方》
- 《中国注册会计师审计准则第1301号——审计证据》
- 《企业会计准则第36号——关联方披露》

---

## tips

1. **关联方识别须穿透完整**：须通过工商登记、股权结构、章程、管理层声明、往来核查等多渠道穿透识别关联方，防止隐藏关联方及未披露关联关系。
2. **关注未披露的关联方关系**：警惕通过第三方、共同控制、关键管理人员近亲属等隐蔽形式存在的关联关系，重大异常交易的对手方须核查是否为关联方。
3. **关联交易真实性须验证**：关联交易须验证是否具有商业实质，警惕无商业实质的虚假交易用于粉饰业绩。
4. **关联交易公允性须评估**：关联交易定价是否公允须评估，非公允定价可能构成利益输送或利润操纵。
5. **超越正常经营的关联交易须重点关注**：非正常经营过程中的重大关联交易（如期末大额交易、异常条款交易）须作为舞弊风险重点审查。
6. **关联方披露须完整**：关联方关系、关联交易类型金额、未结算余额、定价政策须完整披露（详见A7-2）。

## checklist

### 一、关联方识别完整性

- [ ] 是否通过工商/股权/章程穿透识别关联方
- [ ] 是否取得管理层关联方声明
- [ ] 是否核查往来单位中的潜在关联方
- [ ] 关键管理人员及其近亲属是否识别
- [ ] 是否识别通过共同控制/重大影响的关联方
- [ ] 是否存在未披露的关联方关系

### 二、关联交易实质性程序充分性

- [ ] 关联交易是否完整识别并汇总（A7-1）
- [ ] 关联交易真实性（商业实质）是否验证
- [ ] 关联交易是否取得合同、凭证等证据
- [ ] 期末大额或异常关联交易是否重点核查
- [ ] 关联方资金往来是否核查（资金占用/拆借）

### 三、公允性评估

- [ ] 关联交易定价是否评估公允性
- [ ] 非公允定价是否评估其影响
- [ ] 是否识别通过关联方的利润操纵或利益输送
- [ ] 关联担保、代垫费用等是否评估

### 四、披露充分性

- [ ] 关联方关系是否完整披露
- [ ] 关联交易类型、金额是否披露
- [ ] 未结算关联方往来余额是否披露
- [ ] 关联方披露是否与附注（A7-2/A3-5）一致
- [ ] 关联方程序是否有编制人和复核人签字

## risk_areas

### 高风险

1. **未披露关联方遗漏**：隐藏的关联方关系或关联交易未识别，重大舞弊或利益输送风险被掩盖。
2. **虚假关联交易未识别**：无商业实质的关联交易用于粉饰业绩但未被识别，财务报表严重失实。
3. **非公允关联交易未评估**：关联交易非公允定价用于利润操纵但未评估其影响。
4. **关联方资金占用未查**：控股股东或关联方资金占用未识别，掩盖资产被侵占风险。

### 中风险

1. **识别渠道不全**：关联方识别渠道单一，未穿透股权和往来核查。
2. **关联交易证据不足**：关联交易缺乏合同、凭证等真实性证据。
3. **期末异常交易未重点核查**：期末大额或异常条款关联交易未作重点审查。
4. **公允性评估流于形式**：关联交易公允性评估未取得可比价格等依据。

### 低风险

1. **关联方清单不规范**：关联方清单编排、分类不规范。
2. **交易汇总不完整**：关联交易汇总（A7-1）个别项目遗漏。
3. **底稿索引不完整**：与A7-1、A7-2、附注交叉引用缺失。
