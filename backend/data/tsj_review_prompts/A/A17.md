# A17 重大事项概要程序表（关键审计事项）复核提示词

## 概述

本提示词针对重大事项概要程序表（A17）的复核，聚焦关键审计事项（KAM）识别的恰当性、KAM 应对程序与结论的支持性、KAM 在审计报告中描述的准确性。CAS1504 要求注册会计师从与治理层沟通过的事项中确定关键审计事项并在报告中沟通，KAM 识别不当、应对不足或描述失当会削弱审计报告的沟通价值并可能构成报告缺陷。

**法规依据：**
- 《中国注册会计师审计准则第1504号——在审计报告中沟通关键审计事项》
- 《中国注册会计师审计准则第1501号——对财务报表形成审计意见和出具审计报告》
- 《中国注册会计师审计准则第1151号——与治理层的沟通》

---

## tips

1. **KAM 从沟通事项中确定**：关键审计事项应从与治理层沟通过的事项中，选取审计中需要重点关注的事项确定，须体现"最为重要"的职业判断。
2. **重点关注领域优先考虑**：评估的较高重大错报风险领域、涉及重大管理层判断的领域、重大交易或事项应优先考虑作为 KAM。
3. **应对程序须充分记录**：每项 KAM 应记录其被确定为 KAM 的原因、审计中如何应对，应对程序须有底稿支持。
4. **KAM 描述须准确适当**：报告中 KAM 的描述应准确、不泄露不应披露的信息、不替代管理层披露，且与底稿应对一致。
5. **与意见类型协调**：KAM 沟通不改变审计意见，涉及保留/否定/无法表示意见的事项的处理须与 KAM 协调。
6. **无 KAM 情形须说明**：确定不存在需沟通的 KAM 时须有充分依据（如非上市实体或确无重点事项）。

## checklist

### 一、KAM 识别恰当性

- [ ] KAM 是否从与治理层沟通过的事项中确定
- [ ] 较高重大错报风险领域是否优先考虑
- [ ] 涉及重大管理层判断的领域是否考虑
- [ ] 重大交易或事项是否考虑
- [ ] KAM 选取是否体现"最为重要"的职业判断

### 二、应对程序与结论

- [ ] 每项 KAM 被确定为 KAM 的原因是否记录
- [ ] 审计中如何应对该 KAM 是否记录
- [ ] 应对程序是否有底稿支持
- [ ] KAM 应对结论是否与相关科目底稿一致

### 三、报告描述准确性

- [ ] 报告中 KAM 描述是否准确、与底稿应对一致
- [ ] 是否避免泄露不应披露的信息
- [ ] 是否避免替代管理层应有的披露
- [ ] KAM 是否指向财务报表相关披露

### 四、协调与记录

- [ ] KAM 沟通是否与审计意见类型协调
- [ ] 涉及保留/否定/无法表示意见事项的处理是否恰当
- [ ] 确定无 KAM 的情形是否有充分依据
- [ ] 底稿是否与风险评估、治理层沟通、报告底稿建立交叉索引

## risk_areas

### 高风险

1. **重大风险领域未列为 KAM**：评估的较高重大错报风险领域未被考虑为 KAM，KAM 识别未体现重点。
2. **KAM 应对无底稿支持**：报告披露的 KAM 应对程序在底稿中无对应支持，报告与底稿脱节。
3. **KAM 描述失当**：报告中 KAM 描述泄露不应披露信息或替代管理层披露，构成报告缺陷。
4. **KAM 与意见类型不协调**：涉及非无保留意见的事项处理与 KAM 沟通冲突。

### 中风险

1. **KAM 原因记录不足**：确定为 KAM 的原因记录不充分，判断依据不清。
2. **无 KAM 依据不足**：确定不存在 KAM 却缺乏充分依据。
3. **KAM 未指向披露**：KAM 描述未指向财务报表相关披露，可追溯性不足。

### 低风险

1. **KAM 描述冗长**：KAM 描述过于冗长或表述可优化。
2. **应对记录简略**：KAM 应对程序记录不够详细。
3. **交叉索引不完整**：与风险评估、治理层沟通、报告底稿的索引引用不完整。
