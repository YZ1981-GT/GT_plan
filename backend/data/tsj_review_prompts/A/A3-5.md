# A3-5 Word附注复核提示词

## 概述

本提示词针对报告阶段"Word附注"（A3-5，附注编制）的复核，聚焦附注披露的完整性、附注与报表主表的勾稽一致性、准则披露要求的遵循及附注编制的准确性。财务报表附注是报表不可分割的组成部分，须完整披露会计政策、重要科目明细、或有事项、关联方等信息，附注数据须与主表、审定表严格勾稽，披露内容须符合企业会计准则的披露要求。

**法规依据：**
- 《企业会计准则第33号——合并财务报表》
- 《企业会计准则第30号——财务报表列报》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **附注披露须完整覆盖准则要求**：会计政策、会计估计、重要科目明细、或有事项、承诺事项、关联方、期后事项等准则要求披露的内容须完整。
2. **附注数据须与主表勾稽**：附注中各科目金额须与资产负债表、利润表、现金流量表主表数据完全一致。
3. **附注明细合计须与审定表勾稽**：附注科目明细的合计数须与审定表（含合并抵销后）一致。
4. **会计政策披露须与实际执行一致**：披露的会计政策须与实际采用的政策一致，且与前期一致或说明变更。
5. **文字描述须准确规范**：附注文字表述须准确、规范，避免歧义或与数据矛盾。
6. **关注附注与主表的交叉引用**：主表项目对附注的引用编号须准确，便于报表使用者查阅。

## checklist

### 一、附注披露完整性

- [ ] 重要会计政策和会计估计是否完整披露
- [ ] 重要报表科目明细是否披露
- [ ] 或有事项、承诺事项是否披露
- [ ] 关联方及关联交易是否披露
- [ ] 期后事项、分部信息（如适用）是否披露
- [ ] 合并范围及变动是否披露

### 二、附注与主表勾稽

- [ ] 附注科目金额是否与资产负债表主表一致
- [ ] 附注科目金额是否与利润表主表一致
- [ ] 附注现金流量相关披露是否与现金流量表一致
- [ ] 主表对附注的交叉引用编号是否准确
- [ ] 附注合并数是否反映合并抵销

### 三、附注与审定表勾稽

- [ ] 附注科目明细合计是否与审定表一致
- [ ] 附注披露的调整是否与A2调整分录一致
- [ ] 附注关联方交易是否与关联方底稿（A7）一致
- [ ] 附注或有事项是否与A5-3或有事项底稿一致

### 四、披露准确性

- [ ] 披露的会计政策是否与实际执行一致
- [ ] 会计政策变更是否说明原因和影响
- [ ] 附注文字描述是否与数据一致
- [ ] 附注编制是否有编制人和复核人签字

## risk_areas

### 高风险

1. **附注披露重大遗漏**：准则要求披露的重大信息（或有事项、关联方、重大不确定性）遗漏，构成披露不充分。
2. **附注与主表不勾稽**：附注数据与报表主表不一致，破坏报表内部一致性。
3. **会计政策披露不实**：披露的会计政策与实际执行不符，误导报表使用者。
4. **附注掩盖重大风险**：或有负债、担保、诉讼等重大风险事项披露不充分或回避披露。

### 中风险

1. **附注明细与审定表不勾稽**：附注科目明细合计与审定表不一致。
2. **关联方披露不完整**：关联方或关联交易披露与A7底稿不一致。
3. **交叉引用错误**：主表对附注的引用编号错误或缺失。
4. **政策变更未说明**：会计政策变更未披露原因和影响。

### 低风险

1. **附注格式不规范**：附注编排、格式、编号不规范。
2. **文字表述不严谨**：个别措辞不够精准但不影响理解。
3. **底稿索引不完整**：附注底稿与主表、审定表交叉引用缺失。
