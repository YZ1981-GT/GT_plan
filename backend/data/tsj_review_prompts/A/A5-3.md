# A5-3 或有事项审计程序复核提示词

## 概述

本提示词针对报告阶段"或有事项审计程序"（A5-3，CAS13或有事项）的复核，聚焦或有事项识别的完整性、预计负债确认与计量的恰当性、或有负债/或有资产披露的充分性及审计程序执行的充分性。或有事项审计是报告阶段的重要程序，须完整识别未决诉讼、担保、产品质量保证等或有事项，恰当区分预计负债确认与或有事项披露，防止应确认负债未确认或重大或有风险未披露。

**法规依据：**
- 《企业会计准则第13号——或有事项》
- 《中国注册会计师审计准则第1301号——审计证据》
- 《中国注册会计师审计准则第1318号——期后事项》

## tips

1. **或有事项识别须多渠道**：须通过律师函证、管理层声明、董事会决议、合同审阅、税务核查等多渠道识别，防止未决诉讼、税务争议等遗漏。
2. **确认与披露须正确区分**：很可能（>50%）导致经济利益流出且金额能可靠计量的确认为预计负债；其余符合条件的作为或有负债披露；或有资产一般不确认。
3. **预计负债计量须合理**：预计负债金额须为履行义务所需支出的最佳估计，涉及多项目时按概率加权，涉及时间价值重大的须折现。
4. **律师函证是关键证据**：未决诉讼、仲裁的评估须取得律师函证，评估律师意见与管理层判断的一致性。
5. **或有负债披露须充分**：或有负债的性质、预计财务影响、不确定性因素须充分披露，极小可能的可不披露。
6. **关注或有事项的期后进展**：资产负债表日后或有事项的进展（判决、和解）须评估是否为调整事项或披露事项。

## checklist

### 一、或有事项识别完整性

- [ ] 是否取得律师函证识别未决诉讼/仲裁
- [ ] 是否取得管理层关于或有事项的声明
- [ ] 是否检查董事会决议、重大合同中的或有事项
- [ ] 对外担保、产品质量保证、环保等或有是否识别
- [ ] 税务争议、行政处罚等或有是否识别
- [ ] 是否存在应识别未识别的或有事项

### 二、确认与计量恰当性

- [ ] 很可能流出且可计量的义务是否确认为预计负债
- [ ] 预计负债金额是否为最佳估计（概率加权/折现）
- [ ] 预计负债是否与相关科目底稿勾稽
- [ ] 或有资产是否恰当处理（一般不确认）
- [ ] 确认与披露的区分是否恰当

### 三、披露充分性

- [ ] 或有负债性质、财务影响、不确定性是否披露
- [ ] 重大未决诉讼是否充分披露
- [ ] 对外担保或有是否披露
- [ ] 或有事项披露是否与附注（A3-5）一致

### 四、程序执行充分性

- [ ] 律师函证是否取得并评估律师意见
- [ ] 管理层评估与律师意见是否一致
- [ ] 期后进展是否评估（调整/披露事项）
- [ ] 或有事项程序是否有编制人和复核人签字

## risk_areas

### 高风险

1. **应确认预计负债未确认**：很可能导致经济利益流出的义务未确认为预计负债，低估负债和高估利润。
2. **重大或有负债未披露**：重大未决诉讼、担保或有负债未识别或未披露，隐藏重大潜在损失。
3. **未取得律师函证**：涉诉事项未取得律师函证即依赖管理层判断，证据不充分。
4. **确认与披露误判**：将应确认的预计负债仅作或有披露（或反之），确认披露错位。

### 中风险

1. **预计负债计量不当**：预计负债金额估计不合理，未按概率加权或未折现。
2. **识别渠道不全**：或有事项识别渠道单一，遗漏部分领域。
3. **律师意见与管理层不一致未处理**：律师评估与管理层判断分歧未追查。
4. **期后进展未评估**：资产负债表日后或有进展未评估影响。

### 低风险

1. **披露要素不完整**：或有负债披露要素（不确定性因素）不完整。
2. **函证索引不完整**：律师函证证据索引不完整。
3. **底稿索引不完整**：与附注、预计负债科目底稿交叉引用缺失。
