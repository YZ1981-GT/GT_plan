# A26-1 与治理层沟通函/记录复核提示词

## 概述

本提示词针对报告阶段"与治理层沟通函/记录"（A26-1）的复核，聚焦沟通函内容的完整准确性、送达与签收记录、与审计结论的一致性及沟通记录的可追溯性。沟通函是与治理层沟通的书面载体，须完整承载准则要求沟通的事项，并有送达、签收等证据链，确保沟通义务书面履行且可查证。

**法规依据：**
- 《中国注册会计师审计准则第1151号——与治理层的沟通》
- 《中国注册会计师审计准则第1152号——向治理层和管理层通报内部控制缺陷》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **沟通函内容须完整承载法定沟通事项**：沟通函应涵盖审计责任、审计范围、重大发现、独立性、内控缺陷等准则要求书面沟通的事项。
2. **沟通函须有送达与签收证据**：函件的发出、送达、治理层签收须留痕，形成书面履行沟通义务的完整证据链。
3. **沟通函结论须与审计报告一致**：沟通函所述审计发现和结论须与正式审计报告、审计小结口径一致。
4. **沟通函须由适当层级签发**：沟通函须由项目合伙人或授权人签发，收函方须为适当的治理层主体。
5. **沟通函日期须适当**：沟通函日期须与审计报告签发时点相协调，避免沟通滞后于报告。
6. **关注沟通函的回复与后续处理**：治理层对沟通函的书面回复须归档，涉及审计意见影响的须评估处理。

## checklist

### 一、沟通函内容完整性

- [ ] 沟通函是否载明注册会计师的审计责任
- [ ] 是否载明重大审计发现（会计政策/估计/调整/困难）
- [ ] 是否载明识别的重大内部控制缺陷
- [ ] 是否载明独立性相关声明
- [ ] 沟通函随附文件（如缺陷清单）是否齐备

### 二、送达与签收记录

- [ ] 沟通函发出是否有记录（邮寄/电子/当面）
- [ ] 治理层签收或接收回执是否归档
- [ ] 送达对象是否为适当的治理层主体
- [ ] 送达时间是否记录

### 三、与审计结论一致性

- [ ] 沟通函结论是否与审计报告一致
- [ ] 沟通函所述调整事项是否与A2一致
- [ ] 沟通函所述内控缺陷是否与A9一致
- [ ] 财务数据引用是否与已审报表一致

### 四、签发与记录

- [ ] 沟通函是否由适当层级人员签发
- [ ] 沟通函日期是否与审计报告时点协调
- [ ] 治理层书面回复是否归档
- [ ] 底稿索引是否与A26及相关底稿建立引用

## risk_areas

### 高风险

1. **沟通函内容缺失法定事项**：函件未涵盖准则要求书面沟通的事项，构成沟通义务未书面履行。
2. **无送达签收证据**：沟通函缺乏送达或签收记录，无法证明已实际送达治理层。
3. **沟通函结论与报告矛盾**：函件结论与正式审计报告口径不一致。
4. **送达对象错误**：沟通函送达管理层而非治理层，未达到与治理层沟通的目的。

### 中风险

1. **签发层级不当**：沟通函未由项目合伙人或授权人签发。
2. **沟通函日期滞后**：函件日期晚于审计报告签发，沟通失去及时性。
3. **随附文件缺失**：应随附的缺陷清单等文件未附。
4. **治理层回复未归档**：治理层书面反馈缺失或未妥善处理。

### 低风险

1. **函件格式不规范**：文书格式、抬头、落款不规范。
2. **底稿索引不完整**：沟通函底稿与A26等底稿交叉引用缺失。
3. **归档延迟**：签收回执归档不及时。
