# A18-2 与监管层沟通函复核提示词

## 概述

本提示词针对报告阶段"与监管层沟通函"（A18-2）的复核，聚焦沟通事项的完整性、沟通结论与底稿证据的一致性、沟通时效性及沟通记录的充分性。与监管层的沟通是审计报告收尾阶段的重要对外环节，沟通内容须客观、准确，沟通过程须留痕可查，确保沟通义务得到实质履行且有据可依。

**法规依据：**
- 《中国注册会计师审计准则第1151号——与治理层的沟通》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **沟通事项须完整覆盖监管关注领域**：与监管层沟通应涵盖监管关注的重大事项、审计发现、合规情况，遗漏关键领域将影响沟通有效性。
2. **沟通内容须与审计结论对应**：沟通函所述审计发现和结论须与审计报告、审计小结口径一致，并能追溯至底稿证据。
3. **沟通时效性须满足监管要求**：沟通须在监管规定或约定时点前完成，复核时核对沟通日期。
4. **沟通记录须双向留痕**：不仅记录事务所发出的沟通内容，也应记录监管层的反馈或答复，形成完整沟通闭环。
5. **敏感事项沟通须谨慎准确**：涉及重大风险、违规线索等敏感事项的沟通须表述精准，避免歧义或过度解读。
6. **关注沟通授权与层级适当性**：沟通函的签发人须具备相应授权，沟通层级须与事项重要程度匹配。

## checklist

### 一、沟通事项完整性

- [ ] 沟通函是否覆盖监管关注的全部重大事项
- [ ] 审计过程中识别的重大发现是否均已沟通
- [ ] 合规性事项、异常事项是否完整反映
- [ ] 是否存在应沟通但遗漏的事项

### 二、沟通内容准确性

- [ ] 沟通所述审计发现是否有底稿证据支持
- [ ] 沟通结论是否与审计报告、审计小结一致
- [ ] 沟通中的数据引用是否与已审报表一致
- [ ] 敏感事项表述是否精准无歧义

### 三、沟通时效性

- [ ] 沟通日期是否在监管要求或约定期限内
- [ ] 沟通安排是否与审计进度相衔接
- [ ] 紧急事项是否及时沟通

### 四、沟通记录充分性

- [ ] 沟通函发出记录是否完整
- [ ] 监管层反馈或答复是否记录归档
- [ ] 沟通闭环是否形成（发出-接收-反馈）
- [ ] 沟通函签发人授权是否适当
- [ ] 底稿索引是否与相关底稿建立引用

## risk_areas

### 高风险

1. **重大事项漏沟通**：应向监管层沟通的重大审计发现或风险事项遗漏，导致沟通义务未实质履行。
2. **沟通结论与审计报告矛盾**：沟通内容与正式审计结论口径不一致，引发监管质疑和执业责任。
3. **敏感事项表述失当**：违规线索或重大风险的沟通表述含糊或过度，可能误导监管或引发纠纷。
4. **无据沟通**：沟通所述发现缺乏底稿证据支持。

### 中风险

1. **沟通不及时**：未在监管要求时点前完成沟通。
2. **沟通记录单向**：仅记录发出内容，缺少监管层反馈记录。
3. **签发授权不当**：沟通函签发人层级或授权不足。
4. **数据引用偏差**：沟通中数据与已审报表不一致。

### 低风险

1. **沟通函格式不规范**：文书格式问题不影响沟通实质。
2. **底稿索引缺失**：沟通底稿与相关底稿交叉引用不完整。
3. **归档不及时**：沟通记录归档存在延迟。
