# A5-4 审定表复核提示词

## 概述

本提示词针对报告阶段"审定表A5-4"（报表支持类审定表）的复核，聚焦审定数据的准确性、与报表及试算平衡表的勾稽、审计调整的完整反映及审定记录的充分性。A5-4作为报表支持程序序列中的审定表，承载报表相关事项的审定汇总，须确保审定数据源自充分证据、经过审计调整、与报表主表和试算平衡表严格勾稽，为财务报表列报提供可靠数据基础。

**法规依据：**
- 《企业会计准则第30号——财务报表列报》
- 《中国注册会计师审计准则第1301号——审计证据》
- 《中国注册会计师审计准则第1251号——评价审计过程中识别出的错报》

---

## tips

1. **审定数据须经审计调整**：A5-4审定数须为纳入全部相关审计调整（AJE/RJE）后的数据，而非未审数。
2. **审定表须与报表主表勾稽**：审定数据须与财务报表相应项目勾稽一致，作为报表列报的支持。
3. **审定表须与试算平衡表勾稽**：审定数须与试算平衡表对应科目审定数一致。
4. **未审→调整→审定链路须完整**：审定表须清晰体现未审数、调整数、审定数的完整链路，链路断裂提示数据来源不清。
5. **审定依据须有证据支持**：审定数的确定须有充分审计证据支持，杜绝无据审定。
6. **关注审定表与相关支持底稿的衔接**：A5-4须与A5支持程序表、A5-1勾稽核对表等衔接一致。

## checklist

### 一、审定数据准确性

- [ ] A5-4审定数是否为纳入审计调整后的数据
- [ ] 未审数、调整数、审定数链路是否完整
- [ ] 审定数是否有充分证据支持
- [ ] 是否存在未审数据混入审定表

### 二、勾稽核对

- [ ] 审定数是否与财务报表主表勾稽
- [ ] 审定数是否与试算平衡表审定数一致
- [ ] 审定数是否与相关明细底稿勾稽
- [ ] 期初数是否与上年审定数据一致

### 三、审计调整反映

- [ ] 影响本表的AJE调整是否完整反映
- [ ] 影响本表的RJE调整是否完整反映
- [ ] 调整后金额是否等于未审数加调整数
- [ ] 是否存在调整遗漏

### 四、审定记录充分性

- [ ] 审定过程是否留痕
- [ ] 审定依据的证据索引是否完整
- [ ] 审定表是否有编制人和复核人签字
- [ ] 底稿索引是否与A5支持程序表建立引用

## risk_areas

### 高风险

1. **审定数与报表不勾稽**：A5-4审定数与财务报表主表不一致，报表列报缺乏审定支持。
2. **审计调整遗漏**：影响本表的调整未反映，审定数失真。
3. **使用未审数据**：审定表混入管理层未审数据，审定失去意义。
4. **审定无据**：审定数缺乏充分审计证据支持。

### 中风险

1. **与试算平衡表不勾稽**：审定数与试算平衡表对应科目不一致。
2. **未审调整审定链路断裂**：未审数、调整数、审定数链路不完整。
3. **期初数不勾稽**：审定表期初数与上年审定数据不一致。
4. **明细不勾稽**：审定数与相关明细底稿不一致。

### 低风险

1. **审定表格式不规范**：审定表列示、格式不规范。
2. **证据索引不完整**：审定依据证据索引不完整。
3. **底稿索引不完整**：与A5支持程序表交叉引用缺失。
