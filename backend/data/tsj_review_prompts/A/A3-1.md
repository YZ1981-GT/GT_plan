# A3-1 已审比率分析复核提示词

## 概述

本提示词针对报告阶段"已审比率分析"（A3-1）的复核，聚焦比率分析程序的完整性、异常比率的解释充分性、勾稽核对及分析结论对审计判断的支持性。已审比率分析是报告阶段基于审定（含合并）数据的整体分析程序，通过盈利能力、偿债能力、营运能力等关键比率的计算与比较，验证已审数据的合理性并识别潜在遗漏错报或持续经营迹象。

**法规依据：**
- 《中国注册会计师审计准则第1301号——审计证据》
- 《企业会计准则第33号——合并财务报表》
- 《中国注册会计师审计准则第1231号——针对评估的重大错报风险采取的应对措施》

---

## tips

1. **比率须基于审定/合并后数据**：A3-1分析对象为审定（含合并）数据，须确认数据已纳入全部调整和合并抵销。
2. **比率异常须有合理解释**：关键比率与上期、行业、预期的重大偏离须追溯原因，解释须与审计发现一致。
3. **比率分析须覆盖关键维度**：盈利能力、偿债能力、营运能力、成长能力等关键比率须计算齐全。
4. **比率须评估持续经营影响**：偿债能力比率（流动比率、资产负债率）异常须评估对持续经营假设的影响。
5. **比率勾稽须与报表数据一致**：比率计算所用分子分母须与已审报表数据一致，计算公式须正确。
6. **关注比率间的内在逻辑关系**：如毛利率与净利率、周转率与收入的逻辑关系，异常组合可能揭示未识别错报。

## checklist

### 一、比率分析完整性

- [ ] 比率所用数据是否为审定（含合并）后数据
- [ ] 盈利能力比率是否计算（毛利率/净利率/ROE）
- [ ] 偿债能力比率是否计算（流动比率/速动比率/资产负债率）
- [ ] 营运能力比率是否计算（周转率）
- [ ] 是否执行本期与上期、行业的比较

### 二、异常比率解释

- [ ] 重大偏离比率是否逐项分析原因
- [ ] 解释是否与已识别审计发现一致
- [ ] 解释是否有底稿证据支持
- [ ] 无法解释的异常是否追加程序

### 三、勾稽核对

- [ ] 比率分子分母是否与已审报表数据一致
- [ ] 比率计算公式是否正确
- [ ] 比率间内在逻辑关系是否核对
- [ ] 期初比率是否与上年审定数据一致

### 四、分析结论支持性

- [ ] 偿债能力异常是否评估持续经营影响
- [ ] 分析是否识别遗漏错报迹象
- [ ] 分析发现是否传导至审计结论
- [ ] 分析底稿是否有编制人和复核人签字

## risk_areas

### 高风险

1. **比率基于未审数据**：使用未审或未合并数据计算比率，分析结论失去意义。
2. **偿债能力异常未评估持续经营**：资产负债率或流动比率异常但未评估对持续经营假设的影响，遗漏重大不确定性。
3. **重大异常比率无解释**：关键比率重大偏离未分析或解释无据，遗漏潜在错报。
4. **比率逻辑组合异常被忽略**：毛利率与净利率、周转率与收入逻辑矛盾未追查。

### 中风险

1. **比率分析覆盖不全**：关键比率维度遗漏计算。
2. **计算公式错误**：比率分子分母口径或公式错误。
3. **期初比率不勾稽**：期初比率与上年审定数据不一致。
4. **分析流于形式**：比率计算后未形成有意义结论。

### 低风险

1. **分析说明不充分**：比率波动分析文字简略。
2. **格式不规范**：比率分析表格式、列示不规范。
3. **复核签字缺失**：分析底稿缺编制或复核签字。
