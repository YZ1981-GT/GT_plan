# A17-5-4 审计工作完成核对表（复核与签署）复核提示词

## 概述

本提示词针对审计工作完成核对表——复核与签署部分（A17-5-4）的复核，聚焦各级复核的落实确认、项目质量控制复核的执行、签署责任主体的到位。A17-5-4 专项核对复核环节的完成状况，确认现场经理复核、项目合伙人复核、项目质量控制复核（EQCR）均已按要求执行并留痕，是审计质量控制在完成阶段的收口核对。

**法规依据：**
- 《中国注册会计师审计准则第1101号——注册会计师的总体目标和审计工作的基本要求》
- 《中国注册会计师审计准则第1121号——对财务报表审计的质量管理》
- 《中国注册会计师审计准则第1131号——审计工作底稿》

---

## tips

1. **各级复核逐级确认**：应确认现场经理一级复核、项目合伙人复核、项目质量控制复核（EQCR）均已执行并留痕。
2. **EQCR 完成时点须在报告日前**：对要求实施项目质量控制复核的业务，EQCR 须在审计报告日之前完成。
3. **复核意见须处理闭环**：各级复核提出的意见应记录处理结果，未处理的复核意见须闭环解决。
4. **签署主体须适当**：报告签字注册会计师须为符合资质要求、实际参与并负责审计工作的人员。
5. **复核范围须充分**：复核应覆盖重大判断、重大风险领域、审计意见形成等关键事项，而非仅形式勾选。
6. **质量控制符合事务所政策**：复核与签署应符合事务所质量管理制度的要求。

## checklist

### 一、各级复核落实

- [ ] 现场经理一级复核是否确认已执行并留痕
- [ ] 项目合伙人复核是否确认已执行并留痕
- [ ] 要求 EQCR 的业务是否确认已执行项目质量控制复核
- [ ] EQCR 是否确认在审计报告日前完成

### 二、复核意见处理

- [ ] 各级复核提出的意见是否记录
- [ ] 复核意见的处理结果是否记录
- [ ] 未处理的复核意见是否闭环解决
- [ ] 重大分歧是否按事务所政策处理

### 三、复核范围充分性

- [ ] 复核是否覆盖重大判断领域
- [ ] 复核是否覆盖重大风险与 KAM 领域
- [ ] 复核是否覆盖审计意见形成过程
- [ ] 复核是否为实质性复核而非形式勾选

### 四、签署与合规

- [ ] 报告签字注册会计师资质是否符合要求
- [ ] 签字人是否实际参与并负责审计工作
- [ ] 复核与签署是否符合事务所质量管理制度
- [ ] 底稿是否与复核记录、EQCR 底稿建立交叉索引

## risk_areas

### 高风险

1. **EQCR 未在报告日前完成**：要求实施项目质量控制复核的业务，EQCR 未在报告日前完成即签发报告，质量控制程序缺失。
2. **各级复核未执行**：应执行的现场经理或合伙人复核未执行或未留痕，审计质量控制失效。
3. **复核意见未闭环**：重大复核意见未处理即签发报告，遗留未解决的质量问题。
4. **签字人资质不符**：报告签字注册会计师不符合资质要求或未实际参与审计。

### 中风险

1. **复核范围不足**：复核未覆盖重大判断或重大风险领域，实质性复核不充分。
2. **复核意见处理未记录**：复核意见的处理结果未记录，处理过程不可追溯。
3. **重大分歧处理不当**：项目组内部或与 EQCR 的重大分歧未按事务所政策处理。

### 低风险

1. **复核留痕形式不规范**：复核签署或留痕形式欠规范。
2. **复核记录简略**：复核过程与意见记录不够详细。
3. **交叉索引不完整**：与复核记录、EQCR 底稿的索引引用不完整。
