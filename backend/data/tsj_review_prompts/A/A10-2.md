# A10-2 沟通记录模板复核提示词

## 概述

本提示词针对治理层/管理层沟通记录（A10-2）的复核，聚焦沟通记录要素的完整性、沟通内容与实际发现的一致性、治理层回应及后续跟踪的记录充分性。A10-2 是沟通程序执行的证据载体，记录要素缺失或内容与底稿不符将削弱沟通程序的证明力，并影响审计档案的完整性。

**法规依据：**
- 《中国注册会计师审计准则第1151号——与治理层的沟通》
- 《中国注册会计师审计准则第1152号——向治理层和管理层通报内部控制缺陷》
- 《中国注册会计师审计准则第1131号——审计工作底稿》

---

## tips

1. **记录要素须完整**：沟通记录应载明沟通日期、方式、参加人员、沟通事项、治理层回应及后续行动，任一要素缺失影响证据完整性。
2. **内容须与审计发现一致**：沟通记录所载事项应与审计底稿中的实际发现、错报、缺陷一致，不得选择性省略重大事项。
3. **回应与跟踪须闭环**：治理层对沟通事项的回应应记录，涉及需整改或跟进的事项应记录后续跟踪结果。
4. **书面与口头沟通均须留痕**：口头沟通的重要事项也应转化为书面记录，注明沟通时点与见证。
5. **敏感事项记录审慎**：涉及舞弊、违法违规、管理层诚信的记录应客观、审慎、有据。
6. **签署与归档规范**：沟通记录应由相关注册会计师签署，并按审计档案管理要求及时归档。

## checklist

### 一、记录要素完整性

- [ ] 是否载明沟通日期与沟通方式（会议/函件/口头）
- [ ] 是否载明参加人员及其身份（治理层/管理层/项目组）
- [ ] 是否载明具体沟通事项
- [ ] 是否记录治理层/管理层的回应
- [ ] 是否记录需后续跟踪的行动事项

### 二、内容一致性

- [ ] 沟通记录事项是否与审计底稿实际发现一致
- [ ] 重大错报、内控缺陷是否完整反映于记录
- [ ] 是否存在选择性省略重大事项的情况
- [ ] 记录与 A10 沟通程序结论是否衔接

### 三、回应与跟踪闭环

- [ ] 治理层对重要事项的回应是否记录
- [ ] 需整改事项的后续跟踪结果是否记录
- [ ] 口头沟通的重要事项是否转化为书面记录
- [ ] 跟踪事项是否闭环或说明未闭环原因

### 四、签署与归档规范

- [ ] 沟通记录是否由相关注册会计师签署
- [ ] 敏感事项记录是否客观审慎、有据可查
- [ ] 记录是否按档案管理要求及时归档
- [ ] 底稿是否与 A10 及内控缺陷底稿建立交叉索引

## risk_areas

### 高风险

1. **重大事项记录缺失**：沟通记录选择性省略重大错报或内控缺陷，掩盖已沟通事项的真实内容。
2. **回应无记录**：治理层对重大事项的回应未记录，无法证明治理层已知悉并作出决策。
3. **口头重大沟通无书面留痕**：重要口头沟通未转化为书面记录，程序执行缺乏证据。

### 中风险

1. **记录要素不全**：沟通日期、参加人员等关键要素缺失，记录证明力不足。
2. **跟踪事项未闭环**：需整改事项无后续跟踪结果，沟通未形成闭环。
3. **内容与底稿不一致**：记录事项与审计底稿发现存在差异且未说明。

### 低风险

1. **签署或日期遗漏**：记录未签署或日期缺失，不影响内容但欠规范。
2. **归档不及时**：沟通记录未及时归入审计档案。
3. **索引引用不完整**：与 A10 沟通程序底稿的交叉索引缺失。
