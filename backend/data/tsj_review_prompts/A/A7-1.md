# A7-1 关联交易及往来汇总复核提示词

## 概述

本提示词针对报告阶段"关联交易及往来汇总"（A7-1）的复核，聚焦关联交易汇总的完整性、交易金额与往来余额的勾稽、汇总数据与披露的一致性及记录的充分性。关联交易及往来汇总是关联方审计的数据基础，须完整归集各类关联交易（购销、资金、担保、租赁等）及期末往来余额，汇总数据须与相关科目底稿勾稽，并作为关联方披露（A7-2）的数据来源。

**法规依据：**
- 《中国注册会计师审计准则第1323号——关联方》
- 《企业会计准则第36号——关联方披露》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **关联交易汇总须完整分类**：须按交易类型（购销商品、提供接受劳务、资金拆借、担保、租赁、代垫费用等）完整归集，遗漏任一类型将导致披露不完整。
2. **交易金额须与科目底稿勾稽**：关联交易金额须与收入、成本、往来等相应科目审计底稿勾稽一致。
3. **期末往来余额须准确**：与各关联方的期末应收、应付、其他往来余额须准确列示并与明细账勾稽。
4. **双向核对关联方与往来单位**：须将往来单位清单与关联方清单双向核对，确保关联方往来完整识别，非关联往来不误列。
5. **汇总数据须支持披露**：A7-1汇总数据须能直接支持A7-2披露和附注披露，数据口径须一致。
6. **关注资金占用与拆借的单独归集**：控股股东及关联方资金占用、拆借须单独归集，作为监管和披露重点。

---

## checklist

### 一、关联交易汇总完整性

- [ ] 购销商品/提供接受劳务交易是否汇总
- [ ] 资金拆借/资金占用是否汇总
- [ ] 关联担保是否汇总
- [ ] 租赁、代垫费用等其他交易是否汇总
- [ ] 是否按关联方逐一归集交易
- [ ] 是否存在遗漏的关联交易类型

### 二、金额与余额勾稽

- [ ] 关联交易金额是否与收入/成本科目底稿勾稽
- [ ] 期末应收/应付关联方余额是否与往来科目勾稽
- [ ] 关联方往来余额是否与明细账一致
- [ ] 汇总合计是否准确

### 三、往来核对

- [ ] 往来单位清单是否与关联方清单双向核对
- [ ] 关联方往来是否完整纳入汇总
- [ ] 非关联往来是否误列为关联
- [ ] 资金占用/拆借是否单独归集

### 四、披露一致性与记录

- [ ] 汇总数据是否与A7-2披露口径一致
- [ ] 汇总数据是否与附注披露一致
- [ ] 汇总是否有证据（合同/凭证/往来函证）支持
- [ ] 汇总表是否有编制人和复核人签字
- [ ] 底稿索引是否与A7、A7-2建立引用

## risk_areas

### 高风险

1. **关联交易类型遗漏**：某类关联交易（如担保、资金拆借）未归集，披露不完整，掩盖关联风险。
2. **资金占用未单独归集**：控股股东资金占用混入普通往来未单独反映，掩盖资产被侵占。
3. **汇总与科目底稿不勾稽**：关联交易金额与收入/成本/往来底稿不一致，数据不可靠。
4. **关联往来识别不完整**：往来单位未与关联方清单核对，关联方往来遗漏。

### 中风险

1. **期末余额不勾稽**：关联方往来余额与明细账不一致。
2. **非关联误列**：将非关联往来误列为关联交易。
3. **汇总证据不足**：关联交易汇总缺乏合同、凭证支持。
4. **披露口径不一致**：汇总数据与A7-2或附注披露口径不一致。

### 低风险

1. **汇总表格式不规范**：交易分类、列示格式不规范。
2. **归集颗粒度不当**：交易归集颗粒度过粗或过细。
3. **底稿索引不完整**：与A7、A7-2交叉引用缺失。
