# A5-1 相关报表勾稽关系核对复核提示词

## 概述

本提示词针对报告阶段"相关报表勾稽关系核对"（A5-1）的复核，聚焦勾稽关系覆盖的完整性、勾稽核对的准确性、勾稽差异的追查及核对记录的充分性。报表勾稽关系核对是验证财务报表内部一致性的专项程序，须系统核对四表之间及表内各项目的勾稽等式，任何勾稽差异均须追溯原因，确保报表数据形成严密的逻辑闭环。

**法规依据：**
- 《企业会计准则第30号——财务报表列报》
- 《中国注册会计师审计准则第1301号——审计证据》
- 《企业会计准则第31号——现金流量表》

---

## tips

1. **勾稽核对须系统覆盖核心等式**：资产=负债+权益、期初+本期变动=期末、净利润传导、现金流量传导等核心勾稽等式须逐一核对。
2. **勾稽差异须零容忍追查**：任何勾稽不平衡（即使金额较小）均须追溯原因，不得以"尾差"为由忽略。
3. **表内勾稽同样重要**：不仅表间勾稽，表内项目合计（如流动资产合计、营业利润构成）亦须核对。
4. **现金流量表勾稽是难点**：经营、投资、筹资活动现金流量净额之和加期初现金须等于期末现金，间接法调节须与净利润和资产负债变动勾稽。
5. **权益变动表勾稽须完整**：各权益项目期初+本期增减=期末，且与资产负债表权益、利润表净利润勾稽。
6. **关注跨表数据的多点勾稽**：同一数据在不同报表中出现时（如净利润、货币资金）须多点核对一致。

## checklist

### 一、勾稽关系覆盖完整性

- [ ] 资产负债表平衡等式是否核对
- [ ] 利润表构成等式（收入-成本费用=利润）是否核对
- [ ] 现金流量表勾稽（净额+期初=期末）是否核对
- [ ] 权益变动表勾稽（期初+变动=期末）是否核对
- [ ] 表内项目合计勾稽是否核对

### 二、勾稽核对准确性

- [ ] 净利润在利润表、权益变动表、现金流量表间是否一致
- [ ] 货币资金在资产负债表与现金流量表期末数是否一致
- [ ] 未分配利润期末数是否勾稽（期初+净利润-分配）
- [ ] 现金流量间接法调节是否与净利润和资产负债变动勾稽
- [ ] 期初数是否与上年审定报表勾稽

### 三、勾稽差异追查

- [ ] 是否存在勾稽不平衡的项目
- [ ] 勾稽差异是否逐笔追溯原因
- [ ] 差异原因是否有底稿证据支持
- [ ] 差异是否已修正或合理解释

### 四、核对记录充分性

- [ ] 勾稽核对表是否系统列示核对项和结果
- [ ] 核对过程是否留痕
- [ ] 核对是否有编制人和复核人签字
- [ ] 底稿索引是否与A5支持程序表建立引用

## risk_areas

### 高风险

1. **核心勾稽不平衡未追查**：资产负债表或现金流量表等核心勾稽不平衡但未追溯原因，报表存在未识别错误。
2. **净利润多点不一致**：净利润在各报表间列示不一致，暴露报表编制错误。
3. **勾稽差异被忽略**：以"尾差"为由忽略勾稽差异，可能掩盖系统性错误。
4. **现金流量勾稽错误**：现金流量表净额与货币资金变动不勾稽，现金流量表编制错误。

### 中风险

1. **勾稽覆盖不全**：核对遗漏部分核心等式或表内勾稽。
2. **间接法调节不勾稽**：现金流量间接法调节与净利润、资产负债变动不勾稽。
3. **权益变动勾稽错误**：权益项目期初期末变动勾稽错误。
4. **期初数不勾稽**：报表期初数与上年审定报表不一致。

### 低风险

1. **核对表格式不规范**：勾稽核对表列示不规范。
2. **核对记录简略**：核对过程记录不充分。
3. **底稿索引不完整**：与A5支持程序表交叉引用缺失。
