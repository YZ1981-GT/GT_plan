# A3 合并流程程序表复核提示词

## 概述

本提示词针对报告阶段"合并流程程序表"（A3，合并财务报表编制，CAS33）的复核，聚焦合并范围确定的完整性、合并抵销分录的准确性、合并勾稽核对及审计程序执行的充分性。合并财务报表编制是集团报表形成的关键环节，须正确确定合并范围、完整执行内部交易抵销、准确处理少数股东权益，并确保合并报表各要素勾稽平衡。

**法规依据：**
- 《企业会计准则第33号——合并财务报表》
- 《中国注册会计师审计准则第1401号——对集团财务报表审计的特殊考虑》
- 《中国注册会计师审计准则第1301号——审计证据》

## tips

1. **合并范围须基于控制判断完整确定**：合并范围以"控制"为基础，须评估对被投资单位的权力、可变回报及运用权力影响回报的能力，范围遗漏或多计均导致合并报表错误。
2. **内部交易抵销须完整**：集团内部往来、内部销售、内部投资、内部未实现损益须完整抵销，抵销不全将虚增合并资产、收入或利润。
3. **少数股东权益与损益须准确列示**：非全资子公司的少数股东权益和少数股东损益须按持股比例准确计算和列示。
4. **合并勾稽须闭环**：合并资产负债表、利润表、现金流量表、所有者权益变动表须相互勾稽，合并抵销分录借贷须平衡。
5. **母子公司报表期间与政策须统一**：纳入合并的子公司会计期间、会计政策须与母公司一致，不一致须调整。
6. **关注特殊事项对合并的影响**：报告期内的企业合并、处置、股权变动对合并范围和合并数的影响须正确处理。

## checklist

### 一、合并范围完整性

- [ ] 合并范围是否基于控制判断确定
- [ ] 全部应纳入合并的子公司是否完整纳入
- [ ] 结构化主体的合并判断是否执行（详见A3-3）
- [ ] 报告期内新增/处置子公司的合并处理是否正确
- [ ] 是否存在应合并未合并或不应合并却合并的主体

### 二、内部交易抵销准确性

- [ ] 集团内部往来是否完整抵销
- [ ] 内部销售收入与成本是否抵销
- [ ] 内部未实现损益（存货/固定资产）是否抵销
- [ ] 母公司长期股权投资与子公司权益是否抵销
- [ ] 内部投资收益与利润分配是否抵销

### 三、少数股东权益处理

- [ ] 少数股东权益是否按持股比例准确计算
- [ ] 少数股东损益是否准确列示
- [ ] 非全资子公司的抵销是否考虑少数股东部分
- [ ] 少数股东权益变动是否与权益变动表勾稽

### 四、合并勾稽与程序

- [ ] 合并抵销分录借贷是否平衡
- [ ] 合并资产负债表是否平衡
- [ ] 合并四表之间是否相互勾稽
- [ ] 子公司报表期间与政策是否统一（不一致是否调整）
- [ ] 合并程序是否有编制人和复核人签字

## risk_areas

### 高风险

1. **合并范围错误**：应合并主体遗漏或不应合并主体纳入，直接导致合并报表整体失真。
2. **内部交易抵销不全**：内部往来、销售、未实现损益抵销遗漏，虚增合并资产、收入或利润。
3. **合并报表不平衡**：合并抵销分录不平衡或合并资产负债表不平衡，破坏报表勾稽基础。
4. **控制判断错误**：对结构化主体或复杂股权结构的控制判断错误，合并范围认定失当。

### 中风险

1. **少数股东权益计算错误**：持股比例或计算基础错误导致少数股东权益/损益失真。
2. **会计政策未统一**：子公司政策与母公司不一致但未调整。
3. **未实现损益抵销不完整**：内部存货或固定资产未实现损益抵销遗漏。
4. **股权变动处理错误**：报告期内股权变动对合并的影响处理不当。

### 低风险

1. **抵销分录说明不充分**：抵销分录事由记录简略。
2. **合并工作底稿格式不规范**：合并工作表格式、勾稽标注不规范。
3. **底稿索引不完整**：合并程序表与子公司报表、抵销明细交叉引用缺失。
