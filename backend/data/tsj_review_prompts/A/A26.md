# A26 与治理层沟通复核提示词

## 概述

本提示词针对报告阶段"与治理层沟通"（A26，CAS1151与治理层沟通）的复核，聚焦沟通事项的完整性、沟通时点的适当性、沟通结论与审计发现的一致性及沟通记录的充分性。与治理层沟通是审计报告收尾阶段的法定程序，须就审计范围时间安排、重大审计发现、独立性、内控缺陷等准则要求事项与治理层充分沟通，并保留完整沟通记录。

**法规依据：**
- 《中国注册会计师审计准则第1151号——与治理层的沟通》
- 《中国注册会计师审计准则第1152号——向治理层和管理层通报内部控制缺陷》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **沟通事项须覆盖准则规定的全部内容**：CAS1151要求沟通审计责任、审计范围和时间安排、重大审计发现、独立性等，遗漏任一法定沟通事项即构成程序不完整。
2. **重大审计发现须充分沟通**：会计政策的适当性、重大会计估计、审计中遇到的重大困难、重大调整、内控缺陷等须完整、及时地向治理层通报。
3. **沟通时点须适当**：部分事项须在审计过程中及时沟通，报告阶段须就审计结论进行总结性沟通，时点滞后将削弱沟通有效性。
4. **书面沟通与口头沟通须区分并留痕**：准则要求书面沟通的事项（如独立性、重大内控缺陷）须有书面记录，口头沟通亦须记录时间、对象、内容。
5. **沟通对象须为适当的治理层**：确认沟通对象为具备治理职责的主体（董事会、审计委员会等），而非仅管理层。
6. **关注治理层反馈的处理**：治理层对沟通事项的反馈、意见须记录，涉及审计结论影响的须评估是否需调整审计策略或意见。

## checklist

### 一、沟通事项完整性

- [ ] 是否沟通了注册会计师对财务报表审计的责任
- [ ] 是否沟通了计划的审计范围和时间安排
- [ ] 是否沟通了审计中的重大发现（会计政策/估计/困难/调整）
- [ ] 是否沟通了识别的重大内部控制缺陷（CAS1152）
- [ ] 是否就独立性相关事项进行书面沟通
- [ ] 关键审计事项（如适用）是否与治理层沟通

### 二、沟通时点适当性

- [ ] 需及时沟通的事项是否在审计过程中及时通报
- [ ] 报告阶段是否进行总结性沟通
- [ ] 重大内控缺陷是否及时（而非拖延至报告末期）沟通
- [ ] 沟通时点是否与审计报告签发相衔接

### 三、沟通内容一致性

- [ ] 沟通的审计发现是否与底稿证据一致
- [ ] 沟通结论是否与审计报告口径一致
- [ ] 沟通的调整事项是否与A2调整分录汇总一致
- [ ] 沟通的内控缺陷是否与A9缺陷评价一致

### 四、沟通记录充分性

- [ ] 书面沟通事项是否有书面记录并送达治理层
- [ ] 口头沟通是否记录时间、对象、内容
- [ ] 沟通对象是否为适当的治理层主体
- [ ] 治理层反馈是否记录并妥善处理
- [ ] 沟通底稿是否与相关底稿建立交叉引用

## risk_areas

### 高风险

1. **法定沟通事项遗漏**：CAS1151要求的沟通事项未覆盖，构成审计程序缺失，可能影响审计质量责任认定。
2. **重大内控缺陷未沟通**：识别的重大缺陷未向治理层书面通报，违反CAS1152要求。
3. **沟通结论与审计报告矛盾**：向治理层沟通的结论与正式报告口径不一致，暴露审计判断不一致。
4. **独立性未书面沟通**：涉及独立性的事项未按准则要求书面沟通，构成独立性程序缺陷。

### 中风险

1. **沟通时点滞后**：应及时沟通的事项拖延至报告末期，削弱沟通有效性。
2. **沟通对象不当**：仅与管理层沟通而未与真正的治理层沟通。
3. **口头沟通未留痕**：口头沟通缺乏时间、对象、内容记录。
4. **治理层反馈未处理**：治理层提出的意见或反馈未记录或未评估影响。

### 低风险

1. **沟通记录格式不规范**：沟通纪要格式、结构不规范。
2. **底稿索引不完整**：沟通底稿与调整分录、内控缺陷等底稿交叉引用缺失。
3. **沟通清单不完整**：沟通事项清单未逐项对照准则要求列示。
