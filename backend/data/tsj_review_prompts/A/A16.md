# A16 审计程序A16（完成阶段核对复核）复核提示词

## 概述

本提示词针对完成阶段核对复核程序（A16）的复核，聚焦财务报表各表间勾稽核对的完整性、报表数据与审定表/试算平衡表的一致性、报表编制与附注披露的对应关系。A16 作为报告签发前的最终核对环节，验证财务报表内部及与底稿间的勾稽闭环，任一勾稽断裂或数据不一致均可能导致报表数据错误随报告对外发布。

**法规依据：**
- 《中国注册会计师审计准则第1131号——审计工作底稿》
- 《中国注册会计师审计准则第1301号——审计证据》
- 《中国注册会计师审计准则第1501号——对财务报表形成审计意见和出具审计报告》

---

## tips

1. **表间勾稽须全覆盖**：核对应覆盖资产负债表、利润表、现金流量表、所有者权益变动表之间的全部勾稽关系（如净利润↔未分配利润、期末现金↔资产负债表货币资金）。
2. **报表数与审定数一致**：财务报表各项目金额须与审定表、试算平衡表审定数完全一致，差异须追溯至汇总或调整。
3. **报表与附注对应**：报表项目金额须与附注披露金额对应一致，附注明细合计须等于报表项目金额。
4. **本期与比较期同步核对**：核对应同时覆盖本期数与比较期数，比较期数须与 A1-17 比较信息核对一致。
5. **勾稽公式逐项验证**：合计、小计、勾稽公式须逐项复算验证，避免手工汇总错误。
6. **最终核对基于终版报表**：核对应基于最终定稿的财务报表进行，任何后续修改须重新核对。

## checklist

### 一、表间勾稽核对

- [ ] 利润表净利润是否与所有者权益变动表本期利润勾稽
- [ ] 现金流量表期末现金是否与资产负债表货币资金勾稽
- [ ] 所有者权益变动表期末数是否与资产负债表所有者权益勾稽
- [ ] 资产总计是否等于负债与所有者权益总计
- [ ] 各表小计、合计公式是否逐项复算无误

### 二、报表与审定数一致性

- [ ] 资产负债表各项目是否与审定表/试算平衡表审定数一致
- [ ] 利润表各项目是否与审定数一致
- [ ] 现金流量表数据是否与相关底稿勾稽
- [ ] 是否存在报表已更新但底稿未同步（反之）的情况

### 三、报表与附注对应

- [ ] 报表项目金额是否与附注披露金额对应一致
- [ ] 附注明细合计是否等于报表项目金额
- [ ] 附注披露的分类是否与报表列报一致
- [ ] 重大会计政策与估计披露是否与报表处理一致

### 四、比较期与终版核对

- [ ] 比较期数据是否与 A1-17 比较信息核对一致
- [ ] 本期与比较期核对是否同步完成
- [ ] 核对是否基于最终定稿财务报表
- [ ] 底稿是否与审定表、附注、比较信息底稿建立交叉索引

## risk_areas

### 高风险

1. **表间勾稽断裂**：财务报表各表间勾稽关系不成立（如净利润与权益变动不符），报表存在编制错误。
2. **报表数与审定数不一致**：报表项目金额与审定表/试算平衡表不符，报表数据失去底稿支持。
3. **报表与附注不对应**：报表项目与附注披露金额不一致，信息内部矛盾。
4. **基于非终版核对**：核对基于中间版本报表，最终定稿后的修改未重新核对。

### 中风险

1. **勾稽公式复算遗漏**：合计、小计未逐项复算，可能存在手工汇总错误。
2. **比较期数据未核对**：仅核对本期数而遗漏比较期数据核对。
3. **附注明细合计不符**：附注明细合计与报表项目金额存在差异。

### 低风险

1. **核对记录简略**：核对过程记录不够详细。
2. **勾稽关系列示不全**：核对未列示全部勾稽关系，遗漏次要勾稽。
3. **交叉索引不完整**：与审定表、附注、比较信息底稿的索引引用不完整。
