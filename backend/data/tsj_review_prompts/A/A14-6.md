# A14-6 T4非财务报告内部控制缺陷评价复核提示词

## 概述

本提示词针对 T4 非财务报告内部控制缺陷评价（A14-6）的复核，聚焦非财务报告内控缺陷识别范围的界定、缺陷严重程度分级的适当性、非财报内控缺陷与财报审计关注点的边界处理。A14-6 关注与财务报告无直接关联但影响经营合规、运营效率的内部控制缺陷（如合规控制、经营控制），须在履行沟通义务的同时明确其与财务报表审计目标的边界。

**法规依据：**
- 《中国注册会计师审计准则第1152号——向治理层和管理层通报内部控制缺陷》
- 《中国注册会计师审计准则第1211号——通过了解被审计单位及其环境识别和评估重大错报风险》

---

## tips

1. **明确非财报内控范围**：A14-6 关注非财务报告内部控制（经营合规、运营效率类），须与财务报告内部控制（A14）的评价范围明确区分。
2. **审计目标边界须清晰**：财务报表审计的目标是财务报表整体是否公允，非财报内控缺陷通常不属于强制评价范围，识别到的应作管理建议式沟通。
3. **分级参照缺陷严重程度**：非财报内控缺陷可参照严重程度分级，但通报义务与财报内控缺陷存在差异，须区别处理。
4. **合规类缺陷关注间接影响**：非财报内控缺陷（如合规缺陷）可能间接影响财务报表（如导致罚款、诉讼），须评估其间接财务影响。
5. **管理建议为主**：非财报内控缺陷的沟通通常以管理建议形式提出，注重建设性与可操作性。
6. **避免超越审计职责**：不得将非财报内控缺陷评价扩大为内部控制审计，超越财务报表审计的职责范围。

## checklist

### 一、范围界定

- [ ] 非财务报告内控缺陷的识别范围是否明确
- [ ] 是否与财务报告内控缺陷（A14）范围明确区分
- [ ] 识别的缺陷是否属于非财报内控范畴
- [ ] 是否避免超越财务报表审计职责范围

### 二、缺陷识别与分级

- [ ] 识别的非财报内控缺陷是否记录清晰
- [ ] 缺陷严重程度是否参照适当标准分级
- [ ] 合规类缺陷的间接财务影响是否评估
- [ ] 是否存在间接影响财报的缺陷未评估

### 三、边界与关联处理

- [ ] 非财报内控缺陷与财报审计关注点边界是否清晰
- [ ] 可能间接影响财报的缺陷是否关联至财报风险评估
- [ ] 是否避免将评价扩大为内部控制审计
- [ ] 缺陷是否与 A14 财报内控缺陷底稿区分且无重复

### 四、沟通与记录

- [ ] 非财报内控缺陷是否以管理建议形式沟通
- [ ] 管理建议是否具建设性、可操作
- [ ] 沟通对象与方式是否恰当
- [ ] 底稿是否与 A14、A10 沟通底稿建立交叉索引

## risk_areas

### 高风险

1. **间接财务影响缺陷被忽视**：非财报内控缺陷（如重大合规缺陷）可能导致重大罚款/诉讼影响财报，却未评估间接影响。
2. **范围界定混乱**：非财报内控与财报内控缺陷混淆，导致评价范围与通报义务错误。
3. **超越审计职责**：将非财报内控缺陷评价扩大为内部控制审计，超出财务报表审计范围并产生额外责任。

### 中风险

1. **缺陷分级依据不足**：非财报内控缺陷分级缺乏明确标准。
2. **沟通方式不当**：非财报内控缺陷未以适当方式（管理建议）沟通。
3. **与财报内控缺陷重复**：同一缺陷在 A14 与 A14-6 重复列示。

### 低风险

1. **改进建议空泛**：管理建议缺乏可操作性。
2. **缺陷描述简略**：非财报内控缺陷描述不够具体。
3. **交叉索引不完整**：与 A14、A10 底稿的索引引用不完整。
