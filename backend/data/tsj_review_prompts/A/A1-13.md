# A1-13 完成阶段的分析性复核（整体复核）复核提示词

## 概述

本提示词针对完成阶段分析性复核（A1-13）的复核，聚焦总体复核程序是否覆盖财务报表整体、异常波动是否已充分调查解释、分析结论是否与审计过程中形成的了解相一致。CAS1313 要求在接近审计结束时运用分析程序进行总体复核，以评价财务报表整体是否与注册会计师对被审计单位的了解一致，是发现遗漏错报与识别持续经营迹象的最后防线。

**法规依据：**
- 《中国注册会计师审计准则第1313号——分析程序》
- 《中国注册会计师审计准则第1301号——审计证据》
- 《中国注册会计师审计准则第1324号——持续经营》

---

## tips

1. **总体复核须覆盖财务报表整体**：完成阶段分析程序应对资产负债表、利润表、现金流量表各主要项目进行整体性趋势与结构分析，而非局部科目分析。
2. **异常波动必须调查到位**：识别出的重大波动或异常关系应追溯至具体原因，取得管理层解释并与审计证据相互印证，不得仅记录波动而不解释。
3. **分析结论须与整体了解一致**：分析结果应与注册会计师在风险评估及实质性程序中形成的对被审计单位的了解相互印证，出现背离需重新评估。
4. **关注可能未识别的重大错报风险**：总体复核旨在发现前期程序遗漏的错报迹象，对预期外的波动或缺失波动均应保持职业怀疑。
5. **兼顾持续经营信号**：完成阶段分析应关注可能表明存在持续经营重大不确定性的财务指标（如流动比率、资产负债率、盈利趋势）。
6. **数据基础须为审定数**：分析程序应基于经审计调整后的审定数进行，确保结论建立在最终财务数据之上。

## checklist

### 一、程序覆盖完整性

- [ ] 完成阶段分析程序是否覆盖资产负债表主要项目
- [ ] 是否覆盖利润表主要项目及关键盈利指标
- [ ] 是否覆盖现金流量表结构与经营活动现金流质量
- [ ] 是否进行了本期与上期、预算/预期的多维度对比
- [ ] 关键财务比率（偿债/营运/盈利/发展能力）是否计算并分析

### 二、异常调查与解释

- [ ] 识别出的重大波动是否逐项调查原因
- [ ] 管理层解释是否取得并与审计证据相互印证
- [ ] 预期应出现而未出现的波动是否引起关注并分析
- [ ] 异常关系是否评估其是否表明存在未识别的重大错报风险

### 三、结论一致性

- [ ] 分析结果是否与风险评估阶段形成的了解一致
- [ ] 分析结果是否与实质性程序结论相互印证
- [ ] 出现背离时是否重新评估并追加程序
- [ ] 分析所用数据是否为经审计调整后的审定数

### 四、持续经营与记录

- [ ] 分析是否关注可能的持续经营重大不确定性信号
- [ ] 财务指标异常是否与 A15 持续经营底稿衔接
- [ ] 分析过程与结论是否记录充分、可复核
- [ ] 底稿是否建立与审定表、试算平衡表的交叉索引

## risk_areas

### 高风险

1. **总体复核流于形式**：仅计算比率而不分析原因，未真正发挥总体复核发现遗漏错报的作用。
2. **异常波动未调查**：识别出重大波动却未追查原因或取得解释，可能掩盖未识别的重大错报。
3. **分析结论与整体了解背离未处理**：分析结果与前期了解明显不一致却未重新评估，风险应对失效。
4. **持续经营信号被忽视**：财务指标已显示持续经营重大不确定性迹象但未在完成阶段识别并深入。

### 中风险

1. **分析基于未审数据**：分析程序使用未经调整的数据，结论未建立在最终审定数之上。
2. **管理层解释未印证**：接受管理层解释但未与其他审计证据相互印证，解释可靠性存疑。
3. **对比基准不当**：对比期间或预期基准选取不合理，导致波动分析失真。

### 低风险

1. **比率选取不全面**：分析使用的财务比率覆盖面不足，遗漏部分维度但不影响主要结论。
2. **记录简略**：分析过程记录过于简略，波动原因描述不够具体。
3. **交叉索引不完整**：分析底稿与审定表、持续经营底稿的索引引用不完整。
