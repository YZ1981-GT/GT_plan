# A17-5-1 审计工作完成核对表复核提示词

## 概述

本提示词针对审计工作完成核对表（A17-5-1）的复核，聚焦审计工作整体完成情况的系统核对、各阶段程序的落实确认、报告签发前置条件的满足性。A17-5-1 作为完成阶段核对表系列的总体核对环节，逐项确认从计划、执行到完成各阶段的关键程序是否均已落实，任一核对项未满足即表明审计工作尚未具备报告签发条件。

**法规依据：**
- 《中国注册会计师审计准则第1101号——注册会计师的总体目标和审计工作的基本要求》
- 《中国注册会计师审计准则第1131号——审计工作底稿》
- 《中国注册会计师审计准则第1501号——对财务报表形成审计意见和出具审计报告》

---

## tips

1. **核对项须逐项确认状态**：完成核对表每一项应有明确的确认状态（已完成/不适用/待办），不得留空，空白项视为未确认。
2. **覆盖审计全周期**：核对应覆盖计划、风险评估、控制测试、实质性程序、完成阶段全周期的关键程序落实情况。
3. **待办项须清零**：核对中标注为"待办"的项目须在报告签发前清零，未清零不得进入签发环节。
4. **核对以底稿为依据**：每项核对结论应以对应底稿的实际完成情况为依据，不得凭印象勾选。
5. **前置条件满足确认**：报告签发的前置条件（充分适当证据、错报评价、期后事项、书面声明等）须均已满足。
6. **签署确认责任**：核对表应由现场经理及项目合伙人签署确认，明确完成核对的责任主体。

## checklist

### 一、核对项完整性

- [ ] 完成核对表各项是否逐项确认状态（已完成/不适用/待办）
- [ ] 是否覆盖计划、执行、完成各阶段关键程序
- [ ] 标注"不适用"的项目是否说明依据
- [ ] 是否存在应确认而未确认的核对项

### 二、程序落实确认

- [ ] 风险评估与应对程序是否确认完成
- [ ] 实质性程序是否确认完成并取得充分证据
- [ ] 完成阶段程序（分析复核/期后/声明/错报/持续经营）是否确认完成
- [ ] 各核对结论是否以对应底稿实际完成情况为依据

### 三、待办清零与前置条件

- [ ] 标注"待办"的项目是否已跟踪清零
- [ ] 报告签发前置条件是否均已满足
- [ ] 未清零事项是否已评估对报告签发的影响
- [ ] 是否存在未解决的重大事项

### 四、签署与记录

- [ ] 核对表是否由现场经理签署确认
- [ ] 核对表是否由项目合伙人签署确认
- [ ] 核对过程与结论是否记录充分
- [ ] 底稿是否与各阶段程序底稿建立交叉索引

## risk_areas

### 高风险

1. **关键程序未落实即签发**：核对表显示关键程序未完成却进入报告签发，审计工作存在实质性缺口。
2. **待办事项未清零**：报告签发前存在未清零的待办核对项，签发前置条件不满足。
3. **核对凭印象勾选**：核对结论未以底稿实际完成情况为依据，核对流于形式。
4. **前置条件未满足**：报告签发的前置条件（充分证据/错报评价等）未满足即签发。

### 中风险

1. **核对项遗漏**：应确认的核对项未纳入核对表，覆盖不全。
2. **不适用依据不足**：将应完成项标注为"不适用"却无合理依据。
3. **签署不完整**：核对表缺少现场经理或项目合伙人签署。

### 低风险

1. **状态标注不清**：核对项状态标注不够明确。
2. **核对记录简略**：核对过程记录不够详细。
3. **交叉索引不完整**：与各阶段程序底稿的索引引用不完整。
