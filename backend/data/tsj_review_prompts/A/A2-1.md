# A2-1 已审资产负债表分析复核提示词

## 概述

本提示词针对报告阶段"已审资产负债表分析"（A2-1）的复核，聚焦分析程序执行的完整性、异常波动的解释充分性、勾稽核对及分析结论对审计判断的支持性。已审资产负债表分析是报告阶段的整体复核程序，通过对审定后资产负债表各项目的比较分析、趋势分析、比率分析，验证已审数据的合理性并识别遗漏错报的迹象。

**法规依据：**
- 《中国注册会计师审计准则第1301号——审计证据》
- 《中国注册会计师审计准则第1231号——针对评估的重大错报风险采取的应对措施》
- 《中国注册会计师审计准则第1251号——评价审计过程中识别出的错报》

---

## tips

1. **分析应基于审定后数据**：A2-1分析对象是审定数（已审），须确认所用数据已纳入全部调整分录，而非未审数。
2. **重大波动须有合理解释**：资产负债表各项目本期与上期、预期的重大差异须追溯原因，解释须与审计发现和底稿一致。
3. **分析程序须覆盖全部重大科目**：分析应覆盖所有重大资产、负债、权益项目，避免仅分析部分科目而遗漏异常。
4. **比率分析须评估合理性**：流动比率、资产负债率、周转率等关键比率须与行业、历史、预期比较，异常比率提示潜在错报或经营风险。
5. **分析结论须支持审计判断**：分析发现的异常若无法合理解释，须评估是否需追加审计程序或调整，分析不能流于形式。
6. **关注科目间的内在勾稽关系**：如应收账款与收入、存货与营业成本、固定资产与折旧的匹配关系，勾稽异常可能揭示未识别错报。

## checklist

### 一、分析程序完整性

- [ ] 分析所用数据是否为审定后（已审）数据
- [ ] 分析是否覆盖全部重大资产、负债、权益项目
- [ ] 是否执行了本期与上期的比较分析
- [ ] 是否执行了与预期（预算/行业）的比较分析
- [ ] 关键财务比率是否计算并分析

### 二、异常波动解释

- [ ] 重大波动项目是否逐项分析原因
- [ ] 波动解释是否与已识别的审计发现一致
- [ ] 波动解释是否有底稿证据支持
- [ ] 无法合理解释的异常是否追加了审计程序
- [ ] 是否存在异常波动被忽略未分析的情况

### 三、勾稽核对

- [ ] A2-1所列已审数据是否与审定表、试算平衡表一致
- [ ] 资产总计是否等于负债与所有者权益总计
- [ ] 科目间内在勾稽关系（应收/收入、存货/成本）是否核对
- [ ] 与已审利润表、现金流量表的勾稽关系是否核对
- [ ] 期初数是否与上年审定资产负债表一致

### 四、分析结论支持性

- [ ] 分析结论是否明确表述已审数据的合理性判断
- [ ] 分析是否识别出遗漏错报的迹象
- [ ] 分析发现的问题是否传导至审计结论或调整
- [ ] 分析程序是否有编制人和复核人签字

## risk_areas

### 高风险

1. **分析基于未审数据**：使用未纳入调整的未审数进行分析，导致分析结论失去意义并可能掩盖已审数据问题。
2. **重大异常无解释或解释无据**：资产负债表重大波动未分析或解释缺乏证据支持，遗漏潜在重大错报。
3. **资产负债表不平衡**：已审资产总计与负债权益总计不等，暴露审定数汇总错误。
4. **科目勾稽异常被忽略**：应收与收入、存货与成本等关键勾稽关系异常未追查，可能存在系统性错报。

### 中风险

1. **分析覆盖不全**：仅分析部分科目，遗漏重大项目的分析。
2. **比率异常未评估**：关键财务比率异常但未评估其对审计判断或持续经营的影响。
3. **期初数不勾稽**：A2-1期初数与上年审定报表不一致。
4. **分析流于形式**：分析未识别问题也未形成有意义结论，程序空转。

### 低风险

1. **分析说明不充分**：波动分析文字过于简略。
2. **格式不规范**：分析表格式、比率列示不规范。
3. **复核签字缺失**：分析底稿缺少编制或复核签字。
