# A7-2 关联方附注披露要求复核提示词

## 概述

本提示词针对报告阶段"关联方附注披露要求"（A7-2，CAS36关联方披露）的复核，聚焦关联方披露的完整性、披露内容与汇总数据的勾稽、披露口径的准确性及披露记录的充分性。关联方披露须完整反映关联方关系、关联交易类型金额、未结算余额及定价政策，披露内容须与关联交易汇总（A7-1）勾稽一致，符合CAS36的披露要求，确保报表使用者充分了解关联方影响。

**法规依据：**
- 《企业会计准则第36号——关联方披露》
- 《中国注册会计师审计准则第1323号——关联方》
- 《企业会计准则第30号——财务报表列报》

---

## tips

1. **关联方关系披露须完整**：须披露存在控制关系的关联方（无论有无交易）及本期发生交易的其他关联方，控制关系关联方即使无交易也须披露。
2. **关联交易披露要素须齐全**：关联交易须披露交易类型、金额、占同类交易比例、未结算项目金额及条款、定价政策等要素。
3. **披露须与A7-1汇总勾稽**：披露的关联交易金额、往来余额须与关联交易汇总（A7-1）数据一致。
4. **重大关联交易须单独披露**：重大关联交易不得以汇总方式笼统披露，须单独反映其性质和金额。
5. **未结算往来的坏账准备须披露**：关联方未结算应收款项计提的坏账准备须单独披露。
6. **关注定价政策披露的实质性**：关联交易定价政策披露须实质反映定价基础（市场价/成本加成/协议价），不得笼统表述。

## checklist

### 一、披露完整性

- [ ] 存在控制关系的关联方是否全部披露（无论有无交易）
- [ ] 本期有交易的其他关联方是否披露
- [ ] 关联方名称、关系类型是否披露
- [ ] 各类关联交易是否披露
- [ ] 未结算关联方往来余额是否披露

### 二、披露要素齐全性

- [ ] 关联交易类型、金额是否披露
- [ ] 关联交易占同类交易比例是否披露（如要求）
- [ ] 未结算项目金额、条款是否披露
- [ ] 关联交易定价政策是否披露
- [ ] 关联方应收款坏账准备是否单独披露

### 三、勾稽核对

- [ ] 披露的关联交易金额是否与A7-1汇总一致
- [ ] 披露的往来余额是否与A7-1一致
- [ ] 披露数据是否与附注（A3-5）一致
- [ ] 重大关联交易是否单独披露而非笼统汇总

### 四、披露记录充分性

- [ ] 披露口径是否准确（定价政策实质反映）
- [ ] 披露是否有A7-1汇总及证据支持
- [ ] 披露要求核对是否有编制人和复核人签字
- [ ] 底稿索引是否与A7、A7-1建立引用

## risk_areas

### 高风险

1. **控制关系关联方遗漏披露**：存在控制关系的关联方即使无交易也须披露但被遗漏，披露不符合CAS36。
2. **重大关联交易未披露或笼统披露**：重大关联交易未单独披露，掩盖关联影响。
3. **披露与汇总不勾稽**：披露金额与A7-1汇总数据不一致，披露数据不可靠。
4. **资金占用披露回避**：控股股东资金占用等敏感事项披露回避或淡化。

### 中风险

1. **披露要素不齐全**：交易金额、条款、定价政策等要素缺失。
2. **定价政策披露笼统**：定价政策未实质反映定价基础。
3. **坏账准备未单独披露**：关联方应收款坏账准备未单独反映。
4. **占比披露缺失**：关联交易占同类交易比例（如要求）未披露。

### 低风险

1. **披露格式不规范**：关联方披露表编排、分类不规范。
2. **关系类型表述不准**：关联关系类型描述不够精确。
3. **底稿索引不完整**：与A7、A7-1交叉引用缺失。
