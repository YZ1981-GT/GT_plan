# A18 向监管部门报送审计报告/小结的函复核提示词

## 概述

本提示词针对报告阶段"向监管部门报送审计报告及审计小结的函"（A18）的复核，聚焦报送内容完整性、口径一致性、报送时效性与沟通记录充分性。向监管部门报送是审计报告收尾阶段的对外沟通环节，报送文件必须与已签发的审计报告、财务报表、治理层沟通结论保持完全一致，任何口径偏差或报送遗漏均可能引发监管质询或合规风险。

**法规依据：**
- 《中国注册会计师审计准则第1151号——与治理层的沟通》
- 《中国注册会计师审计准则第1301号——审计证据》
- 《中国注册会计师审计准则第1101号——注册会计师执行财务报表审计的总体目标》

## tips

1. **报送内容必须与已签发审计报告完全一致**：报送函引用的审计意见类型、报告日期、被审计单位名称、报表期间须与正式审计报告逐字核对，不得出现口径差异。
2. **报送时效性是合规底线**：向监管部门报送须在监管规定或约定的期限内完成，复核时应核对报送日期与要求期限，评估是否存在逾期报送风险。
3. **报送范围应完整覆盖监管要求文件**：审计报告、审计小结、财务报表及附注、专项说明等监管要求随附的文件须齐备，遗漏任一附件均构成报送不完整。
4. **沟通记录须留痕可追溯**：报送函的发出、签收、回执等过程须有完整记录（邮寄凭证、电子回执、签收单），作为已履行报送义务的证据。
5. **报送对象与文号引用应准确**：收函监管部门名称、报送文号、被审计单位统一社会信用代码等关键标识须准确无误，错误标识可能导致报送无效。
6. **关注监管特殊披露要求的落实**：针对特定行业或事项监管部门可能有额外披露或说明要求，复核时应核实这些要求是否在报送文件中得到充分回应。

## checklist

### 一、报送内容完整性

- [ ] 报送函随附的审计报告是否为已签发的正式版本
- [ ] 报送范围是否涵盖监管要求的全部文件（报告/小结/报表/附注/专项说明）
- [ ] 报送函正文是否完整列示随附文件清单
- [ ] 是否存在应报送但遗漏的监管要求附件
- [ ] 报送文件是否加盖事务所公章及注册会计师签章

### 二、口径一致性核对

- [ ] 报送函引用的审计意见类型是否与正式审计报告一致
- [ ] 报送函载明的报告日期是否与审计报告日期一致
- [ ] 被审计单位名称、报表期间是否与审计报告一致
- [ ] 报送文号、监管部门名称、信用代码等标识是否准确
- [ ] 报送文件金额数据是否与已审财务报表一致

### 三、报送时效性

- [ ] 报送日期是否在监管规定或约定期限内
- [ ] 是否存在逾期报送情形及原因说明
- [ ] 报送安排是否与审计报告签发时点相衔接
- [ ] 加急或特殊时效要求是否得到满足

### 四、沟通记录充分性

- [ ] 报送函发出是否有完整凭证（邮寄单/电子回执/签收记录）
- [ ] 监管部门签收或接收回执是否已归档
- [ ] 报送过程中的沟通往来是否留痕
- [ ] 报送底稿索引与相关底稿（审计报告/治理层沟通）是否建立交叉引用

## risk_areas

### 高风险

1. **报送口径与审计报告不一致**：报送函引用的审计意见类型或报告日期与正式报告不符，可能误导监管判断并引发合规责任。
2. **报送内容遗漏**：应报送的监管要求文件缺失，导致报送不完整，可能构成未履行法定报送义务。
3. **逾期报送**：超过监管规定期限报送，可能触发监管处罚或影响被审计单位合规状态。
4. **报送对象或标识错误**：收函部门、报送文号、信用代码等关键标识错误，可能导致报送无效或错送。

### 中风险

1. **随附文件版本错误**：报送的审计报告或报表非最终签发版本，存在使用草稿或过期版本的风险。
2. **签章不完整**：报送文件未加盖公章或缺少注册会计师签章，影响文件法律效力。
3. **沟通记录缺失**：报送过程无回执或签收凭证，无法证明已履行报送义务。
4. **监管特殊要求未回应**：行业或事项特定披露要求未在报送文件中落实。

### 低风险

1. **报送函格式不规范**：文号编排、正文格式等不影响内容准确性，但影响文件规范性。
2. **底稿索引不完整**：报送底稿未与审计报告、治理层沟通底稿建立完整交叉引用。
3. **随附清单描述不清**：报送文件清单表述含糊，增加监管查阅难度。
