# A15 持续经营审计程序复核提示词

## 概述

本提示词针对持续经营审计程序（A15）的复核，聚焦持续经营评估的完整性、持续经营重大不确定性事项与情况的识别与应对、管理层评估期间与方法的适当性、审计意见与披露的恰当处理。CAS1324 要求注册会计师就管理层运用持续经营假设的适当性获取充分适当审计证据，并就是否存在重大不确定性得出结论，评估遗漏或结论错误将导致审计意见类型与披露处理不当。

**法规依据：**
- 《中国注册会计师审计准则第1324号——持续经营》
- 《中国注册会计师审计准则第1301号——审计证据》
- 《中国注册会计师审计准则第1501号——对财务报表形成审计意见和出具审计报告》

## tips

1. **识别持续经营迹象须全面**：应从财务、经营、其他三方面全面识别可能导致对持续经营能力产生重大疑虑的事项或情况（如资不抵债、持续亏损、流动性困难、重大诉讼、许可丧失）。
2. **管理层评估期间须充分**：管理层评估持续经营能力的期间应至少覆盖资产负债表日后十二个月，期间不足须要求延长。
3. **缓解措施须评估可行性**：管理层拟采取的缓解措施（融资、资产处置、股东支持）须评估其可行性与可实现性，不得仅凭管理层意向。
4. **重大不确定性结论须明确**：应明确得出是否存在可能导致对持续经营能力产生重大疑虑的重大不确定性的结论。
5. **披露充分性核对**：存在重大不确定性时，须核实财务报表是否充分披露相关事项及管理层应对计划。
6. **意见类型联动**：持续经营结论直接影响审计意见类型（无保留+强调事项段/保留/否定/无法表示意见），须与报告底稿联动。

## checklist

### 一、迹象识别完整性

- [ ] 是否从财务方面识别持续经营迹象（资不抵债/持续亏损/流动性）
- [ ] 是否从经营方面识别（关键人员流失/市场丧失/供应中断）
- [ ] 是否从其他方面识别（法律诉讼/许可丧失/自然灾害）
- [ ] 是否结合分析性复核（A1-13/A1-14）识别的财务指标异常

### 二、管理层评估适当性

- [ ] 管理层是否作出持续经营能力评估
- [ ] 评估期间是否至少覆盖资产负债表日后十二个月
- [ ] 评估方法与假设是否合理
- [ ] 期间不足或未评估的是否要求管理层补充

### 三、缓解措施与应对

- [ ] 管理层拟采取的缓解措施是否识别
- [ ] 缓解措施的可行性与可实现性是否评估
- [ ] 是否取得支持缓解措施的证据（融资协议/股东承诺）
- [ ] 是否实施追加程序应对识别的迹象

### 四、结论、披露与意见

- [ ] 是否明确得出是否存在重大不确定性的结论
- [ ] 存在重大不确定性时披露是否充分
- [ ] 持续经营结论是否与审计意见类型联动
- [ ] 底稿是否与 A11 期后、A12 声明、报告底稿建立交叉索引

## risk_areas

### 高风险

1. **重大不确定性未识别**：存在明显持续经营重大不确定性迹象却未识别，审计意见与披露处理严重不当。
2. **缓解措施可行性未评估**：仅凭管理层意向接受缓解措施，未评估其可行性，结论缺乏证据支持。
3. **评估期间不足**：管理层评估期间未覆盖资产负债表日后十二个月而未要求延长，评估基础不充分。
4. **披露不充分或意见不当**：存在重大不确定性但披露不充分或审计意见类型选择错误。

### 中风险

1. **迹象识别不全面**：仅关注财务迹象而忽视经营或其他方面的持续经营迹象。
2. **追加程序不足**：识别迹象后未实施充分的追加审计程序应对。
3. **结论表述含糊**：是否存在重大不确定性的结论表述不明确。

### 低风险

1. **评估过程记录简略**：持续经营评估过程记录不够详细。
2. **迹象归类不清**：识别的迹象未按财务/经营/其他分类。
3. **交叉索引不完整**：与分析性复核、期后事项、报告底稿的索引引用不完整。
