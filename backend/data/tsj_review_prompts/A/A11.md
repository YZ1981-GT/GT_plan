# A11 期后事项审计程序（财报+内控）复核提示词

## 概述

本提示词针对期后事项审计程序（A11）的复核，聚焦期后事项识别程序的完整性、调整事项与非调整事项的划分准确性、期后审计程序覆盖至报告日的充分性。CAS1332 要求注册会计师就资产负债表日至审计报告日之间发生的期后事项实施审计程序，并对报告日后知悉的事实作出恰当处理，期后事项遗漏或分类错误会导致财务报表调整或披露不当。

**法规依据：**
- 《中国注册会计师审计准则第1332号——期后事项》
- 《中国注册会计师审计准则第1301号——审计证据》
- 《中国注册会计师审计准则第1501号——对财务报表形成审计意见和出具审计报告》

---

## tips

1. **期后程序须覆盖至报告日**：期后事项审计程序应覆盖资产负债表日至审计报告日的完整期间，程序执行时点不得早于报告日过多。
2. **调整与非调整事项须正确划分**：期后事项应准确区分为需调整报表的事项（提供资产负债表日已存在情况的证据）与需披露的非调整事项。
3. **识别程序须多渠道**：应通过询问管理层、查阅期后会议纪要、复核期后财务信息、查阅期后重大合同等多渠道识别期后事项。
4. **报告日后知悉事实的处理**：报告日后至报表报出日、报出日后知悉的事实须按准则规定的不同情形分别处理。
5. **管理层书面声明覆盖期后**：书面声明应涵盖管理层对期后事项的确认，与 A12 书面声明底稿衔接。
6. **重大期后事项影响持续经营**：期后事项可能影响持续经营评估，须与 A15 持续经营底稿关联。

## checklist

### 一、识别程序完整性

- [ ] 是否询问管理层期后重大事项
- [ ] 是否查阅资产负债表日后的董事会/股东会/管理层会议纪要
- [ ] 是否复核期后最新可获得的财务信息
- [ ] 是否查阅期后重大合同、诉讼、承诺事项
- [ ] 识别程序是否覆盖至审计报告日

### 二、调整与非调整划分

- [ ] 期后事项是否准确区分为调整事项与非调整事项
- [ ] 调整事项是否提供资产负债表日已存在情况的证据
- [ ] 需调整事项是否已恰当调整财务报表
- [ ] 需披露的非调整事项是否充分披露

### 三、报告日后处理

- [ ] 报告日后至报出日知悉的事实是否恰当处理
- [ ] 报出日后知悉的事实是否按准则规定处理
- [ ] 涉及报表修改的是否评估对报告的影响
- [ ] 管理层书面声明是否涵盖期后事项确认

### 四、关联与记录

- [ ] 期后事项对持续经营的影响是否与 A15 关联
- [ ] 期后事项对报表调整的影响是否与 A13 错报评价衔接
- [ ] 程序执行记录是否充分、可复核
- [ ] 底稿是否与 A12 书面声明、附注披露建立交叉索引

## risk_areas

### 高风险

1. **重大期后事项遗漏**：未识别应调整或应披露的重大期后事项，导致财务报表错报或披露不足。
2. **调整/非调整划分错误**：将需调整事项误判为披露事项（反之），影响报表金额准确性。
3. **期后程序未覆盖至报告日**：程序执行时点与报告日存在较大间隔，间隔期间的期后事项未覆盖。
4. **报告日后事实处理不当**：报告日后知悉的重大事实未按准则规定处理，报告可靠性受损。

### 中风险

1. **识别渠道不足**：仅询问管理层而未查阅会议纪要、期后财务信息等，识别不充分。
2. **非调整事项披露不充分**：需披露的重大非调整事项披露内容不完整。
3. **书面声明未涵盖期后**：管理层书面声明未包含对期后事项的确认。

### 低风险

1. **程序记录简略**：期后程序执行过程记录不够详细。
2. **期后期间标注不清**：程序覆盖的期后期间起止标注不明确。
3. **交叉索引不完整**：与持续经营、书面声明底稿的索引引用不完整。
