# A17-5-5 审计工作完成核对表（报告签发前最终核对）复核提示词

## 概述

本提示词针对审计工作完成核对表——报告签发前最终核对部分（A17-5-5）的复核，聚焦报告签发前置条件的最终确认、审计报告与底稿结论的一致性、签发时点合规性。A17-5-5 作为完成核对表系列的最终环节，在报告正式签发前对全部前置条件作最后确认，确保审计意见有充分底稿支持、报告要素准确、签发时点满足准则要求。

**法规依据：**
- 《中国注册会计师审计准则第1501号——对财务报表形成审计意见和出具审计报告》
- 《中国注册会计师审计准则第1131号——审计工作底稿》
- 《中国注册会计师审计准则第1101号——注册会计师的总体目标和审计工作的基本要求》

---

## tips

1. **前置条件最终确认**：报告签发前须最终确认取得充分适当审计证据、错报评价完成、期后事项覆盖、书面声明取得、持续经营评估完成等全部前置条件。
2. **报告与底稿结论一致**：审计意见类型、KAM、强调事项段等报告内容须与完成阶段底稿结论完全一致。
3. **报告日不早于证据取得日**：审计报告日须不早于取得充分适当审计证据（含书面声明、期后程序完成）之日。
4. **报告要素最终核对**：被审计单位名称、报告期间、报表构成、意见类型、签字等报告要素须最终核对无误（与 A1-11 衔接）。
5. **遗留事项彻底清零**：签发前须确认无未清零的待办事项或未解决的重大事项。
6. **签发授权到位**：报告签发须经事务所内部授权程序，签发主体与授权链完整。

## checklist

### 一、前置条件最终确认

- [ ] 是否确认已取得充分适当审计证据
- [ ] 错报评价（A13）是否确认完成
- [ ] 期后事项程序（A11）是否确认覆盖至报告日
- [ ] 书面声明（A12）是否确认取得
- [ ] 持续经营评估（A15）是否确认完成

### 二、报告与底稿一致

- [ ] 审计意见类型是否与完成阶段底稿结论一致
- [ ] KAM（A17）是否与底稿应对一致
- [ ] 强调事项段/其他事项段是否有底稿支持
- [ ] 报告数据是否与最终财务报表（A16 核对后）一致

### 三、报告要素与时点

- [ ] 报告要素是否最终核对无误（与 A1-11 衔接）
- [ ] 报告日是否不早于取得充分适当审计证据之日
- [ ] 报告日是否不早于书面声明日与期后程序完成日
- [ ] 报告文号是否唯一、准确

### 四、遗留清零与签发授权

- [ ] 是否确认无未清零的待办事项
- [ ] 是否确认无未解决的重大事项
- [ ] 报告签发是否经事务所内部授权程序
- [ ] 底稿是否与 A1-11、A13、A16、A17 及报告底稿建立交叉索引

## risk_areas

### 高风险

1. **前置条件未满足即签发**：报告在充分证据/错报评价/期后覆盖/书面声明等前置条件未满足时签发，签发条件缺失。
2. **报告与底稿结论不一致**：审计意见类型或 KAM 与底稿结论不符，报告内容失去底稿支持。
3. **报告日早于证据取得日**：审计报告日早于取得充分适当审计证据之日，报告时点违反准则。
4. **遗留重大事项未清零**：签发前存在未解决的重大事项，签发条件不成立。

### 中风险

1. **报告要素核对遗漏**：报告要素（名称/期间/构成/意见）未最终核对，存在要素错误风险。
2. **报告数据与终版报表不符**：报告数据与 A16 核对后的最终报表存在差异。
3. **签发授权不完整**：报告签发未经完整的内部授权程序。

### 低风险

1. **核对记录简略**：最终核对过程记录不够详细。
2. **文号格式细节偏差**：报告文号格式存在细微不规范。
3. **交叉索引不完整**：与前置底稿及报告底稿的索引引用不完整。
