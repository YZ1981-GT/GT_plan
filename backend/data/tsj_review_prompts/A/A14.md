# A14 内部控制缺陷评价审计程序复核提示词

## 概述

本提示词针对内部控制缺陷评价审计程序（A14）的复核，聚焦控制缺陷识别的完整性、缺陷严重程度分级的恰当性、缺陷汇总与通报的准确性。A14 汇集各业务循环控制测试与实质性程序中识别的控制缺陷，按重大缺陷/值得关注缺陷/一般缺陷分级评价，缺陷分级不当或通报遗漏将影响治理层对内部控制状况的判断及缺陷通报义务的履行。

**法规依据：**
- 《中国注册会计师审计准则第1152号——向治理层和管理层通报内部控制缺陷》
- 《中国注册会计师审计准则第1211号——通过了解被审计单位及其环境识别和评估重大错报风险》
- 《中国注册会计师审计准则第1231号——针对评估的重大错报风险采取的应对措施》

---

## tips

1. **缺陷识别须汇集全部来源**：控制缺陷可能在了解内控、控制测试、实质性程序、期后程序等各阶段识别，A14 应完整汇集各来源缺陷。
2. **严重程度分级须有判断依据**：缺陷应按可能导致错报的严重程度与发生可能性分级，重大缺陷/值得关注缺陷/一般缺陷的划分须有明确判断依据。
3. **缺陷组合评价**：单个一般缺陷组合后可能构成值得关注缺陷或重大缺陷，须评价缺陷的组合影响。
4. **重大缺陷与值得关注缺陷须书面通报**：达到通报门槛的缺陷须书面通报治理层（与 A10 衔接），一般缺陷可视情况通报管理层。
5. **缺陷与错报关联**：控制缺陷应与实质性程序发现的错报关联分析，缺陷导致的错报须评估影响。
6. **改进建议具建设性**：针对每项缺陷应提出具体、可操作的改进建议，避免空泛。

## checklist

### 一、缺陷识别完整性

- [ ] 是否汇集了解内控阶段识别的设计缺陷
- [ ] 是否汇集控制测试识别的运行缺陷
- [ ] 是否汇集实质性程序中反映出的控制缺陷
- [ ] 是否存在已识别但未汇集至 A14 的缺陷

### 二、严重程度分级

- [ ] 缺陷是否按重大/值得关注/一般分级
- [ ] 分级是否考虑可能导致错报的金额与发生可能性
- [ ] 分级是否有明确判断依据
- [ ] 缺陷的组合影响是否评价（单个一般缺陷组合后升级）

### 三、缺陷与错报关联

- [ ] 控制缺陷是否与实质性程序发现的错报关联分析
- [ ] 缺陷导致的错报影响是否评估
- [ ] 缺陷是否影响后续审计程序的性质、时间与范围
- [ ] 舞弊相关控制缺陷是否特别关注

### 四、通报与记录

- [ ] 重大缺陷与值得关注缺陷是否书面通报治理层（A10 衔接）
- [ ] 一般缺陷是否视情况通报管理层
- [ ] 每项缺陷是否附具体、可操作的改进建议
- [ ] 底稿是否与控制测试底稿、A10 沟通底稿建立交叉索引

## risk_areas

### 高风险

1. **重大缺陷未识别或未通报**：存在重大控制缺陷却未识别或未书面通报治理层，缺陷通报义务未履行。
2. **缺陷分级偏低**：将重大缺陷或值得关注缺陷错误分级为一般缺陷，低估内控风险。
3. **缺陷组合影响被忽视**：多个一般缺陷组合后已构成值得关注/重大缺陷但未评价组合影响。
4. **缺陷与错报脱节**：控制缺陷与实质性程序发现的错报未关联，缺陷严重性评估失真。

### 中风险

1. **缺陷识别来源不全**：仅汇集控制测试缺陷而遗漏实质性程序反映的缺陷。
2. **分级依据不足**：缺陷分级缺乏明确判断依据，主观性强。
3. **改进建议空泛**：改进建议笼统，缺乏可操作性。

### 低风险

1. **缺陷描述简略**：缺陷描述不够具体，影响复核理解。
2. **汇总表格式不规范**：缺陷汇总列示格式欠规范。
3. **交叉索引不完整**：与控制测试、治理层沟通底稿的索引引用不完整。
