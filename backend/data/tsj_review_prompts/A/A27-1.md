# A27-1 IT审计备忘录复核提示词

## 概述

本提示词针对报告阶段"IT审计备忘录"（A27-1）的复核，聚焦备忘录记录的IT审计程序执行完整性、发现与结论的证据支持、结论对财报审计的传导及备忘录记录的充分性。IT审计备忘录是IT审计工作的正式书面成果，须完整记录IT环境了解、ITGC与应用控制测试、缺陷识别及对财报审计影响的评估，作为信赖系统生成数据的证据基础。

**法规依据：**
- 《中国注册会计师审计准则第1211号——通过了解被审计单位及其环境识别和评估重大错报风险》
- 《中国注册会计师审计准则第1421号——利用专家的工作》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **备忘录须完整记录IT环境了解**：应记录被审计单位IT组织架构、关键信息系统、IT依赖程度，作为范围界定的依据。
2. **测试程序与结果须逐项记录**：ITGC和应用控制的测试方法、样本、结果、结论须逐项记录，测试无据将无法支持结论。
3. **缺陷识别须明确严重程度**：识别的IT控制缺陷须评估其性质和严重程度（一般/重要/重大），并说明判断依据。
4. **对财报审计影响须明确表述**：备忘录须明确IT发现对实质性程序性质、时间、范围的影响，形成审计策略的传导。
5. **备忘录结论须清晰可追溯**：IT审计的整体结论（是否可信赖系统数据）须清晰表述并能追溯至测试证据。
6. **关注跨期IT变更的影响**：报告期内的重大系统变更、迁移是否评估其对控制持续有效性的影响。

## checklist

### 一、IT审计程序完整性

- [ ] 备忘录是否记录IT环境了解（架构/系统/依赖）
- [ ] ITGC测试的方法、样本、结果是否逐项记录
- [ ] 应用控制测试是否记录
- [ ] 报告期内系统变更的影响是否评估
- [ ] 测试范围是否与风险评估匹配

### 二、发现与证据支持

- [ ] 识别的IT缺陷是否有测试证据支持
- [ ] 缺陷严重程度评估是否说明依据
- [ ] 测试样本量和选取是否合理
- [ ] 是否存在测试结论无据的情况

### 三、结论传导性

- [ ] IT发现对实质性程序的影响是否明确
- [ ] IT缺陷是否评估手工补偿控制
- [ ] 备忘录整体结论（可否信赖系统数据）是否清晰
- [ ] 结论是否传导至项目组审计策略

### 四、专家利用与记录

- [ ] 利用IT专家的，其工作充分性是否评价（CAS1421）
- [ ] 备忘录编制人、复核人是否签字
- [ ] 备忘录记录是否完整可追溯
- [ ] 底稿索引是否与A27及相关底稿建立引用

## risk_areas

### 高风险

1. **测试程序无据记录**：ITGC或应用控制测试的方法、样本、结果记录缺失，结论无法支持。
2. **IT缺陷影响未传导**：识别的重大IT缺陷未评估对财报实质性程序的影响。
3. **缺陷严重程度误判**：IT缺陷严重程度评估缺乏依据或明显偏低，掩盖重大控制失效。
4. **系统变更影响未评估**：报告期内重大系统变更未评估对控制持续有效性的影响。

### 中风险

1. **IT环境了解不充分**：备忘录未充分记录IT架构和依赖程度，范围界定缺乏基础。
2. **补偿控制评估缺失**：IT缺陷未评估手工补偿控制。
3. **专家工作充分性未评价**：利用IT专家但未评价其工作。
4. **测试样本不合理**：样本量或选取方法不足以支持结论。

### 低风险

1. **备忘录格式不规范**：结构、章节编排不规范。
2. **签字缺失**：备忘录缺编制或复核签字。
3. **底稿索引不完整**：与A27、风险评估底稿交叉引用缺失。
