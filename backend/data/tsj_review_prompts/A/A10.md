# A10 审计程序A10（与治理层沟通及管理建议）复核提示词

## 概述

本提示词针对完成阶段治理层沟通及管理建议程序（A10）的复核，聚焦沟通事项的完整性、沟通时点的适当性、内部控制缺陷与管理建议的准确传达。CAS1151/1152 要求注册会计师就审计范围与时间安排、重大发现、内部控制缺陷等事项与治理层和管理层进行有效沟通，沟通遗漏或不及时可能导致治理层未能履行监督责任。

**法规依据：**
- 《中国注册会计师审计准则第1151号——与治理层的沟通》
- 《中国注册会计师审计准则第1152号——向治理层和管理层通报内部控制缺陷》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **应沟通事项须完整覆盖**：与治理层沟通应涵盖审计责任、计划范围与时间、审计中的重大发现、独立性声明等 CAS1151 要求的全部事项。
2. **内部控制缺陷分级通报**：识别的内部控制缺陷须按重大缺陷/值得关注缺陷/一般缺陷分级，重大缺陷与值得关注缺陷应书面通报治理层。
3. **沟通时点须及时**：重大事项应及时沟通而非集中到报告签发时，确保治理层有时间作出回应。
4. **管理建议须具建设性且有据**：管理建议应基于审计发现，具体、可操作，避免空泛表述，并注明相关底稿依据。
5. **书面沟通留痕**：重要沟通事项应有书面记录（沟通函/会议纪要），载明沟通对象、时间、内容与治理层回应。
6. **区分沟通对象**：治理层与管理层沟通事项不同，须正确区分，涉及管理层舞弊或凌驾的须直接与治理层沟通。

## checklist

### 一、沟通事项完整性

- [ ] 是否沟通了注册会计师就财务报表审计承担的责任
- [ ] 是否沟通了计划的审计范围与时间安排
- [ ] 是否沟通了审计工作中的重大发现
- [ ] 是否作出了独立性声明（针对上市实体等）
- [ ] 是否沟通了审计过程中遇到的重大困难

### 二、内部控制缺陷通报

- [ ] 识别的内部控制缺陷是否已分级（重大/值得关注/一般）
- [ ] 重大缺陷与值得关注缺陷是否书面通报治理层
- [ ] 缺陷描述是否清晰、影响是否说明、改进建议是否具体
- [ ] 缺陷通报是否与 A14 内控缺陷评价底稿一致

### 三、沟通时点与对象

- [ ] 重大事项是否及时沟通而非集中报告时
- [ ] 沟通对象（治理层/管理层）是否正确区分
- [ ] 涉及管理层舞弊或凌驾的是否直接与治理层沟通
- [ ] 沟通是否给治理层留出合理回应时间

### 四、记录与管理建议

- [ ] 重要沟通是否有书面记录（沟通函/会议纪要）
- [ ] 记录是否载明对象、时间、内容与治理层回应
- [ ] 管理建议是否基于审计发现、具体可操作
- [ ] 管理建议是否注明相关底稿依据并建立交叉索引

## risk_areas

### 高风险

1. **重大发现未沟通**：审计中的重大发现未与治理层沟通，治理层无法履行监督职责。
2. **重大内控缺陷未书面通报**：识别的重大缺陷未书面通报治理层，缺陷通报义务未履行。
3. **管理层舞弊未直达治理层**：涉及管理层舞弊或凌驾控制的事项未直接与治理层沟通，沟通渠道失效。
4. **独立性声明遗漏**：对上市实体等未作出应有的独立性声明，违反沟通准则强制要求。

### 中风险

1. **沟通不及时**：重大事项集中到报告签发时才沟通，治理层缺乏回应时间。
2. **缺陷分级不当**：内控缺陷分级判断不准确，导致通报层级错误。
3. **沟通记录不完整**：书面沟通记录缺少治理层回应或关键内容。

### 低风险

1. **管理建议空泛**：管理建议表述笼统，缺乏可操作性但不影响主要发现传达。
2. **沟通对象表述不清**：沟通记录中对象身份标注不够明确。
3. **交叉索引缺失**：管理建议与内控缺陷底稿的索引引用不完整。
