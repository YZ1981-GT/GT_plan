# A17-5-2 审计工作完成核对表（内部控制）复核提示词

## 概述

本提示词针对审计工作完成核对表——内部控制部分（A17-5-2）的复核，聚焦内部控制相关审计工作完成情况的系统核对、控制了解与测试程序的落实确认、内控缺陷识别与通报的完整性。A17-5-2 专项核对内部控制相关程序的完成状况，确认从了解内控、评价设计、测试运行到缺陷评价通报各环节均已落实，是内控相关工作在完成阶段的收口核对。

**法规依据：**
- 《中国注册会计师审计准则第1152号——向治理层和管理层通报内部控制缺陷》
- 《中国注册会计师审计准则第1131号——审计工作底稿》
- 《中国注册会计师审计准则第1211号——通过了解被审计单位及其环境识别和评估重大错报风险》

---

## tips

1. **内控工作全环节核对**：核对应覆盖了解内控、评价控制设计、控制测试、缺陷识别与通报各环节的完成情况。
2. **缺陷评价通报确认**：应确认识别的内控缺陷已分级评价（A14）并按要求通报治理层与管理层（A10）。
3. **控制测试结论支持依赖**：拟信赖控制的，须确认控制测试已执行且结论支持信赖水平。
4. **内控缺陷与实质性程序衔接**：应确认内控缺陷对实质性程序性质、时间、范围的影响已在程序中体现。
5. **非财报内控边界确认**：应确认非财报内控缺陷（A14-6）已按适当方式处理且未越界。
6. **签署确认责任**：内控完成核对应由相关注册会计师签署确认。

## checklist

### 一、内控程序落实

- [ ] 是否确认已完成对内部控制的了解
- [ ] 是否确认已评价关键控制的设计有效性
- [ ] 拟信赖控制的是否确认已执行控制测试
- [ ] 控制测试结论是否确认支持拟信赖的水平

### 二、缺陷识别与通报

- [ ] 是否确认内控缺陷已汇集至 A14 并分级评价
- [ ] 重大缺陷与值得关注缺陷是否确认已书面通报治理层
- [ ] 一般缺陷是否确认已视情况通报管理层
- [ ] 非财报内控缺陷（A14-6）是否确认已适当处理

### 三、内控与实质性程序衔接

- [ ] 内控缺陷对实质性程序的影响是否确认已体现
- [ ] 控制未按拟信赖运行时是否确认已调整程序
- [ ] 舞弊相关控制缺陷是否确认已特别应对
- [ ] 内控结论是否与实质性程序结论衔接一致

### 四、签署与记录

- [ ] 内控完成核对是否由相关注册会计师签署
- [ ] 核对结论是否以内控底稿实际完成情况为依据
- [ ] 核对过程与结论是否记录充分
- [ ] 底稿是否与 A14、A14-6、A10、控制测试底稿建立交叉索引

## risk_areas

### 高风险

1. **控制测试未执行即信赖**：拟信赖控制却未确认控制测试执行，信赖缺乏证据基础。
2. **重大缺陷未通报**：识别的重大内控缺陷未确认书面通报治理层，通报义务未履行。
3. **缺陷未衔接实质性程序**：内控缺陷对实质性程序的影响未体现，风险应对不充分。
4. **舞弊控制缺陷未应对**：舞弊相关控制缺陷未特别应对，舞弊风险未有效覆盖。

### 中风险

1. **内控环节核对遗漏**：内控某环节（如设计评价）未纳入核对确认。
2. **缺陷分级未确认**：内控缺陷是否已分级评价未确认。
3. **非财报内控处理未确认**：A14-6 非财报内控缺陷处理状况未确认。

### 低风险

1. **核对状态标注不清**：内控核对项状态标注不够明确。
2. **签署缺失**：内控完成核对缺少签署。
3. **交叉索引不完整**：与内控相关底稿的索引引用不完整。
