# A17-5-3 审计工作完成核对表（底稿归档与索引）复核提示词

## 概述

本提示词针对审计工作完成核对表——底稿归档与索引部分（A17-5-3）的复核，聚焦审计工作底稿完整性的核对、交叉索引闭环的确认、底稿归档要求的满足性。A17-5-3 专项核对底稿层面的收口工作，确认支持审计结论的底稿完整、索引可追溯、归档合规，是审计档案质量在完成阶段的核对环节。

**法规依据：**
- 《中国注册会计师审计准则第1131号——审计工作底稿》
- 《中国注册会计师审计准则第1101号——注册会计师的总体目标和审计工作的基本要求》
- 《中国注册会计师审计准则第1501号——对财务报表形成审计意见和出具审计报告》

---

## tips

1. **底稿完整性核对**：应确认支持各项审计结论的底稿均已完成并归入档案，无缺失底稿。
2. **交叉索引闭环**：应确认底稿间交叉索引准确、双向可追溯，无悬空索引或断链。
3. **底稿要素齐全**：应确认底稿具备编制人、复核人、日期、来源、结论等基本要素。
4. **归档时限合规**：应确认底稿在准则规定的归档期限内完成整理归档。
5. **底稿修改留痕**：报告日后对底稿的任何补充或修改应留痕，记录修改人、时间、原因。
6. **电子底稿完整性**：电子底稿应确认已锁定、备份，防止归档后未授权修改。

## checklist

### 一、底稿完整性

- [ ] 支持各项审计结论的底稿是否均已完成
- [ ] 是否存在缺失或未完成的关键底稿
- [ ] 底稿是否覆盖计划、执行、完成全周期
- [ ] 底稿内容是否足以支持审计结论

### 二、交叉索引闭环

- [ ] 底稿间交叉索引是否准确
- [ ] 索引是否双向可追溯
- [ ] 是否存在悬空索引或断链
- [ ] 完成阶段底稿（A11/A12/A13/A15/A17）索引是否闭环

### 三、底稿要素与修改留痕

- [ ] 底稿是否具备编制人、复核人、日期等基本要素
- [ ] 底稿来源与结论是否清晰记录
- [ ] 报告日后底稿的补充/修改是否留痕
- [ ] 修改记录是否载明修改人、时间、原因

### 四、归档合规

- [ ] 底稿是否在规定归档期限内整理归档
- [ ] 电子底稿是否已锁定、备份
- [ ] 是否防止归档后未授权修改
- [ ] 归档核对是否由相关注册会计师签署确认

## risk_areas

### 高风险

1. **关键底稿缺失**：支持审计结论的关键底稿缺失或未完成，审计结论失去底稿支持。
2. **索引断链**：底稿间交叉索引悬空或断链，结论的可追溯性丧失。
3. **归档后未授权修改**：底稿归档后被未授权修改且未留痕，档案完整性受损。
4. **超期归档**：底稿未在规定期限内归档，违反档案管理准则要求。

### 中风险

1. **底稿要素不齐**：底稿缺少编制人、复核人或日期等基本要素。
2. **修改未留痕**：报告日后底稿补充/修改未记录修改痕迹。
3. **电子底稿未锁定**：电子底稿未锁定备份，存在被修改风险。

### 低风险

1. **索引表述不统一**：交叉索引表述格式不统一。
2. **归档整理欠规范**：底稿归档整理顺序或标识欠规范。
3. **核对签署缺失**：归档核对缺少签署确认。
