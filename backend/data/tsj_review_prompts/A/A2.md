# A2 调整分录程序表复核提示词

## 概述

本提示词针对报告阶段"调整分录程序表"（A2，审计调整AJE/RJE汇总）的复核，聚焦调整分录的完整性、借贷平衡、审批授权、汇总勾稽及错报累积评估。调整分录汇总是连接实质性审计发现与最终审定数的枢纽，所有账项调整（AJE）与重分类调整（RJE）须完整、平衡、经审批，并与试算平衡表、审定表形成闭环勾稽，同时须评估未调整错报是否累积超过重要性水平。

**法规依据：**
- 《中国注册会计师审计准则第1251号——评价审计过程中识别出的错报》
- 《中国注册会计师审计准则第1301号——审计证据》
- 《中国注册会计师审计准则第1131号——审计工作底稿》

## tips

1. **借贷平衡是调整分录的第一道校验**：每一笔调整分录的借方合计必须等于贷方合计，全部调整汇总后借贷总额亦须平衡，任何不平衡均为录入或勾稽错误。
2. **调整分录须区分AJE与RJE并正确归类**：账项调整（影响利润或净资产）与重分类调整（仅影响列报）性质不同，混淆归类将导致审定数或列报失真。
3. **每笔调整须有充分证据与审批**：调整分录须追溯至具体审计发现和底稿证据，并经项目合伙人审批，未经审批的调整不得纳入审定数。
4. **调整分录须与审定表、试算平衡表勾稽**：A2汇总的AJE/RJE合计须与各科目审定表调整列、试算平衡表调整数完全一致。
5. **未调整错报须完整记录并评估**：被审计单位未接受的建议调整须记录于未调整错报汇总表（SUD），并评估单项及累计影响是否超过重要性水平。
6. **关注调整分录对已审报表各要素的传导**：一笔调整可能同时影响资产负债表、利润表、现金流量表、附注，须核实传导的完整性与一致性。

## checklist

### 一、调整分录完整性

- [ ] 实质性程序中识别的所有调整事项是否均已编制调整分录
- [ ] 调整分录是否区分AJE（账项调整）与RJE（重分类调整）
- [ ] 每笔调整分录是否有对应的审计发现说明和底稿索引
- [ ] 是否存在已识别错报但未编制调整分录的情况
- [ ] 期后事项相关调整是否完整反映

### 二、借贷平衡与勾稽

- [ ] 每笔调整分录借方合计是否等于贷方合计
- [ ] 全部AJE汇总借贷总额是否平衡
- [ ] 全部RJE汇总借贷总额是否平衡
- [ ] A2调整合计是否与各科目审定表调整列一致
- [ ] A2调整合计是否与试算平衡表调整数一致

### 三、审批授权

- [ ] 每笔调整分录是否经项目合伙人审批
- [ ] 重大调整是否经质量控制复核合伙人复核
- [ ] 是否存在未经审批即纳入审定数的调整
- [ ] 调整分录的编制人、复核人、审批人是否留痕

### 四、未调整错报评估

- [ ] 被审计单位未接受的建议调整是否记录于SUD
- [ ] 单项未调整错报是否评估其对报表的影响
- [ ] 累计未调整错报是否与整体重要性水平比较
- [ ] 累计错报接近重要性时是否重新评估审计意见
- [ ] 定性错报（分类、披露）是否一并考虑

## risk_areas

### 高风险

1. **调整分录不平衡**：借贷方金额不等，直接导致试算平衡表和审定数错误，破坏报表勾稽基础。
2. **已识别错报未调整且未记录**：实质性程序发现的错报既未调整也未纳入SUD，掩盖重大错报。
3. **调整未经审批**：未经合伙人审批的调整直接纳入审定数，存在越权或错误调整风险。
4. **累计错报超重要性未处理**：未调整错报累计超过整体重要性水平但未重新评估审计意见，可能出具不恰当意见。

### 中风险

1. **AJE与RJE混淆归类**：账项调整误作重分类或反之，导致利润或列报失真。
2. **调整与审定表不勾稽**：A2汇总数与审定表调整列不一致，存在遗漏或重复。
3. **调整传导不完整**：一笔调整未同步反映到所有受影响报表要素及附注。
4. **证据支持不足**：调整分录缺乏充分底稿证据支持其金额和性质。

### 低风险

1. **调整分录说明不充分**：调整事由描述过于简略，影响复核理解。
2. **编号或索引不规范**：调整分录编号、底稿索引编排不规范。
3. **格式不统一**：AJE/RJE汇总表格式不统一，影响汇总效率。
