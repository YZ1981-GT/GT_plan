# A28 项目内复核表复核提示词

## 概述

本提示词针对报告阶段"项目内复核表"（A28，三级复核，CAS1121项目质量管理）的复核，聚焦复核层级的完整性、复核意见的落实闭环、复核时点的适当性及复核记录的充分性。项目内复核是项目质量管理的核心机制，须落实审计助理自我复核、现场经理一级复核、项目合伙人二级复核（必要时质控复核合伙人独立复核）的多级复核体系，确保底稿质量和审计结论经过充分复核。

**法规依据：**
- 《中国注册会计师审计准则第1121号——对财务报表审计实施的质量管理》
- 《中国注册会计师审计准则第1131号——审计工作底稿》
- 《中国注册会计师审计准则第1101号——注册会计师执行财务报表审计的总体目标》

---

## tips

1. **复核层级须完整覆盖**：项目内复核须体现分级复核（编制人自查、现场经理复核、合伙人复核），关键底稿须经更高层级复核。
2. **复核意见须闭环落实**：复核提出的问题须有整改回应并经复核人确认关闭，未闭环的复核意见构成质量隐患。
3. **复核时点须在报告签发前**：所有层级复核须在审计报告签发前完成，报告签发后补做复核违反质量管理要求。
4. **复核深度须与风险匹配**：高风险领域、重大判断事项须经更深入复核，复核不能仅停留于形式勾选。
5. **复核记录须留痕可追溯**：复核人、复核日期、复核意见、整改回应须完整记录，形成复核轨迹。
6. **关注EQCR复核的触发与执行**：对于需要项目质量控制复核（EQCR）的项目，须确认EQCR在报告签发前完成且意见得到处理。

## checklist

### 一、复核层级完整性

- [ ] 底稿是否经编制人自我复核
- [ ] 是否经现场经理一级复核
- [ ] 是否经项目合伙人二级复核
- [ ] 关键判断事项是否经适当层级复核
- [ ] 需EQCR的项目是否执行独立质量复核

### 二、复核意见落实闭环

- [ ] 复核提出的问题是否有整改回应
- [ ] 整改是否经复核人确认关闭
- [ ] 是否存在未闭环的复核意见
- [ ] 重大复核意见的处理是否记录

### 三、复核时点适当性

- [ ] 各层级复核是否在报告签发前完成
- [ ] EQCR（如适用）是否在报告签发前完成
- [ ] 复核时点是否与审计进度衔接
- [ ] 是否存在报告后补做复核的情况

### 四、复核记录充分性

- [ ] 复核人、复核日期是否记录
- [ ] 复核意见是否具体记录
- [ ] 整改回应及确认是否留痕
- [ ] 复核轨迹是否完整可追溯
- [ ] 底稿索引是否与相关底稿建立引用

## risk_areas

### 高风险

1. **复核层级缺失**：关键底稿未经合伙人或必要层级复核，质量管理体系失效。
2. **复核意见未闭环**：复核提出的重大问题未整改或未确认关闭即出具报告。
3. **报告后补做复核**：审计报告签发后补做复核，违反复核前置要求，质量控制形同虚设。
4. **EQCR未执行或意见未处理**：需EQCR的项目未执行独立复核，或EQCR重大意见未处理即签发报告。

### 中风险

1. **复核流于形式**：复核仅勾选未实质审阅，高风险领域复核深度不足。
2. **复核时点滞后**：部分层级复核在报告末期仓促完成。
3. **整改回应缺失**：复核意见有提出但整改回应未记录。
4. **复核深度与风险不匹配**：重大判断事项复核不充分。

### 低风险

1. **复核表格式不规范**：复核表结构、栏目不规范。
2. **复核意见记录简略**：复核意见表述过于简略。
3. **底稿索引不完整**：复核表与被复核底稿交叉引用缺失。
