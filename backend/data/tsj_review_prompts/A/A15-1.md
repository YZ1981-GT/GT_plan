# A15-1 持续经营调查问卷复核提示词

## 概述

本提示词针对持续经营调查问卷（A15-1）的复核，聚焦问卷调查事项的完整覆盖、问卷回答与审计证据的一致性、问卷识别事项与 A15 持续经营评估结论的衔接。A15-1 以结构化问卷形式系统识别持续经营迹象，是 A15 评估的证据基础，问卷覆盖不全或回答未印证会削弱持续经营评估的完整性与可靠性。

**法规依据：**
- 《中国注册会计师审计准则第1324号——持续经营》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **问卷须覆盖三类迹象**：调查问卷应系统覆盖财务、经营、其他三类可能导致持续经营重大疑虑的事项，避免遗漏关键领域。
2. **肯定回答须追加核查**：对表明存在持续经营迹象的肯定回答，须追加核查取得支持证据，不得仅记录回答。
3. **回答须与审计证据印证**：问卷回答应与财务数据、分析性复核结果、管理层访谈及其他审计证据相互印证。
4. **问卷结论汇入 A15**：问卷识别的迹象与结论应完整汇入 A15 持续经营评估，形成证据链。
5. **回答来源须可追溯**：问卷回答的信息来源（管理层访谈/财务数据/外部信息）应记录，确保可追溯。
6. **异常回答重点关注**：与预期不符或存在矛盾的问卷回答须重点关注并深入调查。

## checklist

### 一、问卷覆盖完整性

- [ ] 问卷是否覆盖财务类持续经营迹象
- [ ] 问卷是否覆盖经营类持续经营迹象
- [ ] 问卷是否覆盖其他类（法律/许可/外部环境）迹象
- [ ] 问卷事项是否与被审计单位实际情况适配

### 二、回答核查与印证

- [ ] 表明存在迹象的肯定回答是否追加核查
- [ ] 问卷回答是否与财务数据相互印证
- [ ] 问卷回答是否与分析性复核结果一致
- [ ] 异常或矛盾的回答是否深入调查

### 三、结论衔接

- [ ] 问卷识别的迹象是否完整汇入 A15
- [ ] 问卷结论与 A15 持续经营评估结论是否一致
- [ ] 问卷未发现迹象的结论是否有充分支持
- [ ] 问卷与分析性复核识别的异常是否交叉验证

### 四、来源与记录

- [ ] 问卷回答的信息来源是否记录
- [ ] 回答来源是否可追溯
- [ ] 问卷执行人与复核是否留痕
- [ ] 底稿是否与 A15 持续经营底稿建立交叉索引

## risk_areas

### 高风险

1. **持续经营迹象漏答**：问卷未覆盖关键迹象领域，导致存在的重大不确定性未被识别。
2. **肯定回答未核查**：对表明迹象的肯定回答仅记录而未追加核查证据，识别流于形式。
3. **问卷与 A15 脱节**：问卷识别的迹象未汇入 A15 评估，证据链断裂。
4. **矛盾回答未处理**：问卷回答与审计证据存在矛盾却未深入调查，评估可靠性受损。

### 中风险

1. **回答未印证**：接受问卷回答但未与其他审计证据印证。
2. **覆盖领域不全**：问卷仅覆盖财务迹象而忽视经营或其他迹象。
3. **来源未记录**：问卷回答的信息来源缺失，可追溯性不足。

### 低风险

1. **问卷格式不规范**：问卷列示格式欠规范，不影响内容完整性。
2. **执行留痕缺失**：问卷执行人或复核痕迹缺失。
3. **交叉索引不完整**：与 A15 持续经营底稿的索引引用不完整。
