# A9 内部控制缺陷相关审计程序复核提示词

## 概述

本提示词针对报告阶段"内部控制缺陷相关审计程序"（A9，缺陷沟通，CAS1152书面沟通内控缺陷）的复核，聚焦缺陷识别的完整性、缺陷严重程度评价的恰当性、缺陷沟通的及时性与书面性及沟通记录的充分性。内部控制缺陷的识别、评价与沟通是审计报告收尾阶段的法定程序，须完整汇总审计过程中识别的控制缺陷，恰当评价其严重程度，并按CAS1152要求向治理层和管理层书面通报值得关注的缺陷及重大缺陷。

**法规依据：**
- 《中国注册会计师审计准则第1152号——向治理层和管理层通报内部控制缺陷》
- 《中国注册会计师审计准则第1151号——与治理层的沟通》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **缺陷识别须汇总全程发现**：控制缺陷来源于控制测试、实质性程序、舞弊风险评估等审计全过程，须完整汇总，防止分散发现的缺陷未被归集评价。
2. **缺陷严重程度评价须恰当分级**：须区分一般缺陷、值得关注的缺陷、重大缺陷，评价须考虑缺陷导致错报的可能性和潜在错报金额。
3. **值得关注缺陷及重大缺陷须书面沟通**：CAS1152要求向治理层书面沟通值得关注的内部控制缺陷，及时且书面是合规要求。
4. **缺陷沟通对象须区分**：重大缺陷及值得关注缺陷向治理层书面沟通，其他缺陷可向管理层适当层级沟通。
5. **缺陷评价须与审计策略一致**：识别的重大缺陷须评估其对审计程序性质、时间、范围及审计意见的影响。
6. **关注缺陷的补偿控制与整改**：评价缺陷时须考虑是否存在补偿控制，缺陷的整改情况及管理层回应须记录。

## checklist

### 一、缺陷识别完整性

- [ ] 控制测试中识别的缺陷是否汇总
- [ ] 实质性程序中发现的控制缺陷是否汇总
- [ ] 舞弊风险评估相关的控制缺陷是否汇总
- [ ] IT审计（A27）识别的IT控制缺陷是否纳入
- [ ] 是否存在分散发现但未归集的缺陷

### 二、严重程度评价恰当性

- [ ] 缺陷是否分级（一般/值得关注/重大）
- [ ] 评价是否考虑错报可能性和潜在金额
- [ ] 评价是否考虑补偿控制的存在
- [ ] 重大缺陷判断是否有依据
- [ ] 缺陷评价是否与B22等内控底稿一致

### 三、沟通及时性与书面性

- [ ] 值得关注缺陷及重大缺陷是否书面沟通治理层
- [ ] 书面沟通是否及时（未拖延至报告末期）
- [ ] 一般缺陷是否向管理层适当层级沟通
- [ ] 沟通内容是否包括缺陷描述、影响、建议

### 四、评价影响与记录

- [ ] 重大缺陷对审计程序的影响是否评估
- [ ] 重大缺陷对审计意见的影响是否评估
- [ ] 管理层对缺陷的回应及整改是否记录
- [ ] 缺陷沟通是否与A26治理层沟通一致
- [ ] 底稿索引是否与内控底稿、治理层沟通底稿建立引用

## risk_areas

### 高风险

1. **重大缺陷未识别或未沟通**：识别出重大内部控制缺陷但未评价或未向治理层书面沟通，违反CAS1152。
2. **缺陷严重程度低估**：将重大缺陷或值得关注缺陷评价为一般缺陷，掩盖控制重大失效。
3. **缺陷汇总不完整**：审计全过程识别的缺陷未完整归集，缺陷评价失据。
4. **重大缺陷影响未评估**：重大缺陷对审计程序或审计意见的影响未评估。

### 中风险

1. **沟通不及时**：值得关注缺陷或重大缺陷沟通拖延至报告末期。
2. **书面沟通缺失**：应书面沟通的缺陷仅口头沟通，不符合CAS1152书面要求。
3. **补偿控制未考虑**：缺陷严重程度评价未考虑补偿控制。
4. **缺陷评价与内控底稿不一致**：A9缺陷评价与B22等内控底稿结论不一致。

### 低风险

1. **缺陷描述不充分**：缺陷描述、影响、建议记录简略。
2. **整改记录缺失**：管理层对缺陷的回应及整改情况未记录。
3. **底稿索引不完整**：与内控底稿、治理层沟通底稿交叉引用缺失。
