# A3-4 已审比率分析复核提示词

## 概述

本提示词针对报告阶段"已审比率分析"（A3-4）的复核，作为合并层面已审比率分析的补充或专项分析，聚焦比率分析程序的完整性、异常波动的解释充分性、勾稽核对及分析结论对审计判断的支持性。A3-4在A3-1基础上进一步深化比率分析，可能侧重合并层面或特定维度的比率验证，确保已审（合并）数据经过充分的分析性复核。

**法规依据：**
- 《中国注册会计师审计准则第1301号——审计证据》
- 《企业会计准则第33号——合并财务报表》
- 《中国注册会计师审计准则第1231号——针对评估的重大错报风险采取的应对措施》

---

## tips

1. **分析对象须为审定/合并后数据**：A3-4比率分析须基于已纳入全部调整和合并抵销的审定数据。
2. **专项或深化比率须聚焦目标**：若A3-4为特定维度深化分析，须明确分析目标和关注领域。
3. **异常须追溯并有据解释**：比率异常须追溯原因，解释与审计发现及底稿一致。
4. **多期趋势分析须充分**：除本期与上期比较外，多期趋势分析有助于识别渐进式错报或经营恶化。
5. **合并与母公司比率对比**：合并层面比率与母公司比率的差异可揭示子公司或抵销事项的影响。
6. **关注比率与非财务指标的匹配**：财务比率与业务量、产能等非财务指标的匹配关系异常可能提示错报。

## checklist

### 一、比率分析完整性

- [ ] 分析所用数据是否为审定（含合并）数据
- [ ] 专项/深化分析目标是否明确
- [ ] 是否执行多期趋势分析
- [ ] 是否进行合并与母公司比率对比
- [ ] 关键比率是否计算齐全

### 二、异常波动解释

- [ ] 比率异常是否逐项追溯原因
- [ ] 解释是否与审计发现一致
- [ ] 解释是否有底稿证据支持
- [ ] 无法解释的异常是否追加程序

### 三、勾稽核对

- [ ] 比率分子分母是否与已审报表一致
- [ ] 计算公式是否正确
- [ ] 比率与非财务指标匹配关系是否核对
- [ ] 多期数据口径是否一致可比

### 四、分析结论支持性

- [ ] 分析结论是否明确表述数据合理性判断
- [ ] 异常趋势是否评估持续经营或错报影响
- [ ] 分析发现是否传导至审计结论
- [ ] 分析底稿是否有编制人和复核人签字

## risk_areas

### 高风险

1. **分析基于未审/未合并数据**：使用未审或未合并数据，分析结论无效。
2. **渐进式异常趋势被忽略**：多期趋势揭示的渐进式恶化或错报未被识别和追查。
3. **重大异常无据解释**：比率重大偏离解释缺乏证据支持。
4. **合并异常未追查**：合并与母公司比率重大差异未追溯至子公司或抵销事项。

### 中风险

1. **分析覆盖不全**：专项分析目标不明确或维度遗漏。
2. **计算公式错误**：比率口径或公式错误。
3. **非财务指标匹配未核对**：财务比率与业务指标匹配关系异常未评估。
4. **分析流于形式**：比率计算后未形成有意义结论。

### 低风险

1. **分析说明不充分**：趋势分析文字简略。
2. **格式不规范**：分析表格式不规范。
3. **复核签字缺失**：分析底稿缺签字。
