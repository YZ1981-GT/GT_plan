# A1-17 对应数据（比较信息）程序表复核提示词

## 概述

本提示词针对对应数据（比较信息）程序表（A1-17）的复核，聚焦比较信息的完整列报、比较信息与前期已出具报告的一致性、期初余额与前期审计衔接的适当性。CAS1511 要求注册会计师就财务报表中列报的比较信息（对应数据/比较财务报表）实施审计程序，比较信息错报或与前期报告不一致会直接影响本期报告意见段的表述。

**法规依据：**
- 《中国注册会计师审计准则第1511号——比较信息：对应数据和比较财务报表》
- 《中国注册会计师审计准则第1501号——对财务报表形成审计意见和出具审计报告》
- 《中国注册会计师审计准则第1331号——首次审计业务涉及的期初余额》

---

## tips

1. **区分对应数据与比较财务报表**：应先明确比较信息的性质（对应数据仅作本期报表组成部分，或比较财务报表需单独发表意见），二者审计要求与报告表述不同。
2. **比较信息须与前期报告一致**：本期列报的比较信息应与前期已出具审计报告的财务报表金额与分类一致，不一致须查明原因（重述/重分类/差错更正）。
3. **重述与重分类须充分披露**：前期比较信息因会计政策变更、差错更正而重述或重分类的，须核实调整的恰当性并检查披露充分性。
4. **前期非本所审计的衔接**：前期由前任注册会计师审计的，须评估期初余额与比较信息的可靠性，必要时在报告中作出相应表述。
5. **前期意见影响本期报告**：前期报告为非无保留意见且相关事项对本期仍有影响的，应评估对本期意见段/其他事项段的影响。
6. **期初余额勾稽**：本期期初余额须与前期期末审定数勾稽一致，断裂须追溯至重述调整或差错。

## checklist

### 一、比较信息完整性与性质

- [ ] 是否明确比较信息性质（对应数据/比较财务报表）
- [ ] 财务报表各项目比较信息是否完整列报
- [ ] 附注中的比较信息是否完整
- [ ] 比较信息列报格式是否符合适用编制基础要求

### 二、与前期报告一致性

- [ ] 本期列报的比较信息是否与前期已出具报告金额一致
- [ ] 分类与列报口径是否与前期一致
- [ ] 不一致项是否查明原因（重述/重分类/差错更正）
- [ ] 期初余额是否与前期期末审定数勾稽一致

### 三、重述与重分类恰当性

- [ ] 比较信息重述的原因是否恰当（政策变更/差错更正）
- [ ] 重述调整的计算与方向是否正确
- [ ] 重述/重分类是否在附注中充分披露
- [ ] 追溯调整的影响期间是否正确

### 四、前期审计衔接与报告影响

- [ ] 前期由前任审计的，期初余额可靠性是否评估
- [ ] 前期非无保留意见事项对本期的影响是否评估
- [ ] 报告意见段/其他事项段对比较信息的表述是否恰当
- [ ] 底稿是否与期初余额、附注披露建立交叉索引

## risk_areas

### 高风险

1. **比较信息与前期报告不一致**：本期列报的上期数与前期已出具报告不符且未查明原因，构成报表错报或前期报告可靠性问题。
2. **重述调整不恰当**：以差错更正或政策变更为名进行不当追溯调整，操纵比较信息。
3. **期初余额勾稽断裂**：本期期初余额与前期期末审定数不一致且无合理解释，本期数据基准失真。
4. **报告表述遗漏**：前期非无保留意见事项对本期仍有影响却未在报告中恰当表述。

### 中风险

1. **重述披露不充分**：比较信息重述或重分类未在附注中充分披露，信息透明度不足。
2. **比较信息性质判断错误**：将比较财务报表当作对应数据处理，报告表述与审计要求不匹配。
3. **前任审计衔接评估不足**：对前期非本所审计的比较信息可靠性评估不充分。

### 低风险

1. **比较信息个别项目遗漏**：非重大项目的比较信息列报有遗漏，不影响整体理解。
2. **列报格式细节偏差**：比较信息列报格式与规范存在细微差异。
3. **索引引用不完整**：比较信息底稿与期初余额、附注的交叉索引不完整。
