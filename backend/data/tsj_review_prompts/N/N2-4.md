# N2-4 税收政策检查复核提示词

## 概述

本提示词针对税收政策检查表（N2-4）的复核，聚焦被审计单位适用税种及税率的正确性、税收优惠资质的有效性、征收方式的合规性，以及本期税收政策变化对应交税费的影响。税收政策检查是判断计税基础与税率是否正确的前提，政策适用错误将系统性影响全部税种的计提与申报。

**法规依据：**
- 《中华人民共和国税收征收管理法》
- 《企业会计准则第30号——财务报表列报》
- 《中国注册会计师审计准则第1301号——审计证据》
- 《中国注册会计师审计准则第1141号——财务报表审计中与舞弊相关的责任》

## tips

1. **先确认纳税人身份与适用税种**：一般纳税人/小规模纳税人身份决定增值税计税方式；行业属性决定适用税种（如资源税、消费税、土地增值税），身份或税种识别错误将系统性影响计提。
2. **税率须核对最新政策文件**：各税种税率（增值税 13%/9%/6%/征收率、企业所得税 25%/优惠税率、附加税比例）须核对现行税法及地方规定，防止套用过期税率。
3. **税收优惠资质需有效证据**：高新技术企业、小型微利企业、软件企业、西部大开发等优惠须核验批文、备案、资质证书的有效期与适用条件，资质失效或不符条件仍享受优惠为重大风险。
4. **征收方式合规性**：查账征收/核定征收方式须与税务登记一致；核定征收下计税依据与查账口径可能不同，需关注计提逻辑。
5. **政策变化的影响评估**：本期税率调整、优惠到期、政策新规（如留抵退税、加计抵减）须评估对期末应交税费和当期损益的影响，并检查是否及时反映。
6. **保持职业怀疑（舞弊视角）**：关注是否存在滥用优惠、虚构资质、拆分业务规避税负等税务舞弊迹象，异常低税负须追查。

## checklist

### 一、纳税人身份与适用税种（高风险）

- [ ] 【必检】增值税纳税人身份（一般/小规模）是否与税务登记一致
- [ ] 【必检】适用税种是否完整（结合行业属性识别资源税/消费税/土地增值税等）
- [ ] 【必检】各税种适用税率是否核对现行税法及地方规定
- [ ] 【必检】附加税（城建税、教育费附加、地方教育附加）比例是否正确
- [ ] 【风险检查】是否存在应缴税种未识别（漏缴风险）
- [ ] 【风险检查】是否套用已废止或过期的税率

### 二、税收优惠资质（高风险）

- [ ] 【必检】所享受税收优惠是否有批文/备案/资质证书
- [ ] 【必检】优惠资质是否在有效期内
- [ ] 【必检】是否持续符合优惠适用条件（如高新研发费占比、小微企业指标）
- [ ] 【条件检查：若为高新技术企业】研发费用占比、高新收入占比是否达标
- [ ] 【条件检查：若为小型微利企业】从业人数、资产总额、应纳税所得额是否符合标准
- [ ] 【风险检查】是否存在资质失效仍享受优惠或虚构资质套取优惠

### 三、征收方式与政策变化（中风险）

- [ ] 【必检】征收方式（查账/核定征收）是否与税务登记一致
- [ ] 【必检】本期税收政策变化（税率调整/优惠到期/新政）是否识别
- [ ] 【必检】政策变化对期末应交税费及当期损益的影响是否评估并反映
- [ ] 【条件检查：若适用留抵退税/加计抵减】是否符合政策条件且会计处理正确
- [ ] 【必检】税务事项通知书、税务检查结论是否已考虑

## risk_areas

### 高风险

1. **适用税率错误**：套用错误或过期税率，系统性影响全部相关税种计提与申报。
2. **税收优惠资质失效**：优惠资质过期或不符条件仍享受，形成补税及滞纳金风险。
3. **应缴税种漏识别**：因行业属性识别错误漏缴资源税、消费税、土地增值税等。

### 中风险

1. **征收方式不合规**：核定征收与查账口径混用，计提逻辑错误。
2. **政策变化未及时反映**：税率调整、优惠到期未反映至计提，影响期末应交数。
3. **优惠会计处理错误**：留抵退税、加计抵减政策会计处理不符合规定。

### 低风险

1. **政策文件索引不全**：适用税率、优惠依据的政策文件引用不完整。
2. **征收方式说明不足**：核定征收计税依据说明不清晰。
