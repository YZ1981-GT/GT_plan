# N4-3 税金及附加调整分录复核提示词

## 概述

本提示词针对税金及附加调整分录（N4-3，科目 6403）的复核，含账项调整（AJE）与重分类调整（RJE）。复核聚焦：每笔调整分录借贷平衡、调整依据充分（漏提税种补计/计税基础修正/计入科目口径修正）、金额完整回写审定表 N4-1、以及与 A13 未调整错报汇总的交叉验证。税金及附加的调整多源于小税种漏提补计、税金及附加与管理费用的口径重分类、以及与 N2 应交税费计提的联动修正，调整须同步影响应交税费负债。

**法规依据：**
- 《企业会计准则第30号——财务报表列报》
- 《企业会计准则第28号——会计政策、会计估计变更和差错更正》
- 《中国注册会计师审计准则第1301号——审计证据》

## tips

1. **借贷平衡是形式底线**：每笔调整分录借贷方必须完全平衡，税金及附加（6403）的补提对方通常为应交税费（2221），须核对对方科目与联动负债。
2. **调整依据须充分可追溯**：调整分录须有明确依据——漏提税种补计、计税基础/税率修正、计入科目口径修正（税金及附加↔管理费用重分类），每笔可追溯至具体审计程序或明细表 N4-2。
3. **完整回写 N4-1 审定表**：审定表 N4-1 调整列金额须与 N4-3 已确认分录逐笔一致，遗漏任一笔即审定数失真。
4. **补提须联动应交税费**：补计税金及附加（AJE）通常同步增加应交税费（N2），须核实调整是否同步反映到 N2 应交税费，避免费用调而负债未调。
5. **区分 AJE 与 RJE**：税金及附加与管理费用间的口径重分类为 RJE（仅影响列报不影响利润总额）；补计漏提税种为 AJE（影响损益）——不得以 RJE 掩盖费用漏计。
6. **A13 交叉验证**：因漏提税种或计税基础错误形成的未调整错报，须与 A13 未调整错报汇总交叉验证，评估单独及累计影响。

## checklist

### 一、分录平衡与依据（高风险）

- [ ] 【必检】每笔调整分录借贷方是否完全平衡
- [ ] 【必检】税金及附加（6403）补提的对方科目是否正确（应交税费 2221）
- [ ] 【必检】每笔调整是否有充分依据（漏提补计/计税基础修正/口径重分类）
- [ ] 【必检】调整金额是否可追溯至明细表 N4-2 或具体审计程序
- [ ] 【条件检查：若为补计漏提税种】补计税种是否有计税依据支持
- [ ] 【风险检查】是否存在无依据或仅为调节利润的不当调整

### 二、回写与联动（高风险）

- [ ] 【必检】审定表 N4-1 调整列是否与 N4-3 已确认分录逐笔一致
- [ ] 【必检】补计税金及附加（AJE）是否同步增加应交税费（N2）
- [ ] 【必检】各税种调整是否与 N2 应交税费对应税种计提额勾稽一致
- [ ] 【必检】税金及附加↔管理费用重分类是否正确（RJE 仅影响列报）
- [ ] 【风险检查】是否存在费用调整但应交税费负债未同步的情况

### 三、分类与错报评估（中风险）

- [ ] 【必检】AJE 与 RJE 是否正确区分（补提为 AJE，口径重分类为 RJE）
- [ ] 【必检】超过明细层次重要性水平的调整是否经适当层级审批
- [ ] 【必检】因漏提税种/计税错误形成的未调整错报是否纳入 A13 汇总
- [ ] 【条件检查：若为前期差错更正】是否正确区分本期调整与前期差错追溯
- [ ] 【风险检查】未调整错报单独及累计是否超过重要性阈值

## risk_areas

### 高风险

1. **补计费用未联动负债**：补计税金及附加（AJE）但应交税费（N2）未同步增加，导致费用调整与负债失衡。
2. **回写审定表不一致**：调整已录入 N4-3 但审定表 N4-1 未同步，导致审定数失真。
3. **调整缺乏依据或未经授权**：税金及附加调整无支持证据或未经适当审批。

### 中风险

1. **AJE/RJE 混淆**：将补计漏提税种（影响损益）误作 RJE 处理，掩盖费用漏计。
2. **口径重分类错误**：税金及附加与管理费用间重分类方向或金额错误。
3. **A13 交叉验证缺失**：漏提税种形成的错报未纳入未调整错报汇总。

### 低风险

1. **分录摘要/科目编码不规范**。
2. **索引指向明细表/应交税费底稿不完整**。
