# N5-7 财产损失明细表复核提示词

## 概述

本提示词针对财产损失明细表（N5-7）的复核，聚焦资产损失税前扣除的合规性、申报方式的正确性（专项申报/清单申报）、损失证据的充分性。明细表逐项列示本期发生的资产损失（应收款项坏账损失、存货毁损报废损失、固定资产处置/毁损损失、投资损失等），并核对税前扣除依据、申报方式与损失证据。资产损失税前扣除直接影响应纳税所得额（N5-4/N5-5），扣除不合规将形成纳税调整与补税风险。

**法规依据：**
- 《企业会计准则第18号——所得税》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **申报方式区分专项与清单**：正常经营活动中按公允价格销售/转让资产的损失、存货正常损耗等按清单申报；其他资产损失（如坏账、非正常损失、自然灾害）须专项申报，申报方式错误将影响扣除有效性。
2. **损失证据充分性是核心**：资产损失税前扣除须具备外部证据（法院判决、工商注销、公安证明、中介鉴证等）与内部证据（会计核算资料、内部审批、损失情况说明），证据不足不得税前扣除。
3. **坏账损失扣除条件**：应收款项坏账损失税前扣除须满足账龄、催收无果、债务人破产/注销等法定条件，仅计提减值准备（未实际发生）不得税前扣除，须纳税调增。
4. **损失金额=账面价值−可收回残值−责任赔偿/保险赔偿**：损失净额计算须扣除残值、保险赔偿、责任人赔偿，遗漏将虚增税前扣除损失。
5. **会计损失与税前扣除损失差异**：会计上确认的减值/损失与税法允许扣除的损失可能不同，差异形成纳税调整（N5-5）与暂时性差异（N1 递延所得税资产）。
6. **与减值/处置底稿勾稽**：财产损失须与相关资产减值底稿（K11/D2-3 坏账、F2 存货跌价、H1 固定资产处置）勾稽，损失确认与资产账面核销一致。

## checklist

### 一、损失税前扣除合规性（高风险）

- [ ] 【必检】各项资产损失税前扣除是否满足法定条件
- [ ] 【必检】坏账损失是否满足账龄/催收无果/债务人破产注销等条件
- [ ] 【必检】仅计提减值未实际发生的损失是否已纳税调增（不得税前扣除）
- [ ] 【必检】损失净额=账面价值−残值−赔偿 计算是否正确
- [ ] 【风险检查】是否将未实际发生损失税前扣除导致少缴所得税
- [ ] 【风险检查】损失是否遗漏扣除保险/责任人赔偿

### 二、申报方式与证据（高风险）

- [ ] 【必检】损失申报方式（专项申报/清单申报）是否正确
- [ ] 【必检】专项申报损失是否具备外部证据（法院/工商/公安/中介鉴证）
- [ ] 【必检】损失是否具备内部证据（会计资料/内部审批/情况说明）
- [ ] 【条件检查：若为非正常损失】增值税进项转出是否同步处理
- [ ] 【风险检查】证据不足的损失是否仍税前扣除

### 三、勾稽与调整（中风险）

- [ ] 【必检】财产损失是否与相关减值/处置底稿（K11/D2-3/F2/H1）勾稽
- [ ] 【必检】会计损失与税前扣除损失差异是否形成纳税调整（N5-5）
- [ ] 【必检】暂时性差异是否与 N1 递延所得税资产对应
- [ ] 【必检】损失确认是否与资产账面核销一致
- [ ] 【条件检查：若为以前年度损失】追补扣除是否符合规定期限

## risk_areas

### 高风险

1. **未实际发生损失税前扣除**：仅计提减值即税前扣除未纳税调增，少缴所得税。
2. **损失证据不足仍扣除**：缺乏外部/内部证据的损失税前扣除，形成补税风险。
3. **损失净额虚增**：未扣除残值/保险/责任赔偿，虚增税前扣除损失。

### 中风险

1. **申报方式错误**：专项申报损失按清单申报，影响扣除有效性。
2. **纳税调整遗漏**：会计损失与税前扣除损失差异未形成纳税调整。
3. **与减值底稿不勾稽**：财产损失与资产减值/核销底稿不一致。

### 低风险

1. **证据资料索引不全**：损失外部/内部证据归集索引不完整。
2. **格式与交叉索引不规范**：与 N5-5/N1/K11/D2-3/F2/H1 交叉引用标注不全。
