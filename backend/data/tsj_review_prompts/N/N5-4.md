# N5-4 当期所得税费用计算表复核提示词

## 概述

本提示词针对当期所得税费用计算表（N5-4，核心底稿）的复核，聚焦应纳税所得额的推算、适用税率的正确性，以及与应交企业所得税的勾稽。计算表按"应纳税所得额 = 利润总额 ± 纳税调整"、"当期所得税 = 应纳税所得额 × 适用税率 − 减免"的逻辑重构当期所得税计算过程，是所得税费用的两大构成之一，也是纳税调整完整性验证的核心。当期所得税计算错误将直接导致所得税费用与应交税费双向错报。

**法规依据：**
- 《企业会计准则第18号——所得税》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **利润总额为计算起点**：应纳税所得额从利润总额出发，须与利润表利润总额勾稽，起点错误将系统性影响后续计算。
2. **纳税调整完整性是首要风险**：应纳税所得额=利润总额±纳税调整，纳税调整须涵盖永久性差异（罚款、非公益捐赠、超标招待费/广宣费）与暂时性差异（减值、折旧税会差异等），调整项遗漏（尤其调增项）将低估应纳税所得额与当期所得税。
3. **适用税率须有依据**：基本税率 25%，优惠税率（高新 15%、小微 5%/20% 等）须核验资质与政策条件，税率适用与 N5-6 税收优惠明细一致。
4. **与应交企业所得税勾稽**：当期所得税费用须与 N2 应交企业所得税本期计提、企业所得税汇算清缴/预缴申报勾稽，差异须解释。
5. **减免税额与抵免**：税额减免、研发费加计扣除、境外所得税抵免等须核验依据并正确计算，不得虚增减免。
6. **纳税调整明细勾稽 N5-5**：纳税调整各项须与纳税调整明细表（N5-5）逐项勾稽；调整方向（调增/调减）须正确，避免调增调减混淆。

## checklist

### 一、应纳税所得额推算（高风险）

- [ ] 【必检】利润总额是否与利润表勾稽
- [ ] 【必检】应纳税所得额=利润总额±纳税调整 计算是否正确
- [ ] 【必检】纳税调整各项是否与 N5-5 纳税调整明细表勾稽
- [ ] 【必检】永久性差异（罚款/非公益捐赠/超标招待费广宣费）调增是否完整
- [ ] 【必检】暂时性差异纳税调整方向（调增/调减）是否正确
- [ ] 【风险检查】是否遗漏纳税调增项导致应纳税所得额低估
- [ ] 【风险检查】是否将不可扣除支出误作可扣除（少调增）

### 二、税率适用与减免（高风险）

- [ ] 【必检】适用税率（25%/优惠税率）是否有依据
- [ ] 【必检】优惠税率适用是否与 N5-6 税收优惠明细一致
- [ ] 【必检】当期所得税=应纳税所得额×税率−减免 计算是否正确
- [ ] 【条件检查：若有研发加计扣除】加计扣除计算是否正确且有依据
- [ ] 【条件检查：若有境外所得】境外所得税抵免限额计算是否正确
- [ ] 【风险检查】是否虚增税额减免/抵免

### 三、勾稽核对（中风险）

- [ ] 【必检】当期所得税费用是否与 N2 应交企业所得税本期计提勾稽
- [ ] 【必检】当期所得税是否与企业所得税汇算清缴/预缴申报勾稽
- [ ] 【必检】计算表当期所得税是否与 N5-2 明细表当期所得税分项一致
- [ ] 【条件检查：若有以前年度调整】汇算清缴差异是否单独反映
- [ ] 【必检】计算结果差异（账面vs申报）是否查明原因

## risk_areas

### 高风险

1. **纳税调整不完整**：漏调永久性差异（罚款、非公益捐赠、超标费用），应纳税所得额与当期所得税低估。
2. **调整方向错误**：调增调减混淆或暂时性差异方向错误，系统性影响应纳税所得额。
3. **税率/减免虚增**：套用不符条件的优惠税率或虚增减免抵免，少计当期所得税。

### 中风险

1. **与应交所得税不勾稽**：当期所得税费用与 N2 应交企业所得税、申报数不一致未解释。
2. **利润总额起点错误**：利润总额与利润表不一致导致计算偏差。
3. **加计扣除计算错误**：研发费加计扣除范围或比例错误。

### 低风险

1. **计算过程说明不足**：纳税调整与税率适用说明不清晰。
2. **格式与交叉索引不规范**：与 N5-5/N5-6/N2/申报表交叉引用标注不全。
