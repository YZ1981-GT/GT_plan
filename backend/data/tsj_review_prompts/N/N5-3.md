# N5-3 所得税费用调整分录复核提示词

## 概述

本提示词针对所得税费用调整分录汇总表（N5-3）的复核，含账项调整（AJE）、重分类调整（RJE）及未调整错报评估。所得税调整多源于纳税调整补充确认当期所得税、递延所得税重新计量、以前年度汇算清缴差异、税率变动影响等。复核须验证：每笔调整有税务/准则依据、借贷平衡、完整回写 N5-1 审定表、并与 N1/N3 递延所得税及 A13 未调整错报汇总联动。

**法规依据：**
- 《企业会计准则第18号——所得税》
- 《企业会计准则第28号——会计政策、会计估计变更和差错更正》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **AJE 与 RJE 区分**：补提当期所得税、重新计量递延所得税为 AJE（影响损益）；所得税费用与递延资产/负债列报调整为 RJE（仅影响列报）。
2. **调整须有依据**：所得税调整须附纳税调整依据、汇算清缴结果、递延税计算表、税率文件等，不得主观补提/冲减。
3. **联动 N1/N3 递延税**：递延所得税费用调整须同步调整 N1 递延所得税资产/N3 递延所得税负债余额，单向调整将造成递延税不勾稽。
4. **区分损益与 OCI**：计入其他综合收益的递延税调整须计入 OCI 而非所得税费用，误计入损益是常见错误。
5. **跨期差错处理**：以前年度所得税差错更正区分本期调整与前期差错追溯（CAS28），重大前期差错可能需追溯重述。
6. **TB 回写与 A13 汇总**：确认调整已同步试算平衡表 6801/1811/2901 科目；未调整错报与 A13 交叉验证，评估对损益与税务负债的综合影响。

## checklist

### 一、调整合规性（高风险）

- [ ] 【必检】每笔调整分录借贷方是否完全平衡
- [ ] 【必检】所得税调整是否有充分依据（纳税调整/汇算清缴/递延税计算）
- [ ] 【必检】调整金额是否完整反映到 N5-1 审定表对应调整列
- [ ] 【必检】递延所得税调整是否同步联动 N1 资产/N3 负债余额
- [ ] 【必检】当期所得税调整是否与 N2 应交企业所得税勾稽
- [ ] 【风险检查】是否存在无依据的主观补提/冲减所得税
- [ ] 【风险检查】计入 OCI 的递延税调整是否误计入损益

### 二、分类与跨期（中风险）

- [ ] 【必检】RJE 是否仅涉及列报，未影响损益类科目
- [ ] 【必检】跨期调整是否正确区分本期调整与前期差错更正（CAS28）
- [ ] 【条件检查：若涉及重大前期差错】是否评估追溯重述及披露
- [ ] 【条件检查：若税率变动】税率变动对递延税调整是否正确计量
- [ ] 【必检】调整原因说明是否清晰可追溯至审计程序/税务核查

### 三、汇总与索引（中风险）

- [ ] 【必检】未调整错报累计是否与 A13 未调整错报汇总交叉验证
- [ ] 【必检】调整后审定数是否同步回写试算平衡表 6801/1811/2901
- [ ] 【必检】分录编号是否连续，删除后重号风险是否可控
- [ ] 【必检】索引是否指向 N5-4/N5-5/N5-8 等支持底稿

## risk_areas

### 高风险

1. **调整缺乏依据**：补提/冲减所得税无纳税调整/汇算清缴支持。
2. **递延税联动遗漏**：递延所得税调整未同步 N1/N3，递延税不勾稽。
3. **OCI 递延税误计损益**：计入权益的递延税调整误影响损益。

### 中风险

1. **审定表回写不一致**：调整金额未完整回写 N5-1，审定数失真。
2. **跨期差错分类错误**：前期所得税差错误作本期调整未追溯。
3. **A13 汇总遗漏**：未调整所得税错报未纳入错报汇总。

### 低风险

1. **编号、摘要、科目编码不规范**。
2. **调整说明与支持底稿索引不完整**。
