# N4-note-soe 税金及附加附注披露复核提示词（国有企业）

## 概述

本提示词针对税金及附加国有企业附注披露底稿（N4-note-soe，科目 6403）的复核。在满足企业会计准则通用披露（按税种分项披露本期发生额与上期可比数）的基础上，聚焦国有企业特定关注点：国资委财务决算报告对税费负担的补充披露要求、税费与预算执行的关联、决算报表口径一致性。国有企业税金及附加披露除满足会计准则外，还须满足国有资产监管的决算报告要求。

**法规依据：**
- 《企业会计准则第30号——财务报表列报》
- 《中央企业财务决算报告管理办法》
- 《国有资产监督管理委员会关于加强中央企业财务决算管理工作有关事项的通知》
- 《中国注册会计师审计准则第1501号——对财务报表形成审计意见和出具审计报告》

## tips

1. **国企附注"双层"披露**：既满足 CAS30 通用披露（按税种分项披露本期发生额与上期数），又满足国资委财务决算报告的补充要求，两套要求互补不可替代。
2. **按税种分项披露**：税金及附加须按税种（城建税/教育费附加/地方教育附加/印花税/房产税/土地使用税/车船税/消费税/资源税等）分项披露本期发生额与上期可比数。
3. **税费与预算执行关联**：国有企业年度预算通常包含税费预算，附注/决算相关披露须体现实际税金及附加与预算的偏差及原因。
4. **决算报表口径一致**：附注税金及附加数据须与年度财务决算报表一致，差异须调节说明。
5. **合计勾稽审定表与利润表**：附注各税种合计必须等于审定表 N4-1 审定数，并与利润表"税金及附加"行项目一致。
6. **与明细表勾稽**：附注各税种发生额须与明细表 N4-2 逐税种一致，计入税金及附加的口径一致。

## checklist

### 一、基础披露完整性（与上市版共有）

- [ ] 税金及附加是否按税种分项披露本期发生额
- [ ] 城建税、教育费附加、地方教育附加是否分项列示
- [ ] 印花税、房产税、城镇土地使用税、车船税等小税种是否分项列示
- [ ] 各税种是否同时列示本期数与上期数（可比信息）
- [ ] 附注各税种合计是否等于审定表 N4-1 审定数
- [ ] 附注合计是否与利润表"税金及附加"行项目一致

### 二、预算执行与决算一致性

- [ ] 本期税金及附加与年度税费预算的对比是否披露（如决算要求）
- [ ] 预算偏差超过一定比例时是否说明原因
- [ ] 附注税金及附加数据是否与年度财务决算报表一致
- [ ] 决算数据与审计后数据差异是否编制调节说明

### 三、变动分析与勾稽

- [ ] 某税种较上期重大变动是否有原因说明
- [ ] 税金及附加变动是否与营业收入变动趋势匹配
- [ ] 消费税、资源税变动是否与应税销售/产量匹配
- [ ] 附注各税种发生额是否与明细表 N4-2 逐税种一致
- [ ] 计入税金及附加的口径是否与会计政策一致

## risk_areas

### 高风险

1. **附注合计与审定表/利润表/决算不勾稽**：附注税金及附加各税种合计与审定表 N4-1、利润表行项目或财务决算报表不一致。
2. **税种分项披露缺失**：仅披露税金及附加总额未按税种分项，不满足编报及决算细化披露要求。

### 中风险

1. **预算偏差未说明**：税金及附加与年度预算存在重大偏差但未说明原因（决算报告要求）。
2. **小税种遗漏或笼统归集**：印花税、房产税、土地使用税等未分项或全部计入"其他"。
3. **决算与审计口径差异未调节**：财务决算数据与审计后附注数据存在差异但未编制调节说明。

### 低风险

1. **披露格式未完全按决算模板**：附注格式与国资委决算报表模板有细微差异。
2. **变动分析深度不足**：仅列示数据未结合业务对税费结构变动进行分析。
