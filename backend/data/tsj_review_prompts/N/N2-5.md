# N2-5 应交税金认定表复核提示词

## 概述

本提示词针对应交税金认定表（N2-5）的复核，聚焦对各税种期末应交金额的独立认定与验证。认定表以税种为维度，逐项列示计税依据、适用税率、认定应交金额，并与账面计提数、纳税申报数三方核对。认定表是审定表（N2-1）"存在与完整性"认定的支撑底稿，核心目的是通过独立测算验证账面应交税费余额既不虚增亦无遗漏，防止负债低估或虚挂。

**法规依据：**
- 《企业会计准则第30号——财务报表列报》
- 《中国注册会计师审计准则第1301号——审计证据》

## tips

1. **独立认定优先于账面复核**：认定表应基于计税依据（销售额、利润、房产原值、占地面积等）独立测算应交金额，而非简单照抄账面计提数，独立测算与账面差异是发现漏计/多计的关键。
2. **计税依据的取数须可追溯**：各税种计税依据须追溯至收入明细、利润表、资产台账、工资表等原始数据源，计税依据错误将直接导致认定金额失真。
3. **三方核对是认定的核心**：认定应交金额、账面计提数、纳税申报数三者须一致；任一差异须查明原因（时间性差异、计税口径差异或错报）。
4. **税率适用须与 N2-4 政策检查一致**：认定所用税率、征收率、优惠税率须与税收政策检查表（N2-4）结论一致，防止税率适用矛盾。
5. **完整性认定（首要）**：须交叉核查是否存在应认定而未认定的税种（视同销售增值税、代扣代缴、印花税等），认定范围遗漏即完整性缺陷。
6. **认定结果回勾审定表**：各税种认定应交金额合计须与 N2-1 审定合计勾稽，认定差异须通过 N2-3 调整分录处理。

## checklist

### 一、计税依据与认定准确性（高风险）

- [ ] 【必检】各税种计税依据是否取自可追溯的原始数据源
- [ ] 【必检】计税依据金额是否与收入明细/利润表/资产台账勾稽
- [ ] 【必检】认定应交金额=计税依据×适用税率 计算是否正确
- [ ] 【必检】适用税率是否与 N2-4 税收政策检查结论一致
- [ ] 【风险检查】独立认定金额与账面计提数差异是否查明原因
- [ ] 【风险检查】是否存在计税依据人为压低导致认定金额偏低

### 二、税种认定完整性（高风险）

- [ ] 【必检】增值税、企业所得税等主税种是否逐项认定
- [ ] 【必检】城建税及附加、印花税、房产税、土地使用税等是否完整认定
- [ ] 【必检】代扣代缴个税、视同销售增值税是否纳入认定范围
- [ ] 【条件检查：若有特殊税种】资源税、消费税、土地增值税是否认定
- [ ] 【风险检查】是否存在应认定税种遗漏导致负债低估

### 三、三方核对与勾稽（中风险）

- [ ] 【必检】认定应交金额与账面计提数是否核对一致
- [ ] 【必检】认定应交金额与纳税申报数是否核对一致
- [ ] 【必检】各税种认定金额合计是否与 N2-1 审定合计勾稽
- [ ] 【必检】认定差异是否通过 N2-3 调整分录处理
- [ ] 【条件检查：若存在差异】差异是否区分时间性差异与错报

## risk_areas

### 高风险

1. **认定范围遗漏**：应认定税种未纳入（视同销售、代扣代缴、小税种），完整性缺陷导致负债低估。
2. **计税依据错误**：计税依据取数错误或人为压低，系统性影响认定金额。
3. **三方核对不一致**：认定/账面/申报三方差异未查明原因，隐藏错报。

### 中风险

1. **税率适用矛盾**：认定税率与 N2-4 政策检查结论不一致。
2. **认定差异未调整**：认定与账面差异未通过 N2-3 调整处理。
3. **审定表勾稽断裂**：认定合计与 N2-1 审定数不一致。

### 低风险

1. **认定说明不足**：计税依据来源与计算过程说明不清晰。
2. **格式与交叉索引不规范**：与 N2-1/N2-4/纳税申报表交叉引用标注不全。
