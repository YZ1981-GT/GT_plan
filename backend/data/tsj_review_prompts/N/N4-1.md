# N4-1 税金及附加审定表复核提示词

## 概述

本提示词针对税金及附加审定表（N4-1，科目 6403，损益类借方，取本期发生额）的复核。税金及附加核算城建税、教育费附加、地方教育附加、印花税、房产税、土地使用税、车船税、消费税、资源税等与经营相关的税费。聚焦：发生额勾稽、试算表核对、与 N2 应交税费计提的对应、与营业收入/主营业务的匹配、完整性。

**法规依据：**
- 《企业会计准则第30号——财务报表列报》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **取"发生额"非"余额"**：审定数按 6403 本期借方发生额±调整。
2. **发生额勾稽**：审定合计=未审+AJE+RJE，且=明细表 N4-2 各税种合计（N4-2-subtotal）。
3. **试算表核对**：审定合计与试算表 6403 审定发生额一致。
4. **与 N2 计提对应**：各税种费用（税金及附加）本期发生额应与 N2 应交税费对应税种本期计提额勾稽一致（费用确认=计提）。
5. **与收入匹配**：城建税、教育费附加随增值税，消费税随应税销售——税金及附加变动应与营业收入/主营业务税基变动匹配。
6. **完整性**：印花税、房产税、土地使用税、车船税等易漏计；注意计入税金及附加 vs 管理费用的口径（现行准则多数计税金及附加）。

## checklist

### 一、发生额勾稽与试算表核对

- [ ] 审定表各税种审定数=未审+AJE+RJE 是否正确
- [ ] 审定合计是否与明细表 N4-2 各税种合计一致
- [ ] 审定合计是否与试算表 6403 审定发生额一致
- [ ] 上期审定数是否与上年底稿一致

### 二、与 N2 及收入匹配

- [ ] 各税种本期费用是否与 N2 应交税费对应税种计提额勾稽一致
- [ ] 城建税、教育费附加是否按增值税计提基数正确计算
- [ ] 消费税、资源税是否与应税销售/产量匹配
- [ ] 税金及附加变动是否与营业收入变动匹配、异常是否解释

### 三、完整性与分类

- [ ] 印花税、房产税、土地使用税、车船税等是否完整计提
- [ ] 各税费计入税金及附加 vs 管理费用的口径是否正确一致
- [ ] 资产负债表日税费是否足额计提（截止）

### 四、审计调整完整性

- [ ] 已确认的账项/重分类调整是否完整反映
- [ ] 调整分录借贷平衡、证据充分、经审批

## risk_areas

### 高风险

1. **与 N2 不对应**：税金及附加费用与应交税费计提不勾稽，存在少计费用/负债。
2. **完整性缺失**：小税种漏提，费用与负债双低估。
3. **审定表与试算表不勾稽**：发生额口径不一致。

### 中风险

1. **与收入不匹配**：税金及附加变动与收入背离未解释。
2. **计入科目口径错误**：房产税/土地使用税等在税金及附加与管理费用间错分。
3. **审计调整遗漏**。

### 低风险

1. **格式与索引不规范**。
2. **税种明细说明不足**。
