# N2-10 土地增值税测算表复核提示词

## 概述

本提示词针对土地增值税测算表（N2-10）的复核，聚焦增值额计算、扣除项目归集、四级超率累进税率适用，以及清算时点与预征的正确处理。测算表按"收入 − 扣除项目 = 增值额"、"增值额 ÷ 扣除项目 = 增值率"、按增值率适用四级累进税率的逻辑重构土地增值税计算，并区分预征与清算。土地增值税涉及金额通常重大、计算复杂，扣除项目归集与清算判断是高风险审计领域。

**法规依据：**
- 《企业会计准则第30号——财务报表列报》
- 《中国注册会计师审计准则第1301号——审计证据》

## tips

1. **收入确认口径须准确**：土地增值税转让房地产收入含货币及非货币收入，须与销售明细、发票、收入确认勾稽，价外费用是否计入须判断。
2. **扣除项目归集是核心难点**：扣除项目含取得土地使用权成本、开发成本、开发费用、税金及附加、房地产开发企业加计扣除 20%；扣除项目虚增将低估增值额与税额，须逐项核验凭证。
3. **增值额与增值率决定税率级次**：增值额=收入−扣除项目，增值率=增值额÷扣除项目；四级超率累进税率（30%/40%/50%/60%）按增值率级次适用并有速算扣除，级次判断错误直接影响税额。
4. **预征与清算区分**：达到清算条件前按预征率预缴，达到清算条件（如竣工验收、销售比例达标、转让整体项目）须清算；应清算未清算将导致应交税费与损益重大错报。
5. **普通住宅免税与分类核算**：符合条件的普通标准住宅增值率未超 20% 免税，须与其他类型房产分类核算，混算将影响免税判断。
6. **清算测算与账面勾稽**：清算应补/应退土地增值税须与预缴数比较，测算认定数与账面计提数差异须查明，并评估对存货/开发成本结转的影响。

## checklist

### 一、收入与扣除项目（高风险）

- [ ] 【必检】转让房地产收入是否完整（含货币及非货币收入、价外费用判断）
- [ ] 【必检】收入是否与销售明细、发票、D4 收入确认勾稽
- [ ] 【必检】扣除项目（土地成本/开发成本/开发费用/税金/加计扣除）是否逐项核验凭证
- [ ] 【必检】房地产开发企业加计扣除 20% 适用是否正确
- [ ] 【风险检查】扣除项目是否虚增（无凭证/不相关成本计入）导致税额低估
- [ ] 【风险检查】收入是否遗漏价外费用或非货币对价

### 二、增值额与税率（高风险）

- [ ] 【必检】增值额=收入−扣除项目 计算是否正确
- [ ] 【必检】增值率=增值额÷扣除项目 计算是否正确
- [ ] 【必检】四级超率累进税率级次（30%/40%/50%/60%）适用是否正确
- [ ] 【必检】速算扣除系数是否正确应用
- [ ] 【条件检查：若含普通住宅】普通标准住宅增值率未超20%免税是否分类核算
- [ ] 【风险检查】税率级次判断是否错误（人为压低增值率降级次）

### 三、预征清算与勾稽（中风险）

- [ ] 【必检】预征阶段是否按预征率正确预缴
- [ ] 【必检】是否达到清算条件（竣工验收/销售比例/整体转让），应清算是否已清算
- [ ] 【必检】清算应补/应退土地增值税与预缴数比较是否正确
- [ ] 【必检】测算认定数与账面计提数差异是否查明原因
- [ ] 【条件检查：若已清算】清算对存货/开发成本结转影响是否反映

## risk_areas

### 高风险

1. **应清算未清算**：达到清算条件未清算，应交税费与损益重大错报。
2. **扣除项目虚增**：无凭证或不相关成本计入扣除，低估增值额与税额。
3. **税率级次错误**：增值率计算或级次判断错误，系统性影响税额。

### 中风险

1. **收入不完整**：价外费用、非货币对价遗漏，低估增值额。
2. **免税判断错误**：普通住宅未分类核算，免税适用不当。
3. **预征清算勾稽断裂**：清算应补/应退与预缴数比较错误。

### 低风险

1. **测算过程说明不足**：扣除项目归集与税率适用说明不清晰。
2. **格式与交叉索引不规范**：与 D4/F2 存货/N2-2 交叉引用标注不全。
