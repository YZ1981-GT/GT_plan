# N2-6 应交增值税测算表复核提示词

## 概述

本提示词针对应交增值税测算表（N2-6）的复核，聚焦增值税应纳税额的独立测算与勾稽验证。测算表按"销项税额 − 进项税额 − 已交税额 = 期末应交/留抵"的逻辑重构增值税计算过程，并关注进项转出、视同销售、留抵税额等特殊事项，最终与增值税纳税申报表勾稽。增值税是应交税费的核心税种，测算错误将直接导致负债与损益的重大错报。

**法规依据：**
- 《企业会计准则第30号——财务报表列报》
- 《中国注册会计师审计准则第1301号——审计证据》

## tips

1. **销项税额与收入勾稽是起点**：销项税额=不含税销售额×适用税率，须与 D4 营业收入、增值税申报表销售额勾稽；收入与销项税不匹配（少计销项）是虚减负债的典型迹象。
2. **进项税额须核验抵扣合规性**：进项税额须凭合规增值税专用发票/海关缴款书等抵扣凭证，关注不得抵扣项目（用于集体福利、简易计税、免税项目的进项）是否已转出。
3. **进项税额转出的完整性**：非正常损失、改变用途、免税项目对应进项须转出；进项转出漏计将虚增可抵扣进项、虚减应交增值税。
4. **视同销售须全面识别**：无偿赠送、自产自用、以货抵债等视同销售行为须计提销项，遗漏视同销售导致销项少计。
5. **留抵税额的方向与列报**：进项大于销项形成期末留抵（借方余额），留抵退税须符合政策条件；留抵在报表列报应考虑重分类。
6. **与申报表逐栏勾稽**：测算的销项、进项、进项转出、已交税额、期末应交/留抵须与增值税纳税申报表主表及附列资料逐栏核对，差异须解释。

## checklist

### 一、销项税额（高风险）

- [ ] 【必检】销项税额=不含税销售额×适用税率 计算是否正确
- [ ] 【必检】销售额是否与 D4 营业收入、增值税申报销售额勾稽
- [ ] 【必检】不同税率（13%/9%/6%/征收率）销售是否分别测算
- [ ] 【必检】视同销售行为（无偿赠送/自产自用/以货抵债）是否计提销项
- [ ] 【风险检查】是否存在收入已确认但销项税未计提（少计销项）
- [ ] 【风险检查】是否存在延迟确认销项以推迟纳税

### 二、进项税额与转出（高风险）

- [ ] 【必检】进项税额是否凭合规抵扣凭证（专票/海关缴款书等）
- [ ] 【必检】不得抵扣项目（集体福利/简易计税/免税项目）进项是否已转出
- [ ] 【必检】非正常损失、改变用途对应进项转出是否完整
- [ ] 【条件检查：若有农产品收购】农产品进项计算抵扣是否正确
- [ ] 【风险检查】是否存在虚抵进项（无真实业务/发票不合规）
- [ ] 【风险检查】进项转出是否漏计导致虚减应交增值税

### 三、勾稽与申报核对（中风险）

- [ ] 【必检】"销项−进项−已交=期末应交/留抵"测算逻辑是否成立
- [ ] 【必检】期末应交增值税/留抵税额是否与增值税申报表勾稽
- [ ] 【必检】已交税额是否与完税凭证/银行回单核对
- [ ] 【必检】测算期末数是否与 N2-2 明细表增值税期末余额一致
- [ ] 【条件检查：若适用留抵退税/加计抵减】政策条件与会计处理是否正确

## risk_areas

### 高风险

1. **销项税额少计**：收入已确认未计提销项、视同销售遗漏，虚减应交增值税。
2. **进项转出漏计**：不得抵扣进项未转出，虚增可抵扣进项、虚减负债。
3. **虚抵进项**：无真实业务或发票不合规的进项税额抵扣。

### 中风险

1. **测算与申报不符**：测算期末应交/留抵与增值税申报表差异未解释。
2. **留抵列报错误**：期末留抵（借方）未按列报要求重分类。
3. **税率适用错误**：不同税率业务混算，销项测算偏差。

### 低风险

1. **测算过程说明不足**：销项/进项分项测算依据说明不清晰。
2. **格式与交叉索引不规范**：与 D4/N2-2/申报表交叉引用标注不全。
