# N5-8 递延所得税费用核对表复核提示词

## 概述

本提示词针对递延所得税费用核对表（N5-8）的复核，聚焦递延所得税费用的核算勾稽：递延所得税费用 = 递延所得税负债（N3）本期变动 − 递延所得税资产（N1）本期变动，并区分计入损益与计入其他综合收益/权益的部分。核对表将递延所得税费用与 N1 递延所得税资产、N3 递延所得税负债的期初期末变动逐项衔接，是所得税费用（N5-1/N5-2）的两大构成之一。递延所得税与 N1/N3 不勾稽、OCI 部分误计损益是本表的核心风险。

**法规依据：**
- 《企业会计准则第18号——所得税》
- 《中国注册会计师审计准则第1301号——审计证据》

## tips

1. **核心勾稽公式**：递延所得税费用（计入损益）=（N3 递延所得税负债期末−期初）−（N1 递延所得税资产期末−期初），且须剔除计入 OCI/权益的部分，公式勾稽断裂即错报。
2. **计入 OCI/权益部分不计入损益**：其他债权投资公允价值变动、现金流量套期、其他综合收益相关的递延税影响直接计入 OCI；与直接计入权益交易相关的递延税计入权益，误计入所得税费用是常见错误。
3. **与 N1/N3 本期变动逐项衔接**：递延所得税资产（N1）、递延所得税负债（N3）的本期确认/转回须逐项与暂时性差异对应，核对表须列示各暂时性差异项目的递延税变动。
4. **税率变动的影响**：适用税率变动时，递延所得税资产/负债须按新税率重新计量，重新计量差额计入变动当期损益（或 OCI），须单独反映。
5. **递延所得税资产确认的谨慎性**：可抵扣暂时性差异及可弥补亏损确认递延所得税资产须以"很可能取得用来抵扣的未来应纳税所得额"为限，未确认部分须在有效税率调节表体现。
6. **勾稽 N5-2 与有效税率调节**：递延所得税费用须与 N5-2 明细表递延所得税分项一致，并在有效税率调节表中作为调节项之一体现。

## checklist

### 一、递延所得税费用勾稽（高风险）

- [ ] 【必检】递延所得税费用（损益）=N3 负债本期变动−N1 资产本期变动 是否成立
- [ ] 【必检】计入损益与计入 OCI/权益的递延税是否正确区分
- [ ] 【必检】OCI/权益相关递延税是否未计入所得税费用
- [ ] 【必检】递延所得税费用是否与 N5-2 明细表递延所得税分项一致
- [ ] 【风险检查】是否将 OCI 递延税误计入损益
- [ ] 【风险检查】递延税费用与 N1/N3 变动是否勾稽断裂

### 二、N1/N3 变动衔接（高风险）

- [ ] 【必检】各暂时性差异项目递延税变动是否与 N1 资产/N3 负债逐项衔接
- [ ] 【必检】递延所得税资产/负债本期确认与转回是否与暂时性差异对应
- [ ] 【条件检查：若税率变动】递延税资产/负债是否按新税率重新计量
- [ ] 【条件检查：若税率变动】重新计量差额计入损益/OCI 是否正确
- [ ] 【风险检查】递延所得税资产确认是否超过"很可能取得应纳税所得额"限度

### 三、勾稽与调节（中风险）

- [ ] 【必检】未确认递延所得税资产（可弥补亏损等）是否在有效税率调节表体现
- [ ] 【必检】递延所得税费用是否在有效税率调节表作为调节项
- [ ] 【必检】暂时性差异是否与 N5-5 纳税调整明细对应
- [ ] 【必检】上期递延所得税费用是否与上年底稿一致

## risk_areas

### 高风险

1. **与 N1/N3 不勾稽**：递延所得税费用与递延资产/负债本期变动不一致，勾稽断裂。
2. **OCI 递延税误计损益**：计入其他综合收益/权益的递延税影响错计入所得税费用。
3. **递延所得税资产确认过度**：可抵扣差异/亏损确认递延税资产超出未来应纳税所得额限度。

### 中风险

1. **税率变动重新计量错误**：税率变动未按新税率重新计量递延税或差额计入错误。
2. **暂时性差异衔接遗漏**：部分暂时性差异递延税变动未与 N1/N3 逐项衔接。
3. **有效税率调节遗漏**：未确认递延税资产未在调节表体现。

### 低风险

1. **核对过程说明不足**：递延税变动衔接说明不清晰。
2. **格式与交叉索引不规范**：与 N1/N3/N5-2/N5-5 交叉引用标注不全。
