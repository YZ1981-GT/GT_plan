# N5-note-soe 所得税费用附注披露复核提示词（国有企业）

## 概述

本提示词针对所得税费用国有企业附注披露底稿（N5-note-soe）的复核，聚焦国有企业特定的所得税披露要求：在所得税费用构成、有效税率调节表基础披露之外，增加税收优惠合规性、税务稽查/补税事项、财务决算报表口径一致性等国资监管相关信息。国有企业所得税披露除满足会计准则外，还须满足国资委财务决算报告要求，税负异常、税收优惠合规性是国资监管与审计的重点关注领域。

**法规依据：**
- 《企业会计准则第18号——所得税》
- 《中央企业财务决算报告管理办法》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **国有企业"双层"披露要求**：既满足会计准则的所得税费用构成与有效税率调节披露，又满足国资委财务决算报告的税负专项披露要求。
2. **所得税费用构成与调节表**：与上市版一致，须分别披露当期/递延所得税费用，并提供利润总额至所得税费用的有效税率调节表。
3. **税收优惠合规性专项披露**：享受的所得税优惠（高新、西部大开发、加计扣除等）须披露资质合规性，国企税收优惠合规是国资监管重点。
4. **税务稽查与补税披露**：本期税务稽查、补税、罚款、滞纳金等事项须披露金额及原因，可能涉及国有资产损失责任追究。
5. **决算报表口径一致**：所得税费用数据须与年度财务决算报表一致，决算附加信息表中税负相关数据须与本附注勾稽。
6. **与上市版的差异在监管层面**：基础披露框架（构成/调节表/递延税）与上市版相同，国企版额外增加税收优惠合规、税务稽查、决算口径等国资监管信息。

## checklist

### 一、基础披露完整性（与上市版共有）

- [ ] 是否分别披露当期所得税费用与递延所得税费用
- [ ] 所得税费用合计是否等于利润表及 N5-1 审定合计
- [ ] 是否提供利润总额至所得税费用的有效税率调节表
- [ ] 调节项是否逐项列示且与 N5-5/N5-6/N5-8 勾稽
- [ ] 递延所得税资产/负债及未确认可抵扣差异是否披露

### 二、税收优惠与税务合规（国企特定）

- [ ] 享受的所得税优惠是否披露资质及合规性
- [ ] 优惠资质有效性、适用条件持续满足情况是否说明
- [ ] 本期税务稽查/补税事项是否披露金额及原因
- [ ] 补税产生的滞纳金/罚款是否披露
- [ ] 是否存在税收优惠不合规导致的补税风险披露

### 三、决算口径与勾稽（中风险）

- [ ] 附注所得税数据是否与年度财务决算报表一致
- [ ] 决算附加信息表税负数据是否与本附注勾稽
- [ ] 有效税率异常（远高/低于法定）是否充分解释
- [ ] 所得税费用及构成是否与 N5-1 审定表、N5-2 明细表勾稽
- [ ] 集团合并层面所得税抵销/汇总是否完整

## risk_areas

### 高风险

1. **税收优惠合规性未披露**：享受优惠的资质合规性未说明，掩盖补税风险。
2. **税务稽查/补税未披露**：本期补税、罚款等重大事项未反映，可能涉及责任追究。
3. **附注与决算/审定不勾稽**：所得税数据与财务决算或 N5-1 审定合计不一致。

### 中风险

1. **有效税率调节表不勾稽**：调节后所得税费用与实际不符或调节项倒挤。
2. **构成披露不完整**：未分别披露当期与递延所得税费用。
3. **决算口径差异未调节**：决算数据与审计后附注差异未调节说明。

### 低风险

1. **未确认递延税资产披露缺失**：可弥补亏损金额及到期日未披露。
2. **格式未按决算模板**：披露格式与国资委决算模板有细微差异但信息完整。
