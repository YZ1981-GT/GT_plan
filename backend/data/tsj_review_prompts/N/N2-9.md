# N2-9 房产税测算表复核提示词

## 概述

本提示词针对房产税测算表（N2-9）的复核，聚焦房产税从价计征（房产原值×税率）与从租计征（租金收入×税率）两种方式的正确适用与测算准确性，以及减免政策的适用性。测算表须区分自用房产（从价）与出租房产（从租），核对计税房产原值、扣除比例、适用税率，并与固定资产台账、租赁合同、纳税申报勾稽。房产税计税依据（房产原值范围）易出错，是小税种中的高频错报点。

**法规依据：**
- 《企业会计准则第30号——财务报表列报》
- 《中国注册会计师审计准则第1301号——审计证据》

## tips

1. **区分从价与从租计征**：自用房产从价计征（房产原值扣除 10%~30% 后×1.2%）；出租房产从租计征（租金收入×12%，个人住房出租另有优惠）；计征方式混用将导致计税错误。
2. **计税房产原值范围须准确**：从价计税的房产原值应包含与房屋不可分割的附属设备及配套设施（如给排水、采暖、电梯），遗漏附属设施将低估计税原值。
3. **扣除比例按地方规定**：房产原值一次减除比例（10%~30%）由省级政府确定，须核对当地规定，防止套用错误比例。
4. **从租收入的完整性**：出租房产须按实际租金收入（含视同租金、免租期分摊）计征，关联方低价出租、免租期未分摊将低估从租房产税。
5. **减免政策核验**：符合条件的房产（如自用于特定用途、困难减免）享受减免须有批文/备案，减免范围与期限须核验。
6. **与固定资产及租赁台账勾稽**：计税房产原值须与 H1 固定资产（房屋建筑物）台账勾稽，从租收入须与租赁合同/收入明细勾稽；测算认定数与账面计提差异须查明。

## checklist

### 一、从价计征测算（高风险）

- [ ] 【必检】自用房产是否按房产原值从价计征（原值×(1−扣除比例)×1.2%）
- [ ] 【必检】计税房产原值是否包含不可分割的附属设备及配套设施
- [ ] 【必检】房产原值扣除比例是否与当地省级规定一致
- [ ] 【必检】计税房产原值是否与 H1 固定资产（房屋建筑物）台账勾稽
- [ ] 【风险检查】是否遗漏附属设施导致计税原值低估
- [ ] 【风险检查】在建/未办产权房产的计税起始时点是否正确

### 二、从租计征测算（中风险）

- [ ] 【必检】出租房产是否按租金收入从租计征（租金×12%）
- [ ] 【必检】从租收入是否完整（含视同租金、免租期分摊）
- [ ] 【必检】从租收入是否与租赁合同/收入明细勾稽
- [ ] 【条件检查：若关联方出租】租金定价公允性是否评估
- [ ] 【风险检查】是否存在免租期未分摊或关联方低价出租低估从租房产税

### 三、减免与勾稽（中风险）

- [ ] 【必检】享受减免的房产是否有批文/备案且符合条件
- [ ] 【必检】减免范围与期限是否核验
- [ ] 【必检】房产税本期计提数是否与 N4 税金及附加勾稽
- [ ] 【必检】测算认定数与账面计提数差异是否查明原因
- [ ] 【条件检查：若期后已缴纳】期后缴纳是否与完税凭证核对

## risk_areas

### 高风险

1. **计税原值遗漏附属设施**：从价计税房产原值未含不可分割附属设备，低估计税原值。
2. **计征方式错误**：自用/出租房产从价从租计征方式混用。
3. **房产税漏提**：应税房产未纳入计征范围，负债低估。

### 中风险

1. **从租收入不完整**：免租期未分摊、关联方低价出租低估从租房产税。
2. **扣除比例错误**：房产原值扣除比例套用错误。
3. **减免适用不当**：减免条件不符或无批文仍享受减免。

### 低风险

1. **测算说明不足**：从价/从租计税依据与减免依据说明不清晰。
2. **格式与交叉索引不规范**：与 H1/N4/N2-2 交叉引用标注不全。
