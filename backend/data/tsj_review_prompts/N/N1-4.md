# N1-4 递延所得税资产测算表复核提示词

## 概述

本提示词针对递延所得税资产测算表（N1-4，科目 1811）的复核。测算表是递延所得税资产确认的核心引擎，逐项测算各可抵扣暂时性差异（账面价值与计税基础之差）、可弥补亏损、税款抵减，乘以预计转回期间适用税率，并在评估未来应纳税所得额充足性后确认可确认金额。复核聚焦：各项差异确认的准确性、适用税率（含税率变动重新计量）、确认前提（未来应纳税所得额充足）、税款抵减处理。测算表是全链路的判断核心，确认前提评估不当将直接导致虚增资产利润。

**法规依据：**
- 《企业会计准则第18号——所得税》
- 《中国注册会计师审计准则第1301号——审计证据》

## tips

1. **差异=账面价值−计税基础**：可抵扣暂时性差异须基于资产/负债账面价值与计税基础的准确比较，测算表须逐项列示账面价值、计税基础、差异金额，不得直接填列差异。
2. **适用税率取转回期间税率**：递延所得税资产=差异×预计转回期间适用税率；已颁布将于未来生效的税率变动，须在测算时对相关差异按新税率重新计量。
3. **确认前提是核心判断（首要风险）**：只有"很可能取得用来抵扣可抵扣暂时性差异的未来应纳税所得额"时才确认递延所得税资产，测算表须体现对未来应纳税所得额充足性的评估依据（盈利预测/纳税筹划）。
4. **可弥补亏损与税款抵减纳入测算**：可弥补亏损、税款抵减产生的递延所得税资产须在弥补/抵减有效期内测算，超期部分不得确认。
5. **未确认部分须明示**：对确认前提不足的可抵扣差异/可弥补亏损，测算表须列示"可确认金额"与"实际确认金额"的差异，未确认部分供附注披露。
6. **测算表驱动明细与审定**：N1-4 各项测算结果驱动明细表 N1-2 与审定表 N1-1，三者逐项勾稽；测算表是差异×税率×确认前提三重判断的落地。

## checklist

### 一、差异确认准确性（高风险）

- [ ] 【必检】各可抵扣暂时性差异是否基于账面价值与计税基础的准确比较
- [ ] 【必检】测算表是否逐项列示账面价值、计税基础、差异金额
- [ ] 【必检】各类差异（减值准备/预计负债/未实现内部利润/预收预提）是否测算完整
- [ ] 【必检】可弥补亏损、税款抵减是否纳入测算并在有效期内
- [ ] 【条件检查：若有合并抵销差异】未实现内部销售利润差异是否在合并层面正确测算
- [ ] 【风险检查】是否存在差异金额直接填列而无账面/计税基础支持

### 二、适用税率（高风险）

- [ ] 【必检】各项差异是否采用预计转回期间的适用税率
- [ ] 【必检】税率变动（已颁布未来生效）时是否对相关差异重新计量
- [ ] 【条件检查：若有多主体不同税率】各主体/分支机构适用税率是否分别测算
- [ ] 【风险检查】是否存在税率错用导致递延所得税资产虚增/少计

### 三、确认前提（高风险）

- [ ] 【必检】是否评估未来应纳税所得额充足性并留存依据
- [ ] 【必检】盈利预测/纳税筹划支持是否合理、有据、无明显乐观偏差
- [ ] 【必检】可弥补亏损确认递延所得税资产是否有充分证据（尤其历史亏损企业）
- [ ] 【必检】不满足确认前提的差异是否未确认（列示可确认与实际确认差异）
- [ ] 【必检】期末是否复核以前确认的递延所得税资产可收回性
- [ ] 【风险检查】是否存在确认前提不足仍全额确认导致虚增资产利润

### 四、税款抵减与勾稽（中风险）

- [ ] 【必检】税款抵减（如研发费用加计、投资抵免）处理是否正确
- [ ] 【必检】测算表各项结果是否与明细表 N1-2、审定表 N1-1 逐项勾稽
- [ ] 【必检】本期测算变动是否与 N5 递延所得税费用勾稽
- [ ] 【条件检查：若有可弥补亏损检查表 N1-5】测算与 N1-5 亏损弥补金额是否一致
- [ ] 【风险检查】未确认部分是否与附注披露口径一致

## risk_areas

### 高风险

1. **确认前提不足仍确认**：无充足未来应纳税所得额（尤其连续亏损企业的可弥补亏损）却全额确认递延所得税资产，虚增资产与利润，为最核心风险。
2. **差异×税率错误**：适用税率错用（未采用转回期间税率）或税率变动未重新计量，导致递延所得税资产计量错误。
3. **差异确认不准确**：账面价值与计税基础比较错误，或差异金额无支持性计算直接填列。

### 中风险

1. **可收回性未复核**：以前年度确认的递延所得税资产未在期末复核可收回性，未及时转销。
2. **可弥补亏损超期确认**：对已超过税法弥补期限的亏损仍确认递延所得税资产。
3. **未确认部分口径不一致**：测算表未确认金额与附注披露、N1-5 检查表不一致。

### 低风险

1. **测算过程记录不完整**：账面价值/计税基础来源未标注，复核可追溯性不足。
2. **格式与索引不规范**：与明细表、审定表、N1-5 检查表交叉索引缺失。
