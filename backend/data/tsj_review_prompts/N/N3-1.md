# N3-1 递延所得税负债审定表复核提示词

## 概述

本提示词针对递延所得税负债审定表（N3-1，科目 2901，负债类取期末余额）的复核。递延所得税负债源于应纳税暂时性差异（资产评估增值、公允价值变动收益、使用权资产/固定资产折旧税会差异、超税法摊销资产等）。聚焦：期初期末勾稽、试算表核对、应纳税暂时性差异×税率、与 N1 同源差异分列、与 N5 勾稽。核心风险为差异识别不完整导致少计负债、税率错误。

**法规依据：**
- 《企业会计准则第18号——所得税》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **负债类取"期末余额"**：审定数=期初+本期确认−本期转回±调整；本期变动经递延所得税费用（N5）体现。
2. **期初期末勾稽**：期初审定数=上年期末审定数；审定合计=明细表 N3-2 各项期末递延所得税负债合计。
3. **试算表核对**：审定合计与试算表 2901 审定余额一致（贷方方向）。
4. **差异×税率**：每项=应纳税暂时性差异×预计转回期间适用税率；税率变动重新计量。
5. **完整性**：应纳税暂时性差异易漏识（资产评估增值、其他权益工具/交易性金融资产公允价值变动、超税法折旧摊销、分期收款销售等），须逐项核查。
6. **与 N1/N5 勾稽**：同源差异在 N1/N3 分列不重复；本期 N1 资产变动+N3 负债变动应与 N5 递延所得税费用勾稽；计入其他综合收益的差异其递延税影响应计 OCI 而非损益。

## checklist

### 一、期初期末勾稽与试算表核对

- [ ] 期初审定数是否等于上年期末审定数
- [ ] 审定数=期初+确认−转回±调整 是否正确
- [ ] 审定合计是否与明细表 N3-2 期末合计一致
- [ ] 审定合计是否与试算表 2901 审定余额一致（贷方方向）

### 二、差异识别与计量

- [ ] 应纳税暂时性差异是否识别完整（评估增值、公允价值变动、折旧摊销税会差异、分期收款等）
- [ ] 每项差异×适用税率计算是否正确
- [ ] 税率变动时是否重新计量
- [ ] 与商誉初始确认等豁免情形是否正确处理（不确认递延所得税负债）

### 三、勾稽与调整

- [ ] 同源暂时性差异在 N1/N3 是否分列不重复
- [ ] 本期变动是否与 N5 递延所得税费用勾稽
- [ ] 计入其他综合收益的公允价值变动其递延税影响是否计 OCI 而非损益
- [ ] 已确认的账项/重分类调整是否完整反映、经审批

## risk_areas

### 高风险

1. **差异识别不完整**：漏识应纳税暂时性差异（评估增值、公允价值变动），少计递延所得税负债与所得税费用。
2. **差异×税率错误**：适用税率错误或税率变动未重新计量。
3. **期初期末不勾稽 / 与试算表不一致**。

### 中风险

1. **与 N1/N5 不勾稽**：同源差异重复计列或本期变动与所得税费用不符。
2. **OCI 项目处理错误**：公允价值变动的递延税影响错计损益。
3. **审计调整遗漏**。

### 低风险

1. **格式与索引不规范**。
2. **差异项目说明不足**。
