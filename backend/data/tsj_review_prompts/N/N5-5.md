# N5-5 纳税调整明细表复核提示词

## 概述

本提示词针对纳税调整明细表（N5-5）的复核，聚焦纳税调整项目的完整性与调整方向、金额的准确性。明细表逐项列示各纳税调整事项，区分永久性差异（罚款、非公益捐赠、超标业务招待费/广告宣传费、免税收入等）与暂时性差异（资产减值准备、折旧摊销税会差异、预计负债等），并标注调增/调减方向及金额。纳税调整明细是当期所得税计算表（N5-4）应纳税所得额推算的支撑底稿，调整项遗漏或方向错误将直接传导至当期所得税。

**法规依据：**
- 《企业会计准则第18号——所得税》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **永久性差异不可遗漏（调增项为重点）**：行政罚款/滞纳金、非公益性捐赠、超标业务招待费（发生额60%与收入5‰孰低）、超标广告费/业务宣传费等须调增，遗漏调增将低估应纳税所得额。
2. **暂时性差异区分调整完整性**：资产减值准备、折旧摊销税会差异、预计负债、公允价值变动等暂时性差异须逐项列示，且与递延所得税（N1/N3）对应一致。
3. **调整方向须准确**：明确区分纳税调增（利润<应纳税所得额）与纳税调减（利润>应纳税所得额），方向错误直接导致应纳税所得额反向偏差。
4. **免税收入与不征税收入调减**：国债利息、符合条件的居民企业间股息红利、财政性资金（不征税收入）等须调减，同时不征税收入对应支出须调增。
5. **调整项与凭证依据对应**：每一调整项须有支持性证据（费用明细、捐赠票据、减值计算表、税会差异分析），防止随意调整或调整金额估算。
6. **明细勾稽 N5-4 与递延税**：纳税调整明细各项合计须与 N5-4 应纳税所得额推算中的调整总额一致；暂时性差异调整须与 N1/N3 递延所得税本期变动勾稽。

## checklist

### 一、永久性差异完整性（高风险）

- [ ] 【必检】行政罚款、滞纳金是否全额纳税调增
- [ ] 【必检】非公益性/超限额公益性捐赠是否调增
- [ ] 【必检】业务招待费是否按"发生额60%与收入5‰孰低"调增超标部分
- [ ] 【必检】广告费/业务宣传费超扣除限额部分是否调增
- [ ] 【必检】免税收入（国债利息/符合条件股息）是否调减
- [ ] 【风险检查】是否遗漏永久性差异调增项导致应纳税所得额低估
- [ ] 【风险检查】不征税收入对应支出是否相应调增

### 二、暂时性差异调整（高风险）

- [ ] 【必检】资产减值准备（未经税务确认）纳税调增是否完整
- [ ] 【必检】折旧摊销税会差异调整方向与金额是否正确
- [ ] 【必检】预计负债、公允价值变动等暂时性差异是否逐项列示
- [ ] 【必检】暂时性差异调整是否与 N1/N3 递延所得税本期变动对应
- [ ] 【风险检查】暂时性差异是否误作永久性差异（或反之）

### 三、调整方向与勾稽（中风险）

- [ ] 【必检】各调整项调增/调减方向是否准确标注
- [ ] 【必检】纳税调整明细合计是否与 N5-4 应纳税所得额调整总额一致
- [ ] 【必检】每一调整项是否有支持性证据（费用明细/票据/计算表）
- [ ] 【条件检查：若有可弥补亏损】以前年度亏损弥补是否正确扣除
- [ ] 【必检】调整明细是否与企业所得税汇算清缴纳税调整表勾稽

## risk_areas

### 高风险

1. **永久性差异漏调增**：罚款、非公益捐赠、超标招待费/广宣费未调增，低估应纳税所得额。
2. **暂时性差异调整错误**：调整方向或金额错误，与递延税不勾稽。
3. **调整方向混淆**：调增调减方向错误，应纳税所得额反向偏差。

### 中风险

1. **免税/不征税收入处理错误**：免税收入未调减或不征税收入对应支出未调增。
2. **暂时性/永久性差异误分类**：影响递延所得税确认。
3. **调整与 N5-4 不勾稽**：调整明细合计与当期所得税计算表调整总额不一致。

### 低风险

1. **调整依据说明不足**：调整项支持性证据索引不完整。
2. **格式与交叉索引不规范**：与 N5-4/N1/N3/汇算清缴表交叉引用标注不全。
