# N2-2 应交税费明细表复核提示词

## 概述

本提示词针对应交税费明细表（N2-2）的复核，聚焦按税种维度列示的期末应交明细。明细表以税种为行（增值税、企业所得税、城市维护建设税、教育费附加、地方教育附加、印花税、房产税、城镇土地使用税、车船税、土地增值税、资源税、代扣代缴个人所得税等），列示各税种期初余额、本期计提（贷方）、本期缴纳（借方）、期末余额，是应交税费审定表（N2-1）的基础数据底稿。其数据质量直接影响负债计价、纳税申报核对、以及与 N4 税金及附加、N5 所得税费用的勾稽。

**法规依据：**
- 《企业会计准则第30号——财务报表列报》
- 《中国注册会计师审计准则第1301号——审计证据》
- 《中国注册会计师审计准则第1141号——财务报表审计中与舞弊相关的责任》

## tips

1. **逐税种滚动勾稽是明细表核心**：每一税种"期初余额 + 本期计提 − 本期缴纳 ± 调整 = 期末余额"必须逐行成立，任一税种滚动关系断裂即数据失真。
2. **明细合计必须回勾审定表**：各税种期末余额合计须等于 N2-1 审定表审定合计，期初合计须与上年期末审定数衔接，不得存在无源差异。
3. **完整性是首要风险（负债科目）**：视同销售、进项转出、代扣代缴个税、印花税等易漏计，须结合收入明细、合同台账、工资表交叉核查，防止负债低估。
4. **贷方余额与借方余额分向列示**：多数税种期末为贷方（应交未交），增值税可能因留抵形成借方；借方余额（如多缴、留抵）在报表列报应考虑重分类至其他流动资产。
5. **本期计提数应与费用/损益科目勾稽**：城建税、教育费附加、印花税、房产税等计提数应与 N4 税金及附加借方发生额一致；企业所得税计提数应与 N5 当期所得税费用勾稽。
6. **期后缴纳验证期末应交真实性**：对期末应交余额执行期后缴纳测试（核对完税凭证/银行回单），验证负债存在性与完整性。

## checklist

### 一、逐税种滚动勾稽（高风险）

- [ ] 【必检】各税种"期初+本期计提−本期缴纳±调整=期末"是否逐行成立
- [ ] 【必检】各税种期初余额是否与上年期末审定数一致
- [ ] 【必检】明细表各税种期末余额合计是否等于 N2-1 审定表审定合计
- [ ] 【必检】明细数据是否直接来自纳税明细账/税金及附加明细账，未经人工调整
- [ ] 【风险检查】是否存在税种期末余额异常（长期挂账贷方大额未缴）
- [ ] 【风险检查】是否存在借方余额（多缴/留抵）未按列报要求重分类

### 二、各税种完整性（高风险）

- [ ] 【必检】增值税、企业所得税等主税种是否单独列示且计算完整
- [ ] 【必检】城建税、教育费附加、地方教育附加是否按增值税为基数计提
- [ ] 【必检】印花税、房产税、城镇土地使用税、车船税等小税种是否完整计提
- [ ] 【必检】代扣代缴个人所得税是否单独列示且与工资表勾稽
- [ ] 【条件检查：若有出口业务】出口退税相关应交/应退是否正确反映
- [ ] 【条件检查：若有房地产开发】土地增值税预征及清算是否列示
- [ ] 【风险检查】是否存在应计提税种遗漏（视同销售、进项转出未反映）

### 三、跨底稿勾稽（中风险）

- [ ] 【必检】各小税种本期计提数是否与 N4 税金及附加借方发生额一致
- [ ] 【必检】企业所得税本期计提数是否与 N5 当期所得税费用勾稽
- [ ] 【必检】增值税销项/进项数据是否与 N2-6 增值税测算表一致
- [ ] 【必检】各税种期末应交数是否与最后一期纳税申报表核对
- [ ] 【条件检查：若期后已缴纳】期后缴纳金额是否与完税凭证核对一致

## risk_areas

### 高风险

1. **应交税费漏计**：视同销售、进项转出、代扣代缴、小税种漏提，导致负债低估、费用少计。
2. **明细与审定表不勾稽**：各税种期末合计与 N2-1 审定合计不一致，存在遗漏或错记。
3. **滚动关系断裂**：单一税种"期初+计提−缴纳≠期末"，反映记账错误或数据篡改。

### 中风险

1. **税种间不勾稽**：小税种计提与 N4、所得税计提与 N5 不联动一致。
2. **借方余额列报错误**：留抵/多缴形成的借方余额未重分类至其他流动资产。
3. **期后缴纳未测试**：期末应交余额真实性缺乏期后缴纳/完税凭证支持。

### 低风险

1. **税种明细归集笼统**：将多个小税种合并为"其他税费"未列明细。
2. **格式与交叉索引不规范**：与 N2-1/N4/N5 的交叉引用标注不全。
