# N3-note-listed 递延所得税负债附注披露复核提示词

## 概述

本提示词针对递延所得税负债附注披露底稿（N3-note-listed，科目 2901）的复核（N3 为单一附注，不区分上市/国企变体）。聚焦财务报表附注中递延所得税负债相关披露的充分性和准确性：递延所得税负债项目（按应纳税暂时性差异类别）披露、应纳税暂时性差异金额披露、递延所得税资产与负债抵销列报、以及与审定表 N3-1 的勾稽。递延所得税负债披露反映企业未来须缴纳的所得税义务，是评估税务风险和盈利质量的重要信息。

**法规依据：**
- 《企业会计准则第18号——所得税》
- 《企业会计准则第37号——金融工具列报》
- 《公开发行证券的公司信息披露编报规则第15号——财务报告的一般规定》
- 《中国注册会计师审计准则第1501号——对财务报表形成审计意见和出具审计报告》

## tips

1. **按应纳税暂时性差异类别披露项目**：递延所得税负债须按产生差异的项目（资产评估增值、公允价值变动、折旧摊销税会差异等）分类披露，同时列示应纳税暂时性差异金额与对应递延所得税负债。
2. **应纳税暂时性差异金额须披露**：附注须披露产生递延所得税负债的应纳税暂时性差异总额及分项，与递延所得税负债可勾稽（差异×税率）。
3. **抵销列报须符合准则**：递延所得税资产与递延所得税负债满足抵销条件（同一税收征管主体、有法定抵销权利）时以净额列报，附注须说明抵销前金额与抵销情况。
4. **未确认递延所得税负债的差异须披露**：对与联营/合营企业投资相关等特定应纳税暂时性差异未确认递延所得税负债的，须披露相关差异金额及未确认原因。
5. **OCI 相关递延税须单独反映**：计入其他综合收益的应纳税暂时性差异（公允价值变动）其递延所得税负债，须在附注中与损益相关部分区分反映。
6. **附注与审定表闭环勾稽**：附注披露的递延所得税负债总额必须等于审定表 N3-1 审定数，各项目金额与明细表 N3-2 一致。

## checklist

### 一、递延所得税负债项目披露

- [ ] 递延所得税负债是否按应纳税暂时性差异类别分项披露
- [ ] 各项目是否同时列示应纳税暂时性差异金额与递延所得税负债金额
- [ ] 各项目递延所得税负债合计是否等于审定表 N3-1 审定数
- [ ] 是否同时列示期末数与期初数（可比信息）
- [ ] 分类项目是否与明细表 N3-2 的分类一致

### 二、应纳税暂时性差异披露

- [ ] 产生递延所得税负债的应纳税暂时性差异总额是否披露
- [ ] 各类应纳税差异（评估增值/公允价值变动/折旧摊销差异）是否分项披露
- [ ] 差异金额与递延所得税负债是否可勾稽（差异×税率）
- [ ] 适用税率及税率变动影响是否披露
- [ ] 未确认递延所得税负债的应纳税暂时性差异（如适用）是否披露及原因

### 三、抵销与 OCI 列报

- [ ] 递延所得税资产与负债的抵销情况是否披露（抵销前金额/净额）
- [ ] 抵销是否符合条件（同一税收征管主体、有法定抵销权利）
- [ ] 计入其他综合收益的递延所得税负债是否与损益相关部分区分反映
- [ ] 是否披露与投资相关等特定情形未确认递延所得税负债的说明

### 四、勾稽与变动

- [ ] 附注总额与审定表 N3-1、明细表 N3-2 是否勾稽一致
- [ ] 本期递延所得税负债变动与所得税费用附注（N5）是否勾稽
- [ ] 同源暂时性差异在递延所得税资产（N1）/负债（N3）附注是否分列不重复
- [ ] 本期新增/转回的重大应纳税差异是否有说明

## risk_areas

### 高风险

1. **应纳税暂时性差异披露缺失**：未披露产生递延所得税负债的应纳税暂时性差异金额，不满足 CAS18 强制披露要求，无法评估未来税务义务。
2. **附注总额与审定表不勾稽**：附注披露的递延所得税负债总额与审定表 N3-1 审定数不一致，属数据勾稽重大错误。
3. **OCI 相关递延税列报错误**：计入其他综合收益的应纳税差异其递延所得税负债错误反映于损益相关部分。

### 中风险

1. **项目分类披露不完整**：仅笼统披露递延所得税负债总额，未按应纳税暂时性差异类别分项。
2. **抵销列报说明缺失**：递延所得税资产与负债抵销后净额列报但未说明抵销情况或抵销条件不满足。
3. **可比信息缺失**：仅列示期末数据，未列示期初可比数据。

### 低风险

1. **披露格式不完全规范**：表格列序、金额单位等格式细节未严格按编报规则。
2. **差异说明模板化**：应纳税差异说明照搬准则原文，未结合企业实际资产/交易。
