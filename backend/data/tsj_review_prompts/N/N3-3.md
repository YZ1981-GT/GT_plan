# N3-3 递延所得税负债调整分录复核提示词

## 概述

本提示词针对递延所得税负债调整分录（N3-3，科目 2901）的复核，含账项调整（AJE）与重分类调整（RJE）。复核聚焦：每笔调整分录借贷平衡、调整依据充分（差异识别修正/税率修正）、金额完整回写审定表 N3-1、与递延所得税费用（N5）勾稽、以及与其他综合收益（OCI）项目相关的递延税影响须计入 OCI 而非损益。递延所得税负债的调整多源于应纳税暂时性差异重新计量或识别修正，其中评估增值、公允价值变动等对方科目差异较大，须准确判断调整对方。

**法规依据：**
- 《企业会计准则第18号——所得税》
- 《企业会计准则第28号——会计政策、会计估计变更和差错更正》
- 《中国注册会计师审计准则第1301号——审计证据》

## tips

1. **借贷平衡是形式底线**：每笔调整分录借贷方必须完全平衡，递延所得税负债（2901）的调整对方可能为所得税费用（6801）、其他综合收益或资本公积（企业合并），须核对对方科目正确性。
2. **调整依据须充分可追溯**：调整分录须有明确依据——应纳税差异识别修正（补计遗漏差异）、适用税率修正、税率变动重新计量，每笔可追溯至具体审计程序或明细表 N3-2。
3. **完整回写 N3-1 审定表**：审定表 N3-1 调整列金额须与 N3-3 已确认分录逐笔一致，遗漏任一笔即审定数失真。
4. **与 N5 递延所得税费用勾稽**：影响损益的递延所得税负债调整应同步反映到 N5 递延所得税费用，本期 N1 资产变动+N3 负债变动应与 N5 递延所得税费用勾稽一致。
5. **OCI 项目递延税影响计入 OCI（关键）**：与其他综合收益相关的应纳税暂时性差异（如其他权益工具投资公允价值变动），其递延所得税负债的调整应计入其他综合收益而非当期损益，这是负债侧调整的高频错误点。
6. **A13 交叉验证**：因遗漏应纳税差异形成的少计负债/未调整错报，须与 A13 未调整错报汇总交叉验证，评估单独及累计影响。

## checklist

### 一、分录平衡与依据（高风险）

- [ ] 【必检】每笔调整分录借贷方是否完全平衡
- [ ] 【必检】递延所得税负债（2901）调整的对方科目是否正确（所得税费用/OCI/资本公积）
- [ ] 【必检】每笔调整是否有充分依据（差异识别修正/税率修正/税率变动重新计量）
- [ ] 【必检】调整金额是否可追溯至明细表 N3-2 或具体审计程序
- [ ] 【条件检查：若为补计遗漏应纳税差异】遗漏差异是否有账面/计税基础支持
- [ ] 【风险检查】是否存在无依据或仅为调平所得税费用的不当调整

### 二、回写与勾稽（高风险）

- [ ] 【必检】审定表 N3-1 调整列是否与 N3-3 已确认分录逐笔一致
- [ ] 【必检】影响损益的调整是否同步反映到 N5 递延所得税费用
- [ ] 【必检】本期 N1 资产变动+N3 负债变动是否与 N5 勾稽
- [ ] 【必检】与其他综合收益相关的调整是否计入 OCI 而非损益
- [ ] 【必检】同源暂时性差异在 N1/N3 调整是否分列不重复
- [ ] 【风险检查】是否存在调整已入 N3-3 但审定表/N5 未同步的双真源

### 三、审批与错报评估（中风险）

- [ ] 【必检】超过明细层次重要性水平的调整是否经适当层级审批
- [ ] 【必检】AJE 与 RJE 是否正确区分（RJE 仅影响列报不影响损益）
- [ ] 【必检】因遗漏应纳税差异形成的未调整错报是否纳入 A13 汇总
- [ ] 【条件检查：若为前期差错更正】是否正确区分本期调整与前期差错追溯
- [ ] 【风险检查】未调整错报单独及累计是否超过重要性阈值

## risk_areas

### 高风险

1. **OCI 项目递延税影响错计损益**：与其他综合收益相关的应纳税差异（公允价值变动等）其递延所得税负债调整错计入当期损益，为负债侧调整最高频错误。
2. **回写审定表/N5 不一致**：调整已录入 N3-3 但审定表 N3-1 或 N5 递延所得税费用未同步，导致审定数与所得税费用失真。
3. **调整缺乏依据或未经授权**：递延所得税负债调整无支持证据或未经适当审批。

### 中风险

1. **对方科目判断错误**：企业合并评估增值产生的递延所得税负债调整对方科目误判（应调整合并成本/资本公积而非损益）。
2. **AJE/RJE 混淆**：重分类调整误含损益影响。
3. **A13 交叉验证缺失**：遗漏应纳税差异形成的少计负债错报未纳入未调整错报汇总。

### 低风险

1. **分录摘要/科目编码不规范**。
2. **索引指向明细表/审定表不完整**。
