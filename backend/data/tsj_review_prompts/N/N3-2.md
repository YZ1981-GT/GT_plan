# N3-2 递延所得税负债明细表复核提示词

## 概述

本提示词针对递延所得税负债明细表（N3-2，科目 2901，负债类）的复核。明细表按应纳税暂时性差异项目（资产评估增值、交易性金融资产/其他权益工具投资公允价值变动、固定资产/使用权资产折旧摊销税会差异、超税法摊销资产、分期收款销售等）逐项列示差异金额、适用税率与递延所得税负债金额，是审定表 N3-1 审定数的数据基础。复核聚焦：应纳税暂时性差异识别的完整性（易漏识导致少计负债）、差异×适用税率计算准确性、明细合计与审定表 N3-1 勾稽、期初期末衔接。

**法规依据：**
- 《企业会计准则第18号——所得税》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **逐项列示应纳税暂时性差异**：每一项应纳税暂时性差异必须单独列示差异金额、适用税率和对应递延所得税负债，笼统合并会掩盖差异来源。
2. **完整性是首要关注（易漏识）**：应纳税暂时性差异易遗漏——资产评估增值、公允价值变动收益、超税法折旧摊销、分期收款销售、投资性房地产公允价值模式等，遗漏将导致递延所得税负债少计、所得税费用低估。
3. **差异×税率取转回期间税率**：每项递延所得税负债=应纳税暂时性差异×预计转回期间适用税率；税率变动时须重新计量。
4. **明细合计勾稽审定表**：明细表各项期末递延所得税负债合计必须等于审定表 N3-1 期末审定合计，任何差异需追溯至具体项目。
5. **期初期末衔接**：各项目期初数须与上年期末数衔接，期末=期初+本期确认−本期转回±调整。
6. **豁免情形正确处理**：商誉初始确认、非企业合并且不影响会计利润与应纳税所得额的交易产生的应纳税暂时性差异，不确认递延所得税负债，须核实是否误列。

## checklist

### 一、应纳税暂时性差异识别完整性（高风险）

- [ ] 【必检】资产评估增值（企业合并/重组）产生的应纳税差异是否列示
- [ ] 【必检】交易性金融资产、其他权益工具投资公允价值变动产生的应纳税差异是否列示
- [ ] 【必检】固定资产、使用权资产折旧摊销税会差异（加速折旧/一次性扣除）是否列示
- [ ] 【必检】投资性房地产公允价值模式产生的应纳税差异是否列示
- [ ] 【必检】分期收款销售、超税法摊销资产等应纳税差异是否列示
- [ ] 【条件检查：若有豁免情形】商誉初始确认等豁免情形是否正确不列示
- [ ] 【风险检查】是否存在应识别而遗漏的应纳税暂时性差异（少计负债）

### 二、差异金额与适用税率准确性（高风险）

- [ ] 【必检】各项应纳税暂时性差异金额是否有账面价值与计税基础的支持性计算
- [ ] 【必检】每项差异×适用税率计算是否正确
- [ ] 【必检】适用税率是否为差异转回期间的税率
- [ ] 【必检】税率变动时是否对相关递延所得税负债重新计量
- [ ] 【条件检查：若有多主体不同税率】各主体适用税率是否分别计量
- [ ] 【风险检查】是否存在税率错用导致递延所得税负债少计/虚增

### 三、勾稽关系（高风险）

- [ ] 【必检】明细表各项期末合计是否等于审定表 N3-1 期末审定合计
- [ ] 【必检】各项目期初数是否与上年期末数衔接
- [ ] 【必检】期末=期初+本期确认−本期转回±调整 是否成立
- [ ] 【必检】同源暂时性差异在 N1/N3 是否分列不重复
- [ ] 【必检】本期变动合计是否与 N5 递延所得税费用勾稽
- [ ] 【风险检查】计入其他综合收益的公允价值变动其递延税影响是否计 OCI 而非损益

## risk_areas

### 高风险

1. **应纳税暂时性差异识别不完整**：漏识评估增值、公允价值变动、超税法折旧摊销等应纳税差异，导致递延所得税负债少计、所得税费用低估。
2. **差异×税率错误**：适用税率错用（未采用转回期间税率）或税率变动未重新计量。
3. **明细与审定表不勾稽**：明细表合计与审定表 N3-1 审定数不一致。

### 中风险

1. **期初期末不衔接**：各项目期初数与上年期末数存在无源差异未调节。
2. **OCI 项目处理错误**：公允价值变动的递延税影响错计损益而非其他综合收益。
3. **豁免情形误列**：将商誉初始确认等豁免情形产生的差异误列递延所得税负债。

### 低风险

1. **差异项目说明不足**：项目摘要笼统，无法追溯至具体资产/交易。
2. **格式与索引不规范**：与审定表交叉索引标注不完整。
