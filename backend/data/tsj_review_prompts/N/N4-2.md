# N4-2 税金及附加明细表复核提示词

## 概述

本提示词针对税金及附加明细表（N4-2，科目 6403，损益类，取本期发生额）的复核。明细表按税种（城市维护建设税、教育费附加、地方教育附加、印花税、房产税、城镇土地使用税、车船税、消费税、资源税等）逐项列示本期发生额，是审定表 N4-1 审定数的数据基础。复核聚焦：各税种发生额的完整性（小税种易漏）、与 N2 应交税费对应税种计提额的勾稽、各税种计税基础与税率的合理性、明细合计与审定表 N4-1 的勾稽。税金及附加与 N2 应交税费高度联动，费用确认应等于当期计提。

**法规依据：**
- 《企业会计准则第30号——财务报表列报》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **按税种逐项列示本期发生额**：每一税种必须单独列示本期发生额，不得笼统合并，便于与 N2 应交税费对应税种计提额逐一勾稽。
2. **与 N2 计提对应是核心勾稽**：各税种税金及附加本期发生额应与 N2 应交税费对应税种本期计提额一致（费用确认=计提），差异须追溯至具体计提凭证或跨期因素。
3. **完整性关注小税种（易漏）**：印花税、房产税、城镇土地使用税、车船税等易漏计或漏列，遗漏将导致税金及附加费用低估、应交税费低估。
4. **计税基础与税率合理性**：城建税、教育费附加、地方教育附加以实际缴纳的增值税、消费税为计税基础；消费税随应税销售、资源税随应税产量——各税种计税基础与适用税率须核对。
5. **明细合计勾稽审定表**：明细表各税种本期发生额合计必须等于审定表 N4-1 审定数（N4-2-subtotal），任何差异需追溯。
6. **计入科目口径正确**：现行准则下房产税、土地使用税、车船税、印花税等多数计入税金及附加（而非管理费用），须核对分类口径一致，避免在税金及附加与管理费用间错分。

## checklist

### 一、税种完整性（高风险）

- [ ] 【必检】城市维护建设税、教育费附加、地方教育附加是否列示
- [ ] 【必检】印花税、房产税、城镇土地使用税、车船税等小税种是否列示完整
- [ ] 【必检】消费税、资源税（如适用应税销售/产量）是否列示
- [ ] 【必检】环境保护税、土地增值税（如适用）是否列示
- [ ] 【条件检查：若有应税消费品/资源】消费税、资源税是否与应税销售/产量匹配
- [ ] 【风险检查】是否存在应计提而遗漏的税种（费用与负债双低估）

### 二、与 N2 对应及计税合理性（高风险）

- [ ] 【必检】各税种本期发生额是否与 N2 应交税费对应税种本期计提额勾稽一致
- [ ] 【必检】城建税、教育费附加、地方教育附加是否按实际缴纳的增值税/消费税为基数计算
- [ ] 【必检】各税种适用税率/征收率是否正确
- [ ] 【必检】房产税、土地使用税计税依据（房产原值/占地面积）是否合理
- [ ] 【条件检查：若有跨期计提】跨期因素导致费用与计提差异是否有合理解释
- [ ] 【风险检查】是否存在税金及附加与应交税费计提不勾稽（少计费用/负债）

### 三、分类口径与勾稽（中风险）

- [ ] 【必检】各税费计入税金及附加 vs 管理费用的口径是否正确一致
- [ ] 【必检】明细表各税种合计是否等于审定表 N4-1 审定数
- [ ] 【必检】税金及附加变动是否与营业收入变动匹配，异常是否解释
- [ ] 【必检】资产负债表日税费是否足额计提（截止性）
- [ ] 【风险检查】是否存在将税金及附加错分至其他科目以调节利润结构

## risk_areas

### 高风险

1. **税种完整性缺失**：印花税、房产税、土地使用税等小税种漏提，导致税金及附加费用与应交税费负债双低估。
2. **与 N2 不对应**：各税种税金及附加与应交税费计提额不勾稽，存在少计费用或少计负债。
3. **明细与审定表不勾稽**：明细表合计与审定表 N4-1 审定数不一致。

### 中风险

1. **计税基础/税率错误**：城建税、教育费附加计税基数错误，或消费税、资源税与应税销售/产量不匹配。
2. **计入科目口径错误**：房产税、土地使用税等在税金及附加与管理费用间错分。
3. **与收入不匹配未解释**：税金及附加变动与营业收入背离而未说明原因。

### 低风险

1. **税种明细说明不足**：各税种计税依据、计算过程记录不完整。
2. **格式与索引不规范**：与审定表、应交税费底稿（N2）交叉索引标注不完整。
