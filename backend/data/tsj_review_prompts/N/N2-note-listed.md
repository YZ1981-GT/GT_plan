# N2-note-listed 应交税费附注披露复核提示词（上市公司）

## 概述

本提示词针对应交税费上市公司附注披露底稿（N2-note-listed）的复核，聚焦应交税费按税种明细披露的完整性、期初期末可比信息、与审定表的勾稽，以及上市公司主要税种及税率的披露要求。附注须按税种（增值税、企业所得税、城建税、教育费附加、印花税、房产税、土地使用税等）列示期末应交余额及期初可比数，并披露适用的主要税种及税率。披露不完整或与审定表不勾稽将影响报表使用者对税务负债的判断。

**法规依据：**
- 《企业会计准则第30号——财务报表列报》
- 《公开发行证券的公司信息披露编报规则第15号——财务报告的一般规定》
- 《中国注册会计师审计准则第1301号——审计证据》

## tips

1. **按税种明细披露是基本要求**：应交税费须按税种逐项列示期末余额，不得笼统合并为"应交税费"一行，各税种明细合计须等于报表应交税费总额。
2. **期初期末可比信息完整**：附注须同时列示期末数与期初（上年年末）数，缺少可比信息属披露不充分。
3. **主要税种及税率披露**：上市公司须在"税项"附注中披露适用的主要税种、计税依据及税率（增值税税率、企业所得税税率、附加税比例等）。
4. **与审定表闭环勾稽**：附注各税种期末余额合计须等于 N2-1 审定表审定合计，期初数须与上年审定期末数一致。
5. **税收优惠披露**：享受的税收优惠（如高新技术企业 15% 税率、小微优惠、增值税加计抵减/留抵退税）须在附注中披露优惠依据与影响。
6. **借方余额列报**：因留抵/多缴形成的借方余额应在其他流动资产列报，附注披露口径须与列报一致，不得以应交税费负数列示。

## checklist

### 一、税种明细披露完整性

- [ ] 应交税费是否按税种逐项列示期末余额
- [ ] 各税种期末余额合计是否等于报表应交税费总额
- [ ] 各税种是否同时披露期末数与期初（上年年末）数
- [ ] 是否存在笼统合并披露（未列明细税种）
- [ ] 税种明细是否与 N2-2 明细表勾稽

### 二、主要税种及税率披露

- [ ] 是否披露适用的主要税种及计税依据
- [ ] 增值税、企业所得税、附加税等适用税率是否披露
- [ ] 是否披露享受的税收优惠及依据（高新/小微/加计抵减等）
- [ ] 税收优惠对当期税负的影响是否说明
- [ ] 税率披露是否与 N2-4 税收政策检查结论一致

### 三、勾稽与列报

- [ ] 附注应交税费总额是否与 N2-1 审定表审定合计一致
- [ ] 期初数是否与上年审定期末数衔接
- [ ] 借方余额（留抵/多缴）是否在其他流动资产列报（不以负数列示）
- [ ] 应交增值税相关披露是否与 N2-6 增值税测算勾稽
- [ ] 重大税务不确定性/税务争议是否披露

## risk_areas

### 高风险

1. **税种明细披露不完整**：笼统合并披露或遗漏重要税种，无法反映税务负债结构。
2. **附注与审定表不勾稽**：附注应交税费总额与 N2-1 审定合计不一致，数据勾稽错误。
3. **重大税务事项未披露**：税务争议、欠税、重大税收优惠未披露。

### 中风险

1. **可比信息缺失**：仅列期末数未列期初可比数。
2. **税率披露缺失或错误**：主要税种税率未披露或与实际适用不一致。
3. **借方余额列报错误**：留抵/多缴以应交税费负数列示而非重分类。

### 低风险

1. **披露格式不规范**：税种排列、金额单位等格式细节不统一。
2. **优惠说明模板化**：税收优惠描述照搬政策原文未结合企业实际。
