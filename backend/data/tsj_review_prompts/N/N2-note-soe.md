# N2-note-soe 应交税费附注披露复核提示词（国有企业）

## 概述

本提示词针对应交税费国有企业附注披露底稿（N2-note-soe）的复核，聚焦国有企业特定的税费披露要求：在按税种明细披露基础上，增加欠税及滞纳金情况、税务合规性、财务决算报表口径一致性等国资监管相关信息。国有企业税费披露除满足会计准则外，还须满足国资委财务决算报告要求，长期欠税、税务违规可能涉及国有资产管理责任。

**法规依据：**
- 《企业会计准则第30号——财务报表列报》
- 《中央企业财务决算报告管理办法》
- 《中国注册会计师审计准则第1301号——审计证据》

## tips

1. **国有企业"双层"披露要求**：既满足会计准则按税种明细披露，又满足国资委财务决算报告的税费专项披露要求，两套要求互为补充。
2. **欠税与滞纳金须专项披露**：期末长期欠缴税款、因欠税产生的滞纳金/罚款须单独披露金额及原因，长期欠税可能反映资金紧张或税务合规问题。
3. **决算报表口径一致**：附注应交税费数据须与年度财务决算报表一致，决算附加信息表中的税费数据须与本附注勾稽。
4. **税务合规性视角**：国企税务合规是国资监管重点，须关注是否存在税务稽查事项、补税罚款、税收优惠合规性等，并在附注反映。
5. **与上市版的差异在监管层面**：基础披露框架（按税种明细、期初期末、税率）与上市版相同，国企版额外增加欠税、决算口径、税务合规等国资监管信息，而非替代基础披露。
6. **勾稽闭环**：附注各税种期末合计须等于 N2-1 审定合计，并与财务决算报表、纳税申报数三方核对一致。

## checklist

### 一、基础披露完整性（与上市版共有）

- [ ] 应交税费是否按税种逐项列示期末余额及期初可比数
- [ ] 各税种期末余额合计是否等于报表应交税费总额
- [ ] 是否披露适用的主要税种、计税依据及税率
- [ ] 附注应交税费总额是否与 N2-1 审定表审定合计一致
- [ ] 税种明细是否与 N2-2 明细表勾稽

### 二、欠税与税务合规披露（国企特定）

- [ ] 期末长期欠缴税款是否单独披露金额及原因
- [ ] 因欠税产生的滞纳金/罚款是否披露
- [ ] 是否存在税务稽查/补税事项并披露进展
- [ ] 享受税收优惠的合规性是否说明（资质、批文有效性）
- [ ] 是否存在税收优惠不合规导致的补税风险披露

### 三、决算口径与勾稽（中风险）

- [ ] 附注应交税费数据是否与年度财务决算报表一致
- [ ] 决算附加信息表中税费数据是否与本附注勾稽
- [ ] 各税种期末应交数是否与纳税申报数核对一致
- [ ] 集团合并层面内部税费往来抵销是否完整
- [ ] 借方余额（留抵/多缴）是否按列报要求处理

## risk_areas

### 高风险

1. **长期欠税未披露**：期末长期欠缴税款及滞纳金未单独披露，掩盖资金与合规风险。
2. **附注与决算/审定不勾稽**：附注税费数据与财务决算报表或 N2-1 审定合计不一致。
3. **税务违规事项未披露**：税务稽查、补税罚款等重大事项未反映。

### 中风险

1. **税种明细不完整**：笼统合并披露或遗漏重要税种。
2. **税收优惠合规性未说明**：享受优惠的资质合规性未披露。
3. **决算口径差异未调节**：决算数据与审计后附注数据差异未调节说明。

### 低风险

1. **可比信息缺失**：仅列期末数未列期初可比数。
2. **格式未按决算模板**：披露格式与国资委决算模板有细微差异但信息完整。
