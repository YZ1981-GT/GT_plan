# N2-11 应交税费检查表复核提示词

## 概述

本提示词针对应交税费凭证级检查表（N2-11）的复核，聚焦样本选取方法合理性、计提/缴纳凭证核对完整性、检查比例达标性、异常事项标注充分性。检查表以记账凭证为单位，对应交税费的计提（贷方）与缴纳（借方）逐笔核对原始单据（纳税申报表、完税凭证、银行回单、计税依据资料），验证税款计提与缴纳的真实性、准确性与完整性。凭证级检查是应交税费"发生、准确性、截止"认定的直接证据来源。

**法规依据：**
- 《中国注册会计师审计准则第1314号——审计抽样》
- 《中国注册会计师审计准则第1301号——审计证据》

## tips

1. **样本选取应与风险匹配**：高风险税种（增值税、企业所得税）及大额计提/缴纳应作必选样本，其余按 CAS1314 合理抽样；样本须覆盖计提与缴纳两个方向。
2. **计提凭证核对计税依据**：税款计提凭证须核对计税依据（销售额、利润、房产原值等）与适用税率，验证计提金额准确性，防止漏提或错提。
3. **缴纳凭证核对完税证据**：税款缴纳凭证须核对纳税申报表、完税凭证/电子缴款凭证、银行回单三者一致，验证缴纳真实性与截止归属。
4. **截止性关注跨期计提缴纳**：期末前后的计提与缴纳凭证须重点核查，防止跨期错记（本期税款延迟计提或提前计入下期）。
5. **异常凭证标注**：无计税依据的调整分录、整数金额补提、期末突击计提/冲减、缴纳与申报不符等异常须标注异常类型及初步判断。
6. **检查比例达标**：已检查金额（计提额+缴纳额）÷ 本期发生额总体须达到计划检查比例，不达标须说明原因并评估是否补充样本。

## checklist

### 一、样本选取合理性（高风险）

- [ ] 【必检】样本选取方法是否与识别的税务重大错报风险匹配
- [ ] 【必检】抽样方法是否符合 CAS1314 要求（统计/非统计抽样有据）
- [ ] 【必检】大额计提/缴纳、高风险税种是否纳入必选样本
- [ ] 【必检】样本是否同时覆盖计提（贷方）与缴纳（借方）两个方向
- [ ] 【必检】抽样总体是否完整（从完整应交税费明细账导出）
- [ ] 【风险检查】样本是否遗漏异常凭证（无依据补提/期末突击调整）

### 二、凭证核对完整性（高风险）

- [ ] 【必检】计提凭证是否核对计税依据与适用税率
- [ ] 【必检】缴纳凭证是否核对纳税申报表、完税凭证、银行回单三者一致
- [ ] 【必检】计提金额=计税依据×税率 是否准确
- [ ] 【必检】期末前后计提/缴纳凭证截止归属是否正确（无跨期错记）
- [ ] 【必检】原始单据是否齐全（申报表/完税凭证/计税资料）
- [ ] 【风险检查】是否存在无真实业务支持的税款计提/冲减凭证

### 三、检查比例与异常标注（中风险）

- [ ] 【必检】检查比例（已检查金额÷本期发生额）是否达到计划水平
- [ ] 【必检】计提方向与缴纳方向检查比例是否分别达标
- [ ] 【必检】异常凭证是否全部标注异常类型及初步判断
- [ ] 【必检】核对过程发现的差异是否逐一追踪解决
- [ ] 【条件检查：若检查比例不达标】是否说明原因并补充样本

## risk_areas

### 高风险

1. **计提凭证无依据**：税款计提无计税依据支持或整数金额补提，可能操纵负债与损益。
2. **缴纳真实性存疑**：缴纳凭证与申报表/完税凭证/银行回单不一致，税款缴纳真实性存疑。
3. **截止性错误**：期末税款计提/缴纳跨期错记，影响本期负债与费用归属。

### 中风险

1. **样本代表性不足**：抽样方法不当或未覆盖计提/缴纳双向，样本不具代表性。
2. **检查比例不足**：实际检查比例低于计划水平，审计证据不充分。
3. **异常事项遗漏标注**：期末突击调整、缴纳异常未标注。

### 低风险

1. **记录不完整**：抽样参数、选取过程、核对结果记录不完整。
2. **索引缺失**：与 N2-1/N2-2/N2-6 及纳税申报底稿交叉索引不完整。
