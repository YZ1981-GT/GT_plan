# N4-note-listed 税金及附加附注披露复核提示词（上市公司）

## 概述

本提示词针对税金及附加上市公司附注披露底稿（N4-note-listed，科目 6403）的复核。聚焦财务报表附注中税金及附加相关披露的充分性和准确性：按税种（城建税、教育费附加、地方教育附加、印花税、房产税、土地使用税、车船税、消费税、资源税等）分项披露本期发生额与上期可比数、税种明细的完整性、以及与审定表 N4-1 的勾稽。税金及附加附注是利润表附注的组成部分，反映企业与经营相关的税费负担结构。

**法规依据：**
- 《企业会计准则第30号——财务报表列报》
- 《公开发行证券的公司信息披露编报规则第15号——财务报告的一般规定》
- 《中国注册会计师审计准则第1501号——对财务报表形成审计意见和出具审计报告》

## tips

1. **按税种分项披露**：税金及附加须按税种（城建税/教育费附加/地方教育附加/印花税/房产税/土地使用税/车船税/消费税/资源税等）分项披露本期发生额，不得仅披露总额。
2. **列示上期可比数**：各税种须同时列示本期数与上期数（可比信息），便于报表使用者分析税费结构变动。
3. **税种明细完整性**：小税种（印花税、房产税、土地使用税、车船税）易在披露中遗漏或合并入"其他"，须核实是否完整分项。
4. **合计勾稽审定表与利润表**：附注各税种合计必须等于审定表 N4-1 审定数，并与利润表"税金及附加"行项目一致。
5. **重大变动须说明**：某税种较上期发生重大变动（如消费税随应税销售大幅变化、房产税因资产变动）时，是否有变动原因说明。
6. **与明细表勾稽**：附注各税种发生额须与明细表 N4-2 逐税种一致，口径（计入税金及附加而非管理费用）一致。

## checklist

### 一、税种分项披露

- [ ] 税金及附加是否按税种分项披露本期发生额
- [ ] 城建税、教育费附加、地方教育附加是否分项列示
- [ ] 印花税、房产税、城镇土地使用税、车船税是否分项列示
- [ ] 消费税、资源税（如适用）是否分项列示
- [ ] "其他"税费是否金额较小且无重大遗漏

### 二、可比信息与勾稽

- [ ] 各税种是否同时列示本期数与上期数（可比信息）
- [ ] 附注各税种合计是否等于审定表 N4-1 审定数
- [ ] 附注合计是否与利润表"税金及附加"行项目一致
- [ ] 附注各税种发生额是否与明细表 N4-2 逐税种一致
- [ ] 计入税金及附加的口径是否与会计政策一致

### 三、变动分析与其他

- [ ] 某税种较上期重大变动是否有原因说明
- [ ] 税金及附加总额变动是否与营业收入变动趋势匹配
- [ ] 消费税、资源税变动是否与应税销售/产量匹配
- [ ] 是否存在应披露而未披露的税费事项

## risk_areas

### 高风险

1. **附注合计与审定表/利润表不勾稽**：附注税金及附加各税种合计与审定表 N4-1 或利润表行项目不一致，属数据勾稽重大错误。
2. **税种分项披露缺失**：仅披露税金及附加总额未按税种分项，不满足编报规则细化披露要求。

### 中风险

1. **小税种遗漏或笼统归集**：印花税、房产税、土地使用税等未分项或全部计入"其他"。
2. **可比信息缺失**：仅列示本期数据，未列示上期可比数。
3. **重大变动未说明**：某税种较上期重大变动但无原因说明。

### 低风险

1. **披露格式不完全规范**：表格列序、金额单位等格式细节未严格按编报规则。
2. **变动分析深度不足**：仅列示数据未结合业务对税费结构变动进行分析。
