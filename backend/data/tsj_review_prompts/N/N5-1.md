# N5-1 所得税费用审定表复核提示词

## 概述

本提示词针对所得税费用审定表（N5-1，科目 6801，损益类借方，取本期发生额）的复核。所得税费用=当期所得税费用+递延所得税费用。聚焦：发生额勾稽、试算表核对、当期所得税与纳税申报勾稽、递延所得税与 N1/N3 本期变动勾稽、有效税率调节表合理性。核心风险为纳税调整不完整、递延所得税与 N1/N3 不勾稽、有效税率异常未解释。

**法规依据：**
- 《企业会计准则第18号——所得税》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **取"发生额"非"余额"**：所得税费用=当期所得税费用+递延所得税费用（审定表两项合计）。
2. **发生额勾稽**：审定合计=当期所得税（N5-1-current-tax）+递延所得税（N5-1-deferred-tax）±调整。
3. **试算表核对**：审定合计与试算表 6801 审定发生额一致。
4. **当期所得税勾稽**：当期所得税费用=应纳税所得额×税率，应与 N2 应交企业所得税、企业所得税汇算清缴/申报勾稽；纳税调整项（如罚款、非公益捐赠、超标招待费、税会差异）是否完整。
5. **递延所得税勾稽**：递延所得税费用=（期末−期初）递延所得税负债 N3 变动−递延所得税资产 N1 变动；计入 OCI/权益的递延税影响不计入所得税费用。
6. **有效税率调节（核心分析）**：实际税负率（所得税费用/利润总额）与法定税率的差异应通过调节表逐项解释（永久性差异、税率差异、未确认递延所得税资产的亏损等），异常须追查。

## checklist

### 一、发生额勾稽与试算表核对

- [ ] 审定合计=当期所得税+递延所得税 是否正确
- [ ] 当期所得税、递延所得税分项是否与 N5-4/N5-8 计算表勾稽
- [ ] 审定合计是否与试算表 6801 审定发生额一致
- [ ] 上期审定数是否与上年底稿一致

### 二、当期所得税与纳税调整

- [ ] 当期所得税=应纳税所得额×适用税率 是否正确
- [ ] 应纳税所得额=利润总额±纳税调整，调整项是否完整（罚款/捐赠/招待费/减值/税会差异等）
- [ ] 当期所得税是否与 N2 应交企业所得税、汇算清缴勾稽
- [ ] 税收优惠、税率（高新/小微）适用是否有依据

### 三、递延所得税与勾稽

- [ ] 递延所得税费用是否等于 N3 负债本期变动−N1 资产本期变动
- [ ] 计入其他综合收益/权益的递延税影响是否未计入所得税费用
- [ ] 未确认递延所得税资产的可抵扣亏损是否在调节表体现

### 四、有效税率调节与调整

- [ ] 有效税率调节表是否从"利润总额×法定税率"调节至实际所得税费用
- [ ] 各调节项（永久性差异、税率差异等）是否有依据、合计是否勾稽
- [ ] 有效税率异常（远高/低于法定）是否解释
- [ ] 已确认的账项/重分类调整是否完整反映、经审批

## risk_areas

### 高风险

1. **纳税调整不完整**：漏调永久性差异（罚款、非公益捐赠、超标费用），当期所得税少计。
2. **递延所得税与 N1/N3 不勾稽**：递延所得税费用与 N1/N3 本期变动不一致。
3. **审定表与试算表不勾稽**：发生额口径不一致。

### 中风险

1. **有效税率异常未解释**：实际税负率与法定税率差异大但调节表无法解释。
2. **OCI 递延税误计损益**：计入权益的递延税影响错计所得税费用。
3. **税收优惠无依据**：适用优惠税率缺乏批文/资质。
4. **审计调整遗漏**。

### 低风险

1. **格式与索引不规范**。
2. **调节项说明不足**。
