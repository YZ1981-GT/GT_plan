# N1-2 递延所得税资产明细表复核提示词

## 概述

本提示词针对递延所得税资产明细表（N1-2，科目 1811，资产类）的复核。明细表按可抵扣暂时性差异项目（资产减值准备、预计负债、未实现内部销售利润、预收/预提费用、可弥补亏损、税款抵减等）逐项列示差异金额、适用税率与递延所得税资产金额，是审定表 N1-1 审定数的数据基础。复核聚焦：差异项目识别的完整性、每项差异×适用税率计算的准确性、明细合计与审定表 N1-1 的勾稽、期初期末的衔接。明细表的数据质量直接决定递延所得税资产确认与所得税费用（N5）的正确性。

**法规依据：**
- 《企业会计准则第18号——所得税》
- 《中国注册会计师审计准则第1301号——审计证据》

## tips

1. **逐项列示是明细表的核心**：每一项可抵扣暂时性差异（或可弥补亏损/税款抵减）必须单独列示差异金额、适用税率和对应递延所得税资产，笼统合并会掩盖差异来源和确认前提的差异化判断。
2. **差异×税率是计算主线**：每项递延所得税资产=可抵扣暂时性差异（或可弥补亏损）×预计转回期间适用税率；税率应为差异转回年度的适用税率（含税率变动时的重新计量），而非当期税率。
3. **明细合计必须勾稽审定表**：明细表各项期末递延所得税资产合计必须等于审定表 N1-1 期末审定合计（N1-2-total-deferred-tax-asset），任何差异需追溯至具体项目。
4. **期初期末衔接不得断裂**：各项目期初递延所得税资产必须与上年期末数衔接，本期确认/转回金额须有支持性计算，期末=期初+本期确认−本期转回/转销±调整。
5. **差异识别完整性关系少计资产**：减值准备、预计负债、未实现内部利润、预收预提等常见可抵扣差异易遗漏，遗漏将导致递延所得税资产少计、所得税费用高估。
6. **与 N1-4 测算表勾稽**：明细表各项差异金额与递延所得税资产测算表（N1-4）逐项一致，确认前提（未来应纳税所得额充足性）在 N1-4/N1-5 评估后方可确认对应递延所得税资产。

## checklist

### 一、差异项目识别完整性（高风险）

- [ ] 【必检】资产减值准备（应收款项/存货/固定资产/商誉等）产生的可抵扣差异是否列示完整
- [ ] 【必检】预计负债（质保金/预计诉讼损失等）产生的可抵扣差异是否列示
- [ ] 【必检】未实现内部销售利润（合并层面）产生的可抵扣差异是否列示
- [ ] 【必检】预收/预提费用、递延收益等产生的可抵扣差异是否列示
- [ ] 【必检】可弥补亏损、税款抵减是否单独列示并在有效期内
- [ ] 【条件检查：若有股份支付】股份支付相关可抵扣差异是否列示
- [ ] 【风险检查】是否存在应识别而遗漏的可抵扣暂时性差异

### 二、差异金额与适用税率准确性（高风险）

- [ ] 【必检】各项可抵扣暂时性差异金额是否有账面价值与计税基础的支持性计算
- [ ] 【必检】每项差异×适用税率计算是否正确
- [ ] 【必检】适用税率是否为差异转回期间的税率（非当期税率）
- [ ] 【必检】税率变动时是否对相关递延所得税资产重新计量
- [ ] 【条件检查：若有优惠税率/分支机构不同税率】各主体适用税率是否分别计量
- [ ] 【风险检查】是否存在税率错用导致递延所得税资产虚增/少计

### 三、勾稽关系（高风险）

- [ ] 【必检】明细表各项期末合计是否等于审定表 N1-1 期末审定合计
- [ ] 【必检】各项目期初数是否与上年期末数衔接
- [ ] 【必检】期末=期初+本期确认−本期转回/转销±调整 是否成立
- [ ] 【必检】明细表各项差异金额是否与 N1-4 测算表逐项一致
- [ ] 【必检】本期变动合计是否与 N5 递延所得税费用勾稽
- [ ] 【风险检查】是否存在无源差异或合计不平的情况

## risk_areas

### 高风险

1. **差异识别不完整**：漏识可抵扣暂时性差异（减值准备、预计负债、未实现内部利润等），导致递延所得税资产少计、所得税费用高估。
2. **差异×税率错误**：适用税率错用（用当期税率而非转回期间税率）或税率变动未重新计量，导致递延所得税资产计量错误。
3. **明细与审定表不勾稽**：明细表合计与审定表 N1-1 审定数不一致，属数据勾稽重大错误。

### 中风险

1. **期初期末不衔接**：各项目期初数与上年期末数存在无源差异未调节。
2. **与 N1-4 测算不一致**：明细表差异金额与测算表逐项存在差异未解释。
3. **可弥补亏损有效期核查缺失**：未核实可弥补亏损是否在税法规定的弥补期限内。

### 低风险

1. **差异项目说明不足**：项目摘要笼统，无法追溯至具体交易或科目。
2. **格式与索引不规范**：与审定表、测算表的交叉索引标注不完整。
