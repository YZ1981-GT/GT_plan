# N5-6 税收优惠明细表复核提示词

## 概述

本提示词针对税收优惠明细表（N5-6）的复核，聚焦企业所享受各项企业所得税优惠的资质有效性、适用条件的持续满足、优惠金额计算的准确性。明细表逐项列示享受的税收优惠（高新技术企业 15% 税率、小型微利企业优惠、研发费用加计扣除、西部大开发、软件企业减免、固定资产加速折旧等），并核对批文/备案/资质证书与适用条件。税收优惠直接影响当期所得税计算（N5-4），资质失效或条件不符仍享受优惠将形成补税及滞纳金风险。

**法规依据：**
- 《企业会计准则第18号——所得税》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **优惠资质须有有效证据**：高新技术企业证书、软件企业认定、西部大开发备案等须核验证书有效期、发证机关，资质过期仍享受优惠为重大风险。
2. **适用条件持续满足**：高新技术企业须持续满足研发费占比、高新收入占比、科技人员占比等指标；小型微利企业须满足从业人数、资产总额、应纳税所得额三项标准，条件不符即不得享受。
3. **优惠金额计算准确**：优惠税率减免额、研发费加计扣除额、加速折旧税会差异等须独立测算，防止虚增优惠金额。
4. **研发费加计扣除范围**：加计扣除须核验研发项目立项、研发费用归集口径（人员/材料/折旧等）、辅助账，防止将非研发费用纳入加计扣除。
5. **优惠与 N5-4 联动**：各项优惠须与当期所得税计算表（N5-4）的税率适用、减免税额、加计扣除勾稽一致，优惠明细变化须联动更新 N5-4。
6. **备案与申报一致**：享受优惠须在企业所得税申报中如实申报（"自行判别、申报享受、相关资料留存备查"），须核对申报表优惠明细与本表一致。

## checklist

### 一、优惠资质与条件（高风险）

- [ ] 【必检】所享受优惠是否有批文/备案/资质证书
- [ ] 【必检】优惠资质是否在有效期内
- [ ] 【条件检查：若为高新技术企业】研发费占比、高新收入占比、科技人员占比是否持续达标
- [ ] 【条件检查：若为小型微利企业】从业人数、资产总额、应纳税所得额是否符合标准
- [ ] 【条件检查：若为软件/集成电路企业】认定条件与减免期是否符合
- [ ] 【风险检查】是否存在资质失效或条件不符仍享受优惠

### 二、优惠金额计算（高风险）

- [ ] 【必检】优惠税率减免额计算是否正确
- [ ] 【必检】研发费用加计扣除计算是否正确且研发费归集口径合规
- [ ] 【条件检查：若有加速折旧】固定资产加速折旧税会差异计算是否正确
- [ ] 【风险检查】研发费加计扣除是否将非研发费用纳入
- [ ] 【风险检查】是否虚增优惠金额

### 三、勾稽与申报（中风险）

- [ ] 【必检】各项优惠是否与 N5-4 当期所得税计算表勾稽
- [ ] 【必检】优惠明细是否与企业所得税申报优惠明细表一致
- [ ] 【必检】优惠对当期所得税的影响金额是否与 N5-9 有效税率调节勾稽
- [ ] 【条件检查：若优惠到期】优惠到期后是否恢复法定税率计提
- [ ] 【必检】留存备查资料是否完整

## risk_areas

### 高风险

1. **资质失效仍享受优惠**：优惠资质过期或适用条件不符仍享受，形成补税及滞纳金风险。
2. **优惠金额虚增**：优惠税率减免或加计扣除金额虚增，少计当期所得税。
3. **研发费归集违规**：非研发费用纳入加计扣除，虚增优惠。

### 中风险

1. **优惠与 N5-4 不勾稽**：优惠适用与当期所得税计算不一致。
2. **备案申报不一致**：享受优惠与申报表优惠明细不符。
3. **优惠到期未恢复法定税率**：优惠期满后仍按优惠税率计提。

### 低风险

1. **留存备查资料不完整**：优惠依据资料索引不全。
2. **格式与交叉索引不规范**：与 N5-4/申报表交叉引用标注不全。
