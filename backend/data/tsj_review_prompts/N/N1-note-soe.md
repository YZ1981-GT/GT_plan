# N1-note-soe 递延所得税资产附注披露复核提示词（国有企业）

## 概述

本提示词针对递延所得税资产国有企业附注披露底稿（N1-note-soe，科目 1811）的复核。在满足企业会计准则通用披露（按暂时性差异类别披露项目、可抵扣差异及可弥补亏损、未确认递延所得税资产）的基础上，聚焦国有企业特定关注点：国资委财务决算报告对递延所得税及资产质量的补充披露要求、可弥补亏损确认对国有资本保值增值的影响、与预算/经营业绩考核的关联。国有企业递延所得税资产确认须兼顾会计准则与国有资产监管的审慎性要求。

**法规依据：**
- 《企业会计准则第18号——所得税》
- 《企业会计准则第37号——金融工具列报》
- 《中央企业财务决算报告管理办法》
- 《国有资产监督管理委员会关于加强中央企业财务决算管理工作有关事项的通知》
- 《中国注册会计师审计准则第1501号——对财务报表形成审计意见和出具审计报告》

## tips

1. **国企附注"双层"披露**：既满足 CAS18 通用披露（项目分类/暂时性差异/可弥补亏损/未确认部分），又满足国资委财务决算报告的补充要求，两套要求互补不可替代。
2. **可弥补亏损确认须审慎**：国有企业确认可弥补亏损递延所得税资产直接影响利润与国有资本保值增值率，须审慎评估未来盈利能力，避免通过确认递延所得税资产美化经营业绩。
3. **未确认递延所得税资产是重点披露**：未确认递延所得税资产的可抵扣差异/可抵扣亏损金额及到期年度须完整披露，反映企业潜在的未来税务利益和亏损弥补压力。
4. **递延所得税对保值增值率的影响**：递延所得税资产的确认与转销对当期利润的影响，进而对国有资本保值增值率的影响，须在决算相关披露中说明。
5. **与决算报表一致**：附注递延所得税资产数据须与年度财务决算报表及资产质量分析表一致，差异须调节说明。
6. **附注与审定表闭环**：附注披露的递延所得税资产总额=审定表 N1-1 审定数，各项目与明细表 N1-2 一致，未确认部分与 N1-5 检查表一致。

## checklist

### 一、基础披露完整性（与上市版共有）

- [ ] 递延所得税资产是否按暂时性差异类别分项披露
- [ ] 各项目是否列示可抵扣暂时性差异与递延所得税资产金额
- [ ] 附注递延所得税资产总额是否等于审定表 N1-1 审定数
- [ ] 可弥补亏损产生的递延所得税资产是否单独列示及到期年度分布
- [ ] 未确认递延所得税资产的可抵扣差异/可抵扣亏损金额及到期年度是否披露
- [ ] 是否列示期末数与期初数可比信息

### 二、国有资产监管相关披露

- [ ] 可弥补亏损确认递延所得税资产对国有资本保值增值率的影响是否说明
- [ ] 递延所得税资产确认/转销对当期利润的影响是否披露
- [ ] 大额可弥补亏损（超过规定标准）确认是否经适当决策程序
- [ ] 是否披露递延所得税资产中涉及重大会计估计判断的事项
- [ ] 连续亏损企业确认可弥补亏损递延所得税资产是否有审慎依据

### 三、预算执行与决算一致性

- [ ] 递延所得税对利润的影响与年度预算/经营业绩考核口径是否一致
- [ ] 附注递延所得税资产数据是否与年度财务决算报表一致
- [ ] 决算资产质量分析表中递延所得税资产数据是否与本附注一致
- [ ] 决算数据与审计后数据差异是否编制调节说明

### 四、确认依据、抵销与勾稽

- [ ] 确认可弥补亏损递延所得税资产的依据是否定性说明
- [ ] 递延所得税资产与负债的抵销情况是否披露
- [ ] 适用税率及税率变动影响是否披露
- [ ] 附注总额与审定表 N1-1、明细表 N1-2、未确认部分与 N1-5 是否勾稽
- [ ] 本期变动与所得税费用附注（N5）是否勾稽

## risk_areas

### 高风险

1. **可弥补亏损确认美化业绩**：国有企业为改善经营业绩考核结果而确认缺乏盈利预测支持的可弥补亏损递延所得税资产，虚增利润与国有资本保值增值率。
2. **未确认递延所得税资产披露缺失**：未披露未确认递延所得税资产的可抵扣差异/可抵扣亏损金额及到期年度，掩盖未来税务利益或亏损弥补压力。
3. **附注总额与审定表/决算不勾稽**：附注、审定表 N1-1、财务决算报表三者数据不一致。

### 中风险

1. **保值增值率影响未说明**：递延所得税确认/转销对国有资本保值增值率的影响未在决算相关披露中说明。
2. **大额可弥补亏损确认程序缺失**：大额可弥补亏损确认递延所得税资产未经适当决策程序或未披露。
3. **决算与审计口径差异未调节**：财务决算数据与审计后附注数据存在差异但未编制调节说明。

### 低风险

1. **披露格式未完全按决算模板**：附注格式与国资委决算报表模板有细微差异。
2. **确认依据描述模板化**：确认依据说明未结合企业实际盈利预测。
