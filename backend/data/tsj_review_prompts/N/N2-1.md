# N2-1 应交税费审定表复核提示词

## 概述

本提示词针对应交税费审定表（N2-1，科目 2221，负债类取期末余额）的复核。应交税费按税种核算（增值税、企业所得税、城建税、教育费附加、印花税、房产税、土地使用税等）。聚焦：期初期末勾稽、试算表核对、各税种完整性、与纳税申报表核对、与 N4 税金及附加/N5 所得税费用勾稽。核心风险为少计应交税费（尤其增值税、所得税）导致负债低估。

**法规依据：**
- 《企业会计准则第30号——财务报表列报》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **负债类取"期末余额"**：审定数=期初+本期计提（贷方）−本期缴纳（借方）±调整；分税种逐项核对。
2. **期初期末勾稽**：期初审定数=上年期末审定数；审定合计=明细表 N2-2 各税种期末合计。
3. **试算表核对**：审定合计与试算表 2221 审定余额一致（贷方；留抵可能为借方）。
4. **与申报表核对**：各税种期末应交数应与最后一期纳税申报表、完税凭证核对；期后缴纳测试验证真实性。
5. **税种勾稽**：应交增值税→N4 城建税及附加计提基数；应交企业所得税→N5 当期所得税费用；应交税费与 N4/N5 应联动一致。
6. **完整性（首要风险）**：视同销售、进项转出、代扣代缴、印花税等易漏计，须结合收入、合同、工资表核查。

## checklist

### 一、期初期末勾稽与试算表核对

- [ ] 期初审定数是否等于上年期末审定数
- [ ] 各税种审定数=期初+计提−缴纳±调整 是否正确
- [ ] 审定合计是否与明细表 N2-2 各税种合计一致
- [ ] 审定合计是否与试算表 2221 审定余额一致（方向正确，含留抵）

### 二、各税种完整性与申报核对

- [ ] 应交增值税（销项−进项−已交）计算是否正确，是否与增值税申报一致
- [ ] 应交企业所得税是否与 N5 当期所得税费用/所得税申报一致
- [ ] 城建税、教育费附加是否按增值税计提，与 N4 勾稽
- [ ] 印花税、房产税、土地使用税等小税种是否完整计提
- [ ] 代扣代缴个税、视同销售、进项转出是否完整
- [ ] 期后缴纳测试是否执行，验证期末应交数真实性

### 三、审计调整完整性

- [ ] 已确认的账项/重分类调整是否完整反映
- [ ] 是否存在多缴形成的借方余额（其他流动资产列报考虑）
- [ ] 调整分录借贷平衡、证据充分、经审批

## risk_areas

### 高风险

1. **应交税费少计**：增值税/所得税/小税种漏提，低估负债。
2. **与申报表不符**：账面应交数与纳税申报/完税凭证差异未解释。
3. **期初期末不勾稽 / 与试算表不一致**。

### 中风险

1. **税种间不勾稽**：应交增值税与 N4 附加、应交所得税与 N5 不联动。
2. **小税种漏提**：印花税、房产税、土地使用税等未足额计提。
3. **审计调整遗漏**。

### 低风险

1. **格式与索引不规范**。
2. **税种明细说明不足**。
