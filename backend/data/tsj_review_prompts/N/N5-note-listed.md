# N5-note-listed 所得税费用附注披露复核提示词（上市公司）

## 概述

本提示词针对所得税费用上市公司附注披露底稿（N5-note-listed）的复核，聚焦所得税费用构成披露、有效税率调节表（会计利润与所得税费用调节过程）、以及与审定表的勾稽。附注须披露当期所得税费用与递延所得税费用的构成，并提供"利润总额×适用税率"至实际所得税费用的调节表，逐项解释永久性差异、税率差异、未确认递延所得税资产等调节项。有效税率调节表是上市公司所得税附注的核心，也是报表使用者评估税负合理性的关键信息。

**法规依据：**
- 《企业会计准则第18号——所得税》
- 《公开发行证券的公司信息披露编报规则第15号——财务报告的一般规定》
- 《中国注册会计师审计准则第1301号——审计证据》

## tips

1. **所得税费用构成披露**：附注须分别披露当期所得税费用与递延所得税费用金额，合计须等于利润表所得税费用及 N5-1 审定合计。
2. **有效税率调节表是核心披露**：须从"利润总额×适用税率"出发，逐项调节至实际所得税费用，调节项（永久性差异影响、优惠税率影响、未确认递延税资产、以前年度调整等）须逐项列示且金额可追溯。
3. **调节项勾稽支撑底稿**：调节表各项须与 N5-5 纳税调整明细、N5-6 税收优惠明细、N5-8 递延所得税核对勾稽，不得为凑平而人为倒挤调节项。
4. **有效税率异常须解释**：实际税负率（所得税费用/利润总额）远高或远低于法定税率时，调节表须充分解释，异常且无法解释是重大风险。
5. **递延所得税资产/负债披露**：须披露递延所得税资产/负债的确认依据、暂时性差异项目、未确认递延所得税资产的可抵扣差异及可弥补亏损金额与到期日。
6. **闭环勾稽**：附注所得税费用及构成须与 N5-1 审定合计、利润表、N5-2 明细表勾稽；调节表调节后所得税费用须等于实际所得税费用。

## checklist

### 一、所得税费用构成披露

- [ ] 是否分别披露当期所得税费用与递延所得税费用
- [ ] 所得税费用合计是否等于利润表所得税费用及 N5-1 审定合计
- [ ] 构成分项是否与 N5-2 明细表一致
- [ ] 以前年度汇算清缴调整是否单独披露
- [ ] 是否披露计入其他综合收益/权益的所得税影响

### 二、有效税率调节表

- [ ] 是否提供"利润总额×适用税率"至实际所得税费用的调节表
- [ ] 调节项（永久性差异/优惠税率/未确认递延税资产/以前年度调整）是否逐项列示
- [ ] 各调节项金额是否与 N5-5/N5-6/N5-8 勾稽
- [ ] 调节后所得税费用是否等于实际所得税费用（调节表勾稽成立）
- [ ] 有效税率异常（远高/低于法定）是否充分解释
- [ ] 适用税率是否披露（含优惠税率及依据）

### 三、递延所得税与勾稽

- [ ] 递延所得税资产/负债确认依据及暂时性差异项目是否披露
- [ ] 未确认递延所得税资产的可抵扣差异/可弥补亏损金额及到期日是否披露
- [ ] 附注所得税数据是否与 N5-1 审定表、利润表勾稽
- [ ] 递延所得税相关披露是否与 N1/N3 附注一致
- [ ] 税收优惠对所得税费用的影响是否披露

## risk_areas

### 高风险

1. **有效税率调节表不勾稽**：调节后所得税费用与实际不符，或调节项人为倒挤凑平。
2. **附注与审定表不一致**：所得税费用及构成与 N5-1 审定合计、利润表不勾稽。
3. **有效税率异常未解释**：实际税负率与法定税率重大差异无法解释。

### 中风险

1. **构成披露不完整**：未分别披露当期与递延所得税费用。
2. **未确认递延税资产披露缺失**：可弥补亏损金额及到期日未披露。
3. **调节项与支撑底稿不勾稽**：调节项金额与 N5-5/N5-6/N5-8 不一致。

### 低风险

1. **披露格式不规范**：调节表列序、金额单位等格式细节不统一。
2. **税率说明模板化**：适用税率描述照搬政策原文未结合企业实际。
