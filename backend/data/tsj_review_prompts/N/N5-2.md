# N5-2 所得税费用明细表复核提示词

## 概述

本提示词针对所得税费用明细表（N5-2，科目 6801，损益类取本期发生额）的复核，聚焦所得税费用按"当期所得税费用 + 递延所得税费用"分项列示的准确性与完整性。明细表将所得税费用拆分为当期所得税（应交所得税本期计提）与递延所得税（递延所得税资产/负债本期变动）两大构成，并逐项列示，是审定表（N5-1）的基础数据底稿。其分项数据直接来源于当期所得税计算表（N5-4）与递延所得税核对表（N5-8）。

**法规依据：**
- 《企业会计准则第18号——所得税》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **分项构成须完整**：所得税费用=当期所得税费用+递延所得税费用；明细表须清晰拆分两项，合计须等于 N5-1 审定合计与利润表所得税费用。
2. **当期所得税分项勾稽 N5-4**：当期所得税费用（本期应交所得税、以前年度汇算清缴调整）须与当期所得税计算表（N5-4）勾稽。
3. **递延所得税分项勾稽 N5-8**：递延所得税费用须与递延所得税费用核对表（N5-8）一致，且=N3 负债本期变动−N1 资产本期变动。
4. **计入 OCI/权益部分不进本表**：与其他综合收益、所有者权益相关的递延所得税影响直接计入 OCI/权益，不计入所得税费用明细，须核查是否误计入损益。
5. **发生额口径非余额**：明细表列示本期发生额（非期末余额），当期与递延均为本期变动数，须与损益类科目发生额口径一致。
6. **合计回勾审定表与利润表**：明细表所得税费用合计须同时与 N5-1 审定合计、利润表"所得税费用"项、试算表 6801 发生额三者勾稽。

## checklist

### 一、分项构成完整性（高风险）

- [ ] 【必检】所得税费用是否清晰拆分为当期所得税与递延所得税两项
- [ ] 【必检】明细表所得税费用合计是否等于 N5-1 审定合计
- [ ] 【必检】合计是否与利润表"所得税费用"、试算表 6801 发生额一致
- [ ] 【必检】当期所得税分项是否与 N5-4 当期所得税计算表勾稽
- [ ] 【必检】递延所得税分项是否与 N5-8 递延所得税核对表勾稽
- [ ] 【风险检查】是否存在计入 OCI/权益的递延税误计入所得税费用

### 二、当期所得税明细（高风险）

- [ ] 【必检】本期应交所得税是否与 N2 应交企业所得税勾稽
- [ ] 【必检】以前年度汇算清缴调整是否单独列示
- [ ] 【条件检查：若有境外所得】境外所得税抵免是否正确反映
- [ ] 【风险检查】当期所得税是否因纳税调整不完整而少计

### 三、递延所得税明细与勾稽（中风险）

- [ ] 【必检】递延所得税费用是否=N3 负债本期变动−N1 资产本期变动
- [ ] 【必检】递延所得税资产/负债本期变动是否分别列示
- [ ] 【条件检查：若有税率变动】税率变动对递延税影响是否反映
- [ ] 【必检】上期发生额是否与上年底稿一致

## risk_areas

### 高风险

1. **分项合计不勾稽**：所得税费用合计与 N5-1 审定/利润表/试算表不一致。
2. **当期所得税少计**：纳税调整不完整导致当期所得税低估。
3. **OCI 递延税误计损益**：计入权益的递延税影响错计入所得税费用明细。

### 中风险

1. **递延所得税与 N1/N3 不勾稽**：递延所得税费用与资产负债本期变动不一致。
2. **汇算清缴调整遗漏**：以前年度汇算清缴调整未单独列示。
3. **税率变动影响未反映**：税率变动对递延税的影响未在明细体现。

### 低风险

1. **分项说明不足**：当期/递延分项来源说明不清晰。
2. **格式与交叉索引不规范**：与 N5-1/N5-4/N5-8 交叉引用标注不全。
