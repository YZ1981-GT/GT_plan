# N2-7 出口退税核对表复核提示词

## 概述

本提示词针对出口退税核对表（N2-7）的复核，聚焦出口销售额的真实性、退税率适用的正确性、免抵退税额计算的准确性，以及应退税额到账的完整性。核对表按"免抵退税"计算逻辑重构出口退税过程，并与出口销售明细、报关单、增值税及退税申报表勾稽。出口退税涉及应交税费（应交增值税）与其他应收款（应收出口退税）的联动，计算错误将影响负债与资产双向列报。

**法规依据：**
- 《企业会计准则第30号——财务报表列报》
- 《中国注册会计师审计准则第1301号——审计证据》

## tips

1. **出口销售额真实性是前提**：出口销售额须与报关单、出口发票、外汇收款、物流单据交叉核对，防止"假出口、真骗税"或虚构出口业务。
2. **退税率须逐商品核对**：不同商品出口退税率不同（且可能与征税率存在征退差），须按商品编码（HS 编码）核对现行退税率，退税率适用错误直接影响退税额。
3. **免抵退计算逻辑须完整**：生产企业适用"免抵退"，须按"免抵退税额=出口销售额×退税率、当期应退税额、免抵税额"三步逻辑测算，关注免抵税额对城建税及附加计税基数的影响。
4. **征退差（不得免征和抵扣税额）须计入成本**：征税率高于退税率的差额部分不得抵扣，须转出计入主营业务成本，遗漏将虚减成本、虚增利润。
5. **应退税额到账核对**：期末应收出口退税须与退税申报、税务批复、实际到账核对，长期挂账未到账的应退税须评估可收回性。
6. **单证齐全与申报期匹配**：出口退税须在规定申报期内收齐报关单、发票、收汇等单证，单证不齐或逾期申报将影响退税确认与列报。

## checklist

### 一、出口销售额与退税率（高风险）

- [ ] 【必检】出口销售额是否与报关单、出口发票、外汇收款核对一致
- [ ] 【必检】出口收入是否与 D4 营业收入中出口部分勾稽
- [ ] 【必检】各商品退税率是否按 HS 编码核对现行政策
- [ ] 【必检】征退差（征税率−退税率）不得抵扣部分是否转出计入成本
- [ ] 【风险检查】是否存在虚构出口或单证与实物不符（骗税风险）
- [ ] 【风险检查】退税率是否套用错误（偏高多退）

### 二、免抵退计算（高风险）

- [ ] 【必检】免抵退税额=出口销售额×退税率 计算是否正确
- [ ] 【必检】当期应退税额、免抵税额计算逻辑是否完整
- [ ] 【必检】免抵税额对城建税及附加计税基数的影响是否反映
- [ ] 【条件检查：若为外贸企业】"先征后退"计算是否按购进价格与退税率
- [ ] 【风险检查】免抵退计算是否与增值税测算表（N2-6）留抵/应交联动一致

### 三、应退税额到账与勾稽（中风险）

- [ ] 【必检】期末应收出口退税是否与退税申报/税务批复核对
- [ ] 【必检】应退税额实际到账是否与银行回单核对
- [ ] 【必检】长期挂账未到账的应退税是否评估可收回性
- [ ] 【必检】出口退税相关应交增值税/应收退税是否正确列报
- [ ] 【条件检查：若单证不齐】逾期未收齐单证的税务处理是否正确

## risk_areas

### 高风险

1. **虚构出口骗税**：出口业务不真实或单证与实物不符，涉及重大舞弊与合规风险。
2. **退税率适用错误**：套用错误退税率导致多退/少退，影响退税额与负债。
3. **征退差未转出**：不得抵扣税额未计入成本，虚减成本虚增利润。

### 中风险

1. **免抵退计算错误**：免抵退税额/应退税额/免抵税额测算错误。
2. **应退税额长期挂账**：应收出口退税长期未到账未评估可收回性。
3. **附加税基数影响遗漏**：免抵税额对城建税及附加基数影响未反映。

### 低风险

1. **单证归集不完整**：报关单、发票、收汇单证归集索引不全。
2. **格式与交叉索引不规范**：与 D4/N2-6/退税申报表交叉引用标注不全。
