# N1-1 递延所得税资产审定表复核提示词

## 概述

本提示词针对递延所得税资产审定表（N1-1，科目 1811，资产类取期末余额）的复核。递延所得税资产源于可抵扣暂时性差异、可抵扣亏损及税款抵减。聚焦：期初期末勾稽、试算表核对、暂时性差异×适用税率的准确性、确认前提（未来应纳税所得额充足）、与 N3/N5 的勾稽。核心风险为确认前提不足仍确认（虚增资产利润）、差异识别不完整。

**法规依据：**
- 《企业会计准则第18号——所得税》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **资产类取"期末余额"**：审定数=期初+本期确认−本期转回/转销±调整；本期变动经递延所得税费用（N5）体现。
2. **期初期末勾稽**：期初审定数=上年期末审定数；审定合计=明细表 N1-2 期末合计（N1-2-total-deferred-tax-asset）。
3. **试算表核对**：审定合计与试算表 1811 审定余额一致。
4. **差异×税率**：每项递延所得税资产=可抵扣暂时性差异（或可弥补亏损）×预计转回期间适用税率；税率是否正确（含税率变动重新计量）。
5. **确认前提（首要风险）**：只有"很可能取得用来抵扣的未来应纳税所得额"时才确认；可弥补亏损/可抵扣差异确认须有盈利预测支持，否则不得确认。
6. **与 N3/N5 勾稽**：同源暂时性差异在 N1/N3 分列不重复；本期递延所得税资产变动+N3 负债变动应与 N5 递延所得税费用勾稽。

## checklist

### 一、期初期末勾稽与试算表核对

- [ ] 期初审定数是否等于上年期末审定数
- [ ] 审定数=期初+确认−转回/转销±调整 是否正确
- [ ] 审定合计是否与明细表 N1-2 期末合计一致
- [ ] 审定合计是否与试算表 1811 审定余额一致

### 二、差异识别与计量

- [ ] 可抵扣暂时性差异是否识别完整（减值准备、预计负债、未实现内部利润、预收/预提等）
- [ ] 可弥补亏损、税款抵减是否纳入并在有效期内
- [ ] 每项差异×适用税率计算是否正确
- [ ] 税率变动时是否对递延所得税资产重新计量

### 三、确认前提

- [ ] 是否评估未来应纳税所得额充足性（盈利预测/纳税筹划支持）
- [ ] 可弥补亏损确认递延所得税资产是否有充分证据
- [ ] 不满足确认前提的差异是否未确认（避免虚增资产）
- [ ] 期末是否复核以前确认的递延所得税资产可收回性

### 四、勾稽与调整

- [ ] 同源暂时性差异在 N1/N3 是否分列不重复
- [ ] 本期变动是否与 N5 递延所得税费用勾稽
- [ ] 已确认的账项/重分类调整是否完整反映、经审批

## risk_areas

### 高风险

1. **确认前提不足仍确认**：无充足未来应纳税所得额却确认递延所得税资产（尤其可弥补亏损），虚增资产与利润。
2. **差异×税率错误**：适用税率错误或税率变动未重新计量。
3. **期初期末不勾稽 / 与试算表不一致**。

### 中风险

1. **差异识别不完整**：漏确认可抵扣暂时性差异。
2. **与 N3/N5 不勾稽**：同源差异重复计列或本期变动与所得税费用不符。
3. **可收回性未复核**：以前确认的资产未在期末复核。

### 低风险

1. **格式与索引不规范**。
2. **差异项目说明不足**。
