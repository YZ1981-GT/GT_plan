# N1-note-listed 递延所得税资产附注披露复核提示词（上市公司）

## 概述

本提示词针对递延所得税资产上市公司附注披露底稿（N1-note-listed，科目 1811）的复核。聚焦上市公司财务报表附注中递延所得税资产相关披露的充分性和准确性：递延所得税资产项目（按暂时性差异类别）披露、可抵扣暂时性差异及可弥补亏损金额披露、未确认递延所得税资产的可抵扣暂时性差异/可抵扣亏损披露及到期年度、以及与审定表 N1-1 的勾稽。上市公司递延所得税披露是投资者评估盈利质量与税务风险的重要信息。

**法规依据：**
- 《企业会计准则第18号——所得税》
- 《企业会计准则第37号——金融工具列报》
- 《公开发行证券的公司信息披露编报规则第15号——财务报告的一般规定》
- 《中国注册会计师审计准则第1501号——对财务报表形成审计意见和出具审计报告》

## tips

1. **按暂时性差异类别披露项目**：递延所得税资产须按产生差异的项目（资产减值准备、可弥补亏损、未实现内部利润、预计负债等）分类披露，同时列示可抵扣暂时性差异金额与对应递延所得税资产。
2. **可弥补亏损与可抵扣差异分别披露**：可弥补亏损产生的递延所得税资产须与其他可抵扣暂时性差异分别列示，并披露亏损到期年度分布。
3. **未确认递延所得税资产是强制披露项**：须披露未确认递延所得税资产的可抵扣暂时性差异和可抵扣亏损金额，可抵扣亏损还须披露到期年度，这是投资者评估未来税务利益的关键信息。
4. **抵销列报须符合准则**：递延所得税资产与递延所得税负债满足抵销条件时以净额列报，附注须说明抵销前金额与抵销情况。
5. **确认依据须定性说明**：对确认可弥补亏损递延所得税资产的，须说明确认依据（未来很可能取得足够应纳税所得额的判断），尤其对亏损企业。
6. **附注与审定表闭环勾稽**：附注披露的递延所得税资产总额必须等于审定表 N1-1 审定数，各项目金额与明细表 N1-2 一致，未确认部分与 N1-5 检查表一致。

## checklist

### 一、递延所得税资产项目披露

- [ ] 递延所得税资产是否按暂时性差异类别分项披露
- [ ] 各项目是否同时列示可抵扣暂时性差异金额与递延所得税资产金额
- [ ] 各项目递延所得税资产合计是否等于审定表 N1-1 审定数
- [ ] 是否同时列示期末数与期初数（可比信息）
- [ ] 分类项目是否与明细表 N1-2 的分类一致

### 二、暂时性差异及可弥补亏损披露

- [ ] 可抵扣暂时性差异总额是否披露
- [ ] 可弥补亏损产生的递延所得税资产是否单独列示
- [ ] 可弥补亏损的到期年度分布是否披露
- [ ] 税款抵减（如适用）是否单独披露
- [ ] 差异金额与递延所得税资产是否可勾稽（差异×税率）

### 三、未确认递延所得税资产披露

- [ ] 未确认递延所得税资产的可抵扣暂时性差异金额是否披露
- [ ] 未确认递延所得税资产的可抵扣亏损金额是否披露
- [ ] 未确认部分的可抵扣亏损到期年度是否披露
- [ ] 未确认部分是否与 N1-5 可弥补亏损检查表一致
- [ ] 未确认原因（未来应纳税所得额不足）是否有说明

### 四、抵销、确认依据与勾稽

- [ ] 递延所得税资产与负债的抵销情况是否披露（抵销前金额/净额）
- [ ] 确认可弥补亏损递延所得税资产的依据是否定性说明
- [ ] 适用税率及税率变动影响是否披露
- [ ] 附注总额与审定表 N1-1、明细表 N1-2 是否勾稽一致
- [ ] 本期递延所得税资产变动与所得税费用附注（N5）是否勾稽

## risk_areas

### 高风险

1. **未确认递延所得税资产披露缺失**：未披露未确认递延所得税资产的可抵扣差异/可抵扣亏损金额及到期年度，不满足 CAS18 强制披露要求，隐瞒未来税务利益或亏损风险。
2. **附注总额与审定表不勾稽**：附注披露的递延所得税资产总额与审定表 N1-1 审定数不一致，属数据勾稽重大错误。
3. **可弥补亏损确认依据披露不充分**：亏损企业确认可弥补亏损递延所得税资产但未披露确认依据，投资者无法评估判断合理性。

### 中风险

1. **项目分类披露不完整**：仅笼统披露递延所得税资产总额，未按暂时性差异类别分项。
2. **抵销列报说明缺失**：递延所得税资产与负债抵销后净额列报但未说明抵销情况。
3. **可比信息缺失**：仅列示期末数据，未列示期初可比数据。

### 低风险

1. **披露格式不完全规范**：表格列序、金额单位等格式细节未严格按编报规则。
2. **确认依据描述模板化**：确认依据说明照搬准则原文，未结合企业实际盈利预测。
