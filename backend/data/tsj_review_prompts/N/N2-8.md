# N2-8 应交其他税费测算表复核提示词

## 概述

本提示词针对应交其他税费测算表（N2-8）的复核，聚焦以增值税为计税基数的附加税费（城市维护建设税、教育费附加、地方教育附加）及印花税等小税种的独立测算。测算表以增值税实际缴纳额（含免抵税额）为基数，按适用比例测算各项附加税费，并与账面计提数、纳税申报数勾稽。附加税费虽单笔金额较小，但漏提或计税基数错误具有系统性，直接影响 N4 税金及附加的完整性。

**法规依据：**
- 《企业会计准则第30号——财务报表列报》
- 《中国注册会计师审计准则第1301号——审计证据》

## tips

1. **计税基数是附加税费的关键**：城建税、教育费附加、地方教育附加以"实际缴纳的增值税、消费税"为计税基数，须包含免抵税额；计税基数错误将系统性影响全部附加税费。
2. **税率/比例须按现行规定**：城建税按纳税人所在地分 7%/5%/1%，教育费附加 3%、地方教育附加 2%；须核对适用比例，防止套用错误。
3. **减免政策的适用**：小微企业"六税两费"减半等优惠须核验适用条件与备案，减免会计处理须正确反映。
4. **印花税按应税凭证测算**：印花税按合同金额、账簿、权利许可证照等应税凭证及税目税率测算，须结合购销合同、借款合同等台账，防止应税凭证遗漏。
5. **与增值税测算表联动**：附加税计税基数须与 N2-6 增值税测算表的实际缴纳增值税（含免抵）勾稽，增值税测算变化须联动更新附加税。
6. **计提与 N4 勾稽**：各附加税费本期计提数须与 N4 税金及附加借方发生额一致，测算认定数与账面计提差异须查明。

## checklist

### 一、附加税费测算（高风险）

- [ ] 【必检】城建税、教育费附加、地方教育附加计税基数是否为实际缴纳增值税（含免抵税额）
- [ ] 【必检】城建税适用比例（7%/5%/1%）是否与纳税人所在地一致
- [ ] 【必检】教育费附加 3%、地方教育附加 2% 比例是否正确
- [ ] 【必检】附加税计税基数是否与 N2-6 增值税测算表勾稽
- [ ] 【条件检查：若适用小微减免】"六税两费"减半优惠条件与会计处理是否正确
- [ ] 【风险检查】附加税是否漏提或计税基数遗漏免抵税额

### 二、印花税等小税种测算（中风险）

- [ ] 【必检】印花税是否按应税凭证（购销合同/借款合同/账簿等）及税目税率测算
- [ ] 【必检】应税凭证是否完整（结合合同台账、账簿设置）
- [ ] 【条件检查：若有权利许可证照】权利许可证照印花税是否计提
- [ ] 【风险检查】是否存在应税合同遗漏导致印花税少提

### 三、计提核对与勾稽（中风险）

- [ ] 【必检】各附加税费本期计提数是否与 N4 税金及附加借方发生额一致
- [ ] 【必检】测算认定数与账面计提数差异是否查明原因
- [ ] 【必检】各税费期末应交数是否与 N2-2 明细表、纳税申报勾稽
- [ ] 【条件检查：若期后已缴纳】期后缴纳是否与完税凭证核对

## risk_areas

### 高风险

1. **计税基数错误**：附加税计税基数遗漏免抵税额或错用，系统性影响全部附加税费。
2. **附加税漏提**：城建税及附加未足额计提，负债与 N4 费用低估。
3. **比例适用错误**：城建税比例、附加费率套用错误。

### 中风险

1. **印花税应税凭证遗漏**：应税合同/账簿遗漏，印花税少提。
2. **减免政策适用错误**：小微减免条件不符或会计处理错误。
3. **与 N4 不勾稽**：附加税计提与税金及附加发生额不一致。

### 低风险

1. **测算说明不足**：计税基数与比例适用说明不清晰。
2. **格式与交叉索引不规范**：与 N2-6/N2-2/N4 交叉引用标注不全。
