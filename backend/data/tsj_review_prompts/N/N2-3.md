# N2-3 应交税费调整分录复核提示词

## 概述

本提示词针对应交税费调整分录汇总表（N2-3）的复核，含账项调整（AJE）、重分类调整（RJE）及未调整错报评估。应交税费调整多源于补提漏计税款（增值税、所得税、小税种）、纠正计税错误、留抵/多缴重分类等。复核须验证：每笔调整有税务依据、借贷平衡、完整回写 N2-1 审定表、并索引至 A13 未调整错报汇总。

**法规依据：**
- 《企业会计准则第28号——会计政策、会计估计变更和差错更正》
- 《中国注册会计师审计准则第1301号——审计证据》
- 《中国注册会计师审计准则第1324号——持续经营》

---

## tips

1. **AJE 与 RJE 区分**：补提税款、纠正计税差错为 AJE（影响损益/负债金额）；留抵借方余额重分类至其他流动资产、一年内到期区分为 RJE（仅影响列报）。
2. **调整须有税务依据**：应交税费调整须附计税依据、税率、纳税申报表、税务事项通知书等支持性证据，不得凭主观判断补提或冲减。
3. **完整回写 N2-1**：审定表调整列金额须与 N2-3 已确认分录逐笔一致，遗漏任一笔即审定数失真。
4. **税种间联动调整**：补提增值税须同步调整城建税及附加；补提企业所得税须与 N5 所得税费用调整联动，避免单向调整造成税种间不勾稽。
5. **跨期差错区分**：区分本期计税错报与前期税款差错更正（CAS28），会计处理与披露要求不同；重大前期差错可能需追溯重述。
6. **TB 回写与 A13 汇总**：确认调整已同步试算平衡表 2221 科目；未调整错报单独及累计与 A13 交叉验证，评估对负债与损益的综合影响。

## checklist

### 一、调整合规性（高风险）

- [ ] 【必检】每笔调整分录借贷方是否完全平衡
- [ ] 【必检】补提/冲减税款是否有充分税务依据（计税依据、税率、申报表）
- [ ] 【必检】调整金额是否完整反映到 N2-1 审定表对应调整列
- [ ] 【必检】增值税调整是否同步引起城建税及附加联动调整
- [ ] 【必检】企业所得税调整是否与 N5 所得税费用调整勾稽
- [ ] 【风险检查】是否存在无税务依据的主观补提或冲减
- [ ] 【风险检查】是否存在为规避少缴税款风险而虚假调整

### 二、分类与跨期（中风险）

- [ ] 【必检】RJE 是否仅涉及列报（留抵/多缴借方余额重分类），未影响损益
- [ ] 【必检】跨期调整是否正确区分本期错报与前期差错更正（CAS28）
- [ ] 【条件检查：若涉及重大前期差错】是否评估追溯重述及披露要求
- [ ] 【必检】调整原因说明是否清晰可追溯至具体审计程序/税务核查

### 三、汇总与索引（中风险）

- [ ] 【必检】未调整错报累计是否与 A13 未调整错报汇总交叉验证
- [ ] 【必检】调整后审定数是否同步回写试算平衡表 2221 科目
- [ ] 【必检】分录编号是否连续，删除后重号风险是否可控
- [ ] 【必检】索引是否指向 N2-6/N2-8/N2-11 等支持底稿

## risk_areas

### 高风险

1. **调整缺乏税务依据**：补提或冲减税款无计税依据/申报表支持，属主观调整。
2. **审定表与 N2-3 调整不一致**：调整金额未完整回写 N2-1，审定数失真。
3. **税种间联动遗漏**：补提增值税未同步调整附加税、所得税调整未联动 N5。

### 中风险

1. **RJE 误含损益影响**：留抵重分类调整误影响损益类科目。
2. **跨期差错分类错误**：前期税款差错误作本期调整，未评估追溯重述。
3. **A13 汇总遗漏**：未调整税款错报未纳入错报汇总累计评估。

### 低风险

1. **编号、摘要、科目编码不规范**。
2. **调整说明与支持底稿索引不完整**。
