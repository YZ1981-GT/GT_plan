# N1-3 递延所得税资产调整分录复核提示词

## 概述

本提示词针对递延所得税资产调整分录（N1-3，科目 1811）的复核，含账项调整（AJE）与重分类调整（RJE）。复核聚焦：每笔调整分录借贷平衡、调整依据充分（差异识别修正/税率修正/确认前提变化）、金额完整回写审定表 N1-1、与递延所得税费用（N5）勾稽、以及与 A13 未调整错报汇总的交叉验证。递延所得税资产的调整多源于暂时性差异重新计量或确认前提再评估，须区分影响损益（递延所得税费用）与影响其他综合收益的调整。

**法规依据：**
- 《企业会计准则第18号——所得税》
- 《企业会计准则第28号——会计政策、会计估计变更和差错更正》
- 《中国注册会计师审计准则第1301号——审计证据》

## tips

1. **借贷平衡是形式底线**：每笔调整分录借贷方必须完全平衡，递延所得税资产（1811）的调整对方通常为所得税费用（6801）或其他综合收益，须核对对方科目正确性。
2. **调整依据须充分可追溯**：调整分录须有明确依据——差异识别修正、适用税率修正、确认前提变化（未来应纳税所得额评估调整）、可弥补亏损确认/转销，每笔可追溯至具体审计程序或测算表 N1-4。
3. **完整回写 N1-1 审定表**：审定表 N1-1 调整列金额须与 N1-3 已确认分录逐笔一致，遗漏任一笔即审定数失真。
4. **与 N5 递延所得税费用勾稽**：影响损益的递延所得税资产调整应同步反映到 N5 递延所得税费用，本期递延所得税资产变动+N3 负债变动应与 N5 递延所得税费用勾稽一致。
5. **区分损益 vs OCI**：与其他综合收益项目（如其他权益工具投资公允价值变动）相关的暂时性差异，其递延所得税资产调整应计入其他综合收益而非当期损益。
6. **A13 交叉验证**：因确认前提不足调减或未确认递延所得税资产形成的未调整错报，须与 A13 未调整错报汇总交叉验证，评估单独及累计影响。

## checklist

### 一、分录平衡与依据（高风险）

- [ ] 【必检】每笔调整分录借贷方是否完全平衡
- [ ] 【必检】递延所得税资产（1811）调整的对方科目是否正确（所得税费用/其他综合收益）
- [ ] 【必检】每笔调整是否有充分依据（差异修正/税率修正/确认前提变化/亏损确认转销）
- [ ] 【必检】调整金额是否可追溯至 N1-4 测算表或具体审计程序
- [ ] 【条件检查：若为确认前提变化调整】未来应纳税所得额再评估是否有支持证据
- [ ] 【风险检查】是否存在无依据或仅为调平所得税费用的不当调整

### 二、回写与勾稽（高风险）

- [ ] 【必检】审定表 N1-1 调整列是否与 N1-3 已确认分录逐笔一致
- [ ] 【必检】影响损益的调整是否同步反映到 N5 递延所得税费用
- [ ] 【必检】本期递延所得税资产变动+N3 负债变动是否与 N5 勾稽
- [ ] 【必检】与其他综合收益相关的调整是否计入 OCI 而非损益
- [ ] 【风险检查】是否存在调整已入 N1-3 但审定表/N5 未同步的双真源

### 三、审批与错报评估（中风险）

- [ ] 【必检】超过明细层次重要性水平的调整是否经适当层级审批
- [ ] 【必检】AJE 与 RJE 是否正确区分（RJE 仅影响列报不影响损益）
- [ ] 【必检】因确认前提不足形成的未调整错报是否纳入 A13 汇总
- [ ] 【条件检查：若为前期差错更正】是否正确区分本期调整与前期差错追溯
- [ ] 【风险检查】未调整错报单独及累计是否超过重要性阈值

## risk_areas

### 高风险

1. **调整缺乏依据或未经授权**：递延所得税资产调整无支持证据或未经适当审批，可能为操纵利润而调整。
2. **回写审定表/N5 不一致**：调整已录入 N1-3 但审定表 N1-1 或 N5 递延所得税费用未同步，导致审定数与所得税费用失真。
3. **确认前提变化调整证据不足**：因"未来应纳税所得额充足"而转回或新增确认递延所得税资产，缺乏盈利预测支持。

### 中风险

1. **损益与 OCI 错分**：与其他综合收益相关的暂时性差异调整错计入当期损益。
2. **AJE/RJE 混淆**：重分类调整误含损益影响。
3. **A13 交叉验证缺失**：未确认递延所得税资产形成的错报未纳入未调整错报汇总。

### 低风险

1. **分录摘要/科目编码不规范**。
2. **索引指向测算表/审定表不完整**。
