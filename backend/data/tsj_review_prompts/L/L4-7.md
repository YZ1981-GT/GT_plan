# L4-7 应付债券后续计量复核提示词

## 概述

本提示词针对应付债券后续计量表（L4-7，科目2502）的复核，聚焦实际利率法摊销表的准确性、利息费用的确认、溢折价摊销，以及两种付息方式（到期一次还本付息/分期付息到期一次还本）分支的计量差异。后续计量摊销表是逐期验证债券摊余成本和利息费用的核心底稿。

**法规依据：**
- 《企业会计准则第22号——金融工具确认和计量》
- 《企业会计准则第37号——金融工具列报》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **实际利率法摊销表是后续计量核心**：每期利息费用=期初摊余成本×实际利率，与票面利息的差额为溢折价摊销额，须逐期验证摊销表。
2. **两种付息方式计量不同**：到期一次还本付息债券的利息滚入摊余成本（应计利息累积），分期付息债券每期支付票面利息，两者摊销表结构不同（与L4-8账面核对分支联动）。
3. **利息费用须与财务费用勾稽**：实际利率法确认的利息费用须计入财务费用（或资本化），与利润表勾稽。
4. **摊余成本逐期滚动**：期末摊余成本=期初摊余成本+利息费用-已付利息（分期付息）或=期初+利息费用（到期一次付息，利息滚入本金）。
5. **溢折价摊销至到期日归零**：债券到期时利息调整余额应摊销完毕，摊余成本等于面值。
6. **实际利率须与初始计量一致**：后续摊销使用的实际利率须与L4-6初始计量确定的一致，不得随意变更。

## checklist

### 一、实际利率法摊销准确性

- [ ] 每期利息费用是否=期初摊余成本×实际利率
- [ ] 溢折价摊销额是否=利息费用-票面利息
- [ ] 摊销表使用的实际利率是否与L4-6初始计量一致
- [ ] 摊销表期初摊余成本是否与上期期末一致

### 二、付息方式分支

- [ ] 到期一次还本付息债券的应计利息是否累积滚入摊余成本
- [ ] 分期付息债券每期是否支付票面利息
- [ ] 付息方式分支是否与L4-8账面核对分支一致
- [ ] 期末摊余成本计算是否符合付息方式

### 三、利息费用勾稽

- [ ] 本期利息费用是否与财务费用（6603）勾稽
- [ ] 符合资本化条件的利息是否已区分
- [ ] 已付利息现金流是否与现金流量表勾稽

### 四、到期归零验证

- [ ] 债券到期时利息调整余额是否摊销完毕
- [ ] 到期时摊余成本是否等于面值
- [ ] 摊销表是否覆盖债券完整存续期

## risk_areas

### 高风险

1. **摊销表计算错误**：利息费用或溢折价摊销额计算错误，导致债券账面和利息费用失真。
2. **付息方式分支错误**：到期一次付息与分期付息处理混淆，应计利息累积错误。
3. **实际利率变更**：后续摊销随意变更实际利率，偏离初始计量基础。
4. **利息费用与财务费用不勾稽**：实际利率法利息费用与利润表不一致。

### 中风险

1. **摊余成本滚动断裂**：期初摊余成本与上期期末不一致。
2. **到期未归零**：债券到期时利息调整余额未摊销完毕。
3. **资本化利息未区分**：符合资本化条件的债券利息未区分。

### 低风险

1. **摊销表格式不规范**：摊销表列示不清晰。
2. **摊销过程记录不完整**：逐期摊销计算记录不全。
3. **索引不完整**：后续计量未与初始计量、账面核对底稿建立索引。
