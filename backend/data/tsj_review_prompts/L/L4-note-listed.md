# L4-note-listed 应付债券附注披露复核提示词（上市公司）

## 概述

本提示词针对应付债券上市公司附注披露底稿（L4-note-listed，科目2502）的复核，聚焦附注中应付债券的逐只列示（面值/发行日/到期日/票面利率/发行金额/期末余额）、可转换债券条款披露、一年内到期披露、应计利息、违约情况，以及CAS37金融工具列报要求。应付债券披露是投资者评估企业债务融资和偿债结构的关键信息。

**法规依据：**
- 《企业会计准则第37号——金融工具列报》
- 《企业会计准则第22号——金融工具确认和计量》
- 《公开发行证券的公司信息披露编报规则第15号——财务报告的一般规定》

---

## tips

1. **应付债券须逐只列示**：附注须逐只列示债券名称、面值、票面利率、发行日期、债券期限、发行金额，续表列示上年余额、本期发行、按面值计提利息、溢折价摊销、本期偿还、期末余额。
2. **摊余成本变动须完整披露**：每只债券的期初余额、本期发行、按面值计提利息、溢折价摊销、本期偿还、期末余额须完整披露并勾稽。
3. **可转换债券条款须专项披露**：可转换债券须披露转股价、转股期、赎回/回售条款、负债权益成分分拆金额。
4. **一年内到期债券须披露并重分类**：一年内到期的应付债券金额须披露，与一年内到期的非流动负债勾稽。
5. **违约情况须披露**：债券是否违约、是否触发交叉违约、兑付情况须披露，这是投资者评估信用风险的关键。
6. **附注数据须与审定表/明细表勾稽**：附注债券期末余额合计须等于审定表审定数，逐只数据与明细表L4-2一致。

## checklist

### 一、逐只列示披露

- [ ] 是否逐只列示债券名称、面值、票面利率、发行日期、期限、发行金额
- [ ] 续表是否列示上年余额、本期发行、按面值计提利息、溢折价摊销、本期偿还、期末余额
- [ ] 各只债券期末余额合计是否等于审定表审定数
- [ ] 逐只数据是否与明细表L4-2一致

### 二、可转换债券与特殊工具披露

- [ ] 可转换债券转股价、转股期、赎回/回售条款是否披露
- [ ] 可转换债券负债成分与权益成分分拆金额是否披露
- [ ] 优先股/永续债等其他工具是否结合分类披露

### 三、一年内到期与利息披露

- [ ] 一年内到期的应付债券金额是否披露
- [ ] 是否与一年内到期的非流动负债附注勾稽
- [ ] 按面值计提利息和实际利率法利息费用是否披露

### 四、违约与CAS37列报

- [ ] 债券是否违约/触发交叉违约是否披露
- [ ] 本期兑付情况是否披露
- [ ] 信用风险/流动性风险管理是否披露
- [ ] 附注总额是否与审定表审定数一致

## risk_areas

### 高风险

1. **附注总额与审定表不一致**：附注应付债券期末余额合计与审定表审定数不一致。
2. **可转换债券条款/分拆未披露**：可转换债券转股条款或负债权益分拆金额未披露。
3. **违约情况未披露**：债券违约或交叉违约未披露，隐瞒重大信用风险。
4. **一年内到期披露/重分类错误**：一年内到期金额未披露或未重分类。

### 中风险

1. **摊余成本变动披露不完整**：债券续表变动项目不完整（缺溢折价摊销等）。
2. **逐只列示要素缺失**：个别债券缺发行金额或期限披露。
3. **利息披露不充分**：按面值计提利息与实际利率法利息费用未区分披露。
4. **可比信息缺失**：仅列示期末数据未列示上年余额。

### 低风险

1. **披露格式不完全规范**：表格格式细节未严格按编报规则。
2. **债券条款说明简略**：赎回/回售条款披露不详。
3. **数字精度不一致**：披露表格精度不统一。
