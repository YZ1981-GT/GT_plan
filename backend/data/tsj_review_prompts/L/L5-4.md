# L5-4 长期应付款调整分录复核提示词

## 适用底稿
长期应付款调整分录汇总表（L5-4），含账项调整（AJE）、重分类调整（RJE，尤指一年内到期重分类）及未调整错报（SUD）评估。

## 概述
L5-4 是长期应付款审定数链路的关键环节。复核须验证：每笔调整有证据、借贷平衡、完整反映到 L5-1 审定表、一年内到期重分类正确、SUD 评估符合重要性水平要求。

---

## tips

1. **AJE vs RJE**：AJE 影响长期应付款净额或财务费用金额；RJE 仅影响列报（尤指一年内到期重分类至流动负债），不得通过 RJE 掩盖负债计量错报。
2. **一年内到期重分类**：将于一年内到期的长期应付款净额从非流动负债重分类至"一年内到期的非流动负债"，须以净额（扣除对应未确认融资费用）重分类。
3. **与 L5-1 勾稽**：审定表调整列金额须与 L5-4 已确认分录逐笔一致，遗漏任一笔即审定数失真。
4. **未确认融资费用摊销调整**：涉及未确认融资费用摊销的补提/调整须同步财务费用，避免负债与损益单边调整。
5. **审批链**：超过明细层次重要性水平的调整须合伙人/项目经理审批留痕。
6. **TB 回写**：确认调整已同步试算平衡表2701/2702科目，避免「底稿已调、TB 未更」双真源。

## checklist

### 高风险检查项

- [ ] 所有 AJE 是否有充分审计证据（合同、付款凭证、现值重算、管理层确认）
- [ ] AJE 是否经适当层级审批（超重要性水平须合伙人知悉）
- [ ] 每笔调整分录借贷方是否完全平衡
- [ ] 调整金额是否完整反映到 L5-1 审定表对应调整列
- [ ] 一年内到期重分类（RJE）是否以净额正确重分类至流动负债
- [ ] 未确认融资费用摊销调整是否同步财务费用（负债与损益联动）
- [ ] 未调整错报累计是否超过整体重要性水平（须评估）

### 中风险检查项

- [ ] RJE 是否仅涉及列报，未影响长期应付款净额
- [ ] 调整原因说明是否清晰可追溯至具体审计程序
- [ ] 与 A13 未调整错报汇总表索引是否完整
- [ ] 专项应付款转入长期应付款的调整是否有依据
- [ ] 建议调整与已执行调整是否区分记录

### 低风险检查项

- [ ] 分录摘要、科目编码规范
- [ ] 索引指向 L5-2 明细、L5-5 测算等支持底稿
- [ ] 审计说明/结论是否概括调整性质与残余风险

## risk_areas

### 高风险

- 调整缺乏证据或未经授权
- 审定表与 L5-4 调整金额长期不一致
- 一年内到期重分类遗漏或方向错误
- 负债与财务费用单边调整（未确认融资费用摊销）

### 中风险

- RJE 误含净额影响
- 专项应付款转入调整无依据

### 低风险

- 编号、格式不规范

## 跨底稿勾稽

- L5-4 已确认 AJE/RJE 合计 ↔ L5-1 审定表调整列
- L5-4 一年内到期 RJE ↔ L5-1 披露审定数
- L5-4 SUD ↔ A13 未调整错报汇总
- 调整后审定数 ↔ 试算平衡表 2701/2702 科目
