# L1-6 短期借款贷款合同检查复核提示词

## 概述

本提示词针对短期借款贷款合同检查表（L1-6，科目2001）的复核，聚焦借款合同要素（金额/利率/期限/担保/用途）与账面记录的一致性、合同条款（限制性条款、提前还款、违约）的识别，以及合同与征信、明细表的勾稽。合同检查是验证借款真实性和条款合规性的基础。

**法规依据：**
- 《企业会计准则第22号——金融工具确认和计量》
- 《企业会计准则第37号——金融工具列报》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **合同是借款存在性和条款的原始证据**：逐笔检查借款合同的借款人、金额、利率、期限、担保方式、资金用途，与账面明细逐项核对。
2. **限制性条款须识别并评估**：合同中的财务比率限制、资产处置限制、交叉违约等限制性条款须识别，评估是否触发违约或需披露。
3. **利率条款须与利息测算勾稽**：固定/浮动利率、计息方式须与L1-5利息测算一致，罚息条款须在逾期借款中考虑。
4. **担保条款须与抵质押检查勾稽**：合同约定的担保方式和担保物须与L1-8抵质押资产检查一致，识别重复担保。
5. **资金用途须与实际使用匹配**：合同约定用途与实际资金流向须匹配，专项借款挪用可能构成违约。
6. **关注短借长用与借新还旧**：短期借款用于长期投资（短借长用）或滚动借新还旧，须评估流动性风险和分类恰当性。

## checklist

### 一、合同要素一致性

- [ ] 借款合同的借款人、金额是否与账面明细一致
- [ ] 合同利率是否与L1-5利息测算和明细表一致
- [ ] 合同借款期限是否在1年以内
- [ ] 合同担保方式是否与L1-8抵质押检查一致
- [ ] 合同资金用途是否与实际资金流向匹配

### 二、合同条款识别

- [ ] 是否识别合同中的限制性条款（财务比率/资产处置限制）
- [ ] 限制性条款是否评估触发违约的可能
- [ ] 提前还款条款和罚息条款是否识别
- [ ] 交叉违约条款是否识别并评估影响

### 三、真实性与用途

- [ ] 借款合同是否真实有效（签章、放款凭证齐全）
- [ ] 是否存在短借长用的流动性风险
- [ ] 是否存在借新还旧的滚动借款
- [ ] 专项借款是否存在挪用

### 四、跨底稿勾稽

- [ ] 合同检查是否与征信报告L1-4勾稽
- [ ] 合同担保是否与L1-8抵质押资产勾稽
- [ ] 合同要素是否与L1-2明细表一致

## risk_areas

### 高风险

1. **限制性条款违约未识别**：合同财务比率限制已被突破但未识别，可能触发提前偿还义务。
2. **借款合同虚假**：合同缺签章或放款凭证，借款真实性存疑。
3. **短借长用流动性风险**：短期借款用于长期资产，期末集中到期偿还压力大。
4. **交叉违约触发**：其他债务违约触发本借款交叉违约条款未评估。

### 中风险

1. **利率条款与测算不一致**：合同利率与L1-5测算不符。
2. **担保条款与抵质押不勾稽**：合同担保与L1-8不对应。
3. **专项借款挪用**：资金用途与合同约定不符。

### 低风险

1. **合同要素记录不完整**：个别合同缺利率或用途记录。
2. **合同检查格式不规范**：检查底稿格式不统一。
3. **索引不完整**：合同检查未与征信、抵质押底稿建立索引。
