# L2-note-soe 应付利息附注披露复核提示词（国有企业）

## 概述

本提示词针对应付利息国有企业附注披露底稿（L2-note-soe，科目2231）的复核，聚焦国有企业特定的披露要求：基础分类披露（长期借款/债券/短期借款/优先股永续债/其他利息）、重要逾期未付利息披露、国资监管相关的利息负担与偿债能力披露、关联方借款利息披露，以及决算报表口径一致性。

**法规依据：**
- 《企业会计准则第37号——金融工具列报》
- 《企业会计准则第22号——金融工具确认和计量》
- 《中央企业财务决算报告管理办法》

---

## tips

1. **国企附注有"双层"披露要求**：既满足CAS37通用披露，又满足国资委决算报告对利息负担、财务费用的额外要求。
2. **应付利息须按利息类别分类披露**：附注按长期借款/债券/短期借款/优先股永续债/其他利息分类列示（国企版通常列"期初余额"而非"上年年末余额"）。
3. **重要逾期未付利息须结合国资监管披露**：欠付利息须披露金额和原因，大额欠付反映债务风险管控问题。
4. **利息负担须服务于国资考核**：利息支出、财务费用是国企经营业绩考核指标，须与决算报表口径一致。
5. **关联方借款利息范围更广**：除一般关联方外，须考虑同一国有控股股东控制的其他国有企业间资金拆借利息。
6. **优先股/永续债利息须结合工具分类**：结合负债/权益分类判断利息列报位置。

## checklist

### 一、基础披露完整性（与上市版共有）

- [ ] 应付利息是否按利息类别分类披露
- [ ] 各类别期末余额合计是否等于审定表审定数
- [ ] 重要逾期未付利息是否单独披露
- [ ] 期初/期末可比信息是否完整
- [ ] 附注总额是否与审定表审定数一致

### 二、国资监管相关披露

- [ ] 利息负担及财务费用是否与决算口径一致
- [ ] 大额欠付利息是否披露风险管控措施
- [ ] 是否披露利息资本化对财务费用的影响

### 三、关联方借款利息披露（国企特定）

- [ ] 与控股股东及关联企业的借款利息是否披露
- [ ] 与同受国有控制单位的资金拆借利息是否披露
- [ ] 关联方借款利率公允性是否说明

### 四、决算报表一致性

- [ ] 应付利息数据是否与年度财务决算报表一致
- [ ] 利息支出是否纳入经营业绩考核相关披露
- [ ] 集团合并层面内部利息抵销是否完整

## risk_areas

### 高风险

1. **附注与审定表/决算不勾稽**：附注应付利息总额与审定表或决算报表不一致。
2. **欠付利息风险未披露**：大额欠付利息未披露风险管控，涉及债务风险问责。
3. **关联方利息范围遗漏**：同受国有控制单位间的资金拆借利息未纳入披露。
4. **利息漏提仍未反映**：应计未付利息漏提仍未在附注反映。

### 中风险

1. **财务费用口径不一致**：附注利息负担与决算考核口径存在差异。
2. **优先股永续债利息列报错误**：结合工具分类的利息列报错误。
3. **关联方利息公允性未说明**：关联方借款利率公允性披露不足。

### 低风险

1. **披露格式未按决算模板**：附注格式与国资委决算模板有细微差异。
2. **欠付原因说明简略**：欠付利息原因披露不详。
3. **历史趋势分析不完整**：利息负担趋势分析未覆盖建议年限。
