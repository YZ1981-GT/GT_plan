# L8-4 非金融机构利息支出测算复核提示词

## 概述

本提示词针对非金融机构利息支出测算表（L8-4）的复核，聚焦向非金融机构（含关联方、股东、其他企业）借款利息支出的真实性、利率合理性、计算准确性以及税前扣除限额的合规性。非金融机构借款利息因缺乏金融机构规范约束，是利息费用操纵、关联方利益输送和税务合规风险的重点领域，测算须验证利息=本金×利率×期间，并关注超同期同类银行贷款利率部分的税务处理。

**法规依据：**
- 《企业会计准则第17号——借款费用》
- 《企业会计准则第22号——金融工具确认和计量》
- 《中国注册会计师审计准则第1301号——审计证据》

## tips

1. **利息测算基本公式**：非金融机构借款利息=借款本金×约定利率×计息期间，测算须逐笔核对本金、利率、期间与借款合同一致。
2. **利率合理性**：非金融机构借款利率须与市场公允水平及同期同类银行贷款利率比较，异常高息可能为利益输送或费用操纵。
3. **税前扣除限额**：向非金融企业借款利息，超过按金融企业同期同类贷款利率计算部分不得税前扣除，测算须关注税会差异及递延所得税影响。
4. **关联方借款关注**：向关联方（股东/关联企业）借款利息须关注资本弱化规则（债资比限制）及定价公允性。
5. **利息支出与费用勾稽**：测算利息合计须与L8-2财务费用明细表利息支出（非金融机构部分）及L8-1审定表勾稽。
6. **资本化判断**：符合资本化条件的非金融机构借款利息应计入资产成本，测算须区分费用化与资本化部分。

## checklist

### 一、利息真实性与计算

- [ ] 每笔非金融机构借款利息是否逐笔核对本金、利率、期间
- [ ] 利息=本金×利率×期间的计算是否准确
- [ ] 本金、利率、期间是否与借款合同一致
- [ ] 是否有借款合同、付息凭证等证据支持

### 二、利率合理性

- [ ] 借款利率是否与市场公允水平比较
- [ ] 是否与同期同类银行贷款利率比较
- [ ] 异常高息/低息是否有合理解释
- [ ] 关联方借款利率是否公允

### 三、税前扣除合规性

- [ ] 超同期同类银行贷款利率部分是否识别（不得税前扣除）
- [ ] 税会差异是否计算并考虑递延所得税影响
- [ ] 关联方借款是否符合资本弱化规则（债资比）
- [ ] 超债资比部分利息的税务处理是否正确

### 四、勾稽与资本化

- [ ] 测算利息合计是否与L8-2利息支出（非金融机构）勾稽
- [ ] 是否与L8-1审定表勾稽
- [ ] 符合资本化条件的利息是否区分并计入资产成本
- [ ] 关联方借款利息是否与L5/关联方底稿勾稽

## risk_areas

### 高风险

1. **虚增利息费用**：向非金融机构（尤其关联方）借款利息虚增，操纵利润或利益输送。
2. **异常高息未质疑**：非金融机构借款利率异常高未查明，可能为费用操纵。
3. **税前扣除超限未识别**：超同期同类银行贷款利率部分未识别，税务合规风险。
4. **资本弱化未考虑**：关联方借款超债资比部分利息税前扣除未调整。

### 中风险

1. **利息计算错误**：本金、利率或期间与合同不符导致计算错误。
2. **费用化/资本化划分错误**：应资本化的利息费用化或反之。
3. **利息与费用不勾稽**：测算与L8-2/L8-1不一致。

### 低风险

1. **测算表格式不规范**：逐笔列示不清晰。
2. **利率比较依据不足**：利率合理性未附比较依据。
3. **索引引用不完整**：未与借款合同建立索引。
