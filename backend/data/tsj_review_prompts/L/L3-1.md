# L3-1 长期借款审定表复核提示词

## 概述

本提示词针对长期借款审定表（L3-1，科目2501）的复核，聚焦借款完整性、一年内到期部分重分类、期初期末勾稽、试算平衡表核对、审计调整完整性与分类列报。长期借款审定表须体现"一年内到期的长期借款"重分类列，是流动性分类和偿债结构分析的核心。

**法规依据：**
- 《企业会计准则第17号——借款费用》
- 《企业会计准则第22号——金融工具确认和计量》
- 《企业会计准则第37号——金融工具列报》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **一年内到期重分类是长期借款审定表的独有关注点**：距资产负债表日1年内到期的长期借款须重分类至"一年内到期的非流动负债"，审定表须体现减一年内到期后的最终披露审定数。
2. **借款完整性防表外负债**：结合银行函证、征信报告核对，确认不存在未入账的长期借款，负债低估风险最高。
3. **期初期末勾稽必须成立**：期末审定数=期初审定数+本期借入-本期归还（加减审计调整），承前启后核对到上年期末。
4. **利息资本化须区分**：符合资本化条件的借款费用（用于购建符合条件资产）须资本化计入在建工程等，不得全部计入财务费用。
5. **抵质押担保须与L3-8勾稽**：以资产抵押/质押取得的长期借款，担保状况须与抵质押资产检查一致，受限资产披露。
6. **借款合同限制性条款（covenant）须评估**：长期借款合同常含财务比率限制、加速到期条款，突破须评估重分类和披露影响。

## checklist

### 一、期初期末勾稽与试算平衡表核对

- [ ] 审定表期初审定数是否等于上年期末审定数
- [ ] 期末审定数是否等于期初+本期借入-本期归还（加减审计调整）
- [ ] 审定数合计（减一年内到期前）是否与试算平衡表2501科目一致
- [ ] 各借款种类小计是否与明细表L3-2勾稽

### 二、一年内到期重分类

- [ ] 距资产负债表日1年内到期的长期借款是否已识别
- [ ] 一年内到期部分是否重分类至一年内到期的非流动负债
- [ ] 披露审定数=审定数-一年内到期金额是否正确
- [ ] 重分类调整是否与L3-3勾稽

### 三、借款完整性

- [ ] 是否已实施银行函证覆盖全部长期借款账户
- [ ] 账面长期借款是否与征信报告完整对应
- [ ] 是否存在表外长期借款
- [ ] 应计未付利息是否已分离至应付利息（2231）

### 四、利息资本化与分类列报

- [ ] 符合资本化条件的借款费用是否已资本化
- [ ] 关联方长期借款是否单独列示
- [ ] 抵质押担保借款是否与L3-8勾稽
- [ ] 外币借款是否按期末汇率折算
- [ ] 审计调整（AJE/RJE）是否完整反映

## risk_areas

### 高风险

1. **一年内到期未重分类**：距资产负债表日1年内到期的长期借款仍列为非流动负债，虚增流动性、误导偿债结构判断。
2. **表外长期借款漏记**：存在未入账的长期借款，负债严重低估。
3. **利息资本化处理错误**：应资本化的借款费用全部费用化，或不符合条件的费用被资本化。
4. **限制性条款违约未评估**：合同财务比率限制被突破触发加速到期，未重分类为流动负债。
5. **审定数与试算平衡表不一致**：审定表合计与2501科目差异。

### 中风险

1. **期初期末不勾稽**：期末余额无法用借入归还解释。
2. **明细与汇总不勾稽**：审定表借款种类合计与L3-2不一致。
3. **抵质押担保未勾稽**：担保借款与L3-8不对应。
4. **外币借款折算错误**：外币借款未按期末汇率折算。
5. **本息未分离**：应计利息混在长期借款本金中。

### 低风险

1. **审定表格式不规范**：列标题、行顺序等格式问题。
2. **交叉索引不完整**：未与试算平衡表、明细表、调整分录建立索引。
3. **变动说明不充分**：期末变动较大的借款种类未附说明。
