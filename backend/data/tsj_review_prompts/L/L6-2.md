# L6-2 专项应付款明细表复核提示词

## 概述

本提示词针对专项应付款明细表（L6-2）的复核，聚焦按专项项目逐项列示的完整性、拨款来源与用途的清晰性、本期增减变动（拨入/使用/结转/退回）的准确性以及与审定表的勾稽。明细表是审定表金额的支撑，须逐项反映专项项目名称、拨款单位、批文号、拨款金额、已使用/结转金额及期末余额，是专款专用合规性的核心记录。

**法规依据：**
- 《企业会计准则第16号——政府补助》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **逐项列示须完整**：每个专项项目须列明项目名称、拨款单位、批文号、拨款金额、用途、已使用/结转金额、期末余额。
2. **拨款来源与批文核对**：专项拨款须有政府拨款文件/批文支持，明细表拨款金额须与拨款文件一致。
3. **增减变动可追溯**：本期拨入与本期结转/退回须与银行收付凭证、完工验收报告、结转批复勾稽。
4. **专款专用记录**：明细表应反映各专项项目资金的实际使用情况，专项资金的使用去向须与项目用途一致。
5. **明细合计勾稽审定表**：明细表各专项项目期末余额合计须等于审定表L6-1审定数。
6. **完工项目标识**：已完工待结转或已结转的专项项目须标识，供审定表结转和附注披露。

## checklist

### 一、逐项列示完整性

- [ ] 每个专项项目是否列明名称、拨款单位、批文号
- [ ] 是否列明拨款金额、用途、已使用/结转金额、期末余额
- [ ] 是否标识项目完工状态
- [ ] 是否存在应列示而遗漏的专项项目

### 二、拨款来源与用途

- [ ] 拨款金额是否与政府拨款文件/批文一致
- [ ] 拨款用途是否明确并与批文一致
- [ ] 资金实际使用去向是否与项目用途相符（专款专用）
- [ ] 是否存在挪用/串用迹象

### 三、增减变动准确性

- [ ] 本期拨入是否与银行收款凭证勾稽
- [ ] 本期结转是否与完工验收/结转批复勾稽
- [ ] 本期退回是否有依据
- [ ] 期末余额是否等于期初加拨入减使用/结转/退回

### 四、勾稽

- [ ] 明细表期末余额合计是否与审定表L6-1勾稽
- [ ] 完工结转是否与L6-1审定表结转方向一致
- [ ] 明细表是否与附注专项应付款披露一致

## risk_areas

### 高风险

1. **专款挪用**：专项资金实际使用去向偏离项目用途，专款专用合规性缺陷。
2. **完整性缺口**：存在的专项拨款未在明细表列示，低估负债或隐瞒资金往来。
3. **拨款金额不实**：明细表拨款金额与批文不符，金额真实性存疑。

### 中风险

1. **明细与审定表不勾稽**：明细合计与审定数不一致。
2. **结转缺依据**：本期结转缺乏完工验收/批复支持。
3. **用途标识不清**：专项项目用途未明确，无法评估专款专用。

### 低风险

1. **列示要素不全**：批文号、拨款单位等缺项。
2. **完工状态未标识**：未标识项目完工状态。
3. **索引引用不完整**：未与拨款文件建立索引。
