# L2-4 应付利息检查表复核提示词

## 概述

本提示词针对应付利息检查表（L2-4，科目2231）的复核，是应付利息审计程序的综合性核对底稿，聚焦利息计提完整性测试、准确性测试（本金×利率×期间独立测算）、本息分离与勾稽测试、以及分类列报测试。检查表统领应付利息的审计结论。

**法规依据：**
- 《企业会计准则第22号——金融工具确认和计量》
- 《企业会计准则第37号——金融工具列报》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **检查表统领应付利息全部审计程序**：须逐项确认完整性、准确性、分类列报各认定的审计程序已执行并得出结论。
2. **完整性测试须核对全部计息负债**：所有短期借款、长期借款、应付债券的应计利息须核对，防止利息漏提。
3. **准确性测试须独立测算**：以本金×利率×计息期间独立测算，与账面比对，验证计提准确性。
4. **本息分离测试须验证**：应计利息须从借款本金中分离至应付利息，检查表须体现分离恰当性。
5. **凭证核对须覆盖计提与支付**：本期计提和支付利息须抽样核对计提凭证、付息凭证。
6. **欠付利息与偿债压力须评估**：检查表须反映欠付利息的识别结论及对持续经营的影响。

## checklist

### 一、完整性测试

- [ ] 是否核对全部计息负债的应计利息
- [ ] 短期借款利息是否核对（L1-5勾稽）
- [ ] 长期借款利息是否核对（L3-5勾稽）
- [ ] 债券利息是否核对（L4勾稽）
- [ ] 是否存在计息负债但未计提利息

### 二、准确性测试

- [ ] 是否以本金×利率×计息期间独立测算
- [ ] 测算利息与账面差异是否追查
- [ ] 利率是否与借款合同一致
- [ ] 计息期间是否与实际借款期间匹配

### 三、本息分离与分类

- [ ] 应计利息是否从借款本金中正确分离
- [ ] 应付利息是否按短期/长期/债券利息分类
- [ ] 资本化利息是否正确区分
- [ ] 欠付利息是否识别并评估偿债压力

### 四、凭证核对与检查比例

- [ ] 本期计提利息是否抽样核对计提凭证
- [ ] 本期支付利息是否抽样核对付息凭证
- [ ] 检查比例是否达到计划水平
- [ ] 核对发现的差异是否追查解决

## risk_areas

### 高风险

1. **利息漏提未识别**：计息负债的应计利息漏提未被检查发现，费用完整性存疑。
2. **准确性未独立验证**：未独立测算利息，仅依赖账面记录。
3. **本息未分离**：应计利息混在借款本金中未分离。
4. **欠付利息未评估**：欠付利息未识别或未评估偿债压力。

### 中风险

1. **检查比例不足**：计提支付检查比例低于计划。
2. **分类测试遗漏**：利息分类未充分测试。
3. **资本化利息未区分**：符合资本化条件的利息未识别。

### 低风险

1. **凭证核对记录不完整**：计提支付核对记录不规范。
2. **检查表格式不统一**：检查底稿格式不规范。
3. **索引缺失**：检查表与利息测算、借款底稿索引不完整。
