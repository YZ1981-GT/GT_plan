# L2-2 应付利息明细表复核提示词

## 概述

本提示词针对应付利息明细表（L2-2，科目2231）的复核，聚焦逐笔应付利息明细的完整性、计息要素（债权人/本金/利率/计息期间）准确性、期初计提支付期末勾稽，以及明细与对应借款本金和审定表的勾稽。明细表是验证利息计提完整性和本息对应关系的基础。

**法规依据：**
- 《企业会计准则第22号——金融工具确认和计量》
- 《企业会计准则第37号——金融工具列报》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **逐笔明细须与借款本金对应**：每笔应付利息须列示债权人、对应借款本金、利率、计息期间和利息金额，与借款明细逐笔勾稽。
2. **期末余额勾稽公式必须成立**：每笔应付利息期末=期初+本期计提-本期支付，公式不成立须追溯。
3. **计息要素须与借款合同一致**：利率、计息期间须与L1-6/L3-6贷款合同一致。
4. **明细合计须与审定表勾稽**：明细表按利息类别的合计须等于审定表L2-1对应类别未审数。
5. **关注长期挂账的应付利息**：长期未支付的应付利息可能是欠付利息，须评估偿债压力和披露。
6. **债券利息须与L4勾稽**：债券应计利息须与应付债券底稿的应计利息一致。

## checklist

### 一、明细完整性

- [ ] 每笔应付利息是否列示债权人、对应本金、利率、计息期间、利息金额
- [ ] 每笔应付利息是否能追溯至对应借款本金
- [ ] 是否存在借款有本金但明细表无对应利息（漏提）
- [ ] 债券应计利息是否与L4应付债券勾稽

### 二、勾稽准确性

- [ ] 每笔应付利息期末是否=期初+本期计提-本期支付
- [ ] 明细表按类别合计是否等于审定表L2-1对应类别未审数
- [ ] 明细表总额是否与试算平衡表2231科目一致

### 三、计息要素准确性

- [ ] 利率是否与L1-6/L3-6贷款合同一致
- [ ] 计息期间是否与实际借款期间匹配
- [ ] 利息计算是否准确（本金×利率×天数）

### 四、异常识别

- [ ] 是否存在长期挂账未支付的应付利息
- [ ] 长期挂账利息是否评估欠付和披露
- [ ] 关联方借款利息是否单独标识

## risk_areas

### 高风险

1. **利息漏提**：借款有本金但明细表无对应利息，费用完整性存疑。
2. **本息不对应**：应付利息无法追溯至借款本金。
3. **期末余额勾稽不成立**：应付利息行余额无法用计提支付解释。

### 中风险

1. **利率与合同不一致**：明细表利率与借款合同不符。
2. **明细与审定表不勾稽**：明细合计与审定表类别合计不一致。
3. **长期挂账未评估**：长期未付利息未评估欠付。

### 低风险

1. **计息要素记录不完整**：个别利息缺利率或计息期间记录。
2. **列设置不规范**：明细表列缺失。
3. **索引不完整**：明细表未与借款明细、合同底稿建立索引。
