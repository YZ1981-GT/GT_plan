# L4-4 应付债券调整分录复核提示词

## 概述

本提示词针对应付债券调整分录汇总表（L4-4，科目2502）的复核，含账项调整（AJE）、重分类调整（RJE）。复核须验证摊销调整、利息调整、可转换债券分拆调整、一年内到期重分类有证据、借贷平衡、完整反映到L4-1审定表，并确认调整已同步试算平衡表。

**法规依据：**
- 《企业会计准则第22号——金融工具确认和计量》
- 《企业会计准则第37号——金融工具列报》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **实际利率法摊销调整是应付债券AJE的重点**：溢折价摊销差错通过AJE调整，借方/贷方财务费用与利息调整，须与L4-7后续计量勾稽。
2. **可转换债券分拆调整**：可转换债券负债与权益成分分拆的调整须验证，负债成分按市场利率折现，差额计入权益。
3. **一年内到期重分类是核心RJE**：一年内到期债券通过RJE重分类至一年内到期的非流动负债。
4. **应计利息调整**：漏提的应计利息通过AJE计提并可能重分类至应付利息（2231）。
5. **与L4-1勾稽**：审定表调整列金额须与L4-4已确认分录逐笔一致。
6. **TB回写**：确认调整已同步试算平衡表2502科目。

## checklist

### 一、调整分录有效性

- [ ] 所有AJE是否有充分证据（摊销测算、利率核对、分拆计算）
- [ ] 实际利率法摊销调整是否与L4-7后续计量勾稽
- [ ] 可转换债券分拆调整是否有折现计算支持
- [ ] 每笔调整分录借贷方是否平衡
- [ ] AJE是否经适当层级审批

### 二、与审定表勾稽

- [ ] 调整金额是否完整反映到L4-1审定表调整列
- [ ] 审定表调整后金额是否等于未审数+AJE+RJE
- [ ] 摊余成本调整后是否与L4-8账面核对一致

### 三、重分类恰当性

- [ ] 一年内到期债券是否通过RJE重分类
- [ ] 重分类金额是否与L4-2明细到期分类一致
- [ ] 应计利息重分类至应付利息（2231）是否正确
- [ ] RJE是否仅涉及列报未影响损益

### 四、TB回写与错报汇总

- [ ] 调整是否已同步试算平衡表2502科目
- [ ] 未调整错报是否记录于A13
- [ ] 跨期调整是否正确区分本期/前期

## risk_areas

### 高风险

1. **摊销调整缺乏证据**：溢折价摊销调整缺实际利率法测算支持。
2. **可转换债券分拆调整错误**：分拆调整折现计算错误或未分拆。
3. **一年内到期重分类遗漏**：应重分类的一年内到期债券未通过RJE处理。
4. **审定表与L4-4不一致**：调整金额未完整反映到审定表。

### 中风险

1. **应计利息调整遗漏**：漏提的应计利息未通过AJE计提。
2. **RJE误含损益影响**：重分类调整错误影响损益。
3. **重分类金额与明细不符**：一年内到期重分类金额与L4-2不一致。

### 低风险

1. **编号、格式不规范**：分录编号或摘要不规范。
2. **索引不完整**：调整分录未指向L4-2明细、后续计量底稿。
3. **审计说明不充分**：未概括调整性质。
