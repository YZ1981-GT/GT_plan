# L3-note-listed 长期借款附注披露复核提示词（上市公司）

## 概述

本提示词针对长期借款上市公司附注披露底稿（L3-note-listed，科目2501）的复核，聚焦附注中长期借款的分类披露（信用/抵押/质押/保证借款）、一年内到期部分的披露与重分类、逾期借款披露、受限资产披露、借款费用资本化情况，以及CAS37列报要求。长期借款披露反映企业的长期偿债结构和融资状况。

**法规依据：**
- 《企业会计准则第37号——金融工具列报》
- 《企业会计准则第22号——金融工具确认和计量》
- 《企业会计准则第17号——借款费用》
- 《公开发行证券的公司信息披露编报规则第15号——财务报告的一般规定》

---

## tips

1. **长期借款须按担保方式分类披露**：附注按信用/抵押/质押/保证借款分类列示期末和期初余额，各类合计等于审定表审定数（减一年内到期前）。
2. **一年内到期部分须清晰披露并重分类**：附注须披露一年内到期的长期借款金额，与"一年内到期的非流动负债"附注勾稽，长期借款附注列示的应为减一年内到期后的余额。
3. **逾期未偿还借款须单独披露**：期末逾期借款须披露借款单位、期末余额、逾期利率和逾期原因。
4. **受限资产（抵质押）须披露**：用于抵押/质押的资产须披露账面价值和受限原因，与L3-8勾稽。
5. **借款费用资本化情况须披露**：本期资本化的借款费用金额和资本化率须在借款费用附注披露。
6. **附注数据须与审定表/明细表勾稽**：附注长期借款总额（含/不含一年内到期口径须明确）与审定表勾稽，分类小计等于明细表。

## checklist

### 一、分类披露检查

- [ ] 长期借款是否按信用/抵押/质押/保证借款分类披露
- [ ] 各类别期末余额合计是否与审定表审定数勾稽
- [ ] 各类别是否同时披露期末数和期初（上年年末）数
- [ ] 分类方式是否与明细表L3-2勾稽

### 二、一年内到期与到期结构披露

- [ ] 一年内到期的长期借款金额是否披露
- [ ] 长期借款附注列示金额是否为减一年内到期后的余额
- [ ] 是否与"一年内到期的非流动负债"附注勾稽
- [ ] 借款到期结构（分年度到期金额）是否披露

### 三、逾期借款与受限资产披露

- [ ] 期末逾期未偿还借款是否单独披露（单位/余额/逾期利率/原因）
- [ ] 抵押/质押资产账面价值是否披露
- [ ] 受限资产受限原因是否说明（与L3-8勾稽）
- [ ] 保证借款的保证方是否披露

### 四、借款费用与CAS37列报

- [ ] 本期资本化借款费用金额和资本化率是否披露
- [ ] 是否披露长期借款利率区间或加权平均利率
- [ ] 外币借款币种和折算汇率是否披露
- [ ] 附注总额是否与审定表审定数勾稽

## risk_areas

### 高风险

1. **一年内到期披露/重分类错误**：一年内到期金额未披露或长期借款附注未减除，误导偿债结构判断。
2. **附注总额与审定表不一致**：附注长期借款总额与审定表审定数不一致。
3. **逾期借款未披露**：期末逾期借款未单独披露，隐瞒违约风险。
4. **受限资产披露缺失**：抵质押资产未披露账面价值和受限原因。

### 中风险

1. **到期结构披露缺失**：未披露分年度到期金额，无法评估偿债结构。
2. **资本化借款费用未披露**：本期资本化金额和资本化率未披露。
3. **分类披露不完整**：仅按单一维度披露未按担保方式分类。
4. **可比信息缺失**：仅列示期末数据未列示期初。

### 低风险

1. **披露格式不完全规范**：表格格式细节未严格按编报规则。
2. **利率信息说明简略**：利率区间披露不详。
3. **数字精度不一致**：披露表格精度不统一。
