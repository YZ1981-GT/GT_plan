# L5-5 未确认融资费用测算表复核提示词

## 概述

本提示词针对未确认融资费用测算表（L5-5）的复核，聚焦实际利率法摊销计划的准确性：实际利率确定、逐期摊销额计算、期初期末摊余成本勾稽以及与L5-3明细表和财务费用的联动。测算表是长期应付款按摊余成本计量的核心引擎，实际利率或现值计算错误将系统性扭曲各期财务费用与负债余额，是长期应付款计量准确性的最高风险环节。

**法规依据：**
- 《企业会计准则第21号——租赁》
- 《企业会计准则第22号——金融工具确认和计量》
- 《企业会计准则第17号——借款费用》
- 《中国注册会计师审计准则第1301号——审计证据》

## tips

1. **实际利率是测算表的灵魂**：实际利率应为使未来付款额现值等于负债初始入账金额（购买价款现值/租赁负债）的折现率，须复核其计算过程与合同条款一致。
2. **逐期摊销遵循实际利率法**：每期摊销额=期初摊余成本×实际利率，期末摊余成本=期初摊余成本+本期摊销额-本期付款额，不得采用直线法。
3. **摊销总额勾稽**：全部期间摊销额合计须等于未确认融资费用初始总额（未来付款额合计-负债初始入账金额）。
4. **本期摊销额勾稽L5-3**：测算表本期摊销额须与L5-3未确认融资费用明细表本期摊销额一致，并计入财务费用。
5. **重估触发利率调整**：租赁付款额重估、合同修改或续租时须重新计算实际利率或调整摊余成本，测算表应反映重估影响。
6. **期末摊余成本勾稽净额**：测算表期末摊余成本须等于L5-1审定表长期应付款净额，形成闭环。

## checklist

### 一、实际利率确定

- [ ] 实际利率是否为使未来付款额现值等于负债初始入账金额的折现率
- [ ] 实际利率计算过程是否有现值公式/IRR支持
- [ ] 实际利率是否与合同约定利率或增量借款利率相符
- [ ] 分期付款购入固定资产的现值确定是否合理（折现率选取有据）

### 二、逐期摊销计算

- [ ] 每期摊销额是否等于期初摊余成本乘实际利率
- [ ] 期末摊余成本是否等于期初摊余成本加本期摊销额减本期付款额
- [ ] 全部期间摊销额合计是否等于未确认融资费用初始总额
- [ ] 是否采用实际利率法而非直线法

### 三、勾稽与联动

- [ ] 本期摊销额是否与L5-3未确认融资费用明细表一致
- [ ] 本期摊销额是否计入财务费用（或符合条件时资本化）
- [ ] 期末摊余成本是否与L5-1审定表长期应付款净额勾稽
- [ ] 付款计划是否与L5-2明细表付款安排一致

### 四、重估与修改

- [ ] 租赁付款额重估是否重新计算实际利率或调整摊余成本
- [ ] 合同修改/续租是否反映在测算表
- [ ] 重估影响是否有充分依据和会计处理

## risk_areas

### 高风险

1. **实际利率计算错误**：折现率选取或现值计算错误，系统性扭曲各期财务费用与负债余额。
2. **采用直线法摊销**：违反CAS21/CAS22实际利率法要求，各期费用分布失真。
3. **期末摊余成本与净额不勾稽**：测算表期末余额与审定表净额不一致，闭环断裂。

### 中风险

1. **重估未反映**：租赁付款额重估或合同修改未在测算表体现。
2. **本期摊销与L5-3不一致**：测算与明细表摊销额脱节。
3. **资本化条件判断错误**：应资本化的融资费用费用化或反之。

### 低风险

1. **测算表格式不规范**：逐期列示不清晰，难以复核。
2. **现值计算过程未留痕**：实际利率来源未附计算底稿。
3. **索引引用不完整**：未与L5-2/L5-3建立索引。
