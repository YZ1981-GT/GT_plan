# L6-4 专项应付款检查表复核提示词

## 适用底稿
专项应付款检查表（L6-4），聚焦专款专用核查、拨款文件与批复核对、结转合规性、样本选取合理性及检查比例达标性。

## 概述
L6-4 是专项应付款存在性、完整性、合规性认定的证据支撑底稿。复核须验证：拨款文件齐全、专款专用、结转有批复、样本覆盖重大专项项目、检查比例满足审计目标。专款专用合规性是专项应付款审计的核心目标。

## tips

- 样本选取应覆盖金额重大专项项目、本期新增拨款及本期结转项目
- 凭证核对须覆盖完整链条（拨款文件/批文→银行收款→资金使用→完工验收→结转批复）
- 专款专用核查须追踪专项资金的实际使用去向，验证与项目用途一致
- 结转合规性须核对完工验收报告与政府结转批复，确认结转方向正确
- 检查比例应满足《中国注册会计师审计准则第1314号——审计抽样》要求
- 关注政府补助与专项应付款的性质界分，防止规避损益确认
- 异常事项标注需明确类型（资金挪用/结转无批复/性质存疑/长期挂账）

## checklist

### 高风险检查项

- [ ] 样本选取是否覆盖金额重大及本期变动专项项目
- [ ] 金额重大专项项目（超过重要性水平）是否100%检查
- [ ] 拨款文件/批文是否齐全并核对拨款金额
- [ ] 专项资金实际使用去向是否与项目用途一致（专款专用）
- [ ] 是否存在专项资金被挪作他用的情况
- [ ] 本期结转是否有完工验收报告及政府结转批复
- [ ] 结转方向（资本公积/损益）是否符合批复
- [ ] 是否存在应计入损益的政府补助被长期挂账专项应付款
- [ ] 长期挂账无使用/结转的专项项目是否评估其合理性

### 中风险检查项

- [ ] 检查比例（已检查金额/总体金额）是否达到计划水平
- [ ] 本期拨入检查比例是否达标
- [ ] 本期结转检查比例是否达标
- [ ] 资金使用是否符合预算及批文限定范围
- [ ] 完工项目是否及时结转，未及时结转是否说明原因
- [ ] 核对中发现的差异是否逐一追踪解决

### 低风险检查项

- [ ] 抽样参数是否完整记录
- [ ] 样本选取过程是否可追溯
- [ ] 检查结果记录格式是否规范
- [ ] 检查比例计算公式是否正确
- [ ] 底稿索引与交叉引用是否完整（关联审定表/明细表）

## risk_areas

### 高风险

- **专款挪用风险**：专项资金被挪作他用，专款专用合规性缺陷，可能涉及违规
- **性质挂账规避损益风险**：应计入损益的政府补助长期挂账专项应付款，虚增负债低估利润
- **结转无批复风险**：完工项目结转缺乏政府批复，结转方向随意导致权益/损益错配
- **完整性缺口风险**：存在的专项拨款未纳入检查，负债不完整

### 中风险

- **检查比例不足风险**：实际检查比例低于计划水平
- **资金使用超范围风险**：专项资金使用超出批文限定范围未被识别
- **结转不及时风险**：完工项目未及时结转长期挂账

### 低风险

- **记录不完整风险**：抽样参数/核对结果记录不完整
- **索引缺失风险**：与审定表/明细表交叉索引不完整
- **格式不规范风险**：检查结果记录格式不统一

## 法规依据

- 《企业会计准则第16号——政府补助》
- 《中国注册会计师审计准则第1314号——审计抽样》
- 《中国注册会计师审计准则第1301号——审计证据》
