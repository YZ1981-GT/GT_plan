# L8-1 财务费用审定表复核提示词

## 概述

本提示词针对财务费用审定表（L8-1）的复核。财务费用（6603）为损益类科目，审定表取本期发生额而非余额，须按明细项目（利息支出、利息收入、汇兑损益、手续费及其他）分项列示。复核聚焦发生额取数方向、利息资本化与费用化划分、与借款循环（L1/L3/L4）利息的勾稽以及与利润表的一致性。发生额取数方向错误或利息资本化划分不当将直接扭曲当期损益。

**法规依据：**
- 《企业会计准则第17号——借款费用》
- 《企业会计准则第19号——外币折算》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **损益类取发生额而非余额**：财务费用审定表取本期发生额，利息支出/手续费按借方发生额（借-贷），利息收入/冲减项按贷方发生额（贷-借），取数方向须按明细项目性质确定，不得笼统取净额。
2. **分项列示是复核基础**：财务费用须分利息支出、利息收入、汇兑损益、手续费及其他分项列示，各分项发生额合计等于财务费用净额，混列将掩盖异常项目。
3. **利息资本化与费用化划分**：符合资本化条件的借款费用（CAS17）应计入相关资产成本而非财务费用，审定表须验证费用化利息未包含应资本化部分。
4. **与借款循环利息勾稽**：财务费用中的利息支出须与L1短期借款、L3长期借款、L4应付债券的利息计提勾稽，利息支出与借款余额、利率的匹配关系须合理。
5. **汇兑损益单独关注**：汇兑损益（CAS19）源于外币货币性项目期末折算及外币结算，须与外币科目余额及汇率变动匹配，异常大额汇兑损益须查明。
6. **审定表勾稽中心**：审定数（净额）应与L8-2明细表分项合计、试算平衡表6603科目发生额及利润表财务费用项目一致。

## checklist

### 一、发生额取数方向

- [ ] 利息支出/手续费是否按借方发生额（借-贷）取数
- [ ] 利息收入/冲减项是否按贷方发生额（贷-借）取数
- [ ] 各分项取数方向是否按项目性质确定
- [ ] 财务费用净额是否等于各分项发生额代数和
- [ ] 是否与试算平衡表6603科目本期发生额一致

### 二、分项列示完整性

- [ ] 是否分利息支出、利息收入、汇兑损益、手续费及其他分项列示
- [ ] 各分项发生额合计是否等于财务费用净额
- [ ] 是否与L8-2明细表分项勾稽
- [ ] 是否存在异常项目被混列掩盖

### 三、利息资本化与费用化划分

- [ ] 费用化利息是否未包含应资本化部分（CAS17）
- [ ] 符合资本化条件的借款费用是否已计入资产成本
- [ ] 资本化利息的计算（资本化率×累计支出）是否合理
- [ ] 一般借款与专门借款的资本化处理是否正确

### 四、勾稽与利润表核对

- [ ] 利息支出是否与L1/L3/L4借款利息计提勾稽
- [ ] 利息支出与借款余额、利率的匹配关系是否合理
- [ ] 汇兑损益是否与外币科目余额及汇率变动匹配
- [ ] 审定数是否与利润表财务费用项目一致
- [ ] 审定表调整数是否与L8-3调整分录一致

## risk_areas

### 高风险

1. **应资本化利息费用化**：符合资本化条件的借款费用计入财务费用，虚增当期费用、低估资产成本（或反之操纵损益）。
2. **发生额取数方向错误**：利息收入与支出取数方向混淆，导致财务费用净额失真。
3. **利息支出与借款不匹配**：财务费用利息与借款循环计提不勾稽，可能存在利息漏记或多记。
4. **异常汇兑损益未查明**：大额汇兑损益与外币敞口不匹配，可能存在错误折算或操纵损益。

### 中风险

1. **分项混列**：各明细项目混列，掩盖异常项目和趋势。
2. **明细与汇总不勾稽**：审定表与L8-2明细表分项合计不一致。
3. **手续费归集不当**：将应计入其他科目的费用归入财务费用手续费。

### 低风险

1. **审定表格式不规范**：分项列示不清晰。
2. **变动说明不充分**：财务费用重大变动未附说明。
3. **交叉索引不完整**：未与L8-2及借款循环底稿建立索引。
