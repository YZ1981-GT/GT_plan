# L3-3 长期借款调整分录复核提示词

## 概述

本提示词针对长期借款调整分录汇总表（L3-3，科目2501）的复核，含账项调整（AJE）、重分类调整（RJE），其中一年内到期长期借款重分类是核心RJE。复核须验证每笔调整有证据、借贷平衡、完整反映到L3-1审定表、重分类恰当，并确认调整已同步试算平衡表。

**法规依据：**
- 《企业会计准则第17号——借款费用》
- 《企业会计准则第22号——金融工具确认和计量》
- 《企业会计准则第37号——金融工具列报》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **一年内到期重分类是长期借款RJE的核心**：距资产负债表日1年内到期的长期借款通过RJE重分类至一年内到期的非流动负债，借方长期借款/贷方一年内到期的非流动负债。
2. **补记表外借款是长期借款AJE的重点**：函证/征信发现的未入账长期借款须通过AJE补记，证据须充分。
3. **利息资本化调整须区分**：应资本化的借款费用调整计入在建工程等，费用化部分计入财务费用。
4. **AJE与RJE区分**：AJE调整本金或利息金额，RJE仅调整列报（如一年内到期重分类），不得混淆。
5. **与L3-1勾稽**：审定表调整列金额须与L3-3已确认分录逐笔一致。
6. **TB回写**：确认调整已同步试算平衡表2501科目。

## checklist

### 一、调整分录有效性

- [ ] 所有AJE是否有充分证据（函证差异、征信核对、利息测算）
- [ ] 补记表外借款AJE是否有借款合同和资金流向证据
- [ ] 每笔调整分录借贷方是否平衡
- [ ] 利息资本化调整是否正确区分
- [ ] AJE是否经适当层级审批

### 二、一年内到期重分类

- [ ] 一年内到期长期借款是否通过RJE重分类
- [ ] 重分类金额是否与L3-2明细到期分类一致
- [ ] 重分类是否借长期借款/贷一年内到期的非流动负债
- [ ] RJE是否仅涉及列报未影响损益

### 三、与审定表勾稽

- [ ] 调整金额是否完整反映到L3-1审定表调整列
- [ ] 审定表调整后金额是否等于未审数+AJE+RJE
- [ ] 披露审定数是否体现减一年内到期后金额

### 四、TB回写与错报汇总

- [ ] 调整是否已同步试算平衡表2501科目
- [ ] 应计利息重分类至应付利息（2231）是否正确
- [ ] 未调整错报是否记录于A13
- [ ] 跨期调整是否正确区分本期/前期

## risk_areas

### 高风险

1. **一年内到期重分类遗漏**：应重分类的一年内到期长期借款未通过RJE处理，虚增流动性。
2. **表外长期借款未补记**：函证/征信发现的未入账借款未补记。
3. **调整缺乏证据或未授权**：补记借款或调整利息缺证据或未经批准。
4. **利息资本化调整错误**：应资本化的借款费用错误费用化。

### 中风险

1. **审定表与L3-3不一致**：调整金额未完整反映到审定表。
2. **重分类金额与明细不符**：一年内到期重分类金额与L3-2到期分类不一致。
3. **RJE误含损益影响**：重分类调整错误影响损益。

### 低风险

1. **编号、格式不规范**：分录编号或摘要不规范。
2. **索引不完整**：调整分录未指向L3-2明细、函证底稿。
3. **审计说明不充分**：未概括调整性质。
