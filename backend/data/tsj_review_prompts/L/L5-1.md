# L5-1 长期应付款审定表复核提示词

## 概述

本提示词针对长期应付款审定表（L5-1）的复核，聚焦双期结构勾稽、原值与未确认融资费用备抵关系、净额列示、一年内到期部分重分类以及试算平衡表核对。长期应付款以摊余成本计量，审定表须清晰呈现应付融资租赁款/分期付款购入固定资产原值（2701）扣减未确认融资费用（2702）后的净额，任何备抵勾稽断裂或重分类遗漏均可能导致非流动负债与流动负债列报错误。

**法规依据：**
- 《企业会计准则第21号——租赁》
- 《企业会计准则第22号——金融工具确认和计量》
- 《企业会计准则第37号——金融工具列报》
- 《中国注册会计师审计准则第1301号——审计证据》

## tips

1. **净额勾稽是长期应付款审定表的核心**：审定表净额必须等于长期应付款原值（2701）减去未确认融资费用（2702），备抵科目方向不得颠倒，净额应与L5-3未确认融资费用明细表期末余额勾稽。
2. **双期结构承前启后**：期初审定数须等于上年期末审定数，期末审定数=期初审定数+本期贷方（新增融资租赁/分期购入）-本期借方（本期支付本金），任何期初差异须追溯会计政策变更或前期差错。
3. **一年内到期部分必须重分类**：将于资产负债表日后一年内到期支付的长期应付款净额须重分类至"一年内到期的非流动负债"，审定表应设"减：一年内到期"列，披露审定数=审定数-一年内到期数。
4. **未确认融资费用摊销进财务费用**：本期未确认融资费用摊销额（实际利率法，来自L5-5测算表）应计入财务费用，审定表贷方（原值增加）与借方（本金支付）须区分本金与利息组成部分。
5. **专项应付款转入须有依据**：若存在从专项应付款（2601）转入的长期应付款，须核对转入依据、金额及会计处理，防止科目串用美化流动性指标。
6. **审定表是跨底稿勾稽中心**：审定数应与L5-2明细表合计、L5-3未确认融资费用明细、L5-5摊销测算、试算平衡表2701/2702科目及附注披露形成闭环，任何节点断裂均为复核重点。

## checklist

### 一、双期勾稽与承前启后

- [ ] 期初未审数是否等于上年审定表期末审定数
- [ ] 期初审定数是否等于期初未审数加期初调整（如有追溯）
- [ ] 期末审定数是否等于期初审定数加本期新增减本期支付本金（含审计调整）
- [ ] 期初差异（会计政策变更/前期差错）是否已充分说明
- [ ] 审定表各款项行期初期末变动是否与L5-2明细表增减一致

### 二、原值与未确认融资费用备抵勾稽

- [ ] 长期应付款净额是否等于原值（2701）减未确认融资费用（2702）
- [ ] 未确认融资费用备抵方向是否正确（借方余额抵减负债）
- [ ] 净额是否与L5-3未确认融资费用明细表期末余额勾稽
- [ ] 本期未确认融资费用摊销额是否与L5-5实际利率法测算一致
- [ ] 应付融资租赁款与分期付款购入固定资产是否分别列示原值与备抵

### 三、一年内到期重分类

- [ ] 一年内到期的长期应付款净额是否已单独列示并重分类
- [ ] 披露审定数是否等于审定数减一年内到期数
- [ ] 重分类金额是否与L5-4调整分录（RJE）一致
- [ ] 一年内到期部分是否以净额（扣除对应未确认融资费用）重分类

### 四、试算平衡表核对与分类列报

- [ ] 长期应付款原值审定数是否与试算平衡表2701科目一致
- [ ] 未确认融资费用审定数是否与试算平衡表2702科目一致
- [ ] 审定表调整数（AJE+RJE）是否与试算平衡表调整数一致
- [ ] 关联方长期应付款是否单独列示
- [ ] 审定表分类是否与财务报表附注披露口径一致

## risk_areas

### 高风险

1. **净额备抵勾稽断裂**：长期应付款净额与原值减未确认融资费用不符，或备抵方向颠倒，导致非流动负债金额虚增或虚减。
2. **一年内到期未重分类**：将于一年内到期的长期应付款仍列示为非流动负债，虚增非流动负债、低估流动负债，扭曲流动比率。
3. **期初期末不勾稽**：期初审定数与上年期末审定数不一致，本期审定数失去基准，可能存在未授权调整。
4. **未确认融资费用摊销不实**：摊销额未采用实际利率法或与L5-5测算不符，导致财务费用与负债余额同时失真。

### 中风险

1. **明细与汇总不勾稽**：审定表各款项合计与L5-2明细表总计不一致，可能存在明细遗漏或重复。
2. **专项应付款转入无依据**：从专项应付款转入长期应付款缺乏转入依据或会计处理错误。
3. **本金与利息未区分**：本期支付未区分本金偿还与利息（未确认融资费用摊销），影响现金流量表分类。
4. **审定表与附注口径不一致**：审定表分类与附注披露分类不一致，影响信息一致性。

### 低风险

1. **审定表格式不规范**：列标题、行顺序、备抵列列示方式不规范，影响可读性。
2. **交叉索引不完整**：审定表未与L5-2/L5-3/L5-5及试算平衡表建立完整索引引用。
3. **变动说明不充分**：净额重大变动的行项目未附简要说明。
