# L4-note-soe 应付债券附注披露复核提示词（国有企业）

## 概述

本提示词针对应付债券国有企业附注披露底稿（L4-note-soe，科目2502）的复核，聚焦国有企业特定的披露要求：债券逐只列示与摊余成本变动、可转换债券条款、一年内到期披露、国资监管相关的债务规模与偿债能力披露、违约与兑付情况，以及决算报表口径一致性。国企债券融资规模较大，披露须同时满足会计准则与国资监管要求。

**法规依据：**
- 《企业会计准则第37号——金融工具列报》
- 《企业会计准则第22号——金融工具确认和计量》
- 《中央企业财务决算报告管理办法》

---

## tips

1. **国企附注有"双层"披露要求**：既满足CAS37通用披露，又满足国资委决算报告对债务规模、债券融资、偿债能力的额外要求。
2. **应付债券须逐只列示并披露摊余成本变动**：附注逐只列示债券要素（国企版通常列"期初余额"），续表披露本期发行、利息计提、溢折价摊销、本期偿还、期末余额。
3. **违约与兑付情况须结合国资监管披露**：债券违约、兑付情况须披露，大额违约涉及债务风险管控和问责，影响国有企业信用。
4. **债券融资规模服务国资考核**：债券余额、融资成本是国企债务管理和考核指标，须与决算口径一致。
5. **一年内到期债券须披露并重分类**：一年内到期金额披露并与非流动负债勾稽，评估短期兑付压力。
6. **可转换债券与永续债须专项披露**：可转换债券条款、永续债的负债权益分类须披露。

## checklist

### 一、基础披露完整性（与上市版共有）

- [ ] 是否逐只列示债券名称、面值、票面利率、发行日期、期限、发行金额
- [ ] 摊余成本变动（期初/本期发行/利息计提/摊销/偿还/期末）是否完整披露
- [ ] 各只债券期末余额合计是否等于审定表审定数
- [ ] 一年内到期金额是否披露并与非流动负债勾稽
- [ ] 期初/期末可比信息是否完整

### 二、国资监管相关披露

- [ ] 债券融资规模及占债务总额比例是否与决算口径一致
- [ ] 债券违约/兑付情况是否披露风险管控措施
- [ ] 分年度到期结构是否披露以评估兑付压力
- [ ] 债券融资成本（实际利率）是否披露

### 三、特殊工具与违约披露

- [ ] 可转换债券转股条款及负债权益分拆是否披露
- [ ] 永续债负债/权益分类是否披露
- [ ] 债券是否违约/触发交叉违约是否披露
- [ ] 本期兑付情况是否披露

### 四、决算报表一致性

- [ ] 应付债券数据是否与年度财务决算报表一致
- [ ] 债券融资规模是否纳入债务管理考核相关披露
- [ ] 集团合并层面内部债券抵销是否完整

## risk_areas

### 高风险

1. **附注与审定表/决算不勾稽**：附注应付债券期末余额与审定表或决算报表不一致。
2. **违约情况未披露**：债券违约或交叉违约未披露，涉及债务风险问责，隐瞒重大信用风险。
3. **可转换债券条款/分拆未披露**：转股条款或负债权益分拆金额未披露。
4. **一年内到期披露/重分类错误**：一年内到期金额未披露或未重分类。

### 中风险

1. **债券融资规模口径不一致**：附注债券规模与决算考核口径存在差异。
2. **摊余成本变动披露不完整**：债券续表变动项目不完整。
3. **到期结构披露缺失**：未披露分年度到期金额。
4. **融资成本未披露**：债券实际利率/融资成本未披露。

### 低风险

1. **披露格式未按决算模板**：附注格式与国资委决算模板有细微差异。
2. **债券条款说明简略**：赎回/回售/转股条款披露不详。
3. **历史趋势分析不完整**：债券融资规模趋势分析未覆盖建议年限。
