# L4-9 应付债券检查表复核提示词

## 概述

本提示词针对应付债券检查表（L4-9，科目2502）的复核，是应付债券审计程序的综合性核对底稿，聚焦完整性测试（债券发行完整性）、准确性测试（摊余成本/实际利率法/应计利息）、分类列报测试（负债权益划分/一年内到期重分类）、可转换债券分拆测试，以及凭证核对充分性。检查表统领应付债券各专项底稿的审计结论。

**法规依据：**
- 《企业会计准则第22号——金融工具确认和计量》
- 《企业会计准则第37号——金融工具列报》
- 《中国注册会计师审计准则第1301号——审计证据》
- 《中国注册会计师审计准则第1312号——函证》

---

## tips

1. **检查表统领应付债券全部审计程序**：须逐项确认完整性、准确性、分类列报各认定的审计程序已执行并得出结论。
2. **完整性须核对全部发行债券**：结合债券募集说明书、监管备案、托管记录，确认账面债券完整反映全部已发行债券。
3. **准确性核心是摊余成本与实际利率法**：须验证初始计量实际利率、后续摊销、应计利息的准确性，与L4-6/L4-7/L4-8勾稽。
4. **负债权益划分与可转换分拆须测试**：优先股/永续债分类、可转换债券负债权益分拆须测试，与L4-3/L4-5勾稽。
5. **一年内到期重分类须测试**：一年内到期债券识别和重分类须测试，与L4-1/L4-4勾稽。
6. **凭证核对须覆盖发行与偿还**：债券发行募集资金、付息、兑付本金须核对募集资金到账、付息凭证、兑付凭证。

## checklist

### 一、完整性测试

- [ ] 是否核对债券募集说明书、监管备案、托管记录
- [ ] 账面债券是否完整反映全部已发行债券
- [ ] 债券发行募集资金是否核对到账凭证
- [ ] 是否存在已发行债券未入账

### 二、准确性测试

- [ ] 初始计量实际利率是否验证（L4-6勾稽）
- [ ] 实际利率法后续摊销是否验证（L4-7勾稽）
- [ ] 账面与摊销表是否核对（L4-8勾稽）
- [ ] 应计利息计算是否准确
- [ ] 付息、兑付本金是否核对付息/兑付凭证

### 三、分类列报测试

- [ ] 负债权益划分是否测试（L4-3勾稽）
- [ ] 可转换债券负债权益分拆是否测试（L4-5勾稽）
- [ ] 一年内到期债券是否识别并重分类（L4-1/L4-4勾稽）
- [ ] 应计利息列报是否恰当

### 四、检查比例与异常

- [ ] 债券本息核对比例是否达到计划水平
- [ ] 大额/复杂债券（可转债/永续债）是否重点检查
- [ ] 核对发现的差异是否逐一追查解决
- [ ] 异常事项（违约/回售/转股）是否记录

## risk_areas

### 高风险

1. **完整性程序不到位**：未核对募集/备案/托管记录，已发行债券未入账风险。
2. **摊余成本计量未验证**：未验证实际利率法计量，债券账面和利息费用可靠性存疑。
3. **负债权益划分未测试**：优先股/永续债分类或可转换分拆未测试，分类错误未识别。
4. **一年内到期重分类未测试**：未测试一年内到期识别和重分类。

### 中风险

1. **检查比例不足**：债券本息核对比例低于计划。
2. **应计利息准确性未验证**：应计利息计算未核对。
3. **凭证核对造假未识别**：付息/兑付凭证异常未被发现。
4. **异常事项未追查**：违约/回售/转股等异常未记录追查。

### 低风险

1. **检查记录不完整**：审计程序执行记录不规范。
2. **检查表格式不统一**：检查底稿格式不规范。
3. **索引缺失**：检查表与各专项底稿交叉索引不完整。
