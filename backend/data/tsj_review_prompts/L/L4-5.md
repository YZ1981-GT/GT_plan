# L4-5 权益与负债划分检查复核提示词

## 概述

本提示词针对应付债券权益与负债划分检查表（L4-5，科目2502）的复核，聚焦复合金融工具（可转换债券）的负债成分与权益成分分拆、含权益特征债券的分类判断（CAS37）、以及分拆金额的计量。可转换债券和含权债券的分拆是应付债券审计的核心难点，错误将导致负债、权益、财务费用同时错报。

**法规依据：**
- 《企业会计准则第22号——金融工具确认和计量》
- 《企业会计准则第37号——金融工具列报》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **可转换债券分拆是权益负债划分的核心**：可转换公司债券须先确定负债成分（按不含转股权的类似债券市场利率折现未来现金流），发行价减负债成分为权益成分。
2. **负债成分折现率须为市场利率**：负债成分折现使用的是不含转股权的类似债券的市场利率，而非票面利率，须验证折现率的合理性。
3. **权益成分计入其他权益工具/资本公积**：分拆出的权益成分（转股权价值）计入其他权益工具或资本公积，后续不重新计量。
4. **分拆后负债成分按实际利率法摊销**：负债成分作为债券负债按实际利率法后续计量，实际利率基于负债成分初始金额。
5. **转股/赎回/回售条款须评估**：转股权、赎回权、回售权等嵌入衍生工具须评估是否需分拆单独确认。
6. **含权益特征工具的整体分类判断**：其他含权益特征的债券须整体判断分类为金融负债还是权益工具（与L4-3勾稽）。

## checklist

### 一、可转换债券分拆

- [ ] 可转换债券是否分拆负债成分与权益成分
- [ ] 负债成分是否按不含转股权的市场利率折现确定
- [ ] 权益成分是否=发行价-负债成分
- [ ] 折现使用的市场利率是否合理（有依据）
- [ ] 分拆时点是否为初始确认时

### 二、权益成分列报与后续计量

- [ ] 权益成分是否计入其他权益工具/资本公积
- [ ] 权益成分后续是否未重新计量
- [ ] 负债成分是否按实际利率法后续计量
- [ ] 负债成分实际利率是否基于负债成分初始金额

### 三、嵌入衍生工具评估

- [ ] 转股权是否评估是否需分拆单独确认
- [ ] 赎回权、回售权等嵌入衍生工具是否评估
- [ ] 嵌入衍生工具与主合同经济特征关联度是否评估

### 四、整体分类判断

- [ ] 含权益特征债券整体分类是否与L4-3勾稽
- [ ] 分类判断依据是否充分
- [ ] 重大会计判断是否披露

## risk_areas

### 高风险

1. **可转换债券未分拆**：未将负债成分和权益成分分拆，负债和权益均失真，财务费用低估。
2. **折现率错误**：负债成分折现使用票面利率而非市场利率，负债成分金额错误。
3. **权益成分计量错误**：权益成分金额或列报位置错误。
4. **嵌入衍生工具未分拆**：需分拆的嵌入衍生工具未单独确认。

### 中风险

1. **负债成分实际利率错误**：后续摊销的实际利率基于错误的初始金额。
2. **整体分类判断错误**：含权债券整体分类与L4-3不一致。
3. **权益成分后续重新计量**：权益成分错误地进行了后续重新计量。

### 低风险

1. **分拆计算过程记录不清**：折现和分拆过程未清晰列示。
2. **检查表格式不规范**：检查底稿格式不统一。
3. **重大判断披露不充分**：分类和分拆的重大判断披露不足。
