# L7-1 其他非流动负债审定表复核提示词

## 概述

本提示词针对其他非流动负债审定表（L7-1）的复核，聚焦双期结构勾稽、按项目分类、长期性判断（是否满足非流动分类条件）、一年内到期部分重分类以及与试算平衡表的核对。其他非流动负债（2801）核算不能归入长期借款、长期应付款等特定科目的其他长期负债，审定表须清晰列示各项目性质，长期性判断错误或重分类遗漏将导致流动性列报重大错误。

**法规依据：**
- 《企业会计准则第22号——金融工具确认和计量》
- 《企业会计准则第37号——金融工具列报》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **长期性判断是分类前提**：其他非流动负债须满足清偿期在资产负债表日后一年以上的条件，审定表应逐项验证长期性，不满足条件的应重分类至流动负债。
2. **双期结构承前启后**：期初审定数须等于上年期末审定数，期末审定数=期初+本期增加-本期减少（含审计调整），期初差异须追溯说明。
3. **性质分类须准确**：其他非流动负债是"兜底"科目，须核查各项目是否应归入更特定科目（长期借款/长期应付款/递延收益/预计负债等），防止科目滥用掩盖负债性质。
4. **一年内到期重分类**：将于一年内到期的其他非流动负债须重分类至"一年内到期的非流动负债"，审定表应设重分类列，披露审定数=审定数-一年内到期数。
5. **递延收益等特殊项目**：若其他非流动负债包含递延收益、长期递延项目等，须验证其确认与摊销的合理性。
6. **审定表勾稽中心**：审定数应与L7-2明细表合计、试算平衡表2801科目及附注披露形成闭环。

## checklist

### 一、双期勾稽与承前启后

- [ ] 期初未审数是否等于上年审定表期末审定数
- [ ] 期末审定数是否等于期初加本期增加减本期减少（含调整）
- [ ] 期初差异是否已充分说明
- [ ] 各项目期初期末变动是否与L7-2明细表一致

### 二、长期性判断与性质分类

- [ ] 各项目清偿期是否在资产负债表日后一年以上
- [ ] 不满足长期性条件的项目是否重分类至流动负债
- [ ] 各项目是否应归入更特定科目（长期借款/长期应付款/递延收益等）
- [ ] 是否存在利用其他非流动负债科目掩盖负债性质的情况

### 三、一年内到期重分类

- [ ] 一年内到期部分是否已单独列示并重分类
- [ ] 披露审定数是否等于审定数减一年内到期数
- [ ] 重分类金额是否与L7-3调整分录（RJE）一致

### 四、试算平衡表核对与列报

- [ ] 审定数是否与试算平衡表2801科目一致
- [ ] 审定表调整数（AJE+RJE）是否与试算平衡表调整数一致
- [ ] 审定数是否与L7-2明细表合计勾稽
- [ ] 审定表分类是否与附注披露口径一致

## risk_areas

### 高风险

1. **科目滥用掩盖性质**：将应归入特定科目的负债计入其他非流动负债，掩盖负债真实性质，误导报表使用者。
2. **长期性判断错误**：不满足长期性条件的负债仍列为非流动，虚增非流动负债、低估流动负债。
3. **一年内到期未重分类**：一年内到期部分未重分类，扭曲流动比率。
4. **期初期末不勾稽**：期初审定数与上年期末不一致，审定基准失真。

### 中风险

1. **明细与汇总不勾稽**：审定表与L7-2明细表合计不一致。
2. **递延项目确认不当**：递延收益等特殊项目确认或摊销不合理。
3. **审定表与附注口径不一致**：分类与附注披露不一致。

### 低风险

1. **审定表格式不规范**：项目列示不清晰。
2. **变动说明不充分**：重大变动项目未附说明。
3. **交叉索引不完整**：未与L7-2及试算平衡表建立索引。
