# L5-7 长期应付款检查表复核提示词

## 适用底稿
长期应付款检查表（L5-7），聚焦凭证核对完整性、合同条款核查、款项存在性与义务真实性、样本选取合理性及检查比例达标性。

## 概述
L5-7 是长期应付款存在性、完整性和计量认定的证据支撑底稿。复核须验证：样本选取覆盖高风险款项、凭证核对覆盖完整链条（合同→现值计算→入账→付款）、异常事项标注充分、检查比例满足审计目标。

## tips

- 样本选取应覆盖金额重大项目、关联方款项、本期新增及一年内到期款项
- 凭证核对须覆盖完整链条（融资租赁/购货合同→现值/实际利率计算→入账凭证→付款凭证）
- 合同条款核查须关注付款计划、利率、租赁期/分期期、购买选择权、违约条款
- 检查比例应满足《中国注册会计师审计准则第1314号——审计抽样》要求
- 关注融资租赁资产是否已确认使用权资产（CAS21承租人会计处理）
- 期后付款测试验证本金偿还的真实性和一年内到期金额的准确性
- 异常事项标注需明确类型（利率异常/付款逾期/合同缺失/关联方/性质存疑）

## checklist

### 高风险检查项

- [ ] 样本选取是否覆盖金额重大及高风险款项（关联方/新增/一年内到期）
- [ ] 抽样方法是否符合CAS1314要求
- [ ] 金额重大款项（超过重要性水平）是否100%检查
- [ ] 融资租赁/购货合同是否齐全并核对付款计划、利率、期限
- [ ] 现值计算/实际利率确定是否有支持性底稿
- [ ] 入账金额是否与合同现值一致（原值-未确认融资费用）
- [ ] 本期付款是否有付款凭证支持并区分本金与利息
- [ ] 一年内到期金额是否经期后付款测试验证
- [ ] 是否存在无真实业务支持的长期应付款挂账
- [ ] 融资租赁是否已同步确认使用权资产（CAS21）

### 中风险检查项

- [ ] 检查比例（已检查金额/总体金额）是否达到计划水平
- [ ] 借方（本期支付本金）检查比例是否达标
- [ ] 贷方（本期新增）检查比例是否达标
- [ ] 合同条款（购买选择权/违约/续租）核查是否充分
- [ ] 付款逾期款项是否已识别并评估违约影响
- [ ] 款项性质分类是否与合同实质核对一致
- [ ] 核对中发现的差异是否逐一追踪解决

### 低风险检查项

- [ ] 抽样参数（总体/置信水平/可容忍错报）是否完整记录
- [ ] 样本选取过程是否可追溯
- [ ] 检查结果记录格式是否规范
- [ ] 检查比例计算公式是否正确
- [ ] 底稿索引与交叉引用是否完整（关联审定表/明细表/测算表）

## risk_areas

### 高风险

- **完整性缺口风险**：存在的长期应付款（尤其表外融资租赁）未纳入检查，低估非流动负债
- **入账金额错误风险**：现值/实际利率计算错误导致入账原值与未确认融资费用失真
- **一年内到期不准确风险**：一年内到期金额未经期后付款测试验证，流动性列报错误
- **虚假挂账风险**：无真实业务支持的长期应付款，可能为变相融资或关联方资金占用
- **使用权资产遗漏风险**：融资租赁未同步确认使用权资产，资产负债表不完整

### 中风险

- **检查比例不足风险**：实际检查比例低于计划水平，审计证据不充分
- **合同条款核查不深风险**：仅核对金额而忽略购买选择权/违约/续租条款
- **付款逾期未识别风险**：逾期款项未评估违约与持续经营影响

### 低风险

- **记录不完整风险**：抽样参数/核对结果记录不完整
- **索引缺失风险**：与审定表/明细表/测算表交叉索引不完整
- **格式不规范风险**：检查结果记录格式不统一
