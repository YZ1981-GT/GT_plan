# L6-note-listed 附注披露复核提示词（上市公司）

## 概述

本提示词针对专项应付款上市公司附注披露底稿（L6-note-listed）的复核，聚焦上市公司财务报表附注中专项应付款相关披露的充分性和准确性：按专项项目分类披露、期初本期增减期末变动、资本性拨款性质说明、完工结转情况以及与政府补助披露的界分和勾稽。上市公司须充分披露专项应付款的来源、用途、变动及结转，使报表使用者了解专项资金的性质和使用状况。

**法规依据：**
- 《企业会计准则第16号——政府补助》
- 《企业会计准则第37号——金融工具列报》
- 《企业会计准则第30号——财务报表列报》
- 《公开发行证券的公司信息披露编报规则第15号——财务报告的一般规定》

---

## tips

1. **按专项项目分类披露**：专项应付款须按专项项目分类披露期初余额、本期增加、本期结转/退回、期末余额，各项目变动清晰可追溯。
2. **资本性拨款性质说明**：附注须说明专项应付款为具有专门用途的资本性拨款，与计入递延收益的政府补助区分披露。
3. **完工结转情况披露**：本期完工结转的专项项目须披露结转金额及结转方向（资本公积/递延收益/营业外收入）。
4. **拨款来源与用途披露**：重大专项项目宜披露拨款单位、批文依据及资金用途。
5. **与政府补助勾稽界分**：附注专项应付款与政府补助（递延收益）披露须界分清晰，防止性质混淆。
6. **闭环勾稽**：附注专项应付款期末余额合计须等于审定表审定数，各专项项目变动须与L6-2明细表勾稽。

## checklist

### 一、分类与变动披露

- [ ] 专项应付款是否按专项项目分类披露
- [ ] 是否列示期初余额、本期增加、本期结转/退回、期末余额
- [ ] 各专项项目期末余额合计是否等于审定表审定数
- [ ] 是否同时列示期末数和期初数（可比信息）

### 二、性质与结转披露

- [ ] 是否说明专项应付款为资本性拨款性质
- [ ] 本期完工结转的专项项目是否披露结转金额及方向
- [ ] 结转方向（资本公积/递延收益/营业外收入）是否说明
- [ ] 是否与政府补助（递延收益）披露界分清晰

### 三、来源与用途披露

- [ ] 重大专项项目是否披露拨款单位及批文依据
- [ ] 专项资金用途是否披露
- [ ] 是否说明专款专用情况

### 四、勾稽

- [ ] 附注专项应付款各项目变动是否与L6-2明细表勾稽
- [ ] 附注结转情况是否与L6-1审定表结转一致
- [ ] 附注专项应付款期末余额是否与资产负债表项目一致

## risk_areas

### 高风险

1. **性质披露误导**：将应计入损益的政府补助作为专项应付款披露，掩盖损益确认问题。
2. **结转方向披露错误**：完工结转方向披露与实际会计处理不一致，误导报表使用者。
3. **附注余额与审定表不一致**：附注专项应付款期末余额与审定数不勾稽。

### 中风险

1. **变动明细不完整**：未完整披露本期增减变动，无法了解专项资金流动。
2. **与政府补助界分不清**：专项应付款与递延收益披露界分模糊。
3. **来源用途披露缺失**：未披露拨款单位、批文及用途。

### 低风险

1. **披露格式不规范**：分类表列序、金额单位不符编报规则。
2. **可比信息缺失**：仅列示期末数据未列示期初可比数据。
3. **专款专用说明简略**：未充分说明专款专用情况。
