# L4-6 应付债券初始计量复核提示词

## 概述

本提示词针对应付债券初始计量表（L4-6，科目2502）的复核，聚焦债券初始入账金额（发行价减交易费用）、实际利率（IRR）的计算、发行费用的处理，以及初始计量与后续摊销的衔接。初始计量确定的实际利率是后续实际利率法摊销的基础，是应付债券计量准确性的起点。

**法规依据：**
- 《企业会计准则第22号——金融工具确认和计量》
- 《企业会计准则第37号——金融工具列报》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **初始入账金额=发行价-交易费用**：债券初始确认金额为实际收到的发行价款减去归属于该债券的交易费用（承销费、发行费等）。
2. **实际利率（IRR）计算是初始计量核心**：实际利率是将债券存续期未来现金流（票面利息+本金）折现到初始入账金额的折现率，须验证IRR计算的准确性。
3. **交易费用计入债券初始金额**：发行费用不得当期费用化，须计入债券初始入账金额，通过实际利率法在存续期摊销。
4. **实际利率须区别于票面利率**：溢价发行时实际利率低于票面利率，折价发行时实际利率高于票面利率，平价且无费用时两者相等。
5. **初始实际利率贯穿存续期**：初始确定的实际利率在债券存续期内保持不变（除非重新估计现金流），是后续摊销的基础。
6. **初始计量须与L4-7后续计量衔接**：初始入账金额和实际利率须与后续计量摊销表的起点一致。

## checklist

### 一、初始入账金额

- [ ] 初始入账金额是否=发行价款-交易费用
- [ ] 发行价款是否与实际募集资金一致
- [ ] 交易费用（承销费/发行费）是否已归集并计入初始金额
- [ ] 是否存在发行费用错误当期费用化

### 二、实际利率计算

- [ ] 实际利率是否将未来现金流折现到初始入账金额
- [ ] 未来现金流（票面利息+本金）是否完整准确
- [ ] IRR计算方法是否正确
- [ ] 溢价/折价发行的实际利率与票面利率关系是否合理

### 三、可转换债券初始计量

- [ ] 可转换债券负债成分初始金额是否按市场利率折现（与L4-5勾稽）
- [ ] 可转换债券实际利率是否基于负债成分初始金额
- [ ] 交易费用是否在负债成分和权益成分间合理分摊

### 四、与后续计量衔接

- [ ] 初始入账金额是否与L4-7后续计量摊销表起点一致
- [ ] 初始实际利率是否与后续摊销使用的实际利率一致
- [ ] 初始计量是否在债券发行日确认

## risk_areas

### 高风险

1. **实际利率计算错误**：IRR计算错误导致整个存续期摊销和利息费用失真。
2. **交易费用费用化**：发行费用错误当期费用化而非计入债券初始金额，虚增当期费用、虚增债券账面。
3. **初始入账金额错误**：未减除交易费用或发行价款记录错误。
4. **可转换债券负债成分初始金额错误**：负债成分未按市场利率折现。

### 中风险

1. **现金流不完整**：IRR计算的未来现金流遗漏或错误。
2. **交易费用分摊错误**：可转换债券交易费用未在负债权益成分间合理分摊。
3. **初始与后续计量不衔接**：初始金额或实际利率与后续摊销表不一致。

### 低风险

1. **IRR计算过程记录不清**：实际利率计算过程未清晰列示。
2. **交易费用归集记录不完整**：发行费用明细记录不全。
3. **索引不完整**：初始计量未与后续计量、权益负债划分底稿建立索引。
