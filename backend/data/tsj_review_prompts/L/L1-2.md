# L1-2 短期借款明细表复核提示词

## 概述

本提示词针对短期借款明细表（L1-2，科目2001）的复核，聚焦逐笔借款明细的完整性、期初借入归还期末勾稽、借款要素（贷款人/金额/利率/期限/担保方式）的准确性，以及明细合计与审定表的勾稽。明细表是识别表外借款和验证借款存在性的基础底稿。

**法规依据：**
- 《企业会计准则第22号——金融工具确认和计量》
- 《企业会计准则第37号——金融工具列报》
- 《中国注册会计师审计准则第1312号——函证》

---

## tips

1. **逐笔明细完整性是防表外负债的第一线**：每笔借款须列示贷款人、借款金额、利率、起止日期、担保方式，与征信报告和银行函证逐笔核对，识别未入账借款。
2. **期末余额勾稽公式必须成立**：每笔借款期末余额=期初余额+本期借入-本期归还，任何行的公式不成立须追溯原始凭证。
3. **利率与期限须与合同一致**：明细表记录的利率、期限须与L1-6贷款合同检查一致，异常低利率或超期借款需重点关注。
4. **担保方式须与担保资产勾稽**：抵押/质押借款的担保方式须与L1-8抵质押资产检查对应，识别重复担保或超额担保。
5. **明细合计须与审定表勾稽**：明细表按借款种类的合计须等于审定表L1-1对应种类的未审数。
6. **关注关联方借款与异常利率借款**：关联方借款须单独标识评估公允性，明显偏离市场利率的借款需分析商业实质。

## checklist

### 一、明细完整性与存在性

- [ ] 每笔借款是否列示贷款人、借款金额、利率、起止日期、担保方式
- [ ] 明细表借款是否与银行函证回函逐笔一致
- [ ] 明细表借款是否与征信报告/贷款卡记录完整对应
- [ ] 是否存在征信有记录但明细表未列示的借款
- [ ] 期末新增借款是否有借款合同和资金到账凭证

### 二、勾稽准确性

- [ ] 每笔借款期末余额是否=期初+本期借入-本期归还
- [ ] 明细表按借款种类合计是否等于审定表L1-1对应种类未审数
- [ ] 明细表借款总额是否与试算平衡表2001科目一致
- [ ] 外币借款是否按期末汇率折算并单独标识币种

### 三、借款要素准确性

- [ ] 利率是否与L1-6贷款合同检查一致
- [ ] 借款期限是否在1年以内（超期部分是否已重分类或说明）
- [ ] 担保方式是否与L1-8抵质押资产检查勾稽
- [ ] 关联方借款是否单独标识
- [ ] 异常利率（明显偏离市场）借款是否已分析

### 四、列设置与披露

- [ ] 明细表列是否覆盖披露所需全部要素（种类/担保/逾期状态）
- [ ] 逾期借款是否已标识并与L1-7勾稽
- [ ] 明细表数据是否与附注披露分类一致

## risk_areas

### 高风险

1. **借款漏记**：明细表遗漏征信/函证中的借款，导致负债低估。
2. **虚构归还掩盖余额**：通过虚构本期归还调低期末余额，掩盖真实负债规模。
3. **期末余额勾稽不成立**：借款行期末余额无法用借入归还解释。
4. **关联方借款隐匿**：关联方拆借未单独标识或按一般借款处理。

### 中风险

1. **利率与合同不一致**：明细表利率与贷款合同记录不符。
2. **担保方式与担保资产不对应**：抵质押借款担保方式与L1-8不勾稽。
3. **明细与审定表不勾稽**：明细合计与审定表种类合计不一致。
4. **外币折算错误**：外币借款期末未按即期汇率折算。

### 低风险

1. **借款要素记录不完整**：个别借款缺利率或期限记录。
2. **列设置不规范**：明细表列缺失导致披露信息不全。
3. **索引不完整**：明细表未与合同检查、函证底稿建立索引。
