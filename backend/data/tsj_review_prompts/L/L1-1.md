# L1-1 短期借款审定表复核提示词

## 概述

本提示词针对短期借款审定表（L1-1，科目2001）的复核，聚焦借款完整性（防止表外负债）、期初期末勾稽、试算平衡表核对、审计调整完整性与分类列报。审定表是短期借款审计的枢纽，承载未审数→调整→审定数链路，借款漏记或分类错误将导致负债低估的重大错报。

**法规依据：**
- 《企业会计准则第22号——金融工具确认和计量》
- 《企业会计准则第37号——金融工具列报》
- 《中国注册会计师审计准则第1312号——函证》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **借款完整性是短期借款审定表的首要关注点**：负债类科目的核心风险是低估，须结合银行函证、征信报告、贷款卡查询交叉验证，确认不存在未入账的表外借款。
2. **期初期末勾稽必须成立**：期初审定数应等于上年期末审定数，期末审定数=期初审定数+本期借入（贷方）-本期归还（借方），任何无源差异需追溯。
3. **审定数合计必须与试算平衡表2001科目一致**：审定表按借款种类（信用/抵押/质押/保证）汇总的审定数合计须与试算平衡表短期借款科目审定数完全勾稽。
4. **利息计提须与L1-5利息测算表勾稽**：应计未付利息应重分类至应付利息（2231）而非留在短期借款，审定表须体现本息分离。
5. **抵质押担保借款须单独列示**：以资产抵押/质押取得的借款，其担保资产状况须与L1-8抵质押资产检查勾稽，受限资产在附注中披露。
6. **关注期末突增借款与逾期借款**：期末新增大额借款需核查用途与授权，逾期借款须与L1-7逾期检查勾稽并评估重分类及违约影响。

## checklist

### 一、期初期末勾稽与试算平衡表核对

- [ ] 审定表期初未审数是否等于上年审定表期末审定数
- [ ] 期末审定数是否等于期初审定数+本期借入-本期归还（加减审计调整）
- [ ] 审定表按借款种类的审定数合计是否与试算平衡表2001科目审定数一致
- [ ] 各借款种类（信用/抵押/质押/保证）小计是否与明细表L1-2勾稽
- [ ] 未审数、AJE调整、RJE调整是否与试算平衡表口径一致

### 二、借款完整性

- [ ] 是否已实施银行函证覆盖全部借款账户，函证回函与账面是否一致
- [ ] 是否已核对征信报告/贷款卡，账面借款是否与征信记录完整对应
- [ ] 是否存在征信有记录但账面未入账的表外借款
- [ ] 期末新增大额借款是否有授权文件和资金到账凭证
- [ ] 应计未付利息是否已正确从本金中分离并计提

### 三、审计调整完整性

- [ ] 所有账项调整（AJE）是否完整反映在审定表调整列
- [ ] 所有重分类调整（RJE）是否完整反映在审定表重分类列
- [ ] 调整分录借贷方是否平衡，是否等于L1-3调整分录汇总
- [ ] 逾期一年以上借款是否评估是否需重分类
- [ ] 未调整错报是否记录于A13未调整错报汇总表

### 四、分类列报准确性

- [ ] 短期借款是否严格按1年以内到期分类（超期部分处理是否恰当）
- [ ] 关联方借款是否单独列示
- [ ] 抵质押/保证借款是否按担保方式分类披露
- [ ] 外币借款是否按期末汇率折算并确认汇兑损益
- [ ] 审定表分类是否与附注披露分类一致

## risk_areas

### 高风险

1. **表外借款漏记**：存在未入账的短期借款（民间借贷、关联方拆借），导致负债严重低估，须结合征信/函证识别。
2. **期初期末不勾稽**：期初审定数与上年期末不一致，或期末余额无法用借入归还解释，存在未授权调整。
3. **审定数与试算平衡表不一致**：审定表合计与2001科目审定数存在差异，意味着汇总错误或调整遗漏。
4. **利息本金未分离**：应计利息混在短期借款本金中，导致短期借款高估、应付利息低估。
5. **逾期借款未评估违约影响**：逾期借款未考虑交叉违约条款触发或需重分类的影响。

### 中风险

1. **明细与汇总不勾稽**：审定表借款种类合计与L1-2明细表不一致。
2. **外币借款折算错误**：外币借款未按期末汇率折算或汇兑损益计算错误。
3. **抵质押担保未与L1-8勾稽**：担保借款金额与抵质押资产检查表不对应。
4. **重分类调整方向错误**：RJE借贷方向颠倒导致审定数偏离。
5. **关联方借款未单独列示**：关联方借款混入一般借款。

### 低风险

1. **审定表格式不规范**：列标题、行顺序等格式问题不影响数据准确性。
2. **交叉索引不完整**：未与试算平衡表、明细表、调整分录建立完整索引。
3. **变动说明不充分**：期末变动较大的借款种类未附简要说明。
4. **可比数据缺失**：未列示前期可比数据不便趋势分析。
