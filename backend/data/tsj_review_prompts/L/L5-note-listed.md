# L5-note-listed 附注披露复核提示词（上市公司）

## 概述

本提示词针对长期应付款上市公司附注披露底稿（L5-note-listed）的复核，聚焦上市公司财务报表附注中长期应付款相关披露的充分性和准确性：按性质分类披露（应付融资租赁款/分期付款购入固定资产/其他）、原值与未确认融资费用分列、到期期限分析、关联方长期应付款单独披露以及与审定表的闭环勾稽。上市公司须按证监会编报规则和CAS30列报要求充分披露长期应付款信息。

**法规依据：**
- 《企业会计准则第21号——租赁》
- 《企业会计准则第37号——金融工具列报》
- 《企业会计准则第30号——财务报表列报》
- 《公开发行证券的公司信息披露编报规则第15号——财务报告的一般规定》

## tips

1. **按性质分类披露**：长期应付款须按应付融资租赁款、分期付款购入固定资产、其他长期应付款分类披露，各类别期末期初余额并列。
2. **原值与未确认融资费用分列**：附注须分别列示长期应付款原值、减未确认融资费用、净额（账面价值），使报表使用者了解融资成本构成。
3. **到期期限分析**：须披露长期应付款按到期期限的分布（1年以内/1-2年/2-3年/3年以上），一年内到期部分已重分类的须与流动负债附注勾稽。
4. **关联方长期应付款单独披露**：根据CAS36，关联方长期应付款须单独列示关联方名称、关系、交易金额、期末余额。
5. **利率与折现信息**：应付融资租赁款的利率区间、分期付款的折现率等信息宜披露，便于评估融资成本合理性。
6. **闭环勾稽**：附注长期应付款净额合计须等于审定表审定数，各分类小计须与L5-2明细表对应分类合计勾稽，未确认融资费用须与L5-3勾稽。

## checklist

### 一、分类披露检查

- [ ] 长期应付款是否按性质分类披露（融资租赁款/分期购入固定资产/其他）
- [ ] 各类别是否同时列示期末数和期初数（可比信息）
- [ ] 各类别净额合计是否等于审定表长期应付款审定数
- [ ] 分类方式是否与会计政策一致
- [ ] 各分类之间是否存在重叠或遗漏

### 二、原值与未确认融资费用披露

- [ ] 是否分别列示原值、减未确认融资费用、净额
- [ ] 未确认融资费用是否与L5-3明细表勾稽
- [ ] 是否披露未确认融资费用的摊销方法（实际利率法）
- [ ] 净额是否与资产负债表长期应付款项目一致

### 三、到期期限分析

- [ ] 是否披露长期应付款按到期期限的分布
- [ ] 一年内到期部分是否已重分类并与流动负债附注勾稽
- [ ] 到期期限分布合计是否等于长期应付款总额
- [ ] 到期分布是否与L5-2明细表一致

### 四、关联方与其他披露

- [ ] 关联方长期应付款是否单独列示（名称/关系/金额）
- [ ] 应付融资租赁款利率区间是否披露
- [ ] 分期付款折现率是否披露
- [ ] 是否披露与融资租赁相关的使用权资产信息（CAS21）
- [ ] 是否披露长期应付款的担保/抵押安排

## risk_areas

### 高风险

1. **原值与净额混淆披露**：未分别列示原值、未确认融资费用、净额，报表使用者无法了解融资成本，或直接以原值列示虚增负债。
2. **一年内到期未与流动负债勾稽**：重分类金额在长期应付款附注与流动负债附注之间不勾稽，列报矛盾。
3. **关联方长期应付款未单独披露**：违反CAS36，可能隐瞒关联方融资安排。
4. **附注净额与审定表不一致**：附注披露的长期应付款净额与审定表审定数不一致，数据勾稽错误。

### 中风险

1. **到期期限披露缺失**：未披露到期期限分析，无法评估流动性风险。
2. **未确认融资费用摊销方法未披露**：未说明实际利率法及利率区间。
3. **可比信息缺失**：仅列示期末数据，未列示期初可比数据。

### 低风险

1. **披露格式不规范**：分类表列序、金额单位不符编报规则。
2. **利率/折现率披露过简**：仅提及利率但未披露区间或加权平均。
3. **使用权资产关联信息缺失**：未披露融资租赁对应的使用权资产信息。
