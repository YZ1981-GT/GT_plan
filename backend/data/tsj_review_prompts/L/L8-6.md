# L8-6 财务费用检查表复核提示词

## 适用底稿
财务费用检查表（L8-6），聚焦凭证核对完整性、利息/手续费/汇兑损益发生真实性、分类准确性、样本选取合理性及检查比例达标性。

## 概述
L8-6 是财务费用发生、准确性、分类认定的证据支撑底稿。复核须验证：样本覆盖各类财务费用及大额凭证、凭证核对覆盖完整链条、利息资本化划分正确、汇兑损益计算准确、检查比例满足审计目标。

## tips

- 样本选取应覆盖利息支出、手续费、汇兑损益各类别及金额重大凭证
- 凭证核对须覆盖完整链条（借款合同/服务协议→计息/计费依据→银行扣款/付款凭证→记账）
- 利息支出核对须关注资本化与费用化划分（CAS17）
- 汇兑损益核对须关注外币金额、适用汇率、折算/结算计算（CAS19）
- 手续费核对须关注是否应计入财务费用（vs 其他科目）及是否有服务真实性
- 检查比例应满足《中国注册会计师审计准则第1314号——审计抽样》要求
- 异常事项标注需明确类型（利率异常/资本化错配/汇率错误/费用性质存疑/无服务支持）

## checklist

### 高风险检查项

- [ ] 样本选取是否覆盖各类财务费用及金额重大凭证
- [ ] 金额重大凭证（超过重要性水平）是否100%检查
- [ ] 利息支出凭证是否有借款合同及计息依据支持
- [ ] 利息资本化与费用化划分是否正确（CAS17）
- [ ] 汇兑损益的外币金额、适用汇率、计算是否准确（CAS19）
- [ ] 手续费是否应计入财务费用（vs其他科目）且有服务真实性
- [ ] 是否存在无真实业务支持的财务费用
- [ ] 利率异常/费用性质存疑的凭证是否重点核查

### 中风险检查项

- [ ] 检查比例（已检查金额/总体发生额）是否达到计划水平
- [ ] 借方（利息/手续费支出）检查比例是否达标
- [ ] 贷方（利息收入/冲减）检查比例是否达标
- [ ] 分类准确性（各费用项目归属）是否核对
- [ ] 期后付息凭证是否核对验证截止
- [ ] 核对中发现的差异是否逐一追踪解决

### 低风险检查项

- [ ] 抽样参数（总体/置信水平/可容忍错报）是否完整记录
- [ ] 样本选取过程是否可追溯
- [ ] 检查结果记录格式是否规范
- [ ] 检查比例计算公式是否正确
- [ ] 底稿索引与交叉引用是否完整（关联审定表/明细表/测算表/截止测试）

## risk_areas

### 高风险

- **资本化错配风险**：应资本化利息费用化或反之，扭曲损益与资产成本
- **虚增财务费用风险**：无真实业务支持的利息/手续费，操纵利润或利益输送
- **汇兑损益计算错误风险**：外币金额/汇率/折算计算错误导致损益失真
- **费用性质错误风险**：应计入其他科目的费用归入财务费用或反之

### 中风险

- **检查比例不足风险**：实际检查比例低于计划水平
- **分类核对不深风险**：仅核对金额而忽略费用性质归属
- **服务真实性存疑风险**：手续费缺乏服务真实性验证

### 低风险

- **记录不完整风险**：抽样参数/核对结果记录不完整
- **索引缺失风险**：与审定表/明细表/测算表交叉索引不完整
- **格式不规范风险**：检查结果记录格式不统一

## 法规依据

- 《中国注册会计师审计准则第1314号——审计抽样》

- 《企业会计准则第17号——借款费用》
