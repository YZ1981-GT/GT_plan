# L7-note-listed 附注披露复核提示词（上市公司）

## 概述

本提示词针对其他非流动负债上市公司附注披露底稿（L7-note-listed）的复核，聚焦上市公司财务报表附注中其他非流动负债相关披露的充分性和准确性：按项目性质分类披露、期初期末变动、长期性及到期期限说明、一年内到期重分类与流动负债附注的勾稽以及与审定表的闭环勾稽。其他非流动负债作为兜底科目，附注须清晰说明各项目性质，防止性质模糊误导报表使用者。

**法规依据：**
- 《企业会计准则第37号——金融工具列报》
- 《企业会计准则第30号——财务报表列报》
- 《公开发行证券的公司信息披露编报规则第15号——财务报告的一般规定》

---

## tips

1. **按项目性质分类披露**：其他非流动负债须按项目性质分类披露，各项目期末期初余额并列，性质须清晰说明避免笼统"其他"。
2. **性质说明防兜底模糊**：附注须说明各项目的具体性质和形成原因，避免以"其他"笼统披露掩盖负债实质。
3. **到期期限与长期性**：宜披露其他非流动负债的到期期限，一年内到期部分已重分类的须与流动负债附注勾稽。
4. **重大项目单独披露**：金额重大的单项其他非流动负债宜单独披露性质、金额、形成原因。
5. **关联方项目单独披露**：涉及关联方的其他非流动负债须单独列示。
6. **闭环勾稽**：附注其他非流动负债期末余额合计须等于审定表审定数，各项目变动须与L7-2明细表勾稽。

## checklist

### 一、分类与性质披露

- [ ] 其他非流动负债是否按项目性质分类披露
- [ ] 各项目性质及形成原因是否清晰说明
- [ ] 是否避免以"其他"笼统披露掩盖实质
- [ ] 各项目期末余额合计是否等于审定表审定数
- [ ] 是否同时列示期末数和期初数（可比信息）

### 二、变动与到期披露

- [ ] 是否披露本期增减变动
- [ ] 是否披露到期期限及长期性说明
- [ ] 一年内到期部分是否已重分类并与流动负债附注勾稽
- [ ] 重大项目是否单独披露性质、金额、形成原因

### 三、关联方与其他

- [ ] 关联方其他非流动负债是否单独列示
- [ ] 是否披露相关的担保/抵押安排
- [ ] 递延项目等特殊负债的确认与摊销是否说明

### 四、勾稽

- [ ] 附注各项目变动是否与L7-2明细表勾稽
- [ ] 附注一年内到期是否与L7-1审定表重分类一致
- [ ] 附注期末余额是否与资产负债表项目一致

## risk_areas

### 高风险

1. **性质披露模糊**：以"其他"笼统披露而不说明各项目实质，掩盖负债性质，误导报表使用者。
2. **一年内到期未与流动负债勾稽**：重分类金额在两附注间不勾稽，列报矛盾。
3. **附注余额与审定表不一致**：附注其他非流动负债期末余额与审定数不勾稽。

### 中风险

1. **重大项目未单独披露**：金额重大单项未单独披露性质和原因。
2. **到期期限披露缺失**：未披露到期期限，无法评估长期性。
3. **关联方项目未单独披露**：涉及关联方的项目未单独列示。

### 低风险

1. **披露格式不规范**：分类表列序、金额单位不符编报规则。
2. **可比信息缺失**：仅列示期末数据未列示期初可比数据。
3. **形成原因说明简略**：项目形成原因说明不充分。
