# L6-3 专项应付款调整分录复核提示词

## 适用底稿
专项应付款调整分录汇总表（L6-3），含账项调整（AJE）、重分类调整（RJE）及未调整错报（SUD）评估。

## 概述
L6-3 是专项应付款审定数链路的关键环节。复核须验证：每笔调整有证据、借贷平衡、完整反映到 L6-1 审定表、结转方向调整正确、SUD 评估符合重要性水平要求。

---

## tips

1. **AJE vs RJE**：AJE 影响专项应付款金额或权益/损益（结转调整）；RJE 仅影响列报，不得通过调整掩盖性质误判。
2. **结转方向调整**：完工项目结转方向调整（资本公积/递延收益/营业外收入）须有政府批复依据，调整须同步权益或损益。
3. **性质重分类**：将误计入专项应付款的政府补助重分类至递延收益/营业外收入的调整，须核对性质认定依据。
4. **与 L6-1 勾稽**：审定表调整列金额须与 L6-3 已确认分录逐笔一致。
5. **审批链**：超过明细层次重要性水平的调整须合伙人/项目经理审批留痕。
6. **TB 回写**：确认调整已同步试算平衡表2601科目及相关权益/损益科目。

## checklist

### 高风险检查项

- [ ] 所有 AJE 是否有充分审计证据（拨款文件、批复、完工报告）
- [ ] AJE 是否经适当层级审批
- [ ] 每笔调整分录借贷方是否完全平衡
- [ ] 调整金额是否完整反映到 L6-1 审定表对应调整列
- [ ] 结转方向调整（资本公积/损益）是否有批复依据并同步对应科目
- [ ] 政府补助性质重分类调整是否有认定依据
- [ ] 未调整错报累计是否超过整体重要性水平

### 中风险检查项

- [ ] RJE 是否仅涉及列报，未影响专项应付款性质认定
- [ ] 调整原因说明是否清晰可追溯
- [ ] 与 A13 未调整错报汇总表索引是否完整
- [ ] 建议调整与已执行调整是否区分记录

### 低风险检查项

- [ ] 分录摘要、科目编码规范
- [ ] 索引指向 L6-2 明细、L6-4 检查表等支持底稿
- [ ] 审计说明/结论是否概括调整性质与残余风险

## risk_areas

### 高风险

- 调整缺乏证据或未经授权
- 结转方向调整错误（权益/损益错配）
- 政府补助性质重分类缺依据
- 审定表与 L6-3 调整金额不一致

### 中风险

- RJE 误改性质认定
- 跨期结转调整分类错误

### 低风险

- 编号、格式不规范

## 跨底稿勾稽

- L6-3 已确认 AJE/RJE 合计 ↔ L6-1 审定表调整列
- L6-3 SUD ↔ A13 未调整错报汇总
- 调整后审定数 ↔ 试算平衡表 2601 科目及相关权益/损益科目
