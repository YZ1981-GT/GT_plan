# L6-note-soe 附注披露复核提示词（国有企业）

## 概述

本提示词针对专项应付款国有企业附注披露底稿（L6-note-soe）的复核，聚焦国有企业特定的附注披露要求：在按专项项目分类、增减变动、资本性拨款性质、完工结转等基础披露之上，额外增加国资监管相关信息——财政专项资金的拨付与使用、专项资金的专款专用监督、结转对国有资本的影响以及与决算报表的一致性。国有企业专项应付款多来源于财政拨款，审计须同时满足会计准则和财政/国资监管要求。

**法规依据：**
- 《企业会计准则第16号——政府补助》
- 《企业会计准则第37号——金融工具列报》
- 《企业国有资产法》
- 《中央企业财务决算报告管理办法》
- 《财政专项资金管理相关规定》

## tips

1. **国有企业附注有"双层"披露要求**：既满足CAS的基础披露（分类/变动/性质/结转），又满足财政专项资金及国资委决算报告的额外披露要求。
2. **财政专项资金专款专用监督**：国企专项应付款多为财政拨入的专项资金，附注须说明专款专用情况及财政监督要求的执行。
3. **结转对国有资本的影响**：专项应付款完工结转资本公积将增加国有资本，附注宜说明结转对国有资本保值增值的影响。
4. **拨款批文与预算对应**：财政专项拨款须有批文及预算安排，附注宜说明拨款依据及预算执行情况。
5. **未使用资金的处置**：长期未使用的专项资金是否需返还财政，附注须说明处置安排。
6. **与决算报表一致**：附注专项应付款数据须与年度财务决算报表一致，财政专项资金收支须与决算勾稽。

## checklist

### 一、基础披露完整性（与上市版共有）

- [ ] 专项应付款是否按专项项目分类披露
- [ ] 是否列示期初、本期增加、本期结转/退回、期末余额
- [ ] 是否说明资本性拨款性质
- [ ] 附注期末余额合计是否与审定表审定数一致
- [ ] 期初数/期末数可比信息是否完整

### 二、财政专项资金监管披露

- [ ] 财政专项资金的拨付依据（批文/预算）是否披露
- [ ] 专款专用情况及财政监督执行是否说明
- [ ] 专项资金使用是否符合财政限定用途
- [ ] 长期未使用专项资金的处置安排（是否返还财政）是否披露

### 三、结转与国有资本

- [ ] 本期完工结转的专项项目结转金额及方向是否披露
- [ ] 结转资本公积对国有资本的影响是否说明
- [ ] 结转是否有政府/财政批复依据

### 四、国资委补充披露

- [ ] 重大专项资金是否纳入清理/使用管理方案
- [ ] 专项资金相关的诉讼/审计整改事项是否披露
- [ ] 是否披露专项资金收支与预算的对比

### 五、与上市版的差异关注点

- [ ] 国企版是否在基础披露上增加财政专项资金监管信息
- [ ] 是否增加专款专用及财政监督说明
- [ ] 是否增加未使用资金处置安排
- [ ] 是否增加结转对国有资本影响分析

### 六、决算报表特殊要求

- [ ] 专项应付款数据是否与年度财务决算报表一致
- [ ] 财政专项资金收支是否与决算勾稽
- [ ] 集团合并层面内部专项款抵销是否完整

## risk_areas

### 高风险

1. **专款挪用未披露**：财政专项资金被挪用未披露，违反专款专用要求，涉及财政合规风险。
2. **结转方向披露错误**：完工结转方向披露与会计处理不一致，影响国有资本核算。
3. **未使用资金处置不明**：长期未使用专项资金是否返还财政未说明，掩盖资金滞留。
4. **基础披露与审定表不勾稽**：附注专项应付款期末余额与审定数不一致。

### 中风险

1. **财政监督执行未说明**：专款专用及财政监督要求的执行情况未披露。
2. **预算对比缺失**：专项资金收支与预算对比未披露。
3. **决算与审计口径差异未调节**：财务决算数据与审计后附注数据差异未说明。

### 低风险

1. **披露格式未按决算模板**：附注格式与国资委/财政决算模板有细微差异。
2. **拨款批文信息简略**：拨款依据披露不够详细。
3. **专款专用说明简略**：专款专用情况说明不充分。
