# L7-3 其他非流动负债调整分录复核提示词

## 适用底稿
其他非流动负债调整分录汇总表（L7-3），含账项调整（AJE）、重分类调整（RJE，尤指一年内到期及科目性质重分类）及未调整错报（SUD）评估。

## 概述
L7-3 是其他非流动负债审定数链路的关键环节。复核须验证：每笔调整有证据、借贷平衡、完整反映到 L7-1 审定表、一年内到期及性质重分类正确、SUD 评估符合重要性水平要求。

---

## tips

1. **AJE vs RJE**：AJE 影响其他非流动负债金额；RJE 仅影响列报（一年内到期重分类、科目性质重分类），不得通过 RJE 掩盖负债计量错报。
2. **一年内到期重分类**：将于一年内到期的其他非流动负债从非流动重分类至流动负债。
3. **性质重分类**：将误计入其他非流动负债的项目重分类至更特定科目（长期借款/长期应付款/递延收益等），须核对性质认定依据。
4. **与 L7-1 勾稽**：审定表调整列金额须与 L7-3 已确认分录逐笔一致。
5. **审批链**：超过明细层次重要性水平的调整须合伙人/项目经理审批留痕。
6. **TB 回写**：确认调整已同步试算平衡表2801科目及重分类目标科目。

## checklist

### 高风险检查项

- [ ] 所有 AJE 是否有充分审计证据（合同、凭证、管理层确认）
- [ ] AJE 是否经适当层级审批
- [ ] 每笔调整分录借贷方是否完全平衡
- [ ] 调整金额是否完整反映到 L7-1 审定表对应调整列
- [ ] 一年内到期重分类（RJE）是否正确重分类至流动负债
- [ ] 科目性质重分类是否有性质认定依据
- [ ] 未调整错报累计是否超过整体重要性水平

### 中风险检查项

- [ ] RJE 是否仅涉及列报，未影响负债计量
- [ ] 调整原因说明是否清晰可追溯
- [ ] 与 A13 未调整错报汇总表索引是否完整
- [ ] 建议调整与已执行调整是否区分记录

### 低风险检查项

- [ ] 分录摘要、科目编码规范
- [ ] 索引指向 L7-2 明细、L7-4 检查表等支持底稿
- [ ] 审计说明/结论是否概括调整性质与残余风险

## risk_areas

### 高风险

- 调整缺乏证据或未经授权
- 一年内到期重分类遗漏或方向错误
- 科目性质重分类缺依据（兜底滥用未纠正）
- 审定表与 L7-3 调整金额不一致

### 中风险

- RJE 误含计量影响
- 跨期调整分类错误

### 低风险

- 编号、格式不规范

## 跨底稿勾稽

- L7-3 已确认 AJE/RJE 合计 ↔ L7-1 审定表调整列
- L7-3 一年内到期 RJE ↔ L7-1 披露审定数
- L7-3 SUD ↔ A13 未调整错报汇总
- 调整后审定数 ↔ 试算平衡表 2801 科目及重分类目标科目
