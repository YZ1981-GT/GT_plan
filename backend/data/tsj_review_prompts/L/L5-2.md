# L5-2 长期应付款明细表复核提示词

## 概述

本提示词针对长期应付款明细表（L5-2）的复核，聚焦按款项（应付融资租赁款、分期付款购入固定资产、其他长期应付款）逐笔列示的完整性、期初期末增减变动准确性、款项性质分类以及与审定表的勾稽。明细表是审定表金额的支撑底稿，须逐笔反映债权人、款项性质、原值、未确认融资费用及净额，任何遗漏或分类错误将传导至审定表和附注。

**法规依据：**
- 《企业会计准则第21号——租赁》
- 《企业会计准则第22号——金融工具确认和计量》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **逐笔列示须完整**：每笔长期应付款须列明债权人（出租方/供应商）、款项性质、起止日期、原值、未确认融资费用、净额，缺项将影响存在性与完整性认定。
2. **增减变动可追溯**：本期新增（融资租入资产/分期购入固定资产）与本期减少（支付本金）须与合同、付款凭证、L5-4调整分录逐笔勾稽。
3. **款项性质决定后续计量**：应付融资租赁款按CAS21处理，分期付款购入固定资产按购买价款现值入账、差额作未确认融资费用，性质误判导致计量方法错误。
4. **明细合计勾稽审定表**：明细表原值合计、未确认融资费用合计、净额合计须分别等于审定表L5-1对应审定数。
5. **关联方款项标识**：明细表中涉及关联方的长期应付款须标识关联方名称及关系，供L5-6关联方检查表和附注单独列示。
6. **一年内到期标注**：明细表应标注每笔款项一年内到期的净额，供审定表重分类和附注账龄披露使用。

## checklist

### 一、逐笔列示完整性

- [ ] 每笔长期应付款是否列明债权人名称及关系
- [ ] 款项性质（融资租赁/分期购入固定资产/其他）是否明确
- [ ] 是否列明合同起止日期、原值、未确认融资费用、净额
- [ ] 是否标注一年内到期净额及付款计划
- [ ] 是否存在应列示而遗漏的长期应付款款项

### 二、增减变动准确性

- [ ] 本期新增款项是否与融资租赁合同/购货合同勾稽
- [ ] 本期减少（支付本金）是否与付款凭证及L5-4调整勾稽
- [ ] 期末净额是否等于期初净额加本期新增减本期支付本金
- [ ] 各笔款项增减变动是否有充分原始凭证支持

### 三、款项性质与计量

- [ ] 应付融资租赁款是否按CAS21确认（租赁负债现值）
- [ ] 分期付款购入固定资产是否按购买价款现值入账，差额作未确认融资费用
- [ ] 款项性质分类是否与合同实质一致
- [ ] 未确认融资费用是否按实际利率法在租赁期/分期期内摊销

### 四、勾稽与关联方

- [ ] 明细表原值/未确认融资费用/净额合计是否与审定表L5-1勾稽
- [ ] 关联方长期应付款是否已标识并与L5-6勾稽
- [ ] 明细表账龄/到期分布是否与附注披露一致

## risk_areas

### 高风险

1. **款项性质误判**：将应付融资租赁款错分为一般应付款或反之，导致CAS21计量方法适用错误。
2. **完整性缺口**：存在的长期应付款未在明细表列示，低估负债，可能为表外融资隐匿。
3. **增减变动无凭证**：本期新增或减少缺乏合同、付款凭证支持，金额真实性存疑。

### 中风险

1. **明细与审定表不勾稽**：明细合计与审定表审定数不一致。
2. **未确认融资费用未按实际利率法**：分摊方法错误导致各期净额偏离真实摊余成本。
3. **关联方款项未标识**：涉及关联方的款项未标识，影响附注单独列示。

### 低风险

1. **列示要素不全**：债权人、日期等要素缺项但不影响金额。
2. **一年内到期标注缺失**：未标注到期分布，增加审定表重分类工作量。
3. **索引引用不完整**：未与合同、付款凭证建立索引。
