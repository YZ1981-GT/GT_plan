# L3-note-soe 长期借款附注披露复核提示词（国有企业）

## 概述

本提示词针对长期借款国有企业附注披露底稿（L3-note-soe，科目2501）的复核，聚焦国有企业特定的披露要求：基础分类披露（信用/抵押/质押/保证）、一年内到期披露、逾期借款披露、国资监管相关的债务规模与资产负债率披露、关联方（含同受国有控制单位）借款披露，以及决算报表口径一致性。

**法规依据：**
- 《企业会计准则第37号——金融工具列报》
- 《企业会计准则第22号——金融工具确认和计量》
- 《企业会计准则第17号——借款费用》
- 《中央企业财务决算报告管理办法》

---

## tips

1. **国企附注有"双层"披露要求**：既满足CAS37通用披露，又满足国资委决算报告对债务规模、资产负债率、偿债结构的额外要求。
2. **长期借款须按担保方式分类披露**：附注按信用/抵押/质押/保证借款分类列示（国企版通常列"期初余额"而非"上年年末余额"）。
3. **一年内到期部分须清晰披露并重分类**：附注披露一年内到期金额，与一年内到期的非流动负债勾稽。
4. **逾期借款须结合国资监管披露**：逾期借款须披露金额、原因和展期情况，大额逾期涉及债务风险管控和问责。
5. **债务规模与资产负债率服务国资考核**：长期借款规模、资产负债率是国企考核指标，须与决算口径一致。
6. **关联方借款范围更广**：除一般关联方外，须考虑同一国有控股股东控制的其他国有企业间的长期资金拆借。

## checklist

### 一、基础披露完整性（与上市版共有）

- [ ] 长期借款是否按信用/抵押/质押/保证借款分类披露
- [ ] 各类别期末余额合计是否与审定表审定数勾稽
- [ ] 一年内到期金额是否披露并与非流动负债勾稽
- [ ] 逾期借款是否单独披露金额和原因
- [ ] 期初/期末可比信息是否完整

### 二、国资监管相关披露

- [ ] 长期借款规模及资产负债率是否与决算口径一致
- [ ] 分年度到期结构是否披露以评估偿债压力
- [ ] 大额逾期借款是否披露风险管控措施
- [ ] 抵质押受限资产是否披露账面价值和处置权限
- [ ] 本期资本化借款费用是否披露

### 三、关联方借款披露（国企特定）

- [ ] 与控股股东及关联企业的长期借款是否披露
- [ ] 与同一母公司控制的其他国有企业的资金拆借是否披露
- [ ] 关联方借款利率公允性是否说明
- [ ] 是否运用"同受国家控制"关联方豁免条款且符合条件

### 四、决算报表一致性

- [ ] 长期借款数据是否与年度财务决算报表一致
- [ ] 债务规模是否纳入经营业绩考核相关披露
- [ ] 集团合并层面内部借款抵销是否完整

## risk_areas

### 高风险

1. **一年内到期披露/重分类错误**：一年内到期金额未披露或未重分类，误导偿债结构。
2. **附注与审定表/决算不勾稽**：附注长期借款总额与审定表或决算报表不一致。
3. **逾期借款风险未披露**：大额逾期未披露风险管控，涉及债务风险问责。
4. **关联方拆借范围遗漏**：同受国有控制单位间的长期资金拆借未纳入披露。

### 中风险

1. **资产负债率口径不一致**：附注债务规模与决算考核口径存在差异。
2. **到期结构披露缺失**：未披露分年度到期金额。
3. **受限资产披露不足**：抵质押资产未披露处置权限。
4. **资本化借款费用未披露**：本期资本化金额未披露。

### 低风险

1. **披露格式未按决算模板**：附注格式与国资委决算模板有细微差异。
2. **关联方豁免适用不当**：不符合条件却简化同受国有控制关联方披露。
3. **历史趋势分析不完整**：债务规模趋势分析未覆盖建议年限。
