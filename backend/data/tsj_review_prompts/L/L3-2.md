# L3-2 长期借款明细表复核提示词

## 概述

本提示词针对长期借款明细表（L3-2，科目2501）的复核，聚焦逐笔长期借款明细的完整性、借款要素（贷款人/金额/利率/借款期限/到期日/担保方式）准确性、到期分类（一年内/一年以上）、期初借入归还期末勾稽，以及明细与审定表的勾稽。明细表是识别一年内到期部分和表外借款的基础。

**法规依据：**
- 《企业会计准则第17号——借款费用》
- 《企业会计准则第22号——金融工具确认和计量》
- 《企业会计准则第37号——金融工具列报》

---

## tips

1. **到期日是长期借款明细表的关键列**：每笔借款须列示到期日，据此判断一年内到期部分，直接决定重分类金额。
2. **逐笔明细完整性防表外负债**：每笔借款列示贷款人、金额、利率、期限、到期日、担保方式，与征信和函证逐笔核对。
3. **期末余额勾稽公式必须成立**：每笔借款期末=期初+本期借入-本期归还。
4. **到期分类须准确**：明细表须区分一年内到期和一年以上的金额，据此支持审定表重分类。
5. **利率与期限须与合同一致**：明细表利率、借款期限须与L3-6贷款合同一致。
6. **担保方式须与抵质押检查勾稽**：抵押/质押借款担保方式须与L3-8对应。

## checklist

### 一、明细完整性与存在性

- [ ] 每笔借款是否列示贷款人、金额、利率、借款期限、到期日、担保方式
- [ ] 明细表借款是否与银行函证回函逐笔一致
- [ ] 明细表借款是否与征信报告完整对应
- [ ] 是否存在征信有记录但明细未列示的借款

### 二、到期分类与勾稽

- [ ] 每笔借款到期日是否准确记录
- [ ] 一年内到期和一年以上金额是否正确区分
- [ ] 一年内到期合计是否支持审定表L3-1重分类
- [ ] 每笔借款期末是否=期初+本期借入-本期归还
- [ ] 明细合计是否与审定表L3-1对应种类未审数一致

### 三、借款要素准确性

- [ ] 利率是否与L3-6贷款合同一致
- [ ] 借款期限、还款计划是否与合同一致
- [ ] 担保方式是否与L3-8抵质押检查勾稽
- [ ] 关联方借款是否单独标识
- [ ] 外币借款是否按期末汇率折算并标识币种

### 四、列设置与披露

- [ ] 明细表列是否覆盖披露所需要素（种类/担保/到期/逾期）
- [ ] 逾期借款是否标识并与L3-7勾稽
- [ ] 明细数据是否与附注披露一致

## risk_areas

### 高风险

1. **借款漏记**：明细表遗漏征信/函证中的长期借款，负债低估。
2. **到期日错误导致重分类错误**：到期日记录错误使一年内到期金额失真。
3. **期末余额勾稽不成立**：借款行余额无法用借入归还解释。
4. **关联方借款隐匿**：关联方长期借款未单独标识。

### 中风险

1. **利率与合同不一致**：明细表利率与贷款合同不符。
2. **担保方式与担保资产不对应**：抵质押借款担保方式与L3-8不勾稽。
3. **明细与审定表不勾稽**：明细合计与审定表种类合计不一致。
4. **外币折算错误**：外币借款期末未按即期汇率折算。

### 低风险

1. **借款要素记录不完整**：个别借款缺利率或还款计划记录。
2. **列设置不规范**：明细表列缺失导致披露信息不全。
3. **索引不完整**：明细表未与合同检查、征信底稿建立索引。
