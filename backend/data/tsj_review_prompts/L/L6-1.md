# L6-1 专项应付款审定表复核提示词

## 概述

本提示词针对专项应付款审定表（L6-1）的复核，聚焦双期结构勾稽、按专项项目分类、资本性拨款性质认定、完工后结转方向（资本公积/递延收益/营业外收入）以及与政府补助的界分。专项应付款（2601）核算企业取得的具有专门用途的政府资本性拨款，审定表须按专项项目清晰列示期初、本期增加、本期结转与期末余额，性质误判或结转方向错误将导致权益或损益列报重大错误。

**法规依据：**
- 《企业会计准则第16号——政府补助》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **资本性拨款是专项应付款的核心特征**：专项应付款核算的是国家拨入的具有专门用途的资本性拨款（如资本性政府投资），须与计入递延收益/营业外收入的一般政府补助严格区分。
2. **双期结构承前启后**：期初审定数须等于上年期末审定数，期末审定数=期初+本期拨入-本期结转/退回，任何期初差异须追溯说明。
3. **完工结转方向决定权益/损益**：项目完工后，形成长期资产的部分结转资本公积，未形成资产需返还的按规定处理，属于对企业补助的部分转入递延收益或营业外收入，结转方向须有批复依据。
4. **专款专用是合规底线**：专项应付款须专款专用，审定表应反映各专项项目的拨入与使用/结转情况，挪用或串用为高风险。
5. **与政府补助勾稽**：专项应付款与政府补助（递延收益）的界分须清晰，防止将应计入损益的补助长期挂账专项应付款规避损益确认。
6. **审定表勾稽中心**：审定数应与L6-2明细表按专项项目合计、试算平衡表2601科目及附注披露形成闭环。

---

## checklist

### 一、双期勾稽与承前启后

- [ ] 期初未审数是否等于上年审定表期末审定数
- [ ] 期末审定数是否等于期初加本期拨入减本期结转/退回
- [ ] 期初差异是否已充分说明
- [ ] 各专项项目期初期末变动是否与L6-2明细表一致

### 二、性质认定与分类

- [ ] 专项应付款是否为具有专门用途的资本性拨款
- [ ] 是否按专项项目分类列示
- [ ] 是否与应计入递延收益/营业外收入的政府补助正确区分
- [ ] 各专项项目是否列明拨款来源、批文号、用途

### 三、完工结转方向

- [ ] 项目完工后结转方向是否正确（资本公积/递延收益/营业外收入）
- [ ] 结转是否有政府批复或拨款文件依据
- [ ] 形成长期资产部分是否结转资本公积
- [ ] 未形成资产需返还部分是否作应付款处理

### 四、勾稽与列报

- [ ] 审定数是否与试算平衡表2601科目一致
- [ ] 审定数是否与L6-2明细表专项项目合计勾稽
- [ ] 是否与政府补助（递延收益）附注勾稽界分
- [ ] 审定表分类是否与附注披露口径一致

## risk_areas

### 高风险

1. **性质误判**：将应计入损益的政府补助长期挂账专项应付款，规避损益确认，虚增负债、低估利润。
2. **结转方向错误**：完工结转方向错误（应转资本公积却转损益或反之），扭曲权益与损益。
3. **期初期末不勾稽**：期初审定数与上年期末不一致，审定基准失真。
4. **专款挪用未识别**：专项拨款被挪作他用未被识别，合规性重大缺陷。

### 中风险

1. **明细与汇总不勾稽**：审定表与L6-2明细表专项项目合计不一致。
2. **结转缺依据**：完工结转缺乏政府批复文件支持。
3. **与政府补助界分不清**：专项应付款与递延收益界分模糊。

### 低风险

1. **审定表格式不规范**：专项项目列示不清晰。
2. **批文信息缺失**：未列明拨款批文号、用途。
3. **交叉索引不完整**：未与L6-2及试算平衡表建立索引。
