# L8-3 财务费用调整分录复核提示词

## 适用底稿
财务费用调整分录汇总表（L8-3），含账项调整（AJE）、重分类调整（RJE）及未调整错报（SUD）评估。

## 概述
L8-3 是财务费用审定数链路的关键环节。复核须验证：每笔调整有证据、借贷平衡、完整反映到 L8-1 审定表、利息资本化调整正确、跨期利息调整恰当、SUD 评估符合重要性水平要求。

---

## tips

1. **AJE vs RJE**：AJE 影响财务费用金额（进损益）；RJE 仅影响列报，不得通过 RJE 掩盖损益错报。
2. **利息资本化调整**：将误计入财务费用的应资本化利息调整至资产成本（CAS17），须核对资本化条件及资本化率。
3. **跨期利息调整**：补提/冲回跨期利息须区分本期费用与前期差错，与L8-5截止性测试勾稽。
4. **利息与借款联动**：涉及利息的调整须同步借款循环（L1/L3/L4）应付利息，避免损益与负债单边调整。
5. **与 L8-1 勾稽**：审定表调整列金额须与 L8-3 已确认分录逐笔一致。
6. **审批链与TB回写**：超重要性水平调整须合伙人审批留痕，确认调整已同步试算平衡表6603科目及相关科目。

## checklist

### 高风险检查项

- [ ] 所有 AJE 是否有充分审计证据（利息计算、合同、截止测试结果）
- [ ] AJE 是否经适当层级审批
- [ ] 每笔调整分录借贷方是否完全平衡
- [ ] 调整金额是否完整反映到 L8-1 审定表对应调整列
- [ ] 利息资本化调整是否核对资本化条件及资本化率，并同步资产成本
- [ ] 跨期利息调整是否正确区分本期/前期差错
- [ ] 涉及利息的调整是否同步借款循环应付利息（损益与负债联动）
- [ ] 未调整错报累计是否超过整体重要性水平

### 中风险检查项

- [ ] RJE 是否仅涉及列报，未影响财务费用金额
- [ ] 调整原因说明是否清晰可追溯
- [ ] 与 A13 未调整错报汇总表索引是否完整
- [ ] 汇兑损益调整是否有汇率及外币敞口支持
- [ ] 建议调整与已执行调整是否区分记录

### 低风险检查项

- [ ] 分录摘要、科目编码规范
- [ ] 索引指向 L8-2 明细、L8-4 测算、L8-5 截止测试等支持底稿
- [ ] 审计说明/结论是否概括调整性质与残余风险

## risk_areas

### 高风险

- 调整缺乏证据或未经授权
- 利息资本化调整错误（费用/资产错配）
- 跨期利息调整分类错误
- 损益与负债单边调整（利息计提）

### 中风险

- RJE 误含损益影响
- 汇兑损益调整无依据

### 低风险

- 编号、格式不规范

## 跨底稿勾稽

- L8-3 已确认 AJE/RJE 合计 ↔ L8-1 审定表调整列
- L8-3 利息调整 ↔ L1/L3/L4 借款循环应付利息
- L8-3 SUD ↔ A13 未调整错报汇总
- 调整后审定数 ↔ 试算平衡表 6603 科目及相关资产/负债科目
