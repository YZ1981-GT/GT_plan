# L7-2 其他非流动负债明细表复核提示词

## 概述

本提示词针对其他非流动负债明细表（L7-2）的复核，聚焦按项目逐项列示的完整性、项目性质与长期性、本期增减变动准确性以及与审定表的勾稽。明细表是审定表金额的支撑，须逐项反映负债项目名称、性质、对手方、金额、清偿期及一年内到期部分，任何遗漏、性质误判或长期性错误将传导至审定表和附注。

**法规依据：**
- 《企业会计准则第22号——金融工具确认和计量》
- 《企业会计准则第37号——金融工具列报》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **逐项列示须完整**：每项其他非流动负债须列明项目名称、性质、对手方、金额、清偿期，缺项将影响存在性与完整性认定。
2. **性质核查防兜底滥用**：逐项核查是否应归入更特定科目，防止其他非流动负债成为掩盖负债性质的兜底科目。
3. **长期性逐项验证**：每项负债的清偿期须逐项验证是否在一年以上，标注一年内到期金额。
4. **增减变动可追溯**：本期增加与减少须与合同、凭证及L7-3调整分录勾稽。
5. **明细合计勾稽审定表**：明细表各项目期末金额合计须等于审定表L7-1审定数。
6. **关联方标识**：涉及关联方的其他非流动负债须标识，供附注单独列示。

## checklist

### 一、逐项列示完整性

- [ ] 每项负债是否列明名称、性质、对手方、金额、清偿期
- [ ] 是否标注一年内到期金额
- [ ] 是否存在应列示而遗漏的其他非流动负债
- [ ] 关联方负债是否已标识

### 二、性质与长期性

- [ ] 各项目是否应归入更特定科目（未被兜底滥用）
- [ ] 各项目清偿期是否逐项验证在一年以上
- [ ] 项目性质分类是否与合同实质一致
- [ ] 递延收益等特殊项目确认是否合理

### 三、增减变动准确性

- [ ] 本期增加是否与合同/凭证勾稽
- [ ] 本期减少是否与付款凭证及L7-3调整勾稽
- [ ] 期末金额是否等于期初加本期增加减本期减少
- [ ] 增减变动是否有充分原始凭证支持

### 四、勾稽

- [ ] 明细表期末金额合计是否与审定表L7-1勾稽
- [ ] 一年内到期标注是否与审定表重分类一致
- [ ] 明细表是否与附注披露一致

## risk_areas

### 高风险

1. **兜底滥用**：应归入特定科目的负债计入其他非流动负债明细，掩盖负债性质。
2. **完整性缺口**：存在的其他非流动负债未列示，低估负债。
3. **长期性误判**：一年内到期负债未标注，影响审定表重分类。

### 中风险

1. **明细与审定表不勾稽**：明细合计与审定数不一致。
2. **性质分类不清**：项目性质未明确，无法评估归类合理性。
3. **关联方未标识**：涉及关联方的负债未标识。

### 低风险

1. **列示要素不全**：对手方、清偿期等缺项。
2. **增减变动说明不足**：变动未附说明。
3. **索引引用不完整**：未与合同/凭证建立索引。
