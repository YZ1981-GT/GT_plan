# L2-1 应付利息审定表复核提示词

## 概述

本提示词针对应付利息审定表（L2-1，科目2231）的复核，聚焦利息计提的准确性与完整性、与借款本金的勾稽、利息分类（短期借款利息/长期借款利息/债券利息）的准确性、欠付利息的识别，以及期初期末勾稽和试算平衡表核对。应付利息审定表是验证利息费用完整性和负债分离的枢纽。

**法规依据：**
- 《企业会计准则第22号——金融工具确认和计量》
- 《企业会计准则第37号——金融工具列报》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **利息计提准确性是应付利息的核心**：审定表应计利息须以借款本金×利率×计息期间独立测算验证，与L1/L3利息测算及债券利息勾稽，防止漏提或多提。
2. **与借款本金勾稽是防漏提的关键**：每笔应付利息须能追溯至对应的短期借款（2001）、长期借款（2501）或应付债券（2502）本金，无对应本金的应付利息须调查。
3. **利息分类须准确**：应付利息须按短期借款利息、长期借款利息、企业债券利息等分类，分类错误影响费用归属和资本化判断。
4. **欠付利息须识别并披露**：到期应付而未支付的欠付利息须单独识别，反映偿债压力，可能是持续经营信号。
5. **期初期末勾稽必须成立**：期末应付利息=期初+本期计提-本期支付，与财务费用（6603）和利息现金流勾稽。
6. **审定数须与试算平衡表2231科目一致**：审定表应付利息审定数合计须与试算平衡表应付利息科目完全勾稽。

## checklist

### 一、利息计提准确性

- [ ] 应计利息是否以本金×利率×计息期间独立测算验证
- [ ] 测算利息与账面已提利息差异是否追查
- [ ] 是否与L1-5短期借款利息测算勾稽
- [ ] 是否与L3-5长期借款利息测算勾稽
- [ ] 债券利息是否与L4应付债券应计利息勾稽

### 二、与借款本金勾稽

- [ ] 每笔应付利息是否能追溯至对应借款本金
- [ ] 是否存在无对应本金的应付利息
- [ ] 应付利息是否已从借款本金中正确分离

### 三、分类与欠付利息

- [ ] 应付利息是否按短期/长期借款利息、债券利息分类
- [ ] 到期未付的欠付利息是否单独识别
- [ ] 欠付利息是否反映偿债压力并评估持续经营影响
- [ ] 符合资本化条件的利息是否已区分

### 四、期初期末勾稽与试算表核对

- [ ] 期末应付利息是否=期初+本期计提-本期支付
- [ ] 审定数合计是否与试算平衡表2231科目一致
- [ ] 本期计提是否与财务费用（6603）勾稽
- [ ] 本期支付利息是否与现金流量表勾稽
- [ ] 审计调整（AJE/RJE）是否完整反映

## risk_areas

### 高风险

1. **利息漏提**：期末应计未付利息未计提，导致应付利息和财务费用双低估。
2. **无对应本金的应付利息**：应付利息无法追溯至借款本金，存在虚记或错记。
3. **审定数与试算平衡表不一致**：审定表合计与2231科目存在差异。
4. **欠付利息未识别**：到期未付利息未识别，掩盖偿债压力。

### 中风险

1. **利息分类错误**：短期/长期借款利息或债券利息分类错误。
2. **资本化利息未区分**：符合资本化条件的利息未从费用中区分。
3. **期初期末不勾稽**：应付利息余额无法用计提支付解释。
4. **计提利息与财务费用不勾稽**：本期计提与利润表财务费用不一致。

### 低风险

1. **审定表格式不规范**：列标题、行顺序等格式问题。
2. **利息测算过程记录不清**：独立测算过程未清晰列示。
3. **交叉索引不完整**：未与借款利息测算、财务费用底稿建立索引。
