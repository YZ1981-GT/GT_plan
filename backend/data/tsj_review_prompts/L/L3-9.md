# L3-9 长期借款检查表复核提示词

## 概述

本提示词针对长期借款检查表（L3-9，科目2501）的复核，是长期借款审计程序的综合性核对底稿，聚焦完整性测试（函证/征信）、准确性测试（利息计提/资本化/本息分离）、分类列报测试（一年内到期重分类/逾期）、限制性条款合规测试，以及凭证核对充分性。检查表统领长期借款各专项底稿的审计结论。

**法规依据：**
- 《中国注册会计师审计准则第1312号——函证》
- 《企业会计准则第17号——借款费用》
- 《企业会计准则第22号——金融工具确认和计量》
- 《企业会计准则第37号——金融工具列报》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **检查表统领长期借款全部审计程序**：须逐项确认完整性、存在性、准确性、分类列报、合规性各认定的审计程序已执行并得出结论。
2. **完整性是长期借款首要认定**：负债低估风险最高，须确认函证全覆盖、征信核对完整，检查表反映表外借款排查结论。
3. **一年内到期重分类须测试**：检查表须确认一年内到期部分已正确识别并重分类，与L3-1/L3-3勾稽。
4. **限制性条款合规须测试**：财务比率契约合规性须测试，突破须评估重分类和披露，与L3-6勾稽。
5. **借款费用资本化须验证**：资本化判断和计算须验证，与L3-5勾稽。
6. **凭证核对须覆盖借入与归还**：本期借入和归还发生额须抽样核对借款合同、放款凭证、还款凭证，大额借款全覆盖。

## checklist

### 一、完整性测试

- [ ] 银行函证是否全覆盖全部长期借款账户
- [ ] 征信报告/贷款卡核对是否完整（L3-4勾稽）
- [ ] 是否已排查表外长期借款并得出结论
- [ ] 未回函账户是否实施替代程序

### 二、准确性测试

- [ ] 借入/归还发生额是否抽样核对合同和收付款凭证
- [ ] 利息计提准确性是否验证（L3-5勾稽）
- [ ] 借款费用资本化判断和计算是否验证
- [ ] 应计利息本息分离是否恰当
- [ ] 外币借款期末折算是否核对

### 三、分类列报与合规测试

- [ ] 一年内到期部分是否正确识别并重分类（L3-1/L3-3勾稽）
- [ ] 逾期借款是否识别（L3-7勾稽）
- [ ] 限制性条款合规性是否测试（L3-6勾稽）
- [ ] 抵质押担保借款是否正确列示（L3-8勾稽）
- [ ] 关联方借款是否单独列示

### 四、检查比例与异常

- [ ] 本期发生额检查比例是否达到计划水平
- [ ] 大额借款是否全覆盖检查
- [ ] 核对发现的差异是否逐一追查解决
- [ ] 异常借款、逾期借款、契约突破是否记录

## risk_areas

### 高风险

1. **完整性程序不到位**：函证未全覆盖或征信核对不完整，表外借款未排查，负债低估。
2. **一年内到期重分类未测试**：未测试一年内到期识别和重分类，流动性分类错误。
3. **限制性条款合规未测试**：契约合规性未测试，违约触发重分类未识别。
4. **资本化未验证**：借款费用资本化判断和计算未验证。

### 中风险

1. **检查比例不足**：本期发生额检查比例低于计划。
2. **替代程序不充分**：未回函账户替代程序执行不到位。
3. **凭证核对造假未识别**：借款凭证造假未被发现。
4. **异常事项未追查**：核对发现的差异未追踪解决。

### 低风险

1. **检查记录不完整**：审计程序执行记录不规范。
2. **检查表格式不统一**：检查底稿格式不规范。
3. **索引缺失**：检查表与各专项底稿交叉索引不完整。
