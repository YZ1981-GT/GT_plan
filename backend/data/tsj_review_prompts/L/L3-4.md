# L3-4 长期借款征信报告核对复核提示词

## 概述

本提示词针对长期借款征信报告核对表（L3-4，科目2501）的复核，聚焦征信报告/人民银行贷款卡与账面长期借款的完整性核对，识别表外长期负债、对外担保和或有负债。征信核对是识别表外负债最有效的审计程序，对长期借款尤为重要。

**法规依据：**
- 《中国注册会计师审计准则第1312号——函证》
- 《企业会计准则第22号——金融工具确认和计量》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **征信核对是防表外长期负债的最强程序**：企业信用报告记录全部金融机构长期授信，逐笔核对可发现账面未反映的长期借款、担保和承诺。
2. **核对须覆盖全部授信主体与到期结构**：不仅核对余额，还须核对授信额度、贷款期限、还款计划、逾期记录，识别隐性负债和到期结构。
3. **征信报告须为审计期间有效版本**：使用资产负债表日附近的完整版本，过期或不完整版本会遗漏借款。
4. **对外担保须评估或有负债**：征信中的对外担保记录须评估是否需确认预计负债或披露或有负债。
5. **逾期记录须与L3-7勾稽**：征信中的逾期记录须与逾期检查一致，评估违约和交叉违约影响。
6. **差异须逐笔追查解释**：征信与账面差异须逐笔调查并取得管理层解释。

## checklist

### 一、征信核对完整性

- [ ] 征信报告/贷款卡是否为资产负债表日附近的完整有效版本
- [ ] 是否核对全部金融机构的长期授信和借款记录
- [ ] 账面长期借款是否与征信记录逐笔对应
- [ ] 是否存在征信有记录但账面未入账的长期借款
- [ ] 是否存在账面有借款但征信无记录的异常

### 二、隐性负债识别

- [ ] 征信报告中的授信额度和已用额度是否核对
- [ ] 征信报告中的对外担保记录是否评估或有负债
- [ ] 是否识别银团贷款、委托贷款等特殊借款
- [ ] 是否存在非金融机构长期借款未反映在征信中的补充核查

### 三、逾期与到期结构

- [ ] 征信报告中的逾期记录是否与L3-7逾期检查一致
- [ ] 征信的到期结构信息是否用于验证一年内到期分类
- [ ] 不良/关注类贷款分类是否评估持续经营影响

### 四、差异处理

- [ ] 征信与账面差异是否逐笔追查并取得解释
- [ ] 需补记的表外借款是否通过L3-3调整处理
- [ ] 核对结论是否明确并附管理层声明

## risk_areas

### 高风险

1. **表外长期借款未发现**：征信有记录但账面未入账的长期借款未识别，负债严重低估。
2. **对外担保未披露**：征信中的对外担保未评估或有负债或未披露。
3. **征信报告不完整**：使用过期或不完整版本导致遗漏借款。
4. **非金融机构借款遗漏**：委托贷款等不进征信，未实施补充核查。

### 中风险

1. **逾期记录未与L3-7勾稽**：征信逾期记录与逾期检查不一致。
2. **到期结构信息未利用**：未用征信到期信息验证一年内到期分类。
3. **差异未追查解释**：征信与账面差异未逐笔调查。

### 低风险

1. **征信报告版本日期偏离**：使用的征信报告与资产负债表日间隔较长。
2. **核对记录格式不规范**：核对底稿格式不统一。
3. **索引不完整**：核对表未与借款明细、逾期检查建立索引。
