# L4-3 划分为金融负债的其他金融工具复核提示词

## 概述

本提示词针对划分为金融负债的其他金融工具检查表（L4-3，科目2502相关）的复核，聚焦优先股、永续债等特殊金融工具的负债/权益分类判断（CAS37），以及作为金融负债列报的其他工具的确认、计量与列报。分类判断错误将导致负债与权益、财务费用与利润分配的重大错报。

**法规依据：**
- 《企业会计准则第22号——金融工具确认和计量》
- 《企业会计准则第37号——金融工具列报》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **负债/权益分类判断是核心（CAS37）**：优先股、永续债等工具须根据是否存在交付现金的合同义务判断分类为金融负债或权益工具，判断依据须充分。
2. **强制付息/固定到期赎回指向金融负债**：含强制付息条款、固定到期赎回义务、或发行方无权无条件避免交付现金的工具，通常分类为金融负债。
3. **分类为金融负债的工具须按负债计量**：分类为金融负债的优先股/永续债须按摊余成本或公允价值计量，其分派计入财务费用而非利润分配。
4. **利率跳升条款须评估**：永续债的利率跳升/重置条款可能构成间接支付义务，影响分类判断。
5. **列报须与工具分类一致**：分类为金融负债的其他工具须在负债项目列报，其利息计入财务费用。
6. **关注分类变更**：工具条款变化或续期选择权行使可能导致分类变更，须评估会计处理。

## checklist

### 一、分类判断（CAS37）

- [ ] 是否根据是否存在交付现金的合同义务判断负债/权益分类
- [ ] 强制付息条款是否评估
- [ ] 固定到期赎回义务是否评估
- [ ] 发行方是否有权无条件避免交付现金
- [ ] 分类判断依据是否充分并有工具条款支持

### 二、计量准确性

- [ ] 分类为金融负债的工具是否按摊余成本/公允价值计量
- [ ] 工具的分派/利息是否计入财务费用（非利润分配）
- [ ] 利率跳升/重置条款是否评估其对分类和计量的影响

### 三、列报与披露

- [ ] 分类为金融负债的其他工具是否在负债项目列报
- [ ] 工具的主要条款是否在附注披露
- [ ] 分类判断的重大会计判断是否披露

### 四、分类变更

- [ ] 工具条款变化是否评估分类变更
- [ ] 续期选择权行使是否评估会计处理
- [ ] 分类变更的会计处理是否恰当

## risk_areas

### 高风险

1. **负债误分类为权益**：应分类为金融负债的优先股/永续债被分类为权益，负债低估、权益高估，其分派误计利润分配少计费用。
2. **权益误分类为负债**：应分类为权益的工具被分类为负债，反向错报。
3. **利率跳升条款未评估**：永续债利率跳升构成间接支付义务未识别，分类错误。
4. **分派列报位置错误**：分类为金融负债的工具分派误计入利润分配而非财务费用。

### 中风险

1. **计量方法错误**：分类为金融负债的工具计量方法不当。
2. **分类变更未评估**：条款变化或续期选择权行使未评估分类变更。
3. **重大判断未披露**：负债/权益分类的重大会计判断未披露。

### 低风险

1. **工具条款记录不完整**：工具主要条款记录不全。
2. **检查表格式不规范**：检查底稿格式不统一。
3. **索引不完整**：检查表未与审定表、权益划分检查建立索引。
