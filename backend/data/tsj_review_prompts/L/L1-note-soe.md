# L1-note-soe 短期借款附注披露复核提示词（国有企业）

## 概述

本提示词针对短期借款国有企业附注披露底稿（L1-note-soe，科目2001）的复核，聚焦国有企业特定的披露要求：基础分类披露（信用/抵押/质押/保证）、逾期借款披露、国资监管相关的债务规模与偿债能力披露、关联方（含同受国有控制单位）借款披露，以及决算报表口径一致性。国企审计须同时满足会计准则与国资监管要求。

**法规依据：**
- 《企业会计准则第37号——金融工具列报》
- 《企业会计准则第22号——金融工具确认和计量》
- 《中央企业财务决算报告管理办法》
- 《企业国有资产法》

---

## tips

1. **国企附注有"双层"披露要求**：既满足CAS37通用披露，又满足国资委财务决算报告对债务规模、资产负债率的额外要求。
2. **短期借款须按担保方式分类披露**：附注按信用/抵押/质押/保证借款分类列示，各类合计等于审定表审定数。
3. **逾期借款须结合国资监管披露**：逾期借款须披露逾期金额、原因和展期情况，大额逾期可能涉及债务风险管控和责任追究。
4. **关联方借款范围更广**：除一般关联方外，须考虑同一国有控股股东控制的其他国有企业间的资金拆借。
5. **债务规模须服务于国资监管考核**：短期借款规模、资产负债率是国企经营业绩考核指标，须与决算报表口径一致。
6. **受限资产须披露**：抵质押资产作为受限资产披露，涉及国有资产处置权限须说明。

## checklist

### 一、基础披露完整性（与上市版共有）

- [ ] 短期借款是否按信用/抵押/质押/保证借款分类披露
- [ ] 各类别期末余额合计是否等于审定表审定数
- [ ] 逾期借款是否单独披露金额和原因
- [ ] 期初数/期末数可比信息是否完整
- [ ] 附注总额是否与审定表审定数一致

### 二、国资监管相关披露

- [ ] 短期借款规模及资产负债率是否与决算口径一致
- [ ] 大额逾期借款是否披露风险管控措施
- [ ] 抵质押受限资产是否披露账面价值和处置权限
- [ ] 是否披露银行授信额度使用情况

### 三、关联方借款披露（国企特定）

- [ ] 与控股股东及其关联企业的借款是否披露
- [ ] 与同一母公司控制的其他国有企业的资金拆借是否披露
- [ ] 关联方借款利率公允性是否说明
- [ ] 是否运用"同受国家控制"关联方豁免条款且符合条件

### 四、决算报表一致性

- [ ] 短期借款数据是否与年度财务决算报表一致
- [ ] 借款规模是否纳入经营业绩考核相关披露
- [ ] 集团合并层面内部借款抵销是否完整

## risk_areas

### 高风险

1. **附注与审定表/决算不勾稽**：附注短期借款总额与审定表或决算报表不一致。
2. **逾期借款风险未披露**：大额逾期未披露风险管控措施，涉及债务风险管理问责。
3. **关联方拆借范围遗漏**：同受国有控制单位间的资金拆借未纳入关联方披露。
4. **表外借款未反映**：征信/函证发现的表外借款仍未在附注反映。

### 中风险

1. **资产负债率口径不一致**：附注债务规模与决算考核口径存在差异。
2. **受限资产披露不足**：抵质押资产未披露处置权限。
3. **关联方豁免适用不当**：不符合条件却简化同受国有控制关联方披露。

### 低风险

1. **披露格式未按决算模板**：附注格式与国资委决算模板有细微差异。
2. **授信信息说明简略**：银行授信额度使用情况说明不详。
3. **历史趋势分析不完整**：债务规模趋势分析未覆盖建议年限。
