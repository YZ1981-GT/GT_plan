# L1-9 短期借款检查表复核提示词

## 概述

本提示词针对短期借款检查表（L1-9，科目2001）的复核，是短期借款审计程序的综合性核对底稿，聚焦审计程序执行的完整性：完整性测试（银行函证/征信核对）、准确性测试（利息计提/本息分离）、分类列报测试、以及凭证核对的充分性。检查表统领各专项底稿的审计结论。

**法规依据：**
- 《中国注册会计师审计准则第1312号——函证》
- 《企业会计准则第22号——金融工具确认和计量》
- 《企业会计准则第37号——金融工具列报》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **检查表统领短期借款全部审计程序**：须逐项确认完整性、存在性、准确性、分类列报各认定的审计程序均已执行并得出结论。
2. **完整性是短期借款的首要认定**：负债低估风险最高，须确认银行函证全覆盖、征信核对完整，检查表须反映表外借款的排查结论。
3. **凭证核对须覆盖借入与归还**：本期借入（贷方）和归还（借方）发生额须抽样核对借款合同、放款凭证、还款凭证。
4. **准确性测试须验证利息与本金**：利息计提准确、本息分离恰当须在检查表中体现，与L1-5勾稽。
5. **检查比例须达标**：本期发生额检查比例须满足审计计划要求，大额借款应全覆盖。
6. **异常事项须记录并追查**：核对中发现的差异、异常借款、逾期借款须记录并追查解决。

## checklist

### 一、完整性测试

- [ ] 银行函证是否全覆盖全部借款账户
- [ ] 征信报告/贷款卡核对是否完整（L1-4勾稽）
- [ ] 是否已排查表外借款并得出结论
- [ ] 未回函账户是否实施替代程序

### 二、准确性测试

- [ ] 借入/归还发生额是否抽样核对借款合同和收付款凭证
- [ ] 利息计提准确性是否验证（L1-5勾稽）
- [ ] 应计利息本息分离是否恰当
- [ ] 外币借款期末折算是否核对

### 三、分类列报测试

- [ ] 短期借款是否正确分类（1年以内）
- [ ] 逾期借款是否识别（L1-7勾稽）
- [ ] 抵质押担保借款是否正确列示（L1-8勾稽）
- [ ] 关联方借款是否单独列示

### 四、检查比例与异常

- [ ] 本期发生额检查比例是否达到计划水平
- [ ] 大额借款是否全覆盖检查
- [ ] 核对发现的差异是否逐一追查解决
- [ ] 异常借款和逾期借款是否记录

## risk_areas

### 高风险

1. **完整性程序不到位**：函证未全覆盖或征信核对不完整，表外借款未排查，负债低估风险。
2. **检查比例不足**：本期发生额检查比例低于计划，审计证据不充分。
3. **凭证核对造假未识别**：借款凭证造假掩盖资金异常流向未被发现。
4. **利息准确性未验证**：未验证利息计提准确性，费用完整性存疑。

### 中风险

1. **替代程序不充分**：未回函账户的替代程序执行不到位。
2. **分类测试遗漏**：逾期或抵质押借款分类未充分测试。
3. **异常事项未追查**：核对发现的差异未追踪解决。

### 低风险

1. **检查记录不完整**：审计程序执行记录不规范。
2. **检查表格式不统一**：检查底稿格式不规范。
3. **索引缺失**：检查表与各专项底稿交叉索引不完整。
