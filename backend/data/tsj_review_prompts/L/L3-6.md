# L3-6 长期借款贷款合同检查复核提示词

## 概述

本提示词针对长期借款贷款合同检查表（L3-6，科目2501）的复核，聚焦借款合同要素与账面一致性、限制性条款（财务比率契约covenant）的识别与合规评估、还款计划、担保条款，以及合同与征信、明细表的勾稽。长期借款合同的限制性条款突破是重分类和披露的关键触发因素。

**法规依据：**
- 《企业会计准则第17号——借款费用》
- 《企业会计准则第22号——金融工具确认和计量》
- 《企业会计准则第37号——金融工具列报》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **限制性条款（covenant）评估是长期借款合同检查的核心**：合同中的资产负债率、流动比率、利息保障倍数等财务比率契约须逐项测算是否满足，突破可能触发加速到期。
2. **加速到期条款触发须重分类**：违反契约触发债权人有权要求提前偿还时，即使实际未要求，也须评估是否重分类为流动负债（除非取得豁免）。
3. **合同要素须与账面一致**：借款人、金额、利率、期限、还款计划、担保方式须与账面明细逐项核对。
4. **利率与还款计划须与利息测算勾稽**：合同利率、计息方式、还款计划须与L3-5利息测算一致。
5. **担保条款须与抵质押检查勾稽**：合同约定的担保方式和担保物须与L3-8一致。
6. **关注专项借款用途与资本化条件**：专项借款用途须与资本化的符合条件资产匹配，挪用可能影响资本化判断。

## checklist

### 一、合同要素一致性

- [ ] 借款合同的借款人、金额是否与账面明细一致
- [ ] 合同利率是否与L3-5利息测算和明细表一致
- [ ] 合同借款期限、到期日是否与明细表一致
- [ ] 合同还款计划是否与账面归还记录匹配
- [ ] 合同担保方式是否与L3-8抵质押检查一致

### 二、限制性条款（covenant）评估

- [ ] 是否识别合同中的财务比率契约（资产负债率/流动比率/利息保障倍数）
- [ ] 各财务比率契约是否逐项测算是否满足
- [ ] 是否存在契约被突破的情况
- [ ] 契约突破是否触发加速到期条款
- [ ] 契约突破是否取得债权人豁免（书面证据）

### 三、还款计划与用途

- [ ] 还款计划是否用于验证一年内到期分类
- [ ] 专项借款用途是否与资本化的符合条件资产匹配
- [ ] 是否存在专项借款挪用影响资本化判断
- [ ] 提前还款条款和罚息条款是否识别

### 四、跨底稿勾稽

- [ ] 合同检查是否与征信报告L3-4勾稽
- [ ] 合同担保是否与L3-8抵质押资产勾稽
- [ ] 合同要素是否与L3-2明细表一致

## risk_areas

### 高风险

1. **限制性条款违约未识别未重分类**：财务比率契约被突破触发加速到期，未评估重分类为流动负债，虚增流动性。
2. **契约豁免无书面证据**：管理层声称已取得豁免但无债权人书面证据，重分类判断依据不足。
3. **借款合同虚假**：合同缺签章或放款凭证，借款真实性存疑。
4. **专项借款挪用影响资本化**：专项借款挪作他用但仍资本化其利息。

### 中风险

1. **利率条款与测算不一致**：合同利率与L3-5测算不符。
2. **担保条款与抵质押不勾稽**：合同担保与L3-8不对应。
3. **还款计划与到期分类不符**：还款计划未用于验证一年内到期。

### 低风险

1. **合同要素记录不完整**：个别合同缺利率或还款计划记录。
2. **合同检查格式不规范**：检查底稿格式不统一。
3. **索引不完整**：合同检查未与征信、抵质押底稿建立索引。
