# L7-note-soe 附注披露复核提示词（国有企业）

## 概述

本提示词针对其他非流动负债国有企业附注披露底稿（L7-note-soe）的复核，聚焦国有企业特定的附注披露要求：在按项目性质分类、变动、到期期限等基础披露之上，额外增加国资监管相关信息——重大长期负债的形成与决策、与国有关联方的长期往来、长期负债对国有资本的影响以及与决算报表的一致性。国有企业其他非流动负债审计须同时满足会计准则和国资监管要求。

**法规依据：**
- 《企业会计准则第37号——金融工具列报》
- 《企业会计准则第36号——关联方披露》
- 《企业国有资产法》
- 《中央企业财务决算报告管理办法》

---

## tips

1. **国有企业附注有"双层"披露要求**：既满足CAS的基础披露（分类/变动/到期/性质），又满足国资委决算报告的额外披露要求。
2. **重大长期负债决策程序**：重大其他非流动负债的形成可能涉及"三重一大"决策，附注宜说明重大长期负债的决策审批情况。
3. **关联方范围更广**：国企关联方须考虑同一国有控股股东控制的其他国有企业，与国有关联方的长期往来须单独披露。
4. **国有资本影响视角**：其他非流动负债作为长期负债影响国有资本负债率，附注宜说明重大长期负债的影响。
5. **性质核查防规避**：防止将应计入损益或应归特定科目的项目挂账其他非流动负债规避监管，附注须清晰说明性质。
6. **与决算报表一致**：附注其他非流动负债数据须与年度财务决算报表一致，合并层面内部往来抵销须完整。

## checklist

### 一、基础披露完整性（与上市版共有）

- [ ] 其他非流动负债是否按项目性质分类披露
- [ ] 各项目性质及形成原因是否清晰说明
- [ ] 是否披露本期增减变动及到期期限
- [ ] 附注期末余额合计是否与审定表审定数一致
- [ ] 期初数/期末数可比信息是否完整

### 二、国有资产监管相关披露

- [ ] 重大其他非流动负债的形成是否披露决策审批程序（"三重一大"）
- [ ] 重大长期负债对国有资本负债率的影响是否说明
- [ ] 是否披露涉及国有资产处置/划转形成的长期负债
- [ ] 是否存在挂账其他非流动负债规避监管的情况

### 三、关联交易披露（国企特定）

- [ ] 与控股股东及其关联企业的长期往来是否逐户列示
- [ ] 与同一母公司控制的其他国有企业的长期负债是否披露
- [ ] 是否运用"同受国家控制"关联方豁免条款，运用是否符合条件
- [ ] 关联方长期往来的交易实质是否清晰说明

### 四、国资委补充披露

- [ ] 重大长期负债是否纳入清理/负债管理方案
- [ ] 涉及诉讼/仲裁的长期负债是否披露
- [ ] 是否披露相关的担保/抵押安排

### 五、与上市版的差异关注点

- [ ] 国企版是否在基础披露上增加国资监管补充信息
- [ ] 关联方范围是否扩展至"同受国有控制"企业
- [ ] 重大长期负债是否增加决策程序说明
- [ ] 是否增加国有资本负债率影响分析

### 六、决算报表特殊要求

- [ ] 其他非流动负债数据是否与年度财务决算报表一致
- [ ] 集团合并层面内部往来抵销是否完整
- [ ] 抵销后余额是否与决算一致

## risk_areas

### 高风险

1. **国有关联方长期往来未单独披露**：与国有关联方的长期往来未单独列示，关联交易信息不完整。
2. **挂账规避监管**：应归特定科目或计入损益的项目挂账其他非流动负债规避监管，性质披露误导。
3. **基础披露与审定表不勾稽**：附注其他非流动负债期末余额与审定数不一致。

### 中风险

1. **决策程序说明缺失**：重大长期负债形成未披露决策审批程序。
2. **国有资本影响未说明**：重大长期负债对国有资本负债率影响未分析。
3. **决算与审计口径差异未调节**：财务决算数据与审计后附注数据差异未说明。

### 低风险

1. **披露格式未按决算模板**：附注格式与国资委决算模板有细微差异。
2. **性质说明简略**：项目性质及形成原因说明不充分。
3. **可比信息缺失**：仅列示期末数据未列示期初可比数据。
