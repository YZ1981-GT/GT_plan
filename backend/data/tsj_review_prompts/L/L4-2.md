# L4-2 应付债券明细表复核提示词

## 概述

本提示词针对应付债券明细表（L4-2，科目2502）的复核，聚焦逐只债券明细的完整性、债券要素（债券名称/发行日/到期日/面值/票面利率/实际利率/发行价）准确性、摊余成本各子项（面值/利息调整/应计利息）的期初期末勾稽，以及明细与审定表的勾稽。明细表是验证债券摊余成本计量和到期分类的基础。

**法规依据：**
- 《企业会计准则第22号——金融工具确认和计量》
- 《企业会计准则第37号——金融工具列报》

---

## tips

1. **逐只债券要素完整性**：每只债券须列示债券名称、发行日、到期日、面值、票面利率、实际利率、发行价格、期限、付息方式。
2. **摊余成本子项须分解勾稽**：每只债券的面值、利息调整余额、应计利息须分别列示，期末摊余成本=面值±未摊销利息调整+应计利息。
3. **实际利率须与初始计量一致**：明细表记录的实际利率须与L4-6初始计量确定的实际利率一致。
4. **到期日决定重分类**：每只债券到期日决定是否为一年内到期，据此支持审定表重分类。
5. **可转换债券须标识**：可转换债券须单独标识，其负债成分和权益成分分别记录。
6. **明细合计须与审定表勾稽**：明细表按债券品种的合计须等于审定表L4-1对应品种。

---

## checklist

### 一、债券要素完整性

- [ ] 每只债券是否列示名称、发行日、到期日、面值、票面利率、实际利率、发行价
- [ ] 付息方式（分期付息/到期一次还本付息）是否标识
- [ ] 可转换债券是否单独标识
- [ ] 是否存在债券发行但明细表未列示

### 二、摊余成本子项勾稽

- [ ] 每只债券面值是否正确
- [ ] 利息调整（溢折价）期末余额是否随摊销变动
- [ ] 应计利息是否按付息方式准确计算
- [ ] 期末摊余成本是否=面值±未摊销利息调整+应计利息
- [ ] 明细合计是否与审定表L4-1品种勾稽

### 三、计量要素准确性

- [ ] 实际利率是否与L4-6初始计量一致
- [ ] 票面利率是否与债券募集说明书一致
- [ ] 发行价格是否与实际募集资金一致

### 四、到期分类与披露

- [ ] 每只债券到期日是否准确记录
- [ ] 一年内到期债券是否标识并支持审定表重分类
- [ ] 明细数据是否与附注披露一致

## risk_areas

### 高风险

1. **债券要素错误**：实际利率、面值、发行价错误导致摊余成本计量失真。
2. **摊余成本子项勾稽不成立**：面值±利息调整+应计利息≠期末摊余成本。
3. **可转换债券未标识分拆**：可转换债券未标识，负债权益成分未分别记录。
4. **到期日错误导致重分类错误**：到期日记录错误使一年内到期分类失真。

### 中风险

1. **实际利率与初始计量不一致**：明细表实际利率与L4-6不符。
2. **应计利息计算错误**：应计利息按付息方式计算错误。
3. **明细与审定表不勾稽**：明细合计与审定表品种不一致。

### 低风险

1. **债券要素记录不完整**：个别债券缺付息方式或发行价记录。
2. **列设置不规范**：明细表列缺失导致披露信息不全。
3. **索引不完整**：明细表未与初始计量、后续计量底稿建立索引。
