# L5-note-soe 附注披露复核提示词（国有企业）

## 概述

本提示词针对长期应付款国有企业附注披露底稿（L5-note-soe）的复核，聚焦国有企业特定的附注披露要求：在按性质分类、原值与未确认融资费用分列、到期期限分析等基础披露之上，额外增加国资监管相关信息——大额融资租赁的决策程序、与国有关联方的融资安排、长期负债对国有资本的影响以及与决算报表的一致性。国有企业长期应付款审计须同时满足会计准则和国资监管要求。

**法规依据：**
- 《企业会计准则第21号——租赁》
- 《企业会计准则第37号——金融工具列报》
- 《企业会计准则第36号——关联方披露》
- 《企业国有资产法》
- 《中央企业财务决算报告管理办法》

---

## tips

1. **国有企业附注有"双层"披露要求**：既满足CAS的基础披露（分类/原值净额/到期分析），又满足国资委财务决算报告的额外披露要求。
2. **大额融资租赁决策程序**：大额融资租赁/分期购置固定资产可能涉及"三重一大"决策，附注宜说明重大长期应付款的决策审批情况。
3. **关联方范围更广**：国企关联方除一般定义外，须考虑同一国有控股股东控制的其他国有企业，与国有关联方的融资租赁须单独披露。
4. **国有资本影响视角**：长期应付款作为长期负债，其规模和融资成本影响国有资本负债率和保值增值，附注宜说明重大长期负债的影响。
5. **融资成本合规性**：与国有关联方的融资利率须符合公允及合规要求，防止变相利益输送。
6. **与决算报表一致**：附注长期应付款数据须与年度财务决算报表一致，合并层面内部长期应付款抵销须完整。

## checklist

### 一、基础披露完整性（与上市版共有）

- [ ] 长期应付款是否按性质分类披露（融资租赁款/分期购入固定资产/其他）
- [ ] 是否分别列示原值、减未确认融资费用、净额
- [ ] 是否披露到期期限分析
- [ ] 附注净额合计是否与审定表审定数一致
- [ ] 期初数/期末数可比信息是否完整

### 二、国有资产监管相关披露

- [ ] 大额融资租赁/分期购置是否披露决策审批程序（"三重一大"）
- [ ] 重大长期应付款对国有资本负债率的影响是否说明
- [ ] 是否披露涉及国有资产处置/划转形成的长期应付款
- [ ] 长期应付款的融资成本合规性是否说明

### 三、关联交易披露（国企特定）

- [ ] 与控股股东及其关联企业的长期应付款是否逐户列示
- [ ] 与同一母公司控制的其他国有企业的融资租赁是否披露
- [ ] 是否运用"同受国家控制"关联方豁免条款，运用是否符合条件
- [ ] 关联方融资定价方式是否披露（市场价/协议价）
- [ ] 是否存在以长期应付款名义的关联方资金占用

### 四、国资委补充披露

- [ ] 重大长期应付款是否纳入清理处置/负债管理方案
- [ ] 涉及诉讼/仲裁的长期应付款是否披露
- [ ] 是否披露长期应付款相关的担保/抵押安排
- [ ] 融资租赁对应的使用权资产是否披露（CAS21）

### 五、与上市版的差异关注点

- [ ] 国企版是否在基础披露上增加国资监管补充信息
- [ ] 关联方范围是否扩展至"同受国有控制"企业
- [ ] 大额融资是否增加决策程序说明
- [ ] 是否增加国有资本负债率影响分析

### 六、决算报表特殊要求

- [ ] 长期应付款数据是否与年度财务决算报表一致
- [ ] 集团合并层面内部长期应付款抵销是否完整
- [ ] 抵销后余额是否与决算一致

## risk_areas

### 高风险

1. **国有关联方融资未单独披露**：与国有关联方的融资租赁/分期购货未单独列示，关联交易信息不完整，违反CAS36和国资委要求。
2. **大额融资缺决策程序说明**：大额融资租赁未经"三重一大"决策或未披露决策过程，存在合规风险。
3. **变相资金占用**：以长期应付款名义的关联方资金占用未披露，掩盖利益输送。
4. **基础披露与审定表不勾稽**：附注长期应付款净额与审定表审定数不一致。

### 中风险

1. **国有资本影响未说明**：重大长期负债对国有资本负债率影响未分析。
2. **"同受国有控制"豁免适用不当**：不符合条件却简化同受国家控制关联方披露。
3. **决算与审计口径差异未调节**：财务决算数据与审计后附注数据差异未说明。

### 低风险

1. **披露格式未按决算模板**：附注格式与国资委决算模板有细微差异。
2. **融资成本说明简略**：利率合规性已提及但依据不详。
3. **使用权资产关联信息缺失**：融资租赁对应使用权资产未披露。
