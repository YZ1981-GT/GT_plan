# L5-3 未确认融资费用明细表复核提示词

## 概述

本提示词针对未确认融资费用明细表（L5-3）的复核，聚焦未确认融资费用（2702）作为长期应付款备抵科目的期初期末余额、本期摊销额、摊销方法（实际利率法）以及与L5-5测算表、财务费用的勾稽。未确认融资费用代表尚未摊销的融资成本，其余额直接影响长期应付款净额，摊销额直接影响财务费用，是长期应付款计量准确性的关键环节。

**法规依据：**
- 《企业会计准则第21号——租赁》
- 《企业会计准则第17号——借款费用》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **备抵性质决定余额方向**：未确认融资费用为长期应付款的备抵科目（借方余额），期末余额抵减长期应付款原值得出净额，方向不得颠倒。
2. **实际利率法是摊销唯一正确方法**：未确认融资费用须按实际利率法在租赁期/分期期内摊销，直线法摊销不符合CAS21要求。
3. **本期摊销去向**：本期摊销的未确认融资费用应计入财务费用（利息费用），若为购建固定资产期间且符合资本化条件，则计入资产成本（CAS17）。
4. **期末余额勾稽净额**：期末未确认融资费用余额=长期应付款原值-长期应付款净额，须与L5-1审定表和L5-2明细表净额勾稽。
5. **摊销额勾稽测算表**：本期摊销额须与L5-5未确认融资费用测算表逐期摊销计划一致，任何差异须查明。
6. **实际利率一经确定不得随意变更**：除非重估租赁付款额或修改合同，实际利率应保持稳定，利率变更须有合同依据。

## checklist

### 一、余额与备抵勾稽

- [ ] 未确认融资费用期末余额是否为借方（备抵长期应付款）
- [ ] 期末余额是否等于长期应付款原值减净额
- [ ] 是否与L5-1审定表2702科目审定数勾稽
- [ ] 是否与L5-2明细表各笔款项未确认融资费用合计勾稽
- [ ] 期初余额是否等于上年期末余额

### 二、摊销方法与金额

- [ ] 未确认融资费用是否按实际利率法摊销
- [ ] 本期摊销额是否与L5-5测算表逐期计划一致
- [ ] 实际利率的确定是否有合同或现值计算支持
- [ ] 期末余额是否等于期初余额加本期新增减本期摊销

### 三、摊销去向

- [ ] 本期摊销额是否计入财务费用（利息费用）
- [ ] 符合资本化条件的融资费用是否计入资产成本（CAS17）
- [ ] 财务费用中的融资费用是否与L8财务费用底稿勾稽
- [ ] 是否存在费用化与资本化划分错误

## risk_areas

### 高风险

1. **摊销方法错误**：采用直线法而非实际利率法摊销，导致各期财务费用与负债净额失真。
2. **备抵方向颠倒**：未确认融资费用余额方向错误，导致长期应付款净额计算错误。
3. **摊销额与测算不符**：本期摊销额与L5-5测算表不一致，财务费用金额不实。

### 中风险

1. **资本化/费用化划分错误**：应资本化的融资费用费用化或反之。
2. **实际利率随意变更**：无合同依据变更实际利率，操纵各期费用。
3. **余额与净额不勾稽**：期末余额与L5-1/L5-2净额不一致。

### 低风险

1. **摊销计划表格不规范**：逐期摊销明细列示不清晰。
2. **索引引用不完整**：未与L5-5测算表建立索引。
3. **利率确定依据说明不足**：实际利率来源未附计算说明。
