# L2-3 应付利息调整分录复核提示词

## 概述

本提示词针对应付利息调整分录汇总表（L2-3，科目2231）的复核，含账项调整（AJE）、重分类调整（RJE）。复核须验证利息计提调整有证据、借贷平衡、完整反映到L2-1审定表、利息分类重分类恰当，并确认调整已同步试算平衡表。

**法规依据：**
- 《企业会计准则第22号——金融工具确认和计量》
- 《企业会计准则第37号——金融工具列报》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **补提应计利息是应付利息AJE的重点**：期末漏提的应计利息通过AJE计提，借方财务费用/在建工程，贷方应付利息，须与L2-2利息测算勾稽。
2. **AJE与RJE区分**：AJE调整利息金额（影响费用/负债），RJE调整列报（如利息分类），不得用RJE掩盖费用漏提。
3. **资本化利息调整须区分**：符合资本化条件的利息调整应计入在建工程等而非财务费用。
4. **与L2-1勾稽**：审定表调整列金额须与L2-3已确认分录逐笔一致。
5. **TB回写**：确认调整已同步试算平衡表2231科目。
6. **未调整错报累计**：未调整的利息错报须与A13交叉验证。

## checklist

### 一、调整分录有效性

- [ ] 所有AJE是否有充分证据（利息独立测算、合同利率核对）
- [ ] 补提应计利息的AJE是否与L2-2利息测算勾稽
- [ ] 每笔调整分录借贷方是否平衡
- [ ] 资本化利息调整是否正确区分（计入在建工程）
- [ ] AJE是否经适当层级审批

### 二、与审定表勾稽

- [ ] 调整金额是否完整反映到L2-1审定表调整列
- [ ] 审定表调整后金额是否等于未审数+AJE+RJE
- [ ] 已确认分录是否与审定表逐笔一致

### 三、重分类恰当性

- [ ] RJE是否仅涉及列报未影响损益类科目
- [ ] 利息分类调整是否正确（短期/长期/债券利息）
- [ ] 应付利息与应付债券应计利息列报是否恰当

### 四、TB回写与错报汇总

- [ ] 调整是否已同步试算平衡表2231科目
- [ ] 未调整的利息错报是否记录于A13
- [ ] 跨期利息调整是否正确区分本期/前期

## risk_areas

### 高风险

1. **利息补提调整缺乏证据**：补提应计利息缺独立测算支持。
2. **审定表与L2-3不一致**：调整金额未完整反映到审定表。
3. **资本化利息误计财务费用**：应资本化利息通过AJE错误计入费用。

### 中风险

1. **RJE误含损益影响**：利息重分类调整错误影响损益。
2. **利息分类调整错误**：短期/长期/债券利息分类调整错误。
3. **跨期利息调整分类错误**：本期错报与前期差错混淆。

### 低风险

1. **编号、格式不规范**：分录编号或摘要不规范。
2. **索引不完整**：调整分录未指向L2-2明细、利息测算底稿。
3. **审计说明不充分**：未概括调整性质。
