# L8-note-soe 附注披露复核提示词（国有企业）

## 概述

本提示词针对财务费用国有企业附注披露底稿（L8-note-soe）的复核，聚焦国有企业特定的附注披露要求：在按明细项目分类、利息资本化、汇兑损益等基础披露之上，额外增加国资监管相关信息——向国有关联方支付利息的披露、融资成本对经营业绩的影响、汇兑损益对国有资本的影响以及与决算报表的一致性。国有企业财务费用审计须同时满足会计准则和国资监管要求。

**法规依据：**
- 《企业会计准则第17号——借款费用》
- 《企业会计准则第19号——外币折算》
- 《企业会计准则第36号——关联方披露》
- 《中央企业财务决算报告管理办法》

---

## tips

1. **国有企业附注有"双层"披露要求**：既满足CAS的基础披露（分项/资本化/汇兑），又满足国资委决算报告的额外披露要求。
2. **向国有关联方支付利息披露**：向控股股东及同一母公司控制的其他国有企业支付的利息须关注定价公允性并纳入关联交易披露（CAS36）。
3. **融资成本对经营业绩影响**：财务费用（尤其利息支出）规模影响国企经营业绩考核，附注宜说明融资成本变动及原因。
4. **汇兑损益对国有资本影响**：重大汇兑损益影响国有资本保值增值，附注宜说明外币敞口管理及汇率风险应对。
5. **利息资本化合规性**：利息资本化涉及资产成本与损益划分，须符合CAS17且与国有资产核算一致。
6. **与决算报表一致**：附注财务费用数据须与年度财务决算报表一致，合并层面内部利息往来抵销须完整。

## checklist

### 一、基础披露完整性（与上市版共有）

- [ ] 财务费用是否按利息支出/利息收入/汇兑损益/手续费及其他分项披露
- [ ] 是否披露本期资本化利息金额
- [ ] 汇兑损益是否单独列示
- [ ] 附注财务费用净额是否与审定表审定数及利润表一致
- [ ] 本期/上期可比信息是否完整

### 二、关联交易披露（国企特定）

- [ ] 向控股股东及关联企业支付的利息是否披露
- [ ] 向同一母公司控制的其他国有企业支付的利息是否披露
- [ ] 关联方借款利息定价公允性是否说明
- [ ] 是否运用"同受国家控制"关联方豁免条款，运用是否符合条件

### 三、融资成本与经营业绩

- [ ] 财务费用变动对经营业绩的影响是否说明
- [ ] 融资成本变动原因（借款规模/利率）是否分析
- [ ] 利息支出与借款循环是否勾稽

### 四、汇兑损益与国有资本

- [ ] 重大汇兑损益对国有资本的影响是否说明
- [ ] 外币敞口管理及汇率风险应对是否披露
- [ ] 汇兑损益计算是否符合CAS19

### 五、与上市版的差异关注点

- [ ] 国企版是否在基础披露上增加国资监管补充信息
- [ ] 关联方范围是否扩展至"同受国有控制"企业
- [ ] 是否增加融资成本对经营业绩影响分析
- [ ] 是否增加汇兑损益对国有资本影响分析

### 六、决算报表特殊要求

- [ ] 财务费用数据是否与年度财务决算报表一致
- [ ] 集团合并层面内部利息往来抵销是否完整
- [ ] 抵销后金额是否与决算一致

## risk_areas

### 高风险

1. **向国有关联方利息未披露**：向国有关联方支付的利息未纳入关联交易披露，信息不完整，可能掩盖利益输送。
2. **资本化利息合规性问题**：利息资本化划分错误影响国有资产核算，未按CAS17处理。
3. **基础披露与审定表/利润表不一致**：附注财务费用净额与审定数或利润表不勾稽。

### 中风险

1. **关联方利息定价未说明**：向关联方支付利息的定价公允性未说明。
2. **汇兑损益影响未分析**：重大汇兑损益对国有资本影响未说明。
3. **决算与审计口径差异未调节**：财务决算数据与审计后附注数据差异未说明。

### 低风险

1. **披露格式未按决算模板**：附注格式与国资委决算模板有细微差异。
2. **融资成本分析简略**：财务费用变动原因分析不充分。
3. **可比信息缺失**：仅列示本期数据未列示上期可比数据。
