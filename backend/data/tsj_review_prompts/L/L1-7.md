# L1-7 短期借款逾期贷款检查复核提示词

## 概述

本提示词针对短期借款逾期贷款检查表（L1-7，科目2001）的复核，聚焦逾期借款的识别完整性、逾期原因与违约后果评估、罚息计提，以及逾期借款对持续经营能力的影响。逾期借款是债务风险和持续经营重大不确定性的重要信号。

**法规依据：**
- 《企业会计准则第22号——金融工具确认和计量》
- 《企业会计准则第37号——金融工具列报》
- 《中国注册会计师审计准则第1324号——持续经营》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **逾期借款识别须完整**：逐笔核对借款到期日与实际偿还情况，结合征信逾期记录，识别全部逾期借款，防止遗漏。
2. **逾期须评估违约后果**：逾期可能触发罚息、加速到期、交叉违约条款，须评估对负债规模和分类的影响。
3. **罚息须计提**：逾期借款按合同罚息条款计提的罚息须确认，与L1-5利息测算勾稽。
4. **逾期对持续经营的影响须评估**：大额逾期或多笔逾期是持续经营重大不确定性的信号，须结合整体偿债能力评估。
5. **逾期借款分类与披露**：逾期借款须在附注中披露逾期金额、逾期原因和展期/重组情况。
6. **关注展期与债务重组**：借款展期或重组须评估是否构成债务重组，会计处理和披露要求不同。

## checklist

### 一、逾期识别完整性

- [ ] 是否逐笔核对借款到期日与实际偿还情况
- [ ] 逾期借款是否与征信报告逾期记录一致
- [ ] 是否存在已逾期但未在检查表中反映的借款
- [ ] 逾期金额、逾期天数是否准确记录

### 二、违约后果评估

- [ ] 逾期是否触发罚息条款，罚息是否已计提
- [ ] 逾期是否触发加速到期（提前偿还全部）
- [ ] 逾期是否触发交叉违约条款影响其他债务
- [ ] 罚息计提是否与L1-5利息测算勾稽

### 三、持续经营影响

- [ ] 逾期借款规模是否评估对偿债能力的影响
- [ ] 是否存在持续经营重大不确定性的信号
- [ ] 逾期是否与A系列持续经营评估勾稽

### 四、分类披露与重组

- [ ] 逾期借款是否在附注中披露逾期金额和原因
- [ ] 借款展期是否评估分类和披露影响
- [ ] 债务重组是否按CAS恰当处理和披露

## risk_areas

### 高风险

1. **逾期借款遗漏**：已逾期借款未识别，掩盖债务风险和违约后果。
2. **持续经营重大不确定性未识别**：大额逾期未评估持续经营影响，审计意见可能不当。
3. **加速到期未评估**：逾期触发加速到期条款，短期偿债压力剧增未反映。
4. **罚息漏提**：逾期罚息未计提，负债和费用低估。

### 中风险

1. **交叉违约未评估**：逾期触发其他债务交叉违约未评估。
2. **债务重组处理不当**：展期/重组未按CAS恰当会计处理。
3. **逾期披露不充分**：附注未充分披露逾期金额和原因。

### 低风险

1. **逾期天数记录偏差**：逾期天数计算不精确。
2. **检查表格式不规范**：逾期检查底稿格式不统一。
3. **索引不完整**：逾期检查未与征信、利息测算底稿建立索引。
