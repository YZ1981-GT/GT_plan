# L1-note-listed 短期借款附注披露复核提示词（上市公司）

## 概述

本提示词针对短期借款上市公司附注披露底稿（L1-note-listed，科目2001）的复核，聚焦上市公司财务报表附注中短期借款的分类披露（信用/抵押/质押/保证借款）、逾期借款披露、受限资产披露、CAS37金融工具列报要求，以及信息披露编报规则要求的补充信息。披露充分性直接影响投资者对偿债能力的判断。

**法规依据：**
- 《企业会计准则第37号——金融工具列报》
- 《企业会计准则第22号——金融工具确认和计量》
- 《公开发行证券的公司信息披露编报规则第15号——财务报告的一般规定》

---

## tips

1. **短期借款须按担保方式分类披露**：附注须按信用借款、抵押借款、质押借款、保证借款分类列示期末和期初余额，各类合计须等于审定表审定数。
2. **逾期未偿还借款须单独披露**：期末已逾期未偿还的短期借款须披露借款单位、期末余额、逾期利率和逾期原因，这是投资者评估流动性风险的关键信息。
3. **受限资产（抵质押）须披露**：用于抵押/质押的资产须披露账面价值和受限原因，与L1-8抵质押资产检查勾稽。
4. **附注数据须与审定表/明细表勾稽**：附注短期借款总额须等于审定表审定数，分类小计须等于明细表对应分类合计。
5. **利率区间与加权平均利率披露**：上市公司通常须披露短期借款的利率区间，异常利率借款须有说明。
6. **关联方借款须结合关联方附注**：关联方短期借款须在关联方交易附注中披露，与本附注勾稽。

## checklist

### 一、分类披露检查

- [ ] 短期借款是否按信用/抵押/质押/保证借款分类披露
- [ ] 各类别期末余额合计是否等于审定表审定数
- [ ] 各类别是否同时披露期末数和期初（上年年末）数
- [ ] 分类方式是否与明细表L1-2勾稽
- [ ] 各分类之间是否存在重叠或遗漏

### 二、逾期借款披露

- [ ] 期末逾期未偿还借款是否单独披露
- [ ] 是否披露逾期借款的借款单位、期末余额、逾期利率
- [ ] 逾期原因是否披露（与L1-7勾稽）
- [ ] 由长期借款转入的短期借款是否披露转入金额

### 三、受限资产与担保披露

- [ ] 抵押/质押资产的账面价值是否披露
- [ ] 受限资产受限原因是否说明（与L1-8勾稽）
- [ ] 保证借款的保证方是否披露（如为关联方须结合关联方附注）

### 四、CAS37列报充分性

- [ ] 是否披露短期借款利率区间或加权平均利率
- [ ] 是否披露外币借款的币种和折算汇率
- [ ] 信用风险/流动性风险管理是否披露
- [ ] 附注总额是否与审定表审定数一致

## risk_areas

### 高风险

1. **附注总额与审定表不一致**：附注短期借款总额与审定表审定数不一致，属数据勾稽重大错误。
2. **逾期借款未披露**：期末逾期未偿还借款未单独披露，隐瞒流动性风险。
3. **表外借款仍未反映**：附注仍未反映征信/函证发现的表外借款。
4. **受限资产披露缺失**：抵质押资产未披露账面价值和受限原因。

### 中风险

1. **分类披露不完整**：仅按单一维度披露未按担保方式分类。
2. **利率信息缺失**：未披露利率区间或异常利率无说明。
3. **可比信息缺失**：仅列示期末数据未列示期初可比数据。
4. **关联方借款未结合关联方附注**：关联方借款披露不完整。

### 低风险

1. **披露格式不完全规范**：表格格式细节未严格按编报规则。
2. **文字描述模板化**：风险管理描述照搬会计政策未结合实际。
3. **数字精度不一致**：披露表格精度不统一。
