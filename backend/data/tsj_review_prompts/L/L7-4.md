# L7-4 其他非流动负债检查表复核提示词

## 适用底稿
其他非流动负债检查表（L7-4），聚焦凭证核对完整性、项目性质核查、长期性验证、存在性与义务真实性、样本选取合理性及检查比例达标性。

## 概述
L7-4 是其他非流动负债存在性、完整性、计量与列报认定的证据支撑底稿。复核须验证：样本覆盖重大项目、凭证核对完整、项目性质与长期性核查充分、异常事项标注、检查比例满足审计目标。核心目标是验证负债性质归类正确及长期性成立。

## tips

- 样本选取应覆盖金额重大项目、本期新增及一年内到期项目
- 凭证核对须覆盖完整链条（合同/协议→确认依据→入账→后续计量/付款）
- 项目性质核查须判断是否应归入更特定科目（长期借款/长期应付款/递延收益/预计负债）
- 长期性验证须核对合同清偿期，确认非流动分类条件成立
- 检查比例应满足《中国注册会计师审计准则第1314号——审计抽样》要求
- 关注是否存在利用兜底科目掩盖负债性质或调节流动性指标
- 异常事项标注需明确类型（性质存疑/长期性不足/义务不实/关联方/长期挂账）

## checklist

### 高风险检查项

- [ ] 样本选取是否覆盖金额重大及高风险项目
- [ ] 金额重大项目（超过重要性水平）是否100%检查
- [ ] 合同/协议是否齐全并核对金额、清偿期
- [ ] 项目性质是否核查（是否应归入更特定科目）
- [ ] 是否存在利用其他非流动负债掩盖负债性质
- [ ] 长期性是否核对合同清偿期验证成立
- [ ] 一年内到期项目是否识别并重分类
- [ ] 是否存在无真实义务支持的挂账
- [ ] 义务真实性是否有充分证据支持

### 中风险检查项

- [ ] 检查比例（已检查金额/总体金额）是否达到计划水平
- [ ] 借方（本期减少）检查比例是否达标
- [ ] 贷方（本期增加）检查比例是否达标
- [ ] 后续计量（如递延项目摊销）是否核查
- [ ] 长期挂账项目是否评估合理性
- [ ] 核对中发现的差异是否逐一追踪解决

### 低风险检查项

- [ ] 抽样参数是否完整记录
- [ ] 样本选取过程是否可追溯
- [ ] 检查结果记录格式是否规范
- [ ] 检查比例计算公式是否正确
- [ ] 底稿索引与交叉引用是否完整（关联审定表/明细表）

## risk_areas

### 高风险

- **兜底滥用风险**：应归入特定科目的负债被计入其他非流动负债，掩盖负债性质
- **长期性不成立风险**：不满足长期性条件的负债列为非流动，流动性列报错误
- **虚假挂账风险**：无真实义务支持的其他非流动负债
- **完整性缺口风险**：存在的长期负债未纳入检查，低估非流动负债

### 中风险

- **检查比例不足风险**：实际检查比例低于计划水平
- **性质核查不深风险**：仅核对金额而忽略负债性质归类
- **一年内到期未识别风险**：一年内到期项目未识别，重分类遗漏

### 低风险

- **记录不完整风险**：抽样参数/核对结果记录不完整
- **索引缺失风险**：与审定表/明细表交叉索引不完整
- **格式不规范风险**：检查结果记录格式不统一
