# L3-5 长期借款利息测算表复核提示词

## 概述

本提示词针对长期借款利息测算表（L3-5，科目2501联动2231应付利息/6603财务费用/在建工程）的复核，聚焦利息计提准确性、借款费用资本化的判断与计算（CAS17）、应计未付利息分离，以及与财务费用和资本化资产的勾稽。借款费用资本化是长期借款利息测算的核心难点。

**法规依据：**
- 《企业会计准则第17号——借款费用》
- 《企业会计准则第22号——金融工具确认和计量》
- 《企业会计准则第37号——金融工具列报》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **借款费用资本化判断是长期借款利息测算的核心**：为购建符合资本化条件资产的专门借款/一般借款利息须资本化，须验证资本化开始、暂停、停止时点的判断。
2. **专门借款与一般借款资本化计算不同**：专门借款按实际发生利息减存款利息收入资本化；一般借款按资本化率×累计支出加权平均数计算，须验证计算方法。
3. **利息独立测算验证完整性**：以本金×利率×计息期间独立测算，与账面已提利息比对，防止漏提。
4. **应计未付利息须重分类至应付利息**：期末应计未付的长期借款利息应在应付利息（2231）列示。
5. **资本化利息须与在建工程/固定资产勾稽**：资本化的借款费用须与在建工程或固定资产成本勾稽。
6. **利率须与合同一致**：浮动利率借款须核对基准利率调整，与L3-6合同一致。

## checklist

### 一、利息计提准确性

- [ ] 是否以本金×利率×计息期间独立测算应计利息
- [ ] 测算利息与账面已提利息差异是否追查
- [ ] 利率是否与L3-6贷款合同一致
- [ ] 浮动利率借款是否核对基准利率调整
- [ ] 是否存在利息漏提或多提

### 二、借款费用资本化（CAS17）

- [ ] 资本化开始、暂停、停止时点判断是否恰当
- [ ] 专门借款资本化金额是否=实际利息-闲置资金利息收入
- [ ] 一般借款资本化是否按资本化率×累计支出加权平均数计算
- [ ] 资本化率计算是否正确
- [ ] 资本化利息是否与在建工程/固定资产成本勾稽

### 三、本息分离与勾稽

- [ ] 期末应计未付利息是否重分类至应付利息（2231）
- [ ] 长期借款本金中是否混有应计利息
- [ ] 费用化利息是否与财务费用（6603）勾稽

### 四、跨底稿联动

- [ ] L3-5测算利息是否与L2应付利息审定表勾稽
- [ ] 已付利息现金流是否与现金流量表勾稽

## risk_areas

### 高风险

1. **资本化判断错误**：应资本化的借款费用全部费用化（低估资产），或不符合条件的费用被资本化（虚增资产、少计费用）。
2. **资本化时点错误**：资产建造中断期间未暂停资本化，或达到可使用状态后未停止资本化。
3. **利息漏提**：期末未计提应计利息，费用和应付利息双低估。
4. **一般借款资本化率错误**：资本化率或累计支出加权平均数计算错误。

### 中风险

1. **本息未分离**：应计利息混在长期借款本金中。
2. **利率与合同不一致**：测算利率与贷款合同不符。
3. **专门借款闲置资金利息未扣减**：资本化金额未扣减闲置资金存款利息收入。
4. **利息与财务费用不勾稽**：费用化利息与利润表财务费用不一致。

### 低风险

1. **计息公式记录不规范**：测算过程未清晰列示。
2. **资本化计算过程记录不清**：资本化率计算过程未详细列示。
3. **索引不完整**：利息测算未与合同、在建工程、应付利息底稿建立索引。
