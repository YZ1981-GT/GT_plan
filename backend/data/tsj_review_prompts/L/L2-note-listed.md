# L2-note-listed 应付利息附注披露复核提示词（上市公司）

## 概述

本提示词针对应付利息上市公司附注披露底稿（L2-note-listed，科目2231）的复核，聚焦附注中应付利息的分类披露（分期付息长期借款利息/企业债券利息/短期借款利息/优先股永续债利息/其他）、重要逾期未付利息披露、与借款本金的勾稽，以及CAS37金融工具列报要求。应付利息披露反映企业的利息负担和偿债状况。

**法规依据：**
- 《企业会计准则第37号——金融工具列报》
- 《企业会计准则第22号——金融工具确认和计量》
- 《公开发行证券的公司信息披露编报规则第15号——财务报告的一般规定》

---

## tips

1. **应付利息须按利息类别分类披露**：附注须按分期付息长期借款利息、企业债券利息、短期借款利息、优先股/永续债利息、其他分类列示期末和期初余额，各类合计等于审定表审定数。
2. **重要的逾期未付利息须单独披露**：期末重要的逾期未付利息须披露欠付金额和欠付原因，这是投资者评估偿债风险的关键信息。
3. **应付利息须与借款本金附注勾稽**：各类应付利息须与短期借款、长期借款、应付债券附注中的对应本金勾稽。
4. **优先股/永续债利息须结合工具分类**：优先股和永续债的股息/利息须结合金融工具分类（负债/权益）判断列报位置。
5. **附注数据须与审定表勾稽**：附注应付利息总额须等于审定表审定数，分类小计等于明细表对应分类。
6. **利息资本化情况须结合相关附注**：资本化利息须在借款费用附注中说明，与应付利息计提勾稽。

## checklist

### 一、分类披露检查

- [ ] 应付利息是否按利息类别分类披露（长期借款/债券/短期借款/优先股永续债/其他）
- [ ] 各类别期末余额合计是否等于审定表审定数
- [ ] 各类别是否同时披露期末数和期初（上年年末）数
- [ ] 分类方式是否与明细表L2-2勾稽
- [ ] 优先股/永续债利息是否结合工具分类正确列报

### 二、逾期未付利息披露

- [ ] 期末重要的逾期未付利息是否单独披露
- [ ] 是否披露欠付利息的金额和欠付原因
- [ ] 欠付利息是否反映偿债压力

### 三、与借款本金勾稽

- [ ] 长期借款利息是否与长期借款附注勾稽
- [ ] 债券利息是否与应付债券附注勾稽
- [ ] 短期借款利息是否与短期借款附注勾稽

### 四、CAS37列报充分性

- [ ] 资本化利息情况是否结合借款费用附注说明
- [ ] 附注总额是否与审定表审定数一致
- [ ] 关联方借款利息是否结合关联方附注披露

## risk_areas

### 高风险

1. **附注总额与审定表不一致**：附注应付利息总额与审定表审定数不一致。
2. **逾期未付利息未披露**：重要欠付利息未单独披露，隐瞒偿债风险。
3. **利息漏提仍未反映**：应计未付利息漏提仍未在附注反映。
4. **优先股永续债利息列报错误**：结合工具分类的利息列报位置错误。

### 中风险

1. **分类披露不完整**：未按利息类别分类披露。
2. **与借款本金不勾稽**：应付利息与对应借款附注不勾稽。
3. **可比信息缺失**：仅列示期末数据未列示期初。

### 低风险

1. **披露格式不完全规范**：表格格式细节未严格按编报规则。
2. **欠付原因说明简略**：欠付利息原因披露不详。
3. **数字精度不一致**：披露表格精度不统一。
