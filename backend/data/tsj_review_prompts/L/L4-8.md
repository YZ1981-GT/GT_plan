# L4-8 应付债券账面核对复核提示词

## 概述

本提示词针对应付债券账面核对表（L4-8，科目2502）的复核，聚焦账面记录的债券摊余成本与后续计量摊销表的核对、账面利息费用与摊销表利息的核对，以及两种付息方式分支下账面与测算的一致性。账面核对是验证账面记录是否符合实际利率法计量的关键程序。

**法规依据：**
- 《企业会计准则第22号——金融工具确认和计量》
- 《企业会计准则第37号——金融工具列报》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **账面核对是验证账面符合实际利率法的关键**：将账面记录的债券摊余成本、利息费用与L4-7后续计量摊销表逐期核对，识别账务处理差错。
2. **付息方式分支须与后续计量一致**：账面核对分支（到期一次还本付息/分期付息到期一次还本）须与L4-7后续计量分支一致。
3. **账面利息费用须与摊销表勾稽**：账面确认的利息费用须与摊销表每期利息费用（期初摊余成本×实际利率）一致，差异须调整。
4. **账面摊余成本须与摊销表期末一致**：账面债券账面价值须与摊销表期末摊余成本一致。
5. **差异须通过调整分录处理**：账面与测算的差异须通过L4-4调整分录处理并反映到审定表。
6. **应计利息账面核对**：到期一次付息债券的账面应计利息须与摊销表累积应计利息一致。

## checklist

### 一、摊余成本核对

- [ ] 账面债券摊余成本是否与L4-7摊销表期末一致
- [ ] 账面面值、利息调整余额是否与摊销表一致
- [ ] 账面核对分支是否与L4-7后续计量分支一致

### 二、利息费用核对

- [ ] 账面利息费用是否与摊销表每期利息一致
- [ ] 账面确认的利息费用是否=期初摊余成本×实际利率
- [ ] 账面票面利息计提是否正确

### 三、应计利息核对

- [ ] 到期一次付息债券账面应计利息是否与摊销表累积一致
- [ ] 分期付息债券应付利息是否与摊销表一致
- [ ] 应计利息列报（2502内/重分类至2231）是否恰当

### 四、差异处理

- [ ] 账面与测算差异是否识别
- [ ] 差异是否通过L4-4调整分录处理
- [ ] 调整后账面是否与审定表L4-1一致

## risk_areas

### 高风险

1. **账面不符合实际利率法**：账面按票面利率或直线法确认利息，未按实际利率法，导致利息费用和债券账面失真。
2. **账面与摊销表重大差异未调整**：账面摊余成本或利息费用与测算存在重大差异未调整。
3. **付息方式账务处理错误**：到期一次付息与分期付息账务处理混淆。

### 中风险

1. **应计利息核对差异**：账面应计利息与摊销表累积不一致。
2. **差异未通过调整处理**：识别的差异未通过L4-4调整分录处理。
3. **分支与后续计量不一致**：账面核对分支与L4-7不一致。

### 低风险

1. **核对记录不完整**：账面与测算核对记录不规范。
2. **核对表格式不统一**：核对底稿格式不规范。
3. **索引不完整**：账面核对未与后续计量、调整分录底稿建立索引。
