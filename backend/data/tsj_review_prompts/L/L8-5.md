# L8-5 财务费用截止性测试复核提示词

## 适用底稿
财务费用截止性测试（L8-5），基于序时账在资产负债表日前后一定天数选取利息/手续费凭证，验证财务费用是否记录于正确会计期间。

## 概述
L8-5 是财务费用截止（Cutoff）认定的证据支撑底稿。复核须验证：测试窗口天数合理、样本覆盖期末前后关键凭证、跨期费用识别充分、利息计提截止准确（尤其是应计未付利息）、检查比例达标。财务费用截止错误将导致当期损益跨期错配。

## tips

- 截止测试窗口应覆盖资产负债表日前后合理天数（如±5至±10天），高风险时扩大窗口
- 样本应涵盖期末大额利息/手续费凭证及期后首笔利息付息凭证
- 应计未付利息的截止是核心：本期已发生但期后支付的利息须在本期计提
- 跨期识别须核对费用所属期间（利息计息期间/服务发生期间）与记账期间是否一致
- 检查比例应满足《中国注册会计师审计准则第1314号——审计抽样》要求
- 关注期末为调节利润而人为提前/推迟确认财务费用的情形
- 异常事项标注需明确类型（跨期费用/利息计提遗漏/付息期与计息期错配）

## checklist

### 高风险检查项

- [ ] 截止测试窗口天数是否合理并与风险评估匹配
- [ ] 样本是否覆盖期末大额利息/手续费凭证
- [ ] 期后首笔付息凭证是否纳入测试
- [ ] 本期已发生期后支付的应计未付利息是否在本期计提
- [ ] 费用所属期间（计息期间）与记账期间是否一致
- [ ] 是否识别期末人为提前/推迟确认财务费用的情形
- [ ] 跨期费用是否已识别并作调整（与L8-3勾稽）
- [ ] 利息计提截止是否与借款循环（L1/L3/L4）应付利息勾稽

### 中风险检查项

- [ ] 检查比例是否达到计划水平
- [ ] 汇兑损益的期末折算截止是否正确（外币货币性项目期末汇率）
- [ ] 手续费所属期间与记账期间是否核对
- [ ] 期后冲回的财务费用是否评估其本期确认合理性
- [ ] 核对中发现的跨期差异是否逐一追踪调整

### 低风险检查项

- [ ] 抽样参数（窗口天数/样本量）是否完整记录
- [ ] 样本选取过程是否可追溯
- [ ] 检查结果记录格式是否规范
- [ ] 底稿索引与交叉引用是否完整（关联审定表/明细表/调整分录）

## risk_areas

### 高风险

- **应计未付利息漏计风险**：本期已发生但期后支付的利息未在本期计提，低估本期财务费用
- **跨期费用错配风险**：财务费用记账期间与所属期间不一致，跨期错配调节利润
- **人为调节截止风险**：期末为达成利润目标人为提前/推迟确认财务费用
- **利息截止与借款不勾稽风险**：利息计提截止与借款循环应付利息不匹配

### 中风险

- **检查比例不足风险**：截止测试样本覆盖不足
- **汇兑损益截止错误风险**：期末外币折算未按资产负债表日汇率
- **手续费截止错误风险**：手续费所属期间与记账期间错配

### 低风险

- **记录不完整风险**：窗口天数/抽样参数记录不完整
- **索引缺失风险**：与审定表/明细表/调整分录交叉索引不完整
- **格式不规范风险**：检查结果记录格式不统一

## 法规依据
