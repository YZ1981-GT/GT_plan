# L1-3 短期借款调整分录复核提示词

## 概述

本提示词针对短期借款调整分录汇总表（L1-3，科目2001）的复核，含账项调整（AJE）、重分类调整（RJE）。复核须验证每笔调整有证据、借贷平衡、完整反映到L1-1审定表、逾期借款重分类恰当，并确认调整已同步试算平衡表。

**法规依据：**
- 《企业会计准则第22号——金融工具确认和计量》
- 《企业会计准则第37号——金融工具列报》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **AJE与RJE区分**：AJE调整借款本金或利息金额（影响负债/损益），RJE仅调整列报（如逾期借款重分类），不得用RJE掩盖负债低估。
2. **补记表外借款是短期借款AJE的重点**：函证/征信发现的未入账借款须通过AJE补记，确认贷款人、金额和资金流向证据充分。
3. **利息计提调整须与L1-5勾稽**：应计未付利息通过AJE计提并重分类至应付利息（2231），借方财务费用/在建工程，贷方应付利息。
4. **与L1-1勾稽**：审定表调整列金额须与L1-3已确认分录逐笔一致，遗漏任一笔即审定数失真。
5. **TB回写**：确认调整已同步试算平衡表2001科目，避免"底稿已调、TB未更"双真源。
6. **未调整错报累计**：未调整错报须与A13未调整错报汇总交叉验证，评估是否超过重要性水平。

## checklist

### 一、调整分录有效性

- [ ] 所有AJE是否有充分审计证据（函证差异、征信核对、利息测算）
- [ ] 补记表外借款的AJE是否有贷款合同和资金流向证据
- [ ] 每笔调整分录借贷方是否完全平衡
- [ ] 利息计提AJE是否与L1-5利息测算表勾稽
- [ ] AJE是否经适当层级审批（超重要性水平须合伙人知悉）

### 二、与审定表勾稽

- [ ] 调整金额是否完整反映到L1-1审定表对应调整列
- [ ] 审定表调整后金额是否等于未审数+AJE+RJE
- [ ] 调整已确认分录是否与审定表逐笔一致

### 三、重分类调整恰当性

- [ ] 逾期一年以上借款是否通过RJE重分类
- [ ] RJE是否仅涉及列报未影响损益类科目
- [ ] 应计利息重分类至应付利息（2231）是否正确
- [ ] 长期借款一年内到期部分是否恰当反映

### 四、TB回写与错报汇总

- [ ] 调整是否已同步试算平衡表2001科目
- [ ] 未调整错报是否已记录于A13并评估重要性
- [ ] 跨期调整是否正确区分本期/前期差错更正

## risk_areas

### 高风险

1. **调整缺乏证据或未经授权**：补记借款或调整利息缺充分证据，或未经合伙人批准。
2. **审定表与L1-3不一致**：调整金额未完整反映到审定表，审定数失真。
3. **利息计提调整遗漏**：应计未付利息未通过AJE计提，负债和费用双低估。
4. **表外借款未补记**：函证/征信发现的未入账借款未通过调整补记。

### 中风险

1. **RJE误含损益影响**：重分类调整错误影响了损益类科目。
2. **逾期借款重分类遗漏**：逾期借款未恰当重分类或披露。
3. **跨期调整分类错误**：本期错报与前期差错更正混淆。

### 低风险

1. **编号、格式不规范**：分录编号不连续或摘要不清晰。
2. **索引不完整**：调整分录未指向L1-2明细、函证等支持底稿。
3. **审计说明不充分**：未概括调整性质与残余风险。
