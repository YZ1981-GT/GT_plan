# L8-2 财务费用明细表复核提示词

## 概述

本提示词针对财务费用明细表（L8-2）的复核，聚焦按费用项目（利息支出、利息收入、汇兑损益、手续费及其他）分项分析的完整性、发生额取数准确性、同比变动分析以及与审定表的勾稽。明细表是审定表金额的支撑并承载费用项目分析，须逐项反映各费用项目的本期发生额、上期发生额、变动额与变动率，异常波动须附原因分析。

**法规依据：**
- 《企业会计准则第17号——借款费用》
- 《企业会计准则第19号——外币折算》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **分项分析须完整**：明细表须按利息支出、利息收入、汇兑损益、手续费及其他分项列示本期发生额、上期发生额、变动额及变动率。
2. **发生额取数方向**：各费用项目按性质确定取数方向（支出类借-贷、收入/冲减类贷-差），与L8-1审定表口径一致。
3. **同比变动分析**：变动率超过阈值（如30%）的项目须附原因分析，异常波动是识别错报的重要信号。
4. **利息支出细分**：利息支出宜按借款来源（短期借款/长期借款/应付债券/非金融机构借款）细分，便于与借款循环勾稽。
5. **汇兑损益构成**：汇兑损益宜区分外币货币性项目期末折算损益与外币结算实现损益，便于验证。
6. **明细合计勾稽审定表**：明细表各费用项目发生额合计（净额）须等于审定表L8-1审定数。

## checklist

### 一、分项分析完整性

- [ ] 是否按利息支出/利息收入/汇兑损益/手续费及其他分项列示
- [ ] 是否列示本期发生额、上期发生额、变动额、变动率
- [ ] 各分项取数方向是否与L8-1审定表一致
- [ ] 各分项发生额合计（净额）是否与审定表勾稽

### 二、发生额准确性

- [ ] 各费用项目发生额是否与序时账/明细账勾稽
- [ ] 支出类是否按借-贷、收入/冲减类是否按贷-差取数
- [ ] 是否与试算平衡表6603科目发生额一致

### 三、同比变动分析

- [ ] 变动率超阈值的项目是否附原因分析
- [ ] 异常波动是否合理解释并有证据支持
- [ ] 利息支出变动是否与借款规模/利率变动匹配
- [ ] 汇兑损益变动是否与汇率变动及外币敞口匹配

### 四、细分与勾稽

- [ ] 利息支出是否按借款来源细分
- [ ] 汇兑损益是否区分折算损益与结算损益
- [ ] 明细表是否与附注财务费用披露一致

## risk_areas

### 高风险

1. **发生额取数错误**：费用项目取数方向或金额错误，导致财务费用净额失真。
2. **异常波动未解释**：重大变动项目未分析原因，可能掩盖错报或异常交易。
3. **利息支出与借款不匹配**：利息支出与借款规模、利率明显不匹配未查明。

### 中风险

1. **分项分析不完整**：未按项目分项列示或缺少同比分析。
2. **明细与审定表不勾稽**：明细合计与审定数不一致。
3. **汇兑损益构成不清**：未区分折算损益与结算损益。

### 低风险

1. **细分层次不足**：利息支出未按借款来源细分。
2. **变动分析简略**：原因分析不够充分。
3. **索引引用不完整**：未与序时账/借款循环建立索引。
