# L1-4 短期借款征信报告核对复核提示词

## 概述

本提示词针对短期借款征信报告核对表（L1-4，科目2001）的复核，聚焦征信报告/人民银行贷款卡与账面借款的完整性核对，这是识别表外负债最有效的审计程序。核对须覆盖全部授信记录，识别账面未入账的借款、担保和或有负债。

**法规依据：**
- 《中国注册会计师审计准则第1312号——函证》
- 《企业会计准则第22号——金融工具确认和计量》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **征信核对是防表外负债的最强程序**：企业信用报告/贷款卡记录了全部金融机构授信，逐笔核对可发现账面未反映的借款、担保和承兑汇票。
2. **核对须覆盖全部授信主体**：不仅核对借款余额，还须核对授信额度、已用额度、担保记录、逾期记录，识别隐性负债。
3. **征信报告须为审计期间的有效版本**：核对使用的征信报告应为资产负债表日附近打印的完整版本，过期或不完整版本会遗漏借款。
4. **对外担保须评估或有负债**：征信报告中的对外担保记录须评估是否需确认预计负债或在附注披露或有负债。
5. **逾期记录须与L1-7勾稽**：征信中的逾期记录须与逾期借款检查一致，评估违约风险和交叉违约条款触发。
6. **差异须逐笔追查解释**：征信有记录而账面无、或账面有而征信无的差异，须逐笔调查并取得管理层解释。

## checklist

### 一、征信核对完整性

- [ ] 征信报告/贷款卡是否为资产负债表日附近的完整有效版本
- [ ] 是否核对了全部金融机构的授信和借款记录
- [ ] 账面短期借款是否与征信报告借款记录逐笔对应
- [ ] 是否存在征信有记录但账面未入账的借款
- [ ] 是否存在账面有借款但征信无记录的异常

### 二、隐性负债识别

- [ ] 征信报告中的授信额度和已用额度是否核对
- [ ] 征信报告中的对外担保记录是否评估或有负债
- [ ] 征信报告中的承兑汇票/信用证敞口是否已识别
- [ ] 是否存在民间借贷或非金融机构借款未反映在征信中的补充核查

### 三、逾期与违约

- [ ] 征信报告中的逾期记录是否与L1-7逾期检查一致
- [ ] 逾期记录是否评估交叉违约条款触发影响
- [ ] 不良/关注类贷款分类是否评估对持续经营的影响

### 四、差异处理

- [ ] 征信与账面的差异是否逐笔追查并取得解释
- [ ] 需补记的表外借款是否已通过L1-3调整分录处理
- [ ] 核对结论是否明确并附管理层声明

## risk_areas

### 高风险

1. **表外借款未发现**：征信报告有记录但账面未入账的借款未被识别，导致负债严重低估。
2. **对外担保未披露**：征信中的对外担保未评估或有负债或未在附注披露。
3. **征信报告不完整**：使用过期或不完整版本导致遗漏借款，核对结论失效。
4. **民间借贷遗漏**：非金融机构借款不进征信，未实施补充核查程序。

### 中风险

1. **逾期记录未与L1-7勾稽**：征信逾期记录与逾期检查表不一致。
2. **授信额度信息未利用**：仅核对余额未分析授信使用情况和敞口。
3. **差异未追查解释**：征信与账面差异未逐笔调查。

### 低风险

1. **征信报告版本日期偏离**：使用的征信报告与资产负债表日间隔较长。
2. **核对记录格式不规范**：核对底稿格式不统一。
3. **索引不完整**：核对表未与借款明细、逾期检查建立索引。
