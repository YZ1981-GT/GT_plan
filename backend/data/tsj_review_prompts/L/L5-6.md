# L5-6 关联方及交易检查表复核提示词

## 概述

本提示词针对长期应付款关联方及交易检查表（L5-6）的复核，聚焦关联方长期应付款的识别完整性、交易实质与商业合理性、定价公允性以及披露充分性。长期应付款中涉及关联方的融资租赁、分期购货或资金往来，可能被用于变相融资、利益输送或美化流动性，是舞弊与关联交易审计的重点关注领域。

**法规依据：**
- 《企业会计准则第36号——关联方披露》
- 《中国注册会计师审计准则第1323号——关联方》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **关联方识别须穿透**：长期应付款对手方须与关联方清单（B19）核对，识别是否为关联方，尤其关注通过融资租赁公司等中间方的变相关联融资。
2. **交易实质重于形式**：关联方长期应付款须评估交易实质——是真实购货/租赁融资，还是以应付款名义的资金占用或利益输送。
3. **定价公允性**：关联方融资租赁利率、分期付款折现率须与市场公允水平比较，异常低息或高息均须质疑。
4. **完整性双向核查**：既核查已列示的关联方款项，也核查关联方清单中应有而未在长期应付款体现的往来，防止遗漏。
5. **商业合理性**：本期新增关联方长期应付款须评估商业合理性，无真实业务支持的挂账为高风险。
6. **披露联动**：识别结果须与附注关联方交易披露及L5-2明细表关联方标识联动，确保信息一致。

## checklist

### 一、关联方识别完整性

- [ ] 长期应付款各对手方是否与关联方清单（B19）核对
- [ ] 是否识别通过融资租赁公司等中间方的变相关联融资
- [ ] 关联方清单中应有而未在长期应付款体现的往来是否核查
- [ ] 是否穿透识别最终受益人/实际控制人的关联关系

### 二、交易实质与商业合理性

- [ ] 关联方长期应付款是否有真实购货/租赁业务支持
- [ ] 本期新增关联方款项的商业合理性是否评估
- [ ] 是否存在以应付款名义的资金占用或利益输送
- [ ] 交易实质（经营性/资金性/融资性）是否清晰

### 三、定价公允性

- [ ] 关联方融资租赁利率是否与市场公允水平比较
- [ ] 分期付款折现率选取是否公允
- [ ] 异常低息/高息是否有合理解释
- [ ] 定价方式（市场价/协议价）是否披露

### 四、披露联动

- [ ] 识别结果是否与附注关联方交易披露一致
- [ ] 是否与L5-2明细表关联方标识勾稽
- [ ] 关联方款项账龄及余额是否单独披露

## risk_areas

### 高风险

1. **变相关联融资未识别**：通过融资租赁公司等中间方的关联融资未被识别，关联交易披露不完整。
2. **资金占用隐匿**：关联方以长期应付款名义占用资金，无真实业务支持，掩盖利益输送。
3. **定价严重偏离公允**：关联方融资异常利率未被质疑，可能构成利益输送或费用操纵。

### 中风险

1. **关联方识别遗漏**：部分关联方款项未识别，附注披露不完整。
2. **商业合理性存疑**：新增关联方款项缺乏商业合理性评估。
3. **披露不一致**：检查结果与附注/明细表标识不一致。

### 低风险

1. **定价依据说明不足**：定价公允性未附比较依据。
2. **索引引用不完整**：未与B19关联方清单建立索引。
3. **交易实质描述简略**：交易性质描述不够清晰。
