# L1-5 短期借款利息测算表复核提示词

## 概述

本提示词针对短期借款利息测算表（L1-5，科目2001联动2231应付利息/6603财务费用）的复核，聚焦利息计提的准确性、计息基础与利率的合理性、应计未付利息的分离，以及与财务费用和应付利息的勾稽。利息测算是验证费用完整性和负债分离的核心程序。

**法规依据：**
- 《企业会计准则第22号——金融工具确认和计量》
- 《企业会计准则第37号——金融工具列报》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **利息独立测算是验证费用完整性的关键**：以借款本金×利率×计息天数独立测算应计利息，与账面已提利息比对，差异须追查，防止利息费用漏提。
2. **计息基础须与实际借款期间匹配**：计息天数应基于实际借款起止日期，中途借入/归还的借款须分段计息，避免多计或少计。
3. **利率须与合同一致**：测算使用的利率须与L1-6贷款合同一致，浮动利率借款须核对基准利率调整。
4. **应计未付利息须重分类至应付利息**：期末应计但未支付的利息应在应付利息（2231）列示，不应留在短期借款本金中。
5. **利息费用须与财务费用勾稽**：本期利息费用合计须与利润表财务费用（6603）中的利息支出勾稽，符合资本化条件的须区分。
6. **关注异常利率与关联方借款利息**：明显偏离市场的利率或关联方借款利息须评估公允性和商业实质。

## checklist

### 一、利息计提准确性

- [ ] 是否以本金×利率×计息天数独立测算应计利息
- [ ] 测算利息与账面已提利息的差异是否追查解释
- [ ] 计息天数是否基于实际借款起止日期
- [ ] 中途借入/归还的借款是否分段计息
- [ ] 是否存在利息费用漏提或多提

### 二、计息要素合理性

- [ ] 测算使用的利率是否与L1-6贷款合同一致
- [ ] 浮动利率借款是否核对基准利率调整
- [ ] 异常利率借款是否已分析商业实质
- [ ] 关联方借款利率公允性是否评估

### 三、本息分离与勾稽

- [ ] 期末应计未付利息是否重分类至应付利息（2231）
- [ ] 短期借款本金中是否混有应计利息
- [ ] 本期利息费用是否与财务费用（6603）利息支出勾稽
- [ ] 符合资本化条件的利息是否已区分（联动在建工程）

### 四、跨底稿联动

- [ ] L1-5测算利息是否与L2应付利息审定表勾稽
- [ ] 已付利息现金流是否与现金流量表筹资活动勾稽

## risk_areas

### 高风险

1. **利息费用漏提**：期末未计提应计利息，导致财务费用低估、应付利息低估。
2. **本息未分离**：应计利息混在短期借款本金中，两科目均失真。
3. **计息天数错误**：中途借入归还未分段计息，导致利息测算偏差。
4. **关联方利息不公允**：关联方借款利率明显偏离市场未评估。

### 中风险

1. **利率与合同不一致**：测算利率与贷款合同不符。
2. **浮动利率未调整**：基准利率变动未反映在测算中。
3. **利息与财务费用不勾稽**：测算利息合计与利润表财务费用不一致。

### 低风险

1. **计息公式记录不规范**：测算过程未清晰列示。
2. **资本化利息未标识**：符合资本化条件的利息未单独标注。
3. **索引不完整**：利息测算未与合同、应付利息底稿建立索引。
