# L4-1 应付债券审定表复核提示词

## 概述

本提示词针对应付债券审定表（L4-1，科目2502）的复核，聚焦债券摊余成本计量（实际利率法）、面值与溢折价（利息调整）的分解、应计利息、一年内到期重分类，以及期初期末勾稽和试算平衡表核对。应付债券审定表须按面值、利息调整、应计利息等子项列示，是摊余成本计量准确性的枢纽。

**法规依据：**
- 《企业会计准则第22号——金融工具确认和计量》
- 《企业会计准则第37号——金融工具列报》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **摊余成本计量（实际利率法）是应付债券审定表的核心**：审定表须按债券面值+利息调整（溢折价摊销）+应计利息列示期末摊余成本，实际利率法摊销须验证。
2. **面值与利息调整须分解列示**：债券按面值发行、溢价发行、折价发行的利息调整（溢折价）须单独列示，期末利息调整余额随摊销逐期变动。
3. **可转换债券须分拆负债与权益成分**：可转换公司债券须将负债成分（按市场利率折现）和权益成分（转股权）分拆，审定表负债部分仅反映负债成分。
4. **应计利息须准确**：按票面利率计算的应付利息（分期付息）或按实际利率计算的应计利息须准确列示。
5. **一年内到期债券须重分类**：距资产负债表日1年内到期的应付债券须重分类至一年内到期的非流动负债。
6. **期初期末勾稽与试算平衡表核对**：期末摊余成本=期初+实际利息-已付利息-已偿还本金（加减调整），审定数合计与试算平衡表2502科目一致。

## checklist

### 一、摊余成本计量

- [ ] 期末摊余成本是否按面值+利息调整+应计利息列示
- [ ] 实际利率法摊销是否与L4-6初始计量的实际利率一致
- [ ] 利息调整（溢折价）摊销是否随期间逐期变动
- [ ] 期末摊余成本是否与L4-7后续计量/L4-8账面核对勾稽

### 二、面值溢折价与可转换分拆

- [ ] 债券面值是否单独列示
- [ ] 利息调整（溢价/折价）期末余额是否正确
- [ ] 可转换债券是否分拆负债成分与权益成分
- [ ] 权益成分（其他权益工具/资本公积）是否正确列报

### 三、应计利息与重分类

- [ ] 应计利息是否按票面/实际利率准确计算
- [ ] 分期付息债券的应付利息是否列示（联动2231）
- [ ] 一年内到期债券是否重分类至一年内到期的非流动负债
- [ ] 重分类调整是否与L4-4勾稽

### 四、期初期末勾稽与试算表核对

- [ ] 期末摊余成本是否=期初+实际利息-已付利息-已偿还本金（加减调整）
- [ ] 期初审定数是否等于上年期末审定数
- [ ] 审定数合计是否与试算平衡表2502科目一致
- [ ] 审计调整（AJE/RJE）是否完整反映

## risk_areas

### 高风险

1. **摊余成本计量错误**：未按实际利率法摊销溢折价，或实际利率错误，导致债券账面价值和利息费用失真。
2. **可转换债券未分拆**：可转换债券未分拆负债与权益成分，负债和权益均失真，利息费用低估。
3. **一年内到期未重分类**：一年内到期债券仍列为非流动负债，误导偿债结构。
4. **审定数与试算平衡表不一致**：审定表合计与2502科目差异。
5. **应计利息计算错误**：应计利息按票面而非实际利率或计算错误。

### 中风险

1. **面值溢折价未分解**：债券未按面值和利息调整分解列示。
2. **实际利息与费用不勾稽**：实际利率法确认的利息费用与财务费用不一致。
3. **期初期末不勾稽**：摊余成本变动无法用实际利息和偿还解释。
4. **权益成分列报错误**：可转换债券权益成分列报位置错误。

### 低风险

1. **审定表格式不规范**：子项列示、行顺序等格式问题。
2. **摊销计算过程记录不清**：实际利率法摊销过程未清晰列示。
3. **交叉索引不完整**：未与初始计量、后续计量、账面核对底稿建立索引。
