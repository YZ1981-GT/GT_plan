# L1-8 短期借款抵质押资产检查复核提示词

## 概述

本提示词针对短期借款抵质押资产检查表（L1-8，科目2001）的复核，聚焦抵押/质押资产的完整性、抵质押资产账面价值与借款金额的匹配、受限资产的识别与披露，以及重复担保和超额担保的识别。抵质押资产检查是识别受限资产和评估担保充分性的关键。

**法规依据：**
- 《企业会计准则第22号——金融工具确认和计量》
- 《企业会计准则第37号——金融工具列报》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **抵质押资产须逐笔与借款对应**：每笔抵押/质押借款须列示担保资产名称、账面价值、评估价值、抵质押率，与借款金额匹配。
2. **受限资产须识别并披露**：用于抵押/质押的资产（存货、固定资产、应收账款、存单等）属受限资产，须在附注中披露账面价值和受限原因。
3. **重复担保与超额担保须识别**：同一资产为多笔借款重复担保，或担保资产价值远超借款金额（超额担保），须关注商业合理性。
4. **抵质押资产权属须核实**：抵质押资产须为企业拥有且权属清晰，权属受限或存在争议的资产不能有效担保。
5. **担保状况须与合同和征信勾稽**：抵质押资产检查须与L1-6合同担保条款、L1-4征信担保记录一致。
6. **关注抵质押率异常**：抵质押率明显偏离常规（过高或过低）须评估资产估值合理性和担保有效性。

## checklist

### 一、抵质押资产完整性

- [ ] 每笔抵押/质押借款是否列示担保资产名称、账面价值、抵质押率
- [ ] 抵质押资产是否与L1-6合同担保条款一致
- [ ] 抵质押担保是否与L1-4征信担保记录勾稽
- [ ] 是否存在担保借款但未列示担保资产

### 二、受限资产识别披露

- [ ] 用于抵质押的资产是否已识别为受限资产
- [ ] 受限资产账面价值是否在附注中披露
- [ ] 受限资产受限原因和期限是否披露
- [ ] 受限资产是否与相关资产科目（存货/固定资产/应收）勾稽

### 三、担保充分性与合理性

- [ ] 是否存在同一资产重复担保多笔借款
- [ ] 是否存在担保资产价值远超借款的超额担保
- [ ] 抵质押率是否合理（无异常偏离）
- [ ] 担保资产估值是否可靠

### 四、权属核实

- [ ] 抵质押资产权属是否清晰且为企业拥有
- [ ] 是否存在权属受限或争议资产用于担保
- [ ] 抵质押登记手续是否完备

## risk_areas

### 高风险

1. **受限资产未披露**：抵质押资产未识别为受限资产或未在附注披露，误导报表使用者对资产流动性的判断。
2. **重复担保风险**：同一资产为多笔借款重复担保，担保有效性存疑。
3. **权属争议资产担保**：用于担保的资产权属受限或存在争议。
4. **担保资产估值虚高**：抵质押资产账面/评估价值虚高掩盖担保不足。

### 中风险

1. **抵质押率异常**：抵质押率明显偏离常规未评估。
2. **担保与合同不勾稽**：抵质押资产与L1-6合同担保条款不一致。
3. **超额担保未关注**：担保资产价值远超借款未分析商业合理性。

### 低风险

1. **担保资产记录不完整**：个别担保缺评估价值或抵质押率记录。
2. **抵质押登记手续瑕疵**：登记手续记录不完整。
3. **索引不完整**：抵质押检查未与合同、征信、资产科目底稿建立索引。
