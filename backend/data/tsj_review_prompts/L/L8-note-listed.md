# L8-note-listed 附注披露复核提示词（上市公司）

## 概述

本提示词针对财务费用上市公司附注披露底稿（L8-note-listed）的复核，聚焦上市公司财务报表附注中财务费用相关披露的充分性和准确性：按明细项目分类披露（利息支出/利息收入/汇兑损益/手续费及其他）、利息资本化金额披露、本期与上期可比信息以及与利润表和审定表的勾稽。财务费用附注是报表使用者了解企业融资成本和财务费用构成的主要途径。

**法规依据：**
- 《企业会计准则第17号——借款费用》
- 《企业会计准则第19号——外币折算》
- 《企业会计准则第30号——财务报表列报》
- 《公开发行证券的公司信息披露编报规则第15号——财务报告的一般规定》

---

## tips

1. **按明细项目分类披露**：财务费用须按利息支出、利息收入、汇兑损益、手续费及其他分项披露本期及上期发生额，各分项合计等于财务费用净额。
2. **利息费用与资本化金额披露**：须披露本期利息费用总额及其中资本化的利息金额（CAS17），使报表使用者了解借款费用的费用化与资本化情况。
3. **本期与上期可比**：各分项须同时列示本期和上期发生额，重大变动宜说明原因。
4. **汇兑损益披露**：汇兑损益作为财务费用组成部分须单独列示，重大汇兑损益宜说明外币敞口及汇率变动影响（CAS19）。
5. **利息收入抵减列示**：利息收入在财务费用中以负数（抵减）列示还是单独列报须符合列报要求并保持一致。
6. **闭环勾稽**：附注财务费用各分项合计须等于审定表审定数及利润表财务费用项目，资本化利息须与相关资产附注勾稽。

## checklist

### 一、分类披露检查

- [ ] 财务费用是否按利息支出/利息收入/汇兑损益/手续费及其他分项披露
- [ ] 各分项是否同时列示本期数和上期数（可比信息）
- [ ] 各分项合计是否等于财务费用净额
- [ ] 财务费用净额是否与审定表审定数及利润表一致
- [ ] 分类方式是否与会计政策一致

### 二、利息与资本化披露

- [ ] 是否披露本期利息费用总额
- [ ] 是否披露其中资本化的利息金额（CAS17）
- [ ] 资本化利息是否与相关资产附注勾稽
- [ ] 资本化率的确定是否合理披露

### 三、汇兑损益披露

- [ ] 汇兑损益是否单独列示
- [ ] 重大汇兑损益是否说明外币敞口及汇率变动影响
- [ ] 汇兑损益计算是否符合CAS19

### 四、其他披露与勾稽

- [ ] 利息收入的列示方式（抵减/单列）是否符合列报要求
- [ ] 重大变动分项是否说明原因
- [ ] 附注各分项是否与L8-2明细表勾稽
- [ ] 手续费及其他的构成是否清晰

## risk_areas

### 高风险

1. **资本化利息未披露**：未披露本期资本化利息金额，报表使用者无法了解借款费用处理，不满足CAS17披露要求。
2. **附注净额与审定表/利润表不一致**：附注财务费用净额与审定数或利润表不勾稽，数据错误。
3. **分项混列掩盖异常**：各明细项目混列或以净额笼统披露，掩盖异常项目（如大额汇兑损益）。

### 中风险

1. **汇兑损益披露不充分**：重大汇兑损益未说明外币敞口及汇率影响。
2. **可比信息缺失**：仅列示本期数据未列示上期可比数据。
3. **利息收入列示不一致**：利息收入列示方式前后期不一致。

### 低风险

1. **披露格式不规范**：分类表列序、金额单位不符编报规则。
2. **重大变动说明简略**：分项重大变动原因说明不充分。
3. **手续费构成不清**：手续费及其他构成披露笼统。
