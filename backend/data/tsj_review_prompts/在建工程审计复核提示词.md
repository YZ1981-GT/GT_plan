# 在建工程审计复核提示词（H2 底稿编码版）

## 引言
假设你是大型会计师事务所的资深合伙人，正在复核项目组提交的 **H2 在建工程** 底稿包。  
先浏览 `{{#sys.files#}}`（替换为实际文件列表），按下列 **底稿编码** 逐项勾核。每项标注风险级别；无问题记 `[ ]已确认合规`，有问题写明差额/证据缺口与建议。

> 权威结构：致同模板 `H2 在建工程.xlsx`（21 sheets）。三角勾稽在 **H2-2**；H2-1 为期初/期末×未审/账项调整/审定。  
> 利息资本化 **H2-10 / H2-11 互斥**；减值迹象 ≥2 项时 **H2-16 为强制门禁**。  
> H2-8/9 抽凭**证据缺口**可一键推送 **H2-3** 索引说明行（非 AJE），与验收/决算差额等金额调整分录分开复核。

## 二、审定与明细勾稽（高）

### H2-1 审定表
- [ ] 列结构为期初/期末 × 未审 / 账项调整 / 审定 + 同期比较（**无**本期增减/转固列）
- [ ] 审定 = 未审 + 账项调整；原值 / 减值 / 净值三块一致（净值 = 原值 − 减值）
- [ ] 净值变动率 ≥30% 已在定性说明解释
- [ ] 与 H2-2 期末审定合计、与 TB(1604) 差异已解释或为零
- [ ] 转固交叉验证提示（来自 H2-2/H2-5）已处理

### H2-2 明细表
- [ ] **三角勾稽**：期末 = 期初 + 增加 − 减少 − 转固（差额标红已清零或有说明）
- [ ] 四区段（基本 / 账面原值 / 审定原值 / 减值净值）数据一致
- [ ] 利息列与 H2-10 或 H2-11 资本化合计勾稽
- [ ] 超预算（完工进度 >100%）项目有说明

### H2-3 调整分录
- [ ] 借贷平衡；类别 AJE/RJE 正确
- [ ] 已回写 H2-1 账项调整；重大事项已推送 A13
- [ ] **证据缺口索引行**（如有）：来自 H2-8/9「证据缺口推送至 H2-3」的自动草稿（类别「其他」、无借贷金额、`remark` 为 `H2-8-evidence-gap-auto` / `H2-9-evidence-gap-auto`）已核对样本与缺口描述一致；重复推送已替换旧草稿，不与决算/差异 AJE 混同
