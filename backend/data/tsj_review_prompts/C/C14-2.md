# C14-2 租赁循环-评价控制偏差 复核提示词

## 概述

本提示词针对租赁循环控制测试的偏差评价（C14-2）的复核，聚焦租赁循环关键控制点——租赁合同审批与识别、租赁分类判断、使用权资产与租赁负债初始计量复核、租赁付款与折现率确定、租赁变更处理——的控制偏差识别、偏差性质判断、偏差率外推、缺陷分级及对使用权资产与租赁负债实质性程序的影响（CAS1231、CAS1314、CAS1211）。新租赁准则下租赁涉及使用权资产、租赁负债、折旧与利息费用多重认定，租赁识别与初始计量控制的偏差直接影响资产负债的完整性与计价准确性。

**法规依据：**
- 《中国注册会计师审计准则第1231号——针对评估的重大错报风险采取的应对措施》
- 《中国注册会计师审计准则第1314号——审计抽样》
- 《中国注册会计师审计准则第1211号——通过了解被审计单位及其环境识别和评估重大错报风险》

## tips

1. **租赁识别控制偏差影响资产负债完整性**：合同是否包含租赁、是否适用简化处理（短期/低价值）的识别控制偏差，直接决定使用权资产与租赁负债的完整确认，是租赁循环偏差评价核心。
2. **初始计量复核偏差影响计价**：租赁负债现值、使用权资产初始成本计算复核控制的偏差影响初始计量准确性，须评估折现率与租赁期确定的合理性。
3. **折现率确定控制偏差系统性影响**：增量借款利率/租赁内含利率确定控制的偏差通常系统性影响多项租赁的负债现值与利息费用，须评估累积影响。
4. **租赁期判断偏差影响计量范围**：续租、终止选择权评估控制的偏差影响租赁期确定，进而影响使用权资产与租赁负债的计量。
5. **租赁变更处理偏差影响后续计量**：租赁变更、重估的会计处理复核控制偏差影响使用权资产与租赁负债的后续计量准确性。
6. **缺陷分级决定租赁程序范围**：租赁识别或初始计量控制重大缺陷时，须扩大租赁合同全面梳理、初始计量重算、折现率合理性复核的实质性程序范围。

## checklist

### 一、控制偏差识别（租赁循环专属）

- [ ] 租赁合同审批与租赁识别控制偏差是否识别（合同是否含租赁的判断）
- [ ] 简化处理（短期租赁/低价值资产租赁）适用判断控制偏差是否识别
- [ ] 使用权资产与租赁负债初始计量复核控制偏差是否识别
- [ ] 折现率（增量借款利率/内含利率）确定控制偏差是否识别
- [ ] 租赁期（续租/终止选择权）判断控制偏差是否识别
- [ ] 租赁付款与租赁负债后续计量控制偏差是否识别
- [ ] 租赁变更/重估处理控制偏差是否识别

### 二、偏差性质与根本原因

- [ ] 每项偏差是否评价为偶发例外还是系统性控制失效
- [ ] 折现率/租赁期判断类偏差是否评估系统性计量影响
- [ ] 偏差是否影响使用权资产/租赁负债的完整确认或计价
- [ ] 偏差根本原因是否分析（识别标准缺失/计量复核缺位/参数错误）

### 三、偏差率外推与评价

- [ ] 样本偏差率是否正确计算并外推总体偏差率
- [ ] 偏差影响的认定维度是否明确（完整性/计价/后续计量）
- [ ] 外推总体偏差率是否与可容忍偏差率比较
- [ ] 重大租赁合同的控制例外是否单独评估

### 四、缺陷分级与影响

- [ ] 偏差导致的缺陷是否按控制缺陷/值得关注缺陷/重大缺陷分级
- [ ] 缺陷是否评估了对使用权资产/租赁负债/折旧/利息费用的影响
- [ ] 控制不可信赖时是否扩大合同梳理、初始计量重算、折现率复核
- [ ] 重大缺陷是否已沟通治理层与管理层

## risk_areas

### 高风险

1. **租赁识别控制系统性失效**：合同含租赁的识别偏差系统性发生却被评为偶发，使用权资产与租赁负债漏确认，资产负债完整性存疑。
2. **初始计量复核缺陷影响计价**：初始计量复核控制偏差未评估对使用权资产与租赁负债计价准确性影响。
3. **缺陷分级偏低未扩大实质性程序**：租赁控制重大缺陷未触发合同梳理与初始计量重算扩大，租赁错报检查风险失控。
4. **折现率系统性偏差**：折现率确定控制偏差系统性影响多项租赁负债现值却未评估累积影响。

### 中风险

1. **简化处理判断偏差影响确认未评估**：短期/低价值简化处理适用判断偏差未评估对资产负债确认影响。
2. **租赁期判断偏差影响计量未评估**：续租/终止选择权评估偏差未评估对计量范围影响。
3. **租赁变更处理偏差影响后续计量未评估**：变更/重估处理偏差未评估对后续计量准确性影响。

### 低风险

1. **偏差记录不规范**：偏差类型、涉及租赁合同、金额记录格式不统一。
2. **抽样参数留痕不足**：样本量、可容忍偏差率、预计偏差率记录不完整。
3. **底稿索引缺失**：C14-2 与租赁控制测试底稿、使用权资产/租赁负债审定表、初始计量与折现率底稿缺乏交叉索引。
