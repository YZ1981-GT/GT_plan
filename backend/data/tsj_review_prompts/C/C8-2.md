# C8-2 无形资产及其他长期资产循环-评价控制偏差 复核提示词

## 概述

本提示词针对无形资产及其他长期资产循环控制测试的偏差评价（C8-2）的复核，聚焦该循环关键控制点——无形资产取得审批、摊销计提复核、减值评估复核、长期待摊费用摊销、资本化条件判断——的控制偏差识别、偏差性质判断、偏差率外推、缺陷分级及对无形资产及其他长期资产实质性程序的影响（CAS1231、CAS1314、CAS1211）。无形资产涉及取得成本、摊销、减值多重认定，取得审批与减值评估控制的偏差影响存在性、计价与减值充分性。

**法规依据：**
- 《中国注册会计师审计准则第1231号——针对评估的重大错报风险采取的应对措施》
- 《中国注册会计师审计准则第1314号——审计抽样》
- 《中国注册会计师审计准则第1211号——通过了解被审计单位及其环境识别和评估重大错报风险》

## tips

1. **无形资产取得审批偏差影响资本化合规**：外购/自研无形资产取得未经审批或资本化条件不符的偏差影响入账价值真实性，偏差评价须审视资本化的授权与依据。
2. **摊销计提控制偏差系统性影响费用**：摊销年限、方法设置与计提复核控制的偏差通常系统性影响多期摊销费用，须评估对累计摊销与损益的传导。
3. **减值评估控制偏差影响计价**：无形资产（尤其使用寿命不确定的无形资产须每年减值测试）减值迹象评估与测试复核控制的偏差影响计价认定。
4. **长期待摊费用摊销控制偏差影响期间损益**：长期待摊费用的摊销期间与金额复核控制偏差影响各期损益的准确性。
5. **资本化与费用化划分偏差影响损益**：研发支出、软件购置等资本化与费用化划分控制的偏差影响资产与费用的准确性（研发另见 C9-2）。
6. **缺陷分级决定无形资产程序范围**：取得/摊销/减值控制重大缺陷时，须扩大取得凭证核对、摊销重算、减值复核的实质性程序范围。

## checklist

### 一、控制偏差识别（无形资产及其他长期资产循环专属）

- [ ] 无形资产取得（外购/自研）审批控制偏差是否识别
- [ ] 无形资产资本化条件判断控制偏差是否识别
- [ ] 摊销（年限/方法）计提复核控制偏差是否识别
- [ ] 无形资产减值迹象评估与减值测试复核控制偏差是否识别
- [ ] 长期待摊费用摊销期间与金额复核控制偏差是否识别
- [ ] 其他长期资产（如长期股权投资以外）确认与后续计量控制偏差是否识别

### 二、偏差性质与根本原因

- [ ] 每项偏差是否评价为偶发例外还是系统性控制失效
- [ ] 摊销参数类偏差是否评估其系统性跨期影响
- [ ] 偏差根本原因是否分析（审批缺陷/参数错误/复核缺位）
- [ ] 偏差是否影响无形资产存在性、计价或摊销准确性

### 三、偏差率外推与评价

- [ ] 样本偏差率是否正确计算并外推总体偏差率
- [ ] 偏差影响的认定维度是否明确（存在/计价/摊销/减值）
- [ ] 外推总体偏差率是否与可容忍偏差率比较
- [ ] 系统性摊销偏差是否单独评估其累积金额影响

### 四、缺陷分级与影响

- [ ] 偏差导致的缺陷是否按控制缺陷/值得关注缺陷/重大缺陷分级
- [ ] 缺陷是否评估了对无形资产计价/摊销/减值/损益的影响
- [ ] 控制不可信赖时是否扩大取得核对、摊销重算、减值复核范围
- [ ] 重大缺陷是否已沟通治理层与管理层

## risk_areas

### 高风险

1. **取得审批控制系统性失效**：无形资产取得未审批或资本化条件不符偏差被评为偶发，入账价值真实性存疑。
2. **减值评估控制缺陷影响计价**：减值测试复核控制偏差未评估对计价可靠性传导，无形资产高估风险未被识别。
3. **缺陷分级偏低未扩大实质性程序**：无形资产控制重大缺陷未触发取得核对与减值复核扩大，无形资产错报检查风险失控。
4. **摊销系统性偏差**：摊销参数控制偏差系统性影响多期费用却未评估累积金额影响。

### 中风险

1. **资本化费用化划分偏差影响损益未评估**：资本化与费用化划分偏差未评估对损益影响。
2. **长期待摊费用摊销偏差被忽视**：长期待摊费用摊销期间/金额偏差未评估对期间损益影响。
3. **偏差根本原因未析**：偏差仅记笔数未分析原因，无法判断偶发或系统性。

### 低风险

1. **偏差记录不规范**：偏差类型、涉及资产项目、金额记录格式不统一。
2. **抽样参数留痕不足**：样本量、可容忍偏差率、预计偏差率记录不完整。
3. **底稿索引缺失**：C8-2 与无形资产控制测试底稿、无形资产审定表、摊销与减值底稿缺乏交叉索引。
