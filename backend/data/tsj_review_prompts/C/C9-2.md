# C9-2 研发循环-评价控制偏差 复核提示词

## 概述

本提示词针对研发循环控制测试的偏差评价（C9-2）的复核，聚焦研发循环关键控制点——研发项目立项审批、研究阶段与开发阶段划分、开发支出资本化条件判断、研发费用归集与分配、资本化开发支出的后续处理——的控制偏差识别、偏差性质判断、偏差率外推、缺陷分级及对研发支出实质性程序的影响（CAS1231、CAS1314、CAS1211）。研发支出资本化涉及重大判断，研究与开发阶段划分及资本化条件控制的偏差直接影响费用化与资本化的划分准确性，进而影响损益与资产。

**法规依据：**
- 《中国注册会计师审计准则第1231号——针对评估的重大错报风险采取的应对措施》
- 《中国注册会计师审计准则第1314号——审计抽样》
- 《中国注册会计师审计准则第1211号——通过了解被审计单位及其环境识别和评估重大错报风险》

## tips

1. **研究与开发阶段划分偏差直击资本化合规**：研究阶段应费用化、开发阶段满足条件方可资本化，阶段划分控制的偏差直接决定资本化的合规性，是研发循环偏差评价核心。
2. **资本化条件判断偏差影响损益与资产**：五项资本化条件（技术可行性、意图、能力、经济利益、可靠计量）判断复核控制的偏差可能导致不当资本化虚增资产、虚减费用。
3. **研发费用归集分配偏差影响准确性**：人工、材料、间接费用归集至具体研发项目的分配控制偏差影响费用归集准确性，须评估分配依据合理性。
4. **资本化时点偏差影响期间划分**：满足资本化条件的时点确认控制偏差影响费用化与资本化金额在期间的划分。
5. **研发加计扣除关联税务**：研发费用归集控制偏差还可能传导至研发费用加计扣除的税务处理（联动 C12-2 税金循环）。
6. **缺陷分级决定研发程序范围**：阶段划分或资本化条件控制重大缺陷时，须扩大研发项目文档核对、资本化条件独立评估、费用归集测试的实质性程序范围。

## checklist

### 一、控制偏差识别（研发循环专属）

- [ ] 研发项目立项审批控制偏差是否识别（未审批立项）
- [ ] 研究阶段与开发阶段划分控制偏差是否识别
- [ ] 开发支出资本化条件（五项条件）判断复核控制偏差是否识别
- [ ] 研发费用归集与分配（人工/材料/间接费用）控制偏差是否识别
- [ ] 资本化时点确认控制偏差是否识别
- [ ] 资本化开发支出转无形资产的时点与金额控制偏差是否识别

### 二、偏差性质与根本原因

- [ ] 每项偏差是否评价为偶发例外还是系统性控制失效
- [ ] 阶段划分/资本化条件偏差是否评估其对资本化金额的影响
- [ ] 偏差根本原因是否分析（判断标准缺失/复核缺位/归集依据不当）
- [ ] 偏差是否影响研发支出费用化/资本化划分或损益准确性

### 三、偏差率外推与评价

- [ ] 样本偏差率是否正确计算并外推总体偏差率
- [ ] 偏差影响的认定维度是否明确（资本化/费用化/损益）
- [ ] 外推总体偏差率是否与可容忍偏差率比较
- [ ] 重大研发项目的资本化控制例外是否单独评估

### 四、缺陷分级与影响

- [ ] 偏差导致的缺陷是否按控制缺陷/值得关注缺陷/重大缺陷分级
- [ ] 缺陷是否评估了对资本化金额/研发费用/损益/加计扣除的影响
- [ ] 控制不可信赖时是否扩大项目文档核对、资本化条件评估、费用归集测试
- [ ] 重大缺陷是否已沟通治理层与管理层

## risk_areas

### 高风险

1. **阶段划分控制系统性失效**：研究与开发阶段划分偏差系统性发生却被评为偶发，不当资本化虚增资产虚减费用风险未被应对。
2. **资本化条件判断缺陷**：五项资本化条件复核控制偏差未评估对资本化金额的影响，损益与资产错报风险未被识别。
3. **缺陷分级偏低未扩大实质性程序**：研发控制重大缺陷未触发资本化条件评估与文档核对扩大，研发支出错报检查风险失控。
4. **不当资本化操纵损益**：阶段划分偏差可能被用于跨期操纵损益，须警惕系统性倾向。

### 中风险

1. **费用归集分配偏差影响准确性**：研发费用归集至项目的分配偏差未评估对费用准确性影响。
2. **加计扣除税务传导未评估**：研发费用归集偏差未评估对研发加计扣除税务处理的传导。
3. **资本化时点偏差影响期间划分**：资本化时点确认偏差未评估对期间费用化/资本化划分影响。

### 低风险

1. **偏差记录不规范**：偏差类型、涉及研发项目、金额记录格式不统一。
2. **抽样参数留痕不足**：样本量、可容忍偏差率、预计偏差率记录不完整。
3. **底稿索引缺失**：C9-2 与研发控制测试底稿、研发支出审定表、资本化条件评估与费用归集底稿缺乏交叉索引。
