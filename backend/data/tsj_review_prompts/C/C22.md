# C22 IT一般控制测试（ITGC） 复核提示词

## 概述

本提示词针对 IT 一般控制测试（C22）的复核，聚焦四大 ITGC 领域——访问安全、变更管理、系统运行、系统开发——的控制识别、测试样本与方法、运行有效性结论、以及 ITGC 缺陷对自动化应用控制信赖的传导影响（CAS1211 附录 IT 控制、CAS1231、CAS1314）。ITGC 是自动化应用控制得以持续有效运行的基础，一般控制失效会削弱对所有依赖该 IT 环境的应用控制的信赖。

**法规依据：**
- 《中国注册会计师审计准则第1211号——通过了解被审计单位及其环境识别和评估重大错报风险》（附录：信息技术控制）
- 《中国注册会计师审计准则第1231号——针对评估的重大错报风险采取的应对措施》
- 《中国注册会计师审计准则第1314号——审计抽样》

## tips

1. **四大领域须全覆盖**：访问安全、变更管理、系统运行、系统开发四类 ITGC 均须识别并测试，任一领域缺失都会形成 IT 控制评价盲区。
2. **访问安全是 ITGC 的核心**：用户权限授予/回收、职责分离、特权账户管理、密码策略是访问控制测试重点，权限失控会使一切应用控制可被绕过。
3. **变更管理防止未授权程序改动**：程序变更须经申请、测试、审批、上线的完整流程，未受控变更会破坏已测试的自动化控制。
4. **ITGC 测试样本须匹配控制频率与自动化程度**：配置类控制可测单笔加验证配置稳定性，事件驱动控制（如变更、权限变动）须按发生笔数抽样。
5. **ITGC 有效是应用控制可信赖的前提**：只有在 ITGC 运行有效时，才能对自动化应用控制仅测试单笔即给予信赖，ITGC 缺陷会连带削弱应用控制信赖。
6. **系统开发控制关注新系统与重大升级**：本期上线的新系统或重大升级须评价其开发、迁移、测试、上线控制，数据迁移完整性尤为关键。

## checklist

### 一、访问安全控制

- [ ] 用户权限授予/变更/回收是否经恰当审批
- [ ] 是否测试了职责分离（如开发与运行、录入与审批权限分离）
- [ ] 特权账户（系统管理员/数据库管理员）是否受控并定期复核
- [ ] 离职/调岗人员的系统权限是否及时回收
- [ ] 密码策略、账户锁定、登录日志等身份认证控制是否有效
- [ ] 是否定期执行用户权限复核并保留证据

### 二、变更管理控制

- [ ] 程序变更是否经申请-测试-审批-上线完整流程
- [ ] 变更是否在投产前经用户测试和授权批准
- [ ] 是否存在未经审批的紧急变更及其事后补审机制
- [ ] 开发环境与生产环境是否隔离
- [ ] 变更上线是否由独立于开发的人员执行

### 三、系统运行控制

- [ ] 数据备份是否定期执行并测试恢复有效性
- [ ] 批处理作业调度是否受控、异常是否监控处理
- [ ] 系统故障/中断是否有应急与恢复机制
- [ ] 接口数据传输的完整性与准确性是否有控制

### 四、系统开发控制

- [ ] 本期新上线系统/重大升级是否纳入测试范围
- [ ] 系统开发是否遵循规范流程（需求-设计-开发-测试-上线）
- [ ] 数据迁移的完整性与准确性是否经验证
- [ ] 新系统上线前是否经用户验收测试

### 五、测试方法与结论

- [ ] ITGC 测试样本量是否与控制频率和自动化程度匹配
- [ ] 测试期间是否覆盖整个拟信赖期间
- [ ] 每项 ITGC 的运行有效性结论是否有充分证据支持
- [ ] ITGC 缺陷是否已汇总至 C21-1 并评价对应用控制的影响

## risk_areas

### 高风险

1. **访问权限失控**：权限授予无审批、离职人员权限未回收、职责分离缺失，使自动化控制可被绕过，一切应用控制信赖丧失基础。
2. **变更未受控**：程序变更未经测试审批即上线，破坏了已测试的自动化控制配置，导致控制测试结论失效。
3. **ITGC 缺陷未传导应用控制**：一般控制失效却仍对依赖该系统的自动化应用控制给予单笔信赖，检查风险失控。
4. **四大领域覆盖缺失**：系统运行或开发领域未测试，重大 IT 风险（数据丢失、迁移错误）未被识别。

### 中风险

1. **特权账户管理松散**：管理员/数据库特权账户共享或未定期复核，权限滥用无法被发现。
2. **样本量与频率不匹配**：变更或权限变动类事件驱动控制未按发生笔数抽样，测试范围不足。
3. **测试期间覆盖不全**：仅测试期中 ITGC 而未覆盖期末，无法证明整个拟信赖期间持续有效。
4. **数据迁移验证不足**：新系统上线数据迁移完整性未经验证，期初余额可靠性存疑。

### 低风险

1. **备份恢复未实测**：有备份制度但未测试恢复有效性，无法确认备份可用。
2. **日志留存不完整**：登录、变更等日志留存期不足或未定期审阅，影响追溯。
3. **底稿索引缺失**：C22 测试底稿与 C21-1、应用控制底稿、相关业务循环底稿缺乏交叉索引。
