# C4-2 存货循环-评价控制偏差 复核提示词

## 概述

本提示词针对存货循环控制测试的偏差评价（C4-2）的复核，聚焦存货循环关键控制点——出入库审批与记录、存货盘点、成本核算与结转、存货跌价评估——的控制偏差识别、偏差性质判断、偏差率外推、缺陷分级及对存货实质性程序的影响（CAS1231、CAS1314、CAS1211）。存货涉及数量、成本、跌价多重认定，出入库与盘点控制的偏差直接影响存货存在性与计价准确性，成本结转控制偏差还会传导至营业成本。

**法规依据：**
- 《中国注册会计师审计准则第1231号——针对评估的重大错报风险采取的应对措施》
- 《中国注册会计师审计准则第1314号——审计抽样》
- 《中国注册会计师审计准则第1211号——通过了解被审计单位及其环境识别和评估重大错报风险》

## tips

1. **出入库控制偏差影响存货数量真实性**：入库验收、出库审批、领料记录控制的偏差直接关联存货账实差异，偏差评价须审视数量记录的完整准确。
2. **盘点控制偏差决定存在性信赖**：盘点计划、监盘、盘点差异调查处理控制的偏差若系统性发生，将削弱对存货存在性的信赖，须扩大监盘范围。
3. **成本核算控制偏差传导营业成本**：成本归集、分配、结转控制的偏差不仅影响存货计价，还直接影响营业成本与毛利率，须联动评估。
4. **跌价评估控制偏差影响计价**：存货可变现净值评估、跌价准备计提审批控制的偏差影响存货计价认定，须评估对跌价充分性的传导。
5. **偏差外推须区分数量与金额维度**：存货控制偏差可能表现为数量记录偏差或成本金额偏差，外推评价须明确偏差影响的认定维度。
6. **缺陷分级决定监盘与计价程序范围**：出入库或盘点控制重大缺陷时，须扩大实地监盘、盘点结果核对、成本测试与跌价复核的实质性程序范围。

## checklist

### 一、控制偏差识别（存货循环专属）

- [ ] 入库验收控制偏差是否识别（未验收即入账/数量不符）
- [ ] 出库/领料审批控制偏差是否识别（未审批出库）
- [ ] 存货盘点控制偏差是否识别（盘点未监督/差异未调查处理）
- [ ] 成本核算归集与结转控制偏差是否识别
- [ ] 存货跌价评估与计提审批控制偏差是否识别
- [ ] 存货收发存永续盘存记录准确性控制偏差是否识别

### 二、偏差性质与根本原因

- [ ] 每项偏差是否评价为偶发例外还是系统性控制失效
- [ ] 偏差是否集中于特定仓库/品类/时段（系统性迹象）
- [ ] 偏差根本原因是否分析（流程缺陷/记录滞后/人为调整）
- [ ] 偏差是否影响存货存在性、完整性或计价认定的判断

### 三、偏差率外推与评价

- [ ] 样本偏差率是否正确计算并外推总体偏差率
- [ ] 偏差影响的认定维度（数量/成本金额）是否明确
- [ ] 外推总体偏差率是否与可容忍偏差率比较
- [ ] 是否考虑抽样风险对偏差评价的影响

### 四、缺陷分级与影响

- [ ] 偏差导致的缺陷是否按控制缺陷/值得关注缺陷/重大缺陷分级
- [ ] 缺陷是否评估了对存货存在性/计价/营业成本的影响
- [ ] 控制不可信赖时是否扩大实地监盘、成本测试、跌价复核范围
- [ ] 重大缺陷是否已沟通治理层与管理层

## risk_areas

### 高风险

1. **盘点控制系统性失效**：盘点差异未调查处理的偏差系统性发生却被评为偶发，存货存在性信赖失去基础，监盘范围未扩大。
2. **成本结转控制缺陷传导营业成本**：成本核算控制偏差未评估对营业成本与毛利率的影响，成本错报风险未被应对。
3. **缺陷分级偏低未扩大实质性程序**：出入库控制重大缺陷被误评为一般缺陷，监盘与成本测试范围未扩大，存货错报检查风险失控。
4. **跌价评估控制失效影响计价**：跌价评估审批偏差未传导评估跌价准备充分性，存货高估风险未被识别。

### 中风险

1. **出入库偏差根本原因未析**：出入库记录偏差仅记笔数未分析原因，无法判断偶发或系统性。
2. **偏差认定维度不清**：偏差影响数量还是成本金额未明确，外推评价口径混乱。
3. **偏差集中性未分析**：偏差是否集中于特定仓库/品类未分析，系统性迹象被忽略。

### 低风险

1. **偏差记录不规范**：偏差类型、涉及仓库/品类、数量金额记录格式不统一。
2. **抽样参数留痕不足**：样本量、可容忍偏差率、预计偏差率记录不完整。
3. **底稿索引缺失**：C4-2 与存货控制测试底稿、存货审定表、监盘底稿、成本测试底稿缺乏交叉索引。
