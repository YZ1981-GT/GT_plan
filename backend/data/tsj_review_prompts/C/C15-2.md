# C15-2 关联方循环-评价控制偏差 复核提示词

## 概述

本提示词针对关联方循环控制测试的偏差评价（C15-2）的复核，聚焦关联方循环关键控制点——关联方识别与清单维护、关联交易审批、关联交易定价（公允性）审批、关联交易识别与记录、关联方及关联交易披露复核——的控制偏差识别、偏差性质判断、偏差率外推、缺陷分级及对关联方交易实质性程序的影响（CAS1231、CAS1314、CAS1141）。关联方交易是舞弊与利益输送高发领域，关联方识别与交易审批控制的偏差直接关联未披露关联方、不公允定价及利益输送风险。

**法规依据：**
- 《中国注册会计师审计准则第1231号——针对评估的重大错报风险采取的应对措施》
- 《中国注册会计师审计准则第1314号——审计抽样》
- 《中国注册会计师审计准则第1141号——财务报表审计中与舞弊相关的责任》

## tips

1. **关联方识别控制偏差直击未披露风险**：关联方清单识别、维护、更新控制的偏差可能导致未识别关联方及其交易被当作第三方处理，是关联方循环偏差评价核心，须警惕隐匿关联关系。
2. **关联交易审批偏差关联利益输送**：关联交易决策审批、回避表决控制的偏差可能掩盖利益输送，须审慎判断是否系统性规避审批。
3. **定价公允性审批偏差影响交易真实性**：关联交易定价（对比市场价/成本加成）审批复核控制的偏差影响交易公允性，须评估对损益操纵的传导。
4. **交易识别与记录偏差影响完整性**：将关联交易错误标识为普通交易或未按关联交易记录的控制偏差影响关联交易的完整识别，直接影响披露完整性。
5. **披露复核偏差影响披露充分性**：关联方关系与交易披露复核控制的偏差影响财务报表附注披露的完整准确，须评估对披露认定的影响。
6. **缺陷分级决定关联方程序范围**：识别或审批控制重大缺陷时，须扩大关联方检索、交易全面梳理、定价公允性核查与披露完整性复核的实质性程序范围。

## checklist

### 一、控制偏差识别（关联方循环专属）

- [ ] 关联方清单识别与维护更新控制偏差是否识别
- [ ] 关联交易决策审批与回避表决控制偏差是否识别
- [ ] 关联交易定价（公允性）审批复核控制偏差是否识别
- [ ] 关联交易识别与记录（标识）控制偏差是否识别
- [ ] 关联方资金往来与担保审批控制偏差是否识别
- [ ] 关联方及关联交易披露复核控制偏差是否识别

### 二、偏差性质与根本原因

- [ ] 每项偏差是否评价为偶发例外还是系统性控制失效
- [ ] 偏差是否呈现隐匿关联关系/利益输送/不公允定价的舞弊迹象
- [ ] 偏差是否集中于特定关联方或特定交易类型（系统性迹象）
- [ ] 偏差根本原因是否分析（识别机制缺失/审批规避/披露复核缺位）

### 三、偏差率外推与评价

- [ ] 样本偏差率是否正确计算并外推总体偏差率
- [ ] 偏差影响的认定维度是否明确（完整性/披露/公允性）
- [ ] 外推总体偏差率是否与可容忍偏差率比较
- [ ] 单笔重大关联交易的控制例外是否单独评估

### 四、缺陷分级与影响

- [ ] 偏差导致的缺陷是否按控制缺陷/值得关注缺陷/重大缺陷分级
- [ ] 缺陷是否评估了对关联交易完整性/披露充分性/定价公允性的影响
- [ ] 控制不可信赖时是否扩大关联方检索、交易梳理、定价核查、披露复核
- [ ] 重大缺陷及舞弊迹象是否已按 CAS1141 升级并沟通治理层

## risk_areas

### 高风险

1. **关联方识别控制系统性失效**：关联方识别/维护控制偏差系统性发生却被评为偶发，未披露关联方及其交易风险未被应对。
2. **关联交易审批规避利益输送**：交易审批/回避表决控制偏差未评估对利益输送舞弊的影响，被隐匿的关联交易未被识别。
3. **缺陷分级偏低未扩大实质性程序**：关联方控制重大缺陷未触发关联方检索与交易梳理扩大，关联交易披露与公允性错报检查风险失控。
4. **舞弊迹象未升级**：偏差呈现隐匿关联关系/不公允定价迹象却未按 CAS1141 升级评估。

### 中风险

1. **定价公允性偏差影响损益未评估**：定价审批偏差未评估对交易公允性与损益操纵的传导。
2. **交易识别记录偏差影响完整性未评估**：关联交易被错标为普通交易的偏差未评估对识别完整性影响。
3. **披露复核偏差影响披露充分性未评估**：披露复核偏差未评估对附注披露完整准确影响。

### 低风险

1. **偏差记录不规范**：偏差类型、涉及关联方、交易金额记录格式不统一。
2. **抽样参数留痕不足**：样本量、可容忍偏差率、预计偏差率记录不完整。
3. **底稿索引缺失**：C15-2 与关联方控制测试底稿、关联方交易审定/披露底稿、关联方检索底稿缺乏交叉索引。
