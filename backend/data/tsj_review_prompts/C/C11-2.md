# C11-2 管理循环-评价控制偏差 复核提示词

## 概述

本提示词针对管理循环（采购付款、费用报销及日常管理）控制测试的偏差评价（C11-2）的复核，聚焦管理循环关键控制点——采购申请与供应商审批、采购订单与验收匹配、费用报销审批、付款审批与职责分离、预算控制——的控制偏差识别、偏差性质判断、偏差率外推、缺陷分级及对相关科目实质性程序的影响（CAS1231、CAS1314、CAS1141）。管理循环覆盖采购付款与费用报销，涉及应付账款完整性、管理/销售费用准确性，采购审批与费用报销控制的偏差直接关联虚假采购、虚报费用等舞弊风险。

**法规依据：**
- 《中国注册会计师审计准则第1231号——针对评估的重大错报风险采取的应对措施》
- 《中国注册会计师审计准则第1314号——审计抽样》
- 《中国注册会计师审计准则第1141号——财务报表审计中与舞弊相关的责任》

## tips

1. **采购审批与供应商准入偏差关联虚假采购**：采购申请审批、供应商准入审批控制的偏差可能掩盖虚假采购或关联方利益输送，偏差评价须警惕供应商异常。
2. **三单匹配偏差影响采购真实性**：采购订单、验收单、发票三单匹配控制的偏差直接关联无实物采购入账风险，须审视匹配的完整性。
3. **费用报销审批偏差关联虚报费用**：费用报销单据审批、报销标准控制的偏差是虚报费用、套取资金的高危信号，须审慎判断系统性。
4. **付款审批与职责分离偏差是核心缺陷**：付款审批、请款与付款职责分离控制的偏差为资金套取创造条件，即使少量偏差也须关注。
5. **预算控制偏差影响费用合规**：超预算支出未经审批的偏差影响费用发生的合规性，须评估预算控制的约束有效性。
6. **缺陷分级决定应付与费用程序范围**：采购/报销/付款控制重大缺陷时，须扩大采购函证、费用凭证检查、供应商核对与应付账款截止测试的实质性程序范围。

## checklist

### 一、控制偏差识别（管理循环专属）

- [ ] 采购申请审批控制偏差是否识别（未审批即采购）
- [ ] 供应商准入/名录管理控制偏差是否识别
- [ ] 采购订单-验收单-发票三单匹配控制偏差是否识别
- [ ] 费用报销单据审批与标准控制偏差是否识别
- [ ] 付款审批控制偏差是否识别（未审批/超权限付款）
- [ ] 请款与付款职责分离控制偏差是否识别
- [ ] 预算控制（超预算审批）偏差是否识别

### 二、偏差性质与根本原因

- [ ] 每项偏差是否评价为偶发例外还是系统性控制失效
- [ ] 偏差是否呈现虚假采购/虚报费用/利益输送的舞弊迹象
- [ ] 偏差是否集中于特定供应商/报销人/时段（系统性迹象）
- [ ] 偏差根本原因是否分析（审批缺陷/匹配缺失/职责未分离）

### 三、偏差率外推与评价

- [ ] 样本偏差率是否正确计算并外推总体偏差率
- [ ] 偏差影响的认定维度是否明确（完整性/准确性/发生）
- [ ] 外推总体偏差率是否与可容忍偏差率比较
- [ ] 是否考虑抽样风险对偏差评价的影响

### 四、缺陷分级与影响

- [ ] 偏差导致的缺陷是否按控制缺陷/值得关注缺陷/重大缺陷分级
- [ ] 缺陷是否评估了对应付账款完整性/管理费用准确性的影响
- [ ] 控制不可信赖时是否扩大采购函证、费用凭证检查、截止测试
- [ ] 重大缺陷及舞弊迹象是否已按 CAS1141 升级并沟通治理层

## risk_areas

### 高风险

1. **采购审批控制系统性失效**：采购申请/供应商准入审批偏差集中于特定供应商却被评为偶发，虚假采购或利益输送风险未被应对。
2. **付款审批与职责分离缺陷**：付款超权限或请款付款不分离偏差未评为重大缺陷，资金套取风险未被应对。
3. **缺陷分级偏低未扩大实质性程序**：管理循环控制重大缺陷未触发采购函证与费用凭证检查扩大，应付与费用错报检查风险失控。
4. **舞弊迹象未升级**：偏差呈现虚报费用/虚假采购迹象却未按 CAS1141 升级评估。

### 中风险

1. **三单匹配偏差影响采购真实性未评估**：三单不匹配偏差未评估对无实物采购入账风险影响。
2. **费用报销偏差被忽视**：报销审批偏差未评估对费用准确性与套取风险影响。
3. **预算控制偏差影响合规未评估**：超预算未审批偏差未评估对费用发生合规性影响。

### 低风险

1. **偏差记录不规范**：偏差类型、涉及供应商/部门、金额记录格式不统一。
2. **抽样参数留痕不足**：样本量、可容忍偏差率、预计偏差率记录不完整。
3. **底稿索引缺失**：C11-2 与管理循环控制测试底稿、应付账款/费用审定表、采购与费用凭证检查底稿缺乏交叉索引。
