# C1 企业层面控制测试程序表 复核提示词

## 概述

本提示词针对企业层面控制测试程序表（C1）的复核，聚焦 COSO 五要素（控制环境、风险评估、控制活动、信息与沟通、监督）的识别、穿行测试与运行有效性评价。企业层面控制是内部控制的顶层设计，直接影响对业务流程层面控制的信赖程度与实质性程序的性质、时间和范围。复核须验证控制识别的完整性、测试证据的充分性、控制运行有效性结论的可靠性，以及缺陷分级对整体审计策略的影响。

**法规依据：**
- 《中国注册会计师审计准则第1211号——通过了解被审计单位及其环境识别和评估重大错报风险》
- 《中国注册会计师审计准则第1231号——针对评估的重大错报风险采取的应对措施》
- 《中国注册会计师审计准则第1314号——审计抽样》

## tips

1. **企业层面控制决定信赖基调**：控制环境薄弱（如管理层凌驾、治理层缺位）会削弱对所有业务流程控制的信赖，复核须首先评价控制环境的整体有效性再看具体控制。
2. **COSO 五要素须逐项覆盖不得遗漏**：控制环境、风险评估、控制活动、信息与沟通、监督五要素均须识别对应控制点并测试，任一要素缺失识别都属重大覆盖缺口。
3. **穿行测试验证设计有效性，控制测试验证运行有效性**：两者目的不同不可混同，穿行仅证明控制被理解和恰当设计，运行有效性须通过样本测试跨期间证明控制持续执行。
4. **企业层面控制多为间接控制**：企业层面控制往往不直接防止或发现认定层次错报，复核须评估其对业务流程层面控制测试范围的影响（信赖程度越高，实质性程序可越少）。
5. **管理层凌驾于控制之上是必测领域**：即使企业层面控制运行良好，也须始终关注管理层凌驾风险（CAS1141），并与会计分录测试（C23）联动评估。
6. **控制运行有效性结论须与缺陷分级一致**：若测试发现偏差，须评价是控制缺陷、值得关注的缺陷还是重大缺陷，并据此调整对下游业务循环控制信赖的策略。

## checklist

### 一、控制识别与穿行测试

- [ ] 是否针对 COSO 五要素分别识别了企业层面控制点
- [ ] 控制环境要素（诚信与道德价值观、治理层监督、组织结构、胜任能力、问责机制）是否完整评价
- [ ] 风险评估要素（目标设定、风险识别、舞弊风险考虑、变化管理）是否覆盖
- [ ] 每项识别的控制是否执行穿行测试以确认设计有效性
- [ ] 穿行测试是否追踪一笔交易/事项完整流经该控制的路径
- [ ] 控制设计缺陷（设计不当/缺失）是否已识别并记录

### 二、控制测试样本与频率

- [ ] 控制测试样本量是否与控制执行频率匹配（日常控制/周期控制/年度控制）
- [ ] 样本量是否符合 CAS1314 控制测试抽样要求
- [ ] 自动化控制是否采用测试单笔加验证 ITGC 的方式（而非属性抽样）
- [ ] 测试期间是否覆盖整个拟信赖期间（含期中至期末的滚动更新）
- [ ] 样本选取是否具有代表性（未仅选取无异常期间）

### 三、控制运行有效性结论

- [ ] 每项控制的运行有效性结论是否有充分的测试证据支持
- [ ] 是否区分记录了控制"设计有效但运行无效"与"设计本身无效"
- [ ] 控制运行有效性结论是否明确说明对信赖程度的影响
- [ ] 企业层面控制结论是否影响并已联动更新业务流程层面控制测试计划

### 四、控制偏差评价与缺陷分级

- [ ] 测试中发现的每一偏差是否评价了偏差性质与根本原因
- [ ] 偏差是否评估为偶发例外还是系统性控制失效
- [ ] 缺陷是否按控制缺陷/值得关注的缺陷/重大缺陷正确分级
- [ ] 重大缺陷与值得关注的缺陷是否已沟通治理层与管理层
- [ ] 缺陷是否评估了对实质性程序性质、时间、范围的影响

## risk_areas

### 高风险

1. **控制环境薄弱被忽视**：管理层凌驾迹象、治理层监督缺位等控制环境缺陷未被识别，却仍对下游业务控制给予高信赖，导致审计信赖基础崩塌。
2. **COSO 要素识别缺失**：风险评估或监督要素未识别对应控制，企业层面控制评价不完整，无法支持对内控整体有效性的结论。
3. **设计有效性与运行有效性混同**：仅执行穿行测试即得出运行有效结论，未进行跨期间样本测试，控制信赖缺乏充分证据。
4. **管理层凌驾风险未测试**：未针对管理层凌驾于控制之上实施必要程序，掩盖了舞弊风险，与会计分录测试脱节。
5. **缺陷分级错误影响审计策略**：重大缺陷被误评为一般控制缺陷，未相应扩大实质性程序范围，导致检查风险失控。

### 中风险

1. **样本量与频率不匹配**：日常控制仅测试少量样本或年度控制未测试单笔即下结论，测试范围不足以支持信赖。
2. **测试期间覆盖不全**：仅测试期中控制而未覆盖期末更新，无法证明控制在整个拟信赖期间持续有效运行。
3. **间接控制影响评估不足**：企业层面控制对实质性程序范围的影响未量化说明，信赖决策缺乏依据。
4. **偏差根本原因分析缺失**：发现偏差仅记录笔数未分析根本原因，无法判断是偶发还是系统性失效。

### 低风险

1. **控制描述不清晰**：控制点描述过于笼统未说明谁在何时以何种方式执行，影响复核对控制的理解。
2. **底稿交叉索引不完整**：企业层面控制测试底稿与业务流程控制底稿、风险评估底稿之间缺乏索引引用。
3. **测试记录格式不规范**：控制测试的样本、结果、结论记录格式不统一，影响复核效率与可追溯性。
