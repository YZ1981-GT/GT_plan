# C10-2 职工薪酬循环-评价控制偏差 复核提示词

## 概述

本提示词针对职工薪酬循环控制测试的偏差评价（C10-2）的复核，聚焦职工薪酬循环关键控制点——考勤与工时记录、薪酬计算与审批、社保公积金计提、薪酬发放授权、离职人员薪酬停发——的控制偏差识别、偏差性质判断、偏差率外推、缺陷分级及对职工薪酬实质性程序的影响（CAS1231、CAS1314、CAS1141）。职工薪酬涉及应付职工薪酬完整性与相关费用准确性，考勤、薪酬计算与发放授权控制的偏差直接关联虚列人员（幽灵员工）等舞弊风险与费用真实性。

**法规依据：**
- 《中国注册会计师审计准则第1231号——针对评估的重大错报风险采取的应对措施》
- 《中国注册会计师审计准则第1314号——审计抽样》
- 《中国注册会计师审计准则第1141号——财务报表审计中与舞弊相关的责任》

## tips

1. **考勤与人员名册控制偏差关联幽灵员工**：考勤记录、人员入离职名册管理控制的偏差可能掩盖虚列人员套取薪酬的舞弊，偏差评价须警惕系统性人员虚增迹象。
2. **薪酬计算与审批偏差影响费用真实性**：工资计算、薪酬标准变更审批控制的偏差直接影响薪酬费用准确性，须审视计算复核的有效性。
3. **社保公积金计提控制偏差系统性影响**：社保公积金计提基数与比例设置控制偏差通常系统性影响多期计提，须评估对应付职工薪酬完整性的传导。
4. **薪酬发放授权偏差关联资金安全**：薪酬发放清单审批、发放金额与计算一致性控制的偏差是资金套取信号，须审慎判断系统性。
5. **离职停发控制偏差影响完整准确**：离职人员薪酬未及时停发的控制偏差既影响费用准确性也是套取风险，须评估处理及时性。
6. **缺陷分级决定薪酬程序范围**：考勤/计算/发放控制重大缺陷时，须扩大人员名册核对、薪酬重算、发放记录与银行流水核对的实质性程序范围。

## checklist

### 一、控制偏差识别（职工薪酬循环专属）

- [ ] 考勤与工时记录控制偏差是否识别（考勤缺失/记录不实）
- [ ] 人员入离职名册管理控制偏差是否识别
- [ ] 薪酬计算准确性复核控制偏差是否识别
- [ ] 薪酬标准/调薪审批控制偏差是否识别
- [ ] 社保公积金计提基数与比例控制偏差是否识别
- [ ] 薪酬发放清单审批与发放一致性控制偏差是否识别
- [ ] 离职人员薪酬停发控制偏差是否识别

### 二、偏差性质与根本原因

- [ ] 每项偏差是否评价为偶发例外还是系统性控制失效
- [ ] 偏差是否呈现虚列人员/套取薪酬的舞弊迹象
- [ ] 社保公积金计提类偏差是否评估系统性跨期影响
- [ ] 偏差根本原因是否分析（记录缺陷/审批缺位/计算错误）

### 三、偏差率外推与评价

- [ ] 样本偏差率是否正确计算并外推总体偏差率
- [ ] 偏差影响的认定维度是否明确（完整性/准确性）
- [ ] 外推总体偏差率是否与可容忍偏差率比较
- [ ] 是否考虑抽样风险对偏差评价的影响

### 四、缺陷分级与影响

- [ ] 偏差导致的缺陷是否按控制缺陷/值得关注缺陷/重大缺陷分级
- [ ] 缺陷是否评估了对应付职工薪酬完整性/薪酬费用准确性的影响
- [ ] 控制不可信赖时是否扩大人员名册核对、薪酬重算、流水核对
- [ ] 重大缺陷及舞弊迹象是否已按 CAS1141 升级并沟通治理层

## risk_areas

### 高风险

1. **考勤名册控制系统性失效**：考勤/人员名册控制偏差系统性发生却被评为偶发，虚列人员套取薪酬舞弊风险未被应对。
2. **发放授权控制缺陷**：薪酬发放清单未审批或发放与计算不一致偏差未评为重大缺陷，资金套取风险未被应对。
3. **缺陷分级偏低未扩大实质性程序**：薪酬控制重大缺陷未触发名册核对与薪酬重算扩大，薪酬错报检查风险失控。
4. **舞弊迹象未升级**：偏差呈现幽灵员工/套取薪酬迹象却未按 CAS1141 升级评估。

### 中风险

1. **社保公积金计提系统性偏差**：计提基数/比例控制偏差系统性影响多期计提却未评估累积影响。
2. **薪酬计算偏差影响准确性未评估**：计算复核偏差未评估对薪酬费用准确性影响。
3. **离职停发偏差被忽视**：离职人员未及时停发偏差未评估对费用准确性与套取风险影响。

### 低风险

1. **偏差记录不规范**：偏差类型、涉及部门/人员、金额记录格式不统一。
2. **抽样参数留痕不足**：样本量、可容忍偏差率、预计偏差率记录不完整。
3. **底稿索引缺失**：C10-2 与职工薪酬控制测试底稿、应付职工薪酬审定表、薪酬测算底稿缺乏交叉索引。
