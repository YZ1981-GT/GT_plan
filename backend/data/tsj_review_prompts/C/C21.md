# C21 具有信息技术专业技能的项目组成员 复核提示词

## 概述

本提示词针对"利用具有信息技术专业技能的项目组成员"底稿（C21）的复核，聚焦 IT 专家利用的必要性判断、专家胜任能力与客观性评价、工作范围与指令明确性、以及 IT 专家发现对控制测试和实质性程序的影响（CAS1421）。当被审计单位 IT 环境复杂、信息处理高度依赖系统时，项目组须评估是否利用 IT 专业技能人员，并对其工作实施充分的指导、监督与复核。

**法规依据：**
- 《中国注册会计师审计准则第1421号——利用专家的工作》
- 《中国注册会计师审计准则第1211号——通过了解被审计单位及其环境识别和评估重大错报风险》
- 《中国注册会计师审计准则第1231号——针对评估的重大错报风险采取的应对措施》

---

## tips

1. **利用 IT 专家的必要性须基于风险与复杂度**：IT 环境越复杂、自动化控制与 ITGC 越关键，越须利用 IT 专业技能人员，复核首先验证利用决策是否与风险评估匹配。
2. **区分项目组成员与外部专家**：C21 关注具有 IT 专业技能的项目组内部成员，其独立性天然满足，但仍须评价胜任能力与经验是否胜任所分配的 IT 审计工作。
3. **工作范围与指令须书面明确**：IT 专家的工作目标、范围、拟测试的系统与控制、报告要求须清晰界定，模糊指令会导致 IT 测试覆盖不足或方向偏差。
4. **IT 专家发现须回归审计结论**：IT 专家对 ITGC 或自动化控制的测试结果须由项目组理解并整合，评估其对可否信赖系统生成信息、可否信赖自动化控制的影响。
5. **对 IT 专家工作的复核不可缺位**：项目负责人须对 IT 专家的工作充分指导监督与复核，不得因技术专业性而放弃复核责任。
6. **IT 专家利用与 ITGC 测试联动**：C21 的利用决策直接决定 C22（IT 一般控制测试）的深度与范围，两者须保持一致联动。

## checklist

### 一、利用必要性与胜任能力评价

- [ ] 是否评价了被审计单位 IT 环境的复杂程度和对系统的依赖程度
- [ ] 利用 IT 专业技能人员的决策是否与识别的重大错报风险相匹配
- [ ] IT 专业成员的专业资格、经验、技能是否与所分配工作相适应
- [ ] 是否评价了 IT 成员对被审计单位所用系统/技术的熟悉程度
- [ ] 未利用 IT 专家时，是否说明理由并评估项目组自身 IT 能力是否充分

### 二、工作范围与指令明确性

- [ ] IT 工作的目标、范围、拟测试系统与控制是否书面明确
- [ ] 拟测试的 ITGC 领域（访问安全/变更管理/运行/开发）是否清晰界定
- [ ] 拟依赖的自动化应用控制清单是否明确
- [ ] 报告格式、时间要求、发现汇总方式是否约定

### 三、指导监督与工作复核

- [ ] 项目负责人是否对 IT 成员工作提供了充分的指导与监督
- [ ] IT 成员的工作底稿是否经项目组复核
- [ ] 项目组是否理解 IT 测试的方法、范围与结论
- [ ] IT 测试证据是否充分适当以支持相关审计结论

### 四、发现整合与结论影响

- [ ] IT 专家发现的控制缺陷是否已汇总至 IT 审计发现汇总表（C21-1）
- [ ] ITGC 测试结果是否影响对自动化控制信赖的结论
- [ ] IT 发现是否影响系统生成信息的可靠性评价
- [ ] IT 专家结论是否已整合入整体控制测试结论与实质性程序计划

## risk_areas

### 高风险

1. **该利用未利用**：IT 环境复杂却未利用 IT 专业技能人员，项目组自身 IT 能力不足，导致 ITGC 和自动化控制测试缺失或流于形式。
2. **胜任能力不匹配**：分配的 IT 成员经验或技能不胜任所测系统，测试结论不可靠却被用于支持控制信赖。
3. **工作范围界定不清**：IT 工作指令模糊，关键系统或控制领域未纳入测试范围，形成审计覆盖盲区。
4. **IT 发现未回归审计结论**：IT 专家识别的 ITGC 缺陷未整合入控制测试结论，仍对自动化控制给予信赖，导致检查风险失控。

### 中风险

1. **指导监督不足**：项目负责人因技术门槛放弃对 IT 工作的实质监督与复核，无法确保工作质量。
2. **C21 与 C22 脱节**：利用决策与实际 ITGC 测试范围不一致，测试深度与风险评估不匹配。
3. **报告要求不明确**：IT 发现汇总方式未约定，导致缺陷未能及时、完整地传递给项目组。

### 低风险

1. **资格证明留痕不足**：IT 成员的专业资格、经验记录不完整，影响胜任能力评价的可追溯性。
2. **工作底稿索引缺失**：C21 与 C21-1、C22 之间缺乏交叉索引引用。
3. **利用决策记录简略**：利用或不利用 IT 专家的判断依据记录过于简略。
