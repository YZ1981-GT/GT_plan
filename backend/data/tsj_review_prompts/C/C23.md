# C23 会计分录控制测试程序表 复核提示词

## 概述

本提示词针对会计分录控制测试程序表（C23）的复核，聚焦管理层凌驾于控制之上的应对、会计分录与其他调整的完整性获取、高风险分录的选取标准、以及分录测试对舞弊风险的响应（CAS1141、CAS1211、CAS1314）。管理层凌驾于控制之上是所有被审计单位均存在的舞弊风险，会计分录测试是应对该风险的必备程序，其控制测试维度须验证分录录入、审批、过账的授权控制是否有效。

**法规依据：**
- 《中国注册会计师审计准则第1141号——财务报表审计中与舞弊相关的责任》
- 《中国注册会计师审计准则第1211号——通过了解被审计单位及其环境识别和评估重大错报风险》
- 《中国注册会计师审计准则第1314号——审计抽样》

---

## tips

1. **管理层凌驾是不可反驳的舞弊风险**：无论控制运行多好，会计分录测试都是必测程序，复核首先确认该程序是否已执行且未被简化省略。
2. **分录总体完整性是测试有效性的前提**：须验证获取的会计分录清单是完整总体（含手工分录、系统自动分录、期末调整分录），不完整的总体会使高风险分录漏检。
3. **高风险分录选取标准须明确且有据**：非常规分录、期末/结账后分录、整数金额分录、无摘要或摘要异常分录、涉及舞弊风险科目的分录应作为选取重点。
4. **分录授权控制与测试维度并重**：C23 既测试分录相关内部控制（录入权限、审批流、过账控制、职责分离）的运行有效性，也针对高风险分录实施细节测试。
5. **系统自动分录须结合 ITGC 评价**：自动生成分录的可靠性依赖系统一般控制（C22），若 ITGC 存在缺陷，自动分录完整性存疑须扩大测试。
6. **异常分录须追查至原始凭证与商业实质**：选取的高风险分录须核对支持性文件与业务合理性，评估是否存在无商业实质的操纵性分录。

## checklist

### 一、管理层凌驾应对与总体完整性

- [ ] 会计分录测试是否作为必备程序已执行（未被省略）
- [ ] 获取的会计分录清单是否为完整总体（手工+自动+期末调整）
- [ ] 分录总体是否与总账/试算平衡表发生额勾稽核对
- [ ] 是否覆盖了整个报告期间及期末结账后的分录

### 二、分录授权控制测试

- [ ] 分录录入权限是否受控并与审批权限职责分离
- [ ] 手工分录是否经恰当级别的审批
- [ ] 过账控制是否有效（未经审批不得过账）
- [ ] 分录编号是否连续、是否存在删除或作废分录的受控机制
- [ ] 系统是否记录分录录入人、审批人、过账人及时间戳

### 三、高风险分录选取与测试

- [ ] 高风险分录选取标准是否明确（非常规/期末/整数/异常摘要/舞弊风险科目）
- [ ] 期末及结账后的调整分录是否重点选取测试
- [ ] 整数金额、无摘要、跨期科目组合异常的分录是否纳入
- [ ] 选取的高风险分录是否核对了支持性文件与商业实质
- [ ] 是否关注了涉及收入、储备、关联方等舞弊敏感科目的分录

### 四、结论与舞弊响应

- [ ] 每笔测试分录的结果是否记录（正常/异常/需追查）
- [ ] 发现的异常分录是否已追查并评价是否构成错报或舞弊迹象
- [ ] 分录控制测试结论是否影响对整体控制信赖的评价
- [ ] 舞弊迹象是否已按 CAS1141 要求升级评估并与项目组沟通

## risk_areas

### 高风险

1. **管理层凌驾测试缺失或简化**：会计分录测试未执行或仅象征性抽查，未真正应对管理层凌驾舞弊风险。
2. **分录总体不完整**：获取的分录清单遗漏系统自动分录或期末结账后分录，高风险操纵性分录漏检。
3. **高风险分录选取标准失效**：选取标准未覆盖非常规/期末/异常摘要分录，测试样本无法命中舞弊迹象。
4. **异常分录未追查商业实质**：选取的异常分录仅核对金额一致性，未评估业务合理性，操纵性分录未被识别。

### 中风险

1. **分录授权控制失效未评价**：录入与审批未职责分离、过账无审批控制，却未在测试中识别。
2. **自动分录可靠性存疑**：系统自动分录依赖的 ITGC 存在缺陷，自动分录完整性未扩大测试。
3. **结账后分录关注不足**：期末结账后的调整分录未重点测试，利润操纵高发区被忽略。

### 低风险

1. **分录测试记录不规范**：测试结果记录格式不统一，异常标注不清晰。
2. **总体勾稽留痕不足**：分录清单与总账发生额的勾稽核对未留痕。
3. **底稿索引缺失**：C23 与舞弊风险评估底稿、调整分录汇总、相关业务循环底稿缺乏交叉索引。
