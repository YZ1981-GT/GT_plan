# C7-2 在建工程循环-评价控制偏差 复核提示词

## 概述

本提示词针对在建工程循环控制测试的偏差评价（C7-2）的复核，聚焦在建工程循环关键控制点——工程预算与合同审批、工程进度与计量确认、工程款支付审批、转固时点确认、借款费用资本化复核——的控制偏差识别、偏差性质判断、偏差率外推、缺陷分级及对在建工程实质性程序的影响（CAS1231、CAS1314、CAS1211）。在建工程金额通常重大，工程款支付与转固控制的偏差直接影响在建工程与固定资产的完整性、计价及借款费用资本化的准确性。

**法规依据：**
- 《中国注册会计师审计准则第1231号——针对评估的重大错报风险采取的应对措施》
- 《中国注册会计师审计准则第1314号——审计抽样》
- 《中国注册会计师审计准则第1211号——通过了解被审计单位及其环境识别和评估重大错报风险》

## tips

1. **工程合同与预算审批偏差影响成本源头**：工程合同签订、预算超支审批控制的偏差影响在建工程归集成本的合规性，偏差评价须审视合同与变更的授权。
2. **进度计量确认偏差影响成本真实性**：工程进度确认、工程量计量复核控制的偏差直接关联工程成本归集的准确性与虚增风险。
3. **转固时点控制偏差影响折旧起点**：达到预定可使用状态却未及时转固（或提前转固）的控制偏差影响固定资产完整性与折旧起算，须评估跨期影响。
4. **借款费用资本化控制偏差影响损益**：资本化条件判断、资本化期间与金额计算复核控制的偏差影响利息资本化的准确性，进而影响损益。
5. **工程款支付审批偏差关联资金与成本**：工程款超进度支付、未审批支付的偏差既是资金风险也是成本虚增信号，须审慎判断系统性。
6. **缺陷分级决定在建工程程序范围**：进度计量或转固控制重大缺陷时，须扩大工程成本核对、进度实地检查、转固测试与借款费用重算的实质性程序范围。

## checklist

### 一、控制偏差识别（在建工程循环专属）

- [ ] 工程合同签订与预算审批控制偏差是否识别
- [ ] 工程变更/预算超支审批控制偏差是否识别
- [ ] 工程进度与工程量计量确认复核控制偏差是否识别
- [ ] 工程款支付审批控制偏差是否识别（超进度/未审批支付）
- [ ] 转固时点确认控制偏差是否识别（未及时/提前转固）
- [ ] 借款费用资本化条件与金额复核控制偏差是否识别

### 二、偏差性质与根本原因

- [ ] 每项偏差是否评价为偶发例外还是系统性控制失效
- [ ] 转固时点偏差是否评估其跨期折旧影响
- [ ] 偏差根本原因是否分析（审批缺陷/计量复核缺位）
- [ ] 偏差是否影响在建工程完整性、计价或借款费用准确性

### 三、偏差率外推与评价

- [ ] 样本偏差率是否正确计算并外推总体偏差率
- [ ] 偏差影响的认定维度是否明确（完整性/计价/资本化）
- [ ] 外推总体偏差率是否与可容忍偏差率比较
- [ ] 单项重大工程的控制例外是否单独评估

### 四、缺陷分级与影响

- [ ] 偏差导致的缺陷是否按控制缺陷/值得关注缺陷/重大缺陷分级
- [ ] 缺陷是否评估了对在建工程/转固/借款费用/损益的影响
- [ ] 控制不可信赖时是否扩大成本核对、进度检查、转固与资本化测试
- [ ] 重大缺陷是否已沟通治理层与管理层

## risk_areas

### 高风险

1. **进度计量控制系统性失效**：工程量计量确认偏差系统性发生却被评为偶发，工程成本虚增风险未被应对。
2. **转固时点控制缺陷跨期影响**：转固不及时的控制偏差未评估对折旧起算与损益的跨期影响，固定资产完整性存疑。
3. **缺陷分级偏低未扩大实质性程序**：在建工程控制重大缺陷未触发成本核对与转固测试扩大，在建工程错报检查风险失控。
4. **工程款支付审批失效**：超进度/未审批支付偏差未评为重大缺陷，资金与成本虚增风险未被应对。

### 中风险

1. **借款费用资本化偏差影响损益未评估**：资本化条件/金额复核偏差未评估对利息资本化与损益的影响。
2. **合同变更审批偏差被忽视**：工程变更/预算超支未审批偏差未评估对成本合规性影响。
3. **单项重大工程例外未评估**：重大工程的控制例外未单独评估其对整体信赖的影响。

### 低风险

1. **偏差记录不规范**：偏差类型、涉及工程项目、金额记录格式不统一。
2. **抽样参数留痕不足**：样本量、可容忍偏差率、预计偏差率记录不完整。
3. **底稿索引缺失**：C7-2 与在建工程控制测试底稿、在建工程审定表、转固与借款费用底稿缺乏交叉索引。
