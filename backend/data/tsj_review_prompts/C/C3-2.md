# C3-2 货币资金循环-评价控制偏差 复核提示词

## 概述

本提示词针对货币资金循环控制测试的偏差评价（C3-2）的复核，聚焦货币资金循环关键控制点——收付款审批、银行对账、印鉴与网银权限分管、大额资金支付授权——的控制偏差识别、偏差性质判断、偏差率外推、缺陷分级及对货币资金实质性程序的影响（CAS1231、CAS1314、CAS1141）。货币资金是舞弊高发领域，收付款审批与职责分离控制的偏差直接关联资金挪用与账实不符风险，偏差评价须结合舞弊风险审慎判断。

**法规依据：**
- 《中国注册会计师审计准则第1231号——针对评估的重大错报风险采取的应对措施》
- 《中国注册会计师审计准则第1314号——审计抽样》
- 《中国注册会计师审计准则第1141号——财务报表审计中与舞弊相关的责任》

## tips

1. **收付款审批偏差直击资金挪用风险**：付款未经审批或超权限支付的偏差是资金舞弊的高危信号，货币资金循环偏差评价须优先审视审批控制失效。
2. **银行对账控制偏差影响账实相符**：银行存款余额调节表未及时编制或未经复核的偏差，可能掩盖未达账项异常或账实差异。
3. **职责分离偏差是货币资金核心缺陷**：出纳与记账、印鉴与网银 U 盾分管的职责分离失效，为单人操纵资金创造条件，即使少量偏差也须高度关注。
4. **偏差率外推须结合大额支付全查**：货币资金大额支付通常全查而非抽样，偏差评价须区分全查项目的例外与抽样项目的偏差外推。
5. **缺陷分级决定货币资金实质性程序**：审批或对账控制重大缺陷时，须扩大函证范围、加强期末余额调节表核对与大额收付款凭证检查。
6. **偏差集中性揭示系统性挪用**：偏差若集中于特定账户、特定经办人或特定时段，应警惕系统性资金挪用而非偶发失误。

## checklist

### 一、控制偏差识别（货币资金循环专属）

- [ ] 付款审批控制偏差是否识别（未审批/超权限支付）
- [ ] 收款入账及时性控制偏差是否识别（收款未及时入账）
- [ ] 银行对账（余额调节表编制与复核）控制偏差是否识别
- [ ] 印鉴、网银 U 盾、密码分管的职责分离偏差是否识别
- [ ] 大额资金支付授权控制偏差是否识别
- [ ] 现金库存盘点控制偏差是否识别

### 二、偏差性质与根本原因

- [ ] 每项偏差是否评价为偶发例外还是系统性控制失效
- [ ] 偏差是否集中于特定账户/经办人/时段（挪用迹象）
- [ ] 偏差根本原因是否分析（授权流程缺陷/职责分离缺失）
- [ ] 是否评估偏差是否存在资金挪用舞弊迹象

### 三、偏差率外推与评价

- [ ] 抽样项目样本偏差率是否正确计算并外推总体
- [ ] 大额支付全查项目的例外是否单独评价（非外推）
- [ ] 外推总体偏差率是否与可容忍偏差率比较
- [ ] 是否考虑抽样风险对偏差评价的影响

### 四、缺陷分级与影响

- [ ] 偏差导致的缺陷是否按控制缺陷/值得关注缺陷/重大缺陷分级
- [ ] 缺陷是否评估了对货币资金存在性/完整性认定的影响
- [ ] 控制不可信赖时是否扩大函证、余额调节表核对、大额凭证检查
- [ ] 重大缺陷及舞弊迹象是否已按 CAS1141 升级并沟通治理层

## risk_areas

### 高风险

1. **付款审批控制系统性失效**：付款超权限或未审批偏差集中于特定经办人却被评为偶发，掩盖资金挪用系统性缺陷。
2. **职责分离缺陷被低估**：出纳记账不分离、印鉴网银集中于一人的偏差未评为重大缺陷，单人操纵资金风险未被应对。
3. **缺陷分级偏低未扩大实质性程序**：货币资金控制重大缺陷未触发函证与大额凭证检查扩大，资金错报/挪用检查风险失控。
4. **舞弊迹象未升级**：偏差呈现挪用迹象却未按 CAS1141 升级评估。

### 中风险

1. **银行对账偏差影响账实相符未评估**：余额调节表未复核的偏差未评估对账实相符的影响。
2. **全查与抽样例外混同评价**：大额支付全查例外与抽样偏差混同处理，偏差评价口径不清。
3. **偏差集中性未分析**：偏差是否集中于特定账户/时段未分析，系统性挪用迹象被忽略。

### 低风险

1. **偏差记录不规范**：偏差类型、涉及账户、金额、期间记录格式不统一。
2. **抽样参数留痕不足**：样本量、可容忍偏差率、预计偏差率记录不完整。
3. **底稿索引缺失**：C3-2 与货币资金控制测试底稿、货币资金审定表、函证底稿缺乏交叉索引。
