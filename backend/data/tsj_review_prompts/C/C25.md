# C25 利用内部审计工作 复核提示词

## 概述

本提示词针对"利用内部审计工作"底稿（C25）的复核，聚焦内部审计职能的客观性与胜任能力评价、内部审计方法系统性与规范性评价、拟利用内审工作的性质与范围确定、以及注册会计师对所利用工作的复核与重新执行（CAS1411）。利用内部审计工作可提高审计效率，但不减轻注册会计师的审计责任，利用前须评价内审职能是否满足利用条件，利用后须实施充分的复核程序。

**法规依据：**
- 《中国注册会计师审计准则第1411号——利用内部审计人员的工作》
- 《中国注册会计师审计准则第1211号——通过了解被审计单位及其环境识别和评估重大错报风险》
- 《中国注册会计师审计准则第1231号——针对评估的重大错报风险采取的应对措施》

---

## tips

1. **利用前须过三道门槛**：内审职能的客观性（组织地位与政策）、胜任能力（资格与经验）、方法系统规范性（是否有系统化质量控制），三者任一不满足即不得利用其工作。
2. **客观性受组织地位制约**：内审直接向治理层报告、不承担被审计业务的经营职责，客观性较高；若内审隶属于被审计的管理层，客观性受损须审慎。
3. **利用范围与风险成反比**：风险越高、判断越主观的领域，越应减少对内审工作的利用；重大错报风险高或涉及重大判断的事项不宜过度依赖内审。
4. **利用不减轻审计责任**：无论利用程度多深，审计意见的责任完全由注册会计师承担，须对所利用的内审工作实施复核甚至重新执行部分工作。
5. **复核与重新执行不可省略**：对拟利用的内审工作须评价其工作是否充分适当，并选择部分重新执行以验证内审工作质量。
6. **区分"利用工作"与"直接协助"**：利用内审已完成的工作与利用内审人员提供直接协助是不同情形，直接协助须另行评价并加强指导监督。

## checklist

### 一、客观性评价

- [ ] 内部审计职能的组织地位是否支持其客观性（向治理层报告）
- [ ] 内审是否承担了可能损害客观性的经营管理职责
- [ ] 内审人员薪酬与晋升是否独立于被审计业务的管理层
- [ ] 是否存在限制内审工作范围或干预内审结论的情形

### 二、胜任能力评价

- [ ] 内审人员是否具备相应的专业资格与经验
- [ ] 内审是否有持续的培训与专业发展机制
- [ ] 内审对被审计单位业务与风险的了解是否充分

### 三、方法系统性与规范性

- [ ] 内审是否采用系统化、规范化的审计方法
- [ ] 内审是否有质量控制政策与程序
- [ ] 内审工作是否有恰当的计划、执行、记录、复核流程
- [ ] 内审工作底稿是否完整、结论是否有证据支持

### 四、利用范围与复核

- [ ] 拟利用内审工作的性质与范围是否与风险水平匹配（高风险少利用）
- [ ] 重大判断/高主观性事项是否避免过度依赖内审
- [ ] 是否对拟利用的内审工作实施了充分复核
- [ ] 是否选择部分内审工作重新执行以验证质量
- [ ] 利用内审工作后整体审计证据是否仍充分适当

## risk_areas

### 高风险

1. **客观性不足仍利用**：内审隶属于被审计管理层或承担经营职责，客观性受损却仍利用其工作，审计证据可靠性存疑。
2. **高风险领域过度依赖**：对重大错报风险高或涉及重大判断的事项过度利用内审工作，未保持应有的注册会计师直接测试。
3. **复核与重新执行缺失**：直接采用内审结论而未复核或重新执行，无法验证内审工作质量，审计责任落空。
4. **误将利用等同减责**：以利用内审工作为由减少必要审计程序，导致整体审计证据不充分。

### 中风险

1. **胜任能力评价不足**：未充分评价内审人员资格经验即利用其工作，工作质量无保障。
2. **方法规范性未评价**：未评价内审是否采用系统化方法与质量控制，工作可靠性缺乏基础。
3. **利用范围界定模糊**：拟利用工作的性质范围不清晰，实际利用超出了适当边界。

### 低风险

1. **评价记录简略**：客观性、胜任能力、方法规范性的评价依据记录不充分。
2. **重新执行留痕不足**：重新执行内审工作的范围与结果记录不完整。
3. **底稿索引缺失**：C25 与相关业务循环控制底稿、风险评估底稿缺乏交叉索引。
