# C26 信息处理控制测试 复核提示词

## 概述

本提示词针对信息处理控制测试（C26）的复核，聚焦应用控制（自动控制与人工控制）的识别、自动化控制测试方法、依赖 ITGC 的信赖前提、以及信息处理控制运行有效性对业务循环认定的影响（CAS1211、CAS1231、CAS1314）。信息处理控制是嵌入业务流程中确保交易被完整、准确、有效处理的应用层控制，包括系统自动校验、审批控制、匹配控制、人工复核控制等，其测试须与 IT 一般控制（C22）联动评价。

**法规依据：**
- 《中国注册会计师审计准则第1211号——通过了解被审计单位及其环境识别和评估重大错报风险》
- 《中国注册会计师审计准则第1231号——针对评估的重大错报风险采取的应对措施》
- 《中国注册会计师审计准则第1314号——审计抽样》

## tips

1. **区分自动控制与人工控制的测试方法**：自动化控制在 ITGC 有效前提下可仅测单笔加验证配置稳定性；人工控制须按执行频率进行属性抽样。
2. **自动化控制信赖以 ITGC 有效为前提**：若 C22 显示相关 ITGC 存在缺陷（尤其变更管理、访问安全），自动化控制的配置稳定性无保障，须扩大测试或转实质性程序。
3. **信息处理控制对应认定须清晰**：每项控制应明确其防止或发现的错报类型与所支持的认定（完整性/准确性/存在性/发生等），控制与认定脱节则信赖无意义。
4. **匹配与校验类控制是自动化重点**：三单匹配（订单-收货-发票）、系统自动校验（信用额度、库存可用量、审批限额）是常见自动化控制，测试重点在配置正确性与例外处理。
5. **人工复核控制须验证复核的实质性**：人工复核控制（如经理审阅、对账复核）须验证是否实质执行（有复核证据、发现并处理例外）而非流于形式的签字。
6. **半自动控制须拆分测试**：依赖系统生成报告后由人工复核的半自动控制，须同时验证系统报告可靠性（依赖 ITGC/系统信息可靠性）和人工复核有效性。

## checklist

### 一、控制识别与分类

- [ ] 是否识别了业务流程中的关键信息处理控制点
- [ ] 每项控制是否区分了自动控制/人工控制/半自动控制
- [ ] 每项控制是否明确对应所支持的财务报表认定
- [ ] 是否识别了系统自动校验、匹配、审批、复核等控制类型

### 二、自动化控制测试

- [ ] 自动化控制是否在相关 ITGC 有效前提下测试
- [ ] 自动化控制是否采用测试单笔加验证配置稳定性的方法
- [ ] 系统自动校验（信用/库存/限额）的配置正确性是否验证
- [ ] 三单匹配等自动匹配控制的例外处理机制是否测试
- [ ] 若 ITGC 存在缺陷，自动化控制信赖是否已相应调整

### 三、人工与半自动控制测试

- [ ] 人工控制样本量是否与执行频率匹配（CAS1314）
- [ ] 人工复核控制是否验证了复核的实质性（例外发现与处理）
- [ ] 半自动控制依赖的系统报告可靠性是否验证
- [ ] 人工控制执行是否有充分的执行证据（签字/记录/系统留痕）

### 四、结论与影响

- [ ] 每项信息处理控制的运行有效性结论是否有证据支持
- [ ] 控制运行无效或缺陷是否评价了对相关认定的影响
- [ ] 信息处理控制结论是否影响对应业务循环实质性程序范围
- [ ] 发现的控制缺陷是否已按分级评价并沟通

## risk_areas

### 高风险

1. **自动化控制脱离 ITGC 信赖**：在相关 ITGC（变更管理/访问安全）存在缺陷时仍对自动化控制给予单笔信赖，配置可能被未授权修改而不知。
2. **控制与认定脱节**：识别的控制未明确对应认定，无法说明该控制防止或发现何种错报，信赖失去针对性。
3. **人工复核流于形式**：人工复核控制仅有签字而无实质复核证据（未发现处理例外），却被评价为运行有效。
4. **例外处理机制未测试**：自动化匹配/校验控制的例外（不匹配/超限）处理未测试，异常交易可能被绕过。

### 中风险

1. **半自动控制测试不完整**：仅测试人工复核而未验证依赖的系统报告可靠性，或反之，控制链条测试不完整。
2. **样本量与频率不匹配**：人工控制未按执行频率抽样，测试范围不足以支持信赖。
3. **自动化控制配置稳定性未验证**：仅测试单笔通过而未验证测试期间配置未发生变更。

### 低风险

1. **控制描述不清晰**：控制点执行主体、时点、方式描述笼统，影响复核理解与测试针对性。
2. **控制类型标注不准**：自动/人工/半自动分类标注不准确，影响测试方法选择。
3. **底稿索引缺失**：C26 与 C22（ITGC）、C21-1（IT 发现）及相关业务循环底稿缺乏交叉索引。
