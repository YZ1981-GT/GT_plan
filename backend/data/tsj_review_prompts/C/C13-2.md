# C13-2 债务循环-评价控制偏差 复核提示词

## 概述

本提示词针对债务循环（借款与债券融资）控制测试的偏差评价（C13-2）的复核，聚焦债务循环关键控制点——融资决策审批、借款合同与担保审批、利息计提复核、本息偿还授权、债务契约合规监控——的控制偏差识别、偏差性质判断、偏差率外推、缺陷分级及对借款与债券相关科目实质性程序的影响（CAS1231、CAS1314、CAS1211）。债务循环涉及借款、应付债券完整性与利息费用准确性，融资审批与利息计提控制的偏差直接关联未入账债务、利息费用错报及债务契约违约风险。

**法规依据：**
- 《中国注册会计师审计准则第1231号——针对评估的重大错报风险采取的应对措施》
- 《中国注册会计师审计准则第1314号——审计抽样》
- 《中国注册会计师审计准则第1211号——通过了解被审计单位及其环境识别和评估重大错报风险》

## tips

1. **融资决策审批偏差关联未入账债务**：重大融资未经治理层/董事会审批的偏差可能构成越权融资，也可能存在账外债务，偏差评价须首查融资审批的完整合规。
2. **利息计提复核偏差系统性影响费用**：借款利率、计息期间、资本化与费用化划分的利息计提复核控制偏差通常系统性影响利息费用，须评估对损益的传导。
3. **担保与抵押审批偏差影响或有事项**：对外担保、资产抵押审批控制的偏差影响或有负债与受限资产的完整披露，须评估对披露充分性的影响。
4. **本息偿还授权偏差关联资金安全**：本金与利息偿还未经授权或金额与合同不符的偏差是资金风险信号，须审慎判断系统性。
5. **债务契约合规监控偏差关联违约风险**：财务契约（如资产负债率、流动比率限制）监控控制的偏差可能掩盖已违约的债务重分类需求，须评估对流动性列报与持续经营的影响。
6. **缺陷分级决定债务程序范围**：融资审批或利息计提控制重大缺陷时，须扩大借款函证、利息重算、合同条款核对与债务完整性检查的实质性程序范围。

## checklist

### 一、控制偏差识别（债务循环专属）

- [ ] 融资决策审批控制偏差是否识别（未经恰当层级审批）
- [ ] 借款合同与债券发行文件审批控制偏差是否识别
- [ ] 对外担保/资产抵押审批控制偏差是否识别
- [ ] 利息计提（利率/期间/资本化划分）复核控制偏差是否识别
- [ ] 本息偿还授权控制偏差是否识别（未授权/金额不符）
- [ ] 债务契约（财务指标限制）合规监控控制偏差是否识别

### 二、偏差性质与根本原因

- [ ] 每项偏差是否评价为偶发例外还是系统性控制失效
- [ ] 利息计提类偏差是否评估其系统性跨期影响
- [ ] 偏差是否关联未入账债务、越权融资或契约违约风险
- [ ] 偏差根本原因是否分析（审批缺陷/计提参数错误/监控缺位）

### 三、偏差率外推与评价

- [ ] 样本偏差率是否正确计算并外推总体偏差率
- [ ] 偏差影响的认定维度是否明确（完整性/计价/披露）
- [ ] 外推总体偏差率是否与可容忍偏差率比较
- [ ] 单笔重大融资的控制例外是否单独评估

### 四、缺陷分级与影响

- [ ] 偏差导致的缺陷是否按控制缺陷/值得关注缺陷/重大缺陷分级
- [ ] 缺陷是否评估了对借款/应付债券完整性、利息费用、担保披露的影响
- [ ] 控制不可信赖时是否扩大借款函证、利息重算、合同核对、完整性检查
- [ ] 重大缺陷（尤其契约违约/越权融资）是否已沟通治理层与管理层

## risk_areas

### 高风险

1. **融资审批控制系统性失效**：重大融资未经审批偏差被评为偶发，越权融资或账外债务风险未被应对。
2. **债务契约违约监控缺陷**：契约合规监控控制偏差未评估对已违约债务重分类与持续经营的影响，流动性列报错报风险未被识别。
3. **缺陷分级偏低未扩大实质性程序**：债务控制重大缺陷未触发借款函证与完整性检查扩大，债务与利息错报检查风险失控。
4. **利息计提系统性偏差**：利息计提控制偏差系统性影响利息费用却未评估累积影响。

### 中风险

1. **担保抵押审批偏差影响披露未评估**：担保/抵押审批偏差未评估对或有负债与受限资产披露充分性影响。
2. **本息偿还授权偏差被忽视**：偿还未授权或金额不符偏差未评估对资金安全与债务准确性影响。
3. **利息资本化划分偏差影响损益未评估**：利息资本化与费用化划分偏差未评估对损益影响。

### 低风险

1. **偏差记录不规范**：偏差类型、涉及债务项目、金额记录格式不统一。
2. **抽样参数留痕不足**：样本量、可容忍偏差率、预计偏差率记录不完整。
3. **底稿索引缺失**：C13-2 与债务控制测试底稿、借款/应付债券审定表、利息测算与函证底稿缺乏交叉索引。
