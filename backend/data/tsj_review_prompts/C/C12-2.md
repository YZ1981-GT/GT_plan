# C12-2 税金循环-评价控制偏差 复核提示词

## 概述

本提示词针对税金循环控制测试的偏差评价（C12-2）的复核，聚焦税金循环关键控制点——税款计算复核、纳税申报审批与及时性、发票管理、税收优惠适用审批、税会差异处理复核——的控制偏差识别、偏差性质判断、偏差率外推、缺陷分级及对应交税费与税金相关科目实质性程序的影响（CAS1231、CAS1314、CAS1211）。税金循环涉及应交税费完整性、税金及附加与所得税费用准确性，税款计算与申报控制的偏差直接关联少缴/多缴税款、滞纳金及合规风险。

**法规依据：**
- 《中国注册会计师审计准则第1231号——针对评估的重大错报风险采取的应对措施》
- 《中国注册会计师审计准则第1314号——审计抽样》
- 《中国注册会计师审计准则第1211号——通过了解被审计单位及其环境识别和评估重大错报风险》

## tips

1. **税款计算复核偏差影响应交税费完整性**：各税种应纳税额计算复核控制的偏差直接影响应交税费的完整性与准确性，偏差评价须审视计算依据与税率适用。
2. **申报及时性控制偏差关联滞纳金风险**：纳税申报审批与及时申报控制的偏差可能导致逾期申报滞纳金与合规处罚，须评估对或有负债的影响。
3. **发票管理控制偏差关联进项与合规**：增值税发票开具、认证抵扣、作废红冲控制的偏差影响进项税额准确性与虚开发票合规风险。
4. **税收优惠适用审批偏差影响税负真实性**：税收优惠、加计扣除、减免适用条件判断控制的偏差可能导致不当享受优惠的税务风险。
5. **税会差异处理偏差影响所得税**：税会差异识别与递延所得税处理复核控制的偏差影响所得税费用与递延所得税的准确性。
6. **缺陷分级决定税金程序范围**：税款计算或申报控制重大缺陷时，须扩大各税种税额重算、申报表核对、发票核查与税会差异复核的实质性程序范围。

## checklist

### 一、控制偏差识别（税金循环专属）

- [ ] 各税种应纳税额计算复核控制偏差是否识别
- [ ] 纳税申报审批与及时申报控制偏差是否识别
- [ ] 增值税发票开具/认证抵扣/作废红冲控制偏差是否识别
- [ ] 税收优惠/加计扣除/减免适用审批控制偏差是否识别
- [ ] 税会差异识别与递延所得税处理复核控制偏差是否识别
- [ ] 税款缴纳与应交税费核销控制偏差是否识别

### 二、偏差性质与根本原因

- [ ] 每项偏差是否评价为偶发例外还是系统性控制失效
- [ ] 税额计算类偏差是否评估其对应交税费的系统性影响
- [ ] 偏差是否关联少缴税款、逾期申报或不当享受优惠的合规风险
- [ ] 偏差根本原因是否分析（计算依据错误/审批缺位/政策理解偏差）

### 三、偏差率外推与评价

- [ ] 样本偏差率是否正确计算并外推总体偏差率
- [ ] 偏差影响的认定维度是否明确（完整性/准确性/合规）
- [ ] 外推总体偏差率是否与可容忍偏差率比较
- [ ] 是否评估偏差对滞纳金/罚款等或有负债的影响

### 四、缺陷分级与影响

- [ ] 偏差导致的缺陷是否按控制缺陷/值得关注缺陷/重大缺陷分级
- [ ] 缺陷是否评估了对应交税费/税金及附加/所得税费用的影响
- [ ] 控制不可信赖时是否扩大税额重算、申报表核对、发票核查
- [ ] 重大缺陷（尤其合规风险）是否已沟通治理层与管理层

## risk_areas

### 高风险

1. **税款计算控制系统性失效**：税额计算复核偏差系统性发生却被评为偶发，应交税费少计与少缴税款风险未被应对。
2. **发票管理控制缺陷关联合规风险**：发票认证抵扣/作废红冲控制偏差未评估对进项准确性与虚开合规风险影响。
3. **缺陷分级偏低未扩大实质性程序**：税金控制重大缺陷未触发税额重算与申报表核对扩大，税费错报检查风险失控。
4. **税收优惠不当适用**：优惠适用审批偏差未评估对税负真实性与税务合规风险影响。

### 中风险

1. **申报及时性偏差影响或有负债未评估**：逾期申报偏差未评估对滞纳金/罚款或有负债影响。
2. **税会差异处理偏差影响所得税未评估**：税会差异复核偏差未评估对所得税费用与递延所得税影响。
3. **偏差根本原因未析**：偏差仅记笔数未分析原因，无法判断偶发或系统性。

### 低风险

1. **偏差记录不规范**：偏差类型、涉及税种、金额记录格式不统一。
2. **抽样参数留痕不足**：样本量、可容忍偏差率、预计偏差率记录不完整。
3. **底稿索引缺失**：C12-2 与税金控制测试底稿、应交税费/税金及附加/所得税审定表、税额测算底稿缺乏交叉索引。
