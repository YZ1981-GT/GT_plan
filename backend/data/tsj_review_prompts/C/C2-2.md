# C2-2 销售循环-评价控制偏差 复核提示词

## 概述

本提示词针对销售循环控制测试的偏差评价（C2-2）的复核，聚焦销售循环关键控制点——收入确认审批、发货与开票匹配、信用审批、销售退回授权——的控制偏差识别、偏差性质判断、偏差率外推、缺陷分级及对收入实质性程序的影响（CAS1231、CAS1314）。销售循环涉及收入这一舞弊风险推定领域，控制偏差评价须与舞弊风险应对联动，任何系统性控制失效都可能直接影响收入的完整性、准确性与截止认定。

**法规依据：**
- 《中国注册会计师审计准则第1231号——针对评估的重大错报风险采取的应对措施》
- 《中国注册会计师审计准则第1314号——审计抽样》
- 《中国注册会计师审计准则第1141号——财务报表审计中与舞弊相关的责任》

## tips

1. **收入确认控制偏差直击舞弊敏感区**：销售循环偏差评价须格外审慎，收入确认时点、发货开票匹配的控制失效直接关联收入舞弊，偏差性质判断不可轻易归为偶发。
2. **区分偶发例外与系统性失效**：发货单与开票不匹配若仅个别笔属操作失误，若集中于期末或特定客户则可能是系统性截止操纵，须追根本原因。
3. **偏差率须正确外推至总体**：控制测试发现的偏差笔数须按 CAS1314 计算样本偏差率并外推评估总体偏差率是否超过可容忍偏差率。
4. **信用审批控制偏差影响坏账**：信用额度审批失效的偏差不仅影响收入真实性，还传导至应收账款坏账准备的充分性评估。
5. **缺陷分级决定实质性程序调整**：偏差若构成重大缺陷则不能信赖销售循环控制，须将收入截止测试、发货核对、函证等实质性程序范围显著扩大。
6. **销售退回与折让授权偏差须关注收入冲减真实性**：退回/折让缺乏授权的偏差可能掩盖虚增收入后的冲回，须评估对收入完整性的影响。

## checklist

### 一、控制偏差识别（销售循环专属）

- [ ] 收入确认审批控制的测试偏差是否完整识别（未审批即确认收入）
- [ ] 发货单与销售发票匹配控制的偏差是否识别（数量/金额/日期不匹配）
- [ ] 信用审批控制偏差是否识别（超信用额度发货未审批）
- [ ] 销售价格/折扣审批控制偏差是否识别
- [ ] 销售退回与折让授权控制偏差是否识别
- [ ] 发货截止控制偏差是否识别（跨期发货未正确记录期间）

### 二、偏差性质与根本原因

- [ ] 每项偏差是否评价为偶发例外还是系统性控制失效
- [ ] 偏差是否集中于期末、特定客户或特定人员（系统性迹象）
- [ ] 偏差根本原因是否分析（培训不足/流程缺陷/故意规避）
- [ ] 是否评估偏差是否存在舞弊迹象（收入操纵）

### 三、偏差率外推与评价

- [ ] 样本偏差率是否正确计算（偏差笔数÷样本量）
- [ ] 样本偏差率外推的总体偏差率是否与可容忍偏差率比较
- [ ] 超过可容忍偏差率时是否结论控制不可信赖
- [ ] 是否考虑抽样风险对偏差率评价的影响

### 四、缺陷分级与影响

- [ ] 偏差导致的缺陷是否按控制缺陷/值得关注缺陷/重大缺陷分级
- [ ] 缺陷是否评估了对收入完整性/准确性/截止认定的影响
- [ ] 控制不可信赖时收入实质性程序（截止测试/发货核对/函证）是否相应扩大
- [ ] 重大缺陷是否已沟通治理层与管理层

## risk_areas

### 高风险

1. **收入确认控制系统性失效**：收入确认审批偏差集中于期末却被评为偶发，掩盖了跨期收入操纵的系统性缺陷。
2. **偏差率外推缺失**：仅记录偏差笔数未外推总体偏差率，无法判断控制是否可信赖，错误延续对销售控制的信赖。
3. **缺陷分级偏低未扩大实质性程序**：销售控制重大缺陷被误评为一般缺陷，收入截止测试与函证范围未扩大，收入错报检查风险失控。
4. **舞弊迹象未升级**：偏差呈现收入操纵舞弊迹象却未按 CAS1141 升级评估，与项目组舞弊应对脱节。

### 中风险

1. **信用审批偏差影响坏账未联动**：信用控制偏差未传导评估应收账款坏账准备充分性。
2. **发货开票匹配偏差根本原因未析**：仅记录不匹配笔数未分析原因，无法判断偶发或系统性。
3. **销售退回授权偏差被忽视**：退回/折让缺乏授权的偏差未评估对收入完整性影响。

### 低风险

1. **偏差记录不规范**：偏差类型、涉及金额、发生期间记录格式不统一。
2. **样本参数留痕不足**：样本量、可容忍偏差率、预计偏差率等抽样参数记录不完整。
3. **底稿索引缺失**：C2-2 与销售循环控制测试底稿、收入审定表、收入截止测试底稿缺乏交叉索引。
