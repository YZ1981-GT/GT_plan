# C5-2 投资循环-评价控制偏差 复核提示词

## 概述

本提示词针对投资循环控制测试的偏差评价（C5-2）的复核，聚焦投资循环关键控制点——投资决策审批、投资资金划拨授权、投资估值与减值评估复核、投资收益确认——的控制偏差识别、偏差性质判断、偏差率外推、缺陷分级及对投资实质性程序的影响（CAS1231、CAS1314、CAS1211）。投资业务金额通常重大且涉及公允价值、减值等重大判断，投资决策审批与估值复核控制的偏差直接影响投资的存在性、计价与投资收益的准确性。

**法规依据：**
- 《中国注册会计师审计准则第1231号——针对评估的重大错报风险采取的应对措施》
- 《中国注册会计师审计准则第1314号——审计抽样》
- 《中国注册会计师审计准则第1211号——通过了解被审计单位及其环境识别和评估重大错报风险》

## tips

1. **投资决策审批偏差关联越权投资风险**：重大投资未经治理层/董事会审批的偏差可能构成越权决策，投资循环偏差评价须首查决策审批层级的合规性。
2. **资金划拨授权偏差直击资金安全**：投资资金划拨未经授权或超权限的偏差是资金流失高危信号，须审慎判断是否系统性失效。
3. **估值与减值复核控制偏差影响计价**：公允价值估值、减值迹象评估、减值测试复核控制的偏差直接影响投资计价认定，须评估对估值可靠性的传导。
4. **投资收益确认控制偏差影响损益**：投资收益（含权益法调整、公允价值变动、处置损益）确认审批控制的偏差影响损益真实性。
5. **投资业务笔数少金额大宜全查评价**：投资业务通常单笔金额重大、笔数较少，偏差评价多针对全查项目的例外而非抽样外推，须逐笔评估重大性。
6. **缺陷分级决定投资估值与函证程序**：投资控制重大缺陷时，须扩大投资估值独立复核、被投资单位财务信息核对、投资函证的实质性程序范围。

## checklist

### 一、控制偏差识别（投资循环专属）

- [ ] 投资决策审批控制偏差是否识别（未经恰当层级审批）
- [ ] 投资资金划拨授权控制偏差是否识别（超权限/未授权划拨）
- [ ] 投资估值/公允价值确定复核控制偏差是否识别
- [ ] 投资减值迹象评估与减值测试复核控制偏差是否识别
- [ ] 投资收益（权益法/公允价值变动/处置损益）确认控制偏差是否识别
- [ ] 投资持有与处置的会计处理审批控制偏差是否识别

### 二、偏差性质与根本原因

- [ ] 每项偏差是否评价为偶发例外还是系统性控制失效
- [ ] 偏差是否涉及重大投资或重大判断（估值/减值）
- [ ] 偏差根本原因是否分析（审批层级缺陷/复核缺位）
- [ ] 偏差是否影响投资存在性、计价或投资收益认定

### 三、偏差评价（全查为主）

- [ ] 全查投资项目的控制例外是否逐笔评估重大性
- [ ] 如有抽样项目，样本偏差率是否正确外推
- [ ] 偏差影响的认定维度是否明确（存在/计价/损益）
- [ ] 是否考虑单笔重大例外对整体控制信赖的影响

### 四、缺陷分级与影响

- [ ] 偏差导致的缺陷是否按控制缺陷/值得关注缺陷/重大缺陷分级
- [ ] 缺陷是否评估了对投资计价/存在性/投资收益的影响
- [ ] 控制不可信赖时是否扩大估值独立复核、财务信息核对、函证
- [ ] 重大缺陷（尤其越权投资）是否已沟通治理层与管理层

## risk_areas

### 高风险

1. **投资决策审批系统性失效**：重大投资未经治理层审批的偏差被评为偶发，越权投资风险未被应对。
2. **估值复核控制缺陷影响计价**：公允价值/减值复核控制偏差未评估对投资计价可靠性的传导，投资估值错报风险未被识别。
3. **缺陷分级偏低未扩大实质性程序**：投资控制重大缺陷未触发估值独立复核与函证扩大，投资错报检查风险失控。
4. **资金划拨授权失效**：投资资金划拨越权偏差未评为重大缺陷，资金流失风险未被应对。

### 中风险

1. **投资收益确认偏差影响损益未评估**：投资收益确认控制偏差未评估对损益真实性影响。
2. **单笔重大例外影响未评估**：全查项目的单笔重大控制例外未评估对整体控制信赖的影响。
3. **偏差认定维度不清**：偏差影响存在性、计价还是损益未明确。

### 低风险

1. **偏差记录不规范**：偏差类型、涉及投资项目、金额记录格式不统一。
2. **评价参数留痕不足**：例外评估的重大性判断依据记录不充分。
3. **底稿索引缺失**：C5-2 与投资控制测试底稿、投资审定表、估值/减值底稿缺乏交叉索引。
