# C6-2 固定资产循环-评价控制偏差 复核提示词

## 概述

本提示词针对固定资产循环控制测试的偏差评价（C6-2）的复核，聚焦固定资产循环关键控制点——购置审批与验收、折旧计提复核、资产处置授权、资产实物盘点、减值评估——的控制偏差识别、偏差性质判断、偏差率外推、缺陷分级及对固定资产实质性程序的影响（CAS1231、CAS1314、CAS1211）。固定资产涉及原值、折旧、减值多重认定，购置与处置授权控制偏差影响存在性与完整性，折旧计提控制偏差影响计价与费用准确性。

**法规依据：**
- 《中国注册会计师审计准则第1231号——针对评估的重大错报风险采取的应对措施》
- 《中国注册会计师审计准则第1314号——审计抽样》
- 《中国注册会计师审计准则第1211号——通过了解被审计单位及其环境识别和评估重大错报风险》

## tips

1. **购置审批与验收控制偏差影响原值真实性**：固定资产购置未经审批或未验收即资本化的偏差直接影响原值存在性与完整性，偏差评价须审视资本化的授权依据。
2. **折旧计提控制偏差系统性影响费用**：折旧方法、年限、残值的设置与计提复核控制偏差通常系统性影响多期折旧费用，须评估对累计折旧与损益的传导。
3. **处置授权控制偏差关联资产流失**：固定资产处置未经授权或处置收入不入账的偏差是资产流失高危信号，须审慎判断系统性。
4. **实物盘点控制偏差决定存在性信赖**：定期实物盘点与账实核对控制的偏差若系统性发生，将削弱对固定资产存在性的信赖。
5. **资本化与费用化划分偏差影响损益**：修理支出与资本性支出划分控制的偏差影响资产与费用的准确性，须评估对损益的影响。
6. **缺陷分级决定固定资产程序范围**：购置/折旧/处置控制重大缺陷时，须扩大实物检查、折旧重算、处置收入核对与减值复核的实质性程序范围。

## checklist

### 一、控制偏差识别（固定资产循环专属）

- [ ] 固定资产购置审批控制偏差是否识别（未审批即购置/资本化）
- [ ] 固定资产验收控制偏差是否识别（未验收即入账）
- [ ] 折旧计提（方法/年限/残值）复核控制偏差是否识别
- [ ] 资产处置授权控制偏差是否识别（未授权处置/收入不入账）
- [ ] 固定资产实物盘点与账实核对控制偏差是否识别
- [ ] 资本化与费用化划分控制偏差是否识别
- [ ] 固定资产减值迹象评估控制偏差是否识别

### 二、偏差性质与根本原因

- [ ] 每项偏差是否评价为偶发例外还是系统性控制失效
- [ ] 折旧参数类偏差是否评估其系统性跨期影响
- [ ] 偏差根本原因是否分析（审批缺陷/参数设置错误/复核缺位）
- [ ] 偏差是否影响固定资产存在性、完整性或计价认定

### 三、偏差率外推与评价

- [ ] 样本偏差率是否正确计算并外推总体偏差率
- [ ] 偏差影响的认定维度是否明确（存在/原值/折旧/减值）
- [ ] 外推总体偏差率是否与可容忍偏差率比较
- [ ] 系统性折旧偏差是否单独评估其累积金额影响

### 四、缺陷分级与影响

- [ ] 偏差导致的缺陷是否按控制缺陷/值得关注缺陷/重大缺陷分级
- [ ] 缺陷是否评估了对固定资产原值/累计折旧/减值/损益的影响
- [ ] 控制不可信赖时是否扩大实物检查、折旧重算、处置核对范围
- [ ] 重大缺陷（尤其资产流失）是否已沟通治理层与管理层

## risk_areas

### 高风险

1. **处置授权控制系统性失效**：资产处置未授权或处置收入不入账偏差被评为偶发，资产流失风险未被应对。
2. **折旧计提系统性偏差**：折旧参数控制偏差系统性影响多期折旧却未评估累积金额影响，费用与计价错报未被识别。
3. **缺陷分级偏低未扩大实质性程序**：固定资产控制重大缺陷未触发实物检查与折旧重算扩大，固定资产错报检查风险失控。
4. **购置资本化控制失效**：未审批未验收即资本化偏差未评为重大缺陷，原值真实性存疑。

### 中风险

1. **资本化费用化划分偏差影响损益未评估**：资本性支出与修理费划分偏差未评估对损益影响。
2. **盘点控制偏差影响存在性未评估**：账实核对偏差未评估对固定资产存在性信赖的影响。
3. **偏差根本原因未析**：偏差仅记笔数未分析原因，无法判断偶发或系统性。

### 低风险

1. **偏差记录不规范**：偏差类型、涉及资产类别、金额记录格式不统一。
2. **抽样参数留痕不足**：样本量、可容忍偏差率、预计偏差率记录不完整。
3. **底稿索引缺失**：C6-2 与固定资产控制测试底稿、固定资产审定表、折旧测算与减值底稿缺乏交叉索引。
