# M2-2 实收资本（股本）明细表复核提示词

## 概述

本提示词针对实收资本（股本）明细表（M2-2，科目4001）的复核。该表分上市公司/非上市公司双版本，按出资人（股东）逐户列示实收资本的期初余额、本期增减、期末余额、出资方式及持股比例。明细表逐户核对可验证股本结构的完整性、出资到位的真实性及与股东名册的一致性。

**法规依据：**
- 《企业会计准则第11号——股份支付》
- 《企业会计准则第30号——财务报表列报》
- 《中国注册会计师审计准则第1301号——审计证据》
- 《中华人民共和国公司法》《公司注册资本登记管理规定》

---

## tips

1. **区分上市/非上市版本口径**：上市公司股本按股份数×面值列示并区分流通股/限售股，非上市公司按各股东实缴出资额列示，核对时须采用对应版本的列示逻辑。
2. **逐户核对股东名册**：各出资人名称、出资额、持股比例须与股东名册、公司章程、工商登记逐一核对，比例之和须为100%。
3. **明细合计必与审定表勾稽**：M2-2各股东期末余额合计须等于M2-1审定表期末审定数，差异反映遗漏、重复或录入错误。
4. **出资方式与到位核对**：区分货币出资、实物出资、知识产权出资、股权出资等方式，各出资须有验资报告和到位凭证支持。
5. **本期变动逐户追溯**：本期增资/减资/股权转让须逐户核对决议、验资、工商变更登记，验证变动的合法性和真实性。
6. **上市公司限售股与解禁**：上市公司须关注限售股份的锁定期、解禁安排，限售股与流通股的划分须准确列示。

## checklist

### 一、逐户核对与股本结构

- [ ] 各股东名称、出资额/股份数是否与股东名册/工商登记一致
- [ ] 各股东持股比例是否计算准确，比例之和是否为100%
- [ ] 上市公司版本是否按股份数×面值列示并区分流通股/限售股
- [ ] 非上市公司版本是否按各股东实缴出资额列示

### 二、出资到位与真实性

- [ ] 各股东出资是否有验资报告和到位凭证支持
- [ ] 出资方式（货币/实物/知识产权/股权）是否清晰列示
- [ ] 非货币出资是否经评估作价并办理产权转移
- [ ] 是否存在认缴未实缴部分被计入实收资本的情况

### 三、本期变动与勾稽

- [ ] 各股东本期增减变动是否有决议、验资、工商变更登记支持
- [ ] 股权转让是否办理变更登记，转让价格是否影响实收资本
- [ ] M2-2各股东期末余额合计是否等于M2-1审定表期末审定数
- [ ] 上市公司限售股锁定期、解禁安排是否准确列示

## risk_areas

### 高风险

1. **股东出资不实**：个别股东认缴未实缴或虚假出资却列示实收资本，导致资本虚增和股本结构失真。
2. **持股比例错误**：持股比例计算错误或比例之和不为100%，反映股本结构核算错误。
3. **变动未经法定程序**：股东出资变动未办理工商变更登记即入账，存在性和合法性缺陷。

### 中风险

1. **明细与审定表不勾稽**：逐户合计与审定表审定数不一致，存在遗漏、重复或汇总错误。
2. **出资方式与到位不符**：列示的出资方式与实际到位凭证不符，或非货币出资作价不实。
3. **限售股划分错误**：上市公司限售股与流通股划分错误，影响股本结构披露。

### 低风险

1. **股东排列顺序不统一**：列序、股东排列等格式问题不影响数据准确性。
2. **交叉索引不完整**：未与审定表、验资报告、股东名册建立完整索引引用。
3. **出资方式说明简略**：非货币出资的评估作价依据未详细列示。
