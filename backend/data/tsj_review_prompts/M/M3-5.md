# M3-5 库存股检查表复核提示词

## 概述

本提示词针对库存股检查表（M3-5，科目4002）的复核，聚焦股份回购与注销全流程的凭证级检查：回购决议与授权核对、回购交易与付款凭证核对、库存股用途合规（注销/员工持股/股权激励）、注销冲减核对、检查比例达标性、异常事项标注。检查表通过凭证核对验证回购真实性、用途合规性与注销处理正确性，是审定表和明细表的证据支撑。

**法规依据：**
- 《中国注册会计师审计准则第1314号——审计抽样》
- 《中国注册会计师审计准则第1301号——审计证据》
- 《企业会计准则第11号——股份支付》
- 《中华人民共和国公司法》（股份回购的条件、比例与期限限制）

## tips

1. **回购决议与授权是回购合法性基础**：核对董事会/股东大会回购决议、回购方案（数量上限/价格区间/资金总额/用途/期限），验证回购在授权范围内。
2. **凭证核对覆盖回购处置链条**：核对链条为回购决议→交易执行（券商清单）→资金支付（银行凭证）→库存股入账→注销/转让处置，任一环节缺失均属证据不完整。
3. **库存股用途合规是检查重点**：核对回购用途是否符合公司法规定情形（减少注册资本/员工持股计划/股权激励/可转债转股/维护公司价值及股东权益），不同用途处置方式和期限限制不同。
4. **注销冲减核对**：核对注销库存股冲减股本及资本公积/盈余公积/未分配利润的会计处理，验证与M2/M4/M5的联动正确。
5. **检查比例与限制核对**：验证回购比例是否超过法定限制（如维护公司价值目的回购不超过已发行股份10%）、是否在规定期限内处置或注销。
6. **关注异常回购事项**：回购价格显著偏离市价、回购后短期高价转让、股权激励行权与回购价差异常等须标注类型并调查。

## checklist

### 一、回购决议与授权核对

- [ ] 是否取得董事会/股东大会回购决议，形成程序是否合法
- [ ] 回购方案（数量/价格/资金/用途/期限）是否明确
- [ ] 实际回购是否在授权数量、价格区间和资金总额范围内
- [ ] 回购用途是否符合公司法规定情形

### 二、交易与付款凭证核对

- [ ] 回购交易是否有券商交易清单支持
- [ ] 回购资金支付是否有银行付款凭证，金额与交易一致
- [ ] 库存股入账金额（回购成本）是否与实际支付对价一致
- [ ] 是否存在回购价格显著偏离市价的异常并已标注

### 三、用途合规与注销核对

- [ ] 库存股用途（注销/员工持股/股权激励）是否合规且逐笔标注
- [ ] 注销库存股冲减股本及相关权益的处理是否正确（与M2/M4/M5联动）
- [ ] 用于股权激励的库存股行权处理是否符合CAS11
- [ ] 回购比例是否超过法定限制，是否在规定期限内处置/注销

### 四、检查比例与异常标注

- [ ] 金额重大回购/注销是否100%全覆盖检查
- [ ] 检查比例（已检查金额/总体金额）是否达到计划水平
- [ ] 异常事项（价格偏离/短期高价转让/行权价差异常）是否全部标注
- [ ] 检查发现的差异是否逐一追踪解决

## risk_areas

### 高风险

1. **回购缺乏合法授权**：股份回购无决议或超出授权范围（数量/价格/资金），构成违规回购。
2. **用途不合规**：回购用途不符合公司法规定情形，或超比例/超期限持有未处置。
3. **注销冲减处理错误**：注销库存股未正确冲减股本及相关权益，导致权益结构失真。

### 中风险

1. **检查比例不足**：实际检查比例低于计划水平，审计证据不充分。
2. **回购凭证不完整**：券商清单、付款凭证等缺失，回购真实性核对深度不够。
3. **异常回购遗漏**：回购价格偏离市价、短期高价转让等异常未识别标注。

### 低风险

1. **检查记录不完整**：抽样参数、核对结果的工作底稿记录不完整。
2. **索引缺失**：检查表与审定表、明细表、回购/注销决议的交叉索引不完整。
3. **格式不规范**：检查结果记录格式不统一，影响汇总分析。
