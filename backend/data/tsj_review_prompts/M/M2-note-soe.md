# M2-note-soe 实收资本（股本）附注披露复核提示词（国有企业）

## 概述

本提示词针对实收资本（股本）国有企业附注披露底稿（M2-note-soe，科目4001）的复核，聚焦国有企业特定的资本披露要求：国有资本出资及产权登记、国有股权比例变动、"三重一大"资本运作决策、与财务决算/产权登记勾稽。国有企业注册资本变动兼具会计披露与国有资产产权管理双重属性，附注须同时满足会计准则和国资监管要求。

**法规依据：**
- 《企业会计准则第30号——财务报表列报》
- 《企业会计准则第11号——股份支付》
- 《企业国有资产法》《企业国有资产交易监督管理办法》
- 《企业国有产权登记管理办法》

---

## tips

1. **国企资本披露有"双层"要求**：既满足会计准则通用披露，又须满足国有产权登记、国有资本经营预算等国资监管要求。
2. **国有资本出资须单独披露**：国有股东出资额、国有股权比例须单独披露，并与国有产权登记（占有/变动登记）勾稽。
3. **国有股权变动须履行审批程序**：国有股权增减、转让须经国资监管机构审批和产权交易程序，附注应披露审批和交易情况。
4. **"三重一大"决策须披露**：重大资本运作（增资/减资/改制）须经"三重一大"集体决策，附注应说明决策过程。
5. **与财务决算/产权登记勾稽**：实收资本数据须与年度财务决算报表、国有产权登记表一致。
6. **附注数据与审定表闭环勾稽**：附注实收资本期末余额必须等于M2-1审定表审定数，各股东份额与明细表勾稽。

## checklist

### 一、基础披露完整性（与上市版共有）

- [ ] 实收资本期末余额是否等于M2-1审定表审定数
- [ ] 是否披露期初数、本期变动数与期末数
- [ ] 各出资人出资额、持股比例是否列示且比例合计100%
- [ ] 本期资本变动是否说明性质及原因

### 二、国有资本与产权登记披露

- [ ] 国有股东出资额、国有股权比例是否单独披露
- [ ] 实收资本是否与国有产权登记（占有/变动登记）勾稽
- [ ] 国有股权变动是否披露国资监管机构审批及产权交易情况
- [ ] 是否披露国有资本经营预算相关资本变动

### 三、决策程序与决算勾稽

- [ ] 重大资本运作是否经"三重一大"决策并披露
- [ ] 实收资本数据是否与年度财务决算报表一致
- [ ] 增减资是否有验资报告和工商变更登记支持
- [ ] 是否披露资本变动对国有权益的影响

### 四、与上市版差异及关联方

- [ ] 国企版是否在基础披露上增加国有产权登记及审批信息
- [ ] 国有控股股东出资是否单独列示
- [ ] 是否披露关联方（同受国有控制单位）出资情况
- [ ] 混合所有制改革涉及的资本变动是否充分披露

## risk_areas

### 高风险

1. **国有资本出资未单独披露**：国有股东出资额、国有股权比例未单独列示，不满足国资监管要求。
2. **国有股权变动未履行审批**：国有股权增减/转让未经国资审批和产权交易程序，涉及国有资产流失风险。
3. **附注余额与审定表不一致**：附注实收资本期末余额与审定表审定数不勾稽，属重大数据错误。

### 中风险

1. **产权登记不勾稽**：实收资本与国有产权登记不一致，反映产权管理与账务脱节。
2. **"三重一大"程序说明缺失**：重大资本运作未披露集体决策过程。
3. **与财务决算不勾稽**：附注数据与年度财务决算报表存在差异未调节。

### 低风险

1. **披露格式未按决算模板**：附注格式与国资委决算报表模板有细微差异但信息完整。
2. **股权比例说明简略**：国有股权比例已披露但变动原因未详述。
3. **可比信息追溯不完整**：资本变动历史信息覆盖不足。
