# M5-4 盈余公积计提检查复核提示词

## 概述

本提示词针对盈余公积计提检查表（M5-4，科目4101）的复核，聚焦法定盈余公积计提的合规性专项检查：计提基数准确性、10%提取比例合规、注册资本50%上限判断、任意盈余公积决议依据、重新测算差异。计提检查是验证盈余公积提取是否符合公司法强制规定的核心底稿，计提错误将影响可供分配利润和权益结构。

**法规依据：**
- 《企业会计准则第30号——财务报表列报》
- 《中国注册会计师审计准则第1301号——审计证据》
- 《中华人民共和国公司法》第一百六十六条（法定盈余公积提取10%、累计达50%可不再提取、弥补亏损后提取）

---

## tips

1. **计提基数须为弥补亏损后净利润**：法定盈余公积提取基数=当年税后净利润−弥补以前年度亏损，验证基数确定的顺序和金额正确。
2. **10%比例是法定强制下限**：法定盈余公积按税后净利润10%强制提取，企业不得低于10%，验证实际提取比例合规。
3. **50%上限判断**：法定盈余公积累计额达到注册资本50%后可不再提取，验证累计余额与注册资本比例，判断是否达到停提条件。
4. **重新测算验证**：独立测算应提取法定盈余公积=（净利润−弥补亏损）×10%，与账面计提对比，差异须查明原因。
5. **任意盈余公积须决议支持**：任意盈余公积计提比例由公司自定，须有股东会决议，验证计提金额与决议一致。
6. **关注跨期与补提**：以前年度漏提/少提的补提须验证补提基数（对应年度净利润）和会计处理，跨期计提须正确归属。

## checklist

### 一、计提基数与比例

- [ ] 法定盈余公积计提基数是否为弥补亏损后的税后净利润
- [ ] 弥补亏损顺序是否正确（先弥补以前年度亏损）
- [ ] 法定盈余公积提取比例是否不低于10%
- [ ] 任意盈余公积计提是否有股东会决议且比例明确

### 二、上限判断与重新测算

- [ ] 法定盈余公积累计余额与注册资本50%上限的比例是否判断准确
- [ ] 累计达50%后是否正确停止强制提取
- [ ] 独立重新测算应提取额=（净利润−弥补亏损）×10%是否与账面一致
- [ ] 测算差异是否查明原因并记录

### 三、勾稽与合规

- [ ] 计提基数（净利润）是否与利润表勾稽
- [ ] 本期计提是否与M5-1审定表、M6利润分配提取栏勾稽
- [ ] 以前年度补提是否基数正确、归属恰当
- [ ] 计提检查结论是否支持审定表盈余公积审定数

## risk_areas

### 高风险

1. **漏提/少提法定盈余公积**：未按净利润10%足额提取，或提取比例低于法定下限，违反公司法强制规定。
2. **计提基数错误**：未弥补亏损即提取，或基数非税后净利润，导致计提金额错误、可供分配利润失真。
3. **上限判断错误**：累计未达50%却停止提取，或已达50%仍强制提取，计提合规判断错误。

### 中风险

1. **重新测算差异未查明**：独立测算与账面计提存在差异但未查明原因。
2. **任意盈余公积无决议**：任意盈余公积计提缺乏股东会决议支持。
3. **补提基数错误**：以前年度补提的基数或归属错误。

### 低风险

1. **计提检查记录不完整**：测算过程、基数确定的工作底稿记录不完整。
2. **索引缺失**：计提检查与审定表、明细表、利润表、M6的交叉索引不完整。
3. **格式不规范**：计提检查表格式不统一，影响复核效率。
