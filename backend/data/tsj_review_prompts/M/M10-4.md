# M10-4 负债与权益区分检查表 复核提示词

## 适用底稿
负债与权益区分检查表（M10-4），是M10模块的核心底稿，按CAS37逐条判定发行的金融工具应分类为金融负债还是权益工具，直接决定其他权益工具审定表的分类基础。

## tips

- 权益工具核心判定：是否不存在交付现金或其他金融资产的合同义务，且以自身权益工具结算时满足"固定换固定"
- 强制付息、含回售权、到期强制赎回、利率跳升实质构成付息义务的，通常应分类为金融负债
- 永续债判定关注：是否有明确到期日、发行人是否有权无条件递延付息、清偿顺序、利率跳升幅度是否构成间接义务
- 优先股判定关注：是否强制分派股息、是否可回售、是否强制赎回、股息是否累积
- 混合工具须拆分（含权益成分和负债成分的复合金融工具分别确认）
- 逐条判定须对照工具合同条款原文，判定结论须有明确依据
- 分类结论直接决定M10-1审定表分类及利息/股息的会计处理（利润分配vs财务费用）

## checklist

### 高风险检查项

- [ ] 是否逐条对照CAS37判定标准（合同义务/结算方式）进行分类判定
- [ ] 是否存在交付现金或其他金融资产的合同义务（决定负债属性）
- [ ] 永续债是否有明确到期日或实质到期义务
- [ ] 发行人是否有权无条件地自主递延付息（权益关键条件）
- [ ] 利率跳升机制是否构成间接的付息义务（实质为负债）
- [ ] 优先股是否强制分派股息或可回售/强制赎回（决定负债属性）
- [ ] 分类结论是否与M10-1审定表、M10-2明细表一致

### 中风险检查项

- [ ] 复合金融工具是否正确拆分权益成分与负债成分
- [ ] 以自身权益工具结算的是否满足"固定换固定"条件
- [ ] 清偿顺序、投资者权利等条款是否已纳入判定考量
- [ ] 判定依据是否引用合同条款原文并归档
- [ ] 分类对利息/股息会计处理（利润分配vs财务费用）的影响是否一致

### 低风险检查项

- [ ] 判定过程记录是否完整、逻辑清晰
- [ ] 合同/募集说明书等支持文件是否归档
- [ ] 检查表结论是否明确、可追溯
- [ ] 底稿索引与交叉引用是否完整（审定表/明细表）

## risk_areas

### 高风险

- **误分类为权益风险**：应分类为金融负债的工具（强制付息/含赎回义务/利率跳升构成间接义务）错分为权益，虚增权益、隐藏负债和财务费用（重大列报错报）
- **递延付息实质判断错误风险**：名义可递延付息但实质构成义务（如递延受限、利率跳升惩罚过高）仍分为权益
- **优先股属性误判风险**：强制分派/可回售/强制赎回的优先股误分为权益
- **复合工具未拆分风险**：含权益和负债成分的复合工具未分拆确认

### 中风险

- **结算条件判断错误风险**：以自身权益工具结算未满足"固定换固定"却分为权益
- **判定依据不足风险**：分类结论缺少合同条款支持
- **跨底稿不一致风险**：M10-4判定与M10-1、M10-2分类不一致

### 低风险

- **记录不完整风险**：判定过程记录不完整
- **文件归档缺失风险**：合同/募集说明书未归档
- **索引缺失风险**：与审定表、明细表交叉索引不完整
