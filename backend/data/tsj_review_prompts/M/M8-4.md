# M8-4 一般风险准备测试表 复核提示词

## 适用底稿
一般风险准备测试表（M8-4），聚焦风险资产范围界定、计提比例（1.5%）达标测试、计提金额重新测算及与拨备覆盖的勾稽。

## tips

- 风险资产范围须按监管口径界定（一般包括承担风险和损失的资产：贷款、拆借、投资、应收款项等，剔除低风险资产）
- 一般风险准备余额原则上不低于风险资产期末余额的1.5%（财金〔2012〕20号）
- 达标测试：测算应计提余额=风险资产×1.5%，与账面一般风险准备余额比对
- 计提金额重新测算：本期应补提=应计提余额-期初余额（若为正）
- 一般风险准备是在已足额计提资产减值准备基础上的补充，二者不可相互替代
- 关注风险资产范围人为缩小（少提）或以一般准备替代减值（掩盖资产质量）
- 结合拨备覆盖率、拨贷比等监管指标综合评估准备金充足性

## checklist

### 高风险检查项

- [ ] 风险资产范围界定是否符合监管口径
- [ ] 风险资产期末余额计算是否准确、是否包含全部应纳入资产
- [ ] 一般风险准备余额是否不低于风险资产的1.5%
- [ ] 计提金额重新测算是否与账面提取一致
- [ ] 是否以一般风险准备替代应计提的资产减值准备
- [ ] 是否存在人为缩小风险资产范围以规避补提

### 中风险检查项

- [ ] 低风险资产（如国债、现金等）是否正确剔除
- [ ] 应补提金额是否正确计算（应计提余额-期初余额）
- [ ] 计提金额是否与M8-2明细表本期提取一致
- [ ] 计提金额是否与M8-1审定表本期提取勾稽
- [ ] 拨备覆盖率/拨贷比等指标是否一并评估

### 低风险检查项

- [ ] 风险资产分类明细及来源数据是否附于底稿
- [ ] 计提比例的监管依据是否引用正确
- [ ] 测算过程是否可复核、公式是否正确
- [ ] 底稿索引与交叉引用是否完整（审定表/明细表）

## risk_areas

### 高风险

- **计提不足风险**：一般风险准备低于风险资产1.5%且未补提，违反监管要求
- **风险资产范围错误风险**：人为缩小风险资产范围以降低应计提金额
- **替代减值风险**：以一般风险准备替代应计提的资产减值准备，掩盖资产质量恶化
- **测算基数错误风险**：风险资产期末余额计算错误导致达标判断失真

### 中风险

- **低风险资产剔除错误风险**：应剔除的低风险资产未剔除或不应剔除的被剔除
- **补提金额计算错误风险**：应补提金额未正确计算
- **跨底稿不勾稽风险**：计提金额与M8-1、M8-2不一致

### 低风险

- **数据来源缺失风险**：风险资产分类明细未附于底稿
- **依据引用错误风险**：计提比例监管依据引用不准确
- **索引缺失风险**：与审定表、明细表交叉索引不完整
