# M6-2 未分配利润明细表 复核提示词

## 概述

本提示词针对未分配利润明细表（M6-2）的复核。明细表以利润分配结转公式链为核心，逐层反映"期初未分配利润→加本年净利润→减提取盈余公积→减分配股利→期末未分配利润"的完整过程。复核聚焦公式链各节点数据来源可靠、结转顺序正确、与审定表及相关权益科目勾稽一致。

**法规依据：**
- 《企业会计准则第30号——财务报表列报》
- 《企业会计准则第28号——会计政策、会计估计变更和差错更正》

---

## tips

1. **利润分配结转公式链是明细表核心**：逐行核对期初未分配利润、加本年净利润、减提取法定/任意盈余公积、减应付股利、加以前年度损益调整，得出期末未分配利润。
2. **本年净利润来源须可追溯**：明细表引入的本年净利润应可追溯至利润表及本年利润科目结转，不得手工录入无源数字。
3. **提取顺序须符合规定**：先提取法定盈余公积、再提取任意盈余公积、后向所有者分配，顺序颠倒可能违反公司法。
4. **以前年度损益调整单列**：追溯调整项须在明细表中单独列示并注明性质（政策变更/前期差错），调整期初而非本期。
5. **股利分配区分类型**：现金股利、股票股利（转增股本）、优先股股息须分别列示，各自对应不同的会计处理和权益科目变动。
6. **弥补亏损专项列示**：用未分配利润弥补以前年度亏损、盈余公积转入弥补亏损须专项列示并勾稽相关决议。

## checklist

### 一、公式链完整性

- [ ] 期末未分配利润=期初+本年净利润-盈余公积提取-股利分配±追溯调整
- [ ] 明细表各结转节点金额是否与来源底稿/科目一致
- [ ] 本年净利润是否与利润表净利润勾稽
- [ ] 提取法定盈余公积、任意盈余公积金额与M5盈余公积明细是否一致
- [ ] 应付股利、转增股本金额与M1应付股利、实收资本变动是否一致

### 二、结转顺序与合规

- [ ] 利润分配是否遵循法定盈余公积→任意盈余公积→股利的顺序
- [ ] 是否在弥补亏损后再进行分配
- [ ] 各项分配是否有股东会/董事会决议支持
- [ ] 以前年度损益调整是否单独列示并注明性质
- [ ] 弥补亏损项是否符合五年结转期限及相关决议

### 三、勾稽与汇总

- [ ] 明细表期末未分配利润合计是否等于M6-1审定表审定数
- [ ] 明细表本期变动是否与审定表借贷方发生额一致
- [ ] 明细表是否同时列示期初/期末可比数据
- [ ] 是否存在明细遗漏或重复计入

## risk_areas

### 高风险

1. **净利润结转来源错误**：明细表引入的本年净利润与利润表不符，导致整条公式链失真。
2. **利润分配顺序违规**：未弥补亏损或未提足法定盈余公积即分配股利。
3. **追溯调整错误处理**：以前年度损益调整未单列、错误调整本期或未提供依据。
4. **股票股利/转增股本处理错误**：股票股利转作股本金额与实收资本变动不勾稽。

### 中风险

1. **盈余公积提取与M5不一致**：明细表提取金额与盈余公积明细表口径不同。
2. **股利与M1不勾稽**：应付股利金额、类型与应付股利底稿不一致。
3. **明细与审定表不勾稽**：期末合计或本期变动与M6-1不一致。

### 低风险

1. **列示顺序不规范**：结转项排列顺序未按标准分配流程。
2. **可比信息缺失**：仅列期末数未列期初可比数。
3. **索引不完整**：未与利润表、M5、M1建立交叉索引。
