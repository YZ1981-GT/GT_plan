# M2-5 实收资本（股本）检查表复核提示词

## 概述

本提示词针对实收资本（股本）检查表（M2-5，科目4001）的复核，聚焦资本变动全流程的凭证级测试：出资/验资凭证核对、股本变动决议与工商登记核对、股份支付确认、股东名册核对、检查比例达标性、异常事项标注。检查表通过凭证核对验证资本形成与变动的真实性、合法性与完整性，是审定表和明细表的证据支撑。

**法规依据：**
- 《中国注册会计师审计准则第1314号——审计抽样》
- 《中国注册会计师审计准则第1301号——审计证据》
- 《企业会计准则第11号——股份支付》
- 《中华人民共和国公司法》《公司注册资本登记管理规定》

---

## tips

1. **验资报告是出资到位的核心证据**：核对验资报告的验资机构资质、验资范围、验资结论，验资金额须与实收资本入账金额一致。
2. **凭证核对覆盖资本变动链条**：核对链条为出资决议→资金到位/资产转移→验资→工商变更登记→账务确认，任一环节缺失均属证据不完整。
3. **股本变动决议与工商登记核对**：增减资、股权转让须核对股东会决议、公司章程修正案、工商变更登记，验证程序合法与登记及时。
4. **股份支付确认须符合CAS11**：涉及以权益结算的股份支付形成的实收资本，须核对授予协议、行权条件、公允价值计量是否符合CAS11。
5. **股东名册核对验证股本结构**：核对股东名册与实收资本明细、工商登记的一致性，验证股东身份、出资额、持股比例真实准确。
6. **关注异常出资事项**：以自身资产循环出资、抽逃出资、名义股东/代持、评估作价虚高等异常须标注类型并调查。

## checklist

### 一、出资与验资凭证核对

- [ ] 是否取得验资报告，验资机构资质、验资结论是否合法有效
- [ ] 验资金额是否与实收资本入账金额一致
- [ ] 货币出资是否有银行进账凭证，收款方为公司账户
- [ ] 非货币出资是否有评估报告和产权转移凭证

### 二、变动决议与工商登记核对

- [ ] 资本增减/股权转让是否有股东会决议、章程修正案
- [ ] 是否办理工商变更登记，登记的注册资本与账面一致
- [ ] 变动决议形成程序是否合法（表决权比例、程序要件）
- [ ] 是否存在已变动但未办理工商登记的情况

### 三、股份支付与股东名册

- [ ] 涉及股份支付的实收资本是否符合CAS11确认计量要求
- [ ] 股东名册与实收资本明细、工商登记是否一致
- [ ] 股东身份、出资额、持股比例是否真实准确
- [ ] 是否存在名义股东/代持安排并已核查披露

### 四、检查比例与异常标注

- [ ] 金额重大出资/变动是否100%全覆盖检查
- [ ] 检查比例（已检查金额/总体金额）是否达到计划水平
- [ ] 异常事项（抽逃出资/循环出资/作价虚高）是否全部标注
- [ ] 检查发现的差异是否逐一追踪解决

## risk_areas

### 高风险

1. **虚假出资/抽逃出资**：验资后抽回出资、以自身资产循环出资，导致实收资本虚增、资本不实。
2. **变动未办工商登记**：资本增减/股权转让未办理工商变更登记即入账，登记与账面不符，存在合法性缺陷。
3. **股份支付确认错误**：以权益结算的股份支付未按CAS11确认计量，导致实收资本和费用核算错误。

### 中风险

1. **检查比例不足**：实际检查比例低于计划水平，审计证据不充分。
2. **验资凭证不完整**：验资报告、进账凭证、评估报告等缺失，核对深度不够。
3. **代持/名义股东未核查**：存在股权代持安排但未核查真实出资人和披露。

### 低风险

1. **检查记录不完整**：抽样参数、核对结果的工作底稿记录不完整。
2. **索引缺失**：检查表与审定表、明细表、验资报告的交叉索引不完整。
3. **格式不规范**：检查结果记录格式不统一，影响汇总分析。
