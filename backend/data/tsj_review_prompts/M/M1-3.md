# M1-3 应付股利调整分录汇总复核提示词

## 概述

本提示词针对应付股利调整分录汇总表（M1-3，科目2232）的复核，含账项调整（AJE）、重分类调整（RJE）及未调整错报（SUD）评估。复核须验证每笔调整有证据、借贷平衡、完整反映至M1-1审定表，并同步试算平衡表，避免"底稿已调、TB未更"的双真源问题。

**法规依据：**
- 《中国注册会计师审计准则第1301号——审计证据》
- 《企业会计准则第30号——财务报表列报》
- 《中华人民共和国公司法》（利润分配决议）

---

## tips

1. **AJE 与 RJE 区分**：AJE 影响负债或权益金额（如补记漏宣告的应付股利）；RJE 仅影响列报（如流动/非流动重分类），不得通过 RJE 掩盖负债漏记。
2. **与 M1-1 勾稽**：审定表调整列金额须与 M1-3 已确认分录逐笔一致，遗漏任一笔即审定数失真。
3. **补记宣告股利的调整需决议支持**：因宣告未挂账而补记应付股利的AJE，须以董事会/股东大会决议为依据，借记利润分配、贷记应付股利。
4. **审批链留痕**：超过明细层次重要性水平的调整须经合伙人/项目经理审批留痕。
5. **SUD 累计评估**：未调整错报单独及累计是否超过整体/明显微小错报阈值，须与 A13 未调整错报汇总交叉验证。
6. **TB 回写确认**：确认调整已同步试算平衡表2232科目，与M6利润分配对应调整联动。

## checklist

### 高风险检查项

- [ ] 所有 AJE 是否有充分审计证据（分配决议、股东名册、支付凭证等）
- [ ] 补记漏宣告应付股利的调整是否有分配决议支持且对方科目正确（利润分配）
- [ ] AJE 是否经适当层级审批（超重要性水平须合伙人知悉）
- [ ] 每笔调整分录借贷方是否完全平衡
- [ ] 调整金额是否完整反映到 M1-1 审定表对应调整列
- [ ] 未调整错报累计是否超过整体重要性水平（须评估并记录）

### 中风险检查项

- [ ] RJE 是否仅涉及列报（如流动/非流动重分类），未影响负债或权益金额
- [ ] 调整原因说明是否清晰可追溯至具体审计程序
- [ ] 与 A13 未调整错报汇总表索引是否完整
- [ ] 建议调整与已执行调整是否区分记录
- [ ] 涉及代扣个税的调整是否同步考虑税金负债影响

### 低风险检查项

- [ ] 分录摘要、科目编码是否规范，编号是否连续
- [ ] 索引是否指向 M1-6 检查表、M6 利润分配等支持底稿
- [ ] 审计说明/结论是否概括调整性质与残余风险

## risk_areas

### 高风险

1. **调整缺乏证据或未经授权**：补记或冲减应付股利的调整无分配决议或审批支持，构成越权或错误调整。
2. **审定表与M1-3调整金额不一致**：调整未完整反映审定表，导致审定数失真、掩盖负债漏记。
3. **SUD累计超阈值未处理**：未调整错报累计超过整体重要性水平却未恰当处理审计意见。

### 中风险

1. **RJE误含负债金额影响**：本应仅重分类的调整却改变了应付股利金额，混淆列报与计量。
2. **对方科目错误**：补记应付股利未借记利润分配而误借其他科目，导致权益变动核算错误。
3. **代扣个税联动遗漏**：调整应付股利未同步考虑代扣个税负债的影响。

### 低风险

1. **编号、格式不规范**：分录编号不连续、摘要不清晰影响可追溯性。
2. **索引指向不完整**：调整分录与支持底稿的交叉引用缺失。
3. **审计说明过于简略**：未概括调整性质及对财务报表的整体影响。
