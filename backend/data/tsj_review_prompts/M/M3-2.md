# M3-2 库存股明细表复核提示词

## 概述

本提示词针对库存股明细表（M3-2，科目4002）的复核，该表按回购批次逐笔列示库存股的回购日期、回购数量、回购价格、回购成本、注销/转让情况及期末余额。明细表逐批次核对可验证回购的真实性、回购成本计量准确性及库存股用途与处置的合规性。

**法规依据：**
- 《企业会计准则第11号——股份支付》
- 《企业会计准则第30号——财务报表列报》
- 《中国注册会计师审计准则第1301号——审计证据》
- 《中华人民共和国公司法》（股份回购）

---

## tips

1. **逐批次核对回购真实性**：各回购批次的回购日期、数量、价格、金额须与回购交易记录、券商交易清单、银行付款凭证逐笔核对。
2. **回购成本按实际对价计量**：库存股按回购支付的实际对价（含交易费用是否计入须一致处理）计量，逐批次核对回购成本=数量×价格计算准确。
3. **明细合计必与审定表勾稽**：M3-2各批次期末余额合计须等于M3-1审定表期末审定数，差异反映遗漏、重复或录入错误。
4. **回购用途逐批次标注**：各批次回购用途（减资/员工持股/股权激励/可转债转股）须逐批次标注，用途决定后续处置方式和会计处理。
5. **注销/转让处置核对**：本期注销或转让的库存股批次须核对处置决议、处置价格及会计处理，转让价差计入资本公积。
6. **关注回购限制与期限**：核对回购是否超过法定比例限制（如用于减资外的回购不超过已发行股份总数10%）、是否在规定期限内处置。

## checklist

### 一、逐批次核对与回购真实性

- [ ] 各批次回购日期、数量、价格是否与交易记录/券商清单一致
- [ ] 各批次回购成本是否有银行付款凭证支持
- [ ] 回购成本=回购数量×回购价格是否逐批次计算正确
- [ ] 交易费用处理是否前后一致（计入成本或费用化）

### 二、用途与处置核对

- [ ] 各批次回购用途是否逐批次标注且符合公司法情形
- [ ] 本期注销/转让批次是否有处置决议支持
- [ ] 转让价差是否正确计入资本公积（不计入损益）
- [ ] 是否超过法定回购比例限制或处置期限

### 三、勾稽与列报

- [ ] M3-2各批次期末余额合计是否等于M3-1审定表期末审定数
- [ ] 库存股各批次是否以备抵借方列示
- [ ] 用于股权激励的库存股是否与股份支付核算勾稽
- [ ] 各批次剩余库存股数量与股份登记机构记录是否一致

## risk_areas

### 高风险

1. **回购交易虚假**：列示的回购批次缺乏真实交易记录或付款凭证，导致库存股虚增。
2. **回购成本计量错误**：回购成本未按实际对价计量或计算错误，导致权益备抵金额失真。
3. **超比例/超期限回购**：回购超过法定比例限制或未在规定期限内处置，构成违规。

### 中风险

1. **明细与审定表不勾稽**：各批次合计与审定表审定数不一致，存在遗漏、重复或汇总错误。
2. **转让价差处理错误**：库存股转让价差误计入损益而非资本公积。
3. **用途标注缺失**：各批次回购用途未标注，无法评估处置合规性。

### 低风险

1. **交易费用处理不一致**：交易费用计入成本或费用化处理前后不一致。
2. **批次排列不规范**：列序、批次排列等格式问题不影响数据准确性。
3. **交叉索引不完整**：未与审计表、交易记录、处置决议建立完整索引。
