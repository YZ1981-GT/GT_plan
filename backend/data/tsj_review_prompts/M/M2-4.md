# M2-4 外币投资汇率测算表复核提示词

## 概述

本提示词针对实收资本外币投资汇率测算表（M2-4，科目4001）的复核，聚焦外币出资（外商投资/外币增资）的折算准确性：出资到位日汇率选取、折算本币入账、汇率折算差额处理、公式勾稽。外币出资形成的实收资本按出资到位日即期汇率折算入账，属非货币性权益项目，后续不因汇率变动调整实收资本，折算错误将导致注册资本本币金额失真。

**法规依据：**
- 《企业会计准则第19号——外币折算》
- 《企业会计准则第30号——财务报表列报》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **实收资本是非货币性权益项目**：外币出资形成的实收资本按出资到位日即期汇率折算入账后不再随汇率变动重新折算，与外币货币性负债处理不同。
2. **折算汇率应为出资到位日即期汇率**：核对各笔外币出资的到位日期与采用的折算汇率是否匹配，多笔分期出资须分别按各自到位日汇率折算。
3. **折算差额处理须正确**：合同约定汇率与实际到位日汇率的差额处理须符合章程/合同约定和准则要求，通常计入资本公积而非实收资本。
4. **公式勾稽逐项验证**：折算本币金额=外币出资额×到位日汇率，逐笔核对计算无误，多笔出资合计准确。
5. **与审定表和验资报告勾稽**：折算后实收资本本币金额须与M2-1审定表和验资报告一致，验资报告中的折算汇率是重要核对依据。
6. **关注汇率来源与合规**：折算汇率须采用权威来源（中国人民银行公布汇率），外商投资须符合外汇管理规定。

## checklist

### 一、汇率选取与来源

- [ ] 各笔外币出资的折算汇率是否为出资到位日的即期汇率
- [ ] 汇率来源是否权威（中国人民银行公布汇率）并核对生效日期
- [ ] 分期出资是否分别按各自到位日汇率折算
- [ ] 折算汇率是否与验资报告中的汇率一致

### 二、折算公式与计算

- [ ] 折算本币金额=外币出资额×到位日汇率是否逐笔成立
- [ ] 合同约定汇率与实际汇率差额处理是否正确（通常计入资本公积）
- [ ] 多笔出资折算本币合计是否加总无误
- [ ] 折算后是否未因后续汇率变动错误调整实收资本

### 三、勾稽与合规

- [ ] 折算后实收资本本币金额是否与M2-1审定表一致
- [ ] 折算差额计入资本公积部分是否与M4勾稽
- [ ] 外币出资是否符合外汇管理及外商投资相关规定
- [ ] 外币出资在附注中是否按币种披露（如金额重大）

## risk_areas

### 高风险

1. **使用错误汇率折算**：外币出资未按到位日即期汇率折算（如误用合同汇率或期末汇率），导致实收资本本币金额失真。
2. **实收资本随汇率变动错误调整**：将实收资本作为货币性项目期末重新折算，违反外币折算准则。
3. **折算金额与审定表脱节**：M2-4折算结果未回填审定表或与验资报告不一致。

### 中风险

1. **折算差额处理错误**：合同汇率与实际汇率差额误计入实收资本而非资本公积。
2. **分期出资汇率混用**：多笔分期出资未分别按到位日汇率折算，混用汇率产生偏差。
3. **汇率来源不可靠**：折算汇率来源不明或生效日期错误。

### 低风险

1. **小数位精度不一致**：汇率或金额小数位处理不统一，产生微小误差。
2. **披露不充分**：外币出资金额重大但附注未按币种披露。
3. **测算表格式不规范**：币种、汇率、金额列序不清晰。
