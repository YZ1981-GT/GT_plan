# M8-1 一般风险准备审定表 复核提示词

## 概述

本提示词针对一般风险准备审定表（M8-1）的复核。一般风险准备是金融企业按规定从净利润中提取、用于弥补尚未识别的可能性损失的所有者权益项目（一般按风险资产期末余额的1.5%作为参考下限）。审定表须验证权益类贷方勾稽（期末=期初+本期提取-本期使用）、计提比例合规、与拨备覆盖及风险资产勾稽、以及与试算平衡表科目勾稽。

**法规依据：**
- 《企业会计准则第30号——财务报表列报》
- 《企业会计准则第22号——金融工具确认和计量》
- 《金融企业准备金计提管理办法》（财金〔2012〕20号）
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **一般风险准备是权益类贷方科目**：期末余额=期初余额+本期提取（贷方）-本期动用（借方），方向判断错误将导致审定数失真。
2. **计提来源于净利润分配**：一般风险准备从净利润中提取（借利润分配、贷一般风险准备），属所有者权益内部，不计入当期损益，与专项储备（计入成本费用）处理不同。
3. **计提比例合规是核心**：金融企业一般准备余额原则上不低于风险资产期末余额的1.5%，须核实计提基数（风险资产）与比例是否达标。
4. **与减值准备的关系**：一般风险准备是在已计提资产减值准备（拨备）基础上的补充缓冲，不得以一般风险准备替代应计提的减值准备。
5. **期初承前启后核对**：期初一般风险准备须等于上年审定表期末余额，差异须追溯说明。
6. **动用限制**：一般风险准备的动用（弥补损失）须符合监管规定和审批程序，关注是否存在违规冲回或动用。

## checklist

### 一、权益勾稽与方向

- [ ] 期末一般风险准备是否等于期初+本期提取-本期动用
- [ ] 提取（贷方）、动用（借方）方向是否正确
- [ ] 期初一般风险准备是否等于上年审定表期末余额
- [ ] 计提是否通过利润分配而非计入当期损益
- [ ] 是否存在期初被修改但未留痕、未说明的情况

### 二、计提比例合规

- [ ] 一般风险准备余额是否不低于风险资产期末余额的1.5%
- [ ] 计提基数（风险资产）范围界定是否正确
- [ ] 本期提取金额是否使余额达到监管要求
- [ ] 是否以一般风险准备替代应计提的资产减值准备
- [ ] 计提比例是否与M8-4风险资产测试结果一致

### 三、试算平衡表与调整核对

- [ ] 审定表一般风险准备审定数是否与试算平衡表对应科目审定数一致
- [ ] 所有AJE、RJE是否完整反映在审定表
- [ ] 调整分录借贷方是否平衡、调整后金额是否=未审数+AJE+RJE
- [ ] 审定表数据是否与M8-2明细表提取/动用勾稽
- [ ] 动用一般风险准备是否有充分审批依据

## risk_areas

### 高风险

1. **计提比例不达标**：一般风险准备余额低于风险资产1.5%的监管要求且未补提，存在合规风险。
2. **以一般准备替代减值准备**：用一般风险准备掩盖应计提的资产减值，虚增资产和利润。
3. **计提来源错误**：将一般风险准备计入当期损益而非利润分配，扭曲净利润。
4. **违规动用/冲回**：未经审批动用或冲回一般风险准备，虚增可分配利润。

### 中风险

1. **计提基数错误**：风险资产范围界定错误，导致计提基数偏差。
2. **与M8-4测试不一致**：审定表计提金额与风险资产测试结果不符。
3. **调整分录方向或金额错误**：AJE/RJE影响一般风险准备的方向颠倒或金额有误。
4. **期初不勾稽**：期初余额与上年期末审定数不一致且无追溯依据。

### 低风险

1. **审定表格式不规范**：行项目顺序、列标题等格式问题。
2. **交叉索引不完整**：未与M8-2明细表、M8-4风险资产测试建立索引。
3. **变动说明不充分**：重大变动未附说明。
