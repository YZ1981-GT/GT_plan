# M4-3 资本公积调整分录汇总复核提示词

## 概述

本提示词针对资本公积调整分录汇总表（M4-3，科目4002）的复核，含账项调整（AJE）、重分类调整（RJE）及未调整错报（SUD）评估。复核须验证每笔调整有来源凭证/决议证据、借贷平衡、完整反映至M4-1审定表，并同步试算平衡表，尤须关注资本溢价与其他资本公积的划分及权益法核算调整的正确性。

**法规依据：**
- 《中国注册会计师审计准则第1301号——审计证据》
- 《企业会计准则第30号——财务报表列报》
- 《企业会计准则第2号——长期股权投资》
- 《中华人民共和国公司法》

---

## tips

1. **AJE 与 RJE 区分**：AJE 影响资本公积金额（如更正权益法其他权益变动）；RJE 涉及权益内部重分类（资本公积与实收资本/盈余公积调整），不得通过 RJE 掩盖权益错报。
2. **与 M4-1 勾稽**：审定表调整列金额须与 M4-3 已确认分录逐笔一致，遗漏任一笔即审定数失真。
3. **权益法调整须与G7联动**：调整权益法下其他资本公积须与长期股权投资（G7）权益法核算联动核对，对方科目正确。
4. **转增资本调整须联动M2**：资本公积转增股本的调整须借记资本公积、贷记实收资本，与实收资本（M2）联动核对。
5. **SUD 累计评估**：未调整错报单独及累计是否超过整体/明显微小错报阈值，须与 A13 未调整错报汇总交叉验证。
6. **TB 回写确认**：确认调整已同步试算平衡表4002科目（贷方口径），方向正确。

## checklist

### 高风险检查项

- [ ] 所有 AJE 是否有充分审计证据（发行凭证、权益法核算、决议等）
- [ ] 更正资本溢价/其他资本公积的调整是否来源清晰且对方科目正确
- [ ] 权益法其他资本公积调整是否与G7联动核对
- [ ] 每笔调整分录借贷方是否完全平衡
- [ ] 调整金额是否完整反映到 M4-1 审定表对应调整列
- [ ] 转增资本调整是否与实收资本（M2）联动核对
- [ ] 未调整错报累计是否超过整体重要性水平（须评估并记录）

### 中风险检查项

- [ ] RJE 是否仅涉及权益内部重分类，未虚增或虚减权益总额
- [ ] 资本溢价与其他资本公积划分调整是否正确
- [ ] 调整原因说明是否清晰可追溯至具体审计程序
- [ ] 与 A13 未调整错报汇总表索引是否完整
- [ ] 建议调整与已执行调整是否区分记录

### 低风险检查项

- [ ] 分录摘要、科目编码是否规范，编号是否连续
- [ ] 索引是否指向 M4-4 检查表、G7、发行凭证等支持底稿
- [ ] 审计说明/结论是否概括调整性质与残余风险

## risk_areas

### 高风险

1. **调整缺乏来源凭证**：调整资本公积无发行凭证、权益法核算或决议支持，构成越权或错误调整。
2. **审定表与M4-3调整金额不一致**：调整未完整反映审定表，导致审定数失真。
3. **权益法调整与G7脱节**：其他资本公积权益法调整未与长期股权投资联动，核算不一致。

### 中风险

1. **资本溢价与其他资本公积划分错误**：调整未正确区分两类资本公积，来源性质混淆。
2. **转增资本联动遗漏**：转增股本调整未与实收资本联动，权益内部结构核算错误。
3. **RJE虚增/虚减权益总额**：本应内部重分类的调整却改变了所有者权益总额。

### 低风险

1. **编号、格式不规范**：分录编号不连续、摘要不清晰影响可追溯性。
2. **索引指向不完整**：调整分录与G7、发行凭证等支持底稿的交叉引用缺失。
3. **审计说明过于简略**：未概括调整性质及对财务报表的整体影响。
