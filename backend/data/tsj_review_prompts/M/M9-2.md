# M9-2 其他综合收益明细表 复核提示词

## 概述

本提示词针对其他综合收益明细表（M9-2）的复核。明细表按OCI分项逐项列示"税前发生额、所得税影响、税后净额"及"计入OCI、结转损益（重分类）、结转留存收益"的完整过程。复核聚焦分项归类正确、税前税后勾稽、重分类与结转处理，以及与审定表和各来源底稿勾稽。

**法规依据：**
- 《企业会计准则第30号——财务报表列报》
- 《企业会计准则第19号——外币折算》
- 《企业会计准则第22号——金融工具确认和计量》

---

## tips

1. **OCI分项+税后净额公式链**：逐项核对税前发生额、所得税影响、税后净额，税后净额=税前发生额-所得税影响。
2. **分项须归入两大类**：明细表各分项须明确归入"不能重分类"或"能重分类"，并与审定表分类一致。
3. **本期变动构成**：区分本期计入OCI的金额、本期转入损益（重分类）的金额、以及FVOCI权益工具处置转入留存收益的金额。
4. **所得税影响联动递延税**：每项OCI的所得税影响须与递延所得税资产/负债的变动勾稽。
5. **来源可追溯**：各分项应可追溯至来源底稿（G8公允变动、J2重计量、外币折算差额等）。
6. **期末合计勾稽审定表**：明细表各分项税后净额合计的期末余额须等于M9-1审定表审定数。

---

## checklist

### 一、公式链完整性

- [ ] 各分项税后净额=税前发生额-所得税影响
- [ ] 各分项是否明确归入两大类且与审定表一致
- [ ] 本期变动是否区分计入OCI、转入损益、转入留存收益
- [ ] 各分项期末合计是否等于M9-1审定表审定数
- [ ] 是否同时列示期初/期末可比数据

### 二、税务与来源核对

- [ ] 各项所得税影响是否与递延所得税变动勾稽
- [ ] FVOCI公允价值变动分项是否与G8勾稽
- [ ] 设定受益计划重计量分项是否与J2勾稽
- [ ] 外币财务报表折算差额是否与折算底稿勾稽
- [ ] 权益法下OCI份额是否与长期股权投资勾稽

### 三、重分类与结转

- [ ] 可重分类项目转入损益的金额及依据是否正确
- [ ] FVOCI权益工具处置是否正确转入留存收益（非损益）
- [ ] 重分类时点是否符合准则要求
- [ ] 明细表本期变动是否与审定表勾稽

## risk_areas

### 高风险

1. **税前税后勾稽断裂**：税后净额与税前发生额扣所得税影响不勾稽。
2. **重分类处理错误**：可重分类项目结转损益金额或时点错误，权益工具处置误转损益。
3. **分项归类错误**：分项归入错误大类，影响能否转损益。

### 中风险

1. **所得税影响与递延税不勾稽**：OCI所得税影响与递延所得税变动不一致。
2. **来源不勾稽**：分项与G8、J2、外币折算等来源底稿不一致。
3. **明细与审定表不勾稽**：分项合计与M9-1不一致。

### 低风险

1. **列示不规范**：分项排列或两大类顺序问题。
2. **可比信息缺失**：仅列期末数未列期初可比数。
3. **索引不完整**：未与来源底稿建立交叉索引。
