# M3-note-listed 库存股附注披露复核提示词（上市公司）

## 概述

本提示词针对库存股上市公司附注披露底稿（M3-note-listed，科目4002）的复核，聚焦上市公司库存股披露的充分性与准确性：库存股期末余额及构成、本期回购/注销/转让变动、回购决议与授权披露、回购用途及处置进展、与股本及所有者权益变动表勾稽。库存股是上市公司资本运作的重要事项，回购信息是投资者和监管高度关注的内容。

**法规依据：**
- 《企业会计准则第30号——财务报表列报》
- 《企业会计准则第11号——股份支付》
- 《公开发行证券的公司信息披露编报规则第15号——财务报告的一般规定》
- 《上市公司股份回购规则》

---

## tips

1. **库存股作为权益备抵披露**：附注须披露库存股期末数量、金额，并说明其作为所有者权益备抵项目冲减权益的性质。
2. **回购变动明细须完整披露**：完整列示期初库存股、本期回购（数量/金额/价格区间）、本期注销/转让、期末库存股，各变动须说明依据。
3. **回购决议与授权须充分披露**：披露回购的董事会/股东大会决议、回购方案（数量上限/价格/资金/用途/期限）及实施进展。
4. **回购用途及处置进展是披露重点**：披露回购用途（注销/员工持股/股权激励）及后续处置安排、期限，用于股权激励的须与激励计划勾稽。
5. **与股本及权益变动表勾稽**：库存股变动须与所有者权益变动表勾稽，注销库存股导致的股本减少须与股本变动披露一致。
6. **附注数据与审定表闭环勾稽**：附注库存股期末余额必须等于M3-1审定表审定数，各批次与M3-2明细表勾稽。

## checklist

### 一、期末余额与构成披露

- [ ] 库存股期末数量、金额是否披露
- [ ] 库存股期末余额是否等于M3-1审定表审定数
- [ ] 是否说明库存股作为权益备抵冲减所有者权益的性质
- [ ] 是否披露期初数与期末数（可比信息）

### 二、回购变动明细披露

- [ ] 回购变动明细是否完整（期初/回购/注销/转让/期末）
- [ ] 本期回购数量、金额、价格区间是否披露
- [ ] 本期注销/转让数量、金额及处置价差是否披露
- [ ] 各变动是否说明依据（回购/注销决议）

### 三、回购决议与用途披露

- [ ] 是否披露回购的董事会/股东大会决议及回购方案
- [ ] 回购用途（注销/员工持股/股权激励）是否披露
- [ ] 回购实施进展、剩余额度、处置期限是否说明
- [ ] 用于股权激励的库存股是否与激励计划勾稽

### 四、勾稽与其他披露

- [ ] 库存股变动是否与所有者权益变动表勾稽
- [ ] 注销库存股导致的股本减少是否与股本变动披露一致
- [ ] 各批次库存股与M3-2明细表是否勾稽
- [ ] 期后重大回购/注销/转让是否作为期后事项披露

## risk_areas

### 高风险

1. **附注余额与审定表不一致**：附注库存股期末余额与审定表审定数不一致，属重大数据勾稽错误。
2. **回购决议信息缺失**：未披露回购决议、方案及授权情况，不满足上市公司股份回购信息披露要求。
3. **回购用途披露缺失**：未披露回购用途及处置安排，投资者无法评估回购目的与后续影响。

### 中风险

1. **回购变动明细不完整**：库存股变动明细缺失或与权益变动表不勾稽。
2. **注销与股本变动不一致**：注销库存股导致的股本减少与股本变动披露不一致。
3. **股权激励勾稽缺失**：用于股权激励的库存股未与激励计划勾稽。

### 低风险

1. **披露格式不规范**：表格标题、列序、单位等格式细节未严格按编报规则。
2. **备抵性质说明简略**：库存股冲减权益的性质说明过于简略。
3. **期后事项披露简略**：期后回购/处置仅提及事实未说明影响。
