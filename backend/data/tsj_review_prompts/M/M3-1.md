# M3-1 库存股审定表复核提示词

## 概述

本提示词针对库存股审定表（M3-1，科目4002）的复核，聚焦所有者权益循环中库存股这一特殊权益备抵项目的审计要点：期初期末勾稽（借方口径）、试算平衡表核对、回购真实性与授权、注销冲减完整性。库存股是企业回购尚未注销或转让的本公司股份，作为所有者权益的备抵项目以借方列示，期末=期初+回购（借方）−注销/转让（贷方），方向处理错误将导致权益列报重大错报。

**法规依据：**
- 《企业会计准则第11号——股份支付》
- 《企业会计准则第30号——财务报表列报》
- 《中国注册会计师审计准则第1301号——审计证据》
- 《中华人民共和国公司法》（股份回购的条件与限制）

---

## tips

1. **库存股是权益备抵借方项目**：库存股在所有者权益中以借方（负数）列示，冲减所有者权益，期末余额=期初+本期回购（借方增加）−本期注销/转让（贷方减少），方向与一般权益科目相反。
2. **期初期末勾稽须遵循借方口径**：期初审定数须等于上年期末审定数，期末=期初+回购−注销/转让±审计调整，任何变动须有回购决议、注销决议支持。
3. **试算平衡表核对须注意备抵方向**：审定表库存股审定数须与试算平衡表4002科目审定数一致（权益备抵借方口径），核对时须确认借贷方向正确。
4. **回购须有合法授权和用途**：股份回购须符合公司法规定的情形（减少注册资本/员工持股/股权激励/可转债转股/维护公司价值等），核对回购决议、授权范围及用途合规性。
5. **回购价格与金额核对**：库存股按回购成本（实际支付对价）入账，核对回购价格、数量与实际支付金额，验证入账金额准确。
6. **注销冲减处理须正确**：注销库存股时冲减股本及资本公积/盈余公积/未分配利润，核对注销的会计处理和对各权益项目的影响，与M2/M4/M5联动。

## checklist

### 一、期初期末勾稽（借方口径）

- [ ] 审定表期初未审数是否等于上年审定表期末审定数（承前启后核对）
- [ ] 期末审定数是否等于期初+本期回购（借方）−本期注销/转让（贷方）±审计调整
- [ ] 库存股是否以备抵借方（负数）冲减所有者权益列示
- [ ] 审定表各行变动是否与明细表（M3-2）按回购批次增减一致

### 二、试算平衡表与科目核对

- [ ] 审定表库存股审定数是否与试算平衡表4002科目审定数一致（备抵借方口径）
- [ ] 试算平衡表未审数、调整数（AJE+RJE）与审定表对应列是否一致
- [ ] 库存股借贷方向是否正确（冲减权益而非增加）
- [ ] 是否存在试算平衡表已更新但审定表未同步的情况

### 三、回购真实性与授权

- [ ] 本期回购是否有董事会/股东大会决议和合法授权
- [ ] 回购用途是否符合公司法规定情形（减资/员工持股/股权激励等）
- [ ] 库存股是否按回购成本（实际支付对价）入账
- [ ] 回购价格、数量与实际支付金额是否核对一致

### 四、注销冲减与审计调整

- [ ] 本期注销库存股是否有注销决议支持
- [ ] 注销冲减股本及资本公积/盈余公积的处理是否正确（与M2/M4/M5联动）
- [ ] 所有已确认的AJE/RJE是否完整反映审定表调整列且借贷平衡
- [ ] 审定表调整后金额是否等于未审数+AJE+RJE，未调整错报是否记录SUD

## risk_areas

### 高风险

1. **借贷方向错误**：库存股未以备抵借方冲减权益，或期末公式方向颠倒（回购计贷方/注销计借方），导致所有者权益列报重大错报。
2. **回购缺乏合法授权**：股份回购无决议或用途不符合公司法规定情形，构成违规回购。
3. **注销冲减处理错误**：注销库存股未正确冲减股本及相关权益项目，导致权益内部结构失真。
4. **期初期末不勾稽**：期初审定数与上年期末审定数不一致，审定数失去基准。

### 中风险

1. **回购成本入账错误**：库存股未按实际回购成本入账，或回购价格/数量与支付金额不符。
2. **试算平衡表方向不一致**：审定表与试算平衡表库存股借贷方向核对不一致。
3. **明细与汇总不勾稽**：审定表各批次合计与明细表（M3-2）总计不一致。
4. **联动冲减遗漏**：注销库存股未与M2股本、M4资本公积、M5盈余公积联动核对。

### 低风险

1. **审定表格式不规范**：列标题、行顺序、编号等格式问题不影响数据准确性。
2. **底稿交叉索引不完整**：未与试算平衡表、明细表、回购/注销决议、调整分录建立完整索引。
3. **用途说明不充分**：回购用途及授权范围未附简要说明。
