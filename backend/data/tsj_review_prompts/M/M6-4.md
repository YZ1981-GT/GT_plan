# M6-4 未分配利润检查表 复核提示词

## 适用底稿
未分配利润检查表（M6-4），聚焦利润分配决议合规性、盈余公积提取正确性、亏损弥补合法性、以前年度损益调整核查及净利润结转完整性。

## tips

- 利润分配须有股东会/董事会决议支持，分配金额、类型、比例与决议一致
- 提取法定盈余公积须核对比例（净利润10%）及累计封顶（注册资本50%）判断
- 亏损弥补须核查五年结转期限、弥补顺序及用盈余公积补亏的决议
- 以前年度损益调整须核查性质判定（政策变更/前期差错）及追溯处理正确性
- 本年净利润结转须与利润表勾稽，关注结转分录的完整性和过账准确性
- 关注违规分配、超分配、抽逃资金以应付股利挂账等异常情形
- 结合公司章程核查任意盈余公积提取及股利政策执行

## checklist

### 高风险检查项

- [ ] 利润分配是否有合法有效的股东会/董事会决议
- [ ] 本年净利润结转金额是否与利润表净利润一致
- [ ] 法定盈余公积提取比例是否为10%、基数是否正确
- [ ] 是否在弥补亏损、提足法定盈余公积后再分配利润
- [ ] 亏损弥补是否符合五年结转期限规定
- [ ] 以前年度损益调整性质判定是否正确、追溯处理是否合规
- [ ] 是否存在违规分配或超未分配利润余额分配的情形

### 中风险检查项

- [ ] 任意盈余公积提取是否符合公司章程规定
- [ ] 股利分配类型（现金/股票）是否与决议及会计处理一致
- [ ] 优先股股息计提是否符合发行条款
- [ ] 分配金额与M1应付股利、M5盈余公积是否勾稽
- [ ] 转增股本是否与实收资本变动一致
- [ ] 期后利润分配事项是否已识别并评估披露需求

### 低风险检查项

- [ ] 决议文件、章程条款等支持性文件是否齐全并归档
- [ ] 检查表结论是否清晰、可追溯
- [ ] 底稿索引与交叉引用是否完整（审定表/明细表/利润表）

## risk_areas

### 高风险

- **违规分配风险**：在存在未弥补亏损或未提足法定盈余公积时分配利润，违反公司法
- **净利润结转错误风险**：结转金额与利润表不符，导致未分配利润失真
- **追溯调整错误风险**：以前年度损益调整性质误判或错误调整本期损益，虚增/虚减业绩
- **抽逃资金风险**：以应付股利/其他应付款名义变相抽逃资金，未真实分配

### 中风险

- **盈余公积提取错误风险**：提取比例、基数或累计封顶判断有误
- **决议依据不足风险**：分配事项缺少或超越股东会/董事会授权
- **跨底稿不勾稽风险**：分配金额与M1、M5口径不一致

### 低风险

- **文件归档不完整风险**：决议、章程等支持文件缺失
- **结论表述不清风险**：检查结论未明确指向具体核查事项
- **索引缺失风险**：与审定表、明细表、利润表交叉索引不完整
