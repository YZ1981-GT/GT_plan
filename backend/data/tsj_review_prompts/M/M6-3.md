# M6-3 未分配利润调整分录汇总 复核提示词

## 适用底稿
未分配利润调整分录汇总表（M6-3），含账项调整（AJE）、重分类调整（RJE）及未调整错报（SUD）评估。

## 概述
M6-3 是未分配利润审定数链路的关键环节。复核须验证：每笔调整有证据、借贷平衡、完整反映到 M6-1 审定表，且区分本期损益调整与以前年度损益调整（追溯重述）——后者直接调整期初未分配利润，二者会计处理与披露要求截然不同。

---

## tips

1. **区分本期损益调整与追溯调整**：影响本期净利润的调整通过损益科目结转未分配利润；以前年度损益调整（政策变更/前期重大差错）直接调整期初未分配利润，不得错置。
2. **AJE vs RJE**：涉及未分配利润的 AJE 影响权益金额；RJE 仅涉及权益内部或列报重分类，不得通过 RJE 掩盖损益或分配错报。
3. **与 M6-1 勾稽**：审定表调整列金额须与 M6-3 已确认分录逐笔一致，遗漏任一笔即审定数失真。
4. **审批链**：涉及利润分配、追溯重述的重大调整须经合伙人审批留痕，追溯调整还须评估对可比期间报表的影响。
5. **SUD 累计**：影响权益/损益的未调整错报单独及累计是否超过重要性阈值，须与 A13 未调整错报汇总交叉验证。
6. **TB 回写**：确认调整已同步试算平衡表 4104 科目，避免"底稿已调、TB 未更"双真源。

## checklist

### 高风险检查项

- [ ] 所有 AJE 是否有充分审计证据支持
- [ ] 以前年度损益调整是否正确调整期初未分配利润而非本期损益
- [ ] 追溯重述是否评估并披露对可比期间报表及每股收益的影响
- [ ] 每笔调整分录借贷方是否完全平衡
- [ ] 调整金额是否完整反映到 M6-1 审定表对应调整列
- [ ] 涉及利润分配的调整是否有股东会/董事会决议依据
- [ ] 未调整错报累计是否超过整体重要性水平（须评估）

### 中风险检查项

- [ ] RJE 是否仅涉及权益内部重分类，未影响损益
- [ ] 调整原因说明是否清晰可追溯至具体审计程序
- [ ] 与 A13 未调整错报汇总索引是否完整
- [ ] 调整分录编号是否连续，删除后重号风险可控
- [ ] 是否区分建议调整与已执行调整

### 低风险检查项

- [ ] 分录摘要、科目编码是否规范
- [ ] 索引是否指向 M6-4 检查表、利润表等支持底稿
- [ ] 审计说明/结论是否概括调整性质与剩余风险

## risk_areas

### 高风险

1. **追溯调整错置本期**：应作为以前年度损益调整的事项计入本期损益，虚增/虚减本期业绩。
2. **调整缺乏证据或未经授权**：涉及利润分配的重大调整无决议或未经合伙人审批。
3. **审定表与 M6-3 调整金额不一致**：调整未完整回写审定表，审定数失真。

### 中风险

1. **RJE 误含损益影响**：本应仅重分类的调整影响了净利润或未分配利润余额。
2. **SUD 累计超阈值未处理**：权益/损益错报累计超重要性水平仍出无保留意见。

### 低风险

1. **编号、格式不规范**。
2. **索引指向支持底稿不完整**。

## 跨底稿勾稽

- M6-3 已确认 AJE/RJE 合计 ↔ M6-1 审定表调整列
- M6-3 SUD ↔ A13 未调整错报汇总
- 调整后审定数 ↔ 试算平衡表 4104 科目
- 以前年度损益调整 ↔ 期初未分配利润重述
