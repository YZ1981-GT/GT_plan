# M7-5 专项储备支出检查表 复核提示词

## 适用底稿
专项储备支出检查表（M7-5），聚焦专项储备使用（支出）的真实性、合规性、用途正确性及凭证完整性，通过抽样核对验证支出符合安全生产等指定用途。

## tips

- 专项储备支出须符合指定用途（安全生产/维护改造/技术措施等），核查支出性质
- 抽样核对须覆盖大额支出、期末集中支出、关联方交易等高风险项目
- 凭证核对须完整（支出申请→审批→合同/采购→验收→付款凭证）
- 区分费用性支出（直接冲减储备）与资本性支出（形成固定资产），处理方式不同
- 关注是否存在以专项储备名义列支非指定用途费用（挪用/套取）
- 支出金额须与M7-2明细表本期使用勾稽
- 资本性支出须核查是否同步形成固定资产并全额计提折旧

## checklist

### 高风险检查项

- [ ] 抽样样本是否覆盖大额、期末集中及高风险支出
- [ ] 支出用途是否符合安全生产费/维简费的指定用途
- [ ] 支出凭证是否完整（申请/审批/合同/验收/付款）
- [ ] 是否存在挪用专项储备用于非指定用途的情形
- [ ] 是否存在虚构支出套取专项储备资金的情形
- [ ] 资本性支出是否同步形成固定资产并全额计提折旧

### 中风险检查项

- [ ] 费用性支出是否直接、正确冲减专项储备
- [ ] 支出金额是否与M7-2明细表本期使用一致
- [ ] 大额支出是否履行了必要的审批程序
- [ ] 关联方相关支出是否公允、有商业实质
- [ ] 支出的会计期间归属是否正确（无跨期）
- [ ] 检查比例是否达到计划抽样水平

### 低风险检查项

- [ ] 抽样参数（总体/样本量/选取依据）是否完整记录
- [ ] 支出凭证扫描件/复印件是否归档
- [ ] 检查结果记录格式是否规范统一
- [ ] 底稿索引与交叉引用是否完整（审定表/明细表）

## risk_areas

### 高风险

- **挪用风险**：专项储备被用于非安全生产等指定用途，违反管理办法
- **套取资金风险**：虚构支出（伪造合同/发票/验收单）套取专项储备资金
- **资本性支出处理错误风险**：形成固定资产未同步入账或未全额计提折旧
- **用途不合规风险**：支出名义合规但实质不符合专项用途要求

### 中风险

- **审批缺失风险**：大额支出未履行审批程序
- **凭证不完整风险**：支出缺少关键原始单据（合同/验收/付款凭证）
- **跨期支出风险**：支出会计期间归属错误
- **检查比例不足风险**：实际检查比例低于计划水平

### 低风险

- **记录不完整风险**：抽样参数、选取过程记录不完整
- **凭证归档缺失风险**：支持性凭证未归档
- **索引缺失风险**：与审定表、明细表交叉索引不完整
