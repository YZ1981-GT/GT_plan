# M1-note-soe 应付股利附注披露复核提示词（国有企业）

## 概述

本提示词针对应付股利国有企业附注披露底稿（M1-note-soe，科目2232）的复核，聚焦国有企业特定的股利分配披露要求：应交国有资本收益（国有股利上缴）、"三重一大"分配决策程序、与出资人财务决算勾稽、逾期未付国有股利披露。国有企业利润分配兼具会计披露与国有资本收益上缴双重属性，附注须同时满足会计准则和国资监管要求。

**法规依据：**
- 《企业会计准则第37号——金融工具列报》
- 《企业会计准则第30号——财务报表列报》
- 《企业国有资产法》
- 《中央企业国有资本收益收取管理暂行办法》

---

## tips

1. **国企股利分配有"双层"披露要求**：既满足会计准则通用披露，又须满足国资委关于国有资本收益上缴的额外要求，两者互补不可替代。
2. **应上缴国有资本收益须单独识别**：向国有出资人分配的股利/应上缴的国有资本收益须单独披露金额、上缴比例及缴纳情况。
3. **"三重一大"决策程序须披露**：重大利润分配方案须经"三重一大"集体决策，附注应说明决策过程和审批情况。
4. **与财务决算勾稽**：应付股利数据须与年度财务决算报表一致，向出资人分配金额须与决算报告勾稽。
5. **逾期未缴国有股利须重点披露**：跨年度未上缴的国有资本收益须单独披露金额、原因及补缴计划，涉及国有权益保护。
6. **附注数据与审定表闭环勾稽**：附注应付股利期末余额必须等于M1-1审定表审定数，本期宣告须与M6利润分配勾稽。

## checklist

### 一、基础披露完整性（与上市版共有）

- [ ] 应付股利期末余额是否等于M1-1审定表审定数
- [ ] 是否披露期初数与期末数（可比信息）
- [ ] 本期宣告股利是否与分配决议一致
- [ ] 应付股利是否按流动性正确列示

### 二、国有资本收益披露

- [ ] 应上缴国有资本收益/向国有出资人分配的股利是否单独披露
- [ ] 是否披露国有资本收益上缴比例及计算依据
- [ ] 本期应缴、实缴、期末未缴的国有资本收益是否清晰列示
- [ ] 逾期未缴国有股利是否单独披露原因及补缴计划

### 三、决策程序与决算勾稽

- [ ] 重大利润分配方案是否经"三重一大"决策并披露
- [ ] 应付股利数据是否与年度财务决算报表一致
- [ ] 向出资人分配金额是否与决算报告勾稽
- [ ] 本期宣告股利是否与M6利润分配勾稽

### 四、与上市版差异及关联方

- [ ] 国企版是否在基础披露上增加国有资本收益上缴信息
- [ ] 向国有控股股东的应付股利是否单独列示
- [ ] 是否披露关联方名称、关系及金额
- [ ] 长期挂账国有股利是否说明是否形成国有资金占用

## risk_areas

### 高风险

1. **国有资本收益未单独披露**：应上缴国有出资人的股利/国有资本收益未单独列示，不满足国资监管要求，可能掩盖上缴义务。
2. **逾期未缴国有股利隐匿**：跨年度未上缴的国有资本收益未披露原因，涉及国有权益流失风险。
3. **附注余额与审定表不一致**：附注应付股利期末余额与审定表审定数不勾稽，属重大数据错误。

### 中风险

1. **"三重一大"程序说明缺失**：重大分配方案未披露集体决策过程，存在合规风险。
2. **与财务决算不勾稽**：附注数据与年度财务决算报表存在差异未调节。
3. **关联方应付股利未识别**：向国有控股股东应付股利未单独列示。

### 低风险

1. **披露格式未按决算模板**：附注格式与国资委决算报表模板有细微差异但信息完整。
2. **上缴比例说明简略**：国有资本收益上缴比例已披露但计算依据未详述。
3. **可比信息追溯不完整**：应付股利变动历史趋势分析覆盖不足。
