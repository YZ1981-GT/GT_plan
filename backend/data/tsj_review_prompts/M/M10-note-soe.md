# M10-note-soe 其他权益工具附注披露 复核提示词（国有企业）

## 概述

本提示词针对其他权益工具国有企业附注披露底稿（M10-note-soe）的复核，聚焦国有企业特定的附注披露要求：其他权益工具（永续债/优先股）发行的国资监管审批、权益/负债划分对国有资本结构的影响、分派对国有资本收益的影响、决算报表勾稽，以及与上市公司版本的差异关注点。国有企业发行永续债/优先股关系国有资本结构与融资合规，权益属性判定影响资产负债率考核。

**法规依据：**
- 《企业会计准则第37号——金融工具列报》
- 《企业会计准则第22号——金融工具确认和计量》
- 《企业国有资产法》
- 《中央企业财务决算报告管理办法》

---

## tips

1. **国有企业其他权益工具有"双层"披露要求**：既满足会计准则条款及分类披露，又满足国资委融资监管及决算的额外要求。
2. **发行审批合规披露**：永续债/优先股发行须经国资监管审批，附注须披露发行审批情况。
3. **权益属性对考核影响**：分类为权益降低资产负债率，须结合国资委资产负债率约束及考核口径说明分类的影响。
4. **分派对国有资本收益影响**：分派（利息/股息）作为利润分配影响可分配利润及国有资本收益上缴，须说明。
5. **决算报表勾稽**：其他权益工具数据须与年度财务决算报表一致。
6. **与上市版差异主要在监管层面**：条款及分类披露框架相同，国企版额外增加融资审批、资产负债率约束与国有资本结构信息。

## checklist

### 一、基础披露完整性（与上市版共有）

- [ ] 发行在外的其他权益工具是否逐项披露（数量/账面价值/条款）
- [ ] 分类为权益工具的判定依据是否披露
- [ ] 本期发行/赎回/变动是否披露
- [ ] 变动是否与所有者权益变动表勾稽
- [ ] 期末账面价值是否等于审定表审定数

### 二、国资监管与融资合规披露

- [ ] 永续债/优先股发行是否经国资监管审批并披露
- [ ] 权益属性判定对资产负债率的影响是否说明
- [ ] 是否符合国资委资产负债率约束要求
- [ ] 分派对可分配利润及国有资本收益上缴的影响是否说明
- [ ] 募集资金用途是否合规并披露

### 三、决算与勾稽披露

- [ ] 其他权益工具数据是否与年度财务决算报表一致
- [ ] 分派金额及处理是否披露
- [ ] 相关会计政策是否披露
- [ ] 附注数据是否与M10-2明细表勾稽

### 四、与上市版的差异关注点

- [ ] 国企版是否在基础披露上增加融资审批信息
- [ ] 是否增加资产负债率约束及国有资本结构影响分析
- [ ] 决算报表与审计报表口径差异是否调节说明
- [ ] 是否增加分派对国有资本收益的影响说明

## risk_areas

### 高风险

1. **权益属性误判虚降杠杆**：应分类为负债的工具误分为权益，虚降资产负债率规避国资约束。
2. **发行审批缺失未披露**：发行未经国资监管审批或未披露审批情况。
3. **变动与决算/权益变动表不勾稽**：其他权益工具数据与决算报表或所有者权益变动表不一致。
4. **期末余额与审定表不一致**：附注期末账面价值与审定数不符。

### 中风险

1. **资产负债率影响未说明**：权益属性对资产负债率约束的影响缺少分析。
2. **分派对国有资本收益影响未说明**：分派对可分配利润及收益上缴的影响未披露。
3. **决算口径差异未调节**：决算数据与审计后数据差异未说明。

### 低风险

1. **披露格式未按决算模板**：格式细节差异但信息完整。
2. **条款描述简略**：主要条款描述不够详细。
3. **可比信息追溯不完整**：历史趋势覆盖年度不足。
