# M10-3 其他权益工具调整分录汇总 复核提示词

## 适用底稿
其他权益工具调整分录汇总表（M10-3），含账项调整（AJE）、重分类调整（RJE）及未调整错报（SUD）评估。

## 概述
M10-3 是其他权益工具审定数链路的关键环节。复核须验证：每笔调整有证据、借贷平衡、完整反映到 M10-1 审定表，并重点关注涉及负债/权益重分类的调整（工具属性重判定后的重分类）、发行费用及分派处理的调整正确性。

---

## tips

1. **负债/权益重分类调整**：若审计发现工具应重分类为金融负债，须通过RJE将其他权益工具重分类至相应负债科目，并追溯调整分派处理（利润分配→财务费用）。
2. **发行费用调整**：发行交易费用应冲减权益，调整时不得计入损益。
3. **分派处理调整**：调整分类为权益的工具分派须作为利润分配，分类为负债的作为财务费用，不得错置。
4. **AJE vs RJE**：涉及其他权益工具的 AJE 影响权益金额；负债/权益重分类为 RJE，影响列报结构且可能连带损益（分派处理）。
5. **与 M10-1 勾稽**：审定表调整列金额须与 M10-3 已确认分录逐笔一致。
6. **TB 回写**：确认调整已同步试算平衡表4003科目及相关负债/损益科目。

## checklist

### 高风险检查项

- [ ] 所有 AJE/RJE 是否有充分审计证据支持
- [ ] 负债/权益重分类调整是否基于M10-4判定结论
- [ ] 重分类为负债的工具其分派是否追溯调整为财务费用
- [ ] 发行费用调整是否冲减权益而非计入损益
- [ ] 每笔调整分录借贷方是否完全平衡
- [ ] 调整金额是否完整反映到 M10-1 审定表对应调整列
- [ ] 未调整错报累计是否超过整体重要性水平（须评估）

### 中风险检查项

- [ ] 分派处理调整是否正确区分利润分配与财务费用
- [ ] 赎回/回购差额调整是否正确处理权益
- [ ] 调整原因说明是否清晰可追溯至具体审计程序
- [ ] 与 A13 未调整错报汇总索引是否完整
- [ ] 调整分录编号是否连续，删除后重号风险可控

### 低风险检查项

- [ ] 分录摘要、科目编码是否规范
- [ ] 索引是否指向 M10-4 区分检查表、M10-5 检查表等支持底稿
- [ ] 审计说明/结论是否概括调整性质与剩余风险

## risk_areas

### 高风险

1. **重分类未做或错误**：工具应重分类为负债但未通过调整重分类，或重分类未追溯调整分派处理。
2. **分派处理调整错误**：分派处理在利润分配与财务费用之间错置。
3. **审定表与 M10-3 调整不一致**：调整未完整回写审定表。

### 中风险

1. **发行费用调整错误**：发行费用调整计入损益而非冲减权益。
2. **SUD 累计超阈值未处理**：错报累计超重要性水平仍出无保留意见。

### 低风险

1. **编号、格式不规范**。
2. **索引指向支持底稿不完整**。

## 跨底稿勾稽

- M10-3 已确认 AJE/RJE 合计 ↔ M10-1 审定表调整列
- M10-3 SUD ↔ A13 未调整错报汇总
- 调整后审定数 ↔ 试算平衡表 4003 科目
- 负债/权益重分类 ↔ 相应金融负债科目及分派处理（财务费用/利润分配）
