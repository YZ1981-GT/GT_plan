# M7-4 专项储备计提测试 复核提示词

## 适用底稿
专项储备计提测试表（M7-4），聚焦安全生产费/维简费提取基数、提取比例、提取金额重新测算的准确性与合规性。

## tips

- 安全生产费提取须按行业适用标准执行（按营业收入分档比例或按产量单位定额）
- 提取基数须核实（营业收入口径/产量口径），关注是否使用正确的计提基础
- 分档累进提取的须按对应档次比例分段计算，不得简单按单一比例计算
- 提取金额重新测算：测算值=基数×适用比例（或产量×单位定额），与账面提取比对
- 关注超提（虚增成本/权益）与少提（安全投入不足合规风险）
- 提取应计入相关产品成本或当期损益，核查计提分录科目正确性
- 结合行业属性（矿山/建筑施工/危险品/交通运输等）判断适用的提取标准

## checklist

### 高风险检查项

- [ ] 提取标准是否适用正确的行业规定（财资〔2022〕136号或行业专项办法）
- [ ] 提取基数（营业收入/产量）是否准确、口径是否正确
- [ ] 分档累进比例是否按对应档次分段计算
- [ ] 提取金额重新测算是否与账面提取金额一致
- [ ] 是否存在超提虚增成本/权益的情形
- [ ] 是否存在少提导致安全投入不足的合规风险

### 中风险检查项

- [ ] 单位定额提取（按产量）的产量数据是否与生产记录/统计报表勾稽
- [ ] 计提分录是否正确计入产品成本或当期损益
- [ ] 提取金额是否与M7-2明细表本期计提一致
- [ ] 提取金额是否与M7-1审定表本期提取勾稽
- [ ] 期中标准调整（如政策变更）是否正确应用

### 低风险检查项

- [ ] 提取比例/定额的政策依据文件是否归档
- [ ] 基数数据来源（收入/产量报表）是否附于底稿
- [ ] 测算过程是否可复核、公式是否正确
- [ ] 底稿索引与交叉引用是否完整（审定表/明细表）

## risk_areas

### 高风险

- **提取标准适用错误风险**：错误适用行业标准或提取比例，导致提取金额系统性偏差
- **基数错误风险**：计提基数口径错误（如误用含税收入、错误产量口径）导致提取失真
- **超提虚增风险**：故意超提专项储备以调节成本费用和利润
- **少提合规风险**：少提导致安全投入不足，存在监管处罚及安全事故风险

### 中风险

- **分档计算错误风险**：分档累进比例未分段计算，简单套用单一比例
- **产量数据不实风险**：按产量提取的产量数据与生产统计不勾稽
- **计提科目错误风险**：提取未正确计入产品成本或损益

### 低风险

- **政策依据缺失风险**：适用标准的政策文件未归档
- **测算过程不可复核风险**：测算公式或数据来源未充分记录
- **索引缺失风险**：与审定表、明细表交叉索引不完整
