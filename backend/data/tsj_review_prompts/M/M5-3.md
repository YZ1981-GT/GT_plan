# M5-3 盈余公积调整分录汇总复核提示词

## 概述

本提示词针对盈余公积调整分录汇总表（M5-3，科目4101）的复核，含账项调整（AJE）、重分类调整（RJE）及未调整错报（SUD）评估。复核须验证每笔调整有净利润数据/决议证据、借贷平衡、完整反映至M5-1审定表，并同步试算平衡表，尤须关注法定盈余公积计提调整的合规性及与利润分配的联动。

**法规依据：**
- 《中国注册会计师审计准则第1301号——审计证据》
- 《企业会计准则第30号——财务报表列报》
- 《中华人民共和国公司法》（法定盈余公积）

---

## tips

1. **AJE 与 RJE 区分**：AJE 影响盈余公积金额（如补提法定盈余公积）；RJE 涉及权益内部重分类，不得通过 RJE 掩盖漏提。
2. **与 M5-1 勾稽**：审定表调整列金额须与 M5-3 已确认分录逐笔一致，遗漏任一笔即审定数失真。
3. **补提法定盈余公积须有净利润依据**：因漏提/少提而补提法定盈余公积的AJE，须借记利润分配、贷记盈余公积，计提基数（净利润10%）正确。
4. **与利润分配联动**：调整盈余公积计提须与M6利润分配对应调整联动，对方科目（利润分配）正确。
5. **SUD 累计评估**：未调整错报单独及累计是否超过整体/明显微小错报阈值，须与 A13 未调整错报汇总交叉验证。
6. **TB 回写确认**：确认调整已同步试算平衡表4101科目（贷方口径），方向正确。

## checklist

### 高风险检查项

- [ ] 所有 AJE 是否有充分审计证据（净利润数据、决议等）
- [ ] 补提法定盈余公积的调整是否基数正确（净利润10%）且对方科目为利润分配
- [ ] AJE 是否经适当层级审批（超重要性水平须合伙人知悉）
- [ ] 每笔调整分录借贷方是否完全平衡
- [ ] 调整金额是否完整反映到 M5-1 审定表对应调整列
- [ ] 调整盈余公积是否与M6利润分配对应调整联动
- [ ] 未调整错报累计是否超过整体重要性水平（须评估并记录）

### 中风险检查项

- [ ] RJE 是否仅涉及权益内部重分类，未错误改变权益总额
- [ ] 法定与任意盈余公积调整是否分别正确处理
- [ ] 调整原因说明是否清晰可追溯至具体审计程序
- [ ] 与 A13 未调整错报汇总表索引是否完整
- [ ] 建议调整与已执行调整是否区分记录

### 低风险检查项

- [ ] 分录摘要、科目编码是否规范，编号是否连续
- [ ] 索引是否指向 M5-4 计提检查、M5-5 检查表、M6 利润分配等支持底稿
- [ ] 审计说明/结论是否概括调整性质与残余风险

## risk_areas

### 高风险

1. **调整缺乏依据**：补提/冲减盈余公积无净利润数据或决议支持，构成越权或错误调整。
2. **审定表与M5-3调整金额不一致**：调整未完整反映审定表，导致审定数失真、掩盖漏提。
3. **SUD累计超阈值未处理**：未调整错报累计超过整体重要性水平却未恰当处理审计意见。

### 中风险

1. **补提基数错误**：补提法定盈余公积基数非净利润10%，导致计提金额错误。
2. **对方科目错误**：补提盈余公积未借记利润分配而误借其他科目。
3. **与利润分配联动遗漏**：调整盈余公积未与M6利润分配联动，权益变动核算不一致。

### 低风险

1. **编号、格式不规范**：分录编号不连续、摘要不清晰影响可追溯性。
2. **索引指向不完整**：调整分录与支持底稿的交叉引用缺失。
3. **审计说明过于简略**：未概括调整性质及对财务报表的整体影响。
