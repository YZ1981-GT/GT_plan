# M1-note-listed 应付股利附注披露复核提示词（上市公司）

## 概述

本提示词针对应付股利上市公司附注披露底稿（M1-note-listed，科目2232）的复核，聚焦上市公司财务报表附注中应付股利披露的充分性与准确性：期末余额及构成、股利分配政策与决议、逾期未付股利披露、与利润分配表勾稽、关联方（控股股东）应付股利单独披露。上市公司股利分配是投资者高度关注事项，披露不充分将影响投资决策。

**法规依据：**
- 《企业会计准则第37号——金融工具列报》
- 《企业会计准则第30号——财务报表列报》
- 《公开发行证券的公司信息披露编报规则第15号——财务报告的一般规定》
- 《企业会计准则第36号——关联方披露》

---

## tips

1. **应付股利附注须披露构成与变动**：披露期末应付股利余额、本期宣告及支付情况，重大项目应说明形成原因和支付安排。
2. **分配政策与决议须充分披露**：上市公司须披露利润分配政策、本期分配预案及股东大会审议情况，宣告金额须与决议一致。
3. **逾期长期未付股利是披露重点**：跨年度未支付的应付股利须单独披露金额、对象及未支付原因，异常长期挂账须风险提示。
4. **与利润分配表勾稽不可断裂**：附注应付股利本期宣告须与所有者权益变动表、利润分配相关披露勾稽，金额相互印证。
5. **关联方应付股利单独披露**：向控股股东、实际控制人分配的应付股利须按CAS36单独列示关联方名称、关系及金额。
6. **附注数据与审定表闭环勾稽**：附注应付股利期末余额必须等于M1-1审定表审定数，本期宣告须与M1-5测算表和M6利润分配勾稽。

## checklist

### 一、期末余额与构成披露

- [ ] 应付股利期末余额是否等于M1-1审定表审定数
- [ ] 是否披露期初数与期末数（可比信息）
- [ ] 重大应付股利项目是否说明对象及形成原因
- [ ] 应付股利是否按流动性正确列示于报表

### 二、分配政策与决议披露

- [ ] 是否披露利润分配政策及本期分配预案
- [ ] 本期宣告股利是否与董事会/股东大会决议一致
- [ ] 分配决议的审议程序、表决结果是否披露
- [ ] 每股股利/分配比例是否披露

### 三、逾期未付与勾稽

- [ ] 逾期/长期未付的应付股利是否单独披露金额及原因
- [ ] 本期宣告股利是否与所有者权益变动表勾稽
- [ ] 附注本期宣告是否与M1-5测算表、M6利润分配勾稽
- [ ] 涉及代扣个税的应付净额列示是否清晰

### 四、关联方应付股利披露

- [ ] 向控股股东/实际控制人的应付股利是否单独列示
- [ ] 是否披露关联方名称、关系类型及金额
- [ ] 关联方应付股利支付情况是否说明
- [ ] 是否存在关联方股利长期挂账形成资金占用的情形并披露

## risk_areas

### 高风险

1. **附注余额与审定表不一致**：附注披露的应付股利期末余额与审定表审定数不一致，属重大数据勾稽错误。
2. **关联方应付股利未单独披露**：向控股股东分配的应付股利混入未单独列示，违反CAS36并可能掩盖资金占用。
3. **分配决议信息缺失**：未披露分配政策、预案及决议审议情况，不满足上市公司信息披露编报规则要求。

### 中风险

1. **逾期未付披露不充分**：长期挂账应付股利未披露原因，投资者无法评估分配执行情况。
2. **与利润分配不勾稽**：附注本期宣告与所有者权益变动表或M6利润分配不一致。
3. **可比信息缺失**：仅列期末数未列期初可比数据。

### 低风险

1. **披露格式不规范**：表格标题、列序、金额单位等格式细节未严格按编报规则。
2. **文字描述模板化**：分配政策描述照搬未结合本企业实际。
3. **代扣个税说明简略**：应付净额与代扣税款关系未清晰说明。
