# M9-4 其他综合收益核对表 复核提示词

## 适用底稿
其他综合收益核对表（M9-4），聚焦OCI各来源多底稿核对：FVOCI公允价值变动（G8）、设定受益计划重计量（J2）、外币财务报表折算差额、权益法下OCI份额等，验证OCI各分项与来源底稿逐项勾稽。

## tips

- OCI是"汇聚型"科目，各分项均来源于其他底稿，核对表须逐项建立来源勾稽关系
- FVOCI（其他债权投资/其他权益工具投资）公允价值变动须与G8等金融资产底稿勾稽
- 设定受益计划重计量须与J2长期应付职工薪酬底稿勾稽
- 外币财务报表折算差额须与合并/外币折算底稿勾稽
- 权益法下享有被投资单位OCI份额须与长期股权投资底稿勾稽
- 各分项须核对税前发生额与税后净额，所得税影响与递延所得税勾稽
- 关注来源底稿已确认变动但OCI未同步、或OCI有变动但来源不明的情况

## checklist

### 高风险检查项

- [ ] OCI各分项是否均建立了明确的来源底稿勾稽
- [ ] FVOCI公允价值变动是否与G8等金融资产底稿逐项一致
- [ ] 设定受益计划重计量是否与J2底稿一致
- [ ] 外币财务报表折算差额是否与外币折算底稿一致
- [ ] 权益法下OCI份额是否与长期股权投资底稿一致
- [ ] 是否存在OCI有变动但来源不明/无支持的情况
- [ ] 是否存在来源底稿已确认变动但OCI未同步

### 中风险检查项

- [ ] 各分项税前发生额与税后净额核对是否勾稽
- [ ] 所得税影响是否与递延所得税变动勾稽
- [ ] 可重分类项目的重分类金额是否与来源底稿处置/终止确认勾稽
- [ ] 核对表汇总是否与M9-1审定表、M9-2明细表一致
- [ ] 权益工具处置转入留存收益的金额是否核对无误

### 低风险检查项

- [ ] 各来源底稿的索引引用是否完整
- [ ] 核对差异（如有）是否已说明并追踪解决
- [ ] 核对表格式是否规范、勾稽关系是否清晰
- [ ] 底稿交叉索引是否完整

## risk_areas

### 高风险

- **来源勾稽断裂风险**：OCI分项与来源底稿（G8/J2/外币折算/长期股权投资）不一致，OCI失真
- **变动来源不明风险**：OCI有变动但缺少来源支持，可能存在人为调节权益
- **同步遗漏风险**：来源底稿已确认变动但OCI未同步反映
- **重分类勾稽错误风险**：可重分类项目转损益金额与来源底稿处置/终止确认不勾稽

### 中风险

- **税务勾稽错误风险**：OCI所得税影响与递延所得税变动不勾稽
- **权益工具处置处理风险**：处置累计公允变动误转损益而非留存收益
- **汇总不一致风险**：核对表与审定表、明细表不勾稽

### 低风险

- **索引缺失风险**：来源底稿引用不完整
- **差异未追踪风险**：核对差异未说明或未解决
- **格式不规范风险**：勾稽关系列示不清晰

## 法规依据

- 《企业会计准则第30号——财务报表列报》：其他综合收益列示
- 《企业会计准则第19号——外币折算》：外币财务报表折算差额
- 《企业会计准则第22号——金融工具确认和计量》：FVOCI公允价值变动
- 《企业会计准则第2号——长期股权投资》：权益法下其他综合收益份额
- 《中国注册会计师审计准则第1301号——审计证据》
