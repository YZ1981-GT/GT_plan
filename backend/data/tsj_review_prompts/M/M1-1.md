# M1-1 应付股利审定表复核提示词

## 概述

本提示词针对应付股利审定表（M1-1，科目2232）的复核，聚焦所有者权益循环中股利分配的核心审计要点：期初期末勾稽、试算平衡表核对、宣告未付股利挂账完整性、与利润分配（M6）勾稽。应付股利是股利宣告后至实际支付前的负债挂账，审定表承载未审数→调整→审定数的完整链路，任何宣告遗漏或勾稽断裂均可能导致负债低估。

**法规依据：**
- 《企业会计准则第37号——金融工具列报》
- 《企业会计准则第30号——财务报表列报》
- 《中国注册会计师审计准则第1301号——审计证据》
- 《中华人民共和国公司法》（利润分配与股利宣告）

## tips

1. **股利宣告即确认负债**：应付股利应在董事会/股东大会作出利润分配决议（宣告日）时确认，审定表期末数须与已宣告未支付的股利决议金额一致，宣告后未挂账构成负债完整性缺陷。
2. **期初期末勾稽是审定表生命线**：期初审定数须等于上年期末审定数（承前启后），期末审定数=期初+本期宣告（贷方）−本期支付（借方）±审计调整，任何无源差异需追溯决议或调整分录。
3. **试算平衡表是第一道勾稽防线**：审定表应付股利审定数合计须与试算平衡表2232科目审定数完全一致（负债类贷方口径），差异意味着存在未记录的调整或汇总错误。
4. **与利润分配（M6）勾稽不可断裂**：本期宣告的股利须与M6未分配利润的"应付股利"分配栏勾稽，宣告金额、决议日期、分配比例须相互印证。
5. **区分对法人股东与自然人股东**：向自然人股东分配股利涉及代扣代缴个人所得税，审定表应付股利净额与代扣税款应清晰列示，避免负债与税金混淆。
6. **关注长期挂账未付股利**：跨年度长期挂账的应付股利需评估支付计划与合理性，异常长期挂账可能反映资金占用或分配决议执行障碍。

## checklist

### 一、期初期末勾稽

- [ ] 审定表期初未审数是否等于上年审定表期末审定数（承前启后核对）
- [ ] 期末审定数是否等于期初审定数+本期宣告股利−本期支付股利（加减审计调整）
- [ ] 审定表各行项目期初期末变动是否与明细表（M1-2）增减变动一致
- [ ] 是否存在期初数据被修改但未留痕或未做差异说明的情况

### 二、试算平衡表与科目核对

- [ ] 审定表应付股利审定数合计是否与试算平衡表2232科目审定数一致（贷方口径）
- [ ] 试算平衡表未审数、调整数（AJE+RJE）与审定表对应列是否一致
- [ ] 审定表各明细行（按股东分类）之和是否等于科目合计
- [ ] 是否存在试算平衡表已更新但审定表未同步的情况

### 三、宣告与勾稽完整性

- [ ] 本期宣告的股利是否有董事会/股东大会决议支持，宣告日与账务确认日是否一致
- [ ] 本期宣告股利是否与M6利润分配"应付股利"分配栏金额勾稽
- [ ] 各股东应分配金额是否按持股比例/章程约定计算准确
- [ ] 已宣告未支付的股利是否全部挂账（负债完整性）

### 四、分类列报与审计调整

- [ ] 应付股利是否按流动性正确列报（预计1年内支付列流动负债）
- [ ] 关联方（控股股东）应付股利是否单独可识别
- [ ] 所有已确认的AJE/RJE是否完整反映在审定表调整列且借贷平衡
- [ ] 审定表调整后金额是否等于未审数+AJE+RJE，未调整错报是否记录SUD

## risk_areas

### 高风险

1. **宣告未挂账导致负债低估**：董事会已作出分配决议但未在账面确认应付股利，导致负债完整性缺失和所有者权益虚增。
2. **期初期末不勾稽**：期初审定数与上年期末审定数不一致，存在未经授权调整或数据错误，审定数失去基准。
3. **与M6利润分配不勾稽**：本期宣告股利与未分配利润分配栏金额不一致，反映分配核算断裂或跨表数据错误。
4. **试算平衡表与审定表不一致**：两者口径不一致意味着存在未被发现的汇总错误或调整遗漏，影响报表准确性。

### 中风险

1. **明细与汇总不勾稽**：审定表各行合计与明细表（M1-2）按股东列示总计不一致，可能存在遗漏或重复。
2. **审计调整遗漏或方向错误**：已确认调整未反映审定表，或RJE借贷方向颠倒导致审定数偏离。
3. **流动性分类不当**：预计1年以上支付的股利仍列流动负债，或分类与附注披露不一致。
4. **代扣税款与净额混淆**：应付股利总额、代扣个税、实付净额未清晰列示，导致负债金额失真。

### 低风险

1. **审定表格式不规范**：列标题、行顺序、编号等格式问题不影响数据准确性但影响可读性。
2. **底稿交叉索引不完整**：未与试算平衡表、明细表、M6、调整分录汇总建立完整索引引用。
3. **变动说明不充分**：重大变动行项目未附简要说明，增加复核理解难度。
