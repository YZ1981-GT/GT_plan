# M8-3 一般风险准备调整分录汇总 复核提示词

## 适用底稿
一般风险准备调整分录汇总表（M8-3），含账项调整（AJE）、重分类调整（RJE）及未调整错报（SUD）评估。

## 概述
M8-3 是一般风险准备审定数链路的关键环节。复核须验证：每笔调整有证据、借贷平衡、完整反映到 M8-1 审定表，并关注调整是否正确通过利润分配核算（而非损益），以及是否涉及以一般准备替代减值准备的不当处理。

---

## tips

1. **计提调整通过利润分配**：调整本期一般风险准备提取时须通过利润分配科目，不得计入当期损益。
2. **不得替代减值调整**：调整不得以增提一般风险准备替代应补提的资产减值准备。
3. **AJE vs RJE**：涉及一般风险准备的 AJE 影响权益及利润分配；RJE 仅涉及列报重分类，不得通过 RJE 掩盖计提不足。
4. **与 M8-1 勾稽**：审定表调整列金额须与 M8-3 已确认分录逐笔一致。
5. **SUD 累计**：未调整错报单独及累计是否超过重要性阈值，须与 A13 未调整错报汇总交叉验证。
6. **TB 回写**：确认调整已同步试算平衡表对应科目及利润分配科目。

---

## checklist

### 高风险检查项

- [ ] 所有 AJE 是否有充分审计证据支持
- [ ] 计提调整是否通过利润分配核算而非损益
- [ ] 调整是否以一般准备不当替代减值准备
- [ ] 每笔调整分录借贷方是否完全平衡
- [ ] 调整金额是否完整反映到 M8-1 审定表对应调整列
- [ ] 补提一般风险准备的调整是否使余额达标
- [ ] 未调整错报累计是否超过整体重要性水平（须评估）

### 中风险检查项

- [ ] RJE 是否仅涉及列报重分类，未影响计提实质
- [ ] 调整原因说明是否清晰可追溯至具体审计程序
- [ ] 与 A13 未调整错报汇总索引是否完整
- [ ] 调整分录编号是否连续，删除后重号风险可控
- [ ] 是否区分建议调整与已执行调整

### 低风险检查项

- [ ] 分录摘要、科目编码是否规范
- [ ] 索引是否指向 M8-4 风险资产测试等支持底稿
- [ ] 审计说明/结论是否概括调整性质与剩余风险

## risk_areas

### 高风险

1. **计提调整计入损益**：本期计提调整错误计入当期损益而非利润分配。
2. **以一般准备替代减值**：调整以增提一般风险准备掩盖减值计提不足。
3. **审定表与 M8-3 调整不一致**：调整未完整回写审定表。

### 中风险

1. **RJE 误含计提实质**：本应仅重分类的调整影响了计提金额。
2. **SUD 累计超阈值未处理**：错报累计超重要性水平仍出无保留意见。

### 低风险

1. **编号、格式不规范**。
2. **索引指向支持底稿不完整**。

## 跨底稿勾稽

- M8-3 已确认 AJE/RJE 合计 ↔ M8-1 审定表调整列
- M8-3 SUD ↔ A13 未调整错报汇总
- 调整后审定数 ↔ 试算平衡表一般风险准备科目
- 计提调整 ↔ M6 利润分配中一般风险准备提取
