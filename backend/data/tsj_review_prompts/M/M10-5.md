# M10-5 其他权益工具检查表 复核提示词

## 适用底稿
其他权益工具检查表（M10-5），聚焦其他权益工具发行合规性、条款执行、分派/赎回决策、以及权益属性持续判定的核查。

## tips

- 发行合规性核查：发行是否经必要审批（董事会/股东会/监管核准），募集资金用途是否合规
- 条款执行核查：付息/分派、利率跳升、赎回等条款是否按合同执行
- 分派决策核查：分派（利息/股息）是否有决议依据、是否作为利润分配处理、是否影响可分配利润
- 赎回/回购核查：赎回是否符合条款约定、价格是否公允、是否履行审批程序
- 权益属性持续判定：条款变更、续期、利率重置等是否触发重新评估负债/权益分类
- 关注永续债续期、优先股转股、强制赎回触发等对分类的影响
- 结合M10-4区分检查表核查分类判定的持续有效性

## checklist

### 高风险检查项

- [ ] 工具发行是否经必要审批及监管核准
- [ ] 权益属性判定是否持续有效（条款变更是否触发重新评估）
- [ ] 分派（利息/股息）是否作为利润分配处理（分类为权益时）
- [ ] 分派是否有决议依据、是否符合可分配利润限制
- [ ] 赎回/回购是否符合条款约定并履行审批程序
- [ ] 利率跳升/续期条款执行是否影响权益分类

### 中风险检查项

- [ ] 募集资金用途是否与募集文件一致
- [ ] 付息/分派时点与金额是否按合同执行
- [ ] 赎回价格与账面差额处理是否正确
- [ ] 优先股转股/强制赎回触发条件是否已核查
- [ ] 分派对未分配利润及所有者权益的影响是否正确核算
- [ ] 检查结论是否与M10-1、M10-4一致

### 低风险检查项

- [ ] 发行文件、决议、监管批复等支持文件是否归档
- [ ] 条款执行记录是否完整
- [ ] 检查表结论是否明确、可追溯
- [ ] 底稿索引与交叉引用是否完整（审定表/明细表/区分检查表）

## risk_areas

### 高风险

- **权益属性失效风险**：条款变更/续期/利率重置触发工具应重分类为负债但未重新评估
- **分派处理错误风险**：分派未作为利润分配或超可分配利润分派（分类为权益时）
- **发行合规风险**：发行未经必要审批或监管核准，募集资金用途违规
- **赎回违规风险**：赎回未符合条款或未履行审批程序

### 中风险

- **条款执行偏差风险**：付息/分派/赎回条款未按合同执行
- **募集资金用途偏差风险**：资金用途与募集文件不一致
- **跨底稿不一致风险**：检查结论与M10-1、M10-4不一致

### 低风险

- **文件归档缺失风险**：发行文件、决议、批复未归档
- **记录不完整风险**：条款执行记录不完整
- **索引缺失风险**：与审定表、明细表、区分检查表交叉索引不完整
