# M4-note-soe 资本公积附注披露复核提示词（国有企业）

## 概述

本提示词针对资本公积国有企业附注披露底稿（M4-note-soe，科目4002）的复核，聚焦国有企业特定的资本公积披露要求：国有资本投入形成的资本公积、国有资产无偿划入、专项拨款结转、"三重一大"资本公积运作决策、与财务决算勾稽。国有企业资本公积除一般来源外，还涉及国有资本运作和政府专项拨款，附注须同时满足会计准则和国资监管要求。

**法规依据：**
- 《企业会计准则第30号——财务报表列报》
- 《企业会计准则第2号——长期股权投资》
- 《企业国有资产法》
- 《企业会计准则第16号——政府补助》（专项拨款结转资本公积部分）

---

## tips

1. **国企资本公积披露有"双层"要求**：既满足会计准则通用披露，又须满足国有资本运作、国有资产划转等国资监管要求。
2. **国有资本投入及无偿划入须单独披露**：国有股东超额投入、国有资产无偿划入形成的资本公积须单独披露来源、金额及审批。
3. **专项拨款结转须说明依据**：政府专项拨款结转形成的资本公积须披露拨款项目、结转依据及是否符合准则要求。
4. **资本公积转增/运作须履行程序**：资本公积转增资本、用于弥补亏损等运作须经"三重一大"决策和国资审批，附注应披露决策过程。
5. **与财务决算勾稽**：资本公积数据须与年度财务决算报表一致，国有资本运作事项须与决算报告勾稽。
6. **附注数据与审定表闭环勾稽**：附注资本公积期末余额必须等于M4-1审定表审定数，各构成项与明细表勾稽。

## checklist

### 一、基础披露完整性（与上市版共有）

- [ ] 资本公积期末余额是否等于M4-1审定表审定数
- [ ] 资本溢价与其他资本公积构成是否分类披露
- [ ] 是否披露期初数、本期增减与期末数
- [ ] 各构成项变动是否说明来源及依据

### 二、国有资本相关披露

- [ ] 国有股东超额投入形成的资本公积是否单独披露
- [ ] 国有资产无偿划入形成的资本公积是否披露来源及审批
- [ ] 政府专项拨款结转资本公积是否披露拨款项目及结转依据
- [ ] 是否披露国有资本运作对资本公积的影响

### 三、决策程序与决算勾稽

- [ ] 资本公积转增/弥补亏损等运作是否经"三重一大"决策并披露
- [ ] 是否履行国资监管机构审批程序
- [ ] 资本公积数据是否与年度财务决算报表一致
- [ ] 转增资本是否与实收资本变动勾稽

### 四、与上市版差异及关联方

- [ ] 国企版是否在基础披露上增加国有资本运作及划转信息
- [ ] 与控股股东/关联方的资本性投入是否单独披露
- [ ] 权益法下其他资本公积是否与长期股权投资勾稽
- [ ] 混合所有制改革涉及的资本公积变动是否充分披露

## risk_areas

### 高风险

1. **国有资产划入未单独披露**：国有资产无偿划入形成的资本公积未披露来源及审批，不满足国资监管要求。
2. **资本公积运作未履行程序**：转增/弥补亏损未经"三重一大"决策和国资审批，涉及合规风险。
3. **附注余额与审定表不一致**：附注资本公积期末余额与审定表审定数不勾稽，属重大数据错误。

### 中风险

1. **专项拨款结转依据不清**：政府专项拨款结转资本公积未说明依据或结转不符合准则。
2. **与财务决算不勾稽**：附注数据与年度财务决算报表存在差异未调节。
3. **关联方资本性投入未识别**：与控股股东的资本性投入未单独披露。

### 低风险

1. **披露格式未按决算模板**：附注格式与国资委决算报表模板有细微差异但信息完整。
2. **来源说明简略**：资本公积构成来源已披露但形成过程未详述。
3. **可比信息追溯不完整**：资本公积变动历史信息覆盖不足。
