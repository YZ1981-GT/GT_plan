# M1-5 应付股利（利润）测算表复核提示词

## 概述

本提示词针对应付股利（利润）测算表（M1-5，科目2232）的复核，该表测算本期应分配股利（利润）金额，接收M6未分配利润数据，验证分配基数、分配比例、可供分配利润的充足性及测算公式勾稽。测算表是股利宣告金额的计算依据，测算错误将直接导致应付股利负债金额和利润分配核算失真。

**法规依据：**
- 《企业会计准则第37号——金融工具列报》
- 《企业会计准则第30号——财务报表列报》
- 《中国注册会计师审计准则第1301号——审计证据》
- 《中华人民共和国公司法》（利润分配顺序与限制）

---

## tips

1. **分配基数须为可供分配利润**：股利分配基数应为弥补以往年度亏损、提取法定盈余公积后的可供分配利润，测算须验证分配未超过可分配限额。
2. **接收M6数据须勾稽一致**：M1-5测算的可供分配利润、未分配利润期初期末数须与M6利润分配底稿逐项勾稽，数据来源单一可靠。
3. **分配比例与决议一致**：测算的分配比例（每股股利/分配率）须与董事会/股东大会决议一致，比例错误导致分配总额失真。
4. **公式勾稽逐项验证**：应分配股利=分配基数×分配比例，各股东分配额=总额×持股比例，逐行核对公式设置无误。
5. **验证利润分配顺序合规**：分配顺序须符合公司法（弥补亏损→法定盈余公积→任意盈余公积→股利），测算须体现法定提取的优先性。
6. **关注超分配与优先股**：分配是否超过可供分配利润（违规分配），涉及优先股/永续债时须区分固定股息与普通股利。

## checklist

### 一、分配基数与充足性

- [ ] 分配基数是否为弥补亏损、提取盈余公积后的可供分配利润
- [ ] 可供分配利润、未分配利润数据是否与M6利润分配底稿勾稽
- [ ] 本期分配总额是否未超过可供分配利润（无超分配）
- [ ] 分配顺序是否符合公司法（亏损弥补→盈余公积→股利）

### 二、分配比例与测算公式

- [ ] 分配比例/每股股利是否与董事会/股东大会决议一致
- [ ] 应分配股利=分配基数×分配比例是否计算正确
- [ ] 各股东分配额=总额×持股比例是否逐行成立
- [ ] 测算总额是否与M1-1审定表本期宣告股利勾稽

### 三、勾稽与合规

- [ ] 测算结果是否传递至M1-2明细表按股东列示
- [ ] 涉及优先股/永续债时是否区分固定股息与普通股利
- [ ] 法定盈余公积提取是否已按净利润10%优先扣除（与M5勾稽）
- [ ] 分配决议日期与测算期间是否匹配

## risk_areas

### 高风险

1. **超可供分配利润分配**：分配总额超过弥补亏损、提取盈余公积后的可供分配利润，构成违规分配、损害债权人利益。
2. **分配基数错误**：未扣除应弥补亏损或未提取法定盈余公积即分配，违反利润分配顺序。
3. **与M6数据不勾稽**：测算的可供分配利润与M6底稿不一致，反映数据来源断裂或核算错误。

### 中风险

1. **分配比例与决议不符**：测算比例与分配决议不一致，导致分配总额和个股金额失真。
2. **测算公式错误**：分配基数×比例或持股比例分配公式设置错误，产生系统性偏差。
3. **优先股处理不当**：涉及优先股/永续债时未区分固定股息，混淆分配性质。

### 低风险

1. **测算与明细传递脱节**：测算结果未准确传递至M1-2明细表。
2. **测算表格式不规范**：分配基数、比例、金额列序不清晰。
3. **决议日期标注缺失**：未标注分配决议日期，影响期间匹配核对。
