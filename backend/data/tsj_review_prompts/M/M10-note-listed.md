# M10-note-listed 其他权益工具附注披露 复核提示词（上市公司）

## 概述

本提示词针对其他权益工具上市公司附注披露底稿（M10-note-listed）的复核，聚焦上市公司财务报表附注中其他权益工具相关披露的充分性与准确性：发行在外工具的期末情况（数量/账面价值/分类依据）、本期变动、权益属性判定依据、利息/股息分派、以及与所有者权益变动表的勾稽。其他权益工具（永续债/优先股）的权益/负债划分是投资者关注焦点，披露不充分将掩盖真实财务杠杆。

**法规依据：**
- 《企业会计准则第37号——金融工具列报》
- 《企业会计准则第22号——金融工具确认和计量》
- 《公开发行证券的公司信息披露编报规则第15号——财务报告的一般规定》

---

## tips

1. **发行在外工具期末情况须披露**：优先股、永续债等其他权益工具期末数量、账面价值须逐项披露。
2. **权益属性判定依据须披露**：分类为权益工具的依据（主要条款分析）须披露，使报表使用者理解分类判断。
3. **主要条款须披露**：发行时间、发行价格、票面利率/股息率、赎回条款、付息安排、利率跳升机制等关键条款须披露。
4. **本期变动须披露**：本期发行、赎回、转换及金额变动须披露。
5. **分派归属须披露**：分类为权益工具的利息/股息分派金额及其归属须披露（作为利润分配）。
6. **附注数据须与审定表/所有者权益变动表勾稽**：期末账面价值=审定表审定数。

## checklist

### 一、发行工具情况披露

- [ ] 发行在外的其他权益工具是否逐项披露（数量/账面价值）
- [ ] 各工具类型（永续债/优先股）是否分别披露
- [ ] 主要条款（发行时间/价格/利率/赎回/付息）是否披露
- [ ] 利率跳升机制、递延付息选择权等关键条款是否披露
- [ ] 期末账面价值合计是否等于审定表审定数

### 二、权益属性与变动披露

- [ ] 分类为权益工具的判定依据是否披露
- [ ] 本期发行/赎回/转换及金额变动是否披露
- [ ] 变动是否与所有者权益变动表勾稽
- [ ] 是否列示上年可比数据
- [ ] 归属于母公司所有者的其他权益工具是否清晰列示

### 三、分派与勾稽披露

- [ ] 本期利息/股息分派金额是否披露
- [ ] 分派是否说明作为利润分配处理
- [ ] 分派对未分配利润的影响是否披露
- [ ] 相关会计政策是否披露
- [ ] 附注数据是否与M10-2明细表勾稽

## risk_areas

### 高风险

1. **权益属性判定依据缺失**：未披露分类为权益的依据，无法评估权益/负债划分合理性。
2. **主要条款披露不充分**：赎回、利率跳升、递延付息等影响分类的关键条款未披露。
3. **变动与权益变动表不勾稽**：其他权益工具变动与所有者权益变动表不一致。
4. **期末余额与审定表不一致**：附注期末账面价值与审定数不符。

### 中风险

1. **分派披露不完整**：利息/股息分派金额或处理方式未披露。
2. **发行工具情况不完整**：未逐项披露各工具数量、账面价值。
3. **可比信息缺失**：仅列本期未列可比数据。

### 低风险

1. **披露格式不规范**：工具列示顺序、列标题等细节问题。
2. **条款描述简略**：主要条款描述不够详细。
3. **文字描述模板化**：会计政策描述照搬未结合实际。
