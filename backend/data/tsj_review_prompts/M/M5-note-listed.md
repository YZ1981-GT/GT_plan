# M5-note-listed 盈余公积附注披露复核提示词（上市公司）

## 概述

本提示词针对盈余公积上市公司附注披露底稿（M5-note-listed，科目4101）的复核，聚焦上市公司盈余公积披露的充分性与准确性：法定/任意盈余公积构成及变动、本期计提依据、盈余公积使用（补亏/转增/分配）披露、计提合规性、与所有者权益变动表及利润分配勾稽。盈余公积反映上市公司留存收益结构和分配能力，是投资者评估分红能力和权益质量的重要信息。

**法规依据：**
- 《企业会计准则第30号——财务报表列报》
- 《公开发行证券的公司信息披露编报规则第15号——财务报告的一般规定》
- 《中华人民共和国公司法》（法定盈余公积）

---

## tips

1. **盈余公积构成须分类披露**：披露法定盈余公积和任意盈余公积各自的期初、本期计提、本期使用、期末，各类合计须等于盈余公积总额。
2. **计提依据须说明**：本期盈余公积计提须说明计提基数（净利润）、比例（法定10%）及决议依据，与利润分配预案勾稽。
3. **使用情况须充分披露**：盈余公积用于弥补亏损、转增资本、分配股利须披露决议、金额及对权益的影响。
4. **计提合规性披露**：披露法定盈余公积提取比例及累计是否达注册资本50%上限，体现计提符合公司法规定。
5. **与权益变动表及利润分配勾稽**：附注盈余公积变动须与所有者权益变动表盈余公积栏、利润分配相关披露勾稽，金额相互印证。
6. **附注数据与审定表闭环勾稽**：附注盈余公积期末余额必须等于M5-1审定表审定数，各构成项与M5-2明细表、M5-4计提检查勾稽。

## checklist

### 一、构成分类披露

- [ ] 法定盈余公积与任意盈余公积是否分类披露
- [ ] 各类盈余公积期初、计提、使用、期末是否完整列示
- [ ] 各类合计是否等于盈余公积总额
- [ ] 盈余公积期末余额是否等于M5-1审定表审定数

### 二、计提与使用披露

- [ ] 本期计提是否说明基数（净利润）、比例（法定10%）及决议
- [ ] 计提是否与利润分配预案、净利润勾稽
- [ ] 盈余公积使用（补亏/转增/分配）是否披露决议及金额
- [ ] 使用对权益结构的影响是否说明

### 三、计提合规性披露

- [ ] 是否披露法定盈余公积提取比例（10%）
- [ ] 是否披露法定盈余公积累计是否达注册资本50%上限
- [ ] 计提基数（弥补亏损后净利润）确定是否披露
- [ ] 是否与M5-4计提检查勾稽

### 四、勾稽与其他披露

- [ ] 附注盈余公积变动是否与所有者权益变动表勾稽
- [ ] 各构成项与M5-2明细表是否一致
- [ ] 盈余公积可分配性及使用限制是否说明
- [ ] 期后盈余公积重大变动是否作为期后事项披露

## risk_areas

### 高风险

1. **附注盈余公积与审定表不一致**：附注披露的盈余公积期末余额与审定表审定数不一致，属重大数据勾稽错误。
2. **计提合规性披露缺失**：未披露提取比例及上限判断，无法评估计提是否符合公司法。
3. **使用披露缺失**：盈余公积重大使用（转增/补亏）未披露决议及影响，投资者无法评估权益变动实质。

### 中风险

1. **构成分类不完整**：法定与任意盈余公积未分类披露或各类合计不等于总额。
2. **计提依据不清**：本期计提未说明基数、比例或与利润分配不勾稽。
3. **与权益变动表不勾稽**：附注盈余公积变动与所有者权益变动表不一致。

### 低风险

1. **披露格式不规范**：表格标题、列序、单位等格式细节未严格按编报规则。
2. **使用限制说明缺失**：盈余公积可分配性及使用限制未说明。
3. **期后事项披露简略**：期后盈余公积变动仅提及事实未说明影响。
