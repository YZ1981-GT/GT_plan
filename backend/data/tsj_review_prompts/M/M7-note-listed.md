# M7-note-listed 专项储备附注披露 复核提示词（上市公司）

## 概述

本提示词针对专项储备上市公司附注披露底稿（M7-note-listed）的复核，聚焦上市公司财务报表附注中专项储备相关披露的充分性与准确性：专项储备变动明细（期初/本期提取/本期使用/期末）、提取依据与标准、使用情况、以及与所有者权益变动表的勾稽。专项储备涉及安全生产投入，披露不充分将影响投资者对企业安全生产合规性的判断。

**法规依据：**
- 《企业会计准则第30号——财务报表列报》
- 《企业会计准则解释第3号》
- 《企业安全生产费用提取和使用管理办法》（财资〔2022〕136号）
- 《公开发行证券的公司信息披露编报规则第15号——财务报告的一般规定》

---

## tips

1. **专项储备须在所有者权益单独列示**：根据解释第3号，专项储备作为所有者权益项目单独列示，不并入盈余公积。
2. **变动明细须与所有者权益变动表勾稽**：期初、本期提取、本期使用、期末余额须与所有者权益变动表一致。
3. **提取依据须披露**：本期提取的标准（提取比例/单位定额）及依据（行业规定）须明确披露。
4. **使用情况须披露**：本期使用金额及用途（费用性/资本性）须披露，资本性使用形成固定资产的须说明。
5. **各类别分别披露**：安全生产费、维简费等不同专项储备须分别披露变动情况。
6. **附注数据须与审定表/明细表勾稽**：期末余额=审定表审定数，变动=明细表提取/使用合计。

## checklist

### 一、变动明细披露

- [ ] 专项储备是否披露期初余额、本期提取、本期使用、期末余额
- [ ] 变动明细是否与所有者权益变动表勾稽
- [ ] 期末余额是否等于审定表审定数
- [ ] 各专项储备类别是否分别列示
- [ ] 是否列示上年可比数据

### 二、提取与使用披露

- [ ] 本期提取的标准（比例/定额）及依据是否披露
- [ ] 本期使用金额及用途是否披露
- [ ] 费用性使用与资本性使用是否区分说明
- [ ] 资本性使用形成固定资产的处理是否说明
- [ ] 专项储备的性质及会计政策是否披露

### 三、勾稽与列示

- [ ] 专项储备是否在所有者权益中单独列示（未并入盈余公积）
- [ ] 变动金额是否与M7-2明细表勾稽
- [ ] 提取金额是否与相关成本费用勾稽
- [ ] 披露口径是否与会计政策一致

## risk_areas

### 高风险

1. **变动明细与权益变动表不勾稽**：专项储备各变动项与所有者权益变动表不一致。
2. **未单独列示**：专项储备错误并入盈余公积或其他权益项目。
3. **提取依据未披露**：本期提取标准及依据缺失，无法评估合规性。
4. **期末余额与审定表不一致**：附注期末专项储备与审定数不符。

### 中风险

1. **使用情况披露不充分**：本期使用未区分费用性与资本性，或未说明用途。
2. **各类别未分别披露**：安全生产费与维简费混合披露。
3. **会计政策描述不完整**：专项储备的确认、计量政策披露不清。

### 低风险

1. **披露格式不规范**：表格列序、金额单位等细节问题。
2. **可比信息不完整**：仅列本期未列可比数据。
3. **文字描述模板化**：政策描述照搬未结合实际。
