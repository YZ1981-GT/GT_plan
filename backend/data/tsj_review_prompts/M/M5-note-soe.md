# M5-note-soe 盈余公积附注披露复核提示词（国有企业）

## 概述

本提示词针对盈余公积国有企业附注披露底稿（M5-note-soe，科目4101）的复核，聚焦国有企业特定的盈余公积披露要求：法定/任意盈余公积构成及变动、国有企业专项盈余公积（如安全生产费用外的特定公积）、盈余公积使用的"三重一大"决策、与财务决算及国有资本收益勾稽。国有企业盈余公积计提与使用兼具会计披露与国有资本管理属性，附注须同时满足会计准则和国资监管要求。

**法规依据：**
- 《企业会计准则第30号——财务报表列报》
- 《中华人民共和国公司法》
- 《企业国有资产法》
- 《中央企业财务决算报告管理办法》

---

## tips

1. **国企盈余公积披露有"双层"要求**：既满足会计准则通用披露，又须满足国资委财务决算及国有资本管理要求。
2. **法定/任意盈余公积构成变动须完整披露**：披露法定盈余公积、任意盈余公积各自的期初、计提、使用、期末，各类合计等于总额。
3. **盈余公积使用须履行决策程序**：盈余公积转增资本、弥补亏损等重大使用须经"三重一大"决策，附注应披露决策过程。
4. **与财务决算勾稽**：盈余公积数据须与年度财务决算报表一致，计提与使用须与决算报告勾稽。
5. **计提合规性披露**：披露法定盈余公积提取比例（10%）及是否达注册资本50%上限，体现计提合规性。
6. **附注数据与审定表闭环勾稽**：附注盈余公积期末余额必须等于M5-1审定表审定数，各构成项与明细表勾稽。

## checklist

### 一、基础披露完整性（与上市版共有）

- [ ] 盈余公积期末余额是否等于M5-1审定表审定数
- [ ] 法定盈余公积与任意盈余公积构成是否分类披露
- [ ] 是否披露期初数、本期计提/使用与期末数
- [ ] 本期变动是否说明性质及依据

### 二、计提合规与使用披露

- [ ] 是否披露法定盈余公积提取比例（10%）及计提基数
- [ ] 是否披露法定盈余公积是否达注册资本50%上限
- [ ] 盈余公积使用（补亏/转增）是否披露决议及用途
- [ ] 重大使用是否经"三重一大"决策并披露

### 三、决算勾稽与国资管理

- [ ] 盈余公积数据是否与年度财务决算报表一致
- [ ] 本期计提是否与利润分配、净利润勾稽
- [ ] 转增资本是否与实收资本变动勾稽
- [ ] 是否披露盈余公积对国有权益及可供分配利润的影响

### 四、与上市版差异及关联事项

- [ ] 国企版是否在基础披露上增加国资管理及决策程序信息
- [ ] 专项盈余公积（如有）是否披露性质及用途限制
- [ ] 盈余公积使用限制是否说明
- [ ] 混合所有制改革涉及盈余公积变动是否披露

## risk_areas

### 高风险

1. **计提合规性未披露**：未披露法定盈余公积提取比例及上限判断，无法评估计提合规性。
2. **重大使用未履行决策**：盈余公积转增/补亏未经"三重一大"决策，涉及合规风险。
3. **附注余额与审定表不一致**：附注盈余公积期末余额与审定表审定数不勾稽，属重大数据错误。

### 中风险

1. **构成变动披露不完整**：法定与任意盈余公积构成变动未分类披露。
2. **与财务决算不勾稽**：附注数据与年度财务决算报表存在差异未调节。
3. **使用限制说明缺失**：盈余公积使用限制及对可供分配利润影响未说明。

### 低风险

1. **披露格式未按决算模板**：附注格式与国资委决算报表模板有细微差异但信息完整。
2. **计提说明简略**：提取比例已披露但计提基数确定过程未详述。
3. **可比信息追溯不完整**：盈余公积变动历史信息覆盖不足。
