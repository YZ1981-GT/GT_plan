# M4-2 资本公积明细表复核提示词

## 概述

本提示词针对资本公积明细表（M4-2，科目4002）的复核，该表按资本溢价（股本溢价）和其他资本公积分类列示期初余额、本期增减及期末余额（24列区段Tab）。明细表逐类核对可验证资本公积各构成项的来源真实性、增减变动的合规性及与审定表的勾稽一致性。

**法规依据：**
- 《企业会计准则第2号——长期股权投资》（权益法下其他权益变动）
- 《企业会计准则第30号——财务报表列报》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **按构成项逐类核对**：资本公积明细区分资本溢价（股本溢价）、其他资本公积（权益法其他权益变动/股份支付/其他），各构成项须逐类核对来源和变动。
2. **资本溢价来源逐笔追溯**：资本溢价的本期增加须逐笔核对发行/增资凭证，溢价=实际收到对价−计入实收资本部分，计算准确。
3. **其他资本公积明细核对**：权益法下其他权益变动形成的其他资本公积须与长期股权投资（G7）逐项勾稽，股份支付形成部分须与股份支付核算勾稽。
4. **明细合计必与审定表勾稽**：M4-2各构成项期末余额合计须等于M4-1审定表期末审定数，差异反映遗漏、重复或录入错误。
5. **区段Tab数据完整性**：24列区段Tab须完整填列各构成项的期初、增加、减少、期末，各区段数据须相互勾稽。
6. **关注可转损益的其他资本公积**：其他资本公积中未来可转入损益的部分（如权益法下应转损益的其他综合收益）须单独标识，处置时正确结转。

## checklist

### 一、构成项分类与来源

- [ ] 资本溢价（股本溢价）与其他资本公积是否分类清晰
- [ ] 资本溢价本期增加是否逐笔核对发行/增资凭证
- [ ] 溢价金额=实际对价−计入实收资本部分是否计算正确
- [ ] 其他资本公积各来源（权益法/股份支付/其他）是否清晰列示

### 二、变动核对与勾稽

- [ ] 权益法下其他权益变动是否与长期股权投资（G7）逐项勾稽
- [ ] 股份支付形成的其他资本公积是否与股份支付核算勾稽
- [ ] 本期减少（转增资本/处置结转）是否有依据且金额准确
- [ ] M4-2各构成项期末余额合计是否等于M4-1审定表期末审定数

### 三、列报完整性与特殊标识

- [ ] 24列区段Tab各构成项期初/增加/减少/期末是否完整填列
- [ ] 各区段数据是否相互勾稽
- [ ] 未来可转入损益的其他资本公积是否单独标识
- [ ] 转增资本部分是否与实收资本（M2）勾稽

## risk_areas

### 高风险

1. **资本溢价来源虚假**：资本溢价本期增加无真实发行/增资凭证支持，虚增资本公积。
2. **权益法核算错误**：其他资本公积中权益法其他权益变动与长期股权投资核算不一致或计量错误。
3. **溢价计算错误**：溢价金额未正确从对价中扣除实收资本部分，导致资本公积或实收资本失真。

### 中风险

1. **明细与审定表不勾稽**：各构成项合计与审定表审定数不一致，存在遗漏、重复或汇总错误。
2. **可转损益部分未标识**：未来可转损益的其他资本公积未单独标识，处置时结转错误。
3. **股份支付勾稽缺失**：股份支付形成的其他资本公积未与股份支付核算勾稽。

### 低风险

1. **区段数据填列不完整**：24列区段Tab部分构成项期初/增减未完整填列。
2. **构成项排列不规范**：列序、构成项排列等格式问题不影响数据准确性。
3. **交叉索引不完整**：未与审定表、G7、发行凭证建立完整索引引用。
