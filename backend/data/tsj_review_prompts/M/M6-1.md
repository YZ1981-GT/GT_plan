# M6-1 未分配利润审定表 复核提示词

## 概述

本提示词针对未分配利润审定表（M6-1）的复核。未分配利润是所有者权益的核心枢纽科目，承载"期初未分配利润+本年净利润-提取盈余公积-向所有者分配"的完整利润分配链路。审定表须验证期初期末勾稽、利润分配公式完整、以前年度损益调整合规，以及与利润表净利润、盈余公积（M5）、应付股利（M1）的跨底稿闭环，任何断裂均可能导致权益类重大错报。

**法规依据：**
- 《企业会计准则第30号——财务报表列报》
- 《企业会计准则第28号——会计政策、会计估计变更和差错更正》
- 《中国注册会计师审计准则第1301号——审计证据》

## tips

1. **未分配利润是权益类贷方科目**：期末余额=期初余额+本期贷方发生额（结转净利润）-本期借方发生额（提取盈余公积/分配股利/弥补亏损），方向判断错误将导致审定数正负颠倒。
2. **利润分配公式链是审定表的生命线**：期末未分配利润=期初+本年净利润-提取法定盈余公积-提取任意盈余公积-应付普通股股利-转作股本的股利，任一环节遗漏或重复均使审定数失真。
3. **本年净利润必须与利润表勾稽**：结转至未分配利润的本年净利润须与利润表"净利润"完全一致，差异意味着结转错误或存在未过账的损益。
4. **以前年度损益调整须严格区分**：追溯重述（会计政策变更/前期重大差错）调整期初未分配利润，须有充分依据并单独披露，不得混入本期损益。
5. **期初承前启后核对**：期初未分配利润须等于上年审定表期末未分配利润，差异须追溯至追溯调整或前期差错更正，不得存在无源差异。
6. **亏损弥补顺序与限制**：以未分配利润弥补亏损、盈余公积补亏须符合公司法及章程规定的顺序，关注五年结转弥补期限与用盈余公积补亏的董事会/股东会决议。

## checklist

### 一、利润分配公式勾稽

- [ ] 期末未分配利润是否等于期初+本年净利润-利润分配各项
- [ ] 结转的本年净利润是否与利润表净利润完全一致
- [ ] 提取法定盈余公积是否为净利润的10%（累计达注册资本50%可不再提取）
- [ ] 提取任意盈余公积是否有股东会决议依据
- [ ] 应付普通股股利/优先股股利是否与M1应付股利、利润分配方案一致
- [ ] 转作股本的股利是否与实收资本/股本变动勾稽

### 二、期初期末与追溯调整

- [ ] 期初未分配利润是否等于上年审定表期末未分配利润
- [ ] 以前年度损益调整是否有充分依据（政策变更/前期差错）
- [ ] 追溯重述是否正确调整期初未分配利润而非本期损益
- [ ] 是否存在人为修改期初数但未留痕、未说明的情况
- [ ] 亏损弥补是否符合公司法与章程规定的顺序和期限

### 三、试算平衡表与调整核对

- [ ] 审定表未分配利润审定数是否与试算平衡表4104科目审定数一致
- [ ] 所有账项调整（AJE）、重分类调整（RJE）是否完整反映在审定表
- [ ] 调整分录借贷方是否平衡、调整后金额是否=未审数+AJE+RJE
- [ ] 审定表数据是否与M6-2明细表利润分配结转勾稽
- [ ] 是否存在试算平衡表已更新但审定表未同步的情况

## risk_areas

### 高风险

1. **利润分配链断裂**：净利润结转、盈余公积提取、股利分配任一环节遗漏或重复，导致期末未分配利润失真。
2. **净利润与利润表不一致**：结转的本年净利润与利润表净利润存在差异，暴露损益结转错误或未记录损益。
3. **追溯调整混入本期损益**：应作为以前年度损益调整的事项被计入本期利润，虚增/虚减本期业绩。
4. **期初不勾稽**：期初未分配利润与上年期末审定数不一致且无追溯调整依据，基准错误。
5. **违规分配利润**：在存在未弥补亏损或未提足法定盈余公积的情况下分配利润，违反公司法。

### 中风险

1. **盈余公积提取比例错误**：法定盈余公积提取比例、基数或累计封顶判断有误。
2. **股利分配与M1不勾稽**：应付股利金额、宣告日与M1应付股利底稿不一致。
3. **调整分录方向或金额错误**：AJE/RJE影响未分配利润的方向颠倒或金额有误。
4. **明细表与审定表不勾稽**：M6-2利润分配结转合计与审定表未分配利润变动不一致。

### 低风险

1. **审定表格式不规范**：行项目顺序、列标题、编号等格式问题不影响数据但降低可读性。
2. **交叉索引不完整**：未与利润表、M5盈余公积、M1应付股利建立完整索引引用。
3. **变动说明不充分**：期末较期初重大变动未附简要说明，增加复核理解难度。
