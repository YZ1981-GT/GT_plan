# M7-2 专项储备明细表 复核提示词

## 概述

本提示词针对专项储备明细表（M7-2）的复核。明细表按储备类别（安全生产费/维简费/其他）分区列示本期计提与使用的完整过程，核心是"期初余额+本期计提-本期使用（费用性/资本性）=期末余额"的公式链。复核聚焦计提依据可靠、使用分类正确、资本性支出与折旧联动，以及与审定表和计提测试勾稽。

**法规依据：**
- 《企业会计准则第30号——财务报表列报》
- 《企业安全生产费用提取和使用管理办法》（财资〔2022〕136号）
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **计提+使用明细公式链**：逐类核对期初余额、本期计提、本期使用（区分费用化与资本化）、期末余额，各节点勾稽。
2. **计提依据须可追溯**：本期计提金额应可追溯至营业收入/产量及适用提取比例，不得手工录入无源数字。
3. **使用须区分费用性与资本性**：费用性支出直接冲减储备；资本性支出（形成固定资产）冲减储备并全额计提折旧，二者会计处理不同。
4. **资本性使用与折旧联动**：形成固定资产的专项储备使用须与固定资产、累计折旧同步，关注是否全额计提折旧。
5. **分类分区列示**：安全生产费、维简费、其他专项储备须分别列示，各类别独立勾稽。
6. **使用凭证支持**：本期使用须有支出凭证、合同等支持，与M7-5支出检查表勾稽。

## checklist

### 一、公式链完整性

- [ ] 各类别期末余额=期初+本期计提-本期使用
- [ ] 本期计提金额是否可追溯至收入/产量及提取比例
- [ ] 本期使用是否区分费用性支出与资本性支出
- [ ] 资本性使用是否与固定资产/累计折旧同步并全额计提折旧
- [ ] 各类别期末合计是否等于M7-1审定表审定数

### 二、计提与使用核对

- [ ] 本期计提是否与M7-4计提测试结果一致
- [ ] 本期使用是否有支出凭证支持并与M7-5检查表勾稽
- [ ] 使用是否符合指定用途（安全生产/维护改造等）
- [ ] 是否存在计提或使用的分类错误

### 三、勾稽与汇总

- [ ] 明细表本期变动是否与审定表借贷方发生额一致
- [ ] 明细表是否同时列示期初/期末可比数据
- [ ] 各储备类别是否分别列示无混淆
- [ ] 是否存在明细遗漏或重复计入

## risk_areas

### 高风险

1. **计提金额来源错误**：本期计提与收入/产量及提取比例不匹配，导致公式链失真。
2. **资本性使用处理错误**：形成固定资产未全额计提折旧或未冲减储备。
3. **使用超范围**：专项储备用于非指定用途。

### 中风险

1. **计提与M7-4不一致**：明细表计提金额与计提测试结果不符。
2. **使用与M7-5不勾稽**：本期使用与支出检查表金额不一致。
3. **明细与审定表不勾稽**：期末合计或本期变动与M7-1不一致。

### 低风险

1. **分类列示不规范**：储备类别排列顺序未按标准。
2. **可比信息缺失**：仅列期末数未列期初可比数。
3. **索引不完整**：未与M7-4、M7-5建立交叉索引。
