# M1-4 应付股利外币汇率测算表复核提示词

## 概述

本提示词针对应付股利外币汇率测算表（M1-4，科目2232）的复核，聚焦以外币计价的应付股利（如向境外股东宣告分配的外币股利）的折算准确性：折算汇率选取、期末汇率折算、汇兑损益计算、公式勾稽。外币应付股利属外币货币性项目，须按资产负债表日即期汇率折算，汇率错误将导致负债金额和汇兑损益失真。

**法规依据：**
- 《企业会计准则第19号——外币折算》
- 《企业会计准则第37号——金融工具列报》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **应付股利是外币货币性项目**：以外币计价的应付股利须在资产负债表日按即期汇率折算，折算差额计入当期财务费用（汇兑损益）。
2. **区分宣告日汇率与期末汇率**：宣告时按宣告日即期汇率入账，期末按资产负债表日即期汇率重新折算，两者差额为汇兑损益。
3. **汇率来源须权威可靠**：折算汇率应采用中国人民银行公布或经认可的即期汇率，核对汇率来源与生效日期，避免使用错误期间的汇率。
4. **公式勾稽逐项验证**：折算后本币金额=外币金额×折算汇率，汇兑损益=期末折算本币−账面原本币，逐行核对计算公式无误。
5. **与审定表和汇兑损益勾稽**：折算后应付股利本币金额须回填至M1-1审定表，汇兑损益须与财务费用（利润表）勾稽。
6. **关注多币种与汇率波动**：涉及多个外币币种时须分币种测算，汇率大幅波动期间尤须关注折算金额的合理性。

## checklist

### 一、汇率选取与来源

- [ ] 期末折算汇率是否采用资产负债表日的即期汇率
- [ ] 汇率来源是否权威（中国人民银行公布或认可来源）并核对生效日期
- [ ] 宣告日入账汇率是否为宣告日即期汇率
- [ ] 多币种情形是否分币种采用对应汇率

### 二、折算公式与计算

- [ ] 折算后本币金额=外币金额×折算汇率是否逐行成立
- [ ] 汇兑损益=期末折算本币−账面原本币是否计算正确
- [ ] 各币种折算本币合计是否加总无误
- [ ] 是否存在汇率小数位截断导致的重大累计误差

### 三、勾稽与列报

- [ ] 折算后应付股利本币金额是否回填至M1-1审定表期末数
- [ ] 本期汇兑损益是否与财务费用（利润表）勾稽
- [ ] 外币应付股利是否在附注中按币种披露（如金额重大）
- [ ] 折算方法是否与会计政策一致且前后期一致

## risk_areas

### 高风险

1. **使用错误汇率折算**：期末未按资产负债表日即期汇率折算（如误用宣告日汇率或平均汇率），导致负债和汇兑损益失真。
2. **汇兑损益漏记或错记**：外币应付股利期末未重新折算或折算差额未计入财务费用，影响损益准确性。
3. **折算金额与审定表脱节**：M1-4折算结果未回填审定表，导致负债本币金额错误。

### 中风险

1. **汇率来源不可靠**：折算汇率来源不明或生效日期错误，折算基础不可靠。
2. **多币种测算遗漏**：涉及多币种时未分币种测算，混用汇率导致金额偏差。
3. **公式计算错误**：折算公式或汇兑损益公式设置错误，产生系统性偏差。

### 低风险

1. **小数位精度不一致**：汇率或金额小数位处理不统一，产生微小误差。
2. **披露不充分**：外币应付股利金额重大但附注未按币种披露。
3. **测算表格式不规范**：币种、汇率、金额列序不清晰，影响复核效率。
