# M7-note-soe 专项储备附注披露 复核提示词（国有企业）

## 概述

本提示词针对专项储备国有企业附注披露底稿（M7-note-soe）的复核，聚焦国有企业特定的附注披露要求：安全生产费提取与使用的监管合规披露、国资委安全生产投入考核相关信息、专项储备结存的国有资产管理视角，以及与上市公司版本的差异关注点。国有企业（尤其矿山、建筑、化工等高危行业）的安全生产费提取使用是国资监管与安全生产双重合规的重点。

**法规依据：**
- 《企业会计准则第30号——财务报表列报》
- 《企业会计准则解释第3号》
- 《企业安全生产费用提取和使用管理办法》（财资〔2022〕136号）
- 《企业国有资产法》
- 《中央企业财务决算报告管理办法》

## tips

1. **国有企业专项储备有"双层"披露要求**：既满足会计准则通用披露，又满足国资委安全生产投入考核及财务决算的额外要求。
2. **安全生产投入考核相关披露**：本期安全生产费提取与使用须与国资委安全投入考核指标勾稽披露。
3. **专项储备结存视角**：长期大额结存（提取多、使用少）可能反映安全投入不足，须结合安全生产责任说明。
4. **决算报表勾稽**：专项储备数据须与年度财务决算报表一致。
5. **与上市版差异主要在监管层面**：基础披露框架相同（变动明细/提取使用），国企版额外增加安全投入考核与国资监管信息。
6. **形成固定资产的安全设施**：以专项储备形成的安全生产固定资产须说明并关注国有资产登记。

## checklist

### 一、基础披露完整性（与上市版共有）

- [ ] 专项储备是否披露期初/本期提取/本期使用/期末余额
- [ ] 变动明细是否与所有者权益变动表勾稽
- [ ] 期末余额是否等于审定表审定数
- [ ] 各专项储备类别是否分别列示
- [ ] 提取标准及使用用途是否披露

### 二、安全投入与监管披露

- [ ] 本期安全生产费提取与使用是否与国资委考核指标勾稽
- [ ] 专项储备结存是否结合安全投入充足性说明
- [ ] 以专项储备形成的安全生产固定资产是否说明
- [ ] 安全生产投入是否达到监管要求的最低标准
- [ ] 是否披露安全生产费专项使用的合规情况

### 三、决算与结存披露

- [ ] 专项储备数据是否与年度财务决算报表一致
- [ ] 大额长期结存的原因及安全投入计划是否说明
- [ ] 是否披露专项储备使用的审批与监督情况

### 四、与上市版的差异关注点

- [ ] 国企版是否在基础披露上增加安全投入考核信息
- [ ] 是否增加国资监管相关合规说明
- [ ] 决算报表与审计报表口径差异是否调节说明
- [ ] 是否增加安全生产责任及投入充足性分析

## risk_areas

### 高风险

1. **安全投入不足未披露**：专项储备长期大额结存、安全投入不足但未说明，涉及安全生产合规及监管风险。
2. **变动明细与决算/权益变动表不勾稽**：专项储备数据与决算报表或所有者权益变动表不一致。
3. **提取使用合规信息缺失**：安全生产费提取使用未披露合规情况，无法评估监管符合性。

### 中风险

1. **考核指标未勾稽**：安全投入与国资委考核指标脱节。
2. **决算口径差异未调节**：决算数据与审计后数据差异未说明。
3. **固定资产形成信息缺失**：以专项储备形成的安全设施未说明及登记。

### 低风险

1. **披露格式未按决算模板**：格式细节差异但信息完整。
2. **结存说明简略**：大额结存原因说明不充分。
3. **可比信息追溯不完整**：历史趋势覆盖年度不足。
