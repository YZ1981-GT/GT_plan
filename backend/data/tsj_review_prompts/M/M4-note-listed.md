# M4-note-listed 资本公积附注披露复核提示词（上市公司）

## 概述

本提示词针对资本公积上市公司附注披露底稿（M4-note-listed，科目4002）的复核，聚焦上市公司资本公积披露的充分性与准确性：资本公积构成（资本溢价/其他资本公积）、本期增减变动明细、权益法下其他综合收益及其他权益变动披露、资本公积转增资本披露、与所有者权益变动表勾稽。资本公积构成及变动是反映上市公司资本运作的重要信息，披露不充分将影响报表使用者判断权益质量。

**法规依据：**
- 《企业会计准则第30号——财务报表列报》
- 《企业会计准则第2号——长期股权投资》
- 《公开发行证券的公司信息披露编报规则第15号——财务报告的一般规定》
- 《企业会计准则第11号——股份支付》

---

## tips

1. **资本公积构成须分类披露**：披露资本溢价（股本溢价）和其他资本公积各构成项的期初、增减、期末，各类合计须等于资本公积总额。
2. **变动明细须说明来源**：本期资本公积增减须逐项说明来源（增发溢价/权益法其他权益变动/股份支付/转增资本），各变动须有依据。
3. **权益法其他权益变动披露**：因联营/合营企业其他综合收益及其他权益变动确认的其他资本公积须披露，并与长期股权投资附注勾稽。
4. **转增资本披露**：资本公积转增股本须披露决议、转增比例、对股本的影响，与股本变动披露勾稽。
5. **与权益变动表勾稽**：附注资本公积变动须与所有者权益变动表资本公积栏逐项勾稽，金额相互印证。
6. **附注数据与审定表闭环勾稽**：附注资本公积期末余额必须等于M4-1审定表审定数，各构成项与M4-2明细表勾稽。

## checklist

### 一、构成分类披露

- [ ] 资本溢价与其他资本公积是否分类披露
- [ ] 各构成项期初、增减、期末是否完整列示
- [ ] 各类资本公积合计是否等于资本公积总额
- [ ] 资本公积期末余额是否等于M4-1审定表审定数

### 二、变动明细披露

- [ ] 本期增减变动是否逐项说明来源
- [ ] 增发溢价形成的资本溢价是否披露并与股本变动勾稽
- [ ] 权益法其他权益变动形成的其他资本公积是否披露
- [ ] 股份支付形成的资本公积是否披露

### 三、转增资本与勾稽

- [ ] 资本公积转增股本是否披露决议、比例及对股本影响
- [ ] 转增部分是否与股本变动披露勾稽
- [ ] 附注资本公积变动是否与所有者权益变动表勾稽
- [ ] 各构成项与M4-2明细表是否一致

### 四、其他披露事项

- [ ] 权益法其他资本公积是否与长期股权投资附注勾稽
- [ ] 未来可转损益的其他资本公积是否说明性质
- [ ] 是否披露资本公积使用限制（如不得用于弥补亏损的部分）
- [ ] 期后重大资本公积变动是否作为期后事项披露

## risk_areas

### 高风险

1. **附注资本公积与审定表不一致**：附注披露的资本公积期末余额与审定表审定数不一致，属重大数据勾稽错误。
2. **变动来源披露缺失**：本期资本公积增减未说明来源，无法评估资本运作实质。
3. **权益法其他权益变动未披露**：权益法形成的其他资本公积未披露或与长期股权投资附注不勾稽。

### 中风险

1. **构成分类不完整**：资本溢价与其他资本公积未分类披露或各类合计不等于总额。
2. **转增资本披露不充分**：资本公积转增股本未披露决议或与股本变动不勾稽。
3. **与权益变动表不勾稽**：附注资本公积变动与所有者权益变动表不一致。

### 低风险

1. **披露格式不规范**：表格标题、列序、单位等格式细节未严格按编报规则。
2. **使用限制说明缺失**：资本公积使用限制未说明。
3. **期后事项披露简略**：期后资本公积变动仅提及事实未说明影响。
