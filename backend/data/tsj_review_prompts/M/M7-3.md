# M7-3 专项储备调整分录汇总 复核提示词

## 适用底稿
专项储备调整分录汇总表（M7-3），含账项调整（AJE）、重分类调整（RJE）及未调整错报（SUD）评估。

## 概述
M7-3 是专项储备审定数链路的关键环节。复核须验证：每笔调整有证据、借贷平衡、完整反映到 M7-1 审定表，并关注调整是否正确处理提取（计入成本费用）与使用（费用化/资本化）的对应关系，避免仅调整权益而未同步成本/固定资产。

---

## tips

1. **提取调整的对应关系**：调整本期专项储备提取时须同步调整对应的成本/费用科目，不得只调权益不调成本。
2. **资本性使用调整联动**：调整形成固定资产的专项储备使用时，须联动固定资产、累计折旧，确保全额计提折旧。
3. **AJE vs RJE**：涉及专项储备的 AJE 影响权益及成本费用金额；RJE 仅涉及列报重分类，不得通过 RJE 掩盖提取/使用错报。
4. **与 M7-1 勾稽**：审定表调整列金额须与 M7-3 已确认分录逐笔一致。
5. **SUD 累计**：未调整错报单独及累计是否超过重要性阈值，须与 A13 未调整错报汇总交叉验证。
6. **TB 回写**：确认调整已同步试算平衡表 4201 科目及相关成本/固定资产科目。

## checklist

### 高风险检查项

- [ ] 所有 AJE 是否有充分审计证据支持
- [ ] 调整提取金额是否同步调整对应成本/费用科目
- [ ] 调整资本性使用是否联动固定资产、累计折旧并全额计提折旧
- [ ] 每笔调整分录借贷方是否完全平衡
- [ ] 调整金额是否完整反映到 M7-1 审定表对应调整列
- [ ] 未调整错报累计是否超过整体重要性水平（须评估）

### 中风险检查项

- [ ] RJE 是否仅涉及列报重分类，未影响提取/使用实质
- [ ] 调整原因说明是否清晰可追溯至具体审计程序
- [ ] 与 A13 未调整错报汇总索引是否完整
- [ ] 调整分录编号是否连续，删除后重号风险可控
- [ ] 是否区分建议调整与已执行调整

### 低风险检查项

- [ ] 分录摘要、科目编码是否规范
- [ ] 索引是否指向 M7-4 计提测试、M7-5 支出检查等支持底稿
- [ ] 审计说明/结论是否概括调整性质与剩余风险

## risk_areas

### 高风险

1. **调整未同步成本/资产**：仅调整专项储备权益而未同步成本费用或固定资产，破坏勾稽。
2. **调整缺乏证据**：涉及提取标准或使用合规的重大调整无充分证据。
3. **审定表与 M7-3 调整不一致**：调整未完整回写审定表。

### 中风险

1. **RJE 误含提取/使用实质**：本应仅重分类的调整影响了储备提取或使用金额。
2. **SUD 累计超阈值未处理**：错报累计超重要性水平仍出无保留意见。

### 低风险

1. **编号、格式不规范**。
2. **索引指向支持底稿不完整**。

## 跨底稿勾稽

- M7-3 已确认 AJE/RJE 合计 ↔ M7-1 审定表调整列
- M7-3 SUD ↔ A13 未调整错报汇总
- 调整后审定数 ↔ 试算平衡表 4201 科目
- 资本性使用调整 ↔ 固定资产/累计折旧科目
