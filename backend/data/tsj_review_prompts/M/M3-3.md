# M3-3 库存股调整分录汇总复核提示词

## 概述

本提示词针对库存股调整分录汇总表（M3-3，科目4002）的复核，含账项调整（AJE）、重分类调整（RJE）及未调整错报（SUD）评估。复核须验证每笔调整有回购/注销决议证据、借贷平衡、完整反映至M3-1审定表，并同步试算平衡表，尤须关注库存股备抵借方口径下调整方向的正确性及注销冲减的联动处理。

**法规依据：**
- 《中国注册会计师审计准则第1301号——审计证据》
- 《企业会计准则第30号——财务报表列报》
- 《企业会计准则第11号——股份支付》
- 《中华人民共和国公司法》

---

## tips

1. **AJE 与 RJE 区分（备抵口径）**：AJE 影响库存股金额（如更正回购成本）；RJE 涉及权益内部重分类。库存股为备抵借方项目，调整方向须与备抵性质一致。
2. **与 M3-1 勾稽**：审定表调整列金额须与 M3-3 已确认分录逐笔一致，遗漏任一笔即审定数失真。
3. **注销冲减调整须联动**：注销库存股的调整须冲减股本（M2）及资本公积（M4）/盈余公积（M5）/未分配利润，联动核对各权益项目调整一致性。
4. **回购成本更正须有交易凭证**：更正库存股回购成本的AJE须以交易记录、付款凭证为依据。
5. **SUD 累计评估**：未调整错报单独及累计是否超过整体/明显微小错报阈值，须与 A13 未调整错报汇总交叉验证。
6. **TB 回写确认**：确认调整已同步试算平衡表4002科目（备抵借方口径），方向正确。

## checklist

### 高风险检查项

- [ ] 所有 AJE 是否有充分审计证据（回购/注销决议、交易凭证等）
- [ ] 更正回购成本的调整是否有交易记录、付款凭证支持
- [ ] 库存股调整方向是否与备抵借方口径一致（回购借方/注销贷方）
- [ ] 每笔调整分录借贷方是否完全平衡
- [ ] 调整金额是否完整反映到 M3-1 审定表对应调整列
- [ ] 注销库存股调整是否与M2股本、M4资本公积、M5盈余公积联动核对
- [ ] 未调整错报累计是否超过整体重要性水平（须评估并记录）

### 中风险检查项

- [ ] RJE 是否仅涉及权益内部重分类，未错误改变权益总额
- [ ] 调整原因说明是否清晰可追溯至具体审计程序
- [ ] 与 A13 未调整错报汇总表索引是否完整
- [ ] 转让库存股价差调整是否正确计入资本公积（不计损益）
- [ ] 建议调整与已执行调整是否区分记录

### 低风险检查项

- [ ] 分录摘要、科目编码是否规范，编号是否连续
- [ ] 索引是否指向 M3-5 检查表、回购/注销决议等支持底稿
- [ ] 审计说明/结论是否概括调整性质与残余风险

## risk_areas

### 高风险

1. **调整方向错误**：库存股调整未遵循备抵借方口径，回购与注销方向颠倒，导致权益列报错误。
2. **审定表与M3-3调整金额不一致**：调整未完整反映审定表，导致审定数失真。
3. **注销联动冲减遗漏**：注销库存股调整未与股本/资本公积/盈余公积联动，权益内部结构核算错误。

### 中风险

1. **回购成本更正无凭证**：更正回购成本的调整缺乏交易记录或付款凭证支持。
2. **转让价差误入损益**：库存股转让价差调整误计入损益而非资本公积。
3. **RJE错误改变权益总额**：本应内部重分类的调整却改变了所有者权益总额。

### 低风险

1. **编号、格式不规范**：分录编号不连续、摘要不清晰影响可追溯性。
2. **索引指向不完整**：调整分录与决议、交易凭证等支持底稿的交叉引用缺失。
3. **审计说明过于简略**：未概括调整性质及对财务报表的整体影响。
