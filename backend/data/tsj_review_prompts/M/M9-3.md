# M9-3 其他综合收益调整分录汇总 复核提示词

## 适用底稿
其他综合收益调整分录汇总表（M9-3），含账项调整（AJE）、重分类调整（RJE）及未调整错报（SUD）评估。

## 概述
M9-3 是其他综合收益审定数链路的关键环节。复核须验证：每笔调整有证据、借贷平衡、完整反映到 M9-1 审定表，并重点关注调整是否正确处理税后净额（联动递延所得税）、两大类归属，以及重分类调整（转入损益/留存收益）的正确性。

---

## tips

1. **税后净额调整联动递延税**：调整OCI时须同步调整相关递延所得税影响，确保以税后净额列示。
2. **两大类归属正确**：调整须归入正确的OCI大类（能/不能重分类），不得错置。
3. **重分类调整方向**：可重分类项目转入损益、权益工具处置转入留存收益的调整须区分处理，不得误转。
4. **AJE vs RJE**：涉及OCI的 AJE 影响权益及递延税金额；RJE 涉及OCI内部重分类或列报，不得混淆两大类。
5. **与 M9-1 勾稽**：审定表调整列金额须与 M9-3 已确认分录逐笔一致。
6. **TB 回写**：确认调整已同步试算平衡表4103科目及递延所得税科目。

## checklist

### 高风险检查项

- [ ] 所有 AJE 是否有充分审计证据支持
- [ ] 调整OCI是否同步调整相关递延所得税影响
- [ ] 调整是否归入正确的OCI大类（能/不能重分类）
- [ ] 重分类调整是否正确区分转入损益与转入留存收益
- [ ] 每笔调整分录借贷方是否完全平衡
- [ ] 调整金额是否完整反映到 M9-1 审定表对应调整列
- [ ] 未调整错报累计是否超过整体重要性水平（须评估）

### 中风险检查项

- [ ] RJE 是否正确处理OCI内部重分类且未错置大类
- [ ] 调整原因说明是否清晰可追溯至具体审计程序
- [ ] 与 A13 未调整错报汇总索引是否完整
- [ ] 调整分录编号是否连续，删除后重号风险可控
- [ ] 是否区分建议调整与已执行调整

### 低风险检查项

- [ ] 分录摘要、科目编码是否规范
- [ ] 索引是否指向 M9-4 OCI核对表及各来源底稿
- [ ] 审计说明/结论是否概括调整性质与剩余风险

## risk_areas

### 高风险

1. **税后净额调整错误**：调整OCI未同步递延所得税，未以税后净额列示。
2. **重分类调整误转**：可重分类项目误转留存收益或权益工具处置误转损益。
3. **审定表与 M9-3 调整不一致**：调整未完整回写审定表。

### 中风险

1. **两大类错置**：调整将OCI项目归入错误大类。
2. **SUD 累计超阈值未处理**：错报累计超重要性水平仍出无保留意见。

### 低风险

1. **编号、格式不规范**。
2. **索引指向支持底稿不完整**。

## 跨底稿勾稽

- M9-3 已确认 AJE/RJE 合计 ↔ M9-1 审定表调整列
- M9-3 SUD ↔ A13 未调整错报汇总
- 调整后审定数 ↔ 试算平衡表 4103 科目
- OCI税后净额调整 ↔ 递延所得税资产/负债科目
