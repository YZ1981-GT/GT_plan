# M8-note-soe 一般风险准备附注披露 复核提示词（国有企业）

## 概述

本提示词针对一般风险准备国有企业附注披露底稿（M8-note-soe）的复核，聚焦国有（金融）企业特定的附注披露要求：准备金计提的监管合规披露、国资委风险管理考核相关信息、国有资本风险抵补充足性视角，以及与上市公司版本的差异关注点。国有金融企业一般风险准备的计提使用是国资监管与金融监管双重合规重点。

**法规依据：**
- 《企业会计准则第30号——财务报表列报》
- 《企业会计准则第22号——金融工具确认和计量》
- 《金融企业准备金计提管理办法》（财金〔2012〕20号）
- 《企业国有资产法》
- 《中央企业财务决算报告管理办法》

## tips

1. **国有企业一般风险准备有"双层"披露要求**：既满足会计准则通用披露，又满足国资委及金融监管的额外要求。
2. **风险抵补充足性披露**：一般风险准备结合减值准备、拨备覆盖率等综合反映风险抵补能力，须结合考核指标说明。
3. **计提达标与监管勾稽**：计提是否达到1.5%要求须与监管报表勾稽披露。
4. **决算报表勾稽**：一般风险准备数据须与年度财务决算报表一致。
5. **与上市版差异主要在监管层面**：基础披露框架相同（变动明细/计提政策），国企版额外增加国资监管与风险管理考核信息。
6. **国有资本保值增值视角**：一般风险准备的计提影响可分配利润，须结合国有资本保值增值说明。

## checklist

### 一、基础披露完整性（与上市版共有）

- [ ] 一般风险准备是否披露期初/本期提取/本期动用/期末余额
- [ ] 变动明细是否与所有者权益变动表勾稽
- [ ] 期末余额是否等于审定表审定数
- [ ] 计提政策、比例及风险资产口径是否披露
- [ ] 是否在所有者权益中单独列示

### 二、风险抵补与监管披露

- [ ] 一般风险准备是否结合减值准备、拨备覆盖率说明风险抵补能力
- [ ] 计提是否达到1.5%要求并与监管报表勾稽
- [ ] 风险管理考核相关信息是否披露
- [ ] 本期提取对可分配利润及国有资本保值增值的影响是否说明
- [ ] 动用一般风险准备的合规情况是否披露

### 三、决算与合规披露

- [ ] 一般风险准备数据是否与年度财务决算报表一致
- [ ] 计提充足性及监管合规情况是否披露
- [ ] 是否披露准备金计提的审批与监督情况

### 四、与上市版的差异关注点

- [ ] 国企版是否在基础披露上增加风险管理考核信息
- [ ] 是否增加国资监管相关合规说明
- [ ] 决算报表与审计报表口径差异是否调节说明
- [ ] 是否增加国有资本风险抵补充足性分析

## risk_areas

### 高风险

1. **风险抵补不足未披露**：一般风险准备加减值准备不足以覆盖风险但未披露，涉及监管合规风险。
2. **变动明细与决算/权益变动表不勾稽**：一般风险准备数据与决算报表或所有者权益变动表不一致。
3. **计提达标信息缺失**：未披露是否达到1.5%监管要求。

### 中风险

1. **考核指标未勾稽**：风险管理指标与国资委考核脱节。
2. **决算口径差异未调节**：决算数据与审计后数据差异未说明。
3. **保值增值影响未说明**：计提对可分配利润及保值增值的影响缺少分析。

### 低风险

1. **披露格式未按决算模板**：格式细节差异但信息完整。
2. **动用说明简略**：动用原因及审批说明不充分。
3. **可比信息追溯不完整**：历史趋势覆盖年度不足。
