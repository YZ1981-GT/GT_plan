# M10-2 其他权益工具明细表 复核提示词

## 概述

本提示词针对其他权益工具明细表（M10-2）的复核。明细表逐笔列示永续债、优先股等其他权益工具的发行要素（发行日期、发行金额、票面利率/股息率、赎回条款、付息安排）及本期变动。复核聚焦发行要素完整、权益分类依据充分、本期发行/赎回/分派处理正确，以及与审定表和区分检查表勾稽。

**法规依据：**
- 《企业会计准则第22号——金融工具确认和计量》
- 《企业会计准则第37号——金融工具列报》

---

## tips

1. **发行要素须完整**：逐笔记录工具名称、类型（永续债/优先股）、发行日期、发行金额、票面利率/股息率、期限/赎回条款、付息/分派安排。
2. **权益分类依据可追溯**：每笔工具分类为权益的依据（无强制付息、无回售义务等）须可追溯至合同条款。
3. **本期变动明细**：区分本期新发行、赎回/回购、转为负债/股本、分派金额，各自会计处理不同。
4. **利率跳升/递延付息条款关注**：永续债的利率跳升机制、递延付息选择权是判断权益属性的关键条款。
5. **发行金额扣费用**：明细中发行金额应体现扣除发行交易费用后的净额（冲减权益）。
6. **期末合计勾稽审定表**：明细表各工具期末余额合计须等于M10-1审定表审定数。

---

## checklist

### 一、发行要素完整性

- [ ] 各工具是否记录名称、类型、发行日期、发行金额、利率/股息率、条款
- [ ] 赎回条款、付息/分派安排是否记录
- [ ] 利率跳升机制、递延付息选择权等关键条款是否记录
- [ ] 发行金额是否体现扣除发行费用后净额
- [ ] 各工具期末余额合计是否等于M10-1审定表审定数

### 二、分类与变动核对

- [ ] 各工具分类为权益的依据是否可追溯至合同条款
- [ ] 本期新发行是否有发行文件/募集说明书支持
- [ ] 本期赎回/回购是否有决议及价格依据
- [ ] 本期分派金额是否作为利润分配处理
- [ ] 是否存在应转为负债/股本的情形

### 三、勾稽与汇总

- [ ] 明细表本期变动是否与审定表借贷方发生额一致
- [ ] 分类判断是否与M10-4区分检查表一致
- [ ] 明细表是否同时列示期初/期末可比数据
- [ ] 是否存在明细遗漏或重复计入

## risk_areas

### 高风险

1. **分类依据不充分**：工具分类为权益缺少合同条款支持，可能应为金融负债。
2. **关键条款遗漏**：利率跳升、递延付息、强制赎回等影响分类的条款未记录。
3. **变动处理错误**：赎回/回购/分派会计处理错误，影响权益金额。

### 中风险

1. **发行费用未扣减**：发行金额未体现扣除交易费用后净额。
2. **明细与审定表不勾稽**：期末合计或本期变动与M10-1不一致。
3. **与M10-4不一致**：分类判断与区分检查表结论不符。

### 低风险

1. **发行要素记录不全**：部分工具要素（如条款细节）记录不完整。
2. **可比信息缺失**：仅列期末数未列期初可比数。
3. **索引不完整**：未与M10-4、发行文件建立交叉索引。
