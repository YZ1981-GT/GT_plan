# M5-2 盈余公积明细表复核提示词

## 概述

本提示词针对盈余公积明细表（M5-2，科目4101）的复核，该表按法定盈余公积和任意盈余公积分类列示期初余额、本期计提、本期使用及期末余额。明细表逐类核对可验证盈余公积各构成项计提的合规性、使用的合法性及与审定表的勾稽一致性。

**法规依据：**
- 《企业会计准则第30号——财务报表列报》
- 《中国注册会计师审计准则第1301号——审计证据》
- 《中华人民共和国公司法》（法定盈余公积）

---

## tips

1. **按法定/任意分类逐项核对**：明细表须区分法定盈余公积和任意盈余公积，各类分别列示期初、计提、使用、期末，逐类核对变动。
2. **法定盈余公积计提逐项验证**：本期法定盈余公积计提=税后净利润（弥补亏损后）×10%，核对计提基数与比例，累计余额是否达注册资本50%上限。
3. **任意盈余公积以决议为准**：任意盈余公积计提及使用须有股东会决议支持，核对决议金额与账面一致。
4. **明细合计必与审定表勾稽**：M5-2各类期末余额合计须等于M5-1审定表期末审定数，差异反映遗漏、重复或录入错误。
5. **本期使用逐项核对**：盈余公积用于弥补亏损、转增资本、分配股利的使用须逐项核对决议、金额及会计处理。
6. **与利润分配勾稽**：本期计提须与M6利润分配提取栏勾稽，计提基数（净利润）须与利润表勾稽。

## checklist

### 一、分类与计提核对

- [ ] 法定盈余公积与任意盈余公积是否分类列示
- [ ] 法定盈余公积本期计提=税后净利润×10%是否计算正确
- [ ] 计提基数是否为弥补亏损后的净利润
- [ ] 任意盈余公积计提是否有股东会决议支持

### 二、使用核对与合规

- [ ] 本期使用（补亏/转增/分配）是否逐项有决议支持
- [ ] 使用金额与会计处理是否正确
- [ ] 转增资本后留存盈余公积是否不低于注册资本25%
- [ ] 法定盈余公积累计是否达注册资本50%上限

### 三、勾稽与列报

- [ ] M5-2各类期末余额合计是否等于M5-1审定表期末审定数
- [ ] 本期计提是否与M6利润分配提取栏勾稽
- [ ] 计提基数（净利润）是否与利润表勾稽
- [ ] 期末余额=期初+计提−使用是否逐类成立

## risk_areas

### 高风险

1. **法定盈余公积计提错误**：计提比例非10%或基数错误（未弥补亏损即提取），违反公司法。
2. **使用无决议支持**：盈余公积用于补亏/转增/分配无决议，构成违规使用。
3. **计提与利润分配不勾稽**：本期计提与M6提取栏或利润表净利润不一致。

### 中风险

1. **明细与审定表不勾稽**：各类合计与审定表审定数不一致，存在遗漏、重复或汇总错误。
2. **法定与任意混淆**：两类盈余公积未正确区分，强制提取部分核算错误。
3. **转增留存不合规**：转增资本后留存盈余公积低于注册资本25%。

### 低风险

1. **分类排列不规范**：列序、分类排列等格式问题不影响数据准确性。
2. **交叉索引不完整**：未与审定表、M6、决议建立完整索引引用。
3. **使用说明简略**：本期使用未附决议依据简要说明。
