# M9-1 其他综合收益审定表 复核提示词

## 概述

本提示词针对其他综合收益（OCI）审定表（M9-1）的复核。其他综合收益是未在损益中确认的利得和损失，须按"以后会计期间不能重分类进损益"和"以后会计期间在满足条件时将重分类进损益"两大类分别列示。审定表须验证权益类贷方勾稽、两大类分类正确、税后净额计量准确、以及与OCI各来源底稿（公允价值变动、设定受益计划重计量、外币折算等）勾稽。

**法规依据：**
- 《企业会计准则第30号——财务报表列报》
- 《企业会计准则第19号——外币折算》
- 《企业会计准则第22号——金融工具确认和计量》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **其他综合收益是权益类科目**：期末余额=期初余额+本期OCI变动（税后净额），本期利得计入贷方、损失计入借方，方向判断错误将导致审定数失真。
2. **两大类分类是核心**：OCI须区分"不能重分类进损益"（如设定受益计划重计量、FVOCI权益工具公允价值变动、权益法下不能转损益的份额）与"能重分类进损益"（如FVOCI债务工具公允价值变动、外币财务报表折算差额、现金流量套期损益），分类错误影响后续结转。
3. **税后净额计量**：OCI各项目须以扣除相关所得税影响后的净额列示，须核对所得税影响的计算（与递延所得税勾稽）。
4. **重分类调整**：可重分类项目在满足条件（如处置、终止确认）时转入损益，须核查重分类金额及时点，防止提前或滞后。
5. **期初承前启后核对**：期初OCI须等于上年审定表期末余额，差异须追溯说明。
6. **多来源勾稽**：审定表OCI各分项须与来源底稿勾稽（FVOCI公允变动←G8、设定受益计划重计量←J2、外币折算差额、权益法下OCI份额←长期股权投资），形成闭环。

## checklist

### 一、分类与勾稽

- [ ] OCI是否正确区分"不能重分类"与"能重分类"两大类
- [ ] 各分项是否归入正确的大类
- [ ] 期末OCI是否等于期初+本期变动（税后净额）
- [ ] 本期利得/损失方向（贷/借）是否正确
- [ ] 期初OCI是否等于上年审定表期末余额

### 二、税后净额与来源核对

- [ ] OCI各项目是否以税后净额列示
- [ ] 所得税影响计算是否正确、是否与递延所得税勾稽
- [ ] FVOCI公允价值变动是否与G8等来源底稿一致
- [ ] 设定受益计划重计量是否与J2应付职工薪酬（长期）勾稽
- [ ] 外币财务报表折算差额是否与折算底稿一致
- [ ] 权益法下享有被投资单位OCI份额是否与长期股权投资勾稽

### 三、重分类与调整核对

- [ ] 可重分类项目转入损益的金额及时点是否正确
- [ ] 是否存在应重分类未重分类或提前重分类的情况
- [ ] 审定表OCI审定数是否与试算平衡表4103科目一致
- [ ] 所有AJE、RJE是否完整反映在审定表
- [ ] 审定表数据是否与M9-2明细表、M9-4核对表勾稽

## risk_areas

### 高风险

1. **两大类分类错误**：可重分类与不可重分类项目混淆，导致后续能否转损益判断错误。
2. **应重分类未重分类**：处置FVOCI债务工具、外币折算等满足条件时未转入损益，或反之提前转入。
3. **税后净额计量错误**：OCI未扣除所得税影响或所得税计算错误，与递延所得税不勾稽。
4. **来源不勾稽**：OCI分项与G8公允变动、J2重计量、外币折算等来源底稿不一致。
5. **期初不勾稽**：期初OCI与上年期末审定数不一致且无追溯依据。

### 中风险

1. **权益法OCI份额错误**：享有被投资单位其他综合收益份额计算或结转错误。
2. **明细与审定表不勾稽**：M9-2明细表分项合计与审定表不一致。
3. **调整分录方向或金额错误**：AJE/RJE影响OCI的方向颠倒或金额有误。
4. **FVOCI权益工具处置处理错误**：权益工具投资处置时公允价值累计变动错误转入留存收益（应转留存收益而非损益）。

### 低风险

1. **审定表格式不规范**：两大类列示顺序、列标题等格式问题。
2. **交叉索引不完整**：未与G8、J2、外币折算、长期股权投资建立索引。
3. **变动说明不充分**：重大变动未附说明。
