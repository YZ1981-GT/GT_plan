# M1-6 应付股利（利润）检查表复核提示词

## 概述

本提示词针对应付股利（利润）检查表（M1-6，科目2232）的复核，聚焦股利分配全流程的凭证级检查：分配决议合法性、宣告与支付凭证核对、代扣代缴个税合规、检查比例达标性、异常事项标注充分性。检查表通过凭证核对验证股利分配的真实性、完整性与合规性，是审定表和明细表的证据支撑。

**法规依据：**
- 《中国注册会计师审计准则第1314号——审计抽样》
- 《中国注册会计师审计准则第1301号——审计证据》
- 《企业会计准则第37号——金融工具列报》
- 《中华人民共和国公司法》《中华人民共和国个人所得税法》

---

## tips

1. **分配决议是股利宣告的合法性基础**：核对董事会决议、股东大会决议的形成程序、表决结果、分配方案是否合法有效，宣告金额须与决议一致。
2. **凭证核对覆盖完整链条**：核对链条为分配决议→账务宣告→支付审批→银行付款→个税代扣申报，任一环节缺失均属证据不完整。
3. **代扣代缴个税合规是检查重点**：自然人股东股利须按适用税率代扣代缴个人所得税，核对完税凭证/申报记录，验证税款计算与申报及时性。
4. **检查比例须满足抽样要求**：金额重大项目（超重要性水平）应全覆盖，其余合理抽样，检查比例=已检查金额/总体金额须达计划水平（CAS1314）。
5. **关注异常分配事项**：大额现金支付股利、支付对象与股东不符、非等比例分配、宣告后长期不支付等须标注异常类型并调查。
6. **验证支付真实性**：核对银行回单收款方是否为对应股东，支付金额是否为应付净额（扣除代扣个税后），防止资金体外循环。

## checklist

### 一、分配决议合法性

- [ ] 是否取得董事会决议、股东大会决议，形成程序是否合法
- [ ] 决议中分配方案（分配总额、比例、方式）是否明确
- [ ] 账面宣告金额是否与决议一致，宣告日与决议日是否匹配
- [ ] 分配是否符合公司章程约定及公司法利润分配限制

### 二、凭证核对与支付真实性

- [ ] 宣告分录是否有决议支持，对方科目（利润分配）是否正确
- [ ] 支付是否有支付审批、银行回单，收款方是否为对应股东
- [ ] 支付金额是否为应付净额（扣除代扣个税后）
- [ ] 是否存在大额现金支付、支付对象与股东不符的异常并已标注

### 三、代扣个税合规

- [ ] 自然人股东股利是否按适用税率代扣代缴个人所得税
- [ ] 代扣税款是否及时申报缴纳，有完税凭证/申报记录支持
- [ ] 代扣税款计算基数、税率是否正确
- [ ] 是否存在应代扣未代扣的税务合规风险

### 四、检查比例与异常标注

- [ ] 金额重大项目（超重要性水平）是否100%全覆盖检查
- [ ] 检查比例（已检查金额/总体金额）是否达到计划水平
- [ ] 异常事项（非等比例分配/长期不支付/关联方大额）是否全部标注
- [ ] 检查发现的差异是否逐一追踪解决

## risk_areas

### 高风险

1. **无合法决议宣告分配**：股利宣告缺乏合法有效的分配决议，构成越权分配或程序违规。
2. **代扣个税漏缴**：自然人股东股利未代扣代缴个人所得税，形成税务合规风险和滞纳金隐患。
3. **支付真实性存疑**：银行回单收款方与股东不符，或以现金大额支付缺乏合理性，可能存在资金体外循环。

### 中风险

1. **检查比例不足**：实际检查比例低于计划水平，审计证据不充分，无法支持审计结论。
2. **凭证链不完整**：分配决议、支付审批、银行回单等原始单据缺失，核对深度不够。
3. **异常事项遗漏**：非等比例分配、长期挂账不支付等异常未识别标注。

### 低风险

1. **检查记录不完整**：抽样参数、核对结果的工作底稿记录不完整，影响可追溯性。
2. **索引缺失**：检查表与审定表、明细表、决议底稿的交叉索引不完整。
3. **格式不规范**：检查结果记录格式不统一，影响汇总分析效率。
