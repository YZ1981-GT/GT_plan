# M2-note-listed 实收资本（股本）附注披露复核提示词（上市公司）

## 概述

本提示词针对实收资本（股本）上市公司附注披露底稿（M2-note-listed，科目4001）的复核，聚焦上市公司股本披露的充分性与准确性：股本结构（普通股/优先股、流通股/限售股）、本期股本变动（增发/送转/回购注销）、股份变动明细表、限售股份变动情况、与所有者权益变动表勾稽。上市公司股本是投资者高度关注的核心信息，披露不充分将影响资本市场信息透明度。

**法规依据：**
- 《企业会计准则第30号——财务报表列报》
- 《企业会计准则第11号——股份支付》
- 《公开发行证券的公司信息披露编报规则第15号——财务报告的一般规定》
- 《上市公司信息披露管理办法》

---

## tips

1. **股本结构须完整披露**：披露股份总数、每股面值、普通股/优先股构成、流通股/限售股划分，各类股份数量之和须等于股份总数。
2. **股本变动明细表是披露核心**：完整列示期初股份数、本期增减（增发/送股/转增/回购注销/股份支付行权）、期末股份数，各变动均须说明原因和依据。
3. **限售股份变动须单独披露**：限售股份的锁定期、本期解禁数量、期末限售余额须单独列示，限售股持有人及锁定原因须说明。
4. **股本变动须与权益变动表勾稽**：附注股本变动须与所有者权益变动表股本栏勾稽，增发溢价须与资本公积变动勾稽。
5. **回购注销须披露决议与程序**：股份回购注销须披露董事会/股东大会决议、回购价格、注销数量及对股本的影响。
6. **附注数据与审定表闭环勾稽**：附注股本期末余额（股份数×面值）必须等于M2-1审定表审定数，各类股份与明细表勾稽。

## checklist

### 一、股本结构披露

- [ ] 是否披露股份总数、每股面值、股本总额
- [ ] 普通股/优先股构成是否清晰列示
- [ ] 流通股/限售股划分是否准确，各类股份数之和是否等于股份总数
- [ ] 股本总额（股份数×面值）是否等于M2-1审定表审定数

### 二、股本变动明细披露

- [ ] 股本变动明细表是否完整（期初/增发/送转/回购注销/行权/期末）
- [ ] 各项股本变动是否说明原因、依据及决议
- [ ] 本期增发/送转是否与资本公积、盈余公积变动勾稽
- [ ] 回购注销是否披露决议、回购价格及对股本的影响

### 三、限售股份披露

- [ ] 限售股份的锁定期、限售原因是否披露
- [ ] 本期解禁数量、期末限售余额是否单独列示
- [ ] 限售股份持有人（高管/发起人/定增对象）是否说明
- [ ] 限售股份变动是否与股本变动明细勾稽

### 四、勾稽与其他披露

- [ ] 附注股本变动是否与所有者权益变动表股本栏勾稽
- [ ] 各类股份数量、比例与明细表（M2-2）是否一致
- [ ] 涉及股份支付行权形成的股本是否披露
- [ ] 期后股本变动（如重大增发/回购）是否作为期后事项披露

## risk_areas

### 高风险

1. **附注股本与审定表不一致**：附注披露的股本期末余额与审定表审定数不一致，属重大数据勾稽错误。
2. **股本变动明细缺失或不勾稽**：股本变动明细表不完整或与权益变动表不勾稽，掩盖资本变动实质。
3. **限售股份披露缺失**：限售股份锁定期、解禁安排未披露，不满足上市公司信息披露要求。

### 中风险

1. **股本结构披露不完整**：普通股/优先股或流通股/限售股划分不清，各类股份数之和不等于总数。
2. **回购注销披露不充分**：股份回购注销未披露决议、价格及影响。
3. **增发溢价不勾稽**：增发形成的溢价未与资本公积变动勾稽。

### 低风险

1. **披露格式不规范**：表格标题、列序、单位等格式细节未严格按编报规则。
2. **文字描述模板化**：股本变动说明照搬未结合本期实际。
3. **期后事项披露简略**：期后股本变动仅提及事实未说明影响。
