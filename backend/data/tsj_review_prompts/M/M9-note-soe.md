# M9-note-soe 其他综合收益附注披露 复核提示词（国有企业）

## 概述

本提示词针对其他综合收益国有企业附注披露底稿（M9-note-soe）的复核，聚焦国有企业特定的附注披露要求：两大类OCI分项披露、外币财务报表折算差额（境外国有资产）、国有资本保值增值中OCI的影响、决算报表勾稽，以及与上市公司版本的差异关注点。国有企业OCI（尤其境外投资折算差额、金融资产公允价值变动）关系国有资本的账面波动与保值增值考核。

**法规依据：**
- 《企业会计准则第30号——财务报表列报》
- 《企业会计准则第19号——外币折算》
- 《企业会计准则第22号——金融工具确认和计量》
- 《企业国有资产法》
- 《中央企业财务决算报告管理办法》

---

## tips

1. **国有企业OCI有"双层"披露要求**：既满足会计准则两大类分项披露，又满足国资委决算及保值增值考核的额外要求。
2. **境外资产折算差额披露**：境外经营外币财务报表折算差额涉及境外国有资产，须结合境外投资情况说明。
3. **保值增值影响披露**：OCI（尤其公允价值变动、折算差额）影响国有资本账面价值波动，须结合保值增值考核口径说明。
4. **决算报表勾稽**：OCI数据须与年度财务决算报表一致。
5. **与上市版差异主要在监管层面**：两大类分项披露框架相同，国企版额外增加国有资本保值增值与境外资产监管信息。
6. **权益法下OCI份额**：对联营/合营（含国有参股）享有的OCI份额须披露来源。

## checklist

### 一、基础披露完整性（与上市版共有）

- [ ] OCI是否按两大类（不能/能重分类）分项披露
- [ ] 各分项是否披露税前发生额、所得税影响、税后净额
- [ ] OCI本期变动是否与所有者权益变动表勾稽
- [ ] 期末OCI余额是否等于审定表审定数
- [ ] 是否列示上年可比数据

### 二、境外资产与保值增值披露

- [ ] 境外经营外币财务报表折算差额是否披露并说明境外投资情况
- [ ] OCI对国有资本保值增值率的影响是否说明
- [ ] 金融资产公允价值变动对国有资本账面波动的影响是否说明
- [ ] 境外国有资产相关OCI是否纳入监管披露
- [ ] 权益法下享有被投资单位OCI份额来源是否披露

### 三、决算与勾稽披露

- [ ] OCI数据是否与年度财务决算报表一致
- [ ] 重分类转入损益金额是否披露
- [ ] OCI相关会计政策是否披露
- [ ] 分项披露是否与明细表勾稽

### 四、与上市版的差异关注点

- [ ] 国企版是否在基础披露上增加境外资产/保值增值信息
- [ ] 是否增加国资监管相关说明
- [ ] 决算报表与审计报表口径差异是否调节说明
- [ ] 是否增加OCI对国有资本波动的影响分析

## risk_areas

### 高风险

1. **两大类分项披露错误**：分项归入错误大类，误导对能否转损益的判断。
2. **境外折算差额披露缺失**：境外国有资产折算差额未披露，涉及境外国有资产监管。
3. **变动与决算/权益变动表不勾稽**：OCI数据与决算报表或所有者权益变动表不一致。
4. **期末余额与审定表不一致**：附注OCI余额与审定数不符。

### 中风险

1. **保值增值影响未说明**：OCI对国有资本保值增值的影响缺少分析。
2. **重分类金额未披露**：本期转入损益的重分类调整未单独披露。
3. **决算口径差异未调节**：决算数据与审计后数据差异未说明。

### 低风险

1. **披露格式未按决算模板**：格式细节差异但信息完整。
2. **来源说明简略**：OCI分项来源说明不充分。
3. **可比信息追溯不完整**：历史趋势覆盖年度不足。
