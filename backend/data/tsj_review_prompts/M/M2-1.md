# M2-1 实收资本（股本）审定表复核提示词

## 概述

本提示词针对实收资本（股本）审定表（M2-1，科目4001）的复核，聚焦所有者权益循环最核心的注册资本审计要点：期初期末勾稽、试算平衡表核对、出资/增减资的真实性与合法性、按出资人分类的准确性。实收资本代表股东实际投入并经工商登记的资本，审定表承载资本变动的完整链路，任何虚假出资或未登记变动均构成重大错报。（注：企业自身权益工具不适用CAS22金融工具确认计量，股份支付适用CAS11、列报适用CAS30。）

**法规依据：**
- 《企业会计准则第11号——股份支付》
- 《企业会计准则第30号——财务报表列报》
- 《中国注册会计师审计准则第1301号——审计证据》
- 《中华人民共和国公司法》《公司注册资本登记管理规定》

## tips

1. **实收资本以实际到位并登记为准**：实收资本（股本）应以股东实际缴纳并经验资、工商登记的金额确认，认缴未实缴部分不计入实收资本，审定数须与验资报告和工商登记一致。
2. **期初期末勾稽是审定表生命线**：期初审定数须等于上年期末审定数，期末=期初+本期增资（贷方）−本期减资（借方）±审计调整，任何变动须有决议、验资、工商变更登记支持。
3. **试算平衡表是第一道勾稽防线**：审定表实收资本审定数合计须与试算平衡表4001科目审定数完全一致（权益类贷方口径），差异反映未记录调整或汇总错误。
4. **按出资人分类须与股东名册一致**：审定表各出资人实收资本份额须与股东名册、公司章程记载的持股结构一致，为附注和分类列报提供支撑。
5. **区分实收资本与资本公积**：溢价发行/超额出资部分应计入资本公积（M4）而非实收资本，验证注册资本与溢价的正确划分。
6. **关注股本变动与股份支付**：涉及股份支付、以资本公积转增股本、送红股等变动须区分性质，转增股本不改变所有者权益总额但改变结构。

## checklist

### 一、期初期末勾稽

- [ ] 审定表期初未审数是否等于上年审定表期末审定数（承前启后核对）
- [ ] 期末审定数是否等于期初+本期增资−本期减资（加减审计调整）
- [ ] 审定表各行项目变动是否与明细表（M2-2）增减变动一致
- [ ] 本期资本变动是否均有股东会决议、验资报告、工商变更登记支持

### 二、试算平衡表与科目核对

- [ ] 审定表实收资本审定数合计是否与试算平衡表4001科目审定数一致（贷方口径）
- [ ] 试算平衡表未审数、调整数（AJE+RJE）与审定表对应列是否一致
- [ ] 审定表各出资人份额之和是否等于科目合计
- [ ] 是否存在试算平衡表已更新但审定表未同步的情况

### 三、出资真实性与合法性

- [ ] 实收资本是否与验资报告、工商登记的注册资本一致
- [ ] 非货币出资（实物/知识产权/股权）是否经评估作价并办理产权转移
- [ ] 溢价出资部分是否正确划分至资本公积（M4）而非实收资本
- [ ] 认缴未实缴部分是否未计入实收资本

### 四、分类列报与审计调整

- [ ] 各出资人实收资本份额是否与股东名册、章程一致
- [ ] 国有股/法人股/自然人股/外资股等分类是否准确列示
- [ ] 所有已确认的AJE/RJE是否完整反映审定表调整列且借贷平衡
- [ ] 审定表调整后金额是否等于未审数+AJE+RJE，未调整错报是否记录SUD

## risk_areas

### 高风险

1. **虚假出资/抽逃出资**：股东未实际缴纳出资却登记实收资本，或出资后抽逃，导致实收资本虚增和资本不实。
2. **期初期末不勾稽**：期初审定数与上年期末审定数不一致，存在未经授权调整，审定数失去基准。
3. **资本变动未经法定程序**：增减资未经股东会决议、验资或工商变更登记即入账，构成程序违规和存在性缺陷。
4. **试算平衡表与审定表不一致**：两者口径不一致意味着存在未被发现的汇总错误或调整遗漏。

### 中风险

1. **溢价划分错误**：溢价出资部分误计入实收资本而非资本公积，导致注册资本虚增、结构失真。
2. **非货币出资作价不实**：实物/无形资产出资未经评估或高估作价，导致资本虚增。
3. **明细与汇总不勾稽**：审定表各出资人份额合计与明细表总计不一致。
4. **分类不准确**：国有股/外资股等股权性质分类错误，影响附注披露和监管要求。

### 低风险

1. **审定表格式不规范**：列标题、行顺序、编号等格式问题不影响数据准确性。
2. **底稿交叉索引不完整**：未与试算平衡表、明细表、验资报告、调整分录建立完整索引。
3. **变动说明不充分**：重大资本变动行项目未附简要说明。
