# M4-1 资本公积审定表复核提示词

## 概述

本提示词针对资本公积审定表（M4-1，科目4002）的复核，聚焦所有者权益循环中资本公积的核心审计要点：期初期末勾稽、试算平衡表核对、资本溢价与其他资本公积的正确划分、权益法核算下其他综合收益及其他权益变动的准确性。资本公积作为权益类贷方科目，期末=期初+贷方增加−借方减少，涵盖资本溢价（股本溢价）和其他资本公积两大类，任何科目串用或来源不实均构成权益错报。

**法规依据：**
- 《企业会计准则第2号——长期股权投资》（权益法下其他权益变动）
- 《企业会计准则第30号——财务报表列报》
- 《中国注册会计师审计准则第1301号——审计证据》
- 《中华人民共和国公司法》（资本公积转增资本）

---

## tips

1. **区分资本溢价与其他资本公积**：资本溢价（股本溢价）来源于超面值发行/超额出资，其他资本公积来源于权益法下被投资单位其他权益变动、股份支付等，两类须分别列示不得混用。
2. **期初期末勾稽是审定表生命线**：期初审定数须等于上年期末审定数，期末=期初+贷方增加−借方减少±审计调整，各类资本公积变动须有来源凭证支持。
3. **试算平衡表是第一道勾稽防线**：审定表资本公积审定数合计须与试算平衡表4002科目审定数完全一致（权益类贷方口径），差异反映未记录调整或汇总错误。
4. **权益法下其他权益变动核对**：因被投资单位除净损益、利润分配外的其他所有者权益变动而调整的资本公积（其他资本公积），须与长期股权投资（G7）权益法核算联动核对。
5. **资本公积转增资本核对**：资本公积转增股本不改变所有者权益总额但改变结构，须有股东会决议和工商变更登记，与实收资本（M2）联动核对。
6. **关注资本溢价来源真实性**：溢价发行/超额出资形成的资本溢价须与发行/出资凭证核对，防止虚增资本公积美化权益结构。

## checklist

### 一、期初期末勾稽

- [ ] 审定表期初未审数是否等于上年审定表期末审定数（承前启后核对）
- [ ] 期末审定数是否等于期初+贷方增加−借方减少（加减审计调整）
- [ ] 审定表各类资本公积变动是否与明细表（M4-2）增减变动一致
- [ ] 本期资本公积变动是否均有来源凭证支持

### 二、试算平衡表与科目核对

- [ ] 审定表资本公积审定数合计是否与试算平衡表4002科目审定数一致（贷方口径）
- [ ] 试算平衡表未审数、调整数（AJE+RJE）与审定表对应列是否一致
- [ ] 资本溢价与其他资本公积明细之和是否等于科目合计
- [ ] 是否存在试算平衡表已更新但审定表未同步的情况

### 三、来源与划分准确性

- [ ] 资本溢价（股本溢价）来源是否有超面值发行/超额出资凭证支持
- [ ] 其他资本公积来源（权益法其他权益变动/股份支付）是否清晰可追溯
- [ ] 资本溢价与其他资本公积是否正确划分未混用
- [ ] 权益法下其他权益变动是否与长期股权投资（G7）联动核对

### 四、转增与审计调整

- [ ] 资本公积转增股本是否有决议、工商登记，与实收资本（M2）联动核对
- [ ] 转增后资本公积减少与股本增加金额是否勾稽一致
- [ ] 所有已确认的AJE/RJE是否完整反映审定表调整列且借贷平衡
- [ ] 审定表调整后金额是否等于未审数+AJE+RJE，未调整错报是否记录SUD

## risk_areas

### 高风险

1. **资本公积来源不实**：虚增资本溢价或其他资本公积无真实来源凭证支持，美化权益结构。
2. **期初期末不勾稽**：期初审定数与上年期末审定数不一致，审定数失去基准。
3. **权益法其他权益变动错误**：权益法下其他资本公积变动与长期股权投资核算不一致或计量错误。
4. **试算平衡表与审定表不一致**：两者口径不一致意味着存在未被发现的汇总错误或调整遗漏。

### 中风险

1. **资本溢价与其他资本公积混用**：两类资本公积未正确划分，导致来源与性质混淆。
2. **转增资本处理错误**：资本公积转增股本未与实收资本联动或金额不勾稽。
3. **明细与汇总不勾稽**：审定表各类合计与明细表（M4-2）总计不一致。
4. **股份支付计入错误**：股份支付形成的资本公积计入错误科目或金额不符。

### 低风险

1. **审定表格式不规范**：列标题、行顺序、编号等格式问题不影响数据准确性。
2. **底稿交叉索引不完整**：未与试算平衡表、明细表、G7、调整分录建立完整索引。
3. **变动来源说明不充分**：重大资本公积变动未附来源简要说明。
