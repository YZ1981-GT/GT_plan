# M4-4 资本公积检查表复核提示词

## 概述

本提示词针对资本公积检查表（M4-4，科目4002）的复核，聚焦资本公积各构成项变动的凭证级检查：资本溢价来源核对、其他资本公积（权益法/股份支付）核对、资本公积转增资本核对、检查比例达标性、异常事项标注。检查表通过凭证核对验证资本公积来源真实性、核算准确性与转增合规性，是审定表和明细表的证据支撑。

**法规依据：**
- 《中国注册会计师审计准则第1314号——审计抽样》
- 《中国注册会计师审计准则第1301号——审计证据》
- 《企业会计准则第2号——长期股权投资》
- 《中华人民共和国公司法》（资本公积转增资本）

---

## tips

1. **资本溢价来源逐笔核对**：核对超面值发行/超额出资凭证，验证溢价=实际对价−计入实收资本部分，溢价来源真实且计算准确。
2. **凭证核对覆盖变动链条**：核对链条为变动依据（发行/权益法核算/决议）→账务确认→相关权益联动，任一环节缺失均属证据不完整。
3. **权益法其他资本公积核对**：核对被投资单位其他所有者权益变动的相关资料，验证按持股比例确认的其他资本公积与G7长期股权投资核算一致。
4. **股份支付形成资本公积核对**：以权益结算的股份支付在等待期确认的资本公积（其他资本公积）须核对授予协议、公允价值、行权条件是否符合CAS11。
5. **转增资本核对**：核对资本公积转增股本的股东会决议、工商变更登记，验证转增金额、程序合法及与实收资本的联动。
6. **关注异常变动**：资本公积大额无来源增加、异常转出、跨类别调整等须标注类型并调查。

## checklist

### 一、资本溢价来源核对

- [ ] 资本溢价本期增加是否有发行/增资凭证支持
- [ ] 溢价=实际对价−计入实收资本部分是否计算正确
- [ ] 溢价发行价格、数量与收到对价是否核对一致
- [ ] 是否存在无真实来源的资本溢价增加

### 二、其他资本公积核对

- [ ] 权益法其他资本公积是否与被投资单位其他权益变动资料核对
- [ ] 按持股比例确认的其他资本公积是否与G7长期股权投资一致
- [ ] 股份支付形成的资本公积是否符合CAS11确认计量
- [ ] 其他资本公积各来源是否有充分依据

### 三、转增资本与检查比例

- [ ] 资本公积转增股本是否有决议、工商变更登记
- [ ] 转增金额是否与实收资本增加联动核对
- [ ] 金额重大变动是否100%全覆盖检查
- [ ] 检查比例（已检查金额/总体金额）是否达到计划水平

### 四、异常标注与差异追踪

- [ ] 异常事项（无来源大额增加/异常转出/跨类调整）是否全部标注
- [ ] 检查发现的差异是否逐一追踪解决
- [ ] 未来可转损益的其他资本公积处置是否正确
- [ ] 检查结论是否支持审定表资本公积审定数

## risk_areas

### 高风险

1. **资本溢价无真实来源**：资本溢价增加缺乏发行/增资凭证支持，虚增资本公积。
2. **权益法核算错误**：其他资本公积权益法变动与被投资单位资料及G7核算不一致。
3. **转增资本未经法定程序**：资本公积转增股本无决议或未办工商登记，程序违规。

### 中风险

1. **检查比例不足**：实际检查比例低于计划水平，审计证据不充分。
2. **股份支付确认错误**：股份支付形成的资本公积未按CAS11确认计量。
3. **溢价计算错误**：溢价未正确从对价中扣除实收资本部分。

### 低风险

1. **检查记录不完整**：抽样参数、核对结果的工作底稿记录不完整。
2. **索引缺失**：检查表与审定表、明细表、G7、发行凭证的交叉索引不完整。
3. **格式不规范**：检查结果记录格式不统一，影响汇总分析。
