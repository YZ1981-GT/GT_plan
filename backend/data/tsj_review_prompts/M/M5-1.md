# M5-1 盈余公积审定表复核提示词

## 概述

本提示词针对盈余公积审定表（M5-1，科目4101）的复核，聚焦所有者权益循环中盈余公积的核心审计要点：期初期末勾稽、试算平衡表核对、法定/任意盈余公积计提的合规性、盈余公积用途（补亏/转增/分配）的合法性。盈余公积作为权益类贷方科目，期末=期初+本期计提（贷方）−本期使用（借方），法定盈余公积按净利润10%强制提取，与利润分配（M6）勾稽不可断裂。

**法规依据：**
- 《企业会计准则第30号——财务报表列报》
- 《中国注册会计师审计准则第1301号——审计证据》
- 《中华人民共和国公司法》（法定盈余公积提取比例与用途）

---

## tips

1. **区分法定盈余公积与任意盈余公积**：法定盈余公积按税后净利润10%强制提取（累计达注册资本50%可不再提取），任意盈余公积由股东会决议提取，两者须分别列示。
2. **期初期末勾稽是审定表生命线**：期初审定数须等于上年期末审定数，期末=期初+本期计提−本期使用±审计调整，计提与使用须有净利润数据和决议支持。
3. **试算平衡表是第一道勾稽防线**：审定表盈余公积审定数合计须与试算平衡表4101科目审定数完全一致（权益类贷方口径），差异反映未记录调整或汇总错误。
4. **与利润分配（M6）勾稽不可断裂**：本期计提的盈余公积须与M6利润分配"提取法定盈余公积/任意盈余公积"栏勾稽，计提基数（净利润）、比例须相互印证。
5. **法定提取比例合规核对**：法定盈余公积提取=税后净利润×10%，验证提取基数为弥补亏损后的净利润，累计达注册资本50%后可停止提取。
6. **用途合法性核对**：盈余公积用于弥补亏损、转增资本、分配股利须符合公司法限制（如转增后留存不低于注册资本25%），核对使用决议和合规性。

## checklist

### 一、期初期末勾稽

- [ ] 审定表期初未审数是否等于上年审定表期末审定数（承前启后核对）
- [ ] 期末审定数是否等于期初+本期计提−本期使用（加减审计调整）
- [ ] 法定盈余公积与任意盈余公积是否分别列示且变动清晰
- [ ] 审定表各项变动是否与明细表（M5-2）增减变动一致

### 二、试算平衡表与科目核对

- [ ] 审定表盈余公积审定数合计是否与试算平衡表4101科目审定数一致（贷方口径）
- [ ] 试算平衡表未审数、调整数（AJE+RJE）与审定表对应列是否一致
- [ ] 法定与任意盈余公积明细之和是否等于科目合计
- [ ] 是否存在试算平衡表已更新但审定表未同步的情况

### 三、计提合规性

- [ ] 法定盈余公积提取是否为税后净利润（弥补亏损后）的10%
- [ ] 累计法定盈余公积达注册资本50%后是否停止提取
- [ ] 任意盈余公积提取是否有股东会决议支持
- [ ] 本期计提是否与M6利润分配提取栏勾稽（基数、比例一致）

### 四、用途合法性与审计调整

- [ ] 盈余公积用于弥补亏损/转增资本/分配股利是否有决议
- [ ] 转增资本后留存盈余公积是否不低于注册资本25%（公司法限制）
- [ ] 所有已确认的AJE/RJE是否完整反映审定表调整列且借贷平衡
- [ ] 审定表调整后金额是否等于未审数+AJE+RJE，未调整错报是否记录SUD

## risk_areas

### 高风险

1. **法定盈余公积漏提/少提**：未按净利润10%足额提取法定盈余公积，或提取基数错误（未弥补亏损即提取），违反公司法强制规定。
2. **期初期末不勾稽**：期初审定数与上年期末审定数不一致，审定数失去基准。
3. **与M6利润分配不勾稽**：本期计提盈余公积与利润分配提取栏金额不一致，反映分配核算断裂。
4. **试算平衡表与审定表不一致**：两者口径不一致意味着存在未被发现的汇总错误或调整遗漏。

### 中风险

1. **用途违规**：盈余公积转增资本后留存低于注册资本25%，或使用无决议支持。
2. **法定与任意混淆**：法定盈余公积与任意盈余公积未正确区分，导致强制提取部分核算错误。
3. **明细与汇总不勾稽**：审定表各项合计与明细表（M5-2）总计不一致。
4. **提取比例适用错误**：法定盈余公积累计已达50%仍继续强制提取，或未达50%却停止提取。

### 低风险

1. **审定表格式不规范**：列标题、行顺序、编号等格式问题不影响数据准确性。
2. **底稿交叉索引不完整**：未与试算平衡表、明细表、M6、调整分录建立完整索引。
3. **变动说明不充分**：重大计提/使用行项目未附简要说明。
