# M6-note-soe 未分配利润附注披露 复核提示词（国有企业）

## 概述

本提示词针对未分配利润国有企业附注披露底稿（M6-note-soe）的复核，聚焦国有企业特定的附注披露要求：国有资本收益上缴（国有资本经营预算）、利润分配的"三重一大"决策程序、国有资本保值增值相关信息、以及与上市公司版本的差异关注点。国有企业利润分配须同时满足会计准则与国资监管要求，未分配利润的形成与分配涉及国有资本收益管理。

**法规依据：**
- 《企业会计准则第30号——财务报表列报》
- 《企业会计准则第28号——会计政策、会计估计变更和差错更正》
- 《企业国有资产法》
- 《中央企业财务决算报告管理办法》
- 《中央企业国有资本收益收取管理暂行办法》

## tips

1. **国有企业利润分配有"双层"要求**：既满足会计准则通用披露，又满足国资委财务决算及国有资本收益上缴的额外要求。
2. **国有资本收益上缴须披露**：本年应上缴/已上缴国有资本收益（利润上缴）的金额、比例及依据须单独披露。
3. **利润分配的"三重一大"程序**：重大利润分配、盈余公积转增等须经"三重一大"集体决策，附注须披露决策过程。
4. **国有资本保值增值视角**：未分配利润的形成与积累关系国有资本保值增值率，须结合考核口径说明。
5. **与上市版差异主要在监管层面**：基础披露框架相同（变动明细/利润分配/追溯调整），国企版额外增加国有资本收益上缴与决策程序信息。
6. **附注须与决算报表一致**：未分配利润数据须与年度财务决算报表及国有资本经营预算执行情况勾稽。

## checklist

### 一、基础披露完整性（与上市版共有）

- [ ] 未分配利润是否披露期初/本年增减/期末余额
- [ ] 变动明细是否与所有者权益变动表勾稽
- [ ] 本年净利润转入是否与利润表一致
- [ ] 期末余额是否等于审定表审定数
- [ ] 提取盈余公积、利润分配是否完整披露

### 二、国有资本收益与监管披露

- [ ] 本年应上缴/已上缴国有资本收益金额、比例及依据是否披露
- [ ] 国有资本收益上缴是否与国有资本经营预算勾稽
- [ ] 重大利润分配是否经"三重一大"决策并披露过程
- [ ] 盈余公积转增资本等是否有集体决策依据
- [ ] 未分配利润积累对国有资本保值增值率的影响是否说明

### 三、决算与追溯调整披露

- [ ] 未分配利润数据是否与年度财务决算报表一致
- [ ] 以前年度损益调整/追溯重述金额及性质是否披露
- [ ] 弥补亏损情况及决策程序是否披露
- [ ] 是否披露不可分配或受限的未分配利润部分

### 四、与上市版的差异关注点

- [ ] 国企版是否在基础披露上增加国有资本收益上缴信息
- [ ] 是否增加"三重一大"决策程序说明
- [ ] 是否增加国有资本保值增值相关分析
- [ ] 决算报表与审计报表口径差异是否调节说明

## risk_areas

### 高风险

1. **国有资本收益上缴未披露**：应上缴利润未披露或未上缴且未说明，涉及国有资本收益管理合规问题。
2. **重大分配缺少"三重一大"程序**：重大利润分配/转增未经集体决策或未披露决策过程。
3. **变动明细与决算/权益变动表不勾稽**：未分配利润数据与决算报表或所有者权益变动表不一致。
4. **追溯重述影响未披露**：政策变更/前期差错调整期初未分配利润未量化披露。

### 中风险

1. **国有资本保值增值影响未说明**：未分配利润积累对考核指标的影响缺少分析。
2. **上缴比例依据不清**：国有资本收益上缴比例适用依据未说明。
3. **决算口径差异未调节**：决算数据与审计后数据存在差异但未编制调节说明。

### 低风险

1. **披露格式未按决算模板**：格式细节与国资委模板有差异但信息完整。
2. **决策程序说明简略**：仅提及决议未说明具体决策层级。
3. **可比信息追溯不完整**：历史趋势分析覆盖年度不足。
