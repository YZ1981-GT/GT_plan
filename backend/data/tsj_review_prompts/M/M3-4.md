# M3-4 库存股外币投资汇率测算表复核提示词

## 概述

本提示词针对库存股外币投资汇率测算表（M3-4，科目4002）的复核，聚焦以外币回购本公司股份（如境外上市H股/红筹回购）形成的库存股折算准确性：回购日汇率选取、折算本币入账、汇率处理、公式勾稽。外币回购形成的库存股按回购日即期汇率折算入账，作为非货币性权益备抵项目后续不因汇率变动重新折算，折算错误将导致库存股本币金额失真。

**法规依据：**
- 《企业会计准则第19号——外币折算》
- 《企业会计准则第30号——财务报表列报》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **库存股是非货币性权益备抵项目**：外币回购形成的库存股按回购日即期汇率折算入账后不再随汇率变动重新折算，与外币货币性项目处理不同。
2. **折算汇率应为回购日即期汇率**：核对各笔外币回购的回购日期与折算汇率是否匹配，多笔分批回购须分别按各自回购日汇率折算。
3. **折算本币金额勾稽验证**：折算本币金额=外币回购对价×回购日汇率，逐笔核对计算无误，多笔回购合计准确。
4. **与审定表和明细表勾稽**：折算后库存股本币金额须与M3-1审定表和M3-2明细表勾稽一致。
5. **汇率来源须权威可靠**：折算汇率采用中国人民银行公布或认可的即期汇率，核对来源与生效日期。
6. **关注注销/转让时的折算**：外币库存股注销/转让时的折算处理须与回购日入账口径一致，价差处理正确。

## checklist

### 一、汇率选取与来源

- [ ] 各笔外币回购的折算汇率是否为回购日的即期汇率
- [ ] 汇率来源是否权威（中国人民银行公布汇率）并核对生效日期
- [ ] 分批回购是否分别按各自回购日汇率折算
- [ ] 折算后是否未因后续汇率变动错误调整库存股

### 二、折算公式与计算

- [ ] 折算本币金额=外币回购对价×回购日汇率是否逐笔成立
- [ ] 多笔回购折算本币合计是否加总无误
- [ ] 注销/转让时折算处理是否与回购日入账口径一致
- [ ] 是否存在汇率小数位截断导致的重大累计误差

### 三、勾稽与列报

- [ ] 折算后库存股本币金额是否与M3-1审定表一致
- [ ] 折算结果是否与M3-2明细表按批次勾稽
- [ ] 外币回购库存股是否在附注中按币种披露（如金额重大）
- [ ] 折算方法是否与会计政策一致且前后期一致

## risk_areas

### 高风险

1. **使用错误汇率折算**：外币回购未按回购日即期汇率折算（如误用期末汇率），导致库存股本币金额失真。
2. **库存股随汇率变动错误调整**：将库存股作为货币性项目期末重新折算，违反外币折算准则。
3. **折算金额与审定表脱节**：M3-4折算结果未回填审定表或与明细表不一致。

### 中风险

1. **分批回购汇率混用**：多笔分批回购未分别按回购日汇率折算，混用汇率产生偏差。
2. **注销折算口径不一致**：注销/转让时折算处理与回购日入账口径不一致。
3. **汇率来源不可靠**：折算汇率来源不明或生效日期错误。

### 低风险

1. **小数位精度不一致**：汇率或金额小数位处理不统一，产生微小误差。
2. **披露不充分**：外币回购库存股金额重大但附注未按币种披露。
3. **测算表格式不规范**：币种、汇率、金额列序不清晰。
