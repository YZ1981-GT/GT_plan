# M2-3 实收资本（股本）调整分录汇总复核提示词

## 概述

本提示词针对实收资本（股本）调整分录汇总表（M2-3，科目4001）的复核，含账项调整（AJE）、重分类调整（RJE）及未调整错报（SUD）评估。复核须验证每笔调整有验资/决议/登记证据、借贷平衡、完整反映至M2-1审定表，并同步试算平衡表，尤须关注实收资本与资本公积间的正确划分。

**法规依据：**
- 《中国注册会计师审计准则第1301号——审计证据》
- 《企业会计准则第30号——财务报表列报》
- 《企业会计准则第11号——股份支付》
- 《中华人民共和国公司法》

---

## tips

1. **AJE 与 RJE 区分**：AJE 影响实收资本金额（如更正虚增出资）；RJE 涉及权益内部重分类（如实收资本与资本公积调整），不得通过 RJE 掩盖资本不实。
2. **与 M2-1 勾稽**：审定表调整列金额须与 M2-3 已确认分录逐笔一致，遗漏任一笔即审定数失真。
3. **资本变动调整须有法定文件**：涉及实收资本的调整须以验资报告、股东会决议、工商变更登记为依据，缺乏法定文件的调整不得入账。
4. **实收资本与资本公积划分**：溢价部分调整须正确区分实收资本（M2）与资本公积（M4），联动核对两科目调整的一致性。
5. **SUD 累计评估**：未调整错报单独及累计是否超过整体/明显微小错报阈值，须与 A13 未调整错报汇总交叉验证。
6. **TB 回写确认**：确认调整已同步试算平衡表4001科目，避免"底稿已调、TB未更"的双真源。

## checklist

### 高风险检查项

- [ ] 所有 AJE 是否有充分审计证据（验资报告、决议、工商登记等）
- [ ] 更正虚假/抽逃出资的调整是否有充分依据且对方科目正确
- [ ] AJE 是否经适当层级审批（超重要性水平须合伙人知悉）
- [ ] 每笔调整分录借贷方是否完全平衡
- [ ] 调整金额是否完整反映到 M2-1 审定表对应调整列
- [ ] 涉及实收资本与资本公积划分的调整是否与M4联动核对
- [ ] 未调整错报累计是否超过整体重要性水平（须评估并记录）

### 中风险检查项

- [ ] RJE 是否仅涉及权益内部重分类，未虚增或虚减资本总额
- [ ] 调整原因说明是否清晰可追溯至具体审计程序
- [ ] 与 A13 未调整错报汇总表索引是否完整
- [ ] 建议调整与已执行调整是否区分记录
- [ ] 转增股本调整是否与盈余公积（M5）/资本公积（M4）联动

### 低风险检查项

- [ ] 分录摘要、科目编码是否规范，编号是否连续
- [ ] 索引是否指向 M2-5 检查表、验资报告等支持底稿
- [ ] 审计说明/结论是否概括调整性质与残余风险

## risk_areas

### 高风险

1. **调整缺乏法定文件支持**：调整实收资本无验资、决议或工商登记支持，构成越权或错误调整。
2. **审定表与M2-3调整金额不一致**：调整未完整反映审定表，导致审定数失真、掩盖资本不实。
3. **SUD累计超阈值未处理**：未调整错报累计超过整体重要性水平却未恰当处理审计意见。

### 中风险

1. **实收资本与资本公积划分错误**：调整未正确区分实收资本与资本公积，导致注册资本或资本公积失真。
2. **转增股本联动遗漏**：转增股本调整未与盈余公积/资本公积联动，权益内部结构核算错误。
3. **RJE虚增/虚减资本总额**：本应内部重分类的调整却改变了权益总额。

### 低风险

1. **编号、格式不规范**：分录编号不连续、摘要不清晰影响可追溯性。
2. **索引指向不完整**：调整分录与验资报告、决议等支持底稿的交叉引用缺失。
3. **审计说明过于简略**：未概括调整性质及对财务报表的整体影响。
