# M5-5 盈余公积检查表复核提示词

## 概述

本提示词针对盈余公积检查表（M5-5，科目4101）的复核，聚焦盈余公积计提与使用全流程的凭证级检查：计提决议核对、使用（补亏/转增/分配股利）凭证核对、用途合规性、检查比例达标性、异常事项标注。检查表通过凭证核对验证盈余公积提取的合规性、使用的合法性与会计处理的正确性，是审定表和明细表的证据支撑。

**法规依据：**
- 《中国注册会计师审计准则第1314号——审计抽样》
- 《中国注册会计师审计准则第1301号——审计证据》
- 《中华人民共和国公司法》（盈余公积提取与用途）

---

## tips

1. **计提决议与利润分配方案核对**：核对股东会利润分配决议中盈余公积提取方案，法定部分（10%）为强制、任意部分须决议明确，账面计提须与决议一致。
2. **凭证核对覆盖计提使用链条**：核对链条为利润分配决议→计提入账→使用决议→使用入账，任一环节缺失均属证据不完整。
3. **使用用途合规是检查重点**：盈余公积用于弥补亏损、转增资本、分配股利须符合公司法（转增后留存不低于注册资本25%），核对使用决议和合规性。
4. **补亏使用核对**：以盈余公积弥补亏损须核对亏损金额、弥补决议及会计处理（借记盈余公积、贷记利润分配），验证补亏合规。
5. **转增资本核对**：盈余公积转增资本须核对股东会决议、工商变更登记，与实收资本（M2）联动核对。
6. **关注异常使用事项**：盈余公积异常大额转出、无决议使用、转增后留存不足等须标注类型并调查。

## checklist

### 一、计提决议核对

- [ ] 盈余公积计提是否有股东会利润分配决议支持
- [ ] 法定盈余公积计提是否符合10%强制比例
- [ ] 任意盈余公积计提比例是否与决议一致
- [ ] 账面计提金额是否与决议方案一致

### 二、使用凭证与合规核对

- [ ] 盈余公积使用（补亏/转增/分配）是否逐项有决议支持
- [ ] 补亏使用的会计处理是否正确（借盈余公积、贷利润分配）
- [ ] 转增资本是否办理工商变更登记，与实收资本（M2）联动
- [ ] 转增/使用后留存盈余公积是否不低于注册资本25%

### 三、检查比例与异常标注

- [ ] 金额重大计提/使用是否100%全覆盖检查
- [ ] 检查比例（已检查金额/总体金额）是否达到计划水平
- [ ] 异常事项（无决议使用/异常转出/留存不足）是否全部标注
- [ ] 检查发现的差异是否逐一追踪解决

### 四、勾稽与结论

- [ ] 本期计提是否与M5-4计提检查、M6利润分配勾稽
- [ ] 计提基数（净利润）是否与利润表勾稽
- [ ] 使用金额是否与明细表（M5-2）本期使用一致
- [ ] 检查结论是否支持审定表盈余公积审定数

## risk_areas

### 高风险

1. **无决议提取或使用**：盈余公积计提或使用缺乏股东会决议支持，构成越权或程序违规。
2. **法定提取不合规**：法定盈余公积提取比例低于10%或基数错误，违反公司法。
3. **使用用途违规**：转增资本后留存低于注册资本25%，或用途不符合公司法规定。

### 中风险

1. **检查比例不足**：实际检查比例低于计划水平，审计证据不充分。
2. **补亏处理错误**：以盈余公积弥补亏损的会计处理错误或金额不符。
3. **转增联动缺失**：盈余公积转增资本未与实收资本联动核对。

### 低风险

1. **检查记录不完整**：抽样参数、核对结果的工作底稿记录不完整。
2. **索引缺失**：检查表与审定表、明细表、M6、决议的交叉索引不完整。
3. **格式不规范**：检查结果记录格式不统一，影响汇总分析。
