# M1-2 应付股利明细表复核提示词

## 概述

本提示词针对应付股利明细表（M1-2，科目2232）的复核，该表按股东逐户列示应付股利的期初余额、本期宣告、本期支付、代扣个税及期末余额。明细表是审定表（M1-1）的数据支撑，逐户核对可验证股利分配的完整性、准确性与按持股比例分配的正确性。

**法规依据：**
- 《企业会计准则第37号——金融工具列报》
- 《企业会计准则第30号——财务报表列报》
- 《中国注册会计师审计准则第1301号——审计证据》
- 《中华人民共和国个人所得税法》（自然人股东股利代扣代缴）

---

## tips

1. **逐户核对持股比例分配**：各股东本期宣告股利=可分配利润×分配比例×该股东持股比例，须与股东名册和分配决议逐一核对，比例错误将导致个别股东金额失真。
2. **区分法人股东与自然人股东**：自然人股东股利涉及个人所得税代扣代缴（通常20%或差别化税率），明细表应清晰列示应付净额与代扣税款。
3. **明细合计必与审定表勾稽**：M1-2各股东期末余额合计须等于M1-1审定表期末审定数，任何差异反映遗漏、重复或录入错误。
4. **关注宣告与支付的时间匹配**：本期宣告在贷方、本期支付在借方，逐户核对支付凭证与银行回单，验证实际支付真实性。
5. **长期挂账股东需重点关注**：某股东应付股利长期未支付需查明原因（资金紧张/决议执行障碍/关联方资金占用），评估是否存在异常。
6. **关联方股东单独识别**：控股股东、实际控制人及其关联方应付股利须单独可识别，为附注关联方披露和审定表分类提供支撑。

## checklist

### 一、逐户核对与分配准确性

- [ ] 各股东名称、持股比例是否与股东名册/工商登记一致
- [ ] 各股东本期宣告股利是否按持股比例和分配决议正确计算
- [ ] 各股东期末余额=期初+本期宣告−本期支付是否逐户成立
- [ ] 是否存在应分配股东遗漏或非股东被列入分配的情况

### 二、宣告支付与凭证核对

- [ ] 本期宣告金额合计是否与分配决议总额一致
- [ ] 本期支付是否有支付凭证、银行回单支持，收款方是否为对应股东
- [ ] 代扣代缴个人所得税金额是否按适用税率正确计算并申报
- [ ] 是否存在以现金大额支付股利、支付对象与股东不符的异常

### 三、勾稽与分类

- [ ] M1-2各股东期末余额合计是否等于M1-1审定表期末审定数
- [ ] 明细表本期宣告合计是否与M6利润分配应付股利分配栏勾稽
- [ ] 关联方股东应付股利是否单独可识别
- [ ] 长期挂账（跨年度未付）股东是否单独标注并说明原因

## risk_areas

### 高风险

1. **分配比例计算错误**：个别股东宣告金额未按持股比例计算，导致股东间金额分配失真、负债个别错报。
2. **股东遗漏或虚列**：应分配股东未列入或非股东被列入分配名单，导致负债完整性或存在性缺陷。
3. **代扣个税漏缴**：自然人股东股利未代扣代缴个人所得税，形成税务合规风险和潜在滞纳金负债。

### 中风险

1. **明细与审定表不勾稽**：逐户合计与审定表审定数不一致，存在遗漏、重复或汇总错误。
2. **支付真实性存疑**：支付凭证收款方与股东名册不符，或以现金大额支付缺乏合理性。
3. **关联方股东未识别**：控股股东应付股利未单独标注，影响关联方披露和分类。

### 低风险

1. **长期挂账未说明**：跨年度未付股利未标注原因，增加复核判断难度。
2. **明细表格式不统一**：列序、股东排列顺序等格式问题不影响数据准确性。
3. **交叉索引不完整**：未与审定表、M6、支付凭证建立完整索引引用。
