# M7-1 专项储备审定表 复核提示词

## 概述

本提示词针对专项储备审定表（M7-1）的复核。专项储备是按国家规定从成本或费用中提取、专门用于安全生产等特定用途的所有者权益项目（如安全生产费、维简费）。审定表须验证权益类贷方勾稽（期末=期初+本期提取-本期使用）、提取与使用的合规性、与试算平衡表4201科目及明细表勾稽，以及形成固定资产部分的正确处理。

**法规依据：**
- 《企业会计准则第30号——财务报表列报》
- 《企业会计准则解释第3号》（专项储备列报）
- 《企业安全生产费用提取和使用管理办法》（财资〔2022〕136号）
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **专项储备是权益类贷方科目**：期末余额=期初余额+本期提取（贷方）-本期使用（借方，费用化/形成资产），方向判断错误将导致审定数失真。
2. **提取计入成本费用而非损益分配**：专项储备提取时借记成本/费用、贷记专项储备，属所有者权益内部项目，不通过利润分配，且不影响净利润的形成逻辑但影响成本费用。
3. **使用分两种情形**：费用性支出直接冲减专项储备（借专项储备、贷银行存款等）；形成固定资产的，先按在建工程/固定资产核算，完工后同时冲减专项储备并全额计提折旧（借专项储备、贷累计折旧）。
4. **提取标准须合规**：安全生产费按行业标准（营业收入或产量分档比例）提取，维简费按规定标准，超提或少提均需关注。
5. **期初承前启后核对**：期初专项储备须等于上年审定表期末余额，差异须追溯说明。
6. **试算平衡表与明细勾稽**：审定数须与试算平衡表4201科目及M7-2明细表提取/使用合计勾稽，形成闭环。

## checklist

### 一、权益勾稽与方向

- [ ] 期末专项储备是否等于期初+本期提取-本期使用
- [ ] 提取（贷方）、使用（借方）方向是否正确
- [ ] 期初专项储备是否等于上年审定表期末余额
- [ ] 是否存在期初被修改但未留痕、未说明的情况
- [ ] 审定表分类（安全生产费/维简费/其他）合计是否等于总额

### 二、提取与使用合规

- [ ] 本期提取金额是否按规定标准（营业收入/产量比例）计算
- [ ] 提取是否正确计入相关成本/费用科目
- [ ] 费用性使用是否直接冲减专项储备
- [ ] 形成固定资产的使用是否冲减专项储备并全额计提折旧
- [ ] 是否存在挪用专项储备用于非指定用途的情形

### 三、试算平衡表与调整核对

- [ ] 审定表专项储备审定数是否与试算平衡表4201科目审定数一致
- [ ] 所有AJE、RJE是否完整反映在审定表
- [ ] 调整分录借贷方是否平衡、调整后金额是否=未审数+AJE+RJE
- [ ] 审定表数据是否与M7-2明细表提取/使用勾稽
- [ ] 提取金额是否与M7-4计提测试结果一致

## risk_areas

### 高风险

1. **提取标准错误**：安全生产费/维简费提取比例或基数适用错误，导致超提或少提，影响成本费用和权益。
2. **使用方向或处理错误**：形成固定资产未冲减专项储备并全额计提折旧，或费用性支出未正确冲减。
3. **专项储备被挪用**：将专项储备用于非安全生产等指定用途，违反管理办法。
4. **期初不勾稽**：期初专项储备与上年期末审定数不一致且无追溯依据。

### 中风险

1. **提取与M7-4测试不一致**：审定表提取金额与计提测试结果存在差异。
2. **调整分录方向或金额错误**：AJE/RJE影响专项储备的方向颠倒或金额有误。
3. **明细与审定表不勾稽**：M7-2提取/使用合计与审定表变动不一致。
4. **分类列示不当**：安全生产费与维简费未分别列示。

### 低风险

1. **审定表格式不规范**：行项目顺序、列标题等格式问题。
2. **交叉索引不完整**：未与M7-2明细表、M7-4计提测试建立索引。
3. **变动说明不充分**：重大变动未附说明。
