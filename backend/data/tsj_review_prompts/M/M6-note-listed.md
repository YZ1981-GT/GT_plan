# M6-note-listed 未分配利润附注披露 复核提示词（上市公司）

## 概述

本提示词针对未分配利润上市公司附注披露底稿（M6-note-listed）的复核，聚焦上市公司财务报表附注中未分配利润相关披露的充分性与准确性：期初期末变动明细、本年提取盈余公积、本年利润分配（含分配政策与派息方案）、以前年度损益调整及追溯重述影响、期末未分配利润构成，以及与所有者权益变动表的勾稽。上市公司利润分配直接关系中小投资者利益，披露不充分将影响投资决策。

**法规依据：**
- 《企业会计准则第30号——财务报表列报》
- 《企业会计准则第28号——会计政策、会计估计变更和差错更正》
- 《公开发行证券的公司信息披露编报规则第15号——财务报告的一般规定》
- 《中国注册会计师审计准则第1501号——对财务报表形成审计意见和出具审计报告》

---

## tips

1. **未分配利润变动明细须与所有者权益变动表勾稽**：附注中期初、本年增减、期末余额须与所有者权益变动表相应列完全一致。
2. **利润分配方案披露须完整**：本年宣告及实施的现金股利、股票股利、每股派息金额、分配比例须清晰披露，并区分对普通股与优先股的分配。
3. **提取盈余公积须单独披露**：本年提取法定盈余公积、任意盈余公积的金额及依据须明确列示。
4. **追溯重述影响须量化披露**：会计政策变更/前期差错更正调整期初未分配利润的金额及对可比期间的影响须单独披露。
5. **期末未分配利润受限情况须提示**：若存在因监管、章程或协议限制而不可分配的部分，须予以提示。
6. **附注数据须与审定表/所有者权益变动表/利润表形成闭环勾稽**：期末余额=审定表审定数，本年净利润=利润表净利润。

## checklist

### 一、变动明细披露

- [ ] 未分配利润是否披露期初余额、本年增减、期末余额
- [ ] 变动明细是否与所有者权益变动表勾稽一致
- [ ] 本年净利润转入金额是否与利润表净利润一致
- [ ] 期末余额是否等于审定表审定数
- [ ] 是否列示上年同期可比数据

### 二、利润分配披露

- [ ] 本年提取法定盈余公积、任意盈余公积金额及依据是否披露
- [ ] 本年宣告/实施的现金股利、股票股利是否披露
- [ ] 每股派息、分配比例及分配对象（普通股/优先股）是否清晰
- [ ] 分配方案是否已履行股东会审议程序并披露
- [ ] 期后拟分配利润方案是否作为期后事项披露

### 三、追溯调整与受限披露

- [ ] 以前年度损益调整/追溯重述的金额及性质是否单独披露
- [ ] 追溯重述对可比期间报表及每股收益的影响是否量化
- [ ] 是否披露不可分配的未分配利润部分（如有限制）
- [ ] 弥补亏损情况是否披露

## risk_areas

### 高风险

1. **变动明细与权益变动表不勾稽**：未分配利润各变动项与所有者权益变动表不一致，属重大披露错误。
2. **利润分配方案披露缺失或不实**：漏披露或错误披露股利分配金额、每股派息，误导投资者。
3. **追溯重述影响未量化披露**：政策变更/前期差错调整期初未分配利润未披露金额及可比期间影响。
4. **期末余额与审定表不一致**：附注期末未分配利润与审定数不符。

### 中风险

1. **盈余公积提取披露不完整**：未单独列示本年提取金额及依据。
2. **优先股分配披露缺失**：对优先股的利润分配未单独说明。
3. **受限情况未提示**：不可分配部分未提示，影响投资者对可分配利润的判断。

### 低风险

1. **披露格式不完全规范**：表格列序、金额单位等细节问题。
2. **文字描述模板化**：分配政策描述照搬未结合本企业实际。
3. **可比信息不完整**：仅列本期未列可比期数据。
