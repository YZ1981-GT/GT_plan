# M8-note-listed 一般风险准备附注披露 复核提示词（上市公司）

## 概述

本提示词针对一般风险准备上市公司附注披露底稿（M8-note-listed）的复核，聚焦上市（金融）公司财务报表附注中一般风险准备相关披露的充分性与准确性：变动明细（期初/本期提取/本期动用/期末）、计提政策与比例、风险资产口径、以及与所有者权益变动表和监管指标的勾稽。一般风险准备涉及金融企业风险抵补能力，披露不充分将影响投资者对企业风险状况的判断。

**法规依据：**
- 《企业会计准则第30号——财务报表列报》
- 《企业会计准则第22号——金融工具确认和计量》
- 《金融企业准备金计提管理办法》（财金〔2012〕20号）
- 《公开发行证券的公司信息披露编报规则第15号——财务报告的一般规定》

## tips

1. **一般风险准备须在所有者权益单独列示**：作为所有者权益项目单独列示，与盈余公积、未分配利润区分。
2. **变动明细须与所有者权益变动表勾稽**：期初、本期提取、本期动用、期末余额须与所有者权益变动表一致。
3. **计提政策及比例须披露**：计提方法（按风险资产1.5%）、风险资产口径及计提依据须披露。
4. **达标情况须披露**：一般风险准备余额是否达到风险资产1.5%的监管要求须说明。
5. **与减值准备关系须说明**：一般风险准备是减值准备之外的补充，其性质须清晰披露。
6. **附注数据须与审定表/明细表/所有者权益变动表勾稽**：期末余额=审定表审定数。

## checklist

### 一、变动明细披露

- [ ] 一般风险准备是否披露期初/本期提取/本期动用/期末余额
- [ ] 变动明细是否与所有者权益变动表勾稽
- [ ] 期末余额是否等于审定表审定数
- [ ] 是否列示上年可比数据
- [ ] 是否在所有者权益中单独列示

### 二、计提政策与达标披露

- [ ] 计提方法、比例（1.5%）及风险资产口径是否披露
- [ ] 一般风险准备余额是否达到监管要求的说明
- [ ] 本期提取的依据及决策是否披露
- [ ] 一般风险准备与减值准备的关系是否说明
- [ ] 计提政策是否与会计政策一致

### 三、勾稽与列示

- [ ] 变动金额是否与M8-2明细表勾稽
- [ ] 计提金额是否与M6利润分配中提取勾稽
- [ ] 动用情况及依据是否披露
- [ ] 披露口径是否与监管报表一致

## risk_areas

### 高风险

1. **变动明细与权益变动表不勾稽**：一般风险准备各变动项与所有者权益变动表不一致。
2. **计提不达标未披露**：一般风险准备低于1.5%要求但未披露，掩盖风险抵补不足。
3. **计提政策未披露**：计提方法、比例、风险资产口径缺失。
4. **期末余额与审定表不一致**：附注期末余额与审定数不符。

### 中风险

1. **与减值准备关系未说明**：未说明一般风险准备的性质及与减值准备的区别。
2. **动用披露不充分**：本期动用金额及依据未披露。
3. **达标情况说明不清**：未明确说明是否达到监管要求。

### 低风险

1. **披露格式不规范**：表格列序、金额单位等细节问题。
2. **可比信息不完整**：仅列本期未列可比数据。
3. **文字描述模板化**：计提政策描述照搬未结合实际。
