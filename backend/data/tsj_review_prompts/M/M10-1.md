# M10-1 其他权益工具审定表 复核提示词

## 概述

本提示词针对其他权益工具审定表（M10-1）的复核。其他权益工具是企业发行的、按金融工具准则分类为权益工具的金融工具（如永续债、优先股中符合权益条件的部分）。审定表须验证权益类贷方勾稽（期末=期初+发行/转入-赎回/回购）、按工具类型分类正确、权益工具与金融负债划分准确（CAS37核心判断），以及与试算平衡表4003科目及明细表勾稽。

**法规依据：**
- 《企业会计准则第22号——金融工具确认和计量》
- 《企业会计准则第37号——金融工具列报》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **其他权益工具是权益类贷方科目**：期末余额=期初余额+本期发行/转入（贷方）-本期赎回/回购/转出（借方），方向判断错误将导致审定数失真。
2. **权益/负债划分是核心判断**：须核实工具是否符合权益工具定义（无支付现金的合同义务、以自身权益工具结算的固定换固定等），错误分类为权益将虚增权益、隐藏负债。
3. **按工具类型分类**：审定表须按永续债、优先股等工具类型分类列示，各类型独立勾稽。
4. **发行费用处理**：权益工具发行的交易费用应冲减权益（其他权益工具），不计入损益。
5. **利息/股利分派处理**：分类为权益的工具，其分派（利息/股息）作为利润分配处理（冲减未分配利润），不计入财务费用。
6. **期初承前启后核对**：期初其他权益工具须等于上年审定表期末余额，赎回/回购须核实决议及价格。

## checklist

### 一、权益勾稽与方向

- [ ] 期末其他权益工具是否等于期初+发行/转入-赎回/回购/转出
- [ ] 发行（贷方）、赎回/回购（借方）方向是否正确
- [ ] 各工具类型（永续债/优先股）合计是否等于总额
- [ ] 期初其他权益工具是否等于上年审定表期末余额
- [ ] 是否存在期初被修改但未留痕、未说明的情况

### 二、权益/负债划分与处理

- [ ] 各工具分类为权益是否符合CAS37权益工具定义
- [ ] 是否存在应分类为金融负债却错分为权益的情形
- [ ] 发行交易费用是否冲减权益（不计入损益）
- [ ] 分派（利息/股息）是否作为利润分配处理（不计入财务费用）
- [ ] 赎回/回购价格与账面差额处理是否正确

### 三、试算平衡表与调整核对

- [ ] 审定表其他权益工具审定数是否与试算平衡表4003科目审定数一致
- [ ] 所有AJE、RJE是否完整反映在审定表
- [ ] 调整分录借贷方是否平衡、调整后金额是否=未审数+AJE+RJE
- [ ] 审定表数据是否与M10-2明细表勾稽
- [ ] 分类判断是否与M10-4负债与权益区分检查表一致

## risk_areas

### 高风险

1. **权益/负债划分错误**：应分类为金融负债的工具（如强制付息、含赎回义务的永续债）错分为权益，虚增权益、隐藏负债和财务费用。
2. **分派处理错误**：将权益工具分派计入财务费用而非利润分配，或反之，扭曲损益与权益。
3. **发行费用处理错误**：发行交易费用计入损益而非冲减权益。
4. **期初不勾稽**：期初其他权益工具与上年期末审定数不一致且无说明。

### 中风险

1. **赎回/回购差额处理错误**：赎回价格与账面差额未正确调整权益。
2. **分类与M10-4不一致**：审定表分类判断与负债权益区分检查表结论不符。
3. **调整分录方向或金额错误**：AJE/RJE影响其他权益工具的方向颠倒或金额有误。
4. **明细与审定表不勾稽**：M10-2明细合计与审定表不一致。

### 低风险

1. **审定表格式不规范**：工具类型列示顺序、列标题等格式问题。
2. **交叉索引不完整**：未与M10-2明细表、M10-4区分检查表建立索引。
3. **变动说明不充分**：重大变动未附说明。
