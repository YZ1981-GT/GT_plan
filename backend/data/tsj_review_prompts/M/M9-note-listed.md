# M9-note-listed 其他综合收益附注披露 复核提示词（上市公司）

## 概述

本提示词针对其他综合收益上市公司附注披露底稿（M9-note-listed）的复核，聚焦上市公司财务报表附注中OCI相关披露的充分性与准确性：按两大类（不能重分类/能重分类）列示各分项的税前发生额、所得税影响、税后净额，本期转入损益的重分类金额，以及与所有者权益变动表和综合收益总额的勾稽。OCI披露直接影响投资者对企业未实现损益的理解。

**法规依据：**
- 《企业会计准则第30号——财务报表列报》
- 《企业会计准则第19号——外币折算》
- 《企业会计准则第22号——金融工具确认和计量》
- 《公开发行证券的公司信息披露编报规则第15号——财务报告的一般规定》

## tips

1. **须按两大类分项披露**：OCI须区分"以后不能重分类进损益"和"以后能重分类进损益"两大类，分别列示各分项。
2. **三栏披露**：每项OCI须披露"本期所得税前发生额、减所得税影响、税后归属于母公司/少数股东金额"。
3. **重分类金额单独披露**：本期由OCI转入损益的重分类调整金额须单独列示。
4. **与综合收益总额勾稽**：OCI税后净额加净利润=综合收益总额，须与利润表综合收益总额勾稽。
5. **与所有者权益变动表勾稽**：OCI本期变动须与所有者权益变动表OCI列一致。
6. **附注数据须与审定表/明细表勾稽**：期末OCI余额=审定表审定数。

## checklist

### 一、两大类分项披露

- [ ] OCI是否按两大类（不能/能重分类）分项披露
- [ ] 各分项是否披露税前发生额、所得税影响、税后净额
- [ ] 是否区分归属于母公司所有者与少数股东的金额
- [ ] 各分项归类是否正确
- [ ] 是否列示上年可比数据

### 二、重分类与勾稽披露

- [ ] 本期转入损益的重分类调整金额是否单独披露
- [ ] OCI税后净额加净利润是否等于综合收益总额（与利润表勾稽）
- [ ] OCI本期变动是否与所有者权益变动表勾稽
- [ ] 期末OCI余额是否等于审定表审定数
- [ ] FVOCI权益工具处置转入留存收益是否披露

### 三、来源与政策披露

- [ ] OCI各分项来源（FVOCI变动/设定受益计划重计量/外币折算/权益法份额）是否清晰
- [ ] 所得税影响的计算是否披露
- [ ] OCI相关会计政策是否披露
- [ ] 分项披露是否与明细表勾稽

## risk_areas

### 高风险

1. **两大类分项披露错误**：分项归入错误大类，误导投资者对能否转损益的判断。
2. **重分类金额未单独披露**：本期转入损益的重分类调整未单独列示。
3. **与综合收益总额不勾稽**：OCI税后净额加净利润不等于综合收益总额。
4. **期末余额与审定表不一致**：附注OCI余额与审定数不符。

### 中风险

1. **三栏披露不完整**：未披露税前发生额、所得税影响、税后净额的完整信息。
2. **归属划分缺失**：未区分归属于母公司与少数股东的OCI。
3. **权益工具处置披露缺失**：处置FVOCI权益工具转入留存收益未披露。

### 低风险

1. **披露格式不规范**：两大类列示顺序、列标题等细节问题。
2. **可比信息不完整**：仅列本期未列可比数据。
3. **来源说明简略**：OCI分项来源说明不充分。
