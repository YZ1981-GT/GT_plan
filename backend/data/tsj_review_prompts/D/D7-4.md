# D7-4 合同负债分析表复核提示词

## 概述

本提示词针对合同负债分析表（D7-4，科目码2205）的复核，聚焦四大核心审计要点：账龄分析准确性、变动分析合理性、与收入确认勾稽、异常项目识别。分析表通过账龄结构、期间变动趋势及与收入的勾稽关系，评估合同负债的合理性、收入确认时点的恰当性及潜在的长期挂账风险。合同负债的减少对应收入确认，分析表是识别提前/滞后确认收入、长期挂账等风险的重要分析性程序底稿。

**法规依据：**
- 《企业会计准则第14号——收入》
- 《企业会计准则第37号——金融工具列报》
- 《中国注册会计师审计准则第1301号——审计证据》
- 《中国注册会计师审计准则第1313号——分析程序》

## tips

1. **账龄分析揭示长期挂账风险**：合同负债账龄结构反映预收款转化为收入的周期，长账龄合同负债（超过正常履约周期）需重点关注是否应确认收入、是否应退回，须与D7-5长期挂账检查勾稽。
2. **变动分析识别收入确认异常**：合同负债本期减少额对应本期确认的收入，变动趋势应与业务模式、履约周期一致，异常增减可能提示收入确认时点操纵。
3. **与收入确认的勾稽是分析核心**：本期合同负债结转收入金额应与收入底稿中来自合同负债的收入一致，期末合同负债应与未履约合同义务匹配，勾稽断裂提示收入确认错误。
4. **合同负债与收入的比率分析**：合同负债余额与营业收入、预收款占比等比率的期间变动，可揭示预收模式变化或收入确认政策异常。
5. **分析程序须结合业务实质**：不同行业（如软件、建筑、会员服务）的合同负债特征不同，分析须结合企业业务模式判断合同负债水平及变动的合理性。
6. **关注跨底稿勾稽**：D7-4账龄分析 ↔ D7-2明细表账龄；D7-4变动分析 ↔ D7-1审定表期初期末；本期结转收入 ↔ 收入底稿；长账龄合同负债 ↔ D7-5长期挂账检查。

## checklist

### 一、账龄分析准确性

- [ ] 账龄划分标准是否与会计政策及D7-2明细表一致
- [ ] 各账龄段合同负债金额合计是否等于合同负债总额（与D7-1审定数勾稽）
- [ ] 账龄起算日是否以收款日/合同负债确认日为准且口径统一
- [ ] 账龄分析数据是否与D7-2明细表账龄分析一致
- [ ] 长账龄（超过正常履约周期）合同负债是否单独列示并分析
- [ ] 账龄结构较上期是否存在重大变动并说明原因

### 二、变动分析合理性

- [ ] 合同负债期初、本期新增、本期结转、期末的变动是否完整列示
- [ ] 本期变动趋势是否与业务模式、履约周期一致
- [ ] 期末余额较期初重大变动（超过30%）是否有合理解释
- [ ] 本期新增合同负债是否与新签合同/预收款一致
- [ ] 本期结转合同负债是否与实际履约进度一致
- [ ] 是否存在异常波动提示收入确认时点操纵

### 三、与收入确认勾稽

- [ ] 本期合同负债结转收入金额是否与收入底稿勾稽
- [ ] 期末合同负债是否与未履约合同义务匹配
- [ ] 合同负债结转收入的时点是否与履约进度证据一致
- [ ] 是否存在合同负债提前结转收入（虚增当期收入）的迹象
- [ ] 是否存在合同负债应结转却滞后结转（低估当期收入）的迹象
- [ ] 合同负债余额与营业收入的比率分析是否合理

### 四、异常项目识别

- [ ] 长期挂账合同负债是否已识别并转D7-5专项检查
- [ ] 是否存在履约义务已消失但仍挂账的合同负债
- [ ] 是否存在异常大额合同负债集中于个别客户/合同
- [ ] 关联方合同负债的变动是否异常（与D7-6勾稽）
- [ ] 期末新增大额合同负债是否核查真实性（是否为调节收入）
- [ ] 分析中发现的异常项目是否已追踪并记录处理结果

## risk_areas

### 高风险

1. **提前确认收入减少合同负债**：本期合同负债异常减少但无对应真实履约，虚增当期收入，涉及收入确认时点操纵。
2. **长期挂账应确认收入未识别**：长账龄合同负债履约义务已完成却长期挂账未结转收入，分析未能识别。
3. **合同负债结转与收入不勾稽**：本期结转收入金额与收入底稿不一致，提示收入确认错误。
4. **期末调节收入**：期末通过大额合同负债增减调节当期收入及业绩，未被分析识别。
5. **履约义务已消失仍挂账**：合同负债对应履约义务已消失（客户放弃/合同终止）却仍挂账，掩盖应确认的收入或应退款项。

### 中风险

1. **账龄分析口径不一致**：分析表账龄起算日与明细表不一致，账龄结构失真。
2. **变动分析缺乏业务解释**：合同负债重大变动未结合业务模式说明原因。
3. **比率分析异常未追踪**：合同负债与收入比率异常变动但未进一步分析原因。
4. **关联方合同负债变动异常**：关联方合同负债变动异常但未与D7-6勾稽核查。
5. **长期挂账未转专项检查**：识别出的长账龄合同负债未转D7-5专项检查。

### 低风险

1. **分析表格式不规范**：账龄表、变动表格式等形式问题。
2. **分析深度不足**：仅列示数据未进行趋势/结构分析。
3. **辅助信息缺失**：缺少行业对比、业务模式说明等辅助分析信息。
4. **交叉索引不完整**：与D7-1审定表、D7-2明细、D7-5长期挂账及收入底稿的交叉引用标注不全。
