# D4-13 ERP系统收入检查表复核提示词

## 概述

本提示词针对 ERP 系统收入检查表（D4-13）的复核，聚焦四大核心审计要点：系统收入数据完整性、与账面收入勾稽、系统权限与内控、数据导出可靠性。ERP 系统收入检查通过验证信息系统中收入数据的完整性、准确性和一致性，评估收入相关信息系统内部控制（IT一般控制和应用控制）的有效性，是数据驱动审计时代验证收入真实性、识别系统性错报和舞弊的关键程序。

**法规依据：**
- 《企业会计准则第14号——收入》
- 《中国注册会计师审计准则第1301号——审计证据》
- 《中国注册会计师审计准则第1633号——电子商务对财务报表审计的影响》
- 《中国注册会计师审计准则第1211号——识别和评估重大错报风险》（信息系统了解）

---

## tips

1. **系统数据完整性是数据审计的前提**：须验证从 ERP 导出的收入数据是否完整（无遗漏订单/发票/交易），导出参数（期间/科目/维度）是否正确，数据总量与系统汇总数是否一致。
2. **系统与账面勾稽验证一致性**：ERP 销售模块收入必须与财务模块账面收入、总账 6001/6051 科目勾稽一致，模块间差异反映系统集成或人工调整问题。
3. **系统权限反映内控有效性**：须评估收入相关系统权限（录入/审核/修改/删除）是否职责分离，是否存在超级用户绕过控制、是否有未经授权的价格/订单修改权限。
4. **警惕系统外的人工调整**：须识别绕过系统的人工凭证、系统数据被后台直接修改、系统日志被删除等迹象，系统外调整是收入舞弊的高发区。
5. **数据导出可靠性影响审计证据**：审计师应亲自或监督数据导出，验证导出工具/查询语句的正确性，避免管理层提供经筛选/篡改的数据。
6. **勾稽关系**：ERP销售模块收入 ↔ 财务模块收入 ↔ 总账6001/6051 ↔ D4-2明细表；系统订单数 ↔ 发票数 ↔ 发货数，勾稽断裂为复核重点。

## checklist

### 一、系统收入数据完整性（高风险）

- [ ] 【必检】ERP 导出收入数据的期间范围是否完整覆盖审计期间
- [ ] 【必检】导出数据是否包含全部销售订单/发票/收入交易（无遗漏）
- [ ] 【必检】导出数据总量是否与系统汇总数一致
- [ ] 【必检】导出参数（科目/期间/维度/公司范围）是否正确
- [ ] 【必检】数据导出是否由审计师亲自执行或监督
- [ ] 【条件检查：若多系统】各销售子系统数据是否完整汇总
- [ ] 【风险检查】是否存在系统数据被筛选/篡改后提供

### 二、与账面收入勾稽（高风险）

- [ ] 【必检】ERP 销售模块收入是否与财务模块账面收入勾稽
- [ ] 【必检】系统收入是否与总账 6001/6051 科目一致
- [ ] 【必检】系统收入是否与 D4-2/D4-3 明细表勾稽
- [ ] 【必检】销售订单-发货-开票-收入的系统流转是否闭环
- [ ] 【条件检查：若有差异】系统与账面差异是否调节并说明
- [ ] 【风险检查】是否存在系统无记录但账面有收入（系统外收入）
- [ ] 【风险检查】是否存在系统有订单但未确认收入（遗漏收入）

### 三、系统权限与内控（中风险）

- [ ] 【必检】收入相关系统权限（录入/审核/修改/删除）是否职责分离
- [ ] 【必检】价格/折扣修改权限是否受控并留痕
- [ ] 【必检】订单/发票修改删除是否有审批和日志
- [ ] 【必检】是否存在超级用户绕过应用控制
- [ ] 【条件检查：若权限集中】权限过度集中的补偿控制是否有效
- [ ] 【风险检查】是否存在未经授权的收入数据修改

### 四、数据可靠性与系统日志（中风险）

- [ ] 【必检】系统数据导出工具/查询语句是否验证正确
- [ ] 【必检】系统日志（操作日志/修改记录）是否完整未被删除
- [ ] 【必检】系统时间戳与业务发生时间是否一致
- [ ] 【条件检查：若发现异常修改】异常修改记录是否追溯核实
- [ ] 【风险检查】是否存在批量后台修改收入数据的迹象
- [ ] 【风险检查】系统日志是否显示期末集中修改/删除

## risk_areas

### 高风险

1. **系统外收入舞弊**：账面存在收入但 ERP 系统无对应订单/发货记录，反映绕过系统的人工虚增收入，是舞弊高发区。
2. **系统数据被篡改**：管理层提供经筛选或篡改的收入数据，或后台直接修改系统收入，审计证据基础失真。
3. **系统与账面重大差异**：ERP 收入与总账/账面收入存在重大差异未调节，反映系统集成失效或人工调整舞弊。
4. **系统权限失控**：收入录入/审核/修改权限未职责分离，超级用户可绕过控制修改收入，内控形同虚设。
5. **系统日志被删除**：收入相关操作日志被删除或不完整，掩盖未经授权的数据修改，反映舞弊隐匿。

### 中风险

1. **数据导出不完整**：导出参数错误或范围不全导致收入数据遗漏，影响审计总体完整性。
2. **模块间数据不一致**：销售模块与财务模块收入数据不一致，反映系统集成或人工干预问题。
3. **订单-发货-开票流转断裂**：系统内销售流程未闭环，存在无发货的开票或无开票的收入。
4. **价格修改无留痕**：系统价格/折扣修改无审批和日志，无法验证定价合规性。
5. **系统时间异常**：系统时间戳与业务发生时间不一致，可能存在倒签或跨期操作。

### 低风险

1. **数据导出记录不详**：导出参数、执行人、时间等记录不完整。
2. **系统了解文档缺失**：收入相关信息系统的了解和流程记录不充分。
3. **权限清单不完整**：系统权限清单未完整获取或未及时更新。
4. **交叉索引不完整**：与明细表、审定表、控制测试底稿的交叉引用不全。
