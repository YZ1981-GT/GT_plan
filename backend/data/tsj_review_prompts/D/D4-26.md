# D4-26 境外收入核查表复核提示词

## 概述

本提示词针对营业收入境外收入核查表（D4-26）的复核，聚焦境外客户身份真实性、交易真实性、外汇回款情况、以及是否虚构境外收入。境外收入因客户远隔、函证回收难、监管信息不对称，成为收入舞弊的高发领域，虚构境外客户和境外销售是典型手段。复核须综合海关报关、外汇收付、物流单据、客户背景等多方证据穿透验证。

**法规依据：**
- 《企业会计准则第14号——收入》
- 《中国注册会计师审计准则第1141号——财务报表审计中与舞弊相关的责任》
- 《中国注册会计师审计准则第1231号——针对评估的重大错报风险采取的应对措施》
- 《中国注册会计师审计准则第1312号——函证》

---

## tips

1. **境外收入是收入舞弊高发区**：客户远隔、函证难、信息不对称使虚构境外客户和境外销售成为常见舞弊手段，须作为重大错报风险重点应对（CAS1141/CAS1231）。
2. **海关报关单是境外货物销售的独立外部证据**：出口销售须核对海关出口报关单，报关金额、品名、目的国、日期须与账面收入和物流单据一致，无报关的境外销售须重点质疑。
3. **外汇回款是验证真实性的关键**：境外收入应有对应外汇收款，须核对银行外汇入账、结汇记录，警惕长期无外汇回款、回款来自异常地区或非客户主体的境外收入。
4. **境外客户身份须穿透核实**：通过境外工商登记、企业信用信息、独立第三方渠道核实境外客户真实存在、有实际经营，警惕注册于避税地、成立时间短、无实际经营的空壳客户。
5. **境外函证与替代程序**：境外客户函证回收率低，须评估函证有效性，未回函须实施海关报关+物流签收+外汇回款的组合替代程序（CAS1312）。
6. **物流与运输单据交叉验证**：境外销售的提单、海运/空运单据、目的港签收记录须与报关、收入、外汇回款相互印证，形成完整证据链。

## checklist

### 一、境外客户身份核查

- [ ] 主要境外客户是否通过独立渠道核实真实存在
- [ ] 境外客户是否有实际经营（经营场所/经营历史/信用信息）
- [ ] 是否存在注册于避税地/离岸地的境外客户
- [ ] 境外客户成立时间是否过短即发生大额交易
- [ ] 境外客户是否与被审计单位存在关联关系
- [ ] 是否存在多个境外客户共用地址/联系方式/收款账户

### 二、交易真实性与报关

- [ ] 出口销售是否核对海关出口报关单
- [ ] 报关金额、品名、数量、目的国是否与账面收入一致
- [ ] 报关日期是否与收入确认时点匹配
- [ ] 是否存在无报关记录的境外销售
- [ ] 物流单据（提单/海运空运单/签收）是否齐全并与报关印证
- [ ] 境外销售的货物流是否真实完整

### 三、外汇回款核查

- [ ] 境外收入是否有对应外汇收款记录
- [ ] 外汇入账金额、币种、汇率折算是否与收入勾稽
- [ ] 是否存在长期无外汇回款的境外收入
- [ ] 外汇回款是否来自客户本身（非第三方/异常地区）
- [ ] 结汇记录是否与外汇入账一致
- [ ] 汇率折算差异（汇兑损益）是否处理正确

### 四、函证替代与结论

- [ ] 境外客户函证是否发送，回收率是否评估
- [ ] 函证有效性是否评估（回函地址/方式是否可靠）
- [ ] 未回函是否实施组合替代程序（报关+物流+外汇回款）
- [ ] 境外收入是否存在虚构迹象（三流不一致/无报关/无回款）
- [ ] 核查结论是否明确（真实/存疑需进一步/虚构需调整）
- [ ] 底稿是否记录核查方法、证据链及交叉索引

## risk_areas

### 高风险

1. **虚构境外客户与销售**：利用境外客户难核实、函证难回收，虚构境外客户和销售虚增收入，属重大收入舞弊（CAS1141）。
2. **无报关无回款的境外收入**：境外销售无海关报关、无外汇回款却确认收入，缺乏独立外部证据支撑，虚构嫌疑重大。
3. **避税地空壳客户**：境外客户注册于避税地、无实际经营、成立时间短即大额交易，客户真实性严重存疑。
4. **三流不一致**：报关、物流、外汇回款与账面收入相互矛盾，交易实质与账面背离。

### 中风险

1. **外汇回款异常**：境外收入长期无回款或回款来自非客户主体/异常地区，收款真实性存疑。
2. **函证有效性不足**：境外函证回函地址/方式不可靠或回收率极低，函证证据力弱。
3. **替代程序不充分**：未回函境外销售的替代程序未形成完整证据链。
4. **报关与账面差异**：报关金额与账面收入存在差异未合理解释。

### 低风险

1. **境外客户核查范围不足**：仅核查部分主要境外客户，覆盖面不足。
2. **汇率折算记录不完整**：外汇折算依据及汇兑损益计算记录不完整。
3. **交叉索引缺失**：与函证、报关单、外汇收款、物流单据的交叉引用不完整。
