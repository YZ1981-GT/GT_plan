# D6-3 合同资产减值准备明细表复核提示词

## 概述

本提示词针对合同资产减值准备明细表（D6-3，科目码1402对应备抵）的复核，聚焦四大核心审计要点：减值准备变动完整性、预期信用损失计提合理性、单项与组合划分准确性、减值准备与合同资产账面价值勾稽。根据CAS22，合同资产同样适用预期信用损失（ECL）减值模型。减值准备明细表承载期初余额、本期计提、转回、核销、期末余额的完整变动链路，是评估合同资产减值充分性的核心底稿。

**法规依据：**
- 《企业会计准则第22号——金融工具确认和计量》
- 《企业会计准则第14号——收入》
- 《中国注册会计师审计准则第1301号——审计证据》
- 《中国注册会计师审计准则第1540号——审计会计估计（含公允价值会计估计）及相关披露》

---

## tips

1. **合同资产适用ECL减值模型**：根据CAS22，合同资产的减值须按预期信用损失计量，通常采用简化法（始终按整个存续期预期信用损失计量），减值准备明细表须体现这一计量基础。
2. **减值准备变动表的勾稽是复核核心**：期初余额 + 本期计提 − 本期转回 − 本期核销 ± 其他变动 = 期末余额，各项须可追溯至具体计提测算（D6-8）或核销审批（D6-9）。
3. **单项计提与组合计提的划分须有依据**：对信用风险显著增加或已发生信用减值的合同资产单项评估，其余按组合评估，划分标准须与会计政策及ECL计算表（D6-8）一致。
4. **本期计提金额须与损益勾稽**：合同资产减值计提计入信用减值损失，须与利润表信用减值损失科目及D6-8计算结果一致。
5. **减值准备须覆盖后续履约风险与信用风险双重因素**：合同资产减值不仅考虑对方信用风险，还需考虑企业能否完成后续履约义务从而实现收款权，评估须综合两者。
6. **关注减值准备与账面价值的勾稽**：合同资产减值准备期末余额 = 合同资产账面余额 − 合同资产净额；各账龄/组合减值 ↔ D6-8对应损失率测算；核销金额 ↔ D6-9核销检查表。

## checklist

### 一、减值准备变动完整性

- [ ] 减值准备变动表是否完整列示（期初/计提/转回/核销/其他/期末）
- [ ] 变动表勾稽是否成立（期初+计提−转回−核销±其他=期末）
- [ ] 期初减值准备余额是否与上年审定期末数一致
- [ ] 本期计提金额是否与D6-8预期信用损失计算结果一致
- [ ] 本期核销金额是否与D6-9核销检查表一致且有审批依据
- [ ] 本期转回是否有合理依据（信用风险实质性下降或后续履约恢复）

### 二、预期信用损失计提合理性

- [ ] 减值是否按CAS22预期信用损失模型计量（合同资产通常适用简化法）
- [ ] 损失率的确定是否基于历史损失经验并结合前瞻性信息
- [ ] 是否同时考虑对方信用风险与企业后续履约能力风险
- [ ] 计提比例是否与合同资产账龄、履约进度及对方信用状况匹配
- [ ] 减值计提是否充分覆盖长账龄及后续履约存疑的合同资产
- [ ] 计提金额是否与利润表信用减值损失科目勾稽一致

### 三、单项与组合划分准确性

- [ ] 单项计提与组合计提的划分标准是否与会计政策一致
- [ ] 信用风险显著增加或已减值的合同资产是否纳入单项评估
- [ ] 组合评估的分组是否基于共同信用风险特征合理划分
- [ ] 单项计提与组合计提合计是否等于减值准备总额
- [ ] 划分是否与ECL计算表（D6-8）的分组一致
- [ ] 单项计提的可收回金额估计是否有充分依据

### 四、减值准备与账面价值勾稽

- [ ] 减值准备期末余额是否等于合同资产账面余额减净额
- [ ] 减值准备明细各行是否与合同资产明细表（D6-2）对应
- [ ] 各账龄/组合减值准备是否与D6-8对应损失率测算勾稽
- [ ] 减值准备净额列示是否与审定表（D6-1）及附注一致
- [ ] 期末减值准备是否与试算平衡表对应备抵科目审定数一致

## risk_areas

### 高风险

1. **减值准备变动表不勾稽**：变动表各项金额勾稽关系不成立，或与D6-8/D6-9数据不一致，属重大错误。
2. **减值计提不足**：长账龄或后续履约存疑的合同资产未充分计提减值，通过低估损失率虚增合同资产净额及利润。
3. **单项/组合划分不当**：应单项评估的高风险合同资产混入组合，掩盖个别重大减值风险。
4. **计提与损益不勾稽**：减值计提金额与利润表信用减值损失不一致，存在跨科目错报。
5. **核销缺乏审批**：本期核销未经适当审批或与D6-9不勾稽，可能掩盖坏账或虚减减值准备余额。

### 中风险

1. **损失率缺乏依据**：损失率未基于历史损失经验或未结合前瞻性信息，估计缺乏客观支持。
2. **未考虑后续履约风险**：减值仅考虑对方信用风险，忽略企业能否完成后续履约义务的因素。
3. **转回缺乏合理依据**：本期减值转回未说明信用风险实质性下降或履约恢复的依据。
4. **减值与账龄不匹配**：长账龄合同资产计提比例与短账龄无明显差异，未体现风险递增。
5. **组合分组不合理**：组合评估分组未基于共同信用风险特征，损失率适用错误。

### 低风险

1. **变动表格式不规范**：变动表列序、标题等格式问题不影响数据准确性。
2. **计提测算过程记录不详**：损失率测算过程记录不完整，影响复核可追溯性。
3. **交叉索引不完整**：与D6-2明细表、D6-8 ECL表、D6-9核销表的交叉引用标注不全。
4. **前瞻性信息说明简略**：前瞻性调整因子的选取依据说明过于简略。
