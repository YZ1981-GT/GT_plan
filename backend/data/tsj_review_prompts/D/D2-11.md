# D2-11 坏账准备转回（收回）、核销检查复核提示词

## 适用底稿
坏账准备转回（收回）及核销检查表（D2-11），含转回区、核销区及与 D2-3 一致性校验。

## 概述
转回与核销直接影响损益与 ECL 模型有效性。复核须验证：审批完整、会计处理正确、与 D2-3/D2-2 勾稽、期后收回证据充分。

---

## tips

1. **转回 vs 收回**：区分坏账准备转回（原已计提后收回）与直接冲减应收，会计分录与披露不同。
2. **核销条件**：核销须有充分证据（法院裁定、债务重组协议、内部审批），不得随意核销美化账龄。
3. **与 D2-3 一致性**：系统 `reversalConsistencyWarning` 类告警须逐笔解释；转回/核销合计应能在 D2-3 变动分析中追溯。
4. **合理性判断**：「合理/不合理/待核实」结论须有证据，不能全部默认合理。
5. **期后程序**：大额转回/核销是否执行期后凭证检查或银行回单核对。
6. **关联方**：关联方转回/核销须特别关注商业实质与披露。

## checklist

### 高风险检查项

- [ ] 每笔核销是否有充分法律依据或内部审批（法院裁定、董事会决议等）
- [ ] 转回金额是否与期后实际收款或重组协议一致
- [ ] 转回/核销合计与 D2-3 坏账准备本期变动勾稽（系统一致性告警须清零或解释）
- [ ] 是否存在通过核销掩盖长期挂账或关联方占用的情形
- [ ] 核销后是否仍与客户存在未披露交易或往来
- [ ] 大额异常转回（尤其期末集中）是否执行追加程序

### 中风险检查项

- [ ] 债务人名称、金额与 D2-2 明细可对应
- [ ] 转回原因分类（收回/重组/其他）是否准确
- [ ] 「合理性」判断是否有逐行审计意见或 AI 复核留痕
- [ ] 总体分析是否概括转回/核销规模、趋势及对 ECL 的影响
- [ ] 索引号是否指向收款凭证、法院文书、重组协议

### 低风险检查项

- [ ] 转回区、核销区合计公式正确
- [ ] 导入导出 round-trip 数据完整
- [ ] 审计结论模板选用是否匹配实际情况

## risk_areas

### 高风险

- 无证据批量核销降低账龄或隐藏损失
- 转回与 D2-3 变动严重不符
- 关联方核销缺乏商业实质

### 中风险

- 合理性判断流于形式
- 总体分析未覆盖重大转回/核销

### 低风险

- 格式、索引不规范

## 跨底稿勾稽

- D2-11 转回/核销合计 ↔ D2-3 坏账准备本期变动
- D2-11 债务人 ↔ D2-2 明细表对应客户
- 核销后余额 ↔ D2-1 审定表应收与坏账准备
