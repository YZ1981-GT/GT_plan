# D6-9 合同资产核销检查复核提示词

## 概述

本提示词针对合同资产核销检查表（D6-9，科目码1141）的复核，聚焦四大核心审计要点：核销审批程序完整性、核销依据充分性、核销会计处理正确性、核销后续追踪与披露。合同资产核销是在确定无法收回（如对方破产、后续履约义务无法完成且无追索）时冲减合同资产及减值准备的处理。核销缺乏审批或依据不足可能掩盖坏账或人为操纵减值准备余额，是舞弊风险关注领域。

**法规依据：**
- 《企业会计准则第22号——金融工具确认和计量》
- 《中国注册会计师审计准则第1301号——审计证据》
- 《中国注册会计师审计准则第1141号——财务报表审计中与舞弊相关的责任》
- 《中国注册会计师审计准则第1540号——审计会计估计（含公允价值会计估计）及相关披露》

## tips

1. **核销审批程序是核销合规性的基础**：合同资产核销须经适当层级审批（重大核销须经董事会/管理层集体决策），检查表须核对审批文件的完整性及审批权限。
2. **核销依据须充分证明无法收回**：核销须有充分证据证明合同资产确实无法收回（对方破产清算证明、法院判决、后续履约无法完成的证明、长期催收无果记录等），仅账龄长不足以支持核销。
3. **核销会计处理须正确**：核销应冲减合同资产及已计提的减值准备（借：减值准备 贷：合同资产），核销金额与减值准备计提是否匹配，超过已计提部分是否补提，处理须正确。
4. **核销与减值准备变动勾稽**：核销金额须与D6-3减值准备变动表的本期核销栏一致，并与D6-1审定表期末余额变动勾稽。
5. **核销后续追踪不可忽视**：已核销的合同资产在法律上债权仍存在的，须建立备查登记，后续收回时应重新入账，检查表须关注是否有已核销又收回的情况。
6. **关注核销的舞弊迹象**：警惕通过虚假核销转移资产、核销后私下收款、或期末集中核销以调节减值准备余额及利润的舞弊行为。

## checklist

### 一、核销审批程序完整性

- [ ] 本期核销的合同资产是否逐笔列示（金额/合同/客户/核销原因）
- [ ] 核销是否经适当层级审批（重大核销须集体决策）
- [ ] 审批是否在审批权限范围内，超权限是否上报
- [ ] 审批文件是否完整（审批单、决议、签字）
- [ ] 审批时点是否在核销入账之前
- [ ] 是否存在未经审批即核销的情况

### 二、核销依据充分性

- [ ] 核销是否有充分证据证明无法收回
- [ ] 对方破产/清算/注销的，是否有法律证明文件
- [ ] 涉诉的，是否有法院判决/裁定支持
- [ ] 后续履约义务无法完成导致无法收款的，是否有相关证明
- [ ] 长期催收无果的，是否有催收记录支持
- [ ] 是否存在依据不足（仅账龄长）即核销的情况

### 三、核销会计处理正确性

- [ ] 核销会计分录是否正确（冲减合同资产及减值准备）
- [ ] 核销金额是否与已计提减值准备匹配，超过部分是否补提
- [ ] 核销金额是否与D6-3减值准备变动表本期核销栏一致
- [ ] 核销是否正确反映在D6-1审定表期末余额变动中
- [ ] 核销是否影响利润表（超过已计提部分补提减值损失）
- [ ] 核销的增值税处理（如涉及）是否正确

### 四、核销后续追踪与披露

- [ ] 已核销合同资产在法律上债权仍存在的，是否建立备查登记
- [ ] 是否存在已核销又收回的情况，收回是否重新入账
- [ ] 重大核销事项是否在附注中披露
- [ ] 核销是否与D6-note核销披露勾稽一致
- [ ] 是否评估核销责任（如涉及国有资产是否启动责任追究）
- [ ] 核销后是否放弃继续追偿，放弃是否有决策依据

## risk_areas

### 高风险

1. **虚假核销转移资产**：通过虚构核销依据核销可收回的合同资产，实为转移资产或核销后私下收款，属舞弊。
2. **核销未经审批**：合同资产核销未经适当层级审批或超权限核销，存在越权及合规风险。
3. **核销依据不足**：仅以账龄长为由核销，缺乏对方无法履约/付款的充分证据，可能虚减资产及利润。
4. **期末集中核销操纵利润**：期末集中核销以调节减值准备余额及当期利润，属会计估计操纵。
5. **核销后收回未入账**：已核销合同资产后续收回但未重新入账，形成账外资产及舞弊风险。

### 中风险

1. **核销金额与减值不匹配**：核销金额超过已计提减值准备但未补提减值损失，会计处理错误。
2. **核销与减值变动不勾稽**：核销金额与D6-3减值准备变动表本期核销栏不一致。
3. **备查登记缺失**：已核销但法律债权仍存在的合同资产未建立备查登记。
4. **披露不充分**：重大核销事项未在附注中充分披露。
5. **审批时点异常**：审批时点在核销入账之后，程序倒置。

### 低风险

1. **核销文档格式不规范**：核销审批单、依据文件格式等形式问题。
2. **催收记录不完整**：长期催收无果的催收记录记载不完整。
3. **责任追究信息缺失**：涉及国有资产核销未记录责任追究进展。
4. **交叉索引不完整**：与D6-3减值变动、D6-1审定表及附注披露的交叉引用标注不全。
