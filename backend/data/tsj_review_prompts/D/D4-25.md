# D4-25 经销商核查表复核提示词

## 概述

本提示词针对营业收入经销商核查表（D4-25）的复核，聚焦经销模式下的压货风险、期末压货冲收入、经销商真实性及终端动销情况。经销/买断模式下，向经销商发货即确认收入，但若经销商仅为渠道压货而终端未实现销售，则存在通过压货虚增收入、期后大额退货的风险。复核须穿透至终端动销，评估收入的真实性和可持续性。

**法规依据：**
- 《企业会计准则第14号——收入》（控制权转移、附退货权销售）
- 《中国注册会计师审计准则第1141号——财务报表审计中与舞弊相关的责任》
- 《中国注册会计师审计准则第1301号——审计证据》

## tips

1. **经销模式须判断控制权是否真正转移（CAS14）**：买断式经销通常在发货时确认收入，但须评估经销商是否承担存货风险、是否有退货权、是否受被审计单位控制，控制权未真正转移则不应确认收入。
2. **期末压货是经销模式收入操纵高危信号**：临近期末向经销商大量压货冲收入、次年初大额退货或销售折让，是典型的渠道塞货操纵，须结合终端动销和期后退货识别（CAS1141）。
3. **终端动销数据是收入真实性的终极验证**：向经销商的发货收入是否有终端零售/二次销售支撑，经销商库存是否合理，动销缓慢的大量渠道库存对应的收入质量存疑。
4. **经销商真实性须核查**：经销商是否真实独立、是否与被审计单位存在关联或受控关系、经销商是否有实际经营场所和终端销售能力，警惕虚构经销商或关联方伪装经销商。
5. **经销商退货率与返利政策分析**：经销商退货率异常、返利/折扣政策是否变相调节收入、经销商回款是否正常，均反映经销收入的真实性和质量。
6. **经销商期末库存与压货识别**：分析经销商期末库存水平、库存周转，识别是否存在期末突击压货导致渠道库存虚高、终端消化不良。

## checklist

### 一、经销模式与收入确认

- [ ] 经销合同性质是否明确（买断式/代销式）
- [ ] 收入确认时点是否符合控制权转移原则（CAS14）
- [ ] 经销商是否真正承担存货风险和价格风险
- [ ] 经销商是否有退货权，退货权对收入确认的影响是否评估
- [ ] 代销模式是否错误按买断确认收入
- [ ] 附退货权销售是否估计预期退货并作可变对价处理

### 二、经销商真实性

- [ ] 主要经销商是否核实真实性（工商信息/经营场所/经营能力）
- [ ] 经销商是否与被审计单位存在关联或受控关系
- [ ] 是否存在虚构经销商或关联方伪装经销商
- [ ] 新增大额经销商是否核查背景和交易合理性
- [ ] 经销商回款是否正常，是否存在长期挂账
- [ ] 是否存在多个经销商共用地址/联系方式/银行账户

### 三、压货与终端动销

- [ ] 期末是否存在向经销商集中压货冲收入的迹象
- [ ] 经销商期末库存水平是否合理，是否渠道库存虚高
- [ ] 是否获取终端动销数据验证发货收入的真实性
- [ ] 动销缓慢的渠道库存对应收入质量是否评估
- [ ] 经销商库存周转是否分析，异常缓慢是否已核查
- [ ] 期末压货收入是否追踪次年退货/折让/消化情况

### 四、退货返利与结论

- [ ] 经销商退货率是否分析，异常高企是否已调查
- [ ] 返利/折扣政策是否稳定，是否变相调节收入
- [ ] 期后经销商大额退货是否核查对本期收入的影响
- [ ] 经销收入是否与D4-20销售退回、D4-19折扣折让交叉印证
- [ ] 核查结论是否明确（收入真实/存在压货需关注/需调整）
- [ ] 底稿是否记录核查方法、终端数据来源及交叉索引

## risk_areas

### 高风险

1. **期末压货虚增收入**：临近期末向经销商大量压货冲收入，终端未实际销售，次年初大额退货，属渠道塞货式收入操纵（CAS1141）。
2. **控制权未转移仍确认收入**：代销模式或经销商未承担存货风险却按买断确认收入，收入确认时点错误。
3. **虚构/关联经销商**：经销商为虚构主体或关联方伪装，向其销售缺乏真实终端需求，收入真实性存疑。
4. **渠道库存虚高**：经销商渠道库存严重积压、动销停滞，对应收入质量差且面临大额退货风险。

### 中风险

1. **附退货权未作可变对价**：附退货权的经销销售未估计预期退货，收入虚增。
2. **经销商回款异常**：经销商回款长期挂账，实质为压货未消化或资金占用。
3. **退货率异常未调查**：经销商退货率显著高于正常水平但未分析原因。
4. **终端动销数据缺失**：未获取终端动销数据，发货收入真实性缺乏终端验证。

### 低风险

1. **经销商核查范围不足**：仅核查部分主要经销商，覆盖面不足。
2. **返利政策文档不完整**：经销返利/折扣政策未形成完整书面记录。
3. **交叉索引缺失**：与销售退回、折扣折让、存货、收入明细底稿的交叉引用不完整。
