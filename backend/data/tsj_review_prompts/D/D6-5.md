# D6-5 合同资产关联方检查表复核提示词

## 概述

本提示词针对合同资产关联方检查表（D6-5，科目码1402）的复核，聚焦四大核心审计要点：关联方识别完整性、关联方合同资产真实性、交易定价公允性、关联方减值与披露充分性。关联方合同资产因存在通过关联交易操纵履约进度、虚增收入及合同资产的风险，是合同资产审计的高风险领域。检查表须完整识别关联方、验证履约真实性、评估定价公允性并支持关联方披露。

**法规依据：**
- 《企业会计准则第36号——关联方披露》
- 《企业会计准则第14号——收入》
- 《中国注册会计师审计准则第1301号——审计证据》
- 《中国注册会计师审计准则第1550号——关联方》

---

## tips

1. **关联方识别完整性是检查的前提**：须核对关联方清单（B19/关联方登记）与合同资产明细（D6-2），确保所有关联方合同资产被识别，避免遗漏"隐性"关联方（同受控制、关键管理人员相关方等）。
2. **关联方履约真实性须重点验证**：关联方合同资产因缺乏独立第三方约束，存在虚构履约或提前确认履约进度的风险，须核对履约的客观证据（验收、里程碑等）。
3. **交易定价公允性影响收入及合同资产金额**：关联方合同定价是否公允直接影响按履约进度确认的收入及合同资产，须与市场价或独立交易价格比较。
4. **关联方合同资产的减值需独立评估**：关联方合同资产的可回收性与后续履约能力评估不应因关联关系而放松，需与D6-3/D6-8减值评估勾稽。
5. **CAS36要求关联方交易单独披露**：关联方合同资产须单独列示关联方名称、关系类型、交易金额、期末余额及减值，检查表是披露的支持底稿。
6. **关注跨底稿勾稽**：D6-5关联方合同资产 ↔ D6-2明细表关联方标志；关联方交易金额 ↔ 收入底稿关联方收入；关联方减值 ↔ D6-3/D6-8；披露 ↔ D6-note关联方披露。

## checklist

### 一、关联方识别完整性

- [ ] 关联方清单是否与关联方登记（B19）及集团架构一致
- [ ] 合同资产明细（D6-2）中关联方合同是否全部识别并标注
- [ ] 是否识别隐性关联方（同受控制、关键管理人员及其近亲属相关方）
- [ ] 关联关系类型是否准确判断（母子公司/同一控制/联营合营等）
- [ ] 是否存在通过第三方过桥掩盖关联关系的迹象
- [ ] 新增关联方合同资产是否有关联关系认定记录

### 二、关联方合同资产真实性

- [ ] 关联方合同是否有真实合同文本及履约义务约定
- [ ] 关联方合同的履约进度是否有客观第三方证据支持
- [ ] 是否存在向关联方虚构履约或提前确认履约进度的迹象
- [ ] 关联方合同资产余额与合同履约进度是否匹配
- [ ] 期末大额关联方合同资产是否核查后续履约及收款安排
- [ ] 是否存在期末突增关联方合同资产以虚增收入的情况

### 三、交易定价公允性

- [ ] 关联方合同定价方式是否披露（市场价/协议价/成本加成）
- [ ] 关联方合同定价是否与同类非关联交易价格比较且公允
- [ ] 是否存在通过关联方定价转移利润或虚增收入的情况
- [ ] 定价公允性的判断是否有支持性证据（价格清单、评估报告等）
- [ ] 关联方合同的信用/收款条件是否与非关联交易存在异常差异

### 四、关联方减值与披露充分性

- [ ] 关联方合同资产的减值评估是否独立进行（未因关联关系放松）
- [ ] 关联方合同资产减值是否与D6-3/D6-8勾稽一致
- [ ] 关联方名称、关系类型、交易金额、期末余额是否完整列示
- [ ] 关联方合同资产的账龄及后续履约状况是否分析
- [ ] 检查表数据是否支持附注关联方披露（D6-note）
- [ ] 是否存在资金性往来以合同资产名义挂账的情况

## risk_areas

### 高风险

1. **关联方虚构履约**：向关联方虚构合同或提前确认履约进度，虚增收入及合同资产，涉及舞弊风险。
2. **关联方未识别**：隐性关联方合同资产未识别或未标注，影响关联交易披露完整性及减值评估。
3. **定价不公允转移利润**：通过关联方合同定价虚增收入或转移利润，扭曲财务业绩。
4. **关联方合同资产减值不足**：因关联关系放松减值评估，掩盖关联方无力履约或付款的风险。
5. **资金占用挂账**：关联方资金占用以合同资产名义挂账，掩盖非经营性资金往来。

### 中风险

1. **关联关系判断错误**：关联关系类型判断错误，影响披露分类及豁免条款适用。
2. **披露不完整**：关联方合同资产未按CAS36完整列示名称、关系、金额、减值。
3. **履约证据不充分**：关联方合同履约进度缺乏客观第三方证据，真实性存疑。
4. **定价依据缺失**：关联方合同定价公允性未提供支持性证据。
5. **账龄分析缺失**：关联方合同资产账龄及后续履约状况未单独分析。

### 低风险

1. **格式不规范**：检查表格式、列序等形式问题。
2. **辅助信息不足**：关联方交易背景说明简略。
3. **交叉索引不完整**：与D6-2明细、D6-3减值、收入底稿及附注的交叉引用标注不全。
