# D4-note-listed 附注披露复核提示词（上市公司）

## 概述

本提示词针对营业收入上市公司附注披露底稿（D4-note-listed）的复核，聚焦上市公司财务报表附注中营业收入相关披露的充分性和准确性：收入分类披露（主营/其他业务）、按主要产品或服务类别的分解、按经营地区的分解、按收入确认时点（某一时点/某一时段）的分解、合同履约义务信息、以及与收入相关的合同资产合同负债披露。收入是报表使用者最关注的核心指标，CAS14及证监会编报规则对上市公司收入披露有细化要求，披露不充分将影响投资者对收入结构、质量和可持续性的判断。

**法规依据：**
- 《企业会计准则第14号——收入》（收入分解、履约义务、合同余额披露）
- 《企业会计准则第30号——财务报表列报》
- 《公开发行证券的公司信息披露编报规则第15号——财务报告的一般规定》
- 《中国注册会计师审计准则第1501号——对财务报表形成审计意见和出具审计报告》

## tips

1. **收入分解披露是CAS14的核心要求**：须按反映收入性质、金额、时间及不确定性的类别对收入进行分解披露（如按产品/服务类别、按经营地区、按确认时点），分解维度须与企业向管理层报告的口径一致。
2. **主营业务收入须按主要产品或服务分类**：上市公司须披露主营业务收入按主要产品/服务类别的构成及占比，各类别合计须等于主营业务收入总额，并与分部信息（如有）协调。
3. **按确认时点分解揭示收入模式**：须区分在某一时点确认的收入和在某一时段内确认的收入，帮助使用者理解收入确认模式和相关风险，两类合计须等于收入总额。
4. **合同履约义务信息须充分披露**：须披露履约义务的性质、履约时间、重大付款条件，以及分摊至剩余履约义务的交易价格（未来将确认的收入），这是CAS14区别于旧准则的重点披露。
5. **合同资产与合同负债须与收入勾稽**：合同负债（预收）的确认与结转、合同资产的形成，须与收入确认相互印证，期末合同负债余额变动应能解释收入的时间性差异。
6. **收入附注须与审定表/明细表/分部/关联交易多向勾稽**：附注收入总额须等于审定表审定数（6001+6051），分类小计须与明细表一致，关联方收入须与关联交易披露一致，各勾稽节点断裂均为复核重点。

## checklist

### 一、收入分类与总额勾稽

- [ ] 营业收入是否区分主营业务收入（6001）与其他业务收入（6051）披露
- [ ] 附注营业收入总额是否与审定表审定数一致
- [ ] 主营与其他业务收入合计是否等于营业收入总额
- [ ] 各类收入是否同时列示本期数和上期可比数
- [ ] 分类口径是否与会计政策及管理层报告口径一致
- [ ] 收入总额是否与利润表营业收入一致

### 二、按产品/服务与地区分解

- [ ] 主营业务收入是否按主要产品/服务类别分解披露
- [ ] 各产品/服务类别收入合计是否等于主营业务收入
- [ ] 是否按经营地区（境内/境外或具体区域）分解披露
- [ ] 各地区收入合计是否等于收入总额
- [ ] 分解维度是否反映收入的性质、金额、时间及不确定性（CAS14）
- [ ] 分解信息是否与分部报告（如有）协调一致
- [ ] 前五大客户收入及占比是否披露（编报规则要求）

### 三、按确认时点分解

- [ ] 收入是否按某一时点确认/某一时段确认分解披露
- [ ] 两类确认方式的收入合计是否等于收入总额
- [ ] 某一时段确认收入的进度计量方法是否披露
- [ ] 确认时点分解是否与收入确认会计政策一致
- [ ] 各主要业务的确认时点判断依据是否说明

### 四、履约义务与合同余额

- [ ] 是否披露履约义务的性质（商品/服务/时点/时段）
- [ ] 是否披露重大的付款条件、质保、退货等安排
- [ ] 是否披露分摊至剩余履约义务的交易价格（未来确认收入）
- [ ] 合同负债（预收）期初期末余额及变动是否披露
- [ ] 本期确认的、包含在期初合同负债中的收入是否披露
- [ ] 合同资产的形成与结转是否披露
- [ ] 合同资产/合同负债是否与收入确认相互勾稽

### 五、关联交易与其他披露

- [ ] 关联方收入是否与关联交易披露（CAS36）一致
- [ ] 收入中重大可变对价（折扣/返利/退货）估计方法是否披露
- [ ] 收入确认涉及的重大会计估计和判断是否披露
- [ ] 收入相关的重大合同变更是否披露
- [ ] 收入增长的驱动因素（如管理层讨论与分析衔接）是否有说明
- [ ] 其他业务收入的主要构成是否披露

## risk_areas

### 高风险

1. **收入分解披露缺失或不充分**：未按产品/服务、地区、确认时点分解披露收入，不满足CAS14收入分解强制要求，使用者无法评估收入结构和风险。
2. **附注收入总额与审定表不一致**：附注披露收入与审定表审定数（6001+6051）不一致，属数据勾稽重大错误。
3. **剩余履约义务信息未披露**：未披露分摊至剩余履约义务的交易价格，隐藏未来收入信息，不满足CAS14披露要求。
4. **合同负债与收入不勾稽**：合同负债变动与收入确认无法勾稽，可能掩盖跨期收入操纵或预收虚增。
5. **关联方收入披露遗漏**：附注收入分类未单独反映关联方收入，或与关联交易披露不一致，违反CAS36。

### 中风险

1. **确认时点分解口径不当**：某一时点/某一时段分解与收入确认政策不一致，或进度计量方法未披露。
2. **产品/服务分类不合理**：分解类别过粗或过细，未真实反映收入性质和风险差异。
3. **可变对价披露不足**：折扣/返利/退货等可变对价的估计方法未充分披露，影响收入质量判断。
4. **可比信息缺失**：附注仅列本期数据未列上期可比数据。
5. **前五大客户信息缺失**：未按编报规则披露前五大客户收入及占比，集中度信息不足。

### 低风险

1. **披露格式不完全规范**：表格标题、列序、金额单位等格式细节未严格按编报规则。
2. **文字描述模板化**：收入确认政策等描述照搬准则原文，未结合企业实际针对性说明。
3. **数字精度不一致**：不同披露表格金额精度不统一。
4. **分部协调说明不足**：收入分解与分部报告的对应关系未清晰说明。
