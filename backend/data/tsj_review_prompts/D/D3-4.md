# D3-4 分析表复核提示词

## 概述

本提示词针对预收账款/合同负债分析表（D3-4）的复核，聚焦四大核心审计要点：账龄分析、变动分析、与收入的勾稽分析、长期挂账占比分析。分析表通过实质性分析程序识别合同负债的异常波动和潜在错报风险，是判断收入确认合理性、长期挂账风险和持续经营影响的重要工具，其分析结论直接影响审计程序的方向和范围。

**法规依据：**
- 《企业会计准则第14号——收入》
- 《中国注册会计师审计准则第1301号——审计证据》
- 《中国注册会计师审计准则第1313号——分析程序》
- 《中国注册会计师审计准则第1141号——财务报表审计中与舞弊相关的责任》

## tips

1. **分析程序须建立合理预期**：合同负债的变动分析应建立在对被审计单位业务模式、销售政策、行业特点的了解之上，形成独立预期后与实际值对比，差异超阈值须调查。
2. **合同负债账龄结构揭示履约健康度**：账龄分析中长账龄占比上升通常意味着履约延迟或长期挂账风险，需结合履约进度判断是否应确认收入或退回。
3. **与收入的勾稽是识别收入操纵的关键**：合同负债本期减少额（结转部分）应与营业收入中来自期初合同负债的部分勾稽，异常的合同负债激增或骤降可能预示收入跨期操纵。
4. **长期挂账占比是持续经营与减值信号**：超过1年的合同负债占比过高，可能表明存在无法履约、应退款或已丧失商业实质的款项，需评估对财务报表的影响。
5. **变动分析须结合业务实质**：合同负债增减应与销售订单、预收政策变化、季节性因素相匹配，无业务支撑的异常变动是舞弊风险信号。
6. **关注比率与趋势的双维度异常**：合同负债/营业收入比率、合同负债周转天数、长账龄占比等指标的期间趋势和同行业对比，任一维度异常均为分析重点。

## checklist

### 一、账龄分析

- [ ] 合同负债账龄结构是否与D3-2明细表账龄分析一致
- [ ] 各账龄段占比较上期变动是否合理，异常变动是否已分析原因
- [ ] 1年以内合同负债占比是否符合业务正常履约周期
- [ ] 长账龄（1年以上）合同负债金额及占比是否单独列示并分析
- [ ] 账龄结构变化是否与销售模式、履约周期变化相匹配
- [ ] 是否存在账龄集中在特定客户或特定合同的情况

### 二、变动分析

- [ ] 合同负债期末较期初变动额及变动率是否计算正确
- [ ] 变动是否与营业收入变动、销售订单变化趋势相匹配
- [ ] 本期新增预收与本期结转收入的规模是否合理
- [ ] 变动是否存在季节性特征，是否与历史规律一致
- [ ] 重大变动（超过20%或重要性水平）是否已追溯至具体交易和原因
- [ ] 是否存在期末突增合同负债（可能为跨期调节收入）的迹象

### 三、与收入的勾稽分析

- [ ] 期初合同负债本期结转为收入的金额是否与D4收入底稿勾稽
- [ ] 合同负债/营业收入比率是否合理，与上期及同行业对比是否异常
- [ ] 合同负债周转天数是否符合业务特点
- [ ] 本期确认收入中来自合同负债的比例是否可追溯
- [ ] 是否存在收入确认与合同负债结转不匹配（少转或多转）的情况
- [ ] 期末合同负债余额与后续期间收入实现是否具有逻辑关联

### 四、长期挂账占比分析

- [ ] 超过1年的长期挂账合同负债占比是否计算并披露
- [ ] 长期挂账占比较上期是否异常上升，原因是否分析
- [ ] 长期挂账合同负债是否已在D3-5长期挂账检查表中逐笔评估
- [ ] 长期挂账是否评估应确认收入、应退回或应转营业外收入
- [ ] 长期挂账对流动比率、负债结构的影响是否分析
- [ ] 长期挂账是否存在无法履约或客户失联的情况

## risk_areas

### 高风险

1. **收入跨期操纵**：期末合同负债异常激增或骤降，与收入确认时点不匹配，可能为通过合同负债蓄水池调节利润。
2. **长期挂账占比异常上升**：超过1年的合同负债占比大幅上升但未评估处理，可能掩盖应确认收入或应退款项，构成收入或负债错报。
3. **合同负债与收入不勾稽**：合同负债结转金额与收入底稿数据无法勾稽，表明收入确认或负债结转存在系统性错误。
4. **无业务支撑的异常变动**：合同负债变动与销售订单、业务规模严重背离且无合理解释，是舞弊风险的强信号。

### 中风险

1. **账龄结构恶化未预警**：长账龄占比逐年上升但分析表未识别或未提示风险。
2. **比率异常未深究**：合同负债/收入比率、周转天数等指标异常但仅简单列示，未开展进一步调查。
3. **变动分析深度不足**：仅计算变动额和变动率，未结合业务实质分析变动合理性。
4. **同行业对比缺失**：未与同行业或历史趋势对比，无法判断合同负债规模的合理性。

### 低风险

1. **分析指标单一**：仅分析余额变动，未从周转率、占比、账龄多维度分析。
2. **预期建立不充分**：分析程序未事先建立独立预期，事后套用实际值。
3. **图表可视化缺失**：分析结论缺少趋势图、结构图辅助，影响复核直观性。
4. **交叉索引不完整**：分析表与明细表、收入底稿、长期挂账检查表的交叉引用标注不全。
