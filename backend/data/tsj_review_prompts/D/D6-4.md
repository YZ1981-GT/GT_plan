# D6-4 合同资产调整分录复核提示词

## 适用底稿
合同资产调整分录汇总表（D6-4，科目码1141），含账项调整（AJE）、重分类调整（RJE）及未调整错报（SUD）评估。

## 概述
D6-4 是合同资产审定数链路的关键环节。复核须验证：每笔调整有证据、借贷平衡、完整反映到 D6-1 审定表、SUD 评估符合重要性水平要求，并重点关注合同资产减值、合同资产转应收账款、履约进度修正等合同资产特有调整。

**法规依据：**
- 《企业会计准则第28号——会计政策、会计估计变更和差错更正》
- 《中国注册会计师审计准则第1301号——审计证据》
- 《中国注册会计师审计准则第1324号——持续经营》

## tips

1. **AJE vs RJE**：AJE 影响损益或资产金额（如合同资产减值、履约进度修正冲减收入）；RJE 仅影响列报（如合同资产转应收账款、流动/非流动重分类），不得通过 RJE 掩盖损益错报。
2. **与 D6-1 勾稽**：审定表调整列金额须与 D6-4 已确认分录逐笔一致，遗漏任一笔即审定数失真。
3. **合同资产转应收账款调整**：当收款权转为仅取决于时间流逝时的结转，属RJE性质，须核对结转时点判断是否恰当。
4. **减值调整勾稽**：合同资产减值调整须与 D6-3 减值准备变动及 D6-8 ECL 计算勾稽一致。
5. **SUD 累计**：未调整错报单独及累计是否超过整体/明显微小错报阈值，须与 A13 未调整错报汇总交叉验证。
6. **TB 回写**：确认调整已同步试算平衡表1141科目，避免「底稿已调、TB 未更」双真源。

## checklist

### 一、账项调整（AJE）检查项（高风险）

- [ ] 所有 AJE 是否有充分审计证据（减值测算、履约进度复核、管理层确认等）
- [ ] AJE 是否经适当层级审批（超重要性水平须合伙人知悉）
- [ ] 每笔调整分录借贷方是否完全平衡
- [ ] 合同资产减值计提AJE是否与D6-3/D6-8勾稽一致
- [ ] 履约进度修正导致的合同资产及收入调整是否有客观依据
- [ ] 调整金额是否完整反映到 D6-1 审定表对应调整列
- [ ] 是否存在仅为美化比率或规避业绩考核的不当调整

### 二、重分类调整（RJE）检查项（中风险）

- [ ] 合同资产转应收账款的RJE结转时点判断是否恰当（收款权是否已转为仅取决于时间）
- [ ] RJE 是否仅涉及列报，未影响损益类科目
- [ ] 流动/非流动重分类是否与预计收回时间及履约进度匹配
- [ ] 合同资产与合同负债按合同净额列示的重分类是否正确
- [ ] 与A13未调整错报汇总表索引是否完整
- [ ] 调整原因说明是否清晰可追溯至具体审计程序

### 三、未调整错报（SUD）与规范性检查项（低风险）

- [ ] 未调整错报累计是否超过整体重要性水平且仍出具无保留意见（须评估）
- [ ] 跨期调整是否正确区分本期错报与前期差错更正
- [ ] 建议调整与已执行调整是否区分记录
- [ ] 调整分录编号是否连续，删除后是否重号风险可控
- [ ] 分录摘要、科目编码是否规范
- [ ] 索引是否指向 D6-6 凭证检查、D6-8 ECL 等支持底稿

## risk_areas

### 高风险

1. **调整缺乏证据或未经授权**：合同资产减值或履约进度调整无充分证据或未经适当审批。
2. **审定表与D6-4调整金额不一致**：已确认调整未完整反映到审定表，导致审定数失真。
3. **减值调整与D6-3/D6-8不勾稽**：合同资产减值AJE与减值准备变动及ECL测算脱节。
4. **SUD累计超阈值未恰当处理**：未调整错报累计超过整体重要性水平仍出具无保留意见。

### 中风险

1. **RJE误含损益影响**：本应仅调列报的重分类分录误影响损益类科目。
2. **合同资产转应收账款时点错误**：结转时点判断不当导致列报错误或减值方法适用错误。
3. **跨期调整分类错误**：本期错报与前期差错更正未正确区分，会计处理及披露错误。

### 低风险

1. **编号、格式不规范**：分录编号、摘要、科目编码等格式问题。
2. **索引不完整**：与支持底稿的交叉索引标注不全。

## 跨底稿勾稽

- D6-4 已确认 AJE/RJE 合计 ↔ D6-1 审定表调整列
- D6-4 减值调整 ↔ D6-3 减值准备变动 ↔ D6-8 ECL 计算
- D6-4 SUD ↔ A13 未调整错报汇总
- 调整后审定数 ↔ 试算平衡表 1141 科目
