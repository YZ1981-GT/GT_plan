# D4-29 客户明细核查表复核提示词

## 概述

本提示词针对营业收入客户明细核查表（D4-29）的复核，聚焦客户基本信息完整性、工商信息核对、异常客户识别。客户明细是收入真实性核查的基础数据，通过对客户工商登记、经营状态、成立时间、注册资本、经营范围等信息的系统核对，识别虚构客户、空壳客户、异常客户，为收入真实性判断和函证走访对象选取提供依据。

**法规依据：**
- 《企业会计准则第14号——收入》
- 《中国注册会计师审计准则第1141号——财务报表审计中与舞弊相关的责任》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **客户明细是收入真实性核查的基础**：完整准确的客户信息（名称/统一社会信用代码/注册地/法人/成立时间/注册资本/经营范围/经营状态）是识别异常客户和虚构收入的起点。
2. **工商信息核对识别虚构与空壳客户**：通过企业信用信息公示系统核对客户真实存在、经营状态正常，警惕已注销/吊销/异常经营状态的客户仍发生大额交易。
3. **成立时间与交易规模的匹配性**：客户成立时间过短即发生大额交易、成立当年即成为大客户，是虚构客户或关联安排的信号，须重点核查。
4. **经营范围与交易内容的一致性**：客户经营范围应涵盖所购商品/服务，经营范围与采购内容明显不符（如贸易公司大额采购专业设备）须质疑交易真实性。
5. **异常客户特征系统识别**：注册资本过小却大额采购、注册地为住宅/异常地址、多客户共用信息、法人任职异常等，均为异常客户信号，须汇总标注。
6. **客户明细与收入/应收/函证勾稽**：客户明细须与收入明细客户、应收账款明细客户、函证走访清单一致，客户信息为后续函证走访对象核实提供支撑。

## checklist

### 一、客户基本信息完整性

- [ ] 客户名称是否规范完整，与合同/发票一致
- [ ] 统一社会信用代码是否记录完整
- [ ] 客户注册地、法人代表、联系方式是否记录
- [ ] 客户成立时间、注册资本是否记录
- [ ] 客户经营范围、经营状态是否记录
- [ ] 主要客户信息是否齐全，缺失项是否补充

### 二、工商信息核对

- [ ] 主要客户是否通过企业信用信息系统核对真实存在
- [ ] 客户经营状态是否正常（非注销/吊销/异常）
- [ ] 是否存在已注销/吊销客户仍发生交易的情况
- [ ] 客户工商登记信息是否与账面记录一致
- [ ] 客户是否被列入经营异常名录/失信名单
- [ ] 客户统一社会信用代码是否有效且唯一

### 三、异常客户识别

- [ ] 是否识别成立时间过短即大额交易的客户
- [ ] 是否识别注册资本过小却大额采购的客户
- [ ] 是否识别注册地为住宅/异常地址的客户
- [ ] 是否识别多客户共用地址/电话/邮箱/银行账户
- [ ] 客户经营范围是否与采购内容一致
- [ ] 是否识别法人/股东任职异常或关联迹象的客户
- [ ] 异常客户是否汇总标注并纳入重点核查

### 四、勾稽与运用

- [ ] 客户明细是否与收入明细客户勾稽一致
- [ ] 客户明细是否与应收账款明细客户勾稽一致
- [ ] 客户明细是否为函证走访对象选取提供依据
- [ ] 识别出的异常客户是否纳入函证走访必选样本
- [ ] 异常客户交易真实性是否进一步穿透核查
- [ ] 底稿是否记录核对方法、数据来源及交叉索引

## risk_areas

### 高风险

1. **虚构客户虚增收入**：向工商登记不存在、已注销吊销或空壳客户"销售"虚增收入，客户明细核对是识别虚构收入的第一道防线（CAS1141）。
2. **异常客户掩盖舞弊**：成立时间短即大额交易、注册资本过小却大额采购、住宅地址注册等异常客户，可能为虚构收入或关联安排的通道。
3. **多客户共用信息**：多个客户共用地址/电话/账户，提示可能为同一实际控制人操纵的虚假客户群。
4. **经营范围严重不符**：客户经营范围与采购内容明显矛盾，交易真实性和商业合理性存疑。

### 中风险

1. **客户信息不完整**：主要客户基本信息缺失，无法有效核对真实性和识别异常。
2. **工商核对不充分**：仅核对部分客户或未核对经营状态，虚构客户可能未被识别。
3. **异常客户未追查**：识别出异常客户但未进一步穿透核查交易真实性。
4. **客户明细与收入不勾稽**：客户明细与收入/应收明细客户不一致，数据基础存在缺陷。

### 低风险

1. **信息记录格式不规范**：客户信息记录格式不统一，影响汇总分析效率。
2. **核对范围有限**：仅核对大客户，中小客户工商信息未核对。
3. **交叉索引缺失**：与收入明细、应收账款明细、函证走访清单的交叉引用不完整。
