# D3-note-soe 附注披露复核提示词（国有企业）

## 概述

本提示词针对预收账款/合同负债国有企业附注披露底稿（D3-note-soe）的复核，聚焦国有企业特定的附注披露要求：国有资产监管相关披露、关联交易（含与政府/国有控股单位交易）、预算执行相关信息、国资委要求的补充披露事项，以及与上市公司版本的差异关注点。国有企业审计具有双重属性（财务审计+国有资产监管），合同负债披露须同时满足会计准则（CAS14）和国资监管要求，尤其关注长期挂账合同负债的资金占用实质。

**法规依据：**
- 《企业会计准则第14号——收入》
- 《企业会计准则第30号——财务报表列报》
- 《企业会计准则第36号——关联方披露》
- 《企业国有资产法》
- 《中央企业财务决算报告管理办法》

---

## tips

1. **国有企业附注有"双层"披露要求**：既要满足企业会计准则（CAS14）的通用披露要求，又要满足国资委财务决算报告的额外披露要求，两套要求互为补充、不可替代。
2. **关联方范围比一般企业更广**：国有企业的关联方除一般定义外，还需考虑同一国有控股股东控制/共同控制的其他国有企业（"同受国有控制"的关联方），关联方预收款须完整识别。
3. **长期挂账合同负债的资金占用视角**：国企长期挂账的预收款可能实质为其他国企或政府的资金占用/拆借，附注需说明其性质、形成原因和清理计划。
4. **预算执行视角是国企独有的关注点**：国企年度预算中通常包含预收款回收/结转目标，附注需说明实际执行与预算的偏差及原因。
5. **国有资产保值增值视角下的合同负债**：长期无法履约的合同负债若涉及应退国有资金或应确认收入，需评估对国有资本保值增值的影响。
6. **与上市版的差异主要在监管层面而非准则层面**：基础披露框架与上市版相同（分类/变动表/履约义务/含税列报），国企版额外增加国资监管相关信息，而非替代基础披露要求。

## checklist

### 一、基础披露完整性（与上市版共有）

- [ ] 合同负债是否按业务性质分类披露（预收货款/预收工程款/服务费/其他）
- [ ] 合同负债变动表是否完整（期初/新增/结转收入/退款/其他/期末）
- [ ] 是否披露分摊至剩余履约义务的交易价格及预计确认时间（CAS14）
- [ ] 附注合同负债总额是否与审定表审定数一致
- [ ] 各分类维度的小计是否与总额勾稽
- [ ] 期初数/期末数可比信息是否完整列示
- [ ] 含税预收款是否正确拆分列报

### 二、国有资产监管相关披露

- [ ] 1年以上长期挂账合同负债是否单独披露金额、客户及形成原因
- [ ] 长期挂账合同负债的清理/结转/退款计划是否披露
- [ ] 是否披露合同负债中属于财政性资金的部分（如政府预付工程款）
- [ ] 大额合同负债（超过单户限额标准）是否按国资委要求逐户披露
- [ ] 是否披露以预收名义存在的国有资金占用/拆借事项
- [ ] 长期挂账合同负债对流动负债结构和资产质量的影响是否说明

### 三、关联交易披露（国企特定）

- [ ] 与控股股东及其关联企业的合同负债是否逐户列示
- [ ] 与同一母公司控制的其他国有企业的预收款是否披露
- [ ] 是否运用了"同受国家控制"关联方的豁免条款，如运用是否符合条件
- [ ] 关联方合同负债的交易实质是否清晰说明（经营性/资金性）
- [ ] 关联方交易定价方式是否披露（市场价/协议价/政府定价）
- [ ] 是否存在大额资金往来被以合同负债名义挂账的情况并予以说明
- [ ] 与政府部门的预收款（专项资金/补贴预付）是否单独列示

### 四、预算执行相关披露

- [ ] 本期预收款实际结转/回收额与年度预算目标的对比是否披露
- [ ] 预算偏差超过一定比例（如20%）时是否说明原因
- [ ] 新增大额预收款是否属于预算内业务
- [ ] 期末合同负债余额是否超出年度资产负债预算
- [ ] 长期挂账合同负债的清理是否纳入年度经营目标考核

### 五、国资委要求的补充披露

- [ ] 长期挂账无法履约的合同负债处理（退款/转营业外收入）是否披露决策程序
- [ ] 涉及国有资金退回的重大事项是否经"三重一大"决策程序
- [ ] 合同负债中涉及法律诉讼/仲裁的金额及进展是否披露
- [ ] 是否编制长期挂账合同负债清理处置方案并披露执行情况
- [ ] 以预收名义对外提供资金是否按国资委要求单独披露

### 六、与上市版的差异关注点

- [ ] 国企版是否在上市版基础披露的基础上增加了国资监管层面的补充信息
- [ ] 关联方范围是否已扩展至"同受国有控制"的企业
- [ ] 长期挂账处理是否增加了"三重一大"决策程序的说明
- [ ] 是否增加了预算执行偏差分析
- [ ] 是否增加了长期挂账合同负债的清理/处置/责任追究信息
- [ ] 是否增加了国有资本保值增值相关影响分析

## risk_areas

### 高风险

1. **长期挂账未按国资要求披露**：1年以上合同负债未逐户说明原因和清理计划，可能掩盖资金占用或国有资产流失。
2. **资金占用伪装预收**：以合同负债名义存在的其他国企或政府资金占用未单独披露，违反国资委要求。
3. **关联方合同负债范围遗漏**：未将同一国有控股股东下的兄弟单位纳入关联方披露范围，违反CAS36和国资委要求。
4. **应确认收入/应退款项处理缺程序**：长期挂账合同负债转营业外收入或退款未经集体决策或未披露决策过程，存在合规风险。
5. **基础披露与审定表不勾稽**：附注合同负债各维度合计与审定表审定数不一致，属重大数据错误。

### 中风险

1. **预算执行偏差未充分说明**：预收款结转/回收远低于年度预算目标但未说明原因和改进措施。
2. **"同受国有控制"豁免条款适用不当**：不符合豁免条件却简化了同受国家控制关联方的披露。
3. **长期挂账清理信息缺失**：长期挂账合同负债未说明清理处置方案及执行进展。
4. **决算报表与审计报表口径差异未调节**：财务决算数据与审计后附注数据存在差异但未编制调节说明。
5. **履约义务披露不充分**：未按CAS14披露剩余履约义务交易价格及预计确认时间。

### 低风险

1. **披露格式未完全按决算报表模板**：附注格式与国资委决算报表模板有细微差异，但信息内容完整。
2. **资金占用说明过于简略**：关联方或政府资金占用已披露但形成原因未详细说明。
3. **预算对比分析维度单一**：仅对比余额未对比结转率/周转率等多维度指标。
4. **历史年度信息追溯不完整**：合同负债增减变动的历史趋势分析仅覆盖2年而非国资委建议的3年。
