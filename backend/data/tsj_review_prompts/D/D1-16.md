# D1-16 核销检查表复核提示词

## 概述

本提示词针对应收票据核销检查表（D1-16）的复核，聚焦四大核心审计要点：核销依据充分性、核销审批程序合规性、核销会计处理正确性、后续追偿与再确认。应收票据核销通常源于承兑人违约且无法收回（尤其商业承兑汇票），核销直接减少资产并冲减已计提减值准备，是舞弊（掩盖资金挪用、清理虚构资产）和利润操纵的高风险环节，须核查核销依据的真实性和审批的完整性。

**法规依据：**
- 《企业会计准则第22号——金融工具确认和计量》
- 《中国注册会计师审计准则第1301号——审计证据》
- 《中国注册会计师审计准则第1141号——财务报表审计中与舞弊相关的责任》

---

## tips

1. **核销依据须真实充分**：票据核销须有承兑人破产清算、法院终止执行、协商无果、追索时效届满等确凿证据，仅凭管理层判断"无法收回"不足以支持核销，须防范以核销掩盖资产挪用或虚构资产清理。
2. **核销须经适当审批**：核销须经董事会/管理层按权限审批，重大核销（超过一定金额）须经更高层级或"三重一大"决策，审批程序缺失是重大内控缺陷。
3. **核销会计处理须正确**：核销应冲减已计提的减值准备（借：减值准备，贷：应收票据），减值准备不足的差额计入当期信用减值损失，处理方向和金额须准确。
4. **核销不解除追偿义务**：已核销票据仍应保留备查登记并继续追偿，核销仅是会计上的处理，不代表放弃债权，须核查是否继续追偿。
5. **已核销后收回须再确认**：已核销票据后续收回的，应重新确认并计入当期损益，须核查是否存在核销后收回未入账（体外循环）的情况。
6. **关注核销的关联方与舞弊迹象**：向关联方票据核销、核销后资产流向异常、集中核销粉饰资产质量等，须保持职业怀疑并追查资金/资产去向。

## checklist

### 一、核销依据充分性

- [ ] 【必检】每笔核销是否有确凿的无法收回证据（破产/法院文书/追索时效届满等）
- [ ] 【必检】核销依据是否真实有效（防伪造证据）
- [ ] 【必检】核销票据的承兑人违约事实是否核实
- [ ] 【条件检查：若为商业承兑汇票】承兑人及出票人（追索链）是否均无法追偿
- [ ] 【风险检查】是否存在依据不充分即核销（掩盖挪用/虚构资产）

### 二、核销审批程序合规性

- [ ] 【必检】核销是否经适当层级按权限审批
- [ ] 【必检】重大核销是否经董事会/更高层级或"三重一大"决策
- [ ] 【必检】审批文件是否完整留存
- [ ] 【风险检查】是否存在越权审批或审批程序缺失

### 三、核销会计处理正确性

- [ ] 【必检】核销是否正确冲减已计提减值准备
- [ ] 【必检】减值准备不足的差额是否计入当期信用减值损失
- [ ] 【必检】核销金额、方向是否准确
- [ ] 【必检】核销是否与 D1-1 审定表、D1-4 坏账准备、D1-15 ECL 勾稽
- [ ] 【风险检查】是否通过核销调节减值准备余额或利润

### 四、后续追偿与再确认

- [ ] 【必检】已核销票据是否保留备查登记并继续追偿
- [ ] 【必检】已核销后收回的票据是否重新确认计入当期损益
- [ ] 【条件检查：若核销后有收回】收回是否入账（防体外循环）
- [ ] 【风险检查】核销后资产/资金流向是否异常

## risk_areas

### 高风险

1. **核销掩盖资产挪用/虚构**：以"无法收回"名义核销实际被挪用或本不存在的票据，掩盖舞弊。
2. **依据不充分核销**：缺乏确凿证据即核销，或伪造破产/法院文书支持核销。
3. **越权/无审批核销**：重大核销未经适当审批或"三重一大"决策，重大内控缺陷。
4. **核销后收回体外循环**：已核销票据后续收回未重新入账，资金流入账外。
5. **关联方核销利益输送**：向关联方票据核销，实质放弃债权向关联方输送利益。

### 中风险

1. **会计处理错误**：核销冲减方向/金额错误，减值准备不足差额未计入损失。
2. **追偿义务放弃**：核销后未保留备查、未继续追偿。
3. **核销调节利润**：通过核销时点/金额调节减值准备和当期利润。
4. **勾稽不完整**：核销与审定表、坏账准备、ECL 勾稽存在差异。

### 低风险

1. **审批文档留存不全**：核销审批文件保管不完整。
2. **备查登记不规范**：已核销票据备查登记格式不统一。
3. **索引不完整**：与审定表、坏账准备、ECL 底稿的索引不全。
