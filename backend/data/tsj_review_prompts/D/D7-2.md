# D7-2 合同负债明细表复核提示词

## 概述

本提示词针对合同负债明细表（D7-2，科目码2205）的复核，聚焦四大核心审计要点：客户/合同信息完整性、余额准确性、账龄分析正确性、待履约义务合理性。明细表是合同负债科目审计的基础数据底稿，承载按客户/合同维度的余额明细、账龄分布及待履约义务，其数据质量直接影响完整性核查、长期挂账分析（D7-5）、收入确认时点评估等后续审计程序的有效性。合同负债作为负债科目，明细完整性尤为关键。

**法规依据：**
- 《企业会计准则第14号——收入》
- 《企业会计准则第37号——金融工具列报》
- 《中国注册会计师审计准则第1301号——审计证据》
- 《中国注册会计师审计准则第1502号——对特殊项目审计证据的进一步考虑》

## tips

1. **合同/客户信息完整性是明细表质量的基石**：每一行合同负债记录须具备完整识别信息（合同编号、客户名称、待履约义务、关联方标志等），空白或笼统归集可能掩盖漏记负债或分类错误。
2. **余额准确性的核心是勾稽关系**：明细账合计必须与审定表D7-1期末审定数完全一致，期初余额必须与上年审定数衔接，任何差异需追溯至具体调整分录。
3. **完整性是合同负债明细的核心关注**：须核对所有已收预收款/已开票未履约的合同是否完整反映在明细表，防止已收对价却未确认合同负债（漏记负债虚增收入）。
4. **账龄分析驱动长期挂账判断**：合同负债账龄（自收款/确认日起算）划分标准须与会计政策一致，长账龄合同负债需评估待履约义务能否完成、是否应确认收入、是否应退回。
5. **待履约义务是收入确认时点的判断基础**：明细表中待履约义务的性质及完成情况决定合同负债何时结转收入，须核对履约义务描述与合同一致。
6. **关注明细与汇总的双向勾稽**：各合同期末余额合计 = D7-1审定数；各合同余额 ↔ 已收对价减已确认收入；各账龄段合计 = D7-4账龄分析；长账龄合同负债 ↔ D7-5长期挂账检查；关联方合同负债 ↔ D7-6关联方检查。

## checklist

### 一、客户/合同信息完整性

- [ ] 合同编号、客户名称是否完整规范，无空白或笼统归集
- [ ] 是否标注关联方客户，关联方合同负债是否全部识别（与D7-6勾稽）
- [ ] 待履约义务及履约安排是否清晰记录
- [ ] 合同清单是否与合同管理系统或ERP销售数据一致
- [ ] 是否核对所有已收预收款/已开票未履约合同均已确认合同负债
- [ ] 是否存在已收对价却未确认合同负债（漏记负债虚增收入）的迹象

### 二、余额准确性

- [ ] 明细表各合同期末余额合计是否与总账/审定表D7-1一致
- [ ] 明细表期初余额是否与上年审定期末数衔接
- [ ] 各合同余额计算是否正确（期初 + 本期新增预收 − 本期确认收入结转 = 期末）
- [ ] 合同负债数据是否直接从系统导出，未经不当人工调整
- [ ] 本期确认收入结转（借方）是否与收入确认底稿勾稽
- [ ] 是否存在余额异常波动（超过30%且无合理解释）

### 三、账龄分析正确性

- [ ] 账龄划分标准是否与公司会计政策一致（1年以内/1-2年/2-3年/3年以上）
- [ ] 各合同各账龄段金额之和是否等于该合同余额
- [ ] 全部合同各账龄段合计是否与账龄分析表（D7-4）一致
- [ ] 账龄起算日是否以收款日/合同负债确认日为准，标准是否统一
- [ ] 长账龄（1年以上/2年以上）合同负债是否逐项标注原因及待履约状况
- [ ] 是否存在长期挂账合同负债应确认收入却未及时结转的迹象

### 四、待履约义务合理性

- [ ] 待履约义务描述是否与合同约定一致
- [ ] 待履约义务是否真实存在（未履约的部分是否有对应义务）
- [ ] 已履约完毕的合同负债是否已及时结转收入
- [ ] 待履约义务的完成时间预计是否合理（影响流动性分类）
- [ ] 是否存在履约义务已消失（如客户放弃）但仍挂账合同负债的情况
- [ ] 待履约义务金额与合同负债余额是否匹配

## risk_areas

### 高风险

1. **漏记合同负债虚增收入**：已收对价却未确认合同负债或提前结转收入，导致负债低估、收入虚增，涉及完整性认定。
2. **长期挂账应确认收入未结转**：履约义务已完成的合同负债长期挂账未结转收入，或反之提前结转，操纵收入确认时点。
3. **余额与总账不一致**：明细合计数与审定表/总账存在差异未调节，表明可能存在遗漏或错误记录。
4. **待履约义务虚构**：合同负债对应的待履约义务实际已消失或从未存在，掩盖应确认的收入或应退款项。
5. **关联方合同负债未识别**：明细表中关联方合同负债未标注或遗漏，影响关联交易披露完整性。

### 中风险

1. **账龄人为操纵**：通过滚动收款或调整确认日人为改变账龄分布，掩盖长期挂账。
2. **合同信息不完整**：部分合同缺少待履约义务、履约安排等关键信息，影响收入确认时点判断。
3. **合同负债与预收账款混淆**：CAS14下应确认为合同负债的预收款仍列示为预收账款。
4. **结转收入与履约进度不匹配**：本期确认收入结转金额与实际履约进度不匹配。
5. **流动性分类不当**：长期限合同负债仍分类为流动负债。

### 低风险

1. **格式规范性问题**：明细表格式不统一、排列顺序不规范等形式问题。
2. **辅助信息缺失**：缺少合同行业分类、地区分布等辅助分析信息。
3. **小额合同归集**：小额合同归集为"其他"时未附明细清单。
4. **交叉索引不完整**：与账龄分析、长期挂账检查、收入底稿的交叉引用标注不全。
