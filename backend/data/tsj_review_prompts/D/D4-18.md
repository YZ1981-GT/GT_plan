# D4-18 收入后向截止测试表复核提示词

## 概述

本提示词针对营业收入后向截止测试表（D4-18）的复核。后向截止测试从原始单据出发正向追查记账（发货单/验收单/出库单→记账凭证），验证资产负债表日前后已发生的销售业务是否在正确会计期间确认收入，重点防范漏记收入（跨期至次年）和推迟确认收入。后向测试对应收入的完整性认定，与前向测试的存在/发生认定形成方向互补，是收入截止审计不可或缺的一环。

**法规依据：**
- 《企业会计准则第14号——收入》
- 《中国注册会计师审计准则第1141号——财务报表审计中与舞弊相关的责任》
- 《中国注册会计师审计准则第1231号——针对评估的重大错报风险采取的应对措施》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **后向测试的方向是"从单到账"**：以资产负债表日前后的发货单、出库单、验收单为起点，正向追查是否已及时确认收入并记账，重点识别货已发而账未记的漏记/推迟确认。
2. **后向测试对应完整性认定**：与前向测试查"多记/提前"相反，后向测试查"少记/漏记/推迟"，防范企业将本期收入推迟至次年以平滑利润或规避业绩超预期。
3. **发货台账/出库记录的完整性是测试基础**：须确认发货记录来源完整（仓库出库系统、物流签收台账），避免以已开票记录为总体导致漏记交易根本不进入测试范围。
4. **期末已发货未开票是后向测试的核心关注点**：期末前已完成控制权转移但尚未开票或未记账的交易，须评估是否应在本期确认收入（CAS14控制权转移原则）。
5. **推迟确认可能配合次年业绩需要**：识别出的推迟收入须结合次年初收入激增、次年业绩目标等背景评估管理层是否存在跨期操纵动机（CAS1141）。
6. **后向测试与存货截止、发出商品勾稽**：期末已发货未确认收入的交易，对应存货应转出或列示为发出商品，须与存货截止测试结果交叉核对，避免收入与成本截止不一致。

## checklist

### 一、测试范围与总体完整性

- [ ] 后向测试是否以发货单/出库单/验收单等原始单据为选取总体（后向方向正确）
- [ ] 测试窗口是否覆盖资产负债表日前后合理天数
- [ ] 发货/出库记录来源是否完整（仓储系统、物流台账），非仅取已开票记录
- [ ] 期末前最后几天的发货记录是否全部纳入测试范围
- [ ] 大额发货/高风险客户发货是否重点覆盖
- [ ] 主营业务与其他业务的发货记录是否均纳入测试

### 二、单据到记账的追查

- [ ] 每笔期末前发货是否追查到对应的收入确认凭证
- [ ] 发货日在期末前的交易是否已在本期确认收入（防漏记）
- [ ] 是否存在货已发出、控制权已转移但收入未确认的情况
- [ ] 记账日期是否与发货/验收日期在合理期间内
- [ ] 是否存在期末已发货但推迟至次年确认收入的交易
- [ ] 原始单据（发货/物流签收/验收）与记账凭证是否相互印证

### 三、跨期与勾稽

- [ ] 识别出的漏记/推迟收入是否逐笔标注并汇总金额
- [ ] 期末已发货未确认收入的交易是否与存货截止测试交叉核对
- [ ] 期末已发货未开票交易的成本是否已同步处理（收入成本配比）
- [ ] 推迟确认的收入是否核查次年初确认情况及背景动机
- [ ] 跨期金额是否评估对本期收入、利润及完整性认定的影响
- [ ] 后向测试结果是否与前向测试（D4-17）交叉印证

### 四、结论与调整

- [ ] 截止测试结论是否明确（收入完整无漏记/存在漏记需调整）
- [ ] 需调整的漏记收入是否形成调整分录建议并计算金额影响
- [ ] 重大漏记错报是否评估累计影响并与重要性水平对比
- [ ] 底稿是否记录测试方法、总体来源、窗口天数、样本依据及结论
- [ ] 交叉索引是否完整（收入审定表、发货台账、存货截止、次年序时账）

## risk_areas

### 高风险

1. **漏记收入平滑利润**：期末已发货、控制权已转移的销售未确认收入，推迟至次年入账以平滑或压低本期利润，违反收入完整性和CAS14控制权转移原则。
2. **发货总体不完整导致漏检**：以已开票记录而非仓储出库台账作为测试总体，漏记交易根本不进入测试范围，测试失效。
3. **收入成本截止不一致**：期末已发货未确认收入的交易，成本已结转或存货已转出，导致收入与成本截止口径不匹配，扭曲毛利。
4. **推迟确认配合跨期操纵**：将临近期末的大额收入系统性推迟确认，配合次年业绩需要，属跨期利润操纵（CAS1141）。

### 中风险

1. **测试窗口过窄漏检**：后向测试窗口天数不足，窗口边界外的跨期发货未被捕获。
2. **前后向未交叉印证**：后向测试与前向测试、存货截止测试结果未相互印证，结论孤立。
3. **已发货未开票判断不当**：对期末已发货未开票交易简单不确认收入，未评估控制权是否已转移。
4. **跨期金额未汇总评估**：识别漏记交易但未汇总计算对完整性认定的影响。

### 低风险

1. **底稿记录不完整**：总体来源、窗口天数、样本选取依据未充分记录。
2. **交叉索引缺失**：与收入审定表、发货台账、存货截止底稿的交叉引用不完整。
3. **核对痕迹不清**：单据追查记账的勾稽标记不清晰，复核难以还原。
