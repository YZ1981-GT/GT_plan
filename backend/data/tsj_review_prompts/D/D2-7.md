# D2-7 凭证检查复核提示词

## 适用底稿
应收账款凭证检查表（D2-7），聚焦样本选取方法合理性、凭证核对完整性、检查比例达标性、异常交易标注充分性。

## tips

- 样本选取方法应与风险评估结果匹配，高风险领域采用更严格的抽样策略
- 凭证核对须覆盖完整交易链条（合同→订单→发货→验收→开票→收款）
- 检查比例应满足《中国注册会计师审计准则第1314号——审计抽样》要求
- 异常交易标注需明确异常类型（金额异常/时间异常/对手方异常/业务逻辑异常）
- 关注期末集中确认收入、大额现金交易、关联方交易等高风险凭证
- 函证样本选取应金额重大项目全覆盖，其余项目合理抽样（CAS1314）
- 未回函项目须实施替代程序，回函差异须调查解释
- 职业怀疑贯穿始终：对管理层重大判断保持警觉，记录质疑过程和替代方案

## checklist

### 高风险检查项

- [ ] 样本选取方法是否与识别的重大错报风险相匹配
- [ ] 抽样方法是否符合CAS1314要求（统计抽样/非统计抽样选择有据）
- [ ] 金额重大项目（超过重要性水平）是否100%全覆盖检查
- [ ] 高风险客户（新客户/长账龄/关联方/大额变动）是否纳入必选样本
- [ ] MUS抽样间隔是否基于可容忍错报和总体规模正确计算
- [ ] 凭证核对是否覆盖完整交易链（合同-订单-发货/验收-开票-收款）
- [ ] 原始单据是否齐全（销售合同/发货单/验收单/发票/银行回单）
- [ ] 异常交易是否全部标注并记录异常类型和初步判断
- [ ] 期末突增的应收账款对应凭证是否重点核查
- [ ] 是否存在无实际业务支持的往来款项凭证

### 中风险检查项

- [ ] 抽样总体是否完整（是否排除了不应排除的项目）
- [ ] 样本量是否满足审计目标所需的置信水平
- [ ] 分层抽样的分层标准是否合理（按金额/客户类型/账龄）
- [ ] 检查比例（已检查金额/总体金额）是否达到计划水平
- [ ] 借方发生额检查比例是否达标（本期新增应收）
- [ ] 贷方发生额检查比例是否达标（本期收回/核销）
- [ ] 期后收款测试是否有效执行并记录
- [ ] 销售退回/折扣/折让凭证是否有合理依据和授权审批
- [ ] 凭证日期与记账日期是否一致，是否存在跨期记录
- [ ] 核对过程中发现的差异是否逐一追踪解决

### 低风险检查项

- [ ] 抽样工作底稿是否完整记录抽样参数（总体/置信水平/可容忍偏差/预计偏差）
- [ ] 样本选取过程是否可追溯（随机数种子/系统抽样间隔/选取依据）
- [ ] 凭证检查结果记录格式是否规范统一
- [ ] 检查比例计算公式是否正确（分子=已检查金额，分母=总体金额）
- [ ] 底稿索引与交叉引用是否完整（关联审定表/明细表/函证底稿）

## risk_areas

### 高风险

- **样本选取偏差风险**：抽样方法不当（如仅选取整数金额/特定客户）导致样本不具代表性，未能覆盖重大错报风险领域
- **凭证造假风险**：虚构销售凭证（伪造合同/发货单/验收单）掩盖虚增收入，需交叉核对多方原始单据
- **截止性错误风险**：期末集中确认收入的凭证未实施截止测试，跨期交易未被识别和标注
- **关联方交易隐匿风险**：关联方凭证混入普通客户样本，未实施针对性的公允性核查程序
- **异常交易遗漏风险**：金额异常（如整数金额/恰好低于审批权限）、时间异常（节假日/非工作时间）的交易未被标注

### 中风险

- **检查比例不足风险**：实际检查比例低于计划水平，导致审计证据不充分，无法支持审计结论
- **替代程序不充分风险**：未回函项目的替代程序（期后收款/发货单据/验收单据核对）执行不到位
- **分层不合理风险**：抽样分层标准未体现风险差异，低风险层占用过多检查资源而高风险层覆盖不足
- **核对深度不够风险**：仅核对金额一致性而忽略交易实质（如合同条款/发货时间/验收条件是否匹配）

### 低风险

- **记录不完整风险**：抽样参数/选取过程/核对结果的工作底稿记录不完整，影响复核可追溯性
- **索引缺失风险**：凭证检查底稿与审定表/明细表/函证底稿的交叉索引不完整
- **格式不规范风险**：检查结果记录格式不统一，影响汇总分析效率

## 法规依据

- 《中国注册会计师审计准则第1314号——审计抽样》：抽样设计、执行与评价
- 《中国注册会计师审计准则第1301号——审计证据》：证据充分性与适当性
- 《中国注册会计师审计准则第1141号——财务报表审计中与舞弊相关的责任》：舞弊风险凭证核查
- 《中国注册会计师审计准则第1211号——通过了解被审计单位及其环境识别和评估重大错报风险》：风险导向抽样
- 《中国注册会计师审计准则第1504号——在审计财务报表时对舞弊的考虑》：凭证异常识别

## 关注场景

### 样本选取方法合理性
1. 确认抽样方法选择依据（统计抽样适用于大量同质交易；非统计抽样适用于异质性高/项目少的场景）
2. 核实必选样本是否涵盖：金额超重要性水平项目、高风险客户（新客户/关联方/长账龄）、期末异常变动项目
3. 验证MUS/系统抽样的间隔计算：间隔 = 可容忍错报 ÷ 风险系数（查泊松表）
4. 检查总体完整性：是否从完整的序时账/明细账导出，未人为排除项目
5. 评估分层标准合理性：按金额分层（大额全查/中额系统抽样/小额随机抽样）

### 凭证核对完整性
1. 核对链条五要素：合同（签订日期/条款/金额）→ 发货（发货日期/数量/签收）→ 发票（开票日期/金额/税率）→ 记账（记账日期/分录）→ 收款（到账日期/金额/对方户名）
2. 异常核对结果分类：金额不一致/日期不匹配/缺少原始单据/签章不完整/对方单位名称不一致
3. 期后收款核对：检查资产负债表日后实际回款情况，验证余额存在性
4. 替代程序执行：未回函客户须核对发货单+验收单+期后收款，三者中至少两项一致

### 检查比例达标性
1. 计算总体检查比例：已检查样本金额 ÷ 应收账款总体金额 × 100%
2. 分方向检查比例：借方（本期新增）检查比例 + 贷方（本期收回/核销）检查比例分别计算
3. 对照计划比例：实际比例 ≥ 计划比例为达标；不达标须说明原因并评估是否需补充样本
4. 区分不同风险层的检查比例：高风险层 ≥ 80%、中风险层 ≥ 50%、低风险层 ≥ 20%（参考值）

### 异常交易标注充分性
1. 金额异常判断标准：整数金额/恰好低于审批权限/与历史交易偏差超30%/单笔超重要性水平
2. 时间异常判断标准：非工作时间交易/节假日交易/期末最后3天集中入账/基准日前后异常波动
3. 对手方异常判断标准：新客户首笔大额/客户地址为住宅/多个客户同一联系方式或银行账户
4. 业务逻辑异常：发货在合同签订前/收入确认在发货前/退货比例异常/信用期外长期挂账不催收
5. 标注要素：异常类型 + 异常描述 + 涉及金额 + 初步判断（合理解释/需进一步调查/疑似错报）
