# D4-17 收入前向截止测试表复核提示词

## 概述

本提示词针对营业收入前向截止测试表（D4-17）的复核。前向截止测试从记账日出发反向追查原始单据（记账凭证→发货单/验收单/发票），验证资产负债表日前后一定期间内已确认收入是否在正确会计期间入账，重点防范提前确认收入（虚增本期业绩）和推迟确认收入（平滑利润）。收入截止是营业收入审计中舞弊风险最高的领域，属重大错报风险重点应对环节。

**法规依据：**
- 《企业会计准则第14号——收入》（控制权转移时点确认收入）
- 《中国注册会计师审计准则第1141号——财务报表审计中与舞弊相关的责任》
- 《中国注册会计师审计准则第1231号——针对评估的重大错报风险采取的应对措施》
- 《中国注册会计师审计准则第1211号——通过了解被审计单位及其环境识别和评估重大错报风险》

## tips

1. **前向测试的方向是"从账到单"**：以资产负债表日前后已入账的收入凭证为起点，反向追查发货单、验收单、物流签收记录，验证控制权转移时点是否落在正确会计期间，重点识别账已记而货未发的提前确认。
2. **测试窗口须覆盖资产负债表日前后足够天数**：一般取期末前后各5-10天（视客户业务性质和舞弊风险调整），高风险企业或期末收入异常集中的应扩大窗口，确保跨期交易被充分捕获。
3. **控制权转移时点是判断收入归属期的核心依据（CAS14）**：须依据合同约定的交货条款（EXW/FOB/CIF/送达验收）确定控制权转移日，而非简单以开票日或发货日为准，条款不同则截止判断结论不同。
4. **期末最后几天集中确认的大额收入是舞弊高危信号**：临近期末突击开票、突击发货、突击签订合同的交易须逐笔核查业务真实性，警惕为达成业绩目标而提前确认收入（CAS1141）。
5. **前向与后向测试互为补充不可偏废**：前向测试查提前/多记（存在与发生认定），后向测试查漏记/少记（完整性认定），两者方向相反，复核时须确认前向测试确已覆盖记账日在期末前的凭证样本。
6. **跨期交易须追踪至次年冲回或结转情况**：识别出的疑似跨期收入须核对次年初是否存在异常退货、红字冲销或收入结转，验证本期确认的合理性。

## checklist

### 一、测试范围与样本选取

- [ ] 前向测试窗口是否覆盖资产负债表日前后合理天数（前后各5-10天或更宽）
- [ ] 测试样本是否以记账日在窗口内的收入凭证为选取起点（前向方向正确）
- [ ] 期末最后3-5天确认的大额收入是否全部纳入必测样本
- [ ] 高风险客户（新客户/关联方/大额突增）的期末收入是否重点覆盖
- [ ] 样本选取是否兼顾主营业务收入（6001）与其他业务收入（6051）
- [ ] 抽样比例与金额覆盖率是否满足审计目标与舞弊风险应对要求

### 二、控制权转移时点核对

- [ ] 每笔样本是否核对合同交货条款以确定控制权转移时点（CAS14）
- [ ] 记账日与发货日/验收日/物流签收日是否一致或在合理期间内
- [ ] 是否存在记账已确认收入但货物尚未发出的情况（提前确认）
- [ ] 是否存在验收条款未满足即确认收入的情况（如需安装调试验收）
- [ ] 原始单据（发货单/出库单/物流签收/验收单/发票）是否齐全并相互印证
- [ ] 单据日期链条是否逻辑合理（合同→发货→签收→开票→记账）

### 三、跨期与异常识别

- [ ] 是否识别出记账期与控制权转移期不一致的跨期交易并逐笔标注
- [ ] 期末集中确认的大额收入是否核查了业务真实性和商业合理性
- [ ] 是否存在临近期末突击签订合同/突击发货的异常交易
- [ ] 疑似提前确认的收入是否追踪至次年初退货/冲回情况
- [ ] 跨期收入金额是否汇总并评估对本期收入及利润的影响
- [ ] 是否存在通过调整发货或开票日期人为归属会计期间的迹象

### 四、结论与调整

- [ ] 截止测试结论是否明确（无跨期/存在跨期需调整）
- [ ] 需调整的跨期收入是否形成调整分录建议（AJE）并计算金额影响
- [ ] 测试发现的异常是否与D4-18后向测试、收入分析程序交叉印证
- [ ] 重大跨期错报是否评估累计影响并与重要性水平对比
- [ ] 底稿是否记录测试方法、窗口天数、样本选取依据及结论
- [ ] 交叉索引是否完整（关联收入审定表、明细账、发货记录、次年序时账）

## risk_areas

### 高风险

1. **提前确认收入虚增业绩**：期末货物未发出或验收未完成即确认收入，将次年收入提前计入本期，直接虚增营业收入和利润，属典型收入舞弊（CAS1141）。
2. **控制权转移时点判断错误**：未依据合同交货条款判断控制权转移，简单以开票日确认收入，导致大量交易归属期错误。
3. **期末突击交易未识别**：临近期末突击开票发货的大额交易未纳入测试或未核查真实性，可能掩盖为达成业绩目标的收入操纵。
4. **单据造假掩盖跨期**：通过倒签发货单、篡改物流签收日期使跨期交易"看似"符合截止，前向测试须交叉核对多方独立单据。
5. **测试窗口过窄漏检**：截止窗口天数不足导致临近窗口边界的跨期交易未被捕获，测试失去有效性。

### 中风险

1. **样本覆盖不足**：期末大额收入或高风险客户未全部纳入样本，抽样代表性不足，无法支持截止认定结论。
2. **验收条款收入确认不当**：需安装调试验收的合同在验收前确认收入，未识别履约义务尚未完成。
3. **前后向测试未交叉印证**：前向测试与后向测试、收入分析结果未相互印证，孤立结论可靠性不足。
4. **跨期金额未评估影响**：识别出跨期交易但未汇总计算对本期收入利润的影响，无法判断是否达到调整门槛。

### 低风险

1. **底稿记录不完整**：测试窗口天数、样本选取依据、抽样参数未在底稿中充分记录，影响复核可追溯性。
2. **交叉索引缺失**：截止测试底稿与收入审定表、发货记录、次年序时账的交叉引用不完整。
3. **单据核对痕迹不清**：核对原始单据后未留下清晰的勾稽标记或核对说明，复核难以还原核对过程。
