# D6-2 合同资产明细表复核提示词

## 概述

本提示词针对合同资产明细表（D6-2，科目码1402）的复核，聚焦四大核心审计要点：合同/客户信息完整性、余额准确性、履约进度合理性、账龄分析正确性。明细表是合同资产科目审计的基础数据底稿，承载按合同/客户维度的余额明细、履约进度和账龄分布，其数据质量直接影响减值准备计提（D6-3）、ECL计算（D6-8）、合同资产转应收账款判断等后续审计程序的有效性。

**法规依据：**
- 《企业会计准则第14号——收入》
- 《企业会计准则第22号——金融工具确认和计量》
- 《中国注册会计师审计准则第1301号——审计证据》
- 《中国注册会计师审计准则第1502号——对特殊项目审计证据的进一步考虑》

## tips

1. **合同信息完整性是明细表质量的基石**：每一行合同资产记录须具备完整识别信息（合同编号、客户名称、履约义务、关联方标志等），空白或笼统归集可能掩盖虚构履约或分类错误。
2. **余额准确性的核心是勾稽关系**：明细账合计必须与审定表D6-1期末审定数完全一致，期初余额必须与上年审定数衔接，任何差异需追溯至具体调整分录。
3. **履约进度是合同资产确认的关键判断**：合同资产金额应与按履约进度确认的收入相匹配，履约进度虚高将导致合同资产及收入虚增，需核对履约进度计量方法（产出法/投入法）及支持性证据。
4. **账龄分析驱动减值计提**：合同资产账龄（自确认日起算）划分标准须与会计政策一致，各账龄段合计须等于合同余额，长账龄合同资产需评估后续履约义务能否完成及对方信用状况。
5. **合同资产转应收账款的时点判断**：当收款权转为仅取决于时间流逝时，应及时从合同资产结转至应收账款，明细表需反映这一结转，未及时结转将导致列报错误。
6. **关注明细与汇总的双向勾稽**：各合同期末余额合计 = D6-1审定数；各合同履约进度对应金额 ↔ 收入确认底稿；各账龄段合计 = D6-3/D6-8账龄汇总数；关联方合同资产 ↔ D6-5关联方检查表。

## checklist

### 一、合同/客户信息完整性

- [ ] 合同编号、客户名称是否完整规范，无空白或笼统归集
- [ ] 是否标注关联方客户，关联方合同资产是否全部识别（与D6-5勾稽）
- [ ] 合同履约义务及收款条件是否清晰记录（区分时间流逝外的因素）
- [ ] 合同清单是否与合同管理系统或ERP数据一致
- [ ] 新增重要合同是否有合同文本及履约进度支持
- [ ] 是否存在无实际履约支持的合同资产记录（虚构履约迹象）

### 二、余额准确性

- [ ] 明细表各合同期末余额合计是否与总账/审定表D6-1一致
- [ ] 明细表期初余额是否与上年审定期末数衔接
- [ ] 各合同余额计算是否正确（期初 + 本期新增 − 本期结转/收款 = 期末）
- [ ] 合同资产数据是否直接从系统导出，未经不当人工调整
- [ ] 已满足无条件收款权的合同资产是否及时结转至应收账款
- [ ] 是否存在余额异常波动（超过30%且无合理解释）

### 三、履约进度合理性

- [ ] 各合同履约进度计量方法是否与会计政策一致（产出法/投入法）
- [ ] 合同资产金额是否与按履约进度确认的收入相匹配
- [ ] 履约进度是否有客观支持性证据（工程量确认、里程碑验收等）
- [ ] 期末履约进度较期初是否存在异常跳跃，是否有合理解释
- [ ] 是否存在人为提高履约进度以虚增合同资产及收入的迹象
- [ ] 完工合同的合同资产是否已及时转应收账款或收回

### 四、账龄分析正确性

- [ ] 账龄划分标准是否与公司会计政策一致（1年以内/1-2年/2-3年/3年以上）
- [ ] 各合同各账龄段金额之和是否等于该合同余额
- [ ] 全部合同各账龄段合计是否与减值底稿（D6-3/D6-8）账龄汇总一致
- [ ] 账龄起算日是否以合同资产确认日为准，标准是否统一
- [ ] 长账龄（2年以上）合同资产是否逐项标注原因及后续履约/回收评估
- [ ] 是否存在人为调整账龄的迹象（如通过结转、滚动确认推迟账龄）

## risk_areas

### 高风险

1. **虚构合同或履约**：明细表中出现无实际业务的合同资产，或履约进度无法验证，涉及存在性认定。
2. **履约进度虚高**：人为提高履约进度导致合同资产及收入虚增，未有客观完工证据支持。
3. **合同资产与应收账款划分错误**：已满足无条件收款权的债权仍列示为合同资产，或反之，导致列报及减值方法错误。
4. **长账龄未充分减值**：2年以上合同资产金额重大但未评估后续履约能否完成及对方信用，减值计提不足。
5. **余额与总账不一致**：明细合计数与审定表/总账存在差异未调节，表明可能存在遗漏或错误记录。

### 中风险

1. **账龄人为操纵**：通过结转、滚动确认等方式人为缩短账龄，导致减值计提不足。
2. **合同信息不完整**：部分合同缺少履约义务、收款条件等关键信息，影响减值风险判断。
3. **未及时结转应收账款**：完工且满足无条件收款权后仍挂账合同资产，未及时结转。
4. **关联方合同资产未识别**：明细表中关联方合同未标注或遗漏，影响关联交易披露完整性。
5. **履约进度方法不一致**：不同合同或期间采用不同履约进度计量方法，影响可比性。

### 低风险

1. **格式规范性问题**：明细表格式不统一、排列顺序不规范等形式问题。
2. **辅助信息缺失**：缺少合同行业分类、地区分布等辅助分析信息。
3. **小额合同归集**：小额合同归集为"其他"时未附明细清单。
4. **交叉索引不完整**：与减值底稿、ECL底稿、收入底稿的交叉引用标注不全。
