# D2-3 坏账准备复核提示词

## 适用底稿
坏账准备计提表（D2-3）

## 审计目标
验证应收账款坏账准备计提的充分性、准确性和合规性，确保预期信用损失（ECL）模型参数合理、迁徙率计算准确、单项减值判断充分、计提比例与会计政策一致。

## 法规依据
- 《企业会计准则第22号——金融工具确认和计量》（CAS22）
- 《企业会计准则第37号——金融工具列报》
- 《中国注册会计师审计准则第1301号——审计证据》
- 《中国注册会计师审计准则第1502号——审计数据完整性及准确性》

---

## tips

- ECL模型需使用前瞻性信息调整历史损失率，仅依赖历史数据不足以满足CAS22要求
- 迁徙率法需至少3年（建议5年）的账龄迁徙数据作为计算基础，数据年限不足将显著影响计算结果的可靠性
- 单项减值判断需关注客户是否出现"信用风险显著增加"的迹象（如诉讼、破产、失联、逾期超过合同期90天等）
- 组合减值的分组标准应与信用风险特征一致，不同信用风险等级的应收账款不应混合在同一组合中
- 账龄划分标准的选取（按发票日/到期日/入账日）将直接影响账龄分析和ECL计算结果，需确认与被审计单位会计政策一致
- 坏账准备计提比例变更应作为会计估计变更处理，且需有充分理由支持
- 关注期后回款情况对坏账准备充分性的验证作用——大额期后收回可能说明计提过多，大额期后无回款则可能说明计提不足
- 前五大客户集中度高时，需对这些客户单独评估信用风险，不能简单并入组合计提

## checklist

### 一、ECL模型参数合理性（高风险）

- [ ] 预期信用损失模型是否符合CAS22"三阶段"框架要求（12个月ECL / 整个存续期ECL）
- [ ] 违约概率（PD）的估计方法是否合理，历史数据来源是否充分
- [ ] 违约损失率（LGD）的估计是否考虑了担保品价值、回收可能性等因素
- [ ] 违约风险敞口（EAD）的确定是否准确反映资产负债表日的信用风险敞口
- [ ] 是否纳入前瞻性信息（宏观经济预测、行业趋势、政策变化）调整历史损失率
- [ ] 前瞻性调整的方法是否合理（如GDP增速、行业景气指数、失业率等宏观变量的选取及权重设置）
- [ ] ECL模型参数是否定期更新（至少每年），更新依据是否充分
- [ ] 模型输入数据的质量和完整性是否经过验证
- [ ] 信用风险"显著增加"的判断标准是否明确且持续一致地应用
- [ ] 是否对模型输出结果进行回测验证（实际损失率 vs 预测损失率）

### 二、迁徙率计算准确性（高风险）

- [ ] 迁徙率计算所使用的历史数据年限是否充分（至少3年，建议5年）
- [ ] 账龄划分标准（按发票日期/到期日/入账日）是否与会计政策一致
- [ ] 各账龄段的迁徙率计算过程是否可追溯、可验证
- [ ] 迁徙率计算是否剔除了特殊事项（如一次性大额核销、债务重组等非经常性因素）
- [ ] 各账龄段的迁徙率是否符合逻辑递增规律（账龄越长，迁徙至更长账龄的概率越高）
- [ ] 迁徙率是否考虑了不同客户群体/业务类型的差异
- [ ] 最终损失率的计算（迁徙率连乘）是否数学正确
- [ ] 迁徙率计算中的期初余额与期末余额取数是否正确（与明细表D2-2勾稽）
- [ ] 年度间迁徙率的变动是否合理，异常波动是否有充分解释

### 三、单项减值判断充分性（高风险）

- [ ] 是否对所有存在客观减值证据的应收账款逐项评估减值
- [ ] 单项减值的判断标准是否明确（如逾期天数、涉诉金额、客户经营状况等）
- [ ] 单项计提减值的应收账款是否确实存在"信用风险显著增加"的客观证据
- [ ] 单项减值金额的确定是否有合理依据（如预计可收回金额的评估方法）
- [ ] 是否关注以下情形并纳入单项减值考虑：客户破产/清算、涉及诉讼仲裁、失联无法联系、逾期超过合同约定期限90天以上、发生债务重组
- [ ] 上期单项减值的应收账款本期状态是否重新评估（是否仍需单项计提、金额是否调整）
- [ ] 单项减值后的剩余应收账款是否按信用风险特征分组纳入组合减值
- [ ] 已全额计提减值但未核销的应收账款，是否存在应核销而未核销的情况
- [ ] 单项减值判断是否经过适当授权审批

### 四、计提比例与政策一致性（中风险）

- [ ] 各账龄段坏账准备计提比例是否与被审计单位会计政策（附注披露）一致
- [ ] 本期计提比例与上期是否一致，如有变更是否有充分理由和审批
- [ ] 同一行业同类企业的计提比例是否进行了对标分析
- [ ] 实际发生坏账损失率是否支持当前计提比例的合理性
- [ ] 不同组合之间的计提比例差异是否与信用风险差异匹配
- [ ] 组合划分标准（如按账龄、按客户类别、按业务类型等）是否合理
- [ ] 计提金额=计提基数×计提比例的计算是否准确无误
- [ ] 坏账准备余额=期初余额+本期计提-本期转回-本期核销，期末勾稽是否正确
- [ ] 与审定表（D2-1）的坏账准备期末余额是否勾稽一致
- [ ] 附注中披露的坏账政策与实际执行的计提比例是否一致

## risk_areas

### 高风险

- ECL模型参数不合理：违约概率/损失率估计缺乏充分数据支持，或未纳入前瞻性信息调整
- 迁徙率计算错误：数据年限不足、计算过程存在数学错误、未剔除非经常性因素
- 单项减值遗漏：存在明显减值迹象的客户未纳入单项评估（如涉诉大额客户仍按组合计提）
- 坏账准备计提严重不足：实际坏账发生率显著高于当前计提比例，管理层有低估减值的动机
- 人为操纵账龄：通过期末转账、红冲重开、关联方代付等方式人为缩短账龄，降低计提金额
- 核销未经授权：大额核销缺乏审批流程或审批层级不够

### 中风险

- 计提比例与政策不一致：实际计提比例偏离会计政策披露的比例但无充分解释
- 组合划分不合理：不同信用风险特征的客户混合分组，导致组合损失率被平均化
- 迁徙率数据年限偏短：仅使用1-2年数据计算迁徙率，代表性不足
- 账龄划分标准不一致：本期与上期使用了不同的账龄起算日但未披露变更
- 前瞻性调整不充分：宏观经济环境已发生重大变化但ECL模型参数未相应更新
- 同行业对比差异过大：计提比例显著低于同行业可比公司但缺乏合理解释

### 低风险

- 坏账准备明细表与总账存在尾差（四舍五入差异在合理范围内）
- 迁徙率表格式不规范但计算结果正确
- 坏账政策描述不够精确但实际执行无偏差
- ECL模型文档不够完整但核心参数有据可查
