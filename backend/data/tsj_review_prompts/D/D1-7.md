# D1-7 备查簿核对表复核提示词

## 概述

本提示词针对应收票据备查簿核对表（D1-7）的复核，聚焦四大核心审计要点：备查簿与账簿的核对、物理保管的健全性、票据进出登记的完整性、内部控制的有效性。应收票据备查簿是逐笔登记票据种类、号码、金额、出票人、承兑人、出票日、到期日及收取/背书/贴现/兑付全生命周期状态的辅助簿，是验证应收票据存在性、完整性和真实性的重要底稿，也是评估票据管理内控的关键依据。

**法规依据：**
- 《企业会计准则第22号——金融工具确认和计量》
- 《中国注册会计师审计准则第1301号——审计证据》
- 《中国注册会计师审计准则第1211号——通过了解被审计单位及其环境识别和评估重大错报风险》

## tips

1. **备查簿是应收票据存在性与完整性的双向验证工具**：备查簿逐笔登记应与总账/明细账（D1-2）、实物盘点（D1-10）三方核对，任一不符可能指向票据遗失、账外票据或虚构票据。
2. **进出登记完整性反映生命周期管理**：应收票据从收取、背书转出、贴现、质押、到期兑付到退票的每一环节均应在备查簿登记，进出登记不连续或状态未更新可能导致账实不符和列报错误。
3. **物理保管的健全性是防范舞弊的第一道防线**：纸质票据须有专人保管、库房/保险柜管理、领用审批；电子票据须有 ECDS 系统操作权限分离和审批控制，保管不善易发生票据被盗用、私自贴现等舞弊。
4. **备查簿与背书贴现/质押底稿须交叉勾稽**：备查簿中标注"已背书/已贴现/已质押"的票据须与 D1-8、D1-12 逐笔一致，状态不一致可能掩盖已出表票据或受限资产。
5. **到期日跟踪是备查簿的动态管理职能**：备查簿应能反映即将到期、已逾期票据，用于催收和减值判断，逾期票据未在备查簿更新状态将影响 D1-4 减值评估。
6. **关注备查簿与账簿的三方勾稽**：备查簿票据金额合计 = D1-2 分类明细合计 = D1-1 审定数 = 实物盘点（D1-10）合计；备查簿状态标注 = D1-8 背书贴现/D1-12 质押明细。

## checklist

### 一、备查簿与账簿核对

- [ ] 备查簿是否逐笔登记所有应收票据（种类/号码/金额/出票人/承兑人/出票日/到期日）
- [ ] 备查簿票据金额合计是否与明细账/总账（D1-2）一致
- [ ] 备查簿票据金额合计是否与审定表 D1-1 审定数一致
- [ ] 备查簿登记的票据是否与实物盘点（D1-10）三方核对一致
- [ ] 是否存在账上有记录但备查簿未登记的票据（或反之）
- [ ] 备查簿数据是否与 ECDS 电子商业汇票系统信息核对一致

### 二、票据进出登记完整性

- [ ] 本期收取票据是否全部登记入账（收取日期/来源/贸易背景）
- [ ] 背书转出票据是否登记（背书日期/被背书人/用途）并与 D1-8 一致
- [ ] 贴现票据是否登记（贴现日期/贴现行/贴现率/贴现净额）并与 D1-8 一致
- [ ] 到期兑付票据是否登记并核销（兑付日期/收款金额）
- [ ] 退票/拒付票据是否登记并跟踪后续处理
- [ ] 进出登记是否连续、无跳号或断档

### 三、物理保管健全性

- [ ] 纸质票据是否有专人保管、库房/保险柜管理
- [ ] 票据领用、背书、贴现是否有审批手续和审批权限
- [ ] 电子票据 ECDS 系统操作是否权限分离（经办/复核/审批）
- [ ] 是否存在票据保管与账务处理未分离（不相容职务）
- [ ] 空白票据/收到票据的保管责任是否明确
- [ ] 是否发生过票据丢失、被盗用、私自贴现等事件及处理

### 四、内部控制有效性

- [ ] 是否建立应收票据管理制度并有效执行
- [ ] 备查簿是否定期与账簿、实物核对并留痕
- [ ] 票据到期是否有提前跟踪催收机制
- [ ] 逾期/拒付票据的处理是否有内部审批流程
- [ ] 关联方票据、无真实贸易背景票据是否有识别和审批控制
- [ ] 内部控制缺陷是否已识别并评估对实质性程序的影响

## risk_areas

### 高风险

1. **账实不符**：备查簿、账簿、实物三方核对不一致，可能存在票据遗失、被盗用、账外票据或虚构票据。
2. **票据被私自处置**：保管与账务未分离，票据被私自背书/贴现套取资金而账簿未反映。
3. **进出登记缺失**：背书/贴现/质押票据未在备查簿登记，导致账面高估或受限资产未披露。
4. **虚构票据**：备查簿登记的票据在 ECDS 系统或实物中无对应，涉及存在性舞弊。
5. **逾期票据状态未更新**：备查簿未反映逾期/拒付状态，影响减值评估和资产真实性。

### 中风险

1. **备查簿登记不完整**：部分票据要素缺失，影响存在性和真实性验证。
2. **状态标注与专项底稿不一致**：备查簿"已背书/已质押"标注与 D1-8/D1-12 不勾稽。
3. **内控制度执行不到位**：有制度但未定期核对或审批流于形式。
4. **电子票据权限控制薄弱**：ECDS 系统操作权限未分离，存在越权操作风险。
5. **到期跟踪机制缺失**：无到期提前跟踪，导致催收不及时。

### 低风险

1. **备查簿格式不规范**：登记栏目不齐全、格式不统一。
2. **核对留痕不充分**：定期核对已执行但未签字留痕。
3. **交叉索引不完整**：与分类明细、背书贴现、质押、盘点底稿的索引标注不全。
4. **辅助信息缺失**：缺少票据贸易背景、来源等辅助登记信息。
