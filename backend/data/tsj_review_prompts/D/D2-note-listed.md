# D2-note-listed 附注披露复核提示词（上市公司）

## 概述

本提示词针对应收账款上市公司附注披露底稿（D2-note-listed）的复核，聚焦上市公司财务报表附注中应收账款相关披露的充分性和准确性：分类披露、账龄披露、坏账准备变动披露、CAS37金融工具列报要求的充分性、关联方应收款项单独披露、以及信用风险集中度披露。附注披露是报表使用者获取应收账款详细信息的主要途径，披露不充分或不准确将影响投资者决策。

**法规依据：**
- 《企业会计准则第37号——金融工具列报》
- 《企业会计准则第22号——金融工具确认和计量》
- 《企业会计准则第36号——关联方披露》
- 《公开发行证券的公司信息披露编报规则第15号——财务报告的一般规定》
- 《中国注册会计师审计准则第1501号——对财务报表形成审计意见和出具审计报告》

---

## tips

1. **上市公司披露要求高于一般企业**：除CAS37基本要求外，证监会编报规则第15号对应收账款披露有额外细化要求，包括按业务性质分类、前五名应收账款等，缺失任何一项均属披露不充分。
2. **分类披露须与会计政策中的分类方法一致**：附注中应收账款按业务性质、按账龄、按坏账计提方法（单项/组合）等多维度分类披露，各维度的合计数必须相互勾稽。
3. **坏账准备变动表是投资者重点关注的信息**：变动表须完整列示期初余额、本期计提、本期转回、本期核销、其他变动和期末余额，且各项金额可追溯至具体交易或调整。
4. **信用风险集中度是CAS37的强制披露要求**：须披露应收账款中按客户/地区/行业等维度的集中度信息，前五大客户应收账款占比是上市公司必须披露的内容。
5. **关联方应收账款须独立成表**：根据CAS36要求，关联方应收账款须单独列示关联方名称、关系类型、交易金额、期末余额和坏账准备，不得混入一般客户。
6. **附注数据必须与审定表/明细表/坏账准备表形成闭环勾稽**：附注中的应收账款总额必须等于审定表审定数，分类小计必须等于明细表对应分类合计，坏账准备合计必须等于D2-3表期末余额。

## checklist

### 一、分类披露检查

- [ ] 应收账款是否按业务性质分类披露（货款/服务费/质保金/其他）
- [ ] 各类别期末余额合计是否等于审定表应收账款审定数
- [ ] 各类别是否同时披露期末数和期初数（可比信息）
- [ ] 按坏账计提方法分类（单项计提/组合计提）是否完整
- [ ] 单项计提和组合计提的合计是否等于应收账款总额
- [ ] 分类方式是否与会计政策中确定的分类标准一致
- [ ] 各分类之间是否存在重叠或遗漏

### 二、账龄披露检查

- [ ] 账龄披露是否按规定区间完整列示（1年以内/1-2年/2-3年/3年以上）
- [ ] 各账龄段金额合计是否等于应收账款总额
- [ ] 账龄起算日口径是否与会计政策一致且予以说明
- [ ] 各账龄段是否同时列示账面余额和坏账准备
- [ ] 账龄结构较上期是否存在重大异常变动，如有是否已说明原因
- [ ] 1年以内的应收账款是否进一步细分（如3个月/6个月/1年）
- [ ] 账龄分析数据是否与D2-2明细表账龄分析一致

### 三、坏账准备变动披露

- [ ] 坏账准备变动表是否完整（期初/计提/转回/核销/其他/期末）
- [ ] 变动表各栏金额是否与D2-3坏账准备计算表勾稽
- [ ] 本期计提金额是否与利润表信用减值损失一致
- [ ] 本期核销是否有充分审批依据和披露
- [ ] 本期转回的原因是否合理披露
- [ ] 是否区分单项计提和组合计提的变动情况
- [ ] 期末坏账准备余额是否等于应收账款总额减净额

### 四、CAS37金融工具列报充分性

- [ ] 是否披露应收账款的信用风险管理目标和政策
- [ ] 是否披露预期信用损失的计量方法（一般方法/简化方法）
- [ ] 是否披露ECL模型的关键假设和参数（违约定义/损失率/前瞻性信息）
- [ ] 是否披露信用风险最大敞口金额（通常为应收账款账面余额）
- [ ] 是否披露应收账款的信用质量信息（按风险等级/逾期状态分类）
- [ ] 是否披露担保品或其他信用增级的信息
- [ ] 是否披露应收账款公允价值（如与账面价值存在重大差异）
- [ ] 预期信用损失变动原因是否有定性和定量说明

### 五、关联方应收款项披露

- [ ] 关联方应收账款是否单独列表披露（不混入一般客户）
- [ ] 是否完整列示关联方名称、关系类型
- [ ] 是否披露与各关联方的交易金额和期末余额
- [ ] 关联方应收账款的坏账准备是否单独披露
- [ ] 关联方应收账款的账龄是否单独分析
- [ ] 关联方交易定价的公允性是否有说明
- [ ] 本期新增的关联方应收账款是否有商业合理性说明

### 六、信用风险集中度披露

- [ ] 是否披露前五名应收账款客户的期末余额和占比
- [ ] 前五名客户的坏账准备是否单独披露
- [ ] 是否分析客户集中度对信用风险的影响
- [ ] 是否披露按地区/行业的集中度信息（如适用）
- [ ] 集中度信息是否与D2-2明细表前五大客户数据一致
- [ ] 单一客户占比超过50%时是否有特别风险提示
- [ ] 本期集中度较上期是否存在重大变动，如有是否已说明

### 七、其他披露事项

- [ ] 已质押的应收账款是否单独披露金额和质押对象
- [ ] 已保理/已贴现的应收账款是否披露终止确认/未终止确认金额
- [ ] 期后已收回的重大应收账款是否披露
- [ ] 应收账款中涉诉金额是否披露
- [ ] 应收账款与合同资产的划分依据是否披露
- [ ] 与收入确认相关的应收账款变动是否与收入附注勾稽

## risk_areas

### 高风险

1. **坏账准备变动表不完整或不勾稽**：变动表各项金额之间的勾稽关系不成立（期初+计提-转回-核销±其他≠期末），或与D2-3表数据不一致，属重大披露错误。
2. **关联方应收账款未单独披露**：关联方应收账款混入一般客户未单独列示，违反CAS36强制要求，可能被视为故意隐瞒关联交易。
3. **ECL模型关键假设未披露**：未披露预期信用损失模型的违约定义、损失率假设和前瞻性调整因子，不满足CAS37对金融工具披露的要求。
4. **信用风险集中度信息缺失**：未披露前五名客户信息或单一客户占比异常高但未风险提示，不满足证监会编报规则要求。
5. **附注总额与审定表不一致**：附注中披露的应收账款期末余额与审定表审定数不一致，属数据勾稽重大错误。

### 中风险

1. **账龄披露口径不一致**：附注账龄起算日与减值模型使用的起算日不同，导致账龄分布与计提比例无法对应。
2. **分类维度不完整**：仅按单一维度（如账龄）分类披露，未按业务性质和坏账计提方法多维度披露。
3. **坏账准备核销披露不充分**：本期核销金额较大但未披露核销客户及原因，投资者无法评估管理层判断的合理性。
4. **质押/保理信息披露不完整**：已质押或保理的应收账款仅披露总额，未披露具体安排和条件。
5. **可比信息缺失**：附注中仅列示期末数据，未列示期初可比数据或上年同期数据。

### 低风险

1. **披露格式不完全规范**：表格标题、列序、金额单位等格式细节未严格按编报规则，但不影响信息实质完整性。
2. **文字描述过于模板化**：信用风险管理政策等文字描述照搬会计政策原文，未结合本企业实际情况进行针对性说明。
3. **数字精度不一致**：部分披露表格保留两位小数，部分取整到万元，精度不统一但不影响决策判断。
4. **期后事项披露过于简略**：期后收回的重大应收账款仅提及事实，未说明对减值评估的影响。
