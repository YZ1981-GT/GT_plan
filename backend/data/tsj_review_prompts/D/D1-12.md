# D1-12 质押票据检查表复核提示词

## 概述

本提示词针对应收票据质押检查表（D1-12）的复核，聚焦四大核心审计要点：质押票据识别完整性、质押事项与合同核对、受限资产列报与披露、质押对相关负债的勾稽。已质押的应收票据属所有权受限资产，其存在性无法通过常规监盘验证，且质押通常对应借款或担保义务，须结合质押协议、借款底稿（L1 短期借款等）交叉核查，防范未披露的资产受限和或有负债。

**法规依据：**
- 《企业会计准则第37号——金融工具列报》
- 《中国注册会计师审计准则第1301号——审计证据》
- 《企业会计准则第22号——金融工具确认和计量》
- 《企业会计准则第23号——金融资产转移》

## tips

1. **质押票据须完整识别**：通过质押协议、银行授信合同、董事会/股东会决议、企业征信报告、票据台账状态等多渠道识别已质押票据，防范管理层隐瞒资产受限事项。
2. **质押≠终止确认**：质押票据的所有权和风险报酬仍归出质方，不满足 CAS23 终止确认条件，应继续列示应收票据并作受限披露，不得出表。
3. **质押须与对应负债勾稽**：应收票据质押通常为借款或开立银行承兑汇票提供担保，须与 L1 短期借款、应付票据保证金等底稿勾稽，核对质押票据金额与担保负债的对应关系。
4. **受限资产披露是 CAS37 强制要求**：已质押票据须披露账面金额、质押原因、质权人、担保的债务，披露遗漏或不完整属列报缺陷。
5. **质押票据的减值仍须评估**：质押不改变票据本身的信用风险，承兑人违约风险仍存在，减值评估不因质押而豁免。
6. **关注质押的存在性替代程序**：质押票据由质权人（银行）保管，无法现场监盘，须通过质押协议、质权人函证、保管凭证等替代程序验证存在性。

## checklist

### 一、质押票据识别完整性

- [ ] 【必检】是否通过质押协议、授信合同、决议、征信报告等多渠道识别质押票据
- [ ] 【必检】质押票据是否与票据台账（D1-7）状态标识核对一致
- [ ] 【必检】是否存在已质押但账面未标注受限的票据
- [ ] 【条件检查：若有银行授信】授信项下质押的票据是否完整识别
- [ ] 【风险检查】是否存在管理层隐瞒的质押事项（通过征信报告交叉验证）

### 二、质押事项与合同核对

- [ ] 【必检】质押协议要素（质押票据/质权人/担保债务/期限）是否与账面核对
- [ ] 【必检】质押票据金额是否与担保的债务金额匹配
- [ ] 【必检】质押是否经适当授权（决议/审批）
- [ ] 【条件检查：若质押到期或解除】质押解除后受限标识是否及时更新
- [ ] 【风险检查】是否存在超额质押或质押条款异常

### 三、受限资产列报与披露

- [ ] 【必检】已质押票据是否继续列示应收票据（未错误出表）
- [ ] 【必检】已质押票据是否作为所有权受限资产在附注单独披露
- [ ] 【必检】披露是否包含账面金额、质押原因、质权人、担保债务
- [ ] 【必检】受限票据金额是否与 D1-1 审定表勾稽
- [ ] 【风险检查】是否存在应披露而未披露的受限资产

### 四、质押与负债勾稽

- [ ] 【必检】质押票据是否与对应借款（L1）或担保负债勾稽
- [ ] 【必检】质押担保的或有负债是否评估并披露
- [ ] 【条件检查：若为第三方担保】对外提供质押担保是否披露或有负债
- [ ] 【风险检查】是否存在质押担保关联方债务未披露的情况

## risk_areas

### 高风险

1. **质押票据错误出表**：将已质押票据错误终止确认（出表），虚减资产，违反 CAS23。
2. **未披露资产受限**：已质押票据未作受限披露，误导报表使用者对资产流动性的判断。
3. **隐瞒质押担保或有负债**：质押为他人（尤其关联方）债务担保未披露或有负债。
4. **管理层隐瞒质押事项**：账面未标注、协议未提供，通过征信报告才发现的隐瞒质押。
5. **超额/循环质押**：同一票据重复质押或超额质押，掩盖真实负债规模。

### 中风险

1. **质押减值豁免**：以质押为由未评估质押票据的承兑人违约减值风险。
2. **披露要素不完整**：受限披露遗漏质权人、担保债务等关键要素。
3. **质押与负债不勾稽**：质押票据金额与对应借款/担保负债无法对应。
4. **解除质押未更新**：质押解除后受限标识未及时更新。

### 低风险

1. **索引不完整**：与借款底稿、征信报告、附注的交叉索引不全。
2. **协议留存不全**：质押协议、决议等支持性文件留存不完整。
3. **格式不规范**：质押事项记录格式不统一。
