# D7-3 合同负债调整分录复核提示词

## 适用底稿
合同负债调整分录汇总表（D7-3，科目码2205），含账项调整（AJE）、重分类调整（RJE）及未调整错报（SUD）评估。

## 概述
D7-3 是合同负债审定数链路的关键环节。复核须验证：每笔调整有证据、借贷平衡、完整反映到 D7-1 审定表、SUD 评估符合重要性水平要求，并重点关注合同负债补记（漏记负债更正）、收入确认时点修正、合同负债转其他科目（退款义务/营业外收入）等合同负债特有调整。

**法规依据：**
- 《企业会计准则第28号——会计政策、会计估计变更和差错更正》
- 《中国注册会计师审计准则第1301号——审计证据》
- 《中国注册会计师审计准则第1324号——持续经营》

## tips

1. **AJE vs RJE**：AJE 影响损益或负债金额（如合同负债补记冲减收入、收入确认时点修正）；RJE 仅影响列报（如合同负债流动/非流动重分类、与合同资产净额列示），不得通过 RJE 掩盖损益错报。
2. **合同负债补记调整关注收入完整性**：漏记合同负债即提前确认收入，补记调整（借收入 贷合同负债）是纠正收入虚增的关键，须核对补记依据充分。
3. **与 D7-1 勾稽**：审定表调整列金额须与 D7-3 已确认分录逐笔一致，遗漏任一笔即审定数失真。
4. **收入确认时点修正调整**：合同负债应结转收入却未结转（低估收入）或反之的调整，须与收入确认（履约进度）证据勾稽。
5. **SUD 累计**：未调整错报单独及累计是否超过整体/明显微小错报阈值，须与 A13 未调整错报汇总交叉验证。
6. **TB 回写**：确认调整已同步试算平衡表2205科目，避免「底稿已调、TB 未更」双真源。

## checklist

### 一、账项调整（AJE）检查项（高风险）

- [ ] 所有 AJE 是否有充分审计证据（履约进度复核、合同核对、管理层确认等）
- [ ] AJE 是否经适当层级审批（超重要性水平须合伙人知悉）
- [ ] 每笔调整分录借贷方是否完全平衡
- [ ] 合同负债补记AJE（纠正漏记负债/收入虚增）依据是否充分
- [ ] 收入确认时点修正调整是否与履约进度证据勾稽
- [ ] 调整金额是否完整反映到 D7-1 审定表对应调整列
- [ ] 是否存在仅为美化收入或规避业绩考核的不当调整

### 二、重分类调整（RJE）检查项（中风险）

- [ ] 合同负债流动/非流动重分类是否与预计履约时间匹配
- [ ] RJE 是否仅涉及列报，未影响损益类科目
- [ ] 合同负债与合同资产按合同净额列示的重分类是否正确
- [ ] 合同负债与预收账款/其他应付款的重分类是否正确
- [ ] 长期挂账合同负债转其他应付款（退款义务）或营业外收入的调整是否恰当
- [ ] 与A13未调整错报汇总表索引是否完整
- [ ] 调整原因说明是否清晰可追溯至具体审计程序

### 三、未调整错报（SUD）与规范性检查项（低风险）

- [ ] 未调整错报累计是否超过整体重要性水平且仍出具无保留意见（须评估）
- [ ] 跨期调整是否正确区分本期错报与前期差错更正
- [ ] 建议调整与已执行调整是否区分记录
- [ ] 调整分录编号是否连续，删除后是否重号风险可控
- [ ] 分录摘要、科目编码是否规范
- [ ] 索引是否指向 D7-7 凭证检查、D7-5 长期挂账等支持底稿

## risk_areas

### 高风险

1. **调整缺乏证据或未经授权**：合同负债补记或收入时点调整无充分证据或未经适当审批。
2. **审定表与D7-3调整金额不一致**：已确认调整未完整反映到审定表，导致审定数失真。
3. **收入完整性调整遗漏**：漏记合同负债导致收入虚增，未做补记调整。
4. **SUD累计超阈值未恰当处理**：未调整错报累计超过整体重要性水平仍出具无保留意见。

### 中风险

1. **RJE误含损益影响**：本应仅调列报的重分类分录误影响损益类科目。
2. **合同负债转科目不当**：长期挂账合同负债转营业外收入的时点或依据不当，操纵利润。
3. **跨期调整分类错误**：本期错报与前期差错更正未正确区分，会计处理及披露错误。

### 低风险

1. **编号、格式不规范**：分录编号、摘要、科目编码等格式问题。
2. **索引不完整**：与支持底稿的交叉索引标注不全。

## 跨底稿勾稽

- D7-3 已确认 AJE/RJE 合计 ↔ D7-1 审定表调整列
- D7-3 收入时点调整 ↔ 收入确认底稿（履约进度）
- D7-3 长期挂账转科目调整 ↔ D7-5 长期挂账检查表
- D7-3 SUD ↔ A13 未调整错报汇总
- 调整后审定数 ↔ 试算平衡表 2205 科目
