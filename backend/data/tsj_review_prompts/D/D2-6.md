# D2-6 关联方应收款项检查复核提示词

## 适用底稿
关联方应收款项检查表（D2-6）

## tips

- 关联方应收账款必须单独识别、单独列示、单独披露（CAS36）
- 关联方交易的公允性须有独立证据支持（如第三方可比价格）
- 关注是否存在未识别的关联方（实际控制人的其他企业、家族成员企业等）
- 关联方应收款项的坏账准备须单独评估，不能简单并入账龄组合计提
- 关联方资金往来如无真实交易支撑，可能构成资金占用需特别披露
- 期末突增的关联方应收款项须重点核查商业实质

## checklist

### 高风险

- [ ] 关联方是否已全面识别（含隐性关联方）
- [ ] 关联方交易定价是否具有商业合理性（与第三方可比价格对比）
- [ ] 是否存在关联方资金占用（无真实业务支撑的资金往来）
- [ ] 关联方应收款项在附注中是否单独充分披露
- [ ] 是否存在关联方利益输送迹象
- [ ] 大额关联方应收账款的商业实质是否经过验证

### 中风险

- [ ] 关联方应收款项的坏账准备是否单独评估
- [ ] 关联方交易的决策审批程序是否规范（董事会/股东大会审批）
- [ ] 关联方交易条款（信用期/折扣/退货）是否与非关联方一致
- [ ] 期后关联方回款情况是否验证
- [ ] 关联方范围变动（新增/退出）是否合理

### 低风险

- [ ] 关联方清单格式是否规范
- [ ] 关联方信息（名称/关系类型/持股比例）是否完整
- [ ] 底稿交叉索引（关联D2-1/D2-2/附注披露）是否完整

## risk_areas

### 高风险

- 隐性关联方未识别导致关联交易披露不完整
- 关联方利益输送通过应收账款通道实施
- 关联方资金占用以经营性应收款名义挂账
- 关联方应收账款长期不回收但未充分计提减值

### 中风险

- 关联方交易定价明显偏离市场价格但无合理解释
- 关联方坏账准备未单独评估，混入组合计提
- 关联方交易审批程序不规范

### 低风险

- 关联方清单信息不够详细但不影响实质判断
- 关联方交叉索引不完整
