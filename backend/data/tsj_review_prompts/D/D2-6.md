# D2-6 关联方应收款项检查复核提示词

## 适用底稿
关联方应收款项检查表（D2-6），聚焦 CAS36 识别、定价公允性、单独列示及与 D2-1/D2-2/附注披露勾稽。

## 概述
关联方应收是舞弊与披露高风险领域。复核须验证：关联方清单完整、交易定价公允、坏账单独评估、附注单独披露，并与明细表、审定表一致。

---

## tips

1. **识别完整性**：除法定关联名单外，须关注隐性关联方（同一实际控制人、家族成员、关键管理人员关联方）。
2. **单独列示**：D2-1 审定表、D2-2 明细表、附注均须单独披露关联方余额，不得与非关联方混列。
3. **定价公允**：须与第三方可比交易或独立评估对比，偏离须解释。
4. **坏账单独评估**：关联方应收不得简单并入普通账龄组合，须单独评估 ECL（参见 D2-3/D2-9）。
5. **资金占用**：无真实交易支撑的往来可能构成非经营性占用，须评估披露与减值。
6. **期后验证**：关联方期后回款/展期情况须作为减值与披露充分性证据。

## checklist

### 高风险检查项

- [ ] 关联方清单是否完整（含隐性关联方排查记录）
- [ ] 关联方应收余额与 D2-2 明细表「关联方」行/列勾稽一致
- [ ] 关联方余额是否在 D2-1 审定表单独列示或附注可拆分
- [ ] 关联交易定价是否与第三方可比价格或独立评估匹配
- [ ] 是否存在无商业实质的关联方资金往来（疑似占用）
- [ ] 关联方应收坏账准备是否单独评估（非简单组合计提）
- [ ] 附注 CAS36 披露（定价政策、余额、坏账、担保）是否充分

### 中风险检查项

- [ ] 关联方交易审批程序是否规范（董事会/股东大会）
- [ ] 信用条款（账期、折扣）与非关联方是否一致，不一致是否合理解释
- [ ] 期后关联方回款是否验证并记录
- [ ] 新增/退出关联方是否更新清单及披露
- [ ] 与 D0 函证（如适用）回函金额核对

### 低风险检查项

- [ ] 关联方名称、关系类型、持股比例信息完整
- [ ] 索引指向 D2-1/D2-2/D2-note 交叉引用
- [ ] 审计说明/结论概括关联方风险与程序

---

## risk_areas

### 高风险

- 隐性关联方未识别导致披露不完整
- 关联方利益输送或资金占用
- 关联方长期挂账未充分计提减值

### 中风险

- 定价偏离市场无合理解释
- 坏账未单独评估

### 低风险

- 清单格式、索引不完整

## 跨底稿勾稽

- D2-6 关联方余额合计 ↔ D2-2 关联方明细合计
- D2-6 ↔ D2-1 审定表关联方行
- D2-6 披露口径 ↔ D2-note-listed / D2-note-soe 关联方章节
