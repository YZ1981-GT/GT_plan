# D4-11 产品价格分析表复核提示词

## 概述

本提示词针对产品价格分析表（D4-11）的复核，聚焦四大核心审计要点：同一产品价格趋势、产品价格与成本联动、异常价格识别、价格与市场行情匹配。产品价格分析从产品维度审视销售单价的时间趋势和市场对标，通过识别异常价格（趋势突变、价成背离、偏离市场行情）验证收入的量价勾稽真实性，是识别虚增收入（虚高单价）和收入错报的重要分析工具。

**法规依据：**
- 《企业会计准则第14号——收入》
- 《中国注册会计师审计准则第1301号——审计证据》
- 《中国注册会计师审计准则第1231号——针对评估的重大错报风险采取的应对措施》
- 《中国注册会计师审计准则第1313号——分析程序》

## tips

1. **产品价格趋势揭示收入量价结构**：同一产品单价的期间趋势应与市场行情、成本变动、供需关系匹配，价格趋势突变（尤其期末上涨）是虚增收入的信号。
2. **价格与成本联动是合理性锚点**：正常经营下产品售价与单位成本应保持合理联动（成本上升传导至售价），价格与成本背离（成本降但价升/成本升但价降）需追溯原因。
3. **异常价格需核实收入真实性**：显著偏离历史价格或市场行情的产品价格，须核实其对应收入是否有真实交易和合理定价依据，警惕虚高单价虚增收入。
4. **价格与市场行情对标验证公允性**：大宗商品/标准化产品应有公开市场价格参照，产品价格显著偏离市场行情需评估收入真实性和定价合理性。
5. **价格与销量的反向关系需合理**：正常需求规律下价格与销量应呈反向关系，价格上涨同时销量激增的异常组合需警惕虚构交易。
6. **勾稽关系**：产品单价 = 产品收入 ÷ 产品销量（D4-2）；单价 × 销量 = 收入；价格趋势 ↔ 成本趋势（D4-8毛利分析）↔ 市场行情，勾稽断裂为复核重点。

## checklist

### 一、同一产品价格趋势（高风险）

- [ ] 【必检】主要产品单价是否按期间列示趋势
- [ ] 【必检】产品单价是否用收入÷销量正确计算
- [ ] 【必检】价格趋势变动是否标注并说明原因
- [ ] 【必检】价格趋势是否与市场供需、行业价格走势匹配
- [ ] 【条件检查：若价格趋势突变】价格突变期间的交易是否核实
- [ ] 【风险检查】是否存在期末价格异常上涨虚增收入
- [ ] 【风险检查】价格上涨同时销量激增的异常组合是否核实

### 二、产品价格与成本联动（高风险）

- [ ] 【必检】产品价格变动是否与单位成本变动联动分析
- [ ] 【必检】价格与成本的差额（单位毛利）趋势是否合理
- [ ] 【必检】价格与成本背离的产品是否说明原因
- [ ] 【条件检查：若价成背离】成本降但价升/成本升但价降是否核实
- [ ] 【风险检查】是否存在虚高单价而成本未同步的虚增收入迹象

### 三、异常价格识别（高风险）

- [ ] 【必检】显著偏离历史价格的产品是否标注
- [ ] 【必检】异常高价产品的收入真实性是否核实
- [ ] 【必检】异常低价产品的商业合理性是否说明
- [ ] 【条件检查：若价格异常】异常价格对应合同/交易是否验证
- [ ] 【风险检查】是否存在虚高单价虚增收入
- [ ] 【风险检查】异常价格是否集中于特定客户或期末

### 四、价格与市场行情匹配（中风险）

- [ ] 【必检】标准化产品价格是否与公开市场行情对标
- [ ] 【必检】市场价格基准来源是否可靠
- [ ] 【必检】价格偏离市场行情的幅度及原因是否分析
- [ ] 【条件检查：若显著偏离市场】偏离市场价的收入真实性是否核实
- [ ] 【风险检查】是否存在价格显著偏离市场且无核心竞争力支撑

## risk_areas

### 高风险

1. **虚高单价虚增收入**：产品单价显著高于历史价格或市场行情但成本未同步，反映可能通过虚高单价虚增收入，涉及计价认定。
2. **期末价格异常上涨**：资产负债表日前产品价格异常上涨，配合期末放量虚增当期收入，是收入舞弊的隐蔽手段。
3. **价格与成本背离**：产品售价与单位成本明显背离且无合理解释，反映收入或成本可能失真。
4. **价格销量异常同增**：价格上涨同时销量激增违反需求规律，需警惕虚构交易或量价数据操纵。
5. **价格显著偏离市场行情**：标准化产品价格大幅偏离公开市场行情且无核心竞争力支撑，反映收入真实性存疑。

### 中风险

1. **价格趋势无法解释**：产品价格趋势无法用市场、成本、供需因素解释。
2. **异常低价倾销**：产品价格显著低于成本或市场价但未说明商业合理性。
3. **市场对标数据不可靠**：使用的市场价格基准来源不可靠或可比性差。
4. **单位毛利趋势异常**：产品单位毛利（价-成本）趋势异常波动无解释。

### 低风险

1. **价格计算口径不一**：不同期间单价计算口径不一致。
2. **分析样本不足**：仅分析少数产品价格，覆盖面不足。
3. **市场基准缺失**：无公开市场价格的定制产品缺少对标参照。
4. **交叉索引不完整**：与明细表、毛利分析、成本底稿的交叉引用不全。
