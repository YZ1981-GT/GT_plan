# D6-note-soe 合同资产附注披露复核提示词（国有企业）

## 概述

本提示词针对合同资产国有企业附注披露底稿（D6-note-soe，科目码1402）的复核，聚焦国有企业特定的附注披露要求：国有资产监管相关披露、关联交易（含与政府/国有控股单位交易）、预算执行相关信息、国资委要求的补充披露事项，以及与上市公司版本的差异关注点。合同资产多产生于工程施工、长期服务等履约周期较长的业务，国有企业（尤其工程建设类）合同资产金额往往重大，其披露须同时满足会计准则（CAS14/CAS37）和国资监管要求。

**法规依据：**
- 《企业会计准则第37号——金融工具列报》
- 《企业会计准则第14号——收入》
- 《企业会计准则第36号——关联方披露》
- 《企业国有资产法》
- 《中央企业财务决算报告管理办法》
- 《国有资产监督管理委员会关于加强中央企业财务决算管理工作有关事项的通知》

## tips

1. **国有企业合同资产披露有"双层"要求**：既满足CAS14/CAS37通用披露，又满足国资委财务决算报告的额外披露要求（如工程履约进度、大额合同资产逐户披露），两套要求互补不可替代。
2. **工程建设类国企合同资产是关注重点**：合同资产多源于工程施工按履约进度确认，需披露履约进度、已办未收金额及后续收款安排，长周期工程合同资产的可回收性是国资监管重点。
3. **国资委"三重一大"涉及合同资产核销**：重大合同资产核销须经"三重一大"决策程序，附注需披露本期核销的重大合同资产的决策过程和审批情况（与D6-9勾稽）。
4. **国有资产保值增值视角下的长账龄合同资产**：长账龄或后续履约存疑的合同资产累积可能被视为国有资产流失风险，需说明催收/推进履约措施及处置计划。
5. **关联方范围比一般企业更广**：除一般定义外，还需考虑同一国有控股股东控制的其他国有企业（"同受国有控制"关联方），但可按准则豁免条款简化部分披露。
6. **与上市版差异主要在监管层面**：基础披露框架（分类/账龄/减值变动/信用风险/ECL）与上市版相同，国企版额外增加国资监管相关信息，而非替代基础披露。

## checklist

### 一、基础披露完整性（与上市版共有）

- [ ] 合同资产的性质是否披露（收款权取决于时间流逝外的因素）
- [ ] 合同资产是否按业务性质/合同类型分类披露
- [ ] 账龄分析表是否完整列示（1年以内/1-2年/2-3年/3年以上）
- [ ] 减值准备变动表是否完整（期初/计提/转回/核销/其他/期末）
- [ ] 附注合同资产总额是否与审定表审定数一致
- [ ] 期初数/期末数可比信息是否完整列示
- [ ] 合同资产与合同负债的期末余额及关系是否披露

### 二、国有资产监管相关披露

- [ ] 3年以上长账龄合同资产是否单独披露金额、合同、客户及形成原因
- [ ] 长账龄或后续履约存疑合同资产的催收/推进履约措施是否披露
- [ ] 工程建设类合同资产的履约进度及已办未收金额是否披露
- [ ] 大额合同资产（超过单户限额标准）是否按国资委要求逐户披露
- [ ] 是否披露合同资产中涉及国有资产处置/划转的事项
- [ ] 合同资产减值损失对国有资本保值增值率的影响是否说明
- [ ] 是否披露与政府部门相关的合同资产（政府投资项目履约款）

### 三、关联交易披露（国企特定）

- [ ] 与控股股东及其关联企业的合同资产是否逐户列示
- [ ] 与同一母公司控制的其他国有企业的合同资产是否披露
- [ ] 是否运用"同受国家控制"关联方的豁免条款，如运用是否符合条件
- [ ] 关联方合同资产的交易实质是否清晰说明（经营性/工程性）
- [ ] 关联方合同定价方式是否披露（市场价/协议价/政府定价）
- [ ] 关联方合同资产的账龄、履约进度和减值准备是否单独披露
- [ ] 是否存在以合同资产名义挂账的资金性往来并予以说明

### 四、预算执行相关披露

- [ ] 本期合同资产实际结算/收回额与年度预算目标的对比是否披露
- [ ] 预算偏差超过一定比例（如20%）时是否说明原因
- [ ] 本期合同资产核销是否在年度核销预算额度内，超额是否追加审批
- [ ] 工程项目回款率是否与预算目标对比分析
- [ ] 新增大额合同资产是否属于预算内业务
- [ ] 期末合同资产余额是否超出年度资产预算

### 五、国资委要求的补充披露

- [ ] 本期核销的合同资产是否逐笔披露（金额/合同/客户/核销原因/审批程序）
- [ ] 核销是否经过"三重一大"决策程序（超过规定金额时）
- [ ] 是否编制合同资产清理处置方案并披露执行情况
- [ ] 合同资产中涉及法律诉讼/仲裁的金额及进展是否披露
- [ ] 是否披露合同资产涉及的担保/抵押/质押安排
- [ ] 长账龄且无法收回的合同资产是否已启动责任追究程序并披露

### 六、与上市版的差异关注点

- [ ] 国企版是否在上市版基础披露基础上增加国资监管层面补充信息
- [ ] 关联方范围是否已扩展至"同受国有控制"的企业
- [ ] 合同资产核销是否增加"三重一大"决策程序说明
- [ ] 是否增加预算执行偏差分析
- [ ] 是否增加长账龄合同资产的催收/推进履约/处置/责任追究信息
- [ ] 是否增加国有资本保值增值相关影响分析
- [ ] 是否补充工程建设类合同资产的履约进度专项披露

### 七、决算报表特殊要求

- [ ] 合同资产数据是否与年度财务决算报表一致
- [ ] 决算报表附加信息表（如资产质量分析表）中合同资产数据是否与本附注一致
- [ ] 合同资产中属于"不良资产"的部分是否按决算要求单独披露
- [ ] 集团合并层面内部合同资产抵销是否完整，抵销后余额是否与决算一致
- [ ] 合同资产减值损失是否纳入年度经营业绩考核的相关披露

## risk_areas

### 高风险

1. **长账龄合同资产未按国资要求披露**：3年以上合同资产未逐户说明原因、催收及推进履约措施，可能被认定为国有资产流失管理不到位。
2. **关联方合同资产范围遗漏**：未将同一国有控股股东下兄弟单位纳入关联方披露范围，违反CAS36和国资委要求。
3. **核销缺少"三重一大"程序说明**：大额合同资产核销未经集体决策或未披露决策过程，存在合规风险。
4. **以合同资产名义挂账资金占用未披露**：其他国企或政府部门长期占用资金以合同资产挂账未单独说明，掩盖国有资产流失。
5. **基础披露与审定表不勾稽**：附注合同资产各维度合计与审定表审定数不一致，属重大数据错误。

### 中风险

1. **预算执行偏差未充分说明**：合同资产结算/回收率远低于预算目标但未说明原因和改进措施。
2. **"同受国有控制"豁免适用不当**：不符合豁免条件却简化了同受国家控制关联方的披露。
3. **履约进度专项披露缺失**：工程建设类合同资产未披露履约进度及已办未收金额。
4. **核销责任追究信息缺失**：已核销的大额合同资产未说明是否启动责任追究程序。
5. **决算与审计口径差异未调节**：财务决算数据与审计后附注数据存在差异但未编制调节说明。

### 低风险

1. **披露格式未完全按决算报表模板**：附注格式与国资委决算报表模板有细微差异，但信息内容完整。
2. **资金占用利息说明简略**：关联方资金占用已披露但占用利息计算依据未详细说明。
3. **预算对比分析维度单一**：仅对比余额未对比周转率/回款率等多维度指标。
4. **历史年度信息追溯不完整**：合同资产增减变动的历史趋势分析仅覆盖2年而非国资委建议的3年。
