# D3-2 明细表复核提示词

## 概述

本提示词针对预收账款/合同负债明细表（D3-2）的复核，聚焦四大核心审计要点：客户信息完整性、按客户预收余额准确性、账龄分析正确性、履约义务与待确认收入分析。明细表是合同负债科目审计的基础数据底稿，承载按客户/合同维度的余额明细、账龄分布及履约进度，其数据质量直接影响长期挂账检查（D3-5）、收入确认时点判断、附注披露等后续审计程序的有效性。

**法规依据：**
- 《企业会计准则第14号——收入》
- 《企业会计准则第30号——财务报表列报》
- 《中国注册会计师审计准则第1301号——审计证据》
- 《中国注册会计师审计准则第1502号——对特殊项目审计证据的进一步考虑》

## tips

1. **客户信息完整性是明细表质量的基石**：明细表中每一行客户/合同记录必须具备完整的识别信息（客户名称、合同编号、关联方标志、履约状态等），空白客户或"其他"笼统归集可能掩盖长期挂账或虚假预收，关联方遗漏将直接影响披露完整性。
2. **余额准确性的核心是勾稽关系**：明细账合计必须与审定表 D3-1 期末审定数完全一致，期初余额必须与上年审定数衔接，任何差异需追溯至具体调整分录，不得存在无源差异。
3. **账龄分析揭示长期挂账风险**：账龄划分标准必须与公司会计政策一致，各账龄段金额合计必须等于客户余额，长账龄（超过1年）合同负债需逐笔标注原因，评估是否应确认收入、退回或转营业外收入。
4. **履约义务与待确认收入是CAS14核心判断**：明细表应区分已收款但尚未履约（待确认收入）与已部分履约的合同负债，关注是否存在已履约但仍挂账合同负债的情况（应结转收入）。
5. **明细表是多项后续程序的数据源**：长期挂账检查、关联方核查、收入确认时点测试、集中度披露等均以明细表数据为基础，明细表错误将沿数据链传导至多张底稿。
6. **关注明细与汇总的双向勾稽**：明细表各客户期末余额合计 = D3-1审定数；各客户余额 = 该客户各账龄段金额之和；各账龄段全部客户合计 = 账龄汇总数；长账龄合同负债合计 = D3-5长期挂账检查表金额。

## checklist

### 一、客户信息完整性（高风险）

- [ ] 【必检】客户名称是否完整、规范，无空白或"其他"笼统归集
- [ ] 【必检】是否标注关联方客户，关联方预收款项是否全部识别
- [ ] 【必检】合同编号/订单编号是否完整，是否可追溯至销售合同
- [ ] 【必检】履约状态是否标注（未履约/部分履约/已履约待结转）
- [ ] 【必检】客户清单是否与销售系统或合同台账一致
- [ ] 【条件检查：若有境外客户】境外客户预收款的交易真实性是否验证
- [ ] 【条件检查：若有长期挂账客户】长期挂账客户的合同履约进展是否评估
- [ ] 【风险检查】是否存在虚构预收或"资金占用"以应收/预收挂账的迹象
- [ ] 【风险检查】客户变动（新增/退出）是否符合行业特点和企业经营策略

### 二、按客户预收余额准确性（高风险）

- [ ] 【必检】明细表各客户期末余额合计是否与总账/审定表 D3-1 一致
- [ ] 【必检】明细表期初余额是否与上年审定期末数衔接
- [ ] 【必检】各客户余额计算是否正确（期初 + 本期预收 − 本期结转收入/退款 = 期末）
- [ ] 【必检】合同负债数据是否直接从系统导出，未经人工调整
- [ ] 【必检】含税预收款是否正确拆分合同负债与待转销项税额
- [ ] 【条件检查：若有外币预收款】外币折算汇率是否正确，汇兑损益是否准确
- [ ] 【条件检查：若有合并报表】内部交易抵销是否准确完整
- [ ] 【风险检查】是否存在余额异常波动（超过 30% 且无合理解释）
- [ ] 【风险检查】是否存在借方余额异常（预付/退款错分为合同负债）

### 三、账龄分析正确性（高风险）

- [ ] 【必检】账龄划分标准是否与公司会计政策一致（1年以内/1-2年/2-3年/3年以上）
- [ ] 【必检】各客户各账龄段金额之和是否等于该客户合同负债余额
- [ ] 【必检】全部客户各账龄段合计是否与账龄汇总一致
- [ ] 【必检】账龄起算日是否以收款日或合同签订日为准，标准是否统一
- [ ] 【必检】长账龄（1年以上）合同负债是否逐笔标注原因及处理计划
- [ ] 【条件检查：若有部分结转】部分结转收入是否按正确顺序冲减
- [ ] 【风险检查】是否存在人为调整账龄的迹象（如通过退款再收款推迟账龄）
- [ ] 【风险检查】长账龄比例是否异常上升但未评估收入确认或退回

### 四、履约义务与待确认收入分析（中风险）

- [ ] 【必检】明细表是否区分待确认收入与已部分履约的合同负债
- [ ] 【必检】各合同的履约进度是否有支持性证据（发货单/验收单/服务记录）
- [ ] 【必检】是否存在已履约完成但仍挂账合同负债的情况（应结转收入）
- [ ] 【必检】预计未来12个月内确认为收入的合同负债金额是否可估计
- [ ] 【条件检查：若有分期履约合同】履约进度百分比法的计算依据是否合理
- [ ] 【条件检查：若有可变对价】可变对价对合同负债金额的影响是否评估
- [ ] 【风险检查】是否存在通过延迟确认收入以调节利润（利润蓄水池）的迹象
- [ ] 【风险检查】履约义务判断是否与收入确认底稿（D4）一致

## risk_areas

### 高风险

1. **应确认收入未结转**：已履约完成的合同负债长期挂账未结转收入，虚增负债、少计收入，构成收入完整性错报。
2. **余额与总账不一致**：明细合计数与审定表/总账存在差异未调节，表明可能存在遗漏或错误记录。
3. **账龄人为操纵**：通过退款再收款、虚假履约等方式人为调整账龄，掩盖长期挂账风险。
4. **虚构预收**：明细表中出现无实际合同支持的预收款，或以合同负债名义挂账资金占用，涉及存在性认定。
5. **关联方未识别**：明细表中关联方预收款项未标注或遗漏，影响关联交易披露的完整性。

### 中风险

1. **含税拆分错误**：含增值税预收款未拆分待转销项税额，导致合同负债虚增。
2. **客户信息不完整**：部分客户缺少合同编号、履约状态等关键信息，影响收入确认判断。
3. **账龄划分标准不一致**：不同客户或不同期间采用不同的账龄起算标准，影响账龄分析的可比性。
4. **履约进度判断缺乏证据**：合同履约百分比无支持性证据，可能被用于操纵收入确认时点。
5. **系统数据差异**：销售系统与财务系统的预收数据存在差异，数据完整性存疑。

### 低风险

1. **格式规范性问题**：明细表格式不统一、排列顺序不规范等形式问题。
2. **辅助信息缺失**：缺少客户行业分类、合同类型等辅助分析信息。
3. **小额散户归集**：小额客户归集为"其他"时未附明细清单。
4. **交叉索引不完整**：与长期挂账检查底稿、收入确认底稿的交叉引用标注不全。
