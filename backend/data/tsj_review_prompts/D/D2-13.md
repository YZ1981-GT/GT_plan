# D2-13 业务模式复核提示词

## 适用底稿
业务模式判断表（D2-13），含 4 项 Y/N 判断、业务模式组合表、推荐计量模式（摊余成本/FVOCI/FVTPL）及 SPPI 测试关联。

## 概述
业务模式决定金融资产分类与计量，直接影响 D2 余额列报及 D2-12 保理终止确认。复核须验证：四问是否完整回答、组合划分合理、推荐模式与合同现金流特征一致。

---

## tips

1. **四问完整性**：`allAnswered` 为 false 时不得出具分类结论；每项 Y/N 须有业务证据支持。
2. **出售 vs 持有**：若存在频繁出售、保理终止确认（D2-12），业务模式不应简单认定为「仅为收取合同现金流」。
3. **推荐模式**：`recommendedModel` 须与四问答案、组合表各行 `measurement` 一致，不能结论与表格矛盾。
4. **SPPI 测试**：合同现金流是否仅为本金+利息，须与 D2-8 政策及合同条款核对。
5. **与 D5/D1 联动**：出售模式应收/票据与 D5-明细、D1-6 勾稽芯片指向一致。
6. **变更处理**：业务模式变更是否作为会计政策/估计变更处理并披露。

## checklist

### 高风险检查项

- [ ] 4 项业务模式判断问题是否全部作答且有证据支持
- [ ] 推荐计量模式（摊余成本/FVOCI/FVTPL）与判断结论逻辑一致
- [ ] 存在 D2-12 保理终止确认或频繁出售时，业务模式是否仍合理认定为持有
- [ ] 业务模式组合表各行计量属性与推荐模式无矛盾
- [ ] SPPI 测试结论是否支持所选计量分类
- [ ] 与财务报表附注金融资产分类披露一致

### 中风险检查项

- [ ] 不同业务线/产品组合划分是否合理（不得仅为达成目标分类而拆分）
- [ ] 新增业务线是否补充业务模式评估
- [ ] 审计说明是否涵盖 CAS22 分类框架及关键判断
- [ ] 与 D2-1 列报分类（流动/非流动、出售模式）一致
- [ ] 索引指向合同、董事会纪要、保理协议等支持性文件

### 低风险检查项

- [ ] 组合表列头、合计完整
- [ ] 导入导出 round-trip 正确
- [ ] 结论模板选用匹配项目情况

## risk_areas

### 高风险

- 业务模式判断与事实不符，导致错误分类（如应 FVTPL 却按摊余成本）
- 四问未答全即确定推荐模式
- 与 D2-12 终止确认判断相互矛盾

### 中风险

- 组合划分过粗或过细缺乏依据
- SPPI 测试文档不足

### 低风险

- 说明文字、格式不规范

## 跨底稿勾稽

- D2-13 推荐模式 ↔ D2-1 审定表列报分类
- D2-13 出售判断 ↔ D2-12 保理终止确认
- D2-13 组合金额 ↔ D2-2 明细按业务线汇总
