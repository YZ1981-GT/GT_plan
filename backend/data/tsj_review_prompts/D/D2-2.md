# D2-2 应收账款明细表复核提示词

## 概述

本提示词针对应收账款明细表（D2-2）的复核，聚焦四大核心审计要点：客户信息完整性、余额准确性、账龄分析正确性、前五大客户集中度分析。明细表是应收账款科目审计的基础数据底稿，承载按客户维度的余额明细和账龄分布，其数据质量直接影响坏账准备计提（D2-3）、函证选样、集中度风险判断等后续审计程序的有效性。

**法规依据：**
- 《企业会计准则第22号——金融工具确认和计量》
- 《企业会计准则第37号——金融工具列报》
- 《中国注册会计师审计准则第1301号——审计证据》
- 《中国注册会计师审计准则第1502号——对特殊项目审计证据的进一步考虑》

---

## tips

1. **客户信息完整性是明细表质量的基石**：明细表中每一行客户记录必须具备完整的识别信息（名称、信用等级、关联方标志等），空白客户或"其他"笼统归集可能掩盖虚构交易，关联方遗漏将直接影响披露完整性。
2. **余额准确性的核心是勾稽关系**：明细账合计必须与审定表 D2-1 期末审定数完全一致，期初余额必须与上年审定数衔接，任何差异需追溯至具体调整分录，不得存在无源差异。
3. **账龄分析直接驱动坏账计提**：账龄划分标准必须与公司会计政策一致，各账龄段金额合计必须等于客户余额，人为调整账龄（如通过滚动付款缩短账龄）将导致ECL模型输入失真、坏账准备计提不足。
4. **前五大客户集中度揭示信用风险集中敞口**：集中度过高（如超过50%）意味着单一客户流失可能导致重大坏账，需评估对持续经营假设的影响，并判断附注披露是否充分。
5. **明细表是多项后续程序的数据源**：函证选样、坏账准备分组、集中度披露、关联方交易核查等均以明细表数据为基础，明细表错误将沿数据链传导至多张底稿。
6. **关注明细与汇总的双向勾稽**：明细表各客户期末余额合计 = D2-1审定数；各客户余额 = 该客户各账龄段金额之和；各账龄段全部客户合计 = D2-3账龄汇总数；前五大客户余额合计 ÷ 全部余额合计 = 集中度比例。

## checklist

### 一、客户信息完整性（高风险）

- [ ] 【必检】客户名称是否完整、规范，无空白或"其他"笼统归集
- [ ] 【必检】是否标注关联方客户，关联方应收账款是否全部识别
- [ ] 【必检】客户状态是否标注（正常/异常/已注销），异常客户是否有说明
- [ ] 【必检】客户清单是否与销售系统或ERP数据一致
- [ ] 【必检】是否存在多个客户使用同一地址、联系方式或银行账户的情况
- [ ] 【必检】新增重要客户是否有背景调查和信用评估记录
- [ ] 【条件检查：若有境外客户】境外客户身份及交易真实性是否验证
- [ ] 【条件检查：若有长期挂账客户】长期挂账客户的持续经营状况是否评估
- [ ] 【条件检查：若有大额应收客户】大额客户的经营规模是否与其采购规模匹配
- [ ] 【风险检查】是否存在虚构客户或"壳公司"迹象
- [ ] 【风险检查】客户变动（新增/退出）是否符合行业特点和企业经营策略

### 二、余额准确性（高风险）

- [ ] 【必检】明细表各客户期末余额合计是否与总账/审定表 D2-1 一致
- [ ] 【必检】明细表期初余额是否与上年审定期末数衔接
- [ ] 【必检】各客户余额计算是否正确（期初 + 本期增加 − 本期减少 = 期末）
- [ ] 【必检】应收账款数据是否直接从系统导出，未经人工调整
- [ ] 【必检】不同系统间应收账款数据是否一致（销售系统 vs 财务系统）
- [ ] 【必检】应收账款余额与函证回函金额差异是否合理解释
- [ ] 【必检】期初期末调节是否准确，调整事项是否有支持性证据
- [ ] 【条件检查：若有外币应收账款】外币折算汇率是否正确，汇兑损益是否准确
- [ ] 【条件检查：若有合并报表】内部交易抵销是否准确完整
- [ ] 【条件检查：若有保理/质押】保理或质押相关调整是否正确反映
- [ ] 【风险检查】是否存在余额异常波动（超过 30% 且无合理解释）
- [ ] 【风险检查】是否存在大额期后调整，可能为操纵期末余额
- [ ] 【风险检查】是否存在借方余额异常（应付款项错分为应收）

### 三、账龄分析正确性（高风险）

- [ ] 【必检】账龄划分标准是否与公司会计政策一致（1年以内/1-2年/2-3年/3年以上等）
- [ ] 【必检】各客户各账龄段金额之和是否等于该客户应收余额
- [ ] 【必检】全部客户各账龄段合计是否与坏账准备底稿 D2-3 的账龄汇总一致
- [ ] 【必检】账龄起算日是否以发票日期或收入确认日为准，标准是否统一
- [ ] 【必检】同一客户多笔交易的账龄是否分别计算（先进先出或个别认定）
- [ ] 【必检】长账龄（2年以上）应收账款是否逐笔标注原因及可回收性评估
- [ ] 【条件检查：若有信用期变更】信用期变更是否影响账龄计算，影响金额是否准确
- [ ] 【条件检查：若有部分收款】部分收款是否按正确顺序冲减（先冲早期欠款）
- [ ] 【条件检查：若有债务重组】重组应收的账龄是否重新起算并有依据
- [ ] 【风险检查】是否存在人为调整账龄的迹象（如通过转账、滚动付款推迟账龄）
- [ ] 【风险检查】长账龄比例是否异常上升但坏账计提未相应调整
- [ ] 【风险检查】是否存在跨期记录销售以改变账龄分布的情况

### 四、前五大客户集中度分析（中风险）

- [ ] 【必检】前五大客户名称、余额、占比是否列示完整
- [ ] 【必检】前五大客户占应收账款总额比例是否计算正确
- [ ] 【必检】前五大客户变动情况是否分析（与上年对比新进/退出客户及原因）
- [ ] 【必检】前五大客户应收余额变动是否与销售收入变动匹配
- [ ] 【必检】前五大客户中是否包含关联方，若有是否单独标注
- [ ] 【必检】前五大客户的账龄结构是否合理，是否存在长期未回款
- [ ] 【必检】前五大客户的期后回款情况是否良好
- [ ] 【条件检查：若集中度超过50%】是否评估单一客户依赖风险及对持续经营假设的影响
- [ ] 【条件检查：若前五大客户发生重大变动】变动原因是否调查，是否存在异常
- [ ] 【条件检查：若前五大客户含新客户】新客户进入前五大的合理性是否验证
- [ ] 【风险检查】是否存在前五大客户集中度过高导致的信用风险集中
- [ ] 【风险检查】是否存在虚增前五大客户交易以美化收入结构的迹象
- [ ] 【风险检查】前五大客户的行业分布是否过于集中（同行业风险共振）

## risk_areas

### 高风险

1. **虚构客户或交易**：明细表中出现无实际经营的"壳公司"客户，或客户信息无法验证，涉及存在性认定。
2. **余额与总账不一致**：明细合计数与审定表/总账存在差异未调节，表明可能存在遗漏或错误记录。
3. **账龄人为操纵**：通过滚动付款、虚假收款后退回等方式人为缩短账龄，导致坏账计提不足。
4. **长账龄未充分减值**：2年以上应收账款金额重大但未逐笔评估可回收性，坏账准备计提比例与实际回收经验不符。
5. **关联方未识别**：明细表中关联方客户未标注或遗漏，影响关联交易披露的完整性。

### 中风险

1. **前五大客户集中度过高**：单一或少数客户占比过大（如前五大超过 60%），存在信用风险集中敞口。
2. **客户信息不完整**：部分客户缺少信用等级、联系方式等关键信息，影响坏账风险判断。
3. **账龄划分标准不一致**：不同客户或不同期间采用不同的账龄起算标准，影响账龄分析的可比性。
4. **新增大客户异常**：新进入前五大客户的交易金额与其公开信息的经营规模不匹配。
5. **系统数据差异**：销售系统与财务系统的应收数据存在差异，数据完整性存疑。

### 低风险

1. **格式规范性问题**：明细表格式不统一、排列顺序不规范等形式问题。
2. **辅助信息缺失**：缺少客户行业分类、地区分布等辅助分析信息。
3. **小额散户归集**：小额客户归集为"其他"时未附明细清单。
4. **期后回款信息滞后**：期后回款数据未及时更新（非金额错误）。
5. **交叉索引不完整**：与函证底稿、坏账底稿的交叉引用标注不全。
