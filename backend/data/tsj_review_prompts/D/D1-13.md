# D1-13 抽样凭证检查表复核提示词

## 概述

本提示词针对应收票据抽样凭证检查表（D1-13）的复核，聚焦四大核心审计要点：样本选取方法合理性、凭证核对完整性、检查比例达标性、异常交易标注充分性。应收票据凭证检查须覆盖票据收取（销售回款→票据）、背书转出、贴现、到期兑付的完整交易链，核对票据实物/ECDS 记录、贸易背景单据（合同/发票/发货单）、银行贴现单据等，验证票据交易的真实性、存在性和截止准确性，并按 CAS1314 要求达到计划检查比例。

**法规依据：**
- 《中国注册会计师审计准则第1314号——审计抽样》
- 《中国注册会计师审计准则第1301号——审计证据》
- 《中国注册会计师审计准则第1141号——财务报表审计中与舞弊相关的责任》

## tips

1. **样本选取应与应收票据风险评估匹配**：高风险领域（商业承兑汇票、关联方票据、大额票据、期末集中收取票据）应作为必选样本，银行承兑汇票风险较低可合理抽样。
2. **凭证核对须覆盖票据完整交易链**：收取环节核对贸易背景（销售合同→发货→发票→票据）；背书/贴现环节核对协议/银行单据；兑付环节核对银行到账，仅核对票据本身不足以验证真实性。
3. **票据真实性核对须多方验证**：核对票据实物要素或 ECDS 系统登记、贸易背景单据、承兑人信息，防范无真实贸易背景的融资性票据和虚构票据。
4. **检查比例应满足 CAS1314 要求**：大额票据（超重要性水平）宜全覆盖，其余合理抽样；分方向计算借方（本期收取）和贷方（本期背书/贴现/兑付）检查比例。
5. **异常交易标注需明确类型**：金额异常（整数/雷同/临近审批权限）、时间异常（期末集中收取）、对手方异常（关联方/新客户/承兑人可疑）、业务逻辑异常（无贸易背景/票号连号）。
6. **职业怀疑贯穿始终**：对期末集中收取票据（可能虚构收入换票据）、关联方对开票据、无贸易背景票据保持警觉，记录质疑过程和替代程序。

## checklist

### 一、样本选取方法合理性

- [ ] 【必检】样本选取方法是否与识别的重大错报风险相匹配
- [ ] 【必检】抽样方法是否符合 CAS1314 要求（统计/非统计抽样选择有据）
- [ ] 【必检】大额票据（超重要性水平）是否100%全覆盖检查
- [ ] 【必检】高风险票据（商承/关联方/大额/期末集中收取）是否纳入必选样本
- [ ] 【必检】抽样总体是否完整（从完整票据台账导出，未人为排除）
- [ ] 【条件检查：若采用MUS】抽样间隔是否基于可容忍错报和总体规模正确计算
- [ ] 【风险检查】样本是否覆盖背书、贴现、质押、兑付各类交易

### 二、凭证核对完整性

- [ ] 【必检】票据收取是否核对贸易背景（销售合同/发货单/发票）
- [ ] 【必检】票据实物要素或 ECDS 系统登记是否核对一致
- [ ] 【必检】背书转出票据是否核对背书协议/用途单据
- [ ] 【必检】贴现票据是否核对贴现协议、贴现率、银行贴现单据、到账流水
- [ ] 【必检】到期兑付票据是否核对银行到账凭证
- [ ] 【必检】异常交易是否全部标注并记录异常类型和初步判断
- [ ] 【条件检查：若有无贸易背景票据】是否核查商业实质并实施追加程序
- [ ] 【风险检查】期末突增的应收票据对应凭证是否重点核查

### 三、检查比例达标性

- [ ] 【必检】总体检查比例（已检查金额÷总体金额）是否达到计划水平
- [ ] 【必检】借方发生额（本期收取票据）检查比例是否达标
- [ ] 【必检】贷方发生额（本期背书/贴现/兑付）检查比例是否达标
- [ ] 【必检】商业承兑汇票检查比例是否高于银行承兑汇票
- [ ] 【条件检查：若比例不达标】是否说明原因并评估是否需补充样本
- [ ] 【风险检查】高风险层检查比例是否显著高于低风险层

### 四、异常交易标注充分性

- [ ] 【必检】金额异常（整数/雷同/临近审批权限/超重要性）是否标注
- [ ] 【必检】时间异常（期末集中收取/非工作时间/资产负债表日前后）是否标注
- [ ] 【必检】对手方异常（关联方/新客户/承兑人可疑）是否标注
- [ ] 【必检】业务逻辑异常（无贸易背景/票号连号/对开票据）是否标注
- [ ] 【必检】异常标注是否包含异常类型+描述+涉及金额+初步判断
- [ ] 【风险检查】期末集中收取票据是否实施截止测试
- [ ] 【风险检查】发现的异常是否追踪解决或提交进一步调查

## risk_areas

### 高风险

1. **虚构票据未识别**：无真实贸易背景或票号连号/金额雷同的虚构票据未在抽样中识别，涉及存在性舞弊。
2. **样本选取偏差**：抽样方法不当导致高风险的商业承兑汇票、关联方票据、期末集中收取票据未被覆盖。
3. **截止性错误**：期末集中收取票据（可能虚构收入换取票据）未实施截止测试，跨期交易未识别。
4. **贸易背景缺失**：融资性票据缺乏销售合同/发票支持，未核查商业实质。
5. **关联方对开票据未核查**：关联方票据混入普通样本，未实施针对性的商业实质和公允性核查。

### 中风险

1. **检查比例不足**：实际检查比例低于计划水平，审计证据不充分。
2. **凭证核对深度不够**：仅核对票据本身而未核对完整贸易背景交易链。
3. **贴现单据核对不充分**：贴现票据的银行单据、到账流水核对不到位。
4. **分层不合理**：抽样分层未体现银承/商承风险差异。
5. **异常追踪不彻底**：发现的异常交易未彻底追踪解决。

### 低风险

1. **记录不完整**：抽样参数/选取过程/核对结果记录不完整，影响可追溯性。
2. **索引缺失**：与审定表/分类明细/背书贴现/函证底稿的交叉索引不完整。
3. **格式不规范**：检查结果记录格式不统一。
4. **检查比例公式列示不清**：分子分母口径未清晰说明。
