# D6-1 合同资产审定表复核提示词

## 概述

本提示词针对合同资产审定表（D6-1，科目码1402）的复核，聚焦四大核心审计要点：期初期末勾稽、试算平衡表1402核对、审计调整完整性、分类列报与合同资产/应收账款划分。合同资产是CAS14收入准则引入的科目，代表企业已向客户转让商品但收款权尚取决于时间流逝之外因素（如尚需完成其他履约义务）的权利。审定表是合同资产审计的枢纽底稿，承载未审数→调整→审定数的完整链路，划分错误或勾稽断裂均可能导致重大错报。

**法规依据：**
- 《企业会计准则第14号——收入》
- 《企业会计准则第22号——金融工具确认和计量》
- 《企业会计准则第37号——金融工具列报》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **合同资产与应收账款的划分是审定表复核的首要要点**：合同资产的收款权取决于时间流逝之外的因素（如后续履约义务），而应收账款的收款权仅取决于时间流逝，审定表中1402科目不应混入应仅按时间即可无条件收款的应收账款。
2. **期初期末勾稽是审定表的生命线**：期初审定数必须等于上年期末审定数（承前启后），任何差异需追溯至调整分录、会计政策变更或首次执行CAS14的追溯调整，不得存在无源差异。
3. **试算平衡表是勾稽的第一道防线**：审定表合同资产审定数合计必须与试算平衡表1402科目审定数完全一致，合同资产减值准备须与对应备抵科目审定数一致（借贷方向核对）。
4. **审计调整完整性决定审定数可靠性**：所有账项调整（AJE）和重分类调整（RJE）须完整反映在审定表，尤其关注合同资产转应收账款、合同资产减值的调整是否遗漏。
5. **合同资产的重分类需关注流动性与履约进度**：审定表中合同资产按预计收回时间分类，超过一年的部分是否重分类至其他非流动资产，需与履约进度（D6-2）勾稽。
6. **审定表是跨底稿勾稽的中心节点**：审定数应与明细表（D6-2）合计、减值准备（D6-3）、ECL计算（D6-8）、试算平衡表、附注披露形成闭环勾稽，任何节点断裂均为复核重点。

## checklist

### 一、期初期末勾稽

- [ ] 审定表期初未审数是否等于上年审定表期末审定数（承前启后核对）
- [ ] 期初审定数是否等于期初未审数加期初调整（含首次执行CAS14追溯调整）
- [ ] 期末审定数是否等于期初审定数加本期借方发生额减本期贷方发生额（加减审计调整）
- [ ] 审定表各行项目期初期末变动是否与明细表（D6-2）增减变动一致
- [ ] 合同资产转应收账款的结转是否在期末余额变动中正确反映
- [ ] 是否存在期初数据被人为修改但未留痕的情况

### 二、试算平衡表核对

- [ ] 审定表合同资产审定数合计是否与试算平衡表1402科目审定数一致
- [ ] 合同资产减值准备审定数是否与对应备抵科目审定数一致（借贷方向核对）
- [ ] 试算平衡表未审数、调整数（AJE+RJE）与审定表对应列是否一致
- [ ] 审定表各明细口径审定数之和是否等于1402一级科目审定数
- [ ] 是否存在试算平衡表已更新但审定表未同步的情况

### 三、审计调整完整性

- [ ] 所有已确认的账项调整分录（AJE）是否已完整反映在审定表调整列
- [ ] 所有已确认的重分类调整分录（RJE）是否已完整反映在审定表重分类列
- [ ] 调整分录借贷方金额是否平衡，调整后审定数是否等于未审数+AJE+RJE
- [ ] 合同资产减值计提调整是否与D6-3/D6-8勾稽一致
- [ ] 建议但未调整的错报是否已记录于未调整错报汇总表（SUD）并与A13交叉验证
- [ ] 调整分录是否均有充分审计证据支持和适当层级审批

### 四、分类列报与划分准确性

- [ ] 合同资产与应收账款的划分是否正确（收款权是否仅取决于时间流逝）
- [ ] 合同资产与合同负债是否按同一合同净额列示（未不当总额列示）
- [ ] 超过一年预计收回的合同资产是否正确分类或披露为非流动
- [ ] 关联方合同资产是否在审定表中单独可识别
- [ ] 合同资产净额（扣除减值准备后）在报表列示是否准确
- [ ] 审定表分类是否与财务报表附注披露的分类一致

## risk_areas

### 高风险

1. **合同资产与应收账款划分错误**：将应仅按时间流逝即可无条件收款的债权错列为合同资产，或反之，导致列报错误并影响ECL计量方法适用。
2. **期初期末不勾稽**：期初审定数与上年期末审定数不一致，可能存在未经授权的调整或首次执行CAS14追溯调整未正确处理。
3. **审计调整遗漏**：已确认的合同资产减值或转应收账款调整未反映在审定表，导致审定数失真。
4. **试算平衡表与审定表不一致**：两者1402科目数据口径不一致，意味着存在未被发现的汇总错误或调整遗漏。
5. **减值准备扣减错误**：合同资产减值准备方向错误或与D6-3/D6-8不勾稽，导致合同资产净额虚增。

### 中风险

1. **明细与汇总不勾稽**：审定表各行项目合计与明细表（D6-2）总计不一致，可能存在明细遗漏或重复。
2. **流动性分类不当**：长期限合同资产仍分类为流动资产，未按预计收回时间正确划分。
3. **合同资产与合同负债不当抵销**：不同合同的合同资产与合同负债相互抵销，违反净额列示的合同层面要求。
4. **重分类调整方向错误**：RJE借贷方向颠倒导致审定数偏离真实值。
5. **审定表与附注披露口径不一致**：审定表分类与附注中的分类披露不一致，影响信息一致性。

### 低风险

1. **审定表格式不规范**：列标题、行顺序、编号等格式问题不影响数据准确性，但影响可读性。
2. **底稿交叉索引不完整**：审定表未与试算平衡表、明细表、减值准备、调整分录建立完整索引引用。
3. **辅助说明不充分**：变动较大的行项目未附简要说明，增加复核理解难度。
4. **历史数据对比缺失**：审定表未列示前期可比数据，不便于分析趋势和异常。
