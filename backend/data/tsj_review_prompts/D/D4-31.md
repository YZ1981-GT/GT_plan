# D4-31 客户访谈明细表复核提示词

## 概述

本提示词针对营业收入客户访谈明细表（D4-31）的复核，聚焦单个客户访谈记录的完整性、交易金额确认、合同履行确认。访谈明细表记录对单个客户访谈的详细过程与结果，是D4-30访谈汇总的底层支撑。复核须确认每份访谈记录要素齐全、交易金额与合同履行经客户逐项确认、访谈过程真实可追溯，为收入真实性判断提供可靠的一手证据。

**法规依据：**
- 《企业会计准则第14号——收入》
- 《中国注册会计师审计准则第1141号——财务报表审计中与舞弊相关的责任》
- 《中国注册会计师审计准则第1301号——审计证据》

## tips

1. **访谈明细须要素齐全**：单份访谈记录应包含访谈时间、地点/方式、访谈对象姓名职务、审计方参与人员、访谈内容、客户确认结果、佐证材料，缺一影响记录可靠性。
2. **交易金额须逐项确认**：访谈应就本期交易金额、期末往来余额与客户逐项核对确认，确认结果应精确到金额，模糊的"大致确认"证据力不足。
3. **合同履行确认验证收入实质**：应就合同签订、货物/服务交付、验收、款项支付等履约环节向客户确认，验证收入确认所依据的履约义务确已完成（CAS14）。
4. **访谈对象适当性是证据有效性前提**：访谈对象须为熟悉且有权确认交易的客户方人员，记录其姓名职务并核实身份，避免访谈无关人员使确认无效。
5. **访谈过程真实可追溯**：访谈应留存录音/影像/签字确认/名片等佐证，访谈记录须能还原真实访谈过程，警惕事后补记或伪造的访谈记录（CAS1141）。
6. **明细与汇总、其他程序勾稽**：单份访谈明细结果须汇总至D4-30，并与该客户的函证、交易记录、资金流一致，明细中的异常须在汇总层面得到反映和处理。

## checklist

### 一、访谈记录完整性

- [ ] 访谈时间、地点/方式是否记录
- [ ] 访谈对象姓名、职务是否记录并核实
- [ ] 审计方参与人员是否记录
- [ ] 访谈内容是否详细记录
- [ ] 客户确认结果是否明确记录
- [ ] 佐证材料（录音/影像/签字/名片）是否留存

### 二、交易金额确认

- [ ] 本期交易金额是否与客户逐项核对确认
- [ ] 期末往来余额是否经客户确认
- [ ] 确认金额是否精确并与账面记录比对
- [ ] 金额差异是否记录并说明
- [ ] 客户是否能说明主要交易的具体内容
- [ ] 大额/异常交易是否重点确认

### 三、合同履行确认

- [ ] 合同签订情况是否经客户确认
- [ ] 货物/服务交付情况是否经客户确认
- [ ] 验收情况是否经客户确认（如适用）
- [ ] 款项支付情况是否经客户确认
- [ ] 履约义务是否确已完成（支持收入确认，CAS14）
- [ ] 是否存在客户否认或无法确认履约的情况

### 四、真实性与勾稽

- [ ] 访谈对象是否为客户方熟悉且有权确认交易人员
- [ ] 访谈佐证是否充分支持记录的真实性
- [ ] 是否存在事后补记或伪造访谈记录的迹象
- [ ] 访谈明细结果是否汇总至D4-30
- [ ] 访谈结果是否与该客户函证/交易记录/资金流一致
- [ ] 底稿是否记录访谈方法及交叉索引

## risk_areas

### 高风险

1. **客户否认交易或履约**：单份访谈中客户否认交易存在、否认收到货物或否认履约，直接指向虚构收入（CAS1141）。
2. **访谈记录伪造**：访谈记录事后补记或伪造，无真实佐证支撑，访谈证据完全失效。
3. **访谈对象无权/身份不实**：访谈对象非有权人员或身份未核实，确认结果无效。
4. **交易金额确认严重不符**：客户确认金额与账面存在重大差异且无法解释，收入真实性存疑。

### 中风险

1. **履约确认不充分**：仅确认交易存在未确认货物交付/验收/付款，履约验证不完整。
2. **金额确认模糊**：客户仅"大致确认"未精确核对金额，确认证据力不足。
3. **佐证材料不足**：访谈缺少录音/影像/签字等佐证，记录真实性难以验证。
4. **访谈内容记录简略**：访谈内容记录过于简单，无法还原访谈过程和确认深度。

### 低风险

1. **记录要素不齐**：访谈时间/地点/对象职务等要素记录不完整。
2. **佐证格式不规范**：佐证材料留存格式不统一。
3. **交叉索引缺失**：与访谈汇总、函证、收入明细的交叉引用不完整。
