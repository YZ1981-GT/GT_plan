# D7-1 合同负债审定表复核提示词

## 概述

本提示词针对合同负债审定表（D7-1，科目码2205）的复核，聚焦四大核心审计要点：期初期末勾稽、试算平衡表2205核对、审计调整完整性、分类列报与完整性。合同负债是CAS14收入准则引入的负债科目，代表企业已收或应收客户对价而应向客户转让商品的义务（预收性质）。审定表是合同负债审计的枢纽底稿，承载未审数→调整→审定数的完整链路。合同负债作为负债类科目，完整性认定尤为关键（低估负债即高估收入），任何勾稽断裂或分类错误均可能导致重大错报。

**法规依据：**
- 《企业会计准则第14号——收入》
- 《企业会计准则第37号——金融工具列报》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **合同负债的完整性是审定表复核的首要认定**：合同负债低估意味着收入提前确认（虚增收入），审定表须核对所有已收对价而未履约的义务是否完整确认为合同负债，防止漏记负债。
2. **期初期末勾稽是审定表的生命线**：期初审定数必须等于上年期末审定数（承前启后），任何差异需追溯至调整分录、会计政策变更或首次执行CAS14追溯调整，不得存在无源差异。
3. **试算平衡表是勾稽的第一道防线**：审定表合同负债审定数合计必须与试算平衡表2205科目审定数完全一致（贷方余额），差异意味着存在未记录的调整或汇总错误。
4. **合同负债的减少即收入确认**：本期合同负债借方发生额对应本期履约确认的收入，审定表期末余额变动须与收入确认（履约进度）勾稽，异常减少可能为提前确认收入。
5. **合同负债与预收账款、合同资产的划分与列报**：审定表须正确区分合同负债与其他预收性质款项，同一合同下合同负债与合同资产按净额列示，超过一年的合同负债流动性分类须正确。
6. **审定表是跨底稿勾稽的中心节点**：审定数应与明细表（D7-2）合计、账龄分析（D7-4）、试算平衡表、收入底稿、附注披露形成闭环勾稽，任何节点断裂均为复核重点。

## checklist

### 一、期初期末勾稽

- [ ] 审定表期初未审数是否等于上年审定表期末审定数（承前启后核对）
- [ ] 期初审定数是否等于期初未审数加期初调整（含首次执行CAS14追溯调整）
- [ ] 期末审定数是否等于期初审定数加本期贷方发生额减本期借方发生额（加减审计调整）
- [ ] 审定表各行项目期初期末变动是否与明细表（D7-2）增减变动一致
- [ ] 本期合同负债借方（结转收入）是否与收入确认勾稽
- [ ] 是否存在期初数据被人为修改但未留痕的情况

### 二、试算平衡表核对

- [ ] 审定表合同负债审定数合计是否与试算平衡表2205科目审定数一致（贷方余额）
- [ ] 试算平衡表未审数、调整数（AJE+RJE）与审定表对应列是否一致
- [ ] 审定表各明细口径审定数之和是否等于2205一级科目审定数
- [ ] 是否存在借方余额异常（合同负债出现借方余额可能为分类错误）
- [ ] 是否存在试算平衡表已更新但审定表未同步的情况

### 三、审计调整完整性

- [ ] 所有已确认的账项调整分录（AJE）是否已完整反映在审定表调整列
- [ ] 所有已确认的重分类调整分录（RJE）是否已完整反映在审定表重分类列
- [ ] 调整分录借贷方金额是否平衡，调整后审定数是否等于未审数+AJE+RJE
- [ ] 合同负债补记（漏记负债/提前确认收入的更正）调整是否完整
- [ ] 建议但未调整的错报是否已记录于未调整错报汇总表（SUD）并与A13交叉验证
- [ ] 调整分录是否均有充分审计证据支持和适当层级审批

### 四、分类列报与完整性

- [ ] 合同负债与预收账款、其他应付款的划分是否正确
- [ ] 同一合同下合同负债与合同资产是否按净额列示（未不当总额列示）
- [ ] 超过一年预计履约的合同负债是否正确分类或披露为非流动
- [ ] 关联方合同负债是否在审定表中单独可识别
- [ ] 是否存在应确认为合同负债却挂其他科目（漏记负债虚增收入）的情况
- [ ] 审定表分类是否与财务报表附注披露的分类一致

## risk_areas

### 高风险

1. **合同负债漏记虚增收入**：已收对价而未履约的义务未完整确认为合同负债，导致收入提前确认、负债低估，属重大错报。
2. **期初期末不勾稽**：期初审定数与上年期末审定数不一致，可能存在未经授权的调整或首次执行CAS14追溯调整未正确处理。
3. **提前确认收入减少合同负债**：本期合同负债异常减少但无对应真实履约，虚增当期收入。
4. **试算平衡表与审定表不一致**：两者2205科目数据口径不一致，意味着存在未被发现的汇总错误或调整遗漏。
5. **审计调整遗漏**：已确认的合同负债补记或重分类调整未反映在审定表，导致审定数失真。

### 中风险

1. **明细与汇总不勾稽**：审定表各行项目合计与明细表（D7-2）总计不一致，可能存在明细遗漏或重复。
2. **合同负债与预收账款混淆**：CAS14下预收性质款项应确认为合同负债，仍列示为预收账款导致分类错误。
3. **合同负债与合同资产不当抵销**：不同合同的合同负债与合同资产相互抵销，违反净额列示的合同层面要求。
4. **流动性分类不当**：长期限合同负债仍分类为流动负债，未按预计履约时间正确划分。
5. **审定表与附注披露口径不一致**：审定表分类与附注中的分类披露不一致，影响信息一致性。

### 低风险

1. **审定表格式不规范**：列标题、行顺序、编号等格式问题不影响数据准确性，但影响可读性。
2. **底稿交叉索引不完整**：审定表未与试算平衡表、明细表、账龄分析、调整分录建立完整索引引用。
3. **辅助说明不充分**：变动较大的行项目未附简要说明，增加复核理解难度。
4. **历史数据对比缺失**：审定表未列示前期可比数据，不便于分析趋势和异常。
