# D5-4 公允价值与分类检查表复核提示词

## 概述

本提示词针对应收款项融资公允价值与分类检查表（D5-4）的复核，聚焦四大核心审计要点：CAS22业务模式测试、SPPI测试与FVOCI分类、公允价值层次与计量、已质押/已背书/已贴现的终止确认（CAS23）。应收款项融资的分类和计量是CAS22的核心判断领域，业务模式测试和SPPI测试决定分类是否正确，公允价值计量决定账面金额是否可靠，终止确认判断决定资产和负债列报是否完整，是金融工具审计的高风险领域。

**法规依据：**
- 《企业会计准则第22号——金融工具确认和计量》
- 《企业会计准则第23号——金融资产转移》
- 《企业会计准则第39号——公允价值计量》
- 《中国注册会计师审计准则第1301号——审计证据》

## tips

1. **业务模式测试是分类的首要判断**：应收款项融资须满足"既以收取合同现金流为目标又以出售为目标"的业务模式，须核查企业票据/应收账款的持有意图和历史处置行为（背书、贴现频率），业务模式判断错误将导致整体分类错误。
2. **SPPI测试决定能否FVOCI计量**：金融资产的合同现金流量特征须仅为本金和以未偿付本金金额为基础的利息（SPPI），不通过SPPI测试的须以FVTPL计量，须逐项核查合同条款。
3. **公允价值层次影响计量可靠性**：应收款项融资的公允价值须按CAS39确定层次（第一/二/三层次），第三层次（不可观察输入）的估值须重点核查估值技术和关键假设的合理性。
4. **终止确认是CAS23的核心判断**：已背书、已贴现的票据须判断是否"几乎所有风险和报酬"已转移，银行承兑汇票背书/贴现通常满足终止确认，商业承兑汇票通常不满足（追索权风险保留），须逐项判断。
5. **未终止确认须确认相应负债**：不满足终止确认条件的已贴现/背书票据，须继续确认应收款项融资资产并同时确认短期借款等负债，不得直接转出。
6. **已质押资产须披露受限**：已质押的应收款项融资虽仍列示为资产，但须披露其受限状态和质押安排，防止遗漏担保信息披露。

## checklist

### 一、CAS22业务模式测试

- [ ] 是否核查企业持有应收票据/应收账款的业务模式（收取现金流/出售/两者兼有）
- [ ] 业务模式判断是否有管理层书面政策或历史行为支持
- [ ] 是否核查历史期间票据背书、贴现的频率和规模（判断是否以出售为目标之一）
- [ ] 分类为应收款项融资（FVOCI）的项目是否确实符合"两者兼有"的业务模式
- [ ] 业务模式判断是否在同类资产间保持一致
- [ ] 是否存在业务模式判断与实际处置行为不符的情况

### 二、SPPI测试与FVOCI分类

- [ ] 是否逐项/分组核查合同现金流量特征是否满足SPPI（本金+利息）
- [ ] 是否存在含衍生特征、杠杆或非SPPI条款的应收款项
- [ ] 不通过SPPI测试的项目是否已改按FVTPL计量
- [ ] FVOCI分类是否同时满足业务模式测试和SPPI测试两个条件
- [ ] 分类结论是否与D5-1审定表、D5-2明细表一致
- [ ] 分类判断是否有充分的文档记录

### 三、公允价值层次与计量

- [ ] 应收款项融资公允价值是否按CAS39确定层次（第一/二/三层次）
- [ ] 各项公允价值确定的输入值是否披露（市场报价/可观察参数/不可观察参数）
- [ ] 第三层次估值的估值技术和关键假设是否合理并记录
- [ ] 银行承兑汇票公允价值是否接近面值（信用风险低、期限短）
- [ ] 商业承兑汇票公允价值是否考虑承兑人信用风险
- [ ] 公允价值变动是否正确计入其他综合收益
- [ ] 公允价值计量是否与D5-2明细表金额一致

### 四、终止确认（CAS23）

- [ ] 已背书票据是否逐项判断是否满足终止确认条件（风险报酬转移）
- [ ] 已贴现票据是否逐项判断是否满足终止确认条件
- [ ] 银行承兑汇票背书/贴现终止确认判断是否合理（通常满足）
- [ ] 商业承兑汇票背书/贴现是否正确处理（通常不满足，保留追索权）
- [ ] 未终止确认的已贴现票据是否继续列示资产并确认相应负债（短期借款）
- [ ] 已质押的应收款项融资是否披露受限状态和质押安排
- [ ] 终止确认的会计处理是否与D5-3调整分录勾稽
- [ ] 是否存在应终止确认未终止或不应终止已终止的情况

## risk_areas

### 高风险

1. **业务模式判断错误**：将不符合"两者兼有"业务模式的票据/应收账款分类为应收款项融资，或反之，导致整体分类和计量错误。
2. **终止确认判断错误**：商业承兑汇票贴现按满足终止确认处理（实际保留追索权），虚减资产、漏记负债，或银行承兑汇票应终止未终止虚增资产。
3. **公允价值操纵**：通过第三层次估值的不可观察参数调节公允价值，操纵其他综合收益或掩盖信用风险。
4. **SPPI测试遗漏**：未对含特殊条款的应收款项进行SPPI测试，错误采用FVOCI计量而非FVTPL。
5. **未终止确认负债漏记**：已贴现未满足终止确认的票据仅转出资产未确认负债，导致负债完整性错报。

### 中风险

1. **公允价值层次判断不当**：将实际为第三层次的估值列为第二层次，掩盖估值主观性和不确定性。
2. **业务模式文档不足**：业务模式判断缺乏书面政策和历史行为支持，判断合理性存疑。
3. **质押受限未披露**：已质押的应收款项融资未披露受限状态，遗漏担保信息。
4. **公允价值未考虑信用风险**：商业承兑汇票公允价值未反映承兑人信用风险，计量偏高。
5. **分类与明细/审定表不一致**：检查表分类结论与D5-1/D5-2数据不一致。

### 低风险

1. **估值技术记录简略**：第三层次估值的技术和假设已记录但不够详细。
2. **SPPI测试记录不完整**：SPPI测试已执行但测试过程和结论记录不完整。
3. **层次划分依据未充分说明**：公允价值层次划分结论已列示但依据说明不足。
4. **交叉索引不完整**：与明细表、调整分录、附注披露的交叉引用标注不全。
