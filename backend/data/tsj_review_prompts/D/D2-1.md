# D2-1 审定表复核提示词

## 概述

本提示词针对应收账款审定表（D2-1）的复核，聚焦四大核心审计要点：期初期末勾稽、试算平衡表核对、审计调整完整性、分类列报准确性。审定表是科目审计的枢纽底稿，承载未审数→调整→审定数的完整链路，任何勾稽断裂或分类错误均可能导致财务报表重大错报。

**法规依据：**
- 《企业会计准则第22号——金融工具确认和计量》
- 《企业会计准则第37号——金融工具列报》
- 《中国注册会计师审计准则第1301号——审计证据》
- 《中国注册会计师审计准则第1324号——持续经营》

---

## tips

1. **期初期末勾稽是审定表的生命线**：期初审定数必须等于上年期末审定数（承前启后），任何差异需追溯至调整分录或会计政策变更，不得存在无源差异。
2. **试算平衡表是勾稽的第一道防线**：审定表各科目审定数合计必须与试算平衡表对应科目审定数完全一致，差异意味着存在未记录的调整或汇总错误。
3. **审计调整的完整性决定审定数的可靠性**：所有账项调整（AJE）和重分类调整（RJE）必须完整反映在审定表中，遗漏任何一笔调整都将导致审定数失真。
4. **分类列报直接影响报表使用者的决策**：应收账款须严格按流动性分类，关联方单独列示，一年内到期部分重分类至流动资产，错误分类可能构成重大错报。
5. **审定表是跨底稿勾稽的中心节点**：审定表数据应与明细表合计、坏账准备计提、试算平衡表、财务报表附注形成闭环勾稽，任何节点断裂均为复核重点。
6. **关注期末突增或突减的科目行**：审定表中期末余额较期初发生重大变动（超过20%或重要性水平）的行项目，需追溯至具体交易和调整分录，评估变动合理性。

## checklist

### 一、期初期末勾稽

- [ ] 审定表期初未审数是否等于上年审定表期末审定数（承前启后核对）
- [ ] 期初审定数是否等于期初未审数加期初调整（如有追溯调整）
- [ ] 是否存在期初差异未做说明的情况（会计政策变更、前期差错更正等）
- [ ] 期末审定数是否等于期初审定数加本期借方发生额减本期贷方发生额（加减审计调整）
- [ ] 审定表各行项目期初期末变动是否与明细表增减变动一致
- [ ] 是否存在期初数据被人为修改但未留痕的情况

### 二、试算平衡表核对

- [ ] 审定表应收账款审定数合计是否与试算平衡表1122科目审定数一致
- [ ] 审定表坏账准备审定数是否与试算平衡表1231科目审定数一致（借贷方向核对）
- [ ] 审定表各明细科目审定数之和是否等于一级科目审定数
- [ ] 试算平衡表中未审数与审定表未审数是否一致
- [ ] 试算平衡表中调整数（AJE+RJE）与审定表调整数是否一致
- [ ] 是否存在试算平衡表已更新但审定表未同步的情况

### 三、审计调整完整性

- [ ] 所有已确认的账项调整分录（AJE）是否已完整反映在审定表调整列
- [ ] 所有已确认的重分类调整分录（RJE）是否已完整反映在审定表重分类列
- [ ] 调整分录的借贷方金额是否平衡（借方合计=贷方合计）
- [ ] 审定表调整后金额是否等于未审数+AJE调整+RJE调整
- [ ] 是否存在调整分录已编制但未纳入审定表的情况
- [ ] 建议但未调整的错报是否已记录于未调整错报汇总表（SUD）
- [ ] 调整分录是否均有充分的审计证据支持和合伙人审批

### 四、分类列报准确性

- [ ] 应收账款是否严格按流动性正确分类（一年内/一年以上）
- [ ] 关联方应收账款是否在审定表中单独列示
- [ ] 应收账款与预收款项是否按客户分别列示，未进行不当抵销
- [ ] 应收账款净额（扣除坏账准备后）在报表中列示是否准确
- [ ] 超过一年的重大应收账款是否已重分类至非流动资产或充分披露
- [ ] 应收账款与应收票据、合同资产的划分是否正确
- [ ] 审定表中的分类是否与财务报表附注披露的分类一致

## risk_areas

### 高风险

1. **期初期末不勾稽**：期初审定数与上年期末审定数不一致，可能存在未经授权的调整或数据录入错误，直接导致本期审定数失去基准。
2. **审计调整遗漏**：已确认的调整分录未反映在审定表中，导致审定数不真实，可能掩盖重大错报。
3. **试算平衡表与审定表不一致**：两者数据口径不一致，意味着存在未被发现的汇总错误或调整遗漏，影响报表整体准确性。
4. **不当分类美化报表**：将长账龄应收账款仍分类为流动资产，或将关联方应收账款混入一般客户，误导报表使用者。
5. **调整分录缺乏审批**：审计调整未经合伙人批准即纳入审定表，存在越权审批或错误调整的风险。

### 中风险

1. **明细与汇总不勾稽**：审定表各行项目合计与明细表（D2-2）总计不一致，可能存在明细遗漏或重复。
2. **坏账准备列示不准确**：坏账准备金额未与D2-3（坏账准备计算表）勾稽，或扣减方向错误。
3. **审定表与附注披露口径不一致**：审定表分类与财务报表附注中的分类披露不一致，影响信息一致性。
4. **重分类调整方向错误**：RJE借贷方向颠倒导致审定数偏离真实值，或同一科目多笔RJE冲抵不完全。
5. **未调整错报累积超过重要性**：单项未调整错报未超重要性，但累计后可能超过整体重要性水平。

### 低风险

1. **审定表格式不规范**：列标题、行顺序、编号等格式问题不影响数据准确性，但影响底稿可读性和复核效率。
2. **底稿交叉索引不完整**：审定表未与相关底稿（试算平衡表、明细表、调整分录汇总）建立完整索引引用。
3. **辅助说明不充分**：审定表中变动较大的行项目未附简要说明，增加复核理解难度。
4. **历史数据对比缺失**：审定表未列示前期可比数据，不便于分析趋势和异常。
