# D3-note-listed 附注披露复核提示词（上市公司）

## 概述

本提示词针对预收账款/合同负债上市公司附注披露底稿（D3-note-listed）的复核，聚焦上市公司财务报表附注中合同负债相关披露的充分性和准确性：分类披露、合同负债变动披露、CAS14收入准则要求的履约义务及预计确认时间披露、含税列报、关联方预收单独披露。合同负债披露是报表使用者理解企业未来收入实现和履约义务的重要途径，披露不充分或不准确将影响投资者对收入可持续性的判断。

**法规依据：**
- 《企业会计准则第14号——收入》
- 《企业会计准则第30号——财务报表列报》
- 《企业会计准则第36号——关联方披露》
- 《公开发行证券的公司信息披露编报规则第15号——财务报告的一般规定》
- 《中国注册会计师审计准则第1501号——对财务报表形成审计意见和出具审计报告》

## tips

1. **上市公司披露要求高于一般企业**：除CAS14基本要求外，证监会编报规则第15号对合同负债披露有额外细化要求，包括按业务性质分类、重大合同负债说明等，缺失任何一项均属披露不充分。
2. **CAS14要求披露履约义务及预计确认时间**：新收入准则要求披露分摊至剩余履约义务的交易价格总额及预计确认为收入的时间，这是合同负债披露的核心，缺失则不满足准则要求。
3. **合同负债变动表是投资者关注的信息**：变动表须完整列示期初余额、本期新增、本期结转收入、本期退款、其他变动和期末余额，且各项金额可追溯至具体交易或调整。
4. **列报名称须体现CAS14过渡**：在新收入准则下，原"预收账款"应列报为"合同负债"，附注须清晰说明列报变化及重分类金额。
5. **关联方预收款项须独立披露**：根据CAS36要求，关联方合同负债须单独列示关联方名称、关系类型、交易金额、期末余额，不得混入一般客户。
6. **附注数据必须与审定表/明细表/收入底稿形成闭环勾稽**：附注中的合同负债总额必须等于审定表审定数，分类小计必须等于明细表对应分类合计，本期结转收入必须与收入附注勾稽。

## checklist

### 一、分类披露检查

- [ ] 合同负债是否按业务性质分类披露（预收货款/预收服务费/会员费/其他）
- [ ] 各类别期末余额合计是否等于审定表合同负债审定数
- [ ] 各类别是否同时披露期末数和期初数（可比信息）
- [ ] 合同负债是否按流动性分类（一年内履约/一年以上履约）
- [ ] 分类方式是否与会计政策中确定的分类标准一致
- [ ] 各分类之间是否存在重叠或遗漏
- [ ] 列报名称是否已从"预收账款"过渡为"合同负债"并说明重分类

### 二、合同负债变动披露

- [ ] 合同负债变动表是否完整（期初/新增/结转收入/退款/其他/期末）
- [ ] 变动表各栏金额是否与明细表（D3-2）及审定表勾稽
- [ ] 本期结转收入金额是否与营业收入附注勾稽（来自期初合同负债的收入）
- [ ] 本期退款是否有充分依据和披露
- [ ] 期末合同负债余额是否等于变动表结转后余额
- [ ] 重大合同负债变动是否有原因说明

### 三、CAS14履约义务及确认时间披露

- [ ] 是否披露分摊至剩余履约义务的交易价格总额
- [ ] 是否披露预计将上述金额确认为收入的时间（如1年内/1-2年/2年以上）
- [ ] 是否披露收入确认的会计政策（时点法/时段法）
- [ ] 是否披露重大合同负债的性质和履约义务内容
- [ ] 是否披露合同负债对应的商品/服务交付计划
- [ ] 是否运用了准则允许的简化披露豁免条款（原始预期期限≤1年），如运用是否符合条件
- [ ] 履约义务披露是否与收入确认底稿（D4）一致

### 四、含税列报与其他披露

- [ ] 含增值税的预收款是否正确拆分列报（合同负债/待转销项税额）
- [ ] 合同负债与合同资产是否按合同分别列报，抵销是否符合条件
- [ ] 长期挂账合同负债（超1年）是否单独披露金额及原因
- [ ] 重大合同负债的期后结转或退款情况是否披露
- [ ] 合同负债中涉诉/争议金额是否披露
- [ ] 与收入确认相关的合同负债变动是否与收入附注勾稽

### 五、关联方合同负债披露

- [ ] 关联方合同负债/预收款项是否单独列表披露（不混入一般客户）
- [ ] 是否完整列示关联方名称、关系类型
- [ ] 是否披露与各关联方的交易金额和期末余额
- [ ] 关联方合同负债的账龄和长期挂账是否单独分析
- [ ] 关联方交易定价的公允性是否有说明
- [ ] 本期新增的关联方预收款项是否有商业合理性说明

## risk_areas

### 高风险

1. **合同负债变动表不完整或不勾稽**：变动表各项金额之间的勾稽关系不成立（期初+新增-结转-退款±其他≠期末），或与明细表数据不一致，属重大披露错误。
2. **履约义务及确认时间未披露**：未披露分摊至剩余履约义务的交易价格及预计确认时间，不满足CAS14强制披露要求。
3. **本期结转收入与收入附注不勾稽**：合同负债本期结转金额与营业收入附注中来自合同负债的收入不一致，可能预示收入操纵。
4. **关联方合同负债未单独披露**：关联方预收款项混入一般客户未单独列示，违反CAS36强制要求。
5. **附注总额与审定表不一致**：附注中披露的合同负债期末余额与审定表审定数不一致，属数据勾稽重大错误。

### 中风险

1. **含税列报错误**：含增值税预收款未拆分列报，合同负债虚增。
2. **分类维度不完整**：仅按单一维度分类披露，未按业务性质和流动性多维度披露。
3. **列报过渡未说明**：未说明从"预收账款"到"合同负债"的列报变化及重分类金额。
4. **长期挂账披露不充分**：长期挂账合同负债金额较大但未披露原因和处理计划。
5. **可比信息缺失**：附注中仅列示期末数据，未列示期初可比数据或上年同期数据。

### 低风险

1. **披露格式不完全规范**：表格标题、列序、金额单位等格式细节未严格按编报规则，但不影响信息实质完整性。
2. **文字描述过于模板化**：收入确认政策等文字描述照搬会计政策原文，未结合本企业实际情况说明。
3. **数字精度不一致**：部分披露表格保留两位小数，部分取整到万元，精度不统一但不影响决策判断。
4. **期后事项披露过于简略**：期后结转或退款的重大合同负债仅提及事实，未说明影响。
