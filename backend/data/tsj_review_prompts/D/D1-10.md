# D1-10 实物盘点监盘表复核提示词

## 概述

本提示词针对应收票据实物盘点监盘表（D1-10）的复核，聚焦四大核心审计要点：盘点范围完整性、票据实物/ECDS 登记核对、存在性认定证据、盘点差异处理。应收票据兼具纸质票据与电子商业汇票（ECDS）两种形态，盘点须同时覆盖库存实物票据和电子票据系统余额，并与备查簿（D1-7）、分类明细（D1-2）逐笔核对，是验证应收票据存在性认定最直接的审计程序。

**法规依据：**
- 《中国注册会计师审计准则第1301号——审计证据》
- 《中国注册会计师审计准则第1311号——对存货、诉讼、事项以及分部信息的特定考虑》
- 《企业会计准则第22号——金融工具确认和计量》

## tips

1. **盘点须同时覆盖纸质票据与电子票据**：库存实物票据现场清点，电子商业汇票须调取 ECDS（电子商业汇票系统）截屏或对账单，两类合计才是完整的库存票据总体，遗漏任一形态均导致存在性证据不完整。
2. **监盘应在资产负债表日或临近日进行并做期间调节**：非资产负债表日监盘的，须将监盘日余额向前/向后滚动调节至报表日，滚动期间的收取、背书、贴现、兑付须逐笔追溯。
3. **盘点须核对票据要素完整性**：出票人、承兑人、票面金额、出票日、到期日、票号，核对要素与备查簿及账面记录一致，防范以旧票、废票、复印件充数。
4. **库存票据须与已背书/已贴现票据区分**：已背书或已贴现但未终止确认的票据不在库存，须核对其去向单据（D1-8），避免将已转出票据仍计入库存导致重复。
5. **盘点差异须查明原因并追溯**：账面有而实物/ECDS 无（可能已丢失、被盗用、账实不符或虚构），实物有而账面无（可能漏记），差异金额重大须评估对存在性认定和内部控制的影响。
6. **关注质押、保管在外票据的替代程序**：已质押给银行、交由第三方保管或诉讼中的票据无法现场盘点，须通过函证、质押协议、保管凭证等替代程序验证存在性。

## checklist

### 一、盘点范围完整性

- [ ] 【必检】盘点是否同时覆盖库存纸质票据和电子商业汇票（ECDS）
- [ ] 【必检】盘点总体是否与账面应收票据余额、备查簿（D1-7）范围一致
- [ ] 【必检】已背书/已贴现未到期票据是否单独列示并核对去向（不计入库存实物）
- [ ] 【必检】质押、保管在外、诉讼中的票据是否列明并说明无法盘点原因
- [ ] 【条件检查：若非报表日监盘】监盘日至报表日的滚动调节是否完整准确
- [ ] 【风险检查】是否存在应盘未盘的票据（选择性盘点）

### 二、票据实物与登记核对

- [ ] 【必检】纸质票据要素（出票人/承兑人/金额/到期日/票号）是否与备查簿核对一致
- [ ] 【必检】电子票据 ECDS 系统余额是否与账面及备查簿核对一致
- [ ] 【必检】票据实物是否真实有效（非复印件/作废票/过期未处理票）
- [ ] 【必检】承兑人类型（银行承兑/商业承兑）是否与 D1-2 分类明细一致
- [ ] 【条件检查：若有大额票据】大额票据是否重点核对并留存影像证据
- [ ] 【风险检查】是否存在票号连号、金额雷同等异常票据

### 三、存在性认定证据

- [ ] 【必检】盘点表是否由被审计单位保管人与审计人员双方签字
- [ ] 【必检】审计人员是否实施监盘而非仅接受管理层盘点结果
- [ ] 【必检】盘点结果是否与 D1-1 审定表期末余额勾稽
- [ ] 【条件检查：若采用替代程序】质押/保管在外票据的替代程序证据是否充分
- [ ] 【风险检查】期末突增票据是否重点验证存在性

### 四、盘点差异处理

- [ ] 【必检】盘点差异（账实不符）是否逐笔查明原因
- [ ] 【必检】差异是否已作调整或记录于未调整错报
- [ ] 【必检】账面有而实物/ECDS 无的差异是否评估丢失/被盗用/虚构风险
- [ ] 【条件检查：若差异重大】是否评估对存在性认定和内部控制的影响
- [ ] 【风险检查】盘点差异是否存在管理层未如实说明的情况

## risk_areas

### 高风险

1. **虚构票据充数**：以复印件、作废票、过期票或票号连号的虚构票据充抵库存，掩盖应收票据不存在的事实，涉及存在性舞弊。
2. **已转出票据重复计入库存**：已背书/已贴现票据仍计入库存实物，导致应收票据虚增。
3. **电子票据未纳入盘点**：仅盘点纸质票据而遗漏 ECDS 电子票据，存在性证据严重不完整。
4. **盘点差异掩盖资产流失**：账面有而实物无的重大差异未查明，可能掩盖票据被挪用、盗用或质押未披露。
5. **未实施监盘仅接受管理层结果**：审计人员未现场监盘，存在性证据可靠性不足。

### 中风险

1. **滚动调节不准确**：非报表日监盘的期间调节遗漏收取/背书/贴现/兑付交易。
2. **替代程序不充分**：质押、保管在外票据的替代程序证据不足以支持存在性。
3. **票据要素核对不细**：仅核对金额而未核对出票人/承兑人/到期日等要素。
4. **盘点与备查簿不勾稽**：盘点结果与 D1-7 备查簿、D1-2 明细存在差异未调节。

### 低风险

1. **盘点表格式不规范**：栏目、签字、日期记录不完整。
2. **影像证据缺失**：大额票据未留存盘点影像。
3. **交叉索引不完整**：与审定表、备查簿、背书贴现底稿索引标注不全。
