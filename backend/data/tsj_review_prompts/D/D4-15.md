# D4-15 收入完整性测试表复核提示词

## 概述

本提示词针对收入完整性测试表（D4-15，completeness 认定）的复核，聚焦四大核心审计要点：已发货未确认收入排查、漏记收入识别、反向凭证核对（发货→收入）、截止期完整性。完整性认定测试针对"所有应确认的收入是否均已入账"这一认定，测试方向与发生认定相反（从凭证到账簿），通过发货记录、物流单据、合同履约情况反查收入确认，识别漏记收入、隐瞒收入和推迟确认（少计当期收入）的错报。

**法规依据：**
- 《企业会计准则第14号——收入》
- 《中国注册会计师审计准则第1301号——审计证据》
- 《中国注册会计师审计准则第1141号——财务报表审计中与舞弊相关的责任》
- 《中国注册会计师审计准则第1314号——审计抽样》

## tips

1. **完整性认定针对漏记/推迟收入**：完整性测试的方向是"从凭证到账簿"（发货记录→已确认收入），验证所有已履约的销售是否均已确认收入，应对漏记收入和推迟确认舞弊。
2. **已发货未确认是漏记的核心信号**：须从发货单/物流单/出库记录反查收入确认，已发货（控制权已转移）但未确认收入的交易是漏记收入或推迟确认的直接证据。
3. **反向核对是完整性测试的方法论**：从发货台账、物流系统、出库记录选取样本反查是否确认收入，与发生认定（从收入查发货）方向相反，两者结合形成双向验证。
4. **推迟确认收入平滑业绩**：将本期已履约收入推迟至下期确认（少计当期收入以平滑业绩或规避税负），是完整性认定的常见错报，需关注期末发货未开票。
5. **隐瞒收入的动机与迹象**：为逃税或体外循环隐瞒收入（现金销售不入账/发货不开票/收入转入关联方），须结合存货减少、物流记录、银行流水交叉验证。
6. **勾稽关系**：发货单/出库记录 ↔ 收入确认；存货减少 ↔ 销售收入；物流签收 ↔ 收入入账；期末未开票发货 ↔ 次期收入，勾稽断裂为漏记信号。

## checklist

### 一、已发货未确认收入排查（高风险）

- [ ] 【必检】期末已发货但未确认收入的交易是否排查
- [ ] 【必检】发货台账/出库记录是否与收入确认逐笔核对
- [ ] 【必检】已发货未确认收入的原因是否合理（未验收/退货约定）
- [ ] 【条件检查：若有已发货未确认】控制权是否实际已转移
- [ ] 【风险检查】是否存在已发货且控制权转移但未确认收入（漏记/推迟）
- [ ] 【风险检查】期末发货未开票是否推迟至次期确认

### 二、漏记收入识别（高风险）

- [ ] 【必检】存货减少是否均有对应销售收入
- [ ] 【必检】物流/运输记录是否均对应收入确认
- [ ] 【必检】银行大额收款是否均有对应收入或合理解释
- [ ] 【必检】生产领用-产出-销售的物流是否闭环
- [ ] 【条件检查：若有现金销售】现金销售是否全部入账
- [ ] 【风险检查】是否存在发货不开票、销售不入账（隐瞒收入）
- [ ] 【风险检查】是否存在收入转入关联方或体外循环

### 三、反向凭证核对（中风险）

- [ ] 【必检】从发货台账选取样本反查收入确认
- [ ] 【必检】从物流系统选取样本反查收入确认
- [ ] 【必检】从出库记录选取样本反查收入确认
- [ ] 【必检】反向核对样本是否覆盖期末高风险期间
- [ ] 【条件检查：若发现未确认】未确认交易是否追查原因和影响
- [ ] 【风险检查】反向核对方向是否正确（凭证→账簿）

### 四、截止期完整性（高风险）

- [ ] 【必检】资产负债表日前发货的收入是否在本期完整确认
- [ ] 【必检】期末最后几天发货是否及时确认收入
- [ ] 【必检】跨期发货的收入归属期间是否正确
- [ ] 【条件检查：若期末大量发货】期末发货未确认的比例是否异常
- [ ] 【风险检查】是否存在期末已发货推迟至次期确认（少计当期）
- [ ] 【风险检查】截止测试结果是否与 D4-4 跨期调整一致

## risk_areas

### 高风险

1. **隐瞒收入逃税**：发货不开票、现金销售不入账、收入转入关联方或体外循环，系统性漏记收入以逃税，涉及完整性认定重大舞弊。
2. **推迟确认平滑业绩**：将本期已履约收入推迟至下期确认，少计当期收入以平滑业绩或规避税负，构成跨期错报。
3. **已发货未确认漏记**：控制权已转移的发货未确认收入，直接漏记应确认收入，影响收入完整性。
4. **存货减少无对应收入**：存货大量减少但无对应销售收入，反映可能存在隐瞒销售或存货舞弊。
5. **期末发货推迟确认**：期末最后几天发货未及时确认收入而推迟至次期，少计当期收入。

### 中风险

1. **反向核对方向错误**：完整性测试误用发生认定方向（从收入查发货），无法有效识别漏记收入。
2. **物流记录未闭环**：生产-产出-销售的物流未闭环核对，漏记收入难以发现。
3. **银行收款未匹配收入**：大额银行收款未与收入或其他合理事项匹配，可能存在未入账收入。
4. **截止样本不足**：期末截止期间的完整性测试样本不足，跨期漏记未能识别。
5. **已发货未确认原因不实**：已发货未确认收入的原因（未验收）未经核实，可能掩盖推迟确认。

### 低风险

1. **反向核对记录不详**：从凭证到账簿的核对结果记录过于简略。
2. **抽样覆盖不均**：反向核对样本时间/产品分布不均。
3. **异常处理记录不全**：发现的未确认交易追查过程记录不充分。
4. **交叉索引不完整**：与发生测试、调整分录、存货底稿的交叉引用不全。
