# D6-6 合同资产凭证检查复核提示词

## 适用底稿
合同资产凭证检查表（D6-6，科目码1141），聚焦样本选取方法合理性、合同与履约进度核对完整性、结算凭证核对、检查比例达标性、异常交易标注充分性。

## 概述
D6-6 是通过凭证细节测试验证合同资产存在性、准确性及收入确认真实性的关键底稿。合同资产的确认依赖履约进度判断，凭证检查须穿透至合同、履约进度证据（验收/里程碑）及结算安排，验证按履约进度确认的合同资产是否真实、准确、完整。

**法规依据：**
- 《中国注册会计师审计准则第1314号——审计抽样》
- 《企业会计准则第14号——收入》
- 《中国注册会计师审计准则第1301号——审计证据》
- 《中国注册会计师审计准则第1141号——财务报表审计中与舞弊相关的责任》

## tips

- 样本选取方法应与风险评估结果匹配，履约进度判断复杂或金额重大的合同采用更严格抽样策略
- 凭证核对须覆盖合同资产完整确认链条（合同→履约义务→履约进度证据→按进度确认收入→合同资产确认→结算/转应收账款）
- 检查比例应满足《中国注册会计师审计准则第1314号——审计抽样》要求
- 合同资产核心是履约进度真实性，须核对履约进度的客观支持性证据（工程量确认单、验收单、里程碑证明）
- 异常交易标注需明确异常类型（履约进度异常/金额异常/时间异常/对手方异常）
- 关注期末集中确认履约进度、大额合同资产、关联方合同等高风险凭证
- 职业怀疑贯穿始终：对管理层履约进度判断保持警觉，记录质疑过程和替代验证方案

## checklist

### 一、样本选取与检查比例（高风险）

- [ ] 样本选取方法是否与识别的重大错报风险相匹配
- [ ] 抽样方法是否符合CAS1314要求（统计抽样/非统计抽样选择有据）
- [ ] 金额重大合同资产（超过重要性水平）是否100%全覆盖检查
- [ ] 高风险合同（履约进度判断复杂/关联方/长账龄/大额变动）是否纳入必选样本
- [ ] 抽样总体是否完整（是否排除了不应排除的项目）
- [ ] 总体检查比例（已检查金额/总体金额）是否达到计划水平
- [ ] 借方发生额（本期新增合同资产）检查比例是否达标
- [ ] 贷方发生额（本期结转/收款）检查比例是否达标

### 二、合同与履约进度核对（高风险）

- [ ] 是否核对合同文本，确认履约义务及收款条件（区分时间流逝外因素）
- [ ] 履约进度是否有客观支持性证据（工程量确认单/验收单/里程碑证明）
- [ ] 按履约进度确认的收入及合同资产金额计算是否正确
- [ ] 履约进度计量方法（产出法/投入法）是否与会计政策一致
- [ ] 是否存在无履约进度证据支持却确认合同资产的情况
- [ ] 期末集中确认履约进度的合同资产是否重点核查
- [ ] 是否存在人为提高履约进度虚增合同资产及收入的迹象

### 三、结算凭证核对（中风险）

- [ ] 合同资产转应收账款的结算凭证是否核对（收款权转为无条件的证据）
- [ ] 已收款部分冲减合同资产的凭证是否核对准确
- [ ] 结算凭证日期与记账日期是否一致，是否存在跨期记录
- [ ] 部分结算是否按正确顺序冲减，剩余合同资产计算是否准确
- [ ] 结算安排是否与合同约定的付款里程碑一致
- [ ] 核对过程中发现的差异是否逐一追踪解决

### 四、异常交易标注（中低风险）

- [ ] 异常交易是否全部标注并记录异常类型和初步判断
- [ ] 履约进度异常（跳跃式增长/期末突增）是否标注
- [ ] 金额异常（整数金额/恰好低于审批权限/偏差超30%）是否标注
- [ ] 时间异常（期末最后几天集中确认/非正常时点）是否标注
- [ ] 对手方异常（关联方/新客户首笔大额/信息不完整）是否标注
- [ ] 抽样工作底稿是否完整记录抽样参数及选取过程（可追溯）
- [ ] 底稿索引与交叉引用是否完整（关联审定表/明细表/ECL底稿）

## risk_areas

### 高风险

- **履约进度造假风险**：伪造工程量确认单/验收单/里程碑证明，虚增履约进度从而虚增合同资产及收入
- **样本选取偏差风险**：抽样方法不当导致样本不具代表性，未能覆盖履约进度判断复杂或金额重大的合同
- **收入确认真实性风险**：无真实履约支持却确认合同资产，涉及虚增收入的舞弊
- **截止性错误风险**：期末集中确认履约进度的合同资产未实施截止测试，跨期确认未被识别
- **关联方交易隐匿风险**：关联方合同凭证混入普通样本，未实施针对性核查

### 中风险

- **检查比例不足风险**：实际检查比例低于计划水平，审计证据不充分
- **结算核对不充分风险**：合同资产转应收账款或收款冲减的结算凭证核对不到位
- **履约进度方法不一致风险**：不同合同采用不同履约进度计量方法未核对一致性
- **核对深度不够风险**：仅核对金额而忽略履约进度证据与合同条款的实质匹配

### 低风险

- **记录不完整风险**：抽样参数/选取过程/核对结果记录不完整，影响可追溯性
- **索引缺失风险**：凭证检查底稿与审定表/明细表/ECL底稿的交叉索引不完整
- **格式不规范风险**：检查结果记录格式不统一，影响汇总分析效率
