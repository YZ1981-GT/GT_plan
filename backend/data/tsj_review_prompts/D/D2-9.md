# D2-9 单项预期信用损失（ECL）测算复核提示词

## 适用底稿
单项 ECL 测算表（D2-9），聚焦大额/高风险客户的单项减值评估与应计提金额测算。

## 概述
单项 ECL 是组合计提之外的必要补充。复核须验证：识别标准是否完整、预计可收回金额估计是否合理、单项应计提与 D2-3 坏账准备勾稽一致。

---

## tips

1. **单项识别边界**：逾期超 90 天、涉诉/仲裁、破产清算、失联、债务重组、信用风险显著增加的客户须纳入单项评估，不得仅依赖组合迁徙率。
2. **预计可收回金额**：须考虑担保品、抵押物、第三方保证、期后回款及诉讼进展，估计过程须留痕。
3. **与 D2-3 勾稽**：D2-9 单项应计提合计须与 D2-3 单项减值行一致；系统差异告警须解释或更正。
4. **与 D2-2 明细勾稽**：单项客户余额须能在明细表 D2-2 追溯，客户名称/余额不得脱节。
5. **前瞻性调整**：单项评估亦须考虑客户所在行业、宏观环境对回收概率的影响，不能机械沿用历史回收率。
6. **期后证据**：资产负债表日后大额收回或确认无法收回，须评估对单项计提充分性的影响。

## checklist

### 高风险检查项

- [ ] 是否对所有存在客观减值迹象的客户逐项评估（非仅按金额排序抽查）
- [ ] 单项客户余额与 D2-2 明细表对应行一致（名称、金额、账龄）
- [ ] 单项应计提合计与 D2-3 坏账准备表中单项减值金额一致（差异须说明）
- [ ] 预计可收回金额的估计方法、关键假设是否记录且合理
- [ ] 已全额计提但仍挂账的款项是否评估应核销而未核销
- [ ] 涉诉/破产客户是否获取法律意见或公开信息支持计提比例
- [ ] 单项减值是否经适当层级审批（项目经理/合伙人）

### 中风险检查项

- [ ] 单项评估工作底稿是否包含客户经营状况、还款能力分析
- [ ] 担保品/抵押物估值是否有独立依据或第三方评估
- [ ] 期后回款是否用于验证计提充分性并记录结论
- [ ] 新增/转回单项减值的变动原因是否清晰
- [ ] 单项与组合计提边界是否一致（同一客户不得重复或遗漏）

### 低风险检查项

- [ ] 表格合计行公式正确（应计提、账面、差异列）
- [ ] 索引号指向合同、诉讼、银行回单等支持性证据完整
- [ ] 审计说明/结论是否概括单项评估结论与 residual 风险

## risk_areas

### 高风险

- 大额客户存在明显减值迹象但未纳入单项评估，依赖组合计提导致计提不足
- D2-9 与 D2-3 单项金额长期不一致且无解释
- 预计可收回金额明显乐观，缺乏证据支持

### 中风险

- 单项评估文档不完整，无法复现计提过程
- 担保品价值高估或未考虑处置成本

### 低风险

- 格式、索引、说明文字不够规范但不影响实质判断

## 跨底稿勾稽

- D2-9 单项应计提合计 ↔ D2-3 单项减值小计
- D2-9 客户余额 ↔ D2-2 明细表对应客户行
- D2-3 坏账准备审定数 ↔ D2-1 审定表坏账准备行
