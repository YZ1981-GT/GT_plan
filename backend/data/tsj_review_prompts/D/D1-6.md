# D1-6 业务模式判断表复核提示词

## 概述

本提示词针对应收票据业务模式判断表（D1-6）的复核，聚焦 CAS22 金融资产分类的核心判断：业务模式测试（以收取合同现金流为目标/以收取和出售为目标/其他）、SPPI 测试（合同现金流是否仅为本金和利息的支付）、持有目的评估。业务模式判断直接决定票据分类为以摊余成本计量（应收票据 1121）还是以公允价值计量且其变动计入其他综合收益（应收款项融资 1124）——若企业频繁背书/贴现票据，其业务模式可能为"既收取又出售"，应分类为应收款项融资而非应收票据。分类错误将导致列报科目错误和计量基础错误。

**法规依据：**
- 《企业会计准则第22号——金融工具确认和计量》（金融资产分类）
- 《企业会计准则第23号——金融资产转移》
- 《企业会计准则第37号——金融工具列报》
- 《中国注册会计师审计准则第1301号——审计证据》

## tips

1. **业务模式判断是应收票据分类的起点**：CAS22 下票据分类取决于管理金融资产的业务模式，须评估企业持有票据的实际目的（到期收款 vs 背书/贴现出售），而非仅凭票据法律形式。
2. **频繁背书/贴现指向"既收取又出售"业务模式**：若企业持有的银行承兑汇票经常用于背书支付或贴现融资，其业务模式为"以收取合同现金流和出售为目标"，应分类为应收款项融资（1124，FVOCI）而非应收票据（1121，摊余成本）。
3. **SPPI 测试须逐类评估**：合同现金流是否仅为对本金和以未偿付本金为基础的利息的支付；应收票据（无息或含约定利息）通常通过 SPPI 测试，但须关注是否存在与基本借贷不符的特殊条款。
4. **业务模式判断须一致应用且有据**：同类票据应采用一致的业务模式判断，判断依据（历史背书贴现比例、管理层意图、内部政策）须有充分证据，不得为调节报表随意改变分类。
5. **分类结果直接影响列报与后续计量**：摊余成本计量（应收票据）与 FVOCI 计量（应收款项融资）的减值、公允价值变动处理不同，判断表结论须与 D1-1 审定表分类、D5 应收款项融资底稿的划分保持一致。
6. **关注分类与实际背书贴现行为的一致性**：判断表结论（如"以收取合同现金流为目标"）应与 D1-8 背书贴现明细反映的实际交易频率相符，若大量票据被背书贴现却仍分类为应收票据，须质疑分类合理性。

## checklist

### 一、业务模式测试

- [ ] 是否明确评估持有应收票据的业务模式（收取现金流/收取和出售/其他）
- [ ] 业务模式判断是否基于实际持有目的和历史行为，而非仅凭法律形式
- [ ] 是否分析历史期间票据的背书/贴现比例作为业务模式判断依据
- [ ] 频繁背书/贴现的票据是否评估应否分类为应收款项融资（1124）
- [ ] 不同类别票据（银承/商承）的业务模式判断是否分别评估
- [ ] 业务模式判断是否与内部票据管理政策和管理层意图一致

### 二、SPPI 测试（合同现金流特征）

- [ ] 是否对票据合同现金流进行 SPPI 测试（仅为本金和利息的支付）
- [ ] 无息票据/带息票据的现金流特征是否符合基本借贷安排
- [ ] 是否存在与基本借贷不符的特殊条款（如与业绩挂钩、杠杆等）
- [ ] SPPI 测试结论是否有据且逐类记录
- [ ] 通过 SPPI 测试是否为分类为应收票据/应收款项融资的前提

### 三、持有目的与分类结论

- [ ] 分类结论（应收票据/应收款项融资/以公允价值计量）是否明确
- [ ] 分类结论是否与 D1-1 审定表科目分类一致
- [ ] 分类为应收款项融资的票据是否已划分至 D5 底稿（1124）
- [ ] 同类票据分类是否一致，无选择性分类调节报表
- [ ] 分类变更（如从应收票据重分类至应收款项融资）是否有充分理由并披露
- [ ] 分类结论与实际背书贴现行为（D1-8）是否一致

### 四、判断依据与证据

- [ ] 业务模式判断是否有历史数据（背书贴现比例）支持
- [ ] 管理层关于持有意图的声明是否获取并评估
- [ ] 分类判断是否经适当层级复核
- [ ] 判断依据是否可追溯、文档是否充分
- [ ] 是否考虑前瞻性因素（未来是否计划改变持有策略）

## risk_areas

### 高风险

1. **分类科目错误**：频繁背书贴现的票据（业务模式为"既收取又出售"）被错误分类为应收票据（摊余成本）而非应收款项融资（FVOCI），导致计量基础和列报科目错误。
2. **选择性分类调节报表**：对同类票据采用不一致的业务模式判断，人为选择有利于报表的分类。
3. **业务模式判断缺乏依据**：分类判断无历史背书贴现数据或管理层意图证据支持。
4. **分类与实际行为背离**：判断表结论与 D1-8 反映的大量背书贴现行为明显矛盾。

### 中风险

1. **SPPI 测试遗漏或形式化**：未对含特殊条款的票据进行实质性 SPPI 测试。
2. **应收款项融资划分不完整**：应分类为应收款项融资的票据未完整划分至 D5 底稿。
3. **分类变更未充分披露**：业务模式变化导致的重分类未恰当处理和披露。
4. **银承商承业务模式未分别评估**：对不同承兑人类型票据的持有目的未分别判断。

### 低风险

1. **判断表格式不规范**：测试步骤、结论列示格式问题。
2. **判断依据文档不充分**：业务模式测试过程记录简略。
3. **交叉索引不完整**：与审定表、背书贴现表、D5 底稿的索引标注不全。
4. **管理层声明未留痕**：口头获取持有意图但未书面记录。
