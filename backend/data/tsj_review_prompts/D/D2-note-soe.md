# D2-note-soe 附注披露复核提示词（国有企业）

## 概述

本提示词针对应收账款国有企业附注披露底稿（D2-note-soe）的复核，聚焦国有企业特定的附注披露要求：国有资产监管相关披露、关联交易（含与政府/国有控股单位交易）、预算执行相关信息、国资委要求的补充披露事项，以及与上市公司版本的差异关注点。国有企业审计具有双重属性（财务审计+国有资产监管），附注披露须同时满足会计准则和国资监管要求。

**法规依据：**
- 《企业会计准则第37号——金融工具列报》
- 《企业会计准则第36号——关联方披露》
- 《企业国有资产法》
- 《国有资产监督管理委员会关于加强中央企业财务决算管理工作有关事项的通知》
- 《中央企业财务决算报告管理办法》
- 《关于做好中央企业财务决算工作的通知》（每年度版）

## tips

1. **国有企业附注有"双层"披露要求**：既要满足企业会计准则（CAS）的通用披露要求，又要满足国资委财务决算报告的额外披露要求，两套要求互为补充、不可替代。
2. **关联方范围比一般企业更广**：国有企业的关联方除一般定义外，还需考虑同一国有控股股东控制/共同控制的其他国有企业（"同受国有控制"的关联方），但可按准则豁免条款简化部分披露。
3. **国资委要求的"三重一大"涉及应收账款**：重大应收账款核销须经"三重一大"决策程序，附注需披露本期核销的重大应收账款的决策过程和审批情况。
4. **预算执行视角是国企独有的关注点**：国企年度预算中通常包含应收账款回收目标和坏账核销预算，附注需说明实际执行与预算的偏差及原因。
5. **国有资产保值增值视角下的应收账款**：长账龄应收账款的累积可能被视为国有资产流失风险，需在附注中说明催收措施和未来处置计划。
6. **与上市版的差异主要在监管层面而非准则层面**：基础披露框架与上市版相同（分类/账龄/坏账变动/信用风险），国企版额外增加国资监管相关信息，而非替代基础披露要求。

## checklist

### 一、基础披露完整性（与上市版共有）

- [ ] 应收账款是否按业务性质分类披露（货款/工程款/服务费/其他）
- [ ] 账龄分析表是否完整列示（1年以内/1-2年/2-3年/3年以上/5年以上）
- [ ] 坏账准备变动表是否完整（期初/计提/转回/核销/其他/期末）
- [ ] 附注应收账款总额是否与审定表审定数一致
- [ ] 各分类/账龄维度的小计是否与总额勾稽
- [ ] 期初数/期末数可比信息是否完整列示

### 二、国有资产监管相关披露

- [ ] 3年以上长账龄应收账款是否单独披露金额、客户及形成原因
- [ ] 长账龄应收账款的催收措施是否披露
- [ ] 是否披露应收账款中属于财政性资金的部分（如财政拨付/政府补贴尾款）
- [ ] 大额应收账款（超过单户限额标准）是否按国资委要求逐户披露
- [ ] 是否披露本期应收账款中涉及国有资产处置/划转的事项
- [ ] 国有资产经营性占用（其他国企占用本单位资金）是否单独说明
- [ ] 应收账款减值损失对国有资本保值增值率的影响是否说明

### 三、关联交易披露（国企特定）

- [ ] 与控股股东及其关联企业的应收账款是否逐户列示
- [ ] 与同一母公司控制的其他国有企业的应收账款是否披露
- [ ] 是否运用了"同受国家控制"关联方的豁免条款，如运用是否符合条件
- [ ] 关联方应收账款的交易实质是否清晰说明（经营性/资金性/投资性）
- [ ] 关联方交易定价方式是否披露（市场价/协议价/政府定价）
- [ ] 关联方应收账款的账龄和坏账准备是否单独披露
- [ ] 是否存在大额资金往来被以应收账款名义挂账的情况并予以说明
- [ ] 与政府部门的应收账款（财政返还/补贴/奖励）是否单独列示

### 四、预算执行相关披露

- [ ] 本期应收账款实际回收额与年度预算目标的对比是否披露
- [ ] 预算偏差超过一定比例（如20%）时是否说明原因
- [ ] 本期坏账核销是否在年度核销预算额度内，超额是否有追加审批
- [ ] 应收账款周转天数是否与预算目标对比分析
- [ ] 新增大额应收账款是否属于预算内业务
- [ ] 期末应收账款余额是否超出年度资产负债预算

### 五、国资委要求的补充披露

- [ ] 本期核销的应收账款是否逐笔披露（金额/客户/核销原因/审批程序）
- [ ] 核销是否经过"三重一大"决策程序（超过规定金额时）
- [ ] 是否编制应收账款清理处置方案并披露执行情况
- [ ] 应收账款中涉及法律诉讼/仲裁的金额及进展是否披露
- [ ] 是否披露应收账款中涉及的担保/抵押/质押安排
- [ ] 对外提供资金（以应收款名义）是否按国资委要求单独披露
- [ ] 应收账款账龄3年以上且无法回收的是否已启动责任追究程序并披露

### 六、与上市版的差异关注点

- [ ] 国企版是否在上市版基础披露的基础上增加了国资监管层面的补充信息
- [ ] 关联方范围是否已扩展至"同受国有控制"的企业
- [ ] 坏账核销是否增加了"三重一大"决策程序的说明
- [ ] 是否增加了预算执行偏差分析
- [ ] 是否增加了长账龄应收账款的催收/处置/责任追究信息
- [ ] 是否增加了国有资本保值增值相关影响分析
- [ ] 信用风险管理部分是否补充了国企内部信用评级和授信管理制度说明

### 七、决算报表特殊要求

- [ ] 应收账款数据是否与年度财务决算报表一致
- [ ] 决算报表附加信息表（如资产质量分析表）中的应收账款数据是否与本附注一致
- [ ] 应收账款中属于"不良资产"的部分是否按决算要求单独披露
- [ ] 应收账款损失是否纳入年度经营业绩考核的相关披露
- [ ] 集团合并层面内部应收账款抵销是否完整，抵销后余额是否与决算一致

## risk_areas

### 高风险

1. **长账龄应收账款未按国资要求披露**：3年以上应收账款未逐户说明原因和催收措施，可能被认定为国有资产流失管理不到位，涉及审计责任。
2. **关联方应收账款范围遗漏**：未将同一国有控股股东下的兄弟单位纳入关联方披露范围，导致关联交易信息不完整，违反CAS36和国资委要求。
3. **坏账核销缺少"三重一大"程序说明**：大额坏账核销（超过国资委规定限额）未经集体决策或未披露决策过程，存在合规风险。
4. **国有资金占用未单独披露**：其他国有企业或政府部门长期占用资金以应收账款挂账，未按国资委要求单独说明，可能掩盖国有资产流失。
5. **基础披露与审定表数据不勾稽**：附注应收账款各维度合计与审定表审定数不一致，属重大数据错误。

### 中风险

1. **预算执行偏差未充分说明**：应收账款回收率远低于年度预算目标但未说明原因和改进措施，影响经营业绩考核信息的可靠性。
2. **"同受国有控制"豁免条款适用不当**：不符合豁免条件却简化了同受国家控制关联方的披露，导致关联交易信息不充分。
3. **核销责任追究信息缺失**：已核销的大额应收账款未说明是否启动了责任追究程序，不符合国有资产损失责任追究制度要求。
4. **决算报表与审计报表口径差异未调节**：财务决算数据与审计后附注数据存在差异但未编制调节说明。
5. **诉讼/仲裁进展披露不及时**：涉诉应收账款的最新进展未更新至附注中，信息滞后影响使用者判断。

### 低风险

1. **披露格式未完全按决算报表模板**：附注格式与国资委决算报表模板有细微差异（如表格列序），但信息内容完整。
2. **资金占用利息说明过于简略**：关联方资金占用已披露但占用利息的计算依据未详细说明。
3. **预算对比分析维度单一**：仅对比余额未对比周转率/回收率等多维度指标，分析深度不足。
4. **历史年度信息追溯不完整**：应收账款增减变动的历史趋势分析仅覆盖2年而非国资委建议的3年。
