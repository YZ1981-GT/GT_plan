# D4-12 收入合同检查表复核提示词

## 概述

本提示词针对收入合同检查表（D4-12）的复核，聚焦四大核心审计要点：CAS14 合同识别、单项履约义务识别、交易价格确定、合同条款关键要素核查。合同是收入确认五步法的起点和证据基础，合同检查通过审阅销售合同的成立要件、履约义务、价格条款、控制权转移安排等，验证收入确认的合规性和真实性，是从源头识别收入舞弊（虚假合同、条款操纵、履约义务误判）的关键程序。

**法规依据：**
- 《企业会计准则第14号——收入》（五步法首二步：识别合同、识别单项履约义务）
- 《中国注册会计师审计准则第1301号——审计证据》
- 《中国注册会计师审计准则第1141号——财务报表审计中与舞弊相关的责任》
- 《中华人民共和国民法典》（合同编）

## tips

1. **合同识别是五步法的起点（CAS14步骤一）**：须核实合同满足五项条件（各方批准并承诺履行/可辨认各方权利义务/有明确支付条款/具有商业实质/对价很可能收回），任一条件不满足则不能确认收入。
2. **单项履约义务识别决定收入拆分（步骤二）**：须核实合同中可明确区分的商品或服务，捆绑销售须拆分为多个履约义务，履约义务识别错误将导致收入确认时点和金额错误。
3. **合同条款是控制权转移判断的依据**：交货条款（FOB/CIF）、验收条款、退货条款、风险报酬转移安排等决定收入确认时点，须逐一核查关键条款。
4. **警惕合同真实性与阴阳合同**：须核实合同的真实性（签章、日期、对方主体）、是否存在阴阳合同、抽屉协议、附加回购/退货安排等隐藏条款影响收入确认。
5. **交易价格条款验证收入金额（步骤三）**：合同价格、折扣、返利、可变对价条款须与实际确认收入金额勾稽，价格条款操纵将直接影响收入金额。
6. **勾稽关系**：合同金额 ↔ D4-2明细表收入；合同履约义务 ↔ 收入确认时点；合同价格条款 ↔ D4-10/D4-11价格分析，勾稽断裂为复核重点。

## checklist

### 一、CAS14 合同识别（高风险）

- [ ] 【必检】合同是否经各方批准并承诺履行各自义务
- [ ] 【必检】合同是否明确可辨认各方与所转让商品相关的权利义务
- [ ] 【必检】合同是否有明确的支付条款
- [ ] 【必检】合同是否具有商业实质
- [ ] 【必检】企业因转让商品有权取得的对价是否很可能收回
- [ ] 【必检】合同签章、日期、对方主体是否真实有效
- [ ] 【条件检查：若为框架合同】框架合同下的具体订单是否单独识别
- [ ] 【风险检查】是否存在虚假合同或伪造签章
- [ ] 【风险检查】是否存在阴阳合同、抽屉协议、隐藏回购条款

### 二、单项履约义务识别（高风险）

- [ ] 【必检】合同中的单项履约义务是否正确识别（可明确区分的商品/服务）
- [ ] 【必检】捆绑销售是否拆分为多个履约义务
- [ ] 【必检】商品与安装/培训/维护等服务是否合理拆分或合并
- [ ] 【条件检查：若含质保】质保是否区分为保证类质保（不单独确认）和服务类质保
- [ ] 【风险检查】是否存在履约义务拆分/合并错误影响收入确认

### 三、交易价格确定（高风险）

- [ ] 【必检】合同交易价格是否明确
- [ ] 【必检】折扣、返利、退货等可变对价条款是否核查
- [ ] 【必检】合同价格是否与实际确认收入勾稽
- [ ] 【条件检查：若含可变对价】可变对价估计是否受"极可能不重大转回"限制
- [ ] 【条件检查：若分期收款超一年】是否评估重大融资成分
- [ ] 【风险检查】是否存在价格条款操纵虚增收入

### 四、合同条款关键要素核查（中风险）

- [ ] 【必检】交货条款（FOB/CIF/工厂交货）是否明确
- [ ] 【必检】验收条款及验收标准是否明确
- [ ] 【必检】风险报酬/控制权转移时点是否清晰
- [ ] 【必检】退货/换货条款是否核查并影响收入确认
- [ ] 【条件检查：若有特殊条款】回购、寄售、代销等特殊安排是否识别
- [ ] 【风险检查】合同条款是否与实际收入确认时点一致
- [ ] 【风险检查】是否存在通过条款设计规避收入确认标准

## risk_areas

### 高风险

1. **虚假合同虚增收入**：伪造销售合同、伪造签章、虚构对方主体以支撑虚增收入，涉及发生认定，是收入舞弊的源头。
2. **隐藏条款操纵收入**：存在阴阳合同、抽屉协议、附加回购/退货安排等隐藏条款，实质不满足收入确认条件却确认收入。
3. **合同识别条件不满足**：合同缺乏商业实质、对价收回存疑或缺少明确支付条款，却确认了收入。
4. **履约义务识别错误**：捆绑销售未拆分或过度拆分履约义务，导致收入确认时点和金额系统性错误。
5. **合同金额与收入不勾稽**：合同约定金额与实际确认收入不一致且无补充协议，反映收入金额失真。

### 中风险

1. **可变对价条款未审慎处理**：折扣、返利、退货条款的可变对价估计过于乐观，虚增收入。
2. **控制权转移时点误判**：交货/验收条款约定的控制权转移时点与实际收入确认时点不一致。
3. **特殊安排未识别**：回购、寄售、代销等特殊安排未识别，按普通销售确认收入。
4. **重大融资成分未拆分**：长期分期收款合同未评估和拆分重大融资成分。
5. **合同条款不完整**：合同缺少关键条款（验收标准/退货安排）影响收入确认判断。

### 低风险

1. **合同文档管理不规范**：合同归档、编号、索引不规范，影响追溯。
2. **合同抽样覆盖不足**：合同检查样本覆盖面不足，未覆盖高风险交易。
3. **条款核查记录不详**：合同关键条款核查记录过于简略。
4. **交叉索引不完整**：与明细表、价格分析、发生测试底稿的交叉引用不全。
