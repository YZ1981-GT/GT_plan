# D3-5 长期挂账检查表复核提示词

## 概述

本提示词针对预收账款/合同负债长期挂账检查表（D3-5）的复核，聚焦四大核心审计要点：长期挂账款项识别完整性、是否应确认收入（CAS14履约义务判断）、是否应退回、是否应转营业外收入。长期挂账的合同负债往往隐含收入确认时点错误、无法履约款项、丧失商业实质的沉淀资金等风险，是收入完整性和负债真实性审计的高风险领域，也是识别利润蓄水池操纵的关键环节。

**法规依据：**
- 《企业会计准则第14号——收入》
- 《中国注册会计师审计准则第1301号——审计证据》
- 《中国注册会计师审计准则第1141号——财务报表审计中与舞弊相关的责任》
- 《中国注册会计师审计准则第1324号——持续经营》

---

## tips

1. **长期挂账识别须完整**：所有超过正常履约周期（通常1年以上）未结转的合同负债均应纳入检查范围，识别不完整将遗漏重大收入确认或退款风险。
2. **CAS14履约义务判断是核心**：对每笔长期挂账须判断相关履约义务是否已履行，若已履行则应结转收入（借合同负债、贷收入），长期不结转可能为利润蓄水池操纵。
3. **应退回款项须评估负债真实性**：客户已放弃履约、合同已终止或超过退款期的款项，应评估是否仍构成合同负债，或应转其他应付款/营业外收入。
4. **无法履约款项的会计处理**：因企业无法履约（如产品停产、服务终止）导致的长期挂账，若无退款义务且已丧失商业实质，可能应转营业外收入并披露。
5. **长期挂账是舞弊风险的重要信号**：长期挂账合同负债可能被用作跨期调节利润的工具，或掩盖虚假预收，须保持职业怀疑，追溯资金来源和合同真实性。
6. **处理结论须有明确依据和联动**：每笔长期挂账的处理结论（应确认收入→D4/应退回→其他应付款/应转营业外收入→营业外收入）须有支持性证据，并联动至相应底稿和调整分录。

## checklist

### 一、长期挂账款项识别完整性

- [ ] 是否将所有超过1年未结转的合同负债全部纳入检查
- [ ] 长期挂账清单金额合计是否与D3-2明细表长账龄段一致
- [ ] 是否逐笔列示客户名称、合同编号、挂账金额、挂账起始日、账龄
- [ ] 是否标注每笔长期挂账的履约状态和挂账原因
- [ ] 是否识别客户已失联、合同已终止、企业已无法履约的款项
- [ ] 是否存在应纳入但被遗漏的长期挂账款项（与账龄分析交叉核对）

### 二、是否应确认收入（CAS14判断）

- [ ] 每笔长期挂账相关履约义务是否已履行是否逐笔判断
- [ ] 已履约完成的款项是否应结转收入而未结转
- [ ] 履约进度判断是否有支持性证据（发货单/验收单/服务完成记录）
- [ ] 应确认收入的金额是否已编制调整分录并联动D3-3/D4
- [ ] 是否存在故意延迟确认收入以调节利润（利润蓄水池）的迹象
- [ ] 已履约但未结转的原因是否合理（如等待验收、质保期）

### 三、是否应退回

- [ ] 客户已放弃履约或要求退款的款项是否识别
- [ ] 合同约定的退款条件和退款期限是否核查
- [ ] 应退回款项是否仍列为合同负债还是应重分类至其他应付款
- [ ] 期后实际退款情况是否核查并验证负债真实性
- [ ] 是否存在应退未退长期占用客户资金的情况
- [ ] 退款义务的估计是否准确，是否影响流动性

### 四、是否应转营业外收入

- [ ] 因企业无法履约且无退款义务的款项是否识别
- [ ] 超过法定或约定退款期且客户未主张的款项是否评估
- [ ] 转营业外收入的判断是否符合负债终止确认条件
- [ ] 转营业外收入的金额、时点、依据是否充分记录
- [ ] 转营业外收入是否已编制调整分录并联动K12（营业外收入）
- [ ] 是否存在通过随意转营业外收入虚增利润的迹象

## risk_areas

### 高风险

1. **应确认收入未确认（利润蓄水池）**：已履约完成的长期挂账合同负债未结转收入，人为压低当期利润形成蓄水池，构成收入完整性和跨期错报。
2. **虚假预收长期挂账**：以合同负债名义挂账无真实合同支持的资金占用，掩盖资金往来实质，涉及存在性和舞弊风险。
3. **应退未退侵占客户资金**：客户已要求退款但企业长期挂账不退，负债真实性和持续经营存疑。
4. **随意转营业外收入虚增利润**：将仍有履约或退款义务的款项转营业外收入，虚增当期利润，构成负债和利润错报。

### 中风险

1. **长期挂账识别不完整**：部分长账龄合同负债未纳入检查，遗漏收入确认或退款风险。
2. **履约义务判断缺乏证据**：结转收入或不结转的判断无支持性证据，判断合理性存疑。
3. **处理结论未联动调整**：识别出应确认收入/应退/应转营业外收入但未编制调整分录或未联动相关底稿。
4. **退款义务估计不准**：应退回款项金额估计不准确，影响流动负债列报。

### 低风险

1. **挂账原因说明简略**：长期挂账原因仅简单归类，未详细说明具体情况。
2. **期后核查滞后**：期后退款或结转情况未及时更新至检查表。
3. **交叉索引不完整**：与明细表、收入底稿、调整分录、营业外收入底稿的交叉引用标注不全。
4. **格式规范性问题**：检查表格式不统一、栏目不完整等形式问题。
