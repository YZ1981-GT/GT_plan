# D7-note-listed 合同负债附注披露复核提示词（上市公司）

## 概述

本提示词针对合同负债上市公司附注披露底稿（D7-note-listed，科目码2205）的复核，聚焦上市公司财务报表附注中合同负债相关披露的充分性和准确性：合同负债分类披露、账龄披露、与合同资产/预收账款的关系披露、履约义务与收入确认时点披露、CAS14要求的充分性、以及重大合同负债变动披露。合同负债是CAS14引入的负债科目，其披露反映企业未履约义务及未来收入实现能力，是投资者评估收入可持续性的重要信息。

**法规依据：**
- 《企业会计准则第14号——收入》
- 《企业会计准则第37号——金融工具列报》
- 《企业会计准则第36号——关联方披露》
- 《公开发行证券的公司信息披露编报规则第15号——财务报告的一般规定》
- 《中国注册会计师审计准则第1501号——对财务报表形成审计意见和出具审计报告》

## tips

1. **合同负债披露以CAS14为核心**：合同负债源于收入准则，须披露其性质（已收对价而未履约的义务）、分类、与合同资产及预收账款的关系，帮助报表使用者理解未履约义务及未来收入。
2. **履约义务与收入确认时点是重点披露**：CAS14要求披露分摊至剩余履约义务的交易价格及预计确认收入的时间，合同负债对应未履约义务，其披露与收入确认时点信息关联。
3. **合同负债与合同资产、预收账款的关系须清晰**：附注须披露合同负债与合同资产按合同净额列示的情况，以及与预收账款的区分，避免混淆。
4. **账龄与长期挂账须匹配披露**：按账龄披露合同负债，长账龄（长期挂账）合同负债须说明原因，与D7-5长期挂账检查勾稽。
5. **重大合同负债变动须披露原因**：合同负债期末较期初重大变动（如大额预收或大额结转）须说明原因，反映业务模式或收入确认的变化。
6. **附注数据须与审定表/明细表/分析表形成闭环勾稽**：附注合同负债总额=审定表审定数；分类小计=明细表对应分类合计；账龄分析=D7-4；关联方合同负债=D7-6。

## checklist

### 一、分类与性质披露

- [ ] 合同负债的性质是否披露（已收对价而未履约的义务）
- [ ] 合同负债是否按业务性质/合同类型分类披露
- [ ] 各类别期末余额合计是否等于审定表合同负债审定数
- [ ] 各类别是否同时披露期末数和期初数（可比信息）
- [ ] 合同负债与合同资产的期末余额及净额列示关系是否披露
- [ ] 合同负债与预收账款的区分是否清晰
- [ ] 分类方式是否与会计政策中确定的分类标准一致

### 二、账龄披露

- [ ] 账龄披露是否按规定区间完整列示（1年以内/1-2年/2-3年/3年以上）
- [ ] 各账龄段金额合计是否等于合同负债总额
- [ ] 账龄起算日口径是否与会计政策一致且予以说明
- [ ] 长账龄（长期挂账）合同负债是否单独列示并说明原因
- [ ] 账龄结构较上期是否存在重大异常变动，如有是否已说明原因
- [ ] 账龄分析数据是否与D7-2明细表/D7-4分析表一致

### 三、履约义务与收入确认时点披露

- [ ] 是否披露分摊至剩余履约义务的交易价格（合同负债对应未履约义务）
- [ ] 是否披露预计将确认为收入的时间（履约义务完成时点）
- [ ] 本期确认的、原计入合同负债的收入金额是否披露
- [ ] 履约义务的性质及满足时点是否说明
- [ ] 收入确认时点披露是否与收入附注勾稽
- [ ] 是否披露重大融资成分（如预收款含融资性质）

### 四、重大变动与其他披露

- [ ] 合同负债期末较期初重大变动是否说明原因
- [ ] 本期新增大额合同负债（大额预收）是否披露
- [ ] 本期大额结转收入的合同负债是否披露
- [ ] 关联方合同负债是否单独披露（名称/关系/金额，与D7-6勾稽）
- [ ] 长期挂账转营业外收入的合同负债是否披露（与D7-5勾稽）
- [ ] 涉及退款义务的合同负债是否说明

## risk_areas

### 高风险

1. **合同负债性质及履约义务未披露**：未披露合同负债的性质及对应未履约义务，报表使用者无法评估未来收入实现。
2. **附注总额与审定表不一致**：附注合同负债期末余额与审定表审定数不一致，属数据勾稽重大错误。
3. **收入确认时点信息缺失**：未披露分摊至剩余履约义务的交易价格及预计确认收入时间，不满足CAS14要求。
4. **关联方合同负债未单独披露**：关联方合同负债混入一般对方未单独列示，违反CAS36要求。
5. **长期挂账及退款义务未披露**：长期挂账或涉及退款义务的合同负债未披露，掩盖收入确认或偿付问题。

### 中风险

1. **账龄披露口径不一致**：附注账龄起算日与明细表/分析表不一致，账龄结构失真。
2. **合同负债与合同资产关系披露缺失**：未披露合同负债与合同资产按合同净额列示的关系。
3. **合同负债与预收账款混淆**：未清晰区分合同负债与预收账款的披露。
4. **重大变动未说明原因**：合同负债重大增减变动未说明原因。
5. **可比信息缺失**：附注中仅列示期末数据，未列示期初可比数据。

### 低风险

1. **披露格式不完全规范**：表格标题、列序、金额单位等格式细节问题。
2. **文字描述模板化**：履约义务描述照搬会计政策原文，未结合本企业实际业务。
3. **数字精度不一致**：部分披露保留两位小数、部分取整到万元，精度不统一。
4. **重大融资成分披露简略**：含融资性质的预收款仅提及事实，未量化说明。
