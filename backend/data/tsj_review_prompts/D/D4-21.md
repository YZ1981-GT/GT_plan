# D4-21 关联方交易价格检查表复核提示词

## 概述

本提示词针对营业收入关联方交易价格检查表（D4-21）的复核，聚焦关联方销售定价的公允性、是否存在通过关联交易进行利益输送或虚增收入。关联方交易是收入舞弊和利益输送的高发领域，非公允定价的关联销售可能虚增收入、转移利润或掩盖关联方资金占用。复核须结合CAS1323关联方审计要求，穿透识别关联关系并评估定价公允性。

**法规依据：**
- 《企业会计准则第14号——收入》
- 《中国注册会计师审计准则第1323号——关联方》
- 《企业会计准则第36号——关联方披露》
- 《中国注册会计师审计准则第1141号——财务报表审计中与舞弊相关的责任》

## tips

1. **关联方定价公允性须有可比基准**：关联销售价格应与同期非关联方交易价格、市场公允价格或独立第三方报价比较，缺乏可比基准或显著偏离市场价的定价须重点质疑（CAS1323）。
2. **关联交易是利益输送与收入操纵的高危区**：通过高价向关联方销售虚增收入、低价销售转移利润、无商业实质的循环交易做大收入，均为常见手段，须穿透业务实质而非仅看表面价格。
3. **关联关系识别须穿透至实际控制**：除已披露关联方外，须警惕通过隐性关联方（同一实际控制人、共同高管、异常一致的经营特征）进行的未披露关联交易（关联D4-27）。
4. **关联销售的收付款与商业实质匹配性**：关联方销售是否伴随真实货物流、资金流，回款是否正常，警惕仅有账面收入而无实际交付或款项长期挂账的虚假关联交易（CAS1141）。
5. **定价政策一致性与变动分析**：关联交易定价政策是否与非关联交易一致、是否年度间保持稳定，期末临近突击的关联销售或定价异常调整须重点核查。
6. **关联销售须与披露、抵销勾稽**：关联销售金额须与关联方披露（CAS36）、合并报表内部交易抵销一致，防范披露遗漏或抵销不完整。

## checklist

### 一、关联关系识别

- [ ] 关联销售对手方是否已全部识别为关联方并纳入检查范围
- [ ] 是否核查隐性关联方（同一实际控制人/共同高管/异常一致特征）
- [ ] 关联方名单是否与B19关联方登记、工商信息交叉核对
- [ ] 是否存在以非关联方名义进行的实质关联交易
- [ ] 新增关联销售对手方是否评估其关联关系
- [ ] 关联关系类型是否明确（控股股东/子公司/联营合营/共同控制人等）

### 二、定价公允性核查

- [ ] 关联销售价格是否与同期非关联方交易价格比较
- [ ] 关联销售价格是否与市场公允价/独立第三方报价比较
- [ ] 是否存在显著高于市场价销售（虚增收入嫌疑）
- [ ] 是否存在显著低于市场价销售（利润转移嫌疑）
- [ ] 定价政策是否与非关联交易一致
- [ ] 定价依据（市场价/成本加成/协议价/政府定价）是否明确且合理
- [ ] 缺乏可比基准的关联销售是否采用其他方法评估公允性

### 三、商业实质核查

- [ ] 关联销售是否伴随真实货物流（发货/物流/验收记录）
- [ ] 关联销售的回款是否正常，是否存在长期挂账
- [ ] 是否存在无商业实质的循环交易做大收入
- [ ] 期末临近的大额关联销售是否核查业务真实性
- [ ] 关联销售的毛利率是否与非关联交易存在异常差异
- [ ] 是否存在关联方资金占用以销售收入名义挂账的迹象

### 四、披露与勾稽

- [ ] 关联销售金额是否与CAS36关联方披露一致
- [ ] 合并报表内部关联销售是否完整抵销
- [ ] 关联销售定价的公允性说明是否在附注充分披露
- [ ] 关联销售金额是否与D4收入明细、审定表勾稽
- [ ] 关联应收款项是否与D2应收账款关联方明细一致
- [ ] 关联交易占收入总额比例是否合理，异常高企是否已分析

## risk_areas

### 高风险

1. **非公允定价虚增收入**：以显著高于市场价向关联方销售虚增营业收入，配合关联方资金回流做实，属重大收入舞弊（CAS1141）。
2. **利润转移与利益输送**：以显著低于市场价向关联方销售转移利润，或高价采购变相输送利益，损害中小股东和国有资产利益。
3. **无实质循环交易做大收入**：关联方间无真实货物交付的循环购销做大收入规模，虚增业务体量，常见于IPO或业绩粉饰。
4. **隐性关联交易未识别**：通过未披露的隐性关联方进行非公允交易，规避关联交易披露和监管（关联D4-27）。

### 中风险

1. **定价公允性缺乏基准**：关联销售缺少可比非关联交易或市场价基准，公允性无法有效评估。
2. **关联应收长期挂账**：关联销售形成的应收款项长期挂账不催收，实质为资金占用。
3. **披露与抵销不完整**：关联销售披露遗漏或合并抵销不完整，导致关联交易信息失真。
4. **毛利率异常未分析**：关联交易毛利率与非关联交易显著差异但未分析原因。

### 低风险

1. **定价依据文档不完整**：关联交易定价政策及依据未形成完整书面记录。
2. **底稿记录不充分**：定价公允性比较过程、可比数据来源记录不完整。
3. **交叉索引缺失**：与关联方登记、收入明细、应收账款明细、附注披露的交叉引用不完整。
