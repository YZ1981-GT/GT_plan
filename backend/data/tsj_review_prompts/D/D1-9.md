# D1-9 带息票据利息检查表复核提示词

## 概述

本提示词针对应收票据带息票据利息检查表（D1-9）的复核，聚焦四大核心审计要点：带息票据的识别完整性、利息计提方法（实际利率法）的恰当性、利息计算的准确性、利息收入的期间归属。多数应收票据为不带息票据（到期按票面金额收款），但对于约定利率的带息票据，须按 CAS22 采用实际利率法确认利息收入并计入应收票据账面价值。利息计提遗漏将导致应收票据账面价值和利息收入双低估，计提错误将影响期末余额准确性。

**法规依据：**
- 《企业会计准则第22号——金融工具确认和计量》（实际利率法）
- 《企业会计准则第37号——金融工具列报》
- 《中国注册会计师审计准则第1301号——审计证据》

## tips

1. **带息票据的识别是利息检查的前提**：须从票据要素中识别所有约定利率的带息票据（银行承兑汇票通常不带息，部分商业承兑汇票或特殊安排票据可能带息），遗漏带息票据将导致利息收入和账面价值低估。
2. **实际利率法是 CAS22 的计量要求**：带息票据的利息收入应按实际利率法确认，而非简单的名义利率直线计提，尤其当票据存在溢折价或交易费用时，实际利率与票面利率可能不同。
3. **利息计算准确性依赖三要素**：利息=计息本金×利率×计息天数，须核对计息本金（票面金额）、利率（票面/实际利率）、计息期间（出票日至资产负债表日）三要素的准确性。
4. **利息收入的期间归属须准确**：应计利息应按权责发生制在持有期间分期确认，须核对资产负债表日应计利息的截止是否正确，不得跨期确认。
5. **应计利息须与审定表和明细表勾稽**：D1-9 计算的期末应计利息须计入 D1-1 审定表应收票据余额（或单独列示应收利息），并与 D1-2 分类明细的利息列勾稽。
6. **关注利息与到期兑付的一致性**：票据到期兑付时收到的利息应与累计计提的应计利息一致，差异须查明；利息收入的对方科目（投资收益/财务费用/其他）列示是否恰当。

## checklist

### 一、带息票据识别完整性

- [ ] 是否从票据要素完整识别所有带息票据（约定利率的票据）
- [ ] 带息票据的利率、计息起止日是否完整记录
- [ ] 是否存在带息票据被遗漏未计提利息的情况
- [ ] 带息票据清单是否与 D1-2 分类明细中的带息标注一致
- [ ] 无息票据是否正确未计提利息
- [ ] 特殊安排票据（含溢折价）是否识别并单独处理

### 二、利息计提方法恰当性

- [ ] 带息票据是否按 CAS22 实际利率法确认利息收入
- [ ] 存在溢折价/交易费用的票据是否采用实际利率而非票面利率
- [ ] 实际利率的确定是否有测算依据
- [ ] 利息计提方法是否与会计政策（D1-14）一致
- [ ] 计提方法前后期是否一致
- [ ] 是否恰当区分利息收入的核算科目

### 三、利息计算准确性

- [ ] 计息本金（票面金额）是否准确
- [ ] 适用利率（票面/实际利率）是否正确
- [ ] 计息天数（出票日/持有起始日至资产负债表日）是否正确
- [ ] 利息计算公式和结果是否准确（本金×利率×天数）
- [ ] 应计利息合计是否正确汇总
- [ ] 是否重新计算复核抽样票据的利息金额

### 四、利息收入期间归属与勾稽

- [ ] 应计利息是否按权责发生制在持有期间分期确认
- [ ] 资产负债表日应计利息截止是否正确，无跨期确认
- [ ] 期末应计利息是否计入 D1-1 审定表或单独列示应收利息
- [ ] 应计利息是否与 D1-2 分类明细利息列勾稽
- [ ] 到期兑付收到利息是否与累计计提应计利息一致
- [ ] 利息收入对方科目（投资收益/财务费用等）列示是否恰当

## risk_areas

### 高风险

1. **带息票据遗漏计提利息**：未识别约定利率的带息票据导致利息收入和应收票据账面价值双低估。
2. **利息跨期确认操纵利润**：将下期利息提前确认或本期利息递延，人为调节利润。
3. **应计利息未与审定表勾稽**：D1-9 计提利息未计入 D1-1 审定表余额，导致资产低估。
4. **实际利率法适用错误**：含溢折价票据仍按票面利率直线计提，利息收入计量错误。

### 中风险

1. **计息要素错误**：计息本金、利率或计息天数错误导致利息金额错报。
2. **利息核算科目错误**：利息收入计入错误科目（如应计入投资收益却计入财务费用冲减）。
3. **到期利息与计提不一致差异未查明**：兑付利息与累计应计利息差异未调查。
4. **计提方法前后期不一致**：利息计提方法变更未恰当处理。

### 低风险

1. **检查表格式不规范**：利息计算栏目、公式列示格式问题。
2. **实际利率测算文档不充分**：实际利率确定过程记录简略。
3. **交叉索引不完整**：与审定表、分类明细、损益类底稿的索引标注不全。
4. **计息天数惯例未说明**：按实际天数或约定天数计息的惯例未注明。
