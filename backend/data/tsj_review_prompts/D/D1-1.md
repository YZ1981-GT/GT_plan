# D1-1 审定表复核提示词

## 概述

本提示词针对应收票据审定表（D1-1）的复核，聚焦四大核心审计要点：期初期末勾稽、试算平衡表（1121科目）核对、审计调整完整性、分类列报准确性。审定表是应收票据科目审计的枢纽底稿，承载未审数→调整→审定数的完整链路，须特别关注银行承兑汇票与商业承兑汇票的分类、已背书/已贴现未到期票据的终止确认列报，以及一年内到期票据的流动性分类，任何勾稽断裂或分类错误均可能导致财务报表重大错报。

**法规依据：**
- 《企业会计准则第22号——金融工具确认和计量》
- 《企业会计准则第23号——金融资产转移》
- 《企业会计准则第37号——金融工具列报》
- 《中国注册会计师审计准则第1301号——审计证据》

## tips

1. **期初期末勾稽是审定表的生命线**：期初审定数必须等于上年期末审定数（承前启后），任何差异需追溯至调整分录或会计政策变更，不得存在无源差异；应收票据周转快，期末余额构成与期初可能完全不同，须结合背书、贴现、到期兑付逐笔理解变动。
2. **银承与商承必须分列审定**：银行承兑汇票由银行承兑（信用风险低），商业承兑汇票由企业承兑（信用风险高、可能计提减值），审定表须按承兑人类型分列，混列将掩盖信用风险敞口并影响 D1-4 坏账计提基础。
3. **已背书/已贴现未到期票据的列报是审定表特有难点**：根据 CAS23，未满足终止确认条件的已背书或已贴现票据仍应保留在应收票据科目内并披露，审定表期末余额是否包含此类票据须与 D1-8 背书贴现明细表勾稽。
4. **试算平衡表是勾稽的第一道防线**：审定表应收票据审定数合计必须与试算平衡表 1121 科目审定数完全一致；若计提减值，减值准备须与 1231 科目审定数按借贷方向核对。
5. **一年内到期与流动性分类**：应收票据通常为流动资产，但到期日超过一年的（如长期分期收款票据）须重分类，审定表分类须与 D1-2 到期日分析一致。
6. **审定表是跨底稿勾稽的中心节点**：审定表数据应与 D1-2 分类明细合计、D1-4 坏账准备、D1-8 背书贴现、D1-9 带息利息、试算平衡表、财务报表附注形成闭环勾稽，任何节点断裂均为复核重点。

## checklist

### 一、期初期末勾稽

- [ ] 审定表期初未审数是否等于上年审定表期末审定数（承前启后核对）
- [ ] 期末审定数是否等于期初审定数加本期收取票据减本期背书/贴现/到期兑付（加减审计调整）
- [ ] 银行承兑汇票、商业承兑汇票各类别期初期末变动是否与 D1-2 明细表一致
- [ ] 是否存在期初差异未做说明的情况（会计政策变更、前期差错更正等）
- [ ] 带息票据本期计提利息是否已计入期末余额并与 D1-9 勾稽
- [ ] 是否存在期初数据被人为修改但未留痕的情况

### 二、试算平衡表核对

- [ ] 审定表应收票据审定数合计是否与试算平衡表 1121 科目审定数一致
- [ ] 若计提减值，坏账/减值准备审定数是否与试算平衡表 1231 科目审定数一致（借贷方向核对）
- [ ] 审定表银承/商承各明细类别审定数之和是否等于一级科目审定数
- [ ] 试算平衡表中未审数与审定表未审数是否一致
- [ ] 试算平衡表中调整数（AJE+RJE）与审定表调整数是否一致
- [ ] 是否存在试算平衡表已更新但审定表未同步的情况

### 三、审计调整完整性

- [ ] 所有已确认的账项调整分录（AJE）是否已完整反映在审定表调整列
- [ ] 所有已确认的重分类调整分录（RJE）是否已完整反映在审定表重分类列（如银承转应收账款、贴现终止确认调整）
- [ ] 调整分录的借贷方金额是否平衡（借方合计=贷方合计）
- [ ] 审定表调整后金额是否等于未审数+AJE调整+RJE调整
- [ ] 建议但未调整的错报是否已记录于未调整错报汇总表（SUD）并与 A13 交叉验证
- [ ] 调整分录是否均有充分的审计证据支持和合伙人审批

### 四、分类列报准确性

- [ ] 应收票据是否按承兑人类型正确分类（银行承兑汇票/商业承兑汇票）
- [ ] 已背书转让但未终止确认的票据是否仍列示于应收票据并单独标注
- [ ] 已贴现但未终止确认的票据是否仍列示于应收票据并单独标注
- [ ] 已质押的应收票据是否作为受限资产单独列示或披露
- [ ] 关联方应收票据是否在审定表中单独列示
- [ ] 到期日超过一年的应收票据是否已重分类至非流动资产或充分披露
- [ ] 审定表中的分类是否与财务报表附注披露的分类一致

## risk_areas

### 高风险

1. **期初期末不勾稽**：期初审定数与上年期末审定数不一致，可能存在未经授权的调整或数据录入错误，直接导致本期审定数失去基准。
2. **审计调整遗漏**：已确认的调整分录（尤其贴现终止确认调整）未反映在审定表中，导致审定数不真实。
3. **已背书/已贴现票据终止确认错误**：不满足 CAS23 终止确认条件的票据被错误终止确认（提前出表），或应终止确认的票据仍挂账，导致资产与负债列报错误。
4. **银承商承混列掩盖信用风险**：将高风险商业承兑汇票与低风险银行承兑汇票混列，掩盖信用风险敞口，导致减值计提不足。
5. **试算平衡表与审定表不一致**：两者数据口径不一致，意味着存在未被发现的汇总错误或调整遗漏。

### 中风险

1. **明细与汇总不勾稽**：审定表各类别合计与 D1-2 分类明细表总计不一致，可能存在明细遗漏或重复。
2. **减值/坏账准备列示不准确**：减值准备金额未与 D1-4/D1-15 勾稽，或扣减方向错误。
3. **带息票据利息计提未入账**：带息票据应计利息未计提或未计入期末余额，与 D1-9 不勾稽。
4. **重分类调整方向错误**：RJE 借贷方向颠倒导致审定数偏离真实值。
5. **未调整错报累积超过重要性**：单项未调整错报未超重要性，但累计后可能超过整体重要性水平。

### 低风险

1. **审定表格式不规范**：列标题、行顺序、编号等格式问题不影响数据准确性，但影响底稿可读性。
2. **底稿交叉索引不完整**：审定表未与相关底稿（试算平衡表、明细表、背书贴现表）建立完整索引引用。
3. **辅助说明不充分**：审定表中变动较大的行项目未附简要说明。
4. **历史数据对比缺失**：审定表未列示前期可比数据，不便于分析趋势和异常。
