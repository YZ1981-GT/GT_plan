# D1-5 调整分录汇总表复核提示词

## 概述

本提示词针对应收票据调整分录汇总表（D1-5）的复核，含账项调整（AJE）、重分类调整（RJE）及未调整错报（SUD）评估。应收票据的调整具有特殊性：贴现/背书的终止确认调整、银行承兑汇票转应收账款、带息票据补计提利息、逾期商业承兑汇票转应收账款并补提减值、一年内到期重分类等均通过本表实现。复核须验证每笔调整有证据、借贷平衡、完整反映到 D1-1 审定表，且 SUD 评估符合重要性水平要求。

**法规依据：**
- 《企业会计准则第23号——金融资产转移》（背书/贴现终止确认）
- 《企业会计准则第28号——会计政策、会计估计变更和差错更正》
- 《中国注册会计师审计准则第1301号——审计证据》
- 《中国注册会计师审计准则第1324号——持续经营》

## tips

1. **AJE 与 RJE 的区分**：AJE 影响损益或资产/负债金额（如补计提减值、补计提利息）；RJE 仅影响列报（如贴现终止确认重分类、一年内到期重分类），不得通过 RJE 掩盖损益错报。
2. **终止确认调整是应收票据特有的核心调整**：根据 CAS23，已贴现/已背书票据若不满足终止确认条件，须调整恢复应收票据与相应负债（短期借款/其他应付款），此类调整须与 D1-8 背书贴现明细表逐笔勾稽。
3. **与 D1-1 审定表勾稽**：审定表调整列金额须与 D1-5 已确认分录逐笔一致，遗漏任一笔即审定数失真；重分类调整须准确反映银承/商承分类变化。
4. **审批链**：超过明细层次重要性水平的调整须经合伙人/项目经理审批留痕，尤其涉及承兑人违约的减值调整和大额终止确认调整。
5. **SUD 累计评估**：未调整错报单独及累计是否超过整体/明显微小错报阈值，须与 A13 未调整错报汇总表交叉验证。
6. **TB 回写**：确认调整已同步试算平衡表 1121/1231 科目，避免"底稿已调、TB 未更"的双真源不一致。

## checklist

### 一、账项调整（AJE）完整性

- [ ] 所有 AJE 是否有充分审计证据（承兑人违约证据、利息测算、减值评估等）
- [ ] 补计提减值调整是否与 D1-4/D1-15 减值计算勾稽
- [ ] 带息票据补计提利息调整是否与 D1-9 利息检查勾稽
- [ ] 逾期商业承兑汇票转应收账款并补提减值的调整是否恰当
- [ ] AJE 是否经适当层级审批（超重要性水平须合伙人知悉）
- [ ] 每笔调整分录借贷方是否完全平衡
- [ ] AJE 调整金额是否完整反映到 D1-1 审定表对应调整列

### 二、重分类调整（RJE）恰当性

- [ ] 贴现/背书未终止确认票据的恢复调整是否与 D1-8 勾稽（CAS23）
- [ ] 银行承兑汇票到期转应收账款的重分类是否恰当
- [ ] 一年内到期票据与非流动重分类是否正确
- [ ] RJE 是否仅涉及列报，未影响损益类科目
- [ ] 终止确认调整的对方科目（短期借款/其他应付款）是否正确
- [ ] RJE 借贷方向是否正确，未颠倒或冲抵不完全

### 三、未调整错报（SUD）评估

- [ ] 未调整错报是否单独及累计评估是否超过整体重要性水平
- [ ] SUD 是否与 A13 未调整错报汇总表交叉验证一致
- [ ] 建议调整与已执行调整是否区分记录
- [ ] 跨期调整是否正确区分本期错报与前期差错更正
- [ ] 未调整错报对应收票据净额/利润的影响是否已评估
- [ ] 累计未调整错报仍出具无保留意见的合理性是否评估

### 四、勾稽与追溯

- [ ] 调整分录编号是否连续，删除后重号风险是否可控
- [ ] 调整原因说明是否清晰可追溯至具体审计程序
- [ ] 调整后审定数是否已回写试算平衡表 1121/1231 科目
- [ ] 索引是否指向 D1-8 背书贴现、D1-13 凭证检查、函证回函等支持底稿
- [ ] 调整分录摘要、科目编码是否规范
- [ ] 审计说明/结论是否概括调整性质与剩余风险

## risk_areas

### 高风险

1. **终止确认调整缺失或错误**：不满足 CAS23 终止确认条件的贴现/背书票据未恢复入表，导致资产和负债双低估。
2. **调整缺乏证据或未经授权**：重大减值调整或终止确认调整无充分证据或未经合伙人审批。
3. **审定表与 D1-5 调整金额不一致**：调整未完整反映到审定表，导致审定数失真。
4. **SUD 累计超阈值未恰当处理**：未调整错报累计超过整体重要性水平仍出具无保留意见而未评估。
5. **减值调整被人为规避**：应补计提的商业承兑汇票减值调整被列为未调整错报以粉饰利润。

### 中风险

1. **RJE 误含损益影响**：重分类调整错误地影响了损益类科目。
2. **跨期调整分类错误**：本期错报与前期差错更正区分不当。
3. **利息补提调整遗漏**：带息票据应计利息调整遗漏或计算错误。
4. **TB 回写不同步**：调整已在底稿反映但未同步试算平衡表。

### 低风险

1. **编号、格式不规范**：调整分录编号不连续、科目编码不规范。
2. **索引指向不完整**：与支持底稿的交叉索引缺失。
3. **审计说明简略**：调整性质与剩余风险说明不充分。
