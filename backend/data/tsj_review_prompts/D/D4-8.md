# D4-8 产品毛利分析表复核提示词

## 概述

本提示词针对产品毛利分析表（D4-8）的复核，聚焦四大核心审计要点：分产品毛利率合理性、异常高/低毛利产品识别、毛利率结构与趋势分析、与量价成本的分解验证。产品毛利分析是从产品维度分解收入与成本的配比关系，通过识别异常高毛利（虚增收入信号）和异常低毛利（成本倒挂/降价倾销）产品，精准定位收入舞弊和错报的产品层面根源。

**法规依据：**
- 《企业会计准则第14号——收入》
- 《中国注册会计师审计准则第1301号——审计证据》
- 《中国注册会计师审计准则第1231号——针对评估的重大错报风险采取的应对措施》
- 《中国注册会计师审计准则第1313号——分析程序》

## tips

1. **产品毛利率是虚增收入的产品级探针**：单个产品毛利率异常偏高（收入虚增无对应成本）远比综合毛利率更易暴露，须逐产品对比历史和同类产品毛利水平。
2. **异常高毛利产品需核实收入真实性**：毛利率显著高于同类产品或历史水平的产品，须核实其收入是否有真实交易、成本是否完整结转、单价是否合理。
3. **异常低毛利/负毛利产品揭示商业实质问题**：负毛利或极低毛利产品可能反映成本倒挂、关联方低价交易、降价倾销或成本高估，需评估商业合理性。
4. **毛利率须与量价成本分解匹配**：产品毛利率变动应能用单价变动、单位成本变动、产品结构变动分解解释，无法分解的毛利率变动需追溯。
5. **产品结构变动影响综合毛利率**：高毛利产品占比上升会推高综合毛利率，须区分是结构变动还是单产品毛利率变动导致综合毛利率变化。
6. **勾稽关系**：各产品收入合计 = D4-2主营业务收入；各产品毛利率加权 = 综合毛利率（D4-6）；产品单价 ↔ D4-11产品价格分析，勾稽断裂为复核重点。

## checklist

### 一、分产品毛利率合理性（高风险）

- [ ] 【必检】各产品收入、成本、毛利、毛利率是否完整列示
- [ ] 【必检】各产品毛利率是否与上期对比列示趋势
- [ ] 【必检】各产品收入合计是否等于 D4-2 主营业务收入
- [ ] 【必检】各产品毛利率加权是否与综合毛利率（D4-6）勾稽
- [ ] 【必检】同类产品毛利率是否处于合理可比区间
- [ ] 【条件检查：若有新产品】新产品毛利率是否合理
- [ ] 【风险检查】是否存在产品毛利率明显偏离行业/历史水平

### 二、异常高毛利产品识别（高风险）

- [ ] 【必检】毛利率显著高于同类产品的产品是否标注
- [ ] 【必检】高毛利产品的收入是否有真实交易支撑
- [ ] 【必检】高毛利产品的成本是否完整结转（无成本漏记）
- [ ] 【条件检查：若毛利率异常高】高毛利产品收入是否抽查核实
- [ ] 【风险检查】是否存在虚增收入导致产品毛利率虚高
- [ ] 【风险检查】高毛利产品是否为关联方交易或新增可疑产品

### 三、异常低毛利产品识别（中风险）

- [ ] 【必检】负毛利/极低毛利产品是否标注并说明原因
- [ ] 【必检】低毛利产品的成本核算是否准确（无成本高估）
- [ ] 【必检】低毛利产品的定价是否有商业合理性
- [ ] 【条件检查：若有负毛利产品】负毛利的持续经营影响是否评估
- [ ] 【风险检查】是否存在关联方低价交易导致负毛利
- [ ] 【风险检查】是否存在成本倒挂或降价倾销

### 四、毛利率结构与量价分解（中风险）

- [ ] 【必检】产品结构变动对综合毛利率的影响是否分析
- [ ] 【必检】毛利率变动是否分解为价格因素和成本因素
- [ ] 【必检】产品单价是否与 D4-11 产品价格分析一致
- [ ] 【条件检查：若毛利率大幅变动】变动是否可分解解释
- [ ] 【风险检查】是否存在无法用量价成本分解的毛利率异常

## risk_areas

### 高风险

1. **产品毛利率虚高**：单个产品毛利率显著高于同类或历史水平，源于虚增收入未匹配对应成本，是产品级虚增收入的核心信号。
2. **高毛利产品收入虚构**：异常高毛利产品的收入无真实交易支撑或成本漏记，涉及发生和计价认定。
3. **关联方交易扭曲毛利**：关联方产品交易以非公允价格进行，导致毛利率异常高或异常低。
4. **成本漏记推高毛利**：产品对应成本未完整结转导致毛利虚高，可能存在成本跨期或存货高估。
5. **产品毛利与量价成本不勾稽**：产品毛利率无法用单价、成本、结构分解解释，反映数据可能被操纵。

### 中风险

1. **负毛利产品无合理解释**：负毛利或极低毛利产品持续存在但未说明商业合理性，可能存在成本倒挂或倾销。
2. **产品结构变动未区分**：综合毛利率变化未区分产品结构因素与单产品毛利率因素。
3. **新产品毛利率异常**：新产品毛利率明显不合理但未核实定价和成本。
4. **产品分类不一致**：不同期间产品归类不一致，影响毛利率趋势可比性。

### 低风险

1. **毛利率计算口径不一**：产品毛利率计算口径与综合毛利率不完全一致。
2. **分析深度不足**：异常产品仅标注未深入分析。
3. **小产品未单独分析**：小额产品归集未单独列示毛利率。
4. **交叉索引不完整**：与明细表、价格分析、成本底稿的交叉引用不全。
