# D5-2 明细表复核提示词

## 概述

本提示词针对应收款项融资明细表（D5-2）的复核，聚焦四大核心审计要点：转入项目信息完整性、公允价值计量准确性、账龄分析正确性、票据状态与背书贴现追踪。明细表是应收款项融资科目审计的基础数据底稿，承载转入应收款项融资的应收票据/应收账款明细、公允价值、账龄及票据流转状态，其数据质量直接影响公允价值与分类检查（D5-4）、终止确认判断、附注披露等后续审计程序的有效性。

**法规依据：**
- 《企业会计准则第22号——金融工具确认和计量》
- 《企业会计准则第23号——金融资产转移》
- 《企业会计准则第37号——金融工具列报》
- 《中国注册会计师审计准则第1301号——审计证据》

## tips

1. **转入项目信息完整性是明细表质量的基石**：明细表中每一行记录必须具备完整的识别信息（票据号/合同编号、出票人/债务人、金额、公允价值、票据状态等），信息缺失将影响业务模式判断和终止确认核查。
2. **公允价值计量准确性的核心是计量依据**：应收款项融资以公允价值计量，明细表须列示每项的账面成本、公允价值及差异，公允价值确定须有充分依据（活跃市场报价/估值技术）。
3. **余额准确性依赖勾稽关系**：明细账合计必须与审定表 D5-1 期末审定数完全一致，期初余额必须与上年审定数衔接，任何差异需追溯至具体调整分录。
4. **票据状态追踪是终止确认的基础**：明细表须清晰标注每张票据的状态（持有/已背书/已贴现/已质押/已到期），已背书或贴现的须追踪是否满足CAS23终止确认条件。
5. **明细表是多项后续程序的数据源**：公允价值与分类检查、终止确认判断、质押受限披露、集中度分析等均以明细表数据为基础，明细表错误将沿数据链传导至多张底稿。
6. **关注明细与汇总的双向勾稽**：明细表各项期末余额（公允价值）合计 = D5-1审定数；各项公允价值变动累计 = OCI科目；已背书/贴现项目合计 = 终止确认分析金额；已质押项目合计 = 受限资产披露金额。

## checklist

### 一、转入项目信息完整性（高风险）

- [ ] 【必检】票据号/合同编号是否完整、规范，无空白记录
- [ ] 【必检】出票人/承兑人/债务人名称是否完整
- [ ] 【必检】是否标注关联方项目，关联方应收款项融资是否全部识别
- [ ] 【必检】票据类型是否标注（银行承兑汇票/商业承兑汇票/应收账款）
- [ ] 【必检】票据状态是否标注（持有/已背书/已贴现/已质押/已到期）
- [ ] 【必检】明细清单是否与票据台账/应收账款系统数据一致
- [ ] 【条件检查：若有商业承兑汇票】承兑人信用状况是否评估
- [ ] 【风险检查】是否存在票据信息无法验证或来源不明的项目
- [ ] 【风险检查】转入应收款项融资的业务模式判断是否有依据

### 二、公允价值计量准确性（高风险）

- [ ] 【必检】明细表各项期末余额（公允价值）合计是否与总账/审定表 D5-1 一致
- [ ] 【必检】明细表期初余额是否与上年审定期末数衔接
- [ ] 【必检】各项是否列示账面成本、公允价值及差异
- [ ] 【必检】公允价值确定依据是否充分（活跃市场报价/估值技术）
- [ ] 【必检】公允价值变动是否正确累计计入其他综合收益
- [ ] 【条件检查：若有到期日临近票据】临近到期票据公允价值是否接近面值
- [ ] 【条件检查：若有商业承兑汇票】商业承兑汇票公允价值是否考虑信用风险
- [ ] 【风险检查】是否存在公允价值异常波动（超过 10% 且无合理解释）
- [ ] 【风险检查】公允价值计量是否被用于调节OCI或利润

### 三、账龄分析正确性（中风险）

- [ ] 【必检】账龄/到期日划分是否与票据实际期限一致
- [ ] 【必检】各账龄段/到期区间金额之和是否等于总额
- [ ] 【必检】到期日是否逐项标注，逾期票据是否单独列示
- [ ] 【必检】长账龄或逾期应收账款融资是否评估可回收性
- [ ] 【条件检查：若有逾期票据】逾期票据的追偿情况是否记录
- [ ] 【风险检查】是否存在长期挂账无法兑付的票据

### 四、票据状态与背书贴现追踪（高风险）

- [ ] 【必检】已背书票据是否逐张标注背书对象和背书金额
- [ ] 【必检】已贴现票据是否逐张标注贴现银行、贴现金额和贴现率
- [ ] 【必检】已质押票据是否标注质押对象和质押用途
- [ ] 【必检】已背书/贴现票据是否判断终止确认条件（CAS23）
- [ ] 【必检】未终止确认的已背书/贴现票据是否继续列示并确认相关负债
- [ ] 【条件检查：若有已贴现商业承兑汇票】商业承兑汇票贴现通常不满足终止确认，是否正确处理
- [ ] 【风险检查】是否存在已背书/贴现但未从账面转出（重复列示）的情况
- [ ] 【风险检查】是否存在应终止确认未终止或不应终止已终止的情况

## risk_areas

### 高风险

1. **公允价值计量操纵**：通过调整公允价值计量金额调节其他综合收益或掩盖减值，涉及计量准确性。
2. **余额与总账不一致**：明细合计数与审定表/总账存在差异未调节，表明可能存在遗漏或错误记录。
3. **终止确认处理错误**：已背书/贴现票据的终止确认判断错误，导致资产和负债列报错误。
4. **票据状态标注错误**：已背书/贴现/质押票据状态标注错误或遗漏，影响终止确认和受限披露。
5. **关联方未识别**：明细表中关联方应收款项融资未标注或遗漏，影响关联交易披露的完整性。

### 中风险

1. **公允价值依据不足**：公允价值确定缺乏活跃市场报价或估值技术支持，计量合理性存疑。
2. **信息不完整**：部分项目缺少票据号、出票人、到期日等关键信息，影响后续核查。
3. **业务模式判断依据缺失**：转入应收款项融资的业务模式判断无支持性文件。
4. **逾期票据未评估**：逾期或长期挂账票据未评估可回收性和减值。
5. **系统数据差异**：票据台账与财务系统的数据存在差异，数据完整性存疑。

### 低风险

1. **格式规范性问题**：明细表格式不统一、排列顺序不规范等形式问题。
2. **辅助信息缺失**：缺少票据行业分布、承兑人类型等辅助分析信息。
3. **小额项目归集**：小额票据归集时未附明细清单。
4. **交叉索引不完整**：与公允价值检查底稿、附注披露的交叉引用标注不全。
