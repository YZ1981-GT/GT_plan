# D3-1 审定表复核提示词

## 概述

本提示词针对预收账款/合同负债审定表（D3-1）的复核，聚焦四大核心审计要点：期初期末勾稽、试算平衡表2205科目核对、审计调整完整性、分类列报准确性。在新收入准则（CAS14）下，预收款项已重分类为合同负债，审定表须清晰体现从"预收账款"科目向"合同负债"列报的过渡，任何勾稽断裂或列报错误均可能导致收入与负债的重大错报。

**法规依据：**
- 《企业会计准则第14号——收入》
- 《企业会计准则第30号——财务报表列报》
- 《中国注册会计师审计准则第1301号——审计证据》
- 《中国注册会计师审计准则第1324号——持续经营》

## tips

1. **期初期末勾稽是审定表的生命线**：期初审定数必须等于上年期末审定数（承前启后），任何差异需追溯至调整分录或会计政策变更（如首次执行新收入准则的追溯调整），不得存在无源差异。
2. **CAS14下的重分类是复核重点**：预收款项（原2203/预收账款）在新收入准则下应重分类为"合同负债"（2205），审定表须体现该重分类，关注是否将不符合合同负债定义的款项（如押金、代收款）错误归入。
3. **试算平衡表是勾稽的第一道防线**：审定表合同负债审定数合计必须与试算平衡表2205科目审定数完全一致，差异意味着存在未记录的调整或汇总错误。
4. **审计调整的完整性决定审定数的可靠性**：所有账项调整（AJE）和重分类调整（RJE）必须完整反映在审定表中，尤其关注长期挂账合同负债结转收入的调整、含税与不含税列报的调整。
5. **合同负债与合同资产不得随意抵销**：同一合同下的合同资产与合同负债在满足抵销条件时净额列报，但不同合同间不得抵销，审定表须按合同/客户维度正确列报。
6. **关注期末突增或长期挂账的合同负债**：审定表中期末余额较期初重大变动（超过20%或重要性水平）或长期挂账（超过1年未结转）的行项目，需追溯至具体交易，评估是否应确认收入或退回。

## checklist

### 一、期初期末勾稽

- [ ] 审定表期初未审数是否等于上年审定表期末审定数（承前启后核对）
- [ ] 期初审定数是否等于期初未审数加期初调整（如首次执行新收入准则的追溯调整）
- [ ] 是否存在期初差异未做说明的情况（会计政策变更、前期差错更正等）
- [ ] 期末审定数是否等于期初审定数加本期贷方发生额减本期借方发生额（加减审计调整）
- [ ] 审定表各行项目期初期末变动是否与明细表（D3-2）增减变动一致
- [ ] 是否存在期初数据被人为修改但未留痕的情况

### 二、试算平衡表核对与列报过渡

- [ ] 审定表合同负债审定数合计是否与试算平衡表2205科目审定数一致
- [ ] 原"预收账款"科目余额是否已按CAS14正确重分类至"合同负债"
- [ ] 审定表各明细科目审定数之和是否等于一级科目审定数
- [ ] 试算平衡表中未审数与审定表未审数是否一致
- [ ] 试算平衡表中调整数（AJE+RJE）与审定表调整数是否一致
- [ ] 是否存在试算平衡表已更新但审定表未同步的情况

### 三、审计调整完整性

- [ ] 所有已确认的账项调整分录（AJE）是否已完整反映在审定表调整列
- [ ] 所有已确认的重分类调整分录（RJE）是否已完整反映在审定表重分类列
- [ ] 长期挂账合同负债结转收入的调整是否已纳入审定表
- [ ] 调整分录的借贷方金额是否平衡（借方合计=贷方合计）
- [ ] 审定表调整后金额是否等于未审数+AJE调整+RJE调整
- [ ] 建议但未调整的错报是否已记录于未调整错报汇总表（SUD）
- [ ] 调整分录是否均有充分的审计证据支持和合伙人审批

### 四、分类列报准确性

- [ ] 合同负债是否严格按流动性正确分类（一年内/一年以上履约义务）
- [ ] 关联方合同负债/预收款项是否在审定表中单独列示
- [ ] 合同负债与合同资产是否按合同分别核算，未进行不当抵销
- [ ] 含增值税的预收款是否正确拆分为合同负债与应交税费（待转销项税额）
- [ ] 不属于合同负债定义的款项（押金、保证金、代收款）是否正确分类至其他科目
- [ ] 审定表中的分类是否与财务报表附注披露的分类一致
- [ ] 超过一年的长期合同负债是否已重分类至非流动负债或充分披露

## risk_areas

### 高风险

1. **期初期末不勾稽**：期初审定数与上年期末审定数不一致，可能存在未经授权的调整或数据录入错误，直接导致本期审定数失去基准。
2. **应确认收入未确认**：长期挂账的合同负债已满足履约义务但未结转收入，虚增负债、少计收入，构成收入完整性错报。
3. **审计调整遗漏**：已确认的调整分录未反映在审定表中，导致审定数不真实，可能掩盖重大错报。
4. **含税列报错误**：含增值税的预收款未拆分，将销项税额虚计入合同负债，导致负债虚增。
5. **不当抵销美化报表**：将不同合同的合同资产与合同负债相互抵销，或将合同负债与应收账款抵销，误导报表使用者。

### 中风险

1. **明细与汇总不勾稽**：审定表各行项目合计与明细表（D3-2）总计不一致，可能存在明细遗漏或重复。
2. **重分类调整方向错误**：RJE借贷方向颠倒导致审定数偏离真实值，或长期挂账重分类不完全。
3. **审定表与附注披露口径不一致**：审定表分类与财务报表附注中的分类披露不一致，影响信息一致性。
4. **合同负债与其他负债混淆**：将押金、保证金等不符合合同负债定义的款项错误归入合同负债。
5. **未调整错报累积超过重要性**：单项未调整错报未超重要性，但累计后可能超过整体重要性水平。

### 低风险

1. **审定表格式不规范**：列标题、行顺序、编号等格式问题不影响数据准确性，但影响底稿可读性和复核效率。
2. **底稿交叉索引不完整**：审定表未与相关底稿（试算平衡表、明细表、调整分录汇总）建立完整索引引用。
3. **辅助说明不充分**：审定表中变动较大的行项目未附简要说明，增加复核理解难度。
4. **历史数据对比缺失**：审定表未列示前期可比数据，不便于分析趋势和异常。
