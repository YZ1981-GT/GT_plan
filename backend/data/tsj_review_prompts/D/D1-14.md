# D1-14 会计政策检查表复核提示词

## 概述

本提示词针对应收票据会计政策检查表（D1-14）的复核，聚焦四大核心审计要点：分类政策恰当性、终止确认政策、减值（预期信用损失）政策、政策一致性与合规性。应收票据的会计政策贯穿 CAS22（分类与计量）、CAS23（转移终止确认）、CAS37（列报）三大准则，政策选择直接决定后续所有底稿的处理基础，政策不当或前后不一致将导致系统性错报。

**法规依据：**
- 《企业会计准则第22号——金融工具确认和计量》
- 《企业会计准则第23号——金融资产转移》
- 《企业会计准则第37号——金融工具列报》
- 《企业会计准则第28号——会计政策、会计估计变更和差错更正》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **分类政策须与业务模式一致**：应收票据按 CAS22 分类为以摊余成本计量（收取合同现金流）、FVOCI（既收取又出售，重分类至应收款项融资 D5）或 FVTPL，分类政策须以业务模式测试（D1-6）和 SPPI 测试为基础，不得随意分类。
2. **终止确认政策须明确判断标准**：企业应制定背书/贴现票据终止确认的判断政策（风险报酬转移标准、追索权处理），政策须符合 CAS23，且区分银承与商承的一般处理原则。
3. **减值政策须符合预期信用损失模型**：应收票据减值适用 CAS22 一般模型（三阶段）或简化模型，须明确违约定义、组合划分标准、损失率确定方法、前瞻性信息运用，政策须与 D1-15 ECL 计算一致。
4. **组合划分标准须合理**：按承兑人类型（银承/商承）、信用风险特征划分减值组合，商业承兑汇票信用风险显著高于银行承兑汇票，不得笼统合并。
5. **政策一致性是可比性基础**：会计政策须前后期一致，政策变更须符合 CAS28（更可靠更相关或准则要求），并追溯调整、充分披露，不得通过政策变更操纵利润。
6. **政策须与实际执行核对**：核对披露的会计政策与各底稿实际处理是否一致，政策"写一套做一套"是常见缺陷。

## checklist

### 一、分类政策恰当性

- [ ] 【必检】应收票据分类政策是否以业务模式测试和 SPPI 测试为基础
- [ ] 【必检】以摊余成本/FVOCI/FVTPL 的分类标准是否明确且符合 CAS22
- [ ] 【必检】FVOCI 分类的票据是否重分类至应收款项融资（D5）
- [ ] 【风险检查】分类政策是否与实际业务模式一致（非事后随意分类）

### 二、终止确认政策

- [ ] 【必检】背书/贴现票据终止确认的判断政策是否明确并符合 CAS23
- [ ] 【必检】政策是否区分银行承兑汇票与商业承兑汇票的一般处理
- [ ] 【必检】追索权对终止确认的影响是否在政策中明确
- [ ] 【风险检查】终止确认政策是否与 D1-8 实际处理一致

### 三、减值（ECL）政策

- [ ] 【必检】减值模型选择（一般模型三阶段/简化模型）是否明确且恰当
- [ ] 【必检】违约定义、组合划分标准是否明确合理
- [ ] 【必检】损失率确定方法、前瞻性信息运用是否符合 CAS22
- [ ] 【必检】减值组合是否按承兑人类型/信用风险特征合理划分
- [ ] 【风险检查】减值政策是否与 D1-15 ECL 计算实际执行一致

### 四、政策一致性与合规性

- [ ] 【必检】会计政策是否前后期一致
- [ ] 【必检】政策变更是否符合 CAS28（更可靠更相关或准则要求）并追溯调整
- [ ] 【必检】披露的会计政策是否与各底稿实际处理一致
- [ ] 【条件检查：若政策变更】变更原因、影响、追溯调整是否充分披露
- [ ] 【风险检查】是否存在通过政策选择/变更操纵利润的迹象

## risk_areas

### 高风险

1. **分类政策与业务模式不符**：为规避减值或公允价值波动而随意分类，违反 CAS22 业务模式基础。
2. **终止确认政策不当**：政策允许商业承兑汇票或带追索权贴现票据终止确认，导致系统性提前出表。
3. **减值政策规避计提**：组合划分掩盖商承高风险、损失率偏低、未运用前瞻性信息，导致减值系统性不足。
4. **政策变更操纵利润**：以政策变更之名调节减值计提或收入确认时点，未追溯调整或披露不充分。
5. **政策与执行脱节**：披露政策与实际处理不一致，"写一套做一套"导致披露失真。

### 中风险

1. **组合划分不合理**：减值组合未按承兑人类型细分，银承商承混合。
2. **政策要素不明确**：违约定义、损失率方法等关键要素表述模糊，难以执行和复核。
3. **政策更新滞后**：准则修订后会计政策未及时更新。
4. **一致性文档不足**：政策前后期一致性缺乏文档支持。

### 低风险

1. **政策表述照搬准则**：会计政策照抄准则原文，未结合企业实际。
2. **索引不完整**：政策与业务模式、ECL、终止确认底稿的索引不全。
3. **格式不规范**：政策检查记录格式不统一。
