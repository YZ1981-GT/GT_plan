# D6-8 合同资产预期信用损失（ECL）计算表复核提示词

## 概述

本提示词针对合同资产预期信用损失计算表（D6-8，科目码1402）的复核，聚焦四大核心审计要点：ECL计量模型适用性、损失率确定合理性、账龄分组与损失率矩阵准确性、前瞻性信息运用充分性。根据CAS22，合同资产的减值采用预期信用损失模型，通常适用简化法（始终按整个存续期预期信用损失计量）。ECL计算表是合同资产减值计提金额的测算底稿，直接决定D6-3减值准备及利润表信用减值损失，属重大会计估计。

**法规依据：**
- 《企业会计准则第22号——金融工具确认和计量》
- 《企业会计准则第14号——收入》
- 《中国注册会计师审计准则第1540号——审计会计估计（含公允价值会计估计）及相关披露》
- 《中国注册会计师审计准则第1301号——审计证据》

## tips

1. **合同资产ECL通常采用简化法**：根据CAS22，合同资产可选择始终按整个存续期预期信用损失计量（简化法），无需评估信用风险是否显著增加，计算表须体现这一计量基础及其一致适用。
2. **损失率矩阵是ECL计算的核心**：采用账龄组合的损失率矩阵法时，各账龄段损失率须基于历史损失经验（历史迁徙率）并经前瞻性信息调整，损失率的推导须可追溯、可复核。
3. **账龄分组须与明细表勾稽**：ECL计算表的账龄分组金额须与D6-2明细表账龄分析一致，各组合基础金额×损失率=该组合ECL，合计=D6-3减值准备计提基础。
4. **前瞻性信息运用须有依据**：损失率的前瞻性调整须结合宏观经济指标（GDP、行业景气度等）及其对合同对方的影响，调整方向及幅度须有支持性分析，不得随意调节。
5. **合同资产ECL需考虑后续履约风险**：不同于纯应收账款，合同资产收款权还取决于企业完成后续履约义务，ECL评估应考虑企业无法完成履约导致无法收款的因素。
6. **关注跨底稿勾稽**：D6-8各组合基础金额 ↔ D6-2明细账龄；D6-8计算的ECL ↔ D6-3减值准备本期计提；损失率 ↔ 会计政策（D6-7）；单项评估合同资产 ↔ D6-3单项计提。

## checklist

### 一、ECL计量模型适用性

- [ ] 是否采用CAS22预期信用损失模型计量合同资产减值
- [ ] 是否恰当选择简化法（按整个存续期预期信用损失计量）
- [ ] 计量模型选择是否与会计政策（D6-7）一致
- [ ] 单项评估与组合评估的划分是否合理（高风险合同单项评估）
- [ ] 是否考虑合同资产特有的后续履约风险因素
- [ ] 模型关键假设是否有充分文档记录

### 二、损失率确定合理性

- [ ] 损失率是否基于历史损失经验（历史迁徙率/违约损失率）
- [ ] 历史损失数据的观察期是否具有代表性
- [ ] 损失率推导过程是否可追溯、可复核
- [ ] 损失率是否与合同资产账龄、对方信用状况匹配
- [ ] 损失率较上期变动是否有合理解释
- [ ] 是否存在人为调低损失率以少计减值的迹象

### 三、账龄分组与损失率矩阵准确性

- [ ] 账龄分组是否基于共同信用风险特征合理划分
- [ ] 各账龄组基础金额是否与D6-2明细表账龄分析勾稽
- [ ] 损失率矩阵各组合损失率是否正确对应
- [ ] 各组合ECL计算是否正确（基础金额×损失率）
- [ ] 全部组合ECL合计是否与D6-3减值准备本期计提勾稽
- [ ] 单项评估合同资产的可收回金额估计是否有依据并与D6-3单项计提一致

### 四、前瞻性信息运用充分性

- [ ] 前瞻性信息调整因子是否结合宏观经济及行业指标
- [ ] 前瞻性调整方向及幅度是否有支持性分析
- [ ] 前瞻性信息是否针对性反映对合同对方的影响
- [ ] 多情景（乐观/基准/悲观）加权是否合理（如适用）
- [ ] 前瞻性调整是否一致适用于各组合
- [ ] 前瞻性信息运用是否在附注中充分披露

## risk_areas

### 高风险

1. **损失率人为调低**：通过调低损失率或不当调整前瞻性因子少计减值，虚增合同资产净额及利润，属重大估计操纵。
2. **模型适用错误**：合同资产未采用ECL模型或简化法适用错误，减值计量缺乏准则基础。
3. **账龄基础金额不勾稽**：ECL计算的账龄基础金额与D6-2明细不一致，测算基础错误。
4. **计算结果与减值准备不勾稽**：ECL计算结果与D6-3减值准备本期计提不一致，存在跨底稿错报。
5. **忽略后续履约风险**：ECL仅考虑对方信用风险，忽略企业无法完成后续履约义务导致无法收款的因素，低估减值。

### 中风险

1. **历史损失数据不代表性**：损失率所依据的历史观察期过短或不具代表性。
2. **前瞻性调整缺乏依据**：前瞻性信息调整方向及幅度无支持性分析，随意调节。
3. **组合划分不合理**：账龄组合未基于共同信用风险特征划分，损失率适用错误。
4. **单项评估依据不足**：单项评估合同资产的可收回金额估计缺乏客观依据。
5. **损失率推导不可追溯**：损失率推导过程记录不完整，无法复核。

### 低风险

1. **计算表格式不规范**：损失率矩阵、账龄分组表格式等形式问题。
2. **前瞻性信息说明简略**：前瞻性调整因子选取依据说明过于简略。
3. **多情景加权文档不足**：多情景加权的权重确定依据文档不完整。
4. **交叉索引不完整**：与D6-2明细、D6-3减值、D6-7政策及附注的交叉引用标注不全。
