# D5-3 调整分录汇总表复核提示词

## 适用底稿
应收款项融资调整分录汇总表（D5-3），含账项调整（AJE）、重分类调整（RJE）及未调整错报（SUD）评估。

## 概述
D5-3 是审定数链路的关键环节。复核须验证：每笔调整有证据、借贷平衡、完整反映到 D5-1 审定表、SUD 评估符合重要性水平要求，尤其关注公允价值变动计入OCI、终止确认、分类重分类等CAS22/CAS23特有调整。

---

## tips

1. **AJE vs RJE**：AJE 影响资产/负债金额或OCI（如公允价值变动、终止确认）；RJE 仅影响列报（如应收款项融资与应收票据/应收账款重分类），不得通过 RJE 掩盖计量错报。
2. **与 D5-1 勾稽**：审定表调整列金额须与 D5-3 已确认分录逐笔一致，遗漏任一笔即审定数失真。
3. **公允价值变动调整**：公允价值变动应借/贷记应收款项融资、对应计入其他综合收益（其他综合收益——其他债权投资公允价值变动），不得错计入损益。
4. **终止确认调整**：已背书/贴现满足终止确认条件的，应转销应收款项融资账面；不满足的应确认短期借款或其他应付款等负债，须与D5-4检查表勾稽。
5. **审批链**：超过明细层次重要性水平的调整须合伙人/项目经理审批留痕。
6. **TB 回写**：确认调整已同步试算平衡表1124科目，避免「底稿已调、TB 未更」双真源。

## checklist

### 高风险检查项

- [ ] 所有 AJE 是否有充分审计证据（公允价值依据、终止确认判断、函证差异等）
- [ ] 公允价值变动调整是否正确计入其他综合收益而非损益
- [ ] 终止确认调整是否符合CAS23条件并有充分依据
- [ ] AJE 是否经适当层级审批（超重要性水平须合伙人知悉）
- [ ] 每笔调整分录借贷方是否完全平衡
- [ ] 调整金额是否完整反映到 D5-1 审定表对应调整列
- [ ] 是否存在通过公允价值调整操纵OCI或利润的不当调整
- [ ] 未调整错报累计是否超过整体重要性水平且仍出具无保留意见（须评估）

### 中风险检查项

- [ ] RJE 是否仅涉及列报（应收款项融资与应收票据/应收账款重分类），未影响计量
- [ ] 分类重分类调整是否基于业务模式和SPPI测试结论
- [ ] 调整原因说明是否清晰可追溯至具体审计程序
- [ ] 调整分录编号是否连续，删除后是否重号风险可控
- [ ] 与 A13 未调整错报汇总表索引是否完整
- [ ] 建议调整与已执行调整是否区分记录

### 低风险检查项

- [ ] 分录摘要、科目编码规范
- [ ] 索引指向 D5-4 公允价值与分类检查、函证回函等支持底稿
- [ ] 审计说明/结论是否概括调整性质与 residual 风险

## risk_areas

### 高风险

- 公允价值变动错计入损益而非OCI
- 终止确认调整缺乏依据或方向错误
- 审定表与 D5-3 调整金额长期不一致
- SUD 累计超阈值未恰当处理

### 中风险

- 分类重分类缺乏业务模式测试依据
- 跨科目重分类方向或金额错误

### 低风险

- 编号、格式不规范

## 跨底稿勾稽

- D5-3 已确认 AJE/RJE 合计 ↔ D5-1 审定表调整列
- D5-3 公允价值变动调整 ↔ 其他综合收益科目
- D5-3 终止确认调整 ↔ D5-4 公允价值与分类检查表
- D5-3 SUD ↔ A13 未调整错报汇总
- 调整后审定数 ↔ 试算平衡表 1124 科目
