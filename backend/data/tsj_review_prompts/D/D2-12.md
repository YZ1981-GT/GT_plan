# D2-12 应收账款质押及保理检查复核提示词

## 适用底稿
应收账款质押及保理检查表（D2-12），含质押情况、保理终止确认（CAS23）及与 D2-1 审定表联动核对。

## 概述
质押与保理涉及权利限制、终止确认及披露。复核须验证：质押比例合理、保理是否满足 derecognition 条件、与审定表及附注披露一致。

---

## tips

1. **质押比例**：质押金额/应收账款审定总额比例过高（系统 `pledgeRatioWarning`）须评估流动性及 covenant 风险。
2. **保理终止确认**：须逐项对照 CAS23 三条件（转移风险报酬、保留控制、继续涉入），不得将不符合条件的保理终止确认。
3. **与 D2-1 勾稽**：`auditedTotal` 须来自 D2-1 审定表应收审定数，质押比例计算分母正确。
4. **出售模式联动**：出售模式/保理终止确认与 D2-13 业务模式、D5/D1 出售模式底稿交叉验证。
5. **披露**：质押、受限资产、保理安排须在附注 D2-note 充分披露。
6. **法律文件**：质押合同、保理协议、登记证明须索引完整。

## checklist

### 高风险检查项

- [ ] 质押应收账款是否已在附注披露受限资产及质押用途
- [ ] 质押比例是否超过借款合同/监管要求警戒线（系统告警须回应）
- [ ] 保理业务是否满足 CAS23 终止确认条件，不满足的不得终止确认
- [ ] `factoringDerecognizedCount` 与协议条款一致，继续涉入部分是否正确计量
- [ ] 质押/保理对象与 D2-2 明细客户可对应，金额无重复或遗漏
- [ ] 与 D2-1 审定表应收总额勾稽（`auditedTotal` 取数正确）

### 中风险检查项

- [ ] 质押状态（有效/已解除/部分解除）与合同及登记信息一致
- [ ] 保理费率、期限、追索权条款是否记录并评估对 ECL 的影响
- [ ] 终止确认概览（D2DerecognitionOverview）与逐笔判断一致
- [ ] 审计说明/结论是否涵盖质押比例、保理会计处理及披露
- [ ] 索引指向 D1/D5 等跨循环底稿是否完整

### 低风险检查项

- [ ] 表格合计、比例列公式正确
- [ ] 参考示例与项目选用方法一致
- [ ] 导入导出数据完整

## risk_areas

### 高风险

- 不符合条件的保理错误终止确认，虚减应收账款
- 大比例质押未披露或影响持续经营判断
- 质押/保理与客户真实交易脱节

### 中风险

- 终止确认判断文档不足
- 与附注披露口径不一致

### 低风险

- 格式、索引不完整

## 跨底稿勾稽

- D2-12 质押合计 / 审定总额 ↔ D2-1 应收审定数
- 保理终止确认金额 ↔ D2-13 业务模式「出售」判断
- 受限资产披露 ↔ D2-note-listed / D2-note-soe
