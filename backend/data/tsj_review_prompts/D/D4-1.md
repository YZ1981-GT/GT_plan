# D4-1 营业收入审定表复核提示词

## 概述

本提示词针对营业收入审定表（D4-1）的复核，聚焦四大核心审计要点：期初期末与试算平衡表勾稽、主营业务收入（6001）与其他业务收入（6051）分类准确性、审计调整完整性、收入确认与利润表勾稽。营业收入是财务报表舞弊风险最高的领域（虚增收入、提前确认、跨期截止），审定表承载未审数→调整→审定数的完整链路，任何勾稽断裂或分类错误均可能构成重大错报。

**法规依据：**
- 《企业会计准则第14号——收入》（五步法确认模型）
- 《中国注册会计师审计准则第1301号——审计证据》
- 《中国注册会计师审计准则第1141号——财务报表审计中与舞弊相关的责任》（收入确认默认存在舞弊风险）
- 《企业会计准则第37号——金融工具列报》
- 《公开发行证券的公司信息披露编报规则第15号》

## tips

1. **收入确认默认存在舞弊风险（CAS1141）**：营业收入审定表复核必须以职业怀疑贯穿，将虚增收入、提前/推迟确认列为默认高风险，而非常规科目对待，任何异常波动都需追溯至具体交易和履约义务。
2. **6001 与 6051 分类是审定表的第一道关口**：主营业务收入（6001）与其他业务收入（6051）须严格区分，材料销售、租赁、废料处置等应归入其他业务收入，混入主营会误导报表使用者对核心业务规模的判断。
3. **试算平衡表是勾稽第一防线**：审定表营业收入审定数合计必须与试算平衡表 6001+6051 科目审定发生额（损益类取发生额而非余额）完全一致，差异意味着存在未记录调整或汇总错误。
4. **审计调整完整性决定审定数可靠性**：所有虚增收入冲回、跨期截止调整（AJE）和总额/净额法重分类（RJE）必须完整反映在审定表中，遗漏任一笔均导致审定数失真。
5. **审定表是收入链路的中心节点**：审定数应与明细表（D4-2/D4-3）合计、利润表营业收入、成本毛利勾稽、附注披露形成闭环，任何节点断裂均为复核重点。
6. **关注期末与期初的重大变动行**：收入较上期发生重大变动（超过20%或重要性水平）的行项目，需结合行业景气、产能、价格因素评估合理性，警惕期末冲刺式收入。

## checklist

### 一、期初期末与试算平衡表勾稽

- [ ] 审定表本期未审数是否与试算平衡表 6001+6051 未审发生额一致
- [ ] 审定表营业收入审定数合计是否与试算平衡表 6001+6051 审定发生额一致（损益类取发生额）
- [ ] 主营业务收入（6001）审定数是否与试算平衡表 6001 科目一致
- [ ] 其他业务收入（6051）审定数是否与试算平衡表 6051 科目一致
- [ ] 审定表调整数（AJE+RJE）是否与试算平衡表调整数一致
- [ ] 是否存在试算平衡表已更新但审定表未同步的情况
- [ ] 本期营业收入审定数是否与上年同期数列示对比且变动可解释

### 二、主营与其他业务分类准确性

- [ ] 主营业务收入是否仅包含企业核心经营活动产生的收入
- [ ] 材料销售、废料处置、包装物出租等是否正确归入其他业务收入（6051）
- [ ] 租赁收入、技术服务费、代理费等是否分类恰当
- [ ] 是否存在将其他业务收入混入主营以美化核心业务规模的情况
- [ ] 分类是否与会计政策及上期保持一致（一致性原则）
- [ ] 审定表分类是否与利润表及附注披露分类一致

### 三、审计调整完整性

- [ ] 所有已确认的账项调整分录（AJE）是否完整反映在审定表调整列
- [ ] 所有已确认的重分类调整分录（RJE，如总额法/净额法调整）是否完整反映
- [ ] 虚增收入冲回、跨期收入截止调整是否已纳入审定表
- [ ] 调整分录借贷方金额是否平衡
- [ ] 审定表调整后金额是否等于未审数+AJE+RJE
- [ ] 建议但未调整的收入错报是否已记录于未调整错报汇总表（SUD）并与 A13 交叉验证
- [ ] 调整分录是否均有充分审计证据支持和合伙人审批

### 四、收入确认与利润表勾稽

- [ ] 审定表营业收入审定数是否等于利润表营业收入
- [ ] 审定表主营/其他业务收入是否与利润表明细分项一致
- [ ] 营业收入是否与营业成本、毛利勾稽（毛利率合理性）
- [ ] 营业收入是否与增值税销项税额、纳税申报表收入勾稽
- [ ] 营业收入是否与现金流量表"销售商品、提供劳务收到的现金"勾稽（收现比）
- [ ] 是否存在收入确认与合同履约义务不匹配的行项目

## risk_areas

### 高风险

1. **虚增营业收入**：通过虚构客户、伪造合同发货单据、虚开发票等虚增收入，审定表数据无真实交易支撑，涉及发生认定，是收入审计的首要舞弊风险。
2. **提前/推迟确认收入跨期**：资产负债表日前后集中确认或延迟确认收入以调节利润，审定数未反映正确会计期间，需与截止测试勾稽。
3. **主营与其他业务分类错误**：将其他业务收入混入主营美化核心业务规模，或反向操作平滑收入结构，误导报表使用者。
4. **审定表与试算平衡表/利润表不勾稽**：审定数与 6001+6051 发生额或利润表营业收入不一致，意味着存在未发现的汇总错误或调整遗漏。
5. **审计调整遗漏或缺乏审批**：已确认的收入调整未反映在审定表，或未经合伙人批准即纳入，掩盖重大错报或存在越权审批。

### 中风险

1. **明细与汇总不勾稽**：审定表营业收入合计与明细表（D4-2/D4-3）总计不一致，可能存在明细遗漏或重复。
2. **总额法/净额法应用不当**：主要责任人与代理人身份判断错误导致收入按总额或净额确认失当，重分类调整方向错误。
3. **审定表与附注披露口径不一致**：审定表分类与财务报表附注收入披露不一致，影响信息一致性。
4. **收现比异常**：营业收入与销售收现严重背离且未合理解释，可能存在收入真实性问题。
5. **未调整收入错报累积超重要性**：单项未调整收入错报未超重要性，但累计后可能超过整体重要性水平。

### 低风险

1. **审定表格式不规范**：列标题、行顺序、编号等格式问题不影响数据准确性，但影响底稿可读性。
2. **底稿交叉索引不完整**：审定表未与试算平衡表、明细表、调整分录、利润表建立完整索引引用。
3. **辅助说明不充分**：变动较大的行项目未附简要说明，增加复核理解难度。
4. **历史数据对比缺失**：审定表未列示前期可比数据，不便于分析趋势和异常。
