# D7-7 合同负债凭证检查复核提示词

## 适用底稿
合同负债凭证检查表（D7-7，科目码2205），聚焦样本选取方法合理性、收款凭证与合同核对完整性、收入确认时点核对、检查比例达标性、异常交易标注充分性。

## 概述
D7-7 是通过凭证细节测试验证合同负债存在性、完整性及收入确认时点恰当性的关键底稿。合同负债的核心是已收对价而未履约的义务，凭证检查须穿透至收款凭证（预收款到账）、合同（待履约义务）及收入确认（结转时点），验证合同负债是否真实、完整确认，以及结转收入的时点是否恰当（防止提前确认收入）。

**法规依据：**
- 《中国注册会计师审计准则第1314号——审计抽样》
- 《企业会计准则第14号——收入》
- 《中国注册会计师审计准则第1301号——审计证据》
- 《中国注册会计师审计准则第1141号——财务报表审计中与舞弊相关的责任》

## tips

- 样本选取方法应与风险评估结果匹配，收入确认时点判断复杂或金额重大的合同采用更严格抽样策略
- 凭证核对须覆盖合同负债完整链条（合同→预收款收款凭证→合同负债确认→履约进度→结转收入/退款）
- 检查比例应满足《中国注册会计师审计准则第1314号——审计抽样》要求
- 合同负债核心是完整性与收入确认时点，须核对收款凭证与合同以验证预收款是否完整确认为合同负债
- 收入确认时点核对是防止提前确认收入的关键，须核对合同负债结转收入是否有真实履约支持
- 异常交易标注需明确异常类型（收入时点异常/金额异常/时间异常/对手方异常）
- 关注期末集中预收/结转、大额合同负债、关联方合同等高风险凭证
- 职业怀疑贯穿始终：对管理层收入确认时点判断保持警觉，记录质疑过程和替代验证方案

## checklist

### 一、样本选取与检查比例（高风险）

- [ ] 样本选取方法是否与识别的重大错报风险相匹配
- [ ] 抽样方法是否符合CAS1314要求（统计抽样/非统计抽样选择有据）
- [ ] 金额重大合同负债（超过重要性水平）是否100%全覆盖检查
- [ ] 高风险合同（收入时点判断复杂/关联方/长期挂账/大额变动）是否纳入必选样本
- [ ] 抽样总体是否完整（尤其关注完整性，是否遗漏已收预收款项）
- [ ] 总体检查比例（已检查金额/总体金额）是否达到计划水平
- [ ] 贷方发生额（本期新增预收）检查比例是否达标
- [ ] 借方发生额（本期结转收入/退款）检查比例是否达标

### 二、收款凭证与合同核对（高风险）

- [ ] 是否核对预收款收款凭证（银行回单）确认款项真实到账
- [ ] 是否核对合同文本，确认待履约义务及预收安排
- [ ] 已收预收款是否完整确认为合同负债（完整性核对）
- [ ] 合同负债金额与实际收款金额是否一致
- [ ] 是否存在已收对价却未确认合同负债（漏记负债虚增收入）的情况
- [ ] 期末集中预收的合同负债对应凭证是否重点核查
- [ ] 收款凭证的对方户名是否与合同客户一致

### 三、收入确认时点核对（高风险）

- [ ] 合同负债结转收入是否有真实履约支持（交付/验收/服务记录）
- [ ] 结转收入的时点是否与履约义务完成时点一致（CAS14）
- [ ] 是否存在合同负债提前结转收入（虚增当期收入）的情况
- [ ] 是否存在履约完成却未结转（低估当期收入）的情况
- [ ] 期末临近结转的合同负债是否实施截止测试
- [ ] 结转凭证日期与记账日期是否一致，是否跨期记录

### 四、异常交易标注（中低风险）

- [ ] 异常交易是否全部标注并记录异常类型和初步判断
- [ ] 收入确认时点异常（期末集中结转/提前结转）是否标注
- [ ] 金额异常（整数金额/恰好低于审批权限/偏差超30%）是否标注
- [ ] 时间异常（期末最后几天集中预收或结转）是否标注
- [ ] 对手方异常（关联方/新客户大额预收/信息不完整）是否标注
- [ ] 抽样工作底稿是否完整记录抽样参数及选取过程（可追溯）
- [ ] 底稿索引与交叉引用是否完整（关联审定表/明细表/收入底稿）

## risk_areas

### 高风险

- **收入提前确认风险**：合同负债无真实履约支持却结转收入，或期末集中结转虚增当期收入，属舞弊
- **合同负债漏记风险**：已收预收款却未完整确认合同负债，导致负债低估、收入虚增（完整性认定）
- **样本选取偏差风险**：抽样方法不当导致样本不具代表性，未能覆盖收入确认时点复杂或金额重大的合同
- **截止性错误风险**：期末临近结转的合同负债未实施截止测试，跨期确认收入未被识别
- **关联方交易隐匿风险**：关联方合同凭证混入普通样本，未实施针对性核查（预收真实性/资金往来性质）

### 中风险

- **检查比例不足风险**：实际检查比例低于计划水平，审计证据不充分
- **完整性核对不充分风险**：未从收款记录反向核对合同负债确认的完整性，漏记负债未被发现
- **收入时点核对不深入风险**：仅核对结转金额而忽略履约完成的客观证据
- **核对深度不够风险**：仅核对金额一致性而忽略合同待履约义务与结转时点的实质匹配

### 低风险

- **记录不完整风险**：抽样参数/选取过程/核对结果记录不完整，影响可追溯性
- **索引缺失风险**：凭证检查底稿与审定表/明细表/收入底稿的交叉索引不完整
- **格式不规范风险**：检查结果记录格式不统一，影响汇总分析效率
