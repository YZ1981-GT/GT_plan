# D4-14 收入发生认定测试表复核提示词

## 概述

本提示词针对收入发生认定测试表（D4-14，occurrence 认定）的复核，聚焦四大核心审计要点：收入真实性验证、销售链条完整核对（合同→发货→验收→开票→回款）、样本选取代表性、异常交易追查。发生认定测试是收入审计的核心实质性程序，针对"已记录的收入是否真实发生"这一舞弊高风险认定，通过完整销售链条的凭证核对验证收入的真实性，是识别虚增收入舞弊的决定性程序。

**法规依据：**
- 《企业会计准则第14号——收入》
- 《中国注册会计师审计准则第1301号——审计证据》
- 《中国注册会计师审计准则第1141号——财务报表审计中与舞弊相关的责任》（收入确认舞弊推定）
- 《中国注册会计师审计准则第1314号——审计抽样》

---

## tips

1. **发生认定针对虚增收入舞弊**：发生认定测试的方向是"从账簿到凭证"（记录的收入→真实交易），验证已确认收入是否真实发生，是应对虚增收入舞弊的核心程序。
2. **完整销售链条核对是真实性铁证**：须核对完整链条（销售合同→销售订单→发货单/物流单→客户签收/验收单→销售发票→银行回款），链条任一环节缺失或不匹配均为虚增收入信号。
3. **样本选取须覆盖高风险交易**：金额重大项目全覆盖，高风险交易（新客户/期末大额/关联方/异常价格/整数金额）纳入必选样本，抽样须符合 CAS1314 要求。
4. **回款是收入真实性的最终验证**：期后实际回款是收入真实发生的强证据，无回款或异常回款（第三方回款/循环回款）的收入需重点追查。
5. **警惕单据链条的形式完整但实质虚假**：即使单据齐全也需验证实质（发货物流真实性、客户验收真实性、回款来源合理性），警惕全套伪造单据。
6. **勾稽关系**：测试样本收入 ↔ D4-2明细表；发货单 ↔ 存货减少；发票 ↔ 增值税销项；回款 ↔ 银行流水/应收账款减少，链条各环节勾稽为核心。

## checklist

### 一、收入真实性验证（高风险）

- [ ] 【必检】测试样本的收入是否有真实交易基础
- [ ] 【必检】销售合同/订单是否真实存在且有效
- [ ] 【必检】发货/物流记录是否证实商品实际发出
- [ ] 【必检】客户签收/验收是否证实控制权转移
- [ ] 【必检】销售发票是否真实开具且与交易匹配
- [ ] 【条件检查：若无法验证发货】替代程序（客户函证/期后回款）是否执行
- [ ] 【风险检查】是否存在无发货记录的收入（虚构销售）
- [ ] 【风险检查】是否存在单据齐全但实质虚假的交易

### 二、销售链条完整核对（高风险）

- [ ] 【必检】合同→订单→发货→验收→开票→回款链条是否完整核对
- [ ] 【必检】各环节的日期逻辑是否合理（合同先于发货先于开票）
- [ ] 【必检】各环节的金额/数量是否一致
- [ ] 【必检】各环节的客户/产品信息是否一致
- [ ] 【条件检查：若链条环节缺失】缺失环节的原因及替代证据是否充分
- [ ] 【风险检查】是否存在开票在发货前（提前确认）
- [ ] 【风险检查】是否存在链条各环节信息不一致（拼凑单据）

### 三、样本选取代表性（中风险）

- [ ] 【必检】金额重大项目（超重要性水平）是否100%覆盖
- [ ] 【必检】高风险交易（新客户/期末大额/关联方/异常价格）是否纳入必选样本
- [ ] 【必检】抽样方法是否符合 CAS1314 要求
- [ ] 【必检】样本量是否满足审计目标置信水平
- [ ] 【必检】检查比例（已检查金额/总体）是否达到计划水平
- [ ] 【条件检查：若统计抽样】抽样参数（总体/置信度/可容忍错报）是否合理
- [ ] 【风险检查】样本是否覆盖各产品线/客户群/时间段

### 四、异常交易追查（高风险）

- [ ] 【必检】发现的异常交易是否逐笔追查解决
- [ ] 【必检】期末大额收入是否重点核查真实性
- [ ] 【必检】期后回款情况是否验证（收入真实性最终证据）
- [ ] 【条件检查：若无回款】长期无回款收入的真实性是否深查
- [ ] 【条件检查：若第三方回款】第三方回款的合理性是否核实
- [ ] 【风险检查】是否存在循环交易（销售后回购/资金回流）
- [ ] 【风险检查】异常交易是否评估对整体收入的影响

## risk_areas

### 高风险

1. **虚构销售无发货**：已确认收入无对应发货/物流记录，反映虚构销售虚增收入，是发生认定的核心舞弊。
2. **提前确认收入**：开票或收入确认在实际发货/验收之前，跨期虚增当期收入，需结合截止测试。
3. **拼凑单据舞弊**：销售链条各环节单据信息（客户/产品/金额/日期）不一致，反映单据拼凑掩盖虚假交易。
4. **循环交易资金回流**：销售后通过回购或资金循环回流虚构收入，交易无商业实质，需追查资金流向。
5. **样本未覆盖高风险交易**：抽样未覆盖期末大额、新客户、关联方等高风险交易，未能有效识别虚增收入。

### 中风险

1. **无回款收入真实性存疑**：长期无回款的收入未深查真实性，可能存在虚增或无法收回。
2. **第三方回款异常**：收入回款来自非交易对手方且无合理解释，反映交易真实性或资金安排异常。
3. **替代程序不充分**：无法验证发货的收入未执行充分替代程序（函证/期后回款）。
4. **检查比例不达标**：实际检查比例低于计划水平，审计证据不充分。
5. **链条日期逻辑异常**：销售链条各环节日期逻辑不合理但未追查。

### 低风险

1. **单据核对记录不详**：链条核对结果记录过于简略，影响复核追溯。
2. **抽样参数记录缺失**：抽样总体、方法、参数记录不完整。
3. **异常处理记录不全**：异常交易的追查过程和结论记录不充分。
4. **交叉索引不完整**：与明细表、合同检查、完整性测试底稿的交叉引用不全。
