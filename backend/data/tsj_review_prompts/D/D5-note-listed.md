# D5-note-listed 附注披露复核提示词（上市公司）

## 概述

本提示词针对应收款项融资上市公司附注披露底稿（D5-note-listed）的复核，聚焦上市公司财务报表附注中应收款项融资相关披露的充分性和准确性：分类披露、减值准备情况、期末已质押的应收票据、期末已背书或贴现但尚未到期的应收票据（CAS23金融资产转移）、公允价值层次披露、关联方应收款项融资单独披露。应收款项融资以FVOCI计量，其披露涉及金融工具列报（CAS37）、金融资产转移（CAS23）和公允价值计量（CAS39）的多重要求，是投资者理解企业票据融资安排和信用风险敞口的重要途径。

**法规依据：**
- 《企业会计准则第37号——金融工具列报》
- 《企业会计准则第22号——金融工具确认和计量》
- 《企业会计准则第23号——金融资产转移》
- 《企业会计准则第39号——公允价值计量》
- 《公开发行证券的公司信息披露编报规则第15号——财务报告的一般规定》

## tips

1. **附注披露须对齐源模板结构，禁止自造披露内容**：应收款项融资附注真实结构为——分类表（主表，无编号）+（1）减值准备情况 +（2）期末已质押的应收票据（按银行承兑/商业承兑列示已质押金额）+（3）期末已背书或贴现但尚未到期的应收票据（按终止确认/未终止确认金额列示），不得凭"常识"臆造"金融资产风险敞口"等表格。
2. **CAS23金融资产转移是应收款项融资披露的特色**：已背书或贴现但尚未到期的应收票据须区分"已终止确认金额"和"未终止确认金额"分别披露，并说明终止确认判断依据（参考证监会2014年监管报告关于终止确认判断的要求）。
3. **公允价值计量须披露层次信息**：应收款项融资以公允价值计量，须按CAS39披露公允价值层次（第一/二/三层次）及计量方法。
4. **已质押的应收票据是受限资产披露重点**：期末已质押的应收票据须按银行承兑汇票/商业承兑汇票分别列示已质押金额，说明质押安排。
5. **关联方应收款项融资须独立披露**：根据CAS36要求，关联方应收款项融资须单独列示，不得混入一般项目。
6. **附注数据必须与审定表/明细表形成闭环勾稽**：附注分类表期末余额必须等于审定表审定数，减值/质押/背书贴现各表金额必须与D5-2明细表对应状态项目勾稽。

## checklist

### 一、分类表主表披露

- [ ] 应收款项融资是否按类型分类披露（银行承兑汇票/商业承兑汇票/应收账款）
- [ ] 各类别期末余额合计是否等于审定表应收款项融资审定数
- [ ] 主表是否同时披露期末数和上年年末数（可比信息）
- [ ] 分类方式是否与会计政策一致
- [ ] 主表是否无编号（对齐源模板结构）
- [ ] 应收款项融资列报是否与资产负债表一致

### 二、（1）减值准备情况披露

- [ ] 是否披露应收款项融资的减值准备情况
- [ ] 减值准备的计量方法（预期信用损失）是否说明
- [ ] 减值准备变动是否列示（如适用）
- [ ] 银行承兑汇票信用风险低是否有相应说明
- [ ] 商业承兑汇票的信用风险和减值是否单独考虑

### 三、（2）期末已质押的应收票据披露

- [ ] 是否披露期末已质押的应收票据金额
- [ ] 是否按银行承兑汇票/商业承兑汇票分别列示已质押金额
- [ ] 已质押金额是否与D5-2明细表已质押状态项目勾稽
- [ ] 是否说明质押安排（质押对象、质押用途）
- [ ] 已质押应收票据的受限性质是否说明

### 四、（3）期末已背书或贴现但尚未到期的应收票据披露

- [ ] 是否披露期末已背书或贴现但尚未到期的应收票据
- [ ] 是否按银行承兑汇票/商业承兑汇票分别列示
- [ ] 是否区分"已终止确认金额"和"未终止确认金额"分别披露
- [ ] 终止确认判断依据是否说明（CAS23风险报酬转移，参考证监会2014监管报告）
- [ ] 未终止确认部分对应的负债是否披露
- [ ] 已背书/贴现金额是否与D5-2明细表和D5-4检查表勾稽

### 五、公允价值层次与关联方披露

- [ ] 是否披露应收款项融资的公允价值层次（第一/二/三层次）
- [ ] 公允价值计量方法和关键输入值是否披露
- [ ] 公允价值变动计入其他综合收益的金额是否披露
- [ ] 关联方应收款项融资是否单独列示（不混入一般项目）
- [ ] 关联方名称、关系类型、期末余额是否披露
- [ ] 附注各表金额是否与审定表/明细表形成闭环勾稽

## risk_areas

### 高风险

1. **自造披露内容**：凭"常识"臆造"金融资产风险敞口/前五名集中度"等表格，偏离源模板真实结构（分类表+减值+质押+背书贴现），属披露内容错误。
2. **终止确认披露缺失或错误**：已背书/贴现票据未区分已终止确认和未终止确认金额，或终止确认判断依据未说明，不满足CAS23披露要求。
3. **未终止确认负债漏披露**：未终止确认的已贴现票据对应负债未披露，导致负债信息不完整。
4. **已质押受限资产未披露**：期末已质押的应收票据未披露金额和质押安排，遗漏受限资产信息。
5. **附注总额与审定表不一致**：附注分类表期末余额与审定表审定数不一致，属数据勾稽重大错误。

### 中风险

1. **公允价值层次未披露**：应收款项融资以公允价值计量但未披露公允价值层次和计量方法，不满足CAS39要求。
2. **减值准备披露不充分**：减值准备情况披露简略，未说明预期信用损失计量方法。
3. **关联方应收款项融资未单独披露**：关联方项目混入一般项目未单独列示。
4. **银行/商业承兑未分别列示**：质押/背书贴现表未按银行承兑汇票和商业承兑汇票分别列示。
5. **可比信息缺失**：附注中仅列示期末数据，未列示上年年末可比数据。

### 低风险

1. **披露格式不完全规范**：表格标题、列序、金额单位等格式细节未严格按编报规则，但不影响信息实质完整性。
2. **文字描述过于模板化**：信用风险管理政策等文字描述照搬会计政策原文，未结合本企业实际情况说明。
3. **数字精度不一致**：部分披露表格保留两位小数，部分取整到万元，精度不统一但不影响决策判断。
4. **终止确认说明过于简略**：终止确认判断依据仅提及原则，未结合具体票据类型说明。
