# D4-27 未披露关联方核查表复核提示词

## 概述

本提示词针对营业收入未披露关联方核查表（D4-27）的复核，聚焦隐性关联方的识别、以第三方名义进行的关联交易虚增收入。未披露/隐性关联方是收入舞弊和利益输送的隐蔽通道，企业可能通过表面独立实则受同一实际控制人控制的"客户"进行非公允交易做大收入。复核须结合CAS1323关联方审计要求，运用多维度信号穿透识别未披露的关联关系。

**法规依据：**
- 《中国注册会计师审计准则第1323号——关联方》
- 《企业会计准则第36号——关联方披露》
- 《企业会计准则第14号——收入》
- 《中国注册会计师审计准则第1141号——财务报表审计中与舞弊相关的责任》

---

## tips

1. **隐性关联方识别须穿透实际控制（CAS1323）**：除管理层申报的关联方外，须主动识别通过共同实际控制人、共同董监高、家族关系、异常经营特征等隐蔽方式存在的未披露关联方。
2. **多维度信号交叉识别隐性关联**：客户与被审计单位共用地址/电话/邮箱/银行账户、客户高管与被审计单位人员重叠、客户成立时间与合作时间高度吻合、客户财务/经营异常一致，均为隐性关联信号。
3. **以第三方名义的关联交易是虚增收入通道**：通过表面独立的第三方"客户"进行受控交易做大收入或转移利益，须穿透第三方背后的控制关系（关联D4-21/D4-24）。
4. **异常交易特征提示隐性关联**：客户只与被审计单位交易、客户资金来源依赖被审计单位、交易条件（信用期/定价/退货）明显优于其他客户，提示可能存在关联关系。
5. **工商/司法/征信数据是识别利器**：通过企业信用信息公示系统、股权穿透工具、司法诉讼记录核查客户与被审计单位的股权、任职、担保、诉讼关联。
6. **未披露关联交易须评估对收入和披露的影响**：一旦识别隐性关联方，其交易须重新评估定价公允性、收入真实性，并评估关联方披露遗漏对报表的影响（CAS36）。

## checklist

### 一、隐性关联方识别

- [ ] 是否运用工商/股权穿透工具核查主要客户与被审计单位的股权关联
- [ ] 是否核查客户高管/股东与被审计单位人员的任职重叠
- [ ] 是否核查客户与被审计单位的共用地址/电话/邮箱/银行账户
- [ ] 是否核查客户成立时间与开始合作时间的吻合度
- [ ] 是否核查客户与被审计单位间的担保/资金往来/诉讼关联
- [ ] 是否识别家族关系、历史关联等隐蔽关联方

### 二、异常交易特征分析

- [ ] 是否存在只与被审计单位交易的单一依赖型客户
- [ ] 客户资金来源是否依赖被审计单位（资金循环迹象）
- [ ] 特定客户交易条件（信用期/定价/退货）是否明显优于其他客户
- [ ] 客户财务/经营特征是否与被审计单位异常一致
- [ ] 新增大客户是否核查其背景与关联可能性
- [ ] 是否存在以第三方名义进行受控交易的迹象

### 三、收入影响评估

- [ ] 识别出的隐性关联方交易金额是否统计
- [ ] 隐性关联销售的定价公允性是否重新评估
- [ ] 隐性关联销售的收入真实性是否穿透核查（货物流/资金流）
- [ ] 是否存在通过隐性关联方虚增收入的情况
- [ ] 隐性关联交易占收入比例是否评估
- [ ] 是否与D4-21关联方定价、D4-24第三方回款交叉印证

### 四、披露与结论

- [ ] 识别出的未披露关联方是否要求管理层补充披露
- [ ] 关联方披露遗漏对财务报表的影响是否评估
- [ ] 管理层未申报关联方的原因是否评估（疏忽/故意隐瞒）
- [ ] 是否评估管理层诚信及对整体审计的影响（CAS1141）
- [ ] 核查结论是否明确（无隐性关联/已识别需披露/影响重大）
- [ ] 底稿是否记录识别方法、穿透过程、数据来源及交叉索引

## risk_areas

### 高风险

1. **隐性关联方虚增收入**：通过未披露的受控第三方进行非公允交易或虚构交易做大收入，系统性粉饰业绩（CAS1141）。
2. **关联方披露重大遗漏**：管理层故意隐瞒关联方及关联交易，违反CAS36强制披露要求，可能构成财务报表重大错报。
3. **以第三方名义利益输送**：通过表面独立实则关联的第三方转移利润或输送利益，损害股东和债权人利益。
4. **管理层诚信问题**：未申报关联方系管理层故意隐瞒，提示管理层诚信缺陷，须重估整体审计风险（CAS1141）。

### 中风险

1. **单一依赖型客户未穿透**：只与被审计单位交易或资金依赖被审计单位的客户未核查关联可能。
2. **异常交易条件未调查**：特定客户明显优于其他客户的交易条件未追查背后关联关系。
3. **股权穿透不充分**：未充分运用工商/股权穿透工具核查客户关联，识别程序不到位。
4. **隐性关联交易定价未重估**：识别出隐性关联后未重新评估交易定价公允性。

### 低风险

1. **识别程序文档不完整**：隐性关联方识别的方法、工具、数据来源记录不完整。
2. **核查范围有限**：仅核查部分大客户，中小客户的关联可能未评估。
3. **交叉索引缺失**：与关联方定价、第三方回款、关联方登记底稿的交叉引用不完整。
