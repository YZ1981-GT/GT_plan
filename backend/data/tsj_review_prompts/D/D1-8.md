# D1-8 背书贴现明细表复核提示词

## 概述

本提示词针对应收票据背书贴现明细表（D1-8）的复核，聚焦四大核心审计要点：终止确认判断的恰当性（CAS23 金融资产转移）、背书/贴现交易的完整性、未终止确认部分的负债确认与披露、贴现利息费用的准确性。这是应收票据最具专业判断难度的底稿：背书转让和贴现本质是金融资产转移，须根据 CAS23 判断票据的风险和报酬是否几乎全部转移，从而决定终止确认（出表）还是继续确认。银行承兑汇票（银行信用高）通常可终止确认，商业承兑汇票（存在追索权、出票人违约风险）通常不满足终止确认条件，须继续列示应收票据并确认相应负债。

**法规依据：**
- 《企业会计准则第23号——金融资产转移》（终止确认判断核心）
- 《企业会计准则第22号——金融工具确认和计量》
- 《企业会计准则第37号——金融工具列报》
- 《中国注册会计师审计准则第1301号——审计证据》

## tips

1. **终止确认判断遵循 CAS23 风险报酬转移三分法**：几乎全部风险报酬转移→终止确认（出表）；几乎全部保留→继续确认（不出表）；既未转移也未保留→按是否保留控制判断（继续涉入），判断错误将直接导致资产负债表虚增或虚减。
2. **银承与商承的终止确认结论通常不同**：银行承兑汇票因承兑银行信用极高、违约风险极低，背书/贴现后风险报酬几乎全部转移，通常可终止确认；商业承兑汇票因追索权和出票人违约风险，风险报酬未几乎全部转移，通常不满足终止确认条件，须继续确认应收票据。
3. **不带追索权 vs 带追索权是关键条款**：贴现协议是否附追索权直接影响风险是否转移，带追索权贴现通常不满足终止确认，须核对贴现协议条款而非仅凭票据类型。
4. **未终止确认票据须同时确认应收票据与负债**：不满足终止确认条件的已贴现票据，应继续列示应收票据，同时按取得的贴现款确认短期借款/其他应付款，两侧均须完整反映，D1-1 审定表期末余额须包含此类票据。
5. **已背书/已贴现未到期票据须充分披露**：CAS37 要求披露已背书或贴现但尚未到期票据的终止确认金额和未终止确认金额，披露不完整属列报缺陷。
6. **关注勾稽与真实性**：D1-8 已背书/已贴现票据须与 D1-2 分类明细、D1-7 备查簿逐笔勾稽；终止确认票据须核对已出 ECDS 系统/实物已转出；贴现利息费用须与财务费用/利息支出勾稽。

## checklist

### 一、终止确认判断恰当性（CAS23）

- [ ] 每笔背书/贴现票据是否进行终止确认判断并记录依据
- [ ] 银行承兑汇票终止确认（出表）是否有 CAS23 风险报酬转移分析支持
- [ ] 商业承兑汇票是否恰当判断为不满足终止确认（继续确认）
- [ ] 贴现协议是否附追索权，是否据此判断风险是否转移
- [ ] 是否恰当运用风险报酬转移三分法（转移/保留/继续涉入）
- [ ] "既未转移也未保留"的票据是否按保留控制程度进行继续涉入处理
- [ ] 终止确认判断是否与会计政策（D1-14）一致且前后期一致

### 二、背书贴现交易完整性

- [ ] 本期所有背书/贴现交易是否完整记录（日期/票号/金额/对手方）
- [ ] 背书转出票据是否与 D1-7 备查簿、D1-2 分类明细勾稽
- [ ] 贴现票据的贴现行、贴现率、贴现净额是否完整准确
- [ ] 终止确认票据是否核对已从 ECDS 系统/实物转出
- [ ] 是否存在期末前集中背书/贴现以粉饰流动性的情况
- [ ] 期后到期或被追索的已背书/已贴现票据是否跟踪

### 三、未终止确认部分处理

- [ ] 不满足终止确认条件的已贴现票据是否继续列示应收票据
- [ ] 未终止确认部分是否同时确认相应负债（短期借款/其他应付款）
- [ ] 未终止确认票据的应收与负债两侧金额是否匹配
- [ ] D1-1 审定表期末余额是否包含未终止确认票据
- [ ] 未终止确认的贴现票据利息费用是否按期确认
- [ ] 未终止确认部分是否在附注单独披露（终止确认/未终止确认金额）

### 四、贴现利息与费用准确性

- [ ] 贴现利息费用计算是否正确（票面金额×贴现率×贴现期）
- [ ] 贴现利息是否计入财务费用/利息支出并与相关科目勾稽
- [ ] 终止确认票据的处置损益是否正确计算
- [ ] 未终止确认票据按摊余成本确认的利息费用是否准确
- [ ] 贴现净额（收到金额）是否与银行流水核对一致
- [ ] 贴现相关费用是否有充分的银行单据支持

## risk_areas

### 高风险

1. **终止确认判断错误（提前出表）**：商业承兑汇票或带追索权贴现票据不满足 CAS23 终止确认条件却被终止确认，虚减资产、虚减负债、粉饰流动性和资产负债率。
2. **未终止确认票据的负债未确认**：已贴现未终止确认票据继续列示资产却未同时确认负债，导致负债低估。
3. **追索权条款被忽略**：未核对贴现协议追索权条款，仅凭票据类型判断终止确认，导致判断错误。
4. **期末集中贴现粉饰报表**：资产负债表日前集中背书/贴现以美化流动性指标或降低资产负债率。
5. **虚假贴现套取资金**：无真实贸易背景票据贴现，或已终止确认票据实际未转出（ECDS/实物仍在）。

### 中风险

1. **未终止确认披露不完整**：CAS37 要求的已背书/已贴现未到期票据终止确认金额和未终止确认金额未充分披露。
2. **贴现利息费用计算错误**：贴现期或贴现率计算错误导致财务费用错报。
3. **继续涉入处理不当**："既未转移也未保留"的票据未按继续涉入恰当处理。
4. **背书贴现与备查簿不勾稽**：D1-8 交易与 D1-7 备查簿状态不一致。
5. **期后追索未跟踪**：已背书/已贴现票据期后被追索的情况未跟踪评估或有负债。

### 低风险

1. **明细表格式不规范**：交易记录栏目、终止确认判断列示格式问题。
2. **判断依据文档不充分**：终止确认判断的分析过程记录简略。
3. **交叉索引不完整**：与备查簿、分类明细、财务费用底稿的索引标注不全。
4. **贴现单据保管不全**：贴现凭证/协议留存不完整。
