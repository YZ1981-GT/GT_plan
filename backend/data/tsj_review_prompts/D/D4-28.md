# D4-28 客户函证走访清单表复核提示词

## 概述

本提示词针对营业收入客户函证走访清单表（D4-28）的复核，聚焦函证与走访客户的选取合理性、覆盖率、身份核实。函证和实地走访是验证收入真实性和客户存在性的核心程序，尤其对高风险客户（大额/新增/关联/异常）的组合验证至关重要。清单须确保样本选取覆盖重大错报风险领域，函证走访对象身份经过核实，避免函证被拦截或走访流于形式。

**法规依据：**
- 《中国注册会计师审计准则第1312号——函证》
- 《中国注册会计师审计准则第1314号——审计抽样》
- 《企业会计准则第14号——收入》
- 《中国注册会计师审计准则第1141号——财务报表审计中与舞弊相关的责任》

## tips

1. **函证走访样本须覆盖重大错报风险（CAS1314）**：选取应金额重大项目全覆盖，高风险客户（新增/关联/大额突增/异常）纳入必选，普通客户合理抽样，确保样本代表性和风险针对性。
2. **函证过程须由审计师控制（CAS1312）**：函证的发出、回收全过程须由审计师掌控，防止被审计单位截留、代填、篡改回函，回函地址/联系方式须独立核实避免被引导至虚假地址。
3. **走访是函证的有力补充**：对高风险或函证异常的客户实施实地走访，核实经营场所真实存在、经营规模与交易匹配、交易由客户确认，走访须留存影像/签字/名片等佐证。
4. **客户身份核实是前提**：函证走访对象须先核实真实存在（工商信息/实际经营），警惕虚构客户，避免向不存在或虚假客户"函证"制造已验证假象。
5. **覆盖率须分方向评估**：函证走访对收入/应收账款的金额覆盖率、笔数覆盖率、高风险客户覆盖率须分别评估，覆盖不足须补充样本或说明。
6. **函证走访与其他程序协同**：函证走访结果须与收入截止、发票比对、第三方回款、关联方核查等程序交叉印证，形成收入真实性的综合判断。

## checklist

### 一、样本选取合理性

- [ ] 金额重大客户（超重要性水平）是否全部纳入函证走访
- [ ] 高风险客户（新增/关联/大额突增/异常）是否纳入必选
- [ ] 样本选取方法是否符合CAS1314（统计/非统计选择有据）
- [ ] 普通客户是否合理抽样，兼顾覆盖面
- [ ] 走访对象是否针对高风险或函证异常客户选取
- [ ] 样本是否兼顾主营业务与其他业务客户

### 二、覆盖率评估

- [ ] 函证走访对收入的金额覆盖率是否计算并达到计划水平
- [ ] 对应收账款余额的金额覆盖率是否达标
- [ ] 高风险客户覆盖率是否单独评估
- [ ] 笔数覆盖率是否合理
- [ ] 覆盖率不足时是否补充样本或说明原因
- [ ] 覆盖率是否满足审计目标与风险应对要求

### 三、身份核实与控制

- [ ] 函证走访对象是否先核实真实存在（工商/经营信息）
- [ ] 是否警惕并排除虚构/虚假客户
- [ ] 函证发出与回收是否由审计师全程控制
- [ ] 回函地址/联系方式是否独立核实（非被审计单位提供）
- [ ] 是否防范函证被截留/代填/篡改
- [ ] 走访是否留存佐证（影像/签字/名片/现场记录）

### 四、执行与结论

- [ ] 函证发送、回收、差异状态是否清晰记录
- [ ] 未回函客户是否实施替代程序
- [ ] 回函差异是否逐一调查解释
- [ ] 走访客户的经营真实性、交易确认情况是否记录
- [ ] 函证走访结果是否与截止/发票比对/第三方回款交叉印证
- [ ] 底稿是否记录选取依据、覆盖率计算及交叉索引

## risk_areas

### 高风险

1. **函证被操纵**：被审计单位截留、代填或篡改回函，回函地址被引导至虚假地址，函证证据失效，掩盖虚假收入（CAS1312/CAS1141）。
2. **虚构客户被"函证"**：向不存在或虚假客户发送函证制造已验证假象，未先核实客户真实存在。
3. **高风险客户未覆盖**：大额、新增、关联、异常客户未纳入函证走访，样本未覆盖重大错报风险领域。
4. **走访流于形式**：走访未核实经营真实存在、未由客户确认交易、无佐证留存，走访证据力不足。

### 中风险

1. **覆盖率不足**：函证走访金额覆盖率低于计划水平且未补充样本，审计证据不充分。
2. **替代程序不到位**：未回函客户的替代程序执行不充分，无法验证收入真实性。
3. **回函差异未查清**：回函金额差异未逐一调查解释，可能掩盖收入错报。
4. **样本选取偏差**：抽样方法不当导致样本不具代表性，未针对风险选取。

### 低风险

1. **清单记录不完整**：函证走访对象、发送回收状态、覆盖率计算记录不完整。
2. **走访佐证不规范**：走访佐证材料留存格式不统一或不够充分。
3. **交叉索引缺失**：与函证底稿、收入明细、截止测试的交叉引用不完整。
