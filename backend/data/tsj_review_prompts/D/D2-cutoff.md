# D2 应收账款截止测试复核提示词

## 适用底稿
应收账款截止测试表（截止测试 sheet），含发票号、收入/入账日期、跨期判定、结论及序时账自动抽样（GtCutoffAutoSampling）。

## 概述
截止测试验证应收确认是否计入正确会计期间。复核须验证：样本选取覆盖期末前后、跨期判定准确、异常项已调查、与收入截止（D4）无矛盾。

---

## tips

1. **资产负债表日**：`bsDate` 为截止基准，入账日晚于 bsDate 的贷方/借方应收确认须重点检查。
2. **跨期判定**：系统自动跨期标记（`hasCutoffIssue`）须逐笔复核，不能批量默认「无跨期」。
3. **样本来源**：自动抽样（序时账 ±N 天）须记录抽样参数；手工补充样本须说明原因。
4. **凭证链条**：发票、出库单、签收单、记账凭证日期逻辑一致。
5. **与收入勾稽**：应收截止异常往往伴随收入跨期，须与 D4 截止测试交叉验证。
6. **汇总结论**：`cutoffCount`、`cutoffTotalAmount` 须在审计结论中反映，重大跨期须评估错报影响。

## checklist

### 高风险检查项

- [ ] 样本是否覆盖资产负债表日前后足够区间（建议 ±5~15 天）
- [ ] 跨期判定列与发票日期、入账日期逻辑一致（系统标红项须逐笔核实）
- [ ] 跨期金额合计（cutoffTotalAmount）是否超过明显微小错报阈值并评估影响
- [ ] 期末大额应收是否对应期后收款或真实发货证据
- [ ] 未执行替代程序的跨期异常是否记录原因及结论
- [ ] 是否存在应调整未调整的截止性错报

### 中风险检查项

- [ ] 自动抽样填充后是否人工复核关键字段（金额、日期、客户）
- [ ] 样本量是否满足审计目标（借方/贷方发生额方向覆盖）
- [ ] 结论字段（auditConclusion）是否概括截止测试结果
- [ ] 索引号是否指向记账凭证、发票、出库单
- [ ] 与 D4 收入截止测试结论是否矛盾

### 低风险检查项

- [ ] 表格 8 列（序号/发票号/收入日期/入账日期/金额/跨期判定/结论/备注）填写完整
- [ ] 合计行、跨期笔数统计正确
- [ ] 编制提示 CAS 引用准确

---

## risk_areas

### 高风险

- 大量跨期确认未调查或调整
- 截止样本不覆盖高风险方向（期末突增应收）
- 系统跨期告警被忽略

### 中风险

- 样本量不足或抽样区间过窄
- 结论与明细结论不一致

### 低风险

- 格式、备注不完整

## 跨底稿勾稽

- 截止测试跨期金额 ↔ D2-1/D2-2 期末余额变动解释
- 应收截止 ↔ D4 营业收入截止测试
- 期后收款 ↔ D2-7 凭证检查期后程序
