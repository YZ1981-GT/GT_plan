# D2-8 政策检查复核提示词

## 概述

本提示词针对应收账款政策检查底稿（D2-8）的复核，聚焦会计政策一致性检查：应收账款确认政策、计量政策、减值政策、披露政策的一致性，政策变更的合理性和披露充分性，以及与同行业政策的对标。政策检查是确保应收账款核算基础合规的关键环节，政策不一致或变更不当可能导致系统性错报。

**法规依据：**
- 《企业会计准则第22号——金融工具确认和计量》
- 《企业会计准则第28号——会计政策、会计估计变更和差错更正》
- 《企业会计准则第37号——金融工具列报》
- 《中国注册会计师审计准则第1501号——对财务报表形成审计意见和出具审计报告》
- 《中国注册会计师审计准则第1502号——在审计报告中发表非无保留意见》

---

## tips

1. **政策一致性是财务报表可比性的基石**：应收账款确认、计量、减值和披露政策在前后各期之间必须保持一致，除非存在准则变更或合理的政策变更。
2. **减值政策是核心关注点**：预期信用损失（ECL）模型的参数选取、账龄分组标准、迁徙率假设、前瞻性调整因子等必须与书面会计政策一致，不得存在执行偏差。
3. **政策变更须同时满足合规性和充分披露**：任何政策变更都必须有合理依据（准则变更或提供更可靠信息），且在附注中充分披露变更内容、原因和影响金额。
4. **同行业对标提供合理性参照**：将被审计单位的减值政策（如账龄组合划分、计提比例）与同行业上市公司对标，可快速识别异常偏离。
5. **关注政策与实际执行的脱节**：书面政策规定的条件/标准与实际操作中采用的条件/标准是否一致，脱节往往意味着内控缺陷或人为调节。
6. **披露政策需覆盖CAS37全部要求**：金融工具列报准则要求披露信用风险管理目标和方法、信用风险敞口最大金额、信用风险集中度等，遗漏任何一项均属披露不充分。

## checklist

### 一、确认政策一致性

- [ ] 应收账款初始确认条件是否与会计政策手册一致（合同对价的无条件收款权）
- [ ] 应收账款终止确认条件是否与政策一致（合同权利终止或转移满足CAS23条件）
- [ ] 销售收入确认时点与应收账款确认时点是否匹配（控制权转移模型）
- [ ] 含重大融资成分的应收账款是否按政策单独确认和计量
- [ ] 票据到期后转应收账款的确认时点是否符合政策规定
- [ ] 确认政策的前后期适用是否一致，无选择性适用

### 二、计量政策一致性

- [ ] 应收账款初始计量是否按政策以公允价值（通常为合同对价）计量
- [ ] 含重大融资成分的应收账款是否按政策采用实际利率法摊余成本计量
- [ ] 外币应收账款的折算汇率选取是否与政策一致（交易日即期汇率）
- [ ] 期末外币应收账款资产负债表日折算是否按政策执行（即期汇率）
- [ ] 应收账款减值后的后续计量（转回条件）是否与政策一致
- [ ] 保理/质押/贴现等特殊交易的计量方法是否与政策一致

### 三、减值政策一致性

- [ ] ECL模型选用（一般方法/简化方法）是否与政策规定一致
- [ ] 账龄分组标准（天数区间划分）是否与书面政策完全一致
- [ ] 预期信用损失率（迁徙率/历史损失率）计算方法是否与政策一致
- [ ] 单项减值评估的触发条件是否与政策规定一致（如逾期超过一定金额/天数）
- [ ] 前瞻性信息调整因子的选取是否有政策依据和合理支撑
- [ ] 坏账核销条件是否与政策一致（如满足全部核销条件方可核销）
- [ ] 组合计提中"信用风险特征组合"的划分标准是否与政策一致
- [ ] 已转回的坏账准备是否符合政策规定的转回条件

### 四、披露政策一致性

- [ ] 应收账款分类披露方式（按业务性质/按客户类型）是否与政策一致
- [ ] 账龄披露的起算日（发票日/到期日/入账日）是否与政策一致
- [ ] 坏账准备变动表的披露格式是否与政策和准则要求一致
- [ ] 信用风险相关信息披露是否覆盖CAS37要求的全部事项
- [ ] 关联方应收款项披露粒度是否与政策要求一致
- [ ] 与收入确认相关的合同资产与应收账款划分披露是否与政策一致

### 五、政策变更合理性

- [ ] 本期是否存在会计政策变更，如存在是否有合理依据
- [ ] 政策变更是否属于准则强制要求还是企业自愿选择
- [ ] 自愿变更是否能提供更可靠、更相关的会计信息（CAS28要求）
- [ ] 政策变更的追溯调整金额计算是否准确
- [ ] 政策变更对本期及以前各期财务报表的影响金额是否充分披露
- [ ] 政策变更是否经过公司治理层（董事会/审计委员会）审批

### 六、同行业政策对标

- [ ] 应收账款减值计提比例是否与同行业可比上市公司大致相当
- [ ] 账龄分组标准（区间划分）是否与同行业惯例一致
- [ ] 若偏离同行业水平，是否有合理解释和充分证据支持
- [ ] ECL模型参数假设（如违约定义、前瞻性调整）是否与同行业实践相当
- [ ] 信用期限/信用条件设定是否与同行业水平相当
- [ ] 坏账核销政策是否与同行业实践一致

## risk_areas

### 高风险

1. **减值政策执行偏差**：书面政策规定的ECL计提比例或分组标准与实际执行不一致，可能导致坏账准备系统性偏低或偏高，属重大错报。
2. **政策变更未充分披露**：会计政策变更的内容、原因、影响金额未在附注中完整披露，违反CAS28要求，可能导致审计报告非标准意见。
3. **单项减值触发条件被规避**：实际已满足单项减值条件的应收账款仍按组合计提（比例更低），可能系管理层有意低估减值损失。
4. **政策不一致掩盖利润操纵**：前后期减值政策不一致（如本期收紧/放松计提比例）且未披露，可能存在利用政策变更调节利润。
5. **确认政策与收入准则脱节**：应收账款确认时点与收入确认时点不匹配，可能导致提前确认收入或虚增应收账款。

### 中风险

1. **同行业对标显著偏离**：减值计提比例显著低于同行业水平但无合理解释，可能暗示计提不足。
2. **前瞻性调整因子缺乏支撑**：ECL模型中的前瞻性调整因子（如宏观经济指标权重）缺乏客观数据支持，依赖主观判断。
3. **政策变更审批程序不规范**：政策变更未经董事会/审计委员会审议，或审批文件不完整。
4. **外币折算政策不一致**：部分外币应收账款按月末汇率折算、部分按交易日汇率折算，政策适用不统一。
5. **披露口径与计量口径不一致**：附注披露的账龄起算日与减值模型使用的起算日不同，导致信息不可比。

### 低风险

1. **政策手册更新滞后**：会计政策手册未及时更新至最新准则版本，但实际执行已按新准则操作。
2. **同行业对标样本选取不够全面**：对标仅选取2-3家上市公司，样本代表性有限。
3. **政策描述文字表述模糊**：政策手册中对某些条件的描述不够精确（如"重大"金额的定义未量化），但实操中有一致的标准。
4. **政策检查底稿格式不统一**：各检查项的记录格式不完全统一，不影响实质判断但影响可读性。
