# D7-5 合同负债长期挂账检查复核提示词

## 概述

本提示词针对合同负债长期挂账检查表（D7-5，科目码2205）的复核，聚焦四大核心审计要点：长期挂账原因分析充分性、收入确认时点判断恰当性（CAS14）、是否应退回的判断、是否应转营业外收入的判断及处理正确性。长期挂账的合同负债（履约周期已过而未结转的预收款）存在多重风险：履约义务已完成却未确认收入（低估收入）、客户已放弃但未退款或未转收益、或无法履约应退回。长期挂账检查是评估合同负债合理性及收入确认完整性的关键专项底稿。

**法规依据：**
- 《企业会计准则第14号——收入》
- 《中国注册会计师审计准则第1301号——审计证据》
- 《中国注册会计师审计准则第1141号——财务报表审计中与舞弊相关的责任》
- 《企业会计准则第22号——金融工具确认和计量》

## tips

1. **长期挂账原因是判断处理方式的基础**：须逐笔分析长账龄合同负债的挂账原因（履约进行中/履约已完成未结转/客户放弃/纠纷未决等），不同原因对应不同会计处理，原因分析不充分则处理判断无据。
2. **收入确认时点判断须依据CAS14**：若履约义务实际已完成（商品已转让/服务已提供），应结转确认收入，长期挂账未结转即低估收入，须核对履约完成的客观证据。
3. **是否应退回的判断关系负债真实性**：若企业无法履约或客户有权要求退款，合同负债实质为退款义务，应重分类至其他应付款并评估退款可能性，不得继续作为合同负债挂账。
4. **是否应转营业外收入的判断须谨慎**：仅当履约义务确已解除（如超过退款时效、客户明确放弃且无退款义务）时，长期挂账合同负债才可转营业外收入，转入时点及依据须充分，防止随意转益操纵利润。
5. **跨底稿联动是长期挂账处理的落脚点**：长期挂账处理结论应联动至相应底稿——应确认收入→收入底稿/D4；应退回→其他应付款重分类；应转营业外收入→K12营业外收入；相关调整→D7-3调整分录。
6. **关注长期挂账的舞弊迹象**：警惕通过长期挂账合同负债储备收入（跨期调节）、或将应退款项长期挂账占用客户资金等行为。

## checklist

### 一、长期挂账原因分析充分性

- [ ] 长账龄（超过正常履约周期/1年以上/2年以上）合同负债是否逐笔列示
- [ ] 每笔长期挂账合同负债的挂账原因是否分析清晰
- [ ] 挂账原因分类是否恰当（履约进行中/已完成未结转/客户放弃/纠纷未决）
- [ ] 长期挂账是否与合同履约安排核对（履约周期是否确已超过）
- [ ] 长期挂账金额是否与D7-2明细表长账龄数据勾稽
- [ ] 是否存在原因分析不充分即继续挂账的情况

### 二、收入确认时点判断恰当性（CAS14）

- [ ] 履约义务是否实际已完成（商品已转让/服务已提供）
- [ ] 履约完成是否有客观证据（验收/交付/服务记录）
- [ ] 履约已完成的合同负债是否应结转确认收入
- [ ] 是否存在履约完成却长期挂账未结转（低估收入）的情况
- [ ] 收入确认时点判断是否符合CAS14履约义务完成的标准
- [ ] 应确认收入的处理是否联动至收入底稿/D4

### 三、是否应退回的判断

- [ ] 是否评估企业能否完成履约义务
- [ ] 无法履约或客户有权退款的合同负债是否识别
- [ ] 实质为退款义务的合同负债是否重分类至其他应付款
- [ ] 退款可能性及退款金额是否评估
- [ ] 是否存在应退回却长期挂账占用客户资金的情况
- [ ] 应退回的处理是否联动至其他应付款重分类

### 四、是否应转营业外收入的判断与处理

- [ ] 转营业外收入的合同负债是否确已解除履约及退款义务
- [ ] 转益依据是否充分（超过退款时效/客户明确放弃/合同终止）
- [ ] 转益时点是否恰当，是否存在随意转益调节利润的迹象
- [ ] 转益金额及会计处理是否正确
- [ ] 转益的增值税处理（如涉及）是否正确
- [ ] 转营业外收入的处理是否联动至K12营业外收入及D7-3调整分录

## risk_areas

### 高风险

1. **履约完成未确认收入**：履约义务实际已完成的合同负债长期挂账未结转收入，低估当期收入，属重大错报。
2. **储备收入跨期调节**：通过长期挂账合同负债人为储备收入，在需要时结转以调节各期业绩，涉及舞弊。
3. **应退款项长期挂账**：无法履约或应退款的合同负债长期挂账占用客户资金，负债性质错误且掩盖偿付风险。
4. **随意转益操纵利润**：将仍有履约/退款义务的合同负债转营业外收入，虚增当期利润。
5. **原因分析缺失即挂账**：长期挂账合同负债未分析原因即继续挂账，掩盖收入确认或退款问题。

### 中风险

1. **收入确认时点判断错误**：履约完成的判断标准不符合CAS14，导致收入确认时点错误。
2. **退款义务未重分类**：实质为退款义务的合同负债未重分类至其他应付款。
3. **转益依据不充分**：转营业外收入的依据（退款时效/客户放弃）不充分。
4. **处理未联动下游底稿**：长期挂账处理结论未联动至收入底稿/其他应付款/K12。
5. **长账龄金额与明细不勾稽**：长期挂账检查金额与D7-2明细表长账龄数据不一致。

### 低风险

1. **检查表格式不规范**：长期挂账清单、原因分析格式等形式问题。
2. **原因分析记录简略**：挂账原因分析记录简略，缺乏支持性证据引用。
3. **转益增值税说明缺失**：转营业外收入涉及的增值税处理未说明。
4. **交叉索引不完整**：与D7-2明细、D7-3调整分录、收入底稿及K12的交叉引用标注不全。
