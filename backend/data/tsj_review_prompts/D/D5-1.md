# D5-1 审定表复核提示词

## 概述

本提示词针对应收款项融资审定表（D5-1）的复核，聚焦四大核心审计要点：期初期末勾稽、试算平衡表1124科目核对、审计调整完整性、分类列报准确性。应收款项融资是以公允价值计量且其变动计入其他综合收益（FVOCI）的应收票据/应收账款，其分类基于CAS22业务模式测试（既收取合同现金流又出售）和SPPI测试，审定表须清晰体现公允价值计量结果和OCI变动，任何勾稽断裂或分类错误均可能导致金融资产列报重大错报。

**法规依据：**
- 《企业会计准则第22号——金融工具确认和计量》
- 《企业会计准则第23号——金融资产转移》
- 《企业会计准则第37号——金融工具列报》
- 《中国注册会计师审计准则第1301号——审计证据》

## tips

1. **期初期末勾稽是审定表的生命线**：期初审定数必须等于上年期末审定数（承前启后），任何差异需追溯至调整分录或会计政策变更，不得存在无源差异。
2. **FVOCI计量的公允价值变动是复核核心**：应收款项融资以公允价值计量，公允价值变动计入其他综合收益，审定表须体现公允价值计量金额与账面成本的差异及OCI影响。
3. **试算平衡表是勾稽的第一道防线**：审定表应收款项融资审定数合计必须与试算平衡表1124科目审定数完全一致，差异意味着存在未记录的调整或汇总错误。
4. **业务模式决定分类的正确性**：只有"既以收取合同现金流为目标又以出售为目标"的业务模式且通过SPPI测试的应收票据/应收账款才能分类为应收款项融资（1124），错误分类应重分类至应收票据（1121）或应收账款（1122）。
5. **终止确认影响审定数完整性**：已背书、已贴现的应收款项融资须根据CAS23判断是否满足终止确认条件，审定表须正确反映终止确认后余额，未终止确认的须继续列示并确认相关负债。
6. **关注期末公允价值计量的合理性**：审定表中应收款项融资的公允价值计量若较账面成本存在重大差异，需追溯公允价值确定依据，评估计量合理性。

## checklist

### 一、期初期末勾稽

- [ ] 审定表期初未审数是否等于上年审定表期末审定数（承前启后核对）
- [ ] 期初审定数是否等于期初未审数加期初调整（如有追溯调整）
- [ ] 是否存在期初差异未做说明的情况（会计政策变更、前期差错更正等）
- [ ] 期末审定数是否等于期初审定数加本期增加减本期减少（加减审计调整及公允价值变动）
- [ ] 审定表各行项目期初期末变动是否与明细表（D5-2）增减变动一致
- [ ] 公允价值变动累计计入其他综合收益的金额是否与OCI科目勾稽

### 二、试算平衡表核对与分类

- [ ] 审定表应收款项融资审定数合计是否与试算平衡表1124科目审定数一致
- [ ] 转入应收款项融资的应收票据/应收账款是否符合业务模式和SPPI测试
- [ ] 不符合FVOCI分类的项目是否已重分类至应收票据（1121）或应收账款（1122）
- [ ] 审定表各明细科目审定数之和是否等于一级科目审定数
- [ ] 试算平衡表中未审数与审定表未审数是否一致
- [ ] 试算平衡表中调整数（AJE+RJE）与审定表调整数是否一致

### 三、审计调整完整性

- [ ] 所有已确认的账项调整分录（AJE）是否已完整反映在审定表调整列
- [ ] 所有已确认的重分类调整分录（RJE）是否已完整反映在审定表重分类列
- [ ] 公允价值变动调整（计入OCI）是否已纳入审定表
- [ ] 已背书/贴现终止确认的调整是否正确反映
- [ ] 调整分录的借贷方金额是否平衡（借方合计=贷方合计）
- [ ] 审定表调整后金额是否等于未审数+AJE调整+RJE调整
- [ ] 建议但未调整的错报是否已记录于未调整错报汇总表（SUD）
- [ ] 调整分录是否均有充分的审计证据支持和合伙人审批

### 四、分类列报准确性

- [ ] 应收款项融资是否列示为流动资产
- [ ] 关联方应收款项融资是否在审定表中单独列示
- [ ] 已质押的应收款项融资是否正确列报并披露受限情况
- [ ] 已背书/贴现未终止确认的应收款项融资是否继续列示并确认相关负债
- [ ] 应收款项融资与应收票据、应收账款的划分是否正确
- [ ] 审定表中的分类是否与财务报表附注披露的分类一致
- [ ] 公允价值计量与减值准备（如适用）的列报是否正确

## risk_areas

### 高风险

1. **期初期末不勾稽**：期初审定数与上年期末审定数不一致，可能存在未经授权的调整或数据录入错误，直接导致本期审定数失去基准。
2. **分类错误**：将不符合业务模式或SPPI测试的应收票据/应收账款错误分类为应收款项融资，或反之，导致金融资产列报和后续计量错误。
3. **公允价值变动未正确计入OCI**：公允价值变动错误计入损益而非其他综合收益，导致利润和OCI错报。
4. **终止确认判断错误**：已背书/贴现的应收款项融资终止确认条件判断错误，导致资产虚减或虚增及负债漏记。
5. **审计调整遗漏**：已确认的调整分录未反映在审定表中，导致审定数不真实。

### 中风险

1. **明细与汇总不勾稽**：审定表各行项目合计与明细表（D5-2）总计不一致，可能存在明细遗漏或重复。
2. **公允价值计量依据不足**：公允价值确定缺乏充分依据，计量金额合理性存疑。
3. **审定表与附注披露口径不一致**：审定表分类与财务报表附注中的分类披露不一致，影响信息一致性。
4. **质押/受限披露不完整**：已质押的应收款项融资未标注受限情况。
5. **未调整错报累积超过重要性**：单项未调整错报未超重要性，但累计后可能超过整体重要性水平。

### 低风险

1. **审定表格式不规范**：列标题、行顺序、编号等格式问题不影响数据准确性，但影响底稿可读性和复核效率。
2. **底稿交叉索引不完整**：审定表未与相关底稿（试算平衡表、明细表、公允价值检查表）建立完整索引引用。
3. **辅助说明不充分**：审定表中变动较大的行项目未附简要说明，增加复核理解难度。
4. **历史数据对比缺失**：审定表未列示前期可比数据，不便于分析趋势和异常。
