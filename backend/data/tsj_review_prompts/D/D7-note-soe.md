# D7-note-soe 合同负债附注披露复核提示词（国有企业）

## 概述

本提示词针对合同负债国有企业附注披露底稿（D7-note-soe，科目码2205）的复核，聚焦国有企业特定的附注披露要求：国有资产监管相关披露、关联交易（含与政府/国有控股单位交易）、预算执行相关信息、国资委要求的补充披露事项，以及与上市公司版本的差异关注点。合同负债多产生于工程施工预收、长期服务预收等业务，国有企业（尤其工程建设、公用事业类）合同负债金额往往重大，其披露须同时满足会计准则（CAS14/CAS37）和国资监管要求。

**法规依据：**
- 《企业会计准则第14号——收入》
- 《企业会计准则第37号——金融工具列报》
- 《企业会计准则第36号——关联方披露》
- 《企业国有资产法》
- 《中央企业财务决算报告管理办法》
- 《国有资产监督管理委员会关于加强中央企业财务决算管理工作有关事项的通知》

## tips

1. **国有企业合同负债披露有"双层"要求**：既满足CAS14/CAS37通用披露，又满足国资委财务决算报告的额外披露要求（如工程预收款、大额合同负债逐户披露），两套要求互补不可替代。
2. **工程建设类国企合同负债是关注重点**：合同负债多源于工程预收款，需披露预收款对应工程履约进度、结转收入安排及长期挂账情况，长期未履约预收款是国资监管关注点。
3. **国资委关注长期挂账合同负债处置**：长期挂账合同负债（履约周期已过而未结转）的处置须谨慎，转营业外收入或退款须经适当决策程序，附注需披露处置情况（与D7-5勾稽）。
4. **收入确认时点直接影响业绩考核**：国企收入确认时点关系年度经营业绩考核，合同负债结转收入的时点披露须真实，防止通过合同负债储备或提前释放收入调节考核业绩。
5. **关联方范围比一般企业更广**：除一般定义外，还需考虑同一国有控股股东控制的其他国有企业（"同受国有控制"关联方），但可按准则豁免条款简化部分披露；须警惕以合同负债名义掩盖关联方资金往来。
6. **与上市版差异主要在监管层面**：基础披露框架（分类/账龄/履约义务/收入时点）与上市版相同，国企版额外增加国资监管相关信息，而非替代基础披露。

## checklist

### 一、基础披露完整性（与上市版共有）

- [ ] 合同负债的性质是否披露（已收对价而未履约的义务）
- [ ] 合同负债是否按业务性质/合同类型分类披露
- [ ] 账龄分析表是否完整列示（1年以内/1-2年/2-3年/3年以上）
- [ ] 附注合同负债总额是否与审定表审定数一致
- [ ] 期初数/期末数可比信息是否完整列示
- [ ] 合同负债与合同资产的期末余额及净额列示关系是否披露
- [ ] 分摊至剩余履约义务的交易价格及预计确认收入时间是否披露

### 二、国有资产监管相关披露

- [ ] 长账龄（长期挂账）合同负债是否单独披露金额、合同、客户及原因
- [ ] 工程建设类合同负债对应的工程履约进度及结转安排是否披露
- [ ] 大额合同负债（超过单户限额标准）是否按国资委要求逐户披露
- [ ] 是否披露与政府部门相关的合同负债（政府项目预付款）
- [ ] 涉及退款义务的合同负债是否单独说明
- [ ] 长期挂账合同负债处置对经营业绩的影响是否说明

### 三、关联交易披露（国企特定）

- [ ] 与控股股东及其关联企业的合同负债是否逐户列示
- [ ] 与同一母公司控制的其他国有企业的合同负债是否披露
- [ ] 是否运用"同受国家控制"关联方的豁免条款，如运用是否符合条件
- [ ] 关联方合同负债的交易实质是否清晰说明（经营性预收/资金性）
- [ ] 是否穿透判断关联方"预收款"是否实为资金性往来并予以说明
- [ ] 关联方合同定价方式是否披露（市场价/协议价/政府定价）
- [ ] 关联方合同负债的账龄及待履约状况是否单独披露

### 四、预算执行相关披露

- [ ] 本期合同负债结转收入额与年度预算目标的对比是否披露
- [ ] 预算偏差超过一定比例（如20%）时是否说明原因
- [ ] 本期新增合同负债（预收款）是否属于预算内业务
- [ ] 工程项目预收款回款/结转是否与预算目标对比分析
- [ ] 期末合同负债余额是否超出年度负债预算
- [ ] 收入确认时点对预算业绩考核的影响是否说明

### 五、国资委要求的补充披露

- [ ] 长期挂账合同负债转营业外收入是否经适当决策程序（超金额须"三重一大"）
- [ ] 是否编制长期挂账合同负债清理处置方案并披露执行情况
- [ ] 涉及退款义务的合同负债退款安排是否披露
- [ ] 合同负债中涉及法律诉讼/纠纷的金额及进展是否披露
- [ ] 大额预收款的资金使用及保管是否合规并披露
- [ ] 是否存在以合同负债名义占用客户资金/关联方资金的情况并说明

### 六、与上市版的差异关注点

- [ ] 国企版是否在上市版基础披露基础上增加国资监管层面补充信息
- [ ] 关联方范围是否已扩展至"同受国有控制"的企业
- [ ] 长期挂账合同负债处置是否增加决策程序说明
- [ ] 是否增加预算执行偏差分析
- [ ] 是否增加工程建设类合同负债的履约进度专项披露
- [ ] 是否增加收入确认时点对业绩考核影响的分析

### 七、决算报表特殊要求

- [ ] 合同负债数据是否与年度财务决算报表一致
- [ ] 决算报表附加信息表中合同负债数据是否与本附注一致
- [ ] 集团合并层面内部合同负债抵销是否完整，抵销后余额是否与决算一致
- [ ] 合同负债结转收入是否纳入年度经营业绩考核的相关披露
- [ ] 长期挂账合同负债是否按决算要求单独分析

## risk_areas

### 高风险

1. **长期挂账合同负债未按国资要求披露**：长期挂账合同负债未逐户说明原因及处置计划，可能掩盖收入确认或退款问题。
2. **关联方合同负债范围遗漏**：未将同一国有控股股东下兄弟单位纳入关联方披露范围，违反CAS36和国资委要求。
3. **以合同负债名义占用资金未披露**：以预收款名义占用客户或关联方资金未单独说明，掩盖资金往来实质。
4. **收入时点操纵业绩考核**：通过合同负债储备或提前释放收入调节业绩考核，附注未真实反映。
5. **基础披露与审定表不勾稽**：附注合同负债各维度合计与审定表审定数不一致，属重大数据错误。

### 中风险

1. **预算执行偏差未充分说明**：合同负债结转收入率远低于预算目标但未说明原因和改进措施。
2. **"同受国有控制"豁免适用不当**：不符合豁免条件却简化了同受国家控制关联方的披露。
3. **履约进度专项披露缺失**：工程建设类合同负债未披露对应工程履约进度及结转安排。
4. **转营业外收入决策程序缺失**：长期挂账合同负债转营业外收入未说明是否经适当决策程序。
5. **决算与审计口径差异未调节**：财务决算数据与审计后附注数据存在差异但未编制调节说明。

### 低风险

1. **披露格式未完全按决算报表模板**：附注格式与国资委决算报表模板有细微差异，但信息内容完整。
2. **大额预收款资金使用说明简略**：大额预收款的资金使用及保管合规性说明简略。
3. **预算对比分析维度单一**：仅对比余额未对比结转率等多维度指标。
4. **历史年度信息追溯不完整**：合同负债增减变动的历史趋势分析仅覆盖2年而非国资委建议的3年。
