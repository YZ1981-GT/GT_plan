# D3-3 调整分录汇总表复核提示词

## 适用底稿
预收账款/合同负债调整分录汇总表（D3-3），含账项调整（AJE）、重分类调整（RJE）及未调整错报（SUD）评估。

## 概述
D3-3 是审定数链路的关键环节。复核须验证：每笔调整有证据、借贷平衡、完整反映到 D3-1 审定表、SUD 评估符合重要性水平要求，尤其关注长期挂账合同负债结转收入、含税拆分、列报重分类等CAS14特有调整。

---

## tips

1. **AJE vs RJE**：AJE 影响损益或负债金额（如结转收入、含税拆分）；RJE 仅影响列报（如流动/非流动重分类），不得通过 RJE 掩盖收入错报。
2. **与 D3-1 勾稽**：审定表调整列金额须与 D3-3 已确认分录逐笔一致，遗漏任一笔即审定数失真。
3. **收入结转调整**：长期挂账合同负债已满足履约义务的，调整分录应借记合同负债、贷记主营业务收入，同步确认销项税额，须与收入底稿（D4）勾稽。
4. **审批链**：超过明细层次重要性水平的调整须合伙人/项目经理审批留痕。
5. **SUD 累计**：未调整错报单独及累计是否超过整体/明显微小错报阈值，须与 A13 未调整错报汇总交叉验证。
6. **TB 回写**：确认调整已同步试算平衡表2205科目，避免「底稿已调、TB 未更」双真源。

## checklist

### 高风险检查项

- [ ] 所有 AJE 是否有充分审计证据（履约证据、函证差异、管理层确认等）
- [ ] 长期挂账合同负债结转收入的调整是否有履约完成的支持性证据
- [ ] AJE 是否经适当层级审批（超重要性水平须合伙人知悉）
- [ ] 每笔调整分录借贷方是否完全平衡
- [ ] 调整金额是否完整反映到 D3-1 审定表对应调整列
- [ ] 含税预收款拆分调整（合同负债/待转销项税额）是否正确
- [ ] 是否存在仅为调节利润（推迟或提前结转收入）的不当调整
- [ ] 未调整错报累计是否超过整体重要性水平且仍出具无保留意见（须评估）

### 中风险检查项

- [ ] RJE 是否仅涉及列报（流动/非流动重分类），未影响损益类科目
- [ ] 合同负债与合同资产抵销的重分类是否符合抵销条件
- [ ] 调整原因说明是否清晰可追溯至具体审计程序
- [ ] 调整分录编号是否连续，删除后是否重号风险可控
- [ ] 与 A13 未调整错报汇总表索引是否完整
- [ ] 建议调整与已执行调整是否区分记录

### 低风险检查项

- [ ] 分录摘要、科目编码规范
- [ ] 索引指向 D3-7 凭证检查、D3-5 长期挂账检查等支持底稿
- [ ] 审计说明/结论是否概括调整性质与 residual 风险

## risk_areas

### 高风险

- 收入结转调整缺乏履约证据或未经授权
- 审定表与 D3-3 调整金额长期不一致
- 通过调整时点操纵收入确认（利润蓄水池）
- SUD 累计超阈值未恰当处理

### 中风险

- RJE 误含损益影响
- 含税拆分调整方向或金额错误
- 合同资产/负债抵销不符合条件

### 低风险

- 编号、格式不规范

## 跨底稿勾稽

- D3-3 已确认 AJE/RJE 合计 ↔ D3-1 审定表调整列
- D3-3 收入结转调整 ↔ D4 营业收入底稿
- D3-3 SUD ↔ A13 未调整错报汇总
- 调整后审定数 ↔ 试算平衡表 2205 科目
