# D4-9 客户结构分析表复核提示词

## 概述

本提示词针对客户结构分析表（D4-9）的复核，聚焦四大核心审计要点：客户集中度分析、前五大客户收入及占比、新老客户结构变动、关联方与异常客户识别。客户结构分析从客户维度剖析收入的分布特征，通过客户集中度、前五大客户变动、新增客户异常等揭示收入的信用风险集中度和潜在的虚增收入舞弊（虚构客户、关联方伪装、新客户突增）。

**法规依据：**
- 《企业会计准则第14号——收入》
- 《中国注册会计师审计准则第1301号——审计证据》
- 《中国注册会计师审计准则第1141号——财务报表审计中与舞弊相关的责任》
- 《中国注册会计师审计准则第1502号——对特殊项目审计证据的进一步考虑》

## tips

1. **客户集中度揭示收入依赖风险**：单一或少数客户收入占比过高（如前五大超过50%）意味着客户流失可能导致收入重大波动，需评估对持续经营的影响并核实大客户交易真实性。
2. **前五大客户是收入舞弊的高发靶区**：前五大客户收入占比大、影响重大，须核实其交易真实性、回款情况、是否为关联方伪装、是否与其经营规模匹配。
3. **新增客户突增是虚增收入红旗**：新客户当年即进入前五大或贡献大额收入，须核实客户背景、经营实质、交易合理性，警惕虚构客户或"壳公司"。
4. **老客户流失需评估收入连续性**：重要老客户退出但被新客户填补，须评估客户更替的商业合理性，警惕通过虚构新客户掩盖真实客户流失。
5. **关联方客户必须穿透识别**：客户结构中的关联方须穿透识别（同一实际控制人、隐性关联），关联方收入占比过高需评估交易公允性和收入真实性。
6. **勾稽关系**：前五大客户收入合计 ÷ 全部收入 = 集中度；各客户收入 = D4-2明细表客户收入；客户收入变动 ↔ 销售政策/市场变化，异常需追溯。

## checklist

### 一、客户集中度分析（高风险）

- [ ] 【必检】客户集中度指标（前五大/前十大占比）是否计算正确
- [ ] 【必检】集中度是否与上期对比分析变动
- [ ] 【必检】各客户收入合计是否与 D4-2 明细表勾稽
- [ ] 【条件检查：若集中度超50%】单一客户依赖风险及持续经营影响是否评估
- [ ] 【条件检查：若集中度显著上升】集中度上升原因是否分析
- [ ] 【风险检查】是否存在客户集中度过高的信用风险集中敞口
- [ ] 【风险检查】大客户交易真实性是否核实

### 二、前五大客户分析（高风险）

- [ ] 【必检】前五大客户名称、收入、占比是否完整列示
- [ ] 【必检】前五大客户收入变动是否与整体收入变动匹配
- [ ] 【必检】前五大客户中是否包含关联方，若有是否单独标注
- [ ] 【必检】前五大客户收入是否与其经营规模匹配
- [ ] 【必检】前五大客户的回款情况/应收账款账龄是否良好
- [ ] 【条件检查：若前五大发生重大变动】变动原因是否调查
- [ ] 【风险检查】是否存在虚增前五大客户交易以美化收入结构
- [ ] 【风险检查】前五大客户是否存在同一地址/联系方式/银行账户

### 三、新老客户结构变动（高风险）

- [ ] 【必检】新增客户与流失客户是否分别列示
- [ ] 【必检】新增客户收入贡献及占比是否分析
- [ ] 【必检】新增大客户的背景调查/信用评估是否记录
- [ ] 【条件检查：若新客户进入前五大】新客户进入前五大的合理性是否验证
- [ ] 【条件检查：若重要老客户流失】老客户流失原因及影响是否评估
- [ ] 【风险检查】是否存在虚构新客户以填补真实客户流失
- [ ] 【风险检查】新客户经营规模是否与其采购规模匹配

### 四、关联方与异常客户识别（中风险）

- [ ] 【必检】客户结构中的关联方是否穿透识别
- [ ] 【必检】关联方客户收入占比及公允性是否评估
- [ ] 【必检】异常客户（新注册/无经营场所/首笔大额）是否标注
- [ ] 【条件检查：若关联方占比高】关联方收入真实性和定价公允性是否核实
- [ ] 【风险检查】是否存在关联方伪装为普通客户
- [ ] 【风险检查】是否存在"壳公司"客户迹象

## risk_areas

### 高风险

1. **虚构客户虚增收入**：新增客户为无实际经营的"壳公司"或客户信息无法验证，是虚增收入的核心舞弊手段，涉及发生认定。
2. **新客户突增异常**：新客户当年即贡献大额收入或进入前五大，但经营规模与采购规模不匹配，反映收入可能虚构。
3. **关联方伪装普通客户**：关联方通过隐性关联伪装为普通客户，规避关联交易披露，涉及披露完整性和公允性。
4. **前五大客户交易虚构**：前五大客户收入无真实交易支撑或回款异常，因金额重大构成重大错报风险。
5. **客户集中度过高**：单一或少数客户占比过大导致收入高度依赖，客户流失将引发重大收入波动，影响持续经营。

### 中风险

1. **老客户流失被掩盖**：重要老客户流失但通过虚构新客户填补，掩盖真实经营下滑。
2. **大客户回款异常**：前五大客户收入大但应收账款账龄长/回款差，反映收入真实性或信用风险问题。
3. **关联方收入占比高**：关联方收入占比过大且定价公允性存疑，影响收入质量判断。
4. **客户信息不完整**：重要客户缺少背景信息、信用评估，影响风险判断。
5. **同一控制客户群**：多个客户存在同一地址/联系方式/账户，可能为同一实际控制人。

### 低风险

1. **格式规范性问题**：客户结构表格式不统一、排列不规范。
2. **辅助信息缺失**：缺少客户行业、地区分布等辅助分析信息。
3. **小客户归集**：小额客户归集未附明细。
4. **交叉索引不完整**：与明细表、函证底稿、关联方底稿的交叉引用不全。
