# D4-3 其他业务收入明细表复核提示词

## 概述

本提示词针对其他业务收入明细表（D4-3，科目6051）的复核，聚焦四大核心审计要点：其他业务范围界定准确性、材料销售/租赁/服务等明细完整性、与其他业务成本的配比勾稽、与主营业务收入的分类边界。其他业务收入是企业非核心经营活动产生的收入（材料销售、包装物出租、技术转让、废料处置等），虽金额通常较小，但常被用作分类调节工具或掩盖主营业务的异常波动，其真实性和分类准确性同样需要审慎复核。

**法规依据：**
- 《企业会计准则第14号——收入》
- 《中国注册会计师审计准则第1301号——审计证据》
- 《中国注册会计师审计准则第1141号——财务报表审计中与舞弊相关的责任》

---

## tips

1. **其他业务范围界定是分类准确性的前提**：其他业务收入仅包含企业日常活动中非核心业务产生的收入（材料销售/出租/技术服务/废料等），须与主营业务收入、营业外收入严格区分。
2. **明细合计必须与审定表勾稽**：D4-3 各项其他业务收入合计必须等于 D4-1 审定表其他业务收入（6051）审定数，任何差异需追溯至具体调整。
3. **配比原则要求收入与成本对应**：材料销售应有对应的材料成本结转，出租应有折旧和维护成本，其他业务收入应与其他业务成本形成合理配比，无成本的其他业务收入需警惕。
4. **警惕分类调节工具**：其他业务收入常被用于将主营业务的异常收入转移分类，或将营业外性质收入错误计入营业收入，需核实每项收入的业务实质。
5. **关注偶发性大额其他业务收入**：一次性大额技术转让、资产处置性质的收入是否正确归类（可能应计入营业外收入或资产处置收益），须核实业务实质而非仅看科目。
6. **勾稽关系**：各项其他业务收入合计 = D4-1其他业务收入审定数；材料销售收入 ↔ 材料销售成本；出租收入 ↔ 相关资产折旧，勾稽断裂为复核重点。

## checklist

### 一、其他业务范围界定（高风险）

- [ ] 【必检】其他业务收入是否仅包含非核心日常活动收入（材料销售/出租/服务等）
- [ ] 【必检】是否存在主营业务收入被错误计入其他业务收入
- [ ] 【必检】是否存在营业外性质收入（资产处置/政府补助）被错误计入其他业务收入
- [ ] 【必检】各项其他业务的性质是否明确标注（材料销售/租赁/技术服务/废料等）
- [ ] 【条件检查：若有大额一次性收入】一次性技术转让/资产处置收入归类是否正确
- [ ] 【风险检查】是否存在通过其他业务收入调节收入分类的迹象

### 二、明细完整性（高风险）

- [ ] 【必检】明细表是否按业务类型完整列示各项其他业务收入
- [ ] 【必检】各项收入是否有对应合同/协议/结算单据支撑
- [ ] 【必检】明细合计是否与 D4-1 审定表其他业务收入（6051）一致
- [ ] 【必检】收入是否为不含税金额
- [ ] 【条件检查：若有关联方交易】关联方其他业务收入是否单独标注
- [ ] 【风险检查】是否存在无真实业务支撑的其他业务收入

### 三、配比与成本勾稽（中风险）

- [ ] 【必检】材料销售收入是否有对应材料销售成本结转
- [ ] 【必检】出租收入是否有对应资产折旧和维护成本
- [ ] 【必检】其他业务收入与其他业务成本是否形成合理毛利
- [ ] 【条件检查：若有无成本收入】纯收入无成本项目的合理性是否说明
- [ ] 【风险检查】是否存在收入与成本期间不配比

### 四、分类边界与列报（中风险）

- [ ] 【必检】其他业务收入与主营业务收入的分类边界是否清晰
- [ ] 【必检】收入确认时点是否符合CAS14履约义务完成标准
- [ ] 【必检】其他业务收入在利润表/附注列报是否准确
- [ ] 【条件检查：若跨期】跨期收入截止是否正确
- [ ] 【风险检查】分类是否与上期一致，变动是否有合理解释

## risk_areas

### 高风险

1. **收入性质错误归类**：将营业外收入（资产处置/政府补助）或主营业务收入错误计入其他业务收入，扭曲收入结构和营业利润。
2. **虚构其他业务收入**：无真实业务支撑的材料销售或服务收入，涉及发生认定，虽金额较小但反映内控和舞弊风险。
3. **分类调节工具化**：利用其他业务收入平滑主营业务波动或转移异常收入，误导报表使用者对核心业务的判断。
4. **明细与审定表不勾稽**：其他业务收入明细合计与 D4-1 审定数不一致，存在遗漏或错误记录。

### 中风险

1. **收入成本不配比**：材料销售/出租收入无对应成本结转，或收入与成本期间不一致，违反配比原则。
2. **关联方其他业务收入未识别**：关联方材料销售/租赁未单独标注，影响关联交易披露和公允性判断。
3. **一次性大额收入归类不当**：技术转让等偶发性大额收入未核实业务实质即计入其他业务收入。
4. **收入确认时点错误**：其他业务收入未按履约义务完成确认，存在跨期或提前确认。

### 低风险

1. **格式规范性问题**：明细表格式不统一、业务类型标注不规范。
2. **辅助信息缺失**：缺少业务背景说明、合同编号等辅助信息。
3. **交叉索引不完整**：与其他业务成本、审定表的交叉引用标注不全。
