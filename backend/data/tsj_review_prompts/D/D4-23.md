# D4-23 发票比对检查表复核提示词

## 概述

本提示词针对营业收入发票比对检查表（D4-23）的复核，聚焦金税系统/开票系统的开票数据与账面收入的比对及差异分析。发票数据作为独立于账务系统的外部证据，与账面收入的比对是验证收入真实性和完整性的有力手段。账面收入大于开票（可能虚增无票收入）、开票大于账面收入（可能漏记收入或虚开发票）、以及税会差异，均须逐项分析并合理解释。

**法规依据：**
- 《企业会计准则第14号——收入》
- 《中国注册会计师审计准则第1141号——财务报表审计中与舞弊相关的责任》
- 《中国注册会计师审计准则第1314号——审计抽样》
- 《中国注册会计师审计准则第1301号——审计证据》

## tips

1. **发票数据是独立于账务的外部证据**：金税/开票系统数据由税务系统背书，独立性高，与账面收入比对可有效验证收入真实性，比对差异是收入错报的重要线索。
2. **账面大于开票须警惕虚增收入**：账面收入显著大于开票金额（超出合理无票收入范围）可能存在虚构收入、跨期确认，须逐项核查无票收入的真实业务支撑。
3. **开票大于账面须警惕漏记或虚开**：开票金额大于账面收入可能存在漏记收入（完整性问题）或对外虚开发票（重大合规/舞弊风险），两个方向须分别调查（CAS1141）。
4. **税会差异须有合理解释**：收入确认时点与开票时点差异、视同销售、价外费用、免税收入等会导致税会差异，每类差异须有制度依据和金额验证，无法解释的差异为重点。
5. **比对口径须一致可勾稽**：账面收入与开票金额比对须统一含税/不含税口径、统一期间，剔除非收入类开票（如代垫、往来），确保比对基础可比。
6. **抽样比对与整体比对结合（CAS1314）**：整体上进行收入总额与开票总额的勾稽，同时对差异项、大额开票、异常开票（红冲/作废异常）进行抽样穿透核查。

## checklist

### 一、比对基础与口径

- [ ] 开票数据是否取自金税系统/税控开票系统（独立外部来源）
- [ ] 账面收入与开票金额是否统一含税/不含税口径比对
- [ ] 比对期间是否一致（同一会计期间）
- [ ] 是否剔除非收入类开票（代垫费用/往来款/预收）
- [ ] 主营业务收入（6001）与其他业务收入（6051）是否分别比对
- [ ] 比对是否覆盖全部开票主体（含分支机构）

### 二、差异识别与方向分析

- [ ] 账面收入与开票总额的差异是否计算并列示
- [ ] 账面大于开票的差异是否逐项分析（无票收入真实性）
- [ ] 开票大于账面的差异是否逐项分析（漏记收入/虚开风险）
- [ ] 差异是否按类型归类（时点差异/视同销售/价外费用/免税等）
- [ ] 无法解释的差异金额是否单独列示并调查
- [ ] 差异占收入比例是否合理，异常大是否已重点核查

### 三、异常开票核查

- [ ] 红字发票（冲销）金额是否异常，是否有合理业务依据
- [ ] 作废发票比例是否异常
- [ ] 期末集中开票是否与截止测试结果印证
- [ ] 大额开票是否抽样穿透核查对应真实交易
- [ ] 是否存在对外虚开发票的迹象
- [ ] 是否存在开票客户与账面客户不一致的情况

### 四、税会勾稽与结论

- [ ] 开票销售额是否与增值税申报表销售额勾稽
- [ ] 账面收入与增值税纳税申报收入差异是否合理解释
- [ ] 比对差异是否与D4-17/D4-18截止测试交叉印证
- [ ] 无票收入是否有真实业务支撑并评估税务合规风险
- [ ] 比对结论是否明确（一致/差异已解释/存在异常需调整）
- [ ] 底稿是否记录比对方法、数据来源、差异分析及交叉索引

## risk_areas

### 高风险

1. **账面虚增无票收入**：账面收入远超开票金额，无票收入缺乏真实业务支撑，可能虚构收入，属收入舞弊（CAS1141）。
2. **漏记开票收入**：开票金额大于账面收入，存在已开票销售未确认收入，违反收入完整性认定。
3. **对外虚开发票**：开票金额异常且无对应真实交易，存在虚开发票的重大合规和舞弊风险。
4. **异常红冲作废掩盖操纵**：大额或高频红字发票、作废发票用于冲销虚假开票或掩盖收入操纵。

### 中风险

1. **税会差异未充分解释**：账面收入与增值税申报收入差异缺乏合理制度依据和金额验证。
2. **比对口径不一致**：含税/不含税或期间口径不一致导致比对差异失真，掩盖真实差异。
3. **无票收入税务合规风险**：无票收入真实但存在未依法开票、税务处理不当的合规风险。
4. **开票客户与账面客户不符**：开票对象与账面记录客户不一致，收入归属或客户真实性存疑。

### 低风险

1. **比对未覆盖全部主体**：分支机构开票数据未纳入比对，比对完整性不足。
2. **底稿记录不完整**：比对方法、差异分类、数据来源记录不完整。
3. **交叉索引缺失**：发票比对底稿与收入明细、截止测试、增值税申报的交叉引用不完整。
