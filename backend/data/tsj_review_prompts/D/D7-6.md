# D7-6 合同负债关联方检查表复核提示词

## 概述

本提示词针对合同负债关联方检查表（D7-6，科目码2205）的复核，聚焦四大核心审计要点：关联方识别完整性、关联方合同负债商业实质、交易定价与资金往来性质、关联方披露充分性。关联方合同负债因存在通过关联方预收款调节收入确认时点、或以合同负债名义掩盖关联方资金往来的风险，是合同负债审计的高风险领域。检查表须完整识别关联方、验证预收款的商业实质、评估是否为真实预收、并支持关联方披露。

**法规依据：**
- 《企业会计准则第36号——关联方披露》
- 《企业会计准则第14号——收入》
- 《中国注册会计师审计准则第1301号——审计证据》
- 《中国注册会计师审计准则第1550号——关联方》

---

## tips

1. **关联方识别完整性是检查的前提**：须核对关联方清单（B19/关联方登记）与合同负债明细（D7-2），确保所有关联方合同负债被识别，避免遗漏隐性关联方（同受控制、关键管理人员相关方等）。
2. **关联方合同负债的商业实质须重点验证**：关联方预收款可能缺乏真实商业目的，实为资金拆借或调节收入的工具，须核对是否有真实合同及待履约义务。
3. **警惕以合同负债名义掩盖关联方资金往来**：关联方向企业提供资金以"预收款"名义挂账合同负债，实为资金性往来，须穿透判断性质，防止负债科目错列。
4. **关联方合同负债影响收入确认时点操纵**：通过关联方预收后再结转收入可人为调节收入，须评估关联方合同负债结转收入的真实性及时点恰当性。
5. **CAS36要求关联方交易单独披露**：关联方合同负债须单独列示关联方名称、关系类型、交易金额、期末余额，检查表是披露的支持底稿。
6. **关注跨底稿勾稽**：D7-6关联方合同负债 ↔ D7-2明细表关联方标志；关联方结转收入 ↔ 收入底稿关联方收入；关联方长期挂账 ↔ D7-5长期挂账检查；披露 ↔ D7-note关联方披露。

## checklist

### 一、关联方识别完整性

- [ ] 关联方清单是否与关联方登记（B19）及集团架构一致
- [ ] 合同负债明细（D7-2）中关联方合同负债是否全部识别并标注
- [ ] 是否识别隐性关联方（同受控制、关键管理人员及其近亲属相关方）
- [ ] 关联关系类型是否准确判断（母子公司/同一控制/联营合营等）
- [ ] 是否存在通过第三方过桥掩盖关联关系的迹象
- [ ] 新增关联方合同负债是否有关联关系认定记录

### 二、关联方合同负债商业实质

- [ ] 关联方合同负债是否有真实合同文本及待履约义务
- [ ] 关联方预收款是否有真实的商业目的（对应真实交易）
- [ ] 待履约义务是否真实存在且与合同一致
- [ ] 期末大额关联方合同负债是否核查履约安排及交易背景
- [ ] 是否存在向关联方虚构预收以调节收入的迹象
- [ ] 关联方合同负债结转收入的时点及真实性是否核查

### 三、交易定价与资金往来性质

- [ ] 关联方合同定价方式是否披露（市场价/协议价/成本加成）
- [ ] 关联方合同定价是否与同类非关联交易比较且公允
- [ ] 是否穿透判断关联方"预收款"是否实为资金性往来（资金拆借）
- [ ] 是否存在以合同负债名义掩盖关联方资金占用的情况
- [ ] 关联方预收款的收款条件是否与非关联交易存在异常差异
- [ ] 是否存在通过关联方预收再退回的循环交易

### 四、关联方披露充分性

- [ ] 关联方名称、关系类型、交易金额、期末余额是否完整列示
- [ ] 关联方合同负债的账龄及待履约状况是否分析
- [ ] 关联方长期挂账合同负债是否与D7-5勾稽
- [ ] 检查表数据是否支持附注关联方披露（D7-note）
- [ ] 关联方合同负债的商业实质是否清晰说明
- [ ] 是否存在应披露而未披露的重大关联方合同负债

## risk_areas

### 高风险

1. **以合同负债名义掩盖资金往来**：关联方向企业提供资金以预收款名义挂账合同负债，掩盖非经营性资金拆借，属负债科目错列及舞弊风险。
2. **关联方虚构预收调节收入**：通过关联方虚构预收后再结转收入，人为调节各期收入及业绩。
3. **关联方未识别**：隐性关联方合同负债未识别或未标注，影响关联交易披露完整性。
4. **关联方预收无商业实质**：关联方预收款缺乏真实交易背景及待履约义务，实为资金运作工具。
5. **循环交易虚增业务**：通过关联方预收再退回的循环交易虚增业务规模。

### 中风险

1. **关联关系判断错误**：关联关系类型判断错误，影响披露分类及豁免条款适用。
2. **披露不完整**：关联方合同负债未按CAS36完整列示名称、关系、金额。
3. **定价不公允**：关联方合同定价与非关联交易存在异常差异未说明。
4. **结转收入时点操纵**：关联方合同负债结转收入的时点异常，调节收入。
5. **长期挂账未勾稽**：关联方长期挂账合同负债未与D7-5长期挂账检查勾稽。

### 低风险

1. **格式不规范**：检查表格式、列序等形式问题。
2. **辅助信息不足**：关联方交易背景说明简略。
3. **交叉索引不完整**：与D7-2明细、D7-5长期挂账、收入底稿及附注的交叉引用标注不全。
