# D5-note-soe 附注披露复核提示词（国有企业）

## 概述

本提示词针对应收款项融资国有企业附注披露底稿（D5-note-soe）的复核，聚焦国有企业特定的附注披露要求：国有资产监管相关披露、关联交易（含与政府/国有控股单位票据往来）、国资委要求的补充披露事项，以及与上市公司版本的差异关注点。国有企业审计具有双重属性（财务审计+国有资产监管），应收款项融资披露须同时满足会计准则（CAS22/CAS23/CAS37）和国资监管要求，尤其关注已质押/已贴现票据涉及的国有资产受限和融资安排。

**法规依据：**
- 《企业会计准则第37号——金融工具列报》
- 《企业会计准则第22号——金融工具确认和计量》
- 《企业会计准则第23号——金融资产转移》
- 《企业国有资产法》
- 《中央企业财务决算报告管理办法》

## tips

1. **国有企业附注有"双层"披露要求**：既要满足企业会计准则（CAS22/CAS23/CAS37）的通用披露要求，又要满足国资委财务决算报告的额外披露要求，两套要求互为补充、不可替代。
2. **国企版结构与上市版一致但增加监管信息**：国企版披露框架与上市版相同——（1）应收款项融资分项目列示 +（减值/质押/背书贴现参考披露，表样参考D1/D2，数据取自D5-2），额外增加国资监管相关补充信息，禁止自造披露内容。
3. **已质押/已贴现票据是国有资产受限披露重点**：国企以应收票据质押或贴现融资涉及国有资产受限，须披露质押/贴现金额、对象及融资安排，评估对国有资产安全的影响。
4. **关联方范围比一般企业更广**：国有企业的关联方除一般定义外，还需考虑同一国有控股股东控制的其他国有企业（"同受国有控制"的关联方），关联方票据往来须完整识别。
5. **CAS23终止确认披露与国资监管结合**：已背书/贴现的应收票据须区分已终止确认和未终止确认金额，未终止确认部分形成的负债涉及国企融资规模，须结合预算和融资管理披露。
6. **与上市版的差异主要在监管层面而非准则层面**：基础披露框架相同（分类/减值/质押/背书贴现），国企版额外增加国资监管相关信息，而非替代基础披露要求。

## checklist

### 一、基础披露完整性（与上市版共有）

- [ ] 应收款项融资是否按（1）分项目列示（银行承兑汇票/商业承兑汇票/应收账款）
- [ ] 各分项期末余额合计是否等于审定表应收款项融资审定数
- [ ] 减值准备情况是否披露（参考披露，表样参考D1/D2）
- [ ] 期末已质押的应收票据是否披露（数据取自D5-2）
- [ ] 期末已背书或贴现但尚未到期的应收票据是否披露（区分终止确认/未终止确认）
- [ ] 期初数/期末数可比信息是否完整列示

### 二、国有资产监管相关披露

- [ ] 已质押的应收款项融资是否披露金额、质押对象及融资用途
- [ ] 已贴现票据形成的融资规模是否披露（涉及国企负债管理）
- [ ] 是否披露应收款项融资中涉及国有资产受限的情况
- [ ] 大额应收款项融资（超过单户限额标准）是否按国资委要求逐户披露
- [ ] 商业承兑汇票的承兑人信用状况和坏账风险是否说明
- [ ] 应收款项融资公允价值变动对国有资本保值增值的影响是否说明

### 三、关联交易披露（国企特定）

- [ ] 与控股股东及其关联企业的应收款项融资/票据往来是否逐户列示
- [ ] 与同一母公司控制的其他国有企业的票据往来是否披露
- [ ] 是否运用了"同受国家控制"关联方的豁免条款，如运用是否符合条件
- [ ] 关联方票据往来的交易实质是否清晰说明（经营性/融资性）
- [ ] 是否存在通过关联方票据背书/贴现进行融资安排的情况并说明
- [ ] 与政府部门相关的应收票据（如财政专项）是否单独列示

### 四、国资委要求的补充披露

- [ ] 重大票据贴现/质押融资是否披露决策程序（涉及"三重一大"时）
- [ ] 已贴现商业承兑汇票的追索权风险是否披露
- [ ] 应收款项融资中涉及法律诉讼/票据纠纷的金额及进展是否披露
- [ ] 是否披露应收款项融资相关的融资规模与年度预算的对比
- [ ] 以应收票据为关联方提供融资便利是否按国资委要求披露

### 五、与上市版的差异关注点

- [ ] 国企版是否在上市版基础披露的基础上增加了国资监管层面的补充信息
- [ ] 关联方范围是否已扩展至"同受国有控制"的企业
- [ ] 已质押/已贴现票据是否补充了国有资产受限和融资管理信息
- [ ] 是否增加了商业承兑汇票追索权风险和融资规模披露
- [ ] 是否增加了国有资本保值增值相关影响分析
- [ ] CAS23终止确认披露是否结合国企融资管理和预算说明

## risk_areas

### 高风险

1. **自造披露内容**：凭"常识"臆造披露表格，偏离源模板真实结构（分项目列示+减值+质押+背书贴现），属披露内容错误。
2. **已质押/已贴现受限资产未披露**：涉及国有资产受限的质押/贴现票据未披露金额和融资安排，可能掩盖国有资产受限风险。
3. **终止确认披露缺失或错误**：已背书/贴现票据未区分终止确认和未终止确认金额，未终止确认负债漏披露，不满足CAS23要求。
4. **关联方票据往来范围遗漏**：未将同一国有控股股东下的兄弟单位票据往来纳入关联方披露，违反CAS36和国资委要求。
5. **基础披露与审定表不勾稽**：附注各项目合计与审定表审定数不一致，属重大数据错误。

### 中风险

1. **商业承兑汇票追索权风险未披露**：已贴现商业承兑汇票保留追索权但未披露相关风险。
2. **"同受国有控制"豁免条款适用不当**：不符合豁免条件却简化了同受国家控制关联方的披露。
3. **融资规模预算对比缺失**：票据贴现/质押形成的融资规模未与年度预算对比说明。
4. **决算报表与审计报表口径差异未调节**：财务决算数据与审计后附注数据存在差异但未编制调节说明。
5. **减值准备披露不充分**：商业承兑汇票信用风险和减值披露简略。

### 低风险

1. **披露格式未完全按决算报表模板**：附注格式与国资委决算报表模板有细微差异，但信息内容完整。
2. **质押/贴现说明过于简略**：融资安排已披露但具体条件（利率、期限）未详细说明。
3. **公允价值层次说明不足**：公允价值层次已列示但计量方法说明简略。
4. **历史年度信息追溯不完整**：应收款项融资增减变动的历史趋势分析仅覆盖2年而非国资委建议的3年。
