# D2-10 ECL 计量测试复核提示词

## 适用底稿
ECL 计量测试表（D2-10），含迁徙率矩阵、折现法测算、组合损失率推导及与 D2-3 应计提勾稽。

## 概述
D2-10 承载 CAS22 组合 ECL 的核心计量逻辑。复核须验证历史数据基础、迁徙率/损失率计算、折现参数及与 D2-3、D2-9 的闭环勾稽。

---

## tips

1. **历史数据年限**：迁徙率至少 3 年（建议 5 年），取数须与 D2-2 账龄明细一致。
2. **迁徙率逻辑**：账龄越长，向更长账龄或损失迁徙的概率应合理递增；异常波动须解释。
3. **折现法**：若采用折现法，折现率选取须与合同现金流特征匹配，现值计算可复核。
4. **与 D2-3 勾稽**：D2-10 组合应计提与 D2-3 组合计提部分一致；D2-3↔D2-9 差异告警须在 D2-10 侧有解释。
5. **前瞻性信息**：是否对历史损失率做宏观/行业调整，方法与权重须披露。
6. **分组一致性**：组合划分标准须与 D2-3/D2-8 会计政策一致，不同信用风险不得混组。

## checklist

### 高风险检查项

- [ ] 迁徙率矩阵取数期间、账龄分段与 D2-2/D2-8 政策一致
- [ ] 迁徙率计算公式正确，各段连乘得到的历史损失率可复算
- [ ] 组合应计提合计与 D2-3 坏账准备组合部分勾稽一致
- [ ] D2-3 与 D2-9 合计差异（如有系统告警）是否在 D2-10 或说明中解释
- [ ] 折现率、折现期数、现金流假设是否合理且有依据
- [ ] 是否纳入前瞻性调整，调整幅度与宏观假设匹配
- [ ] 信用风险显著增加（Stage 2）客户的组合边界是否正确

### 中风险检查项

- [ ] 历史数据是否剔除一次性大额核销、债务重组等非经常性因素
- [ ] 不同客户群体/业务线是否应分组合并评估
- [ ] 模型输出是否做过回测（实际 vs 预测损失率）
- [ ] 账龄段边界（发票日/到期日/入账日）是否与会计政策一致
- [ ] 迁徙率矩阵合计、小计行无公式错误

### 低风险检查项

- [ ] 参考示例/方法论说明是否与项目实际选用方法一致
- [ ] 审计说明/结论是否涵盖计量方法、关键参数与 residual 风险
- [ ] 导入导出数据与界面展示一致

## risk_areas

### 高风险

- 迁徙率基于不完整或错误的历史数据，导致 ECL 系统性偏低
- 组合应计提与 D2-3 长期不符且无调整
- 折现率或现金流假设严重偏离市场/合同实际

### 中风险

- 前瞻性调整缺失或过于主观
- 组合划分与信用风险特征不匹配

### 低风险

- 文档格式、索引不完整

## 跨底稿勾稽

- D2-10 组合应计提 ↔ D2-3 组合计提部分
- D2-10 历史账龄数据 ↔ D2-2 明细账龄分析
- D2-3 + D2-9 合计 ↔ D2-1 审定表坏账准备审定数
