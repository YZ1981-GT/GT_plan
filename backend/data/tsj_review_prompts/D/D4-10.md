# D4-10 客户价格分析表复核提示词

## 概述

本提示词针对客户价格分析表（D4-10）的复核，聚焦四大核心审计要点：同一客户不同期价格波动、客户间价格差异合理性、异常定价识别、关联方客户定价公允性。客户价格分析从客户维度审视销售单价的横向（客户间）和纵向（期间）差异，通过识别异常定价（同客户价格突变、客户间价格悬殊、关联方低价/高价）揭示可能的虚增收入、利润转移和关联交易舞弊。

**法规依据：**
- 《企业会计准则第14号——收入》
- 《中国注册会计师审计准则第1301号——审计证据》
- 《中国注册会计师审计准则第1141号——财务报表审计中与舞弊相关的责任》
- 《企业会计准则第36号——关联方披露》

---

## tips

1. **同一客户价格波动揭示定价异常**：同一客户同一产品在不同期间价格大幅波动，须核实是市场因素、成本变动还是人为调价，警惕通过调价虚增收入或转移利润。
2. **客户间价格差异需商业合理性支撑**：同一产品对不同客户的价格差异应有合理依据（采购量、信用、地区、合同期限），无依据的价格悬殊是关联交易或舞弊信号。
3. **关联方定价公允性是核心关注**：关联方客户的销售价格须与非关联方公允价格对比，异常偏离（低价输送利润/高价虚增收入）涉及关联交易公允性和收入真实性。
4. **异常低价可能反映倾销或利润转移**：显著低于成本或市场价的销售价格，可能反映向关联方转移利润、清库存倾销或收入虚减。
5. **异常高价可能反映虚增收入**：显著高于市场价的销售价格，可能反映虚增收入、循环交易或关联方虚构交易。
6. **勾稽关系**：客户单价 = 客户收入 ÷ 客户销量（D4-2）；关联方价格 ↔ 非关联方公允价格；期间价格变动 ↔ 成本/市场变动，勾稽断裂为复核重点。

## checklist

### 一、同一客户不同期价格波动（高风险）

- [ ] 【必检】主要客户同一产品的期间价格是否列示对比
- [ ] 【必检】价格波动幅度是否标注并说明原因
- [ ] 【必检】价格变动是否与成本变动、市场价格趋势匹配
- [ ] 【条件检查：若价格突变】价格突变客户的交易是否核实
- [ ] 【风险检查】是否存在通过期末调价虚增收入
- [ ] 【风险检查】价格波动是否与合同约定一致

### 二、客户间价格差异分析（高风险）

- [ ] 【必检】同一产品对不同客户的价格是否横向对比
- [ ] 【必检】价格差异是否有商业合理性依据（量/信用/地区/期限）
- [ ] 【必检】价格差异是否符合公司定价政策
- [ ] 【条件检查：若价格悬殊】价格悬殊客户的合理性是否核实
- [ ] 【风险检查】是否存在无依据的客户间价格歧视
- [ ] 【风险检查】异常价格客户是否为关联方

### 三、异常定价识别（高风险）

- [ ] 【必检】显著偏离市场价/历史价的定价是否标注
- [ ] 【必检】低于成本的销售价格是否说明原因
- [ ] 【必检】异常高价的商业合理性是否验证
- [ ] 【条件检查：若有低于成本定价】倾销/利润转移可能性是否评估
- [ ] 【风险检查】是否存在异常高价虚增收入
- [ ] 【风险检查】是否存在循环交易或虚构交易的价格特征

### 四、关联方客户定价公允性（中风险）

- [ ] 【必检】关联方客户价格是否与非关联方公允价格对比
- [ ] 【必检】关联方定价方式是否披露（市场价/协议价/成本加成）
- [ ] 【必检】关联方价格偏离公允价格的金额及影响是否评估
- [ ] 【条件检查：若关联方价格异常】利润转移/收入虚增影响是否量化
- [ ] 【风险检查】是否存在关联方低价输送利润或高价虚增收入

## risk_areas

### 高风险

1. **关联方非公允定价**：关联方客户以显著偏离公允价格交易（低价输送利润或高价虚增收入），涉及关联交易公允性和收入真实性。
2. **期末调价虚增收入**：资产负债表日前通过对客户调高价格虚增当期收入，是收入舞弊的隐蔽手段。
3. **异常高价虚构交易**：显著高于市场价的销售价格，可能反映虚增收入、循环交易或与关联方虚构交易。
4. **同一客户价格无规律波动**：主要客户价格大幅波动且无法用成本/市场因素解释，反映定价可能被操纵。
5. **价格与合同不符**：实际销售价格与合同约定价格不一致且无补充协议，反映收入金额可能失真。

### 中风险

1. **客户间价格歧视无依据**：同一产品对不同客户价格悬殊但无商业合理性依据。
2. **低于成本销售**：显著低于成本的销售价格未说明商业合理性，可能存在倾销或利润转移。
3. **关联方定价方式未披露**：关联方交易定价方式未清晰披露，影响公允性判断。
4. **价格趋势与成本背离**：销售价格趋势与成本趋势明显背离且无解释。

### 低风险

1. **价格数据口径不一**：不同期间价格计算口径（含税/不含税）不一致。
2. **分析样本不足**：仅分析少数客户价格，覆盖面不足。
3. **辅助信息缺失**：缺少定价政策、市场价格基准等参照信息。
4. **交叉索引不完整**：与明细表、合同检查、关联方底稿的交叉引用不全。
