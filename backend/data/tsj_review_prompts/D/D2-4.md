# D2-4 调整分录复核提示词

## 适用底稿
调整分录汇总表（D2-4）

## tips

- 审计调整分录（AJE）必须有充分的审计证据支持和合伙人审批
- 重分类调整分录（RJE）仅影响报表列报不影响利润，方向不得颠倒
- 所有调整分录借贷方必须平衡，且金额须与审定表调整列完全一致
- 未调整错报（SUD）须评估单独及累计影响是否超过整体重要性水平
- 跨期调整须明确属于本期还是前期差错更正，处理方式不同

## checklist

### 高风险

- [ ] 所有 AJE 是否有充分审计证据支持
- [ ] AJE 是否经过合伙人/项目经理审批
- [ ] 调整分录借贷方是否完全平衡
- [ ] 调整分录涉及的金额是否超过明细层次重要性水平
- [ ] 是否存在仅为美化报表目的的不当调整

### 中风险

- [ ] RJE 是否仅涉及列报不影响损益
- [ ] 调整分录是否已完整反映到审定表（D2-1）调整列
- [ ] 未调整错报累计金额是否超过整体重要性水平
- [ ] 调整原因说明是否清晰可追溯

### 低风险

- [ ] 调整分录编号是否连续无遗漏
- [ ] 调整分录与其他底稿（A13）交叉索引是否完整

## risk_areas

### 高风险

- 调整分录缺乏审计证据支持或未经授权审批
- 调整金额超过重要性水平但未进行专项说明
- 存在不当调整美化报表的迹象

### 中风险

- RJE 方向错误导致科目余额失真
- 未调整错报累计接近重要性水平边界
- 调整未同步至审定表造成不勾稽

### 低风险

- 调整分录格式不规范
- 编号不连续但不影响完整性
