# D1-note-listed 附注披露复核提示词（上市公司）

## 概述

本提示词针对应收票据上市公司附注披露底稿（D1-note-listed）的复核，聚焦上市公司财务报表附注中应收票据相关披露的充分性和准确性：分类披露（银行承兑汇票/商业承兑汇票）、已背书或贴现但尚未到期票据的终止确认/未终止确认披露、已质押票据披露、坏账准备变动披露、CAS37 金融工具列报要求、关联方应收票据单独披露。应收票据附注的特有难点在于金融资产转移（CAS23）相关披露，披露不充分将影响投资者对资产真实性和流动性的判断。

**法规依据：**
- 《企业会计准则第37号——金融工具列报》
- 《企业会计准则第22号——金融工具确认和计量》
- 《企业会计准则第23号——金融资产转移》
- 《企业会计准则第36号——关联方披露》
- 《公开发行证券的公司信息披露编报规则第15号——财务报告的一般规定》

## tips

1. **应收票据附注须按承兑人分类披露**：银行承兑汇票与商业承兑汇票须分别列示期末/期初余额，商业承兑汇票须进一步披露信用风险信息，这是应收票据区别于应收账款的核心披露维度。
2. **已背书/已贴现未到期票据是应收票据附注的特有强制披露**：根据 CAS23/CAS37，须披露资产负债表日已背书或贴现但尚未到期的应收票据的终止确认金额和未终止确认金额，这是应收票据附注最易遗漏且最关键的披露项。
3. **已质押票据须单独披露**：所有权受限的已质押应收票据须披露账面金额、质押原因及担保的债务，与借款附注勾稽。
4. **坏账/减值准备变动表须完整且勾稽**：变动表须列示期初、计提、转回、核销、期末，与 D1-15 ECL 计算和利润表信用减值损失勾稽（银承通常减值极小或为零）。
5. **信用风险披露须区分银承商承**：CAS37 要求披露信用风险敞口，银行承兑汇票信用风险集中于承兑银行，商业承兑汇票集中于承兑企业，须分别说明。
6. **附注须与审定表/明细/背书贴现/质押底稿闭环勾稽**：附注应收票据总额=D1-1 审定数；分类小计=D1-2 明细；终止确认/未终止确认金额=D1-8；质押金额=D1-12；减值变动=D1-15。

## checklist

### 一、分类披露检查

- [ ] 应收票据是否按银行承兑汇票/商业承兑汇票分类披露
- [ ] 各类别期末余额合计是否等于审定表应收票据审定数
- [ ] 各类别是否同时披露期末数和期初数（可比信息）
- [ ] 分类是否与会计政策及 D1-2 明细表一致
- [ ] 商业承兑汇票是否进一步披露信用风险信息

### 二、已背书/贴现未到期票据披露（CAS23 特有强制项）

- [ ] 是否披露已背书或贴现但尚未到期票据的终止确认金额
- [ ] 是否披露已背书或贴现但尚未到期票据的未终止确认金额
- [ ] 未终止确认票据是否说明未终止确认原因（如带追索权、商承风险未转移）
- [ ] 未终止确认部分对应的负债是否披露
- [ ] 披露金额是否与 D1-8 背书贴现明细表勾稽
- [ ] 期后到期或被追索情况是否披露

### 三、已质押票据披露

- [ ] 已质押应收票据是否单独披露账面金额
- [ ] 是否披露质押原因、质权人及担保的债务
- [ ] 质押金额是否与 D1-12 及借款附注勾稽
- [ ] 受限资产披露是否完整

### 四、坏账/减值准备变动披露

- [ ] 坏账/减值准备变动表是否完整（期初/计提/转回/核销/期末）
- [ ] 变动表各项是否与 D1-15 ECL 计算勾稽
- [ ] 本期计提是否与利润表信用减值损失一致
- [ ] 本期核销是否与 D1-16 勾稽并有依据
- [ ] 是否区分银承/商承的减值情况

### 五、CAS37 金融工具列报充分性

- [ ] 是否披露应收票据的信用风险管理目标和政策
- [ ] 是否披露预期信用损失的计量方法和关键假设
- [ ] 是否披露信用风险最大敞口
- [ ] 是否披露按承兑人类型的信用质量信息
- [ ] 是否披露应收票据公允价值（如与账面存在重大差异）

### 六、关联方应收票据披露

- [ ] 关联方应收票据是否单独列示（名称/关系/金额）
- [ ] 关联方应收票据是否与一般客户区分
- [ ] 关联方票据的信用风险/减值是否单独说明
- [ ] 关联方对开票据/无背景票据是否充分披露

## risk_areas

### 高风险

1. **已背书/贴现未到期票据未披露**：CAS23/CAS37 强制要求的终止确认/未终止确认金额未披露，属应收票据附注最严重的披露遗漏。
2. **未终止确认负债缺失**：披露了未终止确认票据却未披露对应负债，负债低估。
3. **附注总额与审定表不一致**：附注应收票据余额与审定数不勾稽，属重大数据错误。
4. **质押受限未披露**：已质押票据未作受限披露，误导资产流动性判断。
5. **关联方票据未单独披露**：关联方票据混入一般客户，违反 CAS36。

### 中风险

1. **分类维度不完整**：未按银承/商承分类披露，掩盖信用风险差异。
2. **减值变动表不勾稽**：变动表与 ECL 计算或利润表不一致。
3. **信用风险披露不充分**：未区分银承商承的信用风险敞口。
4. **可比信息缺失**：仅列示期末数据，未列示期初可比数据。

### 低风险

1. **披露格式不规范**：表格标题、列序、单位等格式细节问题。
2. **政策描述模板化**：信用风险管理政策照搬会计政策原文。
3. **期后事项披露简略**：期后到期/追索情况披露不详。
