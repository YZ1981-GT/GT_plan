# D6-note-listed 合同资产附注披露复核提示词（上市公司）

## 概述

本提示词针对合同资产上市公司附注披露底稿（D6-note-listed，科目码1402）的复核，聚焦上市公司财务报表附注中合同资产相关披露的充分性和准确性：合同资产分类披露、账龄披露、减值准备变动披露、CAS37/CAS14要求的充分性、合同资产与合同负债的对应关系披露、以及信用风险集中度披露。合同资产是CAS14引入的科目，其披露须同时满足金融工具列报（CAS37）与收入准则（CAS14）的要求，是投资者理解企业履约与收款权状况的重要信息。

**法规依据：**
- 《企业会计准则第37号——金融工具列报》
- 《企业会计准则第14号——收入》
- 《企业会计准则第22号——金融工具确认和计量》
- 《公开发行证券的公司信息披露编报规则第15号——财务报告的一般规定》
- 《中国注册会计师审计准则第1501号——对财务报表形成审计意见和出具审计报告》

## tips

1. **合同资产披露须兼顾CAS14与CAS37**：合同资产源于收入准则，其分类、与合同负债的关系披露遵循CAS14；其减值、信用风险披露遵循CAS37，两准则要求互补不可偏废。
2. **合同资产与应收账款、合同负债的关系须清晰披露**：附注须披露合同资产的性质（收款权取决于时间流逝外的因素）、期内转应收账款的金额，以及合同资产与合同负债的期末余额，帮助报表使用者理解合同履约进展。
3. **减值准备变动表是重点披露信息**：变动表须完整列示期初、本期计提、转回、核销、其他变动及期末余额，且与D6-3减值明细勾稽。
4. **合同资产账龄与减值须匹配披露**：按账龄披露合同资产及对应减值准备，账龄结构较上期重大变动须说明原因。
5. **信用风险披露须体现ECL计量**：须披露合同资产预期信用损失的计量方法（通常简化法）、关键假设、损失率矩阵及前瞻性信息，以及信用风险最大敞口。
6. **附注数据须与审定表/明细表/减值表/ECL表形成闭环勾稽**：附注合同资产总额=审定表审定数；分类小计=明细表对应分类合计；减值准备合计=D6-3期末余额；损失率=D6-8测算。

## checklist

### 一、分类与性质披露

- [ ] 合同资产的性质是否披露（收款权取决于时间流逝外的因素）
- [ ] 合同资产是否按业务性质/合同类型分类披露
- [ ] 各类别期末余额合计是否等于审定表合同资产审定数
- [ ] 各类别是否同时披露期末数和期初数（可比信息）
- [ ] 本期转应收账款的合同资产金额是否披露
- [ ] 合同资产与合同负债的期末余额及关系是否披露
- [ ] 分类方式是否与会计政策中确定的分类标准一致

### 二、账龄披露

- [ ] 账龄披露是否按规定区间完整列示（1年以内/1-2年/2-3年/3年以上）
- [ ] 各账龄段金额合计是否等于合同资产总额
- [ ] 账龄起算日口径是否与会计政策一致且予以说明
- [ ] 各账龄段是否同时列示账面余额和减值准备
- [ ] 账龄结构较上期是否存在重大异常变动，如有是否已说明原因
- [ ] 账龄分析数据是否与D6-2明细表账龄分析一致

### 三、减值准备变动披露

- [ ] 减值准备变动表是否完整（期初/计提/转回/核销/其他/期末）
- [ ] 变动表各栏金额是否与D6-3减值准备明细表勾稽
- [ ] 本期计提金额是否与利润表信用减值损失一致
- [ ] 本期核销是否有充分披露（金额/原因，与D6-9勾稽）
- [ ] 本期转回的原因是否合理披露
- [ ] 期末减值准备余额是否等于合同资产总额减净额

### 四、CAS37信用风险与ECL披露

- [ ] 是否披露合同资产的信用风险管理目标和政策
- [ ] 是否披露预期信用损失的计量方法（合同资产通常简化法）
- [ ] 是否披露ECL模型关键假设及损失率矩阵（与D6-8勾稽）
- [ ] 是否披露前瞻性信息的运用
- [ ] 是否披露信用风险最大敞口金额
- [ ] 是否披露合同资产的信用质量信息（按账龄/风险等级）
- [ ] 是否披露合同资产是否用于担保/质押

### 五、信用风险集中度与关联方披露

- [ ] 是否披露合同资产的信用风险集中度信息（前五名/按客户/行业）
- [ ] 集中度信息是否与D6-2明细表数据一致
- [ ] 关联方合同资产是否单独披露（名称/关系/金额/减值，与D6-5勾稽）
- [ ] 单一对方占比过高时是否有特别风险提示
- [ ] 关联方合同资产定价的公允性是否有说明
- [ ] 本期集中度较上期是否存在重大变动并说明

### 六、其他披露事项

- [ ] 合同资产与合同负债的划分及净额列示依据是否披露
- [ ] 合同资产减值损失对当期损益的影响是否披露
- [ ] 期后已转应收账款或已收回的重大合同资产是否披露
- [ ] 合同资产中涉诉金额是否披露
- [ ] 与收入确认相关的合同资产变动是否与收入附注勾稽
- [ ] 履约进度对合同资产确认的影响是否有说明

## risk_areas

### 高风险

1. **减值准备变动表不完整或不勾稽**：变动表勾稽关系不成立或与D6-3不一致，属重大披露错误。
2. **合同资产性质及与应收账款关系未披露**：未披露合同资产收款权取决于时间流逝外因素的性质，报表使用者无法区分合同资产与应收账款。
3. **ECL计量方法及关键假设未披露**：未披露预期信用损失计量方法、损失率矩阵及前瞻性信息，不满足CAS37要求。
4. **附注总额与审定表不一致**：附注合同资产期末余额与审定表审定数不一致，属数据勾稽重大错误。
5. **关联方合同资产未单独披露**：关联方合同资产混入一般对方未单独列示，违反CAS36要求。

### 中风险

1. **账龄披露口径不一致**：附注账龄起算日与减值模型使用的起算日不同，账龄分布与损失率无法对应。
2. **合同资产与合同负债关系披露缺失**：未披露合同资产与合同负债的期末余额及对应关系。
3. **转应收账款金额未披露**：本期转应收账款的合同资产金额未披露，影响履约进展理解。
4. **信用风险集中度信息缺失**：未披露合同资产信用风险集中度或前五名信息。
5. **可比信息缺失**：附注中仅列示期末数据，未列示期初可比数据。

### 低风险

1. **披露格式不完全规范**：表格标题、列序、金额单位等格式细节问题。
2. **文字描述模板化**：信用风险管理政策描述照搬会计政策原文，未结合本企业实际。
3. **数字精度不一致**：部分披露保留两位小数、部分取整到万元，精度不统一。
4. **期后事项披露简略**：期后转应收账款或收回的合同资产仅提及事实，未说明影响。
