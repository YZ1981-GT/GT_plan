# D4-5 收入确认会计政策检查表复核提示词

## 概述

本提示词针对收入确认会计政策检查表（D4-5）的复核，聚焦四大核心审计要点：CAS14 五步法应用正确性、时段法与时点法判断、总额法与净额法应用、主要责任人与代理人身份识别。收入确认会计政策是收入审计的方法论基础，政策应用错误将系统性地影响所有收入交易的确认时点、金额和列报，是收入审计中判断难度最高、舞弊隐蔽性最强的领域。

**法规依据：**
- 《企业会计准则第14号——收入》（五步法：识别合同→识别单项履约义务→确定交易价格→分摊交易价格→履约时确认收入）
- 《中国注册会计师审计准则第1301号——审计证据》
- 《中国注册会计师审计准则第1141号——财务报表审计中与舞弊相关的责任》
- 《企业会计准则第14号——收入 应用指南》

---

## tips

1. **五步法是收入确认的方法论主线**：CAS14 五步法（识别合同→识别单项履约义务→确定交易价格→分摊交易价格→履约时确认收入）必须逐步验证应用正确性，任一步骤判断错误都将传导至收入确认结果。
2. **时段法vs时点法决定确认节奏**：须核实履约义务是在某一时段内履行（三条件之一：客户即时取得控制/在建资产客户控制/不可替代用途且有收款权）还是在某一时点履行，判断错误将导致收入确认时点系统性错误。
3. **总额法vs净额法影响收入规模**：企业作为主要责任人按总额确认，作为代理人按净额确认，须依据"是否控制商品/服务"判断，错误应用将虚增或虚减收入规模。
4. **主要责任人与代理人识别是净额/总额法前提**：须评估企业是否在转让前控制商品（承担存货风险、有定价权、承担主要责任），身份识别错误是电商/平台/贸易类企业的高发问题。
5. **可变对价与重大融资成分需专门评估**：折扣、返利、退货、质保金等可变对价的估计方法，以及超过一年的分期收款是否含重大融资成分，均影响交易价格确定。
6. **政策一致性与合理性双重验证**：收入政策是否与上期一致（一致性），是否符合CAS14及行业惯例（合理性），政策变更是否有充分理由并追溯调整。

## checklist

### 一、CAS14 五步法应用（高风险）

- [ ] 【必检】步骤一：是否正确识别与客户的合同（五项条件：批准并承诺/可辨认权利义务/有支付条款/有商业实质/很可能收回对价）
- [ ] 【必检】步骤二：是否正确识别合同中的单项履约义务（可明确区分的商品/服务）
- [ ] 【必检】步骤三：交易价格确定是否考虑可变对价、重大融资成分、非现金对价、应付客户对价
- [ ] 【必检】步骤四：交易价格是否按单独售价比例分摊至各单项履约义务
- [ ] 【必检】步骤五：是否在履约义务完成（控制权转移）时确认收入
- [ ] 【条件检查：若有多重履约义务】捆绑销售的价格分摊是否合理
- [ ] 【风险检查】是否存在跳过或简化五步法导致确认时点/金额错误

### 二、时段法与时点法判断（高风险）

- [ ] 【必检】履约义务是时段内履行还是时点履行的判断依据是否充分
- [ ] 【必检】时段内履行是否满足三条件之一（客户即时取得并消耗/客户控制在建资产/不可替代用途且有收款权）
- [ ] 【必检】时段法下履约进度计量方法（产出法/投入法）是否合理一致
- [ ] 【必检】时点法下控制权转移时点（发出/验收/安装完成）判断是否恰当
- [ ] 【条件检查：若为建造/服务合同】履约进度的估计和更新是否有依据
- [ ] 【风险检查】是否存在通过时段/时点判断操纵收入确认节奏

### 三、总额法与净额法应用（高风险）

- [ ] 【必检】总额法/净额法的选择是否基于是否控制商品的判断
- [ ] 【必检】总额法下是否确实承担了主要责任、存货风险、定价权
- [ ] 【必检】净额法下是否仅赚取佣金/手续费性质的差额
- [ ] 【条件检查：若为平台/贸易/电商业务】主要责任人vs代理人判断是否审慎
- [ ] 【风险检查】是否存在为虚增收入规模而不当采用总额法

### 四、可变对价与政策一致性（中风险）

- [ ] 【必检】折扣、返利、退货等可变对价的估计方法是否合理
- [ ] 【必检】可变对价是否受"极可能不发生重大转回"限制
- [ ] 【必检】质保金/尾款的收入确认是否恰当
- [ ] 【条件检查：若有分期收款超一年】是否评估重大融资成分
- [ ] 【必检】收入政策是否与上期一致，变更是否有充分理由并追溯
- [ ] 【风险检查】可变对价估计是否被用于调节收入

## risk_areas

### 高风险

1. **五步法应用错误**：合同识别、履约义务拆分、交易价格分摊或确认时点判断系统性错误，导致所有相关收入确认失当。
2. **时段/时点判断错误**：将时点履约误判为时段履约（提前确认）或反之，系统性错报收入确认时点。
3. **总额法虚增收入规模**：作为代理人却采用总额法确认收入，虚增营业收入规模误导报表使用者对经营规模的判断。
4. **主要责任人识别错误**：贸易/平台/电商业务未审慎评估是否控制商品，身份识别错误导致收入规模系统性失真。
5. **收入政策变更操纵利润**：无充分理由变更收入确认政策以调节各期利润，未追溯调整或披露。

### 中风险

1. **可变对价估计不当**：折扣、返利、退货估计过于乐观未受"极可能不重大转回"限制，虚增收入。
2. **重大融资成分未识别**：长期分期收款未拆分融资成分，收入与利息收益混淆。
3. **多重履约义务分摊不合理**：捆绑销售价格分摊未按单独售价比例，扭曲各义务收入确认。
4. **履约进度计量方法不一致**：时段法下进度计量方法在不同合同或期间不一致，影响可比性。
5. **政策与行业惯例背离**：收入确认政策明显偏离行业通行做法且无合理解释。

### 低风险

1. **政策文档不完整**：收入确认政策文档描述不够详细，未涵盖所有业务类型。
2. **政策表述模板化**：政策描述照搬准则原文，未结合企业实际业务特点。
3. **交叉索引不完整**：政策检查表与合同检查、发生测试底稿的交叉引用不全。
4. **新业务政策滞后**：新增业务类型的收入政策未及时补充制定。
