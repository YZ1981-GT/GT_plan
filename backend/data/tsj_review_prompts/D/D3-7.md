# D3-7 凭证检查复核提示词

## 适用底稿
预收账款/合同负债凭证检查表（D3-7），聚焦样本选取方法合理性、收款凭证与合同核对完整性、收入确认时点准确性、检查比例达标性、异常交易标注充分性。

## tips

- 样本选取方法应与风险评估结果匹配，高风险领域（长期挂账/关联方/期末突增）采用更严格的抽样策略
- 凭证核对须覆盖完整链条（合同→收款→合同负债确认→履约→收入结转）
- 收款凭证须与销售合同核对，验证预收金额、收款方、合同条款一致性
- 收入确认时点须核查履约义务履行时点，警惕提前或延迟确认收入
- 检查比例应满足《中国注册会计师审计准则第1314号——审计抽样》要求
- 异常交易标注需明确异常类型（金额异常/时间异常/对手方异常/履约逻辑异常）
- 关注期末集中收款、大额现金预收、关联方预收、长期挂账等高风险凭证
- 职业怀疑贯穿始终：对预收款真实性和收入确认时点保持警觉，记录质疑过程

## checklist

### 高风险检查项

- [ ] 样本选取方法是否与识别的重大错报风险相匹配
- [ ] 抽样方法是否符合CAS1314要求（统计抽样/非统计抽样选择有据）
- [ ] 金额重大项目（超过重要性水平）是否100%全覆盖检查
- [ ] 高风险预收（长期挂账/关联方/大额期末收款）是否纳入必选样本
- [ ] 收款凭证是否与销售合同核对（金额/收款方/合同条款一致）
- [ ] 预收款对应的合同是否真实存在，合同标的是否明确
- [ ] 收入确认时点是否与履约义务履行时点一致
- [ ] 是否存在提前确认收入（合同负债结转过早）的情况
- [ ] 是否存在延迟确认收入（已履约仍挂账）的情况
- [ ] 期末突增的合同负债对应凭证是否重点核查
- [ ] 是否存在无实际业务支持的预收款项凭证

### 中风险检查项

- [ ] 抽样总体是否完整（是否排除了不应排除的项目）
- [ ] 样本量是否满足审计目标所需的置信水平
- [ ] 分层抽样的分层标准是否合理（按金额/客户类型/账龄）
- [ ] 检查比例（已检查金额/总体金额）是否达到计划水平
- [ ] 贷方发生额检查比例是否达标（本期新增预收）
- [ ] 借方发生额检查比例是否达标（本期结转收入/退款）
- [ ] 含税预收款的拆分（合同负债/待转销项税额）是否正确
- [ ] 收款凭证日期与记账日期是否一致，是否存在跨期记录
- [ ] 退款凭证是否有合理依据和授权审批
- [ ] 核对过程中发现的差异是否逐一追踪解决

### 低风险检查项

- [ ] 抽样工作底稿是否完整记录抽样参数（总体/置信水平/可容忍偏差/预计偏差）
- [ ] 样本选取过程是否可追溯（随机数种子/系统抽样间隔/选取依据）
- [ ] 凭证检查结果记录格式是否规范统一
- [ ] 检查比例计算公式是否正确（分子=已检查金额，分母=总体金额）
- [ ] 底稿索引与交叉引用是否完整（关联审定表/明细表/收入底稿）

## risk_areas

### 高风险

- **收入确认时点操纵风险**：合同负债结转收入的时点与履约义务履行时点不一致，提前或延迟确认收入以调节利润
- **虚假预收风险**：以合同负债名义挂账无真实合同支持的资金，掩盖资金占用或虚构交易，需交叉核对合同与收款凭证
- **截止性错误风险**：期末集中收款的预收款未实施截止测试，跨期交易未被识别和标注
- **关联方交易隐匿风险**：关联方预收凭证混入普通客户样本，未实施针对性的商业实质核查
- **异常交易遗漏风险**：金额异常（整数金额/恰好低于审批权限）、时间异常（期末最后几天集中入账）的预收未被标注

### 中风险

- **检查比例不足风险**：实际检查比例低于计划水平，导致审计证据不充分，无法支持审计结论
- **含税拆分错误风险**：含增值税预收款的合同负债与待转销项税额拆分不正确
- **分层不合理风险**：抽样分层标准未体现风险差异，长期挂账/关联方等高风险层覆盖不足
- **核对深度不够风险**：仅核对金额一致性而忽略合同条款、履约进度是否匹配

### 低风险

- **记录不完整风险**：抽样参数/选取过程/核对结果的工作底稿记录不完整，影响复核可追溯性
- **索引缺失风险**：凭证检查底稿与审定表/明细表/收入底稿的交叉索引不完整
- **格式不规范风险**：检查结果记录格式不统一，影响汇总分析效率

## 法规依据

- 《中国注册会计师审计准则第1314号——审计抽样》：抽样设计、执行与评价
- 《中国注册会计师审计准则第1301号——审计证据》：证据充分性与适当性
- 《中国注册会计师审计准则第1141号——财务报表审计中与舞弊相关的责任》：舞弊风险凭证核查
- 《企业会计准则第14号——收入》：合同负债确认与收入结转时点
- 《中国注册会计师审计准则第1211号——通过了解被审计单位及其环境识别和评估重大错报风险》：风险导向抽样

## 关注场景

### 样本选取方法合理性
1. 确认抽样方法选择依据（统计抽样适用于大量同质预收交易；非统计抽样适用于异质性高/项目少的场景）
2. 核实必选样本是否涵盖：金额超重要性水平项目、高风险预收（长期挂账/关联方/大额期末收款）、期末异常变动项目
3. 验证MUS/系统抽样的间隔计算：间隔 = 可容忍错报 ÷ 风险系数（查泊松表）
4. 检查总体完整性：是否从完整的合同负债明细账/序时账导出，未人为排除项目

### 收款凭证与合同核对完整性
1. 核对链条：销售合同（签订日期/标的/金额/条款）→ 收款凭证（收款日期/金额/收款方）→ 合同负债确认（记账日期/分录）→ 履约（发货/服务/验收）→ 收入结转（结转日期/金额）
2. 异常核对结果分类：金额不一致/合同缺失/收款方与合同方不符/无履约义务约定/含税拆分错误
3. 合同真实性核查：合同标的是否明确、合同方是否真实存在、合同条款是否具备商业实质

### 收入确认时点准确性
1. 履约义务履行时点判断：核查发货单/验收单/服务完成记录，验证收入结转时点与履约时点一致
2. 提前确认识别：合同负债在履约完成前即结转收入
3. 延迟确认识别：履约已完成但合同负债仍长期挂账未结转
4. 跨期核查：资产负债表日前后的收款和收入结转，验证是否存在跨期操纵

### 异常交易标注充分性
1. 金额异常判断标准：整数金额/恰好低于审批权限/与历史交易偏差超30%/单笔超重要性水平
2. 时间异常判断标准：期末最后几天集中收款/节假日交易/基准日前后异常波动
3. 对手方异常判断标准：关联方大额预收/新客户首笔大额/多个客户同一联系方式或银行账户
4. 履约逻辑异常：收款后长期无履约/退款比例异常/长期挂账不结转不退回
5. 标注要素：异常类型 + 异常描述 + 涉及金额 + 初步判断（合理解释/需进一步调查/疑似错报）
