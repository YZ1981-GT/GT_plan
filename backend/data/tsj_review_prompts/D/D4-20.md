# D4-20 销售退回检查表复核提示词

## 概述

本提示词针对营业收入销售退回检查表（D4-20）的复核，聚焦销售退回的真实性、期后退回情况、预计退回负债的合理性（附退货条款的销售在CAS14下须估计预期退货并作可变对价处理）、以及退回冲减收入的准确性。销售退回尤其是期末大额销售的期后集中退回，是识别虚增收入舞弊的关键切入点。

**法规依据：**
- 《企业会计准则第14号——收入》（附退货条款的销售、预期退货负债与应收退货成本）
- 《中国注册会计师审计准则第1141号——财务报表审计中与舞弊相关的责任》
- 《中国注册会计师审计准则第1301号——审计证据》
- 《中国注册会计师审计准则第1332号——期后事项》

## tips

1. **附退货条款销售须在CAS14下估计预期退货**：对可退货销售，应按预期不会退回的金额确认收入，同时确认预计负债（应退款）和应收退货成本，而非简单在实际退货时冲减。
2. **期后退回是识别虚增收入的利器**：资产负债表日后短期内集中发生的大额退回，往往对应期末为冲业绩的虚假销售，须逐笔追查退回原因与原始销售真实性（CAS1141）。
3. **退回真实性须核对完整退货链条**：退货申请、退货审批、退货入库单、红字发票、退款记录须相互印证，警惕无实物入库的虚假退回或有实物但未冲减收入的隐匿退回。
4. **预计退货负债的估计须有历史数据支撑**：预期退货率应基于历史退货数据、行业惯例和当期具体情况合理估计，退货率显著偏低可能低估负债、虚增收入。
5. **退回冲减的会计期间归属**：期末前的退回是否已冲减本期收入、期后退回是否作为调整事项处理，须结合CAS1332期后事项准则评估。
6. **退回与折让、坏账须区分处理**：真实退货（货物退回）、销售折让（价格减让）、坏账核销（款项无法收回）会计处理不同，须防止混淆或以退货名义掩盖坏账。

## checklist

### 一、退回真实性核查

- [ ] 每笔销售退回是否有完整退货链条（退货申请/审批/入库单/红字发票/退款）
- [ ] 退回货物是否有实物入库记录，与退货数量一致
- [ ] 退回对应的原始销售交易是否真实且可追溯
- [ ] 退回原因是否合理（质量问题/规格不符/滞销/其他）并有依据
- [ ] 退货审批是否经过恰当授权
- [ ] 是否存在无实物入库的虚假退回或未冲减收入的隐匿退回

### 二、期后退回核查

- [ ] 是否获取资产负债表日后至审计报告日的退货记录
- [ ] 期后集中退回的大额交易是否逐笔追查原始销售真实性
- [ ] 期末最后期间确认的销售是否在期后发生异常退回
- [ ] 期后退回是否评估对本期收入确认的影响（是否属虚假销售）
- [ ] 期后退回是否按CAS1332评估是否属资产负债表日后调整事项
- [ ] 特定客户是否存在"期末销售、期后退回"的循环交易模式

### 三、预计退货负债合理性

- [ ] 附退货条款的销售是否识别并按CAS14估计预期退货
- [ ] 预期退货率的估计是否有历史退货数据支撑
- [ ] 预计负债（应退款）和应收退货成本是否正确确认
- [ ] 退货率估计是否结合当期具体情况（新品/促销/行业变化）调整
- [ ] 预期退货率是否显著偏低导致低估负债、虚增收入
- [ ] 期末预计退货负债余额是否合理并与历史实际退货趋势一致

### 四、退回冲减准确性

- [ ] 销售退回是否正确冲减营业收入（数量×单价）
- [ ] 退回的增值税是否通过红字发票正确冲减销项税
- [ ] 退回对应的销售成本是否同步冲减（收入成本配比）
- [ ] 退回的会计期间归属是否正确（本期退回冲减本期）
- [ ] 退回金额是否与D4收入明细、审定表勾稽
- [ ] 退回是否与销售折让、坏账核销正确区分处理

## risk_areas

### 高风险

1. **期末虚假销售期后退回**：为达成业绩目标在期末虚构或提前确认销售，次年初集中退回，属典型虚增收入舞弊，须通过期后退回逆向识别（CAS1141）。
2. **预期退货低估虚增收入**：附退货条款销售的预期退货率估计显著偏低，少提预计负债、多确认收入，虚增本期业绩。
3. **隐匿退回不冲减收入**：实物已退回入库但未冲减收入，虚增期末收入和应收账款。
4. **以退货掩盖坏账**：将无法收回的应收款项以销售退回名义处理，掩盖坏账损失和收入质量问题。

### 中风险

1. **退回真实性证据不足**：退货缺少实物入库单/红字发票等完整链条证据，真实性存疑。
2. **退回期间归属错误**：本期退回未冲减本期收入或期后退回未按CAS1332评估调整事项。
3. **收入成本冲减不同步**：退回仅冲减收入未同步冲减成本，或反之，导致毛利扭曲。
4. **预计退货负债无数据支撑**：预期退货率估计缺乏历史数据基础，随意性大。

### 低风险

1. **退货政策文档不完整**：退货政策及审批权限未形成完整书面制度。
2. **底稿记录不充分**：退回检查过程、期后退回获取范围、样本选取记录不完整。
3. **交叉索引缺失**：退回检查底稿与收入明细、存货、期后事项底稿的交叉引用不完整。
