# D4-4 调整分录汇总表复核提示词

## 适用底稿
营业收入调整分录汇总表（D4-4），含账项调整（AJE）、重分类调整（RJE）及未调整错报（SUD）评估。

## 概述
D4-4 是营业收入审定数链路的关键环节。复核须验证：每笔收入调整有证据、借贷平衡、完整反映到 D4-1 审定表、SUD 评估符合重要性水平要求。收入调整常涉及虚增收入冲回、跨期截止调整、总额/净额法重分类，属高舞弊敏感区域。

**法规依据：**
- 《企业会计准则第14号——收入》
- 《企业会计准则第28号——会计政策、会计估计变更和差错更正》
- 《中国注册会计师审计准则第1301号——审计证据》
- 《中国注册会计师审计准则第1141号——财务报表审计中与舞弊相关的责任》

## tips

1. **AJE vs RJE 的收入语义**：AJE 影响营业收入金额（虚增冲回、跨期调整）；RJE 仅影响列报（主营↔其他业务重分类、总额↔净额法），不得通过 RJE 掩盖收入金额错报。
2. **与 D4-1 勾稽**：审定表调整列金额须与 D4-4 已确认分录逐笔一致，遗漏任一笔即审定数失真，尤其虚增收入冲回和跨期截止调整。
3. **审批链**：超过明细层次重要性水平的收入调整须合伙人/项目经理审批留痕，收入舞弊敏感调整须合伙人知悉。
4. **SUD 累计**：未调整收入错报单独及累计是否超过整体/明显微小错报阈值，须与 A13 未调整错报汇总交叉验证，注意收入错报对利润的直接影响。
5. **跨期调整**：区分本期收入截止错报与前期差错更正，会计处理与披露要求不同，跨期收入调整需与截止测试结论一致。
6. **TB 回写**：确认收入调整已同步试算平衡表 6001/6051 科目，避免「底稿已调、TB 未更」双真源。

## checklist

### 高风险检查项

- [ ] 所有收入 AJE 是否有充分审计证据（截止测试差异、抽样错报、函证差异、管理层确认等）
- [ ] 虚增收入冲回调整是否完整反映到 D4-1 审定表
- [ ] 跨期收入截止调整是否与截止测试（D4-14/D4-15/D4-16）结论一致
- [ ] 收入 AJE 是否经适当层级审批（超重要性水平须合伙人知悉）
- [ ] 每笔调整分录借贷方是否完全平衡
- [ ] 调整金额是否完整反映到 D4-1 审定表对应调整列
- [ ] 是否存在仅为达成收入目标或规避 covenant 的不当收入调整
- [ ] 未调整收入错报累计是否超过整体重要性水平且仍出具无保留意见（须评估）
- [ ] 跨期调整是否正确区分本期收入截止/前期差错更正

### 中风险检查项

- [ ] RJE 是否仅涉及列报（主营↔其他业务/总额↔净额），未影响收入总额
- [ ] 总额法/净额法重分类调整是否基于主要责任人vs代理人正确判断
- [ ] 调整原因说明是否清晰可追溯至具体审计程序
- [ ] 调整分录编号是否连续，删除后重号风险可控
- [ ] 与 A13 未调整错报汇总表索引是否完整
- [ ] 建议调整与已执行调整是否区分记录

### 低风险检查项

- [ ] 分录摘要、科目编码规范（6001/6051区分）
- [ ] 索引指向 D4-12 合同检查、D4-14 发生测试、函证回函等支持底稿
- [ ] 审计说明/结论是否概括调整性质与 residual 风险

## risk_areas

### 高风险

1. **收入调整缺乏证据或未经授权**：虚增收入冲回、跨期调整无充分证据支持，或未经合伙人批准即纳入审定表。
2. **审定表与 D4-4 收入调整金额不一致**：已确认收入调整未完整反映在审定表，导致审定数失真。
3. **跨期截止调整与截止测试矛盾**：D4-4 跨期调整与 D4-14/D4-15 截止测试结论不一致，反映底稿间勾稽断裂。
4. **SUD 累计超阈值未恰当处理**：未调整收入错报累计超过整体重要性水平，未评估对审计意见的影响。
5. **为达成收入目标的不当调整**：为满足业绩承诺/上市要求/借款条件人为调整收入。

### 中风险

1. **RJE 误含收入金额影响**：本应仅列报重分类的 RJE 实际影响了收入总额。
2. **总额/净额法重分类判断错误**：主要责任人与代理人身份判断错误导致重分类方向错误。
3. **跨期调整分类错误**：本期收入截止错报与前期差错更正混淆。

### 低风险

1. **编号、格式不规范**：调整分录编号、科目编码、摘要格式问题。

## 跨底稿勾稽

- D4-4 已确认 AJE/RJE 合计 ↔ D4-1 审定表调整列
- D4-4 跨期截止调整 ↔ D4-14/D4-15/D4-16 截止测试结论
- D4-4 SUD ↔ A13 未调整错报汇总
- 调整后审定数 ↔ 试算平衡表 6001/6051 科目发生额
