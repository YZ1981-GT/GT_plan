# D4-30 客户访谈汇总表复核提示词

## 概述

本提示词针对营业收入客户访谈汇总表（D4-30）的复核，聚焦访谈客户的汇总、交易确认情况、访谈发现的异常。客户访谈汇总表汇集对各客户实地/远程访谈的核心结果，是评估收入真实性的重要证据集合。复核须确认访谈客户选取覆盖高风险领域、交易金额得到客户确认、访谈发现的异常（否认交易/金额不符/身份存疑）得到充分调查和评估。

**法规依据：**
- 《企业会计准则第14号——收入》
- 《中国注册会计师审计准则第1141号——财务报表审计中与舞弊相关的责任》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **访谈汇总是收入真实性的综合证据集**：汇总表须完整反映每个访谈客户的交易确认结果、访谈方式、访谈对象职务、发现异常，是评估收入整体真实性的关键依据。
2. **访谈客户选取须覆盖高风险领域**：访谈对象应重点覆盖大额、新增、关联、函证异常、第三方回款等高风险客户，确保访谈针对重大错报风险。
3. **交易确认须由客户有权人员做出**：访谈对象应为熟悉交易的客户方有权人员（采购负责人/财务负责人），确认内容应涵盖交易存在、金额、货物接收、款项支付，避免访谈对象无关或无权。
4. **访谈异常是舞弊识别的关键信号**：客户否认交易、确认金额与账面不符、无法说明交易细节、访谈对象身份存疑等异常，是虚构收入的直接信号，须逐项深入调查（CAS1141）。
5. **访谈真实性与佐证**：汇总表须能追溯至D4-31访谈明细及佐证材料（录音/影像/签字/访谈记录），警惕访谈流于形式或访谈记录被伪造。
6. **访谈结果须与其他程序综合印证**：访谈确认结果须与函证、截止测试、发票比对、资金流核查等综合判断，孤立的访谈确认不足以支持收入真实性结论。

## checklist

### 一、访谈客户选取

- [ ] 访谈客户是否覆盖大额、高风险客户
- [ ] 新增、关联、函证异常、第三方回款客户是否纳入访谈
- [ ] 访谈客户对收入的金额覆盖率是否合理
- [ ] 访谈客户选取依据是否记录
- [ ] 是否覆盖主营业务与其他业务客户
- [ ] 访谈样本是否与函证走访清单协同（避免重复或遗漏）

### 二、交易确认情况

- [ ] 每个访谈客户的交易确认结果是否记录（确认/部分确认/否认）
- [ ] 确认内容是否涵盖交易存在、金额、货物接收、款项支付
- [ ] 访谈对象是否为客户方有权/熟悉交易人员
- [ ] 确认金额是否与账面记录一致
- [ ] 部分确认/金额不符情况是否说明差异
- [ ] 访谈方式（实地/电话/视频）是否记录且适当

### 三、异常发现与调查

- [ ] 客户否认交易的情况是否逐项深入调查
- [ ] 确认金额与账面不符的差异是否查清
- [ ] 访谈对象无法说明交易细节的情况是否记录并评估
- [ ] 访谈对象身份存疑的情况是否进一步核实
- [ ] 异常发现是否评估对收入真实性的影响
- [ ] 重大异常是否评估管理层诚信及舞弊风险（CAS1141）

### 四、佐证与综合印证

- [ ] 访谈汇总是否可追溯至D4-31访谈明细
- [ ] 访谈是否留存佐证（录音/影像/签字/记录）
- [ ] 访谈佐证是否充分支持访谈结果的真实性
- [ ] 访谈结果是否与函证、截止测试、发票比对综合印证
- [ ] 汇总结论是否明确（收入真实/部分存疑/存在虚构需调整）
- [ ] 底稿是否记录访谈方法、覆盖率及交叉索引

## risk_areas

### 高风险

1. **客户否认交易**：访谈中客户否认交易存在或否认交易金额，直接指向虚构收入，须评估对收入及管理层诚信的重大影响（CAS1141）。
2. **访谈对象无权或身份存疑**：访谈对象非客户方有权人员或身份无法核实，确认结果无效，可能被安排应付访谈。
3. **访谈记录造假**：访谈汇总缺乏真实佐证或佐证被伪造，访谈流于形式，无法支持收入真实性。
4. **高风险客户未访谈**：大额、关联、异常客户未纳入访谈，访谈未覆盖重大错报风险领域。

### 中风险

1. **确认金额差异未查清**：访谈确认金额与账面不符但差异未调查解释。
2. **确认内容不完整**：访谈确认仅涉及交易存在未涵盖金额/货物/款项，确认深度不足。
3. **访谈与其他程序未印证**：访谈结果与函证/截止/资金流未综合印证，结论孤立。
4. **访谈覆盖率不足**：访谈客户金额覆盖率偏低，代表性不足。

### 低风险

1. **汇总记录不完整**：访谈客户、确认结果、异常发现记录不完整。
2. **佐证留存不规范**：访谈佐证格式不统一或不够充分。
3. **交叉索引缺失**：与访谈明细、函证走访清单、收入明细的交叉引用不完整。
