# D1-note-soe 附注披露复核提示词（国有企业）

## 概述

本提示词针对应收票据国有企业附注披露底稿（D1-note-soe）的复核，在满足 CAS37/CAS23 通用披露（分类/已背书贴现未到期/质押/减值变动）基础上，聚焦国有企业特定披露要求：国有资产监管相关披露、关联交易（含同受国有控制单位的票据往来）、票据核销的"三重一大"决策披露、资金占用性票据披露。国有企业审计具有财务审计+国有资产监管双重属性，附注披露须同时满足会计准则和国资监管要求。

**法规依据：**
- 《企业会计准则第37号——金融工具列报》
- 《企业会计准则第23号——金融资产转移》
- 《企业会计准则第36号——关联方披露》
- 《企业国有资产法》
- 《中央企业财务决算报告管理办法》

---

## tips

1. **国有企业附注有"双层"披露要求**：既满足 CAS37/CAS23 通用要求（分类/背书贴现未到期/质押/减值），又满足国资委财务决算报告的额外披露要求，两套要求互为补充。
2. **关联方范围更广**：除一般关联方外，须考虑同一国有控股股东控制的其他国有企业（"同受国有控制"），关联方票据往来须完整识别，但可按准则豁免条款简化部分披露。
3. **票据核销须披露"三重一大"决策**：重大应收票据核销须经"三重一大"集体决策，附注须披露核销的决策过程、审批情况和责任追究。
4. **资金占用性票据是国企监管重点**：以票据往来形式的非经营性资金占用（尤其被其他国企或关联方占用）须单独披露，防范国有资产流失。
5. **无真实贸易背景票据须披露实质**：关联方对开、循环背书的融资性票据须按经济实质披露，不得以票据形式掩盖资金拆借。
6. **附注须与审定表/明细/背书贴现/质押/核销底稿闭环勾稽**：与上市版共有的基础勾稽要求相同，另需与国资决算报表数据一致。

## checklist

### 一、基础披露完整性（与上市版共有）

- [ ] 应收票据是否按银行承兑汇票/商业承兑汇票分类披露
- [ ] 已背书/贴现但未到期票据的终止确认/未终止确认金额是否披露
- [ ] 已质押票据是否单独披露账面金额及担保债务
- [ ] 坏账/减值准备变动表是否完整（期初/计提/转回/核销/期末）
- [ ] 附注应收票据总额是否与审定表审定数一致
- [ ] 期初/期末可比信息是否完整

### 二、国有资产监管相关披露

- [ ] 长期未兑付的商业承兑汇票是否单独披露金额、承兑人及原因
- [ ] 是否披露以票据形式被其他国企/关联方占用的资金
- [ ] 大额应收票据（超单户限额标准）是否按国资委要求逐户披露
- [ ] 应收票据减值损失对国有资本保值增值率的影响是否说明
- [ ] 是否披露涉及国有资产处置/划转的票据事项

### 三、关联交易披露（国企特定）

- [ ] 与控股股东及其关联企业的应收票据是否逐户列示
- [ ] 与同一母公司控制的其他国有企业的应收票据是否披露
- [ ] "同受国家控制"关联方豁免条款是否符合条件适用
- [ ] 关联方对开/无贸易背景票据的交易实质是否披露
- [ ] 是否存在以票据名义的资金拆借并说明

### 四、核销与决策披露

- [ ] 本期核销的应收票据是否逐笔披露（金额/承兑人/原因/审批）
- [ ] 重大核销是否经"三重一大"决策程序并披露
- [ ] 核销是否启动责任追究程序并披露
- [ ] 涉诉/仲裁票据的金额及进展是否披露

### 五、决算报表特殊要求

- [ ] 应收票据数据是否与年度财务决算报表一致
- [ ] 属于"不良资产"的票据是否按决算要求单独披露
- [ ] 集团合并层面内部票据往来抵销是否完整
- [ ] 应收票据损失是否纳入经营业绩考核相关披露

## risk_areas

### 高风险

1. **资金占用性票据未披露**：以票据往来隐匿其他国企/关联方非经营性资金占用，未识别未披露，可能被认定为国有资产流失。
2. **已背书/贴现未到期票据未披露**：CAS23/CAS37 强制披露项遗漏。
3. **核销缺少"三重一大"程序**：重大票据核销未经集体决策或未披露决策过程，合规风险。
4. **关联方票据范围遗漏**：同受国有控制单位的票据往来未纳入关联方披露。
5. **附注与审定表/决算不勾稽**：附注数据与审定数或决算报表不一致。

### 中风险

1. **无贸易背景票据实质未披露**：关联方对开融资性票据未按实质披露。
2. **豁免条款适用不当**：不符合条件却简化同受国有控制关联方披露。
3. **核销责任追究缺失**：大额核销未说明责任追究程序。
4. **决算与审计口径差异未调节**：决算数据与审计后附注差异未编制调节说明。

### 低风险

1. **披露格式未按决算模板**：附注格式与国资委决算模板有细微差异。
2. **资金占用利息说明简略**：占用利息计算依据未详细说明。
3. **历史趋势追溯不完整**：票据增减变动历史趋势分析覆盖年度不足。
