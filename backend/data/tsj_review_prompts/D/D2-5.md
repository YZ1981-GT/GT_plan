# D2-5 应收账款分析表复核提示词

## 适用底稿
分析表D2-5（应收账款分析程序底稿）

## 审计目标
通过分析程序识别应收账款的异常变动、验证周转效率的合理性、评估账龄结构变化趋势，发现可能存在的重大错报风险。

## tips

- 应收账款周转率 = 营业收入 / 应收账款平均余额，需确认分子分母口径一致（含税vs不含税）
- 变动分析须区分业务增长驱动与信用政策放宽导致的余额增长
- 账龄结构恶化（长账龄占比上升）即使总余额下降也应重点关注
- 前后期对比基数须一致：同期、同口径、同范围（合并范围变化需剔除）
- 异常波动阈值参考：单客户变动超30%、整体周转率变动超20%、账龄结构迁移率偏离历史均值超15%
- 分析程序发现的异常须形成闭环：识别→调查→获取解释→评价合理性→结论
- 行业对标数据应取同行业、同规模、同区域可比公司，来源须可靠（年报/行业报告）
- 季节性行业（如农业、零售）的周转率分析须按季度拆分，避免全年均值掩盖异常

## checklist

### 高风险

- [ ] 应收账款周转率计算是否准确（公式=营业收入÷应收账款平均余额，确认期初期末余额取数正确）
- [ ] 周转率与上期对比是否合理，变动超过20%是否有充分解释
- [ ] 周转天数（365÷周转率）与信用政策授予的平均账期是否匹配
- [ ] 应收账款余额变动率与营业收入变动率是否匹配（差异超过15%须解释）
- [ ] 前五大客户应收账款余额变动是否逐户分析原因
- [ ] 账龄结构变动是否合理：1年以上占比较上期是否显著上升
- [ ] 迁徙率（各账龄段向下一段迁移比例）是否与历史趋势一致
- [ ] 分析程序发现的异常波动是否全部得到调查和解释
- [ ] 异常解释是否有充分审计证据支持（非仅管理层口头说明）
- [ ] 期末突增的应收账款（尤其最后一个月）是否结合截止测试分析

### 中风险

- [ ] 应收账款占流动资产比例变动是否与经营模式变化一致
- [ ] 应收账款增长率与同行业可比公司是否存在显著偏离
- [ ] 坏账准备计提比例与实际核销率的历史对比是否合理
- [ ] 应收账款与预收款项的联动分析是否执行（一增一减是否合理）
- [ ] 客户集中度变动分析是否充分（前五大客户占比变化）
- [ ] 不同业务板块/产品线的应收账款变动是否分别分析
- [ ] 信用政策变更对应收账款周转率的影响是否量化评估
- [ ] 账龄分析中"重新计龄"（老账清零后重新挂账）现象是否识别并排除
- [ ] 期后回款分析是否与账龄分析结论一致（长账龄是否确实难回收）

### 低风险

- [ ] 分析表格式是否规范，数据来源是否标注清楚
- [ ] 同比/环比分析的基期数据是否经核实与上年审定数一致
- [ ] 图表（如趋势图、结构图）是否正确反映底层数据
- [ ] 分析程序的结论是否明确记录，与审计总体结论是否衔接
- [ ] 行业对标数据来源是否注明，是否为最新可获取数据

## risk_areas

### 高风险
- 应收账款周转率显著下降但管理层未能提供合理解释——可能存在虚构收入或信用政策失控
- 期末应收账款余额突增（尤其12月单月增幅超全年均值2倍）——提前确认收入或虚构销售的舞弊信号
- 账龄结构急剧恶化（1年以上占比上升超5个百分点）——坏账准备计提可能严重不足
- 迁徙率异常（某账龄段迁移率突然降低）——可能存在人为调整账龄的操纵行为
- 前后期对比数据口径不一致（合并范围变化、会计政策变更未调整可比数据）——分析结论可能误导

### 中风险
- 应收账款增长率持续高于营业收入增长率——信用政策可能过度放宽或回款能力下降
- 周转率与同行业差异显著（偏离行业均值30%以上）——需评估是否为行业特性或异常信号
- 客户集中度显著上升——大客户依赖度增加，单一客户风险敞口扩大
- 坏账准备计提比例与历史实际核销率长期偏离——计提政策可能不够审慎

### 低风险
- 分析表数据引用格式不规范（未标注数据来源底稿及单元格位置）
- 行业对标数据过于陈旧（超过2年）或可比性存疑
- 分析结论描述笼统，未具体到金额和客户
