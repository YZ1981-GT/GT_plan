# D4-7 月度毛利分析表复核提示词

## 概述

本提示词针对月度毛利分析表（D4-7）的复核，聚焦四大核心审计要点：分月收入成本毛利勾稽、月度毛利率波动合理性、异常月份识别、期末月份截止关注。月度毛利分析是通过时间维度分解收入与成本的配比关系，识别毛利率异常波动的月份，是发现跨期错报、成本配比错误、期末冲刺式收入的有效分析工具。

**法规依据：**
- 《企业会计准则第14号——收入》
- 《中国注册会计师审计准则第1301号——审计证据》
- 《中国注册会计师审计准则第1231号——针对评估的重大错报风险采取的应对措施》
- 《中国注册会计师审计准则第1313号——分析程序》

---

## tips

1. **月度收入成本毛利须逐月勾稽**：每月毛利 = 每月收入 − 每月成本，各月合计须等于全年收入、成本、毛利，逐月分解可暴露被年度汇总掩盖的异常月份。
2. **月度毛利率波动揭示配比与截止问题**：正常经营下月度毛利率应相对稳定，某月毛利率突高（收入无对应成本）或突低（成本超前）是跨期错报或配比错误的信号。
3. **期末月份是截止测试的重点靶区**：12月毛利异常（收入放量但成本未同步/毛利率突变）需结合截止测试，警惕期末冲刺式收入和成本跨期。
4. **收入成本的期间配比是核心验证**：某月收入激增但成本未同步增长，或成本入账滞后于收入，均违反配比原则，需追溯凭证核实期间归属。
5. **月度分析须结合季节性特征**：不同行业有其季节性规律，月度毛利波动应与行业季节特征匹配，异常偏离季节规律需追溯原因。
6. **勾稽关系**：Σ各月收入 = 全年主营业务收入（D4-2）；Σ各月成本 = 全年营业成本；各月毛利率与综合毛利率（D4-6）应可对账，任一断裂为复核重点。

## checklist

### 一、分月收入成本毛利勾稽（高风险）

- [ ] 【必检】各月收入、成本、毛利数据是否完整列示
- [ ] 【必检】各月毛利是否等于当月收入减当月成本
- [ ] 【必检】各月收入合计是否等于全年主营业务收入（D4-2）
- [ ] 【必检】各月成本合计是否等于全年营业成本
- [ ] 【必检】各月毛利率是否正确计算（毛利/收入）
- [ ] 【条件检查：若有合并数据】各子公司/分部月度数据是否完整汇总
- [ ] 【风险检查】是否存在某月收入无对应成本记录

### 二、月度毛利率波动分析（高风险）

- [ ] 【必检】各月毛利率是否列示并对比波动
- [ ] 【必检】月度毛利率标准差/波动幅度是否在合理范围
- [ ] 【必检】毛利率突高/突低月份是否标注并说明原因
- [ ] 【条件检查：若某月毛利率异常】异常月份的收入成本是否追溯核实
- [ ] 【风险检查】是否存在某月毛利率虚高（收入虚增无成本）
- [ ] 【风险检查】是否存在通过调整月度成本分配平滑毛利率

### 三、异常月份识别与追溯（中风险）

- [ ] 【必检】收入或成本异常波动的月份是否识别标注
- [ ] 【必检】异常月份是否与业务事件（大订单/停产/促销）对应
- [ ] 【条件检查：若有异常月份】异常月份的凭证是否抽查核实
- [ ] 【风险检查】异常波动是否存在合理商业解释
- [ ] 【风险检查】是否存在人为在特定月份集中确认收入

### 四、期末月份截止关注（高风险）

- [ ] 【必检】12月毛利率是否与其他月份对比无异常
- [ ] 【必检】期末月份收入是否存在异常放量
- [ ] 【必检】期末月份成本是否与收入同步入账
- [ ] 【条件检查：若期末放量】期末大额收入是否实施截止测试（勾稽D4-14）
- [ ] 【条件检查：若次年初回落】是否存在跨期确认迹象
- [ ] 【风险检查】期末月份毛利率突变是否反映跨期错报

## risk_areas

### 高风险

1. **某月收入无对应成本**：特定月份收入大幅增长但成本未同步，毛利率虚高，是虚增收入或成本跨期的核心信号。
2. **期末月份收入异常放量**：12月收入显著高于其他月份且次年初回落，存在期末冲刺式收入和跨期确认风险。
3. **月度毛利率剧烈波动**：月度毛利率大幅波动无合理解释，反映收入成本配比错误或人为调节。
4. **成本入账滞后于收入**：收入已确认但对应成本延迟到后续月份入账，违反配比原则虚增当期毛利。
5. **月度分析未追溯异常**：识别出异常月份但未追溯至具体交易核实，未发挥分析程序作用。

### 中风险

1. **月度分布偏离季节规律**：收入月度分布明显背离行业季节性特征且无合理解释。
2. **成本分配人为平滑**：通过调整月度成本分配方式平滑毛利率，掩盖真实波动。
3. **月度数据汇总不完整**：合并范围内子公司/分部月度数据未完整汇总。
4. **大额订单未分月核实**：跨月大额订单的收入成本分月归属未核实。

### 低风险

1. **数据口径不一致**：月度数据与年度审定数据口径不完全一致。
2. **波动分析不充分**：月度波动仅列示未深入分析。
3. **交叉索引不完整**：与明细表、截止测试、成本底稿的交叉引用不全。
