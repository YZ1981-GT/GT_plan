# D4-24 第三方回款核查表复核提示词

## 概述

本提示词针对营业收入第三方回款核查表（D4-24）的复核，聚焦非合同客户（第三方）代付货款的真实性、是否掩盖资金循环或虚构收入。第三方回款（付款方与销售合同客户不一致）是识别收入舞弊的重要红旗，异常的第三方回款往往对应资金体外循环回流以坐实虚假销售，或掩盖关联方资金占用。复核须穿透资金流验证收入的真实性。

**法规依据：**
- 《企业会计准则第14号——收入》
- 《中国注册会计师审计准则第1141号——财务报表审计中与舞弊相关的责任》
- 《中国注册会计师审计准则第1231号——针对评估的重大错报风险采取的应对措施》
- 《中国注册会计师审计准则第1312号——函证》

## tips

1. **第三方回款是收入舞弊的核心红旗**：付款方与销售合同客户不一致时，须警惕资金体外循环回流坐实虚假销售，或以第三方付款掩盖真实资金来源，属高风险应对重点（CAS1141）。
2. **穿透资金流是核查关键**：须核查回款资金的实际来源，警惕企业将自有资金通过第三方账户回流形成"销售回款"的资金循环，制造收入真实的假象。
3. **第三方付款须有合理商业解释**：正常的第三方代付（如集团统一结算、指定付款方、承兑背书转让）应有书面协议或商业惯例支撑，无依据的第三方回款须重点调查。
4. **回款方与销售方、关联方的关系核查**：第三方付款方是否与被审计单位存在关联关系、是否为员工个人账户、是否多个客户共用同一付款账户，均为异常信号。
5. **第三方回款与函证结合验证**：对第三方回款对应的销售，函证须同时向合同客户和实际付款方发送或核实，验证交易和付款的真实性（CAS1312）。
6. **回款时点与销售确认的匹配性**：第三方回款集中在期末冲业绩、或回款后短期又流出，须结合资金流向和交易实质评估是否为循环交易。

## checklist

### 一、第三方回款识别

- [ ] 是否系统识别付款方与销售合同客户不一致的回款
- [ ] 第三方回款金额、笔数、占总回款比例是否统计列示
- [ ] 大额第三方回款是否全部纳入核查
- [ ] 期末集中的第三方回款是否重点核查
- [ ] 是否识别个人账户回款、多客户共用账户回款等异常
- [ ] 第三方回款对应的销售交易是否可追溯

### 二、真实性与商业实质

- [ ] 第三方付款是否有书面协议/授权/商业惯例支撑
- [ ] 第三方付款方与合同客户的关系是否核实（代付/承兑背书/指定）
- [ ] 第三方付款方是否与被审计单位存在关联关系
- [ ] 回款资金的实际来源是否穿透核查
- [ ] 是否存在自有资金通过第三方回流的资金循环迹象
- [ ] 第三方回款对应销售的货物流是否真实（发货/物流/验收）

### 三、资金循环与舞弊迹象

- [ ] 是否存在回款后短期又流出的异常资金往来
- [ ] 是否存在多笔销售由同一第三方账户回款的集中现象
- [ ] 第三方回款是否与关联方资金占用相关联
- [ ] 是否存在通过第三方回款坐实虚假销售的迹象
- [ ] 期末第三方回款冲业绩后次年是否发生退款/冲回
- [ ] 资金流、货物流、合同流三流是否一致

### 四、函证与结论

- [ ] 第三方回款对应销售是否向合同客户函证验证
- [ ] 必要时是否向实际付款方核实付款真实性
- [ ] 核查结论是否明确（正常代付/异常需进一步调查/存在虚假）
- [ ] 疑似虚假收入是否评估对收入确认的影响并形成调整建议
- [ ] 核查结果是否与收入分析、截止测试交叉印证
- [ ] 底稿是否记录核查方法、资金穿透过程及交叉索引

## risk_areas

### 高风险

1. **资金循环坐实虚假销售**：自有资金通过第三方账户回流形成"销售回款"，制造收入真实假象，属重大收入舞弊（CAS1141）。
2. **第三方回款掩盖关联占用**：以第三方付款掩盖关联方资金占用或利益输送，规避关联交易披露。
3. **个人账户/共用账户回款**：销售回款来自员工个人账户或多客户共用账户，收入及客户真实性严重存疑。
4. **三流不一致**：资金流、货物流、合同流不匹配，交易实质与账面记录背离，虚构交易嫌疑重大。

### 中风险

1. **第三方付款缺乏依据**：第三方代付无书面协议或商业惯例支撑，付款安排合理性存疑。
2. **回款资金来源未穿透**：仅核对到账未穿透资金实际来源，无法排除资金循环。
3. **期末集中第三方回款**：期末集中的第三方回款未充分核查，可能配合冲业绩。
4. **函证未覆盖付款方**：仅向合同客户函证未核实实际付款方，验证不完整。

### 低风险

1. **第三方回款统计不完整**：未系统识别或统计第三方回款情况，核查范围不清。
2. **底稿记录不充分**：资金穿透核查过程、付款方关系核实记录不完整。
3. **交叉索引缺失**：与收入明细、函证、应收账款、关联方底稿的交叉引用不完整。
