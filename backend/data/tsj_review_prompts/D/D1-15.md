# D1-15 预期信用损失(ECL)计算表复核提示词

## 概述

本提示词针对应收票据预期信用损失（ECL）计算表（D1-15）的复核，聚焦四大核心审计要点：ECL 模型方法恰当性、关键参数与假设合理性、三阶段划分与前瞻性调整、计算准确性与勾稽。应收票据减值采用 CAS22 预期信用损失模型，须区分银行承兑汇票（承兑人为银行，违约风险极低）与商业承兑汇票（承兑人为企业，违约风险与应收账款类似），ECL 计算涉及重大会计估计和管理层判断，是审计的关键领域。

**法规依据：**
- 《企业会计准则第22号——金融工具确认和计量》（预期信用损失模型）
- 《企业会计准则第37号——金融工具列报》
- 《中国注册会计师审计准则第1301号——审计证据》
- 《中国注册会计师审计准则第1540号——审计会计估计和相关披露》

## tips

1. **银承与商承的 ECL 须差异化处理**：银行承兑汇票由银行承兑，违约风险极低，损失率通常接近于零；商业承兑汇票违约风险取决于承兑人（出票企业）信用，须比照应收账款方法评估，两者混合计算将高估银承或低估商承损失。
2. **模型方法须与信用风险特征匹配**：一般模型按三阶段（初始/信用风险显著增加/已发生信用减值）计量，通常应收票据信用风险低、期限短，多处于第一阶段（12 个月 ECL）；已逾期或承兑人财务困难的进入第二/三阶段（整个存续期 ECL）。
3. **关键参数须有依据**：违约概率（PD）、违约损失率（LGD）、违约风险敞口（EAD）或损失率的确定须有历史损失数据、承兑人信用评级或外部数据支持，不得凭空设定。
4. **前瞻性信息运用须合理**：ECL 须纳入宏观经济前瞻性调整（如 GDP、行业景气度对承兑人违约的影响），前瞻性因子的选择和权重须有依据，不得为调节利润而随意调整。
5. **信用风险显著增加判断须客观**：承兑人逾期、评级下调、财务恶化等是信用风险显著增加的迹象，判断标准须客观且前后一致，避免延迟进入第二阶段以少提减值。
6. **计算须与审定表和利润表勾稽**：ECL 计算的期末减值准备须与 D1-1 审定表减值/1231 科目、D1-4 坏账准备勾稽，本期计提须与利润表信用减值损失勾稽。

## checklist

### 一、模型方法恰当性

- [ ] 【必检】ECL 模型选择（一般模型/简化模型）是否恰当并符合 CAS22
- [ ] 【必检】银行承兑汇票与商业承兑汇票是否差异化计量
- [ ] 【必检】模型方法是否与会计政策（D1-14）一致
- [ ] 【条件检查：若采用简化模型】简化模型适用条件是否满足
- [ ] 【风险检查】模型是否被人为简化以规避减值计提

### 二、关键参数与假设合理性

- [ ] 【必检】PD/LGD/EAD 或损失率的确定是否有历史数据或外部依据
- [ ] 【必检】承兑人信用评级/财务状况是否作为参数输入依据
- [ ] 【必检】损失率是否与历史实际损失经验相符
- [ ] 【条件检查：若参数较上期变动】参数变动原因是否合理并有依据
- [ ] 【风险检查】关键参数是否偏低以少提减值

### 三、三阶段划分与前瞻性调整

- [ ] 【必检】信用风险显著增加的判断标准是否客观且前后一致
- [ ] 【必检】逾期/承兑人财务困难票据是否恰当进入第二/三阶段
- [ ] 【必检】前瞻性宏观信息是否纳入并有依据
- [ ] 【条件检查：若有承兑人违约】已减值票据的整个存续期 ECL 是否充分
- [ ] 【风险检查】是否存在延迟进入第二/三阶段以少提减值

### 四、计算准确性与勾稽

- [ ] 【必检】ECL 计算公式与逻辑是否正确（分组×损失率）
- [ ] 【必检】期末减值准备是否与 D1-1 审定表/1231 科目/D1-4 勾稽
- [ ] 【必检】本期计提是否与利润表信用减值损失勾稽
- [ ] 【必检】ECL 计算的票据总体是否与明细表（D1-2）一致
- [ ] 【风险检查】计算是否存在人为调整以达到目标减值金额

## risk_areas

### 高风险

1. **商承违约风险低估**：商业承兑汇票（尤其承兑人财务困难）损失率设定过低或未进入第二/三阶段，减值严重不足。
2. **模型规避计提**：错误选择简化模型或人为简化模型以规避减值。
3. **参数无依据操纵**：PD/LGD/损失率凭空设定或偏低，缺乏历史数据支持。
4. **延迟阶段迁移**：承兑人已出现信用风险显著增加迹象却未及时迁移阶段。
5. **计算结果倒推**：先定目标减值金额再倒推参数，会计估计缺乏客观基础。

### 中风险

1. **前瞻性调整不合理**：前瞻性因子选择或权重缺乏依据，或为调节利润随意调整。
2. **银承商承混合计量**：未区分承兑人类型，掩盖商承高风险。
3. **参数变动未说明**：关键参数较上期变动无合理解释。
4. **勾稽不完整**：ECL 结果与审定表/利润表/坏账准备勾稽存在差异。

### 低风险

1. **模型文档不充分**：ECL 模型的假设、参数来源记录简略。
2. **敏感性分析缺失**：未对关键参数进行敏感性分析。
3. **索引不完整**：与审定表、坏账准备、政策底稿的索引不全。
