# D4-2 主营业务收入明细表复核提示词

## 概述

本提示词针对主营业务收入明细表（D4-2，科目6001）的复核，聚焦四大核心审计要点：按产品/客户/月度的收入明细完整性、单价×数量的量价勾稽、与成本的毛利勾稽、异常波动识别。明细表是主营业务收入审计的基础数据底稿，承载分产品分客户分月度的收入分布，其数据质量直接影响毛利分析、价格分析、集中度判断等后续程序的有效性，也是识别虚增收入和跨期错报的关键数据源。

**法规依据：**
- 《企业会计准则第14号——收入》
- 《中国注册会计师审计准则第1301号——审计证据》
- 《中国注册会计师审计准则第1141号——财务报表审计中与舞弊相关的责任》
- 《中国注册会计师审计准则第1502号——对特殊项目审计证据的进一步考虑》

## tips

1. **量价勾稽是收入真实性的核心验证**：主营业务收入明细必须满足"收入 = 单价 × 数量"的基本恒等，量价关系断裂（如收入增长但量价均未变）是虚增收入的典型信号，需逐产品验证。
2. **明细合计必须与审定表勾稽**：D4-2 各产品/客户收入合计必须等于 D4-1 审定表主营业务收入审定数，任何差异需追溯至具体调整，不得存在无源差异。
3. **月度分布揭示季节性与异常**：分月度收入明细可暴露期末冲刺（12月异常放量）、跨期确认（次年1月回落）等操纵迹象，须结合行业季节特征评估。
4. **收入与成本的毛利勾稽验证真实性**：每类产品收入应与对应成本形成合理毛利率，毛利率异常偏高（虚增收入无对应成本）或为负（成本倒挂）均为重点关注。
5. **明细表是多项后续程序的数据源**：毛利分析、产品价格分析、客户结构分析均以本明细为基础，明细错误将沿数据链传导。
6. **关注双向勾稽关系**：各产品收入 = 单价×数量；各产品/客户收入合计 = D4-1审定数；分月合计 = 全年收入；各产品收入-成本 = 毛利，勾稽任一断裂均为复核重点。

## checklist

### 一、收入明细完整性（高风险）

- [ ] 【必检】明细表是否按产品/客户/月度维度完整列示，无笼统归集
- [ ] 【必检】产品/客户名称是否完整规范，无空白或"其他"大额归集
- [ ] 【必检】明细清单是否与销售系统/ERP导出数据一致
- [ ] 【必检】是否标注关联方客户，关联方收入是否全部识别
- [ ] 【必检】各产品/客户收入合计是否与 D4-1 审定表主营业务收入一致
- [ ] 【条件检查：若有新增产品线】新增产品收入的真实性是否验证
- [ ] 【条件检查：若有停产产品仍有收入】停产产品收入的合理性是否核实
- [ ] 【风险检查】是否存在无对应发货/合同的收入记录
- [ ] 【风险检查】客户/产品变动是否符合经营策略和行业特点

### 二、量价勾稽准确性（高风险）

- [ ] 【必检】各产品收入是否满足"单价 × 数量 = 收入"恒等关系
- [ ] 【必检】单价是否与合同/价目表/历史价格匹配
- [ ] 【必检】销售数量是否与发货记录/出库单一致
- [ ] 【必检】收入是否为不含税金额（增值税销项单独核算）
- [ ] 【条件检查：若有外币销售】外币折算汇率是否正确
- [ ] 【条件检查：若有价格折扣】商业折扣/现金折扣处理是否符合CAS14
- [ ] 【风险检查】是否存在收入增长但量价均无变动的异常（纯金额虚增）
- [ ] 【风险检查】是否存在单价异常偏离市场价的产品

### 三、毛利勾稽合理性（高风险）

- [ ] 【必检】各产品收入是否与对应营业成本匹配形成合理毛利
- [ ] 【必检】各产品毛利率是否在合理区间且与上期可比
- [ ] 【必检】收入与成本的期间归属是否一致（配比原则）
- [ ] 【条件检查：若有高毛利产品】异常高毛利产品是否核实收入真实性
- [ ] 【条件检查：若有负毛利产品】负毛利产品的商业合理性是否说明
- [ ] 【风险检查】是否存在虚增收入无对应成本导致毛利率虚高
- [ ] 【风险检查】毛利率突变的产品是否有合理解释

### 四、月度分布与异常识别（中风险）

- [ ] 【必检】分月度收入合计是否等于全年主营业务收入
- [ ] 【必检】月度收入分布是否符合行业季节性特征
- [ ] 【必检】期末月份（12月）收入是否存在异常放量
- [ ] 【条件检查：若期末放量】期末大额收入对应凭证是否重点核查（截止测试）
- [ ] 【条件检查：若次年初回落】是否存在跨期确认迹象
- [ ] 【风险检查】是否存在月度间大幅波动无合理解释
- [ ] 【风险检查】是否存在通过调整月度分布平滑收入的迹象

## risk_areas

### 高风险

1. **虚增销售收入**：明细表出现无实际发货/合同支撑的收入记录，或量价关系断裂（纯金额虚增），涉及发生认定。
2. **量价勾稽断裂**：收入无法用单价×数量还原，或单价、数量与合同发货记录不符，表明数据可能被操纵。
3. **期末冲刺式收入**：12月收入异常放量且次年初回落，存在提前确认或虚构交易调节利润的重大跨期错报风险。
4. **毛利率虚高**：虚增收入未匹配对应成本导致毛利率异常偏高，是识别虚增收入的关键红旗。
5. **明细与审定表不勾稽**：明细合计与 D4-1 审定数存在差异未调节，表明可能存在遗漏或错误记录。

### 中风险

1. **关联方收入未识别**：明细表中关联方客户收入未标注或遗漏，影响关联交易披露完整性和公允性判断。
2. **产品分类不一致**：不同期间产品归类标准不同，影响毛利分析和趋势对比的可比性。
3. **月度分布异常**：收入月度分布与行业季节性明显背离且无合理解释。
4. **单价异常偏离**：部分产品单价显著偏离市场价或历史价格，存在收入真实性或关联交易定价问题。
5. **系统数据差异**：销售系统与财务系统收入数据存在差异，数据完整性存疑。

### 低风险

1. **格式规范性问题**：明细表格式不统一、排列顺序不规范等形式问题。
2. **辅助信息缺失**：缺少产品规格、客户地区分布等辅助分析信息。
3. **小额归集**：小额产品/客户归集为"其他"时未附明细清单。
4. **交叉索引不完整**：与毛利分析、价格分析、合同检查底稿的交叉引用标注不全。
