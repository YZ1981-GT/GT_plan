# D4-19 销售折扣折让检查表复核提示词

## 概述

本提示词针对营业收入销售折扣折让检查表（D4-19）的复核，聚焦销售折扣与折让的真实性、授权合规性、会计处理正确性（是否作为可变对价冲减收入）、以及是否被用于调节收入。CAS14将现金折扣、商业折扣、销售折让等纳入可变对价，须在确认收入时予以估计并冲减交易价格；折扣折让的滥用（虚构折让冲减收入或隐匿折让虚增收入）是收入操纵的常见手段。

**法规依据：**
- 《企业会计准则第14号——收入》（可变对价、交易价格的确定）
- 《中国注册会计师审计准则第1141号——财务报表审计中与舞弊相关的责任》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **折扣折让在CAS14下属可变对价**：现金折扣、商业折扣、销售折让、返利等均影响交易价格，须在确认收入时按最可能金额或期望值法估计并冲减收入，而非简单在实际发生时处理。
2. **折让真实性须有业务实质支撑**：每笔折让须核对折让协议、质量异议单、退补价通知等原始依据，警惕无真实业务背景的虚构折让被用于冲减收入或转移利益。
3. **授权审批是折让合规的关键控制**：折扣折让须经与其金额相匹配的授权层级审批，越权审批或事后补批的折让存在管理层凌驾内控风险（CAS1141）。
4. **折让时点与收入确认的匹配性**：期末前给予的折让是否已冲减本期收入、期后折让是否属于资产负债表日后调整事项，须评估折让的会计期间归属。
5. **折让被用于调节收入的信号**：期末集中给予大额折让压低收入、次年初异常冲回折让、特定客户折让率显著偏离等，均为收入调节高危信号，须穿透核查。
6. **折扣折让须与开票、回款、返利政策勾稽**：折让金额应与销售发票红字冲销、实际回款差额、既定返利政策相互印证，孤立无据的折让为重点关注对象。

## checklist

### 一、真实性核查

- [ ] 每笔销售折让是否有原始业务依据（质量异议单/折让协议/退补价通知）
- [ ] 折让对应的原始销售交易是否真实存在且可追溯
- [ ] 商业折扣、现金折扣的计算依据是否与合同/销售政策一致
- [ ] 是否存在无真实业务背景的虚构折让
- [ ] 折让金额是否与销售发票红字冲销、实际回款差额勾稽一致
- [ ] 返利折扣是否符合既定返利政策的触发条件和计算方法

### 二、授权与合规

- [ ] 折扣折让是否经过与金额相匹配的授权层级审批
- [ ] 是否存在越权审批或事后补批的折让
- [ ] 大额折让是否有充分的书面审批记录
- [ ] 折让审批流程是否符合企业内部控制制度
- [ ] 是否存在管理层凌驾于折让审批控制之上的迹象
- [ ] 折扣折让政策是否统一执行，特定客户是否存在特殊安排未经审批

### 三、会计处理正确性

- [ ] 折扣折让是否正确作为可变对价冲减营业收入（而非计入费用）
- [ ] 现金折扣是否在确认收入时按CAS14合理估计并冲减交易价格
- [ ] 销售折让的增值税处理是否正确（红字发票冲减销项税）
- [ ] 折让的会计期间归属是否正确（本期折让冲减本期收入）
- [ ] 期后折让是否评估是否属于资产负债表日后调整事项
- [ ] 折让金额是否与D4收入明细、审定表勾稽

### 四、收入调节识别

- [ ] 期末是否存在集中给予大额折让压低收入的异常
- [ ] 次年初是否存在异常冲回折让虚增次年收入的情况
- [ ] 特定客户折让率是否显著偏离整体水平且无合理解释
- [ ] 折让率同比是否发生重大变动，如有是否说明原因
- [ ] 是否存在通过折让向关联方或特定方输送利益的迹象
- [ ] 折让金额占收入比是否合理，异常高企是否已调查

## risk_areas

### 高风险

1. **虚构折让冲减收入或输送利益**：无真实业务背景的折让被用于冲减收入调节利润，或向关联方/特定客户变相输送利益，属收入舞弊（CAS1141）。
2. **折让未作可变对价处理**：折扣折让未按CAS14在确认收入时估计并冲减交易价格，导致收入虚增、后续期间大额冲减。
3. **期末集中折让操纵收入**：临近期末集中给予大额折让压低本期收入，或次年初异常冲回，构成跨期收入操纵。
4. **越权审批的大额折让**：大额折让未经恰当授权即执行，存在管理层凌驾内控、掩盖收入操纵的风险。

### 中风险

1. **折让真实性证据不足**：折让缺少质量异议单/折让协议等原始依据，仅凭内部单据处理，真实性存疑。
2. **折让期间归属错误**：本期折让未冲减本期收入或期后折让未评估调整事项，导致收入跨期。
3. **增值税处理错误**：销售折让未通过红字发票正确冲减销项税，税务处理不合规。
4. **特定客户折让异常**：个别客户折让率显著偏离整体且无合理商业解释，未进一步核查。

### 低风险

1. **折让政策文档不完整**：折扣折让政策未形成完整书面制度，执行依据分散。
2. **底稿记录不充分**：折让检查过程、样本选取、核对结果记录不完整。
3. **交叉索引缺失**：折让检查底稿与收入明细、审定表、发票记录的交叉引用不完整。
