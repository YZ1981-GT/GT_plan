# D4-16 出口/外销收入检查表复核提示词

## 概述

本提示词针对出口/外销收入检查表（D4-16）的复核，聚焦四大核心审计要点：报关单核对、外汇收款核对、出口退税核对、外币折算与收入确认时点。出口收入因涉及报关、外汇、退税等特殊环节，且交易对手为境外主体（真实性验证难度大），是收入舞弊（虚假出口骗税、虚构外销虚增收入）的高发领域，检查须通过报关单、外汇核销、出口退税、物流单据的多方交叉验证确保收入真实性。

**法规依据：**
- 《企业会计准则第14号——收入》
- 《企业会计准则第19号——外币折算》
- 《中国注册会计师审计准则第1301号——审计证据》
- 《中国注册会计师审计准则第1141号——财务报表审计中与舞弊相关的责任》
- 《出口货物劳务增值税和消费税管理办法》

## tips

1. **报关单是出口收入真实性的核心证据**：出口收入必须有真实的海关报关单支撑，须核对报关单的出口日期、商品、数量、金额、境外收货人与收入记录一致，警惕虚假报关或买单出口。
2. **外汇收款验证收入实现**：出口收入的外汇实际收款（结汇/外汇核销）是收入真实实现的强证据，须核对外汇收款金额、时间、来源与收入匹配，警惕无外汇回款的虚假出口。
3. **出口退税勾稽验证一致性**：出口退税申报数据应与出口收入、报关单、增值税进项勾稽一致，退税异常（无实际出口骗税/退税与收入不匹配）是重大舞弊和合规风险。
4. **外币折算影响收入金额（CAS19）**：出口收入须按交易日即期汇率折算，汇率适用错误或折算时点错误将影响收入金额，须核对折算汇率来源和适用。
5. **收入确认时点须匹配贸易术语**：不同贸易术语（FOB/CIF/CFR）下控制权转移时点不同，收入确认时点须与贸易术语和实际发货/报关时点匹配。
6. **勾稽关系**：报关单金额 ↔ 出口收入 ↔ 外汇收款 ↔ 出口退税申报；报关数量 ↔ 发货数量 ↔ 存货减少，多方交叉验证真实性。

## checklist

### 一、报关单核对（高风险）

- [ ] 【必检】出口收入是否均有真实的海关报关单支撑
- [ ] 【必检】报关单的商品、数量、金额是否与收入记录一致
- [ ] 【必检】报关单的出口日期是否与收入确认时点匹配
- [ ] 【必检】报关单境外收货人是否与销售合同客户一致
- [ ] 【必检】报关单是否可通过海关系统验证真伪
- [ ] 【条件检查：若有代理出口】代理出口的报关主体和收入归属是否清晰
- [ ] 【风险检查】是否存在虚假报关或"买单出口"
- [ ] 【风险检查】报关单信息是否与物流/提单不一致

### 二、外汇收款核对（高风险）

- [ ] 【必检】出口收入是否有对应外汇实际收款
- [ ] 【必检】外汇收款金额是否与出口收入匹配（考虑汇率）
- [ ] 【必检】外汇收款时间是否合理（账期内到账）
- [ ] 【必检】外汇收款来源是否为境外交易对手
- [ ] 【必检】外汇核销单/收款水单是否核对
- [ ] 【条件检查：若长期未收汇】长期未收汇的出口收入真实性是否深查
- [ ] 【风险检查】是否存在无外汇回款的虚假出口
- [ ] 【风险检查】外汇收款是否来自第三方或异常账户

### 三、出口退税核对（高风险）

- [ ] 【必检】出口退税申报数据是否与出口收入勾稽
- [ ] 【必检】退税所依据的报关单与收入报关单是否一致
- [ ] 【必检】退税金额计算是否正确（退税率/计税基础）
- [ ] 【必检】增值税进项与出口退税是否匹配
- [ ] 【条件检查：若退税异常】退税与收入不匹配的原因是否核实
- [ ] 【风险检查】是否存在无实际出口的骗税迹象
- [ ] 【风险检查】退税申报是否存在虚增出口金额

### 四、外币折算与收入确认（中风险）

- [ ] 【必检】出口收入是否按交易日即期汇率折算（CAS19）
- [ ] 【必检】折算汇率来源是否可靠（央行中间价）
- [ ] 【必检】收入确认时点是否与贸易术语（FOB/CIF）控制权转移匹配
- [ ] 【必检】汇兑损益核算是否正确
- [ ] 【条件检查：若有远期结汇】远期结汇/套期是否影响收入金额
- [ ] 【风险检查】是否存在利用汇率折算调节收入
- [ ] 【风险检查】收入确认时点是否与报关/发货时点跨期

## risk_areas

### 高风险

1. **虚假出口骗税**：无实际货物出口而虚构报关和退税申报骗取出口退税，涉及重大舞弊和刑事合规风险。
2. **无外汇回款虚增收入**：出口收入长期无对应外汇回款或回款来源异常，反映出口交易可能虚构。
3. **买单出口虚增收入**：借用他人报关单据（买单出口）虚构出口收入，报关主体与实际经营主体不一致。
4. **报关单与收入不匹配**：报关单商品/数量/金额与收入记录不一致，反映出口收入真实性存疑。
5. **退税与收入不勾稽**：出口退税申报数据与出口收入、报关单严重不匹配，反映虚增出口或骗税。

### 中风险

1. **外币折算错误调节收入**：折算汇率适用错误或折算时点选择性使用以调节收入金额。
2. **收入确认时点与贸易术语不符**：不同贸易术语下控制权转移时点判断错误，导致收入跨期。
3. **第三方外汇回款**：外汇收款来自非交易对手的第三方且无合理解释，反映交易安排异常。
4. **代理出口收入归属不清**：代理出口的报关主体、收入归属、退税归属不清晰。
5. **长期未收汇未评估**：长期未收汇的出口应收账款未评估可回收性和收入真实性。

### 低风险

1. **报关单归档不规范**：报关单、核销单、退税单据归档索引不规范。
2. **汇率适用记录不详**：外币折算汇率来源和适用记录过于简略。
3. **抽样覆盖不足**：出口交易检查样本覆盖面不足。
4. **交叉索引不完整**：与明细表、外汇核销、退税申报、物流单据的交叉引用不全。
