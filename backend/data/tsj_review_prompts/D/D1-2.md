# D1-2 分类明细表复核提示词

## 概述

本提示词针对应收票据分类明细表（D1-2）的复核，聚焦四大核心审计要点：按承兑人类型（银行承兑汇票/商业承兑汇票）分类的正确性、逐笔票据余额准确性、到期日分析、票据要素完整性。分类明细表是应收票据科目审计的基础数据底稿，按票据维度记录票号、出票人、承兑人、出票日、到期日、票面金额等要素，其数据质量直接驱动坏账计提（D1-4/D1-15）、到期兑付跟踪、背书贴现核查（D1-8）等后续程序。

**法规依据：**
- 《企业会计准则第22号——金融工具确认和计量》
- 《企业会计准则第37号——金融工具列报》
- 《中国注册会计师审计准则第1301号——审计证据》
- 《中国注册会计师审计准则第1502号——对特殊项目审计证据的进一步考虑》

## tips

1. **承兑人类型分类是分类明细表的第一要务**：银行承兑汇票以承兑银行信用为担保（信用风险极低），商业承兑汇票以出票/承兑企业信用为担保（信用风险显著），分类错误将直接导致 D1-15 ECL 模型损失率选取错误、减值计提失真。
2. **票据要素完整性决定存在性与真实性**：每张票据须具备完整要素（票号、出票人、承兑人、出票日、到期日、票面金额、票据类型），电子票据须核对 ECDS 电子商业汇票系统信息，纸质票据须核对实物，要素缺失或不一致可能是虚构票据的迹象。
3. **余额准确性的核心是勾稽关系**：分类明细各票据票面金额合计必须与审定表 D1-1 期末审定数完全一致，期初必须与上年审定数衔接，任何差异需追溯至具体背书/贴现/兑付或调整。
4. **到期日分析驱动流动性分类与减值判断**：须按到期日区间统计（如资产负债表日后1个月/3个月/6个月/1年内/1年以上），逾期未兑付票据须单独标注并评估可回收性，到期日超过一年的须重分类。
5. **明细表是多项后续程序的数据源**：坏账分组、背书贴现核查、质押核查、函证选样、关联方识别等均以分类明细表为基础，明细错误将沿数据链传导。
6. **关注明细与汇总的双向勾稽**：各票据票面金额合计 = D1-1审定数；银承合计+商承合计 = 应收票据总额；各到期区间金额合计 = 总额；已背书/已贴现标注票据合计 = D1-8 对应金额。

## checklist

### 一、承兑人类型分类正确性（高风险）

- [ ] 【必检】每张票据是否明确标注承兑人类型（银行承兑汇票/商业承兑汇票）
- [ ] 【必检】银行承兑汇票的承兑银行名称是否完整、可识别
- [ ] 【必检】商业承兑汇票的承兑企业名称是否完整，是否评估其信用状况
- [ ] 【必检】银承合计、商承合计是否分别列示并与总额勾稽
- [ ] 【必检】是否存在承兑人类型标注错误（如将财务公司承兑票据误归银承）
- [ ] 【条件检查：若有财务公司承兑票据】集团财务公司承兑票据的分类和风险评估是否恰当
- [ ] 【风险检查】商业承兑汇票占比是否异常上升但减值计提未相应调整
- [ ] 【风险检查】是否存在承兑人为关联方的商业承兑汇票未识别

### 二、票据要素完整性与真实性（高风险）

- [ ] 【必检】每张票据的票号是否唯一、完整、无重复
- [ ] 【必检】出票人、承兑人、收款人（背书链）信息是否完整
- [ ] 【必检】出票日、到期日、票面金额是否齐全且逻辑一致（到期日晚于出票日）
- [ ] 【必检】电子票据是否与 ECDS 电子商业汇票系统登记信息核对一致
- [ ] 【必检】纸质票据是否与实物盘点（D1-10）结果核对一致
- [ ] 【条件检查：若有大额票据】大额票据的出票人经营规模是否与票面金额匹配
- [ ] 【风险检查】是否存在票号连号、金额雷同等虚构票据迹象
- [ ] 【风险检查】是否存在票据要素与合同/发票不匹配的情况

### 三、余额准确性（高风险）

- [ ] 【必检】分类明细各票据票面金额合计是否与审定表 D1-1 一致
- [ ] 【必检】期初余额是否与上年审定期末数衔接
- [ ] 【必检】应收票据数据是否直接从系统/票据台账导出，未经人工调整
- [ ] 【必检】带息票据的应计利息是否单独列示并与 D1-9 勾稽
- [ ] 【条件检查：若有外币票据】外币票据折算汇率是否正确，汇兑损益是否准确
- [ ] 【条件检查：若有合并报表】内部交易票据抵销是否准确完整
- [ ] 【风险检查】是否存在余额异常波动（超过30%且无合理解释）
- [ ] 【风险检查】是否存在大额期后收取/背书，可能为操纵期末余额

### 四、到期日分析（中风险）

- [ ] 【必检】到期日分析是否按规定区间完整列示（资产负债表日后1月/3月/6月/1年内/1年以上）
- [ ] 【必检】各到期区间金额合计是否等于应收票据总额
- [ ] 【必检】逾期未兑付票据是否单独标注并评估可回收性
- [ ] 【必检】到期日超过一年的票据是否已考虑重分类至非流动资产
- [ ] 【必检】即将到期票据的期后兑付情况是否跟踪核实
- [ ] 【条件检查：若有逾期票据】逾期票据是否已转应收账款或计提减值
- [ ] 【风险检查】是否存在到期日集中于资产负债表日后短期，可能为期末冲量
- [ ] 【风险检查】长期未到期的商业承兑汇票是否存在承兑人违约风险

## risk_areas

### 高风险

1. **虚构票据**：分类明细中出现无实际交易背景的票据，票号连号/金额雷同/要素缺失，或电子票据在 ECDS 系统无对应登记，涉及存在性认定。
2. **承兑人类型分类错误**：将商业承兑汇票误归为银行承兑汇票，掩盖信用风险敞口，导致减值计提不足。
3. **余额与总账不一致**：明细合计数与审定表/总账存在差异未调节，表明可能存在遗漏或错误记录。
4. **逾期票据未减值**：逾期未兑付的商业承兑汇票金额重大但未转应收账款或未计提减值。
5. **关联方承兑票据未识别**：承兑人为关联方的票据未标注，影响关联交易披露和信用风险评估。

### 中风险

1. **到期日分析口径不一致**：到期日区间划分与减值模型或流动性分类口径不一致。
2. **票据要素记录不完整**：部分票据缺少出票人、承兑人或到期日等关键要素。
3. **带息票据利息未单独列示**：带息票据应计利息混入票面金额或未单独反映。
4. **商业承兑汇票集中度过高**：单一承兑人商业承兑汇票占比过大，存在信用风险集中敞口。
5. **系统数据与台账差异**：票据管理台账与财务系统数据存在差异，数据完整性存疑。

### 低风险

1. **格式规范性问题**：明细表格式不统一、排列顺序不规范等形式问题。
2. **辅助信息缺失**：缺少票据来源（销售回款/其他）、贸易背景等辅助分析信息。
3. **小额票据归集**：小额票据归集时未附明细清单。
4. **期后兑付信息滞后**：期后兑付数据未及时更新（非金额错误）。
5. **交叉索引不完整**：与背书贴现表、质押表、函证底稿的交叉引用标注不全。
