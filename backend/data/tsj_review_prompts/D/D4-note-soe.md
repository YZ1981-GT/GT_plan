# D4-note-soe 附注披露复核提示词（国有企业）

## 概述

本提示词针对营业收入国有企业附注披露底稿（D4-note-soe）的复核，聚焦国有企业特定的收入附注披露要求：在CAS14通用收入披露（分类/产品服务/地区/确认时点/履约义务）基础上，增加国资监管相关披露、关联交易（含同受国有控制单位）、主营业务突出度、预算执行、以及国资委财务决算报告的补充要求。国有企业审计具双重属性（财务审计+国有资产监管），收入披露须同时满足会计准则与国资监管要求。

**法规依据：**
- 《企业会计准则第14号——收入》
- 《企业会计准则第30号——财务报表列报》
- 《企业会计准则第36号——关联方披露》
- 《企业国有资产法》
- 《中央企业财务决算报告管理办法》及年度决算工作通知

## tips

1. **国有企业收入披露有"双层"要求**：既满足CAS14通用收入披露（分解/履约义务/合同余额），又满足国资委财务决算报告的额外要求（主营业务突出度、非经常性业务收入、预算执行等），两套要求互补不可替代。
2. **主营业务突出度是国企考核关注点**：国资委关注国有企业主业经营质量，附注须能反映主营业务收入占比、主业与非主业收入结构，主营业务占比过低或非主业收入异常增长须说明。
3. **关联方范围更广（同受国有控制）**：国企关联方除一般定义外，须考虑同一国有控股股东控制/共同控制的其他国有企业，关联销售收入须充分披露，但可按准则豁免条款简化部分披露。
4. **预算执行视角是国企独有关注点**：国企年度预算含营业收入目标，附注须说明收入实际执行与预算目标的偏差及原因，收入未达预算或大幅超预算均须解释。
5. **收入质量与国有资本考核挂钩**：收入的真实性、可持续性直接影响国有资本经营业绩考核，异常的收入增长、依赖关联方或政府补贴的收入须审慎披露。
6. **与上市版差异在监管层非准则层**：基础收入披露框架与上市版相同（分解/时点/履约义务/合同余额），国企版额外增加国资监管、预算执行、决算报表衔接等信息，而非替代基础披露。

## checklist

### 一、基础披露完整性（与上市版共有）

- [ ] 营业收入是否区分主营业务收入（6001）与其他业务收入（6051）
- [ ] 主营业务收入是否按主要产品/服务类别分解
- [ ] 是否按经营地区分解披露
- [ ] 收入是否按某一时点/某一时段确认分解
- [ ] 剩余履约义务、合同负债/合同资产是否披露
- [ ] 附注收入总额是否与审定表审定数一致
- [ ] 各分解维度小计是否与总额勾稽，本期上期可比信息是否完整

### 二、主营业务突出度披露

- [ ] 是否披露主营业务收入占营业收入总额的比重
- [ ] 主营与非主营业务收入结构是否清晰列示
- [ ] 主营业务占比较上期是否重大变动，如有是否说明原因
- [ ] 非主营业务收入异常增长是否说明
- [ ] 是否反映主业经营质量（结合国资委主业管理要求）
- [ ] 是否披露收入中属于战略性/政策性业务的部分

### 三、关联交易披露（国企特定）

- [ ] 与控股股东及其关联企业的销售收入是否披露
- [ ] 与同一母公司控制的其他国有企业的收入是否披露
- [ ] 是否运用"同受国家控制"关联方豁免条款，运用是否符合条件
- [ ] 关联销售收入的交易实质与定价方式是否披露
- [ ] 关联销售收入占收入总额比例是否披露
- [ ] 是否存在通过关联交易做大收入的情况并予说明
- [ ] 与政府部门相关的收入（政府采购/专项业务）是否单独列示

### 四、预算执行相关披露

- [ ] 本期营业收入实际数与年度预算目标的对比是否披露
- [ ] 收入预算偏差超过一定比例（如20%）时是否说明原因
- [ ] 主营业务收入完成情况是否与预算对比
- [ ] 收入未达预算的原因及改进措施是否说明
- [ ] 收入大幅超预算的合理性是否说明
- [ ] 收入是否与年度经营业绩考核指标衔接说明

### 五、国资委决算报告补充要求

- [ ] 收入数据是否与年度财务决算报表一致
- [ ] 决算报表相关附加信息表中的收入数据是否与本附注一致
- [ ] 非经常性/一次性业务收入是否单独披露
- [ ] 收入中依赖政府补贴/财政资金支撑的部分是否说明
- [ ] 集团合并层面内部销售收入抵销是否完整，抵销后是否与决算一致
- [ ] 重大收入确认判断是否经恰当决策程序（如涉重大事项）

### 六、与上市版差异关注点

- [ ] 国企版是否在上市版基础披露上增加国资监管层面补充信息
- [ ] 关联方范围是否扩展至"同受国有控制"企业
- [ ] 是否增加主营业务突出度分析
- [ ] 是否增加预算执行偏差分析
- [ ] 是否增加收入与国有资本经营考核的衔接说明
- [ ] 决算报表与审计报表收入口径差异是否调节说明

## risk_areas

### 高风险

1. **关联销售收入披露遗漏**：未将同一国有控股股东下兄弟单位的销售收入纳入关联方披露，或以关联交易做大收入未说明，违反CAS36和国资委要求。
2. **基础披露与审定表不勾稽**：附注收入各维度合计与审定表审定数（6001+6051）不一致，属重大数据错误。
3. **收入分解披露缺失**：未按产品/服务、地区、确认时点分解披露收入，不满足CAS14强制要求。
4. **主营业务收入质量存疑未披露**：主业收入依赖关联方或政府补贴支撑但未充分说明，掩盖收入质量和可持续性问题。

### 中风险

1. **预算执行偏差未充分说明**：收入远低于或远高于年度预算目标但未说明原因，影响经营业绩考核信息可靠性。
2. **主营业务突出度信息缺失**：未披露主营业务占比，无法评估主业经营质量。
3. **"同受国有控制"豁免适用不当**：不符合豁免条件却简化同受国家控制关联方披露，关联交易信息不充分。
4. **决算与审计口径差异未调节**：财务决算收入数据与审计后附注收入存在差异但未编制调节说明。
5. **剩余履约义务/合同负债披露不足**：未充分披露未来收入信息及合同余额变动。

### 低风险

1. **披露格式未完全按决算模板**：附注格式与国资委决算报表模板有细微差异，但信息内容完整。
2. **预算对比分析维度单一**：仅对比收入总额未对比主业/分部等多维度，分析深度不足。
3. **文字描述模板化**：收入确认政策描述照搬准则，未结合国企实际。
4. **历史趋势追溯不完整**：收入变动趋势分析仅覆盖2年而非国资委建议的3年。
