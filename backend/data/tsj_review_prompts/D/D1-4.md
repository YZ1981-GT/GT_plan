# D1-4 坏账准备计算表复核提示词

## 概述

本提示词针对应收票据坏账准备计算表（D1-4）的复核，聚焦四大核心审计要点：减值计提方法的恰当性、账龄组合计提的准确性、单项计提评估的充分性、减值准备（1231科目）与审定表的勾稽。应收票据减值须区分承兑人信用风险：银行承兑汇票由银行信用担保，违约风险极低（通常不计提或按极低损失率组合计提）；商业承兑汇票由企业信用担保，须按 CAS22 预期信用损失模型计提减值。计算表数据是判断资产净额准确性的直接依据。

**法规依据：**
- 《企业会计准则第22号——金融工具确认和计量》（预期信用损失）
- 《企业会计准则第37号——金融工具列报》
- 《中国注册会计师审计准则第1301号——审计证据》

## tips

1. **承兑人类型决定减值基础**：银行承兑汇票违约风险极低，实务中通常不计提或按接近零的损失率计提；商业承兑汇票须评估承兑人信用状况并计提预期信用损失，将两者混同计提是常见错误。
2. **账龄组合与单项计提须清晰划分**：对信用风险显著上升或已发生信用减值的商业承兑汇票（如承兑人财务困难、已逾期）应单项评估计提；其余按账龄/风险特征组合计提，两部分不得重复或遗漏。
3. **减值准备与 1231 科目的勾稽是准确性防线**：D1-4 计算的期末减值准备余额必须等于试算平衡表 1231 科目审定数，本期计提额须等于利润表信用减值损失对应金额。
4. **损失率的合理性须有依据**：组合计提的损失率应基于历史违约损失经验并考虑前瞻性信息，须与 D1-15 ECL 模型的损失率参数一致，不得随意调节以操纵利润。
5. **计提基数须准确**：减值计提基数应为对应类别票据的账面余额，须与 D1-2 分类明细勾稽；已背书/已贴现未终止确认的票据是否纳入计提基数须明确。
6. **关注计提充分性与一致性**：本期计提比例较上期是否合理，商业承兑汇票占比上升时减值是否相应增加，逾期票据是否足额计提，会计估计变更是否有充分理由。

## checklist

### 一、减值计提方法恰当性

- [ ] 银行承兑汇票与商业承兑汇票是否分别确定减值计提方法
- [ ] 银行承兑汇票的低损失率或不计提是否有合理依据（银行信用担保）
- [ ] 商业承兑汇票是否按 CAS22 预期信用损失模型计提减值
- [ ] 减值计提方法是否与会计政策（D1-14）一致
- [ ] 单项计提与组合计提的划分标准是否明确且一致
- [ ] 计提方法较上期是否发生变更，变更是否有充分理由并追溯处理

### 二、账龄组合计提准确性

- [ ] 账龄/风险特征分组是否与 D1-2 分类明细一致
- [ ] 各组合的损失率是否有历史数据和前瞻性信息支持
- [ ] 组合计提金额 = 各组合账面余额 × 对应损失率，计算是否正确
- [ ] 组合损失率是否与 D1-15 ECL 模型参数一致
- [ ] 计提基数是否准确（是否恰当处理已背书/已贴现票据）
- [ ] 各组合计提额合计是否正确汇总

### 三、单项计提评估充分性

- [ ] 信用风险显著上升的商业承兑汇票是否纳入单项评估
- [ ] 承兑人已发生财务困难/违约的票据是否单项足额计提
- [ ] 逾期未兑付票据是否评估减值或转应收账款
- [ ] 单项计提的可回收金额估计是否有依据（承兑人偿付能力、担保等）
- [ ] 单项计提项目是否已从组合计提基数中剔除（避免重复）
- [ ] 单项计提的判断依据是否有充分审计证据支持

### 四、减值准备与 1231 科目勾稽

- [ ] D1-4 期末减值准备余额是否等于试算平衡表 1231 科目审定数
- [ ] 本期计提额是否等于利润表信用减值损失对应金额
- [ ] 减值准备期初+本期计提-本期转回-本期核销=期末余额，勾稽是否成立
- [ ] 减值准备变动是否与 D1-15 ECL 计算表、D1-16 核销检查表一致
- [ ] 减值准备扣减方向是否正确（应收票据净额=账面余额-减值准备）
- [ ] 减值准备是否在审定表 D1-1 中正确列示

## risk_areas

### 高风险

1. **商业承兑汇票减值计提不足**：承兑人信用恶化或已逾期的商业承兑汇票未足额计提减值，虚增资产和利润。
2. **银承商承混同计提**：对高风险商业承兑汇票套用银行承兑汇票的极低损失率，导致减值严重不足。
3. **减值准备与1231科目不勾稽**：计算表期末减值准备与试算平衡表科目审定数不一致，属重大数据错误。
4. **损失率操纵利润**：随意调整组合损失率以调节当期利润，缺乏历史数据和前瞻性信息支持。
5. **单项与组合重复或遗漏**：单项计提项目未从组合基数剔除（重复计提），或应单项评估的未纳入（遗漏计提）。

### 中风险

1. **计提基数错误**：已背书/已贴现未终止确认票据的计提基数处理不当。
2. **前瞻性信息缺失**：损失率仅依赖历史数据，未考虑宏观经济和承兑人行业前瞻性调整。
3. **本期计提与信用减值损失不一致**：D1-4 计提额与利润表信用减值损失科目金额不匹配。
4. **会计估计变更未披露**：损失率或计提方法变更未作为会计估计变更恰当处理和披露。
5. **逾期票据处理不当**：逾期票据既未计提减值也未转应收账款。

### 低风险

1. **计算表格式不规范**：分组标题、损失率列示等格式问题。
2. **损失率依据文档不充分**：损失率测算过程记录不完整。
3. **交叉索引不完整**：与 ECL 计算表、核销表、分类明细表的索引标注不全。
4. **辅助分析缺失**：未列示计提比例较上期变动分析。
