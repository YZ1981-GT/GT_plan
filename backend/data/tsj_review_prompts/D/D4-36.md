# D4-36 其他业务收入截止测试表复核提示词

## 概述

本提示词针对其他业务收入（科目6051）截止测试表（D4-36）的复核，聚焦其他业务收入的截止准确性。其他业务收入涵盖材料销售、租赁收入、包装物出租、技术服务、废料处置等非主营业务收入，虽金额通常低于主营业务，但因业务分散、确认时点多样、易被用于跨期调节，其截止测试同样重要。复核须验证各类其他业务收入在正确会计期间确认，防范跨期错报。

**法规依据：**
- 《企业会计准则第14号——收入》
- 《中国注册会计师审计准则第1141号——财务报表审计中与舞弊相关的责任》
- 《中国注册会计师审计准则第1301号——审计证据》

---

## tips

1. **其他业务收入类型多样确认时点各异（CAS14）**：材料销售按控制权转移确认、租赁收入按期间确认、技术服务按履约进度确认，截止测试须针对不同类型采用相应的时点判断标准。
2. **租赁类收入的期间归属是截止重点**：租赁/出租收入应按租赁期间直线确认，须核查跨期租金是否正确按期分摊，一次性收取的跨期租金是否作递延处理。
3. **材料销售/废料处置截止同主营**：材料销售、废料处置等一次性交易的截止判断与主营收入一致，以控制权转移时点确定收入归属期，须核对出库/交付单据。
4. **其他业务收入易被用于跨期调节**：因金额分散、关注度低，其他业务收入可能被用于期末微调利润，须关注期末集中确认或异常波动的其他业务收入。
5. **测试窗口覆盖资产负债表日前后**：截止测试须覆盖期末前后合理期间，识别跨期确认的其他业务收入，验证归属期正确性。
6. **其他业务收入与成本配比**：其他业务收入确认须与其他业务成本配比，期末已确认收入对应成本是否同步结转须核查。

## checklist

### 一、测试范围与分类

- [ ] 测试是否覆盖各类其他业务收入（材料销售/租赁/服务/废料等）
- [ ] 测试窗口是否覆盖资产负债表日前后合理天数
- [ ] 期末集中确认的其他业务收入是否重点纳入
- [ ] 大额其他业务收入是否纳入测试
- [ ] 各类收入是否按其确认时点特征分类测试
- [ ] 样本选取是否兼顾金额与风险

### 二、确认时点核对

- [ ] 材料销售/废料处置是否按控制权转移时点确认（核对出库/交付）
- [ ] 租赁/出租收入是否按租赁期间正确分摊确认
- [ ] 一次性收取的跨期租金是否作递延处理
- [ ] 技术/劳务服务收入是否按履约进度确认
- [ ] 记账日与业务发生/交付/期间是否匹配
- [ ] 原始单据是否齐全并与记账印证

### 三、跨期与异常识别

- [ ] 是否识别确认时点与账面归属期不一致的跨期收入
- [ ] 期末集中确认的其他业务收入是否核查真实性
- [ ] 是否存在通过其他业务收入微调利润的迹象
- [ ] 跨期收入金额是否汇总评估影响
- [ ] 其他业务收入确认是否与成本配比（成本同步结转）
- [ ] 是否追踪跨期收入次年确认/冲回情况

### 四、结论与勾稽

- [ ] 截止测试结论是否明确（无跨期/存在跨期需调整）
- [ ] 需调整的跨期收入是否形成调整分录建议
- [ ] 其他业务收入截止是否与主营业务截止（D4-17/18）协调
- [ ] 测试结果是否与其他业务收入明细、审定表勾稽
- [ ] 重大跨期错报是否评估累计影响
- [ ] 底稿是否记录测试方法、窗口天数、样本依据及交叉索引

## risk_areas

### 高风险

1. **跨期调节利润**：利用其他业务收入金额分散、关注度低的特点，通过跨期确认微调本期利润，规避重点关注（CAS1141）。
2. **租金收入期间归属错误**：一次性收取的跨期租金未作递延，全额确认为本期收入，导致收入跨期虚增。
3. **控制权转移判断错误**：材料销售/废料处置未按控制权转移确认，归属期错误。
4. **收入成本截止不匹配**：其他业务收入确认但对应成本未同步结转，扭曲其他业务毛利。

### 中风险

1. **服务收入进度确认不当**：技术/劳务服务收入未按履约进度合理确认，时点存在偏差。
2. **测试覆盖不足**：其他业务收入类型多样但测试未覆盖主要类型或大额项目。
3. **期末异常波动未查**：期末其他业务收入异常增减未核查原因。
4. **跨期金额未评估**：识别跨期交易但未汇总评估对利润的影响。

### 低风险

1. **分类测试不细**：未按其他业务收入类型分别测试，测试针对性不足。
2. **底稿记录不完整**：测试窗口、样本依据、原始单据核对记录不完整。
3. **交叉索引缺失**：与其他业务收入明细、审定表、成本结转的交叉引用不完整。
