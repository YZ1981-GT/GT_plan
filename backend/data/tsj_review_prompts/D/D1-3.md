# D1-3 客户明细表复核提示词

## 概述

本提示词针对应收票据客户明细表（D1-3）的复核，聚焦四大核心审计要点：按出票人/客户维度的信息完整性、余额准确性、持有账龄分析、客户集中度分析。客户明细表从交易对手（出票人/背书前手）维度汇总应收票据余额，是识别关联方票据、评估信用风险集中度、判断票据贸易背景真实性的基础底稿。应收票据的"客户"通常指票据的直接来源方（销售回款客户或背书转入前手）。

**法规依据：**
- 《企业会计准则第22号——金融工具确认和计量》
- 《企业会计准则第37号——金融工具列报》
- 《企业会计准则第36号——关联方披露》
- 《中国注册会计师审计准则第1301号——审计证据》

## tips

1. **客户信息完整性是明细表质量的基石**：每一行客户（出票人/背书前手）记录须具备完整识别信息（名称、关联方标志、信用状况），空白客户或"其他"笼统归集可能掩盖无真实贸易背景的融资性票据。
2. **区分出票人与承兑人是应收票据客户分析的特殊要求**：客户明细通常以票据来源方（销售客户或背书前手）为维度，而信用风险取决于承兑人，须结合 D1-2 承兑人分析综合判断，不可仅凭客户维度判断可回收性。
3. **余额准确性依赖勾稽关系**：客户明细各客户票据余额合计必须等于审定表 D1-1 审定数，期初必须与上年衔接；同一客户可能持有多张不同承兑人的票据，须完整归集。
4. **持有账龄分析辅助真实性与减值判断**：应收票据账龄一般较短（票据期限通常6个月内），若存在长期持有（远超正常票据期限）或反复背书的票据，须评估其贸易背景真实性和减值需要。
5. **客户集中度揭示贸易背景集中风险**：前五大出票人/客户集中度过高，或票据来源高度集中于关联方/单一客户，可能存在融资性票据或资金占用迹象。
6. **关注明细与汇总的双向勾稽**：客户明细各客户余额合计 = D1-1审定数；各客户余额 = 该客户名下各票据金额之和（与 D1-2 逐笔勾稽）；关联方客户余额 = D1-11 关联方票据合计；前五大客户余额 ÷ 总额 = 集中度比例。

## checklist

### 一、客户信息完整性（高风险）

- [ ] 【必检】客户（出票人/背书前手）名称是否完整、规范，无空白或"其他"笼统归集
- [ ] 【必检】是否标注关联方客户，关联方应收票据是否全部识别（与 D1-11 一致）
- [ ] 【必检】客户名称是否与销售系统/合同/发票记录一致
- [ ] 【必检】是否标注票据来源类型（销售回款/背书转入/其他）
- [ ] 【必检】是否存在多个客户使用同一承兑人或相互背书的异常关联
- [ ] 【条件检查：若有新增重要客户】新增大额票据客户是否有背景调查
- [ ] 【风险检查】是否存在无真实贸易背景的融资性票据客户迹象
- [ ] 【风险检查】客户是否既是应收票据出票人又是应付票据收款人（对开票据）

### 二、余额准确性（高风险）

- [ ] 【必检】客户明细各客户票据余额合计是否与审定表 D1-1 一致
- [ ] 【必检】期初余额是否与上年审定期末数衔接
- [ ] 【必检】各客户余额是否等于该客户名下各票据金额之和（与 D1-2 勾稽）
- [ ] 【必检】数据是否直接从票据台账/系统导出，未经人工调整
- [ ] 【条件检查：若有外币票据客户】外币折算是否正确
- [ ] 【条件检查：若有合并报表】内部客户票据抵销是否准确
- [ ] 【风险检查】是否存在客户余额异常波动无合理解释
- [ ] 【风险检查】是否存在大额期后收取集中于特定客户

### 三、持有账龄分析（中风险）

- [ ] 【必检】账龄/持有期是否按规定区间列示，起算日口径是否一致
- [ ] 【必检】各账龄段金额合计是否等于客户余额及总额
- [ ] 【必检】持有期显著超过正常票据期限（如超过1年）的票据是否单独标注原因
- [ ] 【必检】长账龄票据的贸易背景真实性和可回收性是否评估
- [ ] 【条件检查：若有反复背书票据】多次背书流转的票据账龄是否合理计算
- [ ] 【风险检查】是否存在长期持有的商业承兑汇票未评估减值
- [ ] 【风险检查】账龄结构较上期是否异常变化

### 四、客户集中度分析（中风险）

- [ ] 【必检】前五大客户（出票人/背书前手）名称、余额、占比是否列示完整
- [ ] 【必检】前五大客户占应收票据总额比例是否计算正确
- [ ] 【必检】前五大客户变动情况是否与上年对比分析
- [ ] 【必检】前五大客户中是否包含关联方，若有是否单独标注
- [ ] 【必检】前五大客户票据的承兑人类型和期后兑付情况是否分析
- [ ] 【条件检查：若集中度超过50%】是否评估单一来源依赖风险
- [ ] 【风险检查】是否存在票据来源高度集中于关联方的融资性安排
- [ ] 【风险检查】前五大客户是否与前五大供应商/关联方存在对开票据循环

## risk_areas

### 高风险

1. **融资性票据无真实贸易背景**：客户明细中票据缺乏对应的销售合同/发票支持，可能为无真实交易背景的融资性票据，涉及存在性和交易真实性。
2. **余额与总账不一致**：客户明细合计数与审定表/总账存在差异未调节。
3. **关联方客户未识别**：出票人/背书前手为关联方的票据未标注，影响关联交易披露完整性。
4. **对开票据循环**：应收票据出票人同时为应付票据收款人，存在虚增资产负债或资金腾挪迹象。
5. **长账龄商业承兑汇票未减值**：来源客户信用恶化的长期持有商业承兑汇票未计提减值。

### 中风险

1. **客户集中度过高**：单一或少数客户/出票人占比过大，存在贸易背景集中风险。
2. **客户信息不完整**：部分客户缺少关联方标志、信用状况等关键信息。
3. **账龄划分标准不一致**：不同客户或期间采用不同账龄起算标准。
4. **票据来源类型标注缺失**：未区分销售回款票据与背书转入票据，影响真实性判断。
5. **系统数据差异**：票据台账与财务系统的客户维度数据存在差异。

### 低风险

1. **格式规范性问题**：明细表格式不统一、排列顺序不规范。
2. **辅助信息缺失**：缺少客户行业分类、地区分布等辅助信息。
3. **小额散户归集**：小额客户归集为"其他"时未附明细清单。
4. **期后兑付信息滞后**：期后兑付数据未及时更新（非金额错误）。
5. **交叉索引不完整**：与关联方票据表、分类明细表的交叉引用标注不全。
