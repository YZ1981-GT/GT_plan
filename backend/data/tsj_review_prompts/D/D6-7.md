# D6-7 合同资产会计政策检查复核提示词

## 概述

本提示词针对合同资产会计政策检查表（D6-7，科目码1141）的复核，聚焦四大核心审计要点：合同资产确认政策合理性、合同资产与应收账款划分标准、收款权是否仅取决于时间流逝的判断、减值政策与列报政策一致性。会计政策是合同资产确认、计量、列报的准绳，CAS14下合同资产与应收账款的划分核心在于"收款权是否仅取决于时间流逝"，政策不当或适用不一致将系统性影响合同资产的真实性与可比性。

**法规依据：**
- 《企业会计准则第14号——收入》
- 《企业会计准则第22号——金融工具确认和计量》
- 《企业会计准则第37号——金融工具列报》
- 《中国注册会计师审计准则第1301号——审计证据》

## tips

1. **合同资产与应收账款划分是政策检查的核心**：CAS14规定，企业已向客户转让商品而有权收取对价的权利，若该权利取决于时间流逝之外的因素（如尚需完成其他履约义务），确认为合同资产；若仅取决于时间流逝，确认为应收账款，政策须明确划分标准。
2. **收款权判断须结合合同条款**：判断收款权是否"仅取决于时间流逝"须穿透合同的付款条件、履约义务捆绑关系及验收/里程碑安排，政策应有清晰的判断路径。
3. **合同资产确认时点与履约进度政策一致**：合同资产随履约进度确认，其确认政策须与收入确认政策（时段法/时点法、产出法/投入法）协调一致。
4. **减值政策须符合CAS22 ECL要求**：合同资产减值适用预期信用损失模型（通常简化法），政策须明确损失率确定方法、组合划分及前瞻性信息运用。
5. **列报政策须体现合同净额及流动性**：同一合同下合同资产与合同负债须按净额列示，超过一年的合同资产分类政策须明确，政策适用应保持一致。
6. **关注政策变更及首次执行影响**：若本期发生会计政策变更或首次执行CAS14，须评估追溯调整的正确性及对期初合同资产的影响，并与D6-1审定表期初调整勾稽。

## checklist

### 一、合同资产确认政策合理性

- [ ] 合同资产确认政策是否符合CAS14规定
- [ ] 合同资产确认是否与履约进度及收入确认政策协调一致
- [ ] 履约进度计量方法（产出法/投入法）政策是否明确并一致适用
- [ ] 合同资产初始确认金额的确定方法是否合理
- [ ] 政策是否明确合同资产与合同履约成本、合同取得成本的界限
- [ ] 会计政策是否在报表附注中充分披露

### 二、合同资产与应收账款划分标准

- [ ] 政策是否明确合同资产与应收账款的划分标准
- [ ] 划分标准是否以"收款权是否仅取决于时间流逝"为核心判断
- [ ] 政策是否明确合同资产转应收账款的时点（收款权转为无条件时）
- [ ] 划分标准是否在各类合同中一致适用
- [ ] 是否存在应确认为应收账款却列示为合同资产（或反之）的政策性偏差
- [ ] 划分政策是否与附注披露的分类口径一致

### 三、收款权判断路径

- [ ] 政策是否规定判断收款权性质须穿透合同付款条件及履约义务
- [ ] 是否明确捆绑履约义务对收款权无条件性的影响
- [ ] 验收条款、里程碑安排对收款权判断的影响是否有政策指引
- [ ] 判断路径是否有支持性文档（合同条款分析）
- [ ] 相同性质合同的收款权判断是否一致
- [ ] 是否存在通过延后确认无条件收款权以调节合同资产/应收账款的迹象

### 四、减值与列报政策一致性

- [ ] 合同资产减值政策是否符合CAS22预期信用损失模型（简化法适用性）
- [ ] 损失率确定方法、组合划分、前瞻性信息运用政策是否明确
- [ ] 同一合同下合同资产与合同负债的净额列示政策是否明确
- [ ] 合同资产流动/非流动分类政策是否明确并一致适用
- [ ] 减值及列报政策是否与D6-3减值明细、D6-1审定表列报一致
- [ ] 政策变更或首次执行CAS14的追溯调整是否正确处理并披露

## risk_areas

### 高风险

1. **划分标准缺失或不当**：政策未明确合同资产与应收账款的划分标准，或标准偏离"收款权是否仅取决于时间流逝"的核心判断，导致系统性列报错误。
2. **收款权判断操纵**：通过政策性延后确认无条件收款权，将应确认为应收账款的债权保留为合同资产（或反之），调节科目结构或规避减值方法差异。
3. **确认政策与收入政策脱节**：合同资产确认政策与收入确认政策（履约进度方法）不一致，导致合同资产与收入不匹配。
4. **减值政策不符合CAS22**：合同资产减值未采用预期信用损失模型或简化法适用错误，减值计提缺乏政策基础。
5. **政策变更追溯错误**：首次执行CAS14或政策变更的追溯调整错误，扭曲期初合同资产及留存收益。

### 中风险

1. **净额列示政策缺失**：未明确同一合同下合同资产与合同负债的净额列示政策，可能不当总额列示。
2. **流动性分类政策不明确**：合同资产流动/非流动分类政策缺失或适用不一致。
3. **履约进度方法不一致**：产出法/投入法政策未一致适用于同类合同。
4. **损失率政策依据不足**：减值损失率确定方法及前瞻性信息运用政策缺乏客观依据。
5. **政策披露不充分**：合同资产会计政策在附注中披露不完整。

### 低风险

1. **政策文档格式不规范**：会计政策文档表述、编号等形式问题。
2. **判断路径记录简略**：收款权判断路径的支持性文档记录简略。
3. **交叉索引不完整**：与D6-1审定表、D6-3减值、附注披露的交叉引用标注不全。
