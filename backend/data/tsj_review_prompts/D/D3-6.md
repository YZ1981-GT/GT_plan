# D3-6 关联方检查表复核提示词

## 概述

本提示词针对预收账款/合同负债关联方检查表（D3-6）的复核，聚焦四大核心审计要点：关联方预收款项识别完整性、交易商业实质、定价公允性、披露完整性。关联方预收款项可能被用作资金往来通道、利润操纵工具或掩盖资金占用，须核查每笔关联方合同负债的商业实质和真实履约义务，防止以预收名义进行非经营性资金拆借，是关联交易审计和舞弊风险应对的重要环节。

**法规依据：**
- 《企业会计准则第14号——收入》
- 《企业会计准则第36号——关联方披露》
- 《中国注册会计师审计准则第1301号——审计证据》
- 《中国注册会计师审计准则第1323号——关联方》

## tips

1. **关联方识别须穿透完整**：不仅识别直接关联方，还须穿透识别通过第三方安排、隐性控制关系形成的关联方预收款，识别不完整将遗漏关联交易披露和舞弊风险。
2. **商业实质是关联交易核查核心**：关联方预收款须核查是否存在真实的销售合同和履约义务，警惕以预收名义进行的非经营性资金占用或拆借。
3. **定价公允性影响利润真实性**：关联方交易的预收定价应与市场公允价格对比，异常高价预收可能虚增未来收入，异常低价可能存在利益输送。
4. **关联方长期挂账风险更高**：关联方合同负债长期挂账可能为资金占用的伪装，须结合D3-5长期挂账检查评估是否应退回或确认收入。
5. **CAS36披露要求须严格满足**：关联方预收款项须单独披露关联方名称、关系、交易金额、期末余额，不得混入一般客户，遗漏属披露不完整。
6. **保持职业怀疑追溯资金流**：对关联方大额预收款，须追溯资金来源和流向，判断是否为循环交易、虚假交易或资金占用，防止关联方利益输送。

## checklist

### 一、关联方预收款项识别完整性

- [ ] 关联方清单是否与公司关联方登记表、股权结构一致
- [ ] 是否将所有关联方预收款项/合同负债全部识别并纳入检查
- [ ] 是否穿透识别通过第三方或隐性关系形成的关联方预收款
- [ ] 关联方预收款金额合计是否与明细表（D3-2）关联方标注项一致
- [ ] 是否核查董监高、控股股东及其关联企业的预收款情况
- [ ] 是否存在应识别为关联方但未标注的客户

### 二、交易商业实质

- [ ] 每笔关联方预收款是否有真实的销售合同和履约义务支持
- [ ] 是否核查关联方预收对应的产品/服务是否真实存在
- [ ] 是否警惕以预收名义进行的非经营性资金拆借
- [ ] 关联方预收的履约进度和交付情况是否核查
- [ ] 是否存在关联方之间的循环交易（预收-退款-再预收）
- [ ] 关联方预收款是否与关联销售规模、业务往来相匹配

### 三、定价公允性

- [ ] 关联方交易预收定价是否与市场公允价格对比
- [ ] 是否存在异常高价预收虚增未来收入的情况
- [ ] 是否存在异常低价或无偿使用资金的利益输送
- [ ] 关联方交易定价方式（市场价/协议价）是否披露
- [ ] 定价差异对利润和负债的影响是否评估
- [ ] 是否存在通过关联方预收调节收入确认时点的迹象

### 四、披露完整性

- [ ] 关联方预收款项是否单独列示（不混入一般客户）
- [ ] 是否完整披露关联方名称、关系类型
- [ ] 是否披露与各关联方的交易金额和期末余额
- [ ] 关联方合同负债的账龄和长期挂账情况是否单独分析
- [ ] 关联方交易的定价政策和结算方式是否披露
- [ ] 披露是否符合CAS36要求，是否与附注（D3-note）勾稽

## risk_areas

### 高风险

1. **资金占用伪装预收**：以合同负债名义为关联方提供非经营性资金，掩盖资金占用或拆借实质，涉及舞弊和资金安全。
2. **关联方未识别或未披露**：关联方预收款项未识别或未单独披露，违反CAS36，可能故意隐瞒关联交易。
3. **利益输送**：通过异常定价的关联方预收进行利益输送，损害中小股东利益，影响利润真实性。
4. **循环交易虚增业绩**：关联方之间通过预收-履约-退款循环虚构交易规模，虚增收入和现金流。

### 中风险

1. **商业实质存疑**：关联方预收缺乏真实合同或履约义务支持，交易实质无法验证。
2. **定价公允性未评估**：关联方预收定价未与市场价对比，公允性无法判断。
3. **关联方长期挂账未处理**：关联方合同负债长期挂账未评估应确认收入或退回。
4. **穿透识别不足**：仅识别直接关联方，未穿透隐性关联关系。

### 低风险

1. **关联关系说明不详**：关联方关系类型描述过于简略。
2. **定价依据记录不全**：定价公允性核查已执行但依据记录不完整。
3. **交叉索引不完整**：与明细表、长期挂账检查表、附注披露的交叉引用标注不全。
4. **格式规范性问题**：检查表格式不统一、栏目缺失等形式问题。
