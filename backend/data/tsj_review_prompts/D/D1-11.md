# D1-11 关联方票据检查表复核提示词

## 概述

本提示词针对应收票据关联方检查表（D1-11）的复核，聚焦四大核心审计要点：关联方识别完整性、关联方票据交易真实性与商业实质、交易公允性、披露充分性。关联方之间的票据往来（尤其关联方对开票据、无真实贸易背景的融资性票据）是资金占用、利润操纵和信用风险转移的高发领域，须结合 D1-2 明细、D1-8 背书贴现、B19 关联方清单交叉核查。

**法规依据：**
- 《企业会计准则第36号——关联方披露》
- 《中国注册会计师审计准则第1301号——审计证据》
- 《中国注册会计师审计准则第1323号——关联方》
- 《企业会计准则第22号——金融工具确认和计量》

## tips

1. **关联方识别须完整且穿透**：除直接持股关联方外，须识别同一控制人下的兄弟单位、关键管理人员及其近亲属控制的企业，与 B19 关联方清单逐户比对，防范未披露关联方以票据往来隐匿资金占用。
2. **关联方对开票据是重大舞弊信号**：关联方之间互开商业承兑汇票、循环背书，可能无真实贸易背景，用于虚构交易、粉饰资金链或规避资金占用披露，须核查贸易背景真实性。
3. **无真实贸易背景的融资性票据须重点关注**：关联方票据缺乏销售合同、发货单、发票支持的，本质是资金拆借，须按其经济实质而非法律形式处理和披露。
4. **交易公允性须评估**：关联方票据的账期、是否计息、贴现条件是否显著优于/劣于第三方，异常条款可能构成利益输送或资金占用。
5. **关联方商业承兑汇票的信用风险须单独评估**：关联方（尤其财务困难的关联方）承兑的商业汇票违约风险高，减值计提须单独评估，不得混入一般组合。
6. **披露须完整且区分**：关联方应收票据须在附注单独披露关联方名称、关系、金额、是否计息、坏账准备，不得混入一般客户。

## checklist

### 一、关联方识别完整性

- [ ] 【必检】关联方应收票据是否与 B19 关联方清单逐户核对识别
- [ ] 【必检】是否识别同一控制人下兄弟单位、关键管理人员控制企业的票据
- [ ] 【必检】出票人/承兑人是否存在实质关联但未标注为关联方的情况
- [ ] 【条件检查：若有新增票据关系】新增关联方票据是否有商业合理性说明
- [ ] 【风险检查】是否存在通过第三方过桥掩盖关联方票据往来的情况

### 二、交易真实性与商业实质

- [ ] 【必检】关联方票据是否有真实贸易背景（销售合同/发货单/发票）
- [ ] 【必检】关联方对开/循环背书票据是否核查商业实质
- [ ] 【必检】无贸易背景的融资性票据是否按经济实质（资金拆借）处理
- [ ] 【条件检查：若关联方财务困难】其承兑票据的可回收性是否评估
- [ ] 【风险检查】是否存在期末突击开立关联方票据粉饰报表的情况

### 三、交易公允性

- [ ] 【必检】关联方票据账期、计息条件是否与第三方交易可比
- [ ] 【必检】是否存在显著异常的定价或条款（利益输送/资金占用迹象）
- [ ] 【必检】关联方票据贴现/背书条件是否公允
- [ ] 【风险检查】是否存在无偿或超长账期占用资金的情况

### 四、披露充分性

- [ ] 【必检】关联方应收票据是否在附注单独列示（名称/关系/金额）
- [ ] 【必检】关联方票据是否与一般客户票据严格区分
- [ ] 【必检】关联方票据坏账/减值准备是否单独披露
- [ ] 【条件检查：若涉及资金占用】非经营性资金占用是否按监管要求披露
- [ ] 【风险检查】是否存在应披露而未披露的关联方票据交易

## risk_areas

### 高风险

1. **未披露关联方资金占用**：通过关联方票据往来隐匿非经营性资金占用，未识别、未披露，违反 CAS36 及监管要求。
2. **关联方对开无背景票据**：关联方互开商业承兑汇票无真实贸易背景，虚构交易或粉饰资金链。
3. **关联方票据可回收性高估**：财务困难关联方承兑的商业汇票未充分计提减值，虚增资产。
4. **关联方识别遗漏**：实质关联方未被识别，其票据混入一般客户，掩盖关联交易。
5. **利益输送**：通过异常票据条款（超长账期/无息/优惠贴现）向关联方输送利益。

### 中风险

1. **商业实质核查不足**：关联方票据的贸易背景核查流于形式。
2. **公允性评估缺失**：未将关联方票据条款与第三方交易对比评估公允性。
3. **减值未单独评估**：关联方商业承兑汇票混入一般组合计提减值。
4. **披露不完整**：关联方票据披露遗漏计息、坏账准备等要素。

### 低风险

1. **索引不完整**：与 B19 关联方清单、明细表、背书贴现底稿的交叉索引不全。
2. **格式不规范**：关联方票据检查记录格式不统一。
3. **关系描述不清**：关联关系类型描述过于笼统。
