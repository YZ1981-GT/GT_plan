# B60-1 工时预算与控制板复核提示词

## 概述

本提示词针对工时预算与控制底稿（B60-1，按审计阶段）的复核，聚焦审计资源（工时/人员）预算的合理性、与总体审计策略和风险评估的匹配性、以及预算执行监控的有效性。工时预算是总体审计策略的资源配置载体，预算不足或分配不当可能导致关键领域审计投入不够、审计质量受损。

**法规依据：**
- 《中国注册会计师审计准则第1201号——计划审计工作》
- 《中国注册会计师审计准则第1121号——对财务报表审计实施的质量管理》
- 《中国注册会计师审计准则第1231号——针对评估的重大错报风险采取的应对措施》

---

## tips

1. **工时预算须与风险评估匹配**：高风险/关键领域应配置更充分的工时和更有经验的人员，预算分配应体现风险导向（CAS1231）。
2. **人员配置须考虑胜任能力与独立性**：项目组成员的专业胜任能力、经验、行业知识和独立性应与审计任务匹配（CAS1121）。
3. **各阶段工时分配须合理**：计划、执行、完成/报告各阶段的工时分配应合理，避免完成阶段（复核/报告）投入不足。
4. **专家与特殊领域工时须预留**：需利用专家（评估/精算/IT）或复杂领域（合并/金融工具/收入）应预留充分工时。
5. **预算执行须监控并分析偏差**：实际工时与预算的偏差应监控，重大超支或投入不足须分析原因并评估对审计质量的影响。
6. **工时预算是质量管理的一部分**：不切实际的低预算可能形成审计质量压力，须警惕为压缩成本而削减必要程序。

## checklist

### 一、预算合理性

- [ ] 工时预算总量是否与被审计单位规模和复杂度匹配
- [ ] 高风险/关键领域是否配置更充分的工时
- [ ] 各审计阶段（计划/执行/完成）工时分配是否合理
- [ ] 是否为需利用专家/复杂领域预留充分工时

### 二、人员配置

- [ ] 项目组人员的专业胜任能力和经验是否与任务匹配
- [ ] 关键领域是否配置有经验的人员
- [ ] 项目组独立性是否已确认
- [ ] 督导和复核的层级安排是否充分

### 三、与策略/风险衔接

- [ ] 工时预算是否体现风险导向（与 B50 风险评估匹配）
- [ ] 预算是否与总体审计策略衔接
- [ ] 是否考虑不可预见程序的时间安排

### 四、执行监控

- [ ] 实际工时与预算的偏差是否监控
- [ ] 重大超支/投入不足是否分析原因
- [ ] 是否评估工时偏差对审计质量的影响
- [ ] 是否存在为压缩成本削减必要程序的迹象

## risk_areas

### 高风险

1. **关键领域工时投入不足**：高风险或复杂领域工时预算不足，导致审计程序执行不充分，重大错报风险应对不到位。
2. **人员胜任能力不匹配**：关键/复杂领域配置经验不足的人员，审计质量受损。
3. **低预算形成质量压力**：不切实际的低工时预算迫使削减必要审计程序，审计质量被成本压力侵蚀。

### 中风险

1. **阶段分配失衡**：完成/报告阶段（复核）工时投入不足，复核质量下降。
2. **专家工时未预留**：需利用专家的领域未预留充分工时，专家工作仓促。
3. **偏差监控缺失**：实际工时与预算偏差未监控分析。

### 低风险

1. **预算记录不完整**：工时预算的编制依据记录简略。
2. **偏差分析不深入**：工时偏差原因分析停留在表面。
3. **交叉索引缺失**：与总体审计策略、风险评估底稿的索引不完整。
