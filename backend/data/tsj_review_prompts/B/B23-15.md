# B23-15 了解信息处理控制 复核提示词

## 概述

本提示词针对了解信息处理控制程序（B23-15）的复核，聚焦信息系统了解充分性、信息处理控制识别、控制设计评价、IT依赖与一般控制关联四大要点。信息处理控制确保交易被完整、准确、有效地记录和处理，随着被审计单位对信息系统依赖加深，了解信息处理控制的设计及其执行成为风险评估不可或缺的环节。

**法规依据：**
- 《中国注册会计师审计准则第1211号——通过了解被审计单位及其环境识别和评估重大错报风险》
- 《中国注册会计师审计准则第1231号——针对评估的重大错报风险采取的应对措施》
- 《中国注册会计师审计准则第1633号——电子商务对财务报表审计的影响》

## tips

1. **了解应覆盖信息系统与业务流程的衔接**：应了解交易如何在信息系统中发起、授权、处理、记录，识别信息系统在财务报告流程中的作用。
2. **信息处理控制关注完整性、准确性、有效性**：应识别确保交易被完整记录（无遗漏）、准确处理（金额科目正确）、有效授权（合规发起）的自动与人工控制。
3. **区分自动化控制与人工控制**：自动化控制依赖IT一般控制的有效性，人工控制依赖执行人员，两者评价路径不同应分别识别。
4. **IT依赖程度决定了解深度**：高度依赖信息系统处理的交易，信息处理控制及IT一般控制的了解应更深入。
5. **信息处理控制须与IT一般控制关联评价**：应用层控制的有效性依赖于IT一般控制（访问、变更、运行管理），二者应关联而非孤立评价。
6. **了解结论须支持控制信赖决策**：了解信息处理控制的设计是判断是否信赖控制、是否实施控制测试的基础。

## checklist

### 一、信息系统了解

- [ ] 是否了解财务相关信息系统的构成和作用
- [ ] 是否了解交易在系统中的发起、授权、处理、记录流程
- [ ] 是否了解系统间的数据接口和传递
- [ ] 是否识别信息系统在财务报告流程中的关键节点
- [ ] IT依赖程度是否评估并匹配了解深度

### 二、信息处理控制识别

- [ ] 是否识别确保交易完整记录的控制
- [ ] 是否识别确保交易准确处理的控制
- [ ] 是否识别确保交易有效授权的控制
- [ ] 是否区分了自动化控制与人工控制
- [ ] 关键信息处理控制点是否识别完整

### 三、设计评价与关联

- [ ] 信息处理控制的设计有效性是否评价
- [ ] 自动化控制是否关联IT一般控制评价
- [ ] IT一般控制（访问/变更/运行）薄弱是否影响应用控制信赖
- [ ] 了解结论是否支持控制信赖和测试决策
- [ ] 信息处理控制缺陷是否结转控制风险评估

## risk_areas

### 高风险

1. **关键信息处理控制漏识别**：确保交易完整准确处理的关键控制未识别，控制缺口评估不完整。
2. **信赖自动控制忽视IT一般控制**：拟信赖自动化控制却未评价IT一般控制有效性，信赖基础不牢。
3. **系统数据接口风险未识别**：系统间数据传递的完整准确控制未了解，可能存在数据丢失或篡改风险。

### 中风险

1. **自动与人工控制未区分**：混淆两类控制导致评价路径错误。
2. **IT依赖程度评估不足**：高度IT依赖的交易了解深度不够。
3. **设计评价流于形式**：仅描述控制存在而未评价其设计是否有效。

### 低风险

1. **系统了解记录不完整**：信息系统构成和流程了解记录不充分。
2. **控制点描述不清**：识别的信息处理控制描述笼统。
3. **索引引用缺失**：了解结论未与控制风险评估及IT一般控制底稿建立索引。
