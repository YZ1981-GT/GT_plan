# B1-5 KAA（关键审计事项候选）检查表-业务承接 复核提示词

## 概述

本提示词针对业务承接阶段关键审计事项候选（KAA）检查表（B1-5）的复核，聚焦候选事项识别充分性、判定依据合理性、KAA标准达成判断、后续跟踪安排四大要点。承接阶段前瞻性识别关键审计事项候选，有助于在计划阶段合理配置资源、明确重点审计领域，并为审计报告关键审计事项段落的最终确定奠定基础。

**法规依据：**
- 《中国注册会计师审计准则第1121号——对财务报表审计实施的质量管理》
- 《中国注册会计师审计准则第1201号——计划审计工作》
- 《中国注册会计师审计准则第1504号——在审计报告中沟通关键审计事项》

---

## tips

1. **KAA候选识别应覆盖高风险与重大判断领域**：重大错报风险较高的领域、涉及重大管理层判断的领域、重大交易或事项的影响均应作为候选来源，避免遗漏。
2. **判定应依据"给审计工作带来重大困难"的实质标准**：候选事项是否构成KAA，应基于其对审计的重要程度和沟通治理层的关注程度判断，而非机械套用清单。
3. **承接阶段的候选具有前瞻性和暂定性**：B1-5是初步识别，后续随审计推进应动态更新，任一判定项达标即应纳入KAA候选池。
4. **判定依据须与被审计单位实际结合**：收入确认、减值、公允价值、重大估计等通用领域须结合客户具体业务和风险实际说明理由。
5. **KAA候选应与风险评估与审计计划联动**：识别出的候选事项应影响资源配置和重点程序设计，并结转至审计报告阶段最终确定。
6. **审批与报备安排须落实**：达到KAA标准的候选事项应有恰当的内部审批及必要的报备安排，留痕完整。

## checklist

### 一、候选事项识别

- [ ] 是否覆盖了重大错报风险较高的领域作为候选来源
- [ ] 是否识别涉及重大管理层判断和会计估计的领域
- [ ] 是否考虑了本期重大交易、事项及重大变化的影响
- [ ] 是否结合行业特点识别行业特有的关键领域
- [ ] 候选事项是否与B50风险评估结果保持一致

### 二、判定依据与标准

- [ ] 每项候选是否说明了纳入的具体理由（结合客户实际）
- [ ] 判定是否基于对审计工作的重要程度和治理层关注程度
- [ ] 判定项达标情况是否清晰标注（是/否/待定）
- [ ] 任一判定项达标是否已触发纳入KAA候选池
- [ ] 综合判定结论是否与各判定项逻辑一致

### 三、后续跟踪与审批

- [ ] KAA候选是否已影响审计资源配置和重点程序设计
- [ ] 候选事项是否安排了后续动态更新与跟踪机制
- [ ] 达到KAA标准的事项是否经恰当层级审批
- [ ] 必要的报备安排是否已落实并留痕
- [ ] 候选池是否结转至审计报告阶段最终确定

## risk_areas

### 高风险

1. **重大高风险领域遗漏候选**：重大错报风险高的领域未纳入KAA候选，导致关键审计事项识别不完整，影响报告沟通质量。
2. **判定标准误用导致漏判**：机械套用清单而未依据"给审计工作带来重大困难"的实质标准，遗漏应披露的关键事项。
3. **候选与风险评估脱节**：KAA候选未与B50风险汇总保持一致，识别口径矛盾。

### 中风险

1. **判定理由缺乏针对性**：以通用模板理由代替结合客户实际的说明，判定依据不充分。
2. **候选未影响资源配置**：识别出候选却未在审计计划中相应配置资源和设计程序，识别流于形式。
3. **动态更新机制缺失**：承接阶段候选未安排后续跟踪更新，与最终报告阶段脱节。

### 低风险

1. **达标审批留痕不全**：达到KAA标准事项的审批或报备安排记录不完整。
2. **标注不清晰**：判定项达标情况标注模糊，影响复核判断效率。
3. **交叉索引缺失**：KAA候选未与B50及审计报告底稿建立索引引用。
