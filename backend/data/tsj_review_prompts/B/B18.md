# B18 了解内部审计程序表复核提示词

## 概述

本提示词针对了解内部审计底稿（B18）的复核，聚焦对被审计单位内部审计职能的了解是否充分、是否恰当评价内部审计的客观性与胜任能力、以及是否合理确定利用内部审计工作的范围。了解内部审计有助于识别控制环境线索并为是否利用内审工作提供依据，评价不当可能过度依赖不可靠的内审工作。

**法规依据：**
- 《中国注册会计师审计准则第1411号——利用内部审计人员的工作》
- 《中国注册会计师审计准则第1211号——通过了解被审计单位及其环境识别和评估重大错报风险》
- 《中国注册会计师审计准则第1231号——针对评估的重大错报风险采取的应对措施》

---

## tips

1. **了解内审是风险评估的组成部分**：即使不拟利用内审工作，了解内审职能的存在、地位和活动也有助于了解控制环境和识别风险（CAS1211）。
2. **利用内审工作前须评价三要素**：内部审计在组织中的地位与客观性、胜任能力、是否采用系统而规范的方法，三者缺一不可（CAS1411）。
3. **客观性评价关注组织地位与报告路径**：内审是否直接向治理层报告、是否独立于被评价的经营活动，决定其客观性。
4. **利用范围与程度须与风险匹配**：风险和判断程度越高的领域，可利用内审工作的程度越低，重大错报风险高的关键领域不宜过度依赖。
5. **拟利用的内审工作须复核与测试**：对拟利用的具体内审工作须评价其充分适当性，并实施必要的重新执行等测试。
6. **注册会计师承担全部审计责任**：利用内审工作不减轻注册会计师的审计责任，须保持足够的自身参与。

## checklist

### 一、内审职能了解

- [ ] 是否了解内部审计的职责范围、组织地位和报告路径
- [ ] 是否了解内审的年度计划及本期主要活动
- [ ] 内审活动是否与财务报表审计相关
- [ ] 是否了解内审发现的重大问题及整改情况

### 二、客观性与胜任能力评价

- [ ] 是否评价内审的组织地位与客观性（报告对象/独立性）
- [ ] 是否评价内审人员的专业胜任能力（资质/经验/培训）
- [ ] 是否评价内审是否采用系统而规范的方法（含质量控制）
- [ ] 是否存在影响内审客观性的因素（如兼任经营职务）

### 三、利用范围确定

- [ ] 拟利用内审工作的领域和范围是否与风险水平匹配
- [ ] 高风险/高判断领域是否避免过度依赖内审
- [ ] 拟利用的内审工作是否评价其充分适当性
- [ ] 是否对拟利用的内审工作实施了复核和必要测试

### 四、责任与记录

- [ ] 是否保持足够的自身审计参与（未过度依赖）
- [ ] 利用内审工作的决策依据是否记录
- [ ] 了解与评价结论是否与风险评估（B50）衔接

## risk_areas

### 高风险

1. **过度依赖不可靠内审**：在高风险领域过度利用客观性或胜任能力不足的内审工作，导致审计证据不充分。
2. **未评价即利用**：未评价内审客观性、胜任能力和方法规范性即利用其工作，违反 CAS1411。
3. **削弱自身责任**：以利用内审为由减少必要的自身审计程序，注册会计师审计责任未充分履行。

### 中风险

1. **客观性评价不足**：未关注内审报告路径和组织地位，客观性判断依据不充分。
2. **利用范围与风险不匹配**：利用程度未随风险和判断程度调整。
3. **拟利用工作未测试**：对拟利用的内审工作未实施复核或重新执行测试。

### 低风险

1. **了解记录不完整**：内审职能了解的记录简略。
2. **交叉索引缺失**：与风险评估、控制了解底稿的索引不完整。
3. **格式不规范**：评价结论表述格式不统一。
