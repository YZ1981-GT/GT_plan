# B51-3 识别对货币资金需保持警觉的情形复核提示词

## 概述

本提示词针对识别货币资金舞弊警觉情形底稿（B51-3）的复核，聚焦对货币资金领域舞弊风险迹象的识别是否全面、警觉情形的评估是否恰当、以及是否传导至货币资金实质性程序（E1）和舞弊风险评估。货币资金因流动性强、易被挪用和虚构，是舞弊高发领域，识别警觉情形有助于针对性设计审计程序。

**法规依据：**
- 《中国注册会计师审计准则第1141号——财务报表审计中与舞弊相关的责任》
- 《中国注册会计师审计准则第1211号——通过了解被审计单位及其环境识别和评估重大错报风险》

## tips

1. **货币资金舞弊迹象须系统识别**：包括大额闲置资金、异常大额或频繁的资金往来、受限资金未披露、境外或第三方账户、定期存单质押、资金体外循环等。
2. **关注资金与业务的匹配性**：资金收支是否与经营规模、收入成本匹配，无对应业务的大额资金流动是舞弊警觉信号。
3. **函证与银行账户完整性是关键**：识别是否存在未纳入账簿的银行账户、未函证的重要账户，防范隐匿账户和体外资金。
4. **受限与质押资金须警觉**：定期存单、保证金、被冻结/质押资金若未识别，可能掩盖对外担保或资金占用。
5. **企业信用报告是识别利器**：通过人民银行企业信用报告核对全部银行账户和授信，识别未入账账户和隐性负债。
6. **警觉情形须传导应对**：识别的警觉情形应传导至货币资金实质性程序（E1，如加强函证、监盘、截止测试）和舞弊风险评估（B50）。

## checklist

### 一、舞弊迹象识别

- [ ] 是否识别大额闲置资金及其合理性
- [ ] 是否识别异常大额或频繁的资金往来
- [ ] 是否识别无对应业务的大额资金流动
- [ ] 是否识别境外账户、第三方代收付等情形

### 二、账户完整性

- [ ] 是否关注可能存在未纳入账簿的银行账户
- [ ] 是否通过企业信用报告核对全部银行账户和授信
- [ ] 重要银行账户是否均纳入函证范围
- [ ] 是否识别销户/开户异常频繁的情况

### 三、受限与质押

- [ ] 是否识别定期存单、保证金等受限资金
- [ ] 是否识别被冻结/质押的货币资金
- [ ] 受限资金对应的担保/借款是否核查
- [ ] 受限资金披露是否完整

### 四、评估与传导

- [ ] 识别的警觉情形是否评估舞弊风险影响
- [ ] 是否传导至货币资金实质性程序（E1）加强应对
- [ ] 是否传导至舞弊风险评估（B50）
- [ ] 识别方法与结论是否完整记录

## risk_areas

### 高风险

1. **隐匿银行账户未识别**：存在未纳入账簿的银行账户或体外资金循环未被识别，货币资金存在性和完整性存疑。
2. **资金挪用/占用未警觉**：大额异常资金往来或无业务支撑的资金流动未识别，可能掩盖资金挪用或关联方占用。
3. **受限资金及关联担保未识别**：质押/冻结资金未识别，掩盖对外担保或有负债。

### 中风险

1. **资金与业务匹配性未分析**：资金收支与经营规模的匹配性未评估。
2. **信用报告未充分利用**：未通过企业信用报告核对账户完整性和授信。
3. **警觉情形未传导**：识别的情形未传导至 E1 程序和舞弊评估。

### 低风险

1. **识别记录不完整**：警觉情形识别过程记录简略。
2. **交叉索引缺失**：与 E1 货币资金、B50 舞弊评估的索引不完整。
3. **格式不规范**：识别结论表述格式不统一。
