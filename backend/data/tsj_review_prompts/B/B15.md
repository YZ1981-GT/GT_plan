# B15 重要性水平计算表 复核提示词

## 概述

本提示词针对重要性水平计算表（B15）的复核，聚焦基准选取合理性、比例运用适当性、实际执行重要性与明显微小错报临界值确定、重要性修订与运用四大要点。重要性水平是审计计划与执行的量化基准，贯穿风险评估、样本设计、错报评价全过程，其确定失当将直接影响审计程序的充分性和审计结论的可靠性。

**法规依据：**
- 《中国注册会计师审计准则第1221号——计划和执行审计工作时的重要性》
- 《中国注册会计师审计准则第1201号——计划审计工作》
- 《中国注册会计师审计准则第1211号——通过了解被审计单位及其环境识别和评估重大错报风险》

## tips

1. **基准选取应反映报表使用者关注点**：营业收入、资产总额、净利润、净资产、费用总额等基准的选取应结合被审计单位性质和报表使用者关注重点，而非机械套用。
2. **异常年度基准须审慎处理**：净利润在亏损或微利年度波动大，作为基准可能失真，应考虑采用正常化利润、三年平均或改用其他更稳定基准。
3. **比例运用应有合理依据**：所选比例应处于行业惯常区间，公开交易实体通常采用较低比例，比例选取应与风险水平相匹配。
4. **实际执行重要性须体现风险考量**：实际执行重要性（PM）通常为整体重要性的一定比例（如50%-75%），风险越高该比例应越低，以降低未更正与未发现错报累积超过重要性的概率。
5. **明显微小错报临界值须合理**：明显微小错报临界值（通常不超过整体重要性的5%）用于确定无需累积的错报门槛，设定过高将导致错报遗漏。
6. **重要性修订须留痕并贯彻**：审计过程中获取新信息导致重要性修订的，应记录修订原因并评估对已执行程序和样本量的影响。

## checklist

### 一、基准选取与计算依据

- [ ] 基准选取是否结合被审计单位性质和报表使用者关注点
- [ ] 是否说明了选取该基准的理由
- [ ] 异常年度（亏损/微利）是否对基准作正常化处理
- [ ] 计算基础是采用预测数、未审数还是三年平均，是否恰当
- [ ] 是否区分公开交易实体与非公开实体选取比例区间

### 二、比例与重要性水平

- [ ] 所选比例是否处于行业惯常区间且有依据
- [ ] 比例选取是否与被审计单位整体风险水平匹配
- [ ] 整体重要性计算是否准确（基准×比例）
- [ ] 是否为特定类别交易/账户/披露确定了较低重要性
- [ ] 特定类别重要性的确定理由是否充分

### 三、实际执行重要性与临界值

- [ ] 实际执行重要性（PM）比例是否体现风险考量
- [ ] PM确定是否降低了错报累积超重要性的概率
- [ ] 明显微小错报临界值是否合理（通常≤整体重要性5%）
- [ ] 临界值设定是否避免了错报遗漏
- [ ] 重要性各层级之间关系是否逻辑一致

### 四、修订与运用

- [ ] 审计过程中重要性是否需修订及是否记录原因
- [ ] 重要性修订是否评估了对样本量和已执行程序的影响
- [ ] 重要性是否已贯彻至风险评估和样本设计
- [ ] 重要性是否用于错报评价（链接至错报汇总）
- [ ] 重要性确定是否经恰当层级审核

## risk_areas

### 高风险

1. **基准选取不当致重要性失真**：在亏损或微利年度仍以净利润为基准且未正常化，重要性水平严重偏离合理区间。
2. **比例明显偏高**：所选比例超出行业惯常区间且无依据，导致重要性过高、审计程序不足。
3. **PM未体现风险**：高风险项目仍采用高比例PM，未降低错报累积超重要性的概率。
4. **临界值过高遗漏错报**：明显微小错报临界值设定过高，导致大量错报未被累积评价。

### 中风险

1. **基准理由不充分**：基准选取未说明理由或与报表使用者关注点不符。
2. **特定类别重要性缺失**：对存在较低错报容忍度的特定类别未单独确定重要性。
3. **重要性修订未贯彻**：修订后未重新评估对已执行程序和样本量的影响。

### 低风险

1. **计算过程记录不完整**：基准、比例、各层级重要性的计算过程留痕不充分。
2. **重要性未建立联动**：重要性水平未明确链接至样本设计和错报评价底稿。
3. **审核留痕缺失**：重要性确定未经恰当层级审核或审核未留痕。
