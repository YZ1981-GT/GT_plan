# B2 与前任注册会计师的沟通复核提示词

## 概述

本提示词针对与前任注册会计师沟通底稿（B2）的复核，聚焦首次接受委托前与前任的沟通程序是否充分执行、沟通内容是否完整、前任答复的评价是否恰当。首次审计业务中，与前任沟通是识别是否存在不宜承接情形、了解被审计单位诚信及重大分歧的关键程序，沟通缺失或流于形式将使承接决策失去重要依据。

**法规依据：**
- 《中国注册会计师审计准则第1153号——前任注册会计师和后任注册会计师的沟通》
- 《中国注册会计师审计准则第1101号——注册会计师的总体目标》
- 《中国注册会计师审计准则第1121号——对财务报表审计实施的质量管理》

---

## tips

1. **沟通须以取得被审计单位授权为前提**：后任在沟通前须取得被审计单位书面同意前任作出答复，被审计单位拒绝授权本身即为重要的承接预警信号，须评估拒绝原因。
2. **沟通内容须覆盖 CAS1153 规定事项**：包括被审计单位管理层诚信、前后任在会计/审计/报告方面的重大分歧、更换会计师事务所的原因、前任了解的舞弊或违反法规情况等，遗漏关键事项则沟通不充分。
3. **沟通时点须在接受委托之前**：与前任的沟通应在决定是否承接前完成，事后补做的沟通无法支持承接决策，属程序倒置。
4. **前任答复的评价须形成结论**：对前任答复（含拒绝或有限答复）须评价其对承接决策的影响，前任提示的重大问题须在后续审计计划中予以应对。
5. **前任拒绝或有限答复须实施替代程序**：前任未答复或答复受限时，后任须通过其他渠道（查询、走访、公开信息）了解相关情况并记录。
6. **沟通须完整留痕**：授权函、沟通函、前任答复、评价结论须完整归档，形成可追溯的证据链。

## checklist

### 一、沟通授权与时点

- [ ] 是否取得被审计单位书面授权同意前任作出答复
- [ ] 被审计单位拒绝授权的，是否评估原因并记录承接预警
- [ ] 沟通是否在接受委托之前完成
- [ ] 沟通函的发送、接收是否有记录

### 二、沟通内容完整性

- [ ] 是否询问被审计单位管理层诚信情况
- [ ] 是否询问前后任在会计/审计/报告方面的重大分歧
- [ ] 是否询问更换会计师事务所的原因
- [ ] 是否询问前任了解的舞弊、违反法规及关联方等情况
- [ ] 是否询问前任未收到审计费用等其他影响承接的事项

### 三、答复评价与替代程序

- [ ] 前任答复内容是否记录并评价其对承接决策的影响
- [ ] 前任提示的重大问题是否纳入后续审计计划应对
- [ ] 前任拒绝/有限答复的，是否实施替代程序了解情况
- [ ] 沟通结论是否明确（可承接/需进一步评估/不宜承接）

### 四、记录与归档

- [ ] 授权函、沟通函、前任答复、评价结论是否完整归档
- [ ] 沟通证据链是否可追溯
- [ ] 沟通结果是否与 B1 业务承接评估、B2-5 评价衔接

## risk_areas

### 高风险

1. **未与前任沟通即承接**：首次业务未执行前任沟通程序即接受委托，丧失识别不宜承接情形的关键依据，违反 CAS1153。
2. **忽视授权被拒的预警**：被审计单位拒绝授权前任答复却未评估原因仍承接，可能掩盖重大诚信或分歧问题。
3. **前任重大提示未应对**：前任提示的舞弊、重大分歧或管理层诚信问题未纳入审计计划应对，重大错报风险未被识别。

### 中风险

1. **沟通内容不完整**：遗漏诚信、重大分歧、更换原因等 CAS1153 关键询问事项，沟通证据力不足。
2. **替代程序缺失**：前任未答复或有限答复时未实施替代程序，无法弥补信息缺口。
3. **沟通时点倒置**：承接后补做沟通，无法支持已作出的承接决策。

### 低风险

1. **沟通记录不规范**：授权函/沟通函/答复归档不完整，影响可追溯性。
2. **评价结论笼统**：对前任答复的评价未形成明确结论。
3. **交叉索引缺失**：与 B1 承接评估、B2-5 评价的交叉引用不完整。
