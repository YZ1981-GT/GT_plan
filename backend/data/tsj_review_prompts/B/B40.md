# B40 审计项目组的讨论程序表 复核提示词

## 概述

本提示词针对审计项目组讨论程序表（B40）的复核，聚焦讨论参与充分性、讨论内容覆盖、舞弊风险专项讨论、讨论结论对审计计划的影响四大要点。项目组讨论（含关于舞弊导致的重大错报风险的讨论）是风险评估的必经程序，通过项目组成员就被审计单位易发生重大错报的领域交换意见，促进风险识别的全面性，讨论流于形式将削弱风险评估质量。

**法规依据：**
- 《中国注册会计师审计准则第1211号——通过了解被审计单位及其环境识别和评估重大错报风险》
- 《中国注册会计师审计准则第1141号——财务报表审计中与舞弊相关的责任》
- 《中国注册会计师审计准则第1201号——计划审计工作》

---

## tips

1. **讨论应有关键成员实质参与**：项目合伙人和关键项目组成员应参与讨论，仅由助理走过场记录不构成有效讨论。
2. **讨论内容应覆盖风险领域交流**：应就财务报表易发生重大错报的领域、被审计单位业务风险、会计政策适用等交换意见。
3. **舞弊风险讨论是强制专项内容**：项目组必须讨论财务报表因舞弊导致重大错报的可能性，包括收入确认舞弊推定和管理层凌驾风险。
4. **讨论应鼓励职业怀疑与质疑**：讨论应营造开放氛围，鼓励成员对管理层诚信和舞弊可能性保持职业怀疑并提出质疑。
5. **讨论结论须转化为审计计划输入**：讨论识别的风险领域和舞弊风险应结转至风险评估汇总（B50）和审计程序设计。
6. **讨论应留痕体现实质而非形式**：讨论记录应体现参与人员、讨论要点、达成的风险共识，而非仅记录"已讨论"。

## checklist

### 一、参与与实质性

- [ ] 项目合伙人是否参与了讨论
- [ ] 关键项目组成员是否实质参与
- [ ] 讨论是否为面对面或有效的交流形式
- [ ] 讨论是否体现成员间意见交换而非单向传达
- [ ] 是否营造了鼓励质疑的开放氛围

### 二、讨论内容覆盖

- [ ] 是否讨论了财务报表易发生重大错报的领域
- [ ] 是否讨论了被审计单位业务和行业风险
- [ ] 是否讨论了会计政策选用的适当性
- [ ] 是否讨论了重大交易和会计估计
- [ ] 讨论内容是否结合了被审计单位实际

### 三、舞弊风险专项与运用

- [ ] 是否专项讨论了舞弊导致重大错报的可能性
- [ ] 是否讨论了收入确认舞弊风险
- [ ] 是否讨论了管理层凌驾于控制之上的风险
- [ ] 讨论识别的风险是否结转至B50风险汇总
- [ ] 讨论结论是否影响审计程序设计

## risk_areas

### 高风险

1. **舞弊风险讨论缺失**：未专项讨论舞弊导致重大错报的可能性，违反准则强制要求，舞弊风险识别不完整。
2. **关键成员未参与**：项目合伙人或关键成员未参与讨论，讨论缺乏专业判断和权威性。
3. **讨论与审计计划脱节**：讨论识别的风险未结转风险评估和程序设计，讨论价值落空。

### 中风险

1. **讨论流于形式**：仅记录"已讨论"而无实质意见交换和风险共识。
2. **收入确认舞弊未讨论**：未讨论收入确认舞弊推定（除非可反驳）。
3. **管理层凌驾风险未讨论**：未讨论管理层凌驾于控制之上的风险。

### 低风险

1. **讨论记录不完整**：参与人员、讨论要点、结论记录不充分。
2. **讨论时点不当**：讨论在风险评估基本完成后进行，未起到促进识别作用。
3. **索引引用缺失**：讨论结论未与B50及舞弊风险底稿建立索引。
