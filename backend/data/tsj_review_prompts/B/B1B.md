# B1B 业务保持（续做决策）程序表 复核提示词

## 概述

本提示词针对业务保持（续做）决策程序表（B1B）的复核，聚焦续做程序执行完整性、变化与遗留问题评估、决策与评估一致性、审批与文档化四大要点。B1B是连续审计年度续做决策的程序性汇总底稿，串联客户情况变化评估、上年遗留问题跟踪、独立性持续确认等程序，最终形成是否继续承接的决策。复核重点在于验证续做是否基于对变化的实质评估而非惯性延续。

**法规依据：**
- 《中国注册会计师审计准则第1121号——对财务报表审计实施的质量管理》
- 《中国注册会计师审计准则第1101号——注册会计师的总体目标和审计工作的基本要求》
- 《中国注册会计师审计准则第1201号——计划审计工作》

---

## tips

1. **续做决策的实质是对变化和遗留问题的再评估**：程序表应体现对客户情况变化（B1-2）和上年遗留问题的实质跟踪，而非机械沿用上年承接结论。
2. **每一续做程序步骤应有本年执行结果**：独立性持续确认、变化评估、遗留问题跟踪等步骤应记录本年实际执行情况和结论。
3. **续做结论须与续做风险评估一致**：继续建议应与B1-2风险评估结果相匹配，风险升高仍续做须有额外应对说明。
4. **独立性持续满足须重新确认**：轮换要求、密切关系威胁、新增非审计服务等应在续做程序中重新评估。
5. **续做审批权限须与风险等级匹配**：风险升高的续做业务不得因连续合作省略应有审批层级。
6. **文档化应支持续做决策可追溯**：续做决策依据的变化评估、遗留问题跟踪、审批记录应完整归档。

## checklist

### 一、续做程序执行完整性

- [ ] 客户情况变化评估（B1-2）是否已执行并记录本年结论
- [ ] 上年遗留问题（重大风险/审计调整/内控缺陷/意见类型）是否已跟踪
- [ ] 独立性持续满足确认是否完成（含轮换要求）
- [ ] 胜任能力与资源是否仍匹配本年业务需求
- [ ] 各续做程序步骤是否均有本年实际执行结果

### 二、变化与遗留问题评估

- [ ] 客户经营、治理、财务状况的重大变化是否已实质评估
- [ ] 上年重大风险本年是否仍存续及应对是否升级
- [ ] 上年审计调整是否已入账、内控缺陷是否已整改
- [ ] 新增诉讼、监管、诚信负面信号是否已识别
- [ ] 持续经营能力较上年变化是否已评估

### 三、决策一致性与审批

- [ ] 续做决策是否与B1-2风险评估结果一致
- [ ] 风险升高仍续做时是否有额外应对说明
- [ ] 续做决策是否经与风险等级匹配的层级审批
- [ ] 审批人签字、日期是否完整且早于外勤开始
- [ ] 续做决策相关文档是否完整归档、可追溯

## risk_areas

### 高风险

1. **惯性续做未评估变化**：程序表未体现对客户重大变化的实质评估，机械延续上年结论即续做。
2. **重大遗留问题未解决仍续做**：上年重大风险或内控缺陷持续存在，续做未升级应对。
3. **续做与风险评估背离**：B1-2评为风险升高却无额外应对措施即续做。
4. **独立性持续要求未确认**：合伙人轮换到期或密切关系威胁未在续做程序中重新评估。

### 中风险

1. **续做程序步骤空转**：仅勾选"已完成"而无本年实质执行结果。
2. **遗留问题跟踪不完整**：上年审计调整入账、缺陷整改缺乏后续验证。
3. **新增风险信号遗漏**：本年新增诉讼、监管或诚信信号未在续做评估中反映。

### 低风险

1. **审批时序倒置**：续做审批晚于外勤开始。
2. **上年数据未刷新**：程序表沿用上年字段未更新至本年。
3. **索引引用缺失**：续做程序表未与B1-2风险评估建立索引。
