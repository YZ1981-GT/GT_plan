# B30-12 指令-已识别组成部分错报汇总表 复核提示词

## 概述

本提示词针对指令性质的已识别组成部分错报汇总表（B30-12）的复核，聚焦错报汇集完整性、错报性质分类、集团层面影响评估、汇总与错报评价联动四大要点。B30-12汇集各组成部分注册会计师报告的已识别错报，供集团项目组在合并层面评价错报累积影响，是集团审计错报评价链条的关键节点，汇集遗漏将导致集团层面错报评价失真。

**法规依据：**
- 《中国注册会计师审计准则第1401号——对集团财务报表审计的特殊考虑》
- 《中国注册会计师审计准则第1251号——评价审计过程中识别出的错报》

---

## tips

1. **错报汇集应覆盖所有报告错报的组成部分**：各组成部分注册会计师报告的已更正和未更正错报均应完整汇集，遗漏任一组成部分将低估集团错报。
2. **错报应区分已更正与未更正**：已更正错报和未更正错报对集团财务报表的影响不同，应分类汇总，未更正错报是集团层面评价的重点。
3. **组成部分错报须考虑对合并层面的影响**：组成部分层面的错报经合并抵销、少数股东权益分摊后对集团报表的影响可能变化，应评估合并后净影响。
4. **错报性质分类有助于识别系统性问题**：错报应按性质（事实错报/判断错报/推断错报）和成因分类，同类错报在多组成部分重复出现可能指向系统性问题。
5. **汇总须与集团整体重要性对照**：汇集的错报累积影响应与集团整体重要性和实际执行重要性对照，判断是否需进一步调整或影响意见。
6. **汇总须联动集团错报评价**：B30-12的汇集结果应结转至集团层面未更正错报汇总和错报评价，形成完整链条。

## checklist

### 一、错报汇集完整性

- [ ] 是否汇集了所有报告错报的组成部分
- [ ] 各组成部分报告的错报是否完整录入
- [ ] 是否区分了已更正错报和未更正错报
- [ ] 错报金额、科目、认定是否准确记录
- [ ] 是否确认无组成部分错报遗漏汇集

### 二、性质分类与合并影响

- [ ] 错报是否按性质分类（事实/判断/推断）
- [ ] 是否分析同类错报在多组成部分的重复出现
- [ ] 组成部分错报经合并抵销后的净影响是否评估
- [ ] 少数股东权益分摊对错报影响是否考虑
- [ ] 系统性错报迹象是否识别

### 三、汇总与错报评价

- [ ] 错报累积影响是否与集团整体重要性对照
- [ ] 累积未更正错报是否评估是否超过重要性
- [ ] 汇集结果是否结转集团未更正错报汇总
- [ ] 汇集是否联动集团错报评价和意见判断
- [ ] 重大错报是否提请集团项目组和治理层关注

## risk_areas

### 高风险

1. **组成部分错报遗漏汇集**：未汇集全部报告错报的组成部分，低估集团层面错报累积影响。
2. **未更正错报累积超重要性未识别**：各部分单项未超重要性但合并累积超过集团重要性却未评价。
3. **合并影响评估缺失**：仅简单相加组成部分错报而未考虑合并抵销和少数股东权益影响。

### 中风险

1. **错报性质未分类**：未按性质分类，无法识别系统性错报迹象。
2. **同类错报重复未关注**：多组成部分出现同类错报未识别为系统性问题。
3. **汇集与评价脱节**：汇集结果未结转集团错报评价。

### 低风险

1. **错报记录不完整**：错报金额、科目、认定记录不充分。
2. **分类标注不清**：已更正/未更正标注不清晰。
3. **索引引用缺失**：汇总未与集团错报评价及组成部分沟通底稿建立索引。
