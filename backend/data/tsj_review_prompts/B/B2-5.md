# B2-5 与前任注册会计师沟通后的评价复核提示词

## 概述

本提示词针对与前任注册会计师沟通后的评价底稿（B2-5）的复核，聚焦对前任答复的分析、对承接决策及审计计划影响的评价、以及后续应对措施的恰当性。B2-5 是 B2 沟通程序的结论环节，须将前任提供的信息转化为承接判断和风险应对，评价缺失将使沟通程序失去价值。

**法规依据：**
- 《中国注册会计师审计准则第1153号——前任注册会计师和后任注册会计师的沟通》
- 《中国注册会计师审计准则第1121号——对财务报表审计实施的质量管理》

---

## tips

1. **评价须基于前任答复的实质内容**：逐项分析前任答复中反映的管理层诚信、重大分歧、更换原因等信息，判断其对本所承接及审计的影响，而非简单记录"无异常"。
2. **重大分歧须评估对审计计划的影响**：前后任在会计处理或审计结论上的重大分歧，须评估相关领域的重大错报风险并在审计计划中加强应对。
3. **管理层诚信疑虑须提升风险评估**：前任提示的诚信问题应传导至舞弊风险评估（B50/B52）和承接决策（B1）。
4. **前任答复受限须评估证据充分性**：前任拒绝或有限答复时，须评价已获信息是否足以支持承接决策，不足的须说明替代程序及其结论。
5. **评价结论须可操作**：结论应明确对承接决策（承接/附条件/不承接）和审计计划（需加强的领域）的具体影响。
6. **评价须与后续底稿衔接**：评价发现须传导至 B1 承接、B15 重要性、B50 风险评估等相关计划底稿。

---

## checklist

### 一、答复分析

- [ ] 是否逐项分析前任答复的实质内容
- [ ] 管理层诚信相关信息是否分析并形成判断
- [ ] 前后任重大分歧是否分析其性质和影响
- [ ] 更换事务所原因是否评价其合理性

### 二、对承接与计划的影响

- [ ] 是否评价前任答复对承接决策的影响
- [ ] 重大分歧涉及领域是否评估重大错报风险
- [ ] 前任提示的舞弊/违规是否传导至舞弊风险评估
- [ ] 需加强应对的领域是否在审计计划中反映

### 三、答复受限的处理

- [ ] 前任拒绝/有限答复时是否评价已获信息充分性
- [ ] 替代程序及其结论是否记录
- [ ] 信息不足是否影响承接决策并说明

### 四、结论与衔接

- [ ] 评价结论是否明确（承接/附条件/不承接）
- [ ] 评价发现是否传导至 B1/B15/B50/B52 等底稿
- [ ] 评价过程与结论是否完整记录

## risk_areas

### 高风险

1. **评价流于形式**：仅记录"沟通无异常"而未实质分析前任答复，使沟通程序丧失对承接决策的支持作用。
2. **重大分歧未传导应对**：前任提示的重大会计/审计分歧未评估风险、未纳入审计计划，重大错报风险漏应对。
3. **诚信疑虑被忽视**：前任反映的管理层诚信问题未影响承接决策和舞弊风险评估。

### 中风险

1. **答复受限未评估充分性**：前任有限答复时未评价信息是否足以支持承接。
2. **结论不可操作**：评价结论未明确对承接和审计计划的具体影响。
3. **衔接不足**：评价发现未传导至相关计划底稿。

### 低风险

1. **记录不完整**：评价分析过程记录简略。
2. **交叉索引缺失**：与 B2、B1 及风险评估底稿的索引不完整。
3. **格式不规范**：评价结论表述格式不统一。
