# B52 管理层凌驾于控制之上复核提示词

## 概述

本提示词针对管理层凌驾于控制之上底稿（B52）的复核，聚焦针对管理层凌驾这一所有主体固有特别风险所设计和执行的审计程序是否充分，包括会计分录测试、会计估计复核、重大非常规交易的商业理由评价。管理层凌驾是舞弊导致重大错报的主要途径，CAS1141 要求对所有主体强制实施相应程序。

**法规依据：**
- 《中国注册会计师审计准则第1141号——财务报表审计中与舞弊相关的责任》
- 《中国注册会计师审计准则第1231号——针对评估的重大错报风险采取的应对措施》
- 《中国注册会计师审计准则第1211号——通过了解被审计单位及其环境识别和评估重大错报风险》

---

## tips

1. **管理层凌驾是强制应对的特别风险**：无论是否识别出具体舞弊风险，对所有主体均须实施 CAS1141 规定的应对程序，不得省略。
2. **会计分录测试是核心程序**：须测试总账中记录的会计分录和其他调整，重点关注非常规、期末、重大手工分录及异常科目组合（如收入对现金以外科目、异常对方科目）。
3. **会计估计复核关注管理层偏向**：复核会计估计是否存在可能导致重大错报的管理层偏向，包括回顾上期估计与实际的差异（后见测试）。
4. **重大非常规交易评价商业理由**：对超出正常经营的重大交易，评价其商业理由是否合理，是否为粉饰报表或掩盖舞弊/利益输送而安排。
5. **分录测试须覆盖完整总体并合理选取**：分录测试总体应完整（含所有分录来源），选取标准应针对舞弊特征（金额/时间/科目组合/录入人）。
6. **保持职业怀疑**：对管理层解释不轻信，异常分录和交易须获取佐证，凌驾迹象须评估对整体审计的影响。

## checklist

### 一、会计分录测试

- [ ] 是否测试总账会计分录和其他调整
- [ ] 分录测试总体是否完整（覆盖所有分录来源系统）
- [ ] 样本选取是否针对舞弊特征（非常规/期末/手工/异常科目组合）
- [ ] 异常分录是否核对原始凭证并评价业务实质
- [ ] 是否关注收入确认相关的异常分录

### 二、会计估计复核

- [ ] 是否复核重大会计估计是否存在管理层偏向
- [ ] 是否实施上期估计与实际结果的回顾（后见测试）
- [ ] 会计估计的关键假设是否评价其中立性
- [ ] 发现的偏向迹象是否评估对整体的影响

### 三、重大非常规交易

- [ ] 是否识别超出正常经营的重大交易
- [ ] 重大非常规交易的商业理由是否评价其合理性
- [ ] 是否关注与关联方的重大非常规交易
- [ ] 交易是否存在为粉饰报表/掩盖舞弊而安排的迹象

### 四、结论与联动

- [ ] 管理层凌驾程序执行结果是否形成结论
- [ ] 发现的凌驾迹象是否评估对审计意见的影响
- [ ] 是否与舞弊风险评估（B50）、关联方（B19）联动
- [ ] 是否与 C23 会计分录控制测试衔接

## risk_areas

### 高风险

1. **未实施管理层凌驾程序**：未对所有主体强制执行分录测试等程序，违反 CAS1141 强制要求，舞弊风险未被应对。
2. **分录测试总体不完整**：分录测试遗漏部分分录来源，异常舞弊分录未进入测试范围。
3. **会计估计偏向未识别**：未复核估计中的管理层偏向或未做后见测试，通过估计操纵利润未被发现。

### 中风险

1. **样本选取无舞弊针对性**：分录选取未针对舞弊特征，测试有效性不足。
2. **非常规交易商业理由未评价**：重大非常规交易未评价商业实质，可能掩盖粉饰或利益输送。
3. **职业怀疑不足**：轻信管理层解释，异常事项未获取佐证。

### 低风险

1. **记录不完整**：分录选取标准和测试结果记录简略。
2. **联动不足**：与舞弊评估、关联方、控制测试底稿的关联不清。
3. **交叉索引缺失**：与 B50、C23 的索引不完整。
