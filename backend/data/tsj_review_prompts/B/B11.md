# B11 检查相关信息程序表 复核提示词

## 概述

本提示词针对检查相关信息程序表（B11）的复核，聚焦信息来源完整性、检查程序适当性、信息可靠性评价、检查结论对风险评估的支持四大要点。B11是了解被审计单位过程中通过检查外部与内部相关信息（公开资料、监管信息、行业数据、内部文件等）以佐证和补充风险评估的程序，其价值在于提供独立于管理层的信息来源。

**法规依据：**
- 《中国注册会计师审计准则第1211号——通过了解被审计单位及其环境识别和评估重大错报风险》
- 《中国注册会计师审计准则第1301号——审计证据》
- 《中国注册会计师审计准则第1201号——计划审计工作》

## tips

1. **检查信息来源应兼顾内部与外部、独立与非独立**：工商登记、监管公告、行业报告、征信、诉讼记录等外部独立信息价值高于管理层提供的内部资料。
2. **信息可靠性须评价而非照单全收**：应评估信息来源的独立性、权威性、时效性，外部独立来源的可靠性通常更高。
3. **检查应聚焦对风险评估有影响的信息**：检查目的是佐证或修正风险判断，无关信息的堆砌不构成有效程序。
4. **检查发现的矛盾信息须追查**：外部信息与管理层陈述不一致时应保持职业怀疑，追查差异原因。
5. **检查结论应支持或修正风险评估**：检查获取的信息应明确其对报表层次或认定层次风险评估的影响。
6. **信息检查的时效性须关注**：过期信息可能失去佐证价值，应确认所检查信息反映当前实际状况。

## checklist

### 一、信息来源完整性

- [ ] 是否检查了工商登记、股权结构等基础工商信息
- [ ] 是否检查了监管公告、处罚记录等监管信息
- [ ] 是否检查了行业报告、市场数据等行业信息
- [ ] 是否检查了诉讼、失信、征信等风险信息
- [ ] 是否检查了内部治理文件、重大合同等内部信息

### 二、检查程序与可靠性

- [ ] 检查程序是否覆盖了对风险评估有影响的关键信息
- [ ] 信息来源的独立性和权威性是否已评价
- [ ] 信息的时效性是否确认反映当前状况
- [ ] 外部独立信息是否用于佐证管理层陈述
- [ ] 检查方法和范围是否与信息重要性匹配

### 三、检查结论与风险支持

- [ ] 检查发现的矛盾或异常信息是否已追查
- [ ] 检查结论是否明确对风险评估的影响
- [ ] 检查获取的风险信号是否结转至风险评估汇总
- [ ] 检查是否补充或修正了通过询问获取的了解
- [ ] 重大发现是否提请审计计划关注

## risk_areas

### 高风险

1. **关键风险信息未检查**：监管处罚、重大诉讼、失信记录等重大风险信息未检查，遗漏重大风险信号。
2. **矛盾信息未追查**：外部信息与管理层陈述矛盾却未保持职业怀疑追查原因，可能掩盖重大问题。
3. **信息可靠性未评价即采用**：对来源不可靠或过期的信息未加评价直接用于风险判断。

### 中风险

1. **信息来源单一**：主要依赖管理层提供的内部信息，缺乏外部独立信息佐证。
2. **检查与风险评估脱节**：检查信息未明确其对风险评估的影响，程序价值未实现。
3. **时效性未关注**：所检查信息可能已过期，佐证价值下降。

### 低风险

1. **信息记录不完整**：检查信息的来源、时点、结论记录不充分。
2. **无关信息堆砌**：检查记录中包含大量与风险评估无关的信息。
3. **索引引用缺失**：检查结论未与风险评估底稿建立索引。
