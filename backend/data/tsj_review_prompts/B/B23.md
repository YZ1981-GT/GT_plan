# B23 业务层面控制-职责分离分析表 复核提示词

## 概述

本提示词针对业务层面控制中的职责分离分析表（B23）的复核，聚焦不相容职务识别完整性、职责分离评价准确性、控制缺陷判定合理性、缺陷影响与联动四大要点。职责分离是业务流程层面控制的核心，不相容职务未分离将形成舞弊和错报的控制缺口，B23通过分析关键岗位的职责配置识别控制设计缺陷，为控制风险评估提供依据。

**法规依据：**
- 《中国注册会计师审计准则第1211号——通过了解被审计单位及其环境识别和评估重大错报风险》
- 《中国注册会计师审计准则第1231号——针对评估的重大错报风险采取的应对措施》
- 《中国注册会计师审计准则第1141号——财务报表审计中与舞弊相关的责任》

---

## tips

1. **不相容职务识别应覆盖关键循环**：授权、执行、记录、保管、复核五类职能在销售收款、采购付款、货币资金、存货、薪酬等循环中的分离应逐一分析。
2. **职责分离评价应实质而非仅看岗位名称**：应关注实际操作权限（如系统权限、印章保管、审批权限）是否真正分离，而非仅凭组织架构图上的岗位设置。
3. **货币资金相关职责分离是重中之重**：出纳与会计、审批与执行、印鉴与票据保管的分离对防范资金舞弊至关重要，应作为重点分析对象。
4. **小规模主体的固有局限须客观评估**：人员精简的小规模主体职责分离受限是固有局限，应评估管理层是否有补偿性控制（如所有者亲自监督）。
5. **职责分离缺陷须判定严重程度**：识别出的分离缺失应判定为一般缺陷、重要缺陷或重大缺陷，并评估对相关认定重大错报风险的影响。
6. **缺陷须联动控制风险评估与舞弊考虑**：职责分离缺陷应结转至控制风险评估和舞弊风险考虑，尤其是可能被管理层凌驾的领域。

## checklist

### 一、不相容职务识别

- [ ] 是否覆盖了授权、执行、记录、保管、复核五类职能
- [ ] 是否分析了各关键循环的职责分离状况
- [ ] 是否识别了货币资金相关的不相容职务
- [ ] 是否关注了系统权限、印章、审批权限的实际分配
- [ ] 不相容职务清单是否完整

### 二、职责分离评价

- [ ] 职责分离评价是否基于实际操作权限而非仅岗位名称
- [ ] 是否识别出一人身兼不相容职务的情形
- [ ] 出纳与会计、审批与执行是否有效分离
- [ ] 印鉴、票据、资产保管是否与相关记账分离
- [ ] 小规模主体固有局限是否评估补偿性控制

### 三、缺陷判定与联动

- [ ] 识别出的分离缺失是否判定了严重程度
- [ ] 缺陷是否评估了对相关认定重大错报风险的影响
- [ ] 可能被管理层凌驾的分离缺陷是否特别关注
- [ ] 缺陷是否结转至控制风险评估
- [ ] 舞弊相关的分离缺陷是否结转至舞弊风险考虑

## risk_areas

### 高风险

1. **货币资金职责未分离**：出纳兼会计、审批兼执行、印鉴与票据集中保管，形成资金舞弊的重大控制缺口。
2. **关键不相容职务漏识别**：授权、执行、记录、保管、复核职能的重大交叉未被识别，控制缺陷评估不完整。
3. **缺陷严重程度误判**：将重大控制缺陷判定为一般缺陷，低估控制风险，影响后续审计程序。
4. **缺陷与风险评估脱节**：职责分离缺陷未联动控制风险评估和舞弊考虑。

### 中风险

1. **仅看岗位名称评价**：未穿透实际操作权限（系统权限/印章/审批）评价分离,评价流于形式。
2. **补偿性控制未评估**：小规模主体固有局限下未评估管理层补偿性控制。
3. **分析循环不全**：仅分析部分循环的职责分离，覆盖不完整。

### 低风险

1. **分析记录不完整**：职责分离分析的岗位、权限、结论记录不充分。
2. **缺陷描述不清**：识别出的缺陷描述笼统，不便于后续跟踪。
3. **索引引用缺失**：缺陷未与控制风险评估及舞弊风险底稿建立索引。
