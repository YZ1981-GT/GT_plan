# B5 审计计划相关程序表 复核提示词

## 概述

本提示词针对审计计划相关程序表（B5）的复核，聚焦计划程序执行完整性、总体审计策略与具体计划衔接、风险评估与计划匹配、计划文档化四大要点。审计计划是将风险评估转化为具体审计行动的桥梁，涵盖总体审计策略制定和具体审计计划编制，计划失当将导致审计程序缺乏针对性、资源配置不合理。

**法规依据：**
- 《中国注册会计师审计准则第1201号——计划审计工作》
- 《中国注册会计师审计准则第1211号——通过了解被审计单位及其环境识别和评估重大错报风险》
- 《中国注册会计师审计准则第1231号——针对评估的重大错报风险采取的应对措施》

---

## tips

1. **计划程序应涵盖策略与具体计划两个层次**：总体审计策略（范围、时间、方向）和具体审计计划（风险评估程序、进一步审计程序的性质时间范围）均应制定。
2. **计划应建立在风险评估基础之上**：审计计划应针对识别的重大错报风险设计应对，脱离风险评估的计划无针对性。
3. **总体策略与具体计划须衔接一致**：具体审计计划应贯彻总体审计策略确定的方向和重点，二者不应脱节或矛盾。
4. **资源配置应与风险和重要性匹配**：项目组人员构成、时间安排、专家利用应与被审计单位规模、复杂度、风险水平相匹配。
5. **计划应保持灵活可修订**：计划并非一成不变，审计过程中获取新信息应及时修订计划并记录原因。
6. **计划须经恰当层级审核**：审计计划应经项目合伙人审核批准，确保方向和资源配置恰当。

## checklist

### 一、计划程序执行完整性

- [ ] 是否制定了总体审计策略（范围/时间/方向）
- [ ] 是否编制了具体审计计划
- [ ] 是否确定了风险评估程序的性质、时间和范围
- [ ] 是否确定了进一步审计程序的性质、时间和范围
- [ ] 计划程序各步骤是否均已执行并记录

### 二、策略与计划衔接

- [ ] 总体审计策略确定的重点是否在具体计划中贯彻
- [ ] 总体策略与具体计划是否一致无矛盾
- [ ] 计划是否针对识别的重大错报风险设计应对
- [ ] 特别风险是否安排了针对性程序
- [ ] 计划是否体现了对高风险领域的资源倾斜

### 三、资源匹配与审核

- [ ] 项目组人员构成是否与业务复杂度匹配
- [ ] 时间安排是否合理且满足报告时限
- [ ] 是否安排了必要的专家利用
- [ ] 计划是否可根据新信息修订并记录原因
- [ ] 审计计划是否经项目合伙人审核批准

## risk_areas

### 高风险

1. **计划脱离风险评估**：审计计划未针对识别的重大错报风险设计应对，程序缺乏针对性。
2. **特别风险无针对性程序**：识别的特别风险未在计划中安排针对性审计程序。
3. **策略与计划脱节**：总体策略确定的重点未在具体计划中贯彻，方向落空。
4. **资源配置严重不足**：人员或时间配置明显不足以完成必要审计程序。

### 中风险

1. **计划程序不完整**：总体策略或具体计划部分要素缺失。
2. **资源与风险不匹配**：高风险领域资源投入不足或未倾斜。
3. **计划僵化未修订**：获取新信息后未及时修订计划。

### 低风险

1. **计划审核留痕缺失**：审计计划未经审核或审核未留痕。
2. **计划记录不完整**：计划要素记录不充分。
3. **索引引用缺失**：计划未与风险评估及具体循环程序建立索引。
