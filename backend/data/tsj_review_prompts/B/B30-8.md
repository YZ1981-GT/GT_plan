# B30-8 组成部分注册会计师沟通 复核提示词

## 概述

本提示词针对组成部分注册会计师沟通程序（B30-8）的复核，聚焦沟通指令完整性、沟通事项充分性、组成部分反馈评价、沟通结论运用四大要点。集团项目组与组成部分注册会计师的双向沟通是集团审计协作的纽带，集团须明确传达要求（指令），组成部分须及时反馈工作结果和发现，沟通不畅将导致集团层面遗漏组成部分识别的重大事项。

**法规依据：**
- 《中国注册会计师审计准则第1401号——对集团财务报表审计的特殊考虑》
- 《中国注册会计师审计准则第1151号——与治理层的沟通》
- 《中国注册会计师审计准则第1121号——对财务报表审计实施的质量管理》

---

## tips

1. **集团指令应明确、完整、及时**：集团项目组应向组成部分注册会计师明确传达工作范围、重要性、报告要求、时间安排、集团层面风险等，指令模糊将导致工作偏差。
2. **沟通应双向而非单向下达**：集团既要下达要求，也应获取组成部分注册会计师对合并层面相关事项的反馈，双向沟通才完整。
3. **沟通事项须覆盖关键内容**：独立性确认、遵守集团要求、已识别错报、发现的舞弊或违规、内控缺陷、未决事项等关键内容应完整沟通。
4. **组成部分反馈须评价而非仅接收**：应评价组成部分注册会计师反馈的完整性和其工作是否满足集团要求，异常反馈应追查。
5. **沟通中的重大发现须结转集团层面**：组成部分反馈的重大错报、舞弊、内控缺陷应结转集团层面评估和错报汇总。
6. **沟通须及时以支持集团审计进度**：沟通时点应配合集团审计整体进度，滞后沟通可能影响集团意见形成。

## checklist

### 一、集团指令完整性

- [ ] 是否向组成部分注册会计师明确传达了工作范围
- [ ] 是否传达了组成部分重要性水平和报告门槛
- [ ] 是否传达了集团层面识别的相关风险
- [ ] 是否传达了报告要求、格式和时间安排
- [ ] 指令是否明确、完整、及时

### 二、沟通事项充分性

- [ ] 是否要求组成部分注册会计师确认独立性和遵守集团要求
- [ ] 是否要求报告已识别的错报
- [ ] 是否要求报告发现的舞弊、违规或重大内控缺陷
- [ ] 是否要求报告未决事项和限制情形
- [ ] 沟通是否为双向（下达要求+获取反馈）

### 三、反馈评价与运用

- [ ] 组成部分反馈的完整性是否评价
- [ ] 反馈工作是否满足集团要求是否评价
- [ ] 异常或不完整反馈是否追查
- [ ] 反馈的重大发现是否结转集团层面评估
- [ ] 沟通时点是否配合集团审计进度

## risk_areas

### 高风险

1. **集团指令缺失关键内容**：未传达组成部分重要性、集团层面风险或报告要求，导致组成部分工作偏离集团需要。
2. **组成部分重大发现未结转**：组成部分反馈的舞弊、重大错报或内控缺陷未结转集团层面评估。
3. **反馈未评价即采用**：未评价组成部分反馈的完整性和工作充分性即采用其结果。

### 中风险

1. **单向沟通**：仅下达要求而未获取组成部分对合并相关事项的反馈。
2. **沟通事项不全**：独立性确认、未决事项等关键内容未纳入沟通。
3. **异常反馈未追查**：组成部分异常或不完整反馈未追查原因。

### 低风险

1. **沟通时点滞后**：沟通未配合集团审计进度，影响意见形成节奏。
2. **沟通记录不完整**：指令下达和反馈接收的记录不充分。
3. **索引引用缺失**：沟通结论未与B30及错报汇总底稿建立索引。
