# B30 集团审计程序表 复核提示词

## 概述

本提示词针对集团审计程序表（B30）的复核，聚焦组成部分识别与重要性划分、集团层面风险评估、组成部分审计工作范围确定、集团项目组参与程度四大要点。集团财务报表审计涉及多个组成部分和组成部分注册会计师，集团项目组须对合并财务报表整体发表意见，程序设计失当将导致重要组成部分覆盖不足或合并层面风险遗漏。

**法规依据：**
- 《中国注册会计师审计准则第1401号——对集团财务报表审计的特殊考虑》
- 《中国注册会计师审计准则第1211号——通过了解被审计单位及其环境识别和评估重大错报风险》
- 《中国注册会计师审计准则第1231号——针对评估的重大错报风险采取的应对措施》

---

## tips

1. **组成部分识别与重要性划分是集团审计起点**：应识别所有组成部分并基于财务重要性和特定风险划分为重要组成部分与非重要组成部分，划分标准应有依据。
2. **集团层面重大错报风险须单独评估**：合并抵销、商誉减值、内部交易、跨部门舞弊等集团层面特有风险应在集团层面识别评估，不能仅汇总各部分。
3. **组成部分审计工作类型须与其重要性匹配**：财务重要的组成部分应实施整体审计，特定风险重要的应实施特定项目审计，非重要部分实施分析程序。
4. **集团项目组对重要组成部分参与程度须充分**：对重要组成部分，集团项目组应参与其风险评估、审阅其工作底稿或亲自实施部分程序。
5. **组成部分注册会计师的胜任能力与独立性须评价**：利用组成部分注册会计师工作前应评价其专业胜任能力、独立性及所处监管环境。
6. **合并流程与抵销分录须专门审计**：合并范围、合并抵销分录、少数股东权益、内部往来抵销等合并环节应设计专门程序。

## checklist

### 一、组成部分识别与重要性

- [ ] 是否识别了集团所有组成部分（子公司/分支/合营联营）
- [ ] 组成部分是否按财务重要性和特定风险分类
- [ ] 重要组成部分的划分标准是否有依据
- [ ] 组成部分重要性水平的确定是否恰当（低于集团整体）
- [ ] 合并范围是否完整、无遗漏或不当纳入

### 二、集团层面风险评估

- [ ] 是否单独识别评估了集团层面重大错报风险
- [ ] 商誉减值、合并抵销、内部交易风险是否评估
- [ ] 跨组成部分舞弊风险是否考虑
- [ ] 集团统一会计政策的一致性风险是否评估
- [ ] 集团层面风险是否结转应对措施

### 三、审计范围与参与程度

- [ ] 各组成部分审计工作类型是否与其重要性匹配
- [ ] 重要组成部分是否实施整体审计或特定项目审计
- [ ] 集团项目组对重要组成部分参与程度是否充分
- [ ] 组成部分注册会计师胜任能力和独立性是否评价
- [ ] 合并流程和抵销分录是否设计专门审计程序

## risk_areas

### 高风险

1. **重要组成部分覆盖不足**：财务重要的组成部分未实施整体审计，集团意见缺乏充分证据支持。
2. **集团层面风险遗漏**：商誉减值、合并抵销、内部交易等集团特有风险未在集团层面评估。
3. **合并范围错误**：应纳入合并的主体遗漏或不应纳入的主体错误合并，导致合并报表重大错报。
4. **组成部分注册会计师未评价即依赖**：未评价其胜任能力和独立性即利用其工作。

### 中风险

1. **重要性划分无依据**：组成部分重要性划分标准不清晰，覆盖范围合理性存疑。
2. **参与程度不足**：对重要组成部分未参与风险评估或审阅底稿。
3. **抵销分录审计不足**：内部往来抵销、少数股东权益等合并环节缺乏专门程序。

### 低风险

1. **组成部分清单记录不完整**：组成部分识别及分类记录不充分。
2. **审计范围说明不清**：各部分审计工作类型的确定理由记录笼统。
3. **索引引用缺失**：集团程序表未与组成部分沟通及汇总底稿建立索引。
