# B19-1 识别未披露关联方复核提示词

## 概述

本提示词针对识别未披露关联方及关联交易底稿（B19-1）的复核，聚焦对隐性关联方的主动识别、异常交易特征的分析、以及未披露关联方对披露完整性和舞弊风险的影响评估。未披露关联方是掩盖利益输送、虚增收入、资金占用的隐蔽通道，须运用多维度信号穿透识别。

**法规依据：**
- 《中国注册会计师审计准则第1323号——关联方》
- 《中国注册会计师审计准则第1141号——财务报表审计中与舞弊相关的责任》

---

## tips

1. **未披露关联方识别须主动穿透**：不能仅依赖管理层申报，须通过股权穿透、共同董监高、共用地址电话账户、异常一致的经营特征等主动识别隐性关联方（CAS1323）。
2. **多维度信号交叉识别**：客户/供应商与被审计单位共用联系方式或银行账户、高管重叠、成立时间与合作时间高度吻合、只与被审计单位交易，均为隐性关联信号。
3. **以第三方名义的关联交易须警惕**：通过表面独立的第三方进行受控交易做大收入或转移利益，须穿透第三方背后的控制关系。
4. **异常交易特征提示隐性关联**：交易条件明显优于其他方、资金来源依赖被审计单位、无商业实质的循环交易，提示可能存在未披露关联关系。
5. **工商/司法/征信数据是识别利器**：运用企业信用信息、股权穿透工具、司法诉讼记录核查潜在关联关系。
6. **识别结果影响披露与诚信评估**：识别出未披露关联方须要求管理层补充披露，并评估管理层未申报的原因（疏忽或故意隐瞒）对诚信及整体审计的影响（CAS1141）。

## checklist

### 一、隐性关联方识别

- [ ] 是否运用股权穿透工具核查客户/供应商与被审计单位的关联
- [ ] 是否核查高管/股东与被审计单位人员的任职重叠
- [ ] 是否核查共用地址/电话/邮箱/银行账户情况
- [ ] 是否核查主体成立时间与合作时间的吻合度
- [ ] 是否识别只与被审计单位交易的单一依赖型主体

### 二、异常交易分析

- [ ] 是否分析交易条件明显优于其他方的主体
- [ ] 是否识别资金来源依赖被审计单位的交易对手
- [ ] 是否识别无商业实质的循环交易
- [ ] 是否识别以第三方名义进行的受控交易

### 三、影响评估

- [ ] 识别出的未披露关联方交易金额是否统计
- [ ] 是否要求管理层对未披露关联方补充披露
- [ ] 未披露关联交易的定价公允性是否重新评估
- [ ] 管理层未申报原因是否评估（疏忽/故意隐瞒）

### 四、诚信与联动

- [ ] 未申报是否评估对管理层诚信的影响（CAS1141）
- [ ] 识别结果是否传导至舞弊风险评估（B50/B52）
- [ ] 识别方法、穿透过程与结论是否完整记录
- [ ] 是否与 B19、A7 关联方汇总衔接

## risk_areas

### 高风险

1. **隐性关联方虚增收入/利益输送**：通过未披露的受控第三方进行非公允或虚构交易，系统性粉饰业绩或输送利益。
2. **关联方披露重大遗漏**：管理层故意隐瞒关联方及交易，违反 CAS36 披露要求，构成重大错报。
3. **管理层诚信问题**：未申报系故意隐瞒，提示诚信缺陷，须重估整体审计风险（CAS1141）。

### 中风险

1. **单一依赖型主体未穿透**：只与被审计单位交易或资金依赖的主体未核查关联可能。
2. **异常交易条件未追查**：明显优于其他方的交易条件未追查背后关联关系。
3. **股权穿透不充分**：未充分运用工商/股权工具，识别程序不到位。

### 低风险

1. **识别记录不完整**：识别方法、工具、数据来源记录简略。
2. **核查范围有限**：仅核查大额交易对手，中小对手关联可能未评估。
3. **交叉索引缺失**：与 B19、A7、各循环关联方检查的索引不完整。
