# B50 汇总风险评估结果复核提示词

## 概述

本提示词针对汇总风险评估结果底稿（B50）的复核，聚焦报表层次和认定层次重大错报风险的识别与汇总是否完整、特别风险的确定是否恰当、以及风险与拟实施审计程序（风险应对）的对应是否清晰。B50 是风险导向审计的枢纽，承接各了解程序的风险线索并驱动 D~N 循环的实质性程序与控制测试，风险汇总遗漏将导致应对缺失。

**法规依据：**
- 《中国注册会计师审计准则第1211号——通过了解被审计单位及其环境识别和评估重大错报风险》
- 《中国注册会计师审计准则第1231号——针对评估的重大错报风险采取的应对措施》
- 《中国注册会计师审计准则第1141号——财务报表审计中与舞弊相关的责任》

## tips

1. **风险须区分报表层次与认定层次**：报表层次风险影响整体（应对为总体审计方案），认定层次风险针对具体科目认定（应对为进一步审计程序），两者不可混淆。
2. **风险须追溯至具体来源**：每项重大错报风险应能追溯至了解被审计单位（B10）、初步分析（B13）、内控了解、关联方（B19）、舞弊评估等程序中识别的具体线索。
3. **特别风险须专门识别与应对**：舞弊风险、重大非常规交易、重大判断事项等特别风险须单独识别，且不能仅依赖控制、须实施针对性实质性程序（CAS1231）。
4. **收入确认默认存在舞弊风险**：除非反驳，收入确认应假定存在舞弊风险；管理层凌驾于控制之上是所有主体的特别风险（CAS1141）。
5. **风险须与认定和循环对应**：每项认定层次风险应明确对应的科目/循环和认定（存在/完整性/计价等），驱动 D~N 循环的针对性程序。
6. **风险评估须动态更新**：审计过程中发现的新信息须回评风险评估，B50 结论应与最终执行的审计程序一致。

## checklist

### 一、风险识别完整性

- [ ] 报表层次重大错报风险是否识别并汇总
- [ ] 认定层次重大错报风险是否按科目/循环/认定识别
- [ ] 各了解程序（B10/B13/内控/B19/舞弊）识别的风险是否已汇总
- [ ] 是否存在识别的风险线索未纳入汇总的情况

### 二、特别风险确定

- [ ] 是否识别特别风险（舞弊/重大非常规/重大判断）
- [ ] 收入确认舞弊风险是否考虑（未反驳则假定存在）
- [ ] 管理层凌驾于控制之上是否作为特别风险
- [ ] 特别风险是否安排针对性实质性程序（不单纯依赖控制）

### 三、风险与应对对应

- [ ] 报表层次风险是否对应总体审计方案（人员/督导/不可预见性）
- [ ] 认定层次风险是否对应进一步审计程序的性质/时间/范围
- [ ] 拟信赖控制的风险是否安排控制测试
- [ ] 风险与拟实施程序的对应关系是否清晰可追溯

### 四、来源追溯与更新

- [ ] 每项风险是否可追溯至具体识别来源
- [ ] 风险评估是否随审计过程中新信息动态更新
- [ ] B50 结论是否与最终执行的审计程序一致
- [ ] 汇总结果是否传导至 D~N 循环及控制测试底稿

## risk_areas

### 高风险

1. **重大错报风险漏识别**：了解程序识别的风险线索未汇总进 B50，导致相应领域无审计应对，重大错报未被发现。
2. **特别风险未针对性应对**：舞弊风险、重大判断事项等特别风险仅依赖控制或常规程序，未实施针对性实质性程序（CAS1231）。
3. **管理层凌驾/收入舞弊未考虑**：未将管理层凌驾作为特别风险、未考虑收入确认舞弊风险，违反 CAS1141。

### 中风险

1. **报表层次与认定层次混淆**：风险层次划分不当，导致应对措施错配。
2. **风险与应对脱节**：风险已识别但未清晰对应到具体审计程序，应对可追溯性不足。
3. **风险评估未更新**：审计中新信息未回评风险，B50 与实际程序不一致。

### 低风险

1. **来源追溯不完整**：部分风险未标注识别来源。
2. **汇总记录格式不规范**：风险汇总表要素不齐。
3. **交叉索引缺失**：与各了解程序底稿及 D~N 循环的索引不完整。
