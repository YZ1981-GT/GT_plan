# B10 了解被审计单位及其环境和适用财报编制基础程序表 复核提示词

## 概述

本提示词针对了解被审计单位及其环境和适用财务报告编制基础程序表（B10）的复核，聚焦了解范围充分性、风险识别关联性、风险评估程序适当性、了解结论可用性四大要点。了解被审计单位是风险导向审计的基石，了解不充分将导致重大错报风险识别不完整，进而使后续审计程序失去针对性。

**法规依据：**
- 《中国注册会计师审计准则第1211号——通过了解被审计单位及其环境识别和评估重大错报风险》
- 《中国注册会计师审计准则第1201号——计划审计工作》
- 《中国注册会计师审计准则第1301号——审计证据》

## tips

1. **了解范围须覆盖准则要求的各维度**：行业与监管环境、单位性质、所有权与治理结构、经营与融资活动、会计政策选用、目标战略及相关经营风险、财务业绩衡量均应了解，缺一即为了解不完整。
2. **了解应服务于风险识别而非记录信息**：了解的最终目的是识别可能导致重大错报的风险因素，仅罗列客户背景信息而未导出风险即背离程序目的。
3. **风险评估程序须综合运用询问、分析、观察与检查**：不应仅依赖管理层询问，应结合分析程序、实地观察和文件检查获取证据。
4. **适用财报编制基础须明确并评估其恰当性**：应确认被审计单位采用的会计准则体系（企业会计准则/小企业会计准则等）及其对财报列报的影响。
5. **了解结论须转化为风险评估输入**：了解获取的信息应结构化转化为报表层次和认定层次的风险因素，结转至B50风险汇总。
6. **首次审计与连续审计了解深度应有区分**：首次审计须全面了解，连续审计聚焦变化更新，但不得因连续而省略必要程序。

## checklist

### 一、了解范围完整性

- [ ] 是否了解行业状况、监管环境及外部因素
- [ ] 是否了解单位性质（业务、所有权、治理结构、投融资）
- [ ] 是否了解会计政策的选择与运用及其恰当性
- [ ] 是否了解单位目标、战略及相关经营风险
- [ ] 是否了解财务业绩的衡量与评价方式
- [ ] 适用财务报告编制基础是否明确并评估恰当性

### 二、风险评估程序适当性

- [ ] 风险评估程序是否综合运用询问、分析、观察、检查
- [ ] 是否不仅依赖管理层询问而获取了佐证证据
- [ ] 询问对象是否覆盖治理层、内审、法务等多层级
- [ ] 分析程序是否用于识别异常关系和潜在风险领域
- [ ] 实地观察和文件检查是否验证了了解的信息

### 三、风险识别与结论

- [ ] 了解获取的信息是否导出了具体的风险因素
- [ ] 是否识别了报表层次的重大错报风险
- [ ] 是否识别了认定层次的重大错报风险
- [ ] 是否识别了需特别考虑的特别风险
- [ ] 了解结论是否结转至B50风险评估汇总

## risk_areas

### 高风险

1. **了解范围重大缺失**：行业、单位性质、会计政策等准则要求维度未充分了解，导致风险识别存在盲区。
2. **了解未导出风险**：仅记录客户背景信息而未识别可能导致重大错报的风险因素，程序目的落空。
3. **仅依赖管理层询问**：风险评估程序未获取佐证证据，了解结论可靠性存疑，易被管理层误导。
4. **特别风险漏识别**：涉及重大判断、非常规交易、舞弊风险的领域未在了解中识别为特别风险。

### 中风险

1. **风险评估程序单一**：未综合运用分析、观察、检查，程序类型不足以支持全面风险识别。
2. **适用编制基础评估不足**：未明确会计准则体系或未评估其对列报的影响。
3. **了解深度与业务复杂度不匹配**：复杂业务或特殊行业了解流于表面。
4. **连续审计更新不足**：仅沿用上年了解未更新本年变化。

### 低风险

1. **了解信息未结构化**：了解结论未有序转化为风险评估输入，衔接不清晰。
2. **询问对象单一**：主要依赖财务人员询问，未覆盖治理层和其他职能。
3. **交叉索引缺失**：了解程序表未与B50及具体循环风险评估建立索引。
