# B13 初步分析程序表 复核提示词

## 概述

本提示词针对计划阶段初步分析程序表（B13）的复核，聚焦分析程序设计合理性、异常关系识别充分性、异常追查到位性、分析结论对风险评估的支持四大要点。计划阶段的分析程序旨在增进对被审计单位的了解、识别可能存在重大错报风险的领域，是风险评估的重要程序，其质量直接影响风险识别的完整性。

**法规依据：**
- 《中国注册会计师审计准则第1313号——分析程序》
- 《中国注册会计师审计准则第1211号——通过了解被审计单位及其环境识别和评估重大错报风险》
- 《中国注册会计师审计准则第1201号——计划审计工作》

---

## tips

1. **计划阶段分析程序的目的是识别风险而非验证余额**：初步分析用于发现异常波动和意外关系以定位风险领域，不同于实质性分析程序的证据获取功能。
2. **分析应结合财务与非财务信息**：将财务数据与经营数据、行业数据、预算等结合分析，比单纯财务比率分析更能揭示异常。
3. **比较基准应恰当且多维**：应进行同比、环比、预算对比、行业对比等多维度分析，单一基准难以识别异常。
4. **识别出的异常波动必须追查**：分析发现的重大波动或意外关系应追查原因，未追查的异常等于未完成分析程序。
5. **分析结论应导出风险评估输入**：分析识别的风险领域应明确转化为报表层次或认定层次的风险因素。
6. **数据可靠性影响分析有效性**：用于分析的数据（尤其未审数据）可靠性应评估，不可靠数据得出的分析结论无意义。

## checklist

### 一、分析程序设计

- [ ] 是否对主要财务报表项目进行了初步分析
- [ ] 是否结合非财务信息（产量、人数、面积等）进行分析
- [ ] 比较基准是否多维（同比/环比/预算/行业）
- [ ] 关键财务比率（偿债/营运/盈利/发展能力）是否分析
- [ ] 分析口径是否一致（会计政策变更是否已调整）

### 二、异常识别与追查

- [ ] 是否识别出重大波动和异常比率
- [ ] 是否识别出与预期不符的意外关系
- [ ] 识别出的异常是否逐项追查原因
- [ ] 追查是否获取了合理解释或指向具体风险
- [ ] 异常追查是否保持了职业怀疑

### 三、结论与风险支持

- [ ] 分析结论是否明确指向可能的重大错报风险领域
- [ ] 分析识别的风险是否结转至B50风险评估
- [ ] 用于分析的数据可靠性是否已评估
- [ ] 分析是否补充了通过了解获取的风险判断
- [ ] 重大异常是否提请后续审计程序重点关注

## risk_areas

### 高风险

1. **重大异常未识别**：主要项目重大波动或异常比率未被分析发现，遗漏风险领域。
2. **异常未追查**：识别出异常波动却未追查原因，分析程序未完成即得出结论。
3. **分析结论与风险评估脱节**：分析未导出风险因素，未影响后续审计程序设计。
4. **数据不可靠仍据以分析**：使用未评估可靠性的数据得出风险判断，结论失真。

### 中风险

1. **分析维度单一**：仅做同比或简单比率分析，缺乏多维度和非财务信息结合。
2. **口径不一致**：会计政策变更未调整即比较，导致虚假波动或掩盖真实异常。
3. **追查解释未获证据支持**：接受管理层口头解释而未获取佐证。

### 低风险

1. **分析记录不完整**：分析过程、异常识别、追查结论记录不充分。
2. **比率计算错误**：个别财务比率计算公式或取数有误，不影响整体但影响准确性。
3. **索引引用缺失**：分析结论未与风险评估底稿建立索引。
