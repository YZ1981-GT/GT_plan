# B1-2 业务保持风险评估表 复核提示词

## 概述

本提示词针对业务保持（续做）阶段风险评估表（B1-2）的复核，聚焦客户情况变化评估、上年度审计遗留问题、独立性持续满足、续做结论合理性四大要点。业务保持是连续审计年度的风险再评估，重点在于识别客户经营、治理、财务状况及关系的变化，避免因惯性续做而承担新增或加剧的执业风险。

**法规依据：**
- 《中国注册会计师审计准则第1121号——对财务报表审计实施的质量管理》
- 《中国注册会计师审计准则第1101号——注册会计师的总体目标和审计工作的基本要求》
- 《中国注册会计师审计准则第1201号——计划审计工作》

---

## tips

1. **续做评估的核心是识别变化而非重复上年结论**：应聚焦客户经营环境、股权结构、管理层、财务状况自上年以来的重大变化，惯性沿用上年评估是最大误区。
2. **上年度审计遗留问题必须结转跟踪**：上年识别的重大风险、审计调整、内控缺陷、意见类型是否已解决或仍存续，直接影响本年续做风险等级。
3. **独立性持续满足需重新确认**：轮换要求、长期合作产生的密切关系威胁、新增非审计服务等应重新评估，独立性并非一次确认永久有效。
4. **诚信状况变化应保持警觉**：管理层变动、监管调查、诉讼新增、诚信事件等负面信号应触发续做风险重估。
5. **续做结论应与变化及遗留问题相匹配**：若客户出现重大不利变化或上年遗留重大问题未解决，续做结论不应轻率评为"可继续"。
6. **续做审批同样须恰当层级留痕**：风险升高的续做业务应经业务合伙人及质控复核合伙人审批，不得因连续合作而省略。

## checklist

### 一、客户情况变化

- [ ] 是否评估客户经营环境、行业地位、财务状况自上年的重大变化
- [ ] 是否关注股权结构、治理层、关键管理人员的变动
- [ ] 是否识别新增的重大交易、并购重组、融资担保等事项
- [ ] 是否关注客户诚信、声誉、监管处罚等负面信号的新增
- [ ] 持续经营能力较上年是否发生不利变化

### 二、上年度遗留问题

- [ ] 上年识别的重大错报风险本年是否仍然存在
- [ ] 上年提出的审计调整是否已被采纳并正确入账
- [ ] 上年发现的内部控制缺陷是否已整改
- [ ] 上年审计意见类型及关键审计事项是否已妥善处理
- [ ] 上年与管理层、治理层的重大分歧是否已解决

### 三、独立性持续满足

- [ ] 项目合伙人及关键人员轮换要求是否满足
- [ ] 长期合作产生的密切关系威胁是否重新评估并防范
- [ ] 本年是否新增非审计服务导致自我评价威胁
- [ ] 收费依赖度是否处于可接受水平
- [ ] 事务所与客户是否新增任何利害关系

### 四、续做结论与审批

- [ ] 续做风险等级是否与识别的变化及遗留问题相匹配
- [ ] 继续/终止建议是否有充分评估证据支持
- [ ] 风险升高事项是否已提请本年审计计划关注（链接至B50）
- [ ] 续做决策是否经恰当层级审批并完整留痕
- [ ] 审批时点是否早于外勤审计开始

## risk_areas

### 高风险

1. **惯性续做忽视重大不利变化**：客户出现财务恶化、诚信事件、监管调查等重大变化仍机械续做，未重估风险等级。
2. **上年重大遗留问题未解决仍续做**：上年重大错报风险或内控缺陷持续存在，本年未升级应对即续做，风险敞口累积。
3. **独立性持续要求未满足**：合伙人轮换到期未轮换或密切关系威胁未防范，独立性受损。
4. **诚信负面信号被忽略**：管理层变动伴随的诚信疑虑或新增诉讼未触发续做风险重估。

### 中风险

1. **变化评估不充分**：仅确认"无重大变化"而未实质分析客户经营与财务的具体变动。
2. **遗留问题跟踪不完整**：上年审计调整是否入账、缺陷是否整改缺乏后续验证证据。
3. **非审计服务威胁未评估**：本年新增咨询或代编服务未评估其对独立性的影响。
4. **收费依赖度未监控**：单一客户收费占比过高的自身利益威胁未评估。

### 低风险

1. **审批时序倒置**：续做审批晚于外勤开始，实质评估已完成但程序时点不当。
2. **上年数据引用未更新**：续做表沿用上年字段未刷新至本年最新情况。
3. **交叉索引缺失**：续做结论未与B50及B1B续做决策建立索引。
