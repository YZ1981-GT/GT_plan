# B3 独立性确认表 复核提示词

## 概述

本提示词针对独立性确认表（B3）的复核，聚焦独立性威胁识别完整性、防范措施适当性、项目组独立性声明、独立性持续满足四大要点。独立性是审计的基石，独立性受损将使审计意见丧失可信度。B3通过系统识别自身利益、自我评价、过度推介、密切关系、外在压力五类威胁并记录防范措施，确保项目组在形式和实质上保持独立。

**法规依据：**
- 《中国注册会计师审计准则第1121号——对财务报表审计实施的质量管理》
- 《中国注册会计师审计准则第1101号——注册会计师的总体目标和审计工作的基本要求》
- 《中国注册会计师职业道德守则》

## tips

1. **五类独立性威胁应逐一识别**：自身利益、自我评价、过度推介、密切关系、外在压力五类威胁均应针对本项目具体识别，笼统声明"不存在威胁"不构成有效确认。
2. **威胁识别须覆盖事务所与项目组两个层面**：事务所层面（如收费依赖、非审计服务）和项目组个人层面（如持股、亲属关系、任职）的威胁均应识别。
3. **防范措施须与威胁严重程度匹配**：识别出的威胁应有相应防范措施，威胁严重到无法降至可接受水平的应回避（如更换人员或不承接）。
4. **非审计服务的自我评价威胁须重点评估**：为客户提供代编报表、估值、内控咨询等非审计服务可能产生自我评价威胁，应评估其对独立性的影响。
5. **合伙人及关键人员轮换要求须确认**：对公众利益实体的项目合伙人和关键审计合伙人应遵守轮换要求，避免长期合作产生的密切关系威胁。
6. **独立性确认须覆盖项目组全体成员**：项目组每一成员均应作出独立性声明，新加入成员应及时补充确认。

## checklist

### 一、威胁识别完整性

- [ ] 是否识别了自身利益威胁（持股/收费依赖/贷款担保）
- [ ] 是否识别了自我评价威胁（非审计服务/代编报表）
- [ ] 是否识别了过度推介威胁（为客户推介/代言）
- [ ] 是否识别了密切关系威胁（亲属/长期合作/礼品款待）
- [ ] 是否识别了外在压力威胁（客户施压/低价）

### 二、层面覆盖与防范措施

- [ ] 事务所层面威胁是否识别（收费依赖度/非审计服务）
- [ ] 项目组个人层面威胁是否逐人识别
- [ ] 每项识别出的威胁是否有对应防范措施
- [ ] 防范措施是否足以将威胁降至可接受水平
- [ ] 无法降至可接受水平的是否回避或不承接

### 三、声明与持续满足

- [ ] 项目组全体成员是否作出独立性声明
- [ ] 新加入成员是否及时补充独立性确认
- [ ] 合伙人及关键人员轮换要求是否满足
- [ ] 独立性确认时点是否早于审计工作开始
- [ ] 审计过程中新增威胁是否重新评估

## risk_areas

### 高风险

1. **重大独立性威胁未识别**：项目组成员持有客户股份、存在近亲属任职等重大威胁未识别，独立性实质受损。
2. **威胁无防范措施仍执行**：识别出重大威胁却无有效防范措施仍执行审计，独立性无法保障。
3. **非审计服务自我评价威胁未评估**：为客户提供代编报表或估值服务却未评估自我评价威胁。
4. **轮换要求未满足**：公众利益实体项目合伙人到期未轮换，密切关系威胁累积。

### 中风险

1. **威胁识别笼统**：仅声明"不存在威胁"而未逐类具体识别。
2. **收费依赖度未评估**：单一客户收费占比过高的自身利益威胁未评估。
3. **成员声明不全**：部分项目组成员未作独立性声明。

### 低风险

1. **确认时点滞后**：独立性确认晚于审计工作开始。
2. **防范措施记录不详**：防范措施记录笼统，不便评估其充分性。
3. **索引引用缺失**：独立性确认未与承接决策及质量管理底稿建立索引。
