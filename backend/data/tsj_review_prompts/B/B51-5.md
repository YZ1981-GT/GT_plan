# B51-5 识别收入确认舞弊风险迹象程序复核提示词

## 概述

本提示词针对识别收入确认舞弊风险迹象底稿（B51-5）的复核，聚焦对收入确认领域舞弊风险迹象的识别是否全面、是否恰当反驳或确认收入舞弊推定、以及是否传导至收入实质性程序（D4）。CAS1141 要求将收入确认假定为存在舞弊风险，除非能够反驳，识别收入舞弊迹象是设计针对性收入审计程序的基础。

**法规依据：**
- 《中国注册会计师审计准则第1141号——财务报表审计中与舞弊相关的责任》
- 《企业会计准则第14号——收入》
- 《中国注册会计师审计准则第1211号——通过了解被审计单位及其环境识别和评估重大错报风险》

---

## tips

1. **收入确认默认存在舞弊风险**：CAS1141 要求假定收入确认存在舞弊风险，除非有充分理由反驳；反驳须记录依据，不能默认不适用。
2. **收入舞弊迹象须系统识别**：包括期末集中确认、提前确认、虚构客户/交易、跨期截止操纵、第三方回款、经销商压货、异常高毛利、收入与现金流/产能背离等。
3. **业绩压力与动机是舞弊三角要素**：识别是否存在达成业绩目标、上市/再融资、业绩承诺、薪酬挂钩等收入操纵动机。
4. **收入确认政策与商业模式匹配性**：关注总额法vs净额法、时点vs时段、主要责任人vs代理人等判断是否被用于操纵收入。
5. **迹象须转化为具体风险应对**：识别的迹象应明确对应收入实质性程序（D4，如截止测试、函证、发票比对、第三方核查、分析程序）的加强。
6. **保持职业怀疑**：对管理层收入确认判断保持警觉，异常迹象须获取佐证并评估对整体审计的影响。

## checklist

### 一、舞弊推定与反驳

- [ ] 是否将收入确认假定为存在舞弊风险
- [ ] 如反驳收入舞弊推定，反驳依据是否充分并记录
- [ ] 是否针对具体收入类型分别评估（主营/其他/各产品线）

### 二、舞弊迹象识别

- [ ] 是否识别期末集中/提前确认收入的迹象
- [ ] 是否识别虚构客户/交易、第三方回款、经销商压货迹象
- [ ] 是否识别跨期截止操纵迹象
- [ ] 是否识别异常高毛利、收入与现金流/产能背离
- [ ] 是否识别收入确认政策被用于操纵的迹象

### 三、动机与压力

- [ ] 是否识别收入操纵的动机（业绩目标/上市/业绩承诺/薪酬）
- [ ] 管理层对收入的关注度和激励机制是否评估
- [ ] 是否存在异常的收入增长压力

### 四、风险应对传导

- [ ] 识别的迹象是否评估收入舞弊风险等级
- [ ] 是否明确对应 D4 收入实质性程序的加强
- [ ] 是否传导至舞弊风险评估（B50）和特别风险
- [ ] 识别方法与结论是否完整记录

## risk_areas

### 高风险

1. **未考虑收入舞弊推定**：未将收入确认假定为舞弊风险且无反驳依据，违反 CAS1141，收入舞弊未被针对性应对。
2. **收入舞弊迹象漏识别**：期末集中/提前确认、虚构交易、跨期操纵等迹象未识别，虚增收入未被发现。
3. **迹象未传导应对**：识别的收入舞弊迹象未转化为 D4 收入程序的加强，风险应对缺失。

### 中风险

1. **反驳依据不充分**：反驳收入舞弊推定的理由证据不足。
2. **动机分析缺失**：未识别收入操纵的动机和业绩压力。
3. **政策操纵未关注**：未关注收入确认政策判断是否被用于操纵。

### 低风险

1. **识别记录不完整**：舞弊迹象识别过程记录简略。
2. **交叉索引缺失**：与 D4 收入、B50 舞弊评估的索引不完整。
3. **格式不规范**：识别结论表述格式不统一。
