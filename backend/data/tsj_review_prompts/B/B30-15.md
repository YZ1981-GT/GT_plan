# B30-15 组成部分预算和实际收费信息 复核提示词

## 概述

本提示词针对组成部分预算和实际收费信息表（B30-15）的复核，聚焦收费信息完整性、资源投入合理性、收费与工作范围匹配性、独立性影响评估四大要点。组成部分的预算与实际收费反映集团审计资源在各组成部分的配置，收费与工作范围显著不匹配可能预示审计投入不足或独立性威胁，是集团审计资源管理与质量控制的辅助信息。

**法规依据：**
- 《中国注册会计师审计准则第1401号——对集团财务报表审计的特殊考虑》
- 《中国注册会计师审计准则第1121号——对财务报表审计实施的质量管理》

---

## tips

1. **收费信息应覆盖各组成部分完整**：预算与实际收费应涵盖所有实施审计工作的组成部分，含集团项目组和各组成部分注册会计师。
2. **收费应与组成部分重要性和工作范围匹配**：重要组成部分实施整体审计应有相应的资源投入，收费畸低可能预示审计投入不足。
3. **预算与实际差异须分析成因**：实际收费显著偏离预算的应分析原因，可能反映工作范围变化或资源投入不当。
4. **收费畸低须评估对审计质量的影响**：收费明显不足以支撑必要审计程序的，应评估其对审计工作充分性的影响。
5. **收费信息可辅助独立性评估**：单一组成部分收费依赖度过高或收费安排异常可能构成独立性威胁的线索。
6. **收费信息应服务于资源管理决策**：本表是集团审计资源配置与监控的辅助工具，应服务于审计范围和参与程度决策，而非单纯记录。

## checklist

### 一、收费信息完整性

- [ ] 是否覆盖所有实施审计工作的组成部分
- [ ] 是否区分预算收费与实际收费
- [ ] 集团项目组与组成部分注册会计师收费是否分别列示
- [ ] 收费口径是否一致（含税/不含税、期间口径）
- [ ] 收费数据来源是否可靠

### 二、资源投入合理性

- [ ] 各组成部分收费是否与其重要性匹配
- [ ] 重要组成部分资源投入是否充足
- [ ] 是否存在收费畸低的组成部分
- [ ] 收费与拟实施审计工作类型是否匹配
- [ ] 资源配置是否覆盖高风险组成部分

### 三、差异分析与影响评估

- [ ] 预算与实际收费显著差异是否分析成因
- [ ] 收费畸低是否评估对审计质量的影响
- [ ] 收费依赖度或异常安排是否评估独立性影响
- [ ] 收费信息是否服务于审计范围决策
- [ ] 资源不足事项是否提请集团项目组关注

## risk_areas

### 高风险

1. **重要组成部分投入严重不足**：重要组成部分收费畸低反映审计资源投入不足，可能无法获取充分证据。
2. **收费异常预示独立性威胁**：收费依赖度过高或安排异常构成独立性威胁却未评估。

### 中风险

1. **收费与工作范围不匹配**：收费与拟实施审计工作类型明显不匹配未分析。
2. **预算实际差异未分析**：显著差异未分析成因，资源配置合理性存疑。
3. **收费信息未服务决策**：仅记录收费而未用于审计范围和资源决策。

### 低风险

1. **收费信息不完整**：部分组成部分收费信息缺失。
2. **口径不一致**：收费口径混杂影响可比性。
3. **索引引用缺失**：收费信息未与集团审计范围底稿建立索引。
