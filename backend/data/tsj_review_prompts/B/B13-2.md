# B13-2 同行业对比分析 复核提示词

## 概述

本提示词针对同行业对比分析（B13-2）的复核，聚焦可比公司选取合理性、对比指标适当性、差异分析深度、对比结论对风险评估的支持四大要点。同行业对比是计划阶段分析程序的重要延伸，通过将被审计单位关键指标与同行业可比公司比较，识别偏离行业水平的异常，为风险评估提供行业维度的参照系。

**法规依据：**
- 《中国注册会计师审计准则第1313号——分析程序》
- 《中国注册会计师审计准则第1211号——通过了解被审计单位及其环境识别和评估重大错报风险》

---

## tips

1. **可比公司选取须真正可比**：应选取业务模式、规模、所处细分行业、发展阶段相近的公司，选取不当的对比对象会得出误导性结论。
2. **对比指标应聚焦风险敏感领域**：毛利率、应收周转、存货周转、资产负债率等能揭示经营与财务风险的指标优先，而非泛泛罗列。
3. **偏离行业水平的指标是风险信号**：显著高于或低于行业均值的指标（如毛利率异常偏高）应作为潜在舞弊或错报的风险线索追查。
4. **对比须考虑口径可比性**：不同公司会计政策、报表口径差异应在对比时予以说明或调整，避免虚假差异。
5. **差异分析须深入到成因**：不应仅列示差异数值，应分析差异是否由合理的经营特点解释，还是指向风险。
6. **对比数据来源与时效须可靠**：所引用的行业数据应来源权威、时点匹配，过期或口径混杂的行业数据会削弱对比价值。

## checklist

### 一、可比公司与指标选取

- [ ] 可比公司选取标准是否合理（业务/规模/细分行业/阶段）
- [ ] 可比公司数量是否足以形成有效参照
- [ ] 对比指标是否聚焦风险敏感领域
- [ ] 财务指标口径是否与被审计单位可比
- [ ] 行业均值/中位数计算是否恰当

### 二、差异分析深度

- [ ] 是否识别出被审计单位显著偏离行业的指标
- [ ] 显著偏离的指标是否分析了成因
- [ ] 差异是否区分为合理经营特点还是潜在风险
- [ ] 毛利率、周转率等关键指标异常是否作为风险线索追查
- [ ] 会计政策或口径差异是否已说明或调整

### 三、结论与风险支持

- [ ] 对比结论是否明确指向潜在风险领域
- [ ] 对比识别的风险是否结转至风险评估
- [ ] 对比数据来源和时效是否可靠
- [ ] 对比是否为收入、成本等高风险科目提供风险参照
- [ ] 重大偏离是否提请后续审计程序关注

## risk_areas

### 高风险

1. **异常偏离未作为风险信号**：毛利率、周转率等显著偏离行业却未识别为潜在舞弊或错报线索。
2. **可比公司选取不当**：选取业务或规模不可比的对象，得出误导性对比结论。
3. **差异未分析成因**：仅列示与行业的差异数值而未分析原因，无法支持风险判断。

### 中风险

1. **口径不可比**：会计政策或报表口径差异未说明即对比，产生虚假差异。
2. **对比指标不聚焦**：泛泛罗列指标而未突出风险敏感领域。
3. **行业数据来源存疑**：引用数据来源不权威或时点不匹配。

### 低风险

1. **可比公司数量不足**：可比样本过少，参照有效性下降。
2. **对比结论未结转**：对比发现未明确导入风险评估。
3. **索引引用缺失**：对比分析未与B13及风险评估底稿建立索引。
