# B19 识别关联方程序表复核提示词

## 概述

本提示词针对识别关联方底稿（B19）的复核，聚焦关联方及关联方关系识别的完整性、关联方交易的了解、以及关联方相关重大错报风险（含舞弊风险）的评估。关联方是舞弊和利益输送的高发领域，关联方识别不完整将导致关联交易披露遗漏和相关风险漏评估。

**法规依据：**
- 《中国注册会计师审计准则第1323号——关联方》
- 《中国注册会计师审计准则第1211号——通过了解被审计单位及其环境识别和评估重大错报风险》
- 《中国注册会计师审计准则第1141号——财务报表审计中与舞弊相关的责任》

---

## tips

1. **关联方识别须穿透实际控制关系**：除管理层提供的关联方清单外，须通过股权结构、共同控制、关键管理人员及其近亲属等识别所有关联方，防范隐性关联方（CAS1323）。
2. **关联方清单须多渠道交叉验证**：将管理层清单与工商登记、公开信息、以往审计档案、银行询证、合同等交叉核对，识别未披露关联方。
3. **超出正常经营的重大关联交易须重点关注**：无商业理由、条款异常、临近期末的重大关联交易可能存在舞弊或利益输送，应作为特别风险考虑。
4. **关联方是舞弊风险的高发领域**：识别关联方须与舞弊风险评估（B50/B52）联动，管理层凌驾常通过关联方实现。
5. **项目组内须传达关联方信息**：识别的关联方及关联关系应在项目组内沟通，使各循环审计人员保持警觉。
6. **关联方识别是持续过程**：审计过程中发现的以往未识别关联方或交易须及时评估并更新识别结果。

## checklist

### 一、关联方识别完整性

- [ ] 是否取得管理层提供的关联方及关联关系清单
- [ ] 是否通过股权结构穿透识别控制/共同控制关联方
- [ ] 是否识别关键管理人员及其近亲属控制的主体
- [ ] 是否将清单与工商/公开信息/以往档案交叉验证
- [ ] 是否识别同一控制人下的其他企业（兄弟单位）

### 二、关联交易了解

- [ ] 是否了解本期主要关联交易的类型、金额和条款
- [ ] 是否识别超出正常经营范围的重大关联交易
- [ ] 关联交易定价方式及公允性是否初步了解
- [ ] 是否关注临近期末、无商业理由的异常关联交易

### 三、风险评估与联动

- [ ] 关联方相关重大错报风险是否评估
- [ ] 存在舞弊迹象的关联交易是否作为特别风险
- [ ] 识别结果是否与舞弊风险评估（B50/B52）联动
- [ ] 关联方信息是否在项目组内传达

### 四、记录与持续更新

- [ ] 识别方法、渠道和结果是否完整记录
- [ ] 审计中发现的新关联方/交易是否及时更新
- [ ] 识别结果是否与 A7 关联方汇总、各循环关联方检查衔接

## risk_areas

### 高风险

1. **隐性关联方未识别**：未穿透识别通过隐蔽方式存在的关联方，导致关联交易披露遗漏和利益输送未被发现（CAS1323）。
2. **管理层清单不完整未察觉**：过度依赖管理层提供的清单而未多渠道验证，遗漏未披露关联方。
3. **关联交易舞弊风险漏评估**：异常重大关联交易未作为特别风险考虑，管理层凌驾风险未被应对。

### 中风险

1. **关联交易了解不足**：对主要关联交易类型、金额、条款了解不充分，公允性判断缺乏基础。
2. **项目组未传达**：识别的关联方信息未在项目组内沟通，各循环警觉性不足。
3. **持续更新缺失**：审计中发现的新关联方未及时纳入识别结果。

### 低风险

1. **识别记录不完整**：识别方法和渠道记录简略。
2. **交叉索引缺失**：与 A7 关联方汇总、B19-1、各循环关联方检查的索引不完整。
3. **格式不规范**：关联关系描述格式不统一。
