# B30-1 指令-了解组成部分注册会计师程序表 复核提示词

## 概述

本提示词针对指令性质的了解组成部分注册会计师程序表（B30-1）的复核，聚焦组成部分注册会计师胜任能力评价、独立性评价、监管环境了解、了解结论对利用决策的支持四大要点。集团项目组拟利用组成部分注册会计师工作前，必须充分了解并评价其专业素质与独立性，B30-1以指令形式规范该了解程序，是集团审计质量控制的关键环节。

**法规依据：**
- 《中国注册会计师审计准则第1401号——对集团财务报表审计的特殊考虑》
- 《中国注册会计师审计准则第1121号——对财务报表审计实施的质量管理》

---

## tips

1. **胜任能力评价须具体到人和机构**：应评价组成部分注册会计师及其事务所的专业资质、行业经验、执业质量记录，而非仅确认其具备执业资格。
2. **独立性评价须覆盖对集团和组成部分两个层面**：组成部分注册会计师应对集团和该组成部分均保持独立，两个层面的独立性均应评价。
3. **所处监管环境须了解**：应了解组成部分注册会计师所处的职业监管环境、准则体系差异，评估其对工作可靠性的影响。
4. **了解程度应与拟利用程度匹配**：拟深度利用（承担重要组成部分整体审计）的，了解和评价应更深入。
5. **了解结论须支持利用决策**：了解和评价应明确得出是否可以及在何种程度上利用组成部分注册会计师工作的结论。
6. **不利评价须有应对**：评价发现胜任能力或独立性不足的，应调整利用程度或由集团项目组亲自实施程序。

---

## checklist

### 一、胜任能力评价

- [ ] 是否评价组成部分注册会计师的专业资质和资格
- [ ] 是否评价其行业经验和对相关领域的熟悉程度
- [ ] 是否了解其事务所的执业质量记录
- [ ] 是否评价其是否理解集团审计的相关要求
- [ ] 胜任能力评价是否具体而非仅确认执业资格

### 二、独立性与监管环境

- [ ] 是否评价其对集团保持独立性
- [ ] 是否评价其对所审组成部分保持独立性
- [ ] 是否了解其所处职业监管环境
- [ ] 是否评估准则体系差异对工作可靠性的影响
- [ ] 独立性和监管评价结论是否清晰

### 三、了解结论与利用决策

- [ ] 了解程度是否与拟利用程度匹配
- [ ] 了解结论是否明确是否可利用及利用程度
- [ ] 不利评价是否有相应应对（调整利用/亲自实施）
- [ ] 了解结论是否结转至集团审计范围决策
- [ ] 是否向组成部分注册会计师传达了集团要求

## risk_areas

### 高风险

1. **未评价即利用**：未评价组成部分注册会计师胜任能力和独立性即利用其工作，引入不当依赖。
2. **独立性不足仍深度利用**：组成部分注册会计师独立性存疑却承担重要组成部分整体审计。
3. **胜任能力不匹配**：其行业经验或专业素质不足以胜任所审组成部分，工作质量无保障。

### 中风险

1. **监管环境未了解**：未了解其所处监管环境和准则差异对工作可靠性的影响。
2. **了解程度不足**：拟深度利用却仅作表面了解。
3. **不利评价无应对**：评价发现不足却未调整利用程度。

### 低风险

1. **评价记录不完整**：胜任能力和独立性评价的依据记录不充分。
2. **集团要求传达不清**：向组成部分注册会计师传达的要求记录笼统。
3. **索引引用缺失**：了解结论未与B30及组成部分沟通底稿建立索引。
