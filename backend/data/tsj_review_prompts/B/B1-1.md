# B1-1 业务承接风险评估表 复核提示词

## 概述

本提示词针对业务承接阶段风险评估表（B1-1）的复核，聚焦客户诚信评价、独立性与胜任能力、承接风险因素识别、承接结论合理性四大要点。业务承接是审计风险防控的第一道闸门，承接决策失当将使事务所在项目开始前即承担难以化解的执业风险与声誉风险。复核应验证风险评估是否充分、判断是否有证据支持、结论是否与识别出的风险相匹配。

**法规依据：**
- 《中国注册会计师审计准则第1121号——对财务报表审计实施的质量管理》
- 《中国注册会计师审计准则第1101号——注册会计师的总体目标和审计工作的基本要求》
- 《中国注册会计师审计准则第1201号——计划审计工作》

## tips

1. **客户诚信是承接决策的首要前提**：应评价管理层与治理层的诚信状况、经营理念、对内部控制的态度，任何诚信疑虑均应作为高风险信号审慎对待，而非流于形式打勾。
2. **独立性评价须覆盖全部威胁类型**：自身利益、自我评价、过度推介、密切关系、外在压力五类威胁均应逐一识别评估，并记录已采取的防范措施，不得仅作笼统结论。
3. **胜任能力与资源须与业务复杂度匹配**：评估项目所需的行业专长、专业胜任能力、时间与人力资源是否具备，特殊行业或复杂交易须确认专家利用安排。
4. **承接风险评估应识别具体风险因素而非通用套话**：财务状况、行业环境、关联方复杂度、诉讼与监管、持续经营等风险因素应结合被审计单位实际逐项评估。
5. **风险评估结论须与识别的风险因素相匹配**：若识别出多项高风险信号，综合结论不应轻率评为"低风险可承接"，风险等级与承接建议之间应存在可追溯的逻辑。
6. **承接决策须经恰当层级审批**：高风险业务的承接应经业务合伙人及质量控制复核合伙人审批，审批留痕应完整且早于外勤开始。

## checklist

### 一、客户诚信与背景

- [ ] 是否评价了管理层和治理层的诚信、声誉及经营理念
- [ ] 是否核查了主要股东、关键管理人员的背景及涉诉涉罚情况
- [ ] 是否了解客户变更会计师事务所的原因及历史审计意见类型
- [ ] 是否关注客户是否存在限制审计范围或不当施压的迹象
- [ ] 客户所处行业、监管环境的特殊风险是否已识别

### 二、独立性与胜任能力

- [ ] 五类独立性威胁是否逐一识别并记录防范措施
- [ ] 是否确认项目组及事务所与客户不存在利害关系
- [ ] 是否评估了执行该业务所需的行业专长和专业胜任能力
- [ ] 时间、人力资源是否充足，是否需利用专家或其他会计师工作
- [ ] 是否确认收费水平不会损害独立性（低价揽客风险）

### 三、承接风险因素识别

- [ ] 是否评估被审计单位财务状况、盈利能力及持续经营能力
- [ ] 是否识别关联方关系复杂度及重大关联交易风险
- [ ] 是否关注诉讼、担保、或有事项等潜在重大风险
- [ ] 是否识别可能存在的舞弊风险因素及管理层凌驾迹象
- [ ] 是否评估首次接受委托的期初余额及可比数据风险

### 四、承接结论与审批

- [ ] 综合风险等级判断是否与识别出的具体风险因素相匹配
- [ ] 承接/不承接建议是否有充分的评估证据支持
- [ ] 高风险信号是否已提请后续审计计划关注（链接至B50）
- [ ] 承接决策是否经恰当层级（业务合伙人/质控复核合伙人）审批
- [ ] 审批时点是否早于外勤审计开始，留痕是否完整

## risk_areas

### 高风险

1. **客户诚信重大疑虑被忽视**：管理层存在诚信问题、历史舞弊或监管处罚记录却未作为承接障碍评估，事务所承接后将暴露于重大执业与声誉风险。
2. **独立性威胁未识别或防范不足**：存在自身利益或密切关系威胁却未记录防范措施，可能导致独立性受损、审计结论不可信。
3. **胜任能力与资源严重不匹配**：承接超出事务所行业专长或人力资源承受能力的复杂业务，将无法获取充分适当的审计证据。
4. **承接结论与风险因素背离**：识别出多项高风险信号仍评为低风险轻率承接，风险评估形同虚设。
5. **限制审计范围仍承接**：客户明确限制审计范围或施加不当压力，仍予承接，可能导致无法发表恰当审计意见。

### 中风险

1. **风险因素评估流于形式**：以通用套话代替针对被审计单位实际的具体风险识别，评估缺乏实质性内容。
2. **变更事务所原因未查明**：未了解前任解聘或客户变更的真实原因，可能遗漏重大风险信号。
3. **收费水平影响独立性未评估**：低价揽客或收费依赖度过高未作独立性威胁评估。
4. **持续经营风险评估不足**：被审计单位财务困难迹象未充分评估其对承接决策的影响。

### 低风险

1. **审批留痕时点滞后**：承接审批时间晚于外勤开始，程序时序倒置但风险评估实质已完成。
2. **交叉索引不完整**：承接风险评估结论未与B50风险汇总、B1A承接决策建立索引引用。
3. **评估表格式不规范**：字段填写不完整或格式问题，不影响判断实质但影响底稿可读性。
