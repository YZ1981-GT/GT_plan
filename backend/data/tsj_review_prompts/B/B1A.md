# B1A 业务承接（承接决策）程序表 复核提示词

## 概述

本提示词针对业务承接决策程序表（B1A）的复核，聚焦承接程序执行完整性、决策依据充分性、结论与评估一致性、审批与文档化四大要点。B1A是业务承接的程序性汇总底稿，串联客户诚信调查、独立性确认、胜任能力评估、前任沟通等前置程序，最终形成是否承接的决策。复核应验证各前置程序是否已执行、决策是否有据、审批是否到位。

**法规依据：**
- 《中国注册会计师审计准则第1121号——对财务报表审计实施的质量管理》
- 《中国注册会计师审计准则第1101号——注册会计师的总体目标和审计工作的基本要求》
- 《中国注册会计师审计准则第1201号——计划审计工作》

## tips

1. **承接决策须建立在完整前置程序之上**：客户诚信调查、独立性确认（B3）、风险评估（B1-1）、前任沟通（B2）等前置程序应全部完成并汇总，决策不得跳过任一关键程序。
2. **每一程序步骤应有执行结果而非空转**：程序表各步骤应记录实际执行情况和结论，避免仅勾选"已完成"而无实质证据支持。
3. **决策结论须与风险评估结果一致**：承接建议应与B1-1风险评估的综合等级相匹配，高风险仍承接须有额外说明和防范措施。
4. **首次承接须特别关注期初余额与前任工作**：首次接受委托应确认期初余额审计安排及是否需查阅前任工作底稿。
5. **承接决策审批权限须与风险等级匹配**：常规业务与高风险业务的审批层级应有区分，高风险须经业务合伙人及质控复核合伙人审批。
6. **文档化应完整支持决策可追溯**：承接决策所依据的评估、沟通、审批记录应完整归档，能重现决策形成过程。

## checklist

### 一、承接程序执行完整性

- [ ] 客户诚信与背景调查程序是否已执行并记录结论
- [ ] 独立性确认程序（B3）是否完成
- [ ] 承接风险评估（B1-1）是否完成
- [ ] 与前任注册会计师沟通（B2）是否完成（如适用）
- [ ] 胜任能力与资源评估是否完成
- [ ] 各程序步骤是否均有实际执行结果记录

### 二、决策依据与一致性

- [ ] 承接决策是否有充分的前置程序证据支持
- [ ] 决策结论是否与B1-1风险评估综合等级一致
- [ ] 高风险仍承接时是否有额外说明及防范措施
- [ ] 首次承接是否安排期初余额审计及前任工作查阅
- [ ] 承接范围、条件、限制是否清晰界定

### 三、审批与文档化

- [ ] 承接决策是否经与风险等级匹配的层级审批
- [ ] 审批人签字及日期是否完整
- [ ] 审批时点是否早于外勤审计开始
- [ ] 承接决策相关文档是否完整归档、可追溯
- [ ] 与业务约定书的衔接是否明确

## risk_areas

### 高风险

1. **前置程序缺失即决策**：独立性确认或风险评估等关键前置程序未完成即作出承接决策，决策缺乏基础。
2. **决策与风险评估背离**：B1-1评为高风险却无额外防范措施即承接，程序表决策与评估结论矛盾。
3. **首次承接未安排期初余额程序**：首次委托未确认期初余额审计安排，导致期初数据可靠性无保障。
4. **越权审批**：高风险业务未经业务合伙人或质控复核合伙人审批即承接。

### 中风险

1. **程序步骤空转**：程序表仅勾选"已完成"而无实质执行结果和证据。
2. **承接条件限制未界定**：承接范围或客户施加的限制未在决策中清晰记录。
3. **前任沟通遗漏**：应与前任沟通的情形未执行B2程序即承接。

### 低风险

1. **审批留痕时点滞后**：审批日期晚于外勤开始，程序时序不当。
2. **文档归档不完整**：支持决策的部分记录未完整归档，影响可追溯性。
3. **索引引用缺失**：程序表未与B1-1、B2、B3等前置底稿建立索引。
