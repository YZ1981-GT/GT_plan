## 3. 引擎输入/输出规格

### 3.1 useS4FormulaEngine

```typescript
// ─── calcExchangeGainLoss ───
interface S4ExchangeInput {
  inFairValue: number   // 换入资产公允价值
  outFairValue: number  // 换出资产公允价值
  outBookValue: number  // 换出资产账面价值
  taxes: number         // 相关税费
}
interface S4ExchangeOutput {
  gainLoss: number  // = outFairValue - outBookValue
  inCost: number    // = outFairValue + taxes
}

// ─── judgeApplicable ───
interface CommercialSubstanceInput {
  exclusions: boolean[]      // 6项排除情形 (true=属于该情形)
  cashflowDifferent: boolean // 现金流量显著不同
}
// → boolean: 所有exclusions为false → 适用(true)

// ─── judgeCommercialSubstance ───
// 同CommercialSubstanceInput → boolean = cashflowDifferent
```

**S4-2 IF公式逻辑确认**:
```
=IF(AND(B8="不属于",C8="不属于",D8="不属于",E8="不属于",F8="不属于",G8="不属于"),"是","否")
```
- 6项排除情形全为"不属于" → 适用准则
- 商业实质 = 未来现金流量在风险/时间/金额方面显著不同

### 3.2 useS5FormulaEngine

```typescript
// ─── calcCreditorGainLoss (债权人视角) ───
interface CreditorInput {
  origBook: number   // 债权原账面价值
  origFair: number   // 债权原公允价值
  recvFair: number   // 收到资产(金融资产)公允价值
  otherCost: number  // 可直接归属于受让资产的其他成本
}
// → number: 源模板公式 = origBook - origFair + recvFair (具体口径待源确认)

// ─── calcDebtorGainLoss (债务人视角) ───
interface DebtorInput {
  debtBook: number    // 所清偿债务账面价值
  assetBook: number   // 转让资产账面价值
  equityFair: number  // 发行的权益工具公允价值
}
// → number: = debtBook - assetBook - equityFair
```

**S5-1 源模板公式确认**:
- 债权人: `=D8-E8+F8` (原账面-公允+受让成本)
- 债务人: `=C16-E16-F16-G16` (所清偿债务-金融资产账面-非金融资产账面-权益工具公允)
