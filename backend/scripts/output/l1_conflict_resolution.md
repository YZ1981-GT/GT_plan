## 3. 🔴 利息测算公式 — **关键冲突**

### xlsx证据（权威）
```
M11: =J11*I11/365*L11
```
- **J11** = 借款本金
- **I11** = 年利率
- **L11** = 计息天数（下述天数逻辑）
- **除数 = 365**

### md证据
- md利息测算表列头：`序号 | 借款种类 | 贷款单位 | 借款起始日期 | 借款讫止日期 | 结息日 | 起算时点 | 截止时点 | 年利率 | 借款本金 | 本期实计利息① | 本期应计息天数 | 本期应计利息 | 差异 | 财务费用-利息支出② | 资本化利息支出③ | 本期未付利息天数 | 本期应付利息账面数 | 本期应付利测算 | 备注`
- md**未明确写出360还是365**，仅描述"对短期借款的利息进行测算"

### spec design当前状态
- design.md ADR-2 写："采用360天计息惯例（银行借款惯例），可配置"
- design.md P3 写：`calcInterest = p×rate×days/360`
- tasks.md P3 PBT 写：断言 `calcInterest(p, rate, days) === p×rate×days/360`

### 冲突分析
| 来源 | 天数基准 | 权威性 |
|---|---|---|
| xlsx公式（实际模板） | **365** | ⭐⭐⭐ 最高（这是实际执行的底稿） |
| md模板库 | 未明确 | — |
| spec design | 360 | ⭐ 需修正 |

### 🔴 决议
**以xlsx为准：利息计算使用365天制。**

spec中需修正：
1. `design.md` ADR-2: "360天计息惯例" → "**365天计息制**（致同2025修订版模板实际公式）"
2. `design.md` P3: `p×rate×days/360` → `p×rate×days/365`
3. `tasks.md` 2.5 PBT断言: `/360` → `/365`
4. `useL1InterestEngine.ts` 实现: 除数用365

**注：** 中国银行借款实务中，央行基准利率贷款通常按365天（实际天数/365）计息，而非国际银行业惯例的360天（实际天数/360）。致同模板采用365天符合中国实务。

## 4. 计息天数逻辑

### xlsx证据
```
L11: =IF(G11=0,0,IF((H11-G11)=365,H11-G11,H11-G11+1))
```
- **G11** = 起算时点（`=IF(D11<=$D$9,$D$9,D11)`，取max(报告期起始日, 借款起始日)）
- **H11** = 截止时点（`=IF(E11<=$E$9,E11,$E$9)`，取min(借款讫止日, 报告期截止日)）
- 逻辑：**如果起止差=365天（整年），取365；否则差值+1（含首尾日）**

### md证据
- md列头有"本期应计息天数"但未给出计算公式

### spec design状态
- 当前未在design中详细描述天数逻辑

### 决议
**以xlsx为准。天数计算规则：**
```
days = 起算时点为0? 0 : (截止-起算)==365? 365 : (截止-起算)+1
```
含义：非整年区间"算头算尾"（+1），整年区间直接取365天。
这是中国银行利息计算的"算头不算尾"的变体实现。

## 5. 征信核对对应字段

### xlsx证据（L1-4, 31行×30列, 19公式）
- 列结构（从公式推断）：

## 6. 逾期检查天数计算

### xlsx证据（L1-7）
```
J11: =IF(I11=0,0,$I$9-I11)
```
- **$I$9** = 报告期截止日（如2025-12-31）
- **I11** = 借款到期日
- 逻辑：**逾期天数 = 报告期截止日 - 借款到期日**（到期日为0则逾期0天）

另有天数逻辑：
```
K11: =IF(#REF!=0,0,IF((#REF!-#REF!)=365,#REF!-#REF!,#REF!-#REF!+1))
```
（同L1-5天数逻辑，但有#REF!引用错误，说明模板中可能有列偏移）

### md证据
- 列头：`序号 | 贷款单位 | 贷款类别 | 贷款资金用途 | 贷款金额 | 借款利率 | 逾期利率（日） | 借款日期 | 借款到期日期 | 累计逾期时间（天） | 本期计息天数 | 本期应计利息 | 累计应付利息 | 是否涉诉 | 未按期偿还的原因 | 预计还款期 | 备注`

### 决议
**一致。** `calcOverdueDays(dueDate, reportDate) = reportDate - dueDate`
- 正值=逾期天数
- 负值=尚未到期
- spec设计正确

## 11. 天数计算补充规则（从xlsx发现）

xlsx揭示了一个完整的天数计算体系，spec中应记录：

```
// 起算时点：max(报告期起始日, 借款起始日)
startDate = max(reportStart, loanStart)

// 截止时点：min(借款讫止日, 报告期截止日)  
endDate = min(loanEnd, reportEnd)

// 计息天数：
days = startDate==0 ? 0 
     : (endDate - startDate) == 365 ? 365 
     : (endDate - startDate) + 1
```

含义：
- 报告期区间裁剪（仅计算落入报告期的天数）
- 整年取365天（避免闰年366天问题）
- 非整年"算头算尾"（+1天）
