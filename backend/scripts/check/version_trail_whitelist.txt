# version_trail_whitelist.txt — 版本链集成豁免列表
#
# 格式：每行一个文件名（仅文件名，非完整路径）
# 以 # 开头的行为注释，空行跳过
#
# 用途：对于确认不需要接入版本链的 D~N 主入口组件，
# 添加到此文件以跳过 CI 守卫检查。
#
# 典型豁免场景：
#   - 纯 OnlyOffice 包装组件（无 HTML 主入口、无独立保存逻辑）
#   - 已通过其他机制集成版本链的组件（如 S 循环）
#
# 注意：当前所有 D~N 主入口均含 HTML tabs + 保存逻辑，
# 无纯 OO 无保存的情况，故暂无豁免项。
# 若未来新增确实不需要版本链的底稿，添加到此处。
