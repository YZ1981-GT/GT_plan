# G2 应收利息 — 平台使用手册

> 配合「编制手册」页签使用。  
> 本手册只说明**平台怎么操作**；审计目标与勾稽逻辑见编制手册。  
> **不修改**各分表页内已有说明文案。  
> 入口：顶栏「编制手册」或 G2A 程序控制台工具栏。

---

## 1. 打开与模式

1. 在项目底稿树打开 **G2 应收利息**（`componentType: g2-interest-receivable`）。  
2. 通过 sheet 页签切换分表（G2A、G2-1～G2-8、附注上市/国企）。  
3. 已迁移分表支持 **结构化 HTML ↔ OnlyOffice** 双模式；以项目配置为准。  
4. 只读阶段「带入 / 回写 / 确认 / 导入」类按钮会禁用。

**需要项目上下文的操作**（缺 `projectId` 可能失败）：

- G2-1 取试算 / 回写试算 1132  
- G2-4 从调整分录模块同步、推送 A13  
- 附注「同步至附注」  
- G2-8 抽凭引擎

---

## 2. 推荐操作路径（点击顺序）

| 步骤 | 分表 | 建议操作 |
|------|------|----------|
| 1 | G2A | 勾选程序、填索引；可打开本手册 |
| 2 | G2-2 | 导入或录入明细；设账龄口径 →「同步账龄至各表」 |
| 3 | G2-5 | 「从 G2-2 取数」→ 核对差异 → 可选「写入对照说明」到 G2-1 |
| 4 | G2-7 | 填单项/组合测算 →「回填 G2-3」→「推送差异至 G2-4」 |
| 5 | G2-3 | 核对滚动态；必要时手工微调 |
| 6 | G2-6 | 「从 G2-2 导入超1年」→ 填原因/可收回性；参考 Stage 建议 |
| 7 | G2-8 | 「从 G2-2 带入总体」→ 抽凭/核对五项 |
| 8 | G2-4 | 同步模块或接收差异 → 核对 → **确认**（回写 G2-1） |
| 9 | G2-1 | 「从 G2-2/G2-3 汇总未审」→ 核对调整回写 → 勾稽试算 |
| 10 | 附注 | 「从审定/明细取数」；「从 G2-6 取数」→「同步至附注」 |

## 3. 分表工具栏速查

| 分表 | 常用按钮 | 说明 |
|------|----------|------|
| G2-1 | 从 G2-2/G2-3 汇总未审；取试算 1132 | 审定自动回写试算；调整默认落在「原值·组合」 |
| G2-2 | 账龄切换；同步账龄至各表；IE | 枢纽表，改完再刷下游 |
| G2-3 | 账龄；同步账龄；IE | 承接 G2-7 回填 |
| G2-4 | 从调整模块同步；确认；推送 A13 | **确认**才会回写 G2-1 |
| G2-5 | 从 G2-2 取数；写入对照说明 | ⑤与 G2-1 原值勾稽告警 |
| G2-6 | 从 G2-2 导入超1年；同步账龄 | Stage 建议列供减值参考 |
| G2-7 | 回填 G2-3；推送差异 G2-4；同步账龄 | 回填默认「差异」口径 |
| G2-8 | 从 G2-2 带入总体；抽凭；IE | 导入走扁平 `G2-8-rows` |
| 附注上市/国企 | 从审定/明细取数；从 G2-6 取数；同步附注 | 需 projectId |

索引芯片（如 `wp:G2-2`）用于跳转，不代替数据带入。

## 4. 导入导出

| 支持 IE | 不支持 IE（界面编辑） |
|---------|----------------------|
| G2-1～G2-8 | G2A、附注 |

- 工具栏「导入/导出」按当前 sheet 作用。  
- G2-7 导入扁平表后自动还原三区段；G2-8 导入后还原借/贷区。  
- 导入后若改了 G2-2，请重新对下游执行「取数/导入」。

## 5. 常见问题

| 现象 | 处理 |
|------|------|
| G2-1 取试算为空 | 确认项目已导入试算且含 1132 |
| 审定未进试算 | 检查项目 ID；看是否有回写失败提示 |
| G2-4 确认后 G2-1 无变化 | 确认点了「确认」；默认写入「原值·按组合计提」行 |
| G2-7 回填把期初冲掉 | 使用默认「差异」回填，勿选「应计提全额」除非有意覆盖 |
| 各表账龄不一致 | 在任一张表点「同步账龄至各表」 |
| G2-8 导入后空白 | 等待 hydrate；或重新打开 G2-8 |
| 附注同步失败 | 检查项目 ID、准则类型（上市/国企）与附注权限 |
