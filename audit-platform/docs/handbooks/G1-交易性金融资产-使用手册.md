# G1 交易性金融资产 — 平台使用手册

> 配合「编制手册」页签使用。  
> 本手册只说明**平台怎么操作**；审计目标与勾稽逻辑见编制手册。  
> **不修改**各分表页内已有说明文案。  
> 入口：G1A 程序控制台工具栏「使用手册」。

---

## 1. 打开与模式

1. 在项目底稿树打开 **G1 交易性金融资产**（`componentType: g1-trading-financial-assets`）。  
2. 通过 sheet 页签切换分表（G1A、G1-1～G1-14、附注、目录）。  
3. 已迁移分表支持 **结构化 HTML ↔ OnlyOffice** 双模式（目录页除外）；以项目配置为准。  
4. 只读阶段工具栏「带入 / 回写 / 确认」类按钮会禁用。

**需要项目上下文的操作**（缺 `projectId` 会提示无法执行）：

- G1-3 与调整模块同步  
- G1-4 从函证模块回填  
- G1-11 / G1-13 / G1-14 抽凭或项目级接口  
- 附注「同步到附注模块」

## 2. 推荐操作路径（点击顺序）

| 步骤 | 分表 | 建议操作 |
|------|------|----------|
| 1 | G1A | 勾选程序、填索引 |
| 2 | G1-2 | 导入或录入明细，过编制闸门 |
| 3 | G1-8 → G1-10 → G1-9 | 问卷 → SPPI → 分类依据（「从 G1-8 带入」「从 G1-10 带入 SPPI」或「联合写入」） |
| 4 | G1-11 → G1-12 | 「从 G1-2 带入」→ 监盘 →「推送/取数」倒轧 |
| 5 | G1-4 | 「从 G1-2 带入账面」→「从 G1-11 回填监盘」→「从函证模块回填④」→ 处理差异 |
| 5 | G1-5 / G1-6 | 「从 G1-2 带入」→ 测算/测试 → 可选回写 G1-2 → L3 推 G1-7；G1-5「差异推送」含债息+股利 |
| 7 | G1-13 → G1-14 | 抽凭或手工检查 →「从 G1-13 带入」/ 抽凭引擎 |
| 8 | G1-3 | 同步模块或接收差异草稿 → 核对借贷 → **确认**（回写 G1-1） |
| 9 | G1-1 | 「从 G1-2 汇总未审」→ 核对 G1-3 回写 → 勾稽 TB |
| 10 | 附注 | 拉取上游 → 编辑 → 同步附注模块 |

## 4. 导入导出

| 支持 IE | 不支持 IE（界面编辑） |
|---------|----------------------|
| G1-1～7、G1-10～14 | G1A、G1-8、G1-9、附注、底稿目录 |

- 工具栏「导入/导出」按当前 sheet 作用。  
- 导入后刷新当前表；若改了 G1-2，请重新对下游执行「带入」。

## 5. 常见问题

| 现象 | 处理 |
|------|------|
| G1-4 函证按钮灰 | 检查是否传入项目 ID；或先编制 G0-3S |
| G1-3 确认后 G1-1 无变化 | 确认是否点了「确认」而非仅保存；看是否有 `g1:adjustment-confirmed` 回写提示 |
| G1-9 依据空白 | 先完成 G1-8，再点「从 G1-8 带入依据」 |
| G1-14 一直「未完成」 | 先答完 B；若有「是」再答完 C |
| 抽凭无数据 | 确认项目凭证库有 1501 发生额且抽凭引擎可访问 |
| 附注同步失败 | 检查项目 ID、附注模块权限与准则类型（上市/国企） |
