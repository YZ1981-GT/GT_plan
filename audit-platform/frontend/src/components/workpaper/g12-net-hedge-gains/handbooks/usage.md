# G12 净敞口套期损益 — 平台使用手册

> 本页说明各底稿在平台上的操作方式。审计目标与编制逻辑见「编制手册」页签。

## 1. 目录页（本页）

- **跨表结论口径看板**：汇总核心表「审计说明或结论」是否已填，点击标签跳转补全。
- **底稿架构（4 阶段泳道）**：审计计划 / 科目审定 / 实质性程序 / 披露与调整。
- **本循环底稿目录**：G 循环其他科目，点击跳转。
- **编制/使用手册**：右上角按钮。

## 2. 各底稿操作要点

### G12-1 审定表
点「从 G12-2 带入」填未审数；调整列由 G12-3 回写；点「回写试算平衡表」写入对应科目。

### G12-2 损益明细表
录入各套期关系的套期工具/被套期净敞口公允价值变动、有效/无效部分；支持导入导出。

### 套期有效性测试
录入套期比率、经济关系、有效性测试结果，系统提示是否满足高度有效。

### G12-3 调整分录
录入借贷、实时校验平衡；可「推送至 A13」。

### 附注（上市 / 国企）
点「从明细带入」聚合套期工具/有效性数据；文本区可「🤖 AI 辅助」生成套期策略披露草稿。

## 3. 常用操作速查

| 操作 | 位置 |
|------|------|
| 回写试算平衡表 | G12-1 审定表工具栏 |
| 从明细带入 | G12-1 / 附注 工具栏 |
| 导入 / 导出 | 各表「导入导出 ▾」 |
| 推送错报至 A13 | G12-3 调整分录 |

| 复核对话 | 各区块标题右侧 💬 |
