# G12 净敞口套期损益 — 底稿编制手册

> **适用范围**：净敞口套期损益（CAS 24 套期会计下，对以净敞口为被套期项目的套期关系确认的套期损益）。
> **组件**：GtBIndex 通用目录（G12 科目）
> **说明**：本手册说明各分表的审计目标、编制逻辑与勾稽关联，不替代各表页内已有说明文案。平台按钮与操作步骤见「使用手册」页签。

---

## 1. 总体编制思路

净敞口套期是 CAS 24（套期会计）允许的一种套期关系，企业将一组资产和负债的**净敞口（多头与空头相抵后的净头寸）**指定为被套期项目，用套期工具（通常为衍生工具）对冲。核算要点：**①套期关系须满足套期会计三条件（存在正式指定与书面文件、套期高度有效、有效性可可靠计量）②套期工具的公允价值变动与被套期净敞口的公允价值变动分别确认 ③套期有效部分计入相应损益/OCI，无效部分计入当期损益 ④持续评估套期有效性（前瞻性与回顾性）**。审计核心是套期关系的合规性、套期工具与被套期项目公允价值变动的计量、套期有效性评估、有效/无效部分损益归属的正确性。

| 证据链 | 主要底稿 | 回答的问题 |
|--------|----------|------------|
| 套期关系是否成立 | 套期指定文件、有效性测试 | 是否满足套期会计三条件 |
| 公允价值变动是否准确 | 套期工具/被套期项目明细 | 套期工具与净敞口公允价值变动计量 |
| 有效性是否满足 | 套期有效性测试 | 前瞻性/回顾性有效性、有效比率 |
| 损益归属是否正确 | G12-2 损益明细 | 有效部分/无效部分损益归属 |
| 审定是否正确 | G12-1 审定表 | 未审→调整→审定，与 TB 勾稽 |
| 披露是否完整 | 附注（上市/国企） | 套期策略、套期工具、有效性披露 |

### 建议编制顺序

```
套期关系指定核查 → 套期工具/被套期净敞口公允价值变动 → 套期有效性测试 → G12-2 损益明细(有效/无效) → G12-3 调整 → 回写 G12-1 审定 → 勾稽 TB → 附注(上市/国企)
```

## 2. 分表编制说明

### G12-1 审定表
汇总净敞口套期损益未审数、账项/重分类调整、审定数，回写 TB，与 G12-2 明细勾稽。

### G12-2 损益明细表
列示各套期关系的套期工具公允价值变动、被套期净敞口公允价值变动、套期有效部分、无效部分及其损益归属。

### G12-3 调整分录
录入 AJE/RJE 回写 G12-1 审定表调整列，可推送 A13。

### 套期有效性测试
评估套期关系的经济关系、信用风险影响、套期比率，进行前瞻性与回顾性有效性测试，判断套期是否高度有效。

### 附注（上市 / 国企）
披露风险管理策略、套期工具（名义金额/公允价值）、被套期项目、套期有效性及无效部分损益；数据取自 G12-2 明细与有效性测试。

## 3. 认定覆盖速查

| 认定 | 主要底稿 |
|------|----------|
| 存在 | 套期指定文件、衍生工具合约 |
| 完整性 | G12-1 审定、TB 勾稽 |
| 权利和义务 | 套期文件、合约条款 |
| 计价和分摊 | 公允价值变动、有效性测试、损益归属 |
| 列报和披露 | 附注（上市/国企） |

## 4. 外部模块衔接

| 模块 | 关系 |
|------|------|
| TB 试算平衡表 | G12-1 审定合计回写 |
| G10 交易性金融负债 / G1 | 衍生工具作为套期工具的核算 |
| G13 公允价值变动损益 | 套期无效部分等损益归属区分 |
| A13 未更正错报 | G12-3 调整分录推送 |
| 附注模块 | 披露表数据同步 |

## 5. 质量复核要点（摘要）

1. 套期关系是否有正式书面指定文件，是否满足套期会计三条件。
2. 套期工具与被套期净敞口公允价值变动计量是否准确。
3. 套期有效性（前瞻性/回顾性）是否高度有效，有效比率是否恰当。
4. 有效部分/无效部分损益归属是否正确。
5. G12-1 审定合计 = G12-2 明细合计 = TB。
