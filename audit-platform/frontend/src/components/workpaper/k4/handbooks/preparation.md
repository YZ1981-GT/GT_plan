# K4 其他流动负债 — 底稿编制手册

> **适用范围**：科目 **2245 其他流动负债（贷方/负债类）**（含短期应付债券、待转销项税额、预提费用、政府补助流动部分、代扣代缴等）
> **组件**：`k4-other-current-liabilities`
> **说明**：本手册说明各分表的审计目标、编制逻辑与勾稽关联，不替代各表页内已有说明文案。
> 平台按钮与操作步骤见「使用手册」页签。

---

## 1. 总体编制思路

K4 把「其他流动负债」拆成金额枢纽与检查两条证据链，最后汇入审定与附注：

| 证据链 | 主要底稿 | 回答的问题 |
|--------|----------|------------|
| **金额枢纽** | K4-2 明细 → K4-1 审定 ← K4-3 调整 | 其他流动负债各项余额未审→调整→审定是否完整准确？ |
| **专项检查** | K4-4 检查表 | 分类正确性/流动性/完整性/合规性是否恰当？ |

**枢纽原则**：

1. **K4-2 明细表是数据枢纽**——审定表按项目从明细带入。
2. **K4-3 是调整枢纽**——差异确认后回写 K4-1。
3. **K4-1 是结论枢纽**——与试算（2245）、附注披露勾稽。
4. **K4A 程序表**统领「做了哪些程序」；分表记录「证据与结论」。

> **负债类方向铁律**：其他流动负债 期末 = 期初 + 贷方（增加） − 借方（减少）；审计重点为**完整性认定**（负债易被少计/漏记）。

### 建议编制顺序（标准路径）

```
K4A 程序计划
  → K4-2 明细（按项目逐笔立清单）
  → K4-4 检查表（分类/流动性/完整性/合规性）
  → 差异汇入 K4-3 → 确认回写 K4-1
  → 附注上市 / 附注国企
```

可按项目风险裁剪，但 **明细 → K4-1** 不宜省略。

## 2. 分表编制说明

每张表按统一结构：**审计目标 → 编制逻辑 → 上游/下游 → 完成标志**。

### K4A 实质性程序表
- **审计目标**：规划并记录针对其他流动负债的实质性程序范围、性质与时间。
- **完成标志**：计划程序均有执行记录或「不适用」说明。

### K4-1 审定表
- **审计目标**：核实其他流动负债各项余额准确完整；分类列报恰当；提供审定数。
- **编制逻辑**：按项目类型（短期应付债券/政府补助/待转销项税额/应付退货款等）展开；未审 / 账项调整(AJE) / 重分类(RJE) / 审定；审定 = 未审 + AJE + RJE。
- **上游**：K4-2 明细汇总；K4-3 确认回写。**下游**：试算表(2245)；附注。
- **完成标志**：与 TB 勾稽差异已解释；审计结论已填。

### K4-2 明细表（数据枢纽）
- **审计目标**：核实其他流动负债各项存在、完整、义务与计价。
- **编制逻辑**：按项目逐笔列示，期初 + 贷方 − 借方 = 期末滚动（2 区段 Tab）。
- **完成标志**：清单完整、滚动勾稽通过；与 K4-1 汇总一致。

### K4-3 调整分录汇总
- **审计目标**：核实调整完整、借贷平衡。
- **完成标志**：借贷平衡；已确认回写 K4-1；索引指向证据表。

### K4-4 其他流动负债检查表
- **审计目标**：凭证级综合检查（分类正确性/流动性/完整性/合规性）。
- **编制逻辑**：抽查凭证核对 5 项内容；判断分类与流动性划分是否恰当。
- **完成标志**：抽查比例达方案要求；异常已跟进。

### 附注披露（上市/国企）
- **审计目标**：按附注格式披露其他流动负债构成（短期应付债券明细/政府补助明细等），与审定勾稽。
- **完成标志**：金额与 K4-1 审定一致；已同步附注模块。

### 底稿目录
- **审计目标**：导航与编制进度总览（跨表结论口径 + 底稿架构）。
- **完成标志**：计划执行的分表状态均为完成或已说明不适用。

## 3. 认定覆盖速查

| 认定 | 主要底稿 |
|------|----------|
| 完整性（负债重点） | K4-2、K4-4 |
| 存在 | K4-2 |
| 义务 | K4-1 |
| 计价 | K4-1 |
| 列报与披露 | 附注上市/国企 |

## 5. 质量复核要点（摘要）

1. K4-2 明细合计 ↔ K4-1 未审是否勾稽？
2. K4-4 检查是否覆盖分类正确性与流动性划分？
3. K4-3 已确认调整是否已回写 K4-1？借贷是否平衡？
4. 附注金额是否等于 K4-1 审定？
