# K4 其他流动负债 — 平台使用手册

> 配合「编制手册」页签使用。本手册只说明**平台怎么操作**；审计目标与勾稽逻辑见编制手册。
> **不修改**各分表页内已有说明文案。入口：底稿目录页顶部「使用手册」按钮。

---

## 1. 打开与模式

1. 在项目底稿树打开 **K4 其他流动负债**（`componentType: k4-other-current-liabilities`，覆盖科目 2245）。
2. 通过 sheet 页签切换分表（K4A、K4-1～K4-4、附注上市/国企、底稿目录）。
3. 复杂 sheet 支持 **结构化 HTML ↔ OnlyOffice** 双模式；以项目配置为准（目录页不显示双模式）。
4. 只读阶段工具栏「取数 / 回写 / 确认」类按钮会禁用。

---

## 2. 推荐操作路径（点击顺序）

| 步骤 | 分表 | 建议操作 |
|------|------|----------|
| 1 | K4A | 勾选实质性程序、填索引 |
| 2 | K4-2 | 按项目逐笔录入其他流动负债明细 |
| 3 | K4-4 | 检查表（分类正确性/流动性/完整性/合规性） |
| 4 | K4-3 | 调整分录汇总 → 确认 → 回写 K4-1 |
| 5 | K4-1 | 「从明细带入」汇总未审 → 核对调整回写 → 勾稽 TB |
| 6 | 附注上市/国企 | 拉取上游 → 编辑 → 同步附注模块 |

---

## 3. 目录页速查

| 区块 | 说明 |
|------|------|
| 编制进度 | 各分表按实际填写字段数计算完成度 |
| 跨表结论口径 | 每张表审计结论「已填/未填」标签，点击跳转对应 sheet 补全 |
| 底稿架构 | 4 阶段泳道（审计计划/科目审定/实质性程序/披露与调整），点击卡片跳转 |
| 本循环底稿目录 | 同循环其他科目（K0~K18），点击跳转（灰色表示尚未生成） |

---

## 4. 导入导出

- 工具栏「导入/导出」按当前 sheet 作用。
- 导入后刷新当前表；若改了明细（K4-2），请重新对 K4-1 执行「从明细带入」。

---

## 5. 常见问题

| 现象 | 处理 |
|------|------|
| K4-1 审定合计 ≠ TB 数 | 检查明细是否全部带入、调整是否已确认回写 |
| 流动性划分存疑 | 结合合同到期日核对是否应重分类至非流动负债 |
| 附注同步失败 | 检查项目 ID、附注模块权限与准则类型（上市/国企） |

---

## 6. 复核入口

各分表工具栏/结论区「复核」打开复核对话。合伙人级复核提示词参考：`backend/data/tsj_review_prompts/K/`（若环境已部署）。
