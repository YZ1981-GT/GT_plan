# D3 预收账款 — 底稿编制手册

> **适用范围**：科目 **2203 预收账款**（不适用新收入准则的余额；执行新收入准则的合同性预收列 D7 合同负债）
> **组件**：`d3-prepaid-accounts`
> **说明**：本手册说明各分表的审计目标、编制逻辑与勾稽关联。
> **不替代**各表页内已有的审计目标/过程提示文案（页内说明保持不变）。
> 平台按钮与操作步骤见「使用手册」页签。

---

## 1. 总体编制思路

D3 把「预收账款」拆成三条证据链，最后汇入审定与附注：

| 证据链 | 主要底稿 | 回答的问题 |
|--------|----------|------------|
| **金额枢纽** | D3-2 明细 → D3-1 ← D3-3 | 未审→调整→审定是否完整准确？ |
| **完整性/结转** | D3-4 分析；D3-5 账龄1年以上；D3-7 凭证检查 | 预收是否应结转收入而挂账？长期挂账是否合理？ |
| **关联方/披露** | D3-6 关联方；附注 | 关联方预收、账龄结构披露是否完整？ |

**枢纽原则**：

1. **D3-2 明细表是数据枢纽**——审定表按往来单位从明细带入。
2. **D3-3 是调整枢纽**——差异确认后回写 D3-1。
3. **D3-1 是结论枢纽**——与试算（2203）、附注披露勾稽。
4. **完整性是核心风险**——预收挂账过久往往应确认收入或退回。

### 建议编制顺序（标准路径）

```
D3A 程序计划
  → D3-2 明细（先立清单，标注账龄）
  → D3-4 分析 → D3-7 凭证检查（存在/完整性）
  → D3-5 账龄1年以上检查（长期挂账合理性）
  → D3-6 关联方
  → 差异汇入 D3-3 → 确认回写 D3-1
  → 附注上市 / 附注国企
```

## 2. 分表编制说明

### D3A 实质性程序表
- **审计目标**：规划并记录预收账款实质性程序范围、性质与时间。
- **完成标志**：计划程序均有执行记录或「不适用」说明。

### D3-1 审定表
- **审计目标**：核实预收账款余额准确完整；按账龄/往来单位列报；提供审定数。
- **编制逻辑**：期初/期末 × 未审 / 账项调整 / 审定；按账龄段（动态账龄配置）展开；审定 = 未审 + 调整。
- **上游**：D3-2 汇总；D3-3 确认回写。**下游**：试算表（2203）；附注。
- **完成标志**：与 TB 勾稽差异已解释；结论已填。

### D3-2 明细表（数据枢纽）
- **审计目标**：核实存在、完整、义务与计价；逐往来单位列示账龄。
- **编制逻辑**：往来单位 × 账龄段；期末余额滚动；驱动 D3-1 账龄聚合。
- **下游**：D3-1、D3-4、D3-5 带入源。
- **完成标志**：清单完整、账龄勾稽通过；与 D3-1 汇总一致。

### D3-3 调整分录汇总表
- **审计目标**：核实预收账款及相关科目调整完整、借贷平衡。
- **完成标志**：借贷平衡；已确认回写 D3-1。

### D3-4 预收账款分析表
- **审计目标**：分析预收账款构成、账龄结构、大额与异常变动的合理性。
- **完成标志**：重大变动已解释；跨期结转疑点已跟进。

### D3-5 账龄1年以上的预收账款检查表
- **审计目标**：核查长期挂账预收的合理性——是否应确认收入、退回或转营业外收入。
- **编制逻辑**：逐笔列示挂账原因、处理结论；跨底稿联动（应确认收入→D4；应转营业外收入→K12；应退回→其他应付款）。
- **完成标志**：长期挂账处理结论已填。

### D3-6 关联关系及交易检查表
- **审计目标**：识别关联方预收，核对披露完整性。
- **完成标志**：关联方预收已识别，与 B19 清单核对。

### D3-7 预收账款检查表
- **审计目标**：以凭证级检查佐证预收账款存在、结转真实。
- **编制逻辑**：记账凭证逐笔核对（原始凭证齐全/账务处理正确/会计期间恰当）；可自动标记跨期。
- **完成标志**：抽查比例达方案要求；异常/跨期已跟进。

### 附注披露（上市/国企）
- **审计目标**：按附注格式披露预收账款账龄、前五名、关联方，与审定勾稽。
- **完成标志**：金额与 D3-1 审定一致；已同步附注模块。

### 底稿目录
- **审计目标**：导航与编制进度总览（跨表结论口径 + 底稿架构）。

## 5. 质量复核要点（摘要）

1. D3-2 合计 ↔ D3-1 未审是否勾稽？账龄段是否一致？
2. D3-3 已确认调整是否已体现在 D3-1？借贷是否平衡？
3. D3-5 长期挂账是否有处理结论？应确认收入的是否与 D4 勾稽？
4. D3-7 跨期项是否已标注处理？
5. 附注金额是否等于 D3-1 审定？
