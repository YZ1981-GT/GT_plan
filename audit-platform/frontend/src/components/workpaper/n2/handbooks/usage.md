# N2 应交税费 — 平台使用手册

> 配合「编制手册」页签使用。本手册只说明**平台怎么操作**；审计目标与勾稽逻辑见编制手册。
> **不修改**各分表页内已有说明文案。入口：底稿目录页顶部「使用手册」按钮。

---

## 1. 打开与模式

1. 在项目底稿树打开 **N2 应交税费**（`componentType: n2-taxes-payable`，覆盖科目 2221）。
2. 通过 sheet 页签切换分表（N2A、N2-1～N2-11、附注上市/国企、底稿目录）。
3. 复杂 sheet 支持 **结构化 HTML ↔ OnlyOffice** 双模式；以项目配置为准（目录页不显示双模式）。
4. 只读阶段工具栏「取数 / 回写 / 确认」类按钮会禁用。

---

## 2. 推荐操作路径（点击顺序）

| 步骤 | 分表 | 建议操作 |
|------|------|----------|
| 1 | N2A | 勾选实质性程序、填索引 |
| 2 | N2-6 | 增值税测算：销项 −（进项 − 进项转出） |
| 3 | N2-8/9/10 | 城建税及附加 / 房产税 / 土地增值税测算 |
| 4 | N2-2 | 按税种录入计提/缴纳/期末明细 |
| 5 | N2-3 | 调整分录汇总 → 确认 → 回写 N2-1 |
| 6 | N2-1 | 确认各税种审定期末 → 回写 TB(2221) → 核对 N4 |
| 7 | 附注上市/国企 | 从审定表取数 → 编辑 → 同步附注模块 |

## 3. 目录页速查

| 区块 | 说明 |
|------|------|
| 编制进度 | 各分表按审计说明/结论填写情况计算完成度 |
| 跨表结论口径 | 每张表审计结论「已填/未填」标签，点击跳转对应 sheet 补全 |
| 底稿架构 | 4 阶段泳道（审计计划/科目审定/实质性程序/披露与调整），点击卡片跳转 |
| 本循环底稿目录 | 同循环其他科目（N1~N5），点击跳转（灰色表示尚未生成） |

---

## 4. 常见问题

| 现象 | 处理 |
|------|------|
| N2-1 审定 ≠ TB 数 | 检查明细/测算是否全部带入、调整是否已确认回写；TB 取 2221 期末余额 |
| 城建税及附加计税依据为空 | 先完成 N2-6 增值税测算，其应交增值税自动作为 N2-8 计税依据 |
| 与 N4 税金及附加不符 | 复核 N2 各税种本期计提额与 N4 费用确认是否一致 |
| 出口退税额不符 | 核对 N2-7 免抵退税额计算与增值税申报表 |
| 附注同步失败 | 检查项目 ID、附注模块权限与准则类型（上市/国企） |

## 5. 复核入口

各分表工具栏/结论区「复核」打开复核对话。合伙人级复核提示词参考：`backend/data/tsj_review_prompts/N/`（若环境已部署）。
