## 1. 总体编制思路

应交税费是**多税种归集科目**（增值税、城建税及附加、房产税、土地增值税、出口退税等），核心是核实各税种**计提是否准确、缴纳是否及时、期末余额是否完整**。

| 证据链 | 主要底稿 | 回答的问题 |
|--------|----------|------------|
| **金额枢纽** | N2-2 明细 → N2-1 审定 ← N2-3 调整 | 各税种期末应交余额是否准确完整？ |
| **计量引擎** | N2-6 增值税 / N2-8 其他税费 / N2-9 房产税 / N2-10 土地增值税 | 各税种应交额测算是否恰当？ |
| **合规检查** | N2-4 税收政策检查 / N2-5 认定表 / N2-11 检查表 / N2-7 出口退税 | 计税依据、税率、优惠适用是否合规？ |

**枢纽原则**：

1. **负债类贷方科目**：期末 = 期初 + 本期贷方（计提增加）− 本期借方（缴纳减少），取期末余额。
2. **测算表是计量核心**：N2-6 增值税测算 = 销项税额 −（进项税额 − 进项转出）；城建税及附加计税依据取自增值税+消费税。
3. **N2-1 是结论枢纽**：各税种审定期末余额回写试算表 2221；各税种本期计提额供 N4 税金及附加费用核对。
4. **多税种分行列示**：审定表按税种（增值税/城建税/教育费附加/房产税/土地增值税等）分行，各行独立审定。

### 建议编制顺序

```
N2A 程序计划
  → N2-6 增值税测算 + N2-8/N2-9/N2-10 其他税费测算
  → N2-2 明细（按税种逐项计提/缴纳/期末）
  → 差异汇入 N2-3 → 确认回写 N2-1
  → N2-1 勾稽 TB(2221) + 各税种计提额核对 N4 → 附注上市/国企
```

## 2. 分表编制说明

### N2A 实质性程序表
- **审计目标**：规划并记录应交税费实质性程序范围、性质与时间。
- **完成标志**：计划程序均有执行记录或「不适用」说明。

### N2-1 审定表（负债类贷方）
- **审计目标**：核实各税种期末应交余额准确完整；提供审定数。
- **编制逻辑**：期末 = 期初 + 贷方（计提）− 借方（缴纳）；审定 = 未审 + AJE + RJE，按税种分行。
- **上游**：N2-2 明细 / N2-6~N2-10 各测算表；N2-3 确认回写。**下游**：TB(2221)、N4 税金及附加费用核对、附注。
- **完成标志**：与 TB 及各测算表勾稽差异已解释；审计结论已填。

### N2-2 明细表
- **审计目标**：核实各税种计提、缴纳、期末余额存在、完整、准确。
- **完成标志**：清单完整、合计与 N2-1 一致。

### N2-3 调整分录汇总
- **审计目标**：核实调整完整、借贷平衡。
- **完成标志**：借贷平衡；已确认回写 N2-1。

### N2-4 税收政策检查
- **审计目标**：核实税收政策、税率、优惠适用的合规性。
- **完成标志**：政策依据充分；审计结论已填。

### N2-5 应交税金认定表
- **审计目标**：将应交税费各认定映射到测试程序，核实覆盖充分。
- **完成标志**：各认定均有对应程序；结论已填。

### N2-6 增值税测算表（核心引擎）
- **审计目标**：核实应交增值税测算恰当。
- **编制逻辑**：应交增值税 = 销项税额 −（进项税额 − 进项转出）；结果供城建税及附加计税依据。
- **完成标志**：与 N2-1 增值税行审定一致。

### N2-7 出口退税核对表
- **审计目标**：核实出口退税免抵退税额计算与申报一致。
- **完成标志**：退税额核对无误；结论已填。

### N2-8 应交其他税费测算表
- **审计目标**：核实城建税及附加（城建税/教育费附加/地方教育附加）测算恰当。
- **编制逻辑**：计税依据 =（增值税 + 消费税）；城建税率分市区 7% / 县城 5% / 其他 1%，加教育费附加 3% + 地方教育附加 2%。
- **完成标志**：与 N2-1 相关税种行审定一致。

### N2-9 房产税测算表
- **审计目标**：核实房产税测算恰当。
- **编制逻辑**：从价 = 原值 ×（1 − 扣除比例）× 1.2%；从租 = 租金 × 12%。
- **完成标志**：与 N2-1 房产税行审定一致。

### N2-10 土地增值税测算表
- **审计目标**：核实土地增值税测算恰当。
- **编制逻辑**：四级超率累进（30%/40%/50%/60%），增值率 = 增值额 ÷ 扣除项目金额。
- **完成标志**：与 N2-1 土地增值税行审定一致。

### N2-11 应交税费检查表
- **审计目标**：核实各税种申报、计提、缴纳凭证的真实合规。
- **完成标志**：检查比例达标；异常已说明；结论已填。

### 附注披露（上市/国企）
- **审计目标**：按附注格式披露各税种应交余额，与审定勾稽。
- **完成标志**：金额与 N2-1 审定一致；已同步附注模块。

### 底稿目录
- **审计目标**：导航与编制进度总览（跨表结论口径 + 底稿架构 + 本循环其他科目）。

## 4. 外部模块衔接

| 模块 | 与 N2 关系 |
|------|------------|
| **N4 税金及附加** | 各税种本期计提额 → N4 费用确认核对（城建税/教育费附加/房产税/土地使用税等） |
| **试算平衡表** | N2-1 各税种审定期末余额回写 2221 |

## 5. 质量复核要点（摘要）

1. 各测算表结果 ↔ N2-1 对应税种行审定是否勾稽？
2. N2-1 审定期末合计 ↔ TB(2221) 是否勾稽？
3. N2 各税种本期计提额 ↔ N4 税金及附加费用确认是否一致？
4. 增值税进项转出、出口退税免抵退是否合规？
5. 附注金额是否等于 N2-1 审定？
