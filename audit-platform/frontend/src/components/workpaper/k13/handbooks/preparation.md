# K13 营业外支出 — 底稿编制手册

> **适用范围**：科目 **6711 营业外支出（借方/损益类）**（与企业日常活动无关的损失：非流动资产毁损报废损失/捐赠支出/罚款支出/非常损失/债务重组损失等）
> **组件**：`k13-non-operating-expense`
> **说明**：本手册说明各分表的审计目标、编制逻辑与勾稽关联，不替代各表页内已有说明文案。
> 平台按钮与操作步骤见「使用手册」页签。

---

## 1. 总体编制思路

K13 把「营业外支出」拆成三条证据链，最后汇入审定与附注：

| 证据链 | 主要底稿 | 回答的问题 |
|--------|----------|------------|
| **金额枢纽** | K13-2 明细 → K13-1 审定 ← K13-3 调整 | 营业外支出各性质发生额未审→调整→审定是否完整准确？ |
| **凭证级检查** | K13-4 检查表 | 大额/异常项目是否真实、有据、税前扣除性是否恰当？ |

**枢纽原则**：

1. **损益类借方科目（6711）取本期借方发生额累计（借方 = 支出增加），非期末余额**。
2. **营业外支出仅指与日常活动无关的损失**。
3. **关注税前扣除性**——罚款/滞纳金/赞助支出等不得税前扣除，需关注纳税调整（联动 N4 税金及附加/所得税）。
4. **K13-2 明细表是数据枢纽**——审定表从明细带入。
5. **K13-3 是调整枢纽**——差异确认后回写 K13-1，联动 A13。
6. **K13-1 是结论枢纽**——审定发生额回写试算平衡表（6711）、与附注披露勾稽。

### 建议编制顺序（标准路径）

```
K13A 程序计划
  → K13-2 明细（按性质登记发生额）
  → K13-4 检查表（凭证级：真实性/审批/期间/税前扣除性）
  → 差异汇入 K13-3 → 确认回写 K13-1（TB 回写 6711）
  → 附注上市 / 附注国企
```

## 2. 分表编制说明

每张表按统一结构：**审计目标 → 编制逻辑 → 上游/下游 → 完成标志**。

### K13A 实质性程序表
- **审计目标**：规划并记录针对营业外支出的实质性程序范围、性质与时间。
- **完成标志**：计划程序均有执行记录或「不适用」说明。

### K13-1 审定表
- **审计目标**：核实营业外支出各性质发生额准确完整；分类列报恰当；提供审定数。
- **编制逻辑**：按支出性质展开；未审发生额 + AJE + RJE = 审定发生额；审定发生额回写 TB（6711）。
- **上游**：K13-2 明细汇总；K13-3 确认回写。**下游**：试算表(6711)；附注。
- **完成标志**：与 TB 勾稽差异已解释；审计结论已填。

### K13-2 明细表（数据枢纽）
- **审计目标**：核实营业外支出各性质发生额存在、完整、准确。
- **编制逻辑**：逐笔登记支出性质本期借方发生额。
- **完成标志**：清单完整、与 K13-1 汇总一致。

### K13-3 调整分录汇总
- **审计目标**：核实调整完整、借贷平衡。
- **完成标志**：借贷平衡；已确认回写 K13-1；联动 A13 错报汇总。

### K13-4 营业外支出检查表
- **审计目标**：凭证级综合检查（真实性/审批/期间/税前扣除性）。
- **完成标志**：抽查比例达方案要求；异常已跟进；税前扣除性判断有据。

### 附注披露（上市/国企）
- **审计目标**：按性质分别披露营业外支出金额（含计入当期非经常性损益的金额），与审定勾稽。
- **完成标志**：金额与 K13-1 审定一致；已同步附注模块。

### 底稿目录
- **审计目标**：导航与编制进度总览（跨表结论口径 + 底稿架构）。
- **完成标志**：计划执行的分表状态均为完成或已说明不适用。

## 3. 认定覆盖速查

| 认定 | 主要底稿 |
|------|----------|
| 发生 | K13-4 |
| 完整性 | K13-2 |
| 准确性 | K13-1、K13-4 |
| 分类 | K13-1、K13-4、附注上市/国企 |

---

## 4. 外部模块衔接

| 模块 | 与 K13 关系 |
|------|------------|
| **调整分录模块** | 与 K13-3 双向同步；确认驱动 K13-1 |
| **试算平衡表** | K13-1 审定发生额回写 6711 |
| **N4 税金及附加/所得税** | 不得税前扣除支出的纳税调整 |
| **附注模块** | 营业外支出披露（含非经常性损益） |
| **A13 错报汇总** | K13-3 调整推送 |

---

## 5. 质量复核要点（摘要）

1. K13-2 明细合计 ↔ K13-1 未审是否勾稽？
2. K13-1 审定发生额是否已回写 TB（6711）？借贷是否平衡？
3. K13-4 抽查比例是否达标？税前扣除性判断是否有据？
4. 附注金额是否等于 K13-1 审定？非经常性损益列报是否正确？
