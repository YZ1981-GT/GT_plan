# F3 应付票据 — 底稿编制手册

> **适用范围**：科目 **2201 应付票据**（银行承兑汇票 / 商业承兑汇票 / 供应链票据）
> **组件**：`f3-notes-payable`（贷方科目：期末 = 期初审定 + 贷方 − 借方）
> **说明**：本手册说明各分表的审计目标、编制逻辑与勾稽关联。
> **不替代**各表页内已有的审计目标/过程提示文案（页内说明保持不变）。
> 平台按钮与操作步骤见「使用手册」页签。

## 1. 总体编制思路

F3 把「应付票据」拆成三条证据链，最后汇入审定与附注：

| 证据链 | 主要底稿 | 回答的问题 |
|--------|----------|------------|
| **金额枢纽** | F3-2 → F3-1 ← F3-3 | 未审→调整→审定是否完整准确？ |
| **完整/权利** | F3-7 凭证检查；F3-6 关联方；F3-5 逾期检查 | 应付票据是否完整入账、逾期风险、关联方票据？ |
| **计价/披露** | F3-4 带息票据利息测算；附注 | 带息票据利息是否计提、票据分类与已质押披露是否完整？ |

**枢纽原则（负债完整性重点）**：

1. **F3-2 明细表是数据枢纽**——审定表按承兑类别（银承/商承/供应链）从明细带入；负债审计重点在**完整性**（有无未入账应付票据）。
2. **F3-3 是调整枢纽**——差异确认后回写 F3-1；逾期票据（银承逾期→短期借款、商承逾期→应付账款）可提示重分类。
3. **F3-1 是结论枢纽**——与试算（2201）勾稽，向报表与附注提供审定数。
4. **F3A 程序表**统领「做了哪些程序」。

### 建议编制顺序（标准路径）

```
F3A 程序计划
  → F3-2 明细表（先立清单，按银承/商承/供应链票据分类）
  → 完整性链：F3-7 凭证检查（票据签发/承兑/兑付凭证）→ 完整性搜索（有无未入账票据）
  → F3-5 逾期检查（逾期票据风险与重分类）
  → F3-6 关联方票据识别
  → 计价链：F3-4 带息票据利息测算（供应链/带息票据）
  → 差异汇入 F3-3 → 确认回写 F3-1
  → F3-1 从明细带入 → 勾稽 TB(2201)
  → 附注上市 / 附注国企
```

按项目风险裁剪（无带息票据可弱化 F3-4；无逾期可弱化 F3-5），但 **明细 → F3-1** 与 **完整性搜索** 不宜省略。

## 2. 分表编制说明

每张表按统一结构：**审计目标 → 编制逻辑 → 上游/下游 → 完成标志**。

### F3A 实质性程序表
- **审计目标**：规划并记录针对应付票据的实质性程序范围、性质与时间。
- **完成标志**：计划程序均有执行记录或「不适用」说明；索引可跳转分表。

### F3-1 审定表
- **审计目标**：核实应付票据余额完整准确；银承/商承/供应链分类列报恰当；为报表与附注提供审定数。
- **编制逻辑**：期初/期末 × 未审 / 账项调整 / 审定；按承兑类别展开（含供应链票据）；审定 = 未审 + 调整。
- **上游**：F3-2 汇总；F3-3 确认回写。**下游**：试算表（2201）；附注。
- **完成标志**：与 TB 勾稽差异已解释；调整来源可追溯至 F3-3；结论已填。

### F3-2 明细表（数据枢纽）
- **审计目标**：核实完整、权利与义务、计价；按承兑类别与出票人/收款人列示。
- **编制逻辑**：逐票据列示票据类别、票面金额、签发/到期日、收款人、保证金；期后兑付/结转情况佐证。
- **下游**：F3-1、F3-4、F3-5、F3-6 带入源。
- **完成标志**：清单完整、与 F3-1 汇总一致；含供应链票据。

### F3-3 调整分录
- **审计目标**：核实应付票据及相关科目调整完整、借贷平衡。
- **编制逻辑**：逾期银行承兑→短期借款（2001）、逾期商业承兑→应付账款（2202）的重分类提示。
- **完成标志**：借贷平衡；已确认回写 F3-1；索引指向证据表。

### F3-4 带息票据利息测算
- **审计目标**：带息票据（供应链/带息商票）利息计提完整准确。
- **编制逻辑**：按票面利率、期间测算应计利息，与账面（应付利息）差异分析；可与 L2 应付利息勾稽。
- **完成标志**：利息测算与账面差异已解释。

### F3-5 逾期检查
- **审计目标**：识别逾期未兑付票据，评估重分类与信用风险。
- **编制逻辑**：按到期日筛选逾期票据，逐笔说明逾期金额、原因；关联 ECL 阶段升级信号。
- **完成标志**：逾期票据逐笔有说明与处置结论。

### F3-6 关联方
- **审计目标**：识别关联方应付票据，核对披露完整性。
- **完成标志**：关联方票据已识别，与 B19 清单核对。

### F3-7 凭证检查
- **审计目标**：以凭证级检查佐证票据签发、承兑、兑付真实完整（含完整性搜索）。
- **编制逻辑**：抽凭引擎科目 2201；记账凭证 + 支持性文件（票据/承兑协议）；期后付款检查佐证完整性。
- **完成标志**：抽查比例达方案要求；异常已跟进；无未入账票据。

### 附注披露（上市/国企）
- **审计目标**：按附注格式披露应付票据构成、已开具未到期票据、保证金、已质押票据等，与审定勾稽。
- **完成标志**：金额与 F3-1 审定一致；分类与受限情况已披露；已同步附注模块。

### 底稿目录
- **审计目标**：导航与编制进度总览（跨表结论口径 + 底稿架构）。

## 4. 外部模块衔接

| 模块 | 与 F3 关系 |

| **调整分录模块** | 与 F3-3 双向同步；确认驱动 F3-1 |

## 5. 质量复核要点（摘要）

1. F3-2 合计 ↔ F3-1 未审是否勾稽？供应链票据是否纳入？
2. 完整性搜索是否执行（有无未入账应付票据）？
3. F3-3 已确认调整是否已体现在 F3-1？借贷是否平衡？
4. F3-5 逾期票据是否有重分类/信用风险结论？
5. 附注金额是否等于 F3-1 审定？已质押/未到期票据是否披露？
