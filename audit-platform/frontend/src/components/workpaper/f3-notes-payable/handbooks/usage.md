# F3 应付票据 — 平台使用手册

> 配合「编制手册」页签使用。
> 本手册只说明**平台怎么操作**；审计目标与勾稽逻辑见编制手册。
> **不修改**各分表页内已有说明文案。
> 入口：底稿目录页顶部「使用手册」按钮。

---

## 1. 打开与模式

1. 在项目底稿树打开 **F3 应付票据**（`componentType: f3-notes-payable`，覆盖科目 2201）。
2. 通过 sheet 页签切换分表（F3A、F3-1～F3-7、附注上市/国企、底稿目录）。
3. 复杂 sheet 支持 **结构化 HTML ↔ OnlyOffice** 双模式；以项目配置为准（目录页除外）。
4. 只读阶段工具栏「取数 / 回写 / 确认」类按钮会禁用。

**需要项目上下文的操作**（缺 `projectId` 会提示无法执行）：

- F3-7 抽凭
- 附注「同步到附注模块」

---

## 2. 推荐操作路径（点击顺序）

| 步骤 | 分表 | 建议操作 |
|------|------|----------|
| 1 | F3A | 勾选实质性程序、填索引 |
| 2 | F3-2 | 录入票据明细（类别/票面/到期/收款人/保证金） |
| 3 | F3-7 | 凭证检查（抽凭引擎，科目 2201）+ 完整性搜索 |
| 4 | F3-5 | 逾期票据检查（重分类提示） |
| 5 | F3-6 | 关联方票据识别（与 B19 核对） |
| 6 | F3-4 | 带息票据利息测算（与 L2 勾稽） |
| 7 | F3-3 | 调整分录 → 确认 → 回写 F3-1 |
| 8 | F3-1 | 「从明细带入」汇总未审 → 核对调整回写 → 勾稽 TB |
| 9 | 附注上市/国企 | 拉取上游 → 编辑 → 同步附注模块 |

## 3. 目录页速查

| 区块 | 说明 |
|------|------|
| 编制进度 | 各分表填妥「审计说明或结论」即计入完成 |
| 跨表结论口径 | 每张表审计结论「已填/未填」标签，点击跳转对应 sheet 补全 |
| 编制提示 | 折叠展开，推荐编制工作流 |
| 底稿架构 | 4 阶段泳道（审计计划/科目审定/实质性程序/披露与调整），点击卡片跳转 |
| 本循环底稿目录 | 同循环（F 循环）其他底稿（灰色表示未生成） |

---

## 4. 导入导出

- 工具栏「导入/导出」按当前 sheet 作用（具备后端端点的 sheet）。
- F3-2 为宽表，可用「导入导出▾」+ ⚙列设置；导入后刷新当前表；改了明细请重新对 F3-1 执行「从明细带入」。

---

## 5. 常见问题

| 现象 | 处理 |
|------|------|
| F3-1 审定合计 ≠ TB 数 | 检查明细是否全部带入、调整是否已确认回写 |
| 供应链票据缺失 | F3-2/F3-1 承兑类别需含供应链票据 |
| 逾期票据无结论 | F3-5 逐笔填逾期原因与重分类/信用风险结论 |
| 带息利息对不上 | F3-4 核对票面利率与计息期间，与 L2 应付利息勾稽 |
| 抽凭无数据 | 确认凭证库有 2201 发生额且抽凭引擎可访问 |
| 附注同步失败 | 检查项目 ID、附注模块权限与准则类型（上市/国企） |

## 6. 复核入口

各分表工具栏/结论区「复核」打开复核对话（按 section-id）。
合伙人级复核提示词参考：`backend/data/tsj_review_prompts/F/`（若环境已部署）。
