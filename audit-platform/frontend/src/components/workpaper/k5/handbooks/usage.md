# K5 预计负债 — 平台使用手册

> 配合「编制手册」页签使用。本手册只说明**平台怎么操作**；审计目标与勾稽逻辑见编制手册。
> **不修改**各分表页内已有说明文案。入口：底稿目录页顶部「使用手册」按钮。

---

## 1. 打开与模式

1. 在项目底稿树打开 **K5 预计负债**（`componentType: k5-provisions`，覆盖科目 2701，CAS13 或有事项）。
2. 通过 sheet 页签切换分表（K5A、K5-1～K5-7、附注上市/国企、底稿目录）。
3. 复杂 sheet 支持 **结构化 HTML ↔ OnlyOffice** 双模式；以项目配置为准（目录页不显示双模式）。
4. 只读阶段工具栏「取数 / 回写 / 确认」类按钮会禁用。

---

## 2. 推荐操作路径（点击顺序）

| 步骤 | 分表 | 建议操作 |
|------|------|----------|
| 1 | K5A | 勾选实质性程序、填索引 |
| 2 | K5-2 | 识别或有事项、判断三级可能性、计量最佳估计数 |
| 3 | K5-4 | 产品质量保修测算（收入 × 保修率），历史率对照 |
| 4 | K5-5 | 弃置费用现值折现，评估关键假设 |
| 5 | K5-6 | 未决诉讼律师函联动，判断可能性与预计损失 |
| 6 | K5-7 | 综合检查（10 项合规判断） |
| 7 | K5-3 | 调整分录汇总 → 确认 → 回写 K5-1 |
| 8 | K5-1 | 汇总各类型未审 → 核对调整回写 → 勾稽 TB(2701) |
| 9 | 附注上市/国企 | 拉取上游 → 编辑（预计负债+或有负债）→ 同步附注模块 |

---

## 3. 目录页速查

| 区块 | 说明 |
|------|------|
| 编制进度 | 各分表按实际填写字段数计算完成度 |
| 跨表结论口径 | 每张表审计结论「已填/未填」标签，点击跳转对应 sheet 补全 |
| 底稿架构 | 4 阶段泳道（审计计划/科目审定/实质性程序/披露与调整），点击卡片跳转 |
| 本循环底稿目录 | 同循环其他科目（K0~K18），点击跳转（灰色表示尚未生成） |

---

## 4. 导入导出

- 工具栏「导入/导出」按当前 sheet 作用。
- 导入后刷新当前表；若改了明细（K5-2）或专项检查，请重新核对 K5-1 各类型行。

---

## 5. 常见问题

| 现象 | 处理 |
|------|------|
| K5-1 审定合计 ≠ TB 数 | 检查各专项检查是否回连、调整是否已确认回写 |
| 可能性判断难以界定 | 结合律师函、历史数据、专家意见按 CAS13 三级判断 |
| 弃置现值折现结果存疑 | 复核折现率、期限与未来弃置支出估计 |
| 附注同步失败 | 检查项目 ID、附注模块权限与准则类型（上市/国企） |

---

## 6. 复核入口

各分表工具栏/结论区「复核」打开复核对话。合伙人级复核提示词参考：`backend/data/tsj_review_prompts/K/`（若环境已部署）。
