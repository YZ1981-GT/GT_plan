# K5 预计负债 — 底稿编制手册

> **适用范围**：科目 **2701 预计负债（贷方/负债类）**（含产品质量保证、弃置义务、未决诉讼、亏损合同、重组义务等）
> **准则**：**CAS13 或有事项**
> **组件**：`k5-provisions`
> **说明**：本手册说明各分表的审计目标、编制逻辑与勾稽关联，不替代各表页内已有说明文案。
> 平台按钮与操作步骤见「使用手册」页签。

---

## 1. 总体编制思路

K5 围绕 CAS13 或有事项，把「预计负债」拆成识别计量与专项检查两条证据链，最后汇入审定与附注：

| 证据链 | 主要底稿 | 回答的问题 |
|--------|----------|------------|
| **识别与计量枢纽** | K5-2 明细 → K5-1 审定 ← K5-3 调整 | 或有事项是否识别？可能性判断与最佳估计数是否恰当？ |
| **专项检查** | K5-4 质保 / K5-5 弃置 / K5-6 诉讼 / K5-7 综合 | 各类预计负债的计量方法、假设与合规性是否恰当？ |

**枢纽原则**：

1. **K5-2 明细表是识别枢纽**——识别或有事项、判断三级可能性、计量最佳估计数。
2. **各专项检查（K5-4/5/6）回连 K5-1**——按类型填入审定表对应行。
3. **K5-3 是调整枢纽**——差异确认后回写 K5-1。
4. **K5-1 是结论枢纽**——与试算（2701）、附注披露勾稽。
5. **K5A 程序表**统领「做了哪些程序」；分表记录「证据与结论」。

> **CAS13 三级可能性**：很可能(>50%)→确认预计负债；可能(≤50%)→披露或有负债；极小可能→不处理。
> **最佳估计数**：单一最可能金额 / 区间中值(上+下)/2 / 期望值加权 Σ(金额×概率)；时间价值重大时（如弃置费用）按现值折现。

### 建议编制顺序（标准路径）

```
K5-2 明细（识别或有事项 + 可能性判断 + 最佳估计数）
  → 专项检查：K5-4 质保测算 → K5-5 弃置现值 → K5-6 诉讼律师函
  → K5-7 综合检查（10 项合规判断）
  → 差异汇入 K5-3 → 确认回写 K5-1（TB 2701）
  → 附注上市 / 附注国企（预计负债 + 或有负债披露）
```

可按项目风险裁剪（如无弃置义务可弱化 K5-5），但 **明细识别 → K5-1** 与 **或有负债披露** 不宜省略。

## 2. 分表编制说明

每张表按统一结构：**审计目标 → 编制逻辑 → 上游/下游 → 完成标志**。

### K5A 实质性程序表
- **审计目标**：规划并记录针对预计负债的实质性程序范围、性质与时间。
- **完成标志**：计划程序均有执行记录或「不适用」说明。

### K5-1 审定表
- **审计目标**：核实预计负债各项余额准确完整；分类列报恰当；提供审定数。
- **编制逻辑**：按类型（质保/弃置/诉讼/亏损合同/重组）展开；未审 / 账项调整(AJE) / 重分类(RJE) / 审定；审定 = 未审 + AJE + RJE。
- **上游**：K5-2 明细 + 各专项检查回连；K5-3 确认回写。**下游**：试算表(2701)；附注。
- **完成标志**：与 TB 勾稽差异已解释；审计结论已填。

### K5-2 明细表（识别枢纽）
- **审计目标**：核实或有事项识别完整、可能性判断恰当、最佳估计数计量准确。
- **编制逻辑**：逐项识别或有事项，判断三级可能性，计量最佳估计数（3 区段 + 色标）。
- **完成标志**：或有事项识别完整；可能性与计量有据；与 K5-1 汇总一致。

### K5-3 调整分录汇总
- **审计目标**：核实调整完整、借贷平衡。
- **完成标志**：借贷平衡；已确认回写 K5-1；索引指向证据表。

### K5-4 产品质量保修检查表
- **审计目标**：核实产品质量保证预计负债计量恰当。
- **编制逻辑**：政策 + 历史保修率对照（本期及前两期）+ 重新测算（计提基数 × 保修率）+ 差异 + 预计发生时间。
- **完成标志**：保修率合理性有据；测算差异已解释；与 K5-1 质保行一致。

### K5-5 弃置费用检查表
- **审计目标**：核实弃置义务预计负债的现值计量与利息调整恰当。
- **编制逻辑**：完整性检查 + 关键假设评估 + 现值折现（future/(1+rate)^years）+ 本期利息调整 + 借贷方发生额分析。
- **完成标志**：假设合理；现值计算准确；与 K5-1 弃置行一致。

### K5-6 未决诉讼检查表
- **审计目标**：核实未决诉讼可能性判断与预计损失计量恰当。
- **编制逻辑**：律师函联动 + 三级可能性判断 + 预计损失 + 已计提差异 + 差异原因。
- **完成标志**：律师函证据充分；预计损失有据；与 K5-1 诉讼行一致。

### K5-7 预计负债综合检查表
- **审计目标**：凭证级综合检查（10 项合规/不合规/不适用逐项判断）。
- **编制逻辑**：抽查凭证核对；判断确认条件、计量方法、披露充分性。
- **完成标志**：抽查比例达方案要求；异常已跟进。

### 附注披露（上市/国企）
- **审计目标**：按附注格式披露预计负债构成与或有负债，与审定勾稽。
- **完成标志**：金额与 K5-1 审定一致；或有负债已披露；已同步附注模块。

### 底稿目录
- **审计目标**：导航与编制进度总览（跨表结论口径 + 底稿架构）。
- **完成标志**：计划执行的分表状态均为完成或已说明不适用。

## 4. 外部模块衔接

| 模块 | 与 K5 关系 |
|------|------------|
| **调整分录模块** | 与 K5-3 双向同步；确认驱动 K5-1 |
| **试算平衡表** | K5-1 审定回写 2701 |
| **律师函/函证** | K5-6 未决诉讼可能性判断证据来源 |
| **附注模块** | 预计负债 + 或有负债披露 |

---

## 5. 质量复核要点（摘要）

1. K5-2 或有事项识别是否完整？三级可能性判断是否恰当？
2. 各专项检查（K5-4/5/6）期末是否与 K5-1 对应类型行一致？
3. 最佳估计数计量方法（单值/中值/期望值）是否恰当？弃置现值折现是否合理？
4. K5-3 已确认调整是否已回写 K5-1？借贷是否平衡？
5. 附注是否既披露预计负债又披露或有负债？金额是否等于 K5-1 审定？
