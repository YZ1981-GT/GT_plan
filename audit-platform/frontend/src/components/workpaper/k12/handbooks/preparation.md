# K12 营业外收入 — 底稿编制手册

> **适用范围**：科目 **6301 营业外收入（贷方/损益类）**（政府补助、盘盈利得、捐赠利得、罚款收入、债务重组利得等与日常活动无关的利得）
> **组件**：`k12-non-operating-income`
> **说明**：本手册说明各分表的审计目标、编制逻辑与勾稽关联，不替代各表页内已有说明文案。
> 平台按钮与操作步骤见「使用手册」页签。

---

## 1. 总体编制思路

K12 把「营业外收入」拆成金额枢纽与专项检查，最后汇入审定与附注：

| 证据链 | 主要底稿 | 回答的问题 |
|--------|----------|------------|
| **金额枢纽** | K12-2 明细 → K12-1 审定 ← K12-3 调整 | 营业外收入各来源本期发生额是否真实完整准确？ |
| **专项检查** | K12-4 检查表 | 凭证级抽查是否真实、有据、期间正确、分类恰当？ |
| **列报披露** | 附注上市 / 附注国企 | 按来源分类披露是否与审定一致？ |

**枢纽原则**：

1. **K12-2 明细表是数据枢纽**——审定表从明细带入。
2. **K12-3 是调整枢纽**——差异确认后回写 K12-1，联动 A13。
3. **K12-1 是结论枢纽**——审定发生额回写试算表（6301），与附注勾稽。
4. **K12A 程序表**统领「做了哪些程序」；分表记录「证据与结论」。

> **损益类科目铁律**：营业外收入取本期**发生额**（贷方发生 − 借方发生），**非期末余额**。

### 建议编制顺序（标准路径）

```
K12A 程序计划
  → K12-2 明细（逐笔按来源立清单）
  → K12-4 检查表（凭证级抽查分类正确性）
  → 差异汇入 K12-3 → 确认回写 K12-1
  → K12-1 勾稽 TB(6301) → 附注上市 / 附注国企
```

## 2. 分表编制说明

每张表按统一结构：**审计目标 → 编制逻辑 → 上游/下游 → 完成标志**。

### K12A 实质性程序表
- **审计目标**：规划并记录针对营业外收入的实质性程序范围、性质与时间。
- **完成标志**：计划程序均有执行记录或「不适用」说明。

### K12-1 审定表
- **审计目标**：核实营业外收入本期发生额真实完整准确；按来源分类恰当；提供审定数。
- **编制逻辑**：按来源分行（政府补助/盘盈利得/捐赠利得/罚款收入/债务重组利得/其他）；审定 = 未审 + AJE + RJE；同比变动 =（本期审定 − 上期审定）÷ |上期审定|。
- **上游**：K12-2 明细汇总；K12-3 确认回写。**下游**：试算表(6301)；附注。
- **完成标志**：与 TB 勾稽差异已解释；审计结论已填。

### K12-2 明细表（数据枢纽）
- **审计目标**：核实各来源营业外收入发生、完整、准确、分类。
- **编制逻辑**：逐笔登记本期营业外收入，按来源分类；合计行联动 K12-1 审定净发生额。
- **完成标志**：清单完整；合计与 K12-1 一致。

### K12-3 调整分录汇总
- **审计目标**：核实调整完整、借贷平衡。
- **完成标志**：借贷平衡；已确认回写 K12-1；索引指向证据表；联动 A13 错报汇总。

### K12-4 营业外收入检查表（凭证级）
- **审计目标**：凭证级综合检查（原始凭证齐全/账记相符/账务处理正确/会计期间恰当/分类正确）。
- **编制逻辑**：从 K12-2 明细抽凭核查；分类正确性——与日常活动**无关**的利得计入 6301 营业外收入，与日常相关计入 6117 其他收益（K10）。
- **完成标志**：抽查比例达方案要求；异常已跟进（红色标记）；审计结论已填。

### 附注披露（上市/国企）
- **审计目标**：按附注格式披露营业外收入构成，与审定勾稽；关注非经常性损益列报。
- **完成标志**：金额与 K12-1 审定一致；已同步附注模块。

### 底稿目录
- **审计目标**：导航与编制进度总览（跨表结论口径 + 底稿架构 + 本循环其他科目）。
- **完成标志**：计划执行的分表状态均为完成或已说明不适用。

## 4. 外部模块衔接

| 模块 | 与 K12 关系 |
|------|------------|
| **调整分录模块 / A13** | 与 K12-3 双向同步；确认驱动 K12-1；异常项推送 A13 错报 |
| **试算平衡表** | K12-1 审定发生额回写 6301 |
| **附注模块** | 营业外收入披露（非经常性损益） |
| **K10 其他收益** | 分类边界：与日常相关→6117(K10)；无关→6301(K12) |

---

## 5. 质量复核要点（摘要）

1. K12-2 明细合计 ↔ K12-1 未审是否勾稽？
2. K12-1 审定合计 ↔ TB(6301) 发生额是否勾稽？差异是否已解释？
3. K12-3 已确认调整是否已回写 K12-1？借贷是否平衡？
4. K12-4 抽查是否覆盖大额/异常？分类是否正确（6301 vs 6117）？
5. 附注金额是否等于 K12-1 审定？非经常性损益列报是否正确？
