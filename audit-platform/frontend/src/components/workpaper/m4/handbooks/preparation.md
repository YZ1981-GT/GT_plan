# M4 资本公积 — 底稿编制手册

> **适用范围**：科目 **4002 资本公积（贷方/权益类，期末=期初+贷方−借方）**
> **组件**：`m4-capital-reserve`
> **说明**：本手册说明各分表的审计目标、编制逻辑与勾稽关联，不替代各表页内已有说明文案。
> 平台按钮与操作步骤见「使用手册」页签。

---

## 1. 总体编制思路

资本公积核实**资本溢价与其他资本公积的来源合规性**：资本溢价在贷方增加（出资超面值），转增资本/弥补亏损时借方减少。

| 证据链 | 主要底稿 | 回答的问题 |
|--------|----------|------------|
| **余额审定** | M4-1 审定 ← M4-2 明细 | 资本公积期末余额是否准确完整？ |
| **构成明细** | M4-2 明细（资本溢价 + 其他资本公积） | 各构成项目来源是否合规？ |
| **合规检查** | M4-4 检查表 | 资本溢价、其他资本公积形成依据是否充分？ |

**枢纽原则**：

1. **权益类贷方科目**：期末 = 期初 + 贷方（增加）− 借方（转增/弥补）。
2. **双区块明细**：M4-2 分资本溢价、其他资本公积两大区块。
3. **接收 J3 股份支付**：股份支付权益结算 → 其他资本公积。
4. **接收 M2 折算差异**：M2 外币投资折算差异 → 资本溢价。
5. **M4-1 是结论枢纽**：审定合计回写试算表 4002，并驱动附注披露。

### 建议编制顺序

```
M4A 程序计划
  → M4-2 明细（资本溢价 + 其他资本公积双区块）
  → M4-4 检查表（形成依据合规核对）
  → M4-1 审定（未审 + AJE + RJE → 审定）→ 回写 TB(4002) → 附注上市/国企
  → M4-3 调整分录（借贷平衡，回写审定）
```

## 2. 分表编制说明

### M4A 实质性程序表
- **审计目标**：规划并记录资本公积实质性程序范围、性质与时间。
- **完成标志**：计划程序均有执行记录或「不适用」说明。

### M4-1 审定表（权益类贷方）
- **审计目标**：核实资本公积期末余额准确完整；提供审定数。
- **编制逻辑**：审定 = 未审 + AJE + RJE；权益期末 = 期初 + 贷方 − 借方。
- **上游**：M4-2 明细；M4-3 确认回写。**下游**：TB(4002)、附注。
- **完成标志**：与 M4-2 明细合计勾稽；审计结论已填。

### M4-2 明细表（资本溢价 + 其他资本公积）
- **审计目标**：核实各构成项目来源合规、金额准确。
- **完成标志**：明细合计与 M4-1 一致；审计说明已填。

### M4-3 调整分录汇总
- **审计目标**：核实调整完整、借贷平衡。
- **完成标志**：借贷平衡；已确认回写 M4-1。

### M4-4 资本公积检查表
- **审计目标**：核实资本溢价、其他资本公积形成依据充分合规。
- **完成标志**：形成凭证核对完整；结论已填。

### 附注披露（上市/国企）
- **审计目标**：按附注格式披露资本公积，与审定勾稽。
- **完成标志**：金额与 M4-1 审定一致；已同步附注模块。

### 底稿目录
- **审计目标**：导航与编制进度总览（跨表结论口径 + 底稿架构 + 本循环其他科目）。

---

## 5. 质量复核要点（摘要）

1. M4-2 明细合计 ↔ M4-1 审定是否勾稽？
2. 资本溢价、其他资本公积来源是否合规、依据是否充分？
3. M4-1 审定 ↔ TB(4002) 是否勾稽？
4. J3 股份支付、M2 折算差异是否正确计入？
5. 附注披露金额是否等于 M4-1 审定？
