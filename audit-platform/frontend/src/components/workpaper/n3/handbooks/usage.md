# N3 递延所得税负债 — 平台使用手册

> 配合「编制手册」页签使用。本手册只说明**平台怎么操作**；审计目标与勾稽逻辑见编制手册。
> **不修改**各分表页内已有说明文案。入口：底稿目录页顶部「使用手册」按钮。

---

## 1. 打开与模式

1. 在项目底稿树打开 **N3 递延所得税负债**（`componentType: n3-deferred-tax-liabilities`，覆盖科目 2901）。
2. 通过 sheet 页签切换分表（N3A、N3-1～N3-3、底稿目录）。
3. 复杂 sheet 支持 **结构化 HTML ↔ OnlyOffice** 双模式；以项目配置为准（目录页不显示双模式）。
4. 只读阶段工具栏「取数 / 回写 / 确认」类按钮会禁用。

---

## 2. 推荐操作路径（点击顺序）

| 步骤 | 分表 | 建议操作 |
|------|------|----------|
| 1 | N3A | 勾选实质性程序、填索引 |
| 2 | N3-2 | 按应纳税暂时性差异项目录入，差异×税率 |
| 3 | N3-3 | 调整分录汇总 → 确认 → 回写 N3-1 |
| 4 | N3-1 | 确认审定期末 → 回写 TB(2901) → 核对 N1/N5 |

## 3. 目录页速查

| 区块 | 说明 |
|------|------|
| 编制进度 | 各分表按审计说明/结论填写情况计算完成度 |
| 跨表结论口径 | 每张表审计结论「已填/未填」标签，点击跳转对应 sheet 补全 |
| 底稿架构 | 4 阶段泳道（审计计划/科目审定/实质性程序/披露与调整），点击卡片跳转 |
| 本循环底稿目录 | 同循环其他科目（N1~N5），点击跳转（灰色表示尚未生成） |

---

## 4. 常见问题

| 现象 | 处理 |
|------|------|
| N3-1 审定 ≠ TB 数 | 检查明细是否全部带入、调整是否已确认回写；TB 取 2901 期末余额 |
| 递延税资产/负债混淆 | 应纳税暂时性差异 → 负债（N3）；可抵扣暂时性差异 → 资产（N1）；同一主体可抵销 |
| 与 N5 递延税费用不符 | 复核递延税负债本期变动额（期末−期初）与 N5-8 是否一致 |
| 特殊项是否确认 | 商誉初始确认、拟长期持有长投相关差异一般不确认递延所得税负债 |
