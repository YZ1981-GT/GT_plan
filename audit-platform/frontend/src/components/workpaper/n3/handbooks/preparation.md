> **适用范围**：科目 **2901 递延所得税负债（贷方/负债类）**

## 1. 总体编制思路

递延所得税负债核心 = **应纳税暂时性差异 × 适用税率**，与 N1 递延所得税资产同源对应（同一纳税主体可抵销后净额列示）。

| 证据链 | 主要底稿 | 回答的问题 |
|--------|----------|------------|
| **金额枢纽** | N3-2 明细 → N3-1 审定 ← N3-3 调整 | 递延所得税负债期末余额是否准确完整？ |
| **计量逻辑** | N3-2 明细（差异×税率） | 各项应纳税暂时性差异确认额是否恰当？ |

**枢纽原则**：

1. **负债类贷方科目**：期末 = 期初 + 本期贷方（确认增加）− 本期借方（转回减少），取期末余额。
2. **应纳税暂时性差异**：资产账面价值 > 计税基础，或负债账面价值 < 计税基础 → 产生应纳税暂时性差异。
3. **N3-1 是结论枢纽**：审定期末余额回写试算表 2901；本期变动额（期末−期初）供 N5 递延所得税费用核对。
4. **不确认的特殊项**：商誉初始确认、拟长期持有的长期股权投资相关应纳税暂时性差异，一般不确认递延所得税负债。

### 建议编制顺序

```
N3A 程序计划
  → N3-2 明细（按应纳税暂时性差异项目 × 税率）
  → 差异汇入 N3-3 → 确认回写 N3-1
  → N3-1 勾稽 TB(2901) + 核对 N1/N5 → 与 N1 同源分列
```

## 2. 分表编制说明

### N3A 实质性程序表
- **审计目标**：规划并记录递延所得税负债实质性程序范围、性质与时间。
- **完成标志**：计划程序均有执行记录或「不适用」说明。

### N3-1 审定表（负债类贷方）
- **审计目标**：核实递延所得税负债期末余额准确完整；提供审定数。
- **编制逻辑**：期末 = 期初 + 贷方 − 借方；审定 = 未审 + AJE + RJE。
- **上游**：N3-2 明细；N3-3 确认回写。**下游**：TB(2901)、N5 递延税费用核对、附注。
- **完成标志**：与 TB 勾稽差异已解释；审计结论已填。

### N3-2 明细表
- **审计目标**：核实各应纳税暂时性差异项目确认额存在、完整、准确。
- **编制逻辑**：递延所得税负债 = 应纳税暂时性差异 × 适用税率。
- **完成标志**：清单完整、合计与 N3-1 一致。

### N3-3 调整分录汇总
- **审计目标**：核实调整完整、借贷平衡。
- **完成标志**：借贷平衡；已确认回写 N3-1。

### 底稿目录
- **审计目标**：导航与编制进度总览（跨表结论口径 + 底稿架构 + 本循环其他科目）。

## 5. 质量复核要点（摘要）

1. N3-2 明细（差异×税率）↔ N3-1 审定是否勾稽？
2. N3-1 审定期末 ↔ TB(2901) 是否勾稽？
3. 应纳税暂时性差异确认是否恰当（不确认的特殊项是否排除）？
4. 递延税负债本期变动 ↔ N5 递延所得税费用是否核对一致？
5. 与 N1 递延税资产的抵销/分列是否按同一纳税主体判断？
