# N4 税金及附加 — 底稿编制手册

> **适用范围**：科目 **6403 税金及附加（借方/损益类，取本期发生额）**
> **组件**：`n4-taxes-and-surcharges`
> **说明**：本手册说明各分表的审计目标、编制逻辑与勾稽关联，不替代各表页内已有说明文案。
> 平台按钮与操作步骤见「使用手册」页签。

---

## 1. 总体编制思路

税金及附加核算企业经营活动应负担的**各项税费**（消费税、城建税及附加、房产税、土地使用税、车船税、印花税、资源税等），损益类科目**取本期发生额**（借方发生 − 贷方发生），非期末余额。核心是核实**费用确认 = 应交税费对应税种本期计提额**。

| 证据链 | 主要底稿 | 回答的问题 |
|--------|----------|------------|
| **金额枢纽** | N4-2 明细 → N4-1 审定 ← N4-3 调整 | 各税种费用发生额是否准确完整？ |
| **交叉核对** | N4 ↔ N2 计提额 | 费用确认是否等于应交税费计提额？ |

**枢纽原则**：

1. **损益类借方科目**：取本期发生额（借方发生 − 贷方发生），非期末余额。
2. **N4-1 是结论枢纽**：各税种审定发生额回写试算表 6403（发生额口径）；合计进利润表"税金及附加"行。
3. **N4 ↔ N2 核心勾稽**：各税种本期费用确认应等于 N2 应交税费对应税种本期计提额（城建税/教育费附加/房产税/土地使用税/车船税等）。
4. **城建税及附加**：=（增值税 + 消费税）× 税率（城建税 7%/5%/1% + 教育费附加 3% + 地方教育附加 2%）。

### 建议编制顺序

```
N4A 程序计划
  → N4-2 明细（逐税种计税依据与发生额）
  → 差异汇入 N4-3 → 确认回写 N4-1
  → N4-1 勾稽 TB(6403 发生额) + 核对 N2 各税种计提额 → 附注上市/国企
```

## 2. 分表编制说明

### N4A 实质性程序表
- **审计目标**：规划并记录税金及附加实质性程序范围、性质与时间。
- **完成标志**：计划程序均有执行记录或「不适用」说明。

### N4-1 审定表（损益类借方，取发生额）
- **审计目标**：核实各税种本期费用发生额准确完整；提供审定数。
- **编制逻辑**：审定 = 未审 + AJE + RJE，按税种分行；合计为利润表税金及附加。
- **上游**：N4-2 明细；N4-3 确认回写。**下游**：TB(6403 发生额)、利润表、附注、N2 交叉核对。
- **完成标志**：与 N2 各税种计提额核对一致；审计结论已填。

### N4-2 明细表
- **审计目标**：核实各税种计税依据与发生额存在、完整、准确。
- **完成标志**：清单完整、合计与 N4-1 一致。

### N4-3 调整分录汇总
- **审计目标**：核实调整完整、借贷平衡。
- **完成标志**：借贷平衡；已确认回写 N4-1，联动 A13。

### 附注披露（上市/国企）
- **审计目标**：按附注格式披露税金及附加各税种发生额，与审定勾稽。
- **完成标志**：金额与 N4-1 审定一致；已同步附注模块。

### 底稿目录
- **审计目标**：导航与编制进度总览（跨表结论口径 + 底稿架构 + 本循环其他科目）。

## 4. 外部模块衔接

| 模块 | 与 N4 关系 |
|------|------------|
| **N2 应交税费** | 各税种本期计提额 → N4 费用确认核对（核心勾稽） |
| **试算平衡表** | N4-1 审定发生额回写 6403 |
| **A 类利润表** | N4-1 合计 → 利润表"税金及附加"行 |
| **调整分录 / A13** | 与 N4-3 双向同步 |
| **附注模块** | 税金及附加披露 |

---

## 5. 质量复核要点（摘要）

1. N4-2 明细 ↔ N4-1 审定是否勾稽？
2. N4 各税种费用确认 ↔ N2 应交税费对应税种计提额是否一致？
3. 城建税及附加计税依据（增值税+消费税）是否正确？
4. N4-1 审定合计 ↔ TB(6403 发生额) 与利润表是否勾稽？
5. 附注金额是否等于 N4-1 审定？
