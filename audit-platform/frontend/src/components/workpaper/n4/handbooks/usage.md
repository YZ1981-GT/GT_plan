# N4 税金及附加 — 平台使用手册

> 配合「编制手册」页签使用。本手册只说明**平台怎么操作**；审计目标与勾稽逻辑见编制手册。
> **不修改**各分表页内已有说明文案。入口：底稿目录页顶部「使用手册」按钮。

---

## 1. 打开与模式

1. 在项目底稿树打开 **N4 税金及附加**（`componentType: n4-taxes-and-surcharges`，覆盖科目 6403）。
2. 通过 sheet 页签切换分表（N4A、N4-1～N4-3、附注上市/国企、底稿目录）。
3. 复杂 sheet 支持 **结构化 HTML ↔ OnlyOffice** 双模式；以项目配置为准（目录页不显示双模式）。
4. 只读阶段工具栏「取数 / 回写 / 确认」类按钮会禁用。

---

## 2. 推荐操作路径（点击顺序）

| 步骤 | 分表 | 建议操作 |
|------|------|----------|
| 1 | N4A | 勾选实质性程序、填索引 |
| 2 | N4-2 | 逐税种录入计税依据与本期发生额 |
| 3 | N4-3 | 调整分录汇总 → 确认 → 回写 N4-1（联动 A13） |
| 4 | N4-1 | 确认各税种审定发生额 → 回写 TB(6403) → 核对 N2 计提额 |
| 5 | 附注上市/国企 | 从审定表取数 → 编辑 → 同步附注模块 |

## 3. 目录页速查

| 区块 | 说明 |
|------|------|
| 编制进度 | 各分表按审计说明/结论填写情况计算完成度 |
| 跨表结论口径 | 每张表审计结论「已填/未填」标签，点击跳转对应 sheet 补全 |

| 本循环底稿目录 | 同循环其他科目（N1~N5），点击跳转（灰色表示尚未生成） |

## 4. 常见问题

| 现象 | 处理 |
|------|------|
| N4-1 审定 ≠ TB 数 | 税金及附加取本期发生额（非期末余额）；检查明细/调整是否带入 |
| 与 N2 计提额不符 | 复核 N4 各税种费用确认与 N2 应交税费对应税种本期计提额 |
| 城建税及附加为空 | 计税依据 =（增值税 + 消费税），先完成 N2 增值税测算 |
| 附注同步失败 | 检查项目 ID、附注模块权限与准则类型（上市/国企） |
