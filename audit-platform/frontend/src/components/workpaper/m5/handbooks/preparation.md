# M5 盈余公积 — 底稿编制手册

> **适用范围**：科目 **4101 盈余公积（贷方/权益类，期末=期初+贷方−借方）**
> **组件**：`m5-surplus-reserve`
> **说明**：本手册说明各分表的审计目标、编制逻辑与勾稽关联，不替代各表页内已有说明文案。
> 平台按钮与操作步骤见「使用手册」页签。

---

## 1. 总体编制思路

盈余公积核实**法定盈余公积计提合规性与任意盈余公积用途**：计提时贷方增加，转增资本/弥补亏损时借方减少。

| 证据链 | 主要底稿 | 回答的问题 |
|--------|----------|------------|
| **余额审定** | M5-1 审定 ← M5-2 明细 | 盈余公积期末余额是否准确完整？ |
| **构成明细** | M5-2 明细（法定 + 任意） | 法定/任意盈余公积构成是否准确？ |
| **计提测试** | M5-4 计提检查（法定 10% + 50% 上限） | 法定盈余公积计提比例是否合规？ |
| **合规检查** | M5-5 检查表 | 计提、转增、弥补亏损处理是否合规？ |

**枢纽原则**：

1. **权益类贷方科目**：期末 = 期初 + 贷方（计提）− 借方（转增/弥补）。
2. **法定 10% 计提**：法定盈余公积按净利润 10% 计提，累计达注册资本 50% 可停提。
3. **接收 M6 净利润**：计提基数来自 M6 未分配利润的本年净利润。
4. **反向驱动 M6**：M5 计提盈余公积减少 M6 可供分配利润。
5. **M5-1 是结论枢纽**：审定合计回写试算表 4101，并驱动附注披露。

### 建议编制顺序

```
M5A 程序计划
  → M5-2 明细（法定 + 任意盈余公积）
  → M5-4 计提检查（法定 10% + 50% 上限，核对 M6 净利润基数）
  → M5-5 检查表（计提/转增/弥补合规）
  → M5-1 审定（未审 + AJE + RJE → 审定）→ 回写 TB(4101) → 附注上市/国企
  → M5-3 调整分录（借贷平衡，回写审定）
```

## 2. 分表编制说明

### M5A 实质性程序表
- **审计目标**：规划并记录盈余公积实质性程序范围、性质与时间。
- **完成标志**：计划程序均有执行记录或「不适用」说明。

### M5-1 审定表（权益类贷方）
- **审计目标**：核实盈余公积期末余额准确完整；提供审定数。
- **编制逻辑**：审定 = 未审 + AJE + RJE；权益期末 = 期初 + 贷方 − 借方。
- **上游**：M5-2 明细；M5-3 确认回写。**下游**：TB(4101)、附注。
- **完成标志**：与 M5-2 明细合计勾稽；审计结论已填。

### M5-2 明细表（法定 + 任意盈余公积）
- **审计目标**：核实法定、任意盈余公积构成准确。
- **完成标志**：明细合计与 M5-1 一致；审计说明已填。

### M5-3 调整分录汇总
- **审计目标**：核实调整完整、借贷平衡。
- **完成标志**：借贷平衡；已确认回写 M5-1。

### M5-4 盈余公积计提检查表
- **审计目标**：核实法定盈余公积按净利润 10% 计提，累计达注册资本 50% 上限判断。
- **编制逻辑**：计提基数 = M6 本年净利润；比例 = 10%；上限 = 注册资本 50%。
- **完成标志**：计提测算有据；结论已填。

### M5-5 盈余公积检查表
- **审计目标**：核实计提、转增资本、弥补亏损处理合规。
- **完成标志**：凭证核对完整；结论已填。

### 附注披露（上市/国企）
- **审计目标**：按附注格式披露盈余公积，与审定勾稽。
- **完成标志**：金额与 M5-1 审定一致；已同步附注模块。

### 底稿目录
- **审计目标**：导航与编制进度总览（跨表结论口径 + 底稿架构 + 本循环其他科目）。

| 认定 | 主要底稿 |
|------|----------|
| 存在/完整性 | M5-1、M5-2、M5-5 |
| 计价/准确 | M5-2、M5-4 |
| 列报与披露 | 附注上市/国企 |

## 4. 外部模块衔接

| 模块 | 与 M5 关系 |
|------|------------|
| **M6 未分配利润** | 本年净利润 → M5-4 计提基数；计提盈余公积 → 减少 M6 可供分配利润 |
| **试算平衡表** | M5-1 审定余额回写 4101 |

---

## 5. 质量复核要点（摘要）

1. M5-2 明细合计 ↔ M5-1 审定是否勾稽？
2. 法定盈余公积计提基数（M6 净利润）与比例（10%）是否正确？
3. 累计是否达注册资本 50% 上限（可停提）？
4. M5-1 审定 ↔ TB(4101) 是否勾稽？
5. 附注披露金额是否等于 M5-1 审定？
