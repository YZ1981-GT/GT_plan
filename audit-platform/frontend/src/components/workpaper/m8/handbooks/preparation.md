# M8 一般风险准备 — 底稿编制手册

> **适用范围**：科目 **4104 一般风险准备（贷方/权益类，期末=期初+贷方−借方）**
> **组件**：`m8-general-risk-reserve`
> **适用主体**：**金融企业（银行、证券、保险、信托、基金、期货、金融租赁等）**；非金融企业不适用。
> **说明**：本手册说明各分表的审计目标、编制逻辑与勾稽关联，不替代各表页内已有说明文案。
> 平台按钮与操作步骤见「使用手册」页签。

---

## 1. 总体编制思路

一般风险准备是**金融企业从净利润中计提的风险准备**：计提时贷方增加，转回/使用时借方减少。

| 证据链 | 主要底稿 | 回答的问题 |
|--------|----------|------------|
| **余额审定** | M8-1 审定 ← M8-2 明细 | 一般风险准备期末余额是否准确完整？ |
| **计提明细** | M8-2 明细 | 计提明细是否准确？ |
| **计提测试** | M8-4 一般风险准备测试（按风险资产 1.5%） | 按风险资产期末余额计提是否合规？ |

**枢纽原则**：

1. **权益类贷方科目**：期末 = 期初 + 贷方（计提）− 借方（转回/使用）。
2. **金融企业行业守卫**：仅金融企业适用；非金融企业标记不适用。
3. **计提标准**：按风险资产期末余额的一定比例（一般为 1.5%）从净利润中计提。
4. **M8-1 是结论枢纽**：审定合计回写试算表 4104，并驱动附注披露。

### 建议编制顺序

```
（行业适用性判断：非金融企业 → 标记不适用）
M8A 程序计划
  → M8-2 明细（计提明细）
  → M8-4 计提测试（按风险资产期末余额 1.5%）
  → M8-1 审定（未审 + AJE + RJE → 审定）→ 回写 TB(4104) → 附注上市/国企
  → M8-3 调整分录（借贷平衡，回写审定）
```

## 2. 分表编制说明

### M8A 实质性程序表
- **审计目标**：规划并记录一般风险准备实质性程序范围、性质与时间。
- **完成标志**：计划程序均有执行记录或「不适用」说明。

### M8-1 审定表（权益类贷方）
- **审计目标**：核实一般风险准备期末余额准确完整；提供审定数。
- **编制逻辑**：审定 = 未审 + AJE + RJE；权益期末 = 期初 + 贷方 − 借方。
- **上游**：M8-2 明细；M8-3 确认回写。**下游**：TB(4104)、附注。
- **完成标志**：与 M8-2 明细合计勾稽；审计结论已填。

### M8-2 明细表
- **审计目标**：核实一般风险准备计提明细准确。
- **完成标志**：明细合计与 M8-1 一致；审计说明已填。

### M8-3 调整分录汇总
- **审计目标**：核实调整完整、借贷平衡。
- **完成标志**：借贷平衡；已确认回写 M8-1。

### M8-4 一般风险准备测试表
- **审计目标**：核实按风险资产期末余额计提比例（一般 1.5%）合规。
- **完成标志**：计提测算有据；结论已填。

### 附注披露（上市/国企）
- **审计目标**：按附注格式披露一般风险准备，与审定勾稽。
- **完成标志**：金额与 M8-1 审定一致；已同步附注模块。

### 底稿目录
- **审计目标**：导航与编制进度总览（跨表结论口径 + 底稿架构 + 本循环其他科目）。

## 5. 质量复核要点（摘要）

1. 是否属金融企业（行业适用性）？非金融企业应标记不适用。
2. M8-2 明细合计 ↔ M8-1 审定是否勾稽？
3. M8-4 按风险资产期末余额计提比例（1.5%）是否合规？
4. M8-1 审定 ↔ TB(4104) 是否勾稽？
5. 附注披露金额是否等于 M8-1 审定？
