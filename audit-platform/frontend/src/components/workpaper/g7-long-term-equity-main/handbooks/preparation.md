# G7 长期股权投资 — 底稿编制手册

> **适用范围**：科目 1511 长期股权投资（CAS 2 长期股权投资准则）。
> **组件**：GtBIndex 通用目录（G7 科目）
> **说明**：本手册说明各分表的审计目标、编制逻辑与勾稽关联，不替代各表页内已有说明文案。平台按钮与操作步骤见「使用手册」页签。

---

## 1. 总体编制思路

长期股权投资按 CAS 2 分两种后续计量：**对子公司（控制）采用成本法**（个别报表按成本，合并层面纳入合并范围）；**对联营企业、合营企业（重大影响 / 共同控制）采用权益法**（按享有被投资单位所有者权益份额调整账面，确认投资收益、其他综合收益及其他权益变动）。取得环节区分**同一控制下企业合并**（按被合并方账面权益份额计量，差额调资本公积）与**非同一控制下企业合并**（按付出对价公允价值计量，形成商誉或计入当期损益）。减值适用 CAS 8，**一经计提不得转回**。审计核心是初始计量、权益法调整、减值、处置损益的正确性与合并层面勾稽。

| 证据链 | 主要底稿 | 回答的问题 |
|--------|----------|------------|
| 初始成本是否正确 | 投资成本测试、同控/非同控合并 | 取得成本计量方法与差额处理是否恰当 |
| 后续计量是否正确 | 权益法调整、被投资单位财务信息 | 权益法确认的投资损益/OCI/其他权益变动是否准确 |
| 减值是否充分 | 减值测试（CAS 8） | 可收回金额、减值准备是否恰当（不转回） |
| 处置是否正确 | 处置损益 | 处置日、处置价款、处置损益、剩余股权重新计量 |
| 审定是否正确 | G7-1 审定表 | 未审→调整→审定，与 TB 1511 及明细勾稽 |
| 披露是否完整 | 附注（上市/国企） | 子公司/联营合营明细、少数股东、企业合并披露 |

### 建议编制顺序

```
被投资单位财务信息 → 投资成本测试 → 同控/非同控合并 → 权益法调整 → 减值测试 → 处置损益 → 未确认损失 → 调整回写 G7-1 审定 → 勾稽 TB(1511) → 附注(上市/国企)
```

## 2. 分表编制说明

### G7-1 审定表
汇总长期股权投资未审数、账项/重分类调整、审定数，回写 TB 1511，与 G7-2 明细合计勾稽。

### G7-2 明细表 / G7-3 调整分录
G7-2 逐笔列示各被投资单位的持股比例、计量方法、成本、权益法累计调整、减值准备、账面价值；G7-3 录入 AJE/RJE 回写审定表。

### G7-4 / G7-5 被投资单位财务信息
汇总子公司/联营合营的净利润、净资产、少数股东权益、现金流，作为权益法调整与合并披露的取数来源。

### G7-6 会计政策差异调整 / G7-13 投资成本测试
G7-6 检查被投资单位会计政策与母公司是否一致并调整；G7-13 测试初始投资成本与享有可辨认净资产公允价值份额的差额（正差额确认商誉/负差额计入当期损益）。

### G7-8 同一控制合并 / G7-9 非同一控制合并
G7-8 按被合并方账面权益份额计量、差额调资本公积；G7-9 按付出对价公允价值计量、判断是否构成业务、形成商誉。

### G7-10 减值测试
按 CAS 8 测算可收回金额（公允价值减处置费用与未来现金流量现值孰高），计提减值准备，**一经计提不得转回**。

### G7-12 处置损益 / G7-16 未确认损失
G7-12 计算各次交易处置损益及丧失控制权后剩余股权重新计量；G7-16 按 CAS 2 顺序（投资→长期应收款→其他）确认超额亏损的未确认部分。

### G7-11 / G7-14 / G7-15 / G7-17 / G7-18
分别为权益法明细、投资收益汇总、其他权益变动、减值迹象、凭证检查等辅助测试表。

### 附注（上市 / 国企）
按子公司、联营合营企业明细，少数股东损益/权益，同控/非同控企业合并信息披露；数据取自 G7-4/G7-5 及各明细。

## 3. 认定覆盖速查

| 认定 | 主要底稿 |
|------|----------|
| 存在 | G7-2 明细、权属证明、函证 |
| 完整性 | G7-1 审定、TB 勾稽 |
| 权利和义务 | 股权协议、章程、控制/重大影响判断 |
| 计价和分摊 | 投资成本测试、权益法调整、减值测试、处置损益 |
| 列报和披露 | 附注（上市/国企） |

| 模块 | 关系 |

## 5. 质量复核要点（摘要）

1. 计量方法（成本法/权益法）与控制/共同控制/重大影响的判断是否一致。
2. 同控/非同控合并的差额处理是否正确（资本公积 vs 商誉/损益）。
3. 权益法调整是否完整（净利润份额、OCI、其他权益变动、内部交易未实现损益抵销）。
4. 减值测试可收回金额是否合理，减值**是否未违规转回**。
5. 处置损益、剩余股权重新计量、未确认损失顺序是否正确。
6. G7-1 审定合计 = G7-2 明细合计 = TB 1511；与合并底稿勾稽一致。
