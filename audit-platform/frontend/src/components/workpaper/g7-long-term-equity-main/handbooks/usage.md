# G7 长期股权投资 — 平台使用手册

> 本页说明各底稿在平台上的操作方式。审计目标与编制逻辑见「编制手册」页签。

## 1. 目录页（本页）

- **跨表结论口径看板**：汇总核心表「审计说明或结论」是否已填，点击标签跳转补全。
- **底稿架构（4 阶段泳道）**：审计计划 / 科目审定 / 实质性程序 / 披露与调整。
- **本循环底稿目录**：G 循环其他科目，点击跳转。
- **编制/使用手册**：右上角按钮。

## 2. 各底稿操作要点

### G7-1 审定表
点「从 G7-2 带入」填未审数；账项/重分类调整由 G7-3 回写；点「回写试算平衡表」写入 TB 1511。

### G7-2 明细表 / G7-3 调整分录
G7-2 逐笔录入被投资单位/持股比例/计量方法/成本/权益法调整/减值/账面；G7-3 录入调整分录并可推送 A13。

### G7-4 / G7-5 被投资单位财务信息
录入或从子公司/联营合营带入净利润、净资产、少数股东权益，供权益法与合并披露取数。

### G7-13 投资成本测试 / G7-8 同控 / G7-9 非同控
录入取得成本与可辨认净资产公允价值份额，系统测算正/负差额；同控/非同控按各自规则计量并给出合并建议分录。

### G7-17 减值测试
录入可收回金额（公允价值减处置费用、现金流量现值），测算减值准备；系统提示不得转回。保存后同步 G7-14 减值准备列，并把本期减值合计推给 K11 资产减值损失作来源金额。

### G7-11 / G7-12 处置损益 / G7-16 未确认损失
G7-11 单次（非一揽子）处置检查；G7-12 分次录入处置价款/账面/剩余股权公允价值算处置损益；G7-16 按 CAS 2 顺序自动分配超额亏损。凭证抽取目前在 G7-18 凭证检查表（抽凭引擎，科目 1511）。

### 附注（上市 / 国企）
点「从审定表/明细带入」聚合子公司、联营合营、少数股东数据；文本区可「🤖 AI 辅助」。
