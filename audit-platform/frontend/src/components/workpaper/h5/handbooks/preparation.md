# H5 生产性生物资产 / 油气资产 — 底稿编制手册

> **适用范围**：采掘业油气资产及林木/畜禽等生产性生物资产。科目 1631 生产性生物资产（原值）、1632 生产性生物资产累计折旧，以及油气资产及其累计折耗。
> **组件**：GtBIndex 通用目录（H5 科目）
> **说明**：本手册说明各分表的审计目标、编制逻辑与勾稽关联，不替代各表页内已有说明文案。平台按钮与操作步骤见「使用手册」页签。

---

## 1. 总体编制思路

H5 覆盖两类以**产量为基础耗用**的长期资产，行业专属性强（农林牧渔、采掘业）：

- **油气资产**：依《企业会计准则第 27 号——石油天然气开采》核算，包括矿区权益与油气井及相关设施；后续按**产量法（单位产量法）**计提折耗——本期折耗 = 期末账面成本 × (本期产量 ÷ 期末剩余可采储量 + 本期产量)。
- **生产性生物资产**：依《企业会计准则第 5 号——生物资产》(CAS5) 核算成熟生产性生物资产（如经济林木、产畜、役畜），按直线法或产量法计提折旧。
- **折耗/折旧的关键在产量记录**：单位产量法依赖**实际产量与可采储量估计**，储量估计变更属会计估计变更，须复核其合理性与依据。
- **减值**：依《企业会计准则第 8 号——资产减值》(CAS8) 识别减值迹象（储量大幅下调、油价持续低迷、生物资产病害等），测算可收回金额并计提减值。

| 证据链 | 主要底稿 | 回答的问题 |
|--------|----------|------------|
| 期末存量真实完整 | H5 明细表 | 油气资产/生物资产是否真实、归属被审计单位？ |
| 折耗/折旧计价 | H5 折耗（单位产量法）| 产量、储量估计是否可靠，折耗是否足额？ |
| 产量与储量 | H5 产量记录 | 本期产量、剩余可采储量是否有据、变更是否恰当？ |
| 减值 | H5 减值（CAS8）| 是否存在减值迹象，可收回金额与减值是否充分？ |
| 审定与列报 | H5 审定表 / 附注 | 审定余额是否勾稽 TB 1631/1632、披露是否恰当？ |

### 建议编制顺序

```
H5程序表 → H5明细(立清单: 油气资产/生产性生物资产)
  → 产量记录(本期产量+期末剩余可采储量)
  → 折耗测算(单位产量法) / 生物资产折旧
  → 减值测试(CAS8迹象+可收回金额)
  → 调整(账项/重分类) → 回写审定表(勾稽TB 1631/1632) → 附注
```

## 2. 分表编制说明

### H5 审定表
按油气资产、生产性生物资产分类列示原值、累计折耗折旧、减值、账面价值；未审数 + 账项调整(AJE) + 重分类调整(RJE) = 审定数；审定合计回写并勾稽试算表 1631/1632 及油气资产科目。

### H5 明细表
逐项资产明细：名称/矿区/林畜类别、取得日、原值、累计折耗折旧、减值、账面价值；核对权属与取得成本；是折耗与减值分表的行来源。

### H5 折耗（单位产量法）
油气资产折耗测算：期初账面成本、本期产量、期末剩余可采储量 → 单位折耗率 × 本期产量 = 本期折耗；生产性生物资产按其折旧方法测算；测算额与账面计提额比对，差异说明。

### H5 产量记录
本期实际产量、期末剩余可采储量（含储量估计变更）；核对生产台账/储量评估报告；储量估计变更的依据与会计处理复核。

### H5 减值（CAS8）
减值迹象识别（储量下调、价格低迷、病害等）→ 可收回金额（公允价值减处置费用 与 未来现金流量现值 孰高）测算 → 应计提减值，与账面减值比对。

### 调整 / 附注
账项与重分类调整分录回写审定表并推送 A13；附注按分类列示期末余额、本期变动、折耗折旧政策与储量估计。

## 5. 质量复核要点（摘要）

- 单位产量法的产量、剩余可采储量是否有据（生产台账、储量评估报告）。
- 储量估计变更是否属会计估计变更、依据是否充分、处理是否恰当（未来适用法）。
- 折耗折旧是否足额，测算额与账面计提额差异是否查明。
- 减值迹象是否充分识别（行业专属：油价、储量、病害），可收回金额假设是否合理。
- 行业适用性判断是否正确（农林牧渔 / 采掘业），非该行业不应误用本科目。
