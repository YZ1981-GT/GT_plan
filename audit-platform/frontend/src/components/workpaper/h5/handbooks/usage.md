# H5 生产性生物资产 / 油气资产 — 平台使用手册

> 本页说明各底稿在平台上的操作方式。审计目标与编制逻辑见「编制手册」页签。

## 1. 目录页（本页）

- 跨表结论口径看板：汇总核心表"审计说明或结论"是否已填，点击标签跳转对应分表。
- 底稿架构（4 阶段泳道）：审计计划 / 科目审定 / 实质性程序 / 披露与调整。
- 本循环底稿目录：H 循环其他科目，点击跳转。
- 编制/使用手册：右上角按钮。

## 2. 各底稿操作要点

- **H5 明细表**：录入油气资产/生产性生物资产逐项明细，选择资产类别，是折耗与减值分表的行来源。
- **H5 产量记录**：录入本期实际产量与期末剩余可采储量，储量估计变更需备注依据。
- **H5 折耗**：录入产量/储量后系统按单位产量法测算本期折耗，与账面计提额比对。
- **H5 减值**：录入减值迹象与可收回金额，测算应计提减值。
- **H5 审定表**：从明细带入未审数，录入 AJE/RJE 得审定数，保存回写试算表 1631/1632。
- **附注**：从审定表带入分类余额、变动及折耗折旧政策。

## 3. 常用操作速查

| 操作 | 位置 |
|------|------|
| 从明细带入审定表 | H5 审定表「从明细带入」按钮 |
| 折耗测算 | H5 折耗（单位产量法）「测算」按钮 |
| 减值测算 | H5 减值「可收回金额测算」 |
| 回写试算表 | H5 审定表保存时回写 1631/1632 |
| AI 辅助说明/结论 | 各表审计说明区「AI 辅助」按钮 |
| 复核对话 | 各表结论区复核圆点/复核按钮 |
| 版本历史 | 顶部工具栏版本按钮 |

## 4. 联动关系速查

| 联动 | 说明 |
|------|------|
| 产量 → 折耗 | 产量记录驱动单位产量法折耗测算 |
| 明细 → 审定 | H5 明细按类别聚合到审定表 |
| 调整 → 审定 | 调整分录回写审定 AJE/RJE |
| 审定 → 附注 | 审定数带入附注分类披露 |
| 审定 → 试算表 | 审定合计回写 1631/1632 及油气资产科目 |
| 折耗折旧 → 成本 | 计入生产成本/主营业务成本 |
| 调整 → A13 | 未更正错报推送错报汇总 |
