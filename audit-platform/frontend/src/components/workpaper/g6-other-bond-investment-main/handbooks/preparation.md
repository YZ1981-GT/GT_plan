# G6 其他债权投资 — 底稿编制手册

> **适用范围**：科目 1503 其他债权投资（以公允价值计量且其变动计入其他综合收益的债务工具投资，FVOCI 债务工具）。
> **组件**：GtBIndex 通用目录（G6 科目）
> **说明**：本手册说明各分表的审计目标、编制逻辑与勾稽关联，不替代各表页内已有说明文案。平台按钮与操作步骤见「使用手册」页签。

---

## 1. 总体编制思路

其他债权投资是 CAS 22（金融工具确认和计量）下的第二类金融资产：**同时满足 ①业务模式为「既以收取合同现金流量为目标又以出售为目标」②合同现金流量特征通过 SPPI 测试（仅为本金和以未偿付本金为基础的利息支付）** 的债务工具，分类为 FVOCI。其核算要点区别于其他科目：**账面按公允价值计量，公允价值变动计入其他综合收益（OCI）而非当期损益；同时按预期信用损失（ECL）三阶段模型计提减值，但减值计入其他综合收益、不冲减账面价值（账面仍等于公允价值）；处置时 OCI 累计公允价值变动转入投资收益**。审计核心是验证分类判断（SPPI + 业务模式）、公允价值计量、ECL 计提及 OCI 与损益的正确归属。

| 证据链 | 主要底稿 | 回答的问题 |
|--------|----------|------------|
| 分类是否成立 | SPPI 测试、业务模式判定 | 是否真的应分类为 FVOCI 债务工具（而非 FVTPL/摊余成本） |
| 账面是否真实 | G6-2 明细表、公允价值来源 | 各笔投资的成本、公允价值、OCI 累计变动是否准确 |
| 减值是否充分 | ECL 测试 | 三阶段划分与减值准备计提是否恰当（计入 OCI） |
| 审定是否正确 | G6-1 审定表 | 未审→调整→审定，是否与 TB 1503 及明细勾稽 |
| 调整是否入账 | G6-3 调整分录 | AJE/RJE 是否正确回写审定数 |
| 披露是否完整 | 附注（上市/国企） | 公允价值层次、减值、受限情况披露 |

### 建议编制顺序

```
业务模式判定 → SPPI 测试 → G6-2 明细(成本/公允价值/OCI变动) → ECL 三阶段测试 → G6-3 调整 → 回写 G6-1 审定 → 勾稽 TB(1503) → 附注披露
```

## 2. 分表编制说明

### G6-1 审定表
汇总各类其他债权投资的未审数、账项调整（AJE）、重分类调整（RJE）、审定数，审定合计回写 TB 1503 并与 G6-2 明细合计勾稽。审定数 = 未审 + 账项调整 + 重分类调整。

### G6-2 明细表
逐笔列示债券投资的名称、面值、票面利率、取得成本、期末公允价值、公允价值累计变动（计入 OCI）、计提的 ECL 减值准备。是审定表与附注的取数来源。

### G6-3 调整分录
录入本科目 AJE/RJE，按性质分列借贷，回写 G6-1 审定表的账项/重分类调整列，并可推送至 A13 未更正错报汇总。

### SPPI 测试
针对每笔债务工具判断合同现金流量是否「仅为本金和利息」，含提前还款/展期条款、与本金和信用风险不符的杠杆/挂钩条款的排除性测试；不通过 SPPI 则不得分类为 FVOCI（应为 FVTPL）。

### ECL 测试
按三阶段模型（阶段一 12 个月 ECL / 阶段二、三 整个存续期 ECL）评估信用风险是否显著增加、是否已发生信用减值，计算减值准备。**FVOCI 债务工具的减值计入其他综合收益，不减记账面价值**。

### 附注（上市 / 国企）
按公允价值分类、公允价值层次（Level 1/2/3）、减值准备情况、期末受限（质押/冻结）情况披露，数据取自 G6-2 明细与 ECL 测试。

## 3. 认定覆盖速查

| 认定 | 主要底稿 |
|------|----------|
| 存在 | G6-2 明细、公允价值来源、函证 |
| 完整性 | G6-1 审定、TB 勾稽 |
| 权利和义务 | 权属证明、受限情况 |
| 计价和分摊 | 公允价值计量、SPPI/业务模式、ECL 测试 |
| 列报和披露 | 附注（上市/国企） |

## 4. 外部模块衔接

| 模块 | 关系 |
|------|------|
| TB 试算平衡表 | G6-1 审定合计回写 1503 |
| G13 公允价值变动损益 | 本科目公允价值变动计入 OCI 不进 G13（区别 FVTPL） |
| G11 投资收益 | 处置时 OCI 累计变动转入投资收益；持有期利息计入投资收益 |
| G14 信用减值损失 | ECL 减值本科目计入 OCI，与信用减值损失科目口径区分 |
| A13 未更正错报 | G6-3 调整分录推送 |
| 附注模块 | 披露表数据同步 |

## 5. 质量复核要点（摘要）

1. SPPI 测试与业务模式判定是否有充分依据支持 FVOCI 分类，是否误分类。
2. 公允价值计量的输入值与层次划分是否恰当，Level 3 是否有估值技术与关键参数。
3. ECL 三阶段划分与减值计提是否充分，是否**正确计入 OCI 且未冲减账面价值**。
4. OCI 累计公允价值变动与处置时结转投资收益是否勾稽一致。
5. G6-1 审定合计 = G6-2 明细合计 = TB 1503，差异是否已查明。
