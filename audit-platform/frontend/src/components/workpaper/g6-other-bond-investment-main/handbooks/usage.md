# G6 其他债权投资 — 平台使用手册

> 本页说明各底稿在平台上的操作方式。审计目标与编制逻辑见「编制手册」页签。

## 1. 目录页（本页）

- **跨表结论口径看板**：汇总核心表「审计说明或结论」是否已填，点击标签跳转补全。
- **底稿架构（4 阶段泳道）**：审计计划 / 科目审定 / 实质性程序 / 披露与调整。
- **本循环底稿目录**：G 循环其他科目，点击跳转。
- **编制/使用手册**：右上角按钮。

## 2. 各底稿操作要点

### G6-1 审定表
在明细编制完成后点「从 G6-2 带入」按未审数填充；账项/重分类调整列由 G6-3 自动回写；点「回写试算平衡表」将审定合计写入 TB 1503。

### G6-2 明细表
逐笔录入投资名称/面值/票面利率/成本/公允价值/OCI 累计变动/ECL 减值；宽表可用「⚙ 列设置」显隐列；支持导入导出。

### SPPI 测试
逐笔勾选合同现金流量特征判断项，判断结论驱动分类；不通过 SPPI 会有告警提示应改分类。

### ECL 测试
选择三阶段、录入违约概率/违约损失率等参数，测算减值准备；结果计入 OCI（不减账面）。

### G6-3 调整分录
点「新增调整分录」录入借贷，实时校验借贷平衡；点「推送至 A13」将错报同步至未更正错报汇总。

### 附注（上市 / 国企）
点「从明细带入」按分类聚合公允价值/减值数据；文本区可用「🤖 AI 辅助」生成披露草稿。

## 3. 常用操作速查

| 操作 | 位置 |
|------|------|
| 回写试算平衡表 | G6-1 审定表工具栏 |
| 从明细带入 | G6-1 / 附注 工具栏 |
| 列设置（显隐列） | G6-2 明细表工具栏 ⚙ |
| 导入 / 导出 | 各表「导入导出 ▾」 |
| 推送错报至 A13 | G6-3 调整分录 |
| AI 辅助说明 | 各审计说明/结论区右侧 |
| 复核对话 | 各区块标题右侧 💬 |

## 4. 联动关系速查

| 联动 | 说明 |
|------|------|
| G6-2 → G6-1 | 明细合计带入审定表未审数 |
| G6-3 → G6-1 | 调整分录回写账项/重分类调整列 |
| G6-1 → TB | 审定合计回写 1503 |
| G6-1 → 附注 | 审定数驱动披露自动取数 |
| SPPI/业务模式 → 分类 | 判断结论决定 FVOCI 分类是否成立 |
| ECL → OCI | 减值计入其他综合收益，不减账面 |
