# I1 无形资产 — 底稿编制手册

> **适用范围**：科目 **1701 无形资产（资产借方）/ 1702 累计摊销（备抵贷方）/ 1703 无形资产减值准备（备抵贷方）**
> **组件**：`i1-intangible-assets`
> **说明**：本手册说明各分表的审计目标、编制逻辑与勾稽关联，不替代各表页内已有说明文案。
> 平台按钮与操作步骤见「使用手册」页签。

---

## 1. 总体编制思路

无形资产核心 = **原值 − 累计摊销 − 减值准备 = 账面净值**，三科目三角勾稽同步审定。

| 证据链 | 主要底稿 | 回答的问题 |
|--------|----------|------------|
| **金额枢纽** | I1-2 明细 → I1-1 审定 ← I1-3 调整 | 三科目期末余额是否准确完整？ |
| **摊销引擎** | I1-9 分配 / I1-10 不含减值 / I1-11 含减值 | 本期摊销计提是否恰当、分配去向是否配平？ |
| **减值测试** | I1-12 减值测试 / I1-13 可收回金额(DCF) | 减值迹象与减值金额确认是否恰当？ |
| **专项检查** | I1-4 政策 / I1-5 增加 / I1-6 减少 / I1-7 寿命 / I1-8 权属 | 政策、增减、寿命估计、权属是否恰当完整？ |

**枢纽原则**：

1. **方向**：1701 资产借方 期末 = 期初 + 借方 − 贷方；1702/1703 备抵贷方 期末 = 期初 + 贷方 − 借方。
2. **I1-1 是结论枢纽**：审定期末回写试算表 1701 / 1702 / 1703，账面净值供附注披露。
3. **摊销双分支**：I1-10（不含减值）与 I1-11（含减值）二选一，取决于是否存在减值准备；结果与 I1-9 分配去向配平。
4. **使用寿命**：不确定寿命的无形资产不摊销、须年度减值测试并记录管理层询问（I1-7）。
5. **I1-5 增加检查** 可接收 I2 开发支出资本化转入的联动。

### 建议编制顺序

```
I1A 程序计划
  → I1-2 明细（56 列逐项登记）
  → I1-4 政策 / I1-7 寿命 / I1-8 权属
  → I1-9 摊销分配 + I1-10 或 I1-11 摊销测算
  → I1-12 减值测试 + I1-13 可收回金额(DCF)
  → I1-5 增加 / I1-6 减少
  → 差异汇入 I1-3 → 确认回写 I1-1
  → I1-1 勾稽 TB(1701/1702/1703) → 附注上市/国企
```

## 2. 分表编制说明

### I1A 实质性程序表
- **审计目标**：规划并记录无形资产实质性程序范围、性质与时间。
- **完成标志**：计划程序均有执行记录或「不适用」说明。

### I1-1 审定表（三科目三角勾稽）
- **审计目标**：核实原值/累计摊销/减值准备期末余额准确完整；提供审定数与账面净值。
- **编制逻辑**：审定 = 未审 + AJE + RJE；账面净值 = 1701 − 1702 − 1703。
- **上游**：I1-2 明细、I1-9~11 摊销、I1-12~13 减值；I1-3 确认回写。**下游**：TB(1701/1702/1703)、附注。
- **完成标志**：与 TB 勾稽差异已解释；审计说明与结论已填。

### I1-2 明细表
- **审计目标**：逐项核实无形资产存在、完整、准确（原值/摊销/减值分列）。
- **完成标志**：清单完整、合计与 I1-1 一致。

### I1-3 调整分录汇总
- **审计目标**：核实调整完整、借贷平衡。
- **完成标志**：借贷平衡；已确认回写 I1-1。

### I1-4 摊销减值政策检查表
- **审计目标**：核实摊销方法、年限、残值及减值政策恰当且前后一致。

### I1-5 增加检查表 / I1-6 减少明细表
- **审计目标**：核实本期增加（外购/自研/I2 资本化转入）与减少（处置/报废）真实、完整、计价准确。

### I1-7 使用寿命检查表
- **审计目标**：核实使用寿命估计合理；不确定寿命须记录判断依据与管理层询问。

### I1-8 权属检查表
- **审计目标**：核实无形资产权利归属清晰、无受限/抵押未披露。

### I1-9 摊销分配分析表
- **审计目标**：核实本期摊销分配去向（生产成本/制造费用/销售/管理/研发/其他）配平。
- **完成标志**：各去向合计 = 本期摊销总额。

### I1-10 / I1-11 摊销测算表（不含减值 / 含减值）
- **审计目标**：独立测算本期应计提摊销，与账面比对；含减值时按扣减后账面重算。
- **完成标志**：与 I1-1 摊销计提一致；分支选择正确。

### I1-12 减值准备测试表 / I1-13 可收回金额测试(DCF)
- **审计目标**：核实减值迹象识别与减值金额确认恰当；DCF 关键假设合理。

### 附注披露（上市/国企）
- **审计目标**：按附注格式披露无形资产原值/摊销/减值及账面净值，与审定勾稽。

### 底稿目录
- **审计目标**：导航与编制进度总览（跨表结论口径 + 底稿架构 + 本循环其他科目）。

## 5. 质量复核要点（摘要）

1. I1-1 三科目审定 ↔ TB(1701/1702/1703) 是否勾稽？账面净值是否 = 原值 − 摊销 − 减值？
2. I1-9 摊销分配去向合计 ↔ 本期摊销总额是否配平？
3. I1-10/11 分支选择是否与减值存在情况一致？测算 ↔ I1-1 摊销是否一致？
4. I1-7 不确定寿命项是否记录判断依据与管理层询问？
5. 附注金额是否等于 I1-1 审定？
