# I1 无形资产 — 平台使用手册

> 配合「编制手册」页签使用。本手册只说明**平台怎么操作**；审计目标与勾稽逻辑见编制手册。
> **不修改**各分表页内已有说明文案。入口：底稿目录页顶部「使用手册」按钮。

---

## 1. 打开与模式

1. 在项目底稿树打开 **I1 无形资产**（`componentType: i1-intangible-assets`，覆盖科目 1701/1702/1703）。
2. 通过 sheet 页签切换分表（I1A、I1-1~I1-13、附注上市/国企、底稿目录）。
3. 复杂 sheet 支持 **结构化 HTML ↔ OnlyOffice** 双模式；以项目配置为准（目录页不显示双模式）。
4. 只读阶段工具栏「取数 / 回写 / 确认」类按钮会禁用。

---

## 2. 推荐操作路径（点击顺序）

| 步骤 | 分表 | 建议操作 |
|------|------|----------|
| 1 | I1A | 勾选实质性程序、填索引 |
| 2 | I1-2 | 逐项登记明细（原值/摊销/减值分列） |
| 3 | I1-4 / I1-7 / I1-8 | 政策、使用寿命、权属检查 |
| 4 | I1-9 + I1-10/11 | 摊销分配 + 摊销测算（选不含/含减值分支） |
| 5 | I1-12 / I1-13 | 减值测试 + 可收回金额(DCF) |
| 6 | I1-5 / I1-6 | 增加/减少检查（增加可带入 I2 资本化） |
| 7 | I1-3 | 调整分录汇总 → 确认 → 回写 I1-1 |
| 8 | I1-1 | 确认审定 → 回写 TB(1701/1702/1703) |
| 9 | 附注上市/国企 | 从审定表取数 → 编辑 → 同步附注模块 |

## 3. 目录页速查

| 区块 | 说明 |
|------|------|
| 编制进度 | 各分表按审计说明/结论填写情况计算完成度 |
| 跨表结论口径 | 每张表审计结论「已填/未填」标签，点击跳转对应 sheet 补全 |
| 底稿架构 | 4 阶段泳道（审计计划/科目审定/实质性程序/披露与调整），点击卡片跳转 |
| 本循环底稿目录 | 同循环其他科目（I1~I6），点击跳转（灰色表示尚未生成） |

## 4. 常见问题

| 现象 | 处理 |
|------|------|
| I1-1 审定 ≠ TB 数 | 检查明细/摊销/减值是否全部带入、调整是否已确认回写；TB 取 1701/1702/1703 期末余额 |
| 账面净值不符 | 净值 = 原值(1701) − 累计摊销(1702) − 减值准备(1703)，检查三科目审定 |
| 摊销测算 ↔ 账面不符 | 确认分支（含/不含减值）与实际减值情况一致，I1-9 分配去向须配平 |
| 使用寿命项未通过校验 | I1-7 不确定寿命须补判断依据并完成管理层询问 |
| 附注同步失败 | 检查项目 ID、附注模块权限与准则类型（上市/国企） |
