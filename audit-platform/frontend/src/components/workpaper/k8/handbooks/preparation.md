# K8 销售费用 — 底稿编制手册

> **适用范围**：科目 **6601 销售费用（借方/损益类）**（含职工薪酬、业务费、广告宣传费、运输费、折旧摊销等）
> **组件**：`k8-selling-expenses`
> **说明**：本手册说明各分表的审计目标、编制逻辑与勾稽关联，不替代各表页内已有说明文案。
> 平台按钮与操作步骤见「使用手册」页签。

---

## 1. 总体编制思路

K8 是**损益类科目取发生额**（非期末余额），把「销售费用」拆成金额枢纽、分析截止与检查三条证据链，最后汇入审定与附注：

| 证据链 | 主要底稿 | 回答的问题 |
|--------|----------|------------|
| **金额枢纽** | K8-2 明细 → K8-1 审定 ← K8-3 调整 | 各明细科目发生额未审→调整→审定是否准确？ |
| **分析与截止** | K8-4 实质性分析 / K8-6 K8-7 双向截止 | 波动是否合理？期末费用截止是否正确？ |
| **专项检查** | K8-5 合同 / K8-8 综合检查 | 重大费用合同、凭证级检查是否恰当？ |

**枢纽原则**：

1. **K8-2 明细表是数据枢纽**——按明细科目登记发生额。
2. **K8-4 实质性分析**——同比/环比/占收入比识别异常波动。
3. **K8-6/K8-7 双向截止**——存在与完整性认定。
4. **K8-3 是调整枢纽**——差异确认后回写 K8-1。
5. **K8-1 是结论枢纽**——与试算（6601 发生额）、附注披露勾稽。

> **损益类方向铁律**：销售费用（6601）取**发生额非期末余额**；费用类发生额 = 借方发生累计 − 贷方发生（红冲）。审定数 = 未审数 + AJE + RJE。
> **双向截止**：K8-6 记账凭证→原始凭证（存在认定，验证已入账费用真实）；K8-7 原始凭证→记账凭证（完整性认定，验证期末费用无漏记）。

### 建议编制顺序（标准路径）

```
K8A 程序计划
  → K8-2 明细（按明细科目登记发生额）
  → K8-4 实质性分析（同比/环比/占收入比）
  → K8-6/K8-7 双向截止测试
  → K8-5 合同检查 → K8-8 综合检查
  → 差异汇入 K8-3 → 确认回写 K8-1（TB 6601 发生额）
  → 附注上市 / 附注国企
```

可按项目风险裁剪，但 **明细 → K8-1** 与 **实质性分析** 不宜省略。

## 2. 分表编制说明

每张表按统一结构：**审计目标 → 编制逻辑 → 上游/下游 → 完成标志**。

### K8A 实质性程序表
- **审计目标**：规划并记录针对销售费用的实质性程序范围、性质与时间。
- **完成标志**：计划程序均有执行记录或「不适用」说明。

### K8-1 审定表
- **审计目标**：核实销售费用各明细科目发生额准确完整；分类列报恰当；提供审定数。
- **编制逻辑**：按明细科目展开；未审发生额 / 账项调整(AJE) / 重分类(RJE) / 审定；审定 = 未审 + AJE + RJE。
- **上游**：K8-2 明细汇总；K8-3 确认回写。**下游**：试算表(6601 发生额)；附注。
- **完成标志**：与 TB 发生额勾稽差异已解释；审计结论已填。

### K8-2 明细表（数据枢纽）
- **审计目标**：核实各明细科目发生额发生、完整、准确、分类恰当。
- **编制逻辑**：按明细科目/月度登记发生额（3 区段），本期未审 / 账项调整 / 审定；占收入比。
- **完成标志**：清单完整；与 K8-1 汇总一致。

### K8-3 调整分录汇总
- **审计目标**：核实调整完整、借贷平衡。
- **完成标志**：借贷平衡；已确认回写 K8-1；异常推送 A13。

### K8-4 实质性分析
- **审计目标**：通过分析程序识别异常波动。
- **编制逻辑**：同比变动率 =(本期−上期)/上期；占收入比 = 费用/营业收入；结构比；异常波动原因分析。
- **完成标志**：异常波动已解释；结论有据。

### K8-5 合同检查表
- **审计目标**：核实重大费用合同真实性、金额匹配与审批。
- **编制逻辑**：按合同逐项核对费用摊销、金额匹配、审批完整性。
- **完成标志**：重大合同检查完整；异常已跟进。

### K8-6 截止性测试（记账凭证→原始凭证）
- **审计目标**：验证资产负债表日前后已入账费用真实（存在认定）。
- **编制逻辑**：从记账凭证追查原始凭证，按截止日前后分段判断跨期。
- **完成标志**：跨期项已识别；无未更正错报或已提调整。

### K8-7 截止性测试（原始凭证→记账凭证）
- **审计目标**：验证期末费用无漏记（完整性认定）。
- **编制逻辑**：从原始凭证倒查记账凭证，识别漏记/滞后入账。
- **完成标志**：漏记项已识别；无未更正错报或已提调整。

### K8-8 销售费用检查表
- **审计目标**：凭证级综合检查（真实性/审批/期间/分类）。
- **编制逻辑**：抽查凭证核对 5 项内容；检查比例达方案要求。
- **完成标志**：抽查完整；异常已跟进。

### 附注披露（上市/国企）
- **审计目标**：按附注格式披露销售费用构成（按性质分类），与审定勾稽。
- **完成标志**：金额与 K8-1 审定一致；已同步附注模块。

### 底稿目录
- **审计目标**：导航与编制进度总览（跨表结论口径 + 底稿架构）。
- **完成标志**：计划执行的分表状态均为完成或已说明不适用。

## 5. 质量复核要点（摘要）

1. K8-2 明细合计 ↔ K8-1 未审是否勾稽？（发生额口径）
2. K8-4 实质性分析异常波动是否已解释？占收入比是否合理？
3. K8-6/K8-7 双向截止是否发现跨期/漏记？是否已提调整？
4. K8-3 已确认调整是否已回写 K8-1？借贷是否平衡？
5. 附注金额是否等于 K8-1 审定（发生额）？
