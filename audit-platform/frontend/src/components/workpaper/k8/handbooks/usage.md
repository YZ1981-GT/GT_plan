# K8 销售费用 — 平台使用手册

> 配合「编制手册」页签使用。本手册只说明**平台怎么操作**；审计目标与勾稽逻辑见编制手册。
> **不修改**各分表页内已有说明文案。入口：底稿目录页顶部「使用手册」按钮。

---

## 1. 打开与模式

1. 在项目底稿树打开 **K8 销售费用**（`componentType: k8-selling-expenses`，覆盖科目 6601 损益类，取发生额）。
2. 通过 sheet 页签切换分表（K8A、K8-1～K8-8、附注上市/国企、底稿目录）。
3. 复杂 sheet 支持 **结构化 HTML ↔ OnlyOffice** 双模式；切换「在线编辑」需 OnlyOffice 拉取成功（目录页不显示双模式）。
4. 只读阶段工具栏「取数 / 回写 / 确认」类按钮会禁用。

---

## 2. 推荐操作路径（点击顺序）

| 步骤 | 分表 | 建议操作 |
|------|------|----------|
| 1 | K8A | 勾选实质性程序、填索引 |
| 2 | K8-2 | 按明细科目登记销售费用发生额（可从序时账取数） |
| 3 | K8-4 | 实质性分析（同比/环比/占收入比），解释异常波动 |
| 4 | K8-6 / K8-7 | 双向截止测试（记账→原始 / 原始→记账） |
| 5 | K8-5 | 重大费用合同检查 |
| 6 | K8-8 | 综合检查（凭证级） |
| 7 | K8-3 | 调整分录汇总 → 确认 → 回写 K8-1 |
| 8 | K8-1 | 「从明细带入」汇总未审发生额 → 核对调整回写 → 勾稽 TB(6601) |
| 9 | 附注上市/国企 | 拉取上游 → 编辑（按性质）→ 同步附注模块 |

---

## 3. 目录页速查

| 区块 | 说明 |
|------|------|
| 编制进度 | 各分表按实际填写字段数计算完成度 |
| 跨表结论口径 | 每张表审计结论「已填/未填」标签，点击跳转对应 sheet 补全 |
| 底稿架构 | 4 阶段泳道（审计计划/科目审定/实质性程序/披露与调整），点击卡片跳转 |
| 本循环底稿目录 | 同循环其他科目（K0~K18），点击跳转（灰色表示尚未生成） |

---

## 4. 导入导出

- 工具栏「导入/导出」按当前 sheet 作用。
- 导入后刷新当前表；若改了明细（K8-2），请重新对 K8-1 执行「从明细带入」。

---

## 5. 常见问题

| 现象 | 处理 |
|------|------|
| K8-1 审定合计 ≠ TB 数 | 检查是发生额口径而非余额；明细是否全部带入、调整是否已确认回写 |
| 双向截止发现跨期/漏记 | 在 K8-3 补调整，回写 K8-1 |
| 占收入比异常 | 核对营业收入基数（K/D 收入循环），分析费用波动合理性 |
| 附注同步失败 | 检查项目 ID、附注模块权限与准则类型（上市/国企） |

---

## 6. 复核入口

各分表工具栏/结论区「复核」打开复核对话。合伙人级复核提示词参考：`backend/data/tsj_review_prompts/K/`（若环境已部署）。
