# K10 其他收益 — 底稿编制手册

> **适用范围**：科目 **6117 其他收益（贷方/损益类）**（与企业日常活动相关的政府补助，如即征即退/财政贴息/研发补助/稳岗补贴）
> **组件**：`k10-other-income`
> **说明**：本手册说明各分表的审计目标、编制逻辑与勾稽关联，不替代各表页内已有说明文案。
> 平台按钮与操作步骤见「使用手册」页签。

---

## 1. 总体编制思路

K10 把「其他收益」拆成三条证据链，最后汇入审定与附注：

| 证据链 | 主要底稿 | 回答的问题 |
|--------|----------|------------|
| **金额枢纽** | K10-2 明细 → K10-1 审定 ← K10-3 调整 | 其他收益各补助项目发生额未审→调整→审定是否完整准确？ |
| **政府补助专项** | K10-4 政府补助核对 + K10-5 应收政府补助检查 | 补助分类是否恰当？递延分摊是否与 K7 一致？收款权利与时点是否成立？ |
| **综合检查** | K10-6 其他收益检查 | 分类正确性/合规性是否满足？ |

**枢纽原则**：

1. **损益类贷方科目（6117）取本期贷方发生额累计（贷方 = 收益增加），非期末余额**。
2. **其他收益仅指与日常活动相关的政府补助**——与日常活动无关的政府补助计入营业外收入（6301，K12 底稿）。
3. **K10-2 明细表是数据枢纽**——审定表从明细带入。
4. **K10-3 是调整枢纽**——差异确认后回写 K10-1，联动 A13。
5. **K10-1 是结论枢纽**——审定发生额回写试算平衡表（6117）、与附注披露勾稽。
6. **K10-4 政府补助核对**：直接计入 + 递延分摊，与 K7 递延收益（2401）本期分摊做一致性校验。

### 建议编制顺序（标准路径）

```
K10A 程序计划
  → K10-2 明细（按补助项目登记发生额）
  → K10-4 政府补助核对（直接/递延 → 与 K7 递延分摊一致性）
  → K10-5 应收政府补助检查（收款权利/确认时点）
  → K10-6 其他收益检查（分类正确性/合规性）
  → 差异汇入 K10-3 → 确认回写 K10-1（TB 回写 6117）
  → 附注上市 / 附注国企
```

## 2. 分表编制说明

每张表按统一结构：**审计目标 → 编制逻辑 → 上游/下游 → 完成标志**。

### K10A 实质性程序表
- **审计目标**：规划并记录针对其他收益的实质性程序范围、性质与时间。
- **完成标志**：计划程序均有执行记录或「不适用」说明。

### K10-1 审定表
- **审计目标**：核实其他收益各补助项目发生额准确完整；分类列报恰当；提供审定数。
- **编制逻辑**：按补助项目展开；未审发生额 + AJE + RJE = 审定发生额；审定发生额回写 TB（6117）。
- **上游**：K10-2 明细汇总；K10-3 确认回写。**下游**：试算表(6117)；附注。
- **完成标志**：与 TB 勾稽差异已解释；审计结论已填。

### K10-2 明细表（数据枢纽）
- **审计目标**：核实其他收益各补助项目发生额存在、完整、准确。
- **编制逻辑**：逐笔登记补助项目本期贷方发生额。
- **完成标志**：清单完整、与 K10-1 汇总一致。

### K10-3 调整分录汇总
- **审计目标**：核实调整完整、借贷平衡。
- **完成标志**：借贷平衡；已确认回写 K10-1；联动 A13 错报汇总。

### K10-4 政府补助核对表
- **审计目标**：核实政府补助分类（收益法/资产法）与金额恰当，递延分摊符合 CAS16。
- **编制逻辑**：直接计入其他收益 + 递延收益本期分摊转入；与 K7 递延收益（2401）本期分摊一致性校验。
- **完成标志**：分类判断有据；本期计入合计与 K10-1 勾稽；与 K7 一致。

### K10-5 应收政府补助检查表
- **审计目标**：核实应收政府补助的收款权利存在、预期可收回、确认时点恰当。
- **完成标志**：收款权利成立；确认时点有据；异常已跟进。

### K10-6 其他收益检查表
- **审计目标**：综合检查（分类正确性/合规性/凭证级测试）。
- **完成标志**：抽查比例达方案要求；异常已跟进。

### 附注披露（上市/国企）
- **审计目标**：按补助类型分别披露其他收益金额，与审定勾稽。
- **完成标志**：金额与 K10-1 审定一致；已同步附注模块。

### 底稿目录
- **审计目标**：导航与编制进度总览（跨表结论口径 + 底稿架构）。
- **完成标志**：计划执行的分表状态均为完成或已说明不适用。

## 4. 外部模块衔接

| 模块 | 与 K10 关系 |
|------|------------|
| **调整分录模块** | 与 K10-3 双向同步；确认驱动 K10-1 |

## 5. 质量复核要点（摘要）

1. K10-2 明细合计 ↔ K10-1 未审是否勾稽？
2. K10-4 递延分摊转入 ↔ K7 递延收益本期分摊是否一致？
3. K10-1 审定发生额是否已回写 TB（6117）？借贷是否平衡？
4. 附注金额是否等于 K10-1 审定？其他收益 vs 营业外收入分类是否正确？
