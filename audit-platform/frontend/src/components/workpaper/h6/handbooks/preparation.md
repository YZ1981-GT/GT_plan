# H6 固定资产清理 — 底稿编制手册

> **适用范围**：因出售、报废、毁损、对外投资等原因处置固定资产而转入清理的过渡性核算。科目 1606 固定资产清理。
> **组件**：GtBIndex 通用目录（H6 科目）
> **说明**：本手册说明各分表的审计目标、编制逻辑与勾稽关联，不替代各表页内已有说明文案。平台按钮与操作步骤见「使用手册」页签。

---

## 1. 总体编制思路

固定资产清理是**处置过程的中转科目**，期末余额通常应清零（清理完毕），未清零则说明处置尚在途：

- **清理净损益计算**：清理净损益 = 处置收入 + 残值 − 转入的账面价值（原值 − 累计折旧 − 减值）− 清理费用（含相关税费）。
- **净损益去向**：正常经营性处置的清理净损益转入**资产处置损益（H10）**；非正常（如自然灾害毁损报废）转入**营业外收入/营业外支出**。
- **联动 H1 固定资产减少**：转入清理的固定资产账面价值应与 H1 固定资产"减少（处置）"金额勾稽一致。
- 关注**长期挂账的清理科目**：期末仍有余额的清理项目须说明未完成原因，防止已实际完成处置却未结转损益。

| 证据链 | 主要底稿 | 回答的问题 |
|--------|----------|------------|
| 清理项目真实完整 | H6-2 明细表 | 每笔清理是否真实、对应固定资产处置？ |
| 净损益计算 | H6-2 明细 | 转入账面价值/清理费用/处置收入/残值是否准确？ |
| 净损益去向 | H6-2 明细 / H6-3 调整 | 转资产处置损益(H10)还是营业外收支？ |
| 与 H1 勾稽 | H6-2 明细 | 转入账面价值是否与 H1 固定资产减少勾稽？ |
| 期末余额 | H6-1 审定表 | 期末是否清零、未清零原因是否说明？ |

### 建议编制顺序

```
H6程序表 → H6-2明细(逐笔清理: 转入账面价值+清理费用-处置收入-残值=净损益)
  → 勾稽H1固定资产减少 → 判定净损益去向(H10资产处置损益 或 营业外收支)
  → H6-3调整(结转净损益) → 回写H6-1审定表(勾稽TB 1606) → 附注
```

## 2. 分表编制说明

### H6-1 审定表
列示清理项目期初、本期转入、本期结转、期末余额；未审数 + 账项调整(AJE) + 重分类调整(RJE) = 审定数；审定合计回写并勾稽试算表 1606；关注期末余额是否合理（通常应清零或有明确在途项目）。

### H6-2 明细表
逐笔清理明细：处置固定资产名称、处置原因、转入账面价值（原值/累计折旧/减值）、清理费用、处置收入、残值、清理净损益、净损益去向；核对处置合同、报废审批、收款凭证；与 H1 固定资产减少勾稽。

### H6-3 调整
清理净损益结转分录（转资产处置损益 H10 或营业外收支）、账项与重分类调整，借贷平衡后回写审定表并向 A13 推送错报。

### 附注
重大固定资产处置及清理情况说明；期末未完成清理项目及原因。

## 3. 认定覆盖速查

| 认定 | 主要底稿 |
|------|----------|
| 存在 | H6-2 明细（处置凭证/审批） |
| 完整性 | H6-2 明细 / H6-3 调整 |
| 权利和义务 | H6-2 明细（处置合同/收款） |
| 计价和分摊 | H6-2 明细（净损益计算） |
| 列报和披露 | H6-1 审定表 / 附注 |

## 4. 外部模块衔接

| 模块 | 关系 |
|------|------|
| H1 固定资产 | 转入清理的账面价值与 H1 固定资产减少（处置）勾稽 |
| H10 资产处置收益 | 经营性处置清理净损益转入资产处置损益 |
| 营业外收支 | 非正常处置（毁损报废）净损益转营业外收入/支出 |
| A13 错报汇总 | H6-3 调整分录未更正部分推送错报汇总 |
| 试算表 | H6-1 审定合计回写 1606 |

## 5. 质量复核要点（摘要）

- 清理净损益计算是否准确（转入账面价值、清理费用、处置收入、残值、相关税费）。
- 净损益去向判定是否恰当（资产处置损益 H10 vs 营业外收支），依据处置性质。
- 转入清理的账面价值是否与 H1 固定资产减少勾稽一致。
- 期末未清零的清理项目原因是否合理，是否存在已完成处置未结转损益。
- 处置合同、报废审批、收款凭证是否齐全，处置价格是否公允（尤其关联方处置）。
