# H6 固定资产清理 — 平台使用手册

> 本页说明各底稿在平台上的操作方式。审计目标与编制逻辑见「编制手册」页签。

## 1. 目录页（本页）

- 跨表结论口径看板：汇总核心表"审计说明或结论"是否已填，点击标签跳转对应分表。
- 底稿架构（4 阶段泳道）：审计计划 / 科目审定 / 实质性程序 / 披露与调整。
- 本循环底稿目录：H 循环其他科目，点击跳转。
- 编制/使用手册：右上角按钮。

## 2. 各底稿操作要点

- **H6-2 明细表**：逐笔录入清理项目，填转入账面价值/清理费用/处置收入/残值，系统算清理净损益；选择净损益去向（资产处置损益/营业外收支）。
- **H6-3 调整**：录入净损益结转分录与账项/重分类调整。
- **H6-1 审定表**：从明细带入未审数，录入 AJE/RJE 得审定数，保存回写试算表 1606。
- **附注**：从审定表带入重大处置及未完成清理说明。

## 3. 常用操作速查

| 操作 | 位置 |
|------|------|
| 从明细带入审定表 | H6-1 审定表「从明细带入」按钮 |
| 净损益计算 | H6-2 明细录入后自动算净损益 |
| 勾稽 H1 减少 | H6-2 明细「勾稽 H1」提示 |
| 回写试算表 | H6-1 审定表保存时回写 1606 |
| AI 辅助说明/结论 | 各表审计说明区「AI 辅助」按钮 |
| 复核对话 | 各表结论区复核圆点/复核按钮 |
| 版本历史 | 顶部工具栏版本按钮 |

## 4. 联动关系速查

| 联动 | 说明 |
|------|------|
| H1 → H6 | 固定资产处置转入清理，账面价值勾稽 H1 减少 |
| H6 → H10 | 经营性处置净损益转资产处置损益 |
| H6 → 营业外 | 非正常处置净损益转营业外收支 |

| 审定 → 试算表 | 审定合计回写 1606 |
| 调整 → A13 | 未更正错报推送错报汇总 |
