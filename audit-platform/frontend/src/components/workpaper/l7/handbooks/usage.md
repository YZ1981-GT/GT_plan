# L7 其他非流动负债 — 平台使用手册

> 配合「编制手册」页签使用。本手册只说明**平台怎么操作**；审计目标与勾稽逻辑见编制手册。
> **不修改**各分表页内已有说明文案。入口：底稿目录页顶部「使用手册」按钮。

---

## 1. 打开与模式

1. 在项目底稿树打开 **L7 其他非流动负债**（`componentType: l7-other-noncurrent-liabilities`，覆盖科目 2801）。
2. 通过 sheet 页签切换分表（L7A、L7-1～L7-4、附注上市/国企、底稿目录）。
3. 程序表（L7A）支持 **结构化 HTML ↔ OnlyOffice** 双模式；以项目配置为准（目录页不显示双模式）。
4. 只读阶段工具栏「取数 / 回写 / 确认」类按钮会禁用。

---

## 2. 推荐操作路径（点击顺序）

| 步骤 | 分表 | 建议操作 |
|------|------|----------|
| 1 | L7A | 勾选实质性程序、填索引 |
| 2 | L7-2 | 按项目逐行录入其他非流动负债明细（行可增删） |
| 3 | L7-4 | 检查表：分类恰当性 + 完整性/准确性核对 + 结论 |
| 4 | L7-3 | 调整分录汇总（含一年内到期重分类）→ 确认 → 回写 L7-1 |
| 5 | L7-1 | 确认审定期末（从 L7-2 带入）→ 回写 TB(2801) |
| 6 | 附注上市/国企 | 从审定表按项目取数 → 编辑 → 同步附注模块 |

## 3. 目录页速查

| 区块 | 说明 |
|------|------|
| 编制进度 | 各分表按审计说明/结论填写情况计算完成度 |
| 跨表结论口径 | 每张核心表（L7-1/L7-2/L7-4）审计结论「已填/未填」标签，点击跳转对应 sheet 补全 |
| 底稿架构 | 4 阶段泳道（审计计划/科目审定/实质性程序/披露与调整），点击卡片跳转 |
| 本循环底稿目录 | 同循环其他科目（L1~L8），点击跳转（灰色表示尚未生成） |

---

## 4. 常见问题

| 现象 | 处理 |
|------|------|
| L7-1 审定 ≠ TB 数 | 检查明细是否全部带入、调整是否已确认回写；TB 取 2801 期末余额 |
| 应否重分类 | 若项目实质为长期借款/应付债券/长期应付款/递延收益等，应在 L7-4 判定并经 L7-3 重分类 |
| 一年内到期 | 临近到期部分经 L7-3 重分类至流动负债（一年内到期的非流动负债 / 其他流动负债） |
| 附注金额不符 | 附注按项目披露金额应等于 L7-1 各项目审定数 |
| 附注同步失败 | 检查项目 ID、附注模块权限与准则类型（上市/国企） |

## 5. 复核入口

各分表工具栏/结论区「复核」打开复核对话。合伙人级复核提示词参考：`backend/data/tsj_review_prompts/L/`（若环境已部署）。
