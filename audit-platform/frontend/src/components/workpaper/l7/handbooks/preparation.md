# L7 其他非流动负债 — 底稿编制手册

> **适用范围**：科目 **2801 其他非流动负债（贷方/负债类）**
> **组件**：`l7-other-noncurrent-liabilities`
> **说明**：本手册说明各分表的审计目标、编制逻辑与勾稽关联，不替代各表页内已有说明文案。
> 平台按钮与操作步骤见「使用手册」页签。

---

## 1. 总体编制思路

其他非流动负债 = **不能归入长期借款、应付债券、长期应付款等明确项目的长期负债**（如超过一年的专项应付款尾差、长期递延收益之外的其他长期负债等）。核心 = **按项目列示的期末余额审定 + 分类恰当性 + 一年内到期部分重分类**。

| 证据链 | 主要底稿 | 回答的问题 |
|--------|----------|------------|
| **金额枢纽** | L7-2 明细 → L7-1 审定 ← L7-3 调整 | 其他非流动负债期末余额是否准确完整？ |
| **分类恰当性** | L7-4 检查表 | 是否应归入其他更明确的负债科目？ |
| **一年内到期** | L7-1 审定 / L7-3 调整 | 一年内到期部分是否已重分类至流动负债？ |
| **完整性/准确性** | L7-4 检查表 | 是否真实、完整、计量准确？ |

**枢纽原则**：

1. **负债类贷方科目**：期末 = 期初 + 贷方（增加）− 借方（减少）。审定表按项目双期列示（期初/期末各未审、账项调整、重分类、审定）。
2. **两期动态行**：项目行可增删，按被审计单位实际其他非流动负债项目逐行录入。
3. **L7-1 是结论枢纽**：审定期末合计回写试算表 2801，并驱动附注披露（上市/国企）。
4. **分类恰当性优先**：其他非流动负债是"其他"科目，编制时首要判断是否应重分类到长期借款/应付债券/长期应付款/递延收益等更明确科目。
5. **一年内到期重分类**：临近到期（一年内）的部分应重分类至流动负债（一年内到期的非流动负债 / 其他流动负债）。

### 建议编制顺序

```
L7A 程序计划
  → L7-2 明细（按项目逐行列示）
  → L7-4 检查表（分类恰当性 + 完整性/准确性 + 结论）
  → 差异/重分类汇入 L7-3 → 确认回写 L7-1
  → L7-1 勾稽 TB(2801) → 附注上市/国企
```

## 2. 分表编制说明

### L7A 实质性程序表
- **审计目标**：规划并记录其他非流动负债实质性程序范围、性质与时间。
- **完成标志**：计划程序均有执行记录或「不适用」说明。

### L7-1 审定表（负债类贷方，双期，动态项目行）
- **审计目标**：核实其他非流动负债期末余额准确完整；按项目提供审定数。
- **编制逻辑**：期末 = 期初 + 贷方 − 借方；审定 = 未审 + 账项调整 + 重分类；期初/期末双期分列；项目行可增删。
- **上游**：L7-2 明细（按项目带入）；L7-3 确认回写。**下游**：TB(2801)、附注上市/国企。
- **完成标志**：与 TB 勾稽差异已解释；一年内到期部分已重分类；审计说明与结论已填。

### L7-2 明细表
- **审计目标**：核实各项其他非流动负债存在、完整、准确（按项目列示）。
- **完成标志**：清单完整、合计与 L7-1 一致；审计说明与结论已填。

### L7-3 调整分录汇总
- **审计目标**：核实调整（含重分类）完整、借贷平衡。
- **完成标志**：借贷平衡；已确认回写 L7-1；同步集中调整登记 / 发布 A13 错报（如适用）。

### L7-4 其他非流动负债检查表
- **审计目标**：核对存在性、完整性、分类与列报恰当性、计量准确性，形成整体审计结论。
- **编制逻辑**：四区段（存在性 / 完整性 / 分类与列报 / 准确性）逐项核对，每项结论（通过/不通过/不适用）；重点判断是否应重分类到更明确科目。
- **完成标志**：各核对项完成；总体审计结论已填。

### 附注披露（上市/国企）
- **审计目标**：按附注格式披露其他非流动负债构成（按项目）及一年内到期情况，与审定勾稽。
- **完成标志**：披露金额与 L7-1 审定一致；已同步附注模块。

### 底稿目录
- **审计目标**：导航与编制进度总览（跨表结论口径 + 底稿架构 + 本循环其他科目）。

## 3. 认定覆盖速查

| 认定 | 主要底稿 |
|------|----------|
| 存在 | L7-2、L7-4（存在性） |
| 完整性 | L7-4（完整性） |
| 计价与分摊 | L7-1、L7-4（准确性） |
| 列报与披露 | L7-4（分类与列报）、附注上市/国企 |

---

## 4. 外部模块衔接

| 模块 | 与 L7 关系 |
|------|------------|
| **流动负债（一年内到期）** | L7-1 一年内到期部分重分类至流动负债 |
| **L 循环其他负债** | 分类恰当性判断是否应归入 L1~L6 更明确科目 |
| **试算平衡表** | L7-1 审定期末合计回写 2801 |
| **调整分录 / 集中登记 / A13** | 与 L7-3 双向同步 |
| **附注模块** | 其他非流动负债构成披露（按项目）+ 一年内到期 |

---

## 5. 质量复核要点（摘要）

1. L7-2 明细合计 ↔ L7-1 审定是否勾稽？
2. L7-1 审定期末 ↔ TB(2801) 是否勾稽？
3. 是否存在应重分类到长期借款/应付债券/长期应付款/递延收益等更明确科目的项目？
4. 一年内到期部分是否已重分类至流动负债？
5. L7-4 检查表分类与列报结论是否恰当？
6. 附注披露金额是否等于 L7-1 审定？
