# L8 财务费用 — 底稿编制手册

> **适用范围**：科目 **6603 财务费用（损益类/借方）**
> **组件**：`l8-financial-expenses`
> **说明**：本手册说明各分表的审计目标、编制逻辑与勾稽关联，不替代各表页内已有说明文案。
> 平台按钮与操作步骤见「使用手册」页签。

## 1. 总体编制思路

财务费用核心 = **按费用项目（利息支出/利息收入/汇兑损益/手续费/其他）汇总的本期发生额审定**，并验证利息测算、税前扣除性与截止归属。

| 证据链 | 主要底稿 | 回答的问题 |
|--------|----------|------------|
| **金额枢纽** | L8-2 明细 → L8-1 审定 ← L8-3 调整 | 财务费用本期发生额是否准确完整？ |
| **利息验证** | L8-4 非金融机构利息支出测算 | 借款利息计入财务费用是否恰当、可否税前扣除？ |
| **截止归属** | L8-5 截止性测试 | 费用是否记录于恰当会计期间？ |
| **综合核对** | L8-6 财务费用检查表 | 各费用项目分类、计量是否恰当？ |

**枢纽原则**：

1. **损益类借方科目**：本期发生额 = **借方发生 − 贷方发生**（**不是期末余额**），从 tb_ledger 取本期借贷发生额。
2. **费用构成**：财务费用 = 利息支出 − 利息收入 + 汇兑损益 + 手续费 + 其他；利息收入冲减，汇兑损益按净额。
3. **利息联动**：利息支出与 **L1 短期借款 / L3 长期借款 / L4 应付债券** 的利息测算及 **L5 未确认融资费用摊销** 勾稽核对。
4. **L8-1 是结论枢纽**：审定本期发生额回写试算表 6603，并驱动附注披露（上市/国企）。
5. **税前扣除性**：非金融机构（企业间）借款利息支出，超过按同期同类金融机构贷款利率计算部分，不得税前扣除（L8-4）。

### 建议编制顺序

```
L8A 程序计划
  → L8-2 明细（按费用项目：利息支出/收入/汇兑/手续费/其他）
  → L8-4 非金融机构利息测算（税前扣除性）
  → L8-5 截止性测试（序时账报告日±天数，费用归属）
  → L8-6 检查表（综合核对）
  → 差异汇入 L8-3 → 确认回写 L8-1
  → L8-1 勾稽 TB(6603) → 附注上市/国企
```

## 2. 分表编制说明

### L8A 实质性程序表
- **审计目标**：规划并记录财务费用实质性程序范围、性质与时间。
- **完成标志**：计划程序均有执行记录或「不适用」说明。

### L8-1 审定表（损益类借方，取发生额）
- **审计目标**：核实财务费用本期发生额准确完整；按费用项目提供审定数。
- **编制逻辑**：本期发生额 = 借方发生 − 贷方发生；审定 = 未审 + 账项调整 + 重分类。
- **上游**：L8-2 明细（按项目带入）；L8-3 确认回写。**下游**：TB(6603)、附注上市/国企。
- **完成标志**：与 TB 勾稽差异已解释；审计说明与结论已填。

### L8-2 明细表
- **审计目标**：核实各费用项目（利息支出/利息收入/汇兑损益/手续费/其他）发生真实、完整、准确、分类恰当。
- **完成标志**：项目列示完整、合计与 L8-1 一致；审计说明与结论已填。

### L8-3 调整分录汇总
- **审计目标**：核实调整完整、借贷平衡。
- **完成标志**：借贷平衡；已确认回写 L8-1；发布 A13 错报（如适用）。

### L8-4 非金融机构利息支出测算表
- **审计目标**：核实企业间（非金融机构）借款利息计入财务费用恰当，评价税前扣除性。
- **编制逻辑**：可扣除利息 = 本金 × min(实际利率, 同期同类金融机构贷款利率) × 天数 / 365；超额部分纳税调增。
- **完成标志**：测算与账面利息差异已解释；超同期金融利率部分已识别。

### L8-5 截止性测试
- **审计目标**：核实财务费用记录于恰当会计期间（跨期检查）。
- **编制逻辑**：以资产负债表日为基准，序时账报告日 ± 天数自动提取，检查费用归属期间正确性。
- **完成标志**：跨期项目逐笔说明；审计说明与结论已填。

### L8-6 财务费用检查表
- **审计目标**：综合核对费用项目分类、计量、披露，形成整体审计结论。
- **完成标志**：各核对项完成；审计结论与意见已填。

### 附注披露（上市/国企）
- **审计目标**：按附注格式披露财务费用明细（利息支出/利息收入/汇兑损益/手续费等），与审定勾稽。
- **完成标志**：明细金额与 L8-1 审定一致；已同步附注模块。

### 底稿目录
- **审计目标**：导航与编制进度总览（跨表结论口径 + 底稿架构 + 本循环其他科目）。

## 4. 外部模块衔接

| 模块 | 与 L8 关系 |
|------|------------|
| **L1 短期借款** | 短期借款利息测算 → L8 利息支出 |
| **L3 长期借款** | 长期借款利息测算 → L8 利息支出 |
| **L4 应付债券** | 应付债券利息 / 溢折价摊销 → L8 利息支出 |
| **L5 长期应付款** | 未确认融资费用摊销 → L8 利息支出 |
| **试算平衡表** | L8-1 审定本期发生额回写 6603 |
| **调整分录 / A13** | 与 L8-3 双向同步 |
| **附注模块** | 财务费用明细披露（利息支出/收入/汇兑/手续费） |
| **递延所得税 / N 循环** | 非金融利息超额不可扣除部分 → 纳税调增 |

## 5. 质量复核要点（摘要）

1. L8-2 明细合计 ↔ L8-1 审定是否勾稽？
2. L8-1 审定本期发生额 ↔ TB(6603) 是否勾稽？（发生额口径，非期末余额）
3. L8-4 利息测算 ↔ L1/L3/L4 借款利息测算是否核对一致？
4. 利息收入是否已冲减、汇兑损益是否按净额列示？
5. 非金融机构借款利息超同期金融利率部分是否已识别（税前扣除性）？
6. L8-5 截止测试跨期项目是否已恰当调整？
7. 附注明细金额是否等于 L8-1 审定？
