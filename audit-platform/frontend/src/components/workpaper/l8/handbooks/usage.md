# L8 财务费用 — 平台使用手册

> 配合「编制手册」页签使用。本手册只说明**平台怎么操作**；审计目标与勾稽逻辑见编制手册。
> **不修改**各分表页内已有说明文案。入口：底稿目录页顶部「使用手册」按钮。

---

## 1. 打开与模式

1. 在项目底稿树打开 **L8 财务费用**（`componentType: l8-financial-expenses`，覆盖科目 6603）。
2. 通过 sheet 页签切换分表（L8A、L8-1～L8-6、附注上市/国企、底稿目录）。
3. 程序表（L8A）支持结构化 HTML 渲染；复杂表以 OnlyOffice 兜底，以项目配置为准（目录页不显示双模式工具栏）。
4. 只读阶段工具栏「取数 / 回写 / 确认」类按钮会禁用。

---

## 2. 推荐操作路径（点击顺序）

| 步骤 | 分表 | 建议操作 |
|------|------|----------|
| 1 | L8A | 勾选实质性程序、填索引 |
| 2 | L8-2 | 按费用项目录入明细：利息支出/利息收入/汇兑损益/手续费/其他 |
| 3 | L8-4 | 非金融机构利息测算：本金×利率×天数/365，评价税前扣除性 |
| 4 | L8-5 | 截止性测试：报告日±天数自动提取，检查费用归属期间 |
| 5 | L8-6 | 财务费用检查表：综合核对分类/计量 |
| 6 | L8-3 | 调整分录汇总 → 确认 → 回写 L8-1 |
| 7 | L8-1 | 确认审定本期发生额（从 L8-2 带入）→ 回写 TB(6603) |
| 8 | 附注上市/国企 | 从审定表按项目取数 → 编辑 → 同步附注模块 |

## 4. 常见问题

| 现象 | 处理 |
|------|------|
| L8-1 审定 ≠ TB 数 | 财务费用取**本期发生额**（借方发生 − 贷方发生），非期末余额；检查明细是否全部带入、调整是否已确认回写 |
| 利息测算与账面不符 | 复核本金、年利率、计息天数；确认与 L1/L3/L4 借款利息、L5 摊销口径一致 |
| 利息收入未冲减 | 财务费用为借方发生额，利息收入应作贷方冲减，净额列示 |
| 非金融利息超额 | 企业间借款利息超同期同类金融机构贷款利率部分不可税前扣除，L8-4 识别后纳税调增 |
| 截止测试跨期 | 报告日前后 N 天序时账逐笔检查，跨期费用应调整至正确期间 |
| 附注明细金额不符 | 附注财务费用各项目金额应等于 L8-1 各项目审定数 |
| 附注同步失败 | 检查项目 ID、附注模块权限与准则类型（上市/国企） |
