# M2 实收资本（股本） — 底稿编制手册

> **适用范围**：科目 **4001 实收资本/股本（贷方/权益类，期末=期初+贷方−借方）**
> **组件**：`m2-paid-in-capital`
> **说明**：本手册说明各分表的审计目标、编制逻辑与勾稽关联，不替代各表页内已有说明文案。
> 平台按钮与操作步骤见「使用手册」页签。

---

## 1. 总体编制思路

实收资本（股本）核实**出资的真实性、完整性与合规性**：增资时贷方增加，减资时借方减少。

| 证据链 | 主要底稿 | 回答的问题 |
|--------|----------|------------|
| **余额审定** | M2-1 审定 ← M2-2 明细 | 实收资本期末余额是否准确完整？ |
| **出资明细** | M2-2 明细（上市/非上市） | 各出资人出资是否到位、比例是否正确？ |
| **外币折算** | M2-4 外币投资汇率测算 | 外币出资折算是否正确？ |
| **验资核对** | M2-5 检查表 | 验资报告、工商登记、章程是否一致？ |

**枢纽原则**：

1. **权益类贷方科目**：期末 = 期初 + 贷方（增资）− 借方（减资）。
2. **按出资人列示**：明细表 M2-2 分上市/非上市双版本，按出资人分列。
3. **外币投资折算**：M2-4 外币出资按约定汇率折算，折算差异计入 M4 资本公积。
4. **验资核对**：M2-5 核对验资报告、工商登记、公司章程与账面一致。
5. **M2-1 是结论枢纽**：审定合计回写试算表 4001，并驱动附注披露。

### 建议编制顺序

```
M2A 程序计划
  → M2-2 明细（选上市/非上市版本，按出资人列示）
  → M2-4 外币投资汇率测算（外币出资折算）
  → M2-5 检查表（验资/工商/章程核对）
  → M2-1 审定（未审 + AJE + RJE → 审定）→ 回写 TB(4001) → 附注上市/国企
  → M2-3 调整分录（借贷平衡，回写审定）
```

## 2. 分表编制说明

### M2A 实质性程序表
- **审计目标**：规划并记录实收资本实质性程序范围、性质与时间。
- **完成标志**：计划程序均有执行记录或「不适用」说明。

### M2-1 审定表（权益类贷方）
- **审计目标**：核实实收资本期末余额准确完整；提供审定数。
- **编制逻辑**：审定 = 未审 + AJE + RJE；权益期末 = 期初 + 贷方 − 借方。
- **上游**：M2-2 明细；M2-3 确认回写。**下游**：TB(4001)、附注。
- **完成标志**：与 M2-2 明细合计勾稽；审计结论已填。

### M2-2 明细表（上市/非上市双版本）
- **审计目标**：核实各出资人出资到位、持股比例准确。
- **完成标志**：明细合计与 M2-1 一致；审计说明已填。

### M2-3 调整分录汇总
- **审计目标**：核实调整完整、借贷平衡。
- **完成标志**：借贷平衡；已确认回写 M2-1。

### M2-4 外币投资汇率测算表
- **审计目标**：核实外币出资折算准确，折算差异正确计入资本公积。
- **完成标志**：折算差异已列示并解释；结论已填。

### M2-5 实收资本（股本）检查表
- **审计目标**：核对验资报告、工商登记、公司章程与账面一致。
- **完成标志**：验资/工商/章程凭证核对完整；结论已填。

### 附注披露（上市/国企）
- **审计目标**：按附注格式披露实收资本/股本，与审定勾稽。
- **完成标志**：金额与 M2-1 审定一致；已同步附注模块。

### 底稿目录
- **审计目标**：导航与编制进度总览（跨表结论口径 + 底稿架构 + 本循环其他科目）。

## 4. 外部模块衔接

| 模块 | 与 M2 关系 |
|------|------------|
| **M4 资本公积** | M2-4 外币折算差异 → 资本公积 |
| **验资报告 / 工商登记** | 出资到位核对（M2-5） |
| **试算平衡表** | M2-1 审定余额回写 4001 |

---

## 5. 质量复核要点（摘要）

1. M2-2 明细合计 ↔ M2-1 审定是否勾稽？
2. 各出资人出资是否到位、持股比例是否正确？
3. M2-1 审定 ↔ TB(4001) 是否勾稽？
4. 外币出资折算是否正确，差异是否计入资本公积？
5. 附注披露金额是否等于 M2-1 审定？
