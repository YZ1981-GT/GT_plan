# M7 专项储备 — 底稿编制手册

> **适用范围**：科目 **4201 专项储备（贷方/权益类，期末=期初+贷方−借方）**
> **组件**：`m7-special-reserve`
> **说明**：本手册说明各分表的审计目标、编制逻辑与勾稽关联，不替代各表页内已有说明文案。
> 平台按钮与操作步骤见「使用手册」页签。

---

## 1. 总体编制思路

专项储备核实**安全生产费等专项储备的计提合规性与使用**：计提时贷方增加，使用（费用化/资本化）时借方减少。

| 证据链 | 主要底稿 | 回答的问题 |
|--------|----------|------------|
| **余额审定** | M7-1 审定 ← M7-2 明细 | 专项储备期末余额是否准确完整？ |
| **计提+使用明细** | M7-2 明细 | 计提、使用明细是否准确？ |
| **计提测试** | M7-4 计提测试（安全生产费，按产量/收入分档） | 安全生产费计提标准是否合规？ |
| **支出检查** | M7-5 支出检查 | 专项储备支出（费用化/资本化）处理是否合规？ |

**枢纽原则**：

1. **权益类贷方科目**：期末 = 期初 + 贷方（计提）− 借方（使用）。
2. **安全生产费计提**：按产量或收入分档计提标准（如煤炭、非煤矿山、危化品等）。
3. **使用处理**：费用化计入成本费用，资本化形成的固定资产 → H1。
4. **M7-1 是结论枢纽**：审定合计回写试算表 4201，并驱动附注披露。

### 建议编制顺序

```
M7A 程序计划
  → M7-2 明细（计提 + 使用明细）
  → M7-4 计提测试（安全生产费按产量/收入分档标准）
  → M7-5 支出检查（费用化/资本化处理合规）
  → M7-1 审定（未审 + AJE + RJE → 审定）→ 回写 TB(4201) → 附注上市/国企
  → M7-3 调整分录（借贷平衡，回写审定）
```

## 2. 分表编制说明

### M7A 实质性程序表
- **审计目标**：规划并记录专项储备实质性程序范围、性质与时间。
- **完成标志**：计划程序均有执行记录或「不适用」说明。

### M7-1 审定表（权益类贷方）
- **审计目标**：核实专项储备期末余额准确完整；提供审定数。
- **编制逻辑**：审定 = 未审 + AJE + RJE；权益期末 = 期初 + 贷方 − 借方。
- **上游**：M7-2 明细；M7-3 确认回写。**下游**：TB(4201)、附注。
- **完成标志**：与 M7-2 明细合计勾稽；审计结论已填。

### M7-2 明细表（计提 + 使用）
- **审计目标**：核实各类专项储备计提、使用明细准确。
- **完成标志**：明细合计与 M7-1 一致；审计说明已填。

### M7-3 调整分录汇总
- **审计目标**：核实调整完整、借贷平衡。
- **完成标志**：借贷平衡；已确认回写 M7-1。

### M7-4 专项储备计提测试表
- **审计目标**：核实安全生产费按产量/收入分档标准计提合规。
- **完成标志**：计提测算有据；结论已填。

### M7-5 专项储备支出检查表
- **审计目标**：核实专项储备支出（费用化/资本化）处理合规。
- **完成标志**：支出凭证核对完整；资本化支出正确转 H1；结论已填。

### 附注披露（上市/国企）
- **审计目标**：按附注格式披露专项储备，与审定勾稽。
- **完成标志**：金额与 M7-1 审定一致；已同步附注模块。

### 底稿目录
- **审计目标**：导航与编制进度总览（跨表结论口径 + 底稿架构 + 本循环其他科目）。

## 5. 质量复核要点（摘要）

1. M7-2 明细合计 ↔ M7-1 审定是否勾稽？
2. 安全生产费计提标准（按产量/收入分档）是否合规？
3. 专项储备支出费用化/资本化处理是否正确？
4. M7-1 审定 ↔ TB(4201) 是否勾稽？
5. 附注披露金额是否等于 M7-1 审定？
