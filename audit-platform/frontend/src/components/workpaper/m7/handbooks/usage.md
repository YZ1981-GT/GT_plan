# M7 专项储备 — 平台使用手册

> 配合「编制手册」页签使用。本手册只说明**平台怎么操作**；审计目标与勾稽逻辑见编制手册。
> **不修改**各分表页内已有说明文案。入口：底稿目录页顶部「使用手册」按钮。

---

## 1. 打开与模式

1. 在项目底稿树打开 **M7 专项储备**（`componentType: m7-special-reserve`，覆盖科目 4201）。
2. 通过 sheet 页签切换分表（M7A、M7-1～M7-5、附注上市/国企、底稿目录）。
3. 复杂 sheet 支持 **结构化 HTML ↔ OnlyOffice** 双模式；以项目配置为准（目录页不显示双模式）。
4. 只读阶段工具栏「取数 / 回写 / 确认」类按钮会禁用。

---

## 2. 推荐操作路径（点击顺序）

| 步骤 | 分表 | 建议操作 |
|------|------|----------|
| 1 | M7A | 勾选实质性程序、填索引 |
| 2 | M7-2 | 录入计提 + 使用明细 |
| 3 | M7-4 | 安全生产费按产量/收入分档计提测试 |
| 4 | M7-5 | 专项储备支出（费用化/资本化）检查 |
| 5 | M7-1 | 确认审定（未审 + AJE + RJE）→ 回写 TB(4201) |
| 6 | 附注上市/国企 | 从审定表取数 → 同步附注模块 |

## 3. 目录页速查

| 区块 | 说明 |
|------|------|
| 编制进度 | 各分表按审计说明/结论填写情况计算完成度 |
| 跨表结论口径 | 每张表审计结论「已填/未填」标签，点击跳转对应 sheet 补全 |
| 底稿架构 | 4 阶段泳道（审计计划/科目审定/实质性程序/披露与调整），点击卡片跳转 |
| 本循环底稿目录 | 同循环其他科目（M1~M10），点击跳转（灰色表示尚未生成） |

## 4. 常见问题

| 现象 | 处理 |
|------|------|
| M7-1 审定 ≠ TB 数 | 专项储备为权益类贷方（期末=期初+贷−借）；检查 M7-2 明细是否带入 |
| 明细合计与审定不符 | 复核 M7-2 计提、使用明细是否齐全 |
| 计提标准对不上 | 核对 M7-4 安全生产费按产量/收入分档标准 |
| 支出处理不清 | 复核 M7-5：费用化计入成本费用，资本化支出转 H1 固定资产 |
| 附注同步失败 | 检查项目 ID、附注模块权限与准则类型（上市/国企） |

---

## 5. 复核入口

各分表工具栏/结论区「复核」打开复核对话。合伙人级复核提示词参考：`backend/data/tsj_review_prompts/M/`（若环境已部署）。
