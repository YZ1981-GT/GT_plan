# D1 应收票据 — 底稿编制手册

> **适用范围**：科目 **1121 应收票据**（银行承兑汇票 / 商业承兑汇票）
> **组件**：`d1-notes-receivable`
> **说明**：本手册说明各分表的审计目标、编制逻辑与勾稽关联。
> **不替代**各表页内已有的审计目标/过程提示文案（页内说明保持不变）。
> 平台按钮与操作步骤见「使用手册」页签。

---

## 1. 总体编制思路

D1 把「应收票据」拆成四条证据链，最后汇入审定与附注：

| 证据链 | 主要底稿 | 回答的问题 |
|--------|----------|------------|
| **金额枢纽** | D1-2/D1-3 → D1-1 ← D1-5 | 未审→调整→审定是否完整准确？ |
| **存在/权利** | D1-7 备查簿核对；D1-10 票据监盘；D1-8 贴现背书；D1-13 抽凭 | 票据账实、权属、终止确认是否恰当？ |
| **计价/减值** | D1-4 坏账准备；D1-14 政策；D1-15 ECL；D1-16 核销转回 | 减值计提是否充分、政策是否恰当？ |
| **完整性/披露** | D1-9 利息计算；D1-11 关联方；D1-12 质押；附注 | 利息、关联方、受限票据披露是否完整？ |

**枢纽原则**：

1. **D1-2/D1-3 明细表是数据枢纽**——审定表按类别/客户从明细带入。
2. **D1-5 是调整枢纽**——差异确认后回写 D1-1。
3. **D1-1 是结论枢纽**——与试算（1121）、附注披露勾稽。
4. **D1A 程序表**统领「做了哪些程序」；分表记录「证据与结论」。

### 建议编制顺序（标准路径）

```
D1A 程序计划
  → D1-2 按类别明细 / D1-3 按客户明细（先立清单）
  → 存在链：D1-10 票据监盘 / D1-7 备查簿核对 / D1-8 贴现背书 / D1-13 抽凭
  → 计价链：D1-4 坏账准备 / D1-14 政策检查 / D1-15 ECL 减值模型 / D1-16 核销转回
  → 完整性链：D1-9 利息计算 / D1-11 关联方 / D1-12 质押检查 / D1-6 基准日后回收
  → 差异汇入 D1-5 → 确认回写 D1-1
  → 附注上市 / 附注国企
```

可按项目风险裁剪（如无贴现背书可弱化 D1-8；无质押可弱化 D1-12），但 **明细 → D1-1** 与 **减值计提** 不宜省略。

## 2. 分表编制说明

每张表按统一结构：**审计目标 → 编制逻辑 → 上游/下游 → 完成标志**。

### D1A 实质性程序表
- **审计目标**：规划并记录针对应收票据的实质性程序范围、性质与时间。
- **完成标志**：计划程序均有执行记录或「不适用」说明；索引可跳转分表。

### D1-1 审定表
- **审计目标**：核实应收票据余额准确完整；银行/商业承兑分类列报恰当；为报表与附注提供审定数。
- **编制逻辑**：期初/期末 × 未审 / 账项调整 / 审定；按银承/商承展开；审定 = 未审 + 调整。
- **上游**：D1-2/D1-3 汇总；D1-5 确认回写。**下游**：试算表（1121）；附注。
- **完成标志**：与 TB 勾稽差异已解释；调整来源可追溯至 D1-5；结论已填。

### D1-2 按类别明细表 / D1-3 按客户明细表（数据枢纽）
- **审计目标**：核实存在、完整、权利与计价；按承兑类别/出票人列示。
- **编制逻辑**：逐票据列示出票人、票据类别、票面金额、出票/到期日；期末未终止确认票据保留在账。
- **下游**：D1-1、D1-4、D1-8、D1-10 带入源。
- **完成标志**：清单完整、与 D1-1 汇总一致。

### D1-4 坏账准备
- **审计目标**：核实应收票据（主要为商业承兑）减值准备计提充分、恰当。
- **编制逻辑**：单项计提 + 组合计提；商业承兑存在信用风险的按 ECL 计提。
- **下游**：D1-1 减值列；与 D1-15 ECL 模型勾稽。
- **完成标志**：计提金额与 D1-15 一致；结论已填。

### D1-5 调整分录
- **审计目标**：核实应收票据及相关科目调整完整、借贷平衡。
- **完成标志**：借贷平衡；已确认回写 D1-1；索引指向证据表。

### D1-6 基准日后应收款项回收
- **审计目标**：以期后到期兑付/背书佐证期末票据存在与可回收性。
- **完成标志**：期后回款/兑付记录与账面勾稽。

### D1-7 票据备查簿核对
- **审计目标**：应收票据备查簿与账面记录一致，无账外票据。
- **完成标志**：备查簿逐票核对通过。

### D1-8 贴现背书明细
- **审计目标**：核实贴现/背书票据的终止确认判断（CAS23 金融资产转移）。
- **编制逻辑**：已贴现/背书但尚未到期票据区分「已终止确认 / 未终止确认」；未终止确认的仍列应收票据并表外披露。
- **完成标志**：终止确认判断有据；未终止确认金额已披露；与 D5 应收款项融资勾稽。

### D1-9 利息计算检查
- **审计目标**：带息票据利息计算完整准确。
- **完成标志**：利息测算与账面差异已解释。

### D1-10 票据监盘
- **审计目标**：实物票据存在且账实相符。
- **完成标志**：监盘要素（日期/范围/差异处理）已记录。

### D1-11 关联方
- **审计目标**：识别关联方票据，核对披露完整性。
- **完成标志**：关联方票据已识别，与 B19 清单核对。

### D1-12 质押检查
- **审计目标**：核实质押/受限票据，所有权受限情况披露完整。
- **完成标志**：受限票据与借款质押/或有事项交叉核对。

### D1-13 抽凭检查
- **审计目标**：以凭证级检查佐证票据存在、发生真实。
- **编制逻辑**：抽凭引擎科目 1121；记账凭证 + 支持性文件（票据/贴现协议）。
- **完成标志**：抽查比例达方案要求；异常已跟进。

### D1-14 会计政策检查
- **审计目标**：应收票据分类、减值政策符合准则。
- **完成标志**：政策逐项判断结论已填。

### D1-15 ECL 减值模型
- **审计目标**：按预期信用损失模型测算应收票据（商业承兑）减值。
- **编制逻辑**：组合/单项 ECL；模型应计提减值与 D1-4 坏账准备勾稽。
- **完成标志**：模型测算与 D1-4 一致；差异已解释。

### D1-16 核销与转回
- **审计目标**：核实票据核销、减值转回的合规性与授权。
- **完成标志**：核销/转回有据、已授权。

### 附注披露（上市/国企）
- **审计目标**：按附注格式披露应收票据构成、已质押/已背书或贴现未到期票据，与审定勾稽。
- **完成标志**：金额与 D1-1 审定一致；受限/终止确认情况已披露；已同步附注模块。

### 底稿目录
- **审计目标**：导航与编制进度总览（跨表结论口径 + 底稿架构）。
- **完成标志**：计划执行的分表状态均为完成或已说明不适用。

## 5. 质量复核要点（摘要）

1. D1-2/D1-3 合计 ↔ D1-1 未审是否勾稽？
2. D1-5 已确认调整是否已体现在 D1-1？借贷是否平衡？
3. D1-15 ECL 模型应计提 ↔ D1-4 坏账准备审定是否一致？
4. D1-8 已贴现未终止确认票据是否表外披露、与 D5 勾稽？
5. 附注金额是否等于 D1-1 审定？受限票据是否披露？
