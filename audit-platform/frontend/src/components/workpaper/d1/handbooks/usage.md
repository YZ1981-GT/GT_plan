# D1 应收票据 — 平台使用手册

> 配合「编制手册」页签使用。
> 本手册只说明**平台怎么操作**；审计目标与勾稽逻辑见编制手册。
> **不修改**各分表页内已有说明文案。
> 入口：底稿目录页顶部「使用手册」按钮。

---

## 1. 打开与模式

1. 在项目底稿树打开 **D1 应收票据**（`componentType: d1-notes-receivable`，覆盖科目 1121）。
2. 通过 sheet 页签切换分表（D1A、D1-1～D1-16、附注上市/国企、底稿目录）。
3. 复杂 sheet 支持 **结构化 HTML ↔ OnlyOffice** 双模式；以项目配置为准（目录页除外）。
4. 只读阶段工具栏「取数 / 回写 / 确认」类按钮会禁用。

**需要项目上下文的操作**（缺 `projectId` 会提示无法执行）：

- D1-3 期后兑付取数、D1-13 抽凭
- 附注「同步到附注模块」

## 2. 推荐操作路径（点击顺序）

| 步骤 | 分表 | 建议操作 |
|------|------|----------|
| 1 | D1A | 勾选实质性程序、填索引 |
| 2 | D1-2 / D1-3 | 录入按类别 / 按客户票据明细 |
| 3 | D1-10 / D1-7 | 票据监盘、备查簿核对 |
| 4 | D1-8 | 贴现背书明细，判断终止确认 |
| 5 | D1-4 / D1-15 | 坏账准备、ECL 减值模型（两者勾稽） |
| 6 | D1-14 | 会计政策检查 |
| 7 | D1-9 | 利息计算检查 |
| 8 | D1-11 / D1-12 | 关联方、质押检查 |
| 9 | D1-13 | 抽凭检查（抽凭引擎，科目 1121） |
| 10 | D1-6 | 基准日后应收款项回收 |
| 11 | D1-16 | 核销与转回检查 |
| 12 | D1-5 | 调整分录汇总 → 确认 → 回写 D1-1 |
| 13 | D1-1 | 「从明细带入」汇总未审 → 核对调整回写 → 勾稽 TB |

## 3. 目录页速查

| 区块 | 说明 |
|------|------|
| 编制进度 | 各分表填妥「审计说明或结论」即计入完成 |
| 跨表结论口径 | 每张表审计结论「已填/未填」标签，点击跳转对应 sheet 补全 |
| 编制提示 | 折叠展开，推荐编制工作流 |
| 底稿架构 | 4 阶段泳道（审计计划/科目审定/实质性程序/披露与调整），点击卡片跳转 |
| 本循环底稿目录 | 同循环（D 循环）其他底稿（灰色表示未生成） |

---

## 4. 导入导出

- 工具栏「导入/导出」按当前 sheet 作用（具备后端端点的 sheet）。
- 导入后刷新当前表；若改了明细（D1-2/D1-3），请重新对 D1-1 执行「从明细带入」。

---

## 5. 常见问题

| 现象 | 处理 |
|------|------|
| D1-1 审定合计 ≠ TB 数 | 检查明细是否全部带入、调整是否已确认回写 |
| D1-15 与 D1-4 减值差异 | 核对 ECL 模型口径与坏账准备计提基础 |
| D1-8 已贴现未终止确认告警 | 确认票据仍列示应收票据并作表外披露、与 D5 勾稽 |
| 抽凭无数据 | 确认凭证库有 1121 发生额且抽凭引擎可访问 |
| 附注同步失败 | 检查项目 ID、附注模块权限与准则类型（上市/国企） |
