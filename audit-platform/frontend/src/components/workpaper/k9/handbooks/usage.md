# K9 管理费用 — 平台使用手册

> 配合「编制手册」页签使用。本手册只说明**平台怎么操作**；审计目标与勾稽逻辑见编制手册。
> **不修改**各分表页内已有说明文案。入口：底稿目录页顶部「使用手册」按钮。

---

## 1. 打开与模式

1. 在项目底稿树打开 **K9 管理费用**（`componentType: k9-admin-expenses`，覆盖科目 6602）。
2. 通过 sheet 页签切换分表（K9A、K9-1～K9-8、附注上市/国企、底稿目录）。
3. 复杂 sheet 支持 **结构化 HTML ↔ OnlyOffice** 双模式；以项目配置为准（目录页不显示双模式）。
4. 只读阶段工具栏「取数 / 回写 / 确认」类按钮会禁用。

---

## 2. 推荐操作路径（点击顺序）

| 步骤 | 分表 | 建议操作 |
|------|------|----------|
| 1 | K9A | 勾选实质性程序、填索引 |
| 2 | K9-2 | 按费用性质录入管理费用明细科目发生额 |
| 3 | K9-4 | 实质性分析（同比/环比/占收入比），解释异常波动 |
| 4 | K9-6 / K9-7 | 双向截止测试，标记跨期项目 |
| 5 | K9-5 | 重大费用合同检查 |
| 6 | K9-8 | 综合检查（凭证级测试） |
| 7 | K9-3 | 调整分录汇总 → 确认 → 回写 K9-1 |
| 8 | K9-1 | 「从明细带入」汇总未审 → 核对调整回写 → 勾稽 TB(6602) |
| 9 | 附注上市/国企 | 拉取上游 → 编辑 → 同步附注模块 |

---

## 3. 目录页速查

| 区块 | 说明 |
|------|------|
| 编制进度 | 各分表按实际填写字段数计算完成度 |
| 跨表结论口径 | 每张表审计结论「已填/未填」标签，点击跳转对应 sheet 补全 |
| 底稿架构 | 4 阶段泳道（审计计划/科目审定/实质性程序/披露与调整），点击卡片跳转 |
| 本循环底稿目录 | 同循环其他科目（K0~K18），点击跳转（灰色表示尚未生成） |

---

## 4. 导入导出

- 工具栏「导入/导出」按当前 sheet 作用。
- 导入后刷新当前表；若改了明细（K9-2），请重新对 K9-1 执行「从明细带入」。

---

## 5. 常见问题

| 现象 | 处理 |
|------|------|
| K9-1 审定合计 ≠ TB 数 | 检查明细是否全部带入、调整是否已确认回写；确认取的是发生额非余额 |
| K9-4 波动异常未通过 | 补充异常波动原因说明 |
| 附注同步失败 | 检查项目 ID、附注模块权限与准则类型（上市/国企） |

---

## 6. 复核入口

各分表工具栏/结论区「复核」打开复核对话。合伙人级复核提示词参考：`backend/data/tsj_review_prompts/K/`（若环境已部署）。
