# K9 管理费用 — 底稿编制手册

> **适用范围**：科目 **6602 管理费用（借方/损益类）**（企业行政管理部门为组织和管理生产经营发生的各项费用）
> **组件**：`k9-admin-expenses`
> **说明**：本手册说明各分表的审计目标、编制逻辑与勾稽关联，不替代各表页内已有说明文案。
> 平台按钮与操作步骤见「使用手册」页签。

---

## 1. 总体编制思路

K9 把「管理费用」拆成三条证据链，最后汇入审定与附注：

| 证据链 | 主要底稿 | 回答的问题 |
|--------|----------|------------|
| **金额枢纽** | K9-2 明细 → K9-1 审定 ← K9-3 调整 | 管理费用各明细科目发生额未审→调整→审定是否完整准确？ |
| **分析与截止** | K9-4 实质性分析 + K9-6/K9-7 截止测试 | 波动是否合理？期末费用截止是否正确？ |
| **专项检查** | K9-5 合同检查 + K9-8 综合检查 | 大额合同是否真实有据、逐项是否合规？ |

**枢纽原则**：

1. **损益类借方科目（6602）取发生额，非期末余额**——发生额 = 借方发生累计 − 贷方发生（红冲）。
2. **K9-2 明细表是数据枢纽**——审定表从明细带入。
3. **K9-3 是调整枢纽**——差异确认后回写 K9-1。
4. **K9-1 是结论枢纽**——审定发生额回写试算平衡表（6602）、与附注披露勾稽。
5. **K9A 程序表**统领「做了哪些程序」；分表记录「证据与结论」。

### 建议编制顺序（标准路径）

```
K9A 程序计划
  → K9-2 明细（按费用性质立清单，登记发生额）
  → K9-4 实质性分析（同比/环比/占收入比）
  → K9-6 / K9-7 截止测试（双向）
  → K9-5 合同检查 → K9-8 综合检查
  → 差异汇入 K9-3 → 确认回写 K9-1（TB 回写 6602）
  → 附注上市 / 附注国企
```

可按项目风险裁剪（如无重大费用合同可弱化 K9-5），但 **明细 → K9-1** 不宜省略。

## 2. 分表编制说明

每张表按统一结构：**审计目标 → 编制逻辑 → 上游/下游 → 完成标志**。

### K9A 实质性程序表
- **审计目标**：规划并记录针对管理费用的实质性程序范围、性质与时间。
- **完成标志**：计划程序均有执行记录或「不适用」说明。

### K9-1 审定表
- **审计目标**：核实管理费用各明细科目发生额准确完整；分类列报恰当；提供审定数。
- **编制逻辑**：按费用性质展开；未审发生额 + AJE + RJE = 审定发生额；审定发生额回写 TB（6602）。
- **上游**：K9-2 明细汇总；K9-3 确认回写。**下游**：试算表(6602)；附注。
- **完成标志**：与 TB 勾稽差异已解释；审计结论已填。

### K9-2 明细表（数据枢纽）
- **审计目标**：核实管理费用各明细科目发生额存在、完整、准确。
- **编制逻辑**：按明细科目（职工薪酬/折旧/摊销/办公费/差旅费/中介机构费等）登记本期借方发生额。
- **完成标志**：清单完整、与 K9-1 汇总一致。

### K9-3 调整分录汇总
- **审计目标**：核实调整完整、借贷平衡。
- **完成标志**：借贷平衡；已确认回写 K9-1；联动 A13 错报汇总。

### K9-4 实质性分析
- **审计目标**：通过趋势与比率分析识别异常波动。
- **编制逻辑**：同比变动率 = (本期−上期)/上期；占收入比 = 费用/营业收入；异常波动需原因说明。
- **完成标志**：异常波动已解释；分析合计与 K9-2 明细一致。

### K9-6 截止性测试（记账凭证 → 原始凭证）
- **审计目标**：验证资产负债表日前后所记费用真实发生（存在认定）。
- **完成标志**：抽样凭证均追至原始单据；跨期项目已标记。

### K9-7 截止性测试（原始凭证 → 记账凭证）
- **审计目标**：验证期末已发生费用均已入账（完整性认定）。
- **完成标志**：抽样原始单据均已入账；漏记项目已跟进。

### K9-5 合同检查表
- **审计目标**：核实重大费用合同真实性、金额匹配、审批完整。
- **完成标志**：抽查合同均有据；异常已跟进。

### K9-8 管理费用检查表
- **审计目标**：凭证级综合检查（真实性/审批/期间/分类）。
- **完成标志**：抽查比例达方案要求；异常已跟进。

### 附注披露（上市/国企）
- **审计目标**：按附注格式披露管理费用构成，与审定勾稽。
- **完成标志**：金额与 K9-1 审定一致；已同步附注模块。

### 底稿目录
- **审计目标**：导航与编制进度总览（跨表结论口径 + 底稿架构）。
- **完成标志**：计划执行的分表状态均为完成或已说明不适用。

## 4. 外部模块衔接

| 模块 | 与 K9 关系 |
|------|------------|
| **调整分录模块** | 与 K9-3 双向同步；确认驱动 K9-1 |

| **附注模块** | 管理费用披露 |

## 5. 质量复核要点（摘要）

1. K9-2 明细合计 ↔ K9-1 未审是否勾稽？
2. K9-1 审定发生额是否已回写 TB（6602）？借贷是否平衡？
3. K9-4 异常波动是否已解释？
4. 附注金额是否等于 K9-1 审定？
