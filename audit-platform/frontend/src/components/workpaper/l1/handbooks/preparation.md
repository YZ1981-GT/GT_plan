# L1 短期借款 — 底稿编制手册

> **适用范围**：科目 **2001 短期借款（贷方/负债类）**
> **组件**：`l1-short-term-loans`
> **说明**：本手册说明各分表的审计目标、编制逻辑与勾稽关联，不替代各表页内已有说明文案。
> 平台按钮与操作步骤见「使用手册」页签。

---

## 1. 总体编制思路

短期borrowing核心 = **按借款种类（信用/抵押/保证/质押）汇总的期末余额审定**，并验证利息计提与担保、逾期、征信完整性。

| 证据链 | 主要底稿 | 回答的问题 |
|--------|----------|------------|
| **金额枢纽** | L1-2 明细 → L1-1 审定 ← L1-3 调整 | 短期借款期末余额是否准确完整？ |
| **利息验证** | L1-5 利息测算表 | 应计短期借款利息是否恰当？ |
| **完整性** | L1-4 征信报告核对 / L1-7 逾期检查 | 是否存在账外借款、逾期未偿？ |
| **担保** | L1-8 抵质押资产检查 | 抵押/质押担保是否披露完整？ |
| **合同** | L1-6 贷款合同检查 / L1-9 检查表 | 合同要素、分类、期限是否恰当？ |

**枢纽原则**：

1. **负债类贷方科目**：期末 = 期初 + 贷方（借入）− 借方（归还）。审定表按借款种类分类，双期（期初/期末各未审、账项调整、重分类、审定）。
2. **利息测算（365 天制）**：应计利息 = 本金 × 年利率 × 计息天数 / 365；测算结果联动 L2 应付利息、L8 财务费用。
3. **L1-1 是结论枢纽**：审定期末合计回写试算表 2001，并驱动附注披露（上市/国企）。
4. **完整性双向核对**：征信报告（人行/百行）披露的借款清单与 L1-2 明细双向差集，防账外借款。

### 建议编制顺序

```
L1A 程序计划
  → L1-2 明细（按借款银行/合同逐笔）+ L1-5 利息测算
  → L1-4 征信核对 + L1-7 逾期检查（完整性）
  → L1-6 合同检查 + L1-8 抵质押检查
  → 差异汇入 L1-3 → 确认回写 L1-1
  → L1-1 勾稽 TB(2001) → 附注上市/国企
```

## 2. 分表编制说明

### L1A 实质性程序表
- **审计目标**：规划并记录短期借款实质性程序范围、性质与时间。
- **完成标志**：计划程序均有执行记录或「不适用」说明。

### L1-1 审定表（负债类贷方，双期）
- **审计目标**：核实短期借款期末余额准确完整；按借款种类提供审定数。
- **编制逻辑**：期末 = 期初 + 贷方 − 借方；审定 = 未审 + 账项调整 + 重分类；期初/期末双期分列。
- **上游**：L1-2 明细（按种类 SUMIF 带入）；L1-3 确认回写。**下游**：TB(2001)、附注上市/国企。
- **完成标志**：与 TB 勾稽差异已解释；审计说明与结论已填。

### L1-2 明细表
- **审计目标**：核实各笔借款存在、完整、准确（按借款银行/合同列示）。
- **完成标志**：清单完整、合计与 L1-1 一致；审计说明与结论已填。

### L1-3 调整分录汇总
- **审计目标**：核实调整完整、借贷平衡。
- **完成标志**：借贷平衡；已确认回写 L1-1；发布 A13 错报（如适用）。

### L1-4 征信报告核对表
- **审计目标**：核实征信报告披露的借款与账面借款一致，识别账外借款（完整性认定）。
- **完成标志**：差异逐笔说明；审计说明与结论已填。

### L1-5 利息测算表（核心，联动 L2/L8）
- **审计目标**：核实应计短期借款利息计提恰当。
- **编制逻辑**：利息 = 本金 × 年利率 × 天数 / 365；结果联动 L2 应付利息、L8 财务费用。
- **完成标志**：测算与账面利息差异已解释；审计说明与结论已填。

### L1-6 贷款合同检查
- **审计目标**：核实合同要素（利率、期限、担保、用途）与账面一致。
- **完成标志**：合同要素核对完整；审计说明与结论已填。

### L1-7 逾期贷款检查表
- **审计目标**：识别逾期借款、评价风险等级、关注展期。
- **完成标志**：逾期天数计算有据；风险等级判断正确；审计说明与结论已填。

### L1-8 抵质押资产检查表
- **审计目标**：核实抵押/质押担保存在完整，披露充分。
- **编制逻辑**：担保比例 = 担保借款 / 抵质押资产账面价值 × 100%。
- **完成标志**：担保清单完整；审计说明与结论已填。

### L1-9 短期借款检查表
- **审计目标**：综合核对清单，形成整体审计结论。
- **完成标志**：各核对项完成；审计结论已填。

### 附注披露（上市/国企）
- **审计目标**：按附注格式披露短期借款分类（信用/抵押/保证/质押）及逾期情况，与审定勾稽。
- **完成标志**：分类金额与 L1-1 审定一致；已同步附注模块。

### 底稿目录
- **审计目标**：导航与编制进度总览（跨表结论口径 + 底稿架构 + 本循环其他科目）。

## 3. 认定覆盖速查

| 认定 | 主要底稿 |
|------|----------|
| 存在 | L1-2、L1-6 |
| 完整性 | L1-4、L1-7 |
| 权利与义务 | L1-8（担保）、L1-6（合同） |
| 计价与分摊 | L1-1、L1-5（利息） |
| 列报与披露 | 附注上市/国企 |

---

## 4. 外部模块衔接

| 模块 | 与 L1 关系 |
|------|------------|
| **L2 应付利息** | L1-5 利息测算结果联动应付利息计提 |
| **L8 财务费用** | L1-5 利息费用化部分联动财务费用 |
| **L3 长期借款** | 一年内到期长期借款重分类与短期借款区分 |
| **试算平衡表** | L1-1 审定期末合计回写 2001 |
| **调整分录 / A13** | 与 L1-3 双向同步 |
| **附注模块** | 短期借款分类披露（信用/抵押/保证/质押）+ 逾期 |

---

## 5. 质量复核要点（摘要）

1. L1-2 明细合计 ↔ L1-1 审定是否勾稽？
2. L1-1 审定期末 ↔ TB(2001) 是否勾稽？
3. L1-5 利息测算 ↔ 账面利息 / L2 应付利息 是否核对一致？
4. L1-4 征信核对是否覆盖全部借款（无账外借款）？
5. L1-7 逾期借款风险等级与展期披露是否充分？
6. 附注分类金额是否等于 L1-1 审定？
