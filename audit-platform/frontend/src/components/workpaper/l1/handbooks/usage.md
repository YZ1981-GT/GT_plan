# L1 短期借款 — 平台使用手册

> 配合「编制手册」页签使用。本手册只说明**平台怎么操作**；审计目标与勾稽逻辑见编制手册。
> **不修改**各分表页内已有说明文案。入口：底稿目录页顶部「使用手册」按钮。

---

## 1. 打开与模式

1. 在项目底稿树打开 **L1 短期借款**（`componentType: l1-short-term-loans`，覆盖科目 2001）。
2. 通过 sheet 页签切换分表（L1A、L1-1～L1-9、附注上市/国企、底稿目录）。
3. 程序表（L1A）支持 **结构化 HTML ↔ OnlyOffice** 双模式；以项目配置为准（目录页不显示双模式）。
4. 只读阶段工具栏「取数 / 回写 / 确认」类按钮会禁用。

---

## 2. 推荐操作路径（点击顺序）

| 步骤 | 分表 | 建议操作 |
|------|------|----------|
| 1 | L1A | 勾选实质性程序、填索引 |
| 2 | L1-2 | 按借款银行/合同逐笔录入明细 |
| 3 | L1-5 | 利息测算：本金×利率×天数/365，联动 L2/L8 |
| 4 | L1-4 | 征信报告核对：与账面借款双向差集 |
| 5 | L1-7 | 逾期检查：逾期天数、风险等级、展期 |
| 6 | L1-6 / L1-8 | 合同要素检查 / 抵质押担保检查 |
| 7 | L1-3 | 调整分录汇总 → 确认 → 回写 L1-1 |
| 8 | L1-1 | 确认审定期末（从 L1-2 带入）→ 回写 TB(2001) |
| 9 | 附注上市/国企 | 从审定表按分类取数 → 编辑 → 同步附注模块 |

## 3. 目录页速查

| 区块 | 说明 |
|------|------|
| 编制进度 | 各分表按审计说明/结论填写情况计算完成度 |
| 跨表结论口径 | 每张核心表审计结论「已填/未填」标签，点击跳转对应 sheet 补全 |
| 底稿架构 | 4 阶段泳道（审计计划/科目审定/实质性程序/披露与调整），点击卡片跳转 |
| 本循环底稿目录 | 同循环其他科目（L1~L8），点击跳转（灰色表示尚未生成） |

---

## 4. 常见问题

| 现象 | 处理 |
|------|------|
| L1-1 审定 ≠ TB 数 | 检查明细是否全部带入、调整是否已确认回写；TB 取 2001 期末余额 |
| 利息测算与账面不符 | 复核本金、年利率、计息天数；确认与 L2 应付利息 / L8 财务费用口径一致 |
| 征信核对差异 | 逐笔说明征信报告与账面差异，重点关注账外借款 |
| 附注分类金额不符 | 附注分类（信用/抵押/保证/质押）金额应等于 L1-1 各分类审定数 |
| 附注同步失败 | 检查项目 ID、附注模块权限与准则类型（上市/国企） |

## 5. 复核入口

各分表工具栏/结论区「复核」打开复核对话。合伙人级复核提示词参考：`backend/data/tsj_review_prompts/L/`（若环境已部署）。
