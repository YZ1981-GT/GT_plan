# G10 交易性金融负债 — 平台使用手册

> 本页说明各底稿在平台上的操作方式。审计目标与编制逻辑见「编制手册」页签。

## 1. 目录页（本页）

- **跨表结论口径看板**：汇总核心表「审计说明或结论」是否已填，点击标签跳转补全。
- **底稿架构（4 阶段泳道）**：审计计划 / 科目审定 / 实质性程序 / 披露与调整。
- **本循环底稿目录**：G 循环其他科目，点击跳转。
- **编制/使用手册**：右上角按钮。

## 2. 各底稿操作要点

### G10-1 审定表
点「从 G10-2 带入」填未审数；调整列由 G10-3 回写；点「回写试算平衡表」写入 TB 2101。

### G10-2 明细表
逐笔录入负债类型/初始金额/公允价值/公允价值变动/自身信用风险 OCI 部分；支持导入导出与列设置。

### G10-3 调整分录
录入借贷、实时校验平衡；可「推送至 A13」。

### 附注（上市 / 国企）
点「从明细带入」聚合公允价值/变动损益/信用风险数据；文本区可「🤖 AI 辅助」。

## 3. 常用操作速查

| 操作 | 位置 |
|------|------|
| 回写试算平衡表 | G10-1 审定表工具栏 |
| 从明细带入 | G10-1 / 附注 工具栏 |
| 导入 / 导出 | 各表「导入导出 ▾」 |
| 推送错报至 A13 | G10-3 调整分录 |
| AI 辅助说明 | 各审计说明/结论区右侧 |
| 复核对话 | 各区块标题右侧 💬 |

## 4. 联动关系速查

| 联动 | 说明 |
|------|------|
| G10-2 → G10-1 | 明细合计带入审定表 |
| G10-3 → G10-1 | 调整分录回写调整列 |
| G10-1 → TB | 审定合计回写 2101 |
| G10 → G13 | 公允价值变动(非信用风险)计入公允价值变动损益 |
| 信用风险 → OCI | 指定 FVTPL 负债自身信用风险变动计入 OCI |
| G10 → G12 | 作为套期工具纳入套期会计 |
