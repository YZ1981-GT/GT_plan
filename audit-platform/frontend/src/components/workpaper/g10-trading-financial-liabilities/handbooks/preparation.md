# G10 交易性金融负债 — 底稿编制手册

> **适用范围**：科目 2101 交易性金融负债（以公允价值计量且其变动计入当期损益的金融负债，FVTPL 金融负债，含衍生金融负债、指定为 FVTPL 的金融负债）。
> **组件**：GtBIndex 通用目录（G10 科目）
> **说明**：本手册说明各分表的审计目标、编制逻辑与勾稽关联，不替代各表页内已有说明文案。平台按钮与操作步骤见「使用手册」页签。

---

## 1. 总体编制思路

交易性金融负债是 CAS 22 下以公允价值计量且其变动计入当期损益的金融负债，包括：**①为交易目的承担的负债（如卖空）②衍生金融负债 ③初始确认时指定为 FVTPL 的金融负债**。核算要点：**账面按公允价值计量，公允价值变动一般计入当期损益（公允价值变动损益，进 G13）；但对于「指定为 FVTPL 的金融负债」，由企业自身信用风险变化引起的公允价值变动应计入其他综合收益（OCI），其余部分计入当期损益（除非计入 OCI 会造成或扩大损益错配）**。审计核心是分类、公允价值计量、公允价值变动损益归属，以及自身信用风险变动的 OCI 拆分是否正确。

| 证据链 | 主要底稿 | 回答的问题 |
|--------|----------|------------|
| 分类是否成立 | G10-2 明细、指定文件 | 是否为交易性/衍生/指定 FVTPL 负债 |
| 账面是否真实 | G10-2 明细、公允价值来源 | 公允价值、公允价值变动是否准确 |
| 损益/OCI 拆分 | 公允价值变动核对、信用风险测算 | 变动计入 G13、自身信用风险部分计入 OCI |
| 审定是否正确 | G10-1 审定表 | 未审→调整→审定，与 TB 2101 及明细勾稽 |
| 披露是否完整 | 附注（上市/国企） | 公允价值层次、变动损益、信用风险 OCI 披露 |

### 建议编制顺序

```
G10-2 明细(公允价值/变动) → 公允价值变动损益核对 → 自身信用风险 OCI 拆分(指定 FVTPL 负债) → G10-3 调整 → 回写 G10-1 审定 → 勾稽 TB(2101) → 附注(上市/国企)
```

## 2. 分表编制说明

### G10-1 审定表
汇总交易性金融负债未审数、账项/重分类调整、审定数，回写 TB 2101，与 G10-2 明细合计勾稽。

### G10-2 明细表
逐笔列示负债类型（交易/衍生/指定 FVTPL）、初始金额、期末公允价值、本期公允价值变动、其中计入 OCI 的自身信用风险变动部分。

### G10-3 调整分录
录入 AJE/RJE 回写 G10-1 审定表调整列，可推送 A13。

### 附注（上市 / 国企）
按公允价值层次（Level 1/2/3）、本期公允价值变动损益、指定为 FVTPL 金融负债的自身信用风险 OCI 变动、衍生金融负债披露；数据取自 G10-2 明细。

## 3. 认定覆盖速查

| 认定 | 主要底稿 |
|------|----------|
| 存在 | G10-2 明细、合约/协议 |
| 完整性 | G10-1 审定、TB 勾稽、衍生工具完整性 |
| 权利和义务 | 合约条款、指定文件 |
| 计价和分摊 | 公允价值计量、损益/OCI 拆分 |
| 列报和披露 | 附注（上市/国企） |

## 4. 外部模块衔接

| 模块 | 关系 |
|------|------|
| TB 试算平衡表 | G10-1 审定合计回写 2101 |
| G13 公允价值变动损益 | 本科目公允价值变动（非信用风险部分）计入 G13 |
| G12 净敞口套期损益 | 作为套期工具时纳入套期会计核算 |
| 权益/OCI | 指定 FVTPL 负债的自身信用风险变动计入 OCI |
| A13 未更正错报 | G10-3 调整分录推送 |
| 附注模块 | 披露表数据同步 |

## 5. 质量复核要点（摘要）

1. 分类是否成立（交易目的/衍生/指定 FVTPL），衍生金融负债是否完整识别。
2. 公允价值计量输入值与层次是否恰当，Level 3 是否有估值依据。
3. **自身信用风险变动是否正确拆分计入 OCI**（仅指定 FVTPL 负债），其余计入损益。
4. 公允价值变动损益是否正确计入 G13。
5. G10-1 审定合计 = G10-2 明细合计 = TB 2101。
