# H3 投资性房地产 — 平台使用手册

> 本页说明各底稿在平台上的操作方式。审计目标与编制逻辑见「编制手册」页签。

## 1. 目录页（本页）

- 跨表结论口径看板：汇总核心表"审计说明或结论"是否已填，点击标签跳转对应分表。
- 底稿架构（4 阶段泳道）：审计计划 / 科目审定 / 实质性程序 / 披露与调整。
- 本循环底稿目录：H 循环其他科目，点击跳转。
- 编制/使用手册：右上角按钮。

## 2. 各底稿操作要点

- **H3-2 明细表**：录入或从序时账带入逐项房地产明细，选择计量模式（成本/公允价值），是折旧/公允/减值分表的行来源。
- **H3-5 增加 / H3-3 调整**：录入本期新增与调整分录；用途转换在调整表中体现转入转出。
- **H3-7 折旧摊销**（成本模式）：录入折旧年限/残值，系统测算应计提额并与账面比对，差异标红。
- **H3-8 公允价值**（公允价值模式）：录入期末公允价值与来源，系统算出变动额并提示计入当期损益。
- **H3-10 减值**（成本模式）：录入减值迹象与可收回金额，测算应计提减值。
- **H3-12 产权证**：录入产权证信息与受限情形，勾选抵押/查封。
- **H3-1 审定表**：从明细带入未审数，录入 AJE/RJE 得审定数，点保存回写试算表。
- **附注**：从审定表带入，公允价值模式补充公允价值层次与估值技术。

## 3. 常用操作速查

| 操作 | 位置 |
|------|------|
| 从明细带入审定表 | H3-1 审定表「从明细带入」按钮 |
| 折旧测算 | H3-7 折旧摊销「测算」按钮（成本模式） |
| 公允价值变动 | H3-8 公允价值录入期末公允价值自动算差额 |
| 减值测算 | H3-10 减值「可收回金额测算」 |
| 回写试算表 | H3-1 审定表保存时回写 1503/1504 |
| AI 辅助说明/结论 | 各表审计说明区「AI 辅助」按钮 |
| 复核对话 | 各表结论区复核圆点/复核按钮 |
| 版本历史 | 顶部工具栏版本按钮 |

## 4. 联动关系速查

| 联动 | 说明 |
|------|------|
| 明细 → 审定 | H3-2 明细按计量模式聚合到 H3-1 审定表 |
| 调整 → 审定 | H3-3 调整分录回写 H3-1 审定 AJE/RJE |
| 审定 → 附注 | H3-1 审定数带入附注分类披露 |
| 审定 → 试算表 | 审定合计回写 1503/1504 及减值科目 |
| 公允变动 → 损益 | 公允价值模式变动额计入当期损益 |
| 租金 → D4 | 租金收入与其他业务收入勾稽 |
| 受限 → 借款/或有 | 抵押受限房地产与借款质押、或有事项核对 |
| 调整 → A13 | 未更正错报推送错报汇总 |
