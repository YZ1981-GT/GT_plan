# H3 投资性房地产 — 底稿编制手册

> **适用范围**：为赚取租金、资本增值或两者兼有而持有的房地产。科目 1503 投资性房地产（原值）、1504 投资性房地产累计折旧/摊销、及相应减值准备。
> **组件**：GtBIndex 通用目录（H3 科目）
> **说明**：本手册说明各分表的审计目标、编制逻辑与勾稽关联，不替代各表页内已有说明文案。平台按钮与操作步骤见「使用手册」页签。

---

## 1. 总体编制思路

投资性房地产依《企业会计准则第 3 号——投资性房地产》(CAS3) 核算，**成本模式与公允价值模式二选一**，且一经确定不得随意变更：

- **成本模式**：按固定资产/无形资产口径**计提折旧或摊销**并做减值测试，期末账面价值 = 原值(1503) − 累计折旧摊销(1504) − 减值准备。
- **公允价值模式**：**不计提折旧摊销、不计提减值**，以资产负债表日公允价值计量，公允价值变动计入当期损益（公允价值变动损益）；采用该模式须有确凿证据表明公允价值能够持续可靠取得。
- **用途转换**：自用房地产/存货转为投资性房地产、或投资性房地产转为自用，须按 CAS3 规定确认转换日账面价值与差额处理。
- **租金收入联动**：投资性房地产产生的租金收入应与 D4 营业收入（其他业务收入）勾稽一致。
- **公允价值层次披露**：公允价值模式下按《企业会计准则第 39 号——公允价值计量》(CAS39) 披露公允价值层次（第一/二/三层次）、估值技术与关键不可观察输入值。

| 证据链 | 主要底稿 | 回答的问题 |
|--------|----------|------------|
| 计量模式与政策 | H3-1 审定表 / 附注 | 采用成本还是公允价值模式？政策是否一贯？ |
| 期末存量真实完整 | H3-2 明细表 | 每项房地产原值/折旧/减值是否真实、归属被审计单位？ |
| 本期增减变动 | H3-5 增加 / H3-3 调整 | 新增、转入、处置、用途转换是否恰当入账？ |
| 成本模式计价 | H3-7 折旧摊销 / H3-10 减值 | 折旧摊销是否足额、迹象下减值是否充分？ |
| 公允价值模式计价 | H3-8 公允价值 | 期末公允价值是否可靠、变动是否计入当期损益？ |
| 权利归属 | H3-12 产权证 | 产权证是否齐全、是否存在抵押/受限？ |
| 列报披露 | 附注（上市/国企） | 分类、变动、公允价值层次是否充分披露？ |

### 建议编制顺序

```
H3程序表 → H3-2明细(立清单) → H3-5增加/H3-3调整(本期变动)
  → 成本模式: H3-7折旧摊销 + H3-10减值
  → 公允价值模式: H3-8公允价值(变动计当期损益)
  → H3-12产权证核查(权利归属/受限)
  → 回写 H3-1审定表(勾稽TB 1503/1504)
  → 租金收入勾稽 D4 → 附注(上市/国企,公允价值层次)
```

## 2. 分表编制说明

### H3-1 审定表
按成本/公允价值两类分别列示原值、累计折旧摊销、减值、账面价值，未审数 + 账项调整(AJE) + 重分类调整(RJE) = 审定数；审定合计回写并勾稽试算表 1503/1504 及减值科目。

### H3-2 明细表
逐项房地产明细：坐落、用途、计量模式、取得日、原值、累计折旧摊销、减值准备、账面价值；是明细→审定表 SUMIF 聚合的取数源，也是折旧/公允/减值分表的行来源。

### H3-3 调整
本期账项调整与重分类调整分录（含用途转换的转入转出），借贷平衡后回写审定表并向 A13 推送错报。

### H3-5 增加
本期新增投资性房地产（购入、自建转入、用途转换转入）明细，核对入账价值与凭证、合同、产权证。

### H3-7 折旧摊销
**仅成本模式适用**。按房屋建筑物直线法计提折旧、土地使用权按年限摊销；测算本期应计提额并与账面计提额比对，差异说明；折旧起算与年限、残值合理性复核。

### H3-8 公允价值
**仅公允价值模式适用**。期末公允价值来源（评估报告/活跃市场价/收益法）、公允价值变动额 = 期末公允价值 − 期初账面，变动计入公允价值变动损益；关注估值假设与关键输入合理性，为附注公允价值层次披露提供数据。

### H3-10 减值
**仅成本模式适用**。CAS8 减值迹象识别 → 可收回金额(公允价值减处置费用 与 未来现金流量现值 孰高)测算 → 应计提减值，与账面减值比对。

### H3-12 产权证
产权证书号、权属人、面积与账面核对；是否存在抵押、查封等权利受限情形（联动借款质押披露与或有事项）。

### 附注（上市/国企）
按计量模式分类列示期末余额与本期变动；公允价值模式下披露公允价值层次(CAS39)、估值技术、关键不可观察输入值及敏感性。

## 3. 认定覆盖速查

| 认定 | 主要底稿 |
|------|----------|
| 存在 | H3-2 明细 / H3-12 产权证 |
| 完整性 | H3-2 明细 / H3-5 增加 / H3-3 调整 |
| 权利和义务 | H3-12 产权证（权属/受限） |
| 计价和分摊 | H3-7 折旧摊销 / H3-8 公允价值 / H3-10 减值 |
| 列报和披露 | 附注（上市/国企，含公允价值层次） |

## 4. 外部模块衔接

| 模块 | 关系 |
|------|------|
| D4 营业收入 | 投资性房地产租金收入应与其他业务收入勾稽一致 |
| 借款/或有事项 | 抵押、受限房地产须与借款质押披露及或有事项核对 |
| 公允价值变动损益 | 公允价值模式下变动额计入当期损益，勾稽利润表 |
| A13 错报汇总 | H3-3 调整分录未更正部分推送错报汇总 |
| 试算表 | H3-1 审定合计回写 1503/1504 及减值科目 |

## 5. 质量复核要点（摘要）

- 计量模式选择是否有依据、是否一贯，公允价值模式是否满足「持续可靠取得」条件。
- 成本模式下折旧摊销是否足额、减值迹象是否充分识别与测算。
- 公允价值模式下评估报告是否适当、变动是否正确计入当期损益（而非其他综合收益）。
- 用途转换的转换日账面价值与差额处理是否符合 CAS3。
- 租金收入与 D4 勾稽、受限房地产与借款/或有事项披露是否一致。
- 附注公允价值层次披露是否完整（层次划分、估值技术、关键输入、敏感性）。
