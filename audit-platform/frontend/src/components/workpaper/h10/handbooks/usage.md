# H10 资产处置收益 — 平台使用手册

> 本页说明各底稿在平台上的操作方式。审计目标与编制逻辑见「编制手册」页签。

## 1. 目录页（本页）

- 跨表结论口径看板：汇总核心表"审计说明或结论"是否已填，点击标签跳转对应分表。
- 底稿架构（4 阶段泳道）：审计计划 / 科目审定 / 实质性程序 / 披露与调整。
- 本循环底稿目录：H 循环其他科目，点击跳转。
- 编制/使用手册：右上角按钮。

## 2. 各底稿操作要点

- **H10-1 明细表**：逐笔录入非流动资产处置，填账面价值/处置价款/税费，系统算处置净损益；选择来源类别并勾稽 H1/I1/H8/H6；上市版录入试运行收入成本。
- **调整**：录入误计入营业外收支的重分类、试运行净额处理等调整分录。
- **H10 审定表**：从明细带入未审数，录入 AJE/RJE 得审定数，保存回写试算表 6115。
- **附注（上市/国企）**：从审定表带入构成，上市版补试运行明细与非经常性损益划分。

## 3. 常用操作速查

| 操作 | 位置 |
|------|------|
| 从明细带入审定表 | H10 审定表「从明细带入」按钮 |
| 净损益计算 | H10-1 明细录入后自动算净损益 |
| 勾稽 H6 清理 | H10-1 明细「勾稽 H6」提示 |
| 回写试算表 | H10 审定表保存时回写 6115 |
| AI 辅助说明/结论 | 各表审计说明区「AI 辅助」按钮 |
| 复核对话 | 各表结论区复核圆点/复核按钮 |
| 版本历史 | 顶部工具栏版本按钮 |

## 4. 联动关系速查

| 联动 | 说明 |
|------|------|
| H6 → H10 | 固定资产清理净损益与本科目勾稽 |
| H1/I1/H8 → H10 | 固定资产/无形资产/使用权资产处置损益来源 |
| H10 vs 营业外 | 归类区分，非资产处置项不入本科目 |
| 明细 → 审定 | H10-1 明细按类别聚合到审定表 |
| 调整 → 审定 | 调整分录回写审定 AJE/RJE |
| 审定 → 附注 | 审定数带入附注构成披露 |
| 审定 → 试算表 | 审定合计回写 6115（发生额） |
| 调整 → A13 | 未更正错报推送错报汇总 |
