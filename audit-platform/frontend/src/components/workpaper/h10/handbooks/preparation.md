# H10 资产处置收益 — 底稿编制手册

> **适用范围**：处置非流动资产（划分为持有待售的除外）产生的处置利得或损失。科目 6115 资产处置损益（损益类）。
> **组件**：GtBIndex 通用目录（H10 科目）
> **说明**：本手册说明各分表的审计目标、编制逻辑与勾稽关联，不替代各表页内已有说明文案。平台按钮与操作步骤见「使用手册」页签。

---

## 1. 总体编制思路

资产处置收益是损益类科目，归集**非流动资产处置**的净损益，损益类取**发生额**（贷方发生额 − 借方发生额）：

- **处置范围**：固定资产（H1）、无形资产（I1）、使用权资产（H8）、在建工程等非流动资产的出售、转让、报废毁损的处置损益（划分为持有待售的资产处置计入其他科目）。
- **与营业外收支的区别**：处置**非流动资产**的利得损失计入资产处置收益；而与日常经营无关、非资产处置的利得损失（如无法支付的应付款、政府罚没）计入营业外收支——须正确区分归类。
- **与 H6 固定资产清理勾稽**：经固定资产清理（H6）结转的净损益应与本科目相应部分勾稽一致。
- **试运行收入成本（上市版）**：上市公司在建工程达到预定可使用状态前试运行产生的产品对外销售，其收入与成本按规定处理，相关净额在本科目或相应科目列示（上市版专项披露）。

| 证据链 | 主要底稿 | 回答的问题 |
|--------|----------|------------|
| 处置损益真实完整 | H10-1 明细表 | 每笔资产处置损益是否真实、计算准确？ |
| 处置来源勾稽 | H10-1 明细 | 是否与 H1/I1/H8/H6 处置勾稽？ |
| 归类正确 | H10-1 明细 / 调整 | 是否应计入资产处置收益而非营业外收支？ |
| 试运行（上市）| 附注（上市）| 试运行收入成本处理与披露是否恰当？ |
| 审定与列报 | H10 审定表 / 附注 | 审定发生额是否勾稽 TB 6115、披露是否恰当？ |

### 建议编制顺序

```
H10程序表 → H10-1明细(逐笔非流动资产处置损益)
  → 勾稽来源(H1固定资产/I1无形/H8使用权/H6清理)
  → 归类核查(资产处置收益 vs 营业外收支)
  → 试运行收入成本(上市版) → 调整 → 回写审定表(勾稽TB 6115发生额) → 附注(上市/国企)
```

## 2. 分表编制说明

### H10 审定表
按处置资产类别（固定资产/无形资产/使用权资产等）列示处置损益发生额；损益类取发生额（贷 − 借）；未审数 + 账项调整(AJE) + 重分类调整(RJE) = 审定数；审定合计回写并勾稽试算表 6115。

### H10-1 明细表
逐笔处置明细：处置资产名称、类别、处置日、账面价值、处置价款、相关税费、处置净损益、来源底稿；核对处置合同、收款凭证、审批；与 H1/I1/H8/H6 相应处置勾稽；含试运行收入成本行（上市版）。

### 调整
账项与重分类调整分录（如误计入营业外收支的重分类、试运行净额处理），借贷平衡后回写审定表并向 A13 推送错报。

### 附注（上市/国企）
按处置资产类别列示资产处置收益构成；上市版专项披露试运行收入与成本明细及其净额处理；区分经常性与非经常性损益（上市版非经常性损益勾稽）。

## 5. 质量复核要点（摘要）

- 处置净损益计算是否准确（账面价值、处置价款、相关税费）。
- 归类是否正确：非流动资产处置计入资产处置收益，非资产处置项计入营业外收支。
- 是否与 H1/I1/H8/H6 相应处置勾稽一致，来源可追溯。
- 上市版试运行收入成本处理与披露是否符合规定，净额列示是否恰当。
- 上市版非经常性损益划分是否正确。
- 关联方处置价格是否公允，是否存在利润操纵。
