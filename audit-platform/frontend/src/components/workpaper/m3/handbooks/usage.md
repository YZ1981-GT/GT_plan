# M3 库存股 — 平台使用手册

> 配合「编制手册」页签使用。本手册只说明**平台怎么操作**；审计目标与勾稽逻辑见编制手册。
> **不修改**各分表页内已有说明文案。入口：底稿目录页顶部「使用手册」按钮。

---

## 1. 打开与模式

1. 在项目底稿树打开 **M3 库存股**（`componentType: m3-treasury-stock`，覆盖科目 4002）。
2. 通过 sheet 页签切换分表（M3A、M3-1～M3-5、附注上市、底稿目录）。
3. 复杂 sheet 支持 **结构化 HTML ↔ OnlyOffice** 双模式；以项目配置为准（目录页不显示双模式）。
4. 只读阶段工具栏「取数 / 回写 / 确认」类按钮会禁用。

---

## 2. 推荐操作路径（点击顺序）

| 步骤 | 分表 | 建议操作 |
|------|------|----------|
| 1 | M3A | 勾选实质性程序、填索引 |
| 2 | M3-2 | 按回购批次录入成本、数量 |
| 3 | M3-4 | 外币回购按汇率折算 |
| 4 | M3-5 | 回购决议、注销冲减核对 |
| 5 | M3-1 | 确认审定（未审 + AJE + RJE）→ 回写 TB(4002) |
| 6 | 附注上市 | 从审定表取数 → 同步附注模块 |

## 3. 目录页速查

| 区块 | 说明 |
|------|------|
| 编制进度 | 各分表按审计说明/结论填写情况计算完成度 |
| 跨表结论口径 | 每张表审计结论「已填/未填」标签，点击跳转对应 sheet 补全 |

## 4. 常见问题

| 现象 | 处理 |
|------|------|
| M3-1 审定 ≠ TB 数 | 库存股为权益备抵**借方**（期末=期初+借−贷，方向与其他 M 权益类相反）；检查 M3-2 明细 |
| 明细合计与审定不符 | 复核 M3-2 各回购批次成本/数量是否齐全 |
| 注销处理不清 | 核对 M3-5 注销时冲减 M2 实收资本、M4 资本公积的分录 |
| 外币折算异常 | 检查 M3-4 外币回购折算汇率 |
| 无国企附注 | 库存股主要为上市公司业务，仅提供上市公司附注 |
