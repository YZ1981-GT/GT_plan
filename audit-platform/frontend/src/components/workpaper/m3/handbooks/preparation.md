# M3 库存股 — 底稿编制手册

> **适用范围**：科目 **4002 库存股（借方/权益备抵类，期末=期初+借方−贷方）**
> **组件**：`m3-treasury-stock`
> **说明**：本手册说明各分表的审计目标、编制逻辑与勾稽关联，不替代各表页内已有说明文案。
> 平台按钮与操作步骤见「使用手册」页签。

---

## 1. 总体编制思路

库存股是**权益备抵类科目（借方！与其他 M 权益类方向相反）**：回购股份时借方增加库存股，注销/再售时贷方减少。

| 证据链 | 主要底稿 | 回答的问题 |
|--------|----------|------------|
| **余额审定** | M3-1 审定 ← M3-2 明细 | 库存股期末余额是否准确完整？ |
| **回购批次** | M3-2 明细 | 各批次回购成本、数量是否准确？ |
| **外币折算** | M3-4 外币投资汇率测算 | 外币回购折算是否正确？ |
| **回购/注销核对** | M3-5 检查表 | 回购决议、注销冲减处理是否合规？ |

**枢纽原则**：

1. **权益备抵借方科目**：期末 = 期初 + 借方（回购）− 贷方（注销/再售），**方向与其他 M 权益类相反**。
2. **按回购批次列示**：明细表 M3-2 按回购批次分列成本与数量。
3. **外币折算**：M3-4 外币回购按汇率折算本位币。
4. **注销冲减**：M3-5 核对注销时冲减实收资本（M2）与资本公积（M4）的处理。
5. **M3-1 是结论枢纽**：审定合计回写试算表 4002，并驱动附注披露（仅上市公司）。

### 建议编制顺序

```
M3A 程序计划
  → M3-2 明细（按回购批次列示成本/数量）
  → M3-4 外币投资汇率测算（外币回购折算）
  → M3-5 检查表（回购决议/注销冲减核对）
  → M3-1 审定（未审 + AJE + RJE → 审定）→ 回写 TB(4002) → 附注上市
  → M3-3 调整分录（借贷平衡，回写审定）
```

## 2. 分表编制说明

### M3A 实质性程序表
- **审计目标**：规划并记录库存股实质性程序范围、性质与时间。
- **完成标志**：计划程序均有执行记录或「不适用」说明。

### M3-1 审定表（权益备抵借方）
- **审计目标**：核实库存股期末余额准确完整；提供审定数。
- **编制逻辑**：审定 = 未审 + AJE + RJE；期末 = 期初 + 借方（回购）− 贷方（注销/再售）。
- **上游**：M3-2 明细；M3-3 确认回写。**下游**：TB(4002)、附注上市。
- **完成标志**：与 M3-2 明细合计勾稽；审计结论已填。

### M3-2 明细表（按回购批次）
- **审计目标**：核实各回购批次成本、数量准确完整。
- **完成标志**：明细合计与 M3-1 一致；审计说明已填。

### M3-3 调整分录汇总
- **审计目标**：核实调整完整、借贷平衡。
- **完成标志**：借贷平衡；已确认回写 M3-1。

### M3-4 外币投资汇率测算表
- **审计目标**：核实外币回购折算准确。
- **完成标志**：折算差异已列示并解释；结论已填。

### M3-5 库存股检查表
- **审计目标**：核对回购决议、注销/再售冲减处理合规（冲减 M2 实收资本、M4 资本公积）。
- **完成标志**：回购/注销凭证核对完整；结论已填。

### 附注披露（上市公司）
- **审计目标**：按附注格式披露库存股，与审定勾稽（库存股主要为上市公司业务，无国企版）。
- **完成标志**：金额与 M3-1 审定一致；已同步附注模块。

### 底稿目录
- **审计目标**：导航与编制进度总览（跨表结论口径 + 底稿架构 + 本循环其他科目）。

|------|------------|
| **M2 实收资本** | 注销库存股冲减实收资本 |
| **M4 资本公积** | 注销库存股差额冲减/计入资本公积 |
| **试算平衡表** | M3-1 审定余额回写 4002（借方） |

---

## 5. 质量复核要点（摘要）

1. M3-2 明细合计 ↔ M3-1 审定是否勾稽？
2. 库存股方向是否正确（借方增加，贷方减少）？
3. M3-1 审定 ↔ TB(4002) 是否勾稽？
4. 注销冲减是否正确处理 M2 实收资本、M4 资本公积？
5. 附注披露金额是否等于 M3-1 审定？
