# F4 应付账款 — 底稿编制手册

> **适用范围**：科目 **2202 应付账款**
> **组件**：`f4-accounts-payable`（贷方科目：期末 = 期初审定 + 贷方 − 借方）
> **说明**：本手册说明各分表的审计目标、编制逻辑与勾稽关联。
> **不替代**各表页内已有的审计目标/过程提示文案（页内说明保持不变）。
> 平台按钮与操作步骤见「使用手册」页签。

## 1. 总体编制思路

F4 把「应付账款」拆成三条证据链，核心为**完整性**（有无未入账应付），最后汇入审定与附注：

| 证据链 | 主要底稿 | 回答的问题 |
|--------|----------|------------|
| **金额枢纽** | F4-2 → F4-1 ← F4-3 | 未审→调整→审定是否完整准确？ |
| **完整/权利** | F4-7 未入账检查；F4-8 凭证检查；F4-6 关联方；F4-9 供应链融资 | 应付是否完整入账、权属清晰、供应链融资是否重分类？ |
| **计价/披露** | F4-4 实质性分析；F4-5 长期挂账；附注 | 长期挂账是否需转营业外收入？账龄披露是否完整？ |

**枢纽原则（负债完整性重点）**：

1. **F4-2 明细表是数据枢纽**——审定表按供应商从明细带入；负债审计核心在**完整性**。
2. **F4-7 未入账检查是完整性关键**——期后付款/未达发票搜索，识别漏记应付。
3. **F4-3 是调整枢纽**——差异确认后回写 F4-1，可推送 A13 错报汇总。
4. **F4-1 是结论枢纽**——与试算（2202）勾稽，向报表与附注提供审定数。
5. **F4A 程序表**统领「做了哪些程序」。

### 建议编制顺序（标准路径）

```
F4A 程序计划
  → F4-2 明细表（先立清单，按供应商 + 账龄）
  → 完整性链：F4-7 未入账检查（期后付款/未达发票搜索）→ F4-8 凭证检查
  → F4-6 关联方应付识别
  → F4-9 供应链融资（是否应重分类为借款）
  → 分析/账龄链：F4-4 实质性分析 → F4-5 长期挂账（是否转营业外收入）
  → 差异汇入 F4-3 → 确认回写 F4-1
  → F4-1 从明细带入 → 勾稽 TB(2202)
  → 附注上市 / 附注国企
```

按项目风险裁剪（无供应链融资可弱化 F4-9），但 **明细 → F4-1** 与 **未入账检查（完整性）** 不宜省略。

## 2. 分表编制说明

每张表按统一结构：**审计目标 → 编制逻辑 → 上游/下游 → 完成标志**。

### F4A 实质性程序表
- **审计目标**：规划并记录针对应付账款的实质性程序范围、性质与时间。
- **完成标志**：计划程序均有执行记录或「不适用」说明；索引可跳转分表。

### F4-1 审定表
- **审计目标**：核实应付账款余额完整准确；列报恰当（是否有借方余额应重分类为预付、1年以上是否披露）；为报表与附注提供审定数。
- **编制逻辑**：期初/期末 × 未审 / 账项调整 / 重分类调整 / 审定；审定 = 未审 + 调整。
- **上游**：F4-2 汇总；F4-3 确认回写。**下游**：试算表（2202）；附注。
- **完成标志**：与 TB 勾稽差异已解释；调整来源可追溯至 F4-3；结论已填。

### F4-2 明细表（数据枢纽）
- **审计目标**：核实完整、权利与义务；按供应商与账龄列示。
- **编制逻辑**：逐户列示供应商、应付金额、形成日期、账龄；期后付款情况佐证真实性与完整性；借方余额单独列示（拟重分类）。
- **下游**：F4-1、F4-4、F4-5、F4-6 带入源。
- **完成标志**：清单完整、与 F4-1 汇总一致。

### F4-3 调整分录
- **审计目标**：核实应付账款及相关科目调整完整、借贷平衡。
- **编制逻辑**：AJE（未入账应付补记）/ RJE（借方余额转预付、长期挂账转营业外收入）分列。
- **下游**：确认回写 F4-1；可推送 A13 未更正错报汇总。
- **完成标志**：借贷平衡；已确认回写 F4-1；索引指向证据表。

### F4-4 实质性分析
- **审计目标**：通过趋势/结构分析识别异常应付（大额异动、周转异常、与采购/存货勾稽）。
- **完成标志**：异常波动原因已分析、有结论。

### F4-5 长期挂账
- **审计目标**：识别账龄较长的应付款，判断是否无需支付应转营业外收入。
- **编制逻辑**：按账龄筛选长期挂账，逐笔说明原因与处置结论。
- **下游**：处置结论联动 F4-3 调整。
- **完成标志**：长期挂账逐笔有处置结论。

### F4-6 关联方
- **审计目标**：识别关联方应付款，核对披露完整性、是否存在资金占用。
- **完成标志**：关联方应付已识别，与 B19 清单核对。

### F4-7 未入账检查（完整性核心）
- **审计目标**：搜索未入账应付（漏记负债），佐证完整性认定。
- **编制逻辑**：期后付款测试、未达发票/验收单搜索，按供应商归集次年序时账 2202 借方（期后付款）。
- **完成标志**：期后付款/未达发票已核对，未入账应付已补记或说明。

### F4-8 凭证检查
- **审计目标**：以凭证级检查佐证应付发生真实、计价准确。
- **编制逻辑**：抽凭引擎科目 2202；记账凭证 + 支持性文件（发票/合同/验收单）。
- **完成标志**：抽查比例达方案要求；异常已跟进。

### F4-9 供应链融资
- **审计目标**：识别供应链金融安排（如反向保理），判断是否应重分类为短期借款。
- **完成标志**：供应链融资安排已识别，重分类判断有据。

### 附注披露（上市/国企）
- **审计目标**：按附注格式披露应付账款账龄、按性质分类、关联方应付、1年以上大额应付等，与审定勾稽。
- **完成标志**：金额与 F4-1 审定一致；账龄与长期应付已披露；已同步附注模块。

### 底稿目录
- **审计目标**：导航与编制进度总览（跨表结论口径 + 底稿架构）。

## 3. 认定覆盖速查

| 认定 | 主要底稿 |
|------|----------|
| 存在 | F4-8、F4-2 |
| 完整性（负债重点） | F4-7 未入账检查、F4-2、F4-6 |
| 权利与义务 | F4-6、F4-9 供应链融资 |
| 准确性/计价 | F4-8、F4-4、F4-1 |
| 列报与披露 | 附注上市/国企、F4-5 重分类 |
| 截止 | F4-7 期后付款 |

## 4. 外部模块衔接

| 模块 | 与 F4 关系 |

## 5. 质量复核要点（摘要）

1. F4-2 合计 ↔ F4-1 未审是否勾稽？
2. F4-7 未入账检查是否执行（完整性核心）？期后付款是否核对？
3. F4-3 已确认调整（含重分类）是否已体现在 F4-1？借贷是否平衡？
4. F4-5 长期挂账是否逐笔有处置结论（无需支付→营业外收入）？
5. F4-9 供应链融资是否需重分类为借款？
6. 附注金额是否等于 F4-1 审定？账龄披露是否完整？
