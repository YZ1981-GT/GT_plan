# F4 应付账款 — 平台使用手册

> 配合「编制手册」页签使用。
> 本手册只说明**平台怎么操作**；审计目标与勾稽逻辑见编制手册。
> **不修改**各分表页内已有说明文案。
> 入口：底稿目录页顶部「使用手册」按钮。

---

## 1. 打开与模式

1. 在项目底稿树打开 **F4 应付账款**（`componentType: f4-accounts-payable`，覆盖科目 2202）。
2. 通过 sheet 页签切换分表（F4A、F4-1～F4-9、附注上市/国企、底稿目录）。
3. 复杂 sheet 支持 **结构化 HTML ↔ OnlyOffice** 双模式；以项目配置为准（目录页除外）。
4. 只读阶段工具栏「取数 / 回写 / 确认」类按钮会禁用。

**需要项目上下文的操作**（缺 `projectId` 会提示无法执行）：

- F4-2/F4-7 期后付款取数、F4-8 抽凭
- 附注「同步到附注模块」

---

## 2. 推荐操作路径（点击顺序）

| 步骤 | 分表 | 建议操作 |
|------|------|----------|
| 1 | F4A | 勾选实质性程序、填索引 |
| 2 | F4-2 | 录入应付明细（供应商/金额/账龄），取期后付款 |
| 3 | F4-7 | 未入账检查（期后付款/未达发票搜索，完整性核心） |
| 4 | F4-8 | 凭证检查（抽凭引擎，科目 2202） |
| 5 | F4-6 | 关联方应付识别（与 B19 核对） |
| 6 | F4-9 | 供应链融资识别（重分类判断） |
| 7 | F4-4 | 实质性分析 |
| 8 | F4-5 | 长期挂账逐笔判断处置结论 |
| 9 | F4-3 | 调整分录（AJE/RJE）→ 确认 → 回写 F4-1 |
| 10 | F4-1 | 「从明细带入」汇总未审 → 核对调整回写 → 勾稽 TB |
| 11 | 附注上市/国企 | 拉取上游 → 编辑 → 同步附注模块 |

## 3. 目录页速查

| 区块 | 说明 |
|------|------|
| 编制进度 | 各分表填妥「审计说明或结论」即计入完成 |
| 跨表结论口径 | 每张表审计结论「已填/未填」标签，点击跳转对应 sheet 补全 |
| 编制提示 | 折叠展开，推荐编制工作流 |
| 底稿架构 | 4 阶段泳道（审计计划/科目审定/实质性程序/披露与调整），点击卡片跳转 |
| 本循环底稿目录 | 同循环（F 循环）其他底稿（灰色表示未生成） |

---

## 4. 导入导出

- 工具栏「导入/导出」按当前 sheet 作用（具备后端端点的 sheet）。
- 导入后刷新当前表；若改了明细（F4-2），请重新对 F4-1 执行「从明细带入」。

---

## 5. 常见问题

| 现象 | 处理 |
|------|------|
| F4-1 审定合计 ≠ TB 数 | 检查明细是否全部带入、调整是否已确认回写 |
| 完整性存疑 | F4-7 执行期后付款/未达发票搜索，补记未入账应付 |
| 长期挂账无结论 | F4-5 逐笔填处置结论（无需支付→转营业外收入 K12） |
| 供应链融资未处理 | F4-9 判断是否重分类为短期借款（L1） |
| 借方余额 | 应重分类为预付账款，经 F4-3 RJE 调整 |
| 附注同步失败 | 检查项目 ID、附注模块权限与准则类型（上市/国企） |

## 6. 复核入口

各分表工具栏/结论区「复核」打开复核对话（按 section-id）。
合伙人级复核提示词参考：`backend/data/tsj_review_prompts/F/`（若环境已部署）。
