# L2 应付利息 — 平台使用手册

> 配合「编制手册」页签使用。本手册只说明**平台怎么操作**；审计目标与勾稽逻辑见编制手册。
> **不修改**各分表页内已有说明文案。入口：底稿目录页顶部「使用手册」按钮。

---

## 1. 打开与模式

1. 在项目底稿树打开 **L2 应付利息**（`componentType: l2-interest-payable`，覆盖科目 2231）。
2. 通过 sheet 页签切换分表（L2A、L2-1～L2-4、附注上市/国企、底稿目录）。
3. 程序表（L2A）支持 **结构化 HTML ↔ OnlyOffice** 双模式；以项目配置为准（目录页不显示双模式）。
4. 只读阶段工具栏「取数 / 回写 / 确认」类按钮会禁用。

---

## 2. 推荐操作路径（点击顺序）

| 步骤 | 分表 | 建议操作 |
|------|------|----------|
| 1 | L2A | 勾选实质性程序、填索引 |
| 2 | L2-2 | 按借款银行/债券/债权人逐笔录入明细 |
| 3 | L2-2 | 核对 L1-5 / L3 利息测算与账面计提差异 |
| 4 | L2-4 | 应付利息检查表：记账凭证核对①~⑤、检查比例 |
| 5 | L2-3 | 调整分录汇总 → 确认 → 回写 L2-1 |
| 6 | L2-1 | 确认审定期末（从 L2-2 带入）→ 回写 TB(2231) |
| 7 | 附注上市/国企 | 从审定表按分类取数 → 编辑 → 同步附注模块 |

## 3. 目录页速查

| 区块 | 说明 |
|------|------|
| 编制进度 | 各分表按审计说明/结论填写情况计算完成度 |
| 跨表结论口径 | 每张核心表审计结论「已填/未填」标签，点击跳转对应 sheet 补全 |

## 4. 常见问题

| 现象 | 处理 |
|------|------|
| L2-1 审定 ≠ TB 数 | 检查明细是否全部带入、调整是否已确认回写；TB 取 2231 期末余额 |
| 计提与测算不符 | 复核借款本金、利率、计息天数；确认与 L1-5 短借测算 / L3 长借测算口径一致 |
| 明细合计不符 | 核对期末应付 = 期初 + 计提 − 支付；确认调整（账项调整/重分类）已录入 |
| 附注分类金额不符 | 附注分类（分期付息长借/企业债券/短借/优先股永续债/其他）金额应等于 L2-1 各分类审定数 |
| 附注同步失败 | 检查项目 ID、附注模块权限与准则类型（上市/国企） |

## 5. 复核入口

各分表工具栏/结论区「复核」打开复核对话。合伙人级复核提示词参考：`backend/data/tsj_review_prompts/L/`（若环境已部署）。
