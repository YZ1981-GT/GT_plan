# L2 应付利息 — 底稿编制手册

> **适用范围**：科目 **2231 应付利息（贷方/负债类）**
> **组件**：`l2-interest-payable`
> **说明**：本手册说明各分表的审计目标、编制逻辑与勾稽关联，不替代各表页内已有说明文案。
> 平台按钮与操作步骤见「使用手册」页签。

## 1. 总体编制思路

应付利息核心 = **按借款来源（短借/长借/企业债券/优先股永续债/其他）汇总的期末余额审定**，并验证利息计提与借款测算的一致性、完整性。

| 证据链 | 主要底稿 | 回答的问题 |
|--------|----------|------------|
| **金额枢纽** | L2-2 明细 → L2-1 审定 ← L2-3 调整 | 应付利息期末余额是否准确完整？ |
| **计提验证** | L2-1 审定表 ← L1-5 / L3 利息测算 | 应计利息计提是否恰当？ |
| **完整性** | L2-2 明细（按来源逐笔） | 是否存在漏计提、欠付利息？ |
| **凭证核对** | L2-4 应付利息检查表 | 计提/支付凭证是否真实、恰当？ |
| **披露** | 附注上市/国企 | 分类披露是否与审定勾稽？ |

**枢纽原则**：

1. **负债类贷方科目**：期末 = 期初 + 贷方（计提）− 借方（支付）。审定表按借款来源分类，双期（期初/期末各未审、账项调整、重分类、审定）。
2. **计提联动测算**：应付利息按借款来源计提，本期计提与 **L1-5 短期借款利息测算**、**L3 长期借款利息测算** 联动核对，差异逐笔说明。
3. **L2-1 是结论枢纽**：审定期末合计回写试算表 2231，并驱动附注披露（上市/国企）。
4. **本期计提联动 L8 财务费用**：利息费用化部分联动财务费用（利息支出）。

### 建议编制顺序

```
L2A 程序计划
  → L2-2 明细（按借款/债券来源逐笔）
  → 核对 L1-5 / L3 利息测算 与账面计提差异
  → L2-4 应付利息检查表（凭证级）
  → 差异汇入 L2-3 → 确认回写 L2-1
  → L2-1 勾稽 TB(2231) → 附注上市/国企
```

## 2. 分表编制说明

### L2A 实质性程序表
- **审计目标**：规划并记录应付利息实质性程序范围、性质与时间。
- **完成标志**：计划程序均有执行记录或「不适用」说明。

### L2-1 审定表（负债类贷方，双期）
- **审计目标**：核实应付利息期末余额准确完整；按借款来源提供审定数。
- **编制逻辑**：期末 = 期初 + 贷方（计提）− 借方（支付）；审定 = 未审 + 账项调整 + 重分类；期初/期末双期分列；变动率超 30% 高亮并分析原因。
- **上游**：L2-2 明细（按来源 SUMIF 带入）；L2-3 确认回写。**下游**：TB(2231)、附注上市/国企。
- **完成标志**：与 TB 勾稽差异已解释；与经审计财报核对；审计说明与结论已填。

### L2-2 明细表
- **审计目标**：核实各笔应付利息存在、完整、准确（按借款银行/债券/债权人逐笔列示）。
- **编制逻辑**：期末应付 = 期初 + 本期计提 − 本期支付（负债类）；含调整（账项调整/重分类）与审定验证列、逾期与附注列。
- **完成标志**：清单完整、合计与 L2-1 一致；明细分析说明已填。

### L2-3 调整分录汇总
- **审计目标**：核实调整完整、借贷平衡。
- **完成标志**：借贷平衡；已确认回写 L2-1；发布 A13 错报（如适用）。

### L2-4 应付利息检查表（凭证级）
- **审计目标**：核实应付利息计提/支付凭证真实、账务处理恰当、会计期间正确。
- **编制逻辑**：记账凭证行 + 核对内容①~⑤ + 检查比例（本期发生额来自 L2-2 的 Σ计提/Σ支付）。
- **完成标志**：凭证检查覆盖充分；审计说明与结论已填。

### 附注披露（上市/国企）
- **审计目标**：按附注格式披露应付利息分类（分期付息长借利息/企业债券/短借/优先股永续债/其他）及重要逾期未付利息，与审定勾稽。
- **编制逻辑**：分类金额从 L2-2 明细按类别 SUMIF 聚合（期末=Σ审定期末；上年年末/期初=Σ审定期初）；优先股/永续债由工具 1 + 工具 2 汇总。
- **完成标志**：分类金额与 L2-1 审定一致；已同步附注模块。

### 底稿目录
- **审计目标**：导航与编制进度总览（跨表结论口径 + 底稿架构 + 本循环其他科目）。

## 3. 认定覆盖速查

| 认定 | 主要底稿 |
|------|----------|
| 存在 | L2-2、L2-4 |
| 完整性 | L2-2、L2-4 |
| 权利与义务 | L2-2（来源合同）、L2-1 |
| 计价与分摊 | L2-1、L2-2（计提测算） |
| 列报与披露 | 附注上市/国企 |

## 4. 外部模块衔接

| 模块 | 与 L2 关系 |
|------|------------|
| **L1 短期借款** | L1-5 利息测算联动短期借款应付利息计提 |
| **L3 长期借款** | L3 利息测算联动长期借款应付利息计提 |
| **L4 应付债券** | 企业债券应付利息计提来源 |
| **L8 财务费用** | 应付利息本期计提费用化部分联动财务费用（利息支出） |
| **试算平衡表** | L2-1 审定期末合计回写 2231 |
| **调整分录 / A13** | 与 L2-3 双向同步 |
| **附注模块** | 应付利息分类披露 + 重要逾期未付利息 |

---

## 5. 质量复核要点（摘要）

1. L2-2 明细合计 ↔ L2-1 审定是否勾稽？
2. L2-1 审定期末 ↔ TB(2231) 是否勾稽？
3. L2-1 本期计提 ↔ L1-5 / L3 利息测算是否核对一致？
4. L2-2 明细是否覆盖全部借款来源（无漏计提）？
5. 重要逾期未付利息是否披露充分、原因及可收回性已评估？
6. 附注分类金额是否等于 L2-1 审定？
