# M1 应付股利（利润） — 平台使用手册

> 配合「编制手册」页签使用。本手册只说明**平台怎么操作**；审计目标与勾稽逻辑见编制手册。
> **不修改**各分表页内已有说明文案。入口：底稿目录页顶部「使用手册」按钮。

---

## 1. 打开与模式

1. 在项目底稿树打开 **M1 应付股利（利润）**（`componentType: m1-dividends-payable`，覆盖科目 2232）。
2. 通过 sheet 页签切换分表（M1A、M1-1～M1-6、附注上市/国企、底稿目录）。
3. 复杂 sheet 支持 **结构化 HTML ↔ OnlyOffice** 双模式；以项目配置为准（目录页不显示双模式）。
4. 只读阶段工具栏「取数 / 回写 / 确认」类按钮会禁用。

---

## 2. 推荐操作路径（点击顺序）

| 步骤 | 分表 | 建议操作 |
|------|------|----------|
| 1 | M1A | 勾选实质性程序、填索引 |
| 2 | M1-2 | 按股东录入各项应付股利明细 |
| 3 | M1-4 | 境外股东应付股利按期末汇率折算 |
| 4 | M1-5 | 核对 M6 利润分配宣告股利 |
| 5 | M1-6 | 宣告决议、支付、代扣所得税检查 |
| 6 | M1-1 | 确认审定（未审 + AJE + RJE）→ 回写 TB(2232) |
| 7 | 附注上市/国企 | 从审定表取数 → 同步附注模块 |

| 区块 | 说明 |

| 编制进度 | 各分表按审计说明/结论填写情况计算完成度 |

---

## 4. 常见问题

| 现象 | 处理 |
|------|------|
| M1-1 审定 ≠ TB 数 | 应付股利为负债类贷方（期末=期初+贷−借）；检查 M1-2 明细是否带入 |
| 明细合计与审定不符 | 复核 M1-2 各股东明细是否齐全，是否含境外股东折算 |
| 宣告金额对不上 | 核对 M1-5 与 M6 利润分配的分配股利数据 |
| 外币折算异常 | 检查 M1-4 是否按期末汇率折算境外股东应付股利 |
| 附注同步失败 | 检查项目 ID、附注模块权限与准则类型（上市/国企） |

## 5. 复核入口
