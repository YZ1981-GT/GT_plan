# M1 应付股利（利润） — 底稿编制手册

> **适用范围**：科目 **2232 应付股利（贷方/负债类，期末=期初+贷方−借方）**
> **组件**：`m1-dividends-payable`
> **说明**：本手册说明各分表的审计目标、编制逻辑与勾稽关联，不替代各表页内已有说明文案。
> 平台按钮与操作步骤见「使用手册」页签。

---

## 1. 总体编制思路

应付股利是**M 股东权益循环中唯一的负债类科目**：董事会/股东会宣告分配时贷方增加，实际支付时借方减少。

| 证据链 | 主要底稿 | 回答的问题 |
|--------|----------|------------|
| **余额审定** | M1-1 审定 ← M1-2 明细 | 应付股利期末余额是否准确完整？ |
| **外币折算** | M1-4 外币汇率测算 | 对境外股东的应付股利折算是否正确？ |
| **宣告核对** | M1-5 测算 ← M6 利润分配 | 宣告分配金额是否与利润分配一致？ |
| **合规检查** | M1-6 检查表 | 宣告依据、支付、代扣所得税是否合规？ |

**枢纽原则**：

1. **负债类贷方科目**：期末 = 期初 + 贷方（宣告分配）− 借方（实际支付）。
2. **按股东列示**：明细表 M1-2 按股东分列各项应付股利，与审定表合计交叉核对。
3. **外币折算**：M1-4 对境外股东应付股利按期末汇率折算本位币。
4. **宣告核对**：M1-5 接收 M6 利润分配的分配股利，验证宣告准确性。
5. **M1-1 是结论枢纽**：审定合计回写试算表 2232，并驱动附注披露。

### 建议编制顺序

```
M1A 程序计划
  → M1-2 明细（按股东列示）
  → M1-4 外币汇率测算（境外股东折算）
  → M1-5 应付股利测算（核对 M6 利润分配宣告）
  → M1-6 检查表（宣告/支付/代扣合规）
  → M1-1 审定（未审 + AJE + RJE → 审定）→ 回写 TB(2232) → 附注上市/国企
  → M1-3 调整分录（借贷平衡，回写审定）
```

## 2. 分表编制说明

### M1A 实质性程序表
- **审计目标**：规划并记录应付股利实质性程序范围、性质与时间。
- **完成标志**：计划程序均有执行记录或「不适用」说明。

### M1-1 审定表（负债类贷方）
- **审计目标**：核实应付股利期末余额准确完整；提供审定数。
- **编制逻辑**：审定 = 未审 + AJE + RJE；负债期末 = 期初 + 贷方 − 借方。
- **上游**：M1-2 明细；M1-3 确认回写。**下游**：TB(2232)、附注。
- **完成标志**：与 M1-2 明细合计勾稽；审计结论已填。

### M1-2 明细表
- **审计目标**：核实各股东应付股利明细准确完整。
- **完成标志**：明细合计与 M1-1 一致；审计说明已填。

### M1-3 调整分录汇总
- **审计目标**：核实调整完整、借贷平衡。
- **完成标志**：借贷平衡；已确认回写 M1-1。

### M1-4 外币汇率测算表
- **审计目标**：核实对境外股东应付股利的期末汇率折算准确。
- **完成标志**：折算差异已列示并解释；结论已填。

### M1-5 应付股利（利润）测算表
- **审计目标**：核实宣告分配金额与 M6 利润分配一致。
- **编制逻辑**：接收 M6 利润分配的分配股利，验证宣告准确性。
- **完成标志**：与 M6 分配数据勾稽；结论已填。

### M1-6 应付股利（利润）检查表
- **审计目标**：核实宣告依据（决议）、实际支付、代扣代缴所得税合规。
- **完成标志**：凭证核对完整、依据充分；结论已填。

### 附注披露（上市/国企）
- **审计目标**：按附注格式披露应付股利，与审定勾稽。
- **完成标志**：金额与 M1-1 审定一致；已同步附注模块。

### 底稿目录
- **审计目标**：导航与编制进度总览（跨表结论口径 + 底稿架构 + 本循环其他科目）。

## 5. 质量复核要点（摘要）

1. M1-2 明细合计 ↔ M1-1 审定是否勾稽？
2. M1-5 宣告分配 ↔ M6 利润分配是否一致？
3. M1-1 审定 ↔ TB(2232) 是否勾稽？
4. 境外股东应付股利折算是否按期末汇率？
5. 附注披露金额是否等于 M1-1 审定？
