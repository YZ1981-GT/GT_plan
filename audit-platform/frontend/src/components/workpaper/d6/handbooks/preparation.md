# D6 合同资产 — 底稿编制手册

> **适用范围**：科目 **1141 合同资产**（CAS14 收入准则：已转移商品但收款权取决于未来履约以外条件）
> **组件**：`d6-contract-assets`
> **说明**：本手册说明各分表的审计目标、编制逻辑与勾稽关联。
> **不替代**各表页内已有的审计目标/过程提示文案（页内说明保持不变）。
> 平台按钮与操作步骤见「使用手册」页签。

---

## 1. 总体编制思路

D6 把「合同资产」拆成三条证据链，最后汇入审定与附注：

| 证据链 | 主要底稿 | 回答的问题 |
|--------|----------|------------|
| **金额枢纽** | D6-2 明细 → D6-1 ← D6-4 | 未审→调整→审定是否完整准确？ |
| **计价/减值** | D6-3 减值明细；D6-7 政策；D6-8 减值测算；D6-9 转回核销 | 合同资产减值（ECL）是否充分、政策恰当？ |
| **存在/完整性/披露** | D6-5 关联方；D6-6 检查表；附注 | 合同资产确认真实、关联方披露完整？ |

**枢纽原则**：

1. **D6-2 明细表是数据枢纽**——审定表原值从明细带入；可从四表库取数（block1 原值期初/期末）。
2. **D6-4 是调整枢纽**——差异确认后回写 D6-1。
3. **D6-1 是结论枢纽**——与试算（1141）、附注披露勾稽。
4. **合同资产 ↔ 应收账款转换**——履约义务完成、收款权变为无条件时结转应收账款。

### 建议编制顺序（标准路径）

```
D6A 程序计划
  → D6-2 明细（先立清单，可从四表库取数）
  → D6-6 检查表 → D6-5 关联方
  → D6-7 政策 → D6-8 减值测算 → D6-3 减值准备明细 → D6-9 转回核销
  → 差异汇入 D6-4 → 确认回写 D6-1
  → 附注上市 / 附注国企
```

## 2. 分表编制说明

### D6A 实质性程序表
- **审计目标**：规划并记录合同资产实质性程序范围、性质与时间。
- **完成标志**：计划程序均有执行记录或「不适用」说明。

### D6-1 审定表
- **审计目标**：核实合同资产原值/减值/净值准确完整；提供审定数。
- **编制逻辑**：期初/期末 × 未审 / 账项调整 / 审定；原值 − 减值 = 净值；审定 = 未审 + 调整。
- **上游**：D6-2 原值 + D6-3 减值汇总；D6-4 确认回写。**下游**：试算表（1141）；附注。
- **完成标志**：与 TB 勾稽差异已解释；结论已填。

### D6-2 明细表（数据枢纽）
- **审计目标**：核实存在、完整、权利与计价；逐合同/客户列示。
- **编制逻辑**：合同 × 原值滚动；1 年以上合同资产列示（非流动扣减参考）；期后结转应收账款。
- **下游**：D6-1、D6-3、D6-8 带入源。
- **完成标志**：清单完整；与 D6-1 汇总一致。

### D6-3 减值准备明细表
- **审计目标**：核实合同资产减值准备期初/计提/转回/核销/期末完整准确。
- **编制逻辑**：与 D6-8 ECL 测算勾稽（差异>1 元告警）。
- **完成标志**：与 D6-8 一致；结论已填。

### D6-4 调整分录汇总表
- **审计目标**：核实合同资产及相关科目调整完整、借贷平衡。
- **完成标志**：借贷平衡；已确认回写 D6-1。

### D6-5 关联关系及交易检查
- **审计目标**：识别关联方合同资产，核对披露完整性。
- **完成标志**：关联方合同资产已识别，与 B19 清单核对（完整性双向核对）。

### D6-6 合同资产检查表
- **审计目标**：以凭证级/合同级检查佐证合同资产确认真实、金额准确。
- **完成标志**：抽查比例达方案要求；异常已跟进。

### D6-7 合同资产减值准备会计政策检查
- **审计目标**：减值计提政策（ECL 组合划分、比例）符合准则。
- **完成标志**：政策逐项判断结论已填。

### D6-8 合同资产减值准备测算
- **审计目标**：按 ECL 模型重新测算合同资产减值，与账面比较。
- **编制逻辑**：与 D6-3 减值明细勾稽（eclVsImpairmentDiff 差异>1 元告警）。
- **完成标志**：测算与 D6-3 一致；差异已解释。

### D6-9 减值准备转回核销检查
- **审计目标**：核实减值转回/核销的合规性与授权。
- **完成标志**：转回/核销有据、已授权；确认后联动 D6-3。

### 附注披露（上市/国企）
- **审计目标**：按附注格式披露合同资产构成、减值准备、账龄，与审定勾稽。
- **完成标志**：金额与 D6-1 审定一致；已同步附注模块。

### 底稿目录
- **审计目标**：导航与编制进度总览（跨表结论口径 + 底稿目录表）。

## 5. 质量复核要点（摘要）

1. D6-2 原值合计 ↔ D6-1 未审是否勾稽？
2. D6-4 已确认调整是否已体现在 D6-1？借贷是否平衡？
3. D6-8 ECL 测算 ↔ D6-3 减值准备是否一致（差异>1 元告警）？
4. 1 年以上合同资产非流动扣减是否考虑？
5. 附注金额是否等于 D6-1 审定？
