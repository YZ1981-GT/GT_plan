# K11 资产减值损失 — 底稿编制手册

> **适用范围**：科目 **6701 资产减值损失（借方/损益类）**（各类非金融资产计提的减值损失：存货/固定资产/在建工程/无形资产/商誉/长期股权投资等）
> **组件**：`k11-asset-impairment-loss`
> **说明**：本手册说明各分表的审计目标、编制逻辑与勾稽关联，不替代各表页内已有说明文案。
> 平台按钮与操作步骤见「使用手册」页签。

---

## 1. 总体编制思路

K11 是**汇总性损益底稿**——各类资产减值损失在各自源底稿（F2 存货/H1 固定资产/I1 无形资产/I3 商誉等）计提，K11 汇总核对并确认发生额：

| 证据链 | 主要底稿 | 回答的问题 |
|--------|----------|------------|
| **金额枢纽** | K11-2 明细 → K11-1 审定 ← K11-3 调整 | 各类资产减值损失发生额未审→调整→审定是否完整准确？ |
| **源底稿核对** | K11-2 明细 ↔ F2/H1/I1/I3 等源底稿 | 各类减值计提是否与源底稿一致？ |

**枢纽原则**：

1. **损益类借方科目（6701）取本期发生额（借方 = 减值增加），非期末余额**。
2. **各类资产减值损失在源底稿计提**——K11 明细逐类与源底稿（F2/H1/H2/I1/I3/G7 等）交叉核对。
3. **商誉减值损失一经确认不得转回**（CAS8）。
4. **K11-2 明细表是数据枢纽**——审定表从明细带入。
5. **K11-3 是调整枢纽**——差异确认后回写 K11-1，联动 A13。
6. **K11-1 是结论枢纽**——审定发生额回写试算平衡表（6701）、与附注披露勾稽。

### 建议编制顺序（标准路径）

```
K11A 程序计划
  → K11-2 明细（按资产类别登记减值损失，与源底稿核对）
  → 差异汇入 K11-3 → 确认回写 K11-1（TB 回写 6701）
  → 附注上市 / 附注国企
```

## 2. 分表编制说明

每张表按统一结构：**审计目标 → 编制逻辑 → 上游/下游 → 完成标志**。

### K11A 实质性程序表
- **审计目标**：规划并记录针对资产减值损失的实质性程序范围、性质与时间。
- **完成标志**：计划程序均有执行记录或「不适用」说明。

### K11-1 审定表
- **审计目标**：核实各类资产减值损失发生额准确完整；分类列报恰当；提供审定数。
- **编制逻辑**：按资产类别（18 类 canonical）展开；未审发生额 + AJE + RJE = 审定发生额；审定发生额回写 TB（6701）。
- **上游**：K11-2 明细汇总；K11-3 确认回写。**下游**：试算表(6701)；附注。
- **完成标志**：与 TB 勾稽差异已解释；审计结论已填。

### K11-2 明细表（数据枢纽）
- **审计目标**：核实各类资产减值损失发生额存在、完整、准确，与源底稿一致。
- **编制逻辑**：按资产类别登记本期计提/转回，与源底稿（F2/H1/H2/I1/I3/G7 等）交叉核对。
- **完成标志**：清单完整；与源底稿一致；与 K11-1 汇总一致。

### K11-3 调整分录汇总
- **审计目标**：核实调整完整、借贷平衡。
- **完成标志**：借贷平衡；已确认回写 K11-1；联动 A13 错报汇总。

### 附注披露（上市/国企）
- **审计目标**：按资产类别分别披露减值损失金额（项目/本期/上期发生额），与审定勾稽。
- **完成标志**：金额与 K11-1 审定一致；已同步附注模块。

### 底稿目录
- **审计目标**：导航与编制进度总览（跨表结论口径 + 底稿架构）。
- **完成标志**：计划执行的分表状态均为完成或已说明不适用。

## 3. 认定覆盖速查

| 认定 | 主要底稿 |
|------|----------|
| 发生 | K11-2 |
| 完整性 | K11-2（与源底稿核对） |
| 准确性 | K11-1、K11-2 |
| 分类 | K11-1、附注上市/国企 |

## 4. 外部模块衔接

| 模块 | 与 K11 关系 |
|------|------------|
| **F2/H1/H2/I1/I3/G7 等源底稿** | 各类资产减值计提来源，K11-2 交叉核对 |
| **调整分录模块** | 与 K11-3 双向同步；确认驱动 K11-1 |
| **试算平衡表** | K11-1 审定发生额回写 6701 |
| **附注模块** | 资产减值损失披露 |
| **A13 错报汇总** | K11-3 调整推送 |

---

## 5. 质量复核要点（摘要）

1. K11-2 明细各类减值 ↔ 源底稿（F2/H1/I1/I3 等）是否一致？
2. K11-2 明细合计 ↔ K11-1 未审是否勾稽？
3. K11-1 审定发生额是否已回写 TB（6701）？借贷是否平衡？
4. 商誉减值是否未转回？附注金额是否等于 K11-1 审定？
