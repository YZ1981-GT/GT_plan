# I5 其他非流动资产 — 平台使用手册

> 配合「编制手册」页签使用。本手册只说明**平台怎么操作**；审计目标与勾稽逻辑见编制手册。
> **不修改**各分表页内已有说明文案。入口：底稿目录页顶部「使用手册」按钮。

---

## 1. 打开与模式

1. 在项目底稿树打开 **I5 其他非流动资产**（`componentType: i5-other-noncurrent-assets`，覆盖科目 1911）。
2. 通过 sheet 页签切换分表（I5A、I5-1~I5-4、附注上市/国企、底稿目录）。
3. 复杂 sheet 支持 **结构化 HTML ↔ OnlyOffice** 双模式；以项目配置为准（目录页不显示双模式）。
4. 只读阶段工具栏「取数 / 回写 / 确认」类按钮会禁用。

---

## 2. 推荐操作路径（点击顺序）

| 步骤 | 分表 | 建议操作 |
|------|------|----------|
| 1 | I5A | 勾选实质性程序、填索引 |
| 2 | I5-2 | 逐项登记明细（原值/减值/净值三层滚动） |
| 3 | I5-4 | 抽凭核对 + 分类/期限/可回收性专项评估 |
| 4 | I5-3 | 调整分录汇总 → 确认 → 回写 I5-1、推送 A13 |
| 5 | I5-1 | 从 I5-2 带入 → 确认审定 → 回写 TB(1911) |
| 6 | 附注上市/国企 | 从审定表取数 → 编辑 → 同步附注模块 |

---

## 3. 目录页速查

| 区块 | 说明 |
|------|------|
| 编制进度 | 各分表按审计说明/结论填写情况计算完成度 |
| 跨表结论口径 | 每张表审计结论「已填/未填」标签，点击跳转对应 sheet 补全 |
| 底稿架构 | 4 阶段泳道（审计计划/科目审定/实质性程序/披露与调整），点击卡片跳转 |
| 本循环底稿目录 | 同循环其他科目（I1~I6），点击跳转（灰色表示尚未生成） |

---

## 4. 常见问题

| 现象 | 处理 |
|------|------|
| I5-1 审定 ≠ TB 数 | 检查明细是否全部带入、调整是否已确认回写；TB 取 1911 期末余额 |
| 账面净值不符 | 净值 = 原值 − 减值准备，检查 I5-2 两层审定数 |
| 明细合计 ↔ I5-1 不符 | 确认 I5-2 三层滚动（未审→调整→审定）配平、类别齐全 |
| I5-4 专项评估未通过 | 补齐分类正确性/期限适当性/可回收性判断依据 |
| 附注同步失败 | 检查项目 ID、附注模块权限与准则类型（上市/国企） |

## 5. 复核入口

各分表工具栏/结论区「复核」打开复核对话。合伙人级复核提示词参考：`backend/data/tsj_review_prompts/I/`（若环境已部署）。
