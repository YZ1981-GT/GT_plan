# I5 其他非流动资产 — 底稿编制手册

> **适用范围**：科目 **1911 其他非流动资产（资产借方，期末 = 期初 + 增加 − 减少）**
> **组件**：`i5-other-noncurrent-assets`
> **说明**：本手册说明各分表的审计目标、编制逻辑与勾稽关联，不替代各表页内已有说明文案。
> 平台按钮与操作步骤见「使用手册」页签。

---

## 1. 总体编制思路

其他非流动资产核心 = **原值 − 减值准备 = 账面净值**，按类别（预付土地款/工程款、合同资产非流动部分、其他）逐项滚动审定。

| 证据链 | 主要底稿 | 回答的问题 |
|--------|----------|------------|
| **金额枢纽** | I5-2 明细 → I5-1 审定 ← I5-3 调整 | 原值/减值期末余额是否准确完整？ |
| **专项检查** | I5-4 针对性检查 | 抽凭核对 + 分类正确性/期限适当性/可回收性是否恰当？ |
| **列报披露** | 附注上市 / 附注国企 | 按附注格式披露其他非流动资产及账面净值，与审定勾稽？ |

**枢纽原则**：

1. **方向**：1911 资产借方，期末 = 期初 + 增加 − 减少。
2. **I5-1 是结论枢纽**：审定期末回写试算表 1911，账面净值供附注披露。
3. **三层结构**：I5-2 明细按 **原值 / 减值 / 净值** 三层滚动（未审 → 调整 → 审定），**无直线摊销列**。
4. **I5-4 针对性检查**：对样本凭证核对存在/发生、账证相符，并做分类正确性、期限适当性、可回收性专项评估。

### 建议编制顺序

```
I5A 程序计划
  → I5-2 明细（原值/减值/净值三层逐项登记）
  → I5-4 针对性检查（抽凭核对 + 分类/期限/可回收性评估）
  → 差异汇入 I5-3 → 确认回写 I5-1
  → I5-1 勾稽 TB(1911) → 附注上市/国企
```

## 2. 分表编制说明

### I5A 实质性程序表
- **审计目标**：规划并记录其他非流动资产实质性程序范围、性质与时间。
- **完成标志**：计划程序均有执行记录或「不适用」说明。

### I5-1 审定表
- **审计目标**：核实原值/减值准备期末余额准确完整；提供审定数与账面净值。
- **编制逻辑**：审定 = 未审 + AJE + RJE；账面净值 = 原值 − 减值准备。
- **上游**：I5-2 明细、I5-4 针对性检查；I5-3 确认回写。**下游**：TB(1911)、附注。
- **完成标志**：与 TB 勾稽差异已解释；审计说明与结论已填。

### I5-2 明细表
- **审计目标**：逐项核实其他非流动资产存在、完整、准确（原值/减值/净值分列）。
- **编制逻辑**：原值/减值各按 未审 → 调整 → 审定 滚动；净值 = 原值审定 − 减值审定。
- **完成标志**：清单完整、合计与 I5-1 一致；审计说明与结论已填。

### I5-3 调整分录汇总
- **审计目标**：核实调整完整、借贷平衡。
- **完成标志**：借贷平衡；已确认回写 I5-1、推送 A13。

### I5-4 针对性检查表
- **审计目标**：抽凭核对（存在/发生、账证相符），并做分类正确性、期限适当性、可回收性专项评估。
- **完成标志**：样本核对完成；专项评估结论已填。

### 附注披露（上市/国企）
- **审计目标**：按附注格式披露其他非流动资产原值/减值及账面净值，与审定勾稽。
- **完成标志**：附注金额 = I5-1 审定；上市/国企版按准则类型选取。

### 底稿目录
- **审计目标**：导航与编制进度总览（跨表结论口径 + 底稿架构 + 本循环其他科目）。

## 4. 外部模块衔接

| 模块 | 与 I5 关系 |
|------|------------|
| **试算平衡表** | I5-1 审定期末回写 1911 |
| **调整分录 / A13** | 与 I5-3 双向同步 |
| **附注模块** | 其他非流动资产披露 |

> **与 I4 长期待摊费用差异**：I4 侧重摊销引擎与受益期分摊；I5 侧重原值/减值/净值滚动、分类与重分类（预付土地/工程款、合同资产非流动部分等），**无直线摊销表**。

---

## 5. 质量复核要点（摘要）

1. I5-1 原值/减值审定 ↔ TB(1911) 是否勾稽？账面净值是否 = 原值 − 减值？
2. I5-2 明细合计 ↔ I5-1 审定是否一致？三层滚动（未审→调整→审定）是否配平？
3. I5-4 抽凭样本是否覆盖大额/异常项？分类/期限/可回收性专项评估结论是否恰当？
4. I5-3 调整是否借贷平衡并已确认回写 I5-1？
5. 附注金额是否等于 I5-1 审定？
