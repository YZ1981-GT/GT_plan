## 2. 各底稿操作要点

### J2A 实质性程序表
- 程序控制台：勾选执行状态、填写执行说明、指派与复核；索引联动各分表。

### J2-1 审定表
- 逐单元格录入 **未审数 / AJE / RJE**，审定数自动计算（未审 + AJE + RJE）。
- 「保存」后审定期末数**回写试算表（TB 2211/长期应付款相关科目）**，并联动 M9（其他综合收益重计量）与附注取数。
- 顶部「审计说明 / 审计结论」文本框支持 🤖 AI 辅助生成。

### J2-2 明细表
- 按 **CAS9 六要素**录入变动：期初 → 当期服务成本 / 过去服务成本 / 结算利得损失 / 利息净额 → 重计量（OCI）→ 期末。
- 明细合计与 J2-1 审定勾稽，差异在页面顶部提示。

### J2-3 调整分录汇总表
- 「新增调整分录」录入借贷方，实时校验借贷平衡；可「同步到集中登记」。
- 调整合计回写 J2-1 的 AJE/RJE 列。

### J2-4 计提情况检查表
- 录入精算假设（折现率 / 工资增长率 / 死亡率等）、当期服务成本与利息净额测算。
- 「利用专家的工作」区登记精算专家（S12/S12A），评价其资质与工作。

### 附注披露（上市公司 / 国有企业）
- 从 J2-1 审定数自动取数；录入敏感性分析等叙述；「同步到附注」推送至附注模块。
- 支持 🤖 AI 辅助起草叙述性说明。
