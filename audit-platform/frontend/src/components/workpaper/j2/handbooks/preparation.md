# J2 长期应付职工薪酬（设定受益计划） — 底稿编制手册

> **适用范围**：**长期应付职工薪酬 — 设定受益计划净负债/净资产**（离职后福利之设定受益计划、其他长期职工福利）
> **组件**：`j2-defined-benefit-plan`
> **说明**：本手册说明各分表的审计目标、编制逻辑与勾稽关联，不替代各表页内已有说明文案。
> 平台按钮与操作步骤见「使用手册」页签。

---

## 1. 总体编制思路

设定受益计划按 **CAS9** 核算：设定受益计划义务现值（DBO）− 计划资产公允价值 = 净负债/净资产；重计量计入其他综合收益（OCI，M9）。

| 证据链 | 主要底稿 | 回答的问题 |
|--------|----------|------------|
| **金额枢纽** | J2-2 明细 → J2-1 审定 ← J2-3 调整 | 设定受益计划净负债期末余额准确完整？ |
| **计提检查** | J2-4 计提情况检查 | 精算假设、当期服务成本、利息净额恰当？ |

**枢纽原则**：

1. **CAS9 六要素**：期初 → 当期服务成本 + 过去服务成本 + 结算利得/损失 + 利息净额（计入损益）→ 重计量（精算利得损失、计划资产回报，计入 OCI）→ 期末。
2. **利用精算专家（S12/S12A）**：关键假设（折现率、工资增长率、死亡率等）。
3. **J2-1 是结论枢纽**：审定净负债回写试算表，重计量部分联动 M9 其他综合收益。

### 建议编制顺序

```
J2A 程序计划 → J2-4 计提检查（精算假设+六要素）→ J2-2 明细
  → 差异进 J2-3 → 回写 J2-1 → 联动 M9(OCI) → 附注上市/国企
```

## 2. 分表编制说明

### J2A 实质性程序表
- **审计目标**：规划并记录设定受益计划实质性程序范围、性质与时间。

### J2-1 审定表
- **审计目标**：核实设定受益计划净负债/净资产期末余额准确完整；提供审定数。
- **编制逻辑**：DBO − 计划资产 = 净负债；审定 = 未审 + AJE + RJE。
- **下游**：TB、M9（OCI 重计量）、附注。

### J2-2 明细表
- **审计目标**：核实 CAS9 六要素变动（服务成本/利息净额/重计量等）准确、完整。

### J2-3 调整分录汇总
- **审计目标**：核实调整完整、借贷平衡。

### J2-4 计提情况检查表
- **审计目标**：核实精算假设合理、当期服务成本与利息净额计量恰当（利用精算专家工作）。

### 附注披露（上市/国企）
- **审计目标**：按附注格式披露设定受益计划义务、计划资产、精算假设及敏感性分析，与审定勾稽。

### 底稿目录
- **审计目标**：导航与编制进度总览（跨表结论口径 + 底稿架构 + 本循环其他科目）。

## 4. 外部模块衔接

| 模块 | 与 J2 关系 |
|------|------------|
| **M9 其他综合收益** | 设定受益计划重计量计入 OCI |
| **专家利用（S12/S12A）** | 精算假设与计量利用精算专家 |
| **试算平衡表 / 附注模块** | J2-1 审定回写 + 披露 |

---

## 5. 质量复核要点（摘要）

1. J2-2 六要素变动 ↔ J2-1 审定是否勾稽？
2. 精算假设（折现率/工资增长率）是否合理，专家资质与工作是否评价？
3. 重计量部分是否正确计入 M9（OCI）？
4. 附注披露（敏感性分析）是否与审定一致？
