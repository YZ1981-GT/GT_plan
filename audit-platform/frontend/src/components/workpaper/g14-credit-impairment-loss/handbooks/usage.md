# G14 信用减值损失 — 平台使用手册

> 本页说明各底稿在平台上的操作方式。审计目标与编制逻辑见「编制手册」页签。

## 1. 目录页（本页）

- **跨表结论口径看板**：汇总核心表「审计说明或结论」是否已填，点击标签跳转补全。
- **底稿架构（4 阶段泳道）**：审计计划 / 科目审定 / 实质性程序 / 披露与调整。
- **本循环底稿目录**：G 循环其他科目，点击跳转。
- **编制/使用手册**：右上角按钮。

## 2. 各底稿操作要点

### G14-1 审定表
点「从 G14-2 带入」填未审数；调整列由 G14-3 回写；点「回写试算平衡表」写入 TB 6702。

### G14-2 明细表
按资产分项录入应收款项/债权投资/其他债权投资等本期 ECL 减值计提（含转回）；支持导入导出。

### G14-3 调整分录
录入借贷、实时校验平衡；可「推送至 A13」。

### 附注（上市 / 国企）
点「从明细带入」按资产类别聚合信用减值损失；文本区可「🤖 AI 辅助」。

## 3. 常用操作速查

| 操作 | 位置 |
|------|------|
| 回写试算平衡表 | G14-1 审定表工具栏 |
| 从明细带入 | G14-1 / 附注 工具栏 |
| 导入 / 导出 | 各表「导入导出 ▾」 |
| 推送错报至 A13 | G14-3 调整分录 |
| AI 辅助说明 | 各审计说明/结论区右侧 |
| 复核对话 | 各区块标题右侧 💬 |

## 4. 联动关系速查

| 联动 | 说明 |
|------|------|
| G14-2 → G14-1 | 明细合计带入审定表 |
| G14-3 → G14-1 | 调整分录回写调整列 |
| G14-1 → TB | 审定合计回写 6702 发生额 |
| D1/D2/K1/G4/G6 → G14 | 各金融资产 ECL 减值本期计提汇入 |

| G14 vs K11 | 信用减值损失(6702,金融资产)区别资产减值损失(6701,非金融资产) |
