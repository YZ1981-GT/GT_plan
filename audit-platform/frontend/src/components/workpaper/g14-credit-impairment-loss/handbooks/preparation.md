# G14 信用减值损失 — 底稿编制手册

> **适用范围**：科目 6702 信用减值损失（损益类），核算按预期信用损失（ECL）模型计提的各类金融资产减值损失。
> **组件**：GtBIndex 通用目录（G14 科目）
> **说明**：本手册说明各分表的审计目标、编制逻辑与勾稽关联，不替代各表页内已有说明文案。平台按钮与操作步骤见「使用手册」页签。

---

## 1. 总体编制思路

信用减值损失是损益类科目，汇集企业按 CAS 22 **预期信用损失（ECL）三阶段模型**对各类金融资产计提/转回的减值损失，主要来源包括：**①应收款项（应收账款、其他应收款、应收票据等）②债权投资（G4）③其他债权投资（G6，减值计入 OCI 但损失额进本科目）④长期应收款、合同资产、租赁应收款、贷款等**。核算要点：**三阶段模型（阶段一：信用风险未显著增加，计提未来 12 个月 ECL；阶段二：信用风险显著增加但未减值，计提整个存续期 ECL；阶段三：已发生信用减值，计提整个存续期 ECL 并按账面净额计息）；本期计提数（含转回）计入信用减值损失，对应各金融资产减值准备的本期变动**。审计核心是完整性（各金融资产 ECL 无遗漏）、准确性（三阶段划分与减值计量）、与各资产减值准备的勾稽一致性。

| 证据链 | 主要底稿 | 回答的问题 |
|--------|----------|------------|
| 来源是否完整 | G14-2 明细（按资产分项） | 各金融资产 ECL 计提是否无遗漏 |
| 三阶段是否恰当 | ECL 三阶段测试 | 信用风险显著增加、已减值判断是否合理 |
| 是否与减值准备勾稽 | 跨科目勾稽核对 | 与各资产减值准备本期变动一致 |
| 审定是否正确 | G14-1 审定表 | 未审→调整→审定，与 TB 6702 勾稽 |
| 披露是否完整 | 附注（上市/国企） | 信用减值损失按资产类别披露 |

### 建议编制顺序

```
G14-2 明细(按资产分项:应收款项/债权投资/其他债权投资) → ECL 三阶段测试 → 与各资产减值准备本期变动勾稽 → G14-3 调整 → 回写 G14-1 审定 → 勾稽 TB(6702) → 附注(上市/国企)
```

## 2. 分表编制说明

### G14-1 审定表
汇总信用减值损失未审数、账项/重分类调整、审定数，回写 TB 6702（损益类取发生额），与 G14-2 明细勾稽。

### G14-2 明细表
按资产分项列示：应收账款、其他应收款、应收票据、债权投资（G4）、其他债权投资（G6）、长期应收款、合同资产等的本期减值计提（含转回）；各分项应能追溯到对应资产减值准备的本期变动。

### G14-3 调整分录
录入 AJE/RJE 回写 G14-1 审定表调整列，可推送 A13。

### 附注（上市 / 国企）
按信用减值损失来源资产类别披露；数据取自 G14-2 明细。

## 3. 认定覆盖速查

| 认定 | 主要底稿 |
|------|----------|
| 发生 | G14-2 明细、ECL 测算依据 |
| 完整性 | 跨科目勾稽、TB 勾稽 |
| 准确性 | 三阶段测试、减值计量 |
| 截止 | 期末信用风险评估时点 |
| 分类 | 附注（资产类别） |

## 4. 外部模块衔接

| 模块 | 关系 |
|------|------|
| TB 试算平衡表 | G14-1 审定合计回写 6702（发生额） |
| D2 应收账款 / K1 其他应收款 / D1 应收票据 | 应收款项 ECL 减值本期计提汇入 |
| G4 债权投资 | 债权投资 ECL 减值汇入 |
| G6 其他债权投资 | 其他债权投资 ECL 损失额汇入（减值计入 OCI，损失额进本科目） |
| A13 未更正错报 | G14-3 调整分录推送 |
| 附注模块 | 披露表数据同步 |

## 5. 质量复核要点（摘要）

1. 各金融资产的 ECL 计提是否完整、无遗漏，是否与对应资产减值准备本期变动勾稽一致。
2. 三阶段划分（信用风险显著增加/已减值）判断是否有充分依据。
3. ECL 计量参数（违约概率 PD、违约损失率 LGD、违约风险敞口 EAD）是否合理。
4. **区分信用减值损失（金融资产 ECL，6702）与资产减值损失（非金融资产，6701，属 K11）**，勿混淆。
5. G14-1 审定合计 = G14-2 明细合计 = TB 6702 发生额。
