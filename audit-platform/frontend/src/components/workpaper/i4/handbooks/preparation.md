# I4 长期待摊费用 — 底稿编制手册

> **适用范围**：**长期待摊费用**（科目 1801，如经营租入固定资产改良支出、开办费等分期摊销支出）
> **组件**：`i4-long-term-prepaid`
> **说明**：本手册说明各分表的审计目标、编制逻辑与勾稽关联，不替代各表页内已有说明文案。
> 平台按钮与操作步骤见「使用手册」页签。

---

## 1. 总体编制思路

长期待摊费用为**资产类借方科目（1801）**：期末 = 期初 + 本期增加 − 本期摊销 − 本期减少（转销）。

| 证据链 | 主要底稿 | 回答的问题 |
|--------|----------|------------|
| **金额枢纽** | I4-2 明细 → I4-1 审定 ← I4-3 调整 | 长期待摊费用期末余额准确完整？ |
| **政策与摊销** | I4-4 政策检查 / I4-6·I4-7 摊销测算 | 摊销期限、方法恰当，摊销金额准确？ |
| **针对性核查** | I4-5 抽凭检查 | 支出真实、资本化恰当、期间归属正确？ |

**枢纽原则**：

1. **摊销测算二选一**：I4-6 直线法 / I4-7 工作量法，按支出性质选择；结果回写审定。
2. **I4-1 是结论枢纽**：审定期末回写试算表（TB 1801）并驱动附注披露。
3. **抽凭覆盖率闸门**：I4-5 抽查比例达门槛，异常与政策检查（I4-4）交叉。

### 建议编制顺序

```
I4A 程序 → I4-2 明细（滚转四区段）→ I4-1 审定带入 → I4-3 调整
  → I4-4 政策检查 → I4-5 针对性抽凭 → I4-6/7 摊销测算（二选一）
  → 回写 I4-1 → 附注上市/国企
```

## 2. 分表编制说明

### I4A 实质性程序表
- **审计目标**：规划并记录长期待摊费用实质性程序范围、性质与时间。

### I4-1 审定表
- **审计目标**：核实长期待摊费用期末余额准确完整；提供审定数。
- **编制逻辑**：三角勾稽（期初 + 增加 − 摊销 − 减少 = 期末）；审定 = 未审 + AJE + RJE；自 I4-2 明细带入。
- **下游**：TB(1801)、附注。

### I4-2 明细表（滚转四区段）
- **审计目标**：逐项核实长期待摊费用的增减、摊销与基础信息（未审滚动 / 调整与审定 / 摊销信息 / 基础信息）。

### I4-3 调整分录汇总
- **审计目标**：核实调整完整、借贷平衡；可推送 A13 未更正错报。

### I4-4 摊销政策检查表（表 A/B/C）
- **审计目标**：核实摊销期限与方法符合 CAS，与同业 / 租赁期一致。

### I4-5 针对性检查表（抽凭）
- **审计目标**：抽凭核对（真实性 / 审批 / 资本化恰当 / 期间归属），达覆盖率门槛，与 I4-4 交叉。

### I4-6 摊销测算-直线法 / I4-7 摊销测算-工作量法
- **审计目标**：重新测算本期摊销，与账面比对差异；二选一，回写审定。

### 附注披露（上市/国企）
- **审计目标**：按附注格式披露长期待摊费用变动，与审定勾稽。

### 底稿目录
- **审计目标**：导航与编制进度总览（跨表结论口径 + 底稿架构 + 本循环其他科目）。

## 5. 质量复核要点（摘要）

1. I4-2 明细滚转与 I4-1 审定是否三角勾稽？
2. 摊销期限、方法是否恰当（I4-4），重新测算（I4-6/7）与账面差异是否查明？
3. I4-5 抽凭覆盖率是否达门槛，异常是否处理？
4. 附注披露是否与审定一致？
