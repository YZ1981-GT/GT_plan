## 2. 各底稿操作要点

### I4A 实质性程序表
- 程序控制台：勾选执行状态、填写执行说明、指派与复核。

### I4-1 审定表
- 「从 I4-2 明细带入」自动汇总期初/增加/摊销/减少；录入 AJE/RJE，审定数自动计算。
- 「保存」后审定期末**回写试算表（TB 1801）**并驱动附注取数。

### I4-2 明细表（滚转四区段）
- 逐项录入：未审滚动 / 调整与审定 / 摊销信息 / 基础信息四区段切换。

### I4-3 调整分录汇总
- 「新增调整分录」录入借贷，实时校验平衡；可「推送 A13 未更正错报」「同步到集中登记」。

### I4-4 摊销政策检查表
- 表 A/B/C 分区录入摊销期限、方法与 CAS/同业/租赁期一致性判断。

### I4-5 针对性检查表（抽凭）
- 抽凭核对（1~5 项），显示覆盖率闸门；异常与 I4-4 交叉。

### I4-6 / I4-7 摊销测算
- 二选一：直线法 / 工作量法重新测算摊销；两表同时有数据时目录告警并以 I4-6 为准。

### 附注披露（上市/国企）
- 从 I4-1 审定取数；根据 projectContext 判断上市/国企版；支持 🤖 AI 辅助。
