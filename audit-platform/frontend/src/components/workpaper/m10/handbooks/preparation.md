# M10 其他权益工具 — 底稿编制手册

> **适用范围**：科目 **4003 其他权益工具（贷方/权益类，期末=期初+贷方−借方）**
> **组件**：`m10-other-equity-instruments`
> **说明**：本手册说明各分表的审计目标、编制逻辑与勾稽关联，不替代各表页内已有说明文案。
> 平台按钮与操作步骤见「使用手册」页签。

---

## 1. 总体编制思路

其他权益工具核实**混合金融工具（永续债、优先股等）划分为权益工具的分类恰当性**：发行时贷方增加，赎回/转换时借方减少。核心是 **CAS37《金融工具列报》** 的负债与权益区分判定。

| 证据链 | 主要底稿 | 回答的问题 |
|--------|----------|------------|
| **余额审定** | M10-1 审定（按工具类型：永续债/优先股分类） | 其他权益工具期末余额是否准确完整？ |
| **分项明细** | M10-2 明细（永续债/优先股逐项发行/赎回/利息） | 各工具变动是否准确？ |
| **分类判定** | M10-4 负债与权益区分检查（CAS37 逐条判定） | 划分为权益工具的分类是否恰当？ |
| **合规检查** | M10-5 检查表 | 发行/赎回/分派程序是否合规？ |

**枢纽原则**：

1. **权益类贷方科目**：期末 = 期初 + 贷方（发行增加）− 借方（赎回/转换减少）。
2. **CAS37 分类核心**：判定是否存在交付现金/其他金融资产的合同义务——无合同义务 → 权益工具（计入 4003）；有合同义务 → 金融负债（计入负债科目）。
3. **金额守恒**：单一工具拆分的权益部分 + 负债部分 = 工具总额。
4. **M10-1 是结论枢纽**：审定合计（按工具类型分组小计）回写试算表 4003，并驱动附注披露。

### 建议编制顺序

```
M10A 程序计划
  → M10-2 明细（永续债/优先股逐项明细）
  → M10-4 负债与权益区分检查（CAS37 逐条判定分类）
  → M10-5 其他权益工具检查表（发行/赎回/分派合规）
  → M10-1 审定（未审 + AJE + RJE → 审定，按工具类型分组小计）→ 回写 TB(4003) → 附注上市/国企
  → M10-3 调整分录（借贷平衡，回写审定）
```

## 2. 分表编制说明

### M10A 实质性程序表
- **审计目标**：规划并记录其他权益工具实质性程序范围、性质与时间。
- **完成标志**：计划程序均有执行记录或「不适用」说明。

### M10-1 审定表（权益类贷方，按工具类型分组）
- **审计目标**：核实其他权益工具期末余额准确完整；提供审定数。
- **编制逻辑**：审定 = 未审 + AJE + RJE；权益期末 = 期初 + 贷方 − 借方；按永续债/优先股/其他分组小计。
- **上游**：M10-2 明细、M10-4 分类判定；M10-3 确认回写。**下游**：TB(4003)、附注。
- **完成标志**：与 M10-2 明细合计勾稽、与 M10-4 权益部分一致；审计结论已填。

### M10-2 明细表（永续债/优先股明细）
- **审计目标**：核实各工具发行/赎回/利息变动准确、完整。
- **完成标志**：明细合计与 M10-1 一致；审计说明已填。

### M10-3 调整分录汇总
- **审计目标**：核实调整完整、借贷平衡。
- **完成标志**：借贷平衡；已确认回写 M10-1。

### M10-4 负债与权益区分检查表（CAS37 核心）
- **审计目标**：逐条判定工具有无交付现金/金融资产的合同义务，核实权益/负债划分恰当。
- **编制逻辑**：无合同义务 → 权益部分；有合同义务 → 负债部分；权益 + 负债 = 工具总额。
- **完成标志**：逐条判定有据；分类一致性校验通过；结论已填。

### M10-5 其他权益工具检查表
- **审计目标**：核实发行、赎回、股利/利息分派等程序合规。
- **完成标志**：检查项均已判定；审计结论已填。

### 附注披露（上市/国企）
- **审计目标**：按附注格式披露其他权益工具（发行在外数量、账面价值、归属），与审定勾稽。
- **完成标志**：金额与 M10-1 审定一致；已同步附注模块。

### 底稿目录
- **审计目标**：导航与编制进度总览（跨表结论口径 + 底稿架构 + 本循环其他科目）。

## 3. 认定覆盖速查

| 认定 | 主要底稿 |
|------|----------|
| 存在/完整性 | M10-1、M10-2 |
| 计价/准确 | M10-2、M10-4 |
| 分类（权益 vs 负债） | M10-4 |
| 列报与披露 | 附注上市/国企 |

## 4. 外部模块衔接

| 模块 | 与 M10 关系 |
|------|------------|
| **金融负债科目** | M10-4 判定为负债的部分计入相应负债科目（不计入 4003） |
| **M6 利润分配** | 永续债/优先股股利分派影响可供分配利润 |
| **试算平衡表** | M10-1 审定余额回写 4003 |
| **附注模块** | 其他权益工具披露 |

## 5. 质量复核要点（摘要）

1. M10-2 明细合计 ↔ M10-1 审定是否勾稽？
2. M10-4 是否按 CAS37 逐条判定合同义务，权益/负债划分是否恰当？
3. M10-4 权益部分合计 ↔ M10-1 审定是否一致（金额守恒）？
4. M10-1 审定 ↔ TB(4003) 是否勾稽？
5. 附注披露金额是否等于 M10-1 审定？
