# M10 其他权益工具 — 平台使用手册

> 配合「编制手册」页签使用。本手册只说明**平台怎么操作**；审计目标与勾稽逻辑见编制手册。
> **不修改**各分表页内已有说明文案。入口：底稿目录页顶部「使用手册」按钮。

---

## 1. 打开与模式

1. 在项目底稿树打开 **M10 其他权益工具**（`componentType: m10-other-equity-instruments`，覆盖科目 4003）。
2. 通过 sheet 页签切换分表（M10A、M10-1～M10-5、附注上市/国企、底稿目录）。
3. 复杂 sheet 支持 **结构化 HTML ↔ OnlyOffice** 双模式；以 OnlyOffice 健康检查为准（目录页/程序表不显示双模式）。
4. 只读阶段工具栏「取数 / 回写 / 确认」类按钮会禁用。

---

## 2. 推荐操作路径（点击顺序）

| 步骤 | 分表 | 建议操作 |
|------|------|----------|
| 1 | M10A | 勾选实质性程序、填索引 |
| 2 | M10-2 | 录入永续债/优先股逐项明细（发行/赎回/利息） |
| 3 | M10-4 | 负债与权益区分：CAS37 逐条判定合同义务、拆分权益/负债 |
| 4 | M10-5 | 检查发行/赎回/分派程序合规 |
| 5 | M10-1 | 确认审定期末（按工具类型分组） → 回写 TB(4003) |
| 6 | M10-3 | 调整分录汇总 → 确认 → 回写 M10-1 |
| 7 | 附注上市/国企 | 从审定表取数 → 编辑 → 同步附注模块 |

---

## 3. 目录页速查

| 区块 | 说明 |
|------|------|
| 编制进度 | 各分表按审计说明/结论填写情况计算完成度 |
| 跨表结论口径 | 每张表审计结论「已填/未填」标签，点击跳转对应 sheet 补全 |
| 底稿架构 | 4 阶段泳道（审计计划/科目审定/实质性程序/披露与调整），点击卡片跳转 |
| 本循环底稿目录 | 同循环其他科目（M1~M10），点击跳转（灰色表示尚未生成） |

---

## 4. 常见问题

| 现象 | 处理 |
|------|------|
| M10-1 审定 ≠ TB 数 | 检查明细是否全部带入、调整是否已确认回写；TB 取 4003 期末余额 |
| 权益 / 负债划分存疑 | M10-4 按 CAS37 判定是否存在交付现金/金融资产的合同义务；有义务→负债，无义务→权益 |
| 权益 + 负债 ≠ 工具总额 | 复核 M10-4 拆分金额守恒，逐条工具核对 |
| 附注同步失败 | 检查项目 ID、附注模块权限与准则类型（上市/国企） |

## 5. 复核入口

各分表工具栏/结论区「复核」打开复核对话。合伙人级复核提示词参考：`backend/data/tsj_review_prompts/M/`（若环境已部署）。
