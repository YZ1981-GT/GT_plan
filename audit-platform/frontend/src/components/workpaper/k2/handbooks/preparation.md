# K2 其他流动资产 — 底稿编制手册

> **适用范围**：科目 **1231 其他流动资产（借方/资产类）**（含合同取得成本、待摊费用、预缴税费等）
> **组件**：`k2-other-current-assets`
> **说明**：本手册说明各分表的审计目标、编制逻辑与勾稽关联，不替代各表页内已有说明文案。
> 平台按钮与操作步骤见「使用手册」页签。

---

## 1. 总体编制思路

K2 把「其他流动资产」拆成两条证据链，最后汇入审定与附注：

| 证据链 | 主要底稿 | 回答的问题 |
|--------|----------|------------|
| **金额枢纽** | K2-2 明细 → K2-1 审定 ← K2-3 调整 | 其他流动资产各项余额未审→调整→审定是否完整准确？ |
| **合同成本与摊销** | K2-4 合同取得成本 → K2-5 摊销测算 | 合同取得成本资本化(CAS14)与摊销是否恰当？ |
| **专项检查** | K2-6 检查表 | 大额/异常项目是否真实、有据、期间正确？ |

**枢纽原则**：

1. **K2-2 明细表是数据枢纽**——审定表从明细带入。
2. **K2-3 是调整枢纽**——差异确认后回写 K2-1。
3. **K2-1 是结论枢纽**——与试算（1231）、附注披露勾稽。
4. **K2A 程序表**统领「做了哪些程序」；分表记录「证据与结论」。

### 建议编制顺序（标准路径）

```
K2A 程序计划
  → K2-2 明细（按项目立清单）
  → 合同成本链：K2-4 合同取得成本明细 → K2-5 摊销测算
  → K2-6 检查表
  → 差异汇入 K2-3 → 确认回写 K2-1
  → 附注上市 / 附注国企
```

可按项目风险裁剪（如无合同取得成本可弱化 K2-4/K2-5），但 **明细 → K2-1** 不宜省略。

## 2. 分表编制说明

每张表按统一结构：**审计目标 → 编制逻辑 → 上游/下游 → 完成标志**。

### K2A 实质性程序表
- **审计目标**：规划并记录针对其他流动资产的实质性程序范围、性质与时间。
- **完成标志**：计划程序均有执行记录或「不适用」说明。

### K2-1 审定表
- **审计目标**：核实其他流动资产各项余额准确完整；分类列报恰当；提供审定数。
- **编制逻辑**：期初/期末 × 未审 / 账项调整 / 审定；按项目展开；审定 = 未审 + 调整。
- **上游**：K2-2 明细汇总；K2-3 确认回写。**下游**：试算表(1231)；附注。
- **完成标志**：与 TB 勾稽差异已解释；审计结论已填。

### K2-2 明细表（数据枢纽）
- **审计目标**：核实其他流动资产各项存在、完整、权利与计价。
- **编制逻辑**：逐项目列示，期初+增-减=期末滚动。
- **完成标志**：清单完整、滚动勾稽通过；与 K2-1 汇总一致。

### K2-3 调整分录汇总
- **审计目标**：核实调整完整、借贷平衡。
- **完成标志**：借贷平衡；已确认回写 K2-1；索引指向证据表。

### K2-4 合同取得成本明细表
- **审计目标**：核实合同取得成本资本化符合 CAS14（增量成本 + 预期可收回 + 与合同直接相关）。
- **编制逻辑**：逐合同列示取得成本、资本化判断、累计摊销、摊余成本。
- **下游**：K2-5 摊销测算源。
- **完成标志**：资本化条件判断有据；合计与 K2-1 一致。

### K2-5 摊销测算表
- **审计目标**：核实合同取得成本摊销方法与金额恰当。
- **编制逻辑**：直线法 = 取得成本 ÷ 摊销期总期数 × 本期期数；进度法 = 取得成本 ×(本期履约进度 − 上期履约进度)；摊余成本 = 取得成本 − 累计摊销。
- **完成标志**：摊销与 K2-4 累计摊销一致；差异已解释。

### K2-6 其他流动资产检查表
- **审计目标**：凭证级综合检查（真实性/审批/期间/分类）。
- **完成标志**：抽查比例达方案要求；异常已跟进。

### 附注披露（上市/国企）
- **审计目标**：按附注格式披露其他流动资产构成，与审定勾稽。
- **完成标志**：金额与 K2-1 审定一致；已同步附注模块。

### 底稿目录
- **审计目标**：导航与编制进度总览（跨表结论口径 + 底稿架构）。
- **完成标志**：计划执行的分表状态均为完成或已说明不适用。

## 5. 质量复核要点（摘要）

1. K2-2 明细合计 ↔ K2-1 未审是否勾稽？
2. K2-4 合同成本合计 ↔ K2-5 摊销测算基数是否一致？
3. K2-3 已确认调整是否已回写 K2-1？借贷是否平衡？
4. 附注金额是否等于 K2-1 审定？
