# L6 专项应付款 — 平台使用手册

> 配合「编制手册」页签使用。本手册只说明**平台怎么操作**；审计目标与勾稽逻辑见编制手册。
> **不修改**各分表页内已有说明文案。入口：底稿目录页顶部「使用手册」按钮。

---

## 1. 打开与模式

1. 在项目底稿树打开 **L6 专项应付款**（`componentType: l6-special-payables`，覆盖科目 2601）。
2. 通过 sheet 页签切换分表（L6A、L6-1～L6-4、附注上市/国企、底稿目录）。
3. 程序表（L6A）支持 **结构化 HTML ↔ OnlyOffice** 双模式；以项目配置为准（目录页不显示双模式）。
4. 只读阶段工具栏「取数 / 回写 / 确认」类按钮会禁用。

---

## 2. 推荐操作路径（点击顺序）

| 步骤 | 分表 | 建议操作 |
|------|------|----------|
| 1 | L6A | 勾选实质性程序、填索引 |
| 2 | L6-2 | 按专项项目逐项录入：拨款来源、批准文号、资金使用、结余 |
| 3 | L6-4 | 专款专用核查：实际用途 vs 批准用途 + 结余处理 |
| 4 | L6-3 | 调整分录汇总 → 确认 → 回写 L6-1 |
| 5 | L6-1 | 确认审定期末（从 L6-2 带入）→ 回写 TB(2601) |
| 6 | 附注上市/国企 | 从审定表按专项分项取数 → 编辑 → 同步附注模块 |

## 3. 目录页速查

| 区块 | 说明 |
|------|------|
| 编制进度 | 各分表按审计说明/结论填写情况计算完成度 |
| 跨表结论口径 | 每张核心表审计结论「已填/未填」标签，点击跳转对应 sheet 补全 |
| 底稿架构 | 4 阶段泳道（审计计划/科目审定/实质性程序/披露与调整），点击卡片跳转 |
| 本循环底稿目录 | 同循环其他科目（L1~L8），点击跳转（灰色表示尚未生成） |

## 4. 常见问题

| 现象 | 处理 |
|------|------|
| L6-1 审定 ≠ TB 数 | 检查明细是否全部带入、调整是否已确认回写；TB 取 2601 期末余额 |
| 专项项目行如何增减 | 审定表项目行为动态行，从 L6-2 明细带入，可手动增删 |
| 实际用途与批准用途不符 | L6-4 重点关注，判断是否存在挪用并记录审计结论 |
| 结余资金如何处理 | 按拨款规定（返还/继续使用/结转收益）核对并披露 |
| 与专项储备/递延收益混淆 | 核对拨款文件资金性质：专项储备走 4301，政府补助递延收益走 2401 |
| 附注分项金额不符 | 附注专项分项金额应等于 L6-1 各专项审定数 |
| 附注同步失败 | 检查项目 ID、附注模块权限与准则类型（上市/国企） |

## 5. 复核入口

各分表工具栏/结论区「复核」打开复核对话。合伙人级复核提示词参考：`backend/data/tsj_review_prompts/L/`（若环境已部署）。
