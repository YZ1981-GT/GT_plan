# L6 专项应付款 — 底稿编制手册

> **适用范围**：科目 **2601 专项应付款（贷方/负债类）**
> **组件**：`l6-special-payables`
> **说明**：本手册说明各分表的审计目标、编制逻辑与勾稽关联，不替代各表页内已有说明文案。
> 平台按钮与操作步骤见「使用手册」页签。

---

## 1. 总体编制思路

专项应付款核心 = **按专项项目列示的期末余额审定**，并验证专款专用、资金来源与结余处理。

| 证据链 | 主要底稿 | 回答的问题 |
|--------|----------|------------|
| **金额枢纽** | L6-2 明细 → L6-1 审定 ← L6-3 调整 | 专项应付款期末余额是否准确完整？ |
| **专款专用** | L6-4 专项应付款检查表 | 专项资金是否按批准用途使用，有无挪用？ |
| **列报披露** | 附注上市 / 附注国企 | 专项应付款分项及增减变动披露是否充分？ |

**枢纽原则**：

1. **负债类贷方科目**：期末 = 期初 + 贷方（拨入）− 借方（使用/结转）。审定表按**专项项目**列示，双期（期初/期末各未审、账项调整、重分类、审定），项目行为**动态行**，从 L6-2 明细带入、可增删。
2. **无"减一年内到期"列**：专项应付款不区分流动/非流动到期（区别于长期借款 L3），审定表不设减一年内到期口径。
3. **L6-1 是结论枢纽**：审定期末合计回写试算表 2601，并驱动附注披露（上市/国企）。
4. **专款专用是核心程序**：专项应付款多为政府专项拨款/上级专项拨款，L6-4 核查实际用途与批准用途是否一致；结余资金按规定处理（返还/继续使用/结转收益）。
5. **与专项储备、递延收益区分**：专项储备（安全生产费用等，权益类 4301）与政府补助形成的递延收益（2401）不并入本科目；核对拨款文件明确资金性质，防错分类。

### 建议编制顺序

```
L6A 程序计划
  → L6-2 明细（按专项项目逐项：拨款来源 / 资金使用）
  → L6-4 专款专用核查（实际用途 vs 批准用途 + 结余处理）
  → 差异汇入 L6-3 → 确认回写 L6-1
  → L6-1 勾稽 TB(2601) → 附注上市/国企
```

## 2. 分表编制说明

### L6A 实质性程序表
- **审计目标**：规划并记录专项应付款实质性程序范围、性质与时间。
- **完成标志**：计划程序均有执行记录或「不适用」说明。

### L6-1 审定表（负债类贷方，双期，动态行）
- **审计目标**：核实专项应付款期末余额准确完整；按专项项目提供审定数。
- **编制逻辑**：期末 = 期初 + 贷方 − 借方；审定 = 未审 + 账项调整 + 重分类；期初/期末双期分列；项目行动态，从 L6-2 带入。
- **上游**：L6-2 明细（按专项项目带入）；L6-3 确认回写。**下游**：TB(2601)、附注上市/国企。
- **完成标志**：与 TB 勾稽差异已解释；审计说明与结论已填。

### L6-2 明细表
- **审计目标**：核实各专项项目存在、完整、准确（按专项项目逐项：拨款来源、批准文号、资金使用、结余）。
- **完成标志**：项目清单完整、合计与 L6-1 一致；审计说明与结论已填。

### L6-3 调整分录汇总
- **审计目标**：核实调整完整、借贷平衡。
- **完成标志**：借贷平衡；已确认回写 L6-1；发布 A13 错报（如适用）。

### L6-4 专项应付款检查表（核心：专款专用）
- **审计目标**：核实专项资金按批准用途专款专用，识别挪用；核对结余资金处理是否合规。
- **编制逻辑**：逐项核对实际用途 vs 批准用途；不符时重点关注是否挪用；结余按规定处理（返还/继续使用/结转收益）。
- **完成标志**：各专项核对项完成；审计结论已填。

### 附注披露（上市/国企）
- **审计目标**：按附注格式披露专项应付款分项及本期增减变动，与审定勾稽。
- **完成标志**：分项金额与 L6-1 审定一致；已同步附注模块。

### 底稿目录
- **审计目标**：导航与编制进度总览（跨表结论口径 + 底稿架构 + 本循环其他科目）。

## 3. 认定覆盖速查

| 认定 | 主要底稿 |
|------|----------|
| 存在 | L6-2、L6-4 |
| 完整性 | L6-2、L6-4 |
| 权利与义务 | L6-4（专款专用/结余处理） |
| 计价与分摊 | L6-1 |
| 列报与披露 | 附注上市/国企 |

## 4. 外部模块衔接

| 模块 | 与 L6 关系 |
|------|------------|
| **专项储备（4301）** | 安全生产费用等权益类专项储备不并入本科目，核对拨款性质区分 |
| **递延收益（2401）** | 政府补助形成的递延收益单独核算，防与专项应付款混淆 |
| **试算平衡表** | L6-1 审定期末合计回写 2601 |
| **调整分录 / A13** | 与 L6-3 双向同步 |
| **附注模块** | 专项应付款分项及增减变动披露 |

---

## 5. 质量复核要点（摘要）

1. L6-2 明细合计 ↔ L6-1 审定是否勾稽？
2. L6-1 审定期末 ↔ TB(2601) 是否勾稽？
3. L6-4 专款专用核查是否覆盖全部专项，实际用途与批准用途是否一致？
4. 结余资金处理（返还/继续使用/结转收益）是否合规？
5. 专项应付款与专项储备（4301）、递延收益（2401）是否正确区分？
6. 附注分项金额是否等于 L6-1 审定？
