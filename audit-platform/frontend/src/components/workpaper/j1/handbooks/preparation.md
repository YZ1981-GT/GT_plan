# J1 应付职工薪酬 — 底稿编制手册

> **适用范围**：科目 **2211 应付职工薪酬（负债/贷方）**（工资、社保、公积金、工会经费、职工教育经费、非货币性福利、辞退福利等）
> **组件**：`j1-employee-compensation`
> **说明**：本手册说明各分表的审计目标、编制逻辑与勾稽关联，不替代各表页内已有说明文案。
> 平台按钮与操作步骤见「使用手册」页签。

---

## 1. 总体编制思路

| 证据链 | 主要底稿 | 回答的问题 |
|--------|----------|------------|
| **金额枢纽** | J1-2 明细 → J1-1 审定 ← J1-3 调整 | 各类职工薪酬期末余额准确完整？ |
| **计提与分配** | J1-6 计提检查 / J1-7 分配检查 | 计提标准恰当、分配去向正确？ |
| **专项检查** | J1-8 检查 / J1-9 非货币性福利 / J1-10 辞退福利 | 凭证真实、特殊福利处理恰当？ |
| **分析** | J1-4 月度分析 / J1-5 同行业对比 | 波动是否合理？ |

**枢纽原则**：

1. **负债类贷方科目**：期末 = 期初 + 贷方（计提）− 借方（支付）。按明细项目（工资/社保/公积金/工会/教育经费等）分类。
2. **J1-1 是结论枢纽**：审定期末回写试算表 2211，驱动附注披露。
3. **辞退福利（J1-10）** 按 CAS9 在不能撤回时确认；**非货币性福利（J1-9）** 按公允价值计量。

### 建议编制顺序

```
J1A 程序计划 → J1-2 明细（按项目分类）→ J1-6 计提检查 / J1-7 分配检查
  → J1-8/J1-9/J1-10 专项检查 → J1-4/J1-5 分析 → 差异进 J1-3 → 回写 J1-1
  → 勾稽 TB(2211) → 附注上市/国企
```

## 2. 分表编制说明

### J1A 实质性程序表
- **审计目标**：规划并记录应付职工薪酬实质性程序范围、性质与时间。

### J1-1 审定表（负债类贷方）
- **审计目标**：核实各类职工薪酬期末余额准确完整；提供审定数。
- **编制逻辑**：期末 = 期初 + 计提 − 支付；审定 = 未审 + AJE + RJE；按项目分类。
- **上游**：J1-2 明细；J1-3 确认回写。**下游**：TB(2211)、附注。

### J1-2 明细表
- **审计目标**：核实各薪酬项目发生、完整、准确、分类。

### J1-3 调整分录汇总
- **审计目标**：核实调整完整、借贷平衡。

### J1-4 月度分析表 / J1-5 同行业对比分析表
- **审计目标**：分析程序——月度波动、同行业人均薪酬对比，识别异常。

### J1-6 计提情况检查表 / J1-7 分配情况检查表
- **审计目标**：核实计提标准恰当、分配去向（成本/费用）正确。

### J1-8 检查表
- **审计目标**：凭证级综合检查（原始凭证/账务处理/期间/审批）。

### J1-9 非货币性福利检查表
- **审计目标**：核实非货币性福利按公允价值计量、恰当列报。

### J1-10 辞退福利检查表
- **审计目标**：核实辞退福利按 CAS9 确认时点与计量恰当（专家利用+关键假设）。

### 附注披露（上市/国企）
- **审计目标**：按附注格式披露应付职工薪酬构成，与审定勾稽。

### 底稿目录
- **审计目标**：导航与编制进度总览（跨表结论口径 + 底稿架构 + 本循环其他科目）。
