# J1 应付职工薪酬 — 平台使用手册

> 配合「编制手册」页签使用。本手册只说明**平台怎么操作**；审计目标与勾稽逻辑见编制手册。
> **不修改**各分表页内已有说明文案。入口：底稿目录页顶部「使用手册」按钮。

---

## 1. 打开与模式

1. 在项目底稿树打开 **J1 应付职工薪酬**（`componentType: j1-employee-compensation`，覆盖科目 2211）。
2. 通过 sheet 页签切换分表（J1A、J1-1～J1-10、附注上市/国企、IPO 提示、底稿目录）。
3. 只读阶段工具栏「取数 / 回写 / 确认」类按钮会禁用。

---

## 2. 推荐操作路径（点击顺序）

| 步骤 | 分表 | 建议操作 |
|------|------|----------|
| 1 | J1A | 勾选实质性程序、填索引 |
| 2 | J1-2 | 按项目录入职工薪酬明细（工资/社保/公积金等） |
| 3 | J1-6 / J1-7 | 计提检查、分配检查 |
| 4 | J1-8 / J1-9 / J1-10 | 凭证检查、非货币性福利、辞退福利 |
| 5 | J1-4 / J1-5 | 月度分析、同行业对比 |
| 6 | J1-3 | 调整分录汇总 → 确认 → 回写 J1-1 |
| 7 | J1-1 | 确认审定期末 → 回写 TB(2211) |
| 8 | 附注上市/国企 | 从审定表取数 → 编辑 → 同步附注模块 |

## 3. 目录页速查

| 区块 | 说明 |
|------|------|
| 编制进度 | 各分表按填写情况计算完成度 |
| 跨表结论口径 | 每张表审计结论「已填/未填」标签，点击跳转对应 sheet 补全 |

---

## 4. 常见问题

| 现象 | 处理 |
|------|------|
| J1-1 审定 ≠ TB 数 | 检查明细是否全部带入、调整是否已确认回写；TB 取 2211 期末余额 |
| 辞退福利确认时点存疑 | J1-10 按 CAS9：企业不能撤回时确认，利用精算专家（S12/S12A）工作 |
| 非货币性福利计量 | J1-9 按公允价值计量并恰当列报 |
| 附注同步失败 | 检查项目 ID、附注模块权限与准则类型（上市/国企） |
