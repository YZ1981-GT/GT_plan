# G4 平台使用手册

## 日常操作

- 从底稿目录查看 G4-1 至 G4-13 的数据、结论、闸门和勾稽状态（聚合 Main / SPPI / ECL 三组已保存 checklist；G4A 为程序表，通常无表格数据）。
- 状态为“待补”时进入对应表页补充结论；“闸门待办”或“勾稽差”应先处理异常。
- 表页数据保存后返回目录即可刷新状态。

## 上年结转

1. 进入 G4-2，点击“上年结转”。
2. 系统先读取上年同编码底稿并生成预览（默认跳过已填期初）。
3. 核对拟结转类别和行数后确认应用。
4. 若提示无可结转数据且期初已填，可选择“强制覆盖”后再次确认。

## 版本与复核

- 重要批量操作前可打开“版本历史”确认已有快照。
- 审计说明写明程序、证据及例外；审计结论采用 A/B/C 口径并与异常处理一致。
- 结转后应复核到期日、阶段划分、减值参数和本年凭证，不得沿用失效证据。
