# G11 投资收益 — 底稿编制手册

> **适用范围**：科目 6111 投资收益（损益类），核算企业对外投资取得的各项收益及处置损益。
> **组件**：GtBIndex 通用目录（G11 科目）
> **说明**：本手册说明各分表的审计目标、编制逻辑与勾稽关联，不替代各表页内已有说明文案。平台按钮与操作步骤见「使用手册」页签。

---

## 1. 总体编制思路

投资收益是损益类科目，汇集各类对外投资在持有和处置环节产生的收益，主要来源包括：**①持有金融资产/债权投资取得的利息收入 ②持有权益工具/股权投资取得的现金股利或利润分配 ③处置各类投资的处置损益（含 FVOCI 债务工具处置时 OCI 累计变动转入）④权益法下按持股比例确认的被投资单位净损益 ⑤金融资产重分类、终止确认产生的损益**。作为汇总性损益科目，其审计核心是**发生、准确性、截止、完整性**，且必须与各投资类资产科目（G1 交易性金融资产、G4 债权投资、G5 长期应收款、G6 其他债权投资、G7 长期股权投资、G8 其他权益工具投资、G9）逐项勾稽，确保投资收益的来源可追溯、无遗漏或虚增。

| 证据链 | 主要底稿 | 回答的问题 |
|--------|----------|------------|
| 来源是否真实 | G11-2 明细（按来源分项） | 利息/股利/处置/权益法各来源金额是否准确 |
| 是否与资产勾稽 | 跨科目勾稽核对 | 与 G1/G4/G5/G7/G8 各投资科目是否一致 |
| 截止是否正确 | 截止测试、凭证检查 | 是否计入恰当会计期间 |
| 审定是否正确 | G11-1 审定表 | 未审→调整→审定，与 TB 6111 勾稽 |
| 披露是否完整 | 附注（上市/国企） | 投资收益按来源分类披露 |

### 建议编制顺序

```
G11-2 明细(按来源分项:利息/股利/处置/权益法) → 与各投资科目勾稽 → 截止/凭证检查 → G11-3 调整 → 回写 G11-1 审定 → 勾稽 TB(6111) → 附注(上市/国企)
```

## 2. 分表编制说明

### G11-1 审定表
汇总投资收益未审数、账项/重分类调整、审定数，回写 TB 6111（损益类取发生额），与 G11-2 明细合计勾稽。

### G11-2 明细表
按来源分项列示：利息收入、股利/利润分配、处置损益、权益法确认的投资损益、金融资产重分类损益等；各分项应能追溯到对应资产科目的发生额。

### G11-3 调整分录
录入 AJE/RJE 回写 G11-1 审定表调整列，可推送 A13。

### 附注（上市 / 国企）
按投资收益来源分类披露（利息、股利、处置、权益法、公允价值转损益等）；数据取自 G11-2 明细。

## 3. 认定覆盖速查

| 认定 | 主要底稿 |
|------|----------|
| 发生 | G11-2 明细、凭证检查、来源单据 |
| 完整性 | 跨科目勾稽、TB 勾稽 |
| 准确性 | 明细分项、金额核对 |
| 截止 | 截止测试 |
| 分类 | 附注（来源分类） |

## 4. 外部模块衔接

| 模块 | 关系 |
|------|------|
| TB 试算平衡表 | G11-1 审定合计回写 6111（发生额） |
| G1 交易性金融资产 | 持有期利息/股利、处置损益 |
| G4 债权投资 | 利息收入、处置损益 |
| G5 长期应收款 | 融资租赁未实现融资收益等 |
| G6 其他债权投资 | 利息收入、处置时 OCI 累计变动转入 |
| G7 长期股权投资 | 权益法投资损益、股利、处置损益 |
| G8 其他权益工具投资 | 持有期股利（非成本收回部分） |
| A13 未更正错报 | G11-3 调整分录推送 |
| 附注模块 | 披露表数据同步 |

## 5. 质量复核要点（摘要）

1. 各来源分项是否完整、无遗漏，是否与对应投资科目（G1/G4/G5/G6/G7/G8/G9）逐项勾稽一致。
2. 权益法确认的投资损益是否与 G7 权益法调整一致。
3. 处置损益（含 FVOCI 债务工具 OCI 结转）计算是否正确。
4. 截止是否恰当，是否有跨期投资收益。
5. G11-1 审定合计 = G11-2 明细合计 = TB 6111 发生额。
