# H8 使用权资产 — 平台使用手册

> 本页说明各底稿在平台上的操作方式。审计目标与编制逻辑见「编制手册」页签。

## 1. 目录页（本页）

- 跨表结论口径看板：汇总核心表"审计说明或结论"是否已填，点击标签跳转对应分表。
- 底稿架构（4 阶段泳道）：审计计划 / 科目审定 / 实质性程序 / 披露与调整。
- 本循环底稿目录：H 循环其他科目，点击跳转。
- 编制/使用手册：右上角按钮。

## 2. 各底稿操作要点

- **H8 租赁识别**：录入合同要素，判定是否构成租赁、是否短期/低价值豁免。
- **H8 初始计量**：录入租赁付款额、折现率、初始直接费用、复原成本，系统算使用权资产成本并与 H9 勾稽。
- **H8 折旧**：录入折旧期（租赁期与寿命孰短），系统直线法测算。
- **H8 减值**：录入减值迹象与可收回金额，测算应计提减值。
- **H8 审定表**：从明细带入未审数，录入 AJE/RJE 得审定数，保存回写试算表 1901。
- **附注**：从审定表带入分类余额、变动、折旧政策及短期/低价值租赁。

## 3. 常用操作速查

| 操作 | 位置 |
|------|------|
| 从明细带入审定表 | H8 审定表「从明细带入」按钮 |
| 初始计量测算 | H8 初始计量录入后算使用权资产成本 |
| 勾稽 H9 | H8 明细/初始计量「勾稽 H9」提示 |
| 折旧测算 | H8 折旧「测算」按钮 |
| 减值测算 | H8 减值「可收回金额测算」 |
| 回写试算表 | H8 审定表保存时回写 1901 |
| AI 辅助说明/结论 | 各表审计说明区「AI 辅助」按钮 |
| 复核对话 | 各表结论区复核圆点/复核按钮 |
| 版本历史 | 顶部工具栏版本按钮 |

## 4. 联动关系速查

| 联动 | 说明 |
|------|------|
| H8 ↔ H9 | 使用权资产与租赁负债初始/变更/终止同步勾稽 |
| 初始计量 → 折旧 | 使用权资产成本为折旧基础 |
| 明细 → 审定 | H8 明细按分类聚合到审定表 |
| 调整 → 审定 | 调整分录回写审定 AJE/RJE |
| 审定 → 附注 | 审定数带入附注分类披露 |
| 审定 → 试算表 | 审定合计回写 1901 |
| 调整 → A13 | 未更正错报推送错报汇总 |
