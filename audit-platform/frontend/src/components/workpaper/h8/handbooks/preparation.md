# H8 使用权资产 — 底稿编制手册

> **适用范围**：承租人在租赁期内使用租赁资产的权利。科目 1901 使用权资产，及累计折旧、减值准备。
> **组件**：GtBIndex 通用目录（H8 科目）
> **说明**：本手册说明各分表的审计目标、编制逻辑与勾稽关联，不替代各表页内已有说明文案。平台按钮与操作步骤见「使用手册」页签。

---

## 1. 总体编制思路

使用权资产依《企业会计准则第 21 号——租赁》(CAS21) 由承租人确认，与租赁负债（H9）互为一体：

- **初始计量**：使用权资产成本 = 租赁负债初始计量金额（未来租赁付款额按增量借款利率折现的现值）+ 已支付的初始直接费用 + 预计的复原成本 − 已收到的租赁激励。
- **后续计量**：一般按**直线法**在租赁期与资产使用寿命孰短期间计提折旧；发生减值迹象时按 CAS8 计提减值。
- **豁免确认**：短期租赁（≤12 个月且无购买选择权）与低价值资产租赁可选择简化处理，租金计入相关成本费用，不确认使用权资产/租赁负债。
- **与 H9 勾稽**：初始使用权资产成本中的租赁负债部分应与 H9 租赁负债初始计量勾稽一致；租赁变更、提前终止时两表须同步调整。

| 证据链 | 主要底稿 | 回答的问题 |
|--------|----------|------------|
| 租赁识别与分类 | H8 租赁识别 | 是否构成租赁？是否属短期/低价值豁免？ |
| 初始计量 | H8 初始计量 | 使用权资产成本各组成是否准确？与 H9 勾稽？ |
| 后续折旧 | H8 折旧 | 折旧年限（租赁期与寿命孰短）与直线法是否恰当？ |
| 减值 | H8 减值 | 是否存在减值迹象、减值是否充分？ |
| 与 H9 勾稽 | H8 明细 / 审定 | 使用权资产与租赁负债是否勾稽一致？ |

### 建议编制顺序

```
H8程序表 → 租赁识别(是否租赁/是否短期低价值豁免)
  → 初始计量(租赁负债现值+初始直接费用+复原成本-激励)勾稽H9
  → 后续直线法折旧(租赁期与寿命孰短) → 减值测试
  → 调整(租赁变更/终止) → 回写审定表(勾稽TB 1901) → 附注
```

## 2. 分表编制说明

### H8 审定表
按租赁类别列示使用权资产原值、累计折旧、减值、账面价值；未审数 + 账项调整(AJE) + 重分类调整(RJE) = 审定数；审定合计回写并勾稽试算表 1901。

### H8 明细表
逐项租赁使用权资产明细：租赁标的、租赁期、初始成本组成、累计折旧、减值、账面价值；与 H9 租赁负债逐项勾稽。

### H8 租赁识别
判断合同是否构成租赁（是否存在已识别资产及控制其使用权）；短期租赁（≤12 月无购买权）与低价值资产租赁豁免判定，豁免的不确认使用权资产。

### H8 初始计量
使用权资产成本 = 租赁负债现值 + 初始直接费用 + 复原成本 − 租赁激励；核对折现率（增量借款利率）与租赁付款额；与 H9 租赁负债初始计量勾稽。

### H8 折旧
后续折旧测算：折旧期取租赁期与资产使用寿命孰短，直线法计提；测算额与账面计提额比对。

### H8 减值
CAS8 减值迹象识别与可收回金额测算，应计提减值与账面比对。

### 调整 / 附注
租赁变更、提前终止的调整分录（与 H9 同步）回写审定表并推送 A13；附注披露使用权资产分类、变动、折旧政策及短期/低价值租赁情况。

## 3. 认定覆盖速查

| 认定 | 主要底稿 |
|------|----------|
| 存在 | H8 明细 / 租赁识别（租赁合同） |
| 完整性 | H8 明细 / 租赁识别（未确认租赁排查） |
| 权利和义务 | H8 租赁识别（使用权控制） |
| 计价和分摊 | H8 初始计量 / 折旧 / 减值 |
| 列报和披露 | H8 审定表 / 附注 |

| 模块 | 关系 |

## 5. 质量复核要点（摘要）

- 租赁识别是否恰当（已识别资产 + 使用权控制），短期/低价值豁免判定是否正确。
- 初始计量各组成是否准确，折现率（增量借款利率）是否合理，与 H9 勾稽是否一致。
- 折旧期是否取租赁期与使用寿命孰短，直线法计提是否足额。
- 租赁变更、提前终止时 H8 与 H9 是否同步调整。
- 是否存在应确认而未确认的租赁（完整性），或滥用短期/低价值豁免。
