# D5 应收款项融资 — 平台使用手册

> 配合「编制手册」页签使用。本手册只说明**平台怎么操作**；审计目标与勾稽逻辑见编制手册。
> **不修改**各分表页内已有说明文案。入口：底稿目录页顶部「使用手册」按钮。

---

## 1. 打开与模式

1. 在项目底稿树打开 **D5 应收款项融资**（`componentType: d5-receivables-financing`，覆盖科目 1124）。
2. 通过 sheet 页签切换分表（D5A、D5-1～D5-4、附注上市/国企、底稿目录）。
3. 复杂 sheet 支持 **结构化 HTML ↔ OnlyOffice** 双模式；以项目配置为准（目录页除外）。
4. 只读阶段工具栏「取数 / 回写 / 确认」类按钮会禁用。

**需要项目上下文的操作**：D5-2 期后实现取数、附注「同步到附注模块」。

---

## 2. 推荐操作路径（点击顺序）

| 步骤 | 分表 | 建议操作 |
|------|------|----------|
| 1 | D5A | 勾选实质性程序、填索引 |
| 2 | D5-2 | 录入票据/应收明细，标注质押/背书贴现、期后实现 |
| 3 | D5-4 | 公允价值测算（贴现率合理性预警，可从明细带入） |
| 4 | D5-3 | 调整分录汇总 → 确认 → 回写 D5-1 |
| 5 | D5-1 | 从 D5-2 带入 → 核对调整回写 → 勾稽 TB |
| 6 | 附注上市/国企 | 拉取上游 → 编辑（质押/背书贴现披露）→ 同步附注模块 |

---

## 3. 目录页速查

| 区块 | 说明 |
|------|------|
| 编制进度 | 各分表填妥「审计说明或结论」即计入完成 |
| 跨表结论口径 | 每张表审计结论「已填/未填」标签，点击跳转对应 sheet 补全 |
| 编制提示 | 折叠展开，推荐编制工作流 |
| 底稿目录表 | 逐 sheet 名称/编码/分组/状态，跳转 |
| 本循环底稿目录 | 同循环（D 循环）其他底稿（灰色表示未生成） |

---

## 4. 导入导出

- 工具栏「导入/导出」按当前 sheet 作用（具备后端端点的 sheet，如 D5-2）。
- 导入后刷新当前表；若改了 D5-2 明细，请重新对 D5-1 执行「从明细带入」。

---

## 5. 常见问题

| 现象 | 处理 |
|------|------|
| D5-1 审定合计 ≠ TB 数 | 检查 D5-2 是否全部带入、调整是否已确认回写 |
| D5-4 贴现率预警 | 核对贴现率与市场利率差异（>200bp 预警） |
| 附注质押/背书贴现披露 | 按分类表 +（1）减值 +（2）质押 +（3）背书贴现结构填 |
| 附注同步失败 | 检查项目 ID、附注模块权限与准则类型（上市/国企） |

---

## 6. 复核入口

各分表工具栏/结论区「复核」打开复核对话（按 section-id）。
合伙人级复核提示词参考：`backend/data/tsj_review_prompts/D/`（若环境已部署）。
