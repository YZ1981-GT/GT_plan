# D5 应收款项融资 — 底稿编制手册

> **适用范围**：科目 **1124 应收款项融资**（以公允价值计量且其变动计入其他综合收益的应收票据/应收账款）
> **组件**：`d5-receivables-financing`
> **说明**：本手册说明各分表的审计目标、编制逻辑与勾稽关联。
> **不替代**各表页内已有的审计目标/过程提示文案（页内说明保持不变）。
> 平台按钮与操作步骤见「使用手册」页签。

---

## 1. 总体编制思路

D5 把「应收款项融资」拆成三条证据链，最后汇入审定与附注：

| 证据链 | 主要底稿 | 回答的问题 |
|--------|----------|------------|
| **金额枢纽** | D5-2 明细 → D5-1 ← D5-3 | 未审→调整→审定是否完整准确？ |
| **计价（公允价值）** | D5-4 公允价值测算 | 公允价值计量是否恰当（FVOCI）？ |
| **权利/披露** | D5-2 质押/背书/贴现；附注 | 已质押、已背书/贴现未到期票据披露是否完整？ |

**枢纽原则**：

1. **D5-2 明细表是数据枢纽**——审定表从明细带入。
2. **D5-3 是调整枢纽**——差异确认后回写 D5-1。
3. **D5-1 是结论枢纽**——与试算（1124）、附注披露勾稽。
4. **业务模式判断**决定分类为应收款项融资（既收取合同现金流又出售）。

### 建议编制顺序（标准路径）

```
D5A 程序计划
  → D5-2 明细（先立清单）
  → D5-4 公允价值测算
  → 差异汇入 D5-3 → 确认回写 D5-1
  → 附注上市 / 附注国企
```

## 2. 分表编制说明

### D5A 实质性程序表
- **审计目标**：规划并记录应收款项融资实质性程序范围、性质与时间。
- **完成标志**：计划程序均有执行记录或「不适用」说明。

### D5-1 审定表
- **审计目标**：核实应收款项融资余额准确完整；FVOCI 计量恰当；提供审定数。
- **编制逻辑**：期初/期末 × 未审 / 账项调整 / 审定；审定 = 未审 + 调整。
- **上游**：D5-2 汇总；D5-3 确认回写。**下游**：试算表（1124）；附注。
- **完成标志**：与 TB 勾稽差异已解释；结论已填。

### D5-2 明细表（数据枢纽）
- **审计目标**：核实存在、完整、权利与计价；逐票据/应收列示。
- **编制逻辑**：按出票人/债务人列示票面/账面/公允价值；标注已质押、已背书或贴现未到期票据（终止确认判断）；期后实现（贴现/背书/收款）。
- **下游**：D5-1、D5-4、附注带入源。
- **完成标志**：清单完整；与 D5-1 汇总一致；受限票据已标注。

### D5-3 调整分录汇总
- **审计目标**：核实应收款项融资及相关科目调整完整、借贷平衡。
- **完成标志**：借贷平衡；已确认回写 D5-1。

### D5-4 公允价值测算
- **审计目标**：核实应收款项融资公允价值计量恰当（贴现率合理性）。
- **编制逻辑**：贴现率合理性预警（200bp 阈值）；从 D5-2 明细带入应收票据。
- **完成标志**：公允价值测算有据；贴现率异常已解释。

### 附注披露（上市/国企）
- **审计目标**：按附注格式披露应收款项融资分类、减值准备、已质押票据、已背书或贴现未到期票据（终止确认/未终止确认），与审定勾稽。
- **编制逻辑**：分类表 +（1）减值准备 +（2）已质押票据 +（3）已背书或贴现尚未到期票据（CAS23 金融资产转移 + 证监会 2014 监管报告终止确认判断）。
- **完成标志**：金额与 D5-1 审定一致；质押/背书贴现情况已披露；已同步附注模块。

### 底稿目录
- **审计目标**：导航与编制进度总览（跨表结论口径 + 底稿目录表）。

## 3. 认定覆盖速查

| 认定 | 主要底稿 |
|------|----------|
| 存在 | D5-2、期后实现 |
| 完整性 | D5-2 |
| 权利与义务 | D5-2 质押/背书贴现终止确认 |
| 准确性/计价 | D5-4 公允价值、D5-1 |
| 列报与披露 | 附注上市/国企 |

## 4. 外部模块衔接

| 模块 | 与 D5 关系 |
|------|------------|
| **调整分录模块** | 与 D5-3 双向同步；确认驱动 D5-1 |

## 5. 质量复核要点（摘要）

1. D5-2 合计 ↔ D5-1 未审是否勾稽？
2. D5-3 已确认调整是否已体现在 D5-1？借贷是否平衡？
3. D5-4 贴现率是否在合理区间？异常是否已解释？
4. 附注质押/背书贴现（终止确认）披露是否完整？
5. 附注金额是否等于 D5-1 审定？
