# H2 在建工程 · 使用手册（平台操作）

## 一、导航与目录

- **底稿目录页**：目录卡（标题 + 复核 + 编制/使用手册）+ **跨表结论口径看板** + 顶部引导区 + 底稿目录表 + **本循环底稿目录**。
- 点击目录表行或「跨表结论口径」标签 → 跳转对应 sheet；「本循环底稿目录」grid 跳转 H 循环其他底稿。

## 二、双模式

- 非目录 sheet 顶部提供「结构化视图 / 在线编辑（OnlyOffice）」切换；不可用时回退结构化视图。
- 目录页不显示模式切换工具栏。

## 三、数据录入与联动

- 审定表/明细表数值列自动计算（净值 = 原值 − 减值），公式列只读。
- H2-1 审定表确认后自动回写 TB 1604 并广播 `substantive:adjudicated`，附注披露自动刷新。
- H2-10/H2-11 利息资本化互斥：选定一支后另一支标为不适用。
- H2-5 转固检查完成后联动 H1 固定资产。
- 调整分录（H2-3）借贷平衡后推送调整分录模块 / A13 错报。

## 四、复核与版本

- 各表「💬 复核」发起复核对话（蓝/红圆点表示线程状态）；顶部「版本历史」查看快照。

## 五、导入导出

- 含动态行的明细/检查表提供「导入导出▾」（导出模板 / 导出数据 / 导入数据）。
