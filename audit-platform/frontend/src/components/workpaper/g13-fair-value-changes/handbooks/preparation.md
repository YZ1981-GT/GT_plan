# G13 公允价值变动损益 — 底稿编制手册

> **适用范围**：科目 6101 公允价值变动损益（损益类），核算各类以公允价值计量且其变动计入当期损益的资产/负债的公允价值变动。
> **组件**：GtBIndex 通用目录（G13 科目）
> **说明**：本手册说明各分表的审计目标、编制逻辑与勾稽关联，不替代各表页内已有说明文案。平台按钮与操作步骤见「使用手册」页签。

---

## 1. 总体编制思路

公允价值变动损益是损益类科目，汇集**期末仍持有的、以公允价值计量且变动计入当期损益的资产/负债在本期发生的公允价值变动**，主要来源包括：**①交易性金融资产（G1）②交易性金融负债（G10，除指定 FVTPL 负债计入 OCI 的自身信用风险部分）③其他非流动金融资产（G9，FVTPL）④采用公允价值模式计量的投资性房地产 ⑤其他 FVTPL 项目**。核算要点：**公允价值变动损益是持有期间的浮动损益；处置时该项目累计的公允价值变动损益不结转（不转入投资收益），实现损益直接以处置价与账面差额确认**。审计核心是完整性（各 FVTPL 来源无遗漏）、准确性、与各资产/负债科目公允价值变动的勾稽一致性。

| 证据链 | 主要底稿 | 回答的问题 |
|--------|----------|------------|
| 来源是否完整 | G13-2 明细（按来源分项） | 各 FVTPL 来源公允价值变动是否无遗漏 |
| 是否与资产勾稽 | 跨科目勾稽核对 | 与 G1/G9/G10/投资性房地产公允价值变动一致 |
| 处置结转是否正确 | 处置核对 | 处置时是否**未误结转**累计公允价值变动 |
| 审定是否正确 | G13-1 审定表 | 未审→调整→审定，与 TB 6101 勾稽 |
| 披露是否完整 | 附注（上市/国企） | 公允价值变动损益按来源分类披露 |

### 建议编制顺序

```
G13-2 明细(按来源分项) → 与各 FVTPL 科目公允价值变动勾稽 → 处置结转核对 → G13-3 调整 → 回写 G13-1 审定 → 勾稽 TB(6101) → 附注(上市/国企)
```

## 2. 分表编制说明

### G13-1 审定表
汇总公允价值变动损益未审数、账项/重分类调整、审定数，回写 TB 6101（损益类取发生额），与 G13-2 明细勾稽。

### G13-2 明细表
按来源分项列示：交易性金融资产、交易性金融负债、其他非流动金融资产、投资性房地产（公允模式）等的本期公允价值变动；各分项应能追溯到对应资产/负债科目。

### G13-3 调整分录
录入 AJE/RJE 回写 G13-1 审定表调整列，可推送 A13。

### 附注（上市 / 国企）
按公允价值变动损益来源分类披露；数据取自 G13-2 明细。

## 3. 认定覆盖速查

| 认定 | 主要底稿 |
|------|----------|
| 发生 | G13-2 明细、公允价值来源 |
| 完整性 | 跨科目勾稽、TB 勾稽 |
| 准确性 | 明细分项、金额核对 |
| 截止 | 期末公允价值时点核对 |
| 分类 | 附注（来源分类） |

## 4. 外部模块衔接

| 模块 | 关系 |
|------|------|
| TB 试算平衡表 | G13-1 审定合计回写 6101（发生额） |
| G1 交易性金融资产 | 本期公允价值变动汇入 |
| G9 其他非流动金融资产 | 本期公允价值变动汇入 |
| G10 交易性金融负债 | 公允价值变动（非信用风险 OCI 部分）汇入 |
| 投资性房地产（公允模式） | 本期公允价值变动汇入 |
| A13 未更正错报 | G13-3 调整分录推送 |
| 附注模块 | 披露表数据同步 |

## 5. 质量复核要点（摘要）

1. 各 FVTPL 来源的公允价值变动是否完整、无遗漏，是否与对应科目（G1/G9/G10/投资性房地产）勾稽一致。
2. G10 指定 FVTPL 负债的自身信用风险变动部分是否**已从 G13 剔除并计入 OCI**。
3. 处置时是否**未误将累计公允价值变动结转**（区别于 FVOCI）。
4. 期末公允价值时点与计量是否恰当。
5. G13-1 审定合计 = G13-2 明细合计 = TB 6101 发生额。
