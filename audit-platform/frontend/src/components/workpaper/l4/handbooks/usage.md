# L4 应付债券 — 平台使用手册

> 配合「编制手册」页签使用。本手册只说明**平台怎么操作**；审计目标与勾稽逻辑见编制手册。
> **不修改**各分表页内已有说明文案。入口：底稿目录页顶部「使用手册」按钮。

---

## 1. 打开与模式

1. 在项目底稿树打开 **L4 应付债券**（`componentType: l4-bonds-payable`，覆盖科目 2502）。
2. 通过 sheet 页签切换分表（L4A、L4-1～L4-9、附注上市/国企、底稿目录）。
3. L4-7 后续计量 / L4-8 账面核对各有 **2 分支**（到期一次还本付息 / 分期付息到期一次还本），页面顶部 `分支选择器` 切换，两表分支状态同步。
4. 只读阶段工具栏「取数 / 回写 / 确认」类按钮会禁用。

---

## 2. 推荐操作路径（点击顺序）

| 步骤 | 分表 | 建议操作 |
|------|------|----------|
| 1 | L4A | 勾选实质性程序、填索引 |
| 2 | L4-2 | 按债券逐笔录入明细（89 列区段 Tab：基础/发行/计息付息/摊余成本/兑付） |
| 3 | L4-6 | 初始计量：发行价−交易费用，IRR 求实际利率 |
| 4 | L4-7 | 后续计量：选付息分支，实际利率法测算摊销表（联动 L2/L8） |
| 5 | L4-8 | 账面核对：账面摊余成本 vs L4-7 测算（差异高亮） |
| 6 | L4-5 / L4-3 | 权益负债划分（可转债分拆）/ 其他金融工具分类 |
| 7 | L4-4 | 调整分录汇总 → 确认 → 回写 L4-1 |
| 8 | L4-1 | 确认审定期末（从 L4-2 按品种带入）→ 减一年内到期 → 回写 TB(2502) |
| 9 | 附注上市/国企 | 从审定表按品种取数 → 编辑 → 同步附注模块 |

## 4. 常见问题

| 现象 | 处理 |
|------|------|
| L4-1 审定 ≠ TB 数 | 检查明细是否全部按品种带入、调整是否已确认回写；TB 取 2502 期末余额 |
| 后续计量末期摊余成本 ≠ 面值 | 复核初始入账、实际利率、票面利率与计息期数；允许 ±1 元尾差 |
| L4-8 账面与测算不符 | 逐笔核对账面摊余成本与 L4-7 测算，关注利息调整摊销、兑付时点 |
| 应计利息与 L2/L8 不符 | 确认 L4-7 利息费用与 L2 应付利息 / L8 财务费用口径一致 |
| 附注品种金额不符 | 附注品种（普通/可转换）金额、一年内到期重分类应等于 L4-1 各分类审定数 |
| 附注同步失败 | 检查项目 ID、附注模块权限与准则类型（上市/国企） |
