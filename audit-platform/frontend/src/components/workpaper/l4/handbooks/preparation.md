# L4 应付债券 — 底稿编制手册

> **适用范围**：科目 **2502 应付债券（贷方/负债类）**
> **组件**：`l4-bonds-payable`
> **说明**：本手册说明各分表的审计目标、编制逻辑与勾稽关联，不替代各表页内已有说明文案。
> 平台按钮与操作步骤见「使用手册」页签。

## 1. 总体编制思路

应付债券核心 = **按债券品种（普通/可转换）与子项（成本/利息调整/应计利息）汇总的期末摊余成本审定**，并以实际利率法验证每期利息费用、复合工具权益负债划分与一年内到期重分类。

| 证据链 | 主要底稿 | 回答的问题 |
|--------|----------|------------|
| **金额枢纽** | L4-2 明细 → L4-1 审定 ← L4-4 调整 | 应付债券期末摊余成本是否准确完整？ |
| **初始计量** | L4-6 初始计量 | 初始入账金额、溢折价、实际利率是否恰当？ |
| **后续计量** | L4-7 后续计量（实际利率法，2 分支） | 每期利息费用与摊销是否正确？ |
| **准确性核对** | L4-8 账面核对 | 账面摊余成本 vs 测算摊余成本是否一致？ |
| **分类** | L4-5 权益与负债划分 / L4-3 其他金融工具 | 复合工具负债/权益成分划分是否恰当？ |
| **完整性** | L4-9 应付债券检查表 | 发行、计息、兑付、担保、披露是否完整？ |

**枢纽原则**：

1. **负债类贷方科目**：期末 = 期初 + 贷方（发行 + 利息调整摊销）− 借方（兑付）。审定表按品种（普通/可转换）× 子项（成本/利息调整/应计利息）双期分列，含品种小计、合计与「减一年内到期」重分类。
2. **实际利率法后续计量**：每期利息费用 = 期初摊余成本 × 实际利率；摊销 = 利息费用 − 票面利息。付息方式分 2 分支：**到期一次还本付息**（利息资本化滚入摊余成本）/ **分期付息到期一次还本**（期间支付票面利息）。
3. **L4-1 是结论枢纽**：审定期末摊余成本合计回写试算表 2502，并驱动附注披露（上市/国企）。
4. **权益负债划分（可转债）**：负债成分 = 未来现金流按同期限市场利率折现；权益成分 = 发行总额 − 负债成分现值。

### 建议编制顺序

```
L4A 程序计划
  → L4-2 明细（按债券逐笔，89 列区段 Tab）
  → L4-6 初始计量（发行价−交易费用，IRR 求实际利率）
  → L4-7 后续计量（实际利率法，选付息分支）→ L4-8 账面核对
  → L4-5 权益负债划分 + L4-3 其他金融工具（分类）
  → 差异汇入 L4-4 → 确认回写 L4-1
  → L4-1 勾稽 TB(2502) → 附注上市/国企
```

## 2. 分表编制说明

### L4A 实质性程序表
- **审计目标**：规划并记录应付债券实质性程序范围、性质与时间。
- **完成标志**：计划程序均有执行记录或「不适用」说明。

### L4-1 审定表（负债类贷方，双期）
- **审计目标**：核实应付债券期末摊余成本准确完整；按品种/子项提供审定数。
- **编制逻辑**：期末 = 期初 + 贷方 − 借方；审定 = 未审 + 账项调整 + 重分类；期初/期末双期分列；减一年内到期后为披露审定数。
- **上游**：L4-2 明细（按品种 × 子项聚合带入）；L4-4 确认回写。**下游**：TB(2502)、附注上市/国企。
- **完成标志**：与 TB 勾稽差异已解释；审计说明与结论已填。

### L4-2 明细表（89 列极宽表）
- **审计目标**：核实各笔债券存在、完整、准确（按债券逐笔列示，区段 Tab：基础/发行/计息付息/摊余成本/兑付）。
- **完成标志**：清单完整、合计与 L4-1 一致；审计说明已填。

### L4-3 划分为金融负债的其他金融工具明细表
- **审计目标**：核实划分为金融负债的其他金融工具分类恰当、计量准确。
- **完成标志**：分类判断有据；审计说明已填。

### L4-4 调整分录汇总
- **审计目标**：核实调整完整、借贷平衡。
- **完成标志**：借贷平衡；已确认回写 L4-1；发布 A13 错报（如适用）。

### L4-5 权益与负债划分检查表（复合金融工具）
- **审计目标**：核实可转换债券等复合工具负债/权益成分划分恰当。
- **编制逻辑**：负债成分 = 未来现金流按市场利率折现；权益成分 = 发行总额 − 负债成分现值。
- **完成标志**：分拆计算有据；审计说明已填。

### L4-6 应付债券初始计量
- **审计目标**：核实初始入账金额、溢折价与实际利率恰当。
- **编制逻辑**：初始入账 = 发行价格 − 交易费用；溢折价 = 初始入账 − 面值；IRR 求解实际利率。
- **完成标志**：实际利率求解收敛；审计说明已填。

### L4-7 应付债券后续计量（核心，联动 L2/L8）
- **审计目标**：核实每期利息费用与摊销恰当（实际利率法）。
- **编制逻辑**：利息费用 = 期初摊余成本 × 实际利率；2 分支（到期一次还本付息 / 分期付息到期一次还本）；结果联动 L2 应付利息、L8 财务费用。
- **完成标志**：最后一期摊余成本 ≈ 面值（±1 元尾差）；测算与账面差异已解释；审计说明已填。

### L4-8 应付债券账面核对
- **审计目标**：核实账面摊余成本与 L4-7 测算摊余成本一致（准确性认定）。
- **完成标志**：差异高亮已逐项说明；审计结论已填。

### L4-9 应付债券检查表
- **审计目标**：综合核对发行、计息、兑付、担保、披露，形成整体审计结论。
- **完成标志**：各核对项完成；审计结论已填。

### 附注披露（上市/国企）
- **审计目标**：按附注格式披露应付债券品种、期末余额、发行/兑付/一年内到期，与审定勾稽。
- **完成标志**：披露金额与 L4-1 审定一致；已同步附注模块。

### 底稿目录
- **审计目标**：导航与编制进度总览（跨表结论口径 + 底稿架构 + 本循环其他科目）。

## 3. 认定覆盖速查

| 认定 | 主要底稿 |
|------|----------|
| 存在 | L4-2、L4-6 |
| 完整性 | L4-2、L4-9 |
| 权利与义务 | L4-5（权益负债划分）、L4-9（担保） |
| 计价与分摊 | L4-1、L4-6、L4-7（摊余成本/实际利率） |
| 列报与披露 | 附注上市/国企（含一年内到期重分类） |

## 4. 外部模块衔接

| 模块 | 与 L4 关系 |
|------|------------|
| **L2 应付利息** | L4-7 应计利息测算联动应付利息计提 |
| **L8 财务费用** | L4-7 利息费用化部分联动财务费用 |
| **L3 长期借款** | 债务融资分类区分（债券 vs 借款） |
| **试算平衡表** | L4-1 审定期末摊余成本合计回写 2502 |
| **调整分录 / A13** | 与 L4-4 双向同步 |
| **附注模块** | 应付债券品种披露 + 发行/兑付/一年内到期 |

## 5. 质量复核要点（摘要）

1. L4-2 明细合计 ↔ L4-1 审定是否勾稽？
2. L4-1 审定期末 ↔ TB(2502) 是否勾稽？
3. L4-7 测算摊余成本 ↔ L4-8 账面摊余成本是否核对一致？
4. L4-7 应计利息 ↔ L2 应付利息 / L8 财务费用是否核对一致？
5. L4-5 可转债权益/负债成分分拆是否有据？
6. 附注品种金额、一年内到期重分类是否等于 L4-1 审定？
