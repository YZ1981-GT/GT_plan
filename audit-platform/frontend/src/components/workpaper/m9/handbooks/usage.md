# M9 其他综合收益 — 平台使用手册

> 配合「编制手册」页签使用。本手册只说明**平台怎么操作**；审计目标与勾稽逻辑见编制手册。
> **不修改**各分表页内已有说明文案。入口：底稿目录页顶部「使用手册」按钮。

---

## 1. 打开与模式

1. 在项目底稿树打开 **M9 其他综合收益**（`componentType: m9-other-comprehensive-income`，覆盖科目 4103）。
2. 通过 sheet 页签切换分表（M9A、M9-1～M9-4、附注上市/国企、底稿目录）。
3. 复杂 sheet 支持结构化视图；以项目配置为准（目录页不显示双模式）。
4. 只读阶段工具栏「取数 / 回写 / 确认」类按钮会禁用。

---

## 2. 推荐操作路径（点击顺序）

| 步骤 | 分表 | 建议操作 |
|------|------|----------|
| 1 | M9A | 勾选实质性程序、填索引 |
| 2 | M9-2 | 录入 OCI 分项 + 税后净额（不可/可重分类双大类） |
| 3 | M9-4 | OCI 多来源核对（G8 公允变动 / J2 重计量 / 外币折算） |
| 4 | M9-1 | 确认审定（未审 + AJE + RJE，双大类小计）→ 回写 TB(4103) |
| 5 | 附注上市/国企 | 从审定表取数 → 同步附注模块 |

## 3. 目录页速查

| 区块 | 说明 |
|------|------|
| 编制进度 | 各分表按审计说明/结论填写情况计算完成度 |
| 跨表结论口径 | 每张表审计结论「已填/未填」标签，点击跳转对应 sheet 补全 |
| 底稿架构 | 4 阶段泳道（审计计划/科目审定/实质性程序/披露与调整），点击卡片跳转 |
| 本循环底稿目录 | 同循环其他科目（M1~M10），点击跳转（灰色表示尚未生成） |

## 4. 常见问题

| 现象 | 处理 |
|------|------|
| M9-1 审定 ≠ TB 数 | OCI 为权益类贷方（期末=期初+贷−借）；检查 M9-2 明细是否带入 |
| 明细合计与审定不符 | 复核 M9-2 各 OCI 分项税后净额、双大类划分是否齐全 |
| OCI 来源对不上 | 核对 M9-4 与 G8 公允变动、J2 重计量、外币折算差额 |
| 重分类不清 | 区分不可重分类（如权益工具公允变动）与可重分类（如外币折算差额） |
| 附注同步失败 | 检查项目 ID、附注模块权限与准则类型（上市/国企） |

## 5. 复核入口

各分表工具栏/结论区「复核」打开复核对话。合伙人级复核提示词参考：`backend/data/tsj_review_prompts/M/`（若环境已部署）。
