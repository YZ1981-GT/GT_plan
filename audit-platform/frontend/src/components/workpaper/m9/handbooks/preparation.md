# M9 其他综合收益 — 底稿编制手册

> **适用范围**：科目 **4103 其他综合收益（贷方/权益类，期末=期初+贷方−借方）**
> **组件**：`m9-other-comprehensive-income`
> **说明**：本手册说明各分表的审计目标、编制逻辑与勾稽关联，不替代各表页内已有说明文案。
> 平台按钮与操作步骤见「使用手册」页签。

---

## 1. 总体编制思路

其他综合收益（OCI）核实**不可重分类与可重分类项目的税后净额**：OCI 增加时贷方增加，减少/重分类进损益时借方减少。

| 证据链 | 主要底稿 | 回答的问题 |
|--------|----------|------------|
| **余额审定** | M9-1 审定（双大类：不可/可重分类） | OCI 期末余额是否准确完整？ |
| **分项明细** | M9-2 明细（OCI 分项 + 税后净额） | 各 OCI 分项税后净额是否准确？ |
| **多来源核对** | M9-4 OCI 核对（G8 公允变动 + J2 重计量 + 外币折算） | OCI 变动来源是否完整一致？ |

**枢纽原则**：

1. **权益类贷方科目**：期末 = 期初 + 贷方（OCI 增加）− 借方（OCI 减少/重分类进损益）。
2. **两大类**：不可重分类进损益的 OCI、可重分类进损益的 OCI（CAS30）。
3. **税后净额**：OCI 分项按税后净额列示。
4. **多来源核对**：接收 G8 其他权益工具公允变动、J2 重计量、外币报表折算差额。
5. **M9-1 是结论枢纽**：审定合计回写试算表 4103，并驱动附注披露。

### 建议编制顺序

```
M9A 程序计划
  → M9-2 明细（OCI 分项 + 税后净额，双大类）
  → M9-4 OCI 核对（G8 公允变动 + J2 重计量 + 外币折算）
  → M9-1 审定（未审 + AJE + RJE → 审定，双大类小计）→ 回写 TB(4103) → 附注上市/国企
  → M9-3 调整分录（借贷平衡，回写审定）
```

## 2. 分表编制说明

### M9A 实质性程序表
- **审计目标**：规划并记录其他综合收益实质性程序范围、性质与时间。
- **完成标志**：计划程序均有执行记录或「不适用」说明。

### M9-1 审定表（权益类贷方，双大类）
- **审计目标**：核实 OCI 期末余额准确完整；提供审定数。
- **编制逻辑**：审定 = 未审 + AJE + RJE；权益期末 = 期初 + 贷方 − 借方；按不可/可重分类双大类小计。
- **上游**：M9-2 明细；M9-3 确认回写。**下游**：TB(4103)、附注。
- **完成标志**：与 M9-2 明细合计勾稽；审计结论已填。

### M9-2 明细表（OCI 分项 + 税后净额）
- **审计目标**：核实各 OCI 分项税后净额准确。
- **完成标志**：明细合计与 M9-1 一致；审计说明已填。

### M9-3 调整分录汇总
- **审计目标**：核实调整完整、借贷平衡。
- **完成标志**：借贷平衡；已确认回写 M9-1。

### M9-4 OCI 核对表（多来源）
- **审计目标**：核实 OCI 变动与 G8 公允变动、J2 重计量、外币折算等来源一致完整。
- **完成标志**：多来源核对无差异；结论已填。

### 附注披露（上市/国企）
- **审计目标**：按附注格式披露其他综合收益（分项税后净额），与审定勾稽。
- **完成标志**：金额与 M9-1 审定一致；已同步附注模块。

### 底稿目录
- **审计目标**：导航与编制进度总览（跨表结论口径 + 底稿架构 + 本循环其他科目）。

## 4. 外部模块衔接

| 模块 | 与 M9 关系 |
|------|------------|
| **G8 其他权益工具投资** | 公允价值变动（不可重分类）→ M9-4 核对 |

| **外币报表折算** | 外币财务报表折算差额（可重分类）→ M9-4 核对 |
| **试算平衡表** | M9-1 审定余额回写 4103 |

## 5. 质量复核要点（摘要）

1. M9-2 明细合计 ↔ M9-1 审定是否勾稽？
2. OCI 分项是否正确划分不可/可重分类，是否按税后净额列示？
3. M9-4 与 G8 公允变动、J2 重计量、外币折算是否勾稽？
4. M9-1 审定 ↔ TB(4103) 是否勾稽？
5. 附注披露金额是否等于 M9-1 审定？
