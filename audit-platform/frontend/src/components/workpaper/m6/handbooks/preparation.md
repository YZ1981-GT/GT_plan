# M6 未分配利润 — 底稿编制手册

> **适用范围**：科目 **4104 利润分配-未分配利润（贷方/权益类，期末=期初+贷方−借方）**
> **组件**：`m6-retained-earnings`
> **说明**：本手册说明各分表的审计目标、编制逻辑与勾稽关联，不替代各表页内已有说明文案。
> 平台按钮与操作步骤见「使用手册」页签。

## 1. 总体编制思路

未分配利润是**利润分配的枢纽科目**：本年净利润转入时贷方增加，提取盈余公积/宣告股利时借方减少。

| 证据链 | 主要底稿 | 回答的问题 |
|--------|----------|------------|
| **余额审定** | M6-1 审定 ← M6-2 明细 | 未分配利润期末余额是否准确完整？ |
| **分配结转** | M6-2 明细（利润分配结转公式链，核心） | 净利润、盈余公积、股利结转是否准确？ |
| **合规检查** | M6-4 检查表 | 利润分配决议、结转处理是否合规？ |

**枢纽原则**：

1. **权益类贷方科目**：期末 = 期初 + 贷方（本年净利润转入）− 借方（提取盈余公积、宣告股利）。
2. **利润分配结转核心公式链**：期末 = 期初 + 本年净利润 − 提取盈余公积 − 宣告股利。
3. **上游接收本年利润**：本年净利润转入未分配利润。
4. **下游驱动 M5/M1**：提取盈余公积 → M5；宣告股利 → M1。
5. **M6-1 是结论枢纽**：审定合计回写试算表 4104，并驱动附注披露。

### 建议编制顺序

```
M6A 程序计划
  → M6-2 明细（利润分配结转公式链：期末=期初+净利润−盈余公积−股利）
  → M6-4 检查表（分配决议/结转合规）
  → M6-1 审定（未审 + AJE + RJE → 审定）→ 回写 TB(4104) → 附注上市/国企
  → M6-3 调整分录（借贷平衡，回写审定）
```

## 2. 分表编制说明

### M6A 实质性程序表
- **审计目标**：规划并记录未分配利润实质性程序范围、性质与时间。
- **完成标志**：计划程序均有执行记录或「不适用」说明。

### M6-1 审定表（权益类贷方）
- **审计目标**：核实未分配利润期末余额准确完整；提供审定数。
- **编制逻辑**：审定 = 未审 + AJE + RJE；权益期末 = 期初 + 贷方 − 借方。
- **上游**：M6-2 明细；M6-3 确认回写。**下游**：TB(4104)、附注、M5/M1。
- **完成标志**：与 M6-2 明细合计勾稽；审计结论已填。

### M6-2 明细表（利润分配结转公式链，核心）
- **审计目标**：核实净利润转入、盈余公积提取、股利宣告结转准确。
- **编制逻辑**：期末 = 期初 + 本年净利润 − 提取盈余公积 − 宣告股利。
- **完成标志**：结转公式链勾稽；明细合计与 M6-1 一致；审计说明已填。

### M6-3 调整分录汇总
- **审计目标**：核实调整完整、借贷平衡。
- **完成标志**：借贷平衡；已确认回写 M6-1。

### M6-4 未分配利润检查表
- **审计目标**：核实利润分配决议、结转处理合规。
- **完成标志**：分配决议凭证核对完整；结论已填。

### 附注披露（上市/国企）
- **审计目标**：按附注格式披露未分配利润，与审定勾稽。
- **完成标志**：金额与 M6-1 审定一致；已同步附注模块。

### 底稿目录
- **审计目标**：导航与编制进度总览（跨表结论口径 + 底稿架构 + 本循环其他科目）。

## 5. 质量复核要点（摘要）

1. M6-2 结转公式链（期末=期初+净利润−盈余公积−股利）是否勾稽？
2. M6-2 明细合计 ↔ M6-1 审定是否勾稽？
3. 净利润转入、盈余公积提取、股利宣告是否与 M5/M1 一致？
4. M6-1 审定 ↔ TB(4104) 是否勾稽？
5. 附注披露金额是否等于 M6-1 审定？
