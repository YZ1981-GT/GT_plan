# K6 持有待售资产和负债 — 底稿编制手册

> **适用范围**：**持有待售的非流动资产/处置组（资产 1481 借方）+ 持有待售负债（2605 贷方）**
> **准则**：**CAS42 持有待售的非流动资产、处置组和终止经营**
> **组件**：`k6-held-for-sale`
> **说明**：本手册说明各分表的审计目标、编制逻辑与勾稽关联，不替代各表页内已有说明文案。
> 平台按钮与操作步骤见「使用手册」页签。

---

## 1. 总体编制思路

K6 围绕 CAS42，把「持有待售」拆成分类计量与减值测试两条证据链，最后汇入审定与附注：

| 证据链 | 主要底稿 | 回答的问题 |
|--------|----------|------------|
| **分类与金额枢纽** | K6-4 初始确认 → K6-2 明细 → K6-1 审定 ← K6-3 调整 | 是否满足 CAS42 五条件分类？余额未审→调整→审定是否准确？ |
| **减值测试** | K6-5 减值 / K6-6 处置组减值 / K6-7 不再满足 | 孰低法计量与处置组分摊是否恰当？不再满足条件如何处理？ |

**枢纽原则**：

1. **K6-4 初始确认是分类前提**——CAS42 五条件全部满足方可分类为持有待售。
2. **K6-2 明细表是数据枢纽**——逐项登记处置组/资产基本信息。
3. **K6-5/K6-6 减值测试**——孰低法计量、处置组减值分摊。
4. **K6-3 是调整枢纽**——差异确认后回写 K6-1。
5. **K6-1 是结论枢纽**——与试算（1481 资产 + 2605 负债）、附注披露勾稽。

> **CAS42 五条件**：①可立即出售 ②已作出决议 ③已签不可撤销协议 ④预计 1 年内完成出售 ⑤售价合理不太可能变更。
> **减值孰低法**：账面价值 与 公允价值减出售费用净额 取低者，超出部分计提减值。处置组减值先抵减商誉，再按账面比例分摊至组内非流动资产。
> **方向铁律**：持有待售资产（1481）期末 = 期初 + 增加 − 减少 − 减值；持有待售负债（2605）期末 = 期初 + 增加 − 减少。

### 建议编制顺序（标准路径）

```
K6-4 初始确认（CAS42 五条件判断）
  → K6-2 明细（登记处置组/资产）
  → 减值测试：K6-5 孰低法 → K6-6 处置组分摊
  → K6-7 不再满足条件检查（较低者计量 + 重分类）
  → 差异汇入 K6-3 → 确认回写 K6-1（TB 1481+2605）
  → 附注上市 / 附注国企
```

可按项目风险裁剪（如无处置组可弱化 K6-6），但 **初始确认 K6-4 → 明细 → K6-1** 不宜省略。

## 2. 分表编制说明

每张表按统一结构：**审计目标 → 编制逻辑 → 上游/下游 → 完成标志**。

### K6A 实质性程序表
- **审计目标**：规划并记录针对持有待售的实质性程序范围、性质与时间。
- **完成标志**：计划程序均有执行记录或「不适用」说明。

### K6-1 审定表
- **审计目标**：核实持有待售资产与负债余额准确完整；分类列报恰当；提供审定数。
- **编制逻辑**：资产 + 负债双区块；未审 / 账项调整(AJE) / 重分类(RJE) / 审定；审定 = 未审 + AJE + RJE。
- **上游**：K6-2 明细 + 减值测试；K6-3 确认回写。**下游**：试算表(1481+2605)；附注。
- **完成标志**：与 TB 勾稽差异已解释；审计结论已填。

### K6-2 明细表（数据枢纽）
- **审计目标**：核实处置组/资产存在、完整、权利与计价。
- **编制逻辑**：逐项登记处置组/资产基本信息，动态行。
- **完成标志**：清单完整；与 K6-1 汇总一致。

### K6-3 调整分录汇总
- **审计目标**：核实调整完整、借贷平衡。
- **完成标志**：借贷平衡；已确认回写 K6-1；索引指向证据表。

### K6-4 初始确认检查表
- **审计目标**：核实是否满足 CAS42 五条件分类为持有待售。
- **编制逻辑**：估值表（公允价值三方法：销售协议价/活跃市场价/估计价）+ 出售费用 + 孰低净额 + CAS42 五条件核对。
- **完成标志**：五条件判断有据；满足方可分类；不满足终止分类。

### K6-5 减值准备测试表
- **审计目标**：核实持有待售后续计量减值（孰低法）恰当。
- **编制逻辑**：账面价值 vs 公允价值减出售费用净额，孰低计提减值。
- **完成标志**：孰低法计算准确；减值有据；与 K6-1 一致。

### K6-6 处置组减值测试表
- **审计目标**：核实处置组整体减值测算与分摊恰当。
- **编制逻辑**：(一)处置组减值测算（孰低）+ (二)按报表项目分摊（先抵商誉再按比例分摊至非流动资产）+ 勾稽一致。
- **完成标志**：应计提减值 ↔ 已分摊一致；与 K6-1 一致。

### K6-7 不再满足持有待售检查表
- **审计目标**：核实不再满足持有待售条件时的计量与重分类处理。
- **编制逻辑**：净额分解（原划归前账面 − 假设折旧摊销 − 假设减值）→ 较低者（可收回金额 vs 假设未分类账面）→ 重分类。
- **完成标志**：较低者计量有据；重分类处理恰当。

### 附注披露（上市/国企）
- **审计目标**：按附注格式披露持有待售分类、减值与已确认减值损失，与审定勾稽。
- **完成标志**：金额与 K6-1 审定一致；已同步附注模块。

### 底稿目录
- **审计目标**：导航与编制进度总览（跨表结论口径 + 底稿架构）。
- **完成标志**：计划执行的分表状态均为完成或已说明不适用。

## 5. 质量复核要点（摘要）

1. K6-4 五条件是否全部满足？公允价值三方法确定是否有据？
2. K6-5 孰低法与 K6-6 处置组分摊（先抵商誉再分摊）是否正确？应计提 ↔ 已分摊是否一致？
3. K6-7 不再满足条件时是否按较低者计量并重分类？
4. K6-3 已确认调整是否已回写 K6-1（1481+2605）？借贷是否平衡？
5. 附注金额是否等于 K6-1 审定？
