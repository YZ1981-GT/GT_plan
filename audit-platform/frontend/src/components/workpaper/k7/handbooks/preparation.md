# K7 递延收益 — 底稿编制手册

> **适用范围**：科目 **2401 递延收益（贷方/负债类）**（主要为政府补助递延，与资产相关/与收益相关）
> **准则**：**CAS16 政府补助**
> **组件**：`k7-deferred-income`
> **说明**：本手册说明各分表的审计目标、编制逻辑与勾稽关联，不替代各表页内已有说明文案。
> 平台按钮与操作步骤见「使用手册」页签。

---

## 1. 总体编制思路

K7 围绕 CAS16 政府补助，把「递延收益」拆成金额枢纽与分摊测算两条证据链，最后汇入审定与附注：

| 证据链 | 主要底稿 | 回答的问题 |
|--------|----------|------------|
| **金额枢纽** | K7-2 明细 → K7-1 审定 ← K7-3 调整 | 各项政府补助递延余额未审→调整→审定是否准确？ |
| **分摊测算** | K7-4 分摊测算 → K7-5 检查 | 分摊方法与金额是否恰当？分摊去向是否正确？ |

**枢纽原则**：

1. **K7-2 明细表是数据枢纽**——登记各项政府补助收到/分摊明细。
2. **K7-4 分摊测算**——复核分摊金额合理性（直线分摊/系统合理方法）。
3. **K7-3 是调整枢纽**——差异确认后回写 K7-1。
4. **K7-1 是结论枢纽**——与试算（2401）、附注披露勾稽。
5. **K7A 程序表**统领「做了哪些程序」；分表记录「证据与结论」。

> **CAS16 政府补助**：与资产相关→按资产使用寿命在使用期内直线分摊计入损益；与收益相关→用于补偿以后期间费用的分期计入，用于补偿已发生费用的一次性计入。
> **分摊去向**：与日常活动相关→其他收益（K10）；与日常活动无关→营业外收入（K12）。
> **方向铁律**：递延收益（2401）期末 = 期初 + 收到（增加） − 分摊（减少）。

### 建议编制顺序（标准路径）

```
K7-2 明细（登记各项政府补助收到/分摊）
  → K7-4 分摊测算（复核分摊金额 + 差异标记）
  → K7-5 检查（合规判断 + 抽凭）
  → 差异汇入 K7-3 → 确认回写 K7-1（TB 2401）
  → 附注上市 / 附注国企（按相关类型披露）
```

可按项目风险裁剪，但 **明细 → 分摊测算 → K7-1** 不宜省略。

## 2. 分表编制说明

每张表按统一结构：**审计目标 → 编制逻辑 → 上游/下游 → 完成标志**。

### K7A 实质性程序表
- **审计目标**：规划并记录针对递延收益的实质性程序范围、性质与时间。
- **完成标志**：计划程序均有执行记录或「不适用」说明。

### K7-1 审定表
- **审计目标**：核实递延收益各项余额准确完整；分类列报恰当；提供审定数。
- **编制逻辑**：按补助项目/相关类型展开；未审 / 账项调整(AJE) / 重分类(RJE) / 审定；审定 = 未审 + AJE + RJE。
- **上游**：K7-2 明细汇总 + K7-4 分摊测算；K7-3 确认回写。**下游**：试算表(2401)；附注。
- **完成标志**：与 TB 勾稽差异已解释；审计结论已填。

### K7-2 明细表（数据枢纽）
- **审计目标**：核实政府补助各项存在、完整、义务与计价。
- **编制逻辑**：逐项登记收到/分摊明细（3 区段 + 补助项目明细），期初 + 收到 − 分摊 = 期末滚动。
- **完成标志**：清单完整、滚动勾稽通过；与 K7-1 汇总一致。

### K7-3 调整分录汇总
- **审计目标**：核实调整完整、借贷平衡。
- **完成标志**：借贷平衡；已确认回写 K7-1；索引指向证据表。

### K7-4 分摊测算表
- **审计目标**：核实政府补助分摊方法与金额恰当。
- **编制逻辑**：与资产相关按资产使用寿命直线分摊；测算分摊 vs 账面分摊差异标记。
- **完成标志**：分摊方法有据；测算与明细分摊一致；差异已解释。

### K7-5 递延收益检查表
- **审计目标**：合规判断（确认条件/分类/分摊/披露）+ 凭证级抽查。
- **编制逻辑**：逐项合规/不合规/不适用判断 + 抽凭核对。
- **完成标志**：抽查比例达方案要求；异常已跟进。

### 附注披露（上市/国企）
- **审计目标**：按附注格式披露递延收益构成（按相关类型：与资产相关/与收益相关），与审定勾稽。
- **完成标志**：金额与 K7-1 审定一致；已同步附注模块。

### 底稿目录
- **审计目标**：导航与编制进度总览（跨表结论口径 + 底稿架构）。
- **完成标志**：计划执行的分表状态均为完成或已说明不适用。

| 列报与披露（按相关类型） | 附注上市/国企 |

## 4. 外部模块衔接

| 模块 | 与 K7 关系 |
|------|------------|
| **调整分录模块** | 与 K7-3 双向同步；确认驱动 K7-1 |
| **试算平衡表** | K7-1 审定回写 2401 |
| **K10 其他收益** | 与日常活动相关的政府补助分摊去向 |
| **K12 营业外收入** | 与日常活动无关的政府补助分摊去向 |
| **附注模块** | 递延收益披露（按相关类型） |

---

## 5. 质量复核要点（摘要）

1. K7-2 明细合计 ↔ K7-1 未审是否勾稽？
2. K7-4 测算分摊 ↔ 明细分摊是否一致？分摊方法是否恰当？
3. 分摊去向是否正确（其他收益 K10 / 营业外收入 K12）？
4. K7-3 已确认调整是否已回写 K7-1？借贷是否平衡？
5. 附注金额是否等于 K7-1 审定？是否按相关类型披露？
