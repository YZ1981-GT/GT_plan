# D7 合同负债 — 底稿编制手册

> **适用范围**：科目 **2205 合同负债**（CAS14 收入准则：已收或应收对价而尚未履约的义务）
> **组件**：`d7-contract-liabilities`
> **说明**：本手册说明各分表的审计目标、编制逻辑与勾稽关联。
> **不替代**各表页内已有的审计目标/过程提示文案（页内说明保持不变）。
> 平台按钮与操作步骤见「使用手册」页签。

---

## 1. 总体编制思路

D7 把「合同负债」拆成三条证据链，最后汇入审定与附注：

| 证据链 | 主要底稿 | 回答的问题 |
|--------|----------|------------|
| **金额枢纽** | D7-2 明细 → D7-1 ← D7-3 | 未审→调整→审定是否完整准确？ |
| **完整性/结转** | D7-4 分析；D7-5 账龄1年以上；D7-7 凭证检查 | 合同负债是否应结转收入而挂账？长期挂账合理？ |
| **关联方/披露** | D7-6 关联方；附注 | 关联方合同负债、账龄结构披露是否完整？ |

**枢纽原则**：

1. **D7-2 明细表是数据枢纽**——审定表按往来单位/账龄从明细带入。
2. **D7-3 是调整枢纽**——差异确认后回写 D7-1。
3. **D7-1 是结论枢纽**——与试算（2205）、附注披露勾稽。
4. **合同负债 ↔ 收入结转**——履约后结转营业收入（与 D4 勾稽）。

### 建议编制顺序（标准路径）

```
D7A 程序计划
  → D7-2 明细（先立清单，标注账龄）
  → D7-4 分析 → D7-7 凭证检查（存在/完整性）
  → D7-5 账龄1年以上检查（长期挂账合理性）
  → D7-6 关联方
  → 差异汇入 D7-3 → 确认回写 D7-1
  → 附注上市 / 附注国企
```

## 2. 分表编制说明

### D7A 实质性程序表
- **审计目标**：规划并记录合同负债实质性程序范围、性质与时间。
- **完成标志**：计划程序均有执行记录或「不适用」说明。

### D7-1 审定表
- **审计目标**：核实合同负债余额准确完整；按账龄/往来单位列报；提供审定数。
- **编制逻辑**：期初/期末 × 未审 / 账项调整 / 审定；按账龄段（动态账龄配置）展开；审定 = 未审 + 调整。
- **上游**：D7-2 汇总；D7-3 确认回写。**下游**：试算表（2205）；附注。
- **完成标志**：与 TB 勾稽差异已解释；结论已填。

### D7-2 明细表（数据枢纽）
- **审计目标**：核实存在、完整、义务与计价；逐往来单位列示账龄。
- **编制逻辑**：往来单位 × 账龄段；期末余额滚动；可从序时账导入。
- **下游**：D7-1、D7-4、D7-5 带入源。
- **完成标志**：清单完整、账龄勾稽通过；与 D7-1 汇总一致。

### D7-3 调整分录汇总
- **审计目标**：核实合同负债及相关科目调整完整、借贷平衡。
- **完成标志**：借贷平衡；已确认回写 D7-1。

### D7-4 合同负债分析表
- **审计目标**：分析合同负债构成、账龄结构、大额与异常变动的合理性。
- **完成标志**：重大变动已解释；D7↔D4 收入结转勾稽。

### D7-5 账龄1年以上检查
- **审计目标**：核查长期挂账合同负债的合理性——是否应确认收入、退回或转营业外收入。
- **编制逻辑**：逐笔列示挂账原因、处理结论；跨底稿联动（应确认收入→D4/应转营业外收入→K12/应退回→其他应付款）。
- **完成标志**：长期挂账处理结论已填。

### D7-6 关联方检查
- **审计目标**：识别关联方合同负债，核对披露完整性。
- **完成标志**：关联方合同负债已识别，与 B19 清单核对。

### D7-7 凭证检查
- **审计目标**：以凭证级检查佐证合同负债存在、结转真实。
- **编制逻辑**：记账凭证逐笔核对（原始凭证齐全/账务处理正确/会计期间恰当）；抽凭引擎科目 2205；可自动标记跨期。
- **完成标志**：抽查比例达方案要求；异常/跨期已跟进。

### 附注披露（上市/国企）
- **审计目标**：按附注格式披露合同负债账龄、前五名、关联方、预计确认收入时间，与审定勾稽。
- **完成标志**：金额与 D7-1 审定一致；已同步附注模块。

### 底稿目录
- **审计目标**：导航与编制进度总览（跨表结论口径 + 底稿目录表）。

## 5. 质量复核要点（摘要）

1. D7-2 合计 ↔ D7-1 未审是否勾稽？账龄段是否一致？
2. D7-3 已确认调整是否已体现在 D7-1？借贷是否平衡？
3. D7-5 长期挂账是否有处理结论？应确认收入的是否与 D4 勾稽？
4. D7-7 跨期项是否已标注处理？
5. 附注金额是否等于 D7-1 审定？
