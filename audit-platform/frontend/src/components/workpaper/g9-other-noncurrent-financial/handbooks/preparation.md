# G9 其他非流动金融资产 — 底稿编制手册

> **适用范围**：其他非流动金融资产（以公允价值计量且其变动计入当期损益的金融资产，FVTPL，且预计持有或变现期限在一年以上的非流动部分）。
> **组件**：GtBIndex 通用目录（G9 科目）
> **说明**：本手册说明各分表的审计目标、编制逻辑与勾稽关联，不替代各表页内已有说明文案。平台按钮与操作步骤见「使用手册」页签。

---

## 1. 总体编制思路

其他非流动金融资产核算按 CAS 22 分类为 **FVTPL（以公允价值计量且其变动计入当期损益）** 且非流动的金融资产，包括未通过 SPPI 测试或业务模式为交易的债务工具、未指定为 FVOCI 的权益工具、衍生工具等预计一年以上变现部分。其核算要点：**账面按公允价值计量，公允价值变动直接计入当期损益（公允价值变动损益，进 G13）；不计提减值（FVTPL 无 ECL）；相关利息/股利计入投资收益**。它与交易性金融资产（G1，流动）的区别仅在于流动性分类（预计持有期限一年以上）。审计核心是公允价值计量、分类（流动 vs 非流动）、损益归属的正确性。

| 证据链 | 主要底稿 | 回答的问题 |
|--------|----------|------------|
| 账面是否真实 | G9-2 明细、公允价值来源 | 成本、期末公允价值、公允价值变动是否准确 |
| 分类是否恰当 | 明细、持有期判断 | 流动/非流动划分、FVTPL 分类是否成立 |
| 损益归属 | 公允价值变动核对、投资收益核对 | 公允价值变动计入 G13、利息/股利计入 G11 |
| 审定是否正确 | G9-1 审定表 | 未审→调整→审定，与 TB 及明细勾稽 |
| 披露是否完整 | 附注（上市/国企） | 公允价值层次、变动损益披露 |

### 建议编制顺序

```
G9-2 明细(成本/公允价值/变动) → 公允价值变动损益核对 → G9-3 调整 → 回写 G9-1 审定 → 勾稽 TB → 附注(上市/国企)
```

## 2. 分表编制说明

### G9-1 审定表
汇总其他非流动金融资产未审数、账项/重分类调整、审定数，回写 TB，与 G9-2 明细合计勾稽。

### G9-2 明细表
逐笔列示金融资产名称/类型（债务工具/权益工具/衍生工具）、取得成本、期末公允价值、本期公允价值变动、预计变现期限（判断非流动）。

### G9-3 调整分录
录入 AJE/RJE 回写 G9-1 审定表调整列，可推送 A13。

### 附注（上市 / 国企）
按公允价值层次（Level 1/2/3）、本期公允价值变动损益披露；数据取自 G9-2 明细。

## 3. 认定覆盖速查

| 认定 | 主要底稿 |
|------|----------|
| 存在 | G9-2 明细、权属证明 |
| 完整性 | G9-1 审定、TB 勾稽 |
| 权利和义务 | 合同/协议、受限情况 |
| 计价和分摊 | 公允价值计量、流动/非流动分类 |
| 列报和披露 | 附注（上市/国企） |

## 4. 外部模块衔接

| 模块 | 关系 |
|------|------|
| TB 试算平衡表 | G9-1 审定合计回写对应科目 |
| G13 公允价值变动损益 | 本科目公允价值变动计入 G13（FVTPL） |
| G11 投资收益 | 持有期利息/股利、处置损益计入投资收益 |
| G1 交易性金融资产 | 同为 FVTPL，仅流动性分类不同（G9 非流动） |
| A13 未更正错报 | G9-3 调整分录推送 |
| 附注模块 | 披露表数据同步 |

## 5. 质量复核要点（摘要）

1. FVTPL 分类是否成立（未通过 SPPI / 业务模式为交易 / 未指定 FVOCI）。
2. 流动 / 非流动划分是否恰当（预计变现期限一年以上）。
3. 公允价值计量输入值与层次是否恰当，Level 3 是否有估值依据。
4. 公允价值变动**是否正确计入当期损益（G13）**、**是否未误计提减值**。
5. G9-1 审定合计 = G9-2 明细合计 = TB。
