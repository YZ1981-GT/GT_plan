# D4 营业收入 — 平台使用手册

> 配合「编制手册」页签使用。本手册只说明**平台怎么操作**；审计目标与勾稽逻辑见编制手册。
> **不修改**各分表页内已有说明文案。入口：底稿目录页顶部「使用手册」按钮。

---

## 1. 打开与模式

1. 在项目底稿树打开 **D4 营业收入**（`componentType: d4-operating-revenue`，覆盖科目 6001/6051）。
2. 通过 sheet 页签切换分表（D4A、D4-1～D4-36、附注上市/国企、底稿目录）。
3. 目录页顶部可切换分组标签；IPO/舞弊组、出口核对按项目性质自动适用/不适用（灰色）。
4. 复杂 sheet 支持 **结构化 HTML ↔ OnlyOffice** 双模式；以项目配置为准（目录页除外）。
5. 只读阶段工具栏「取数 / 回写 / 确认」类按钮会禁用。

**需要项目上下文的操作**：D4-2 序时账取数、D4-14 抽凭、D4-17/D4-18 截止自动抽样、附注「同步到附注模块」。

## 2. 推荐操作路径（点击顺序）

| 步骤 | 分表 | 建议操作 |
|------|------|----------|
| 1 | D4A | 勾选实质性程序、填索引 |
| 2 | D4-2 / D4-3 | 「从序时账取数」录入主营/其他业务收入明细 |
| 3 | D4-5 / D4-12 / D4-13 | 政策 → 合同 → ERP 核对 |
| 4 | D4-14 / D4-17 / D4-18 | 发生检查（抽凭）、截止测试（自动抽样） |
| 5 | D4-15 / D4-16 | 完整性、出口核对（如适用） |
| 6 | D4-6～D4-11 | 分析程序（指标/毛利/客户/价格） |
| 7 | D4-19 / D4-20 / D4-21 | 折扣折让 / 退货 / 关联方价格 |
| 8 | D4-22～D4-32 | IPO/舞弊专项（如适用） |
| 9 | D4-33～D4-36 | 其他业务收入 |
| 10 | D4-4 | 调整分录汇总 → 确认 → 回写 D4-1（可推 A13） |
| 11 | D4-1 | 从明细带入 → 核对调整回写 → 勾稽 TB/利润表 |
| 12 | 附注上市/国企 | 拉取上游 → 编辑 → 同步附注模块 |

## 3. 目录页速查

| 区块 | 说明 |
|------|------|
| 编制进度 | 各分表填妥「审计说明或结论」即计入完成 |
| 跨表结论口径 | 每张表审计结论「已填/未填」标签，点击跳转对应 sheet 补全 |
| 编制提示 | 折叠展开，推荐编制工作流 |
| 底稿目录表 | 逐 sheet 名称/编码/分组/适用性，索引跳转 |
| 本循环底稿目录 | 同循环（D 循环）其他底稿（灰色表示未生成） |

---

## 4. 导入导出

- 工具栏「导入导出▾」按当前 sheet 作用（如 D4-2 主营业务收入明细）。
- 导入后刷新当前表；若改了明细，请重新对 D4-1 执行「从明细带入」。

---

## 5. 常见问题

| 现象 | 处理 |
|------|------|
| D4-1 审定合计 ≠ TB/利润表数 | 检查明细是否全部带入、调整是否已确认回写 |
| D4-2 序时账取数无数据 | 确认序时账已导入且科目 6001 有发生额 |
| 截止自动抽样无数据 | 确认序时账已导入且基准日正确 |
| IPO 组灰色不可点 | 项目非 IPO/舞弊场景，正常不适用 |
| 附注同步失败 | 检查项目 ID、附注模块权限与准则类型（上市/国企） |
