# D4 营业收入 — 底稿编制手册

> **适用范围**：科目 **6001 主营业务收入 / 6051 其他业务收入**（CAS14 收入准则）
> **组件**：`d4-operating-revenue`
> **说明**：本手册说明各分表的审计目标、编制逻辑与勾稽关联。
> **不替代**各表页内已有的审计目标/过程提示文案（页内说明保持不变）。
> 平台按钮与操作步骤见「使用手册」页签。

## 1. 总体编制思路

D4 把「营业收入」拆成五组证据链，最后汇入审定与附注：

| 证据链 | 主要底稿 | 回答的问题 |
|--------|----------|------------|
| **金额枢纽** | D4-2/D4-3 明细 → D4-1 ← D4-4 | 未审→调整→审定是否完整准确？ |
| **发生/截止** | D4-14 发生检查；D4-17/D4-18 截止；D4-12 合同；D4-13 ERP | 收入真实发生、记于恰当期间？ |
| **完整性** | D4-15 完整性；D4-16 出口核对 | 收入是否完整、无漏记？ |
| **分析程序** | D4-6~D4-11 指标/毛利/客户/价格 | 收入趋势、毛利率、价格是否合理？ |
| **IPO/舞弊** | D4-22~D4-32 IPO 专项 | 舞弊风险应对（发票比对、资金流水、访谈）？ |

**枢纽原则**：

1. **D4-2/D4-3 明细表是数据枢纽**——审定表从明细带入，可从序时账按产品×月导入。
2. **D4-4 是调整枢纽**——差异确认后回写 D4-1。
3. **D4-1 是结论枢纽**——与试算（6001+6051）、附注披露、利润表勾稽。
4. **发生认定是收入核心风险**——CAS14 五步法 + 截止测试双向。

### 建议编制顺序（标准路径）

```
D4A 程序计划
  → D4-2/D4-3 明细（先立清单，可从序时账取数）
  → D4-5 政策 → D4-12 合同 → D4-13 ERP 核对
  → 发生/截止：D4-14 发生 / D4-17·D4-18 截止 / D4-16 出口
  → 完整性：D4-15
  → 分析：D4-6~D4-11 / D4-19 折扣 / D4-20 退货 / D4-21 关联方价格
  → IPO/舞弊（如适用）：D4-22~D4-32
  → 其他业务收入：D4-33~D4-36
  → 差异汇入 D4-4 → 确认回写 D4-1 → 附注上市/国企
```

按项目性质裁剪：IPO/舞弊组仅 IPO 项目适用；出口核对仅有出口业务适用。

## 2. 分表编制说明（分组）

### 核心组
- **D4A 收入审计程序表**：规划实质性程序，记录执行与索引。
- **D4-1 审定表**：核实主营+其他业务收入准确完整；审定=未审+调整；上游 D4-2/D4-3，下游 TB(6001/6051)/附注/利润表。
- **D4-2 主营业务收入明细表**：按产品/客户×月列示；可从序时账按产品×月导入（贷方净额）。
- **D4-3 其他业务收入明细表**：其他业务收入按类别列示。
- **D4-4 调整分录汇总**：借贷平衡；确认回写 D4-1；可推 A13 错报。
- **附注上市/国企**：按收入准则披露收入分解（时点/时段、地区、产品），与审定勾稽。

### 政策组
- **D4-5 会计政策检查**：收入确认政策符合 CAS14（五步法、时点/时段判断）。

### 分析程序组
- **D4-6 重要指标分析**：收入增长率、周转、占比。
- **D4-7 毛利率分析表 / D4-8 重要产品毛利分析**：毛利率月度/产品维度异常识别。
- **D4-9 客户结构 / D4-10 客户价格 / D4-11 产品价格分析**：重要客户与价格合理性。

### 检查程序组
- **D4-12 合同检查表**：合同关键条款（履约义务、交易价格、控制权转移）。
- **D4-13 ERP 系统核对**：账面收入与业务系统数据核对。
- **D4-14 发生检查表**：抽凭佐证收入真实发生（抽凭引擎科目 6001）。
- **D4-15 完整性检查表**：反向检查收入完整（发货/开票→收入）。
- **D4-16 出口收入电子口岸核对**：出口业务报关数据核对（有出口才适用）。
- **D4-17 截止测试（账到单据）/ D4-18 截止测试（单据到账）**：资产负债表日前后凭证抽取，判断跨期（可从序时账自动抽样）。
- **D4-19 折扣折让 / D4-20 退货检查**：可变对价、退货冲减合理性。

### 关联方组
- **D4-21 关联方销售价格分析**：关联方交易价格公允性。

### IPO/舞弊组（仅 IPO 项目适用）
- **D4-22A/D4-22 IPO 程序/指标**、**D4-23 收入与开票比较**、**D4-24 第三方回款**、**D4-25 经销商检查**、**D4-26 境外销售**、**D4-27 识别未披露关联方**、**D4-28~D4-32 客户核查/访谈/资金流水**。

### 其他收入组
- **D4-33 其他业务毛利率 / D4-34 其他业务合同测算 / D4-35 其他业务检查 / D4-36 其他业务截止测试**。

### 底稿目录
- 导航与编制进度总览（跨表结论口径 + 底稿目录表）。

## 5. 质量复核要点（摘要）

1. D4-2/D4-3 合计 ↔ D4-1 未审是否勾稽？
2. D4-4 已确认调整是否已体现在 D4-1？借贷是否平衡？
3. D4-14 发生 + D4-15 完整性覆盖是否充分？截止跨期是否处理？
4. 毛利率/价格分析异常是否已解释？
5. 附注收入分解是否等于 D4-1 审定？利润表是否勾稽？
