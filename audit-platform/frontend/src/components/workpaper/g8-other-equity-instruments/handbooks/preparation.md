# G8 其他权益工具投资 — 底稿编制手册

> **适用范围**：科目 1522 其他权益工具投资（初始确认时**指定**为以公允价值计量且其变动计入其他综合收益的**权益工具**投资，FVOCI 权益工具，指定不可撤销）。
> **组件**：GtBIndex 通用目录（G8 科目）
> **说明**：本手册说明各分表的审计目标、编制逻辑与勾稽关联，不替代各表页内已有说明文案。平台按钮与操作步骤见「使用手册」页签。

---

## 1. 总体编制思路

其他权益工具投资是 CAS 22 下企业**在初始确认时不可撤销地指定**为 FVOCI 的非交易性权益工具投资。其核算要点与债务工具的 FVOCI（G6）截然不同：**①公允价值变动计入其他综合收益（OCI）②处置时 OCI 累计公允价值变动不结转损益，而是直接转入留存收益 ③持有期间取得的股利（除属于投资成本收回部分外）计入投资收益 ④不计提减值（权益工具无 ECL）**。审计核心是验证「指定」的合规性（初始确认时、不可撤销、非交易性）、公允价值计量、OCI 变动与处置结转留存收益的正确性。

| 证据链 | 主要底稿 | 回答的问题 |
|--------|----------|------------|
| 指定是否合规 | G8 明细、指定文件 | 是否初始确认时不可撤销指定、是否非交易性权益工具 |
| 账面是否真实 | G8-2 明细、公允价值来源 | 成本、公允价值、OCI 累计变动是否准确 |
| 股利/处置是否正确 | 明细、投资收益核对 | 股利计入投资收益、处置 OCI 转留存收益是否正确 |
| 审定是否正确 | G8-1 审定表 | 未审→调整→审定，与 TB 1522 及明细勾稽 |
| 披露是否完整 | 附注（上市/国企） | 指定原因、公允价值层次、股利、处置披露 |

### 建议编制顺序

```
指定合规性检查 → G8-2 明细(成本/公允价值/OCI变动/股利) → G8-3 调整 → 回写 G8-1 审定 → 勾稽 TB(1522) → 附注(上市/国企)
```

## 2. 分表编制说明

### G8-1 审定表
汇总其他权益工具投资未审数、账项/重分类调整、审定数，回写 TB 1522，与 G8-2 明细合计勾稽。

### G8-2 明细表
逐笔列示投资对象、持股比例、取得成本、期末公允价值、公允价值累计变动（计入 OCI）、本期取得股利、指定为 FVOCI 的原因。**注意：不设减值准备列（权益工具不计提减值）**。

### G8-3 调整分录
录入 AJE/RJE 回写 G8-1 审定表调整列，可推送 A13。

### 附注（上市 / 国企）
披露指定为 FVOCI 的原因、公允价值层次（Level 1/2/3）、本期确认的股利收入、处置情况及处置时转入留存收益的累计利得/损失；数据取自 G8-2 明细。

## 3. 认定覆盖速查

| 认定 | 主要底稿 |
|------|----------|
| 存在 | G8-2 明细、权属证明 |
| 完整性 | G8-1 审定、TB 勾稽 |
| 权利和义务 | 指定文件、股权协议 |
| 计价和分摊 | 公允价值计量、OCI 变动、股利归属 |
| 列报和披露 | 附注（上市/国企） |

## 4. 外部模块衔接

| 模块 | 关系 |
|------|------|
| TB 试算平衡表 | G8-1 审定合计回写 1522 |
| G11 投资收益 | 持有期股利计入投资收益（非成本收回部分） |
| 权益/留存收益 | 处置时 OCI 累计变动转入留存收益（不进损益） |
| A13 未更正错报 | G8-3 调整分录推送 |
| 附注模块 | 披露表数据同步 |

## 5. 质量复核要点（摘要）

1. 指定为 FVOCI 是否满足「初始确认时、不可撤销、非交易性权益工具」条件。
2. 公允价值计量输入值与层次是否恰当，Level 3 是否有估值依据。
3. **是否未误计提减值**（权益工具不计提 ECL）。
4. 股利是否正确计入投资收益，处置时 OCI **是否正确转入留存收益而非损益**。
5. G8-1 审定合计 = G8-2 明细合计 = TB 1522。
