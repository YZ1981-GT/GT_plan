# N5 所得税费用 — 平台使用手册

> 配合「编制手册」页签使用。本手册只说明**平台怎么操作**；审计目标与勾稽逻辑见编制手册。
> **不修改**各分表页内已有说明文案。入口：底稿目录页顶部「使用手册」按钮。

---

## 1. 打开与模式

1. 在项目底稿树打开 **N5 所得税费用**（`componentType: n5-income-tax-expense`，覆盖科目 6801）。
2. 通过 sheet 页签切换分表（N5A、N5-1～N5-8、N5-6-1、N5-6-2、附注上市/国企、底稿目录）。
3. 复杂 sheet 支持 **结构化 HTML ↔ OnlyOffice** 双模式；以项目配置为准（目录页不显示双模式）。
4. 只读阶段工具栏「取数 / 回写 / 确认」类按钮会禁用。

---

## 2. 推荐操作路径（点击顺序）

| 步骤 | 分表 | 建议操作 |
|------|------|----------|
| 1 | N5A | 勾选实质性程序、填索引 |
| 2 | N5-5 / N5-6 / N5-6-1 / N5-6-2 / N5-7 | 纳税调整、税收优惠、研发加计、高新认定、财产损失 |
| 3 | N5-4 | 当期所得税：会计利润 ± 调整 → 应纳税所得额 × 税率 |
| 4 | N5-8 | 递延所得税费用核对（N1/N3 本期变动） |
| 5 | N5-1 | 确认当期 + 递延 → 合计 → 回写 TB(6801) |
| 6 | 附注上市/国企 | 从审定表取数 → 有效税率调节表 → 同步附注模块 |

## 4. 常见问题

| 现象 | 处理 |
|------|------|
| N5-1 审定 ≠ TB 数 | 所得税费用取本期发生额（非期末余额）；检查 N5-4/N5-8 是否带入 |
| 递延所得税费用不符 | 复核 N5-8 与 N1 递延税资产、N3 递延税负债本期变动是否一致 |
| 有效税率异常 | 有效税率 = 所得税费用 ÷ 会计利润；异常需在说明中解释（优惠/永久性差异等） |
| 研发加计扣除为空 | 检查 I6 研发费用（费用化）/ I2 开发支出（资本化）是否已接入 N5-6-1 |
| 附注同步失败 | 检查项目 ID、附注模块权限与准则类型（上市/国企） |

各分表工具栏/结论区「复核」打开复核对话。合伙人级复核提示词参考：`backend/data/tsj_review_prompts/N/`（若环境已部署）。
