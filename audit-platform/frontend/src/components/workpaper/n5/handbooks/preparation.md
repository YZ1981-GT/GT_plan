# N5 所得税费用 — 底稿编制手册

> **适用范围**：科目 **6801 所得税费用（借方/损益类，取本期发生额）**
> **组件**：`n5-income-tax-expense`
> **说明**：本手册说明各分表的审计目标、编制逻辑与勾稽关联，不替代各表页内已有说明文案。
> 平台按钮与操作步骤见「使用手册」页签。

---

## 1. 总体编制思路

所得税费用 = **当期所得税费用 + 递延所得税费用**。当期所得税以应纳税所得额（会计利润 ± 纳税调整）为基础，递延部分核对 N1/N3 本期变动。

| 证据链 | 主要底稿 | 回答的问题 |
|--------|----------|------------|
| **当期所得税** | N5-4 计算表 ← N5-5 纳税调整 + N5-6 税收优惠 | 应纳税所得额与当期所得税是否准确？ |
| **递延所得税** | N5-8 递延核对 ← N1/N3 本期变动 | 递延所得税费用与 N1/N3 变动是否一致？ |
| **结论枢纽** | N5-1 审定 ← N5-4 + N5-8 | 所得税费用合计是否准确完整？ |

**枢纽原则**：

1. **损益类借方科目**：取本期发生额（借方发生 − 贷方发生），非期末余额。
2. **当期所得税** = 应纳税所得额 × 适用税率 − 减免税额 − 抵免税额；应纳税所得额 = 会计利润 + 纳税调增 − 纳税调减。
3. **递延所得税费用** = 递延税负债本期增加 − 递延税资产本期增加（核对 N1/N3）。
4. **有效税率** = 所得税费用 ÷ 会计利润（合理性分析，异常需说明）。
5. **N5-1 是结论枢纽**：当期 + 递延 → 所得税费用合计，回写试算表 6801（发生额口径）。

### 建议编制顺序

```
N5A 程序计划
  → N5-5 纳税调整明细 + N5-6/N5-6-1/N5-6-2 税收优惠·研发加计·高新认定 + N5-7 财产损失
  → N5-4 当期所得税计算（会计利润 ± 调整 → 应纳税所得额 × 税率）
  → N5-8 递延所得税费用核对（N1/N3 本期变动）
  → N5-1 审定（当期 + 递延 → 合计）→ 回写 TB(6801) → 附注上市/国企
```

## 2. 分表编制说明

### N5A 实质性程序表
- **审计目标**：规划并记录所得税费用实质性程序范围、性质与时间。
- **完成标志**：计划程序均有执行记录或「不适用」说明。

### N5-1 审定表（损益类借方，取发生额）
- **审计目标**：核实所得税费用（当期 + 递延）合计准确完整；提供审定数。
- **编制逻辑**：所得税费用 = 当期所得税（N5-4）+ 递延所得税费用（N5-8）。
- **上游**：N5-4、N5-8；N5-3 确认回写。**下游**：TB(6801 发生额)、利润表、附注。
- **完成标志**：与 N5-4/N5-8 勾稽；有效税率合理性已分析；审计结论已填。

### N5-2 明细表
- **审计目标**：核实所得税费用当期/递延分项列示准确。
- **完成标志**：分项合计与 N5-1 一致。

### N5-3 调整分录汇总
- **审计目标**：核实调整完整、借贷平衡。
- **完成标志**：借贷平衡；已确认回写 N5-1。

### N5-4 当期所得税费用计算表（核心）
- **审计目标**：核实应纳税所得额与当期所得税计算准确。
- **编制逻辑**：会计利润 ± 纳税调整（N5-5）− 优惠（N5-6）→ 应纳税所得额 × 税率。
- **完成标志**：与 N5-1 当期所得税行一致。

### N5-5 纳税调整明细表
- **审计目标**：核实纳税调增/调减项目完整、准确。
- **完成标志**：调整合计带入 N5-4；结论已填。

### N5-6 税收优惠明细表
- **审计目标**：核实减免税、抵免适用合规。
- **完成标志**：优惠依据充分；结论已填。

### N5-6-1 加计扣除研发费用情况明细表
- **审计目标**：核实研发费用加计扣除的归集与比例合规。
- **编制逻辑**：接 I6 研发费用（费用化）/ I2 开发支出（资本化）。
- **完成标志**：加计扣除额测算有据；结论已填。

### N5-6-2 高新技术企业认定条件检查表
- **审计目标**：核实高新技术企业认定条件满足（享受 15% 优惠税率前提）。
- **完成标志**：认定条件逐项核对；结论已填。

### N5-7 财产损失明细表
- **审计目标**：核实资产损失税前扣除的证据与合规。
- **完成标志**：损失清单完整、扣除依据充分；结论已填。

### N5-8 递延所得税费用核对表
- **审计目标**：核实递延所得税费用与 N1/N3 本期变动一致。
- **编制逻辑**：递延所得税费用 = 递延税负债本期增加 − 递延税资产本期增加。
- **完成标志**：与 N1/N3 变动勾稽；与 N5-1 递延行一致。

### 附注披露（上市/国企）
- **审计目标**：按附注格式披露所得税费用及有效税率调节表，与审定勾稽。
- **完成标志**：金额与 N5-1 审定一致；已同步附注模块。

### 底稿目录
- **审计目标**：导航与编制进度总览（跨表结论口径 + 底稿架构 + 本循环其他科目）。

## 5. 质量复核要点（摘要）

1. N5-4 当期所得税（会计利润 ± 调整 × 税率）↔ N5-1 当期行是否勾稽？
2. N5-8 递延所得税费用 ↔ N1/N3 本期变动是否一致？
3. N5-1 合计（当期 + 递延）↔ TB(6801 发生额) 与利润表是否勾稽？
4. 有效税率是否合理，异常项是否已解释？
5. 附注有效税率调节表金额是否等于 N5-1 审定？
