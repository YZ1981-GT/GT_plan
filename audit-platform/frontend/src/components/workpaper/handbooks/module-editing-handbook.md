# 底稿编制模块 · 使用手册

> 本手册面向审计项目组，一页讲清"底稿从裁剪到归档"的全流程、每一步该做什么、由谁做、以及常见注意事项。读完本手册即可掌握模块的主要功能。

---

## 一、模块总览

底稿编制模块围绕**审计生命周期 6 个阶段**顺序推进，左侧导航条即为这 6 个阶段，进度条实时反映各阶段完成度：

| 序号 | 阶段 | 核心动作 | 主要角色 |
|------|------|----------|----------|
| 1 | 程序裁剪 | 按风险评估裁掉不适用的审计程序 | 业务合伙人 / 现场经理 |
| 2 | 底稿生成 | 基于裁剪结果一键生成底稿、附注、报表 | 现场经理 |
| 3 | 委派执行 | 把底稿分派给具体审计员 | 现场经理 |
| 4 | 编制 | 审计员填写底稿、取数、附证据 | 审计助理 |
| 5 | 复核 | 一级 / 二级复核、批注、退回 | 现场经理 / 合伙人 |
| 6 | 归档 | 满足前置条件后归档定稿 | 合伙人 / 质控复核 |

> **顺序依赖**：上一阶段未完成会阻塞下一阶段。例如"未裁剪的循环底稿无法启动后续步骤"。

### 五类角色分工

| 角色 | 在本模块的职责 |
|------|----------------|
| 审计助理 | 现场执行：底稿编制、取数、OCR、调整分录录入 |
| 现场经理 | 进度把控、底稿一级复核、任务分派、程序裁剪 |
| 业务合伙人 | 重大事项决策、审计判断、程序裁剪、签字 |
| 质量控制复核合伙人 | 质控规则、独立质量复核 |
| EQCR 技术复核人 | 项目质量控制复核（技术层面独立复核） |

## 二、程序裁剪（第 1 步）

### 2.1 为什么要裁剪

风险导向审计要求"把资源投到有风险的地方"。裁剪 = **把与本项目不相关、无风险敞口的审计程序标记为"不适用"**，不生成对应底稿，避免无谓工作量。

### 2.2 两层裁剪（重要概念）

平台把裁剪分为**粗裁**和**细裁**两层，职责不同、入口不同：

| 层级 | 做什么 | 在哪里做 | 谁能做 |
|------|--------|----------|--------|
| **粗裁** | 决定"整张底稿是否执行" + 指定该底稿的**主编** | 本页「配置裁剪」 | 项目经理 / 合伙人 |
| **细裁** | 决定"底稿内每条程序是否适用" + 委派**程序执行人 / 操作复核人** | 进入底稿的程序表控制台 | 项目经理 / 合伙人 |

> 高阶复核（合伙人、质控、EQCR）由底稿层 / 项目层机制负责，**不**在程序行里显示为复核人。

### 2.3 如何裁剪

点击右上角**「配置裁剪」**进入裁剪页，可以：

- **按循环切换**（A 报表 / B 计划 / C 控制 / D~N 实质性 / S 专项）逐个循环处理；
- **适用性开关**：每条程序一键切换"执行 / 裁剪"；
- **批量操作**：一键全部执行 / 全部不适用；
- **一键智能裁剪**：系统读取试算表数据，**只裁掉"科目无数据"的循环**，有数据的科目一律保留（宁松勿紧）；取数失败时**不裁任何程序**（安全兜底）；
- **参照其他项目**：套用历史项目的裁剪方案；
- **新增自定义程序**：源模板没有、但本项目需要的程序可手动新增。

### 2.4 裁剪注意事项

> ⚠️ 以下几点直接影响合规性与数据正确性，务必留意。

1. **裁剪理由必填**：任何被裁剪的程序都必须填写裁剪理由，否则**无法保存**（审计轨迹硬性要求）。
2. **切换循环前先保存**：在某循环改了适用性 / 理由后，切到别的循环或离开页面会提示"未保存将丢失"，请先点「保存粗裁」。
3. **智能裁剪≠全部裁光**：它按"科目有无试算表数据"判断，不会把有余额的科目裁掉；若试算表尚未导入，会提示且不裁。
4. **恢复初始**会把适用性、裁剪理由、以及已持久化的委派一并回滚到初始状态。
5. **权限**：非项目经理 / 合伙人角色看到的是**只读**视图，无法裁剪或委派。

## 三、底稿生成（第 2 步）

裁剪定稿后，点**「一键生成底稿+附注」**：

- 按裁剪结果批量生成需要的底稿、附注、报表；
- 自动触发跨模块联动公式（试算表 → 底稿 → 报表 → 附注）；
- 生成结果可在"智能推荐"里看到系统建议补充的底稿。

> 生成是幂等的：已生成的底稿不会重复创建。裁剪掉的程序**不会**生成底稿。

---

## 四、委派人员与委派步骤（第 3 步）

### 4.1 委派矩阵

点**「前往委派矩阵」**打开"成员 × 业务循环"热力图，一屏看清谁负责哪些循环、进度如何、谁负载偏高。支持：

- **编制人 / 复核人**两个维度切换（看每张底稿是否都配了编制人、是否都配了复核人）；
- **负载均衡**提示（人均/最多/最少，负载偏高的成员标红）；
- **按循环筛选**、**导出 Excel**。

### 4.2 委派步骤

1. 在矩阵里**点击某个格子**（成员 × 循环），或点未分配循环的标签；
2. 弹出**委派对话框**：选择候选人 → 预览待委派底稿清单 → 确认；
3. 确认后系统走**增强委派**流程：校验权限、发送**通知**给被委派人。

> ⚠️ 委派动作都有**确认弹窗**，不会"点一下就把整批甩出去"。系统会做**职责分离校验**（程序执行人不应等于操作复核人）。

### 4.3 底稿可见性隔离（重要）

被委派人登录后**只能看到分配给自己的底稿**，未委派给他的底稿在列表、编辑、下载、附件等各处统一不可见（服务端强制隔离，非前端隐藏）。这保证了现场分工的信息边界。

### 4.4 待我协作 / 通知

- 被指派协作补充调整分录时，会收到**通知**，点通知可直达对应分录组；
- 中央台有「待我协作」收件箱，集中查看需要自己接力的事项。

## 五、编制（第 4 步）

### 5.1 底稿导航

编制阶段按**审计循环 → 科目底稿 → 子底稿**三层树形展示，可搜索编码/名称、展开/收起、按"全部 / 我的"过滤。点击底稿即进入编制界面。

### 5.2 底稿内的主要功能

进入任意底稿，常见能力如下（不同底稿按需提供）：

| 功能 | 说明 |
|------|------|
| **结构化 / 在线编辑双模式** | 结构化视图点点点录入；切换"在线编辑"用 OnlyOffice 编辑源 Excel（拉取成功才可切） |
| **自动取数 / 四表取数** | 从试算表、序时账等自动带出未审数，附来源公式可追溯 |
| **审定表回写** | 审定数自动回写试算表，并联动披露表、附注 |
| **调整分录** | 录入 AJE / RJE；可"同步到集中登记"多人协作，可从集中登记"带入调整" |
| **AI 辅助** | 审计说明 / 结论一键 AI 起草（可结合知识库文档、附件 OCR 上下文） |
| **附件与 OCR** | 上传支持性文件，行级 OCR 识别自动回填 |
| **公式管理** | 查看/编辑本底稿的取数与勾稽公式，公式列虚线下划线可查来源 |
| **复核对话** | 每个说明区旁的复核圆点，发起/查看复核意见 |
| **版本历史** | 保存自动打快照，可查看/回滚历史版本 |
| **导入导出** | 明细表支持导出模板、导出数据、导入数据 |

### 5.3 编制注意事项

1. **金额单位默认"元"**（报表/附注呈现惯例），可在需要处切换万元/千元；界面全中文。
2. **审定表 → 披露表 → 附注是自动联动的**：改了审定数（含 AJE/RJE），披露与附注会自动跟随刷新，一般不需要在披露表单独再录一遍。
3. **勾稽告警**：审定合计与试算表、明细表不一致时会有告警提示，请按提示补录/核对。
4. **裁剪理由、审计结论**等文本区支持 AI 辅助，但**结论仍需审计师确认**。

---

## 六、复核（第 5 步）

点**「前往复核工作台」**：

- 一级 / 二级复核流程，支持批注、退回修改、强制通过；
- 底稿内复核圆点（蓝=有意见 / 红=未处理）直观反映复核状态；
- 可用"本页 AI 复核 / 批量 AI 复核"辅助，系统会把已算好的跨底稿勾稽数字注入，帮助判断而非空泛推断。

---

## 七、归档（第 6 步）

归档前系统检查一组**前置条件（Gate）**（如底稿是否完成、复核是否通过等），全部满足才可点**「执行归档」**；未满足会逐项列出待办。

---

## 八、其他视图（顶部切换）

除"审计生命周期"外，顶部还可切换到其他视角查看同一批底稿：

| 视图 | 用途 |
|------|------|
| 生成看板 / 看板 | 卡片式看整体进度与状态 |
| 类别矩阵 | 按循环 × 状态的矩阵总览 |
| 列表 | 扁平表格，适合批量筛选检索 |
| 工作台 | 个人待办与在办底稿聚合 |
| 依赖图 | 底稿间的取数 / 勾稽依赖关系 |

顶部工具栏还提供：生成底稿、增量导入、批量导出（元数据）、批量 Tab 导入导出、模板复制、批量下载（全部）、批量委派等批处理入口。

## 九、常见问题速查

- **底稿打不开 / 显示未生成？** 该循环可能还没裁剪或还没生成，请回到"程序裁剪 / 底稿生成"完成前置步骤。
- **看不到某些底稿？** 可见性隔离生效——你只能看到分配给自己的底稿，找现场经理确认委派。
- **裁剪保存失败？** 检查是否有被裁剪程序未填裁剪理由。
- **在线编辑打不开？** 双模式需 OnlyOffice 拉取成功才可切换，稍等或改用结构化视图。
- **改了披露表附注没变 / 改了附注披露没变？** 二者由审定数联动，优先在审定表核对；必要时点底稿内的"刷新/同步"。

> 有疑问优先联系现场经理或项目合伙人；涉及权限（裁剪/委派）请由项目经理及以上角色操作。
