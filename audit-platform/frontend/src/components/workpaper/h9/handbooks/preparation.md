# H9 租赁负债 — 底稿编制手册

> **适用范围**：承租人尚未支付的租赁付款额现值。科目租赁负债（列报于长期应付款/租赁负债），及一年内到期部分。
> **组件**：GtBIndex 通用目录（H9 科目）
> **说明**：本手册说明各分表的审计目标、编制逻辑与勾稽关联，不替代各表页内已有说明文案。平台按钮与操作步骤见「使用手册」页签。

---

## 1. 总体编制思路

租赁负债依《企业会计准则第 21 号——租赁》(CAS21) 由承租人确认，与使用权资产（H8）互为一体：

- **初始计量**：租赁负债 = 尚未支付的**未来租赁付款额按增量借款利率（或租赁内含利率）折现的现值**。租赁付款额含固定付款额、可变付款额、担保余值、购买/续租/终止选择权行权价款等。
- **后续计量（实际利率法）**：每期确认利息费用（期初余额 × 折现率，计入财务费用）+ 减去本期实际支付的租赁付款额 = 期末余额；即摊余成本滚动。
- **一年内到期重分类**：期末应将一年内到期偿还的租赁负债重分类为流动负债（一年内到期的非流动负债），非流动部分与流动部分分列披露。
- **与 H8 联动**：初始计量金额构成 H8 使用权资产成本的主要部分；租赁变更、提前终止时两表须同步调整。

| 证据链 | 主要底稿 | 回答的问题 |
|--------|----------|------------|
| 初始计量 | H9 初始计量 | 租赁付款额、折现率、现值是否准确？与 H8 勾稽？ |
| 后续摊销 | H9 摊销表 | 实际利率法利息与偿还是否正确、期末余额是否准确？ |
| 一年内到期 | H9 审定表 | 流动/非流动重分类是否恰当？ |
| 与 H8 勾稽 | H9 明细 / 审定 | 租赁负债与使用权资产是否勾稽一致？ |
| 列报披露 | 附注（上市/国企）| 到期分析、折现率、租赁负债变动是否充分披露？ |

### 建议编制顺序

```
H9程序表 → H9初始计量(未来租赁付款额×增量借款利率折现现值)勾稽H8
  → H9摊销表(实际利率法: 期初×利率=利息, -偿还=期末)
  → 一年内到期重分类(流动/非流动分列)
  → 调整(变更/终止,与H8同步) → 回写审定表(勾稽TB) → 附注(到期分析)
```

## 2. 分表编制说明

### H9 审定表
按租赁负债类别列示期初、本期利息、本期偿还、期末余额，及一年内到期与非流动部分；未审数 + 账项调整(AJE) + 重分类调整(RJE) = 审定数；审定合计回写并勾稽试算表相应科目。

### H9 明细表
逐项租赁负债明细：租赁标的、剩余租赁期、折现率、期初余额、本期利息、本期偿还、期末余额、一年内到期额；与 H8 使用权资产逐项勾稽。

### H9 初始计量
未来租赁付款额清单（固定/可变/担保余值/选择权行权价）、折现率（增量借款利率或内含利率）、折现现值测算；与 H8 使用权资产初始成本勾稽。

### H9 摊销表
实际利率法摊销：每期期初余额 × 折现率 = 利息费用（计入财务费用），期初余额 + 利息 − 本期偿还 = 期末余额；测算本期利息与账面比对。

### 调整 / 附注
租赁变更、提前终止的调整分录（与 H8 同步）回写审定表并推送 A13；附注按上市/国企口径披露租赁负债到期分析（一年内/1-2 年/2-5 年/5 年以上）、加权平均折现率、变动情况。

## 3. 认定覆盖速查

| 认定 | 主要底稿 |
|------|----------|
| 存在 | H9 明细 / 初始计量（租赁合同） |
| 完整性（负债重点） | H9 明细 / 初始计量（未确认租赁排查） |
| 权利和义务 | H9 初始计量（付款义务） |
| 计价和分摊 | H9 初始计量 / 摊销表（现值与实际利率法） |
| 列报和披露 | H9 审定表 / 附注（到期分析、流动划分） |

## 4. 外部模块衔接

| 模块 | 关系 |
|------|------|
| H8 使用权资产 | 租赁负债与使用权资产互为一体，初始/变更/终止同步勾稽 |
| 财务费用 | 实际利率法利息计入财务费用，勾稽利润表 |
| 一年内到期非流动负债 | 一年内到期部分重分类为流动负债 |
| A13 错报汇总 | 调整分录未更正部分推送错报汇总 |
| 试算表 | H9 审定合计回写相应科目 |

## 5. 质量复核要点（摘要）

- 折现率（增量借款利率）确定是否合理、是否有据，租赁付款额组成是否完整。
- 初始现值与 H8 使用权资产是否勾稽一致。
- 实际利率法摊销（利息、偿还、期末余额）是否正确，本期利息与账面差异是否查明。
- 一年内到期部分重分类是否恰当，流动/非流动分列是否正确。
- 租赁变更、提前终止时 H9 与 H8 是否同步调整。
- 附注到期分析、加权平均折现率披露是否充分。
