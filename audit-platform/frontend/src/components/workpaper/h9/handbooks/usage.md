# H9 租赁负债 — 平台使用手册

> 本页说明各底稿在平台上的操作方式。审计目标与编制逻辑见「编制手册」页签。

## 1. 目录页（本页）

- 跨表结论口径看板：汇总核心表"审计说明或结论"是否已填，点击标签跳转对应分表。
- 底稿架构（4 阶段泳道）：审计计划 / 科目审定 / 实质性程序 / 披露与调整。
- 本循环底稿目录：H 循环其他科目，点击跳转。
- 编制/使用手册：右上角按钮。

## 2. 各底稿操作要点

- **H9 初始计量**：录入未来租赁付款额、折现率，系统算现值并与 H8 勾稽。
- **H9 摊销表**：录入折现率与偿还计划，系统按实际利率法算每期利息与期末余额。
- **H9 明细表**：逐项租赁负债明细，与 H8 使用权资产勾稽。
- **H9 审定表**：从明细带入未审数，录入 AJE/RJE 得审定数，做一年内到期重分类，保存回写试算表。
- **附注**：从审定表带入到期分析、加权平均折现率与变动情况。

## 3. 常用操作速查

| 操作 | 位置 |
|------|------|
| 从明细带入审定表 | H9 审定表「从明细带入」按钮 |
| 现值测算 | H9 初始计量录入付款额/折现率算现值 |
| 实际利率法摊销 | H9 摊销表「测算」按钮 |
| 勾稽 H8 | H9 明细/初始计量「勾稽 H8」提示 |
| 一年内到期重分类 | H9 审定表流动/非流动分列 |
| 回写试算表 | H9 审定表保存时回写 |
| AI 辅助说明/结论 | 各表审计说明区「AI 辅助」按钮 |
| 复核对话 | 各表结论区复核圆点/复核按钮 |
| 版本历史 | 顶部工具栏版本按钮 |

## 4. 联动关系速查

| 联动 | 说明 |
|------|------|
| H9 ↔ H8 | 租赁负债与使用权资产初始/变更/终止同步勾稽 |
| 摊销 → 财务费用 | 实际利率法利息计入财务费用 |
| 一年内到期 → 流动 | 期末重分类为流动负债分列 |
| 明细 → 审定 | H9 明细按分类聚合到审定表 |
| 调整 → 审定 | 调整分录回写审定 AJE/RJE |
| 审定 → 附注 | 审定数带入附注到期分析 |
| 审定 → 试算表 | 审定合计回写相应科目 |
| 调整 → A13 | 未更正错报推送错报汇总 |
