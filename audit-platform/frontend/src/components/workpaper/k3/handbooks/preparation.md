# K3 其他应付款 — 底稿编制手册

> **适用范围**：科目 **2241 其他应付款（贷方/负债类）**（含押金保证金、暂收款、代扣代缴、往来挂账等）
> **组件**：`k3-other-payables`
> **说明**：本手册说明各分表的审计目标、编制逻辑与勾稽关联，不替代各表页内已有说明文案。
> 平台按钮与操作步骤见「使用手册」页签。

---

## 1. 总体编制思路

K3 把「其他应付款」拆成金额枢纽与专项检查两条证据链，最后汇入审定与附注：

| 证据链 | 主要底稿 | 回答的问题 |
|--------|----------|------------|
| **金额枢纽** | K3-2 明细 → K3-1 审定 ← K3-3 调整 | 其他应付款各项余额未审→调整→审定是否完整准确？ |
| **专项检查** | K3-4 大额 / K3-5 长期挂账 / K3-6 关联方 / K3-7 综合检查 | 大额/长挂/关联/未入账负债是否真实、完整、恰当？ |
| **完整性反向测试** | K3-7 检查表（反向截止） | 期后偿付倒查是否存在期末未入账的其他应付款？ |

**枢纽原则**：

1. **K3-2 明细表是数据枢纽**——审定表按对象/性质从明细带入。
2. **K3-3 是调整枢纽**——差异确认后回写 K3-1。
3. **K3-1 是结论枢纽**——与试算（2241）、附注披露勾稽。
4. **K3A 程序表**统领「做了哪些程序」；分表记录「证据与结论」。

> **负债类方向铁律**：其他应付款 期末 = 期初 + 贷方（增加） − 借方（减少）；审计重点为**完整性认定**（负债易被少计/漏记）。

### 建议编制顺序（标准路径）

```
K3A 程序计划
  → K3-2 明细（按对象+账龄立清单）
  → 专项检查：K3-4 大额分析 → K3-5 长期挂账 → K3-6 关联方
  → K3-7 综合检查（含反向截止：期后偿付倒查未入账负债）
  → 差异汇入 K3-3 → 确认回写 K3-1
  → 附注上市 / 附注国企
```

可按项目风险裁剪（如无关联方往来可弱化 K3-6），但 **明细 → K3-1** 与 **K3-7 完整性反向测试** 不宜省略。

## 2. 分表编制说明

每张表按统一结构：**审计目标 → 编制逻辑 → 上游/下游 → 完成标志**。

### K3A 实质性程序表
- **审计目标**：规划并记录针对其他应付款的实质性程序范围、性质与时间。
- **完成标志**：计划程序均有执行记录或「不适用」说明。

### K3-1 审定表
- **审计目标**：核实其他应付款各项余额准确完整；分类列报恰当；提供审定数。
- **编制逻辑**：双区块（按性质 / 按账龄）；未审 / 账项调整(AJE) / 重分类(RJE) / 审定；审定 = 未审 + AJE + RJE。
- **上游**：K3-2 明细汇总；K3-3 确认回写。**下游**：试算表(2241)；附注。
- **完成标志**：与 TB 勾稽差异已解释；与报表核对（应付利息+应付股利+其他应付款=报表数）；审计结论已填。

### K3-2 明细表（数据枢纽）
- **审计目标**：核实其他应付款各项存在、完整、义务与计价。
- **编制逻辑**：按往来对象逐项列示，期初 + 贷方 − 借方 = 期末滚动；按账龄分层（1年内/1-2/2-3/3年以上）。
- **完成标志**：清单完整、滚动勾稽通过；与 K3-1 汇总一致。

### K3-3 调整分录汇总
- **审计目标**：核实调整完整、借贷平衡。
- **完成标志**：借贷平衡；已确认回写 K3-1；索引指向证据表。

### K3-4 大额其他应付款情况分析表
- **审计目标**：核实大额款项真实性、发生原因与偿付计划。
- **编制逻辑**：按金额降序列示重点款项，记录性质/形成原因/期后偿付。
- **完成标志**：大额款项分析完整；与 K3-2 明细勾稽。

### K3-5 长期挂账检查表
- **审计目标**：核实 3 年以上长期挂账款项是否仍需支付，评估转销必要性。
- **编制逻辑**：筛选账龄 3 年以上款项，判断是否无法支付 → 是否应转营业外收入（CAS14/其他收益判断）。
- **完成标志**：长挂款项逐笔评估；无法支付项已提转销建议。

### K3-6 关联方及交易检查表
- **审计目标**：核实关联方往来的公允性、资金占用与披露充分性。
- **编制逻辑**：识别关联方其他应付款，按 8 类关联关系分类，判断公允性与资金占用。
- **完成标志**：关联方往来完整识别；公允性与披露判断有据。

### K3-7 其他应付款检查表（含反向截止）
- **审计目标**：凭证级综合检查（真实性/审批/期间/分类）+ **完整性反向截止测试**（期后偿付倒查期末未入账负债）。
- **编制逻辑**：抽查凭证核对 5 项内容；期后偿付倒查确认期末负债完整性。
- **完成标志**：抽查比例达方案要求；反向截止无未入账负债或已提调整。

### 附注披露（上市/国企）
- **审计目标**：按附注格式披露其他应付款构成（按性质/按账龄），与审定勾稽。
- **完成标志**：金额与 K3-1 审定一致；已同步附注模块。

### 底稿目录
- **审计目标**：导航与编制进度总览（跨表结论口径 + 底稿架构）。
- **完成标志**：计划执行的分表状态均为完成或已说明不适用。

## 3. 认定覆盖速查

| 认定 | 主要底稿 |
|------|----------|
| 完整性（负债重点） | K3-2、K3-7（反向截止） |
| 存在 | K3-2、K3-4 |
| 义务 | K3-1、K3-6 |
| 计价 | K3-1、K3-5 |

## 5. 质量复核要点（摘要）

1. K3-2 明细合计 ↔ K3-1 未审是否勾稽？
2. K3-7 反向截止是否发现期末未入账负债（完整性）？
3. K3-5 长期挂账是否评估无法支付项的转销？
4. K3-3 已确认调整是否已回写 K3-1？借贷是否平衡？
5. 附注金额是否等于 K3-1 审定？
