# N1 递延所得税资产 — 平台使用手册

> 配合「编制手册」页签使用。本手册只说明**平台怎么操作**；审计目标与勾稽逻辑见编制手册。
> **不修改**各分表页内已有说明文案。入口：底稿目录页顶部「使用手册」按钮。

---

## 1. 打开与模式

1. 在项目底稿树打开 **N1 递延所得税资产**（`componentType: n1-deferred-tax-assets`，覆盖科目 1811）。
2. 通过 sheet 页签切换分表（N1A、N1-1～N1-5、附注上市/国企、底稿目录）。
3. 复杂 sheet 支持 **结构化 HTML ↔ OnlyOffice** 双模式；以项目配置为准（目录页不显示双模式）。
4. 只读阶段工具栏「取数 / 回写 / 确认」类按钮会禁用。

---

## 2. 推荐操作路径（点击顺序）

| 步骤 | 分表 | 建议操作 |
|------|------|----------|
| 1 | N1A | 勾选实质性程序、填索引 |
| 2 | N1-4 | 测算表：暂时性差异×税率，资产/负债分列 |
| 3 | N1-5 | 亏损检查：未弥补亏损确认谨慎性判断 |
| 4 | N1-2 | 按暂时性差异项目录入明细 |
| 5 | N1-3 | 调整分录汇总 → 确认 → 回写 N1-1 |
| 6 | N1-1 | 确认审定期末 → 回写 TB(1811) → 核对 N3/N5 |
| 7 | 附注上市/国企 | 从审定表取数 → 编辑 → 同步附注模块 |

## 3. 目录页速查

| 区块 | 说明 |
|------|------|
| 编制进度 | 各分表按审计说明/结论填写情况计算完成度 |
| 跨表结论口径 | 每张表审计结论「已填/未填」标签，点击跳转对应 sheet 补全 |
| 底稿架构 | 4 阶段泳道（审计计划/科目审定/实质性程序/披露与调整），点击卡片跳转 |
| 本循环底稿目录 | 同循环其他科目（N1~N5），点击跳转（灰色表示尚未生成） |

---

## 4. 常见问题

| 现象 | 处理 |
|------|------|
| N1-1 审定 ≠ TB 数 | 检查明细/测算是否全部带入、调整是否已确认回写；TB 取 1811 期末余额 |
| 递延税资产/负债混淆 | N1-4 测算表按可抵扣（资产 N1）/应纳税（负债 N3）暂时性差异分列，不能抵销的分列 |
| 与 N5 递延税费用不符 | 复核递延税资产本期变动额（期末−期初）与 N5-8 是否一致 |
| 附注同步失败 | 检查项目 ID、附注模块权限与准则类型（上市/国企） |
