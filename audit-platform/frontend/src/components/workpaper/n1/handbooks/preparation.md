> **适用范围**：科目 **1811 递延所得税资产（借方/资产类）**
> **组件**：`n1-deferred-tax-assets`
> **说明**：本手册说明各分表的审计目标、编制逻辑与勾稽关联，不替代各表页内已有说明文案。
> 平台按钮与操作步骤见「使用手册」页签。

## 1. 总体编制思路

递延所得税资产核心 = **可抵扣暂时性差异 × 适用税率**（谨慎性：以未来很可能取得的应纳税所得额为限）。

| 证据链 | 主要底稿 | 回答的问题 |
|--------|----------|------------|
| **金额枢纽** | N1-2 明细 → N1-1 审定 ← N1-3 调整 | 递延所得税资产期末余额是否准确完整？ |
| **计量引擎** | N1-4 测算表（暂时性差异×税率） | 各项暂时性差异确认额是否恰当？ |
| **可弥补亏损** | N1-5 亏损检查表 | 未弥补亏损确认递延税资产是否满足谨慎性？ |

**枢纽原则**：

1. **资产类借方科目**：期末 = 期初 + 本期借方 − 本期贷方（取期末余额，非发生额）。
2. **N1-4 测算表是计量核心**：同源产出递延税资产（归 N1）与递延税负债（归 N3），不能抵销的分列。
3. **N1-1 是结论枢纽**：审定期末余额回写试算表 1811，本期变动额（期末−期初）供 N5-8 递延所得税费用核对。
4. **可弥补亏损**：可确认额 = min(未弥补亏损, 预计未来应纳税所得额) × 税率；弥补期限一般 5 年（高新/科技型中小企业 10 年）。

### 建议编制顺序

```
N1A 程序计划
  → N1-4 测算表（暂时性差异×税率）+ N1-5 亏损充足性检查
  → N1-2 明细（按暂时性差异项目列示）
  → 差异汇入 N1-3 → 确认回写 N1-1
  → N1-1 勾稽 TB(1811) + 核对 N3/N5 → 附注上市/国企
```

## 2. 分表编制说明

### N1A 实质性程序表
- **审计目标**：规划并记录递延所得税资产实质性程序范围、性质与时间。
- **完成标志**：计划程序均有执行记录或「不适用」说明。

### N1-1 审定表（资产类借方）
- **审计目标**：核实递延所得税资产期末余额准确完整；提供审定数。
- **编制逻辑**：期末 = 期初 + 借方 − 贷方；审定 = 未审 + AJE + RJE。
- **上游**：N1-2 明细 / N1-4 测算；N1-3 确认回写。**下游**：TB(1811)、N5 递延税费用核对、附注。
- **完成标志**：与 TB 勾稽差异已解释；审计结论已填。

### N1-2 明细表
- **审计目标**：核实各暂时性差异项目确认额存在、完整、准确。
- **完成标志**：清单完整、合计与 N1-1 一致。

### N1-3 调整分录汇总
- **审计目标**：核实调整完整、借贷平衡。
- **完成标志**：借贷平衡；已确认回写 N1-1。

### N1-4 递延所得税资产（负债）测算表（核心引擎）
- **审计目标**：核实暂时性差异确认与计量（差异×税率）恰当；资产/负债分列。
- **编制逻辑**：可抵扣暂时性差异×税率 → 递延税资产（N1）；应纳税暂时性差异×税率 → 递延税负债（N3）。
- **完成标志**：与 N1-1 审定一致；不能抵销的分列正确。

### N1-5 可用以后年度税前利润弥补的亏损检查表
- **审计目标**：核实未弥补亏损确认递延税资产满足谨慎性（未来很可能取得应纳税所得额）。
- **完成标志**：可确认额测算有据；弥补期限判断正确。

### 附注披露（上市/国企）
- **审计目标**：按附注格式披露递延所得税资产及暂时性差异，与审定勾稽。
- **完成标志**：金额与 N1-1 审定一致；已同步附注模块。

### 底稿目录
- **审计目标**：导航与编制进度总览（跨表结论口径 + 底稿架构 + 本循环其他科目）。

## 5. 质量复核要点（摘要）

1. N1-4 测算暂时性差异×税率 ↔ N1-1 审定是否勾稽？
2. N1-1 审定期末 ↔ TB(1811) 是否勾稽？
3. N1-5 可弥补亏损确认是否满足谨慎性（未来应纳税所得额充足）？
4. 递延税资产本期变动 ↔ N5 递延所得税费用是否核对一致？
5. 附注金额是否等于 N1-1 审定？
