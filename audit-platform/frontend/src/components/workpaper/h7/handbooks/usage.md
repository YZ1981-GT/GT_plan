# H7 生产性生物资产（农业） — 平台使用手册

> 本页说明各底稿在平台上的操作方式。审计目标与编制逻辑见「编制手册」页签。

## 1. 目录页（本页）

- 跨表结论口径看板：汇总核心表"审计说明或结论"是否已填，点击标签跳转对应分表。
- 底稿架构（4 阶段泳道）：审计计划 / 科目审定 / 实质性程序 / 披露与调整。
- 本循环底稿目录：H 循环其他科目，点击跳转。
- 编制/使用手册：右上角按钮。

## 2. 各底稿操作要点

- **H7 明细表**：录入逐项生物资产，选择类别、成熟状态、计量模式，是折旧/公允/减值分表的行来源。
- **H7 折旧**（成本模式、成熟）：录入寿命/残值，系统直线法测算，未成熟资产不计提。
- **H7 公允价值**（公允价值模式）：录入期末公允价值，系统算变动额并提示计入当期损益。
- **H7 减值**（成本模式）：录入减值迹象与可收回金额，测算应计提减值。
- **H7 互转**：录入消耗性↔生产性转换，核对转换日成本与差额。
- **H7 审定表**：从明细带入未审数，录入 AJE/RJE 得审定数，保存回写试算表 1621。
- **附注**：从审定表带入分类余额、变动及计量模式政策。

## 3. 常用操作速查

| 操作 | 位置 |
|------|------|
| 从明细带入审定表 | H7 审定表「从明细带入」按钮 |
| 折旧测算 | H7 折旧「测算」按钮（成熟、成本模式） |
| 公允价值变动 | H7 公允价值录入期末公允价值算差额 |
| 减值测算 | H7 减值「可收回金额测算」 |
| 回写试算表 | H7 审定表保存时回写 1621 |
| AI 辅助说明/结论 | 各表审计说明区「AI 辅助」按钮 |
| 复核对话 | 各表结论区复核圆点/复核按钮 |
| 版本历史 | 顶部工具栏版本按钮 |

## 4. 联动关系速查

| 联动 | 说明 |
|------|------|
| 明细 → 审定 | H7 明细按分类聚合到审定表 |
| 成熟 → 折旧 | 仅成熟生产性生物资产计提折旧 |
| 公允变动 → 损益 | 公允价值模式变动额计入当期损益 |
| 互转 → 存货 | 消耗性↔生产性互转与存货科目勾稽 |
| 调整 → 审定 | 调整分录回写审定 AJE/RJE |
| 审定 → 附注 | 审定数带入附注分类披露 |
| 审定 → 试算表 | 审定合计回写 1621 |
| 调整 → A13 | 未更正错报推送错报汇总 |
