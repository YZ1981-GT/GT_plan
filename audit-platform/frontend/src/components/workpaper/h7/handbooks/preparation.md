# H7 生产性生物资产（农业） — 底稿编制手册

> **适用范围**：农林牧渔企业为产出农产品、提供劳务或出租而持有的生物资产。科目 1621 生产性生物资产（含成熟与未成熟），及累计折旧、减值准备。
> **组件**：GtBIndex 通用目录（H7 科目）
> **说明**：本手册说明各分表的审计目标、编制逻辑与勾稽关联，不替代各表页内已有说明文案。平台按钮与操作步骤见「使用手册」页签。

## 1. 总体编制思路

生产性生物资产依《企业会计准则第 5 号——生物资产》(CAS5) 核算，如经济林、产畜、役畜：

- **成熟 vs 未成熟**：达到预定生产经营目的为**成熟**生产性生物资产，按直线法或产量法计提折旧；**未成熟**（如未挂果经济林、未成年产畜）在达到成熟前不计提折旧，相关支出资本化。
- **计量模式**：一般采用**成本模式**（成本 − 累计折旧 − 减值）；有确凿证据表明公允价值能够可靠取得的可采用**公允价值模式**（不计提折旧，公允价值变动计入当期损益）。
- **直线法折旧**：成熟生产性生物资产按预计使用寿命与净残值直线计提。
- **减值**：成本模式下依 CAS8 识别减值迹象（病虫害、自然灾害、市价下跌等）并测算减值。
- **互转**：消耗性生物资产（存货）与生产性生物资产之间的转换，须按 CAS5 规定确认转换日成本与差额处理（如自繁自育产畜由消耗性转生产性）。

| 证据链 | 主要底稿 | 回答的问题 |
|--------|----------|------------|
| 存量真实完整 | H7 明细表 | 生物资产是否真实存在（实地盘点）、归属被审计单位？ |
| 成熟/未成熟分类 | H7 明细表 | 成熟与未成熟划分是否恰当、折旧起算是否正确？ |
| 折旧计价 | H7 折旧 | 直线法折旧年限/残值是否合理、是否足额？ |
| 公允价值（如适用）| H7 公允价值 | 公允价值来源是否可靠、变动是否计入当期损益？ |
| 减值 | H7 减值 | 病害/灾害/跌价迹象下减值是否充分？ |
| 互转 | H7 互转 | 消耗性↔生产性转换是否恰当入账？ |

### 建议编制顺序

```
H7程序表 → H7明细(立清单: 成熟/未成熟分类)
  → 成本模式: 直线法折旧(仅成熟) + 减值测试
  → 公允价值模式: 公允价值计量(变动计当期损益)
  → 产量记录 → 互转核查(消耗性↔生产性)
  → 调整 → 回写审定表(勾稽TB 1621) → 附注
```

## 2. 分表编制说明

### H7 审定表
按成熟/未成熟、成本/公允价值分类列示原值、累计折旧、减值、账面价值；未审数 + 账项调整(AJE) + 重分类调整(RJE) = 审定数；审定合计回写并勾稽试算表 1621。

### H7 明细表
逐项生物资产明细：类别（经济林/产畜/役畜）、成熟状态、计量模式、取得日、原值、累计折旧、减值、账面价值；核对繁育/购入记录与实地盘点结果。

### H7 折旧
**成本模式且成熟适用**。按预计使用寿命与净残值直线法计提；测算应计提额与账面比对；未成熟资产不应计提折旧的核查。

### H7 公允价值
**公允价值模式适用**。期末公允价值来源与合理性；公允价值变动 = 期末公允价值 − 期初账面，计入当期损益。

### H7 减值
**成本模式适用**。CAS8 减值迹象（病虫害、自然灾害、市价下跌）→ 可收回金额测算 → 应计提减值，与账面比对。

### H7 产量记录 / 互转
产量/产出记录支撑折旧方法与成熟判断；消耗性生物资产（存货）与生产性生物资产互转的转换日成本与差额处理复核。

### 调整 / 附注
账项与重分类调整分录回写审定表并推送 A13；附注按分类列示期末余额、本期变动、计量模式与折旧政策。

## 5. 质量复核要点（摘要）

- 生物资产实地盘点是否执行，存在性证据是否充分（活体资产盘点特殊性）。
- 成熟与未成熟划分是否恰当，未成熟资产是否误提折旧、成熟折旧是否及时起算。
- 计量模式选择是否有依据、是否一贯，公允价值模式是否满足可靠取得条件。
- 减值迹象（病虫害、自然灾害、市价）是否充分识别与测算。
- 消耗性与生产性生物资产互转的转换日成本与差额处理是否符合 CAS5。
- 行业适用性判断是否正确（农林牧渔），非该行业不应误用本科目。
