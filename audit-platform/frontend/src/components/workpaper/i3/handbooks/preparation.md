## 1. 总体编制思路

商誉核心 = **期末余额 = 期初余额 + 本期新并购增加 − 本期减值**，且 **商誉不摊销、仅作年度减值测试**（减值一经确认不可转回，故正常年度只减不增）。

| 证据链 | 主要底稿 | 回答的问题 |
|--------|----------|------------|
| **初始确认** | I3-4 入账价值测算 | 企业合并商誉初始确认金额是否准确？ |
| **金额枢纽** | I3-2 明细 → I3-1 审定 ← I3-3 调整 | 商誉期末余额是否准确完整？ |
| **减值测试** | I3-6 减值测试(CGU分摊) / I3-7 可收回金额(DCF) | 资产组减值迹象与减值金额确认是否恰当？ |
| **复核与检查** | I3-5 针对性检查 / I3-8 复核公司减值测试过程 | 公司减值测试过程与结论是否恰当？ |

**枢纽原则**：

1. **不摊销**：商誉不计提摊销，**仅年度减值测试**；1711 资产借方，期末 = 期初 + 新并购增加 − 减值。
2. **初始确认（I3-4）**：企业合并商誉 = 合并成本 − 购买日被购买方可辨认净资产公允价值份额。
3. **减值测试以资产组为单元**：商誉减值测试基于 **资产组(CGU) / 资产组组合** 的 DCF 模型；可收回金额 = MAX(公允价值减处置费用后净额, 预计未来现金流量现值 DCF/CAPM)。
4. **减值分摊顺序**：减值损失 **先冲减商誉**（至零为止），剩余再按比例分摊至资产组其他各项资产；商誉减值 **不可转回**。
5. **I3-1 是结论枢纽**：审定期末回写试算表 1711，并驱动附注披露。
6. **本期增加只来自新并购**（正常为 0，非零须特别关注）；**本期减少只来自减值**。

### 建议编制顺序

```
I3A 程序计划
  → I3-4 入账价值测算（企业合并商誉初始确认）
  → I3-2 明细（按被投资单位：原值/减值双表滚动）
  → I3-5 针对性检查
  → I3-6 商誉减值测试（CGU 分摊：先冲商誉再按比例分摊）
  → I3-7 可收回金额测试（公允净额 + DCF/CAPM + 敏感性分析）
  → I3-8 复核公司减值测试过程及结论
  → 差异汇入 I3-3 → 确认回写 I3-1
  → I3-1 勾稽 TB(1711) → 附注上市/国企
```

## 2. 分表编制说明

### I3A 实质性程序表
- **审计目标**：规划并记录商誉实质性程序范围、性质与时间。
- **完成标志**：计划程序均有执行记录或「不适用」说明。

### I3-1 审定表
- **审计目标**：核实商誉期末余额准确完整；提供审定数供附注披露。
- **编制逻辑**：审定 = 未审 + AJE + RJE；期末 = 期初 + 新并购增加 − 减值。
- **上游**：I3-2 明细、I3-4 入账价值、I3-6/I3-7 减值；I3-3 确认回写。**下游**：TB(1711)、附注、A13。
- **完成标志**：与 TB 勾稽差异已解释；审计说明与结论已填。

### I3-2 明细表
- **审计目标**：按被投资单位逐项核实商誉存在、完整、准确（原值/减值准备双表滚动）。
- **完成标志**：清单完整、合计与 I3-1 一致。

### I3-3 调整分录汇总
- **审计目标**：核实调整完整、借贷平衡。
- **完成标志**：借贷平衡；已确认回写 I3-1 并联动 A13。

### I3-4 入账价值测算表
- **审计目标**：核实企业合并商誉初始确认金额准确（合并成本 − 可辨认净资产公允价值份额）。
- **完成标志**：初始入账金额与 I3-2 原值一致。

### I3-5 针对性检查表
- **审计目标**：针对商誉重大风险事项执行针对性检查（并购背景、减值迹象、CGU 划分等）。

### I3-6 商誉减值测试（CGU 分摊）
- **审计目标**：核实资产组/资产组组合减值测试恰当；减值损失先冲商誉再按比例分摊至其他资产。
- **完成标志**：CGU 划分合理；减值分摊顺序正确；结论与 I3-7 可收回金额一致。

### I3-7 可收回金额测试（DCF）
- **审计目标**：核实资产组可收回金额（公允价值减处置费用后净额 与 DCF 现值孰高），DCF/CAPM 关键假设合理。
- **完成标志**：DCF 关键假设（增长率、折现率）有依据；含敏感性分析；结果驱动 I3-6 减值。

### I3-8 复核公司减值测试过程及结论
- **审计目标**：复核被审计单位（或其聘请评估机构）商誉减值测试的过程与结论是否恰当。

### 附注披露（上市/国企）
- **审计目标**：按附注格式披露商誉原值/减值准备/账面价值及减值测试关键假设，与审定勾稽。

### 底稿目录
- **审计目标**：导航与编制进度总览（跨表结论口径 + 底稿架构 + 本循环其他科目）。

## 5. 质量复核要点（摘要）

1. I3-1 商誉审定 ↔ TB(1711) 是否勾稽？期末 = 期初 + 新并购增加 − 减值？
2. I3-4 初始入账金额 ↔ I3-2 原值是否一致？合并成本与净资产公允价值份额是否有依据？
3. I3-6 减值分摊顺序是否正确（先冲商誉、剩余按比例分摊）？减值是否未被转回？
4. I3-7 DCF 关键假设（增长率、折现率）是否合理、含敏感性分析？可收回金额 ↔ I3-6 是否一致？
5. I3-8 是否复核公司减值测试过程与结论？附注金额是否等于 I3-1 审定？
