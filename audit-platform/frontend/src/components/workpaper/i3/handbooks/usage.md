# I3 商誉 — 平台使用手册

> 配合「编制手册」页签使用。本手册只说明**平台怎么操作**；审计目标与勾稽逻辑见编制手册。
> **不修改**各分表页内已有说明文案。入口：底稿目录页顶部「使用手册」按钮。

---

## 1. 打开与模式

1. 在项目底稿树打开 **I3 商誉**（`componentType: i3-goodwill`，覆盖科目 1711）。
2. 通过 sheet 页签切换分表（I3A、I3-1~I3-8、附注上市/国企、底稿目录）。
3. 复杂 sheet 支持 **结构化 HTML ↔ OnlyOffice** 双模式；以项目配置为准（目录页不显示双模式）。
4. 只读阶段工具栏「取数 / 回写 / 确认」类按钮会禁用。

---

## 2. 推荐操作路径（点击顺序）

| 步骤 | 分表 | 建议操作 |
|------|------|----------|
| 1 | I3A | 勾选实质性程序、填索引 |
| 2 | I3-4 | 测算企业合并商誉初始入账（合并成本 − 净资产公允价值份额） |
| 3 | I3-2 | 按被投资单位登记明细（原值/减值双表滚动） |
| 4 | I3-5 | 针对性检查（并购背景、减值迹象、CGU 划分） |
| 5 | I3-6 | 商誉减值测试（CGU 分摊：先冲商誉再按比例分摊） |
| 6 | I3-7 | 可收回金额测试（公允净额 + DCF/CAPM + 敏感性分析） |
| 7 | I3-8 | 复核公司减值测试过程及结论 |
| 8 | I3-3 | 调整分录汇总 → 确认 → 回写 I3-1 |
| 9 | I3-1 | 确认审定 → 回写 TB(1711) |
| 10 | 附注上市/国企 | 从审定表取数 → 编辑 → 同步附注模块 |

## 4. 常见问题

| 现象 | 处理 |
|------|------|
| I3-1 审定 ≠ TB 数 | 检查明细/入账/减值是否全部带入、调整是否已确认回写；TB 取 1711 期末余额 |
| 期末余额不符 | 期末 = 期初 + 新并购增加 − 减值；商誉不摊销，检查是否误计摊销 |
| 减值分摊不平 | 减值应先冲商誉（至零为止），剩余按比例分摊至资产组其他资产 |
| 减值被转回 | 商誉减值一经确认不可转回，检查是否误做转回 |
| I3-7 DCF 结果异常 | 核对增长率/折现率关键假设依据，逐 CGU 填报，补敏感性分析 |
| 附注同步失败 | 检查项目 ID、附注模块权限与准则类型（上市/国企） |

## 5. 复核入口

各分表工具栏/结论区「复核」打开复核对话。合伙人级复核提示词参考：`backend/data/tsj_review_prompts/I/`（若环境已部署）。
