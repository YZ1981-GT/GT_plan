# I6 研发费用 — 平台使用手册

> 配合「编制手册」页签使用。本手册只说明**平台怎么操作**；审计目标与勾稽逻辑见编制手册。
> **不修改**各分表页内已有说明文案。入口：底稿目录页顶部「使用手册」按钮。

---

## 1. 打开与模式

1. 在项目底稿树打开 **I6 研发费用**（`componentType: i6-research-development-expense`，覆盖科目 6602）。
2. 通过 sheet 页签切换分表（I6A、I6-1~I6-6、附注上市/国企、底稿目录）。
3. 复杂 sheet 支持 **结构化 HTML ↔ OnlyOffice** 双模式；以项目配置为准（目录页不显示双模式）。
4. 只读阶段工具栏「取数 / 回写 / 确认」类按钮会禁用。

---

## 2. 推荐操作路径（点击顺序）

| 步骤 | 分表 | 建议操作 |
|------|------|----------|
| 1 | I6A | 勾选实质性程序、填索引 |
| 2 | I6-2 | 逐月登记研发费用发生额（月度 12 列矩阵），关注异常月份标红 |
| 3 | I6-4 | 针对性检查抽凭核对（1~5 项），检查比例联动 I6-2 |
| 4 | I6-5 / I6-6 | 双向截止测试（账→单据 / 单据→账），跨期高亮 |
| 5 | I6-3 | 调整分录汇总 → 确认 → 回写 I6-1 + 推送 A13 |
| 6 | I6-1 | 确认审定 → 回写 TB(6602 发生额) |
| 7 | 附注上市/国企 | 从审定表取数 → 编辑 → 同步附注模块 |

| 区块 | 说明 |
|------|------|
| 编制进度 | 各分表按审计说明/结论填写情况计算完成度 |

## 4. 常见问题

| 现象 | 处理 |
|------|------|
| I6-1 审定 ≠ TB 数 | 研发费用是**损益类**，取 6602 **本期发生额（非余额）**；检查明细/调整是否全部带入、是否已确认回写 |
| 研发总额不符 | 费用化(I6) + 资本化(I2) = 研发总额（VR-I6-01），检查 I6 与 I2 拆分 |
| 月度异常月份标红 | I6-2 波动 ±30% 自动标红，须分析性复核并记录原因 |
| 截止测试有跨期 | I6-5/I6-6 跨期项目红色高亮，差异汇入 I6-3 调整 |
| 附注同步失败 | 检查项目 ID、附注模块权限与准则类型（上市/国企） |
