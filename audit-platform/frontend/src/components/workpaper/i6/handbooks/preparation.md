# I6 研发费用 — 底稿编制手册

> **适用范围**：科目 **6602 研发费用（损益类，借方）**
> **组件**：`i6-research-development-expense`
> **说明**：本手册说明各分表的审计目标、编制逻辑与勾稽关联，不替代各表页内已有说明文案。
> 平台按钮与操作步骤见「使用手册」页签。

---

## 1. 总体编制思路

研发费用 = **损益类科目，取本期发生额（非期末余额）**。期末审定数取 6602 本期发生额，核心是费用化研发支出的真实、完整、准确与截止。

| 证据链 | 主要底稿 | 回答的问题 |
|--------|----------|------------|
| **金额枢纽** | I6-2 明细（月度12列）→ I6-1 审定 ← I6-3 调整 | 本期研发费用发生额是否准确完整？ |
| **针对性检查** | I6-4 针对性检查表（抽凭核对 1~5 项） | 费用化研发支出真实、归属恰当？ |
| **截止测试** | I6-5（账→单据）/ I6-6（单据→账） | 研发费用是否记录于恰当会计期间？ |
| **费资联动** | I6 费用化 ↔ I2 资本化 | 研发总额拆分是否恰当（VR-I6-01）？ |

**枢纽原则**：

1. **方向**：6602 损益类借方，审定取**本期发生额**（借方发生额 − 贷方发生额），非期末余额。
2. **I6-1 是结论枢纽**：审定发生额回写试算表 6602，并驱动附注披露与利润表勾稽。
3. **I6↔I2 双向联动（VR-I6-01）**：费用化研发支出（I6）+ 资本化开发支出（I2）= 研发总额；未达资本化条件的研发支出费用化计入 I6。
4. **月度矩阵**：I6-2 按月度 12 列横向登记，异常月份（波动 ±30%）自动标红，供分析性复核。
5. **双向截止**：I6-5（账到单据）与 I6-6（单据到账）双向核对，跨期项目红色高亮。

### 建议编制顺序

```
I6A 程序计划
  → I6-2 明细（月度 12 列矩阵）
  → I6-4 针对性检查（抽凭核对 1~5 项）
  → I6-5（账→单据）/ I6-6（单据→账）截止测试
  → 差异汇入 I6-3 → 确认回写 I6-1
  → I6-1 勾稽 TB(6602) → 附注上市/国企
```

## 2. 分表编制说明

### I6A 研发费用实质性程序表
- **审计目标**：规划并记录研发费用实质性程序范围、性质与时间。
- **完成标志**：计划程序均有执行记录或「不适用」说明。

### I6-1 审定表（损益类发生额）
- **审计目标**：核实本期研发费用发生额准确完整；提供审定数。
- **编制逻辑**：审定发生额 = 未审 + AJE + RJE；取 6602 本期发生额（非余额）。
- **上游**：I6-2 明细、I6-3 确认回写。**下游**：TB(6602)、附注、利润表；与 I2 联动（费用化 + 资本化 = 研发总额）。
- **完成标志**：与 TB 勾稽差异已解释；审计说明与结论已填。

### I6-2 明细表（月度 12 列）
- **审计目标**：逐月核实研发费用发生真实、完整、准确。
- **编制逻辑**：基础列 + 12 月发生额 + 合计；异常月份（±30%）自动标红。
- **完成标志**：清单完整、合计与 I6-1 一致。

### I6-3 调整分录汇总
- **审计目标**：核实调整完整、借贷平衡。
- **完成标志**：借贷平衡；已确认回写 I6-1、推送 A13。

### I6-4 针对性检查表（抽凭核对）
- **审计目标**：对费用化研发支出抽凭核对（原始凭证、审批、归属、计价等 1~5 项）。
- **编制逻辑**：检查比例联动 I6-2 本期发生额合计。
- **完成标志**：核对项齐全；审计说明与结论已填。

### I6-5 截止测试（账→单据）/ I6-6 截止测试（单据→账）
- **审计目标**：核实研发费用记录于恰当会计期间；双向截止无跨期错记。
- **编制逻辑**：I6-5 由账面记录追至原始单据；I6-6 由原始单据追至账面记录；跨期项目红色高亮。
- **完成标志**：截止样本已核对；跨期差异已汇入 I6-3。

### 附注披露（上市/国企）
- **审计目标**：按附注格式披露研发费用（费用化金额及构成），与审定发生额勾稽。

### 底稿目录
- **审计目标**：导航与编制进度总览（跨表结论口径 + 底稿架构 + 本循环其他科目）。

## 4. 外部模块衔接

| 模块 | 与 I6 关系 |
|------|------------|
| **I2 开发支出** | 费用化(I6) + 资本化(I2) = 研发总额（VR-I6-01）；未达资本化条件的研发支出费用化计入 I6 |
| **试算平衡表** | I6-1 审定发生额回写 6602 |
| **调整分录 / A13** | 与 I6-3 双向同步 |
| **附注模块** | 研发费用披露 |
| **利润表** | 研发费用发生额勾稽 |

---

## 5. 质量复核要点（摘要）

1. I6-1 审定发生额 ↔ TB(6602) 是否勾稽？取的是发生额而非余额？
2. I6-2 月度合计 ↔ I6-1 审定是否一致？异常月份是否已分析？
3. I6-4 针对性检查抽凭比例是否充分？费用化归属是否恰当？
4. I6-5/I6-6 双向截止是否覆盖跨期样本？跨期差异是否已调整？
5. I6 费用化 + I2 资本化 = 研发总额是否配平（VR-I6-01）？附注金额是否等于 I6-1 审定？
