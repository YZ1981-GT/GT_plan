# E1 货币资金 — 平台使用手册

> 配合「编制手册」页签使用。
> 本手册只说明**平台怎么操作**；审计目标与勾稽逻辑见编制手册。
> **不修改**各分表页内已有说明文案。
> 入口：底稿目录页顶部「使用手册」按钮。

---

## 1. 打开与模式

1. 在项目底稿树打开 **E1 货币资金**（`componentType: e1-monetary-fund`，覆盖科目 1001 库存现金 / 1002 银行存款 / 1012 其他货币资金）。
2. 通过 sheet 页签切换分表（E1A、E1-1～E1-23、附注上市/国企、底稿目录）。
3. 复杂 sheet 支持 **结构化 HTML ↔ OnlyOffice** 双模式；以项目配置为准（目录页除外）。
4. 只读阶段工具栏「取数 / 回写 / 确认」类按钮会禁用。

**需要项目上下文的操作**（缺 `projectId` 会提示无法执行）：

- E1-3 函证回填、E1-6 银行余额调节交叉校验
- E1-21 / E1-22 截止测试自动抽样、E1-23 大额收支抽凭
- 附注「同步到附注模块」

## 2. 推荐操作路径（点击顺序）

| 步骤 | 分表 | 建议操作 |
|------|------|----------|
| 1 | E1A | 勾选实质性程序、填索引 |

| 7 | E1-11 | 银行账户完整性承诺书 |
| 8 | E1-15 / E1-20 | 利息收入月度分析、应计利息测算 |
| 9 | E1-21 / E1-22 | 银行存款 / 其他货币资金截止测试（可一键从序时账取数） |

## 3. 目录页速查

| 区块 | 说明 |
|------|------|
| 编制进度 | 各分表填妥「审计说明或结论」即计入完成 |
| 跨表结论口径 | 每张表审计结论「已填/未填」标签，点击跳转对应 sheet 补全 |
| 编制提示 | 折叠展开，推荐编制工作流 |
| 底稿架构 | 4 阶段泳道（审计计划/科目审定/实质性程序/披露与调整），点击卡片跳转 |
| 本循环底稿目录 | 同循环其他底稿（灰色表示未生成） |

## 4. 导入导出

- 工具栏「导入/导出」按当前 sheet 作用。
- E1-7/8/9/10/20/21/22 等具备后端端点的 sheet 支持导入导出模板/数据。
- 导入后刷新当前表；若改了明细（E1-2/E1-3），请重新对 E1-1 执行「从明细带入」。

---

## 5. 常见问题

| 现象 | 处理 |
|------|------|
| E1-1 审定合计 ≠ TB 数 | 检查明细是否全部带入、调整是否已确认回写 |
| E1-6 余额调节交叉校验空 | 确认 E1-3 银行明细已录入且开户行/账号一致 |
| E1-10 账外账户告警 | 核对账户清单与账面记录，关注完整性认定 |
| 截止测试自动取数无数据 | 确认项目序时账已导入且基准日正确 |
| 抽凭无数据 | 确认凭证库有 1001/1002/1012 发生额且抽凭引擎可访问 |
| 附注同步失败 | 检查项目 ID、附注模块权限与准则类型（上市/国企） |
