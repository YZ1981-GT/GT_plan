# E1 货币资金 — 底稿编制手册

> **适用范围**：科目 **1001 库存现金 / 1002 银行存款 / 1012 其他货币资金**
> **组件**：`e1-monetary-fund`
> **说明**：本手册说明各分表的审计目标、编制逻辑与勾稽关联。
> **不替代**各表页内已有的审计目标/过程提示文案（页内说明保持不变）。
> 平台按钮与操作步骤见「使用手册」页签。

---

## 1. 总体编制思路

E1 把「货币资金」拆成四条证据链，最后汇入审定与附注：

| 证据链 | 主要底稿 | 回答的问题 |
|--------|----------|------------|
| **金额枢纽** | E1-2/E1-3/E1-4 → E1-1 ← E1-5 | 未审→调整→审定是否完整准确？ |
| **存在/权利** | E1-7/E1-8 现金监盘；E1-9 存单盘点；E1-6 余额调节；E1-3 函证 | 账实、对账、函证是否一致？ |
| **完整性** | E1-10 账户核对；E1-11 承诺书；E1-18/E1-19 信用报告 | 银行账户是否完整、无账外账户？ |
| **计价/收益/截止** | E1-15/E1-20 利息；E1-21/E1-22 截止；E1-23 收支检查 | 利息、外币折算、跨期是否恰当？ |

**枢纽原则**：

1. **E1-2/E1-3/E1-4 明细表是数据枢纽**——审定表与分析表从明细带入。
2. **E1-5 是调整枢纽**——差异确认后回写 E1-1。
3. **E1-1 是结论枢纽**——与试算（1001+1002+1012）、附注披露、现金流量表期末现金勾稽。
4. **E1A 程序表**统领「做了哪些程序」；分表记录「证据与结论」。

### 建议编制顺序（标准路径）

```
E1A 程序计划
  → E1-2/E1-3/E1-4 明细（先立清单）
  → 存在链：E1-6 余额调节 / E1-7·E1-8 现金监盘 / E1-9 存单盘点 / E1-3 函证
  → 完整性链：E1-10 账户核对 / E1-11 承诺书 / E1-18·E1-19 信用报告
  → 计价截止链：E1-15·E1-20 利息 / E1-21·E1-22 截止 / E1-23 收支检查
  → E1-14 分析 → 差异汇入 E1-5 → 确认回写 E1-1
  → 附注上市 / 附注国企
```

可按项目风险裁剪（如无外币可弱化 E1-8；无数字货币可弱化 E1-4），但 **明细 → E1-1** 与 **银行账户完整性** 不宜省略。

## 2. 分表编制说明

每张表按统一结构：**审计目标 → 编制逻辑 → 上游/下游 → 完成标志**。

### E1A 实质性程序表
- **审计目标**：规划并记录针对货币资金的实质性程序范围、性质与时间。
- **完成标志**：计划程序均有执行记录或「不适用」说明；索引可跳转分表。

### E1-1 审定表
- **审计目标**：核实库存现金、银行存款、其他货币资金余额准确完整；分类列报恰当；为报表与附注提供审定数。
- **编制逻辑**：期初/期末 × 未审 / 账项调整 / 审定；按 1001/1002/1012 展开；审定 = 未审 + 调整。
- **上游**：E1-2/E1-3/E1-4 汇总；E1-5 确认回写。**下游**：试算表；附注；现金流量表期末现金。
- **完成标志**：与 TB 勾稽差异已解释；调整来源可追溯至 E1-5；结论已填。

### E1-2 库存现金明细表 / E1-3 银行存款明细表 / E1-4 数字货币明细表（数据枢纽）
- **审计目标**：核实存在、完整、权利与计价；外币按期末汇率折算。
- **编制逻辑**：逐账户/币种列示，期初+增-减=期末滚动；银行存款按开户行×账号；其他货币资金按类别。
- **下游**：E1-1、E1-6、E1-10、E1-14 带入源。
- **完成标志**：清单完整、滚动勾稽通过；与 E1-1 汇总一致。

### E1-5 调整分录汇总
- **审计目标**：核实货币资金及相关科目调整完整、借贷平衡。
- **完成标志**：借贷平衡；已确认回写 E1-1；索引指向证据表。

### E1-6 银行存款余额调节表
- **审计目标**：银行存款账面余额与对账单差异合理（未达账项）。
- **编制逻辑**：企业账面 ± 未达账项 = 银行对账单余额，双向调节；与 E1-3 银行明细交叉校验。
- **完成标志**：调节后一致；未达账项有支持性证据。

### E1-7 库存现金盘点表（人民币）/ E1-8 库存现金盘点表（外币）
- **审计目标**：库存现金存在且账实相符。
- **编制逻辑**：监盘要素（日期/时间/地点/出纳/会计主管/监盘人）+ 盘点明细；账实差异原因。
- **完成标志**：盘点日、范围、差异处理已记录。

### E1-9 银行存单盘点表
- **审计目标**：定期存单/大额存单等存在且权属清晰。
- **完成标志**：存单清单与账面勾稽；受限情况已披露。

### E1-10 银行账户核对表
- **审计目标**：银行账户完整（无账外账户），报表所列账户真实存在。
- **编制逻辑**：账户清单 vs 账面记录双向差集；识别「清单有/账面无」的账外账户疑点。
- **完成标志**：账户完整性双向核对通过；账外账户已查明。

### E1-11 银行账户完整性承诺书
- **审计目标**：获取管理层对银行账户完整性的书面声明。
- **完成标志**：承诺书已签署留档。

### E1-14 货币资金分析表
- **审计目标**：分析货币资金构成、变动与合理性（受限资金、大额异常）。
- **完成标志**：重大变动已解释。

### E1-15 利息收入月度分析 / E1-20 应计利息测算
- **审计目标**：核实利息收入完整准确；期末应计利息合理。
- **编制逻辑**：按月度分析利息流量；按本金×利率×天数测算期末应计存量。
- **完成标志**：测算与账面差异已解释。

### E1-18 企业信用报告查询 / E1-19 企业信用报告核对
- **审计目标**：通过央行企业信用报告核对银行账户与借贷完整性。
- **完成标志**：查询记录留档；与账面账户/借款核对一致。

### E1-21 银行存款截止测试 / E1-22 其他货币资金截止测试
- **审计目标**：货币资金收支记录于恰当会计期间（截止认定）。
- **编制逻辑**：资产负债表日前后 N 天凭证抽取，判断跨期；可一键从序时账取数。
- **完成标志**：跨期项已标注并处理；差异已推送调整。

### E1-23 收支检查情况表
- **审计目标**：大额/异常货币资金收支真实、准确、有据。
- **编制逻辑**：凭证级检查（记账凭证 + 银行回单等支持性文件）；抽凭引擎科目 1001/1002/1012。
- **完成标志**：抽查比例达方案要求；异常已跟进。

### 附注披露（上市/国企）
- **审计目标**：按附注格式披露货币资金构成及受限情况，与审定勾稽。
- **完成标志**：金额与 E1-1 审定一致；受限资金已披露；已同步附注模块。

### 底稿目录
- **审计目标**：导航与编制进度总览（跨表结论口径 + 底稿架构）。
- **完成标志**：计划执行的分表状态均为完成或已说明不适用。

## 5. 质量复核要点（摘要）

1. E1-2/E1-3/E1-4 合计 ↔ E1-1 未审是否勾稽？
2. E1-5 已确认调整是否已体现在 E1-1？借贷是否平衡？
3. E1-6 余额调节是否与 E1-3 银行明细一致？未达账项是否有据？
4. E1-10 是否存在账外账户未查明？
5. E1-21/E1-22 跨期项是否已处理？
6. 附注金额是否等于 E1-1 审定？受限资金是否披露？
