# K1 其他应收款 — 平台使用手册

> 配合「编制手册」页签使用。
> 本手册只说明**平台怎么操作**；审计目标与勾稽逻辑见编制手册。
> **不修改**各分表页内已有说明文案。
> 入口：底稿目录页顶部「使用手册」按钮。

---

## 1. 打开与模式

1. 在项目底稿树打开 **K1 其他应收款**（`componentType: k1-other-receivables`，覆盖科目 1221 其他应收款 + 坏账准备）。
2. 通过 sheet 页签切换分表（K1A、K1-1～K1-12、附注上市/国企、底稿目录）。
3. 复杂 sheet 支持 **结构化 HTML ↔ OnlyOffice** 双模式；以项目配置为准（目录页除外）。
4. 只读阶段工具栏「取数 / 回写 / 确认」类按钮会禁用。

**需要项目上下文的操作**（缺 `projectId` 会提示无法执行）：

- K1-5 期后回款取数、K1-10 长期未收回期后取数
- K1-12 抽凭引擎（科目 1221）
- K1-11 从 B19 关联方清单带入
- 附注「同步到附注模块」

## 2. 推荐操作路径（点击顺序）

| 步骤 | 分表 | 建议操作 |
|------|------|----------|
| 1 | K1A | 勾选实质性程序、填索引 |
| 2 | K1-2 | 按对象 + 账龄录入其他应收款明细（3 区段 Tab） |
| 3 | K1-6 | 检查 ECL 会计政策与减值组合划分 |
| 4 | K1-7 | 三阶段划分（Stage1/2/3），处理升级信号 |
| 5 | K1-8 | 坏账准备测算，与 K1-3 企业计提交叉验证 |
| 6 | K1-3 | 坏账准备明细（计提/转回/核销滚动） |
| 7 | K1-5 | 大额款项分析（金额降序） |
| 8 | K1-9 | 转回/收回/核销检查 |
| 9 | K1-10 | 长期未收回款项检查（升级信号回流 K1-7） |
| 10 | K1-11 | 关联方检查（从 B19 带入 + K1-2 核对） |
| 11 | K1-12 | 综合检查（抽凭引擎，科目 1221） |
| 12 | K1-4 | 调整分录汇总 → 确认 → 回写 K1-1 |

## 3. 目录页速查

| 区块 | 说明 |
|------|------|
| 编制进度 | 各分表按实际填写字段数计算完成度 |
| 跨表结论口径 | 每张表审计结论「已填/未填」标签，点击跳转对应 sheet 补全 |
| 跨表勾稽 | K1-8↔K1-3、K1-2↔K1-1 等勾稽项，待处理项高亮 |
| 分组进度 | 核心 / 减值与ECL / 专项检查 / 附注披露 四组分组表格 |
| 编制提示 | 折叠展开，科目方向与公式速查 |

---

## 4. 导入导出

- 工具栏「导入/导出」按当前 sheet 作用。
- K1-2 明细、K1-9 核销检查等具备后端端点的 sheet 支持导入导出模板/数据。
- 导入后刷新当前表；若改了明细（K1-2），请重新对 K1-1 执行「从明细带入」。

---

## 5. 常见问题

| 现象 | 处理 |
|------|------|
| K1-1 审定合计 ≠ TB 数 | 检查明细是否全部带入、调整是否已确认回写 |
| K1-8 测算与 K1-3 计提差异大 | 复核账龄组合预期损失率与单项评估依据 |
| K1-7 阶段划分与 K1-10 不一致 | 处理 K1-10 升级信号，重新划分 Stage |
| K1-11 关联方带入为空 | 确认 B19 关联方清单已维护 |
| 抽凭无数据 | 确认凭证库有 1221 发生额且抽凭引擎可访问 |
| 附注同步失败 | 检查项目 ID、附注模块权限与准则类型（上市/国企） |

## 6. 复核入口

合伙人级复核提示词参考：`backend/data/tsj_review_prompts/K/`（若环境已部署）。
