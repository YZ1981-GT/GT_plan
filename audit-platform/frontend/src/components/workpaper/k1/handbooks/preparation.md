# K1 其他应收款 — 底稿编制手册

> **适用范围**：科目 **1221 其他应收款（借方/资产类）** + **坏账准备（资产备抵/贷方）**
> **组件**：`k1-other-receivables`
> **说明**：本手册说明各分表的审计目标、编制逻辑与勾稽关联。
> **不替代**各表页内已有的审计目标/过程提示文案（页内说明保持不变）。
> 平台按钮与操作步骤见「使用手册」页签。

## 1. 总体编制思路

K1 把「其他应收款」拆成三条证据链，最后汇入审定与附注：

| 证据链 | 主要底稿 | 回答的问题 |
|--------|----------|------------|
| **金额枢纽** | K1-2 明细 → K1-1 审定 ← K1-4 调整 | 余额（其他应收款+坏账准备）未审→调整→审定是否完整准确？ |
| **减值/ECL** | K1-6 政策 → K1-7 三阶段 → K1-8 测算 → K1-3 坏账明细 | 预期信用损失计量是否恰当、与企业计提是否勾稽？ |
| **专项检查** | K1-5 大额 / K1-9 核销 / K1-10 长期未收回 / K1-11 关联方 / K1-12 综合检查 | 大额与异常款项是否真实、合规、可收回？ |

**枢纽原则**：

1. **K1-2 明细表是数据枢纽**——审定表、大额分析、关联方、测算均从明细带入。
2. **K1-4 是调整枢纽**——AJE/RJE 借贷平衡后回写 K1-1。
3. **K1-1 是结论枢纽**——与试算（1221 其他应收款 / 坏账准备）、附注披露勾稽。
4. **K1A 程序表**统领「做了哪些程序」；分表记录「证据与结论」。

### 建议编制顺序（标准路径）

```
K1A 程序计划
  → K1-2 明细（先按对象+账龄立清单）
  → 减值链：K1-6 政策 → K1-7 三阶段划分 → K1-8 坏账测算 → K1-3 坏账准备明细
  → 专项检查：K1-5 大额 / K1-9 核销 / K1-10 长期未收回 / K1-11 关联方 / K1-12 综合
  → 差异汇入 K1-4 → 确认回写 K1-1
  → 附注上市 / 附注国企
```

可按项目风险裁剪（如无关联方往来可弱化 K1-11），但 **明细 → K1-1** 与 **ECL 三阶段 → 坏账测算** 不宜省略。

## 2. 分表编制说明

每张表按统一结构：**审计目标 → 编制逻辑 → 上游/下游 → 完成标志**。

### K1A 实质性程序表
- **审计目标**：规划并记录针对其他应收款的实质性程序范围、性质与时间。
- **完成标志**：计划程序均有执行记录或「不适用」说明；索引可跳转分表。

### K1-1 审定表（双区块）
- **审计目标**：核实其他应收款及坏账准备余额准确完整；账面净值列报恰当；为报表与附注提供审定数。
- **编制逻辑**：期初/期末 × 未审 / 账项调整 / 重分类 / 审定；分「其他应收款」与「坏账准备」两区块，按计提组合（单项/账龄组合/客户类型组合/其他）展开；审定 = 未审 + 账项调整 + 重分类；账面净值 = 其他应收款 − 坏账准备。
- **上游**：K1-2 明细汇总；K1-4 确认回写。**下游**：试算表；附注。
- **完成标志**：与 TB 勾稽差异已解释；调整来源可追溯至 K1-4；审计结论已填。

### K1-2 明细表（数据枢纽）
- **审计目标**：核实其他应收款存在、完整、权利与计价。
- **编制逻辑**：按往来对象 + 账龄区段列示（源模板 36 列，分 3 区段 Tab）；期末余额支撑 K1-1、K1-5、K1-8、K1-11。
- **完成标志**：清单完整、账龄合计与 K1-1 一致。

### K1-3 坏账准备明细表
- **审计目标**：核实坏账准备计提/转回/核销的完整准确。
- **编制逻辑**：期初 + 计提 − 转回 − 核销 = 期末（备抵类贷方）；与 K1-8 测算结果交叉验证。
- **完成标志**：滚动勾稽通过；与 K1-8 测算差异已解释。

### K1-4 调整分录汇总
- **审计目标**：核实其他应收款及相关科目调整完整、借贷平衡。
- **完成标志**：借贷平衡；已确认回写 K1-1；索引指向证据表。

### K1-5 大额其他应收款情况分析表
- **审计目标**：分析重点/大额款项性质、可收回性与合规性。
- **编制逻辑**：金额降序列示，逐笔说明款项性质、账龄、期后收款；关注股东/关联方占用资金。
- **完成标志**：大额款项均有分析；异常已跟进。

### K1-6 信用减值损失会计政策检查
- **审计目标**：核实 ECL 模型选择、账龄组合划分与预期损失率依据合理。
- **编制逻辑**：减值组合划分 + 预期损失率参数 + 同行业政策参考；判断组合是否合理。
- **完成标志**：政策依据充分；结论（A/B/C 口径）已填。

### K1-7 三阶段划分检查表
- **审计目标**：核实 ECL Stage1（12个月）/ Stage2（整个存续期）/ Stage3（已减值）划分恰当。
- **编制逻辑**：逐笔判断信用风险是否显著增加；逾期≥30 日、长期未收回等触发升级；与 K1-10 联动。
- **完成标志**：阶段划分一致；升级信号已处理。

### K1-8 坏账准备测算
- **审计目标**：独立测算预期信用损失，与企业计提（K1-3）交叉验证。
- **编制逻辑**：账龄组合按预期损失率测算 + 单项评估 + 迁徙率法；ECL = EAD × PD × LGD 或 余额 × 预期损失率。
- **完成标志**：测算与 K1-3 计提差异已解释；差异可推送 K1-4。

### K1-9 坏账准备转回(收回)核销检查表
- **审计目标**：核实坏账转回、收回、核销的审批依据与合规性。
- **编制逻辑**：凭证级检查（审批单/收款凭证）；核销需管理层审批与依据。
- **完成标志**：审批完整；合规判断已填。

### K1-10 长期未收回款项检查表
- **审计目标**：评估长期挂账款项的可回收性，识别应升级 Stage 的信号。
- **编制逻辑**：账龄 + 收回措施 + 可回收性评估；结论回流 K1-7 三阶段。
- **完成标志**：可回收性已评估；升级信号已推送 K1-7。

### K1-11 关联方及交易检查表
- **审计目标**：核实关联方往来的公允性与披露充分性。
- **编制逻辑**：从 B19 关联方清单 + K1-2 明细双向核对；识别资金占用。
- **完成标志**：关联往来完整识别；披露充分。

### K1-12 其他应收款检查表
- **审计目标**：凭证级综合检查（真实性/审批/期间/分类）。
- **编制逻辑**：抽凭引擎科目 1221；核对内容逐项勾选；检查比例达方案要求。
- **完成标志**：抽查比例达标；异常已跟进。

### 附注披露（上市/国企）
- **审计目标**：按附注格式披露其他应收款账龄、计提组合与坏账准备变动，与审定勾稽。
- **完成标志**：金额与 K1-1 审定一致；已同步附注模块。

### 底稿目录
- **审计目标**：导航与编制进度总览（跨表结论口径 + 分组进度）。
- **完成标志**：计划执行的分表状态均为完成或已说明不适用。

## 5. 质量复核要点（摘要）

1. K1-2 账龄合计 ↔ K1-1 未审是否勾稽？
2. K1-8 测算 ↔ K1-3 企业计提差异是否已解释？
3. K1-7 三阶段划分与 K1-10 长期未收回是否一致？

5. 附注金额是否等于 K1-1 审定？
