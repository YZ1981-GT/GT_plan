# G3 应收股利 — 平台使用手册

> 配合「编制手册」页签使用。  
> 本手册只说明**平台怎么操作**；审计目标与勾稽逻辑见编制手册。  
> **不修改**各分表页内已有说明文案。  
> 入口：顶栏「编制手册」或 G3A 程序控制台工具栏。

---

## 1. 打开与模式

1. 在项目底稿树打开 **G3 应收股利**（`componentType: g3-dividend-receivable`）。  
2. 通过 sheet 页签切换分表（G3A、G3-1～G3-5、附注上市/国企）。  
3. 已迁移分表支持 **结构化 HTML ↔ OnlyOffice** 双模式；以项目配置为准。  
4. 只读阶段「确认调整 / 取试算 / 导入 / 从调整分录模块同步」类按钮会禁用。

**需要项目上下文的操作**（缺 `projectId` 可能失败）：

- G3-1 取试算 / 回写试算 1131  
- G3-3 从调整分录模块同步  
- 导入导出 IE  
- 附注同步（若启用）

---

## 2. 推荐操作路径（点击顺序）

| 步骤 | 分表 | 建议操作 |
|------|------|----------|
| 1 | G3A | 勾选程序、填索引；可打开本手册 |
| 2 | G3-2 | 导入或录入明细（被投资方、持股、分红、应收/已收） |
| 3 | G3-1 | 「从 G3-2 汇总」拉入被投资方与本期宣告/收回（保留 AJE/RJE）→「取试算 1131」 |
| 4 | G3-4 | 从 G3-2 同步 → 补账面已计看差异 → 核对减少 → 期后收回抽凭 → 差异可推送 G3-3 |
| 5 | G3-5 | 填约定付款日与可收回性评估（供 G3-1 账龄条） |
| 6 | G3-3 | 按 Excel/D4 列录入 → 借贷平衡 → **确认调整**（联动模块 + 回写 G3-1）；可「从调整分录模块同步」 |
| 7 | G3-1 | 再核差异为 0 → 补齐橙色变动率原因 → 核对账龄条 |
| 8 | 附注 | 从 G3-1 带入或按上市/国企模板完成披露勾稽 |

## 3. 分表工具栏速查

| 分表 | 常用按钮 | 说明 |
|------|----------|------|
| G3-1 | 新增被投资方；**从 G3-2 汇总**；取试算 1131；显示/隐藏期初调整列；IE | 汇总覆盖本期宣告/收回并新建缺失被投资方，**保留**期初与 AJE/RJE；审定自动回写试算；G3-3 回写落在「账项调整汇总」；\|变动率\|>30% 须填原因分析；账龄条读 G3-5 |
| G3-2 | IE | 明细枢纽，改完再刷测算/逾期对照 |
| G3-3 | 新增分录；从调整分录模块同步；推送 A13；**确认调整**；IE | 列对齐 D4（类别=账项/报表/其他）；须借贷平衡且含 1131 行才有净额 |
| G3-4 | IE | 增加测算+减少检查（账面已计、测算差异） |
| G3-4-subsequent | IE | 期后收回凭证与核对勾选 |
| G3-5 | IE；从 G3-2 导入逾期 | 逾期天数自动算；逾期≥365 天进入 G3-1「一年以上」；明细更新且已有逾期行时回页会静默重导入 |
| 附注上市/国企 | 按表内提示 | 需项目适用准则上下文 |

### G3-1 期初调整列说明

- 默认**隐藏**期初 AJE/RJE，避免误把期初当本期调整口。  
- 仅前期差错更正或重述时点「显示期初调整列」。  
- 若已有非零期初调整，表头会提示存在隐藏列。

---

## 4. 导入导出

- G3-1 行 JSON 存于 **remark**；其余动态表默认 **conclusion**。  
- 导入后若改了 G3-2，请重新核 G3-4/G3-5。  
- G3-3 确认过后再导入会覆盖审定行时，请重新确认调整。

---

## 5. 排错

| 现象 | 处理 |
|------|------|
| G3-1 取试算为空 | 确认项目已导入试算且含 1131；确认审计年度已注入（取试算必传 year） |
| 附注表为空 | 点「从 G3-1 带入」同步被投资方期初/增减；空表时审定变更会自动带入 |
| 审定未进试算 | 检查项目 ID；看是否有回写失败提示 |
| 确认调整提示无 1131 净额 | 检查分录科目编码是否以 1131 开头，或科目名称是否含「应收股利」 |
| 确认按钮灰掉 | 借贷不平衡，先改平再确认 |
| 模块同步无数据 | 确认项目已有涉及 1131/6111 的调整分录，且审计年度正确 |
| G3-4 差异始终异常 | 补填「账面已计股利」列（差异=账面−测算） |
| 变动率橙色且提示未填原因 | 在「原因分析」列填写 >30% 波动说明 |
| 账龄「一年以上」为 0 但实际有逾期 | 先在 G3-5 填约定付款日与应收金额 |
| 账龄条告警「一年以上大于审定」 | 核对 G3-5 金额是否重复/是否未在 G3-1 立行 |
