# D2 应收账款 — 平台使用手册

> 配合「编制手册」页签使用。
> 本手册只说明**平台怎么操作**；审计目标与勾稽逻辑见编制手册。
> **不修改**各分表页内已有说明文案。
> 入口：底稿目录页顶部「使用手册」按钮。

---

## 1. 打开与模式

1. 在项目底稿树打开 **D2 应收账款**（`componentType: d2-accounts-receivable`，覆盖科目 1122）。
2. 通过 sheet 页签切换分表（D2A、D2-1～D2-13、附注上市/国企、底稿目录）。
3. 复杂 sheet 支持 **结构化 HTML ↔ OnlyOffice** 双模式；以项目配置为准（目录页除外）。
4. 只读阶段工具栏「取数 / 回写 / 确认」类按钮会禁用。

**需要项目上下文的操作**：D2-7 抽凭、期后回款取数、附注「同步到附注模块」。

---

## 2. 推荐操作路径（点击顺序）

| 步骤 | 分表 | 建议操作 |
|------|------|----------|
| 1 | D2A | 勾选实质性程序、填索引 |
| 2 | D2-2 | 录入客户账龄明细，标注信用风险组合方式（⚙列设置可调列） |
| 3 | D2-5 | 应收账款分析 |
| 4 | D2-7 | 应收账款检查（凭证级 + 期后回款） |
| 5 | D2-8 / D2-9 / D2-10 | 政策检查 → 坏账测算 → ECL 计量测试 |
| 6 | D2-3 | 坏账准备明细（与测算勾稽） |
| 7 | D2-6 / D2-12 / D2-13 | 关联方 / 质押出售 / 业务模式 |
| 8 | D2-11 | 转回核销检查 |
| 9 | D2-4 | 调整分录汇总 → 确认 → 回写 D2-1 |
| 10 | D2-1 | 从 D2-2 按组合方式带入 → 核对调整回写 → 勾稽 TB |
| 11 | 附注上市/国企 | 拉取上游 → 编辑 → 同步附注模块 |

## 3. 目录页速查

| 区块 | 说明 |
|------|------|
| 编制进度 | 各分表填妥「审计说明或结论」即计入完成 |
| 跨表结论口径 | 每张表审计结论「已填/未填」标签，点击跳转对应 sheet 补全 |
| 编制提示 | 折叠展开，推荐编制工作流 |
| 底稿目录表 | 逐 sheet 名称/索引号/适用性，索引 chip 跳转 |
| 本循环底稿目录 | 同循环（D 循环）其他底稿（灰色表示未生成） |

---

## 4. 导入导出

- 工具栏「导入/导出」按当前 sheet 作用（具备后端端点的 sheet，如 D2-2）。
- 导入后刷新当前表；若改了 D2-2 明细，请重新对 D2-1 执行「从明细带入」。

---

## 5. 常见问题

| 现象 | 处理 |
|------|------|
| D2-1 审定合计 ≠ TB 数 | 检查 D2-2 是否全部带入、调整是否已确认回写 |
| D2-10 与 D2-3 减值差异 | 核对 ECL 三要素与坏账准备计提基础 |
| D2-12 保理终止确认 | 用向导逐份合同判断，受限披露 |
| 抽凭无数据 | 确认凭证库有 1122 发生额且抽凭引擎可访问 |
| 附注同步失败 | 检查项目 ID、附注模块权限与准则类型（上市/国企） |

## 6. 复核入口

各分表工具栏/结论区「复核」打开复核对话（按 section-id）。
合伙人级复核提示词参考：`backend/data/tsj_review_prompts/D/`（若环境已部署）。
