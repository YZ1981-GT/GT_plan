# D2 应收账款 — 底稿编制手册

> **适用范围**：科目 **1122 应收账款**
> **组件**：`d2-accounts-receivable`
> **说明**：本手册说明各分表的审计目标、编制逻辑与勾稽关联。
> **不替代**各表页内已有的审计目标/过程提示文案（页内说明保持不变）。
> 平台按钮与操作步骤见「使用手册」页签。

## 1. 总体编制思路

D2 把「应收账款」拆成四条证据链，最后汇入审定与附注：

| 证据链 | 主要底稿 | 回答的问题 |
|--------|----------|------------|
| **金额枢纽** | D2-2 明细 → D2-1 ← D2-4 | 未审→调整→审定是否完整准确？ |
| **计价/减值** | D2-3 坏账明细；D2-8 政策；D2-9 坏账测算；D2-10 ECL；D2-11 转回核销 | 坏账准备计提是否充分、政策是否恰当？ |
| **存在/发生** | D2-7 检查表（凭证级）；函证；D2-5 分析 | 应收账款存在、发生真实？ |
| **完整性/披露** | D2-6 关联方；D2-12 质押出售；D2-13 业务模式；附注 | 关联方、质押保理、业务模式披露是否完整？ |

**枢纽原则**：

1. **D2-2 明细表是数据枢纽**——信用风险组合方式列驱动 D2-1 的 SUMIF 聚合。
2. **D2-4 是调整枢纽**——差异确认后回写 D2-1。
3. **D2-1 是结论枢纽**——与试算（1122）、附注披露勾稽。
4. **D2A 程序表**统领「做了哪些程序」；分表记录「证据与结论」。

### 建议编制顺序（标准路径）

```
D2A 程序计划
  → D2-2 明细（先立清单，标注信用风险组合方式）
  → D2-5 分析 → 函证 → D2-7 凭证检查（存在/发生）
  → D2-8 政策 → D2-9 坏账测算 → D2-10 ECL 计量测试 → D2-3 坏账准备明细
  → D2-6 关联方 / D2-12 质押出售 / D2-13 业务模式 / D2-11 转回核销
  → 差异汇入 D2-4 → 确认回写 D2-1
  → 附注上市 / 附注国企
```

可按项目风险裁剪（如无保理可弱化 D2-12），但 **明细 → D2-1** 与 **坏账减值** 不宜省略。

## 2. 分表编制说明

每张表按统一结构：**审计目标 → 编制逻辑 → 上游/下游 → 完成标志**。

### D2A 实质性程序表
- **审计目标**：规划并记录应收账款实质性程序范围、性质与时间。
- **完成标志**：计划程序均有执行记录或「不适用」说明。

### D2-1 审定表
- **审计目标**：核实应收账款余额准确完整；按单项/账龄/客户组合分类列报；提供审定数。
- **编制逻辑**：期初/期末 × 未审 / 账项调整 / 审定；按信用风险分类展开；审定 = 未审 + 调整。
- **上游**：D2-2 按组合方式 SUMIF 汇总；D2-4 确认回写。**下游**：试算表（1122）；附注。
- **完成标志**：与 TB 勾稽差异已解释；结论已填。

### D2-2 明细表（数据枢纽）
- **审计目标**：核实存在、完整、权利与计价；逐客户列示账龄。
- **编制逻辑**：客户 × 账龄段；标注信用风险组合方式（单项计提/账龄组合/客户类型组合）驱动 D2-1 聚合。
- **下游**：D2-1、D2-3、D2-5 带入源。
- **完成标志**：清单完整、账龄勾稽通过；与 D2-1 汇总一致。

### D2-3 坏账准备明细表
- **审计目标**：核实坏账准备期初/计提/转回/核销/期末完整准确。
- **编制逻辑**：单项 + 账龄组合 + 客户类型组合三视图；期末未审 = 期初审定 + 计提 + 其他增加 − 转回 − 核销 − 其他减少。
- **完成标志**：与 D2-9/D2-10 测算勾稽；结论已填。

### D2-4 调整分录汇总表
- **审计目标**：核实应收账款及相关科目调整完整、借贷平衡。
- **完成标志**：借贷平衡；已确认回写 D2-1。

### D2-5 应收账款分析表
- **审计目标**：分析应收账款周转、账龄结构、大额与异常变动的合理性。
- **完成标志**：重大变动已解释。

### D2-6 关联方及交易检查表
- **审计目标**：识别关联方应收，核对披露完整性。
- **完成标志**：关联方应收已识别，与 B19 清单核对。

### D2-7 应收账款检查表
- **审计目标**：以凭证级检查佐证应收账款存在、发生真实。
- **编制逻辑**：本期发生凭证 + 期后回款；核对内容逐项勾选。
- **完成标志**：抽查比例达方案要求；异常已跟进。

### D2-8 坏账准备计提会计政策检查
- **审计目标**：坏账准备计提政策（减值组合划分、比例）符合准则。
- **完成标志**：政策逐项判断结论已填。

### D2-9 应收坏账准备测算
- **审计目标**：单项 + 组合坏账准备重新测算，与账面比较。
- **完成标志**：测算与账面差异已解释。

### D2-10 预期信用损失计量测试
- **审计目标**：按 ECL 三要素（违约概率/违约损失率/前瞻性）测算减值。
- **编制逻辑**：迁徙率矩阵 + 概率加权 + 前瞻性调整；与 D2-3 合计勾稽。
- **完成标志**：ECL 测算与 D2-3 一致；结论已填。

### D2-11 坏账准备转回（收回）、核销检查表
- **审计目标**：核实坏账转回/核销的合规性与授权。
- **完成标志**：转回/核销有据、已授权。

### D2-12 应收账款质押出售情况检查表
- **审计目标**：核实质押/保理应收，判断终止确认（CAS23）。
- **编制逻辑**：保理合同条款分析 + 终止确认判断向导。
- **完成标志**：质押/保理已识别，终止确认判断有据，受限披露完整。

### D2-13 应收账款业务模式分析
- **审计目标**：判断应收账款的业务模式与计量分类（是否符合 SPPI/以摊余成本计量）。
- **完成标志**：业务模式判断结论已填。

### 附注披露（上市/国企）
- **审计目标**：按附注格式披露应收账款账龄、坏账准备、前五名、关联方，与审定勾稽。
- **完成标志**：金额与 D2-1 审定一致；已同步附注模块。

### 底稿目录
- **审计目标**：导航与编制进度总览（跨表结论口径 + 底稿架构）。
- **完成标志**：计划执行的分表状态均为完成或已说明不适用。

## 5. 质量复核要点（摘要）

1. D2-2 合计（按组合方式）↔ D2-1 未审是否勾稽？
2. D2-4 已确认调整是否已体现在 D2-1？借贷是否平衡？
3. D2-10 ECL 测算 ↔ D2-3 坏账准备是否一致？
4. D2-12 保理/质押终止确认判断是否有据？受限是否披露？
5. 附注金额是否等于 D2-1 审定？账龄结构是否一致？
