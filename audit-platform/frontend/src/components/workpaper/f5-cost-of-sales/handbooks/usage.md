# F5 营业成本 — 平台使用手册

> 配合「编制手册」页签使用。
> 本手册只说明**平台怎么操作**；审计目标与勾稽逻辑见编制手册。
> **不修改**各分表页内已有说明文案。
> 入口：底稿目录页顶部「使用手册」按钮。

---

## 1. 打开与模式

1. 在项目底稿树打开 **F5 营业成本**（`componentType: f5-cost-of-sales`，覆盖科目 6401 发生额）。
2. 通过 sheet 页签切换分表（F5A、F5-1～F5-8、底稿目录）。
3. 复杂 sheet 支持 **结构化 HTML ↔ OnlyOffice** 双模式；以项目配置为准（目录页除外）。
4. 只读阶段工具栏「取数 / 回写 / 确认」类按钮会禁用。

**需要项目上下文的操作**（缺 `projectId` 会提示无法执行）：

- F5-2 从序时账取数（6401 按产品×月）、F5-8 抽凭
- F5-5 拉取 D4 营业收入做毛利分析

---

## 2. 推荐操作路径（点击顺序）

| 步骤 | 分表 | 建议操作 |
|------|------|----------|
| 1 | F5A | 勾选实质性程序、填索引 |
| 2 | F5-2 | 录入/从序时账取数（产品×月度成本） |
| 3 | F5-6 | 数量核对（产销/库存变动数量勾稽） |
| 4 | F5-7 | 成本倒轧表（与 F2 存货勾稽） |
| 5 | F5-3 | 其他业务成本 |
| 6 | F5-5 | 比较分析（毛利率，拉取 D4 收入配比） |
| 7 | F5-8 | 重大调整核查（抽凭引擎，科目 6401） |
| 8 | F5-4 | 调整分录 → 确认 → 回写 F5-1 |
| 9 | F5-1 | 「从明细带入」汇总未审发生额 → 核对调整回写 → 勾稽 TB |

## 3. 目录页速查

| 区块 | 说明 |
|------|------|
| 编制进度 | 各分表填妥「审计说明或结论」即计入完成 |

---

## 4. 导入导出

- 工具栏「导入/导出」按当前 sheet 作用（具备后端端点的 sheet）。
- F5-2 可「从序时账取数」按月×产品聚合 6401 发生额；导入后刷新当前表；改了明细请重新对 F5-1 执行「从明细带入」。

---

## 5. 常见问题

| 现象 | 处理 |
|------|------|
| F5-1 审定发生额 ≠ TB(6401) 发生额 | 检查明细是否全部带入、调整是否已确认回写 |
| 成本倒轧对不上 | F5-7 核对 F2 存货期初/期末余额与入库/生产数据 |
| 毛利率异常 | F5-5 分析原因（价格/成本结构/产品结构），与 D4 收入配比核对 |
| 数量口径不一致 | F5-6 核对产量/销量/库存变动数量 |
| 从序时账取数为空 | 确认序时账有 6401 发生额且项目上下文可访问 |
| 跨期成本 | F5-8 核查后经 F5-4 调整 |

---

## 6. 复核入口

各分表工具栏/结论区「复核」打开复核对话（按 section-id）。
合伙人级复核提示词参考：`backend/data/tsj_review_prompts/F/`（若环境已部署）。
