# F5 营业成本 — 底稿编制手册

> **适用范围**：科目 **6401 营业成本**（主营业务成本 / 其他业务成本）
> **组件**：`f5-cost-of-sales`（损益类借方：审定取本期发生额）
> **说明**：本手册说明各分表的审计目标、编制逻辑与勾稽关联。
> **不替代**各表页内已有的审计目标/过程提示文案（页内说明保持不变）。
> 平台按钮与操作步骤见「使用手册」页签。

## 1. 总体编制思路

F5 是损益类底稿，围绕「成本结转真实完整 → 成本核算准确 → 收入成本配比 → 毛利合理」组织，与存货（F2）、收入（D4）紧密勾稽：

| 证据链 | 主要底稿 | 回答的问题 |
|--------|----------|------------|
| **金额枢纽** | F5-2 → F5-1 ← F5-4 | 未审→调整→审定（本期发生额）是否完整准确？ |
| **成本核算/倒轧** | F5-6 数量核对；F5-7 成本倒轧表；F5-3 其他业务成本 | 成本结转与存货变动是否勾稽？数量口径是否一致？ |
| **配比/合理性** | F5-5 比较分析（毛利率）；F5-8 重大调整核查 | 收入成本是否配比？毛利率异动是否合理？重大调整是否有据？ |

**枢纽原则（损益取发生额）**：

1. **F5-2 月度明细是数据枢纽**——审定表按产品/月度从明细带入；损益类取**本期发生额**（借−贷）。
2. **F5-4 是调整枢纽**——差异确认后回写 F5-1。
3. **F5-1 是结论枢纽**——与试算（6401 发生额）勾稽，向利润表提供审定数。
4. **F5-7 成本倒轧表**是核心勾稽：期初存货 + 本期入库/生产 − 期末存货 = 本期结转成本，与 F2 存货勾稽。
5. **F5A 程序表**统领「做了哪些程序」。

### 建议编制顺序（标准路径）

```
F5A 程序计划
  → F5-2 月度明细（先立各产品/月度成本清单）
  → 成本核算链：F5-6 数量核对 → F5-7 成本倒轧表（与 F2 存货勾稽）
  → F5-3 其他业务成本
  → 配比/分析链：F5-5 比较分析（毛利率，与 D4 收入配比）
  → F5-8 重大调整核查（大额/异常成本调整凭证核查）
  → 差异汇入 F5-4 → 确认回写 F5-1
  → F5-1 从明细带入 → 勾稽 TB(6401 发生额)
```

按项目风险裁剪（无其他业务成本可弱化 F5-3），但 **成本倒轧（F5-7）与毛利分析（F5-5）** 不宜省略。

## 2. 分表编制说明

每张表按统一结构：**审计目标 → 编制逻辑 → 上游/下游 → 完成标志**。

### F5A 实质性程序表
- **审计目标**：规划并记录针对营业成本的实质性程序范围、性质与时间。
- **完成标志**：计划程序均有执行记录或「不适用」说明；索引可跳转分表。

### F5-1 审定表
- **审计目标**：核实营业成本（主营/其他）发生额完整准确；与营业收入配比；为利润表提供审定数。
- **编制逻辑**：主营业务成本 / 其他业务成本 分行；审定 = 未审发生额 + 账项调整；与上期发生额比较分析。
- **上游**：F5-2/F5-3 汇总；F5-4 确认回写。**下游**：试算表（6401 发生额）；利润表。
- **完成标志**：与 TB 发生额勾稽差异已解释；调整来源可追溯至 F5-4；结论已填。

### F5-2 月度明细（数据枢纽）
- **审计目标**：核实各产品/月度成本结转真实、准确、完整。
- **编制逻辑**：按产品 × 月度列示营业成本；可从序时账（6401 按产品×月）取数；与产量/销量核对。
- **下游**：F5-1、F5-5、F5-7 带入源。
- **完成标志**：月度清单完整、与 F5-1 汇总一致。

### F5-3 其他业务成本
- **审计目标**：核实其他业务成本（材料销售、租赁等）真实、与其他业务收入配比。
- **完成标志**：其他业务成本逐项有据、与收入配比。

### F5-4 调整分录
- **审计目标**：核实营业成本及相关科目调整完整、借贷平衡。
- **完成标志**：借贷平衡；已确认回写 F5-1；索引指向证据表。

### F5-5 比较分析（毛利率）
- **审计目标**：通过毛利率、成本结构、占收入比分析识别异常。
- **编制逻辑**：本期 vs 上期毛利率；分产品毛利率（可拉取 D4 收入做配比）；异常波动逐项分析原因。
- **上游**：D4 营业收入。
- **完成标志**：毛利率异动原因已分析、有结论。

### F5-6 数量核对
- **审计目标**：核对成本结转数量与产销、存货变动数量一致。
- **编制逻辑**：产量 / 销量 / 库存变动数量勾稽，验证成本结转数量口径。
- **完成标志**：数量核对一致，差异已解释。

### F5-7 成本倒轧表
- **审计目标**：以「期初存货 + 本期入库/生产 − 期末存货 = 本期结转成本」倒轧验证成本结转完整性。
- **编制逻辑**：与 F2 存货期初/期末余额勾稽；倒轧差异分析。
- **上游**：F2 存货。
- **完成标志**：倒轧结果与 F5-1 结转成本勾稽一致。

### F5-8 重大调整核查表
- **审计目标**：对大额/异常成本调整（如跨期成本、成本冲回）进行凭证级核查。
- **编制逻辑**：抽取重大成本调整，检查记账凭证与支持性文件；含抽凭引擎（科目 6401）。
- **完成标志**：重大调整逐笔核查、异常已跟进。

### 底稿目录
- **审计目标**：导航与编制进度总览（跨表结论口径 + 底稿架构）。

## 3. 认定覆盖速查

| 认定 | 主要底稿 |
|------|----------|
| 发生 | F5-8、F5-2 |
| 完整性 | F5-7 成本倒轧、F5-2 |
| 准确性 | F5-2、F5-6 数量核对、F5-1 |
| 截止 | F5-8 跨期成本核查 |
| 分类 | F5-1（主营/其他业务成本）、F5-3 |

## 4. 外部模块衔接

| 模块 | 与 F5 关系 |
|------|------------|
| **调整分录模块** | 与 F5-4 双向同步；确认驱动 F5-1 |
| **试算平衡表** | F5-1 审定回写 6401（发生额） |
| **F2 存货** | F5-7 成本倒轧与存货变动勾稽 |
| **D4 营业收入** | F5-5 收入成本配比、毛利率分析 |
| **利润表** | F5-1 审定数提供营业成本 |

## 5. 质量复核要点（摘要）

1. F5-2/F5-3 合计 ↔ F5-1 未审发生额是否勾稽？
2. F5-7 成本倒轧（期初+入库−期末=结转成本）是否与 F2 存货勾稽？
3. F5-5 毛利率异动是否合理？是否与 D4 收入配比？
4. F5-6 成本结转数量与产销/存货变动是否一致？
5. F5-8 重大成本调整（跨期/冲回）是否核查、有据？
6. F5-1 审定发生额是否等于 TB(6401) 发生额？
