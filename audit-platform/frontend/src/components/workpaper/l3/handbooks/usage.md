# L3 长期借款 — 平台使用手册

> 配合「编制手册」页签使用。本手册只说明**平台怎么操作**；审计目标与勾稽逻辑见编制手册。
> **不修改**各分表页内已有说明文案。入口：底稿目录页顶部「使用手册」按钮。

---

## 1. 打开与模式

1. 在项目底稿树打开 **L3 长期借款**（`componentType: l3-long-term-loans`，覆盖科目 2501）。
2. 通过 sheet 页签切换分表（L3A、L3-1～L3-9、附注上市/国企、底稿目录）。
3. 程序表（L3A）支持 **结构化 HTML ↔ OnlyOffice** 双模式；以项目配置为准（目录页不显示双模式）。
4. 只读阶段工具栏「取数 / 回写 / 确认」类按钮会禁用。

---

## 2. 推荐操作路径（点击顺序）

| 步骤 | 分表 | 建议操作 |
|------|------|----------|
| 1 | L3A | 勾选实质性程序、填索引 |
| 2 | L3-2 | 按借款银行/合同逐笔录入明细，标记一年内到期 |
| 3 | L3-5 | 利息测算：本金×利率×天数/365，划分资本化/费用化，联动 L2/L8 |
| 4 | L3-4 | 征信报告核对：与账面借款双向差集 |
| 5 | L3-7 | 逾期检查：逾期天数、风险等级、展期 |
| 6 | L3-6 / L3-8 | 合同要素检查 / 抵质押担保检查 |
| 7 | L3-3 | 调整分录汇总（含一年内到期重分类 RJE：借 2501 / 贷 2801）→ 确认 → 回写 L3-1 |
| 8 | L3-1 | 确认审定期末（从 L3-2 带入）→ 减一年内到期得披露审定 → 回写 TB(2501) |
| 9 | 附注上市/国企 | 从审定表按分类取数（披露审定/非流动数）→ 编辑 → 同步附注模块 |

| 区块 | 说明 |
|------|------|
| 编制进度 | 各分表按审计说明/结论填写情况计算完成度 |

## 4. 常见问题

| 现象 | 处理 |
|------|------|
| L3-1 审定 ≠ TB 数 | 检查明细是否全部带入、调整是否已确认回写；TB 取 2501 期末余额 |
| 披露数与审定不符 | 披露审定 = 审定 − 一年内到期；确认 L3-2 一年内到期标记与 L3-3 重分类一致 |
| 利息测算与账面不符 | 复核本金、年利率、计息天数；确认资本化/费用化划分与 L2 应付利息 / L8 财务费用口径一致 |
| 征信核对差异 | 逐笔说明征信报告与账面差异，重点关注账外借款 |
| 附注分类金额不符 | 附注分类（信用/抵押/保证/质押）金额应等于 L3-1 各分类披露审定数（非流动） |
| 附注同步失败 | 检查项目 ID、附注模块权限与准则类型（上市/国企） |
