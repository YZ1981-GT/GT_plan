# G5 长期应收款 — 平台使用手册

> 配合「编制手册」页签使用。  
> 本手册只说明**平台怎么操作**；审计目标与勾稽逻辑见编制手册。  
> **不修改**各分表页内已有说明文案。  
> 入口：顶栏「编制手册」或 G5A 程序控制台工具栏。

---

## 1. 打开与模式

1. 在项目底稿树打开 **G5 长期应收款**（`componentType: g5-long-term-receivable`）。  
2. 通过 sheet 页签切换分表（G5A、G5-1～G5-12、附注上市/国企、底稿目录）。  
3. 已迁移分表支持 **结构化 HTML ↔ OnlyOffice** 双模式；以项目配置为准。  
4. 只读阶段「带入 / 回写 / 确认 / 导入」类按钮会禁用。

**需要项目上下文的操作**（缺 `projectId` 可能失败）：

- G5-1 试算勾稽 1531  
- 附注「同步至附注」  
- G5-12 抽凭引擎  
- 账龄配置（底稿配置）

## 4. 导入导出

| 支持 IE（前后端一致） | 界面编辑为主（无后端 IE） |
|---------|----------------|
| G5-1～G5-7、G5-11、G5-12 | G5-8、G5-9、G5-10、G5A、附注 |

- 工具栏「导入/导出」按当前 sheet 作用；**G5-9/G5-10 不提供 IE**（阶段与 ECL 在界面编辑）。  
- G5-5/6/11 导出为扁平行（Excel），导入后还原为嵌套结构；利率在表中为百分数。  
- 导入后行数据优先写入 checklist `conclusion`（并双写 `remark`）；刷新后仍保留。  
- 改了 G5-2 后请对下游重新「带入」。  
- G5-4「确认调整」会立即回写 G5-1（非仅防抖）。  
- **上年结转**：G5-2 工具栏；默认不覆盖已填期初，空表时可强制覆盖；匹配键优先 `crossSheetReceivableId`。  
- **底稿目录**展示分表编制进度（数据/结论/G5-4 勾稽/G5-11·G5-12 闸门）。

## 5. 常见问题

| 现象 | 处理 |
|------|------|
| 刷新后表格为空 | 确认已编辑触发自动保存；或从 IE 重新导入 |
| G5-4 确认后 G5-1 无变化 | 须点「确认调整」且借贷平衡；默认写入原值合计行期末 AJE |
| 账龄合计红色 | 账龄审定之和应等于净额 |
| G5-9/10 阶段不一致 | 在 G5-9 点「同步阶段至 G5-10」 |
