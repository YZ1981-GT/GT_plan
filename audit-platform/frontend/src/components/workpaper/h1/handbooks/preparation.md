# H1 固定资产 · 编制手册

> 目标：证明固定资产**存在、完整、权属、计价（折旧/减值）、列报披露**五项认定，确认期末原值、累计折旧、减值准备与账面净值，并回写试算平衡表科目 **1601 固定资产原值 / 1602 累计折旧**。

## 一、底稿逻辑与推荐工作流

1. **H1A 程序表**：确认审计程序清单与 C6 前置控制测试结论。
2. **H1-1 审定表**：期初/期末未审 → 账项调整（AJE）/重分类（RJE）→ 审定；原值−累计折旧−减值 = 账面净值；确认后回写 TB（1601/1602）。
3. **H1-2 明细表**：逐项（或分类）登记原值/折旧/减值，勾稽 H1-1 审定合计。
4. **实质性检查**：H1-4 闲置 / H1-5 会计政策估计 / H1-7 增加 / H1-8 减少 / H1-16 房屋权属 / H1-17 运输设备权属 / H1-18 关联交易 / H1-19 经营租出 / H1-20 融资租出。
5. **折旧与减值**：H1-6 分析 → H1-12 折旧测算（直线法等）→ H1-13 折旧分配 → H1-14 减值测算 → H1-15 可收回金额测试。
6. **监盘核查组**：H1-9 监盘计划 → H1-10 盘点检查 → H1-11 监盘小结，与 H1-1 审定表交叉核对实存。
7. **差异**汇总进 **H1-3 调整分录**，回写 H1-1；**附注披露**（上市/国企）从审定表/明细表取数。

## 二、关键勾稽

- 审定表原值合计 = 明细表原值合计；累计折旧、减值同理。
- 账面净值 = 原值 − 累计折旧 − 减值准备。
- 折旧本期计提（H1-12）→ H1-13 分配到成本费用；整体重算复核（H1-6）差异率 > 10% 需说明。
- 转入固定资产（H1-7 在建工程转入）↔ H2 在建工程转固合计勾稽。
- 抵押/查封固定资产（H1-16）↔ 借款质押披露（L1/L3/L4）与或有事项交叉核对。
- 税会折旧差异 → 递延所得税（N1 资产 / N3 负债）。

## 三、审计说明与结论

每张数据承载表（审定/明细/检查/折旧/减值/监盘）均应填写**审计说明**与**审计结论**；目录页「跨表结论口径看板」实时显示各表结论是否已填，点击标签可跳转补全。
