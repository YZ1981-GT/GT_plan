# H1 固定资产 · 使用手册（平台操作）

## 一、导航与目录

- **底稿目录页**顶部为目录卡（标题 + 复核入口 + 编制/使用手册）+ **跨表结论口径看板** + **底稿架构泳道** + **本循环底稿目录**。
- 点击「底稿架构」卡片或「跨表结论口径」标签 → 跳转对应 sheet。
- 「本循环底稿目录」grid 可跳转 H 循环其他底稿（灰色表示尚未生成）。

## 二、双模式

- 非目录 sheet 顶部提供「结构化视图 / 在线编辑（OnlyOffice）」切换；OnlyOffice 不可用时自动回退结构化视图。
- 目录页不显示模式切换工具栏。

## 三、数据录入与联动

- 审定表/明细表数值列自动计算（净值 = 原值 − 累计折旧 − 减值），公式列只读。
- 审定表确认后自动回写试算平衡表（1601/1602）并广播 `substantive:adjudicated`，附注披露自动刷新取数。
- 增加/减少/权属等检查表支持科学抽凭引擎、行级附件 OCR 与跨底稿跳转芯片。
- 调整分录（H1-3）借贷平衡后可推送至 A13 错报汇总 / 集中调整登记。

## 四、复核与版本

- 各表标题栏「💬 复核」可发起复核对话；蓝/红圆点表示复核线程状态。
- 顶部「版本历史」可查看时光机快照，保存后自动生成快照。

## 五、导入导出

- 含动态行的明细/检查表提供「导入导出▾」（导出模板 / 导出数据 / 导入数据）。
