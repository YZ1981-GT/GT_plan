# F2 存货及存货跌价准备 — 底稿编制手册

> **适用范围**：科目 **1401~1411 存货**（原材料/在产品/产成品/周转材料等）+ **1471 存货跌价准备**
> **组件**：`f2-inventory-main` / `f2-inventory-special` / `f2-inventory-valuation` / `f2-stocktake-bundle`
> **说明**：本手册说明各分表的审计目标、编制逻辑与勾稽关联。
> **不替代**各表页内已有的审计目标/过程提示文案（页内说明保持不变）。
> 平台按钮与操作步骤见「使用手册」页签。

## 1. 总体编制思路

F2 是存货循环最复杂的底稿册，围绕「数量真实（存在/完整）→ 计价准确 → 减值充分 → 成本归集正确 → 关联/供应商风险」组织：

| 证据链 | 主要底稿 | 回答的问题 |
|--------|----------|------------|
| **金额枢纽** | F2-2 明细汇总 → F2-1 审定 ← F2-14 调整 | 未审→调整→审定是否完整准确？ |
| **数量存在** | F2 监盘册（GtF2StocktakeBundle）；F2-33/34/35 出入库/领用/委托加工核查 | 账实是否相符？出入库是否真实？ |
| **计价** | F2-38 加权平均 / F2-39 先进先出 / F2-40 标准成本；F2-41~44 生产成本归集与分配 | 存货成本核算方法与成本归集是否恰当？ |
| **减值** | F2-16 政策 / F2-47 减值测试 / F2-48 呆滞 / F2-49 转回；1471 跌价准备 | 存货可变现净值 vs 成本，跌价准备是否充分？ |
| **合同成本** | F2-55/56/57/58（合同履约成本、减值、亏损合同） | CAS14 合同成本确认、减值、亏损合同是否恰当？ |
| **关联/供应商** | F2-52 关联采购；F2-65~72 关联方与供应商结构/走访 | 采购真实性、关联采购定价公允、供应商是否异常？ |

**枢纽原则**：

1. **F2-2 明细汇总是数据枢纽**——审定表按存货类别从明细带入。
2. **F2-14 是调整枢纽**——差异确认后回写 F2-1。
3. **F2-1 是结论枢纽**——与试算（1401 存货 / 1471 跌价准备）勾稽，向报表与附注提供审定数。
4. **F2A 程序表**统领；F2-55A/61A 为合同成本/IPO 专项程序表。

### 建议编制顺序（标准路径）

```
F2A 程序计划
  → F2-2 明细汇总（先立各类别存货清单）
  → 数量链：监盘册（计划/执行/小结）→ F2-33 采购入库 / F2-34 领用 / F2-35 委托加工核查
  → 计价链：F2-38/39/40 计价方法测试 → F2-41~44 生产成本归集与分配
  → 减值链：F2-16 政策 → F2-47 减值测试（NRV vs 成本）→ F2-48 呆滞 / F2-49 转回
  → 合同成本（如适用）：F2-55~58
  → 分析：F2-18 总体分析 / F2-19 产销分析 / F2-20 成本比较
  → 关联/供应商：F2-52 / F2-65~72
  → 差异汇入 F2-14 → 回写 F2-1
  → F2-1 从明细带入 → 勾稽 TB（1401/1471）
  → 附注上市 / 附注国企
```

按项目风险裁剪（无合同成本可弱化 F2-55~58；非制造业弱化 F2-41~44），但 **监盘、计价、减值** 三条链不宜省略。

## 2. 分表编制说明（按功能分组）

每张表按统一结构：**审计目标 → 编制逻辑 → 上游/下游 → 完成标志**。

### 汇总与调整
- **F2A 实质性程序表**：规划并记录存货实质性程序范围。
- **F2-1 审定表**：核实存货余额准确完整、跌价准备恰当、分类列报正确；审定 = 未审 + 账项调整 + 重分类调整。上游 F2-2；下游 TB（1401/1471）、附注。
- **F2-2 明细汇总表**（数据枢纽）：按存货类别汇总数量金额，与 F2-1 勾稽。
- **F2-14 调整分录**：存货及跌价准备调整，借贷平衡后回写 F2-1。

### 明细与成本归集
- **F2-5 周转材料 / F2-7 委托加工物资 / F2-10~11 开发成本 / F2-12 合同履约成本 / F2-13 生物资产**：各类特殊存货明细。
- **F2-41 生产成本明细 / F2-42 直接人工 / F2-43 制造费用 / F2-44 成本分配**：生产成本归集与在产品/产成品分配。

### 计价方法测试
- **F2-38 加权平均 / F2-39 先进先出 / F2-40 标准成本**：验证发出存货计价方法一致性与准确性。
- **F2-61 采购价格 / F2-62 单价 / F2-63 产能能耗 / F2-64 单耗**：单价与投入产出合理性分析。

### 减值（NRV / CAS1）
- **F2-16 会计政策检查**：存货计量、跌价准备政策符合准则。
- **F2-47 减值测试**：按可变现净值 vs 成本孰低测算跌价准备。
- **F2-48 呆滞存货 / F2-49 减值转回**：呆滞识别、转回合规性。

### 出入库与委托加工核查（凭证级）
- **F2-33 采购入库检查 / F2-34 材料领用检查 / F2-35 委托加工核查**：凭证级核对出入库真实性、委托加工物资收回计价（收回成本 ≈ 发出材料 + 加工费）。含行级附件 OCR。

### 合同成本（CAS14）
- **F2-55/55A 合同成本明细及程序 / F2-56 合同成本检查 / F2-57 合同成本减值 / F2-58 亏损合同**：合同履约成本确认、减值与亏损合同准备。

### 分析
- **F2-18 总体分析 / F2-19 产销分析 / F2-20 成本比较**：周转率、产销匹配、成本结构异动分析。

### 关联方与供应商
- **F2-52 关联采购 / F2-65~72（关联方走访、供应商结构、未披露关联方、供应商走访/信息核查/访谈）/ F2-61A IPO 专项程序**：采购真实性与关联采购定价公允、供应商异常识别。

### 附注披露（上市/国企）
- **审计目标**：按附注格式披露存货分类、跌价准备计提及转回、合同成本等，与审定勾稽。
- **完成标志**：金额与 F2-1 审定一致；跌价准备变动已披露；已同步附注模块。

### 底稿目录
- **审计目标**：导航与编制进度总览（跨表结论口径 + 底稿架构）。

## 5. 质量复核要点（摘要）

1. F2-2 明细汇总 ↔ F2-1 未审是否勾稽？
2. 监盘账实差异是否已查明并调整？
3. F2-47 减值测试的可变现净值口径是否合理？跌价准备（1471）计提是否充分？
4. F2-35 委托加工收回计价是否 = 发出材料 + 加工费（计价勾稽）？
5. F2-14 已确认调整是否已体现在 F2-1？借贷是否平衡？
6. 附注金额是否等于 F2-1 审定？跌价准备变动是否披露？
