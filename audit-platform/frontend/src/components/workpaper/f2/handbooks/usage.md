# F2 存货及存货跌价准备 — 平台使用手册

> 配合「编制手册」页签使用。
> 本手册只说明**平台怎么操作**；审计目标与勾稽逻辑见编制手册。
> **不修改**各分表页内已有说明文案。
> 入口：底稿目录页顶部「使用手册」按钮。

---

## 1. 打开与模式

1. 在项目底稿树打开 **F2 存货及存货跌价准备**（覆盖科目 1401~1411 存货 / 1471 跌价准备）。
2. F2 为多组件大册，通过 sheet 页签切换分表（F2A、F2-1/F2-2、明细与成本组、计价组、减值组、出入库核查、合同成本组、关联/供应商组、附注、底稿目录）。
3. 复杂 sheet 支持 **结构化 HTML ↔ OnlyOffice** 双模式；以项目配置为准（目录页除外）。
4. 只读阶段工具栏「取数 / 回写 / 确认」类按钮会禁用。

**需要项目上下文的操作**（缺 `projectId` 会提示无法执行）：

- F2-33/34/35 抽凭与行级附件 OCR
- 附注「同步到附注模块」

## 2. 推荐操作路径（点击顺序）

| 步骤 | 分表 | 建议操作 |
|------|------|----------|
| 1 | F2A | 勾选实质性程序、填索引 |
| 2 | F2-2 | 录入/带入各类别存货明细汇总 |
| 3 | 监盘册 | 计划 → 执行 → 小结（账实核对） |
| 4 | F2-33/34/35 | 出入库/领用/委托加工凭证级核查（📎附件 OCR） |
| 5 | F2-38/39/40 | 计价方法测试 |
| 6 | F2-41~44 | 生产成本归集与分配（制造业） |
| 7 | F2-16 / F2-47 | 政策检查 → 减值测试（NRV vs 成本） |
| 8 | F2-48 / F2-49 | 呆滞识别 / 减值转回 |
| 9 | F2-55~58 | 合同成本（如适用） |
| 10 | F2-18/19/20 | 总体/产销/成本分析 |
| 11 | F2-52 / F2-65~72 | 关联采购与供应商核查 |
| 12 | F2-14 | 调整分录 → 确认 → 回写 F2-1 |
| 13 | F2-1 | 「从明细带入」→ 核对调整 → 勾稽 TB(1401/1471) |
| 14 | 附注上市/国企 | 拉取上游 → 编辑 → 同步附注模块 |

## 4. 导入导出

- 工具栏「导入/导出」按当前 sheet 作用（具备后端端点的 sheet）。
- 明细类宽表可用「导入导出▾」批量填数；导入后刷新当前表；改了明细请重新对 F2-1 执行「从明细带入」。

---

## 5. 常见问题

| 现象 | 处理 |
|------|------|
| F2-1 审定合计 ≠ TB 数 | 检查明细是否全部带入、调整是否已确认回写 |
| 监盘账实差异 | 查明原因，必要时经 F2-14 调整 |
| 减值口径存疑 | F2-47 复核可变现净值（售价−至完工成本−销售费用税金） |
| 委托加工计价不平 | F2-35 核对收回成本 = 发出材料 + 加工费（表三计价勾稽） |
| 附件 OCR 未回填 | 确认后端 OCR 服务可用；上传后确认弹窗再填入 |
| 附注同步失败 | 检查项目 ID、附注模块权限与准则类型（上市/国企） |
