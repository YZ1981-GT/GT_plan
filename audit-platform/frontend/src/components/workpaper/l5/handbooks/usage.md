# L5 长期应付款 — 平台使用手册

> 配合「编制手册」页签使用。本手册只说明**平台怎么操作**；审计目标与勾稽逻辑见编制手册。
> **不修改**各分表页内已有说明文案。入口：底稿目录页顶部「使用手册」按钮。

---

## 1. 打开与模式

1. 在项目底稿树打开 **L5 长期应付款**（`componentType: l5-long-term-payables`，覆盖科目 2701 长期应付款 + 2702 未确认融资费用）。
2. 通过 sheet 页签切换分表（L5A、L5-1～L5-7、附注上市/国企、底稿目录）。
3. 程序表（L5A）以项目配置为准（目录页不显示双模式）。
4. 只读阶段工具栏「取数 / 回写 / 确认」类按钮会禁用。

---

## 2. 推荐操作路径（点击顺序）

| 步骤 | 分表 | 建议操作 |
|------|------|----------|
| 1 | L5A | 勾选实质性程序、填索引 |
| 2 | L5-2 | 按款项（融资租赁/分期购入/其他）逐笔录入明细 |
| 3 | L5-3 | 录入未确认融资费用明细（与 L5-2 款项一一对应） |
| 4 | L5-5 | 摊销测算：期初摊余成本×实际利率，末期验证 → 联动 L8 |
| 5 | L5-6 | 关联方检查：交易条件公允性 |
| 6 | L5-7 | 检查表：分类、期限、一年内到期重分类 |
| 7 | L5-4 | 调整分录汇总 → 确认 → 回写 L5-1 |
| 8 | L5-1 | 确认审定净额（从 L5-2/L5-3 带入）→ 回写 TB(2701/2702) |
| 9 | 附注上市/国企 | 从审定表按分类取数 → 编辑 → 同步附注模块 |

|------|------|
| 编制进度 | 各分表按审计说明/结论及数据填写情况计算完成度 |

## 4. 常见问题

| 现象 | 处理 |
|------|------|
| L5-1 审定 ≠ TB 数 | 检查明细/未确认明细是否全部带入、调整是否已确认回写；TB 取 2701 原值 + 2702 未确认融资费用 |
| 净值行金额异常 | 净值 = 长期应付款原值 − 未确认融资费用，逐行核对 |
| 摊销末期余额不为 0 | 复核期初摊余成本、实际利率、期数；末期未确认余额应趋近 0（±1 元） |
| 摊销与账面/财务费用不符 | 确认与 L8 财务费用口径一致；实际利率法每期摊销=期初摊余成本×EIR |
| 附注分类金额不符 | 附注分类（融资租赁/分期购入/其他）金额应等于 L5-1 各分类审定数 |
| 与财报核对含专项应付款 | L5-1 核对区手填专项应付款，与经审计财报口径一致 |
| 附注同步失败 | 检查项目 ID、附注模块权限与准则类型（上市/国企） |
