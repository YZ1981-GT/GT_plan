# L5 长期应付款 — 底稿编制手册

> **适用范围**：科目 **2701 长期应付款（贷方/负债类）** + **2702 未确认融资费用（借方/负债备抵类）**
> **组件**：`l5-long-term-payables`
> **说明**：本手册说明各分表的审计目标、编制逻辑与勾稽关联，不替代各表页内已有说明文案。
> 平台按钮与操作步骤见「使用手册」页签。

---

## 1. 总体编制思路

长期应付款核心 = **净额审定（原值 − 未确认融资费用）**，验证实际利率法摊销、一年内到期重分类、关联方公允性与附注披露完整。

| 证据链 | 主要底稿 | 回答的问题 |
|--------|----------|------------|
| **金额枢纽** | L5-2 明细 + L5-3 未确认明细 → L5-1 审定 ← L5-4 调整 | 长期应付款净额期末余额是否准确完整？ |
| **摊销验证** | L5-5 未确认融资费用测算表 | 未确认融资费用摊销（实际利率法）是否恰当？ |
| **关联方** | L5-6 关联方及交易检查 | 关联方长期应付款交易条件是否公允？ |
| **合规** | L5-7 长期应付款检查表 | 分类、期限、一年内到期重分类是否恰当？ |
| **披露** | 附注上市 / 附注国企 | 长期应付款分类（融资租赁/分期购入/其他）及专项应付款披露是否完整？ |

**枢纽原则**：

1. **长期应付款为负债类贷方科目（2701）**：期末 = 期初 + 贷方（新增借入）− 借方（偿还）。
2. **未确认融资费用为负债备抵类借方科目（2702）**：期末 = 期初 + 借方（新增）− 贷方（摊销转出）。
3. **净额 = 长期应付款 − 未确认融资费用**；审定表三区段（一、原值 / 二、未确认融资费用 / 三、净值逐行）双期列示。
4. **实际利率法摊销**：每期摊销额 = 期初摊余成本 × 实际利率（EIR）；末期未确认余额应趋近于 0（允许 ±1 元尾差）。
5. **L5-1 是结论枢纽**：审定净额期末合计回写试算表（双科目 2701 原值 + 2702 未确认融资费用），并驱动附注披露（上市/国企）。
6. **一年内到期重分类**：一年内到期的长期应付款重分类至一年内到期的非流动负债；披露审定数 = 审定数 − 减一年内到期。

### 建议编制顺序

```
L5A 程序计划
  → L5-2 明细（按款项：融资租赁/分期购入/其他）+ L5-3 未确认融资费用明细
  → L5-5 未确认融资费用测算（实际利率法）→ 联动 L8 财务费用
  → L5-6 关联方检查 + L5-7 检查表
  → 差异汇入 L5-4 → 确认回写 L5-1
  → L5-1 勾稽 TB(2701/2702) → 附注上市/国企
```

## 2. 分表编制说明

### L5A 实质性程序表
- **审计目标**：规划并记录长期应付款实质性程序范围、性质与时间。
- **完成标志**：计划程序均有执行记录或「不适用」说明。

### L5-1 审定表（三区段：原值 / 未确认融资费用 / 净值，双期）
- **审计目标**：核实长期应付款净额期末余额准确完整；按款项类型提供审定数。
- **编制逻辑**：一、原值（2701）；二、未确认融资费用（2702）；三、净值逐行 = 原值 − 未确认融资费用。审定 = 未审 + 账项调整 + 重分类；期初/期末双期分列；减一年内到期 → 披露审定数。
- **上游**：L5-2 明细 / L5-3 未确认明细（按款项 SUMIF 带入）；L5-4 确认回写。**下游**：TB(2701/2702)、附注上市/国企。
- **完成标志**：与 TB 及经审计财报（含专项应付款）勾稽差异已解释；审计说明与结论已填。

### L5-2 明细表（30 列，按款项分组）
- **审计目标**：核实各笔长期应付款存在、完整、准确（按应付融资租赁款 / 分期付款购入固定资产 / 其他列示）。
- **完成标志**：清单完整、合计与 L5-1 一致、各行与 L5-5 摊销测算一一对应；审计说明与结论已填。

### L5-3 未确认融资费用明细表
- **审计目标**：核实未确认融资费用初始确认（名义金额 − 现值）与后续摊销准确，与 L5-2 各款项一一映射。
- **完成标志**：初始 − 累计摊销 = 期末未确认余额；与 L5-5 核对一致；审计说明与结论已填。

### L5-4 调整分录汇总
- **审计目标**：核实调整完整、借贷平衡。
- **完成标志**：借贷平衡；已确认回写 L5-1；发布 A13 错报（如适用）。

### L5-5 未确认融资费用测算表（核心，联动 L8）
- **审计目标**：核实未确认融资费用摊销（实际利率法）计提恰当。
- **编制逻辑**：每期摊销 = 期初摊余成本 × 实际利率；末期未确认余额趋近 0（±1 元）；本期摊销联动 L8 财务费用。
- **完成标志**：测算与账面摊销差异已解释；末期验证通过。

### L5-6 关联方及交易检查表
- **审计目标**：核实关联方长期应付款交易条件公允、披露充分。
- **完成标志**：关联方清单完整；公允性判断有据。

### L5-7 长期应付款检查表
- **审计目标**：综合核对分类、期限、一年内到期重分类，形成整体审计结论。
- **完成标志**：各核对项完成；审计结论已填。

### 附注披露（上市/国企）
- **审计目标**：按附注格式披露长期应付款分类（融资租赁/分期购入/其他）、专项应付款及一年内到期情况，与审定勾稽。
- **完成标志**：分类金额与 L5-1 审定一致；已同步附注模块。

### 底稿目录
- **审计目标**：导航与编制进度总览（跨表结论口径 + 底稿架构 + 本循环其他科目）。

## 4. 外部模块衔接

| 模块 | 与 L5 关系 |
|------|------------|
| **L8 财务费用** | L5-5 本期摊销联动财务费用 |

| **附注模块** | 长期应付款分类披露（融资租赁/分期购入/其他）+ 专项应付款 + 一年内到期 |

## 5. 质量复核要点（摘要）

1. L5-2 明细合计 + L5-3 未确认明细 ↔ L5-1 审定是否勾稽？
2. L5-1 审定净额期末 ↔ TB(2701/2702) 是否勾稽？
3. L5-5 摊销测算末期未确认余额是否趋近 0？本期摊销 ↔ L8 财务费用是否核对一致？
4. 净值逐行 = 原值 − 未确认融资费用，是否核对无误？
5. 一年内到期重分类与专项应付款披露是否充分？
6. 附注分类金额是否等于 L5-1 审定？
