# H4 工程物资 — 平台使用手册

> 本页说明各底稿在平台上的操作方式。审计目标与编制逻辑见「编制手册」页签。

## 1. 目录页（本页）

- 跨表结论口径看板：汇总核心表"审计说明或结论"是否已填，点击标签跳转对应分表。
- 底稿架构（4 阶段泳道）：审计计划 / 科目审定 / 实质性程序 / 披露与调整。
- 本循环底稿目录：H 循环其他科目，点击跳转。
- 编制/使用手册：右上角按钮。

## 2. 各底稿操作要点

- **H4-2 明细表**：录入或从序时账带入逐项工程物资，填期初/购入/领用，系统自动算期末并校验恒等式；填对应在建工程项目与减值。
- **H4-3 调整**：录入本期账项调整与重分类调整分录（领用补结转、减值计提）。
- **H4-1 审定表**：从明细带入未审数，录入 AJE/RJE 得审定数，点保存回写试算表 1605。
- **附注**：从审定表带入期末余额及变动情况。

## 3. 常用操作速查

| 操作 | 位置 |
|------|------|
| 从明细带入审定表 | H4-1 审定表「从明细带入」按钮 |
| 恒等式校验 | H4-2 明细录入后自动校验期末 = 期初 + 购入 − 领用 |
| 回写试算表 | H4-1 审定表保存时回写 1605 |
| AI 辅助说明/结论 | 各表审计说明区「AI 辅助」按钮 |
| 复核对话 | 各表结论区复核圆点/复核按钮 |
| 版本历史 | 顶部工具栏版本按钮 |

## 4. 联动关系速查

| 联动 | 说明 |
|------|------|
| 明细 → 审定 | H4-2 明细聚合到 H4-1 审定表 |
| 调整 → 审定 | H4-3 调整分录回写 H4-1 审定 AJE/RJE |
| 领用 → H2 | 工程物资领用转入在建工程，勾稽 H2 转入金额 |
| 审定 → 附注 | H4-1 审定数带入附注 |
| 审定 → 试算表 | 审定合计回写 1605 |
| 调整 → A13 | 未更正错报推送错报汇总 |
