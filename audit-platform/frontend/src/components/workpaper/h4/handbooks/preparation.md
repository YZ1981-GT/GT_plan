# H4 工程物资 — 底稿编制手册

> **适用范围**：企业为在建工程准备的各种物资（设备、材料、工器具等）。科目 1605 工程物资（资产类，借方余额）。
> **组件**：GtBIndex 通用目录（H4 科目）
> **说明**：本手册说明各分表的审计目标、编制逻辑与勾稽关联，不替代各表页内已有说明文案。平台按钮与操作步骤见「使用手册」页签。

---

## 1. 总体编制思路

工程物资是**为在建工程购入、尚未领用安装的专项物资**，属过渡性资产科目，最终随领用结转至在建工程（1604），完工后转入固定资产：

- **核心恒等式**：期末余额 = 期初余额 + 本期购入 − 本期领用（领用即转入在建工程 H2）。
- 工程物资**不计提折旧**（尚未投入使用），但期末应做**减值测试**：当发生毁损、长期闲置且无使用价值、或市价持续下跌等迹象时，计提工程物资减值准备。
- 关注**领用去向**：领用应转入在建工程 1604，与 H2 在建工程"工程物资转入"金额勾稽一致。
- 关注**积压与呆滞**：长期挂账、无对应在建工程项目的工程物资可能存在减值或已实际领用未入账。

| 证据链 | 主要底稿 | 回答的问题 |
|--------|----------|------------|
| 期末存量真实完整 | H4-2 明细表 | 每项工程物资是否真实存在、归属被审计单位？ |
| 本期增减变动 | H4-2 明细 / H4-3 调整 | 购入、领用是否恰当入账？恒等式是否成立？ |
| 领用去向勾稽 | H4-2 明细 | 领用是否正确转入在建工程 H2？ |
| 减值 | H4-2 明细（减值列） | 是否存在毁损/闲置/跌价迹象，减值是否充分？ |
| 审定与列报 | H4-1 审定表 / 附注 | 审定余额是否勾稽 TB 1605、披露是否恰当？ |

### 建议编制顺序

```
H4程序表 → H4-2明细(逐项立清单: 期初+购入-领用=期末)
  → 领用去向核对(勾稽H2在建工程转入)
  → 减值测试(毁损/闲置/跌价迹象)
  → H4-3调整(账项/重分类调整)
  → 回写H4-1审定表(勾稽TB 1605) → 附注
```

## 2. 分表编制说明

### H4-1 审定表
按工程物资类别列示期初、购入、领用、期末原值及减值准备、账面价值；未审数 + 账项调整(AJE) + 重分类调整(RJE) = 审定数；审定合计回写并勾稽试算表 1605。

### H4-2 明细表
逐项工程物资明细：名称、规格、对应在建工程项目、期初余额、本期购入、本期领用、期末余额、减值准备；核对购入凭证/合同、领用单据；验证恒等式期末 = 期初 + 购入 − 领用；标注长期挂账/呆滞项。

### H4-3 调整
本期账项调整与重分类调整分录（如领用未及时结转在建工程的补记、减值计提），借贷平衡后回写审定表并向 A13 推送错报。

### 附注
工程物资期末余额及本期变动情况；重大在建工程项目对应的工程物资情况说明。

## 3. 认定覆盖速查

| 认定 | 主要底稿 |
|------|----------|
| 存在 | H4-2 明细（实物/凭证核对） |
| 完整性 | H4-2 明细 / H4-3 调整 |
| 权利和义务 | H4-2 明细（采购合同/所有权） |
| 计价和分摊 | H4-2 明细（购入成本 + 减值） |
| 列报和披露 | H4-1 审定表 / 附注 |

## 4. 外部模块衔接

| 模块 | 关系 |
|------|------|
| H2 在建工程 | 工程物资领用转入在建工程，与 H2"工程物资转入"勾稽 |
| H1 固定资产 | 在建工程完工后转固，工程物资间接支撑固定资产成本 |
| A13 错报汇总 | H4-3 调整分录未更正部分推送错报汇总 |
| 试算表 | H4-1 审定合计回写 1605 |

## 5. 质量复核要点（摘要）

- 期末 = 期初 + 购入 − 领用 恒等式是否成立，差异是否查明。
- 领用是否正确、及时转入在建工程 H2，两表金额是否勾稽一致。
- 长期挂账、无对应工程项目的工程物资是否存在减值或已领用未结转。
- 减值迹象（毁损、闲置、跌价）是否充分识别，减值准备是否足额。
- 购入成本是否含运杂费/税金等恰当资本化项目，凭证合同是否齐全。
