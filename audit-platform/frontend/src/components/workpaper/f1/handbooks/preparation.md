# F1 预付账款 — 底稿编制手册

> **适用范围**：科目 **1123 预付账款**（借方科目：期末 = 期初审定 + 借方 − 贷方）
> **组件**：`f1-prepayment`
> **说明**：本手册说明各分表的审计目标、编制逻辑与勾稽关联。
> **不替代**各表页内已有的审计目标/过程提示文案（页内说明保持不变）。
> 平台按钮与操作步骤见「使用手册」页签。

---

## 1. 总体编制思路

F1 把「预付账款」拆成三条证据链，最后汇入审定与附注：

| 证据链 | 主要底稿 | 回答的问题 |
|--------|----------|------------|
| **金额枢纽** | F1-2 → F1-1 ← F1-3 | 未审→调整→审定是否完整准确？ |
| **真实/权利** | F1-6 关联方；F1-7 综合检查；F1-CONF 函证 | 预付款项真实存在、权属清晰、是否被占用？ |
| **计价/披露** | F1-4 分析；F1-5 长期挂账；附注 | 长期挂账是否应转费用/资产化？账龄披露是否完整？ |

**枢纽原则**：

1. **F1-2 明细表是数据枢纽**——审定表按供应商/性质从明细带入。
2. **F1-3 是调整枢纽**——差异（AJE/RJE）确认后回写 F1-1，并可推送至 A13 错报汇总。
3. **F1-1 是结论枢纽**——与试算（1123）勾稽，向报表与附注提供审定数。
4. **F1A 程序表**统领「做了哪些程序」；分表记录「证据与结论」。

### 建议编制顺序（标准路径）

```
F1A 程序计划
  → F1-2 明细表（先立清单，按供应商/预付性质：货款/工程款/设备款/服务费）
  → F1-CONF 函证程序（对大额预付发函）
  → 真实性链：F1-6 关联方 / F1-7 综合检查
  → 计价/账龄链：F1-4 实质性分析 / F1-5 长期挂账检查（判断是否需重分类或减值）
  → 差异汇入 F1-3 → 确认回写 F1-1
  → F1-1 从明细带入 → 勾稽 TB(1123)
  → 附注上市 / 附注国企
```

可按项目风险裁剪（如无关联方预付可弱化 F1-6），但 **明细 → F1-1** 与 **长期挂账判断** 不宜省略。

## 2. 分表编制说明

每张表按统一结构：**审计目标 → 编制逻辑 → 上游/下游 → 完成标志**。

### F1A 实质性程序表
- **审计目标**：规划并记录针对预付账款的实质性程序范围、性质与时间。
- **完成标志**：计划程序均有执行记录或「不适用」说明；索引可跳转分表。

### F1-1 审定表
- **审计目标**：核实预付账款余额准确完整；分类列报恰当（预付性质、1年以上是否重分类）；为报表与附注提供审定数。
- **编制逻辑**：按预付性质（货款/工程款/设备款/服务费/其他）分行；审定 = 未审 + 账项调整 + 重分类调整。
- **上游**：F1-2 汇总；F1-3 确认回写。**下游**：试算表（1123）；附注。
- **完成标志**：与 TB 勾稽差异已解释；调整来源可追溯至 F1-3；结论已填。

### F1-2 明细表（数据枢纽）
- **审计目标**：核实预付款项真实、完整、权利归属；按供应商与账龄列示。
- **编制逻辑**：逐笔列示供应商、预付内容、预付金额、形成日期、账龄；期后结转/退回情况可佐证真实性。
- **下游**：F1-1、F1-4、F1-5、F1-6 带入源。
- **完成标志**：清单完整、与 F1-1 汇总一致。

### F1-3 调整分录
- **审计目标**：核实预付账款及相关科目调整完整、借贷平衡。
- **编制逻辑**：AJE（账项调整）/ RJE（重分类调整，如 1 年以上预付转其他非流动资产）分列。
- **下游**：确认回写 F1-1；可推送至 A13 未更正错报汇总。
- **完成标志**：借贷平衡；已确认回写 F1-1；索引指向证据表。

### F1-4 实质性分析
- **审计目标**：通过趋势/结构分析识别异常预付（长期挂账、大额异动、与存货/应付勾稽）。
- **编制逻辑**：本期 vs 上期变动率；可从试算表带入存货（1401）/应付（2202）余额做交叉参照。
- **完成标志**：异常波动原因已分析、有结论。

### F1-5 长期挂账检查
- **审计目标**：识别账龄较长、可能无法收回货物/服务的预付款，判断是否应重分类或计提减值。
- **编制逻辑**：按账龄筛选长期挂账，逐笔说明原因与处置结论（继续挂账/转其他应收/减值/转费用）。
- **下游**：处置结论联动 F1-3 调整。
- **完成标志**：长期挂账逐笔有处置结论。

### F1-6 关联方
- **审计目标**：识别关联方预付款，核对披露完整性、是否存在资金占用。
- **完成标志**：关联方预付已识别，与 B19 清单核对。

### F1-7 综合检查
- **审计目标**：以凭证/合同/期后凭据佐证预付款项发生真实、权利归属清晰。
- **编制逻辑**：抽取大额/异常预付，检查采购合同、付款审批、期后结转凭据。
- **完成标志**：抽查比例达方案要求；异常已跟进。

### F1-CONF 函证程序
- **审计目标**：对大额预付款项向供应商发函证实余额及交易真实性。
- **编制逻辑**：复用 D0 函证组件（confirmation-*）；未回函执行替代程序。
- **完成标志**：函证发出/回函记录完整；差异与替代程序有据。

### 附注披露（上市/国企）
- **审计目标**：按附注格式披露预付账款账龄、按预付对象分类、关联方预付等，与审定勾稽。
- **完成标志**：金额与 F1-1 审定一致；账龄分析与关联方情况已披露；已同步附注模块。

### 底稿目录
- **审计目标**：导航与编制进度总览（跨表结论口径 + 底稿架构）。
- **完成标志**：计划执行的分表状态均为完成或已说明不适用。

## 3. 认定覆盖速查

| 认定 | 主要底稿 |
|------|----------|
| 存在 | F1-CONF、F1-7、F1-2 |
| 完整性 | F1-2、F1-6 |
| 权利与义务 | F1-6 资金占用、F1-7 |
| 准确性/计价 | F1-5 长期挂账、F1-4、F1-1 |
| 列报与披露 | 附注上市/国企、F1-5 重分类 |
| 截止 | F1-7 期后结转 |

## 4. 外部模块衔接

| 模块 | 与 F1 关系 |
|------|------------|
| **调整分录模块** | 与 F1-3 双向同步；确认驱动 F1-1 |
| **试算平衡表** | F1-1 审定回写 1123 |
| **F2 存货** | F1-4 与存货余额交叉参照（预付货款→存货入库） |
| **F4 应付账款** | F1-4 与应付余额勾稽 |
| **B19 关联方** | F1-6 关联方预付核对 |
| **附注模块** | 预付账款账龄/分类披露 |

---

## 5. 质量复核要点（摘要）

1. F1-2 合计 ↔ F1-1 未审是否勾稽？
2. F1-3 已确认调整（含重分类）是否已体现在 F1-1？借贷是否平衡？
3. F1-5 长期挂账是否逐笔有处置结论？1 年以上是否需重分类？
4. F1-6 关联方预付是否存在资金占用、是否披露？
5. 附注金额是否等于 F1-1 审定？账龄披露是否完整？
