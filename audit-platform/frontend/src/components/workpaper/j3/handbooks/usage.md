# J3 股份支付 — 平台使用手册

> 本页说明 J3 各底稿在平台上的**操作方式**（按钮、录入、联动、导出）。审计目标与编制逻辑见「编制手册」页签。

---

## 1. 目录页（本页）

- **跨表结论口径看板**：汇总 J3-1 / J3-2 两张核心表的"审计说明或结论"是否已填。
  - 标签为 <el-tag>已填</el-tag>（绿）/<el-tag>未填</el-tag>（灰）；点击任一标签跳转至对应底稿补全。
- **底稿架构（阶段泳道）**：审计计划 / 实质性程序 / 披露与调整；点击卡片跳转。
- **本循环底稿目录**：J 循环其他科目（J1 应付职工薪酬 / J2 长期应付职工薪酬…）；点击卡片跳转（灰色 = 尚未生成）。
- **编制/使用手册**：右上角「📖 编制手册」「使用手册」按钮随时查阅。

## 2. 各底稿操作要点

### J3A 实质性程序表
- 程序控制台：勾选执行状态、填写执行说明、指派与复核；索引联动各分表。

### J3-1 股份支付情况表
- 「新增方案」或操作列「编辑」打开**引导式录入向导**（5 分组卡片：基本信息与分类 / 关键日期条款 / 公允价值 / 协议变更更新 / 索引与结论）。
- 右侧**实时分析面板**：现金结算→重新计量提示、权益结算→M4 提示、授予日 vs 行权日间隔、缺公允价值方法告警。
- 明细表逐方案登记 14 列要素；顶部「审计说明 / 审计结论」支持 🤖 AI 辅助。

### J3-2 股份支付检查表
- **增减变动测算表**：操作列「编辑」打开引导向导（基本信息 / 人数与股份 / 金额勾稽 / 合规判断），测算 vs 账面差异实时勾稽（差异≠0 黄字告警）。
- **凭证检查表**：逐笔录入凭证信息与检查结论。

### 附注披露
- 从 J3-1 情况表取数；录入定价假设等叙述；支持 🤖 AI 辅助起草。

## 4. 联动关系速查

| 联动 | 说明 |
|------|------|
| J3-1 → J3-2 | 情况表方案带入检查表测算 |
| J3-2 测算 ↔ 账面 | 增减变动差异勾稽 |
| J3-1 → M4 | 权益结算股份支付计入资本公积 |
| J3-1 → 应付薪酬 | 现金结算形成负债 |
| J3-1 → 附注 | 情况表驱动附注披露 |
| J3 → S12/S12A | 期权定价模型专家利用 |
