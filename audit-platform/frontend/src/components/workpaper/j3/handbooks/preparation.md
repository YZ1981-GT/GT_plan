# J3 股份支付 — 底稿编制手册

> **适用范围**：**股份支付**（权益结算 / 现金结算，含股票期权、限制性股票、股票增值权等）
> **组件**：`j3-share-based-payment`
> **说明**：本手册说明各分表的审计目标、编制逻辑与勾稽关联，不替代各表页内已有说明文案。
> 平台按钮与操作步骤见「使用手册」页签。

---

## 1. 总体编制思路

股份支付按 **CAS11** 核算：以权益工具授予日公允价值为基础，在等待期内按最佳估计的可行权数量分期确认费用；权益结算计入资本公积（M4），现金结算计入应付职工薪酬并按资产负债表日公允价值重新计量。

| 证据链 | 主要底稿 | 回答的问题 |
|--------|----------|------------|
| **情况汇总** | J3-1 股份支付情况表 | 各股份支付方案要素、公允价值、等待期是否完整准确？ |
| **核查测算** | J3-2 股份支付检查表 | 增减变动准确性、条款一致性、期间归属恰当？ |

**枢纽原则**：

1. **区分权益结算 / 现金结算**：权益结算授予日公允价值一经确定不再重估；现金结算每期按公允价值重新计量。
2. **等待期分摊**：费用 = 授予日单位公允价值 × 预计可行权数量 × 已服务比例。
3. **利用专家（S12/S12A）**：期权定价模型（BS/二叉树）关键假设的评估。

### 建议编制顺序

```
J3A 程序计划 → J3-1 情况表（方案要素+公允价值+等待期）
  → J3-2 检查表（增减变动测算 vs 账面 + 凭证检查）
  → 差异 → 权益结算联动 M4 资本公积 / 现金结算联动应付薪酬 → 附注
```

## 2. 分表编制说明

### J3A 实质性程序表
- **审计目标**：规划并记录股份支付实质性程序范围、性质与时间。

### J3-1 股份支付情况表
- **审计目标**：核实各股份支付方案（类型、授予日、行权日、权益工具数量、等待期、公允价值确定方法）完整准确。
- **编制逻辑**：逐方案登记要素；引导式录入向导实时分析（现金结算重新计量 / 授予日 vs 行权日间隔 / 缺公允价值方法告警）。
- **下游**：M4（权益结算资本公积）、附注。

### J3-2 股份支付检查表
- **审计目标**：核实增减变动准确性（测算 vs 账面差异勾稽）、条款一致性、雇员判断、期间归属正确。
- **编制逻辑**：增减变动测算表（19 列）+ 凭证检查表；测算 − 账面 = 差异，差异≠0 告警。

### 附注披露
- **审计目标**：按 CAS11 披露股份支付方案、当期费用、权益工具公允价值及定价假设，与情况表勾稽。

### 底稿目录
- **审计目标**：导航与编制进度总览（跨表结论口径 + 底稿架构 + 本循环其他科目）。

## 4. 外部模块衔接

| 模块 | 与 J3 关系 |
|------|------------|
| **M4 资本公积** | 权益结算股份支付计入资本公积 |
| **应付职工薪酬** | 现金结算股份支付形成负债 |
| **专家利用（S12/S12A）** | 期权定价模型关键假设评估 |

---

## 5. 质量复核要点（摘要）

1. 权益结算 vs 现金结算判断是否正确，会计处理是否对应？
2. 授予日公允价值确定方法（定价模型）与关键假设是否合理，专家工作是否评价？
3. 等待期内费用分摊（预计可行权数量、已服务比例）是否恰当？
4. J3-2 测算与账面差异是否查明，附注披露是否与情况表一致？
