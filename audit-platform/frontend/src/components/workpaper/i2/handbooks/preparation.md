# I2 开发支出 — 底稿编制手册

> **适用范围**：科目 **1717 开发支出（资产借方，期末 = 期初 + 借方 − 贷方）**
> **组件**：`i2-development-expenditure`
> **说明**：本手册说明各分表的审计目标、编制逻辑与勾稽关联，不替代各表页内已有说明文案。
> 平台按钮与操作步骤见「使用手册」页签。

---

## 1. 总体编制思路

开发支出核心 = **资本化归集研发支出，达资本化条件时计入 1717；项目完成时结转无形资产（I1）**。

| 证据链 | 主要底稿 | 回答的问题 |
|--------|----------|------------|
| **金额枢纽** | I2-2 明细 → I2-1 审定 ← I2-3 调整 | 1717 期末余额是否准确完整？ |
| **资本化判断** | I2-6 CAS6 五条件 / I2-7 项目构成 | 各项目资本化时点是否恰当？归集是否准确？ |
| **投入核查** | I2-8 材料 / I2-9 人员 / I2-10 工时 / I2-11 委外 | 归集的研发投入是否真实、完整、准确？ |
| **专项检查** | I2-4 政策 / I2-5 分析 / I2-12 针对性 | 政策恰当？波动合理？针对性风险应对到位？ |
| **截止 / 减值** | I2-13/14 截止 / I2-15/16 减值 | 期末归集截止是否恰当？是否需计提减值？ |

**枢纽原则**：

1. **方向**：1717 开发支出资产借方，期末 = 期初 + 借方（资本化归集）− 贷方（结转无形资产/费用化）。
2. **I2-1 是结论枢纽**：审定期末回写试算表 1717；期末余额供附注披露。
3. **CAS6 五条件（I2-6 核心）**：技术可行性、完成并使用/出售的意图、经济利益流入方式、资源支持、支出可靠计量——须**同时满足**方可资本化，判断资本化时点。
4. **I6 ↔ I2 双向联动**：**费用化(I6) + 资本化(I2) = 研发总额**，费用化与资本化归集互为校验。
5. **I2 → I1 转入**：项目完成资本化转入无形资产，由 I1-5 增加检查带入。

### 建议编制顺序

```
I2A 程序计划
  → I2-7 研发项目构成（滚动阶段登记）
  → I2-6 CAS6 五条件资本化时点判断（核心）
  → I2-8 材料 / I2-9 人员 / I2-10 工时 / I2-11 委外 检查
  → I2-2 明细（按项目追踪资本化金额）
  → I2-4 会计政策 / I2-5 实质性分析
  → I2-12 针对性检查
  → I2-13/14 双向截止测试（期末 ±5 天跨期检查）
  → I2-15 减值测试 / I2-16 可收回金额
  → 差异汇入 I2-3 → 确认回写 I2-1
  → I2-1 勾稽 TB(1717) → 附注上市/国企
```

## 2. 分表编制说明

### I2A 开发支出实质性程序表
- **审计目标**：规划并记录开发支出实质性程序范围、性质与时间。
- **完成标志**：计划程序均有执行记录或「不适用」说明。

### I2-1 审定表
- **审计目标**：核实 1717 开发支出期末余额准确完整；提供审定数。
- **编制逻辑**：审定 = 未审 + AJE + RJE；期末 = 期初 + 借方（资本化归集）− 贷方（转出）。
- **上游**：I2-2 明细、I2-6/7 资本化归集；I2-3 确认回写。**下游**：TB(1717)、附注、I1-5 转入。
- **完成标志**：与 TB 勾稽差异已解释；审计说明与结论已填。

### I2-2 明细表
- **审计目标**：按项目逐项追踪资本化金额，核实存在、完整、准确。
- **完成标志**：清单完整、合计与 I2-1 一致。

### I2-3 调整分录汇总
- **审计目标**：核实调整完整、借贷平衡。
- **完成标志**：借贷平衡；已确认回写 I2-1 并同步 A13。

### I2-4 会计政策检查
- **审计目标**：核实研发支出费用化/资本化政策恰当且前后一致。

### I2-5 实质性分析
- **审计目标**：分析开发支出本期波动、结构比是否合理，异常须解释。

### I2-6 研发项目资本化时点判断（CAS6 核心）
- **审计目标**：逐项目核实 CAS6 五条件是否同时满足、资本化时点是否恰当。
- **完成标志**：每项目五条件判断齐全；资本化/费用化结论明确。

### I2-7 研发项目构成明细表
- **审计目标**：按滚动阶段登记项目（期初/增减/期末/调整/审定）及费用性质与资本化/费用化。
- **完成标志**：项目构成完整；资本化金额与 I2-2/I2-1 配平。

### I2-8 材料 / I2-9 人员 / I2-10 工时 / I2-11 委外 检查表
- **审计目标**：核实归集的研发材料投入、人员认定、工时分配、委外研发真实、完整、准确。

### I2-12 针对性检查表
- **审计目标**：针对识别的重大错报风险执行针对性程序并记录应对。

### I2-13 截止性测试（账到单据）/ I2-14 截止性测试（单据到账）
- **审计目标**：双向核实期末归集截止恰当；期末 ±5 天跨期检查。

### I2-15 减值准备测试表 / I2-16 可收回金额测试
- **审计目标**：核实减值迹象识别与减值金额确认恰当；可收回金额关键假设合理。

### 附注披露（上市/国企）
- **审计目标**：按附注格式披露开发支出期末余额及变动，与审定勾稽。

### 底稿目录
- **审计目标**：导航与编制进度总览（跨表结论口径 + 底稿架构 + 本循环其他科目）。

## 5. 质量复核要点（摘要）

1. I2-1 审定 ↔ TB(1717) 是否勾稽？期末 = 期初 + 借 − 贷 是否成立？
2. I2-6 CAS6 五条件是否逐项目齐全？资本化时点判断是否恰当？
3. I6 费用化 + I2 资本化 = 研发总额 是否配平？
4. I2-7 项目构成资本化金额 ↔ I2-2 明细 ↔ I2-1 审定是否一致？
5. 附注金额是否等于 I2-1 审定？项目完成转入 I1 是否已带入？
