# I2 开发支出 — 平台使用手册

> 配合「编制手册」页签使用。本手册只说明**平台怎么操作**；审计目标与勾稽逻辑见编制手册。
> **不修改**各分表页内已有说明文案。入口：底稿目录页顶部「使用手册」按钮。

---

## 1. 打开与模式

1. 在项目底稿树打开 **I2 开发支出**（`componentType: i2-development-expenditure`，覆盖科目 1717）。
2. 通过 sheet 页签切换分表（I2A、I2-1~I2-16、附注上市/国企、底稿目录）。
3. 复杂 sheet 支持 **结构化 HTML ↔ OnlyOffice** 双模式；以项目配置为准（目录页不显示双模式）。
4. 只读阶段工具栏「取数 / 回写 / 确认」类按钮会禁用。

---

## 2. 推荐操作路径（点击顺序）

| 步骤 | 分表 | 建议操作 |
|------|------|----------|
| 1 | I2A | 勾选实质性程序、填索引 |
| 2 | I2-7 | 按滚动阶段登记研发项目构成 |
| 3 | I2-6 | 逐项目 CAS6 五条件资本化时点判断 |
| 4 | I2-8 / I2-9 / I2-10 / I2-11 | 材料 / 人员 / 工时 / 委外 检查 |
| 5 | I2-2 | 按项目追踪资本化金额登记明细 |
| 6 | I2-4 / I2-5 | 会计政策检查 + 实质性分析 |
| 7 | I2-12 | 针对性检查 |
| 8 | I2-13 / I2-14 | 双向截止测试（期末 ±5 天跨期） |
| 9 | I2-15 / I2-16 | 减值测试 + 可收回金额 |
| 10 | I2-3 | 调整分录汇总 → 确认 → 回写 I2-1 |
| 11 | I2-1 | 确认审定 → 回写 TB(1717) |
| 12 | 附注上市/国企 | 从审定表取数 → 编辑 → 同步附注模块 |

## 3. 目录页速查

| 区块 | 说明 |
|------|------|
| 编制进度 | 各分表按审计说明/结论填写情况计算完成度 |
| 跨表结论口径 | 每张表审计结论「已填/未填」标签，点击跳转对应 sheet 补全 |
| 底稿架构 | 4 阶段泳道（审计计划/科目审定/实质性程序/披露与调整），点击卡片跳转 |
| 本循环底稿目录 | 同循环其他科目（I1~I6），点击跳转（灰色表示尚未生成） |

## 4. 常见问题

| 现象 | 处理 |
|------|------|
| I2-1 审定 ≠ TB 数 | 检查明细/资本化归集是否全部带入、调整是否已确认回写；TB 取 1717 期末余额 |
| 费用化 + 资本化 ≠ 研发总额 | 检查 I6 费用化数据是否同步；I2 资本化归集是否完整 |
| CAS6 判断项未通过校验 | I2-6 五条件须同时满足方可资本化，补全判断依据 |
| 项目完成未转入 I1 | 资本化转入无形资产由 I1-5 增加检查带入，检查是否已确认 |
| 附注同步失败 | 检查项目 ID、附注模块权限与准则类型（上市/国企） |

## 5. 复核入口

各分表工具栏/结论区「复核」打开复核对话。合伙人级复核提示词参考：`backend/data/tsj_review_prompts/I/`（若环境已部署）。
