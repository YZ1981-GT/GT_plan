# 审计平台使用手册

> 本手册面向首次使用平台的审计人员，从零开始介绍平台的每个功能模块、操作步骤和注意事项。
> 如果你是第一次打开这个系统，请按顺序阅读本手册。

---

## 一、平台是什么？能做什么？

这是一个**一站式审计工作管理平台**，帮助审计团队完成从项目创建到出具审计报告的全部工作。

### 你以前可能这样工作：

- 用 Excel 编制几十张底稿，手动复制粘贴数据
- 用 Word 写审计报告和附注，手动核对数字
- 用邮件和微信沟通复核意见
- 用文件夹管理几百个文件，找东西费时费力

### 现在平台帮你：

- ✅ 自动从企业账套取数填入底稿（不用手动抄）
- ✅ 底稿之间自动联动（改一处其他地方自动更新）
- ✅ 一键生成报表和附注（不用手动拼 Word）
- ✅ AI 辅助撰写审计说明和结论
- ✅ 在线协作复核（不用来回传文件）
- ✅ 全过程可追溯（每个数字从哪来一目了然）

### 模块总览

| 图标 | 模块名称 | 做什么用 |

| 👥 | 人员信息 | 管理项目组成员和角色 |
| ⏱ | 工时 | 记录审计工时 |
| 📋 | 看板 | 任务看板（类似 Trello） |
| 📅 | 日程 | 项目时间安排 |
| ✉️ | 函证 | 函证管理中心（发函、回函、跟踪） |
| 📎 | 附件 | 项目级附件管理 |
| 📚 | 模板库 | 审计底稿模板 |

| 🗄️ | 私人库 | 个人文档存储 |
| 🤖 | AI 模型 | AI 配置 |
| 📐 | 公式管理 | 全局公式管理中心 |
| 🔍 | 高级查询 | 跨底稿数据查询 |
| ↩️ | 收起 | 收起侧边栏 |

### 项目内部的核心数据流

```
企业 Excel 文件
      │
      ▼
┌─────────────┐
│  ① 账套导入  │  上传科目余额表、序时账等
└─────────────┘
      │
      ▼
┌─────────────┐
│  ② 科目映射  │  企业科目 → 标准科目（一般自动完成）
└─────────────┘
      │
      ▼
┌─────────────┐
│  ③ 试算表   │  系统自动生成，汇总全部科目的审定数
└─────────────┘
      │
      ├───────────────────────────────────────┐
      ▼                                       ▼
┌─────────────┐                        ┌─────────────┐
│  ④ 审计底稿  │  ←── 取数 ──→        │  ⑤ 调整分录  │
│  （D~N循环）  │      联动             │  （AJE/RJE） │
└─────────────┘                        └─────────────┘
      │                                       │
      │ 审定数回写 ←─────────────────────────┘
      ▼
┌─────────────┐
│  ⑥ 财务报表  │  从试算表自动取数生成
└─────────────┘
      │
      ▼
┌─────────────┐
│  ⑦ 附注     │  表格从底稿披露表同步 + AI辅助文字
└─────────────┘
      │
      ▼
┌─────────────┐
│  ⑧ 交付出具  │  合并生成审计报告 Word
└─────────────┘
```

**关键理解**：数据是从上往下流动的。你在底稿里修改审定数 → 自动影响试算表 → 自动影响报表 → 附注也会更新。不需要手动同步。

## 三、五大角色说明

| 角色 | 在平台里能做什么 | 不能做什么 |
|------|----------------|-----------|
| **审计助理** | 编制底稿、录入数据、上传附件、填写调整分录 | 不能裁剪程序、不能委派任务、不能签发报告 |
| **现场经理** | 上述全部 + 委派任务 + 裁剪程序 + 一级复核 + 智能裁剪 | 不能签发报告 |
| **业务合伙人** | 上述全部 + 签发报告 + 刷新底稿 + 重大判断 | - |
| **质控复核(QC)** | 只读查看 + QC检查 + 独立复核意见 | 不能编制底稿 |
| **EQCR** | 只读查看 + 技术复核 | 不能编制底稿 |

> 💡 **新手注意**：如果你是审计助理，主要工作是编制底稿和录入数据。看到某些按钮灰色不可点，说明你的角色没有该权限，这是正常的。

## 四、详细操作流程（一步一步来）

### 第 1 步：创建项目

**入口**：左上角「+ 新建项目」按钮

**操作步骤**：
1. 填写基本信息：
   - **客户名称**：被审计单位全称（如"重药控股安徽有限公司"）
   - **审计年度**：如 2025
   - **项目类型**：年度审计 / 专项审计 / IPO 等
2. 选择报表准则：
   - **国企版（SOE）**：适用于国有企业，附注编号用「八、N」
   - **上市版（Listed）**：适用于上市公司，附注编号用「五、N」
3. 点击「创建」

**创建后你会看到**：项目概览页，显示客户信息和建议流程。

> ⚠️ **注意**：报表准则选错会导致附注生成错误。如果选错了，到项目「编辑」里修改。

---

### 第 2 步：导入账套数据

**入口**：项目概览 →「账套导入」快捷按钮

**什么是账套？**
账套就是企业财务系统导出的 Excel 文件，一般包含：
- **科目余额表**（必须）：每个科目的期初、借方发生额、贷方发生额、期末余额
- **序时账 / 明细账**（推荐）：每笔会计分录的明细记录
- **辅助余额表**（可选）：按客户/供应商/部门等维度的余额

**操作步骤**：
1. 点击「账套导入」进入导入页面
2. 上传企业导出的 Excel 文件（支持 .xlsx / .xls）
3. 系统自动识别文件类型（余额表 / 序时账 / 辅助余额表）
4. **列映射确认**：
   - 系统会自动匹配列（如"科目编码"→account_code）
   - 如果识别不准确，手动下拉选择正确的映射
   - **关键列（红色标记）必须映射**：科目编码、期末余额、借方发生额、贷方发生额
   - 次关键列（黄色标记）建议映射：期初余额、年初余额
5. 点击「提交导入」
6. 等待处理完成（大文件可能需要 1~2 分钟）

**导入成功的标志**：
- 页面提示"导入成功，共 N 条记录"
- 项目状态从「计划中」变为「执行中」
- 可以在「试算表」页看到科目数据

> 💡 **提示**：如果导入后试算表是空的，说明科目映射没完成。进入科目映射页点「自动匹配」。

> ⚠️ **常见问题**：
> - "列映射失败" → 检查 Excel 表头是否有合并单元格，拆开后重新上传
> - "导入 0 条" → 检查数据是否从第 2 行开始（第 1 行是表头）
> - "科目编码为空" → 检查是否有空行或汇总行混在数据里

---

### 第 3 步：科目映射

**入口**：项目概览 →「调整分录」→ 科目映射 tab

**什么是科目映射？**
不同企业用不同的科目编码（比如有的用 1122 有的用 112201），需要映射到统一的标准科目体系，系统才能正确生成报表。

**操作步骤**：
1. 进入科目映射页面
2. 点击「🔄 自动匹配」按钮
3. 系统自动根据科目编码和名称完成映射
4. 检查映射结果（绿色=已映射，红色=未映射）
5. 对未映射的科目手动选择标准科目
6. 确认后系统自动生成试算表

**映射完成的标志**：
- 映射覆盖率接近 100%
- 试算表页面有数据显示

> 💡 **大多数情况下一键自动匹配就够了**，只有非标准科目才需要手动处理。

---

### 第 4 步：查看试算表

**入口**：项目概览 →「试算表」快捷按钮

**试算表是什么？**
试算表是全部科目的汇总表，每行一个科目，列出：
- **未审数**：企业账面原始金额
- **AJE 调整**：审计调整分录影响
- **RJE 调整**：重分类调整分录影响
- **审定数**：= 未审数 + AJE + RJE（最终审计确认的金额）

**你能做什么**：
- 搜索某个科目查看审定数
- 双击某行查看明细（跳到对应底稿）
- 查看公式管理（每个数字的来源）

> 💡 **试算表是自动维护的**，你不需要手动编辑它。当你在底稿里修改审定数或录入调整分录时，试算表会自动更新。

---

### 第 5 步：编制审计底稿（核心工作）

**入口**：项目概览 →「底稿」快捷按钮

**底稿是什么？**
审计底稿是审计工作的记录和证据。每张底稿对应一个审计科目或程序。

#### 5.1 底稿的组织方式

底稿按**审计循环**分组，每个循环对应一类业务：

| 循环代码 | 循环名称 | 包含的典型科目 |
|---------|---------|--------------|
| A | 综合类 | A1 报表分析、A13 未更正错报 |
| B | 审计计划 | B15 重要性、B22 内控了解、B50 风险评估 |
| C | 控制测试 | C2~C15 各循环控制测试 |
| D | 销售与收款 | D1 应收票据、D2 应收账款、D3 预收账款、D4 营业收入 |
| E | 货币资金 | E1 银行存款 / 库存现金 / 其他货币资金 |
| F | 采购与付款 | F1 预付账款、F2 存货、F3 应付票据、F4 应付账款 |
| G | 投资 | G1 交易性金融资产、G7 长期股权投资、G14 信用减值 |
| H | 长期资产 | H1 固定资产、H2 在建工程、H8 使用权资产 |
| I | 无形资产 | I1 无形资产、I3 商誉、I5 其他非流动资产 |
| J | 薪酬 | J1 应付职工薪酬 |
| K | 其他项目 | K1 其他应收款、K8 销售费用、K9 管理费用 |
| L | 借款与负债 | L1 短期借款、L3 长期借款、L4 应付债券 |
| M | 权益 | M1 应付股利、M5 盈余公积、M6 未分配利润 |
| N | 税费 | N1 递延所得税资产、N2 应交税费、N5 所得税费用 |
| S | 专项 | S12 利用专家、S34 估计评估 |

#### 5.2 底稿内部结构

打开一张底稿（比如 D2 应收账款），你会看到多个页签（sheet）：

| 页签 | 作用 | 怎么用 |
|------|------|--------|
| **底稿目录** | 本底稿的导航页 | 查看编制进度和各 sheet 状态 |
| **D2A 程序表** | 审计程序清单 | 勾选已执行的程序步骤 |
| **D2-1 审定表** | 科目审定汇总 | 核心！分类汇总未审数→调整→审定数 |
| **D2-2 明细表** | 逐笔明细 | 录入/导入每笔应收的客户、金额、账龄 |
| **D2-3 坏账准备** | 坏账计提测算 | 按账龄/单项计提坏账准备 |
| **D2-4 调整分录** | 本科目的调整 | 录入 AJE/RJE |
| **D2-5 分析表** | 实质性分析 | 前五名、账龄分布、波动分析 |
| **D2-7 检查表** | 凭证级检查 | 抽样凭证核对 |
| **附注上市/国企** | 披露信息表 | 生成附注的数据源 |

#### 5.3 编制底稿的两种模式

每张底稿顶部有模式切换：

1. **结构化视图**（默认）：
   - 表单式填写，字段清晰
   - 公式自动计算（灰色底色列不可编辑）
   - 有审计目标提示、编制提示
   - 适合日常编制

2. **在线编辑（OnlyOffice）**：
   - 完整的 Excel 编辑体验
   - 可以看到源模板的原始格式
   - 适合需要自由编辑/查看格式时使用
   - 如果显示「不可用」说明 OnlyOffice 服务未启动，用结构化视图即可

#### 5.4 底稿编制要点

**审定表（X-1）**：
- 期末未审数：一般从试算表/余额表自动预填
- 账项调整(AJE)：从调整分录或集中登记带入
- 重分类调整(RJE)：同上
- 审定数 = 未审 + AJE + RJE（自动计算，灰色列）
- 底部「与试算平衡表核对」：审定合计应与 TB 一致

**明细表（X-2）**：
- 工具栏「从序时账取数」：一键从账簿导入明细
- 工具栏「从余额表导入」：从辅助余额表导入
- 编辑完成后，审定表的「从明细带入」可汇总明细数据

**检查表（凭证级）**：
- 工具栏「🎲 抽凭引擎」：科学抽样选取凭证
- 逐笔填写核对内容（①~⑤ 勾选）
- 检查比例 = 已检查金额 / 本期发生额

**调整分录**：
- 借贷必须平衡（底部会显示平衡/不平衡）
- 录完后点「同步到集中登记」可推到项目级汇总
- 调整会自动影响审定表和试算表

**附注披露表**：
- 表格数据会用来生成附注
- 编制完成后点「同步到附注」推送到附注模块
- 如果不手动同步，附注里可能是空的

#### 5.5 底稿里的常用按钮

| 按钮 | 作用 |
|------|------|
| 🤖 AI辅助 | AI 生成审计说明/结论初稿，需人工确认 |
| 💬 复核 | 发起/查看复核对话 |
| 📎 OCR | 上传附件后 AI 识别内容自动填入 |
| 🎲 抽凭引擎 | 科学抽样（MUS/随机/分层/系统/特定） |
| ⚙️ 列设置 | 宽表时隐藏/显示列 |
| 📥 导入导出 ▾ | 导出模板 / 导出数据 / 导入 xlsx |
| 🔗 公式管理 | 查看本 sheet 的取数公式和来源 |
| ⏪ 版本历史 | 查看/回退历史版本 |
| 📖 编制手册 | 本科目的编制指南 |

### 第 6 步：录入调整分录

**入口**：底稿内的「调整分录」tab / 项目概览「调整分录」快捷入口

**什么是调整分录？**
- **AJE（审计调整）**：发现账面错误需要调整的分录
- **RJE（重分类调整）**：金额没错但列报位置需要调整

**在底稿内录入**：
1. 切到「调整分录」tab
2. 点「+ 新增」
3. 填写：调整事项说明 / 类别(账项调整/报表调整) / 科目 / 借方 / 贷方
4. 确认借贷平衡
5. 点「同步到集中登记」推到项目级

**在集中页管理**：
1. 项目概览 → 调整分录
2. 查看全部项目调整
3. 可按来源筛选（手工 / 底稿）
4. 合伙人可复核审批

> 💡 **调整分录录完后**：试算表的"AJE调整"/"RJE调整"列会自动更新，审定数随之改变，报表也会变。

---

### 第 7 步：生成财务报表

**入口**：项目概览 →「报表」快捷按钮

**报表包含**：
- 资产负债表
- 利润表
- 现金流量表
- 所有者权益变动表
- 附注相关报表

**操作步骤**：
1. 进入报表页面
2. 点击「生成」或「刷新」
3. 系统自动从试算表取审定数生成报表
4. 检查「资产负债平衡」（资产合计 = 负债 + 权益）
5. 如果不平衡，检查试算表是否有科目缺失

> ⚠️ **报表不平衡常见原因**：
> - 权益类科目（实收资本/未分配利润）导入时缺失期末余额
> - 科目映射不完整（某些科目未映射到报表行）
> - 调整分录借贷不平衡

---

### 第 8 步：编辑附注

**入口**：项目概览 →「附注」快捷按钮

**附注是什么？**
附注是财务报表的补充说明，按章节组织。比如：
- 五、1 货币资金（列示库存现金、银行存款明细）
- 五、5 应收账款（列示账龄、坏账计提、前五名）
- 五、22 固定资产（列示变动情况表）

**操作步骤**：
1. 进入附注编辑页面
2. 左侧树形导航选择章节
3. **表格数据**：从底稿披露表自动同步（如果为空，去底稿点「同步到附注」）
4. **文字说明**：
   - 手动输入 / AI 辅助生成
   - 工具栏「🤖 AI 助手」→ 选择模式
5. 校验：点「✅ 校验」检查数据一致性
6. 导出：工具栏「📤 导入导出 ▾」→ 导出 Word

**附注工具栏功能**：

| 按钮 | 作用 |
|------|------|
| 🔄 刷新 | 重新从试算表取数刷新当前章节 |
| 🔄 全部刷新 | 刷新所有章节 |
| ✅ 校验 | 检查合计/公式一致性 |
| 🤖 AI 助手 ▾ | 批量预填充 / AI对话 / AI建议 |
| 📤 导入导出 ▾ | 导出 Word / 打印预览 / Excel 导入导出 |
| 📋 就绪度 | 查看各章节同步状态和编制完成度 |

> 💡 **附注表格为空的解决办法**：
> 1. 先确认对应底稿的披露 tab 有数据

## 九、常见问题 FAQ

### Q1: 导入账套后试算表是空的？
**A**: 需要完成科目映射。进入「调整分录」→ 科目映射 → 点击「自动匹配」。映射完成后试算表自动生成。

### Q2: 底稿里的数字从哪里来的？
**A**: 
- 审定表「未审数」→ 从试算表/余额表自动预填
- 明细表各行 → 可从序时账/辅助余额表一键导入
- 公式列（灰色底色）→ 系统自动计算
- 你可以点「🔗 公式管理」查看每个数字的来源公式

### Q3: 附注的表格为什么是空的？
**A**: 附注表格数据来自底稿的「附注披露表」tab。操作流程：
1. 先在底稿的「附注上市/国企」tab 编制数据
2. 点击该 tab 的「同步到附注」按钮
3. 回到附注页面点「🔄 刷新」

### Q4: 在线编辑（OnlyOffice）显示「不可用」？
**A**: 这说明 OnlyOffice 文档服务没有启动或健康检查未通过。不影响使用，直接用「结构化视图」编辑即可，功能完全一样。

### Q5: 调整分录录了但审定数没变？
**A**: 两种可能：
1. 调整分录在底稿 tab 录入但审定表没有消费 → 在审定表点「📥 从集中登记带入调整」
2. 调整分录只是录了没填审定表的 AJE/RJE 列 → 手工填入或用带入按钮

### Q6: 报表「资产负债不平」怎么办？
**A**: 
1. 进试算表，检查权益类科目（4001 实收资本、4104 未分配利润等）是否有期末余额
2. 如果权益科目全部为 0/空 → 导入时缺失，重新导入或手工补录
3. 检查科目映射是否完整（是否有未映射的科目）

### Q7: 数据改了一处，其他地方会自动更新吗？
**A**: 大部分会自动联动：
- 明细表 → 审定表「从明细带入」后更新
- 审定表审定数 → 自动回写试算表
- 试算表 → 报表自动取数
- 底稿披露表 → 需手动点「同步到附注」

### Q8: 项目状态一直显示「计划中」？
**A**: 导入账套并完成科目映射后状态会自动推进到「执行中」。如果没变，检查：
1. 是否成功导入了数据（试算表有数据）
2. 科目映射是否完成

### Q9: 怎么知道哪些底稿还没编完？
**A**: 
1. 项目概览 →「底稿」tab → 查看各循环完成率
2. 底稿列表 → 看状态列（未开始/编制中/已完成）
3. 审计检查 → 查看未通过项

### Q10: 怎么把底稿导出给别人看？
**A**: 底稿工具栏「📥 导入导出 ▾」→「导出数据」下载 Excel。如果要导出整个项目底稿，用「批量导出」功能。

## 十、提示与技巧

### 🔑 快捷操作
- **Ctrl+F5**：遇到显示异常先试硬刷新
- **双击**：概览页的指标卡片可双击跳转对应页面
- **右键**：序时账页面右键可直接「挂凭到底稿」

### 📋 编制效率
- **从序时账取数**：明细表工具栏一键导入，比手动录入快 10 倍
- **AI 辅助**：审计说明/结论区域的 🤖 按钮一键生成初稿
- **公式管理**：底稿「公式管理」查看每个数字来源，不用猜
- **列设置 ⚙️**：宽表（>15列）可以隐藏不需要的列

### 🔗 联动理解
- **底稿→试算表**：审定表保存后自动回写 TB
- **试算表→报表**：报表取 TB 审定数，刷新即更新
- **底稿→附注**：需手动点「同步到附注」
- **全局事件**：录入调整分录后相关底稿会标记「数据过期」提示刷新

### ⚠️ 避坑指南
- 不要在 Excel 里编辑完再导入覆盖（会丢失公式和联动）
- 调整分录录完记得点「同步到集中登记」
- 附注编制完记得点「同步到附注」（不会自动推送）
- 导出 Word 前先跑「✅ 校验」确认无异常
- 版本快照是自动保存的，不用担心丢数据
