# 模板库使用手册

> 模板库是致同审计平台的**全局基础数据中心**。它管理全平台所有项目共享的底稿模板、公式、报表配置、编码体系等「主数据」。这里的配置是**平台级、跨项目通用**的——改这里会影响所有新建/生成的项目底稿，请谨慎操作。

---

## 一、模板库是什么

平台把「每个项目都要用、且大体一致」的东西抽出来放在模板库统一维护，避免每个项目各配一套：

- **底稿模板**：179 张致同 2025 修订版底稿的结构骨架（A~S 全循环）
- **公式**：底稿取数公式、报表勾稽公式、跨底稿引用关系
- **报表/附注模板**：四套准则（国企/上市 × 单体/合并）的报表行、附注章节
- **编码体系 / 枚举字典**：底稿编码规则、下拉选项字典

项目实例化时，平台从模板库「拷贝」出各项目自己的一份，项目内的编辑不会回写模板库。

---

## 二、顶部四个指标怎么看

| 指标 | 含义 | 正常范围 |
|------|------|---------|
| 主编码总数 | 模板库里的底稿主编码数量（含 form/word 全部） | 179 左右 |
| 公式覆盖率 | 已配公式的底稿/报表行占比 | 越高越好，红<40% / 黄40-80% / 绿≥80% |
| 种子加载 | 9 类基础种子数据的加载状态 | 应为 9/9 全绿 |
| 版本 | 当前模板库版本标识 | 致同 2025 修订版 |

顶部「刷新」重新拉取这四个指标；「版本历史」查看历次种子加载记录。

## 三、种子数据管理（首次部署/升级必做）

点开顶部「种子数据管理」折叠区。**种子 = 模板库的基础数据**（编码规则、报表配置、公式预设等），共 9 类。

- **首次部署或版本升级后**：逐个点「加载」把 9 类种子灌入，直到「种子加载 9/9」全绿
- 已加载的种子重复加载是**幂等**的（按主键去重更新，不会重复插入）
- 只有 admin / 业务合伙人 角色能执行加载

> ⚠️ 种子没加载全，会导致新建项目缺报表配置、公式覆盖率偏低、底稿生成异常。部署后第一件事就是确认 9/9。

## 四、八个页签逐一说明

### 1. 底稿模板
浏览 179 张底稿模板，按审计阶段（A 完成阶段 / B 计划 / C 控制 / D~N 实质性 / S 专项）分组。点某张底稿看右侧详情（结构、公式、编码）。这里是「看」骨架，项目里才是「填」数据。

### 2. 公式管理
展示三类公式（**只读**，编辑走下方说明）：
- **预填充公式**：底稿从试算表/调整分录自动取数的公式（`TB` / `TB_SUM` / `ADJ` / `PREV` / `WP`）
- **报表公式**：四套准则下报表各行的勾稽/汇总公式（`ROW` / `SUM_ROW`），无效引用会标红
- **跨底稿引用**：底稿之间的数据引用关系

平台已内置**所有企业通用的一套预设公式**；项目里如需自定义，走底稿页内的公式编辑入口（自定义公式仅作用于当前项目，不影响模板库）。

### 3. 审计报告模板
审计报告正文模板（无保留/保留/否定/无法表示意见 四类 + 强调事项段）。按项目变体（国企/上市 × 单体/合并）取用。

### 4. 附注模板
财务报表附注章节模板，分上市/国企两套变体。附注的章节结构、表格骨架在此维护。

### 5. 编码体系
底稿编码规则（A1 / D2-1 / F3A 等命名体系），保证全平台编码一致。

### 6. 报表配置
四套准则的报表行定义（资产负债表/利润表/现金流量表/所有者权益变动表/现金流量附表）：行次、项目名、公式、是否合计行、科目→报表行映射。

### 7. 枚举字典
下拉选项字典（如控制测试结论、风险等级等），统一全平台下拉值。

### 8. 高级查询
跨模块自定义查询构建器：选字段、分组、透视、导出。仅 admin / 现场经理 / 业务合伙人 可用构建器。

## 五、权限说明

模板库是全局主数据，**只有管理角色能改**：

- **admin / 业务合伙人**：种子加载、编辑类操作
- **其他角色**：只读浏览

看到某些按钮灰掉/隐藏，是角色权限所致，属正常。

## 六、常见问题

**Q：模板库改了，项目里为什么没变？**
A：模板库是「模板」，项目实例化时拷贝一份。已存在的项目不会自动回灌，需重新生成对应底稿或新建项目才用到新模板。

**Q：公式覆盖率上不去？**
A：先确认种子 9/9 全绿；报表公式按准则分别配置，切换「报表公式」子页逐套检查覆盖率。

**Q：公式管理里为什么不能直接编辑？**
A：模板库公式是平台通用预设，只读展示。项目级自定义公式在底稿页内编辑，仅作用于当前项目。

**Q：种子加载失败/部分加载？**
A：种子加载幂等，重新点「加载」即可；仍失败看后端日志，多为数据文件缺失或格式问题。
