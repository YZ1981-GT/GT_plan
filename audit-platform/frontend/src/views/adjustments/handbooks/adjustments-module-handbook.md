# 调整分录模块 · 使用手册

本模块集中管理项目的**审计调整（AJE）**与**重分类调整（RJE）**，是全项目调整分录的唯一登记中心。各科目底稿编制的调整分录可汇聚到此，合伙人在此跨循环审阅、复核，并统一触发试算表审定数与报表数据的重算。

---

## 一、核心概念

| 概念 | 说明 |
|------|------|
| 审计调整（AJE） | 因错报、漏记等对未审数进行的调整，影响审定数 |
| 重分类调整（RJE） | 科目列报口径调整（如流动/非流动、应收/预付互转），不改变损益 |
| 分录组（entry group） | 一笔完整分录（含多条借贷明细行），借贷必须平衡 |
| 来源 · 手工录入 | 在本模块直接新建/录入的分录 |
| 来源 · 底稿汇聚 | 从各科目底稿点击"同步到调整分录模块"汇聚而来的分录 |
| 复核状态 | 草稿 → 待复核 → 已通过/已驳回，用于合伙人审批留痕 |

---

## 二、主要功能

### 1. 新建 / 编辑分录
- 点击顶部「**新建分录**」，选择类型（审计调整 / 重分类），录入摘要、借贷科目与金额。
- 「**快捷模板**」提供坏账计提、固定资产折旧、收入截止、流动/非流动重分类等常用分录一键填充。
- 借贷不平衡时**无法保存/提交**（底部实时显示借方合计、贷方合计、平衡状态）。

### 2. 批量模式
- 打开「**批量模式**」开关后，多笔分录先暂存，**提交后一次性触发试算表重算**（避免逐笔重算的性能开销）。
- 底部浮动条显示待提交笔数，点击「批量提交」统一入库并重算。

### 3. 来源筛选
- 顶部「全部来源 / 手工录入 / 底稿汇聚」用于按来源过滤列表，快速区分谁录入的分录。

### 4. 复核与协作
- 「**待协作**」查看指派给自己或待补充的分录。
- 分录可流转复核状态，合伙人审批（通过 / 驳回并填写原因）。

### 5. 导入导出
- 「**导出汇总**」导出审计调整汇总表（xlsx）。
- 「**Excel 导入**」批量导入分录；「**导出模板**」下载标准录入模板。

### 6. 来源追溯
- 列表「来源」列标注分录来自哪张底稿，点击可**跳转回来源底稿**核对。

### 7. AI 辅助
- 顶部提示"AI 生成内容待确认"时，点「查看明细」逐条确认 AI 拟建的分录后方可采纳（AI 仅起草，须人工确认）。

## 三、联动关系

```
科目底稿（调整分录 tab）──同步到调整分录模块──▶ 本模块（集中登记）
                                                    │
                                                    ├─▶ 试算表：更新审定数（未审 + AJE + RJE = 审定）
                                                    └─▶ 报表：审定数据随之刷新
```

- 底稿→集中：各底稿点「同步到调整分录模块」汇聚（幂等，重复同步不产生重复分录）。
- 集中→试算表/报表：分录入库后自动/批量触发重算。
- 审定表（各循环 X-1）：可从集中登记「带入调整」到审定表的账项调整/重分类列。

---

## 四、注意事项

> **借贷必须平衡**：任一分录组借方合计 ≠ 贷方合计时不能提交。

> **底稿来源分录在本模块只读**：来源为"底稿汇聚"的分录不能在本模块直接编辑，请回**来源底稿**修改后重新点"同步到调整分录模块"，避免覆盖底稿数据。

> **已通过（approved）的分录被锁定**：重新同步时不会覆盖已复核通过的分录。

> **批量模式提交才重算**：批量模式下未点"批量提交"前，试算表/报表不会更新。

> **AI 分录须人工确认**：AI 生成内容为辅助线索，必须逐条确认后才纳入正式分录。

> **删除来源底稿产生的孤儿分录**：清空底稿条目后本模块可能残留草稿分录，可在本模块手动删除清理。

## 五、常见问题

**Q：底稿里编了调整分录，为什么本模块看不到？**
A：需要在底稿的调整分录 tab 点击「同步到调整分录模块」按钮，数据才会汇聚过来（非自动实时）。

**Q：为什么"底稿汇聚"的分录编辑按钮是灰的？**
A：底稿是唯一数据源，本模块对底稿来源分录只读，请回来源底稿修改后重新同步。

**Q：改了分录，试算表/报表没变？**
A：确认是否处于批量模式（需点"批量提交"）；非批量模式下入库即重算，可稍等或刷新页面。
