# 调整分录模块 · 使用手册

本模块集中登记项目的**审计调整（AJE）**与**重分类调整（RJE）**：手工录入、Excel 导入、各科目底稿推送的分录都汇聚到这里，经提交复核、批准后计入试算表审定数，报表与附注随之更新。

---

## 一、分录的状态

| 状态 | 含义 | 能做什么 |
|------|------|------|
| 草稿 | 刚录入 / 导入 / 从底稿同步来，**不计入试算表** | 编辑、提交复核、删除 |
| 待复核 | 已提交，等复核人处理，不能修改 | 复核人：通过、驳回；编制人：撤回提交 |
| 已批准 | **计入试算表审定数** | 复核人：撤回复核（回到草稿，审定数随之回退） |
| 已驳回 | 复核人退回，附驳回原因 | 编辑后重新提交、删除；审计调整可转为未更正错报 |

> 只有**已批准**的分录计入审定数。页面顶部「已计入试算表」显示的是已批准的笔数与科目数。

---

## 二、录入

- 点「**+ 新建分录**」：选类型（审计调整 / 重分类），编号可留空自动生成（AJE-001、RJE-001），也可按事务所编号填写（同一年度不能重复）。
- 「**模板**」提供坏账、存货跌价、折旧、摊销、职工薪酬、收入截止、所得税和常见重分类，按科目名称匹配本项目科目；匹配不到的行会提示，请手工选择。
- 明细行规则：每行选科目；金额不能为负（冲减录入到相反方向）；同一行只填借方或贷方；整笔借贷相等且大于 0。弹窗底部实时显示合计与差额，「差额补平」把差额填进最后一个还没填金额的行（没有就新加一行）。
- 可从 Excel 复制「科目编码、科目名称、借方、贷方」多行，点明细表后粘贴；在分录列表上粘贴会打开新建弹窗预填，确认后保存。
- 「保存草稿」只建草稿；「保存并提交复核」保存后直接选择复核人提交。

## 三、Excel 导入

1. 「Excel 导入」→ 下载**国企版 / 上市版**模板（与项目版本一致），在审计调整、重分类两张表里填写；科目名称可从【项目科目库】页复制。
2. 选择导入方式：
   - **追加**：每笔都新建为草稿（自动编号）；
   - **按编号覆盖**：同编号的草稿 / 已驳回分录整笔替换；已提交、已批准或底稿来源的同编号分录跳过并说明原因。
3. **预检**：逐笔列出来源行、科目匹配结果、借贷合计和问题（如科目找不到、借贷不平衡），此时不写入。
4. 导入：可导入的逐笔保存，一笔失败不影响其他笔；结果停留在弹窗，可一键把本次导入的分录提交复核。

分组规则：同一编号的多行为一笔（不相邻也合并）；不填编号的连续行，借贷合计平衡时自动成为一笔。

## 四、提交复核与通知

- 草稿或已驳回的分录，勾选后点「提交复核」（或行内按钮），选择要通知的复核人（默认本项目全部有复核权限的成员），可写备注。
- 复核人在「待复核」筛选里处理：**通过**、**驳回**（必须填原因，批量时可逐笔填写）；已批准的可**撤回复核**。
- 站内通知：
  - 提交 → 所选复核人；
  - 通过 / 驳回 / 撤回复核 → 分录编制人；
  - 手工录入的分录通过或撤回复核（会改试算表）→ 受影响科目对应底稿的负责人；
  - 底稿推送的新分录 / 修改 → 相关科目底稿负责人。
- 点通知直接打开调整大厅并定位、高亮那笔分录。

## 五、底稿推送

- 各科目底稿「调整分录」页签点「同步到调整分录」，分录以草稿汇聚到这里，「来源」列显示底稿编码，点击可回到来源底稿。
- 重复同步：内容没变提示「未变化」、不重复通知；内容变了会更新这笔分录，原为待复核 / 已驳回的回到草稿，需要重新提交。
- 底稿来源的分录不在这里改明细，请回来源底稿修改后重新同步；来源底稿已删除的会标「底稿已删除」，确认无用后可在这里删除。

## 六、联动

```
手工录入 / Excel 导入 / 底稿推送 ──▶ 草稿 ──提交──▶ 待复核 ──通过──▶ 已批准
                                                          │
                                                          ├─▶ 试算表审定数重算（未审 + AJE + RJE = 审定）
                                                          └─▶ 报表、附注、相关底稿标记待更新
```

- 撤回复核后试算表与下游随之回退。项目被合并锁定时，通过 / 驳回 / 撤回复核与导入都会被拒绝。
- 每笔分录「更多」里可查看影响范围（报表行 / 底稿）、关联底稿、变更历史、协作补充。

## 七、常见问题

**Q：录完分录，试算表为什么没变？**
A：草稿不计入试算表。提交复核并经复核人批准后才计入审定数。

**Q：导入提示「科目在项目科目库中找不到」？**
A：模板里填的科目名称要与【项目科目库】一致；或先在【试算表 → 科目映射】把客户科目映射到标准科目。

**Q：本项目科目下拉是空的？**
A：项目还没有标准科目，请先在【试算表 → 科目映射】导入科目表并完成映射。

**Q：提交复核时没有可选的复核人？**
A：本项目还没有其他有复核权限的成员，请在项目团队中委派项目经理或合伙人。
